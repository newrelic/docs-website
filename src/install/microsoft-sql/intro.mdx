Our Microsoft SQL Server integration collects and sends metric and inventory data from your Microsoft SQL Server environment to our platform to equip you to monitor the health of your Microsoft SQL Server environment. We collect both database and instance-level metrics so you can troubleshoot and resolve performance problems.

<Callout variant="tip" title="OpenTelemetry integration">
    You can also use the [Microsoft SQL Server integration with OpenTelemetry](/docs/opentelemetry/db360/mssql/introduction/) for your new setups. This approach provides vendor-neutral telemetry data collection, lower resource overhead, and direct alignment with OpenTelemetry standards.
</Callout>
