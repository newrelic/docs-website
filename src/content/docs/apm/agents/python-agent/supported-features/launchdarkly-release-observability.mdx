The New Relic Python agent integrates with LaunchDarkly feature management so you can observe how feature flags and releases affect your application. This integration uses the LaunchDarkly observability plugin and OpenTelemetry support in the Python agent to connect your LaunchDarkly data with your New Relic APM data.

This document explains how to install the required packages and enable the integration.

## Prerequisites [#prerequisites]

Before you begin, make sure you have:

* A New Relic [license key](/docs/apis/intro-apis/new-relic-api-keys/#license-key)
* A LaunchDarkly account and license
* An application written in Python and monitored with the [New Relic Python APM agent](/docs/apm/agents/python-agent/installation/install-new-relic-python-agent)
* Access to the LaunchDarkly OpenTelemetry (OTel) beta

<Callout variant="important">
  The LaunchDarkly OpenTelemetry integration is currently in beta. Contact LaunchDarkly to request access before you continue.
</Callout>

## Install the required packages [#install-packages]

Install the following Python packages in the same environment as your application:

* `newrelic`
* `launchdarkly-observability`

```bash
pip install newrelic launchdarkly-observability
```

The following packages are also required. They should be installed automatically as dependencies of `launchdarkly-observability`:

* `opentelemetry-api`
* `launchdarkly-eventsource`
* `launchdarkly-server-sdk`
* `launchdarkly-server-sdk-otel`

If these packages aren't installed automatically, install them manually:

```bash
pip install opentelemetry-api launchdarkly-eventsource launchdarkly-server-sdk launchdarkly-server-sdk-otel
```

## Enable the integration [#enable-integration]

To turn on the integration, enable both the `launch_darkly_integration.enabled` and `opentelemetry.enabled` settings. You only need to use one of the following configuration methods.

### Option 1: Use newrelic.ini [#newrelic-ini]

Add the following to your `newrelic.ini` file:

```ini
launch_darkly_integration.enabled = true
opentelemetry.enabled = true
```

### Option 2: Use pyproject.toml [#pyproject-toml]

Add the following to your `pyproject.toml` file:

```toml
[tool.newrelic]
launch_darkly_integration.enabled = true
opentelemetry.enabled = true
```

### Option 3: Use environment variables [#environment-variables]

Set the following environment variables:

```bash
export NEW_RELIC_LAUNCH_DARKLY_ENABLED=true
export NEW_RELIC_OPENTELEMETRY_ENABLED=true
```

<Callout variant="tip">
  For more information about the OpenTelemetry setting, see the [Python agent configuration](/docs/apm/agents/python-agent/configuration/python-agent-configuration#opentelemetry-enabled) documentation.
</Callout>

## Verify the integration [#verify]

After you enable the settings, restart your application so the Python agent picks up the new configuration. Then generate some traffic and confirm that your application is still reporting data in [**APM &amp; services**](/docs/apm/apm-ui-pages/monitoring/apm-summary-page-view-transaction-apdex-usage-data).
