Install the New Relic Python agent for background tasks, queue workers, cron jobs, Celery tasks, and other non-web Python processes. These appear as [non-web transactions](/docs/apm/transactions/intro-transactions/monitor-background-processes-other-non-web-transactions) in APM, separate from your web traffic metrics.

## Prerequisites [#prerequisites]

<Steps>
  <Step>
    ## Install the agent [#install]

    Install the Python agent package using pip:

    ```sh
    pip install newrelic
    ```
  </Step>

  <Step>
    ## Configure the agent [#configure]

    Generate the `newrelic.ini` configuration file in your project directory:

    ```sh
    newrelic-admin generate-config YOUR_LICENSE_KEY newrelic.ini
    ```

    Open `newrelic.ini` and set your app name — this is the only other setting you **must** change:

    ```ini
    app_name = Your Application Name
    ```

    For all other configuration options, see [Python agent configuration](/docs/apm/agents/python-agent/configuration/python-agent-configuration).
  </Step>

  <Step>
    ## Start your worker with the agent [#start]

    Prefix your normal worker startup command with `newrelic-admin run-program` and the config file path:

    ```sh
    NEW_RELIC_CONFIG_FILE=newrelic.ini newrelic-admin run-program YOUR_WORKER_COMMAND
    ```

    **Celery examples:**

    ```sh
    # Celery worker
    NEW_RELIC_CONFIG_FILE=newrelic.ini newrelic-admin run-program celery -A tasks worker --loglevel=info

    # Celery via Django manage.py
    NEW_RELIC_CONFIG_FILE=newrelic.ini newrelic-admin run-program python manage.py celery YOUR_COMMAND_OPTIONS
    ```

    **Other worker examples:**

    ```sh
    # Python script
    NEW_RELIC_CONFIG_FILE=newrelic.ini newrelic-admin run-python my_worker.py

    # Any executable
    NEW_RELIC_CONFIG_FILE=newrelic.ini newrelic-admin run-program python main.py
    ```

    <Callout variant="tip">
      You can also pass the license key and app name as environment variables instead of using a config file:

      ```sh
      NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
      NEW_RELIC_APP_NAME="Your Application Name" \
      newrelic-admin run-program celery -A tasks worker
      ```
    </Callout>
  </Step>

  <Step>
    ## Verify data is flowing [#verify]

    Trigger at least two task executions, then wait 2–3 minutes and open [one.newrelic.com > APM](https://one.newrelic.com/apm). Look for your app by name, then check **Transactions > Non-web** to see your background tasks.

    <Callout variant="tip">
      App not appearing? Run `newrelic-admin validate-config newrelic.ini` to test connectivity, or see [No data appears (Python)](/docs/apm/agents/python-agent/troubleshooting/no-data-appears-python).
    </Callout>
  </Step>
</Steps>
