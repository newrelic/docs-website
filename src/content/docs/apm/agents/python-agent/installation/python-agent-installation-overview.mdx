Our Python agent auto-instruments your code so you can start monitoring applications. Choose the install method below that matches your environment.

You need a [New Relic account](https://newrelic.com/signup) and your <InlinePopover type="licenseKey"/> to complete installation. See [Python agent compatibility and requirements](/docs/apm/agents/python-agent/getting-started/compatibility-requirements-python-agent) before you begin.

## Choose your install method [#install-method]

<CollapserGroup>
  <Collapser
    id="guided"
    title="Standard web application install (Django, Flask, FastAPI, Gunicorn, and more)"
  >
    The standard path for Python apps running in any supported web framework (Django, Flask, FastAPI, Gunicorn, uWSGI, CherryPy, and more). The guided install walks you through pip install, config file generation, and agent integration.

    [Start guided install →](https://one.newrelic.com/marketplace/install-data-source?state=2a8ce851-ad2d-4587-0302-abfffe94d296)
  </Collapser>

  <Collapser
    id="heroku"
    title="Heroku"
  >
    The Python agent can be installed on Heroku via the New Relic add-on or manually. Covers add-on installation, config var setup, and testing the connection.

    [Install on Heroku →](/docs/apm/agents/python-agent/hosting-services/python-agent-heroku)
  </Collapser>

  <Collapser
    id="gae"
    title="Google App Engine flexible environment"
  >
    Install the Python agent in a GAE flex app using either GAE's native mode or a custom Docker runtime.

    [Install in GAE flexible environment →](/docs/apm/agents/python-agent/hosting-services/install-python-agent-gae-flexible-environment)
  </Collapser>

  <Collapser
    id="azure"
    title="Microsoft Azure App Service or Container Apps"
  >
    Install the Python agent on Azure App Service or Azure Container Apps to monitor your Azure-managed Python applications.

    [Install on Azure →](/docs/apm/agents/python-agent/hosting-services/python-azure-containerapps-appservice)
  </Collapser>

  <Collapser
    id="non-web"
    title="Non-web scripts, background tasks, and workers"
  >
    The Python agent also monitors non-web scripts, worker processes, task queues, and functions. Installation is similar to web apps, but you manually wrap the functions you want to monitor.

    See [Python background tasks](/docs/apm/agents/python-agent/supported-features/python-background-tasks) for details. For Celery tasks, see [Celery background tasks](/docs/apm/agents/python-agent/back-end-services/python-agent-celery).
  </Collapser>
</CollapserGroup>

## After you install [#after-install]

Once your app is reporting data, your next steps:

* [View your app in APM](/docs/apm/applications-menu/monitoring/apm-overview-page) — check the Summary page, transactions, and error rates
* [Configure the Python agent](/docs/apm/agents/python-agent/configuration/python-agent-configuration) — set log level, proxy, distributed tracing, and more in `newrelic.ini`
* [Add custom instrumentation](/docs/apm/agents/python-agent/custom-instrumentation/python-custom-instrumentation) — instrument code the agent doesn't cover automatically
* [Check compatibility and requirements](/docs/apm/agents/python-agent/getting-started/compatibility-requirements-python-agent) — supported frameworks and libraries
