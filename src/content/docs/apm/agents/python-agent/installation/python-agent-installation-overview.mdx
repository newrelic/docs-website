Install the New Relic Python agent to start monitoring your Python application. Choose the method that matches your environment from the left navigation.

You need a [New Relic account](https://newrelic.com/signup) and your <InlinePopover type="licenseKey"/> to complete installation. See [Python agent compatibility and requirements](/docs/apm/agents/python-agent/getting-started/compatibility-requirements-python-agent) before you begin.

| Method | Use when |
|---|---|
| [Web application](/docs/apm/agents/python-agent/installation/python-agent-installation-web-app) | Django, Flask, FastAPI, Gunicorn, uWSGI, CherryPy, and other WSGI/ASGI frameworks |
| [Non-web scripts and workers](/docs/apm/agents/python-agent/installation/python-agent-installation-non-web) | Celery, cron jobs, queue workers, background tasks, and standalone scripts |
| [Heroku](/docs/apm/agents/python-agent/hosting-services/python-agent-heroku) | Apps deployed on Heroku using the New Relic add-on |
| [Google App Engine](/docs/apm/agents/python-agent/hosting-services/install-python-agent-gae-flexible-environment) | Apps running in the GAE flexible environment |
| [Microsoft Azure](/docs/apm/agents/python-agent/hosting-services/python-azure-containerapps-appservice) | Azure App Service or Azure Container Apps |
