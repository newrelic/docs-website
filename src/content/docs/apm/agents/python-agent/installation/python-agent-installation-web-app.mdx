Install the New Relic Python agent for web applications running any supported WSGI or ASGI framework — Django, Flask, FastAPI, Gunicorn, uWSGI, CherryPy, and more.

<Steps>
  <Step>
    ## Install the agent [#install]

    Install the Python agent package using pip:

    ```sh
    pip install newrelic
    ```
  </Step>

  <Step>
    ## Configure the agent [#configure]

    Generate the `newrelic.ini` configuration file in your project directory:

    ```sh
    newrelic-admin generate-config YOUR_LICENSE_KEY newrelic.ini
    ```

    Open `newrelic.ini` and set your app name — this is the only other setting you **must** change:

    ```ini
    app_name = Your Application Name
    ```

    For all other configuration options, see [Python agent configuration](/docs/apm/agents/python-agent/configuration/python-agent-configuration).
  </Step>

  <Step>
    ## Start your app with the agent [#start]

    Prefix your normal web server startup command with `newrelic-admin run-program` and the config file path:

    ```sh
    NEW_RELIC_CONFIG_FILE=newrelic.ini newrelic-admin run-program YOUR_WEB_SERVER_COMMAND
    ```

    For example:

    ```sh
    # Gunicorn
    NEW_RELIC_CONFIG_FILE=newrelic.ini newrelic-admin run-program gunicorn myapp.wsgi

    # uWSGI
    NEW_RELIC_CONFIG_FILE=newrelic.ini newrelic-admin run-program uwsgi --http :8000 --module myapp.wsgi

    # Django development server
    NEW_RELIC_CONFIG_FILE=newrelic.ini newrelic-admin run-program python manage.py runserver
    ```

    <Callout variant="tip">
      You can also pass the license key and app name as environment variables instead of using a config file:

      ```sh
      NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
      NEW_RELIC_APP_NAME="Your Application Name" \
      newrelic-admin run-program gunicorn myapp.wsgi
      ```
    </Callout>
  </Step>

  <Step>
    ## Verify data is flowing [#verify]

    Send at least two requests to your application, then wait 2–3 minutes and open [one.newrelic.com > APM](https://one.newrelic.com/apm) to look for your app by name.

    <Callout variant="tip">
      App not appearing? Run `newrelic-admin validate-config newrelic.ini` to test connectivity, or see [No data appears (Python)](/docs/apm/agents/python-agent/troubleshooting/no-data-appears-python).
    </Callout>
  </Step>
</Steps>
