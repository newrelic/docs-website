Install the New Relic Python agent on [Microsoft Azure App Service](https://learn.microsoft.com/en-us/azure/app-service/overview) or [Azure Container Apps](https://learn.microsoft.com/en-us/azure/container-apps/overview).

<Callout variant="tip">
  If you want to integrate New Relic without modifying your application code, see the [touchless integration method](/docs/apm/agents/python-agent/hosting-services/python-azure-touchless-integration).
</Callout>

## Prerequisites [#prerequisites]

<table>
  <thead>
    <tr>
      <th style={{ width: "200px" }}>Requirement</th>
      <th>Details</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>**New Relic account**</td>
      <td>You need a [New Relic account](https://newrelic.com/signup) and your <InlinePopover type="licenseKey"/>.</td>
    </tr>
    <tr>
      <td>**Azure platform**</td>
      <td>A Python app running on Azure App Service or Azure Container Apps.</td>
    </tr>
    <tr>
      <td>**Azure CLI**</td>
      <td>The [Azure CLI](https://learn.microsoft.com/en-us/cli/azure/install-azure-cli-macos) installed in your environment.</td>
    </tr>
    <tr>
      <td>**Python version**</td>
      <td>See [Python agent compatibility and requirements](/docs/apm/agents/python-agent/getting-started/compatibility-requirements-python-agent) for supported versions.</td>
    </tr>
  </tbody>
</table>

<Callout variant="tip">
  The Python agent does not capture telemetry for Azure Functions. Use the [Azure Functions monitoring integration](/docs/infrastructure/microsoft-azure-integrations/azure-integrations-list/azure-functions-monitoring-integration/) for Azure Functions data.
</Callout>

<Steps>
  <Step>
    ## Install the agent [#install]

    Add `newrelic` to your `requirements.txt` file:

    ```
    newrelic
    ```

    Initialize the agent at startup using one of these methods:

    <Tabs>
      <TabsBar>
        <TabsBarItem id="app-code">Initialize in app code</TabsBarItem>
        <TabsBarItem id="dockerfile">Initialize via Dockerfile entrypoint</TabsBarItem>
      </TabsBar>
      <TabsPages>
        <TabsPageItem id="app-code">
          Import `newrelic.agent` and call `initialize()` at the top of your app before any other imports:

          ```python
          import newrelic.agent
          newrelic.agent.initialize()
          ```
        </TabsPageItem>
        <TabsPageItem id="dockerfile">
          Add a New Relic entrypoint in your `Dockerfile`:

          ```dockerfile
          ENTRYPOINT ["newrelic-admin", "run-program", "YOUR_NORMAL_STARTUP_COMMAND"]
          ```
        </TabsPageItem>
      </TabsPages>
    </Tabs>
  </Step>

  <Step>
    ## Configure the agent [#configure]

    Set your app name and license key as Azure application settings (App Service) or secrets (Container Apps):

    | Setting | Value |
    |---|---|
    | `NEW_RELIC_LICENSE_KEY` | Your New Relic license key |
    | `NEW_RELIC_APP_NAME` | The name that will appear in New Relic |

    For all other configuration options, see [Python agent configuration](/docs/apm/agents/python-agent/configuration/python-agent-configuration).
  </Step>

  <Step>
    ## Verify data is flowing [#verify]

    Deploy your app and send at least two requests. Wait 2–3 minutes and open [one.newrelic.com > APM](https://one.newrelic.com/apm) to look for your app by name.

    <Callout variant="tip">
      App not appearing? See [No data appears (Python)](/docs/apm/agents/python-agent/troubleshooting/no-data-appears-python).
    </Callout>
  </Step>
</Steps>
