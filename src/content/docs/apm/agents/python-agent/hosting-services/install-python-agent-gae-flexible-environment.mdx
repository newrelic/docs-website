Install the New Relic Python agent in a [Google App Engine (GAE) flexible environment](https://cloud.google.com/appengine/docs/flexible/python/) using either GAE's native mode or a custom Docker runtime.

## Prerequisites [#prerequisites]

<table>
  <thead>
    <tr>
      <th style={{ width: "200px" }}>Requirement</th>
      <th>Details</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>**New Relic account**</td>
      <td>You need a [New Relic account](https://newrelic.com/signup) and your <InlinePopover type="licenseKey"/>.</td>
    </tr>
    <tr>
      <td>**Google Cloud project**</td>
      <td>A Google Cloud Platform project with an App Engine application created. See [Google App Engine procedures for Python](https://cloud.google.com/appengine/docs/flexible/python/managing-projects-apps-billing#create).</td>
    </tr>
    <tr>
      <td>**Google Cloud SDK**</td>
      <td>The `gcloud` CLI installed and initialized. See [Google Cloud SDK docs](https://cloud.google.com/sdk/docs/).</td>
    </tr>
    <tr>
      <td>**Python version**</td>
      <td>See [Python agent compatibility and requirements](/docs/apm/agents/python-agent/getting-started/compatibility-requirements-python-agent) for supported versions.</td>
    </tr>
  </tbody>
</table>

<Steps>
  <Step>
    ## Install the agent and configure your app [#install]

    Add `newrelic` to your `requirements.txt` file:

    ```
    newrelic
    ```

    <Tabs>
      <TabsBar>
        <TabsBarItem id="native-mode">Native mode (Flask or Django)</TabsBarItem>
        <TabsBarItem id="docker-runtime">Custom Docker runtime</TabsBarItem>
      </TabsBar>
      <TabsPages>
        <TabsPageItem id="native-mode">
          When using GAE native mode, provide your app code and an `app.yaml`. GAE deploys to a standard prebuilt Docker image automatically. No Dockerfile is needed.

          Set the `NEW_RELIC_CONFIG_FILE` environment variable pointing to `newrelic.ini` in your `app.yaml`:

          ```yaml
          env_variables:
            NEW_RELIC_CONFIG_FILE: newrelic.ini
          ```
        </TabsPageItem>
        <TabsPageItem id="docker-runtime">
          If your app needs specific libraries or headers, use a custom runtime. Set `app.yaml` to:

          ```yaml
          runtime: custom
          env: flex
          ```

          Set the `NEW_RELIC_CONFIG_FILE` environment variable in your `Dockerfile` pointing to `newrelic.ini`:

          ```dockerfile
          ENV NEW_RELIC_CONFIG_FILE newrelic.ini
          ```
        </TabsPageItem>
      </TabsPages>
    </Tabs>
  </Step>

  <Step>
    ## Configure the agent [#configure]

    Generate the `newrelic.ini` configuration file:

    ```bash
    newrelic-admin generate-config YOUR_LICENSE_KEY newrelic.ini
    ```

    Edit `newrelic.ini` and set the two required values:

    1. Confirm `license_key` is set to your <InlinePopover type="licenseKey"/>.
    2. Set `app_name` to a meaningful name for your application.

    For all other configuration options, see [Python agent configuration](/docs/apm/agents/python-agent/configuration/python-agent-configuration).
  </Step>

  <Step>
    ## Deploy and verify [#verify]

    Deploy your app:

    ```bash
    gcloud app deploy
    ```

    Wait until the deployment completes. Send at least two requests, then wait 2–3 minutes and open [one.newrelic.com > APM](https://one.newrelic.com/apm) to look for your app by name.

    <Callout variant="tip">
      App not appearing? See [No data appears (Python)](/docs/apm/agents/python-agent/troubleshooting/no-data-appears-python).
    </Callout>
  </Step>
</Steps>
