This page covers installing the New Relic Java agent using Maven. Maven downloads and unpacks `newrelic-java.zip` as a build dependency, placing the agent files in your build directory automatically.

## Compatibility and requirements [#requirements]

### Supported

- Java 8, 11, 17, 21, 24, 25, and 26
- Maven 3.x
- `maven-dependency-plugin` 3.1.1 or higher
- Any supported app server or standalone JVM process that accepts a `-javaagent` argument

### Not supported

- Java 7 — supported through Java agent v6.5.4 only; not supported on current agent versions
- SHA-1 — your app server must support SHA-2 (256-bit); SHA-1 is not supported

### You need

- A New Relic account and <InlinePopover type="licenseKey"/>
- A Maven project with `pom.xml`

## Install [#install]

<Steps>
  <Step>
    ## Configure Maven to download `newrelic-java.zip` [#install-step-1]

    Add the Java agent as a `provided` dependency in your `pom.xml`. Replace `JAVA_AGENT_VERSION` with the [latest Java agent version](/docs/release-notes/agent-release-notes/java-release-notes/current):

    ```xml
    <dependency>
        <groupId>com.newrelic.agent.java</groupId>
        <artifactId>newrelic-java</artifactId>
        <version>JAVA_AGENT_VERSION</version>
        <scope>provided</scope>
        <type>zip</type>
    </dependency>
    ```
  </Step>

  <Step>
    ## Configure Maven to unzip the agent [#install-step-2]

    Add `maven-dependency-plugin` to the `<build><plugins>` section of your `pom.xml` to unpack the agent zip into your build directory:

    ```xml
    <plugin>
        <groupId>org.apache.maven.plugins</groupId>
        <artifactId>maven-dependency-plugin</artifactId>
        <version>3.1.1</version>
        <executions>
            <execution>
                <id>unpack-newrelic</id>
                <phase>package</phase>
                <goals>
                    <goal>unpack-dependencies</goal>
                </goals>
                <configuration>
                    <includeGroupIds>com.newrelic.agent.java</includeGroupIds>
                    <includeArtifactIds>newrelic-java</includeArtifactIds>
                    <overWriteReleases>false</overWriteReleases>
                    <overWriteSnapshots>false</overWriteSnapshots>
                    <overWriteIfNewer>true</overWriteIfNewer>
                    <outputDirectory>${project.build.directory}</outputDirectory>
                </configuration>
            </execution>
        </executions>
    </plugin>
    ```

    After running `mvn package`, a `newrelic/` folder appears in `target/` containing:
    - `newrelic.jar` — the Java agent
    - `newrelic.yml` — the agent configuration file
    - `newrelic-api.jar` — the Java agent API jar
    - `README`

    <CollapserGroup>
      <Collapser id="full-pom-example" title="Full pom.xml example">
        ```xml
        <project xmlns="http://maven.apache.org/POM/4.0.0"
        ```

    </CollapserGroup>
  </Step>

  <Step>
    ## Pass the `-javaagent` argument [#install-step-3]

    Add the `-javaagent` JVM argument pointing to `newrelic.jar` when starting your application. The exact method depends on your app server — see [Pass the JVM argument for your server](/docs/apm/agents/java-agent/installation/java-agent-installation-app-servers#install-step-4) for server-specific instructions.

    For a Spring Boot jar, for example:

    ```bash
    java -javaagent:/path/to/target/newrelic/newrelic.jar -jar my-example-app.jar
    ```
  </Step>
</Steps>

## Configure [#configure]

Edit `target/newrelic/newrelic.yml` and set two required values:

```yaml
license_key: 'YOUR_LICENSE_KEY'
app_name: 'My Application'
```

The agent reads `newrelic.yml` from the same directory as `newrelic.jar` at startup. You can also override any setting using Java system properties (e.g. `-Dnewrelic.config.license_key=YOUR_KEY`) or environment variables.

See [Java agent configuration](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file) for all available options.

## Verify your install [#verify]

Restart your application. Send at least two requests, then wait 2–3 minutes and your app appears in [APM & services](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29).

If no data appears after five minutes, see [No data appears (Java)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java).
