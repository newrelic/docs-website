Install the New Relic Java agent to start monitoring your Java application. Choose the method that matches your environment from the left navigation.

You need a [New Relic account](https://newrelic.com/signup) and your <InlinePopover type="licenseKey"/> to complete installation. See [Java agent compatibility and requirements](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent) before you begin.

| Method | Use when |
|---|---|
| [App servers and standalone JVM](/docs/apm/agents/java-agent/installation/java-agent-installation-app-servers) | Tomcat, Spring Boot, JBoss/WildFly, Glassfish, Jetty, WebLogic, WebSphere, and any JVM that accepts `-javaagent` |
| [Docker](/docs/apm/agents/java-agent/additional-installation/install-new-relic-java-agent-docker) | Containerized Java applications |
| [Maven](/docs/apm/agents/java-agent/installation/java-agent-installation-maven) | Download and unzip the agent as a Maven build dependency via `maven-dependency-plugin` |
| [Gradle](/docs/apm/agents/java-agent/installation/java-agent-installation-gradle) | Download and unzip the agent using Gradle tasks powered by `de.undercouch.download` |
| [Azure App Service (Windows)](/docs/apm/agents/java-agent/installation/java-agent-installation-azure) | Java apps on Azure Windows App Service via the New Relic site extension |
| [AWS Elastic Beanstalk](/docs/apm/agents/java-agent/additional-installation/aws-elastic-beanstalk-installation-java) | Tomcat or Java SE apps deployed on Elastic Beanstalk |
| [Google App Engine](/docs/apm/agents/java-agent/additional-installation/install-new-relic-java-agent-gae-flexible-environment) | Apps running in the GAE flexible environment using a custom Docker runtime |
| [AWS Lambda (serverless)](/docs/serverless-function-monitoring/aws-lambda-monitoring/enable-lambda-monitoring/enable-serverless-monitoring-aws-lambda-legacy#java) | Serverless Java functions — uses a different install path than the standard agent |
