Install the New Relic Java agent on AWS Elastic Beanstalk by adding the agent to your application bundle and configuring the `-javaagent` JVM argument through the Elastic Beanstalk console.

## Prerequisites [#prerequisites]

<table>
  <thead>
    <tr>
      <th style={{ width: "200px" }}>Requirement</th>
      <th>Details</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>**New Relic account**</td>
      <td>You need a [New Relic account](https://newrelic.com/signup) and your <InlinePopover type="licenseKey"/>.</td>
    </tr>
    <tr>
      <td>**AWS account**</td>
      <td>A supported [Amazon Web Services account](http://aws.amazon.com/elasticbeanstalk/) with your Java app deployed on Elastic Beanstalk.</td>
    </tr>
    <tr>
      <td>**Java version**</td>

    </tr>

</table>

<Steps>
  <Step>
    ## Add the agent to your application bundle [#install]

    Download `newrelic-java.zip` and extract `newrelic.jar` and `newrelic.yml`:

    ```bash
    curl -O https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip
    unzip newrelic-java.zip
    ```

    <Tabs>
      <TabsBar>
        <TabsBarItem id="tomcat-platform">Tomcat platform</TabsBarItem>
        <TabsBarItem id="java-se-platform">Java SE platform</TabsBarItem>
      </TabsBar>
      <TabsPages>
        <TabsPageItem id="tomcat-platform">
          Add `newrelic.jar` and `newrelic.yml` to `WEB-INF/lib/` in your WAR file, then repackage and deploy.
        </TabsPageItem>
        <TabsPageItem id="java-se-platform">
          Add `newrelic.jar` and `newrelic.yml` to a subdirectory in your project (for example, `opt/newrelic/`).

          Add a `Procfile` at the root of your source bundle with the `-javaagent` flag:

          ```makefile
          web: java -javaagent:opt/newrelic/newrelic.jar -jar YOUR_APPLICATION.jar
          ```

          Repackage and deploy the source bundle.
        </TabsPageItem>
      </TabsPages>
    </Tabs>
  </Step>

  <Step>
    ## Configure the agent [#configure]

    Edit `newrelic.yml` and set the two required values:

    1. Set `license_key` to your <InlinePopover type="licenseKey"/>.
    2. Set `app_name` to a meaningful name for your application.

    **Tomcat platform only** — Pass the `-javaagent` flag via the Elastic Beanstalk console:

    1. Open the Elastic Beanstalk console and select your environment.
    2. In the left pane, select **Configurations**.
    3. Scroll to **Updates, monitoring, and logging** and click **Edit**.
    4. Under **Platform Software**, add to the **JVM Options** field:

       ```
       -javaagent:/full/path/to/newrelic.jar
       ```

       To find the path to `newrelic.jar` on the EC2 instance, connect to the instance and run:

       ```bash
       sudo find /var -name "newrelic.jar"
       sudo find /usr -name "newrelic.jar"
       ```

    5. Click **Apply**.

    For all other configuration options, see [Java agent configuration](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file).
  </Step>

  <Step>
    ## Verify data is flowing [#verify]

    Elastic Beanstalk will update your environment. Send at least two requests, then wait 2–3 minutes and open [one.newrelic.com > APM](https://one.newrelic.com/apm) to look for your app by name.

    <Callout variant="tip">
      App not appearing? See [No data appears (Java)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java).
    </Callout>
  </Step>
</Steps>
