This page covers installing the New Relic Java agent on AWS Elastic Beanstalk by adding the agent to your application bundle and configuring the `-javaagent` JVM argument through the Elastic Beanstalk console.

## Compatibility and requirements [#requirements]

### Supported

- Java 8, 11, 17, 21, 24, 25, and 26
- Elastic Beanstalk Tomcat platform
- Elastic Beanstalk Java SE platform

### Not supported

- Docker containers on Elastic Beanstalk — use the [Docker install method](/docs/apm/agents/java-agent/additional-installation/install-new-relic-java-agent-docker) instead

### You need

- A New Relic account and <InlinePopover type="licenseKey"/>
- An [AWS account](http://aws.amazon.com/elasticbeanstalk/) with your Java app deployed on Elastic Beanstalk

## Install [#install]

Download `newrelic-java.zip` and extract `newrelic.jar` and `newrelic.yml`: [#install-step-1]

```bash
curl -O https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip
unzip newrelic-java.zip
```

      ```makefile
      web: java -javaagent:opt/newrelic/newrelic.jar -jar YOUR_APPLICATION.jar
      ```

## Configure [#configure]

Edit `newrelic.yml` and set the two required values:

1. Set `license_key` to your <InlinePopover type="licenseKey"/>.
2. Set `app_name` to a meaningful name for your application.

**Tomcat platform only** — Pass the `-javaagent` flag via the Elastic Beanstalk console:

1. Open the Elastic Beanstalk console and select your environment.
2. In the left pane, select **Configurations**.
3. Scroll to **Updates, monitoring, and logging** and click **Edit**.
4. Under **Platform Software**, add to the **JVM Options** field:

   ```
   -javaagent:/full/path/to/newrelic.jar
   ```

   To find the path to `newrelic.jar` on the EC2 instance, connect to the instance and run:

   ```bash
   sudo find /var -name "newrelic.jar"
   sudo find /usr -name "newrelic.jar"
   ```

5. Click **Apply**.

For all other configuration options, see [Java agent configuration](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file).

## Verify your install [#verify]

Elastic Beanstalk will update your environment. Send at least two requests, then wait 2–3 minutes and your app appears in [APM & services](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29).

If no data appears after five minutes, see [No data appears (Java)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java).
