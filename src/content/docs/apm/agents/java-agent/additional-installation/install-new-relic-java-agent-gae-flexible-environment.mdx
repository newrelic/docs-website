Install the New Relic Java agent in a [Google App Engine (GAE) flexible environment](https://cloud.google.com/appengine/docs/flexible/java/) using a custom Docker runtime.

<Callout variant="important">
  Do not use the GAE standard environment or Google App Engine's ["native mode"](https://cloud.google.com/appengine/docs/flexible/java/) — the Java agent requires a custom runtime.
</Callout>

<Steps>
  <Step>
    ## Download the agent and configure your build [#install]

    Download `newrelic-java.zip` and unzip it into your project:

    ```bash
    curl -O https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip
    unzip newrelic-java.zip
    ```

    Configure your `app.yaml` for a custom runtime:

    ```yaml
    runtime: custom
    env: flex
    ```

    Configure your `Dockerfile` to add the agent and pass the `-javaagent` argument. The example below uses Tomcat:

    ```dockerfile
    ADD ./newrelic/newrelic.jar /usr/local/tomcat/newrelic/newrelic.jar
    ENV JAVA_OPTS="$JAVA_OPTS -javaagent:/usr/local/tomcat/newrelic/newrelic.jar"
    ```

    Build your project:

    ```bash
    mvn clean install
    ```
  </Step>

  <Step>
    ## Configure the agent [#configure]

    Edit `newrelic/newrelic.yml` and set the two required values:

    1. Set `license_key` to your <InlinePopover type="licenseKey"/>.
    2. Set `app_name` to a meaningful name for your application.

    For all other configuration options, see [Java agent configuration](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file).
  </Step>

  <Step>
    ## Deploy and verify [#verify]

    Deploy to GAE:

    ```bash
    gcloud --project YOUR_PROJECT_NAME app deploy
    ```

    Wait until the deployment completes. Send at least two requests, then wait 2–3 minutes and open [one.newrelic.com > APM](https://one.newrelic.com/apm) to look for your app by name.

    <Callout variant="tip">
      App not appearing? See [No data appears (Java)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java).
    </Callout>
  </Step>
</Steps>
