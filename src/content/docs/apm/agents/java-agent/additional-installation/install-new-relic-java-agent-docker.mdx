This page covers installing the New Relic Java agent in a Docker container by adding the agent jar to your image and passing the `-javaagent` JVM argument at startup.

## Compatibility and requirements [#requirements]

### Supported

- Java 8, 11, 17, 21, 24, 25, and 26
- Any Docker image running a Java application (Tomcat, Spring Boot, or similar) that accepts a `-javaagent` JVM argument


### You need

- A New Relic account and <InlinePopover type="licenseKey"/>
- Docker installed with a Java application container

## Install [#install]

Download `newrelic-java.zip`: [#install-step-1]

```bash
curl -O https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip
unzip newrelic-java.zip
```

Add the agent jar to your `Dockerfile`. The example below uses Tomcat — adjust the path for your app server:

```dockerfile
RUN mkdir -p /usr/local/tomcat/newrelic
ADD ./newrelic/newrelic.jar /usr/local/tomcat/newrelic/newrelic.jar
ENV JAVA_OPTS="$JAVA_OPTS -javaagent:/usr/local/tomcat/newrelic/newrelic.jar"
```

Build your Docker image as usual.

## Configure [#configure]

Pass your app name and license key as environment variables when running the container:

```bash
docker run -e NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
           -e NEW_RELIC_APP_NAME="Your Application Name" \
           YOUR_IMAGE_NAME:latest
```

You can also use `ENV` directives in your `Dockerfile`:

```dockerfile
ENV NEW_RELIC_APP_NAME="Your Application Name"
```

For all other configuration options, see [Java agent configuration](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file).

## Verify your install [#verify]

Run your container and send at least two requests to your application. Wait 2–3 minutes and your app appears in [APM & services](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29).

If no data appears after five minutes, see [No data appears (Java)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java).
