Install the New Relic Java agent in a Docker container by adding the agent jar to your image and passing the `-javaagent` JVM argument at startup.

## Prerequisites [#prerequisites]

<table>
  <thead>
    <tr>
      <th style={{ width: "200px" }}>Requirement</th>
      <th>Details</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>**New Relic account**</td>
      <td>You need a [New Relic account](https://newrelic.com/signup) and your <InlinePopover type="licenseKey"/>.</td>
    </tr>
    <tr>
      <td>**Java version**</td>
      <td>See [Java agent compatibility and requirements](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent) for supported versions.</td>
    </tr>
    <tr>
      <td>**Docker**</td>
      <td>Docker installed with a Java application container (Tomcat, Spring Boot, or similar).</td>
    </tr>
  </tbody>
</table>

<Steps>
  <Step>
    ## Download the agent and add it to your image [#install]

    Download `newrelic-java.zip`:

    ```bash
    curl -O https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip
    unzip newrelic-java.zip
    ```

    Add the agent jar to your `Dockerfile`. The example below uses Tomcat — adjust the path for your app server:

    ```dockerfile
    RUN mkdir -p /usr/local/tomcat/newrelic
    ADD ./newrelic/newrelic.jar /usr/local/tomcat/newrelic/newrelic.jar
    ENV JAVA_OPTS="$JAVA_OPTS -javaagent:/usr/local/tomcat/newrelic/newrelic.jar"
    ```

    Build your Docker image as usual.
  </Step>

  <Step>
    ## Configure the agent [#configure]

    Pass your app name and license key as environment variables when running the container:

    ```bash
    docker run -e NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
               -e NEW_RELIC_APP_NAME="Your Application Name" \
               YOUR_IMAGE_NAME:latest
    ```

    You can also use `ENV` directives in your `Dockerfile`:

    ```dockerfile
    ENV NEW_RELIC_APP_NAME="Your Application Name"
    ```

    For all other configuration options, see [Java agent configuration](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file).
  </Step>

  <Step>
    ## Verify data is flowing [#verify]

    Run your container and send at least two requests to your application. Wait 2–3 minutes and open [one.newrelic.com > APM](https://one.newrelic.com/apm) to look for your app by name.

    <Callout variant="tip">
      App not appearing? See [No data appears (Java)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java).
    </Callout>
  </Step>
</Steps>
