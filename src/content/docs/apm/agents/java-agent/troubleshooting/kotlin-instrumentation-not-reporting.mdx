## Problem

If you are missing instrumentation in your Kotlin app, set [agent logs to be at the finest level](/docs/agents/java-agent/troubleshooting/generating-logs-troubleshooting-java). 

The logs should mention `ArrayIndexOutOfBoundsException`. Customers with agent version 8.2.0 and up will see the following messge:
```
Unexpected ArrayIndexOutOfBoundsException thrown during class transformation. Try restarting the Java Agent with flag -Dnewrelic.config.class_transformer.clear_return_stacks=true
```

## Solution

Make sure your Java Agent version is greater than or equal to `8.20`. If not, upgrade your Java Agent so its version is within the range (latest is preferred).

Restart the Java Agent or your Java app with the system property: 

```
-Dnewrelic.config.class_transformer.clear_return_stacks=true
```
