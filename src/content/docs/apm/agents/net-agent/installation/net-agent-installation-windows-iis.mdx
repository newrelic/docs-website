Install the New Relic .NET agent on Windows for applications hosted in IIS (.NET Framework and .NET Core).

## Prerequisites [#prerequisites]

<table>
  <thead>
    <tr>
      <th style={{ width: "200px" }}>Requirement</th>
      <th>Details</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>**New Relic account**</td>
      <td>You need a [New Relic account](https://newrelic.com/signup) and your <InlinePopover type="licenseKey"/>. Have it ready before you begin.</td>
    </tr>
    <tr>
      <td>**.NET version**</td>
      <td>See [.NET agent compatibility and requirements](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements) for supported .NET Framework and .NET Core versions.</td>
    </tr>
    <tr>
      <td>**Operating system**</td>
      <td>Windows with IIS. See [.NET agent compatibility and requirements](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements) for supported OS versions.</td>
    </tr>
    <tr>
      <td>**Permissions**</td>
      <td>Administrator rights are required to install the agent.</td>
    </tr>
  </tbody>
</table>

<Steps>
  <Step>
    ## Download the installer [#download]

    Download the MSI installer that matches your system architecture:
    - [64-bit](https://download.newrelic.com/dot_net_agent/latest_release/NewRelicDotNetAgent_x64.msi)
    - [32-bit](https://download.newrelic.com/dot_net_agent/latest_release/NewRelicDotNetAgent_x86.msi)
  </Step>

  <Step>
    ## Install the agent [#install]

    Run the MSI installer. When prompted:
    - Enter your <InlinePopover type="licenseKey"/>
    - Leave **Instrument all** unselected if you want to monitor only IIS-hosted apps
    - Select **Change** if you are updating an existing installation

    **Alternatively, install from the command line:**

    ```powershell
    msiexec.exe /i C:\PATH_TO\NewRelicDotNetAgent_x64.msi /qb NR_LICENSE_KEY=YOUR_LICENSE_KEY INSTALLLEVEL=1
    ```

    Use `INSTALLLEVEL=50` instead of `1` if your application is not hosted in IIS or uses IIS as a reverse proxy.
  </Step>

  <Step>
    ## Configure the agent [#configure]

    Set your app name — this is the only setting you **must** change before going live. Edit `C:\ProgramData\New Relic\.NET Agent\newrelic.config` and set:

    ```xml
    <application>
      <name>Your Application Name</name>
    </application>
    ```

    Your license key was set during installation. For all other configuration options, see [.NET agent configuration](/docs/apm/agents/net-agent/configuration/net-agent-configuration).
  </Step>

  <Step>
    ## Restart IIS [#restart]

    Restart IIS to apply the agent:

    ```powershell
    iisreset
    ```
  </Step>

  <Step>
    ## Verify data is flowing [#verify]

    Send at least two requests to your application, then wait 2–3 minutes and open [one.newrelic.com > APM](https://one.newrelic.com/apm) to look for your app by name.

    <Callout variant="tip">
      App not appearing? See [No data appears (.NET)](/docs/apm/agents/net-agent/troubleshooting/no-data-appears-net).
    </Callout>
  </Step>
</Steps>
