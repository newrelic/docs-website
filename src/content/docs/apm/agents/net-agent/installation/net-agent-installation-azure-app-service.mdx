Install the New Relic .NET agent on Azure App Service using the New Relic Azure Site Extension (recommended) or via NuGet.

## Prerequisites [#prerequisites]

<table>
  <thead>
    <tr>
      <th style={{ width: "200px" }}>Requirement</th>
      <th>Details</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>**New Relic account**</td>
      <td>You need a [New Relic account](https://newrelic.com/signup) and your <InlinePopover type="licenseKey"/>. Have it ready before you begin.</td>
    </tr>
    <tr>
      <td>**Azure App Service**</td>
      <td>A .NET application deployed to Azure App Service.</td>

<Steps>
  <Step>
    ## Install the agent [#install]

    <Tabs>
      <TabsBar>
        <TabsBarItem id="site-extension">Azure Site Extension (recommended)</TabsBarItem>
        <TabsBarItem id="nuget">NuGet</TabsBarItem>
      </TabsBar>
      <TabsPages>
        <TabsPageItem id="site-extension">
          1. Stop your web application before installing.
          2. In the Azure portal, navigate to `https://[yoursitename].scm.azurewebsites.net` and select **Site extensions > Gallery**.
          3. Select the **+** icon next to the New Relic site extension.
          4. Restart your web app after installation completes.

          This installs the latest .NET agent version. The site extension monitors **all** .NET Core applications on the instance. To disable monitoring for a specific app, set `agentEnabled=false` in a `newrelic.config` file in that app's root directory.
        </TabsPageItem>
        <TabsPageItem id="nuget">
          For **NuGet (.NET Framework)**, in the Visual Studio Package Manager console:

          - **64-bit**: `Install-Package NewRelic.Azure.WebSites`
          - **32-bit**: `Install-Package NewRelic.Azure.WebSites.x86`

          Publish your application after installing the package.

          For **NuGet (.NET Core)**, run: `Install-Package NewRelic.Agent`
        </TabsPageItem>
      </TabsPages>
    </Tabs>
  </Step>

  <Step>
    ## Configure the agent [#configure]

    In the Azure portal, go to **App Services > Your App > Configuration > Application settings** and add these key/value pairs:

    | Setting | Value |
    |---|---|
    | `NEW_RELIC_LICENSE_KEY` | Your New Relic license key |
    | `NEW_RELIC_APP_NAME` | The name that will appear in New Relic |

    These app settings override any values in `newrelic.config`. For all other configuration options, see [.NET agent configuration](/docs/apm/agents/net-agent/configuration/net-agent-configuration).
  </Step>

  <Step>
    ## Verify data is flowing [#verify]

    Save your settings and restart the web app. Send at least two requests, then wait 2–3 minutes and open [one.newrelic.com > APM](https://one.newrelic.com/apm) to look for your app by name.

    To verify your environment variables in the Kudu console:
    ```
    https://[yoursitename].scm.azurewebsites.net/Env.cshtml#envVariables
    ```

    <Callout variant="tip">
      App not appearing? See [No data appears (.NET)](/docs/apm/agents/net-agent/troubleshooting/no-data-appears-net) or the [Azure troubleshooting docs](/docs/apm/agents/net-agent/azure-installation/debugging-agent-azure).
    </Callout>
  </Step>
</Steps>
