Install the New Relic .NET agent in a Docker container. The agent must be installed and enabled at runtime inside each container you want to monitor.

<Callout variant="important">
  Windows Nano Server images are not supported.
</Callout>

## Prerequisites [#prerequisites]

<table>
  <thead>
    <tr>
      <th style={{ width: "200px" }}>Requirement</th>
      <th>Details</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>**New Relic account**</td>
      <td>You need a [New Relic account](https://newrelic.com/signup) and your <InlinePopover type="licenseKey"/>. Have it ready before you begin.</td>
    </tr>
    <tr>
      <td>**.NET version**</td>
      <td>See [.NET agent compatibility and requirements](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements) for supported versions.</td>
    </tr>
    <tr>
      <td>**Docker**</td>
      <td>Docker installed with a Linux or Windows base image.</td>
    </tr>
  </tbody>
</table>

<Steps>
  <Step>
    ## Add the agent to your Dockerfile [#install]

    Choose the example that matches your container type:

    <Tabs>
      <TabsBar>
        <TabsBarItem id="linux">Linux container</TabsBarItem>
        <TabsBarItem id="windows-iis">Windows container (.NET Framework / IIS)</TabsBarItem>
        <TabsBarItem id="windows-core">Windows container (.NET Core)</TabsBarItem>
      </TabsBar>
      <TabsPages>
        <TabsPageItem id="linux">
          ```dockerfile
          FROM mcr.microsoft.com/dotnet/aspnet:8.0

          COPY INSERT_NAME_OF_APP_TO_BE_PUBLISHED /app

          RUN apt-get update && apt-get install -y curl ca-certificates gnupg \
          && echo 'deb [signed-by=/etc/apt/keyrings/newrelic-apt.gpg] http://apt.newrelic.com/debian/ newrelic non-free' | tee /etc/apt/sources.list.d/newrelic.list \
          && curl -fsSL https://download.newrelic.com/NEWRELIC_APT_2DAD550E.public | gpg --dearmor > /etc/apt/keyrings/newrelic-apt.gpg \
          && apt-get update \
          && apt-get install -y newrelic-dotnet-agent \
          && rm -rf /var/lib/apt/lists/*

          ENV CORECLR_ENABLE_PROFILING=1 \
          CORECLR_PROFILER={36032161-FFC0-4B61-B559-F6C5D41BAE5A} \
          CORECLR_NEWRELIC_HOME=/usr/local/newrelic-dotnet-agent \
          CORECLR_PROFILER_PATH=/usr/local/newrelic-dotnet-agent/libNewRelicProfiler.so \
          NEW_RELIC_LICENSE_KEY=INSERT_YOUR_LICENSE_KEY \
          NEW_RELIC_APP_NAME=INSERT_YOUR_APP_NAME

          WORKDIR /app
          ENTRYPOINT ["dotnet", "./YOUR_APP_NAME.dll"]
          ```
        </TabsPageItem>
        <TabsPageItem id="windows-iis">
          ```dockerfile
          FROM mcr.microsoft.com/dotnet/framework/aspnet

          COPY YOUR_APP_TO_BE_PUBLISHED /inetpub/wwwroot

          RUN [Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12;\
           Invoke-WebRequest "https://download.newrelic.com/dot_net_agent/latest_release/NewRelicDotNetAgent_x64.msi"\
           -UseBasicParsing -OutFile "NewRelicDotNetAgent_x64.msi"

          RUN Start-Process -Wait -FilePath msiexec -ArgumentList /i, "NewRelicDotNetAgent_x64.msi", /qn,\
           NR_LICENSE_KEY=INSERT_YOUR_LICENSE_KEY

          RUN Remove-Item "NewRelicDotNetAgent_x64.msi"

          ENV NEW_RELIC_APP_NAME=INSERT_YOUR_APP_NAME
          ```
        </TabsPageItem>
        <TabsPageItem id="windows-core">
          ```dockerfile
          FROM mcr.microsoft.com/windows/servercore:ltsc2019

          COPY INSERT_NAME_OF_APP_TO_BE_PUBLISHED /app

          RUN powershell.exe [Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12;\
           Invoke-WebRequest "https://download.newrelic.com/dot_net_agent/latest_release/NewRelicDotNetAgent_x64.msi"\
           -UseBasicParsing -OutFile "NewRelicDotNetAgent_x64.msi"

          RUN powershell.exe Start-Process -Wait -FilePath msiexec -ArgumentList /i, "NewRelicDotNetAgent_x64.msi", /qn,\
           NR_LICENSE_KEY=INSERT_YOUR_LICENSE_KEY

          RUN powershell.exe Remove-Item "NewRelicDotNetAgent_x64.msi"

          ENV CORECLR_ENABLE_PROFILING=1
          ENV NEW_RELIC_APP_NAME=INSERT_YOUR_APP_NAME

          WORKDIR /app
          ENTRYPOINT ["dotnet", ".\\INSERT_YOUR_APP_NAME.dll"]
          ```
        </TabsPageItem>
      </TabsPages>
    </Tabs>
  </Step>

  <Step>
    ## Configure the agent [#configure]

    The Dockerfile examples above set the license key and app name directly via `ENV`. These are the only required settings.

    For all other configuration options, see [.NET agent configuration](/docs/apm/agents/net-agent/configuration/net-agent-configuration).
  </Step>

  <Step>
    ## Verify data is flowing [#verify]

    Build and run your container, then send at least two requests. Wait 2–3 minutes and open [one.newrelic.com > APM](https://one.newrelic.com/apm) to look for your app by name.

    <Callout variant="tip">
      App not appearing? See [No data appears (.NET)](/docs/apm/agents/net-agent/troubleshooting/no-data-appears-net).
    </Callout>
  </Step>
</Steps>
