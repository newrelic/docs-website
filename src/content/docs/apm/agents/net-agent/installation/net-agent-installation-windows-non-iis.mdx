Install the New Relic .NET agent on Windows for self-hosted applications not running in IIS — such as Windows Services, console apps, and WCF services.

## Prerequisites [#prerequisites]

  <thead>
    <tr>
      <th style={{ width: "200px" }}>Requirement</th>
      <th>Details</th>
    </tr>
  </thead>

      <td>You need a [New Relic account](https://newrelic.com/signup) and your <InlinePopover type="licenseKey"/>. Have it ready before you begin.</td>

<Steps>
  <Step>
    ## Download the installer [#download]

    Download the MSI installer that matches your system architecture:
    - [64-bit](https://download.newrelic.com/dot_net_agent/latest_release/NewRelicDotNetAgent_x64.msi)
    - [32-bit](https://download.newrelic.com/dot_net_agent/latest_release/NewRelicDotNetAgent_x86.msi)
  </Step>

  <Step>
    ## Install the agent [#install]

    Run the MSI installer with **Instrument all .NET Framework Applications** selected (required for non-IIS apps), or use the command line with `INSTALLLEVEL=50`:

    ```powershell
    msiexec.exe /i C:\PATH_TO\NewRelicDotNetAgent_x64.msi /qb NR_LICENSE_KEY=YOUR_LICENSE_KEY INSTALLLEVEL=50
    ```

    `INSTALLLEVEL=50` enables the `InstrumentAllNETFramework` option, which sets the global environment variables needed for non-IIS .NET Framework apps. For .NET Core apps, set the [required environment variables](/docs/apm/agents/net-agent/configuration/net-agent-configuration/#net-core-env-variables) manually for each process you want to instrument.

    <Callout variant="caution">
      Do not set profiler environment variables globally on a system with many .NET processes — this will instrument all of them. Set them only for the specific process you want to monitor.
    </Callout>
  </Step>

  <Step>
    ## Configure the agent [#configure]

    Set your app name — this is the only setting you **must** change. Edit `C:\ProgramData\New Relic\.NET Agent\newrelic.config` and set:

    ```xml
    <application>
      <name>Your Application Name</name>
    </application>
    ```

    Your license key was set during installation. For all other configuration options, see [.NET agent configuration](/docs/apm/agents/net-agent/configuration/net-agent-configuration).
  </Step>

  <Step>
    ## Restart your application [#restart]

    Restart the application process for the agent to take effect.
  </Step>

  <Step>
    ## Verify data is flowing [#verify]

    Send at least two requests to your application, then wait 2–3 minutes and open [one.newrelic.com > APM](https://one.newrelic.com/apm) to look for your app by name.

    <Callout variant="tip">
      App not appearing? See [No data appears (.NET)](/docs/apm/agents/net-agent/troubleshooting/no-data-appears-net).
    </Callout>
  </Step>
</Steps>
