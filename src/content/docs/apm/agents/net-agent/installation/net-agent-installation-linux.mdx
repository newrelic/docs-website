Install the New Relic .NET agent on Linux for .NET Core and .NET 5+ applications.

## Prerequisites [#prerequisites]

<table>
  <thead>
    <tr>
      <th style={{ width: "200px" }}>Requirement</th>
      <th>Details</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>**New Relic account**</td>
      <td>You need a [New Relic account](https://newrelic.com/signup) and your <InlinePopover type="licenseKey"/>. Have it ready before you begin.</td>
    </tr>
    <tr>
      <td>**.NET version**</td>
      <td>.NET Core or .NET 5+. See [.NET agent compatibility and requirements](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements) for supported versions. .NET Framework is not supported on Linux.</td>
    </tr>
    <tr>
      <td>**Operating system**</td>
      <td>A supported Linux distribution. See [.NET agent compatibility and requirements](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements) for details. ARM64 is not supported via RPM packages — use the tarball method instead.</td>
    </tr>
    <tr>
      <td>**Permissions**</td>
      <td>`sudo` or root access required.</td>
    </tr>
  </tbody>
</table>

<Steps>
  <Step>
    ## Install the agent [#install]

    Choose the method that matches your package manager:

    <Tabs>
      <TabsBar>
        <TabsBarItem id="apt">APT (Debian/Ubuntu)</TabsBarItem>
        <TabsBarItem id="yum">YUM (RHEL/CentOS/Amazon Linux)</TabsBarItem>
        <TabsBarItem id="rpm">RPM</TabsBarItem>
        <TabsBarItem id="tarball">Tarball</TabsBarItem>
      </TabsBar>
      <TabsPages>
        <TabsPageItem id="apt">
          1. Configure the New Relic APT repository:

             ```bash
             echo 'deb [signed-by=/etc/apt/keyrings/newrelic-apt.gpg] https://apt.newrelic.com/debian/ newrelic non-free' | sudo tee /etc/apt/sources.list.d/newrelic.list
             ```

          2. Enable New Relic's GPG key:

             ```bash
             curl -fsSL https://download.newrelic.com/NEWRELIC_APT_2DAD550E.public | gpg --dearmor | sudo tee /etc/apt/keyrings/newrelic-apt.gpg >/dev/null
             ```

          3. Update the local package list and install:

             ```bash
             sudo apt-get update
             sudo apt-get install newrelic-dotnet-agent
             ```
        </TabsPageItem>
        <TabsPageItem id="yum">
          1. Configure the New Relic YUM repository:

             ```bash
             sudo curl -o /etc/yum.repos.d/newrelic-dotnet-agent.repo https://download.newrelic.com/dot_net_agent/yum/newrelic-dotnet-agent.repo
             ```

          2. Install the agent:

             ```bash
             sudo yum install newrelic-dotnet-agent -y
             ```
        </TabsPageItem>
        <TabsPageItem id="rpm">
          1. Go to [download.newrelic.com/dot_net_agent/latest_release](https://download.newrelic.com/dot_net_agent/latest_release/) and copy the URL for the latest `.rpm` package matching your architecture.

          2. Download and install, replacing `https://INSERT_LINK_TO_PACKAGE` and `VERSION`:

             ```bash
             wget -L https://INSERT_LINK_TO_PACKAGE
             sudo rpm -i newrelic-dotnet-agent_VERSION.x86_64.rpm
             ```
        </TabsPageItem>
        <TabsPageItem id="tarball">
          1. Go to [download.newrelic.com/dot_net_agent/latest_release](https://download.newrelic.com/dot_net_agent/latest_release) and copy the URL for the latest `newrelic-dotnet-agent-VERSION.tar.gz` matching your architecture.

          2. Download and extract, replacing `https://INSERT_LINK_TO_PACKAGE`:

             ```bash
             wget -L https://INSERT_LINK_TO_PACKAGE
             tar xzf newrelic*.tar.gz
             ```

          3. Move the `newrelic-dotnet-agent` directory to `/usr/local` or your preferred install location.

          4. Verify `CORECLR_NEWRELIC_HOME` points to the `newrelic-dotnet-agent` directory and the directory is readable by monitored .NET processes.
        </TabsPageItem>
      </TabsPages>
    </Tabs>
  </Step>

  <Step>
    ## Configure the agent [#configure]

    Set the required environment variables for each process you want to instrument. Replace `PATH_TO_AGENT_DIRECTORY` with the actual path to the agent (typically `/usr/local/newrelic-dotnet-agent` for APT/YUM installs):

    ```ini
    CORECLR_ENABLE_PROFILING=1
    CORECLR_PROFILER={36032161-FFC0-4B61-B559-F6C5D41BAE5A}
    CORECLR_NEWRELIC_HOME=PATH_TO_AGENT_DIRECTORY
    CORECLR_PROFILER_PATH=PATH_TO_AGENT_DIRECTORY/libNewRelicProfiler.so
    NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY
    NEW_RELIC_APP_NAME=Your Application Name
    ```

    <Callout variant="caution">
      Set these environment variables only for the processes you want to instrument. Setting them globally will instrument all .NET processes on the system.
    </Callout>

    For all other configuration options, see [.NET agent configuration](/docs/apm/agents/net-agent/configuration/net-agent-configuration).
  </Step>

  <Step>
    ## Restart your application [#restart]

    Restart the application process with the environment variables set.
  </Step>

  <Step>
    ## Verify data is flowing [#verify]

    Send at least two requests to your application, then wait 2–3 minutes and open [one.newrelic.com > APM](https://one.newrelic.com/apm) to look for your app by name.

    <Callout variant="tip">
      App not appearing? See [No data appears (.NET)](/docs/apm/agents/net-agent/troubleshooting/no-data-appears-net).
    </Callout>
  </Step>
</Steps>
