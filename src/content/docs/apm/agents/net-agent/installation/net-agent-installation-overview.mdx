Install the New Relic .NET agent to start monitoring your .NET application. Choose the method that matches your environment from the left navigation.

You need a [New Relic account](https://newrelic.com/signup) and your <InlinePopover type="licenseKey"/> to complete installation. See [.NET agent compatibility and requirements](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements) before you begin.

| Method | Use when |
|---|---|
| [Windows (IIS)](/docs/apm/agents/net-agent/installation/net-agent-installation-windows-iis) | .NET Framework or .NET Core apps hosted in IIS |
| [Windows (non-IIS)](/docs/apm/agents/net-agent/installation/net-agent-installation-windows-non-iis) | Windows Services, console apps, WCF services, and other self-hosted Windows apps |
| [Linux](/docs/apm/agents/net-agent/installation/net-agent-installation-linux) | .NET Core and .NET 5+ apps on Linux (apt, yum, rpm, or tarball) |
| [Docker](/docs/apm/agents/net-agent/installation/net-agent-installation-docker) | Containerized .NET apps on Linux or Windows base images |
| [Azure App Service](/docs/apm/agents/net-agent/installation/net-agent-installation-azure-app-service) | Apps deployed to Azure App Service (site extension or NuGet) |
| [Manual ZIP (advanced)](/docs/apm/agents/net-agent/other-installation/net-agent-install-resources) | Manual install when the guided installer is not available |
