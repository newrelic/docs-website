Code-level metrics are span attributes that the .NET agent attaches to your application's spans, pinpointing the exact function and class responsible for a given span. This allows you to be more proactive about addressing performance issues as you review your code. You can view these attributes on individual spans in [distributed tracing](/docs/distributed-tracing/ui-data/understand-use-distributed-tracing-data/), or query them directly with [NRQL](/docs/nrql/get-started/introduction-nrql-new-relics-query-language/).

<Callout variant="important">
  With the release of .NET agent version 10.2.0, code-level metrics enabled by default.

  Code-level metrics are available in [.NET agent version 9.9.0 and higher](/docs/release-notes/agent-release-notes/net-release-notes) and are disabled by default. To change this configuration, check out our [documentation](/docs/apm/agents/net-agent/configuration/net-agent-configuration#code_level_metrics).
</Callout>

## Agent attributes [#attributes]

The .NET agent reports and attaches the following attributes to spans produced by your application.

<Callout variant="important">
  In some cases, the agent will directly wrap base framework code (data stores, external calls, etc.) that is invoked within your application, and these attributes won't be attached.
