Install the New Relic Ruby agent to start monitoring your Ruby application. Choose the method that matches your environment from the left navigation.

You need a [New Relic account](https://newrelic.com/signup) and your <InlinePopover type="licenseKey"/> to complete installation. See [Ruby agent requirements and supported frameworks](/docs/apm/agents/ruby-agent/getting-started/ruby-agent-requirements-supported-frameworks) before you begin.

| Method | Use when |
|---|---|
| [Standard (Bundler/Gemfile)](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent) | Most Ruby apps — Rails, Sinatra, Roda, Rack, and other UNIX-based environments |
| [Rails plugin](/docs/apm/agents/ruby-agent/installation/ruby-agent-installation-rails-plugin) | Rails 2+ apps using the legacy plugin install method |
| [Docker](/docs/apm/agents/ruby-agent/installation/ruby-agent-installation-docker) | Containerized Ruby applications |
| [Heroku](/docs/apm/agents/ruby-agent/installation/ruby-agent-heroku) | Apps deployed on Heroku using the New Relic add-on |
| [Google App Engine](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent-gae-flexible-environment) | Apps running in the GAE flexible environment |
