This method is for installing the Ruby agent as a Rails plugin for **Rails 2 or higher**.

<Callout variant="important">
  For most use cases, [install the Ruby agent as a gem](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent) instead. The gem method provides better control over versions and dependencies.
</Callout>

## Prerequisites [#prerequisites]

  <thead>
    <tr>

<Steps>
  <Step>
    ## Install the Rails plugin [#install]

    Install the plugin from GitHub into your application's `vendor/plugins` directory:

    ```sh
    script/plugin install git://github.com/newrelic/newrelic-ruby-agent.git
    mv vendor/plugins/rpm vendor/plugins/newrelic-ruby-agent
    ```

    If you cannot install directly from the git URL, clone the repository into the `vendor/plugins` directory manually.
  </Step>

  <Step>
    ## Configure the agent [#configure]

    Copy the `newrelic.yml` file from the plugin directory into your application's `config` subdirectory:

    ```sh
    cp vendor/plugins/newrelic-ruby-agent/newrelic.yml config/newrelic.yml
    ```

    Edit `config/newrelic.yml` and set the two required values:

    1. Set `license_key` to your <InlinePopover type="licenseKey"/>.
    2. Set `app_name` to a meaningful name for your application.

    For all other configuration options, see [Ruby agent configuration](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration).
  </Step>

  <Step>
    ## Verify data is flowing [#verify]

    Restart your web server, then send at least two requests to your application. Wait 2–3 minutes and open [one.newrelic.com > APM](https://one.newrelic.com/apm) to look for your app by name.

    <Callout variant="tip">
      App not appearing? See [No data appears (Ruby)](/docs/apm/agents/ruby-agent/troubleshooting/no-data-appears-ruby).
    </Callout>
  </Step>
</Steps>
