The `go-easy-instrumentation` tool analyzes your Go source code and generates a `.diff` file with suggested changes to instrument your application with the New Relic Go agent. You review and apply the suggestions — the tool never modifies your code directly.

## What the tool instruments [#coverage]

The tool can suggest instrumentation for:

- Errors in functions wrapped or traced by a transaction
- Locally defined functions invoked in `main()`, traced with a transaction
- Async functions and function literals, traced with an async segment
- Middleware for supported libraries
- Distributed tracing injection into external traffic

**Supported libraries:** standard library, `net/http`, Gin, gRPC, gochi, MySQL, slog

<Steps>
  <Step>
    ## Install the tool [#install]

    Make sure your `GOPATH/bin` is on your `PATH`, then install:

    ```sh
    go install github.com/newrelic/go-easy-instrumentation@latest
    ```

    <CollapserGroup>
      <Collapser id="gopath-mac-linux" title="Add GOPATH/bin to PATH (Mac or Linux)">
        ```sh
        export PATH=$PATH:$(go env GOPATH)/bin
        ```
      </Collapser>
      <Collapser id="gopath-windows" title="Add GOPATH/bin to PATH (Windows)">
        ```sh
        go env -w GOPATH=c:\go-work
        ```
      </Collapser>
    </CollapserGroup>
  </Step>

  <Step>
    ## Generate instrumentation suggestions [#generate]

    Verify your application is on a clean Git branch (no unstaged changes), then run:

    ```sh
    go-easy-instrumentation instrument ../my-application/
    ```

    This creates `new-relic-instrumentation.diff` in your working directory. Open the file and review the suggested changes carefully.

    <Callout variant="tip">
      The tool may invoke `go get` or other Go toolchain commands, which can modify your `go.mod` file. It does not modify your source code directly.
    </Callout>
  </Step>

  <Step>
    ## Apply the suggestions [#apply]

    After reviewing the diff:

    ```sh
    mv new-relic-instrumentation.diff ../my-application/
    cd ../my-application
    git apply new-relic-instrumentation.diff
    ```

    The applied code includes `newrelic.NewApplication()` calls with `newrelic.ConfigAppName()` and `newrelic.ConfigLicense()`. Update these with your app name and license key:

    ```go
    app, err := newrelic.NewApplication(
        newrelic.ConfigAppName("Your Application Name"),
        newrelic.ConfigLicense(os.Getenv("NEW_RELIC_LICENSE_KEY")),
    )
    ```

    Set `NEW_RELIC_LICENSE_KEY` as an environment variable — do not hardcode your license key in source code.

    To revert: `git stash` or reset to the previous commit.
  </Step>

  <Step>
    ## Verify data is flowing [#verify]

    Run your application and send at least two requests, then wait 2–3 minutes and open [one.newrelic.com > APM](https://one.newrelic.com/apm) to look for your app by name.

    <Callout variant="tip">
      App not appearing? See [No data appears (Go)](/docs/apm/agents/go-agent/troubleshooting/no-data-appears-go).
    </Callout>
  </Step>
</Steps>
