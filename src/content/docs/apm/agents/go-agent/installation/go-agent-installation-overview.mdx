Install the New Relic Go agent to start monitoring your Go application. Choose the method that matches your environment from the left navigation.

You need a [New Relic account](https://newrelic.com/signup) and your <InlinePopover type="licenseKey"/> to complete installation. See [Go agent compatibility and requirements](/docs/apm/agents/go-agent/get-started/go-agent-compatibility-requirements) before you begin.

<Callout variant="important">
  The Go agent requires manual instrumentation — unlike some agents, it does not auto-instrument your code. You need to add the agent to your application and wrap the transactions you want to monitor. Use the automated tool below to generate instrumentation suggestions if you prefer a guided approach.
</Callout>

| Method | Use when |
|---|---|
| [Manual instrumentation](/docs/apm/agents/go-agent/installation/install-new-relic-go) | Standard install for any Go application — add `go get`, initialize the agent, and wrap handlers |
| [Automated instrumentation](/docs/apm/agents/go-agent/installation/install-automation-new-relic-go) | Use the `go-easy-instrumentation` tool to generate instrumentation suggestions as a `.diff` file |
| [Google App Engine](/docs/apm/agents/go-agent/installation/install-go-agent-gae-flexible-environment) | Apps running in the GAE flexible environment using a custom Docker runtime |
