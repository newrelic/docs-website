The Go agent can run in a [Google App Engine (GAE) flexible environment](https://cloud.google.com/appengine/docs/flexible/go/) using a custom Docker runtime.

<Callout variant="important">
  The Go agent is not compatible with the GAE standard environment or Google App Engine's ["native mode"](https://cloud.google.com/appengine/docs/flexible/go/). Use the custom runtime method described here.
</Callout>

<Steps>
  <Step>
    ## Install the Go agent and configure your app [#install]

    Add the New Relic Go agent to your project:

    ```sh
    go get github.com/newrelic/go-agent/v3/newrelic
    ```

    Configure your `app.yaml` for a custom runtime:

    ```yaml
    runtime: custom
    env: flex
    ```

    Configure your `Dockerfile`. The following example uses Go 1.8:

    ```dockerfile
    FROM golang:1.8-onbuild
    CMD go run main.go
    ```

    Build your Docker image:

    ```bash
    docker build --rm -t YOUR_IMAGE_NAME .
    ```
  </Step>

  <Step>
    ## Configure the agent [#configure]

    In your Go application, initialize the agent with your app name and license key:

    ```go
    app, err := newrelic.NewApplication(
        newrelic.ConfigAppName("Your Application Name"),
        newrelic.ConfigLicense(os.Getenv("NEW_RELIC_LICENSE_KEY")),
    )
    ```

    Pass `NEW_RELIC_LICENSE_KEY` as an environment variable — do not hardcode it. For all other configuration options, see [Go agent configuration](/docs/apm/agents/go-agent/configuration/go-agent-configuration).

    <Callout variant="tip">
      To disable GAE health checks (recommended), add to your `app.yaml`:

      ```yaml
      health_check:
        enable_health_check: False
      ```

      Google App Engine sends frequent health check requests to `/_ah/health`. Without disabling them, your app may need to handle a large number of requests, which can affect how data appears in APM.
    </Callout>
  </Step>

  <Step>
    ## Deploy to GAE [#deploy]

    Deploy your Docker image to the initialized GAE flexible environment:

    ```bash
    gcloud --project YOUR_PROJECT_NAME app deploy
    ```

    Wait until the deployment completes.
  </Step>

  <Step>
    ## Verify data is flowing [#verify]

    Send at least two requests to your application, then wait 2–3 minutes and open [one.newrelic.com > APM](https://one.newrelic.com/apm) to look for your app by name.

    <Callout variant="tip">
      App not appearing? To redirect Go agent logs to Stackdriver, set `log_file_name: STDOUT` in your `newrelic.yml`. To connect to a GAE instance and debug, see [GAE's documentation for debugging an instance](https://cloud.google.com/appengine/docs/flexible/go/debugging-an-instance).
    </Callout>
  </Step>
</Steps>
