The Go agent requires manual instrumentation — unlike some agents, it does not auto-instrument your code. You need to add the agent to your application and wrap the transactions you want to monitor.

## Prerequisites [#prerequisites]

Check these requirements before you start.

<Steps>
  <Step>
    ## Install the agent [#install]

    Add the New Relic Go agent to your project:

    ```bash
    go get github.com/newrelic/go-agent/v3/newrelic
    ```

    Then add the import to your application:

    ```go
    import "github.com/newrelic/go-agent/v3/newrelic"
    ```
  </Step>

  <Step>
    ## Initialize the agent [#configure]

    Add the agent to your `main` function. The only required settings are your app name and license key.

    ```go
    app, err := newrelic.NewApplication(
        newrelic.ConfigAppName("My Go Application"),
        newrelic.ConfigLicense(os.Getenv("NEW_RELIC_LICENSE_KEY")),
    )
    if err != nil {
        log.Fatal(err)
    }
    ```

    <Callout variant="important">
      Use an environment variable for your license key — do not hardcode it in your source code.
    </Callout>

    For HTTP applications, wrap your handlers so the agent can monitor web transactions:

    ```go
    http.HandleFunc(newrelic.WrapHandleFunc(app, "/", myHandler))
    ```

    For non-HTTP applications (background jobs, CLI tools), see [Instrument Go transactions](/docs/apm/agents/go-agent/instrumentation/instrument-go-transactions).
  </Step>

  <Step>
    ## Verify data is flowing [#verify]

    1. Set your license key environment variable and run your application:

       ```bash
       export NEW_RELIC_LICENSE_KEY="your-license-key-here"
       go run .
       ```

    2. Send at least a few requests to your application.

    3. Wait 2–3 minutes, then open [one.newrelic.com > APM](https://one.newrelic.com/apm) and look for your app by name.

    <Callout variant="tip">
      App not appearing? Check your application logs for New Relic connection messages, or see [No data appears (Go)](/docs/apm/agents/go-agent/troubleshooting/no-data-appears-go).
    </Callout>
  </Step>
</Steps>
