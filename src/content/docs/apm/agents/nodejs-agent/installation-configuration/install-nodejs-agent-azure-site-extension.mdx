Install the New Relic Node.js agent on Azure App Service for Windows using the New Relic Azure Site Extension.

<Callout variant="important">
  This method is for **Windows-based** Azure App Service apps deployed as code only. For Linux containers on Azure, use the standard [npm install method](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent) and pass `NEW_RELIC_LICENSE_KEY` as an app setting.

  For applications running on Windows 32, full Code Level Metrics support (file path, line, column) is not available — profiling falls back to function name only.
</Callout>

<Steps>
  <Step>
    ## Install the site extension [#install]

    1. From the Azure Home page, click **App Services** and select your target application.
    2. In the left menu under **Development Tools**, select **Extensions**.
    3. Click **+ Add** at the top of the page, then select **New Relic Node Agent** from the dropdown.
    4. Accept the legal terms and click **OK**.

    Once installed, the extension creates:
    - Agent files and dependencies at `C:\home\site\wwwroot\node_modules`
    - An XDT transform (`applicationHost.xdt`) that automatically injects `NODE_OPTIONS=-r newrelic` on application startup
  </Step>

  <Step>
    ## Configure the agent [#configure]

    In your application's left menu, go to **Settings > Environment variables** and add:

    | Setting | Value |
    |---|---|
    | `NEW_RELIC_LICENSE_KEY` | Your New Relic license key |
    | `NEW_RELIC_APP_NAME` | The name that will appear in New Relic |

    The extension automatically sets `NODE_OPTIONS` to `-r newrelic`. Any previously defined `NODE_OPTIONS` will be reset. For all other configuration options, see [Node.js agent configuration](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration).
  </Step>

  <Step>
    ## Verify data is flowing [#verify]

    Start your application and send at least two requests. Wait 2–3 minutes and open [one.newrelic.com > APM](https://one.newrelic.com/apm) to look for your app by name.

    If the extension fails to install, check the log at:
    ```
    C:\home\SiteExtensions\NewRelic.Azure.Websites.Extension.NodeAgent\install.log
    ```

    If the agent is installed but data doesn't appear, check:
    ```
    C:\home\site\wwwroot\newrelic_agent.log
    ```

    <Callout variant="tip">
      App not appearing? See [Troubleshooting your Node.js installation](/docs/apm/agents/nodejs-agent/troubleshooting/troubleshooting-your-nodejs-installation).
    </Callout>
  </Step>
</Steps>
