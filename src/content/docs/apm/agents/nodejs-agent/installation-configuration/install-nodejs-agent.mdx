The Node.js agent is publicly available on the [npm repository](https://npmjs.org/package/newrelic) and on [GitHub](https://github.com/newrelic/node-newrelic).

<Callout variant="tip">
  Using Docker? See [Install the Node.js agent in Docker](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent-docker).
</Callout>

## Prerequisites [#prerequisites]

Check these requirements before you start.

  <thead>
    <tr>
      <th style={{ width: "200px" }}>Requirement</th>
      <th>Details</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>**New Relic account**</td>
      <td>You need a [New Relic account](https://newrelic.com/signup) and your <InlinePopover type="licenseKey"/>. Have it ready before you begin.</td>
    </tr>

<Steps>
  <Step>
    ## Install the agent [#install]

    Install the agent package in your application directory:

    ```bash
    npm install newrelic
    ```

    <Callout variant="important">
      If you use Next.js, refer to the [Next.js hybrid agent instrumentation guide](/docs/apm/agents/nodejs-agent/extend-your-instrumentation/nextjs-instrumentation/).
    </Callout>

    Then copy the default configuration file from the package into the root of your application:

    ```bash
    cp node_modules/newrelic/newrelic.js .
    ```
  </Step>

  <Step>
    ## Configure the agent [#configure]

    Open `newrelic.js` in the root of your application. The only two settings you **must** change before going live:

    1. Set `license_key` to your <InlinePopover type="licenseKey"/>.
    2. Set `app_name` to a meaningful name for your application.

    ```js
    exports.config = {
      app_name: ['Your Application Name'],
      license_key: 'YOUR_LICENSE_KEY',
      // ...
    }
    ```

    You can also set these via environment variables instead of editing the file:

    ```bash
    NEW_RELIC_APP_NAME="Your Application Name"
    NEW_RELIC_LICENSE_KEY="YOUR_LICENSE_KEY"
    ```
  </Step>

  <Step>
    ## Start the agent [#start]

    Load the agent before any other `require` statements by adding `-r newrelic` to your startup command:

    ```bash
    node -r newrelic ./your-app.js
    ```

    If your application uses ESM, add the `--import newrelic/esm-loader.mjs` option:

    ```bash
    node --import newrelic/esm-loader.mjs -r newrelic ./your-app.js
    ```

    For a Next.js app, load our agent via `NODE_OPTIONS='-r newrelic' next start`.

    If you're using Nest.js and the `nest start` command to start the application, modify its startup binary to load the New Relic agent: `nest start --exec 'node -r newrelic'`. [Here is an example Nest.js application](https://github.com/newrelic/newrelic-node-examples/tree/main/nestjs).

  </Step>

  <Step>
    ## Verify data is flowing [#verify]

    If your agent version is 14.9.0 or above, you can run this command to validate your configuration:

    ```bash
    npx newrelic validate-config --config-file ./newrelic.js
    ```

    1. Send at least two requests to your application.

    2. Wait 2–3 minutes, then open [one.newrelic.com > APM](https://one.newrelic.com/apm) and look for your app by name.

    <Callout variant="tip">
      App not appearing? See [Troubleshooting your Node.js installation](/docs/apm/agents/nodejs-agent/troubleshooting/troubleshooting-your-nodejs-installation).
    </Callout>
  </Step>
</Steps>
