Install the New Relic Node.js agent in a Docker container by adding it to your `package.json` and loading it at startup.

## Prerequisites [#prerequisites]

<table>
  <thead>
    <tr>
      <th style={{ width: "200px" }}>Requirement</th>
      <th>Details</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>**New Relic account**</td>
      <td>You need a [New Relic account](https://newrelic.com/signup) and your <InlinePopover type="licenseKey"/>.</td>
    </tr>
    <tr>
      <td>**Node.js version**</td>

<Callout variant="caution">
  Do not include your license key in your Dockerfile or Docker image. Pass it as an environment variable at runtime instead.
</Callout>

<Steps>
  <Step>
    ## Add the agent to your application [#install]

    Add `newrelic` to your `package.json`:

    ```json
    "newrelic": "latest"
    ```

    Then update your Dockerfile or startup command to load the agent with the `-r` flag. Update whichever form your container uses:

    | Before | After |
    |---|---|
    | `node YOUR_PROGRAM.js` | `node -r newrelic YOUR_PROGRAM.js` |
    | `ENTRYPOINT ['node', 'YOUR_PROGRAM.js']` | `ENTRYPOINT ['node', '-r', 'newrelic', 'YOUR_PROGRAM.js']` |
    | `CMD ['node', 'YOUR_PROGRAM.js']` | `CMD ['node', '-r', 'newrelic', 'YOUR_PROGRAM.js']` |

    Alternatively, modify an npm start script:

    ```bash
    npm pkg set scripts.start="node -r newrelic your-program.js"
    ```

    <Callout variant="important">
      If you cannot use the `-r` flag, add `require('newrelic')` as the **first line** of your app's main module. Do not use this approach with Babel or other transpilers — it will cause instrumentation issues.
    </Callout>
  </Step>

  <Step>
    ## Configure the agent [#configure]

    Pass your app name and license key as environment variables when running the container. These are the only required settings:

    ```bash
    docker run -e NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
               -e NEW_RELIC_APP_NAME="Your Application Name" \
               YOUR_IMAGE_NAME:latest
    ```

    You can also set configuration via `ENV` directives in your Dockerfile:

    ```dockerfile
    ENV NEW_RELIC_APP_NAME="Your Application Name"
    ```

    For all other configuration options, see [Node.js agent configuration](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration).
  </Step>

  <Step>
    ## Verify data is flowing [#verify]

    Build and run your container, then send at least two requests to your application. Wait 2–3 minutes and open [one.newrelic.com > APM](https://one.newrelic.com/apm) to look for your app by name.

    <Callout variant="tip">
      App not appearing? See [Troubleshooting your Node.js installation](/docs/apm/agents/nodejs-agent/troubleshooting/troubleshooting-your-nodejs-installation).
    </Callout>
  </Step>
</Steps>
