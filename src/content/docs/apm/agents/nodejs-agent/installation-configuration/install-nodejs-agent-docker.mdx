You can use our Node.js agent to instrument Node.js applications deployed in Docker containers. This document explains how to build, configure, and deploy your Dockerized Node.js application that you've instrumented with New Relic.

If you need general help with the Node.js agent installation, see our [main installation instructions](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent).

## Instrument your container [#instrument]

<Callout variant="caution">
Don't include your license key in your Dockerfile or Docker image. For more information, see [our documentation on license key security](/docs/accounts/install-new-relic/account-setup/license-key#license-key-security).
</Callout>

By making a few configuration changes and adding New Relic environment variables to your existing Dockerfile, you can instrument your Dockerized app with our Node.js agent.

1. Add `newrelic` to your `package.json`:

    ```json
    npm install newrelic --save
    ```

1. Inject the agent in your `node` start command to instrument your application.

<CollapserGroup>
  <Collapser
    id="docker-cjs"
    title="App using CommonJS"
  >
  Depending on how you run your Node.js application, the method for injecting the agent may vary.

  * `ENTRYPOINT`

    ```bash
    ENTRYPOINT ["node", "-r", "newrelic", "YOUR_PROGRAM.js"]
    ```

  * `CMD`

    ```bash
    CMD ["node", "-r", "newrelic", "YOUR_PROGRAM.js"]
    ```

  * npm script such as `npm start`

    ```bash
    npm pkg set scripts.start="node -r newrelic your-program.js"
    ```
  </Collapser>
  <Collapser
    id="docker-esm"
    title="App using ESM"
  >
  Depending on how you run your Node.js application, the method for injecting the agent may vary.

  * `ENTRYPOINT`

    ```bash
    ENTRYPOINT ["node", "--import", "newrelic/esm-loader.mjs", "-r", "newrelic", "YOUR_PROGRAM.js"]
    ```

  * `CMD`

    ```bash
    CMD ["node", "--import", "newrelic/esm-loader.mjs", "-r", "newrelic", "YOUR_PROGRAM.js"]
    ```

  * npm script such as `npm start`

    ```bash
    npm pkg set scripts.start="node --import newrelic/esm-loader.mjs -r newrelic your-program.js"
    ```
  </Collapser>
</CollapserGroup>

3. Build your Docker image the way you normally do.
4. To run your Docker app with the agent enabled, add your <InlinePopover type="licenseKey"/> and [app name](/docs/agents/manage-apm-agents/app-naming/name-your-application) to your `docker run` command as environment variables:

    ```bash
    docker run -e NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
            -e NEW_RELIC_APP_NAME="YOUR_APP_NAME" \
            YOUR_IMAGE_NAME:latest
    ```
