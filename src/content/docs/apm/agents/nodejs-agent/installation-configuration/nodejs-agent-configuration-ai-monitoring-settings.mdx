This page covers the Node.js agent settings for AI monitoring, including LLM telemetry, streaming, and content recording.

<Callout variant="tip">
  Back to the full settings index: [Node.js agent configuration](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration)
</Callout>

## AI monitoring [#ai-monitoring]

LLM instrumentation is enabled by default. The agent sends `Llm*` custom events, spans, and metrics without message content.

To opt out, set any of the following to `false`:

* `ai_monitoring.basic_telemetry.enabled` in `newrelic.js`
* `NEW_RELIC_AI_MONITORING_BASIC_TELEMETRY_ENABLED` environment variable
* `ai_monitoring.enabled` in `newrelic.js` (deprecated, but still works)
* `NEW_RELIC_AI_MONITORING_ENABLED` environment variable (deprecated, but still works)

<Callout variant="important">
  You must enable [distributed tracing](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration/#dt-main) to capture AI data. It's turned on by default in Node.js agents 8.3.0 and higher. If you've enabled high security mode, AI monitoring will not work.
</Callout>

<Callout variant="important">
  When enabled, AI Monitoring will record a streaming copy of inputs and outputs sent to and from the models you choose to monitor, including any personal information contained therein. When using AI Monitoring, you are responsible for obtaining consent from your model users that their interactions may be recorded by a third party (New Relic) for the purpose of providing the AI Monitoring feature.
</Callout>
