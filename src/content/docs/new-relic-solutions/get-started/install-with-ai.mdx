You can ask an AI coding agent, such as Claude Code, Cursor, GitHub Copilot, or Codex, to add New Relic to your project. The agent reads our install docs, determines which New Relic agent your project needs, and makes the changes for you.

## Before you begin [#before-you-begin]

* **New Relic account** — If you don't have one, [sign up for a New Relic account](https://newrelic.com/signup).
* **License key** — You'll need your <InlinePopover type="licenseKey"/>. To find it, see [License keys](/docs/apis/intro-apis/new-relic-api-keys#license-key).

<Callout variant="important">
  Keep your license key out of the agent's context. Don't paste it into the chat. Set it yourself as the `NEW_RELIC_LICENSE_KEY` environment variable where your app runs.
</Callout>

## Copy this prompt [#prompt]

Open your AI coding agent in your project's folder and paste this prompt:

<Callout variant="tip">
  Follow the instructions at https://docs.newrelic.com/docs/new-relic-solutions/get-started/install-with-ai.md to add New Relic to this project.
</Callout>

After the agent runs, check what files it changed and verify that data is reaching New Relic.

## Instructions for AI agents [#agent-instructions]

If you're an AI agent installing New Relic, follow these steps:

1. **Find the stack:** Look at the project's files, such as `package.json`, `pom.xml`, `build.gradle`, `requirements.txt`, `pyproject.toml`, `go.mod`, `*.csproj`, `composer.json`, `Gemfile`, `Dockerfile`, Kubernetes manifests, or Helm charts. If the stack is unclear, ask the user what to monitor.
2. **Pick the install guide:** Choose the matching guide from the [install guides](#install-guides) below. For a URL under `/docs/`, add `.md` to the end to get a markdown version.
3. **Keep the license key out of your context:** The key is a secret. You never need its value.
   * Don't ask the user for the key. If they paste it into the chat, tell them to revoke it and create a new one.
   * Refer to the key only by the name `NEW_RELIC_LICENSE_KEY`. Where a guide puts the key in a config file, read it from that environment variable instead.
   * Don't run commands or read files that would show the key, such as `env`, `printenv`, `echo $NEW_RELIC_LICENSE_KEY`, `.env` files, or secret stores.
   * Run `test -n "$NEW_RELIC_LICENSE_KEY" && echo set || echo missing` to check that the key is set without exposing it.
4. **Follow the guide:**
   * Ask the user for an app name, or suggest one based on the project name.
   * If the user's account is in the EU or JP [data center region](/docs/accounts/accounts-billing/account-setup/choose-your-data-center), use the endpoints the guide gives for that region.
5. **Verify:** Ask the user to set `NEW_RELIC_LICENSE_KEY` and restart the app, then follow [Verify the install](#verify). If no data appears, see the troubleshooting page listed for that technology.
6. **Summarize:** Tell the user which files you changed and where to find their app in New Relic: <DNT>**APM & Services**</DNT> for apps, <DNT>**Browser**</DNT> or <DNT>**Mobile**</DNT> for frontends, and <DNT>**Infrastructure**</DNT> for hosts.

## Verify the install [#verify]

Check in two stages: first that the agent is running, then that its data has reached New Relic.

### Check data reached New Relic [#check-data]

Run the query for the technology you installed, replacing each placeholder with the value you configured. Data can take a few minutes to appear, and some queries only return results after the app has handled traffic.

<table>
  <thead>
    <tr>
      <th style={{ width: "200px" }}>
      **Technology**
      </th>
      <th>
      **Query**
      </th>
    </tr>
  </thead>
  <tbody>
      <tr>
        <td>
        APM agents
        </td>
        <td>
        `SELECT count(*) FROM ApplicationAgentContext WHERE agent.language = 'LANGUAGE' AND appName = 'APP_NAME' SINCE 30 minutes ago`, where `LANGUAGE` is `nodejs`, `java`, `python`, `dotnet`, `go`, `php`, or `ruby`
        </td>
      </tr>
      <tr>
        <td>
        Any APM app, after traffic
        </td>
        <td>
        `SELECT count(*) FROM Transaction WHERE appName = 'APP_NAME' SINCE 30 minutes ago`
        </td>
      </tr>
      <tr>
        <td>
        Docker
        </td>
        <td>
        `SELECT count(*) FROM ContainerSample WHERE name = 'CONTAINER_NAME' SINCE 10 minutes ago`
        </td>
      </tr>
      <tr>
        <td>
        Kubernetes
        </td>
        <td>
        `SELECT count(*) FROM K8sClusterSample WHERE clusterName = 'CLUSTER_NAME' SINCE 10 minutes ago`
        </td>
      </tr>
      <tr>
        <td>
        Hosts
        </td>
        <td>
        `SELECT count(*) FROM SystemSample WHERE hostname = 'HOST_NAME' SINCE 10 minutes ago`
        </td>
      </tr>
      <tr>
        <td>
        Web browser, after a page load
        </td>
        <td>
        `SELECT count(*) FROM PageView WHERE appName = 'APP_NAME' SINCE 30 minutes ago`
        </td>
      </tr>
      <tr>
        <td>
        Mobile, after a session
        </td>
        <td>
        `SELECT count(*) FROM MobileSession WHERE appName = 'APP_NAME' SINCE 30 minutes ago`
        </td>
      </tr>
  </tbody>
</table>

A count above zero means data is flowing. There are two ways to run a query, and neither exposes a secret to you:

* **Ask the user** to paste it into the [query builder](/docs/query-your-data/explore-query-data/query-builder/introduction-query-builder) in New Relic and tell you the result.
* **Use the [New Relic CLI](https://github.com/newrelic/newrelic-cli)** if the user has installed it and set a <InlinePopover type="userKey"/> as the `NEW_RELIC_API_KEY` environment variable. Run `newrelic nrql query --accountId ACCOUNT_ID --query 'QUERY'`. The user API key is also a secret, so handle it the same way as the license key.
