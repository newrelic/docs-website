Cloud Cost Intelligence shows your cloud spend at a high level, such as your total **AWS** or **EC2** cost. That view tells you *how much* you spend, but not what it costs to deliver a single unit of value from your service.

Unit economics closes that gap. It measures a business metric such as **cost per query**: how much it costs your business to run one query. When a cost goes up, a unit metric helps you tell the difference between two very different situations:

- **Growth**: costs rose because you served more users or ran more queries. This usually reflects business growth.
- **Waste**: costs rose while the work stayed the same, which points to an inefficiency to investigate.

## Define cost and usage [#define-cost-usage]

A unit metric divides one value by another. You define two parts:

- A **cost definition** built from cost filters.
- A **usage definition** that measures units, such as the number of queries.

The unit cost is one value divided by the other. You can switch which part is the numerator and which is the denominator, so the same two definitions can give you either **cost per unit** (for example, cost per query) or **units per cost** (for example, the number of queries delivered for a given cost).

### Cost filters [#cost-filters]

Cost filters come from the same cost data as your Cost Overview and Kubernetes views. The filters follow the date picker, so your results and chart reflect the period you select. As you add filters, they are automatically converted into a NRQL query.

### Usage definition and guided mode [#usage-definition]

You can define usage across different accounts. If you're not comfortable writing a query, use **guided mode**: select an event you have access to and build the query step by step. Guided mode produces the query for you and returns results in units rather than dollars, along with a chart for the selected period.

## View results [#view-results]

Results are available in a grid view and a table view. For each unit metric, the details include:

- **Unit cost**
- **Total spend**
- **Numerator value**
- **Denominator value**

You can group results, for example by cloud provider, to see how your unit cost breaks down across dimensions.
