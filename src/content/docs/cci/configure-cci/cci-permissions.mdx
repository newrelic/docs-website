Access to <DNT>Cloud Cost Intelligence</DNT> surfaces — <DNT>Settings</DNT>, <DNT>Integrations</DNT>, and <DNT>Custom Facets</DNT> — is controlled by New Relic's standard authorization system. Access is split into read (view configuration) and write (create, update, delete), and is granted per account, not organization-wide.

## Default access [#default-access]

All users with account access — including `all_product_admin` — get view-only access by default. No user has modify, edit, or delete access to CCI out of the box.

Only an <DNT>**Organization Admin**</DNT> can grant modify, edit, or delete access — to themselves, to other individual users, or to a role.

## Grant modify access [#grant-modify-access]

An <DNT>Organization Admin</DNT> grants CCI write access through a [custom role](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/#roles). Two options are available:

### Option 1: Add CCI permissions to an existing custom role [#option-existing-role]

If a custom role already exists for a team (for example, a "FinOps" role), add the CCI write capabilities to it. Everyone already assigned that role automatically gains CCI write access — no per-user reassignment needed.

### Option 2: Create a dedicated custom role for CCI [#option-new-role]

Create a custom role containing only the CCI write capabilities (<DNT>Settings</DNT>, <DNT>Integrations</DNT>, <DNT>Custom Facets</DNT>), then assign it to the specific users, groups, or yourself who need it. Use this option to keep CCI administration fully separate from any other role's responsibilities.

## Recommended onboarding step [#onboarding]

<Callout variant="tip">
  As part of setting up CCI, an <DNT>Organization Admin</DNT> should decide who needs modify and edit access — including whether they themselves need it — and grant it explicitly via a custom role. Use Option 1 if an existing role fits, or Option 2 to keep CCI access separate.
</Callout>
