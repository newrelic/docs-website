Use the `workflowAutomationStartWorkflowRun` mutation to start a workflow run for a specified workflow definition.

<Callout variant="important">
For limits on concurrent workflow runs and steps per run, see [Workflow System Limits](/docs/workflow-automation/limitations-and-faq/workflow-limits).
</Callout>

### logLevel option [#loglevel-option]

The `logLevel` option controls the amount of information the workflow generates during execution.

- `NONE` (default): Generates no log outputs.
- `INFO`: Outputs step-level information.
- `DEBUG`: Adds an attribute to the step started logs with all the action step inputs, using the format `workflowAutomation.inputs.<inputName>: <inputValue>`.
- `TRACE`: In addition to `DEBUG` output, adds an attribute to the step started logs with all the action step outputs, using the format `workflowAutomation.outputs.<outputName>: <outputValue>`.

## Sample request [#sample-request]

Use the [Query Builder](https://one.newrelic.com/nerdgraph-graphiql?state=b8f3b3a9-8d3e-c03e-5da4-34b98a57ff8f) to create and edit a workflow. See [NerdGraph API explorer](/docs/apis/nerdgraph/get-started/nerdgraph-explorer).


```graphql
mutation {
  workflowAutomationStartWorkflowRun(
    definition: {name: "json-parsing", version: 1}
    workflowInputs: [
      {key: "checkOperational", value: "false"}
      {key: "checkNonOperational", value: "true"}]
    scope: {id: "12345678"}
    idempotencyKey: "45e65924-5316-479c-a977-f6adfa17e07a"
    options: {logLevel: INFO}
  ) {
    runId
  }
}
```

## Sample response [#sample-response]

The mutation returns:

- `runId`: The unique identifier for the workflow run. Use this ID with `WorkflowRunInfo`, `SignalWorkflowRun`, or `StopWorkflowRun` APIs.
