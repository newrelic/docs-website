Use the `workflowAutomation.schedule` query to get and return a schedule.

## Input parameters [#input-parameters]

<table>
  <thead>
    <tr>
      <th style={{ width: "200px" }}>Parameter</th>
      <th>Data type</th>
      <th>Description</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>`account.id`</td>
      <td>Number</td>
      <td>(Required) Your account ID.</td>
    </tr>
    <tr>
      <td>`schedule.id`</td>
      <td>String</td>
      <td>(Required) The unique identifier of the schedule to retrieve.</td>
    </tr>
  </tbody>
</table>

## Sample request [#sample-request]

```graphql
    {
      actor {
        account(id: 12345678) {
          workflowAutomation {
            schedule(id: "schedule-id") {
              id
            }
          }
        }
      }
    }
```

## Sample response [#sample-response]

The query returns:

- `schedule.id`: The unique identifier of the schedule.
