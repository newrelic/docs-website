Use the `workflowAutomation.schedules` query to return information about schedules.

## Input parameters [#input-parameters]

<table>
  <thead>
    <tr>
      <th style={{ width: "200px" }}>Parameter</th>
      <th>Data type</th>
      <th>Description</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>`account.id`</td>
      <td>Number</td>
      <td>(Required) Your account ID.</td>
    </tr>
  </tbody>
</table>

## Sample request [#sample-request]

```graphql
{
  actor {
    account(id: 12345678) {
      workflowAutomation {
        schedules {
          results {
            definition {
              name
              scope {
                id
                type
              }
              version
            }
            schedule {
              id
            }
          }
        }
      }
    }
  }
}
```

## Sample response [#sample-response]

The query returns:

- `schedules.results`: An array of schedule objects, each containing:
  - `definition.name`: The workflow definition name
  - `definition.scope.id`: The account ID
  - `definition.scope.type`: The scope type
  - `definition.version`: The workflow definition version
  - `schedule.id`: The unique identifier of the schedule
