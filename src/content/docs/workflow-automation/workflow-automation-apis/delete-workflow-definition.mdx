Use the `workflowAutomationDeleteWorkflowDefinition` mutation to delete all versions of a workflow definition with the specified name.

<Callout variant="important">
- To delete a definition, there must be no schedules using it. If the definition is currently used by a schedule, the deletion fails and returns an error.
- All running workflow runs continue to completion even if the definition is deleted.
</Callout>

## Input parameters [#input-parameters]

<table>
  <thead>
    <tr>
      <th style={{ width: "200px" }}>Parameter</th>
      <th>Data type</th>
      <th>Description</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>`definition.name`</td>
      <td>String</td>
      <td>(Required) The name of the workflow definition to delete. All versions with this name are deleted.</td>
    </tr>
    <tr>
      <td>`scope.id`</td>
      <td>String</td>
      <td>(Required) Your account ID.</td>
    </tr>
    <tr>
      <td>`scope.type`</td>
      <td>Enum</td>
      <td>(Required) The scope type (`ACCOUNT`).</td>
    </tr>
  </tbody>
</table>

## Sample request [#sample-request]

```graphql
mutation {
  workflowAutomationDeleteWorkflowDefinition(
    definition: {name: "my-workflow"}
    scope: {id: "12345678", type: ACCOUNT}
  ) {
    definition {
      name
    }
  }
}
```
