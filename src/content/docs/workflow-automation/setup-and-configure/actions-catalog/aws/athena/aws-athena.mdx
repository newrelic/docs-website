This page provides a reference for AWS Athena actions available in the workflow automation actions catalog. Use these actions to run SQL queries against Amazon Athena, check their execution status, and retrieve results directly from a workflow definition.

## Prerequisites

For prerequisites and credentials setup, see [Set up AWS credentials](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials).

## Start a query execution [#start-query-execution]

The action identifier is `aws.athena.startQueryExecution`.

Runs a SQL query against Amazon Athena and returns the query execution ID. This action does not wait for the query to complete — use `aws.athena.getQueryExecution` to poll for status and `aws.athena.getQueryResults` to retrieve results.

**Example**

```yaml
name: start-athena-query
description: Run a SQL query against Athena
steps:
  - name: startQuery
    type: action
    action: aws.athena.startQueryExecution
    version: '1'
    inputs:
      awsRoleArn: ${{ :secrets:awsRoleArn }}
      region: us-east-2
      queryString: "SELECT * FROM my_table LIMIT 10"
      database: "my-database"
      catalog: "AwsDataCatalog"
      outputLocation: "s3://my-athena-results-bucket/path/"
      workGroup: "primary"
      selectors:
        - name: queryExecutionId
          expression: ".response.QueryExecutionId"
    next: end
```

## Get a query execution [#get-query-execution]

The action identifier is `aws.athena.getQueryExecution`.

Returns the details and current status of a single Athena query execution by its execution ID. Use this to poll a query started by `aws.athena.startQueryExecution` until it reaches a terminal state (`SUCCEEDED`, `FAILED`, or `CANCELLED`).

**Example**

```yaml
name: get-athena-query-execution
description: Check the status of an Athena query execution
steps:
  - name: getExecution
    type: action
    action: aws.athena.getQueryExecution
    version: '1'
    inputs:
      awsRoleArn: ${{ :secrets:awsRoleArn }}
      region: us-east-2
      queryExecutionId: "ef4a125f-9e79-466d-bae5-d6d36536fbee"
      selectors:

          expression: ".response.QueryExecution.Status.State"
        - name: stateChangeReason
          expression: ".response.QueryExecution.Status.StateChangeReason"
    next: end
```

## Get query results [#get-query-results]

The action identifier is `aws.athena.getQueryResults`.

Returns the rows and column metadata of a completed Athena query execution. Results are paginated — when the response includes a `NextToken`, pass it as `nextToken` on the next call to retrieve the following page. The first row of `ResultSet.Rows` is always the header row (column names).

**Example**

```yaml
name: get-athena-query-results
description: Fetch results of a completed Athena query
steps:
  - name: getResults
    type: action
    action: aws.athena.getQueryResults
    version: '1'
    inputs:
      awsRoleArn: ${{ :secrets:awsRoleArn }}
      region: us-east-2
      queryExecutionId: "8d0105c1-30b5-4b8f-a23e-a1b60047c43f"
      maxResults: 100
      selectors:
        - name: rows
          expression: ".response.ResultSet.Rows"
        - name: columnInfo
          expression: ".response.ResultSet.ResultSetMetadata.ColumnInfo"
        - name: nextToken
          expression: ".response.NextToken"
    next: end
```
