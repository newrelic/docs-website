This page provides a reference for AWS Resource Groups Tagging API actions available in the workflow automation actions catalog. Use these actions to get, add, update, and remove tags on AWS resources across services.

## Prerequisites

For prerequisites and credentials setup, see [Set up AWS credentials](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials).

## Get tags by ARN

The action identifier is `aws.resourceGroupsTaggingApi.getResourceTags`.

Returns the tags for one or more AWS resources specified by ARN.

<Callout variant="important">
  You cannot combine `resourceArnList` with `tagFilters`, `resourceTypeFilters`, or pagination inputs. AWS rejects that combination with an `InvalidParameterException`. To find resources by tag or type, use [`aws.resourceGroupsTaggingApi.getResourcesByTag`](#get-resources-by-tag) instead.
</Callout>

**Example workflow**

```yaml
name: get-resource-tags-by-arn
description: 'Get tags for AWS resources by ARN'
steps:
  - name: getResourceTagsByArn
    type: action
    action: aws.resourceGroupsTaggingApi.getResourceTags
    version: '1'
    inputs:
      awsRoleArn: "arn:aws:iam::123456789012:role/my-workflow-role"
      region: "us-east-2"
      resourceArnList:
        - "arn:aws:dynamodb:us-east-2:123456789012:table/my-table"
      selectors:
        - name: tags
          expression: ".response.ResourceTagMappingList"
    next: end
```

## Get resources by tag

The action identifier is `aws.resourceGroupsTaggingApi.getResourcesByTag`.

Finds AWS resources by tag key/value and/or resource type. Only returns resources that have been tagged.

<Callout variant="important">
  You cannot combine `tagFilters` or `resourceTypeFilters` with `resourceArnList` in the same call. AWS rejects that combination with an `InvalidParameterException`. To retrieve tags for specific ARNs, use [`aws.resourceGroupsTaggingApi.getResourceTags`](#get-tags-by-arn) instead.
</Callout>

## Add or update tags on resources

The action identifier is `aws.resourceGroupsTaggingApi.tagResources`.

Adds or updates up to 50 tags on 1–20 AWS resources across services in a single call.

<Callout variant="important">
  Partial failures are reported per-ARN in `response.FailedResourcesMap` rather than as a top-level error. Check `response.FailedResourcesMap` even when `success` is `true`, because one failed ARN in a batch does not fail the entire call.
</Callout>

```yaml

description: 'Add or update tags on AWS resources'
steps:
  - name: tagResources
    type: action
    action: aws.resourceGroupsTaggingApi.tagResources

    inputs:

    next: end
```

## Remove tags from resources

The action identifier is `aws.resourceGroupsTaggingApi.untagResources`.

Removes one or more tags from up to 20 AWS resources across services in a single call. Removing a tag key that does not exist on a resource succeeds silently.

<Callout variant="important">
  Partial failures are reported per-ARN in `response.FailedResourcesMap` rather than as a top-level error. Check `response.FailedResourcesMap` even when `success` is `true`, because one failed ARN in a batch does not fail the entire call.
