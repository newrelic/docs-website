This page provides a reference for AWS Simple Email Service (SES) actions available in the workflow automation actions catalog. Use these actions to create, update, retrieve, and delete email templates, and to send emails through Amazon SES.

## Prerequisites

For prerequisites and credentials setup, see [Set up AWS credentials](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials).

## Create a template

The action identifier is `aws.ses.createTemplate`.

Creates an email template in Amazon SES for sending templated emails.

<Callout variant="important">
  At least one of `textPart` or `htmlPart` must be provided. SES requires the template to have body content in at least one format.
</Callout>

**Example workflow**

```yaml
name: create-ses-template
description: 'Create an email template in Amazon SES'
steps:
  - name: createWelcomeTemplate
    type: action
    action: aws.ses.createTemplate
    version: '1'
    inputs:
      awsRoleArn: "arn:aws:iam::123456789012:role/my-workflow-role"
      region: us-east-2
      templateName: WelcomeEmailTemplate
      subjectPart: "Welcome to Our Service"
      textPart: "Hello, welcome aboard."
      htmlPart: "<h1>Hello</h1><p>Welcome aboard.</p>"
    next: end
```

## Send an email

The action identifier is `aws.ses.sendEmail`.

Sends an email through Amazon SES. The `source` address must be a verified SES identity.

<Callout variant="important">
  At least one of `toAddresses`, `ccAddresses`, or `bccAddresses` must be provided, and at least one of `bodyText` or `bodyHtml` must be provided. The combined recipient count across all three address fields cannot exceed 50. All email addresses must be 7-bit ASCII — Unicode domains must be Punycode-encoded.
</Callout>

## Send bulk templated emails

The action identifier is `aws.ses.sendBulkTemplatedEmail`.

Sends a templated email to multiple recipients in a single call, with per-recipient template data substitution. The `source` address and the referenced `template` must already exist.

<Callout variant="important">
  AWS limits this action to 50 `destinations` entries per call, with up to 50 recipients (combined To/Cc/Bcc) per destination, and a maximum generated message size of 10 MB. Exceeding any of these limits produces an AWS API error at send time.
</Callout>

Each entry in `destinations` accepts the following fields:

- `destination` — **Required.** Object with `toAddresses`, `ccAddresses`, and/or `bccAddresses` (each a list of strings).
- `replacementTemplateData` — **Optional.** JSON string of per-recipient placeholder values. Overrides `defaultTemplateData` for this recipient.
- `replacementTags` — **Optional.** List of `{"name": "...", "value": "..."}` objects that override `defaultTags` for this recipient.
