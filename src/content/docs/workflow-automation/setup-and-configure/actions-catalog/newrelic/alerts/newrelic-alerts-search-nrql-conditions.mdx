The action identifier is `newrelic.alerts.searchNrqlConditions`.

Searches NRQL alert conditions (static or baseline) with optional filtering by name, policy, NRQL query text, or terms operator. Supports cursor-based pagination. Omitting all filters returns all conditions in the account.

The following example finds NRQL conditions attached to a policy by name fragment.

<table>
  <thead>
    <tr>
      <th>Workflow example</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>
```yaml
name: search_nrql_conditions
description: Search NRQL alert conditions
steps:
  - name: searchConditions
    type: action
    action: newrelic.alerts.searchNrqlConditions
    version: 1
    inputs:
      accountId: ${{ .workflowInputs.accountId }}
      policyId: ${{ .workflowInputs.policyId }}
      nameLike: "error rate"
      selectors:
        - name: nrqlConditions
          expression: ".data.actor.account.alerts.nrqlConditionsSearch.nrqlConditions"
    next: end
```
