The action identifier is `newrelic.notification.sendSlack`.

Sends a Slack message to a channel, integrated with destinations.

## Supported block types [#supported-block-types]

The `sendSlack` action supports only two block types and rejects any others during validation.

<table>
  <thead>
    <tr>
      <th>Block type</th>
      <th>Description</th>
      <th>Allowed keys</th>
      <th>Example</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>`section`</td>
      <td>The only block type that renders text. The `text` object's `type` must be either `mrkdwn` or `plain_text`, and `text` must be a non-blank string.</td>
      <td>`type`, `text`</td>
      <td>`{"type":"section","text":{"type":"mrkdwn","text":"*Service:* checkout-api"}}`</td>
    </tr>
    <tr>
      <td>`divider`</td>
      <td>Renders a visual horizontal line.</td>
      <td>`type`</td>
      <td>`{"type":"divider"}`</td>
    </tr>
  </tbody>
</table>

For more information, see the [Slack Block Kit reference](https://api.slack.com/block-kit) and the [Slack Block Kit Builder](https://app.slack.com/block-kit-builder).
