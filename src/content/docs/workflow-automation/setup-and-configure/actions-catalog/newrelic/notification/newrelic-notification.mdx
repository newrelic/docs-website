This page provides a reference for all New Relic notification actions available in the workflow automation actions catalog. These actions let you send messages to configured destinations, generate human-in-the-loop signal URLs, and trigger other workflow runs.

## Prerequisites

Before using New Relic notification actions in workflow automation, ensure you have:

* A New Relic account with appropriate permissions.
* A New Relic license key (if sending data to a different account).
* The necessary permissions for the specific New Relic services you plan to use.

See [License Key](/docs/apis/intro-apis/new-relic-api-keys#license-key) for information on how to create and manage your New Relic Account License Key.

## Notification actions

The following table lists all available New Relic notification actions.

<table>
  <thead>
    <tr>
      <th>Action identifier</th>
      <th>Description</th>
      <th>Reference</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>`newrelic.notification.send`</td>
      <td>Sends a message or email to a configured New Relic destination. Supports Slack, email, and Microsoft Teams via a single generic action.</td>
      <td>[Send a notification](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/notification/newrelic-notification-send)</td>
    </tr>
    <tr>
      <td>`newrelic.notification.sendMicrosoftTeams`</td>
      <td>Sends a message to a Microsoft Teams channel via a configured New Relic destination.</td>
      <td>[Send a Microsoft Teams notification](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/notification/newrelic-notification-sendmicrosoftteams)</td>
    </tr>
    <tr>
      <td>`newrelic.notification.sendEmail`</td>
      <td>Sends an email to a configured New Relic email destination, with optional QUERY, RAW, or dashboard snapshot attachments.</td>
      <td>[Send an email](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/notification/newrelic-notification-sendemail)</td>
    </tr>
    <tr>
      <td>`newrelic.notification.sendSlack`</td>
      <td>Sends a Slack message to a channel via a configured New Relic destination. Supports plain text and Block Kit blocks.</td>
      <td>[Send a Slack message](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/notification/newrelic-notification-sendslack)</td>
    </tr>
    <tr>
      <td>`newrelic.notification.createSignalUrl`</td>
      <td>Generates a URL to deliver to a person so they can send a signal to a paused workflow run. Use with a notification action and a wait step to implement the human-in-the-loop pattern.</td>
      <td>[Create a signal URL](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/notification/newrelic-notification-createsignalurl)</td>
    </tr>
  </tbody>
</table>
