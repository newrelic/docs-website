The action identifier is `newrelic.notification.waitForStatus`.

Polls for the delivery outcome of a notification sent by a prior `newrelic.notification.send` step. Given a `sessionId`, this action polls `NrNotificationsEvent` until the notification reaches a terminal status (`SUCCESS` or `FAIL`) or the specified `timeout` elapses. For Slack destinations, also returns the `thread_ts` value needed to reply into the thread the notification created.

      <td>
```yaml
name: notify_and_wait
description: Send a Slack notification then wait for its delivery status
steps:
  - name: sendNotification
    type: action
    action: newrelic.notification.send
    version: 1
    inputs:
      type: slack
      destinationId: "your-destination-id"
      parameters:
        channel: "your-slack-channel"
        text: "Deployment finished"
      selectors:
        - name: sessionId
          expression: ".response.sessionId"
    next: waitForStatus

  - name: waitForStatus
    type: action
    action: newrelic.notification.waitForStatus
    version: 1
    inputs:
      sessionId: ${{ .steps.sendNotification.outputs.sessionId }}
      timeout: 15
      selectors:
        - name: deliveryStatus
          expression: ".notificationStatus.status"
        - name: threadTs
          expression: ".notificationStatus.threadTs"
    next: end
```
