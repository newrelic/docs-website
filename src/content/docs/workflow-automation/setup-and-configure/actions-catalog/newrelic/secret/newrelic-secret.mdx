This page provides a reference for New Relic Secrets Management actions available in the workflow automation actions catalog. These actions let you list secrets and inspect their version history directly from a workflow definition.

<Callout variant="important">
  There is no action to retrieve a secret's value. Decrypting a secret through a workflow action would expose the value in the run's history and logs. To use a secret's value as an input to a workflow step, reference it directly using the `${{ :secrets:keyName }}` syntax instead.
</Callout>

## Prerequisites

Before using New Relic secret actions in workflow automation, ensure you have:

* A New Relic account with appropriate permissions to read Secrets Management.
* The `scopeId` (account ID or organization ID) and `scopeType` (`ACCOUNT` or `ORGANIZATION`) for the scope you want to query.

## List secret versions [#list-versions]

The action identifier is `newrelic.secret.listVersions`.

Lists all versions of a New Relic Secrets Management secret, including soft-deleted versions when requested.

steps:
  - name: listSecretVersions
    type: action
    action: newrelic.secret.listVersions
    version: 1
    inputs:
      key: "jira_auth_token"
      scopeId: "11933347"
      scopeType: "ACCOUNT"
      fetchDeleted: true

## List secrets [#list-secrets]

The action identifier is `newrelic.secret.list`.

Lists New Relic Secrets Management secrets within an account or organization scope, with optional namespace and deleted-status filtering and cursor-based pagination. Results are sorted by creation time.

      <td>**scopeId**</td>

      <td>String</td>

    <tr>
      <td>**namespace**</td>
      <td>String</td>
      <td>**Optional.** Only return secrets in this namespace. Omit to return secrets across all namespaces.</td>
      <td>`"my-namespace"`</td>
    </tr>
    <tr>
      <td>**deleted**</td>
      <td>Boolean</td>
      <td>**Optional.** Filter by deleted status. `true` returns only soft-deleted secrets, `false` returns only active secrets. Omit to return both.</td>
      <td>`false`</td>
    </tr>
    <tr>
      <td>**sortDirection**</td>
      <td>String</td>
      <td>**Optional.** Sort order by creation time. Allowed values: `ASC`, `DESC`. Default: `DESC` (newest first).</td>
      <td>`"DESC"`</td>
    </tr>
    <tr>
      <td>**cursor**</td>
      <td>String</td>
      <td>**Optional.** Opaque pagination cursor from a previous call's `nextCursor` output. Omit to start from the first page.</td>
      <td>`"${{ .steps.listSecrets.outputs.nextCursor }}"`</td>
    </tr>
    <tr>
      <td>**selectors**</td>
      <td>List</td>
      <td>**Optional.** JQ selectors to extract specific fields from the action output.</td>
      <td>`[{"name": "totalCount", "expression": ".data.customerAdministration.secrets.totalCount"}]`</td>
    </tr>
