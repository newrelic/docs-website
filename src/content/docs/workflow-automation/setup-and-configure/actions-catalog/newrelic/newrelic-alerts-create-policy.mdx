The action identifier is `newrelic.alerts.createPolicy`.

Creates a new alert policy. A policy is the top-level container that groups related alert conditions and determines how incidents are created when conditions are violated.

    <TabsPageItem id="policy-create-example">

The following example creates an alert policy and captures the new policy ID for use in subsequent steps.

<table>
  <thead>
    <tr>
      <th>Workflow example</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>
```yaml
name: create_alert_policy
description: Create an alert policy
steps:
  - name: createPolicy
    type: action
    action: newrelic.alerts.createPolicy
    version: 1
    inputs:
      accountId: ${{ .workflowInputs.accountId }}
      name: "Production Services"
      incidentPreference: "PER_CONDITION"
      selectors:
        - name: policyId
          expression: ".data.alertsPolicyCreate.id"
    next: end
```
      </td>
    </tr>
