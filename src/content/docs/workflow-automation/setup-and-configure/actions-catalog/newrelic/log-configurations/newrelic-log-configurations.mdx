This page provides a reference for New Relic log configuration actions available in the workflow automation actions catalog. Use these actions to query log configuration resources — parsing rules, data partition rules, obfuscation expressions and rules, and pipeline settings — and perform operations like validating Grok patterns and updating pipeline configuration, directly from a workflow definition.

## Prerequisites

Before using New Relic log configuration actions in workflow automation, ensure you have:

* A New Relic account with appropriate permissions to access log management configuration.
* The account ID for each account whose log configuration you want to query or update.

steps:
  - name: upsertPipelineConfiguration
    type: action
    action: newrelic.logConfigurations.upsertPipelineConfiguration
    version: 1
    inputs:
      accountId: 123456
      parsingDisabled: false
      obfuscationDisabled: false
      patternsEnabled: true
