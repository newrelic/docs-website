This page provides a reference for all New Relic Tagging actions available in the workflow automation actions catalog. These actions let you add, replace, and remove tags on New Relic entities directly from your workflows.

## Prerequisites

Before using New Relic Tagging actions in workflow automation, ensure you have:

  * A New Relic account with appropriate permissions to manage entity tags.

## Tagging actions

The following table lists all available New Relic Tagging actions.

<table>
  <thead>
    <tr>
      <th>Action identifier</th>
      <th>Description</th>
      <th>Reference</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>`newrelic.tagging.addTags`</td>
      <td>Adds one or more tags to a New Relic entity, keeping any existing tags.</td>
      <td>[Add tags to a New Relic entity](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging-addtags)</td>
    </tr>
    <tr>
      <td>`newrelic.tagging.replaceTags`</td>
      <td>Replaces a New Relic entity's entire tag set with the tags provided.</td>
      <td>[Replace tags on a New Relic entity](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging-replacetags)</td>
    </tr>
    <tr>
      <td>`newrelic.tagging.deleteTags`</td>
      <td>Removes one or more tag keys and all values under them from a New Relic entity.</td>
      <td>[Delete tags from a New Relic entity](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging-deletetags)</td>
    </tr>
    <tr>
      <td>`newrelic.tagging.deleteTagValues`</td>
      <td>Removes specific tag values from a New Relic entity, leaving other values under the same key untouched.</td>
      <td>[Delete tag values from a New Relic entity](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging-deletetagvalues)</td>
    </tr>
  </tbody>
</table>
