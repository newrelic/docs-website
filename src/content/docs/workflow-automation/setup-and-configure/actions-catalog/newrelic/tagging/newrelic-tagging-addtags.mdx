Adds one or more tags to a New Relic entity, keeping any existing tags.

For prerequisites, see [New Relic Tagging actions](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites).

## Add tags

The action identifier is `newrelic.tagging.addTags`.

Adds one or more tags to a New Relic entity. Adding a value to a key that already exists appends to it rather than replacing it. Built on `newrelic.nerdgraph.execute`.

The following example adds a `team` tag to an entity.

<table>
  <thead>
    <tr>
      <th>Workflow example</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>
```yaml
name: newrelic_tagging_addtags_workflow
workflowInputs:
  entityGuid:
    type: String
steps:
  - name: tagCheckoutApp
    type: action
    action: newrelic.tagging.addTags
    version: 1
    inputs:
      entityGuid: ${{ .workflowInputs.entityGuid }}
      tags:
        - key: team
          values: ["ui"]
    next: end
```
