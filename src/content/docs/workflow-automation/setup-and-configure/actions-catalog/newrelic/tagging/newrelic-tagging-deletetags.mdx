Removes one or more tag keys and all values under them from a New Relic entity.

For prerequisites, see [New Relic Tagging actions](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites).

## Delete tags

The action identifier is `newrelic.tagging.deleteTags`.

Removes one or more tag keys and all values under them from a New Relic entity. To remove only specific values while keeping other values under the same key, use [`newrelic.tagging.deleteTagValues`](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging-deletetagvalues) instead. Built on `newrelic.nerdgraph.execute`.

  - name: untagCheckoutApp
    type: action
