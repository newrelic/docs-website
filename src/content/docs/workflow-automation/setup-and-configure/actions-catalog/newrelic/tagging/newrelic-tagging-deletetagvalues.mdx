Removes specific tag values from a New Relic entity, leaving other values under the same key untouched.

For prerequisites, see [New Relic Tagging actions](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites).

## Delete tag values

The action identifier is `newrelic.tagging.deleteTagValues`.

Removes specific key/value pairs from a New Relic entity's tags. We keep other values under the same key. To remove an entire tag key and all its values, use [`newrelic.tagging.deleteTags`](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging-deletetags) instead. Built on `newrelic.nerdgraph.execute`.

The following example removes the `ui` value from the `team` tag key, leaving any other values under `team` intact.

<table>
  <thead>
    <tr>
      <th>Workflow example</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>
```yaml
name: newrelic_tagging_deletetagvalues_workflow
workflowInputs:
  entityGuid:
    type: String
steps:
  - name: removeUiTagValue
    type: action
    action: newrelic.tagging.deleteTagValues
    version: 1
    inputs:
      entityGuid: ${{ .workflowInputs.entityGuid }}
      tagValues:
        - key: team
          value: ui
    next: end
```
