Replaces a New Relic entity's entire tag set with the tags provided.

For prerequisites, see [New Relic Tagging actions](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites).

## Replace tags

The action identifier is `newrelic.tagging.replaceTags`.

Replaces a New Relic entity's entire tag set with the tags provided. This action is destructive: it removes any existing tag not included in the `tags` input. To add tags without removing existing ones, use [`newrelic.tagging.addTags`](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging-addtags) instead. Built on `newrelic.nerdgraph.execute`.

The following example replaces an entity's entire tag set with a single `team` tag.

<table>
  <thead>
    <tr>
      <th>Workflow example</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>
```yaml
name: newrelic_tagging_replacetags_workflow
workflowInputs:
  entityGuid:
    type: String
steps:
  - name: retagCheckoutApp
    type: action
    action: newrelic.tagging.replaceTags
    version: 1
    inputs:
      entityGuid: ${{ .workflowInputs.entityGuid }}
      tags:
        - key: team
          values: ["cookie-dev"]
    next: end
```
