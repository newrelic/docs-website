Lists GitHub Actions workflow runs for a repository, with optional filtering by workflow, branch, event, status, and more. If `workflowId` is provided, the list is scoped to that specific workflow; otherwise it returns runs across all workflows in the repository.

For authentication setup, see [GitHub workflow run actions](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run).

            <th>Workflow example</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>
```yaml
name: list_workflow_runs
description: List GitHub Actions workflow runs for a specific workflow
steps:
  - name: list_runs
    type: action
    action: gitHub.workflowRun.list
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      workflowId: deploy.yml
      branch: main
      status: completed
      resultsPerPage: 10
      selectors:
        - name: totalCount
          expression: ".total_count"
        - name: latestRunId
          expression: ".workflow_runs[0].id"
        - name: latestConclusion
          expression: ".workflow_runs[0].conclusion"
    next: end
```
            </td>
