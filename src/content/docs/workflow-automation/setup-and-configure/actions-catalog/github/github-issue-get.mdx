Retrieves a single issue from a GitHub repository by issue number.

For authentication setup, see [GitHub issue actions](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-issue).

```yaml
name: github_get_issue_workflow
description: Get a GitHub issue
steps:
  - name: get_issue
    type: action
    action: gitHub.issue.get
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      issueNumber: 7
    next: end
```
