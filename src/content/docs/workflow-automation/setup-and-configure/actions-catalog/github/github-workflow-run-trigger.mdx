Triggers a GitHub Actions workflow run via a `workflow_dispatch` event. The target workflow must have a `workflow_dispatch` trigger configured. GitHub returns HTTP 204 No Content on success.

For authentication setup, see [GitHub workflow run actions](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run).

  The following inputs are available for this action.

  <table>
      <thead>
          <tr>
            <th>Input</th>
            <th>Type</th>
            <th>Description</th>
            <th>Example</th>
          </tr>
      </thead>
      <tbody>
          <tr>
              <td>**token**</td>
              <td>String</td>
              <td>**Required.** GitHub Personal Access Token stored as a secret. Fine-grained PATs require Actions: write permission. Classic PATs require repo scope.</td>
              <td>`"${{ :secrets:github-PAT-token }}"`</td>
          </tr>
          <tr>
              <td>**owner**</td>
              <td>String</td>
              <td>**Required.** The account owner of the repository (user or organization login). Case-insensitive.</td>
              <td>`"octocat"`</td>
          </tr>
          <tr>
              <td>**repo**</td>
              <td>String</td>
              <td>**Required.** Repository name without the .git suffix. Case-insensitive.</td>
              <td>`"Hello-World"`</td>
          </tr>
          <tr>
              <td>**workflowId**</td>
              <td>String</td>
              <td>**Required.** The workflow file name or numeric workflow ID.</td>
              <td>`"deploy.yml"`</td>
          </tr>
          <tr>
              <td>**ref**</td>
              <td>String</td>
              <td>**Required.** The git reference (branch or tag) to run the workflow on. Must exist in the repository.</td>
              <td>`"main"`</td>
          </tr>
          <tr>
              <td>**inputs**</td>
              <td>Map</td>
              <td>**Optional.** Key-value input parameters defined in the workflow's `workflow_dispatch` trigger. All values must be strings. Omitted from the request if empty.</td>
              <td>`{"environment": "staging", "version": "1.2.3"}`</td>
          </tr>
          <tr>
              <td>**selectors**</td>
              <td>List</td>
              <td>**Optional.** JQ selectors to extract values from the response.</td>
              <td>`[{"name": "runId", "expression": ".workflow_run_id"}]`</td>
          </tr>
      </tbody>
  </table>

```yaml
name: trigger_github_workflow
description: Trigger a GitHub Actions workflow run
steps:
  - name: trigger_run
    type: action
    action: gitHub.workflowRun.trigger
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      workflowId: deploy.yml
      ref: main
      inputs:
        environment: staging
        version: "1.2.3"
    next: end
```
