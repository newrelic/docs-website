Locks a GitHub issue, restricting who can add new comments.

For authentication setup, see [GitHub issue actions](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-issue).

name: github_lock_issue_workflow
description: Lock a GitHub issue
steps:
  - name: lock_issue
    type: action
    action: gitHub.issue.lock
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      issueNumber: 7
      lockReason: resolved
    next: end
