Retrieves the most recent GitHub Actions workflow run for a specific workflow. Useful when the exact Run ID is unknown — for example, immediately after triggering a run. Always returns at most one run.

For authentication setup, see [GitHub workflow run actions](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run).

        <tr>
            <td>
```yaml
name: get_latest_workflow_run
description: Retrieve the most recent workflow run for a specific workflow
steps:
  - name: get_latest_run
    type: action
    action: gitHub.workflowRun.getLatest
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      workflowId: deploy.yml
      branch: main
      event: workflow_dispatch
      selectors:
        - name: runId
          expression: ".workflow_runs[0].id"
        - name: conclusion
          expression: ".workflow_runs[0].conclusion"
        - name: htmlUrl
          expression: ".workflow_runs[0].html_url"
    next: end
```
