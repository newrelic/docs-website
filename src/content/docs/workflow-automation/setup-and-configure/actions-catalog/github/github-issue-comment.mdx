Creates a new comment on an existing GitHub issue.

For authentication setup, see [GitHub issue actions](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-issue).

    <TabsPageItem id="github-issue-comment-inputs">

  The following inputs are available for this action.

  <table>
      <thead>
          <tr>
            <th>Input Field</th>
            <th>Optionality</th>
            <th>Type</th>
            <th>Description</th>
            <th>Example</th>
          </tr>
      </thead>
      <tbody>
          <tr>
              <td>**token**</td>
              <td>Required</td>
              <td>String</td>
              <td>GitHub Personal Access Token (fine-grained or classic) stored as a secret. Fine-grained PATs require Issues: Read and write permission. Classic PATs require repo scope.</td>
              <td>`"${{ :secrets:github-PAT-token }}"`</td>
          </tr>
          <tr>
              <td>**owner**</td>
              <td>Required</td>
              <td>String</td>
              <td>The account owner of the repository (user or organization login). Case-insensitive.</td>
              <td>`"octocat"`</td>
          </tr>
          <tr>
              <td>**repo**</td>
              <td>Required</td>
              <td>String</td>
              <td>Repository name without the .git suffix. Case-insensitive.</td>
              <td>`"Hello-World"`</td>
          </tr>
          <tr>
              <td>**issueNumber**</td>
              <td>Required</td>
              <td>Int</td>
              <td>The number that identifies the issue.</td>
              <td>`1347`</td>
          </tr>
          <tr>
              <td>**body**</td>
              <td>Required</td>
              <td>String</td>
              <td>The contents of the comment.</td>
              <td>`"Issue has been investigated and resolved."`</td>
          </tr>
          <tr>
              <td>**selectors**</td>
              <td>Optional</td>
              <td>List</td>
              <td>JQ selectors to extract values from the response.</td>
              <td>`[{"name": "commentId", "expression": ".id"}]`</td>
          </tr>
      </tbody>
  </table>

```yaml
name: github_comment_issue_workflow
description: Add a comment to a GitHub issue
steps:
  - name: add_comment
    type: action
    action: gitHub.issue.comment
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      issueNumber: 7
      body: |
        This issue has been investigated.
        Runbook: https://runbooks.example.com/checkout-5xx
```
