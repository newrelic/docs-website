Retrieves the details, status, and conclusion of a specific GitHub Actions workflow run by its numeric Run ID. The Run ID is typically obtained from a prior `gitHub.workflowRun.trigger` or `gitHub.workflowRun.list` step.

For authentication setup, see [GitHub workflow run actions](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run).

            <td>
```yaml
name: poll_workflow_run
description: Get the status of a specific GitHub Actions workflow run
steps:
  - name: get_run
    type: action
    action: gitHub.workflowRun.get
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      runId: ${{ .steps.trigger_run.outputs.response.workflow_run_id }}
      selectors:
        - name: status
          expression: ".status"
        - name: conclusion
          expression: ".conclusion"
        - name: htmlUrl
          expression: ".html_url"
    next: end
```
