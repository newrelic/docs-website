The following workflow templates automate <DNT>Autopilot</DNT>-powered root cause analysis for New Relic alerts:

- **[Alert RCA with Autopilot and Slack](/docs/workflow-automation/workflow-examples/integrations/autopilot-slack-rca)** — Posts findings to a Slack channel using Block Kit formatting
- **[Alert RCA with Autopilot and Email](/docs/workflow-automation/workflow-examples/integrations/autopilot-email-rca)** — Sends findings as a formatted HTML email

These templates accept an `issueId` input and run <DNT>Autopilot</DNT> with an RCA prompt. They check whether <DNT>Autopilot</DNT> returned a usable response and route the output to the chosen destination. They differ in destination type and how they format <DNT>Autopilot's</DNT> output.

## Requirements [#requirements]

All templates require a New Relic alert issue ID in UUID format. Each template also requires a configured notification destination — see the individual template pages for destination-specific prerequisites.

<Callout variant="tip">
  When triggering any of these templates from <DNT>**Alert Workflows**</DNT>, use `{{ issueId }}` as the value for the `issueId` input. This variable automatically passes the triggering alert's issue ID to the workflow.
</Callout>

## Configuration notes [#configuration]

Keep the following in mind when configuring any of these templates.

<Callout variant="important">
  Write selector `expression` values on a single line. The workflow engine doesn't evaluate multi-line YAML block scalars (`|` or `|-`) as selector expressions — they silently produce no output.
</Callout>

<Callout variant="tip">
  <DNT>Autopilot's</DNT> `finalAnswer` field can return as either a plain string or a JSON-encoded object depending on prompt context. Each template's selectors handle both shapes automatically.
</Callout>
