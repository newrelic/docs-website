This page lists the Agent Control settings you can modify, with their default values. For an overview of local and remote configuration, and for examples of how to configure the agents that Agent Control manages, see [Managing configurations](/docs/new-relic-control/agent-control/configuration).

The Fleet Control connection (`fleet_control`), `host_id`, the managed `agents`, and value providers are covered in [Managing configurations](/docs/new-relic-control/agent-control/configuration).

### Override settings with environment variables [#environment-variables]

You can set any setting as an environment variable. Use the `NR_AC_` prefix, write the setting name in uppercase, and use a double underscore (`__`) to separate nested keys. Environment variables take precedence over the local configuration file.

```bash
# log.level
NR_AC_LOG__LEVEL=DEBUG

# fleet_control.auth_config.client_id
NR_AC_FLEET_CONTROL__AUTH_CONFIG__CLIENT_ID="some-client-id"
```

On hosts, you can define these variables in the service environment file or in an `environment_variables.yaml` file in the local configuration directory (`/etc/newrelic-agent-control/` on Linux, `C:\Program Files\New Relic\newrelic-agent-control\` on Windows). The file must be a flat YAML map of string keys to string values:

```yaml
NR_AC_LOG__LEVEL: "DEBUG"
HTTPS_PROXY: "http://proxy.local:8443"
```

* Keys must start with a letter or underscore, and contain only letters, digits, and underscores.
* Agent Control doesn't watch this file. Restart Agent Control after you change it.
* Agent Control passes these variables to the agents it manages.
* If the file has an invalid entry, Agent Control fails to start.

## Proxy: `proxy` [#proxy]

Agent Control uses the `HTTP_PROXY` and `HTTPS_PROXY` environment variables of your system. You can also set a proxy with the `proxy` setting. If more than one is defined, Agent Control uses them in this order of precedence:

1. The `proxy` setting
2. The `HTTP_PROXY` environment variable
3. The `HTTPS_PROXY` environment variable

```yaml
proxy:
  url: https://user:password@proxy.example.com:8080
  ca_bundle_file: /etc/ssl/certs/proxy-ca.pem
```
