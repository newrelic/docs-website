This page walks you through connecting your OCI account to New Relic using an Oracle Resource Manager (ORM) stack — the recommended install path. ORM deploys the required OCI policies, instrumented namespaces, and log groups for you, without manual OCI console configuration.

<Callout variant="tip" title="Looking for a different install path?">
  If ORM doesn't fit your environment, see [manual installation](/install/oracle-cloud-integrations/manual/install-configure) or [automate with Terraform](https://registry.terraform.io/providers/newrelic/newrelic/latest/docs) instead.
</Callout>

## Compatibility and requirements [#requirements]

### Supported
- OCI tenancies with an Identity and Access Management (IAM) domain
- Oracle Resource Manager stack deployment

### Not supported
- _None._

### You need
- A New Relic account with [infrastructure monitoring permissions](/docs/accounts/accounts-billing/new-relic-one-user-management/user-permissions/#infrastructure)
- A valid New Relic [license key](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key) and [user key](/docs/apis/intro-apis/new-relic-api-keys/#user-api-key)
- Your OCI `IAM_DOMAIN_URL` and the client credential for `newrelic-token-exchange-app`, obtained by completing [Set up Workload Identity Federation](/install/oracle-cloud-integrations/workload-identity-federation)

## Install [#install]

1. [#install-step-1] Go to <DNT>**[one.newrelic.com](https://one.newrelic.com) → Integrations & Agents**</DNT> and click <DNT>**Oracle Cloud**</DNT>.
2. [#install-step-2] Select the data type — **Metrics**, **Logs**, or both — then click **Continue**.
3. [#install-step-3] Select or create the license key and user key to use for the integration, then click **Continue**.
4. [#install-step-4] Choose **Automate OCI integration with ORM**, then click **Deploy to OCI**. This redirects you to the Oracle Cloud console.

   *This step requires your OCI Workload Identity Federation setup to already be in place — see the "You need" section above.*
5. [#install-step-5] Complete the Resource Manager stack deployment as directed in the Oracle Cloud console. The deployment status updates to show successful completion.
6. [#install-step-6] Return to New Relic and click **Continue** to finalize the integration.
7. [#install-step-7] Click **See your data** to view the integration dashboard, then click **Add instrumentation** to see the available namespaces and log groups. Select the ones to monitor, choose the monitoring region, and click **Deploy to OCI**.

   *To instrument additional namespaces or log groups later, return to the OCI page in New Relic and repeat this step.*

## Verify your install [#verify]

Within a few minutes of completing the deployment, you should see:

- Your OCI account listed at <DNT>**one.newrelic.com → Infrastructure → OCI**</DNT>
- Metrics and/or log data flowing in for the namespaces and log groups you selected

If you don't see data after a few minutes, see [Troubleshooting](/install/oracle-cloud-integrations/workload-identity-federation#troubleshooting).
