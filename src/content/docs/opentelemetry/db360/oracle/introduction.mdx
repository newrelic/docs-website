Get deep insights into your Oracle Database performance with our OpenTelemetry-based monitoring solution. Track database metrics, analyze query performance, monitor resource usage, and correlate database performance with your applications.

This NRDOT-based approach complements our existing On-Host Integration (OHI) by leveraging OpenTelemetry standards for database monitoring, making it easier to integrate with your existing observability stack.

Unlike On-Host Integrations, NRDOT operates independently of the Infrastructure agent. It doesn't require the Infrastructure agent to collect database telemetry. NRDOT also includes native host monitoring capabilities, so you can choose to:

- Use the Infrastructure agent for host monitoring alongside NRDOT for database monitoring, or
- Use NRDOT to monitor both the database and the host.

## Capabilities [#capabilities]

- **OpenTelemetry standards**: Integrates seamlessly with existing observability tools
- **Comprehensive metrics**: Deep insight into database performance, wait events, and resource usage
- **Query-level insights**: Identify and analyze slow-performing queries and session activity
- **Flexible deployment**: Works with on-host CDB/PDB and Amazon RDS environments
- **APM correlation**: Connect database performance to application traces

## Choose your install path [#choose]

You can install the NRDOT Collector for Oracle Database monitoring in the following ways:

- Self-hosted environments: Manual installation on your own infrastructure
  - [On-host Container Database (CDB)](/docs/opentelemetry/db360/oracle/host-cdb): Monitor an entire container database, including all pluggable databases under it.
  - [On-host Pluggable Database (PDB)](/docs/opentelemetry/db360/oracle/host-pdb): Monitor an individual pluggable database.
- AWS RDS environments: Cloud-managed Oracle Database monitoring
  - [RDS monitoring](/docs/opentelemetry/db360/oracle/rds): Monitor an Oracle Database instance running in Amazon RDS.
- Oracle Cloud environments: Fully managed Oracle Database monitoring
  - [Autonomous Database (ADB) monitoring](/docs/opentelemetry/db360/oracle/adb): Monitor an Oracle Autonomous Database instance.
- [New Relic CLI](/docs/opentelemetry/db360/oracle/cli): Install and configure the collector with a single command
- [Ansible](/docs/opentelemetry/db360/oracle/ansible): Install and configure the collector at scale using the `newrelic.newrelic_install` Ansible role
- [Chef](/docs/opentelemetry/db360/oracle/chef): Install and configure the collector at scale using the `newrelic-install` Chef cookbook
- [Helm chart](/docs/opentelemetry/db360/oracle/helm): Install and configure Oracle Database monitoring on Kubernetes using the `oracle-otel` Helm chart
- [Docker](/docs/opentelemetry/db360/oracle/docker): Run the collector as a sibling container to an Oracle Database instance already running in Docker
