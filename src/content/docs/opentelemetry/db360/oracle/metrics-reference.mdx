Monitor your Oracle Database performance with comprehensive metrics collected by the NRDOT Collector. By default, New Relic collects the metrics and query-level events referenced in the [Default metrics and events](#default) section. You can enhance your monitoring by enabling your desired metrics listed in the [Full-feature metrics](#full-feature) section.

### Query events [#query-events]

The following events are collected as OpenTelemetry log records and are enabled by default. They provide query-level visibility.

<CollapserGroup>

  <Collapser
    id="db-server-query-sample"
    title="Query samples"
    >

    Per-session active query samples. Captures the current execution state of active Oracle sessions at collection time. This event is enabled by default. 
    
    These attributes can be found by querying the `DbServerQuerySample` event.
    
    Use the `query_sample_collection` block to tune its behavior:

    ```yaml
    query_sample_collection:
      max_rows_per_query: 100
      allowed_comment_keys:
        - nr_service_guid
    ```

    id="db-server-top-query"

    >

    Collection of event metrics for top N queries, filtered based on the highest elapsed time consumed in the collection interval. This event is enabled by default.

    ```yaml
    top_query_collection:
      max_query_sample_count: 1000
      top_query_count: 200

        - nr_service_guid
    ```
