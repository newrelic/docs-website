This reference provides comprehensive YAML configurations for Oracle Database monitoring with the New Relic Distribution of OpenTelemetry (NRDOT) Collector. These full-feature configurations include host infrastructure metrics alongside database monitoring for production environments.

<Callout variant="important">
  **Looking to get started quickly?** These are advanced configurations for production use. If you're setting up Oracle Database monitoring for the first time, we recommend starting with the standard configuration in our setup guides and returning to these comprehensive configurations once you've verified basic functionality.
</Callout>
