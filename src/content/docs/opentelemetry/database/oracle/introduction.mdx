Get deep insights into your Oracle Database performance with our OpenTelemetry-based monitoring solution. Track database metrics, analyze query performance, monitor resource usage, and correlate database performance with your applications.

This NRDOT-based approach complements our existing On-Host Integration (OHI) by leveraging OpenTelemetry standards for database monitoring, making it easier to integrate with your existing observability stack.

## Capabilities [#capabilities]

- **OpenTelemetry standards**: Integrates seamlessly with existing observability tools
- **Comprehensive metrics**: Deep insight into database performance, wait events, and resource usage
- **Query-level insights**: Identify and analyze slow-performing queries and session activity
- **Flexible deployment**: Works with on-host CDB/PDB and Amazon RDS environments
- **APM correlation**: Connect database performance to application traces

## Choose your install path [#choose]

You can install the NRDOT Collector for Oracle Database monitoring in the following ways:

* Self-hosted environments: Manual installation on your own infrastructure
  * [On-host Container Database (CDB)](/docs/opentelemetry/database/oracle/host-cdb): Monitor an entire container database, including all pluggable databases under it.
  * [On-host Pluggable Database (PDB)](/docs/opentelemetry/database/oracle/host-pdb): Monitor an individual pluggable database.
* AWS RDS environments: Cloud-managed Oracle Database monitoring
  * [RDS monitoring](/docs/opentelemetry/database/oracle/rds): Monitor an Oracle Database instance running in Amazon RDS.
* Oracle Cloud environments: Fully managed Oracle Database monitoring
  * [Autonomous Database (ADB) monitoring](/docs/opentelemetry/database/oracle/adb): Monitor an Oracle Autonomous Database instance.

## Guided installation [#ui-install]

Guided installation is available at <DNT>**[one.newrelic.com](https://one.newrelic.com) > Integrations & Agents > Oracle (OpenTelemetry)**</DNT>. The UI provides a guided end-to-end workflow.

## Installation at a glance [#at-a-glance]

<Steps>

<Step>

### Prerequisites [#prerequisites]

* Valid New Relic [license key](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)
* Supported architecture: Linux with AMD64 and ARM64
* Network connectivity to [New Relic OTLP endpoint](/docs/opentelemetry/best-practices/opentelemetry-otlp/)
* Oracle Database 19c or later

For supported detailed prerequisites, refer to the dedicated prerequisites section of installation document.

</Step>

<Step>

### Install NRDOT Collector [#install-step]

Install the NRDOT Collector on your system following the instructions for your specific environment

- [CDB](/docs/opentelemetry/database/oracle/host-cdb)
- [PDB](/docs/opentelemetry/database/oracle/host-pdb)
- [RDS](/docs/opentelemetry/database/oracle/rds)
- [ADB](/docs/opentelemetry/database/oracle/adb)

</Step>

<Step>

### Configure monitoring user [#user]

Create a dedicated Oracle Database user with the necessary read-only permissions to allow the NRDOT Collector to collect metrics and query performance data.

</Step>

<Step>

### Configure NRDOT Collector [#configure]

Configure the NRDOT Collector to connect to your Oracle Database instance. This involves specifying the connection details, authentication method, and any additional configuration options required for your environment.

</Step>

<Step>

### Restart NRDOT Collector [#restart]

After configuring the NRDOT Collector, restart the service to apply the changes and begin collecting data from your Oracle Database instance.

</Step>

<Step>

### Find and use your data [#find]

Once your data is being collected, you can access comprehensive Oracle Database monitoring through the New Relic UI.

To find your Oracle Database entity in New Relic:

1. Go to <DNT>**[one.newrelic.com](https://one.newrelic.com) > All Capabilities > Databases**</DNT>.
2. Set the search criteria as <DNT>`instrumentation.provider = opentelemetry`</DNT>.
3. Select your Oracle Database from the list of entities.

</Step>

</Steps>
