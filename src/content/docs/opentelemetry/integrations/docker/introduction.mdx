The Docker OpenTelemetry integration monitors the health and performance of your containerized applications by collecting real-time metrics directly from the Docker Engine. You get visibility into CPU usage, memory, network I/O, and disk I/O for every running container, so you can catch resource bottlenecks and container failures before they affect your services.

## Capabilities [#capabilities]

This integration provides:

- **Metrics** — CPU usage and utilization, memory usage and percentage, network I/O (bytes and packets sent and received, drops and errors), block I/O, and process (PID) counts
- **Logs** — container log collection, available as an optional step during setup
- **Entities** — Docker containers appear as monitored entities in New Relic, linked to their host

## Choose your install path [#choose]

Two install paths are available:

- **[NRDOT Collector](/docs/opentelemetry/integrations/docker/install-nrdot) (recommended)** — New Relic's OpenTelemetry distribution, pre-configured to send data to New Relic. Use this if you don't already run another OpenTelemetry Collector.
- **[OpenTelemetry Collector Contrib](/docs/opentelemetry/integrations/docker/install-otelcol-contrib)** — the upstream community collector. Use this if you already run OpenTelemetry Collector Contrib for other workloads and want to add Docker monitoring to the same instance.
