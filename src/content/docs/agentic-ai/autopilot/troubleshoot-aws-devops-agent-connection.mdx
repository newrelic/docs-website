Use this page to diagnose errors when you connect <DNT>Autopilot</DNT> to the <DNT>AWS DevOps Agent</DNT> and to understand bearer token expiry.

## Errors during setup [#setup-errors]

If a setup step fails, New Relic shows one of these errors:

<table>
  <thead>
    <tr>
      <th>Error</th>
      <th>Message in New Relic</th>
      <th>Resolution</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>401 Unauthorized</td>
      <td>Token is invalid, expired, or revoked</td>
      <td>Issue a new bearer token at the Operator scope from <DNT>IAM Identity Center</DNT>, <DNT>Amazon Cognito</DNT>, or your IAM service account, and then try again.</td>
    </tr>
    <tr>
      <td>403 Forbidden</td>
      <td>Missing IAM permissions</td>
      <td>Add the four required permissions to the IAM policy attached to the credential.</td>
    </tr>
    <tr>
      <td>404 Not Found</td>
      <td>No agent spaces found</td>
      <td>Verify that the <DNT>AWS DevOps Agent</DNT> is enabled and that the credential has access to at least one agent space.</td>
    </tr>
    <tr>
      <td>429 Rate Limited</td>
      <td>Rate limit hit during discovery</td>
      <td>Wait 30 seconds, then try again.</td>
    </tr>
  </tbody>
</table>

## Token expiry [#token-expiry]

Bearer tokens expire after 60 days. These are the points where you see the expiry:

<table>
  <thead>
    <tr>
      <th>When</th>
      <th>Where it appears</th>
      <th>Action</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>At expiry, during an investigation</td>
      <td>A message in the active investigation thread: "<DNT>AWS</DNT> investigation paused — bearer token expired. Update token in Integrations to resume."</td>
      <td>[Update the bearer token](/docs/agentic-ai/autopilot/connect-to-aws-devops-agent#update-token), and then start the investigation again.</td>
    </tr>
    <tr>
      <td>At investigation start, if the token has already expired</td>
      <td>A "Token expired" status on the connection in the <DNT>**Integrations**</DNT> panel. New Relic also disables routing to the <DNT>AWS DevOps Agent</DNT>.</td>
      <td>[Update the bearer token](/docs/agentic-ai/autopilot/connect-to-aws-devops-agent#update-token)</td>
    </tr>
  </tbody>
</table>

An investigation paused by an expired token doesn't resume automatically, so start it again. The <DNT>AWS DevOps Agent</DNT> treats an updated token as a new identity, so the <DNT>AWS</DNT> side loses any in-progress investigation tied to the previous token.
