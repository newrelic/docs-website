Before enabling [Infra 360](/docs/infrastructure/infra-360/introduction-infra-360) for Azure, ensure you have:

* An Azure account with a subscription ID.
* An Azure app registration with appropriate permissions.
* A New Relic account enrolled in the Infra 360 preview.
* Permissions to manage cloud integrations in New Relic.

## AKS relationship coverage [#aks-coverage]

Infra 360 maps relationships between your Azure Kubernetes Service (AKS) managed clusters and the Azure infrastructure that supports them, including:

* Load balancers
* Virtual machine scale sets (VMSS)
* Virtual machines
* Public IP addresses

Infra 360 doesn't map container- or pod-level relationships, or relationships to APM services running inside the cluster — those come from your Kubernetes and APM agents instead. AKS relationship coverage expands over time based on customer feedback.
