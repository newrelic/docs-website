Before enabling [Infrastructure 360](/docs/infrastructure/infrastructure-360/introduction-infrastructure-360) for AWS, ensure you have:

* Auto-discovery enabled for the AWS account.
* The `cloudformation:StartResourceScan` permission, granted by the CloudFormation stack used during setup.
* Resources in a region that Infrastructure 360 scans (see [scan frequency](#scan-frequency) below).

## What auto-discovery covers on AWS [#coverage]

Auto-discovery scans your connected AWS accounts and creates a New Relic entity for every supported resource, then works out how those resources connect to each other and records those connections as relationships. No agent is required — resources appear whether or not they're instrumented.

If a resource is already monitored another way (for example, the infrastructure agent on an EC2 instance, or CloudWatch Metric Streams on an RDS instance), auto-discovery adds to that existing entity rather than creating a duplicate.

Auto-discovery supports 66 AWS resource types across compute, containers, networking, databases and caching, messaging and streaming, storage, and delivery and security. Coverage expands over time based on customer feedback.

## Scan frequency [#scan-frequency]

A region is rescanned based on your account's metrics polling interval, with a default frequency of 24 hours. You can configure rescanning to run every 8 or 12 hours instead. If you set an interval below 8 hours, it automatically floors to 8 hours.
