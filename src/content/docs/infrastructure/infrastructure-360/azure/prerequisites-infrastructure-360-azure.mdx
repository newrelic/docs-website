Before enabling [Infrastructure 360](/docs/infrastructure/infrastructure-360/introduction-infrastructure-360) for Azure, ensure you have:

* An Azure account with a subscription ID.
* An Azure app registration with the Monitoring Reader role.
* A New Relic account enrolled in the Infrastructure 360 preview.
* Permissions to manage cloud integrations in New Relic.

## APM agent support for entity relationships [#agent-support]

Infrastructure 360 supports entity relationships through native New Relic agents (Java, .NET, Python) and OpenTelemetry (.NET).

## AKS relationship coverage [#aks-coverage]

Infrastructure 360 maps relationships between your Azure Kubernetes Service (AKS) managed clusters and the Azure infrastructure that supports them, including:

* Load balancers
* Virtual machine scale sets (VMSS)
* Virtual machines
* Public IP addresses

Connecting your application to its AKS cluster requires the New Relic Kubernetes agent or OpenTelemetry. Infrastructure 360 doesn't establish that connection on its own, but once it exists, Infrastructure 360 completes the chain by mapping the relationship from your application through the AKS cluster to the other Azure infrastructure it depends on.
