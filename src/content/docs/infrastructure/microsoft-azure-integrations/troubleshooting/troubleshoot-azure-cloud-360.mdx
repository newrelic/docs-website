If you run into issues with [Azure Cloud 360](/docs/infrastructure/microsoft-azure-integrations/get-started/azure-cloud-360), review the following troubleshooting scenarios.

<CollapserGroup>
  <Collapser
    id="no-entities-appear"
    title="No Azure entities appear after enabling Auto-Discovery"
  >
    If no entities appear after enabling Auto-Discovery:

    * **Check permissions**: Ensure your Azure app registration has Reader permissions for the subscription and necessary resource groups.
    * **Verify subscription**: Confirm that the correct Azure subscription ID is configured in your New Relic integration.
    * **Wait for the first scan**: The initial discovery can take time. Check back after the next scheduled scan (default is 3 times per day).
    * **Verify Advanced Compute access**: Confirm your New Relic account has Advanced Compute features enabled by checking <DNT>**Administration > Preview & Trials**</DNT>.
  </Collapser>

  <Collapser
    id="missing-relationships"
    title="Entity relationships are not displaying"
  >
    If relationships between entities aren't showing:

    * **Install APM agents**: Many relationships require APM agents to be installed and actively reporting data from your applications.
    * **Check entity naming**: Ensure your Azure resources use consistent naming that allows Auto-Discovery to match them with APM entities.
    * **Verify network connectivity**: Confirm your Azure resources can reach New Relic's data collectors.
    * **Review resource tags**: Some relationships depend on proper tagging strategies in both Azure and your APM configuration.
  </Collapser>

  <Collapser
    id="scan-failures"
    title="Auto-Discovery scans are failing"
  >
    If your Auto-Discovery scans consistently fail:

    * **Check API limits**: Ensure you haven't exceeded Azure API rate limits. Consider reducing scan frequency temporarily.
    * **Verify app registration**: Confirm your Azure app registration is still valid and hasn't expired.
    * **Review permissions**: Ensure the app registration still has the necessary permissions after any Azure policy changes.
    * **Check subscription status**: Verify your Azure subscription is active and accessible.
  </Collapser>
</CollapserGroup>
