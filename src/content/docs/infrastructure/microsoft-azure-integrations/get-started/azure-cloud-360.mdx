Managing complex Azure environments can be challenging. As your cloud infrastructure grows, it becomes increasingly difficult to understand how your applications connect to underlying infrastructure resources, track configuration changes, and maintain visibility into your entire ecosystem.

<DNT>**Azure Cloud 360**</DNT> solves this problem by automatically mapping your Azure infrastructure and providing real-time insights into the relationships between your applications and the underlying cloud resources powering them. Instead of manually documenting your architecture or struggling to understand dependencies during incidents, Cloud 360 gives you a comprehensive, always-up-to-date view of your cloud environment.

With Cloud 360, you can:

* **Auto-discover Azure entities**: Eliminate blind spots by automatically discovering all Azure entities in your subscription, including resources you might have forgotten about or didn't know existed. New Relic polls your Azure subscription at a set frequency (default is 8 hours) and discovers all resources live in your subscription.
* **Map entity relationships**: See how your applications, databases, virtual machines, and other resources connect to each other. This is crucial for troubleshooting, planning changes, and understanding blast radius during incidents.
* **Stay always up to date**: Your infrastructure map updates automatically as your Azure environment changes. Add a new resource or modify a configuration, and Auto-Discovery reflects these changes without manual intervention.
* **View configuration insights**: See current configurations of your Azure resources directly within New Relic, along with a timeline of configuration changes, eliminating the need to switch between multiple tools during investigations.

* An Azure account with a subscription ID.

* A New Relic account with Advanced Compute capabilities.

## Enable Cloud 360 for a new Azure integration [#setup-new]

If you're setting up Azure integration for the first time:

1. Navigate to <DNT>**Infrastructure > Azure**</DNT> in New Relic.
2. Select an account and click <DNT>**Set up integration**</DNT>.
3. Follow the prompts to create your Azure app registration. For detailed setup instructions, see [Connect Azure integrations](/docs/infrastructure/microsoft-azure-integrations/get-started/activate-azure-integrations).
4. During integration setup, enable the <DNT>**Cloud 360**</DNT> option when prompted.

   <img
     title="Enable Cloud 360 during setup"
     alt="Screenshot of the Azure integration setup page showing the Enable Cloud 360 checkbox"
     src="/images/azure-cloud-360-enable-setup.webp"
   />

5. Configure the scan frequency. By default, Auto-Discovery scans three times per day. To change this, go to <DNT>**Infrastructure > Azure**</DNT>, click <DNT>**Manage Cloud 360**</DNT>, select the subscription, click <DNT>**Configure**</DNT>, select a polling interval, and click <DNT>**Save**</DNT>.

   <img
     title="Configure scan frequency"
     alt="Screenshot showing the polling interval configuration dropdown with options for 8 hours, 12 hours, and 18 hours"
     src="/images/azure-cloud-360-polling-interval.webp"
   />

## Enable Cloud 360 for an existing Azure integration [#setup-existing]

If you already have Azure integrated with New Relic:

1. Go to <DNT>**Infrastructure > Azure**</DNT> and click <DNT>**Manage Cloud 360**</DNT>.

   <img
     title="Manage Cloud 360 settings"
     alt="Screenshot of the Azure infrastructure page showing the Manage Cloud 360 button"
     src="/images/azure-cloud-360-enable-setup.webp"
   />

2. From the account list, find your Azure subscription and click <DNT>**Enable**</DNT>.
3. Configure the scan frequency as described in [Enable Cloud 360 for a new Azure integration](#setup-new).
4. Click <DNT>**Save**</DNT> to enable Cloud 360 for your Azure account.

## Use Cloud 360 [#using-cloud360]

Once Cloud 360 is enabled, Azure Cloud 360 lets you check the relationships among all the entities that include infrastructure, APM, databases, and more.

### View discovered entities and relationships [#view-entities]

1. Go to <DNT>**New Relic > All entities**</DNT> and filter for `collector.name = auto discovery`.

   <img
     title="Filter entities by collector name"
     alt="Screenshot showing the entity filter interface with collector.name = auto-discovery filter applied"
     src="/images/azure-cloud-360-entity-filter.webp"
   />

2. Select any Azure entity to see its infrastructure map, which shows relationships between:
   * Azure entities (virtual machines, databases, storage accounts).
   * APM entities (applications, services).
   * Cross-platform connections (Azure resources connected to APM services).

   <img
     title="Azure infrastructure map"
     alt="Screenshot of the infrastructure map showing Azure resource relationships and dependencies"
     src="/images/azure-cloud-360-infrastructure-map.webp"
   />

   <figcaption>
     The infrastructure map visualizes how your Azure resources connect to each other and to your applications.
   </figcaption>

### View entity configurations [#view-configuration]

1. Go to <DNT>**New Relic > All capabilities**</DNT> and select <DNT>**Azure Services**</DNT>.
2. Select any entity from the list and click <DNT>**Configuration explorer**</DNT> to see its current settings, tags, and properties.

   <img
     title="Configuration changes timeline"
     alt="Screenshot showing the configuration changes timeline view with color-coded changes and timestamps"
     src="/images/azure-cloud-360-config-timeline.webp"
   />

   <figcaption>
     Track configuration changes over time to understand what changed and when.
   </figcaption>

   <img

## Manage Cloud 360 settings [#manage-settings]

### Adjust scan frequency [#adjust-frequency]

You can customize how often Cloud 360 scans your Azure environment:

1. Go to <DNT>**Infrastructure > Azure**</DNT> and click <DNT>**Manage Cloud 360**</DNT>.
2. Find your Azure account and click <DNT>**Edit**</DNT>.
3. Select your preferred scan frequency from the dropdown menu.
4. Click <DNT>**Save**</DNT> to apply the changes.

Consider increasing scan frequency if you make frequent changes to your Azure environment, or decreasing it if your infrastructure is stable and you want to reduce API calls.

### Disable Cloud 360 [#disable]

<Callout variant="important">
  When you disable Cloud 360, you lose access to:

  * Automatically discovered entities and their configurations.
  * Relationship mapping between Azure resources and APM services.
  * Real-time infrastructure topology updates.
</Callout>

To disable Cloud 360:

1. Go to <DNT>**Infrastructure > Azure**</DNT> and click <DNT>**Manage Cloud 360**</DNT>.
2. Find the account where you want to disable Cloud 360.
3. Click <DNT>**Edit**</DNT> and turn off the scan toggle.
4. Click <DNT>**Save**</DNT> to confirm the change.
