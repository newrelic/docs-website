This page lists the OCI namespaces New Relic collects from, the OCI service each namespace belongs to, and the entity type it reports data on in New Relic. For setup, see [Introduction to the OCI integration](/docs/infrastructure/oracle-cloud/introduction).

## Namespaces and entity types [#namespaces]

### Compute and containers
| OCI namespace | Service | Entity type |
|---|---|---|
| `oci_computecontainerinstance` | Container Instance | `OCICONTAINERINSTANCE` |
| `oci_faas` | Functions | `OCIFUNCTION` |
| `oci_instancepools` | Instance Pools | `OCIINSTANCEPOOL` |
| `oci_oke` | Kubernetes (OKE) | `OCIKUBERNETES` |
