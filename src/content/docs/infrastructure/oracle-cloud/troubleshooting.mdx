If you don't see OCI data in New Relic after completing setup, or you hit an error during setup, start here.

## Not seeing data [#no-data]

- Verify the OCI permissions and policies granted to the dynamic group used by the integration.
- Check network connectivity between OCI and New Relic — the functions and service connectors need outbound access to reach New Relic's ingest endpoints.

## Resolving a 409 conflict on Trust Configuration [#trust-conflict]

A 409 conflict when creating an identity propagation trust means a trust configuration with that name already exists. Delete the older configuration, then re-create it.

Using the OCI cloud shell:

1. List the identity domain (skip this if you already know the ID):
   ```
   oci identity-domains identity-propagation-trusts list --all --endpoint $DOMAIN_URL
   ```
2. Delete the conflicting trust configuration — be cautious with this command:
   ```
   oci identity-domains identity-propagation-trust delete --endpoint $DOMAIN_URL --identity-propagation-trust-id $TRUST_CONFIGURATION_ID
   ```
