[New Relic infrastructure](/docs/infrastructure/new-relic-infrastructure/getting-started/introduction-new-relic-infrastructure) integrations monitor the performance of popular products and services. New Relic's Google Cloud Platform (GCP) integrations let you monitor your GCP data in several New Relic features.

If you run workloads on Google Cloud and want to see them alongside the rest of your telemetry, connecting GCP brings your cloud metrics into New Relic, where you can query them, build dashboards, and set alerts.

## Choose how to connect [#connect]

You connect GCP to New Relic using one of three methods:

- <DNT>**Workload Identity Federation**</DNT> (recommended) — you create and own the service account, New Relic uses short-lived credentials, and you automatically get all available GCP metrics, including new ones as Google adds them.
- <DNT>**New Relic service account**</DNT> — New Relic creates and manages the credentials and collects a predefined set of metrics per service.
- <DNT>**Google user account**</DNT> — credentials are tied to a Google user and collect a predefined set of metrics per service.

Use Workload Identity Federation for new integrations. Already connected with a service account or user account? It keeps working, and you can add new projects with Workload Identity Federation alongside your existing setup.

For setup steps and a full comparison of the methods, see [connect your GCP service to New Relic](/docs/infrastructure/google-cloud-platform-integrations/get-started/connect-google-cloud-platform-services-new-relic).

Once connected, your GCP data reports directly to New Relic. To learn how to explore it, see [Understand your GCP data](/docs/infrastructure/google-cloud-platform-integrations/get-started/understand-your-gcp-data).
