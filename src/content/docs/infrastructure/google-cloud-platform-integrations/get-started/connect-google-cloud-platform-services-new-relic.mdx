To start receiving Google Cloud Platform (GCP) data with [New Relic GCP integrations](/docs/introduction-google-cloud-platform-integrations), connect your Google project to New Relic's [infrastructure monitoring](/docs/infrastructure). If you don't have one already, [create a New Relic account](https://newrelic.com/signup). It's free, forever.

You can connect GCP to New Relic in three ways. Compare them below, then follow the matching setup guide.

## Choose a connection method [#choose]

|  | <DNT>**Workload Identity Federation**</DNT> | <DNT>**New Relic service account**</DNT> | <DNT>**Google user account**</DNT> |
| --- | --- | --- | --- |
| Who controls credentials | You create and own the service account | New Relic creates and manages it | Tied to a Google user |
| Credential type | Short-lived tokens (1 hour) | Long-lived key pair | OAuth refresh token |
| Polling frequency | 5 minutes | 5 minutes | 5 minutes |
| Metric coverage | All available GCP metrics (automatic) | Predefined set per service | Predefined set per service |
| Data format | Dimensional metrics (`Metric` event type) | Dimensional metrics + sample events (`GcpXxxSample`) | Dimensional metrics + sample events (`GcpXxxSample`) |
| Services supported | 34 | 27 | 27 |
| New metrics | Available automatically as GCP adds them | Requires New Relic update | Requires New Relic update |

Use <DNT>**Workload Identity Federation**</DNT> for new integrations. It provides better security with short-lived credentials, broader service and metric coverage, and automatic access to new metrics as GCP adds them.

<Callout variant="tip">
  Already have a service account integration? It continues to work. You can also add new projects with WIF alongside your existing setup.
</Callout>

## Explore app data in New Relic [#find-data]

After you authorize New Relic to integrate one or more of your Google project's services, New Relic starts monitoring your GCP data at regular polling intervals. After a few minutes, data will appear in the New Relic UI. To [find and use your data](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), including links to <InlinePopover type="dashboards"/> and alert settings, go to <DNT>**[one.newrelic.com > All capabilities](https://one.newrelic.com/all-capabilities) > Infrastructure > GCP**</DNT>.

It may take few minutes until new resources are detected and synthesized as entities. See Cloud integrations [system limits](/docs/data-apis/manage-data/view-system-limits) for more information.
