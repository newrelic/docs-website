[New Relic integrations](/docs/infrastructure/introduction-infra-monitoring) with the [Google Cloud Platform (GCP)](https://cloud.google.com/) include one that reports [Google Distributed Cloud Edge](https://cloud.google.com/distributed-cloud/edge) data to New Relic. This document explains how to activate the <DNT>GCP Distributed Cloud Edge</DNT> integration and describes the data it reports.

## Features

<DNT>Google Distributed Cloud Edge</DNT> is <DNT>Google Cloud</DNT>'s managed, on-premises edge computing platform for running <DNT>Kubernetes</DNT> workloads on customer-owned hardware. New Relic's <DNT>Distributed Cloud Edge</DNT> integration collects hardware inventory and health metrics for the machines (nodes) and edge clusters in your deployment: CPU, memory, disk, network, GPU, and power/PSU telemetry, along with cluster lifecycle and version status.

## Activate integration [#activate]

<Callout variant="important">
  This integration is available only when you connect your <DNT>GCP</DNT> project with <DNT>**Workload Identity Federation**</DNT>. It isn't available for service account or user account connections.
</Callout>

To enable the integration, follow standard procedures to [connect your GCP service to New Relic](/docs/connect-google-cloud-platform-services-infrastructure) with <DNT>**Workload Identity Federation**</DNT>.

## Polling frequency [#polling]

New Relic integrations query your <DNT>GCP</DNT> services according to a polling interval that varies by integration. The polling frequency for <DNT>Google Distributed Cloud Edge</DNT> is 5 minutes. The resolution is 1 data point every minute.

## Workload Identity Federation [#wif]

### Find and use data [#find-data-wif]

New Relic collects all <DNT>Distributed Cloud Edge</DNT> metrics available in <DNT>GCP Cloud Monitoring</DNT> as dimensional metrics in the `Metric` event type.

This integration doesn't create entities in the New Relic entity explorer. Query its metrics directly on the `Metric` event type, for example:

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'gcp.edgecontainer.%' FACET metricName
```

Metrics carry the resource labels of the underlying machine or edge cluster, so you can facet by cluster name, machine ID, and location without an entity.
