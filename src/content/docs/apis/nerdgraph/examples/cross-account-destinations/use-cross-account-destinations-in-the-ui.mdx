Once you create the <DNT>cross account destinations</DNT> using <DNT>[NerdGraph](/docs/apis/nerdgraph/examples/cross-account-destinations/manage-cross-account-destinations.mdx)</DNT>, you can view the <DNT>Destinations</DNT> and use them to receive notifications by configuring the workflows.

## View destinations on the Destinations page [#view-destinations-page]

1. Go to <DNT>**[one.newrelic.com](https://one.newrelic.com) > Alerts > Destinations**</DNT>
2. Use the <DNT>**Destination scope**</DNT> filter to narrow the list:
   - **Account scope**: destinations available only in the current account
   - **Cross account scope**: destinations available across every account in your organization
3. Identify the scope by its icon:
   - An account icon marks an account-scope destination. Point to the icon to see the account name and ID
   - An organization icon marks a <DNT>cross account destination</DNT>. Point to the icon to see a note that every account in your organization can use it

<img

  src="/images/alerts-destinations.webp"
/>

<Callout variant="important">
You can edit, delete, or test only account-scope destinations from this page. For <DNT>cross account destinations</DNT>, the **Edit** and **Delete** options don't work. To update, delete, or test a <DNT>cross account destination</DNT>, use the [NerdGraph mutations](/docs/apis/nerdgraph/examples/cross-account-destinations/manage-cross-account-destinations).
</Callout>

## Add a destination to a workflow channel [#use-destination-workflow]

A workflow sends notifications through one or more channels, and each channel uses a destination (the underlying integration, such as a <DNT>Slack</DNT> workspace or email address). When you add a channel to a workflow, both account-scope and <DNT>cross account destinations</DNT> appear together in the destination list, for any destination type—email, <DNT>Slack</DNT>, <DNT>Jira</DNT>, <DNT>ServiceNow</DNT>, <DNT>Webhook</DNT>, <DNT>PagerDuty</DNT>, and so on.

1. Go to <DNT>**one.newrelic.com > Alerts > Notification Workflows**</DNT> and select a workflow from the list or create a workflow by clicking <DNT>**+ Add a workflow**</DNT>
   <img
    title="alerts-notificationworkflow.webp"
    alt="alerts-notificationworkflow.webp"
    src="/images/alerts-notificationworkflow.webp"
    /> 
2. Enter relevant details in <DNT>**Configure your notification workflow**</DNT> page
   <img
    title="alerts-configworkflow.webp"
    alt="alerts-configworkflow.webp"
    src="/images/alerts-configworkflow.webp"
    />

3. Click <DNT>**Activate workflow**</DNT> to send notifications to the configured channels
