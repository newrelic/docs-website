Pathpoint maps the health of your technical systems onto the business journeys they support. Each Pathpoint represents one journey — checkout, authentication, or onboarding — broken into stages, so when something goes wrong you can see which part of the customer journey the problem affects.

## Access Pathpoint [#accessing-pathpoint]

Pathpoint is available in the <DNT>**All Capabilities**</DNT> section of the New Relic platform. Select <DNT>**Pathpoint**</DNT> to open the List View, where you'll see all Pathpoints configured for your account.

## List View [#list-view]

  title="Pathpoint List View"
  alt="A screenshot showing the Pathpoint List View."

/>

When you open Pathpoint, you land on the <DNT>**List View**</DNT> — your home base for all the Pathpoints configured in your account. Each row represents a critical business journey you set up to monitor.

If no Pathpoints have been created yet, you'll be prompted to create your first one. See [Create and manage Pathpoints](/docs/pathpoint/create-manage-pathpoints) for more details.

<Callout variant="tip">
  Pathpoint shows Pathpoints for your currently selected account. To see Pathpoints from a different account, use the account dropdown at the top of the screen.
</Callout>

Each row in the list represents one Pathpoint. At a glance, you can see:

* <DNT>**Health status**</DNT>: The entity icon next to the Pathpoint name indicates its current health: green (operational), yellow (degraded), or red (disrupted).
* <DNT>**Name and tag**</DNT>: The name of the Pathpoint, with an optional category tag (for example, E-Commerce or Fintech) to help organize your Pathpoints.
* <DNT>**Stages & their health**</DNT>: The set of stages that make up the journey, shown as pills. Each pill reflects the current health of that stage. For example, a purchase journey might show: Browse → Add to Cart → Checkout → Payment → Confirmation → Fulfillment.
* <DNT>**KPI indicator**</DNT>: Hover over the KPI icon to see the KPIs for that Pathpoint.

Click any row to open the Pathpoint view, where you can see the health status of each stage in detail. See [Pathpoint view](/docs/pathpoint/pathpoint-view) for more.

Use the <DNT>**Team**</DNT> and <DNT>**Category**</DNT> filters at the top of the list to narrow the Pathpoints shown. Use the search bar to find a Pathpoint by name.

To share a Pathpoint, click the <DNT>**...**</DNT> menu on any row in the List View and select <DNT>**Share**</DNT>. This copies a permalink to the Pathpoint to your clipboard. Only users with access to the account will be able to view it.
