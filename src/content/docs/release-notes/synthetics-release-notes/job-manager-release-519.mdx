### Fixes
* Fixed underlying OS and Java vulnerabilities in SJM.
* CVE-2026-33870
* CVE-2026-33871
* Added dual stack (IPv4 and IPv6) support for containerized private locations. Synthetics Job Manager now works in IPv6 environments while maintaining full IPv4 compatibility. Supported container platforms include Docker, Kubernetes, and Podman.
