<Callout variant="important">
  New Relic scans the Node browser runtime image for vulnerabilities every day and publishes a patched release every Thursday. Each release includes fixes for operating system, application, and Chrome CVEs identified by Tuesday 6:29 PM UTC of that week. If we identify a CVE after that time, the fix ships in the following week's Thursday release.

  We publish every release to the `latest` tag, which runs Node.js 22 and the latest stable version of Chrome. Private locations that use `latest` get fixes automatically. If you use a specific version tag, manually update to the newest version to get current fixes.
</Callout>
