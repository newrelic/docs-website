### Bug fixes

* Fixed 12–30 second click delays on Angular and Zone.js applications. The Synthetics browser extension is now loaded via CDP WebSocket (`Extensions.loadUnpacked`) instead of BiDi (`webExtension.install`). Chrome 153+ BiDi introduced a "Waiting for pending navigations" check after every click that stalled responses on apps with pending macrotasks. Switching to CDP keeps BiDi out of the session, restoring ChromeDriver's classic sub-millisecond `document.readyState` navigation check.
