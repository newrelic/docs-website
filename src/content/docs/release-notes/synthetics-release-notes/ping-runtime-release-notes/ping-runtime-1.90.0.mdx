<Callout variant="important">

New Relic scans the Ping runtime image for vulnerabilities every day and publishes a patched release every Thursday. Each release includes fixes for operating system and application CVEs identified by Tuesday 6:29 PM UTC of that week. If we identify a CVE after that time, the fix ships in the following week's Thursday release.

We publish every release to the `latest` tag, so private locations that use `latest` get fixes automatically. If you use a specific version tag, manually update to the newest version to get current fixes.

</Callout>
