### Improvements

* Docker and Kubernetes are now available as collected metadata.
* Upgrades SJM to Java 21.
* Recharacterizes  `Error: timeout of ###ms exceeded` to an `InternalEngineError` (code: 41) so these no longer count against customer checks.

### Security Fixes

* Package updates to resolve CVE-2024-21634.
