Added `AbortController` and `AbortSignal` as available host globals in the Scripted Browser monitor runtime sandbox.

### Bug fixes

Removed the `--jitless` Chrome JS flag to re-enable JIT compilation, improving script execution performance for Scripted Browser monitors.
