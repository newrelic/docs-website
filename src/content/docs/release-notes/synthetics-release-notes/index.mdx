New Relic scans the Ping runtime, Node browser runtime, Node API runtime, and synthetics job manager images for vulnerabilities every day and publishes patched releases every Thursday. Each release includes fixes for operating system and application CVEs that we identify by Tuesday of that week. The Node browser runtime also includes fixes for Chrome CVEs. If we identify a CVE after Tuesday 6:29 PM UTC, the fix ships in the following week's Thursday release.

We publish every release to the `latest` tag, so private locations that use `latest` pick up fixes automatically. The `latest` tag of the Node browser runtime runs Node.js 22 and the latest stable version of Chrome, and the `latest` tag of the Node API runtime runs Node.js 22. If you pin a specific version tag, you need to manually update to the newest version to get current fixes.

The job manager releases separately from the runtimes, so check the release notes for each image to find its fixes.
