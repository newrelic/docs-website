## New Relic PHP agent v12.12.0.41

### Bug fixes

* Fix MongoDB database and collection name retrieval for MongoDB library versions 1.21.4 and 2.4.1 and later. ([#1301](https://github.com/newrelic/newrelic-php-agent/pull/1301))
* Fix a data race in daemon metric harvesting that could crash the daemon when multiple agents report to one daemon. ([#1310](https://github.com/newrelic/newrelic-php-agent/pull/1310))
* Pass `E_DONT_BAIL` through to the PHP error handler so destructors run after an uncaught exception. ([#1317](https://github.com/newrelic/newrelic-php-agent/pull/1317))
* Hold a reference to the callback passed to `newrelic_set_error_group_callback()` to prevent a crash or wrong error group name. ([#1329](https://github.com/newrelic/newrelic-php-agent/pull/1329))
* Remove the Predis command start time once the response is read. ([#1315](https://github.com/newrelic/newrelic-php-agent/pull/1315))

### Security updates

* Upgrade the Go version used to build the daemon to 1.27.3. ([#1304](https://github.com/newrelic/newrelic-php-agent/pull/1304), [#1320](https://github.com/newrelic/newrelic-php-agent/pull/1320), [#1336](https://github.com/newrelic/newrelic-php-agent/pull/1336))

### Support statement
* As previously communicated, PHP Agent support for the following library & framework versions were discontinued and New Relic recommends you upgrade to the latest version supported by the vendor:
    * Slim 2: support has been discontinued in all PHP Agent Versions since July 31, 2026
    * Laravel 11: support has been discontinued in all PHP Agent Versions since September 30, 2026
    * Drupal 7: support has been discontinued in all PHP Agent Versions since October 15, 2026
    * Drupal 9: support has been discontinued in all PHP Agent Versions since October 15, 2026
    * Guzzle 5: support has been discontinued in all PHP Agent Versions since October 15, 2026
    * Guzzle 6: support has been discontinued in all PHP Agent Versions since October 15, 2026

* As previously communicated, PHP Agent support for the following libraries & frameworks were discontinued:
    * Joomla: support has been discontinued in all PHP Agent Versions for all Joomla since September 30, 2026


* PHP Agent support for the following library, framework and OS versions will be discontinued and New Relic recommends you upgrade to the latest version supported by the vendor:
    * Amazon Linux 2 (AL2): Support ends November 15, 2026
    * Red Hat Enterprise Linux 8 (RHEL 8): Support ends November 15, 2026
    * PHP 7.2/7.3: Support ends December 15, 2026

* New Relic recommends that you upgrade the agent regularly and at a minimum every 3 months. For more information on supported agent versions and EOL timelines, check out our [New Relic PHP Agent EOL policy](https://docs.newrelic.com/docs/apm/agents/php-agent/getting-started/php-agent-eol-policy/).
* The [PHP agent compatibility and requirements](https://docs.newrelic.com/docs/apm/agents/php-agent/getting-started/php-agent-compatibility-requirements/) page should be consulted for the latest information on supported PHP versions and platforms.

<Callout variant="important">
  **For installations using an unsupported PHP version or platform, it's highly recommended that you disable the auto-update mechanisms for the PHP agent packages.** This can be done by adding the PHP agent packages to an exclusion list for package upgrades. Or you could version pin the PHP agent package to an agent version that supports the old, unsupported feature(s). Failure to prevent upgrades may result in a newer agent release being installed and the removal of support for the required, unsupported features. This would disrupt APM data collection.

  The PHP agent packages that are affected are:

* newrelic-php5
* newrelic-php5-common
* newrelic-daemon
</Callout>
