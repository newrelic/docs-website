## Notes

This release of the Python agent enables AI monitoring by default with the new `ai_monitoring.basic_telemetry.enabled` setting, deprecates the `ai_monitoring.enabled` setting, and fixes a crash in LangChain tool instrumentation.

Install the agent using `easy_install/pip/distribute` via the [Python Package Index](https://pypi.python.org/pypi/newrelic), using `conda` via the [Conda-Forge Package Index](https://anaconda.org/conda-forge/newrelic), or download it directly from the [New Relic download site](https://download.newrelic.com/python_agent/release).

## Changes

* AI monitoring is now enabled by default

  * LLM instrumentation is now enabled by default and the agent sends `Llm*` custom events, spans, and metrics (without message content) unless configured otherwise.
  * To record prompt and response content, set [`ai_monitoring.record_content.enabled`](/docs/apm/agents/python-agent/configuration/python-agent-configuration/#ai-monitoring-record-content) to `true`.
  * To opt out, set [`ai_monitoring.basic_telemetry.enabled`](/docs/apm/agents/python-agent/configuration/python-agent-configuration/#ai-monitoring-basic-telemetry-enabled) to `false` in newrelic.ini, or set the environment variable `NEW_RELIC_AI_MONITORING_BASIC_TELEMETRY_ENABLED=false`.
  * The [`ai_monitoring.enabled`](/docs/apm/agents/python-agent/configuration/python-agent-configuration/#ai-monitoring-enabled) setting and the `NEW_RELIC_AI_MONITORING_ENABLED` environment variable are deprecated, but setting either one to `false` also opts out of AI Monitoring.

## Bug fixes

* Fixed a crash in [LangChain](https://pypi.org/project/langchain/) `StructuredTool.invoke` and `StructuredTool.ainvoke` instrumentation when `config` or its `metadata` was `None`.
