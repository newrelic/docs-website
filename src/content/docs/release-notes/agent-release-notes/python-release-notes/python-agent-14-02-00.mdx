## Notes

This release of the Python agent adds instrumentation for Microsoft Agent Framework and CrewAI, improves LaunchDarkly feature flag instrumentation and span forwarding support, and fixes several crashes.

Install the agent using `easy_install/pip/distribute` via the [Python Package Index](https://pypi.python.org/pypi/newrelic), using `conda` via the [Conda-Forge Package Index](https://anaconda.org/conda-forge/newrelic), or download it directly from the [New Relic download site](https://download.newrelic.com/python_agent/release).

## New features

* New instrumentation for [Microsoft Agent Framework](https://pypi.org/project/agent-framework/)

  * Instrumentation was added for tools and agents in the `agent-framework` package.
  * Multi-agent configurations are not yet instrumented.

* New instrumentation for [CrewAI](https://pypi.org/project/crewai/)

  * Instrumentation was added for agents, crews, and tools in the `crewai` package.

## Enhanced features

* Improved [LaunchDarkly](https://pypi.org/project/launchdarkly-server-sdk/) feature flag integration.

  <Callout title="preview">
    We're still working on this feature, but we'd love for you to try it out!

    This feature is currently provided as part of a preview program pursuant to our [pre-release policies](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy).
  </Callout>

  * To opt-in to our public preview integration with LaunchDarkly, enable the settings `launch_darkly_integration.enabled` and `opentelemetry.enabled` in your config file.

  * Improved feature flag instrumentation in [ldclient](https://pypi.org/project/launchdarkly-server-sdk/).
    * Added the new `feature_flag.url.full` attribute to enable deep UI linking.
    * Changed the case of the `inExperiment` key to match LaunchDarkly.
    * Added support for falsey values in feature flag attributes.
    * Reduced all LaunchDarkly integration warnings to display only once.

  * Improved span forwarding for [ldobserve](https://pypi.org/project/launchdarkly-observability/).
    * Added the `nr.entity.guid` and `nr.entity.url` span attributes to enable deep UI linking.
    * Corrected span parenting to allow proper nesting in the UI.

## Bug fixes

* Fixed a crash in `TimeTrace` when attributes was `None` in `_add_span_event_event`.
* Fixed a crash in the LaunchDarkly `Config` wrapper when falling back to default values.
