### Bug fixes

* Fixed an issue where calling `recordError` under low-memory conditions could terminate the host application. Error reports are now dropped and logged, and New Relic agent frames are trimmed from the top of the recorded stack.
* Fixed a crash in `NRMALoggerBridge::log` caused by a missing argument in a log format string when removing session attributes. Corrected two additional invalid format strings in the same component.
* Fixed an issue where distributed tracing timestamps (`tracestate` and payload `ti`) were sent in seconds instead of milliseconds when using the new event system.
* Fixed an issue where successful `MobileRequest` events lost all distributed tracing attributes when a cross-platform SDK passed `traceHeaders`.
* Updated the native agent to prevent adding duplicate distributed traces to requests reported with `traceHeaders` by Flutter, React Native, or other hybrid agents. This applies to both `MobileRequest` and `MobileRequestError` in both event systems.
* Enforced minimum and maximum boundary limits for `MaxEventPoolSize` and `MaxEventBufferTime` configuration settings (maximum buffer time capped at 600 seconds).
* Updated `recordCustomEvent` to return a boolean indicating whether the event was successfully added when using the new event system, rather than always returning `YES`.
* Updated React Native JavaScript error uploads to pass the correctly cased `ReactNative` platform value, matching the Android agent behavior.
