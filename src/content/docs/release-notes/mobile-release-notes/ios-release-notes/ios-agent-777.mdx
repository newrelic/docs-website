### New in this release

* The XCFramework is now built with a minimum deployment target of iOS 15.0 and tvOS 15.0, matching the agent's documented minimum supported versions.

### Fixed in this release

* Fixed a crash (`SIGSEGV` inside `objc_msgSend`) that could occur any time the agent read its harvest configuration. Eight object properties on `NRMAHarvesterConfiguration` were declared `assign`, so they pointed into the autoreleased `/connect` response or `NSUserDefaults` dictionary they were parsed from and dangled once that pool drained.

* Fixed all activity traces being dropped for an entire session when the `/connect` response omits `at_capture`.

* Fixed the `platform` value reported with React Native errors, which is now `ReactNative`.

* Fixed `agentVersion` in the JavaScript error payload, which could report the host platform's version instead of the iOS agent version.

* Passing an `NSArray` or `NSDictionary` as a custom attribute or event attribute value now logs an explicit error naming the unsupported type, instead of a generic "value must be an NSString, NSNumber, or BOOL" message.
