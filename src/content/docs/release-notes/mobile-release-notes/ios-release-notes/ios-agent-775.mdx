### Fixed in this release

* Starting in this release we fixed a bug where calling setUserId  with nil always resulted in a new session being started. 

* Agent now prevents old session replay frames from uploading with new session.

* Changed reachability to update a callback on change instead of calling it every time.

* Fixed hex invalidate crash.

* Changes to fix setUserId vendorId crash.

* Fix atomicity across NRMA Trace collections.

* Fixed setUserId to to stay synchronous.

* Fixed by changing session replay from Timer to a DispatchSourceTimer.

* CoreData NRMAMethodProfiler crash fix.

* Crash fix with change so sessionAttributeJSONString now takes a snapshot of dicts.

* MSR text fix by clamping SwiftUI text width-compensation offset to its content.

* Fix for JSErrorController memory leak.

* MSR text fix by refer precise numeric font weight over the binary bold trait.

* Dsym upload tools updated such that appVersion param added to dsym-upload-tools run-symbol-tool.

* fix the missing swiftui modals in msr.
