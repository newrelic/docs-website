## Improvements and enhancements

- Updated the Native Android agent to version 7.8.4. Updated the Native iOS agent to version 7.7.9. ([#336](https://github.com/newrelic/newrelic-react-native-agent/pull/336))

## Bug fixes

- Fixed the opt-in Swift Package Manager integration (`NEWRELIC_USE_SPM=1`): apps no longer crash at launch with `Library not loaded: @rpath/NewRelic.framework/NewRelic`, archives no longer fail on a duplicate xcframework signature, and the iOS agent resolves to the newest 7.7.x release. ([#334](https://github.com/newrelic/newrelic-react-native-agent/pull/334))
