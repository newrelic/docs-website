### New features

- Added a `consoleCaptureEnabled` configuration option (default `true`) that lets you stop the agent from capturing `console.*` calls as logs. ([#342](https://github.com/newrelic/newrelic-react-native-agent/pull/342))

### Improvements and enhancements

- Removed exposed New Relic application token. ([#338](https://github.com/newrelic/newrelic-react-native-agent/pull/338))
- Updated the Native Android agent to version 7.8.5. ([#346](https://github.com/newrelic/newrelic-react-native-agent/pull/346))
- Updated the Native iOS agent to version 7.7.10. If you use CocoaPods and your `Podfile.lock` has an earlier version, run `pod update NewRelicAgent` to upgrade to 7.7.10. ([#346](https://github.com/newrelic/newrelic-react-native-agent/pull/346))

### Bug fixes

- Fixed a crash where `console.log/warn/error/debug` threw an exception when an argument could not be serialized, such as an object with a getter that throws. ([#341](https://github.com/newrelic/newrelic-react-native-agent/pull/341))
