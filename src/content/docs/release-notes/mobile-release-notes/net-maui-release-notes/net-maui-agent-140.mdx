### New features

* Added support for .NET 11, including the CoreCLR runtime on Android and iOS, and removed the .NET 9 targets; unhandled iOS exceptions under CoreCLR are now reported with their managed stack trace. ([#87](https://github.com/newrelic/newrelic-maui-plugin/pull/87))
* Added session replay privacy extensions for .NET MAUI views. ([#102](https://github.com/newrelic/newrelic-maui-plugin/pull/102))

### Improvements and enhancements

* Updated the Native Android agent to version 7.8.6.
* Updated the Native iOS agent to version 7.7.11.
