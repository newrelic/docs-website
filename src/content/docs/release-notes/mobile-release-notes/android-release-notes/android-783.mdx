### Improvements and enhancements
- AGP 9.4 Support: Added support for Android Gradle Plugin (AGP) 9.4.x to the New Relic Gradle plugin.

- Distributed Tracing Header Optimization: Streamlined Distributed Tracing by removing the proprietary newrelic request header and relying solely on W3C standard traceparent and tracestate headers. 

- WebView Browser Agent Detection: Added supportability metrics to detect and track whether active WebViews are utilizing the New Relic Browser Agent. 

- SDK Size Optimization Guidance: Added documentation covering ProGuard/R8 tree-shaking rules to help developers strip unused agent code for disabled features. 

### Bug fixes
- Session Replay Crash Fix: Fixed a multi-threading race condition when initializing Curtains in Session Replay that caused a NullPointerException on the main thread. 

- HTTP2 Payload Size Tracking: Resolved an issue where network request payload size (bytesReceived) incorrectly reported 0 bytes for headerless HTTP/2 and Ktor streams. 

- Resource Leak Resolution: Resolved a static-analysis observation (CWE-404) by properly closing BufferedWriter instances within SessionReplayFileManager. 

## Support statement

We recommend updating the agent at least every three months. Find specific policies and dates for Android agent support in the [Mobile Monitoring Agents EOL Policy](/docs/mobile-monitoring/new-relic-mobile/get-started/mobile-agents-eol-policy/#android-eol).
