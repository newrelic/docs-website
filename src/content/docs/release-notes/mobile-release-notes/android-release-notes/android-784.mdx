### Bug fixes

- Resolved an issue where persisted events were reloaded and re-sent on every launch when `EventPersistence` was disabled.

- Corrected the event buffer behavior so the agent now follows the min/max range for event buffer time.

- Fixed `connectionType` being reported as "unknown" when the cellular subtype couldn't be resolved.

## Support statement
We recommend updating the agent at least every three months. Find specific policies and dates for Android agent support in the [Mobile Monitoring Agents EOL Policy](/docs/mobile-monitoring/new-relic-mobile/get-started/mobile-agents-eol-policy/#android-eol).
