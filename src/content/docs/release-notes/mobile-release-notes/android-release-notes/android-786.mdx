### Improvements and enhancements

- MAUI Session Replay supports global text masking (Mask All, Mask Input, Mask None) and per-view masking by tag or class. It works the same way as native Android and iOS, and password fields are always masked.

### Bug fixes

- `MobileRequest` events no longer include the internal `content_type` and `content_length` attributes, which duplicated `contentType` and `bytesReceived`.
- Fixed a crash when the app comes to the foreground and root detection throws an exception, for example a `NullPointerException` from RootBeer on SUNMI Android 14 devices. The agent now treats the device as not rooted and continues running.
- When the agent starts natively and the hybrid SDK doesn't set the platform at runtime, the agent now reads it from a resource the hybrid SDK ships. Flutter, React Native, Capacitor and Cordova apps report the correct `platform` and `platformVersion` from the first event.
- Ships alongside NDK agent 1.1.6, which fixes native crash-handler failures on PAC-enabled devices and a crash caused by a freed signal stack after the app resumes.

## Support statement

We recommend updating the agent at least every three months. Find specific policies and dates for Android agent support in the [Mobile Monitoring Agents EOL Policy](/docs/mobile-monitoring/new-relic-mobile/get-started/mobile-agents-eol-policy/#android-eol).
