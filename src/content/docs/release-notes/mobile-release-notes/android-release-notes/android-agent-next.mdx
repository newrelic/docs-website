## Improvements and enhancements

* Hybrid apps (Flutter, React Native, Capacitor, Cordova) that start the native agent before the hybrid layer are now reported with the correct `platform` from the first session, once their hybrid agent version ships the framework resource. ([#670](https://github.com/newrelic/newrelic-android-agent/pull/670)) {/* short: Hybrid apps (Flutter, React Native, Capacitor, Cordova) that start the native agent before the hybrid layer are now reported with the correct platform from the first session, once their hybrid agent version ships the framework resource */}

{/* release-note:bug */}
## Bug fixes

* Used ripple content layer for session replay background color. ([#666](https://github.com/newrelic/newrelic-android-agent/pull/666)) {/* short: Used ripple content layer for session replay background color */} {/* flag: unlabelled */}
* Fixed a crash in apps using native crash reporting on some devices, where the agent's root-detection check could throw an unhandled exception when the app came to the foreground. The agent now treats a failed root check as "not rooted" and continues. ([#667](https://github.com/newrelic/newrelic-android-agent/pull/667)) {/* short: Fixed a crash in apps using native crash reporting on some devices, where the agent's root-detection check could throw an unhandled exception when the app came to the foreground. The agent now treats a failed root check as "not rooted" and continues */}
* Request events (`MobileRequest` and `MobileRequestError`) no longer include the internal `content_type` and `content_length` attributes. The content type is now reported as `contentType` on all request events, and the response size is reported as `bytesReceived`. ([#668](https://github.com/newrelic/newrelic-android-agent/pull/668)) {/* short: Request events (MobileRequest and MobileRequestError) no longer include the internal content_type and content_length attributes. The content type is now reported as contentType on all request events, and the response size is reported as bytesReceived */}
