## Bug fixes

* Fixed events recorded while the app was in the foreground being reported with `background = true` when they were sent in a batch harvested after the app moved to the background. With Background Reporting enabled, every event now carries `background = true` or `background = false` for the app's state at the moment it was recorded; foreground events previously had no `background` attribute.
