### New features

- Added `VegaTracker`, an HLS.js tracker for Amazon Vega (Kepler / Fire TV class)
  devices. Import it via the new `@newrelic/video-hls/vega` subpath entry point.
  `VegaTracker` extends `HLSTracker` and routes telemetry through the
  connected-device pipeline instead of the browser pipeline. Ships as both CJS
  and ESM.

### Bug fixes

- Corrected the tracker name reported by `VegaTracker` from `'vega-hls'` to
  `'hls'` so that the `trackerName` attribute in New Relic events matches the
  expected value.
