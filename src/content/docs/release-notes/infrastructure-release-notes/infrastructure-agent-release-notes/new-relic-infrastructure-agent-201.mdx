### Breaking changes

* The [`safe_dir_check_enabled`](/docs/infrastructure/infrastructure-agent/configuration/infrastructure-agent-configuration-settings#safe-dir-check-enabled) setting now defaults to `true`. When enabled, the agent rejects and recreates any directory it manages (such as the data directory and integration temporary directories) that isn't a real directory owned by the user or group running the agent. Directories that are writable by group or other users are also recreated, unless they are a distinct mount point. To change this behavior, set `safe_dir_check_enabled` in your configuration file or the `NRIA_SAFE_DIR_CHECK_ENABLED` environment variable.
