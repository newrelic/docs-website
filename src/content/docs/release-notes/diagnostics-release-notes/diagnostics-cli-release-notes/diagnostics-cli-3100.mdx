## Improvements

* **`DotNet/Agent/Installed`:** Updated the task to detect .NET agent DLLs when `newrelic.config` is absent, and enabled case-insensitive matching for `newrelic.config`. Previously, a missing configuration file prevented agent detection and skipped downstream .NET tasks ([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* **`DotNet/Config/Agent`:** Updated the task to issue a warning rather than a failure when `newrelic.config` is missing ([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* **.NET Core configuration:** Updated file collection to gather and analyze environment-specific configuration files (such as `appsettings.Production.json`). Unrelated files with similar naming patterns (such as `myappsettings.json`) are no longer collected ([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* **.NET Core custom instrumentation:** Updated XML reader tasks to inspect the agent `extensions` and `extensions/netcore` directories, aligning with profiler file-resolution logic ([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* **.NET agent logs:** Updated log filtering so the 1-day cutoff applies exclusively to profiler logs, preserving agent logs from the preceding 7 days. Profiler logs now also respect the `-lastModifiedDate` flag ([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* **.NET agent version and EOL checks:** Updated end-of-life (EOL) and supported version parameters for the .NET agent. Added discrete detection for .NET Framework versions 4.7.1, 4.7.2, 4.8, and 4.8.1, and enabled version collection for the .NET Core agent ([#273](https://github.com/newrelic/newrelic-diagnostics-cli/pull/273)).
* **.NET agent log level:** Updated log level configurations to evaluate settings case-insensitively, matching the .NET agent runtime behavior ([#274](https://github.com/newrelic/newrelic-diagnostics-cli/pull/274)).
* **.NET TLS check:** Updated registry validation so a missing `SchUseStrongCrypto` key is no longer flagged as an error, as supported .NET Framework versions default to TLS 1.2 when the key is absent. An error is now reported only when the key exists and is set to a value other than `1` ([#275](https://github.com/newrelic/newrelic-diagnostics-cli/pull/275)).

## Bug fixes

* Fixed an issue where uploads to the Japan data region failed due to an unassigned upload URL in release builds ([#277](https://github.com/newrelic/newrelic-diagnostics-cli/pull/277)).
* Fixed an issue in .NET Framework profiling environment variable validation to correctly check `COR_ENABLE_PROFILING`. Added support for both `NEW_RELIC_LOG_DIRECTORY` and `NEWRELIC_LOG_DIRECTORY` when resolving .NET agent log locations ([#272](https://github.com/newrelic/newrelic-diagnostics-cli/pull/272)).
* Fixed an issue where environment variable values containing equal signs (`=`) were truncated during parsing ([#272](https://github.com/newrelic/newrelic-diagnostics-cli/pull/272)).
