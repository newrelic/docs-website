## Task Updates

* DotNet/Agent/Installed - The task now detects the .NET agent DLLs even when there is no `newrelic.config`, and matches `newrelic.config` case-insensitively. Previously, a missing config meant no agent was detected and all downstream .NET tasks were skipped ([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* DotNet/Config/Agent - Now warns when `newrelic.config` is missing instead of failing ([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* .NET Core configuration - Environment-specific files such as `appsettings.Production.json` are now collected and checked. Files with similar names, such as `myappsettings.json`, are no longer collected ([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* .NET Core custom instrumentation - XML files are now read from the agent's `extensions` and `extensions/netcore` directories, matching how the profiler locates them ([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* .NET agent logs - The 1-day cutoff now applies only to profiler logs, so agent logs from the past 7 days are no longer dropped. Profiler logs now also respect the `-lastModifiedDate` flag ([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* .NET agent version and EOL checks - Updated the end-of-life and supported version checks to current values for the .NET agent. .NET Framework versions 4.7.1, 4.7.2, 4.8, and 4.8.1 are now detected separately, and the .NET Core agent version is now gathered and checked ([#273](https://github.com/newrelic/newrelic-diagnostics-cli/pull/273)).
* .NET agent log level - Log level settings are now treated as case-insensitive, matching the .NET agent's behavior ([#274](https://github.com/newrelic/newrelic-diagnostics-cli/pull/274)).
* .NET TLS check - A missing `SchUseStrongCrypto` registry key is no longer reported as an error, since supported .NET Framework versions use TLS 1.2 by default when the key is absent. An error is reported only when the key is present and not set to `1` ([#275](https://github.com/newrelic/newrelic-diagnostics-cli/pull/275)).

## Bug Fixes

* Fixed uploads to the Japan data region failing because the upload URL was not set in release builds ([#277](https://github.com/newrelic/newrelic-diagnostics-cli/pull/277)).
* Fixed the .NET Framework profiling environment variable name, which is now correctly checked as `COR_ENABLE_PROFILING`. Both `NEW_RELIC_LOG_DIRECTORY` and `NEWRELIC_LOG_DIRECTORY` are now supported for the .NET agent log location ([#272](https://github.com/newrelic/newrelic-diagnostics-cli/pull/272)).
* Fixed environment variable values containing `=` being truncated ([#272](https://github.com/newrelic/newrelic-diagnostics-cli/pull/272)).
