## New features and improvements

* Upgraded the embedded OpenTelemetry Collector from `v0.156.0` to `v0.164.0`, incorporating the latest upstream components and fixes.
* Upgraded the gateway build to Go `1.26`.

## Security updates

* Updated the `golang.org/x/text` and `google.golang.org/grpc` dependencies to resolve high-severity vulnerabilities reported against the 2.5.0 image.
