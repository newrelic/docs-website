## New features and improvements

* Upgraded the embedded OpenTelemetry Collector from `v0.139.0` to `v0.156.0`, picking up the latest upstream receivers, processors, exporters, and stability fixes.
* Added a new `extraEnv` Helm value, allowing you to inject additional environment variables into the gateway container.

## Security updates

* The gateway container now runs as a non-root user (UID `65532`) by default, reducing its privilege footprint.
* The gateway now listens on the unprivileged port `8080` instead of `80`. The Kubernetes `Service`, ingress, and Gloo upstream definitions are all updated to match. If you reference the gateway service port directly, update it to `8080`.
* Updated Go module dependencies across the gateway's collector components to incorporate the latest upstream security fixes.
