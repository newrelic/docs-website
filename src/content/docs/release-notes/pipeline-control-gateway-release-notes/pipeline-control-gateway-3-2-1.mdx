### Bug fixes

- Fixed an issue where the Python APM agent logged a JSON decoding error on every harvest when sending data through the gateway, which caused duplicate logs and lost error data. The gateway now responds to APM agent data requests with HTTP `202 Accepted` and an empty body, as the agent protocol specifies.
- Fixed an issue where span events from APM agents were recorded with the time the gateway received them instead of the span's start time.

### Security updates

- Updated the `golang.org/x/net` dependency to `v0.62.0` to resolve a high-severity and a medium-severity vulnerability.
