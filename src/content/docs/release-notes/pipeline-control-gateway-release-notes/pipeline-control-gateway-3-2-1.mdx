### Bug fixes

- Fixed an issue introduced in 3.2.0 where the gateway ignored part of its exporter configuration. As a result, Federated Logs usage was reported as Pipeline Control usage, and the New Relic exporter used its default retry settings instead of the configured ones.
- Fixed an issue where span events from APM agents were recorded with the time the gateway received them instead of the span's start time.
- Fixed a gateway crash when the New Relic exporter received data without the originating agent's request information. Such data is now rejected with an error instead.

### Security updates

- Updated the `golang.org/x/net` dependency to `v0.62.0` to resolve a high-severity and a medium-severity vulnerability.
