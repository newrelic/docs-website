### Support for Fluent Bit 5.1.5

Users will now receive Fluent Bit version 5.1.5. For more details, refer to the [Fluent Bit announcements](https://fluentbit.io/announcements/).

This release includes [New Relic Fluent Bit Output Plugin 3.12.0](https://github.com/newrelic/newrelic-fluent-bit-output/releases/tag/v3.12.0).

### Added

* New Relic Fluent Bit Output Plugin 3.12.0 integration
* Native package support for Debian 13 (Trixie)
* Native package support for Windows Server 2025 (LTSC)
* [Fluent Bit Output Plugin Docker image](https://hub.docker.com/r/newrelic/newrelic-fluentbit-output) now publishes a Windows Server 2025 (LTSC) variant

### Changed

* The Go version is upgraded to 1.27.3 for CVE fixes, including blocking the compromised eMudhra intermediate CA keys
* The Linux Docker image no longer trusts the emSign ECC Root CA - G3 and AAA Certificate Services root certificates
* Debian 11 (Bullseye) packages are no longer built because the distribution reached end of life
* The Infrastructure agent recommends Fluent Bit 5.1.5 packages (Linux and Windows)
* [Fluent Bit Output Plugin Docker image](https://hub.docker.com/r/newrelic/newrelic-fluentbit-output) uses Fluent Bit 5.1.5 with output plugin 3.12.0
* [New Relic Logging Helm chart](https://github.com/newrelic/helm-charts/tree/master/charts/newrelic-logging) bumped to version 1.44.0, installing the new plugin image
