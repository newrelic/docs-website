### Features

- Google IMA DAI (dynamic ad insertion) support in `NRTrackerIMA`
- Enable logging with INFO level, and log buffer near-capacity and dropped events, mirroring the iOS `enableLogging` API

### Bug fixes

- Fixed IMA ad tracking so ads cut short by a break end are closed, stray quartile and click events are ignored, per-ad timers no longer carry into the next break, and ad duration is reported in milliseconds
