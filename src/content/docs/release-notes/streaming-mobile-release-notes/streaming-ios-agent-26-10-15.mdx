### Notes

- `NRTHEOplayerTracker` now requires iOS 15.0 or later (upgraded from iOS 13.0) and `THEOplayerSDK-core` version 11.x (upgraded from 10.x). Applications that require iOS 13 or 14 support must remain on `NRTHEOplayerTracker` version 5.0.0. Other tracker packages remain unaffected.

### Improvements

- Updated `NRTHEOplayerTracker` to support `THEOplayerSDK-core` version 11.x.

### Bug fixes

* Fixed an issue in `NRAVPlayerTracker` where pausing playback during rebuffering terminated the buffering event prematurely. The tracker no longer emits `CONTENT_BUFFER_END` while the buffer remains empty, and playtime is no longer accumulated while playback is paused.
* Fixed a crash in `NRTHEOplayerTracker` that occurred when assigning a video source using `THEOplayerSDK` version 11.x.
* Fixed an issue in `NRIMATracker` where the `NRTrackerIMA` class was omitted from the XCFramework binary. This restores `NRTrackerIMA` support for Swift Package Manager and manual installation methods.
