### New features

* Autopilot now applies improved, tailored size limits and smarter budget tracking to every major tool, from NRQL queries to APM and alert analysis, so one oversized response or a single failing tool call is less likely to impact a whole investigation.
* Behind-the-scenes improvements to how Autopilot compresses context, routes requests, and retrieves memory and knowledge help cut processing time without sacrificing answer quality, especially on high-volume accounts. Average run time is down about 20%.
* Improvements for investigating complex environments with many entities, alerts, or logs, where the sheer volume of data could previously cause the run to fail.

### Bug fixes

* Autopilot now better grounds Slack responses to the data it actually retrieved.
* Autopilot now better recovers from individual step failures and continues where it can, resulting in fewer incomplete analyses.
* Fixed an issue where a complex query could cause Autopilot to fail silently. These cases now fail fast with a clear explanation so you can make adjustments.
* Generic "something went wrong" messages have been replaced with suggestions that provide specific detail about what happened and what to try next.
* The chart for "how many active issues" now better matches the text details in the response.
