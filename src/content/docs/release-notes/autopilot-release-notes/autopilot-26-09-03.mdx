## What's new

### Autopilot: faster, more reliable investigations

* **Parallel step execution:** Autopilot now dispatches investigation steps in parallel. Requests that fan out to multiple sub-investigations no longer wait for earlier steps to finish, reducing timeouts on complex investigations.
* **Fast-path routing:** A new routing layer recognizes straightforward requests and resolves them without running the full investigation pipeline, skipping unnecessary steps.
* **Save context to memory:** In the chat panel, tell Autopilot to save information and it adds that context to long-term memory so it's available in future sessions.
* **Copy NRQL to clipboard:** A one-click button in the chat panel copies any generated NRQL query directly to your clipboard.
* **Expand the chat panel:** A single click maximizes the chat panel for a larger workspace.
* **Navigate past queries:** Use the Up (↑) and Down (↓) arrow keys in the prompt box to cycle through and re-select past queries.
* **Clear hourly limit message:** If you've hit your hourly usage limit, Autopilot now shows a clear message instead of a raw error.
* **Investigation completion fix:** Fixed a rare issue where an investigation could appear finished before it actually completed.

### GitHub MCP integration capability updates (public preview)

**GitHub Enterprise Cloud now supported:** The GitHub MCP integration now works with GitHub Enterprise Cloud (`YOURSUBDOMAIN.ghe.com`) in addition to public GitHub. Both investigation use cases are supported: change-triggered root cause identification and manual PR/commit lookup.

The integration supports the following GitHub environments:

| Connection type | URL format | Availability |
|---|---|---|
| Public GitHub | `github.com` | Public preview (since 2.1) |
| GitHub Enterprise Cloud | `YOURSUBDOMAIN.ghe.com` | Public preview (new in 2.2) |

**Connect a GitHub Enterprise Cloud instance:** In **Configure > Autopilot > External MCP connections**, enter `YOURSUBDOMAIN.ghe.com` in the GitHub URL field instead of `github.com`. PAT permissions are unchanged: Pull requests: Read, Contents: Read, Metadata: Read.

If your GHE.com organization enforces SAML SSO, authorize the PAT for SSO in GitHub before entering it in New Relic — an unauthorized token returns a 403 on first use.

Autopilot reads PR descriptions and file change metadata from every repository the token authorizes, so scope your PAT to the repos you actively track.

**Prerequisites:** Active Autopilot setup, Change Tracking configured with commit SHAs flowing into New Relic, GitHub organization admin access to create a fine-grained PAT, and New Relic org manager access.
