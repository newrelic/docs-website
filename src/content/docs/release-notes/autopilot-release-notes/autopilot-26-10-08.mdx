### Bug fixes

- **Faster, more resilient chat panel:** The chat now opens faster, queues bursts of requests, and automatically retries calls that fail due to a brief network hiccup instead of initially surfacing an error.
- **Clearer messaging when you hit a usage limit:** Instead of a generic error, Autopilot now tells you specifically when your hourly request limit or daily usage limit has been reached.
- **More reliable entity search:** Entity lookups now correctly perform fuzzy matching and are more likely to prefer entities in the account you're asking about, so you're more likely to find the right one on the first try.
- **Fixed incorrect time windows:** "IST" could previously be misread as Israel Standard Time instead of India Standard Time, leading to an analysis window that was off by several hours or an unexpected validation error. IST now resolves correctly, along with several other natural-language time-parsing fixes.
- **More accurate NRQL and chart results:** Fixed two issues affecting query results: facet-and-count queries could be constructed incorrectly, and a valid chart value could be stripped from a visualization when it shouldn't have been.
- **Coverage-gap questions now have a more complete answer:** Fixed an issue where asking about monitoring coverage gaps (for example, missing alert or entity coverage) might not actually use Autopilot's dedicated coverage-gap analysis, leading to a less complete answer.
- **Fewer failed requests when attached context is incomplete:** Fixed an issue where a request with incomplete attached context could fail outright instead of falling back to your original question.
