### New features

- Added log levels to `activeLogs`: pass `"INFO"`, `"WARNING"` or `"ERROR"` as a minimum level instead of `true`. `true` still enables all logs and `false` still disables them.
- Added buffer-drop logging: an INFO message when the event buffer reaches 85% full, a WARNING at 90%, and one log line per dropped event with a running drop count.
- Added `QOE_AGGREGATE` values to the agent log output.

### Bug fixes

- Fixed MediaTailor SSAI ad attributes  being added to `VideoAction` events after an ad finished. They are now attached to `VideoAdAction` events only, and ad-level keys are removed from the agent when each ad ends.
- Fixed MediaTailor SSAI `adSrc` being empty. It now carries the stream URL.
- Fixed the MediaTailor tracker overriding ad timing and count attributes (`timeSinceAdStarted`, `timeSinceAdBreakBegin`, `numberOfAds`).
- Fixed `contentRenditionHeight` and `contentRenditionWidth` always reporting 720x480, 1280x720 or 1920x1080. They are now derived from `GetVideoMode()`, so they match `videoMode` (e.g. `2160p` gives 2160 x 3840).
- Fixed colliding `nrSessionId` and `viewId` values when devices launched in the same second. Session IDs now use `GetRandomUUID()`, and `nrVideoCounter` is no longer reset on each `NewRelicVideoStart()`.
