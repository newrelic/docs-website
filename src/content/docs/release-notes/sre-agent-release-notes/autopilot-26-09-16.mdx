Fewer failed investigations, faster answers.

## New features

* **Increased successful investigations from large responses:** <DNT>Autopilot</DNT> now applies improved, tailored size limits and smarter budget tracking to every major tool, from <DNT>NRQL</DNT> queries to <DNT>APM</DNT> and alert analysis, so one oversized response or a single failing tool call is less likely to impact a whole investigation.

* **Faster investigations, especially on high-volume accounts:** Behind-the-scenes improvements to how <DNT>Autopilot</DNT> compresses context, routes requests, and retrieves memory and knowledge help cut processing time without sacrificing answer quality. Average run time is down about 20%.

* **Better handling of large investigations:** Improvements for investigating complex environments with many entities, alerts, or logs, where the sheer volume of data could previously cause the run to fail.

## Bug fixes

* **Improved grounding:** <DNT>Autopilot</DNT> now better grounds <DNT>Slack</DNT> responses to the data it actually retrieved.

* **Fewer investigations abort:** <DNT>Autopilot</DNT> now better recovers from individual step failures and continues where it can, resulting in fewer incomplete analyses.

* **Explanations for failed attempts at complex or long-running queries:** Fixed an issue where a complex query could cause <DNT>Autopilot</DNT> to fail silently. These cases now fail fast with a clear explanation so you can make adjustments.

* **Clearer errors when something does go wrong:** Generic "something went wrong" messages have been replaced with suggestions that provide specific detail about what happened and what to try next.

* **Improved active-issue counts and chart matching:** The chart for "how many active issues" now better matches the text details in the response.
