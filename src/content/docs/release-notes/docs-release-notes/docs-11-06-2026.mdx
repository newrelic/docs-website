### New docs

* Added [Browser: Group request errors tab](/docs/triage-inbox/group-request-errors-browser/) to show you how to group, sort, and filter failed AJAX and fetch requests.
* Added [Exposure check (preview of Security RX)](/docs/vulnerability-management/exposure-check/) to list the APM entities that run a PHP or Node.js version affected by a recent security advisory.
* Added [System identities](/docs/accounts/accounts-billing/new-relic-one-user-management/system-identities/) to explain how to provision non-human identities that authenticate to New Relic with their own credentials.
* Added [Google Gemini Enterprise monitoring integration](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-gemini-enterprise-monitoring-integration/) covering how to activate the integration and the request, latency, session, and quota metrics it collects for apps, agents, tools, and data connectors.
* Added [New Relic log configuration actions](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/log-configurations/newrelic-log-configurations/) to the workflow automation actions catalog to query and update log parsing, partition, and obfuscation rules.
* Added [Security bulletin NR26-12](/docs/security/new-relic-security/security-bulletins/security-bulletin-nr26-12/) with the steps to pull updated Synthetics private location container images after the eMudhra certificate authority compromise.

### Major changes

* Updated [Triage your Kubernetes fleet](/docs/kubernetes-pixie/kubernetes-integration/understand-use-data/explore-k8s/), formerly the cross-cluster page, with the fleet-wide triage view that ranks problems across your clusters.
* Updated [Ruby agent installation](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent/) to simplify installation to three steps, and split the [Ruby agent configuration](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration-overview/) settings into topic pages so you can find options by category.
* Removed the CodeStream docs following its November 5, 2026 end of life, rewrote the agent code-level metrics pages to remove CodeStream references, and added redirects so existing links continue to work.
* Updated [New Relic Ground Truth](/docs/agentic-ai/mcp/overview/) with a section on how to secure MCP access, including revoking OAuth tokens and auditing sign-in activity with `NrAuditEvent`.
* Updated [Access management for managing cardinality](/docs/data-apis/ingest-apis/metric-api/cardinality-access-management/) with the permissions you need to change cardinality budgets through NerdGraph or Terraform.
* Updated [Permissions and roles](/docs/cci/configure-cci/cci-permissions/) for Cloud Cost Intelligence with access prerequisites and a permissions reference table.
* Updated [Upload dSYM files](/docs/mobile-monitoring/new-relic-mobile-ios/configuration/upload-dsyms-bitcode-apps/) with the `run-symbol-tool` Run Script build phase, which replaces the Python upload scripts removed in iOS agent v7.4.8.
* Updated [AWS Lambda actions](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/lambda/aws-lambda/) in the workflow automation actions catalog with concrete example values for output fields, including sample error messages and API response objects.
* Updated [Manage monitor runtimes](/docs/synthetics/synthetic-monitoring/using-monitors/manage-monitor-runtimes/) with the Node.js 22.23.4 runtime and its supported third-party modules.

### Minor changes

* Updated [Browser: JavaScript errors tab](/docs/triage-inbox/browser-tab/) to rename **Errors (errors inbox)** to **JavaScript errors**.
* Updated [Install the Android agent](/docs/mobile-monitoring/new-relic-mobile-android/install-configure/install-android-agent-gradle/) to recommend starting the agent in the `onCreate()` method of your `Application` class.
* Updated [New Relic AI tools](/docs/agentic-ai/tools/) and the mobile monitoring UI pages with links to the Autopilot skills available for each product area.
* Updated [Alerting rules and limits](/docs/alerts/admin/rules-limits-alerts/) to clarify how enabled and disabled conditions count toward limits.
* Updated [Introduction to compound alerts](/docs/alerts/create-alert/create-alert-condition/compound-alerts/compound-alerts/) and [Muting rules](/docs/alerts/get-notified/muting-rules-suppress-notifications/) to explain that muting rules now apply to compound alerts.
* Updated [Send New Relic data via AWS PrivateLink](/docs/data-apis/custom-data/aws-privatelink/) to clarify that you must select **PrivateLink Ready partner services** when creating the VPC endpoint.
* Added the `safe_dir_check_enabled` setting to [Infrastructure agent configuration settings](/docs/infrastructure/infrastructure-agent/configuration/infrastructure-agent-configuration-settings/). This setting defaults to `true` in Infrastructure agent v2.0.1 — a breaking change if you relied on the previous default.
* Updated [Optimize your ingest data](/docs/tutorial-optimize-telemetry/data-optimize-techniques/) and [Optimize your data ingest](/docs/new-relic-solutions/observability-maturity/operational-efficiency/data-governance-optimize-ingest-guide/) to clarify how `enable_process_metrics` and `metrics_process_sample_rate: -1` stop process sampling.
* Updated [Forward your logs using the infrastructure agent](/docs/logs/forward-logs/forward-your-logs-using-infrastructure-agent/) to list Debian 12 and 13 and Windows Server 2025, and remove Debian 11.
* Updated [Errors inbox in APM](/docs/apm/errors-inbox/errors-inbox-ui/) and [Errors inbox external services](/docs/triage-inbox/error-external-services/) to explain that an unresolved error group sends a new Slack notification if the error recurs after 14 days.
* Updated [Azure Monitor integration](/docs/infrastructure/microsoft-azure-integrations/azure-integrations-list/azure-monitor/) to explain that dimensional metric types depend on the data Azure returns, such as `summary`, `gauge`, or `count`.
* Updated [Get started with collector observability](/docs/opentelemetry/collector-observability/collector-observability-setup/) to set `INTERNAL_TELEMETRY_TRACE_LEVEL=basic` when you experiment with collector traces.
* Updated [Database service identification with NRDOT](/docs/opentelemetry/db360/capabilities/db-apm/) to require .NET agent v10.54.0 or higher.
* Updated [Set up connectors](/docs/new-relic-lens/set-up-connectors/) to reflect that connector names now use an underscore prefix (`nrlens_`) instead of a hyphen (`nrlens-`).
* Updated [Usage plan](/docs/licenses/license-information/usage-plans/new-relic-usage-plan/) with an Advantage Plan section and its pay-as-you-go (PAYG) conversion table.
* Updated [Report security vulnerabilities](/docs/security/security-privacy/information-security/report-security-vulnerabilities/) with a section on vulnerability reports and CVE impact.
* Updated [Forward logs from Google Cloud Platform](/docs/logs/forward-logs/google-cloud-platform-log-forwarding/) to use `PubSubToNewRelic` as the correct Dataflow template name.
* Updated the [Node.js agent](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent/) and [.NET agent](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements/) compatibility and requirements pages with the latest verified library versions.
* Updated [Compatibility and requirements for AI monitoring](/docs/ai-monitoring/compatibility-requirements-ai-monitoring/) and [Instrumented Python packages](/docs/apm/agents/python-agent/getting-started/instrumented-python-packages/) with Microsoft Agent Framework and CrewAI.
* Updated [Google VertexAI monitoring integration](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-vertexai-monitoring-integration/) to list Publisher Model as a Vertex AI entity.
