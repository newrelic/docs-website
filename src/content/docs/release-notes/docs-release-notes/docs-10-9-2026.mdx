### New docs

* Added [Configure sampling](/docs/apm/distributed-tracing/distributed-trace-sampling/), covering APM agent sampler contexts, sampler types, and adaptive sampling targets.
* Added [Sampler configuration examples](/docs/apm/distributed-tracing/sampler-configuration-examples/), a companion page with real-world, copy-paste-ready configurations for fixing uneven endpoint coverage and upstream-sampling imbalances.
* Added [Permissions and roles](/docs/cci/configure-cci/cci-permissions/) for Cloud Cost Intelligence, covering default read-only access and how Organization Admins grant modify access through existing or dedicated custom roles.

### Major changes

* Renamed and restructured OpenTelemetry database monitoring docs from "Database monitoring" to [Database 360 (DB360)](/docs/opentelemetry/db360/introduction/), and added CLI, Ansible, Chef, Helm, and Docker install-method pages for MSSQL, MySQL, Oracle, and PostgreSQL, including a new UiPath-related install flow under the MSSQL and MySQL sections.
* Renamed [Errors inbox](/docs/triage-inbox/errors-inbox/) and its related pages to **Triage inbox**, and updated cross-references to the old errors-inbox paths across APM, browser, and mobile docs.
* Restructured Node.js agent pages, including [Introduction to New Relic for Node.js](/docs/apm/agents/nodejs-agent/getting-started/introduction-new-relic-nodejs/), Heroku and Azure hosting, source maps, ES modules, Docker install, update, and troubleshooting, for clarity and consistency.
* [Scheduled NRQL search and reporting](/docs/nrql/using-nrql/schedule-nrql-searches/) is now generally available. Updated the doc with permissions, scheduling, and management details, and linked it from [Use the Logs UI](/docs/logs/ui-data/use-logs-ui/).
* [Intelligent Workloads](/docs/new-relic-solutions/new-relic-one/workloads/create-intelligent-workload/) is now generally available. Added bulk workload creation from recommendations and exclude filters to scope dependency graphs.
* Refreshed the Summary page content and screenshots across [Standard Workloads](/docs/new-relic-solutions/new-relic-one/workloads/use-workloads/), Intelligent Workloads, and the Transaction 360 doc, including a new section on graduating a Transaction 360 view into an Intelligent Workload.
* Updated [How New Relic distributed tracing works](/docs/distributed-tracing/concepts/how-new-relic-distributed-tracing-works/), the distributed tracing planning guide to reflect that mobile agents (Android v7.8.3+ and iOS v7.7.8+) now send only W3C trace context headers and no longer send the legacy proprietary `newrelic` header.

### Minor changes

* Added a limitation note to [Compound alerts](/docs/alerts/create-alert/create-alert-condition/compound-alerts/compound-alerts/).
* Added a `time_zone` query parameter to the [Public dashboards doc](/docs/query-your-data/explore-query-data/dashboards/share-dashboards-publicly/) for pinning a fixed IANA (Internet Assigned Numbers Authority) time zone identifier on public dashboard live URLs, so timestamps and relative time ranges display consistently regardless of the viewer's local browser time zone.
* [Dashboard template variables](/docs/query-your-data/explore-query-data/dashboards/dashboard-template-variables/) now support `{{variable}}` placeholders in widget descriptions.
* Added the `DBMonitoring` namespace to [Understand and manage data retention](/docs/data-apis/manage-data/manage-data-retention/).
* Updated [CCI recommendations](/docs/cci/financial-intelligence/cci-recommendations/).
* Added daily-frequency guidance to [Compute budgets: user limits](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/compute-budgets/compute-user-limits/).
* Updated [Advanced maps](/docs/service-architecture-intelligence/maps/advanced-maps/) for AI node relationships.
* Expanded Kerberos capability guidance in [Private location capabilities](/docs/synthetics/synthetic-monitoring/guides/private-location-capabilities/) and [Kerberos (SPNEGO) authentication support for private locations](/docs/synthetics/synthetic-monitoring/private-locations/synthetics-kerberos-auth-support/).
* Fixed a [.NET agent AppDomain caching troubleshooting](/docs/apm/agents/net-agent/troubleshooting/lock-contention-appdomain-getdata/) doc.
* Updated Flutter and .NET MAUI crash-handling guidance in [Handled exceptions](/docs/mobile-monitoring/mobile-monitoring-ui/crashes/handled-exceptions-analyze-trends-prevent-crashes/), [Monitor your Flutter application](/docs/mobile-monitoring/new-relic-mobile-flutter/monitor-your-flutter-application/), and [Monitor your .NET MAUI application](/docs/mobile-monitoring/new-relic-mobile-maui-dotnet/monitor-your-net-maui-application/).
* Refreshed [Node.js agent compatibility and requirements](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent/) and [.NET agent compatibility and requirements](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements/).
* Fixed the [AWS Lambda SDK-based instrumentation](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/sdk-based-instrumentation/) doc.
* Updated the [Kubernetes summary page](/docs/apm/apm-ui-pages/monitoring/kubernetes-summary-page/) for cell severity.

### What's new

* [Scheduled Search and Reporting is now generally available](/whats-new/2026/10/whats-new-10-05-scheduled-search-reporting-ga): Run NRQL queries on your own schedule and get notified when the results meet a condition you define.
* [Manage New Relic Notebooks with Terraform](/whats-new/2026/10/whats-new-10-06-notebooks-terraform): Define, manage, and provision New Relic Notebooks using Terraform, with full CRUD support and programmatic access.
* [Updates to Intelligent Workloads and Standard Workloads](/whats-new/2026/10/whats-new-10-08-Workloads-GA): Intelligent Workloads reaches GA with bulk creation and exclude filters, and Standard Workloads gets a matching summary page and support for alert-based health configuration.
* [Performance Risks Inbox is now generally available](/whats-new/2026/10/whats-new-10-08-performance-risks-inbox): Performance Risks Inbox GA adds an account-level overview, Workloads support, AI-generated insights, and New Relic MCP server support.
* [Top-level navigation label "Errors Inbox" is now "Triage Inbox"](/whats-new/2026/10/whats-new-10-08-triage-inbox-nav-label): The main navigation entry for Errors Inbox is renamed to Triage Inbox (Errors Inbox), a label-only change with no new pages or features.

### EOLs

* [Deprecation Notice: Kubernetes 1.31 and earlier](/eol/2026/10/k8s-deprecation-notice-v1.31-and-lower): Effective October 5, 2026, the Kubernetes integration v4.8.0 and later is compatible only with Kubernetes v1.32 and later.
* [Kubernetes Supported Version Changes](/eol/2026/10/k8s-supported-version-changes): Effective October 19, 2026, the Kubernetes integration supports only the three most recent minor versions of Kubernetes.
