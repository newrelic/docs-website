### New docs

* Added [Limitations for Streaming Video & Ads](/docs/streaming-video-&-ads/limitations) to consolidate known limitations, unsupported behaviors, and constraints across the Streaming Video & Ads feature set.
* Added [AWS EventBridge action](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/aws-eventbridge) to the Workflow Automation actions catalog for publishing events to Amazon EventBridge.
* Added [New Relic service level action](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/newrelic-service-level) to the Workflow Automation actions catalog for creating and managing service level objectives from a workflow.

### Major changes

* Updated [Create Intelligent Workloads](/docs/new-relic-solutions/new-relic-one/workloads/create-intelligent-workload) with bulk creation from recommendations, an exclude filters section, and a new prerequisites section for enabling distributed tracing.
* Expanded [AWS SQS action](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/aws-sqs) in the Workflow Automation actions catalog with additional configuration options and expanded reference content.
* Restructured [NRQL for CCI financial intelligence](/docs/cci/financial-intelligence/nrql-for-cci) with streamlined query examples and simplified explanations.
* Updated [Introduction to NRQL, New Relic's query language](/docs/query-your-data/nrql-new-relic-query-language/get-started/introduction-nrql-new-relics-query-language), [Query entities and relationships via NRQL](/docs/query-your-data/nrql-new-relic-query-language/get-started/query-entities-and-relationships-via-nrql), [NRQL tutorial: Advanced dashboarding](/docs/query-your-data/nrql-new-relic-query-language/get-started/nrql-tutorial-advanced-dashboarding), and [NRQL tutorial: Process your data](/docs/query-your-data/nrql-new-relic-query-language/get-started/nrql-tutorial-process-your-data) with refreshed screenshots and revised explanations.
* Reverted recently added Private Service Connect and Service Attachment entity documentation from [Google Compute Engine monitoring integration](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-compute-engine-monitoring-integration).
* Added an Oracle Kubernetes Engine (OKE) entry and MariaDB/Aurora MySQL support to [eBPF requirements](/docs/ebpf/requirements).
* Added `agentMetadataReporting` and GenAI monitoring configuration parameters to [eBPF Kubernetes installation](/docs/ebpf/k8s-installation) and [eBPF Linux installation](/docs/ebpf/linux-installation).
* Updated the Grafana dashboard translation endpoint URLs in [View and query Prometheus data in Grafana](/docs/infrastructure/prometheus-integrations/view-query-data/grafana).
* Fixed the NRDOT Collector configuration path update command in the MySQL and PostgreSQL hosted and RDS monitoring docs, which previously didn't correctly update the collector's startup configuration.
* Updated [Agent types](/docs/new-relic-control/agent-control/agent-types) and [Mirror setup](/docs/new-relic-control/agent-control/mirror-setup) with signature verification requirements for OCI mirrors and agent type definitions, and removed the unsupported option to disable signature verification.
* Updated [Install the Java agent with Java 2 security](/docs/apm/agents/java-agent/additional-installation/install-java-agent-java-2-security) with required permissions for Java 9+ environments to prevent access denied errors.
* Updated [MCP overview](/docs/agentic-ai/mcp/overview) and [Set up New Relic MCP](/docs/agentic-ai/mcp/setup) with corrected OAuth scopes and API key casing that were previously causing failed MCP connections, and a simplified VS Code configuration example.
* Updated [Kubernetes integration installation: agent operator](/docs/kubernetes-pixie/kubernetes-integration/installation/k8s-agent-operator) to confirm Kubernetes APM auto-attach support on EKS Fargate nodes, reversing previous guidance that it hadn't been tested.

### Minor changes

* Added a callout to [Connect GCP Workload Identity Federation](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation) clarifying that pool and provider names are customizable suggestions.
* Updated database query performance descriptions in [Monitor Microsoft SQL Server with the CNCF collector](/docs/opentelemetry/database/mssql/cncf).
* Updated [Introduction to Workflow Automation](/docs/workflow-automation/introduction-to-workflow) navigation link.
* Added a callout for GCP migration tooling to [Introduction to Google Cloud Platform integrations](/docs/infrastructure/google-cloud-platform-integrations/get-started/introduction-google-cloud-platform-integrations).
* Updated Jira actions in the Workflow Automation actions catalog with minor formatting fixes to example descriptions.

### What's new

* [Tag-based grouping, custom columns, and column reordering in Catalogs](/whats-new/2026/09/whats-new-09-07-catalogs-tag-grouping) - You can now group entities and add columns using any tag, New Relic-defined or custom, and reorder them to match your workflow, with your layout saved automatically.
