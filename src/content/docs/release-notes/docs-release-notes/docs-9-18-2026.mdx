### New docs

* Added [Configure the React Native agent for EAS Build](/docs/mobile-monitoring/new-relic-monitoring-react-native/configure-eas-build-react-native) to provide guidance on automatic source map, dSYM, and mapping-file uploads when building with EAS Build.
* Added [AWS Auto Scaling actions](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/aws-autoscaling) to the Workflow Automation actions catalog, covering actions for managing instances, desired capacity, instance refresh, and scheduled actions.

### Major changes

* Renamed [New Relic Ground Truth](/docs/agentic-ai/mcp/overview) (formerly New Relic AI MCP) for general availability and moved setup to OAuth only.
* Updated [New Relic Lens overview](/docs/new-relic-lens/overview), [Set up connectors](/docs/new-relic-lens/set-up-connectors), [Query data with Lens](/docs/new-relic-lens/query-data), and [Materialized views](/docs/new-relic-lens/materialized-views) for general availability.
* Updated [Managing configurations](/docs/new-relic-control/agent-control/configuration) with a new value providers system, and [troubleshoot common issues](/docs/new-relic-control/agent-control/troubleshooting) with corrected config names and a new NRDiag troubleshooting section.
* Updated the AWS action pages in the [Actions catalog](/docs/workflow-automation/setup-and-configure/actions-catalog/actions-catalog) with a consistent format, new AWS Bedrock actions, and three new Lambda actions.
* Restructured [New Relic notification actions](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/newrelic-notification) to add a `DASHBOARD_SNAPSHOT` attachment type for sending dashboard snapshots through workflow notifications.
* Fixed a broken response-parsing selector and added a troubleshooting section to [Alert RCA with Autopilot and Slack](/docs/workflow-automation/workflow-examples/integrations/autopilot-slack-rca).
* Added a legend control and a "Visualize relationships" section, and converted node and icon reference tables to tile grids, in [Understand and use Maps](/docs/service-architecture-intelligence/maps/advanced-maps).
* Added a Kafka metrics configuration section to [.NET agent configuration](/docs/apm/agents/net-agent/configuration/net-agent-configuration).
* Added a section on tracking changes across your estate to [How to view and analyze your changes in New Relic](/docs/change-tracking/view-analyze-data) and restructured [Track changes using NerdGraph](/docs/change-tracking/config/nerdgraph) to help users migrate off the deprecated REST API v2 and v0 deployment endpoints.
* Reintroduced Service Attachment and Private Service Connect Endpoint entity types with new key-metrics tables in [Google Compute Engine monitoring integration](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-compute-engine-monitoring-integration).

### What's new

* [New Relic Ground Truth is now generally available](/whats-new/2026/09/whats-new-09-15-ground-truth): Ground Truth gives AI tools and agents governed access to New Relic operational intelligence through MCP, helping them reason from richer operational context with the controls enterprises require.
* [New Relic Lens is now generally available](/whats-new/2026/09/whats-new-09-15-nr-lens-ga): Lens lets you connect and query external data sources like Snowflake, Iceberg, and Google Sheets alongside your telemetry using SQL, without paying for extra data ingestion.
