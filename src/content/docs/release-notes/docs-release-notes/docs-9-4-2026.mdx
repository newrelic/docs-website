### New docs

* Added [Triage vulnerability remediation with the Security RX Agent](/docs/vulnerability-management/agent/overview) to provide guidance on using the Security RX Agent (public preview) to analyze CVEs, generate remediation plans, and trigger coding agents to open pull requests.
* Added [Security RX Jira workflow](/docs/vulnerability-management/workflows/jira) to provide step-by-step instructions for automatically creating and syncing Jira tickets for security vulnerabilities detected by Security RX.
* Added [Troubleshoot New Relic MCP](/docs/agentic-ai/mcp/troubleshoot) to provide common troubleshooting steps and solutions for resolving MCP server setup and configuration issues.

### Major changes

* Restructured [Microsoft SQL Server monitoring with NRDOT](/docs/opentelemetry/database/mssql/introduction) with a new comprehensive configuration reference, a new CNCF collector setup guide, and overhauled installation docs for Windows-hosted, Windows RDS, Linux-hosted, and Linux RDS environments.
* Updated [Agent types](/docs/new-relic-control/agent-control/agent-types) with extensive revisions to existing agent documentation and added Fluent Bit as a supported Agent Control agent type with full configuration guidance.
* Updated [Manage fleets](/docs/new-relic-control/fleet-control/manage-fleets) with comprehensive documentation for the new configuration approval workflow in Fleet Control.
* Updated [Workflow Automation definition schema](/docs/workflow-automation/workflow-automation-apis/definition-schema) with the new State Step action, and updated [workflow limits](/docs/workflow-automation/limitations-and-faq/workflow-limits) and [execution monitoring](/docs/workflow-automation/manage-workflows/monitor-workflow-execution) accordingly.

### Minor changes

* Updated [Set up New Relic MCP](/docs/agentic-ai/mcp/setup) with revised setup steps and configuration guidance for the September Hydra deployment.
* Added OTLP endpoint and `nrExporterEndpoints` configuration block documentation to [Gateway YAML configuration reference](/docs/new-relic-control/pipeline-control/gateway/yaml-overview).
* Added VMware vSphere Kubernetes Service (VKS) to [Kubernetes integration compatibility requirements](/docs/kubernetes-pixie/kubernetes-integration/get-started/kubernetes-integration-compatibility-requirements).
* Updated [Node.js agent configuration](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration) with new Google Cloud Run (GCR) environment configuration options.
* Updated [Trace API troubleshooting](/docs/apm/distributed-tracing/trace-api/troubleshooting-missing-trace-api-data) and [missing trace data](/docs/distributed-tracing/troubleshooting/missing-trace-data) with corrected oldest span timestamp limits for OTLP and Trace API.
* Added a cardinality warnings section to [Manage cardinality](/docs/data-apis/ingest-apis/metric-api/cardinality-management).
* Added the Direct to Live Archive partition option to [Live archives](/docs/logs/get-started/live-archives) and [data partitions](/docs/logs/ui-data/data-partitions).
* Updated [.NET agent compatibility requirements](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements) with the latest supported library versions.
* Fixed a 403 status error in [React Native JavaScript error reporting](/docs/mobile-monitoring/new-relic-monitoring-react-native/react-native-agent-js-error-reporting).
* Fixed code block formatting in [VMware Tanzu service broker integration](/docs/infrastructure/other-infrastructure-integrations/vmware-tanzu-service-broker-integration) and [StatsD integration](/docs/more-integrations/open-source-telemetry-integrations/statsd/statsd-monitoring-integration).
* Fixed NRQL code block formatting in [dbt Cloud integration](/docs/more-integrations/open-source-telemetry-integrations/dbt/dbt-cloud-integration).
* Updated [Catalogs](/docs/service-architecture-intelligence/catalogs/catalogs) with an improved personalize view table.
