### New docs

* Added [Set up connectors for New Relic Lens](/docs/new-relic-lens/set-up-connectors) to guide you through connecting data sources to New Relic Lens.
* Added [Connect Autopilot to GitHub](/docs/agentic-ai/autopilot/connect-to-github), [Use Autopilot with GitHub](/docs/agentic-ai/autopilot/use-autopilot-with-github), and [Troubleshoot the GitHub connection](/docs/agentic-ai/autopilot/troubleshoot-github-connection) to cover the new public preview integration that lets Autopilot pull Pull Request context from Change Tracking deployments during investigations.
* Added [Jira issue actions](/docs/workflow-automation/setup-and-configure/actions-catalog/jira/jira-issue) to the workflow automation actions catalog, covering create, update, search, and transition actions for Jira Cloud issues.
* Added [Ansible job actions](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job-launch) to the workflow automation actions catalog for launching and checking the status of Ansible Automation Platform job templates.
* Added [Run Autopilot action](/docs/workflow-automation/setup-and-configure/actions-catalog/autopilot/newrelic-autopilot) to provide a dedicated actions catalog reference for running Autopilot investigations from a workflow.
* Added [Alert RCA with Autopilot and Slack](/docs/workflow-automation/workflow-examples/integrations/autopilot-slack-rca) to show how to trigger an Autopilot root cause analysis from an alert and post the findings to Slack.
* Added [Unit economics](/docs/cci/financial-intelligence/unit-economics) to Cloud Cost Intelligence to explain how to measure the cost of delivering a single unit of value, such as cost per query, and track efficiency against a benchmark.
* Added [Use cross account destinations in the UI](/docs/apis/nerdgraph/examples/cross-account-destinations/use-cross-account-destinations-in-the-ui) to show where cross-account destinations appear in the New Relic UI and how to use them in workflows.

### Major changes

* Updated [Infrastructure agent configuration settings](/docs/infrastructure/infrastructure-agent/configuration/infrastructure-agent-configuration-settings) with new `safe_bin_dir`, `agent_temp_dir`, and logging directory settings ahead of Agent Control general availability.
* Updated [.NET agent configuration](/docs/apm/agents/net-agent/configuration/net-agent-configuration) with the new `sqlMetadataCommentsEnabled` option, which lets the agent add a service entity GUID comment to instrumented SQL statements for correlating APM data with query performance monitoring.
* Restructured [Introduction to notebooks](/docs/query-your-data/explore-query-data/notebooks/introduction-notebooks) to describe the new fine-grained access model, including organization-level roles (Full access, Creator) and notebook-level roles (Owner, Editor, Reader).
* Updated [Cloud Cost Intelligence: Recommendations](/docs/cci/financial-intelligence/cci-recommendations) to extend the native optimization engine's right-sizing recommendations to Azure resources, and added guidance on telemetry coverage prerequisites and recommendation refresh cadence.
* Restructured [Chart types](/docs/query-your-data/explore-query-data/use-charts/chart-types) with a new simplified bar chart section for ranking series against the largest one, and added a Neutral threshold option for gauge charts.
* Updated [Workload health status configuration](/docs/new-relic-solutions/new-relic-one/workloads/workload-status-configuration) with guidance on the effects of switching setup methods, including health status delay and automatic unlinking and re-linking of alert conditions.

### Minor changes

* Added a Windows support limitation callout to the [MongoDB integration install guide](/install/mongodb/), noting that Percona froze the bundled exporter at its current version because it stopped publishing Windows binaries.
* Updated [Classloading issues from JBoss and WildFly](/docs/apm/agents/java-agent/troubleshooting/classloading-issues-from-jboss-and-wildfly) with a new troubleshooting section for startup failures caused by JBoss's logmanager.
* Updated [Networks](/docs/new-relic-solutions/get-started/networks) with additional dualstack data ingest IP blocks for the US and EU data centers.
* Updated [Third-party instrumentation](/docs/apm/agents/ruby-agent/api-guides/third-party-instrumentation) for the Ruby agent to clarify how to contribute new gem instrumentation and note that `extends_newrelic_rpm` is now archived.
* Updated [FedRAMP](/docs/security/security-privacy/compliance/certificates-standards-regulations/fedramp) to reflect the new FedRAMP Class C (Moderate) certification status and updated the reference to Autopilot's former SRE Agent name.
* Updated [Data encryption](/docs/security/security-privacy/compliance/data-encryption) to reflect the move from FIPS 140-2 to FIPS 140-3 compliant encryption standards.
* Updated [Start a workflow run](/docs/workflow-automation/workflow-automation-apis/start-workflow-run) with a new `idempotencyKey` input, and clarified UUID format validation for `idempotencyKey` across the Azure and New Relic notification actions in the [actions catalog](/docs/workflow-automation/setup-and-configure/actions-catalog/actions-catalog).
* Fixed [Infrastructure agent security](/docs/infrastructure/infrastructure-agent/infrastructure-security) to document Windows service account requirements, including Group Managed Service Account (gMSA) support.
* Updated [Choose your data center](/docs/accounts/accounts-billing/account-setup/choose-your-data-center) to clarify that the US region is the default.
* Fixed [Create NRQL alert conditions](/docs/alerts/create-alert/create-alert-condition/create-nrql-alert-conditions) to update the outdated signal loss and gap filling support link.
* Updated [Azure Native New Relic Service](/docs/infrastructure/microsoft-azure-integrations/get-started/azure-native) with the current Azure Marketplace listing URL and removed the outdated HIPAA availability note.
* Updated [Kubernetes integration compatibility and requirements](/docs/kubernetes-pixie/kubernetes-integration/get-started/kubernetes-integration-compatibility-requirements) to reflect supported Kubernetes versions 1.31 to 1.35.
* Fixed [NRQL syntax, clauses, and functions](/docs/nrql/nrql-syntax-clauses-functions) to correct the default Apdex score to 0.4 seconds.
* Fixed broken navigation entries across the Alerts, APM, Dashboards, Infrastructure, Mobile monitoring, Serverless function monitoring, and Telemetry data platform docs by restoring 42 previously orphaned pages to site navigation.
* Simplified [Intelligent workload UI](/docs/new-relic-solutions/new-relic-one/workloads/intelligent-workload-ui) by removing an outdated screenshot and redundant KPI tile guidance.
