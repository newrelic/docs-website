### New docs

* Added [Oracle Cloud Infrastructure (OCI) monitoring](/docs/infrastructure/oci/introduction/) to provide an overview of monitoring OCI metrics and logs with New Relic.
* Added [Infrastructure 360](/docs/infrastructure/infrastructure-360/introduction-infrastructure-360/) to help you automatically discover your cloud infrastructure, map relationships between resources, and track configuration changes, covering setup for AWS and Azure, supported entities and requirements, and troubleshooting.
* Added [NRQL macros](/docs/nrql/nrql-macros/nrql-macros-overview/) to show you how to save a NRQL expression as a reusable, named shortcut and reference it in queries with the `$` symbol.
* Added [Monitor deployments with New Relic Change Tracking for GitHub Copilot](/docs/agentic-ai/autopilot/change-tracking-for-github-copilot/) to show you how to monitor each deployment and get regressions reported in Slack and GitHub.
* Added [Symbolicate Flutter Dart errors](/docs/mobile-monitoring/new-relic-mobile-flutter/symbolicate-dart-errors/) and [Symbolicate .NET MAUI C# errors](/docs/mobile-monitoring/new-relic-mobile-maui-dotnet/symbolicate-csharp-errors/) to explain how to generate symbol files, symbolicate stack traces, and store symbols for each release.
* Added [LaunchDarkly with the Python agent](/docs/apm/agents/python-agent/supported-features/launchdarkly-release-observability/) to show you how to observe how feature flags and releases affect your application by connecting LaunchDarkly data to the Python agent.
* Added actions to the [workflow automation actions catalog](/docs/workflow-automation/setup-and-configure/actions-catalog/actions-catalog/) for [AWS Athena](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/athena/aws-athena/), [AWS DynamoDB](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/dynamodb/aws-dynamodb/), [Azure App Service](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-appservice/), [GitHub workflow runs](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run/), [New Relic secrets](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/secret/newrelic-secret/), and [New Relic Synthetics](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/synthetics/newrelic-synthetics/), and added a [Wait for notification status](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/notification/newrelic-notification-waitforstatus/) action.
* Added [Security bulletin NR26-11](/docs/security/new-relic-security/security-bulletins/security-bulletin-nr26-11/) with procedures for addressing critical Node.js vulnerabilities, including remote code execution (CVE-2026-111497), affecting Synthetic Monitoring public and private locations.

### Major changes

* Updated the [MCP tool reference](/docs/agentic-ai/mcp/tool-reference/) with a gap analysis section for the `analyze_github_newrelic_gaps` tool, which checks your project for missing New Relic instrumentation.
* Updated [Use Autopilot with GitHub](/docs/agentic-ai/autopilot/use-autopilot-with-github/) with a new section on how Autopilot flags open hotfixes and pull requests opened during an incident window, and how it reconciles release versions.
* Updated [Configure entity ownership](/docs/service-architecture-intelligence/teams/team-ownership/) for Service architecture intelligence with the list of entity types, by domain and type, that New Relic assigns to teams automatically through tag-based ownership.
* Updated [Network traffic](/docs/new-relic-solutions/get-started/networks/) with the Docker Hub registry domains that on-host Agent Control uses to download agent packages from an OCI registry, and changed the listed collector domain to `collector.newrelic.com`.
* Updated [Schedule NRQL searches](/docs/nrql/using-nrql/schedule-nrql-searches/) with the Applied Intelligence Destinations Read and Modify capabilities that you need to select or create an email destination.
* Updated the [Workflow Automation API](/docs/workflow-automation/workflow-automation-apis/using-workflow-automation-api/) reference pages for workflows and schedules with consistent descriptions, parameter tables, and section anchors.
* Updated [Forward your logs using the infrastructure agent](/docs/logs/forward-logs/forward-your-logs-using-infrastructure-agent/) with the `multilineParser` parameter, available with infrastructure agent v1.53.0 or higher, to combine multiline entries such as Java stack traces into a single log record.
* Updated [.NET agent compatibility and requirements](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements/) to list currently supported Windows versions, including Windows Server 2025, and Windows Azure Guest OS Family 5 and higher.
* Updated [Compatibility and requirements for the Node.js agent](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent/) with the latest supported third-party package versions.

### Minor changes

* Updated the [Azure Monitor integration](/docs/infrastructure/microsoft-azure-integrations/azure-integrations-list/azure-monitor/) alert guidance to use the Event timer streaming method instead of an evaluation offset.
* Updated [Alert event attributes](/docs/alerts/create-alert/condition-details/alert-event-attributes/) to explain that the evaluation offset is deprecated in favor of the Delay/timer setting.
* Updated [Kafka integration configuration](/docs/infrastructure/host-integrations/host-integrations-list/kafka/kafka-config/) to explain that changing `CLUSTER_NAME` creates new broker and topic entities, and that APM applications stay linked to the old topics for about a day.
* Updated [Instrument your own Lambda function](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/instrument-your-own/) to add the required `NEW_RELIC_APP_NAME` variable to the example configuration.
* Updated [Lambda extension environment variables](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/env-variables-lambda/) with the serverless mode retry budget setting and the `NEW_RELIC_EXTENSION_SYNCHRONOUS_FLUSH` variable.
* Updated [Java agent approaches for Lambda](/docs/apm/agents/java-agent/getting-started/java-agent-approaches-lambda/) to list the environment variables that you must set.
* Updated [Connect Autopilot to Slack](/docs/agentic-ai/autopilot/connect-to-slack/) to explain that Autopilot accepts messages of up to 1,000 characters.
* Updated [Monitor your Flutter application](/docs/mobile-monitoring/new-relic-mobile-flutter/monitor-your-flutter-application/) and [Monitor your .NET MAUI application](/docs/mobile-monitoring/new-relic-mobile-maui-dotnet/monitor-your-net-maui-application/) to explain that in-browser symbolication applies to handled exceptions only.
* Updated [New Relic API keys](/docs/apis/intro-apis/new-relic-api-keys/) to rename "Default account key" to "Original account key."
* Updated the [eBPF observability installation](/docs/ebpf/linux-installation/) and [pricing and billing](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/new-relic-one-pricing-billing/) docs to rename "eAPM" to "eBPF observability."
* Updated [React Native JavaScript error reporting](/docs/mobile-monitoring/new-relic-monitoring-react-native/react-native-agent-js-error-reporting/) to direct you to New Relic Support to request a higher source map size limit.

### What's new
