### New docs

* Added [Introduction to Oracle Cloud Infrastructure (OCI) monitoring](/docs/infrastructure/oci/introduction/) to provide an overview of monitoring OCI with New Relic, along with guides to [install and configure OCI metrics monitoring](/docs/infrastructure/oci/install-metrics/), [install and configure OCI metrics and logs monitoring](/docs/infrastructure/oci/install-metrics-and-logs/), reference [OCI metrics](/docs/infrastructure/oci/metrics-reference/), [troubleshoot the OCI integration](/docs/infrastructure/oci/troubleshoot/), and [uninstall the OCI integration](/docs/infrastructure/oci/uninstall/).
* Added [Install and configure OCI log forwarding](/docs/logs/forward-logs/oci-log-forwarding/) and [Monitor your OCI log forwarder](/docs/logs/forward-logs/oci-log-forwarder-observability/) to show you how to send OCI logs to New Relic and keep track of the forwarder's health.
* Added [Introduction to Infrastructure 360](/docs/infrastructure/infrastructure-360/introduction-infrastructure-360/) to explain Infrastructure 360, with setup guides for [AWS](/docs/infrastructure/infrastructure-360/aws/onboarding-infrastructure-360-aws/) and [Azure](/docs/infrastructure/infrastructure-360/azure/onboarding-infrastructure-360-azure/), the [AWS requirements and supported entities](/docs/infrastructure/infrastructure-360/aws/prerequisites-infrastructure-360-aws/), and [Azure troubleshooting](/docs/infrastructure/infrastructure-360/azure/troubleshoot-infrastructure-360-azure/).
* Added [NRQL macros](/docs/nrql/nrql-macros/nrql-macros-overview/) and [Create and manage NRQL macros](/docs/nrql/nrql-macros/create-manage-nrql-macros/) to show you how to save a NRQL expression as a reusable, named shortcut and reference it in queries with the `$` symbol.
* Added [Monitor deployments with New Relic Change Tracking for GitHub Copilot](/docs/agentic-ai/autopilot/change-tracking-for-github-copilot/) to show you how to monitor each deployment and get regressions reported in Slack and GitHub.
* Added [Symbolicate Flutter Dart errors](/docs/mobile-monitoring/new-relic-mobile-flutter/symbolicate-dart-errors/) and [Symbolicate .NET MAUI C# errors](/docs/mobile-monitoring/new-relic-mobile-maui-dotnet/symbolicate-csharp-errors/) to explain how to generate symbol files, symbolicate stack traces, and store symbols for each release.
* Added [Integrate LaunchDarkly with the Python agent](/docs/apm/agents/python-agent/supported-features/launchdarkly-release-observability/) to show you how to connect LaunchDarkly feature flag data to your Python agent.
* Added new actions to the [workflow automation actions catalog](/docs/workflow-automation/setup-and-configure/actions-catalog/actions-catalog/):
  * [AWS Athena actions](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/athena/aws-athena/) and [AWS DynamoDB actions](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/dynamodb/aws-dynamodb/).
  * [Azure App Service actions](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-appservice/), including get, list, start, and stop.
  * [GitHub workflow run actions](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run/), including trigger, get, list, and get latest.
  * [Wait for notification status](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/notification/newrelic-notification-waitforstatus/), [New Relic secret actions](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/secret/newrelic-secret/), and [New Relic Synthetics actions](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/synthetics/newrelic-synthetics/).
* Added [NR26-11: Node.js Critical Security Vulnerabilities Including Remote Code Execution](/docs/security/new-relic-security/security-bulletins/security-bulletin-nr26-11/) to describe the procedures for addressing critical Node.js vulnerabilities that affect Synthetic monitoring public and private locations.

### Major changes

* Updated the [MCP tool reference](/docs/agentic-ai/mcp/tool-reference/) with a new gap analysis section for the `analyze_github_newrelic_gaps` tool, which checks your project for missing New Relic config file, APM agent, Browser agent, and Change Tracking instrumentation, and added the `gap-analysis` and `monitoring-analysis` filter tags.
* Updated [Use Autopilot with GitHub](/docs/agentic-ai/autopilot/use-autopilot-with-github/) with a new "Check for in-flight fixes" section that explains how Autopilot flags open hotfixes and pull requests opened during an incident window, and how it reconciles release versions.
* Updated [Team ownership](/docs/service-architecture-intelligence/teams/team-ownership/) with a list of the entity types that receive automated ownership, identified by domain and type.
* Updated [Network traffic](/docs/new-relic-solutions/get-started/networks/) with a new section listing the Docker Hub registry domains that on-host Agent Control uses to download agent packages from an OCI registry, and changed the listed collector domain to `collector.newrelic.com`.
* Updated [Schedule NRQL searches](/docs/nrql/using-nrql/schedule-nrql-searches/) to replace the Workflow Schedules permission with the Applied Intelligence Destinations Read and Modify capabilities that you need to select or create an email destination.
* Updated the [Workflow automation API](/docs/workflow-automation/workflow-automation-apis/using-workflow-automation-api/) reference pages, including the create, update, delete, get, and signal operations for workflows and schedules, with consistent descriptions, parameter tables, and section anchors.
* Updated [Infrastructure agent log forwarding](/docs/logs/forward-logs/forward-your-logs-using-infrastructure-agent/) with the `multilineParser` parameter, available with infrastructure agent version 1.53.0 or higher, to combine multiline entries such as Java stack traces into a single log record.
* Updated [.NET agent compatibility and requirements](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements/) to replace the hard-coded Windows list with currently supported Windows versions, including Windows Server 2025, and to state Guest OS Family 5+ for Windows Azure.
* Updated [Compatibility and requirements for the Node.js agent](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent/) with the latest supported third-party package versions.

* Updated [Lambda extension environment variables](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/env-variables-lambda/) with the serverless-mode retry budget setting and the `NEW_RELIC_EXTENSION_SYNCHRONOUS_FLUSH` variable.
* Updated [Java agent approaches for Lambda](/docs/apm/agents/java-agent/getting-started/java-agent-approaches-lambda/) to list the environment variables that you must set instead of layer defaults.
* Updated the [Autopilot Slack connection](/docs/agentic-ai/autopilot/connect-to-slack/) guide to note that Autopilot accepts messages of up to 1,000 characters.
* Updated [Autopilot compute limits](/docs/agentic-ai/autopilot/autopilot-compute-limits/) to simplify the permissions table.
* Updated [Introduction to Workflow Automation](/docs/workflow-automation/introduction-to-workflow/) to refer to Advanced Compute using advanced CCU.
* Updated [Introduction to NRQL](/docs/nrql/get-started/introduction-nrql-how-nrql-works/) and [NRQL syntax, clauses, and functions](/docs/nrql/nrql-syntax-clauses-functions/) to point to the new NRQL macros docs.
* Updated [Monitor your Flutter application](/docs/mobile-monitoring/new-relic-mobile-flutter/monitor-your-flutter-application/) and [Monitor your .NET MAUI application](/docs/mobile-monitoring/new-relic-mobile-maui-dotnet/monitor-your-net-maui-application/) to clarify that in-browser symbolication applies to handled exceptions only.
* Updated [New Relic API keys](/docs/apis/intro-apis/new-relic-api-keys/) to rename "Default account key" to "Original account key."
* Updated [eBPF observability](/docs/ebpf/linux-installation/) docs and [pricing and billing](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/new-relic-one-pricing-billing/) to replace the "eAPM" name with "eBPF observability."
* Updated [React Native JavaScript error reporting](/docs/mobile-monitoring/new-relic-monitoring-react-native/react-native-agent-js-error-reporting/) to point to New Relic Support for raising the 200 MB source map limit.
* Removed the Infinite Tracing activation callout from [Introduction to Infinite Tracing](/docs/distributed-tracing/infinite-tracing/introduction-infinite-tracing/).
* Removed the outdated Software Development Lifecycle page and its reference in the [Security policy](/docs/licenses/license-information/referenced-policies/security-policy/).
* Added [NR26-11](/docs/security/security-privacy/information-security/security-bulletins/) to the security bulletins list.
* Fixed a typo in the proxy description of the [Python agent configuration](/docs/apm/agents/python-agent/configuration/python-agent-configuration/).
