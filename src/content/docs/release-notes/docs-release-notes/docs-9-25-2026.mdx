### New docs

* Added [HAProxy distributed tracing](/docs/opentelemetry/integrations/haproxy/distributed-tracing/) to cover the HAProxy OTel filter setup for distributed tracing and service relationships.
* Added [NGINX distributed tracing](/docs/opentelemetry/integrations/nginx/nginx-otel-distributed-tracing/), covering OTel-based distributed tracing setup for NGINX using `ngx_otel_module`.
* Added [Linkerd monitoring via OpenTelemetry](/docs/opentelemetry/integrations/linkerd/introduction/), covering overview, Kubernetes setup, distributed tracing, and a full metrics reference.
* Added [APM ↔ Elasticsearch distributed tracing correlation](/docs/opentelemetry/integrations/elasticsearch/distributed-tracing/), a more seamless alternative to hardcoding `es.cluster.name`.
* Added a [multi-receiver configuration](/docs/opentelemetry/database/mssql/multi-receiver/) guide for MSSQL monitoring via OpenTelemetry.
* Added the [AWS Step Function action](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/stepfunctions/aws-stepfunctions/) to the Workflow Automation actions catalog.

### Major changes

* Rewrote the [Distributed tracing UI data](/docs/distributed-tracing/ui-data/understand-use-distributed-tracing-ui/) page to match the redesigned trace list interface, including the new inline filter pills and toggles.
* Restructured the [Oracle DB monitoring via OpenTelemetry](/docs/opentelemetry/database/oracle/introduction/) docs.
* Reorganized the [Workflow Automation actions catalog](/docs/workflow-automation/setup-and-configure/actions-catalog/actions-catalog/) into per-action pages and added the New Relic Alerts action.
* Updated 12 pages across NRQL, query builder, and NerdGraph docs to state the explicit cross-account query limit increase from 5 to 30 accounts.
* Updated [Compound alerts](/docs/alerts/create-alert/create-alert-condition/compound-alerts/compound-alerts/) documentation for general availability.
* Added AWS EC2 actions to the [Actions catalog](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/ec2/aws-ec2/).

### Minor changes

* Added a FAQ entry explaining Cloud Cost Intelligence's 48-hour data buffer, and corrected AWS/Azure cost-report delivery time estimates to match, in [Cloud Cost Intelligence FAQ](/docs/cci/faq/).
* Removed outdated real-time cost-estimate information from [Intelligent Summary](/docs/cci/financial-intelligence/intelligent-summary/) and related CCI pricing pages.
* Updated [pricing information](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/new-relic-one-pricing-billing/) to include New Relic Ground Truth.
* Added the NRQL repetitive-query rate limit to [NRQL rate limits](/docs/nrql/using-nrql/rate-limits-nrql-queries/).
* Updated the Synthetics Japan private-link endpoint reference in [AWS PrivateLink](/docs/data-apis/custom-data/aws-privatelink/).
* Updated supported package versions in [Compatibility and requirements for the Node.js agent](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent/).
* Restructured the `{{selfEntity}}` facet-linking guidance in [Filter New Relic dashboards by facets](/docs/query-your-data/explore-query-data/dashboards/filter-new-relic-one-dashboards-facets/) into its own section instead of a Requirements bullet.

### What's new

* [New Relic Compound Alerts brings multiple conditions together for more precise alerting](/whats-new/2026/09/whats-new-09-22-compound-alerts): Combine up to five alert conditions with AND/OR logic to define the exact signal that warrants your team's attention.
* [Now query up to 30 New Relic accounts at once!](/whats-new/2026/09/whats-new-09-22-cross-account-query-limit-30): The max number of accounts you can query at once is increasing from 5 to 30, available through the UI or API.

### Release notes

* Stay up-to-date with our latest releases:

  * [Infrastructure agent v1.80.4](/docs/release-notes/infrastructure-release-notes/infrastructure-agent-release-notes/new-relic-infrastructure-agent-1804):
    * Replaced deprecated `MemoryLimit` with `MemoryMax` for systemd >=231.
    * Added a group filesystem check for temp file ownership.
    * Bumped several dependencies to address multiple CVEs.
  * [Mobile app for Android v5.43.8](/docs/release-notes/mobile-apps-release-notes/new-relic-android-release-notes/new-relic-android-5438):
    * Bug fixes and UI improvements.
  * [Media agent for HLS JS v2.0.0](/docs/release-notes/streaming-browser-release-notes/streaming-browser-agent-hlsjs-26-09-22):
    * Added a `@newrelic/video-hls/browser` subpath export that excludes unused Vega/connected-device code, reducing bundle size.
    * Added `{ HLSTracker }` as a named export alongside the default export.
    * Updated `@newrelic/video-core` to 5.1.0.
  * [Media agent for Video JS v5.0.0](/docs/release-notes/streaming-browser-release-notes/streaming-browser-agent-videojs-26-09-17):
    * Breaking change: adds a `package.json#exports` map — deep imports into internal paths no longer resolve.
    * Added MediaTailor `notifyAdSkipped()`, `stopTracking()`, `AD_ERROR` events, and an `adPrimaryId` attribute for accurate creative counting.
    * Fixed several MediaTailor ad-tracking bugs, including multi-ad pod tracking and quartile events firing more than once per ad.
  * [Media agent for iOS v5.0.0](/docs/release-notes/streaming-mobile-release-notes/streaming-ios-agent-26-09-23):
    * Added `NRTHEOplayerTracker`, a new tracker for THEOplayer (Dolby OptiView Player).
    * Fixed `NRVAVideo.addPlayer()` silently defaulting to an AVPlayer tracker when it couldn't identify the player type.
  * [Media agent for CAF v5.0.0](/docs/release-notes/streaming-browser-release-notes/streaming-browser-agent-caf-26-09-24):
    * Added a `@newrelic/video-caf/browser` subpath export that excludes the unused connected-device pipeline, keeping the bundle lean.
    * Added `{ CAFTracker }` as a named export alongside the default export.
    * Updated `@newrelic/video-core` to 5.1.0.
  * [Node.js agent v14.5.1](/docs/release-notes/agent-release-notes/nodejs-release-notes/node-agent-14-5-1):
    * Fixed `segment.getExclusiveDuration` to only calculate and cache segment durations once per trace.
  * [Go agent v3.45.0](/docs/release-notes/agent-release-notes/go-release-notes/go-agent-3-45-0):
    * Added `nrgemini` and `nrecho-v5` integrations, and continuous profiling.
    * Fixed a bug where LLM Messages would incorrectly be truncated.
    * Bumped `grpc`, `amqp091-go`, and `echo/v4` to address security vulnerabilities.
  * [Ping runtime v1.84.0](/docs/release-notes/synthetics-release-notes/ping-runtime-release-notes/ping-runtime-1.84.0):
    * Fixed multiple OS and library-level security vulnerabilities.
  * [Node API runtime v1.2.284](/docs/release-notes/synthetics-release-notes/node-api-runtime-release-notes/node-api-runtime-1.2.284):
    * Fixed multiple OS-level security vulnerabilities.
  * [Job Manager v632](/docs/release-notes/synthetics-release-notes/job-manager-release-notes/job-manager-release-632):
    * Fixed multiple OS and library-level security vulnerabilities.
  * [Node browser runtime v3.0.241](/docs/release-notes/synthetics-release-notes/node-browser-runtime-release-notes/node-browser-runtime-3.0.241):
