## New docs

* Added [eBPF Logs Public Preview](/docs/ebpf/logs) capability page with configuration reference and best practices for the eBPF logs feature.
* Added [custom certificate support](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-configuration/#custom-ca-certificates) documentation for configuring custom CA certificates in private locations.

### Major changes

* **Migrated `/search-results` from Swiftype to SearchGPT** (New Relic's internal search service, REST API v2) with cursor-based pagination, locale-scoped results (jp, kr, pt, fr), and rate-limit handling.
* **Removed legacy New Relic Insights references** across 7 documentation pages following the full decommission of the Insights monolith on July 1, 2026. All links now point directly to their current destinations.
* **Retired Mobile Crash REST API v1** documentation page. The deprecated v1 API has been superseded by v2. Redirects added to the mobile monitoring intro page.
* Updated [Azure VNet Flow Logs](/docs/network-performance-monitoring/setup-performance-monitoring/cloud-flow-logs/azure-vnet-flow-log-monitoring) monitoring setup with multi-plan support (`FlexConsumption`, `ElasticPremium`, `Basic`, `Consumption`), FedRAMP/US Gov Cloud endpoint, and private-mode outbound routing documentation.

### Minor changes

* Updated [Usage Plan terms](/docs/licenses/license-information/usage-plans/new-relic-usage-plan) to add "Evaluation Features" definition and temporary free evaluation period clause under Pay As You Go.
* Updated [Account Management](/docs/accounts/accounts-billing/account-setup/downgradecancel-account) page with a reference article on viewing relationships between accounts.
* Updated [Java Agent compatibility requirements](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent).
* Updated [Slack prerequisites for Autopilot](/docs/new-relic-solutions/new-relic-one/workloads/workload-status-views-notifications) with current Slack integration requirements.
* Added missing `DatabaseName` field to the [Microsoft SQL Server integration metrics reference](/docs/infrastructure/host-integrations/host-integrations-list/microsoft-sql-server-monitoring-integration) table.
* Updated [OpenTelemetry MSSQL](/docs/opentelemetry/database/mssql/introduction) documentation with new configuration information.
* Improved [Change Tracking Events API](/docs/change-tracking/change-tracking-events) attribute reference by splitting into Required and Optional sections for faster onboarding.
* Updated [Agent Control uninstall commands](/docs/new-relic-solutions/new-relic-one/install-configure/uninstall-agent) to fix incorrect commands.
* Fixed JSX string-literal syntax corruption in French and Korean HAProxy metrics-reference pages that had been breaking Netlify builds.
* Updated EOL and migration guidance documentation.
