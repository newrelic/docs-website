### New docs

* Added [MySQL monitoring via OpenTelemetry](/docs/opentelemetry/database/mysql/introduction) as a public preview integration, covering guided setup, hosted and Amazon RDS configuration, multi-receiver setups, and a full metrics reference.
* Added [PostgreSQL monitoring via OpenTelemetry](/docs/opentelemetry/database/postgresql/introduction) as a public preview integration, covering guided setup, hosted and Amazon RDS configuration, `EXPLAIN` permissions, and a full metrics reference.
* Added [Private location capabilities](/docs/synthetics/synthetic-monitoring/guides/private-location-capabilities) to consolidate synthetic monitoring private location features like custom CA certificates, mTLS, and Terraform automation.
* Added [Compute User Limits](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/compute-budgets/compute-user-limits), now generally available, for setting per-user monthly compute budgets.
* Added [Mobile User Journeys](/docs/mobile-monitoring/mobile-monitoring-ui/mobile-app-pages/user-journeys) to show the sequence of events leading up to a crash, error, or ANR.
* Added [Configure SQL Query Receiver](/docs/opentelemetry/database/capabilities/sql-query-receiver) as a public preview feature for running custom SQL queries against Oracle or SQL Server databases and ingesting the results as metrics.

### Major changes

* Updated [GCP integrations custom roles](/docs/infrastructure/google-cloud-platform-integrations/get-started/integrations-custom-roles) with permissions for 18 additional services, including AlloyDB, Bigtable, Firestore, and Vertex AI.
* Updated [Oracle Database monitoring with NRDOT](/docs/opentelemetry/database/otel-oracledb) with full support for Oracle Autonomous Database (ADB), including installation, privilege grants, and multi-receiver configuration.

### Minor changes

* Corrected [Report custom events and attributes](/docs/data-apis/custom-data/custom-events/report-mobile-monitoring-custom-events-attributes) and [Set the max event pool size](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/set-max-event-pool-size) to state the default mobile event harvest cycle is 60 seconds, not 600.
* Clarified [User management concepts](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts) that custom organization-scoped roles don't automatically receive permissions for new org-scoped features.
* Clarified [Manage multiple user records](/docs/accounts/accounts-billing/account-setup/multiple-user-records) that switching between user records with the same email uses the "Other users" option in the user menu.
* Clarified [Dashboard template variables](/docs/query-your-data/explore-query-data/dashboards/dashboard-template-variables) that the Include/exclude toggle lives in each variable's own dropdown, not the shared variables bar.
* Clarified [Azure Cost Management monitoring integration](/docs/infrastructure/microsoft-azure-integrations/azure-integrations-list/azure-cost-management-monitoring-integration) that cost data requires keeping the traditional Azure integration enabled.
* Removed an outdated note in [Share notebooks](/docs/query-your-data/explore-query-data/notebooks/share-notebooks) stating notebooks lack granular permission settings.
* Added `onCallMembers` field coverage to the [NerdGraph Teams tutorial](/docs/apis/nerdgraph/examples/nerdgraph-teams-tutorial).
* Added steps to [Troubleshoot GCP integrations](/docs/infrastructure/google-cloud-platform-integrations/troubleshooting/troubleshooting-gcp-integrations) for requesting a GCP Cloud Monitoring API quota increase.
* Added guidance for assigning an On-call role to team members in [Manage teams](/docs/service-architecture-intelligence/teams/manage-teams).
* Added a section on setting [.NET agent environment variables](/docs/apm/agents/net-agent/other-installation/understanding-net-agent-environment-variables) for IIS-hosted applications via `ApplicationHost.config`.
* Restructured [Windows MSI install fails with error 1603](/docs/infrastructure/infrastructure-troubleshooting/troubleshoot-infrastructure/windows-msi-install-fails-error-1603) to prioritize missing mandatory `GENERATE_CONFIG` and `LICENSE_KEY` parameters as the most common cause.
* Updated [Windows MSI installer](/docs/infrastructure/infrastructure-agent/windows-installation/windows-msi-installer) so the default silent-install command includes the required `GENERATE_CONFIG` and `LICENSE_KEY` parameters.
