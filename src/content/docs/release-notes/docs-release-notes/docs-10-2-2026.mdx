### New docs

* Added [Kerberos (SPNEGO) authentication support for private locations](/docs/synthetics/synthetic-monitoring/private-locations/synthetics-kerberos-auth-support/), covering KDC and SPNEGO web server setup and synthetics job manager configuration.
* Added [Manage Fleet Control access](/docs/new-relic-control/fleet-control/access-management/), covering role-based access patterns for per-fleet scoping, lifecycle separation, delegated group management, and business unit isolation.
* Added [Instrument your systems with Agent Control](/docs/new-relic-control/agent-control/instrumentation/), which replaces the former Reinstrumentation page and covers setting up instrumentation from scratch or migrating existing agents on Kubernetes, Linux, and Windows.
* Added [Pathpoint (updated)](/docs/pathpoint/get-started-pathpoint/) documentation for the public preview, covering flows, health indicators, KPIs, and NerdGraph management.
* Added the [Google Distributed Cloud Edge monitoring integration](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-distributed-cloud-edge-monitoring-integration/), covering the data it reports, activation, polling frequency, and Workload Identity Federation.
* Added [Alert RCA with Autopilot and Email](/docs/workflow-automation/workflow-examples/integrations/autopilot-email-rca/) to show how to run an Autopilot root cause analysis on an alert and send an HTML report by email, along with an [Autopilot RCA workflow templates](/docs/workflow-automation/workflow-examples/integrations/autopilot-rca/) overview.
* Added the [Query Azure Monitor logs](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-monitor-querylogs/) action to the Workflow Automation actions catalog.
* Added [Azure Cosmos DB actions](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-cosmos-db/) to the Workflow Automation actions catalog.
* Added [AWS Resource Groups Tagging API actions](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/resourcetagging/aws-resourcetagging/) to the Workflow Automation actions catalog.
* Added [New Relic Tagging actions](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging/) to the Workflow Automation actions catalog for adding, replacing, and removing tags on New Relic entities.

### Major changes

* Rewrote [Understand the trace details UI page](/docs/distributed-tracing/ui-data/trace-details/) for the updated entity map experience.
* Expanded [Agent types](/docs/new-relic-control/agent-control/agent-types/) with the `protocol_version` field, a reference for each variable field, and separate deployment sections for Kubernetes and on-host.
* Added per-agent configuration examples for New Relic APM agents, the OpenTelemetry Collector, the eBPF auto-attach agent, and the infrastructure agent to [Modify agent configuration](/docs/new-relic-control/pipeline-control/gateway/modify-agent-configuration/), along with a compatibility matrix of supported agents and versions.
* Updated the Pipeline Control gateway [overview](/docs/new-relic-control/pipeline-control/gateway/overview/), [UI guide](/docs/new-relic-control/pipeline-control/gateway/ui-guide/), and [YAML configuration reference](/docs/new-relic-control/pipeline-control/gateway/yaml-overview/) to document adding and deleting Sample rate, Filter, and Transform processors at any stage of a pipeline.

### What's new

* [Session replay now has its own billing category](/whats-new/2026/09/whats-new-09-28-session-replay-billing-category): Browser and Mobile Session Replay data is reported under new billing categories, separate from browser and mobile events.
* [A new trace map experience with intelligent clustering](/whats-new/2026/09/whats-new-09-28-trace-map-clustering): Trace maps now keep high-importance services visible and collapse the long tail into clusters, so bottlenecks and failing services stand out.
* [New Relic Control host-based fleets are now generally available](/whats-new/2026/09/whats-new-09-29-host-support-ga): Linux and Windows host-based fleets for Agent Control and Fleet Control are now generally available, with support for config approval governance, remote agent upgrades, audit logging, and on-host integrations.
* [Reference the current dashboard from anywhere with `{{selfEntity}}`](/whats-new/2026/09/whats-new-09-29-selfentity-dashboard-variable): A new template variable resolves to the current dashboard's entity GUID, so queries, widget names, and facet links stay accurate after you duplicate a dashboard.
* [The updated version of Pathpoint is now available in Public Preview](/whats-new/2026/09/whats-new-09-30-pathpoint-2-0): Map your most critical business journeys to the telemetry that powers them, now with programmatic management and richer KPIs.
* [Place pipeline processors anywhere you need them with Pipeline Control](/whats-new/2026/09/whats-new-09-30-pipeline-control-processors): Add, reorder, and delete Sample Rate, Filter, and Transform processors at any point in a pipeline.
