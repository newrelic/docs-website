### New docs

* Added [FedRAMP-compliant endpoints](/docs/security/security-privacy/compliance/fedramp-compliant-endpoints) to document customer obligations, FedRAMP inheritance, and compliant endpoints for APM, infrastructure, browser, and mobile agents.
* Added [Google Cloud Managed Kafka](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-cloud-managed-kafka-monitoring-integration), [Google Memorystore for Valkey](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-memorystore-valkey), [Google Cloud Firebase Authentication](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-cloud-firebase-auth-monitoring-integration), and [Google Cloud API Gateway](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-cloud-api-gateway-monitoring-integration) integration docs, along with a new [Troubleshooting GCP integrations](/docs/infrastructure/google-cloud-platform-integrations/troubleshooting/troubleshooting-gcp-integrations) page, as part of the GCP integrations v2 general availability launch.
* Added [Integrated experiences in Intelligent Workloads](/docs/new-relic-solutions/new-relic-one/workloads/intelligent-workload-integrated-experiences) and [Troubleshooting Workloads](/docs/new-relic-solutions/new-relic-one/workloads/workloads-troubleshooting) to provide guidance on Errors, Performance Risks, Transaction 360, KPIs, Activity, Maps, Change tracking, and Service levels within Intelligent Workloads.

### Major changes

* Updated [Install the ECS integration](/docs/infrastructure/elastic-container-service-integration/install-ecs-integration) with two new Fargate forward-only modes, `NRIA_IS_FORWARD_ONLY` and `NRIA_IS_SECURE_FORWARD_ONLY`, including example task definitions and a comparison table explaining when to use each.
* Restructured GCP connection setup into dedicated [Connect with a New Relic service account](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account), [Connect with a Google user account](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-user-account), and Workload Identity Federation pages (now the recommended default), and rewrote roughly 20 existing GCP integration pages for the v2 metrics format.
* Rebranded Intelligent Workload to Intelligent Workloads, restructured [Getting started with Intelligent Workloads](/docs/new-relic-solutions/new-relic-one/workloads/create-intelligent-workload) and the [Intelligent Workloads UI overview](/docs/new-relic-solutions/new-relic-one/workloads/intelligent-workload-ui) around a new AI Summary section and Dynamic Flow Map, and renamed default KPIs from Workload P99 Latency/Success Rate to Transaction Throughput/Transaction Error Rate.
* Updated [Ruby agent configuration](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration) with new options introduced in Ruby agent 10.7.0, including `transaction_tracer.cap_segment_artifacts`, Puma server-statistics instrumentation settings, and Google Cloud Run hostname options.

### Minor changes

* Fixed [User permissions](/docs/accounts/accounts-billing/new-relic-one-user-management/user-permissions) by restoring the detailed permission-definitions section, and updated [User type](/docs/accounts/accounts-billing/new-relic-one-user-management/user-type) to replace outdated "applied intelligence" naming with "Alerts."
* Updated [Introduction to Workflow Automation](/docs/workflow-automation/introduction-to-workflow) to document the `account.create.own_api_keys` permission required to run a workflow, and the error message users see if they lack it.
* Updated [Applications catalog](/docs/service-architecture-intelligence/catalogs/applications-catalog) and [Infrastructure catalog](/docs/service-architecture-intelligence/catalogs/infrastructure-catalog) to document that the Environment grouping is populated from the `Environment`, `environment`, or `env` tag on your entities.
* Fixed [Integrations and custom roles](/docs/infrastructure/google-cloud-platform-integrations/get-started/integrations-custom-roles) to correct the Cloud Resource Manager API's listed purpose.
* Updated [Cloud Cost Intelligence: Pricing](/docs/cci/cci-pricing) to replace exact per-GB billing-file-ingest rates for AWS, Azure, and GCP with a qualitative cost comparison.
* Updated [Chart types](/docs/query-your-data/explore-query-data/use-charts/chart-types) to restore the simpler bar-chart guidance and threshold description without the Neutral status.
* Updated [Configure mobile monitoring settings](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/configure-settings) to reflect that event persistence is now enabled by default.
* Fixed [Kubernetes APM auto-attach](/docs/kubernetes-pixie/kubernetes-integration/installation/k8s-agent-operator) instrumentation CR deployment instructions to no longer require a specific namespace, and clarified that `podLabelSelector` must be empty unless the CR and operator share a namespace.
* Updated [eBPF agent best practices guide](/docs/ebpf/best-practices) to remove the eBPF logs best practice and add a new "Create a unified monitoring approach" section.
* Updated [Amazon API Gateway REST (v1) monitoring integration](/docs/infrastructure/amazon-integrations/aws-integrations-list/aws-api-gateway-v1-monitoring-integration) to document CloudWatch Metric Streams as a recommended ingest method alongside API polling.
* Fixed [SDK based instrumentation](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/sdk-based-instrumentation) CloudWatch fallback links and re-enabled the CloudWatch fallback navigation entry.
* Updated [NerdGraph tutorial: View and manage Scorecards](/docs/apis/nerdgraph/examples/nerdgraph-scorecards-tutorial) to clarify the `accounts` and `joinAccounts` field descriptions for scorecard rule mutations.
* Added Table-level entity support and four new storage metrics to [Google BigQuery monitoring integration](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-bigquery-monitoring-integration).
* Updated [Set up New Relic Autopilot](/docs/agentic-ai/autopilot/setup) to simplify the pricing requirement to Advanced Compute.
