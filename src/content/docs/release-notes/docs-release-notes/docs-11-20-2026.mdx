### New docs

* Added [Install New Relic with an AI coding agent](/docs/new-relic-solutions/get-started/install-with-ai) with a copy-and-paste prompt so AI coding agents such as Claude Code, Cursor, GitHub Copilot, and Codex can find the right install docs, verify the install, and keep your license key out of their context.
* Added [Collector observability FAQ](/docs/opentelemetry/collector-observability/collector-observability-faq) covering supported collector versions, export formats, auto-detection, auto-classification, and attached collectors, so users no longer have to look for these details across several pages.
* Added [Agent Control settings reference](/docs/new-relic-control/agent-control/configuration-reference) listing the Agent Control settings you can modify, such as logging, proxy, status server, health checks, self-instrumentation, and OCI registry options, with their default values.
* Added [Install & configure NRDOT for MySQL monitoring with Azure flexible server](/docs/opentelemetry/db360/mysql/azure) and [Install & configure NRDOT for PostgreSQL monitoring with Azure flexible server](/docs/opentelemetry/db360/postgresql/azure) so teams running MySQL or PostgreSQL on Azure can set up database observability with the NRDOT Collector.
* Added [Security bulletin NR26-13](/docs/security/new-relic-security/security-bulletins/security-bulletin-nr26-13), [NR26-14](/docs/security/new-relic-security/security-bulletins/security-bulletin-nr26-14), and [NR26-15](/docs/security/new-relic-security/security-bulletins/security-bulletin-nr26-15) covering the eMudhra certificate authority compromise as it affects logs integrations, the Kubernetes integration, and the infrastructure agent and on-host integrations.
* Added [Security bulletin NR26-16](/docs/security/new-relic-security/security-bulletins/security-bulletin-nr26-16) for the OpenJDK Java4Shell remote code execution flaw (CVE-2026-114938), with action items for affected New Relic components.

### Major changes

* Updated [Collector observability](/docs/opentelemetry/collector-observability/collector-observability) for general availability by moving detailed explanations into a new FAQ and linking to it from the setup and KPI pages, so the main pages are shorter and easier to follow.
* Rewrote [New Relic iOS agent and distributed tracing](/docs/mobile-monitoring/new-relic-mobile-ios/get-started/new-relic-ios-and-dt) and [New Relic Android agent and distributed tracing](/docs/mobile-monitoring/new-relic-mobile-android/get-started/new-relic-android-and-dt) to explain which requests are traced automatically, what you need to enable for trace correlation, and how to turn tracing off. Both pages were checked against the agent source, and the outdated video was removed.
* Updated [Important user and access management concepts](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts) with tables of standard roles for organization, account, and entity scopes, including fleet, secret, Lens connector, AI agent, NRQL macro, notebook, alert policy, and dashboard roles, so admins can see what each default role grants.
* Updated [Exposure check](/docs/vulnerability-management/exposure-check) to cover the Java4Shell advisory (CVE-2026-114938) alongside the PHP and Node.js advisories, and to describe the new Exposure and How to fix summary cards, so users can find which APM entities run an affected Java version.
* Updated [Configure privacy settings](/docs/mobile-monitoring/mobile-monitoring-ui/mobile-session-replay/configure-privacy-settings) for mobile session replay to fix examples that didn't compile and tag rules that didn't match agent behavior on iOS, Android, and React Native, and to clarify that password fields stay masked.
* Updated [MCP setup](/docs/agentic-ai/mcp/setup) and [MCP overview](/docs/agentic-ai/mcp/overview) with Cursor as a supported MCP client, including the requirements, access, and `mcp.json` configuration for authenticating with a user API key.
* Updated [Connect Autopilot to Slack](/docs/agentic-ai/autopilot/connect-to-slack) with **Investigate with AI** on alert notifications, so teams can start an investigation from a Slack alert thread without writing a prompt.
* Updated [eBPF logs](/docs/ebpf/logs), [Kubernetes installation](/docs/ebpf/k8s-installation), and [Linux installation](/docs/ebpf/linux-installation) to reflect that `reportLogs` now defaults to `"auto"` instead of `"false"` and that the default `fileRegex` is now `".*\\.log$"`, so users know log collection can now start without extra configuration.
* Updated [Ruby agent distributed tracing settings](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration-distributed-tracing-settings) and [Distributed trace sampling](/docs/apm/distributed-tracing/distributed-trace-sampling) with the `trace_id_ratio_based` sampler settings for the Ruby agent, so users can configure ratio-based sampling.
* Removed metrics that New Relic does not collect from the [Google BigQuery](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-bigquery-monitoring-integration), [Google Cloud Pub/Sub](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-cloud-pubsub-monitoring-integration), and [Google Cloud Storage](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-cloud-storage-monitoring-integration) integration pages because Google doesn't define them or lists them as alpha or deprecated, so dashboard queries and alert conditions don't target metrics that never return data.

### Minor changes

* Updated [Find help and get support](/docs/new-relic-solutions/solve-common-issues/find-help-get-support) with a case status definition table to explain what each support case status means.
* Updated [MCP tool reference](/docs/agentic-ai/mcp/tool-reference) with the read-only `get_retention_policy_and_namespaces`, `get_user_id`, and `list_support_cases` tools and the Kafka Autopilot skill.
* Updated [MCP overview](/docs/agentic-ai/mcp/overview) to explain that removing a user from every group with MCP server permissions is a lower-impact way to revoke one user's access than deleting the user.
* Updated [Autopilot overview](/docs/agentic-ai/autopilot/overview) to add the Mobile monitoring tag.
* Updated [Agent types](/docs/new-relic-control/agent-control/agent-types) to explain why Agent Control reports an `unknown` health state for on-host integrations and that `enable_file_logging` output files aren't rotated.
* Updated [Database service identification with NRDOT](/docs/opentelemetry/db360/capabilities/db-apm) to require Java agent v9.4.0 or higher and to show the `sql_metadata_comments.enabled` setting.
* Updated [Set up connectors](/docs/new-relic-lens/set-up-connectors) with the supported MongoDB and Azure Cosmos DB for MongoDB versions (4.2 or newer).
* Updated [Cardinality management](/docs/data-apis/ingest-apis/metric-api/cardinality-management) to clarify that the per-metric cardinality limit can be raised up to your account limit.
* Updated [Intelligent workload KPIs](/docs/new-relic-solutions/new-relic-one/workloads/intelligent-workload-kpis) to clarify that KPI data starts from the time the KPI is created and isn't backfilled.
* Updated [Forward logs from Google Cloud Platform](/docs/logs/forward-logs/google-cloud-platform-log-forwarding) to require Java 11 or later for the Dataflow template.
* Updated the [Node.js agent](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent) and [.NET agent](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements) compatibility and requirements pages with the latest verified library versions.

### Release notes

* Stay up-to-date with our latest releases:

  * [Python agent v14.3.0](/docs/release-notes/agent-release-notes/python-release-notes/python-agent-14-03-00):
    * Enabled AI monitoring by default; LLM instrumentation now sends `Llm*` events, spans, and metrics without message content unless you opt out.
    * Deprecated the `ai_monitoring.enabled` setting in favor of `ai_monitoring.basic_telemetry.enabled`.
    * Fixed a crash in LangChain `StructuredTool` instrumentation when no config is passed.
  * [Node.js agent v14.13.0](/docs/release-notes/agent-release-notes/nodejs-release-notes/node-agent-14-13-0):
    * Added `event.name` to logs when `eventName` exists on an OpenTelemetry log record.
    * Corrected the protocol and port of outbound `http` and `https` requests.
    * Fixed capturing of response headers for `writeHead`.
    * Returned the application handler promise from the kafkajs `eachMessage` wrapper.
  * [.NET agent v10.58.0](/docs/release-notes/agent-release-notes/net-release-notes/net-agent-10-58-0):
    * Enabled AI basic telemetry by default.
    * Applied spec-compliant SQL obfuscation to MySQL, Oracle, SQL Server, Postgres, and other datastores.
    * Captured request headers on Azure Function HTTP trigger transactions.
    * Fixed explain plan capture for MySQL and SQL Server.
  * [PHP agent v12.13.0.43](/docs/release-notes/agent-release-notes/php-release-notes/php-agent-12-13-0-43):
    * Added instrumentation for `mysqli_execute_query` and `mysqli::execute_query`.
    * Verified support for Ubuntu 26.04 and Alpine 3.24.
    * Added release data for tarball hashes, image digests, and signing key fingerprints.
    * Upgraded Go to 1.27.4 and `golang.org/x/net` to 0.62.0 in the daemon.
  * [Infrastructure agent v2.1.1](/docs/release-notes/infrastructure-release-notes/infrastructure-agent-release-notes/new-relic-infrastructure-agent-211):
    * Added support for SUSE 16.
    * Exposed nrjmx wrapper scripts in the Agent Control package.
    * Bumped Go to 1.27.4 and updated embedded on-host integrations.
  * [Pipeline Control Gateway v3.2.1](/docs/release-notes/pipeline-control-gateway-release-notes/pipeline-control-gateway-3-2-1):
    * Fixed JSON decoding errors in the Python APM agent when sending data through the gateway.
    * Fixed APM span events being recorded with their arrival time instead of their start time.
    * Updated `golang.org/x/net` to resolve high- and medium-severity vulnerabilities.
  * [Collector Observability v1.1.0](/docs/release-notes/nrdot-release-notes/collector-o11y-1-1-0):
    * Verified compatibility with `nrdot-collector:2.9.0` and `opentelemetry-collector-contrib:0.164.0`.
  * [Collector Observability v1.0.0](/docs/release-notes/nrdot-release-notes/collector-o11y-1-0-0):
    * Verified compatibility with `nrdot-collector:2.8.1` and `opentelemetry-collector-contrib:0.163.2`.
    * Removed the `newrelic.service.type` resource attribute, which is no longer required for auto-detection.
    * Set `temporality_preference: delta` to avoid unnecessary conversion during ingest.
  * [Logs 261111](/docs/release-notes/logs-release-notes/logs-26-11-11):
    * Upgraded the Google Cloud Pub/Sub to New Relic Dataflow template to Apache Beam 2.77.0, which requires Java 11 or later.
  * [Media agent for iOS v5.2.0](/docs/release-notes/streaming-mobile-release-notes/streaming-ios-agent-26-11-16):
    * Added IMA tracker ad lifecycle and Google IMA DAI support.
    * Added log event buffer capacity thresholds and dropped events.
  * [Media agent for Android v5.1.0](/docs/release-notes/streaming-mobile-release-notes/streaming-android-agent-26-11-17):
    * Added Google IMA DAI support in `NRTrackerIMA`.
    * Added INFO-level logging with log buffer near-capacity and dropped events.
    * Fixed IMA ad tracking for ads cut short by a break end, stray quartile and click events, per-ad timers, and ad duration units.
  * [Synthetics Job Manager v659](/docs/release-notes/synthetics-release-notes/job-manager-release-notes/job-manager-release-659):
    * Addressed the Java4Shell vulnerability (CVE-2026-114938) and fixed multiple OS vulnerabilities.
  * [Synthetics Ping runtime v1.89.0](/docs/release-notes/synthetics-release-notes/ping-runtime-release-notes/ping-runtime-1.89.0):
    * Addressed the Java4Shell vulnerability (CVE-2026-114938) and fixed multiple OS vulnerabilities.
  * [Synthetics Node API runtime v1.2.302](/docs/release-notes/synthetics-release-notes/node-api-runtime-release-notes/node-api-runtime-1.2.302):
    * Fixed multiple security vulnerabilities.
