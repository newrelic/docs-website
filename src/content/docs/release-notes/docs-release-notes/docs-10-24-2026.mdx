### New docs

* Added [Kotlin instrumentation not reporting](/docs/apm/agents/java-agent/troubleshooting/kotlin-instrumentation-not-reporting/) to help you fix missing Kotlin instrumentation by upgrading to Java agent 8.20 or higher and setting the `clear_return_stacks` system property.
* Added [Migration guide](/docs/new-relic-control/agent-control/migration-guide/) for Agent Control, covering the monitoring gap, configuration mapping, entity continuity, and rollback steps when you move from a standalone Infrastructure agent to Agent Control.
* Added [Autopilot compute limits](/docs/agentic-ai/autopilot/autopilot-compute-limits/) to show you how to set daily and monthly Advanced CCU budgets, isolate automated alert triage from interactive use, and track consumption with NRQL.
* Added [AWS SES actions](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/ses/aws-ses/) to the workflow automation actions catalog, covering email template management and sending emails through Amazon SES.
* Added [Get started with collector observability](/docs/opentelemetry/collector-observability/collector-observability-setup/), a setup guide covering billing notes and step-by-step configuration for enabling collector observability.
* Added [OpenTelemetry Collector KPI reference](/docs/opentelemetry/collector-observability/collector-observability-kpis/) to explain each collector observability KPI tile and its related telemetry charts.

### Major changes

* Rewrote [No data appears: .NET Framework app not using TLS 1.2](/docs/apm/agents/net-agent/troubleshooting/no-data-appears-net-framework-tls-12/) (replacing the old TLS 1.0 version) to walk you through checking your app's configured TLS protocols and fixing .NET Framework apps that aren't using TLS 1.2.
* Updated [Remove applications from New Relic](/docs/apm/new-relic-apm/maintenance/remove-applications-new-relic/) with a new NerdGraph `agentApplicationDelete` mutation that lets you permanently force-delete an application even while it's still reporting data.
* Updated [Kafka monitoring integration](/docs/infrastructure/host-integrations/host-integrations-list/kafka/kafka-integration/) with cluster-wide metrics (`KafkaClusterSample`) and new broker, topic, and consumer offset extended metrics and config options.
* Rewrote the [Kubernetes cross-cluster UI](/docs/kubernetes-pixie/kubernetes-integration/understand-use-data/kubernetes-cross-cluster/) scorecard, table, and drill-down sections to match the current UI, replacing cluster-specific metric columns with a single description column and updating threshold colors and values across all five tabs.
* Updated [Install synthetics job manager](/docs/synthetics/synthetic-monitoring/private-locations/install-job-manager/) with a rootless Podman setup table, a lingering-enablement step so service accounts' systemd services keep running without an active login session, and `--shm-size=2g` in the pod-creation command to prevent browser monitors from crashing due to shared memory limits.
* Restructured [Introduction to Java agent installation](/docs/apm/agents/java-agent/installation/java-agent-installation-overview/) by splitting the config-file and installation docs into separate pages by settings category and install method, aligning the Java agent nav with the PHP agent's structure.
* Updated [New Relic API keys](/docs/apis/intro-apis/new-relic-api-keys/) with a new "Audit and manage your API keys" section covering capabilities and permissions, simplified the key-replacement steps, and fixed an inverted description of the `enabled` field (`enabled: false` deactivates a key, and `enabled: true` reactivates it).
* Updated [NerdGraph tutorial: Manage API keys](/docs/apis/nerdgraph/examples/use-nerdgraph-manage-license-keys-user-keys/) with the new `owningTeamIds`, `enabled`, and `keyUsage` (last-used) fields for creating, updating, and querying API keys through NerdGraph.
* Updated [Troubleshoot private locations](/docs/synthetics/synthetic-monitoring/private-locations/troubleshoot-private-locations/) with a new section explaining why browser monitors crash from Podman pod-level shared memory limits, with diagnostic commands and a fix.
* Restructured [OpenTelemetry Collector monitoring](/docs/opentelemetry/collector-observability/collector-observability/) around new standalone vs. attached collector view modes, moved setup content to its own guide, and reorganized the Summary page into collapsible sections.

### Release notes

* Stay up-to-date with our latest releases:

  * [PHP agent v12.12.0.41](/docs/release-notes/agent-release-notes/php-release-notes/php-agent-12-12-0-41):
    * Fixed MongoDB database and collection name retrieval for MongoDB library versions 1.21.4, 2.4.1, and later.
    * Fixed a data race in daemon metric harvesting that could crash the daemon when multiple agents report to one daemon.
    * Passed `E_DONT_BAIL` through to the PHP error handler so destructors run after an uncaught exception.
    * Held a reference to the error group callback to prevent a crash or wrong error group name.
    * Removed the Predis command start time once the response was read.

  * [Node.js agent v14.8.0](/docs/release-notes/agent-release-notes/nodejs-release-notes/node-agent-14-8-0):
    * Prevented nested server and consumer spans from ending outer transactions early.
    * Truncated every string within an array-based span attribute.
    * Added instrumentation for `dns.promises`, `dns.Resolver`, `dns.promises.Resolver`, and additional `resolve*` methods.
    * Refactored net instrumentation to a subscriber-based model.
