### New docs

* Added [Migrate the iOS agent from CocoaPods](/docs/mobile-monitoring/new-relic-mobile-ios/installation/migrate-from-cocoapods) to provide step-by-step instructions for migrating iOS agent integrations from CocoaPods to Swift Package Manager.
* Added [Upgrade your OCI log forwarding integration](/docs/logs/forward-logs/oci-log-forwarder-upgrade) to provide instructions for upgrading OCI log forwarder configurations to the latest version.
* Added [Microsoft SQL Server monitoring with NRDOT](/docs/opentelemetry/db360/mssql/introduction) to provide deployment guides for monitoring Azure Managed Instance and Azure SQL Database on Linux and Windows.

### Major changes

* Restructured [Node.js agent configuration](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration) documentation into topic-specific pages covering general settings, attributes, logging, tracing, error collection, browser monitoring, and AI monitoring configuration.
* Updated [Compute User Limits](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/compute-budgets/compute-user-limits) with expanded coverage for advanced CCU budgets, enforcement policies, and notification settings for both core and advanced compute meters.
* Updated Ruby agent documentation across API guides, attributes, background jobs, configuration, distributed tracing, and error-handling pages with current API and configuration information.

* Updated [FedRAMP](/docs/security/security-privacy/compliance/certificates-standards-regulations/fedramp) with current certification details.

* Updated [Modify agent configuration](/docs/new-relic-control/pipeline-control/gateway/modify-agent-configuration) with expanded Pipeline Control Gateway guidance.

### What's new

* [Compute User Limits now covers advanced compute](/whats-new/2026/11/whats-new-11-03-compute-user-limits-accu): Set independent core CCU and advanced CCU budgets per user and enforce limits for each meter separately.
* [Change Tracking for GitHub Copilot](/whats-new/2026/11/whats-new-11-09-change-tracking-github-copilot): Link deployments to pull requests and trigger automated GitHub Copilot fix workflows when regressions occur.
* [Detect missing New Relic instrumentation with the Gap Analysis MCP tool](/whats-new/2026/11/whats-new-11-09-gap-analysis-mcp-tool): Scans local repository files to identify gaps in APM agents, Browser agents, config files, and CI/CD Change Tracking workflows.
