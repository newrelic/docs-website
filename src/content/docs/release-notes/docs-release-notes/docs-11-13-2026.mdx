### New docs

* Added [Migrate the iOS agent from CocoaPods](/docs/mobile-monitoring/new-relic-mobile-ios/installation/migrate-from-cocoapods) so iOS teams using CocoaPods can transition to Swift Package Manager without losing instrumentation or having to reconfigure from scratch.
* Added [Upgrade your OCI log forwarding integration](/docs/logs/forward-logs/oci-log-forwarder-upgrade) so users running older OCI log forwarder configurations have a clear upgrade path to access current features and security fixes.
* Added [Microsoft SQL Server monitoring with NRDOT](/docs/opentelemetry/db360/mssql/introduction) covering Azure Managed Instance and Azure SQL Database on both Linux and Windows, so teams can set up full database observability without relying on custom configurations.

### Major changes

* Restructured [Node.js agent configuration](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration) into topic-specific pages for general settings, attributes, logging, tracing, error collection, browser monitoring, and AI monitoring, so users can navigate directly to the settings they need instead of searching a single large page.
* Updated [Compute User Limits](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/compute-budgets/compute-user-limits) to cover advanced CCU budgets alongside core CCU, with separate enforcement policies and notification settings for each meter, so admins can control advanced compute costs independently of core compute.
* Updated [Google Memorystore for Valkey](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-memorystore-valkey) with corrected metric names so dashboard queries and alert conditions targeting Valkey metrics return data instead of empty results.
* Updated [Important user and access management concepts](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts) to correctly identify the Billing user role as account-scoped and add Billing to the Organization manager capabilities, preventing misconfigurations when setting up access.
* Updated [Node.js agent on Microsoft Azure App Services](/docs/apm/agents/nodejs-agent/hosting-services/nodejs-agent-microsoft-azure) with clearer Azure hosting guidance to reduce the trial-and-error users encountered when deploying on Azure App Services.
* Updated [Modify agent configuration](/docs/new-relic-control/pipeline-control/gateway/modify-agent-configuration) with expanded Pipeline Control Gateway configuration guidance to cover steps that were previously missing.
* Updated [Monitor self-managed Kafka on Kubernetes with OpenTelemetry](/docs/opentelemetry/integrations/kafka/kubernetes-self-managed) to remove `kafka.partition.replicas.total` from collector configs, since this metric is not collected by the receiver and its presence caused users to expect data that never arrived.
* Updated [Node.js VM measurements](/docs/apm/agents/nodejs-agent/extend-your-instrumentation/nodejs-vm-measurements) to remove content referencing the deprecated `@newrelic/native-metrics` package, which was replaced by a pure-JS implementation in v14.11.0.
* Updated [FedRAMP](/docs/security/security-privacy/compliance/certificates-standards-regulations/fedramp) with current certification details so customers evaluating FedRAMP-authorized services have accurate compliance information.
* Added treemap chart type documentation to [Chart types](/docs/query-your-data/explore-query-data/use-charts/chart-types) so users know when treemaps are the right visualization and how they differ from other chart types now that the chart type is supported.
* Updated [.NET agent compatibility and requirements](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements) to confirm .NET 11 GA support, so users can confidently upgrade their runtime knowing the agent is verified.

### Minor changes

* Updated [Ruby agent documentation](/docs/apm/agents/ruby-agent/getting-started/introduction-new-relic-ruby) across API guides, attributes, background jobs, configuration, and distributed tracing pages to align with the current agent API, so users following existing examples don't hit deprecated methods or stale option names.
* Updated [MCP tool reference](/docs/agentic-ai/mcp/tool-reference) to group tools under related tags, making it easier to find the right tool for a specific use case without scanning the full list.
* Updated [Manage workflows](/docs/workflow-automation/manage-workflows/managing-workflow) with version history support in the workflow editor so users can review, compare, and revert earlier versions of their workflows.
* Updated [Workflow limits](/docs/workflow-automation/limitations-and-faq/workflow-limits) to reflect the increased workflow input limit from 1,000 to 3,000 characters, accommodating more realistic workflow configurations.
* Updated [Alerting rules and limits](/docs/alerts/admin/rules-limits-alerts/) to clarify the facet limit for NRQL alert conditions that use nested aggregation, so users building complex alert conditions know the applicable constraint.

### What's new

* [Compute User Limits now covers advanced compute](/whats-new/2026/11/whats-new-11-03-compute-user-limits-accu): Set independent core CCU and advanced CCU budgets per user and enforce limits for each meter separately.
* [Change Tracking for GitHub Copilot](/whats-new/2026/11/whats-new-11-09-change-tracking-github-copilot): Link deployments to pull requests and trigger automated GitHub Copilot fix workflows when regressions occur.
* [Detect missing New Relic instrumentation with the Gap Analysis MCP tool](/whats-new/2026/11/whats-new-11-09-gap-analysis-mcp-tool): Scans local repository files to identify gaps in APM agents, Browser agents, config files, and CI/CD Change Tracking workflows.
