### Security updates

- The [AWS Unified Lambda](https://github.com/newrelic/aws-unified-lambda) is bumped to version 1.1.5, which upgrades Go to 1.27.3 for CVE fixes.
- The [aws-log-ingestion Lambda](https://github.com/newrelic/aws-log-ingestion) is bumped to version 2.11.5 to fix [CVE-2026-111064](https://nvd.nist.gov/vuln/detail/CVE-2026-111064) and [CVE-2026-111066](https://nvd.nist.gov/vuln/detail/CVE-2026-111066). This version updates the aiohttp library to 3.14.5 and yarl to 1.25.1, along with related dependencies.
- The [aws_s3_log_ingestion_lambda](https://github.com/newrelic/aws_s3_log_ingestion_lambda) is bumped to version 1.4.4 to fix vulnerable certifi dependencies. This version updates the certifi library to 2026.10.23, along with related dependencies.
