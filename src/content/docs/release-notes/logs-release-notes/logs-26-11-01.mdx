### AWS Unified Lambda version 1.1.5

This release bumps the [AWS Unified Lambda](https://github.com/newrelic/aws-unified-lambda) to version 1.1.5.

#### Changed

* The Go version is upgraded to 1.27.3 for CVE fixes

### AWS log ingestion Lambda version 2.11.5

This release bumps the [aws-log-ingestion Lambda](https://github.com/newrelic/aws-log-ingestion) to version 2.11.5 to fix [CVE-2026-111064](https://nvd.nist.gov/vuln/detail/CVE-2026-111064) and [CVE-2026-111066](https://nvd.nist.gov/vuln/detail/CVE-2026-111066).

#### Changed

* Updated the aiohttp library to 3.14.5 and yarl to 1.25.1, along with related dependencies

### AWS S3 log ingestion Lambda version 1.4.4

This release bumps the [aws_s3_log_ingestion_lambda](https://github.com/newrelic/aws_s3_log_ingestion_lambda) to version 1.4.4 to fix vulnerable certifi dependencies.

#### Changed

* Updated the certifi library to 2026.10.23, along with related dependencies
