### Fix for CVEs in AWS S3 Log Ingestion Lambda

With the latest release (v1.4.5), the following CVEs are fixed in the AWS S3 Log Ingestion Lambda (NewRelic-log-ingestion-s3): GHSA-2g87-pp6c-29x5, CVE-2026-111066, CVE-2026-111064 (aiohttp) and CVE-2026-97689, CVE-2026-97687 (urllib3).

### Changed

* Updated the aiohttp library to >=3.14.4 and urllib3 to >=2.8.0
