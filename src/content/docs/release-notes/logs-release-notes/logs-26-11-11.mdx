### Compatibility change

The [Google Cloud Pub/Sub to New Relic Dataflow template](https://github.com/newrelic-forks/DataflowTemplates) is upgraded to Apache Beam 2.77.0, keeping it on a GCP-supported SDK. Building and running the template requires Java 11 or later. If you use Java 8 to build or run the template, upgrade your JDK before using the updated version.
