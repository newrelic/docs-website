### Debian 13 (Trixie) and Windows Server 2025 (LTSC) support

This release adds Fluent Bit support for Debian 13 (Trixie) and Windows Server 2025 (LTSC). It continues to use Fluent Bit 5.0.8 (Linux) and 5.0.7 (Windows).

### Added

* Native package support for Debian 13 (Trixie)
* Native package support for Windows Server 2025 (LTSC)
* [Fluent Bit Output Plugin Docker image](https://hub.docker.com/r/newrelic/newrelic-fluentbit-output) now publishes a Windows Server 2025 (LTSC) variant, built from output plugin [3.9.0](https://github.com/newrelic/newrelic-fluent-bit-output/releases/tag/v3.9.0) (adds Windows Server 2025 support only; no other functional changes over 3.7.0)

### Changed

* [New Relic Logging Helm chart](https://github.com/newrelic/helm-charts/tree/master/charts/newrelic-logging) bumped to version 1.42.0, packaging output plugin 3.9.0, to deploy the Windows Server 2025 (LTSC) plugin image on Kubernetes nodes running that OS
