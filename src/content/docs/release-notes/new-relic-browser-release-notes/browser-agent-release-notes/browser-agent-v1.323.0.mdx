## v1.323.0

**[View this release on GitHub →](https://github.com/newrelic/newrelic-browser-agent/releases/tag/v1.323.0)** for the full technical changelog and build size information.

### Features

#### Harvest SR on switch from ERROR to FULL mode
Update agent to handle session replays the same way as session traces, and trigger a replay harvest when SR is switching from `error` to `full` mode.

#### Add internal adoption metrics for AJAX Payloads
Adds an internal metric measuring adoption of AJAX payload tracking for quality assurance and improvement purposes.


### Bug fixes

#### fix(ajax): correct DT header timestamp to server time
Distributed tracing headers (`traceparent`/`tracestate`/`newrelic`) generated for AJAX requests now use the New Relic server-corrected timestamp when the agent's TimeKeeper has completed its RUM-based clock correction, rather than the browser's raw local clock value. This timestamp only affects the transport duration value a receiving backend APM agent computes for its own span -- it has no effect on any other browser telemetry.

#### Ensure timeKeeper readiness on Connector race condition
The new Connector in RUM v2 is patched to ready the TimeKeeper, critical to agent timestamp adjustments, under a minority-case race condition branch. This is behind the feature flag and should have no impact to any user right now.

## Support statement

New Relic recommends that you upgrade the agent regularly to ensure that you're getting the latest features and performance benefits. Older releases will no longer be supported when they reach [end-of-life](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/). Release dates are reflective of the original publish date of the agent version.

The following features are currently in limited preview and will not receive standard support:
- [Micro frontend (MFE) monitoring](https://docs-preview.newrelic.com/docs/browser/micro-frontend-monitoring/) via the [register() API](https://docs-preview.newrelic.com/docs/browser/register)
- [BrowserPerformance "resource"](https://docs.newrelic.com/docs/browser/new-relic-browser/browser-pro-features/page-resources/) type events

New browser agent releases are rolled out to customers in small stages over a period of time. Because of this, the date the release becomes accessible to your account may not match the original publish date. Please see this [status dashboard](https://newrelic.github.io/newrelic-browser-agent-release/) for more information.

Consistent with our [browser support policy](https://docs.newrelic.com/docs/browser/new-relic-browser/getting-started/compatibility-requirements-browser-monitoring/#browser-types), v1.323.0 of the Browser agent was built for and tested against these browsers and version ranges: Chrome 143-153, Edge 142-152, Safari 18-27, and Firefox 145-155. For mobile devices, v1.323.0 was built and tested for Android OS 16 and iOS Safari 18-26.2.
