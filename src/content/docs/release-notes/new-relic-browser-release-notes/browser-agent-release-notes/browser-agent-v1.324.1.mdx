## v1.324.1

**[View this release on GitHub →](https://github.com/newrelic/newrelic-browser-agent/releases/tag/v1.324.1)** for the full technical changelog and build size information.

### Bug fixes

#### correct hasMeta/hasSnapshot flags on session replay harvests
Fixed an issue where Session Replay harvests could incorrectly report `hasMeta` and `hasSnapshot` as `false` in their payload metadata even though the harvested data included valid snapshot nodes — most noticeable shortly after a session switched from error-only to full recording, or whenever the recorder restarted. This metadata was used downstream to determine whether a given replay chunk was self-sufficient (i.e. whether it could bootstrap a replay on its own), so an incorrect `false` could cause valid replay data to be mishandled.


### Security fixes

#### bump fflate to 0.8.3
Addressed CVE-2026-45820 - unzipSync could enter an infinite loop when parsing malformed ZIP64 archives

## Support statement

New Relic recommends that you upgrade the agent regularly to ensure that you're getting the latest features and performance benefits. Older releases will no longer be supported when they reach [end-of-life](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/). Release dates are reflective of the original publish date of the agent version.

The following features are currently in limited preview and will not receive standard support:
- [Micro frontend (MFE) monitoring](https://docs-preview.newrelic.com/docs/browser/micro-frontend-monitoring/) via the [register() API](https://docs-preview.newrelic.com/docs/browser/register)
- [BrowserPerformance "resource"](https://docs.newrelic.com/docs/browser/new-relic-browser/browser-pro-features/page-resources/) type events

New browser agent releases are rolled out to customers in small stages over a period of time. Because of this, the date the release becomes accessible to your account may not match the original publish date. Please see this [status dashboard](https://newrelic.github.io/newrelic-browser-agent-release/) for more information.

Consistent with our [browser support policy](https://docs.newrelic.com/docs/browser/new-relic-browser/getting-started/compatibility-requirements-browser-monitoring/#browser-types), v1.324.1 of the Browser agent was built for and tested against these browsers and version ranges: Chrome 144-154, Edge 144-154, Safari 18-27, and Firefox 146-156. For mobile devices, v1.324.1 was built and tested for Android OS 17 and iOS Safari 18-26.2.
