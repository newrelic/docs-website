Monitor video playback in your Amazon Fire TV application using the New Relic `VegaTracker` class. VegaTracker sends playback events directly to the New Relic mobile collector and requires no browser agent.

<Callout variant="important">
  VegaTracker uses the mobile data pipeline, not the browser pipeline. Your application token is a **mobile application token** generated separately from any browser license key.
</Callout>

## Prerequisites [#prerequisites]

Before installing the tracker, make sure you have:

- A New Relic [account ID](/docs/accounts/accounts-billing/account-setup/account-id)
- A New Relic mobile application token (generated in the steps below)
- Familiarity with the [Streaming Video & Ads compatibility requirements](/docs/streaming-video-&-ads/installation/compatibility-requirements)

## Install the tracker [#install]

<Steps>

<Step>
### Access New Relic

Go to <DNT>**[one.newrelic.com](https://one.newrelic.com) > Integrations & Agents**</DNT> and navigate to the integrations marketplace.
</Step>

<Step>
### Select Streaming Video & Ads

Search and select the <DNT>**Streaming Video & Ads**</DNT> tile.
</Step>

<Step>
### Select account

Select an <DNT>**Account**</DNT> from the dropdown and click <DNT>**Continue**</DNT>.
</Step>

<Step>
### Select platform

Select <DNT>**Amazon Vega / Fire TV**</DNT> and click <DNT>**Continue**</DNT>.
</Step>

<Step>
### Select video player

Select your video player and click <DNT>**Continue**</DNT>.
</Step>

<Step>
### Name your application

Provide a name for your application and click <DNT>**Create**</DNT>. This generates the mobile application token you'll use to initialize VegaTracker.
</Step>

<Step>
### Complete player-specific installation

Follow the installation guide for your selected player:

<DocTiles>
  <DocTile title="Shaka Player" path="/docs/streaming-video-&-ads/installation/amazon-fire-tv/install-shaka-player">Install VegaTracker for Shaka Player.</DocTile>
  <DocTile title="Dash.js" path="/docs/streaming-video-&-ads/installation/amazon-fire-tv/install-dashjs">Install VegaTracker for Dash.js.</DocTile>
  <DocTile title="HTML5" path="/docs/streaming-video-&-ads/installation/amazon-fire-tv/install-html5">Install VegaTracker for the native HTML5 video element.</DocTile>
</DocTiles>
</Step>

</Steps>
