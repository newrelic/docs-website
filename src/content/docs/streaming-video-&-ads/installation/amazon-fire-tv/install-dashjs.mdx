Install the New Relic `VegaTracker` to monitor Dash.js video playback in your Amazon Fire TV application.

## Before you begin [#before-begin]

Complete the [common installation steps](/docs/streaming-video-&-ads/installation/amazon-fire-tv/get-started-with-amazon-fire-tv#install) first to create your application and retrieve your mobile application token.

## Install the tracker [#install]

<Steps>

<Step>
### Name your application

Provide a name to your application and click <DNT>**Save and Continue**</DNT>.
</Step>

<Step>
### Install device info

This step is optional. The device info library provides real device attributes — model, OS version, and UUID — in your video events. Without it, events use placeholder values for `deviceModel` and `deviceUuid`.
</Step>

<Step>
### Initialize VegaTracker

Initialize `VegaTracker` inside `onSurfaceViewCreated` — by the time this callback fires, the player's async attach has completed. Pass your Dash.js player instance along with the `info` object containing your account ID, application token, and endpoint. If you installed the device info library, pass the device attributes as `info.deviceInfo`.

When playback ends, call `tracker.dispose()` to release resources.

Use the code snippet in the [New Relic guided install](/docs/streaming-video-&-ads/installation/amazon-fire-tv/get-started-with-amazon-fire-tv#install) for the initialization example.
</Step>

<Step>
### View your data

Deploy your application and interact with the video player. Navigate to <DNT>**[one.newrelic.com](https://one.newrelic.com) > Streaming Video & Ads**</DNT> to verify that data is flowing for your application.
</Step>

</Steps>

## Configuration reference [#configuration]

The following options are available when initializing `VegaTracker`.

### `info` options [#info-options]

  <thead>
    <tr>
      <th style={{width: "220px"}}>

      <th style={{width: "100px"}}>
        Required
      </th>
      <th>
        Description
      </th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>
        `info.accountId`
      </td>
      <td>
        Yes
      </td>
      <td>
        Your New Relic [account ID](/docs/accounts/accounts-billing/account-setup/account-id).
      </td>
    </tr>
    <tr>
      <td>
        `info.applicationToken`
      </td>
      <td>
        Yes
      </td>
      <td>
        The mobile application token generated when you created your application in New Relic.
      </td>
    </tr>
    <tr>
      <td>
        `info.endpoint`
      </td>
      <td>
        No
      </td>
      <td>
        The New Relic data center region: `"US"`, `"EU"`, `"JP"`, or `"GOV"`. Defaults to `"US"`.
      </td>
    </tr>
    <tr>
      <td>
        `info.deviceInfo`
      </td>
      <td>
        No
      </td>
      <td>
        Object containing device attributes. See [deviceInfo options](#deviceinfo-options).
      </td>
    </tr>
  </tbody>
</table>
