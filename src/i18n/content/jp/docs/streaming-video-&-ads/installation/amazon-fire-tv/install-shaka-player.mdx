Amazon Fire TVアプリケーションでのShaka Playerのビデオ再生をモニターするには、New Relic `VegaTracker`をインストールします。

## あなたが始める前に [#before-begin]

まず[共通のインストレーション手順](/docs/streaming-video-&-ads/installation/amazon-fire-tv/get-started-with-amazon-fire-tv#install)を完了して、アプリケーションを作成し、モバイルアプリケーションのトークンを取得してください。

## トラッカーをインストールしてください。 [#install]

<Steps>
  <Step>
    ### Shakaパッケージをインストールします。

    ```shell
    npm install @newrelic/video-shaka --save
    ```
  </Step>

  <Step>
    ### デバイス情報のインストール

    この手順はオプションです。デバイス情報ライブラリは、ビデオイベントに実際のデバイス属性 — モデル、OSバージョン、UUID — を提供します。これがない場合、イベントは`deviceModel`と`deviceUuid`にプレースホルダー値を使用します。

    ```shell
    npm install @amazon-devices/react-native-device-info --save
    ```
  </Step>

  <Step>
    ### VegaTrackerを初期化する

    `onSurfaceViewCreated`コールバック内で`VegaTracker`を初期化します。これにより、初期化前にプレーヤーの非同期アタッチが確実に完了します。

    Shaka playerインスタンスと`info`オブジェクトを渡します。`info`オブジェクトには、アカウントID、アプリケーショントークン、およびエンドポイントが含まれている必要があります。デバイス情報ライブラリをインストールした場合は、デバイス属性も`info.deviceInfo`として渡します。

    再生が終了したら、`tracker.dispose()`を呼び出してリソースを解放します。

    初期化の例については、[New Relicのガイド付きインストール](/docs/streaming-video-&-ads/installation/amazon-fire-tv/get-started-with-amazon-fire-tv#install)のコードスニペットを使用してください。
  </Step>

  <Step>
    ### 自分のデータを見る

    アプリケーションをデプロイし、ビデオを再生します。<DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Streaming Video &amp; Ads**</DNT>に移動して、アプリケーションのデータが流れていることを確認します。
  </Step>
</Steps>
