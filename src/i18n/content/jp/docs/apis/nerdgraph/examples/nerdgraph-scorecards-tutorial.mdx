New Relic では、NerdGraph[スコアカード](/docs/service-architecture-intelligence/scorecards/getting-started)GraphQL ミューテーションを使用してスコアカードとルールを管理できます。 これらのミューテーションにより、既存のワークフローおよびインテグレーションでスコアカードとそれに関連するルールを作成、更新、削除、取得できます。

このチュートリアルでは、NerdGraphを使用してスコアカードとルールを管理する方法の例を紹介します。これらの例を使用して、スコアカードの作成、ルールの追加、スコアカードの詳細の更新などのスコアカード管理タスクを自動化できます。Scorecardsを管理するためのカスタム権限を設定する必要がある場合は、[Scorecardsのカスタムロールの作成](/docs/apis/nerdgraph/examples/nerdgraph-scorecards-custom-tutorial)を参照してください。

## 変異 [#mutations]

New Relic は、スコアカードと関連ルールを作成および管理するためのさまざまな NerdGraph ミューテーションを提供します。

スコアカードのルールを[マチュリティレベル](/docs/service-architecture-intelligence/scorecards/service-maturity)に整理し、各ルールに重みを付けることもできます。APIでは、マチュリティレベルは<DNT>**progress levels**</DNT>と呼ばれます：

* Scorecardは、`progressLevels`フィールドでその成熟度レベルを定義します。カスタム（デフォルトではない）レベルの作成はAPIを介してのみ可能です。[成熟度レベルの作成または更新](#maturity-levels)を参照してください。
* ルールは`progressLevel`フィールドを使用してレベルに割り当てられます。このフィールドは、スコアカードのプログレスレベルのいずれかの`id`を取ります。
* Scorecardの加重平均スコアにおけるルールの重みは、`impactWeight`フィールドで設定されます。重み付けの仕組みについては、[加重スコアリング](/docs/service-architecture-intelligence/scorecards/service-maturity#weighted-scoring)を参照してください。

  <Collapser id="maturity-levels" title="マチュリティレベルの作成または更新">
    成熟度レベルは、スコアカードの`progressLevels`によって定義されます。[スコアカードを作成する](#create-scorecard)ときに設定するか、後で`entityManagementUpdateScorecard`ミューテーションを使用して更新します。

    UIはデフォルトの3つのみをサポートしているため、カスタムレベルを作成する（4番目のレベルを追加したり、デフォルトの名前を変更したりするなど）唯一の方法はAPIです。

    **既存のスコアカードに新しいマチュリティレベルを追加するには：**

    1. 現在のレベルを取得するには、[Scorecard読み取りクエリ](#fetch-scorecards)を実行します。
    2. *完全な*`progressLevels`配列を使用して`entityManagementUpdateScorecard`ミューテーションを呼び出します。保持したい既存のレベルと、新しいレベルを必ず含めてください。

    <Callout variant="important">
      updateミューテーションは、スコアカードのレベルのセット全体を置き換えます。配列から除外したレベルは完全に削除されます。
    </Callout>

    留意事項：

    * **制限：**スコアカードは1～5レベルを持つことができます。
    * **階層:** 配列の順序により、最も低い成熟度から最も高い成熟度までの階層が設定されます。

    `progressLevels`配列の各アイテムは、次のフィールドを受け入れます。

    #### サンプルリクエスト

    ```graphql
    mutation CreateRule(
      $name: String!
      $description: String
      $query: String!
      $accounts: [Int!]!
      $joinAccounts: [Int!]
      $organizationId: ID!
      $progressLevel: ID
      $impactWeight: Int
      $runInterval: Int
    ) {
      entityManagementCreateScorecardRule(
        scorecardRuleEntity: {
          name: $name
          description: $description
          enabled: true
          progressLevel: $progressLevel
          impactWeight: $impactWeight
          runInterval: $runInterval
          nrqlEngine: {
            accounts: $accounts
            joinAccounts: $joinAccounts
            query: $query
          }
          scope: { id: $organizationId, type: ORGANIZATION }
        }
      ) {
        entity {
          id # RULE Id
        }
      }
    }
    ```

    ```json
    // PARAMETERS
    {
      "name": "APM Services Have Alerts Defined",
      "description": "Check that APM services have alerts associated with them",
      "accounts": [1, 2, 3],
      "query": "SELECT if(latest(alertSeverity) != 'NOT_CONFIGURED', 1, 0) AS 'score' FROM Entity WHERE type = 'APM-APPLICATION' AND tags.nr.team IS NOT NULL AND tags.environment IS NOT NULL FACET id AS 'entityGuid', tags.nr.team AS 'team', tags.environment AS 'environment' LIMIT MAX SINCE 1 day ago",
      "organizationId": "xxxxxxxx-yyyy-0000-aaaa-0123456789qwe",
      "progressLevel": "BASIC",
      "impactWeight": 2,
      "runInterval": 1440
    }
    ```

      $joinAccounts: [Int!]
      $enabled: Boolean
      $progressLevel: ID
      $impactWeight: Int
      $runInterval: Int

        scorecardRuleEntity: {
          description: $description
          name: $name
          enabled: $enabled
          progressLevel: $progressLevel
          impactWeight: $impactWeight
          runInterval: $runInterval
          nrqlEngine: {
            accounts: $queryAccounts
            joinAccounts: $joinAccounts
            query: $query

          id
          name
          description
          progressLevel
          impactWeight
          nrqlEngine {
            accounts
            joinAccounts
            query
          }
        }
      }
    }
