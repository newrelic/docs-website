NerdGraphの`dashboardCreateSnapshotUrl`および`dashboardWidgetCreateSnapshotUrl`ミューテーションを使用して、ダッシュボードや個々のチャートをPDFまたはPNGファイルとしてプログラムでエクスポートできます。APIは、テンプレート変数の上書きやエンティティ・フィルターなど、UIでは利用できないオプションをサポートしています。[UIを使用してダッシュボードをエクスポートする](/docs/query-your-data/explore-query-data/dashboards/dashboards-charts-import-export-data/#export-dashboards-pdf)こともできます。

## ダッシュボードをPDFまたはPNGとしてエクスポート [#api-dashboard-snapshot]

`dashboardCreateSnapshotUrl`ミューテーションは、ダッシュボードページ全体のスナップショットURLを生成します。

<Callout variant="tip">
`guid`パラメーターには、ダッシュボードのGUIDではなく、**ページ**のGUIDが必要です。ダッシュボードには複数のページを含めることができます。ページのGUIDを見つけるには、`entitySearch`クエリを使用するか、ダッシュボードページを開いて<DNT>**...**</DNT>メニューから<DNT>**Manage JSON**</DNT>を選択します。

```graphql
{
  actor {
    entitySearch(query: "parentId ='YOUR_DASHBOARD_GUID' AND tags.isDashboardPage = 'true'") {
      results {
        entities {
          guid
          name
        }
      }
    }
  }
}
```
</Callout>

**Mutation schema：**

```graphql
mutation {
  dashboardCreateSnapshotUrl(
    guid: EntityGuid!
    params: SnapshotUrlInput
  ): String
}

input SnapshotUrlInput {
  timeWindow: SnapshotUrlTimeWindowInput
  display: SnapshotUrlDisplayInput
  variables: [SnapshotUrlVariableInput!]
  filter: String
  format: SnapshotUrlFormat
}

input SnapshotUrlTimeWindowInput {
  beginTime: EpochMilliseconds
  endTime: EpochMilliseconds
  duration: Milliseconds
}

input SnapshotUrlDisplayInput {
  width: Int
  height: Int
}

input SnapshotUrlVariableInput {
  name: String!
  values: [String!]!
}

enum SnapshotUrlFormat {
  PDF
  PNG
}
```

<Collapser id="variables-filter" title="変数の上書きとフィルターを使用したエクスポート">
これを使用して、特定の変数値とフィルターをスナップショットに固定します。これは、スケジュールされたレポートの自動化に役立ちます。

```graphql
mutation {
  dashboardCreateSnapshotUrl(
    guid: "YOUR_DASHBOARD_PAGE_GUID"
    params: {
      variables: [
        { name: "environment", values: ["production"] }
        { name: "region", values: ["us-east-1", "eu-west-1"] }
      ]
      filter: "env = 'production' AND service = 'checkout'"
    }
  )
}
```
</Collapser>
</CollapserGroup>

<Callout variant="important">
スナップショットURLは認証なしでパブリックにアクセス可能であり、3か月後に期限切れになります。組織のデータポリシーに従って慎重に共有してください。
</Callout>

## チャートを画像としてエクスポートする [#api-widget-snapshot]

`dashboardWidgetCreateSnapshotUrl`ミューテーションは、単一のチャート・ウィジェットのPDFまたはPNGスナップショットへのURLを生成します。ウィジェットはダッシュボードに存在する必要はありません — インラインで定義できるため、プログラムでチャートのスナップショットを生成する際に便利です。

**Mutation schema：**

```graphql
mutation {
  dashboardWidgetCreateSnapshotUrl(
    widget: DeclarativeUiWidget!
    params: DashboardWidgetSnapshotUrlInput
  ): WidgetSnapshotResult
}

type WidgetSnapshotResult {
  url: String!
}
```

`params`引数はオプションです。これを使用して、出力形式またはスナップショットのサイズを変更します。

`widget`パラメーターは`DeclarativeUiWidget`を受け付けます — 3つのネストされたレイヤーを持つJSONオブジェクト：

```
declarative/widget envelope
└── widget node        ← title and widget-level props
    └── visualization  ← visualization type and configuration
```

```json
{
  "type": "declarative/widget",
  "version": 1,
  "content": {
    "type": "widget",
    "props": {
      "title": "My Chart Title"
    },
    "content": {
      "type": "visualization",
      "id": "viz.line",
      "props": {
        // visualization-specific config (nrqlQueries, colors, thresholds, etc.)
      }
    }
  }
}
```

<Callout variant="tip">
NerdGraphのレガシー`actor.account.nrql.staticChartUrl`フィールドは引き続き利用可能ですが、閾値、カラーフォーマット、新しいチャートタイプなどの最新の視覚化機能はサポートしていません。今後は`dashboardWidgetCreateSnapshotUrl`が推奨されるアプローチです。
</Callout>

<Callout variant="important">
`dashboardWidgetCreateSnapshotUrl` スナップショットのURLは認証なしで公開アクセス可能であり、3か月後に期限切れになります。
</Callout>

## トラブルシューティング [#troubleshooting]

ダッシュボードをエクスポートしようとしたときに次のエラーが発生した場合の対処方法は次のとおりです。

* New Relic UIから: <DNT>**We ran into an error while creating the PDF. Please try again**</DNT>

* New Relic NerdGraphより: <DNT>**Operation on dashboard entity failed with guid:YOUR\_GUID with cause: Error 504: upstream request timeout**</DNT>

これらのエラーは、エクスポートがAPIの最大レスポンスタイムを超えた場合に発生する可能性があります。ダッシュボード上のウィジェットが大きなタイムウィンドウを使用しているかどうかを確認してください — たとえば、1か月全体のデータを比較している場合などです。その場合は、タイムウィンドウを短くしてみてください。

もう1つの考えられる原因は、多数のウィジェットを含むダッシュボードです。未使用のウィジェットを削除して、エラーが解決するかどうかを確認してください。
