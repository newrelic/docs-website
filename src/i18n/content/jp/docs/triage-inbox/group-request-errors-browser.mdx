サードパーティのインテグレーションの破損や、バックエンドAPIが500を返すといったAJAXおよびfetchコールの失敗は、多くの場合、ページの破損や混乱を招くユーザー体験の原因となります。<DNT>**Request errors**</DNT>ページでは、これらの失敗したrequestsをグループ化しているため、破損したページの背後にあるAPIコールを見つけ、それらが失敗する頻度を確認し、どこからデバッグを開始すべきかを把握できます。

リクエストエラーは、Browserエージェントがすでに収集している[`AjaxRequest`](/attribute-dictionary/?event=AjaxRequest)イベントに基づいて構築されているため、使用を開始するためにインストールしたり有効にしたりする必要はありません。

## リクエストエラーページを表示する [#request-errors-page]

リクエストエラーページを表示するには、<DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Browser &gt; (select an app) &gt; Request errors**</DNT>に移動してください。

## 推奨ワークフロー [#suggested-workflow]

リクエストエラーを調査する際は、エラーを理解し、要因を特定してデバッグを開始できるように、以下のアプローチをお勧めします：

1. **全体的な傾向の確認**：まず、<DNT>**Error count**</DNT>および<DNT>**Errors by page**</DNT>チャートを見渡し、想定外の急上昇、急降下、パターンがないか確認します。
2. **グループ化とフィルタリング**：<DNT>**Group by**</DNT>およびフィルターオプションを使用して、特定のリクエストドメイン、リクエストパス、レスポンスコード、またはコード範囲に焦点を当ててください。
3. **単一エラーのドリルダウン**：リクエストエラーテーブルの行を選択して、リクエストURL、レスポンスコード、レスポンス本文などの完全なリクエストの詳細を表示します。
4. **セッションリプレイとイベントトレイルの確認**：特定のエラーから、[イベントトレイル](#event-trail)と、利用可能な場合はその発生中に記録された[セッションリプレイ](#session-replay)を確認します。
5. **データのクエリと共有**：任意のチャートで<DNT>**…**</DNT>メニューを選択し、次に<DNT>**View query**</DNT>を選択して、クエリビルダーで基となる`AjaxRequest`データを探索するか、ダッシュボードに追加してください。
6. **タイムウィンドウを変更する**: タイムピッカーのドロップダウンから新しい期間を選択します。

## リクエストエラーの詳細 [#error-details]

リクエストエラーテーブルの行を選択すると、リクエストの詳細がスタックパネルとして開き、そのエラーの完全なリクエスト情報、リクエスト属性、およびレスポンス本文が表示されます。

### プロファイル [#error-profiles]

リクエストエラーテーブルから<DNT>**View profiles**</DNT>を選択して、このグループのリクエストエラーを他のトラフィックと最も区別する属性を確認します。プロファイルを使用して、影響を受けるrequestsの共通点をすばやく特定します。

### イベントトレイル [#event-trail]

特定のエラーを選択すると、イベントトレイルに、そのエラーに至るまでのブラウザのインタラクションとAJAX呼び出しが表示されます。これにより、リクエストが失敗したときにユーザーが何をしていたか、また同時期の他の呼び出しも影響を受けたかどうかを理解できます。

### セッションのリプレイ [#session-replay]

表示している事象に対してセッションリプレイが記録されている場合は、エラーの詳細からそれを開いて、リクエストが失敗したときにユーザーが正確に何を経験したかを確認できます。

## リクエストエラーデータのクエリと視覚化 [#insights]

New Relicは、リクエストエラーデータを`AjaxRequest`イベントとして保存します。[クエリビルダー](/docs/query-your-data/explore-query-data/query-builder/introduction-query-builder)で`AjaxRequest`イベントタイプをクエリして、NRQLクエリを実行し、リクエストエラーデータからダッシュボードを構築します。
