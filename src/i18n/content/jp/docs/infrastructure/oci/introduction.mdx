New RelicのOCIインテグレーションは、Oracleクラウドインフラストラクチャ環境をNew Relicに接続します。これにより、スタックの他の部分に使用しているのと同じオブザーバビリティプラットフォームから、OCIリソースとアプリケーションをモニターできます。New Relicは、OCI専用に構築されたinfrastructureエージェント、オンホストインテグレーション、およびクラウドインテグレーションを使用して、OCIのメトリクスとログを収集します。接続すると、OCIリソースは、その上で実行されているアプリケーションやホストとともに、New Relicにエンティティとして表示されます。

## 機能 [#capabilities]

New Relicは2種類のOCIデータを収集します：

* **メトリクス**：OCIリソースの健全性、キャパシティ、パフォーマンスを追跡するリアルタイムメトリクス
* **ログ**：OCIサービスおよび監査ログ

## セットアップを選択してください [#choose-setup]

ガイド付きインストレーションは<DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; Oracle Cloud Infrastructure**</DNT>でご利用いただけます。UIでは、インジェストするデータタイプを尋ねられます。その後、OCIアカウントを接続し、モニターするネームスペースとロググループをインストゥルメントされた状態にする手順が案内されます。選択内容によって手順が異なるため、選択に合ったガイドに従ってください：

* **メトリクスのみ**：パフォーマンスと使用状況の統計については、[OCIメトリクスをモニター](/docs/infrastructure/oci/install-metrics)してください。
* **ログのみ**：詳細なイベントおよび監査レコードについては、[OCIログをNew Relicに転送](/docs/logs/forward-logs/oci-log-forwarding)してください。
* **メトリクスとログ**：両方を一緒に送信し、同じOCIリソースについてそれらを関連付けることができるように、[OCIのメトリクスとログをモニター](/docs/infrastructure/oci/install-metrics-and-logs)します。
