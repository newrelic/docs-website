<Callout title="プレビュー">
この機能はまだ開発中ですが、ぜひお試しください。

この機能は現在、弊社の[プレリリース ポリシー](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy)に従ってプレビュー プログラムの一部として提供されています。
</Callout>

<DNT>Azure</DNT>上の[<DNT>Infrastructure 360</DNT>](/docs/infrastructure/infrastructure-360/introduction-infrastructure-360)で問題が発生した場合は、以下のトラブルシューティングのシナリオを確認してください。

<CollapserGroup>
<Collapser id="no-entities-appear" title="自動検出を有効にした後、Azureエンティティが表示されません">
自動検出を有効にした後にエンティティが表示されない場合は、以下を確認してください：

* **権限の確認**: <DNT>Azure</DNT>アプリの登録に、サブスクリプションおよび必要なリソースグループに対する閲覧者権限があることを確認してください。
* **サブスクリプションの確認**: New Relicインテグレーションで正しい<DNT>Azure</DNT>サブスクリプションIDを設定したことを確認してください。
* **最初のスキャンをお待ちください**：初回の検出には時間がかかる場合があります。次回のスケジュールされたスキャンの後に再度ご確認ください（デフォルトは1日3回です）。
* **プレビューアクセスの確認**：<DNT>**Administration &gt; Preview &amp; Trials**</DNT>を確認して、New Relicアカウントが<DNT>Infrastructure 360</DNT>プレビューに登録されていることを確認してください。
</Collapser>

<Collapser id="missing-relationships" title="エンティティ関係が表示されていません">
エンティティ間の関係が表示されない場合は、次を確認してください：

* **適切なAPMエージェントがインストールされているか確認してください**：多くのリレーションシップでは、アプリケーションからデータをアクティブに報告するNew Relic APMエージェントをインストールする必要があります。
* **エンティティの命名を確認する**：自動検出によってAPMエンティティと照合できるように、<DNT>Azure</DNT>リソースで一貫した命名が使用されていることを確認してください。
* **ネットワーク接続の確認**：<DNT>Azure</DNT>リソースがNew Relicのデータコレクターに到達できることを確認してください。
* **リソースタグの確認**：一部のリレーションシップは、<DNT>Azure</DNT>とAPM設定の両方における適切なタグ戦略に依存しています。
</Collapser>

<Collapser id="scan-failures" title="オートディスカバリースキャンが失敗しています">
自動検出スキャンが継続して失敗する場合は、次の点を確認してください：

* **API制限の確認**: <DNT>Azure</DNT> APIのレート制限を超えていないことを確認してください。一時的にスキャンの頻度を下げることを検討してください。
* **アプリ登録の確認**：<DNT>Azure</DNT> アプリ登録が現在も有効であり、期限が切れていないことを確認してください。
* **権限の見直し**: <DNT>Azure</DNT>ポリシーの変更後も、アプリの登録に必要な権限があることを確認してください。
* **サブスクリプションステータスの確認**：<DNT>Azure</DNT>サブスクリプションがアクティブであり、アクセス可能であることを確認してください。
</Collapser>
</CollapserGroup>
