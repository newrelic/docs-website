このページでは、New RelicのGoogle Cloud Platform（GCP）インテグレーションに関する一般的な問題とその解決方法について説明します。

## セットアップ後にデータが表示されない [#no-data]

### 基本事項を確認してください [#no-data-basics]

* セットアップの完了後、5分間お待ちください。データが到着するまで数分かかります。
* セットアップ中に少なくとも1つのサービスを選択したことを確認してください。
* GCPプロジェクトで<DNT>**Stackdriver Monitoring API**</DNT>が有効になっていることを確認してください。

### ワークロードIdentity Federationインテグレーション [#no-data-wif]

[ワークロード Identity Federation（WIF）](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation)で接続した場合：

* 5つの[必須API](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation#step-2)がすべて有効になっていることを確認してください。
* サービスアカウントに<DNT>**Viewer**</DNT>と<DNT>**Service Usage Consumer**</DNT>のロールがあることを確認してください。
* サービスアカウントのプールプリンシパルに<DNT>**Workload Identity User**</DNT>ロールが付与されていることを確認してください。

### サービスアカウントインテグレーション [#no-data-sa]

[New Relicサービスアカウント](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account)を使用して接続した場合：

* プロジェクトのIAMにNew RelicサービスアカウントIDが表示されていることを確認してください。
* <DNT>**Viewer**</DNT>および<DNT>**Service Usage Consumer**</DNT>ロールがあることを確認します。
* [ドメイン制限の制約](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account#reqs)を使用している場合は、New Relicが許可されていることを確認してください。

## 認証エラー [#auth-errors]

### New Relicを再承認する [#reauthorize]

[Google Cloud Platform（GCP）サービスをNew Relicとインテグレーション](/docs/introduction-google-cloud-platform-integrations)する際にAPI認証エラーが発生した場合は、GCP APIを使用できるようにNew Relicを再承認してください：

1. <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP**</DNT>に移動します。
2. GCP アカウント ページから<DNT>**Reauthorize New Relic**</DNT>を選択します。
3. 標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/infrastructure/google-cloud-platform-integrations/get-started/connect-google-cloud-platform-services-new-relic)。

再認証してもエラーが解決しない場合は、インテグレーションのリンクを解除して再度接続できます。リンク解除の手順については、[接続ガイド](/docs/infrastructure/google-cloud-platform-integrations/get-started/connect-google-cloud-platform-services-new-relic)をご覧ください。

これらのエラーの一般的な理由としては、次の点があります。

* ユーザーが、Googleアカウント管理アプリケーションからGCP APIを使用するNew Relicの権限を手動で取り消しました。
* New Relic が GCP API を使用するための権限には、1 つ以上の GCP API を照会するために必要な 1 つ以上のパーミッション ([Google OAuth scopes](https://developers.google.com/identity/protocols/googlescopes)) が含まれていません。
* New Relic が GCP API を使用するための権限が失効しました。

### WIF認証エラー [#wif-auth]

## 特定のサービスのメトリクスの欠落 [#missing-metrics]

* サービスが<DNT>**Infrastructure &gt; GCP &gt; Manage services**</DNT>で有効になっていることを確認してください。
* GCPサービス自体がアクティブであり、メトリクスを生成していることを確認してください。一部のサービスは、使用中にのみメトリクスを報告します。
* [カスタムIAMロール](/docs/integrations/google-cloud-platform-integrations/get-started/integrations-custom-roles)を使用する場合は、そのサービスに固有の権限があることを確認してください。

## 古いメトリクスまたは遅延したメトリクス [#stale-metrics]

* Check the GCP Cloud Monitoring API quotas in your GCP project. If you&apos;re hitting rate limits, data collection can slow down. To request a higher quota:

  1. In the Google Cloud console, go to <DNT>**IAM &amp; Admin &gt; Quotas &amp; System Limits**</DNT>.
  2. <DNT>**Service: Cloud Monitoring API**</DNT>でフィルタリングします。
  3. Find the quota named <DNT>**Time series queries per minute**</DNT>, select it, and click <DNT>**Edit Quotas**</DNT> to request an increase.

* WIFインテグレーションの場合は、サービスアカウントのトークンが取り消されていないことを確認します。

* 報告されたエラーがないか、<DNT>**Infrastructure &gt; GCP**</DNT>のアカウントステータスダッシュボードを確認してください。

## セットアップ中にGCPプロジェクトが表示されない [#no-projects]

* プロジェクトを一覧表示するには、認証されたアカウントに`resourcemanager.projects.get`権限が必要です。
* または、NerdGraph APIを使用して、プロジェクトを一覧表示する必要なく、IDでリンクしてください。

## その他のヘルプ [#get-help]

上記のいずれの方法でも問題が解決しない場合は、以下を添えてNew Relicサポートにお問い合わせください：

* New RelicアカウントID。
* GCPプロジェクトID。
* 使用した接続方法（WIFまたはサービスアカウント）。
* UIに表示されるエラーメッセージ。
