この接続方法では、New Relicは、New Relicが管理するサービスアカウントIDとそれに関連付けられた公開鍵/秘密鍵のペアを使用して、GCPプロジェクトのAPIを呼び出します。サービスアカウントやその秘密鍵を作成または管理する必要はありません — プロジェクトの閲覧権限を持つメンバーとしてサービスアカウントIDを追加するだけです。New Relicは、この方法を使用して可能な限りタグやその他の属性を収集します。

<Callout variant="tip">
  Terraformを使用して、クラウド統合を有効にするプロセスを自動化できます。 [Terraformの公式ドキュメントサイト](https://registry.terraform.io/providers/newrelic/newrelic/latest/docs/guides/cloud_integrations_guide)でその方法をお読みください。
</Callout>

## GCPをNew Relicに接続する [#connect]

<Callout variant="important">
  New RelicでGCPを初めて設定する場合は、プロジェクトでクラウドモニタリングAPIが有効になっていることを確認してください。これは[Google Cloudコンソール](https://console.cloud.google.com/apis/api/monitoring.googleapis.com/)で行うことができます。
</Callout>

サービスアカウント認証を使用してGoogle CloudプロジェクトをNew Relicに接続するには：

1. <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP**</DNT>に移動します。 <DNT>**Google Cloud Services**</DNT>統合] ページで、 <DNT>**Add a GCP account**</DNT>を選択します。

2. <DNT>**Choose Authorization Method**</DNT>：<DNT>**Authorize a Service Account**</DNT>を選択し、UIの指示に従ってNew Relicを承認してください。

3. <DNT>**Add projects:**</DNT> New Relic がデータを受信するプロジェクトを選択します。

4. <DNT>**Select services:**</DNT> GCP アカウントで利用可能なサービスのリストから、New Relic がデータを受信する個々のサービスを選択するか、すべてのサービスを選択します。

   <Callout variant="tip">
     これらのサービスは、前の手順で選択したプロジェクトの<DNT>**all**</DNT>に対して有効になっています。セットアッププロセスが完了したら、プロジェクトごとにモニターしたいサービスを個別に微調整できます。
   </Callout>

5. セットアップ プロセスを完了するには、 <DNT>**Finish**</DNT>を選択します。

API認証エラーが表示される場合は、[トラブルシューティング手順](/docs/infrastructure/google-cloud-platform-integrations/troubleshooting/troubleshooting-gcp-integrations)に従ってください。

新しいリソースが検出され、エンティティとして合成されるまで、数分かかる場合があります。詳しくは、クラウドインテグレーションの[システム制限](/docs/data-apis/manage-data/view-system-limits)を参照してください。

## あなたのGCPデータを見る [#find-data]

接続後、New Relicは定期的な[ポーリング間隔](/docs/infrastructure/google-cloud-platform-integrations/get-started/view-your-data/polling-intervals-gcp-integrations)でGCPデータの監視を開始し、数分後にデータがNew Relic UIに表示されます。データの表示、クエリ、探索の方法 — ダッシュボード、アラート、エンティティなど — については、[GCP データの表示とクエリ](/docs/infrastructure/google-cloud-platform-integrations/get-started/view-your-data/view-and-query-your-gcp-data)をご覧ください。

## 複数のGoogleプロジェクトをリンク [#connect-multiple]

セットアッププロセスでは、一度に複数のプロジェクトを選択できます。

初回のセットアップ後、New Relicで追加のGCPプロジェクトをモニターするには、[GCPサービスを接続する](#connect)手順を必要な回数だけ繰り返します。

## GCPインテグレーションの無効化またはリンク解除 [#disconnect]

いつでも任意のインテグレーションを無効にして、Googleプロジェクトが引き続きNew Relicに接続した状態を維持できます。

### 1つ以上のGCPサービスを無効にする [#disable-services]

GCPアカウントとNew Relicの連携を維持したまま、サービスを無効にすることができます。

1. <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; Manage services**</DNT>に移動します。
2. <DNT>**Edit GCP account**</DNT>ページで、無効にする各アクティブなサービスのチェックボックスをオフにします。
3. 変更を保存します。

### アカウントの切断とリンク解除 [#unlink-account]

New Relicから完全に切断するには、GCPアカウントのリンクを解除してください。これにより、それに関連付けられたすべてのNew Relicインテグレーションが無効になります。カスタムロールを削除する場合、そのロールがNew Relicへのアクセス以外の目的で使用されている可能性があることに注意してください。

<DNT>**custom user role**</DNT>の場合:

1. New Relic にサインインし、 <DNT>**Infrastructure &gt; Integrations &gt; Google Cloud Platform**</DNT>に移動します。
2. <DNT>**IAM &gt; admin &gt; Roles**</DNT>に移動し、ロールを検索して選択し、 <DNT>**DELETE**</DNT>を選択します。

<DNT>**standard (non-custom) user role**</DNT>の場合:

1. New Relic にサインインし、 <DNT>**Infrastructure &gt; Integrations &gt; Google Cloud Platform**</DNT>に移動します。
2. 削除するアカウントの<DNT>**Manage services**</DNT>を選択します。 <DNT>**User**</DNT>の値をコピーして保存します。
3. [Google Cloud](https://console.cloud.google.com/)にログインし、 <DNT>**Select a project**</DNT>ボックスで正しいプロジェクトを選択します。
4. ナビゲーション メニューから<DNT>**IAM &amp; admin &gt; IAM**</DNT>を選択します。
5. 保存したユーザー値を検索して選択し、 <DNT>**REMOVE**</DNT>を選択します。

### リンク解除後にGCPをクリーンアップする [#clean-up]

リンク解除後にGCPプロジェクトをクリーンアップするには：

1. GCP IAMコンソールを開きます。
2. New Relicからリンクを解除するプロジェクトを選択し、<DNT>**Open**</DNT>を選択します。
3. New Relicが使用するサービスアカウントを選択してください。
4. <DNT>**Remove**</DNT>アイコンを選択します。
