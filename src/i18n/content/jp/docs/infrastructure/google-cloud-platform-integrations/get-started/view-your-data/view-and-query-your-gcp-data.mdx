設定プロセスを完了すると、Google Cloud Platformアカウントからのデータが、定期的な[ポーリング間隔](/docs/infrastructure/google-cloud-platform-integrations/get-started/view-your-data/polling-intervals-gcp-integrations)でNew Relicに直接報告されます。数分以内にNew Relic UIにデータが表示されます。

## あなたのGCPデータを見る [#view]

GCP データを表示するには:

1. <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities)**</DNT>に移動します。
2. <DNT>**Google Cloud Platform**</DNT>を検索してタイルを選択します。

<InlinePopover type="Dashboards" />および集計設定へのリンクを含む、[データを検索して使用する](/docs/infrastructure/integrations/find-use-infrastructure-integration-data)には、<DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP**</DNT>に移動します。

## データのクエリ [#query]

NRQLクエリは、事前設定された<InlinePopover type="Dashboards" />と<DNT>**Events explorer**</DNT>ダッシュボード双方で確認・再利用できます。これにより、特定のニーズに合わせてクエリを調整できます。

イベント、ダッシュボード、その他のデータは、New Relic のすべてのサービスで利用できます。

## GCPエンティティ [#entities]

完全なエンティティサポートを備えたサービスの場合、GCPリソースもエンティティエクスプローラーにエンティティとして表示されます。各エンティティには、ゴールデンメトリクスと事前構築済みのダッシュボードを備えたサマリーページがあります。

新しいリソースが検出され、エンティティとして合成されるまで、数分かかる場合があります。詳しくは、[クラウドインテグレーションのシステム制限](/docs/data-apis/manage-data/view-system-limits)を参照してください。

## 次のステップ [#whats-next]

* New Relicが各サービスについて収集するメトリクス名を調べるには、[GCPインテグレーションのメトリクス](/docs/infrastructure/google-cloud-platform-integrations/get-started/gcp-integration-metrics)を参照してください。
* New Relicがデータをポーリングする頻度については、[GCPインテグレーションのポーリング間隔](/docs/infrastructure/google-cloud-platform-integrations/get-started/view-your-data/polling-intervals-gcp-integrations)をご覧ください。
* データが期待どおりに表示されない場合は、[GCPインテグレーションのトラブルシューティング](/docs/infrastructure/google-cloud-platform-integrations/troubleshooting/troubleshooting-gcp-integrations)を参照してください。
