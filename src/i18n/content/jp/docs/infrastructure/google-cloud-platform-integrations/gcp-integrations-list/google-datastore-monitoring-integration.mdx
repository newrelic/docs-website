[Google Cloud Platform（GCP）](https://cloud.google.com/) との[ New](/docs/infrastructure/introduction-infra-monitoring) Relicインテグレーション には、[ Google Cloudデータストア](https://cloud.google.com/datastore) のデータをNew Relicに報告するものが含まれます。本ドキュメントでは、GCPデータストアインテグレーションを有効にする方法と、それが報告するデータについて解説します。

## 特徴

Cloudデータストアは、Webおよびモバイルアプリケーション向けのGoogle CloudのNoSQLドキュメントデータベースです。New Relicデータストラインテグレーションは、APIリクエスト、エンティティの読み取り/書き込み、およびインデックス書き込みメトリクスを収集し、APIメソッド、レスポンスコード、およびエンティティタイプ別に分類します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、インテグレーションによって異なるポーリング間隔に従って、GCPサービスをクエリします。Google Cloudデータストアのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、データストアのリソースがNew Relicのエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示し、サービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動してください。

GCP クラウドモニタリングで利用可能なすべてのデータストアメトリクスは、`Metric`イベントタイプでディメンショナルメトリクスとして収集されます。この表以外の追加のメトリクスは自動的に収集されます。完全なリストについては、[Googleのデータストアメトリクスのドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-datastore)をご覧ください。
