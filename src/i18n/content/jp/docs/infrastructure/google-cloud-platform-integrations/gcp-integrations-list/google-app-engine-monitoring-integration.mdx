[Google Cloud Platform（GCP）](https://cloud.google.com/) との[ New](/docs/infrastructure/introduction-infra-monitoring) Relicインテグレーション には、[ Google App Engine](https://cloud.google.com/appengine/) のデータをNew Relicに報告するものがあります。本ドキュメントでは、GCP App Engineインテグレーションを有効にする方法を解説し、報告されるデータについて説明します。

<InlinePopover type="apm" />（Google App Engineサービス自体を監視するのではなく）を使用してGoogle App Engine環境に存在するアプリケーションを監視する方法の詳細については、[Google App Engine環境](/docs/accounts/install-new-relic/partner-based-installation/google-app-engine-environment)を参照してください。

## 特徴

App Engineは、モバイルおよびウェブアプリケーションの基盤となるインフラストラクチャを抽象化するGoogle Cloud Platformのサービスです。New Relic App Engineインテグレーションは、各App Engineサービスのリクエスト、レスポンス、レイテンシ、メモリ、およびインスタンスのメトリクスを収集します。スタンダード環境とフレキシブル環境の両方がサポートされています。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、インテグレーションによって異なるポーリング間隔に従って、GCPサービスをクエリします。Google App Engineのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、App EngineリソースがNew Relicエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動します。

GCP クラウドモニタリングで利用可能なすべての App Engine メトリクスは、`Metric`イベントタイプでディメンショナルメトリクスとして収集されます。この表以外の追加のメトリクスは自動的に収集されます。完全なリストについては、[Google の App Engine メトリクスのドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-appengine)をご覧ください。

## メトリックデータ [#metrics]

NewRelicでのGoogleAppEngine統合の[指標データ](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics)を表示するには、 `GcpAppEngineServiceSample` イベントと`GcpCloudTasksQueueSample`[イベント](/docs/data-apis/understand-data/new-relic-data-types/#event-data)およびそれらに関連する属性の[NRQLクエリを作成](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql)します。

<Callout variant="important">
  アプリケーションが [標準環境で動作しているか、フレキシブル環境で動作しているかによって、利用できる測定基準が異なります。](#environments) そのため、一部の測定基準はアプリケーションで利用できない場合があります。
</Callout>
