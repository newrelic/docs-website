[Google Cloud Platform（GCP）](https://cloud.google.com/) との[ New](/docs/infrastructure/introduction-infra-monitoring) Relicインテグレーション には、[ Google Cloud Router](https://cloud.google.com/network-connectivity/docs/router) のデータをNew Relicに報告するインテグレーションが含まれています。本ドキュメントでは、GCP Cloud Routerインテグレーションを有効にする方法と、報告されるデータについて解説します。

## 特徴

Cloud Routerは、Cloud VPN、Cloud Interconnect、およびCloud NAT向けのGoogle CloudのフルマネージドBGP対応ルーティングサービスです。New Relic Cloud Routerインテグレーションは、各Cloud RouterおよびNAT GatewayのBGPセッション、ルートアドバタイズ、およびNATゲートウェイのメトリクス（オープン接続、トラフィック、ドロップされたパケット）を収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、インテグレーションによって異なるポーリング間隔に従って、GCPサービスをクエリします。Google Cloud Routerのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、Cloud RouterリソースがNew Relicエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動してください。

GCPクラウドモニタリングで利用可能なすべてのCloud Routerメトリクスは、`Metric`イベントタイプのディメンショナルメトリクスとして収集されます。この表以外の追加のメトリクスも自動的に収集されます。完全なリストについては、[GoogleのCloud Routerメトリクスドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-router)をご覧ください。
