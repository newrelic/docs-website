[New Relicインテグレーション](/docs/infrastructure/introduction-infra-monitoring)には、[Google Cloud Platform（GCP）](https://cloud.google.com/)との[Google Cloud Serverless VPC Access](https://cloud.google.com/vpc/docs/serverless-vpc-access)のデータをNew Relicに報告するものがあります。このドキュメントでは、GCP Serverless VPC Accessインテグレーションを有効にする方法と、報告されるデータについて説明します。

## 特徴

Serverless VPC Accessを使用すると、Google Cloud上のServerlessサービス（Cloud Run、Cloud Functions、App Engine）が、マネージドコネクタを介してVPCネットワーク内の内部IPリソースにアクセスできるようになります。New Relic VPC Accessインテグレーションは、各コネクタのインスタンス数、CPU、メモリ、およびネットワークスループットのメトリクスを収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、ポーリング間隔に従って、GCPサービスをクエリします。ポーリング間隔はインテグレーションによって異なります。Google Cloud Serverless VPC Accessのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、VPC AccessコネクタがNew Relicエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動します。

GCPクラウドモニタリングで利用可能なすべてのServerless VPC Accessメトリクスは、`Metric`イベントタイプのディメンショナルメトリクスとして収集されます。この表以外の追加のメトリクスは自動的に収集されます。完全なリストについては、[GoogleのServerless VPC Accessメトリクスドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-vpcaccess)をご覧ください。
