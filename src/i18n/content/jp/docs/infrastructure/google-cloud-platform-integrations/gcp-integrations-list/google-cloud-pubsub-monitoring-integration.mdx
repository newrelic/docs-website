[Google Cloud Platform（GCP）](https://cloud.google.com/) との[ New](/docs/infrastructure/introduction-infra-monitoring) Relicインテグレーション には、[ Google Cloud Pub/Sub](https://cloud.google.com/pubsub/) データをNew Relicに報告するものが含まれます。本ドキュメントでは、GCP Pub/Subインテグレーションを有効にする方法と、報告されるデータについて解説します。

## 特徴

Google Cloudの[ストリーム分析ソリューション](https://cloud.google.com/solutions/stream-analytics)の一部として、Cloud Pub/Subサービスはイベントストリームを取り込んで配信し、迅速なデータ処理と分析を行います。New Relic Pub/Subインテグレーションは、トピック、サブスクリプション、およびスナップショット全体にわたる公開、配信、バックログ、および保持のメトリクスを収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、インテグレーションによって異なるポーリング間隔に従って、GCPサービスをクエリします。Google Cloud Pub/Subのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

<Callout variant="important">
  Cloud Pub/Subは、リミテッドプレビューのWIFインテグレーションで1分のポーリング間隔をサポートしています。アクセスをリクエストするには、[New Relicサポート](https://support.newrelic.com/)にお問い合わせください。
</Callout>

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、Pub/SubリソースがNew Relicエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動します。

GCPクラウドモニタリングで利用可能なすべてのPub/Subメトリクスは、`Metric`イベントタイプのディメンションメトリクスとして収集されます。この表以外の追加のメトリクスは自動的に収集されます。完全なリストについては、[GoogleのPub/Subメトリクスドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-pubsub)をご覧ください。

## サービスアカウントまたはユーザーアカウント [#service-account]

### データを見つけて使用する [#find-data]

インテグレーションを有効化し、数分待つと（[ポーリング頻度](#polling)に基づきます）、 New Relic UIにデータが表示されます。 <InlinePopover type="dashboards" />や集計設定へのリンクを含む[データを検索して使用する](/docs/infrastructure/integrations/find-use-infrastructure-integration-data)には、 <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>にアクセスしてください。

Pub/Subトピックは、メッセージのフィードを表す名前付きエンティティで、サブスクリプションは、特定のトピックのメッセージの宛先を表す名前付きエンティティです。

NewRelicでのGCPPub/ Sub統合の[指標データ](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics)を表示するには、 `GcpPubSubTopicSample` イベントと`GcpPubSubSubscriptionSample`[イベント](/docs/data-apis/understand-data/new-relic-data-types/#event-data)およびそれらに関連する属性の[NRQLクエリを作成](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql)します。
