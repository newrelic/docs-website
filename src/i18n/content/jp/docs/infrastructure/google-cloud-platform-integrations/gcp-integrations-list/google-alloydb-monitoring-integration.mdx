[New Relic統合](/docs/infrastructure/introduction-infra-monitoring)には、[Google Cloud Platform（GCP）](https://cloud.google.com/)との[Google Cloud AlloyDB](https://cloud.google.com/alloydb)データをNew Relicにレポートするものが含まれています。本ドキュメントでは、GCP AlloyDBインテグレーションを有効にする方法と、それが報告するデータについて解説します。

## 特徴

AlloyDBは、要求の厳しいトランザクションおよび分析ワークロード向けに構築された、フルマネージドでPostgreSQL互換のデータベースサービスです。New Relic AlloyDBインテグレーションは、クラスタ、インスタンス、データベース、およびインスタンスノード全体のパフォーマンス、可用性、およびリソース使用率のメトリクスを収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、ポーリング間隔に従って、GCPサービスをクエリします。ポーリング間隔はインテグレーションによって異なります。Google Cloud AlloyDBのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

<Callout variant="important">
  AlloyDB for PostgreSQLは、リミテッドプレビューでWIFインテグレーションの1分間のポーリング間隔をサポートしています。アクセスをリクエストするには、[New Relicサポート](https://support.newrelic.com/)にお問い合わせください。
</Callout>

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、AlloyDBリソースがNew Relicエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動します。

GCPクラウドモニタリングで利用可能なすべてのAlloyDBメトリクスは、`Metric`イベントタイプのディメンショナルメトリクスとして収集されます。この表以外の追加のメトリクスは自動的に収集されます。完全なリストについては、[GoogleのAlloyDBメトリクスドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-alloydb)をご覧ください。
