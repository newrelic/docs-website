[New Relic統合](/docs/infrastructure/introduction-infra-monitoring)には、[Google Cloud Platform（GCP）](https://cloud.google.com/)との[Google Cloud Bigtable](https://cloud.google.com/bigtable)データをNew Relicに報告するものがあります。本ドキュメントでは、GCP Bigtableインテグレーションを有効にする方法と、それが報告するデータについて解説します。

## 特徴

Cloud Bigtableは、Google Cloudのフルマネージドのワイドカラム型NoSQLデータベースサービスです。New Relic Bigtableインテグレーションは、クラスタとテーブルの両方のスコープでCPU、ストレージ、レプリケーション、およびリクエストのメトリクスを収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、ポーリング間隔に従って、GCPサービスをクエリします。ポーリング間隔はインテグレーションによって異なります。Google Cloud Bigtableのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、BigtableリソースはNew Relicエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動します。

GCPクラウドモニタリングで利用可能なすべてのBigtableメトリクスは、`Metric`イベントタイプのディメンショナルメトリクスとして収集されます。この表以外の追加のメトリクスも自動的に収集されます。完全なリストについては、[Google の Bigtable メトリクス ドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-bigtable)を参照してください。
