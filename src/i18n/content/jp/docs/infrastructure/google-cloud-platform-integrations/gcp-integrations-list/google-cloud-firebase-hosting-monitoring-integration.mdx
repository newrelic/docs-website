[New Relic統合](/docs/infrastructure/introduction-infra-monitoring)と[Google Cloud Platform（GCP）](https://cloud.google.com/)には、[Google Firebase Hosting](https://firebase.google.com/products/hosting)のデータをNew Relicに報告するものが含まれます。本ドキュメントでは、GCP Firebase Hostingインテグレーションを有効にする方法を解説し、レポートされるデータについて説明します。

## 特徴

Firebase Hostingは、静的および動的なWebコンテンツ向けのGoogle Cloudのフルマネージドホスティングサービスです。New Relic Firebase Hostingインテグレーションは、各Firebase Hostingドメインのネットワークエグレスおよびストレージのメトリクスを収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、インテグレーションによって異なるポーリング間隔に従ってGCPサービスをクエリします。Google Cloud Firebase Hostingのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、Firebase HostingリソースがNew Relicエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動します。

GCPクラウドモニタリングで利用可能なすべてのFirebase Hostingメトリクスは、`Metric`イベントタイプのディメンションメトリクスとして収集されます。この表以外の追加のメトリクスは自動的に収集されます。完全なリストについては、[GoogleのFirebase Hostingメトリクスに関するドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-firebasehosting)をご覧ください。
