[Google Cloud Platform（GCP）](https://cloud.google.com/) との[ New](/docs/infrastructure/introduction-infra-monitoring) Relicインテグレーション には、[ Google Cloud Run](https://cloud.google.com/run) のデータをNew Relicに報告するものがあります。本ドキュメントでは、GCP Cloud Runインテグレーションを有効にする方法と、それが報告するデータについて解説します。

## 特徴

Cloud Runは、ステートレスなサービスや1回限りのジョブを実行するための、Google Cloudのフルマネージドのサーバーレスコンテナプラットフォームです。New Relic Cloud Runインテグレーションは、サービス（リビジョン経由）およびジョブ全体で、リクエスト、レイテンシ、コンテナ使用率、および実行メトリクスを収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、インテグレーションによって異なるポーリング間隔に従って、GCPサービスをクエリします。Google Cloud Runのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、Cloud RunリソースがNew Relicエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動してください。

GCPクラウドモニタリングで利用可能なすべてのCloud Runメトリクスは、`Metric`イベントタイプのディメンショナルメトリクスとして収集されます。この表以外の追加のメトリクスは自動的に収集されます。完全なリストについては、[GoogleのCloud Runメトリクスドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-run)をご覧ください。
