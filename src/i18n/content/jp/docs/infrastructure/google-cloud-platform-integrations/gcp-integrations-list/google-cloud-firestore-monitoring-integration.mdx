[Google Cloud Platform（GCP）](https://cloud.google.com/) との[ New](/docs/infrastructure/introduction-infra-monitoring) Relicインテグレーション には、[ Google Cloud Firestore](https://cloud.google.com/firestore) のデータをNew Relicに報告するものがあります。本ドキュメントでは、GCP Firestoreインテグレーションを有効にする方法と、報告されるデータについて解説します。

## 特徴

Firestoreは、Google CloudのサーバーレスでフルマネージドなNoSQLドキュメントデータベースです。New Relic Firestoreインテグレーションは、インスタンススコープでAPIリクエスト、ドキュメントの読み取り/書き込み、およびクォータメトリクスを収集し、さらにデータストア互換のリクエストリソースにアタッチされたリクエストレベルのメトリクスも収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、インテグレーションによって異なるポーリング間隔に従って、GCPサービスをクエリします。Google Cloud Firestoreのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、FirestoreリソースがNew Relicエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動してください。

GCPクラウドモニタリングで利用可能なすべてのFirestoreメトリクスは、`Metric`イベントタイプのディメンショナルメトリクスとして収集されます。この表以外の追加のメトリクスは自動的に収集されます。完全なリストについては、[GoogleのFirestoreメトリクスドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-firestore)をご覧ください。
