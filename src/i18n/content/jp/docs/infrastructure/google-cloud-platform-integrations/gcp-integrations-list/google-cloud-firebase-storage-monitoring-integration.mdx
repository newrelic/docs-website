[New Relicインテグレーション](/docs/infrastructure/introduction-infra-monitoring)と[Google Cloud Platform（GCP）](https://cloud.google.com/)には、[Google Firebase Storage](https://firebase.google.com/products/storage)のデータをNew Relicに報告するものがあります。本ドキュメントでは、GCP Firebase Storageインテグレーションを有効にする方法と、報告されるデータについて解説します。

## 特徴

Firebase Storageは、Cloud Storageバケットをバックエンドとする、Firebaseアプリケーションのユーザー生成コンテンツ向けのGoogle Cloudのオブジェクトストレージサービスです。New Relic Firebase Storageインテグレーションは、各バケットのFirebase Storageセキュリティルール評価メトリクスを収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、インテグレーションによって異なるポーリング間隔に従って、GCPサービスをクエリします。Google Firebase Storageのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、Firebase StorageバケットがNew Relicのエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動します。

GCPクラウドモニタリングで利用可能なすべてのFirebase Storageメトリクスは、`Metric`イベントタイプにディメンショナルメトリクスとして収集されます。完全なリストについては、[GoogleのFirebase Storageメトリクスドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-firebasestorage)をご覧ください。
