[Google Cloud Platform（GCP）](https://cloud.google.com/) との[ New](/docs/infrastructure/introduction-infra-monitoring) Relicインテグレーション には、[ Google Cloud Functions](https://cloud.google.com/functions/) のデータをNew Relicに報告するものが含まれます。このドキュメントでは、GCP Cloud Functionsインテグレーションを有効にする方法と、報告されるデータについて説明します。

## 特徴

Cloud Functionsは、イベント駆動型関数のためのGoogle Cloudのサーバーレス計算サービスです。New Relic Cloud Functionsインテグレーションは、各関数の実行回数、実行時間、メモリ使用量、およびエラー率メトリクスを収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、ポーリング間隔に従って、GCPサービスをクエリします。ポーリング間隔はインテグレーションによって異なります。Google Cloud Functionsのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、Cloud FunctionsのリソースがNew Relicエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動します。

GCPクラウドモニタリングで利用可能なすべてのCloud Functionsメトリクスは、`Metric`イベントタイプのディメンショナルメトリクスとして収集されます。この表以外の追加のメトリクスは自動的に収集されます。完全なリストについては、[GoogleのCloud Functionsメトリクスドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-cloudfunctions)を参照してください。

## サービスアカウントまたはユーザーアカウント [#service-account]

### データを見つけて使用する [#find-data]

インテグレーションをアクティブ化して数分待つと（[ポーリング頻度](#polling)に基づきます）、 UIにデータが表示されます。 <InlinePopover type="dashboards" />へのリンクや集計設定を含む[データを表示および使用する](/docs/infrastructure/integrations/find-use-infrastructure-integration-data)には、 <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動してインテグレーションを選択します。
