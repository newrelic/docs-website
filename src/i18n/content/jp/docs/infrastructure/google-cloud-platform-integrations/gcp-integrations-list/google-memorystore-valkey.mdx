[New Relicインテグレーション](/docs/infrastructure/introduction-infra-monitoring)には、[Google Cloud Platform（GCP）](https://cloud.google.com/)との[Google Memorystore for Valkey](https://cloud.google.com/memorystore/docs/valkey)のデータをNew Relicに報告するものが含まれています。このドキュメントでは、GCP Memorystore for Valkeyインテグレーションを有効にする方法と、報告されるデータについて説明します。

## 特徴

Memorystore for Valkeyは、オープンソースのRedis互換インメモリデータストアを提供する、Google CloudのフルマネージドValkeyサービスです。New RelicのMemorystore for Valkeyインテグレーションは、各ValkeyデプロイメントのCPU、メモリ、クライアント、キースペース、永続性、およびネットワーク全体にわたるインスタンスレベルおよびノード単位のメトリクスを収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity Federationとの接続](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、インテグレーションによって異なるポーリング間隔に従って、GCPサービスをクエリします。Google Memorystore for Valkeyのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、Memorystore for ValkeyリソースがNew Relicエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動します。

GCP クラウドモニタリングで利用可能なすべてのMemorystore for Valkeyメトリクスは、`Metric`イベントタイプのディメンションメトリクスとして収集されます。この表以外の追加のメトリクスは自動的に収集されます。完全なリストについては、[GoogleのMemorystoreメトリクスドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-memorystore)をご覧ください。
