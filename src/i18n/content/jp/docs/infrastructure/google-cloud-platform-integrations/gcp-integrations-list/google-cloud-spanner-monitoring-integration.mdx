[Google Cloud Platform（GCP）](https://cloud.google.com/) との[ New](/docs/infrastructure/introduction-infra-monitoring) Relicインテグレーション には、[ Google Cloud Spanner](https://cloud.google.com/spanner/) のデータをNew Relicに報告するものが含まれます。本ドキュメントでは、GCP Cloud Spannerインテグレーションを有効にする方法と、それが報告するデータについて解説します。

## 特徴 [#features]

Google Cloud Spannerは、cloud向けに構築された、グローバルに分散されたリレーショナルデータベースサービスです。New Relic Spannerインテグレーションは、各Spannerインスタンスとそこでホストされているデータベースのノード、CPU、ストレージ、セッション、APIリクエスト、およびクエリメトリクスを収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、ポーリング間隔に従ってGCPサービスをクエリします。ポーリング間隔はインテグレーションによって異なります。Google Cloud Spannerのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

<Callout variant="important">
  Cloud Spannerは、リミテッドプレビューのWIFインテグレーションにおいて、1分のポーリング間隔をサポートしています。アクセスをリクエストするには、[New Relicサポート](https://support.newrelic.com/)にお問い合わせください。
</Callout>

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、SpannerリソースはNew Relicエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動します。

GCPクラウドモニタリングで利用可能なすべてのSpannerメトリクスは、`Metric`イベントタイプのディメンションメトリクスとして収集されます。この表以外の追加のメトリクスは自動的に収集されます。完全なリストについては、[GoogleのSpannerメトリクスドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-spanner)をご覧ください。

## サービスアカウントまたはユーザーアカウント [#service-account]

### データを見つけて使用する [#find-data]

インテグレーションを有効化し、数分待つと（[ポーリング頻度](#polling)に基づきます）、 New Relic UIにデータが表示されます。 <InlinePopover type="dashboards" />や集計設定へのリンクを含む[データを検索して使用する](/docs/infrastructure/integrations/find-use-infrastructure-integration-data)には、 <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>にアクセスしてください。

NewRelicでのGCPSpanner統合の[指標データ](/docs/integrations/new-relic-integrations/getting-started/#metric)を表示するには、 `GcpSpannerInstanceSample` イベントと`GcpSpannerDatabaseSample`[イベント](/docs/data-apis/understand-data/new-relic-data-types/#event-data)およびそれらに関連する属性の[NRQLクエリを作成](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql)します。
