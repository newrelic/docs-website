[Google Cloud Platform（GCP）](https://cloud.google.com/) との[ New](/docs/infrastructure/introduction-infra-monitoring) Relicインテグレーション には、 Google[ Memorystore for Redis](https://cloud.google.com/memorystore/docs/redis) のデータをNew Relicに報告するものがあります。このドキュメントでは、GCP Memorystore for Redisインテグレーションを有効にする方法と、それが報告するデータについて説明します。

## 特徴

Memorystore for Redisは、Google CloudのフルマネージドRedisサービスです。New RelicのMemorystore for Redisインテグレーションは、各RedisインスタンスのCPU、メモリ、ネットワーク、キースペース、永続性、レプリケーション、およびコマンドスループットのメトリクスを収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、インテグレーションによって異なるポーリング間隔に従って、GCPサービスをクエリします。Google Memorystore for Redisのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、Memorystore for RedisインスタンスがNew Relicエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動します。

GCPクラウドモニタリングで利用可能なすべてのMemorystore for Redisメトリクスは、`Metric`イベントタイプのディメンショナルメトリクスとして収集されます。この表以外の追加のメトリクスは自動的に収集されます。完全なリストについては、[GoogleのMemorystore for Redisメトリクスドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-redis)をご覧ください。
