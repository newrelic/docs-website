[New Relic連携](/docs/infrastructure/introduction-infra-monitoring)と[Google Cloud Platform（GCP）](https://cloud.google.com/)には、[Google Cloud Dataflow](https://cloud.google.com/dataflow)のデータをNew Relicに報告するものが含まれます。本ドキュメントでは、GCP Cloud Dataflowインテグレーションを有効にする方法と、それが報告するデータについて解説します。

## 特徴

Cloud Dataflowは、Apache BeamをベースとしたGoogle Cloudのフルマネージドのストリーミングおよびバッチデータ処理サービスです。New RelicのDataflowインテグレーションは、各Dataflowジョブのワーカーリソース、スループット、ラグ、およびジョブ状態のメトリクスを収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、ポーリング間隔に従って、GCPサービスをクエリします。ポーリング間隔はインテグレーションによって異なります。Google Cloud Dataflowのポーリング頻度は5分です。解像度は1分ごとに1データポイントです。

<Callout variant="important">
  Cloud Dataflowは、リミテッドプレビューでWIFインテグレーションの1分間のポーリング間隔をサポートしています。アクセスをリクエストするには、[New Relicサポート](https://support.newrelic.com/)にお問い合わせください。
</Callout>

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、DataflowリソースがNew Relicエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動してください。

GCPクラウドモニタリングで利用可能なすべてのDataflowメトリクスは、`Metric`イベントタイプのディメンションメトリクスとして収集されます。この表以外の追加のメトリクスは自動的に収集されます。完全なリストについては、[GoogleのDataflowメトリクスドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-dataflow)をご覧ください。
