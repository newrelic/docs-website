[Google Cloud Platform（GCP）](https://cloud.google.com/) との[ New](/docs/infrastructure/introduction-infra-monitoring) Relicインテグレーション には、 Google[ Distributed Cloud Edge](https://cloud.google.com/distributed-cloud/edge) のデータをNew Relicに報告するものが含まれています。本ドキュメントでは、<DNT>GCP Distributed Cloud Edge</DNT>インテグレーションを有効にする方法と、報告されるデータについて解説します。

## 特徴

<DNT>Google Distributed Cloud Edge</DNT> 顧客所有のハードウェア上で<DNT>Kubernetes</DNT>ワークロードを実行するための、<DNT>Google Cloud</DNT>のマネージド型オンプレミスエッジコンピューティングプラットフォームです。New Relicの<DNT>Distributed Cloud Edge</DNT>インテグレーションは、デプロイメント内のマシン（ノード）およびエッジクラスタのハードウェアインベントリとヘルスメトリクスを収集します：CPU、メモリ、ディスク、ネットワーク、GPU、電力/PSUのテレメトリー、ならびにクラスタのライフサイクルとバージョンのステータス。

## 統合をアクティブ化する [#activate]

<Callout variant="important">
  このインテグレーションは、<DNT>GCP</DNT> プロジェクトを <DNT>**Workload Identity Federation**</DNT> に接続する場合にのみ利用可能です。サービスアカウントまたはユーザーアカウントの接続では利用できません。
</Callout>

インテグレーションを有効にするには、標準手順に従い、<DNT>**Workload Identity Federation**</DNT>を使用して[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)。

## ポーリング頻度 [#polling]

New Relicインテグレーションは、インテグレーションによって異なるポーリング間隔に従って、<DNT>GCP</DNT>サービスをクエリします。<DNT>Google Distributed Cloud Edge</DNT>のポーリング頻度は5分です。解像度は1分あたり1データポイントです。

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

New Relicは、<DNT>GCP Cloud Monitoring</DNT>で利用可能なすべての<DNT>Distributed Cloud Edge</DNT>メトリクスを、`Metric`イベントタイプでディメンショナルメトリクスとして収集します。

このインテグレーションは、New Relicエンティティエクスプローラーにエンティティを作成しません。たとえば、`Metric`イベントタイプで直接そのメトリクスをクエリします：

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'gcp.edgecontainer.%' FACET metricName
```

メトリクスは基盤となるマシンまたはエッジクラスタのリソースラベルを保持するため、エンティティなしでクラスタ名、マシンID、ロケーションでファセットできます。
