[New Relicインテグレーション](/docs/infrastructure/introduction-infra-monitoring)には、[Google Cloud Platform（GCP）](https://cloud.google.com/)との[Google Firebase Realtimeデータベース](https://firebase.google.com/products/realtime-database)のデータをNew Relicに報告するものがあります。このドキュメントでは、GCP Firebaseデータベースインテグレーションを有効にする方法と、報告されるデータについて説明します。

## 特徴

Firebase Realtime Databaseは、ユーザー間でデータをリアルタイムに保存および同期できる、Google CloudのNoSQL cloudデータベースです。New Relic Firebase Databaseインテグレーションは、各データベースネームスペースのI/O、ネットワーク、ストレージ、接続、およびセキュリティルールのメトリクスを収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、ポーリング間隔に従って、GCPサービスをクエリします。ポーリング間隔はインテグレーションによって異なります。Google Cloud Firebaseデータベースのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、FirebaseデータベースリソースがNew Relicエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動します。

GCPクラウドモニタリングで利用可能なすべてのFirebaseデータベースメトリクスは、`Metric`イベントタイプのディメンショナルメトリクスとして収集されます。この表以外の追加のメトリクスは自動的に収集されます。完全なリストについては、[GoogleのFirebaseデータベースメトリクスドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-firebasedatabase)を参照してください。
