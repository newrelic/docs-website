[New Relicインテグレーション](/docs/infrastructure/introduction-infra-monitoring)には、[Google Cloud Platform（GCP）](https://cloud.google.com/)との[Google Cloud Managed Service for Apache Kafka](https://cloud.google.com/managed-service-for-apache-kafka)のデータをNew Relicに報告するものがあります。本ドキュメントでは、GCP Managed Kafkaインテグレーションを有効にする方法と、報告されるデータについて解説します。

## 特徴

Managed Service for Apache Kafkaは、Kafka Connectを含む、Google CloudのフルマネージドでApache Kafka互換のストリーミングプラットフォームです。New Relic Managed Kafkaインテグレーションは、クラスタ、トピック、パーティション、消費者グループ、およびKafka Connectのクラスタとコネクタ全体にわたって、スループット、ラグ、リテンション、およびコネクタヘルスメトリクスを収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity Federationとの接続](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、ポーリング間隔に従ってGCPサービスをクエリします。ポーリング間隔はインテグレーションによって異なります。Google Cloud Managed Kafkaのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

<Callout variant="important">
  Managed Service for Apache Kafkaは、リミテッドプレビューでWIFインテグレーションの1分のポーリング間隔をサポートしています。アクセスをリクエストするには、[New Relicサポート](https://support.newrelic.com/)にお問い合わせください。
</Callout>

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、Managed KafkaリソースはNew Relicのエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動します。

GCPクラウドモニタリングで利用可能なすべてのManaged Kafkaメトリクスは、`Metric`イベントタイプのディメンションメトリクスとして収集されます。この表以外の追加のメトリクスは自動的に収集されます。完全なリストについては、[GoogleのManaged Kafkaメトリクスドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp_i_o#gcp-managedkafka)をご覧ください。
