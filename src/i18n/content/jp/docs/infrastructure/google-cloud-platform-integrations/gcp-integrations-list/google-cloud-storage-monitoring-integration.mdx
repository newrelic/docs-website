[Google Cloud Platform（GCP）](https://cloud.google.com/) との[ New](/docs/infrastructure/introduction-infra-monitoring) Relicインテグレーション には、[ Google Cloud Storage](https://cloud.google.com/storage) のデータをNew Relicに報告するものがあります。本ドキュメントでは、GCP Cloud Storageインテグレーションを有効にする方法と、報告されるデータについて解説します。

## 特徴

Google Cloud Storageは、ウェブサイトコンテンツの配信、アーカイブとディザスタリカバリ、および直接ダウンロードによるデータオブジェクトの配布を行うためのGCPのオブジェクトストレージサービスです。New Relic Cloud Storageインテグレーションは、各バケットのAPIリクエスト、ネットワーク、オブジェクト数、および保存バイト数のメトリクスを収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、インテグレーションによって異なるポーリング間隔に従って、GCPサービスをクエリします。Google Cloud Storageのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、Cloud StorageバケットがNew Relicエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動します。

GCPクラウドモニタリングで利用可能なすべてのCloud Storageメトリクスは、`Metric`イベントタイプにディメンショナルメトリクスとして収集されます。この表以外の追加のメトリクスは自動的に収集されます。完全なリストについては、[GoogleのCloud Storageメトリクスドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-storage)をご覧ください。

## サービスアカウントまたはユーザーアカウント [#service-account]

### データを見つけて使用する [#find-data]

インテグレーションを New Relic に接続し、数分待つと、New Relic UI にデータが表示されます。<InlinePopover type="dashboards" />や集計設定を含む[インテグレーションデータを検索して使用する](/docs/telemetry-data-platform/understand-data/new-relic-data-types/)には、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; Google Cloud Storage</DNT>に移動してください。

統合用のカスタムダッシュボードを作成するには、プロバイダー値`GcpStorageBucket`を使用して`GcpStorageBucketSample`イベントタイプの[クエリを作成します](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights)。

### GcpStorageBucketSample [#gcp-storage-bucket-sample]

統合では、 `method`と`response_code`のすべての値の[メトリックデータ](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics)が報告されます。

* `response_code`：リクエストのレスポンスコード。
* `method`：呼び出されたAPIメソッドの名前。
