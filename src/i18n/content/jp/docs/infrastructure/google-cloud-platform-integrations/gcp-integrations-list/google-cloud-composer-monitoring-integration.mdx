[Google Cloud Platform（GCP）](https://cloud.google.com/) との[ New](/docs/infrastructure/introduction-infra-monitoring) Relicインテグレーション には、[ Google Cloud Composer](https://cloud.google.com/composer) のデータをNew Relicに報告するものが含まれます。本ドキュメントでは、GCP Cloud Composerインテグレーションを有効にする方法と、それが報告するデータについて解説します。

## 特徴

Cloud Composerは、Apache Airflow上に構築されたGoogle Cloudのフルマネージドワークフローオーケストレーションサービスです。New Relic Cloud Composerインテグレーションは、環境、ワークロード、およびワークフローのメトリクス — DAGの実行、タスクインスタンス、スケジューラのハートビート、およびワーカーのリソース使用量 — を収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、インテグレーションによって異なるポーリング間隔に従って、GCPサービスをクエリします。Google Cloud Composerのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、Cloud ComposerリソースがNew Relicのエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動します。

GCPクラウドモニタリングで利用可能なすべてのCloud Composerメトリクスは、`Metric`イベントタイプのディメンショナルメトリクスとして収集されます。この表以外の追加のメトリクスは自動的に収集されます。完全なリストについては、[GoogleのCloud Composerメトリクスドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-composer)をご覧ください。
