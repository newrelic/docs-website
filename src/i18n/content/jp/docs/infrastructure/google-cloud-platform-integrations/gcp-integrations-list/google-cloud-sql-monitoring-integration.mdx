[New Relic統合](/docs/infrastructure/introduction-infra-monitoring)と[Google Cloud Platform（GCP）](https://cloud.google.com/)には、[Google Cloud SQL](https://cloud.google.com/sql/docs/)のデータをNew Relicにレポートするものが含まれます。本ドキュメントでは、GCP Cloud SQLインテグレーションを有効にする方法と、それがレポートするデータについて解説します。

## 特徴

Cloud SQLは、MySQL、PostgreSQL、およびSQL Server向けのGoogle Cloudのフルマネージドデータベースサービスです。New Relic Cloud SQLインテグレーションは、各Cloud SQLインスタンスとそのデータベースのCPU、メモリ、ディスク、接続、レプリケーション、およびデータベースレベルのメトリクスを収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、ポーリング間隔に従ってGCPサービスをクエリします。ポーリング間隔はインテグレーションによって異なります。Google Cloud SQLのポーリング頻度は5分です。解像度は1分ごとに1データポイントです。

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、Cloud SQLリソースがNew Relicエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動します。

GCPクラウドモニタリングで利用可能なすべてのCloud SQLメトリクスは、`Metric`イベントタイプにディメンショナルメトリクスとして収集されます。この表以外の追加のメトリクスは自動的に収集されます。完全なリストについては、[GoogleのCloud SQLメトリクスのドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-cloudsql)をご覧ください。

## サービスアカウントまたはユーザーアカウント [#service-account]

### データを見つけて使用する [#find-data]

インテグレーションを有効化し、数分待つと（[ポーリング頻度](#polling)に基づきます）、 New Relic UIにデータが表示されます。 <InlinePopover type="dashboards" />や集計設定へのリンクを含む[データを検索して使用する](/docs/infrastructure/integrations/find-use-infrastructure-integration-data)には、 <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>にアクセスしてください。

NewRelicでGCPSQL統合の[指標データ](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics)を表示するには、 `GcpCloudSqlSample`[イベント](/docs/data-apis/understand-data/new-relic-data-types/#event-data)とそれに関連する属性の[NRQLクエリを作成](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql)します。
