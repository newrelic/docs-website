[Google Cloud Platform（GCP）](https://cloud.google.com/) との[ New](/docs/infrastructure/introduction-infra-monitoring) Relicインテグレーション には、[ Firebase App Hosting](https://firebase.google.com/docs/app-hosting) のデータをNew Relicに報告するものが含まれています。このドキュメントでは、GCP Firebase App Hostingインテグレーションを有効にする方法と、それが報告するデータについて説明します。

## 特徴

Firebase App Hostingは、Next.jsやAngularなどのフレームワークで構築された、動的でサーバーレンダリングされるWebアプリケーション向けのGoogleのマネージドホスティングサービスです。New Relic Firebase App Hostingインテグレーションは、各App Hostingバックエンドのリクエストスループットとレスポンストラフィックボリュームを収集します。

## 統合をアクティブ化する [#activate]

<Callout variant="important">
  この統合は、GCP プロジェクトを \[Workload Identity Federation] に接続する場合にのみ利用可能です。サービスアカウントまたはユーザーアカウントの接続では利用できません。
</Callout>

インテグレーションを有効にするには、標準手順に従い、Workload Identity Federationを使用して[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)。

## ポーリング頻度 [#polling]

New Relicインテグレーションは、インテグレーションによって異なるポーリング間隔に従って、GCPサービスをクエリします。Firebase App Hostingのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

GCPクラウドモニタリングで利用可能なすべてのFirebase App Hostingメトリクスは、`Metric`イベントタイプのディメンショナルメトリクスとして収集されます。

このインテグレーションは、New Relicエンティティエクスプローラーにエンティティを作成しません。たとえば、`Metric`イベントタイプで直接そのメトリクスをクエリします：

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'gcp.firebaseapphosting.%' FACET metricName
```
