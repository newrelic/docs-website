[Google Cloud Platform（GCP）](https://cloud.google.com/) との[ New](/docs/infrastructure/introduction-infra-monitoring) Relicインテグレーション には、[ Google Compute Engine](https://cloud.google.com/compute) のデータをNew Relicに報告するものが含まれます。本ドキュメントでは、GCP Compute Engineインテグレーションを有効にする方法と、それが報告するデータについて解説します。

## 特徴

Compute Engineは、仮想マシンとアタッチされたディスク向けのGoogle Cloudのコアインフラストラクチャ・アズ・ア・サービスです。New Relic Compute Engineインテグレーションは、各VMインスタンスとその永続ディスクのCPU、メモリ、ディスク、ネットワーク、および稼働時間のメトリクスを収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、Compute EngineリソースがNew Relicエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動してください。

GCPクラウドモニタリングで利用可能なすべてのCompute Engineメトリクスは、`Metric`イベントタイプでディメンショナルメトリクスとして収集されます。この表以外の追加のメトリクスは自動的に収集されます。完全なリストについては、[GoogleのCompute Engineメトリクスドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-compute)をご覧ください。

インテグレーションを有効化し、数分待つと（[ポーリング頻度](#polling)に基づきます）、 New Relic UIにデータが表示されます。 <InlinePopover type="dashboards" />や集計設定へのリンクを含む[データを検索して使用する](/docs/infrastructure/integrations/find-use-infrastructure-integration-data)には、 <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>にアクセスしてください。
