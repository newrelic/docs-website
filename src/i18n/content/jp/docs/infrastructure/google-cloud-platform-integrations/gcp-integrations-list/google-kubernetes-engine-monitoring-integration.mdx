[New Relicインテグレーション](/docs/infrastructure/introduction-infra-monitoring)と[Google Cloud Platform（GCP）](https://cloud.google.com/)の連携には、[Google Kubernetes Engine](https://cloud.google.com/kubernetes-engine/)（GKE）のデータをNew Relicに報告するものがあります。本ドキュメントでは、GCP Kubernetes Engineインテグレーションを有効にする方法と、それが報告するデータについて解説します。

## 特徴

Google Kubernetes Engineは、Google CloudのマネージドKubernetesサービスです。New Relic GKEインテグレーションは、クラスタを構成するコンテナ、ノード、およびポッド全体のCPU、メモリ、ネットワーク、ボリューム、および稼働時間のメトリクスを収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、ポーリング間隔に従って、GCPサービスをクエリします。ポーリング間隔はインテグレーションによって異なります。Google Kubernetes Engineのポーリング頻度は5分です。解像度は1分あたり1データポイントです。

<Callout variant="important">
  **推奨：GKEにはNew Relic Kubernetesインテグレーションを使用してください。**Workload Identity Federationを使用すると、GCPインテグレーションはGKEメトリクスを収集しますが、エンティティは作成しません。完全なGKEオブザーバビリティ — クラスタ、ノード、ポッド、コンテナのエンティティ、ダッシュボード、アラート — を実現するには、GKEクラスタに[New Relic Kubernetesインテグレーション](https://docs.newrelic.com/docs/kubernetes-pixie/kubernetes-integration/installation/kubernetes-integration-install-configure/)をインストールしてください。

  Google Kubernetes Engine（GKE）は、リミテッドプレビューのWIFインテグレーションにおいて、1分のポーリング間隔をサポートしています。アクセスをリクエストするには、[New Relicサポート](https://support.newrelic.com/)にお問い合わせください。
</Callout>

## サービスアカウントまたはユーザーアカウント [#service-account]

### データを見つけて使用する [#find-data]

インテグレーションを有効化し、数分待つと（[ポーリング頻度](#polling)に基づきます）、 New Relic UIにデータが表示されます。 <InlinePopover type="dashboards" />や集計設定へのリンクを含む[データを検索して使用する](/docs/infrastructure/integrations/find-use-infrastructure-integration-data)には、 <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>にアクセスしてください。

New Relic がお客様の Google Kubernetes Engine 統合から受け取るデータには、以下のメトリックデータが含まれています。これらのメトリックの詳細については、Google のドキュメント [Metrics for Kubernetes Engine](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-container) を参照してください。
