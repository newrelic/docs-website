[Google Cloud Platform（GCP）](https://cloud.google.com/) との[ New](/docs/infrastructure/introduction-infra-monitoring) Relicインテグレーション には、 Google[ Cloud Load Balancing](https://cloud.google.com/load-balancing/) のデータをNew Relicに報告するものがあります。このドキュメントでは、GCP Cloud Load Balancingインテグレーションを有効にする方法と、報告されるデータについて説明します。

## 特徴

Cloud Load Balancingは、リージョン間でトラフィックを分散するためのGoogle Cloudのソフトウェアベースのマネージドサービスであり、HTTP(S)、TCP/SSLプロキシ、およびL4（ネットワーク）ロードバランシングをサポートしています。New Relic Load Balancingインテグレーションは、各ロードバランサーバリアントのリクエスト率、レイテンシ、バイトスループット、および接続メトリクスを収集します。

## 統合をアクティブ化する [#activate]

このインテグレーションを有効にするには、標準手順に従い、[GCPサービスをNew Relicに接続します](/docs/connect-google-cloud-platform-services-infrastructure)：

* [ワークロード Identity 連携で接続（推奨）](/docs/connect-google-cloud-platform-services-infrastructure)
* [サービスアカウントまたはユーザーアカウントで接続します。](/docs/connect-google-cloud-platform-services-infrastructure)

## ポーリング頻度 [#polling]

New Relicインテグレーションは、ポーリング間隔に従って、GCPサービスをクエリします。ポーリング間隔はインテグレーションによって異なります。Google Cloud Load Balancingのポーリング頻度は5分です。解像度は1分ごとに1データポイントです。

<Callout variant="important">
  Cloud Load Balancingは、リミテッドプレビューのWIFインテグレーションに対して1分のポーリング間隔をサポートしています。アクセスをリクエストするには、[New Relicサポート](https://support.newrelic.com/)にお問い合わせください。
</Callout>

## ワークロード Identity Federation [#wif]

### データを見つけて使用する [#find-data-wif]

インテグレーションを有効にすると、Cloud Load BalancingリソースがNew Relicエンティティエクスプローラーにエンティティとして表示されます。ダッシュボードを表示してサービスを管理するには、<DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>に移動します。

GCPクラウドモニタリングで利用可能なすべてのCloud Load Balancingメトリクスは、`Metric`イベントタイプのディメンショナルメトリクスとして収集されます。この表以外の追加のメトリクスは自動的に収集されます。完全なリストについては、[GoogleのCloud Load Balancingメトリクスドキュメント](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-loadbalancing)をご覧ください。
