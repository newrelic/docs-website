### 新機能

* Debian 13（Trixie）のネイティブパッケージが利用可能になりました。
* Windows Server 2025（LTSC）のネイティブパッケージが利用可能になりました。
* [Fluent Bit OutputプラグインのDockerイメージ](https://hub.docker.com/r/newrelic/newrelic-fluentbit-output)で、Windows Server 2025（LTSC）のバリアントが公開されるようになりました。

### 改善と強化

* Fluent Bitがバージョン5.1.5にアップグレードされました。詳細については、[Fluent Bitのアナウンス](https://fluentbit.io/announcements/)を参照してください。
* このリリースには、[New Relic Fluent Bit Outputプラグイン 3.12.0](https://github.com/newrelic/newrelic-fluent-bit-output/releases/tag/v3.12.0)が含まれています。
* infrastructureエージェントは、Fluent Bit 5.1.5のLinuxおよびWindows向けパッケージを推奨しています。
* Linux向けの[Fluent Bit OutputプラグインのDockerイメージ](https://hub.docker.com/r/newrelic/newrelic-fluentbit-output)は、Fluent Bit 5.1.5およびOutputプラグイン 3.12.0を使用しています。WindowsイメージのバリアントにはOutputプラグイン 3.12.0が含まれており、既存のFluent Bitバージョンが維持されます：5.1.2（Windows Server 2022および2025向け）、および4.0.3（Windows Server 2019向け）。
* [New Relic Logging Helmチャート](https://github.com/newrelic/helm-charts/tree/master/charts/newrelic-logging)はバージョン1.44.0にアップデートされ、新しいプラグインイメージをインストールします。
* ディストリビューションがサポート終了を迎えたため、Debian 11（Bullseye）のパッケージはビルドされなくなりました。

### セキュリティアップデート

* 侵害されたeMudhra中間CAキーのブロックなど、CVE修正のためにGoのバージョンが1.27.3にアップグレードされました。
* LinuxのDockerイメージは、emSign ECC Root CA - G3およびAAA Certificate Servicesのルート証明書を信頼しなくなりました。
