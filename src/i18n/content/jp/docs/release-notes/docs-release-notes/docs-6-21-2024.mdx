### 新しいドキュメント

* Errors Inboxのモバイルクラッシュに関するすべてのドキュメントを、単一の[モバイルグループクラッシュタブ](/docs/triage-inbox/mobile-tab)に統合しました。
* 新しい[モデルデータの分析](/docs/ai-monitoring/explore-ai-data/view-model-data)では、AIモニタリングを使用してモデルのパフォーマンスを監視するさまざまな方法について説明しています。
* 新しい[Google VertexAI監視インテグレーション](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-vertexai-monitoring-integration)では、インテグレーションを有効にして監視を開始する方法を説明しています。
* 新しい[NVIDIA Jetsonインテグレーション](/docs/infrastructure/host-integrations/host-integrations-list/nvidia-jetson-integration)では、NVIDIA Jetsonデバイスをモニターする方法について説明しています。

### 主な変更点

* Pythonエージェントの設定に、[`STARTUP_DEBUG`](/docs/apm/agents/python-agent/configuration/python-agent-configuration/#NEW_RELIC_STARTUP_DEBUG)の情報を追加しました。
* [モバイル監視の設定](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/configure-settings/#android-background-reporting)に、Androidのバックグラウンドおよび`ApplicationExitInfo`レポートの有効化と無効化に関する情報を追加しました。
* アラートナビゲーションの大幅な刷新により、アラートの作成、設定、管理、使用に至るユーザージャーニーがより明確に示されるようになりました。

### マイナーチェンジ

* 両者をより似たものにするべきだという顧客からのフィードバックを受け、[iOS](/docs/mobile-monitoring/new-relic-mobile-ios/configuration/app-launch-times-ios-apps)と[Android](/docs/mobile-monitoring/new-relic-mobile-android/install-configure/configure-app-launch-time-android-apps)のアプリのリリース時間のドキュメントの構造を統一しました。
* [インフラストラクチャログ](/docs/infrastructure/install-infrastructure-agent/get-started/requirements-infrastructure-agent)がUbuntu 24.04（Noble Numbat）をサポートするようになりました。
* [Node.js](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent)および[.NET Coreとフレームワーク](/docs/apm/agents/net-agent/configuration/net-agent-configuration/)の互換性を更新しました。
* AIモニタリングのインストレーションガイドに、[Javaエージェントの設定](/install/ai-monitoring/?agent-lang=java)およびその他の利便性の向上を追加しました。
* [AWS PrivateLink](/docs/data-apis/custom-data/aws-privatelink/#us-endpoints-use1)のNew Relic REST APIエンドポイントを追加しました。
* 当社の[Oracleデータベースインテグレーション](/docs/infrastructure/host-integrations/host-integrations-list/oracle-database-monitoring-integration/#comp-req)は、バージョン23までサポートするようになりました。
* [HAProxyインテグレーション](/docs/infrastructure/host-integrations/host-integrations-list/haproxy-monitoring-integration)は、バージョン3.xまでサポートするようになりました。
* [.NETエージェント](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements/)はジャストインタイム（JIT）コンパイルを必要とするため、Native Ahead of Time（AOT）デプロイメントをサポートしていないことを明確にしました。
* [Linkerdインテグレーションのメトリクスを公開する](/docs/infrastructure/host-integrations/host-integrations-list/linkerd-integration/#expose-linkerd-metrics)方法に関する新しい手順を追加しました。
* 新しいJira UIを表示するように、[Atlassian Jiraインテグレーション](/docs/more-integrations/open-source-telemetry-integrations/atlassian/atlassian-integration/#different-organization)のスクリーンショットを更新しました。
* [外形監視](/docs/synthetics/synthetic-monitoring/private-locations/monitor-private-locations/#minion-status)のプライベートロケーションのジョブマネージャーのエンドポイントを追加しました。
* [.NETエージェントの設定](/docs/apm/agents/net-agent/configuration/net-agent-configuration)のコードブロックのスタイルを更新しました。
