### 新しいドキュメント

* ガイド付きセットアップ、ホスト型およびAmazon RDSの設定、マルチレシーバーのセットアップ、完全なメトリクスリファレンスをカバーする、パブリックプレビューのインテグレーションとして[OpenTelemetry経由のMySQL監視](/docs/opentelemetry/database/mysql/introduction)を追加しました。
* ガイド付きセットアップ、ホスト型およびAmazon RDSの設定、`EXPLAIN`の権限、完全なメトリクスリファレンスを網羅したパブリックプレビューのインテグレーションとして、[OpenTelemetry経由のPostgreSQL監視](/docs/opentelemetry/database/postgresql/introduction)を追加しました。
* カスタムCA証明書、mTLS、Terraform自動化などの外形監視のプライベートロケーション機能を統合するために、[プライベートロケーション機能](/docs/synthetics/synthetic-monitoring/guides/private-location-capabilities)を追加しました。
* ユーザーごとの月間計算予算を設定するための[計算ユーザー制限](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/compute-budgets/compute-user-limits)を追加し、一般提供を開始しました。
* クラッシュ、エラー、またはANRに至るイベントのシーケンスを示すために、[モバイルユーザー・ジャーニー](/docs/mobile-monitoring/mobile-monitoring-ui/mobile-app-pages/user-journeys)を追加しました。
* OracleまたはSQL Serverデータベースに対してカスタムSQLクエリを実行し、その結果をメトリクスとして取り込むためのパブリックプレビュー機能として、[SQLクエリレシーバーの設定](/docs/opentelemetry/database/capabilities/sql-query-receiver)を追加しました。

### 主な変更点

* AlloyDB、Bigtable、Firestore、Vertex AIを含む18の追加サービスの権限を持つように、[GCPインテグレーションのカスタムロール](/docs/infrastructure/google-cloud-platform-integrations/get-started/integrations-custom-roles)を更新しました。
* インストレーション、権限の付与、マルチレシーバーの設定など、Oracle Autonomous Database（ADB）を完全にサポートするように、[NRDOTを使用したOracleデータベース監視](/docs/opentelemetry/database/otel-oracledb)を更新しました。

### マイナーチェンジ

* デフォルトのモバイルイベント収集サイクルが600秒ではなく60秒であることを明記するように、[カスタムイベントと属性の報告](/docs/data-apis/custom-data/custom-events/report-mobile-monitoring-custom-events-attributes)および[最大イベントプールサイズの設定](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/set-max-event-pool-size)を修正しました。
* カスタムの組織スコープのロールが、新しい組織スコープの機能に対する権限を自動的に受け取らないことを、[ユーザー管理の概念](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts)で明確にしました。
* [複数のユーザーレコードの管理](/docs/accounts/accounts-billing/account-setup/multiple-user-records)において、同じメールアドレスを持つユーザーレコード間の切り替えにはユーザーメニューの「他のユーザー」オプションを使用することを明確にしました。
* 包含/除外トグルが共有変数バーではなく、各変数独自のドロップダウンにあることを[ダッシュボードテンプレート変数](/docs/query-your-data/explore-query-data/dashboards/dashboard-template-variables)で明確にしました。
* コストデータには従来のAzureインテグレーションを有効にしておく必要があることを、[Azure Cost Management監視インテグレーション](/docs/infrastructure/microsoft-azure-integrations/azure-integrations-list/azure-cost-management-monitoring-integration)で明確にしました。
* ノートブックには詳細な権限設定がないという、[ノートブックの共有](/docs/query-your-data/explore-query-data/notebooks/share-notebooks)の古いメモを削除しました。
* [NerdGraph Teamsチュートリアル](/docs/apis/nerdgraph/examples/nerdgraph-teams-tutorial)に`onCallMembers`フィールドのカバレッジを追加しました。
* GCPクラウドモニタリングAPIの割り当て増加をリクエストする手順を、[GCPインテグレーションのトラブルシューティング](/docs/infrastructure/google-cloud-platform-integrations/troubleshooting/troubleshooting-gcp-integrations)に追加しました。
* [チームの管理](/docs/service-architecture-intelligence/teams/manage-teams)でチームメンバーにオンコールロールを割り当てるためのガイダンスを追加しました。
* `ApplicationHost.config`を介したIISでホストされるアプリケーションの[.NETエージェントの環境変数](/docs/apm/agents/net-agent/other-installation/understanding-net-agent-environment-variables)の設定に関するセクションを追加しました。
* 必須の`GENERATE_CONFIG`および`LICENSE_KEY`パラメーターの欠落を最も一般的な原因として優先するように、[Windows MSIのインストールがエラー1603で失敗する](/docs/infrastructure/infrastructure-troubleshooting/troubleshoot-infrastructure/windows-msi-install-fails-error-1603)を再構築しました。
* デフォルトのサイレントインストールコマンドに必須の`GENERATE_CONFIG`および`LICENSE_KEY`パラメーターが含まれるように、[Windows MSIインストーラ](/docs/infrastructure/infrastructure-agent/windows-installation/windows-msi-installer)を更新しました。
