### 新しいドキュメント

* New RelicのChange Tracking (変更追跡機能)を使用して、アプリケーションとインフラストラクチャ全体にわたる変更を追跡するために、[Change Tracking (変更追跡機能) イベント](/docs/change-tracking/change-tracking-events/)を追加しました。システムへの影響を理解するために、変更をキャプチャ、視覚化、分析します。
* Prometheusエージェントをバージョン2にアップグレードする[手順](/docs/infrastructure/prometheus-integrations/migrations/v2-upgrade/)を追加しました。
* ネストされた変数とは何か、またダッシュボードでの使用方法について解説する[ドキュメント](/docs/query-your-data/explore-query-data/dashboards/nested-variables/)を追加しました。

### 主な変更点

* .NETエージェント向けの[アプリケーションが起動時にハングアップする](/docs/apm/agents/net-agent/troubleshooting/app-hangs-on-startup/)トラブルシューティングガイドを追加しました。

* Windows - Microsoft SQL Serverに関する[オンホストインテグレーションを手動で実行する（ドライラン）](/docs/infrastructure/host-integrations/troubleshooting/run-integrations-manually/)の例（アドミニストレーターのPowerShellから）を追加しました。

* [Browser API向けMeasure API](/docs/browser/new-relic-browser/browser-apis/measure/)を追加しました。

* 8.21.0 Javaエージェントリリース用に、[Javaエージェント設定ファイルのテンプレート](/docs/apm/agents/java-agent/configuration/java-agent-config-file-template/)を追加しました。

* [セキュリティとアクセスのドキュメント](/docs/query-your-data/explore-query-data/dashboards/prerequisites-to-share-dashboards-charts/)で、ダッシュボードとチャートの共有に必要なユーザータイプを更新しました。

* Github CopilotおよびGemini向けのNew Relic AIエージェントインテグレーションが一般提供されました。次のようにドキュメントを更新しました。

  * [GitHub CopilotとNew Relic AIエージェントのインテグレーション](/docs/agentic-ai/agentic-integration/github-copilot-integration/)
  * [GeminiとのNew Relic AIエージェントインテグレーション](/docs/agentic-ai/agentic-integration/gemini-integration/)

* Browserエージェント バージョン1.259.0以降のセッションリプレイ設定に関するサーバーサイドコンフィグレーションの変更を反映するため、『[New Relicでのセッションリプレイの表示](/docs/browser/browser-monitoring/browser-pro-features/session-replay/view-session-replays/)』ドキュメントを更新しました。

* 退職した社員のアカウント無効化および定期監査に関する情報を、『[New Relicのデータプライバシー](https://docs.newrelic.com/docs/security/security-privacy/data-privacy/data-privacy-new-relic/#account-security)』および『[セキュリティポリシー](/docs/licenses/license-information/referenced-policies/security-policy/)』ドキュメントに追加しました。

* [Browserアプリケーション用のメディアビデオエージェントをインストールする](/install/browser-media/)方法を解説するドキュメントに、更新された設定を追加しました。

### マイナーチェンジ

* Javaエージェントの[互換性要件](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent/)を更新しました。
* Browserエージェントの`start()` APIの機能リストに[ロギング](/docs/browser/new-relic-browser/browser-apis/start/#feature-names)を追加しました。
* `NEW_RELIC_ATTRIBUTES_HTTP_ATTRIBUTE_MODE=both`で『[Javaエージェント設定：設定ファイル](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file/)』を更新しました。
* [Javaエージェントのライセンス](/docs/licenses/product-or-service-licenses/new-relic-apm/java-agent-licenses/)を更新しました。
* インデックス化されたドキュメントの可視性が組織のポリシーに準拠していることを確認するためのコールアウトを、[New Relic AI Knowledge Connector](/docs/agentic-ai/knowledge-integration/overview/)および[RAGツールとドキュメント設定](/docs/apis/nerdgraph/examples/nerdgraph-rag/)のドキュメントに追加しました。
* [SDKベースの計装](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/sdk-based-instrumentation/)のドキュメントにおいて、New Relic AWS Lambda OpenTracing Java SDKライブラリのバージョン3.0.0のAWS依存関係のバージョンを更新しました。
* <DNT>**[Predictive alerts](/docs/alerts/create-alert/set-thresholds/predictive-alerts)**</DNT>ドキュメントのタイトルを更新しました。以前のタイトルは<DNT>**Predictive capability**</DNT>でした。
* ソースマップの最大アップロード制限の改訂に伴い、『[ソースマップAPI](/docs/browser/new-relic-browser/browser-pro-features/upload-source-maps-api/)』ドキュメントを更新しました。
* [.Netエージェントの互換性と要件](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements/)ドキュメントを最新の互換バージョンで更新しました。
* 従量課金プランおよびインプロセス関数モデルでのLinux OSがサポート対象外であることに関する情報を記載し、『[Azure Functionsの監視](/docs/serverless-function-monitoring/azure-function-monitoring/install-serverless-azure-monitoring/)』ドキュメントを更新しました。
* [互換性と要件](/docs/serverless-function-monitoring/azure-function-monitoring/compatibility-requirement-azure-monitoring/)ドキュメントにおいて、インストゥルメントされたAzure Functionsのインストレーション方法を更新しました。具体的には、Azure Site Extensionを使用するWindows向けの環境変数の手順を調整しました。
* カスタムタグをサポートするJavaエージェントのバージョンを記載し、『[アプリケーションログのカスタムタグ](/docs/logs/logs-context/custom-tags-agent-forwarder-logs/)』ドキュメントを更新しました。
* [addToTrace](/docs/browser/new-relic-browser/browser-apis/addtotrace/) APIドキュメントにUnixタイムスタンプの要件を追加しました。
* [Node.jsエージェントの互換性と要件](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent/)を更新しました。
