### 新しいドキュメント

* APMエージェントのサンプラーコンテキスト、サンプラータイプ、および適応型サンプリングのターゲットを網羅した、[サンプリングの設定](/docs/apm/distributed-tracing/distributed-trace-sampling/)を追加しました。
* 不均等なエンドポイントのカバレッジやアップストリームサンプリングの不均衡を修正するための、実際の環境でコピーしてすぐに使える設定を記載した関連ページ、[サンプラー設定の例](/docs/apm/distributed-tracing/sampler-configuration-examples/)を追加しました。
* Cloud Cost Intelligenceの[権限とロール](/docs/cci/configure-cci/cci-permissions/)を追加しました。これには、デフォルトの読み取り専用アクセスや、組織の管理者が既存または専用のカスタムロールを通じて変更アクセス権を付与する方法が含まれます。

### 主な変更点

* OpenTelemetryのデータベース監視ドキュメントを&quot;Database monitoring&quot;から[Database 360（DB360）](/docs/opentelemetry/db360/introduction/)に名前変更および再構成し、MSSQL、MySQL、Oracle、PostgreSQL向けのCLI、Ansible、Chef、Helm、Dockerのインストール方法のページを追加しました。これには、MSSQLおよびMySQLセクションの新しいUiPath関連のインストールフローが含まれます。
* [Errors Inbox](/docs/triage-inbox/errors-inbox/)とその関連ページを**Triage inbox**に名前変更し、APM、ブラウザおよびモバイルのドキュメント全体で古いErrors Inboxのパスへの相互参照を更新しました。
* [Introduction to New Relic for Node.js](/docs/apm/agents/nodejs-agent/getting-started/introduction-new-relic-nodejs/)を含む、Node.jsエージェントのページを再構築しました、明確性と一貫性のための、HerokuおよびAzureのホスティング、ソースマップ、ESモジュール、Dockerのインストール、更新、およびトラブルシューティング。
* [スケジュールされたNRQL検索とレポート](/docs/nrql/using-nrql/schedule-nrql-searches/)が一般提供されました。権限、スケジュール設定、および管理の詳細でドキュメントを更新し、[ログUIの使用](/docs/logs/ui-data/use-logs-ui/)からリンクしました。
* [Intelligent Workloads](/docs/new-relic-solutions/new-relic-one/workloads/create-intelligent-workload/)が一般提供されました。推奨事項からのワークロードの一括作成と、依存関係グラフのスコープを絞り込むための除外フィルターを追加しました。
* [Standard ワークロード](/docs/new-relic-solutions/new-relic-one/workloads/use-workloads/)、Intelligent ワークロード、およびTransaction 360のドキュメント全体で、Summaryページのコンテンツとスクリーンショットを更新しました。これには、Transaction 360ビューをIntelligent ワークロードに昇格させることに関する新しいセクションが含まれています。
* モバイルエージェント（Android v7.8.3+およびiOS v7.7.8+）がW3Cトレースコンテキストヘッダーのみを送信し、レガシーな独自の`newrelic`ヘッダーを送信しなくなったことを反映するために、ディストリビューティッド（分散）トレーシングの計画ガイドである[New Relicディストリビューティッド（分散）トレーシングの仕組み](/docs/distributed-tracing/concepts/how-new-relic-distributed-tracing-works/)を更新しました。

### マイナーチェンジ

* [複合アラート](/docs/alerts/create-alert/create-alert-condition/compound-alerts/compound-alerts/)に制限事項のメモを追加しました。
* パブリックダッシュボードのライブURLに固定のIANA（Internet Assigned Numbers Authority）タイムゾーン識別子を固定するための`time_zone`クエリパラメーターを[パブリックダッシュボードのドキュメント](/docs/query-your-data/explore-query-data/dashboards/share-dashboards-publicly/)に追加しました。これにより、閲覧者のローカルブラウザのタイムゾーンに関係なく、タイムスタンプと相対的な時間範囲が一貫して表示されます。
* [ダッシュボードのテンプレート変数](/docs/query-your-data/explore-query-data/dashboards/dashboard-template-variables/)が、ウィジェットの説明での`{{variable}}`プレースホルダーをサポートするようになりました。
* [データ保持期間の理解と管理](/docs/data-apis/manage-data/manage-data-retention/)に`DBMonitoring`ネームスペースを追加しました。
* [CCIの推奨事項](/docs/cci/financial-intelligence/cci-recommendations/)を更新しました。
* [計算予算：ユーザー制限](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/compute-budgets/compute-user-limits/)に日次頻度のガイダンスを追加しました。
* AIノード関係の[高度なマップ](/docs/service-architecture-intelligence/maps/advanced-maps/)を更新しました。
* [プライベートロケーションの機能](/docs/synthetics/synthetic-monitoring/guides/private-location-capabilities/)および[プライベートロケーションのKerberos（SPNEGO）認証サポート](/docs/synthetics/synthetic-monitoring/private-locations/synthetics-kerberos-auth-support/)におけるKerberos機能のガイダンスを拡充しました。
* [.NETエージェントのAppDomainキャッシュのトラブルシューティング](/docs/apm/agents/net-agent/troubleshooting/lock-contention-appdomain-getdata/)ドキュメントを修正しました。
* [処理済み例外](/docs/mobile-monitoring/mobile-monitoring-ui/crashes/handled-exceptions-analyze-trends-prevent-crashes/)、[Flutterアプリケーションのモニター](/docs/mobile-monitoring/new-relic-mobile-flutter/monitor-your-flutter-application/)および[.NET MAUIアプリケーションのモニター](/docs/mobile-monitoring/new-relic-mobile-maui-dotnet/monitor-your-net-maui-application/)における、Flutterおよび.NET MAUIのクラッシュ処理に関するガイダンスを更新しました。
* [Node.jsエージェントの互換性と要件](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent/)および[.NETエージェントの互換性と要件](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements/)を更新しました。
* [AWS LambdaのSDKベースの計装](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/sdk-based-instrumentation/)のドキュメントを修正しました。
* セルの重大度に関する[Kubernetesサマリーページ](/docs/apm/apm-ui-pages/monitoring/kubernetes-summary-page/)を更新しました。

### 新機能

* [スケジュールされた検索とレポートが一般提供されました](/whats-new/2026/10/whats-new-10-05-scheduled-search-reporting-ga)：独自のスケジュールでNRQLクエリを実行し、結果が定義した条件を満たしたときに通知を受け取ります。
* [Terraformを使用したNew Relic Notebooksの管理](/whats-new/2026/10/whats-new-10-06-notebooks-terraform)：完全なCRUDサポートとプログラムによるアクセスを備えたTerraformを使用して、New Relic Notebooksを定義、管理およびプロビジョニングします。
* [IntelligentワークロードおよびStandardワークロードの更新](/whats-new/2026/10/whats-new-10-08-Workloads-GA)：Intelligentワークロードが一括作成および除外フィルターを備えてGAになり、Standardワークロードには対応するサマリーページと集計ベースのヘルス設定のサポートが追加されました。
* [パフォーマンス・リスク・インボックスが一般提供されました](/whats-new/2026/10/whats-new-10-08-performance-risks-inbox)：パフォーマンス・リスク・インボックスのGAにより、アカウントレベルの概要、ワークロードのサポート、AI生成のインサイト、およびNew Relic MCPサーバーのサポートが追加されます。
* [トップレベルのナビゲーションラベル「Errors Inbox」が「Triage Inbox」に変更されました](/whats-new/2026/10/whats-new-10-08-triage-inbox-nav-label)：Errors InboxのメインナビゲーションエントリがTriage Inbox（Errors Inbox）に名前変更されました。これはラベルのみの変更であり、新しいページや機能はありません。
