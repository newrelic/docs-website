### 新しいドキュメント

* KDCおよびSPNEGO Webサーバーのセットアップと外形監視ジョブマネージャーの設定を含む、[プライベートロケーションのKerberos（SPNEGO）認証サポート](/docs/synthetics/synthetic-monitoring/private-locations/synthetics-kerberos-auth-support/)を追加しました。
* フリートごとのスコープ設定、ライフサイクルの分離、委任されたグループ管理、ビジネスユニットの分離に関するロールベースのアクセスパターンをカバーする、[Fleet Controlアクセスの管理](/docs/new-relic-control/fleet-control/access-management/)を追加しました。
* 以前のReinstrumentationページに代わり、ゼロからの計装のセットアップや、Kubernetes、Linux、Windows上の既存のエージェントの移行について説明する[Agent Controlを使用したシステムの計装](/docs/new-relic-control/agent-control/instrumentation/)を追加しました。
* フロー、ヘルスインジケーター、KPI、およびNerdGraphの管理を含む、パブリックプレビュー向けの[Pathpoint（更新版）](/docs/pathpoint/get-started-pathpoint/)のドキュメントを追加しました。
* レポートされるデータ、有効化、ポーリング頻度、およびワークロード Identity Federationを網羅する、[Google Distributed Cloud Edge監視インテグレーション](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-distributed-cloud-edge-monitoring-integration/)を追加しました。
* 集計に対してAutopilotの根本原因分析を実行し、HTMLレポートをメールで送信する方法を示す[Autopilotとメールを使用した集計のRCA](/docs/workflow-automation/workflow-examples/integrations/autopilot-email-rca/)と、[Autopilot RCAワークフローテンプレート](/docs/workflow-automation/workflow-examples/integrations/autopilot-rca/)の概要を追加しました。
* Workflow Automationのアクションカタログに[Azure Monitorログのクエリ](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-monitor-querylogs/)アクションを追加しました。
* ワークフロー自動化アクションカタログに[Azure Cosmos DBアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-cosmos-db/)を追加しました。
* ワークフロー自動化アクションカタログに[AWS Resource Groups タグ API アクション](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/resourcetagging/aws-resourcetagging/)を追加しました。
* New Relicエンティティのタグを追加、置換、削除するための[New Relicタグアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging/)を、ワークフロー自動化アクションカタログに追加しました。

### 主な変更点

* 更新されたエンティティマップエクスペリエンスに合わせて、[トレース詳細UIページを理解する](/docs/distributed-tracing/ui-data/trace-details/)を書き直しました。
* [エージェントタイプ](/docs/new-relic-control/agent-control/agent-types/)を拡張し、`protocol_version`フィールド、各変数フィールドのリファレンス、およびKubernetesとオンホストの個別のデプロイメントセクションを追加しました。
* [エージェント設定の変更](/docs/new-relic-control/pipeline-control/gateway/modify-agent-configuration/)に、New Relic APMエージェント、OpenTelemetry Collector、eBPF自動アタッチエージェント、およびinfrastructureエージェントのエージェントごとの設定例を、サポートされているエージェントとバージョンの互換性マトリックスとともに追加しました。
* Pipeline Controlゲートウェイの[概要](/docs/new-relic-control/pipeline-control/gateway/overview/)、[UIガイド](/docs/new-relic-control/pipeline-control/gateway/ui-guide/)、および[YAML設定リファレンス](/docs/new-relic-control/pipeline-control/gateway/yaml-overview/)を更新し、Pipelineの任意のステージにおけるサンプルレート、フィルター、変換プロセッサの追加と削除についてドキュメント化しました。

### 新機能

* [セッションリプレイに独自の請求カテゴリが追加されました](/whats-new/2026/09/whats-new-09-28-session-replay-billing-category)：Browserおよびモバイルのセッションリプレイデータは、Browserおよびモバイルのイベントとは別に、新しい請求カテゴリで報告されます。
* [インテリジェントなクラスタを備えた新しいトレースマップエクスペリエンス](/whats-new/2026/09/whats-new-09-28-trace-map-clustering)：トレースマップで重要度の高いサービスが表示されたままになり、ロングテールがクラスタに折りたたまれるようになったため、ボトルネックや障害が発生しているサービスが目立つようになりました。
* [New Relic Controlのホストベースのフリートが一般提供されました](/whats-new/2026/09/whats-new-09-29-host-support-ga)：Agent ControlおよびFleet Control向けのLinuxおよびWindowsのホストベースのフリートが一般提供され、設定承認ガバナンス、リモートエージェントのアップグレード、監査ログ、およびオンホストインテグレーションをサポートしています。
* [`{{selfEntity}}`を使用してどこからでも現在のダッシュボードを参照する](/whats-new/2026/09/whats-new-09-29-selfentity-dashboard-variable): 新しいテンプレート変数が現在のダッシュボードのエンティティGUIDに解決されるため、ダッシュボードを複製した後も、クエリ、ウィジェット名、およびファセットリンクが正確に保たれます。
* [Pathpointの更新版がパブリックプレビューで利用可能になりました](/whats-new/2026/09/whats-new-09-30-pathpoint-2-0): 最も重要なビジネスジャーニーを、それを支えるテレメトリーにマッピングします。プログラムによる管理とより豊富なKPIが利用可能になりました。
* [Pipeline Controlを使用して、必要な場所にPipelineプロセッサを配置する](/whats-new/2026/09/whats-new-09-30-pipeline-control-processors)：Pipelineの任意のポイントで、Sample Rate、Filter、およびTransformプロセッサを追加、並べ替え、削除します。
