### 新しいドキュメント

* ディストリビューティッド（分散）トレーシングとサービス関係のHAProxy OTelフィルターのセットアップをカバーするために、[HAProxyディストリビューティッド（分散）トレーシング](/docs/opentelemetry/integrations/haproxy/distributed-tracing/)を追加しました。
* `ngx_otel_module`を使用したNGINXのOTelベースのディストリビューティッド（分散）トレーシング設定をカバーする、[NGINXディストリビューティッド（分散）トレーシング](/docs/opentelemetry/integrations/nginx/nginx-otel-distributed-tracing/)を追加しました。
* 概要、Kubernetesのセットアップ、ディストリビューティッド（分散）トレーシング、および完全なメトリクスリファレンスを網羅した、[OpenTelemetryによるLinkerdの監視](/docs/opentelemetry/integrations/linkerd/introduction/)を追加しました。
* `es.cluster.name`のハードコーディングに代わる、よりシームレスな代替手段である[APM ↔ Elasticsearchディストリビューティッド（分散）トレーシングの相関関係](/docs/opentelemetry/integrations/elasticsearch/distributed-tracing/)を追加しました。
* OpenTelemetry経由でのMSSQL監視用の[マルチレシーバー設定](/docs/opentelemetry/database/mssql/multi-receiver/)ガイドを追加しました。
* ワークフロー自動化のアクションカタログに[AWS Step Functionアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/stepfunctions/aws-stepfunctions/)を追加しました。

### 主な変更点

* 新しいインラインフィルターのピルやトグルなど、再設計されたトレースリストのインターフェースに合わせて、[ディストリビューティッド（分散）トレーシングUIデータ](/docs/distributed-tracing/ui-data/understand-use-distributed-tracing-ui/)ページを書き直しました。
* [OpenTelemetryによるOracle DBの監視](/docs/opentelemetry/database/oracle/introduction/)のドキュメントを再構築しました。
* [ワークフロー自動化アクションカタログ](/docs/workflow-automation/setup-and-configure/actions-catalog/actions-catalog/)をアクションごとのページに再編成し、New Relicアラートアクションを追加しました。
* NRQL、クエリビルダー、およびNerdGraphのドキュメント全体で12ページを更新し、クロスアカウントクエリの制限が5アカウントから30アカウントに明示的に引き上げられたことを記載しました。
* 一般提供に向けて、[複合アラート](/docs/alerts/create-alert/create-alert-condition/compound-alerts/compound-alerts/)のドキュメントを更新しました。
* [アクションカタログ](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/ec2/aws-ec2/)にAWS EC2アクションを追加しました。

### 新機能

* [New Relic複合アラートは、より正確なアラートのために複数の条件をまとめます](/whats-new/2026/09/whats-new-09-22-compound-alerts)：最大5つのアラート条件をAND/ORロジックと組み合わせて、チームの注意を引く正確なシグナルを定義します。
* [一度に最大30個のNew Relicアカウントにクエリを実行できるようになりました！](/whats-new/2026/09/whats-new-09-22-cross-account-query-limit-30)：一度にクエリを実行できるアカウントの最大数が5から30に増加し、UIまたはAPIを通じて利用可能になります。
