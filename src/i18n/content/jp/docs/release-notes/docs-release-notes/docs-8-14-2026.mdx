### 新しいドキュメント

* 調査中にChange Tracking (変更追跡機能)のデプロイメントの背後にあるプルリクエストを取得するパブリックプレビュー機能である、新しいAutopilot GitHubインテグレーションの[接続](/docs/agentic-ai/autopilot/connect-to-github)、[使用](/docs/agentic-ai/autopilot/use-autopilot-with-github)、および[トラブルシューティング](/docs/agentic-ai/autopilot/troubleshoot-github-connection)の方法を追加しました。
* ワークフロー自動化アクションカタログに[Jira課題アクション](/docs/workflow-automation/setup-and-configure/actions-catalog/jira/jira-issue)を追加し、Jira Cloud課題の作成、更新、検索、およびトランジションアクションをカバーしました。
* Ansible Automation プラットフォームジョブテンプレートの起動およびステータス確認を行うために、ワークフロー自動化アクションカタログに[Ansibleジョブアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job-launch)を追加しました。
* ワークフローからAutopilotの調査を実行するための専用のアクションカタログリファレンスを提供するために、[Autopilot実行アクション](/docs/workflow-automation/setup-and-configure/actions-catalog/autopilot/newrelic-autopilot)を追加しました。
* 集計からAutopilotの根本原因分析をトリガーし、調査結果をSlackに投稿する方法を示すために、[AutopilotとSlackを使用した集計RCA](/docs/workflow-automation/workflow-examples/integrations/autopilot-slack-rca)を追加しました。
* クエリあたりのコストなど、単一の価値単位を提供するコストを測定し、ベンチマークに対する効率を追跡する方法を説明するために、Cloud Cost Intelligenceに[ユニットエコノミクス](/docs/cci/financial-intelligence/unit-economics)を追加しました。
* New Relic UIのどこにクロスアカウントの送信先が表示されるか、およびワークフローでの使用方法を示すために、[UIでのクロスアカウントの送信先の使用](/docs/apis/nerdgraph/examples/cross-account-destinations/use-cross-account-destinations-in-the-ui)を追加しました。

### 主な変更点

* [infrastructureエージェント設定](/docs/infrastructure/infrastructure-agent/configuration/infrastructure-agent-configuration-settings)を更新し、新しい`safe_bin_dir`、`agent_temp_dir`、およびログディレクトリ設定を追加しました。
* APMデータとクエリパフォーマンス監視を関連付けるために、エージェントがインストゥルメントされたSQLステートメントにサービスエンティティGUIDコメントを追加できるようにする新しい`sqlMetadataCommentsEnabled`オプションで、[.NETエージェント設定](/docs/apm/agents/net-agent/configuration/net-agent-configuration)を更新しました。
* パブリックプレビューのコールアウトを削除し、組織レベルのロール（フルアクセス、Creator）およびノートブックレベルのロール（Owner、Editor、Reader）を含む新しいきめ細かいアクセスモデルを説明するために、[ノートブックの概要](/docs/query-your-data/explore-query-data/notebooks/introduction-notebooks)を再構築しました。
* ネイティブの最適化エンジンの適正化の推奨事項をAzureリソースに拡張するために、[Cloud Cost Intelligence：推奨事項](/docs/cci/financial-intelligence/cci-recommendations)を更新し、テレメトリーカバレッジの前提条件と推奨事項の更新頻度に関するガイダンスを追加しました。
* 最大のものに対してシリーズをランク付けするための新しい簡素化されたバーチャートセクションと、ゲージチャート用のニュートラルな閾値オプションを[チャートタイプ](/docs/query-your-data/explore-query-data/use-charts/chart-types)に追加しました。
* 稼働ステータスの遅延やアラート条件の自動リンク解除と再リンクなど、設定方法の切り替えによる影響に関するガイダンスを追加して、[ワークロードの稼働ステータス設定](/docs/new-relic-solutions/new-relic-one/workloads/workload-status-configuration)を更新しました。

### マイナーチェンジ

* [MongoDBインテグレーションインストールガイド](/install/mongodb/)にWindowsサポート制限のコールアウトを追加し、PerconaがWindowsバイナリの公開を停止したため、バンドルされているエクスポーターを現在のバージョンで凍結したことに言及しました。
* JBossのlogmanagerによって引き起こされる起動失敗に関する新しいトラブルシューティングセクションを追加して、[JBossおよびWildFlyからのクラスローディングの問題](/docs/apm/agents/java-agent/troubleshooting/classloading-issues-from-jboss-and-wildfly)を更新しました。
* 米国およびEUのデータセンター向けの追加のデュアルスタックデータ取り込みIPブロックを使用して、[ネットワーク](/docs/new-relic-solutions/get-started/networks)を更新しました。
* Rubyエージェントの[サードパーティの計装](/docs/apm/agents/ruby-agent/api-guides/third-party-instrumentation)を更新し、新しいgem計装を提供する方法を明確にし、`extends_newrelic_rpm`がアーカイブされたことに言及しました。
* 新しいFedRAMP Class C（Moderate）認定ステータスを反映するように、[FedRAMP](/docs/security/security-privacy/compliance/certificates-standards-regulations/fedramp)を更新しました。
* FIPS 140-2からFIPS 140-3準拠の暗号化標準への移行を反映するために、[データの暗号化](/docs/security/security-privacy/compliance/data-encryption)を更新しました。
* 新しい`idempotencyKey`入力を使用して[ワークフロー実行の開始](/docs/workflow-automation/workflow-automation-apis/start-workflow-run)を更新し、[アクションカタログ](/docs/workflow-automation/setup-and-configure/actions-catalog/actions-catalog)のAzureおよびNew Relic通知アクション全体で`idempotencyKey`のUUID形式の検証を明確にしました。
* グループ管理サービスアカウント（gMSA）のサポートを含む、Windowsサービスアカウントの要件を文書化するために、[infrastructureエージェントセキュリティ](/docs/infrastructure/infrastructure-agent/infrastructure-security)を更新しました。
* 米国リージョンがデフォルトであることを明確にするために、[データセンターの選択](/docs/accounts/accounts-billing/account-setup/choose-your-data-center)を更新しました。
* [Azure Native New Relic Service](/docs/infrastructure/microsoft-azure-integrations/get-started/azure-native)を現在のAzure MarketplaceのリストURLで更新し、古いHIPAAの可用性に関する注意事項を削除しました。
* サポートされているKubernetesバージョン1.31から1.35を反映するために、[Kubernetesインテグレーションの互換性と要件](/docs/kubernetes-pixie/kubernetes-integration/get-started/kubernetes-integration-compatibility-requirements)を更新しました。
* [NRQLの構文、句、および関数](/docs/nrql/nrql-syntax-clauses-functions)を修正し、デフォルトのApdexスコアを0.4秒に修正しました。
* [New Relic Lensのコネクタのセットアップ](/docs/new-relic-lens/set-up-connectors)にDatabricks（Azure）コネクタオプションを追加しました。
