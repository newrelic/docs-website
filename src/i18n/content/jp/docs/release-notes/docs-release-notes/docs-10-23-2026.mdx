### 新しいドキュメント

* Javaエージェント8.20以降にアップグレードし、`clear_return_stacks`システムプロパティを設定することで、欠落しているKotlinの計装を修正するのに役立つ[Kotlinの計装が報告されない](/docs/apm/agents/java-agent/troubleshooting/kotlin-instrumentation-not-reporting/)を追加しました。
* スタンドアロンのinfrastructureエージェントからAgent Controlに移行する際の、監視のギャップ、設定のマッピング、エンティティの継続性、およびロールバック手順を網羅した、Agent Controlの[移行ガイド](/docs/new-relic-control/agent-control/migration-guide/)を追加しました。
* 日次および月次のAdvanced CCU予算を設定し、自動化された集計のトリアージを対話型の使用から分離し、NRQLを使用して消費量を追跡する方法を示す[Autopilotの計算制限](/docs/agentic-ai/autopilot/autopilot-compute-limits/)を追加しました。
* メールテンプレートの管理とAmazon SES経由のメール送信をカバーする[AWS SESアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/ses/aws-ses/)を、ワークフロー自動化アクションカタログに追加しました。
* コレクターオブザーバビリティを有効にするための課金に関する注意事項とステップバイステップの設定を網羅したセットアップガイドである、[コレクターオブザーバビリティの開始](/docs/opentelemetry/collector-observability/collector-observability-setup/)を追加しました。
* 各コレクターのオブザーバビリティKPIタイルとそれに関連するテレメトリーチャートを説明する[OpenTelemetry CollectorのKPIリファレンス](/docs/opentelemetry/collector-observability/collector-observability-kpis/)を追加しました。
* 『[データが表示されない：.NETフレームワーク・アプリケーションがTLS 1.2を使用していない](/docs/apm/agents/net-agent/troubleshooting/no-data-appears-net-framework-tls-12/)』を確認できる、.NET向けの新しいトラブルシューティング・ガイドを追加しました。

### 主な変更点

* データがまだレポートされている状態でもアプリケーションを恒久的に強制削除できる新しいNerdGraphの`agentApplicationDelete`ミューテーションを追加し、[New Relicからアプリケーションを削除する](/docs/apm/new-relic-apm/maintenance/remove-applications-new-relic/)を更新しました。
* クラスタ全体のメトリクス（`KafkaClusterSample`）と、新しいブローカー、トピック、および消費者オフセットの拡張メトリクスと設定オプションを使用して、[Kafka監視インテグレーション](/docs/infrastructure/host-integrations/host-integrations-list/kafka/kafka-integration/)を更新しました。
* [Kubernetesクロス・クラスタUI](/docs/kubernetes-pixie/kubernetes-integration/understand-use-data/kubernetes-cross-cluster/)を更新し、スコアカード、テーブル、ドリルダウンのセクションを追加しました。
* ルートレスPodmanのセットアップ表、アクティブなログインセッションなしでサービスアカウントのsystemdサービスを実行し続けるためのlingering有効化手順、および共有メモリの制限によりブラウザーモニターがクラッシュするのを防ぐためのポッド作成コマンド内の`--shm-size=2g`を含めて、[外形監視ジョブマネージャーのインストール](/docs/synthetics/synthetic-monitoring/private-locations/install-job-manager/)を更新しました。
* [New Relic APIキー](/docs/apis/intro-apis/new-relic-api-keys/)を更新し、機能と権限について説明する新しい「APIキーの監査と管理」セクションを追加しました。また、キーの置換手順を簡素化し、`enabled`フィールドの逆になっていた説明を修正しました（`enabled: false`はキーを非アクティブ化し、`enabled: true`は再アクティブ化します）。
* NerdGraphを通じてAPIキーを作成、更新、クエリするための新しい`owningTeamIds`、`enabled`、および`keyUsage`（最終使用）フィールドを追加して、『[NerdGraphチュートリアル：APIキーの管理](/docs/apis/nerdgraph/examples/use-nerdgraph-manage-license-keys-user-keys/)』を更新しました。
* 『[プライベートロケーションのトラブルシューティング](/docs/synthetics/synthetic-monitoring/private-locations/troubleshoot-private-locations/)』を更新し、Podmanのポッド・レベルの共有メモリ制限によりブラウザ・モニターがクラッシュする理由を説明する新しいセクションと、診断コマンドおよび修正方法を追加しました。
* [OpenTelemetry Collector監視](/docs/opentelemetry/collector-observability/collector-observability/)を更新し、スタンドアロン型とアタッチ型のコレクターの新しいビュー・モードを追加しました。
* EOLとなったJoomla、Drupal 7/9、およびLaravel 11のエントリを削除するため、[PHPエージェントの互換性と要件](/docs/apm/agents/php-agent/getting-started/php-agent-compatibility-requirements/)を更新しました。
* [.NET MAUIアプリケーションのモニター](/docs/mobile-monitoring/new-relic-mobile-maui-dotnet/monitor-your-net-maui-application/)で、サポートされる最小iOSバージョンを16から15に更新しました。
* サポートされている最新のサードパーティパッケージバージョンを追加して、『[Node.jsエージェントの互換性と要件](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent/)』を更新しました。

### マイナーチェンジ

* [Guzzle向けPHPエージェントサポート](/docs/apm/agents/php-agent/frameworks-libraries/guzzle/)を更新し、サポート対象バージョンとして7～8を記載し、EOLとなった5～6を削除しました。
* 『[Unityアプリケーションのモニター](/docs/mobile-monitoring/new-relic-mobile-unity/monitor-your-unity-application/)』で、iOSのXCFrameworkのフォルダ名を`NewRelic.xcframework`に更新しました。
* [Pythonエージェント設定](/docs/apm/agents/python-agent/configuration/python-agent-configuration/)の変数`distributed_tracing.sampler.remote_parent_not_sampled.trace_id_ratio_based.ratio`の名前を更新しました。
* デフォルトの `PUBLIC` 権限を取り消す、堅牢化された、またはマネージドの PostgreSQL 環境において、`nri-postgresql` に `information_schema` に対する `USAGE` を付与する必要があることを説明するため、[PostgreSQL インストールガイド](/install/postgresql/)を更新しました。
* 『[ライブ・アーカイブを使用した長期ログ・ストレージ](/docs/logs/get-started/live-archives/)』のパーティション作成手順を更新し、「Send to Live Archives」ドロップダウン・オプションを更新しました。
* 監視リーダーロールを使用すると、各リソースを個別にクエリする代わりに、Azure MonitorのメトリクスバッチAPIを使用してNew Relicがリソースをポーリングできることを説明するように、『[Azure監視インテグレーションのセットアップ](/docs/infrastructure/microsoft-azure-integrations/get-started/activate-azure-integrations/)』を更新しました。
* New Relicは標準のServiceNowアプリケーションのみをサポートし、そのカスタマイズはサポートしていないことを説明するために、[アラート通知インテグレーション](/docs/alerts/get-notified/notification-integrations/)を更新しました。
* [Podmanを使用したデュアルスタック向け外形監視のインストール](/docs/synthetics/synthetic-monitoring/private-locations/install-synthetics-dual-stack-podman/)および[外形監視プライベートロケーションのランタイム移行ガイド](/docs/synthetics/synthetic-monitoring/private-locations/runtime-transition-guide/)のPodmanポッド作成コマンドを更新しました。
