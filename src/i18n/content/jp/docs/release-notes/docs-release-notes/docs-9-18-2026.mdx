### 新しいドキュメント

* EAS Buildでのビルド時に自動ソースマップ、dSYM、およびマッピングファイルのアップロードに関するガイダンスを提供するため、[EAS Build向けReact Nativeエージェントの設定](/docs/mobile-monitoring/new-relic-monitoring-react-native/configure-eas-build-react-native)を追加しました。
* インスタンス、希望する容量、インスタンスの更新、およびスケジュールされたアクションを管理するためのアクションを網羅する[AWS Auto Scalingアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/aws-autoscaling)を、ワークフロー自動化アクションカタログに追加しました。

### 主な変更点

* 一般提供に合わせて[New Relic Ground Truth](/docs/agentic-ai/mcp/overview)（旧New Relic AI MCP）に名称を変更し、セットアップをOAuthのみに移行しました。
* 一般提供に向けて、[New Relic Lensの概要](/docs/new-relic-lens/overview)、[コネクタのセットアップ](/docs/new-relic-lens/set-up-connectors)、[Lensを使用したデータのクエリ](/docs/new-relic-lens/query-data)、および[マテリアライズドビュー](/docs/new-relic-lens/materialized-views)を更新しました。
* [設定の管理](/docs/new-relic-control/agent-control/configuration)を新しい値プロバイダー・システムで更新し、[一般的な問題のトラブルシューティング](/docs/new-relic-control/agent-control/troubleshooting)を修正された設定名と新しいNRDiagトラブルシューティング・セクションで更新しました。
* [「アクションカタログ」](/docs/workflow-automation/setup-and-configure/actions-catalog/actions-catalog)のAWSアクションページを更新し、フォーマットを統一して、新しいAWS Bedrockアクションと3つの新しいLambdaアクションを追加しました。
* ワークフロー通知を通じてダッシュボードのスナップショットを送信するための`DASHBOARD_SNAPSHOT`添付ファイルタイプを追加するために、[New Relic通知アクション](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/newrelic-notification)を再構成しました。
* 壊れたレスポンス解析セレクターを修正し、[AutopilotとSlackによる集計RCA](/docs/workflow-automation/workflow-examples/integrations/autopilot-slack-rca)にトラブルシューティングセクションを追加しました。
* [「マップの理解と使用」](/docs/service-architecture-intelligence/maps/advanced-maps)に凡例コントロールと「関係の視覚化」セクションを追加し、ノードとアイコンのリファレンステーブルをタイルグリッドに変換しました。
* [.NETエージェント設定](/docs/apm/agents/net-agent/configuration/net-agent-configuration)にKafkaメトリクス設定セクションを追加しました。
* ユーザーが非推奨のREST API v2およびv0デプロイメントエンドポイントから移行できるように、[New Relicでの変更の表示と分析方法](/docs/change-tracking/view-analyze-data)に環境全体の変更の追跡に関するセクションを追加し、[NerdGraphを使用した変更の追跡](/docs/change-tracking/config/nerdgraph)を再構築しました。
* [Google Compute Engine監視インテグレーション](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-compute-engine-monitoring-integration)に、新しい主要メトリクステーブルを備えたService AttachmentおよびPrivate Service Connectエンドポイントのエンティティタイプを再導入しました。

### マイナーチェンジ

* [NRDOTによるデータベースサービスの識別](/docs/opentelemetry/database/capabilities/db-apm)に、自動的なAPMからデータベースへのエンティティリンクが失敗する可能性がある場合を明確にするコールアウトを追加しました。
* yumベースのインストールコマンドが`newrelic-infra.repo`を上書きするという警告のコールアウトを、[『Linuxホスト向けNew Relic eBPFエージェントのインストール』](/docs/ebpf/linux-installation)に追加しました。
* .NET 10のサポートを追加し、インプロセスモデルのバージョン要件を修正するために、[インストゥルメントされたAzure Functionsの互換性と要件](/docs/serverless-function-monitoring/azure-function-monitoring/compatibility-requirement-azure-monitoring)を更新しました。
* パブリックインターネット経由のエクスポートにおいて、gRPCよりもOTLP/HTTPを推奨するように[New Relic OTLPエンドポイント](/docs/opentelemetry/best-practices/opentelemetry-otlp)を更新しました。
* [ダッシュボードの管理](/docs/query-your-data/explore-query-data/dashboards/manage-your-dashboard)に、TVモード用の「Cycle interval」ドロップダウンオプションを追加しました。
* 古い互換性テーブルを削除するために、[ワークロードの稼働ステータス設定](/docs/new-relic-solutions/new-relic-one/workloads/workload-status-configuration)を更新しました。
* [AWS Lambda監視の互換性と要件](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/compatibility-requirement-lambda-monitoring)に`ruby4.0`ランタイムのサポートを追加し、[New RelicでのLambda監視のインストールと設定](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/configure-serverless-aws-monitoring)のリンク切れを修正しました。
* [Node.jsエージェントの互換性と要件](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent)でサポートされているパッケージのバージョン番号を更新しました。
* どのツールがCCUとaCCUのどちらとして計測されるかを明確にするため、[New Relic MCPツールリファレンス](/docs/agentic-ai/mcp/tool-reference)に課金に関する注意事項を追加しました。
* [New Relic MCPのセットアップ](/docs/agentic-ai/mcp/setup)にCodex CLIのセットアップ手順を追加しました。
* 拒否リストの変更がNPMでインストールされたBrowserエージェントに自動的に適用されないことを明確にするため、[AjaxRequestイベントの設定](/docs/browser/new-relic-browser/configuration/configure-ajax-request-events)にコールアウトを追加しました。
* [.NETエージェントの互換性と要件](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements)のサードパーティ・ライブラリの互換性バージョンを更新しました。
* [ライブアーカイブを使用した長期ログ・ストレージ](/docs/logs/get-started/live-archives)から、ライブアーカイブ・パーティションに関する古いヒントを削除しました。
* [Rubyエージェントの設定](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration)に、`browser_monitoring.version`設定オプションと新しい「Errors Inboxの設定」セクションを追加しました。
* [『iOSエージェントの互換性と要件』](/docs/mobile-monitoring/new-relic-mobile-ios/get-started/new-relic-ios-compatibility-requirements)および[『tvOS向けNew Relicの互換性と要件』](/docs/mobile-monitoring/new-relic-mobile-ios/tvos/new-relic-tvos-compatibility-requirements)に、エージェントv7.7.7以降のみがiOS/tvOS 15.0～15.5をサポートしていることを記載し、互換性のギャップを修正しました。
* [HIPAA](/docs/security/security-privacy/compliance/certificates-standards-regulations/hipaa)および[FedRAMP](/docs/security/security-privacy/compliance/certificates-standards-regulations/fedramp)のコンプライアンスの日付を更新し、古い除外行を削除しました。

### 新機能

* [New Relic Ground Truthが一般提供されました](/whats-new/2026/09/whats-new-09-15-ground-truth)：Ground Truthは、MCPを通じてNew Relicのオペレーショナルインテリジェンスへの管理されたアクセスをAIツールおよびエージェントに提供し、企業が求める制御を備えたより豊富なオペレーショナルコンテキストからの推論を支援します。
* [New Relic Lensが一般提供されました](/whats-new/2026/09/whats-new-09-15-nr-lens-ga)：Lensを使用すると、追加のデータ取り込み費用を支払うことなく、SQLを使用してテレメトリーと共にSnowflake、Iceberg、およびGoogle Sheetsなどの外部データソースに接続してクエリを実行できます。
