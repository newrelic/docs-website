### 新しいドキュメント

* 失敗したAJAXおよびfetch requestsをグループ化、ソート、フィルタリングする方法を説明する、[Browser: Group request errors tab \[Browser：リクエストエラーのグループ化タブ\]](/docs/triage-inbox/group-request-errors-browser/)を追加しました。
* 最近のセキュリティアドバイザリの影響を受けるPHPまたはNode.jsのバージョンを実行しているAPMエンティティを一覧表示する、[Exposure check\[エクスポージャーチェック\]（Security RXのプレビュー）](/docs/vulnerability-management/exposure-check/)を追加しました。
* 独自の認証情報を使用してNew Relicで認証する人間以外のIDをプロビジョニングする方法を説明する、[System identities](/docs/accounts/accounts-billing/new-relic-one-user-management/system-identities/) \[システムID]を追加しました。
* インテグレーションの有効化方法と、アプリ、エージェント、ツール、データ・コネクタについて収集するリクエスト、レイテンシ、セッション、クォータのメトリクスについて説明した、[Google Gemini Enterprise監視インテグレーション](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-gemini-enterprise-monitoring-integration/)を追加しました。
* ログ解析、パーティション、および難読化ルールをクエリおよび更新するために、ワークフロー自動化アクションカタログに[New Relic Logs設定アクション](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/log-configurations/newrelic-log-configurations/)を追加しました。
* eMudhra認証局の侵害後、更新された外形監視プライベートロケーションコンテナイメージをプルする手順を記載した[セキュリティ情報NR26-12](/docs/security/new-relic-security/security-bulletins/security-bulletin-nr26-12/)を追加しました。

### 主な変更点

* クラスタ全体の問題をランク付けするフリート規模のトリアージビューを追加して、以前のクロスクラスタページであった[Kubernetesフリートのトリアージ](/docs/kubernetes-pixie/kubernetes-integration/understand-use-data/explore-k8s/)を更新しました。
* インストレーションを3つのステップに簡素化するために[Rubyエージェントのインストレーション](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent/)を更新し、カテゴリ別にオプションを見つけられるように[Rubyエージェントの設定](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration-overview/)をトピックページに分割しました。
* 2026年11月5日のサポート終了に伴いCodeStreamのドキュメントを削除し、CodeStreamの参照を削除するためにエージェントのコードレベルメトリクスページを書き直し、既存のリンクが引き続き機能するようにリダイレクトを追加しました。
* OAuthトークンの取り消しや`NrAuditEvent`を使用したサインインアクティビティの監査など、MCPアクセスを保護する方法に関するセクションを[New Relic Ground Truth](/docs/agentic-ai/mcp/overview/)に追加して更新しました。
* NerdGraphまたはTerraformを使用してカーディナリティの予算を変更するために必要な権限について、[カーディナリティを管理するためのアクセス管理](/docs/data-apis/ingest-apis/metric-api/cardinality-access-management/)を更新しました。
* アクセスの前提条件と権限の参照テーブルを含むように、Cloud Cost Intelligenceの[権限とロール](/docs/cci/configure-cci/cci-permissions/)を更新しました。
* iOSエージェントv7.4.8で削除されたPythonアップロードスクリプトを置き換える、`run-symbol-tool` Run Script \[スクリプトの実行] ビルドフェーズで、[『Upload dSYM files』](/docs/mobile-monitoring/new-relic-mobile-ios/configuration/upload-dsyms-bitcode-apps/)を更新しました。
* サンプルのエラーメッセージやAPIレスポンスオブジェクトなど、出力フィールドの具体的なサンプル値を追記して、ワークフロー自動化アクションカタログの[AWS Lambdaアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/lambda/aws-lambda/)を更新しました。
* Node.js 22.23.4ランタイムとそのサポート対象のサードパーティモジュールについて、[モニターランタイムの管理](/docs/synthetics/synthetic-monitoring/using-monitors/manage-monitor-runtimes/)を更新しました。

### マイナーチェンジ

* [Browser: JavaScript errors tab](/docs/triage-inbox/browser-tab/)\[Browser：JavaScriptエラータブ]を更新し、**Errors (Errors Inbox)**\[エラー（Errors Inbox）]から**JavaScript errors**\[JavaScriptエラー]に名前を変更しました。
* `Application`クラスの`onCreate()`メソッドでエージェントを起動することを推奨するように、[Androidエージェントのインストール](/docs/mobile-monitoring/new-relic-mobile-android/install-configure/install-android-agent-gradle/)を更新しました。
* [New Relic AIツール](/docs/agentic-ai/tools/)およびモバイル監視UIページを更新し、各製品エリアで利用可能なAutopilotスキルへのリンクを追加しました。
* 有効および無効な条件が制限にどのようにカウントされるかを明確にするため、[アラートのルールと制限](/docs/alerts/admin/rules-limits-alerts/)を更新しました。
* ミューティングルールが複合アラートに適用されるようになったことを説明するため、[複合アラートの概要](/docs/alerts/create-alert/create-alert-condition/compound-alerts/compound-alerts/)および[ミューティングルール](/docs/alerts/get-notified/muting-rules-suppress-notifications/)を更新しました。
* VPCエンドポイントを作成する際に** PrivateLink Ready partner services** \[PrivateLink Readyパートナーサービス][ を選択する必要があることを明確にするために、 AWS PrivateLink経由でNew Relicデータを送信する を更新しました。](/docs/data-apis/custom-data/aws-privatelink/)
* [infrastructureエージェント設定](/docs/infrastructure/infrastructure-agent/configuration/infrastructure-agent-configuration-settings/)に`safe_dir_check_enabled`設定を追加しました。この設定は、infrastructureエージェントv2.0.1ではデフォルトで`true`になります — 以前のデフォルトに依存していた場合は、互換性を損なう変更となります。
* `enable_process_metrics`と`metrics_process_sample_rate: -1`がプロセスサンプリングを停止する方法を明確にするため、[「Optimize your ingest data」](/docs/tutorial-optimize-telemetry/data-optimize-techniques/)および[「Optimize your data ingest」](/docs/new-relic-solutions/observability-maturity/operational-efficiency/data-governance-optimize-ingest-guide/)を更新しました。
* Debian 12および13とWindows Server 2025をリストに記載し、Debian 11を削除するように、[infrastructureエージェントを使用したログの転送](/docs/logs/forward-logs/forward-your-logs-using-infrastructure-agent/)を更新しました。
* 未解決のエラーグループは、エラーが14日後に再発した場合に新しいSlack通知を送信することを説明するために、[APMのErrors Inbox](/docs/apm/errors-inbox/errors-inbox-ui/)および[Errors Inboxの外部サービス](/docs/triage-inbox/error-external-services/)を更新しました。
* [Azure Monitorインテグレーション](/docs/infrastructure/microsoft-azure-integrations/azure-integrations-list/azure-monitor/)を更新し、ディメンショナルメトリクスのタイプが、`summary`、`gauge`、`count`などのAzureが返すデータに依存することを説明しました。
* コレクターのトレースを試す際に`INTERNAL_TELEMETRY_TRACE_LEVEL=basic`を設定するように、[コレクターのオブザーバビリティの開始](/docs/opentelemetry/collector-observability/collector-observability-setup/)を更新しました。
* [NRDOTを使用したデータベースサービス識別](/docs/opentelemetry/db360/capabilities/db-apm/)を更新し、.NETエージェントv10.54.0以降を必須としました。
* コネクタ名にハイフン（`nrlens-`）の代わりにアンダースコアのプレフィックス（`nrlens_`）を使用するようになったことを反映するように、[コネクタのセットアップ](/docs/new-relic-lens/set-up-connectors/)を更新しました。
* Advantageプランのセクションとその従量課金制（PAYG）の変換テーブルを[利用プラン](/docs/licenses/license-information/usage-plans/new-relic-usage-plan/)に追加して更新しました。
* [セキュリティ脆弱性の報告](/docs/security/security-privacy/information-security/report-security-vulnerabilities/)を更新し、脆弱性レポートとCVEの影響に関するセクションを追加しました。
* 正しいDataflowテンプレート名として`PubSubToNewRelic`を使用するように、[Google Cloud Platformからのログ転送](/docs/logs/forward-logs/google-cloud-platform-log-forwarding/)を更新しました。
* [Node.jsエージェント](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent/)および[.NETエージェント](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements/)の互換性と要件のページを、検証済みの最新のライブラリバージョンで更新しました。
* [AIモニタリングの互換性と要件](/docs/ai-monitoring/compatibility-requirements-ai-monitoring/)および[インストゥルメントされたPythonパッケージ](/docs/apm/agents/python-agent/getting-started/instrumented-python-packages/)を更新し、MicrosoftエージェントフレームワークとCrewAIを追加しました。
* Publisher ModelをVertex AIエンティティとしてリストに記載するように、[Google VertexAI監視インテグレーション](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-vertexai-monitoring-integration/)を更新しました。

### 新機能

* [BrowserアプリケーションにRequest errors \[リクエストエラー\] が表示されるようになりました](/whats-new/2026/11/whats-new-11-02-browser-group-request-errors)：正常に機能しないページの背後にある失敗したAJAXおよびfetch requestsを確認し、Errors Inbox \[エラーインボックス] がJavaScript errors \[JavaScriptエラー] に名前変更されたことをご確認ください。
* [Kubernetes監視の新しいランディングページ](/whats-new/2026/11/whats-new-11-3-k8s-landing-page)：すべてのクラスタにおける問題をランク付けするフリート規模のトリアージビューで、Kubernetes監視を開きます。
