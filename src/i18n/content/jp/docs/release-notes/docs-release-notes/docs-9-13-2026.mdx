### 新しいドキュメント

* Amazon EventBridgeにイベントを公開するための[AWS EventBridgeアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/aws-eventbridge)を、ワークフロー自動化アクションカタログに追加しました。
* ワークフローからサービスレベル目標を作成および管理するための[New Relicサービスレベルアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/newrelic-service-level)をWorkflow Automationのアクションカタログに追加しました。

### 主な変更点

* 推奨事項からの一括作成、除外フィルターセクション、およびディストリビューティッド（分散）トレーシングを有効にするための新しい前提条件セクションを追加して、[インテリジェントワークロードの作成](/docs/new-relic-solutions/new-relic-one/workloads/create-intelligent-workload)を更新しました。
* 追加の設定オプションと拡充されたリファレンスコンテンツにより、ワークフロー自動化のアクションカタログにある[AWS SQSアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/aws-sqs)を拡張しました。
* [CCI financial intelligence向けNRQL](/docs/cci/financial-intelligence/nrql-for-cci)を更新し、クエリ例を整理して説明を簡素化しました。
* [eBPFエージェント](/docs/ebpf/requirements)にOracle Kubernetes Engine（OKE）のエントリとMariaDB/Aurora MySQLのサポートを追加しました。
* [eBPF Kubernetesインストレーション](/docs/ebpf/k8s-installation)および[eBPF Linuxインストレーション](/docs/ebpf/linux-installation)に、`agentMetadataReporting`および生成AI監視設定パラメーターを追加しました。
* [「GrafanaでのPrometheusデータの表示とクエリ」](/docs/infrastructure/prometheus-integrations/view-query-data/grafana)内のGrafanaダッシュボードの翻訳エンドポイントURLを更新しました。
* [MySQL](/docs/opentelemetry/database/mysql/hosted)および[PostgreSQLのホスト型およびRDS監視ドキュメント](/docs/opentelemetry/database/postgresql/hosted)のNRDOT Collector設定パス更新コマンドを更新しました。
* OCIミラーの署名検証要件とエージェントタイプの定義について、[エージェントタイプ](/docs/new-relic-control/agent-control/agent-types)と[ミラーのセットアップ](/docs/new-relic-control/agent-control/mirror-setup)を更新しました。
* アクセス拒否エラーを防ぐため、「[Java 2セキュリティを使用したJavaエージェントのインストール](/docs/apm/agents/java-agent/additional-installation/install-java-agent-java-2-security)」を更新し、Java 9以降の環境に必要な権限を追記しました。
* 新しいOAuthスコープとAPIキーについて、[MCPの概要](/docs/agentic-ai/mcp/overview)と[New Relic MCPのセットアップ](/docs/agentic-ai/mcp/setup)を更新しました。
* [Kubernetesインテグレーションのインストレーションドキュメント](/docs/kubernetes-pixie/kubernetes-integration/installation/k8s-agent-operator)を更新し、EKS FargateノードでのKubernetes APM自動アタッチのサポートを追加しました。

### マイナーチェンジ

* プール名とプロバイダー名はカスタマイズ可能な推奨値であることを明確にするため、「[GCPワークロードIdentity連携の接続](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation)」にコールアウトを追加しました。
* [CNCFコレクターを使用したMicrosoft SQL Serverのモニター](/docs/opentelemetry/database/mssql/cncf)のデータベースクエリのパフォーマンスに関する説明を更新しました。

### 新機能

* [カタログでのタグベースのグループ化、カスタム列、および列の並べ替え](/whats-new/2026/09/whats-new-09-07-catalogs-tag-grouping): New Relic定義またはカスタムの任意のタグを使用してエンティティをグループ化し、列を追加できるようになりました。また、ワークフローに合わせて列を並べ替えることができ、レイアウトは自動的に保存されます。
