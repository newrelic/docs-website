### 主な変更点

* 外形監視ジョブマネージャーのドキュメントに、[スクリプト化されたモニターのユーザー定義変数](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-configuration)を設定する方法と、それをサポートする[ジョブマネージャーのバージョン](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-transition-guide)が記載されるようになりました。
* インストールを容易にし、ドキュメントが正確かつ最新であることを保証するために、オンホストインテグレーションのドキュメントの書き換えを継続しました。今週の更新：[Sonarqube](/docs/infrastructure/host-integrations/host-integrations-list/sonarqube-monitoring-integration)および[Windowsサービス](/docs/infrastructure/host-integrations/host-integrations-list/windows-services-integration)。
* クロスアプリケーショントレースは非推奨となり、今後のAPMエージェントバージョンではサポートされなくなります。これを反映するためにドキュメントを更新しました。
* 2023年に非推奨となったOpenTelemetryの累積メトリクスに関連するドキュメントを削除しました。

### マイナーチェンジ

* Node.jsの[AIモニタリングのカスタマイズ](/docs/ai-monitoring/customize-agent-ai-monitoring)に関連するAPIドキュメントのリンクを更新しました。
* Standard、Pro、およびEnterpriseアカウントに適用される[Data Plusの機能](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/data-ingest-billing/#data-prices)を明確にしました。
* [Java APMエージェントを更新](/docs/apm/agents/java-agent/installation/update-java-agent)し、当社の[JavaエージェントAPI](/docs/apm/agents/java-agent/api-guides/guide-using-java-agent-api)のいずれかを使用している場合、APIの依存関係も更新する必要があることを明確にしました。
* [AIライブラリとフレームワーク](/docs/apm/agents/python-agent/getting-started/compatibility-requirements-python-agent/#digital-intelligence-platform)をモニターするために、Python APMエージェントのサポートバージョンを9.8.0（9.9.0から）に更新しました。
* [宛先通知](/docs/alerts-applied-intelligence/notifications/notification-integrations)の手順にあるServiceNowへのリンクを更新しました。
* 当社のinfrastructureエージェントは、Elasticコンテナサービスを監視する際に、CgroupバージョンV2を使用して、すべての[Docker APIからのEC2ノードコンテナメトリクス](/docs/infrastructure/install-infrastructure-agent/linux-installation/container-instrumentation-infrastructure-monitoring)を収集するようになりました。
* UIで[OpenTelemetry `singlestore`データを見つける](/docs/more-integrations/open-source-telemetry-integrations/opentelemetry/collector/collector-configuration-examples/opentelemetry-collector-singlestore/#view-data)方法に関する情報を更新しました。
* [ログ検索](/docs/codestream/observability/log-search)および[パフォーマンス監視](/docs/codestream/observability/performance-monitoring)に関連するCodeStreamのドキュメントを更新しました。
* Errors Inboxでサポートされている[Javaエージェントのユーザー属性](/docs/triage-inbox/error-users-impacted)へのリンクを追加しました。
* [NRQLアラート条件](/docs/alerts-applied-intelligence/new-relic-alerts/alert-conditions/queries-nrql_screenshot-full_nrql-alert-conditions/#condition-tips)が評価対象のデータを集計する際、30秒から最大6時間までの時間単位でデータを評価できるようになりました。
