### 新しいドキュメント

* New RelicでのOCIのメトリクスとログの監視の概要を提供するために、[Oracle Cloud Infrastructure（OCI）監視](/docs/infrastructure/oci/introduction/)を追加しました。
* AWSおよびAzureのセットアップ、サポートされるエンティティと要件、およびトラブルシューティングを網羅し、クラウドインフラストラクチャの自動検出、リソース間の関係のマッピング、および設定変更の追跡に役立つ[インフラストラクチャ 360](/docs/infrastructure/infrastructure-360/introduction-infrastructure-360/)を追加しました。
* NRQL式を再利用可能な名前付きショートカットとして保存し、`$`記号を使用してクエリで参照する方法を示すために、[NRQLマクロ](/docs/nrql/nrql-macros/nrql-macros-overview/)を追加しました。
* 各デプロイメントをモニターし、SlackやGitHubでリグレッションの報告を受け取る方法を示す、[GitHub Copilot向けNew Relic Change Tracking (変更追跡機能)を使用したデプロイメントのモニター](/docs/agentic-ai/autopilot/change-tracking-for-github-copilot/)を追加しました。
* リリースごとにシンボルファイルを生成し、スタックトレースをシンボル化して、シンボルを保存する方法を説明するために、[Flutter Dartエラーのシンボル化](/docs/mobile-monitoring/new-relic-mobile-flutter/symbolicate-dart-errors/)および[.NET MAUI C#エラーのシンボル化](/docs/mobile-monitoring/new-relic-mobile-maui-dotnet/symbolicate-csharp-errors/)を追加しました。
* LaunchDarklyのデータをPythonエージェントに接続することで、機能フラグとリリースがアプリケーションに与える影響を監視する方法を示す、[Pythonエージェントを使用したLaunchDarkly](/docs/apm/agents/python-agent/supported-features/launchdarkly-release-observability/)を追加しました。
* [ワークフロー自動化アクションカタログ](/docs/workflow-automation/setup-and-configure/actions-catalog/actions-catalog/)に、[AWS Athena](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/athena/aws-athena/)、[AWS DynamoDB](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/dynamodb/aws-dynamodb/)、[Azure App Service](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-appservice/)、[GitHubワークフローの実行](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run/)、[New Relicシークレット](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/secret/newrelic-secret/)、および[New Relic Synthetics](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/synthetics/newrelic-synthetics/)のアクションを追加し、[通知ステータスの待機](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/notification/newrelic-notification-waitforstatus/)アクションを追加しました。
* 外形監視のパブリックおよびプライベートロケーションに影響を与える、リモートコード実行（CVE-2026-111497）を含む重大なNode.jsの脆弱性に対処する手順を記載した[セキュリティ情報NR26-11](/docs/security/new-relic-security/security-bulletins/security-bulletin-nr26-11/)を追加しました。

### 主な変更点

* プロジェクトに不足しているNew Relicの計装がないか確認する`analyze_github_newrelic_gaps`ツールのギャップ分析セクションを追加し、[MCPツールリファレンス](/docs/agentic-ai/mcp/tool-reference/)を更新しました。
* インシデントウィンドウ中に作成されたオープンなホットフィックスおよびプルリクエストにAutopilotがフラグを付ける方法、およびリリースバージョンを調整する方法についての新しいセクションを追加して、[GitHubでのAutopilotの使用](/docs/agentic-ai/autopilot/use-autopilot-with-github/)を更新しました。
* タグベースの所有権を通じてNew Relicが自動的にチームに割り当てるエンティティの種類のリスト（ドメインおよび種類別）を記載して、Serviceアーキテクチャー・インテリジェンスの[エンティティの所有権の設定](/docs/service-architecture-intelligence/teams/team-ownership/)を更新しました。
* ホスト上のAgent ControlがOCIレジストリからエージェントパッケージをダウンロードするために使用するDocker Hubレジストリドメインで[ネットワークトラフィック](/docs/new-relic-solutions/get-started/networks/)を更新し、記載されているコレクターのドメインを`collector.newrelic.com`に変更しました。
* 電子メールの宛先を選択または作成するために必要な、アプライドインテリジェンスの送信先（Destinations）の読み取りおよび変更機能に関する説明を追加し、[NRQL検索のスケジュール設定](/docs/nrql/using-nrql/schedule-nrql-searches/)を更新しました。
* 一貫した説明、パラメーター表、セクションアンカーを使用して、ワークフローとスケジュールに関する[Workflow Automation API](/docs/workflow-automation/workflow-automation-apis/using-workflow-automation-api/)リファレンスページを更新しました。
* Javaのスタックトレースなどの複数行のエントリを単一のログレコードに結合するために、infrastructureエージェントのv1.53.0以降で利用可能な`multilineParser`パラメーターを使用するように、[infrastructureエージェントを使用したログの転送](/docs/logs/forward-logs/forward-your-logs-using-infrastructure-agent/)を更新しました。
* Windows Server 2025およびWindows Azure Guest OS Family 5以降を含む、現在サポートされているWindowsバージョンを記載するように、[.NETエージェントの互換性と要件](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements/)を更新しました。
* サポートされている最新のサードパーティパッケージバージョンを追加して、『[Node.jsエージェントの互換性と要件](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent/)』を更新しました。

### マイナーチェンジ

* 評価オフセットの代わりにイベントタイマーストリーミング方式を使用するように、[Azure Monitorインテグレーション](/docs/infrastructure/microsoft-azure-integrations/azure-integrations-list/azure-monitor/)の集計ガイダンスを更新しました。
* Delay/timer設定への移行に伴い、評価オフセットが非推奨になったことを説明するため、[集計イベント属性](/docs/alerts/create-alert/condition-details/alert-event-attributes/)を更新しました。
* `CLUSTER_NAME`を変更すると新しいブローカーおよびトピックのエンティティが作成され、APMアプリケーションが約1日間古いトピックにリンクされたままになるという説明を追加し、[Kafkaインテグレーションの設定](/docs/infrastructure/host-integrations/host-integrations-list/kafka/kafka-config/)を更新しました。
* サンプルの設定に必須の`NEW_RELIC_APP_NAME`変数を追加するために、[独自のLambda関数を計装する](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/instrument-your-own/)を更新しました。
* サーバーレスモードの再試行バジェット設定および`NEW_RELIC_EXTENSION_SYNCHRONOUS_FLUSH`変数を追加して、[Lambda拡張機能の環境変数](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/env-variables-lambda/)を更新しました。
* 設定が必要な環境変数をリストするように、[Lambdaに対するJavaエージェントのアプローチ](/docs/apm/agents/java-agent/getting-started/java-agent-approaches-lambda/)を更新しました。
* Autopilotが最大1,000文字のメッセージを受け付けるという説明を追加し、[AutopilotをSlackに接続する](/docs/agentic-ai/autopilot/connect-to-slack/)を更新しました。
* ブラウザ内のシンボル化が処理された例外にのみ適用されることを説明するように、[Flutter アプリケーションのモニター](/docs/mobile-monitoring/new-relic-mobile-flutter/monitor-your-flutter-application/)および[.NET MAUI アプリケーションのモニター](/docs/mobile-monitoring/new-relic-mobile-maui-dotnet/monitor-your-net-maui-application/)を更新しました。
* 「Default account key」を「Original account key」に名前を変更するように、[New Relic APIキー](/docs/apis/intro-apis/new-relic-api-keys/)を更新しました。
* &quot;eAPM&quot;を&quot;eBPFオブザーバビリティ&quot;に変更するために、[eBPFオブザーバビリティのインストレーション](/docs/ebpf/linux-installation/)と[価格と請求](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/new-relic-one-pricing-billing/)のドキュメントを更新しました。
* ソースマップのサイズ制限の引き上げをリクエストするためにNew Relicサポートへ案内するように、[React Native JavaScriptエラーレポート](/docs/mobile-monitoring/new-relic-monitoring-react-native/react-native-agent-js-error-reporting/)を更新しました。

### 新機能

* [NRQLマクロが一般提供されました](/whats-new/2026/10/whats-new-10-26-nrql-macros-ga): NRQL式を、再利用可能な名前付きショートカットとして保存し、クエリやダッシュボード全体で使用できます。
* [Oracleクラウドインフラストラクチャインテグレーションが一般提供されました](/whats-new/2026/10/whats-new-10-27-oci-ga)：単一のプラットフォームで、AWS、Azure、Google Cloudと並んでNew RelicでOCIメトリクスとログをモニターします。
