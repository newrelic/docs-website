### 新しいドキュメント

* [NVIDIA Management Library（NVML）インテグレーション](/docs/infrastructure/host-integrations/host-integrations-list/nvml-integration)に関する新しいドキュメントでは、infrastructureエージェントとNRI-Flexを使用してGPU使用率とパフォーマンスメトリクスをモニターする方法について説明しています。

* Vulnerability Management（脆弱性管理）がうまく機能しすぎている場合、最近のアップデートにより、懸念のない[脆弱性を無視](/docs/vulnerability-management/change-vulnerability-status)できるようになりました。

* OpenTelemetryドキュメントカテゴリの大規模な改訂を行いました。これには、確実な出発点となる新しい[APM：OpenTelemetryでアプリとサービスをモニターする](/docs/more-integrations/open-source-telemetry-integrations/opentelemetry/get-started/apm-monitoring/opentelemetry-apm-intro)が含まれます。その他の変更点：

  * **OpenTelemetry &gt; Get started**カテゴリを再編成し、サブカテゴリに一貫した**Overview**ドキュメントを追加しました。
  * 内容を明確にするため、ドキュメントのタイトルを変更しました。
  * 関連情報を見つけやすくするために、関連ドキュメントを統合しました。

* ログを解析するために正規表現やGrokパターンを記述したくない方にとって、[クエリ時の解析](/docs/logs/ui-data/query-time-parsing)は、UIで直接ログを解析するための強力なツールです。（この記事には素晴らしいスクリーンショットが多数含まれています）。

### 主な変更点

* インストールを容易にし、ドキュメントが正確で最新であることを保証するために、オンホストインテグレーションのドキュメントの書き換えを継続しました。今週の更新：[ポート](/docs/infrastructure/host-integrations/host-integrations-list/port-monitoring-integration)および[Unix](/docs/infrastructure/host-integrations/host-integrations-list/unix-monitoring-integration)モニタリングインテグレーション。
* 単一および複数アカウントの組織における[データ保持期間のルール](/docs/data-apis/manage-data/manage-data-retention)の管理および使用方法を明確にしました。
* バージョン追跡情報を[エラー追跡](/docs/triage-inbox/errors-inbox)から[バージョン追跡](/docs/triage-inbox/version-tracking)に移動し、それに伴いいくつかの利便性の向上を行いました。
* 2024年10月をもって、コンテナ化されたプライベートミニオン（CPM）とレガシーsyntheticランタイムバージョンのサポートを終了します。6月に、これらのレガシーランタイムを使用した新しいモニターの作成をブロックします。これに関して、この[サポート終了のお知らせ](/docs/apis/synthetics-rest-api/monitor-examples/manage-synthetics-monitors-rest-api/#before-you-start)のような注意事項を追加しました。

### マイナーチェンジ

* [NerdGraphワークフローのチュートリアル](/docs/apis/nerdgraph/examples/nerdgraph-api-workflows/#update-workflow)に、ワークフロー名と2つのチャネルを追加するGraphQLの例を追加しました。
* [カスタムログ解析ルールを作成する](/docs/logs/ui-data/parsing/#custom-parsing)際、フォーマットされていないログを解析UIに貼り付ける必要があるという注意事項を追加しました。
* ブラウザの[ ユーザー権限](/docs/accounts/accounts-billing/new-relic-one-user-management/user-permissions/#browser)** **リストに セッションリプレイの表示 を追加しました。
* 誤った[Sonarqube設定](/docs/infrastructure/host-integrations/host-integrations-list/sonarqube-monitoring-integration)ファイルの例を修正しました。
* `LlmChatCompletionMessage`、`LlmChatCompletionSummary`、および`LlmEmbedding`のイベントタイプについて、データディクショナリに属性を追加しました。
* [スタイルガイド](/docs/style-guide/capitalization/product-capability-feature-usage)に、セッションリプレイの大文字化に関するガイダンスを追加しました。
* 導入段落に[ログ解析](/docs/logs/ui-data/parsing)のより明確な定義を追加しました。
* [FedRAMP準拠エンドポイント](/docs/security/security-privacy/compliance/fedramp-compliant-endpoints)のリストに `gov-aws-api.newrelic.com` を追加しました。
* [Azureクライアントシークレットトークンをローテーションする](/docs/apis/nerdgraph/examples/nerdgraph-cloud-integrations-api-tutorial/#rotate-azure-token)方法を示すNerdGraphミューテーションの例を追加しました。
* 顧客からのフィードバックに応えて、[チャートの使用](/docs/query-your-data/explore-query-data/use-charts/use-your-charts)を更新し、UIの**Numeric**、**Date**、**Duration**、および**Time to Now**チャートオプションを明確にしました。
* UIの[Errors Inbox OpenTelemetry](/docs/more-integrations/open-source-telemetry-integrations/opentelemetry/view-your-data/opentelemetry-errors-inbox-page)ページに、新しい`http.response.status_code`グループメッセージ値が追加されました。
* [アラート通知メッセージテンプレート](/docs/alerts-applied-intelligence/notifications/message-templates/#escape)がエスケープ文字をサポートするようになり、JSONを破壊する文字などを回避できるようになりました。
* コードブロックの見栄えが大幅に改善されたことにお気づきかもしれません。よりきれいで読みやすくなるように、多くのコードブロックを言語固有の構文ハイライトで更新しました。
* Python APMエージェントの[data\_source\_generator](/docs/apm/agents/python-agent/python-agent-api/datasourcegenerator-python-agent-api/#example)および[register\_data\_source](/docs/apm/agents/python-agent/python-agent-api/registerdatasource-python-agent-api/#examples) APIドキュメントのコード例を更新しました。
* [Azureログ転送のトラブルシューティング](/docs/logs/forward-logs/azure-log-forwarding/#troubleshoot)のヘルプを拡充しました。
