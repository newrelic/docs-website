### 主な変更点

* インストールを容易にし、ドキュメントが正確で最新であることを保証するために、[RabbitMQ](/install/rabbitmq/)、[JMX](/install/jmx/)、[Apache Flink](/install/apache-flink/)、および[HAProxy](/install/haproxy/)のオンホストインテグレーションのドキュメントを見直し、書き直しました。
* [AWS Lambdaサーバーレス監視](/docs/serverless-function-monitoring/aws-lambda-monitoring/get-started/compatibility-requirements-aws-lambda-monitoring/)について、サポートされているランタイムバージョン、依存関係、および非推奨となった.NET NuGetパッケージSDKに関する情報を更新しました。
* New Relicの2024年のコンプライアンス状況を反映するため、[FedRAMP](/docs/security/security-privacy/compliance/certificates-standards-regulations/fedramp/)、[HIPAA](/docs/security/security-privacy/compliance/certificates-standards-regulations/hipaa/)、[ISO-27001](/docs/security/security-privacy/compliance/certificates-standards-regulations/iso-27001/)、[SOC2](/docs/security/security-privacy/compliance/certificates-standards-regulations/soc2/)、[TISAX](/docs/security/security-privacy/compliance/certificates-standards-regulations/tisax/)、[データ暗号化](/docs/security/security-privacy/compliance/data-encryption/)、および[HITRUST CSF](/docs/security/security-privacy/compliance/hitrust/)のコンプライアンスドキュメントを更新しました。
* 読みやすさと品質を向上させるため、[NRQLドキュメント](/docs/nrql/get-started/introduction-nrql-new-relics-query-language)の全面的な見直しと再編成を継続しました。
* Androidの[モバイル監視のオフラインストレージ](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/configure-settings/#android-offline-storage)がデフォルトで無効になっていることを明確にし、[オフラインストレージ設定](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/set-max-offline-storage/#android)のドキュメントを更新しました。
* [Unityモバイル監視設定](https://docs.newrelic.com/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/configure-settings/#unity)の情報を追加しました。
* [AWS PrivateLink](/docs/data-apis/custom-data/aws-privatelink)の外形監視エンドポイントを追加しました。
* [Statsdインテグレーション](/docs/more-integrations/open-source-telemetry-integrations/statsd/statsd-monitoring-integration/#troubleshooting)のドキュメントにトラブルシューティングのセクションを追加しました。
* .NET設定オプションに新しい[rules要素の計装](/docs/apm/agents/net-agent/configuration/net-agent-configuration/#instrumentation-rules)セクションを追加しました。
* 外形監視の[ジョブマネージャー移行のバージョン要件](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-transition-guide)を更新しました。

### 小さなアップデート

* 外形監視の[Kubernetes `vsePassphrase`](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-configuration/#kubernetes-env-config)環境変数を追加しました。
* リンク切れの内部リンクをいくつか修正しました。
* [Errors Inboxのエラーステータス](/docs/triage-inbox/errors-inbox)セクションを更新し、新しい画像とUIに関する詳細を追加しました。
* [外形監視ランタイムモジュール](/docs/synthetics/synthetic-monitoring/using-monitors/manage-monitor-runtimes)のバージョンを更新しました。
* [Fluent Bitプラグインで複数のログソース](/docs/logs/forward-logs/fluent-bit-plugin-log-forwarding)を使用する方法に関する情報を追加しました。
* [NerdGraph APIを使用してログのライブアーカイブをクエリする](/docs/logs/get-started/live-archives)方法を追加しました。
* さまざまなマイナーなスタイルと画像の問題を更新および修正しました。
* NerdGraphアプライドインテリジェンスの[カーソルページネーションの例](/docs/apis/nerdgraph/examples/nerdgraph-api-notifications-channels/#paginate)を追加しました。
* 破損していた[NVIDIA GPUインテグレーション](/docs/infrastructure/host-integrations/host-integrations-list/nvidia-gpu-integration)の設定を修正しました。
* Androidモバイル監視の[マッピングアップロードホスト](/docs/mobile-monitoring/new-relic-mobile-android/install-configure/android-agent-crash-reporting)設定に関するセクションを追加しました。
* Java用の[Temporal 監視インテグレーション](/docs/infrastructure/host-integrations/host-integrations-list/temporal-monitoring-integration)の設定詳細を追加しました。
* [GCP Cloud Functions](/docs/infrastructure/google-cloud-platform-integrations/get-started/integrations-custom-roles)の不足していた権限を追加しました。
* [セキュリティ脆弱性の報告](/docs/security/security-privacy/information-security/security-bulletins/#report)に関連するドキュメントのリンクを更新しました。
* [協調的な開示プロセス](/docs/security/security-privacy/information-security/software-development-lifecycle)で使用しなくなったHackerOneへの言及を削除するために、セキュリティドキュメントを更新しました。
* [ブラウザ監視のプロキシメソッド](/docs/browser/new-relic-browser/configuration/proxy-agent-requests)を使用する際の法的な影響に関する情報を追加しました。
* Windows上の`SystemSample`イベントの[`coreCount`](https://docs.newrelic.com/attribute-dictionary/?event=SystemSample&attribute=coreCount)属性が、プロセッサの現在のインスタンスのプロセッサ数をカウントすることを明確にしました。
* Meraki APIとネットワークデバイスのsyslogに関連する変更を説明するために、[ネットワークパフォーマンス監視設定](/docs/network-performance-monitoring/advanced/advanced-config)のドキュメントを更新しました。
* [KubernetesのPrometheus OpenMetricsインテグレーション](/docs/infrastructure/prometheus-integrations/install-configure-prometheus-agent/migration-guide)のEOL日を削除しました。
* 左側のナビゲーションで、Serverlessレガシー手動計装を[レイヤーレス手動計装](/docs/serverless-function-monitoring/aws-lambda-monitoring/enable-lambda-monitoring/enable-serverless-monitoring-aws-lambda-layerless/)に名前変更しました。
* 明確さとスタイル ガイドとの一貫性を向上させるために、さまざまなマイナーなコピー編集を行いました。
