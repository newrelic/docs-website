### 新機能

* `activeLogs`にログレベルを追加しました：`true`の代わりに、最小レベルとして`"INFO"`、`"WARNING"`、または`"ERROR"`を渡してください。`true`は引き続きすべてのログを有効にし、`false`は引き続きログを無効にします。
* バッファドロップのログ出力を追加しました：イベントバッファの使用量が85％に達したときにINFOメッセージ、90％に達したときにWARNINGメッセージを出力し、ドロップされたイベントごとに累積ドロップ数を含む1行のログを出力します。
* エージェントのログ出力に`QOE_AGGREGATE`の値を追加しました。

### バグ修正

* 広告の終了後にMediaTailor SSAIの広告属性が`VideoAction`イベントに追加される問題を修正しました。これらは現在`VideoAdAction`イベントにのみ付加されるようになり、各広告の終了時に広告レベルのキーがエージェントから削除されます。
* MediaTailor SSAIの`adSrc`が空になる問題を修正しました。現在はストリームURLが含まれるようになりました。
* MediaTailorトラッカーが広告のタイミングとカウントの属性（`timeSinceAdStarted`、`timeSinceAdBreakBegin`、`numberOfAds`）を上書きする問題を修正しました。
* `contentRenditionHeight`および`contentRenditionWidth`が常に720x480、1280x720、または1920x1080を報告する問題を修正しました。これらは現在`GetVideoMode()`から取得されるようになったため、`videoMode`と一致します（例：`2160p`は2160 x 3840となります）。
* デバイスが同一秒内にリリースされたときに、`nrSessionId`と`viewId`の値が競合する問題を修正しました。セッションIDは`GetRandomUUID()`を使用するようになり、`NewRelicVideoStart()`ごとに`nrVideoCounter`がリセットされなくなりました。
