## メモ

* シームレスなクロステレメトリーナビゲーションを可能にするため、すべてのAWS Lambdaログエントリに`trace.id`の相関関係を追加しました。
* * APMの接続失敗に対する回復力を向上させ、プロセスシャットダウン中のテレメトリードロップに関する詳細な診断レポートを追加しました。

## 修理済み

* 一時的なネットワークの問題中にサイレントペイロードドロップを排除するため、信頼性の高いテレメトリー配信を確保しました。
* APM接続の再試行が指定されたAPMパスに維持されるようにする問題を解決しました。
* APMの再試行はAPMパスに維持されます。
