### 新機能

#### SlackでAIを使用して調査する

Slackの集計通知に<DNT>**Investigate with AI**</DNT>ボタンが含まれるようになりました。クリックすると、Autopilotが集計を分析し、インシデントのトリアージ、問題の概要、推奨されるアクションなどの結果を通知スレッドに直接投稿します。

セットアップ手順については、[AutopilotをSlackに接続する](/docs/agentic-ai/autopilot/connect-to-slack)をご覧ください。

### ワンクリックのSlack調査とより正確なタイムウィンドウ

#### 新機能

* **ワンクリックでSlackでの調査を開始：**Slackの集計通知に<DNT>**Investigate with AI**</DNT>ボタンが含まれるようになりました。これをクリックすると、Autopilotが集計を分析し、インシデントのトリアージ、問題の概要、推奨されるアクションなどの結果を通知スレッドに直接投稿します。
* **インシデントを起点とした分析：**過去のインシデントについて質問すると、Autopilotはタイムウィンドウを現在時刻まで延長するのではなく、インシデント発生時の前後に設定できるようになりました。

#### 改善と修正

* **New Relicページへのリンク：** Autopilotの応答に含まれる他のNew Relicページへのリンクを修正しました。
* **インフラストラクチャホストのログ：** 調査中に、Autopilotがホスト名でインフラストラクチャホストのログを取得できるようになりました。
* **時間のフレーズ：**Autopilotは、「今週」、「先月」、「先週から」、「過去1日」、「最近」などの一般的な期間のフレーズをよりよく理解し、「先月」（前のカレンダー月）と「過去1か月」（過去30日間）を区別するようになりました。
* **質問した期間の結果：** ゴールデンメトリクスのサマリーと変更イベントの検索は指定した期間を対象とするようになったため、その期間外の数値やデプロイメントが分析に表示される可能性が低くなりました。
* **概要の完全なリスト：**特定の状態にあるアイテムについて尋ねると、調査の概要に、見つかったすべてのアイテムの名前が記載される可能性が高くなります。Autopilotは、入力された時間を、タイムゾーンを含めて記述されたとおりに保持します。
* **エンティティ検索結果：**名前で検索すると、一致するすべてのエンティティタイプが返されるようになり、優先されるタイプが先頭に表示されます。Autopilotが結果を切り捨てる場合、一致した件数を示し、残りの結果を提示します。
* **新しくオープンした問題：**Autopilotは、過去数分間にオープンした問題の集計イベントを取得できるようになりました。
* **ログ検索の詳細：**アプリケーションログに関する回答で、検索されたログパーティションとアカウントが明記されるようになりました。
* **ログの要約：**タイムウィンドウ内にログが存在しない場合など、集計のために要約するログがない場合に、Autopilotがその旨を説明するようになりました。
* **保存された設定：**Autopilotは、無関係なエスカレーションチャネルの除外など、現在の質問に関連する保存された設定のみを適用します。
* **レジリエントな調査：** デプロイメント中に調査が完了する可能性が高くなります。
* **インテグレーションの認証情報が期限切れになった場合のメッセージ：**接続されているMCPインテグレーションの認証情報の有効期限が切れると、バナーにインテグレーションの再接続を促すプロンプトが表示されるようになりました。
