### 新機能

* Autopilotは、NRQLクエリからAPM、集計分析に至るまで、すべての主要なツールに対して、改善および最適化されたサイズ制限と、よりスマートな予算追跡を適用するようになりました。これにより、1つの過大な応答や単一のツール呼び出しの失敗が、調査全体に影響を及ぼす可能性が低くなります。
* Autopilotがコンテキストを圧縮し、requestsをルーティングし、メモリとナレッジを取得する方法に対する内部的な改善により、特に大量の処理を行うアカウントにおいて、回答の品質を犠牲にすることなく処理時間を短縮できます。平均ランタイムは約20％短縮されました。
* 以前は膨大なデータ量によって実行が失敗する可能性があった、多数のエンティティ、アラート、またはログが存在する複雑な環境の調査に関する改善です。

### バグ修正

* AutopilotのSlackでの応答が、実際に取得したデータにより正確に基づくようになりました。
* Autopilotは、個々のステップの失敗からより適切に回復し、可能な限り処理を継続するようになりました。これにより、不完全な分析が減少します。
* 複雑なクエリによってAutopilotがエラーを出さずに失敗する可能性がある問題を修正しました。これらのケースでは、調整を行えるように明確な説明とともに早期に失敗するようになりました。
* 一般的な「問題が発生しました」というメッセージは、何が発生したか、次に何を試すべきかについての具体的な詳細を提示する提案に置き換えられました。
* 「アクティブな問題の数」のチャートが、応答内のテキストの詳細とより適切に一致するようになりました。
