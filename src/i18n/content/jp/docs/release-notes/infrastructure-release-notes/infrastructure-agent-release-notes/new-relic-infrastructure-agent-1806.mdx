## メモ

### セキュリティに関するお知らせ

* chore(deps): golang.org/x/net を v0.60.0 にバンプします、過剰な SETTINGS フレームによる net/http2 のサービス拒否である CVE-2026-78669（HIGH）を [#2364](https://github.com/newrelic/infrastructure-agent/pull/2364) で修正します

### バグ修正

* fix: [#2354](https://github.com/newrelic/infrastructure-agent/pull/2354) で、一時フォルダーのクリーンアップに失敗した場合にエージェントがクラッシュするのを防ぎ、ERROR\_INVALID\_FUNCTION/STATUS\_NOT\_IMPLEMENTED の場合に手動削除にフォールバックするように修正します
* 修正：[#2357](https://github.com/newrelic/infrastructure-agent/pull/2357) でsafe dirチェックをコンフィグで非表示にしました
* 修正：[#2359](https://github.com/newrelic/infrastructure-agent/pull/2359) でコアインテグレーションを更新
* [#2362](https://github.com/newrelic/infrastructure-agent/pull/2362) で #2306 をリバートします

### その他の変更

* chore(deps): github.com/containerd/containerd をバンプします[#2353](https://github.com/newrelic/infrastructure-agent/pull/2353) で 1.7.35 から 1.7.36 へ
* [#2360](https://github.com/newrelic/infrastructure-agent/pull/2360) でif else条件を最適化しました
* chore(deps): github.com/moby/sys/user をバンプします[#2363](https://github.com/newrelic/infrastructure-agent/pull/2363) で 0.3.0 から 0.4.1 へ
* chore: [#2365](https://github.com/newrelic/infrastructure-agent/pull/2365) で組み込みOHIバージョン（nri-docker、nri-flex、nri-winservices、nri-prometheus）を更新

### サポートステートメント:

エージェントの新しいバージョンがリリースされました。標準的な手順に従って、[infrastructureエージェントをアップデート](/docs/infrastructure/install-configure-manage-infrastructure/update-or-uninstall/update-infrastructure-agent)してください。

最新のエージェントバージョンが利用可能になり次第、アップデートすることをお勧めします。最新バージョンにアップグレードできない場合は、エージェントを90日以内のバージョンにアップデートしてください。[エージェントを最新状態で維持する](https://docs.newrelic.com/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent/)について詳しくお読みください。

エージェントのリリースとサポート日に関する情報については、[New Relic InfrastructureエージェントのEOLポリシー](https://docs.newrelic.com/docs/infrastructure/infrastructure-agent/infrastructure-agent-eol-policy/)をご覧ください。
