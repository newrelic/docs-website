## メモ

### 🛡️ セキュリティ通知

* [#2410](https://github.com/newrelic/infrastructure-agent/pull/2410) でGoを1.27.4に更新しました。
* [#2411](https://github.com/newrelic/infrastructure-agent/pull/2411) で組み込みOHIのバージョン（nri-docker v2.10.1、nri-flex v1.18.19、nri-winservices v1.5.8、nri-prometheus v2.31.1）を更新しました。

### 🚀 機能強化

* [#2381](https://github.com/newrelic/infrastructure-agent/pull/2381) でSUSE 16 OSのサポートを追加しました。
* [#2367](https://github.com/newrelic/infrastructure-agent/pull/2367) でAgent Controlパッケージ内のnrjmxラッパースクリプトとエージェントタイプを公開しました。

### 🐞 バグ修正

* [#2348](https://github.com/newrelic/infrastructure-agent/pull/2348) で複数リージョン（ステージング/EU/JP）をサポートするためのカナリアプルーニングを行いました。
* [#2406](https://github.com/newrelic/infrastructure-agent/pull/2406) でSLES 16.0でrpmプラグインが動作するようにrpm ndbデータベースファイルを追加しました。
* [#2407](https://github.com/newrelic/infrastructure-agent/pull/2407) でSLES 16で/etc/ssh/sshd\_configが見つからない場合に/usr/etc/sshからsshd設定を読み込むようにしました。
* [#2409](https://github.com/newrelic/infrastructure-agent/pull/2409) でOpenProcessを使用してエージェントをそのWindowsジョブオブジェクトに追加しました。

### サポートステートメント:

エージェントの新しいバージョンがリリースされました。標準的な手順に従って、[infrastructureエージェントをアップデート](/docs/infrastructure/install-configure-manage-infrastructure/update-or-uninstall/update-infrastructure-agent)してください。

最新のエージェントバージョンが利用可能になり次第、アップデートすることをお勧めします。最新バージョンにアップグレードできない場合は、エージェントを90日以内のバージョンにアップデートしてください。[エージェントを最新状態で維持する](https://docs.newrelic.com/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent/)について詳しくお読みください。

エージェントのリリースとサポート日に関する情報については、[New Relic InfrastructureエージェントのEOLポリシー](https://docs.newrelic.com/docs/infrastructure/infrastructure-agent/infrastructure-agent-eol-policy/)をご覧ください。
