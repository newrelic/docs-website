## メモ

### 🛡️ セキュリティ通知

* [#2292](https://github.com/newrelic/infrastructure-agent/pull/2292)で、パストラバーサルによるリモートコード実行の脆弱性を修正しました。
* [#2232](https://github.com/newrelic/infrastructure-agent/pull/2232)で、トークンのスコープを縮小するためにGitHub Actionsワークフローに明示的な権限を追加しました。
* google.golang.org/grpcを更新[#2296](https://github.com/newrelic/infrastructure-agent/pull/2296)のgo.modで1.79.3から1.82.1に更新
* [#2302](https://github.com/newrelic/infrastructure-agent/pull/2302)で、既知のCVEを修正するために組み込みOHIのバージョン（nri-docker、nri-flex）を更新しました。
* [#2301](https://github.com/newrelic/infrastructure-agent/pull/2301)でTrivyスキャンによってフラグが立てられた脆弱な依存関係を更新

### 🚀 機能強化

* [#2290](https://github.com/newrelic/infrastructure-agent/pull/2290)で、disable\_plugin\_default\_dir\_scanを介してデフォルトのインテグレーションの場所を無視するサポートを追加しました。
* [#2293](https://github.com/newrelic/infrastructure-agent/pull/2293)でAgent Controlが使用する環境変数を公開
* [#2295](https://github.com/newrelic/infrastructure-agent/pull/2295)で、AWSのタグと一致するようにOCIタグのサポートを追加しました（フェーズ1 + フェーズ2）。
* [#2300](https://github.com/newrelic/infrastructure-agent/pull/2300)で、Agent Controlが管理するエージェントに対してNRIA\_DISABLE\_PLUGIN\_DEFAULT\_DIR\_SCANをデフォルトで有効にしました。
* [#2291](https://github.com/newrelic/infrastructure-agent/pull/2291)で、Agent Controlのアーティファクトからnri-flexを削除しました。

### 🐞 バグ修正

* [#2303](https://github.com/newrelic/infrastructure-agent/pull/2303)で、リリースおよびカナリアワークフローの欠落していたジョブ権限を復元しました。

### サポートステートメント:

エージェントの新しいバージョンがリリースされました。標準的な手順に従って、[infrastructureエージェントをアップデート](/docs/infrastructure/install-configure-manage-infrastructure/update-or-uninstall/update-infrastructure-agent)してください。

最新のエージェントバージョンが利用可能になり次第、アップデートすることをお勧めします。最新バージョンにアップグレードできない場合は、エージェントを90日以内のバージョンにアップデートしてください。[エージェントを最新状態で維持する](https://docs.newrelic.com/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent/)について詳しくお読みください。

エージェントのリリースとサポート日に関する情報については、[New Relic InfrastructureエージェントのEOLポリシー](https://docs.newrelic.com/docs/infrastructure/infrastructure-agent/infrastructure-agent-eol-policy/)をご覧ください。
