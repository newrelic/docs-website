## 更新

[以前にお知らせした](https://support.newrelic.com/s/hubtopic/aAX8W0000008cts/important-upcoming-changes-to-capabilities-and-support-across-errors-classic)とおり、クラウドインテグレーション（AWS、Azure、GCP）からプッシュされるインベントリデータのサポートを終了します。

### 何が変更されますか？

インベントリデータは現在、多くのAWS、Azure、およびGCPインテグレーションで収集されています。これは、静的な設定データまたはリソースのメタデータを表します。インベントリ内のホストまたはオンホストインテグレーションからの情報は、この変更の影響を受けません。

### インベントリとは何ですか？

インベントリデータとは、サービスの状態や設定に関する情報です。例：サービスの設定。データは、元のインフラストラクチャエクスペリエンスの「インベントリ」ページおよび一部のインテグレーションダッシュボードに表示されます。インベントリデータへの変更により、クエリやアラートの対象となるNew Relic `InfrastructureEvent` イベントが生成されます。

### 今後利用できなくなる機能

* Infrastructure &gt; Inventoryを参照する場合、`aws/*`、`azure/*`、または`gcp/*`からのソースは利用できなくなります。
* Infrastructure &gt; AWS | Azure | GCP | GovCloudで利用可能な、インベントリまたはインフラストラクチャのイベントウィジェットを含む組み込みダッシュボードは、データを表示しなくなります。これらのダッシュボードは、標準のNew Relicダッシュボードとして移行される予定であり、infrastructureモニタリングの元のダッシュボードエクスペリエンスでは利用できないすべての新機能（編集、共有、新しい視覚化など）を利用できるようになります。
* `InfrastructureEvent`からの`aws`、`azure`、または`gcp`のソースを使用するクエリは、データを報告しなくなります。

### この機能が非推奨になるのはなぜですか？

* 顧客は、非推奨ではないHost Inventoryにより多くの価値を見出していますが、クラウドインテグレーションにはそれほど価値を見出していません。

### 代替案

* ポーリングインテグレーションでインベントリとして利用可能な属性のほとんどは、メトリクスのメタデータまたはタグとしても利用できるため、この情報をクエリできます。
* 一部のインテグレーションでは、インベントリで利用可能な同じ情報を標準のNew Relicイベントとしても公開していました。たとえば、AWS Healthインテグレーションです。

### これはAWS CloudWatch Metric Streamsと、Azure &amp; GCPの将来のインテグレーションにどのような影響を与えますか？

* インベントリはAWS CloudWatch Metric Streamsでは利用できないため、この機能への影響はありません。
* AzureおよびGCP向けの新しいインテグレーションは、MELTテレメトリー：メトリクス、イベント、ログ&amp;トレースに焦点を当てており、特にメトリクスに重点を置いています。

### フィードバック

この機能が非推奨になった後、問題が発生した場合は、UIの次の手順に従ってヘルプを利用できます：

1. New Relic のアカウントにログインします。
2. 包括的な[ヘルプセンター](https://one.newrelic.com/help-xp)をご覧ください。ここには、豊富な情報とリソースが含まれています。
3. さらにサポートが必要な場合は、**Create a Support Case** \[サポートケースを作成]をクリックしてください。担当チームがサポートいたします。
