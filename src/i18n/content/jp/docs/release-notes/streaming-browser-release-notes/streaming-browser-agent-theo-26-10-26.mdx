### 新機能

* **THEOplayer Web SDKのサポート：**Browser環境向けのNew Relic THEOplayerトラッカーの最初の安定版リリースです。`@newrelic/video-theo/browser`経由でインポートします。
* **Browserのエントリポイント：**Browser専用バンドルのVega/接続デバイスパイプラインを除外する専用の`@newrelic/video-theo/browser`サブパスです。
* **ビットレートトラッキング：** `contentBitrate`、`contentManifestBitrate`、`contentSegmentDownloadBitrate`、および`contentNetworkDownloadBitrate`を報告します。
* **レンディション品質のトラッキング：**トラックレベルの品質変更イベントを通じて、アクティブなレンディションの高さ、幅、および帯域幅をトラッキングします。
* **マルチフォーマットのサポート：** THEOplayerのネイティブなアダプティブストリーミングにより、HLSおよびDASHストリームがサポートされています。

### 改良点

* **`@newrelic/video-core` が 5.1.0 に更新され**、`getHarvester()` 経由で `sendStart`/`sendEnd` の QoE ドレイン コールバックが有効になりました。
* **プレーヤー名：**`playerName`属性は`THEOplayer`として報告されます。
* **エラーコードの処理：** SDKが提供するコードが利用できない場合、`errorCode` はイベントから省略され、NRDBでの無意味なセンチネル値を回避します。
