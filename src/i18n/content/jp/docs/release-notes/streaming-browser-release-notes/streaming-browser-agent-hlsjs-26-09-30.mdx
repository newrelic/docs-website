### バグ修正

* HLS再生が開始された後、`getSrc()` が実際のマニフェストURLではなくブラウザの一時的な `blob:` URLを返す問題を修正しました。トラッカーは基盤となるHls.jsインスタンスからURLを読み取るようになったため、再生中は実際のマニフェストURLが一貫して報告されます。
