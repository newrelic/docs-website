### 新機能

* Amazon Vega（Kepler/Fire TVクラス）デバイス向けのHLS.jsトラッカーである`VegaTracker`を追加しました。新しい`@newrelic/video-hls/vega`サブパスエントリポイント経由でインポートしてください。`VegaTracker` は `HLSTracker` を拡張し、ブラウザー・パイプラインの代わりにコネクテッド・デバイス・パイプラインを経由してテレメトリーをルーティングします。CJSおよびESMの両方として提供されます。

### バグ修正

* New Relic イベントの`trackerName`属性が期待値と一致するように、`VegaTracker` によって報告されるトラッカー名を `'vega-hls'` から `'hls'` に修正しました。
