### 改良点

* **`@newrelic/video-core`が5.1.1に更新され**、この特定のバージョンに固定されたため（以前は`^5.1.0`）、すべてのビルドで同じコアリリースが使用されます。
* **依存関係の固定：** `dependencies`および`devDependencies`は、`package-lock.json`ですでに解決されている正確なバージョンに固定されるようになりました。そのため、新規インストール時に、新しく公開されたビルドツールのリリースが取得されることはなくなりました。
