### 新機能

* **`/browser`サブパスエクスポート：** 未使用のVega/接続デバイスのコードを除外する`@newrelic/video-hls/browser`エントリポイントが利用可能になり、ブラウザの消費者向けのバンドルサイズが縮小されます。`exports`フィールドに対応していないバンドラー向けに、`browser.js`ファイルシステムシムも含まれています。
* **名前付きエクスポート：** `{ HLSTracker }`は、ルートと`/browser`の両方のエントリポイントで、既存のデフォルトエクスポートとともに名前付きエクスポートとして利用できるようになりました。

### 改良点

* **`@newrelic/video-core`が5.1.0に更新されました**、これには、TypeScript宣言ファイル、アップストリームのバグ修正、および依存関係のパッチが含まれています。
