### 新機能

* **`/browser` サブパスエクスポート：** バンドルされた`@newrelic/video-core`依存関係から未使用のconnected-deviceパイプラインを除外し、バンドルを軽量に保つ`@newrelic/video-caf/browser`エントリポイントが利用可能になりました。`exports`フィールドに対応していないバンドラー向けに、`browser.js`ファイルシステムシムも含まれています。
* **名前付きエクスポート：** `{ CAFTracker }`は、ルートと`/browser`の両方のエントリポイントで、既存のデフォルトエクスポートとともに名前付きエクスポートとして利用できるようになりました。

### 改良点

* **`@newrelic/video-core`が5.1.0に更新されました**、これには、TypeScript宣言ファイル、アップストリームのバグ修正、および依存関係のパッチが含まれています。
