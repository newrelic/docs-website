## v1.322.0

### 特徴

#### SPVイベント用のオブザーバーAPIを含める

エージェントローダーの実行前に発生した`securitypolicyviolation`イベントをキャッチするには、`ReportingObserver` APIを使用してください。実際には、既存の設定やバグがFirefoxおよびSafariの収集に影響を与えるため、これは主にChromiumブラウザーに影響します。

#### MFEマニフェスト

マイクロフロントエンドが自身の既知のアセット（スクリプト、スタイルシート、画像、フォント）を宣言できるように、オプションの`manifest`を`register()` APIに追加します。これにより、エージェントはエラー、ログ、AJAX呼び出し、WebSocket、およびリソース・タイミング・イベントをそれに正確に属性付けることができます — `register()`を呼び出したスクリプト以外のスクリプトによってロードされたアセットであっても。また、オプトインの`timingMethod`により、マニフェストは宣言されたアセット全体で`MicroFrontEndTiming`のフェッチ/実行ウィンドウを拡大できます。

#### 登録検証の警告を追加

登録APIに提供されたターゲットから明らかな問題が検出された場合、ローカルデバッグ警告を発行します。

### バグ修正

#### リスナーのリークを修正するため、web-vitalsを4.2.4から6.2.1にアップグレードしてください。

バンドルされているweb-vitalsライブラリを4.2.4から6.2.1にアップグレードし、無制限の`document` `visibilitychange`リスナーのリークを修正しました：web-vitals 4.xはINPレポートサイクルごとに永続的なリスナーを登録するため、長時間開かれているページでは数百のリスナーが蓄積されます。また、エージェントが出力する属性名に変更を加えることなく、エージェントが影響を受けるv5/v6アトリビューションAPIの変更（`LCPAttribution.element` → `target` の名前変更、および新たにオプションとなったINP/CLSアトリビューションフィールド）を取り込みました。

## サポートステートメント

New Relic では、最新の機能とパフォーマンス上のメリットを確実に得られるよう、エージェントを定期的にアップグレードすることをお勧めします。古いリリースは[サポート終了](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/)になるとサポートされなくなります。リリース日は、エージェント バージョンの元の公開日を反映します。

以下の機能は現在リミテッドプレビューであり、標準サポートは提供されません：

* [register() API](https://docs-preview.newrelic.com/docs/browser/register) 経由の[ マイクロフロントエンド（MFE）監視](https://docs-preview.newrelic.com/docs/browser/micro-frontend-monitoring/)
* [BrowserPerformance &quot;resource&quot;](https://docs.newrelic.com/docs/browser/new-relic-browser/browser-pro-features/page-resources/)タイプのイベント

新しいブラウザエージェントのリリースは、一定期間にわたって小さな段階で顧客に展開されます。 このため、リリースがアカウントでアクセス可能になる日付は、元の公開日と一致しない可能性があります。詳細については、この[ステータス ダッシュボード](https://newrelic.github.io/newrelic-browser-agent-release/)をご覧ください。

当社の[ブラウザサポートポリシー](https://docs.newrelic.com/docs/browser/new-relic-browser/getting-started/compatibility-requirements-browser-monitoring/#browser-types)に従い、Browserエージェントのv1.322.0は、以下のブラウザおよびバージョン範囲向けに構築され、テストされました：Chrome 142～152、Edge 141～151、Safari 18～27、およびFirefox 144～154。モバイルデバイスについては、v1.322.0はAndroid OS 16およびiOS Safari 18～26.2向けに構築され、テストされました。
