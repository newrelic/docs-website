## v1.323.0

技術的な変更履歴の全文とビルドサイズ情報については、**[GitHubでこのリリースをご覧ください →](https://github.com/newrelic/newrelic-browser-agent/releases/tag/v1.323.0)**。

### 特徴

#### ERRORモードからFULLモードへの切り替え時にSRをハーベストします。

セッションリプレイをセッショントレースと同じ方法で処理するようにエージェントを更新し、SRが`error`モードから`full`モードに切り替わるときにリプレイハーベストをトリガーします。

#### AJAXペイロードの内部導入メトリクスを追加

品質保証および改善を目的として、AJAXペイロードトラッキングの採用を測定する内部メトリクスを追加します。

### バグ修正

#### fix(ajax): DTヘッダーのタイムスタンプをサーバー時刻に修正します。

AJAX requests用に生成されたディストリビューティッド（分散）トレーシングヘッダー(`traceparent`/`tracestate`/`newrelic`)は、エージェントのTimeKeeperがRUMベースのクロック補正を完了したときに、ブラウザの生のローカルクロック値ではなく、New Relicのサーバーで補正されたタイムスタンプを使用するようになりました。このタイムスタンプは、受信側のバックエンドAPMエージェントが自身のスパンに対して計算するトランスポート期間の値にのみ影響します—他のブラウザテレメトリーには影響しません。

#### Connectorの競合状態時にtimeKeeperの準備が整っていることを確認

RUM v2の新しいConnectorにはパッチが適用され、まれなケースの競合状態ブランチにおいて、エージェントのタイムスタンプ調整に不可欠なTimeKeeperを準備するようになりました。これは機能フラグで制御されており、現時点ではどのユーザーにも影響を与えないはずです。

## サポートステートメント

New Relic では、最新の機能とパフォーマンス上のメリットを確実に得られるよう、エージェントを定期的にアップグレードすることをお勧めします。古いリリースは[サポート終了](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/)になるとサポートされなくなります。リリース日は、エージェント バージョンの元の公開日を反映します。

以下の機能は現在リミテッドプレビューであり、標準サポートは提供されません：

* [register() API](https://docs-preview.newrelic.com/docs/browser/register) 経由の[ マイクロフロントエンド（MFE）監視](https://docs-preview.newrelic.com/docs/browser/micro-frontend-monitoring/)
* [BrowserPerformance &quot;resource&quot;](https://docs.newrelic.com/docs/browser/new-relic-browser/browser-pro-features/page-resources/)タイプのイベント

新しいブラウザエージェントのリリースは、一定期間にわたって小さな段階で顧客に展開されます。 このため、リリースがアカウントでアクセス可能になる日付は、元の公開日と一致しない可能性があります。詳細については、この[ステータス ダッシュボード](https://newrelic.github.io/newrelic-browser-agent-release/)をご覧ください。

当社の[ブラウザサポートポリシー](https://docs.newrelic.com/docs/browser/new-relic-browser/getting-started/compatibility-requirements-browser-monitoring/#browser-types)に従い、Browserエージェントのv1.323.0は、以下のブラウザおよびバージョン範囲向けにビルドされ、テストされました：Chrome 143～153、Edge 142～152、Safari 18～27、およびFirefox 145～155。モバイルデバイスについては、v1.323.0はAndroid OS 16およびiOS Safari 18～26.2向けにビルドされ、テストされました。
