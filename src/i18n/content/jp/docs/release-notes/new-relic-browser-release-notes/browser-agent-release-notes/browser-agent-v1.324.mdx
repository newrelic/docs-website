## v1.324.1

詳細な技術的変更履歴およびビルドサイズ情報については、**[GitHubでこのリリースをご覧ください →](https://github.com/newrelic/newrelic-browser-agent/releases/tag/v1.324.1)**。

### バグ修正

#### セッションリプレイのハーベストにおけるhasMeta/hasSnapshotフラグを修正しました。

収集されたデータに有効なスナップショットノードが含まれているにもかかわらず、セッションリプレイの収集処理がペイロードのメタデータで `hasMeta` と `hasSnapshot` を `false` として誤って報告する可能性がある問題を修正しました — これは、セッションがエラーのみの記録から完全な記録に切り替わった直後、またはレコーダーが再起動したときに最も顕著でした。このメタデータは、ダウンストリームで特定のリプレイチャンクが自己完結しているかどうか（つまり、単独でリプレイをブートストラップできるかどうか）を判断するために使用されていたため、誤った `false` によって有効なリプレイデータが誤って処理される可能性がありました。

### セキュリティ修正

#### fflateを0.8.3に更新しました。

CVE-2026-45820への対応：不正な形式のZIP64アーカイブの解析時に、unzipSyncが無限ループに陥る可能性がある問題を修正しました。

## サポートステートメント

New Relic では、最新の機能とパフォーマンス上のメリットを確実に得られるよう、エージェントを定期的にアップグレードすることをお勧めします。古いリリースは[サポート終了](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/)になるとサポートされなくなります。リリース日は、エージェント バージョンの元の公開日を反映します。

以下の機能は現在リミテッドプレビューであり、標準サポートは提供されません：

* [register() API](https://docs-preview.newrelic.com/docs/browser/register) 経由の[ マイクロフロントエンド（MFE）監視](https://docs-preview.newrelic.com/docs/browser/micro-frontend-monitoring/)
* [BrowserPerformance &quot;resource&quot;](https://docs.newrelic.com/docs/browser/new-relic-browser/browser-pro-features/page-resources/)タイプのイベント

新しいブラウザエージェントのリリースは、一定期間にわたって小さな段階で顧客に展開されます。 このため、リリースがアカウントでアクセス可能になる日付は、元の公開日と一致しない可能性があります。詳細については、この[ステータス ダッシュボード](https://newrelic.github.io/newrelic-browser-agent-release/)をご覧ください。

[ブラウザサポートポリシー](https://docs.newrelic.com/docs/browser/new-relic-browser/getting-started/compatibility-requirements-browser-monitoring/#browser-types)に従い、Browserエージェントのv1.324.1は、以下のブラウザおよびバージョン範囲向けにビルドされ、テストされています：Chrome 144～154、Edge 144～154、Safari 18～27、およびFirefox 146～156。モバイルデバイスについては、v1.324.1はAndroid OS 17およびiOS Safari 18～26.2向けにビルドされ、テストされています。
