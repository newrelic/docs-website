## v1.324.0

完全な技術的変更履歴とビルドサイズ情報については、**[GitHubでこのリリースをご覧ください →](https://github.com/newrelic/newrelic-browser-agent/releases/tag/v1.324.0)**。

### 特徴

#### マニフェストでのスクリプトのマッチングを改善

マニフェストに登録されたマイクロフロントエンドでは、マニフェストマッチャーに一致するすべてのリソースがMicroFrontEndTimingデータにカウントされるようになりました。以前は、各マニフェストアセットは最初に一致したリソースによって消費されていたため、ハッシュチャンク用の正規表現（RegExp）などの広範なマッチャー（例：/catalog-chunk-\[a-f0-9]+.js/）totalWeight、renderBlocking、およびフェッチ/実行のタイミングウィンドウには、1つのチャンクのみが寄与していました。すでにロードされているか、register()の直後にロードされたかにかかわらず、一致するすべてのチャンクが寄与するようになりました。また、同じスクリプトURLが複数回参照された場合（たとえば、通常はブラウザのキャッシュから再提供される重複した`<script>`タグなど）、エージェントはタイミングを上書きするのではなく、最初のロード時のタイミングを保持するようになりました。そのため、キャッシュされた重複によって、フェッチと実行のタイミングが実際のロードよりも短く見えることはなくなりました。

#### 登録されたマイクロフロントエンドのディストリビューティッド（分散）トレーシングを有効にします。

登録されたマイクロフロントエンド（MFE）のディストリビューティッド（分散）トレーシング（DT）を有効にします：登録されたMFEによるAJAX呼び出しは、トレースのルートをそのMFE自身のエンティティに正しく設定するようになり、MFE自身のバックエンド呼び出しが初めて可視化されます。

### バグ修正

#### 属性サイズの肥大化によるログ収集の暴走を防ぎます。

カスタムアトリビュートを繰り返し上書きするページによって、エージェントがログメッセージごとに個別のログリクエストを送信し、ネットワークを圧迫してブラウザのリソースを枯渇させる可能性があるバグを修正しました。エージェントは、値が上書きされたときにカスタムアトリビュートのサイズを正確に追跡し、各機能が早期にハーベストできる頻度を制限するようになりました。また、その処理中にログが欠落しないように、大規模なバッチを迅速に送信します。

#### fix(jserrors): セッションのリセット時にスタックハッシュメモリをリセットします

詳細は[https://new-relic.atlassian.net/browse/NR-626097](https://new-relic.atlassian.net/browse/NR-626097)をご覧ください。キャッシュのTTLによりバックエンドが解決できなくなる可能性のあるハッシュの代わりに、セッションのリセット後に完全なスタックトレースを1回再送信します。

#### 登録時にiframeエンティティのスクリプトのタイミングを取得します。

登録されたiframeエンティティは、親エージェントが応答した後ではなく、作成時にregister()を呼び出したスクリプトを識別するようになりました。以前は、登録のラウンドトリップ後にルックアップが実行されており、その時点では呼び出し元のスクリプトはすでにコールスタック上に存在していなかったため、エンティティのアセット、タイプ、およびフェッチのタイミングが欠落するか、エージェント自身のスクリプトの属性となる可能性がありました。

## サポートステートメント

New Relic では、最新の機能とパフォーマンス上のメリットを確実に得られるよう、エージェントを定期的にアップグレードすることをお勧めします。古いリリースは[サポート終了](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/)になるとサポートされなくなります。リリース日は、エージェント バージョンの元の公開日を反映します。

以下の機能は現在リミテッドプレビューであり、標準サポートは提供されません：

* [register() API](https://docs-preview.newrelic.com/docs/browser/register) 経由の[ マイクロフロントエンド（MFE）監視](https://docs-preview.newrelic.com/docs/browser/micro-frontend-monitoring/)
* [BrowserPerformance &quot;resource&quot;](https://docs.newrelic.com/docs/browser/new-relic-browser/browser-pro-features/page-resources/)タイプのイベント

新しいブラウザエージェントのリリースは、一定期間にわたって小さな段階で顧客に展開されます。 このため、リリースがアカウントでアクセス可能になる日付は、元の公開日と一致しない可能性があります。詳細については、この[ステータス ダッシュボード](https://newrelic.github.io/newrelic-browser-agent-release/)をご覧ください。

当社の[ブラウザサポートポリシー](https://docs.newrelic.com/docs/browser/new-relic-browser/getting-started/compatibility-requirements-browser-monitoring/#browser-types)に従い、Browserエージェントのv1.324.0は、以下のブラウザおよびバージョン範囲向けに構築およびテストされました：Chrome 144～154、Edge 144～154、Safari 18～27、およびFirefox 146～156。モバイルデバイスについては、v1.324.0はAndroid OS 17およびiOS Safari 18～26.2向けに構築およびテストされました。
