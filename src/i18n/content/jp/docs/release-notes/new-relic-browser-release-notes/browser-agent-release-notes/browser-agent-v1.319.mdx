## v1.319.0

### 特徴

#### MFE vitalsの改善

MFE vitalタイミングの収集に関する利便性の改善を実装します。

* 10秒以内にFCP値が観察されない場合、メモリの節約と外れ値の制御のためにオブザーバーをシャットダウンします。
* デバッグを容易にし、同じMFEターゲットを指す複数のインスタンスから同じDOMツリーが二重に計装されるのを防ぐために、観察されたDOMツリーをMFEインスタンスIDで装飾します。

#### MFE Web Socketsの自動検出

`WebSocket`イベントの自動マイクロフロントエンド（MFE）属性付けのサポートを追加します。以前は、`WebSocket`イベントはコンテナのブラウザアプリケーションによってグローバルに*自動的に*キャプチャされるだけでした。この変更により、エージェントはWebSocketメソッドのコールスタックシグネチャと、`register` APIに登録されたMFEモジュールのコールスタックシグネチャを相互比較します。Browserエージェントへの登録を担当するファイルが、トリガーされているWebSocketメソッドのコールスタックシグネチャに見つかった場合、そのイベントはコンテナではなくMFEの属性になります。

#### 属性キーを難読化しない

BELシリアライザーのaddCustomAttributesメソッドで属性キーを難読化しないようにします。この変更は、AjaxRequest、PageViewTiming、およびBrowserInteraction（ソフトナビゲーションのみ）イベントの属性に影響します。

### バグ修正

#### エージェントのAJAXペイロードのキャプチャを回避

AJAX `capture_payloads`機能がエージェント自身のテレメトリーrequests（NRビーコンエンドポイントへのハーベスト）をキャプチャするのを防ぎます。

#### 無関係なイベントからAjaxペイロードを除外

共有された`params`オブジェクトを介して、無関係なイベント（AJAXタイムスライスメトリクス、セッショントレース）からキャプチャされたAJAXリクエスト+ペイロード情報をドロップします。

## サポートステートメント

New Relic では、最新の機能とパフォーマンス上のメリットを確実に得られるよう、エージェントを定期的にアップグレードすることをお勧めします。古いリリースは[サポート終了](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/)になるとサポートされなくなります。リリース日は、エージェント バージョンの元の公開日を反映します。

新しいブラウザエージェントのリリースは、一定期間にわたって小さな段階で顧客に展開されます。 このため、リリースがアカウントでアクセス可能になる日付は、元の公開日と一致しない可能性があります。詳細については、この[ステータス ダッシュボード](https://newrelic.github.io/newrelic-browser-agent-release/)をご覧ください。

[ブラウザサポートポリシー](https://docs.newrelic.com/docs/browser/new-relic-browser/getting-started/compatibility-requirements-browser-monitoring/#browser-types)に従い、Browserエージェントのv1.319.0は、次のブラウザとバージョン範囲向けにビルドおよびテストされています：Chrome 139～149、Edge 139～149、Safari 18～27、およびFirefox 142～152。モバイルデバイスの場合、v1.319.0はAndroid OS 16およびiOS Safari 18～26.2向けにビルドおよびテストされています。
