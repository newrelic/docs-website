### 重大な変更

* **THEOplayerトラッカーAPIの修正：** `NRTrackerTHEOPlayer` は、`THEOplayerView` の代わりに THEOplayer `Player` インスタンスを受け入れるようになりました。ビュー自体ではなく`theoplayer`インスタンスを渡すようにインテグレーションを更新してください。トラッカーはActivityのライフサイクルをプロキシしなくなりました — `onResume()`、`onPause()`、および`onDestroy()`を直接`THEOplayerView`に転送してください。
