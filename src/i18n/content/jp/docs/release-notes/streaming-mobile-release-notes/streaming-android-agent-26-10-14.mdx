### バグ修正

* **ExoPlayer/HLS：** `contentBitrate`はHLSストリームに対して常に`0`を報告していました。media3は内部的に、オーディオ+ビデオが混在するHLSセグメント・ロードを、`TRACK_TYPE_VIDEO`ではなく`TRACK_TYPE_DEFAULT`として分類します（影響を受けなかったDASHおよびプログレッシブ・ストリームとは異なります）。トラッカーのビットレート・キャプチャ・ロジックは`TRACK_TYPE_VIDEO`に対してのみ実行されたため、HLSロードによってフィールドに値が設定されることはありませんでした。`contentBitrate`は、HLSコンテンツの実際のストリーム・ビットレートを正しく反映するようになりました。
