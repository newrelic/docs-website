### ⚠ 重大な変更

* `NRVAVideo.addPlayer()`：プレーヤーのタイプを識別できず、明示的な`playerType`が設定されていない場合、暗黙的にAVPlayerトラッカーをデフォルトにするのではなく、トラッカーを作成せずに戻るようになりました。カスタムまたはラップされたプレーヤーオブジェクトを渡す場合は、`NRVAVideoPlayerConfiguration.playerType`を明示的に設定してください。

### 特徴

* `NRTHEOplayerTracker`：THEOplayer（Dolby OptiView Player）用の新しいトラッカーを追加しました — コンテンツライフサイクルイベント、QoE/レンディショントラッキング、およびエラーマッピング。iOSのみ、iOS 13.0+。CocoaPods、XCFrameworks、およびSwiftパッケージマネージャ経由で利用可能です。
