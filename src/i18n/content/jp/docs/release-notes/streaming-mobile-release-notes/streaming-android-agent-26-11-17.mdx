### 特徴

* Google IMA DAI（動的広告挿入）のサポート `NRTrackerIMA`
* iOSの`enableLogging` APIと同様に、INFOレベルでのログ記録を有効にし、バッファが容量上限に近づいたこと、およびドロップされたイベントをログに記録してください。

### バグ修正

* ブレークの終了によって途中で打ち切られた広告が閉じられ、不要な四分位およびクリックイベントが無視され、広告ごとのタイマーが次のブレークに持ち越されなくなり、広告の長さがミリ秒単位で報告されるように、IMA広告トラッキングを修正しました。
