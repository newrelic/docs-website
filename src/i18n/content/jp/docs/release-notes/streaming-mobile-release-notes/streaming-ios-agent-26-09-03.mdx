### 新機能

* Swiftパッケージマネージャのサポートを追加しました。
* `NRMediaTailorTracker`：`NRIMATracker`と同等の機能を提供する、AVPlayer（iOS 12+およびtvOS 12+）向けの新しいAWS MediaTailorサーバーサイド広告挿入（SSAI）トラッカーを追加しました。

### バグ修正

* `ios-publish`：パイプラインの部分的な障害に耐えられるように、リトライロジックを変更しました。
