### メモ

* `NRTHEOplayerTracker` 現在、iOS 15.0以降（iOS 13.0からアップグレード）および`THEOplayerSDK-core`バージョン11.x（10.xからアップグレード）が必要です。iOS 13または14のサポートを必要とするアプリケーションは、`NRTHEOplayerTracker`バージョン5.0.0を使用し続ける必要があります。その他のトラッカー・パッケージは影響を受けません。

### 改良点

* `THEOplayerSDK-core` バージョン 11.x をサポートするように `NRTHEOplayerTracker` を更新しました。

### バグ修正

* `NRAVPlayerTracker`において、再バッファリング中に再生を一時停止するとバッファリング・イベントが途中で終了する問題を修正しました。バッファが空の間、トラッカーは`CONTENT_BUFFER_END`を発行しなくなり、再生が一時停止されている間は再生時間が累積されなくなりました。
* `THEOplayerSDK`バージョン11.xを使用してビデオ・ソースを割り当てる際に発生していた、`NRTHEOplayerTracker`のクラッシュを修正しました。
* `NRTrackerIMA`クラスがXCFrameworkバイナリから欠落していた`NRIMATracker`の問題を修正しました。これにより、Swiftパッケージマネージャおよび手動でのインストレーション方法に対する`NRTrackerIMA`のサポートが復元されます。
