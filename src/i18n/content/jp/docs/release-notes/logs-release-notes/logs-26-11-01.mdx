### セキュリティアップデート

* [AWS Unified Lambda](https://github.com/newrelic/aws-unified-lambda)はバージョン1.1.5に更新され、CVE修正のためにGoが1.27.3にアップグレードされました。
* [CVE-2026-111064](https://nvd.nist.gov/vuln/detail/CVE-2026-111064) および[ CVE-2026-111066](https://nvd.nist.gov/vuln/detail/CVE-2026-111066) を修正するため、[ aws-log-ingestion](https://github.com/newrelic/aws-log-ingestion) Lambda はバージョン2.11.5に更新されました。このバージョンでは、aiohttpライブラリが3.14.5に、yarlが1.25.1に更新され、関連する依存関係も更新されています。
* 脆弱性のあるcertifiの依存関係を修正するため、[aws\_s3\_log\_ingestion\_lambda](https://github.com/newrelic/aws_s3_log_ingestion_lambda)はバージョン1.4.4に更新されました。このバージョンでは、certifiライブラリが2026.10.23に更新され、関連する依存関係も更新されています。
