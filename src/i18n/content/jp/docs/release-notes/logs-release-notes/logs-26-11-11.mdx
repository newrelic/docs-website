### 互換性の変更

[Google Cloud Pub/SubからNew RelicへのDataflowテンプレート](https://github.com/newrelic-forks/DataflowTemplates)はApache Beam 2.77.0にアップグレードされ、引き続きGCPがサポートするSDKで利用できます。テンプレートのビルドと実行には、Java 11以降が必要です。Java 8を使用してテンプレートをビルドまたは実行している場合は、更新されたバージョンを使用する前にJDKをアップグレードしてください。
