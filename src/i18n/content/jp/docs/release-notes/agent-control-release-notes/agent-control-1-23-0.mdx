### 新機能

* リモート設定キーで `variable.agentConfig` 構文による変数のオーバーライドのサポートを追加しました。
* リモート設定キーでの`variable.agentConfig.<variable>:<map-key>`構文による`string_map`変数オーバーライドの単一エントリのサポートを追加しました。
* On-host infrastructureエージェントタイプ（linux）：新しい`config_docker`変数を通じて`nri-docker`インテグレーション設定を公開します。
* エージェント・タイプ：変数名の形式を、文字で始まり最大長が64文字の`[A-Za-z0-9_-]`に強制します。
* On-Host：デフォルトでセルフアップデート機能を有効にします。セルフアップデートは、Fleet Controlから指示された場合にのみ実行されます。

### バグ修正

* K8sスーパーバイザー：新しいリモート設定が到着してサブエージェントスーパーバイザーを再起動した際に、停止したHelmReleases（例：インストール/アップグレードの再試行を使い果たした後など）に対してFluxリコンシリエーションを強制します。
* On-host：再起動ポリシーを超過した場合、一般的な&quot;Restart policy exceeded&quot;メッセージの代わりに、unhealthyステータスの`lastErrorMessage`に実際の最後の失敗（リリースエラーまたはゼロ以外の終了）を報告します。
* On-host：fluent-bitのホームディレクトリ（`fb.db`）を、置き換えられたパッケージディレクトリに保存するのではなく、infra-agentパッケージのアップデートをまたいで保持します。
