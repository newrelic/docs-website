### 新機能

* YAMLの解析では、空のマップに関する制限が厳しくなりました：保存されたリモート構成内の単独の`config:`など、マップが想定される場所でのnull値（空の値、`~`または`null`）は、空のマップとして扱われるのではなく、拒否されるようになりました。空のマップには`{}`を使用してください。空のドキュメントは引き続き受け入れられます。

### バグ修正

* オンホスト：共有ファイルシステムのクリーンアップではシンボリックリンクをたどらなくなったため、共有ファイルシステム外のコンテンツが削除されることはなくなり、リンク切れのシンボリックリンクは削除されます。
* オンホスト：ログ出力が構成される前に発生した起動エラー（無効な`local_config.yaml`など）は、デフォルトのAgent Controlログファイルに書き込まれるようになったため、Windowsサービスとして実行している場合でも確認できるようになりました。
* オンホスト：OCIレジストリのrequestsは、プロキシURLのスキームに関係なく設定されたプロキシを経由するようになったため、`http://`プロキシがバイパスされることはなくなりました。
* オンホスト：シグナルによって強制終了されたサブエージェント（例：OOM killerによる）は、「process exited with code: 0」の代わりに、そのシグナルによって終了したとして報告されるようになりました。
