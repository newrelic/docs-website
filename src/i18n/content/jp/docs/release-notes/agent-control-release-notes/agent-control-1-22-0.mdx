### 新機能

* オンホスト：Linux上のsystemd `MemoryMax`を介して、Agent Controlプロセスツリー（AC+すべての子エージェント）に2,400 MiBのハードメモリ制限を適用します。

### バグ修正

* Linux：RPMパッケージのアップデート後にsystemdサービスが無効化されるのを防ぐ

### セキュリティアップデート

* Rustクレートのfuturesを0.3.34に更新しました。
* alpine/helmをv4.2.4に更新しました。
* rustクレートserde-saphyrを1.1.0に更新しました

変更の詳細については、[リリースノート](https://github.com/newrelic/newrelic-agent-control/releases/tag/1.22.0)を参照してください。
