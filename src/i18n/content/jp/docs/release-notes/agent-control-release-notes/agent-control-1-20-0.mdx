### 新機能

* Kubernetes：`uninstall-agent-control`では`--release-name`がオプションになりました；これを省略すると、リリース自体のHelmRelease/HelmRepository CRの削除がスキップされます。
* オンホスト：nri-apacheおよびnri-nginxのagentTypesを追加しました。
* オンホスト：nri-postgresql agentTypeを追加しました。
* オンホスト：nri-MySQL agentTypeを追加しました。
* オンホスト：nri-memcachedエージェントタイプを追加しました。
* ローテーションされたログファイルの保持期間が30日になりました。
* エージェントタイプ定義ファイルのスキーマレベルの検証のために、`newrelic-agent-control-cli`と`newrelic-agent-control-k8s-cli`に`agent-type validate --file <path>`サブコマンドを追加しました。
* `agent-type validate`をセマンティック検証で拡張しました：`deployment`内のすべての`${nr-var:X}`参照には、対応する`variables`宣言が必要です。
* リモートのエージェントタイプレジストリのキャッシュを有効化しました。
