### 新機能

* Linux：サポート/公開されているプラットフォームとしてDebian 13（trixie）を追加しました。
* Linux：v1.2.0より前のレガシーなオンホストフォルダーの移行を削除しました `newrelic-agent-control-cli`
* サーバー側の&quot;governance&quot;フローを優先するため、バリアントのサポートは削除されました
* サーバー側の&quot;governance&quot;フローを優先するため、正規表現ベースのリモート構成の検証は削除されました。

### バグ修正

* オンホスト：正常なシャットダウンのたびに出力される不要な`error`レベルのログ`"cannot forward agent control event"`を修正しました；ステータスサーバーブリッジは明示的な停止シグナルによってのみ終了するようになり、クローズされたチャネルは終了を引き起こすのではなく静かに無効化され、パブリッシャーのライフタイムは停止シグナルが発行されるまでチャネルを開いたままにするように延長されました。
* Linux: `uninstall.sh`は`apt-get remove`の代わりに`apt-get purge`を使用するようになり、再インストールが失敗し、パッケージマネージャによって`systemd-env.conf`のconffileが再作成されなかったためにサービスを開始できなくなる原因となっていたdpkgの状態の不整合を防ぎます。
* Windows：インストールディレクトリまたはランタイムデータディレクトリを削除できない場合、アンインストールスクリプトが暗黙のうちに成功するのではなく警告を出すようになりました（例：Windowsエクスプローラーで開いている場合など）。また、ロックが解除された後に再実行できるようにスクリプト自体を保持します。
* On-host：`filesystem:`/`shared_filesystem:`配下のファイルシステムエントリは、アルファベット順にディスクに書き込まれ、各書き込み後にfsyncされるようになり、書き込み順序が確定的になりました。
* オンホスト：実行中のバイナリを置き換える際に、セルフアップデートでダウンロードしたパッケージのバイナリが削除されなくなり、セルフアップデート後のロールバックと同一バージョンの再インストールが修正されました。
* On-host：Agent Controlまたはサブエージェントのログディレクトリが初めて作成されたときに、標準エラー出力に出力される不要な`Error reading the log directory/files: No such file or directory`メッセージを修正しました。
* オンホスト：実行可能ファイルの出力とライフサイクルログは、エージェントプロセスとスーパーバイザーのライフサイクル全体にわたって誤って`start_agent`スパンでタグ付けされることはなくなり、代わりに明示的なフィールドを持つようになりました。
* 終了時に、プロセス終了のログ行（成功またはエラー）がログファイルから破棄されることはなくなりました。以前はファイルロガーがすでにシャットダウンした後に発行されていたため、`journalctl`/stderrにしか到達していませんでした。
