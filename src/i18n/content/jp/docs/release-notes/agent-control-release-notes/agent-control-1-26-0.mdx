### 新機能

* マネージドIDとサービスプリンシパル認証の両方をサポートする、Azure Key Vault値プロバイダーを追加しました。
* すべてのシステムで何も設定されていない場合、セルフ計装は注入されたライセンスキーをヘッダーとして取得するようになりました。

### バグ修正

* Windows：重複するホストレポートを回避するために、`install.ps1`はスタンドアロンのNew Relic Infrastructureエージェントのインストレーションを検出して削除するようになりました；引き続き必要な場合は、その後Agent Controlが管理するサブエージェントとして再構成する必要があります。
* オンホスト：OHI設定ファイルを共有ファイルシステムに書き込む際の、冗長なファイルシステム同期と完全なディレクトリ再作成によって引き起こされるインテグレーションの再起動を修正しました。
* グレースフルシャットダウンのアイドル待機期間を短縮するために、ヘルスチェックスレッドの初期遅延をキャンセル可能にしました。
* マイナーなログの問題を修正しました：冗長なフィールド、重複したログ、誤ったログレベル、および一貫性のないメッセージの大文字と小文字。
* Agent Controlは起動時に常にリモート設定ステータスを再報告するようになり、サーバーが完全な状態の同期をrequestsした際の再起動後の再送信漏れを修正しました。
* Windows：システムのシャットダウン/再起動は、ctrlシグナル処理の代わりに、手動でのサービス停止と同じサービスのグレースフルストップパスを経由するようになりました。
