### 新機能

* アクセス・キー認証情報とEC2インスタンス・プロファイルをサポートする、AWS Secrets Manager値プロバイダー（`nr-awssm`）を追加しました。
* LinuxとWindows：Agent Controlおよびそのサブエージェントは、`os.version`と`host.arch`をOpAMP属性として報告するようになりました。Linuxは`os.name`も報告します（ディストリビューションID、例：&quot;debian&quot;）。

### バグ修正

* オンホスト：ヘルスチェックが定義されていないサブエージェントは、クローズされたチャネルにヘルスをパブリッシュする実行可能ファイルからのエラーをログに記録しなくなりました。
* HTTPクライアントは、Agent Controlのプロキシ設定以外のプロキシ設定を読み込まなくなり、`ignore_system_proxy: true`が完全に適用されるようになりました。
* オンホスト：UTF-8以外のバイトを含むサブエージェントの出力によって、ログ転送が停止したり、サブエージェントが終了したりすることはなくなりました。そのような行は、無効なバイトが置換されてログに記録されるようになりました。
* Windows：新しいバイナリのステージング中にセルフアップデートが失敗しても、Agent Controlの実行可能ファイルが失われることはなくなりました。これにより、次回の再起動後にサービスが開始できなくなる問題が解消されました。
