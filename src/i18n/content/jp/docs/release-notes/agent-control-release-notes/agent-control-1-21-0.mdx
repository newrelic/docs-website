### 新機能

* Windowsファイルシステム：未使用のコードを削除し、Windowsインタラクションに高レベルのAPIを使用するようにしました。
* 起動時に、設定されたエージェントタイプOCIリポジトリに到達可能な場合、`com.newrelic.remoteAgentTypeRepoReachable` OpAMPカスタム機能を報告します。
* オンホスト：nri-flex agentTypeを追加しました。

### バグ修正

* Windows：Agent Controlの管理対象ディレクトリ下のファイルが、使用できない権限のまま残される問題を修正しました。管理対象ディレクトリは継承可能なアドミニストレーターACEを使用するようになり、Agent Controlは起動時にACEの修復を試みます。
