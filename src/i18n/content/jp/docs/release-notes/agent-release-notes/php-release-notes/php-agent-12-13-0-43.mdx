### 新機能

* リンクの有効期間中、mysqliリンクのメタデータを保持します。([#1325](https://github.com/newrelic/newrelic-php-agent/pull/1325))
* `mysqli_execute_query`と`mysqli::execute_query`を計装します。([#1354](https://github.com/newrelic/newrelic-php-agent/pull/1354))
* Ubuntu 26.04およびAlpine 3.24が検証され、サポートされています。

### セキュリティアップデート

* デーモンのビルドに使用するGoのバージョンを1.27.4にアップグレードしました。([#1382](https://github.com/newrelic/newrelic-php-agent/pull/1382))
* デーモンの `golang.org/x/net` を0.62.0にアップデートしました。([#1305](https://github.com/newrelic/newrelic-php-agent/pull/1305)、[#1353](https://github.com/newrelic/newrelic-php-agent/pull/1353))

### サポートステートメント

* 以前にお知らせしたとおり、以下のライブラリ、フレームワーク、およびOSバージョンに対するPHPエージェントのサポートは終了しました。New Relicは、ベンダーがサポートする最新バージョンにアップグレードすることをお勧めします：

  * Drupal 7：2026年10月15日以降、すべてのPHPエージェントバージョンでサポートが終了しました。
  * Drupal 9：2026年10月15日以降、すべてのPHPエージェントのバージョンでサポートが終了しました。
  * CakePHP 4.x：2026年11月15日以降、すべてのPHPエージェントバージョンでサポートが終了しました。
  * Amazon Linux 2（AL2）：2026年11月15日以降、すべてのPHPエージェントバージョンでサポートが終了しました。
  * Red Hat Enterprise Linux 8（RHEL 8）：2026年11月15日以降、すべてのPHPエージェントのバージョンでサポートが終了しています。

* 以下のライブラリ、フレームワーク、およびOSバージョンに対するPHPエージェントのサポートは終了します。New Relicでは、ベンダーがサポートする最新バージョンへのアップグレードをお勧めします：

  * PHP 7.2：2026年12月15日にサポートが終了します。
  * PHP 7.3: サポートは2026年12月15日に終了します。

* New Relic では、エージェントを定期的に、少なくとも 3 か月ごとにアップグレードすることを推奨しています。サポートされているエージェントのバージョンと EOL タイムラインの詳細については、[New Relic PHPエージェント EOL ポリシー](https://docs.newrelic.com/docs/apm/agents/php-agent/getting-started/php-agent-eol-policy/)を確認してください。

* サポートされている PHP バージョンとプラットフォームの最新情報については[、PHP エージェントの互換性と要件の](https://docs.newrelic.com/docs/apm/agents/php-agent/getting-started/php-agent-compatibility-requirements/)ページを参照してください。

<Callout variant="important">
**サポートされていない PHP バージョンまたはプラットフォームを使用したインストールの場合は、PHP エージェント パッケージの自動更新メカニズムを無効にすることを強くお勧めします。** これを行うには、PHPエージェント パッケージをパッケージ アップグレードの除外リストに追加します。 または、PHPエージェント パッケージを、古いサポートされていない機能をサポートするエージェント バージョンにバージョン固定することもできます。 アップグレードを防止しないと、新しいエージェント リリースがインストールされ、必要なサポートされていない機能のサポートが削除される可能性があります。これにより、APM データの収集が中断されます。

影響を受ける PHPエージェント パッケージは次のとおりです。

* newrelic-php5
* newrelic-php5-common
* newrelic-daemon
</Callout>
