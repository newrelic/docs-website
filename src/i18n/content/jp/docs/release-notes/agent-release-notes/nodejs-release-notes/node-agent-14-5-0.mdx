## メモ

#### 特徴

* `browser_monitoring.version`設定オプションを追加しました ([#4269](https://github.com/newrelic/node-newrelic/pull/4269)) ([b62ca00](https://github.com/newrelic/node-newrelic/commit/b62ca002441bcae50b4fd235eb046cdfa6a55bbe))。

  * これを設定すると、`newrelic.getBrowserTimingHeader`を使用する際のBrowserエージェントのバージョンが、選択したバージョンに固定されます。
  * サポートされなくなったバージョンや無効なバージョンを指定した場合、`newrelic.getBrowserTimingHeader`を呼び出す際にどのBrowserエージェントにも解決されません。

#### バグ修正

* トランザクションがアクティブでない場合に外部セグメントの作成を試みないように、`undici`計装を更新しました ([#4278](https://github.com/newrelic/node-newrelic/pull/4278)) ([d634246](https://github.com/newrelic/node-newrelic/commit/d634246308c1a4d359eae59a035687860864969e))。
* 外部セグメントIDを含む`traceparent`ヘッダーを適切に挿入するように、`http2`計装を更新しました ([#4279](https://github.com/newrelic/node-newrelic/pull/4279)) ([ccd7800](https://github.com/newrelic/node-newrelic/commit/ccd7800b6dd64ef9cf5cefaaef86509206d56ab9))。

### サポートステートメント:

最新のエージェント バージョンが利用可能になったらすぐに更新することをお勧めします。最新バージョンにアップグレードできない場合は、エージェントを 90 日以内のバージョンに更新してください。[エージェントを最新の状態に保つ方法](/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent/)の詳細については、こちらをご覧ください。

エージェントのリリースとサポート日に関する情報については、New Relic Node.jsエージェントの[EOLポリシー](/docs/apm/agents/nodejs-agent/getting-started/nodejs-agent-eol-policy/)を参照してください。
