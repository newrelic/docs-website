### サポートステートメント:

最新のエージェントバージョンが利用可能になり次第、アップデートすることをお勧めします。最新バージョンにアップグレードできない場合は、エージェントを90日以内のバージョンにアップデートしてください。[エージェントを最新状態で維持する](/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent)詳細をご覧ください。

エージェントのリリースとサポート日に関する情報については、New Relicの[Node.jsエージェントEOLポリシー](/docs/apm/agents/nodejs-agent/getting-started/nodejs-agent-eol-policy)をご覧ください。
