## メモ

#### 特徴

* `ai_monitoring.basic_telemetry.enabled`を追加し、デフォルトで基本的なAIモニタリングを有効にしました（[#4330](https://github.com/newrelic/node-newrelic/pull/4330)）（[c126335](https://github.com/newrelic/node-newrelic/commit/c1263354150cd30349d316acc162f5388bc3449a)）。

  * LLM計装はデフォルトで有効になり、別の設定が行われない限り、`Llm*`のカスタムイベント、スパン、およびメトリクス（メッセージコンテンツなし）を送信します。オプトアウトするには、`newrelic.js`で`ai_monitoring.basic_telemetry.enabled`を`false`に設定するか、`NEW_RELIC_AI_MONITORING_BASIC_TELEMETRY_ENABLED`環境変数を`false`に設定してください。
  * `ai_monitoring.enabled` および`NEW_RELIC_AI_MONITORING_ENABLED`環境変数は非推奨であり、将来のメジャーバージョンで削除される予定ですが、どちらかをfalseに設定することでもオプトアウトできます。

* コアトレースを無効にしました（[#4394](https://github.com/newrelic/node-newrelic/pull/4394)）（[2d0ee8e](https://github.com/newrelic/node-newrelic/commit/2d0ee8ea2c7355b3764e332b555bcc04f2e691f0)）。

### サポートステートメント:

エージェントのリリースとサポート日については、New Relic Node.js エージェントの EOL ポリシーを参照してください。( [https://docs.newrelic.com/docs/apm/agents/nodejs-agent/getting-started/nodejs-agent-eol-policy/](https://docs.newrelic.com/docs/apm/agents/nodejs-agent/getting-started/nodejs-agent-eol-policy/) )
