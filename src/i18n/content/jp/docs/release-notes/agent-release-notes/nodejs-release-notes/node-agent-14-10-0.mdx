### 特徴

* `@opentelemetry/api@1.10.0`サポートを追加しました ([#4392](https://github.com/newrelic/node-newrelic/pull/4392)) ([504490d](https://github.com/newrelic/node-newrelic/commit/504490dd9540e6d5312441d9feec29b47bfe959a))

  * `@opentelemetry/api-logs`を直接使用している顧客は、これを削除し、`@opentelemetry/api` 1.10.0以降を使用するように更新する必要があります。詳細については、[OpenTelemetry APIの変更履歴](https://github.com/open-telemetry/opentelemetry-js/blob/main/api/CHANGELOG.md#1100)を参照してください。
  * ロギングライブラリ向けのサードパーティ計装を登録する顧客は、以下に更新する必要があります：`@opentelemetry/instrumentation-pino`を0.70.0+に、`@opentelemetry/instrumentation-bunyan`を0.69.0+に、`@opentelemetry/instrumentation-console`を0.6.0+に、または`@opentelemetry/instrumentation-winston`を0.69.0+に

### バグ修正

* Apollo Serverの引数配列メトリクスを集約しました（[#4350](https://github.com/newrelic/node-newrelic/pull/4350)）（[baf35fd](https://github.com/newrelic/node-newrelic/commit/baf35fd6b906dd4d733f0a2f13d600cb42fec246)）。
  * この機能を利用するには、`config.apollo_server.field_metrics`と`config.apollo_server.collapse_field_metrics`の両方を`true`に設定する必要があります。貢献してくださった @cpruijsen に感謝します！
* net.jsが終了したトランザクションを長寿命のソケットに固定する処理を停止しました（[#4411](https://github.com/newrelic/node-newrelic/pull/4411)）（[471e7df](https://github.com/newrelic/node-newrelic/commit/471e7df98fb6467678ca7bb98a3a056821b60f42)）。

### サポートステートメント

最新のエージェント バージョンが利用可能になったらすぐに更新することをお勧めします。最新バージョンにアップグレードできない場合は、エージェントを 90 日以内のバージョンに更新してください。[エージェントを最新の状態に保つ方法](/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent/)の詳細については、こちらをご覧ください。

エージェントのリリースとサポート日に関する情報については、New Relic Node.jsエージェントの[EOLポリシー](/docs/apm/agents/nodejs-agent/getting-started/nodejs-agent-eol-policy/)を参照してください。
