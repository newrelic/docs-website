### 新機能

* SQLに対してNewRelicQueryNameを指定できるようにし、[この提案](https://support.newrelic.com/s/hubtopic/aAX8W0000008aKX/provide-a-pattern-to-explicitly-name-sql-queries-displayed-in-databases-dashboa)を実装します。実装に貢献していただいたコミュニティコントリビューターの@kevinpohlmeierに感謝いたします。([#799](https://github.com/newrelic/newrelic-dotnet-agent/pull/799))

### 修正

* .NET 6アプリケーションのGCメトリクスが適切にキャプチャされていなかった問題を解決しました（[#874](https://github.com/newrelic/newrelic-dotnet-agent/pull/874)）。

## サポートステートメント

New Relicでは、エージェントを定期的に、少なくとも3か月ごとにアップグレードすることを推奨します。このリリースの時点で、サポートされている最も古いバージョンは[.NETエージェント 8.24.244.0](/docs/release-notes/agent-release-notes/net-release-notes/net-agent-8242440)です。

## アップグレード

* [.NET エージェントを更新する](/docs/agents/net-agent/installation-configuration/update-net-agent)には、標準の手順に従ってください。
* 特に古いエージェントからアップグレードする場合は、主な変更点のリストと[レガシー.NETエージェントをアップグレードする](/docs/agents/net-agent/troubleshooting/upgrade-legacy-net-agents)手順を確認してください。
