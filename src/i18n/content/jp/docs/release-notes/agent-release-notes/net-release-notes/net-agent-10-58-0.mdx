### 知らせ

* LLMの計装はデフォルトで有効になり、特に設定されていない限り、`Llm*`のカスタムイベント、スパン、およびメトリクス（メッセージコンテンツなし）を送信します。オプトアウトするには、`<aiMonitoring><basicTelemetry enabled="false" /></aiMonitoring>`を`newrelic.config`に追加するか、`NEW_RELIC_AI_MONITORING_BASIC_TELEMETRY_ENABLED`環境変数を`false`に設定します。`<aiMonitoring>`の`enabled`属性および`NEW_RELIC_AI_MONITORING_ENABLED`環境変数は非推奨であり、将来のメジャーリリースで削除される予定ですが、どちらかを`false`に設定することでもオプトアウトできます。([0b65f33](https://github.com/newrelic/newrelic-dotnet-agent/commit/0b65f338448a6a6213a1db59c4a55844cb4c63af))
* このリリースから、download.newrelic.comに公開されるすべてのファイルにはビルドの出所証明が含まれており、`gh attestation verify <file> --repo newrelic/newrelic-dotnet-agent`を使用して検証できます。download.newrelic.com上のすべてのバージョンのファイルのSHA-256ハッシュは、以前のバージョンを含め、エージェントリポジトリの`release-data/download-site-hashes.json`で公開されています。([99335b1](https://github.com/newrelic/newrelic-dotnet-agent/commit/99335b1f2500ead5e0662b0f6646e86bc68caaba))
* このリリースから、すべてのパッケージ（MSI、ZIP、NuGet、deb、rpm、tar.gz）内のNew RelicバイナリはAuthenticodeで署名され、MSIの署名を含め、署名にはタイムスタンプが付与されます。タイムスタンプにより、署名証明書の有効期限が切れた後も署名は有効に保たれます。([99335b1](https://github.com/newrelic/newrelic-dotnet-agent/commit/99335b1f2500ead5e0662b0f6646e86bc68caaba))

### エージェントの更新

* [.NET エージェントを更新する](/docs/agents/net-agent/installation-configuration/update-net-agent)には、標準の手順に従ってください。
* 特に古いエージェントを使用している場合は、主要な変更点のリストと[レガシー .NET エージェントの更新](/docs/apm/agents/net-agent/installation/update-net-agent/#updating_older_net)手順を確認してください。

最新のエージェント バージョンが利用可能になったらすぐに更新することをお勧めします。最新バージョンにアップグレードできない場合は、エージェントを 90 日以内のバージョンに更新してください。[エージェントを最新の状態に保つ方法](/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent)の詳細については、こちらをご覧ください。エージェントのリリースとサポート日については、New Relic .NET エージェントの[EOL ポリシー ドキュメントを](/docs/apm/agents/net-agent/getting-started/net-agent-eol-policy)参照してください。
