## 3.44.2

### 追加した

* `aws.lambda.eventSource.eventType` `nrlambda`インテグレーションの属性サポート

### 修理済み

* `TransactionTrace` 修正

  * `backtrace` UIで正しく表示される -&gt; NR1でバックトレースが正しく表示されない問題を修正しました
  * `timestamp` nullではなくなりました -&gt; タイムスタンプが常にnullとして表示される問題を修正しました
  * `exclusive_duration_millis` nullではなくなりました -&gt; `exclusive_duration_millis`が常にnullとして表示される問題を修正しました

### セキュリティ

* Dependabotセキュリティアップデート

  * `nrgrpc` google.golang.org/grpcを1.82.1に更新しました
  * `nrconnect` golang.org/x/netを0.55.0に更新しました

### サポートステートメント

最新バージョンのGo言語を使用しています。少なくとも、Goチームが引き続きサポートしているバージョンのGoを使用してください。Goエージェントおよびサードパーティコンポーネントのサポートされているバージョンの詳細については、[GoエージェントのEOLポリシー](/docs/apm/agents/go-agent/get-started/go-agent-eol-policy)を参照してください。
