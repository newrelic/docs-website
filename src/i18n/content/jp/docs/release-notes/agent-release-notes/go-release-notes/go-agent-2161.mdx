## 2.16.1

### New RelicのGoエージェントv3.0は、現在レビューおよびベータテストにご利用いただけます。このプレリリースの使用は自己責任で行ってください。New Relicは、ベータ版リリースに関する明示または黙示のすべての保証を否認します。

### 以下で説明するように、新しいv3フォルダーを使用する手順を手動で実行しない場合、エージェントに変更は反映されません。

この2.16.1リリースには、Goエージェントv3.0のプレリリースを含む新しいv3.0フォルダーが含まれています；Goエージェントv3.0には破壊的変更が含まれています。フィードバックを募集しておりますので、公式リリースの前に内容をご確認いただき、変更をテストしていただければ幸いです。

**これは公式の3.0リリースではなく、提案された変更に関するフィードバックを収集するための手段にすぎません。**Githubで3.0としてタグ付けされておらず、Go modファイルで更新するための3.0リリースはまだ利用できません。これらの変更をテストするには、Goソースディレクトリの`[go-src-dir]/src/github.com/newrelic/go-agent`の下にこのリポジトリをクローンする必要があります。ソースをチェックアウトしたら、[v3/MIGRATION.md](https://github.com/newrelic/go-agent/blob/master/v3/MIGRATION.md)の2番目のセクションの手順に従う必要があります。

変更およびインストレーション手順のリストはv3フォルダーに含まれており、[こちら](https://github.com/newrelic/go-agent/blob/master/v3/MIGRATION.md)で確認できます。

Goエージェントv3.0のこのプレリリース（ベータ）バージョンについては、以下にご注意ください：

* v3フォルダの変更は、メジャー3.0リリースとして\{&apos;-&apos;}2週間後にリリースする予定のものを表しています。ただし、変更に関するフィードバックを募集しているため、公式リリースの前にいくつかの破壊的変更が行われる可能性があります。
* これは公式の3.0リリースではありません；Githubで3.0としてタグ付けされておらず、Go modファイルで更新できる3.0リリースはまだ利用できません。
* これらの変更をテストして、問題や質問が発生した場合、または伝えたいフィードバックがある場合は、[こちら](https://github.com/newrelic/go-agent/issues/new)でissueを開き、必ずラベル`3.0`を含めてください。
  * 通常の（3.0以外の）問題/質問については、[サポートサイト](http://support.newrelic.com/)または[コミュニティフォーラム](https://support.newrelic.com/s/)経由で報告していただくようお願いいたします。3.0プレリリースに関する質問のみ、GitHub経由で直接報告してください。

### 新機能

* V3はGoモジュールのサポートを追加します。go.modファイルはv3フォルダーに存在しますが、3.0リリースに正式にタグを付けるまでは使用できません。さまざまなモジュールで使用する予定のバージョンタグの例は次のとおりです：

  * `v3.0.0`
  * `v3/integrations/nrecho-v3/v1.0.0`
  * `v3/integrations/nrecho-v4/v1.0.0`

### 変更点

* 変更内容は、以前に[こちらのIssue](https://github.com/newrelic/go-agent/issues/106)でフィードバックをお願いしたものです。
* 含まれる変更の完全なリストとアップグレードのチェックリストは、[v3/MIGRATION.md](https://github.com/newrelic/go-agent/blob/master/v3/MIGRATION.md)でご覧いただけます。
