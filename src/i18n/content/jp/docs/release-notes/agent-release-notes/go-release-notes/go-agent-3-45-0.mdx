## 3.45.0

### 追加した

* 新しいインテグレーションnrecho-v5を追加しました。以前のメジャーバージョン（v3、v4）は、引き続きそれぞれのフォルダーで利用可能であることにご注意ください。
* 生成AIパッケージがインストゥルメントされた新しいインテグレーションnrgeminiを追加しました。
* 継続的プロファイリングのサポートを追加しました   \* 注意：継続的プロファイリングは新しい機能であり、まだ一般にはご利用いただけません。エージェント側のコンポーネントコードは現在エージェントに存在しますが、一般提供リリースの前に実際に使用するには、プレビューに早期参加するためにNew Relicの営業担当者にお問い合わせいただく必要があります。

### 修理済み

* LLMメッセージが誤って切り捨てられるバグを修正しました。

### セキュリティ

* Dependabotセキュリティアップデート

  * v3/integrations/nrgrpc および /v3 で grpc を 1.82.1 から 1.83.1 に更新しました
  * v3/integrations/nramqp で amqp091-go を 1.9.0 から 1.13.0 に更新しました
  * v3/integrations/nrecho-v4 で echo/v4 を 4.9.0 から 4.15.3 に更新しました

### サポートステートメント

私たちは Go 言語の最新バージョンを使用します。少なくとも、Go チーム自身がサポートしているバージョンよりも古いバージョンの Go は使用しないでください。[Go エージェントおよびサードパーティ コンポーネントのサポートされているバージョンの詳細については、Go エージェントの EOL ポリシー](https://docs.newrelic.com/docs/apm/agents/go-agent/get-started/go-agent-eol-policy/)を参照してください。
