## メモ

Pythonエージェントの今回のリリースでは、OpenSearch、Microsoft Azure SQL、新しいKinesisメソッド、および新しい`browser_monitoring.version`設定のサポートが追加されました。さらに、Anthropic、MCP、およびGoogle ADKの計装に改善が加えられました。このリリースでは、botocore（SigV4）の署名付きヘッダーとGeminiツールの解析に関する問題も修正されています。

[Python パッケージ インデックス](https://pypi.python.org/pypi/newrelic)経由で`easy_install/pip/distribute`を使用するか、 [Conda-Forge パッケージ インデックス](https://anaconda.org/conda-forge/newrelic)経由で`conda`を使用してエージェントをインストールするか、 [New Relic ダウンロード サイト](https://download.newrelic.com/python_agent/release)から直接ダウンロードします。

## 新機能

* [opensearch-py](https://pypi.org/project/opensearch-py/)の新しい計装

  * 公式のOpenSearchデータベースコネクタに計装が追加されました。

* [mssql-python](https://pypi.org/project/mssql-python/)向けの新しい計装

  * Microsoft Azure SQLの計装が追加されました。

* 新しい[Kinesis](https://pypi.org/project/kinesis-python/)メソッドの新しい計装

  * Kinesisで以下のメソッドがサポートされるようになりました：

    * `create_channel`
    * `delete_channel`
    * `describe_channel`
    * `list_channels`
    * `update_channel`

* の新しい設定 `browser_monitoring.version`

  * 新しい設定 `browser_monitoring.version` により、ユーザーは挿入される[ブラウザ監視エージェント](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/introduction-browser-monitoring/)の特定のバージョンを指定できるようになります。
  * 選択可能な[サポートされているBrowserエージェントのバージョン](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/)のリストをご覧ください。

## 改善された機能

* [anthropic](https://pypi.org/project/anthropic/)のサポートが改善されました。

  * バージョン1.0.0以上のAnthropic SDKにおけるリクエストパラメーターの解析が改善されました。
  * `Messages.with_raw_response.create`経由のレスポンスの新しい解析により、LangChainとの互換性が向上しました。

* [mcp](https://pypi.org/project/mcp/) v2.0.0以降をサポートしました。

  * `mcp` v2.0.0で行われた大規模なリファクタリングに伴い、計装が更新され、再び期待通りに動作するはずです。

* [Google ADK](https://pypi.org/project/google-adk/) v2.9.0以上のサポート。

  * バージョン2.9.0以上のGoogle ADK向けに計装が更新されました。

## バグ

* [botocore](https://pypi.org/project/botocore/)（SigV4）の署名付きヘッダーに関する問題を修正しました。

  * 以前は、他のトレーシングライブラリによって生成されたディストリビューティッド（分散）トレーシングのヘッダーが、ヘッダーの署名が原因でbotocoreの計装に問題を引き起こす可能性がありました。この問題は修正され、ディストリビューティッド（分散）トレーシングのヘッダーは署名前に変更されるようになりました。

* [Gemini](https://pypi.org/project/google-genai/)ツールの解析の修正

  * 以前は、Geminiで作成されたツールのいくつかのインスタンスが解析に失敗し、エラーを出さずに失敗して、その特定のリクエストに対するレスポンスが返されないことがありました。この問題は修正されました。

## サポートステートメント

最新のエージェント バージョンが利用可能になったらすぐに更新することをお勧めします。最新バージョンにアップグレードできない場合は、エージェントを 90 日以内のバージョンに更新してください。エージェントを最新の状態に保つ方法の[詳細](/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent/)については、こちらをご覧ください。

エージェントのリリースとサポート日については、New Relic Python エージェントの[EOL ポリシーを](/docs/apm/agents/python-agent/getting-started/python-agent-eol-policy/)参照してください。
