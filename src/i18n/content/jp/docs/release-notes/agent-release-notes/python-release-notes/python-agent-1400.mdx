## メモ

このPythonエージェントのリリースでは、Azure App Servicesの利用状況、Azure Service Busの計装、新しいKinesisメソッドのサポート、およびv2.10.0以降のGoogle ADKのサポートが追加されています。また、このリリースでは、httplibでディストリビューティッド（分散）トレーシングのトレースヘッダーが重複する問題、および`setup.py`インストレーションファイルを修正しています。

[Python パッケージ インデックス](https://pypi.python.org/pypi/newrelic)経由で`easy_install/pip/distribute`を使用するか、 [Conda-Forge パッケージ インデックス](https://anaconda.org/conda-forge/newrelic)経由で`conda`を使用してエージェントをインストールするか、 [New Relic ダウンロード サイト](https://download.newrelic.com/python_agent/release)から直接ダウンロードします。

## 削除された機能

* Python 3.9のサポートを削除しました。

  * Python 3.9 reached End-of-Life on October 31, 2025 and is no longer supported by the agent. Please consider upgrading your application to a supported version of Python in order to continue to receive updates to the Python Agent.

## 新機能

* Azureアプリサービスの利用率

  * エンティティ関係のマッピングを有効にするため、Azure App Serviceの使用率が追加されました。
  * また、新しい設定も追加されます、 `utilization.detect_azureappservice`

* [Azure Service Bus](https://pypi.org/project/azure-servicebus/)向けの新しい計装

  * Microsoft Azure Service Busの計装が追加されました。

* 新しい[Kinesis](https://pypi.org/project/kinesis-python/)メソッド向けの新しい計装

  * Kinesisで`update_stream_record_distribution_strategy`メソッドがサポートされるようになりました。

## セキュリティアップデート

* `urllib3`の現在のすべてのCVEを解決するために、内部の[urllib3](https://pypi.org/project/urllib3/)パッケージが`2.8.0`に更新されました。

  * これにより、現時点までのエージェントにおけるすべての既知のCVEが解決されます。

## 機能の拡充

* [Google ADK](https://pypi.org/project/google-adk/) v2.10.0以降をサポートしています。

  * バージョン2.10.0以上のGoogle ADK向けに計装が更新されました。

## バグ

* [httplib](https://github.com/python/cpython/blob/main/Lib/http/client.py)における重複したディストリビューティッド（分散）トレーシングヘッダー

  * `httplib`の計装が`traceparent`に対して重複するヘッダーを生成し、不正な値になる問題を修正しました。

* `setup.py` サポートされているすべてのPythonバージョンでインストールファイルが動作するようになりました。

  * ユーザーが`setup.py`ファイルを直接使用してPython 3.12以上にPythonエージェントをインストールしようとすると、`ImportError`が発生します。これは、`distutils`がPython 3.10以降非推奨となり、Python 3.12の標準ライブラリから完全に削除されたためです。

## サポートステートメント

最新のエージェント バージョンが利用可能になったらすぐに更新することをお勧めします。最新バージョンにアップグレードできない場合は、エージェントを 90 日以内のバージョンに更新してください。エージェントを最新の状態に保つ方法の[詳細](/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent/)については、こちらをご覧ください。

エージェントのリリースとサポート日については、New Relic Python エージェントの[EOL ポリシーを](/docs/apm/agents/python-agent/getting-started/python-agent-eol-policy/)参照してください。
