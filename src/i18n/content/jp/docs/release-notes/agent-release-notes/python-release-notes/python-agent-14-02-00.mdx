## メモ

このリリースのPythonエージェントでは、Microsoft エージェント・フレームワークおよびCrewAIの計装を追加し、LaunchDarklyの機能フラグの計装とスパン転送サポートを改善し、いくつかのクラッシュを修正しました。

[Python パッケージ インデックス](https://pypi.python.org/pypi/newrelic)経由で`easy_install/pip/distribute`を使用するか、 [Conda-Forge パッケージ インデックス](https://anaconda.org/conda-forge/newrelic)経由で`conda`を使用してエージェントをインストールするか、 [New Relic ダウンロード サイト](https://download.newrelic.com/python_agent/release)から直接ダウンロードします。

## 新機能

* [Microsoft エージェント・フレームワーク](https://pypi.org/project/agent-framework/)の新しい計装

  * `agent-framework` パッケージのツールとエージェントに計装が追加されました。
  * マルチエージェントの設定はまだインストゥルメントされていません。

* [CrewAI](https://pypi.org/project/crewai/)の新しい計装

  * `crewai`パッケージのエージェント、クルー、およびツールに計装が追加されました。

## 機能の拡充

* [LaunchDarkly](https://pypi.org/project/launchdarkly-server-sdk/)の機能フラグのインテグレーションを改善しました。

  <Callout title="プレビュー">
  この機能はまだ開発中ですが、ぜひお試しください。

  この機能は現在、弊社の[プレリリース ポリシー](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy)に従ってプレビュー プログラムの一部として提供されています。
  </Callout>

  * LaunchDarklyとのパブリックプレビューのインテグレーションにオプトインするには、設定ファイルで`launch_darkly_integration.enabled`および`opentelemetry.enabled`の設定を有効にしてください。

  * [ldclient](https://pypi.org/project/launchdarkly-server-sdk/)における機能フラグの計装を改善しました。

    * UIのディープリンクを有効にするため、新しい `feature_flag.url.full` 属性を追加しました。
    * LaunchDarklyに合わせて、`inExperiment`キーの大文字と小文字を変更しました。
    * 機能フラグの属性におけるfalsyな値のサポートを追加しました。
    * すべてのLaunchDarklyインテグレーションの警告を、1回だけ表示されるように削減しました。

  * [ldobserve](https://pypi.org/project/launchdarkly-observability/)のスパン転送を改善しました。

    * ディープUIリンクを有効にするために、`nr.entity.guid`および`nr.entity.url`のスパン属性を追加しました。
    * UIで適切にネストできるように、スパンの親子関係を修正しました。

## バグ修正

* `_add_span_event_event`で属性が`None`だった場合に`TimeTrace`で発生するクラッシュを修正しました。
* デフォルト値にフォールバックする際に、LaunchDarklyの`Config`ラッパーで発生するクラッシュを修正しました。

## サポートステートメント

最新のエージェント バージョンが利用可能になったらすぐに更新することをお勧めします。最新バージョンにアップグレードできない場合は、エージェントを 90 日以内のバージョンに更新してください。エージェントを最新の状態に保つ方法の[詳細](/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent/)については、こちらをご覧ください。

エージェントのリリースとサポート日については、New Relic Python エージェントの[EOL ポリシーを](/docs/apm/agents/python-agent/getting-started/python-agent-eol-policy/)参照してください。
