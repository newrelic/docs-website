## メモ

Pythonエージェントの今回のリリースでは、新しい`ai_monitoring.basic_telemetry.enabled`設定によりAIモニタリングがデフォルトで有効になり、`ai_monitoring.enabled`設定が非推奨となり、LangChainツールの計装で発生したクラッシュが修正されました。

[Python パッケージ インデックス](https://pypi.python.org/pypi/newrelic)経由で`easy_install/pip/distribute`を使用するか、 [Conda-Forge パッケージ インデックス](https://anaconda.org/conda-forge/newrelic)経由で`conda`を使用してエージェントをインストールするか、 [New Relic ダウンロード サイト](https://download.newrelic.com/python_agent/release)から直接ダウンロードします。

## 変更点

* AIモニタリングがデフォルトで有効化されるようになりました。

  * LLMの計装はデフォルトで有効になっており、別の設定を行わない限り、エージェントは`Llm*`のカスタムイベント、スパン、およびメトリクスを（メッセージの内容を含まずに）送信します。
  * プロンプトとレスポンスの内容を記録するには、[`ai_monitoring.record_content.enabled`](/docs/apm/agents/python-agent/configuration/python-agent-configuration/#ai-monitoring-record-content)を`true`に設定します。
  * オプトアウトするには、newrelic.iniで[`ai_monitoring.basic_telemetry.enabled`](/docs/apm/agents/python-agent/configuration/python-agent-configuration/#ai-monitoring-basic-telemetry-enabled)を`false`に設定するか、または環境変数`NEW_RELIC_AI_MONITORING_BASIC_TELEMETRY_ENABLED=false`を設定します。
  * [`ai_monitoring.enabled`](/docs/apm/agents/python-agent/configuration/python-agent-configuration/#ai-monitoring-enabled)設定および`NEW_RELIC_AI_MONITORING_ENABLED`環境変数は非推奨ですが、どちらかを`false`に設定した場合もAIモニタリングからオプトアウトされます。

## バグ修正

* `config`またはその`metadata`が`None`の場合に、[LangChain](https://pypi.org/project/langchain/)の`StructuredTool.invoke`および`StructuredTool.ainvoke`の計装で発生するクラッシュを修正しました。

## サポートステートメント

最新のエージェント バージョンが利用可能になったらすぐに更新することをお勧めします。最新バージョンにアップグレードできない場合は、エージェントを 90 日以内のバージョンに更新してください。エージェントを最新の状態に保つ方法の[詳細](/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent/)については、こちらをご覧ください。

エージェントのリリースとサポート日については、New Relic Python エージェントの[EOL ポリシーを](/docs/apm/agents/python-agent/getting-started/python-agent-eol-policy/)参照してください。
