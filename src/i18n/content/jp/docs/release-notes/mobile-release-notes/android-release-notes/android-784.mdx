### バグ修正

* `EventPersistence`が無効になっている場合に、永続化されたイベントが毎回のリリース時に再ロードされ、再送信される問題を解決しました。

* エージェントがイベント・バッファ時間の最小/最大範囲に従うように、イベント・バッファの動作を修正しました。

* セルラー・サブタイプを解決できなかった場合に、`connectionType`が&quot;unknown&quot;として報告される問題を修正しました。

## サポートステートメント

少なくとも 3 か月ごとにエージェントを更新することをお勧めします。Androidエージェントのサポートに関する具体的なポリシーと日付については、「 [モバイル監視エージェント EOL ポリシー」](/docs/mobile-monitoring/new-relic-mobile/get-started/mobile-agents-eol-policy/#android-eol)を参照してください。
