### バグ修正

* ポインター認証（PAC）を使用するarm64デバイスで、ネイティブクラッシュレポートが欠落する問題を修正しました。これらのデバイスでは、バンドルされている古いアンワインダー内でクラッシュハンドラーが失敗したため、レポートやtombstoneは生成されませんでした。エージェントはNDK r25でビルドされるようになりました。
* アプリがバックグラウンドから復帰した後、`NR_AppStateMon`スレッドまたはメインスレッドで断続的に発生する&quot;スタックの破損が検出されました（-fstack-protector）&quot;というクラッシュを修正しました。
* アプリがフォアグラウンドに復帰した後に発生する、解放後使用（use-after-free）のクラッシュを修正しました。この問題は、アプリがバックグラウンドに移行した際、エージェントが代替シグナルスタックを事前に無効化せずに解放したために発生していました。
