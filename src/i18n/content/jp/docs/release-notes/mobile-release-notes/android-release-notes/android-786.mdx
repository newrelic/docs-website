### 改善と強化

* MAUIセッションリプレイは、グローバルテキストマスキング（Mask All \[すべてマスク]、Mask Input \[入力をマスク]、Mask None \[マスクなし]）および、タグまたはクラスによるビューごとのマスキングをサポートしています。ネイティブのAndroidおよびiOSと同じように動作し、パスワードフィールドは常にマスクされます。
* このリリースは、Android NDKエージェント 1.1.6とともに提供されており、PAC対応デバイスでのネイティブクラッシュハンドラーの障害と、アプリの再開後に解放されたシグナルスタックによって引き起こされるクラッシュを修正します。

### バグ修正

* `MobileRequest` イベントには、`contentType`および`bytesReceived`と重複していた内部の`content_type`および`content_length`属性が含まれなくなりました。
* アプリがフォアグラウンドになった際に、ルート検出が例外（たとえば、SUNMI Android 14デバイスでのRootBeerからの`NullPointerException`）をスローして発生するクラッシュを修正しました。エージェントはデバイスをルート化されていないものとして扱い、実行を継続するようになりました。
* エージェントがネイティブに起動し、ハイブリッドSDKが実行時にプラットフォームを設定しない場合、エージェントはハイブリッドSDKが提供するリソースからそれを読み取るようになりました。Flutter、React Native、Capacitor、およびCordovaアプリは、最初のイベントから正しい`platform`と`platformVersion`を報告します。

## サポートステートメント

少なくとも 3 か月ごとにエージェントを更新することをお勧めします。Androidエージェントのサポートに関する具体的なポリシーと日付については、「 [モバイル監視エージェント EOL ポリシー」](/docs/mobile-monitoring/new-relic-mobile/get-started/mobile-agents-eol-policy/#android-eol)を参照してください。
