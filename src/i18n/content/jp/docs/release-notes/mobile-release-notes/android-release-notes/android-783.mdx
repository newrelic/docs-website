### 改善と強化

* AGP 9.4サポート：New Relic GradleプラグインにAndroid Gradleプラグイン（AGP）9.4.xのサポートを追加しました。

* ディストリビューティッド（分散）トレーシングヘッダーの最適化：独自のnewrelicリクエストヘッダーを削除し、W3C標準のtraceparentヘッダーとtracestateヘッダーのみに依存することで、ディストリビューティッド（分散）トレーシングを合理化しました。

* WebView Browserエージェントの検出：アクティブなWebViewがNew Relic Browserエージェントを利用しているかどうかを検出および追跡するためのサポートアビリティメトリクスを追加しました。

* SDKサイズ最適化のガイダンス：開発者が無効化された機能の未使用のエージェントコードを削除するのに役立つ、ProGuard/R8のツリーシェイキングルールに関するドキュメントを追加しました。

### バグ修正

* セッションリプレイのクラッシュ修正：セッションリプレイでCurtainsを初期化する際に、メインスレッドでNullPointerExceptionを引き起こしていたマルチスレッドの競合状態を修正しました。

* HTTP2ペイロードサイズの追跡：ヘッダーのないHTTP/2およびKtorストリームにおいて、ネットワークリクエストのペイロードサイズ（bytesReceived）が誤って0バイトと報告される問題を解決しました。

* リソースリークの解決：SessionReplayFileManager内のBufferedWriterインスタンスを適切に閉じることで、静的解析の指摘（CWE-404）を解決しました。

## サポートステートメント

少なくとも 3 か月ごとにエージェントを更新することをお勧めします。Androidエージェントのサポートに関する具体的なポリシーと日付については、「 [モバイル監視エージェント EOL ポリシー」](/docs/mobile-monitoring/new-relic-mobile/get-started/mobile-agents-eol-policy/#android-eol)を参照してください。
