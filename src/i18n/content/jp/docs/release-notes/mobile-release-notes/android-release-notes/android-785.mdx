### 改善と強化

* エージェントはアプリのデフォルトプロセスでのみ起動するようになったため、`android:process` で追加のプロセスを宣言するアプリが、それらのプロセスから空のセッションを報告することはなくなりました。([#648](https://github.com/newrelic/newrelic-android-agent/pull/648))

### バグ修正

* アプリがバックグラウンドにあるときに発生したANRやその他のアプリの終了が次回のリリースで報告される際に、`background`属性が欠落している問題を修正しました；プロセスが終了した際のアプリの状態に基づいて、属性は`true`または`false`になります。([#653](https://github.com/newrelic/newrelic-android-agent/pull/653))
* アプリがフォアグラウンドにある間に記録されたイベントが、アプリがバックグラウンドに移行した後に収集されたバッチで送信された場合に、`background = true` で報告される問題を修正しました。Background Reporting \[バックグラウンドレポート] を有効にすると、すべてのイベントに、記録された時点のアプリの状態を示す `background = true` または `background = false` が含まれるようになりました。以前は、フォアグラウンドイベントには `background` 属性がありませんでした。([#655](https://github.com/newrelic/newrelic-android-agent/pull/655))
* `WebView` のサブクラスが `setWebViewClient` をオーバーライドしてクライアントを保存し、独自の内部クライアントからそのクライアントへ転送するアプリにおいて、ページ読み込み時に発生する `StackOverflowError` のクラッシュを修正しました。エージェントは、そのような WebView に WebView クライアントラッパーをインストールしなくなりました。([#660](https://github.com/newrelic/newrelic-android-agent/pull/660))
* エージェントがメインスレッドでディスクから保存済みのイベントを読み込むことで、アプリの起動時に発生していたANRを修正しました。イベントはバックグラウンドで読み込まれるようになりました。([#661](https://github.com/newrelic/newrelic-android-agent/pull/661))

## サポートステートメント

少なくとも 3 か月ごとにエージェントを更新することをお勧めします。Androidエージェントのサポートに関する具体的なポリシーと日付については、「 [モバイル監視エージェント EOL ポリシー」](/docs/mobile-monitoring/new-relic-mobile/get-started/mobile-agents-eol-policy/#android-eol)を参照してください。
