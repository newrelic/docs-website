## バグ修正

* `MobileRequest`/`MobileRequestError`イベントからのカスタム`httpParams`および追跡されたヘッダー値を暗黙のうちにドロップしていたiOSブリッジのハードコーディング`andParams: nil`を修正しました。Androidはすでにパラメーターを正しく転送していました。

## 機能強化

* ネイティブAndroidエージェントをバージョン7.8.1にアップデートしました。
* ネイティブiOSエージェントをバージョン7.7.6に更新しました。
