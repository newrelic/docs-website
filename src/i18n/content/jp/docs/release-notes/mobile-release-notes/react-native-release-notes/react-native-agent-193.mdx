## 改善と強化

* ネイティブAndroidエージェントをバージョン7.8.4に更新しました。Native iOSエージェントをバージョン7.7.9に更新しました。([#336](https://github.com/newrelic/newrelic-react-native-agent/pull/336))

## バグ修正

* オプトインのSwiftパッケージマネージャのインテグレーション（`NEWRELIC_USE_SPM=1`）を修正しました：アプリが`Library not loaded: @rpath/NewRelic.framework/NewRelic`でリリース時にクラッシュしなくなり、アーカイブが重複するxcframeworkシグネチャで失敗しなくなり、iOSエージェントが最新の7.7.xリリースに解決されるようになりました。([#334](https://github.com/newrelic/newrelic-react-native-agent/pull/334))
