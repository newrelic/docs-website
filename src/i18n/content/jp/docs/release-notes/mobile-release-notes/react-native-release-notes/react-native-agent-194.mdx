### 新機能

* エージェントが`console.*`呼び出しをログとしてキャプチャするのを停止できる`consoleCaptureEnabled`設定オプション（デフォルトは`true`）を追加しました。([#342](https://github.com/newrelic/newrelic-react-native-agent/pull/342))

### 改善と強化

* 公開されていたNew Relicアプリケーショントークンを削除しました。([#338](https://github.com/newrelic/newrelic-react-native-agent/pull/338))
* ネイティブAndroidエージェントをバージョン7.8.5に更新しました。([#346](https://github.com/newrelic/newrelic-react-native-agent/pull/346))
* Swiftパッケージマネージャ（`NEWRELIC_USE_SPM=1`）向けに、ネイティブiOSエージェントをバージョン7.7.10に更新しました。CocoaPodsでは7.7.10が利用できないため、CocoaPodsでのインストールは7.7.9のままです。([#346](https://github.com/newrelic/newrelic-react-native-agent/pull/346))

### バグ修正

* 例外をスローするゲッターを持つオブジェクトなど、引数をシリアライズできない場合に `console.log/warn/error/debug` が例外をスローしてクラッシュする問題を修正しました。([#341](https://github.com/newrelic/newrelic-react-native-agent/pull/341))
