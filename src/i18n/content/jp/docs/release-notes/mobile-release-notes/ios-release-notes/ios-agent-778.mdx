### バグ修正

* メモリ不足の状況下で`recordError`を呼び出すと、ホストアプリケーションが終了する可能性がある問題を修正しました。エラーレポートは破棄されてログに記録されるようになり、記録されたスタックの先頭からNew Relicエージェントのフレームがトリミングされるようになりました。
* セッション属性を削除する際に、ログのフォーマット文字列で引数が欠落していたことが原因で発生した`NRMALoggerBridge::log`のクラッシュを修正しました。同じコンポーネント内のさらに2つの無効なフォーマット文字列を修正しました。
* 新しいイベントシステムを使用する際に、ディストリビューティッド（分散）トレーシングのタイムスタンプ（`tracestate`およびペイロード`ti`）がミリ秒ではなく秒単位で送信される問題を修正しました。
* クロスプラットフォームSDKが`traceHeaders`を渡したときに、成功した`MobileRequest`イベントがすべてのディストリビューティッド（分散）トレーシング属性を失う問題を修正しました。
* Flutter、React Native、またはその他のハイブリッドエージェントによって`traceHeaders`で報告されたrequestsに重複するディストリビューティッド（分散）トレーシングが追加されるのを防ぐため、ネイティブエージェントを更新しました。これは、両方のイベントシステムにおける`MobileRequest`と`MobileRequestError`の両方に適用されます。
* `MaxEventPoolSize`および`MaxEventBufferTime`の設定に対する最小および最大の境界制限を適用しました（最大バッファ時間は600秒に制限されます）。
* 新しいイベントシステムを使用する場合に、常に `YES` を返すのではなく、イベントが正常に追加されたかどうかを示すブール値を返すように `recordCustomEvent` を更新しました。
* Androidエージェントの動作に合わせて、正しい大文字・小文字の`ReactNative`プラットフォーム値を渡すように、React Native JavaScriptエラーのアップロードを更新しました。
