### このリリースで修正された点

* setUserIdをnilで呼び出すと常に新しいセッションが開始されるバグを修正しました。

* 古いセッションリプレイのフレームが新しいセッションと一緒にアップロードされるのを防ぎました。

* 毎回呼び出すのではなく、変更時にコールバックを更新するようにreachabilityを変更しました。

* hex invalidateのクラッシュを修正しました。

* setUserIdのvendorIdに関するクラッシュを修正しました。

* NRMAトレースのコレクション全体における原子性を修正しました。

* setUserIdが同期を維持するように修正しました。

* セッションリプレイをTimerからDispatchSourceTimerに変更することで、クラッシュを修正しました。

* CoreData NRMAMethodProfilerのクラッシュを修正しました。

* sessionAttributeJSONStringが辞書のスナップショットを取得するようにして、クラッシュを修正しました。

* SwiftUIのテキスト幅補正オフセットをコンテンツにクランプすることで、MSRテキストを修正しました。

* JSErrorControllerのメモリリークを修正しました。

* バイナリのボールド特性の代わりに正確な数値のフォントウェイトを参照することで、MSRテキストを修正しました。

* dSYMアップロードツールを更新し、dsym-upload-tools run-symbol-toolにappVersionパラメーターを追加しました。

* MSRでSwiftUIのモーダルが表示されない問題を修正しました。
