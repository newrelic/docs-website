### 新機能

* 文書化された最小プラットフォーム要件に合わせて、iOS 15.0およびtvOS 15.0の最小デプロイメントバージョンをターゲットにするようにXCFrameworkのビルド設定を更新しました。

### バグ修正

* harvest設定の読み取り中に発生したクラッシュ（`objc_msgSend`内の`SIGSEGV`）を解決しました。`/connect`レスポンスまたは`NSUserDefaults`ディクショナリからのautorelease poolのドレイン後、`assign`として宣言された`NRMAHarvesterConfiguration`の8つのオブジェクトプロパティがダングリングポインタを保持していました。

* `/connect`応答で`at_capture`属性が省略された場合に、セッションのすべてのアクティビティトレースが破棄される問題を解決しました。

* React Nativeのエラーとともに報告される`platform`の値を、`ReactNative`として報告するように修正しました。

* ホストプラットフォームのバージョンではなく、iOSエージェントのバージョンを正確に報告するように、JavaScriptエラーペイロードの`agentVersion`フィールドを修正しました。

* カスタムアトリビュートの検証を更新しました：イベント属性として`NSArray`または`NSDictionary`オブジェクトを渡すと、一般的な`"value must be an NSString, NSNumber, or BOOL"`の警告メッセージの代わりに、サポートされていないタイプを特定する明示的なエラーがログに記録されるようになりました。
