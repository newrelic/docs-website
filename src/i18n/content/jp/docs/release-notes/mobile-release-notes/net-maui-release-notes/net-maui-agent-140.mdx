### 新機能

* AndroidおよびiOS上のCoreCLRランタイムを含む、.NET 11のサポートを追加し、.NET 9ターゲットを削除しました；CoreCLRでの未処理のiOS例外は、マネージドスタックトレースとともに報告されるようになりました。([#87](https://github.com/newrelic/newrelic-maui-plugin/pull/87))
* .NET MAUIビューにセッションリプレイのプライバシー拡張機能を追加しました。([#102](https://github.com/newrelic/newrelic-maui-plugin/pull/102))

### 改善と強化

* ネイティブAndroidエージェントをバージョン7.8.6に更新しました。
* ネイティブiOSエージェントをバージョン7.7.11に更新しました。
