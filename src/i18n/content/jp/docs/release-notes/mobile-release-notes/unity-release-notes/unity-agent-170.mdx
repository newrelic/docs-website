## 改良点

* `Library not loaded: @rpath/NewRelic.framework/NewRelic`によりリリース時にiOSアプリがクラッシュする問題を修正しました。1.6.0で追加されたSwiftパッケージマネージャの宣言は削除され、iOSの依存関係はCocoaPods経由でのみ解決されるようになりました。1.6.0から1.6.4までのビルドは、EDM4U iOS Resolverの設定でSwiftパッケージマネージャを手動で無効にしない限り影響を受けました。
* Unity 2019.1から2021.2までのビルドからNew Relic iOSエージェントが完全に欠落する問題を修正しました。これらのビルドでは、EDM4Uは`NewRelicAgent`ポッドを抑制しましたが、Unity 2021.3以降が必要であるためSwiftパッケージマネージャのインジェクションをスキップしていました。
* ネイティブAndroidエージェントがバージョン7.8.2に更新されました。
* ネイティブAndroid NDKエージェントがバージョン1.1.5に更新されました。
* ネイティブiOSエージェントをバージョン7.7.6に更新
* iOSの依存関係はCocoaPods経由でのみ解決されるようになりました。EDM4Uは自動的に`NewRelicAgent`ポッドにフォールバックし、**Swift Package Manager Enabled**設定はオンのままで問題ないため、以前にSwiftパッケージマネージャを使用していた場合でも対応は不要です。
* 生成されたXcodeプロジェクトに以前のビルドの`newrelic-ios-agent-spm`パッケージ参照がまだ含まれている場合は、生成されたプロジェクトを削除し、Unityから再ビルドしてクリアしてください。
