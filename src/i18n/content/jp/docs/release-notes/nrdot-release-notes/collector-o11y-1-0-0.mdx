### 特徴

* `nrdot-collector:2.8.1`および...のCollectorオブザーバビリティのサポートを検証しました `opentelemetry-collector-contrib:0.163.2`
* 自動検出に不要になったため、`newrelic.service.type`リソース属性を削除しました
* 取り込み時の不要な変換を避けるために`temporality_preference: delta`を設定してください
