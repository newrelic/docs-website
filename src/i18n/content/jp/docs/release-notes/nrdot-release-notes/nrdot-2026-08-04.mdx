## 変更ログ

`0.157.0`での`opentelemetry-collector-contrib`からの削除に伴い、`nrdot-collector`と`nrdot-collector-experimental`の両方のコンポーネントマニフェストから`jmxreceiver`が削除されたことを示すために、破壊的変更を伴うリリースを発行します（参考として[issue 45740](https://github.com/open-telemetry/opentelemetry-collector-contrib/issues/45740)を参照してください）。このコンポーネントは、[Kafka監視](/docs/opentelemetry/integrations/kafka/overview/)のユースケースでのみ使用されていましたが、このユースケースはこのレシーバーに依存しないように変更されました。`jmxreceiver`を使用してカスタム設定で`nrdot-collector`をデプロイする場合は、[レシーバーの非推奨に関する通知](https://github.com/open-telemetry/opentelemetry-collector-contrib/tree/v0.156.0/receiver/jmxreceiver#deprecation-notice)のガイダンスに従って移行してください。

### 特徴

* otelコンポーネントのバージョンをv0.156.0からv0.157.0に引き上げました(#643)。
* `nroracledbreceiver`と`nrsqlserverreceiver`をv0.157.2に引き上げました(#643)。
  * これらのコンポーネントの変更リストについては、[それぞれの変更履歴](https://github.com/newrelic-forks/opentelemetry-collector-contrib/blob/receiver/nrsqlserverreceiver/v0.157.2/NR_CHANGELOG.md)を参照してください。
* `sqlqueryreceiver`を`nrdot-collector-experimental`ディストリビューションに追加しました。(#632)

### バグ修正

* `nrdot-collector`と`nrdot-collector-experimental`から`receiver/jmxreceiver`を削除しました。(#635)
  * このコンポーネントは、`v0.145.0`での非推奨化に伴い、`v0.157.0`のアップストリームで削除されました。
* `v0.157.0`でのコンポーネント名の変更に伴い、設定ノード`cumulativetodelta`を`cumulative_to_delta`に名前変更しました。(#644)
  * 元の名前`cumulativetodelta`は、非推奨のエイリアスとして引き続き利用可能です。
* ホスト設定で`system.cpu.logical.count`を無効にしました。(#647)
  * `receiver/host_metrics`への`v0.157.0`のアップデートにより、このメトリクスがデフォルトで有効になりました。この変更により、以前の動作が復元されます。
* ホスト設定から`system.cpu.utilization`の平均集計ルールを削除しました。(#646)
  * `receiver/host_metrics`への`v0.157.0`のアップデートにより、デフォルトの動作が`system.cpu.utilization`を平均で集計するように変更され、削除されたルールが冗長になりました。
* CVE-2026-56852 (#634)
