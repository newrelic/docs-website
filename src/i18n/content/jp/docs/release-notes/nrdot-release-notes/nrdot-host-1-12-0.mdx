## 変更ログ

設定または`nrdot-collector`の関連する変更にスコープを絞った、[「Host 監視」](https://github.com/newrelic/nrdot-collector-releases/blob/main/distributions/nrdot-collector/README.md#use-cases)ユースケース向けの初めての専用リリースノートです。[nrdot-コレクター](https://docs.newrelic.com/docs/release-notes/nrdot-release-notes/nrdot-1-12-0/)は、このユースケースを機能させるために必要な設定を引き続きバンドルします。しかし、`nrdot-collector`がますます多くのユースケースをサポートするようになるにつれて、Host 監視のような特定の目的でNRDOTを使用するユーザーにとって、よりわかりやすい追加のリリースノートを提供したいと考えています。

### 特徴

* 動作確認済みのホストの使用例 `nrdot-collector:1.12.0`
