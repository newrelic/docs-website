## 改良点

* **`DotNet/Agent/Installed`：** `newrelic.config` が存在しない場合に .NET エージェントの DLL を検出するようにタスクを更新し、`newrelic.config` の大文字と小文字を区別しないマッチングを有効にしました。以前は、設定ファイルがないとエージェントの検出が妨げられ、下流の .NET タスクがスキップされていました（[#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)）。
* **`DotNet/Config/Agent`：** `newrelic.config` が見つからない場合、失敗ではなく警告を発行するようにタスクを更新しました（[#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)）。
* **.NET Coreの設定：**環境固有の設定ファイル（`appsettings.Production.json`など）を収集して分析するように、ファイル収集を更新しました。類似の命名パターンを持つ無関係なファイル（`myappsettings.json`など）は収集されなくなりました（[#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)）。
* **.NET Core カスタムインストゥルメンテーション:** プロファイラーのファイル解決ロジックに合わせて、エージェントの`extensions`および`extensions/netcore`ディレクトリを検査するようにXMLリーダータスクを更新しました([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276))。
* **.NETエージェントのログ：**1日のカットオフがプロファイラーのログにのみ適用されるようにログのフィルタリングを更新し、過去7日間のエージェントのログを保持するようにしました。プロファイラーのログにも `-lastModifiedDate` フラグが適用されるようになりました([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276))。
* **.NET エージェントのバージョンと EOL チェック：** .NET エージェントのサポート終了（EOL）およびサポート対象バージョンのパラメーターを更新しました。.NET フレームワークのバージョン 4.7.1、4.7.2、4.8、および 4.8.1 の個別の検出を追加し、.NET Core エージェントのバージョン収集を有効にしました（[#273](https://github.com/newrelic/newrelic-diagnostics-cli/pull/273)）。
* **.NETエージェントのログレベル：**.NETエージェントのランタイム動作に合わせて、設定を大文字と小文字を区別せずに評価するように、ログレベルの設定を更新しました（[#274](https://github.com/newrelic/newrelic-diagnostics-cli/pull/274)）。
* **.NET TLSチェック:** サポートされている.NET フレームワークのバージョンでは、キーが存在しない場合、デフォルトでTLS 1.2が使用されるため、`SchUseStrongCrypto`キーが存在しなくてもエラーとしてフラグ付けされないようにレジストリ検証を更新しました。キーが存在し、`1`以外の値に設定されている場合にのみ、エラーが報告されるようになりました([#275](https://github.com/newrelic/newrelic-diagnostics-cli/pull/275))。

## バグ修正

* リリースビルドでアップロードURLが割り当てられていないために、日本のデータリージョンへのアップロードが失敗する問題を修正しました([#277](https://github.com/newrelic/newrelic-diagnostics-cli/pull/277))。
* `COR_ENABLE_PROFILING`を正しくチェックするように、.NET フレームワークのプロファイリング環境変数の検証における問題を修正しました。.NET エージェントのログの場所を解決する際に、`NEW_RELIC_LOG_DIRECTORY`と`NEWRELIC_LOG_DIRECTORY`の両方のサポートを追加しました（[#272](https://github.com/newrelic/newrelic-diagnostics-cli/pull/272)）。
* 解析中に等号（`=`）を含む環境変数の値が切り捨てられる問題を修正しました（[#272](https://github.com/newrelic/newrelic-diagnostics-cli/pull/272)）。
