New Relicは、毎日Node APIランタイムイメージの脆弱性をスキャンし、毎週木曜日にパッチ適用済みのリリースを公開します。各リリースには、その週の火曜日の18時29分（UTC）までに特定された、OSおよびアプリケーションのCVEに対する修正が含まれています。その時間以降にCVEが特定された場合、その修正は翌週の木曜日のリリースで提供されます。

すべてのリリースは、Node.js 22を実行する`latest`タグに公開されます。`latest`を使用するプライベートロケーションでは、自動的に修正が適用されます。特定のバージョンタグを使用している場合は、手動で最新バージョンに更新して、最新の修正を適用してください。
</Callout>
