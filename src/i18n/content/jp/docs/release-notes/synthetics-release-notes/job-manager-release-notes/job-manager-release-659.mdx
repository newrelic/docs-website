<Callout variant="important">
New Relicは毎日、外形監視ジョブマネージャーのイメージの脆弱性をスキャンし、毎週木曜日にパッチ適用済みのリリースを公開します。各リリースには、その週の火曜日の18時29分（UTC）までに特定されたOSおよびアプリケーションのCVEに対する修正が含まれています。その時間以降にCVEが特定された場合、その修正は翌週の木曜日のリリースで提供されます。

すべてのリリースは`latest`タグに公開されるため、`latest`を使用するプライベートロケーションには自動的に修正が適用されます。特定のバージョンのタグを使用している場合は、手動で最新バージョンにアップデートして最新の修正を取得してください。

ジョブマネージャーは、Ping、Node API、およびNodeブラウザのランタイムとは別にリリースされます。各ランタイム自体の修正については、それぞれのリリースノートをご確認ください。
</Callout>
