New Relicは毎日Pingランタイムイメージの脆弱性をスキャンし、毎週木曜日にパッチを適用したリリースを公開します。各リリースには、その週の火曜日のUTC 18:29までに特定されたOSおよびアプリケーションのCVEに対する修正が含まれます。その時間以降にCVEが特定された場合、修正は翌週の木曜日のリリースで提供されます。

すべてのリリースは`latest`タグに公開されるため、`latest`を使用するプライベートロケーションには自動的に修正が適用されます。特定のバージョンのタグを使用している場合は、手動で最新バージョンにアップデートして最新の修正を取得してください。
