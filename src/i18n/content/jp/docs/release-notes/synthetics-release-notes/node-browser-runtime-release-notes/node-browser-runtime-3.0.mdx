### バグ修正

* AngularおよびZone.jsアプリケーションでの12～30秒のクリック遅延を修正しました。外形監視ブラウザ拡張機能は、BiDi（`webExtension.install`）ではなくCDP WebSocket（`Extensions.loadUnpacked`）経由で読み込まれるようになりました。Chrome 153以降のBiDiでは、クリックのたびに「Waiting for pending navigations」チェックが導入され、保留中のマクロタスクがあるアプリの応答が停止していました。CDPに切り替えることで、BiDiをセッションから除外し、ChromeDriverの従来の1ミリ秒未満の`document.readyState`ナビゲーションチェックを復元します。
