* undiciを7.30.1（npm内では6.29.1）にアップグレードしました：CVE-2026-109383、CVE-2026-109829、CVE-2026-109841、CVE-2026-109869、CVE-2026-109924、CVE-2026-109932、CVE-2026-87018、CVE-2026-87029

* nodemailerを10.2.1にアップグレードしました：GHSA-85x2-q946-cp5h、GHSA-8c8m-p3m8-cjg8、GHSA-m943-m63m-w62w、GHSA-4ffr-jq9g-5ffx、GHSA-g73g-hqqh-jr95
* qsを6.16.1にアップグレードしました：CVE-2026-110816

**OSの脆弱性：**

* zlib1gを1:1.3.dfsg-3.1ubuntu2.3に更新しました：CVE-2026-85091
* libbrotli1を更新しました：CVE-2026-111497

**CA証明書：**

* OSのCAバンドルおよび各キーストアから、eMudhra（emSign）ルート証明書とComodo AAA Certificate Servicesルートの信頼を削除することで、eMudhra認証局の侵害に対処しました。
