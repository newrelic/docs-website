### バグ修正

* ゲートウェイ経由でデータを送信する際、Python APMエージェントがハーベストごとにJSONデコードエラーをログに記録し、重複したログの発生やエラーデータの損失を引き起こす問題を修正しました。エージェントプロトコルの仕様に従い、ゲートウェイはAPMエージェントのデータrequestsに対して、HTTP `202 Accepted`と空のボディで応答するようになりました。
* APMエージェントからのスパンイベントが、スパンの開始時刻ではなく、ゲートウェイが受信した時刻で記録される問題を修正しました。

### セキュリティアップデート

* 高深刻度および中深刻度の脆弱性を解決するために、`golang.org/x/net`の依存関係を`v0.62.0`に更新しました。
