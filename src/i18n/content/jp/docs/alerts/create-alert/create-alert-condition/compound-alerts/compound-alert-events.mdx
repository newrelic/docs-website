複合アラート条件のトリガー式がtrueと評価されると、New Relicは複合アラートイベントを開きます。イベントには、ランブックURLへのリンクが含まれます。各コンポーネント条件の特定の閾値違反を表示するには、個別のアラートイベントをクリックして確認します。

## アラートイベントと問題の相関関係 [#alert-events-correlation]

複合アラート条件は、関連する複数のアラートイベントを作成します：

* <DNT>**Multiple alert events**</DNT>：複合アラート条件は、独自の複合アラートイベントを作成します。デフォルトでは、各コンポーネント条件も、閾値に違反したときに独自のアラートイベントを作成します。ノイズを減らすために、アラート条件の設定からこれらのイベントをサイレンスできます。コンポーネント条件のアラートイベントをサイレンスすると、その条件のタグは複合アラートイベントに表示されません。
* <DNT>**Issue correlation**</DNT>：関連するすべてのアラートイベント（複合およびコンポーネントの両方）が同じ問題にグループ化されるようにするには、複合アラート条件と同じポリシーを使用するようにコンポーネント条件を設定します。これにより、New Relicの問題の相関関係がそれらをグループ化できるようになります。
* <DNT>**Related events**</DNT>：複合アラートイベントから、個々のコンポーネントアラートイベントに移動して、各条件の閾値違反とメトリクスを確認できます。

## カスタムタイトルと説明 [#custom-title-description]

複合アラート条件に[タイトルまたは説明のテンプレート](/docs/alerts/create-alert/create-alert-condition/compound-alerts/create-compound-alert#title-description-templates)を設定すると、そのカスタマイズは生成されるインシデントに引き継がれます：

* <DNT>**Issue title**</DNT>：インシデントのタイトルには、システムが生成するデフォルトの見出しの代わりに、複合条件のタイトルテンプレートからレンダリングされたテキストが表示されます。
* <DNT>**Issue description**</DNT>：複合条件の説明テンプレートからレンダリングされたテキストは、複合条件のアラートイベントセクションの直下に表示されます。

インシデントページをわかりやすく保つため、個々のコンポーネント（子）条件の説明はそこには表示されません — 複合条件の説明のみが表示されます。

## 影響を受けるエンティティ [#impacted-entities]

コンポーネント条件が一致するファセット（たとえば、同じサービスやホスト）を共有している場合、New Relicはインシデントページの下部にある[影響を受けるエンティティ](/docs/alerts/alert-event-management/Issues-and-alert-event-management-and-response/#impacted-entities-and-issue-map)セクションに一致するエンティティを表示します。共有ファセットが複数のエンティティに一致する場合、1つだけでなく、それらすべてが表示されます。

エンティティカードにカーソルを合わせるかクリックすると、レスポンスタイム、スループット、エラー率など、そのエンティティの主要なヘルスおよびパフォーマンスメトリクスを表示できます。
