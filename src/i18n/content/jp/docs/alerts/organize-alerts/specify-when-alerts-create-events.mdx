<Callout variant="important">
  このドキュメントでは、新しい用語「イシュー」や「アラート」を使用しています。これらの用語の詳細については、[こちらの記事](https://support.newrelic.com/s/hubtopic/aAX8W0000008cYv/new-terminology-coming-for-alerts)を参照してください。
</Callout>

このページの情報を最大限に活用するには、以下の用語の意味を理解しておくことをお勧めします。

* <DNT>**Issues**</DNT>：イシューとは、同じ根本的な問題に関連するアラートのグループを指します。アラートが新規作成されると、アラートインテリジェンスが新しいイシューを開く場合があり、さらに他の未解決のイシューとの相関性を評価します。詳細については、[イシューとアラートの管理と対応](/docs/alerts/alert-event-management/Issues-and-alert-event-management-and-response/)を参照してください。

* <DNT>**Alert events**</DNT>：アラートとは、システムに影響を及ぼす症状を経時的に示すイベントを指します。詳細については、[アラートの詳細の表示](/docs/alerts/alert-event-management/view-alert-event-details/)を参照してください。

* <DNT>**Conditions**</DNT>：条件とは、監視対象のデータソースと、そのデータソースのどのような挙動をアラートとみなすかを定義したものです。詳細については、[条件の作成](/docs/alerts-applied-intelligence/new-relic-alerts/alert-conditions/create-alert-conditions/)を参照してください。

* <DNT>**Policies**</DNT>ポリシーとは、1つ以上の条件のグループを指します。詳細については、[ポリシーの管理](/docs/alerts-applied-intelligence/new-relic-alerts/alert-policies/create-edit-or-find-alert-policy/)を参照してください。

イシューによって、事業運営に支障をきたすアラートが通知されるタイミングが決まります。各アラートは、そのアラート条件が満たされると発生します。たとえば、CPU使用率の超過、外形監視の失敗、ウェブアプリのレスポンスタイムの遅延などに関するアラート条件を設定できます。

イシューを引き起こすポリシー条件を制御できる場合は、重要な進行中の問題や再発する問題について通知を受けるようにしてください。こうすることで、不要な通知が大量に送信されることがなくなり、ノイズを回避できます。

ポリシー、条件、または条件と信号の組み合わせ別でイシュープリファレンスを設定する方法をご覧ください。

## 問題の環境設定の選択 [#preference-procedures]

デフォルトでは、各ポリシーごとに1つのイシューレコードが作成されます。

選択したポリシーのイシュープリファレンスを変更するには：

1. <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Alerts &gt; Alert Policies**</DNT>に移動します。

2. ポリシーを選択します。

## 重大なアラートと警告アラート [#alert-event-types]

ポリシー条件が満たされた場合、次の2つの閾値タイプから選択します。

* クリティカル（赤）
* 警告（黄）

ポリシー条件が閾値を超えるとアラートが発生します。また、効率的な対応に役立つ詳細情報を含むイシューレコードが作成される場合があります。イシューレコードには、最初のアラートの後に発生した他のアラートも含まれる場合があります。

通知は、ポリシーのすべての通知チャネル、およびイシューのオープン／認識／クローズ時に適切に設定されたワークフローのすべての宛先に送信されます。

### ポリシーごとに1つのイシュー（デフォルト） [#preference-policy]

ポリシーとその条件に焦点が絞られた範囲がある場合は（エンティティの監視など）、 <DNT>**One issue per policy**</DNT>プリファレンスを選択します。

イシューが開かれた後に、別の条件によってアラートが発生した場合、そのアラートは同じイシューに追加されます。選択したポリシーの<DNT>**Issues &amp; activity**</DNT>ページには、1つのイシューのみが表示されます。[イシュー作成の設定](/docs/new-relic-solutions/best-practices-guides/alerts-applied-intelligence/alerts-best-practices/#issue-creation)の詳細をご覧ください。

<figcaption>
  イシュー作成の設定で<DNT>**One issue per policy**</DNT>オプション（デフォルト）を選択すると、そのポリシーのいずれかの条件によって開かれたすべてのアラートが同じイシューにグループ化されます。
</figcaption>

### 条件ごとに1つのイシュー [#preference-condition]

各インシデントレコードを特定の条件に集中させたい場合に、<DNT>**One issue per condition**</DNT>オプションを選択します。 ポリシーに複数の条件が存在する場合、各条件の別のイシューレコードが<DNT>**Issues &amp; activity**</DNT>ページに表示されます。 [イシューの作成プリファレンス](/docs/new-relic-solutions/best-practices-guides/alerts-applied-intelligence/alerts-best-practices/#issue-creation)の詳細をご覧ください。

* シグナルが条件の閾値を超えると、アラートが発生し、イシューレコードが作成されます。
* 同じシグナルが別の条件の閾値を超えると、別のアラートが発生し、別のイシューレコードが作成されます。
* イシューが開かれた後に、別のシグナルによって同じ条件でアラートが発生した場合、その条件に対してすでに作成されているイシューレコードに、そのアラートが追加されます。

<img width="40%;" class="center" title="A diagram showing how the <DNT>**One issue per condition**</DNT> option works" alt="A diagram showing how the <DNT>**One issue per condition**</DNT> option works" src="/images/alerts_diagram_by-condition.webp" />

<figcaption>
  イシュー作成の設定で<DNT>**One issue per condition**</DNT>オプションを選択すると、あらゆるシグナルによるすべてのアラートが条件ごとに1つのイシューにグループ化されます。
</figcaption>

### 条件と信号ごとのイシュー [#preference-signal]

<DNT>**One issue per condition and signal**</DNT>オプションは、最もきめ細かいレベルのイシューレコードを作成します。インフラストラクチャ全体で発生している内容を緊密に監視する場合に、このイシュープリファレンスを選択します。[イシューの作成プリファレンス](/docs/new-relic-solutions/best-practices-guides/alerts-applied-intelligence/alerts-best-practices/#issue-creation)の詳細をご覧ください。

<img width="40%;" class="center" title="A diagram showing how the <DNT>**One issue per condition and signal**</DNT> option works" alt="A diagram showing how the <DNT>**One issue per per condition and signal**</DNT> option works" src="/images/alerts_diagram_by-signal.webp" />

<figcaption>
  イシュー作成の設定で<DNT>**One issue per condition and signal**</DNT>オプションを選択すると、条件とシグナルが共通するすべてのアラートを1つのイシューにグループ化します。イシューが開かれた後に、同じシグナルによって同じ条件で別のアラートが発生した場合（警告アラートが発生し、その少し後に同じシグナルで重大なアラートが発生した場合など）、新しいアラートは同じイシューに追加されます。<DNT>**Issues &amp; activity**</DNT>ページには、選択した条件とシグナルの組み合わせごとに1つのイシューのみが表示されます。
</figcaption>
