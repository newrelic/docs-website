認証ドメイン マネージャーとして、次の手順を実行して、アカウントとメトリクス カーディナリティを管理するためのアクセスをユーザーに許可します。 ユーザーの具体的なニーズについて確認し、それに応じて設定を行ってください。 ユーザー管理の詳細については、[「ユーザー管理チュートリアル」](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/)を参照してください。

<Callout variant="important">
ユーザーがNerdGraphまたはTerraformを使用してカーディナリティバジェットを変更する必要がある場合は、[NerdGraphおよびTerraformの権限](#nerdgraph-terraform-permissions)をご覧ください。
</Callout>

<Steps>
<Step>
### カスタムロールに権限を追加する [#permissions-to-custom-role]

次の権限を持つ[新しいカスタム ロールを作成するか](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/#roles)、既存のロールに追加します。 必要なアクセス レベルをユーザーに確認してください。

* `Manage account cardinality`: アカウントのカーディナリティ バジェットを調整します。

  * `View`: アカウントのカーディナリティ予算を確認できます。
  * `Modify`：UI、NerdGraph、またはTerraformを使用して、アカウントのカーディナリティバジェットを更新できます。

* `Manage metric cardinality`: メトリクスのカーディナリティ バジェットを調整します。

  * `View`：メトリクスのカーディナリティバジェットを確認できます。
  * `Modify`：UI、NerdGraph、またはTerraformで、メトリクスのカーディナリティ予算を更新できます。

* `Manage pruning rules`: メトリクスのプルーニング ルールを管理します。

  * `View`：メトリクスの枝刈りルールを確認できます。
  * `Modify`: メトリクスのプルーニング ルールを作成および削除できます。

* `Customer limits management`: カーディナリティを含むアカウント内のさまざまな機能の制限を調整します。

  * `View`: 機能に使用可能な制限を確認できます。
  * `Modify`：NerdGraphやTerraformを使用して機能の制限を調整することはできますが、カーディナリティバジェットを調整することはできません。
</Step>

<Step>
### ユーザーロールとアカウントをグループに追加する [#group-access]

カーディナリティ管理については、次のように[新しいグループを作成する](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/#group-access)か、既存のグループを管理します。

1. **[New Relic Administration](https://one.newrelic.com/admin-portal)&gt; Access Management &gt; Groups**に移動します。
2. <DNT>**Create a new group**</DNT>をクリックするか、 <DNT>**Manage group access**</DNT>を選択して<Icon name="fe-more-horizontal" />既存のグループのメニュー。
3. 新しいグループの場合は、名前を入力して<DNT>**Create group**</DNT>をクリックします。 グループの<DNT>**Admin**</DNT>ペインが開きます。
4. <DNT>**Members**</DNT>の下にユーザーを追加します。
5. <DNT>**Account access**</DNT>の下で、カーディナリティ管理の目的のアカウントにカスタム ロールを関連付けます。
6. カーディナリティ管理に複数のアカウントが関係する場合は、 <DNT>**Account access**</DNT>の下に、グループ内の関連するアカウントごとにカスタム ロールを含めます。
</Step>
</Steps>

## NerdGraphおよびTerraformの権限 [#nerdgraph-terraform-permissions]

アカウントおよびメトリクスごとのカーディナリティ予算は、カーディナリティ管理UI、[NerdGraph](/docs/apis/nerdgraph/get-started/introduction-new-relic-nerdgraph)、または[New Relic Terraformプロバイダー](/docs/more-integrations/terraform/terraform-intro)で変更できます。NerdGraphまたはTerraformでカーディナリティ予算を変更するには、ユーザーは変更する各アカウントでその予算に対するカーディナリティ権限が必要です：

| アクション                      | NerdGraphまたはTerraformに必要な権限          |
| -------------------------- | ------------------------------------ |
| アカウントのカーディナリティバジェットを調整します。 | `Manage account cardinality: modify` |
| メトリクスごとのカーディナリティ予算を調整する    | `Manage metric cardinality: modify`  |

`Customer limits management: modify` ユーザーがNerdGraphまたはTerraformでカーディナリティ予算を変更することはできません。アカウント内の他の制限は引き続き制御されます。

NerdGraphおよびTerraformのrequestsは[ユーザーキー](/docs/apis/intro-apis/new-relic-api-keys/#user-key)を使用するため、リクエストにはそのキーを所有するユーザーの権限が適用されます。そのユーザーのロールに権限を追加し、キーが変更されるすべてのアカウントについて、そのロールをグループに追加します。

<Callout variant="important">
カーディナリティ予算を変更する際にNerdGraphまたはTerraformが`Not authorized`エラーを返す場合は、キーを所有するユーザーがそのアカウントで上記の表の権限を持っていることを確認してください。以前は`Customer limits management: modify`のみで機能していた自動化には、現在カーディナリティ権限が必要です。NerdGraphでは、`Dimensional Metric account cardinality ingested per day`および`Dimensional Metric per-metric cardinality ingested per day`という名前の制限を使用して、`dataManagementCreateAccountLimit`ミューテーションでカーディナリティ予算を変更します。
</Callout>
