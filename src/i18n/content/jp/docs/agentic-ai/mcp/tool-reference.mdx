New RelicのMCPサーバーは、AIエージェントがオブザーバビリティデータにアクセス・分析できるようにする特殊なツールを提供します。このリファレンスガイドでは、利用可能なすべてのツールをカテゴリ別に整理しています。

## MCPツールの使い方 [#how-to-use]

MCPツールは、AI開発環境において自然言語によるクエリを通じて呼び出されます。ユーザーが正確なツール名やパラメーターを覚える必要はありません。New Relicのデータについて知りたいことを具体的に説明してください。

**クエリ例：**

* 「私のアカウントにはどのようなエンティティが含まれていますか？」
* 「私のウェブアプリケーションに関する最新のアラートを表示してください」
* 「過去1時間で最も多かったエラーは何ですか？」
* 「NRQLを実行してパフォーマンスを分析してください」

開発ツールのAIエージェントは、適切なMCPツールを自動的に選択し、結果を適切な形式で出力します。

## ツールの絞り込み `include-tags` [#filter-tools]

一部のツールは、複数の関連タグが付けられているため、複数のカテゴリに表示されます（例えば、`analyze_deployment_impact`は`incident-response`と`advanced-analysis`の両方に関連しています）。

requestsに`include-tags` `HTTP`ヘッダーを送信することで、サポートされているMCPクライアントが受け取るツールを動的にフィルタリングできます。これにより、特定のツール群のみを要求することが可能になり、ツール群の削減や、問い合わせに使用されているあらゆるAIモデルの効率性や精度の向上に役立ちます。

フィルタリングに使用できるタグは、このリファレンスのカテゴリヘッダー（`discovery`、`data-access`、`alerting`、`incident-response`、`performance-analytics`、`advanced-analysis`）に直接対応しています。

### 実装例 [#example]

```json
"servers": {
    "new-relic-mcp-server": {
        "url": "https://mcp.newrelic.com/mcp/",
        "type": "http",
        "headers": {
            "include-tags": "discovery,alerting"
        }
    }
}
```

この例では、AIエージェントには、discovery（例：`get_entity`）とalerting（例：`list_alert_policies`）に分類されたツールのみが表示され、モデルが現在のタスクに最も関連性の高い機能のみに焦点を当てるようにします。

<Callout variant="important">
  **セキュリティとアクセス：**AIエージェントがここにリストされているツール（例：`get_entity`、`analyze_deployment_impact`、`execute_nrql_query`）を呼び出す場合、実行されるアクションは、セットアップ時に構成されたNew RelicユーザーのOAuthプロファイル（Antigravity CLIのAPIキー）に付与された権限によって厳密に制御されます。このツールは、New Relicのロールベースアクセス制御（RBAC）によって、該当するユーザーアカウントにアクセス権が付与されているデータ、エンティティ、およびアカウントにのみアクセスできます。OAuthプロファイルまたはAPIキーに特定のアクション（例：アラートの表示やNRQLの実行）に対する権限がない場合、ツール呼び出しは権限エラーで失敗します。
</Callout>

<Callout variant="important">
  一部のツールはOAuth認証を必要とし、APIキーでは利用できません。詳細については、[OAuth専用ツール](#oauth-only-tools)セクションをご覧ください。
</Callout>

<Callout variant="tip">
  **レート制限：**MCPサーバーは、ユーザー1人あたり1時間に最大2,000回のツール呼び出しを許可します。これらの制限は異なる場合があります。ユースケースでより高い制限が必要な場合は、[New Relicサポート](https://support.newrelic.com/s/)にお問い合わせください。
</Callout>

<Callout variant="tip">
  **請求：**ほとんどのMCPツールは、既存のCore Computeの割り当てに対して[Core Computeコンピュートユニット（CCU）](/docs/licenses/license-information/product-definitions/new-relic-one-pricing-definitions/#compute-capacity-unit)として従量課金されます。4つのAIを活用した分析ツール（`natural_language_to_nrql_query`、`generate_alert_insights_report`、`generate_user_impact_report`、`analyze_deployment_impact`）は、[Advanced Compute計算容量ユニット（aCCU）](/docs/licenses/license-information/product-definitions/new-relic-one-pricing-definitions/#compute-capacity-unit)として従量課金され、Advanced Computeアドオンが必要です。
</Callout>

## エンティティおよびアカウント管理（タグ：discovery） [#entity-account]

* `convert_time_period_to_epoch_ms`：時間範囲（例：「過去30分」）をエポックミリ秒に変換します。
* `get_dashboard`：特定のダッシュボードに関する詳細情報を取得します。
* `get_entity`：New RelicエンティティをGUIDで取得するか、名前パターンで検索します。
* `list_related_entities`：指定されたエンティティ`GUID`から1ホップ離れた（関連する）エンティティをリストします。
* `list_available_new_relic_accounts`：ユーザーが利用できるすべてのアカウント`IDs`をリストします。
* `list_dashboards`：New Relicアカウントのすべてのダッシュボードをリストします。
* `search_entity_with_tag`：特定のタグキーと値を使用してエンティティを検索します。
* `list_metric_names`：エンティティまたはアカウントによって報告された、利用可能なすべてのメトリクス名（ディメンショナルおよびレガシータイムスライス）を検出します。

## データアクセス（タグ：data-access） [#data-access]

* `execute_nrql_query`：NRDBに対してNRQLクエリを実行します。
* `natural_language_to_nrql_query`：自然言語リクエストをNRQLクエリに変換し、実行して結果を返すことにより、書き込みを実行します。

## アラートと監視（タグ：alerting） [#alerts]

* `list_alert_conditions`：特定のアラートポリシーについてアラート条件の詳細をリストします。
* `search_incident`：柔軟なフィルタリング機能を使用して、すべてのアラート（開始イベントと終了イベントの両方）を一覧表示します。
* `list_alert_policies`：指定されたアカウントのアラートポリシーを一覧表示します。必要に応じて、ポリシー名でフィルタリングできます。
* `list_recent_issues`：指定されたアカウントについて、New Relicにおけるすべての未解決の問題を一覧表示します。
* `list_synthetic_monitors`：すべての合成モニター（サービスの可用性とパフォーマンスをチェックする自動テスト）をリストします。
* `list_synthetic_monitor_results`：特定の期間内におけるモニターの個々のsyntheticチェック実行行（タイミング、エラー、ロケーション）を返します。
* `get_synthetic_check_statistics`：モニターまたはロケーション全体で、syntheticチェックの成功率、失敗数、および処理時間のパーセンタイルを集計します。

## アラートへの対応（タグ：incident-response） [#alertevents]

* `analyze_deployment_impact`：特定のエンティティにおけるデプロイメントのパフォーマンスへの影響を分析します。
* `generate_alert_insights_report`：特定の問題に関するアラートインテリジェンス分析レポートを生成します。
* `generate_user_impact_report`：特定の問題に関するエンドユーザーへの影響分析レポートを生成します。
* `list_entity_error_groups`：時間枠内でErrors Inboxから特定のエンティティのエラーグループを取得します。
* `list_change_events`：エンティティ`GUID`で識別されるアプリケーションについて、New Relicからの変更イベントの履歴を一覧表示します。
* `get_error_statistics`：`TransactionError`イベントからの集計エラー数、最初/最後に確認されたタイムスタンプ、およびオプションの時系列トレンドを計算し、エラークラス、メッセージ、アプリ、`HTTP`ステータスなどによる柔軟なフィルタリングとファセット化を行います。
* `search_errors`：メッセージ、クラス、`HTTP`ステータス、またはトレース`ID`などのフィルターに一致する生のエラーイベントを返します。

## パフォーマンス分析（タグ：Performance-analytics） [#performance]

* `analyze_entity_logs`：アプリケーションログを分析して、エラーパターン、異常な動作、および繰り返し発生する問題を特定します。
* `analyze_golden_metrics`：ゴールデンメトリクス（主要な健全性指標：スループット、レスポンスタイム、エラー率、飽和度）を分析します。
* `analyze_kafka_metrics`：Kafkaメトリクス（コンシューマーラグ、プロデューサースループット、メッセージのレイテンシ、パーティションのバランスなど）を分析します。
* `analyze_threads`：特定のエンティティのスレッドメトリクスデータ（スレッドの状態、CPU使用率、メモリ消費量など）を分析します。
* `analyze_transactions`：特定の期間内における特定のエンティティのトランザクションを分析し、処理速度が遅いトランザクションやエラーが発生しやすいトランザクションを特定します（最も遅い5％および1％のrequestsのレスポンスタイムの閾値であるP95およびP99レイテンシーメトリクスを含みます）。
* `list_garbage_collection_metrics`：指定されたアカウントとエンティティについて、ガベージコレクションとメモリメトリクスを一覧表示します。
* `list_recent_logs`：指定されたアカウントとエンティティ`GUID`について、New Relicからの最近のログを一覧表示します。
* `list_entity_performance_risk_groups`：Performance Risks Inboxから、指定期間内における特定のエンティティのパフォーマンスリスクグループを取得します。
* `get_metric_statistics`：指定されたディメンショナルまたはタイムスライスメトリクスの集計メトリクス値（平均、合計、パーセンタイル、レート）を取得します。
* `get_log_statistics`：集計ログ数、レベルと属性ごとの内訳、および時間枠にわたるトレンドを返します。
* `get_distributed_trace_details`：トレース内の特定のエンティティまたは個々のスパンの完全なスパン属性、異常、およびスパンリンクを返します。

## 高度な分析（タグ：advanced-analysis） [#advanced-analysis]

* `analyze_deployment_impact`：特定のエンティティにおけるデプロイメントのパフォーマンスへの影響を分析します。
* `generate_alert_insights_report`：特定の問題に関するアラートインテリジェンス分析レポートを生成します。
* `generate_user_impact_report`：特定の問題に関するエンドユーザーへの影響分析レポートを生成します。
* `natural_language_to_nrql_query`：自然言語によるリクエストをNRQLクエリに変換し、実行して結果を返します。

## スキル [#skills]

スキルは、複数のMCPツールを組み合わせて、一般的なオブザーバビリティのシナリオを調査および解決するのに役立つ、事前構築済みのワークフローです。スキルは[New Relic skills hubリポジトリ](https://github.com/newrelic/nr-skills-hub)でホストされています。

顧客はこれらのスキルをダウンロードし、特定のAIエージェントに合わせて構成できます。

利用可能なスキル：

| スキル                     | 説明                                  |
| ----------------------- | ----------------------------------- |
| トレースIDの検出               | 特定のリクエストまたはインシデントに関連するトレースIDを特定します。 |
| apm-error-investigation | APMエラーグループの調査をガイドします。               |
| NL2NRQL                 | 自然言語の質問を実行可能なNRQLクエリに変換します。         |

## OAuth専用ツール [#oauth-only-tools]

以下のツールはOAuth認証を必要とし、APIキーを使用する場合は利用できません。

**AIを活用した分析ツール：**これらのツールは、[Advanced 計算容量ユニット（aCCU）](/docs/licenses/license-information/product-definitions/new-relic-one-pricing-definitions/#compute-capacity-unit)として測定されます。

* `natural_language_to_nrql_query`
* `generate_alert_insights_report`
* `generate_user_impact_report`
* `analyze_deployment_impact`

**プレビューツール：**[プレビューツール](#preview-tools)を参照してください。これらにもOAuthが必要です。

## プレビューツール [#preview-tools]

以下のツールは、GAにおいてプレビュー機能として利用できます。これらは読み取り専用であり、評価目的で提供されています。価格はGA後に決定されます。

* `search_traces`：特定の期間内における特定のエンティティのトレースを検索し、処理時間、エラー数、またはバックエンド時間でランク付けします。
* `analyze_trace_anomaly`：特定のエンティティのトレースを分析して、遅延、失敗、または大量のトレースの原因となっているトランザクションまたはエラークラスを特定します。
* `analyze_service_dependencies`: 特定のエンティティのサービス依存関係を分析し、アップストリームとダウンストリームの接続をマッピングして、どれが異常であるかをフラグ付けします。
