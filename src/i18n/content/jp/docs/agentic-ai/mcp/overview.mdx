Ground Truthは、New Relicの運用インテリジェンスレイヤーです。Model Context Protocol（MCP）ツールは、AIエージェントが技術スタックをよりよく理解できるように、オブザーバビリティデータを整理するのに役立ちます。

MCPとは、AIモデルやエージェントが特定のシステムや環境に関する関連情報（コンテキスト）を取得するための標準的な方法です。このコンテキストは、AIが現状を理解し、タスクをより正確に実行し、より有用な応答を提供するのに役立ちます。MCPサーバーを使用すると、サポートされているAIエージェントは、自然言語でNew Relicデータのクエリ、調査、またはアクションを実行するのに役立つ特定のツールを呼び出すことができます。その結果、インシデント対応とパフォーマンス分析の迅速化に役立ちます。

## 潜在的なメリット

MCPサーバーは、エンジニアや運用チームに次のような具体的なメリットをもたらします。

* **直接インテグレーション：**サポートされている開発環境からNew RelicのMCPツールに直接アクセスできます。これにより、複数のAIツールを切り替える必要がなくなります。
* **トラブルシューティングの迅速化：**MCPを使用することで、AIから得られる洞察を活用し、オブザーバビリティデータからの問題の迅速な発見・修正、エラーログの分析、考えられる原因の特定が可能です。
* **運用クエリ：**AIエージェントに、アラートステータスの確認、アラートレポートの作成、またはデプロイメントがシステムに与える影響の分析を依頼します。
* **シンプルなデータクエリ：**New Relicクエリ言語（NRQL）に詳しくなくても、平易な英語で質問を作成すると、サーバーがそれをNRQLに変換して結果を取得できます。

## サポート対象のAI開発ツール [#supported-tools]

New Relic MCPは、以下のAI開発環境（サポート対象のMCPクライアント）と連携可能です。

* **Claude Code：**Claude向けのコマンドラインインターフェース
* **Antigravity CLI：**Antigravity向けのコマンドラインインターフェース
* **Kiro CLI：**Kiro向けのコマンドラインインターフェース
* **Claude Desktop：**インタラクティブなAI開発のためのデスクトップアプリケーション
* **VS Code：**MCPに対応している統合開発環境

各環境には、ワークフローの好みに応じた独自の利点があります。MCPクライアントごとの設定手順については、[セットアップガイド](/docs/agentic-ai/mcp/setup)をご覧ください。

## 前提条件 [#prerequisites]

New Relic MCPを使用するには、以下が必要です。

* New Relicアカウント（MCPはすべてのアカウントで利用可能です：すべてのデータおよびCCUユーザーはコアツールにアクセスでき、aCCUユーザーは高度なツールを含むすべてのツールにアクセスできます）
* `Node.js` のインストール（一部の認証方法で必要）
* 前述のサポートされているMCPクライアントのいずれかのインストール

### 組織アクセス [#org-access]

接続する前に、New Relicアドミニストレーターは以下の操作を行う必要があります：

**グループメンバーシップとロール**

デフォルトの組織ロール（`Organization Read Only`、`Organization Manager`、`Organization Product Admin`）またはMCPサーバーの読み取り権限がある組織スコープのカスタムロールが割り当てられたグループのメンバーである必要があります。グループに必要な権限がない場合は、`Organization Manager`または`Authentication Domain Manager`ロールを持つアドミニストレーターに連絡し、権限を付与するよう依頼してください。

**機能コントロールマネージャー**

組織のアドミニストレーターは、[機能コントロールマネージャー](/docs/accounts/accounts-billing/new-relic-one-user-management/feature-control-manager/)を介してMCPアクセスを有効にする必要があります。以下のトグルでMCPアクセスを制御します。**New Relic MCP Server**と**Local Clients**は、デフォルトで有効になっています。その他のすべてのサブトグルはデフォルトで無効になっており、必要に応じてNew Relicのアドミニストレーターが有効にすることができます。

* **New Relic MCP Server**：MCPのセットアップに必要です。MCPアクセスを機能させるためにオンにする必要があるメイントグルです。
* **Local Clients**：ローカルクライアント接続（Claude Code、Claude Desktop、VS Code、Kiro）に必要です。
* **APIキー**：自動化スクリプトを含む、APIキー接続に必要です。
* **プレビューツール**：MCPプレビュー（非GA）ツールにアクセスする場合に必要です。
* **Atlassian**：Atlassianインテグレーションに必要です
* **AWS**：AWSインテグレーションに必要です。

### 認証オプション [#auth-options]

* **OAuth（推奨）**：New Relicは事前設定済みのOAuthエンドポイントを提供しています。

  * クライアントID： `pUWGgnjsQ0bydqCbavTPpw==`
  * 認証URL： `https://oauth2.service.newrelic.com/oauth2/auth`
  * トークンURL： `https://oauth2.service.newrelic.com/oauth2/token`
  * スコープ： `["observability:read", "offline", "offline_access"]`

* **ユーザーAPIキー**：**一部のMCPツールはOAuth経由でのみアクセス可能**であることに注意してください。

  1. New Relicにログインしてください
  2. **ユーザーメニュー -&gt; API keys**を選択します。
  3. 新しいユーザーキーを作成するか、既存のユーザーキーをコピーします。
  4. キーの形式：`NRAK-XXXXXXXXXXXXXXXXXXXXX`。

<Callout variant="important">
  一部のツールはOAuth経由でのみアクセス可能であり、APIキーを使用する場合は利用できません。これらには、AIを活用した分析ツール（`natural_language_to_nrql_query`、`generate_alert_insights_report`、`generate_user_impact_report`、`analyze_deployment_impact`）およびプレビューツール（`search_traces`、`analyze_trace_anomaly`、`analyze_service_dependencies`）が含まれます。詳細については、[ツールリファレンス](/docs/agentic-ai/mcp/tool-reference)を参照してください。
</Callout>

## 次のステップ [#next-steps]

サポートされているMCPクライアントをNew Relicのオブザーバビリティデータに接続する準備はよろしいですか？

1. [サポート対象の環境](#supported-tools)から、サポート対象のMCPクライアントを選択します。
2. 設定手順については、[セットアップガイド](/docs/agentic-ai/mcp/setup)をご覧ください。
3. 利用可能なツールについては、[ツールリファレンス](/docs/agentic-ai/mcp/tool-reference)をご覧ください。
4. 自然言語を使ってNew Relicのデータを照会できます。
5. [一般的な問題のトラブルシューティングを行います](/docs/agentic-ai/mcp/troubleshoot)。
