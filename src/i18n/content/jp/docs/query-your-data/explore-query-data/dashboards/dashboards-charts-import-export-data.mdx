[ダッシュボードを](/docs/query-your-data/explore-query-data/dashboards/introduction-dashboards/)使用すると、システムの健全性を視覚化して追跡し、問題に対処し、さらなるステップを計画することができます。 さまざまなインポートおよびエクスポート オプションを使用して、すべての情報をチーム、顧客、その他の関係者と共有する方法を学びます。

## ダッシュボードをインポートする [#import-json]

別のアカウントに移動したり、コードレベルで変更したりするには、ダッシュボードをJSONからインポートします。たとえば、ベースのダッシュボードのJSONで2つの既存のダッシュボードを結合することで、カスタムダッシュボードを作成できます。JSONを取得するには、[ダッシュボードをダウンロード](#export-dashboards-pdf)してください。

<DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Dashboards**</DNT>から、<DNT>**Import dashboard**</DNT>アクションを使用し、JSONを貼り付けます。インポート時にアカウントと権限を選択します。後からアカウントを変更することはできませんが、[権限はいつでも変更](/docs/query-your-data/explore-query-data/dashboards/manage-your-dashboard/#dash-settings)できます。インポートにはターゲットアカウントでダッシュボードを作成する権限が必要であり、アクセスできないアカウントをクエリするウィジェットは表示されません。

<Callout title="注記">
インポートされたダッシュボードはコピーです。元のダッシュボードと同期されないため、後からの変更は編集したダッシュボードにのみ適用されます。
</Callout>

## ダッシュボードのエクスポート [#export-dashboards]

### JSON、PDF、またはPNGとしてダウンロード [#export-dashboards-pdf]

ダッシュボードを以下のいずれかの形式で保存するには、ダッシュボードの<DNT>**...**</DNT>メニューの<DNT>**Download dashboard**</DNT>アクションを使用します：

* **JSON**：ダッシュボードを別のアカウントに移動したり、Terraformなどでコードとして管理したりします。JSONをダウンロードするか、クリップボードにコピーできます。エンティティのGUIDをエクスポートするかどうかにかかわらず、JSONには各ウィジェットのNRQLクエリとアカウントIDが含まれます。
* **PDFおよびPNG**：先週の売上やインシデント中に影響を受けたユーザーなど、ダッシュボードの静的スナップショットをメール、Confluenceページ、またはSlackで共有します。幅と高さをピクセル単位で設定します。どちらもデフォルトは1920×1080です。

UI経由でダッシュボードをPDFまたはPNGとしてエクスポートする場合、New Relicは[カスタムビジュアライゼーション](/docs/query-your-data/explore-query-data/dashboards/add-custom-visualizations-your-dashboards/)をサポートしていません。

### NerdGraph経由でダッシュボードをエクスポートする [#export-api]

テンプレート変数のオーバーライドやエンティティフィルターなど、UIでは提供されていないオプションを使用してプログラムでダッシュボードをエクスポートするには、[NerdGraphチュートリアル：ダッシュボードとチャートをファイルとしてエクスポートする](/docs/apis/nerdgraph/examples/export-dashboards-pdfpng-using-api/#api-dashboard-snapshot)を参照してください。

## チャートのエクスポート [#export-charts]

### CSVとしてエクスポート [#export-charts-csv]

<DNT>**Export as CSV**</DNT>チャートアクションを使用して、テーブルチャートのデータをCSVファイルとしてエクスポートします。

<img title="Export chart as CSV" alt="Screenshot of how to export a table chart as a CSV file" src="/images/dashboards_screenshot-crop_export-csv.webp" />

### チャートのデータをJSONとして取得 [#export-charts-json]

チャートの生のクエリ応答をJSONとして取得するには、チャートの<DNT>**...**</DNT>メニューから<DNT>**View query**</DNT>を開き、クエリを実行して、チャートタイプをJSONに設定します。そこから応答をコピーできます。これはクエリの出力であり、チャートの設定ではありません。

### 画像またはリンクとしてチャートを取得する [#chart-image-link]

ダッシュボードの外部でチャートを共有するには、次の2つの方法のいずれかを使用します：

* **Get as image \[画像として取得]**：チャートのPNGへのリンクをコピーします。リンクは90日後に期限切れになります。
* **Get chart link \[チャートリンクを取得]**：New Relicアカウントがなくても誰でも表示できるライブチャートURLを作成します。`Live Url (individual) > Modify`権限が必要です。[チャートの共有](/docs/query-your-data/explore-query-data/dashboards/share-charts-publicly/#share-chart)をご覧ください。

NerdGraphを使用してチャートリンクを作成、一覧表示、および取り消す方法については、[NerdGraphチュートリアル：公開共有チャートURLの作成、一覧表示、および取り消し](/docs/apis/nerdgraph/examples/manage-live-chart-urls-via-api/)をご覧ください。

### NerdGraph経由でチャートをエクスポートする [#export-charts-api]

プログラムでチャート画像を生成する方法については、[NerdGraphチュートリアル：ダッシュボードとチャートをファイルとしてエクスポートする](/docs/apis/nerdgraph/examples/export-dashboards-pdfpng-using-api/#api-widget-snapshot)をご覧ください。
