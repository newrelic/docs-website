<DNT>**Vulnerability Identifier:**</DNT> NR26-13

<DNT>**Priority:**</DNT> 高

## 概要

2026年10月17日～2026年10月20日の間に、研究者はeMudhraによって発行された8つの中間認証局（CA）証明書の秘密鍵が復元可能であることを公表しました（CVE-2026-111943）。これらの鍵を持つ者は誰でも、ソフトウェアがまだそれらを信頼している場合、本物として受け入れられる証明書を作成できます。ブラウザおよびOSはこれらの証明書をブロックしていますが、一部のコンテナイメージなど、独自の信頼されたCAリストを保持するソフトウェアは更新する必要があります。

New Relicは、これらのCAによって発行された証明書を今後受け入れないように、以下のログコンポーネントを更新しました。更新されたバージョンは自動的には反映されません。顧客は、以下に記載されているバージョンにアップグレードする必要があります。

## 技術的な脆弱性情報

[CVE-2026-111943](https://www.cve.org/CVERecord?id=CVE-2026-111943)

emSign ECC Root CA - G3にチェーンされ、クロス署名を通じてAAA Certificate Servicesにチェーンされている8つの中間CAが影響を受けます。

* プラグインはGo 1.27.3でビルドされており、そのTLSライブラリは、ルートが引き続き信頼されている場合でも、影響を受ける8つのキーを含む証明書チェーンを拒否します。
* Fluent Bit 5.1.5のベースイメージでは、影響を受けるルートがCAバンドルから削除されています。
