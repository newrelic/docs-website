ニューレリックは、お客様とお客様のデータのセキュリティを重視しています。コーディネイテッド・ディスクロージャー・プログラムを通じてセキュリティ研究者と関わることは、私たちのセキュリティ目標を達成するための重要な手段であると考えています。

当社の製品またはWebサイトでセキュリティの脆弱性を発見したと思われる場合は、本書で説明されている当社の協調的な開示プログラムを通じてご報告いただくことを歓迎し、感謝いたします。その他の懸念事項がある場合は、[顧客のセキュリティ問題](#customer-issues)に関する情報をご覧ください。

## 調整された開示プログラム [#coordinated_disclosure_program]

New Relic は、確立されたバグ報奨金プラットフォームと提携して、研究者がセキュリティの脆弱性をできるだけ簡単に報告できるようにしています。 これらの問題を発見するために必要な労力を認識し、対象となるレポートに対して報奨金を提供する場合があります。

New Relic は、協調開示プログラムを BugCrowd に正式に移行しました。

コーディネートされた情報開示プログラムに参加するために

1. セキュリティ テストを開始する前に、Bugcrowd Researcher の利用規約に同意し、 [Bugcrowd のポリシー](https://bugcrowd.com/engagements/newrelic-mbb-og-public)を理解してそれに従う必要があります。
2. New Relic許可されたテスト活動にのみ、適用される 利用規約 に従って使用できる[ ](https://newrelic.com/termsandconditions/terms)アカウントを作成するように求められます。

## 脆弱性報告およびCVEの影響 [#vulnerability_reports_and_cve_impact]

New Relicが使用する脆弱性スキャンツールは、誤検知を減らすために当社の環境に合わせて調整されています。このため、当社のスキャンツールと、別のスキャンレポートで報告された脆弱性との間に差異が生じる場合があります。スキャンレポートの評価についてサポートが必要な場合は、New Relicの[Support Portal \[サポートポータル\]](https://support.newrelic.com/s/)からサポートケースを作成し、エージェントのバージョン、スキャンがどのように実施されたかの詳細な説明、使用したスキャンツール、特別な設定の考慮事項、および正確なレポート出力を記載してください。

顧客の安全を守ることは、New Relicの最優先事項です。当社のエージェントで影響を受ける重大なCVEに関する最新の報告については、New Relicのセキュリティ速報をご覧いただき、[New Relicのセキュリティ通知コミュニティチャンネルまたはRSSフィードの購読](/docs/security/security-privacy/information-security/security-bulletins/)をご検討ください。

## お客様のセキュリティ問題 [#customer-issues]

New Relicの顧客であり、パスワード、APIキー、またはアカウントの問題を含め、サービスに関するセキュリティやその他の懸念がある場合は、当社の協調的開示プログラムを使用しないでください。代わりに、[パスワード、メール、ログインの問題](/docs/accounts/accounts-billing/account-setup/troubleshoot-new-relics-password-email-address-login-problems/)に関する当社の標準のトラブルシューティング手順に従うか、New Relic [Support Portal \[サポートポータル\]](https://support.newrelic.com/s/)を通じてセキュリティサポートケースを作成してください。
