最新のKubernetes環境は、複雑な**マルチクラスタ フリート**に進化しましたが、従来の観察ツールでは、多くの場合、個々のクラスタの分割されたサイロ化されたビューしか提供されません。 この Kubernetes クロスクラスター UI は、このマルチクラスターの複雑さをフリート全体の明確さに変換する統合コマンド センターを提供します。

この統合ビューは、プラットフォーム エンジニアと SRE が次のことを実行するのに役立ちます。

* New RelicエージェントまたはOpenTelemetryによる**クラスタモニターと互換性のある単一ダッシュボード上でフリート全体の監視を統合します**。
* ガイド付きトリアージ ワークフローを使用して**根本原因分析を加速します**。
* 艦隊全体で無駄なリソースを特定することで**コストを削減します**。
* セルフサービスのためのアプリケーション中心のビューで**開発者を支援します**。

## 新しいUIにアクセスする [#access]

New Relic プラットフォームの左側のナビゲーションにある Kubernetes オプションから、新しい Kubernetes クロスクラスター UI にアクセスできます。

Kubernetes クロスクラスター UI にアクセスするには:

1. に行く <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Kubernetes**</DNT>
2. ページの右上隅にある**Try it out** \[試してみる]ボタンをクリックします。

## スコアカードとテーブル [#scorecards]

スコアカードはフリート全体の各メトリクスを要約し、内訳テーブルはクラスタ、ノード、またはワークロードごとに値を分類します。値が[重大度の閾値](#tab)に達すると、スコアカードとテーブルの行の両方がオレンジ色（警告）または赤色（クリティカル）に変わります。`2/436`などの比率は、そのパーセンテージに基づいて色が変わります。

* スコアカードと折れ線グラフを更新するには、**`avg`**、**`p95`**、**`p99`**、または**`max`**を選択します。内訳テーブルには常に平均値が表示されます。
* **Include healthy entities**\[健全なエンティティを含める] を無効にして、アクティブなオレンジ色または赤色のステータス閾値を持つエンティティにリストをフィルタリングします。
* レポートを停止したエンティティはリストに残り、選択した時間範囲の履歴データが表示されます。

## トリアージのためのドリルダウン機能 [#drill-down]

フリート全体のメトリクスから個々のエンティティへと移行するガイド付きトリアージ・ワークフローを使用して、クロス・クラスタUIで根本原因分析を迅速化できます：

* **スコアカードからエンティティのランキングへ：**スコアカードを選択して、そのメトリクスにより重大度の降順でテーブルを並べ替え、上位10個のエンティティを折れ線グラフにプロットします
* **表のメトリクスからKubernetesナビゲーターへ：** メトリクスの値の上にマウスポインターを置いてエンティティのトレンドラインを表示し、<DNT>**View in navigator**</DNT>を選択して[Kubernetesナビゲーター](/docs/kubernetes-pixie/kubernetes-integration/understand-use-data/kubernetes-cluster-explorer/#navigator-preview)を開きます。
* **エンティティから詳細へ：**エンティティ名にカーソルを合わせてそのゴールデンメトリクスと関連するエンティティを表示するか、クリックして概要ページを開きます。
