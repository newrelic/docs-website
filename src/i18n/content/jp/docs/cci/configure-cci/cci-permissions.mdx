<Callout variant="important">
<DNT>Cloud Cost Intelligence</DNT>にアクセスするには、**Advanced CCU SKU**、**フルプラットフォームユーザー**ライセンス、および[Feature Control Manager \[機能コントロールマネージャー\]](/docs/accounts/accounts-billing/new-relic-one-user-management/feature-control-manager/)を通じて有効化されたアクセスが必要です。このページでは、設定アクセス — 製品が組織で有効になった後に誰がCCI設定を変更できるか — について説明します。
</Callout>

当社の標準的な認可システムは、<DNT>Cloud Cost Intelligence</DNT>のサーフェス（<DNT>Settings</DNT>、<DNT>Integrations</DNT>、および<DNT>Custom Facets</DNT>）へのアクセスを制御します。組織全体ではなくアカウントごとに、アクセスを読み取り（設定の表示）と書き込み（作成、更新、削除）に分割します。

## デフォルトアクセス [#default-access]

アカウントアクセス権を持つすべてのユーザーには、デフォルトで閲覧専用アクセス権が付与されます。

自身、他の個別のユーザー、またはロールに対して、変更または削除のアクセス権を付与できるのは <DNT>Organization Admin</DNT> のみです。

## アクセス権限リファレンス [#permissions-reference]

以下の表に、各CCIサーフェスで利用可能な権限を示します。デフォルトで、すべてのユーザーに読み取りアクセスが付与されます。Modify \[変更] および Delete \[削除] アクセスには、[カスタムロール](#grant-modify-access)が必要です。

| CCIサーフェス                 | Read \[読み取り]   | 変更            | 削除            |
| ------------------------ | -------------- | ------------- | ------------- |
| <DNT>Custom Facets</DNT> | すべてのユーザーのデフォルト | カスタムロールが必要です。 | カスタムロールが必要です。 |
| <DNT>Integrations</DNT>  | すべてのユーザーのデフォルト | カスタムロールが必要です。 | —             |
| <DNT>Settings</DNT>      | すべてのユーザーのデフォルト | カスタムロールが必要です。 | —             |

## 変更アクセス権を付与 [#grant-modify-access]

<DNT>Organization Admin</DNT>は、[カスタムロール](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/#roles)を通じてCCI書き込みアクセス権を付与します。利用可能なオプションは、以下の2つです：

### 既存のカスタムロールにCCI権限を追加する [#option-existing-role]

チームのカスタムロール（たとえば「FinOps」ロール）がすでに存在する場合は、そのロールにCCIの書き込み権限を追加してください。そのロールがすでに割り当てられているすべてのユーザーは、自動的にCCIの書き込みアクセス権を取得します。個別のユーザーを再割り当てする必要はありません。

### CCI専用のカスタムロールを作成してください [#option-new-role]

CCI の変更権限（<DNT>Settings</DNT>、<DNT>Integrations</DNT>、<DNT>Custom Facets</DNT>）のみを含むカスタムロールを作成し、必要とする特定のユーザー、グループ、またはご自身に割り当ててください。CCI の管理を他のロールの責務から分離しておくには、このオプションを使用してください。
