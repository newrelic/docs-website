<Callout variant="important">
To access <DNT>Cloud Cost Intelligence</DNT>, you need an **Advanced CCU SKU**, a **full platform user** license, and access enabled through [Feature Control Manager](/docs/accounts/accounts-billing/new-relic-one-user-management/feature-control-manager/). This page covers configuration access — who can modify CCI settings once the product is enabled for your organization.
</Callout>

Our standard authorization system controls access to <DNT>Cloud Cost Intelligence</DNT> surfaces (<DNT>Settings</DNT>, <DNT>Integrations</DNT>, and <DNT>Custom Facets</DNT>). It splits access into read (view configuration) and write (create, update, delete), per account, not organization-wide.

## デフォルトアクセス [#default-access]

アカウントアクセス権を持つすべてのユーザーには、デフォルトで閲覧専用アクセス権が付与されます。

Only an <DNT>Organization Admin</DNT> can grant modify or delete access — to themselves, to other individual users, or to a role.

## Permissions reference [#permissions-reference]

The following table lists the available permissions for each CCI surface. All users receive read access by default. Modify and Delete access require a [custom role](#grant-modify-access).

| CCI surface              | Read                  | Modify               | 削除                   |
| ------------------------ | --------------------- | -------------------- | -------------------- |
| <DNT>Custom Facets</DNT> | Default for all users | Requires custom role | Requires custom role |
| <DNT>Integrations</DNT>  | Default for all users | Requires custom role | —                    |
| <DNT>Settings</DNT>      | Default for all users | Requires custom role | —                    |

## 変更アクセス権を付与 [#grant-modify-access]

<DNT>Organization Admin</DNT>は、[カスタムロール](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/#roles)を通じてCCI書き込みアクセス権を付与します。利用可能なオプションは、以下の2つです：

### Add CCI permissions to an existing custom role [#option-existing-role]

If a custom role already exists for a team (for example, a &quot;FinOps&quot; role), add the CCI write permissions to it. Everyone already assigned that role automatically gains CCI write access. You don&apos;t need to reassign individual users.

### Create a dedicated custom role for CCI [#option-new-role]

Create a custom role containing only the CCI modify permissions (<DNT>Settings</DNT>, <DNT>Integrations</DNT>, <DNT>Custom Facets</DNT>), then assign it to the specific users, groups, or yourself who need it. Use this option to keep CCI administration separate from any other role&apos;s responsibilities.
