## Cloud Cost Intelligenceに「過去48時間のコストデータは利用できません」と表示されるのはなぜですか。 [#48-hour-buffer]

Cloud Cost Intelligenceは、選択された時間範囲に48時間のデータバッファを適用します。CCIダッシュボードを開くと、CCIは選択された時間範囲が48時間前に終了するように自動的に調整し、この通知を表示します：

> 過去48時間のコストデータは利用できません。選択した時間範囲が48時間前に終了するように調整しました。

これは想定されたプラットフォームの動作であり、サポートされているすべてのcloudプロバイダー（AWS、Azure、およびGCP）に一律に適用されます。ご利用のcloudプロバイダーのコストエクスポートがどれほど早く完了するかに関係なく、CCIはプラットフォームレベルでこのバッファを適用します。ご利用のプロバイダーのエクスポートがより早く完了した場合でも、CCIは引き続き、表示可能な時間範囲が48時間前で終了するように制限します。

## 現在プレビュー中の機能にアクセスするにはどうすればよいですか。 [#preview-access]

FinOpsエージェントやCCIアラートなどの一部のCCI機能は、プレビュー機能として利用できます。それらを有効にするには：

1. New Relic のアカウントにログインします。

2. 左下にある**ユーザープロファイル**アイコンを選択します。

3. **Administration &gt; Previews and Trials**に移動します。

4. 有効にする機能を見つけます：

   * **FinOpsエージェントプレビュー：**自然言語によるコストクエリとcloud支出分析を有効にするには、これをオンにします。
   * **CCIアラートプレビュー：** これをオンにすると、CCIエコシステム内で直接アラートを作成および管理できます。

5. Ask AIインターフェースに反映された新しい機能を表示するには、ブラウザを再読み込みしてください。
