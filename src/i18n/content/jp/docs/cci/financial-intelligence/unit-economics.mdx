Cloud Cost Intelligenceは、**AWS**や**EC2**の総コストなど、cloudの支出を概要として表示します。そのビューでは、*いくら*支出したかはわかりますが、サービスから1単位の価値を提供するのにかかるコストはわかりません。

ユニットエコノミクスは、そのギャップを埋めます。これは、**クエリあたりのコスト**: 1つのクエリを実行するのにビジネスにどれくらいのコストがかかるかといったビジネスメトリクスを測定します。コストが上昇した場合、ユニットメトリクスは2つのまったく異なる状況の違いを区別するのに役立ちます：

* **成長**: より多くのユーザーにサービスを提供したか、より多くのクエリを実行したため、コストが上昇しました。これは通常、ビジネスの成長を反映しています。
* **無駄**：作業量は変わらないのにコストが上昇しており、調査すべき非効率性があることを示しています。

## ユニットメトリクスを作成 [#create-unit-metric]

効率を追跡するには、cloudの支出をクエリやトランザクションなどのビジネスイベントに結び付けるユニットメトリクスを作成します。

1. <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Cloud Cost Intelligence**</DNT>に移動します。
2. <DNT>**Create unit cost**</DNT>をクリックして、cloudの支出をクエリなどのビジネス価値の単位に結び付けるユニットメトリクスを設定します。
3. <DNT>**Define New Unit Cost**</DNT>セクションで、次のフィールドに入力します。

## コストと使用量の定義 [#define-cost-usage]

Cloud Cost Intelligenceは、ある値を別の値で割ることでユニットコストを計算します。これら2つの部分を並べて定義します：

* <DNT>**Cost Definition**</DNT>: 支出など、測定したいコストメトリクス。
* <DNT>**Usage Definition**</DNT>：クエリ数など、測定したいビジネスメトリクス。

<Callout variant="tip">
  2つのパネルの間にある切り替えボタンを使用して、分子と分母を入れ替えます。切り替えると、パネルのヘッダーが更新され、どちらの部分が<DNT>**Value Unit (Numerator)**</DNT>で、どちらが<DNT>**Cost (Denominator)**</DNT>であるかが表示されます。これにより、ユニットあたりのコスト（例：クエリあたりのコスト）またはコストあたりのユニット数（例：特定のコストに対して提供されたクエリ数）のいずれかを測定できます。
</Callout>

### コストの定義 [#cost-definition]

<DNT>**Filters**</DNT>タブまたは<DNT>**NRQL**</DNT>タブを使用して、コストメトリクスを定義します。

<DNT>**Filters**</DNT>

1. <DNT>**Configure Filters**</DNT>をクリックして、フィルターソースを選択します：

   * <DNT>**Cost overview**</DNT>：アカウント、サービス、リージョンなどのcloudプロバイダーのディメンションでフィルタリングします。
   * <DNT>**Kubernetes**</DNT>: クラスタ、コンテナ、デプロイメントなどのKubernetesディメンションでフィルタリングします。

2. <DNT>**Validate &amp; Calculate Spend**</DNT>をクリックして、選択した日付範囲の一致する支出を計算します。

3. <DNT>**Matched Spend**</DNT>の値は、フィルタの月間支出を示します。<DNT>**Preview Spend**</DNT>をクリックして結果を確認します。

<DNT>**NRQL**</DNT>

フィルターの代わりにNRQLクエリを使用してコストメトリクスを定義するには、<DNT>**NRQL**</DNT>タブを使用します。

## 分子と分母 [#numerator-denominator]

<DNT>**Dynamic Unit Cost Calculation**</DNT>パネルには、メトリクスを構築する際のライブ結果が表示されます。分子を分母で割って、<DNT>**Resulting Metric**</DNT>を算出します。たとえば、総コストをクエリの総数で割ると、クエリあたりのコストが算出されます。

結果が正しいと思われる場合は、<DNT>**Confirm**</DNT>をクリックしてユニットコストを保存するか、<DNT>**Discard changes**</DNT>をクリックして破棄します。

## 結果を見る [#view-results]

ユニットコストを作成すると、グリッドビューに、作成したすべてのユニットメトリクス（たとえば、<DNT>**Cost per Transaction**</DNT>、<DNT>**Kubernetes Cost per Pod**</DNT>、<DNT>**CCI Cost per query**</DNT>）が表示されます。

ユニットメトリクスで<DNT>**Details &gt;**</DNT>をクリックして、以下を含む詳細ビューを開きます：

* **サマリーメトリクス**：<DNT>**Unit Cost**</DNT>、<DNT>**Total Spend**</DNT>（分子）、分母のボリューム（例：<DNT>**Transaction Volume**</DNT>）、および<DNT>**Efficiency Score**</DNT>。各メトリクスは、前の期間と比較した変化率を示します。効率スコアは、ベンチマークデータが利用可能な場合にのみ値を示します。
* <DNT>**Unit Cost Trend**</DNT>: 選択した時間範囲における総支出と単位コストをプロットするチャート。
* <DNT>**Cost Contribution to Unit Cost**</DNT>：1日あたりの総コストの割合を示すチャート。<DNT>**Group by**</DNT>ドロップダウンを使用して、アカウントなどのディメンション別にコントリビューションを分類します。
* <DNT>**Definition**</DNT>：メトリクスを定義する<DNT>**Cost Definition**</DNT>および<DNT>**Usage Definition**</DNT>のクエリ。
* <DNT>**Metadata**</DNT>：メトリクスの作成者、作成日時と最終更新日時、ステータス、単位などの詳細。

たとえば、結果をcloudプロバイダーなどでグループ化して、単位コストがディメンション全体でどのように分類されるかを確認できます。
