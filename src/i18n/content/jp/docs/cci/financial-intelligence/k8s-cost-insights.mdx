<DNT>**Kubernetes Costs**</DNT>ページには、各Kubernetesクラスタのコストが、CPU、メモリ、未使用リソース、未割り当てリソースに分類して表示されます。New RelicのKubernetesテレメトリーデータを使用して、cloudの請求とクラスタレベルの使用量を関連付けるため、どこに支出されているか、どこでコストを削減できるかを確認できます。

<img title="Kubernetes Cost Insights highlighted on the Cloud Cost Intelligence Kubernetes Cost Insights page" alt="Kubernetes Cost Insights highlighted on the Cloud Cost Intelligence Kubernetes Cost Insights page" src="/images/k8s-cci.webp" />

## 前提条件 [#prerequisites]

<DNT>**Kubernetes Costs**</DNT>ページにデータを表示するには、Kubernetesテレメトリーを保持するNew Relicアカウントを追加する必要があります。CCIは、これらのアカウントからの`K8sContainerSample`イベントを使用し、インスタンスIDに基づいてcloudの請求データと結合します。この手順をスキップすると、CCIにcloudのコストは表示されても、Kubernetesのコストは表示されない場合があります。

これらのアカウントを追加するには、次の手順を実行してください：

1. <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Cloud Cost Intelligence &gt; Settings &gt; Telemetry Accounts**</DNT>に移動します。

2. <DNT>**Accounts**</DNT>ドロップダウンから、`K8sContainerSample`データを持つすべてのNew Relicアカウントを選択します。アカウントを確認するには、そのアカウントで次のクエリを実行します：

   ```sql
   SELECT count(*) FROM K8sContainerSample SINCE 1 day ago
   ```

3. <DNT>**Apply**</DNT>をクリックします。

アカウントを追加すると、CCIは`K8sContainerSample`データを取得し、Kubernetesのコストの割り当てを開始します。

<Callout variant="important">
Kubernetesクラスタが複数のNew Relicアカウントにレポートしている場合は、それぞれを追加してください。追加していないアカウントのクラスタからのコストは、<DNT>**Kubernetes Costs**</DNT>ページに表示されません。
</Callout>

適切なアカウントを追加してもKubernetesのコストが表示されない場合は、[トラブルシューティング](#troubleshoot)をご覧ください。

## フィルターとカスタマイズ

### クラウドプロバイダーフィルター

コストデータをcloudプロバイダーでフィルタリングするには、ページ左上のドロップダウンメニューからオプションを選択します：

* <DNT>**All**</DNT>: すべてのcloudプロバイダー
* <DNT>**AWS**</DNT>: Amazon Web Servicesのみ
* <DNT>**Azure**</DNT>: Microsoft Azureのみ

### 日付範囲セレクター

ページの右上にある日付範囲セレクタを使用して、以下のいずれかを行います：

* 事前定義された期間を選択
* カスタムの開始日と終了日を設定する
* 優先タイムゾーンでコストを表示します（デフォルトではUTCが表示されます）

### エンジニアリングコストフィルター

組織でコスト配分タグを使用している場合、<DNT>**Engineering costs**</DNT>タグでフィルタリングして、cloud環境でタグ付けされた特定のチーム、プロジェクト、またはコストセンターに分析を絞り込むことができます。

## 概要

Summary \[概要] セクションには、選択した期間の4つのコストメトリクスが表示されます：

| メトリック                               | 説明                                      |
| ----------------------------------- | --------------------------------------- |
| <DNT>**Total cost**</DNT>           | すべてのKubernetesクラスタの総支出と、前の期間と比較した変化率    |
| <DNT>**Average cost (Daily)**</DNT> | 1日あたりの平均支出と変化率                          |
| <DNT>**Unused cost**</DNT>          | クラスタが割り当てたがrequestsを受信していないリソースのコストと変化率 |
| <DNT>**Unallocated cost**</DNT>     | どのソースにも割り当てられていないクラスタリソースのコストと変化率       |

## インサイト

Insightsセクションでは、Kubernetesのコストを分析するのに役立つ2つの可視化ウィジェットを提供しています。

### コスト動向

<DNT>**Cost Trends**</DNT>ウィジェットは、経時的なKubernetesコストの変化を示す折れ線グラフを表示します。ビューオプションを使用して、<DNT>**Hourly**</DNT>、<DNT>**Daily**</DNT>、<DNT>**Weekly**</DNT>、または<DNT>**Monthly**</DNT>ビューを切り替えます。

### トップ 20

<DNT>**Top 20**</DNT>ウィジェットは、ツリーチャートの視覚化を使用して、最もコストの高い領域を表示します。デフォルトでは、コストが最も高い上位20のクラスタが表示されます。以下のオプションを使用してビューをカスタマイズできます：

* <DNT>**Dropdown filter**</DNT>: 表示する内容（<DNT>**Cluster name, by cost**</DNT>）を選択します
* <DNT>**Group by**</DNT>：コストデータをグループ化するディメンションを選択します
* <DNT>**View by**</DNT>: <DNT>**Tree chart**</DNT>と他のビジュアル形式を切り替える

## コストと使用状況分析

<DNT>**Cost &amp; Usage Analysis**</DNT>セクションには、クラスタ名別のリソース使用量とコストの内訳を示す表が表示されます：

| カラム                             | 説明                                     |
| ------------------------------- | -------------------------------------- |
| <DNT>**Cluster name**</DNT>     | Kubernetesクラスタの名前                      |
| <DNT>**CPU cost**</DNT>         | 各クラスタのCPU使用量に属性付けられたコスト                |
| <DNT>**CPU usage**</DNT>        | 各クラスタが消費したCPUリソースの割合                   |
| <DNT>**Memory cost**</DNT>      | 各クラスタのメモリ使用量に関連するコスト                   |
| <DNT>**Memory usage**</DNT>     | 各クラスタが使用したメモリリソースの割合                   |
| <DNT>**Unused cost**</DNT>      | クラスタが割り当てているが、requestsを受信していないリソースのコスト |
| <DNT>**Unallocated cost**</DNT> | どのソースにも割り当てられていないクラスタリソースのコスト          |
| <DNT>**Total cost**</DNT>       | すべてのリソース使用量にわたる各クラスタの合計コスト（並べ替え可能）     |

クラスタの未使用または未割り当てのコストが常に高い場合、オーバープロビジョニングされている可能性があります。cloud環境全体で支出を削減する方法については、[コスト最適化の推奨事項](/docs/cci/financial-intelligence/cci-recommendations)をご覧ください。

## 未使用コストと未割り当てコストの比較

これらのコスト ディメンションは、クラスターの効率を測定するのに役立ちます。

| コストタイプ | 定義                                  | 例                                                  |
| ------ | ----------------------------------- | -------------------------------------------------- |
| 未使用コスト | クラスタが割り当てているが、requestsを受信していないリソース。 | 合計コスト：$ 5.60、使用済み：$ 4.64、未使用コスト：$ 0.96             |
| 未配分コスト | どのソースにも割り当てられていないClusterリソース。       | ノードコスト：$ 10.00、ワークロードへの割り当て：$ 7.50、未割り当てコスト：$ 2.50 |

<Callout variant="tip">
任意のクラスタを選択して、その<DNT>**Cost Trends**</DNT>、<DNT>**Cost Breakdown (Total vs Used)**</DNT>、および未使用および未割り当てのコストに関する情報を表示します。
</Callout>

## トラブルシューティング [#troubleshoot]

### AWSのコストは表示されるが、Kubernetesのコストが表示されない

テレメトリーアカウントがまだ追加されていないか、一部しか追加されていません。[前提条件](#prerequisites)をご覧ください。

### 一部のクラスタがページに表示されていません

Kubernetesクラスタが複数のNew Relicアカウントにレポートしている可能性があります。<DNT>**Settings &gt; Telemetry data**</DNT>の下にすべてのレポートアカウントを追加したことを確認してください。

### 適切なアカウントを追加したが、コストがまだ表示されない

New Relicの顧客ケアにお問い合わせください。

CCIのセットアップ、インテグレーション、または権限に関する問題については、[Cloud Cost Intelligenceセットアップのトラブルシューティング](/docs/cci/troubleshooting/troubleshooting)をご覧ください。
