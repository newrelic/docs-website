このページでは、ワークフロー自動化アクションカタログで利用できるすべてのNew Relic Ingestアクションのリファレンスを提供します。これらのアクションを使用すると、ワークフローからNew Relicにイベント、ログ、メトリクスを送信できます。

## 前提条件

ワークフロー自動化でNew Relic Ingestアクションを使用する前に、以下が用意されていることを確認してください：

* 適切な権限を持つ New Relic アカウント。
* New Relicライセンスキー（ワークフローの実行アカウント以外のアカウントにデータを送信する場合に必要です）。

New Relicアカウントの[ライセンスキーの作成および管理方法については、「ライセンスキー」](/docs/apis/intro-apis/new-relic-api-keys#license-key)を参照してください。
