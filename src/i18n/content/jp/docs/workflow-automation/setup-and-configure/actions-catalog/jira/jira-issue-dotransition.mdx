Jiraの課題を別のステータスに移行します。このアクションを呼び出す前に、[Get Jira issue transitions](/docs/workflow-automation/setup-and-configure/actions-catalog/jira/jira-issue-gettransitions)アクションを使用して、利用可能な移行IDを取得してください。

認証のセットアップについては、[Jira issue actions](/docs/workflow-automation/setup-and-configure/actions-catalog/jira/jira-issue)を参照してください。

                  type: action
                  action: jira.issue.doTransition
                  version: 1
                  inputs:
                    authToken: ${{ :secrets:jiraAuthToken }}
                    domain: mycompany
                    issueKey: "PROJ-123"
                    transitionId: "181"
