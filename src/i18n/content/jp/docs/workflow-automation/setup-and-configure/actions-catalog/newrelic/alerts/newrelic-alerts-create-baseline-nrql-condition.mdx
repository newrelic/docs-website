アクション識別子は`newrelic.alerts.createBaselineNrqlCondition`です。

アラートポリシーの下に新しいベースラインNRQLアラート条件を作成します。ベースライン条件は、過去の動作からシグナルの予想される範囲を動的に予測し、ライブシグナルが設定された閾値を超えてその予測されたベースラインから逸脱した場合に違反をオープンします。

`terms`または`expiration`（`openViolationOnExpiration: true`とともに）の少なくとも1つを指定する必要があります。両方を省略すると、NerdGraphの検証に失敗します。

      次の例では、スループットが予想範囲を上回った場合にアラートを発するベースラインNRQL条件を作成します。

      <table>
        <thead>
          <tr>
            <th>
              ワークフローの例
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: create_baseline_nrql_condition
              description: Create a baseline NRQL alert condition
              steps:
                - name: createBaselineCondition
                  type: action
                  action: newrelic.alerts.createBaselineNrqlCondition
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    policyId: ${{ .workflowInputs.policyId }}
                    name: "Anomalous throughput"
                    nrqlQuery: "SELECT count(*) FROM Transaction WHERE appName = 'MyApp'"
                    enabled: true
                    baselineDirection: "UPPER_ONLY"
                    terms:
                      - priority: "WARNING"
                        operator: "ABOVE"
                        threshold: 20
                        thresholdDuration: 600
                        thresholdOccurrences: "ALL"
                    selectors:
                      - name: conditionId
                        expression: ".data.alertsNrqlConditionBaselineCreate.id"
                  next: end
              ```
