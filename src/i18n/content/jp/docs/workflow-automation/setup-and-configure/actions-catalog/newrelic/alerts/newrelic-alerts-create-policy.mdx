アクション識別子は`newrelic.alerts.createPolicy`です。

新しいアラートポリシーを作成します。ポリシーは関連するアラート条件をグループ化し、違反がどのようにインシデントを作成するかを制御します。

        <tbody>
          <tr>
            <td>
              ```yaml
              name: create_alert_policy
              description: Create an alert policy
              steps:
                - name: createPolicy
                  type: action
                  action: newrelic.alerts.createPolicy
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    name: "Production Services"
                    incidentPreference: "PER_CONDITION"
                    selectors:
                      - name: policyId
                        expression: ".data.alertsPolicyCreate.id"
                  next: end
              ```
