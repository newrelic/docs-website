このページでは、ワークフロー自動化アクションカタログで利用可能なAWS Simple Email Service（SES）アクションのリファレンスを提供します。これらのアクションを使用して、電子メールテンプレートを作成、更新、取得、削除し、Amazon SESを介して電子メールを送信します。

## 前提条件

前提条件と認証情報のセットアップについては、[AWS認証情報のセットアップ](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials)をご覧ください。

## テンプレートを作成する

アクション識別子は`aws.ses.createTemplate`です。

Amazon SESで、テンプレート化されたEメールを送信するためのEメールテンプレートを作成します。

  `textPart`または`htmlPart`の少なくとも1つを指定する必要があります。SESでは、テンプレートの本文コンテンツが少なくとも1つの形式で指定されている必要があります。
</Callout>

**ワークフローの例**

```yaml
name: create-ses-template
description: 'Create an email template in Amazon SES'
steps:
  - name: createWelcomeTemplate
    type: action
    action: aws.ses.createTemplate
    version: '1'
    inputs:
      awsRoleArn: "arn:aws:iam::123456789012:role/my-workflow-role"
      region: us-east-2
      templateName: WelcomeEmailTemplate
      subjectPart: "Welcome to Our Service"
      textPart: "Hello, welcome aboard."
      htmlPart: "<h1>Hello</h1><p>Welcome aboard.</p>"
    next: end
```

## テンプレートメールを一括送信する

アクション識別子は`aws.ses.sendBulkTemplatedEmail`です。

1回の呼び出しで複数の受信者にテンプレート化されたEメールを送信し、受信者ごとにテンプレートデータを置換します。`source`アドレスと参照される`template`はすでに存在している必要があります。

<Callout variant="important">
  AWSは、このアクションを呼び出しごとに50個の`destinations`エントリに制限しており、宛先ごとに最大50人の受信者（To/Cc/Bccの合計）、生成されるメッセージの最大サイズは10 MBとなります。これらの制限のいずれかを超えると、送信時にAWS APIエラーが発生します。
</Callout>

`destinations`の各エントリでは、以下のフィールドを受け付けます：

* `destination` — **必須。**`toAddresses`、`ccAddresses`、および/または`bccAddresses`（それぞれ文字列のリスト）を持つオブジェクト。
* `replacementTemplateData` — **オプション。**宛先ごとのプレースホルダー値のJSON文字列。この宛先の`defaultTemplateData`を上書きします。
* `replacementTags` — **オプション。**この受信者の`defaultTags`を上書きする`{"name": "...", "value": "..."}`オブジェクトのリスト。
