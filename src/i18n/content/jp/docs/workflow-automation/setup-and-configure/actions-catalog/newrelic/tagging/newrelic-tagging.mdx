このページでは、ワークフロー自動化アクションカタログで利用可能なすべてのNew Relicタグアクションのリファレンスを提供します。これらのアクションを使用すると、ワークフローから直接New Relicエンティティのタグを追加、置換、削除できます。

## 前提条件

ワークフロー自動化で New Relic タグアクションを使用する前に、以下があることを確認してください：

* エンティティタグを管理するための適切な権限を持つNew Relicアカウント。
