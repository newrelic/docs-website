アクション識別子は`newrelic.alerts.searchNrqlConditions`です。

名前、ポリシー、NRQLクエリテキスト、またはterms演算子による任意のフィルタリングを使用して、NRQLアラート条件（静的またはベースライン）を検索します。カーソルベースのページネーションをサポートしています。すべてのフィルターを省略すると、アカウント内のすべての条件が返されます。

      以下の例では、名前のフラグメントでポリシーにアタッチされているNRQL条件を検索します。

      <table>
        <thead>
          <tr>
            <th>
              ワークフローの例
            </th>

        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: search_nrql_conditions
              description: Search NRQL alert conditions
              steps:
                - name: searchConditions
                  type: action
                  action: newrelic.alerts.searchNrqlConditions
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    policyId: ${{ .workflowInputs.policyId }}
                    nameLike: "error rate"
                    selectors:
                      - name: nrqlConditions
                        expression: ".data.actor.account.alerts.nrqlConditionsSearch.nrqlConditions"
                  next: end
              ```
