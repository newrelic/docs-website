New Relicエンティティのタグセット全体を、提供されたタグに置き換えます。

前提条件については、[New Relicタグアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites)を参照してください。

## タグを置換

アクション識別子は`newrelic.tagging.replaceTags`です。

New Relicエンティティのタグセット全体を、提供されたタグに置き換えます。このアクションは破壊的です：`tags`入力に含まれていない既存のタグはすべて削除されます。既存のタグを削除せずにタグを追加するには、代わりに[`newrelic.tagging.addTags`](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging-addtags)を使用してください。`newrelic.nerdgraph.execute`上に構築されています。
