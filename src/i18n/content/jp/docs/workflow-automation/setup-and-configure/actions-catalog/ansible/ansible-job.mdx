このページでは、ワークフロー自動化アクションカタログで利用可能なすべてのAnsibleジョブアクションのリファレンスを提供します。これらのアクションを使用して、ワークフローからAnsible Automation プラットフォーム（Automation Controller）のジョブテンプレートをリリースおよびモニターしてください。

## 前提条件

ワークフロー自動化でAnsibleアクションを使用する前に、以下が必要です：

* HTTPS経由でアクセス可能なAnsible Automation プラットフォーム（Automation Controller）インスタンス。
* ジョブをリリースするための書き込みスコープを持つOAuth2トークン（**Automation Controller &gt; Users &gt; Tokens**で作成します）。
* リリースするテンプレートの数値のジョブテンプレートIDです。
* 使用する予定の各オプション入力（`extraVars`、`limit`、`inventory`）のジョブテンプレートで有効になっている`ask_*_on_launch`設定。
