特定のワークフローの最新のGitHub Actionsワークフロー実行を取得します。正確なRun IDが不明な場合 — たとえば、実行をトリガーした直後などに役立ちます。常に最大1つの実行を返します。

認証の設定については、[GitHubワークフロー実行アクション](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run)をご覧ください。

ワークフローの例

<tbody>
<tr>
<td>
```yaml
name: get_latest_workflow_run
description: Retrieve the most recent workflow run for a specific workflow
steps:
  - name: get_latest_run
    type: action
    action: gitHub.workflowRun.getLatest
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      workflowId: deploy.yml
      branch: main
      event: workflow_dispatch
      selectors:
        - name: runId
          expression: ".workflow_runs[0].id"
        - name: conclusion
          expression: ".workflow_runs[0].conclusion"
        - name: htmlUrl
          expression: ".workflow_runs[0].html_url"
    next: end
```
</td>
