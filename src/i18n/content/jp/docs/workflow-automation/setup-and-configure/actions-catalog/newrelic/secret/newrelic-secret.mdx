このページでは、ワークフロー自動化アクションカタログで利用可能なNew Relic Secrets Managementアクションのリファレンスを提供します。これらのアクションを使用すると、ワークフロー定義から直接シークレットを一覧表示し、そのバージョン履歴を確認できます。

<Callout variant="important">
シークレットの値を取得するアクションはありません。ワークフローのアクションを通じてシークレットを復号すると、実行履歴やログにその値が露出します。シークレットの値をワークフローステップの入力として使用するには、代わりに`${{ :secrets:keyName }}`構文を使用して直接参照してください。
</Callout>

## 前提条件

ワークフロー自動化でNew Relicのシークレットアクションを使用する前に、以下が準備されていることを確認してください：

* Secrets Managementを読み取るための適切な権限を持つNew Relicアカウント。
* クエリするスコープの`scopeId`（アカウントIDまたは組織ID）および`scopeType`（`ACCOUNT`または`ORGANIZATION`）。

## シークレットバージョンの一覧 [#list-versions]

```yaml
steps:
  - name: listSecretVersions
    type: action
    action: newrelic.secret.listVersions
    version: 1
    inputs:
      key: "jira_auth_token"
      scopeId: "11933347"
      scopeType: "ACCOUNT"
      fetchDeleted: true
      selectors:
        - name: latestVersion
          expression: ".data.customerAdministration.secretVersions.latestVersion"
    next: end
```

## シークレットの一覧表示 [#list-secrets]
