アクション識別子は`newrelic.alerts.searchAsNrqlConditions`です。

NRQL変換された形式のクラシック（レガシー）アラート条件を検索します。名前、ポリシー、またはソース製品によるオプションのフィルタリング、およびカーソルベースのページネーションをサポートします。

      以下の例では、名前の一部でクラシック条件を検索します。

      <table>
        <thead>
          <tr>
            <th>
              ワークフローの例
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: search_as_nrql_conditions
              description: Search classic conditions in NRQL format
              steps:
                - name: searchAsNrqlConditions
                  type: action
                  action: newrelic.alerts.searchAsNrqlConditions
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    nameLike: "error rate"
                    selectors:
                      - name: nrqlConditions
                        expression: ".data.actor.account.alerts.asNrqlConditionsSearch.nrqlConditions"
                  next: end
              ```
