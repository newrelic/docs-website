アクション識別子は`newrelic.alerts.deleteCondition`です。

既存のアラート条件を削除します。条件タイプ全体で機能します — 静的、ベースライン、その他。

                  type: action
                  action: newrelic.alerts.deleteCondition
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
