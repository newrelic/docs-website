アクション識別子は`newrelic.alerts.listMutingRules`です。

アカウントのミュートルールを一覧表示します。オプションで有効状態によってフィルタリングします。このアクションはカーソルによるページネーションを行わず、一致するすべてのルールを単一のレスポンスで返します。

      以下の例では、アカウントで現在有効になっているすべてのミューティングルールを一覧表示します。

      <table>
        <thead>
          <tr>
            <th>
              ワークフローの例
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: list_muting_rules
              description: List enabled muting rules for an account
              steps:
                - name: listMutingRules
                  type: action
                  action: newrelic.alerts.listMutingRules
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    enabled: true
                    selectors:
                      - name: mutingRules
                        expression: ".data.actor.account.alerts.mutingRules"
                  next: end
              ```
