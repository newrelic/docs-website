オプションでファイルを添付して、Slackチャンネルにメッセージを送信します。

前提条件については、[Slackチャットアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/slack/slack-chat#prerequisites)を参照してください。

## メッセージを投稿する

アクション識別子は`slack.chat.postMessage`です。

オプションでファイルを添付して、Slackチャンネルにメッセージを送信します。

    <TabsPageItem id="slack-post-message-example">
      **例1：Slackメッセージを送信する**

      <table>
        <thead>
          <tr>
            <th>
              ワークフローの例
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: SendMessage

              steps:
                - name: send_slack_message
                  type: action
                  action: slack.chat.postMessage
                  version: 1
                  inputs:
                    token: ${{ :secrets:dn_staging_slack_token }}
                    channel: ${{ .workflowInputs.channel }}
                    text: ${{ .workflowInputs.text }}
                    selectors:
                      - name: threadTs
                        expression: ".threadTs"
                      - name: channelID
                        expression: ".channelID"
              ```

              **入力:**

              ```json
              {
                "inputs": [
                  {
                    "key" : "channel",
                    "value" : "test-channel-workflow"
                  },
                  {
                    "key" : "text",
                    "value" : "This is my message *with bold text* and `code backticks`"
                  }
                ]
              }
              ```

              **期待される出力:**

              ```json
              [
                {
                  "threadTs": "1718897637.400609",
                  "channelID": "C063JK1RHN1",
                  "success": true
                }
              ]
              ```
            </td>
          </tr>
        </tbody>
      </table>
