数値のRun IDを使用して、特定のGitHub Actionsワークフロー実行の詳細、ステータス、および結果を取得します。Run IDは通常、前の`gitHub.workflowRun.trigger`または`gitHub.workflowRun.list`ステップから取得されます。

認証の設定については、[GitHubワークフロー実行アクション](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run)をご覧ください。

ワークフローの例
</th>

<tbody>
<tr>
<td>
```yaml
name: poll_workflow_run
description: Get the status of a specific GitHub Actions workflow run
steps:
  - name: get_run
    type: action
    action: gitHub.workflowRun.get
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      runId: ${{ .steps.trigger_run.outputs.response.workflow_run_id }}
      selectors:
        - name: status
          expression: ".status"
        - name: conclusion
          expression: ".conclusion"
        - name: htmlUrl
          expression: ".html_url"
    next: end
```
</td>
