## PagerDutyインシデントを作成する

アクション識別子は`pagerduty.incident.create`です。

指定されたサービス、タイトル、優先度、およびその他のオプション属性を使用して、PagerDuty に新しいインシデントを作成します。

    <TabsPageItem id="pagerduty-incident-create-example">
      次の例では、サービス、緊急度、本文、およびエスカレーション・ポリシーを指定して、新しいPagerDutyインシデントを作成します。

      <table>
        <thead>
          <tr>
            <th>
              ワークフローの例
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: create-pagerduty-incident
              description: Create a new PagerDuty incident
              steps:
                - name: create
                  type: action
                  action: pagerduty.incident.create
                  version: 1
                  inputs:
                    token: ${{ :secrets:pagerdutyApiToken }}
                    type: incident
                    title: Test incident
                    service:
                      id: P123456
                      type: service_reference
                    urgency: low
                    body:
                      type: incident_body
                      details: Test Body
                    incidentKey: a12345-b678910-c111213
                    escalationPolicy:
                      id: P54321
                      type: escalation_policy_reference
                    selectors:
                      - name: incidentId
                        expression: .responseBody | fromjson.incident.id
                  next: end
              ```
            </td>
