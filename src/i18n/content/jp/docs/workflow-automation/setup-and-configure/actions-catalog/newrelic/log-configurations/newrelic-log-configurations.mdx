このページでは、ワークフロー自動化アクションカタログで利用可能なNew Relic Logsの設定アクションのリファレンスを提供します。これらのアクションを使用して、ログ設定リソース — 解析ルール、データパーティションルール、難読化表現とルール、およびパイプライン設定 — をクエリし、ワークフロー定義から直接、Grokパターンの検証やパイプライン設定の更新などの操作を実行します。

## 前提条件

ワークフローの自動化でNew Relic Logsの設定アクションを使用する前に、以下の準備ができていることを確認してください：

* ログ管理設定にアクセスするための適切な権限を持つNew Relicアカウント。
* ログ設定をクエリまたは更新する各アカウントのアカウントIDです。
