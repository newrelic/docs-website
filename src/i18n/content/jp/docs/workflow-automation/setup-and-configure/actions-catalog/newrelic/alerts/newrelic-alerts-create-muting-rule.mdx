アクション識別子は`newrelic.alerts.createMutingRule`です。

条件に一致する違反の集計通知を抑制する新しいミューティングルールを作成します。オプションで、ルールを定期的または1回限りのメンテナンスウィンドウとしてスケジュールします。

    <TabsPageItem id="muting-create-example">
      以下の例では、週末の定期的なメンテナンスウィンドウ中にポリシーのアラートを抑制するミュートルールを作成します。

      <table>
        <thead>
          <tr>
            <th>
              ワークフローの例
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: create_muting_rule
              description: Create a muting rule for a maintenance window
              steps:
                - name: createMutingRule
                  type: action
                  action: newrelic.alerts.createMutingRule
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    name: "Deploy window - checkout service"
                    enabled: true
                    condition:
                      operator: "AND"
                      conditions:
                        - attribute: "policyName"
                          operator: "EQUALS"
                          values:
                            - "Checkout Service"
                    schedule:
                      startTime: "2026-09-01T02:00:00"
                      endTime: "2026-09-01T04:00:00"
                      timeZone: "America/Los_Angeles"
                      repeat: "WEEKLY"
                      weeklyRepeatDays:
                        - "SATURDAY"
                        - "SUNDAY"
                    selectors:
                      - name: mutingRuleId
                        expression: ".data.alertsMutingRuleCreate.id"
                  next: end
              ```
            </td>
          </tr>
