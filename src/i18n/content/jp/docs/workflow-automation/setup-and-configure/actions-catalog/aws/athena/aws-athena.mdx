このページでは、ワークフロー自動化アクションカタログで利用可能なAWS Athenaアクションのリファレンスを提供します。これらのアクションを使用して、Amazon Athenaに対してSQLクエリを実行し、その実行ステータスを確認して、ワークフロー定義から直接結果を取得します。

## 前提条件

前提条件と認証情報のセットアップについては、[AWS認証情報のセットアップ](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials)をご覧ください。

## クエリの実行を開始します。 [#start-query-execution]

アクション識別子は`aws.athena.startQueryExecution`です。

Amazon Athenaに対してSQLクエリを実行し、クエリ実行IDを返します。このアクションはクエリの完了を待機しません — ステータスをポーリングするには`aws.athena.getQueryExecution`を、結果を取得するには`aws.athena.getQueryResults`を使用してください。

**例**

```yaml
name: start-athena-query
description: Run a SQL query against Athena
steps:
  - name: startQuery
    type: action
    action: aws.athena.startQueryExecution
    version: '1'
    inputs:
      awsRoleArn: ${{ :secrets:awsRoleArn }}
      region: us-east-2
      queryString: "SELECT * FROM my_table LIMIT 10"
      database: "my-database"
      catalog: "AwsDataCatalog"
      outputLocation: "s3://my-athena-results-bucket/path/"
      workGroup: "primary"
      selectors:
        - name: queryExecutionId
          expression: ".response.QueryExecutionId"
    next: end
```
