Azure DevOps APIアクションを使用すると、各操作に専用のアクションを必要とせずに、ワークフローから直接任意の[Azure DevOps REST API](https://learn.microsoft.com/en-us/rest/api/azure/devops/?view=azure-devops-rest-7.1)を呼び出すことができます。

## Azure DevOps APIを実行する [#azure-devops-api]

このアクションを使用すると、『[Azure DevOps REST API リファレンス](https://learn.microsoft.com/en-us/rest/api/azure/devops/?view=azure-devops-rest-7.1)』に記載されている任意の操作を実行できます。組織、APIパス、HTTPメソッド、およびオプションのリクエスト本文を指定してください — アクションが認証を自動的に処理します。

    <TabsPageItem id="azuredevopsapiexample">
      ### 例：プロジェクトの取得

      ```yaml
        - name: getProjects
          type: action
          action: azure.devops.api
          version: 1
          inputs:
            clientId: ${{ :secrets:azure-client-id }}
            clientSecret: ${{ :secrets:azure-client-secret }}
            tenantId: ${{ :secrets:azure-client-tenant }}
            organization: ${{ :secrets:organization }}
            urlPath: _apis/projects
            method: GET
      ```

      ### 例：パイプラインを作成する

      ```yaml
        - name: createPipeline
          type: action
          action: azure.devops.api
          version: 1
          inputs:
            clientId: ${{ :secrets:azure-client-id }}
            clientSecret: ${{ :secrets:azure-client-secret }}
            tenantId: ${{ :secrets:azure-client-tenant }}
            organization: ${{ :secrets:organization }}
            urlPath: myProject/_apis/pipelines?api-version=7.1
            method: POST
            body:
              name: testPipeline
              folder: \
              configuration:
                type: yaml
                path: pipelineConfig.yml
                repository:
                  id: 1a8bcfa4-1412-4b3b-af36-4ff1aa5860a1
                  name: testRepository
                  type: azureReposGit
            selectors:
              - name: pipelineId
                expression: .response.id
              - name: pipelineName
                expression: .response.name
      ```

      ### 例：パイプラインを実行する

      ```yaml
        - name: runPipeline
          type: action
          action: azure.devops.api
          version: 1
          inputs:
            clientId: ${{ :secrets:azure-client-id }}
            clientSecret: ${{ :secrets:azure-client-secret }}
            tenantId: ${{ :secrets:azure-client-tenant }}
            organization: ${{ :secrets:organization }}
            urlPath: myProject/_apis/pipelines/1/runs?api-version=7.1-preview.1
            method: POST
            body:
              resources: {}
              variables: {}
      ```

      ### 例：パイプラインを削除する

      ```yaml
        - name: deletePipeline
          type: action
          action: azure.devops.api
          version: 1
          inputs:
            clientId: ${{ :secrets:azure-client-id }}
            clientSecret: ${{ :secrets:azure-client-secret }}
            tenantId: ${{ :secrets:azure-client-tenant }}
            organization: ${{ :secrets:organization }}
            urlPath: myProject/_apis/build/definitions/1?api-version=7.1-preview.7
            method: DELETE
      ```
