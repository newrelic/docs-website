New Relicエンティティから1つ以上のタグキーと、その下のすべての値を削除します。

前提条件については、[New Relicタグアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites)を参照してください。

## タグを削除

アクション識別子は`newrelic.tagging.deleteTags`です。

New Relicエンティティから1つ以上のタグキーと、その下のすべての値を削除します。同じキーの下にある他の値を保持したまま特定の値のみを削除するには、代わりに[`newrelic.tagging.deleteTagValues`](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging-deletetagvalues)を使用してください。`newrelic.nerdgraph.execute`上に構築されています。
