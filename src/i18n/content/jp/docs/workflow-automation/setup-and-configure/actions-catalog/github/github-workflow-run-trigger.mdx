`workflow_dispatch`イベントを介してGitHub Actionsワークフローの実行をトリガーします。ターゲットワークフローには、`workflow_dispatch`トリガーが構成されている必要があります。成功すると、GitHubはHTTP 204 No Contentを返します。

認証の設定については、[GitHubワークフロー実行アクション](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run)をご覧ください。

<td>
```yaml
name: trigger_github_workflow
description: Trigger a GitHub Actions workflow run
steps:
  - name: trigger_run
    type: action
    action: gitHub.workflowRun.trigger
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      workflowId: deploy.yml
      ref: main
      inputs:
        environment: staging
        version: "1.2.3"
    next: end
```
