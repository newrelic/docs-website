New Relicエンティティから特定のタグの値を削除し、同じキーの下にある他の値はそのまま残します。

前提条件については、[New Relicタグアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites)を参照してください。

## タグの値を削除

アクション識別子は`newrelic.tagging.deleteTagValues`です。

New Relicエンティティのタグから特定のキーの値のペアを削除します。同じキーの下にある他の値は保持されます。タグのキー全体とそのすべての値を削除するには、代わりに[`newrelic.tagging.deleteTags`](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging-deletetags)を使用してください。`newrelic.nerdgraph.execute`上に構築されています。
