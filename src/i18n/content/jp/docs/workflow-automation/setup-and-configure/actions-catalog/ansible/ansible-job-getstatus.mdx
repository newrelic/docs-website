このページでは、ワークフロー自動化アクションカタログで利用可能な`ansible.job.getStatus`アクションのリファレンスを提供します。このアクションを使用して、Ansible Automation プラットフォーム（Automation Controller）ジョブのステータスと詳細を取得します。[`ansible.job.launch`](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job-launch)によって作成されたジョブをポーリングするには、このアクションを使用します。このアクションは、`http.get`ベースアクションに基づいています。

**エンドポイント：** `GET https://{host}/api/controller/v2/jobs/{jobId}/`

## 前提条件

ワークフローの自動化でこのアクションを使用する前に、以下が準備されていることを確認してください：

* HTTPS経由でアクセス可能なAnsible Automation プラットフォーム（Automation Controller）インスタンス。
* 書き込みスコープを持つOAuth2トークン（**Automation Controller → ユーザー → トークン**で作成してください）
* ポーリングする数値ジョブID（通常は`ansible.job.launch`によって返される`id`フィールド）。
