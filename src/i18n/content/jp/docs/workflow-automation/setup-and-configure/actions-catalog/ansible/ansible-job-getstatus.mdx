このページでは、ワークフロー自動化アクションカタログで利用可能な`ansible.job.getStatus`アクションのリファレンスを提供します。このアクションを使用して、[`ansible.job.launch`](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job-launch)によって作成されたジョブが終了状態になるまでポーリングします。

前提条件については、[Ansibleジョブアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job#prerequisites)をご覧ください。

## Ansibleジョブのステータスを取得する

アクション識別子は`ansible.job.getStatus`です。

Automation Controllerジョブのステータスと詳細を取得します。ジョブのステータスは、終了状態（`successful`、`failed`、`error`、または`canceled`）に達する前に、`pending`から`waiting`、`running`へと進行します。エンドポイントは`GET https://{host}/api/controller/v2/jobs/{jobId}/`です。

              ```yaml
              name: check-ansible-job
              description: Fetch the status of a previously launched Ansible job
              steps:
                - name: get_status
                  type: action
                  action: ansible.job.getStatus
                  version: 1
                  inputs:
                    host: ${{ :secrets:host }}
                    authToken: ${{ :secrets:ansibleControllerToken }}
                    jobId: "128"
                    selectors:
                      - name: status
                        expression: ".status"
                      - name: failed
                        expression: ".failed"
                  next: end
              ```
