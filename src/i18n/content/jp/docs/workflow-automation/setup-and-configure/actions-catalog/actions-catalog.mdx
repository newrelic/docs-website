New Relicのアクションカタログは、cloudプロバイダー、DevOpsツール、ITSMプラットフォーム、およびNew Relic独自のプラットフォーム向けの事前構築済みアクションを提供します。これらのアクションをワークフロー自動化のステップとして使用して、ツールやサービス全体でデプロイメントをトリガーし、インシデントを管理し、運用タスクを自動化します。

アクションは階層的な命名規則に従います。 `company.product.action`

## 認証アクション [#authentication]

セキュアなAPIアクセスのためにJSON Webトークン（JWT）を作成します。

* [**外部 API で安全な認証を行うための JSON Web ウイルス (JWT) を作成する**](/docs/workflow-automation/setup-and-configure/actions-catalog/auth/auth-jwt-create#auth.jwt.create)
