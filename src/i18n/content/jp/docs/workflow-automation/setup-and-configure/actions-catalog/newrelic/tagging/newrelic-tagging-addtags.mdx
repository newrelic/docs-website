既存のタグを保持したまま、New Relicエンティティに1つ以上のタグを追加します。

前提条件については、[New Relicタグアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites)を参照してください。

## タグの追加

アクション識別子は`newrelic.tagging.addTags`です。

New Relicエンティティに1つ以上のタグを追加します。すでに存在するキーに値を追加すると、置き換えられるのではなく追加されます。`newrelic.nerdgraph.execute`上に構築されています。
