リポジトリのGitHub Actionsワークフローの実行を一覧表示します。オプションで、ワークフロー、ブランチ、イベント、ステータスなどによるフィルタリングが可能です。`workflowId`が指定された場合、リストはその特定のワークフローに限定されます。それ以外の場合は、リポジトリ内のすべてのワークフローの実行を返します。

認証の設定については、[GitHubワークフロー実行アクション](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run)をご覧ください。

ワークフローの例
</th>

<tbody>
<tr>
<td>
```yaml
name: list_workflow_runs
description: List GitHub Actions workflow runs for a specific workflow
steps:
  - name: list_runs
    type: action
    action: gitHub.workflowRun.list
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      workflowId: deploy.yml
      branch: main
      status: completed
      resultsPerPage: 10
      selectors:
        - name: totalCount
          expression: ".total_count"
        - name: latestRunId
          expression: ".workflow_runs[0].id"
        - name: latestConclusion
          expression: ".workflow_runs[0].conclusion"
    next: end
```
