リソースグループ内のAzure App Service Webアプリケーションを一覧表示します。ページ分割された結果を返します — リソースグループに複数ページにまたがる十分な数のアプリが含まれている場合、次のページを取得するための`nextLink`フィールドがレスポンスに含まれます。

認証のセットアップについては、[Azure App Serviceアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-appservice)をご覧ください。

レスポンスに `nextLink` フィールドが含まれている場合、結果には追加のページがあります。セレクターでそれをキャプチャし、そのURLを `urlPath` として直接 `azure.execute.api` を呼び出して、次のページを取得してください。
</TabsPageItem>

<TabsPageItem id="azureappservicelistexample">
```yaml
name: listAzureAppServices
description: List Azure App Services in a resource group
steps:
  - name: list_app_services
    type: action
    action: azure.appService.list
    version: 1
    inputs:
      clientId: ${{ :secrets:azure-client-id }}
      clientSecret: ${{ :secrets:azure-client-secret }}
      tenantId: ${{ :secrets:azure-client-tenant }}
      subscriptionId: "12345678-1234-1234-1234-123456789abc"
      resourceGroupName: "my-resource-group"
      selectors:
        - name: appNames
          expression: "[.response.value[].name]"
        - name: nextLink
          expression: ".response.nextLink // \"\""
    next: end
```
