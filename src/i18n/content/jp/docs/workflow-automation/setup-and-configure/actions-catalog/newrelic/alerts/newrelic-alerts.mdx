このページでは、ワークフロー自動化のアクションカタログで利用可能な、すべてのNew Relicアラートアクションのリファレンスを提供します。これらのアクションを使用すると、ワークフローから直接、アラートポリシー、NRQL条件（静的およびベースライン）、複合条件、およびミュートルールを作成、更新、削除、取得、検索できます。

## 前提条件

ワークフロー自動化でNew Relicアラートアクションを使用する前に、以下があることを確認してください：

* アラートを管理するための適切な権限を持つNew Relicアカウント。
* 集計リソースが存在するアカウントのNew RelicアカウントID。
