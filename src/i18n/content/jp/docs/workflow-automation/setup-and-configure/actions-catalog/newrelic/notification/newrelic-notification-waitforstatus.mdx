アクション識別子は`newrelic.notification.waitForStatus`です。

前の`newrelic.notification.send`ステップで送信された通知の配信結果をポーリングします。`sessionId`を指定すると、このアクションは、通知が最終ステータス（`SUCCESS`または`FAIL`）に達するか、指定された`timeout`が経過するまで`NrNotificationsEvent`をポーリングします。Slackの宛先の場合、通知によって作成されたスレッドに返信するために必要な`thread_ts`の値も返します。

ワークフローの例：Slack通知を送信し、配信確認を待機します
</th>
</tr>
</thead>

<tbody>
<tr>
<td>
```yaml
name: notify_and_wait
description: Send a Slack notification then wait for its delivery status
steps:
  - name: sendNotification
    type: action
    action: newrelic.notification.send
    version: 1
    inputs:
      type: slack
      destinationId: "your-destination-id"
      parameters:
        channel: "your-slack-channel"
        text: "Deployment finished"
      selectors:
        - name: sessionId
          expression: ".response.sessionId"
    next: waitForStatus

  - name: waitForStatus
    type: action
    action: newrelic.notification.waitForStatus
    version: 1
    inputs:
      sessionId: ${{ .steps.sendNotification.outputs.sessionId }}
      timeout: 15
      selectors:
        - name: deliveryStatus
          expression: ".notificationStatus.status"
        - name: threadTs
          expression: ".notificationStatus.threadTs"
    next: end
```
</td>
</tr>
