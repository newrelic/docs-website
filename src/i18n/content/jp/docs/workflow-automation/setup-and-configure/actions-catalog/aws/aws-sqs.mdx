このページでは、ワークフロー自動化アクションカタログで利用可能なAWS SQSアクションのリファレンスを提供します。これらのアクションを使用して、Amazon SQSキューとメッセージを管理します。

## 前提条件

ワークフロー自動化で AWS アクションを使用する前に、次の点を確認してください。

* 適切な権限を持つ AWS アカウント。
* 設定された AWS 認証情報 (IAM ユーザー認証情報、IAM ロール ARN、またはセッション認証情報)。
* SQSに必要なIAM許可。最低限、IAMロールまたはユーザーには、ターゲットキューに対する`sqs:*`が必要です。

IAM ユーザーおよび IAM ロールを作成する方法、およびワークフロー オートメーションAWSアクションと統合するための静的 AWS 認証情報とセッションAWS認証情報を設定する方法については[、 AWS認証情報のセットアップ」を](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials/)参照してください。

Amazon SQSキューのタグを追加または更新します。この操作は、既存のタグを削除せずに、指定されたタグのみを追加または更新します。キューあたり最大50個のタグ。タグのキーと値は、大文字と小文字を区別します。`aws:`プレフィックスは予約されており、使用できません。

## メッセージ移動タスクをキャンセルします。

アクション識別子は`aws.sqs.cancelMessageMoveTask`です。
