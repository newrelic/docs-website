アクション識別子は`newrelic.notification.createSignalUrl`です。

実行中のワークフローにシグナルを送信できるように、<DNT>Microsoft Teams</DNT>、<DNT>Slack</DNT>、または<DNT>email</DNT>を介してユーザーに送信するURLを生成します。このアクションは、[ヒューマン・イン・ザ・ループ・パターン](/docs/workflow-automation/workflow-examples/advanced/human-in-the-loop)を実現します。このパターンでは、人がURLをクリックして実行を承認、拒否、またはその他の方法でルーティングするまで、ワークフローが待機ステップで一時停止します。

<Callout variant="important">
  このアクションは単独では効果がありません。このアクションは常に以下と一緒に使用してください：

  * 生成されたURLを人に配信する**通知アクション**（`newrelic.notification.*`または`slack.chat.postMessage`）。
  * ワークフローの実行が待機するシグナルを少なくとも1つ定義する**待機ステップ**です。

  入力として指定する`waitStepName`は、同じワークフロー定義内の有効な待機ステップの名前と一致する必要があり、その待機ステップには少なくとも1つのシグナルが含まれている必要があります。そうでない場合、作成時にワークフロー定義の検証に失敗します。
</Callout>

              steps:
                - name: createApprovalUrls
                  type: action
                  action: newrelic.notification.createSignalUrl
                  version: 1
                  inputs:
                    waitStepName: waitForApproval
                - name: newrelicNotificationMsTeam
                  type: action
                  action: newrelic.notification.sendMicrosoftTeams
                  version: 1
                  inputs:
                    destinationId: acc24dc2-d4fc-4eba-a7b4-b3ad0170f8aa
                    channel: "dev-channel"
                    teamName: "dev-team"
                    message: "To approve continue at: ${{ .steps.createApprovalUrls.outputs.url }}"
                - name: waitForApproval
                  type: wait
                  seconds: 3900 # 1 hour 5 minutes
                  signals:
                    - name: "approve"
                      next: logApproval
                    - name: "deny"
                      next: logDenial
                  next: handleTimeout
