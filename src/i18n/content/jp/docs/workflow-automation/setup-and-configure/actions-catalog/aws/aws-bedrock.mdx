このページでは、ワークフロー自動化アクションカタログで利用可能なAWS Bedrockアクションのリファレンスを提供します。これらのアクションを使用して、ワークフロー定義の一部としてBedrockエージェントを呼び出してください。

## 前提条件

ワークフロー自動化でAWS Bedrockアクションを使用する前に、以下があることを確認してください：

* 適切な権限を持つ AWS アカウント。
* 設定されたAWS認証情報（IAMユーザー認証情報、IAMロールARN、またはセッション認証情報）。少なくとも1つの認証情報オプションを指定する必要があります — IAMロールは静的アクセスキーよりも優先されます。
* Bedrock操作に必要なIAM権限（`bedrock:InvokeAgent`、`bedrock:InvokeModel`）。

IAM ユーザーおよび IAM ロールを作成する方法、およびワークフロー オートメーションAWSアクションと統合するための静的 AWS 認証情報とセッションAWS認証情報を設定する方法については[、 AWS認証情報のセットアップ」を](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials/)参照してください。

## Bedrockエージェントを呼び出す

アクション識別子は`aws.bedrock.invokeAgent`です。

プロンプトを使用してAWS Bedrockエージェントを呼び出し、エージェントの応答を返します。
