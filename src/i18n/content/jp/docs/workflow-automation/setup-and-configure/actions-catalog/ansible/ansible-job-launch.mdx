このページでは、ワークフロー自動化アクションカタログで利用可能な`ansible.job.launch`アクションのリファレンスを提供します。このアクションを使用して、ワークフローステップからAnsible Automation プラットフォーム（Automation Controller）ジョブテンプレートをリリースします。

前提条件については、[Ansibleジョブアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job#prerequisites)をご覧ください。

## Ansibleジョブテンプレートをリリースします

アクション識別子は`ansible.job.launch`です。

Ansible Automation Platform（Automation Controller）のジョブテンプレートをリリースし、作成されたジョブを返します。成功すると、ジョブが終了状態になるまでポーリングするために[`ansible.job.getStatus`](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job-getstatus)で使用できるジョブ`id`を返します。エンドポイントは`POST https://{host}/api/controller/v2/job_templates/{jobTemplateId}/launch/`です。

          <tr>
            <td>
              ```yaml
              name: launch-ansible-remediation
              description: Launch an Ansible job template to remediate an incident
              steps:
                - name: launch_job
                  type: action
                  action: ansible.job.launch
                  version: 1
                  inputs:
                    host: ${{ :secrets:host }}
                    authToken: ${{ :secrets:ansibleControllerToken }}
                    jobTemplateId: "42"
                    extraVars:
                      target_env: staging
                      app_version: "1.2.3"
                    selectors:
                      - name: jobId
                        expression: ".id"
                  next: end
              ```
