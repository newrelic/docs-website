このページでは、ワークフロー自動化アクションカタログで利用可能なAWS CloudWatchアクションのリファレンスを提供します。これらのアクションを使用して、AWS CloudWatchでログデータを取得およびアップロードします。

## 前提条件

ワークフロー自動化で AWS アクションを使用する前に、次の点を確認してください。

* 適切な権限を持つ AWS アカウント。
* 設定された AWS 認証情報 (IAM ユーザー認証情報、IAM ロール ARN、またはセッション認証情報)。
* 使用する予定の特定のAWSサービスに必要な IAM 権限。

IAM ユーザーおよび IAM ロールを作成する方法、およびワークフロー オートメーションAWSアクションと統合するための静的 AWS 認証情報とセッションAWS認証情報を設定する方法については[、 AWS認証情報のセットアップ」を](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials/)参照してください。

以下のワークフローの例では、このアクションの使用方法を示します。

```yaml
name: get-lambda-logs
description: 'Retrieve log events from an AWS Lambda function'
workflowInputs:
  region:
    type: String
    defaultValue: us-east-2
  logGroupName:
    type: String
    defaultValue: /aws/lambda/my-function
  logStreamName:
    type: String
    defaultValue: 2023/10/27/[$LATEST]abcdef123456
steps:
  - name: get_events_step
    type: action
    action: aws.cloudwatch.getLogEvents
    version: '1'
    inputs:
      region: ${{ .workflowInputs.region }}
      logGroupName: ${{ .workflowInputs.logGroupName }}
      logStreamName: ${{ .workflowInputs.logStreamName }}
      limit: 100
    next: end
```

以下のワークフローの例では、このアクションの使用方法を示します。

```yaml
name: put-custom-logs
description: 'Upload a batch of custom log events to CloudWatch'
workflowInputs:
  region:
    type: String
    defaultValue: us-east-2
  logGroupName:
    type: String
    defaultValue: my-custom-app-logs
  logStreamName:
    type: String
    defaultValue: instance-01-thread-01
steps:
  - name: upload_logs
    type: action
    action: aws.cloudwatch.putLogEvents
    version: '1'
    inputs:
      region: ${{ .workflowInputs.region }}
      logGroupName: ${{ .workflowInputs.logGroupName }}
      logStreamName: ${{ .workflowInputs.logStreamName }}
      logEvents:
        - timestamp: 1698384000000
          message: "Workflow started successfully"
        - timestamp: 1698384005000
          message: "Step 1 completed"
    next: end
```
