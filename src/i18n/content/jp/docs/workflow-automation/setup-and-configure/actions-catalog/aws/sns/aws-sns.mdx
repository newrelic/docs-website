このページでは、ワークフロー自動化アクションカタログで利用可能なAWS SNSアクションのリファレンスを提供します。これらのアクションを使用して、Amazon SNSトピックにメッセージを発行してください。

## 前提条件

前提条件と認証情報のセットアップについては、[AWS認証情報のセットアップ](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials)をご覧ください。

## SNSトピックにメッセージを公開する

アクション識別子は`aws.sns.publish`です。

Amazon SNS トピックにメッセージを送信します。トピックのすべてのサブスクライバーがメッセージを受信します。

```yaml
name: sns-publish-test
description: Publishes a notification to an SNS topic
workflowInputs:
  arnRole:
    type: String
steps:
  - name: aws_sns_publish_1
    type: action
    action: aws.sns.publish
    version: '1'
    inputs:
      awsRoleArn: ${{ .workflowInputs.arnRole }}
      region: us-east-1
      topicArn: arn:aws:sns:us-east-1:123456789012:workflow-test-topic
      subject: "Workflow Update"
      message: "The data processing workflow has completed successfully."
    next: end
```
