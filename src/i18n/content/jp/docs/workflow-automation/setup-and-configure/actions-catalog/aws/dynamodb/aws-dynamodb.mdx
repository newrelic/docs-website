このページでは、ワークフロー自動化のアクションカタログで利用できるAWS DynamoDBアクションのリファレンスを提供します。これらのアクションを使用して、DynamoDBテーブル内の項目の読み取り、書き込み、更新、削除を行ったり、ワークフロー定義から直接テーブル設定を検査または変更したりします。

## 前提条件

前提条件と認証情報のセットアップについては、[AWS認証情報のセットアップ](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials)をご覧ください。

すべてのDynamoDBアクションは、同じ認証入力を受け付けます。`awsRoleArn`（推奨）またはアクセスキーペアを使用します。

```yaml
steps:
  - name: putOrderItem
    type: action
    action: aws.dynamodb.putItem
    version: '1'

      awsRoleArn: ${{ :secrets:awsRoleArn }}
```

```yaml
    next: end
```

## テーブルのスキャン [#scan]

アクション識別子は`aws.dynamodb.scan`です。

必要に応じてフィルタリングを行い、テーブル全体をスキャンすることで、DynamoDBテーブルまたはインデックスから項目を返します。1回のスキャン応答は、ワークフロー自動化によって100 KBに制限されています（DynamoDB自体の制限は1 MBです）。大きなテーブルをページングするには、`limit`と`exclusiveStartKey`を使用します。

<Callout variant="important">
ワークフロー自動化は、アクションごとに100 KBの出力サイズ制限を適用します。`aws.dynamodb.scan`は、レスポンスがこの制限を超過した場合、DynamoDB独自の1レスポンスあたり1 MBの上限に収まっていたとしても、出力サイズ制限超過例外をスローします。結果をページ分割し、この制限内に収めるには、`limit`と`exclusiveStartKey`を使用してください。
</Callout>

```yaml
description: Get the status and configuration of a DynamoDB table
steps:
  - name: describeOrdersTable
    type: action
    action: aws.dynamodb.describeTable
    version: '1'
    inputs:
      awsRoleArn: ${{ :secrets:awsRoleArn }}
```
