このページでは、ワークフロー自動化アクション カタログで利用可能なNew Relicアクションの包括的なリファレンスを提供します。 これらのアクションにより、エージェント プラットフォームで構成されたエージェントを実行できるようになります。

## エージェントのアクション

### エージェントを実行する [#newrelic-agent-run]

エージェントティック プラットフォームで構成されたエージェントを実行します。

              制約と要件：

              * **構造**: リスト内の各要素は、`description`と対応する`value`を厳密に含むオブジェクトである必要があります。
              * **容量**: 1リクエストにつき最大10個のコンテキスト項目を指定できます。
              * **セキュリティ**: このフィールドにシークレットの参照を含めることは固く禁じられています。

              例：

              ```yaml
              context:
                - description: accountId
                  value: "12345678"
                - description: slack_channel_id
                  value: "CXXXXXXXXX"
              ```

    <TabsPageItem id="runagentexample">
      ```yaml
      name: demo-run-agent
      description: Run newrelic word problem agent
      steps:
        - name: runAgent
          type: action
          action: newrelic.agent.run
          version: '1'
          inputs:
            prompt: Sum of prime number less than 100
            agentId: word_problem_agent
            context:
              - description: accountId
                value: "12345678"
              - description: slack_channel_id
                value: "CXXXXXXXXX"
            selectors:
              - name: success
                expression: .success
              - name: error
                expression: .errorMessage
              - name: response
                expression: .response
      ```
