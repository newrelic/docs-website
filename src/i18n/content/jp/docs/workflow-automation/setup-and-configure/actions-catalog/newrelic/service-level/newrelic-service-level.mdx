このページでは、ワークフロー自動化アクションカタログで利用可能なすべてのNew Relic サービスレベルアクションのリファレンスを提供します。これらのアクションにより、ワークフローから直接サービスレベル指標（SLI）とそのサービスレベル目標（SLO）を作成、更新、削除、および列挙できます — これにより、自動化されたサービスのオンボーディング、SLOの修復、およびコンプライアンスワークフローが可能になります。

## 前提条件

ワークフローの自動化でNew Relicサービスレベルのアクションを使用する前に、以下のものがあることを確認してください：

サービスレベルを管理するための適切な権限を持つNew Relicアカウント。

                  action: newrelic.serviceLevel.create
                  version: 1
                  inputs:

                    name: "Checkout API availability"
                    accountId: ${{ .workflowInputs.accountId }}
                    validEventsFrom: "Transaction"
                    eventCategory: "GOOD"
                    conditionEventsFrom: "Transaction"
                    conditionEventsWhere: "appName = 'checkout-api' AND error IS FALSE"

## サービスレベルを更新

アクション識別子は`newrelic.serviceLevel.update`です。

既存のサービスレベルインジケーターの設定、またはそのサービスレベル目標を更新します。`newrelic.nerdgraph.execute`を使用します。

フィールド`name`と`description`は個別にオプションです — どちらかを省略すると既存の値が保持されます。フィールド`target`と`windowDays`は両方指定するか両方省略するかのどちらかです：SLOターゲットを変更するには両方を指定し、既存のSLOを変更しないようにするには両方を省略します。

イベント設定（`validEvents*`、`conditionEvents*`、`eventCategory`、`facets`）では、フィールドを省略すると、保持されるのではなく削除されます。イベントセクションの1つのフィールドを変更するには、変更内容とともに現在のイベント定義全体を再指定してください。
