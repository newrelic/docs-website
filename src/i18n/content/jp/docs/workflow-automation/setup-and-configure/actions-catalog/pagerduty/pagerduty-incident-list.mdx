## List PagerDuty

アクション識別子は`pagerduty.incident.list`です。

日付範囲やステータスなどのオプションのフィルタリングパラメーターを使用して、PagerDutyからインシデントのリストを取得します。`parameters`マップを介して、[PagerDutyのインシデントリストAPI](https://developer.pagerduty.com/api-reference/9d0b4b12e36f9-list-incidents)で利用可能なすべてのクエリパラメーターをサポートします。

                  inputs:
