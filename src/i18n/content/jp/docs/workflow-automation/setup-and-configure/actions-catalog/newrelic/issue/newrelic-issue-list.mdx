オプションのフィルタリングとページネーションを使用して、アカウントのNew Relic 集計インテリジェンスのイシューをクエリし、一覧表示します。

前提条件については、[New Relic Issueアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/issue/newrelic-issue#prerequisites)をご覧ください。

## 問題の一覧表示

アクション識別子は`newrelic.issue.list`です。

アカウントのNew Relicの問題（AI Issues）をクエリして一覧表示し、アクティブな問題または過去の問題のリアルタイムのステータス、タイムライン、相関エンティティ、および影響の詳細を返します。状態、優先度、ソース、エンティティ、条件、ポリシー、相関および承認ステータス、時間枠、およびカーソルベースのページネーションによるフィルタリングをサポートします。`newrelic.nerdgraph.execute`上に構築されています。

      以下の例では、さまざまなフィルター設定でこのアクションを使用する方法を示します。

      <table>
        <thead>
          <tr>
            <th>
              ワークフローの例
            </th>

        <tbody>
          <tr>
            <td>
              フィルターなし — 状態、優先度、またはその他のフィルターに関係なく、アカウント上のすべての問題をリストします。`accountId`のみ必須です：

              ```yaml
              name: newrelic_issue_list_all
              description: list all issues for an account with no filters
              steps:
                - name: newrelic_issue_list
                  type: action
                  action: newrelic.issue.list
                  version: 1
                  inputs:
                    accountId: 123456
                  next: end
              ```

              以下の例では、基本的なフィルターを使用して、アカウントのアクティブで優先度の高い問題をリストします：

              ```yaml
              name: newrelic_issue_list_workflow
              description: list newrelic issues
              steps:
                - name: newrelic_issue_list
                  type: action
                  action: newrelic.issue.list
                  version: 1
                  inputs:
                    accountId: 123456
                    states: ["ACTIVATED", "CREATED"]
                    priority: ["CRITICAL", "HIGH"]
                  next: end
              ```

              以下の例では、特定の時間枠内の未承認、ミュートされていない、クリティカルな問題に対して複数のフィルターを使用し、セレクタを使用してページネーション用にレスポンスをフラット化しています：

              ```yaml
              name: newrelic_issue_list_advanced
              description: list unacknowledged critical issues in a time window
              steps:
                - name: newrelic_issue_list
                  type: action
                  action: newrelic.issue.list
                  version: 1
                  inputs:
                    accountId: 123456
                    states: ["ACTIVATED"]
                    priority: ["CRITICAL"]
                    isAcknowledged: false
                    mutingStates: ["NOT_MUTED"]
                    startTime: 1785900000000
                    endTime: 1785998400000
                    selectors:
                      - name: issues
                        expression: ".data.actor.account.aiIssues.issues.issues"
                      - name: nextCursor
                        expression: ".data.actor.account.aiIssues.issues.nextCursor"
                  next: end
              ```

              3番目の例から追加の結果をページ送りするには、`nextCursor` の出力を取得し、後続の呼び出しで `cursor` の入力として再度渡します。
