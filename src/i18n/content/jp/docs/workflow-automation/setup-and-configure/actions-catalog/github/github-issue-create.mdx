認証のセットアップについては、[GitHub Issueアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-issue)を参照してください。

            <td>
              必須
            </td>

            <td>
              弦
            </td>

            <td>
              シークレットとして保存されたGitHub Personal Access Token（fine-grainedまたはclassic）。Fine-grained PATには、Issues：Read and write権限が必要です。Classic PATには、リポジトリスコープが必要です。
            </td>

            <td>
              `"${{ :secrets:github-PAT-token }}"`

          </tr>

          <tr>
            <td>
              **owner**
            </td>

            <td>
              必須
            </td>

            <td>
              弦
            </td>

            <td>
              リポジトリのアカウント所有者（ユーザーまたは組織のログイン）。大文字と小文字は区別されません。
            </td>

            <td>
              `"octocat"`
            </td>
          </tr>

          <tr>
            <td>
              **repo**
            </td>

            <td>
              必須
            </td>

            <td>
              弦
            </td>

            <td>
              .gitを含まないリポジトリ名サフィックス。大文字と小文字は区別されません。

            <td>
              `"Hello-World"`
            </td>
          </tr>

          <tr>
            <td>
              **title**
            </td>

            <td>
              必須
            </td>

            <td>
              弦
            </td>

              問題のタイトル。
            </td>

              `"Production issue detected"`
            </td>
          </tr>

          <tr>
            <td>
              **body**
            </td>

            <td>
              オプション
            </td>

            <td>
              弦
            </td>

            <td>
              GitHub-flavored Markdown形式のIssueの本文。空の場合、リクエストから省略されます。
            </td>

            <td>
              `"Steps to reproduce: ..."`
            </td>
          </tr>

          <tr>
            <td>
              **assignees**
            </td>

            <td>
              オプション
            </td>

            <td>
              リスト
            </td>

            <td>
              割り当てるGitHubユーザー名。トークンに対するプッシュアクセスが必要です。GitHub APIは、プッシュアクセス権のないユーザーを警告なしにドロップします。
            </td>

            <td>
              `["octocat"]`
            </td>
          </tr>

          <tr>
            <td>
              **labels**
            </td>

            <td>
              オプション

            </td>

            <td>

            </td>

              `3`

            </td>

            <td>
              `"Bug"`
            </td>
          </tr>

          <tr>
            <td>

            </td>

      <table>
        <thead>
          <tr>
            <th>
              ワークフローの例
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: github_create_issue_workflow
              description: Create a GitHub issue
              steps:
                - name: create_issue
                  type: action
                  action: gitHub.issue.create
                  version: 1
                  inputs:
                    token: ${{ :secrets:github-PAT-token }}
                    owner: your_user_name
                    repo: test-workflow
                    title: Production issue detected
                    body: An issue has been detected and needs investigation.
                    assignees:
                      - your_user_name
                    labels:
                      - incident
                    milestone: 3
                  next: end
              ```
            </td>
