Azure Cosmos DBアクションを使用すると、ワークフローから直接、Azure Cosmos DB内のドキュメントやデータベースの読み取り、書き込み、管理を行うことができます。すべてのアクションは、Azure ADサービスプリンシパルを使用して認証を行い、Cosmos DBデータプレーンと通信します。

## アイテムの取得 [#azure-cosmos-getitem]

## アイテムの更新 [#azure-cosmos-updateitem]
