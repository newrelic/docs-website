アクション識別子は`newrelic.alerts.listCompoundConditions`です。

オプションのIDフィルタリングとカーソルベースのページネーションを使用して、アカウントの複合アラート条件を一覧表示します。複合条件は個別のgetアクションでは利用できません — これは、そのコンポーネント構造を表示する唯一のアクションです。

                - name: listCompoundConditions
                  type: action
                  action: newrelic.alerts.listCompoundConditions
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    selectors:
