オープンなNew Relic集計Intelligenceの問題を確認します。

前提条件については、[New Relic Issueアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/issue/newrelic-issue#prerequisites)をご覧ください。

## 問題の認識

アクション識別子は`newrelic.issue.acknowledge`です。

オープンなNew Relicイシュー（AI Issues）を承認し、`ACKNOWLEDGED`としてマークします。New Relicは、ミューテーションの副作用として、誰が承認したかとイシューレコード（`acknowledgedBy` / `acknowledgedAt`）のタイムスタンプを記録します。`newrelic.nerdgraph.execute`上に構築されています。
