このページでは、ワークフロー自動化アクションカタログで利用可能なAWS Resource Groups Tagging APIアクションのリファレンスを提供します。これらのアクションを使用して、複数のサービスにわたるAWSリソースのタグを取得、追加、更新、削除します。

## 前提条件

前提条件と認証情報のセットアップについては、[AWS認証情報のセットアップ](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials)をご覧ください。

## ARNによるタグの取得

アクション識別子は`aws.resourceGroupsTaggingApi.getResourceTags`です。

ARNで指定された1つ以上のAWSリソースのタグを返します。

<Callout variant="important">
  `resourceArnList`を`tagFilters`、`resourceTypeFilters`、またはページネーション入力と組み合わせることはできません。AWSは、その組み合わせを`InvalidParameterException`で拒否します。タグまたはタイプでリソースを検索するには、代わりに[`aws.resourceGroupsTaggingApi.getResourcesByTag`](#get-resources-by-tag)を使用してください。
</Callout>

## タグによるリソースの取得

アクション識別子は`aws.resourceGroupsTaggingApi.getResourcesByTag`です。

タグのキーの値および/またはリソースタイプでAWSリソースを検索します。タグが付けられたリソースのみを返します。

<Callout variant="important">
  同じ呼び出しで`tagFilters`または`resourceTypeFilters`を`resourceArnList`と組み合わせることはできません。AWSは`InvalidParameterException`でその組み合わせを拒否します。特定のARNのタグを取得するには、代わりに[`aws.resourceGroupsTaggingApi.getResourceTags`](#get-tags-by-arn)を使用してください。
</Callout>

## リソースにタグを追加または更新します

アクション識別子は`aws.resourceGroupsTaggingApi.tagResources`です。

1回の呼び出しで、複数のサービスにわたる1～20個のAWSリソースに最大50個のタグを追加または更新します。

<Callout variant="important">
  アクションは、トップレベルのエラーとしてではなく、`response.FailedResourcesMap`でARNごとの部分的な失敗を報告します。バッチ内の1つのARNが失敗しても呼び出し全体が失敗するわけではないため、`success`が`true`の場合でも`response.FailedResourcesMap`を確認してください。
</Callout>

## リソースからタグを削除

アクション識別子は`aws.resourceGroupsTaggingApi.untagResources`です。

1回の呼び出しで、複数のサービスにわたる最大20個のAWSリソースから1つ以上のタグを削除します。リソースに存在しないタグキーを削除しても、エラーなしで成功します。

<Callout variant="important">
  アクションは、トップレベルのエラーとしてではなく、`response.FailedResourcesMap`でARNごとの部分的な失敗を報告します。バッチ内の1つのARNが失敗しても呼び出し全体が失敗するわけではないため、`success`が`true`の場合でも`response.FailedResourcesMap`を確認してください。

**ワークフローの例**

```yaml
name: remove-tags-from-resources
description: 'Remove tags from AWS resources'
steps:
  - name: untagResources
    type: action
    action: aws.resourceGroupsTaggingApi.untagResources
    version: '1'
    inputs:
      awsRoleArn: "arn:aws:iam::123456789012:role/my-workflow-role"
      region: "us-east-2"
      resourceArnList:
        - "arn:aws:sqs:us-east-2:123456789012:my-queue"
      tagKeys:
        - Environment
      selectors:
        - name: failedResources
          expression: ".response.FailedResourcesMap"
    next: end
```
