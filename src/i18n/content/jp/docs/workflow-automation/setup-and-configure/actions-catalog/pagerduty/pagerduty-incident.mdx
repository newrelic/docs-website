このページでは、ワークフロー自動化アクションカタログで利用可能なすべてのPagerDutyインシデントアクションのリファレンスを提供します。これらのアクションを使用すると、ワークフローから直接PagerDutyインシデントを作成、取得、一覧表示、更新、解決できます。

## 前提条件

ワークフロー自動化でPagerDutyアクションを使用する前に、以下が必要です：

* インシデントを管理するための適切な権限を持つPagerDutyアカウント。
* PagerDuty APIトークン（ユーザートークンまたはアカウントトークン）。
* リクエストを行うユーザーの`from`メールアドレス（関連するアクションのアカウントトークンに必要）。
