このページでは、ワークフロー自動化アクションカタログで利用可能な**Run Autopilot**アクション（`newrelic.autopilot.run`）のリファレンスを提供します。

## Autopilotを実行 [#newrelic-autopilot-run]

New Relic Autopilotを実行します — アラートを分析し、潜在的な根本原因を調査し、修復アクションを提案するAIエージェントです。ワークフローエディタのアクションカタログから**Run Autopilot**を選択します — エージェントIDを指定する必要はありません。

    <TabsPageItem id="runautopilotexample">
      ```yaml
      name: demo-run-autopilot
      description: Run Autopilot to analyze an issue
      steps:
        - name: runAutopilot
          type: action
          action: newrelic.autopilot.run
          version: '1'
          inputs:
            prompt: Summarize recent alert activity for my account
            context:
              - description: accountId
                value: "12345678"
              - description: slack_channel_id
                value: "CXXXXXXXXX"
            selectors:
              - name: success
                expression: .success
              - name: error
                expression: .errorMessage
              - name: response
                expression: .response
      ```
