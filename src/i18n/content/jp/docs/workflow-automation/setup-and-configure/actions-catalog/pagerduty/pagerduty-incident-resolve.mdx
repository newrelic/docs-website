## PagerDutyを解決する

アクション識別子は`pagerduty.incident.resolve`です。

ステータスを`resolved`に更新し、任意の解決メモを付けてPagerDutyのインシデントを解決します。

                  action: pagerduty.incident.resolve
                  version: 1
                  inputs:
                    token: ${{ :secrets:pagerdutyApiToken }}
                    from: abc@example.com
                    type: incident
                    incidentId: Q1234567890
