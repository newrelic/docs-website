設定可能なタイムアウトまで待機し、Slackメッセージの絵文字リアクションを取得します。

前提条件については、[Slackチャットアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/slack/slack-chat#prerequisites)を参照してください。

## メッセージの反応を取得する

アクション識別子は`slack.chat.getReactions`です。

Slackチャネルからメッセージのリアクションを取得します。

      **例：Slackメッセージのリアクションを取得する**

      <table>

            <td>
              ```yaml
              name: GetReactions

              steps:
                - name: getReactions
                  type: action
                  action: slack.chat.getReactions
                  version: 1
                  inputs:
                    token: ${{ :secrets:dn_staging_slack_token }}
                    channelID: ${{ .steps.promptUser.outputs.channelID }}
                    threadTs: ${{ .steps.promptUser.outputs.threadTs }}
                    timeout: ${{ .workflowInputs.timeout }}
                    selectors: ${{ .workflowInputs.selectors }}
              ```

              **入力:**

              ```json
              {
                "inputs": [
                  {
                    "key" : "channelID",
                    "value" : "C063JK1RHN1"
                  },
                  {
                    "key" : "threadTs",
                    "value" : "1718897637.400609"
                  },
                  {
                    "key" : "selectors",
                    "value" : "[{\"name\": \"reactions\", \"expression\": \".reactions \"}]"
                  }
                ]
              }
              ```

              **出力:**

              ```json
              [
                {
                  "name": "grinning",
                  "users": ["W222222"],
                  "count": 1
                },
                {
                  "name": "question",
                  "users": ["W333333"],
                  "count": 1
                }
              ]
              ```

              リアクションが追加される前にタイムアウトになった場合、出力は空のリストになります： `[]`
            </td>
