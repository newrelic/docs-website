アクション識別子は`newrelic.notification.sendSlack`です。

Destinationsと統合して、チャンネルにSlackメッセージを送信します。

      ## サポートされているブロックタイプ [#supported-block-types]

      `sendSlack` アクションは2つのブロックタイプのみをサポートし、検証時にそれ以外を拒否します。

      <table>
        <thead>
          <tr>
            <th>
              ブロックタイプ
            </th>

            <th>
              説明
            </th>

            <th>
              許可されたキー
            </th>

            <th>
              例
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              `section`
            </td>

            <td>
              テキストをレンダリングする唯一のブロックタイプです。

              `text`

              オブジェクトの

              `type`

              は

              `mrkdwn`

              または

              `plain_text`

              のいずれかである必要があり、

              `text`

              は空白以外の文字列である必要があります。
            </td>

            <td>
              `type`

              , 

              `text`
            </td>

            <td>
              `{"type":"section","text":{"type":"mrkdwn","text":"*Service:* checkout-api"}}`
            </td>
          </tr>

          <tr>
            <td>
              `divider`
            </td>

            <td>
              視覚的な水平線をレンダリングします。
            </td>

            <td>
              `type`
            </td>

            <td>
              `{"type":"divider"}`
            </td>
          </tr>
        </tbody>
      </table>

      詳細については、[Slack Block Kitリファレンス](https://api.slack.com/block-kit)および[Slack Block Kitビルダー](https://app.slack.com/block-kit-builder)をご覧ください。

                  version: '1'
                  inputs:
                    destinationId: xxxx-ed6f-xxxx-bc7d-b7ea982xxxx
                    channel: test-channel-workflow

                    - type: section
                      text:
                        type: mrkdwn
                        text: "Investigation complete"
