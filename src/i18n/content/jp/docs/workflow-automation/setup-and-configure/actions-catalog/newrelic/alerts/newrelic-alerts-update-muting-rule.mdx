アクション識別子は`newrelic.alerts.updateMutingRule`です。

既存のミュートルールを更新します。`accountId`と`id`を除くすべてのフィールドは任意です — 指定したフィールドのみが変更されます。

      次の例では、デプロイウィンドウの終了後にミューティングルールを無効にします。

      <table>
        <thead>
          <tr>
            <th>
              ワークフローの例
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: update_muting_rule
              description: Disable a muting rule
              steps:
                - name: updateMutingRule
                  type: action
                  action: newrelic.alerts.updateMutingRule
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    id: ${{ .workflowInputs.mutingRuleId }}
                    enabled: false
                  next: end
              ```
