GitHubのIssueをロックし、新しいコメントを追加できるユーザーを制限します。

認証のセットアップについては、[GitHub Issueアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-issue)を参照してください。

        <tbody>
          <tr>
            <td>
              ```yaml
              name: github_lock_issue_workflow
              description: Lock a GitHub issue
              steps:
                - name: lock_issue
                  type: action
                  action: gitHub.issue.lock
                  version: 1
                  inputs:
                    token: ${{ :secrets:github-PAT-token }}
                    owner: your_user_name
                    repo: test-workflow
                    issueNumber: 7
                    lockReason: resolved
                  next: end
              ```
