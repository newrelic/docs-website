GitHubリポジトリ内の既存のissue（タイトル、本文、状態、担当者、ラベル、およびマイルストーン）を更新します。

認証のセットアップについては、[GitHub Issueアクション](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-issue)を参照してください。

              ```yaml
              name: github_update_issue_workflow
              description: Update a GitHub issue
              steps:
                - name: update_issue
                  type: action
                  action: gitHub.issue.update
                  version: 1
                  inputs:
                    token: ${{ :secrets:github-PAT-token }}
                    owner: your_user_name
                    repo: test-workflow
                    issueNumber: 7
                    title: Issue has been resolved
                    body: Investigation complete. Closing this issue.
                    state: closed
                    state_reason: completed
                    labels:
                      - resolved
                  next: end
              ```
