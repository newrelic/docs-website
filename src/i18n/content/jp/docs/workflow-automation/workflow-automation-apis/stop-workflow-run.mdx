実行中のワークフローを停止するには、`workflowAutomationStopWorkflowRun` ミューテーションを使用します。

<thead>

<th>

</tr>

</td>

<td>

（必須）アカウントID。
</td>
</tr>

<tr>
<td>
`runId`
</td>

<td>
弦
</td>

<td>
（必須）停止するワークフロー実行の一意の識別子です。`StartWorkflowRun` APIから取得します。
</td>
</tr>

## サンプルリクエスト [#sample-request]

```graphql
mutation {
  workflowAutomationStopWorkflowRun(
    accountId: 12345678
    runId: "7ffbe082-8efa-4d3d-901a-a08bcf22bcd3"
  ) {
    runId
  }
}
```

## サンプル回答 [#sample-response]

突然変異により以下が返されます:

* `runId`: 停止されたワークフロー実行の一意の識別子。ワークフローが見つからない場合は空の`runId`を返します。
