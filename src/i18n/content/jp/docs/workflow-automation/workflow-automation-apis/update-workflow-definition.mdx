既存のワークフロー定義を更新するには、`workflowAutomationUpdateWorkflowDefinition`ミューテーションを使用します。ワークフロー定義がまだ存在しない場合は、エラーを返します。

## サンプルリクエスト [#sample-request]

```graphql
  mutation {
    workflowAutomationUpdateWorkflowDefinition(
      definition: {yaml: "<workflow definition YAML>"}
      scope: {id: "12345678", type: ACCOUNT}
    ) {
      definition {
        name
        version
        yaml
      }
    }
  }
```

## サンプル回答 [#sample-response]

突然変異により以下が返されます:

* `definition.name`: 更新されたワークフロー定義の名前
* `definition.version`: ワークフロー定義の新しいバージョン番号
* `definition.yaml`: base64エンコードされたワークフロー定義YAML
