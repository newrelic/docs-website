指定された名前のワークフロー定義のすべてのバージョンを削除するには、`workflowAutomationDeleteWorkflowDefinition`ミューテーションを使用します。

<Callout variant="important">
* 定義を削除するには、それを使用しているスケジュールが存在しない必要があります。定義が現在スケジュールによって使用されている場合、削除は失敗し、エラーが返されます。
* 定義が削除されても、実行中のすべてのワークフロー実行は完了するまで続行されます。
</Callout>

## サンプルリクエスト [#sample-request]

```graphql
mutation {
  workflowAutomationDeleteWorkflowDefinition(
    definition: {name: "my-workflow"}
    scope: {id: "12345678", type: ACCOUNT}
  ) {
    definition {
      name
    }
  }
}
```
