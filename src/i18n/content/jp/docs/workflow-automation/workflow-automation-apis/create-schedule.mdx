ワークフロー定義のスケジュールを作成するには、`workflowAutomationCreateSchedule` ミューテーションを使用してください。

<Callout variant="tip">
スケジュールの数と特定のスケジュールの最小期間は、[ワークフローシステムの制限](/docs/workflow-automation/limitations-and-faq/workflow-limits)で定義されています。
</Callout>

### logLevelオプション [#loglevel-option]

`logLevel`オプションは、ワークフロー実行中に生成されるログ情報の量を制御します。

* `NONE` （デフォルト）：ログは出力されません。
* `INFO`：ステップレベルの情報を出力します。
* `DEBUG`：`workflowAutomation.inputs.<inputName>: <inputValue>`の形式を使用して、すべてのアクションステップの入力を含む属性をステップ開始ログに追加します。
* `TRACE`：`DEBUG`の出力に加えて、すべてのアクションステップの出力を含む属性を、`workflowAutomation.outputs.<outputName>: <outputValue>`の形式を使用してステップ開始ログに追加します。

## サンプルリクエスト [#sample-request]

ワークフローの作成・編集には、書き込み[ビルダー](https://one.newrelic.com/nerdgraph-graphiql?state=b8f3b3a9-8d3e-c03e-5da4-34b98a57ff8f)を使用します。 [NerdGraph API エクスプローラー](/docs/apis/nerdgraph/get-started/nerdgraph-explorer)を参照してください。

```graphql
  mutation {
    workflowAutomationCreateSchedule(
      scope: {id: "12345678", type: ACCOUNT}
      definition: {name: "healthyHeartbeat", version: 1}
      cronExpression: "0 0 * * *"
      timezone: "Asia/Kolkata"
      options: {logLevel: DEBUG}
      tags: [{key: "environment", values: ["production"]}]
    ) {
      scheduleId
    }
  }
```
