スケジュールを取得して返すには、`workflowAutomation.schedule`クエリを使用します。

</td>

<td>
弦

## サンプルリクエスト [#sample-request]

```graphql
    {
      actor {
        account(id: 12345678) {
          workflowAutomation {
            schedule(id: "schedule-id") {
              id
            }
          }
        }
      }
    }
```

## サンプル回答 [#sample-response]

クエリは次を返します:

* `schedule.id`: スケジュールの一意の識別子。
