[Workflow Automation dashboard \[Workflow Automationダッシュボード\]](https://onenr.io/0gR7XE8LXjo)は、アカウント内のすべてのワークフローを表示、管理、およびモニターするための一元的な場所を提供します。ダッシュボードを使用して、設定の編集、バージョン履歴の追跡、実行スケジュールの管理、および失敗のトラブルシューティングを行います。ワークフローを管理するには、アカウント内に少なくとも1つのワークフローがあり、編集および削除の権限が必要です。

<Callout variant="important">
**ワークフロー自動化を無効にしますか?**機能制御管理 (FCM) を通じてワークフロー オートメーションをオフにする予定がある場合は、スケジュールされたすべてのワークフローが最初に削除されていることを確認してください。 詳細な手順については、 [「ワークフロー自動化の無効化」](/docs/workflow-automation/troubleshooting#disabling-workflow-automation-fcm)を参照してください。
</Callout>

**ワークフローは初めてですか?**最初のワークフローを構築するには、 [「テンプレートの使用」](/docs/workflow-automation/create-a-workflow-automation/use-a-template)または[「独自のワークフローの作成」](/docs/workflow-automation/create-a-workflow-automation/create-your-own)から始めます。

## ワークフローを表示 [#view-workflows]

<DNT>**All Capabilities &gt; Workflow Automation**</DNT>に移動します。アカウントにワークフローがない場合、ダッシュボードには最初のワークフローを作成するオプションとともに空の状態が表示されます。

### ダッシュボードタブ

ワークフローを作成すると、ダッシュボードに 2 つのタブが表示されます。

<DNT>**Summary tab**</DNT> (デフォルト): アカウントレベルのメトリクスとビジュアライゼーションを表示します。

<DNT>**Top metrics**</DNT>：

* <DNT>**Total workflows**</DNT>：アカウント内のすべてのワークフローの数
* <DNT>**Total number of steps executed**</DNT>: すべてのワークフロー実行の累積ステップ数
* <DNT>**Currently running workflows**</DNT>: アクティブな実行数

<DNT>**Performance charts**</DNT>：

* <DNT>**Total run count of all workflows**</DNT>: 時間の経過に伴うワークフローの実行傾向を示す折れ線グラフ
* <DNT>**Top 5 most frequently run workflows**</DNT>: 実行数が最も多いワークフローを表示するバーチャート
* <DNT>**Ratio of completed to failed workflows**</DNT>: 成功と失敗の割合および数を示す円グラフ

<DNT>**Recently failed runs table**</DNT>: 失敗したワークフローの実行を次の列で表示します：

* <DNT>**Workflow**</DNT>：失敗したワークフローの名前
* <DNT>**Version**</DNT>: 失敗したワークフローバージョン
* <DNT>**Failed on**</DNT>: 失敗のタイムスタンプ
* <DNT>**Run ID**</DNT>: 失敗した実行の一意の識別子
* <DNT>**Failed step**</DNT>: 失敗が発生したステップ
* <DNT>**Error message**</DNT>: エラーの説明

各チャートウィジェットには、クエリの表示、画像の取得、またはアラート条件の作成を行うためのコンテキストメニュー（3つのドット）が含まれています。

<img title="Image of the summary tab in the Workflow Automation dashboard showing account-level metrics and visualizations" alt="Image of the summary tab in the Workflow Automation dashboard showing account-level metrics and visualizations" src="/images/workflow-automation-summary-tab.webp" />

<DNT>**Workflows tab**</DNT>：

<DNT>**Search**</DNT>: <DNT>**Search in all fields**</DNT>バーを使用して、任意の列の値でワークフローを検索します。

<DNT>**All workflows table**</DNT> 次の列を表示します：

* <DNT>**Favorite**</DNT> （星アイコン）：ワークフローをお気に入りとしてマークします
* <DNT>**Name**</DNT>: ワークフロー識別子
* <DNT>**Description**</DNT>：ワークフローの目的または機能
* <DNT>**Last run on**</DNT>: 最新の実行のタイムスタンプ
* <DNT>**Last run status**</DNT>：実行結果（色付きバッジとして表示：完了の場合は緑、失敗の場合は赤）
* <DNT>**Latest version**</DNT>: 現在のバージョン番号
* <DNT>**Created on**</DNT>: ワークフローが作成された日付
* <DNT>**Actions menu**</DNT> （3つの点）：ワークフロー操作にアクセスします

表内の空の値は次のように表示されます。 `—`

<DNT>**Row actions menu**</DNT> （ワークフローの横にある3つの点をクリック）：

* <DNT>**Run**</DNT>: ワークフローをすぐに実行する
* <DNT>**Schedule**</DNT>: スケジュールされた実行を作成します
* <DNT>**Open in editor**</DNT>: ワークフロー設定を変更する
* <DNT>**Duplicate**</DNT>：ワークフローのコピーを作成する
* <DNT>**Delete**</DNT>: ワークフローを完全に削除します

ワークフロー名をクリックすると、詳細なメトリクス、実行履歴、スケジュール、ログを含む[エンティティ概要ページが](/docs/workflow-automation/manage-workflows/workflow-entity-overview)表示されます。

## ワークフローを編集する [#edit-a-workflow]

ワークフローの名前、説明、または設定を更新します。

1. 編集したいワークフローを見つけます

2. ワークフロー名の横にある省略記号（縦に3つの点）をクリックします

3. 選択する <DNT>**Open in editor**</DNT>

4. 次のいずれかを更新します。

   * <DNT>**Name**</DNT> — ワークフロー識別子
   * <DNT>**Description**</DNT> — ワークフローの目的または機能
   * <DNT>**Configuration**</DNT> — パラメーター、アクション、またはロジックを入力

5. クリック <DNT>**Save**</DNT>

[エンティティの概要ページ](/docs/workflow-automation/manage-workflows/workflow-entity-overview)から<DNT>**Edit**</DNT>ボタンをクリックしてエディターにアクセスすることもできます。

## バージョンを管理する [#manage-versions]

ワークフローの自動化により、ワークフロー定義を更新するたびに新しいバージョンが自動的に作成されます。以前のすべてのバージョンは参照用として引き続き利用可能であり、エディタから直接表示または実行できます。

### エディターでバージョン履歴を表示します [#view-version-history]

エディタから離れることなく、ワークフローの以前のすべてのバージョンを参照できます。

1. エディターでワークフローを開きます
2. エディターのツールバーで<DNT>**version dropdown**</DNT>をクリックします
3. リストから以前のバージョンを選択します

選択したバージョンがエディター内の<DNT>**read-only preview**</DNT>で開きます。設定を確認して実行することはできますが、直接編集することはできません。

### 以前のバージョンから新しいバージョンを作成する [#edit-as-new-version]

以前のバージョンを新しい編集のベースとして使用する場合：

1. エディターでワークフローを開き、バージョンドロップダウンから以前のバージョンを選択します
2. クリック <DNT>**Edit as new version**</DNT>
3. 変更を行います。
4. クリック <DNT>**Save**</DNT>

システムは、現在の最高バージョン+1の番号が付けられた新しいバージョンを作成します。たとえば、v5が最新でv2を編集した場合、結果はv6になります。以前のバージョンは上書きされません。

変更を取り消す場合は、<DNT>**Cancel**</DNT>をクリックして進行中の編集を破棄してください。新しいバージョンは保存されず、ワークフローリストに戻ります。

### バージョンを比較する [#compare-versions]

エディターでは、バージョン比較ビューを利用できます。これを使用して、実行またはビルド元にするバージョンを決定する前に、ワークフローの任意の2つのバージョン間の違いを確認します。

### スケジュール用のバージョン固定

ワークフローをスケジュールする際は、特定のバージョンにピン留めする必要があります。そのピン留めされたバージョンは、後でワークフロー定義を更新した場合でも実行されます。

**開始およびスケジュールワークフローはバージョン固定をサポートします。**

* ワークフローをスケジュールするときに、実行するバージョンを指定します
* ワークフロー実行を手動で開始する場合は、実行するバージョンを選択します
* スケジュールを更新する際は、使用する新しいバージョンを指定してください。

これにより、次のことが可能になります。

* 実行スケジュールに影響を与えずにワークフローを更新する
* スケジュールを更新する前に新しいバージョンを手動でテストする
* 生産ワークフローの安定性を維持する

## ワークフローを複製する [#duplicate-a-workflow]

元のワークフローをそのまま保持しながら、テンプレートまたは既存のワークフローを別の目的に適応させる必要がある場合は、ワークフローを複製します。

1. 複製したいワークフローを見つけます
2. 省略記号（縦に3つの点）をクリックします
3. 選択する <DNT>**Duplicate**</DNT>
4. システムは名前に**（Copy）**を付加したコピーを作成します
5. 複製したワークフローの名前を変更し、ニーズに合わせてカスタマイズします

**一般的な重複シナリオ:**

* 特定のユースケースに合わせてワークフローテンプレートを調整する
* 同様の要件を持つ別のチーム用のワークフローを作成する
* オリジナルを維持しながら大幅な変更を試みる

<Callout variant="important">
**バージョン管理のためにワークフローを複製しないでください** — システムがこれを自動的に行います。バージョン管理やロールバックの目的でのみワークフローを複製すると、ワークフローの制限に達する可能性があります。自動バージョン管理については、[「バージョンの管理」](#manage-versions)をご覧ください。
</Callout>

## ワークフローを削除する [#delete-a-workflow]

不要になったワークフローを削除します。

1. 削除したいワークフローを見つけます
2. その他のオプションメニュー（縦に3つの点）をクリックします
3. 選択する <DNT>**Delete**</DNT>
4. ダイアログボックスで削除を確認します

<Callout variant="caution">
ワークフローは完全に削除されます。元に戻すことはできません。すべてのバージョンと実行履歴が削除されます。後でワークフローが必要になる可能性がある場合は、削除するのではなく非アクティブ化することを検討してください。
</Callout>

**削除されるもの:**

* ワークフローのすべてのバージョン
* すべての実行履歴とログ
* ワークフローに関連付けられたすべてのスケジュール実行

**削除する前に、次の点を確認してください。**

* このワークフローに依存する重要な自動化はありません
* 後で必要になるかもしれないので、バックアップコピーを用意しておく
* スケジュールされたすべての実行を特定して把握します
