Node.jsアプリケーションの監視を開始するには、New Relic Node.jsエージェントをインストールしてください。左側のナビゲーションから、環境に合った方法を選択してください。

インストレーションを完了するには、[New Relicアカウント](https://newrelic.com/signup)と<InlinePopover type="licenseKey" />が必要です。始める前に、[Node.jsエージェントの互換性と要件](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent)をご覧ください。

| メソッド                                                                                                                             | 使用する場面                                                             |
| -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| [Standard（npm）](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent)                                   | ほとんどのNode.jsアプリケーション — npm経由でインストールし、次を使用して読み込みます `-r newrelic`    |
| [Docker](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent-docker)                                   | コンテナ化されたNode.jsアプリケーション                                            |
| [Azure App Service（Windows）](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent-azure-site-extension) | New Relicサイト拡張機能を使用してAzure App Service for Windowsにデプロイされたアプリケーション |
