Node.jsエージェントは、[npmリポジトリ](https://npmjs.org/package/newrelic)と[GitHub](https://github.com/newrelic/node-newrelic)で公開されています。

Dockerを使用する場合は、[DockerでのNode.jsエージェントのインストール](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent-docker)をご覧ください。
</Callout>

<Steps>
<Step>
## エージェントのインストール [#install]

アプリケーションディレクトリにエージェントパッケージをインストールしてください。

```bash
npm install newrelic
```

<Callout variant="important">
Next.jsを使用している場合は、[Next.jsハイブリッドエージェントインストゥルメンテーションガイド](/docs/apm/agents/nodejs-agent/extend-your-instrumentation/nextjs-instrumentation/)を参照してください。
</Callout>

次に、パッケージからデフォルトの設定ファイルをアプリケーションのルートにコピーします。

```bash
cp node_modules/newrelic/newrelic.js .
```
</Step>

<Step>
## エージェントの設定 [#configure]

アプリケーションのルートにある`newrelic.js`を開きます。本番環境に移行する前に、次の2つの設定を**必ず**変更してください。

1. `license_key`に<InlinePopover type="licenseKey" />を設定してください。
2. `app_name`にわかりやすいアプリケーション名を設定してください。

```js
exports.config = {
  app_name: ['Your Application Name'],
  license_key: 'YOUR_LICENSE_KEY',
  // ...
}
```

ファイルを編集する代わりに、環境変数を使用してこれらを設定することもできます。

```bash
NEW_RELIC_APP_NAME="Your Application Name"
NEW_RELIC_LICENSE_KEY="YOUR_LICENSE_KEY"
```
</Step>

<Step>
## エージェントを起動する [#start]

起動コマンドに`-r newrelic`を追加して、他の`require`ステートメントの前にエージェントをロードします。

```bash
node -r newrelic ./your-app.js
```

アプリケーションがESMを使用している場合は、`--import newrelic/esm-loader.mjs`オプションを追加します。

```bash
node --import newrelic/esm-loader.mjs -r newrelic ./your-app.js
```

Next.jsアプリケーションの場合は、`NODE_OPTIONS='-r newrelic' next start`経由でエージェントを読み込みます。

Nest.jsで`nest start`コマンドを使用してアプリケーションを起動する場合は、起動バイナリを「`nest start --exec 'node -r newrelic'`」と変更してNew Relicエージェントを読み込みます。[Nest.jsアプリケーションの例はこちら](https://github.com/newrelic/newrelic-node-examples/tree/main/nestjs)。
</Step>

<Step>
## データが送信されていることを確認する [#verify]

エージェントのバージョンが14.9.0以上の場合は、このコマンドを実行して設定を検証できます。

```bash
npx newrelic validate-config --config-file ./newrelic.js
```

1. アプリケーションに少なくとも2つのリクエストを送信します。

2. 2～3分待ってから、[one.newrelic.com &gt; APM](https://one.newrelic.com/apm)を開き、アプリケーション名で検索します。

<Callout variant="tip">
アプリケーションが表示されない場合は、[Node.jsインストレーションのトラブルシューティング](/docs/apm/agents/nodejs-agent/troubleshooting/troubleshooting-your-nodejs-installation)をご覧ください。
</Callout>
</Step>
</Steps>
