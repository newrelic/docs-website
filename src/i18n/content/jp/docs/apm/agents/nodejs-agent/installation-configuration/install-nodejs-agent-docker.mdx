<Steps>
<Step>
## アプリケーションにエージェントを追加します。 [#install]

`newrelic`を`package.json`に追加します。

```json
"newrelic": "latest"
```

次に、エージェントをロードするようにDockerfileまたは起動コマンドを更新します。その方法は、アプリケーションがCommonJSとESMのどちらを使用しているかによって異なります：

<CollapserGroup>
<Collapser id="docker-cjs" title="CommonJSを使用するアプリ">
* `ENTRYPOINT`

  ```bash
  ENTRYPOINT ["node", "-r", "newrelic", "YOUR_PROGRAM.js"]
  ```

* `CMD`

  ```bash
  CMD ["node", "-r", "newrelic", "YOUR_PROGRAM.js"]
  ```

* 次のようなnpmスクリプト `npm start`

  ```bash
  npm pkg set scripts.start="node -r newrelic your-program.js"
  ```
</Collapser>

<Collapser id="docker-esm" title="ESMを使用するアプリ">
* `ENTRYPOINT`

  ```bash
  ENTRYPOINT ["node", "--import", "newrelic/esm-loader.mjs", "-r", "newrelic", "YOUR_PROGRAM.js"]
  ```

* `CMD`

  ```bash
  CMD ["node", "--import", "newrelic/esm-loader.mjs", "-r", "newrelic", "YOUR_PROGRAM.js"]
  ```

* 次のようなnpmスクリプト `npm start`

  ```bash
  npm pkg set scripts.start="node --import newrelic/esm-loader.mjs -r newrelic your-program.js"
  ```
</Collapser>
</CollapserGroup>

<Callout variant="important">
`-r`フラグを使用できない場合は、アプリのメインモジュールの**先頭行**に`require('newrelic')`を追加してください。Babelやその他のトランスパイラーでは、このアプローチを使用しないでください。計装の問題が発生します。
</Callout>
</Step>

<Step>
## エージェントを構成します [#configure]

コンテナを実行する際に、アプリ名とライセンスキーを環境変数として渡します。必須の設定はこれらのみです：

```bash
docker run -e NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
           -e NEW_RELIC_APP_NAME="Your Application Name" \
           YOUR_IMAGE_NAME:latest
```

Dockerfile内の`ENV`ディレクティブを使用して設定を行うこともできます：

```dockerfile
ENV NEW_RELIC_APP_NAME="Your Application Name"
```

その他のすべての設定オプションについては、[Node.jsエージェント設定](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration)を参照してください。
</Step>

<Step>
## データが流れていることを確認します [#verify]

コンテナをビルドして実行し、アプリケーションに少なくとも2つのrequestsを送信してください。2～3分待ってから、[one.newrelic.com &gt; APM](https://one.newrelic.com/apm)を開き、名前でアプリを探してください。

<Callout variant="tip">
アプリが表示されませんか？[Node.jsインストレーションのトラブルシューティング](/docs/apm/agents/nodejs-agent/troubleshooting/troubleshooting-your-nodejs-installation)をご覧ください。
</Callout>
</Step>
</Steps>
