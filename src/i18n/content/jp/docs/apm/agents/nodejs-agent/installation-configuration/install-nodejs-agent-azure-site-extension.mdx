New Relic Azure Site Extensionを使用して、WindowsのAzure App ServiceにNew Relic Node.jsエージェントをインストールします。

<Callout variant="important">
このメソッドは、コードとしてのみデプロイされた**Windowsベース**のAzure App Serviceアプリケーションを対象としています。AzureのLinuxコンテナについては、標準の[npm installメソッド](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent)を使用し、アプリ設定として`NEW_RELIC_LICENSE_KEY`を渡してください。手動でデプロイされたLinuxベースのアプリケーションについては、[Microsoft Azure App ServicesのNode.jsエージェント](/docs/apm/agents/nodejs-agent/hosting-services/nodejs-agent-microsoft-azure)を参照してください。

Windows 32で実行されるアプリケーションの場合、コードレベルメトリクスの完全なサポート（ファイルパス、行、列）は利用できません — プロファイリングは関数名のみにフォールバックします。
</Callout>

<Steps>
<Step>
## サイト拡張機能のインストール [#install]

1. Azureホームページから、**App Services** \[App Services] をクリックし、ターゲットアプリケーションを選択します。
2. 左側のメニューで、**Development Tools** \[開発ツール]の下にある**Extensions** \[拡張機能]を選択します。
3. ページ上部の**+ Add** \[追加]をクリックし、ドロップダウンから**New Relic Node Agent** \[New Relic Nodeエージェント]を選択します。
4. 法的条項に同意し、**OK** をクリックしてください。

インストールされると、拡張機能は以下を作成します：

* 次の場所のエージェントファイルと依存関係 `C:\home\site\wwwroot\node_modules`
* アプリケーションの起動時に`NODE_OPTIONS=-r newrelic`を自動的に注入するXDT変換（`applicationHost.xdt`）
</Step>

<Step>
## エージェントを構成します [#configure]

アプリケーションの左側のメニューで、**Settings &gt; Environment variables** に移動し、次を追加してください：

| 設定                      | 価値                   |
| ----------------------- | -------------------- |
| `NEW_RELIC_LICENSE_KEY` | あなたのNew Relicライセンスキー |
| `NEW_RELIC_APP_NAME`    | New Relicに表示される名前    |

拡張機能は自動的に`NODE_OPTIONS`を`-r newrelic`に設定します。以前に定義された`NODE_OPTIONS`はリセットされます。その他のすべての設定オプションについては、[Node.jsエージェント設定](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration)を参照してください。
</Step>

<Step>
## データが流れていることを確認します [#verify]

アプリケーションを起動し、少なくとも2つのrequestsを送信します。2～3分待ってから、[one.newrelic.com &gt; APM](https://one.newrelic.com/apm)を開き、名前でアプリを探してください。

拡張機能のインストールに失敗した場合は、次の場所でログを確認してください：

```
C:\home\SiteExtensions\NewRelic.Azure.Websites.Extension.NodeAgent\install.log
```

エージェントがインストールされていてもデータが表示されない場合は、次を確認してください：

```
C:\home\site\wwwroot\newrelic_agent.log
```

<Callout variant="tip">
アプリが表示されませんか？[Node.jsインストレーションのトラブルシューティング](/docs/apm/agents/nodejs-agent/troubleshooting/troubleshooting-your-nodejs-installation)をご覧ください。
</Callout>
</Step>
</Steps>
