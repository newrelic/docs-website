Rubyエージェントはコードを自動的に計装するため、アプリケーションの監視を開始できます。

<Callout variant="tip">
Kubernetesで実行している場合、[Kubernetes APM自動アタッチ](/docs/kubernetes-pixie/kubernetes-integration/installation/k8s-agent-operator/)をご覧ください。
</Callout>

<Steps>
<Step>
## gemのインストール [#install]

RubyエージェントのgemをGemfileに追加します。

```ruby
gem 'newrelic_rpm'
```

次に、以下を実行します。

```sh
bundle install
```

<Callout variant="important">
Dockerコンテナでエージェントを使用している場合は、各コンテナにエージェントをインストールします。Dockerベースのデプロイメント例については、[DockerへのRubyエージェントのインストール](/docs/apm/agents/ruby-agent/installation/ruby-agent-installation-docker)をご覧ください。
</Callout>

**フレームワーク別の注意事項：**

* **Rails**：Railsは`Bundler.require`を自動的に呼び出すため、追加の手順なしで起動時に`newrelic_rpm`が読み込まれます。
* **RodaまたはSinatra**：アプリケーションから手動で`require 'newrelic_rpm'`を呼び出す必要があります。
* **その他のRackアプリケーション**：自動ブラウザ監視を使用するには、エージェントが提供する[Rackミドルウェア](/docs/agents/ruby-agent/frameworks/rack-middlewares#manual)を手動で追加してください。
</Step>

<Step>
## エージェントの設定 [#configure]

New RelicのGitHubリポジトリから[`newrelic.yml`](https://github.com/newrelic/newrelic-ruby-agent/blob/dev/newrelic.yml)をダウンロードし、アプリケーションの`config`ディレクトリにコピーします。

本番環境に移行する前に、次の2つの設定を**必ず**変更してください。

1. `license_key`に<InlinePopover type="licenseKey" />を設定してください。
2. `app_name`にわかりやすいアプリケーション名を設定してください。

または、CLIを使用して設定ファイルを生成してください。

```sh
bundle exec newrelic_rpm install --license_key="YOUR_LICENSE_KEY" "YOUR_APP_NAME"
```
</Step>

<Step>
## データが送信されていることを確認する [#verify]

1. Webサーバーを再起動します。

2. アプリケーションに少なくとも2つのリクエストを送信します。

3. 2～3分待ってから、[one.newrelic.com &gt; APM](https://one.newrelic.com/apm)を開き、アプリケーション名で検索します。

<Callout variant="tip">
アプリケーションが表示されない場合は、[データが表示されない（Ruby）](/docs/apm/agents/ruby-agent/troubleshooting/no-data-appears-ruby)をご覧ください。
</Callout>
</Step>
</Steps>
