## 問題

New Relic Ruby エージェント [をインストールし、トラフィックを発生させて 5 分間待っても、New Relic の UI にデータが表示されません。](/docs/agents/ruby-agent/installation-configuration/ruby-agent-installation)

## [解決](/docs/agents/ruby-agent/installation-configuration/ruby-agent-installation)

[欠損したデータのトラブルシューティングに](/docs/agents/ruby-agent/installation-configuration/ruby-agent-installation)

1. [](/docs/agents/ruby-agent/installation-configuration/ruby-agent-installation)
   [設定ファイルを確認してください。](/docs/agents/ruby-agent/installation-configuration/ruby-agent-installation)
   * [* 構成ファイルがアプリケーション ディレクトリ内の`config/newrelic.yml`にインストールされていることを確認してください。* 設定ファイルが有効なYMLであることを確認してください。](/docs/agents/ruby-agent/installation-configuration/ruby-agent-installation)
     [<InlinePopover type="licenseKey" />が事前に入力されたこのファイルのクリーンなコピーをダウンロードするには、 <DNT>****</DNT>](/docs/agents/ruby-agent/installation-configuration/ruby-agent-installation)**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; (user menu) &gt; Account settings &gt; Download a clean configuration file**にアクセスしてください。

2. Webサーバーを再起動します。

3. [New Relic Diagnostics](/docs/agents/manage-apm-agents/troubleshooting/new-relic-diagnostics)を使用すると、問題を自動的に特定できる場合があります。

4. `log/newrelic_agent.log`にあるエージェントのログ ファイルを調べて、アプリケーション サーバー プロセスの再起動時に表示されるエラーまたは警告を確認してください。このログ ファイルが存在しないか、書き込まれていない場合は、「[ログ ファイルがありません](/docs/agents/ruby-agent/troubleshooting/no-log-file-ruby)」を参照してください。

5. New Relic エージェントのログで、 `INFO : Reporting to:`の後に URL が続くエントリがないか確認してください。URL が、New Relic UI で表示しているアカウントとアプリケーションと一致していることを確認してください。

6. デプロイ先の環境で New Relic エージェントが起動するように設定されていることを確認します。詳しくは、 [Controlling when the Ruby agent starts](/docs/agents/ruby-agent/troubleshooting/controlling-when-ruby-agent-starts) をご覧ください。

7. `info`レベルで明らかなエラーがない場合は、[詳細なデバッグ ログを生成し](/docs/agents/ruby-agent/troubleshooting/generating-logs-troubleshooting-ruby)ます。

8. <DNT>**newrelic\_rpm**</DNT> gem の[最新バージョンへのアップデート](/docs/apm/agents/ruby-agent/installation/update-ruby-agent#Updating_the_Agent)をお試しください。

9. Rails 以外のものを使用している場合は、 `RACK_ENV`を、開発や運用など、 `newrelic.yml`ファイルに表示される環境に設定します。
