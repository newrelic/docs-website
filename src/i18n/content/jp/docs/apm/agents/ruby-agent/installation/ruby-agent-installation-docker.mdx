<Steps>
<Step>
## Gemfileにgemを追加してください [#install]

Rubyエージェントのgemを`Gemfile`に追加してください：

```ruby
gem 'newrelic_rpm'
```

`Dockerfile`はビルドの一部として`bundle install`を実行する必要があります：

```dockerfile
COPY Gemfile Gemfile.lock ./
RUN bundle install
```

**フレームワーク固有の注意事項：**

* **Rails**：Railsは`Bundler.require`を自動的に呼び出すため、追加の手順なしで起動時に`newrelic_rpm`が必要になります。
* **RodaまたはSinatra**：アプリケーションで手動で`require 'newrelic_rpm'`を呼び出す必要があります。
* **その他のRackアプリ**：自動ブラウザ監視を使用するには、エージェントが提供する[Rackミドルウェア](/docs/agents/ruby-agent/frameworks/rack-middlewares#manual)を手動で組み込んでください。
</Step>

<Step>
## エージェントを構成します [#configure]

コンテナを実行する際、アプリ名とライセンスキーを環境変数として渡してください — イメージ内にハードコードしないでください：

```bash
docker run -e NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
           -e NEW_RELIC_APP_NAME="Your Application Name" \
           YOUR_IMAGE_NAME:latest
```

`Dockerfile`内の`ENV`経由でこれらを設定することもできます：

```dockerfile
ENV NEW_RELIC_APP_NAME="Your Application Name"
```

その他のすべての設定オプションについては、[Rubyエージェント設定](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration)を参照してください。
</Step>

<Step>
## データが流れていることを確認します [#verify]

コンテナを実行し、アプリケーションに少なくとも2つのrequestsを送信してください。2～3分待ってから、[one.newrelic.com &gt; APM](https://one.newrelic.com/apm)を開き、名前でアプリを検索してください。

<Callout variant="tip">
アプリケーションが表示されませんか？[データが表示されない（Ruby）](/docs/apm/agents/ruby-agent/troubleshooting/no-data-appears-ruby)をご覧ください。
</Callout>
</Step>
</Steps>
