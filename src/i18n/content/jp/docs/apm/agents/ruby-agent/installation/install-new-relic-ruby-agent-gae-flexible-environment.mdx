<Steps>
<Step>
## gemをインストールしてアプリケーションを設定します。 [#install]

`newrelic_rpm` gemを`Gemfile`に追加します。

```ruby
gem 'newrelic_rpm'
```

次に、以下を実行します：

```sh
bundle install
```

<Tabs>
<TabsBar>
<TabsBarItem id="native-mode">ネイティブモード（RailsまたはSinatra）</TabsBarItem> <TabsBarItem id="docker-runtime">カスタムDockerランタイム</TabsBarItem>
</TabsBar>

<TabsPages>
<TabsPageItem id="native-mode">
GAEネイティブモードを使用する場合、アプリケーションコードと`app.yaml`を提供します。GAEは、標準の事前構築済みDockerイメージに自動的にデプロイします。追加のDockerfileは必要ありません。
</TabsPageItem>

<TabsPageItem id="docker-runtime">
アプリに特定のライブラリやヘッダーが必要な場合は、カスタムランタイムを使用してください。`Dockerfile`を作成し、`app.yaml`を次のように設定します：

```yaml
runtime: custom
env: flex
```

New Relicは、カスタムランタイム方式を推奨しています。また、Google App Engineにヘルスチェックを処理させることを推奨しています。
</TabsPageItem>
</TabsPages>
</Tabs>
</Step>

<Step>
## エージェントを構成します [#configure]

New RelicのGitHubリポジトリから[`newrelic.yml`](https://github.com/newrelic/newrelic-ruby-agent/blob/dev/newrelic.yml)をダウンロードし、アプリケーションの`config`ディレクトリにコピーします。

次の必須の2つの値を設定してください：

1. `license_key`を<InlinePopover type="licenseKey" />に設定してください。
2. `app_name`にアプリケーションのわかりやすい名前を設定してください。

その他のすべての設定オプションについては、[Rubyエージェント設定](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration)を参照してください。
</Step>

<Step>
## 導入・検証する [#verify]

`gcloud` CLIを使用してアプリをデプロイします：

```bash
gcloud app deploy
```

デプロイメントが完了するまで待ちます。少なくとも2回requestsを送信してから2～3分待ち、[one.newrelic.com&gt;APM](https://one.newrelic.com/apm)を開いてアプリを名前で検索してください。

<Callout variant="tip">
アプリケーションが表示されませんか？[データが表示されない（Ruby）](/docs/apm/agents/ruby-agent/troubleshooting/no-data-appears-ruby)をご覧ください。
</Callout>
</Step>
</Steps>
