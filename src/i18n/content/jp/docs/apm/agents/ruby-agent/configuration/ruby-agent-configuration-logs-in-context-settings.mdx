ログ転送、ローカルの装飾、ログイベントのカスタムアトリビュート、およびログメトリクスの収集を制御するには、Rubyエージェントのアプリケーションログ設定を構成してください。

## アプリケーションログ [#application-logging]

Ruby エージェントは[、コンテキスト内の APM ログを](/docs/apm/new-relic-apm/getting-started/get-started-logs-context)サポートします。Ruby エージェントのログを構成するためのヒントについて[は、コンテキストで Ruby ログを構成する](/docs/logs/logs-context/configure-logs-context-ruby)を参照してください。

使用可能なロギング関連の構成オプションには、次のものがあります。

New Relicに転送されるログイベントの最小レベルを設定します。指定した重大度以上のログが転送されます。たとえば、`debug`を指定するとすべてのログイベントが転送されますが、`error`を指定した場合は、`error`、`fatal`、`unknown`のイベントのみが転送されます。設定可能な値（重大度の低い順）：`debug`、`info`、`warn`、`error`、`fatal`、`unknown`（大文字と小文字は区別されません）。

この順番は、Rubyの`Logger::Severity`定数の整数値に準拠しています（[https://github.com/ruby/logger/blob/113b82a06b3076b93a71cd467e1605b23afb3088/lib/logger/severity.rb](https://github.com/ruby/logger/blob/113b82a06b3076b93a71cd467e1605b23afb3088/lib/logger/severity.rb)を参照してください）。
</Collapser>
