Rubyアプリケーションの監視を開始するには、New Relic Rubyエージェントをインストールしてください。左側のナビゲーションから、環境に合った方法を選択してください。

インストレーションを完了するには、[New Relicアカウント](https://newrelic.com/signup)と<InlinePopover type="licenseKey" />が必要です。開始する前に、[Rubyエージェントの要件とサポート対象のフレームワーク](/docs/apm/agents/ruby-agent/getting-started/ruby-agent-requirements-supported-frameworks)をご覧ください。

| メソッド                                                                                                                | 使用する場面                                                     |
| ------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| [Standard（Bundler/Gemfile）](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent)                  | ほとんどのRubyアプリケーション — Rails、Sinatra、Roda、Rack、その他のUNIXベースの環境 |
| [Railsプラグイン](/docs/apm/agents/ruby-agent/installation/ruby-agent-installation-rails-plugin)                         | レガシープラグインのインストール方法を使用するRails 2以降のアプリケーション                  |
| [Docker](/docs/apm/agents/ruby-agent/installation/ruby-agent-installation-docker)                                   | コンテナ化されたRubyアプリケーション                                       |
| [Heroku](/docs/apm/agents/ruby-agent/installation/ruby-agent-heroku)                                                | Herokuにデプロイされ、New Relicアドオンを使用しているアプリケーション                 |
| [Google App Engine](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent-gae-flexible-environment) | GAEフレキシブル環境で実行されているアプリケーション                                |
