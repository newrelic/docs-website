[Rack のミドルウェア](/docs/agents/ruby-agent/frameworks/rack-middlewares) は、Ruby agent version 3.9.0 以上で自動的にインストルメント化されます。

`NewRelic::Agent::Instrumentation::Rack`モジュールは、Rubyエージェントのバージョン4.0.0で削除されました。コードからこのモジュールへの参照を削除してください。詳細については、[インストゥルメントされたMetalコントローラー](/docs/agents/ruby-agent/frameworks/instrumenting-metal-controllers)を参照してください。
