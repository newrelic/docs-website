New Relic Javaエージェントによって自動的にインストゥルメントされたJavaアプリケーションでは、アプリケーションのコードを変更することなく、トランザクション、エラー、JVMのパフォーマンスを可視化できます。インストール後、数分以内にNew Relicプラットフォーム上でアプリのレスポンスタイム、スループット、エラー率、JVMの健全性を確認できます。Javaエージェントを使用して、パフォーマンスのボトルネックを見つけ、エラー発生時の状況を詳しく分析し、実際のトラフィック下でアプリケーションがどのように動作するかを把握できます。

## 機能 [#capabilities]

* **メトリクス** — アプリケーションおよびトランザクションごとに、レスポンスタイム、スループット、エラー率、Apdexスコア、JVMメトリクス（ヒープ、ガベージコレクション、スレッド数）
* **イベント** — NRQLでクエリ可能なトランザクションイベント、エラーイベント、およびカスタムイベント
* **ログ** — [Logs in Context](/docs/logs/logs-context/java-configure-logs-context-all/)を使ってトレースやエラーと関連付けられたアプリケーションログデータ
* **トレース** — サービス間のリクエストを関連付けるディストリビューティッド（分散）トレーシング、およびスロークエリのトランザクショントレースとSQLの実行計画
* **エンティティ** — アプリケーションはNew Relic内でサービスエンティティとして表示され、APM &amp; servicesおよびエンティティエクスプローラーで確認可能

## インストールパスの選択 [#choose]

* **アプリケーションサーバーおよびスタンドアロンJVM**（推奨） — Tomcat、Spring Boot、JBoss/WildFly、Glassfish、Jetty、WebLogic、WebSphere、および`-javaagent`引数を受け入れる任意のJVMの標準パス
* **Maven** — ビルドで既にMavenを使用している場合に使用します。エージェントは次を介して、ビルド依存関係としてダウンロードおよび展開されます： `maven-dependency-plugin`
* **Gradle** — ビルドで既にGradleを使用している場合に使用します。`de.undercouch.download`を利用したダウンロードタスクにより、エージェントが自動的に取得および展開されます
* **Azure App Service（Windows）** — JavaアプリケーションをAzure Windows App Serviceで実行している場合に使用します。New Relicサイト拡張機能で、起動スクリプトを変更することなくエージェントを挿入します
* **Docker** — コンテナ化されたJavaアプリケーションに使用します。`-javaagent`を次を介して渡します： `JAVA_TOOL_OPTIONS`
* **AWS Elastic Beanstalk** — Elastic Beanstalkに導入されたTomcatまたはJava SEアプリに使用します
* **Google App Engine** — カスタムDockerランタイムを介して、GAEフレキシブル環境で実行されているアプリに使用します
* **AWS Lambda** — 標準エージェントとは異なるインストールパスを使用します。[サーバーレス機能監視](/docs/serverless-function-monitoring/aws-lambda-monitoring/enable-lambda-monitoring/enable-serverless-monitoring-aws-lambda-legacy#java)をご覧ください

## ガイド付きインストレーション [#ui-install]

ガイド付きインストレーションは<DNT>**[one.newrelic.com](https://one.newrelic.com) → Integrations &amp; Agents → Java**</DNT>でご利用いただけます。UIは、ライセンスキーとアプリ名を事前に入力するガイド付きのエンドツーエンドのワークフローを提供します。

## インストレーションの概要 [#at-a-glance]

1. [互換性と要件](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent)を確認してください
2. エージェントファイルをダウンロードして配置します
3. ライセンスキーとアプリ名を使用してエージェントを設定してください
4. データがNew Relicに送信されていることを確認してください
