このページでは、カスタムDockerランタイムを使用して、[Google App Engine（GAE）フレキシブル環境](https://cloud.google.com/appengine/docs/flexible/java/)にNew Relic Javaエージェントをインストールする方法について説明します。

<Callout variant="important">
GAEスタンダード環境やGoogle App Engineの[「ネイティブモード」](https://cloud.google.com/appengine/docs/flexible/java/)は使用しないでください。Javaエージェントにはカスタムランタイムが必要です。
</Callout>

## 互換性と要件 [#requirements]

### サポート対象

* Java 8、11、17、21、24、25、および26 *（Java 7はエージェントv6.5.4以前でのみサポートされています）*
* カスタムDockerランタイムを備えたGoogle App Engineフレキシブル環境
* サポートされているフレームワークおよびライブラリのバージョン範囲については、[互換性および要件](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent)を参照してください

### サポートされていない

* GAEスタンダード環境 — カスタムランタイムが必要です；スタンダード環境はこれをサポートしていません。
* GAEネイティブモード — Javaエージェントにはカスタムランタイムが必要です
* 他のAPMエージェントとの並行稼働 — 同じJVM内で別のAPMエージェントがアクティブな場合、Javaエージェントは正しい動作を保証できません。

### 必要なこと

* New Relicアカウントおよび<InlinePopover type="licenseKey" />
* SHA-2（256ビット）SSLをサポートするJVM
* App Engine アプリケーションが作成された Google Cloud Platform プロジェクト（[Java 向け Google App Engine の手順](https://cloud.google.com/appengine/docs/flexible/java/managing-projects-apps-billing#create)を参照）
* `gcloud` CLI がインストールおよび初期化されていること（[Google Cloud SDK ドキュメント](https://cloud.google.com/sdk/gcloud/)を参照）
* [App Engine プラグイン](https://cloud.google.com/appengine/docs/flexible/java/using-maven)が構成された Maven または Gradle

## インストール [#install]

`newrelic-java.zip` をダウンロードし、プロジェクトに解凍してください：\[#install-step-1]

```bash
curl -O https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip
unzip newrelic-java.zip
```

カスタムランタイム用に`app.yaml`を設定してください：

```yaml
runtime: custom
env: flex
```

エージェントを追加し、`-javaagent` 引数を渡すように `Dockerfile` を設定します。以下の例ではTomcatを使用しています：

```dockerfile
ADD ./newrelic/newrelic.jar /usr/local/tomcat/newrelic/newrelic.jar
ENV JAVA_OPTS="$JAVA_OPTS -javaagent:/usr/local/tomcat/newrelic/newrelic.jar"
```

プロジェクトをビルドします：

```bash
mvn clean install
```

## 設定 [#configure]

`newrelic/newrelic.yml`を編集して、2つの必要な値を設定します：

1. `license_key`を<InlinePopover type="licenseKey" />に設定してください。
2. `app_name`にアプリケーションのわかりやすい名前を設定してください。

その他のすべての設定オプションについては、[Javaエージェント設定](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file)を参照してください。

## インストールの確認 [#verify]

GAEへのデプロイ：

```bash
gcloud --project YOUR_PROJECT_NAME app deploy
```

デプロイメントが完了するまで待ちます。少なくとも2つのrequestsを送信し、その後2～3分待つと、アプリが[APM &amp; サービス](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29)に表示されます。

5分経過してもデータが表示されない場合は、[データが表示されない（Java）](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java)を参照してください。
