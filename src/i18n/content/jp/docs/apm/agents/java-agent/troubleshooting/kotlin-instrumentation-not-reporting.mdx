## 問題

Kotlinアプリで計装が欠落している場合は、[エージェントのログをfinestレベルに設定](/docs/agents/java-agent/troubleshooting/generating-logs-troubleshooting-java)してください。

ログには`ArrayIndexOutOfBoundsException`が記載されている必要があります。エージェントバージョン8.2.0以降をご利用の顧客には、次のメッセージが表示されます：

```
Unexpected ArrayIndexOutOfBoundsException thrown during class transformation. Try restarting the Java Agent with flag -Dnewrelic.config.class_transformer.clear_return_stacks=true
```

## 解決

Javaエージェントのバージョンが8.20以降であることを確認してください。インストールされているバージョンが8.20より前の場合は、Javaエージェントをサポートされているバージョンにアップグレードしてください（最新バージョンを推奨します）。

システムプロパティを使用して、JavaエージェントまたはJavaアプリを再起動してください：

```
-Dnewrelic.config.class_transformer.clear_return_stacks=true
```
