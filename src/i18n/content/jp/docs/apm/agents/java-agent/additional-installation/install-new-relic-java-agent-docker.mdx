このページでは、エージェントのjarファイルをイメージに追加し、起動時に`-javaagent` JVM引数を渡すことで、DockerコンテナにNew Relic Javaエージェントをインストールする方法について説明します。

## 互換性と要件 [#requirements]

### サポート対象

* Java 8、11、17、21、24、25、および26 *（Java 7はエージェントv6.5.4以前でのみサポートされています）*
* `-javaagent` JVM引数を受け入れる、Javaアプリケーション（Tomcat、Spring Bootなど）を実行する任意のDockerイメージ
* サポートされているフレームワークおよびライブラリのバージョン範囲については、[互換性および要件](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent)を参照してください

### サポートされていない

* 他のAPMエージェントとの並行稼働 — 同じJVM内で別のAPMエージェントがアクティブな場合、Javaエージェントは正しい動作を保証できません。

### 必要なこと

* New Relicアカウントおよび<InlinePopover type="licenseKey" />
* SHA-2（256ビット）SSLをサポートするJVM
* JavaアプリケーションコンテナとともにインストールされたDocker

## インストール [#install]

`newrelic-java.zip` のダウンロード：\[#install-step-1]

```bash
curl -O https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip
unzip newrelic-java.zip
```

`Dockerfile`にエージェントのjarを追加します。以下の例ではTomcatを使用しています — お使いのアプリケーションサーバーに合わせてパスを調整してください：

```dockerfile
RUN mkdir -p /usr/local/tomcat/newrelic
ADD ./newrelic/newrelic.jar /usr/local/tomcat/newrelic/newrelic.jar
ENV JAVA_OPTS="$JAVA_OPTS -javaagent:/usr/local/tomcat/newrelic/newrelic.jar"
```

通常通りDockerイメージをビルドしてください。

## 設定 [#configure]

コンテナを実行する際に、アプリ名とライセンスキーを環境変数として渡してください：

```bash
docker run -e NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
           -e NEW_RELIC_APP_NAME="Your Application Name" \
           YOUR_IMAGE_NAME:latest
```

`Dockerfile` で `ENV` ディレクティブを使用することもできます：

```dockerfile
ENV NEW_RELIC_APP_NAME="Your Application Name"
```

その他のすべての設定オプションについては、[Javaエージェント設定](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file)を参照してください。

## インストールの確認 [#verify]

コンテナを実行し、アプリケーションに少なくとも2つのrequestsを送信してください。2～3分待つと、アプリケーションが[APM &amp; サービス](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29)に表示されます。

5分経過してもデータが表示されない場合は、[データが表示されない（Java）](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java)を参照してください。
