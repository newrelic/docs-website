## サーキットブレーカー

この設定は、[Javaブレーカー](/docs/agents/java-agent/custom-instrumentation/circuit-breaker-java-custom-instrumentation)の動作をカスタマイズします。この設定は、デフォルトでは`newrelic.yml`に含まれていません。変更後にJVMを再起動する必要はありません。

サーキットブレーカーをカスタマイズする場合、それを`common`セクションの下に追加します。

```yml
common: &default_settings​
  OTHER_CONFIG_SETTINGS
  circuitbreaker:
    enabled: true
    memory_threshold: 20
    gc_cpu_threshold: 10
```

ブレーカーのトリップを下回るフリーヒープメモリの比率をカスタマイズします。フリーヒープメモリの比率が`memory_threshold`以下で、ガーベージコレクションに費やしたCPUの時間が`gc_cpu_threshold`より多い場合、ブレーカーがトリップします。ブレーカーのトリップを発生しにくくするには、`memory_threshold`を減らすか、`gc_cpu_threshold`を増やします。アプリケーションの運用パフォーマンスと動作に基づき、必要に応じてこの値を調整します。

## クラウド設定

エージェントYAMLの`cloud`セクションで、クラウド関連のオプションを設定します。これらの設定は、プレフィックスが`newrelic.config.cloud`の[システムプロパティ](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file/#System_Properties)、またはプレフィックスが`NEW_RELIC_CLOUD_`の[環境変数](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file/#Environment_Variables)で上書きできます。

設定の例：

```yml
cloud:
  aws:
    account_id: 123456789012
  metadata_bypass_proxy: false
```

AWS DynamoDBとKinesisの両サービスでは、`cloud.resource_id`属性を設定するためにこの値が必要となります。同様に、AWS Lambdaでは、アカウントIDが関数名の一部として使用されていない場合にこの値が必要となります。

## コードレベルの指標

[コードレベルのメトリクス](/docs/apm/agents/java-agent/features/java-code-level-metrics)からは、コードがメソッドレベルでどのように機能しているかについて詳細なインサイトが得られます。自動的にインストゥルメントされた、または@Traceアノテーションによってインストゥルメントされた各メソッドのメトリクスが表示されます。

## カスタムイベント [#Custom_Events]

`custom_insights_events`セクションでカスタムイベント設定を行います。`newrelic.config.custom_insights_events`プリフィックス化システムプロパティを使用して、この設定を[上書き](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file#System_Properties)できます。

APMでは、New Relic言語エージェントAPIにより[カスタム イベントデータを記録](/docs/insights/insights-data-sources/custom-data/insert-custom-events-new-relic-apm-agents)でき、[これをクエリすることが可能です](/docs/query-your-data/explore-query-data/explore-data/introduction-querying-new-relic-data)。

<Callout variant="important">
4.1.0より前のJavaエージェントのバージョンでは、次のYAML設定が認識されます。

```yml
custom_insights_events.enabled: true
  custom_insights_events.max_samples_stored: 5000
```

エージェントのバージョンが4.1.0以上の場合、YAML設定はネストされたセクションフォーマットを使用します。

```yml
custom_insights_events:
  enabled: false
  max_samples_stored: 5000
```
</Callout>

## JVMプロパティの難読化

Javaエージェントは、UIで表示するJVMプロパティをNew Relicに送信します。Javaエージェントバージョン`8.16.0`以降では、ほとんどのプロパティの値が難読化されます。たとえば、`-Dprop=12345`は`-Dprop=obfuscated`という形で送信されます。

エージェントYAMLの`obfuscate_jvm_props`セクションで難読化関連のオプションを設定します。これらの設定は、プレフィックスが`newrelic.config.obfuscate_jvm_props`の[システムプロパティ](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file/#System_Properties)、またはプレフィックスが`NEW_RELIC_OBFUSCATE_JVM_PROPS_`の[環境変数](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file/#Environment_Variables)で上書きできます。

デフォルトでは、`-X`で始まるプロパティの値は難読化されません。

## アプリケーションをスキップ [#skip-applications]

エージェントは、スタートアップメインクラスまたはコマンドラインから抽出された実行可能jarファイルに基づいて、任意に有効または無効にすることができます。これは、「JAVA\_TOOL\_OPTIONS」環境変数が存在し、-javaagentフラグが含まれているものの、 Kubernetesコンテナ内など、環境内のすべてのJavaアプリに計装を適用したくない場合に便利です。

<Callout variant="important">
エージェントのライフサイクルの早い段階でスキップ設定を確認する必要があるため、スキップ設定はシステムプロパティまたは環境変数を介してのみサポートされます。
</Callout>

診断目的で、excludeまたはinclude設定変数のいずれかが定義されている場合、エージェントは抽出されたコマンドラインと解析されたスキップトークンをstdoutに出力します。

```
New Relic Agent: New Relic Agent: Configured startup Java artifacts [include|skip] string: keytool,Main
New Relic Agent: Retrieved current startup command line / main artifact name: /Users/bob/.sdkman/candidates/java/11.0.17-amzn/bin/keytool
```

includeまたはskip設定変数に基づいてエージェントが無効になっている場合、以下がstdoutにダンプされます。

```
----------
New Relic Agent is disabled by startup class/jar skip or include configuration.
----------
```

## 一時的なJarファイルの削除 [#temporary-jar-file-removal]

一部の顧客環境では、エージェントの一時jarがJVMの終了時に削除されるようにマークされているにもかかわらず、適切にクリーンアップされません。これはJVMの異常終了が原因であると考えられます。この設定は、起動時に指定された値より古い一時エージェントjarファイルを削除するようにエージェントに指示します。

<Callout variant="important">
ファイルの削除はエージェントのライフサイクルの早い段階で実行する必要があるため、この設定はシステムプロパティまたは環境変数を介してのみサポートされます。
</Callout>

診断目的で、この機能を有効にすると、次の内容がコンソールに書き込まれます。

```
New Relic Agent: Removing stale temporary agent file jars from [temporaryFolder] older than [X] hour(s)
```

ファイルが削除された場合、次の内容がコンソールに書き込まれます。

```
New Relic Agent: Deleted [count] stale temporary jar files freeing up [totalBytes] bytes
```
