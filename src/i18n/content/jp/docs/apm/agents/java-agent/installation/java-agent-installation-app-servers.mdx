このページでは、サポートされているアプリケーションサーバーまたはJVMベースのフレームワークにおける、New Relic Javaエージェントの標準的なインストレーション手順について説明します。以下の手順に従ってエージェントをダウンロードして設定し、データがNew Relicに送信されていることを確認してください。

## 互換性および要件 [#requirements]

### サポート対象

* Java 8、11、17、21、24、25、および26*（Java 7はエージェント6.5.4以前でのみサポート）*
* JVMベースの言語：Java、Scala、Kotlin、Clojure
* アプリケーションサーバーとフレームワーク：Tomcat、Spring Boot、JBoss/WildFly、Glassfish、Jetty、WebLogic、WebSphere、Grails、ColdFusion、Solr、Play、Resin、Tanuki Wrapper、Geronimo — サポートされているバージョンの範囲については、[互換性と要件](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent)を参照してください。
* `-javaagent`引数を受け入れる任意のJVMプロセス

### サポートされていない

* 他のAPMエージェントとの並行稼働 — 同じJVM内で別のAPMエージェントがアクティブな場合、Javaエージェントの正常な動作は保証されません。

### 必要なもの

* New Relicアカウントおよび<InlinePopover type="licenseKey" />
* SHA-2（256ビット）SSLをサポートするJVM
* アプリケーションサーバーの起動スクリプトまたはJVM設定を編集する権限
* エージェントファイルを保持するディレクトリを作成する権限

## インストール [#install]

<Steps>
  <Step>
    ### Javaエージェントをダウンロードする [#install-step-1]

    以下のいずれかの方法を使用して、`newrelic-java.zip`をダウンロードします。

    <Tabs>
      <TabsBar>
        <TabsBarItem id="curl">curl</TabsBarItem> <TabsBarItem id="powershell">PowerShell</TabsBarItem> <TabsBarItem id="web">Web</TabsBarItem>
      </TabsBar>

      <TabsPages>
        <TabsPageItem id="curl">
          ```bash
          curl -O https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip
          unzip newrelic-java.zip
          ```
        </TabsPageItem>

        <TabsPageItem id="powershell">
          ```powershell
          Invoke-WebRequest -Uri https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip -OutFile newrelic-java.zip
          Expand-Archive -Path newrelic-java.zip -DestinationPath .
          ```
        </TabsPageItem>

        <TabsPageItem id="web">
          [Javaエージェントのリリースノート](/docs/release-notes/agent-release-notes/java-release-notes/)ページから`newrelic-java.zip`をダウンロードしてください。
        </TabsPageItem>
      </TabsPages>
    </Tabs>

    解凍後、`newrelic/`ディレクトリには、次の手順で設定するエージェントのjar（`newrelic.jar`）と設定ファイル（`newrelic.yml`）が含まれています。
  </Step>

  <Step>
    ### エージェントファイルを配置する [#install-step-2]

    永続的なディレクトリを作成し、その中にエージェントファイルを移動します。

    ```bash
    mkdir -p /opt/newrelic
    mv newrelic/* /opt/newrelic/
    ```

    Linux/macOSでは`/opt/newrelic`、Windowsでは`C:\opt\newrelic`をお勧めします。`newrelic.jar`がアプリケーションのクラスパス、または`java.endorsed.dirs`にリストされているディレクトリに**ない**ことを確認してください。
  </Step>

  <Step>
    ### 次を渡す： `-javaagent` [#install-step-3]

    アプリケーションサーバーのJVM起動設定に`-javaagent`フラグを追加し、`newrelic.jar`のフルパスを指定してください。方法はサーバーごとに異なります — ご使用の環境に一致するものを展開してください。

    <CollapserGroup>
      <Collapser id="tomcat" title="Tomcat">
        Tomcatのセットアップ方法を選択してください。

        <Tabs>
          <TabsBar>
            <TabsBarItem id="tomcat-setenvsh">setenv.sh（Linux/macOS）</TabsBarItem> <TabsBarItem id="tomcat-setenvbat">setenv.bat（Windows）</TabsBarItem> <TabsBarItem id="tomcat-windows-service">Windowsサービス</TabsBarItem> <TabsBarItem id="tomcat-commons-daemon">Apache Commonsデーモン</TabsBarItem>
          </TabsBar>

          <TabsPages>
            <TabsPageItem id="tomcat-setenvsh">
              `CATALINA_BASE/bin/setenv.sh`が存在しない場合は作成し、次を追加してください。

              ```bash
              export CATALINA_OPTS="$CATALINA_OPTS -javaagent:/opt/newrelic/newrelic.jar"
              ```
            </TabsPageItem>

            <TabsPageItem id="tomcat-setenvbat">
              `CATALINA_BASE/bin/setenv.bat`が存在しない場合は作成し、次を追加してください。

              ```batch
              SET "CATALINA_OPTS=%CATALINA_OPTS% -javaagent:C:\opt\newrelic\newrelic.jar"
              ```
            </TabsPageItem>

            <TabsPageItem id="tomcat-windows-service">
              1. **Start &gt; Apache Tomcat X.Y.Z. &gt; Configure Tomcat &gt; Java**を選択します。

              2. **Javaオプション**テキストボックスに、引数を入力します。パスの区切り文字には、フォワードスラッシュ`/`を使用します。Tomcat 6の場合は、`-javaagent`引数の後に改行を追加します。

                 ```
                 -javaagent:/opt/newrelic/newrelic.jar
                 ```

              3. **適用**を選択し、Tomcatを再起動します。
            </TabsPageItem>

            <TabsPageItem id="tomcat-commons-daemon">
              Tomcat 6にバンドルされているApache Commonsデーモン（jsvc）のバージョンでは、`-javaagent`引数はサポートされていません。trunkソースからのビルドは、`-X`プレフィックスでこれをサポートします。[Apacheのバグレポート](https://issues.apache.org/jira/browse/DAEMON-84)および[Apache Commonsのソースリポジトリ](https://commons.apache.org/svninfo.html)を参照してください。
            </TabsPageItem>
          </TabsPages>
        </Tabs>
      </Collapser>

      <Collapser id="spring-boot" title="Spring Boot">
        コマンドラインで、`-jar`引数の前に`-javaagent`引数を追加します。

        ```bash
        java -javaagent:/opt/newrelic/newrelic.jar -jar /path/to/your-application.jar
        ```
      </Collapser>

      <Collapser id="glassfish" title="Glassfish">
        1. Glassfishのアドミンコンソールから、**Application Server &gt; JVM Settings &gt; JVM Options**を選択します。

        2. **Add JVM Option**を選択して、以下を追加します。

           ```
           -javaagent:/opt/newrelic/newrelic.jar
           ```

        3. 保存して、Glassfishを再起動します。

        *Glassfishが起動しない場合は、`-javaagent`のパスが正しくない可能性があります。`domain.xml`を直接編集して、JVM引数を設定することもできます。*

        <Callout variant="important">
          Glassfish 2.1のバグにより、ブートストラップクラスローダーが読み込んだクラスではJavaロギングAPIを使用できません。この問題は、2.1.1以降で修正されています。
        </Callout>
      </Collapser>

        1. ColdFusionサーバーを起動し、ColdFusionアドミンコンソールを開きます。

           ```
           -javaagent:/opt/newrelic/newrelic.jar
           ```

        5. **Submit Changes**を選択し、ColdFusionを再起動します。

## 設定 [#configure]

`newrelic/newrelic.yml`を編集し、次の必須の2つの値を設定してください。

```yaml
license_key: 'YOUR_LICENSE_KEY'
app_name: 'My Application'
```

エージェントは起動時に、`newrelic.jar`と同じディレクトリから`newrelic.yml`を読み取ります。Javaシステムプロパティを使用して任意の設定を上書きすることもできます（例：`-Dnewrelic.config.license_key=YOUR_KEY`）。または環境変数を使用することもできます。

設定ファイルを使用する場合は、パーミッションをアプリケーションサーバープロセスの所有者のみの読み取り/書き込みに制限してください。

```bash
chmod 600 /opt/newrelic/newrelic.yml
```

利用可能なすべてのオプションについては、[Javaエージェントの設定](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file)をご覧ください。

## インストールの確認 [#verify]

アプリケーションサーバーを再起動してください。少なくとも2回リクエストを送信してから2～3分待つと、アプリが[APM &amp; services](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29)に表示されます。

5分経過してもデータが表示されない場合は、[データが表示されない（Java）](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java)をご覧ください。
