このページでは、New Relic Javaエージェントのサイト拡張機能を使用して、Windows上のAzure App ServiceにNew Relic Javaエージェントをインストールする方法について説明します。拡張機能は、アプリの起動スクリプトを変更することなく、エージェントを自動的に挿入します。

## 互換性と要件 [#requirements]

### サポート対象

* Azure Windows App Service で実行されている Java アプリケーション
* Java 8以降と互換性のあるNew Relic Javaエージェントのバージョン*（Java 7はエージェントv6.5.4以前でのみサポートされています）*
* サポートされているフレームワークおよびライブラリのバージョン範囲については、[互換性および要件](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent)を参照してください

### サポートされていない

* Azure上のLinuxコンテナ — [Dockerインストール方法](/docs/apm/agents/java-agent/additional-installation/install-new-relic-java-agent-docker)を使用し、次を経由して`-javaagent`を渡します `JAVA_TOOL_OPTIONS`
* 他のAPMエージェントとの並行稼働 — 同じJVM内で別のAPMエージェントがアクティブな場合、Javaエージェントは正しい動作を保証できません。

### 必要なこと

* New Relicアカウントおよび<InlinePopover type="licenseKey" />
* SHA-2（256ビット）SSLをサポートするJVM
* Azure Windows App Service 上で実行されている Java アプリケーション
* 部分的な計装を避けるため、拡張機能をインストールする前にターゲットアプリケーションを停止する必要があります。

## インストール [#install]

<Steps>
<Step>
### サイト拡張機能のインストール [#install-step-1]

1. Azure ホームページから **App Services** を選択し、次にターゲットアプリケーションを選択します。
2. 左側のメニューで、**Development Tools** \[開発ツール]までスクロールし、**Extensions** \[拡張機能]を選択します。
3. ページ上部の**+ Add**を選択して、拡張機能のドロップダウンを開きます。
4. **New Relic Javaエージェント**を選択してください。
5. 法的条件に同意し、**OK**を選択してインストレーションを開始します。

インストールされると、拡張機能は以下を作成します：

* `C:\home\NewRelic\JavaAgent\newrelic\`の**エージェントファイル**（jar、設定、ソース）
* アプリケーションの起動時に`JAVA_TOOL_OPTIONS`環境変数を自動的に注入する**XDT変換**（`applicationHost.xdt`）

*拡張機能のインストールに失敗した場合は、`C:\home\SiteExtensions\NewRelic.Azure.WebSites.Extension.JavaAgent\install.log`のログを確認してください。*
</Step>

<Step>
### エージェントを構成します [#install-step-2]

1. アプリケーションの左側のメニューで、**Settings &gt; Configuration**に移動します。
2. 以下のアプリケーション設定を追加します：

| 設定                      | 価値                        |
| ----------------------- | ------------------------- |
| `NEW_RELIC_LICENSE_KEY` | あなたのNew Relicライセンスキー      |
| `NEW_RELIC_APP_NAME`    | New Relicプラットフォームに表示される名前 |

エージェントをさらにカスタマイズするために、アプリ設定として[追加の設定](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file/#Environment_Variables)を追加することもできます。
</Step>
</Steps>

## インストールの確認 [#verify]

アプリケーションを起動してください。少なくとも2つのrequestsを送信してください。2～3分待つと、アプリケーションが[APM &amp; サービス](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29)に表示されます。

5分経過してもデータが表示されない場合は、[データが表示されない（Java）](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java)を参照してください。
