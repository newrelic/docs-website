このページでは、Gradleを使用してNew Relic Javaエージェントをインストールする方法について説明します。`de.undercouch.download`プラグインを利用したGradleタスクが、`newrelic-java.zip`を取得し、プロジェクトディレクトリに展開します。

## 互換性および要件 [#requirements]

### サポート対象

* Java 8、11、17、21、24、25、および26*（Java 7はエージェント6.5.4以前でのみサポート）*
* Gradle 6.x以降
* `de.undercouch.download` プラグインバージョン5.3.0以降
* `-javaagent`引数を受け入れる、サポートされている任意のアプリケーションサーバーまたはスタンドアロンJVMプロセス
* サポートされているフレームワークおよびライブラリのバージョン範囲については、[互換性と要件](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent)をご覧ください

### サポートされていない

* 他のAPMエージェントとの並行稼働 — 同じJVM内で別のAPMエージェントがアクティブな場合、Javaエージェントの正常な動作は保証されません。

### 必要なもの

* New Relicアカウントおよび<InlinePopover type="licenseKey" />
* SHA-2（256ビット）SSLをサポートするJVM
* 次を含むGradleプロジェクト： `build.gradle`

## インストール [#install]

<Steps>
  <Step>
    ### ダウンロードプラグインを追加する [#install-step-1]

    `build.gradle`の`plugins`ブロックに`de.undercouch.download`プラグインを追加します。

    ```groovy
    plugins {
        id "de.undercouch.download" version "5.3.0"
    }
    ```
  </Step>

  <Step>
    ### ダウンロードと解凍のタスクを追加する [#install-step-2]

    `build.gradle`に2つのタスクを追加します — 1つはエージェントのzipをダウンロードするタスク、もう1つはそれを展開するタスクです。

    ```groovy
    task downloadNewrelic(type: Download) {
        mkdir 'newrelic'
        src 'https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip'
        dest file('newrelic')
    }

    task unzipNewrelic(type: Copy) {
        from zipTree(file('newrelic/newrelic-java.zip'))
        into rootDir
    }
    ```

    これにより、プロジェクトルートの`newrelic/`ディレクトリにエージェントファイルが配置されます。このディレクトリには以下が含まれます。

    * `newrelic.jar` — Javaエージェント
    * `newrelic.yml` — エージェント設定ファイル
    * `newrelic-api.jar` — JavaエージェントAPIのjar
    * `README`
  </Step>

  <Step>
    ### タスクを実行する [#install-step-3]

    エージェントをダウンロードして展開するために、両方のタスクを実行してください。

    ```bash
    ./gradlew downloadNewrelic
    ./gradlew unzipNewrelic
    ```
  </Step>

  <Step>
    ### 次を渡す： `-javaagent` [#install-step-4]

    アプリケーションの起動時に、`newrelic.jar`を指す`-javaagent` JVM引数を追加します。具体的な方法はアプリケーションサーバーによって異なります — サーバー固有の手順については、[サーバーに応じたJVM引数を渡す](/docs/apm/agents/java-agent/installation/java-agent-installation-app-servers#install-step-3)を参照してください。

    たとえば、Spring Boot jarの場合は次のようになります。

    ```bash
    java -javaagent:/path/to/newrelic/newrelic.jar -jar my-app.jar
    ```
  </Step>
</Steps>

## 設定 [#configure]

`newrelic/newrelic.yml`を編集して、次の必須の2つの値を設定してください。

```yaml
license_key: 'YOUR_LICENSE_KEY'
app_name: 'My Application'
```

エージェントは起動時に、`newrelic.jar`と同じディレクトリから`newrelic.yml`を読み取ります。Javaシステムプロパティを使用して任意の設定を上書きすることもできます（例：`-Dnewrelic.config.license_key=YOUR_KEY`）。または環境変数を使用することもできます。

利用可能なすべてのオプションについては、[Javaエージェントの設定](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file)をご覧ください。

## インストールの確認 [#verify]

アプリケーションを再起動します。少なくとも2回リクエストを送信してから2～3分待つと、アプリが[APM &amp; services](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29)に表示されます。

5分経過してもデータが表示されない場合は、[データが表示されない（Java）](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java)をご覧ください。
