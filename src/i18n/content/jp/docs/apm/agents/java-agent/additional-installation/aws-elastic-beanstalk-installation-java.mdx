このページでは、アプリケーションバンドルにエージェントを追加し、Elastic Beanstalkコンソールから`-javaagent` JVM引数を設定することで、AWS Elastic BeanstalkにNew Relic Javaエージェントをインストールする方法について説明します。

## 互換性と要件 [#requirements]

### サポート対象

* Java 8、11、17、21、24、25、および26 *（Java 7はエージェントv6.5.4以前でのみサポートされています）*
* Elastic Beanstalk Tomcatプラットフォーム
* Elastic Beanstalk Java SEプラットフォーム
* サポートされているフレームワークおよびライブラリのバージョン範囲については、[互換性および要件](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent)を参照してください

### サポートされていない

* Elastic Beanstalk上のDockerコンテナ — 代わりに[Dockerインストール方法](/docs/apm/agents/java-agent/additional-installation/install-new-relic-java-agent-docker)を使用してください
* 他のAPMエージェントとの並行稼働 — 同じJVM内で別のAPMエージェントがアクティブな場合、Javaエージェントは正しい動作を保証できません。

### 必要なこと

* New Relicアカウントおよび<InlinePopover type="licenseKey" />
* SHA-2（256ビット）SSLをサポートするJVM
* Elastic BeanstalkにJavaアプリがデプロイされている[AWSアカウント](http://aws.amazon.com/elasticbeanstalk/)

## インストール [#install]

`newrelic-java.zip` をダウンロードし、`newrelic.jar` と `newrelic.yml` を展開します：\[#install-step-1]

```bash
curl -O https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip
unzip newrelic-java.zip
```

## 設定 [#configure]

`newrelic.yml`を編集して、2つの必要な値を設定します：

1. `license_key`を<InlinePopover type="licenseKey" />に設定してください。
2. `app_name`にアプリケーションのわかりやすい名前を設定してください。

**Tomcatプラットフォームのみ** — Elastic Beanstalkコンソールから`-javaagent`フラグを渡してください：

1. Elastic Beanstalkコンソールを開き、環境を選択してください。

2. 左側のペインで、 **Configurations** を選択します。

3. **Updates, monitoring, and logging** \[更新、監視、ログ]までスクロールし、**Edit** \[編集]をクリックします。

4. **Platform Software** \[プラットフォーム ソフトウェア]で、**JVM Options** \[JVM オプション]フィールドに次を追加します：

   ```
   -javaagent:/full/path/to/newrelic.jar
   ```

   EC2インスタンス上の `newrelic.jar` へのパスを確認するには、インスタンスに接続して次を実行します：

   ```bash
   sudo find /var -name "newrelic.jar"
   sudo find /usr -name "newrelic.jar"
   ```

5. **Apply** \[適用]をクリックします。

その他のすべての設定オプションについては、[Javaエージェント設定](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file)を参照してください。

## インストールの確認 [#verify]

Elastic Beanstalkが環境を更新します。少なくとも2つのrequestsを送信してから2～3分待つと、アプリケーションが[APM &amp; サービス](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29)に表示されます。

5分経過してもデータが表示されない場合は、[データが表示されない（Java）](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java)を参照してください。
