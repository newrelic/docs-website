New Relicの PHP エージェントは、サポートされているプロセッサ上のサポートされている OS 上の圧縮 tar ファイルからインストールできます。 ただし、x86\_64 上のRedHatまたは CentOS の場合は[、 RPM パッケージ](/docs/agents/php-agent/installation/php-agent-installation-aws-linux-redhat-centos/)を使用するのが一般的です。 x86\_64 上の Ubuntu または Debian の場合は[、Debian パッケージを](/docs/agents/php-agent/installation/php-agent-installation-ubuntu-debian)使用するのが一般的です。

## tarファイルのダウンロード [#download]

他のインストール方法と異なり、tar アーカイブは特別なリポジトリの設定を必要としません。必要なのは、アーカイブをダウンロードして、以下の指示に従うだけです。

<DNT>**[download.newrelic.com/php\_agent/release/](https://download.newrelic.com/php_agent/release/)**</DNT>から適切な tar 配布ファイルをダウンロードします:

* GNU libc を搭載した Linux (ほとんどの Linux ディストリビューション) の場合は、 `newrelic-php5-X.X.X.X-linux.tar.gz`をダウンロードしてください。
* musl libc を搭載した Linux (Alpine Linux) の場合は、 `newrelic-php5-X.X.X.X-linux-musl.tar.gz`をダウンロードしてください。

<Callout variant="tip">
PHP エージェントのパッケージ名は`newrelic-php5`です。パッケージ名は PHP 5 を参照していますが、このパッケージは [サポートされているすべての PHP バージョン](/docs/agents/php-agent/getting-started/php-agent-compatibility-requirements#php-release)で機能します。
</Callout>

## インストールまたはアップデート [#install]

tar ファイルのインストールでは、初回インストールと更新の手順は同じです。XXXX を正しい New Relic バージョンに置き換えます。エージェントをインストールまたは更新するには:

1. [New Relic の Web サイト](https://download.newrelic.com/php_agent/release/)から適切な tar ファイルをダウンロードし、ローカル ディスクの便利な場所に保存します。`/tmp`フォルダーは使用しないでください。

2. アーカイブを解凍して取り出す。

   ```bash
   gzip -dc newrelic-php5-X.X.X.X-OS.tar.gz | tar xf -
   ```

3. 新たに作成したディレクトリに変更します。

   ```bash
   cd newrelic-php5-X.X.X.X-OS
   ```

4. インストールスクリプトを実行します。

   ```bash
   ./newrelic-install
   ```

5. デフォルトの[アプリケーション名](/docs/site/naming-your-application)を分かりやすい名前に変更します。

6. ウェブサーバーを再起動します（Apache、Nginx、PHP-FPMなど）。

7. アプリケーションがデータを送信するまで数分待ってから、 [UIでアプリケーションのパフォーマンスを確認します](/docs/apm/applications-menu/monitoring/apm-overview-page) 。

## tarファイルを検証します [#verify]

PHPエージェントのバージョン12.13.0.43以降、ダウンロードサイト上の各tarファイルを、署名キーのフィンガープリントとtarファイルのSHA-256ハッシュを使用して検証できます。どちらも、PHPエージェントのGitHubリポジトリの[`release-data`ディレクトリ](https://github.com/newrelic/newrelic-php-agent/tree/main/release-data)で公開されています。

tarファイルを検証するには：

1. tarファイル、その`.asc`ファイル（同じフォルダーにある、tarファイルの名前に`.asc`を追加したもの）、および公開鍵をダウンロードします。このコマンドは、公開鍵のURLとそのフィンガープリントを出力します：

   ```bash
   curl -s https://raw.githubusercontent.com/newrelic/newrelic-php-agent/main/release-data/signing-key-fingerprints.json | jq -r '.keys[] | select(.purpose == "tarball" and .status == "active") | .public_key_url, (.fingerprint | [scan(".{4}")] | join(" "))'
   ```

2. キーファイルのフィンガープリントを表示し、ステップ1のフィンガープリントと比較してください。一致する場合は、キーをインポートしてください：

   ```bash
   gpg --show-keys --with-fingerprint NEWRELIC_TARBALL_XXXXXXXX.public
   gpg --import NEWRELIC_TARBALL_XXXXXXXX.public
   ```

3. 署名を検証します：

   ```bash
   gpg --verify newrelic-php5-X.X.X.X-OS.tar.gz.asc newrelic-php5-X.X.X.X-OS.tar.gz
   ```

   出力には`Good signature`と表示される必要があり、その`Primary key fingerprint`行目はステップ1のフィンガープリントと一致する必要があります。また、`gpg`は、鍵が信頼できる署名で認定されていないという警告も出力します。これは想定された動作です。

4. tarファイルのSHA-256ハッシュを、`tarball-hashes.json`に記載されているハッシュと比較してください。2つのハッシュは同一である必要があります：

   ```bash
   sha256sum newrelic-php5-X.X.X.X-OS.tar.gz
   curl -s https://raw.githubusercontent.com/newrelic/newrelic-php-agent/main/release-data/tarball-hashes.json | jq -r '.releases[].files[] | select(.filename == "newrelic-php5-X.X.X.X-OS.tar.gz") | .sha256'
   ```
