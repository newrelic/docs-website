この機能は現在、弊社の[プレリリース ポリシー](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy)に従ってプレビュー プログラムの一部として提供されています。

New Relic PythonエージェントはLaunchDarklyの機能管理と連携するため、機能フラグやリリースがアプリケーションに与える影響を監視できます。このインテグレーションは、LaunchDarklyのオブザーバビリティプラグインとPythonエージェントのOpenTelemetryサポートを使用して、LaunchDarklyのデータとNew Relic APMのデータを接続します。

このドキュメントでは、必要なパッケージをインストールし、インテグレーションを有効にする方法について説明します。

## 前提条件 [#prerequisites]

始める前に、以下があることを確認してください：

* New Relic [ライセンス キー](/docs/apis/intro-apis/new-relic-api-keys/#license-key)
* LaunchDarklyアカウントとライセンス
* Pythonで記述され、[New Relic Python APMエージェント](/docs/apm/agents/python-agent/installation/install-new-relic-python-agent)でモニターされるアプリケーション
* LaunchDarkly OpenTelemetry（OTel）ベータ版へのアクセス

## インストレーションと設定 [#install]

<Steps>
<Step>
### 必要なパッケージをインストールしてください。 [#install-packages]

アプリケーションと同じ環境内に以下のPythonパッケージをインストールしてください：

* `newrelic`
* `launchdarkly-observability`

```bash
pip install newrelic launchdarkly-observability
```

以下のパッケージも必要であり、通常は `launchdarkly-observability` の依存関係として自動的にインストールされます：

* `opentelemetry-api`
* `launchdarkly-eventsource`
* `launchdarkly-server-sdk`
* `launchdarkly-server-sdk-otel`

これらの依存関係が自動的にインストールされない場合は、`pip`を使用して手動でインストールしてください：

```bash
pip install opentelemetry-api launchdarkly-eventsource launchdarkly-server-sdk launchdarkly-server-sdk-otel
```
</Step>

<Step>
### 統合を有効にする [#enable-integration]

インテグレーションを有効にするには、`launch_darkly_integration.enabled`と`opentelemetry.enabled`の両方を`true`に設定してください。アプリケーションを設定するには、以下のいずれかの設定方法を選択してください：

<CollapserGroup>
<Collapser id="use-newrelic-ini" title="newrelic.iniを使用する">
`newrelic.ini`ファイルに以下を追加します。

```ini
launch_darkly_integration.enabled = true
opentelemetry.enabled = true
```
</Collapser>

<Collapser id="use-pyproject-toml" title="pyproject.tomlを使用する">
`pyproject.toml`ファイルに以下を追加します。

```toml
[tool.newrelic]
launch_darkly_integration.enabled = true
opentelemetry.enabled = true
```
</Collapser>

<Collapser id="use-environment-variables" title="環境変数の使用">
次の環境変数を設定します：

```bash
export NEW_RELIC_LAUNCH_DARKLY_ENABLED=true
export NEW_RELIC_OPENTELEMETRY_ENABLED=true
```

<Callout variant="tip">
OpenTelemetryの設定に関する詳細については、[Pythonエージェントの設定](/docs/apm/agents/python-agent/configuration/python-agent-configuration#opentelemetry-enabled)のドキュメントをご覧ください。
</Callout>
</Collapser>
</CollapserGroup>
</Step>

<Step>
### インテグレーションを検証してください [#verify]

これらの設定を有効にした後、Pythonエージェントが更新された設定を読み込むように、アプリケーションを再起動してください。次に、テストトラフィックを生成し、アプリケーションが[<DNT>**APM &amp; services**</DNT>](/docs/apm/apm-ui-pages/monitoring/apm-summary-page-view-transaction-apdex-usage-data)でデータを引き続きレポートしていることを確認してください。
</Step>
</Steps>
