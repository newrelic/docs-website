ABAPアドオンをインストールした後、<DNT>**`/NEWR/INSTALL`**</DNT>メニューを使用してSAPシステムをNew Relicに接続し、APIエンドポイントを構成し、監視グループを定義して、セットアップを確認します。

## /NEWR/INSTALLメニューを使用します。 [#menu-newr-install]

1. 中央監視システムの運用クライアントにログインします。
2. コマンドフィールドに`/n`を入力し、<DNT>**Enter**</DNT>を押して<DNT>**SAP Easy Access root menu**</DNT>に移動します。
3. コマンドフィールドに「`/n/NEWR/INSTALL`」を入力して、<DNT>**`/NEWR/INSTALL`**</DNT>メニューを開きます。

設定する前に、以下を確認してください：

* インストーラには、設定を実行するための適切な権限があります。
* `/NEWR/*`パラメーターは、インストーラの`profile/role`にある`S_TCODE`権限オブジェクトに追加されます。

<Callout variant="tip">
  旧バージョンからアップグレードする場合は、[旧バージョンからのアップグレード](/docs/sap-solutions/upgrade/install-upgrade-package)を参照して、必要な手順を確認してください。
</Callout>

## システムを接続 [#connect-systems]

<Callout variant="important">
  先に進む前に、保留中の設定手順をすべて完了してください。
</Callout>

`/NEWR/INSTALL`メニューで<DNT>**Install New Release and Patch**</DNT>フォルダーを開き、次の手順を完了します。

### 標準のRFC宛先設定

トランザクション`SM59`を使用して、オンプレミスのモニター対象システム用の<DNT>**RFC**</DNT>および<DNT>**HTTPS**</DNT>接続をセットアップします：

* RFCのセットアップについては、[Standard RFC Destination](/docs/sap-solutions/install-and-configure/additional-configuration/#standard-rfc-destination)および[Set HTTP destination to New Relic cloud](/docs/sap-solutions/install-and-configure/additional-configuration/#set-http-destination-to-new-relic-cloud)を参照してください。

### SAP Cloud/Business Technology プラットフォーム（BTP）RFC設定

トランザクション`SM59`を使用して、BTPホストシステムのHTTP宛先をセットアップします：

* BTP/CALM認証については、「[Cloud（BTP）RFC宛先](/docs/sap-solutions/install-and-configure/additional-configuration/#cloud-btp-rfc-destination)」を参照してください。
* <DNT>**SAP Cloud Connector**</DNT>をモニターする場合は、ポート<DNT>**8443**</DNT>（デフォルトのCloud Connector HTTPS管理ポート）を使用して、タイプ<DNT>**G**</DNT>（外部HTTP）のRFC宛先を設定します。ユーザーアカウントには、必要な権限とパスワードが必要です。

### リモートデータベースへの接続をセットアップする

プレインストレーション中にこの手順を完了しなかった場合は、今すぐ完了してください。

* SAPトランザクション`DBACOCKPIT`を開いて、リモート<DNT>**HANA databases**</DNT>への接続を確認します。
* モニターする各リモートHANAデータベースのデータベース接続を作成します。
* 詳細な手順については、[データベース接続の作成](/docs/sap-solutions/install-and-configure/additional-configuration/#create-database-connection)をご覧ください。

### New Relic APIエンドポイントへの接続を構成します

このセクションでは、複数のNew Relicアカウントを設定できます。

1. <DNT>**New Entries**</DNT>をクリックします。

2. New Relicアカウントの詳細を入力してください：

   * <DNT>**New Relic Account ID**</DNT> （オプションでSAP-をプリフィックスとして付加）
   * <DNT>**API Ingest Key**</DNT>
   * <DNT>**Metric Endpoint**</DNT> （[ネットワークエンドポイント](/docs/sap-solutions/before-you-begin/#network-endpoints)を参照）
   * <DNT>**Event Endpoint**</DNT>
   * <DNT>**Log Endpoint**</DNT>
   * <DNT>**Trace Endpoint**</DNT>

3. <DNT>**Save**</DNT>をクリックします。

### クライアント000からテンプレートテーブルをコピー

実行アイコン（時計の記号）をクリックして、<DNT>**client 000**</DNT>からテンプレートテーブルをコピーします。成功メッセージが表示されることを確認してください。

### モニター対象システムを定義します

1. <DNT>**New Entries**</DNT>をクリックし、<DNT>**SAP System ID**</DNT>と<DNT>**Client**</DNT>の番号を入力します。

2. <DNT>**Data Provider Installation Information**</DNT>で、以下を指定します：

   * <DNT>**RFC Destination**</DNT>
   * <DNT>**SAP Software Component**</DNT>
   * <DNT>**Database Vendor**</DNT>
   * <DNT>**DB Connection Name**</DNT> （HANAデータベースのみ）
   * <DNT>**New Relic Account ID**</DNT> （オプション） — 指定した場合、このシステムからのデータはそのアカウントにのみ送信され、コレクションマネージャージョブバリアントのアカウントを上書きします。空白のままにした場合、システムはコレクションマネージャージョブバリアントのアカウントを使用します。

3. <DNT>**Monitoring Group**</DNT>をクリックし、<DNT>**Yes**</DNT>を選択して確認します。

4. 必要な監視グループを選択し、生成アイコンをクリックします。

5. 続行するには、<DNT>**BACK**</DNT>をクリックするか、<DNT>**F3**</DNT>を押してください。

<img title="Define monitored system" alt="A screenshot displaying the monitored system configuration details" src="/images/details-of-added-entry.webp" width="600" />

### BTP/CALMアカウント

BTP監視がアクティブな場合、BTP/CALMアカウントをモニター対象システムとして追加します。次の値を使用します。

* <DNT>**SAP System ID**</DNT>：仮名またはエイリアスを使用してください。`CALM`や`BTP`などの予約語は使用しないでください。
* <DNT>**Client**</DNT>：空白のままにします。
* <DNT>**Destination**</DNT>：認証HTTP宛先を入力します。
* <DNT>**Software Component**</DNT>：空白のままにします。
* <DNT>**Database Vendor**</DNT>：空白のままにします。
* <DNT>**DB Connection Name**</DNT>：空白のままにします。
* <DNT>**New Relic Account ID**</DNT>：データを受信するように指定された特定のNew Relicアカウントを入力してください。
* <DNT>**API Host**</DNT>：APIホスト名を入力します。これは、サービスキーの`url`の値に対応します。

次の画面で、<DNT>**Monitoring Group**</DNT>をクリックします。システムに適切な監視グループを選択し、<DNT>**Finish**</DNT>をクリックします。

### RFC宛先を確認します。

このオプションを使用して、New Relic APIエンドポイントおよび各モニター対象システムのRFC宛先を検証します。このテストでは、<DNT>**NONE**</DNT>として指定されたRFC宛先を除外します。

## 設定を生成 [#generate-configurations]

### 新しいデータプロバイダーの設定を生成します

* このオプションを実行して、新しいリリースまたはパッチ用のすべての新しいデータプロバイダーを生成します。新規インストレーションの場合、この1つのステップですべてのデータプロバイダーが生成されます。
* 最初の画面で、リリースとパッチの詳細を確認してください。インストレーションのリリースとパッチのフィールドが空白の場合、設定はすでに確立されています。
* 設定を再生成するには、<DNT>**Maintain Monitored Systems**</DNT>に移動して<DNT>**Re-generate Data Provider Configurations**</DNT>を選択します。<DNT>**Reset Installation Flag (For Re-install only)**</DNT>を選択して、現在のインストレーションフラグをクリアし、再生成することもできます。

<Callout variant="tip">
  CALMベースのデータプロバイダーについては、[CALMデータプロバイダーのレジストリエントリの生成](/docs/sap-solutions/monitor/data-providers-reference)を参照してください。
</Callout>

<img title="Maintain Monitored Systems" alt="A screenshot displaying the SAP maintain monitored systems" src="/images/maintain-monitored-systems.webp" width="500" />

### インストレーションの完全性を確認します。

<DNT>**Verify Installation Completeness**</DNT>を選択します。いずれかのコンポーネントに赤いインジケーターが表示されている場合は、<DNT>**Action Needed**</DNT>列の実行ボタンをクリックして問題を解決します。

## 設定の確認 [#verify-configuration]

1. <DNT>**Data Provider Registry Maintenance**</DNT>フォルダーを開いてください。
2. <DNT>**Data Provider Registry**</DNT>をクリックするか、トランザクション`/n/NEWR/REGISTRY`を使用します。
3. <DNT>**Data Provider Name**</DNT>を選択し、<DNT>**Configure**</DNT>をクリックして設定を確認するか、<DNT>**Test**</DNT>をクリックしてプロバイダーの機能を確認してください。
4. <DNT>**RuntimeStatus**</DNT>をクリックし、「Runtime status」画面のすべてのエントリを削除します。
