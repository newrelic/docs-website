* モニターされる合計<DNT>**SIDs**</DNT>が10未満で、インスタンスが50を超えない場合、専用サーバーは必要ありません。<DNT>**SIDs**</DNT>が10を超えるか、インスタンスが100を超える場合は、専用サーバーをお勧めします。
* 専用サーバーに配置する<DNT>**App Server**</DNT>インスタンスは2つ以下とし、それぞれに96Gのメモリと12コアCPUを搭載する必要があります。監視システムが<DNT>**HANA database**</DNT>で実行されている場合、データベースサーバーのインスタンスをアプリケーションサーバーのインスタンスから分離することをお勧めします。
