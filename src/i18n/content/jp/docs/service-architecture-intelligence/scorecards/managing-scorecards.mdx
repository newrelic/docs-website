スコアカードは、定義された標準への準拠を総合的に評価するさまざまなルールのコンテナとして機能します。 スコアカードはルールを使用して、さまざまなエンティティやチームにわたるコンプライアンスを監視し、改善の余地がある領域を特定し、内部および外部の両方の要件との整合性を確保します。 このドキュメントでは、New Relic でスコアカードとそのルールを作成および管理する方法について説明します。

## 新しいスコアカードを作成する [#create-scorecard]

利用可能なテンプレートの 1 つまたは独自のスコアカードを使用してスコアカードを作成し、要件を満たすルールを追加できます。詳細については、以下を参照してください。

* [テンプレートを使用してスコアカードを作成する](#create-scorecard-using-templates)
* [カスタムスコアカードを作成する](#create-custom-scorecard)

<Callout variant="tip" title="ヒント">
  NerdGraph ミューテーションを使用してスコアカードを作成または管理します。詳細については、[スコアカードのチュートリアル](/docs/apis/nerdgraph/examples/nerdgraph-scorecards-tutorial)を参照してください。
</Callout>

**前提条件:**

* このスコアカードを作成するには、アクティブな New Relic アカウント ID が必要です。
* スコアカードを作成するための適切なロール。[ロールと権限](#roles-permissions)を参照してください。

### テンプレートを使用してスコアカードを作成する [#create-scorecard-using-templates]

**[テンプレート](/docs/service-architecture-intelligence/scorecards/templates)を使用してスコアカードを作成するには:**

1. New Relic のアカウントにログインします。

2. **左側のナビゲーション ペイン &gt; All Capabilities &gt; Scorecards &gt; Create Scorecard**に移動します。

3. **Create a Scorecard** \[スコアカードの作成]画面で、 **Use a template**\[テンプレートの使用]をクリックします。

4. **Choose a template** \[テンプレートの選択]画面で、リストからスコアカード テンプレートを選択し、 **Next** \[次へ]をクリックします。

5. **Manage the rules** \[ルールの管理]画面で次の操作を行います。

   * 必要なルールを有効にします。
   * **Run this rule in** \[このルールを実行する場所] ドロップダウン リストから、このルールを実行するアカウントを選択します。
   * **Next**\[次へ]をクリックします。

6. **Define maturity levels**画面で、各ルールを適切な成熟度バケット（**Below basic**、**Basic maturity**、**Intermediate maturity**、または**Advanced maturity**）にドラッグアンドドロップし、**Next**をクリックします。詳細については、[サービスの成熟度](/docs/service-architecture-intelligence/scorecards/service-maturity)を参照してください。

7. **Review your Scorecard details** \[スコアカードの詳細の確認]画面で、必要に応じて、スコアカードの名前と説明を更新します。
   * **Confirm &amp; Create** \[確認して作成]をクリックします。

8. スコアカードを作成した後、必要に応じて追加のルールを追加することもできます。詳細については、 [「スコアカード ルールの作成」](#create-scorecard-rules)を参照してください。

### カスタムスコアカードを作成する [#create-custom-scorecard]

**独自のスコアカードを作成するには:**

1. New Relic のアカウントにログインします。
2. **左側のナビゲーション ペイン &gt; All Capabilities &gt; Scorecards &gt; Create Scorecard**に移動します。
3. **Create a Scorecard** \[スコアカードの作成]画面で、 **Build your own** \[独自のスコアカードを作成]をクリックします。
4. 名前と説明を入力し、 **Create** \[作成]をクリックします。
5. スコアカードを作成したら、ルールを追加して構成し、特定のコンプライアンス基準を定義します。詳細については、 [「スコアカード ルールの作成」](#create-scorecard-rules)を参照してください。

## スコアカードルールを作成する [#create-scorecard-rules]

スコアカードのルールは、特定のコンプライアンス基準に照らしてエンティティを評価するために使用されます。サービス、アプリケーション、またはその他のリソースが特定の要件に準拠しているかどうかを検証するプロセスを自動化するルールを定義できます。

NRQL クエリを使用してスコアカードのルールを作成できます。各ルールは複数のエンティティにまたがることができ、true または false に評価することで各エンティティが特定の条件を満たすかどうかを検証できます。

**前提条件:**

* このルールを作成するには、アクティブなNew RelicアカウントIDが必要です
* スコアカードが作成されました。詳細については、 [「新しいスコアカードを作成する」](#create-scorecard)を参照してください。
* <DNT>**Org Product Admin**</DNT>ロールを持つユーザーは、スコアカードとルールを作成、更新、削除できます。これらの権限を他のユーザーに委任する必要がある場合は、[UIからScorecardsのカスタムロールを作成](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/#roles)できます。

<Callout variant="tip" title="ヒント">
  NerdGraphミューテーションを使用して、Scorecardsルールを作成または管理します。詳細については、[NerdGraph Scorecardsチュートリアル](/docs/apis/nerdgraph/examples/nerdgraph-scorecards-tutorial)を参照してください。
</Callout>

**ルールを作成するには:**

1. New Relic のアカウントにログインします。

2. **左側のナビゲーション ペイン &gt; All Capabilities &gt; Scorecards**に移動します。

3. 必要なスコアカードを選択します。

4. **+ Create Rule** \[+ ルールの作成を]クリックします。

5. 評価するエンティティを含む New Relic アカウントを選択し、クエリで他のアカウントのデータとエンティティを結合する必要がある場合は、オプションで結合アカウントの短いリストを選択します。

6. 条件を指定する NRQL クエリを入力します。クエリには次の 2 つのフィールドが含まれている必要があります。

   * `FACET`を`entityGUID`で例: `FACET id`として `entityGuid`

   * `0`または`1`のスコアを評価するためのスコア列。たとえば、 `SELECT if(latest(reporting), 1, 0) as 'score'` 。

     NRQLの例:

     ```sql
     SELECT latest(if(tags.language = 'ruby', 0, 1)) as 'score'
     FROM Entity
     WHERE tags.environment = 'production' and type = 'APM-APPLICATION'
     SINCE 1 day ago
     FACET id, tags.nr.team as 'team'
     ```

7. クエリを検証するには、「このクエリを実行」をクリックします。実行が成功すると、プレビュー応答が表示されます。

   <Callout variant="tip" title="ヒント">
     \[既存のクエリを使用する] ドロップダウン リストから、ルールで実行する以前に作成したクエリを選択します。
   </Callout>

8. **Next**\[次へ]をクリックします。

9. ルールの名前と説明を入力します。

10. **Save and create** \[保存して作成]をクリックします。

<Callout variant="tip">
  Scorecardの作成時に成熟度レベルを定義する際、または後でルールを編集する際に、ルールを[成熟度レベル](/docs/service-architecture-intelligence/scorecards/service-maturity)に割り当てることができます。ルールの重みを設定したり、カスタムの成熟度レベルを作成したりするには、[NerdGraph Scorecardsチュートリアル](/docs/apis/nerdgraph/examples/nerdgraph-scorecards-tutorial)を使用してください。
</Callout>

**スコアカードを更新するには:**

1. New Relic のアカウントにログインします。

## 更新ルール [#update-rule]

Scorecardの既存のルールを有効または無効にすることもできます。ルールを編集する際、その[成熟度レベル](/docs/service-architecture-intelligence/scorecards/service-maturity)を変更できます；ルールの重みは[NerdGraph API](/docs/apis/nerdgraph/examples/nerdgraph-scorecards-tutorial)を通じて設定されます。

**ルールを更新するには:**

1. New Relic のアカウントにログインします。
2. **左側のナビゲーション ペイン &gt; All Capabilities &gt; Scorecards**に移動します。
3. 必要なスコアカードを選択します。
4. 右上隅の<DNT>more icon</DNT>クリックし、 **Activate and deactivate rules** \[ルールの有効化と無効化]を選択します。
5. 必要なルールを有効または無効にして、 **Save** \[保存]をクリックします。

## ルールの通知の設定 [#rule-notifications]

ルールのスコアが設定した閾値を下回った場合に通知を受け取ることができます。Scorecardsの通知はNew Relic [アラート](/docs/alerts/overview/)に基づいて構築されています：通知を作成すると、Scorecardsは自動的にルールのためのアラート[ポリシー](/docs/alerts/organize-alerts/create-edit-or-find-alert-policy/)と[条件](/docs/alerts/create-alert/create-alert-condition/create-nrql-alert-conditions/)を作成し、選択した宛先に通知を配信する[ワークフロー](/docs/alerts/get-notified/alert-event-workflows/)をアタッチします。

**通知を設定する場合は、以下の手順に従います。**

1. New Relic のアカウントにログインします。

2. **左側のナビゲーション ペイン &gt; All Capabilities &gt; Scorecards**に移動し、Scorecardを選択します。

3. 通知を受け取りたいルールを開きます。

4. ルールページで、**Set up a notification**をクリックし、ウィザードを完了します：

   1. **閾値を設定する**: ルールのスコアがこのレベルを下回ったときに通知されます。
   2. **Select an account**: アラートポリシーと条件が保存されているアカウント。Scorecardsはポリシーと条件を自動的に作成し、ルールにちなんでポリシーに名前を付けます。
   3. **ワークフローを追加する**: 選択した[宛先](/docs/alerts/get-notified/destinations/)に通知を配信するワークフローを選択します。
   4. **Review &amp; create**: 設定を確認し、通知を作成します。

<img title="Set up a notification on a Scorecard rule" alt="A Scorecard rule page showing the Set up a notification and Manage notifications buttons" src="/images/scorecards-rule-notification.webp" />

後で通知を編集または削除するには、ルールページを開き、**Manage notifications**をクリックします。

## スコアカードのベストプラクティス [#scorecards-best-practices]

* スコアカードを定期的に確認し、戦略目標との整合性を確保します。
* 履歴データを使用して傾向を特定し、情報に基づいた意思決定を行います。
