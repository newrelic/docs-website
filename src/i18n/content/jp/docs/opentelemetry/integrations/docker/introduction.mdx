DockerのOpenTelemetryインテグレーションは、Docker Engineから直接リアルタイムメトリクスを収集することで、コンテナ化されたアプリケーションのヘルスとパフォーマンスをモニターします。実行中のすべてのコンテナについて、CPU使用率、メモリ、ネットワークI/O、およびディスクI/Oを可視化できるため、サービスに影響を及ぼす前に、リソースのボトルネックやコンテナの障害を検知できます。

## 機能 [#capabilities]

このインテグレーションは以下を提供します：

* **メトリクス**：CPU使用量と使用率、メモリ使用量とパーセンテージ、ネットワークI/O（送受信されたバイトとパケット、ドロップ、エラー）、ブロックI/O、およびプロセス（PID）数
* **Entities \[エンティティ]**: Dockerコンテナは、ホストにリンクされたモニターされるエンティティとして、New Relicに表示されます
* **Logs \[ログ]**：コンテナからログを収集します。設定手順については、「[高度な設定](/docs/opentelemetry/integrations/docker/advanced-configuration#logs)」を参照してください。

## インストールパスの選択 [#choose]

* **[NRDOT Collector](/docs/opentelemetry/integrations/docker/install-nrdot)（推奨）**: New Relicにデータを送信するように事前設定された、New RelicのOpenTelemetryディストリビューションです。別のOpenTelemetry Collectorをまだ実行していない場合は、これを使用してください。
* **[OpenTelemetry Collector Contrib](/docs/opentelemetry/integrations/docker/install-otelcol-contrib)**: アップストリームのコミュニティコレクターです。他のワークロードで既にOpenTelemetry Collector Contribを実行しており、同じインスタンスにDocker監視を追加したい場合は、これを使用してください。

## インストレーションの概要 [#at-a-glance]

インストールページでは、以下の手順について説明します：

1. 互換性を確認し、前提条件を収集する
2. 選択したコレクターをインストールしてください。
3. Dockerソケットのパーミッションの設定
4. コレクターを構成する
5. コレクターを再起動します
6. データがNew Relicに送信されていることを確認する
