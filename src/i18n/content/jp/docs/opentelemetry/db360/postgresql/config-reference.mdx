このリファレンスは、New Relic Distribution of OpenTelemetry（NRDOT）Collectorを使用したPostgreSQL監視のための包括的なYAML設定を提供します。これらのフル機能の設定には、セルフホスト型およびAmazon RDSデプロイメント全体にわたる本番環境向けの完全なPostgreSQLメトリクスカタログが含まれています。

<Callout variant="important">
  **すぐに使い始めたいですか？**これらは本番環境用の高度な設定です。初めてPostgreSQL監視を設定する場合は、セットアップガイドの標準設定から始め、基本的な機能を確認してから、これらの包括的な設定に戻ることをお勧めします。
</Callout>
