`newrelic.newrelic_install` Ansibleロールを使用して、MySQL監視用のNRDOT Collectorをインストールして構成できます。このロールは、1回のプレイでコレクターをインストールし、監視ユーザーを作成し、コレクターを構成します。

<Callout variant="tip" title="ガイド付きインストレーション">
代わりにNew Relic UIからインストールするには、<DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; MySQL (Database 360)](https://onenr.io/0oQDYBNG1wy)** </DNT>に移動してください。このページでは、手動インストレーションについてのみ説明します。
</Callout>

<Steps>
<Step>
## 前提条件 [#prerequisites]

* 有効な[ライセンスキー](/docs/apis/intro-apis/new-relic-api-keys/#overview-keys)を持つNew Relicアカウント。
* New Relic [アカウントID](/docs/accounts/accounts-billing/account-structure/account-id)。
* MySQL 5.7以降。
* Ansible Core 2.13または2.14、Python 3.10、および`ansible.windows`と`ansible.utils`のコレクション。
* Debian/UbuntuまたはRHEL/CentOSを実行しているLinuxコレクターホスト。
* セルフホスト型MySQLの場合：パスワードベースの認証を使用した、MySQLサーバーへの管理者アクセス（`root`アカウントまたは同等のもの）。
* AWS RDS上のMySQLまたはAuroraの場合：コレクターホストからRDSエンドポイントへのネットワーク接続、およびRDSマスターユーザー名とパスワードが必要です。
* ご利用のリージョンの[New Relic OTLPエンドポイント](/docs/opentelemetry/best-practices/opentelemetry-otlp)へのネットワーク接続。

詳細な要件については、[「互換性と前提条件」](/docs/opentelemetry/db360/mysql/compatibility)を参照してください。
</Step>

<Step>
## 役割をインストールします [#ansible-install-role]

```bash
ansible-galaxy install newrelic.newrelic_install
```

必要なコレクションもインストールされていることを確認してください：

```bash
ansible-galaxy collection install ansible.windows ansible.utils
```
</Step>

<Step>
## プレイブックを設定してください [#ansible-configure]

<CollapserGroup>
<Collapser id="ansible-host" title="セルフホスト型MySQL">
このロールは、単一のコレクターから1つ以上のMySQLインスタンスをモニターします。単一のホスト/ポート/資格情報のセットの代わりに、ターゲットホスト上にすでに存在している必要がある2つのファイルを読み取ります：モニターするすべてのインスタンスをリストしたインスタンスファイル（YAML）と、各インスタンスの管理者ログインとパスワードを含み、一致するようにインデックス付けされたシークレットファイル（`KEY=VALUE`）です。正確なファイル形式については、[「CLIインストール」](/docs/opentelemetry/db360/mysql/cli/#cli-install)ページを参照してください。

`playbook.yml`という名前のファイルを作成し、以下の内容をコピーします。`targets`を`mysql-otel`に設定し、プレースホルダーの値を独自の値に置き換えます：

```yaml
- name: Install New Relic NRDOT for MySQL
  hosts: all
  roles:
    - role: newrelic.newrelic_install
  vars:
    targets:
      - mysql-otel
  environment:
    NEW_RELIC_API_KEY: <API key>
    NEW_RELIC_ACCOUNT_ID: <Account ID>
    NEW_RELIC_REGION: <Region>
    NR_CLI_MYSQL_CONFIG_PRESET: <1 Basic, 2 Advanced, default 1>
    NR_CLI_MYSQL_INSTANCES_FILE: <path to the instances YAML file on the target host>
    NR_CLI_MYSQL_SECRETS_FILE: <path to the secrets file (KEY=VALUE per instance) on the target host>
```

<Callout variant="important">
ロールはパスワードを使用してTCP経由でMySQLに接続するため、シークレットファイルの管理者アカウントはパスワードベースの認証を使用する必要があります。一部のDebian/Ubuntuインストールでは、`root`@`localhost`はデフォルトで`auth_socket`プラグイン（パスワードなし、ローカルソケットのみ）になりますが、これはここでは機能しません。プレイブックを実行する前に切り替えてください：

```bash
mysql -u root -e "ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '<password>';"
```
</Callout>

<Callout variant="tip">
デバッグロギングを有効にするには、プレイブックの`vars`の下に`verbosity: "debug"`を追加します。
</Callout>

</Callout>

<Collapser id="ansible-rds" title="AWS RDS上のMySQLまたはAurora">
このロールは、セルフホストと同じインスタンスファイル/シークレットファイルのパターンを使用して、単一のコレクターから1つ以上のRDS MySQLまたはAuroraエンドポイントをモニターします（両方のファイルがターゲットホスト上にすでに存在している必要があります）。`playbook.yml`という名前のファイルを作成し、次のコンテンツをコピーします。`targets`を`mysql-otel-rds`に設定し、プレースホルダーの値を独自の値に置き換えます：

```yaml
- name: Install New Relic NRDOT for MySQL on RDS
  hosts: all
  roles:
    - role: newrelic.newrelic_install
  vars:
    targets:
      - mysql-otel-rds
  environment:
    NEW_RELIC_API_KEY: <API key>
    NEW_RELIC_ACCOUNT_ID: <Account ID>
    NEW_RELIC_REGION: <Region>
    NR_CLI_MYSQL_CONFIG_PRESET: <1 Basic, 2 Advanced, default 1>
    NR_CLI_MYSQL_INSTANCES_FILE: <path to the instances YAML file on the target host, using RDS endpoints as host>
    NR_CLI_MYSQL_SECRETS_FILE: <path to the secrets file (KEY=VALUE per instance) on the target host>
```

<Callout variant="tip">
デバッグロギングを有効にするには、プレイブックの`vars`の下に`verbosity: "debug"`を追加します。
</Callout>

## プレイブックを実行します [#ansible-run]

```bash
ansible-playbook -i <inventory_file> <playbook_file>.yml
```
</Step>

<Step>
## データを探す、使う [#find]

データの収集が開始されると、New Relic UIから包括的なMySQLデータベース監視にアクセスできます。

New RelicでMySQLデータベースエンティティを見つけるには：

1. <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; All capabilities &gt; Databases**</DNT>に移動します。
2. **<DNT>Entity type</DNT>**ドロップダウンから<DNT>**MySQL instance**</DNT>を選択し、<DNT>**Apply**</DNT>をクリックします。
3. エンティティのリストからMySQLデータベースを選択します。
</Step>
