`newrelic-install` Chefクックブックを使用して、MySQL監視用のNRDOT Collectorをインストールおよび設定できます。`newrelic-install::default`レシピを実行すると、クックブックはコレクターをインストールし、監視ユーザーを作成し、コレクターを設定します。

<Callout variant="tip" title="ガイド付きインストレーション">
代わりにNew Relic UIからインストールするには、<DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; MySQL (Database 360)](https://onenr.io/0oQDYBNG1wy)** </DNT>に移動してください。このページでは、手動インストレーションについてのみ説明します。
</Callout>

<Steps>
<Step>
## 前提条件 [#prerequisites]

* 有効な[ライセンスキー](/docs/apis/intro-apis/new-relic-api-keys/#overview-keys)を持つNew Relicアカウント。
* New Relic [アカウントID](/docs/accounts/accounts-billing/account-structure/account-id)。
* MySQL 5.7以降。
* Chef 15以降が必要です。
* Debian/UbuntuまたはRHEL/CentOSを実行しているLinuxコレクターホスト。
* セルフホスト型MySQLの場合：パスワードベースの認証を使用した、MySQLサーバーへの管理者アクセス（`root`アカウントまたは同等のもの）。
* AWS RDS上のMySQLまたはAuroraの場合：コレクターホストからRDSエンドポイントへのネットワーク接続、およびRDSマスターユーザー名とパスワードが必要です。
* ご利用のリージョンの[New Relic OTLPエンドポイント](/docs/opentelemetry/best-practices/opentelemetry-otlp)へのネットワーク接続。

詳細な要件については、[「互換性と前提条件」](/docs/opentelemetry/db360/mysql/compatibility)を参照してください。
</Step>

<Step>
## Chefクックブックをダウンロードします。 [#chef-download-cookbook]

Chef Supermarketから`newrelic-install` [Chefクックブック](https://supermarket.chef.io/cookbooks/newrelic-install)をchef-repoディレクトリにダウンロードします：

```bash
knife supermarket install newrelic-install
```
</Step>

<Step>
## デフォルトの属性を置き換えます [#chef-configure]

`attributes/default.rb`のデフォルトの属性をアカウントの詳細に置き換えてください：

<CollapserGroup>
<Collapser id="chef-host" title="セルフホスト型MySQL">
このクックブックは、単一のコレクターから1つ以上のMySQLインスタンスをモニターします。単一のホスト/ポート/認証情報のセットの代わりに、ノード上にすでに存在している必要がある2つのファイルを読み込みます：モニターするすべてのインスタンスをリストしたインスタンスファイル（YAML）と、それぞれに対応するようにインデックス付けされた、管理者のログインとパスワードを含むシークレットファイル（`KEY=VALUE`）です。正確なファイル形式については、[「CLIインストール」](/docs/opentelemetry/db360/mysql/cli/#cli-install)ページを参照してください。

```ruby
default['newrelic_install']['NEW_RELIC_API_KEY']    = <API key>
default['newrelic_install']['NEW_RELIC_ACCOUNT_ID'] = <Account ID>
default['newrelic_install']['NEW_RELIC_REGION']     = <Region>
default['newrelic_install']['targets'] = [
  'nrdot-collector-mysql'
]
default['newrelic_install']['env']['NR_CLI_MYSQL_CONFIG_PRESET']  = <1 Basic, 2 Advanced, default 1>
default['newrelic_install']['env']['NR_CLI_MYSQL_INSTANCES_FILE'] = <path to the instances YAML file on the node>
default['newrelic_install']['env']['NR_CLI_MYSQL_SECRETS_FILE']   = <path to the secrets file (KEY=VALUE per instance) on the node>
# See all available targets at: https://github.com/newrelic/chef-install
```

<Callout variant="important">
クックブックはパスワードを使用してTCP経由でMySQLに接続するため、シークレットファイル内の管理者アカウントはパスワードベースの認証を使用する必要があります。一部のDebian/Ubuntuインストールでは、`root`@`localhost`はデフォルトで`auth_socket`プラグイン（パスワードなし、ローカルソケットのみ）になりますが、これはここでは機能しません。レシピを実行する前に切り替えてください：

```bash
mysql -u root -e "ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '<password>';"
```
</Callout>

<Collapser id="chef-rds" title="AWS RDS上のMySQLまたはAurora">
このクックブックは、セルフホスト型と同じインスタンスファイル/シークレットファイルのパターンを使用して、単一のコレクターから1つ以上のRDS MySQLまたはAuroraエンドポイントをモニターします（両方のファイルはノード上にすでに存在している必要があります）。

```ruby
default['newrelic_install']['NEW_RELIC_API_KEY']    = <API key>
default['newrelic_install']['NEW_RELIC_ACCOUNT_ID'] = <Account ID>
default['newrelic_install']['NEW_RELIC_REGION']     = <Region>
default['newrelic_install']['targets'] = [
  'nrdot-collector-mysql-rds'
]
default['newrelic_install']['env']['NR_CLI_MYSQL_CONFIG_PRESET']  = <1 Basic, 2 Advanced, default 1>
default['newrelic_install']['env']['NR_CLI_MYSQL_INSTANCES_FILE'] = <path to the instances YAML file on the node, using RDS endpoints as host>
default['newrelic_install']['env']['NR_CLI_MYSQL_SECRETS_FILE']   = <path to the secrets file (KEY=VALUE per instance) on the node>
# See all available targets at: https://github.com/newrelic/chef-install
```

<Step>
## Chefクックブックをアップロードします。 [#chef-upload-cookbook]

`newrelic-install` ChefクックブックをChefサーバーにアップロードします：

```bash
knife cookbook upload newrelic-install
```
</Step>

<Step>
## ランリストを更新します。 [#chef-run-list]

ノードのランリストに `newrelic-install` レシピを追加します：

```json
"run_list": [
  "recipe[newrelic-install]"
]
```
</Step>

<Step>
## データを探す、使う [#find]

データの収集が開始されると、New Relic UIから包括的なMySQLデータベース監視にアクセスできます。

New RelicでMySQLデータベースエンティティを見つけるには：

1. <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; All capabilities &gt; Databases**</DNT>に移動します。
2. **<DNT>Entity type</DNT>**ドロップダウンから<DNT>**MySQL instance**</DNT>を選択し、<DNT>**Apply**</DNT>をクリックします。
3. エンティティのリストからMySQLデータベースを選択します。
</Step>
