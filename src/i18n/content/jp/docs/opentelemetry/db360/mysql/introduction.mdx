データベースメトリクス、クエリパフォーマンス、およびシステムヘルスに関する包括的なインサイトを備えたNew Relic Distribution of OpenTelemetry（NRDOT）を使用して、MySQLデータベースのパフォーマンスをモニターします。

この NRDOT ベースのアプローチは、データベース監視のOpenTelemetry標準を活用することで既存のオンホスト インテグレーション (OHI) を補完し、既存の監視スタックとの統合を容易にします。

オンホストインテグレーションとは異なり、NRDOTはinfrastructureエージェントとは独立して動作します。データベースのテレメトリーを収集するために、infrastructureエージェントは必要ありません。NRDOTにはネイティブのホスト監視機能も含まれているため、以下を選択できます：

* ホスト監視用のinfrastructureエージェントをデータベース監視用のNRDOTと併用するか、または
* NRDOTを使用して、データベースとホストの両方をモニターしてください。

MySQL監視用のNRDOT Collectorは、以下の方法でインストールできます。

* [セルフホスト型MySQL](/docs/opentelemetry/db360/mysql/hosted)
* [AWS RDS または Aurora MySQL の監視](/docs/opentelemetry/db360/mysql/rds)
* [New Relic CLI](/docs/opentelemetry/db360/mysql/cli)
* [Ansible](/docs/opentelemetry/db360/mysql/ansible)
* [Chef](/docs/opentelemetry/db360/mysql/chef)
* [Helmチャート](/docs/opentelemetry/db360/mysql/helm)
* [Docker](/docs/opentelemetry/db360/mysql/docker)

## ガイド付きインストール [#ui-install]

代わりにNew Relic UIからこれをインストールするには、<DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; MySQL (Database 360)](https://onenr.io/0oQDYBNG1wy)** </DNT>にアクセスしてください。画面上の指示に従って、インテグレーションを設定します。

## インストレーションの概要 [#at-a-glance]

1. 互換性を確認し、前提条件を収集してください。
2. NRDOT Collectorをインストールします。
3. 監視ユーザーを設定します。
4. NRDOT Collectorを設定します。
5. NRDOT Collectorを再起動してください。
6. New Relic にデータが流れていることを確認します。
