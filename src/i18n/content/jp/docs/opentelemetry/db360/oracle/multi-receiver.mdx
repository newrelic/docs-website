1つのコレクターから複数のOracleデータベースインスタンスをモニターするようにNRDOT Collectorを設定できます。これは、異なるホストで複数のOracleデータベースが実行されており、単一のNRDOT Collectorインスタンスを使用してそれらすべてからメトリクスを収集したい場合に便利です。

<Steps>
  <Step>
    ## 前提条件 [#prerequisites]

    * NRDOTがOracle データベースインスタンス用にインストールおよび設定されていること：

      * [CDB](/docs/opentelemetry/db360/oracle/host-cdb)
      * [PDB](/docs/opentelemetry/db360/oracle/host-pdb)
      * [RDS](/docs/opentelemetry/db360/oracle/rds)
      * [ADB](/docs/opentelemetry/db360/oracle/adb)
  </Step>

  <Step>
    ## マルチレシーバー設定の追加 [#multi]

    以下の例では、マルチレシーバー設定を使用して複数のOracle データベースインスタンスをモニターするようにNRDOT Collectorを設定する方法を示します。環境に合ったデプロイメントタイプを選択してください。追加のインスタンス用に、必要に応じてレシーバーを追加できます。

    <CollapserGroup>
      <Collapser id="cdb" title="オンホストのコンテナデータベース（CDB）向け">
        以下の`oracle-config.yaml`は、共通のエクスポーターを共有しながら、異なるオンホスト（マルチテナント）CDBインスタンス用に複数のレシーバーをセットアップする方法を示しています。

        ```yaml
        receivers:
          # First CDB configuration (anchor cd1; cdb2 inherit via merge key)
          nroracledb/cdb1: &nroracledb-common
            endpoint: "<YOUR_DB_HOST>:<YOUR_DB_PORT>"
            username: "C##<YOUR_DB_USERNAME>"
            password: "<YOUR_DB_PASSWORD>"
            service: "<YOUR_CDB1_SERVICE_NAME>"
            collection_interval: 15s

            events:
              db.server.query_sample:
                enabled: true
              db.server.top_query:
                enabled: true
              db.server.session.wait_sample:
                enabled: true
              db.server.top_procedure:
                enabled: true
              db.server.query_plan:
                enabled: true

              max_query_sample_count: 1000
              top_query_count: 200
              collection_interval: 60s
              allowed_comment_keys:
                - nr_service_guid

            query_sample_collection:
              max_rows_per_query: 100

                - nr_service_guid

              exporters: [otlp/newrelic]
        ```

        ```yaml
                enabled: true
              db.server.top_query:
        ```

  <Step>
    ## NRDOT Collectorを再起動します [#restart]

    設定の変更を有効にするには、<DNT>NRDOT Collector</DNT>サービスを再起動してください。コレクターは起動時に一度だけ設定パラメーターを読み込み、ホットリロードをサポートしていません。コレクターの実行中に設定に加えられた変更は、プロセスが再起動されるまで無効なままです。

    ```bash
    sudo systemctl restart nrdot-collector.service
    ```
  </Step>
