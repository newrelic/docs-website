OpenTelemetryベースの監視ソリューションを使用して、Oracleデータベースのパフォーマンスに関する深いインサイトを取得します。データベースのメトリクスを追跡し、クエリのパフォーマンスを分析し、リソース使用量をモニターして、データベースのパフォーマンスをアプリケーションと関連付けます。

この NRDOT ベースのアプローチは、データベース監視のOpenTelemetry標準を活用することで既存のオンホスト インテグレーション (OHI) を補完し、既存の監視スタックとの統合を容易にします。

オンホストインテグレーションとは異なり、NRDOTはinfrastructureエージェントとは独立して動作します。データベースのテレメトリーを収集するために、infrastructureエージェントは必要ありません。NRDOTにはネイティブのホスト監視機能も含まれているため、以下を選択できます：

* ホスト監視用のinfrastructureエージェントをデータベース監視用のNRDOTと併用するか、または
* NRDOTを使用して、データベースとホストの両方をモニターしてください。

## 機能 [#capabilities]

* **OpenTelemetry標準**：既存のオブザーバビリティツールとシームレスに統合します
* **包括的なメトリクス**：データベースのパフォーマンス、待機イベント、リソース使用状況に関する深いインサイト
* **クエリレベルのインサイト**：パフォーマンスの低いクエリとセッションアクティビティを特定して分析します
* **柔軟なデプロイメント**：オンホストのCDB/PDBおよびAmazon RDS環境で動作します。
* **APMの相関関係**：データベースのパフォーマンスをアプリケーションのトレースに接続します

## インストールパスの選択 [#choose]

Oracleデータベース監視用のNRDOT Collectorは、以下の方法でインストールできます：

* セルフホスト環境: 独自のインフラストラクチャへの手動インストレーション

  * [オンホストのコンテナデータベース（CDB）](/docs/opentelemetry/db360/oracle/host-cdb)：その配下にあるすべてのプラガブルデータベースを含む、コンテナデータベース全体をモニターします。
  * [オンホストのプラガブル・データベース（PDB）](/docs/opentelemetry/db360/oracle/host-pdb)：個々のプラガブル・データベースをモニターします。

* AWS RDS環境：クラウド管理のOracleデータベース監視
  * [RDS監視](/docs/opentelemetry/db360/oracle/rds)：Amazon RDSで実行されているOracleデータベースインスタンスをモニターします。

* Oracle Cloud環境：フルマネージドのOracleデータベース監視
  * [Autonomous Database（ADB）の監視](/docs/opentelemetry/db360/oracle/adb): Oracle Autonomous Databaseインスタンスをモニターします。

* [New Relic CLI](/docs/opentelemetry/db360/oracle/cli)：単一のコマンドでコレクターをインストールして設定します

* [Ansible](/docs/opentelemetry/db360/oracle/ansible)：`newrelic.newrelic_install` Ansibleロールを使用して、コレクターを大規模にインストールおよび構成します

* [Chef](/docs/opentelemetry/db360/oracle/chef): `newrelic-install` Chefクックブックを使用して、コレクターを大規模にインストールおよび構成します

* [Helmチャート](/docs/opentelemetry/db360/oracle/helm)：`oracle-otel` Helmチャートを使用して、Kubernetes上でOracleデータベース監視をインストールして設定します

* [Docker](/docs/opentelemetry/db360/oracle/docker): すでにDockerで実行されているOracleデータベースインスタンスの兄弟コンテナとしてコレクターを実行します。

## ガイド付きインストレーション [#ui-install]

<DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; Oracle (Database 360)](https://onenr.io/0kjnebKW7Ro)**</DNT>でガイド付きインストレーションを利用できます。UIは、ガイド付きのエンドツーエンドのワークフローを提供します。

## インストレーションの概要 [#at-a-glance]

1. 互換性を確認し、前提条件を収集してください。
2. NRDOT Collectorをインストールします。
3. 監視ユーザーを設定します。
4. NRDOT Collectorを設定します。
5. NRDOT Collectorを再起動してください。
6. New Relic にデータが流れていることを確認します。
