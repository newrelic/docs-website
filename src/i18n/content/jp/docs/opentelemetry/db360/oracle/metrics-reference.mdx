NRDOT Collectorによって収集された包括的なメトリクスを使用して、Oracleデータベースのパフォーマンスをモニターします。デフォルトでは、New Relicは[デフォルトのメトリクスとイベント](#default)セクションで参照されているメトリクスとクエリレベルのイベントを収集します。[フル機能のメトリクス](#full-feature)セクションに記載されている目的のメトリクスを有効にすることで、監視を強化できます。

### イベント検索 [#query-events]

次のイベントはOpenTelemetryログレコードとして収集され、デフォルトで有効になっています。これらはクエリレベルの可視性を提供します。

<CollapserGroup>
<Collapser id="db-server-query-sample" title="クエリのサンプル">
セッションごとのアクティブなクエリのサンプル。収集時のアクティブなOracleセッションの現在の実行状態をキャプチャします。このイベントはデフォルトで有効化されています。

これらの属性は、 `DbServerQuerySample`イベントをクエリすることで見つけることができます。

その動作を調整するには、`query_sample_collection`ブロックを使用します：

```yaml
query_sample_collection:
  max_rows_per_query: 100
  allowed_comment_keys:
    - nr_service_guid
```

<Collapser id="db-server-session-wait-sample" title="セッション待機サンプル">
セッションごとの待機イベントの統計。セッションごとの待機時間のカウントと期間をキャプチャします。このイベントはデフォルトで有効化されています。

これらの属性は、 `DbServerSessionWaitSample`イベントをクエリすることで見つけることができます。

その動作を調整するには、`session_wait_event_collection`ブロックを使用します：
