`newrelic-install` Chefクックブックを使用して、Oracleデータベース監視用のNRDOT Collectorをインストールおよび構成できます。`newrelic-install::default` レシピを実行すると、クックブックはコレクターをインストールし、監視データベースユーザーを作成し、コレクターを構成します。

<Callout variant="tip" title="ガイド付きインストレーション">
代わりにNew Relic UIからインストールするには、<DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; Oracle (Database 360)](https://onenr.io/0kjnebKW7Ro)**</DNT>に移動してください。このページでは、手動インストレーションについてのみ説明します。
</Callout>

<Steps>
<Step>
## 前提条件 [#prerequisites]

* 有効な[ライセンスキー](/docs/apis/intro-apis/new-relic-api-keys/#overview-keys)を持つNew Relicアカウント。
* New Relic [アカウントID](/docs/accounts/accounts-billing/account-structure/account-id)。
* Oracleデータベース19c以降。
* Chef 15以降が必要です。
* セルフホスト型Oracleの場合：SSHユーザーがパスワードプロンプトなしで`sudo su - oracle`を実行できるOracleデータベースホストへのSSHアクセス（エージェント転送付き）を備えたOracle Linux 7、8、または9。
* AWS RDS上のOracleの場合：Debian/UbuntuまたはCentOS/RHEL/OELを実行しているコレクター・ホスト。
* Oracle Autonomous データベース（ADB）の場合：Debian/UbuntuまたはCentOS/RHEL/OELを実行し、Oracle Instant Client（`sqlplus`）がインストールされ、`PATH`上にあるコレクターホスト；各インスタンスのエグレスIPがそのADBアクセス制御リストで許可されていること；および各インスタンスのOracle Walletがダウンロードされ、ノード上の独自のディレクトリに解凍されていること。
</Step>

<Step>
## Chefクックブックをダウンロードします。 [#download-cookbook]

Chef Supermarketから`newrelic-install` [Chefクックブック](https://supermarket.chef.io/cookbooks/newrelic-install)をchef-repoディレクトリにダウンロードします：

```bash
knife supermarket install newrelic-install
```
</Step>

<Step>
## デフォルトの属性を置き換えます [#configure]

`attributes/default.rb`のデフォルトの属性をアカウントの詳細に置き換えてください：

<CollapserGroup>
<Collapser id="chef-host" title="セルフホスト型Oracleデータベース">
このクックブックは、単一のコレクターから1つ以上のOracleデータベース・インスタンス（それぞれSSH経由で到達可能）をモニターします。単一のホスト/コンテナ/資格情報セットの代わりに、モニターするすべてのインスタンスがリストされた、ノード上にすでに存在している必要があるインスタンス・ファイル（YAML）と、オプションで、監視ユーザーのパスワードを自動生成する代わりに固定するためのシークレット・ファイルを読み取ります。正確なファイル形式については、[CLIインストール](/docs/opentelemetry/db360/oracle/cli/#install)を参照してください。

```ruby
default['newrelic_install']['NEW_RELIC_API_KEY']    = <API key>
default['newrelic_install']['NEW_RELIC_ACCOUNT_ID'] = <Account ID>
default['newrelic_install']['NEW_RELIC_REGION']     = <Region>
default['newrelic_install']['targets'] = [
  'nrdot-collector-oracle'
]
default['newrelic_install']['env']['NR_CLI_ORACLE_INSTANCES_FILE'] = <path to the instances YAML file on the node>
default['newrelic_install']['env']['NR_CLI_ORACLE_SECRETS_FILE']   = <optional path to a secrets file pinning monitoring passwords, on the node>
default['newrelic_install']['env']['NR_CLI_ORACLE_CONFIG_PRESET']  = <1 Basic, 2 Advanced, default 1>
# See all available targets at: https://github.com/newrelic/chef-install
```

<Collapser id="chef-rds" title="AWS RDS上のOracleデータベース">
このクックブックは、セルフホスト型と同じインスタンスファイル/シークレットファイルのパターンを使用して、単一のコレクターから1つ以上のRDS Oracleエンドポイントをモニターします（両方のファイルがノード上にすでに存在している必要があります）。

```ruby

default['newrelic_install']['targets'] = [
  'nrdot-collector-oracle-rds'
]
default['newrelic_install']['env']['NR_CLI_ORACLE_INSTANCES_FILE'] = <path to the instances YAML file on the node>
default['newrelic_install']['env']['NR_CLI_ORACLE_SECRETS_FILE']   = <path to the secrets file (KEY=VALUE per instance) on the node>
default['newrelic_install']['env']['NR_CLI_ORACLE_CONFIG_PRESET']  = <1 Basic, 2 Advanced, default 1>
# See all available targets at: https://github.com/newrelic/chef-install
```
