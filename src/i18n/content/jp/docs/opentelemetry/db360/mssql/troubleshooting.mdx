NRDOT Collectorを使用してMicrosoft SQL Serverを監視する際に発生する可能性のある一般的な問題のトラブルシューティングを行います。

## よくある問題 [#common-issues]

### ネットワーク接続の問題 [#network-connectivity]

NRDOT Collectorでネットワーク接続の問題が発生した場合は、次のコマンドを実行してSQL Serverインスタンスへの接続をテストしてください：

* Windows の場合は、次を実行します。

  ```shell
  Test-NetConnection -ComputerName <YOUR_IP_ADDRESS> -Port <YOUR_PORT_NUMBER>
  ```

* Linux の場合は、次を実行します。

  ```bash
  nc -zv <YOUR_IP_ADDRESS> <YOUR_PORT_NUMBER>
  ```

## New Relicにデータが表示されない [#data-not-flowing]

* レート制限関連の問題を確認するには、次を実行します：

  ```sql
  SELECT * FROM NrIntegrationError
  ```

* それでもデータが流れない場合は、メトリクスおよびログイベントにドロップルールが設定されているかどうかを確認してください。[ドロップフィルタールールによるログデータのドロップ](/docs/logs/ui-data/drop-data-drop-filter-rules/)および[Pipelineコントロール](/docs/new-relic-control/pipeline-control/overview/)をご覧ください。
