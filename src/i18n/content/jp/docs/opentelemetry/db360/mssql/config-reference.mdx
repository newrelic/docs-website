このリファレンスでは、New Relic Distribution of OpenTelemetry（NRDOT）Collectorを使用したMicrosoft SQL Server監視用の包括的なYAML設定を提供します。これらのフル機能の設定には、セルフホスト型およびAWS RDSデプロイメントの両方における、LinuxおよびWindows全体の利用可能なすべてのメトリクス、高度なプロセッサ設定、および本番環境向けに最適化されたパイプラインが含まれています。

<Callout variant="important">
  **すぐに開始したいとお考えですか？**これらは本番環境用の高度な設定です。初めてSQL Server監視を設定する場合は、セットアップガイドの標準設定から開始し、基本的な機能を確認してから、これらの包括的な設定に戻ることをお勧めします。
</Callout>

## レシーバーを設定してください。 [#receiver]

`max_concurrent_queries`を使用すると、各スクレイプサイクル中にレシーバーがSQL Serverに対して並行して実行するメトリクスクエリの数を制御できます。省略した場合、または0に設定した場合のデフォルト値は4です。

```yaml
receivers:
  nrsqlserver:
    max_concurrent_queries: 4  # default is 4 if omitted or set to 0
```
