OpenTelemetryベースの監視ソリューションを使用して、Oracleデータベースのパフォーマンスに関する深いインサイトを取得します。データベースのメトリクスを追跡し、クエリのパフォーマンスを分析し、リソース使用量をモニターして、データベースのパフォーマンスをアプリケーションと関連付けます。

この NRDOT ベースのアプローチは、データベース監視のOpenTelemetry標準を活用することで既存のオンホスト インテグレーション (OHI) を補完し、既存の監視スタックとの統合を容易にします。

## 機能 [#capabilities]

* **OpenTelemetry標準**：既存のオブザーバビリティツールとシームレスに統合します
* **包括的なメトリクス**：データベースのパフォーマンス、待機イベント、リソース使用状況に関する深いインサイト
* **クエリレベルのインサイト**：パフォーマンスの低いクエリとセッションアクティビティを特定して分析します
* **柔軟なデプロイメント**：オンホストのCDB/PDBおよびAmazon RDS環境で動作します。
* **APMの相関関係**：データベースのパフォーマンスをアプリケーションのトレースに接続します

## インストールパスの選択 [#choose]

Oracleデータベース監視用のNRDOT Collectorは、以下の方法でインストールできます：

* セルフホスト環境: 独自のインフラストラクチャへの手動インストレーション

  * [オンホストのコンテナ・データベース（CDB）](/docs/opentelemetry/database/oracle/host-cdb): その配下にあるすべてのプラガブル・データベースを含む、コンテナ・データベース全体をモニターします。
  * [オンホストのプラガブルデータベース（PDB）](/docs/opentelemetry/database/oracle/host-pdb)：個々のプラガブルデータベースをモニターします。

* AWS RDS環境：クラウド管理のOracleデータベース監視
  * [RDS監視](/docs/opentelemetry/database/oracle/rds)：Amazon RDSで実行されているOracleデータベースインスタンスをモニターします。

* Oracle Cloud環境：フルマネージドのOracleデータベース監視
  * [Autonomous データベース（ADB）の監視](/docs/opentelemetry/database/oracle/adb): Oracle Autonomous データベースのインスタンスをモニターします。

## ガイド付きインストレーション [#ui-install]

<DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; Oracle (OpenTelemetry)**</DNT>でガイド付きインストレーションを利用できます。UIは、ガイド付きのエンドツーエンドのワークフローを提供します。

## インストレーションの概要 [#at-a-glance]

<Steps>
  <Step>
    ### 前提条件 [#prerequisites]

    * 有効なNew Relic[ライセンスキー](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)
    * サポートされているアーキテクチャー: AMD64 および ARM64 を搭載した Linux
    * [New Relic OTLPエンドポイント](/docs/opentelemetry/best-practices/opentelemetry-otlp/)へのネットワーク接続
    * Oracleデータベース 19c 以降
  </Step>

  <Step>
    ### NRDOT Collectorをインストールする [#install-step]

    お使いの特定の環境の指示に従って、システムにNRDOT Collectorをインストールしてください。

    * [CDB](/docs/opentelemetry/database/oracle/host-cdb)
    * [PDB](/docs/opentelemetry/database/oracle/host-pdb)
    * [RDS](/docs/opentelemetry/database/oracle/rds)
    * [ADB](/docs/opentelemetry/database/oracle/adb)
  </Step>

  <Step>
    ### 監視ユーザーの構成 [#user]

    NRDOT Collectorがメトリクスとクエリパフォーマンスデータを収集できるように、必要な読み取り専用権限を持つ専用のOracleデータベースユーザーを作成してください。
  </Step>

  <Step>
    ### NRDOT Collectorを構成する [#configure]

    Oracleデータベースインスタンスに接続するようにNRDOT Collectorを設定してください。これには、接続の詳細、認証方法、および環境に必要な追加の設定オプションの指定が含まれます。
  </Step>

  <Step>
    ### NRDOT Collectorを再起動します [#restart]

    NRDOT Collectorの設定後、変更を適用してOracle データベースインスタンスからのデータ収集を開始するには、サービスを再起動してください。
  </Step>

  <Step>
    ### データを探す、使う [#find]

    データの収集が開始されると、New Relic UIから包括的なOracleデータベース監視にアクセスできます。

    New RelicでOracleデータベースエンティティを見つけるには：

    1. <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT>に移動します。
    2. 検索条件を<DNT>`instrumentation.provider = opentelemetry`</DNT>に設定します。
    3. エンティティのリストからOracleデータベースを選択します。
  </Step>
</Steps>
