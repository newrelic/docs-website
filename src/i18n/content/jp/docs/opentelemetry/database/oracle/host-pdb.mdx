  この機能はまだ開発中ですが、ぜひお試しください。

New Relic Distribution of OpenTelemetry（NRDOT）コレクターを使用して、データベース監視、クエリ分析、およびシステムヘルスメトリクスにより、Oracleプラガブルデータベース（PDB）のパフォーマンスに関する包括的なインサイトを取得します。

<Callout variant="tip" title="ガイド付きインストレーション">
  代わりにNew Relic UIからインストールするには、<DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; Oracle (OpenTelemetry)** </DNT>にアクセスしてください。このページでは、CLIでのインストール手順のみを説明します。
</Callout>

<Callout variant="tip">
  個別のプラガブルデータベースではなくコンテナデータベース全体をモニターする必要がある場合は、[CDB計装](/docs/opentelemetry/database/oracle/host-cdb)を参照してください。
</Callout>

## 前提条件 [#prerequisites]

始める前に、次のものがあることを確認してください。

* 有効なNew Relic[ライセンスキー](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)
* サポートされているアーキテクチャー: AMD64 および ARM64 を搭載した Linux
* [New Relic OTLPエンドポイント](/docs/opentelemetry/best-practices/opentelemetry-otlp)へのネットワーク接続
* Oracleデータベース `19c` 以降

### プレビューに登録 [#enroll]

このインテグレーションは、New Relicパブリックプレビュープログラムの一部として利用可能です。[Previews &amp; Trials](https://one.newrelic.com/admin-portal/promotion-management/home)ページからオプトインするには、組織の管理者に連絡してください。

    ## NRDOT Collectorをインストールする [#installation]

    Linux 環境に適したインストレーション配布方法を選択します。

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_amd64.deb" --output nrdot-collector.deb && sudo dpkg -i nrdot-collector.deb
          ```

  <Step>
    ## データベースユーザーを構成する [#database-user]

    PDB Oracleデータベースインスタンスに必要な権限を持つ監視ユーザーを作成します。

    1. ユーザーを作成したり権限を付与したりする前に、SYSとして以下のステートメントを実行します：
       ```sql
       ALTER SESSION SET CONTAINER = "<YOUR_PDB>";
       ```
    2. ターゲットPDB内でSYSとして次のステートメントを実行し、ローカル監視ユーザーを作成します：
       ```sql
       CREATE USER <USER_NAME> IDENTIFIED BY "<YOUR_PASSWORD>";
       GRANT CREATE SESSION TO <USER_NAME>;
       ```
  </Step>

    ```sql
    GRANT SELECT ON DBA_DATA_FILES                TO <USER_NAME>;
    ```

  <Step>
    ## NRDOT Collectorの設定を更新 [#update]

    `oracle-config.yaml`ファイルを使用するようにNRDOT Collectorの設定を更新してください：

    ```bash
    sudo sed -i 's|OTELCOL_OPTIONS="--config=/etc/nrdot-collector/config.yaml"|OTELCOL_OPTIONS="--config=/etc/nrdot-collector/oracle-config.yaml"|' /etc/nrdot-collector/nrdot-collector.conf
    ```

    <Callout variant="tip">
      もできます。

      * [複数のレシーバーを構成する](/docs/opentelemetry/database/oracle/multi-receiver)：1つのコレクターから複数のOracleデータベースインスタンスをモニターします。
      * [SQL Query Receiverの設定](/docs/opentelemetry/database/capabilities/sql-query-receiver/): Oracleデータベースからカスタムメトリックを収集します。
      * [OracleデータベースをAPMとリンクする](/docs/opentelemetry/database/capabilities/db-apm)：アプリケーションパフォーマンスとデータベース操作を関連付けます。これにより、どのアプリケーションが特定のデータベースワークロードを生成しているかを正確に確認できます。
      * [シークレット管理の設定](/docs/opentelemetry/database/capabilities/db-apm/#secret-management): データベースの認証情報などの機密情報を安全に管理するためです。これにより、設定ファイルに機密データをハードコーディングすることを回避し、監視設定のセキュリティを強化できます。
    </Callout>
  </Step>

  <Step>
    ## NRDOT Collectorを再起動します [#restart-collector]

    設定を更新した後、NRDOT Collectorを再起動します：

    ```bash
    sudo systemctl restart nrdot-collector.service
    sudo systemctl status nrdot-collector.service
    ```

    <Callout variant="tip">
      新しい設定を確実に適用するために、設定を変更した後は常にNRDOT Collectorを再起動してください。
    </Callout>
  </Step>

  <Step>
    ## データを探す、使う [#find-use-data]

    データの収集が開始されると、New RelicのUIを通じて包括的なOracleデータベース監視にアクセスできるようになります。

    New RelicでOracleデータベースエンティティを見つけるには：

    1. <DNT>**[https://one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT>に移動します。
    2. 検索条件を<DNT>`instrumentation.provider = opentelemetry`</DNT>に設定します。
    3. エンティティのリストからOracleデータベースを選択します。
  </Step>
</Steps>
