## よくある問題

<CollapserGroup>
  <Collapser id="test-connection" title="ネットワーク接続をテストする">
    以下のコマンドを実行して、このホストからOracleデータベースポートに到達可能であることを確認します。

    ```bash
    (timeout 3 bash -c '</dev/tcp/<YOUR_ENDPOINT>/<YOUR_PORT>' && echo "PORT OPEN - Network connection successful!") || echo "CONNECTION FAILED - Port closed or firewall blocking"
    ```

    **期待される出力:** `PORT OPEN - Network connection successful!`
  </Collapser>

  <Collapser id="otlp-endpoint-connection" title="OTLPエンドポイントの接続テスト">
    以下のコマンドを実行して、ホストが選択したNew Relic OTLPエンドポイントに到達できることを確認します。

    ```bash
    ENDPOINT="<YOUR_OTLP_ENDPOINT>"
    HOST=$(echo "$ENDPOINT" | sed 's|https://||' | cut -d: -f1)
    PORT=$(echo "$ENDPOINT" | awk -F: '{print $NF}')
    (timeout 2 bash -c "</dev/tcp/$HOST/$PORT" && echo "✅ SUCCESS") || echo "❌ FAILED"
    ```

    **期待される出力:** `✅ SUCCESS`
  </Collapser>
</CollapserGroup>
