Oracleデータベース用OpenTelemetry Collector Contributionを使用して、インスタンスをモニターできます。OpenTelemetry Collector Contributionは、Oracleデータベースからテレメトリーデータを収集してNew Relicに送信する方法を提供する、コミュニティがサポートするプロジェクトです。

デフォルトでは、OpenTelemetry Collector ContributionはOracleデータベースからメトリクスを収集し、New Relicに送信します。ただし、これらは限定的なメトリクスです。クエリパフォーマンスメトリクス、待機時間メトリクス、セッションメトリクス、ASMストレージメトリクス、およびその他の高度なメトリクスを送信するには、OpenTelemetry Collector Contributionを設定する必要があります。このガイドでは、Oracleデータベースから高度なメトリクスを収集してNew Relicに送信するように、OpenTelemetry Collector Contributionを設定する手順を説明します。

<Steps>
  <Step>
    ## 前提条件 [#prerequisites]

    * システムにインストールおよび設定されたOpenTelemetry Collector Contrib（`otelcol-contrib`）。最新リリースは、[OpenTelemetry Collector releases](https://github.com/open-telemetry/opentelemetry-collector-releases/releases)ページからダウンロードできます。
  </Step>

  <Step>
    ## UIメトリクスを有効化 [#enable]

    `otelcol-contrib`設定ファイルにさまざまなメトリクスを追加して有効にすることで、New Relicプラットフォームのエクスペリエンスを充実させることができます。このセクションで提供される設定を使用すると、New Relicプラットフォームの以下のページにデータを入力できます：

    * <DNT>Overview</DNT>
    * <DNT>Query performance</DNT>
    * <DNT>Wait events</DNT>
    * <DNT>Sessions</DNT>

    <CollapserGroup>
      <Collapser id="overview" title="Overviewページメトリクスを有効化">
        <DNT>Overview</DNT>ページには、CPU使用率、待機時間、I/O、メモリ、セッション使用量などの主要なメトリクスを含む、Oracleデータベースインスタンスの概要が表示されます。

        New Relicプラットフォームの<DNT>Overview</DNT>ページにデータを入力するには、`otelcol-contrib`設定ファイルに以下の設定を追加します：

        ```yaml
        receivers:
          oracledb:
            # Metrics required by the "Oracle Database Monitoring (OTel)" dashboard
            metrics:
              oracledb.buffer_cache.utilization:
                enabled: true
              oracledb.consistent_gets:
                enabled: true
              oracledb.cpu_time:
                enabled: true
              oracledb.database.cpu.utilization:
                enabled: true
              oracledb.database.wait.utilization:
                enabled: true
              oracledb.db_block_gets:
                enabled: true
              oracledb.enqueue_deadlocks:
                enabled: true
              oracledb.execution.utilization:
                enabled: true
              oracledb.executions:
                enabled: true
              oracledb.hard_parses:
                enabled: true
              oracledb.host.cpu.utilization:
                enabled: true
              oracledb.library_cache.utilization:
                enabled: true
              oracledb.logical_reads:
                enabled: true
              oracledb.logons:
                enabled: true
              oracledb.parse.rate:
                enabled: true
              oracledb.parse_calls:
                enabled: true
              oracledb.pga_memory:
                enabled: true
              oracledb.physical_io.requests:
                enabled: true
              oracledb.physical_reads:
                enabled: true
              oracledb.physical_writes:
                enabled: true
              oracledb.processes.usage:
                enabled: true
              oracledb.sessions.usage:
                enabled: true
              oracledb.sga.usage:
                enabled: true
              oracledb.shared_pool.utilization:
                enabled: true
              oracledb.sql_service.response.duration:
                enabled: true
              oracledb.sqlnet.io.transferred:
                enabled: true
              oracledb.tablespace_size.usage:
                enabled: true
              oracledb.transactions.usage:
                enabled: true
              oracledb.user_commits:
                enabled: true
              oracledb.user_rollbacks:
                enabled: true
        ```
      </Collapser>

      <Collapser id="query-performance" title="クエリパフォーマンス、セッション、および待機メトリクスを有効にする">
        <DNT>Query performance</DNT>、<DNT>Wait events</DNT>、および<DNT>Sessions</DNT>ページにデータを表示するには、`otelcol-contrib`設定ファイルに以下の設定を追加します。

        ```yaml
        receivers:
          oracledb:
            events:
              db.server.query_sample:
                enabled: true
              db.server.top_query:
                enabled: true
              db.server.session.wait_sample:
                enabled: true

            top_query_collection:
              max_query_sample_count: 1000
              top_query_count: 200
              collection_interval: 60s
              allowed_comment_keys:
                - nr_service_guid

            query_sample_collection:
              max_rows_per_query: 100
              allowed_comment_keys:
                - nr_service_guid

            session_wait_event_collection:
              max_rows_per_query: 100
        ```
      </Collapser>

      <Collapser id="asm" title="ASMディスクグループとディスクのメトリクスを有効にする">
        Oracleデータベースレシーバーは、ASM（Automatic Storage Management）インスタンスの監視をサポートしています。レシーバーは、ディスクグループの容量、使用可能な空き領域、オフラインディスク、物理ディスクの読み取り/書き込みエラーなど、重要なストレージの健全性メトリクスを収集します。

        アクセス権を付与するには、特権Oracleユーザーとして以下を実行します：

        ```sql
        GRANT SELECT ON V_$ASM_DISKGROUP_STAT TO <username>;
        GRANT SELECT ON V_$ASM_DISK_STAT TO <username>;
        ```

        `otelcol-contrib`設定ファイルに以下の設定を追加します。5つのメトリクスはすべて**デフォルトで無効になっています**（オプトイン）：

        ```yaml
        receivers:
          oracledb:
            datasource: "oracle://otel:password@localhost:51521/XE"
            metrics:
              oracledb.asm.disk_group.free:
                enabled: true
              oracledb.asm.disk_group.capacity:
                enabled: true
              oracledb.asm.disk_group.usable_free:
                enabled: true
              oracledb.asm.disk_group.offline_disks:
                enabled: true
              oracledb.asm.disk.errors:
                enabled: true
        ```

        これらのメトリクスの説明については、[メトリクスリファレンス](/docs/opentelemetry/database/oracle/metrics-reference/#asm)をご覧ください。
      </Collapser>
    </CollapserGroup>
  </Step>

  <Step>
    ## OpenTelemetry Collectorを再起動する [#restart]

    設定の変更を適用するには、OpenTelemetry Collectorを再起動します：

    ```bash
    sudo systemctl restart otelcol-contrib
    ```
  </Step>
</Steps>
