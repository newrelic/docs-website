1つのコレクターから複数のOracleデータベースインスタンスをモニターするようにNRDOT Collectorを設定できます。これは、異なるホストで複数のOracleデータベースが実行されており、単一のNRDOT Collectorインスタンスを使用してそれらすべてからメトリクスを収集したい場合に便利です。

<Steps>
  <Step>
    ## 前提条件 [#prerequisites]

    * NRDOTがOracle データベースインスタンス用にインストールおよび設定されていること：

      * [CDB](/docs/opentelemetry/database/oracle/host-cdb)
      * [PDB](/docs/opentelemetry/database/oracle/host-pdb)
      * [RDS](/docs/opentelemetry/database/oracle/rds)
      * [ADB](/docs/opentelemetry/database/oracle/adb)
  </Step>

  <Step>
    ## マルチレシーバー設定の追加 [#multi]

    以下の例では、マルチレシーバー設定を使用して複数のOracle データベースインスタンスをモニターするようにNRDOT Collectorを設定する方法を示します。環境に合ったデプロイメントタイプを選択してください。追加のインスタンス用に、必要に応じてレシーバーを追加できます。

  <Step>
    ## NRDOT Collectorを再起動します [#restart]

    再起動は必須であり、任意ではありません — コレクターは起動時に一度だけ設定を読み込み、ホットリロードしません。プロセスを再起動するまで、設定の変更は反映されません。

    ```bash
    sudo systemctl restart nrdot-collector.service
    ```
  </Step>
