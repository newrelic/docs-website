このリファレンスでは、New Relic Distribution of OpenTelemetry（NRDOT）Collectorを使用したOracleデータベース監視のための包括的なYAML設定を提供します。これらのフル機能の設定には、本番環境向けのデータベース監視に加えて、ホストインフラストラクチャのメトリクスが含まれています。

<Callout variant="important">
  **すぐに開始したいとお考えですか？**これらは本番環境用の高度な設定です。初めてOracle データベース監視を設定する場合は、セットアップガイドの標準設定から始め、基本的な機能を確認してから、これらの包括的な設定に戻ることをお勧めします。
</Callout>
