NRDOT Collectorによって収集された包括的なメトリクスを使用して、Oracleデータベースのパフォーマンスをモニターします。NRDOTを使用したOracleデータベース監視では、以下のメトリクスを利用できます。これらを収集するには、設定で関連するスクレイパーを有効にしてください。
