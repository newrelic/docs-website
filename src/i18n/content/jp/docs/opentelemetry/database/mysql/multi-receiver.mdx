1つのコレクターから複数のMySQLインスタンスをモニターするようにNRDOT Collectorを設定できます。これは、異なるホストまたはポートで実行されている複数のMySQLデータベースがあり、単一のNRDOT Collectorインスタンスを使用してそれらすべてからメトリクスを収集したい場合に便利です。

<Steps>
  <Step>
    ## 前提条件 [#prerequisites]

    * NRDOTがインストールされ、MySQLインスタンス用に設定されていること：

      * [セルフホスト型MySQL](/docs/opentelemetry/database/mysql/hosted)
      * [RDS MySQL監視](/docs/opentelemetry/database/mysql/rds)
  </Step>

  <Step>
    ## マルチレシーバー設定の追加 [#multi]

    以下の例は、マルチレシーバー設定を使用して2つのMySQLインスタンスをモニターするようにNRDOT Collectorを設定する方法を示しています。追加のMySQLインスタンス用に、必要に応じてレシーバーを追加できます。

    ```yaml
    receivers:
      nrmysql/instance1: &nrmysql-common
        endpoint: "<INSTANCE_1_HOST>:<PORT>"
        username: "<YOUR_DB_USERNAME>"
        password: "<YOUR_DB_PASSWORD>"
        collection_interval: 10s
      nrmysql/instance2:
        <<: *nrmysql-common
        endpoint: "<INSTANCE_2_HOST>:<PORT>"

    service:
      pipelines:
        metrics:
          receivers: [nrmysql/instance1, nrmysql/instance2]
          exporters: [otlp/newrelic]
    ```
  </Step>

  <Step>
    ## NRDOT Collectorを再起動します [#restart]

    再起動は必須であり、任意ではありません — コレクターは起動時に一度だけ設定を読み込み、ホットリロードしません。プロセスを再起動するまで、設定の変更は反映されません。

    ```bash
    sudo systemctl restart nrdot-collector
    ```
  </Step>
</Steps>
