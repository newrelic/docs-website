Microsoft SQL Server向けOpenTelemetry Collector Contributionを使用して、インスタンスをモニターできます。OpenTelemetry Collector Contributionは、Microsoft SQL Serverからテレメトリーデータを収集し、New Relicに送信する方法を提供するコミュニティサポートプロジェクトです。

デフォルトでは、OpenTelemetry Collector ContributionはMicrosoft SQL Serverからメトリクスを収集し、New Relicに送信します。ただし、これらは限定的なメトリクスです。クエリのパフォーマンスメトリクス、待機時間メトリクス、セッションメトリクス、およびその他の高度なメトリクスを送信するには、OpenTelemetry Collector Contributionを設定する必要があります。このガイドでは、Microsoft SQL Serverから高度なメトリクスを収集し、New Relicに送信するようにOpenTelemetry Collector Contributionを設定する手順を説明します。

<Steps>
  <Step>
    ## 前提条件 [#prerequisites]

    * システムにインストールおよび設定されたOpenTelemetry Collector Contrib（`otelcol-contrib`）。最新リリースは、[OpenTelemetry Collector releases](https://github.com/open-telemetry/opentelemetry-collector-releases/releases)ページからダウンロードできます。
  </Step>

  <Step>
    ## Enable UI metrics [#enable]

    `otelcol-contrib`設定ファイルにさまざまなメトリクスを追加して有効にすることで、New Relicプラットフォームのエクスペリエンスを充実させることができます。このセクションで提供される設定を使用すると、New Relicプラットフォームの以下のページにデータを入力できます：

    * <DNT>Overview</DNT>
    * <DNT>Query performance</DNT>
    * <DNT>Wait events</DNT>
    * <DNT>Sessions</DNT>
    * <DNT>Clients</DNT>

    <CollapserGroup>
      <Collapser id="overview" title="Overviewページメトリクスを有効化">
        <DNT>Overview</DNT>ページには、データベース数、I/O、レイテンシ、操作、tempdbスペース、デッドロック率などの主要なメトリクスを含む、Microsoft SQL Serverインスタンスの概要が表示されます。

        New Relicプラットフォームの<DNT>Overview</DNT>ページにデータを入力するには、`otelcol-contrib`設定ファイルに以下の設定を追加します：

        ```yaml
        receivers:
            sqlserver:

                # Enable comprehensive database metrics
              metrics:
                sqlserver.database.count:
                  enabled: true
                sqlserver.database.io:
                  enabled: true
                sqlserver.database.latency:
                  enabled: true
                sqlserver.database.operations:
                  enabled: true
                sqlserver.database.tempdb.space:
                  enabled: true
                sqlserver.database.tempdb.version_store.size:
                  enabled: true
                sqlserver.deadlock.rate:
                  enabled: true
                sqlserver.os.wait.duration:
                  enabled: true
                sqlserver.processes.blocked:
                  enabled: true
                sqlserver.memory.grants.pending.count:
                  enabled: true
                sqlserver.memory.area:
                  enabled: true
        ```
      </Collapser>

      <Collapser id="query-performance" title="クエリのパフォーマンス、セッション、待機、およびクライアントメトリクスを有効化">
        New Relicプラットフォームの以下のページにデータを入力できます：

        * <DNT>Query performance</DNT>：以下のタブに、Microsoft SQL Serverインスタンスで実行されているクエリに関する詳細情報を表示します：

          * <DNT>Normalized queries</DNT>：実行回数、平均実行時間、平均CPU時間、論理読み取りなど、クエリごとの集計統計を表示します。クエリをクリックすると、集計パフォーマンス統計、観測されたクエリプラン、待機タイプの内訳を含む最近の個別のサンプルなど、選択したクエリの詳細情報が表示されます。
          * <DNT>Query samples</DNT>：開始時間、実行時間、待機タイプ、待機時間、データベース、DBユーザー、APM相関、クライアントホストなど、個々のクエリの実行を表示します。

        * <DNT>Wait events</DNT>：Microsoft SQL Serverインスタンスで発生している待機イベントに関する情報を表示します。「Query samples」ビューには、現在待機中のクエリが、その待機タイプおよび待機時間とともに表示されます。

        * <DNT>Sessions</DNT>：セッション数、セッション状態、平均アクティブセッション期間、ブロックされたセッション、個々のセッションの詳細など、Microsoft SQL Serverインスタンスに接続されているセッションに関する情報を表示します。

        * <DNT>Clients</DNT>：アクティブなセッション、ブロックされたセッション、接続されているDBユーザー、クライアントホストの詳細など、Microsoft SQL Serverインスタンスに接続されているクライアントに関する情報を表示します。

        これらのページにデータを入力するには、`otelcol-contrib`設定ファイルに次の設定を追加します。

        ```yaml
        receivers:
            sqlserver:

                events:
                    db.server.query_sample:
                        enabled: true
                    db.server.top_query:
                        enabled: true

                top_query_collection:
                    lookback_time: 45s
                    max_query_sample_count: 100
                    top_query_count: 30
                    collection_interval: 30s

                query_sample_collection:
                    max_rows_per_query: 100
        ```
      </Collapser>

      <Collapser id="waits" title="「Wait event」タブですべての待機を有効化">
        「All waits」ビューには、待機カテゴリおよび個々の待機タイプ別に分類されたインスタンスレベルの待機時間が表示されます。

        New Relicプラットフォームの<DNT>Wait event</DNT>タブで<DNT>All waits</DNT>を有効にするには、`otelcol-contrib`設定ファイルに次の設定を追加します。

        ```yaml

        receivers:
            sqlserver:

                metrics:
                    sqlserver.os.wait.duration:
                        enabled: true

        ```
      </Collapser>
    </CollapserGroup>
  </Step>

  <Step>
    ### OpenTelemetry Collectorを再起動する

    設定の変更を適用するには、OpenTelemetry Collectorを再起動します。これを行うには、次のコマンドを実行します。

    ```bash
    Restart-Service -Name "otelcol-contrib"
    ```
  </Step>
</Steps>
