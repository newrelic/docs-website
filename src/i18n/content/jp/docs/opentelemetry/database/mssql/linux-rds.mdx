New Relic Distribution of OpenTelemetry（NRDOT）コレクターを使用し、データベース監視、クエリ分析、およびシステムヘルスメトリクスを通じて、AWS RDS SQL Serverのパフォーマンスに関する包括的なインサイトを取得します。

代わりにNew Relic UIからこれをインストールするには、<DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; MSSQL (OpenTelemetry)** </DNT>にアクセスしてください。画面上の指示に従って、インテグレーションをセットアップします。このページでは、CLIのインストールパスのみを説明します。

<Callout variant="tip">
  Linuxのセルフホスト環境でSQL Serverを使用している場合は、[RDSのLinux計装](/docs/opentelemetry/database/mssql/linux-hosted)を参照してください。
</Callout>

  <Step>
    ## 監視ユーザーを作成する [#user]

    rootユーザーとしてこのスクリプトを実行し、`newrelic`監視ユーザーを作成して、RDS SQL Serverメトリクスを収集するために必要な権限を付与してください。

    1. `nr-grant-permission-rds.sql`という名前のファイルを作成します。

    2. 次のSQLスクリプトを貼り付けて`newrelic`監視ユーザーを作成し、`<YOUR_PASSWORD>`を希望するパスワードに置き換えます：

       ```sql
       USE [master];
       GO
       CREATE LOGIN [newrelic] WITH PASSWORD = '<YOUR_PASSWORD>';
       GO
       -- Instance-level permissions
       GRANT VIEW SERVER STATE TO [newrelic];
       GRANT VIEW ANY DEFINITION TO [newrelic];
       GRANT VIEW ANY DATABASE TO [newrelic];
       GO
       -- Grant read access privileges to all user databases
       DECLARE @name SYSNAME;
       DECLARE db_cursor CURSOR READ_ONLY FORWARD_ONLY FOR
       SELECT [name]
       FROM [master].[sys].[databases]
       WHERE [name] NOT IN ('master', 'msdb', 'model', 'rdsadmin', 'distribution')
       AND [state] = 0; -- Only online databases
       OPEN db_cursor;
       FETCH NEXT FROM db_cursor INTO @name;
       WHILE @@FETCH_STATUS = 0
       BEGIN
         BEGIN TRY
           EXEC('USE [' + @name + '];
             IF NOT EXISTS (SELECT 1 FROM sys.database_principals WHERE name = ''newrelic'')
             BEGIN
               CREATE USER [newrelic] FOR LOGIN [newrelic];
             END;
             GRANT VIEW DATABASE STATE TO [newrelic];');
         END TRY
         BEGIN CATCH
           PRINT 'Error on ' + @name + ': ' + ERROR_MESSAGE();
         END CATCH
         FETCH NEXT FROM db_cursor INTO @name;
       END
       CLOSE db_cursor;
       DEALLOCATE db_cursor;
       GO
       ```

    3. `sqlcmd`を使用してスクリプトを実行します。`<YOUR-RDS-ENDPOINT>`をRDSエンドポイントに、`<YOUR_MASTER_PASSWORD>`をマスターパスワードに置き換えます：

    ```bash
    sqlcmd -S <YOUR-RDS-ENDPOINT> -U <YOUR_MASTER_USER> -P '<YOUR_MASTER_PASSWORD>' -C -i nr-grant-permission-rds.sql
    ```

    3. *（オプション）*ユーザーが正しい権限で正常に作成されたことを確認します：

    ```bash
    sqlcmd -S <YOUR-RDS-ENDPOINT> -U <YOUR_MASTER_USER> -P '<YOUR_MASTER_PASSWORD>' -C -Q "SELECT sp.name AS [User], p.permission_name AS [Permission_Granted] FROM sys.server_permissions p JOIN sys.server_principals sp ON p.grantee_principal_id = sp.principal_id WHERE sp.name = 'newrelic';"
    ```

    <Callout variant="tip">
      RDSマスターユーザー名とパスワードを使用して、これらのコマンドを実行します。スクリプトは、AWSによって予約されている`rdsadmin`データベースを自動的に除外します。
      データベースの認証情報などの機密情報を安全に管理するには、[シークレット管理](/docs/opentelemetry/database/capabilities/db-apm/#secret-management)ツールに保存してください。
    </Callout>

  <Step>
    ## NRDOT Collectorの設定を更新 [#update]

    上記の対話型入力を使用してYAMLファイルを設定した後、NRDOT Collectorのセットアップを完了します：

    1. 次のコマンドを使用して、サービス設定ファイルを編集します：

       ```bash
       sudo nano /etc/nrdot-collector/nrdot-collector.conf
       ```

    2. 新しい`mssql-config.yaml`ファイルを指すように設定パスを更新します：

       ```bash
       OTELCOL_CONFIG="/etc/nrdot-collector/mssql-config.yaml"
       ```

    3. （オプション）NRDOT Collectorの設定を検証します：

       ```bash
       sudo /usr/bin/nrdot-collector validate --config=/etc/nrdot-collector/mssql-config.yaml
       ```

       <Callout variant="tip">
         アプリケーションパフォーマンスとデータベース操作を関連付けるには、データベースサービス識別をセットアップできます。詳細については、[データベースサービス識別セットアップガイド](/docs/opentelemetry/database/capabilities/db-apm)を参照してください。
       </Callout>
  </Step>

  <Step>
    ## NRDOT Collectorを再起動します [#restart]

    設定を更新した後、NRDOT Collectorサービスを再起動します：

    ```bash
    sudo systemctl restart nrdot-collector
    ```

    <Callout variant="tip">
      新しい設定を確実に適用するために、設定を変更した後は常にNRDOT Collectorサービスを再起動してください。
    </Callout>
  </Step>

  <Step>
    ## データを探す、使う [#find]

    データの収集が開始されると、New Relic UIを通じて包括的なSQL Serverデータベース監視にアクセスできます。

    New Relic で SQL Server データベース エンティティを見つけるには:

    1. <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; All capabilities &gt; Databases**</DNT>に移動します。

    2. **<DNT>Entity type</DNT>**ドロップダウンから<DNT>**MSSQL instance**</DNT>を選択し、<DNT>**Apply**</DNT>をクリックします。

    3. エンティティのリストから SQL Server データベースを選択します。

       NRDOTを使用してSQL Serverの監視をセットアップした後、次のことができます：

       * データベースのメトリクスを視覚化する[カスタムダッシュボードを作成する](/docs/query-your-data/explore-query-data/dashboards/introduction-dashboards/)
       * クリティカルデータベースパフォーマンス閾値の[アラートを設定する](/docs/alerts/create-alert/create-alert-condition/alert-conditions/)
       * New Relicのクエリ機能を使用して、[データを探索](/docs/query-your-data/explore-query-data/browse-data/introduction-data-explorer/)します
  </Step>
</Steps>
