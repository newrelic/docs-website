OpenTelemetryベースの監視ソリューションを使用して、SQL Serverのパフォーマンスに関する深いインサイトを取得できます。データベースのメトリクスを追跡し、スロークエリを分析し、リソース使用量をモニターして、データベースのパフォーマンスをアプリケーションと関連付けます。

この NRDOT ベースのアプローチは、データベース監視のOpenTelemetry標準を活用することで既存のオンホスト インテグレーション (OHI) を補完し、既存の監視スタックとの統合を容易にします。

主な機能:

* **OpenTelemetry標準**：既存のオブザーバビリティツールとシームレスに統合します
* **包括的なメトリクス**：50以上のデータベースパフォーマンス指標
* **クエリレベルのインサイト**: パフォーマンスの低いクエリを特定して最適化します。
* **柔軟なデプロイメント**：セルフホスト環境とcloud環境で動作します
* **APMの相関関係**：データベースのパフォーマンスをアプリケーションのトレースに接続します

## 設置方法をお選びください [#install]

SQL Server監視用のNRDOT Collectorは、以下の方法でインストールできます：

* セルフホスト環境: 独自のインフラストラクチャへの手動インストレーション

  * [Windowsセルフホスト](/docs/opentelemetry/database/mssql/windows-hosted)
  * [Linuxセルフホスト](/docs/opentelemetry/database/mssql/linux-hosted)

* AWS RDS環境: クラウド管理のSQL Server監視：

  * [Windows RDS監視](/docs/opentelemetry/database/mssql/windows-rds)
  * [Linux RDS監視](/docs/opentelemetry/database/mssql/linux-rds)

## ガイド付きインストール [#ui-install]

代わりにNew Relic UIからこれをインストールするには、<DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; MSSQL (OpenTelemetry)** </DNT>にアクセスしてください。画面上の指示に従って、インテグレーションを設定します。

## インストレーションの概要 [#at-a-glance]

<Steps>
  <Step>
    ### 前提条件 [#prerequisites]

    * 有効な[ライセンスキー](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)を持つNew Relicアカウント

    * NRDOT CollectorをインストールするホストとMicrosoft SQL Server間のネットワーク接続。

    * [New Relic OTLPエンドポイントのドキュメント](/docs/opentelemetry/best-practices/opentelemetry-otlp/)へのネットワーク接続

    * SQL Serverの要件として、以下が必要です：

      * SQL Server 2017以降
      * SQL Serverへの管理アクセス（`sysadmin`ロールまたは同等のロール）
      * ポート`1433`またはカスタムポートでのコレクターとSQL Server間のネットワーク接続

    * このインテグレーションは、New Relicパブリックプレビュープログラムの一環としてご利用いただけます。[プレビューとトライアル](https://one.newrelic.com/admin-portal/promotion-management/home)ページからオプトインするには、組織マネージャーに確認してください。

    サポートされている詳細な前提条件については、インストレーションドキュメントの専用の前提条件セクションを参照してください。
  </Step>

  <Step>
    ### NRDOT Collectorをインストールする [#install]

    インフラストラクチャに基づいてインストレーションパスを選択してください：

    * **ガイド付きインストール**: New Relic UI経由でインストールするには、<DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; MSSQL (OpenTelemetry)** </DNT>にアクセスしてください。画面上の指示に従って、インテグレーションを設定します。このページでは、CLIインストールパスについてのみ説明します。

    * **セルフホスト環境**: 独自のインフラストラクチャへの手動インストレーション

      * [Windowsセルフホスト](/docs/opentelemetry/database/mssql/windows-hosted)
      * [Linuxセルフホスト](/docs/opentelemetry/database/mssql/linux-hosted)

    * **AWS RDS環境**: クラウド管理のSQL Server監視

      * [Windows RDS監視](/docs/opentelemetry/database/mssql/windows-rds)
      * [Linux RDS監視](/docs/opentelemetry/database/mssql/linux-rds)
  </Step>

  <Step>
    ### 監視ユーザーの構成 [#user]

    NRDOT Collectorがメトリクスを収集し、パフォーマンスデータをクエリできるように、必要な権限を持つ専用のMicrosoft SQL Serverユーザーを作成します。ユーザーは必要な項目への読み取り専用アクセス権を持っている必要があります。
  </Step>

  <Step>
    ### NRDOT Collectorを構成する [#configure]

    Microsoft SQL Serverインスタンスに接続するようにNRDOT Collectorを設定します。これには、接続の詳細、認証方法、および環境に必要な追加の設定オプションの指定が含まれます。
  </Step>

  <Step>
    ### NRDOT Collectorを再起動します [#restart]

    NRDOT Collectorを構成した後、サービスを再起動して変更を適用し、Microsoft SQL Serverインスタンスからのデータ収集を開始します。
  </Step>

  <Step>
    ### データを探す、使う [#find]

    データの収集が開始されると、New Relic UIを通じて包括的なSQL Serverデータベース監視にアクセスできます。

    New Relic で SQL Server データベース エンティティを見つけるには:

    1. <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; All capabilities &gt; Databases**</DNT>に移動します。
    2. **<DNT>Entity type</DNT>**ドロップダウンから<DNT>**MSSQL instance**</DNT>を選択し、<DNT>**Apply**</DNT>をクリックします。
    3. エンティティのリストからSQL Serverデータベースを選択して、そのダッシュボード、メトリクス、およびクエリパフォーマンスデータを表示します。
  </Step>
</Steps>
