Claude Code、Cursor、GitHub Copilot、CodexなどのAIコーディングエージェントに、プロジェクトへのNew Relicの追加を依頼できます。エージェントはインストールに関するドキュメントを読み、プロジェクトに必要なNew Relicエージェントを判断して、変更を行います。

## あなたが始める前に [#before-you-begin]

* **New Relicアカウント** — まだお持ちでない場合は、[New Relicアカウントにサインアップ](https://newrelic.com/signup)してください。
* **ライセンスキー** — <InlinePopover type="licenseKey" />が必要になります。見つけるには、[ライセンスキー](/docs/apis/intro-apis/new-relic-api-keys#license-key)をご覧ください。

<Callout variant="important">
ライセンスキーはエージェントのコンテキスト外に置いてください。チャットに貼り付けないでください。アプリケーションが実行される場所で、ご自身で`NEW_RELIC_LICENSE_KEY`環境変数として設定してください。
</Callout>

## このプロンプトをコピー [#prompt]

プロジェクトのフォルダーでAIコーディングエージェントを開き、このプロンプトを貼り付けます：

<Callout variant="tip">
このプロジェクトにNew Relicを追加するには、[https://docs.newrelic.com/docs/new-relic-solutions/get-started/install-with-ai.md](https://docs.newrelic.com/docs/new-relic-solutions/get-started/install-with-ai.md)の手順に従ってください。
</Callout>

エージェントの実行後、変更されたファイルを確認し、データがNew Relicに到達していることを検証してください。

## AIエージェント向けの手順 [#agent-instructions]

New RelicをインストールするAIエージェントの場合は、以下の手順に従ってください。

1. **スタックを見つける：** `package.json`、`pom.xml`、`build.gradle`、`requirements.txt`、`pyproject.toml`、`go.mod`、`*.csproj`、`composer.json`、`Gemfile`、`Dockerfile`、Kubernetesマニフェスト、Helmチャートなどのプロジェクトのファイルを確認します。スタックが不明な場合は、何をモニターするかユーザーに尋ねます。

2. **インストールガイドの選択：** 以下の[インストールガイド](#install-guides)から一致するガイドを選択してください。`/docs/`の下にあるURLの場合は、末尾に`.md`を追加してMarkdownバージョンを取得してください。

3. **ライセンスキーをコンテキストに含めないでください：**このキーはシークレットです。その値が必要になることはありません。

   * ユーザーにキーを尋ねないでください。チャットに貼り付けられた場合は、それを無効にして新しいものを作成するように伝えてください。
   * キーは`NEW_RELIC_LICENSE_KEY`という名前でのみ参照してください。ガイドでキーが設定ファイルに配置されている場合は、代わりにその環境変数から読み取ってください。
   * `env`、`printenv`、`echo $NEW_RELIC_LICENSE_KEY`、`.env`ファイル、またはシークレットストアなど、キーが表示されるようなコマンドを実行したり、ファイルを読み取ったりしないでください。
   * `test -n "$NEW_RELIC_LICENSE_KEY" && echo set || echo missing`を実行して、キーを公開することなく設定されていることを確認します。

4. **ガイドに従ってください：**

   * ユーザーにアプリ名を尋ねるか、プロジェクト名に基づいて提案してください。
   * ユーザーのアカウントがEUまたはJPの[データセンターリージョン](/docs/accounts/accounts-billing/account-setup/choose-your-data-center)にある場合は、ガイドでそのリージョン用に指定されているエンドポイントを使用してください。

5. **確認：**ユーザーに`NEW_RELIC_LICENSE_KEY`を設定してアプリを再起動するように依頼し、[インストールの確認](#verify)に従ってください。データが表示されない場合は、そのテクノロジーのトラブルシューティングページを参照してください。

6. **要約する：** 変更したファイルと、New Relicでアプリを見つける場所をユーザーに伝えます：アプリの場合は<DNT>**APM &amp; Services**</DNT>、フロントエンドの場合は<DNT>**Browser**</DNT>または<DNT>**Mobile**</DNT>、ホストの場合は<DNT>**Infrastructure**</DNT>です。

## インストールの確認 [#verify]

2つの段階で確認します：最初にエージェントが実行されていること、次にそのデータがNew Relicに到達していることです。

### データがNew Relicに到達したことを確認 [#check-data]

インストールしたテクノロジーのクエリを実行し、各プレースホルダーを設定した値に置き換えてください。データが表示されるまで数分かかる場合があり、一部のクエリはアプリがトラフィックを処理した後にのみ結果を返します。

<table>
<thead>
<tr>
<th style={{ width: "200px" }}>
**テクノロジー**
</th>

<th>
**クエリ**
</th>
</tr>

<tbody>
<tr>
<td>
APMエージェント
</td>

<td>

</td>
</tr>

<tr>

</td>

</td>
</tr>

<tr>
<td>
Docker
</td>

<td>

</td>
</tr>

<tr>
<td>
Kubernetes
</td>

<td>
`SELECT count(*) FROM K8sClusterSample WHERE clusterName = 'CLUSTER_NAME' SINCE 10 minutes ago`
</td>
</tr>

<tr>
<td>
ホスト
</td>

<td>
`SELECT count(*) FROM SystemSample WHERE hostname = 'HOST_NAME' SINCE 10 minutes ago`
</td>
</tr>

<tr>
<td>
Webブラウザー、ページ読み込み後
</td>

<td>
`SELECT count(*) FROM PageView WHERE appName = 'APP_NAME' SINCE 30 minutes ago`
</td>
</tr>

<tr>
<td>
セッション後のモバイル
</td>

<td>
`SELECT count(*) FROM MobileSession WHERE appName = 'APP_NAME' SINCE 30 minutes ago`
</td>
</tr>
</tbody>
</table>

カウントが0より大きい場合は、データが流れていることを意味します。クエリを実行する方法は2つありますが、どちらもシークレットが公開されることはありません：

* **ユーザーに依頼して**、New Relicの[クエリビルダー](/docs/query-your-data/explore-query-data/query-builder/introduction-query-builder)に貼り付け、結果を教えてもらいます。
* ユーザーがインストールし、<InlinePopover type="userKey" />を`NEW_RELIC_API_KEY`環境変数として設定している場合は、**[New Relic CLI](https://github.com/newrelic/newrelic-cli)を使用してください**。`newrelic nrql query --accountId ACCOUNT_ID --query 'QUERY'`を実行します。ユーザーAPIキーもシークレットであるため、ライセンスキーと同じように処理してください。
