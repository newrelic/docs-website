このガイドでは、サンプルのトランザクション概要アプリケーションに`NerdGraphQuery`コンポーネントを追加するプロセスを段階的に説明します。 これにより、 New Relicアカウントからデータをクエリし、それを参加メニューに追加できるようになります。

NerdGraph は GraphQL 実装です。 GraphQL には、REST と比較するといくつかの重要な違いがあります。

* 返されるデータはサーバーではなくクライアントによって決定されます。
* 複数のソースからデータを簡単に収集できます。 たとえば、1 回のクエリで、アカウント情報、インフラストラクチャ データを取得し、NRQL リクエストを発行できます。

<Callout variant="important">
この演習を完了する前に、 [NerdGraph API エクスプローラー](https://api.newrelic.com/graphiql)で GraphQL クエリを試すことができます。
</Callout>

## `NerdGraphQuery`コンポーネントを追加します [#nerdgraphquery]

これで、アプリケーションが表示するアカウントを変更するためのドロップダウン メニューを作成できます。 最初のステップは、 `NerdGraphQuery`コンポーネントをアプリケーションの`index.js`ファイルにインポートすることです。

<Steps>
<Step>
`index.js`ファイルの`return`内の最初の`StackItem`に`NerdGraphQuery`コンポーネントを追加します。

```jsx
<NerdGraphQuery query={query} variables={variables}>
  {({ loading, error, data }) => {
    console.log({ loading, error, data });
    if (loading) {
      return <Spinner />;
    }
    if (error) {
      return 'Error!';
    }
    return null;
  }}
</NerdGraphQuery>
```
</Step>

<Step>
`NerdGraphQuery`コンポーネントは、アクセスするソースと返されるデータを指定するクエリ オブジェクトを受け取ります。

`render`メソッドの`index.js`ファイルに次のコードを追加します。

<Callout variant="important">
browserコンソールでは、最初のクエリのオブジェクトと同じ構造に従うオブジェクトで返されたクエリのデータを確認できます。
</Callout>

```jsx
const query = `
    query($id: Int!) {
        actor {
            account(id: $id) {
                name
            }
        }
    }
`;
```
</Step>

<Step>
NerdGraph クエリによって返されたデータを取得してアプリケーションに表示するには、現在の`NerdGraphQuery`コンポーネントの`return null`を次の`return`ステートメントに置き換えます。

```jsx
return <HeadingText>{data.actor.account.name} Apps:</HeadingText>;
```

browserに戻ってアプリケーションを表示すると、NerdGraph から返されたアカウント名を示す新しい見出しが表示されます。
</Step>
</Steps>

## 使い方 `NerdGraphQuery.query` [#how-nerdgraphquery]

この時点で、アプリケーションの`render`メソッドを使用して`NerdGraphQuery`コンポーネントを実装し、トランザクション概要アプリケーション内で戻りデータを表示しました。

次に行う必要があるのは以下のとおりです。

* `componentDidMount`ライフサイクル メソッド内で NerdGraph をクエリします。
* 返されたデータをアプリケーションで後で使用するために保存します。

<Steps>
<Step>
このコードは、NerdGraph からの応答を受け取り、結果が処理され、アプリケーション状態に保存され、表示のためにbrowserコンソールにログが記録されることを確認します。

このコードを`constructor`のすぐ下の`index.js`ファイルに追加します。

```jsx
componentDidMount() {
    const accountId = this.state;
    const gql = `{ actor { accounts { id name } } }`;

    const accounts = NerdGraphQuery.query({query: gql}) //The NerdGraphQuery.query method called with the query object to get your account data is stored in the accounts variable.
    accounts.then(results => {
        console.log('Nerdgraph Response:', results);
        const accounts = results.data.actor.accounts.map(account => {
            return account;
        });
        const account = accounts.length > 0 && accounts[0];
        this.setState({ selectedAccount: account, accounts });
    }).catch((error) => { console.log('Nerdgraph Error:', error); })
}
```
</Step>

<Step>
データが状態に保存された後、ユーザーがアカウントを変更してアプリケーションを更新できるように選択項目を表示します。

これを行うには、 `return`ステートメントの 2 番目の`StackItem`の`index.js`に次のコードを追加します。

```jsx
{
  accounts && (
    <StackItem>
      <Select
        value={selectedAccount}
        onChange={(evt, value) => this.selectAccount(value)}
      >
        {accounts.map((a) => {
          return (
            <SelectItem key={a.id} value={a}>
              {a.name}
            </SelectItem>
          );
        })}
      </Select>
    </StackItem>
  );
}
```
</Step>
</Steps>

### NerdGraphクエリの結果を確認する [#review-results]

これらの手順を完了したら、 browserでアプリケーションを確認し、次の点に注意してください。

* ドロップダウン メニューに`NerdGraphQuery.query`から返されたデータが表示され、アカウントを選択できるようになりました。
* 新しいアカウントを選択すると、アプリケーションは新しい選択からのデータを表示します。

最終的な`index.js`ファイルには、以下のコードと同様のコードが含まれている必要があります。 この完成したサンプルは、あなたのナードレット`final.js`にあります。

```jsx
import React from 'react';
import { PlatformStateContext, NerdGraphQuery, Spinner, HeadingText, Grid, GridItem, Stack, StackItem, Select, SelectItem, AreaChart, TableChart, PieChart } from 'nr1'
import { timeRangeToNrql } from '@newrelic/nr1-community';

// https://docs.newrelic.com/docs/new-relic-programmable-platform-introduction

export default class UseNerdgraphNerdletNerdlet extends React.Component {
    constructor(props){
        super(props)
        this.state = {
            accountId: <YOUR ACCOUNT ID>,
            accounts: null,
            selectedAccount: null,
        }
    }

    componentDidMount() {
        const accountId = this.state;
        const gql = `{ actor { accounts { id name } } }`;

        const accounts =  NerdGraphQuery.query({ query: gql })
        accounts.then(results => {
            console.log('Nerdgraph Response:', results);
            const accounts = results.data.actor.accounts.map(account => {
                return account;
            });
            const account = accounts.length > 0 && accounts[0];
            this.setState({ selectedAccount: account, accounts });
        }).catch((error) => { console.log('Nerdgraph Error:', error); })
    }

    selectAccount(option) {
        this.setState({ accountId: option.id, selectedAccount: option });
    }


    render() {
        const { accountId, accounts, selectedAccount  } = this.state;
        console.log({ accountId, accounts, selectedAccount });

        const query = `
            query($id: Int!) {
                actor {
                    account(id: $id) {
                        name
                    }
                }
            }
        `;

        const variables = {
          id: accountId,
        };

        const avgResTime = `SELECT average(duration) FROM Transaction FACET appName TIMESERIES AUTO `;
        const trxOverview = `FROM Transaction SELECT count(*) AS 'Transactions', apdex(duration) AS 'apdex', percentile(duration, 99, 95) FACET appName `;
        const errCount = `FROM TransactionError SELECT count(*) AS 'Transaction Errors' FACET error.message `;
        const responseCodes = `SELECT count(*) AS 'Response Code' FROM Transaction FACET httpResponseCode `;

        return (
            <Stack
                fullWidth
                horizontalType={Stack.HORIZONTAL_TYPE.FILL}
                gapType={Stack.GAP_TYPE.EXTRA_LOOSE}
                spacingType={[Stack.SPACING_TYPE.MEDIUM]}
                directionType={Stack.DIRECTION_TYPE.VERTICAL}>
                <StackItem>
                    <NerdGraphQuery query={query} variables={variables}>
                        {({loading, error, data}) => {
                            if (loading) {
                                return <Spinner />;
                            }

                            if (error) {
                                return 'Error!';
                            }

                            return <HeadingText>{data.actor.account.name} Apps:</HeadingText>;
                        }}
                    </NerdGraphQuery>
                </StackItem>
                {accounts &&
                    <StackItem>
                        <Select value={selectedAccount} onChange={(evt, value) => this.selectAccount(value)}>
                        {accounts.map(a => {
                            return (
                              <SelectItem key={a.id} value={a}>
                                {a.name}
                              </SelectItem>
                            )
                        })}
                        </Select>
                    </StackItem>
                }
                <StackItem>
                <hr />
                    <PlatformStateContext.Consumer>
                    {(platformState) => {
                        /* Taking a peek at the platformState */
                        const since = timeRangeToNrql(platformState);
                        return (
                          <Grid
                          className="primary-grid"
                          spacingType={[Grid.SPACING_TYPE.NONE, Grid.SPACING_TYPE.NONE]}
                          >
                              <GridItem className="primary-content-container" columnSpan={6}>
                                  <main className="primary-content full-height">
                                  <HeadingText spacingType={[HeadingText.SPACING_TYPE.MEDIUM]} type={HeadingText.TYPE.HEADING_4}>
                                      Transaction Overview
                                  </HeadingText>
                                  <TableChart fullWidth accountId={accountId} query={trxOverview+since} />
                                  </main>
                              </GridItem>
                              <GridItem className="primary-content-container" columnSpan={6}>
                                  <main className="primary-content full-height">
                                  <HeadingText spacingType={[HeadingText.SPACING_TYPE.MEDIUM]} type={HeadingText.TYPE.HEADING_4}>
                                      Average Response Time
                                  </HeadingText>
                                  <AreaChart fullWidth accountId={accountId} query={avgResTime+since} />
                                  </main>
                              </GridItem>
                              <GridItem className="primary-content-container" columnSpan={6}>
                                  <main className="primary-content full-height">
                                  <HeadingText spacingType={[HeadingText.SPACING_TYPE.MEDIUM]} type={HeadingText.TYPE.HEADING_4}>
                                      Response Code
                                  </HeadingText>
                                  <PieChart fullWidth accountId={accountId} query={responseCodes+since} />
                                  </main>
                              </GridItem>
                              <GridItem className="primary-content-container" columnSpan={6}>
                                  <main className="primary-content full-height">
                                  <HeadingText spacingType={[HeadingText.SPACING_TYPE.MEDIUM]} type={HeadingText.TYPE.HEADING_4}>
                                      Transaction Errors
                                  </HeadingText>
                                  <PieChart fullWidth accountId={accountId} query={errCount+since} />
                                  </main>
                              </GridItem>
                          </Grid>
                        );
                    }}
                    </PlatformStateContext.Consumer>
                </StackItem>
            </Stack>
        )
    }
}
```

## 概要 [#summary]

この例のすべての手順を完了したので、次の 2 つの方法で`NerdGraphQuery`コンポーネントを使用してアカウントからデータを正常にクエリできました。

* アプリケーションのレンダリング メソッド内で`NerdGraphQuery`コンポーネントを使用し、返されたデータを子コンポーネントに渡します。
* アプリケーションがレンダリングされる前に、 `NerdGraphQuery.query`メソッドを使用してデータをクエリします。
