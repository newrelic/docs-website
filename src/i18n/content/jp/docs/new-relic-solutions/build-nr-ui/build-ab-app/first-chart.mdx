<Callout variant="tip">
このレッスンは、New Relic アプリケーションをゼロから構築する方法を学習するコースの一部です。 まだご覧になっていない方は、概要をご覧ください。

コースの各レッスンは前回のレッスンに基づいて構築されるため、このレッスンを開始する前に、前回のレッスン「A/B テスト アプリケーションにチャート コンポーネントを追加する」を完了していることを確認してください。
</Callout>

このコースでは、 New Relicプラットフォーム用の A/B テスト アプリケーションを構築します。 前回は、 New Relic SDK]\(/docs/New Relic-solutions/build-nr-UI/sdk-component/intro-to-sdk) とそのコンポーネント ライブラリについて学習しました。 さて、まずチャート コンポーネントに焦点を当ててアプリケーションの構築を開始します。

作成する必要があるチャートは複数あり、最初は大変に思えるかもしれませんが、1 つずつ進めてください。 一番上のグラフ、つまり最初に作成するグラフは、ニュースレターに登録したユーザーの数と、そのユーザーに表示された Web サイトのバージョンを示す折れ線グラフです。

<Steps>
<Step>
[コースワークリポジトリ](https://github.com/newrelic-experimental/nru-programmability-course)の`add-your-first-chart/ab-test`ディレクトリに変更します:

```sh
cd nru-programmability-course/add-your-first-chart/ab-test
```

このディレクトリには、コースのこの時点でアプリケーションに必要なコードが含まれています。 各レッスンの開始時に正しいディレクトリに移動することで、カスタム コードが残され、間違ったコードがレッスン間で持ち越されることがなくなります。
</Step>

<Step>
`nerdlets/ab-test-nerdlet`に、 `newsletter-signups.js`という名前の新しい Javascript ファイルを追加します。

```sh
touch newsletter-signups.js
```
</Step>

<Step>
この新しいファイルで、最初の`LineChart`といくつかの模擬データを保持する`NewsletterSignups`というコンポーネントを作成します。

```jsx fileName=nerdlets/ab-test-nerdlet/newsletter-signups.js
import React from "react";
import { LineChart } from "nr1";

export default class NewsletterSignups extends React.Component {
render() {
  const versionASignups = {
    metadata: {
      id: "version-a-newsletter-signups",
      name: "Version A",
      viz: "main",
      color: "blue",
    },
    data: [
      { x: 0, y: 0 },
      { x: 10, y: 10 },
      { x: 20, y: 15 },
      { x: 30, y: 5 },
      { x: 40, y: 30 },
      { x: 50, y: 25 },
    ],
  };
  const versionBSignups = {
    metadata: {
      id: "version-b-newsletter-signups",
      name: "Version B",
      viz: "main",
      color: "green",
    },
    data: [
      { x: 0, y: 20 },
      { x: 10, y: 5 },
      { x: 20, y: 25 },
      { x: 30, y: 45 },
      { x: 40, y: 50 },
      { x: 50, y: 35 },
    ],
  };
  return <LineChart data={[versionASignups, versionBSignups]} fullWidth />;
}
}
```

ここでは、テストのバージョン A と B を表す 2 つの任意のデータ シリーズを作成しました。 現時点では、手動で作成されたデータ ポイントを使用しています。 将来的には、これらを New Relic からクエリされたデータに置き換えます。

グラフ内の各系列に色を指定していることに注意してください。 `color`メタデータ属性は、CSS で許容される任意のカラー形式を取ります。 `viz: 'main'`を設定すると、 `LineChart`シリーズをコンポーネントのデフォルトの表示スタイルである線としてレンダリングすることになります。 `LineChart`コンポーネントの`data`プロパティでは、2 つのシリーズを配列で渡して、両方が一緒に表現されるようにしました。 最後に、チャートの`fullWidth`プロパティを使用して、チャートの幅を広げてビューを埋めました。
</Step>

<Step>
Nerdlet の`index.js`ファイルで、新しいコンポーネントをインポートし、Nerdlet の`render()`メソッドのデフォルトの見出しを新しいコンポーネントに置き換えます。

```jsx fileName=nerdlets/ab-test-nerdlet/index.js lineHighlight=2,6-8
import React from 'react';
import NewsletterSignups from './newsletter-signups';

export default class AbTestNerdletNerdlet extends React.Component {
  render() {
    return <div>
      <NewsletterSignups />
    </div>
  }
}
```
</Step>

<Step>
`nru-programmability-course/add-your-first-chart/ab-test`にある Nerdpack のルートに移動します。
</Step>

<Step>
Nerdpack の新しい UUID を生成します。

```sh
nr1 nerdpack:uuid -gf
```

既存の Nerdpack を含むコースワーク リポジトリを複製したため、独自の一意の識別子を生成する必要があります。 この UUID は Nerdpack を New Relic アカウントにマッピングします。
</Step>

<Step>
アプリケーションをローカルで提供します。

```sh
nr1 nerdpack:serve
```
</Step>

<Step>
[New Relic](https://one.newrelic.com?nerdpacks=local)で変更内容を表示します。

ここで、アプリケーションに表示される`LineChart`を確認します。

完了したら、ローカル サーバーのターミナル ウィンドウで`CTRL+C`を押して、New Relic アプリケーションの提供を停止します。
</Step>
</Steps>

7 つのステップで、New Relic アプリケーションに命を吹き込むことができました。 アプリケーションでは、単調な「Hello world」メッセージの代わりに、2 つの模擬データ シリーズを含むカラフルな折れ線グラフが表示されるようになりました。 これらのデータ シリーズは、デモ Web サイト内の競合する各デザインのサーバー側トラフィックを表します。 次のレッスンでは、この基礎を基にして別の種類のグラフを作成します。
