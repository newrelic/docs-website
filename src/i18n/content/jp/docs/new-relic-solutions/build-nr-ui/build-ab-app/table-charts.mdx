<Callout variant="tip">
このレッスンは、New Relic アプリケーションをゼロから構築する方法を学習するコースの一部です。

コースの各レッスンは前回のレッスンに基づいて構築されるため、このレッスンを開始する前に、前回のレッスン「円グラフの追加」を完了していることを確認してください。
</Callout>

このコースの各実践レッスンでは、A/B テスト アプリケーションに何か新しいものを追加してきました。 新しいランチャーを起動し、Nerdlet に複数のチャート コンポーネントを追加しました。 このレッスンでは、登録した顧客と登録を解除した顧客の比率など、Web サイトの各バージョンに関する情報を表示する 2 つの新しい`TableChart`コンポーネントを作成します。

<Steps>
<Step>
[コースワークリポジトリ](https://github.com/newrelic-experimental/nru-programmability-course)の`add-tables/ab-test`ディレクトリに変更します:

```sh
cd nru-programmability-course/add-tables/ab-test
```

このディレクトリには、コースのこの時点でアプリケーションに含まれることが予想されるコードが含まれています。 各レッスンの開始時に正しいディレクトリに移動することで、カスタム コードが残され、間違ったコードがレッスン間で持ち越されることがなくなります。
</Step>

<Step>
`nerdlets/ab-test-nerdlet`に、 `totals.js`という名前の新しい Javascript ファイルを追加します。

```sh
touch totals.js
```
</Step>

<Step>
この新しいファイルで、最初の`TableChart`といくつかの模擬データを保持する`VersionTotals`というコンポーネントを作成します。

```jsx fileName=nerdlets/ab-test-nerdlet/totals.js
import React from "react";
import { TableChart } from "nr1";

export default class VersionTotals extends React.Component {
constructor(props) {
  super(props);
}

render() {
  const versionATotals = {
    metadata: {
      id: `totals-${this.props.version}`,
      name: `Version ${this.props.version}`,
      columns: ["name", "count"],
    },
    data: [
      {
        name: "Subscriptions",
        count: 0,
      },
      {
        name: "Page views",
        count: 0,
      },
    ],
  };
  return <TableChart data={[versionATotals]} fullWidth />;
}
}
```

`TableChart` は、 `PieChart`および`LineChart`とは 3 つの大きな点で異なります。 まず、そのシリーズには`color`または`viz`メタデータ属性がありません。 `TableChart`は標準的な視覚化であるため、適用されない`color`などのものは無視されます。 次に、 `TableChart`シリーズには`columns`メタデータ属性があります。 `columns`テーブル上の列の名前を決定します。 最後に、 `TableChart`シリーズ データでは x 値も y 値も使用されません。 代わりに、テーブル列に一致するキーと、行に何が含まれるかを決定する値を使用します。

`VersionTotals`は`version`プロパティを受け取り、それをチャート メタデータの`id`および`name`フィールドに提供することに注意してください。 これにより、同じコンポーネントを使用してバージョン A とバージョン B のテーブルを作成し、重複コードを排除することができます。
</Step>

<Step>
Nerdlet の`index.js`ファイルで、新しいコンポーネントをインポートし、Nerdlet の`render()`メソッドを更新します。

```jsx fileName=nerdlets/ab-test-nerdlet/index.js lineHighlight=5,13-14
import React from 'react';
import NewsletterSignups from './newsletter-signups';
import TotalCancellations from './total-cancellations';
import TotalSubscriptions from './total-subscriptions';
import VersionTotals from './totals';

export default class AbTestNerdletNerdlet extends React.Component {
  render() {
    return <div>
      <NewsletterSignups />
      <TotalSubscriptions />
      <TotalCancellations />
      <VersionTotals version='a' />
      <VersionTotals version='b' />
    </div>
  }
}
```
</Step>

<Step>
`nru-programmability-course/add-tables/ab-test`にある Nerdpack のルートに移動します。
</Step>

<Step>
Nerdpack の新しい UUID を生成します。

```sh
nr1 nerdpack:uuid -gf
```

既存の Nerdpack を含むコースワーク リポジトリを複製したため、独自の一意の識別子を生成する必要があります。 この UUID は Nerdpack を New Relic アカウントにマッピングします。
</Step>

<Step>
アプリケーションをローカルで提供します。

```sh
nr1 nerdpack:serve
```
</Step>

<Step>
[New Relic](https://one.newrelic.com?nerdpacks=local)で変更内容を表示します。

ここでは、アプリケーションに表示される`TableChart`コンポーネントが表示されます。

完了したら、ローカル サーバーのターミナル ウィンドウで`CTRL+C`を押して、New Relic アプリケーションの提供を停止します。
</Step>
</Steps>

<Callout variant="tip">
設計ガイドには、過去のテストを記録する表がもう 1 つあります。 この表の列は次のとおりです。

* **End Date** \[終了日]: テストの終了日
* **Version A Description** \[バージョン A の説明]: バージョン A の説明
* **Version B Description** \[バージョン B の説明]: バージョン B の説明
* **Winner** \[優勝者]: 最終デザインとして選ばれたバージョン

コード サンプルを参照せずに、これらの列名といくつかの偽のデータを使用して、アプリケーションでこのテーブルを構築してみてください。 この練習により、このレッスンで学んだことが強化されます。

ヘルプが必要な場合は、このコースの次のレッスンに対応する[コースワーク リポジトリ](https://github.com/newrelic-experimental/nru-programmability-course)の`add-a-chart-group`ディレクトリを確認してください。 これには、 `PastTests`コンポーネントのコードが含まれています。
</Callout>

このコースを通じてアプリケーションに追加する各チャートは、そのタイプや表示されるデータがそれぞれ異なります。 これまでに、表、円グラフ、折れ線グラフを作成しましたが、それらはすべて互いに独立して機能します。 次のレッスンでは、さらにいくつかの折れ線グラフを作成しますが、今回はそれらが連携して機能します。
