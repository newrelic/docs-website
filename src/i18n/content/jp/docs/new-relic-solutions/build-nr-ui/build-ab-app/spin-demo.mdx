New Relic アプリケーションを構築する前に、デモ サービスを起動する必要があります。 このコースワークは、次の 2 つの重要なサービスに依存します。

* ニュースレターのサインアップフォームを表示する Web サービス。 フォームの見出しテキストは 2 つのバージョンが交互に表示されます。これは、どのテキストがより高品質のサブスクリプションにつながるかを判断するために A/B テストを実行しているためです。
* 手動でデータを生成する必要がないように、ウェブサイトに安定したトラフィックを送信するシミュレーターサービス

デモ サービスを起動するには、まず[Docker](https://docs.docker.com/get-docker/)と[Docker compose](https://docs.docker.com/compose/install/)をインストールする必要があります。

## デモサービスを開始する [#spin]

<Steps>
<Step>
GitHub から[コースワーク リポジトリ](https://github.com/newrelic-experimental/nru-programmability-course)をクローンします。

```sh
git clone https://github.com/newrelic-experimental/nru-programmability-course
```

このリポジトリには、NodeJS New Relic 自動化を作成するためのコードが含まれています。 また、コース内の各レッスンのアプリ コード ディレクトリも含まれています。 これらのディレクトリを使用して、コースの内容に沿って学習します。
</Step>

<Step>
`ab-test-app`というデモディレクトリに変更します:

```sh
cd nru-programmability-course/ab-test-app
```

このディレクトリには、デモを使用するための設定ファイルと README が含まれています。
</Step>

<Step>
`docker-compose`を使用して、Web サービスとシミュレーター コンテナーをビルドして実行します。

```sh
NEW_RELIC_LICENSE_KEY=YOUR_NEW_RELIC_LICENSE_KEY docker-compose up -d
```

<Callout variant="important">
`YOUR_NEW_RELIC_LICENSE_KEY`を実際の[ライセンスキー](/docs/accounts/accounts-billing/account-setup/new-relic-license-key/)に置き換えてください。
</Callout>

完了したら、 `localhost:3001`の Web サイトを表示します。
</Step>

<Step>
[New Relic](https://one.newrelic.com)にアクセスし、上部のナビゲーション メニューで**APM**に移動します。 インストゥルメントされたサービスのリストから**Newsletter** \[ニュースレター]を選択します。

New Relic がデモ サービスからデータを受信するまで 1 ～ 2 分待つ必要がある場合があります。 準備が完了すると、パフォーマンス、スループット、Apdex スコアなどのトランザクション データが表示されます。
</Step>

<Step>
デモ サービスを停止するには、 `ab-test-app`ディレクトリから`docker-compose down`を実行します。

```sh
docker-compose down
```
</Step>
</Steps>

これで、New Relic アプリケーションを構築する準備が整いました。
