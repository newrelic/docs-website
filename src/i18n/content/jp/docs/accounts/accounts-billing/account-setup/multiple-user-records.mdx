New Relic ユーザーは、同じメール アドレスを使用して複数のユーザー レコードを持っている場合があります。これは、次の場合に当てはまります。

* 複数の[New Relic 組織](/docs/accounts/accounts-billing/account-structure/new-relic-account-structure)へのアクセス
* New Relic 組織内の複数の[認証ドメイン](/docs/accounts/accounts-billing/new-relic-one-user-management/authentication-domains-saml-sso-scim-more)へのアクセス

<Callout variant="important">
  組織の認証ドメインから完全に削除するには（これは永続的であり、元に戻すことはできません）、次のいずれかのパスを使用します：

  * **推奨されるパス:** その組織の管理ユーザーに依頼して、その組織の1つ以上の認証ドメインからユーザーを削除してもらいます
  * **フォールバックパス:** その組織の1つ以上の認証ドメインからユーザーを削除することへの明示的な同意を添えて、[New Relicサポートケース](/docs/new-relic-solutions/solve-common-issues/find-help-get-support/#file-ticket)を作成します。
</Callout>

## ユーザーのカウントと追跡方法 [#user-records]

New Relic でユーザーが作成されると、そのユーザーにはユーザー ID が付与されます。 ユーザーの ID を見つけるには、 [<DNT>**User management**</DNT> UI](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-ui-and-tasks)に移動して特定のユーザーの情報を検索します。

<Callout variant="tip">
  自分のユーザー ID を見つける方法の 1 つは、New Relic UI ページのロードのソース コードを検査し、そのページで `userId`を検索することです。
</Callout>

請求目的で New Relic 組織内のユーザー数を決定するには、ユーザー ID をカウントし、同じ電子メール アドレスを持つユーザーの重複を除外します。

New Relic でメール アドレスを更新しても、二重請求が発生することはありません。電子メールを更新していて、組織内に複数のユーザー レコードがある場合は、必ずすべてのユーザー レコードを更新してください。

## ユーザー レコードを切り替える [#switch]

Each [New Relic organization](/docs/accounts/accounts-billing/account-structure/new-relic-account-structure) you have access to has its own user record for your email address. To switch between these user records, in the user menu, select <DNT>**Other users**</DNT>. Each entry shows the organization name and [authentication domain](/docs/accounts/accounts-billing/new-relic-one-user-management/authentication-domains-saml-sso-scim-more) for that user record. If an organization has more than one authentication domain, you&apos;ll have a separate user record for each one. Choosing another entry prompts you to log in for that organization, either directly or via your identity provider.

アクセスできる組織が1つだけの場合、ユーザーメニューに<DNT>**Other users**</DNT>オプションは表示されません。

<Callout variant="tip">
  別の電子メール アドレスを持つユーザー レコードにアクセスするには、ログアウトしてから再度ログインする必要があります。
</Callout>

## 「複数のログインが見つかりました」メッセージ [#login-message]

メールが複数のユーザー レコードに関連付けられている場合、ログイン時に`Multiple logins found`メッセージが表示され、メールを確認するよう求められます。これは、複数の New Relic 組織、または組織内の複数の[認証ドメイン](/docs/accounts/accounts-billing/new-relic-one-user-management/authentication-domains-saml-sso-scim-more)にアクセスできる場合に発生する可能性があります。

メール アドレスを確認すると、アクセスするユーザー レコードを選択できるようになります。メール アドレスを確認しない場合、New Relic は、メール アドレスに関連付けられた、最近作成されたユーザー レコードを使用してログインを試みます。

ログインのたびにメールを確認する手間を省くには、ログイン画面の<DNT>**Remember me**</DNT>チェックボックスをクリックします。

ログインの問題の詳細については、 [「ログインの問題のトラブルシューティング」](/docs/accounts/accounts-billing/account-setup/troubleshoot-new-relics-password-email-address-login-problems)を参照してください。

## ユーザー レコードの削除 [#delete]

誤って New Relic にサインアップしてしまった場合は、「 [組織を削除する](/docs/accounts/accounts-billing/account-setup/downgradecancel-account/#cancel-unused-org)」を参照してください。

ユーザー レコードを削除する場合は、 [ユーザー管理 UI](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-ui-and-tasks)を使用します。
