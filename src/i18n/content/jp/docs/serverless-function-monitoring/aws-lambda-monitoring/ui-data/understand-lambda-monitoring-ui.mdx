[Serverless monitoring for AWS Lambda](/docs/introduction-new-relic-monitoring-aws-lambda) では、Lambda関数の詳細なパフォーマンスモニタリングが可能です。このドキュメントでは、以下の方法を説明しています。

* [UIでLambdaのデータを探す](#find-data)
* [UIコンポーネントの理解](#ui-pages)
* [チャートデータの把握](#chart-data)
* [カスタムチャートの作成方法](#chart-data)

## 自分のデータを見る [#find-data]

<img title="new-relic-lambda-entities-screenshot.png" alt="new-relic-lambda-entities-screenshot.png" src="/images/lambda_screenshot-full_all-entities.webp" />

<figcaption>
  <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; All entities &gt; Amazon Web Services &gt; Lambda functions**</DNT>：Lambda関数をクリックして、チャートと詳細を表示します。
</figcaption>

New RelicでLambdaデータを表示するには：<DNT>**[one.newrelic.com](https://one.newrelic.com/all-capabilities)**</DNT>に移動し、<DNT>**Explorer.**</DNT>をクリックします。左側のナビゲーションで、<DNT>**Amazon Web Services**</DNT>の下にある次をクリックします。 <DNT>**Lambda functions.**</DNT>

UIの詳細について[は、「NewRelicプラットフォームの概要](/docs/project-wanda-early-access-future-new-relic-platform)」を参照してください。

<Callout variant="important">
  Lambdaのデータが見つからない場合。

  * Lambdaモニタリングを有効にするための [の指示に従っていることを確認してください](/docs/install-enable-new-relics-monitoring-aws-lambda) 。
  * なお、この機能は、 [インフラ監視のLambda統合](/docs/integrations/amazon-integrations/aws-integrations-list/aws-lambda-monitoring-integration) とは異なります。
</Callout>
