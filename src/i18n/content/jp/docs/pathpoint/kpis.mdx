<DNT>**KPIs**</DNT>ページでは、フローに設定されたビジネスメトリクスを分析するための専用ビューが提供されます。アクセスするには、フロー内のナビゲーションから<DNT>**KPIs**</DNT>を選択します。

KPIページには、フローに設定されたすべてのKPIが時系列チャートとして表示され、主要なビジネスメトリクスが時間の経過とともにどのように推移しているかをより深く把握できます。

各KPIチャートには、メトリクスが時間の経過とともにどのように推移したかを示す時系列の視覚化が表示されます。右上のタイムピッカーを使用して、過去30分や過去1時間など、チャートの時間範囲を調整します。

KPIはスコープごとにグループ化されます：

* <DNT>**Global KPIs**</DNT>：フロー全体に適用します。
* <DNT>**Stage-level KPIs**</DNT>：特定のステージに適用します。

KPIを管理するには、右上の<DNT>**Manage KPIs**</DNT>をクリックします。

## KPIを管理する [#manage-kpis]

<DNT>**Manage KPIs**</DNT>ページでは、フローのKPIを作成、編集、および削除できます。設定されたすべてのKPIのテーブルが表示され、それぞれの名前、カテゴリ、説明、ステージ、<DNT>**Metric query**</DNT>、および<DNT>**Evaluation window**</DNT>が示されます。

<img title="Manage KPIs" alt="A screenshot showing the Manage KPIs table with several configured KPIs, and a collapsed Add a KPI section below it." src="/images/pathpoint-manage-kpis.webp" />

### KPIを追加する [#add-a-kpi]

フローの<DNT>**Summary**</DNT>タブで、<DNT>**+ Add KPIs**</DNT>をクリックします。

<img title="Add a KPI" alt="A screenshot showing the Add a KPI form filled in with a Revenue KPI, and the resulting preview chart." src="/images/pathpoint-add-kpi.webp" />

1. <DNT>**KPI name**</DNT>を入力し、任意で<DNT>**Category**</DNT>と<DNT>**Description**</DNT>を入力します。

2. <DNT>**Global / Stage**</DNT>で、フロー全体または特定のステージを選択します。

3. <DNT>**Create query**</DNT>で、生のイベントをビジネスメトリクスに変換するクエリを構築します：

   * <DNT>**FROM**</DNT>：イベントタイプ。
   * <DNT>**SELECT**</DNT>：<DNT>**AS**</DNT>で名前が付けられた集計と属性。
   * <DNT>**WHERE**</DNT>：オプションの条件。

4. <DNT>**Set evaluation window**</DNT>で、<DNT>**Default**</DNT>を維持するか、<DNT>**Custom**</DNT>を選択して<DNT>**Since**</DNT>と<DNT>**Compare against**</DNT>を設定します。

5. <DNT>**Preview**</DNT>をクリックして結果を確認します。

6. <DNT>**Add a KPI**</DNT>をクリックします。

<Callout title="注記">
  <DNT>**Since**</DNT> および<DNT>**Compare against**</DNT>は相対時間のみを受け付けるため、KPIは最新の状態に保たれます。絶対タイムスタンプはサポートされていません。

  [フロービュー](/docs/pathpoint/flow-view)にはタイムピッカーがありません。現在の状態が表示されるため、前週比や前月比などのKPIのケイデンスを設定するのは<DNT>**Set evaluation window**</DNT>です。
</Callout>

### KPIの編集、複製、または削除 [#edit-duplicate-delete-kpi]

テーブル内のKPIの行にある<DNT>**...**</DNT>メニューをクリックします：

* <DNT>**Edit**</DNT>：KPIを再度開いて、任意のフィールドを変更できるようにします。
* <DNT>**Duplicate**</DNT>：変更用のコピーを作成します。既存のKPIのバリアントに役立ちます。
* <DNT>**Delete**</DNT>：KPIをフローから削除します。

<Callout variant="caution">
  KPIの削除は永続的であり、元に戻すことはできません。
</Callout>
