このページでは、変更可能なAgent Controlの設定とそのデフォルト値を一覧で示します。ローカルおよびリモート設定の概要、およびAgent Controlが管理するエージェントの設定方法の例については、「[設定の管理](/docs/new-relic-control/agent-control/configuration)」をご覧ください。

Fleet Controlの接続（`fleet_control`）、`host_id`、管理対象のエージェント（`agents`）、および値プロバイダーについては、[設定の管理](/docs/new-relic-control/agent-control/configuration)で説明しています。

### 環境変数による設定の上書き [#environment-variables]

任意の設定を環境変数として設定できます。`NR_AC_`プレフィックスを使用し、設定名を大文字で記述して、ネストされたキーを区切るには二重のアンダースコア（`__`）を使用します。環境変数はローカル設定ファイルよりも優先されます。

```bash
# log.level
NR_AC_LOG__LEVEL=DEBUG

# fleet_control.auth_config.client_id
NR_AC_FLEET_CONTROL__AUTH_CONFIG__CLIENT_ID="some-client-id"
```

ホストでは、サービス環境ファイル、またはローカル設定ディレクトリ（Linuxでは`/etc/newrelic-agent-control/`、Windowsでは`C:\Program Files\New Relic\newrelic-agent-control\`）の`environment_variables.yaml`ファイルでこれらの変数を定義できます。ファイルは、文字列キーから文字列値へのフラットなYAMLマップである必要があります：

```yaml
NR_AC_LOG__LEVEL: "DEBUG"
HTTPS_PROXY: "http://proxy.local:8443"
```

* キーは文字またはアンダースコアで始まり、文字、数字、およびアンダースコアのみを含む必要があります。
* Agent Controlは、このファイルを監視しません。変更後は、Agent Controlを再起動してください。
* Agent Controlは、管理するエージェントにこれらの変数を渡します。
* ファイルに無効なエントリがある場合、Agent Controlの起動に失敗します。

## プロキシ： `proxy` [#proxy]

Agent Controlは、システムの`HTTP_PROXY`および`HTTPS_PROXY`環境変数を使用します。`proxy`設定を使用してプロキシを設定することもできます。複数が定義されている場合、Agent Controlは以下の優先順位でそれらを使用します：

1. `proxy`設定
2. 環境変数`HTTP_PROXY`
3. 環境変数`HTTPS_PROXY`

```yaml
proxy:
  url: https://user:password@proxy.example.com:8080
  ca_bundle_file: /etc/ssl/certs/proxy-ca.pem
```

## Kubernetesの設定： `k8s` [#k8s]

  cluster_name: "my-cluster"
  namespace: "newrelic-agent-control"
  namespace_agents: "newrelic-agent-control-agents"
