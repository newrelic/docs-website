New Relic Control は、環境全体のエージェントおよびテレメトリー パイプラインに対する一元的かつスケーラブルな制御を提供するオブザーバビリティ管理ソリューションです。 このドキュメントでは、ソリューション コンポーネント、コア機能、およびデプロイメント オプションについて説明します。

## コンポーネント

* **[Agent Control](/docs/new-relic-control/agent-control/overview):** New RelicNew Relic他の およびOpenTelemetry エージェントの ディストリビューションを管理する軽量のスーパーバイザ コンポーネント。Fleet Controlと通信して、インフラストラクチャ レベルの計装の健全性をリモートで構成、更新、監視します。
* **[Fleet Control](/docs/new-relic-control/fleet-control/overview) : インフラストラクチャ**全体にわたるすべての監視対象エージェントの可視性とリモート管理を提供する集中型インターフェイス。 これにより、チームはエージェントを大規模にインストール、構成、監視、アップグレードできるようになります。
* **[Pipeline Control](/docs/new-relic-control/pipeline-control/overview) :**データベースの取り込み前に価値の低いデータをフィルタリングして破棄するのに役立つ、 New Relic Control のデータ管理コンポーネント。

## 範囲

Agent ControlとFleet Controlは、次の3つの環境にわたるインフラストラクチャレベルの計装を管理します：Kubernetesクラスタ、Linuxホスト、Windowsホスト。これらが対象とする計装には以下が含まれます：

* **New Relicエージェント:** New RelicInfrastructureエージェントおよびNew Relic OpenTelemetry(NRDOT) コレクターの ディストリビューションに基づくエージェントが含まれます。
* **オンホストインテグレーション：**Apache、Flex、Memcached、MySQL、NGINX、PostgreSQL、およびRedisが含まれており、今後さらに多くのサポートが追加される予定です。
* **標準ベースの計装:** Prometheus とFluent Bitが含まれます。

すべてのエージェントがすべての環境で利用できるわけではありません。それぞれがサポートしている内容については、[エージェントタイプの互換性に関するドキュメント](/docs/new-relic-control/agent-control/agent-types)を参照してください。

Pipeline Controlは一般提供 (GA) されており、価値の低いデータをドロップすることでAPMエージェントからのデータの管理に使用できます。 サポートされているエージェントの詳細については、 [「サポートされているエージェントのバージョン」](/docs/new-relic-control/pipeline-control/modify-agent-configuration/#supported-agent-versions)を参照してください。

## 重要な行動

* **エージェントなしで開始:** Agent Controlデフォルトで管理エージェントのない軽量スーパーバイザとしてインストールされます。 インストレーション後にFleet Controlを介してどのエージェントをデプロイするかを定義します。自動的にインストルメントされることはありません。
* **Linux でのリモート インストールとアップグレード:** Linux ホストでは、個々のホストに触れることなく、 Fleet Controlリモート設定を通じてエージェントのインストール、構成、アップグレードを完全に行うことができます。
* **エージェントの自動移行なし:** Agent Control既存のエージェント インストレーションを自動的に移行しません。 ホストまたはクラスタ上ですでにエージェントを実行している場合は、まずそれらをアンインストールし、次にFleet Controlを使用して展開する必要があります。 移行プロセスについては、 [「既存の計装の管理」を](/docs/new-relic-control/agent-control/reinstrumentation)参照してください。

## 必要な権限

* **Agent Control :** Agent Controlを設定し、それをFleet Controlに接続するには、認証ドメイン マネージャー ロールが必要です。 詳細については、 [「ユーザー管理の概念」](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts/#admin-settings)を参照してください。
* **Fleet Control：**フリートおよび設定の作成と編集には、組織の製品管理者ロールが必要です。デフォルトのユーザーグループのユーザーは、すでにこのロールを持っています。デプロイメントを実行するには、組織全体の組織マネージャー、または特定のフリートに付与されたフリートマネージャーロールのいずれかが必要です。詳細については、[Fleet Controlアクセスの管理](/docs/new-relic-control/fleet-control/access-management)を参照してください。
* **Pipeline Control :** Pipeline ControlゲートウェイとPipeline Controlルールを設定および管理するには、組織マネージャーの役割が必要です。
