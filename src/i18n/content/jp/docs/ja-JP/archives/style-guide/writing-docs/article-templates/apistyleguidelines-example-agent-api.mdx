## 構文

```
newrelic.apiStyleGuidelines(data type $parameter_name[, integer $optional_param])
newrelic.apiStyleGuidelines(data type $parameter_name, array $different_param, string $third_param)
```

コールについて簡単に説明します。理想的には、「View all methods」ページで1行以下にします。

## 要件

エージェントのバージョン1.2.3.4またはそれ以降。

独自の行に追加の要件を記載します（箇条書きは使用しないでください）。

コールアウトは使用しないでください。

特別な要件がない場合は、次のように記述します： `Compatible with all agent versions.`

## 説明

呼び出しの動作をできるだけ詳細に説明してください。個々のパラメーターの機能については、大まかな説明にとどめてください。パラメーターと呼び出しのバリアントの詳細は、`Parameters`の見出しの下に記載します。同様に、戻り値についても説明しないでください。

別のAPIコールを相互参照する場合は、その名前をコードブロックでフォーマットし、次のように括弧`()`を含めてください：`anotherCoolMethod()`。

<Callout variant="tip">
  コールアウトを含めることはできますが、慎重に使用してください。これらのページはすでに視覚的に煩雑です。
</Callout>

## 戻り値

この呼び出しは何を返しますか、またどのような状況で返しますか？顧客がその戻り値を使用して行うと想定されることはありますか？呼び出しが何も返さない場合は、このセクションを空白のままにしてください。

## 例

このセクションでは、自己文書化されていない変わり種に関するルールを文書化します。残りの例は、ページ自体に埋め込まれています。一般に、このページはスタイルのリファレンスを目的としています。優れたAPIメソッドページの記述方法の例については、[PHP API](/docs/agents/php-agent/php-agent-api)などの既存のAPIドキュメントを確認してください。

### URLガイドライン

ドキュメントのURLの場合：

* URLスラッグを手動で編集して、エージェント名を削除します。
* APIコールに（`newrelic_awesome_call`のように）区切り文字がまだ含まれていない場合は、ハイフン`-`で各部分を区切ります。

例えば：

```
https://docs.newrelic.com/docs/new-relic-only/advanced-style-guide/writing-guidelines/api-style-guidelines
```

### タイトルのガイドライン

ドキュメントのタイトルの場合：

* メソッド名とエージェント名を括弧内に含めます。
* 呼び出し名に不可欠である場合（PHPエージェントの場合など）を除き、`newrelic.`プレフィックスを含めないでください。
* 呼び出し自体に括弧`()`を含めないでください。

例えば：

```
apiStyleGuidelines (Example agent API)
```

### 短いタイトルのガイドライン [#short-title-guideliens]

ドキュメントの短いタイトルの場合：

* メソッド名のみを含めてください。
* 呼び出し名に不可欠である場合（PHPエージェントの場合など）を除き、`newrelic.`プレフィックスを含めないでください。
* 括弧`()`を含めないでください。
* 必要に応じて、カテゴリのサイドバーの1行に収まるように調整します。

例えば：

```
apiStyleGuidelines
```

### 構文のガイドライン

<Callout variant="important">
  PythonおよびiOSエージェントは独自のガイドラインを使用します。これらのガイドラインについては、それらの言語の既存のメソッドを参照してください。
</Callout>

* コールの各バリアントをそれぞれの行にドキュメント化します。
* データ型を斜体にする以外の書式設定は使用しないでください。
* オプションのパラメーター（カンマ区切り文字を含む）を角括弧`[]`で囲みます。
* 変数部分の前にドル記号`$`を付けて示します。
* 呼び出しに`newrelic.`などのプレフィックスを付ける必要がある場合は、それを構文に含めてください。
* オプション: 特定のエージェントにとって重要と思われる場合は、戻り値を含めます。その場合は、言語の規則に従ってください。
