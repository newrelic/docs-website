変更を加える前に、MDXドキュメントファイルの特定の側面について警告し、他のライターやコントリビューターの注意を引く必要がある場合があります。これは、`<CONTRIBUTOR_NOTE>`コンポーネントを使用してコメントを挿入することで実行できます。

このコンポーネントを使用する2つの例を以下に示します：

* サイト上の機密情報への変更について他のユーザーに警告します。
* サイト上のその場所に情報が存在する理由を説明してください。

`<CONTRIBUTOR_NOTE>`コンポーネントを使用してメモを作成する場合、それらのメモがHTMLに変換されることはなく、Webサイト上で読者に直接表示されることもありません（**ソースを表示**を含む）。ただし、サイトを編集する人には表示されるため、常に声のトーンや表現に配慮してください。

次の例を見てみましょう。

```jsx
<CONTRIBUTOR_NOTE>
  Do not change this URL unless you have explicit permission from a manager at New Relic.
</CONTRIBUTOR_NOTE>
```
