画像の注釈は、画面キャプチャや図の中のテキストや図形であり、情報を参照したり、スクリーンショットの最も重要な部分に注意を向けたりするのに役立ちます。注釈は気を散らす原因になることがあり、最新の状態に保つことも難しいため、慎重に使用することをお勧めします。[画像のキャプション](/docs/style-guide/images/screenshots-images/#captions)やテキスト内の指示などの代替手段を使用できることに留意してください。

画像の注釈を使用する必要がある場合：

* 簡潔にしてください。
* 注釈がUIテキストと簡単に区別できることを確認してください。たとえば、UI要素のように見えないようにボックスをずらす必要がある場合があります。
* 注釈は翻訳されないため、使用は控えめにしてください。
* タイトルのように機能する注釈を上部に使用しないでください。キャプションを使用してください。
* 注釈がダークモードとライトモードで表示されることを確認してください。
* 注釈の一貫性を保つために、[New Relic SnagItテーマ](https://github.com/newrelic/newrelic-doc-tools)（リンクはNew Relic社員のみ利用可能）を使用してください。

## New Relic SnagItテーマのインストール [#install-theme]

以下の手順に従ってください。

1. 最新バージョンのSnagItを実行していることを確認してください。

2. GitHub Desktopで、[リポジトリ](https://github.com/newrelic/newrelic-doc-tools)をローカルにクローンします。

3. SnagItを開き、任意のツールを選択して右側のナビゲーションを開きます。

4. 右側のナビゲーションの**Quick Styles** \[クイックスタイル]ペインで、**Theme** \[テーマ]フィールドの歯車アイコンを選択し、次に**Import** \[インポート]を選択します。

5. 開いたダイアログボックスで`YOUR_GIT_DIRECTORY/newrelic-doc-tools/themes`に移動し、`New-Relic-Docs.snagtheme`ファイルを選択して、**Open** \[開く]をクリックします。

   <img width="60%;" title="Selecting the `New-Relic-Docs.snagtheme` file" alt="Selecting the `New-Relic-Docs.snagtheme` file" src="/images/style-guide_screenshot-crop_selecting_theme.webp" />

   <figcaption>
     `New-Relic-Docs.snagtheme`ファイルを選択します。

6. インポートされたテーマは、テーマフィールドですでに選択されています。

## コールアウトボックス [#callout-boxes]

スクリーンショット内の要素を強調表示するには、コールアウトを使用します。可能であれば、スクリーンショットにテキストを追加しないでください。それはドキュメントの役割です。コールアウトボックスは、強調表示している要素を隠さないようにする必要があります。たとえば、UIボタンを囲むコールアウトボックスは、ボタンのどの部分も覆わないようにする必要があります。可能であれば、UI要素とコールアウトボックスの間に2ピクセルの間隔を設けてください。

コールアウトボックスを追加するためのフォーマットは次のとおりです：

* 形状：正方形または長方形、透明な塗りつぶし、border-radiusなし。
* 境界線の色：#00CE7C
* 線幅：5pt
* 不透明度：100％
* 線のスタイル：実線
* シャドウなし

## コールアウトテキスト [#callout-text]

99％の場合、スクリーンショットにテキストのコールアウトは必要ありません；`<figcaption>`タグと、画像の前後の記述内容でスクリーンショットを説明するのに十分なはずです。ただし、テキストボックスが必要な場合でも、重要なUIテキストや要素と重ならないようにしてください。

スクリーンショットにテキストを追加する必要がある場合は、次のガイドラインに従ってください：

* 形状：正方形または長方形、塗りつぶしの色 #00CE7C。
* 境界線の色：#00CE7C
* 線幅：5pt
* 不透明度：100％
* 線のスタイル：実線
* シャドウなし
* フォント：Arial太字 #FFFFFF、サイズ24pt、左揃え

## 矢印 [#arrows]

UI内の要素を参照する場合は、スクリーンショットで片方向の矢印または両端に矢印がある矢印を使用してください。

矢印を使用する場合は、重要なUIテキストや要素と重ならないようにしてください。

矢印を追加するためのフォーマットは次のとおりです：

* 不透明度：100％
* 線の太さ：7pt
* 色: #00CE7C
* 線のスタイル：実線、始点のサイズなし、終点のサイズは5
* シャドウなし
