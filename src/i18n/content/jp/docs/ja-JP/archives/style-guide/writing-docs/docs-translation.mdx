New Relicのドキュメントは以下のサイトに存在します：

* [**docs.newrelic.com**](https://docs.newrelic.com):英語
* [**docs.newrelic.com/jp/**](https://docs.newrelic.com/jp/):日本語
* [**docs.newrelic.com/kr/**](https://docs.newrelic.com/kr/):韓国語
* [**docs.newrelic.com/es/**](https://docs.newrelic.com/es/):スペイン語
* [**docs.newrelic.com/pt/**](https://docs.newrelic.com/pt/)：ポルトガル語
* [**docs.newrelic.com/fr/**](https://docs.newrelic.com/fr/):フランス語

トップメニューバーのボタンで言語を切り替えることができます。

## 翻訳ステータスを表示 [#translation-status]

すべてのドキュメントのフロントマターには、人間による翻訳ステータスが含まれています。

フロントマターに`translate:`要素がない場合、ドキュメントはどの言語にも人手で翻訳されません。それでも、機械翻訳されるすべての言語に自動的に翻訳されます。

`translate:`要素に`jp`などの言語の略語が含まれている場合、そのドキュメントは翻訳済み、翻訳予定、または翻訳が検討されています。例を以下に示します。

```md
---
title: 'NRQL reference'
translate:
  - jp
  - kr
  - es
  - pt
  - fr
metaDescription: "A detailed reference list of clauses and functions in NRQL, the New Relic query language."
redirects:
  - /docs/insights/using-nrql
```

## 翻訳されたドキュメントの更新 [#update-translation]

サイトは1日に1回自動ジョブを実行し、ドキュメントへの変更をターゲット言語に自動的に翻訳します。

## 翻訳されたドキュメントのSEOステータスを表示する [#translation-seo]

サイトのフロントエンドは、ドキュメントの[翻訳ステータス](#translation-status)情報を使用して、ページのSEO`hreflang`要素を表示します。これにより、検索エンジンに、そのページには特定の言語で利用可能なバージョンもあることが伝わります。

```html
<link rel="alternate" href="https://docs.newrelic.com/jp/" hreflang="ja" />
```

## ドキュメントの削除と移動 [#delete]

英語のドキュメントに変更を加えると、GitHubでペアになっていない翻訳エラーが発生する場合があります。i18nフォルダーに変更を加えるシナリオは次のとおりです：

* mdxファイルを削除する場合は、`/kr/`および`/jp/`フォルダー内の対応するmdxファイルも削除してください。yamlファイルは更新**しません**。
* mdxファイルをフォルダーXからフォルダーYに移動する場合、`/kr/`と`/jp/`でも同じmdxファイルをフォルダーYに移動する必要があります。yamlファイルは更新**しません**。
* mdxファイルを新しいフォルダーに移動する場合、`/kr/`と`/jp/`にその新しいフォルダーを作成し、その中にmdxファイルを移動する必要があります。yamlファイルは更新**しません**。

ファイルを手動で削除または移動する代わりに、次のコマンドシーケンスを実行します：

* 翻訳されたファイルを移動/名前変更するには：

  ```bash
  yarn i18n-utility list-renames
  yarn i18n-utility make-renames
  ```

* 翻訳されたファイルを削除するには：

  ```bash
  yarn i18n-utility list-orphans
  yarn i18n-utility delete-orphans
  ```
