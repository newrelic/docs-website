名詞の複数形化は、句読点やスペルに微妙な変化をもたらし、人々が書かれた言葉を解釈する方法に影響を与える可能性があります。

## 基本

* 1文字のアルファベットを複数形にするには、アポストロフィを使用します。
* 頭字語を複数形にするためにアポストロフィを使用しないでください。

| 実行                     | してはいけないこと              |
| ---------------------- | ---------------------- |
| vacuumという単語にはuが2つあります。 | vacuumという単語にはuが2つあります。 |
| 細部まで注意を払うことを忘れないでください。 | 細部まで注意を払うことを忘れないでください。 |
| IPの基本について説明します。        | IPの基本について説明します。        |
