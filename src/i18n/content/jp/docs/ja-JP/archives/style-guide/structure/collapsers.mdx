コラプサーは、[開くようにトリガーする](#trigger-collapser)までページコンテンツを非表示にする展開可能な要素です。読者への配慮から、非常に長いドキュメントのコンテンツを非表示にするためにコラプサーを使用しています。各コラプサーには`title`（読者に表示するもの）がありますが、特定のコラプサーへの深い「アンカー」リンクに使用する`id`もあります。

次のコラプサーの例を見てみましょう。

<CollapserGroup>
  <Collapser id="collapser-1" title="コラプス1">
    これは最初のコラプスの例です。
  </Collapser>

  <Collapser id="collapser-2" title="コラプス2">
    これは2番目のコラプサーの例です。
  </Collapser>
</CollapserGroup>

<Callout variant="tip">
  コラプサー用のKeyboard Maestroマクロは`kkcollapse`です。
</Callout>

## コラプスを作成する [#create]

コラプサーを作成するには、コラプサーコードを使用する必要があります。

コラプスのソースの例を以下に示します：

```jsx
<CollapserGroup>
  <Collapser
    id="collapser-1"
    title="Collapser 1"
  >
    This is our first example collapser.
  </Collapser>

  <Collapser
    id="collapser-2"
    title="Collapser 2"
  >
    This is our second example collapser.
  </Collapser>
</CollapserGroup>
```

## コラプスのトリガー [#trigger-collapser]

サイトでは、いくつかのシナリオでコラプサーが自動的に開きます：

* アンカーIDを介して個々のコラプサーに到達します。たとえば、[上の例のコラプサー1](/docs/style-guide/quick-reference/collapsers#collapser-1)に直接移動します。
* ページ内検索に**CMD+F**（または**CTRL+F**）を使用すると、すべてのコラプスが自動的に開きます。
* ページ上のすべてのコラプスを**s**how（開く）するには、ショートカットキー`s`を入力します。
