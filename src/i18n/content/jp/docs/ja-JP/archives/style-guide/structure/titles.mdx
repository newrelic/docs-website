このドキュメントでは、タイトルと短いタイトルの違いについて説明します。また、これらがパスやリダイレクトにどのように影響し、影響を受けるかについても掘り下げます。

## タイトル

タイトルは、各ドキュメントの先頭にレンダリングされるタイトルです。このドキュメントのタイトルは**タイトル、短いタイトル、パス**です。

ドキュメントのタイトルは、フロントマターで定義されます。このドキュメントのタイトルは以下で定義されています：

```yaml
title: Titles, short titles, and paths
```

## 短いタイトル

短いタイトルは左側のナビゲーションに表示されます。これらは、タイトルが少し長すぎて簡単に確認できない場合に使用されます。このドキュメントの短いタイトルは**Titles and short titles**です。

短いタイトルは、対応するナビゲーションファイルで定義されています。このドキュメントの短いタイトルは`src/content/nav/style-guide.yml`で定義されています：

```yaml
- title: Titles and short titles
  path: /docs/style-guide/structure/titles
```

[左側のナビゲーションの編集](/docs/style-guide/processes-procedures/update-left-navigation-pane)について詳しくご覧ください。

## パスとリダイレクト

特定のドキュメントのパスとファイル名は、そのドキュメントのタイトルとは関係ありません。このドキュメントのパスは`/docs/style-guide/structure/titles`です。ファイル名は`titles`ですが、タイトルも短いタイトルも`Titles`ではないことに注意してください。

リダイレクトは、ドキュメントのタイトル、短いタイトル、およびパスを完全に無視します。リダイレクトが指す場所にリダイレクトされます。[リダイレクト](/docs/style-guide/processes-procedures/rename-or-redirect-document)の詳細をご覧ください。
