`SideBySide`コンポーネントを使用すると、画面を半分またはそれ以上のセクションに分割できます。一般的なユースケースは、右側の列にスクリーンショットを表示し、左側に付随するテキストを表示することです。

各サイドのコンテンツを`Side`コンポーネント内にラップする必要がありますが、各`Side`内には必要なだけコンテンツを追加できます。

技術的には、コンポーネントは3つ以上の`Side`列をサポートしていますが、3つ以上使用することは避けてください。

コンポーネントの例を次に示します：

<SideBySide>
  <Side>
    <img alt="example" src="/images/network_screenshot-full_device-performance.webp" />

    <figcaption>
      **[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Network**に移動します。
    </figcaption>
  </Side>

  <Side>
    これは、素晴らしいドキュメンテーションチームによる素晴らしいコンテンツです。
  </Side>
</SideBySide>

## SideBySideコンポーネントを作成します [#create]

`SideBySide`コンポーネントのテンプレートは次のとおりです：

```jsx
<SideBySide>
    <Side>
        <img alt="Example" src="/images/example-image.webp" />
    </Side>

    <Side>
        This is some awesome content from the amazing documentation team.
    </Side>
</SideBySide>
```

<Callout variant="tip">
  SideBySideのKeyboard Maestroマクロは`kkside`です。
</Callout>
