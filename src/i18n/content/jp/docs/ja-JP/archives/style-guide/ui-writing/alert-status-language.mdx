## 基本

UIには集計ステータスの色付きインジケーターが表示されるため、UI画面とAPI全体で一貫した言語を使用することが重要です。また、このステータスにはアラート以上のものを含め始めています。

必要に応じて、色の意味を説明するホバーステートを含めます。個々のエンティティページのメインステータスバッジでは、ホバーステートにその要因がリストされます。これが不可能な場合は、以下のホバーステートを使用してください。

## UIとAPIの文言のマッピング

| 色    | UIホバー（ツールチップ）   | UIステータスラベル | API             |
| ---- | --------------- | ---------- | --------------- |
| レッド  | 進行中の重大なインシデント   | 致命的        | 致命的             |
| 黄色   | 進行中の警告インシデント    | 低下         | WARNING         |
| グリーン | 進行中のアラートはありません。 | 稼働中        | NOT\_ALERTING   |
| グレー  | レポート停止          | ステータス不明    | NOT\_CONFIGURED |
| 色なし  | -ホバー状態なし-       | -ホバー状態なし-  |                 |
