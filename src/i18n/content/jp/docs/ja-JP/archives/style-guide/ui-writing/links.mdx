当社のUIのリンクは、簡潔であり、当社のスタイルとボイスに一致している必要があります。

## 基本

* スクリーンリーダー向けに最適化するため、リンクテキストは短くしてください。
* リンクの場所ではなく、読者にとってのメリットから始めます。
* 他のコピーで行っているように、会話形式の言語、代名詞、短縮形を使用してください。
* 単に「このリンク」とするのではなく、場所の名前または説明を使用してください。
* ユーザーを製品外に誘導するリンク（当社のドキュメントサイトやサポートサイトなど）の場合は、末尾に外部リンクアイコンを追加してください。

## コード

コードスニペットを顧客に提示する場合は、Menlo等幅フォントでフォーマットします。

```js
var example = "This is an example string in a monospace font!";
```

## リスト

* 各リスト項目の最初の文字を大文字にしてください。
* 一般的な情報のリストには、順序なし（箇条書き）リストを使用します。
* 具体的な手順を含むリストには、順序付き（番号付き）リストを使用します。
