表は情報を整理し、読者が拾い読みしやすくするのに役立ちます。ただし、表が長くなりすぎる場合は、[「5から9」のガイドライン](/docs/style-guide/get-started/introduction-style-guide#organization)に従い、別の方法で情報を再構築することを検討してください。

小文字やすべて大文字にする必要がある特定のファイル名やコード値でない限り、すべてのテーブル列のテキストにはセンテンスケースを使用してください。

<Callout variant="tip">
  TableコンポーネントのKeyboard Maestroマクロは `kktable`
</Callout>

## テーブル構文

当社のテーブルは、MDX Reactコンポーネントとして構築されています。実際には、HTMLテーブルと非常によく似ています：

```html
<table>
    <thead>
        <tr>
            <th style={{ width: "200px" }}>
                Item
            </th>
            <th>
                Description
            </th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>
                Item name
            </td>
            <td>
                Description of item
            </td>
        </tr>
    </tbody>
</table>
```

<Callout variant="tip">
  ドキュメントサイトは技術的に[Markdownテーブル](https://www.markdownguide.org/extended-syntax/#tables)をサポートしていますが、いくつかの理由から使用を避けています：

  * Markdownには複数のフレーバーがあり、フレーバーによって異なるテーブル構文が使用されます。これは、John GruberのオリジナルのMarkdown仕様にはテーブルが含まれていなかったためです。
  * Markdownテーブルは複数行にまたがる要素をサポートしておらず、私たちのテーブルのほとんどには、コードブロック、箇条書きリスト、または複数行を必要とするその他の要素が含まれています。
</Callout>

## 列幅の設定 [#column-width]

`<th>`要素のスタイルルールで列幅を設定できます：

```html
<th style={{ width: "200px" }}>
```

一般的に、ドキュメントサイトの2列のテーブルの場合：

1. 最初の列を200ピクセルに設定します：`style={{ width: "200px" }}`。
2. テーブルが残りのページ幅に自動的に調整されるようにするには、2番目の列の幅を設定しないでください。

## UI機能を説明する表 [#tables-ui]

利用可能な機能を説明するために表を使用する場合は、読者にロードマップを提示してください。ユーザーは、見つけたいことや達成したいことは分かっていても、それが何と呼ばれているか、またはどのように行うかは分からない場合があります。

たとえば、特定のUIページの機能のリストを提供するには、ヘッダーの最初の列に**〜したい場合...**というラベルを付け、2番目の列に**これを行う**というラベルを付けます。
