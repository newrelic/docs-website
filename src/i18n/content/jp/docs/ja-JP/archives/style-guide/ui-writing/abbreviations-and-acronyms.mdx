略語は、頻繁に使用される長い単語やフレーズを表す、単語やフレーズの短縮形です。これらは、スペース、労力、時間を節約するために使用されます。

## 基本

* 読者が頭字語や略語を理解できるかどうかわからない場合は、テキストで初めて使用する際に、単語をスペルアウトし、その後に頭字語を括弧で囲んで記載してください。それ以降は頭字語のみを使用できます。

* スペルアウトされた頭字語は、製品名、チーム名、会社名などの固有名詞が含まれている場合にのみ大文字にします。

* 別途指定がない限り、測定単位は常に省略形を使用してください。

* 可能な限り、略語を使用するのではなく、「average」などの一般的な単語をスペルアウトしてください。

* 一般的な単語を省略する必要がある場合：

  * 文の先頭で略語を使用することは避けてください。
  * 略語の後にピリオドを追加してください。

* スペースが極端に狭い場合を除き、thousand、million、billion、trillionはスペルアウトしてください。省略する必要がある場合は、スペースなしの大文字を使用してください：30K、30M、30B、30T。

* 頭字語を複数形にするためにアポストロフィを使用しないでください。「ABC&apos;s」ではなく「ABCs」とします。[Plurals](../plurals/)ページを参照してください。

## 時間の単位

可能な限り、すべての単位をスペルアウトしてください。

スペースが限られている場合は、以下の標準的な略語を使用してください：

| ユニット | 優先   | 略語（必要な場合） |
| ---- | ---- | --------- |
| ミリ秒  | 4ミリ秒 | 4 ms      |
| 秒    | 5秒   | 5 s       |
| 分    | 6分   | 6 min     |
| 時間   | 7時間  | 7時間       |
| 日数   | 8日   | 8 日       |
| 週数   | 9週間  | 9 w       |
| 月    | 10ヶ月 | 10 mo     |
| 年    | 11年  | 11年       |
