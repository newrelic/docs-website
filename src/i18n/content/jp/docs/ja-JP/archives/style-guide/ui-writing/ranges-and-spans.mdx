---
title: 範囲とスパン
translationType: machine
---

範囲は最小値と最大値を指しますが、スパンは値の間の距離を指します。たとえば、2017年3月1日～2017年5月1日の日付範囲は61日間にわたります。

## 基本

* 範囲や期間の2つの値の間には、enダッシュ（option+-）を使用します。
* 日付とドル金額の場合は、enダッシュの両側にスペースを含めます。
* 未定義の範囲については、可能な最小値を指定し、値の後に+を追加してください。
* 省略された数字に+を追加する場合は、省略形の後にそれを追加します。

| 実行                       | してはいけないこと             |
| ------------------------ | --------------------- |
| 1–20台のサーバー               | 1～20台のサーバー            |
| 2019年8月21日～2019年9月12日    | 2019年8月21日～2019年9月12日 |
| 2019年8月21日 9:45am～8:45pm | 2019年8月21日 9:45～20:45 |
| $ 0.00～$ 29.99           | $ 0.00～$ 29.99        |
| 50以上のアプリケーション            | &gt;50アプリケーション        |
| 29K+ rpm                 | 29+K rpm              |

## タイムレンジ

タイムピッカーで選択したような時間のブロックまたは期間を指す場合は、「time range」を使用してください。

| 実行      | してはいけないこと         |
| ------- | ----------------- |
| 時間範囲    | タイムフレーム、タイムスパン... |
| 別の期間を選択 | 別の期間を選択します。       |
