---
title: ドキュメントの削除
translationType: machine
---

<Callout variant="caution">
  ドキュメントを削除しても、そのコンテンツとリダイレクトはGitHubのコミット履歴で引き続き利用できます。
</Callout>

ドキュメントを削除するには：

1. 削除するドキュメントのMDXファイルを見つけます。

2. リダイレクトに注意してください：

   1. 読者をリダイレクトする最も関連性の高いドキュメントを見つけてください。
   2. [削除されたドキュメントのURLをリダイレクトとして追加します](/docs/style-guide/rename-or-redirect-document)。
   3. 削除されたドキュメントから既存のリダイレクトをコピーし、新しいドキュメントに追加します。

3. 適切なナビゲーションファイルからドキュメントのタイトルとパスを削除します。

4. ドキュメントのMDXファイルを削除します。

5. `src/i18n/content`ディレクトリから対応するMDXファイルを削除します。各英語のドキュメントには、ローカライズされた各言語のMDXファイルがあります。`i18n-utility`スクリプトを使用して、これを自動的に行うことができます：
   ```bash
   yarn i18n-utility delete-orphans
   ```
