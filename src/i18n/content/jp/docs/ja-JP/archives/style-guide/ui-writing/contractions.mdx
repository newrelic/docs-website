translationType: machine

短縮形は、文章に会話的で個人的な雰囲気を与える優れた方法です。自然に感じられる場合に使用してください。

## 基本

* 誰かに話しかける場合と同じ場所で、一般的な短縮形を使用してください。
* 一般的ではない、または不自然に聞こえる短縮形の使用は避けてください。

| 実行               | してはいけないこと        |
| ---------------- | ---------------- |
| アプリケーションを更新しました。 | アプリケーションを更新しました。 |
| エラーが4つある場合のみです。  | エラーが4つある場合のみ。    |
| お話しすることはできません。   | 申し上げることはできません。   |
