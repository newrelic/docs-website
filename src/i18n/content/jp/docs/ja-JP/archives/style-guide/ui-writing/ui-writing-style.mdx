UI向けに執筆する際は、社内の他の部門と同じガイドラインの多くに従います。このセクションでは、よくある質問や、より広範なNew Relicのスタイルガイドラインとのわずかな違いに対処するために、いくつかの特定の要素を取り上げています。

## 当社の音声

New Relicには、製品、ドキュメント、メッセージング、営業資料など、コピーを書く場所であればどこでも使用するボイス（voice）があります。

アメリカ英語を使用し、**誠実**で、**力を与え**、**独創的**な文章を作成します。

当社は信頼できる友人のような印象を与えます。当社は透明性があり、楽観的で、直感的かつ革新的です。New Relicの音声を使用した執筆の詳細については、[音声に関するNew Relicスタイルガイドライン](/docs/style-guide/writing-strategies/voice-strategies-docs-sound-new-relic#voice-strategies)をご覧ください。

ヒント：

* 堅苦しい言葉ではなく、会話的なトーンを使用してください。
* 代名詞と短縮形を使用してください。
* 読者に直接語りかけてください。
* 複雑な概念を簡潔かつ明確に説明し、専門用語を制限してください。
* 該当するアクションや機能からユーザーが何を得るかを考え、その視点から記述してください。
* ユーザーへの価値やメリットを最初に記載し、その後にそれを達成する方法を記載します。
* ユーザーが行うべきことをより適切に表現できる場合は、大胆で革新的な言葉を使用してください。一般的な業界用語にとらわれないでください。
