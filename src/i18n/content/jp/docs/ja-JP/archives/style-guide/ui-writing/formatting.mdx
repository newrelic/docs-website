句読点と同様に、テキストの書式設定は、言葉の解釈に大きな影響を与える可能性があります。たとえば、メッセージ内で強調するためのシンプルなツールとして太字を使用したり、UI上で視線を誘導して何が重要かを直感的に知らせるために使用したりできます。

## 基本

* 太字は、UIの視認性を高めたり、長いテキスト内の特定の単語を強調したりするためによく使用されます。
* 斜体は、入力要素の下にあるコンテキストヒントテキストによく使用され、テキストに強調したトーンや落ち着いたトーンを伝えることができます。
* UIのアンダーライン付きテキストはリンクとして解釈されやすいため、別の目的でこのフォーマットを使用する場合は注意してください。リンクとして機能しないアンダーライン付きの単語に代わる解決策を見つけることを検討してください。

## コード

コードスニペットを顧客に提示する場合は、Menlo等幅フォントでフォーマットします。

```javascript
var example = 'This is an example string in a monospace font!';
```

## リスト

* 各リスト項目の最初の文字を大文字にしてください。
* 一般的な情報のリストには、順序なし（箇条書き）リストを使用します。
* 具体的な手順を含むリストには、順序付き（番号付き）リストを使用します。
