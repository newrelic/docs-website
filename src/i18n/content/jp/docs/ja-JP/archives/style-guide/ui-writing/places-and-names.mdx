title: 場所と名前
translationType: machine
---

社内では通常、場所を略称で呼び(Portland, ORではなくPDX)、人をファーストネームのみで呼びます(Lew CirneではなくLew)。顧客向けのテキストでは、混乱を軽減するために、この情報の提示方法を統一する必要があります。

## 基本

* 固有名詞は大文字にしてください。
* 場所を名詞として言及する場合は、その場所の正式名称を使用してください。

| 実行                       | してはいけないこと           |
| ------------------------ | ------------------- |
| Portland VPNで問題が発生しています。 | PDX VPNで問題が発生しています。 |
