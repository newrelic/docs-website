## インストレーションの方法の概要 [#overview]

現在、顧客がNew Relicをインストールして何かの監視を開始するために使用できる方法は3つあります：

1. ガイド付きインストール、さまざまなシステムにNew Relicをインストールするためのインタラクティブなコマンドラインツール
2. UIの「+ Add more data」ページからの手動インストレーション
3. ドキュメントサイト経由の手動インストレーション

インスタントオブザーバビリティ（I/O）は、インストレーション方法では**ありません**。これは単に、誰かがNew Relicを介してモニターできる可能性のあるすべてのもののカタログを提供します。インスタントオブザーバビリティのページは、利用可能なものに応じて、これら3つのメソッドのいずれかを指し示しているだけです。

CodeStreamには独自のインストレーション方法があります。

## ガイド付きインストール [#guided]

[ガイド付きインストール](/docs/new-relic-one/install-configure/new-relic-guided-install-overview/)では、システムで実行してNew Relicをインストールし、さまざまなものの監視を開始できる単一のコマンドを提供します。

ガイド付きインストールのCLIコマンドを実行すると、infrastructureエージェントがインストールされ、ログの送信が有効になります。また、システム上のインテグレーションを検出し、それらのインテグレーションをモニターするかどうかを選択するプロンプトを表示します。ガイド付きインストールがサポートされている言語のアプリケーションを検出した場合、その言語のAPMエージェントをインストールできます。

ドキュメントでは、適切な場合は常にユーザーをガイド付きインストールに誘導する必要があります。つまり、ガイド付きインストールによって成功する可能性が高い場合です。

## データの追加による手動インストレーション [#manual-add]

[データの追加](https://one.newrelic.com/marketplace?state=7ca7c800-845d-8b31-4677-d21bcc061961)ページは、APMエージェントをインストールしたいユーザーや、最も人気のあるインテグレーションとそれらのインテグレーションの最も一般的なシステム設定を使用しているユーザーに、シンプルでわかりやすいインストレーションパスを提供します。

**Add more data**は、顧客がその情報を探し出す必要がないように、アプリ名やAPIキーなどの値をインストレーション設定ファイルに入力します。また、標準的なユースケースに対して最も簡単なインストレーションパスも提供します。

この方法は、より複雑または不明瞭なものをモニターしようとしている顧客や、非標準的なシステムを持つ顧客にはあまり効果的ではありません。

**データの追加**には、UIに存在するという利点もあります。

## ドキュメントサイト経由の手動インストレーション [#manual-docs]

この[手動でのJavaインストレーション](/docs/apm/agents/java-agent/installation/install-java-agent)のような手動のインストレーション手順は、最後の手段とする必要があります。ドキュメントサイトのインストレーション手順は、古くなっている可能性が非常に高いです。また、非常にわかりにくい方法で提示されているため、実際にユーザーがNew Relicをインストールする妨げになる可能性があります。ドキュメントの観点からは、これがデフォルトです。なぜなら、そこに私たちのエネルギーと注意が集中しているからです。また、簡単に変更を加えることができる場所でもあります。

普遍的に包括的であるように努めた結果、手動インストレーションのドキュメントは非常に複雑に見えるプロセスを提示しています。ただし、複雑さはオプションの多様性にあります。ユーザーが使用する必要のあるインストレーションプロセスを特定すれば、どのインストレーションプロセスでも手順は非常に簡単です。

## インスタントオブザーバビリティ [#io]

[インスタントオブザーバビリティ](https://newrelic.com/instant-observability)は、New Relicによってモニターできるものや、便利なデフォルトのダッシュボードおよびアラートの公開カタログです。このカタログには、CodeStreamやAtlassian Jiraなど、このモデルに適合しないテクノロジーがいくつかあります。

ほとんどのクイックスタートページでは、**今すぐインストール**ボタンをクリックすると、その特定のテクノロジーで利用可能なものに応じて、ガイド付きインストール、データの追加ページ、または手動インストレーションのドキュメントページに移動します。

## UIのインテグレーションとエージェント [#add-data]

UIでは、[+ インテグレーション &amp; エージェント](https://one.newrelic.com/marketplace?state=7ca7c800-845d-8b31-4677-d21bcc061961)をクリックすると、ユーザーが特定のテクノロジーのオンボーディングプロセスをより直接的に進めることができる、Instantオブザーバビリティカタログのバージョンに移動します。
