title: ツールチップ
translationType: machine

ツールチップにはさまざまなユースケースがありますが、そのすべてにおいて、親しみやすく明確な言語と指示が必要です。

## 基本

* それぞれの状況でユーザーが何を知り、感じ、行う必要があるかを考えてください。
* 会話調の言葉を使用してください。
* アイコン名やアクションなどの1行のツールチップについては、言語を短く具体的にし、句点で終わらないようにしてください。
* 定義などのよりリッチなツールチップの場合は、その要素がユーザーにとって重要である理由を含め、完全な文は句点で終わるようにしてください。
* 可能な場合は、詳細情報へのリンクを含めてください。
