title: ドキュメント作成に役立つ5つの質問
translationType: machine

優れた技術ドキュメントの作成についてTech Docsチームがどのように考えているか、その中核をなすのが5つの質問です。非公式には、これらを5Qと呼んでいます。

誰でもドキュメントサイトに貢献できます。貢献によって価値あるコンテンツと品質が提供されることに、自信と誇りを持っていただきたいと考えています。また、読者がドキュメントの情報を信頼し、簡単に利用できるようにしたいと考えています。優れたドキュメントを計画、執筆、編集するために、このドキュメントの質問を自問してみてください。

## 本当に1Qのみです。 [#one-q]

5Qsは、1つの質問に答えるために存在します。ドキュメントを作成する際は、常に次のように自問してください：

> どのような問題を解決しようとしていますか？

何をしようとしているのか、そしてその目標が読者にとってなぜ重要なのかを理解することが重要です。5つの質問（およびサブの質問！）を自問することで、適切なものを構築していることを確認できます。

## 5つの質問とサブ質問 [#details]

5つの質問にはそれぞれ、思考を導くためのサブ質問が含まれています。

  <Collapser className="freq-link" id="why" title="5. 言葉は誠実で、力を与え、独創的ですか？">
    その情報が**なぜ**重要なのか、そして読者がなぜそれを信頼して使用するのかについて考えてみてください。ユーザーがドキュメントを読み、理解し、使用しやすくするためのヒントについては、[plainlanguage.gov](https://www.plainlanguage.gov/)をご覧ください。

    また、New Relicの社員である場合は、企業ブランドのガイドラインを確認することをお勧めします。詳細については、マーケティングにお問い合わせください。

            * 文書は[Flesch-Kinkaidの読みやすさの評価](https://en.wikipedia.org/wiki/Flesch%E2%80%93Kincaid_readability_tests)で40以上のスコアを獲得していますか？

              そうでない場合は、文章をもう一度見直してみてください。ただし、Flesch-Kincaidスコア自体を追求しないでください：私たちの目的は自分たちを挫折させることではなく、読んで楽しいドキュメントを書くことです。
          </td>
        </tr>
