これら3つの要素は、当社のビジネスを推進する中核を形成しています。顧客はシステムのパフォーマンスをゲージするために数値データに依存しており、日付と時間はその情報に不可欠なコンテキストを提供します。

## 基本

* 文中のどこに表示されるかにかかわらず、数字はアラビア数字で記述します。
* 4桁以上の数字にはカンマを使用します。
* 絶対的な数値の正確さよりも、顧客に数値の感覚を伝えることの方が重要な場合は、1k（1,012の場合）や324.5 million（324,501,082の場合）のように丸めても構いません。これについては、ご自身の判断で適切に対応してください。
* 整数を小数点と末尾のゼロを付けて記述しないでください。

| 実行                | してはいけないこと         |
| ----------------- | ----------------- |
| 1,024 KB          | 1024 KB           |
| 上位5つのトランザクショントレース | 上位5つのトランザクショントレース |
| 2秒                | 2.0秒              |

## 大きな数値

UIには一般的なアメリカ英語を使用していますが、これにより大きな数字でいくつかの課題が生じます。1,000（thousand）の国際的およびアメリカ英語の規則は同じです：小文字のk。しかし、million（100万）、billion（10億）、trillion（1兆）は、地域や業界によって略語が異なるため、より複雑です。このため、最も一般的なカウントであるthousand（1,000）のみを省略します。

* 1,000は小文字のkで省略し、最後の数字と文字の間にスペースを入れます：50 k。
* 大きな数値を扱う場合は、スペースを使用し、million、billion、trillionなどを小文字でつづります。スペースが狭すぎて省略する必要がある場合は、B、M、Tを使用しますが、画面やチャートの他の場所に完全なつづりを提供し、ホバー時に完全な数値を提供する場合に限ります。
* 可能な場合は、ホバー時に完全な数値を指定してください。

| UIでは         | ホバー時（可能な場合）        | してはいけないこと    |
| ------------ | ------------------ | ------------ |
| 50.2 k       | 50,200             | 50.2k        |
| 5,020万       | 50,200,000         | 50.2m、50.2M  |
| 50.2 billion | 50,200,000,000     | 50.2G、50.2B  |
| 50.2兆        | 50,200,000,000,000 | 50.2T、50.2 t |

## 日付と時刻

ブラウザーごとに、[標準フォーマッター](https://unicode-org.github.io/icu/userguide/format_parse/datetime/)の自動的な日付と時刻のフォーマットを使用します。製品でこれらの値をコーディングする場合は、社内のデザインシステムを参照してください。正しいフォーマットを取り込むには、usedateおよびusetimeフックを使用してください。

注: 標準フォーマッターからの唯一の偏差は、24時間表記オプション（正確かつ長い）です。12:30 AMの場合、24:30の代わりに00:30を使用します。

| useDateオプション | サンプル出力          |
| ------------ | --------------- |
| 基本（デフォルト）    | 2022年2月24日      |
| 短い           | 2022 年 2 月 24 日 |

| useTimeオプション | サンプル出力              |
| ------------ | ------------------- |
| ベーシック        | 12:16 AM            |
| Day          | 2月24日 0:16          |
| 短い日          | 2月24日 12:16 AM      |
| 正確性          | 00:16:36.969        |
| ロング          | 00:16:36            |
| （近日公開）       | 2022年2月24日 12:16 AM |
| （近日公開）       | 2022/02/24 0:16     |

## 時間単位の省略

可能な限り、すべての単位をスペルアウトしてください。

スペースが限られている場合は、以下の標準的な略語を使用してください：

| ユニット | 優先   | 略語（必要な場合） |
| ---- | ---- | --------- |
| ミリ秒  | 4ミリ秒 | 4 ms      |
| 秒    | 5秒   | 5 s       |
| 分    | 6分   | 6 min     |
| 時間   | 7時間  | 7時間       |
| 日数   | 8日   | 8 日       |
| 週数   | 9週間  | 9週間       |
| 月    | 10ヶ月 | 10 mo     |
| 年    | 11年  | 11年       |

## 小数と分数

* 小数値は10進数形式で記述します。
* 小数点以下2桁に丸めてください。
* 1未満の小数には先頭に0を含めます。

| 実行      | してはいけないこと |
| ------- | --------- |
| 0.92 ms | 0.92 ms   |
| 16.23 s | 16.2822 s |

## 金額

* ドルの整数の場合、末尾の小数と0を省略してください。
* スペースを入れずに、ドル金額の前に適切な通貨記号を配置します。
* 価格に通貨を含める場合、通貨は最後に配置し、ドル金額との間にスペースを入れます。

| 実行          | してはいけないこと   |
| ----------- | ----------- |
| $ 32        | $ 32.00     |
| $ 32.75     | ---         |
| $ 14.99 USD | USD $ 14.99 |

## パーセンテージ

* 数字と記号の間にスペースを入れずに％記号を使用します。
* 小数形式の小数値の場合は、常に先頭にゼロを含めてください。

**例外** - 外形監視データのようにピンポイントの精度が必要な場合は、パーセンテージで小数点以下3桁まで使用できます。

| 実行               | してはいけないこと |
| ---------------- | --------- |
| 25％              | 25％       |
| 0.3％             | 0.3％      |
| **（例外）** 62.356％ | ---       |

## 電話番号

数字はハイフンでのみ区切ってください。

| 実行             | してはいけないこと      |
| -------------- | -------------- |
| 1-409-385-0225 | 1(409)385-0225 |
| 866-225-5262   | (866) 225-5262 |
| +33-673-668    | +33 673-668    |
