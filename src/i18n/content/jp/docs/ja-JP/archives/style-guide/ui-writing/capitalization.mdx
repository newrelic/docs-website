大文字の使用は、特定の単語の重要性を伝えるのに役立ち、意味の変化を示すために使用できます。これを効果的に保つには、大文字にする対象を制限する必要があります。

## 基本

* 2023年2月現在、3種類のUIコンテンツにはタイトルケースを使用します：

  * ページタイトル
  * 左側のナビゲーション（メインナビゲーション）
  * All Capabilitiesページのタイルのタイトル

* その他の場合は、センテンスケースを使用してください。

* 固有名詞（製品名、国名、頭字語、人名）の最初の文字は、文中のどこに表示されるかに関係なく大文字にします。

* [製品と機能：大文字、商標、および使用方法](/docs/style-guide/capitalization/product-capability-feature-usage)のページで説明されているように、製品名は大文字にします。

* 文の先頭にある場合を除き、冠詞（a、an、the）や前置詞（of、on、for、in、to、withなど）を大文字にしないでください。

| 実行                  | してはいけないこと              |
| ------------------- | ---------------------- |
| 上位5つのトランザクショントレース   | 上位5つのトランザクショントレース      |
| New Relicは固有名詞です。   | New Relicは固有名詞です。      |
| 新しいダッシュボードをお試しください。 | 新しいDashboardsをお試しください。 |
| 自由の女神像              | 自由の女神                  |

## 場所ごとの大文字の使用

| コピーの種類                   | 例                                            |
| ------------------------ | -------------------------------------------- |
| 左側のナビゲーション、ページタイトル、機能タイル | エラーインボックス                                    |
| 小見出し、本文など                | Errors Inboxを使用して、すべてのエラーを1か所で調査およびトリアージします。 |
| ボタン、リンクなど。               | Errors Inboxの探索                              |

## タイトルケース

| コピーの種類            | 例                                     |
| ----------------- | ------------------------------------- |
| ナビゲーションまたはページタイトル | Errors Inbox、メトリクス &amp; イベント、サービスレベル |
| 任意の場所の固有名詞        | Amazon CloudWatchログをNew Relicに送信します。  |

## センテンスケース

| コピーの種類     | 例                           |
| ---------- | --------------------------- |
| データのビット数   | Kb、Mb、Gb                    |
| 小見出しとチャート名 | 最も遅い5つのトランザクション             |
| ボタン        | ダッシュボードの作成                  |
| 説明と本文      | 新しいErrors Inboxはお試しになりましたか？ |

## 小文字

| コピーの種類    | 例            |
| --------- | ------------ |
| 1ビットのデータ  | 1 b          |
| ファイル拡張子   | json、gif、pdf |
| 経時的なメトリクス | rpm、ppm      |

## 大文字

| コピーの種類         | 例                                                                                                      |
| -------------- | ------------------------------------------------------------------------------------------------------ |
| データのバイト数       | B、KB、MB                                                                                                |
| 999を超える省略された数値 | 1 k、1 M、1 B                                                                                            |
| 頭字語            | API、CDN、HTTP                                                                                           |
| タイムゾーン         | PDT、CST、BCN                                                                                            |
| 期間             | [AMまたはPM](https://docs.newrelic.com/docs/style-guide/ui-writing/numbers-dates-and-times#date-and-time) |

## 測定単位

メモリ、帯域幅、およびドライブスペースの略語には、大文字化に関するさまざまなルールがあります。

* 値と測定単位の間には常にスペースを含めてください。
* 1ビットのデータは小文字（b）ですが、1,204ビット以上の場合はセンテンスケース（13 Kb）になります。
* バイトは常に大文字です（13 KB、512 MB）。

重量と距離は小文字で、略語の後にピリオドは付けません（ft、lbs、km）。

| 実行      | してはいけないこと |
| ------- | --------- |
| 32 Kb/s | 32 kb/s   |
| 16 s    | 16s       |
| 0.43 MB | 0.43 MB   |
| 15 ft   | 15 ft.    |
