## 基本

* 測定単位とその値は、半角スペース1つで区切ります。
* 時間の経過に伴う測定の場合は、測定単位と時間単位の間にスラッシュを挿入します。

| 測定単位           | 実行        | してはいけないこと |
| -------------- | --------- | --------- |
| 1分あたりのrequests | 29.5K rpm | 29.5Krpm  |
| 1秒あたりのrequests | 14 rps    | 14rps     |
| 1分あたりのページ数     | 6.33 ppm  | 6.33ppm   |
| 1秒あたりのキロバイト数   | 16 KB/s   | 16 KB s   |
