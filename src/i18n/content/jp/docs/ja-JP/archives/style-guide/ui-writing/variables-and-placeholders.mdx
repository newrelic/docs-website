## 変数

計算値やクエリの結果を読みやすい文に挿入する必要がある場合は、変数を使用します。これらをフィルイン、置換、代入、またはその他の用語で呼ぶ場合でも、ガイダンスは同じです。

### 変数とは何ですか？以下の太字の項目です。

| コード内                                                               | UIでは                                     |
| ------------------------------------------------------------------ | ---------------------------------------- |
| **\[service name]**で異常な動作を検出しました。                                  | **RPM-UI-production**で異常な動作が検出されました。     |
| クラッシュの**\[% of crashes]**は、OS**\[operating system type]**を共有しています。 | クラッシュの**80％**は、OS**iOS 11.1.2**を共有しています。 |

### 基本

挿入される値が短い場合は、文が自然に聞こえるように、文中の最も論理的な場所に配置します。値が長い場合、読みにくい場合、またはその他の理由で制御できない場合は、文の最後に配置します。変数が任意の品詞になる可能性がある場合、または単数形になったり複数形になったりする場合は、コロンで区切るか、別の行に配置します。

| 実行                                                                          | してはいけないこと                                                          |
| --------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| レガシーシステムである**bob-long-name-32-october-service-legacy-system**で異常な動作を検出しました。 | サービス**bob-long-name-32-october-service-legacy-system**に異常な動作があります。 |
| クラッシュの**80％**は、ユーザー名**pdiddybigdog**を共有しています。                               | クラッシュの**80％**は、**pdiddybigdog**というユーザー名を共有しています。                   |
| 複数のエラーがあるサービス：**1**                                                         | **1**つのサービスに複数のエラーがあります。                                           |

## プレースホルダーテキスト

入力フィールドのプレースホルダーテキストには、「例：...」を使用します。また、ドキュメントなどでインラインで例を追加する場合は、「〜など」を使用します。たとえば、「Xを閉じるにはアクションが必要です（ユーザーがダッシュボードを削除したいことを確認するなど）。」とします。
