ドキュメントチームは、New Relicデータベースのデフォルトのデータ型（たとえば、トランザクション、メトリクス、ログ）およびそれらに関連する属性に関するメタデータ情報を格納するデータディクショナリを管理しています。このメタデータは、当社の属性ディクショナリサービスによって2つの場所で公開されます：

* New Relic UIのクエリエクスペリエンスでは、データ型や属性にカーソルを合わせるとこの情報が表示されます。
* データは、ドキュメントサイトの[属性ディクショナリ](https://docs.newrelic.com/attribute-dictionary/)に表示されます。

<Callout variant="tip">
  データの範囲に関するいくつかの制限事項を以下に示します：

  * 現在、属性ディクショナリにあるインフラストラクチャ関連の情報はKubernetesに関するもののみです。
  * 一部のデータ型には多くの潜在的な属性を付加できるにもかかわらず、メトリクスデータ型の属性は非常に少なく — 基本的なデフォルトの属性がいくつかあるだけです。
</Callout>

New Relicのライターで、データ辞書に変更を加える必要がある場合は、GitHub Enterpriseのプライベートリポジトリで変更を行います。リポジトリのセットアップ方法とREADME.mdの手順の場所については、社内のGoogleドキュメントのチームドライブをご覧ください。
