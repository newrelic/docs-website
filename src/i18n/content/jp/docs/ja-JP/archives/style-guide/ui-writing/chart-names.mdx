New Relic Oneでは、ユーザーが独自のチャートを作成して名前を付けることができますが、当社が提供する厳選されたチャートもいくつかあります。ユーザーが何を見ているのか分かるように、これらのチャートの名前は明確で分かりやすいものである必要があります。

## 基本

* 明確なキーワードを使用してください。
* チャートの目的を説明するのに十分な情報を提供してください；1語の名前は避けてください。
* 一貫性よりも正確さを目指してください。一部のチャートには完璧でも他のチャートには不正確な命名規則に従うよりも、類似したチャートには少し異なる名前を付けることをお勧めします。
* 名前はセンテンスケースにしてください。
