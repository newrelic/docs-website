translationType: machine

メッセージの感情的な意図を明確にするには優れているかもしれませんが、すべての顧客に対して一貫したメッセージングを確保したいと考えています。ここで指定されている場合、またはアイコンのルールで指定されている場合を除き、UIテキストでの絵文字の使用は避けてください。

## 基本

UIテキストでの絵文字の使用は避けてください。作成したテキスト（エラーメッセージなど）に肯定的な印象を与えるために絵文字を使用したい場合は、声とトーンに関するルールを参照し、目的を達成するまでメッセージを書き直してください。

## メール

メールで顧客とコミュニケーションをとる際は、顧客が先に使用した場合や、すでに顧客との関係が確立されている場合を除き、絵文字の使用は避けてください。

## アプリ内メッセージング

Intercom.ioのようなアプリ内サービスを通じて顧客に連絡する場合、適切であると判断した場合は、メッセージにシンプルなスマイリーフェイスを追加しても問題ありません。
