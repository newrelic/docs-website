NerdGraph APIを使用して、ユーザーの名前、ユーザーID、ユーザータイプ、メールアドレス、および最終アクティブ日をクエリできるようになりました。ユーザーのユーザータイプとメールアドレスを更新することもできます。

詳細については、[NerdGraphドキュメント](/docs/apis/nerdgraph/examples/nerdgraph-manage-users)を参照してください。
