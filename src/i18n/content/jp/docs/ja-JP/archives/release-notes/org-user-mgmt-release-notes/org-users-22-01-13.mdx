**User management** \[ユーザー管理]UIからユーザーデータをエクスポートする機能をリリースしました。データはTSV形式でエクスポート可能です。エクスポート可能な列には、ユーザー名、メールアドレス、現在のユーザータイプ、グループ、およびユーザーIDが含まれます。管理者は、すべてのユーザーをエクスポートするか、ユーザーのサブセットを選択するかを選択できます。

詳細については、[ユーザーリストのエクスポート](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-ui-and-tasks)を参照してください。
