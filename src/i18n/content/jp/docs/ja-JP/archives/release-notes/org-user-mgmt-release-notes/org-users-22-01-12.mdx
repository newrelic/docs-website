## コアユーザーを含むNew Relic Oneの価格設定モデルの新しいバージョン

新しい[ ユーザータイプ](/docs/accounts/accounts-billing/new-relic-one-user-management/user-type) であるコアユーザーを含む、[ New Relic Oneの価格設定モデル](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/new-relic-one-pricing-billing) の新しいバージョンをリリースしました。この価格設定バージョンの組織は、基本ユーザー、コアユーザー、フルプラットフォームユーザーの3種類のユーザータイプを利用できます。コアユーザーは基本ユーザーよりも多くのアクセス権を持ち、フルプラットフォームユーザーよりも低コストです。コアユーザーは、New Relic CodeStream、ログUI、New Relicアプリを構築する機能など、開発者を重視した強力な機能の一部にアクセスできます。

この価格設定バージョンでは、[請求対象ユーザーの計算方法も異なり](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/user-count-billing#user-count)、[異なるユーザードウングレードルール](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/user-count-billing/#user-downgrade-rules)が適用されます。

このリリースと可用性の詳細については、[コアユーザーリリース](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/core-users-release)を参照してください。
