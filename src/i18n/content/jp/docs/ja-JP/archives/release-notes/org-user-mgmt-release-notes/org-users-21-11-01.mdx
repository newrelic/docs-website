## プロエディションで自動ユーザー管理が利用可能になりました

New Relicの[自動ユーザー管理](/docs/accounts/accounts/automated-user-management/automated-user-provisioning-single-sign)機能は、New Relicの[プロエディション](https://newrelic.com/pricing)をご利用の組織で利用できるようになりました。以前は、これはエンタープライズエディションをご利用の組織でのみ利用可能でした。

自動ユーザー管理では、SCIMプロビジョニングを使用して、Azure AD、Okta、OneLoginなどのIDプロバイダーからNew Relicユーザーをインポート、更新、および非アクティブ化できます。また、IDプロバイダーを介して、ユーザータイプやタイムゾーンなど、ユーザーに関する属性を管理することもできます。
