[自動化されたユーザー管理](/docs/accounts/accounts/automated-user-management/automated-user-provisioning-single-sign)を通じて管理されているNew Relic Oneプラットフォームのユーザーは、以前はIDプロバイダー（IdP）を介してのみタイムゾーンを設定できました。

これで、すべてのユーザーがNew Relic Oneで更新することにより、これらのタイムゾーン設定を上書きできるようになります。これは、タイムゾーン設定をNew Relicに送信できないIdPを使用している顧客にとって特に便利です。

これを行うには、ユーザー設定にアクセスしてタイムゾーンを更新するだけです。新しい設定は自動的に保存され、IDプロバイダー経由で送信される内容を上書きします。

詳細については、[タイムゾーン設定のドキュメント](/docs/accounts/accounts-billing/general-account-settings/default-time-zone-setting)を参照してください。
