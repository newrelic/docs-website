### 新機能

* **リアルタイムストリーミングのサポート**

  * イベントデータは、毎分ではなく5秒ごとにNew Relicに送信されるようになりました。その結果、トランザクション、エラー、およびカスタムイベントは、ほぼリアルタイムでNew Relicダッシュボードで利用できるようになります。5秒ごとの更新でイベントを表示する方法の詳細については、[リアルタイムストリーミングのドキュメント](/docs/agents/manage-apm-agents/agent-data/real-time-streaming)をご覧ください。
  * 1分間に送信できるイベント数の全体的な制限に変更はないことにご注意ください。また、スパンイベント、メトリクス、およびトレースデータは影響を受けず、引き続き毎分送信されます。

### バグ修正

* `newrelic_create_app_config()`で作成されたデフォルトの設定は、米国以外のアカウントのライセンスキーで期待どおりに機能するようになりました。

* `pr`（優先度）および/または`sa`（サンプリング済み）の値が無効または欠落しているインバウンドのディストリビューティッド（分散）トレーシングのペイロードに対して、エージェントは以前、トランザクションにデフォルトの優先度-1および/またはデフォルトのサンプリング済み値`false`を割り当てていました。

  これは修正されました：インバウンドのディストリビューティッド（分散）トレーシングのペイロードでそれぞれの値が欠落しているか無効である場合、エージェントは初期の優先度とサンプリングされた値を保持するようになりました。
