### 新機能

* **ディストリビューティッド（分散）トレーシングのサポート**

  ディストリビューティッド（分散）トレーシングでは、リクエストが分散システムを経由するパスを見ることができます。分散されたアクティビティを統合されたビューで表示することで、複雑なシステムのトラブルシューティングと理解をこれまで以上に深めることができます。

  ディストリビューティッド（分散）トレーシングは、APM Proまたは同等のサブスクリプションで利用可能です。完全なディストリビューティッド（分散）トレーシングを表示するには、隣接する一連のサービスで機能を有効にする必要があります。

  C SDKのディストリビューティッド（分散）トレーシングを有効にする方法の詳細については、New Relicの[『C SDKドキュメント』](https://docs.newrelic.com/docs/agents/c-sdk/instrumentation/enable-distributed-tracing-your-c-applications)を参照してください。

### 販売終了のお知らせ

* `newrelic_app_config_t`の`log_filename`および`log_level`フィールドは現在非推奨です。C SDKの将来のバージョンでは、これらのフィールドは完全に削除されます。C SDKで使用するログファイルとログレベルを指定するには、`newrelic_configure_log()`を使用します。
