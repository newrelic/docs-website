New Relicへのユーザーのアクセス管理がさらに簡単になりました。[**アクセス管理**UIページ](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-ui-and-tasks#where)を強化し、よりグループに焦点を当てたものにしました。これにより、グループがアクセスできるロールとアカウントをより迅速に把握し、グループを作成し、グループのアクセス権を編集できるようになりました。

上位レベルの管理機能の管理方法も簡素化しました。以前は、これらの機能に対して組織スコープの個別のロールを用意していました。現在は、組織レベルの管理設定（請求、組織設定、認証ドメイン設定など）を、**グループ**UIページからグループに簡単に割り当てることができます。

詳細について：

* **アクセス管理**UIページを参照してください。
* [グループアクセスの割り当て方法をご覧ください](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial#group-access)
* [管理設定についてお読みください](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts#admin-settings)
