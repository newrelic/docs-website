このリリースでは、コアユーザーのアップグレードに対する追加のガバナンス設定が提供されます。アドミニストレーターは以下を制御できるようになりました：

* 基本ユーザーが自動的にコアにアップグレードできるか、またはアップグレードに管理者の承認が必要かどうか
* コアユーザーが自動的にフルプラットフォームユーザーにアップグレードできるか、またはアップグレードに管理者の承認が必要かどうか

詳細については、[ユーザーのアップグレードに関するドキュメント](/docs/accounts/accounts-billing/new-relic-one-user-management/authentication-domains-saml-sso-scim-more/#user-upgrade)を参照してください。
