### 新機能

これはNew Relic C SDKの最初のリリースです！アプリケーションが[他のNew Relic APMエージェント言語](https://docs.newrelic.com/docs/agents/manage-apm-agents/installation/compatibility-requirements-new-relic-agents-products#apm-compatibility)を使用していない場合、C SDKを使用してNew Relicの監視機能と機能を活用し、幅広いアプリケーションを計装できます。

詳細については、以下を参照してください。

* [ドキュメント](/docs/agents/c-sdk): C SDKの開始方法、インストールと設定、トランザクション、セグメント、エラーの計装、C SDK APIの使用方法、および基本的なトラブルシューティングについて説明します。
* [GitHub](https://newrelic.github.io/c-sdk/index.html): SDKファイル、データ構造、フィールド定義とパラメーター、コード例、関数、変数。

### 販売終了のお知らせ

以前のAPMエージェントSDKは、非推奨のベータ版ソフトウェアです。以前にエージェントSDKを使用していた場合は、C SDKに切り替えることができます。[互換性と要件](/docs/c-sdk-compatibility-requirements)を確認してから、C SDKを使用するようにアプリケーションのコードを[計装、コンパイル、およびリンク](/docs/install-c-sdk-compile-link-your-code)します。C SDKは現在、New RelicのHSM機能をサポートしていません；これは、エージェントSDKからの移行スケジュールに影響を与える可能性があります。
