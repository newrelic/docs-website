Instale o agente Node.js da New Relic para iniciar o monitoramento do seu aplicativo Node.js. Escolha o método que corresponde ao seu ambiente na navegação à esquerda.

Você precisa de uma [conta da New Relic](https://newrelic.com/signup) e do seu <InlinePopover type="licenseKey" />para concluir a instalação. Consulte a [Compatibilidade e requisitos do agente Node.js](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent) antes de começar.

| Método                                                                                                                                         | Usar quando                                                                                      |
| ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| [Padrão (npm)](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent)                                                  | A maioria dos aplicativos Node.js — instale via npm, carregue com `-r newrelic`                  |
| [Docker](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent-docker)                                                 | Aplicativos Node.js conteinerizados                                                              |
| [Serviço de Aplicativo do Azure (Windows)](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent-azure-site-extension) | Aplicativos implantados no Azure App Service para Windows usando a extensão de site do New Relic |
