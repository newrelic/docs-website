Instale o agente Node.js do New Relic no Azure App Service para Windows usando a New Relic Azure Site Extension.

<Callout variant="important">
Este método é apenas para aplicativos do Azure App Service **baseados em Windows** implantados como código. Para contêineres Linux no Azure, use o [método de instalação npm](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent) padrão e passe `NEW_RELIC_LICENSE_KEY` como uma configuração de aplicativo. Para um aplicativo baseado em Linux implantado manualmente, consulte [Agente Node.js no Microsoft Azure App Services](/docs/apm/agents/nodejs-agent/hosting-services/nodejs-agent-microsoft-azure).

Para aplicativos em execução no Windows 32, o suporte completo a métricas de nível do código (caminho do arquivo, linha, coluna) não está disponível — o profiling reverte apenas para o nome da função.
</Callout>

<Steps>
<Step>
## Instale a extensão do site [#install]

1. Na página inicial do Azure, clique em **App Services** e selecione seu aplicativo de destino.
2. No menu à esquerda em **Development Tools**, selecione **Extensions**.
3. Clique em **+ Add** na parte superior da página e, em seguida, selecione **New Relic Node Agent** no dropdown.
4. Aceite os termos legais e clique em **OK**.

Após a instalação, a extensão cria:

* Arquivos e dependências do agente em `C:\home\site\wwwroot\node_modules`
* Uma transformação XDT (`applicationHost.xdt`) que injeta `NODE_OPTIONS=-r newrelic` automaticamente na inicialização do aplicativo
</Step>

<Step>
## Configurar o agente [#configure]

No menu à esquerda do seu aplicativo, acesse **Settings &gt; Environment variables** e adicione:

| Contexto                | Valor                             |
| ----------------------- | --------------------------------- |
| `NEW_RELIC_LICENSE_KEY` | Sua chave de licença New Relic    |
| `NEW_RELIC_APP_NAME`    | O nome que aparecerá no New Relic |

A extensão define automaticamente `NODE_OPTIONS` como `-r newrelic`. Qualquer `NODE_OPTIONS` definido anteriormente será redefinido. Para todas as outras opções de configuração, consulte a [configuração do agente Node.js](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration).
</Step>

<Step>
## Verifique se os dados estão fluindo [#verify]

Inicie seu aplicativo e envie pelo menos dois requests. Aguarde 2–3 minutos e abra [one.newrelic.com &gt; APM](https://one.newrelic.com/apm) para procurar seu aplicativo pelo nome.

Se a extensão não for instalada, verifique o log em:

```
C:\home\SiteExtensions\NewRelic.Azure.Websites.Extension.NodeAgent\install.log
```

Se o agente estiver instalado, mas os dados não aparecerem, verifique:

```
C:\home\site\wwwroot\newrelic_agent.log
```

<Callout variant="tip">
O aplicativo não aparece? Consulte [Resolução de problemas da sua instalação do Node.js](/docs/apm/agents/nodejs-agent/troubleshooting/troubleshooting-your-nodejs-installation).
</Callout>
</Step>
</Steps>
