<Steps>
<Step>
## Adicione o agente ao seu aplicativo [#install]

Adicione `newrelic` ao seu `package.json`:

```json
"newrelic": "latest"
```

Em seguida, atualize seu Dockerfile ou comando de inicialização para carregar o agente. A forma de fazer isso depende se o seu aplicativo usa CommonJS ou ESM:

<CollapserGroup>
<Collapser id="docker-cjs" title="App usando CommonJS">
* `ENTRYPOINT`

  ```bash
  ENTRYPOINT ["node", "-r", "newrelic", "YOUR_PROGRAM.js"]
  ```

* `CMD`

  ```bash
  CMD ["node", "-r", "newrelic", "YOUR_PROGRAM.js"]
  ```

* script npm como `npm start`

  ```bash
  npm pkg set scripts.start="node -r newrelic your-program.js"
  ```
</Collapser>

<Collapser id="docker-esm" title="App usando ESM">
* `ENTRYPOINT`

  ```bash
  ENTRYPOINT ["node", "--import", "newrelic/esm-loader.mjs", "-r", "newrelic", "YOUR_PROGRAM.js"]
  ```

* `CMD`

  ```bash
  CMD ["node", "--import", "newrelic/esm-loader.mjs", "-r", "newrelic", "YOUR_PROGRAM.js"]
  ```

* script npm como `npm start`

  ```bash
  npm pkg set scripts.start="node --import newrelic/esm-loader.mjs -r newrelic your-program.js"
  ```
</Collapser>
</CollapserGroup>

<Callout variant="important">
Se você não puder usar a flag `-r`, adicione `require('newrelic')` como a **primeira linha** do módulo principal do seu aplicativo. Não use essa abordagem com o Babel ou outros transpiladores — isso causará problemas de instrumentação.
</Callout>
</Step>

<Step>
## Configurar o agente [#configure]

Passe o nome do seu aplicativo e a chave de licença como variáveis de ambiente ao executar o contêiner. Estas são as únicas configurações obrigatórias:

```bash
docker run -e NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
           -e NEW_RELIC_APP_NAME="Your Application Name" \
           YOUR_IMAGE_NAME:latest
```

Você também pode definir a configuração por meio de diretivas `ENV` no seu Dockerfile:

```dockerfile
ENV NEW_RELIC_APP_NAME="Your Application Name"
```

Para todas as outras opções de configuração, consulte a [configuração do agente Node.js](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration).
</Step>

<Step>
## Verifique se os dados estão fluindo [#verify]

Crie e execute seu contêiner, depois envie pelo menos dois requests para o seu aplicativo. Aguarde 2–3 minutos e abra [one.newrelic.com &gt; APM](https://one.newrelic.com/apm) para procurar seu aplicativo pelo nome.

<Callout variant="tip">
O aplicativo não aparece? Consulte [Resolução de problemas da sua instalação do Node.js](/docs/apm/agents/nodejs-agent/troubleshooting/troubleshooting-your-nodejs-installation).
</Callout>
</Step>
</Steps>
