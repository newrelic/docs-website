Esta página aborda as configurações do agente Node.js para o AI Monitoring, incluindo telemetria de LLM, streaming e gravação de conteúdo.

Voltar para o índice completo de configurações: [Configuração do agente Node.js](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration)

## AI Monitoring [#ai-monitoring]

A instrumentação de LLM está habilitada por padrão. O agente envia `Llm*` eventos personalizados, spans e métricas sem o conteúdo da mensagem.

Para desativar, defina qualquer um dos seguintes como `false`:

* `ai_monitoring.basic_telemetry.enabled` em `newrelic.js`
* `NEW_RELIC_AI_MONITORING_BASIC_TELEMETRY_ENABLED` variável de ambiente
* `ai_monitoring.enabled` em `newrelic.js` (descontinuado, mas ainda funciona)
* `NEW_RELIC_AI_MONITORING_ENABLED` variável de ambiente (descontinuada, mas ainda funciona)

<Callout variant="important">
Você deve habilitar [distributed tracing](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration/#dt-main) para capturar dados de IA. Ele está ativado por padrão no agente Node.js 8.3.0 e superior. Se você ativou o modo de alta segurança, AI Monitoring não funcionará.
</Callout>

<Callout variant="important">
Quando ativado, AI Monitoring registrará uma cópia de streaming das entradas e saídas enviadas de e para os modelos que você escolher monitorar, incluindo quaisquer informações pessoais contidas neles. Ao usar AI Monitoring, você é responsável por obter o consentimento do seu usuário modelo para que sua interação possa ser gravada por um terceiro (New Relic) com a finalidade de fornecer o recurso AI Monitoring .
</Callout>
