<Steps>
<Step>
## Instale o agente [#install]

Instale o pacote do agente no diretório do seu aplicativo:

```bash
npm install newrelic
```

<Callout variant="important">
Se você usa o Next.js, consulte o [guia de instrumentação de agente híbrido do Next.js](/docs/apm/agents/nodejs-agent/extend-your-instrumentation/nextjs-instrumentation/).
</Callout>

Em seguida, copie o arquivo de configuração padrão do pacote para a raiz do seu aplicativo:

```bash
cp node_modules/newrelic/newrelic.js .
```
</Step>

<Step>
## Configurar o agente [#configure]

Abra `newrelic.js` na raiz do seu aplicativo. As duas únicas configurações que você **deve** alterar antes de entrar em produção:

1. Defina `license_key` como seu <InlinePopover type="licenseKey" />.
2. Defina `app_name` como um nome significativo para seu aplicativo.

```js
exports.config = {
  app_name: ['Your Application Name'],
  license_key: 'YOUR_LICENSE_KEY',
  // ...
}
```

Você também pode defini-las por meio de variáveis de ambiente em vez de editar o arquivo:

```bash
NEW_RELIC_APP_NAME="Your Application Name"
NEW_RELIC_LICENSE_KEY="YOUR_LICENSE_KEY"
```
</Step>

<Step>
## Iniciar o agente [#start]

Carregue o agente antes de quaisquer outras instruções `require` adicionando `-r newrelic` ao seu comando de inicialização:

```bash
node -r newrelic ./your-app.js
```

Se o seu aplicativo usar ESM, adicione a opção `--import newrelic/esm-loader.mjs`:

```bash
node --import newrelic/esm-loader.mjs -r newrelic ./your-app.js
```

Para um aplicativo Next.js, carregue nosso agente via `NODE_OPTIONS='-r newrelic' next start`.

Se você estiver usando o Nest.js e o comando `nest start` para iniciar o aplicativo, modifique o binário de inicialização para carregar o agente New Relic: `nest start --exec 'node -r newrelic'`. [Aqui está um exemplo de aplicativo Nest.js](https://github.com/newrelic/newrelic-node-examples/tree/main/nestjs).
</Step>

<Step>
## Verifique se os dados estão fluindo [#verify]

Se a versão do seu agente for 14.9.0 ou superior, você pode executar este comando para validar sua configuração:

```bash
npx newrelic validate-config --config-file ./newrelic.js
```

1. Envie pelo menos dois requests para o seu aplicativo.

2. Aguarde 2–3 minutos, depois abra [one.newrelic.com &gt; APM](https://one.newrelic.com/apm) e procure seu aplicativo pelo nome.

<Callout variant="tip">
O aplicativo não aparece? Consulte [Resolução de problemas da sua instalação do Node.js](/docs/apm/agents/nodejs-agent/troubleshooting/troubleshooting-your-nodejs-installation).
</Callout>
</Step>
</Steps>
