[Os middlewares de rack](/docs/agents/ruby-agent/frameworks/rack-middlewares) são automaticamente instrumentados com o agente Ruby versão 3.9.0 ou superior.

O módulo `NewRelic::Agent::Instrumentation::Rack` foi removido na versão 4.0.0 do agente Ruby. Remova quaisquer referências a este módulo do seu código. Para mais informações, consulte [Controladores Metal instrumentados](/docs/agents/ruby-agent/frameworks/instrumenting-metal-controllers).
