<Steps>
<Step>
## Instalar a gem e configurar seu aplicativo [#install]

Adicione a gem `newrelic_rpm` ao seu `Gemfile`:

```ruby
gem 'newrelic_rpm'
```

Em seguida, execute:

```sh
bundle install
```

<Tabs>
<TabsBar>
<TabsBarItem id="native-mode">Modo nativo (Rails ou Sinatra)</TabsBarItem> <TabsBarItem id="docker-runtime">Runtime Docker personalizado</TabsBarItem>
</TabsBar>

<TabsPages>
<TabsPageItem id="native-mode">
Ao usar o modo nativo do GAE, você fornece o código do seu aplicativo e um `app.yaml`. O GAE implanta automaticamente em uma imagem Docker padrão pré-construída. Nenhum Dockerfile adicional é necessário.
</TabsPageItem>

<TabsPageItem id="docker-runtime">
Se o seu aplicativo precisar de bibliotecas ou cabeçalhos específicos, use um ambiente de execução personalizado. Crie um `Dockerfile` e defina `app.yaml` como:

```yaml
runtime: custom
env: flex
```

A New Relic recomenda o método de tempo de execução personalizado. Também recomenda que você permita que o Google App Engine gerencie as verificações de integridade.
</TabsPageItem>
</TabsPages>
</Tabs>
</Step>

<Step>
## Configurar o agente [#configure]

Faça o download de [`newrelic.yml`](https://github.com/newrelic/newrelic-ruby-agent/blob/dev/newrelic.yml) do repositório da New Relic no GitHub e copie-o para o diretório `config` do seu aplicativo.

Defina os dois valores obrigatórios:

1. Defina `license_key` como seu <InlinePopover type="licenseKey" />.
2. Defina `app_name` como um nome significativo para seu aplicativo.

Para todas as outras opções de configuração, consulte a [configuração do agente Ruby](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration).
</Step>

<Step>
## Implantar e verificar [#verify]

Implante seu aplicativo usando a CLI `gcloud`:

```bash
gcloud app deploy
```

Aguarde até que a implantação seja concluída. Envie pelo menos dois requests, depois aguarde 2–3 minutos e abra [one.newrelic.com &gt; APM](https://one.newrelic.com/apm) para procurar seu aplicativo pelo nome.

<Callout variant="tip">
O aplicativo não aparece? Consulte [Nenhum dado aparece (Ruby)](/docs/apm/agents/ruby-agent/troubleshooting/no-data-appears-ruby).
</Callout>
</Step>
</Steps>
