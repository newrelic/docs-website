<Steps>
<Step>
## Instale o complemento New Relic [#install]

<Tabs>
<TabsBar>
<TabsBarItem id="heroku-website">Site do Heroku</TabsBarItem> <TabsBarItem id="heroku-toolbelt">Cinto de ferramentas Heroku</TabsBarItem>
</TabsBar>

<TabsPages>
<TabsPageItem id="heroku-website">
1. Acesse a [página de add-ons do Heroku para o New Relic](https://elements.heroku.com/addons/newrelic#pricing) e selecione um plano de assinatura.
2. Em **Select an app**, selecione seu aplicativo.
3. Clique em **Submit Order Form**.
</TabsPageItem>

<TabsPageItem id="heroku-toolbelt">
Execute o seguinte comando, substituindo `$planlevel` pelo [plano de assinatura apropriado](https://elements.heroku.com/addons/newrelic#pricing):

```bash
heroku addons:create newrelic:$planlevel
```
</TabsPageItem>
</TabsPages>
</Tabs>

A instalação do add-on cria automaticamente uma conta da New Relic e configura o acesso para os hosts do Heroku.
</Step>

<Step>
## Configurar o agente [#configure]

Adicione a gem `newrelic_rpm` ao seu `Gemfile`:

```ruby
gem 'newrelic_rpm'
```

Defina o nome do seu aplicativo usando o cinto de ferramentas Heroku:

```bash
heroku config:set NEW_RELIC_APP_NAME='Your Application Name'
```

A chave de licença é definida automaticamente pelo add-on. Para todas as outras opções de configuração, consulte a [configuração do agente Ruby](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration).
</Step>

<Step>
## Verifique se os dados estão fluindo [#verify]

Reinicie seu dyno e gere algum tráfego para o seu app:

```bash
heroku restart
```

Aguarde 2–3 minutos e abra [one.newrelic.com &gt; APM](https://one.newrelic.com/apm) para procurar seu aplicativo pelo nome.

<Callout variant="tip">
O aplicativo não aparece? Consulte [Nenhum dado aparece (Ruby)](/docs/apm/agents/ruby-agent/troubleshooting/no-data-appears-ruby).
</Callout>
</Step>
</Steps>
