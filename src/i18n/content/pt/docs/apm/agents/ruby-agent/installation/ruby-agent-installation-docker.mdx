<Steps>
<Step>
## Adicione a gem ao seu Gemfile [#install]

Adicione a gem do agente Ruby ao seu `Gemfile`:

```ruby
gem 'newrelic_rpm'
```

Seu `Dockerfile` deve executar `bundle install` como parte do build:

```dockerfile
COPY Gemfile Gemfile.lock ./
RUN bundle install
```

**Notas específicas do framework:**

* **Rails**: o Rails chama automaticamente `Bundler.require`, portanto, `newrelic_rpm` é necessário durante a inicialização sem etapas adicionais.
* **Roda ou Sinatra**: você deve chamar manualmente `require 'newrelic_rpm'` em seu aplicativo.
* **Outros aplicativos Rack**: para usar o monitoramento de Browser automático, inclua manualmente os [middlewares Rack](/docs/agents/ruby-agent/frameworks/rack-middlewares#manual) fornecidos pelo agente.
</Step>

<Step>
## Configurar o agente [#configure]

Passe o nome do seu aplicativo e a chave de licença como variáveis de ambiente ao executar o contêiner — não os codifique diretamente na sua imagem:

```bash
docker run -e NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
           -e NEW_RELIC_APP_NAME="Your Application Name" \
           YOUR_IMAGE_NAME:latest
```

Você também pode defini-los via `ENV` em seu `Dockerfile`:

```dockerfile
ENV NEW_RELIC_APP_NAME="Your Application Name"
```

Para todas as outras opções de configuração, consulte a [configuração do agente Ruby](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration).
</Step>

<Step>
## Verifique se os dados estão fluindo [#verify]

Execute o seu contêiner e envie pelo menos dois requests para o seu aplicativo. Aguarde 2–3 minutos, depois abra [one.newrelic.com &gt; APM](https://one.newrelic.com/apm) e procure seu aplicativo pelo nome.

<Callout variant="tip">
O aplicativo não aparece? Consulte [Nenhum dado aparece (Ruby)](/docs/apm/agents/ruby-agent/troubleshooting/no-data-appears-ruby).
</Callout>
</Step>
</Steps>
