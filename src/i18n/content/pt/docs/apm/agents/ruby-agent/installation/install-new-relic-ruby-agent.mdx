<Steps>
<Step>
## Instale a joia [#install]

Adicione a gem do agente Ruby ao seu Gemfile:

```ruby
gem 'newrelic_rpm'
```

Em seguida, execute:

```sh
bundle install
```

<Callout variant="important">
Se você estiver usando o agente em um contêiner Docker, instale o agente dentro de cada contêiner. Consulte [Instalar no ambiente flexível do GAE](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent-gae-flexible-environment) para ver um exemplo de implantação baseada em Docker.
</Callout>

**Notas específicas do framework:**

* **Rails**: o Rails chama automaticamente `Bundler.require`, portanto, `newrelic_rpm` é necessário durante a inicialização sem etapas adicionais.
* **Roda ou Sinatra**: você deve chamar manualmente `require 'newrelic_rpm'` em seu aplicativo.
* **Outros aplicativos Rack**: para usar o monitoramento de Browser automático, inclua manualmente os [middlewares Rack](/docs/agents/ruby-agent/frameworks/rack-middlewares#manual) fornecidos pelo agente.
</Step>

<Step>
## Configurar o agente [#configure]

Faça o download de [`newrelic.yml`](https://github.com/newrelic/newrelic-ruby-agent/blob/dev/newrelic.yml) do repositório da New Relic no GitHub e copie-o para o diretório `config` do seu aplicativo.

As únicas duas configurações que você **deve** alterar antes de entrar em produção:

1. Defina `license_key` como seu <InlinePopover type="licenseKey" />.
2. Defina `app_name` como um nome significativo para seu aplicativo.

Como alternativa, gere o arquivo de configuração com a CLI:

```sh
newrelic install --license_key="YOUR_LICENSE_KEY" "YOUR_APP_NAME"
```
</Step>

<Step>
## Verifique se os dados estão fluindo [#verify]

1. Reinicie seu servidor web.

2. Envie pelo menos dois requests para o seu aplicativo.

3. Aguarde 2–3 minutos, depois abra [one.newrelic.com &gt; APM](https://one.newrelic.com/apm) e procure seu aplicativo pelo nome.

<Callout variant="tip">
O aplicativo não aparece? Consulte [Nenhum dado aparece (Ruby)](/docs/apm/agents/ruby-agent/troubleshooting/no-data-appears-ruby).
</Callout>
</Step>
</Steps>
