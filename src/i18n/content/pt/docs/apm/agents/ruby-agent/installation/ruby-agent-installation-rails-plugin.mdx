Este método destina-se à instalação do agente Ruby como um plug-in do Rails para **Rails 2 ou superior**.

<Callout variant="important">
Para a maioria dos casos de uso, [instale o agente Ruby como uma gem](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent). O método da gem oferece melhor controle sobre versões e dependências.
</Callout>

<Steps>
<Step>
## Instale o plug-in do Rails [#install]

Instale o plug-in do GitHub no diretório `vendor/plugins` do seu aplicativo:

```sh
script/plugin install git://github.com/newrelic/newrelic-ruby-agent.git
mv vendor/plugins/rpm vendor/plugins/newrelic-ruby-agent
```

Se você não conseguir instalar diretamente a partir da URL do git, clone o repositório no diretório `vendor/plugins` manualmente.
</Step>

<Step>
## Configurar o agente [#configure]

Copie o arquivo `newrelic.yml` do diretório do plug-in para o subdiretório `config` do seu aplicativo:

```sh
cp vendor/plugins/newrelic-ruby-agent/newrelic.yml config/newrelic.yml
```

Edite `config/newrelic.yml` e defina os dois valores obrigatórios:

1. Defina `license_key` como seu <InlinePopover type="licenseKey" />.
2. Defina `app_name` como um nome significativo para seu aplicativo.

Para todas as outras opções de configuração, consulte a [configuração do agente Ruby](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration).
</Step>

<Step>
## Verifique se os dados estão fluindo [#verify]

Reinicie seu servidor web e, em seguida, envie pelo menos dois requests para seu aplicativo. Aguarde 2–3 minutos e abra [one.newrelic.com &gt; APM](https://one.newrelic.com/apm) para procurar seu aplicativo pelo nome.

<Callout variant="tip">
O aplicativo não aparece? Consulte [Nenhum dado aparece (Ruby)](/docs/apm/agents/ruby-agent/troubleshooting/no-data-appears-ruby).
</Callout>
</Step>
</Steps>
