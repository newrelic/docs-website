Configure as definições de logging do aplicativo do agente Ruby para controlar o encaminhamento de logs, a decoração local, os atributos personalizados em eventos de log e a coleta de métricas de log.

## Registro do aplicativo [#application-logging]

O agente Ruby oferece suporte [ao logs contextualizados APM](/docs/apm/new-relic-apm/getting-started/get-started-logs-context). Para obter algumas dicas sobre como configurar o log para o agente Ruby, consulte [Configurar logs contextualizados Ruby](/docs/logs/logs-context/configure-logs-context-ruby).

As opções de configuração relacionadas ao registro disponíveis incluem:

Define o nível mínimo que um evento de log deve ter para ser encaminhado para o New Relic. Os logs no nível configurado e em qualquer gravidade superior são encaminhados, por exemplo, `debug` encaminha todo evento de log, enquanto `error` encaminha apenas evento `error`, `fatal` e `unknown`. Valores válidos, da menor para a maior gravidade: `debug`, `info`, `warn`, `error`, `fatal`, `unknown` (não diferencia maiúsculas de minúsculas).

Essa ordenação é baseada nos valores inteiros das constantes `Logger::Severity` do Ruby (consulte [https://github.com/ruby/logger/blob/113b82a06b3076b93a71cd467e1605b23afb3088/lib/logger/severity.rb](https://github.com/ruby/logger/blob/113b82a06b3076b93a71cd467e1605b23afb3088/lib/logger/severity.rb)).
</Collapser>
