Instale o agente Ruby do New Relic para iniciar o monitoramento do seu aplicativo Ruby. Escolha o método que corresponde ao seu ambiente na navegação à esquerda.

Você precisa de uma [conta do New Relic](https://newrelic.com/signup) e do seu <InlinePopover type="licenseKey" />para concluir a instalação. Consulte os [requisitos do agente Ruby e frameworks suportados](/docs/apm/agents/ruby-agent/getting-started/ruby-agent-requirements-supported-frameworks) antes de começar.

| Método                                                                                                              | Usar quando                                                                                     |
| ------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| [Padrão (Bundler/Gemfile)](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent)                   | A maioria dos aplicativos Ruby — Rails, Sinatra, Roda, Rack e outros ambientes baseados em UNIX |
| [Plug-in do Rails](/docs/apm/agents/ruby-agent/installation/ruby-agent-installation-rails-plugin)                   | Aplicativos Rails 2+ usando o método de instalação de plug-in legado                            |
| [Docker](/docs/apm/agents/ruby-agent/installation/ruby-agent-installation-docker)                                   | Aplicativos Ruby conteinerizados                                                                |
| [Heroku](/docs/apm/agents/ruby-agent/installation/ruby-agent-heroku)                                                | Aplicativos implantados no Heroku usando o complemento do New Relic                             |
| [Google App Engine](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent-gae-flexible-environment) | Aplicativos em execução no ambiente flexível do GAE                                             |
