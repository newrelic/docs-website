O seu aplicativo Java é instrumentado automaticamente pelo agente Java da New Relic, fornecendo visibilidade de transações, erros e desempenho da JVM sem alterar o código do seu aplicativo. Uma vez instalado, é possível ver o tempo de resposta, as taxas de transferência, a taxa de erros e a integridade da JVM do seu aplicativo na plataforma New Relic em minutos. Use o agente Java para encontrar gargalos de desempenho, diagnosticar erros no contexto e entender como o seu aplicativo se comporta sob tráfego real.

## Capacidades [#capabilities]

* **Métricas** — tempo de resposta, taxas de transferência, taxa de erros, pontuação Apdex e métricas da JVM (heap, coleta de lixo, contagens de threads) por aplicativo e transação
* **Eventos** — Eventos de transação, eventos de erro e eventos personalizados consultáveis via NRQL
* **Logs** — Dados de log de aplicativo correlacionados com trace e erros via [logs no contexto](/docs/logs/logs-context/java-configure-logs-context-all/)
* **Traces** — Distributed traces que vinculam requests entre serviços, além de traces da transação e planos de execução SQL para consultas lentas
* **Entidades** — Seu aplicativo aparece como uma entidade de serviço no New Relic, visível no APM &amp; serviços e no explorador de entidades

## Escolha seu caminho de instalação [#choose]

* **Servidores de aplicativos e JVM autônoma** (recomendado) — O caminho padrão para Tomcat, Spring Boot, JBoss/WildFly, Glassfish, Jetty, WebLogic, WebSphere e qualquer JVM que aceite um argumento `-javaagent`
* **Maven** — Use quando seu build já utiliza o Maven; o agente é baixado e descompactado como uma dependência de build via `maven-dependency-plugin`
* **Gradle** — use quando sua compilação já usar o Gradle; as tarefas de download executadas por `de.undercouch.download` buscam e descompactam o agente automaticamente
* **Serviço de Aplicativo do Azure (Windows)** — Use quando seu aplicativo Java for executado no Serviço de Aplicativo do Windows no Azure; a extensão de site da New Relic injeta o agente sem modificar seu script de inicialização
* **Docker** — Use para aplicativos Java em contêineres; passe `-javaagent` via `JAVA_TOOL_OPTIONS`
* **AWS Elastic Beanstalk** — Use para aplicativos Tomcat ou Java SE implantados no Elastic Beanstalk
* **Google App Engine** — Use para aplicativos executados no ambiente flexível do GAE via um runtime personalizado do Docker
* **AWS Lambda** — usa um caminho de instalação diferente do agente padrão; consulte o [monitoramento de função serverless](/docs/serverless-function-monitoring/aws-lambda-monitoring/enable-lambda-monitoring/enable-serverless-monitoring-aws-lambda-legacy#java)

## Instalação guiada [#ui-install]

A instalação guiada está disponível em <DNT>**[one.newrelic.com](https://one.newrelic.com) → Integrations &amp; Agents → Java**</DNT>. A interface fornece um fluxo de trabalho guiado de ponta a ponta que preenche previamente sua chave de licença e o nome do aplicativo.

## Instalação em um relance [#at-a-glance]

1. Verifique a [compatibilidade e requisitos](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent)
2. Baixe e coloque os arquivos do agente
3. Configure o agente com a sua chave de licença e o nome do aplicativo
4. Verifique se os dados estão fluindo para o New Relic
