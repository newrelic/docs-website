Esta página aborda a instalação do agente Java da New Relic no Azure App Service para Windows usando a extensão de site do agente Java da New Relic. A extensão injeta o agente automaticamente sem modificar o script de inicialização do seu aplicativo.

## Compatibilidade e requisitos [#requirements]

### Suportado

* Aplicativos Java em execução no Azure Windows App Service
* Versões do agente Java da New Relic compatíveis com Java 8 e superior *(Java 7 suportado apenas no agente v6.5.4 e anteriores)*
* Consulte a [compatibilidade e os requisitos](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent) para ver os intervalos de versões de framework e biblioteca suportados

### Não suportado

* Contêineres Linux no Azure — use o [método de instalação do Docker](/docs/apm/agents/java-agent/additional-installation/install-new-relic-java-agent-docker) e passe `-javaagent` via `JAVA_TOOL_OPTIONS`
* Execução em conjunto com outros agentes APM — o agente Java não pode garantir o comportamento correto quando outro agente APM está ativo na mesma JVM

### Você precisa

* Uma conta New Relic e<InlinePopover type="licenseKey" />
* Uma JVM com suporte a SSL SHA-2 (256 bits)
* Um aplicativo Java em execução no Azure Windows App Service
* O aplicativo de destino deve ser interrompido antes da instalação da extensão para evitar a instrumentação parcial

## Instalar [#install]

<Steps>
  <Step>
    ### Instale a extensão do site [#install-step-1]

    1. Na página inicial do Azure, selecione **App Services** e, em seguida, selecione seu aplicativo de destino.
    2. No menu à esquerda, role até **Development Tools** e selecione **Extensions**.
    3. Selecione **+ Add** na parte superior da página para abrir o dropdown da extensão.
    4. Selecione **New Relic Java Agent**.
    5. Aceite os termos legais e selecione **OK** para iniciar a instalação.

    Após a instalação, a extensão cria:

    * **Arquivos do agente** em `C:\home\NewRelic\JavaAgent\newrelic\` (jars, configurações, fontes)
    * **Transformação XDT** (`applicationHost.xdt`) que injeta automaticamente a variável de ambiente `JAVA_TOOL_OPTIONS` na inicialização do aplicativo

    *Se a extensão não for instalada, verifique o log em `C:\home\SiteExtensions\NewRelic.Azure.WebSites.Extension.JavaAgent\install.log`.*
  </Step>

  <Step>
    ### Configurar o agente [#install-step-2]

    1. No menu à esquerda do seu aplicativo, acesse **Settings &gt; Configuration**.
    2. Adicione as seguintes configurações de aplicativo:

    | Contexto                | Valor                                      |
    | ----------------------- | ------------------------------------------ |
    | `NEW_RELIC_LICENSE_KEY` | Sua chave de licença New Relic             |
    | `NEW_RELIC_APP_NAME`    | O nome que aparece na plataforma New Relic |

    Você também pode adicionar quaisquer [configurações adicionais](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file/#Environment_Variables) como configurações de aplicativo para personalizar ainda mais o agente.
  </Step>
</Steps>

## Verifique sua instalação [#verify]

Inicie seu aplicativo. Envie pelo menos dois requests, depois aguarde 2–3 minutos e seu aplicativo aparecerá em [APM &amp; services](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29).

Se nenhum dado aparecer após cinco minutos, consulte [Nenhum dado aparece (Java)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java).
