## OpenTelemetry [#opentelemetry]

A partir da versão `9.1.0` do agente Java, foi adicionada compatibilidade com a API de Rastreamento, Métricas e Logs do OpenTelemetry, oferecendo uma experiência com &quot;o melhor dos dois mundos&quot; ao combinar a visibilidade profunda da New Relic com os sinais do OpenTelemetry.

Com essa funcionalidade, as APIs de Tracing, Métricas e Logs do OpenTelemetry podem ser usadas para instrumentar diretamente sua aplicação de forma personalizada, em combinação com as APIs do agente Java da New Relic, enquanto o agente Java combina tudo isso de forma transparente em uma experiência de APM familiar. Além disso, algumas bibliotecas que fornecem instrumentação nativa do OpenTelemetry ou instrumentação de biblioteca independente podem ser usadas para fornecer visibilidade aprimorada da sua aplicação.

As opções de configuração a seguir determinam quais sinais do OpenTelemetry devem ser capturados e incorporados à experiência do New Relic APM.

```yml
  opentelemetry:
    enabled: false
    logs:
      enabled: true
    metrics:
      enabled: true
      include: "MeterName1,MeterName2"
      exclude: "MeterName3,MeterName4"
    traces:
      enabled: true
      include: "TracerName1,TracerName2"
      exclude: "TracerName3,TracerName4"
```

    Defina como true para permitir que sinais individuais do OpenTelemetry sejam habilitados, false para desabilitar todos os sinais do OpenTelemetry. O padrão é falso.

    Pode ser definido via propriedade do sistema:

    ```ini
    -Dnewrelic.config.opentelemetry.enabled=false
    ```

    Pode ser definido pela variável de ambiente:

    ```ini
    NEW_RELIC_OPENTELEMETRY_ENABLED
    ```

    Uma string de Medidores OpenTelemetry delimitada por vírgulas (por exemplo, &quot;MeterName1,MeterName2&quot;) cujos sinais devem ser incluídos. Por padrão, todos os Medidores estão incluídos. Isso substituirá quaisquer exclusões padrão de Meter no agente, efetivamente reativando-os.

    O padrão é uma string vazia.

    Pode ser definido via propriedade do sistema:

    ```ini
    -Dnewrelic.config.opentelemetry.metrics.include=MeterName1,MeterName2
    ```

    Pode ser definido pela variável de ambiente:

    ```ini
    NEW_RELIC_OPENTELEMETRY_METRICS_INCLUDE
    ```
