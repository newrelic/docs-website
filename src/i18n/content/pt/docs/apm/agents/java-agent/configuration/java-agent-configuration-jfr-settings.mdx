As configurações do JFR configuram o perfilamento em tempo real baseado no Java Flight Recorder para o monitoramento contínuo de desempenho da JVM.

<Callout variant="tip">
  Voltar ao índice completo de configurações: [configuração do agente Java](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file)
</Callout>

## JFR (perfil em tempo real)

O agente Java usa Java Flight Recorder (JFR) para coletar dados JVM de alta fidelidade para [criação de perfil em tempo real](/docs/agents/java-agent/features/real-time-profiling-java-using-jfr-metrics/).

Configure o perfilamento em tempo real na seção `jfr` no YAML do agente. Essas opções de configuração podem ser sobrescritas por [propriedades do sistema](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file#System_Properties) prefixadas por `newrelic.config.jfr.` ou por [variáveis de ambiente](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file#Environment_Variables) prefixadas por `NEW_RELIC_JFR_`.

    O número máximo de eventos do JFR armazenados na fila de memória do agente. Aumentar este valor pode ajudar a evitar lacunas nos dados do JFR, mas também aumentará o consumo de recursos do agente. Se a fila for muito grande, os dados poderão ser descartados se os limites do pipeline do backend forem excedidos. Para mais informações, consulte [limites de ingestão da API de eventos](/docs/data-apis/ingest-apis/event-api/introduction-event-api/#limits).

    <Callout variant="important">
      Isso se aplica ao agente Java [versão 8.17.0 ou superior](/docs/release-notes/agent-release-notes/java-release-notes).
    </Callout>
