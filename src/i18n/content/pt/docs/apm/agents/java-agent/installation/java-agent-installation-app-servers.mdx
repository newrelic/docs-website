Esta página aborda o caminho de instalação padrão para o agente Java do New Relic em qualquer servidor de aplicativos compatível ou framework baseado em JVM. Siga estas etapas para baixar o agente, configurá-lo e verificar se os dados estão fluindo para o New Relic.

## Compatibilidade e requisitos [#requirements]

### Suportado

* Java 8, 11, 17, 21, 24, 25 e 26 *(Java 7 suportado apenas no agente v6.5.4 e anteriores)*
* Linguagens baseadas na JVM: Java, Scala, Kotlin e Clojure
* Servidores de aplicativos e frameworks: Tomcat, Spring Boot, JBoss/WildFly, Glassfish, Jetty, WebLogic, WebSphere, Grails, ColdFusion, Solr, Play, Resin, Tanuki Wrapper e Geronimo — consulte [compatibilidade e requisitos](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent) para ver os intervalos de versões compatíveis
* Qualquer processo da JVM que aceite um argumento `-javaagent`

### Não suportado

* Execução em conjunto com outros agentes APM — o agente Java não pode garantir o comportamento correto quando outro agente APM está ativo na mesma JVM

### Você precisa

* Uma conta New Relic e<InlinePopover type="licenseKey" />
* Uma JVM com suporte a SSL SHA-2 (256 bits)
* Permissão para editar os scripts de inicialização do seu servidor de aplicativos ou a configuração da JVM
* Permissão para criar um diretório para armazenar os arquivos do agente

## Instalar [#install]

<Steps>
  <Step>
    ### Baixe o agente Java [#install-step-1]

    Faça o download de `newrelic-java.zip` utilizando um destes métodos:

    <Tabs>
      <TabsBar>
        <TabsBarItem id="curl">curl</TabsBarItem> <TabsBarItem id="powershell">PowerShell</TabsBarItem> <TabsBarItem id="web">Web</TabsBarItem>
      </TabsBar>

      <TabsPages>
        <TabsPageItem id="curl">
          ```bash
          curl -O https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip
          unzip newrelic-java.zip
          ```
        </TabsPageItem>

        <TabsPageItem id="powershell">
          ```powershell
          Invoke-WebRequest -Uri https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip -OutFile newrelic-java.zip
          Expand-Archive -Path newrelic-java.zip -DestinationPath .
          ```
        </TabsPageItem>

        <TabsPageItem id="web">
          Faça o download de `newrelic-java.zip` na página de [notas de versão do agente Java](/docs/release-notes/agent-release-notes/java-release-notes/).
        </TabsPageItem>
      </TabsPages>
    </Tabs>

    Após a descompactação, o diretório `newrelic/` contém o jar do agente (`newrelic.jar`) e o arquivo de configuração (`newrelic.yml`) que você configurará nas próximas etapas.
  </Step>

  <Step>
    ### Colocar os arquivos do agente [#install-step-2]

    Crie um diretório permanente e mova os arquivos do agente para ele:

    ```bash
    mkdir -p /opt/newrelic
    mv newrelic/* /opt/newrelic/
    ```

    Recomendamos `/opt/newrelic` no Linux/macOS ou `C:\opt\newrelic` no Windows. Certifique-se de que `newrelic.jar` **não** esteja no classpath do seu aplicativo ou em qualquer diretório listado em `java.endorsed.dirs`.
  </Step>

  <Step>
    ### Passe o `-javaagent` [#install-step-3]

    Adicione a flag `-javaagent` à configuração de inicialização da JVM do seu servidor de aplicativos, apontando para o caminho completo de `newrelic.jar`. O método difere por servidor — expanda o que corresponde ao seu ambiente:

    <CollapserGroup>
      <Collapser id="tomcat" title="Tomcat">
        Escolha o método para a configuração do seu Tomcat:

        <Tabs>
          <TabsBar>
            <TabsBarItem id="tomcat-setenvsh">setenv.sh (Linux/macOS)</TabsBarItem> <TabsBarItem id="tomcat-setenvbat">setenv.bat (Windows)</TabsBarItem> <TabsBarItem id="tomcat-windows-service">serviço do Windows</TabsBarItem> <TabsBarItem id="tomcat-commons-daemon">daemon do Apache Commons</TabsBarItem>
          </TabsBar>

          <TabsPages>
            <TabsPageItem id="tomcat-setenvsh">
              Crie `CATALINA_BASE/bin/setenv.sh` se não existir e, em seguida, adicione:

              ```bash
              export CATALINA_OPTS="$CATALINA_OPTS -javaagent:/opt/newrelic/newrelic.jar"
              ```
            </TabsPageItem>

            <TabsPageItem id="tomcat-setenvbat">
              Crie `CATALINA_BASE/bin/setenv.bat` se não existir e, em seguida, adicione:

              ```batch
              SET "CATALINA_OPTS=%CATALINA_OPTS% -javaagent:C:\opt\newrelic\newrelic.jar"
              ```
            </TabsPageItem>

            <TabsPageItem id="tomcat-windows-service">
              1. Selecione **Start &gt; Apache Tomcat X.Y.Z &gt; Configure Tomcat &gt; Java**.

              2. Na caixa de texto **Java Options**, insira o argumento. Use barras normais `/` para o separador de caminho. Para o Tomcat 6, adicione uma quebra de linha após o argumento `-javaagent`.

                 ```
                 -javaagent:/opt/newrelic/newrelic.jar
                 ```

              3. Selecione **Apply** e, em seguida, reinicie o Tomcat.
            </TabsPageItem>

            <TabsPageItem id="tomcat-commons-daemon">
              A versão do Apache Commons daemon (jsvc) incluída no Tomcat 6 não suporta o argumento `-javaagent`. Uma compilação a partir do código-fonte do trunk oferece suporte a isso por meio do prefixo `-X`. Consulte o [relatório de bugs do Apache](https://issues.apache.org/jira/browse/DAEMON-84) e o [repositório de código-fonte do Apache Commons](https://commons.apache.org/svninfo.html).
            </TabsPageItem>
          </TabsPages>
        </Tabs>
      </Collapser>

      <Collapser id="spring-boot" title="Bota Primavera">
        Adicione o argumento `-javaagent` antes do argumento `-jar` na linha de comando:

        ```bash
        java -javaagent:/opt/newrelic/newrelic.jar -jar /path/to/your-application.jar
        ```
      </Collapser>

      <Collapser id="glassfish" title="Glassfish">
        1. No console de administração do Glassfish, selecionar **Application Server &gt; JVM Settings &gt; JVM Options**.

              ```bash
              exec $JAVA_EXE -javaagent:/opt/newrelic/newrelic.jar -jar lib/resin.jar $@
              ```

## Configurar [#configure]

Edite `newrelic/newrelic.yml` e defina estes dois valores obrigatórios:

```yaml
license_key: 'YOUR_LICENSE_KEY'
app_name: 'My Application'
```

O agente lê `newrelic.yml` do mesmo diretório que `newrelic.jar` na inicialização. Também é possível substituir qualquer configuração usando propriedades do sistema Java (por exemplo, `-Dnewrelic.config.license_key=YOUR_KEY`) ou variáveis de ambiente.

Ao usar o arquivo de configuração, restrinja as permissões de leitura/gravação apenas para o proprietário do processo do servidor de aplicativo:

```bash
chmod 600 /opt/newrelic/newrelic.yml
```

Consulte a [configuração do agente Java](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file) para ver todas as opções disponíveis.

## Verifique sua instalação [#verify]

Reinicie seu servidor de aplicativo. Envie pelo menos dois requests, depois aguarde 2–3 minutos e o seu aplicativo aparecerá em [APM &amp; serviços](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29).

Se nenhum dado aparecer após cinco minutos, consulte [Nenhum dado aparece (Java)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java).
