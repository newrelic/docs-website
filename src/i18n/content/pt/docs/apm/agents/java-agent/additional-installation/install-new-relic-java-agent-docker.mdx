Esta página aborda a instalação do agente Java da New Relic em um contêiner Docker, adicionando o jar do agente à sua imagem e passando o argumento `-javaagent` da JVM na inicialização.

## Compatibilidade e requisitos [#requirements]

### Suportado

* Java 8, 11, 17, 21, 24, 25 e 26 *(Java 7 suportado apenas no agente v6.5.4 e anteriores)*
* Qualquer imagem Docker executando um aplicativo Java (Tomcat, Spring Boot ou similar) que aceite um argumento JVM `-javaagent`
* Consulte a [compatibilidade e os requisitos](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent) para ver os intervalos de versões de framework e biblioteca suportados

### Não suportado

* Execução em conjunto com outros agentes APM — o agente Java não pode garantir o comportamento correto quando outro agente APM está ativo na mesma JVM

### Você precisa

* Uma conta New Relic e<InlinePopover type="licenseKey" />
* Uma JVM com suporte a SSL SHA-2 (256 bits)
* Docker instalado com um contêiner de aplicativo Java

## Instalar [#install]

Baixe `newrelic-java.zip`: \[#install-step-1]

```bash
curl -O https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip
unzip newrelic-java.zip
```

Adicione o jar do agente ao seu `Dockerfile`. O exemplo abaixo usa o Tomcat — ajuste o caminho para o seu servidor de aplicativos:

```dockerfile
RUN mkdir -p /usr/local/tomcat/newrelic
ADD ./newrelic/newrelic.jar /usr/local/tomcat/newrelic/newrelic.jar
ENV JAVA_OPTS="$JAVA_OPTS -javaagent:/usr/local/tomcat/newrelic/newrelic.jar"
```

Crie sua imagem Docker como de costume.

## Configurar [#configure]

Passe o nome do seu aplicativo e a chave de licença como variáveis de ambiente ao executar o contêiner:

```bash
docker run -e NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
           -e NEW_RELIC_APP_NAME="Your Application Name" \
           YOUR_IMAGE_NAME:latest
```

Você também pode usar diretivas `ENV` no seu `Dockerfile`:

```dockerfile
ENV NEW_RELIC_APP_NAME="Your Application Name"
```

Para todas as outras opções de configuração, consulte a [configuração do agente Java](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file).

## Verifique sua instalação [#verify]

Execute seu contêiner e envie pelo menos dois requests para o seu aplicativo. Aguarde 2–3 minutos e seu aplicativo aparecerá em [APM &amp; services](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29).

Se nenhum dado aparecer após cinco minutos, consulte [Nenhum dado aparece (Java)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java).
