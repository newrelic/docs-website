Esta página aborda a instalação do agente Java da New Relic no AWS Elastic Beanstalk adicionando o agente ao pacote do seu aplicativo e configurando o argumento da JVM `-javaagent` por meio do console do Elastic Beanstalk.

## Compatibilidade e requisitos [#requirements]

### Suportado

* Java 8, 11, 17, 21, 24, 25 e 26 *(Java 7 suportado apenas no agente v6.5.4 e anteriores)*
* Plataforma Tomcat do Elastic Beanstalk
* Plataforma Java SE do Elastic Beanstalk
* Consulte a [compatibilidade e os requisitos](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent) para ver os intervalos de versões de framework e biblioteca suportados

### Não suportado

* Contêineres Docker no Elastic Beanstalk — use o [método de instalação do Docker](/docs/apm/agents/java-agent/additional-installation/install-new-relic-java-agent-docker) em vez disso
* Execução em conjunto com outros agentes APM — o agente Java não pode garantir o comportamento correto quando outro agente APM está ativo na mesma JVM

### Você precisa

* Uma conta New Relic e<InlinePopover type="licenseKey" />
* Uma JVM com suporte a SSL SHA-2 (256 bits)
* Uma [conta da AWS](http://aws.amazon.com/elasticbeanstalk/) com seu aplicativo Java implantado no Elastic Beanstalk

## Instalar [#install]

Faça o download de `newrelic-java.zip` e extraia `newrelic.jar` e `newrelic.yml`: \[#install-step-1]

```bash
curl -O https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip
unzip newrelic-java.zip
```

## Configurar [#configure]

Edite `newrelic.yml` e defina os dois valores obrigatórios:

1. Defina `license_key` como seu <InlinePopover type="licenseKey" />.
2. Defina `app_name` como um nome significativo para seu aplicativo.

**Apenas plataforma Tomcat** — passar o sinalizador `-javaagent` pelo console do Elastic Beanstalk:

1. Abra o console do Elastic Beanstalk e selecione seu ambiente.

2. No painel esquerdo, selecione **Configurations**.

3. Role até **Updates, monitoring, and logging** e clique em **Edit**.

4. Em **Platform Software**, adicione ao campo **JVM Options**:

   ```
   -javaagent:/full/path/to/newrelic.jar
   ```

   Para encontrar o caminho para `newrelic.jar` na instância de EC2, conecte-se à instância e execute:

   ```bash
   sudo find /var -name "newrelic.jar"
   sudo find /usr -name "newrelic.jar"
   ```

5. Clique em **Apply**.

Para todas as outras opções de configuração, consulte a [configuração do agente Java](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file).

## Verifique sua instalação [#verify]

O Elastic Beanstalk atualizará o seu ambiente. Envie pelo menos dois requests, depois aguarde 2–3 minutos e o seu aplicativo aparecerá em [APM &amp; serviços](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29).

Se nenhum dado aparecer após cinco minutos, consulte [Nenhum dado aparece (Java)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java).
