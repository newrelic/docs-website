## Problema

Se a instrumentação estiver ausente em seu aplicativo Kotlin, defina [os logs do agente para o nível finest](/docs/agents/java-agent/troubleshooting/generating-logs-troubleshooting-java).

Os logs devem mencionar `ArrayIndexOutOfBoundsException`. Clientes com o agente versão 8.2.0 ou superior verão a seguinte mensagem:

```
Unexpected ArrayIndexOutOfBoundsException thrown during class transformation. Try restarting the Java Agent with flag -Dnewrelic.config.class_transformer.clear_return_stacks=true
```

## Solução

Certifique-se de que a versão do agente Java seja 8.20 ou posterior. Se a versão instalada for anterior à 8.20, atualize o agente Java para uma versão suportada (a versão mais recente é recomendada).

Reinicie o agente Java ou o seu aplicativo Java com a propriedade do sistema:

```
-Dnewrelic.config.class_transformer.clear_return_stacks=true
```
