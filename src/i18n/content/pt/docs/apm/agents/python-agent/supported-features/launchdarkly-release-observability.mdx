O agente Python da New Relic se integra ao gerenciamento de recursos do LaunchDarkly para que você possa observar como os sinalizadores de recursos e os lançamentos afetam o seu aplicativo. Essa integração usa o plug-in de observabilidade do LaunchDarkly e o suporte ao OpenTelemetry no agente Python para conectar seus dados do LaunchDarkly aos dados do New Relic APM.

Este documento explica como instalar os pacotes necessários e habilitar a integração.

## Pré-requisitos [#prerequisites]

Antes de começar, certifique-se de ter:

* Uma [chave de licença](/docs/apis/intro-apis/new-relic-api-keys/#license-key) da New Relic
* Uma conta e uma licença do LaunchDarkly
* Um aplicativo escrito em Python e monitorado com o [agente APM do New Relic para Python](/docs/apm/agents/python-agent/installation/install-new-relic-python-agent)
* Acesso ao beta do OpenTelemetry (OTel) do LaunchDarkly

## Instalação e configuração [#install]

<Steps>
<Step>
### Instale os pacotes necessários [#install-packages]

Instale os seguintes pacotes Python no mesmo ambiente que o aplicativo:

* `newrelic`
* `launchdarkly-observability`

```bash
pip install newrelic launchdarkly-observability
```

Os seguintes pacotes também são necessários e, normalmente, são instalados automaticamente como dependências de `launchdarkly-observability`:

* `opentelemetry-api`
* `launchdarkly-eventsource`
* `launchdarkly-server-sdk`
* `launchdarkly-server-sdk-otel`

Se essas dependências não forem instaladas automaticamente, instale-as manualmente usando `pip`:

```bash
pip install opentelemetry-api launchdarkly-eventsource launchdarkly-server-sdk launchdarkly-server-sdk-otel
```
</Step>

<Step>
### Habilite a integração [#enable-integration]

Para habilitar a integração, defina tanto `launch_darkly_integration.enabled` quanto `opentelemetry.enabled` como `true`. Selecione um dos seguintes métodos de configuração para configurar o aplicativo:

<CollapserGroup>
<Collapser id="use-newrelic-ini" title="Use o newrelic.ini">
Adicione o seguinte ao seu arquivo `newrelic.ini` :

```ini
launch_darkly_integration.enabled = true
opentelemetry.enabled = true
```
</Collapser>

<Collapser id="use-pyproject-toml" title="Use o pyproject.toml">
Adicione o seguinte ao seu arquivo `pyproject.toml` :

```toml
[tool.newrelic]
launch_darkly_integration.enabled = true
opentelemetry.enabled = true
```
</Collapser>

<Collapser id="use-environment-variables" title="Use variáveis de ambiente">
Defina as seguintes variáveis de ambiente:

```bash
export NEW_RELIC_LAUNCH_DARKLY_ENABLED=true
export NEW_RELIC_OPENTELEMETRY_ENABLED=true
```

<Callout variant="tip">
Para obter mais informações sobre a configuração do OpenTelemetry, consulte a documentação de [configuração do agente Python](/docs/apm/agents/python-agent/configuration/python-agent-configuration#opentelemetry-enabled).
</Callout>
</Collapser>
</CollapserGroup>
</Step>

<Step>
### Verifique a integração [#verify]

Após habilitar essas configurações, reinicie o aplicativo para que o agente Python carregue a configuração atualizada. Em seguida, gere tráfego de teste e verifique se o aplicativo continua relatando dados em [<DNT>**APM &amp; services**</DNT>](/docs/apm/apm-ui-pages/monitoring/apm-summary-page-view-transaction-apdex-usage-data).
</Step>
</Steps>
