Você pode usar [o painel](/docs/query-your-data/explore-query-data/dashboards/introduction-dashboards/) para visualizar e monitorar a integridade do seu sistema, resolver problemas e planejar outras etapas. Aprenda a compartilhar todas essas informações com sua equipe, clientes ou outras partes interessadas com diversas opções de importação e exportação.

## Importar dashboards [#import-json]

Importe um dashboard do seu JSON para movê-lo para outra conta ou modificá-lo no nível do código. Por exemplo, você pode criar um dashboard personalizado mesclando dois dashboards existentes no JSON de um dashboard base. Para obter o JSON, [faça o download do dashboard](#export-dashboards-pdf).

Em <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Dashboards**</DNT>, use a ação <DNT>**Import dashboard**</DNT> e cole o JSON. Você escolhe a conta e as permissões na importação. Você não pode alterar a conta posteriormente, mas pode [alterar as permissões](/docs/query-your-data/explore-query-data/dashboards/manage-your-dashboard/#dash-settings) a qualquer momento. A importação exige permissão para criar dashboards na conta de destino, e os widgets que consultam contas às quais você não tem acesso não são exibidos.

<Callout title="Observação">
Um dashboard importado é uma cópia. Ele não se mantém sincronizado com o original, portanto, as alterações posteriores se aplicam apenas ao dashboard que você edita.
</Callout>

## Exportar dashboards [#export-dashboards]

### Fazer download como JSON, PDF ou PNG [#export-dashboards-pdf]

Use a ação <DNT>**Download dashboard**</DNT> no menu <DNT>**...**</DNT> do dashboard para salvar um dashboard em um destes formatos:

* **JSON**: Mova um dashboard para outra conta ou gerencie-o como código, por exemplo, no Terraform. Você pode fazer o download do JSON ou copiá-lo para a área de transferência. O JSON inclui a consulta NRQL e os IDs de conta de cada widget, quer você exporte ou não os GUIDs de entidade.
* **PDF e PNG**: Compartilhe um snapshot estático de um dashboard em e-mails, páginas do Confluence ou no Slack, como as vendas da semana passada ou os usuários afetados durante um incidente. Defina a largura e a altura em pixels. O padrão de ambos é 1920 x 1080.

A New Relic não oferece suporte a [visualizações personalizadas](/docs/query-your-data/explore-query-data/dashboards/add-custom-visualizations-your-dashboards/) ao exportar um dashboard como PDF ou PNG por meio da interface.

### Exportar dashboards via NerdGraph [#export-api]

Para exportar dashboards programaticamente com opções que a interface não oferece, como substituições de variáveis de modelo e filtros de entidade, consulte o [Tutorial do NerdGraph: exportar dashboards e gráficos como arquivos](/docs/apis/nerdgraph/examples/export-dashboards-pdfpng-using-api/#api-dashboard-snapshot).

## Exportar gráficos [#export-charts]

### Exportar como CSV [#export-charts-csv]

Exporte os dados de um gráfico de tabela como um arquivo CSV com a ação de gráfico <DNT>**Export as CSV**</DNT>.

<img title="Export chart as CSV" alt="Screenshot of how to export a table chart as a CSV file" src="/images/dashboards_screenshot-crop_export-csv.webp" />

### Obter os dados de um gráfico como JSON [#export-charts-json]

Para obter a resposta bruta da consulta de um gráfico como JSON, abra <DNT>**View query**</DNT> no menu <DNT>**...**</DNT> do gráfico, execute a consulta e defina o tipo de gráfico como JSON. Você pode copiar a resposta a partir daí. Esta é a saída da consulta, não a configuração do gráfico.

### Obter um gráfico como uma imagem ou link [#chart-image-link]

Compartilhe um gráfico fora do dashboard de uma das duas maneiras:

* **Obter como imagem**: copie um link para um PNG do gráfico. O link expira após 90 dias.
* **Obter link do gráfico**: Crie um URL de gráfico ao vivo que qualquer pessoa possa visualizar sem uma conta da New Relic. Você precisa da permissão `Live Url (individual) > Modify`. Consulte [Compartilhar um gráfico](/docs/query-your-data/explore-query-data/dashboards/share-charts-publicly/#share-chart).

Para criar, listar e revogar links de gráficos com o NerdGraph, consulte [Tutorial do NerdGraph: criar, listar e revogar URLs de gráficos de compartilhamento público](/docs/apis/nerdgraph/examples/manage-live-chart-urls-via-api/).

### Exportar gráficos via NerdGraph [#export-charts-api]

Para gerar imagens de gráficos programaticamente, consulte o [Tutorial do NerdGraph: exportar dashboards e gráficos como arquivos](/docs/apis/nerdgraph/examples/export-dashboards-pdfpng-using-api/#api-widget-snapshot).
