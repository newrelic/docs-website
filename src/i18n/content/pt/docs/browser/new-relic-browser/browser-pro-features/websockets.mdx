A [API WebSocket](https://developer.mozilla.org/en-US/docs/Web/API/WebSockets_API) permite abrir uma sessão de comunicação interativa bidirecional entre o browser do usuário e um servidor. Essa sessão permite enviar e receber dados sem consultar uma resposta do servidor. Com o monitoramento de Browser da New Relic, é possível monitorar e rastrear o tráfego e a integridade das sessões de websocket.

Os dados de websockets da API são registrados como eventos [WebSocket](https://docs.newrelic.com/attribute-dictionary/?dataSource=Browser+agent&event=WebSocket) pelo agente do browser. Esses eventos incluem métricas sobre a conexão, mensagens recebidas, dados enviados e como a conexão foi fechada durante o ciclo de vida do websocket.

## Por que usar o monitoramento de websockets?

O rastreamento automático de websockets com a New Relic fornece as ferramentas e os insights para garantir que os websockets funcionem conforme o esperado. Com os eventos `WebSocket`, é possível:

* Monitore os bytes enviados e recebidos das conexões de rede
* Examine se os websockets fecham com êxito ou não e o motivo
* Solucionar erros de JavaScript que ocorrem durante o ciclo de vida dos websockets
* Criar dashboards personalizados e alertas com base em websockets

## Pré-requisitos [#prerequisites]

* Um agente do browser **Pro** ou **Pro + SPA**, versão 1.318.0 ou superior.

<Callout variant="important">
  O monitoramento de websockets não está disponível para o agente do browser Lite.
</Callout>

## Habilitar coleta automática [#enable-collection]

Melhore a observabilidade e os recursos de depuração do seu aplicativo seguindo estas instruções simples de configuração.

<Steps>
  <Step>
    Acesse **[one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Browser**.
  </Step>

  <Step>
    Selecione seu aplicativo de browser.
  </Step>

  <Step>
    No menu à esquerda, clique em **Application settings**.
  </Step>

  <Step>
    Certifique-se de que o browser do agente **Pro** ou **Pro + SPA** esteja selecionado.
  </Step>

  <Step>
    Ative **Enable websockets**.
  </Step>
</Steps>

## Desativar a coleta de websockets [#disable-websockets]

Para desabilitar websockets para um aplicativo de browser existente:

<Steps>
  <Step>
    Acesse **[one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Browser**.
  </Step>

  <Step>
    Selecione seu aplicativo de browser.
  </Step>

  <Step>
    No menu à esquerda, clique em **Application settings**.
  </Step>

  <Step>
    Para desabilitar websockets, desative **Enable websockets**.
  </Step>
</Steps>

## Consumo de dados

`WebSocket` evento segue o mesmo preço de consumo dos outros bytes do seu navegador. A quantidade de bytes produzidos depende da contagem e do atributo dos dados.

Uma vez ativado, o agente capturará automaticamente os websockets à medida que ocorrerem no aplicativo.

## Encontre seus dados no New Relic [#find-data]

Os websockets são armazenados como eventos `WebSocket` na New Relic. Consulte o [dicionário de dados](https://docs.newrelic.com/attribute-dictionary/?dataSource=Browser+agent&event=WebSocket) para obter mais informações sobre os campos disponíveis para uso com eventos `WebSocket`. Para um dashboard rápido e útil, consulte este [início rápido](https://newrelic.com/instant-observability/browser-web-sockets). É possível consultar e visualizar esses dados para obter insights sobre o desempenho do aplicativo:

**Medir a quantidade total de instâncias de websocket ao longo do tempo**

```nrql
FROM WebSocket
SELECT count(*)
TIMESERIES
```

**Visualizar os motivos pelos quais os websockets fecham inesperadamente**

```nrql
FROM WebSocket
SELECT count(*)
FACET closeReason
```

**Rastrear websockets com erros**

```nrql
FROM WebSocket
SELECT count(*) AS 'Errors'
WHERE hasErrors IS true
TIMESERIES
```

**Visualizar a média de bytes enviados e recebidos**

```nrql
FROM WebSocket
SELECT average(sendBytes), average(messageBytes)
WHERE messageCount IS NOT null
TIMESERIES 
```

**Monitorar a duração média do websocket**

```nrql
FROM WebSocket
SELECT average(connectedDuration)
FACET cases(
  WHERE closeWasClean IS true AS 'Connected - Clean',
  WHERE closeWasClean IS NOT true AS 'Connected - Dirty'
)
TIMESERIES
```

Use estas consultas ou crie as suas próprias para criar dashboards personalizados, configurar alertas e monitorar o desempenho real do seu aplicativo web com precisão.
