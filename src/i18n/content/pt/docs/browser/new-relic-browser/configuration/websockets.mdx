## Para que serve este recurso?

Isso permite o monitoramento da integridade e do tráfego das conexões de websockets.

Uma nova propriedade está disponível no objeto de inicialização do agente do browser chamada `web_sockets`. Essa configuração controla se o recurso de websockets deve ser usado no agente. Disponível no Browser Pro ou Pro + agente SPA, [versão 1.318.0](/docs/release-notes/new-relic-browser-release-notes/browser-agent-release-notes/browser-agent-v1.318.0) ou superior.

## Como eu uso isso?

Para usar este recurso, você precisará acessar a página de configurações do seu aplicativo e ativar a opção `"Enable websockets"`. Essa configuração está desativada por padrão.

O NerdGraph pode ser usado como uma alternativa para ativar e desativar essa configuração. Para fazer isso, execute uma consulta de mutação no objeto graphQL `browserSettings` para a propriedade `browserWebSockets`, definindo `enabled` como `true` ou `false`.

Uma vez habilitada, a coleta de dados para websockets é automática após implantar novamente o agente. Os dados de websockets são coletados como eventos [WebSocket](https://docs.newrelic.com/attribute-dictionary/?dataSource=Browser+agent&event=WebSocket), incluindo métricas de conexão, mensagens recebidas, dados enviados e como a conexão foi fechada. Cada instância `WebSocket` é rastreada de forma independente e emite um evento por tempo de vida da conexão.

## Considerações adicionais

* Se os [traces da sessão](/docs/browser/browser-monitoring/browser-pro-features/session-traces-explore-webpages-life-cycle) estiverem habilitados, os eventos WebSocket poderão ser vinculados por meio da propriedade `sessionTraceId` como parte dos traces da sessão.
