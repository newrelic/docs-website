Na [versão 1211 do agente](/docs/release-notes/new-relic-browser-release-notes/browser-agent-release-notes/browser-agent-v1211/) ou superior, todos os requests de rede feitos por uma página são registrados como eventos `AjaxRequest`. Você pode configurar quais requests são registrados e quais dados são capturados:

* **[Lista de negação](#deny-list)**: filtra quais domínios e URLs são excluídos do rastreamento AJAX
* **[Captura de carga](#enable-payload-capture)**: registre os dados completos de solicitação e resposta para depurar falhas

## Lista de negações [#deny-list]

Por padrão, registramos eventos `AjaxRequest` para todas as solicitações de rede feitas pelo seu aplicativo.

* Para parar de registrar todos os eventos, adicione um único caractere curinga `*` (asterisco).
  * Exemplo: `*`
* Para parar de registrar eventos para um site completo, adicione o nome do domínio.
  * Exemplo: `mywebsite.com`
* Para parar de registrar eventos para uma página específica, adicione o domínio e o caminho.
  * Exemplo: `mywebsite.com/photos`
* Começando com a [versão 1.307.0 do agente](/docs/release-notes/new-relic-browser-release-notes/browser-agent-release-notes/browser-agent-v1.307.0/), em qualquer lugar que encontrarmos um `*` (asterisco), corresponderemos a qualquer comprimento de string.
  * Exemplo: `mywebsite.com/shop/*` (para um caminho), `*.mywebsite.com` (para um subdomínio), `mywebsite.com/*/shop/*/checkout` (para strings de URL intermediárias).

O protocolo, a porta, a pesquisa e o hash de um URL são ignorados pela lista de negação.

### Acesse a lista de negações [#access-deny-list]

Para atualizar a lista de URLs negados que seu aplicativo filtrará na criação do evento, acesse a página de configurações do aplicativo:

1. Vá para <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Browser &gt; (select an app) &gt; Settings &gt; Application settings**</DNT>.
2. Na seção <DNT>**AJAX data capture settings**</DNT>, no campo <DNT>**Deny list**</DNT>, adicione os filtros que você gostaria de aplicar ao seu aplicativo.
3. Selecione <DNT>**Save**</DNT> para atualizar a configuração do agente.
4. [Reimplante o agente browser](/docs/browser/new-relic-browser/installation/upgrade-browser-agent) (reiniciando o agente <InlinePopover type="apm" />associado ou atualizando a instalação de copiar/colar do browser).

<Callout variant="important">
  Salvar as alterações aqui atualiza apenas a configuração `NREUM.init` exibida na página <DNT>**Application settings**</DNT>. Isso não entra em vigor automaticamente para agentes instalados via NPM.

  Se você instalou o agente do browser usando o [pacote NPM](https://www.npmjs.com/package/@newrelic/browser-agent), você deve atualizar manualmente o valor `ajax.deny_list` na configuração `init` do seu aplicativo (ou copiá-lo novamente da interface) e, em seguida, recompilar e reimplantar seu aplicativo para que a alteração entre em vigor.
</Callout>

### Validar filtros de lista de negação [#validation]

Para validar se os filtros adicionados funcionam conforme o esperado, execute uma consulta NRQL para `AjaxRequest` evento correspondente ao seu filtro.

```sql
FROM AjaxRequest SELECT * WHERE requestUrl LIKE '%example.com%'
```

## Dados de captura de carga [#payload-capture]

<Callout variant="important">
  A captura de carga requer o agente do browser versão [1.317.0](/docs/release-notes/new-relic-browser-release-notes/browser-agent-release-notes) ou superior.
</Callout>

Você pode habilitar a captura de carga para todos os requests ou apenas para requests com falha. Quando habilitado, o agente do browser captura as cargas de request e resposta para todas as chamadas AJAX para todos os domínios permitidos. Isso é útil para depurar falhas que não são visíveis apenas pelos metadados, como erros ocultos nos corpos de resposta.

Quando você habilita a captura de carga AJAX, o agente do browser adiciona os seguintes atributos aos eventos `AjaxRequest`:

* `requestBody`: a carga da solicitação.
* `requestHeaders`: cabeçalhos de solicitação como JSON.
* `requestQuery`: parâmetros de consulta de URL como JSON.
* `responseBody`: a carga da resposta.
* `responseHeaders`: cabeçalhos de resposta como JSON.
* `ajaxRequest.id`: identificador único para cada requisição AJAX.

Todos os atributos de dados da carga são truncados em 4096 bytes. Quando ocorre o truncamento, os últimos 4 bytes são substituídos por `...` para indicar que o conteúdo foi cortado.

### Habilitar captura de carga [#enable-payload-capture]

Você pode habilitar a captura de carga usando um dos seguintes métodos:

<CollapserGroup>
  <Collapser id="enable-ui" title="Habilite via plataforma New Relic">
    Para habilitar a captura de carga:

    1. Vá para <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Browser &gt; (select an app) &gt; Settings &gt; Application settings**</DNT>.

    2. Na seção <DNT>**AJAX data capture settings**</DNT>, habilite o botão de alternância <DNT>**Capture payload for allowed domains**</DNT> e, em seguida, selecione o modo de captura:

       * <DNT>**Capture only failure responses**</DNT>: captura carga apenas para requests com um código de status de `0`, um código de `400` ou superior, ou uma assinatura de erro do GraphQL no `response body`.
       * <DNT>**Capture all responses**</DNT>: captura cargas para todos os requests, incluindo os bem-sucedidos. Use isso para depurar falhas ocultas nos corpos de resposta, como erros do GraphQL retornados com um status de sucesso.

       <Callout variant="important">
         Habilitar a captura de carga para <DNT>**Capture all responses**</DNT> requests pode aumentar a ingestão de dados. Use o modo <DNT>**Capture only failure responses**</DNT>, a menos que você precise especificamente capturar respostas bem-sucedidas.
       </Callout>

    3. Clique em <DNT>**Save**</DNT> para aplicar as alterações.
  </Collapser>

  <Collapser id="configure-nerdgraph" title="Configurar via NerdGraph">
    Você pode usar a [API NerdGraph para consultar e atualizar](/docs/apis/nerdgraph/examples/browser-monitoring-config-nerdgraph/#configure-payload-capture) a configuração de captura de carga.

    Os seguintes valores estão disponíveis para a configuração `capture_payloads`:

    * `"none"`: não captura nenhum dado de carga. Esta é a configuração padrão.
    * `"failures"`: captura carga apenas para requests com um código de status de `0`, um código de `400` ou superior, ou uma assinatura de erro do GraphQL no `response body`.
    * `"all"`: captura dados de carga para todos os requests, independentemente do código de status.
  </Collapser>

  <Collapser id="configure-init" title="Configurar via JavaScript">
    Se você estiver usando o método de instalação de copiar/colar ou NPM, poderá configurar a captura de carga diretamente na sua configuração do JavaScript.

    #### Copiar/colar instalação

    Adicione a configuração `ajax.capture_payloads` à configuração do seu navegador antes do carregador do agente:

    ```js
    window.NREUM.init = {
        ...<other init properties>...,
        ajax: {
          deny_list: ["bam.nr-data.net"],
          capture_payloads: 'failures' // or 'none', 'all'
        }
    }
    ```

    #### Instalação NPM

    Adicione a configuração `ajax.capture_payloads` ao inicializar o agente do browser:

    ```js
    import { BrowserAgent } from '@newrelic/browser-agent/loaders/browser-agent'

    const options = {
      init: {
        ...<other init properties>...,
        ajax: {
          deny_list: ["bam.nr-data.net"],
          capture_payloads: 'failures' // or 'none', 'all'
        }
      },
      info: { ... },
      loader_config: { ... }
    }

    new BrowserAgent(options)
    ```

    #### Modos de captura

    Os seguintes valores estão disponíveis para a configuração `capture_payloads`:

    * `"none"`: não captura nenhum dado de carga. Esta é a configuração padrão.
    * `"failures"`: captura carga apenas para requests com um código de status de `0`, um código de `400` ou superior, ou uma assinatura de erro do GraphQL no `response body`.
    * `"all"`: captura dados de carga para todos os requests, independentemente do código de status.
  </Collapser>
</CollapserGroup>

Quando você habilita a captura de carga pela primeira vez, a New Relic adiciona automaticamente regras de ofuscação de baseline para proteger dados confidenciais comuns:

* [**Números de cartão de crédito**](/docs/browser/new-relic-browser/configuration/obfuscate-browser-agent-data/#ccn): detecta e mascara os principais formatos de cartão de crédito (Visa, MasterCard, American Express, Discover, etc.)
* [**Números de Seguro Social**](/docs/browser/new-relic-browser/configuration/obfuscate-browser-agent-data/#ssn): detecta e mascara padrões de SSN

Você pode configurar regras de ofuscação na plataforma New Relic para mascarar dados confidenciais antes que sejam enviados para a New Relic. Para obter mais detalhes sobre regras de ofuscação, consulte [Ofuscar dados do agente do browser](/docs/browser/new-relic-browser/configuration/obfuscate-browser-agent-data).

Após habilitar a configuração de captura de carga, você pode visualizar os dados de carga capturados nas seguintes páginas:

* [Detalhes da solicitação AJAX](/docs/browser/browser-monitoring/browser-pro-features/ajax-page-identify-time-consuming-calls)
* [Visualização de página](/docs/browser/new-relic-browser/browser-pro-features/page-views-examine-page-performance)
* [Session Replay](/docs/browser/browser-monitoring/browser-pro-features/session-replay/get-started)

### Como a captura de carga interage com a lista de negação [#payload-deny-list]

A captura de carga respeita sua lista de negação existente. Para qualquer requisição AJAX:

* Se o URL estiver na lista de negação, o evento é totalmente descartado e não são capturados metadados ou carga.
* Se o URL não estiver na lista de negação, com base nas suas configurações de captura de carga, o agente captura a carga de solicitação e resposta e aplica regra de ofuscação antes de enviar os dados para a New Relic.
