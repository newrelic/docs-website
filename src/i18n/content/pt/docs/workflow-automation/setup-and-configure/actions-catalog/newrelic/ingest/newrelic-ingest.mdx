Esta página fornece uma referência para todas as ações de ingestão do New Relic disponíveis no catálogo de ações de automação do fluxo de trabalho. Essas ações permitem que você envie eventos, logs e métricas para o New Relic a partir dos seus fluxos de trabalho.

## Pré-requisitos

Antes de usar as ações do New Relic Ingest na automação de fluxo de trabalho, certifique-se de ter:

* Uma conta New Relic com as permissões apropriadas.
* Uma chave de licença New Relic (necessária ao enviar dados para uma conta diferente da conta de execução do fluxo de trabalho).

Consulte [Chave de licença](/docs/apis/intro-apis/new-relic-api-keys#license-key) para obter informações sobre como criar e gerenciar a Chave de licença da sua conta New Relic.
