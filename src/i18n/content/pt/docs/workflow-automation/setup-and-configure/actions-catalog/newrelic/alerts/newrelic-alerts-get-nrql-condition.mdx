O identificador da ação é `newrelic.alerts.getNrqlCondition`.

Recupera os detalhes de uma única condição do alerta NRQL. Funciona para ambos os tipos de condição estática e de baseline.

              steps:

                  type: action
                  action: newrelic.alerts.getNrqlCondition
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    id: ${{ .workflowInputs.conditionId }}
                    selectors:
                      - name: conditionName
