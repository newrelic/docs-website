Esta página fornece uma referência para as ações do AWS EventBridge disponíveis no catálogo de ações de automação de fluxo de trabalho. Use essas ações para emitir eventos, gerenciar o estado da regra e executar operações de arquivo, repetição e origem de evento de parceiro.

## Pré-requisitos

Antes de usar as ações AWS na automação do fluxo de trabalho, certifique-se de ter:

* Uma conta da AWS com as permissões apropriadas.
* Credenciais da AWS configuradas (credenciais de usuário do IAM, ARN da função do IAM ou credenciais de sessão).
* As permissões do IAM necessárias para o EventBridge. No mínimo, a função ou o usuário do IAM precisa de `events:*` nos recursos de destino.

Consulte [Configurar credenciais da AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials/) para obter informações sobre como criar usuários e funções do IAM, e configurar credenciais da AWS estáticas e de sessão para integração com ações da AWS de automação de fluxo de trabalho.
