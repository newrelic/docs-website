O identificador da ação é `newrelic.alerts.updateBaselineNrqlCondition`.

Atualiza uma condição do alerta NRQL baseline existente. Todos os campos, exceto `accountId` e `id`, são opcionais — apenas os campos fornecidos são alterados; os campos omitidos mantêm seu valor atual.

              steps:
                - name: updateBaselineCondition
                  type: action
                  action: newrelic.alerts.updateBaselineNrqlCondition
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    id: ${{ .workflowInputs.conditionId }}
