Atualiza uma issue existente em um repositório do GitHub (título, corpo, estado, responsáveis, rótulos e marco).

Para a configuração de autenticação, consulte as [ações de issue do GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-issue).

              description: Update a GitHub issue
              steps:
                - name: update_issue
                  type: action
                  action: gitHub.issue.update
                  version: 1
                  inputs:
                    token: ${{ :secrets:github-PAT-token }}
                    owner: your_user_name
                    repo: test-workflow
                    issueNumber: 7
                    title: Issue has been resolved
                    body: Investigation complete. Closing this issue.
                    state: closed
                    state_reason: completed
                    labels:
                      - resolved
                  next: end
