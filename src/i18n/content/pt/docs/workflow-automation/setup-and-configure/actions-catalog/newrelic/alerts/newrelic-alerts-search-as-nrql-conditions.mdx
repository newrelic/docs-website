O identificador da ação é `newrelic.alerts.searchAsNrqlConditions`.

Pesquisa condições do alerta clássicas (legado) em seu formato convertido para NRQL. Oferece suporte a filtragem opcional por nome, política ou produto de origem e paginação baseada em cursor.

              ```yaml
              name: search_as_nrql_conditions
              description: Search classic conditions in NRQL format
              steps:
                - name: searchAsNrqlConditions
                  type: action
                  action: newrelic.alerts.searchAsNrqlConditions
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    nameLike: "error rate"
                    selectors:
                      - name: nrqlConditions
                        expression: ".data.actor.account.alerts.asNrqlConditionsSearch.nrqlConditions"
                  next: end
              ```
