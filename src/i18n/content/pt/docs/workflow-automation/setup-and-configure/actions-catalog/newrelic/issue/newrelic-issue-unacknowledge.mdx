Reverte um problema previamente reconhecido da Inteligência de Alerta do New Relic para um estado não reconhecido.

Para pré-requisitos, consulte as [ações de Issue de New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/issue/newrelic-issue#prerequisites).

## Não reconhecer problema

O identificador da ação é `newrelic.issue.unacknowledge`.

Reverte um problema do New Relic (AI Issues) previamente reconhecido de volta para um estado não reconhecido, limpando os campos `acknowledgedBy` / `acknowledgedAt` no registro do problema. Desenvolvido em `newrelic.nerdgraph.execute`.
