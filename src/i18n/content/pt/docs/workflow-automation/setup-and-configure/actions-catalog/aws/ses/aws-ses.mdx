Esta página fornece uma referência para as ações do AWS Simple Email Service (SES) disponíveis no catálogo de ações de automação de fluxo de trabalho. Use estas ações para criar, atualizar, recuperar e excluir modelos de e-mail e para enviar e-mails pelo Amazon SES.

## Pré-requisitos

Para pré-requisitos e configuração de credenciais, consulte [Configurar credenciais da AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials).

## Criar um modelo

O identificador da ação é `aws.ses.createTemplate`.

<Callout variant="important">

</Callout>

```yaml
    next: end
```

## Enviar e-mails em massa com modelo

O identificador da ação é `aws.ses.sendBulkTemplatedEmail`.

Envia um e-mail com modelo para vários destinatários em uma única chamada, com substituição de dados do modelo por destinatário. O endereço `source` e o `template` referenciado já devem existir.

<Callout variant="important">
  A AWS limita esta ação a 50 entradas `destinations` por chamada, com até 50 destinatários (combinando Para/Cc/Cco) por destino e um tamanho máximo de mensagem gerada de 10 MB. Exceder qualquer um desses limites produz um erro de API da AWS no momento do envio.
</Callout>

Cada entrada em `destinations` aceita os seguintes campos:

* `destination` — **Obrigatório.** Objeto com `toAddresses`, `ccAddresses` e/ou `bccAddresses` (cada um sendo uma lista de strings).
* `replacementTemplateData` — **Opcional.** String JSON de valores de espaço reservado por destinatário. Substitui `defaultTemplateData` para este destinatário.
* `replacementTags` — **Opcional.** Lista de objetos `{"name": "...", "value": "..."}` que substituem `defaultTags` para este destinatário.
