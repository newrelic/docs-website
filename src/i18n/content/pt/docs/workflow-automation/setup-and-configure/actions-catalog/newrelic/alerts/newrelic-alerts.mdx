Esta página fornece uma referência para todas as ações de alertas do New Relic disponíveis no catálogo de ações de automação de fluxo de trabalho. Essas ações permitem criar, atualizar, excluir, obter e pesquisar políticas de alertas, condições NRQL (estáticas e baseline), condições compostas e regras de silenciamento diretamente de um fluxo de trabalho.

## Pré-requisitos

Antes de usar as ações de alertas do New Relic na automação de fluxo de trabalho, certifique-se de ter:

* Uma conta da New Relic com as permissões apropriadas para gerenciar alertas.
* Um ID de conta da New Relic para a conta onde os recursos de alerta residem.
