Adiciona uma ou mais tags a uma entidade do New Relic, mantendo quaisquer tags existentes.

Para pré-requisitos, consulte [Ações de tag do New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites).

## Adicionar etiqueta

O identificador da ação é `newrelic.tagging.addTags`.

Adiciona uma ou mais tags a uma entidade do New Relic. Adicionar um valor a uma chave que já existe o anexa em vez de substituí-lo. Construído em `newrelic.nerdgraph.execute`.
