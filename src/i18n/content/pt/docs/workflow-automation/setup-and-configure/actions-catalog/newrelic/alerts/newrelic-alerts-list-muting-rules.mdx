O identificador da ação é `newrelic.alerts.listMutingRules`.

Lista as regras de silenciamento para uma conta. Opcionalmente, filtra pelo estado ativado. Esta ação não é paginada por cursor e retorna todas as regras correspondentes em uma única resposta.
