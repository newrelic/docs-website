Recupera a execução de fluxo de trabalho do GitHub Actions mais recente para um fluxo de trabalho específico. Útil quando o ID exato da execução é desconhecido — por exemplo, imediatamente após acionar uma execução. Sempre retorna no máximo uma execução.

Para a configuração de autenticação, consulte as [ações de execução de fluxo de trabalho do GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run).

<tr>
<td>
```yaml
name: get_latest_workflow_run
description: Retrieve the most recent workflow run for a specific workflow
steps:
  - name: get_latest_run
    type: action
    action: gitHub.workflowRun.getLatest
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      workflowId: deploy.yml
      branch: main
      event: workflow_dispatch
      selectors:
        - name: runId
          expression: ".workflow_runs[0].id"
        - name: conclusion
          expression: ".workflow_runs[0].conclusion"
        - name: htmlUrl
          expression: ".workflow_runs[0].html_url"
    next: end
```
</td>
