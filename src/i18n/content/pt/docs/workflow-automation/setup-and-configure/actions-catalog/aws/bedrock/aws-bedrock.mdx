Esta página fornece uma referência para as ações do AWS Bedrock disponíveis no catálogo de ações de automação de fluxo de trabalho. Use essas ações para invocar agentes do Bedrock como parte das definições do seu fluxo de trabalho.

## Pré-requisitos

Para pré-requisitos e configuração de credenciais, consulte [Configurar credenciais da AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials).

## Invocar um agente do Bedrock

O identificador da ação é `aws.bedrock.invokeAgent`.

Invoca um agente do AWS Bedrock com um prompt e retorna a resposta do agente.
