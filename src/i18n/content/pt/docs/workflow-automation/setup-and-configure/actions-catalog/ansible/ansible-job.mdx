Esta página fornece uma referência para todas as ações de job do Ansible disponíveis no catálogo de ações de automação de fluxo de trabalho. Use essas ações para lançar e monitorar modelos de job da Ansible Automation Platform (Automation Controller) a partir dos seus fluxos de trabalho.

## Pré-requisitos

Antes de usar as ações do Ansible na automação de fluxo de trabalho, você precisa:

* Uma instância da plataforma Ansible Automation (Automation Controller) acessível por HTTPS.
* Um token OAuth2 com escopo de gravação para lançar jobs (crie um em **Automation Controller &gt; Users &gt; Tokens**).
* Um ID numérico de template de job para o template que se deseja lançar.
* A configuração `ask_*_on_launch` habilitada no modelo de job para cada entrada opcional que se planeja usar (`extraVars`, `limit`, `inventory`).
