Esta página fornece uma referência para as ações do AWS Step Functions disponíveis no catálogo de ações de automação de fluxo de trabalho. Use essas ações para iniciar, parar, reexecutar e inspecionar execuções e máquinas de estado do Step Functions a partir das definições do seu fluxo de trabalho.

## Pré-requisitos

Antes de usar as ações do AWS Step Functions na automação de fluxo de trabalho, certifique-se de ter:

* Uma conta da AWS com as permissões apropriadas.
* Credenciais da AWS configuradas (credenciais de usuário do IAM, ARN da função do IAM ou credenciais de sessão).
* As permissões do IAM necessárias para as operações do Step Functions.

Consulte [Configurar credenciais da AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials/) para obter informações sobre como criar usuários e funções do IAM, e configurar credenciais da AWS estáticas e de sessão para integração com ações da AWS de automação de fluxo de trabalho.

## Permissões IAM necessárias

As permissões necessárias dependem de quais ações do Step Functions o seu fluxo de trabalho chama. Use o exemplo abaixo como um modelo para uma política de privilégio mínimo que abrange todas as sete ações.

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "states:StartExecution",
        "states:StopExecution",
        "states:RedriveExecution",
        "states:DescribeExecution",
        "states:ListExecutions",
        "states:DescribeStateMachine",
        "states:ListStateMachines"
      ],
      "Resource": "arn:aws:states:<region>:<account-id>:*"
    }
  ]
}
```

<Callout variant="important">
  Substitua `<region>` e `<account-id>` por seus valores reais e restrinja o `Resource` a ARNs de máquina de estado ou de execução específicos, sempre que possível.
</Callout>

## Iniciar uma execução do Step Functions

O identificador da ação é `aws.stepFunctions.startExecution`.

Inicia uma execução de uma máquina de estado do AWS Step Functions. Em caso de sucesso, retorna o `executionArn` da nova execução, que pode ser passado para [`aws.stepFunctions.describeExecution`](#describe-a-step-functions-execution) para consultar seu status.

## Interromper uma execução do Step Functions

O identificador da ação é `aws.stepFunctions.stopExecution`.

Interrompe uma execução do Step Functions em andamento. A AWS marca a execução como `ABORTED` assim que ela é interrompida.

<Callout variant="important">
  Esta ação é compatível apenas com máquinas de estado `STANDARD`. Ela não pode parar execuções `EXPRESS`.
</Callout>

## Fazer o redrive de uma execução do Step Functions

O identificador da ação é `aws.stepFunctions.redriveExecution`.

Reexecuta uma execução do Step Functions com falha, com tempo limite esgotado ou abortada, retomando-a do último estado malsucedido sem começar do início.

<Callout variant="important">
  Esta ação é compatível apenas com máquinas de estado `STANDARD`. Uma execução só pode ser reexecutada se não tiver `SUCCEEDED`, estiver dentro de 14 dias após a conclusão e tiver menos de 24.999 eventos de histórico.
</Callout>

## Descrever uma execução do Step Functions

O identificador da ação é `aws.stepFunctions.describeExecution`.

Retorna o status, a entrada, a saída e os timestamps de uma execução do Step Functions. Use esta ação para consultar o resultado de uma execução iniciada por [`aws.stepFunctions.startExecution`](#start-a-step-functions-execution).

<Callout variant="important">
  Esta ação oferece suporte direto a execuções de máquina de estado `STANDARD`. Você só pode descrever execuções `EXPRESS` que um Map Run despachou.
</Callout>

              ```yaml
                  type: action
                  action: aws.stepFunctions.describeExecution

                  inputs:

                    region: us-east-1
                    executionArn: ${{ .workflowInputs.executionArn }}
                    selectors:
                      - name: status
                        expression: '.response.status'
                      - name: output
                        expression: '.response.output'
              ```
