Esta página fornece uma referência para as ações de configuração do New Relic Logs disponíveis no catálogo de ações de automação de fluxo de trabalho. Essas ações podem ser usadas para consultar recursos de configuração de log — regras de análise, regras de partição de dados, expressão de ofuscação e regra de ofuscação, e configurações de pipeline — e realizar operações como validar padrões Grok e atualizar a configuração de pipeline, diretamente de uma definição de fluxo de trabalho.

## Pré-requisitos

Antes de usar as ações de configuração do New Relic Logs na automação de fluxo de trabalho, certifique-se de ter:

* Uma conta New Relic com as permissões apropriadas para acessar a configuração de gerenciamento de logs.
* O ID da conta para cada conta cuja configuração de log você deseja consultar ou atualizar.
