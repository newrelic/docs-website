Esta página fornece uma referência para as ações do AWS S3 disponíveis no catálogo de ações de automação de fluxo de trabalho. Use essas ações para listar, recuperar, fazer upload e excluir objetos em buckets do Amazon S3.

## Pré-requisitos

Para pré-requisitos e configuração de credenciais, consulte [Configurar credenciais da AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials).

## Listar objetos em um bucket

O identificador da ação é `aws.s3.listObjectsV2`.

Retorna alguns ou todos (até 1.000) os objetos em um bucket com seus metadados. É a versão recomendada de `listObjects`.

```yaml
name: aws-s3-list-objects-v2
description: 'List Objects in an AWS S3 Bucket'
steps:
  - name: aws_s3_listObjectsV2_1
    type: action
    action: aws.s3.listObjectsV2
    version: '1'
    inputs:
      awsRoleArn: "arn:aws:iam::123456789012:role/my-workflow-role"
      region: "us-east-2"
      bucket: "examplebucket"
      prefix: "path/to/folder/"
      maxKeys: 100
    next: end
```
