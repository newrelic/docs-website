Esta página fornece uma referência para as ações do New Relic Secrets Management disponíveis no catálogo de ações de automação de fluxo de trabalho. Essas ações permitem listar segredos e inspecionar seu histórico de versões diretamente de uma definição de fluxo de trabalho.

<Callout variant="important">
Não há nenhuma ação para recuperar o valor de um segredo. Descriptografar um segredo por meio de uma ação de fluxo de trabalho exporia o valor no histórico e nos logs da execução. Para usar o valor de um segredo como entrada para uma etapa de fluxo de trabalho, referencie-o diretamente usando a sintaxe `${{ :secrets:keyName }}`.
</Callout>

## Pré-requisitos

Antes de usar as ações de segredo do New Relic na automação de fluxo de trabalho, certifique-se de ter:

* Uma conta New Relic com as permissões apropriadas para ler o Secrets Management.
* O `scopeId` (ID da conta ou ID da organização) e `scopeType` (`ACCOUNT` ou `ORGANIZATION`) para o escopo que você deseja consultar.

```yaml

description: List all versions of a New Relic secret
steps:
  - name: listSecretVersions
    type: action
    action: newrelic.secret.listVersions
    version: 1
    inputs:
      key: "jira_auth_token"
      scopeId: "11933347"
      scopeType: "ACCOUNT"
      fetchDeleted: true
      selectors:
        - name: latestVersion
          expression: ".data.customerAdministration.secretVersions.latestVersion"
    next: end
```
