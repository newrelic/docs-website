O identificador da ação é `newrelic.alerts.searchPolicies`.

Pesquisa políticas de alertas com filtragem opcional por ID ou nome. Suporta paginação baseada em cursor. Omitir todos os filtros retorna todas as políticas na conta.

              name: search_alert_policies
              description: Search alert policies by name
              steps:
                - name: searchPolicies
                  type: action
                  action: newrelic.alerts.searchPolicies
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    nameLike: "Production"
                    selectors:
                      - name: policies
                        expression: ".data.actor.account.alerts.policiesSearch.policies"
                  next: end
