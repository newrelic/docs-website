Consulta e lista problemas de Inteligência de alerta do New Relic para uma conta com filtragem e paginação opcionais.

Para pré-requisitos, consulte as [ações de Issue de New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/issue/newrelic-issue#prerequisites).

## Listar problemas

O identificador da ação é `newrelic.issue.list`.

Consulta e lista os problemas do New Relic (problemas de IA) para uma conta, retornando o status em tempo real, a linha do tempo, as entidades correlacionadas e os detalhes de impacto para problemas ativos ou passados. Oferece suporte à filtragem por estado, prioridade, origem, entidade, condição, política, status de correlação e reconhecimento, uma janela de tempo e paginação baseada em cursor. Desenvolvido em `newrelic.nerdgraph.execute`.

            <td>
              Sem filtros — lista todos os problemas na conta, independentemente do estado, prioridade ou outros filtros. Apenas `accountId` é obrigatório:

              ```yaml
              name: newrelic_issue_list_all
              description: list all issues for an account with no filters
              steps:
                - name: newrelic_issue_list
                  type: action
                  action: newrelic.issue.list
                  version: 1
                  inputs:
                    accountId: 123456
                  next: end
              ```

              O exemplo a seguir usa filtros básicos para listar problemas ativos e de alta prioridade para uma conta:

              ```yaml
              name: newrelic_issue_list_workflow
              description: list newrelic issues
              steps:
                - name: newrelic_issue_list
                  type: action
                  action: newrelic.issue.list
                  version: 1
                  inputs:
                    accountId: 123456
                    states: ["ACTIVATED", "CREATED"]
                    priority: ["CRITICAL", "HIGH"]
                  next: end
              ```

              O exemplo a seguir usa múltiplos filtros para problemas críticos, não silenciados e não reconhecidos dentro de uma janela de tempo específica, com seletores achatando a resposta para paginação:

              ```yaml
              name: newrelic_issue_list_advanced
              description: list unacknowledged critical issues in a time window
              steps:
                - name: newrelic_issue_list
                  type: action
                  action: newrelic.issue.list
                  version: 1
                  inputs:
                    accountId: 123456
                    states: ["ACTIVATED"]
                    priority: ["CRITICAL"]
                    isAcknowledged: false
                    mutingStates: ["NOT_MUTED"]
                    startTime: 1785900000000
                    endTime: 1785998400000
                    selectors:
                      - name: issues
                        expression: ".data.actor.account.aiIssues.issues.issues"
                      - name: nextCursor
                        expression: ".data.actor.account.aiIssues.issues.nextCursor"
                  next: end
              ```

              Para percorrer os resultados adicionais do terceiro exemplo, utilize a saída `nextCursor` e passe-a novamente como a entrada `cursor` em uma chamada subsequente.
