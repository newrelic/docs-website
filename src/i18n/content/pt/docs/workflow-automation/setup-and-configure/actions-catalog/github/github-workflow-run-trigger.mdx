Aciona a execução de um fluxo de trabalho do GitHub Actions por meio de um evento `workflow_dispatch`. O fluxo de trabalho de destino deve ter um gatilho `workflow_dispatch` configurado. O GitHub retorna HTTP 204 No Content em caso de sucesso.

Para a configuração de autenticação, consulte as [ações de execução de fluxo de trabalho do GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run).

```yaml
name: trigger_github_workflow
description: Trigger a GitHub Actions workflow run
steps:
  - name: trigger_run
    type: action
    action: gitHub.workflowRun.trigger
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      workflowId: deploy.yml
      ref: main
      inputs:
        environment: staging
        version: "1.2.3"
    next: end
```
