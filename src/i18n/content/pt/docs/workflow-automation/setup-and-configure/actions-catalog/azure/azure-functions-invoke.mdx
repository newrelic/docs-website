A ação de invocação do Azure Functions permite chamar qualquer Azure Function acionada por HTTP diretamente dos fluxos de trabalho. Ela fornece uma interface suportada e validada para invocar o Azure Functions — com entradas tipadas, validação de URL e autenticação baseada em segredos — em vez de construir chamadas HTTP brutas.

## Invocar uma função Azure [#azure-functions-invoke]

Esta ação envia uma solicitação HTTP para um endpoint do Azure Function e retorna a resposta. A autenticação usa o mecanismo de chave de função do Azure; o fluxo de trabalho o passa como o cabeçalho `x-functions-key`.

    <TabsPageItem id="azurefunctionsinvokeexample">
      ### Exemplo: acionar uma função de correção

      ```yaml
      name: azure-function-invoke-remediation

      steps:
        - name: invokeRemediationFunction
          type: action
          action: azure.functions.invoke
          version: 1
          inputs:
            function: "https://remediation.azurewebsites.net/api/fix-incident"
            key: ${{ :secrets:azure:functionKey }}
            method: "POST"
            body: '{"incidentId":"${{ .workflowInputs.incidentId }}"}'
      ```

      ### Exemplo: solicitação GET com parâmetros de consulta

      ```yaml
      name: azure-function-invoke-get

      steps:
        - name: getFromFunction
          type: action
          action: azure.functions.invoke
          version: 1
          inputs:
            function: "https://myapp.azurewebsites.net/api/GetStatus"
            key: ${{ :secrets:azure:functionKey }}
            method: "GET"
            queryParameters: "env=prod&region=eastus"
      ```

      ### Exemplo: invocar uma função e registrar o resultado

      ```yaml
      name: azure-function-invoke-and-log

      steps:
        - name: invokeFunction
          type: action
          action: azure.functions.invoke
          version: 1
          inputs:
            function: "https://myapp.azurewebsites.net/api/RunCheck"
            key: ${{ :secrets:azure:functionKey }}
            method: "POST"
            body: '{"target":"${{ .workflowInputs.target }}"}'
            headers:
              Content-Type: "application/json"

        - name: logFunctionResult
          type: action
          action: newrelic.ingest.sendLogs
          version: 1
          inputs:
            logs:
              - message: "Azure Function invocation complete"
                attributes:
                  success: ${{ .steps.invokeFunction.outputs.success }}
                  statusCode: ${{ .steps.invokeFunction.outputs.statusCode }}
                  response: ${{ .steps.invokeFunction.outputs.response }}
      ```
