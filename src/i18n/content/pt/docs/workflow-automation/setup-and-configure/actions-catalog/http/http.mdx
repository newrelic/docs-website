Esta página fornece uma referência para todas as ações HTTP disponíveis no catálogo de ações de automação de fluxo de trabalho. Use essas ações para fazer requests HTTP para qualquer API REST, webhook ou serviço web a partir de uma etapa do fluxo de trabalho.

## Pré-requisitos

Antes de usar ações HTTP na automação de fluxo de trabalho, certifique-se de ter:

* endpointde destino de URLs API.
* Quaisquer credenciais de autenticação necessárias (chaves de API, tokens ou outros cabeçalhos).
* Uma compreensão dos formatos de requisição e resposta da API.

<Callout variant="tip">
  Ações HTTP suportam sintaxe de segredo para qualquer valor de cabeçalho, permitindo que você passe dados sensíveis, como chaves de API, com segurança. Consulte [gerenciamento de segredos](/docs/workflow-automation/limitations-and-faq/workflow-best-practices#secure-credentials) para obter mais informações.
</Callout>
