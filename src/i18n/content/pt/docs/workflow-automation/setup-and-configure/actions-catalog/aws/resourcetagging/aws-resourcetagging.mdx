Esta página fornece uma referência para as ações da AWS Resource Groups Tagging API disponíveis no catálogo de ações de automação de fluxo de trabalho. Use essas ações para obter, adicionar, atualizar e remover tags em recursos da AWS em todos os serviços.

## Pré-requisitos

Para pré-requisitos e configuração de credenciais, consulte [Configurar credenciais da AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials).

## Obter tags por ARN

O identificador da ação é `aws.resourceGroupsTaggingApi.getResourceTags`.

Retorna as tags para um ou mais recursos da AWS especificados por ARN.

<Callout variant="important">
  Não é possível combinar `resourceArnList` com `tagFilters`, `resourceTypeFilters` ou entradas de paginação. A AWS rejeita essa combinação com um `InvalidParameterException`. Para encontrar recursos por tag ou tipo, utilize [`aws.resourceGroupsTaggingApi.getResourcesByTag`](#get-resources-by-tag) em vez disso.
</Callout>

```yaml
    type: action

    version: '1'
    inputs:
      awsRoleArn: "arn:aws:iam::123456789012:role/my-workflow-role"
      region: "us-east-2"
      resourceArnList:
        - "arn:aws:dynamodb:us-east-2:123456789012:table/my-table"
      selectors:
        - name: tags
          expression: ".response.ResourceTagMappingList"
    next: end
```

## Obter recursos por tag

O identificador da ação é `aws.resourceGroupsTaggingApi.getResourcesByTag`.

Encontra recursos da AWS por valor principal de tag e/ou tipo de recurso. Retorna apenas recursos com tag.

<Callout variant="important">
  Não é possível combinar `tagFilters` ou `resourceTypeFilters` com `resourceArnList` na mesma chamada. A AWS rejeita essa combinação com um `InvalidParameterException`. Para recuperar tags para ARNs específicos, use [`aws.resourceGroupsTaggingApi.getResourceTags`](#get-tags-by-arn) em vez disso.
</Callout>

## Adicionar ou atualizar tags em recursos

O identificador da ação é `aws.resourceGroupsTaggingApi.tagResources`.

Adiciona ou atualiza até 50 tags em 1–20 recursos da AWS em vários serviços em uma única chamada.

<Callout variant="important">
  A ação relata falhas parciais por ARN em `response.FailedResourcesMap` em vez de como um erro de nível superior. Verifique `response.FailedResourcesMap` mesmo quando `success` for `true`, porque um ARN com falha em um lote não causa falha na chamada inteira.
</Callout>

## Remover tags de recursos

O identificador da ação é `aws.resourceGroupsTaggingApi.untagResources`.

Remove uma ou mais tags de até 20 recursos da AWS em vários serviços em uma única chamada. A remoção de uma chave de tag que não existe em um recurso é bem-sucedida silenciosamente.

<Callout variant="important">
  A ação relata falhas parciais por ARN em `response.FailedResourcesMap` em vez de como um erro de nível superior. Verifique `response.FailedResourcesMap` mesmo quando `success` for `true`, porque um ARN com falha em um lote não causa falha na chamada inteira.

```yaml
name: remove-tags-from-resources
description: 'Remove tags from AWS resources'
steps:
  - name: untagResources
    type: action
    action: aws.resourceGroupsTaggingApi.untagResources
    version: '1'
    inputs:
      awsRoleArn: "arn:aws:iam::123456789012:role/my-workflow-role"
      region: "us-east-2"
      resourceArnList:
        - "arn:aws:sqs:us-east-2:123456789012:my-queue"
      tagKeys:
        - Environment
      selectors:
        - name: failedResources
          expression: ".response.FailedResourcesMap"
    next: end
```
