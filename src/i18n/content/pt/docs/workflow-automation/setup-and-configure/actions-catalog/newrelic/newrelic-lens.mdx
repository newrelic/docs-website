Esta página fornece uma referência para as ações do New Relic Lens disponíveis no catálogo de ações de automação de fluxo de trabalho. Estas ações permitem executar consultas ANSI SQL em fontes de dados conectadas por meio do New Relic Lens diretamente de uma etapa de fluxo de trabalho.

## Pré-requisitos

Antes de usar as ações do New Relic Lens na automação de fluxo de trabalho, é necessário ter:

* Uma conta New Relic com as permissões apropriadas.
* Uma ou mais fontes de dados conectadas no New Relic Lens.
* As permissões necessárias para o serviço New Relic Lens.
