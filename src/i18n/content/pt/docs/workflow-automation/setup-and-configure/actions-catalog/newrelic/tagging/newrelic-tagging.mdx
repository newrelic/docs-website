Esta página fornece uma referência para todas as ações de tag do New Relic disponíveis no catálogo de ações de automação de fluxo de trabalho. Essas ações permitem adicionar, substituir e remover tags em entidades do New Relic diretamente de seus fluxos de trabalho.

## Pré-requisitos

Antes de usar as ações de tag do New Relic na automação de fluxo de trabalho, certifique-se de ter:

* Uma conta New Relic com as permissões apropriadas para gerenciar tags de entidade.
