Remove o bloqueio de conversa de uma issue do GitHub, permitindo que todos os usuários adicionem novos comentários.

Para a configuração de autenticação, consulte as [ações de issue do GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-issue).
