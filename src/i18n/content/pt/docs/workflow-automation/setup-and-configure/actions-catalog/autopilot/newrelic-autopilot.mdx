Esta página fornece uma referência para a ação **Run Autopilot** (`newrelic.autopilot.run`) disponível no catálogo de ações de automação de fluxo de trabalho.

## Executar Autopilot [#newrelic-autopilot-run]

Executa o New Relic Autopilot — um agente de IA que analisa alertas, investiga possíveis causas raízes e sugere ações de remediação. É possível selecionar **Run Autopilot** no Catálogo de Ações do Editor de Fluxo de Trabalho — não é necessário especificar um ID de agente.

      ```yaml
      name: demo-run-autopilot
      description: Run Autopilot to analyze an issue
      steps:
        - name: runAutopilot
          type: action
          action: newrelic.autopilot.run
          version: '1'
          inputs:
            prompt: Summarize recent alert activity for my account
            context:
              - description: accountId
                value: "12345678"
              - description: slack_channel_id
                value: "CXXXXXXXXX"
            selectors:
              - name: success
                expression: .success
              - name: error
      ```
