Esta página fornece uma referência para as ações do AWS Athena disponíveis no catálogo de ações de automação de fluxo de trabalho. Use estas ações para executar consultas SQL no Amazon Athena, verificar seu status de execução e recuperar resultados diretamente de uma definição de fluxo de trabalho.

## Pré-requisitos

Para pré-requisitos e configuração de credenciais, consulte [Configurar credenciais da AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials).

## Iniciar a execução de uma consulta [#start-query-execution]

O identificador da ação é `aws.athena.startQueryExecution`.

Executa uma consulta SQL no Amazon Athena e retorna o ID de execução da consulta. Esta ação não aguarda a conclusão da consulta — use `aws.athena.getQueryExecution` para verificar o status e `aws.athena.getQueryResults` para recuperar os resultados.

**Exemplo**

```yaml
name: start-athena-query
description: Run a SQL query against Athena
steps:
  - name: startQuery
    type: action
    action: aws.athena.startQueryExecution
    version: '1'
    inputs:
      awsRoleArn: ${{ :secrets:awsRoleArn }}
      region: us-east-2
      queryString: "SELECT * FROM my_table LIMIT 10"
      database: "my-database"
      catalog: "AwsDataCatalog"
      outputLocation: "s3://my-athena-results-bucket/path/"
      workGroup: "primary"
      selectors:
        - name: queryExecutionId
          expression: ".response.QueryExecutionId"
    next: end
```

## Obter resultados da consulta [#get-query-results]

O identificador da ação é `aws.athena.getQueryResults`.

Retorna as linhas e os metadados de coluna de uma execução de consulta concluída do Athena. Os resultados são paginados — quando a resposta incluir um `NextToken`, passe-o como `nextToken` na próxima chamada para recuperar a página seguinte. A primeira linha de `ResultSet.Rows` é sempre a linha de cabeçalho (nomes das colunas).
