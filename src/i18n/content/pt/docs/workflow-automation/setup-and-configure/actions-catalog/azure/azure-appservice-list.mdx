Lista os aplicativos web do Azure App Service em um grupo de recursos. Retorna resultados paginados — se o grupo de recursos contiver aplicativos suficientes para abranger várias páginas, um campo `nextLink` é incluído na resposta para recuperar a próxima página.

Para a configuração de autenticação, consulte as [ações do Azure App Service](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-appservice).

Se a resposta incluir um campo `nextLink`, há páginas adicionais de resultados. Capture-o com um seletor e chame `azure.execute.api` diretamente com essa URL como `urlPath` para recuperar a próxima página.

<TabsPageItem id="azureappservicelistexample">
```yaml
name: listAzureAppServices
description: List Azure App Services in a resource group
steps:
  - name: list_app_services
    type: action
    action: azure.appService.list
    version: 1
    inputs:
      clientId: ${{ :secrets:azure-client-id }}
      clientSecret: ${{ :secrets:azure-client-secret }}
      tenantId: ${{ :secrets:azure-client-tenant }}
      subscriptionId: "12345678-1234-1234-1234-123456789abc"
      resourceGroupName: "my-resource-group"
      selectors:
        - name: appNames
          expression: "[.response.value[].name]"
        - name: nextLink
          expression: ".response.nextLink // \"\""
    next: end
```
