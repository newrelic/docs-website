O identificador da ação é `newrelic.notification.waitForStatus`.

Consulta o resultado da entrega de uma notificação enviada por uma etapa `newrelic.notification.send` anterior. Dado um `sessionId`, esta ação consulta `NrNotificationsEvent` até que a notificação atinja um status final (`SUCCESS` ou `FAIL`) ou o `timeout` especificado expire. Para destinos do Slack, também retorna o valor `thread_ts` necessário para responder na thread criada pela notificação.

<td>
```yaml
name: notify_and_wait
description: Send a Slack notification then wait for its delivery status
steps:
  - name: sendNotification
    type: action
    action: newrelic.notification.send
    version: 1
    inputs:
      type: slack
      destinationId: "your-destination-id"
      parameters:
        channel: "your-slack-channel"
        text: "Deployment finished"
      selectors:
        - name: sessionId
          expression: ".response.sessionId"
    next: waitForStatus

  - name: waitForStatus
    type: action
    action: newrelic.notification.waitForStatus
    version: 1
    inputs:
      sessionId: ${{ .steps.sendNotification.outputs.sessionId }}
      timeout: 15
      selectors:
        - name: deliveryStatus
          expression: ".notificationStatus.status"
        - name: threadTs
          expression: ".notificationStatus.threadTs"
    next: end
```
