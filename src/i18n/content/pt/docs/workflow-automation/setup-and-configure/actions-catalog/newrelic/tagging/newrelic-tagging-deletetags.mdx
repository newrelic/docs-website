Remove uma ou mais chaves de tag e todos os valores sob elas de uma entidade do New Relic.

Para pré-requisitos, consulte [Ações de tag do New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites).

## Excluir tags

O identificador da ação é `newrelic.tagging.deleteTags`.

Remove uma ou mais chaves de tag e todos os valores sob elas de uma entidade do New Relic. Para remover apenas valores específicos enquanto mantém outros valores sob a mesma chave, use [`newrelic.tagging.deleteTagValues`](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging-deletetagvalues) em vez disso. Desenvolvido em `newrelic.nerdgraph.execute`.
