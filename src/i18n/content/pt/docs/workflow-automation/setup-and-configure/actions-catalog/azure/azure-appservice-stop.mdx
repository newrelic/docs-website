Interrompe um aplicativo Web do Serviço de Aplicativo do Azure em execução. Você pode usar esta ação para desligar um aplicativo de forma programada, durante a manutenção ou como parte de um fluxo de trabalho de controle de custos.

Para a configuração de autenticação, consulte as [ações do Azure App Service](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-appservice).

<TabsPageItem id="azureappservicestopexample">
```yaml
name: stopAzureAppService
description: Stop a running Azure App Service
steps:
  - name: stop_app_service
    type: action
    action: azure.appService.stop
    version: 1
    inputs:
      clientId: ${{ :secrets:azure-client-id }}
      clientSecret: ${{ :secrets:azure-client-secret }}
      tenantId: ${{ :secrets:azure-client-tenant }}
      subscriptionId: "12345678-1234-1234-1234-123456789abc"
      resourceGroupName: "my-resource-group"
      appServiceName: "my-web-app"
    next: end
```
