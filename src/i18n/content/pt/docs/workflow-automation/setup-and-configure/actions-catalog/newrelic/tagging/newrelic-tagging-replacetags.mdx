Substitui todo o conjunto de tags de uma entidade New Relic pelas tags fornecidas.

Para pré-requisitos, consulte [Ações de tag do New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites).

## Substituir tags

O identificador da ação é `newrelic.tagging.replaceTags`.

Substitui todo o conjunto de tags de uma entidade New Relic pelas tags fornecidas. Esta ação é destrutiva: remove qualquer tag existente não incluída na entrada `tags`. Para adicionar tags sem remover as existentes, use [`newrelic.tagging.addTags`](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging-addtags) em vez disso. Desenvolvido em `newrelic.nerdgraph.execute`.
