Esta página fornece uma referência para todas as ações de incidente do PagerDuty disponíveis no catálogo de ações de automação de fluxo de trabalho. Use essas ações para criar, recuperar, listar, atualizar e resolver incidentes do PagerDuty diretamente de um fluxo de trabalho.

## Pré-requisitos

Antes de usar as ações do PagerDuty na automação de fluxo de trabalho, é necessário:

* Uma conta PagerDuty com as permissões apropriadas para gerenciar incidentes.
* Um token de API do PagerDuty (token de usuário ou token de conta).
* O endereço de e-mail `from` do usuário que faz a solicitação (necessário para tokens de conta em ações relevantes).
