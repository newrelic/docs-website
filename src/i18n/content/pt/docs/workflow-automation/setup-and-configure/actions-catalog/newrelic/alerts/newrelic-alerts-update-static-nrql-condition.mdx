O identificador da ação é `newrelic.alerts.updateStaticNrqlCondition`.

Atualiza uma condição do alerta NRQL estática existente. Todos os campos, exceto `accountId` e `id`, são opcionais — apenas os campos fornecidos são alterados; os campos omitidos mantêm seu valor atual.
