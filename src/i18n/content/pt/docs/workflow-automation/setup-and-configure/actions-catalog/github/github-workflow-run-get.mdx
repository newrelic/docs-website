Recupera os detalhes, o status e a conclusão de uma execução específica de fluxo de trabalho do GitHub Actions por seu Run ID numérico. O Run ID geralmente é obtido de uma etapa `gitHub.workflowRun.trigger` ou `gitHub.workflowRun.list` anterior.

Para a configuração de autenticação, consulte as [ações de execução de fluxo de trabalho do GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run).

<tr>
<td>
```yaml
name: poll_workflow_run
description: Get the status of a specific GitHub Actions workflow run
steps:
  - name: get_run
    type: action
    action: gitHub.workflowRun.get
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      runId: ${{ .steps.trigger_run.outputs.response.workflow_run_id }}
      selectors:
        - name: status
          expression: ".status"
        - name: conclusion
          expression: ".conclusion"
        - name: htmlUrl
          expression: ".html_url"
    next: end
```
</td>
