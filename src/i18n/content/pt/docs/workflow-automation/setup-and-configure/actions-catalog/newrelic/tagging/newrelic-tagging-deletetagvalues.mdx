Remove valores de tag específicos de uma entidade do New Relic, deixando outros valores sob a mesma chave inalterados.

Para pré-requisitos, consulte [Ações de tag do New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites).

## Excluir valores de tag

O identificador da ação é `newrelic.tagging.deleteTagValues`.

Remove pares específicos de valor principal da tag de uma entidade do New Relic. Mantemos outros valores sob a mesma chave. Para remover uma chave de tag inteira e todos os seus valores, use [`newrelic.tagging.deleteTags`](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging-deletetags) em vez disso. Desenvolvido em `newrelic.nerdgraph.execute`.
