O identificador da ação é `newrelic.alerts.updateMutingRule`.

Atualiza uma regra de silenciamento existente. Todos os campos, exceto `accountId` e `id`, são opcionais — apenas os campos fornecidos são alterados.

              description: Disable a muting rule
              steps:
                - name: updateMutingRule
                  type: action
                  action: newrelic.alerts.updateMutingRule
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    id: ${{ .workflowInputs.mutingRuleId }}
                    enabled: false
                  next: end
