Reporta eventos personalizados para o New Relic.

Para pré-requisitos, consulte as [ações do New Relic Ingest](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/ingest/newrelic-ingest#prerequisites).

## Enviar eventos para o New Relic

O identificador da ação é `newrelic.ingest.sendEvents`.

Reporta um evento personalizado ao New Relic.

    <TabsPageItem id="newrelic-ingest-send-events-example">
      O exemplo a seguir envia vários eventos personalizados com atributos compartilhados e por evento, e em seguida os recupera com uma consulta NRQL.

      <table>
        <thead>
          <tr>
            <th>
              Exemplo de fluxo de trabalho
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: heartbeat_newrelicIngestSendEvents

              workflowInputs:
                cellName:
                  type: String

              steps:
                - name: runAction
                  type: action
                  action: newrelic.ingest.sendEvents
                  version: 1
                  inputs:
                    attributes:
                      colour: red
                      id: 1234
                    events:
                      - eventType: HeartBeat
                        test: "OK"
                        attributes:
                          foo: bar
                      - eventType: HeartBeat1234
                        test: "OK1234"
                        attributes:
                          foo: bar
                      - eventType: HeartBeat12345
                        test: "OK12345"
                        attributes:
                          foo: bar
                          colour: yellow
                      - eventType: HeartBeat12345678
                        test: "OK12345678"
                    selectors:
                      - name: success
                        expression: ".success"
              ```

              **Resultado esperado:**

              ```yaml
                {
                  "success": true
                }
              ```

              **Recuperar evento:**

              Após executar um fluxo de trabalho com sucesso, você pode recuperar o evento associado executando uma consulta na conta que executou o fluxo de trabalho:

              ```sql
              SELECT * FROM HeartBeat
              ```
            </td>
