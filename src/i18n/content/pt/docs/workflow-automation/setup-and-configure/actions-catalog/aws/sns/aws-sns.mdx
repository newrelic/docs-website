Esta página fornece uma referência para as ações do AWS SNS disponíveis no catálogo de ações de automação de fluxo de trabalho. Use essas ações para publicar mensagens em tópicos do Amazon SNS.

## Pré-requisitos

Para pré-requisitos e configuração de credenciais, consulte [Configurar credenciais da AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials).

## Publicar uma mensagem em um tópico SNS

O identificador da ação é `aws.sns.publish`.

Envia uma mensagem para um tópico do Amazon SNS. Todos os assinantes do tópico receberão a mensagem.

```yaml
name: sns-publish-test
description: Publishes a notification to an SNS topic
workflowInputs:
  arnRole:
    type: String
steps:
  - name: aws_sns_publish_1
    type: action
    action: aws.sns.publish
    version: '1'
    inputs:
      awsRoleArn: ${{ .workflowInputs.arnRole }}
      region: us-east-1
      topicArn: arn:aws:sns:us-east-1:123456789012:workflow-test-topic
      subject: "Workflow Update"
      message: "The data processing workflow has completed successfully."
    next: end
```
