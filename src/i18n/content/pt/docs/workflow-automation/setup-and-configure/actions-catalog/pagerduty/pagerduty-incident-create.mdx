## Criar um incidente do PagerDuty

O identificador da ação é `pagerduty.incident.create`.

Cria um novo incidente no PagerDuty com o serviço, título, prioridade e outros atributos opcionais especificados.

      O exemplo a seguir cria um novo incidente do PagerDuty com um serviço, urgência, corpo e política de escalonamento.

          <tr>
            <td>
              ```yaml
              name: create-pagerduty-incident
              description: Create a new PagerDuty incident
              steps:
                - name: create
                  type: action
                  action: pagerduty.incident.create
                  version: 1
                  inputs:
                    token: ${{ :secrets:pagerdutyApiToken }}
                    type: incident
                    title: Test incident
                    service:
                      id: P123456
                      type: service_reference
                    urgency: low
                    body:
                      type: incident_body
                      details: Test Body
                    incidentKey: a12345-b678910-c111213
                    escalationPolicy:
                      id: P54321
                      type: escalation_policy_reference
                    selectors:
                      - name: incidentId
                        expression: .responseBody | fromjson.incident.id
                  next: end
              ```
