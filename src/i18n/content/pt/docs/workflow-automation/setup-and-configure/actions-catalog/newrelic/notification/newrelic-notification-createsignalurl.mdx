O identificador da ação é `newrelic.notification.createSignalUrl`.

Gera um URL para enviar a um usuário via <DNT>Microsoft Teams</DNT>, <DNT>Slack</DNT> ou <DNT>email</DNT> para que ele possa enviar um sinal a um fluxo de trabalho em execução. Esta ação impulsiona o [padrão human-in-the-loop](/docs/workflow-automation/workflow-examples/advanced/human-in-the-loop), em que um fluxo de trabalho pausa em uma etapa de espera até que uma pessoa clique no URL para aprovar, negar ou, de outra forma, rotear a execução.

<Callout variant="important">
  Esta ação não oferece nenhum benefício por si só. Sempre use esta ação com:

  * Uma **ação de notificação** (`newrelic.notification.*` ou `slack.chat.postMessage`) que entrega a URL gerada a uma pessoa.
  * Uma **etapa de espera** que define pelo menos um sinal para a execução do fluxo de trabalho aguardar.

  O `waitStepName` que você fornece como entrada deve corresponder ao nome de uma etapa de espera válida na mesma definição de fluxo de trabalho, e essa etapa de espera deve conter pelo menos um sinal. Caso contrário, a definição de fluxo de trabalho falhará na validação quando você a criar.
</Callout>

                    waitStepName: waitForApproval
                - name: newrelicNotificationMsTeam
                  type: action
                  action: newrelic.notification.sendMicrosoftTeams
                  version: 1
                  inputs:
                    destinationId: acc24dc2-d4fc-4eba-a7b4-b3ad0170f8aa
                    channel: "dev-channel"
                    teamName: "dev-team"
                    message: "To approve continue at: ${{ .steps.createApprovalUrls.outputs.url }}"
                - name: waitForApproval
                  type: wait
                  seconds: 3900 # 1 hour 5 minutes
                  signals:
                    - name: "approve"
                      next: logApproval
                    - name: "deny"
                      next: logDenial
