Esta página fornece uma referência para as ações de fila do Jenkins disponíveis no catálogo de ações de automação de fluxo de trabalho. Use essas ações para inspecionar e gerenciar as compilações que aguardam na fila de compilação do Jenkins.

## Pré-requisitos

Antes de usar as ações de fila do Jenkins na automação de fluxo de trabalho, é necessário:

* Um servidor Jenkins acessível a partir do New Relic Workflow Automation via HTTPS. Se a sua instância do Jenkins estiver atrás de um firewall ou em uma rede privada, permita o acesso de entrada do New Relic Workflow Automation.
* Um token de API do Jenkins para a conta na qual o fluxo de trabalho é executado. Gere um a partir do seu perfil de usuário do Jenkins: **Configure &gt; API Token &gt; Add new Token**.
* Um segredo no New Relic Secrets Service contendo o valor codificado em Base64 de `username:apiToken`. Referencie-o no fluxo de trabalho como `${{ :secrets:<keyName> }}`.

## Obter um item da fila do Jenkins

O identificador da ação é `jenkins.queue.getItem`.

Obtém detalhes do item da fila, incluindo o número do build assim que a execução é iniciada. Use esta ação para consultar a fila após acionar um build com [`jenkins.job.trigger`](/docs/workflow-automation/setup-and-configure/actions-catalog/jenkins/jenkins-job#trigger-a-jenkins-job) para recuperar o número do build necessário para outras ações de job.

O campo `executable.number` na resposta contém o número do build assim que o build começa a ser executado. É `null` enquanto o item ainda está na fila.

            <td>
              ```yaml
              name: poll-jenkins-queue
              description: 'Trigger a build and poll the queue until the build number is available'
              steps:
                - name: trigger_build
                  type: action
                  action: jenkins.job.trigger
                  version: 1
                  inputs:
                    authToken: ${{ :secrets:jenkinsAuthToken }}
                    url: "https://jenkins.example.com"
                    jobName: "my-application-build"
                    selectors:
                      - name: "queueId"
                        expression: ".queueId"
                  next: poll_queue

                - name: poll_queue
                  type: loop
                  for:
                    in: ${{ [range(0; 10)] }}
                    steps:
                      - name: get_queue_item
                        type: action
                        action: jenkins.queue.getItem
                        version: 1
                        inputs:
                          authToken: ${{ :secrets:jenkinsAuthToken }}
                          url: "https://jenkins.example.com"
                          queueId: ${{ .steps.trigger_build.outputs.queueId }}
                          selectors:
                            - name: "buildNumber"
                              expression: ".responseBody | fromjson.executable.number // null"

                      - name: check_if_started
                        type: switch
                        switch:
                          - condition: ${{ .steps.get_queue_item.outputs.buildNumber != null }}
                            next: end
                        next: wait_and_retry

                      - name: wait_and_retry
                        type: wait
                        seconds: 2
                        next: continue
              ```
            </td>

## Cancelar um build do Jenkins na fila

O identificador da ação é `jenkins.queue.cancel`.

Cancela um build do Jenkins na fila antes de iniciar a execução. Requer um `queueId` obtido de uma chamada `jenkins.job.trigger` anterior.

Esta ação falha se o build já tiver começado a ser executado. Para interromper um build já em execução, use [`jenkins.job.stop`](/docs/workflow-automation/setup-and-configure/actions-catalog/jenkins/jenkins-job#stop-a-running-jenkins-build) em vez disso.
