Esta página fornece uma referência para as ações do AWS DynamoDB disponíveis no catálogo de ações de automação de fluxo de trabalho. Você pode usar essas ações para ler, gravar, atualizar e excluir itens em tabelas do DynamoDB e para inspecionar ou modificar a configuração da tabela diretamente de uma definição de fluxo de trabalho.

## Pré-requisitos

Para pré-requisitos e configuração de credenciais, consulte [Configurar credenciais da AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials).

Todas as ações do DynamoDB aceitam as mesmas entradas de autenticação. Use `awsRoleArn` (recomendado) ou o par de chaves de acesso.

```yaml
name: put-dynamodb-item
description: Write an order item to DynamoDB
steps:
  - name: putOrderItem
    type: action
    action: aws.dynamodb.putItem
    version: '1'
    inputs:
      awsRoleArn: ${{ :secrets:awsRoleArn }}
      region: us-east-2
      tableName: Orders
      item:
        orderId: { "S": "123" }
        status: { "S": "PLACED" }
    next: end
```

## Fazer a varredura de uma tabela [#scan]

O identificador da ação é `aws.dynamodb.scan`.

Retorna itens de uma tabela ou índice do DynamoDB fazendo a varredura de toda a tabela, com filtragem opcional. Uma única resposta de varredura é limitada a 100 KB pela Automação de fluxo de trabalho (o limite do próprio DynamoDB é de 1 MB). Utilize `limit` e `exclusiveStartKey` para paginar por tabelas grandes.

<Callout variant="important">
A Automação de fluxo de trabalho impõe um limite de tamanho de saída de 100 KB por ação. `aws.dynamodb.scan` lança uma exceção de limite de tamanho de saída excedido quando a resposta ultrapassa esse limite, mesmo que possa estar dentro do próprio limite de 1 MB por resposta do DynamoDB. Use `limit` e `exclusiveStartKey` para paginar os resultados e permanecer dentro desse limite.
