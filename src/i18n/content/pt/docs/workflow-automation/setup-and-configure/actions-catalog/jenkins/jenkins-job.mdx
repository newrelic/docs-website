Esta página fornece uma referência para as ações de job do Jenkins disponíveis no catálogo de ações de automação de fluxo de trabalho. Use essas ações para acionar e gerenciar builds do Jenkins.

## Pré-requisitos

Antes de usar as ações de job do Jenkins na automação de fluxo de trabalho, você precisa:

* Um servidor Jenkins acessível a partir do New Relic Workflow Automation via HTTPS. Se a sua instância do Jenkins estiver atrás de um firewall ou em uma rede privada, permita o acesso de entrada do New Relic Workflow Automation.
* Um token de API do Jenkins para a conta na qual o fluxo de trabalho é executado. Gere um a partir do seu perfil de usuário do Jenkins: **Configure &gt; API Token &gt; Add new Token**.
* Um segredo no New Relic Secrets Service contendo o valor codificado em Base64 de `username:apiToken`. Referencie-o no fluxo de trabalho como `${{ :secrets:<keyName> }}`.
* Para jobs baseados em pasta, o caminho completo da pasta até o job usando `/` como separador (por exemplo, `deployments/production/my-job`).

## Acionar um job do Jenkins

O identificador da ação é `jenkins.job.trigger`.

Aciona uma compilação do Jenkins com parâmetros opcionais. Em caso de sucesso, retorna um `queueId` que você pode usar com [`jenkins.queue.getItem`](/docs/workflow-automation/setup-and-configure/actions-catalog/jenkins/jenkins-queue#jenkins-queue-getitem) para acompanhar o progresso da compilação e recuperar o número da compilação assim que a execução for iniciada.

## Obter o status de um build do Jenkins

O identificador da ação é `jenkins.job.getStatus`.

Obtém o status de um build de job do Jenkins. Use esta ação para consultar um build acionado por `jenkins.job.trigger`.

Para verificar uma build específica em vez da mais recente, forneça seu `buildNumber`. Obtenha o número da build consultando a fila com [`jenkins.queue.getItem`](/docs/workflow-automation/setup-and-configure/actions-catalog/jenkins/jenkins-queue#jenkins-queue-getitem) após acionar a build.

                  version: 1
                  inputs:
                    authToken: ${{ :secrets:jenkinsAuthToken }}
                    url: "https://jenkins.example.com"
                    jobName: "deployments/production-deploy"
                    buildNumber: 42
                    selectors:
                      - name: buildStatus
                        expression: ".responseBody | fromjson.result"
                      - name: isBuilding
                        expression: ".responseBody | fromjson.building"

                - name: handle_result
                  type: switch
                  switch:
                    - condition: ${{ .steps.check_build_status.outputs.buildStatus == "SUCCESS" }}
                      next: notify_success
                  next: notify_failure

    <TabsPageItem id="jenkins-job-getconsoleoutput-example">
      O exemplo a seguir recupera os logs do build e verifica se há erros.

      <table>
        <thead>
          <tr>
            <th>
              Exemplo de fluxo de trabalho
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: get-jenkins-build-logs
              description: 'Retrieve Jenkins build logs and check for errors'
              steps:
                - name: get_build_logs
                  type: action
                  action: jenkins.job.getConsoleOutput
                  version: 1
                  inputs:
                    authToken: ${{ :secrets:jenkinsAuthToken }}
                    url: "https://jenkins.example.com"
                    jobName: "deployments/production-deploy"
                    buildNumber: 142
                    selectors:
                      - name: buildLogs
                        expression: ".responseBody"
                      - name: hasErrors
                        expression: ".responseBody | contains(\"ERROR\") or contains(\"FAILED\")"

                - name: check_for_errors
                  type: switch
                  switch:
                    - condition: ${{ .steps.get_build_logs.outputs.hasErrors }}
                      next: handle_error
                  next: end
              ```
            </td>
          </tr>
