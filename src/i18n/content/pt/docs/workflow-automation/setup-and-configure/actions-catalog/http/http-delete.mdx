Esta página fornece uma referência completa para a ação &quot;http delete&quot; disponível no catálogo de ações de automação de fluxo de trabalho. Essas ações permitem que você realize operações de exclusão de solicitações HTTP.

## Pré-requisitos

Para pré-requisitos, consulte [ações HTTP](/docs/workflow-automation/setup-and-configure/actions-catalog/http/http#prerequisites).

## EXCLUIR dados da web [#http-delete]

Executa uma solicitação HTTP DELETE para remover dados em um endpointda API.

<Callout variant="important">
  Se você precisar passar dados sensíveis para uma entrada, por exemplo um cabeçalho `Api-Key`, você pode usar valores armazenados por meio da mutação [secretsManagementCreateSecret](https://one.newrelic.com/nerdgraph-graphiql) do NerdGraph.

  Exemplo:

  ```json
  {
    "inputs": [
      {
        "key": "headers",
        "value": "{\"Api-Key\": \"${{ :secrets:NR_API_KEY }}\"}"
      }
    ]
  }
  ```
</Callout>
