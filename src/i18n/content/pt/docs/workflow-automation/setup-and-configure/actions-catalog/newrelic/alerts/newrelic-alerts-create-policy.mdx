O identificador da ação é `newrelic.alerts.createPolicy`.

Cria uma nova política de alertas. Uma política agrupa condições do alerta relacionadas e controla como as violações criam incidentes.

                  type: action
                  action: newrelic.alerts.createPolicy
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    name: "Production Services"
                    incidentPreference: "PER_CONDITION"
