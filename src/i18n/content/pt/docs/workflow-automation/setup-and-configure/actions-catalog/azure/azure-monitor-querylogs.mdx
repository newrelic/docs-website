A ação Azure Monitor Query Logs executa uma consulta [KQL (Kusto Query Language)](https://learn.microsoft.com/en-us/azure/azure-monitor/logs/get-started-queries?tabs=kql) em um workspace do Log Analytics do Azure Monitor e retorna a tabela de resultados para o seu fluxo de trabalho.

## Consultar logs do Azure Monitor [#azure-monitor-querylogs]

Use esta ação para consultar dados de log — por exemplo, requests de aplicativo, falhas ou logs personalizados — e, em seguida, ramificar ou notificar com base nos resultados.

<Callout variant="important">
  A entidade de serviço do Azure AD que você usa deve ter a função **Log Analytics Reader** no workspace de destino.
</Callout>

    <TabsPageItem id="azuremonitorquerylogsexample">
      O exemplo a seguir consulta a tabela `AppRequests` dos últimos 25 dias e envia um resumo para um canal do Slack.

      ````yaml
      name: query-azure-monitor-logs

      steps:
        - name: query_app_requests
          type: action
          action: azure.monitor.queryLogs
          version: 1
          inputs:
            clientId: ${{ :secrets:azure-client-id }}
            clientSecret: ${{ :secrets:azure-client-secret }}
            tenantId: ${{ :secrets:azure-tenant-id }}
            workspaceId: "78460d46-1c7c-494b-90b4-e21288a074d4"
            query: |-
              AppRequests
              | take 10
            timespan: P25D
            selectors:
              - name: records
                expression: ".response.tables[0] as $t | ($t.columns | map(.name)) as $cols | $t.rows | map(. as $row | reduce range(0; ($cols | length)) as $i ({}; . + {($cols[$i]): $row[$i]}))"
        - name: send_slack_notification
          type: action
          action: newrelic.notification.sendSlack
          version: 1
          inputs:
            destinationId: ${{ :secrets:slack-destination-id }}
            channel: ops-alerts
            text: ${{ "*AppRequests* (" + (.steps.query_app_requests.outputs.records | length | tostring) + " rows)\n```\n" + (.steps.query_app_requests.outputs.records | map([(.OperationName // ""), (.ResultCode // ""), (.Url // ""), ((.DurationMs // 0) | tostring) + "ms"] | join(" | ")) | join("\n")) + "\n```" }}
          next: end
      ````
