As ações do Azure Cosmos DB permitem ler, gravar e gerenciar documentos e bancos de dados no Azure Cosmos DB diretamente dos seus fluxos de trabalho. Todas as ações se autenticam usando uma entidade de serviço do Azure AD e se comunicam com o plano de dados do Cosmos DB.

## Obter um item [#azure-cosmos-getitem]

Esta ação lê um único documento por ID de um contêiner do Azure Cosmos DB usando a API REST [Azure Cosmos DB - Get Document](https://learn.microsoft.com/en-us/rest/api/cosmos-db/get-a-document).

## Atualizar um item [#azure-cosmos-updateitem]

Esta ação substitui ou faz upsert de um documento em um contêiner do Azure Cosmos DB usando a API REST [Azure Cosmos DB - Replace Document](https://learn.microsoft.com/en-us/rest/api/cosmos-db/replace-a-document). Por padrão (`upsert: false`) o documento já deve existir. Defina `upsert: true` para criar o documento se ele não existir.
