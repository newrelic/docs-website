Recupera uma única issue de um repositório do GitHub pelo número da issue.

Para a configuração de autenticação, consulte as [ações de issue do GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-issue).

              description: Get a GitHub issue
              steps:
                - name: get_issue
                  type: action
                  action: gitHub.issue.get
                  version: 1
                  inputs:
                    token: ${{ :secrets:github-PAT-token }}
                    owner: your_user_name
                    repo: test-workflow
                    issueNumber: 7
                  next: end
