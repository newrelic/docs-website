Esta página fornece uma referência abrangente para as ações de job do Ansible disponíveis no catálogo de ações de automação de fluxo de trabalho. Essas ações permitem lançar e gerenciar modelos de job da plataforma Ansible Automation (Automation Controller).

## Pré-requisitos

Antes de utilizar as ações do Ansible na automação do fluxo de trabalho, certificar-se de ter:

* Uma instância da plataforma Ansible Automation (Automation Controller) acessível por HTTPS.
* Um token OAuth2 com escopo de gravação para lançar jobs (crie um em **Automation Controller &gt; Users &gt; Tokens**).
* O ID numérico do modelo de job que se deseja lançar.
* A configuração `ask_*_on_launch` habilitada no modelo de job para cada entrada opcional que se planeja usar (`extraVars`, `limit`, `inventory`).
