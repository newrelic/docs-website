Esta página fornece uma referência para a ação `ansible.job.getStatus` disponível no catálogo de ações de automação de fluxo de trabalho. Use esta ação para recuperar o status e os detalhes de um job da Ansible Automation Platform (Automation Controller). Use esta ação para consultar um job criado por [`ansible.job.launch`](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job-launch). Esta ação se baseia na ação base `http.get`.

**Endpoint:** `GET https://{host}/api/controller/v2/jobs/{jobId}/`

## Pré-requisitos

Antes de usar esta ação na automação do fluxo de trabalho, é necessário ter:

* Uma instância da plataforma Ansible Automation (Automation Controller) acessível por HTTPS.
* Um token OAuth2 com escopo de gravação (crie um em **Automation Controller → Usuários → Tokens**)
* O ID numérico do job a ser consultado (normalmente o campo `id` retornado por `ansible.job.launch`).
