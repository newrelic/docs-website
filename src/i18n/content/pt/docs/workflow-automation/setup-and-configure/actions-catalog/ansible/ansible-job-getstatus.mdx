Esta página fornece uma referência para a ação `ansible.job.getStatus` disponível no catálogo de ações de automação de fluxo de trabalho. Use esta ação para consultar um job criado por [`ansible.job.launch`](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job-launch) até que ele atinja um estado terminal.

Para os pré-requisitos, consulte [Ações de job do Ansible](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job#prerequisites).

## Obter o status de um trabalho do Ansible

O identificador da ação é `ansible.job.getStatus`.

Obtém o status e os detalhes de um job do Automation Controller. Os status do job progridem de `pending` para `waiting` e para `running` antes de atingir um estado terminal: `successful`, `failed`, `error` ou `canceled`. O endpoint é `GET https://{host}/api/controller/v2/jobs/{jobId}/`.

              steps:
                - name: get_status
                  type: action
                  action: ansible.job.getStatus
                  version: 1
                  inputs:
                    host: ${{ :secrets:host }}
                    authToken: ${{ :secrets:ansibleControllerToken }}
                    jobId: "128"
                    selectors:
                      - name: status
                        expression: ".status"
                      - name: failed
