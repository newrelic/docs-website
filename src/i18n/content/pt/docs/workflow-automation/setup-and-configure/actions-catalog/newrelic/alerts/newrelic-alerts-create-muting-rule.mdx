O identificador da ação é `newrelic.alerts.createMutingRule`.

Cria uma nova regra de silenciamento para suprimir notificações de alerta para violações que correspondam a uma condição. Opcionalmente, agenda a regra como uma janela de manutenção recorrente ou única.

    <TabsPageItem id="muting-create-example">
      O exemplo a seguir cria uma regra de silenciamento que suprime alertas para uma política durante janelas de manutenção recorrentes aos finais de semana.

      <table>
        <thead>
          <tr>
            <th>
              Exemplo de fluxo de trabalho
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: create_muting_rule
              description: Create a muting rule for a maintenance window
              steps:
                - name: createMutingRule
                  type: action
                  action: newrelic.alerts.createMutingRule
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    name: "Deploy window - checkout service"
                    enabled: true
                    condition:
                      operator: "AND"
                      conditions:
                        - attribute: "policyName"
                          operator: "EQUALS"
                          values:
                            - "Checkout Service"
                    schedule:
                      startTime: "2026-09-01T02:00:00"
                      endTime: "2026-09-01T04:00:00"
                      timeZone: "America/Los_Angeles"
                      repeat: "WEEKLY"
                      weeklyRepeatDays:
                        - "SATURDAY"
                        - "SUNDAY"
                    selectors:
                      - name: mutingRuleId
                        expression: ".data.alertsMutingRuleCreate.id"
                  next: end
              ```
            </td>
