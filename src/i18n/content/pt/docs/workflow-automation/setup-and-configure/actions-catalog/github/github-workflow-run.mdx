Esta página fornece uma referência para as ações de execução de fluxo de trabalho do GitHub disponíveis no catálogo de ações de automação de fluxo de trabalho. Essas ações permitem que você acione, recupere e liste execuções de fluxo de trabalho do GitHub Actions diretamente de uma definição de fluxo de trabalho, possibilitando a orquestração automatizada de CI/CD, pipelines de implantação e automação de lançamentos sem código personalizado ou ferramentas externas.

## Pré-requisitos

Antes de usar as ações de execução de fluxo de trabalho do GitHub na automação de fluxo de trabalho, certifique-se de ter:

* Uma conta do GitHub com acesso ao repositório de destino.
* Um token de acesso pessoal (PAT) do GitHub com as permissões necessárias.
* O PAT armazenado no serviço de segredos da New Relic.
* O fluxo de trabalho de destino configurado com um gatilho `workflow_dispatch` (necessário para `gitHub.workflowRun.trigger`).

## Configurar a autenticação PAT

As ações de execução de fluxo de trabalho do GitHub fazem a autenticação usando um token de acesso pessoal (PAT) transmitido como uma credencial Bearer. Esta ação é compatível com dois tipos de token:

* **PAT de granulação fina** — requer a permissão **Actions: write** para `gitHub.workflowRun.trigger`; **Actions: read** para `gitHub.workflowRun.get`, `gitHub.workflowRun.getLatest` e `gitHub.workflowRun.list`.
* **PAT clássico** — requer o escopo **repositório** para todas as quatro ações.

<Steps>
<Step>
### Crie um token de acesso pessoal do GitHub

1. No GitHub, acesse **Settings &gt; Developer settings &gt; Personal access tokens**.
2. É necessário escolher **Fine-grained tokens** ou **Token (classic)** e clicar em **Generate new token**.
3. Defina as permissões necessárias: **Actions: write** (ou **Actions: read** para ações de somente leitura) para token de granulação fina, ou escopo **repositório** para token clássico.
4. Copie o token gerado — o GitHub o exibe apenas uma vez.
</Step>

<Step>
### Armazenar o token como um segredo

Armazenar o token no New Relic Secrets Service e referenciá-lo no YAML do fluxo de trabalho usando a sintaxe `${{ :secrets:keyName }}`:

```yaml
token: ${{ :secrets:github-PAT-token }}
```
</Step>
</Steps>
