Esta página fornece uma referência para as ações do Azure App Service disponíveis no catálogo de ações de automação de fluxo de trabalho. Essas ações permitem que você obtenha, liste, inicie, pare e reinicie aplicativos web do Azure App Service diretamente de uma definição de fluxo de trabalho, permitindo fluxos de trabalho operacionais, como desligamentos programados para controle de custos, reinicializações acionadas por incidentes e verificações prévias antes de uma etapa de implantar.

## Pré-requisitos

Antes de usar as ações do Azure App Service na automação de fluxo de trabalho, certifique-se de ter:

* Uma assinatura do Azure com um ou mais Serviços de Aplicativo.
* Um registro de aplicativo (entidade de serviço) do Entra (Azure AD) com as permissões necessárias.
* As credenciais de registro do aplicativo armazenadas no New Relic Secrets Service.

## Configurar a autenticação do Entra

As ações do Azure App Service autenticam-se usando um fluxo OAuth2 de credenciais de cliente de entidade de serviço do Entra (Azure AD). As permissões necessárias dependem da ação:

* Função de **Reader** (Leitor) — necessária para `azure.appService.get` e `azure.appService.list`.
* **Contributor** (Colaborador) (ou **Website Contributor** (Colaborador de site) para o menor privilégio) — necessário para `azure.appService.start`, `azure.appService.stop` e `azure.appService.restart`.

<Steps>
<Step>
### Criar um registro de aplicativo do Entra

1. No portal do Azure, acesse **Microsoft Entra ID &gt; App registrations** e clique em **New registration**.
2. Dê um nome ao registro e clique em **Register**.
3. É necessário anotar o **ID do aplicativo (cliente)** e o **ID do diretório (locatário)** — você precisará deles como entradas.
4. Em **Certificates &amp; secrets**, crie um novo segredo do cliente e copie o valor imediatamente.

Para obter instruções completas, consulte [Registrar um aplicativo para obter token de autenticação](https://learn.microsoft.com/en-us/azure/azure-monitor/logs/api/register-app-for-token).
</Step>

<Step>
### Atribua a função necessária

É necessário atribuir ao registro de aplicativo a função de **Reader** (para obter/listar) ou a função de **Contributor** / **Website Contributor** (para iniciar/parar/reiniciar) com escopo no Serviço de Aplicativo de destino ou no grupo de recursos.

1. No portal do Azure, navegue até o grupo de recursos de destino ou App Service.
2. Vá para **Access control (IAM) &gt; Add role assignment**.
3. Selecione a função apropriada e atribua-a ao registro de aplicativo.
</Step>

<Step>
### Armazenar credenciais como segredos

Armazene `clientId`, `clientSecret` e `tenantId` no New Relic Secrets Service e referencie-os no YAML do seu fluxo de trabalho usando a sintaxe `${{ :secrets:keyName }}`:

```yaml
clientId: ${{ :secrets:azure-client-id }}
clientSecret: ${{ :secrets:azure-client-secret }}
tenantId: ${{ :secrets:azure-client-tenant }}
```
</Step>
</Steps>
