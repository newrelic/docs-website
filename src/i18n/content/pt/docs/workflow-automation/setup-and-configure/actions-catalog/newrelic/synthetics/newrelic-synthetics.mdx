Esta página fornece uma referência para as ações do New Relic Synthetics disponíveis no catálogo de ações de automação de fluxo de trabalho. Essas ações permitem que você acione execuções de teste sob demanda para monitores existentes, gerencie o período de inatividade de janelas de manutenção e leia detalhes do monitor diretamente de uma definição de fluxo de trabalho.

## Pré-requisitos

Antes de usar as ações do New Relic Synthetics na automação de fluxo de trabalho, é necessário ter:

* Uma conta New Relic com as permissões apropriadas para acessar os monitores Sintéticos.
* O GUID da entidade de cada monitor que você deseja definir como destino. Você pode encontrar o GUID de um monitor no New Relic em **Synthetics &gt; \[nome do monitor] &gt; Settings**.

## Inicie um teste automatizado [#start-automated-test]

O identificador da ação é `newrelic.synthetics.startAutomatedTest`.

Aciona uma execução de teste automatizado de Sintéticos sob demanda para um ou mais monitores e retorna um `batchId` para consultar os resultados usando `newrelic.synthetics.getAutomatedTestResult`.

<Callout variant="important">
São suportados apenas os tipos de monitor de API com script, navegador com script, etapa e navegador simples. Os monitores SIMPLE (ping) são rejeitados pela API com um erro de tipo de monitor incompatível.
</Callout>

## Criar um período de inatividade de monitor [#create-monitor-downtime]

O identificador da ação é `newrelic.synthetics.createMonitorDowntime`.

Agenda um período de inatividade único (janela de manutenção) de monitor do Sintéticos para um ou mais monitores específicos. A API retorna um rótulo de fuso horário resolvido (como `Pacific Standard Time`) em vez do nome da IANA enviado.

<Callout variant="important">
`monitorGuids` pode ser nulo no esquema do GraphQL, mas é obrigatório na prática — omiti-lo gera um erro de servidor. Não há modo de período de inatividade para toda a conta; os períodos de inatividade sempre têm como destino monitores específicos.
</Callout>

## Editar um período de inatividade do monitor [#edit-monitor-downtime]

O identificador da ação é `newrelic.synthetics.editMonitorDowntime`.

Edita um período de inatividade de monitor Sintéticos existente identificado pelo GUID da sua entidade.

<Callout variant="important">
`monitorGuids` é obrigatório em cada chamada de edição. A API não preserva a lista existente quando este campo é omitido — em vez disso, ela a esvazia. Sempre passe o conjunto completo desejado de GUIDs de monitores.
</Callout>
