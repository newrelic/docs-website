O identificador da ação é `newrelic.alerts.searchNrqlConditions`.

Pesquisa condições do alerta NRQL (estáticas ou baseline) com filtragem opcional por nome, política, texto da consulta NRQL ou operador de termos. Suporta paginação baseada em cursor. Omitir todos os filtros retorna todas as condições na conta.

              ```yaml
              name: search_nrql_conditions
              description: Search NRQL alert conditions
              steps:
                - name: searchConditions
                  type: action
                  action: newrelic.alerts.searchNrqlConditions
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    policyId: ${{ .workflowInputs.policyId }}
                    nameLike: "error rate"
                    selectors:
                      - name: nrqlConditions
                        expression: ".data.actor.account.alerts.nrqlConditionsSearch.nrqlConditions"
                  next: end
              ```
