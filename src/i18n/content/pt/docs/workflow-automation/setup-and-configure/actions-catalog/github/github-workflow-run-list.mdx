Lista as execuções de fluxo de trabalho do GitHub Actions para um repositório, com filtragem opcional por fluxo de trabalho, branch, evento, status e muito mais. Se `workflowId` for fornecido, a lista é restrita a esse fluxo de trabalho específico; caso contrário, ela retorna execuções em todos os fluxos de trabalho no repositório.

Para a configuração de autenticação, consulte as [ações de execução de fluxo de trabalho do GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run).

<tr>
<td>
```yaml
name: list_workflow_runs
description: List GitHub Actions workflow runs for a specific workflow
steps:
  - name: list_runs
    type: action
    action: gitHub.workflowRun.list
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      workflowId: deploy.yml
      branch: main
      status: completed
      resultsPerPage: 10
      selectors:
        - name: totalCount
          expression: ".total_count"
        - name: latestRunId
          expression: ".workflow_runs[0].id"
        - name: latestConclusion
          expression: ".workflow_runs[0].conclusion"
    next: end
```
