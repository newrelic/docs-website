Esta página fornece uma referência para todas as ações de problema do New Relic disponíveis no catálogo de ações de automação de fluxo de trabalho. Essas ações permitem reconhecer, não reconhecer e resolver problemas do Alert Intelligence, além de consultar problemas para habilitar a lógica condicional nos fluxos de trabalho.

## Pré-requisitos

Antes de usar as ações de problemas do New Relic na automação de fluxo de trabalho, é necessário ter:

* Uma conta New Relic com as permissões apropriadas para gerenciar problemas do Alert Intelligence.
* As permissões necessárias para os serviços específicos do New Relic que você planeja usar.
