O [dashboard de automação de fluxo de trabalho](https://onenr.io/0gR7XE8LXjo) fornece um local central para visualizar, gerenciar e monitorar todos os fluxos de trabalho na sua conta. Use o dashboard para editar configurações, acompanhar o histórico de versões, gerenciar agendamentos de execução e solucionar falhas. Para gerenciar fluxos de trabalho, você precisa de pelo menos um fluxo de trabalho na sua conta e de permissões de edição e exclusão.

<Callout variant="important">
**Desativar a automação de fluxo de trabalho?** Se você planeja desativar a Automação de Workflow por meio do Feature Control Management (FCM), certifique-se de que todos os workflows agendados sejam removidos primeiro. Consulte [Desativar a automação de fluxo de trabalho](/docs/workflow-automation/troubleshooting#disabling-workflow-automation-fcm) para obter etapas detalhadas.
</Callout>

**Novo no fluxo de trabalho?** Comece [usando um modelo](/docs/workflow-automation/create-a-workflow-automation/use-a-template) ou [criando seu próprio fluxo de trabalho](/docs/workflow-automation/create-a-workflow-automation/create-your-own) para construir seu primeiro fluxo de trabalho.

## Ver fluxo de trabalho [#view-workflows]

Vá para <DNT>**All Capabilities &gt; Workflow Automation**</DNT>. Se sua conta não tiver fluxos de trabalho, o dashboard exibe um estado vazio com opções para criar seu primeiro fluxo de trabalho.

### Abas do Dashboard

Assim que você criar fluxos de trabalho, o painel exibe duas abas:

<DNT>**Summary tab**</DNT> (padrão): Exibe métricas e visualizações em nível de conta:

<DNT>**Top metrics**</DNT>:

* <DNT>**Total workflows**</DNT>: Contagem de todos os fluxos de trabalho na sua conta
* <DNT>**Total number of steps executed**</DNT>: Contagem cumulativa de etapas em todas as execuções do fluxo de trabalho
* <DNT>**Currently running workflows**</DNT>: Número de execuções ativas

<DNT>**Performance charts**</DNT>:

* <DNT>**Total run count of all workflows**</DNT>: Gráfico de linhas mostrando tendências de execução de fluxos de trabalho ao longo do tempo
* <DNT>**Top 5 most frequently run workflows**</DNT>: Gráfico de barras exibindo os fluxos de trabalho com as maiores contagens de execução
* <DNT>**Ratio of completed to failed workflows**</DNT>: Gráfico de pizza mostrando porcentagens e contagens de sucesso vs. falha

<DNT>**Recently failed runs table**</DNT>: Exibe execuções de fluxo de trabalho com falha com estas colunas:

* <DNT>**Workflow**</DNT>: Nome do fluxo de trabalho com falha
* <DNT>**Version**</DNT>: Versão do fluxo de trabalho que falhou
* <DNT>**Failed on**</DNT>: timestamp da falha
* <DNT>**Run ID**</DNT>: Identificador exclusivo para a execução com falha
* <DNT>**Failed step**</DNT>: Etapa onde a falha ocorreu
* <DNT>**Error message**</DNT>: descrição do erro

Cada widget de gráfico inclui um menu de contexto (três pontos) para visualizar a consulta, obter imagem ou criar condição de alerta.

<DNT>**Workflows tab**</DNT>:

<DNT>**Search**</DNT>: Use a barra <DNT>**Search in all fields**</DNT> para encontrar fluxos de trabalho por qualquer valor de coluna.

<DNT>**All workflows table**</DNT> exibe estas colunas:

* <DNT>**Favorite**</DNT> (ícone de estrela): Marque fluxos de trabalho como favoritos
* <DNT>**Name**</DNT>: Identificador do fluxo de trabalho
* <DNT>**Description**</DNT>: Propósito ou função do fluxo de trabalho
* <DNT>**Last run on**</DNT>: timestamp da execução mais recente
* <DNT>**Last run status**</DNT>: resultado da execução (exibido como selos coloridos: verde para Concluído, vermelho para Falhou)
* <DNT>**Latest version**</DNT>: Número da versão atual
* <DNT>**Created on**</DNT>: Data em que o fluxo de trabalho foi criado
* <DNT>**Actions menu**</DNT> (três pontos): acesse as operações de fluxo de trabalho

Valores vazios na tabela são exibidos como `—`

<DNT>**Row actions menu**</DNT> (clique nos três pontos ao lado do fluxo de trabalho):

* <DNT>**Run**</DNT>: execute o fluxo de trabalho imediatamente
* <DNT>**Schedule**</DNT>: Criar uma execução agendada
* <DNT>**Open in editor**</DNT>: modificar configuração do fluxo de trabalho
* <DNT>**Duplicate**</DNT>: crie uma cópia do fluxo de trabalho
* <DNT>**Delete**</DNT>: Remova o fluxo de trabalho permanentemente

Clique no nome de um fluxo de trabalho para visualizar sua [página Visão Geral da Entidade](/docs/workflow-automation/manage-workflows/workflow-entity-overview) com métricas detalhadas, histórico de execução, agendamentos e logs.

## Editar um fluxo de trabalho [#edit-a-workflow]

Atualize o nome, a descrição ou a configuração do fluxo de trabalho.

1. Localize o fluxo de trabalho que você deseja editar

2. Clique nas reticências (três pontos verticais) ao lado do nome do fluxo de trabalho

3. Selecione <DNT>**Open in editor**</DNT>

4. Atualize qualquer um destes:

   * <DNT>**Name**</DNT> — O identificador do fluxo de trabalho
   * <DNT>**Description**</DNT> — Propósito ou função do fluxo de trabalho
   * <DNT>**Configuration**</DNT> — Parâmetros de entrada, ações ou lógica

5. Clique <DNT>**Save**</DNT>

Você também pode acessar o editor na [página Visão geral da entidade](/docs/workflow-automation/manage-workflows/workflow-entity-overview) clicando no botão <DNT>**Edit**</DNT>.

## Gerenciar versões [#manage-versions]

A automação de fluxo de trabalho cria automaticamente uma nova versão sempre que você atualiza uma definição de fluxo de trabalho. Todas as versões anteriores permanecem disponíveis para referência e podem ser visualizadas ou executadas diretamente do editor.

### Visualize o histórico de versões no editor [#view-version-history]

Você pode navegar por todas as versões anteriores de um fluxo de trabalho sem sair do editor.

1. Abra um fluxo de trabalho no editor
2. Clique no <DNT>**version dropdown**</DNT> na barra de ferramentas do editor
3. Selecione qualquer versão anterior na lista

A versão selecionada abre em um <DNT>**read-only preview**</DNT> dentro do editor. Você pode revisar a configuração e executá-la, mas não pode editá-la diretamente.

### Crie uma nova versão a partir de uma versão anterior [#edit-as-new-version]

Se você deseja usar uma versão anterior como base para uma nova edição:

1. Abra o fluxo de trabalho no editor e selecione uma versão anterior no dropdown de versões
2. Clique <DNT>**Edit as new version**</DNT>
3. Faça suas alterações
4. Clique <DNT>**Save**</DNT>

O sistema cria uma nova versão numerada como a versão mais alta atual + 1. Por exemplo, se a v5 for a mais recente e você editar a v2, o resultado será a v6. A versão anterior não é sobrescrita.

Se você mudar de ideia, clique em <DNT>**Cancel**</DNT> para descartar a edição em andamento. Nenhuma nova versão é salva, e você retorna à lista de fluxos de trabalho.

### Comparar versões [#compare-versions]

Uma visualização de comparação de versões está disponível no editor. Você pode usá-la para inspecionar as diferenças entre duas versões quaisquer de um fluxo de trabalho antes de decidir qual delas executar ou usar como base.

### Fixação de versões para agendamento

Quando você agenda um fluxo de trabalho, você deve fixá-lo em uma versão específica. Essa versão fixada é executada mesmo se você atualizar a definição do fluxo de trabalho posteriormente.

**Iniciar e agendar fixação de versão de suporte ao fluxo de trabalho:**

* Ao agendar um fluxo de trabalho, especifique qual versão executar.
* Ao iniciar manualmente a execução de um fluxo de trabalho, selecione qual versão executar.
* Ao atualizar um agendamento, especifique a nova versão a ser usada

Isso permite que você:

* Atualize o fluxo de trabalho sem afetar os cronogramas de execução
* Teste manualmente as novas versões antes de atualizar os cronogramas.
* Mantenha a estabilidade do fluxo de trabalho da produção

## Duplicar um fluxo de trabalho [#duplicate-a-workflow]

Duplique o fluxo de trabalho quando precisar adaptar um modelo ou fluxo de trabalho existente para uma finalidade diferente, mantendo o original intacto.

1. Localize o fluxo de trabalho que deseja duplicar.
2. Clique nas reticências (três pontos verticais)
3. Selecione <DNT>**Duplicate**</DNT>
4. O sistema cria uma cópia com **(Copy)** anexado ao nome
5. Renomeie e personalize o fluxo de trabalho duplicado de acordo com suas necessidades.

**Cenários comuns de duplicação:**

* Adaptar um modelo de fluxo de trabalho para o seu caso de uso específico.
* Criar um fluxo de trabalho para uma equipe diferente com requisitos semelhantes.
* Experimentar com mudanças significativas, preservando o original.

<Callout variant="important">
**Não duplique fluxos de trabalho para controle de versão** — o sistema faz isso automaticamente. Duplicar fluxos de trabalho apenas para fins de controle de versão ou rollback pode fazer com que você atinja os limites de fluxos de trabalho. Veja [Gerenciar versões](#manage-versions) para informações sobre versionamento automático.
</Callout>

## Excluir um fluxo de trabalho [#delete-a-workflow]

Remova o fluxo de trabalho que você não precisa mais.

1. Localize o fluxo de trabalho que deseja excluir.
2. Clique no menu de mais opções (três pontos verticais).
3. Selecione <DNT>**Delete**</DNT>
4. Confirme a exclusão na caixa de diálogo.

<Callout variant="caution">
A exclusão de um fluxo de trabalho é permanente. Você não pode desfazer isso. Removemos todas as versões e o histórico de execução. Se você precisar do fluxo de trabalho mais tarde, considere desativá-lo em vez de excluí-lo.
</Callout>

**O que é apagado:**

* Todas as versões do fluxo de trabalho
* Todo o histórico de execução e logs.
* Todas as execuções agendadas associadas ao fluxo de trabalho.

**Antes de excluir, verifique:**

* Nenhuma automação crítica depende desse fluxo de trabalho.
* Você tem uma cópia de segurança caso precise dela mais tarde.
* Identifique e contabilize todas as execuções agendadas
