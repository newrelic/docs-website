Este documento descreve os vários dados de observabilidade que podem ser usados para monitorar as execuções de fluxo de trabalho ou agendamentos.

## Auditorias

Todas as chamadas de mutação do NerdGraph são auditadas e os dados podem ser consultados em `NrAuditEvent` na conta dos clientes.

### WorkflowRun

```sql
SELECT actionIdentifier, actorId, actorType, description
FROM NrAuditEvent 
WHERE targetType = 'workflow_run'
SINCE 1 hour ago
```

### WorkflowSchedule

```sql
SELECT actionIdentifier, actorId, actorType, description
FROM NrAuditEvent 
WHERE targetType = 'workflow_schedule'
SINCE 1 hour ago
```

## Evento

Todas as execuções de fluxo de trabalho emitem dados `WorkflowAutomationEvent` no NRDB na conta do cliente que foi usada para iniciar, ou agendar, um fluxo de trabalho.

Um novo namespace `WorkflowAutomation` é criado para os dados de evento das execuções de fluxo de trabalho.

### Exemplo de consulta

Por exemplo:

```sql
SELECT *
FROM WorkflowAutomationEvent
where definitionName = 'json-parsing' and runId = '31c973d2-c669-4bd7-9b15-7e3a70a4a074'
SINCE 1 month ago
```

## Registro

Opcionalmente, um fluxo de trabalho pode ser iniciado, ou agendado, especificando uma opção de verbosidade `logLevel`. Esses logs são adicionados à conta do fluxo de trabalho que foi usada para iniciar, ou agendar, o fluxo de trabalho.

Os logs recebem os seguintes atributos:

* `workflowAutomation.name` é o nome do WorkflowDefinition
* `workflowAutomation.version` é a versão do WorkflowDefinition
* `workflowAutomation.runId` é o runId do fluxo de trabalho
* `entityGuid` é o ID do WorkflowDefinition

Se iniciado a partir de uma ocorrência de agendamento:

* `workflowAutomation.scheduleId`

Para o tipo de etapa Ação, ao usar `DEBUG`, cada entrada de ação adiciona um atributo adicional à entrada de log com o formato `workflowAutomation.inputs.<inputName>: <inputValue>`.

Para o tipo de etapa de Ação, ao usar `TRACE`, cada saída de ação adiciona um atributo adicional à entrada de log com o formato `workflowAutomation.outputs.<outputName>: <outputValue>`.

### Exemplo de consulta NRQL

Você pode consultar seu log com a seguinte consulta NRQL:

```sql
SELECT message FROM Log WHERE workflowAutomation.runId = '{run_id}' SINCE 3 hours ago
```

<img title="Diagram of log attributes for workflow runs" alt="Diagram of log attributes for workflow runs" src="/images/log_attributes.webp" />

Além de `workflowAutomation.runId`, alguns outros atributos de log que podem ajudar na consulta de dados de log são:

* `workflowAutomation.name`
* `workflowAutomation.version`

Para execuções agendadas, as entradas de log também terão o atributo `workflowAutomation.scheduleId`.
