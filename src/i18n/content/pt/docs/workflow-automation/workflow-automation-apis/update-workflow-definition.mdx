Use a mutação `workflowAutomationUpdateWorkflowDefinition` para atualizar uma definição de workflow existente. Ela retorna um erro se a definição do workflow ainda não existir.

## Solicitação de amostra [#sample-request]

```graphql
  mutation {
    workflowAutomationUpdateWorkflowDefinition(
      definition: {yaml: "<workflow definition YAML>"}
      scope: {id: "12345678", type: ACCOUNT}
    ) {
      definition {
        name
        version
        yaml
      }
    }
  }
```

## Resposta de amostra [#sample-response]

A mutação retorna:

* `definition.name`: O nome da definição do fluxo de trabalho atualizada
* `definition.version`: O novo número da versão da definição do fluxo de trabalho
* `definition.yaml`: O YAML da definição do fluxo de trabalho codificado em base64
