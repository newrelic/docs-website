Use a mutação `workflowAutomationCreateSchedule` para criar uma programação para uma definição de workflow.

<Callout variant="tip">
O número de agendamentos e a duração mínima para um determinado agendamento são definidos em [Limites do sistema de fluxo de trabalho](/docs/workflow-automation/limitations-and-faq/workflow-limits).
</Callout>

### Opção logLevel [#loglevel-option]

A opção `logLevel` controla a quantidade de informações de logging geradas durante a execução do fluxo de trabalho.

* `NONE` (padrão): não gera saída de log.
* `INFO`: gera informações no nível da etapa.
* `DEBUG`: adiciona um atributo aos logs de início da etapa com todas as entradas da etapa de ação, usando o formato `workflowAutomation.inputs.<inputName>: <inputValue>`.
* `TRACE`: além da saída de `DEBUG`, adiciona um atributo aos logs de início da etapa com todas as saídas da etapa de ação, usando o formato `workflowAutomation.outputs.<outputName>: <outputValue>`.

## Solicitação de amostra [#sample-request]

Utilize o [criador de consulta](https://one.newrelic.com/nerdgraph-graphiql?state=b8f3b3a9-8d3e-c03e-5da4-34b98a57ff8f) para criar e editar um fluxo de trabalho. Consulte [o explorador de API do NerdGraph](/docs/apis/nerdgraph/get-started/nerdgraph-explorer).

```graphql
  mutation {
    workflowAutomationCreateSchedule(
      scope: {id: "12345678", type: ACCOUNT}
      definition: {name: "healthyHeartbeat", version: 1}
      cronExpression: "0 0 * * *"
      timezone: "Asia/Kolkata"
      options: {logLevel: DEBUG}
      tags: [{key: "environment", values: ["production"]}]
    ) {
      scheduleId
    }
  }
```
