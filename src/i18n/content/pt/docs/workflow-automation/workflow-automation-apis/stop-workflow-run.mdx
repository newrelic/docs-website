Use a mutação `workflowAutomationStopWorkflowRun` para interromper um workflow em execução.

</td>

<tr>

`runId`
</td>

<td>
Corda
</td>

<td>
(Obrigatório) O identificador exclusivo da execução do workflow a ser interrompida. Obtido da API `StartWorkflowRun`.
</td>
</tr>

## Solicitação de amostra [#sample-request]

```graphql
mutation {
  workflowAutomationStopWorkflowRun(
    accountId: 12345678
    runId: "7ffbe082-8efa-4d3d-901a-a08bcf22bcd3"
  ) {
    runId
  }
}
```

## Resposta de amostra [#sample-response]

A mutação retorna:

* `runId`: O identificador exclusivo da execução do fluxo de trabalho interrompido. Retorna um `runId` vazio se o fluxo de trabalho não for encontrado.
