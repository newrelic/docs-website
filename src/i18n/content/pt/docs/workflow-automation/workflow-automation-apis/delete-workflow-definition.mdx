Use a mutação `workflowAutomationDeleteWorkflowDefinition` para excluir todas as versões de uma definição de workflow com o nome especificado.

<Callout variant="important">
* Para excluir uma definição, não deve haver agendamentos que a utilizem. Se a definição estiver sendo usada atualmente por um agendamento, a exclusão falha e retorna um erro.
* Todas as execuções de workflow em andamento continuam até a conclusão, mesmo se a definição for excluída.
</Callout>

```graphql
  workflowAutomationDeleteWorkflowDefinition(
    definition: {name: "my-workflow"}

    definition {
      name
    }
  }
}
```
