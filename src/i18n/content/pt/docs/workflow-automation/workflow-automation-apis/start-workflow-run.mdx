Use a mutação `workflowAutomationStartWorkflowRun` para iniciar uma execução de workflow para uma definição de workflow especificada.

<Callout variant="important">
Para limites de execuções simultâneas de workflow e etapas por execução, consulte [Limites do sistema de workflow](/docs/workflow-automation/limitations-and-faq/workflow-limits).
</Callout>

### Opção logLevel [#loglevel-option]

A opção `logLevel` controla a quantidade de informações que o workflow gera durante a execução.

* `NONE` (padrão): não gera saídas de log.
* `INFO`: gera informações no nível da etapa.
* `DEBUG`: adiciona um atributo aos logs de início da etapa com todas as entradas da etapa de ação, usando o formato `workflowAutomation.inputs.<inputName>: <inputValue>`.
* `TRACE`: além da saída de `DEBUG`, adiciona um atributo aos logs de início da etapa com todas as saídas da etapa de ação, usando o formato `workflowAutomation.outputs.<outputName>: <outputValue>`.

## Solicitação de amostra [#sample-request]

Utilize o [criador de consulta](https://one.newrelic.com/nerdgraph-graphiql?state=b8f3b3a9-8d3e-c03e-5da4-34b98a57ff8f) para criar e editar um fluxo de trabalho. Consulte [o explorador de API do NerdGraph](/docs/apis/nerdgraph/get-started/nerdgraph-explorer).

```graphql
mutation {
  workflowAutomationStartWorkflowRun(
    definition: {name: "json-parsing", version: 1}
    workflowInputs: [
      {key: "checkOperational", value: "false"}
      {key: "checkNonOperational", value: "true"}]
    scope: {id: "12345678"}
    idempotencyKey: "45e65924-5316-479c-a977-f6adfa17e07a"
    options: {logLevel: INFO}
  ) {
    runId
  }
}
```

## Resposta de amostra [#sample-response]

A mutação retorna:

* `runId`: O identificador exclusivo para a execução do fluxo de trabalho. Use este ID com as APIs `WorkflowRunInfo`, `SignalWorkflowRun` ou `StopWorkflowRun`.
