Esta API recupera informações sobre uma execução específica de fluxo de trabalho, incluindo seu status, URL do log e qualquer estado de fluxo de trabalho salvo durante a execução.

## Solicitação de amostra

Utilize o [criador de consulta](https://one.newrelic.com/nerdgraph-graphiql?state=03119d23-7b51-7b7a-1c99-d2cd026300e5) para criar e editar um fluxo de trabalho. Consulte [o explorador de API do NerdGraph](/docs/apis/nerdgraph/get-started/nerdgraph-explorer).

```graphql
{
  actor {
    account(id: 11933347) {
      workflowAutomation {
        workflowRunInfo(runId: "8911c7e4-5a1f-4316-90c8-67adde72dd1c") {
          state(keys: ["foo", "count"]) {
            key
            value
          }
          logUrl
          status
        }
      }
    }
  }
}
```

## Resposta de amostra

A consulta retorna:

* `logUrl`: URL para visualizar os logs de execução do fluxo de trabalho.
* `status`: o status atual da execução do fluxo de trabalho. Valores possíveis: `STARTED`, `COMPLETED`, `FAILED`, `TIMED_OUT`, `STOPPED`.
* `state`: uma matriz de `{ key, value }` objetos para cada chave solicitada encontrada no estado do fluxo de trabalho. As chaves não presentes no estado do fluxo de trabalho são omitidas.

```graphql
{
  "data": {
    "actor": {
      "account": {
        "workflowAutomation": {
          "workflowRunInfo": {
            "logUrl": "https://one.newrelic.com/...",
            "status": "COMPLETED",
            "state": [
              { "key": "foo", "value": "bar" },
              { "key": "count", "value": "2" }
            ]
          }
        }
      }
    }
  }
}
```
