## Solicitação de amostra [#sample-request]

```graphql
    {
      actor {
        account(id: 12345678) {
          workflowAutomation {
            schedule(id: "schedule-id") {
              id
            }
          }
        }
      }
    }
```

## Resposta de amostra [#sample-response]

A consulta retorna:

* `schedule.id`: O identificador exclusivo do agendamento.
