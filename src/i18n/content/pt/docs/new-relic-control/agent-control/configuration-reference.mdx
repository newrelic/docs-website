Esta página lista as configurações do Controle de agentes que você pode modificar, com seus valores padrão. Para obter uma visão geral da configuração local e remota e para ver exemplos de como configurar o agente que o Controle de agentes gerencia, consulte [Gerenciamento de configuração](/docs/new-relic-control/agent-control/configuration).

A conexão do Controle de Agentes (`fleet_control`), `host_id`, o `agents` gerenciado e os provedores de valor são abordados em [Gerenciamento de configuração](/docs/new-relic-control/agent-control/configuration).

### Substituir configurações por variáveis de ambiente [#environment-variables]

Você pode definir qualquer configuração como uma variável de ambiente. É necessário usar o prefixo `NR_AC_`, escrever o nome da configuração em letras maiúsculas e usar um sublinhado duplo (`__`) para separar chaves aninhadas. As variáveis de ambiente têm precedência sobre o arquivo de configuração local.

```bash
# log.level
NR_AC_LOG__LEVEL=DEBUG

# fleet_control.auth_config.client_id
NR_AC_FLEET_CONTROL__AUTH_CONFIG__CLIENT_ID="some-client-id"
```

Nos hosts, você pode definir essas variáveis no arquivo de ambiente do serviço ou em um arquivo `environment_variables.yaml` no diretório de configuração local (`/etc/newrelic-agent-control/` no Linux, `C:\Program Files\New Relic\newrelic-agent-control\` no Windows). O arquivo deve ser um mapa YAML plano de chaves de string para valores de string:

```yaml
NR_AC_LOG__LEVEL: "DEBUG"
HTTPS_PROXY: "http://proxy.local:8443"
```

* As chaves devem começar com uma letra ou sublinhado e conter apenas letras, dígitos e sublinhados.
* O Controle de agentes não monitora este arquivo. Reinicie o Controle de agentes após alterá-lo.
* O Controle de agentes passa essas variáveis aos agentes que ele gerencia.
* Se o arquivo tiver uma entrada inválida, o Controle de agentes não será iniciado.

## Proxy: `proxy` [#proxy]

O Controle de agentes usa as variáveis de ambiente `HTTP_PROXY` e `HTTPS_PROXY` do seu sistema. Você também pode definir um proxy com a configuração `proxy`. Se mais de uma for definida, o Controle de agentes as usará nesta ordem de precedência:

1. A configuração `proxy`
2. A variável de ambiente `HTTP_PROXY`
3. A variável de ambiente `HTTPS_PROXY`

```yaml
proxy:
  url: https://user:password@proxy.example.com:8080
  ca_bundle_file: /etc/ssl/certs/proxy-ca.pem
```
