O Ground Truth é a camada de inteligência operacional da New Relic. As ferramentas do Model Context Protocol (MCP) ajudam a organizar seus dados de observabilidade para que os agentes de IA possam entender melhor sua stack de tecnologia.

O MCP é uma maneira padrão para modelos de IA ou agentes receberem informações relevantes (contexto) sobre um sistema ou ambiente específico. Esse contexto pode ajudar a IA a entender a situação atual, executar tarefas com mais precisão e fornecer respostas mais úteis. O servidor MCP permite que agente(s) de IA suportado(s) chame(m) certas ferramentas que podem ajudar você a consultar, investigar ou atuar nos dados do New Relic em linguagem natural. Isso, por sua vez, pode ajudar a acelerar a resposta a incidentes e a análise de desempenho.

## Benefícios potenciais

O servidor MCP oferece benefícios práticos para engenheiros e equipes de operações das seguintes maneiras:

* **Integração direta:** acesse as ferramentas MCP da New Relic diretamente do seu ambiente de desenvolvimento compatível. Isso evita alternar entre diferentes ferramentas de IA.
* **Resolução de problemas mais rápida:** use o MCP para ajudar a encontrar e corrigir problemas rapidamente a partir dos seus dados de observabilidade, analisar logs de erros e determinar as causas prováveis com insights fornecidos por IA.
* **Consultas operacionais:** peça ao seu agente de IA para verificar status de alertas, gerar relatórios de eventos de alerta ou analisar como as implantações afetam seus sistemas.
* **Consulta de dados simples:** formule perguntas em inglês simples e o servidor as converte para a linguagem de consulta New Relic (NRQL) para obter resultados, mesmo que você não esteja familiarizado com NRQL.

## Ferramentas de desenvolvimento de IA suportadas [#supported-tools]

O New Relic MCP funciona com estes ambientes de desenvolvimento de IA (clientes MCP suportados):

* **Claude Code:** Interface de linha de comando para Claude
* **Antigravity CLI:** interface de linha de comando para o Antigravity
* **Kiro CLI:** Interface de linha de comando para Kiro
* **Claude Desktop:** aplicativo de desktop para desenvolvimento interativo de IA
* **VS Code:** Ambiente de desenvolvimento integrado com suporte a MCP

Cada ambiente oferece vantagens exclusivas dependendo das suas preferências de fluxo de trabalho. Consulte nosso [guia de instalação](/docs/agentic-ai/mcp/setup) para obter instruções de configuração específicas do cliente MCP.

## Pré-requisitos [#prerequisites]

Para usar o New Relic MCP, você precisa de:

* Uma conta New Relic (o MCP está disponível para todas as contas: todos os usuários de dados e CCU podem acessar as ferramentas principais, os usuários aCCU podem acessar todas as ferramentas, incluindo ferramentas avançadas)
* `Node.js` instalado (necessário para alguns métodos de autenticação)
* Um dos clientes MCP compatíveis mencionados anteriormente instalado

### Acesso da organização [#org-access]

Antes de se conectar, um administrador da New Relic deve realizar o seguinte:

**Participação no grupo e funções**

Você deve ser membro de um grupo ao qual foi atribuída uma função organizacional padrão (`Organization Read Only`, `Organization Manager` ou `Organization Product Admin`) ou uma função personalizada com escopo de organização com permissão para ler o servidor MCP. Se o seu grupo não tiver a permissão necessária, entre em contato com um administrador com a função `Organization Manager` ou `Authentication Domain Manager` para que ela seja concedida.

**gerenciador de controle de recursos**

O administrador da sua organização deve habilitar o acesso ao MCP por meio do [gerenciador de controle de recursos](/docs/accounts/accounts-billing/new-relic-one-user-management/feature-control-manager/). Os seguintes botões de alternância controlam o acesso ao MCP. **New Relic MCP Server** e **Local Clients** estão habilitados por padrão. Todos os outros sub-botões de alternância estão desabilitados por padrão e podem ser habilitados pelo seu administrador da New Relic conforme necessário.

* **New Relic MCP Server**: necessário para a configuração do MCP. Chave principal que deve estar ativada para que qualquer acesso ao MCP funcione.
* **Clientes locais**: necessários para conexões de clientes locais (Claude Code, Claude Desktop, VS Code, Kiro).
* **Chaves de API**: necessárias para conexões de chave de API, incluindo scripts automatizados.
* **Ferramentas de preview**: necessárias se desejar acessar as ferramentas de preview (não GA) do MCP.
* **Atlassian**: necessário para a integração Atlassian
* **AWS**: necessário para a integração da AWS

### Opções de autenticação [#auth-options]

* **OAuth (recomendado)**: a New Relic fornece endpoints OAuth pré-configurados:

  * ID do cliente: `pUWGgnjsQ0bydqCbavTPpw==`
  * URL de autorização: `https://oauth2.service.newrelic.com/oauth2/auth`
  * URL do token: `https://oauth2.service.newrelic.com/oauth2/token`
  * Âmbito de aplicação: `["observability:read", "offline", "offline_access"]`

* **Chave de API de usuário**: observe que **algumas ferramentas MCP são acessíveis apenas via OAuth**.

  1. Faça login na New Relic.
  2. Selecione **menu do usuário -&gt; API keys**.
  3. Crie uma nova chave de usuário ou copie uma existente.
  4. Formato da chave: `NRAK-XXXXXXXXXXXXXXXXXXXXX`.

<Callout variant="important">
  Algumas ferramentas são acessíveis apenas via OAuth e não estão disponíveis ao usar uma chave de API. Estas incluem ferramentas de análise baseadas em IA (`natural_language_to_nrql_query`, `generate_alert_insights_report`, `generate_user_impact_report`, `analyze_deployment_impact`) e ferramentas de pré-visualização (`search_traces`, `analyze_trace_anomaly`, `analyze_service_dependencies`). Consulte a [referência da ferramenta](/docs/agentic-ai/mcp/tool-reference) para obter detalhes.
</Callout>
