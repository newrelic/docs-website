## O fluxo OAuth não está iniciando.

* Certifique-se de que seu navegador possa acessar `localhost`.
* Verifique as configurações do firewall.
* Verifique se suas ferramentas podem acessar URLs `OAuth`.

## chave de API não está funcionando

* Verifique o formato da chave (começa com `NRAK-`).
* Verifique as permissões de chave no New Relic.
* Verifique se a chave não expirou.

## Servidor MCP não detectado

* Reinicie o aplicativo completamente.
* Verifique a validade da sintaxe `JSON`.
* Verifique os caminhos e permissões dos arquivos.

## problemas de proxy remoto mcp

* Certifique-se de que `Node.js` esteja instalado.
* Verifique a sua ligação à internet.
* Verifique se o npx pode acessar o pacote `mcp-remote`.

## Acesso negado para grupos personalizados

### Problema

Você não consegue se conectar ou autenticar com sucesso no servidor New Relic AI MCP e recebe a seguinte mensagem de erro: `Missing required capabilities to access MCP server. Please ensure you have the necessary permissions.` Isso normalmente ocorre se você for membro de um grupo de usuários personalizado sem nenhuma permissão em nível organizacional.

### Causa

Seu grupo não possui uma função com escopo organizacional que permita a leitura do servidor MCP. O acesso a este recurso de toda a organização deve ser explicitamente concedido ao seu grupo através de uma função no âmbito da organização.

### Resolução

O administrador da sua organização que possui a função `Authentication Domain Manager` deve implementar uma das duas soluções a seguir para conceder acesso a você:

1. Atribua ao seu grupo uma função com permissão para ler o servidor MCP:

   * O administrador deve adicionar uma das seguintes funções ao grupo personalizado ao qual você pertence: `Organization Read Only`, `Organization Manager` ou `Organization Product admin`.
   * O administrador pode criar uma [função personalizada com escopo organizacional](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/#roles) e atribuí-la a um grupo ao qual você pertence por meio de uma [concessão gerenciada pela organização](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/#access-grants). Esta função personalizada deve incluir a permissão de leitura `New Relic MCP Server`.

2. Adicionar você a um grupo autorizado:

   * O administrador deve adicioná-lo a um grupo de usuários existente que já possua uma função com escopo organizacional e permissão para ler o servidor MCP.

Para obter informações detalhadas sobre conceitos de gerenciamento de usuários, funções e concessões de organização, consulte a [documentação de gerenciamento de usuáriosNew Relic ](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts). Se a sua organização utiliza o Sistema de Gerenciamento de Identidade entre Domínios (SCIM) para o gerenciamento de usuários, esses ajustes de grupo e função devem ser realizados no seu Provedor de Identidade (IdP) externo.

## Erro de conexão inesperado no Claude Code [#connection-error]

### Problema

Ocorre um erro inesperado ao conectar o servidor MCP da New Relic via Claude Code.

### Resolução

Execute o seguinte em um novo terminal e reconecte-se:

```shell
claude mcp logout "plugin:nr:nr-mcp-server" 2>&1
```

## Credenciais OAuth desatualizadas no Claude Desktop [#stale-creds]

### Problema

O erro de conexão persiste após encerrar a sessão. Credenciais OAuth desatualizadas em cache em vários repositórios podem estar fazendo com que o Claude Desktop reutilize credenciais inativas em vez de registrar-se novamente.

### Resolução

Solicite ao Claude que ajude a localizar e limpar as credenciais desatualizadas:

```
Stale OAuth client ID or stale refresh and access tokens for MCP server `newrelic-mcp-server` is making
Claude Desktop's Connect reuse dead credentials instead of re-registering. On macOS, find
every store holding it — the "Claude Code-credentials" keychain item (`.mcpOAuth` keys, watch
for a `plugin:` prefix), `~/Library/Application Support/Claude-3p/config.json`
(`custom3pMcpOAuth."newrelic-mcp-server"`), and every registration across `claude mcp list`,
`~/.claude.json`, and project `.mcp.json` files. Show me which stores match before changing
anything; then clear it (quitting Claude Desktop and backing up config.json first), reconnect,
and confirm a new client ID/new access token is issued.
```

## Mensagem de erro

* **Conexão recusada**: Verifique o URL e a conectividade de rede das suas ferramentas.
* **Autenticação necessária**: Verifique se a chave de API ainda está ativa e foi inserida corretamente ou complete o fluxo `OAuth`.
* **Cliente inválido**: problema de configuração `OAuth`, tente o proxy `mcp-remote`.
* **`Time.UnmarshalJSON`**: Use o proxy `mcp-remote` para `OAuth`.
