O sistema de autorização padrão da New Relic controla o acesso às superfícies de <DNT>Cloud Cost Intelligence</DNT> (<DNT>Settings</DNT>, <DNT>Integrations</DNT> e <DNT>Custom Facets</DNT>). Ele divide o acesso em leitura (visualizar configuração) e gravação (criar, atualizar, excluir), por conta, não em toda a organização.

## Acesso padrão [#default-access]

Todos os usuários com acesso à conta têm acesso somente leitura por padrão.

Apenas um <DNT>Organization Admin</DNT> pode conceder acesso de modificação, edição ou exclusão — a si mesmo, a outros usuários individuais ou a uma função.

## Conceder acesso de modificação [#grant-modify-access]

Um <DNT>Organization Admin</DNT> concede acesso de gravação ao CCI por meio de uma [função personalizada](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/#roles). Duas opções estão disponíveis:

### Opção 1: adicionar permissões de CCI a uma função personalizada existente [#option-existing-role]

Se já existir uma função personalizada para uma equipe (por exemplo, uma função &quot;FinOps&quot;), adicione as capacidades de gravação do CCI a ela. Todos que já possuem essa função atribuída obtêm automaticamente acesso de gravação ao CCI. Nenhuma reatribuição por usuário é necessária.

### Opção 2: criar uma função personalizada dedicada para CCI [#option-new-role]

Crie uma função personalizada contendo apenas as capacidades de modificação do CCI (<DNT>Settings</DNT>, <DNT>Integrations</DNT>, <DNT>Custom Facets</DNT>) e, em seguida, atribua-a aos usuários específicos, grupos ou a você mesmo que precisem dela. Use esta opção para manter a administração de CCI separada das responsabilidades de qualquer outra função.
