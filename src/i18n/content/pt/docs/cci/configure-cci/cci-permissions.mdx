<Callout variant="important">
Para acessar <DNT>Cloud Cost Intelligence</DNT>, você precisa de um **SKU de CCU Avançado**, uma licença de **usuário completo da plataforma** e acesso habilitado por meio do [Gerenciador de controle de recursos](/docs/accounts/accounts-billing/new-relic-one-user-management/feature-control-manager/). Esta página aborda o acesso à configuração — quem pode modificar as configurações do CCI após o produto ser ativado para a sua organização.
</Callout>

Nosso sistema de autorização padrão controla o acesso às superfícies de <DNT>Cloud Cost Intelligence</DNT> (<DNT>Settings</DNT>, <DNT>Integrations</DNT> e <DNT>Custom Facets</DNT>). Ele divide o acesso em leitura (visualizar configuração) e escrita (criar, atualizar, excluir), por conta, não em toda a organização.

## Acesso padrão [#default-access]

Todos os usuários com acesso à conta têm acesso somente leitura por padrão.

Apenas um <DNT>Organization Admin</DNT> pode conceder acesso de modificação ou exclusão — a si mesmo, a outros usuários individuais ou a uma função.

## Referência de permissões [#permissions-reference]

A tabela a seguir lista as permissões disponíveis para cada superfície de CCI. Todos os usuários recebem acesso de leitura por padrão. Os acessos de Modificação e Exclusão exigem uma [função personalizada](#grant-modify-access).

| Superfície do CCI        | Leitura                       | Modificar                   | Excluir                     |
| ------------------------ | ----------------------------- | --------------------------- | --------------------------- |
| <DNT>Custom Facets</DNT> | Padrão para todos os usuários | Requer função personalizada | Requer função personalizada |
| <DNT>Integrations</DNT>  | Padrão para todos os usuários | Requer função personalizada | —                           |
| <DNT>Settings</DNT>      | Padrão para todos os usuários | Requer função personalizada | —                           |

## Conceder acesso de modificação [#grant-modify-access]

Um <DNT>Organization Admin</DNT> concede acesso de gravação ao CCI por meio de uma [função personalizada](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/#roles). Duas opções estão disponíveis:

### Adicionar permissões do CCI a uma função personalizada existente [#option-existing-role]

Se já existir uma função personalizada para uma equipe (por exemplo, uma função &quot;FinOps&quot;), adicione as permissões de gravação do CCI a ela. Todos aos quais essa função já foi atribuída obtêm automaticamente acesso de gravação do CCI. Você não precisa reatribuir usuários individuais.

### Criar uma função personalizada dedicada para o CCI [#option-new-role]

Crie uma função personalizada contendo apenas as permissões de modificação do CCI (<DNT>Settings</DNT>, <DNT>Integrations</DNT>, <DNT>Custom Facets</DNT>) e, em seguida, atribua-a aos usuários ou grupos específicos, ou a você mesmo, que precisarem dela. Use esta opção para manter a administração do CCI separada das responsabilidades de qualquer outra função.
