As facetas personalizadas permitem criar dimensões virtuais que agrupam os custos de cloud com base em regras definidas pelo usuário. Após criar uma faceta, ela fica disponível como uma dimensão em todos os recursos do CCI, sem a necessidade de reaplicar filtros a cada vez.

As facetas personalizadas funcionam da mesma forma que as <DNT>Custom Dimensions</DNT> integradas visíveis em <DNT>Cost Overview</DNT> (por exemplo, nome da conta, nome da equipe e ambiente), exceto pelo fato de serem definidas pelo próprio usuário, combinando tags, dimensões de cloud e condições das contas de cloud. Recomenda-se o uso de facetas personalizadas quando as tags de cloud apresentarem lacunas na cobertura ou quando for necessário combinar condições em várias dimensões. Por exemplo, é possível corresponder custos em que um serviço pertence a um grupo, um nome de equipe corresponde a um padrão ou um ambiente é excluído. Como as facetas personalizadas fazem parte do modelo de dados, em vez de serem um filtro aplicado por sessão, é possível usá-las para criar orçamentos, definir condição do alerta e calcular a economia de unidade.

Cada faceta é composta por um ou mais valores nomeados. Para cada valor, defina um conjunto de condições. O sistema avalia cada linha de custo em relação a essas condições e atribui as linhas correspondentes ao valor correspondente. As linhas que não correspondem a nenhuma condição recebem o valor padrão especificado. Por exemplo, uma faceta `platform-team` com condições correspondentes a tags da AWS, nomes de contas e regiões atribui cada linha de custo correspondente a `platform-team`.

## Casos de uso

### Agrupamento de custos multi-cloud

Se o mesmo workload for executado na AWS, no Azure e no GCP, é possível combinar os três em uma única faceta. Defina condições que correspondam às contas, aos serviços ou às tags de cada provedor. A faceta permite visualizar e agir sobre o custo combinado sem gerenciar filtros para cada cloud.

### Custo por transação entre provedores de cloud

Se um serviço abranger vários provedores de cloud, agrupe seus recursos de cada provedor em uma única faceta. É possível então usar essa faceta como a dimensão de custo em <DNT>Unit economics</DNT> para calcular o custo por transação, independentemente de qual provedor de cloud hospeda o workload.

### Orçamentos dimensionais para equipes ou projetos

Crie uma faceta que corresponda às tags ou contas pertencentes a uma equipe ou projeto. Crie um orçamento para essa faceta para que a equipe possa acompanhar seus gastos de cloud sem precisar de uma conta de cloud por equipe.

## Limites

Os seguintes limites se aplicam às facetas personalizadas.

| Item              | Detalhe                                                                                                        |
| ----------------- | -------------------------------------------------------------------------------------------------------------- |
| Máximo de facetas | O limite é de 90 por conexão, contando tags brutas, rótulos do Kubernetes e facetas personalizadas combinados. |

## Criar uma faceta personalizada

É possível criar facetas por meio da interface ou fazendo o upload de um arquivo YAML.

### Crie usando a interface

Siga estas etapas para criar uma faceta personalizada.

1. Vá para <DNT>[one.newrelic.com](https://one.newrelic.com)</DNT> &gt; <DNT>All Capabilities</DNT> &gt; <DNT>Cloud Cost Intelligence</DNT> &gt; <DNT>Custom Facets</DNT>.

2. Clique em <DNT>Create facet</DNT>.

3. Insira um <DNT>Name</DNT>, <DNT>Description</DNT> e <DNT>Default value</DNT> para a faceta.

4. Clique em <DNT>+ Add facet value</DNT>.

5. Adicione uma ou mais condições. Cada condição especifica o seguinte:

   * <DNT>Dimension</DNT> (por exemplo, conta, provedor de cloud e modelo de IA)
   * <DNT>Operator</DNT> (por exemplo, `in`, `not in`, `equals` e `regex`)
   * <DNT>Values</DNT> (um ou mais)

6. Salve a faceta.

Após salvar, é possível executar opcionalmente o NRQL gerado no editor de consultas para verificar se os valores da faceta estão corretos.

<img title="Cloud cost intelligence add facet" alt="A form for adding a custom facet with condition fields for dimension, operator, and values" src="/images/add-facet.webp" />

A faceta aparece como uma dimensão em <DNT>Cost Overview</DNT> e outros recursos de CCI após o próximo processamento do arquivo de exportação de faturamento, o que normalmente leva 4–8 horas.

### Importar usando YAML

Para definir várias facetas de uma só vez ou migrar regras de outro sistema, faça o upload de um arquivo de configuração YAML. Para ver a estrutura de arquivo necessária antes de começar, clique em <DNT>Download sample YAML</DNT> e use o exemplo como modelo.

1. Em <DNT>Custom Facets</DNT>, clique em <DNT>Upload YAML</DNT>.
2. Selecione seu arquivo de configuração.

O sistema valida o arquivo e aplica as regras.

### Preencher dados históricos

Por padrão, uma faceta se aplica aos dados de custo a partir da data em que a faceta é criada. Para aplicar as mesmas regras a dados de custo anteriores, use o backfill.

1. Após criar ou fazer o upload das regras de faceta, selecione a opção <DNT>Backfill</DNT>.
2. Especificar a data de início para o intervalo de datas passado a ser incluído.

O sistema reprocessa as linhas de custo correspondentes para esse período e preenche a dimensão da faceta. O processamento de backfill começa depois que a faceta atinge o status ativo e normalmente é concluído em 8 horas. Para monitorar o progresso, na página <DNT>Custom Facets</DNT>, acesse a guia <DNT>Audit</DNT>.

## Utilizar facetas em todo o CCI

Após criar uma faceta, ela fica disponível como uma dimensão nos seguintes recursos do CCI:

* <DNT>Cost Overview</DNT>: filtrar e agrupar custos pela dimensão da faceta
* <DNT>Budgets</DNT>: criar um orçamento com escopo para um valor de faceta
* <DNT>Query your data and Alert conditions</DNT>: Definir alertas acionados por gastos em um grupo de facetas
* <DNT>Unit economics</DNT>: Usar uma faceta como a dimensão de denominador ou numerador para cálculos de custo por unidade
* <DNT>Recommendations</DNT>: obter recomendações de otimização com escopo para o grupo de facetas
