A página <DNT>**Kubernetes Costs**</DNT> mostra quanto custa cada um dos seus clusters do Kubernetes, detalhado por CPU, memória, recursos não utilizados e não alocados. Ele usa seus dados de telemetria do Kubernetes no New Relic para correlacionar o faturamento da cloud com o uso no nível do cluster, para que você possa ver para onde vão seus gastos e onde pode reduzir custos.

<img title="Kubernetes Cost Insights highlighted on the Cloud Cost Intelligence Kubernetes Cost Insights page" alt="Kubernetes Cost Insights highlighted on the Cloud Cost Intelligence Kubernetes Cost Insights page" src="/images/k8s-cci.webp" />

## Pré-requisitos [#prerequisites]

Antes que a página <DNT>**Kubernetes Costs**</DNT> possa exibir dados, você precisa adicionar as contas da New Relic que contêm a sua telemetria do Kubernetes. A CCI usa eventos de `K8sContainerSample` dessas contas e os une aos seus dados de faturamento da cloud no ID da instância. Se você pular esta etapa, poderá ver os custos da cloud na CCI, mas não os custos do Kubernetes.

Para adicionar essas contas, complete as seguintes etapas:

1. Vá para <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Cloud Cost Intelligence &gt; Settings &gt; Telemetry Accounts**</DNT>.

2. No dropdown <DNT>**Accounts**</DNT>, selecione todas as contas da New Relic que têm dados de `K8sContainerSample`. Para verificar uma conta, execute esta consulta nela:

   ```sql
   SELECT count(*) FROM K8sContainerSample SINCE 1 day ago
   ```

3. Clique em <DNT>**Apply**</DNT>.

Depois de adicionar as contas, a CCI extrai os dados de `K8sContainerSample` e começa a alocar os custos do Kubernetes.

<Callout variant="important">
Se os seus clusters do Kubernetes reportarem a mais de uma conta da New Relic, adicione cada uma delas. Os custos de clusters em contas que você não adicionou não aparecerão na página <DNT>**Kubernetes Costs**</DNT>.
</Callout>

Se você adicionou as contas corretas e ainda não vê os custos do Kubernetes, consulte [Solução de problemas](#troubleshoot).

## Filtros e personalização

### Filtros de provedor de nuvem

Para filtrar seus dados de custo por provedor de cloud, selecione uma opção no menu dropdown no canto superior esquerdo da página:

* <DNT>**All**</DNT>: Todos os provedores de cloud
* <DNT>**AWS**</DNT>: apenas Amazon Web Services
* <DNT>**Azure**</DNT>: apenas Microsoft Azure

### Seletor de intervalo de datas

No canto superior direito da página, use o seletor de intervalo de datas para realizar uma das seguintes ações:

* Escolha um período de tempo predefinido
* Defina datas de início e fim personalizadas
* Visualize os custos no seu fuso horário preferido (UTC exibido por padrão)

### Filtro de custos de engenharia

Se a sua organização usa tags de alocação de custos, você pode filtrar pela tag <DNT>**Engineering costs**</DNT> para restringir a análise a equipes, projetos ou centros de custo específicos marcados com tag no seu ambiente de cloud.

## Resumo

A seção Resumo exibe quatro métricas de custo para o período selecionado:

| Métrica                             | Descrição                                                                                                    |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| <DNT>**Total cost**</DNT>           | Gastos agregados para todos os cluster do Kubernetes, com variação percentual em relação ao período anterior |
| <DNT>**Average cost (Daily)**</DNT> | Gasto médio diário, com variação percentual                                                                  |
| <DNT>**Unused cost**</DNT>          | Custo dos recursos que seu cluster alocou, mas que não estão recebendo requests, com variação percentual     |
| <DNT>**Unallocated cost**</DNT>     | Custo de recursos do cluster não alocados a nenhuma fonte, com alteração percentual                          |

## Insights

A seção Insights fornece dois widgets de visualização para ajudar você a analisar seus custos do Kubernetes.

### Tendências de Custos

O widget <DNT>**Cost Trends**</DNT> exibe um gráfico de linhas mostrando como seus custos do Kubernetes mudam ao longo do tempo. Use as opções de visualização para alternar entre as visualizações <DNT>**Hourly**</DNT>, <DNT>**Daily**</DNT>, <DNT>**Weekly**</DNT> ou <DNT>**Monthly**</DNT>.

### Top 20

O widget <DNT>**Top 20**</DNT> exibe as suas áreas de maior custo usando uma visualização de gráfico de árvore. Por padrão, ele mostra os 20 principais clusters por custo. Você pode personalizar a visualização com as seguintes opções:

* <DNT>**Dropdown filter**</DNT>: Selecione o que exibir (<DNT>**Cluster name, by cost**</DNT>)
* <DNT>**Group by**</DNT>: Escolha dimensões para agrupar dados de custo
* <DNT>**View by**</DNT>: Alternar entre <DNT>**Tree chart**</DNT> e outros formatos de visualização

## Cost &amp; Usage Analysis

A seção <DNT>**Cost &amp; Usage Analysis**</DNT> apresenta uma tabela com uma análise do uso de recursos e custos por nome do cluster:

| Coluna                          | Descrição                                                                         |
| ------------------------------- | --------------------------------------------------------------------------------- |
| <DNT>**Cluster name**</DNT>     | Nome do seu cluster do Kubernetes                                                 |
| <DNT>**CPU cost**</DNT>         | Custo atribuído ao uso de CPU para cada cluster                                   |
| <DNT>**CPU usage**</DNT>        | Porcentagem de recursos de CPU consumidos por cada cluster                        |
| <DNT>**Memory cost**</DNT>      | Custo associado ao uso de memória para cada cluster                               |
| <DNT>**Memory usage**</DNT>     | Porcentagem de recursos de memória usados por cada cluster                        |
| <DNT>**Unused cost**</DNT>      | Custo dos recursos que o seu cluster alocou, mas que não estão recebendo requests |
| <DNT>**Unallocated cost**</DNT> | Custo dos recursos do cluster não alocados a nenhuma origem                       |
| <DNT>**Total cost**</DNT>       | Custo combinado para cada cluster em todo o uso de recursos (classificável)       |

Se os custos não utilizados ou não alocados forem consistentemente altos para um cluster, ele pode estar superprovisionado. Consulte as [Recomendações de otimização de custos](/docs/cci/financial-intelligence/cci-recommendations) para ver maneiras de reduzir os gastos em todo o seu ambiente de cloud.

## Custos não utilizados vs. não alocados

Essas dimensões de custo ajudam você a medir a eficiência do cluster:

| Tipo de custo       | Definição                                                                | Exemplo                                                                        |
| ------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------ |
| Custo não utilizado | Recursos que o seu cluster alocou, mas que não estão recebendo requests. | Custo total: $ 5,60, utilizado: $ 4,64, custo não utilizado: $ 0,96            |
| Custo não alocado   | Recursos do cluster não alocados a nenhuma origem.                       | Custo do nó: $ 10,00, alocado para workload: $ 7,50, custo não alocado: $ 2,50 |

<Callout variant="tip">
Selecione qualquer cluster para visualizar seus <DNT>**Cost Trends**</DNT>, <DNT>**Cost Breakdown (Total vs Used)**</DNT> e informações sobre custos não utilizados e não alocados.
</Callout>

## Solucionar problemas [#troubleshoot]

### Os custos da AWS aparecem, mas nenhum custo do Kubernetes é exibido

Você ainda não adicionou as suas contas de telemetria ou adicionou apenas algumas delas. Consulte [Pré-requisitos](#prerequisites).

### Alguns clusters estão ausentes da página

Seus clusters do Kubernetes podem reportar para mais de uma conta da New Relic. Certifique-se de ter adicionado todas as contas que reportam em <DNT>**Settings &gt; Telemetry data**</DNT>.

### Você adicionou as contas corretas, mas os custos ainda não aparecem

Entre em contato com o atendimento aos clientes da New Relic.

Para problemas com a configuração, integração ou permissões da CCI, consulte [Solucionar problemas de configuração da Inteligência de Custos na Nuvem](/docs/cci/troubleshooting/troubleshooting).
