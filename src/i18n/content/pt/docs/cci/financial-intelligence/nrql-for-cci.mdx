Consulte seus dados de Inteligência de Custos na Nuvem (CCI) com a New Relic Query Language (NRQL) para analisar seus gastos de cloud e identificar oportunidades de otimização de custos. Para executar qualquer uma das consultas nesta página, acesse <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Cloud Cost Intelligence**</DNT> e abra o <DNT>**Query your data**</DNT>.

## CloudSpend [#cloudspend]

`CloudSpend` e `CloudCost` contêm os mesmos dados de faturamento do seu provedor de cloud, mas diferem em suas capacidades de NRQL. `CloudSpend` oferece suporte a toda a linguagem NRQL e é a escolha recomendada para todas as novas consultas. `CloudCost` oferece suporte a apenas um subconjunto de cláusulas NRQL e está planejado para descontinuação.

`CloudSpend` ingere itens de linha de faturamento brutos do AWS Cost and Usage Reports (CUR), exportações do Azure FOCUS e exportações do GCP BigQuery, atualizados de hora em hora. Ele compartilha atributos principais com `CloudCost`, incluindo `line_item_net_unblended_cost`, `line_item_product_code` e `line_item_usage_account_id`. Para uma referência completa de atributos, consulte o [dicionário de dados](/attribute-dictionary).

Exemplo de consulta:

```sql
FROM CloudSpend SELECT * SINCE 24 hours ago
```

Encontre o total de gastos na cloud detalhado por serviço no último mês:

```sql
FROM CloudSpend SELECT SUM(line_item_net_unblended_cost) FACET line_item_product_code SINCE 1 month ago
```

Veja a tendência dos gastos diários de cloud ao longo do tempo:

```sql
FROM CloudSpend SELECT SUM(line_item_net_unblended_cost) TIMESERIES 1 day SINCE 30 days ago
```

## KubernetesSpend [#kubernetesspend]

`KubernetesSpend` armazena registros individuais de alocação de custos para workloads do Kubernetes. Ele combina a telemetria do New Relic Infrastructure com exportações de faturamento da cloud para detalhar os custos por cluster, namespace, pod e contêiner, e oferece suporte a toda a linguagem NRQL.

Como os custos de nó do Kubernetes são compartilhados entre os workloads, `KubernetesSpend` os distribui proporcionalmente usando `cpu_weightage` e `memory_weightage`. Multiplique `net_unblended_cost` por `(cpu_weightage + memory_weightage)` para obter totais precisos de custos por workload. Para obter uma referência completa de atributos, consulte o [dicionário de dados](/attribute-dictionary).

Exemplo de consulta:

```sql
FROM KubernetesSpend SELECT * SINCE 1 week ago
```

## Custo da Nuvem [#cloudcost]

<Callout variant="important">
  Recomendamos usar `CloudSpend` para toda análise de custos e uso. Ele fornece os mesmos dados de faturamento que `CloudCost` com suporte total a NRQL.
</Callout>

`CloudCost` é um evento de resumo gerado pela Inteligência de Custos na Nuvem a partir dos Relatórios de Custo e Uso (CUR) do provedor de cloud. Ele fornece dados de itens de linha de faturamento, incluindo uso de recursos, custos e metadados de conta em contas da AWS e do Azure, atualizados a cada hora. Como `CloudCost` é pré-agregado, ele suporta apenas um subconjunto de cláusulas NRQL. Para total flexibilidade do NRQL, use `CloudSpend`.

### Atributos principais

Os seguintes atributos são mais úteis para criar consultas do CloudCost:

| Atributo                       | Descrição                                                                                                              |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| `line_item_net_unblended_cost` | Custo após o desconto para o item de linha, específico para a conta individual.                                        |
| `line_item_product_code`       | Código de serviço do provedor de cloud (por exemplo, `AmazonEC2` para AWS ou `Virtual Machine Scale Sets` para Azure). |
| `line_item_usage_account_id`   | ID da conta da AWS de 12 dígitos da conta que usou este item de linha.                                                 |
| `line_item_usage_account_name` | Nome de exibição da conta de cloud ou assinatura.                                                                      |
| `line_item_unblended_cost`     | Custo nas taxas padrão sob demanda antes de qualquer instância reservada, Savings Plan ou descontos por volume.        |
| `amortised_cost`               | Custo amortizado, incluindo taxas iniciais de reserva ou de plano de economia distribuídas ao longo do período de uso. |
| `is_k8s`                       | Sinalizador indicando se o custo está associado a um workload do Kubernetes.                                           |

Exemplo de consulta:

```sql
FROM CloudCost SELECT * SINCE 24 hours ago
```

## Custo do Kubernetes [#kubernetescost]

`KubernetesCost` é um evento de alocação de custos gerado pela Inteligência de Custos na Nuvem. Ele detalha os custos de cloud por cluster do Kubernetes, namespace, pod e contêiner. Esse tipo de evento suporta apenas um subconjunto de cláusulas NRQL.

### Atributos principais

Os seguintes atributos são mais úteis para criar consultas KubernetesCost:

| Atributo             | Descrição                                                                                          |
| -------------------- | -------------------------------------------------------------------------------------------------- |
| `total_cost`         | Custo total, calculado como a soma de `cpu_costs` e `memory_costs`.                                |
| `cpu_costs`          | Parcela do custo atribuída ao uso de CPU.                                                          |
| `memory_costs`       | Parcela do custo atribuído ao uso de memória.                                                      |
| `net_unblended_cost` | Custo líquido após descontos, com base na parcela de uso do recurso do custo do nó EC2 subjacente. |
| `cpu_usage`          | Proporção de núcleos de CPU em uso para núcleos de CPU alocados (valor entre 0 e 1).               |
| `memory_usage`       | Proporção de memória em uso para memória alocada (valor entre 0 e 1).                              |
| `cluster_name`       | Nome do cluster que hospeda os nós e pods.                                                         |
| `namespace_name`     | Namespace do Kubernetes — uma separação lógica de serviços e nós de implantação.                   |
| `pod_name`           | Nome do pod do Kubernetes, que pode hospedar um ou mais contêineres.                               |
| `container_name`     | Nome do contêiner do Docker.                                                                       |
| `node_name`          | Nó do EC2 no qual o pod está implantado.                                                           |
| `deployment_name`    | Nome da implantação do Kubernetes que gerencia o pod.                                              |

Exemplo de consulta:

```sql
FROM KubernetesCost SELECT * SINCE 1 week ago
```

Para custos precisos do Kubernetes, multiplique `cpu_weightage + memory_weightage` em suas consultas:

```sql
SELECT SUM(net_unblended_cost * (cpu_weightage + memory_weightage) + network_net_unblended_cost) FROM KubernetesCost SINCE '2026-09-01' UNTIL '2026-09-10'
```

A consulta multiplica `net_unblended_cost` pela soma da ponderação de CPU e memória para alocações precisas de custos com base no uso de recursos.

<img title="Query Console showing KubernetesCost event attributes" alt="Query Console showing KubernetesCost event attributes" src="/images/kubernetes-cost-cci.webp" />

Identifique os namespaces do Kubernetes mais caros:

```sql
FROM KubernetesCost SELECT SUM(total_cost) FACET namespace_name SINCE 1 week ago LIMIT 10
```

Compare o custo de CPU com o custo de memória por cluster:

```sql
FROM KubernetesCost SELECT SUM(cpu_costs), SUM(memory_costs) FACET cluster_name SINCE 1 week ago
```

Encontre contêineres subutilizados onde o uso da CPU é baixo:

```sql
FROM KubernetesCost SELECT average(cpu_usage) FACET container_name WHERE cpu_usage < 0.2 SINCE 3 days ago
```

## Estimativa de custo da nuvem [#cloudcostestimate]

`CloudCostEstimate` é um evento em tempo real gerado pela Inteligência de Custos na Nuvem. Ele fornece custos de cloud estimados no nível do recurso, incluindo detalhes da instância AWS e metadados, como propriedade da equipe, ambiente e nome do serviço. Esse tipo de evento suporta apenas um subconjunto de cláusulas NRQL.

### Atributos principais

Os seguintes atributos são mais úteis para criar consultas do CloudCostEstimate:

| Atributo        | Descrição                                                                                         |
| --------------- | ------------------------------------------------------------------------------------------------- |
| `cost`          | Custo estimado na moeda da sua fatura da cloud para o recurso durante o período de uso.           |
| `owning_team`   | Valor da tag `owning_team` aplicada ao recurso, se presente.                                      |
| `product_code`  | Código de serviço do provedor de cloud (por exemplo, `EC2`).                                      |
| `service_name`  | O serviço ao qual a estimativa se destina.                                                        |
| `instance_type` | Tipo de instância de EC2 da AWS (por exemplo, `m6g.8xlarge`). Aplica-se apenas a recursos da AWS. |
| `aws_region`    | Região da AWS onde o recurso está implantado (por exemplo, `us-east-2`).                          |
| `department`    | Valor da tag `department` aplicada ao recurso, se presente.                                       |
| `environment`   | Ambiente de implantação do recurso, originado da tag `environment` do recurso.                    |

Exemplo de consulta:

```sql
FROM CloudCostEstimate SELECT * SINCE 24 hours ago
```

<img title="Query Console showing CloudCostEstimate event attributes" alt="Query Console showing CloudCostEstimate event attributes" src="/images/cloud-cost-estimate.webp" />

Revise os custos estimados por equipe proprietária:

```sql
FROM CloudCostEstimate SELECT SUM(cost) FACET owning_team SINCE 24 hours ago
```
