<DNT>**Priority:**</DNT> Alto

## Resumo

Entre 17 e 20 de outubro de 2026, pesquisadores revelaram que as chaves privadas de oito certificados de autoridade de certificação (CA) intermediária emitidos pela eMudhra podem ser recuperadas (CVE-2026-111943). Qualquer pessoa com essas chaves pode criar certificados que o software aceitaria como genuínos se ainda confiar neles. Navegadores e sistemas operacionais bloquearam os certificados, mas o software que carrega sua própria lista de CAs confiáveis, incluindo algumas imagens de contêiner, precisa ser atualizado.

A New Relic atualizou os componentes de Logs abaixo para que eles não aceitem mais certificados emitidos por essas CAs. As versões atualizadas não são obtidas automaticamente. Os clientes precisam atualizar para as versões listadas abaixo.

**Nota para usuários do FireLens:** o plug-in em si agora rejeita certificados emitidos pelas CAs afetadas. A imagem base fornecida pela AWS (`aws-for-fluent-bit`) ainda pode listar as CAs raiz afetadas em seu próprio pacote de CAs até que a AWS publique uma imagem reconstruída. Atualizaremos este boletim quando ele estiver disponível.

## Informações sobre vulnerabilidades técnicas

[CVE-2026-111943](https://www.cve.org/CVERecord?id=CVE-2026-111943)

Oito CAs intermediárias que formam uma cadeia com a emSign ECC Root CA - G3 e, por meio de assinatura cruzada, com a AAA Certificate Services, foram afetadas.

* O plug-in é compilado com Go 1.27.3, cuja biblioteca TLS recusa cadeias de certificados que contêm as oito chaves afetadas, mesmo se a raiz ainda for confiável.
* O Fluent Bit 5.1.5 teve as raízes afetadas removidas do pacote de CA de suas imagens base.
