Com os Limites de usuário de computar, você pode definir orçamentos diários ou mensais para usuários individuais em sua organização e gerenciar o acesso deles aos recursos do New Relic com base no consumo de computar. Cada orçamento monitora o computar principal (CCUs principais) e o computar avançado (CCUs avançadas) como medidores separados. Quando um usuário atinge seu orçamento alocado para um medidor, você pode bloquear o acesso dele aos recursos associados até o final do período do orçamento ou até que você aumente o orçamento dele.

Também simplifica o gerenciamento de orçamento em escala com um orçamento global de usuário que se aplica a todos os usuários, para que não seja necessário configurar um orçamento para cada usuário individualmente. Para usuários com necessidades específicas, é possível criar orçamentos de substituição personalizados.

Use os limites de usuário de computar para fazer o seguinte:

* Controlar custos de computação limitando o consumo por usuário
* Monitorar o consumo de computação no nível do usuário
* Mantenha a visibilidade dos padrões de uso de computar do usuário em toda a sua organização
* Gerenciar orçamentos de computar do usuário em toda uma grande organização

## Principais capacidades

Dois tipos de orçamento estão disponíveis:

* **Orçamento global do usuário**: defina um orçamento padrão que se aplica a todos os usuários da sua organização.
* **Orçamentos de substituição personalizados**: atribuir orçamentos específicos a usuários individuais que precisam de limites maiores ou menores que o orçamento global.

Para ambos os tipos de orçamento, configure o seguinte por medidor:

* **Limite de CCU principal**: definido como uma porcentagem do orçamento de computar em nível de organização, com o valor de CCU equivalente calculado automaticamente. Escolha **Block CCU usage** ou **Do not block CCU usage** como o tipo de limite para este medidor.
* **Limite avançado de CCU**: defina como uma porcentagem do orçamento de computar no nível da sua organização, com o valor equivalente de CCU calculado automaticamente. Escolha **Block CCU usage** ou **Do not block CCU usage** como o tipo de limite para este medidor.

O rastreamento de orçamento se aplica apenas quando se configura um orçamento global ou orçamentos de substituição personalizados.

Se um orçamento global foi configurado, todos os usuários recebem automaticamente esse orçamento. Se apenas orçamentos de substituição personalizados foram criados sem um orçamento global, os usuários sem orçamentos personalizados têm acesso irrestrito.

Se você precisar gerenciar o uso pelo New Relic Autopilot, por gentileza, use o nosso recurso de [limites de computar do Autopilot](/docs/agentic-ai/autopilot/autopilot-compute-limits/) em vez disso.

## Como funcionam os limites de usuário

Os limites de usuário rastreiam o consumo de computar de cada usuário em dois medidores independentes: computar principal (core CCUs) e computar avançado (advanced CCUs). Quando você atribui um orçamento a um usuário, a atividade de computar dele conta para o medidor apropriado. Cada medidor tem seu próprio valor de orçamento e tipo de limite.

Por exemplo, se um usuário tem um orçamento de 10.000 CCUs core e um orçamento de 5.000 CCUs avançados, a atividade padrão de computar, como executar consulta e atualizar dashboards, conta para o limite de CCU core, e a atividade avançada de computar, como Ask AI, Live Archives e MCP, conta para o limite de CCU avançado.

Quando um usuário atinge seu orçamento alocado para um medidor, o tipo de limite configurado para esse medidor entra em vigor.

### Medidores de computar principais e avançados

O computar principal (core CCUs) abrange dashboard, criador de consulta e chamada de API. O computar avançado (advanced CCUs) abrange recursos como o Live Archives e recursos com tecnologia de IA.

Quando o orçamento de CCU principal de um usuário se esgota e o tipo de limite é definido como **Block CCU usage**, ele perde o acesso ao seguinte:

* [Painel](/docs/query-your-data/explore-query-data/dashboards/introduction-dashboards)
* [Criador de consultoria](/docs/query-your-data/explore-query-data/query-builder/introduction-query-builder)
* Chamada de API

Quando o orçamento de CCU avançado de um usuário é esgotado e o tipo de limite é definido como **Block CCU usage**, ele perde o acesso ao seguinte:

* [Ask AI](/docs/agentic-ai/new-relic-ai) (V1 e V2)
* [Live Archives](/docs/logs/get-started/live-archives) (o botão Consulta Live Archives e a opção Usar Live Archives no criador de consulta)
* [MCP](/docs/agentic-ai/mcp/overview)
* [Errors Inbox](/docs/apm/errors-inbox/errors-inbox-ui) (Explicar erro e gerar Insights)

Os seguintes produtos avançados que consomem CCU não são suportados por este recurso Limites de usuário de computar e permanecem acessíveis mesmo quando o orçamento de CCU avançado de um usuário atinge 100%:

* Controle de pipeline
* Cardinalidade ilimitada
* Transaction 360
* Security RX
* Conhecimento do New Relic AI
* Autopilot

<Callout variant="tip">
A lista de produtos avançados de CCU sujeitos à aplicação pode crescer à medida que mais produtos alcançam a disponibilidade geral. Consulte aqui novamente para obter atualizações sobre os produtos avançados de CCU compatíveis.
</Callout>

### Frequência do orçamento

Ao criar um orçamento, você escolhe se ele é redefinido diariamente ou mensalmente. A escolha certa depende dos padrões de trabalho dos seus usuários e do rigor com que você precisa controlar os custos.

A tabela a seguir compara os orçamentos mensais e diários:

| Comportamento            | Mensal                            | Diário                                    |
| ------------------------ | --------------------------------- | ----------------------------------------- |
| **Reinicializações**     | Início de cada mês civil (UTC)    | Início de cada dia do calendário (UTC)    |
| **Remoções de bloqueio** | Início do próximo mês civil (UTC) | Início do próximo dia do calendário (UTC) |

Escolha um orçamento mensal se alguma das seguintes opções se aplicar:

* Seus usuários têm um uso diário variável que se equilibra na média ao longo de um período de faturamento — por exemplo, desenvolvedores que executam consultas intensivas no final de um sprint, mas que, de outra forma, têm um uso leve.
* Você deseja que o período do orçamento se alinhe ao seu ciclo de faturamento
* Você deseja apenas uma redefinição por mês

Escolha um orçamento diário se alguma das seguintes condições se aplicar:

* Você deseja limitar o quanto uma consulta ou script fora de controle pode consumir em um único dia
* Seus usuários têm um uso diário consistente e você deseja um limite diário fixo
* Você deseja uma janela de recuperação mais curta: um usuário bloqueado sob um orçamento diário recupera o acesso no dia seguinte, em vez de esperar até o final do mês

<Callout variant="tip">
Limites diários podem bloquear usuários em dias de alto uso, mesmo quando seu uso total teria permanecido dentro de um orçamento mensal. Analise os padrões de uso típicos dos seus usuários antes de aplicar limites diários de forma ampla.
</Callout>

### Notificações de orçamento

As notificações são acionadas de forma independente para cada medidor de computar. As notificações no aplicativo são acionadas em todos os quatro limites; as notificações por e-mail são acionadas apenas em 75% e 100%.

| Limite   | Urgência    | Notificação no aplicativo | E-mail |
| -------- | ----------- | ------------------------- | ------ |
| **50%**  | Informações | ✓                         | —      |
| **75%**  | Aviso       | ✓                         | ✓      |
| **95%**  | Crítico     | ✓                         | —      |
| **100%** | Crítico     | ✓                         | ✓      |

Por exemplo, um usuário com um orçamento de 100.000 CCUs core e um orçamento de 200.000 CCUs advanced recebe notificações de CCUs core em 50.000; 75.000; 95.000; e 100.000 CCUs core, e notificações separadas de CCUs advanced em 100.000; 150.000; 190.000; e 200.000 CCUs advanced. As notificações por e-mail são enviadas nos limites de 75% e 100% para cada medidor.

### Aplicação de orçamento

Como gerente da organização, você configura os tipos de limite de forma independente para cada medidor de computar. Isso significa que você pode, por exemplo, aplicar **Block CCU usage** ao computar principal de um usuário enquanto define **Do not block CCU usage** para o seu computar avançado, ou aplicar o mesmo tipo de limite a ambos.

**Para computar o núcleo, escolha uma das seguintes opções:**

* **Block CCU usage** (Bloquear uso de CCU): quando um usuário esgota seu orçamento, notifique-o e bloqueie o acesso ao criador de consulta, aos Dashboards e às chamadas de API: executar consultas, atualizar dashboards e fazer chamadas de API.
* **Do not block CCU usage** (Não bloquear uso de CCU): quando um usuário esgota seu orçamento, notifique-o, mas não bloqueie o acesso a nenhum produto que consuma CCU. Esta opção mantém o acesso total à plataforma, mas não evita excedentes.

**Para computar avançado, escolha uma das seguintes opções:**

* **Block CCU usage** (Bloquear o uso de CCU): quando um usuário esgota seu orçamento, notifique-o e bloqueie o acesso a recursos como: [Ask AI](/docs/agentic-ai/new-relic-ai), [Live Archives](/docs/logs/get-started/live-archives), [MCP](/docs/agentic-ai/mcp/overview) e [Errors Inbox](/docs/apm/errors-inbox/errors-inbox-ui).
* **Do not block CCU usage** (Não bloquear uso de CCU): quando um usuário esgota seu orçamento, notifique-o, mas não bloqueie o acesso a ações que consomem CCU. Esta opção mantém o acesso total à plataforma, mas não evita excedentes.

Quando bloqueados, os usuários veem uma tela que informa que usaram seu orçamento para o período e que podem entrar em contato com um gerente da organização em caso de dúvidas.

<Callout variant="tip">
Se você estiver implementando limites de orçamento pela primeira vez, comece com **Do not block CCU usage** para ambos os medidores. Isso permite que você observe os padrões de uso reais antes de habilitar o bloqueio, reduzindo a chance de interrupções de acesso inesperadas.
</Callout>

<Callout variant="important">
Para orçamentos mensais, os bloqueios permanecem em vigor até o final do mês civil (UTC). Para orçamentos diários, os bloqueios permanecem em vigor até o final do dia civil (UTC). Em ambos os casos, você pode restaurar o acesso mais cedo aumentando o orçamento do usuário. Os dados de consumo são atualizados em algumas horas (normalmente de 2 a 4 horas), portanto, o bloqueio não ocorre exatamente em 100%. Os usuários podem exceder o seu orçamento antes que o bloqueio entre em vigor.
</Callout>

## Configurar um orçamento global de usuário

Se a organização abranger mais de uma organização do New Relic, é necessário fazer login em cada uma separadamente para criar e gerenciar limites de usuário para cada usuário.

<Steps>
<Step>
### Acessar Orçamentos Compute

1. Vá para <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; [user menu](/docs/accounts/accounts-billing/general-account-settings/intro-account-settings)**</DNT>.
2. Selecione <DNT>**Administration &gt; Compute Budgets**</DNT>.
</Step>

<Step>
### Abra o assistente de orçamento global

No cartão <DNT>**Global user budget**</DNT>, clique em <DNT>**Manage budget**</DNT>. O assistente <DNT>**Manage global budget**</DNT> é aberto.
</Step>

<Step>
### Definir a frequência do orçamento

Em <DNT>**Set the frequency**</DNT>, selecione com que frequência o orçamento é redefinido:

* <DNT>**Monthly**</DNT>: rastreia o uso ao longo do mês civil e é redefinido no início de cada mês (UTC).
* <DNT>**Daily**</DNT>: acompanha o uso ao longo de cada dia civil e é redefinido no início de cada dia (UTC).

Clique em <DNT>**Next**</DNT>.
</Step>

<Step>
### Definir orçamento de CCU principal

1. Em <DNT>**Budget allocation**</DNT>, insira a porcentagem do orçamento de CCU principal da sua organização para alocar a cada usuário. O assistente mostra o valor equivalente de CCU avançado à medida que você digita. Por exemplo, se a sua organização tem 800.000 CCUs principais e você define 5%, cada usuário recebe 40.000 CCUs principais. Os orçamentos de usuário podem exceder o orçamento total da sua organização.

2. Em <DNT>**Limit type**</DNT>, escolha o que acontece quando um usuário atinge 100% do seu orçamento de CCU principal:

   * <DNT>**Block CCU usage**</DNT>: notificar o usuário e bloquear o acesso a ações que consomem CCU: executar consulta, atualizar dashboard e fazer chamada de API.
   * <DNT>**Do not block CCU usage**</DNT>: notificar o usuário, mas manter o acesso total à plataforma. Isso não evita excedentes.

Clique em <DNT>**Next**</DNT>.
</Step>

<Step>
### Definir orçamento de CCU avançado

1. Em <DNT>**Budget allocation**</DNT>, insira a porcentagem do orçamento de CCU avançado da sua organização para alocar a cada usuário. O assistente mostra o valor de CCU equivalente à medida que você digita. Os orçamentos de usuário podem exceder o orçamento total da sua organização.

2. Em <DNT>**Limit type**</DNT>, escolha o que acontece quando um usuário atinge 100% do seu orçamento de CCU avançado:

   * <DNT>**Block CCU usage**</DNT>: Notificar o usuário e bloquear o acesso a [Ask AI](/docs/agentic-ai/new-relic-ai), [Live Archives](/docs/logs/get-started/live-archives), [MCP](/docs/agentic-ai/mcp/overview) e [Errors Inbox](/docs/apm/errors-inbox/errors-inbox-ui).
   * <DNT>**Do not block CCU usage**</DNT>: notificar o usuário, mas manter o acesso total à plataforma. Isso não evita excedentes.

Clique em <DNT>**Next**</DNT>.
</Step>

<Step>
### Revisar notificações

Esta página confirma o limite de notificação que o usuário recebe para cada medidor de computar. Nenhuma configuração é necessária. Clique em <DNT>**Finish**</DNT> para criar o orçamento global de usuário.
</Step>
</Steps>

## Configurar orçamentos de substituição personalizados

Crie orçamentos de substituição personalizados para usuários que precisam de limites diferentes do orçamento global. Use essa abordagem ao integrar uma equipe ou aplicar um limite uniforme a um grupo sem configurar cada usuário individualmente.

<Steps>
<Step>
### Criar um orçamento de usuário

Na página <DNT>**User Limits**</DNT>, clique em <DNT>**Create a user budget**</DNT>. O assistente <DNT>**Create custom user budget**</DNT> é aberto.
</Step>

<Step>
### Definir a frequência e selecionar usuário

1. Em <DNT>**Set the frequency**</DNT>, selecione com que frequência o orçamento é redefinido:

   * <DNT>**Monthly**</DNT>: rastreia o uso ao longo do mês civil e é redefinido no início de cada mês (UTC).
   * <DNT>**Daily**</DNT>: acompanha o uso ao longo de cada dia civil e é redefinido no início de cada dia (UTC).

2. Em <DNT>**Select users**</DNT>, escolha um ou mais usuários no dropdown para atribuir este orçamento de substituição personalizado. Quando você seleciona vários usuários, o mesmo orçamento se aplica a cada usuário individualmente — eles não compartilham um único orçamento.

Clique em <DNT>**Next**</DNT>.
</Step>

<Step>
### Definir orçamento de CCU principal

1. Em <DNT>**Budget allocation**</DNT>, insira a porcentagem do orçamento principal de CCU da sua organização para alocar a este usuário. O assistente mostra o valor equivalente de CCU conforme você digita. Os orçamentos de usuário podem exceder o orçamento total da sua organização.

2. Em <DNT>**Limit type**</DNT>, escolha o que acontece quando o usuário atinge 100% do seu orçamento de CCU principal. Isso pode diferir das configurações globais de orçamento.

   * <DNT>**Block CCU usage**</DNT>: notificar o usuário e bloquear o acesso a ações que consomem CCU: executar consulta, atualizar dashboard e fazer chamada de API.
   * <DNT>**Do not block CCU usage**</DNT>: notificar o usuário, mas manter o acesso total à plataforma. Isso não evita excedentes.

Clique em <DNT>**Next**</DNT>.
</Step>

<Step>
### Definir orçamento de CCU avançado

1. Em <DNT>**Budget allocation**</DNT>, insira a porcentagem do orçamento de CCU avançado da sua organização para alocar a este usuário. O assistente mostra o valor equivalente de CCU conforme você digita. Os orçamentos de usuário podem exceder o orçamento total da sua organização.

2. Em <DNT>**Limit type**</DNT>, escolha o que acontece quando o usuário atinge 100% de seu orçamento de CCU avançado. Isso pode ser diferente das configurações de orçamento global.

   * <DNT>**Block CCU usage**</DNT>: Notificar o usuário e bloquear o acesso a [Ask AI](/docs/agentic-ai/new-relic-ai), [Live Archives](/docs/logs/get-started/live-archives), [MCP](/docs/agentic-ai/mcp/overview) e [Errors Inbox](/docs/apm/errors-inbox/errors-inbox-ui).
   * <DNT>**Do not block CCU usage**</DNT>: notificar o usuário, mas manter o acesso total à plataforma. Isso não evita excedentes.

Clique em <DNT>**Next**</DNT>.
</Step>

<Step>
### Revisar notificações

Revise os limites de notificação que se aplicam a este usuário para cada medidor de computar. Clique em <DNT>**Finish**</DNT> para criar o orçamento de substituição personalizado.
</Step>
</Steps>

Depois de criá-los, os orçamentos de substituição personalizados aparecem na tabela de orçamentos de usuário como itens de linha separados. Você pode atualizá-los individualmente ou usar o dropdown <DNT>**Group by**</DNT> para visualizar e gerenciar usuários que compartilham a mesma alocação, tipo de limite e frequência.

## Gerenciar limites de usuário

### Visualizar o consumo do orçamento

Os gerentes da organização veem o cartão <DNT>**Global user budget**</DNT> na parte superior da página <DNT>**Compute Budgets**</DNT>. O cartão mostra as quantidades configuradas de CCU principal e CCU avançado, a porcentagem alocada por usuário e o tipo de limite para cada medidor.

Abaixo do cartão, a tabela <DNT>**User budgets**</DNT> mostra os orçamentos de substituição personalizados com as seguintes colunas:

| Coluna                 | Descrição                                                                                                                                              |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Usuário**            | O endereço de e-mail do usuário                                                                                                                        |
| **Frequência**         | Se o orçamento é redefinido diariamente ou mensalmente                                                                                                 |
| **Uso principal**      | Consumo atual de CCU core como uma porcentagem da alocação, ou **Blocked** se o usuário estiver acima do orçamento com a opção Block CCU usage ativada |
| **Alocação principal** | O valor do orçamento principal de CCU e o tipo de limite configurado (Bloquear ou Não bloquear)                                                        |
| **Uso avançado**       | Consumo atual de CCU avançado como uma porcentagem da alocação, ou **Próximo ao limite** ao se aproximar do limite                                     |
| **Alocação avançada**  | O valor do orçamento de CCU avançado e o tipo de limite configurado (Bloquear ou Não bloquear)                                                         |

Use <DNT>**Group by &gt; Allocation, limit, and frequency**</DNT> para fazer cluster de usuários que compartilham a mesma configuração de orçamento. Cada cabeçalho de grupo resume a configuração, por exemplo: `Core CCU 45,000 CCU · Block | Advanced CCU 100,000 CCU · Do not block | Monthly`.

Os **gerentes da organização** podem fazer o seguinte:

* Visualize todos os orçamentos de substituição personalizados na tabela com todos os detalhes

* Acesse um menu de três pontos (**⋯**) ao lado de cada orçamento. O menu inclui as seguintes opções:

  * <DNT>**View**</DNT>: Ver informações detalhadas do orçamento, consumo e tendências
  * <DNT>**Edit**</DNT>: Modificar as configurações do orçamento
  * <DNT>**Delete**</DNT>: Remover o orçamento

**Usuários somente leitura** podem fazer o seguinte:

* Ver seu próprio orçamento como um item de linha na tabela, seja uma substituição personalizada ou um orçamento global
* Acesse apenas a opção <DNT>**View**</DNT> no menu de três pontos

Usuários somente leitura não podem ver os orçamentos de outros usuários ou usar <DNT>**Edit**</DNT> ou <DNT>**Delete**</DNT>.

### Visualização de detalhes do orçamento [#budget-details]

Ao visualizar um orçamento (disponível para todos os usuários para o próprio orçamento), é possível ver:

* Consumo atual de CCU principal e CCU avançado
* Porcentagem de cada orçamento usado
* Tendências de consumo para o período
* Status de bloqueio em 100% para cada medidor
* Status da notificação

### Ajustar orçamentos [#adjust-budgets]

Como gerente da organização, é possível modificar os orçamentos a qualquer momento:

* <DNT>**Edit existing budgets**</DNT>: atualize os valores, a frequência ou os tipos de limite do orçamento para um único usuário, ou use a visualização de grupo para atualizar o orçamento para todos os usuários de um grupo de uma só vez
* <DNT>**Increase a user&apos;s budget**</DNT>: Restaurar o acesso para usuários bloqueados ou fornecer capacidade adicional
* <DNT>**Decrease budgets**</DNT>: ajustar os valores do orçamento para os períodos de orçamento atuais e futuros
* <DNT>**Delete budgets**</DNT>: Exclua os orçamentos globais e de substituição personalizados. Quando você exclui um orçamento de substituição personalizado, o usuário retorna automaticamente ao orçamento global do usuário (se você tiver configurado um).

As alterações nos orçamentos entram em vigor em aproximadamente 15 minutos.

<Callout variant="important">
Excluir um orçamento personalizado não remove o rastreamento de orçamento. O rastreamento de orçamento continua sob o orçamento global (se você tiver configurado um).
</Callout>

### Lidar com usuários bloqueados

Quando um usuário é bloqueado devido ao consumo de orçamento, ele pode fazer o seguinte:

* Ver uma mensagem que diz que usaram seu orçamento para o período
* Ver os detalhes do seu orçamento para verificar o consumo
* Entrar em contato para solicitar um aumento de orçamento

Para restaurar o acesso de um usuário bloqueado, escolha uma das seguintes opções:

* Aumentar seu orçamento. Consulte [Ajustar orçamentos](#adjust-budgets).
* Aguarde até que o orçamento seja redefinido no início do próximo período do orçamento. Consulte [Frequência do orçamento](#budget-frequency).

<Callout variant="tip">
É recomendado publicar uma lista interna de gerentes da organização para que os usuários saibam quem contatar para aumentos de limite e garantir que pelo menos um esteja disponível para aprovar os aumentos rapidamente durante um incidente de serviço.
</Callout>

## Cenários comuns

**Quando os orçamentos são redefinidos?** Depende da frequência selecionada ao configurar o orçamento:

* **Mensal**: os orçamentos são redefinidos no início de cada mês civil (UTC).
* **Diário**: os orçamentos são redefinidos no início de cada dia do calendário (UTC).

**O que acontece com as consultas em andamento quando um usuário atinge 100% do seu orçamento principal de CCU?** As consultas em execução são concluídas. O bloqueio apenas impede que novas consultas, carregamentos de dashboard e chamadas de API sejam iniciados após a aplicação do bloqueio. Veja a nota acima sobre os atrasos no relatório de dados de consumo.

**O que acontece quando um usuário atinge 100% do seu orçamento de CCU avançado?** Se o tipo de limite de CCU avançado estiver definido como **Block CCU usage**, os usuários perdem o acesso ao [Ask AI](/docs/agentic-ai/new-relic-ai), ao [Live Archives](/docs/logs/get-started/live-archives), ao [MCP](/docs/agentic-ai/mcp/overview) e ao [Errors Inbox](/docs/apm/errors-inbox/errors-inbox-ui). Se o tipo de limite for **Do not block CCU usage**, os usuários continuam a ter acesso total, mas recebem notificações.

**O que acontece com um usuário quando excluo seu orçamento de substituição personalizado?** O usuário retorna automaticamente ao orçamento global do usuário se você tiver configurado um. Se não existir um orçamento global, o usuário terá acesso irrestrito.

**O que acontece com os usuários que não têm um orçamento atribuído?** Usuários sem um orçamento atribuído têm acesso irrestrito a dashboards, criador de consulta, chamadas de API e recursos de IA.

**Em quanto tempo as alterações de orçamento entram em vigor?** As alterações de orçamento entram em vigor em aproximadamente 15 minutos.
