Com os Limites de usuário de computar, você pode definir orçamentos diários ou mensais para usuários individuais na sua organização e gerenciar o acesso deles aos recursos da New Relic com base no consumo de computar. Quando um usuário atinge seu orçamento alocado, você pode bloquear o acesso dele a dashboards, ao criador de consulta e a chamadas de API até o final do período do orçamento ou até que você aumente o orçamento dele.

Também simplifica o gerenciamento de orçamento em escala com um orçamento global de usuário que se aplica a todos os usuários, para que não seja necessário configurar um orçamento para cada usuário individualmente. Para usuários com necessidades específicas, é possível criar orçamentos de substituição personalizados.

Use os limites de usuário de computar para fazer o seguinte:

* Controlar custos de computação limitando o consumo por usuário
* Monitorar o consumo de computação no nível do usuário
* Manter a visibilidade dos padrões de uso em toda a organização
* Gerenciar orçamentos em uma grande organização

## Principais capacidades

Dois tipos de orçamento estão disponíveis:

* **Orçamento global de usuário**: definir um orçamento padrão que se aplica a todos os usuários na organização. Configurar como um dos seguintes:

  * **Porcentagem do orçamento da organização**: alocar uma porcentagem do orçamento compute no nível da organização (com base nos compromissos mínimos) para cada usuário
  * **Valor real de computação**: especificar um número exato de unidades de capacidade de computação (CCUs) para cada usuário

* **Orçamentos de substituição personalizados**: atribuir orçamentos específicos a usuários individuais que precisam de limites maiores ou menores que o orçamento global.

O rastreamento de orçamento se aplica apenas quando se configura um orçamento global ou orçamentos de substituição personalizados.

Se um orçamento global foi configurado, todos os usuários recebem automaticamente esse orçamento. Se apenas orçamentos de substituição personalizados foram criados sem um orçamento global, os usuários sem orçamentos personalizados têm acesso irrestrito.

## Como funcionam os limites de usuário

Os limites de usuário rastreiam o consumo de computação de cada usuário. Ao atribuir um orçamento a um usuário, toda a sua atividade de computação conta para esse orçamento. Quando um usuário tem CCU e CoreCCU, apenas o CCU conta para os limites do orçamento.

Por exemplo, se um usuário tiver um orçamento de 1.000 CCUs, todo o consumo de computar que é atributo do seu ID de usuário ou chave de API contará para esse limite.

Quando um usuário atinge seu orçamento alocado, as regras configuradas de bloqueio ou monitoramento entram em vigor.

### Frequência do orçamento

Ao criar um orçamento, você escolhe se ele é redefinido diariamente ou mensalmente. A escolha certa depende dos padrões de trabalho dos seus usuários e do rigor com que você precisa controlar os custos.

A tabela a seguir compara os orçamentos mensais e diários:

| Comportamento            | Mensal                            | Diário                                    |
| ------------------------ | --------------------------------- | ----------------------------------------- |
| **Reinicializações**     | Início de cada mês civil (UTC)    | Início de cada dia do calendário (UTC)    |
| **Remoções de bloqueio** | Início do próximo mês civil (UTC) | Início do próximo dia do calendário (UTC) |

Escolha um orçamento mensal se alguma das seguintes opções se aplicar:

* Seus usuários têm um uso diário variável que se equilibra na média ao longo de um período de faturamento — por exemplo, desenvolvedores que executam consultas intensivas no final de um sprint, mas que, de outra forma, têm um uso leve.
* Você deseja que o período do orçamento se alinhe ao seu ciclo de faturamento
* Você deseja apenas uma redefinição por mês

Escolha um orçamento diário se alguma das seguintes condições se aplicar:

* Você deseja limitar o quanto uma consulta ou script fora de controle pode consumir em um único dia
* Seus usuários têm um uso diário consistente e você deseja um limite diário fixo
* Você deseja uma janela de recuperação mais curta: um usuário bloqueado sob um orçamento diário recupera o acesso no dia seguinte, em vez de esperar até o final do mês

<Callout variant="tip">
  Limites diários podem bloquear usuários em dias de alto uso, mesmo quando seu uso total teria permanecido dentro de um orçamento mensal. Analise os padrões de uso típicos dos seus usuários antes de aplicar limites diários de forma ampla.
</Callout>

### Notificações de orçamento

Recebe-se notificação de banner no aplicativo em cada limite a seguir:

* **50% do orçamento consumido**: banner informativo amarelo
* **75% do orçamento consumido**: banner de aviso amarelo
* **95% do orçamento consumido**: Banner crítico vermelho
* **100% do orçamento consumido**: banner informativo indicando que o usuário está acima do orçamento

Você também recebe notificações por e-mail com 75% e 100% do orçamento consumido.

Estas notificações mantêm você informado sobre o seu status de consumo.

### Aplicação de orçamento

Como gerente da organização, é possível escolher o que acontece quando um usuário atinge 100% de seu orçamento alocado:

* **Bloquear o usuário**: o bloqueio impede que o usuário acesse o seguinte:

  * Acesso ao dashboard
  * Acesso ao criador de consulta
  * Acesso à API por meio da ID de usuário ou chave de API

  Quando bloqueados, os usuários veem uma tela que informa que usaram seu orçamento para o período e que podem entrar em contato com um gerente da organização em caso de dúvidas.

* **Apenas monitorar**: apenas notificar o usuário sobre o consumo do seu orçamento sem bloquear o acesso.

<Callout variant="tip">
  Se você estiver implementando limites de orçamento pela primeira vez, comece apenas com o monitoramento. Isso permite que você observe os padrões reais de uso antes de habilitar o bloqueio, reduzindo a chance de interrupções inesperadas de acesso.
</Callout>

<Callout variant="important">
  Para orçamentos mensais, os bloqueios permanecem em vigor até o final do mês civil (UTC). Para orçamentos diários, os bloqueios permanecem em vigor até o final do dia civil (UTC). Em ambos os casos, é possível restaurar o acesso mais cedo aumentando o orçamento do usuário. Os dados de consumo são atualizados em algumas horas (normalmente 2–4 horas), portanto, o bloqueio não ocorre exatamente em 100%. Os usuários podem exceder ligeiramente seu orçamento antes que o bloqueio entre em vigor.
</Callout>

## Antes de você começar

Ao criar qualquer orçamento, você define quatro configurações. Revisá-las antes de começar ajuda a fazer as escolhas certas no assistente de configuração.

| Contexto               | Opções                                                       | O que considerar                                                                                                                                               |
| ---------------------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Tipo de orçamento**  | Substituição global ou personalizada                         | Comece com um orçamento global como seu baseline. Adicione substituições personalizadas para usuários que precisam de limites diferentes.                      |
| **Método de alocação** | Porcentagem do orçamento da organização ou valor real de CCU | Use a porcentagem se quiser que os limites sejam dimensionados de acordo com os compromissos da sua organização. Use um valor real para um limite fixo de CCU. |
| **Frequência**         | Mensal ou diário                                             | Consulte [Frequência do orçamento](#budget-frequency) para obter orientações sobre como escolher entre eles.                                                   |
| **Imposição**          | Bloquear ou apenas monitorar                                 | Comece apenas com o monitoramento para observar os padrões reais de uso antes de habilitar o bloqueio.                                                         |

## Configurar um orçamento global de usuário

Se a organização abranger mais de uma organização do New Relic, é necessário fazer login em cada uma separadamente para criar e gerenciar limites de usuário para cada usuário.

<Steps>
  <Step>
    ### Acessar Orçamentos Compute

    1. Vá para <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; [user menu](/docs/accounts/accounts-billing/general-account-settings/intro-account-settings)**</DNT>.
    2. Selecione <DNT>**Administration &gt; Compute Budgets**</DNT>.
  </Step>

  <Step>
    ### Adicionar um orçamento global

    Basta clicar em <DNT>**Create a global user budget**</DNT> para criar um orçamento que se aplique a todo usuário na organização na qual se fez login.
  </Step>

  <Step>
    ### Configurar o orçamento

    1. Escolher como alocar orçamentos:

       * **Porcentagem do orçamento da organização**: alocar uma porcentagem do orçamento de computação no nível da organização (com base em seus compromissos mínimos) para cada usuário. Por exemplo, se a organização tiver 800.000 Core CCUs e for definido 1% por usuário, cada usuário receberá 8.000 Core CCUs. A porcentagem total de todo usuário não precisa ser igual a 100%. É possível definir o total abaixo de 100% (deixando parte do orçamento não alocada) ou acima de 100%. Definir o agregado acima de 100% é aceitável.
       * **Valor real**: especifique um número exato de CCUs para cada usuário.

    2. Insira o valor do orçamento.

    3. Em <DNT>**Set the frequency**</DNT>, selecione com que frequência o orçamento é redefinido:

       * **Mensal**: rastreia o uso ao longo do mês civil e é redefinido no início de cada mês (UTC).
       * **Diário**: rastreia o uso ao longo de cada dia civil e é redefinido no início de cada dia (UTC).

    4. Clique em <DNT>**Next**</DNT>.
  </Step>

  <Step>
    ### Revisar notificações de orçamento global

    Esta página confirma os limites de notificação que os usuários recebem. Nenhuma configuração é necessária. Clique em <DNT>**Next**</DNT> para continuar.
  </Step>

  <Step>
    ### Configurar o bloqueio de orçamento global

    1. Escolha como limitar o uso quando os usuários excederem seu orçamento de CCU. Os limites começam quando o orçamento se esgota e duram até o final do período do orçamento (dia ou mês) ou até que você os altere. Selecione um dos seguintes:

       * **Bloquear uso adicional de CCU**: os usuários não podem acessar dashboards, o criador de consulta ou chamadas de API quando atingem o limite de orçamento. Quando um usuário esgota o orçamento, o bloqueio se aplica a ações que consomem CCU, como executar consultas ou atualizar dashboards.
       * **Não limitar o uso**: os usuários recebem notificações, mas mantêm acesso total a todos os recursos. Isso não evita excedentes.

       Você recebe uma notificação quando os limites entram em vigor.

    2. Clique em <DNT>**Finish**</DNT> para criar o orçamento global de usuário.
  </Step>
</Steps>

## Configurar orçamentos de substituição personalizados

Crie orçamentos de substituição personalizados para usuários que precisam de limites diferentes do orçamento global. Use essa abordagem ao integrar uma equipe ou aplicar um limite uniforme a um grupo sem configurar cada usuário individualmente.

<Steps>
  <Step>
    ### Adicionar um orçamento de usuário

    Na página <DNT>**User Limits**</DNT> , clique em <DNT>**+ Create a user budget**</DNT>.
  </Step>

  <Step>
    ### Selecionar usuários

    No menu dropdown, selecione um ou mais usuários para atribuir um orçamento de substituição personalizado. Ao selecionar vários usuários, o mesmo valor de orçamento se aplica a cada usuário individualmente. Por exemplo, ao definir 40.000 CCUs e selecionar cinco usuários, cada usuário recebe 40.000 CCUs, não uma parte compartilhada.
  </Step>

  <Step>
    ### Configurar o orçamento personalizado

    1. Definir uma porcentagem específica ou valor real.

    2. Em <DNT>**Set the frequency**</DNT>, selecione com que frequência o orçamento é redefinido:

       * **Mensal**: rastreia o uso ao longo do mês civil e é redefinido no início de cada mês (UTC).
       * **Diário**: rastreia o uso ao longo de cada dia civil e é redefinido no início de cada dia (UTC).

    3. Clique em <DNT>**Next**</DNT>.
  </Step>

  <Step>
    ### Revisar notificações de orçamento personalizado

    Revise os limites de notificação que se aplicam a este usuário. Clique em <DNT>**Next**</DNT> para continuar.
  </Step>

  <Step>
    ### Configurar o bloqueio de orçamento personalizado

    1. Escolha a preferência de bloqueio para este usuário específico, que pode diferir das configurações de orçamento global.

    2. Clique em <DNT>**Finish**</DNT> para criar o orçamento de substituição personalizado.
  </Step>
</Steps>

Após criá-los, os orçamentos de substituição personalizados aparecem na tabela de orçamentos como itens de linha separados. É possível atualizá-los individualmente ou usar a visualização de grupo para atualizar todos os usuários do grupo de uma só vez.

## Gerenciar limites de usuário

### Visualizar o consumo do orçamento

Os gerentes da organização veem o orçamento global como um cartão na parte superior da página principal do <DNT>**User Limits**</DNT>. Os orçamentos de substituição personalizados aparecem em uma tabela de orçamento abaixo.

Os **gerentes da organização** podem fazer o seguinte:

* É possível visualizar o cartão de orçamento global e todos os orçamentos de substituição personalizados na tabela com todos os detalhes

* Acesse um menu de três pontos (**⋯**) ao lado de cada orçamento. O menu inclui as seguintes opções:

  * <DNT>**View**</DNT>: Ver informações detalhadas do orçamento, consumo e tendências
  * <DNT>**Edit**</DNT>: Modificar as configurações do orçamento
  * <DNT>**Delete**</DNT>: Remover o orçamento

**Usuários somente leitura** podem fazer o seguinte:

* Ver seu próprio orçamento como um item de linha na tabela, seja uma substituição personalizada ou um orçamento global
* Acesse apenas a opção <DNT>**View**</DNT> no menu de três pontos

Usuários somente leitura não podem ver os orçamentos de outros usuários ou usar <DNT>**Edit**</DNT> ou <DNT>**Delete**</DNT>.

### Visualização de detalhes do orçamento [#budget-details]

Ao visualizar um orçamento (disponível para todos os usuários para o próprio orçamento), é possível ver:

* Consumo atual do orçamento
* Porcentagem do orçamento usado
* Tendências de consumo para o período
* Status de bloqueio em 100%
* Status da notificação

### Ajustar orçamentos [#adjust-budgets]

Como gerente da organização, é possível modificar os orçamentos a qualquer momento:

* <DNT>**Edit existing budgets**</DNT>: atualize os valores do orçamento, a frequência ou as preferências de bloqueio para um único usuário, ou use a visualização de grupo para atualizar o orçamento para todos os usuários de um grupo de uma só vez
* <DNT>**Increase a user&apos;s budget**</DNT>: Restaurar o acesso para usuários bloqueados ou fornecer capacidade adicional
* <DNT>**Decrease budgets**</DNT>: ajustar os valores do orçamento para os períodos de orçamento atuais e futuros
* <DNT>**Delete budgets**</DNT>: Exclua os orçamentos globais e de substituição personalizados. Quando você exclui um orçamento de substituição personalizado, o usuário retorna automaticamente ao orçamento global do usuário (se você tiver configurado um).

As alterações nos orçamentos entram em vigor em aproximadamente 15 minutos.

<Callout variant="important">
  Excluir um orçamento personalizado não remove o rastreamento de orçamento. O rastreamento de orçamento continua sob o orçamento global (se você tiver configurado um).
</Callout>

### Lidar com usuários bloqueados

Quando um usuário é bloqueado devido ao consumo de orçamento, ele pode fazer o seguinte:

* Ver uma mensagem que diz que usaram seu orçamento para o período
* Ver os detalhes do seu orçamento para verificar o consumo
* Entrar em contato para solicitar um aumento de orçamento

Para restaurar o acesso de um usuário bloqueado, escolha uma das seguintes opções:

* Aumentar seu orçamento. Consulte [Ajustar orçamentos](#adjust-budgets).
* Aguarde até que o orçamento seja redefinido no início do próximo período do orçamento. Consulte [Frequência do orçamento](#budget-frequency).

<Callout variant="tip">
  É recomendado publicar uma lista interna de gerentes da organização para que os usuários saibam quem contatar para aumentos de limite e garantir que pelo menos um esteja disponível para aprovar os aumentos rapidamente durante um incidente de serviço.
</Callout>

## Cenários comuns

**Quando os orçamentos são redefinidos?** Depende da frequência selecionada ao configurar o orçamento:

* **Mensal**: os orçamentos são redefinidos no início de cada mês civil (UTC).
* **Diário**: os orçamentos são redefinidos no início de cada dia do calendário (UTC).

**O que acontece com as consultas em andamento quando um usuário atinge 100% de seu orçamento?** As consultas em execução são concluídas. O bloqueio apenas impede que novas consultas, carregamentos de dashboard e chamadas de API sejam iniciados.

**O que acontece com um usuário quando excluo seu orçamento de substituição personalizado?** O usuário retorna automaticamente ao orçamento global do usuário se você tiver configurado um. Se não existir um orçamento global, o usuário terá acesso irrestrito.

**O que acontece com os usuários que não têm um orçamento atribuído?** Usuários sem um orçamento atribuído têm acesso irrestrito aos dashboards, ao criador de consulta e às chamadas de API.

**Em quanto tempo as alterações de orçamento entram em vigor?** As alterações de orçamento entram em vigor em aproximadamente 15 minutos.
