O monitoramento tradicional frequentemente força as equipes de engenharia a rastrear métricas de nível de serviço isoladas, criando uma experiência de depuração fragmentada e de &quot;cadeira giratória&quot; quando as jornadas críticas do usuário se degradam. Os Workloads inteligentes evoluem a resolução de problemas reativa da Transação 360 para um hub de monitoramento proativo e de atualização automática. Ao aproveitar o distributed tracing para mapear automaticamente todo o acervo arquitetônico para uma única transação de negócios, ele rastreia continuamente as dependências full-stack e alinha o desempenho técnico com os resultados de negócios (KPIs) em tempo real à medida que o sistema muda.

Pronto para começar? Certifique-se de que o [distributed tracing](/docs/distributed-tracing/enable-configure/quick-start) esteja habilitado para a conta.

## Como criar workloads inteligentes [#create]

É possível criar Workloads inteligentes de três maneiras, cada uma levando apenas alguns minutos para ser configurada:

<CollapserGroup>
  <Collapser id="create-from-recommendations" title="Criar a partir de workloads recomendados">
    Ideal se houver dúvidas sobre quais transações do APM priorizar. O New Relic analisa automaticamente os dados da conta e destaca os fluxos de transação de alto impacto.

    ### Ver recomendações

    Ao navegar para a página de workloads, será exibido um banner na parte superior se o New Relic tiver encontrado workloads recomendados:

    <img title="Workloads page with Review recommendations banner" alt="Screenshot of the Workloads page showing the Review recommendations banner and button" src="/images/intelligent-workload-review-recs.webp" />

    Clique em <DNT>**Review recommendations**</DNT> para abrir o modal de recomendações.

    ### Revisar e criar a partir de recomendações

    O modal **Recommended Intelligent Workloads** exibe transações que se beneficiariam do monitoramento:

    1. **Filtrar por categoria**: Use as abas para alternar entre:

       * **Key Transactions**: Transações de alto tráfego ou críticas para o negócio
       * **Impacted Transactions**: Transações com problemas de desempenho ou erros

    2. **Ordenar recomendações**: Use o menu suspenso para ordenar por:

       * Maior taxa de erro
       * Tempo mais lento médio de resposta
       * Maior consumo de tempo

    3. **Revise os detalhes da transação**: Cada recomendação mostra:

       * **Transaction name**: A transação focal para a carga de trabalho
       * **Focal entity**: O serviço principal que processa a transação
       * **Response Time**: Latência média (ex.: &quot;0,57s&quot;)
       * **Error Rate**: Porcentagem de requisições com falha (por exemplo, &quot;0,6%&quot;)
       * **Total Duration**: Tempo de processamento combinado (ex.: &quot;77.60s&quot;)

    4. **Criar carga de trabalho**: Clique em <DNT>**Create**</DNT> ao lado de qualquer recomendação

    Ao criar a partir de uma recomendação, o New Relic preenche automaticamente a seleção de entidade e transação, levando você diretamente para a etapa **Add details**, onde você pode:

    * Nomeie sua carga de trabalho
    * Adicionar uma descrição (opcional)
    * Verifique o serviço focal e a transação
    * Conclua a configuração

    <Callout variant="tip">
      Criar a partir de recomendações é ideal quando você é novo no Intelligent Workloads ou deseja identificar rapidamente quais transações se beneficiariam mais de um monitoramento dedicado.
    </Callout>
  </Collapser>

  <Collapser id="create-workloads-page" title="Criar a partir da página Workloads">
    Ideal caso já se conheça a conta, o serviço e a transação específicos para os quais se deseja criar um workload usando o assistente de configuração padrão.

    1. Vá para <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Workloads**</DNT>.
    2. Clique em <DNT>**Create a workload**</DNT>.
    3. Selecione o tipo de <DNT>**Intelligent Workload**</DNT>.
    4. Clique em <DNT>**Setup**</DNT> para iniciar o assistente.

    <img title="Select Intelligent Workload type" alt="Screenshot showing workload type selection with Standard and Intelligent options" src="/images/create_intelligent_workload.webp" />

    ### Passo 1: Selecione uma entidade [#select-entity]

    Escolha o serviço ou entidade que contém sua transação crítica:

    1. Pesquise ou navegue pela entidade pelo nome.
    2. Filtre por tipo de entidade, se necessário (serviços de APM, aplicações de navegador, etc.).
    3. Selecione a entidade que processa sua transação-chave.
    4. Clique em <DNT>**Next**</DNT>.

    <Callout variant="tip">
      Escolha uma entidade que seja central para o seu fluxo de transação. Por exemplo, ao monitorar um processo de checkout, selecione o serviço de checkout em vez de um serviço de log periférico.
    </Callout>

    ### Passo 2: Selecione sua transação [#pick-transaction]

    Selecione a transação específica que você deseja monitorar:

    1. Navegue pela lista de transações da entidade selecionada.
    2. Use a pesquisa para encontrar nomes específicos de transações.
    3. Selecione a transação que representa o fluxo de trabalho do negócio.
    4. Clique em <DNT>**Next**</DNT>.

    A carga de trabalho rastreará todas as entidades que participam desta transação com base em rastreamentos distribuídos.

    <Callout variant="important">
      As entidades de infraestrutura estão atualmente excluídas do monitoramento de integridade devido a limitações da plataforma. Apenas serviços de APM, aplicativos de navegador e outras entidades instrumentadas são incluídos nos cálculos de integridade do workload.
    </Callout>

    ### Etapa 3: Adicionar detalhes [#add-details]

    Forneça informações sobre sua carga de trabalho:

    1. **Name**: Insira um nome descritivo (por exemplo, &quot;Transação de Checkout&quot;, &quot;Fluxo de Autenticação de Usuário&quot;)
    2. **Description** (opcional): Adicione contexto sobre o que esta carga de trabalho monitora e por que é importante
    3. **Account**: selecione a conta onde o workload será criado. Por padrão, a conta atualmente ativa é pré-selecionada. Use o dropdown para alterá-la se desejar criar o workload em uma conta diferente.
    4. Clique em <DNT>**Next**</DNT>.

    ### Etapa 4: Visualizar e finalizar [#preview-finalize]

    Revise a configuração da sua carga de trabalho:

    1. Verifique se a **entidade Focal** está correta.
    2. Confirme se a **transação Focal** corresponde ao fluxo de trabalho pretendido.
    3. Revise o **Name** e a **Description** do workload.
    4. Clique em <DNT>**Create Workload**</DNT>.

    Os Workloads inteligentes começarão imediatamente a rastrear as entidades participantes da transação.
  </Collapser>

  <Collapser id="create-from-t360" title="Criar a partir do Transaction 360">
    Ideal se estiver investigando ativamente um incidente e quiser salvar perfeitamente a visualização de transação atual como um workload proativo e permanente.

    <img title="Save as Intelligent Workload from Transaction 360" alt="Screenshot of Transaction 360 showing the Save as workload button" src="/images/intelligent-workload-save-as-workload.webp" />

    1. Vá para <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; APM &amp; Services**</DNT>.
    2. Selecione um serviço que faça parte do fluxo de transação crítico.
    3. Navegue até uma transação específica que deseja monitorar e clique em <DNT>**Transaction 360**</DNT>.
    4. Clique em <DNT>**Save as Intelligent Workload**</DNT>.
    5. Insira um nome descritivo para a carga de trabalho.
    6. Clique em <DNT>**Save**</DNT>.

    <Callout variant="tip">
      Escolha nomes de transação que representem fluxos de trabalho de negócios completos (por exemplo, &quot;checkout&quot;, &quot;user-authentication&quot;) em vez de chamadas de API individuais.
    </Callout>
  </Collapser>
</CollapserGroup>

## Qual é o próximo [#next-steps]

Assim que os Workloads inteligentes forem criados, explore as visualizações e ferramentas principais para se familiarizar com o monitoramento das jornadas críticas dos clientes:

* **[Investigue com experiências integradas](/docs/new-relic-solutions/new-relic-one/workloads/intelligent-workload-integrated-experiences)**: mergulhe em subvisualizações com escopo, incluindo Errors Inbox, riscos de desempenho, Transação 360 e mapas de dependência — criados diretamente no contexto do workload.
* **[Gerencie KPIs personalizados](/docs/new-relic-solutions/new-relic-one/workloads/intelligent-workload-kpis)**: defina e rastreie métricas de negócios personalizadas (como taxas de sucesso de checkout) juntamente com os indicadores de desempenho técnico.
