Você pode pedir a um agente de programação de IA, como Claude Code, Cursor, GitHub Copilot ou Codex, para adicionar o New Relic ao seu projeto. O agente lê nossa documentação de instalação, determina qual agente do New Relic o seu projeto precisa e faz as alterações para você.

## Antes de você começar [#before-you-begin]

* **Conta New Relic** — Se você não tiver uma, [inscreva-se para obter uma conta New Relic](https://newrelic.com/signup).
* **Chave de licença** — Você precisará da sua <InlinePopover type="licenseKey" />. Para encontrá-la, consulte [Chave de licença](/docs/apis/intro-apis/new-relic-api-keys#license-key).

<Callout variant="important">
Mantenha sua chave de licença fora do contexto do agente. Não a cole no chat. Configure-a você mesmo como a variável de ambiente `NEW_RELIC_LICENSE_KEY` onde seu aplicativo é executado.
</Callout>

## Copie este prompt [#prompt]

Abra o seu agente de codificação de IA na pasta do seu projeto e cole este prompt:

<Callout variant="tip">
Siga as instruções em [https://docs.newrelic.com/docs/new-relic-solutions/get-started/install-with-ai.md](https://docs.newrelic.com/docs/new-relic-solutions/get-started/install-with-ai.md) para adicionar o New Relic a este projeto.
</Callout>

Após a execução do agente, verifique quais arquivos ele alterou e confirme se os dados estão chegando ao New Relic.

## Instruções para agentes de IA [#agent-instructions]

Se você for um agente de IA instalando o New Relic, siga estas etapas:

1. **Encontre a stack:** observe os arquivos do projeto, como `package.json`, `pom.xml`, `build.gradle`, `requirements.txt`, `pyproject.toml`, `go.mod`, `*.csproj`, `composer.json`, `Gemfile`, `Dockerfile`, manifestos do Kubernetes ou Helm charts. Se a stack não estiver clara, pergunte ao usuário o que monitorar.

2. **Escolha o guia de instalação:** escolha o guia correspondente nos [guias de instalação](#install-guides) abaixo. Para um URL em `/docs/`, adicione `.md` ao final para obter uma versão em markdown.

3. **Mantenha a chave de licença fora do seu contexto:** a chave é um segredo. Você nunca precisa do valor dela.

   * Não solicite a chave ao usuário. Se o usuário a colar no chat, oriente-o a revogá-la e criar uma nova.
   * Faça referência à chave apenas pelo nome `NEW_RELIC_LICENSE_KEY`. Caso um guia coloque a chave em um arquivo de configuração, em vez disso, leia-a dessa variável de ambiente.
   * Não execute comandos nem leia arquivos que mostrariam a chave, como arquivos `env`, `printenv`, `echo $NEW_RELIC_LICENSE_KEY`, `.env` ou armazenamentos de segredos.
   * Execute `test -n "$NEW_RELIC_LICENSE_KEY" && echo set || echo missing` para verificar se a chave está configurada sem expô-la.

4. **Siga o guia:**

   * Peça ao usuário um nome de aplicativo ou sugira um com base no nome do projeto.
   * Se a conta do usuário estiver na [região de data center](/docs/accounts/accounts-billing/account-setup/choose-your-data-center) da UE ou do JP, use os endpoints que o guia fornece para essa região.

5. **Verifique:** Peça ao usuário para definir `NEW_RELIC_LICENSE_KEY` e reiniciar o aplicativo, em seguida, siga [Verificar a instalação](#verify). Se nenhum dado aparecer, consulte a página de resolução de problemas listada para essa tecnologia.

6. **Resuma:** Informe ao usuário quais arquivos você alterou e onde encontrar o aplicativo dele no New Relic: <DNT>**APM &amp; Services**</DNT> para aplicativos, <DNT>**Browser**</DNT> ou <DNT>**Mobile**</DNT> para frontends e <DNT>**Infrastructure**</DNT> para hosts.

### Verifique se os dados chegaram ao New Relic [#check-data]

Execute a consulta para a tecnologia que você instalou, substituindo cada espaço reservado pelo valor que você configurou. Os dados podem levar alguns minutos para aparecer, e algumas consultas só retornam resultados depois que o aplicativo processa tráfego.

<table>
<thead>
<tr>
<th style={{ width: "200px" }}>
**Tecnologia**
</th>

<th>
**Consulta**
</th>
</tr>
</thead>

<tbody>
<tr>
<td>
Agentes APM
</td>

<td>
`SELECT count(*) FROM ApplicationAgentContext WHERE agent.language = 'LANGUAGE' AND appName = 'APP_NAME' SINCE 30 minutes ago`, onde `LANGUAGE` é `nodejs`, `java`, `python`, `dotnet`, `go`, `php` ou `ruby`
</td>
</tr>

<tr>
<td>
Qualquer aplicativo APM, após o tráfego
</td>

<td>
`SELECT count(*) FROM Transaction WHERE appName = 'APP_NAME' SINCE 30 minutes ago`
</td>
</tr>

<tr>
<td>
Docker
</td>

<td>
`SELECT count(*) FROM ContainerSample WHERE name = 'CONTAINER_NAME' SINCE 10 minutes ago`
</td>
</tr>

<tr>
<td>
Kubernetes
</td>

<td>
`SELECT count(*) FROM K8sClusterSample WHERE clusterName = 'CLUSTER_NAME' SINCE 10 minutes ago`
</td>
</tr>

<tr>
<td>
Anfitriões
</td>

<td>
`SELECT count(*) FROM SystemSample WHERE hostname = 'HOST_NAME' SINCE 10 minutes ago`
</td>
</tr>

<tr>
<td>
Navegador da web, após o carregamento de uma página
</td>

<td>
`SELECT count(*) FROM PageView WHERE appName = 'APP_NAME' SINCE 30 minutes ago`
</td>
</tr>

<tr>
<td>
Mobile, após uma sessão
</td>

<td>
`SELECT count(*) FROM MobileSession WHERE appName = 'APP_NAME' SINCE 30 minutes ago`
</td>
</tr>
</tbody>
</table>

Uma contagem acima de zero significa que os dados estão fluindo. Existem duas maneiras de executar uma consulta, e nenhuma delas expõe um segredo a você:

* **Peça ao usuário** para colar isso no [criador de consulta](/docs/query-your-data/explore-query-data/query-builder/introduction-query-builder) no New Relic e informar o resultado.
* **Use a [CLI do New Relic](https://github.com/newrelic/newrelic-cli)** se o usuário a tiver instalado e definido uma <InlinePopover type="userKey" />como a variável de ambiente `NEW_RELIC_API_KEY`. Execute `newrelic nrql query --accountId ACCOUNT_ID --query 'QUERY'`. A chave de API do usuário também é um segredo, portanto, trate-a da mesma forma que a chave de licença.
