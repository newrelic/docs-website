Este guia orienta você no processo de adição do componente `NerdGraphQuery` a um exemplo de aplicativo de visão geral de transação. Isso permite que você consulte os dados da sua conta New Relic e adicione-os a um menu dropdown .

NerdGraph é nossa implementação GraphQL. GraphQL tem algumas diferenças importantes quando comparado ao REST:

* O cliente, e não o servidor, determina quais dados serão retornados.
* Você pode coletar facilmente dados de várias fontes. Por exemplo, em uma única consulta, você pode obter informações da conta, dados de infraestrutura e emitir uma solicitação NRQL.

<Callout variant="important">
Antes de concluir este exercício, você pode experimentar a consulta GraphQL em nosso [NerdGraph API Explorer](https://api.newrelic.com/graphiql).
</Callout>

## Adicione o componente `NerdGraphQuery` [#nerdgraphquery]

Agora você pode criar um menu dropdown para alterar a conta que o aplicativo está visualizando. A primeira etapa é importar o componente `NerdGraphQuery` para o arquivo `index.js` do aplicativo.

<Steps>
<Step>
Adicione o componente `NerdGraphQuery` ao primeiro `StackItem` dentro de `return` no arquivo `index.js` :

```jsx
<NerdGraphQuery query={query} variables={variables}>
  {({ loading, error, data }) => {
    console.log({ loading, error, data });
    if (loading) {
      return <Spinner />;
    }
    if (error) {
      return 'Error!';
    }
    return null;
  }}
</NerdGraphQuery>
```
</Step>

<Step>
O componente `NerdGraphQuery` utiliza um objeto de consulta que indica a origem que você deseja acessar e os dados que deseja retornar.

Adicione o seguinte código ao arquivo `index.js` no método `render` :

<Callout variant="important">
No console do browser, você pode ver os dados da sua consulta retornados em um objeto que segue a mesma estrutura do objeto da consulta inicial.
</Callout>

```jsx
const query = `
    query($id: Int!) {
        actor {
            account(id: $id) {
                name
            }
        }
    }
`;
```
</Step>

<Step>
Para pegar os dados retornados pela consulta NerdGraph e exibi-los no aplicativo, substitua o `return null` no componente `NerdGraphQuery` atual por esta instrução `return` :

```jsx
return <HeadingText>{data.actor.account.name} Apps:</HeadingText>;
```

Ao voltar ao browser e visualizar seu aplicativo, você verá um novo título mostrando o nome da sua conta retornada do NerdGraph.
</Step>
</Steps>

## Como usar `NerdGraphQuery.query` [#how-nerdgraphquery]

Neste ponto, você implementou o componente `NerdGraphQuery` com o método `render` do aplicativo e exibiu os dados de retorno no aplicativo de visão geral da transação.

Aqui está o que você precisa fazer a seguir:

* Consulta NerdGraph dentro do método de ciclo de vida `componentDidMount` .
* Salve os dados retornados para uso posterior no aplicativo.

<Steps>
<Step>
Este código pega a resposta do NerdGraph e garante que os resultados sejam processados, armazenados no estado do aplicativo e registrados no console do browser para visualização.

Adicione este código ao arquivo `index.js` logo abaixo de `constructor`:

```jsx
componentDidMount() {
    const accountId = this.state;
    const gql = `{ actor { accounts { id name } } }`;

    const accounts = NerdGraphQuery.query({query: gql}) //The NerdGraphQuery.query method called with the query object to get your account data is stored in the accounts variable.
    accounts.then(results => {
        console.log('Nerdgraph Response:', results);
        const accounts = results.data.actor.accounts.map(account => {
            return account;
        });
        const account = accounts.length > 0 && accounts[0];
        this.setState({ selectedAccount: account, accounts });
    }).catch((error) => { console.log('Nerdgraph Error:', error); })
}
```
</Step>

<Step>
Depois que os dados forem armazenados no estado, exiba uma seleção para que o usuário possa alterar as contas e atualizar o aplicativo.

Para fazer isso, adicione este código a `index.js` para o segundo `StackItem` na instrução `return` :

```jsx
{
  accounts && (
    <StackItem>
      <Select
        value={selectedAccount}
        onChange={(evt, value) => this.selectAccount(value)}
      >
        {accounts.map((a) => {
          return (
            <SelectItem key={a.id} value={a}>
              {a.name}
            </SelectItem>
          );
        })}
      </Select>
    </StackItem>
  );
}
```
</Step>
</Steps>

### Revise os resultados da consulta NerdGraph [#review-results]

Depois de concluir essas etapas, observe o aplicativo em seu browser e observe o seguinte:

* O menu dropdown agora exibe os dados retornados de `NerdGraphQuery.query` e permite selecionar uma conta.
* Depois de selecionar uma nova conta, o aplicativo mostra os dados da nova seleção.

O arquivo `index.js` final deve ter um código semelhante ao código abaixo. Este exemplo completo está em seu nerdlet `final.js`.

```jsx
import React from 'react';
import { PlatformStateContext, NerdGraphQuery, Spinner, HeadingText, Grid, GridItem, Stack, StackItem, Select, SelectItem, AreaChart, TableChart, PieChart } from 'nr1'
import { timeRangeToNrql } from '@newrelic/nr1-community';

// https://docs.newrelic.com/docs/new-relic-programmable-platform-introduction

export default class UseNerdgraphNerdletNerdlet extends React.Component {
    constructor(props){
        super(props)
        this.state = {
            accountId: <YOUR ACCOUNT ID>,
            accounts: null,
            selectedAccount: null,
        }
    }

    componentDidMount() {
        const accountId = this.state;
        const gql = `{ actor { accounts { id name } } }`;

        const accounts =  NerdGraphQuery.query({ query: gql })
        accounts.then(results => {
            console.log('Nerdgraph Response:', results);
            const accounts = results.data.actor.accounts.map(account => {
                return account;
            });
            const account = accounts.length > 0 && accounts[0];
            this.setState({ selectedAccount: account, accounts });
        }).catch((error) => { console.log('Nerdgraph Error:', error); })
    }

    selectAccount(option) {
        this.setState({ accountId: option.id, selectedAccount: option });
    }


    render() {
        const { accountId, accounts, selectedAccount  } = this.state;
        console.log({ accountId, accounts, selectedAccount });

        const query = `
            query($id: Int!) {
                actor {
                    account(id: $id) {
                        name
                    }
                }
            }
        `;

        const variables = {
          id: accountId,
        };

        const avgResTime = `SELECT average(duration) FROM Transaction FACET appName TIMESERIES AUTO `;
        const trxOverview = `FROM Transaction SELECT count(*) AS 'Transactions', apdex(duration) AS 'apdex', percentile(duration, 99, 95) FACET appName `;
        const errCount = `FROM TransactionError SELECT count(*) AS 'Transaction Errors' FACET error.message `;
        const responseCodes = `SELECT count(*) AS 'Response Code' FROM Transaction FACET httpResponseCode `;

        return (
            <Stack
                fullWidth
                horizontalType={Stack.HORIZONTAL_TYPE.FILL}
                gapType={Stack.GAP_TYPE.EXTRA_LOOSE}
                spacingType={[Stack.SPACING_TYPE.MEDIUM]}
                directionType={Stack.DIRECTION_TYPE.VERTICAL}>
                <StackItem>
                    <NerdGraphQuery query={query} variables={variables}>
                        {({loading, error, data}) => {
                            if (loading) {
                                return <Spinner />;
                            }

                            if (error) {
                                return 'Error!';
                            }

                            return <HeadingText>{data.actor.account.name} Apps:</HeadingText>;
                        }}
                    </NerdGraphQuery>
                </StackItem>
                {accounts &&
                    <StackItem>
                        <Select value={selectedAccount} onChange={(evt, value) => this.selectAccount(value)}>
                        {accounts.map(a => {
                            return (
                              <SelectItem key={a.id} value={a}>
                                {a.name}
                              </SelectItem>
                            )
                        })}
                        </Select>
                    </StackItem>
                }
                <StackItem>
                <hr />
                    <PlatformStateContext.Consumer>
                    {(platformState) => {
                        /* Taking a peek at the platformState */
                        const since = timeRangeToNrql(platformState);
                        return (
                          <Grid
                          className="primary-grid"
                          spacingType={[Grid.SPACING_TYPE.NONE, Grid.SPACING_TYPE.NONE]}
                          >
                              <GridItem className="primary-content-container" columnSpan={6}>
                                  <main className="primary-content full-height">
                                  <HeadingText spacingType={[HeadingText.SPACING_TYPE.MEDIUM]} type={HeadingText.TYPE.HEADING_4}>
                                      Transaction Overview
                                  </HeadingText>
                                  <TableChart fullWidth accountId={accountId} query={trxOverview+since} />
                                  </main>
                              </GridItem>
                              <GridItem className="primary-content-container" columnSpan={6}>
                                  <main className="primary-content full-height">
                                  <HeadingText spacingType={[HeadingText.SPACING_TYPE.MEDIUM]} type={HeadingText.TYPE.HEADING_4}>
                                      Average Response Time
                                  </HeadingText>
                                  <AreaChart fullWidth accountId={accountId} query={avgResTime+since} />
                                  </main>
                              </GridItem>
                              <GridItem className="primary-content-container" columnSpan={6}>
                                  <main className="primary-content full-height">
                                  <HeadingText spacingType={[HeadingText.SPACING_TYPE.MEDIUM]} type={HeadingText.TYPE.HEADING_4}>
                                      Response Code
                                  </HeadingText>
                                  <PieChart fullWidth accountId={accountId} query={responseCodes+since} />
                                  </main>
                              </GridItem>
                              <GridItem className="primary-content-container" columnSpan={6}>
                                  <main className="primary-content full-height">
                                  <HeadingText spacingType={[HeadingText.SPACING_TYPE.MEDIUM]} type={HeadingText.TYPE.HEADING_4}>
                                      Transaction Errors
                                  </HeadingText>
                                  <PieChart fullWidth accountId={accountId} query={errCount+since} />
                                  </main>
                              </GridItem>
                          </Grid>
                        );
                    }}
                    </PlatformStateContext.Consumer>
                </StackItem>
            </Stack>
        )
    }
}
```

## Resumo [#summary]

Agora que concluiu todas as etapas deste exemplo, você consultou com sucesso os dados da sua conta usando o componente `NerdGraphQuery` em dois métodos:

* Usar o componente `NerdGraphQuery` dentro do método de renderização do aplicativo e depois passar os dados retornados para os componentes filhos.
* Usando o método `NerdGraphQuery.query` para consultar dados antes da renderização do aplicativo.
