<Callout variant="tip">
Esta lição faz parte de um curso que ensina como construir um aplicativo New Relic do zero. Se ainda não o fez, confira a Visão Geral.

Cada lição do curso se baseia na anterior, portanto, certifique-se de ter concluído a última lição, Adicionar componentes de gráfico ao seu aplicativo de teste A/B, antes de iniciar esta.
</Callout>

Neste curso, você criará um aplicativo de teste A/B para a plataforma New Relic. Anteriormente, você aprendeu sobre o New Relic SDK]\(/docs/New Relic-solutions/build-nr-interface/sdk-component/intro-to-sdk) e sua biblioteca de componentes. Agora, é hora de você começar a criar seu aplicativo, focando primeiro nos componentes do gráfico.

Existem vários gráficos que você precisa criar, o que pode parecer complicado no início, mas dê um passo de cada vez. O gráfico superior, e o primeiro que você criará, é um gráfico de linhas que mostra o número de usuários que se inscreveram no seu boletim informativo e qual versão do seu site eles foram exibidos.

<Steps>
<Step>
Mude para o diretório `add-your-first-chart/ab-test` do [repositório de cursos](https://github.com/newrelic-experimental/nru-programmability-course):

```sh
cd nru-programmability-course/add-your-first-chart/ab-test
```

Este diretório contém o código que seu aplicativo deve ter neste ponto do curso. Ao navegar para o diretório correto no início de cada lição, você deixa seu código personalizado para trás, protegendo-se assim de carregar código incorreto de uma lição para outra.
</Step>

<Step>
Em `nerdlets/ab-test-nerdlet`, adicione um novo arquivo Javascript chamado `newsletter-signups.js`:

```sh
touch newsletter-signups.js
```
</Step>

<Step>
Neste novo arquivo, crie um componente chamado `NewsletterSignups` para armazenar seu primeiro `LineChart` e alguns dados simulados:

```jsx fileName=nerdlets/ab-test-nerdlet/newsletter-signups.js
import React from "react";
import { LineChart } from "nr1";

export default class NewsletterSignups extends React.Component {
render() {
  const versionASignups = {
    metadata: {
      id: "version-a-newsletter-signups",
      name: "Version A",
      viz: "main",
      color: "blue",
    },
    data: [
      { x: 0, y: 0 },
      { x: 10, y: 10 },
      { x: 20, y: 15 },
      { x: 30, y: 5 },
      { x: 40, y: 30 },
      { x: 50, y: 25 },
    ],
  };
  const versionBSignups = {
    metadata: {
      id: "version-b-newsletter-signups",
      name: "Version B",
      viz: "main",
      color: "green",
    },
    data: [
      { x: 0, y: 20 },
      { x: 10, y: 5 },
      { x: 20, y: 25 },
      { x: 30, y: 45 },
      { x: 40, y: 50 },
      { x: 50, y: 35 },
    ],
  };
  return <LineChart data={[versionASignups, versionBSignups]} fullWidth />;
}
}
```

Aqui, você criou duas séries de dados arbitrárias que representam as versões A e B do seu teste. No momento, você está usando pontos de dados criados manualmente. No futuro, você os substituirá pela consulta de dados da New Relic.

Observe que você especificou uma cor para cada série no gráfico. O atributo de metadados `color` aceita qualquer formato de cor aceitável por CSS. A configuração `viz: 'main'` significa que você deseja renderizar a série `LineChart` como uma linha, o estilo de exibição padrão do componente. Para a propriedade `data` no componente `LineChart` , você passou as duas séries em uma matriz para que ambas sejam representadas juntas. Por fim, você usou a propriedade `fullWidth` do gráfico para esticar a largura do gráfico e preencher a visualização.
</Step>

<Step>
No arquivo `index.js` do seu Nerdlet, importe seu novo componente e substitua o cabeçalho padrão no método `render()` do seu Nerdlet pelo seu novo componente:

```jsx fileName=nerdlets/ab-test-nerdlet/index.js lineHighlight=2,6-8
import React from 'react';
import NewsletterSignups from './newsletter-signups';

export default class AbTestNerdletNerdlet extends React.Component {
  render() {
    return <div>
      <NewsletterSignups />
    </div>
  }
}
```
</Step>

<Step>
Navegue até a raiz do seu Nerdpack em `nru-programmability-course/add-your-first-chart/ab-test`.
</Step>

<Step>
Gere um novo UUID para o seu Nerdpack:

```sh
nr1 nerdpack:uuid -gf
```

Como você clonou o repositório de cursos que continha um Nerdpack existente, você precisa gerar seu próprio identificador exclusivo. Este UUID mapeia seu Nerdpack para sua conta New Relic.
</Step>

<Step>
Sirva seu aplicativo localmente:

```sh
nr1 nerdpack:serve
```
</Step>

<Step>
Veja suas alterações no [New Relic](https://one.newrelic.com?nerdpacks=local).

Aqui você vê o `LineChart` exibido em seu aplicativo.

Quando terminar, pare de servir seu aplicativo New Relic pressionando `CTRL+C` na janela do terminal do seu servidor local.
</Step>
</Steps>

Em sete etapas, você deu vida ao seu aplicativo New Relic. Em vez de uma mensagem branda “Olá, mundo”, seu aplicativo agora mostra um gráfico de linhas colorido com duas séries de dados simuladas. Essas séries de dados representam o tráfego do lado do servidor para cada um dos designs concorrentes em seu site de demonstração. Na próxima lição, você desenvolverá essa base criando outro tipo de gráfico.
