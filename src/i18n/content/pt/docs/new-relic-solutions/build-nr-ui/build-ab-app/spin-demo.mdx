Antes de criar seu aplicativo New Relic, você precisa ativar seus serviços de demonstração. Este curso depende de dois serviços importantes:

* Um serviço web que mostra um formulário de inscrição em boletim informativo. O texto do título do formulário alterna entre duas versões porque você está realizando um teste A/B para determinar qual texto leva a uma assinatura de maior qualidade.
* Um serviço de simulador que envia tráfego constante para o site para que você não precise gerar dados manualmente

Para ativar seus serviços de demonstração, primeiro você precisa instalar [o Docker](https://docs.docker.com/get-docker/) e [o Docker compose](https://docs.docker.com/compose/install/).

## Aprimore seus serviços de demonstração [#spin]

<Steps>
<Step>
Clone o [repositório de cursos](https://github.com/newrelic-experimental/nru-programmability-course) do GitHub:

```sh
git clone https://github.com/newrelic-experimental/nru-programmability-course
```

Este repositório contém código para criar automações NodeJS New Relic. Ele também contém um diretório de código de aplicativo para cada lição do curso. Você usará esses diretórios para acompanhar o conteúdo do curso.
</Step>

<Step>
Mude para o diretório demo, chamado `ab-test-app`:

```sh
cd nru-programmability-course/ab-test-app
```

Este diretório contém arquivos de configuração e README para usar a demonstração.
</Step>

<Step>
Construa e execute o web service e o simulador contêiner, usando `docker-compose`:

```sh
NEW_RELIC_LICENSE_KEY=YOUR_NEW_RELIC_LICENSE_KEY docker-compose up -d
```

<Callout variant="important">
Certifique-se de substituir `YOUR_NEW_RELIC_LICENSE_KEY` pela sua [chave de licença](/docs/accounts/accounts-billing/account-setup/new-relic-license-key/) real.
</Callout>

Quando terminar, acesse o site em `localhost:3001`.
</Step>

<Step>
Visite [New Relic](https://one.newrelic.com) e navegue até **APM** no menu de navegação superior. Selecione **Newsletter** na lista de serviços instrumentados.

Pode ser necessário esperar um ou dois minutos para que o New Relic receba os dados de seus serviços de demonstração. Quando estiver pronto, você verá dados de transação, como desempenho, taxas de transferência e pontuação Apdex.
</Step>

<Step>
Para desacelerar seus serviços de demonstração, execute `docker-compose down` no diretório `ab-test-app` :

```sh
docker-compose down
```
</Step>
</Steps>

Agora você está pronto para construir seu aplicativo New Relic!
