<Callout variant="tip">
Esta lição faz parte de um curso que ensina como construir um aplicativo New Relic do zero.

Cada lição do curso se baseia na anterior, portanto, certifique-se de ter concluído a última lição, Adicionar gráficos de pizza, antes de iniciar esta.

Em cada lição prática deste curso, você adicionou algo novo ao seu aplicativo de teste A/B. Você criou um novo launcher e adicionou vários componentes gráficos ao seu Nerdlet. Nesta lição, você criará dois novos componentes `TableChart` que exibem informações sobre cada versão do seu website, como a proporção de clientes que assinam aqueles que cancelam a assinatura.

<Steps>
<Step>
Mude para o diretório `add-tables/ab-test` do [repositório de cursos](https://github.com/newrelic-experimental/nru-programmability-course):

```sh
cd nru-programmability-course/add-tables/ab-test
```

Este diretório contém o código que esperamos que seu aplicativo tenha neste ponto do curso. Ao navegar para o diretório correto no início de cada lição, você deixa seu código personalizado para trás, protegendo-se assim de carregar código incorreto de uma lição para outra.
</Step>

<Step>
Em `nerdlets/ab-test-nerdlet`, adicione um novo arquivo Javascript chamado `totals.js`:

```sh
touch totals.js
```
</Step>

<Step>
Neste novo arquivo, crie um componente chamado `VersionTotals` para armazenar seu primeiro `TableChart` e alguns dados simulados:

```jsx fileName=nerdlets/ab-test-nerdlet/totals.js
import React from "react";
import { TableChart } from "nr1";

export default class VersionTotals extends React.Component {
constructor(props) {
  super(props);
}

render() {
  const versionATotals = {
    metadata: {
      id: `totals-${this.props.version}`,
      name: `Version ${this.props.version}`,
      columns: ["name", "count"],
    },
    data: [
      {
        name: "Subscriptions",
        count: 0,
      },
      {
        name: "Page views",
        count: 0,
      },
    ],
  };
  return <TableChart data={[versionATotals]} fullWidth />;
}
}
```

`TableChart` é diferente de `PieChart` e `LineChart` em três grandes aspectos. Primeiramente, não há metadados `color` ou `viz` em sua série. `TableChart` tem uma visualização padrão, portanto ignora coisas como `color`, que não se aplicam. Em segundo lugar, a série `TableChart` tem `columns` metadados atributo. `columns` determina os nomes das colunas da tabela. Finalmente, os dados da série `TableChart` não usam valores x nem y. Em vez disso, eles usam chaves que correspondem à coluna da tabela e valores que determinam o que entra na linha.

Observe que `VersionTotals` pega uma propriedade `version` e a fornece aos campos `id` e `name` dos metadados do gráfico. Isso permite usar esse mesmo componente para criar uma tabela para as versões A e B e eliminar código duplicado.
</Step>

<Step>
No arquivo `index.js` do seu Nerdlet, importe seu novo componente e atualize o método `render()` do seu Nerdlet:

```jsx fileName=nerdlets/ab-test-nerdlet/index.js lineHighlight=5,13-14
import React from 'react';
import NewsletterSignups from './newsletter-signups';
import TotalCancellations from './total-cancellations';
import TotalSubscriptions from './total-subscriptions';
import VersionTotals from './totals';

export default class AbTestNerdletNerdlet extends React.Component {
  render() {
    return <div>
      <NewsletterSignups />
      <TotalSubscriptions />
      <TotalCancellations />
      <VersionTotals version='a' />
      <VersionTotals version='b' />
    </div>
  }
}
```
</Step>

<Step>
Navegue até a raiz do seu Nerdpack em `nru-programmability-course/add-tables/ab-test`.
</Step>

<Step>
Gere um novo UUID para o seu Nerdpack:

```sh
nr1 nerdpack:uuid -gf
```

Como você clonou o repositório de cursos que continha um Nerdpack existente, você precisa gerar seu próprio identificador exclusivo. Este UUID mapeia seu Nerdpack para sua conta New Relic.
</Step>

<Step>
Sirva seu aplicativo localmente:

```sh
nr1 nerdpack:serve
```
</Step>

<Step>
Veja suas alterações no [New Relic](https://one.newrelic.com?nerdpacks=local).

Aqui você vê os `TableChart` componentes exibidos em seu aplicativo.

Quando terminar, pare de servir seu aplicativo New Relic pressionando `CTRL+C` na janela do terminal do seu servidor local.
</Step>
</Steps>

<Callout variant="tip">
Há mais uma tabela no guia de design que registra testes anteriores. As colunas desta tabela são:

* **End Date:** a data de término do teste
* **Version A Description:** uma descrição para a versão A
* **Version B Description:** uma descrição para a versão B
* **Winner:** A versão selecionada como design final

Tente construir esta tabela em seu aplicativo com esses nomes de colunas e alguns dados falsos, sem olhar um exemplo de código. Esta prática reforçará o que você aprendeu nesta lição.

Se precisar de ajuda, consulte o diretório `add-a-chart-group` do [repositório de cursos](https://github.com/newrelic-experimental/nru-programmability-course), que corresponde à próxima lição deste curso. Este contém o código do componente `PastTests`.
</Callout>
