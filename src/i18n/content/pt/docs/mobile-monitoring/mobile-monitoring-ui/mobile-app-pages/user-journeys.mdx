O Jornadas do Usuário Mobile visualiza como os usuários finais navegam no aplicativo mobile de forma agregada. Ele revela padrões no comportamento do usuário — para onde os usuários vão após abrir o aplicativo, onde ficam travados e quais caminhos levam aos resultados de interesse.

<img title="Mobile User Journeys Sankey diagram" alt="A Sankey diagram showing user navigation paths through a mobile app, with nodes representing screens and paths sized by user volume" src="/images/mobile_screenshot-full_user-journeys-sankey.png" />

<Callout variant="important">
  <DNT>Mobile User Journeys</DNT> está atualmente disponível na experiência <DNT>**Errors**</DNT> na interface de monitoramento de Mobile do New Relic. Uma visualização <DNT>Mobile User Journeys</DNT> independente (semelhante ao recurso [Browser User Journeys](/docs/browser/browser-monitoring/browser-pro-features/user-journeys/)) está planejada para um lançamento futuro.
</Callout>

## Como acessar [#access]

<DNT>Mobile User Journeys</DNT> está disponível em todas as quatro seções em <DNT>**Triage**</DNT> na navegação à esquerda: <DNT>**Crashes**</DNT>, <DNT>**Request errors**</DNT>, <DNT>**Handled exceptions**</DNT> e <DNT>**ANRs**</DNT>. A forma de acessá-lo depende da origem:

<img title="Mobile Triage navigation showing Crashes, Request errors, Handled exceptions, and ANRs" alt="The New Relic Mobile left navigation with the Triage section expanded, showing Crashes, Request errors, Handled exceptions, and ANRs" src="/images/mobile_screenshot-full_user-journeys-triage-nav.png" />

**Na aba Triage:**

1. Acesse **[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; <DNT>Mobile</DNT>**.
2. Selecione o aplicativo mobile.
3. Na navegação à esquerda, em <DNT>**Triage**</DNT>, clique em <DNT>**Crashes**</DNT> ou <DNT>**Request errors**</DNT>.
4. A partir do <DNT>error groups</DNT>, selecione o que deseja investigar para abrir a visualização de detalhes do erro.
5. Na visualização de detalhes, clique no link <DNT>**User Journeys**</DNT> para ver os caminhos de navegação que levaram ao erro.

**Na aba &quot;Group crashes or error&quot;:**

1. Acesse **[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; <DNT>Mobile</DNT>**.
2. Selecione o aplicativo mobile.
3. Na navegação à esquerda, em <DNT>**Triage**</DNT>, clique em <DNT>**Crashes**</DNT> ou <DNT>**Request errors**</DNT>.
4. Clique na aba <DNT>**Group crashes**</DNT> ou <DNT>**Group request errors**</DNT>.
5. Selecione o grupo de falhas ou erros a ser investigado para abrir a visualização de detalhes do grupo.
6. Em <DNT>**Triage**</DNT>, clique no link <DNT>**User Journeys**</DNT> para ver os caminhos de navegação que levaram ao erro.

## Como usar o Mobile User Journeys [#how-to-use]

### Diagrama de Sankey [#sankey]

A visualização <DNT>User Journeys</DNT> usa um diagrama de Sankey para mostrar o fluxo de usuários entre as telas. Cada nó representa uma tela ou interação no aplicativo, e a largura de cada caminho de conexão reflete o número de usuários que seguiram essa rota.

Principais elementos do diagrama:

* **Nós**: telas individuais ou interações no aplicativo.
* **Caminhos**: conexões entre nós, dimensionadas proporcionalmente ao volume de usuários que seguiram esse caminho.
* **Pontos de entrada**: as telas onde as sessões do usuário começam.
* **Pontos de saída**: as telas onde os usuários encerraram sua sessão ou acionaram um erro.

Quando visualizada a partir de um grupo de erros, a visualização se ancora automaticamente nas sessões que sofreram esse erro, para que seja possível realizar o trace dos caminhos de navegação que precederam a falha.

### Detalhes do caminho e do evento [#path-details]

Clique em qualquer nó ou caminho no diagrama para detalhar as sessões que seguiram essa rota exata. Isso abre uma visualização dividida com dois painéis:

<img title="Mobile User Journeys crash detail view" alt="Split view showing the Profiles panel on the left with attribute distribution and the Sessions table on the right listing affected sessions" src="/images/mobile_screenshot-full_user-journeys-crash-detail.png" />

* <DNT>**Profiles**</DNT>: mostra a distribuição dos valores de atributos (como versão do aplicativo, dispositivo, sistema operacional, arquitetura e detalhes da falha) nas sessões que seguiram o caminho selecionado. Utilize isso para identificar pontos em comum entre os usuários afetados.
* <DNT>**Sessions that include this event**</DNT>: uma tabela listando sessões individuais, incluindo ID do usuário, data, contagem de ocorrências, versão do aplicativo, dispositivo, versão do sistema operacional e operadora. Clique em qualquer sessão para abrir a página <DNT>Event Trail Drilldown</DNT>.

### Detalhamento da trilha de evento [#event-trail]

Clique em uma sessão na tabela de sessões para abrir a página <DNT>**Event Trail Drilldown**</DNT> — uma linha do tempo cronológica de cada evento registrado nessa sessão.

<img title="Mobile User Journeys Event Trail Drilldown" alt="The Event Trail Drilldown showing a chronological list of Interaction and Crash events with expandable attribute details" src="/images/mobile_screenshot-full_user-journeys-event-trail.png" />

Em <DNT>Event Trail Drilldown</DNT>, é possível:

* <DNT>**Filter by event type**</DNT>: utilize os botões <DNT>**Interaction**</DNT> e <DNT>**Crash**</DNT> para focar em tipos de eventos específicos.
* <DNT>**Expand event details**</DNT>: clique em qualquer evento para ver sua carga completa de atributos — incluindo metadados de falha como `diskAvailable`, `osBuild`, `processName`, `timeSinceLastInteraction` e `interactionHistory`.

Essa visualização permite reconstruir as etapas exatas que um usuário seguiu antes de ocorrer uma falha, até as interações individuais na tela.

## Como Personalizar a Visualização [#customize]

### Filtro de tipo de evento [#event-type]

<img title="Mobile User Journeys event type filter" alt="The event type filter dropdown showing options: Crash, Breadcrumb, Interaction, User action, Handled exception, JavaScript error, Request error, Custom, ANR" src="/images/mobile_screenshot-crop_user-journeys-event-type-filter.png" />

Utilize o filtro <DNT>**Event type**</DNT> para escolher quais tipos de eventos aparecem como nós no diagrama. É possível incluir qualquer combinação de:

* Crash
* Breadcrumb
* Interaction
* User action
* Handled exception
* JavaScript error
* Request error
* Personalizado
* ANR

### Versão do aplicativo [#app-version]

É possível usar o filtro <DNT>**App version**</DNT> para focar em jornadas de uma versão específica. Isso é útil para comparar o comportamento do usuário antes e depois de uma implantação para identificar regressões ou melhorias.

### Filtrar por atributos de usuário [#user-attributes]

Utilize a barra de filtros para refinar os resultados por atributos adicionais, como tipo de dispositivo, versão do sistema operacional, geografia ou atributos personalizados que foram instrumentados com o [Mobile SDK](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/mobile-sdk-api-guide/).
