Solucione problemas comuns que podem ocorrer durante o monitoramento do Microsoft SQL Server com o NRDOT Collector.

## Problemas comuns [#common-issues]

### Problemas de conectividade de rede [#network-connectivity]

Caso encontre problemas de conectividade de rede com o NRDOT Collector, execute os seguintes comandos para testar a conectividade com a instância do SQL Server:

* Para Windows, execute:

  ```shell
  Test-NetConnection -ComputerName <YOUR_IP_ADDRESS> -Port <YOUR_PORT_NUMBER>
  ```

* Para Linux, execute:

  ```bash
  nc -zv <YOUR_IP_ADDRESS> <YOUR_PORT_NUMBER>
  ```

## Dados não aparecem no New Relic [#data-not-flowing]

* Para verificar problemas relacionados a limite de taxa, execute:

  ```sql
  SELECT * FROM NrIntegrationError
  ```

* Se os dados ainda não estiverem fluindo, verifique se há alguma regra de descarte definida em seus eventos de métrica e eventos de log. Consulte [Descartar dados de log com regras de filtro de descarte](/docs/logs/ui-data/drop-data-drop-filter-rules/) e [Controle de Pipeline](/docs/new-relic-control/pipeline-control/overview/).
