Você pode usar o OpenTelemetry Collector para Microsoft SQL Server para monitorar sua instância. O OpenTelemetry Collector é um projeto apoiado pela comunidade que coleta dados de telemetria do Microsoft SQL Server e os envia para a New Relic.

Por padrão, o OpenTelemetry Collector coleta métricas limitadas do Microsoft SQL Server. Para enviar desempenho de consulta, tempo de espera, sessão e outras métricas avançadas, você precisará configurar o OpenTelemetry Collector. Este guia mostra como configurá-lo para coletar métricas avançadas do Microsoft SQL Server e enviá-las para o New Relic.

<Steps>
  <Step>
    ## Pré-requisitos [#prerequisites]

    * OpenTelemetry Collector Contrib (`otelcol-contrib`) instalado e configurado no seu sistema. Você pode fazer o download do release mais recente na página de [releases do OpenTelemetry Collector](https://github.com/open-telemetry/opentelemetry-collector-releases/releases).
  </Step>

  <Step>
    ## Habilite as métricas da interface [#enable]

    Você pode enriquecer sua experiência na plataforma New Relic adicionando e habilitando métricas em seu arquivo de configuração `otelcol-contrib`. Usando a configuração fornecida nesta seção, você pode preencher dados para as seguintes páginas na plataforma New Relic:

    * <DNT>Overview</DNT>
    * <DNT>Query performance</DNT>
    * <DNT>Wait events</DNT>
    * <DNT>Sessions</DNT>
    * <DNT>Clients</DNT>
    * <DNT>Stored procedures</DNT>

    <CollapserGroup>
      <Collapser id="overview" title="Ativar métricas da página Overview">
        A página <DNT>Overview</DNT> exibe uma visão de alto nível da instância do Microsoft SQL Server, incluindo métricas principais, como contagem de banco de dados, I/O, latência, operações, espaço tempdb, taxa de deadlock e muito mais.

        Para preencher os dados da página <DNT>Overview</DNT> na plataforma New Relic, adicione a seguinte configuração ao arquivo de configuração `otelcol-contrib`:

        ```yaml
        receivers:
            sqlserver:

                # Enable comprehensive database metrics
              metrics:
                sqlserver.database.count:
                  enabled: true
                sqlserver.database.io:
                  enabled: true
                sqlserver.database.latency:
                  enabled: true
                sqlserver.database.operations:
                  enabled: true
                sqlserver.database.tempdb.space:
                  enabled: true
                sqlserver.database.tempdb.version_store.size:
                  enabled: true
                sqlserver.deadlock.rate:
                  enabled: true
                sqlserver.os.wait.duration:
                  enabled: true
                sqlserver.processes.blocked:
                  enabled: true
                sqlserver.memory.grants.pending.count:
                  enabled: true
                sqlserver.memory.area:
                  enabled: true
        ```
      </Collapser>

      <Collapser id="query-performance" title="Habilite as métricas de desempenho de consulta, sessão, espera, cliente e procedimento armazenado">
        É possível preencher dados para as seguintes páginas na plataforma New Relic:

        * <DNT>Query performance</DNT>: exibe informações detalhadas sobre as consultas em execução na sua instância do Microsoft SQL Server nas seguintes guias:

          * <DNT>Normalized queries</DNT>: exibe os gráficos de execução e tempo médio de CPU.
          * <DNT>Query samples</DNT>: exibe execuções individuais de consulta, incluindo horário de início, duração, tipo de espera, tempo de espera, banco de dados, usuário do BD e host do cliente.
          * <DNT>Stored procedures</DNT>: exibe métricas de desempenho para os principais procedimentos armazenados.

        * <DNT>Wait events</DNT>: exibe informações sobre os eventos de espera que ocorrem na instância do Microsoft SQL Server. A visualização de amostras de consulta mostra as consultas em espera no momento, juntamente com seu tipo e tempo de espera.

        * <DNT>Sessions</DNT>: Exibe informações sobre as sessões conectadas à sua instância do Microsoft SQL Server, incluindo contagens de sessões, estados das sessões, duração média das sessões ativas, sessões bloqueadas e detalhes individuais das sessões.

        * <DNT>Clients</DNT>: exibe informações sobre os clientes conectados à instância do Microsoft SQL Server, incluindo sessões ativas, sessões bloqueadas, usuários de BD conectados e detalhes do host do cliente.

        * <DNT>Stored procedures</DNT>: exibe métricas de desempenho para os principais procedimentos armazenados.

        Para preencher os dados nessas páginas, adicione a seguinte configuração ao seu arquivo de configuração `otelcol-contrib`:

        ```yaml
        receivers:
            sqlserver:

                events:
                    db.server.query_sample:
                        enabled: true
                    db.server.top_query:
                        enabled: true
                    db.server.query_plan:
                        enabled: true
                    db.server.top_procedure:
                        enabled: true

                # Top query collection configuration
                top_query_collection:
                    lookback_time: 60s
                    max_query_sample_count: 1000
                    top_query_count: 250
                    collection_interval: 60s

                # Query sample collection configuration
                query_sample_collection:
                    max_rows_per_query: 100

                # Top stored procedure collection configuration
                top_procedure_collection:
                    max_procedure_sample_count: 1000
                    top_procedure_count: 250
                    collection_interval: 60s
        ```
      </Collapser>

      <Collapser id="waits" title="Habilitar todas as esperas na guia de evento Wait">
        A visualização All waits mostra o tempo de espera no nível da instância detalhado por categoria de espera e tipo de espera individual.

        Para habilitar <DNT>All waits</DNT> na guia <DNT>Wait event</DNT> da plataforma New Relic, adicione a seguinte configuração ao arquivo de configuração `otelcol-contrib`:

        ```yaml
        receivers:
            sqlserver:

                metrics:
                    sqlserver.os.wait.duration:
                        enabled: true
        ```
      </Collapser>
    </CollapserGroup>
  </Step>

  <Step>
    ## Reinicie o OpenTelemetry Collector

    Reinicie o OpenTelemetry Collector para aplicar as alterações de configuração executando o seguinte comando:

    ```powershell
    Restart-Service -Name "otelcol-contrib"
    ```
  </Step>
</Steps>
