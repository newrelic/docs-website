Obtenha insights profundos sobre o desempenho do seu Oracle Database com nossa solução de monitoramento baseada em OpenTelemetry. Acompanhe as métricas do banco de dados, analise o desempenho da consulta, monitore o uso de recursos e correlacione o desempenho do banco de dados com seus aplicativos.

Essa abordagem baseada em NRDOT complementa nossa Integração On-Host (OHI) existente, utilizando padrões OpenTelemetry para monitoramento de banco de dados, facilitando a integração com sua stack de observabilidade existente.

Diferentemente das integrações no host, o NRDOT opera de forma independente do agente de infraestrutura. Ele não requer o agente de infraestrutura para coletar a telemetria do banco de dados. O NRDOT também inclui recursos nativos de monitoramento de host, para que você possa escolher:

* Use o agente de infraestrutura para monitoramento de host junto com o NRDOT para monitoramento de banco de dados, ou
* Use o NRDOT para monitorar tanto o banco de dados quanto o host.

## Capacidades [#capabilities]

* **Padrões do OpenTelemetry**: integra-se perfeitamente às ferramentas de observabilidade existentes
* **Métricas abrangentes**: insights profundos sobre o desempenho do banco de dados, eventos de espera e uso de recursos
* **Insights em nível de consulta**: identificar e analisar consultas com desempenho lento e atividade de sessão
* **Implantação flexível**: funciona com ambientes CDB/PDB no host e Amazon RDS
* **Correlação de APM**: conectar o desempenho do banco de dados aos traces do aplicativo

## Escolha seu caminho de instalação [#choose]

Você pode instalar o NRDOT Collector para o monitoramento do Oracle Database das seguintes maneiras:

* Ambientes auto-hospedados: instalação manual na própria infraestrutura

  * [Banco de dados de contêiner (CDB) no host](/docs/opentelemetry/db360/oracle/host-cdb): monitore um banco de dados de contêiner inteiro, incluindo todos os bancos de dados plugáveis sob ele.
  * [Banco de dados plugável (PDB) no host](/docs/opentelemetry/db360/oracle/host-pdb): monitore um banco de dados plugável individual.

* Ambientes AWS RDS: monitoramento de banco de dados Oracle gerenciado na nuvem
  * [Monitoramento do RDS](/docs/opentelemetry/db360/oracle/rds): monitore uma instância de banco de dados Oracle em execução no Amazon RDS.

* Ambientes Oracle Cloud: monitoramento de banco de dados Oracle totalmente gerenciado
  * [Monitoramento do Autonomous Database (ADB)](/docs/opentelemetry/db360/oracle/adb): monitorar uma instância do Oracle Autonomous Database.

* [New Relic CLI](/docs/opentelemetry/db360/oracle/cli): instale e configure o coletor com um único comando

* [Ansible](/docs/opentelemetry/db360/oracle/ansible): instale e configure o coletor em escala usando a role `newrelic.newrelic_install` do Ansible

* [Chef](/docs/opentelemetry/db360/oracle/chef): instale e configure o coletor em escala usando o cookbook do Chef `newrelic-install`

* [Helm chart](/docs/opentelemetry/db360/oracle/helm): instale e configure o monitoramento do banco de dados Oracle no Kubernetes usando o Helm chart `oracle-otel`

* [Docker](/docs/opentelemetry/db360/oracle/docker): execute o coletor como um contêiner irmão de uma instância do banco de dados Oracle já em execução no Docker

## Instalação guiada [#ui-install]

A instalação guiada está disponível em <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; Oracle (Database 360)](https://onenr.io/0kjnebKW7Ro)**</DNT>. A interface oferece um fluxo de trabalho guiado de ponta a ponta.

## Instalação em um relance [#at-a-glance]

1. Verifique a compatibilidade e reúna os pré-requisitos.
2. Instale o NRDOT Collector.
3. Configure o usuário de monitoramento.
4. Configure o NRDOT Collector.
5. Reinicie o NRDOT Collector.
6. Verifique se os dados estão fluindo para o New Relic.
