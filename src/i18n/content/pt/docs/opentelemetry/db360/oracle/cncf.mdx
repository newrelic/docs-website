Você pode usar o OpenTelemetry Collector Contribution para banco de dados Oracle para monitorar sua instância. O OpenTelemetry Collector Contribution é um projeto apoiado pela comunidade que fornece uma maneira de coletar dados de telemetria do banco de dados Oracle e enviá-los para o New Relic.

Por padrão, o OpenTelemetry Collector Contribution coleta métricas limitadas do banco de dados Oracle. Para enviar o desempenho de consulta, o tempo de espera, a sessão e outras métricas avançadas, você precisará configurar o OpenTelemetry Collector Contribution. Este guia mostra como configurá-lo para coletar métricas avançadas do banco de dados Oracle e enviá-las para o New Relic.

<Steps>
  <Step>
    ## Pré-requisitos [#prerequisites]

    * OpenTelemetry Collector Contrib (`otelcol-contrib`) instalado e configurado no seu sistema. Você pode fazer o download do release mais recente na página de [releases do OpenTelemetry Collector](https://github.com/open-telemetry/opentelemetry-collector-releases/releases).
  </Step>

  <Step>
    ## Habilite as métricas da interface [#enable]

    Você pode enriquecer sua experiência na plataforma New Relic adicionando e habilitando métricas em seu arquivo de configuração `otelcol-contrib`. Usando a configuração fornecida nesta seção, você pode preencher dados para as seguintes páginas na plataforma New Relic:

    * <DNT>Overview</DNT>
    * <DNT>Query performance</DNT>
    * <DNT>Wait events</DNT>
    * <DNT>Sessions</DNT>

    <CollapserGroup>
      <Collapser id="overview" title="Ativar métricas da página Overview">
        A página <DNT>Overview</DNT> exibe uma visão de alto nível da sua instância do banco de dados Oracle, incluindo métricas principais, como utilização de CPU, tempo de espera, I/O, memória e uso de sessão.

        Para preencher os dados da página <DNT>Overview</DNT> na plataforma New Relic, adicione a seguinte configuração ao arquivo de configuração `otelcol-contrib`:

        ```yaml
        receivers:
          oracledb:
            # Metrics required by the "Oracle Database Monitoring (OTel)" dashboard
            metrics:
              oracledb.buffer_cache.utilization:
                enabled: true
              oracledb.consistent_gets:
                enabled: true
              oracledb.cpu_time:
                enabled: true
              oracledb.database.cpu.utilization:
                enabled: true
              oracledb.database.wait.utilization:
                enabled: true
              oracledb.db_block_gets:
                enabled: true
              oracledb.enqueue_deadlocks:
                enabled: true
              oracledb.execution.utilization:
                enabled: true
              oracledb.executions:
                enabled: true
              oracledb.hard_parses:
                enabled: true
              oracledb.host.cpu.utilization:
                enabled: true
              oracledb.library_cache.utilization:
                enabled: true
              oracledb.logical_reads:
                enabled: true
              oracledb.logons:
                enabled: true
              oracledb.parse.rate:
                enabled: true
              oracledb.parse_calls:
                enabled: true
              oracledb.pga_memory:
                enabled: true
              oracledb.physical_io.requests:
                enabled: true
              oracledb.physical_reads:
                enabled: true
              oracledb.physical_writes:
                enabled: true
              oracledb.processes.usage:
                enabled: true
              oracledb.sessions.usage:
                enabled: true
              oracledb.sga.usage:
                enabled: true
              oracledb.shared_pool.utilization:
                enabled: true
              oracledb.sql_service.response.duration:
                enabled: true
              oracledb.sqlnet.io.transferred:
                enabled: true
              oracledb.tablespace_size.usage:
                enabled: true
              oracledb.transactions.usage:
                enabled: true
              oracledb.user_commits:
                enabled: true
              oracledb.user_rollbacks:
                enabled: true
            resource_attributes:
              oracle.db.edition:
                enabled: true
        ```
      </Collapser>

      <Collapser id="query-performance" title="Ativar métricas de desempenho de consulta, sessão e espera">
        Para preencher os dados das páginas <DNT>Query performance</DNT>, <DNT>Wait events</DNT> e <DNT>Sessions</DNT>, adicione a seguinte configuração ao seu arquivo de configuração `otelcol-contrib`:

        ```yaml
        receivers:
          oracledb:
            events:
              db.server.query_sample:
                enabled: true
              db.server.top_query:
                enabled: true
              db.server.session.wait_sample:
                enabled: true
              db.server.top_procedure:
                enabled: true
              db.server.query_plan:
                enabled: true

            top_query_collection:
              max_query_sample_count: 1000
              top_query_count: 200
              collection_interval: 60s
              allowed_comment_keys:
                - nr_service_guid

            query_sample_collection:
              max_rows_per_query: 100
              allowed_comment_keys:
                - nr_service_guid

            session_wait_event_collection:
              max_rows_per_query: 100

            top_procedure_collection:
              max_procedure_sample_count: 1000
              top_procedure_count: 250
              collection_interval: 60s
        ```
      </Collapser>
    </CollapserGroup>
  </Step>

  <Step>
    ## Reinicie o OpenTelemetry Collector [#restart]

    Reinicie o OpenTelemetry Collector para aplicar as alterações de configuração:

    ```bash
    sudo systemctl restart otelcol-contrib
    ```
  </Step>
</Steps>
