Obtenha insights abrangentes sobre o desempenho do seu Oracle Autonomous Database (ADB) com monitoramento de banco de dados, análise de consulta e métricas de integridade do sistema usando o coletor New Relic Distribution of OpenTelemetry (NRDOT).

<Callout variant="tip" title="Instalação guiada">
  Para instalar pela interface da New Relic, acesse <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; Oracle (Database 360)](https://onenr.io/0kjnebKW7Ro)**</DNT>. Esta página aborda apenas a instalação manual.
</Callout>

## Pré-requisitos [#prerequisites]

Antes de começar, certifique-se de ter o seguinte:

* Uma [chave de licença](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)da New Relic válida
* Arquitetura suportada: Linux com AMD64 e ARM64
* Conectividade de rede para o [endpoint OTLP da New Relic](/docs/opentelemetry/best-practices/opentelemetry-otlp)
* Oracle Database `19c` ou posterior

<Steps>
  <Step>
    ## Instalar o NRDOT Collector [#installation]

    Selecione o método de distribuição de instalação adequado para o seu ambiente Linux:

    <CollapserGroup>
      <Collapser title="Para arquitetura AMD64" id="amd">
        * Para sistemas Debian/Ubuntu, execute:

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_amd64.deb" --output nrdot-collector.deb && sudo dpkg -i nrdot-collector.deb
          ```

        * Para sistemas RHEL/CentOS/OEL, execute:

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_x86_64.rpm" --output nrdot-collector.rpm && sudo rpm -ivh nrdot-collector.rpm
          ```
      </Collapser>

      <Collapser title="Para arquitetura ARM64" id="arm">
        * Para sistemas Debian/Ubuntu, execute:

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_arm64.deb" --output nrdot-collector.deb && sudo dpkg -i nrdot-collector.deb
          ```

          ```bash

          ```
      </Collapser>
    </CollapserGroup>
  </Step>

  <Step>
    ## Configurar usuário do banco de dados [#database-user]

    Crie um usuário de monitoramento com os privilégios necessários para a sua instância de banco de dados ADB Oracle. Execute as seguintes instruções como SYS dentro do seu ADB de destino para criar um usuário de monitoramento local:

    ```sql
    CREATE USER <YOUR_DB_USERNAME> IDENTIFIED BY "<YOUR_DB_PASSWORD>";
    GRANT CREATE SESSION TO <YOUR_DB_USERNAME>;
    ```
  </Step>

  <Step>
    ## Conceder privilégios de monitoramento para o banco de dados autônomo [#grant-privileges]

    Execute estes comandos como administrador dentro do seu ADB. Isso dá à ferramenta de monitoramento o acesso básico necessário para coletar métricas, rastrear eventos e encontrar suas instâncias de banco de dados.

    ```sql

    GRANT SELECT ON SYS.V_$DATABASE   TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$CONTAINERS TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$DATAFILE   TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$PDBS       TO <YOUR_DB_USERNAME>; 
    GRANT SELECT ON SYS.V_$SYSSTAT                    TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$SYSMETRIC                  TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$SESSION                    TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$RESOURCE_LIMIT             TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$OSSTAT                     TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$SGAINFO                    TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$ROWCACHE                   TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$PARAMETER                  TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.DBA_TABLESPACE_USAGE_METRICS  TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.DBA_TABLESPACES               TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.DBA_DATA_FILES                TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.DBA_FREE_SPACE                TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.DBA_RECYCLEBIN                TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$SQL            TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$SQL_PLAN_STATISTICS_ALL       TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$LOCK           TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$SESSION_EVENT  TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.DBA_PROCEDURES    TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.DBA_OBJECTS       TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$PROCESS        TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$TRANSACTION    TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.CDB_SERVICES      TO <YOUR_DB_USERNAME>;
    ```
  </Step>

  <Step>
    ## Reiniciar o NRDOT Collector [#restart-collector]

    Após configurar o coletor, reinicie o serviço NRDOT Collector para aplicar as alterações:

    ```bash
    sudo systemctl restart nrdot-collector
    ```

    Para verificar se o coletor está funcionando corretamente, verifique o status do serviço:

    ```bash
    sudo systemctl status nrdot-collector
    ```

    <Callout variant="tip">
      Sempre reinicie o Collector NRDOT após fazer alterações de configuração para garantir que as novas configurações entrem em vigor.
    </Callout>
  </Step>

  <Step>
    ## Encontre e use seus dados [#find-use-data]

    Assim que seus dados estiverem sendo coletados, você poderá acessar o monitoramento abrangente do banco de dados Oracle por meio da interface do New Relic.

    Para encontrar sua entidade de banco de dados Oracle no New Relic:

    1. Vá para <DNT>**[https://one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT>.
    2. Defina os critérios de pesquisa como <DNT>`instrumentation.provider = opentelemetry`</DNT>.
    3. Selecione seu banco de dados Oracle ADB na lista de entidades.
  </Step>
</Steps>
