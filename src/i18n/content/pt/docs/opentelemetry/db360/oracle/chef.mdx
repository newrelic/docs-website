É possível instalar e configurar o NRDOT Collector para o monitoramento do banco de dados Oracle usando o cookbook `newrelic-install` do Chef. O cookbook instala o coletor, cria o usuário de monitoramento do banco de dados e configura o coletor quando a receita `newrelic-install::default` é executada.

<Callout variant="tip" title="Instalação guiada">
  Para instalar pela interface da New Relic, acesse <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; Oracle (Database 360)](https://onenr.io/0kjnebKW7Ro)**</DNT>. Esta página aborda apenas a instalação manual.
</Callout>

<Steps>
  <Step>
    ## Pré-requisitos [#prerequisites]

    * Uma conta New Relic com uma [chave de licença](/docs/apis/intro-apis/new-relic-api-keys/#overview-keys) válida.
    * Um [ID de conta](/docs/accounts/accounts-billing/account-structure/account-id) da New Relic.
    * Oracle Database 19c ou posterior.
    * Chef 15 ou posterior.
    * Para Oracle auto-hospedado: Oracle Linux 7, 8 ou 9, com acesso SSH (com encaminhamento de agente) ao host do Oracle Database onde o usuário SSH pode executar `sudo su - oracle` sem um prompt de senha.
    * Para Oracle no AWS RDS: um host do coletor executando Debian/Ubuntu ou CentOS/RHEL/OEL.
    * Para o banco de dados Oracle Autonomous (ADB): um host do coletor executando Debian/Ubuntu ou CentOS/RHEL/OEL, com o Oracle Instant Client (`sqlplus`) instalado e em `PATH`; o IP de saída de cada instância permitido em sua lista de controle de acesso do ADB; e a Oracle Wallet de cada instância baixada e descompactada em seu próprio diretório no nó.
  </Step>

  <Step>
    ## Baixar o cookbook do Chef [#download-cookbook]

    Faça o download do `newrelic-install` [cookbook do Chef](https://supermarket.chef.io/cookbooks/newrelic-install) do Chef Supermarket para o seu diretório de repositório (chef-repo):

    ```bash
    knife supermarket install newrelic-install
    ```
  </Step>

  <Step>
    ## Substituir os atributos padrão [#configure]

    Substitua os atributos padrão em `attributes/default.rb` pelos detalhes da sua conta:

    <CollapserGroup>
      <Collapser id="chef-host" title="Oracle Database auto-hospedado">
        Este cookbook monitora uma ou mais instâncias do banco de dados Oracle (cada uma acessível via SSH) a partir de um único coletor. Em vez de um único conjunto de host/contêiner/credencial, ele lê um arquivo de instâncias (YAML) que já deve existir no nó, listando cada instância a ser monitorada e, opcionalmente, um arquivo de segredos para fixar as senhas do usuário de monitoramento em vez de gerá-las automaticamente. Consulte a [instalação da CLI](/docs/opentelemetry/db360/oracle/cli/#install) para obter os formatos exatos dos arquivos.

        ```ruby
        default['newrelic_install']['NEW_RELIC_API_KEY']    = <API key>
        default['newrelic_install']['NEW_RELIC_ACCOUNT_ID'] = <Account ID>
        default['newrelic_install']['NEW_RELIC_REGION']     = <Region>
        default['newrelic_install']['targets'] = [
          'nrdot-collector-oracle'
        ]
        default['newrelic_install']['env']['NR_CLI_ORACLE_INSTANCES_FILE'] = <path to the instances YAML file on the node>
        default['newrelic_install']['env']['NR_CLI_ORACLE_SECRETS_FILE']   = <optional path to a secrets file pinning monitoring passwords, on the node>
        default['newrelic_install']['env']['NR_CLI_ORACLE_CONFIG_PRESET']  = <1 Basic, 2 Advanced, default 1>
        # See all available targets at: https://github.com/newrelic/chef-install
        ```

      <Collapser id="chef-rds" title="Oracle Database no AWS RDS">
        Este cookbook monitora um ou mais endpoints do RDS Oracle a partir de um único coletor, usando o mesmo padrão de arquivo de instâncias/arquivo de segredos como no auto-hospedado (ambos os arquivos já devem existir no nó).

        ```ruby
        default['newrelic_install']['NEW_RELIC_API_KEY']    = <API key>
        default['newrelic_install']['NEW_RELIC_ACCOUNT_ID'] = <Account ID>
        default['newrelic_install']['NEW_RELIC_REGION']     = <Region>
        default['newrelic_install']['targets'] = [
          'nrdot-collector-oracle-rds'
        ]
        default['newrelic_install']['env']['NR_CLI_ORACLE_INSTANCES_FILE'] = <path to the instances YAML file on the node>
        default['newrelic_install']['env']['NR_CLI_ORACLE_SECRETS_FILE']   = <path to the secrets file (KEY=VALUE per instance) on the node>
        default['newrelic_install']['env']['NR_CLI_ORACLE_CONFIG_PRESET']  = <1 Basic, 2 Advanced, default 1>
        # See all available targets at: https://github.com/newrelic/chef-install
        ```

  <Step>
    ## Faça o upload do cookbook do Chef [#upload-cookbook]

    Faça o upload do cookbook `newrelic-install` do Chef para o seu servidor Chef:

    ```bash
    knife cookbook upload newrelic-install
    ```
  </Step>

  <Step>
    ## Atualizar a run list [#run-list]

    Adicione a receita `newrelic-install` à run list de um nó:

    ```json
    "run_list": [
      "recipe[newrelic-install]"
    ]
    ```
  </Step>
