Esta referência fornece configurações YAML abrangentes para o monitoramento do PostgreSQL com o Collector da Distribuição New Relic do OpenTelemetry (NRDOT). Essas configurações com todos os recursos incluem o catálogo completo de métricas do PostgreSQL para ambientes de produção em implantações auto-hospedadas e do Amazon RDS.

<Callout variant="important">
  **Deseja começar rapidamente?** Estas são configurações avançadas para uso em produção. Se você estiver configurando o monitoramento do PostgreSQL pela primeira vez, recomendamos começar com a configuração padrão em nossos guias de configuração e retornar a estas configurações abrangentes depois de verificar a funcionalidade básica.
</Callout>

## Auto-hospedado [#hosted]
