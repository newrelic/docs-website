Monitore o desempenho do banco de dados PostgreSQL usando a New Relic Distribution of OpenTelemetry (NRDOT) com insights abrangentes sobre métricas de banco de dados, desempenho de consultas e saúde do sistema.

Essa abordagem baseada em NRDOT complementa nossa Integração On-Host (OHI) existente, utilizando padrões OpenTelemetry para monitoramento de banco de dados, facilitando a integração com sua stack de observabilidade existente.

Diferentemente das integrações no host, o NRDOT opera de forma independente do agente de infraestrutura. Ele não requer o agente de infraestrutura para coletar a telemetria do banco de dados. O NRDOT também inclui recursos nativos de monitoramento de host, para que você possa escolher:

* Use o agente de infraestrutura para monitoramento de host junto com o NRDOT para monitoramento de banco de dados, ou
* Use o NRDOT para monitorar tanto o banco de dados quanto o host.

## Escolha seu método de instalação [#install]

Você pode instalar o NRDOT Collector para o monitoramento do PostgreSQL das seguintes maneiras:

* **Instalação manual**: configure o coletor você mesmo em sua própria infraestrutura

  * [Configuração auto-hospedada](/docs/opentelemetry/db360/postgresql/hosted)
  * [Configuração do AWS RDS ou Aurora](/docs/opentelemetry/db360/postgresql/rds)

* **[New Relic CLI](/docs/opentelemetry/db360/postgresql/cli)**: instale e configure o coletor com um único comando

* **[Ansible](/docs/opentelemetry/db360/postgresql/ansible)**: instale e configure o coletor em escala usando a role `newrelic.newrelic_install` do Ansible

* **[Chef](/docs/opentelemetry/db360/postgresql/chef)**: instalar e configurar o coletor em escala usando o cookbook do Chef `newrelic-install`

* **[Helm chart](/docs/opentelemetry/db360/postgresql/helm)**: instale e configure o monitoramento do PostgreSQL no Kubernetes usando o Helm chart `postgresql-otel`

* **[Docker](/docs/opentelemetry/db360/postgresql/docker)**: execute o coletor como um contêiner irmão de uma instância do PostgreSQL já em execução no Docker

## Instalação guiada [#guided-installation]

A instalação guiada está disponível em <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; PostgreSQL (Database 360)](https://onenr.io/00jlEJKbdQW)**</DNT>. A interface oferece um fluxo de trabalho guiado de ponta a ponta.

## Instalação em um relance [#glance]

1. Verifique a compatibilidade e reúna os pré-requisitos.
2. Instale o NRDOT Collector.
3. Configure o usuário de monitoramento.
4. Configure o NRDOT Collector.
5. Reinicie o NRDOT Collector.
6. Verifique se os dados estão fluindo para o New Relic.
