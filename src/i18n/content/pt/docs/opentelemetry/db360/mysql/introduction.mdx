Monitorar o desempenho do banco de dados MySQL usando a New Relic Distribution of OpenTelemetry (NRDOT) com insights abrangentes sobre métricas de banco de dados, desempenho de consultas e saúde do sistema.

Essa abordagem baseada em NRDOT complementa nossa Integração On-Host (OHI) existente, utilizando padrões OpenTelemetry para monitoramento de banco de dados, facilitando a integração com sua stack de observabilidade existente.

Diferentemente das integrações no host, o NRDOT opera de forma independente do agente de infraestrutura. Ele não requer o agente de infraestrutura para coletar a telemetria do banco de dados. O NRDOT também inclui recursos nativos de monitoramento de host, para que você possa escolher:

* Use o agente de infraestrutura para monitoramento de host junto com o NRDOT para monitoramento de banco de dados, ou
* Use o NRDOT para monitorar tanto o banco de dados quanto o host.

## Instalação guiada [#ui-install]

Para instalar isso por meio da interface da New Relic, vá para <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; MySQL (Database 360)](https://onenr.io/0oQDYBNG1wy)** </DNT>. Siga as instruções na tela para configurar a integração.

## Instalação em um relance [#at-a-glance]

1. Verifique a compatibilidade e reúna os pré-requisitos.
2. Instale o NRDOT Collector.
3. Configure o usuário de monitoramento.
4. Configure o NRDOT Collector.
5. Reinicie o NRDOT Collector.
6. Verifique se os dados estão fluindo para o New Relic.
