Você pode instalar e configurar o NRDOT Collector para o monitoramento do MySQL usando a CLI da New Relic. A CLI instala o coletor, cria o usuário de monitoramento e configura o coletor em um único comando.

<Callout variant="tip" title="Instalação guiada">
  Para instalar pela interface da New Relic, acesse <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; MySQL (Database 360)](https://onenr.io/0oQDYBNG1wy)** </DNT>. Esta página aborda apenas a instalação manual.
</Callout>

<Steps>
  <Step>
    ## Pré-requisitos [#prerequisites]

    * Uma conta New Relic com uma [chave de licença](/docs/apis/intro-apis/new-relic-api-keys/#overview-keys) válida.
    * Um [ID de conta](/docs/accounts/accounts-billing/account-structure/account-id) da New Relic.
    * MySQL 5.7 ou superior.
    * Um host coletor Linux executando Debian/Ubuntu ou RHEL/CentOS, com `curl` e `systemd` instalados e o cliente `mysql` disponível.
    * Para MySQL auto-hospedado: acesso administrativo ao seu servidor MySQL (a conta `root` ou equivalente).
    * Para o AWS RDS/Aurora MySQL: conectividade de rede do host do coletor para o endpoint do RDS (acesso de entrada na porta do MySQL no grupo de segurança do RDS) e o nome de usuário e a senha mestre do RDS.
    * Conectividade de rede para o [endpoint OTLP da New Relic](/docs/opentelemetry/best-practices/opentelemetry-otlp) para sua região.

    Para requisitos detalhados, consulte [Compatibilidade e pré-requisitos](/docs/opentelemetry/db360/mysql/compatibility).
  </Step>

  <Step>
    ## Instale e configure o NRDOT Collector [#cli-install]

    <CollapserGroup>
      <Collapser id="cli-host" title="MySQL auto-hospedado">
        Esta receita monitora uma ou mais instâncias do MySQL a partir de um único coletor. Em vez de solicitar um único conjunto de host/porta/credencial, ela lê dois arquivos criados previamente: um arquivo de instâncias (YAML) listando cada instância a ser monitorada e um arquivo de segredos (`KEY=VALUE`) com um login e senha de administrador para cada uma, indexados para corresponder.

        1. Crie o arquivo de instâncias. Adicione uma entrada por instância do MySQL que deseja que este coletor monitore; apenas uma entrada se estiver executando somente uma única instância:

           ```bash
           cat > ~/mysql-instances.yml << 'EOF'
           instances:
             - host: localhost
               port: 3306
               login_name: newrelic
           EOF
           ```

        2. Crie o arquivo de segredos com um login de administrador (qualquer usuário administrador com acesso total serve; não precisa ser `root`) e senha para cada instância, indexado para corresponder à ordem do arquivo de instância:

           ```bash
           umask 077
           cat > ~/mysql-secrets.env << 'EOF'
           NR_CLI_MYSQL_ADMIN_USER_1=root
           NR_CLI_MYSQL_ADMIN_PASSWORD_1=YourRootPassword1
           EOF
           chmod 600 ~/mysql-secrets.env
           ```

        ```bash
        curl -Ls https://download.newrelic.com/install/newrelic-cli/scripts/install.sh | bash && sudo NEW_RELIC_API_KEY=INSERT_YOUR_API_KEY NEW_RELIC_ACCOUNT_ID=INSERT_YOUR_ACCOUNT_ID NEW_RELIC_REGION=INSERT_YOUR_REGION /usr/local/bin/newrelic install -n nrdot-collector-mysql
        ```

        <Callout variant="important">
          Este instalador se conecta ao MySQL via TCP usando uma senha, portanto, a conta de administrador no seu arquivo de segredos deve usar autenticação baseada em senha. Em algumas instalações do Debian/Ubuntu, `root`@`localhost` usa por padrão o plug-in `auth_socket` (sem senha, apenas soquete local), o que não funcionará aqui. Altere-o primeiro executando isto localmente como root:

          ```bash
          mysql -u root -e "ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '<password>';"
          ```

          Se isso falhar com `Access denied`, o pacote `mysql-server` também cria uma conta `debian-sys-maint` com credenciais de administrador conhecidas em `/etc/mysql/debian.cnf`. Use-o em vez disso:

          ```bash
          mysql --defaults-file=/etc/mysql/debian.cnf -e "ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '<password>';"
          ```
        </Callout>

      <Collapser id="cli-rds" title="AWS RDS/Aurora MySQL">
        Esta receita monitora um ou mais endpoints do RDS MySQL ou Aurora a partir de um único coletor, usando o mesmo padrão de arquivo de instâncias/arquivo de segredos que o auto-hospedado.

        1. Crie o arquivo de instâncias, usando o endpoint do RDS como `host`; apenas uma entrada se estiver monitorando somente uma única instância do RDS:

           ```bash
           cat > ~/mysql-instances.yml << 'EOF'
           instances:
             - host: mydb1.abcdefg12345.us-east-1.rds.amazonaws.com
               port: 3306
               login_name: newrelic
           EOF
           ```

        2. Crie o arquivo de segredos com o nome de usuário e a senha mestre do RDS para cada instância, indexado para corresponder à ordem do arquivo de instâncias:

           ```bash
           umask 077
           cat > ~/mysql-secrets.env << 'EOF'
           NR_CLI_MYSQL_ADMIN_USER_1=admin
           NR_CLI_MYSQL_ADMIN_PASSWORD_1=YourMasterPassword1
           EOF
           chmod 600 ~/mysql-secrets.env
           ```

        ```bash
        curl -Ls https://download.newrelic.com/install/newrelic-cli/scripts/install.sh | bash && sudo NEW_RELIC_API_KEY=INSERT_YOUR_API_KEY NEW_RELIC_ACCOUNT_ID=INSERT_YOUR_ACCOUNT_ID NEW_RELIC_REGION=INSERT_YOUR_REGION /usr/local/bin/newrelic install -n nrdot-collector-mysql-rds
        ```

  <Step>
    ## Encontre e use seus dados [#find]

    Assim que seus dados estiverem sendo coletados, você poderá acessar o monitoramento abrangente do banco de dados MySQL por meio da interface do New Relic.

    Para encontrar a entidade de banco de dados MySQL no New Relic:

    1. Vá para <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; All capabilities &gt; Databases**</DNT>.
    2. Na dropdown **<DNT>Entity type</DNT>**, selecione <DNT>**MySQL instance**</DNT> e clique em <DNT>**Apply**</DNT>.
    3. Selecione seu banco de dados MySQL na lista de entidades.

    Para confirmar que os dados estão chegando, execute esta consulta no [criador de consulta](/docs/query-your-data/explore-query-data/query-builder/introduction-query-builder/):

    ```sql
    SELECT count(*) FROM Metric
    WHERE metricName LIKE 'mysql.%'
    AND instrumentation.provider = 'opentelemetry'
    SINCE 10 minutes ago
    ```
