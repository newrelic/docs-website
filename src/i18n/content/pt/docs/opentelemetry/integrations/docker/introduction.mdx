A integração do Docker OpenTelemetry monitora a integridade e o desempenho dos seus aplicativos em contêineres coletando métricas em tempo real diretamente do Docker Engine. Você obtém visibilidade do uso de CPU, memória, I/O de rede e I/O de disco para cada contêiner em execução, para que possa detectar gargalos de recursos e falhas de contêiner antes que afetem seus serviços.

## Capacidades [#capabilities]

Esta integração fornece:

* **Métricas**: uso e utilização de CPU, uso e porcentagem de memória, I/O de rede (bytes e pacotes enviados e recebidos, descartes e erros), I/O de bloco e contagens de processos (PID)
* **Entidades**: contêineres Docker aparecem como entidades monitoradas no New Relic, vinculados ao seu host
* **Logs**: coletar logs dos seus contêineres. Para as etapas de configuração, consulte [Configuração avançada](/docs/opentelemetry/integrations/docker/advanced-configuration#logs).

## Escolha seu caminho de instalação [#choose]

* **[NRDOT Collector](/docs/opentelemetry/integrations/docker/install-nrdot) (recomendado)**: distribuição OpenTelemetry da New Relic, pré-configurada para enviar dados para a New Relic. Use esta opção se você ainda não executa outro OpenTelemetry Collector.
* **[OpenTelemetry Collector Contrib](/docs/opentelemetry/integrations/docker/install-otelcol-contrib)**: o coletor da comunidade upstream. Use isto se você já executa o OpenTelemetry Collector Contrib para outros workloads e deseja adicionar o monitoramento do Docker à mesma instância.

## Instalação em um relance [#at-a-glance]

A página de instalação orienta você sobre:

1. Verifique a compatibilidade e reúna os pré-requisitos
2. Instale o coletor escolhido
3. Configurar permissões do socket do Docker
4. Configurar o coletor
5. Reinicie o coletor
6. Verifique se os dados estão fluindo para o New Relic
