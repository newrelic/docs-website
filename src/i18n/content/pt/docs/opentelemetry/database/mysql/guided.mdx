É possível instalar o NRDOT Collector para o monitoramento do MySQL usando a instalação guiada da plataforma New Relic, que fornece uma configuração guiada pela plataforma através da interface da New Relic. Esta é a abordagem recomendada para inícios rápidos.

<Steps>
  <Step>
    ### Pré-requisitos [#prerequisites]

    Certifique-se de que seu ambiente atenda à nossa [compatibilidade e pré-requisitos](/docs/opentelemetry/database/mysql/compatibility).
  </Step>

  <Step>
    ### Instalação guiada [#guided]

    Para instalar o NRDOT Collector usando a instalação guiada:

    1. Entre na sua [conta New Relic](https://one.newrelic.com/).

    2. Vá para <DNT>**left navigation pane &gt; + Integration &amp; Agents &gt; MySQL (OpenTelemetry)**</DNT>.

    3. Na tela <DNT>Select an account</DNT>, selecione a conta na qual deseja instalar a integração do MySQL e clique em <DNT>**Continue**</DNT>.

    4. Na tela <DNT>Enter your credential</DNT>, selecione uma das seguintes opções e clique em **Continue**:

       * **Use uma chave existente**: se você já possui uma chave de licença, forneça a chave de licença. Para mais informações, consulte [Chaves de usuário](/docs/apis/intro-apis/new-relic-api-keys/#user-key).
       * **Criar uma nova chave**: se você não tiver uma chave de licença, clique em **Create a new key** para criar uma.

    5. Na tela <DNT>Select platform</DNT>, selecione a plataforma para instalar a integração do MySQL e clique em <DNT>**Continue**</DNT>.

    6. Siga as instruções na tela para configurar a integração para a plataforma selecionada.

    7. Após a instalação, na tela <DNT>Test your integration</DNT>, clique em **Test connection** para verificar se o NRDOT Collector consegue se conectar à instância do MySQL e enviar dados para o New Relic.
  </Step>

  <Step>
    ### (Opcional) Configurar a correlação entre APM e banco de dados [#optional-service-id]

    Para correlacionar o desempenho do aplicativo com as operações de banco de dados, é possível configurar a identificação de serviço de banco de dados. Este recurso permite visualizar exatamente quais aplicativos estão gerando workloads específicas de banco de dados. Para mais informações, consulte [configurar a identificação de serviço de banco de dados](/docs/opentelemetry/database/capabilities/db-apm/) para obter a correlação APM-banco de dados no New Relic.

    <Callout variant="important">
      Para visualizar dados de desempenho do banco de dados no APM, ambas as entidades devem estar na mesma conta New Relic. Se as entidades estiverem em contas diferentes da New Relic, você deve ter acesso a ambas as contas para visualizar os dados.
    </Callout>
  </Step>

  <Step>
    ### Encontre e use seus dados [#find-use-data]

    Assim que os dados estiverem sendo coletados, será possível acessar o monitoramento abrangente do banco de dados MySQL por meio da interface do New Relic.

    Para encontrar a entidade de banco de dados MySQL no New Relic:

    1. Vá para <DNT>**[https://one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT>.
    2. Na dropdown **<DNT>Entity type</DNT>**, selecione <DNT>**MySQL instance**</DNT> e clique em <DNT>**Apply**</DNT>.
    3. Selecione seu banco de dados MySQL na lista de entidades.
  </Step>
</Steps>
