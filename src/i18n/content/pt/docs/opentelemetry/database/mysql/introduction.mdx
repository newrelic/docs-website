Monitorar o desempenho do banco de dados MySQL usando a New Relic Distribution of OpenTelemetry (NRDOT) com insights abrangentes sobre métricas de banco de dados, desempenho de consultas e saúde do sistema.

Essa abordagem baseada em NRDOT complementa nossa Integração On-Host (OHI) existente, utilizando padrões OpenTelemetry para monitoramento de banco de dados, facilitando a integração com sua stack de observabilidade existente.

## Como configurar a NRDOT para MySQL [#configure]

<Steps>
  <Step>
    ### Pré-requisitos [#prerequisites]

    * Uma [chave de licença](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key) da New Relic.
    * Conectividade de rede entre o host onde o Collector NRDOT é instalado e o seu banco de dados MySQL.
    * Conectividade de rede para a [documentação dos endpoints OTLP da New Relic](/docs/opentelemetry/best-practices/opentelemetry-otlp/)
    * Esta integração está disponível como parte do programa de pré-visualização pública da New Relic. Verifique com seu gerente da organização para fazer a adesão na página [Previews &amp; Trials](https://one.newrelic.com/admin-portal/promotion-management/home).

    Para requisitos detalhados, consulte [Compatibilidade e Pré-requisitos](/docs/opentelemetry/database/mysql/compatibility).
  </Step>

  <Step>
    ### Instalar o NRDOT Collector [#installation]

    Escolha seu caminho de instalação com base em sua infraestrutura:

    * [MySQL auto-hospedado](/docs/opentelemetry/database/mysql/hosted)
    * [Monitoramento do RDS MySQL](/docs/opentelemetry/database/mysql/rds)
  </Step>

  <Step>
    ### Encontre e use seus dados [#find]

    Assim que os dados estiverem sendo coletados, será possível acessar o monitoramento abrangente do banco de dados MySQL por meio da interface do New Relic.

    Para encontrar a entidade de banco de dados MySQL no New Relic:

    1. Vá para <DNT>**[https://one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT>.
    2. Na dropdown **<DNT>Entity type</DNT>**, selecione <DNT>**MySQL instance**</DNT> e clique em <DNT>**Apply**</DNT>.
    3. Selecione seu banco de dados MySQL na lista de entidades.
  </Step>
</Steps>
