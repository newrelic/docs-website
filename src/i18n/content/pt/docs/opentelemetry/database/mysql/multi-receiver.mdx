É possível configurar o NRDOT Collector para monitorar várias instâncias do MySQL a partir de um único coletor. Isso é útil se houver vários bancos de dados MySQL em execução em hosts ou portas diferentes e se desejar coletar métricas de todos eles usando uma única instância do NRDOT Collector.

<Steps>
  <Step>
    ## Pré-requisitos [#prerequisites]

    * O NRDOT está instalado e configurado para suas instâncias do MySQL:

      * [MySQL auto-hospedado](/docs/opentelemetry/database/mysql/hosted)
      * [Monitoramento do RDS MySQL](/docs/opentelemetry/database/mysql/rds)
  </Step>

  <Step>
    ## Adicionar configuração de multirreceptor [#multi]

    O exemplo a seguir mostra como configurar o NRDOT Collector para monitorar duas instâncias do MySQL usando uma configuração de vários receptores. É possível adicionar mais receptores conforme necessário para instâncias adicionais do MySQL.

    ```yaml
    receivers:
      nrmysql/instance1: &nrmysql-common
        endpoint: "<INSTANCE_1_HOST>:<PORT>"
        username: "<YOUR_DB_USERNAME>"
        password: "<YOUR_DB_PASSWORD>"
        collection_interval: 10s
      nrmysql/instance2:
        <<: *nrmysql-common
        endpoint: "<INSTANCE_2_HOST>:<PORT>"

    service:
      pipelines:
        metrics:
          receivers: [nrmysql/instance1, nrmysql/instance2]
          exporters: [otlp/newrelic]
    ```
  </Step>

  <Step>
    ## Reiniciar o NRDOT Collector [#restart]

    A reinicialização é obrigatória, não opcional — o coletor carrega a configuração uma vez na inicialização e não recarrega a quente. Qualquer alteração de configuração não tem efeito até que o processo seja reiniciado.

    ```bash
    sudo systemctl restart nrdot-collector
    ```
  </Step>
</Steps>
