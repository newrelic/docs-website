Esta referência fornece configurações YAML abrangentes para o monitoramento do Microsoft SQL Server com o Collector da distribuição New Relic do OpenTelemetry (NRDOT). Essas configurações com todos os recursos incluem todas as métricas disponíveis, configurações avançadas de processador e pipelines otimizados para ambientes de produção em Linux e Windows, tanto em implantações auto-hospedadas quanto no AWS RDS.

<Callout variant="important">
  **Quer começar rapidamente?** Estas são configurações avançadas para uso em produção. Se você estiver configurando o monitoramento do SQL Server pela primeira vez, recomendamos começar com as configurações padrão em nossos guias de configuração e retornar a estas configurações abrangentes depois de verificar a funcionalidade básica.
</Callout>

## Configure o receptor [#receiver]

Você pode usar `max_concurrent_queries` para controlar quantas consultas de métricas o receiver executa em paralelo no SQL Server durante cada ciclo de coleta. O valor padrão é 4 se omitido ou definido como 0.

```yaml
    receivers:
    nrsqlserver:
        max_concurrent_queries: 4  # default is 4 if omitted or set to 0
```
