Monitore o desempenho do banco de dados SQL Server com métricas abrangentes coletadas pelo NRDOT Collector. Por padrão, o New Relic coleta as métricas referenciadas na seção [Métricas disponíveis](#default). É possível aprimorar o monitoramento habilitando as métricas desejadas listadas na seção [Métricas adicionais](#additional-metrics).

## Limitações do Amazon RDS [#rds-limitations]

Ao realizar o monitoramento de uma instância do Amazon RDS for SQL Server, certas métricas podem reportar `0` ou não ser coletadas devido a restrições do serviço RDS e limitações da edição do SQL Server.

<Callout variant="important">
  As seguintes limitações se aplicam especificamente a instâncias do SQL Server em execução no Amazon RDS. As implantações auto-hospedadas do SQL Server não são afetadas por essas restrições.
</Callout>
