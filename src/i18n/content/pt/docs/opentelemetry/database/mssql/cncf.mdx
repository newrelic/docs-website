É possível usar o OpenTelemetry Collector Contribution para Microsoft SQL Server para monitorar a instância. O OpenTelemetry Collector Contribution é um projeto apoiado pela comunidade que fornece uma maneira de coletar dados de telemetria do Microsoft SQL Server e enviá-los para o New Relic.

Por padrão, o OpenTelemetry Collector Contribution coleta métricas do Microsoft SQL Server e as envia para o New Relic. No entanto, essas são métricas limitadas. Para enviar métricas de desempenho de consulta, métricas de tempo de espera, métricas de sessão e outras métricas avançadas, será necessário configurar o OpenTelemetry Collector Contribution. Este guia fornece instruções para configurar o OpenTelemetry Collector Contribution para coletar métricas avançadas do Microsoft SQL Server e enviá-las para o New Relic.

<Steps>
  <Step>
    ## Pré-requisitos [#prerequisites]

    * OpenTelemetry Collector Contrib (`otelcol-contrib`) instalado e configurado no seu sistema. É possível fazer o download da versão mais recente na página de [releases do OpenTelemetry Collector](https://github.com/open-telemetry/opentelemetry-collector-releases/releases).
  </Step>

  <Step>
    ## Enable UI metrics [#enable]

    É possível enriquecer a experiência na plataforma New Relic adicionando e ativando as várias métricas no arquivo de configuração `otelcol-contrib`. Usando a configuração fornecida nesta seção, é possível preencher dados para as seguintes páginas na plataforma New Relic:

    * <DNT>Overview</DNT>
    * <DNT>Query performance</DNT>
    * <DNT>Wait events</DNT>
    * <DNT>Sessions</DNT>
    * <DNT>Clients</DNT>

    <CollapserGroup>
      <Collapser id="overview" title="Ativar métricas da página Overview">
        A página <DNT>Overview</DNT> exibe uma visão de alto nível da instância do Microsoft SQL Server, incluindo métricas principais, como contagem de banco de dados, I/O, latência, operações, espaço tempdb, taxa de deadlock e muito mais.

        Para preencher os dados da página <DNT>Overview</DNT> na plataforma New Relic, adicione a seguinte configuração ao arquivo de configuração `otelcol-contrib`:

        ```yaml
        receivers:
            sqlserver:

                # Enable comprehensive database metrics
              metrics:
                sqlserver.database.count:
                  enabled: true
                sqlserver.database.io:
                  enabled: true
                sqlserver.database.latency:
                  enabled: true
                sqlserver.database.operations:
                  enabled: true
                sqlserver.database.tempdb.space:
                  enabled: true
                sqlserver.database.tempdb.version_store.size:
                  enabled: true
                sqlserver.deadlock.rate:
                  enabled: true
                sqlserver.os.wait.duration:
                  enabled: true
                sqlserver.processes.blocked:
                  enabled: true
                sqlserver.memory.grants.pending.count:
                  enabled: true
                sqlserver.memory.area:
                  enabled: true
        ```
      </Collapser>

      <Collapser id="query-performance" title="Ativar Métricas de Desempenho de Consulta, Sessão, Espera e Cliente">
        É possível preencher dados para as seguintes páginas na plataforma New Relic:

        * <DNT>Query performance</DNT>: exibe informações detalhadas sobre as consultas em execução na instância do Microsoft SQL Server nas seguintes guias:

          * <DNT>Normalized queries</DNT>: mostra estatísticas agregadas por consulta, incluindo execuções, duração média, tempo médio de CPU e leituras lógicas. Clique em uma consulta para visualizar informações detalhadas da consulta selecionada, incluindo estatísticas agregadas de desempenho, planos de consulta observados e amostras individuais recentes com detalhamento por tipo de espera.
          * <DNT>Query samples</DNT>: mostra execuções de consulta individuais, incluindo horário de início, duração, tipo de espera, tempo de espera, banco de dados, usuário do BD, correlação de APM e host do cliente.

        * <DNT>Wait events</DNT>: exibe informações sobre os eventos de espera que ocorrem na instância do Microsoft SQL Server. A visualização de amostras de consulta mostra as consultas em espera no momento, juntamente com seu tipo e tempo de espera.

        * <DNT>Sessions</DNT>: Exibe informações sobre as sessões conectadas à sua instância do Microsoft SQL Server, incluindo contagens de sessões, estados das sessões, duração média das sessões ativas, sessões bloqueadas e detalhes individuais das sessões.

        * <DNT>Clients</DNT>: exibe informações sobre os clientes conectados à instância do Microsoft SQL Server, incluindo sessões ativas, sessões bloqueadas, usuários de BD conectados e detalhes do host do cliente.

        Para preencher os dados nessas páginas, adicione a seguinte configuração ao seu arquivo de configuração `otelcol-contrib`:

        ```yaml
        receivers:
            sqlserver:

                events:
                    db.server.query_sample:
                        enabled: true
                    db.server.top_query:
                        enabled: true

                top_query_collection:
                    lookback_time: 45s
                    max_query_sample_count: 100
                    top_query_count: 30
                    collection_interval: 30s

                query_sample_collection:
                    max_rows_per_query: 100
        ```
      </Collapser>

      <Collapser id="waits" title="Habilitar todas as esperas na guia de evento Wait">
        A visualização All waits mostra o tempo de espera no nível da instância detalhado por categoria de espera e tipo de espera individual.

        Para habilitar <DNT>All waits</DNT> na guia <DNT>Wait event</DNT> da plataforma New Relic, adicione a seguinte configuração ao arquivo de configuração `otelcol-contrib`:

        ```yaml

        receivers:
            sqlserver:

                metrics:
                    sqlserver.os.wait.duration:
                        enabled: true

        ```
      </Collapser>
    </CollapserGroup>
  </Step>

  <Step>
    ### Reinicie o OpenTelemetry Collector

    Reinicie o OpenTelemetry Collector para aplicar as alterações de configuração. É possível fazer isso executando o seguinte comando:

    ```bash
    Restart-Service -Name "otelcol-contrib"
    ```
  </Step>
</Steps>
