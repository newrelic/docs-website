Obtenha insights profundos sobre o desempenho do SQL Server com nossa solução de monitoramento baseada em OpenTelemetry. Acompanhe as métricas do banco de dados, analise consultas lentas, monitore o uso de recursos e correlacione o desempenho do banco de dados com os aplicativos.

Essa abordagem baseada em NRDOT complementa nossa Integração On-Host (OHI) existente, utilizando padrões OpenTelemetry para monitoramento de banco de dados, facilitando a integração com sua stack de observabilidade existente.

Principais recursos:

* **Padrões do OpenTelemetry**: integra-se perfeitamente às ferramentas de observabilidade existentes
* **Métricas abrangentes**: mais de 50 indicadores de desempenho de banco de dados
* **Insights no nível da consulta**: identifique e otimize consultas com desempenho lento
* **Implantação flexível**: funciona com ambientes auto-hospedados e na cloud
* **Correlação de APM**: conectar o desempenho do banco de dados aos traces do aplicativo

## Escolha seu método de instalação [#install]

É possível instalar o NRDOT Collector para o monitoramento do SQL Server das seguintes maneiras:

* Ambientes auto-hospedados: instalação manual na própria infraestrutura

  * [Windows auto-hospedado](/docs/opentelemetry/database/mssql/windows-hosted)
  * [Linux auto-hospedado](/docs/opentelemetry/database/mssql/linux-hosted)

* Ambientes do AWS RDS: monitoramento do SQL Server gerenciado na nuvem:

  * [Monitoramento do Windows RDS](/docs/opentelemetry/database/mssql/windows-rds)
  * [Monitoramento do Linux RDS](/docs/opentelemetry/database/mssql/linux-rds)

## Instalação guiada [#ui-install]

Para instalar isso por meio da interface da New Relic, vá para <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; MSSQL (OpenTelemetry)** </DNT>. Siga as instruções na tela para configurar a integração.

## Instalação em um relance [#at-a-glance]

<Steps>
  <Step>
    ### Pré-requisitos [#prerequisites]

    * Conta do New Relic com uma [chave de licença](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)válida

    * Conectividade de rede entre o host onde o NRDOT Collector é instalado e o seu Microsoft SQL Server.

    * Conectividade de rede para a [documentação dos endpoints OTLP da New Relic](/docs/opentelemetry/best-practices/opentelemetry-otlp/)

    * Requisitos do SQL Server, será necessário:

      * SQL Server 2017 ou posterior
      * Acesso administrativo ao SQL Server (função `sysadmin` ou equivalente)
      * Conectividade de rede entre o coletor e o SQL Server na porta `1433` ou porta personalizada

    * Esta integração está disponível como parte do programa de pré-visualização pública da New Relic. Verifique com seu gerente da organização para fazer a adesão na página [Previews &amp; Trials](https://one.newrelic.com/admin-portal/promotion-management/home).

    Para obter os pré-requisitos detalhados suportados, consulte a seção de pré-requisitos dedicada do documento de instalação.
  </Step>

  <Step>
    ### Instalar o NRDOT Collector [#install]

    Escolha seu caminho de instalação com base em sua infraestrutura:

    * **Instalação guiada**: para instalar por meio da interface da New Relic, vá para <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; MSSQL (OpenTelemetry)** </DNT>. Siga as instruções na tela para configurar a integração. Esta página abrange apenas o caminho de instalação da CLI.

    * **Ambientes auto-hospedados**: instalação manual em sua própria infraestrutura

      * [Windows auto-hospedado](/docs/opentelemetry/database/mssql/windows-hosted)
      * [Linux auto-hospedado](/docs/opentelemetry/database/mssql/linux-hosted)

    * **Ambientes AWS RDS**: monitoramento do SQL Server gerenciado na nuvem

      * [Monitoramento do Windows RDS](/docs/opentelemetry/database/mssql/windows-rds)
      * [Monitoramento do Linux RDS](/docs/opentelemetry/database/mssql/linux-rds)
  </Step>

  <Step>
    ### Configurar usuários de monitoramento [#user]

    Crie um usuário dedicado do Microsoft SQL Server com as permissões necessárias para permitir que o NRDOT Collector colete métrica e dados de desempenho de consulta. O usuário deve ter acesso somente leitura ao necessário.
  </Step>

  <Step>
    ### Configurar o NRDOT Collector [#configure]

    Configure o Collector NRDOT para se conectar à instância do Microsoft SQL Server. Isso envolve especificar os detalhes de conexão, o método de autenticação e quaisquer opções de configuração adicionais necessárias para o ambiente.
  </Step>

  <Step>
    ### Reiniciar o NRDOT Collector [#restart]

    Após configurar o NRDOT Collector, reinicie o serviço para aplicar as alterações e começar a coletar dados da sua instância do Microsoft SQL Server.
  </Step>

  <Step>
    ### Encontre e use seus dados [#find]

    Assim que os dados estiverem sendo coletados, será possível acessar o monitoramento abrangente do banco de dados SQL Server por meio da interface do New Relic.

    Para encontrar sua entidade de banco de dados SQL Server no New Relic:

    1. Vá para <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; All capabilities &gt; Databases**</DNT>.
    2. Na dropdown **<DNT>Entity type</DNT>**, selecione <DNT>**MSSQL instance**</DNT> e clique em <DNT>**Apply**</DNT>.
    3. Selecione o seu banco de dados do SQL Server na lista de entidades para visualizar o seu dashboard, métricas e dados de desempenho de consulta.
  </Step>
</Steps>
