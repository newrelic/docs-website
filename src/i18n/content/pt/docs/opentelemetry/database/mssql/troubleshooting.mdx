Solucione problemas comuns que podem ocorrer durante o monitoramento do Microsoft SQL Server com o NRDOT Collector.

## Problemas comuns

### Problemas de conectividade de rede

Caso encontre problemas de conectividade de rede com o NRDOT Collector, execute os seguintes comandos para testar a conectividade com a instância do SQL Server:

* Para Windows, execute:

  ```shell
  Test-NetConnection -ComputerName <YOUR_IP_ADDRESS> -Port <YOUR_PORT_NUMBER>
  ```

* Para Linux, execute:

  ```bash
  nc -zv <YOUR_IP_ADDRESS> <YOUR_PORT_NUMBER>
  ```
