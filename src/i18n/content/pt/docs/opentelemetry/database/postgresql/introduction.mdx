Monitore o desempenho do banco de dados PostgreSQL usando a New Relic Distribution of OpenTelemetry (NRDOT) com insights abrangentes sobre métricas de banco de dados, desempenho de consultas e saúde do sistema.

Essa abordagem baseada em NRDOT complementa nossa Integração On-Host (OHI) existente, utilizando padrões OpenTelemetry para monitoramento de banco de dados, facilitando a integração com sua stack de observabilidade existente.

## Escolha seu método de instalação [#install]

É possível instalar o NRDOT Collector para o monitoramento do PostgreSQL das seguintes maneiras:

* [Configuração auto-hospedada](/docs/opentelemetry/database/postgresql/hosted)
* [Configuração do AWS RDS ou Aurora](/docs/opentelemetry/database/postgresql/rds)

## Instalação em um relance [#glance]

As tarefas de alto nível para instalar o NRDOT Collector para o monitoramento do PostgreSQL são:

<Steps>
  <Step>
    ### Pré-requisitos [#prerequisites]

    Antes de instalar, certifique-se de ter:

    * PostgreSQL `14` e superior
    * Uma [chave de licença](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key) da New Relic.
    * Conectividade de rede entre o host onde o NRDOT Collector é instalado e o banco de dados PostgreSQL.
    * Conectividade de rede para a [documentação dos endpoints OTLP da New Relic](/docs/opentelemetry/best-practices/opentelemetry-otlp/)
    * Esta integração está disponível como parte do programa de pré-visualização pública da New Relic. Verifique com seu gerente da organização para fazer a adesão na página [Previews &amp; Trials](https://one.newrelic.com/admin-portal/promotion-management/home).

    Para obter os pré-requisitos detalhados suportados, consulte o documento de [Compatibilidade](/docs/opentelemetry/database/postgresql/compatibility).
  </Step>

  <Step>
    ### Instalar o NRDOT Collector [#install]

    Escolha seu caminho de instalação com base em sua infraestrutura:

    * **[PostgreSQL auto-hospedado](/docs/opentelemetry/database/postgresql/hosted)**
    * **[Monitoramento do RDS PostgreSQL](/docs/opentelemetry/database/postgresql/rds)**
  </Step>

  <Step>
    ### Configurar o usuário de monitoramento do PostgreSQL [#user]

    Cria e fornece as permissões necessárias ao usuário de monitoramento para que o NRDOT Collector colete métricas e amostras de consulta.
  </Step>

  <Step>
    ### Configurar o NRDOT Collector [#configure]

    Configure o NRDOT Collector para se conectar ao banco de dados PostgreSQL e à conta do New Relic. Isso inclui a definição dos detalhes de conexão, da autenticação e de quaisquer opções adicionais de configuração.
  </Step>

  <Step>
    ### Encontre e use seus dados [#find]

    Assim que os dados estiverem sendo coletados, será possível acessar o monitoramento abrangente do banco de dados PostgreSQL por meio da interface do New Relic.

    Para encontrar a entidade de banco de dados PostgreSQL no New Relic:

    1. Vá para <DNT>**[https://one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT>.
    2. Na dropdown **<DNT>Entity type</DNT>**, selecione <DNT>**PostgreSQL instance**</DNT> e clique em <DNT>**Apply**</DNT>.
    3. Selecione seu banco de dados PostgreSQL na lista de entidades.
  </Step>
</Steps>
