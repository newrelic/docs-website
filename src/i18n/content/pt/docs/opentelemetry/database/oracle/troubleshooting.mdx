## Problemas comuns

<CollapserGroup>
  <Collapser id="test-connection" title="Testar a conectividade de rede">
    Execute o seguinte comando para verificar se a porta do banco de dados Oracle está acessível a partir deste host.

    ```bash
    (timeout 3 bash -c '</dev/tcp/<YOUR_ENDPOINT>/<YOUR_PORT>' && echo "PORT OPEN - Network connection successful!") || echo "CONNECTION FAILED - Port closed or firewall blocking"
    ```

    **Resultado esperado:** `PORT OPEN - Network connection successful!`
  </Collapser>

  <Collapser id="otlp-endpoint-connection" title="Teste a conectividade do endpoint OTLP">
    Execute o seguinte comando para verificar se o seu host pode alcançar o endpoint OTLP do New Relic selecionado.

    ```bash
    ENDPOINT="<YOUR_OTLP_ENDPOINT>"
    HOST=$(echo "$ENDPOINT" | sed 's|https://||' | cut -d: -f1)
    PORT=$(echo "$ENDPOINT" | awk -F: '{print $NF}')
    (timeout 2 bash -c "</dev/tcp/$HOST/$PORT" && echo "✅ SUCCESS") || echo "❌ FAILED"
    ```

    **Resultado esperado:** `✅ SUCCESS`
  </Collapser>
</CollapserGroup>
