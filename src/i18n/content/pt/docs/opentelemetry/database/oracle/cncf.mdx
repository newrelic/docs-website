Você pode usar o OpenTelemetry Collector Contribution para banco de dados Oracle para monitorar sua instância. O OpenTelemetry Collector Contribution é um projeto apoiado pela comunidade que fornece uma maneira de coletar dados de telemetria do banco de dados Oracle e enviá-los para o New Relic.

Por padrão, o OpenTelemetry Collector Contribution coleta métricas do banco de dados Oracle e as envia para o New Relic. No entanto, essas são métricas limitadas. Para enviar métricas de desempenho de consulta, métricas de tempo de espera, métricas de sessão, métricas de armazenamento ASM e outras métricas avançadas, você precisará configurar o OpenTelemetry Collector Contribution. Este guia fornece instruções para configurar o OpenTelemetry Collector Contribution para coletar métricas avançadas do banco de dados Oracle e enviá-las para o New Relic.

<Steps>
  <Step>
    ## Pré-requisitos [#prerequisites]

    * OpenTelemetry Collector Contrib (`otelcol-contrib`) instalado e configurado no seu sistema. É possível fazer o download da versão mais recente na página de [releases do OpenTelemetry Collector](https://github.com/open-telemetry/opentelemetry-collector-releases/releases).
  </Step>

  <Step>
    ## Habilite as métricas da interface [#enable]

    É possível enriquecer a experiência na plataforma New Relic adicionando e ativando as várias métricas no arquivo de configuração `otelcol-contrib`. Usando a configuração fornecida nesta seção, é possível preencher dados para as seguintes páginas na plataforma New Relic:

    * <DNT>Overview</DNT>
    * <DNT>Query performance</DNT>
    * <DNT>Wait events</DNT>
    * <DNT>Sessions</DNT>

    <CollapserGroup>
      <Collapser id="overview" title="Ativar métricas da página Overview">
        A página <DNT>Overview</DNT> exibe uma visão de alto nível da sua instância do banco de dados Oracle, incluindo métricas principais, como utilização de CPU, tempo de espera, I/O, memória e uso de sessão.

        Para preencher os dados da página <DNT>Overview</DNT> na plataforma New Relic, adicione a seguinte configuração ao arquivo de configuração `otelcol-contrib`:

        ```yaml
        receivers:
          oracledb:
            # Metrics required by the "Oracle Database Monitoring (OTel)" dashboard
            metrics:
              oracledb.buffer_cache.utilization:
                enabled: true
              oracledb.consistent_gets:
                enabled: true
              oracledb.cpu_time:
                enabled: true
              oracledb.database.cpu.utilization:
                enabled: true
              oracledb.database.wait.utilization:
                enabled: true
              oracledb.db_block_gets:
                enabled: true
              oracledb.enqueue_deadlocks:
                enabled: true
              oracledb.execution.utilization:
                enabled: true
              oracledb.executions:
                enabled: true
              oracledb.hard_parses:
                enabled: true
              oracledb.host.cpu.utilization:
                enabled: true
              oracledb.library_cache.utilization:
                enabled: true
              oracledb.logical_reads:
                enabled: true
              oracledb.logons:
                enabled: true
              oracledb.parse.rate:
                enabled: true
              oracledb.parse_calls:
                enabled: true
              oracledb.pga_memory:
                enabled: true
              oracledb.physical_io.requests:
                enabled: true
              oracledb.physical_reads:
                enabled: true
              oracledb.physical_writes:
                enabled: true
              oracledb.processes.usage:
                enabled: true
              oracledb.sessions.usage:
                enabled: true
              oracledb.sga.usage:
                enabled: true
              oracledb.shared_pool.utilization:
                enabled: true
              oracledb.sql_service.response.duration:
                enabled: true
              oracledb.sqlnet.io.transferred:
                enabled: true
              oracledb.tablespace_size.usage:
                enabled: true
              oracledb.transactions.usage:
                enabled: true
              oracledb.user_commits:
                enabled: true
              oracledb.user_rollbacks:
                enabled: true
        ```
      </Collapser>

      <Collapser id="query-performance" title="Ativar métricas de desempenho de consulta, sessão e espera">
        Para preencher os dados das páginas <DNT>Query performance</DNT>, <DNT>Wait events</DNT> e <DNT>Sessions</DNT>, adicione a seguinte configuração ao seu arquivo de configuração `otelcol-contrib`:

        ```yaml
        receivers:
          oracledb:
            events:
              db.server.query_sample:
                enabled: true
              db.server.top_query:
                enabled: true
              db.server.session.wait_sample:
                enabled: true

            top_query_collection:
              max_query_sample_count: 1000
              top_query_count: 200
              collection_interval: 60s
              allowed_comment_keys:
                - nr_service_guid

            query_sample_collection:
              max_rows_per_query: 100
              allowed_comment_keys:
                - nr_service_guid

            session_wait_event_collection:
              max_rows_per_query: 100
        ```
      </Collapser>

      <Collapser id="asm" title="Ativar métricas de grupo de discos e disco ASM">
        O receiver do banco de dados Oracle oferece suporte ao monitoramento de instâncias do ASM (Automatic Storage Management). O receiver coleta métricas críticas de integridade do armazenamento, incluindo capacidade do grupo de discos, espaço livre utilizável, discos offline e erros de leitura/gravação de disco físico.

        Execute o seguinte como um usuário Oracle privilegiado para conceder acesso:

        ```sql
        GRANT SELECT ON V_$ASM_DISKGROUP_STAT TO <username>;
        GRANT SELECT ON V_$ASM_DISK_STAT TO <username>;
        ```

        Adicione a seguinte configuração ao seu arquivo de configuração `otelcol-contrib`. Todas as 5 métricas estão **desativadas por padrão** (opt-in):

        ```yaml
        receivers:
          oracledb:
            datasource: "oracle://otel:password@localhost:51521/XE"
            metrics:
              oracledb.asm.disk_group.free:
                enabled: true
              oracledb.asm.disk_group.capacity:
                enabled: true
              oracledb.asm.disk_group.usable_free:
                enabled: true
              oracledb.asm.disk_group.offline_disks:
                enabled: true
              oracledb.asm.disk.errors:
                enabled: true
        ```

        Para uma descrição dessas métricas, consulte a [referência de métricas](/docs/opentelemetry/database/oracle/metrics-reference/#asm).
      </Collapser>
    </CollapserGroup>
  </Step>

  <Step>
    ## Reinicie o OpenTelemetry Collector [#restart]

    Reinicie o OpenTelemetry Collector para aplicar as alterações de configuração:

    ```bash
    sudo systemctl restart otelcol-contrib
    ```
  </Step>
</Steps>
