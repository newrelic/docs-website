Esta referência fornece configurações YAML abrangentes para o monitoramento do banco de dados Oracle com o New Relic Distribution of OpenTelemetry (NRDOT) Collector. Essas configurações com todos os recursos incluem métricas de infraestrutura do host junto com o monitoramento de banco de dados para ambientes de produção.

<Callout variant="important">
  **Quer começar rapidamente?** Estas são configurações avançadas para uso em produção. Se você estiver configurando o monitoramento do banco de dados Oracle pela primeira vez, recomendamos começar com a configuração padrão em nossos guias de instalação e retornar a estas configurações abrangentes assim que tiver verificado a funcionalidade básica.
</Callout>
