  Ainda estamos trabalhando nesse recurso, mas adoraríamos que você experimentasse!

  Atualmente, esse recurso é fornecido como parte de uma prévia, de acordo com nossas [políticas de pré-lançamento](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy/).
</Callout>

Você pode configurar o NRDOT Collector para monitorar várias instâncias de banco de dados Oracle a partir de um coletor. Isso é útil se você tiver vários bancos de dados Oracle em execução em hosts diferentes e quiser coletar métricas de todos eles usando uma única instância do NRDOT Collector.

<Steps>
  <Step>
    ## Pré-requisitos [#prerequisites]

    * O NRDOT está instalado e configurado para suas instâncias do banco de dados Oracle:

      * [CDB](/docs/opentelemetry/database/oracle/host-cdb)
      * [PDB](/docs/opentelemetry/database/oracle/host-pdb)
      * [RDS](/docs/opentelemetry/database/oracle/rds)
      * [ADB](/docs/opentelemetry/database/oracle/adb)
  </Step>

  <Step>
    ## Adicionar configuração de multirreceptor [#multi]

    Os exemplos a seguir mostram como configurar o NRDOT Collector para monitorar várias instâncias de banco de dados Oracle usando uma configuração de vários receptores. Selecione o tipo de implantação que corresponde ao seu ambiente. Você pode adicionar mais receptores conforme necessário para instâncias adicionais.

    <CollapserGroup>

    ## Reiniciar o NRDOT Collector [#restart]

    A reinicialização é obrigatória, não opcional — o coletor carrega a configuração uma vez na inicialização e não recarrega a quente. Qualquer alteração de configuração não tem efeito até que o processo seja reiniciado.

    sudo systemctl restart nrdot-collector.service
