Obtenha insights abrangentes sobre o desempenho do seu banco de dados Amazon RDS Oracle com monitoramento de banco de dados, análise de consulta e métricas de integridade do sistema usando o coletor New Relic Distribution of OpenTelemetry (NRDOT).

<Callout variant="tip" title="Instalação guiada">
  Para instalar através da interface da New Relic, acesse <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; Oracle (OpenTelemetry)** </DNT>. Esta página aborda apenas o caminho de instalação da CLI.
</Callout>

## Pré-requisitos [#prerequisites]

Antes de começar, certifique-se de ter o seguinte:

* [Chave de licença](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)da New Relic válida
* Arquitetura suportada: Linux com AMD64 e ARM64
* Conectividade de rede para o [endpoint OTLP da New Relic](/docs/opentelemetry/best-practices/opentelemetry-otlp)
* Oracle Database `19c` ou posterior

  <Step>
    ## Instalar o NRDOT Collector [#installation]

    Selecione o método de distribuição de instalação adequado para o seu ambiente Linux:

    <CollapserGroup>
      <Collapser title="Para arquitetura AMD64" id="amd64-rds">
        * Para sistemas Debian/Ubuntu, execute:

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_amd64.deb" --output nrdot-collector.deb && sudo dpkg -i nrdot-collector.deb
          ```

        * Para sistemas RHEL/CentOS/OEL, execute:

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_x86_64.rpm" --output nrdot-collector.rpm && sudo rpm -ivh nrdot-collector.rpm
          ```
      </Collapser>

      <Collapser title="Para arquitetura ARM64" id="arm64-rds">
        * Para sistemas Debian/Ubuntu, execute:

          ```bash

          ```

        * Para sistemas RHEL/CentOS/OEL, execute:

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_arm64.rpm" --output nrdot-collector.rpm && sudo rpm -ivh nrdot-collector.rpm
          ```

      </Collapser>

  <Step>
    ## Configurar usuário do banco de dados [#database-user]

    Crie um usuário de monitoramento com os privilégios necessários para o seu banco de dados RDS Oracle.

    1. Faça login no banco de dados raiz como administrador:

       ```sql
       CREATE USER <USERNAME> IDENTIFIED BY "<USER_PASSWORD>";
       ```

    2. Conceda privilégios `CONNECT` ao usuário recém-criado:

       ```sql
       GRANT CONNECT TO <USERNAME>;
       ```
  </Step>

  <Step>

  <Step>
    ## Atualize a configuração do NRDOT Collector [#update-config]

    Atualize a configuração do NRDOT Collector para usar seu arquivo `oracle-config.yaml`.

    ```bash
    sudo sed -i 's|OTELCOL_OPTIONS="--config=/etc/nrdot-collector/config.yaml"|OTELCOL_OPTIONS="--config=/etc/nrdot-collector/oracle-config.yaml"|' /etc/nrdot-collector/nrdot-collector.conf
    ```

    <Callout variant="tip">
      Você também pode:

      * [Configure múltiplos receptores](/docs/opentelemetry/database/oracle/multi-receiver): para monitorar várias instâncias do banco de dados Oracle a partir de um coletor.
      * [Configure o SQL Query Receiver](/docs/opentelemetry/database/capabilities/sql-query-receiver/): para coletar métricas personalizadas do seu Oracle Database.
      * [Vincule seu banco de dados Oracle ao APM](/docs/opentelemetry/database/capabilities/db-apm): para correlacionar o desempenho do seu aplicativo com as operações do banco de dados. Isso permite visualizar exatamente quais aplicativos estão gerando workloads específicas de banco de dados.
      * [Configurar o gerenciamento de segredos](/docs/opentelemetry/database/capabilities/db-apm/#secret-management): para gerenciar com segurança informações confidenciais, como credenciais de banco de dados. Isso ajuda a aprimorar a segurança do ambiente de monitoramento ao evitar a inserção direta de dados sensíveis nos arquivos de configuração.
    </Callout>
  </Step>

  <Step>
    ## Reiniciar o NRDOT Collector [#restart-collector]

    Após atualizar a configuração, reinicie o NRDOT Collector:

    ```bash
    sudo systemctl restart nrdot-collector.service
    sudo systemctl status nrdot-collector.service
    ```

    <Callout variant="tip">
      Sempre reinicie o Collector NRDOT após fazer alterações de configuração para garantir que as novas configurações entrem em vigor.
    </Callout>
  </Step>

  <Step>
    ## Encontre e use seus dados [#find-use-data]

    Assim que seus dados estiverem sendo coletados, você poderá acessar o monitoramento abrangente do banco de dados Oracle por meio da interface do New Relic.

    Para encontrar sua entidade de banco de dados Oracle no New Relic:

    1. Vá para <DNT>**[https://one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT>.
    2. Defina os critérios de pesquisa como <DNT>`instrumentation.provider = opentelemetry`</DNT>.
    3. Selecione seu banco de dados Oracle na lista de entidades.
  </Step>
</Steps>
