Obtenha insights profundos sobre o desempenho do seu Oracle Database com nossa solução de monitoramento baseada em OpenTelemetry. Acompanhe as métricas do banco de dados, analise o desempenho da consulta, monitore o uso de recursos e correlacione o desempenho do banco de dados com seus aplicativos.

Essa abordagem baseada em NRDOT complementa nossa Integração On-Host (OHI) existente, utilizando padrões OpenTelemetry para monitoramento de banco de dados, facilitando a integração com sua stack de observabilidade existente.

## Capacidades [#capabilities]

* **Padrões do OpenTelemetry**: integra-se perfeitamente às ferramentas de observabilidade existentes
* **Métricas abrangentes**: insights profundos sobre o desempenho do banco de dados, eventos de espera e uso de recursos
* **Insights em nível de consulta**: identificar e analisar consultas com desempenho lento e atividade de sessão
* **Implantação flexível**: funciona com ambientes CDB/PDB no host e Amazon RDS
* **Correlação de APM**: conectar o desempenho do banco de dados aos traces do aplicativo

## Escolha seu caminho de instalação [#choose]

Você pode instalar o NRDOT Collector para o monitoramento do Oracle Database das seguintes maneiras:

* Ambientes auto-hospedados: instalação manual na própria infraestrutura

  * [Banco de dados de contêiner (CDB) no host](/docs/opentelemetry/database/oracle/host-cdb): monitore um banco de dados de contêiner inteiro, incluindo todos os bancos de dados plugáveis sob ele.
  * [Banco de dados plugável (PDB) no host](/docs/opentelemetry/database/oracle/host-pdb): monitore um banco de dados plugável individual.

* Ambientes AWS RDS: monitoramento de banco de dados Oracle gerenciado na nuvem
  * [Monitoramento do RDS](/docs/opentelemetry/database/oracle/rds): monitore uma instância do Oracle Database em execução no Amazon RDS.

* Ambientes Oracle Cloud: monitoramento de banco de dados Oracle totalmente gerenciado
  * [Monitoramento do Autonomous Database (ADB)](/docs/opentelemetry/database/oracle/adb): monitore uma instância do Oracle Autonomous Database.

## Instalação guiada [#ui-install]

A instalação guiada está disponível em <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; Oracle (OpenTelemetry)**</DNT>. A interface oferece um fluxo de trabalho guiado de ponta a ponta.

## Instalação em um relance [#at-a-glance]

<Steps>
  <Step>
    ### Pré-requisitos [#prerequisites]

    * [Chave de licença](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)da New Relic válida
    * Arquitetura suportada: Linux com AMD64 e ARM64
    * Conectividade de rede para o [endpoint OTLP da New Relic](/docs/opentelemetry/best-practices/opentelemetry-otlp/)
    * Oracle Database 19c ou posterior
  </Step>

  <Step>
    ### Instalar o NRDOT Collector [#install-step]

    Instale o NRDOT Collector em seu sistema seguindo as instruções para seu ambiente específico

    * [CDB](/docs/opentelemetry/database/oracle/host-cdb)
    * [PDB](/docs/opentelemetry/database/oracle/host-pdb)
    * [RDS](/docs/opentelemetry/database/oracle/rds)
    * [ADB](/docs/opentelemetry/database/oracle/adb)
  </Step>

  <Step>
    ### Configure o usuário de monitoramento [#user]

    Crie um usuário dedicado do banco de dados Oracle com as permissões de leitura necessárias para permitir que o NRDOT Collector colete métricas e dados de desempenho de consulta.
  </Step>

  <Step>
    ### Configurar o NRDOT Collector [#configure]

    Configure o NRDOT Collector para se conectar à sua instância do banco de dados Oracle. Isso envolve especificar os detalhes de conexão, o método de autenticação e quaisquer opções de configuração adicionais necessárias para o ambiente.
  </Step>

  <Step>
    ### Reiniciar o NRDOT Collector [#restart]

    Após configurar o NRDOT Collector, reinicie o serviço para aplicar as alterações e começar a coletar dados da sua instância do banco de dados Oracle.
  </Step>

  <Step>
    ### Encontre e use seus dados [#find]

    Assim que seus dados estiverem sendo coletados, você poderá acessar o monitoramento abrangente do banco de dados Oracle por meio da interface do New Relic.

    Para encontrar sua entidade de banco de dados Oracle no New Relic:

    1. Vá para <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT>.
    2. Defina os critérios de pesquisa como <DNT>`instrumentation.provider = opentelemetry`</DNT>.
    3. Selecione seu banco de dados Oracle na lista de entidades.
  </Step>
</Steps>
