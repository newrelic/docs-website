* No host: impor um limite rígido de memória de 2400 MiB na árvore de processos do Agent Control (AC + todos os agentes filhos) via systemd `MemoryMax` no Linux.

### Correções de bugs

* Linux: evitar a desativação do serviço systemd após a atualização do pacote RPM

### Atualizações de segurança

* Atualizado rust crate futures para 0.3.34
* Atualizado alpine/helm para v4.2.4
* Crate do Rust serde-saphyr atualizado para 1.1.0

Para uma descrição detalhada das alterações, consulte as [notas de versão](https://github.com/newrelic/newrelic-agent-control/releases/tag/1.22.0).
