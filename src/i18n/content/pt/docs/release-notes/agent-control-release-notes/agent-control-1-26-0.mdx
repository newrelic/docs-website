### Novo recurso

* Adicionado provedor de valor do Azure Key Vault, com suporte à autenticação de Identidade Gerenciada e Entidade de Serviço.
* A autoinstrumentação agora recebe a chave de licença injetada como cabeçalho se nenhuma estiver definida em todos os sistemas.

### Correções de bugs

* Windows: o `install.ps1` agora detecta e remove uma instalação autônoma do agente de infraestrutura do New Relic para evitar relatórios duplicados de host; ele deve ser reconfigurado como um subagente gerenciado pelo Controle de agentes posteriormente, se ainda for necessário.
* On-host: corrigidas as reinicializações da integração causadas por sincronização redundante do sistema de arquivos e recriação completa do diretório ao gravar arquivos de configuração de OHI no sistema de arquivos compartilhado.
* Tornar cancelável o atraso inicial das threads de health-check, para reduzir os períodos de espera ociosa de encerramento normal.
* Corrigidos pequenos problemas de logging: um campo redundante, um log duplicado, níveis de log incorretos e uso inconsistente de maiúsculas e minúsculas nas mensagens.
* O Controle de agentes agora sempre relata novamente seu status de configuração remota na inicialização, corrigindo uma falha de reenvio após a reinicialização quando o servidor faz requests de uma sincronização de estado completo.
* Windows: o desligamento/reinicialização do sistema passa pelo mesmo caminho de parada normal do serviço que uma parada manual do serviço, em vez do tratamento de sinal ctrl.
