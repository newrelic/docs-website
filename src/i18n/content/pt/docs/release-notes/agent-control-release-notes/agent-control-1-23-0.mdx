### Novo recurso

* Adicionar suporte para sobrescrita de variáveis por meio da sintaxe `variable.agentConfig` em chaves de configuração remota.
* Adicionar suporte para uma única entrada de sobrescrita de variável `string_map` por meio da sintaxe `variable.agentConfig.<variable>:<map-key>` em chaves de configuração remota.
* Tipo de agente de infraestrutura no host (linux): expor a configuração de integração `nri-docker` por meio de uma nova variável `config_docker`.
* Tipo de agente: impor o formato do nome da variável para `[A-Za-z0-9_-]` começando com uma letra e tamanho máximo de 64 caracteres.
* On-Host: habilitar a capacidade de atualização automática por padrão. As atualizações automáticas são executadas apenas quando comandadas pelo Controle de Agentes.

### Correções de bugs

* Supervisor do K8s: forçar uma reconciliação do Flux em HelmReleases paralisados (por exemplo, após esgotar as tentativas de instalação/atualização) quando uma nova configuração remota chega e reinicia o supervisor do subagente.
* On-host: relatar a última falha real (erro de lançamento ou saída diferente de zero) no `lastErrorMessage` do status não íntegro assim que a política de reinicialização for excedida, em vez da mensagem genérica &quot;Restart policy exceeded&quot;.
* On-host: persistir o diretório inicial do fluent-bit (`fb.db`) durante as atualizações do pacote infra-agent em vez de armazená-lo no diretório do pacote substituído

### Atualizações de segurança

* Atualizado o crate rust either para 1.18.0
* Atualizado rust para v1.98.0
* Atualizado o crate rust actix-web para 4.15.0
* Atualizado o alpine/kubectl para a v1.36.4
* Crate rust syn atualizado para 3.0.4

Para uma descrição detalhada das alterações, consulte as [notas de versão](https://github.com/newrelic/newrelic-agent-control/releases/tag/1.23.0).
