### Novo recurso

* Adicionado provedor de valor do AWS Secrets Manager (`nr-awssm`), com suporte a credenciais de chave de acesso e perfis de instâncias de EC2.
* Linux e Windows: o Controle de agentes e seus subagentes agora relatam `os.version` e `host.arch` como atributos do OpAMP. O Linux também relata `os.name` (o ID da distribuição, por exemplo, &quot;debian&quot;).

### Correções de bugs

* On-host: subagentes sem uma verificação de integridade definida não registram mais erros de executáveis que publicam a integridade em um canal fechado.
* Os clientes HTTP não obtêm mais as configurações de proxy fora da configuração de proxy do Controle de agentes, e `ignore_system_proxy: true` é totalmente respeitado.
* On-host: a saída do subagente contendo bytes não UTF-8 não interrompe mais o encaminhamento de logs nem encerra o subagente. Tais linhas agora são registradas com os bytes inválidos substituídos.
* Windows: uma atualização automática que falha durante a preparação do novo binário não deixa mais o Controle de agentes sem um executável, o que impedia o serviço de iniciar após a próxima reinicialização.
