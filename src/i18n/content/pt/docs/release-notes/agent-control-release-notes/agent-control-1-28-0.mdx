### Novo recurso

* A análise de YAML agora é mais rigorosa com mapas vazios: um valor nulo (um valor vazio, `~` ou `null`) onde um mapa é esperado, como um `config:` isolado em uma configuração remota armazenada, é rejeitado em vez de ser tratado como um mapa vazio. Use `{}` para um mapa vazio. Documentos vazios ainda são aceitos.

### Correções de bugs

* On-host: a limpeza do sistema de arquivos compartilhado não segue mais links simbólicos, portanto, o conteúdo fora do sistema de arquivos compartilhado nunca é excluído, e os links simbólicos órfãos são removidos.
* On-host: falhas de inicialização que ocorrem antes da configuração de logging (por exemplo, um `local_config.yaml` inválido) agora são gravadas no arquivo de log padrão do Controle de agentes, para que fiquem visíveis ao executar como um serviço do Windows.
* On-host: os requests do registro OCI agora passam pelo proxy configurado, independentemente do esquema de URL do proxy, portanto, um proxy `http://` não é mais ignorado.
* On-host: um subagente morto por um sinal (por exemplo, pelo OOM killer) agora é relatado como encerrado por esse sinal em vez de &quot;process exited with code: 0&quot;.
