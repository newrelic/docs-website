### Novo recurso

* Kubernetes: `--release-name` agora é opcional em `uninstall-agent-control`; omiti-lo ignora a exclusão dos CRs HelmRelease/HelmRepository da própria versão.
* On-host: adicionados agentTypes nri-apache e nri-nginx.
* On-host: adicionado o agentType nri-postgresql.
* On-host: adicionado o agentType nri-mysql.
* On-host: adicionado tipo de agente nri-memcached.
* Arquivos de log rotacionados agora têm 30 dias de retenção.
* Adicionado o subcomando `agent-type validate --file <path>` a `newrelic-agent-control-cli` e `newrelic-agent-control-k8s-cli` para validação em nível de esquema de arquivos de definição de tipo de agente.
* Estendido `agent-type validate` com validação semântica: cada referência de `${nr-var:X}` em `deployment` deve ter uma declaração `variables` correspondente.
* Habilitar cache para registro de tipo de agente remoto
