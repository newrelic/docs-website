### Novo recurso

* Sistema de arquivos do Windows: código não utilizado removido e uso de APIs de nível superior para interação com o Windows.
* Relata a capacidade personalizada OpAMP `com.newrelic.remoteAgentTypeRepoReachable` quando o repositório OCI do tipo de agente configurado está acessível na inicialização.
* On-host: adicionado agentType nri-flex.

### Correções de bugs

* Windows: arquivos corrigidos nos diretórios gerenciados do controle do agente que eram deixados com permissões que ele não podia usar. Os diretórios gerenciados agora usam uma ACE de administrador herdável, e o controle do agente tenta reparar as ACEs na inicialização.

### Atualizações de segurança

* Atualizado o crate rust http para 1.5.0
