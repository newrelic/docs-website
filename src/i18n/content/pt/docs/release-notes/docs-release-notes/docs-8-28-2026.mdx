### Novos documentos

* Adicionado [Enviar traces de GenAI para a New Relic com o OpenTelemetry](/docs/ai-monitoring/opentelemetry-ai-monitoring), que explica como enviar traces de GenAI do OTel, incluindo chamadas de LLM, chamadas de ferramentas e etapas de agente, para o AI Monitoring da New Relic sem um agente da New Relic.

* Adicionado o [AI Monitoring do eBPF](/docs/ebpf/ai-monitoring), que abrange como o agente eBPF detecta e monitora automaticamente workload de GenAI e LLM em hosts Linux e cluster do Kubernetes sem alterações no código.

* Adicionado [Monitorar automaticamente os websockets](/docs/browser/new-relic-browser/browser-pro-features/websockets), que abrange o rastreamento da integridade da conexão WebSocket, incluindo mensagens enviadas e recebidas, duração da conexão e eventos de fechamento, usando o agente do browser.

* Adicionado [Casos de uso de monitoramento sintético](/docs/synthetics/synthetic-monitoring/guides/synthetic-monitoring-use-cases), que ajuda a escolher o tipo de monitor correto, desde verificações de ping leves até jornadas de API e navegador totalmente roteirizadas.

* Adicionado [Tipos de agente](/docs/new-relic-control/agent-control/agent-types), que abrange as definições de tipo de agente do Agent Control, como eles funcionam e quais agentes são compatíveis.

* Adicionado [Introdução ao Amazon Fire TV](/docs/streaming-video-&-ads/installation/amazon-fire-tv/get-started-with-amazon-fire-tv) e guias de instalação para [Shaka Player](/docs/streaming-video-&-ads/installation/amazon-fire-tv/install-shaka-player), [Dash.js](/docs/streaming-video-&-ads/installation/amazon-fire-tv/install-dashjs) e [HTML5](/docs/streaming-video-&-ads/installation/amazon-fire-tv/install-html5), que explicam como monitorar a reprodução de vídeo no Amazon Fire TV usando o VegaTracker.

* Adicionado [Agrupar funções do Lambda em uma única entidade OTel](/docs/serverless-function-monitoring/aws-lambda-monitoring/opentelemetry/otel-service-name-lambda), que abrange o uso de `OTEL_SERVICE_NAME` para consolidar várias funções do Lambda instrumentadas pelo OTel em uma única entidade do New Relic.

* Adicionados [Relatório de erros de JavaScript do React Native](/docs/mobile-monitoring/new-relic-monitoring-react-native/react-native-agent-js-error-reporting), [Listar e excluir mapas de origem do React Native](/docs/mobile-monitoring/new-relic-monitoring-react-native/list-delete-react-native-source-maps) e [Solucionar problemas de mapas de origem do React Native](/docs/mobile-monitoring/new-relic-monitoring-react-native/troubleshoot-react-native-source-maps) para orientar a migração para o tipo de evento `MobileJSError` introduzido no agente React Native v1.9.0.

* Adicionados os seguintes documentos do catálogo de ações de automação de fluxo de trabalho:

  * [Ações de problema do New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/newrelic-issue): criar, atualizar e gerenciar problemas do New Relic a partir de um fluxo de trabalho.
  * [Ações do New Relic Lens](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/newrelic-lens): executar consultas e análises do New Relic Lens a partir de um fluxo de trabalho.
  * [Invocar uma Azure Function](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-functions-invoke): invocar uma Azure Function a partir de um fluxo de trabalho.
  * [Executar uma API do Azure DevOps](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-devops-api): executar chamadas de API do Azure DevOps a partir de um fluxo de trabalho.
  * [Ações de problema do GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-issue): criar, atualizar, obter, listar, comentar, bloquear e desbloquear problemas do GitHub a partir de um fluxo de trabalho.
