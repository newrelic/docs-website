### Novos documentos

* Introduzida a [Workload Identity Federation](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation) como a maneira padrão recomendada para conectar integrações do GCP.

### Grandes mudanças

* Adicionados [endpoints compatíveis com FedRAMP](/docs/security/security-privacy/compliance/fedramp-compliant-endpoints) para APM, infraestrutura, browser e agentes mobile.
* Atualizado [Instalar a integração do ECS](/docs/infrastructure/elastic-container-service-integration/install-ecs-integration) com dois novos modos Fargate forward-only: `NRIA_IS_FORWARD_ONLY` e `NRIA_IS_SECURE_FORWARD_ONLY`.
* Atualizada a [configuração do agente Ruby](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration) com novas opções do agente Ruby 10.7.0, incluindo `transaction_tracer.cap_segment_artifacts`, configurações de instrumentação do Puma e opções de nome do host do Google Cloud Run.

### Pequenas mudanças

* Corrigidas as [permissões de usuário](/docs/accounts/accounts-billing/new-relic-one-user-management/user-permissions) restaurando a seção permission-definitions.
* Atualizado o [Tipo de Usuário](/docs/accounts/accounts-billing/new-relic-one-user-management/user-type) para substituir &quot;inteligência aplicada&quot; por &quot;alertas&quot;.
* Atualizado o documento [Automação de Fluxo de Trabalho](/docs/workflow-automation/introduction-to-workflow) com a permissão `account.create.own_api_keys` necessária para executar um fluxo de trabalho.
* Atualizado o [Catálogo de Aplicativos](/docs/service-architecture-intelligence/catalogs/applications-catalog) e o [Catálogo de Infraestrutura](/docs/service-architecture-intelligence/catalogs/infrastructure-catalog) para esclarecer como o agrupamento de Ambiente é preenchido.
* Corrigido [Integrações e Funções Personalizadas](/docs/infrastructure/google-cloud-platform-integrations/get-started/integrations-custom-roles) para corrigir a descrição da API do Cloud Resource Manager.
* Atualizado o documento [Inteligência de Custos na Nuvem: Preços](/docs/cci/cci-pricing) com uma comparação qualitativa de custos em vez de taxas exatas de ingestão por GB.
* Atualizado [Tipos de Gráficos](/docs/query-your-data/explore-query-data/use-charts/chart-types) para restaurar a orientação mais simples de gráfico de barras.
* Atualizado [Configurar Definições de Monitoramento de Mobile](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/configure-settings) para refletir a persistência de evento ativada por padrão.
* Corrigida a instrumentação de [auto-attach do APM do Kubernetes](/docs/kubernetes-pixie/kubernetes-integration/installation/k8s-agent-operator), pois ela não exige mais um namespace específico.
* Atualizado o [guia de práticas recomendadas do agente eBPF](/docs/ebpf/best-practices) com uma nova seção de &quot;abordagem de monitoramento unificado&quot;.
* Atualizada a [integração de monitoramento do Amazon API Gateway REST (v1)](/docs/infrastructure/amazon-integrations/aws-integrations-list/aws-api-gateway-v1-monitoring-integration) para documentar o CloudWatch Metric Streams como um método de ingestão.
* Corrigidos os links de fallback do CloudWatch da [instrumentação baseada em SDK](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/sdk-based-instrumentation).
* Adicionado suporte a entidade em nível de tabela e novas métricas de armazenamento à [integração de monitoramento do Google BigQuery](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-bigquery-monitoring-integration).
* Atualizado o documento do [New Relic Autopilot](/docs/agentic-ai/autopilot/setup) para simplificar o requisito de preço para Advanced Compute.
* Renomeado Workload Inteligente para [Workloads Inteligentes](/docs/new-relic-solutions/new-relic-one/workloads/create-intelligent-workload).
