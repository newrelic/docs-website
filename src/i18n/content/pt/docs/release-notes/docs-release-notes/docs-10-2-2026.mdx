### Novos documentos

* Adicionado [suporte à autenticação Kerberos (SPNEGO) para localizações privadas](/docs/synthetics/synthetic-monitoring/private-locations/synthetics-kerberos-auth-support/), cobrindo a configuração do servidor web KDC e SPNEGO e a configuração do gerenciador de jobs de Sintéticos.
* Adicionado [Gerenciar acesso ao Controle de Agentes](/docs/new-relic-control/fleet-control/access-management/), cobrindo padrões de acesso baseados em função para escopo por frota, separação de ciclo de vida, gerenciamento de grupo delegado e isolamento de unidade de negócios.
* Adicionado [Instrumente seus sistemas com o Controle de agentes](/docs/new-relic-control/agent-control/instrumentation/), que substitui a antiga página de Reinstrumentação e abrange a configuração da instrumentação do zero ou a migração de agentes existentes no Kubernetes, Linux e Windows.
* Adicionada a documentação do [Pathpoint (atualizado)](/docs/pathpoint/get-started-pathpoint/) para a pré-visualização pública, abrangendo fluxos, indicadores de integridade, KPIs e gerenciamento do NerdGraph.
* Adicionada a [integração de monitoramento do Google Distributed Cloud Edge](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-distributed-cloud-edge-monitoring-integration/), cobrindo os dados que ela reporta, ativação, frequência de sondagem e Workload Identity Federation.
* Adicionado [RCA de alerta com Autopilot e e-mail](/docs/workflow-automation/workflow-examples/integrations/autopilot-email-rca/) para mostrar como executar uma análise de causa raiz do Autopilot em um alerta e enviar um relatório HTML por e-mail, juntamente com uma visão geral dos [modelos de fluxo de trabalho de RCA do Autopilot](/docs/workflow-automation/workflow-examples/integrations/autopilot-rca/).
* Adicionada a ação [Consulta de logs do Azure Monitor](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-monitor-querylogs/) ao catálogo de ações da Automação de fluxo de trabalho.
* Adicionadas [ações do Azure Cosmos DB](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-cosmos-db/) ao catálogo de ações de automação de fluxo de trabalho.
* Adicionadas as [ações da API de tag do AWS Resource Groups](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/resourcetagging/aws-resourcetagging/) ao catálogo de ações de automação de fluxo de trabalho.
* Adicionadas [ações de tag do New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging/) ao catálogo de ações de Automação de fluxo de trabalho para adicionar, substituir e remover tags em entidades do New Relic.

### Grandes mudanças

* Reescrito [Entenda a página da interface de detalhes do trace](/docs/distributed-tracing/ui-data/trace-details/) para a experiência atualizada do mapa de entidades.
* Os [Tipos de agente](/docs/new-relic-control/agent-control/agent-types/) foram expandidos com o campo `protocol_version`, uma referência para cada campo de variável e seções de implantação separadas para Kubernetes e on-host.
* Adicionados exemplos de configuração por agente para agentes APM do New Relic, o OpenTelemetry Collector, o agente de anexação automática eBPF e o agente de infraestrutura a [Modificar configuração do agente](/docs/new-relic-control/pipeline-control/gateway/modify-agent-configuration/), junto com uma matriz de compatibilidade de agentes e versões suportados.
* Atualizada a [visão geral](/docs/new-relic-control/pipeline-control/gateway/overview/) do gateway do Controle de Pipeline, o [guia da interface](/docs/new-relic-control/pipeline-control/gateway/ui-guide/) e a [referência de configuração YAML](/docs/new-relic-control/pipeline-control/gateway/yaml-overview/) para documentar a adição e exclusão de processadores Sample rate, Filter e Transform em qualquer estágio de um Pipeline.

### Novidades

* [O Session Replay agora tem sua própria categoria de faturamento](/whats-new/2026/09/whats-new-09-28-session-replay-billing-category): os dados do Session Replay de Browser e Mobile são reportados em novas categorias de faturamento, separados dos eventos de Browser e mobile.
* [Uma nova experiência de mapa de trace com cluster inteligente](/whats-new/2026/09/whats-new-09-28-trace-map-clustering): os mapas de trace agora mantêm serviços de alta importância visíveis e recolhem a cauda longa em clusters, para que gargalos e serviços com falha se destaquem.
* [Frotas baseadas em host do New Relic Control agora estão com disponibilidade geral](/whats-new/2026/09/whats-new-09-29-host-support-ga): frotas baseadas em host Linux e Windows para Controle de agentes e Controle de Agentes agora estão com disponibilidade geral, com suporte para governança de aprovação de configuração, atualizações remotas de agente, logging de auditoria e integrações no host.
* [Referencie o dashboard atual de qualquer lugar com `{{selfEntity}}`](/whats-new/2026/09/whats-new-09-29-selfentity-dashboard-variable): uma nova variável de template resolve para o GUID da entidade do dashboard atual, para que consultas, nomes de widget e links de faceta permaneçam precisos após você duplicar um dashboard.
* [A versão atualizada do Pathpoint já está disponível em visualização pública](/whats-new/2026/09/whats-new-09-30-pathpoint-2-0): mapeie suas jornadas de negócios mais críticas para a telemetria que as alimenta, agora com gerenciamento programático e KPIs mais ricos.
* [Coloque processadores de Pipeline onde precisar com o Controle de Pipeline](/whats-new/2026/09/whats-new-09-30-pipeline-control-processors): adicione, reordene e exclua processadores de Sample Rate, Filter e Transform em qualquer ponto de um Pipeline.
