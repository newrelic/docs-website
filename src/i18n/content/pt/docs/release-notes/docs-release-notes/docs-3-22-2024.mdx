<Callout variant="important">
  Estamos experimentando notas de versão para informar você sobre o que está mudando em nossa documentação a cada semana. Isto é um experimento, então [nos avise via issue do GitHub](https://github.com/newrelic/docs-website/issues/new/choose) se você os achar úteis!
</Callout>

### Grandes mudanças

* Revisamos e reescrevemos a documentação de integração no host para [RabbitMQ](/install/rabbitmq/), [JMX](/install/jmx/), [Apache Flink](/install/apache-flink/) e [HAProxy](/install/haproxy/) para facilitar a instalação e garantir que a documentação esteja precisa e atualizada.
* Para o [monitoramento Serverless do AWS Lambda](/docs/serverless-function-monitoring/aws-lambda-monitoring/get-started/compatibility-requirements-aws-lambda-monitoring/), atualizamos as informações sobre as versões de runtime suportadas, dependências e o SDK do pacote NuGet .NET obsoleto.
* Atualizamos nossos documentos de conformidade [FedRAMP](/docs/security/security-privacy/compliance/certificates-standards-regulations/fedramp/), [HIPAA](/docs/security/security-privacy/compliance/certificates-standards-regulations/hipaa/), [ISO-27001](/docs/security/security-privacy/compliance/certificates-standards-regulations/iso-27001/), [SOC2](/docs/security/security-privacy/compliance/certificates-standards-regulations/soc2/), [TISAX](/docs/security/security-privacy/compliance/certificates-standards-regulations/tisax/), [criptografia de dados](/docs/security/security-privacy/compliance/data-encryption/) e [HITRUST CSF](/docs/security/security-privacy/compliance/hitrust/) para refletir o status de conformidade da New Relic em 2024.
* Continuação da revisão e reorganização da nossa [documentação do NRQL](/docs/nrql/get-started/introduction-nrql-new-relics-query-language) para melhorar a legibilidade e a qualidade.
* Esclarecido que o [armazenamento offline do monitoramento de Mobile](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/configure-settings/#android-offline-storage) do Android está desativado por padrão e atualizado o documento de [configuração de armazenamento offline](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/set-max-offline-storage/#android).
* Adicionadas informações sobre as [configurações do monitoramento de Mobile do Unity](https://docs.newrelic.com/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/configure-settings/#unity).
* Adicionado endpoint de monitoramento sintético (Synthetics Monitoring) para o [AWS PrivateLink](/docs/data-apis/custom-data/aws-privatelink).
* Adicionada seção de resolução de problemas ao documento de [integração do Statsd](/docs/more-integrations/open-source-telemetry-integrations/statsd/statsd-monitoring-integration/#troubleshooting).
* Adicionada nova seção de opção de configuração do .NET para [instrumentação do elemento de regras](/docs/apm/agents/net-agent/configuration/net-agent-configuration/#instrumentation-rules) .
* Atualizados os [requisitos de versão de transição do gerenciador de trabalhos](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-transition-guide) do monitoramento sintético.

### Atualizações menores

* Adicionadas variáveis de ambiente do [Kubernetes `vsePassphrase`](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-configuration/#kubernetes-env-config) de monitoramento sintético.
* Corrigidos alguns links internos quebrados.
* Atualizada a seção de [status de erro do Errors Inbox](/docs/triage-inbox/errors-inbox) com uma nova imagem e mais detalhes sobre a interface.
* Atualizadas as versões do [módulo de runtime de monitoramento sintético](/docs/synthetics/synthetic-monitoring/using-monitors/manage-monitor-runtimes).
* Adicionadas informações sobre como usar [várias fontes de log com o plug-in do Fluent Bit](/docs/logs/forward-logs/fluent-bit-plugin-log-forwarding).
* Adicionado como [consultar logs do Live Archives por meio da API NerdGraph](/docs/logs/get-started/live-archives).
* Atualizamos e corrigimos vários problemas menores de estilo e imagem.
* Adicionado [exemplo de paginação de cursor](/docs/apis/nerdgraph/examples/nerdgraph-api-notifications-channels/#paginate) de inteligência aplicada do NerdGraph.
* Corrigida a configuração quebrada da [integração NVIDIA GPU](/docs/infrastructure/host-integrations/host-integrations-list/nvidia-gpu-integration).
* Adicionada uma seção sobre a configuração do [host de upload de mapeamento](/docs/mobile-monitoring/new-relic-mobile-android/install-configure/android-agent-crash-reporting) do monitoramento de Mobile Android.
* Adicionados detalhes de configuração para a [integração de monitoramento Temporal](/docs/infrastructure/host-integrations/host-integrations-list/temporal-monitoring-integration) para Java.
* Adicionada permissão ausente para o [GCP Cloud Functions](/docs/infrastructure/google-cloud-platform-integrations/get-started/integrations-custom-roles).
* Atualizado o link da documentação relacionado ao [relato de vulnerabilidades de segurança](/docs/security/security-privacy/information-security/security-bulletins/#report).
* Atualizado o documento de segurança para remover a menção ao HackerOne, que não usamos mais para nosso [processo de divulgação coordenada](/docs/security/security-privacy/information-security/software-development-lifecycle).
* Adicionadas informações sobre as implicações legais do uso de [métodos de proxy de monitoramento de Browser](/docs/browser/new-relic-browser/configuration/proxy-agent-requests).
* Esclarecido que o atributo [`coreCount`](https://docs.newrelic.com/attribute-dictionary/?event=SystemSample&attribute=coreCount) para o evento `SystemSample` no Windows conta o número de processadores para a instância atual do processador.
* Atualizada a documentação de [configuração de monitoramento de desempenho de rede](/docs/network-performance-monitoring/advanced/advanced-config) para descrever as alterações relacionadas à API do Meraki e aos syslogs de dispositivos de rede.
* Removida a data de EOL da [integração do Prometheus OpenMetrics no Kubernetes](/docs/infrastructure/prometheus-integrations/install-configure-prometheus-agent/migration-guide).
* Na navegação à esquerda, a instrumentação manual legada do Serverless foi renomeada para [instrumentação manual sem camada](/docs/serverless-function-monitoring/aws-lambda-monitoring/enable-lambda-monitoring/enable-serverless-monitoring-aws-lambda-layerless/).
* Diversas pequenas edições para clareza e melhor consistência com nosso guia de estilo.
