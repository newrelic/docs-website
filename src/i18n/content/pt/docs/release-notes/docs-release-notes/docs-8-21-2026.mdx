### Novos documentos

* Adicionado o [Monitoramento do MySQL via OpenTelemetry](/docs/opentelemetry/database/mysql/introduction) como uma integração em versão prévia pública, abrangendo a configuração guiada, a configuração hospedada e do Amazon RDS, configurações de múltiplos receptores e uma referência completa de métricas.
* Adicionado o [Monitoramento do PostgreSQL via OpenTelemetry](/docs/opentelemetry/database/postgresql/introduction) como uma integração de visualização pública, abrangendo a configuração guiada, a configuração hospedada e do Amazon RDS, as permissões `EXPLAIN` e uma referência completa de métricas.
* Adicionados os [Recursos de Localização Privada](/docs/synthetics/synthetic-monitoring/guides/private-location-capabilities) para consolidar os recursos de localização privada de monitoramento sintético, como certificados CA personalizados, mTLS e automação do Terraform.
* Adicionado [Limites de Usuário de Computar](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/compute-budgets/compute-user-limits), agora com disponibilidade geral, para definir orçamentos mensais de computar por usuário.
* Adicionado [Jornadas do Usuário Mobile](/docs/mobile-monitoring/mobile-monitoring-ui/mobile-app-pages/user-journeys) para mostrar a sequência de eventos que levam a uma falha, erro ou ANR.
* Adicionado o [Configurar o Receptor de Consulta SQL](/docs/opentelemetry/database/capabilities/sql-query-receiver) como um recurso em versão prévia pública para executar consultas SQL personalizadas em bancos de dados Oracle ou SQL Server e ingerir os resultados como métricas.

### Grandes mudanças

* Atualizadas as [Funções Personalizadas de Integrações do GCP](/docs/infrastructure/google-cloud-platform-integrations/get-started/integrations-custom-roles) com permissões para 18 serviços adicionais, incluindo AlloyDB, Bigtable, Firestore e Vertex AI.
* Atualizado o [monitoramento de banco de dados Oracle com NRDOT](/docs/opentelemetry/database/otel-oracledb) com suporte total ao Oracle Autonomous Database (ADB), incluindo instalação, concessões de privilégios e configuração de vários receptores.

### Pequenas mudanças

* Corrigido [Reportar eventos personalizados e atributos](/docs/data-apis/custom-data/custom-events/report-mobile-monitoring-custom-events-attributes) e [Definir o tamanho máximo do pool de eventos](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/set-max-event-pool-size) para informar que o ciclo de coleta de eventos móveis padrão é de 60 segundos, não 600.
* Esclarecido nos [Conceitos de Gerenciamento de Usuários](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts) que as funções personalizadas com escopo de organização não recebem automaticamente permissões para novos recursos com escopo de organização.
* Esclarecido em [Gerenciar vários registros de usuário](/docs/accounts/accounts-billing/account-setup/multiple-user-records) que a alternância entre registros de usuário com o mesmo e-mail usa a opção &quot;Outros usuários&quot; no menu do usuário.
* Foi esclarecido em [Variáveis de modelo de dashboard](/docs/query-your-data/explore-query-data/dashboards/dashboard-template-variables) que a alternância de incluir/excluir fica no próprio dropdown de cada variável, não na barra de variáveis compartilhadas.
* Esclarecido na [Integração de Monitoramento do Azure Cost Management](/docs/infrastructure/microsoft-azure-integrations/azure-integrations-list/azure-cost-management-monitoring-integration) que os dados de custo exigem manter a integração tradicional do Azure habilitada.
* Removida uma nota desatualizada em [Compartilhar cadernos](/docs/query-your-data/explore-query-data/notebooks/share-notebooks) afirmando que os cadernos não possuem configurações de permissão granular.
* Adicionada a cobertura do campo `onCallMembers` ao [tutorial do NerdGraph Teams](/docs/apis/nerdgraph/examples/nerdgraph-teams-tutorial).
* Adicionadas etapas em [Solucionar problemas de integrações do GCP](/docs/infrastructure/google-cloud-platform-integrations/troubleshooting/troubleshooting-gcp-integrations) para solicitar um aumento de cota da API de monitoramento de nuvem do GCP.
* Foi adicionada orientação para atribuir uma função de sobreaviso aos membros da equipe em [Gerenciar equipes](/docs/service-architecture-intelligence/teams/manage-teams).
* Adicionada uma seção sobre a configuração de [variáveis de ambiente do agente .NET](/docs/apm/agents/net-agent/other-installation/understanding-net-agent-environment-variables) para aplicativos hospedados no IIS via `ApplicationHost.config`.
* Reestruturado [A Instalação do Windows MSI Falha com o Erro 1603](/docs/infrastructure/infrastructure-troubleshooting/troubleshoot-infrastructure/windows-msi-install-fails-error-1603) para priorizar a falta dos parâmetros obrigatórios `GENERATE_CONFIG` e `LICENSE_KEY` como a causa mais comum.
* Atualizado o [instalador MSI do Windows](/docs/infrastructure/infrastructure-agent/windows-installation/windows-msi-installer) para que o comando de instalação silenciosa padrão inclua os parâmetros `GENERATE_CONFIG` e `LICENSE_KEY` necessários.
