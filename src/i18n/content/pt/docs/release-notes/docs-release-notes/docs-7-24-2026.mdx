## Novos documentos

* Adicionada a documentação do [Intelligent Exemplar](/docs/distributed-tracing/ui-data/intelligent-exemplar) para o recurso de pré-visualização pública para exibir traces anômalos de picos de latência ou erros sem a reconstrução manual de filtros.
* Adicionada a documentação de [Análise de Correlação de Atributos](/docs/distributed-tracing/ui-data/attribute-correlation-analysis) para o recurso de visualização pública para identificar automaticamente pares de atributo-valor que causam picos de latência ou erros.
* Adicionada a documentação de [Maturidade do Serviço](/docs/service-architecture-intelligence/scorecards/service-maturity) para níveis de maturidade de Scorecards e pontuação ponderada para acompanhar a progressão do serviço em direção à excelência operacional.
* Adicionada a documentação [Configurar o roteamento de várias contas para o agente eBPF da New Relic](/docs/ebpf/multi-account-routing) para rotear a telemetria do eBPF para diferentes contas da New Relic por namespace do Kubernetes.
* Adicionada a documentação da [Integração do Autopilot com o Slack](/docs/agentic-ai/autopilot/connect-to-slack) para conectar o Autopilot ao Slack para investigação de incidentes em threads.
* Adicionada a documentação de [Introdução aos Alertas Inteligentes](/docs/alerts/smart-alerts) para o recurso de visualização pública para monitorar a cobertura de alerta da entidade em relação aos padrões recomendados e criar condições em massa.
* Adicionada a documentação [Variáveis em notebooks](/docs/query-your-data/explore-query-data/notebooks/notebook-variables) para parametrizar notebooks com variáveis dinâmicas para runbooks de investigação repetíveis.
* Adicionada a documentação de [instrumentação do Puma](/docs/apm/agents/ruby-agent/instrumented-gems/puma-instrumentation) para a amostragem do agente Ruby de estatísticas do servidor Puma relatadas como métricas de timeslice.
* Adicionada a documentação de [monitoramento do MSSQL do Windows RDS com NRDOT](/docs/opentelemetry/database/mssql/windows-rds) para monitorar o SQL Server no AWS RDS usando o coletor NRDOT no Windows.

### Grandes mudanças

* Atualizada a documentação do Autopilot em [visão geral](/docs/agentic-ai/autopilot/overview), [configuração](/docs/agentic-ai/autopilot/setup), [uso do Autopilot](/docs/agentic-ai/autopilot/use-autopilot) e [memória](/docs/agentic-ai/autopilot/memories) com o lançamento em GA, renomeando de agente SRE para Autopilot, atualizando as informações de conformidade para refletir a disponibilidade da HIPAA.
* Atualizada a [documentação do agente eBPF](/docs/ebpf/k8s-installation) para a versão 1.5.0 com suporte expandido à versão do kernel (`v5.8` a `v7.1`), novas distribuições Linux suportadas (AlmaLinux 9.7+, Oracle Linux 8+, openSUSE Leap 15.5+, SLES 15.7+) e procedimentos de instalação do Kubernetes e do Linux atualizados.
* Atualizadas as [práticas recomendadas do eBPF](/docs/ebpf/best-practices) com uma nova seção de amostragem de dados e ajuste fino explicando como cada tipo de telemetria é amostrado para controle de volume de dados e custos.
* Atualizada a [alta disponibilidade (HA) do Prometheus](/docs/infrastructure/prometheus-integrations/install-configure/prometheus-high-availability-ha) com uma nova tabela de referência rápida para consolidar os três valores de desduplicação e um destaque de introdução atualizado.
* Atualizada a [configuração manual da integração da AWS para métrica](/docs/infrastructure/amazon-integrations/aws-integration-for-metrics/manual) restaurando a seção de configuração do Firehose para a configuração manual do CloudWatch Metric Streams da AWS.
* Atualizado [Gerenciar equipes](/docs/service-architecture-intelligence/teams/manage-teams) com uma nova seção de widgets de produtividade do Team Hub documentando os requisitos de dados para os widgets de frequência de implantação, tempo de lead de mudança, MTTR, tempo de ciclo de PR e pull requests abertos.

### Pequenas mudanças

* Atualizada a [compatibilidade e requisitos da integração com Kubernetes](/docs/kubernetes-pixie/kubernetes-integration/get-started/kubernetes-integration-compatibility-requirements) para adicionar o Kubernetes 1.35 ao intervalo de versões suportadas.
* Corrigidos os [Eventos Relatados pelo Monitoramento de Mobile](/docs/data-apis/understand-data/event-data/events-reported-mobile-monitoring) para corrigir o tempo limite da sessão de evento `Mobile` e `MobileSession` de 10 minutos para 1 minuto.
* Atualizado o [Monitoramento da execução do fluxo de trabalho](/docs/workflow-automation/manage-workflows/monitor-workflow-execution) para esclarecer que o nível de log `TRACE` agora está disponível e documentar seu comportamento para o atributo de saída da ação.
* Atualizada a [instrumentação do Next.js com o agente híbrido](/docs/apm/agents/nodejs-agent/extend-your-instrumentation/nextjs-instrumentation) para adicionar que a abordagem do agente híbrido atualmente suporta apenas o Next.js versão 16 e superior.
* Atualizada a [política de EOL do agente Ruby](/docs/apm/agents/ruby-agent/getting-started/ruby-agent-eol-policy) para adicionar o Ruby 10.x e sua versão mínima suportada (Ruby 2.6.0).
* Atualizado [Vários registros de usuário](/docs/accounts/accounts-billing/account-setup/multiple-user-records) para esclarecer que a remoção dos domínios de autenticação de uma organização é permanente e não pode ser desfeita.
* Atualizado [Locais de dados do Digital Operations Resilience Act (DORA)](/docs/security/security-privacy/compliance/certificates-standards-regulations/dora/dora-data-locations) com informações revisadas sobre o local de processamento.
* Corrigida a [Resolução de problemas do agente PHP para Fargate](/docs/apm/agents/php-agent/troubleshooting/fargate-nitro-clock-performance-impact) para corrigir um link quebrado.
* Atualizado [Equipes](/docs/service-architecture-intelligence/teams/teams) para esclarecer as descrições de permissão para a página de configurações de automações e hierarquias.
* Atualizado o [monitoramento do MSSQL hospedado no Windows com NRDOT](/docs/opentelemetry/database/mssql/windows-hosted) com valores padrão revisados para os parâmetros de configuração de coleta das principais consultas.
