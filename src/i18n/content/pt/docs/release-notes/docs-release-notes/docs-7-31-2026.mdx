## Novos documentos

* A documentação do [eBPF Logs Public Preview](/docs/ebpf/logs) já está disponível, incluindo uma referência de configuração e práticas recomendadas.
* A documentação de [Suporte a Certificados Personalizados](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-configuration/#custom-ca-certificates) já está disponível para configurar certificados de CA personalizados em localizações privadas.

### Grandes mudanças

* Atualizada a configuração de monitoramento do [Azure VNet Flow Logs](/docs/network-performance-monitoring/setup-performance-monitoring/cloud-flow-logs/azure-vnet-flow-log-monitoring) com suporte a vários planos (`FlexConsumption`, `ElasticPremium`, `Basic`, `Consumption`), endpoint do FedRAMP/US Gov Cloud e documentação de roteamento de saída em modo privado.
* Atualizados os [termos do Plano de Uso](/docs/licenses/license-information/usage-plans/new-relic-usage-plan) para incluir uma definição de &quot;Recursos de Avaliação&quot; e uma cláusula de período de avaliação gratuita temporária no Pay As You Go.

### Pequenas mudanças

* Atualizado o [Gerenciamento de Contas](/docs/accounts/accounts-billing/account-setup/downgradecancel-account) para incluir um artigo de referência sobre a visualização de relacionamentos entre contas.
* [Requisitos de compatibilidade do agente Java](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent) atualizados.
* Atualizada a documentação do [OpenTelemetry MSSQL](/docs/opentelemetry/database/mssql/introduction) com novos detalhes de configuração.
* Atualizada a referência de atributo da [API de eventos de Monitoramento de Alterações](/docs/change-tracking/change-tracking-events) dividindo as seções obrigatórias e opcionais para uma integração mais rápida.
* Corrigidos os [comandos de desinstalação do Agent Control](/docs/new-relic-solutions/new-relic-one/install-configure/uninstall-agent) para corrigir comandos incorretos.

### EOLs

* Página de documentação da **API REST v1 do Mobile Crash descontinuada**. A API v1 descontinuada foi substituída pela v2.
