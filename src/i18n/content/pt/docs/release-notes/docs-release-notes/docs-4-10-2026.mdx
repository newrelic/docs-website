### Notas de versão

* Fique por dentro dos nossos últimos lançamentos:

  * [Agente Java v9.2.0](/docs/release-notes/agent-release-notes/java-release-notes/java-agent-920):

    * Adicionado suporte ao Java 26 e modo de monitoramento Serverless do AWS Lambda.
    * Adicionada configuração `log_level_denylist` para encaminhamento de logs.
    * Adicionado suporte à nomenclatura automática de aplicativos para logs, amostradores de trace e métricas de suporte de entidade.
    * Adicionada instrumentação para OpenTelemetry 1.59.0+ e cliente HTTP Reactor Netty.
    * Corrigido NPE com carga de distributed tracing e vazamento de memória no cache `ThreadTracker`.

    * Adicionada instrumentação do Semantic Logger para encaminhamento de logs (versões 4.6.0+).
    * Adicionada a opção de configuração `ignored_middleware_classes`.
    * Adicionada API `NewRelic::Agent.add_transaction_log_attributes`.
    * Corrigidos problemas de cardinalidade de métricas de broadcast do ActionCable e de conformidade com FIPS/FedRAMP.
