### Novos documentos

* Adicionados os [Eventos de Monitoramento de Alterações](/docs/change-tracking/change-tracking-events/) para rastrear alterações em seus aplicativos e infraestrutura usando o recurso de Monitoramento de Alterações da New Relic. Capture, visualize e analise as alterações para entender o impacto delas em seus sistemas.
* Adicionado o [procedimento](/docs/infrastructure/prometheus-integrations/migrations/v2-upgrade/) para atualizar o agente do Prometheus para a versão 2.
* Adicionado um [documento](/docs/query-your-data/explore-query-data/dashboards/nested-variables/) que explica o que são variáveis aninhadas e como usá-las no dashboard.

### Grandes mudanças

* Adicionado o guia de resolução de problemas [Aplicativo trava na inicialização](/docs/apm/agents/net-agent/troubleshooting/app-hangs-on-startup/) para o agente .NET.

* Adicionados exemplos de [Executar integração no host manualmente (execução de teste)](/docs/infrastructure/host-integrations/troubleshooting/run-integrations-manually/) sobre o Windows - Microsoft SQL Server (a partir de um PowerShell de administrador).

* Adicionada a [API Measure para a API do Browser](/docs/browser/new-relic-browser/browser-apis/measure/).

* Adicionado o [modelo de arquivo de configuração do agente Java](/docs/apm/agents/java-agent/configuration/java-agent-config-file-template/) para a versão 8.21.0 do agente Java.

* Atualizados os tipos de usuário necessários para compartilhar dashboard e gráficos no [documento de segurança e acesso](/docs/query-your-data/explore-query-data/dashboards/prerequisites-to-share-dashboards-charts/).

* As integrações do agente do New Relic AI para o Github Copilot e o Gemini agora estão em disponibilidade geral. Documentos atualizados da seguinte forma:

  * [Integração do agente do New Relic AI com o GitHub Copilot](/docs/agentic-ai/agentic-integration/github-copilot-integration/)
  * [Integração do agente New Relic AI com o Gemini](/docs/agentic-ai/agentic-integration/gemini-integration/)

* O documento [Visualizar o Session Replay no New Relic](/docs/browser/browser-monitoring/browser-pro-features/session-replay/view-session-replays/) foi atualizado para refletir as alterações na configuração no lado do servidor para as configurações do Session Replay na versão 1.259.0+ do agente do browser.

* Foram adicionadas informações aos documentos [Privacidade de dados com o New Relic](https://docs.newrelic.com/docs/security/security-privacy/data-privacy/data-privacy-new-relic/#account-security) e [Política de segurança](/docs/licenses/license-information/referenced-policies/security-policy/) sobre auditorias periódicas e desativação de contas para funcionários desligados.

* Adicionada a configuração atualizada ao documento que explica como [instalar o agente de mídia de vídeo para o aplicativo de Browser](/install/browser-media/).
