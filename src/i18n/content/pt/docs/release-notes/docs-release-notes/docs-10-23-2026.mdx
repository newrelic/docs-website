### Novos documentos

* Adicionamos o artigo [Instrumentação do Kotlin não relatando](/docs/apm/agents/java-agent/troubleshooting/kotlin-instrumentation-not-reporting/) para ajudar você a corrigir a instrumentação ausente do Kotlin atualizando para o agente Java 8.20 ou superior e definindo a propriedade de sistema `clear_return_stacks`.
* Adicionamos o [Guia de migração](/docs/new-relic-control/agent-control/migration-guide/) para o Controle de agentes, abrangendo a lacuna de monitoramento, o mapeamento de configuração, a continuidade da entidade e as etapas de reversão quando você passa de um agente de infraestrutura autônomo para o Controle de agentes.
* Adicionamos os [Limites de computar do Autopilot](/docs/agentic-ai/autopilot/autopilot-compute-limits/) para mostrar a você como definir orçamentos diários e mensais de CCU Advanced, isolar a triagem automatizada de alertas do uso interativo e acompanhar o consumo com NRQL.
* Adicionamos as [ações do AWS SES](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/ses/aws-ses/) ao catálogo de ações de automação de fluxo de trabalho, abrangendo o gerenciamento de modelos de e-mail e o envio de e-mails pelo Amazon SES.
* Adicionado [Introdução à observabilidade do coletor](/docs/opentelemetry/collector-observability/collector-observability-setup/), um guia de configuração que abrange notas de faturamento e configuração passo a passo para habilitar a observabilidade do coletor.
* Adicionada a [referência de KPI do OpenTelemetry Collector](/docs/opentelemetry/collector-observability/collector-observability-kpis/) para explicar cada bloco de KPI de observabilidade do coletor e seus gráficos de telemetria relacionados.
* Adicionado um novo guia de resolução de problemas para .NET para verificar quando [Nenhum dado aparece: aplicativo .NET framework não usando TLS 1.2](/docs/apm/agents/net-agent/troubleshooting/no-data-appears-net-framework-tls-12/).

### Grandes mudanças

* Atualizado [Remover aplicativos do New Relic](/docs/apm/new-relic-apm/maintenance/remove-applications-new-relic/) com uma nova mutação `agentApplicationDelete` do NerdGraph que permite forçar a exclusão permanente de um aplicativo, mesmo enquanto ele ainda estiver relatando dados.
* Atualizada a [integração de monitoramento do Kafka](/docs/infrastructure/host-integrations/host-integrations-list/kafka/kafka-integration/) com métricas em todo o cluster (`KafkaClusterSample`) e novas métricas estendidas e opções de configuração de broker, tópico e offset do consumidor.
* A [interface entre clusters do Kubernetes](/docs/kubernetes-pixie/kubernetes-integration/understand-use-data/kubernetes-cross-cluster/) foi atualizada para incluir seções de scorecard, tabela e drill-down.
* Atualizamos o [Instalar o gerenciador de trabalhos de Sintéticos](/docs/synthetics/synthetic-monitoring/private-locations/install-job-manager/) com uma tabela de configuração do Podman sem root, uma etapa de ativação de persistência para que os serviços systemd das contas de serviço continuem em execução sem uma sessão de login ativa e `--shm-size=2g` no comando de criação de pod para evitar que os monitores de navegador travem devido a limites de memória compartilhada.
* Atualizado [Chaves de API do New Relic](/docs/apis/intro-apis/new-relic-api-keys/) com uma nova seção “Auditar e gerenciar suas chaves de API” que abrange recursos e permissões, simplificou as etapas de substituição de chaves e corrigiu uma descrição invertida do campo `enabled` (`enabled: false` desativa uma chave e `enabled: true` a reativa).
* Atualizado o [Tutorial do NerdGraph: gerenciar chaves de API](/docs/apis/nerdgraph/examples/use-nerdgraph-manage-license-keys-user-keys/) com os novos campos `owningTeamIds`, `enabled` e `keyUsage` (último uso) para criar, atualizar e consultar chaves de API por meio do NerdGraph.
* O artigo [Solucionar problemas de localizações privadas](/docs/synthetics/synthetic-monitoring/private-locations/troubleshoot-private-locations/) foi atualizado com uma nova seção que explica por que os monitores de navegador falham devido aos limites de memória compartilhada no nível do pod do Podman, com comandos de diagnóstico e uma correção.
* Atualizado o [monitoramento do OpenTelemetry Collector](/docs/opentelemetry/collector-observability/collector-observability/) com novos modos de visualização de coletor autônomo vs. anexado.
* Atualizado [Compatibilidade e requisitos do agente PHP](/docs/apm/agents/php-agent/getting-started/php-agent-compatibility-requirements/) para remover as entradas do Joomla, Drupal 7/9 e Laravel 11 em fim de vida útil (EOL).
* Atualizamos a versão mínima compatível do iOS de 16 para 15 em [Monitore seu aplicativo .NET MAUI](/docs/mobile-monitoring/new-relic-mobile-maui-dotnet/monitor-your-net-maui-application/).
* [Compatibilidade e requisitos do agente Node.js](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent/) atualizados com as versões mais recentes de pacotes de terceiros compatíveis.

### Pequenas mudanças

* Atualizado o [suporte do agente PHP para Guzzle](/docs/apm/agents/php-agent/frameworks-libraries/guzzle/) para listar as versões compatíveis 7–8 e remover as versões 5–6 em fim de vida útil (EOL).
* O nome da pasta do XCFramework para iOS foi atualizado para `NewRelic.xcframework` em [Monitorar seu aplicativo Unity](/docs/mobile-monitoring/new-relic-mobile-unity/monitor-your-unity-application/).
* Atualizado o nome da variável `distributed_tracing.sampler.remote_parent_not_sampled.trace_id_ratio_based.ratio` na [configuração do agente Python](/docs/apm/agents/python-agent/configuration/python-agent-configuration/).
* O [guia de instalação do PostgreSQL](/install/postgresql/) foi atualizado para explicar que `nri-postgresql` precisa de `USAGE` concedido em `information_schema` em ambientes do PostgreSQL com segurança reforçada ou gerenciados que revogam os privilégios padrão de `PUBLIC`.
* Atualizadas as etapas de criação de partição em [Armazenamento de logs de longo prazo com Live Archives](/docs/logs/get-started/live-archives/) para atualizar a opção de dropdown &quot;Enviar para Live Archives&quot;.
* [Configurar integrações de monitoramento do Azure](/docs/infrastructure/microsoft-azure-integrations/get-started/activate-azure-integrations/) atualizado para explicar que a função Leitor de Monitoramento permite que a New Relic consulte recursos usando a API de lote de métricas do Azure Monitor em vez de consultar cada recurso individualmente.
* As [integrações de notificação de alertas](/docs/alerts/get-notified/notification-integrations/) foram atualizadas para explicar que a New Relic oferece suporte apenas ao aplicativo ServiceNow pronto para uso, e não a personalizações dele.
* Atualizados os comandos de criação de pod do Podman em [Instalar Sintéticos para dual stack usando Podman](/docs/synthetics/synthetic-monitoring/private-locations/install-synthetics-dual-stack-podman/) e no [Guia de transição de runtime de localizações privadas de Sintéticos](/docs/synthetics/synthetic-monitoring/private-locations/runtime-transition-guide/).
