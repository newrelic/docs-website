<Callout variant="important">
  Estamos experimentando notas de versão para informar você sobre o que está mudando em nossa documentação a cada semana. Isto é um experimento, então [nos avise via issue do GitHub](https://github.com/newrelic/docs-website/issues/new/choose) se você os achar úteis!
</Callout>

### Novos documentos

* Guia sobre como usar o [coletor do OpenTelemetry para monitorar as métricas do SingleStore](/docs/more-integrations/open-source-telemetry-integrations/opentelemetry/collector/collector-configuration-examples/opentelemetry-collector-singlestore).

### Grandes mudanças

* Os documentos do gerenciador de trabalhos de monitoramento sintético agora descrevem como configurar [variáveis definidas pelo usuário para monitores com script](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-configuration) e qual [versão do gerenciador de trabalhos](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-transition-guide) oferece suporte a isso.
* Reescrita contínua da documentação de integração no host para facilitar a instalação e garantir que a documentação esteja precisa e atualizada. Nesta semana: [Sonarqube](/docs/infrastructure/host-integrations/host-integrations-list/sonarqube-monitoring-integration) e [serviços do Windows](/docs/infrastructure/host-integrations/host-integrations-list/windows-services-integration).
* O rastreamento multiaplicativo foi descontinuado e não será suportado em versões futuras do agente APM. Atualizamos a documentação para refletir isso.
* Removemos a documentação relacionada às métricas cumulativas do OpenTelemetry, que foram descontinuadas em 2023.

### Pequenas mudanças

* Links atualizados da documentação da API relacionados à [personalização do AI Monitoring](/docs/ai-monitoring/customize-agent-ai-monitoring) do Node.js.
* Esclarecemos quais [recursos do Data Plus](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/data-ingest-billing/#data-prices) se aplicam às contas Standard, Pro e Enterprise.
* Esclarecemos que, ao [atualizar o agente APM Java](/docs/apm/agents/java-agent/installation/update-java-agent) e usar uma de nossas [APIs do agente Java](/docs/apm/agents/java-agent/api-guides/guide-using-java-agent-api), você também precisa atualizar as dependências da API.
* Atualizamos o suporte à versão do agente APM Python para 9.8.0 (de 9.9.0) para monitorar [bibliotecas e frameworks de IA](/docs/apm/agents/python-agent/getting-started/compatibility-requirements-python-agent/#digital-intelligence-platform).
* Link atualizado para o ServiceNow nas instruções de [notificação de destino](/docs/alerts-applied-intelligence/notifications/notification-integrations).
* Nosso agente de infraestrutura agora coleta todas as [métricas de contêiner de nó do EC2 a partir da API do Docker](/docs/infrastructure/install-infrastructure-agent/linux-installation/container-instrumentation-infrastructure-monitoring) com o Cgroup versão V2 ao monitorar um serviço de contêiner da Elastic.
* Informações atualizadas sobre como [encontrar dados `singlestore` do OpenTelemetry](/docs/more-integrations/open-source-telemetry-integrations/opentelemetry/collector/collector-configuration-examples/opentelemetry-collector-singlestore/#view-data) na interface.
* Documentos do CodeStream atualizados relacionados à [pesquisa de logs](/docs/codestream/observability/log-search) e ao [monitoramento de desempenho](/docs/codestream/observability/performance-monitoring).
* Adicionamos um link para os [atributos de usuário do agente Java](/docs/triage-inbox/error-users-impacted) suportados pelo Errors Inbox.
* Quando as [condições do alerta NRQL](/docs/alerts-applied-intelligence/new-relic-alerts/alert-conditions/queries-nrql_screenshot-full_nrql-alert-conditions/#condition-tips) agregam dados a serem avaliados, elas agora podem avaliar dados em incrementos de tempo de 30 segundos até seis horas.
