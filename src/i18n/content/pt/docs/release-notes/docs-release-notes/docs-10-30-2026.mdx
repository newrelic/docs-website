### Novos documentos

* Adicionado o [monitoramento da infraestrutura de nuvem Oracle (OCI)](/docs/infrastructure/oci/introduction/) para fornecer uma visão geral do monitoramento de métricas e logs da OCI com o New Relic.
* Adicionada a [Infraestrutura 360](/docs/infrastructure/infrastructure-360/introduction-infrastructure-360/) para ajudar você a descobrir automaticamente sua infraestrutura de nuvem, mapear relacionamentos entre recursos e rastrear alterações de configuração, abrangendo a configuração para AWS e Azure, entidades e requisitos compatíveis e a resolução de problemas.
* Adicionadas [macros NRQL](/docs/nrql/nrql-macros/nrql-macros-overview/) para mostrar a você como salvar uma expressão NRQL como um atalho nomeado e reutilizável e referenciá-la em consultas com o símbolo `$`.
* Adicionado [Monitorar implantação com o New Relic Monitoramento de Alterações para o GitHub Copilot](/docs/agentic-ai/autopilot/change-tracking-for-github-copilot/) para mostrar a você como monitorar cada implantação e receber relatórios de regressões no Slack e no GitHub.
* Adicionado [Simbolizar erros do Flutter Dart](/docs/mobile-monitoring/new-relic-mobile-flutter/symbolicate-dart-errors/) e [Simbolizar erros do .NET MAUI C#](/docs/mobile-monitoring/new-relic-mobile-maui-dotnet/symbolicate-csharp-errors/) para explicar como gerar arquivos de símbolo, simbolizar stack trace e armazenar símbolos para cada versão.
* Adicionado [LaunchDarkly com o agente Python](/docs/apm/agents/python-agent/supported-features/launchdarkly-release-observability/) para mostrar como observar como os sinalizadores de recurso e as versões afetam seu aplicativo ao conectar os dados do LaunchDarkly ao agente Python.
* Adicionadas ações ao [catálogo de ações de automação de fluxo de trabalho](/docs/workflow-automation/setup-and-configure/actions-catalog/actions-catalog/) para [AWS Athena](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/athena/aws-athena/), [AWS DynamoDB](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/dynamodb/aws-dynamodb/), [Azure App Service](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-appservice/), [execuções de fluxo de trabalho do GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run/), [segredos do New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/secret/newrelic-secret/) e [New Relic Synthetics](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/synthetics/newrelic-synthetics/), e adicionada uma ação [Aguardar status de notificação](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/notification/newrelic-notification-waitforstatus/).
* Adicionado o [Boletim de segurança NR26-11](/docs/security/new-relic-security/security-bulletins/security-bulletin-nr26-11/) com procedimentos para tratar vulnerabilidades críticas do Node.js, incluindo a execução remota de código (CVE-2026-111497), que afetam as localizações públicas e privadas do monitoramento sintético.

### Grandes mudanças

* Atualizamos a [referência da ferramenta MCP](/docs/agentic-ai/mcp/tool-reference/) com uma seção de análise de lacunas para a ferramenta `analyze_github_newrelic_gaps`, que verifica seu projeto em busca de instrumentação do New Relic ausente.
* Atualizado [Use Autopilot with GitHub](/docs/agentic-ai/autopilot/use-autopilot-with-github/) com uma nova seção sobre como o Autopilot sinaliza hotfixes abertos e pull request abertos durante uma janela de incidente, e como ele reconcilia as versões de lançamento.
* Atualizado [Configurar a propriedade da entidade](/docs/service-architecture-intelligence/teams/team-ownership/) para a inteligência de arquitetura de serviço com a lista de tipos de entidade, por domínio e tipo, que a New Relic atribui às equipes automaticamente por meio da propriedade baseada em tag.
* Atualizado o [Tráfego de rede](/docs/new-relic-solutions/get-started/networks/) com o domínio de registro do Docker Hub que o Controle de agentes no host usa para baixar pacotes do agente de um registro OCI, e alterado o domínio do coletor listado para `collector.newrelic.com`.
* Atualizamos [Programar pesquisas NRQL](/docs/nrql/using-nrql/schedule-nrql-searches/) com os recursos de leitura e modificação de destinos de inteligência aplicada que você precisa para selecionar ou criar um destino de e-mail.
* As páginas de referência da [API de Workflow Automation](/docs/workflow-automation/workflow-automation-apis/using-workflow-automation-api/) para fluxo de trabalho e agendamentos foram atualizadas com descrições consistentes, tabelas de parâmetros e âncoras de seção.
* Atualizado [Encaminhar seus logs usando o agente de infraestrutura](/docs/logs/forward-logs/forward-your-logs-using-infrastructure-agent/) com o parâmetro `multilineParser`, disponível no agente de infraestrutura v1.53.0 ou superior, para combinar entradas de várias linhas, como stack trace do Java, em um único registro de log.
* A [compatibilidade e os requisitos do agente .NET](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements/) foram atualizados para listar as versões do Windows atualmente compatíveis, incluindo o Windows Server 2025 e o Windows Azure Guest OS Family 5 e superior.
* [Compatibilidade e requisitos do agente Node.js](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent/) atualizados com as versões mais recentes de pacotes de terceiros compatíveis.

### Pequenas mudanças

* Atualizada a orientação de alerta da [integração do Azure Monitor](/docs/infrastructure/microsoft-azure-integrations/azure-integrations-list/azure-monitor/) para usar o método de streaming de temporizador de evento em vez de um deslocamento de avaliação.
* Atualizamos os [Atributos de evento de alerta](/docs/alerts/create-alert/condition-details/alert-event-attributes/) para explicar que o deslocamento de avaliação foi descontinuado em favor da configuração de Atraso/temporizador.
* A [configuração da integração do Kafka](/docs/infrastructure/host-integrations/host-integrations-list/kafka/kafka-config/) foi atualizada para explicar que a alteração de `CLUSTER_NAME` cria novas entidades de broker e de tópico, e que os aplicativos APM permanecem vinculados aos tópicos antigos por cerca de um dia.
* Atualizado [Instrumentar sua própria função do Lambda](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/instrument-your-own/) para adicionar a variável `NEW_RELIC_APP_NAME` necessária à configuração de exemplo.
* Atualizadas as [variáveis de ambiente da extensão do Lambda](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/env-variables-lambda/) com a configuração de orçamento de repetição do modo serverless e a variável `NEW_RELIC_EXTENSION_SYNCHRONOUS_FLUSH`.
* Atualizadas as [Abordagens do agente Java para Lambda](/docs/apm/agents/java-agent/getting-started/java-agent-approaches-lambda/) para listar as variáveis de ambiente que você deve definir.
* O documento [Connect Autopilot to Slack](/docs/agentic-ai/autopilot/connect-to-slack/) foi atualizado para explicar que o Autopilot aceita mensagens de até 1.000 caracteres.
* Atualizamos [Monitorar seu aplicativo Flutter](/docs/mobile-monitoring/new-relic-mobile-flutter/monitor-your-flutter-application/) e [Monitorar seu aplicativo .NET MAUI](/docs/mobile-monitoring/new-relic-mobile-maui-dotnet/monitor-your-net-maui-application/) para explicar que a simbolização no navegador se aplica apenas a exceções tratadas.
* Atualizamos as [Chaves de API do New Relic](/docs/apis/intro-apis/new-relic-api-keys/) para renomear “Default account key” para “Original account key”.
* Atualizamos os documentos de [instalação da observabilidade do eBPF](/docs/ebpf/linux-installation/) e de [preços e faturamento](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/new-relic-one-pricing-billing/) para renomear “eAPM” para “observabilidade do eBPF”.
* Atualizado o [relatório de erros de JavaScript do React Native](/docs/mobile-monitoring/new-relic-monitoring-react-native/react-native-agent-js-error-reporting/) para direcionar você ao Suporte da New Relic para solicitar um limite maior de tamanho do mapa de origem.
