### Novos documentos

* Adicionado [Migrar o agente iOS do CocoaPods](/docs/mobile-monitoring/new-relic-mobile-ios/installation/migrate-from-cocoapods) para que as equipes de iOS que usam o CocoaPods possam fazer a transição para o gerenciador de pacote Swift sem perder a instrumentação ou ter que reconfigurar do zero.
* Adicionado [Atualize sua integração de encaminhamento de logs do OCI](/docs/logs/forward-logs/oci-log-forwarder-upgrade) para que os usuários que executam configurações mais antigas do encaminhador de logs do OCI tenham um caminho de atualização claro para acessar os recursos atuais e as correções de segurança.
* Adicionado o [monitoramento do Microsoft SQL Server com NRDOT](/docs/opentelemetry/db360/mssql/introduction), abrangendo a instância gerenciada do Azure e o banco de dados SQL do Azure tanto no Linux quanto no Windows, para que as equipes possam configurar a observabilidade completa do banco de dados sem depender de configuração personalizada.

### Grandes mudanças

* Reestruturada a [configuração do agente Node.js](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration) em páginas específicas por tópico para configurações gerais, atributos, logging, rastreamento, coleta de erros, monitoramento de Browser e AI Monitoring, para que os usuários possam navegar diretamente para as configurações de que precisam em vez de pesquisar em uma única página longa.
* O documento [Limites de usuário de computar](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/compute-budgets/compute-user-limits) foi atualizado para abranger orçamentos de CCU avançado juntamente com o CCU principal, com políticas de imposição e configurações de notificação separadas para cada medidor, para que os administradores possam controlar os custos de computar avançado independentemente do computar principal.
* Atualizamos a [documentação do agente Ruby](/docs/apm/agents/ruby-agent/getting-started/introduction-new-relic-ruby) nos guias de API, atributos, tarefas em segundo plano, configuração e páginas de distributed tracing para alinhá-la com a atual API do agente, para que os usuários que seguem os exemplos existentes não encontrem métodos descontinuados ou nomes de opções obsoletos.

### Pequenas mudanças

* Adicionada a documentação do tipo de gráfico treemap em [Tipos de gráfico](/docs/query-your-data/explore-query-data/use-charts/chart-types) para que os usuários saibam quando os treemaps são a visualização ideal e como eles diferem de outros tipos de gráfico agora que esse tipo de gráfico é compatível.
* Atualizamos a [compatibilidade do agente .NET e requisitos](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements) para confirmar o suporte ao .NET 11 GA, para que os usuários possam atualizar seu runtime com confiança sabendo que o agente foi verificado.
* Atualizada a [Referência de ferramentas MCP](/docs/agentic-ai/mcp/tool-reference) para agrupar as ferramentas em tags relacionadas, tornando mais fácil encontrar a ferramenta certa para um caso de uso específico sem examinar a lista completa.
* Atualizamos o [agente Node.js no Microsoft Azure App Services](/docs/apm/agents/nodejs-agent/hosting-services/nodejs-agent-microsoft-azure) com orientações mais claras de hospedagem no Azure para reduzir a tentativa e erro que o usuário encontrava ao implantar no Azure App Services.
* Atualizamos o [Google Memorystore for Valkey](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-memorystore-valkey) com nomes de métrica corrigidos para que a consulta de dashboard e a condição do alerta direcionadas à métrica do Valkey retornem dados em vez de resultados vazios.
* Atualizado o [FedRAMP](/docs/security/security-privacy/compliance/certificates-standards-regulations/fedramp) com os detalhes atuais da certificação para que os clientes que avaliam os serviços autorizados pelo FedRAMP tenham informações precisas de conformidade.
* O documento [Conceitos importantes de gerenciamento de usuários e acesso](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts) foi atualizado para identificar corretamente o perfil do usuário de Faturamento como tendo escopo de conta e adicionar Faturamento aos recursos do gerenciador da organização, evitando configurações incorretas ao definir o acesso.
* Atualizamos a seção [Modificar configuração do agente](/docs/new-relic-control/pipeline-control/gateway/modify-agent-configuration) com diretrizes ampliadas de configuração do Gateway do Controle de Pipeline para abranger etapas que estavam faltando anteriormente.
* Atualizado [Monitore o Kafka autogerenciado no Kubernetes com OpenTelemetry](/docs/opentelemetry/integrations/kafka/kubernetes-self-managed) para remover `kafka.partition.replicas.total` das configurações do coletor, já que essa métrica não é coletada pelo receptor e sua presença fazia com que os usuários esperassem dados que nunca chegavam.
* Atualizado o [Gerenciar fluxos de trabalho](/docs/workflow-automation/manage-workflows/managing-workflow) com suporte a histórico de versões no editor de fluxo de trabalho para que os usuários possam revisar, comparar e reverter versões anteriores de seus fluxos de trabalho.
* Atualizado [Limites de fluxo de trabalho](/docs/workflow-automation/limitations-and-faq/workflow-limits) para refletir o aumento do limite de entrada do fluxo de trabalho de 1.000 para 3.000 caracteres, acomodando configurações mais realistas de fluxo de trabalho.
* Atualizamos as [Regras e limites de alertas](/docs/alerts/admin/rules-limits-alerts/) para esclarecer o limite de facetas para a condição do alerta NRQL que usa agregação aninhada, para que o usuário que cria condição do alerta complexa conheça a restrição aplicável.
* Atualizadas as [Medições de VM do Node.js](/docs/apm/agents/nodejs-agent/extend-your-instrumentation/nodejs-vm-measurements) para remover o conteúdo com referência ao pacote `@newrelic/native-metrics` obsoleto, que foi substituído por uma implementação em JS puro na v14.11.0.

### Novidades

* [Limites de usuário de computar agora abrangem o computar avançado](/whats-new/2026/11/whats-new-11-03-compute-user-limits-accu): defina orçamentos independentes de CCU principal e CCU avançado por usuário e imponha limites para cada medidor separadamente.
* [Monitoramento de Alterações para o GitHub Copilot](/whats-new/2026/11/whats-new-11-09-change-tracking-github-copilot): vincule as implantações aos pull requests e acione fluxos de trabalho automatizados de correção do GitHub Copilot quando ocorrerem regressões.
* [Detectar instrumentação ausente do New Relic com a ferramenta Gap Analysis MCP](/whats-new/2026/11/whats-new-11-09-gap-analysis-mcp-tool): verifica arquivos de repositório local para identificar lacunas em agente APM, agente Browser, arquivos de configuração e fluxo de trabalho de Monitoramento de Alterações de CI/CD.
