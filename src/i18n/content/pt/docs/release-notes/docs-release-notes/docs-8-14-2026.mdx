### Novos documentos

* Adicionado como [conectar](/docs/agentic-ai/autopilot/connect-to-github), [usar](/docs/agentic-ai/autopilot/use-autopilot-with-github) e [resolver problemas](/docs/agentic-ai/autopilot/troubleshoot-github-connection) da nova integração do Autopilot com o GitHub, um recurso de visualização pública que recupera o pull request por trás de uma implantação do Monitoramento de Alterações durante as investigações.
* Adicionadas [ações de problema do Jira](/docs/workflow-automation/setup-and-configure/actions-catalog/jira/jira-issue) ao catálogo de ações de automação de fluxo de trabalho, abrangendo ações de criação, atualização, pesquisa e transição para problemas do Jira Cloud.
* Adicionadas [ações de trabalho do Ansible](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job-launch) ao catálogo de ações de automação de fluxo de trabalho para iniciar e verificar o status dos modelos de trabalho do Ansible Automation Platform.
* Adicionada a [ação Executar Autopilot](/docs/workflow-automation/setup-and-configure/actions-catalog/autopilot/newrelic-autopilot) para fornecer uma referência dedicada no catálogo de ações para executar investigações do Autopilot a partir de um fluxo de trabalho.
* Adicionado o [RCA de Alerta com Autopilot e Slack](/docs/workflow-automation/workflow-examples/integrations/autopilot-slack-rca) para mostrar como acionar uma análise de causa raiz do Autopilot a partir de um alerta e publicar os resultados no Slack.
* Adicionada a [Economia de unidade](/docs/cci/financial-intelligence/unit-economics) à Inteligência de Custos na Nuvem para explicar como medir o custo de entrega de uma única unidade de valor, como o custo por consulta, e acompanhar a eficiência em relação a um benchmark.
* Adicionado [Usar destinos entre contas na interface](/docs/apis/nerdgraph/examples/cross-account-destinations/use-cross-account-destinations-in-the-ui) para mostrar onde os destinos entre contas aparecem na interface da New Relic e como usá-los em fluxos de trabalho.

### Grandes mudanças

* Atualizadas as [configurações do agente de infraestrutura](/docs/infrastructure/infrastructure-agent/configuration/infrastructure-agent-configuration-settings) com as novas configurações `safe_bin_dir`, `agent_temp_dir` e de diretório de logging.
* Atualizada a [configuração do agente .NET](/docs/apm/agents/net-agent/configuration/net-agent-configuration) com a nova opção `sqlMetadataCommentsEnabled`, que permite ao agente adicionar um comentário de GUID de entidade de serviço a instruções SQL instrumentadas para correlacionar dados do APM com o monitoramento de desempenho de consulta.
* Reestruturada a [Introdução aos notebooks](/docs/query-your-data/explore-query-data/notebooks/introduction-notebooks) para remover o aviso de visualização pública e descrever o novo modelo de acesso refinado, incluindo funções no nível da organização (acesso total, Criador) e funções no nível do notebook (Proprietário, Editor, Leitor).
* Atualizamos [Inteligência de Custos na Nuvem: Recomendações](/docs/cci/financial-intelligence/cci-recommendations) para estender as recomendações de dimensionamento correto do mecanismo de otimização nativo para recursos do Azure e adicionamos orientações sobre os pré-requisitos de cobertura de telemetria e a cadência de atualização das recomendações.
* Adicionada uma nova seção simplificada de gráfico de barras para classificar séries em relação à maior, e uma opção de limite Neutro para gráficos de medidor, em [Tipos de gráficos](/docs/query-your-data/explore-query-data/use-charts/chart-types).
* Atualizada a [configuração de status de saúde do workload](/docs/new-relic-solutions/new-relic-one/workloads/workload-status-configuration) com orientações sobre os efeitos da troca de métodos de configuração, incluindo atraso no status de saúde e desvinculação e revinculação automáticas de condições do alerta.

### Pequenas mudanças

* Adicionado um aviso de limitação de suporte ao Windows no [guia de instalação da integração do MongoDB](/install/mongodb/), observando que a Percona congelou o exportador empacotado em sua versão atual porque parou de publicar binários do Windows.
* Atualizado [Problemas de carregamento de classes do JBoss e WildFly](/docs/apm/agents/java-agent/troubleshooting/classloading-issues-from-jboss-and-wildfly) com uma nova seção de resolução de problemas para falhas de inicialização causadas pelo gerenciador de logs do JBoss.
* Atualizado [Redes](/docs/new-relic-solutions/get-started/networks) com blocos de IP de ingestão de dados dualstack adicionais para os data centers dos EUA e da UE.
* Atualizada a [instrumentação de terceiros](/docs/apm/agents/ruby-agent/api-guides/third-party-instrumentation) para o agente Ruby para esclarecer como contribuir com a instrumentação de novas gems e observar que `extends_newrelic_rpm` agora está arquivado.
* Atualizado o [FedRAMP](/docs/security/security-privacy/compliance/certificates-standards-regulations/fedramp) para refletir o novo status de certificação FedRAMP Classe C (Moderado).
* Atualizada a [Criptografia de Dados](/docs/security/security-privacy/compliance/data-encryption) para refletir a mudança dos padrões de criptografia compatíveis com FIPS 140-2 para FIPS 140-3.
* Atualizado o [Iniciar uma execução de fluxo de trabalho](/docs/workflow-automation/workflow-automation-apis/start-workflow-run) com uma nova entrada `idempotencyKey`, e esclarecida a validação de formato UUID para `idempotencyKey` nas ações de notificação do Azure e da New Relic no [catálogo de ações](/docs/workflow-automation/setup-and-configure/actions-catalog/actions-catalog).
* Atualizamos a [Segurança do Agente de Infraestrutura](/docs/infrastructure/infrastructure-agent/infrastructure-security) para documentar os requisitos da conta de serviço do Windows, incluindo o suporte a Group Managed Service Account (gMSA).
* Atualizado o [Escolha seu data center](/docs/accounts/accounts-billing/account-setup/choose-your-data-center) para esclarecer que a região dos EUA é o padrão.
* Atualizado o [Serviço Nativo do Azure da New Relic](/docs/infrastructure/microsoft-azure-integrations/get-started/azure-native) com o URL de listagem atual do Azure Marketplace e removida a nota de disponibilidade desatualizada da HIPAA.
* Atualizada a [compatibilidade e requisitos da integração com Kubernetes](/docs/kubernetes-pixie/kubernetes-integration/get-started/kubernetes-integration-compatibility-requirements) para refletir as versões suportadas do Kubernetes 1.31 a 1.35.
* Corrigida a [sintaxe, cláusulas e funções do NRQL](/docs/nrql/nrql-syntax-clauses-functions) para corrigir a pontuação padrão do Apdex para 0,4 segundos.
* Adicionada uma opção de conector do Databricks (Azure) em [Configurar conectores para o New Relic Lens](/docs/new-relic-lens/set-up-connectors).
