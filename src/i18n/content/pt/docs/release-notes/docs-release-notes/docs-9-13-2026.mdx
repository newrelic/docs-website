### Novos documentos

* Adicionada a [ação do AWS EventBridge](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/aws-eventbridge) ao catálogo de ações de automação de fluxo de trabalho para publicar eventos no Amazon EventBridge.
* Adicionada a [ação de nível de serviço do New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/newrelic-service-level) ao catálogo de ações de automação de fluxo de trabalho para criar e gerenciar objetivos de nível de serviço a partir de um fluxo de trabalho.

### Grandes mudanças

* Atualizado [Criar workloads inteligentes](/docs/new-relic-solutions/new-relic-one/workloads/create-intelligent-workload) com criação em massa a partir de recomendações, uma seção de filtros de exclusão e uma nova seção de pré-requisitos para habilitar o distributed tracing.
* Expandida a [ação do AWS SQS](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/aws-sqs) no catálogo de ações de Automação de fluxo de trabalho com opções adicionais de configuração e conteúdo de referência expandido.
* Atualizamos o [NRQL para inteligência financeira do CCI](/docs/cci/financial-intelligence/nrql-for-cci) com exemplos de consulta otimizados e explicações simplificadas.
* Adicionada uma entrada do Oracle Kubernetes Engine (OKE) e suporte ao MariaDB/Aurora MySQL ao [agente eBPF](/docs/ebpf/requirements).
* Adicionados parâmetros de configuração de monitoramento de `agentMetadataReporting` e GenAI à [instalação do eBPF no Kubernetes](/docs/ebpf/k8s-installation) e à [instalação do eBPF no Linux](/docs/ebpf/linux-installation).
* Atualizadas as URLs do endpoint de tradução do dashboard do Grafana em [Visualizar e consultar dados do Prometheus no Grafana](/docs/infrastructure/prometheus-integrations/view-query-data/grafana).
* Atualizado o comando de atualização do caminho de configuração do NRDOT Collector nos documentos de monitoramento do [MySQL](/docs/opentelemetry/database/mysql/hosted) e nos [documentos de monitoramento do PostgreSQL hospedado e RDS](/docs/opentelemetry/database/postgresql/hosted).
* Atualizados [Tipos de agente](/docs/new-relic-control/agent-control/agent-types) e [Configuração de espelho](/docs/new-relic-control/agent-control/mirror-setup) com requisitos de verificação de assinatura para espelhos OCI e definições de tipo de agente.
* Atualizado [Instalar o agente Java com segurança Java 2](/docs/apm/agents/java-agent/additional-installation/install-java-agent-java-2-security) com as permissões necessárias para ambientes Java 9+ para evitar erros de acesso negado.
* Atualizados [Visão geral do MCP](/docs/agentic-ai/mcp/overview) e [Configurar o New Relic MCP](/docs/agentic-ai/mcp/setup) com novos escopos OAuth e chave de API.
* Atualizado o [documento de instalação da integração do Kubernetes](/docs/kubernetes-pixie/kubernetes-integration/installation/k8s-agent-operator) para adicionar suporte à anexação automática do APM do Kubernetes em nós do EKS Fargate.

### Pequenas mudanças

* Adicionado um aviso a [Conectar a federação de identidade de workload do GCP](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation) esclarecendo que os nomes de pool e provedor são sugestões personalizáveis.
* Atualizadas as descrições de desempenho de consulta ao banco de dados em [Monitorar o Microsoft SQL Server com o coletor CNCF](/docs/opentelemetry/database/mssql/cncf).

### Novidades

* [Agrupamento baseado em tags, colunas personalizadas e reordenação de colunas em Catálogos](/whats-new/2026/09/whats-new-09-07-catalogs-tag-grouping): agora você pode agrupar entidades e adicionar colunas usando qualquer tag, definida pela New Relic ou personalizada, e reordená-las para corresponder ao seu fluxo de trabalho, com seu layout salvo automaticamente.
