## v1.322.0

### Recurso

#### Incluir API de observador para eventos SPV

Use a API `ReportingObserver` para capturar eventos `securitypolicyviolation` que ocorreram antes da execução do carregador do agente. Na prática, isso afeta principalmente os navegadores chromium, pois as configurações e os bugs existentes afetam a coleta do Firefox e do Safari.

#### Manifest do MFE

Adiciona um `manifest` opcional à API `register()` para que um Micro Frontend possa declarar seus próprios ativos conhecidos (scripts, folhas de estilo, imagens, fontes), permitindo que o agente atribua com precisão erros, logs, chamadas AJAX, WebSockets e eventos de tempo de recursos a ele — mesmo para ativos carregados por um script diferente daquele que chamou `register()`. Um `timingMethod` opcional também permite que um manifest amplie as janelas de busca/execução de `MicroFrontEndTiming` em seus ativos declarados.

#### Adicionar avisos de validação de registro

Emite avisos locais de depuração se problemas óbvios forem detectados a partir dos destinos fornecidos para a API de registro.

### Correções de bugs

#### Atualize o web-vitals de 4.2.4 para 6.2.1 para corrigir um vazamento de listener

A biblioteca web-vitals incluída foi atualizada de 4.2.4 para 6.2.1, corrigindo um vazamento ilimitado de listener `document` `visibilitychange`: a web-vitals 4.x registra um listener permanente a cada ciclo de relatório INP, de modo que páginas de longa duração acumulam centenas de listeners. Também foram absorvidas as alterações da API de atribuição v5/v6 às quais o agente está exposto (a renomeação `LCPAttribution.element` → `target` e os campos de atribuição INP/CLS agora opcionais) sem alteração nos nomes de atributo que o agente emite.

## Declaração de apoio

New Relic recomenda que você atualize o agente regularmente para garantir que esteja obtendo os benefícios mais recentes de recursos e desempenho. Versões mais antigas não terão mais suporte quando chegarem [ao fim de sua vida útil](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/). As datas de lançamento refletem a data de publicação original da versão do agente.

Os seguintes recursos estão atualmente em visualização limitada e não receberão suporte padrão:

* [Monitoramento de micro frontend (MFE)](https://docs-preview.newrelic.com/docs/browser/micro-frontend-monitoring/) por meio da [API register()](https://docs-preview.newrelic.com/docs/browser/register)
* Eventos do tipo [BrowserPerformance “resource”](https://docs.newrelic.com/docs/browser/new-relic-browser/browser-pro-features/page-resources/)

Novos lançamentos de agente do browser são disponibilizados aos clientes em pequenas etapas ao longo de um período de tempo. Por esse motivo, a data em que o lançamento fica acessível à sua conta pode não corresponder à data de publicação original. Consulte este [dashboard de status](https://newrelic.github.io/newrelic-browser-agent-release/) para obter mais informações.

Em conformidade com nossa [política de suporte ao navegador](https://docs.newrelic.com/docs/browser/new-relic-browser/getting-started/compatibility-requirements-browser-monitoring/#browser-types), a v1.322.0 do agente do Browser foi desenvolvida e testada para estes navegadores e faixas de versão: Chrome 142–152, Edge 141–151, Safari 18–27 e Firefox 144–154. Para dispositivos móveis, a v1.322.0 foi compilada e testada para Android OS 16 e iOS Safari 18–26.2.
