## v1.324.1

**[Veja esta versão no GitHub →](https://github.com/newrelic/newrelic-browser-agent/releases/tag/v1.324.1)** para obter o changelog técnico completo e informações sobre o tamanho da compilação.

### Correções de bugs

#### corrigir as flags hasMeta/hasSnapshot nas coletas do Session Replay

Corrigido um problema em que as coletas do Session Replay podiam relatar incorretamente `hasMeta` e `hasSnapshot` como `false` nos metadados de sua carga, mesmo que os dados coletados incluíssem nós de snapshot válidos — mais perceptível logo após uma sessão mudar de gravação apenas de erros para gravação completa, ou sempre que o gravador era reiniciado. Esses metadados eram usados posteriormente para determinar se um determinado bloco de replay era autossuficiente (ou seja, se poderia fazer a inicialização de um replay por conta própria), de modo que um `false` incorreto poderia fazer com que dados válidos de replay fossem processados incorretamente.

### Correções de segurança

#### atualizar fflate para 0.8.3

Corrigido o CVE-2026-45820 - o unzipSync poderia entrar em um loop infinito ao analisar arquivos ZIP64 malformados

## Declaração de apoio

New Relic recomenda que você atualize o agente regularmente para garantir que esteja obtendo os benefícios mais recentes de recursos e desempenho. Versões mais antigas não terão mais suporte quando chegarem [ao fim de sua vida útil](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/). As datas de lançamento refletem a data de publicação original da versão do agente.

Os seguintes recursos estão atualmente em visualização limitada e não receberão suporte padrão:

* [Monitoramento de micro frontend (MFE)](https://docs-preview.newrelic.com/docs/browser/micro-frontend-monitoring/) por meio da [API register()](https://docs-preview.newrelic.com/docs/browser/register)
* Eventos do tipo [BrowserPerformance “resource”](https://docs.newrelic.com/docs/browser/new-relic-browser/browser-pro-features/page-resources/)

Novos lançamentos de agente do browser são disponibilizados aos clientes em pequenas etapas ao longo de um período de tempo. Por esse motivo, a data em que o lançamento fica acessível à sua conta pode não corresponder à data de publicação original. Consulte este [dashboard de status](https://newrelic.github.io/newrelic-browser-agent-release/) para obter mais informações.

De acordo com nossa [política de suporte ao navegador](https://docs.newrelic.com/docs/browser/new-relic-browser/getting-started/compatibility-requirements-browser-monitoring/#browser-types), a v1.324.1 do agente do Browser foi criada para e testada nestes navegadores e faixas de versão: Chrome 144–154, Edge 144–154, Safari 18–27 e Firefox 146–156. Para dispositivos móveis, a v1.324.1 foi compilada e testada para Android OS 17 e iOS Safari 18–26.2.
