## v1.324.0

**[Veja esta versão no GitHub →](https://github.com/newrelic/newrelic-browser-agent/releases/tag/v1.324.0)** para obter o changelog técnico completo e as informações de tamanho da compilação.

### Recurso

#### Melhoria na correspondência de script no manifesto

Os micro frontends registrados com um manifesto agora têm cada recurso que um correspondente de manifesto encontra contabilizado em seus dados de MicroFrontEndTiming. Anteriormente, cada ativo de manifesto era consumido por seu primeiro recurso correspondente, de modo que um correspondente amplo, como uma RegExp para chunks com hash aplicado (por exemplo, /catalog-chunk-\[a-f0-9]+.js/) contribuía com apenas um chunk para totalWeight, renderBlocking e a janela de tempo de fetch/execute. Todos os chunks correspondentes, já carregados ou carregados logo após register(), agora contribuem. Separadamente, quando a mesma URL de script é referenciada mais de uma vez (por exemplo, uma tag `<script>` duplicada, normalmente servida novamente a partir do cache do navegador), o agente agora mantém o tempo do primeiro carregamento em vez de substituí-lo, de modo que uma duplicata em cache não pode mais fazer com que o tempo de busca e execução pareça mais curto do que o carregamento real.

#### Habilitar distributed tracing para Micro Frontends registrados

Habilita o distributed tracing (DT) para Micro Frontends (MFEs) registrados: uma chamada AJAX feita por um MFE registrado agora enraíza corretamente seu trace na própria entidade desse MFE, dando visibilidade às próprias chamadas de backend de um MFE pela primeira vez.

### Correções de bugs

#### evitar coletas descontroladas de logs devido ao tamanho inflado do atributo

Corrigido um bug em que uma página que sobrescreve repetidamente um atributo personalizado poderia fazer com que o agente enviasse uma solicitação de logs separada para cada mensagem do log, inundando a rede e esgotando os recursos do navegador. O agente agora rastreia o tamanho do atributo personalizado com precisão quando os valores são sobrescritos, limita a frequência com que cada recurso pode realizar a coleta antecipada e ainda envia grandes lotes prontamente para que nenhum log seja descartado ao fazer isso.

#### fix(jserrors): redefinir a memória de hash da stack na redefinição da sessão

veja [https://new-relic.atlassian.net/browse/NR-626097](https://new-relic.atlassian.net/browse/NR-626097) para obter detalhes Reenviar o stack trace completo uma vez após uma redefinição de sessão, em vez de um hash que o backend pode não conseguir mais resolver devido aos TTLs de cache.

#### encontrar tempos de script de entidade de iframe no registro

As entidades de iframe registradas agora identificam o script que chamou register() quando são criadas, em vez de após o agente pai responder. Anteriormente, a pesquisa era executada após a ida e volta do registro, quando o script de chamada não estava mais na stack de chamadas, de modo que o ativo, o tipo e os tempos de busca da entidade poderiam estar ausentes ou ser um atributo do próprio script do agente.

## Declaração de apoio

New Relic recomenda que você atualize o agente regularmente para garantir que esteja obtendo os benefícios mais recentes de recursos e desempenho. Versões mais antigas não terão mais suporte quando chegarem [ao fim de sua vida útil](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/). As datas de lançamento refletem a data de publicação original da versão do agente.

Os seguintes recursos estão atualmente em visualização limitada e não receberão suporte padrão:

* [Monitoramento de micro frontend (MFE)](https://docs-preview.newrelic.com/docs/browser/micro-frontend-monitoring/) por meio da [API register()](https://docs-preview.newrelic.com/docs/browser/register)
* Eventos do tipo [BrowserPerformance “resource”](https://docs.newrelic.com/docs/browser/new-relic-browser/browser-pro-features/page-resources/)

Novos lançamentos de agente do browser são disponibilizados aos clientes em pequenas etapas ao longo de um período de tempo. Por esse motivo, a data em que o lançamento fica acessível à sua conta pode não corresponder à data de publicação original. Consulte este [dashboard de status](https://newrelic.github.io/newrelic-browser-agent-release/) para obter mais informações.

De acordo com nossa [política de suporte a navegadores](https://docs.newrelic.com/docs/browser/new-relic-browser/getting-started/compatibility-requirements-browser-monitoring/#browser-types), a v1.324.0 do agente do browser foi desenvolvida para e testada nestes navegadores e intervalos de versões: Chrome 144–154, Edge 144–154, Safari 18–27 e Firefox 146–156. Para dispositivos móveis, a v1.324.0 foi compilada e testada para Android OS 17 e iOS Safari 18–26.2.
