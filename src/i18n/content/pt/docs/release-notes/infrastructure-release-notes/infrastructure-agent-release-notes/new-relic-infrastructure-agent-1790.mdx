## Notas

### 🛡️ Avisos de segurança

* Corrigida uma vulnerabilidade de execução remota de código causada por path traversal no [#2292](https://github.com/newrelic/infrastructure-agent/pull/2292).
* Adicionadas permissões explícitas aos fluxos de trabalho do GitHub Actions para reduzir o escopo do token em [#2232](https://github.com/newrelic/infrastructure-agent/pull/2232)
* Atualizado o google.golang.org/grpc de 1.79.3 para 1.82.1 no go.mod em [#2296](https://github.com/newrelic/infrastructure-agent/pull/2296)
* Atualizadas as versões OHI incorporadas (nri-docker, nri-flex) para corrigir CVEs conhecidos em [#2302](https://github.com/newrelic/infrastructure-agent/pull/2302)
* atualização de dependências vulneráveis sinalizadas pela verificação do Trivy em [#2301](https://github.com/newrelic/infrastructure-agent/pull/2301)

### 🚀 Melhorias

* Adicionado suporte para ignorar locais de integração padrão por meio de disable\_plugin\_default\_dir\_scan em [#2290](https://github.com/newrelic/infrastructure-agent/pull/2290)
* Tornadas públicas as variáveis de ambiente usadas pelo controle do agente em [#2293](https://github.com/newrelic/infrastructure-agent/pull/2293)
* Adicionado suporte a tag OCI para corresponder às tags da AWS (Fase 1 + Fase 2) em [#2295](https://github.com/newrelic/infrastructure-agent/pull/2295)
* Habilitado NRIA\_DISABLE\_PLUGIN\_DEFAULT\_DIR\_SCAN por padrão para agentes gerenciados pelo Agent-Control no [#2300](https://github.com/newrelic/infrastructure-agent/pull/2300)
* Removido o nri-flex dos artefatos do agent-control em [#2291](https://github.com/newrelic/infrastructure-agent/pull/2291)

### 🐞 Correções de bugs

* Restauradas as permissões de trabalho ausentes para fluxos de trabalho de lançamento e canário em [#2303](https://github.com/newrelic/infrastructure-agent/pull/2303)

### Declaração de apoio:

Uma nova versão do agente foi lançada. Siga os procedimentos padrão para [atualizar o agente de infraestrutura](/docs/infrastructure/install-configure-manage-infrastructure/update-or-uninstall/update-infrastructure-agent).

Recomendamos atualizar para a versão mais recente do agente assim que estiver disponível. Caso não seja possível atualizar para a versão mais recente, atualize os agentes para uma versão com no máximo 90 dias. Leia mais sobre [como manter o agente atualizado](https://docs.newrelic.com/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent/).

Consulte a [Política de EOL do agente de infraestrutura da New Relic](https://docs.newrelic.com/docs/infrastructure/infrastructure-agent/infrastructure-agent-eol-policy/) para obter informações sobre as versões do agente e as datas de suporte.
