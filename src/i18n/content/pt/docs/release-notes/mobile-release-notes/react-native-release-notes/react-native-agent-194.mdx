### Novo recurso

* Adicionada uma opção de configuração `consoleCaptureEnabled` (padrão `true`) que permite impedir que o agente capture chamadas `console.*` como logs. ([#342](https://github.com/newrelic/newrelic-react-native-agent/pull/342))

### Melhorias e aprimoramentos

* Token de aplicativo do New Relic exposto removido. ([#338](https://github.com/newrelic/newrelic-react-native-agent/pull/338))
* Atualizado o agente Android nativo para a versão 7.8.5. ([#346](https://github.com/newrelic/newrelic-react-native-agent/pull/346))
* Atualizado o agente iOS nativo para a versão 7.7.10. Se você usa CocoaPods e seu `Podfile.lock` tem uma versão anterior, execute `pod update NewRelicAgent` para atualizar para a 7.7.10. ([#346](https://github.com/newrelic/newrelic-react-native-agent/pull/346))

### Correções de bugs

* Corrigida uma falha em que `console.log/warn/error/debug` lançava uma exceção quando um argumento não podia ser serializado, como um objeto com um getter que lança uma exceção. ([#341](https://github.com/newrelic/newrelic-react-native-agent/pull/341))
