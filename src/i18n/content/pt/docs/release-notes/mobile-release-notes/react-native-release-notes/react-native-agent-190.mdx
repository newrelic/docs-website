<Callout variant="important" title="Alteração incompatível no relatório de erros">
  A partir da versão 1.9.0, Os erros de JavaScript são relatados por meio de um novo tipo de evento: `MobileJSError`. Com o novo Mobile Errors Protocol, os erros de JavaScript do React Native não são mais armazenados no tipo de evento `MobileHandledException`.

  <DNT>**Action required:**</DNT>

  * <DNT>**Alerts:**</DNT> Atualize as condições do alerta NRQL para o destino `MobileJSError`.
  * <DNT>**Dashboards:**</DNT> Atualize quaisquer gráficos personalizados que consultem `MobileHandledException` por erros da camada JavaScript.
  * <DNT>**Symbolication:**</DNT> Atualize os scripts de compilação para a versão mais recente para suportar uploads de source map para o novo tipo de evento. Consulte o [relatório de erros de JavaScript do React Native](/docs/mobile-monitoring/new-relic-monitoring-react-native/react-native-agent-js-error-reporting).

  Atualize as consultas da seguinte forma:

  ```sql
  -- Before (1.8.x and lower)
  SELECT count(*) FROM MobileHandledException WHERE platform = 'reactnative'

  -- After (1.9.0 and higher)
  SELECT count(*) FROM MobileJSError
  ```
</Callout>

## Melhorias

* Os erros de JavaScript e as rejeições de promessas não tratadas agora são relatados como um tipo de evento `MobileJSError` de primeira classe por meio do novo Mobile Errors Protocol, em vez de `MobileHandledException`.
* Adicionado suporte ao upload de source map para simbolizar o stack trace de `MobileJSError` (automático, manual e CodePush/OTA). Consulte o [relatório de erros de JavaScript do React Native](/docs/mobile-monitoring/new-relic-monitoring-react-native/react-native-agent-js-error-reporting).
* Adicionada a opção de configuração `jsErrorReportingEnabled` para ativar ou desativar o relatório de erros de JavaScript (ativado por padrão).
* `recordError` agora aceita os argumentos opcionais `isFatal` e `attributes`, o que permite marcar um erro como fatal ou anexar atributos personalizados.
* Atualizado o agente Android nativo para a versão 7.8.2.
* Atualizado o agente iOS nativo para a versão 7.7.6.
