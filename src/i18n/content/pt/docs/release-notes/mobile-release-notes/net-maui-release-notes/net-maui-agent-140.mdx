### Novo recurso

* Adicionado suporte para .NET 11, incluindo o runtime CoreCLR no Android e iOS, e removidos os destinos do .NET 9; exceções não tratadas do iOS no CoreCLR agora são relatadas com seu stack trace gerenciado. ([#87](https://github.com/newrelic/newrelic-maui-plugin/pull/87))
* Adicionadas extensões de privacidade do Session Replay para views do .NET MAUI. ([#102](https://github.com/newrelic/newrelic-maui-plugin/pull/102))

### Melhorias e aprimoramentos

* Atualizado o agente Android nativo para a versão 7.8.6.
* Atualizado o agente iOS nativo para a versão 7.7.11.
