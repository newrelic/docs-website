## Novos recursos e melhorias

* Adicionado armazenamento offline para o Session Replay: as cargas de replay que não podem ser enviadas imediatamente — devido à falta de conexão de rede, fechamento forçado do aplicativo, saída do processo ou encerramento por pouca memória — agora são persistidas no disco e entregues na próxima coleta bem-sucedida, em vez de serem perdidas.
* Adicionado suporte subjacente para relatórios de erros híbridos de aplicativos React Native, a ser ativado junto com um próximo lançamento do agente React Native. Erros de JavaScript não tratados serão capturados como eventos do agente, correlacionados com o Session Replay e receberão a tag com a versão do aplicativo para uma simbolização precisa.
* Adicionado suporte subjacente para upload automático de source maps de JavaScript do React Native durante a compilação do Gradle, a ser ativado junto com um próximo lançamento do agente React Native.
* Adicionado o upload de arquivo de mapeamento do ProGuard/DexGuard por destino de compilação, para que os aplicativos com vários destinos de empacotamento do DexGuard obtenham a desofuscação de falhas correspondida corretamente para cada destino.
* Adicionado um armazenamento de atributo com escopo de sessão para que os eventos de Application Exit Info (AEI) carreguem os atributos de sessão da sessão que realmente falhou, em vez da sessão criada após o lançamento.
* A persistência de evento agora está ativada por padrão, para que os eventos em buffer e os dados de análise sobrevivam ao encerramento do aplicativo e sejam recuperados no próximo lançamento.
* Adicionado suporte para o plug-in do Android Gradle (AGP) 9.x, elevando o limite suportado para 9.3.0.

## Correções de bugs

* Corrigido o tempo de inicialização a frio para medir o tempo até a exibição inicial (TTID) desde o lançamento até o primeiro quadro renderizado, em vez da retomada da Activity.
* Corrigido um problema de recuperação de falhas em que um arquivo de backup obsoleto poderia impedir que o armazenamento de falhas se recuperasse após uma falha anterior.
* Corrigidas as exceções tratadas para serem persistidas fora da thread de chamada, evitando possíveis lentidões quando o armazenamento de exceções é gravado.
* Corrigida a invalidação do cache de compilação do Gradle causada pela incorporação do ID de compilação por compilação e valores de métrica diretamente no código-fonte compilado — estes agora são gerados como recursos do Android, reduzindo recompilações desnecessárias e o tempo de reconstrução, com os recursos protegidos contra remoção quando shrinkResources está ativado.

## Declaração de apoio

Recomendamos atualizar o agente pelo menos a cada três meses. Encontre políticas e datas específicas para suporte ao agente Android na [Política de EOL de monitoramento de agente móvel](/docs/mobile-monitoring/new-relic-mobile/get-started/mobile-agents-eol-policy/#android-eol).
