## Correções de bugs

* Corrigido o hardcoding de `andParams: nil` da ponte do iOS, que descartava silenciosamente `httpParams` personalizados e valores de cabeçalho rastreados de eventos `MobileRequest`/`MobileRequestError`. O Android já encaminhava os parâmetros corretamente.

## Melhorias

* Atualizado o agente Android nativo para a versão 7.8.1.
* Atualizado o agente iOS nativo para a versão 7.7.6.
