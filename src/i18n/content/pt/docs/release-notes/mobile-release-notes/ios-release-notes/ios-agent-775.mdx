### Corrigido nesta versão

* Corrigido um bug em que chamar setUserId com nil sempre iniciava uma nova sessão.

* Evitado o upload de quadros antigos do Session Replay com uma nova sessão.

* Alterada a acessibilidade para atualizar um retorno de chamada na alteração em vez de chamá-lo todas as vezes.

* Corrigida a falha de invalidação de hex.

* Corrigida a falha de vendorId do setUserId.

* Corrigida a atomicidade nas coleções de trace do NRMA.

* Corrigido o setUserId para permanecer síncrono.

* Corrigido um travamento ao alterar o Session Replay de um Timer para um DispatchSourceTimer.

* Corrigida uma falha no CoreData NRMAMethodProfiler.

* Corrigida uma falha fazendo com que sessionAttributeJSONString tire um snapshot de dicts.

* Corrigido o texto MSR limitando o deslocamento de compensação de largura de texto do SwiftUI ao seu conteúdo.

* Corrigido um vazamento de memória no JSErrorController.

* Corrigido o texto MSR referindo-se ao peso numérico preciso da fonte em vez do traço negrito binário.

* Atualizadas as ferramentas de upload de dSYM para adicionar o parâmetro appVersion ao dsym-upload-tools run-symbol-tool.

* Corrigidos os modais ausentes do SwiftUI no MSR.
