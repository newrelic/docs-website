### Novo recurso

* Atualizada a configuração de build do XCFramework para definir como destino uma versão mínima de implantação do iOS 15.0 e tvOS 15.0, alinhando-se aos requisitos mínimos de plataforma documentados.

### Correções de bugs

* Resolvida uma falha (`SIGSEGV` em `objc_msgSend`) que ocorria durante as leituras de configuração de harvest. Oito propriedades de objeto em `NRMAHarvesterConfiguration` declaradas como `assign` retiveram ponteiros pendentes após a drenagem do autorelease pool da resposta `/connect` ou do dicionário `NSUserDefaults`.

* Resolvido um problema em que todos os traces de atividade eram descartados para uma sessão quando a resposta `/connect` omitia o atributo `at_capture`.

* Corrigido o valor `platform` relatado com erros do React Native para ser relatado como `ReactNative`.

* Corrigido o campo `agentVersion` na carga de erro do JavaScript para relatar com precisão a versão do agente iOS em vez da versão da plataforma host.

* Atualizada a validação de atributo personalizado: passar um objeto `NSArray` ou `NSDictionary` como um atributo de evento agora registra um erro explícito identificando o tipo não compatível, substituindo a mensagem de aviso genérica `"value must be an NSString, NSNumber, or BOOL"`.
