### Correções de bugs

* Foi corrigido um problema em que a chamada de `recordError` em condições de pouca memória poderia encerrar o aplicativo host. Os relatórios de erros agora são descartados e registrados, e os frames do agente New Relic são removidos do topo da stack registrada.
* Corrigida uma falha no `NRMALoggerBridge::log` causada por um argumento ausente em uma string de formato de log ao remover atributos de sessão. Corrigidas duas strings de formato inválidas adicionais no mesmo componente.
* Foi corrigido um problema em que os timestamps do distributed tracing (`tracestate` e a carga `ti`) eram enviados em segundos em vez de milissegundos ao usar o novo sistema de eventos.
* Corrigido um problema em que eventos `MobileRequest` bem-sucedidos perdiam todos os atributos de distributed tracing quando um SDK multiplataforma passava `traceHeaders`.
* Atualizamos o agente nativo para evitar adicionar distributed trace duplicados aos requests reportados com `traceHeaders` pelo Flutter, React Native ou outros agentes híbridos. Isso se aplica tanto a `MobileRequest` quanto a `MobileRequestError` em ambos os sistemas de eventos.
* Aplicados limites mínimos e máximos para as configurações de `MaxEventPoolSize` e `MaxEventBufferTime` (tempo máximo de buffer limitado a 600 segundos).
* O `recordCustomEvent` foi atualizado para retornar um booleano indicando se o evento foi adicionado com sucesso ao usar o novo sistema de eventos, em vez de sempre retornar `YES`.
* Atualizados os uploads de erros de JavaScript do React Native para passar o valor da plataforma `ReactNative` com a capitalização correta, correspondendo ao comportamento do agente Android.
