## Melhorias

* Corrigido o travamento de aplicativos iOS no lançamento com `Library not loaded: @rpath/NewRelic.framework/NewRelic`. A declaração do gerenciador de pacote Swift adicionada na versão 1.6.0 foi removida e as dependências do iOS agora são resolvidas apenas via CocoaPods. As compilações na versão 1.6.0 até a versão 1.6.4 foram afetadas, a menos que o gerenciador de pacote Swift tenha sido desativado manualmente nas configurações do EDM4U iOS Resolver.
* Corrigida a ausência total do agente iOS do New Relic nas compilações no Unity 2019.1 a 2021.2, onde o EDM4U suprimiu o pod `NewRelicAgent`, mas ignorou a injeção do gerenciador de pacote do Swift porque requer o Unity 2021.3 ou mais recente.
* Agente Android nativo atualizado para a versão 7.8.2
* Agente Android NDK nativo atualizado para a versão 1.1.5
* Agente iOS nativo atualizado para a versão 7.7.6
* As dependências do iOS agora são resolvidas apenas através do CocoaPods. Nenhuma ação é necessária se o gerenciador de pacote Swift tiver sido usado anteriormente, pois o EDM4U reverte para o pod `NewRelicAgent` automaticamente e a configuração **Swift Package Manager Enabled** pode ser deixada marcada.
* Se um projeto Xcode gerado ainda contiver uma referência de pacote `newrelic-ios-agent-spm` de uma compilação anterior, é necessário excluir o projeto gerado e recompilar a partir do Unity para limpá-lo.
