### Novos recursos e melhorias:

* [O perfilamento em tempo real para Java usando métricas JFR](/docs/agents/java-agent/features/real-time-profiling-java-using-jfr-metrics/) agora está totalmente integrado ao agente Java. Consulte o [README do JFR core](https://github.com/newrelic/newrelic-jfr-core/blob/main/README.md) para obter detalhes adicionais.

Este recurso requer uma versão compatível do Java 8 (especificamente a versão `8u262` ou superior) ou Java 11 ou superior e está atualmente desativado por padrão. Para habilitá-lo, defina o seguinte em seu yaml (com recuo de 2 espaços na seção common).

```
jfr:
  enabled: true
```

**Aviso:** caso o [jar do jfr-daemon](https://github.com/newrelic/newrelic-jfr-core) tenha sido usado anteriormente como uma extensão do agente ou processo autônomo, essa opção deve ser removida para evitar possíveis conflitos com o serviço JFR que agora está integrado ao agente.

* Incompatível com o Java 7. Para continuar a inovar e fornecer novos recursos de forma eficiente aos nossos clientes que executam na JVM, esta e as futuras versões do agente não são compatíveis com o Java 7. Caso execute o Java 7, é possível continuar a usar o agente Java 6.5.0 ou inferior. Para obter detalhes, consulte este tópico no [Explorers Hub](https://support.newrelic.com/s/hubtopic/aAX8W0000008bni/important-upcoming-changes-to-capabilities-across-synthetics-apm-java-php).
* Adiciona suporte ao akka http com Scala 2.13. [#271](https://github.com/newrelic/newrelic-java-agent/pull/271)
* Anotação de classe para realizar o trace de métodos lambda. [#274](https://github.com/newrelic/newrelic-java-agent/pull/274)
* Anotação de classe para realizar o trace de métodos por tipo de retorno. [#275](https://github.com/newrelic/newrelic-java-agent/pull/275)

### Correções:

* Corrige um problema que poderia fazer com que várias versões da instrumentação do `akka-http-core` fossem aplicadas ao mesmo tempo. [#208](https://github.com/newrelic/newrelic-java-agent/pull/208)
* O agente agora registrará os eventos descartados em `FINE` em vez de `WARN` para diminuir a verbosidade. [#296](https://github.com/newrelic/newrelic-java-agent/pull/296)
* Corrige os comentários do Javadoc que afirmavam incorretamente que, ao chamar a API `noticeError` várias vezes, o primeiro erro seria relatado, quando, na verdade, é o último erro que é relatado. [#313](https://github.com/newrelic/newrelic-java-agent/pull/313)

### Declaração de apoio:

* A New Relic recomenda que você atualize o agente regularmente para garantir que obtenha os recursos e benefícios de desempenho mais recentes. Além disso, versões mais antigas não serão mais suportadas quando atingirem o [fim da vida útil](/docs/using-new-relic/cross-product-functions/install-configure/notification-changes-new-relic-saas-features-distributed-software/).

### Problemas Conhecidos

* OkHttp

Esta versão contém um bug que causa falhas nas versões 3.X e inferiores do OkHttp. Todos os usuários afetados devem atualizar para a versão 7.0.1.
