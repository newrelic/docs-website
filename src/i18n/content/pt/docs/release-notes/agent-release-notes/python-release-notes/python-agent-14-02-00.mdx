## Notas

Esta versão do agente Python adiciona instrumentação para o framework de agente da Microsoft e CrewAI, melhora a instrumentação de flag de recurso do LaunchDarkly e o suporte ao encaminhamento de span, e corrige várias falhas.

Instale o agente usando `easy_install/pip/distribute` através do [Índice de Pacotes Python](https://pypi.python.org/pypi/newrelic), usando `conda` através do [Índice de Pacotes Conda-Forge](https://anaconda.org/conda-forge/newrelic) ou baixe-o diretamente do [site de download do New Relic](https://download.newrelic.com/python_agent/release).

## Novo recurso

* Nova instrumentação para o [framework de agente da Microsoft](https://pypi.org/project/agent-framework/)

  * Foi adicionada instrumentação para ferramentas e agentes no pacote `agent-framework`.
  * As configurações de múltiplos agentes ainda não estão instrumentadas.

* Nova instrumentação para o [CrewAI](https://pypi.org/project/crewai/)

  * Foi adicionada instrumentação para agentes, equipes e ferramentas no pacote `crewai`.

## Recursos aprimorados

* Integração aprimorada de flag de recurso do [LaunchDarkly](https://pypi.org/project/launchdarkly-server-sdk/).

  <Callout title="visualização">
  Ainda estamos trabalhando nesse recurso, mas adoraríamos que você experimentasse!

  Atualmente, esse recurso é fornecido como parte de um programa de visualização de acordo com nossas [políticas de pré-lançamento](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy).
  </Callout>

  * Para aderir à nossa integração em prévia pública com o LaunchDarkly, habilite as configurações `launch_darkly_integration.enabled` e `opentelemetry.enabled` no seu arquivo de configuração.

  * Instrumentação aprimorada de flag de recurso no [ldclient](https://pypi.org/project/launchdarkly-server-sdk/).

    * Adicionado o novo atributo `feature_flag.url.full` para habilitar o deep linking na interface.
    * Alterada a capitalização da chave `inExperiment` para corresponder ao LaunchDarkly.
    * Adicionado suporte para valores falsy em atributos de flag de recurso.
    * Reduzidos todos os avisos de integração do LaunchDarkly para serem exibidos apenas uma vez.

  * Encaminhamento de span aprimorado para o [ldobserve](https://pypi.org/project/launchdarkly-observability/).

    * Adicionados os atributos de span `nr.entity.guid` e `nr.entity.url` para habilitar o deep linking na interface.
    * Corrigida a hierarquia de span para permitir o aninhamento adequado na interface.

## Correções de bugs

* Corrigida uma falha em `TimeTrace` quando attributes era `None` em `_add_span_event_event`.
* Corrigida uma falha no wrapper `Config` do LaunchDarkly ao reverter para os valores padrão.
