## Notas

Esta versão do agente Python adiciona instrumentação para OpenAI Responses e o novo comando `hsetex` no Valkey.

Instale o agente usando `easy_install/pip/distribute` através do [Índice de Pacotes Python](https://pypi.python.org/pypi/newrelic), usando `conda` através do [Índice de Pacotes Conda-Forge](https://anaconda.org/conda-forge/newrelic) ou baixe-o diretamente do [site de download do New Relic](https://download.newrelic.com/python_agent/release).

## Novo recurso

* Nova instrumentação para [respostas da OpenAI](https://pypi.org/project/openai/)

  * A instrumentação foi adicionada para os métodos `client.responses` do SDK `openai`, que têm como destino a [API Responses](https://developers.openai.com/api/reference/resources/responses).
  * Esta é uma adição à instrumentação existente dos métodos `client.chat.completions` mais antigos e da [API Chat Completions](https://developers.openai.com/api/reference/resources/chat), que ainda são suportados.

## Recursos aprimorados

* Adicionado suporte para novo comando [do Valkey](https://pypi.org/project/valkey/):

  * O comando `hsetex` agora é suportado.
