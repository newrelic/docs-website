## Notas

Esta versão do agente Python adiciona utilização para o Azure App Services, instrumentação para o Azure Service Bus, suporte para um novo método Kinesis e suporte para o Google ADK para a v2.10.0 e superior. Esta versão também corrige um problema no httplib em que os cabeçalhos de distributed trace eram duplicados, bem como o arquivo de instalação `setup.py`.

Instale o agente usando `easy_install/pip/distribute` através do [Índice de Pacotes Python](https://pypi.python.org/pypi/newrelic), usando `conda` através do [Índice de Pacotes Conda-Forge](https://anaconda.org/conda-forge/newrelic) ou baixe-o diretamente do [site de download do New Relic](https://download.newrelic.com/python_agent/release).

## Recursos removidos

* Removido o suporte ao Python 3.9

  \* O Python 3.9 atingiu o fim da vida útil em 31 de outubro de 2025 e não é mais suportado pelo agente. Considere atualizar seu aplicativo para uma versão suportada do Python para continuar recebendo atualizações do agente Python.

## Novo recurso

* Utilização do Azure App Service

  * A utilização para o Azure App Service foi adicionada para permitir o mapeamento de relacionamento de entidade.
  * Isso também adiciona uma nova configuração, `utilization.detect_azureappservice`

* Nova instrumentação para o [Azure Service Bus](https://pypi.org/project/azure-servicebus/)

  * A instrumentação foi adicionada para o Microsoft Azure Service Bus.

* Nova instrumentação para novo método do [Kinesis](https://pypi.org/project/kinesis-python/)

  * O método `update_stream_record_distribution_strategy` agora é suportado no Kinesis.

## Atualizações de segurança

* O pacote interno [urllib3](https://pypi.org/project/urllib3/) foi atualizado para `2.8.0` para resolver todas as CVEs atuais em `urllib3`.

  * Isso resolve todas as CVEs conhecidas no agente até o momento.

## Recursos aprimorados

* Suporte para o [Google ADK](https://pypi.org/project/google-adk/) v2.10.0 e superior.

  * A instrumentação foi atualizada para o Google ADK nas versões 2.10.0 e superiores.

## Bugs

* Cabeçalhos de distributed tracing duplicados em [httplib](https://github.com/python/cpython/blob/main/Lib/http/client.py)

  * Foram corrigidos problemas em que a instrumentação de `httplib` poderia produzir cabeçalhos duplicados para `traceparent`, resultando em um valor malformado.

* `setup.py` o arquivo de instalação agora funciona para todas as versões suportadas do Python

  * Se um usuário quisesse usar o arquivo `setup.py` diretamente para instalar o agente Python no Python 3.12 e superior, ele se depararia com um `ImportError`. Isso ocorre porque `distutils` foi descontinuado desde o Python 3.10 e totalmente removido da biblioteca padrão no Python 3.12.

## Declaração de apoio
