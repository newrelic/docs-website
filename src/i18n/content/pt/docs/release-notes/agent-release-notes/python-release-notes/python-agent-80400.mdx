## Notas

Esta versão do agente Python aumenta o limite de evento personalizado e inclui uma correção de bug.

Instale o agente usando `easy_install/pip/distribute` por meio do [Índice de Pacotes Python](https://pypi.python.org/pypi/newrelic) ou baixe-o diretamente do [site de download do New Relic](https://download.newrelic.com/python_agent/release).

## Alterações

* **Aumentar o limite de eventos personalizados**

  Esta versão do agente aumenta o limite padrão de eventos personalizados de 1.200 eventos por minuto para 3.600 eventos por minuto. No cenário em que os eventos personalizados estavam sendo limitados, essa alteração permitirá que mais eventos personalizados sejam enviados para a New Relic. Há também um novo limite máximo configurável de 100.000 eventos por minuto. Para alterar os limites, consulte a [documentação para event\_harvest](https://docs.newrelic.com/docs/apm/agents/python-agent/configuration/python-agent-configuration/#harvest-limits-custom-event-data). Para saber mais sobre a mudança e como determinar se eventos personalizados estão sendo descartados, consulte nossa [postagem no Explorers Hub](https://support.newrelic.com/s/hubtopic/aAX8W0000008dby/send-more-custom-events-with-the-latest-apm-agents).

## Correções de bugs

* **Corrigir o erro de atributo do NewRelicContextFormatter**

  Um bug foi introduzido na v8.3.0 que causava um AttributeError ao usar o NewRelicContextFormatter. Isso foi corrigido nesta versão de lançamento.
