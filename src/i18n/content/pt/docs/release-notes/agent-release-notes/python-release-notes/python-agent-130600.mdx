## Notas

Esta versão do agente Python adiciona suporte para OpenSearch, Microsoft Azure SQL, novos métodos do Kinesis e uma nova configuração `browser_monitoring.version`. Além disso, foram feitas melhorias na instrumentação do Anthropic, MCP e Google ADK. Problemas com cabeçalhos assinados no botocore (SigV4) e na análise de ferramentas do Gemini também foram corrigidos para esta versão.

Instale o agente usando `easy_install/pip/distribute` através do [Índice de Pacotes Python](https://pypi.python.org/pypi/newrelic), usando `conda` através do [Índice de Pacotes Conda-Forge](https://anaconda.org/conda-forge/newrelic) ou baixe-o diretamente do [site de download do New Relic](https://download.newrelic.com/python_agent/release).

## Novo recurso

* Nova instrumentação para o [opensearch-py](https://pypi.org/project/opensearch-py/)

  * Foi adicionada instrumentação para o conector oficial do banco de dados OpenSearch.

* Nova instrumentação para [mssql-python](https://pypi.org/project/mssql-python/)

  * A instrumentação foi adicionada para o Microsoft Azure SQL.

* Nova instrumentação para novos métodos do [Kinesis](https://pypi.org/project/kinesis-python/)

  * Os seguintes métodos agora são suportados no Kinesis:

    * `create_channel`
    * `delete_channel`
    * `describe_channel`
    * `list_channels`
    * `update_channel`

* Nova configuração para `browser_monitoring.version`

  * A nova configuração `browser_monitoring.version` permite que os usuários especifiquem versões específicas do nosso [agente de monitoramento de Browser](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/introduction-browser-monitoring/) a serem injetadas.
  * Consulte a lista de [Versões suportadas do agente do browser](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/) para escolher.

## Recursos Melhorados

* Suporte aprimorado para [anthropic](https://pypi.org/project/anthropic/).

  * Análise aprimorada de parâmetros de solicitação para o Anthropic SDK nas versões 1.0.0 e superiores.
  * Nova análise para respostas via `Messages.with_raw_response.create` permitindo melhor compatibilidade com o LangChain.

* Suporte para [mcp](https://pypi.org/project/mcp/) v2.0.0 e superior.

  * A instrumentação foi atualizada após a grande refatoração feita no `mcp` v2.0.0 e deve voltar a funcionar como esperado.

* Suporte para [Google ADK](https://pypi.org/project/google-adk/) v2.9.0 e superior.

  * A instrumentação foi atualizada para o Google ADK nas versões 2.9.0 e superiores.

## Bugs

* Corrige problemas com cabeçalhos assinados no [botocore](https://pypi.org/project/botocore/) (SigV4)

  * Anteriormente, quaisquer cabeçalhos de distributed tracing que fossem gerados por outras bibliotecas de rastreamento poderiam causar problemas com a instrumentação no botocore devido à assinatura de cabeçalho. Isso foi corrigido, e os cabeçalhos de distributed tracing agora são modificados antes da assinatura.

* Correção para análise de ferramentas do [Gemini](https://pypi.org/project/google-genai/)

  * Anteriormente, algumas instâncias de ferramentas criadas com o Gemini apresentavam falha de análise e falhavam silenciosamente, resultando em nenhuma resposta para essa solicitação específica. O problema foi resolvido.
