## Notas

Esta versão do agente Python habilita o AI Monitoring por padrão com a nova configuração `ai_monitoring.basic_telemetry.enabled`, descontinua a configuração `ai_monitoring.enabled` e corrige uma falha na instrumentação de ferramentas do LangChain.

Instale o agente usando `easy_install/pip/distribute` através do [Índice de Pacotes Python](https://pypi.python.org/pypi/newrelic), usando `conda` através do [Índice de Pacotes Conda-Forge](https://anaconda.org/conda-forge/newrelic) ou baixe-o diretamente do [site de download do New Relic](https://download.newrelic.com/python_agent/release).

## Alterações

* AI Monitoring agora está habilitado por padrão

  * A instrumentação de LLM agora está habilitada por padrão e o agente envia `Llm*` eventos personalizados, spans e métricas (sem conteúdo da mensagem), a menos que configurado de outra forma.
  * Para registrar o conteúdo do prompt e da resposta, defina [`ai_monitoring.record_content.enabled`](/docs/apm/agents/python-agent/configuration/python-agent-configuration/#ai-monitoring-record-content) como `true`.
  * Para desativar, defina [`ai_monitoring.basic_telemetry.enabled`](/docs/apm/agents/python-agent/configuration/python-agent-configuration/#ai-monitoring-basic-telemetry-enabled) como `false` no newrelic.ini, ou defina a variável de ambiente `NEW_RELIC_AI_MONITORING_BASIC_TELEMETRY_ENABLED=false`.
  * A configuração [`ai_monitoring.enabled`](/docs/apm/agents/python-agent/configuration/python-agent-configuration/#ai-monitoring-enabled) e a variável de ambiente `NEW_RELIC_AI_MONITORING_ENABLED` foram descontinuadas, mas definir qualquer uma delas como `false` também desativa o AI Monitoring.

## Correções de bugs

* Corrigida uma falha na instrumentação `StructuredTool.invoke` e `StructuredTool.ainvoke` do [LangChain](https://pypi.org/project/langchain/) quando `config` ou seu `metadata` era `None`.
