## Notas

Esta versão do agente Python corrige problemas com cabeçalhos assinados no botocore (SigV4).

Instale o agente usando `easy_install/pip/distribute` através do [Índice de Pacotes Python](https://pypi.python.org/pypi/newrelic), usando `conda` através do [Índice de Pacotes Conda-Forge](https://anaconda.org/conda-forge/newrelic) ou baixe-o diretamente do [site de download do New Relic](https://download.newrelic.com/python_agent/release).

## Bugs

* Corrige problemas com cabeçalhos assinados no [botocore](https://pypi.org/project/botocore/) (SigV4)

  * A alteração anterior nos cabeçalhos de distributed tracing do botocore foi revertida para evitar o envio de cabeçalhos duplicados.
  * Anteriormente, quaisquer cabeçalhos de distributed tracing que fossem gerados por outras bibliotecas de rastreamento poderiam causar problemas com a instrumentação no botocore devido à assinatura de cabeçalho. Isso foi corrigido desativando a assinatura para esses cabeçalhos no botocore.
