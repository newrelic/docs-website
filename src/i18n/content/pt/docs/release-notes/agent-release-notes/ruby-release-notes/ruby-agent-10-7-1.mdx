## v10.7.1

* **Correção de bug: resolve ArgumentError em operações de múltiplas chaves com Dalli 5.1.0**

  Esta correção atualiza a instrumentação do Dalli para aceitar e encaminhar argumentos opcionais de opções de requests em operações múltiplas e em pipeline. Nossos agradecimentos a [@dbackeus](https://github.com/dbackeus) por contribuir com uma correção! [PR#3642](https://github.com/newrelic/newrelic-ruby-agent/pull/3642)

* **Correção de bug: as requests de Async::HTTP não geram mais `NoMethodError` quando um segmento falha ao iniciar**

  Se o agente encontrasse um erro interno ao criar o segmento para uma solicitação `Async::HTTP`, a instrumentação continuava a usar esse segmento ausente e poderia gerar um `NoMethodError`. Isso agora está corrigido, graças a [@ydah](https://github.com/ydah). [PR#3640](https://github.com/newrelic/newrelic-ruby-agent/pull/3640)
