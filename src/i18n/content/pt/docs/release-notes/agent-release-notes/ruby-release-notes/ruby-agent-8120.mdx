## v8.12.0

A versão 8.12.0 do agente Ruby oferece uma nova instrumentação do Elasticsearch. A versão 8.12.0 do agente Ruby também aumenta o número padrão de eventos personalizados registrados, anuncia a descontinuação do Ruby 2.3 e traz uma limpeza de código valiosa.

* **Suporte para instrumentação do Elasticsearch**

  Esta versão do agente Ruby adiciona suporte para instrumentar automaticamente a gem [elasticsearch](https://rubygems.org/gems/elasticsearch). As versões 7.x e 8.x são suportadas. [PR#1525](https://github.com/newrelic/newrelic-ruby-agent/pull/1525)

  | Nome da configuração              | Padrão     | Comportamento                                                                                                                             |
  | --------------------------------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
  | `instrumentation.elasticsearch`   | auto       | Controla a instrumentação automática da biblioteca elasticsearch na inicialização. Pode ser um de `auto`, `prepend`, `chain`, `disabled`. |
  | `elasticsearch.capture_queries`   | verdadeiro | Se `true`, o agente captura a consulta do Elasticsearch no rastreamento da transação.                                                     |
  | `elasticsearch.obfuscate_queries` | verdadeiro | Se `true`, o agente ofusca a consulta do Elasticsearch no rastreamento da transação.                                                      |

* **Aumento do limite de eventos personalizados**

  Esta versão do agente Ruby aumenta o limite padrão de eventos personalizados de 1.000 eventos por minuto para 3.000 eventos por minuto. Se os seus eventos personalizados estavam sendo limitados, essa alteração permitirá que mais eventos personalizados sejam enviados para a New Relic. Há também um novo limite máximo configurável de 100.000 eventos por minuto. Para alterar os limites, consulte a documentação para [max\_samples\_stored](https://docs.newrelic.com/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration/#custom_insights_events-max_samples_stored). Para saber mais sobre a mudança e como determinar se eventos personalizados estão sendo descartados, consulte nossa [postagem](https://support.newrelic.com/s/hubtopic/aAX8W0000008dby/send-more-custom-events-with-the-latest-apm-agents) no Explorers Hub. [PR#1541](https://github.com/newrelic/newrelic-ruby-agent/pull/1541)

* **Descontinuar o suporte para Ruby 2.3**

  O Ruby 2.3 atingiu o fim da vida útil em 31 de março de 2019. O agente Ruby descontinuou o suporte para o Ruby 2.3 e fará alterações de quebra para esta versão em sua próxima versão principal, v9.0.0 (data de lançamento ainda não planejada). Todas as versões 8.x.x do agente permanecerão compatíveis com o Ruby 2.3.

* **Limpeza: remover código órfão**

  Tanto no agente quanto nos testes de unidade, ocorreram mudanças ao longo dos anos que deixaram certos trechos de código inacessíveis. Esse código órfão pode complicar a manutenção e a refatoração do código, portanto, resolvê-lo pode ser muito útil. O membro da comunidade [@ohbarye](https://github.com/ohbarye) contribuiu com dois PRs de limpeza separados para esta versão; um para o agente e outro para os testes. [PR#1537](https://github.com/newrelic/newrelic-ruby-agent/pull/1537) [PR#1548](https://github.com/newrelic/newrelic-ruby-agent/pull/1548)

  Agradecemos a [@ohbarye](https://github.com/ohbarye) por contribuir com esta limpeza útil!

## Declaração de apoio

A New Relic recomenda atualizar o agente Ruby regularmente e, no mínimo, a cada 3 meses. A partir desta versão, a versão mais antiga suportada é a [6.7.0.359](https://docs.newrelic.com/docs/release-notes/agent-release-notes/ruby-release-notes/ruby-agent-670359).
