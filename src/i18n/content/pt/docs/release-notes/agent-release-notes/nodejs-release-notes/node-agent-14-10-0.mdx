### Recurso

* Adicionado suporte para `@opentelemetry/api@1.10.0` ([#4392](https://github.com/newrelic/node-newrelic/pull/4392)) ([504490d](https://github.com/newrelic/node-newrelic/commit/504490dd9540e6d5312441d9feec29b47bfe959a))

  * Para os clientes que usam diretamente o `@opentelemetry/api-logs`, é necessário remover e atualizar para usar o `@opentelemetry/api` 1.10.0+. Consulte o [changelog da API do OpenTelemetry](https://github.com/open-telemetry/opentelemetry-js/blob/main/api/CHANGELOG.md#1100) para obter mais informações.
  * Os clientes que registram instrumentação de terceiros para bibliotecas de logging devem atualizar para o seguinte: `@opentelemetry/instrumentation-pino` para 0.70.0+, `@opentelemetry/instrumentation-bunyan` para 0.69.0+, `@opentelemetry/instrumentation-console` para 0.6.0+, ou `@opentelemetry/instrumentation-winston` para 0.69.0+
