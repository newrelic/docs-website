## Notas

#### Recurso

* Adicionado `ai_monitoring.basic_telemetry.enabled` e habilitado o AI Monitoring básico por padrão ([#4330](https://github.com/newrelic/node-newrelic/pull/4330)) ([c126335](https://github.com/newrelic/node-newrelic/commit/c1263354150cd30349d316acc162f5388bc3449a))

  * A instrumentação de LLM agora está ativada por padrão e envia `Llm*` eventos personalizados, spans e métricas (sem o conteúdo da mensagem), a menos que configurada de outra forma. Para desativar, defina `ai_monitoring.basic_telemetry.enabled` como `false` em `newrelic.js`, ou defina a variável de ambiente `NEW_RELIC_AI_MONITORING_BASIC_TELEMETRY_ENABLED` como `false`.
  * `ai_monitoring.enabled` e a variável de ambiente `NEW_RELIC_AI_MONITORING_ENABLED` foram descontinuadas e serão removidas em uma versão principal futura, mas definir qualquer uma delas como false também cancela a adesão.
