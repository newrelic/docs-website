### Novo recurso

* Aumento do limite de eventos personalizados
  * Esta versão aumenta o limite padrão de eventos personalizados de 10.000 eventos por minuto para 30.000 eventos por minuto. No cenário em que os eventos personalizados estavam sendo limitados, essa alteração permitirá que mais eventos personalizados sejam enviados para a New Relic. Há também um novo limite máximo configurável de 100.000 eventos por minuto. Para alterar os limites, consulte [a documentação para max\_samples\_stored](https://docs.newrelic.com/docs/apm/agents/net-agent/configuration/net-agent-configuration/#custom_events). Para saber mais sobre a mudança e como determinar se eventos personalizados estão sendo descartados, consulte [nossa postagem no Explorers Hub](https://support.newrelic.com/s/hubtopic/aAX8W0000008dby/send-more-custom-events-with-the-latest-apm-agents). [#1284](https://github.com/newrelic/newrelic-dotnet-agent/pull/1284)
