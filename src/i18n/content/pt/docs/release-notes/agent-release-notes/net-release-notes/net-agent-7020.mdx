### Novo recurso

* A modificação de arquivos XML de instrumentação personalizada agora pode ser realizada sem a necessidade de reiniciar o aplicativo monitorado. As atualizações de instrumentação serão aplicadas &quot;dinamicamente&quot; em tempo de execução. Este recurso exigia funcionalidades fornecidas por novas APIs introduzidas no .NET framework 4.5 e mais recentes, que esta versão também aborda (consulte a seção &quot;Suporte a framework&quot; abaixo).

### Correções

* Boletim de segurança [NR18-04](https://docs.newrelic.com/docs/accounts-partnerships/welcome-new-relic/security-bulletins/security-bulletin-nr18-04): corrige o problema em que as mensagens de erro não eram totalmente filtradas dos traces de erro e eventos de erro quando o modo de alta segurança estava ativado.
* Corrigido um problema com o monitoramento de Browser automático que poderia causar uma exceção de estouro de stack.
* Para instrumentação personalizada, o parâmetro metricName será respeitado sem a necessidade de definir transactionNamingPriority.
* O instalador programável agora será instalado e desinstalado com sucesso em cenários onde há um espaço no caminho para os arquivos de instalação.

### Suporte a framework

* Esta versão do agente remove o suporte para versões do .NET framework anteriores à 4.5. Recomendamos consultar a nossa [postagem na comunidade](https://support.newrelic.com/s/hubtopic/aAX8W0000008ZIo/net-agent-security-enhancements-and-legacy-framework-deprecation) sobre isso de novembro do ano passado, para obter mais detalhes.
* Isso não representa o fim da vida útil dos agentes 6.x (que oferecem suporte a frameworks .NET mais antigos), os quais continuarão a funcionar e a reportar para a New Relic.

### Atualização

* Siga os procedimentos padrão para [atualizar o agente .NET](/docs/agents/net-agent/installation-configuration/update-net-agent).
* Se estiver atualizando a partir de um agente particularmente antigo, revise a lista de principais alterações e procedimentos para [atualizar o agente .NET legado](/docs/agents/net-agent/troubleshooting/upgrade-legacy-net-agents).
