### Novo recurso

* O código que o profiler injeta no aplicativo agora armazena em cache suas pesquisas no agente com um cache sem bloqueio, em vez de resolver cada chamada por reflexão, resultando em menor sobrecarga do agente para aplicativos .NET. ([#3709](https://github.com/newrelic/newrelic-dotnet-agent/issues/3709)) ([4c7797c](https://github.com/newrelic/newrelic-dotnet-agent/commit/4c7797c45b98cbdd1e8c4652edffabc259a04106))

### Correções

* Evita a contaminação cruzada de transação no HybridHttpContextStorage ([#3754](https://github.com/newrelic/newrelic-dotnet-agent/issues/3754)) ([2d04565](https://github.com/newrelic/newrelic-dotnet-agent/commit/2d045657d8114ff5c4888a7cef5f369f99b82f82))
* Libera a transação do cliente WCF retida quando o resultado assíncrono é concluído antes da troca do retorno de chamada ([#3772](https://github.com/newrelic/newrelic-dotnet-agent/issues/3772)) ([3ef02f3](https://github.com/newrelic/newrelic-dotnet-agent/commit/3ef02f376163fe74c81b1c97e5cf39cfb016dfd5))
* Ignora a injeção de comentário de metadados SQL para CommandType.StoredProcedure ([#3756](https://github.com/newrelic/newrelic-dotnet-agent/issues/3756)) ([59b92ea](https://github.com/newrelic/newrelic-dotnet-agent/commit/59b92ea2ef9d787d99a5151d6cb8df6df1a86298))

### Atualizando seu agente

* Siga os procedimentos padrão para [atualizar o agente .NET](/docs/agents/net-agent/installation-configuration/update-net-agent).
* Se você estiver usando um agente particularmente antigo, revise a lista de principais alterações e procedimentos para [atualizar o legado .NET agente](/docs/apm/agents/net-agent/installation/update-net-agent/#updating_older_net).

Recomendamos atualizar para a versão mais recente do agente assim que estiver disponível. Se você não puder atualizar para a versão mais recente, atualize seu agente para uma versão com no máximo 90 dias. Saiba mais sobre [como manter seu agente atualizado](/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent). Consulte o New Relic [documento de política de fim de vida útil](/docs/apm/agents/net-agent/getting-started/net-agent-eol-policy) do agente .NET do para obter informações sobre lançamentos e datas de suporte do agente.
