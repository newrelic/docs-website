## Agente PHP da New Relic v12.12.0.41

### Correções de bugs

* Corrigir a recuperação do nome da coleção e do banco de dados do MongoDB para as versões 1.21.4 e 2.4.1 e posteriores da biblioteca MongoDB. ([#1301](https://github.com/newrelic/newrelic-php-agent/pull/1301))
* Corrige uma corrida de dados na coleta de métricas do daemon que poderia causar falha no daemon quando vários agentes se reportam a um único daemon. ([#1310](https://github.com/newrelic/newrelic-php-agent/pull/1310))
* Passar `E_DONT_BAIL` para o manipulador de erros do PHP para que os destrutores sejam executados após uma exceção não capturada. ([#1317](https://github.com/newrelic/newrelic-php-agent/pull/1317))
* Mantenha uma referência ao retorno de chamada passado para `newrelic_set_error_group_callback()` para evitar uma falha ou um nome de grupo de erros incorreto. ([#1329](https://github.com/newrelic/newrelic-php-agent/pull/1329))
* Remover o tempo de início do comando Predis assim que a resposta for lida. ([#1315](https://github.com/newrelic/newrelic-php-agent/pull/1315))

### Atualizações de segurança

* Atualizar a versão do Go usada para compilar o daemon para 1.27.3. ([#1304](https://github.com/newrelic/newrelic-php-agent/pull/1304), [#1320](https://github.com/newrelic/newrelic-php-agent/pull/1320), [#1336](https://github.com/newrelic/newrelic-php-agent/pull/1336))

<Callout variant="important">
**Para instalação usando uma versão ou plataforma PHP não suportada, é altamente recomendável que você desabilite os mecanismos de atualização automática para os pacotes PHP do agente.** Isso pode ser feito adicionando os pacotes do agente PHP a uma lista de exclusão para atualizações de pacotes. Ou você pode fazer o versionamento do pacote PHP do agente para uma versão do agente que suporte os recursos antigos e sem suporte. A falha em impedir atualizações pode resultar na instalação de uma versão mais recente do agente e na remoção do suporte para o recurso necessário e não suportado. Isso interromperia a coleta de dados do APM.

Os pacotes do agente PHP afetados são:

* newrelic-php5
* newrelic-php5-common
* daemon-newrelic
</Callout>
