### Avisos de Fim de Vida

* O suporte para PHP 5.3 e PHP 5.4 no agente PHP da New Relic foi descontinuado e será removido em uma versão futura. A New Relic recomenda fortemente a atualização para uma [versão suportada do PHP](https://www.php.net/supported-versions.php) — 7.3 ou superior a partir da data deste lançamento. Para continuar executando o agente PHP da New Relic com o PHP 5.3 e 5.4, recomendamos usar a versão 9.15 do agente para máxima compatibilidade. No entanto, é importante notar que podemos oferecer apenas suporte limitado neste caso.
* Esta versão marca o último agente PHP do New Relic oficialmente suportado para o CentOS 5.
* As compilações para MacOS do agente PHP da New Relic não serão mais fornecidas, e a compatibilidade nas plataformas MacOS não será mais garantida.
* Para obter mais informações sobre esses avisos de EOL, consulte nossa [publicação no Explorers Hub](https://support.newrelic.com/s/hubtopic/aAX8W0000008bKn/important-upcoming-changes-to-capabilities-across-browser-php-python-mobile).

### Novo recurso

* [Foi adicionado suporte para Laminas 3.x.](https://github.com/newrelic/newrelic-php-agent/pull/36)
* [Foi adicionado suporte para Laravel Lumen 6.x, 7.x e 8.x](https://github.com/newrelic/newrelic-php-agent/pull/38)
* [Foi adicionado suporte experimental para excluir subcaminhos da instrumentação do Wordpress.](https://github.com/newrelic/newrelic-php-agent/pull/37) Isso diminui a sobrecarga geral da instrumentação do Wordpress, pois reduz o número de arquivos sendo instrumentados, mas à custa de perder a visibilidade do código nos subcaminhos excluídos. Isso pode ser ativado usando a configuração do arquivo ini `newrelic.framework.wordpress.hooks_skip_filename`.

### Correções de bugs

* [Representação de string corrigida dos nomes dos parâmetros arginfo](https://github.com/newrelic/newrelic-php-agent/pull/23). Obrigado @TysonAndre por esta contribuição.

### Declaração de apoio

* A New Relic recomenda que você atualize o agente regularmente e, no mínimo, a cada 3 meses. A partir desta versão, a versão mais antiga suportada é a [8.4.0](https://docs.newrelic.com/docs/release-notes/agent-release-notes/php-release-notes/php-agent-840231).
