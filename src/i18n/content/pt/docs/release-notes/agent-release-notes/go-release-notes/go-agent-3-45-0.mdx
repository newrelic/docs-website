## 3.45.0

### Adicionado

* Adicionada nova integração nrecho-v5. Observe que as versões principais anteriores (v3,v4) ainda estão disponíveis em suas respectivas pastas
* Adicionada nova integração nrgemini, na qual o pacote GenAI é instrumentado
* Adicionado suporte para continuous profiling   \* NOTA: o Continuous Profiling é um novo recurso que ainda não está disponível para uso geral. O código do componente do lado do agente agora está presente no agente, mas para realmente usá-lo antes do lançamento em Disponibilidade Geral, será necessário entrar em contato com seu representante de vendas da New Relic para participar do preview antecipadamente

### Fixo

* Corrigido um bug em que as mensagens de LLM eram truncadas incorretamente

### Segurança

* Atualizações de segurança do Dependabot

  * Atualizado grpc de 1.82.1 para 1.83.1 em v3/integrations/nrgrpc e /v3
  * Atualizado amqp091-go de 1.9.0 para 1.13.0 em v3/integrations/nramqp
  * Atualizado echo/v4 de 4.9.0 para 4.15.3 em v3/integrations/nrecho-v4

### Declaração de apoio

Usamos a versão mais recente da linguagem Go. No mínimo, você não deve usar nenhuma versão do Go mais antiga do que aquela suportada pela própria equipe do Go. Consulte a [Política de EOL do agente Go](https://docs.newrelic.com/docs/apm/agents/go-agent/get-started/go-agent-eol-policy/) para obter detalhes sobre versões com suporte do agente Go e componentes de terceiros.
