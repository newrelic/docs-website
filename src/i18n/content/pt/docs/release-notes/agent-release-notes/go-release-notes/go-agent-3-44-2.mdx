## 3.44.2

### Adicionado

* `aws.lambda.eventSource.eventType` suporte a atributo para a integração `nrlambda`

### Fixo

* `TransactionTrace` correções

  * `backtrace` exibe corretamente na interface -&gt; Corrigido um problema em que os backtraces não eram exibidos corretamente no NR1
  * `timestamp` não mais nulo -&gt; Corrigido um problema em que o timestamp sempre era exibido como nulo
  * `exclusive_duration_millis` não é mais nulo -&gt; Corrigido um problema em que `exclusive_duration_millis` sempre era exibido como nulo

### Segurança

* Atualizações de segurança do Dependabot

  * `nrgrpc` atualizar google.golang.org/grpc para 1.82.1
  * `nrconnect` aumente golang.org/x/net para 0.55.0

### Declaração de apoio

Usamos a versão mais recente da linguagem Go. No mínimo, use uma versão do Go que a equipe do Go ainda suporte. Consulte a [Política de EOL do agente Go](/docs/apm/agents/go-agent/get-started/go-agent-eol-policy) para obter detalhes sobre as versões compatíveis do agente Go e de componentes de terceiros.
