## 2.16.1

### O agente Go v3.0 da New Relic está atualmente disponível para revisão e testes beta. O uso deste pré-lançamento é por conta e risco do usuário. A New Relic isenta-se de todas as garantias, expressas ou implícitas, em relação à versão beta.

### Caso não sejam tomadas medidas manuais para utilizar a nova pasta v3, conforme descrito abaixo, nenhuma alteração será observada no agente.

Esta versão 2.16.1 inclui uma nova pasta v3.0 que contém o pré-lançamento do agente Go v3.0; o agente Go v3.0 inclui alterações incompatíveis. Solicitamos feedback e esperamos que as alterações sejam analisadas e testadas antes do lançamento oficial.

**Esta não é uma versão 3.0 oficial, é apenas um meio para coletar feedback sobre as alterações propostas**. Não possui a tag 3.0 no Github e a versão 3.0 ainda não está disponível para atualização no arquivo Go mod. Para testar essas alterações, será necessário clonar este repositório no diretório de origem Go, em `[go-src-dir]/src/github.com/newrelic/go-agent`. Após fazer o checkout da origem, será necessário seguir as etapas na segunda seção de [v3/MIGRATION.md](https://github.com/newrelic/go-agent/blob/master/v3/MIGRATION.md).

Uma lista de alterações e instruções de instalação está incluída na pasta v3 e pode ser encontrada [aqui](https://github.com/newrelic/go-agent/blob/master/v3/MIGRATION.md)

Para esta versão de pré-lançamento (beta) do agente Go v3.0, solicita-se observar:

* As alterações na pasta v3 representam o que esperamos lançar em \{&apos;-&apos;}2 semanas como a nossa principal versão 3.0. No entanto, como estamos solicitando feedback sobre as alterações e existe a possibilidade de algumas alterações de quebra antes do lançamento oficial.
* Esta não é uma versão 3.0 oficial; ela não possui a tag 3.0 no Github e a versão 3.0 ainda não está disponível para atualização no arquivo Go mod.
* Caso estas alterações sejam testadas e sejam encontrados problemas, dúvidas ou haja comentários a serem repassados, solicita-se a abertura de um problema [aqui](https://github.com/newrelic/go-agent/issues/new) e a inclusão do rótulo `3.0`.
  * Para casos normais (não 3.0) de problemas/dúvidas, solicitamos que sejam relatados por meio do nosso [site de suporte](http://support.newrelic.com/) ou do nosso [fórum da comunidade](https://support.newrelic.com/s/). Solicita-se que apenas dúvidas relacionadas à versão de pré-lançamento 3.0 sejam relatadas diretamente pelo GitHub.

### Novo recurso

* A V3 adicionará suporte para Go Modules. Os arquivos go.mod existem na pasta v3, mas não poderão ser utilizados até que a tag da versão 3.0 seja totalmente aplicada de forma oficial. Exemplos de tag de versão que se planeja usar para diferentes módulos incluem:

  * `v3.0.0`
  * `v3/integrations/nrecho-v3/v1.0.0`
  * `v3/integrations/nrecho-v4/v1.0.0`

### Alterações

* As alterações são aquelas sobre as quais solicitamos feedback anteriormente [nesta issue](https://github.com/newrelic/go-agent/issues/106).
* Uma lista completa das alterações incluídas, juntamente com uma lista de verificação para atualização, está disponível em [v3/MIGRATION.md](https://github.com/newrelic/go-agent/blob/master/v3/MIGRATION.md).
