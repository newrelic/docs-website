## Novidades

### Autopilot: investigações mais rápidas e confiáveis

* **Investigações mais rápidas:** o Autopilot agora despacha etapas em paralelo, para que você obtenha um tempo de resposta mais rápido e menos tempos limite, especialmente em requests que se desdobram em várias subinvestigações.
* **Roteamento de caminho rápido:** você obterá respostas instantâneas em requests simples. Um novo mecanismo de caminho rápido reconhece perguntas diretas e ignora etapas desnecessárias, para que você veja uma resposta mais rapidamente.
* **Salvar memória na thread:** diga ao Autopilot no chat para salvar informações na memória e ele adicionará automaticamente esse contexto à memória de longo prazo.
* **Cópia de NRQL com um clique:** copie as consultas NRQL geradas diretamente para a sua área de transferência com um único clique no painel de chat.
* **Expansão do chat com um clique:** maximize instantaneamente o painel de chat com um único clique para obter um espaço de trabalho maior e organizado.
* **Atalhos de navegação de consulta:** navegue e selecione novamente as consultas anteriores usando as teclas de seta para cima (↑) e para baixo (↓) na caixa de prompt.
* **Respostas mais confiáveis:** corrigimos vários problemas para melhorar as investigações e fornecer respostas mais completas. Agora você receberá uma mensagem clara se atingir seu limite de uso por hora em vez de um erro bruto, e corrigimos um problema raro em que uma investigação poderia parecer concluída antes de realmente terminar.

### Atualizações de capacidade de integração do GitHub MCP (pré-visualização pública)

<Callout title="visualização">
  Ainda estamos trabalhando nesse recurso, mas adoraríamos que você experimentasse!

  Atualmente, esse recurso é fornecido como parte de um programa de visualização de acordo com nossas [políticas de pré-lançamento](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy).
</Callout>

**GitHub Enterprise Cloud agora é suportado:** a integração do GitHub MCP agora funciona com o GitHub Enterprise Cloud, além do GitHub público. Se a sua organização usa uma instância `YOURSUBDOMAIN.ghe.com`, conecte-a ao Autopilot usando o mesmo fluxo PAT. A única nova etapa é inserir o URL do seu subdomínio GHE durante a configuração. Ambos os casos de uso de investigação funcionam em `GHE.com`: identificação de causa raiz acionada por alteração e pesquisa manual de PR/commit.

Ambientes suportados do GitHub:

| Tipo de conexão         | Formato de URL          | Disponibilidade              |
| ----------------------- | ----------------------- | ---------------------------- |
| GitHub público          | `github.com`            | Pré-visualização (desde 2.1) |
| GitHub Enterprise Cloud | `YOURSUBDOMAIN.ghe.com` | Preview — Novo no 2.2        |

**Alteração de configuração para usuários do `GHE.com`:** ao conectar o GitHub em **Configure &gt; Autopilot &gt; External MCP connections**, insira `YOURSUBDOMAIN.ghe.com` no campo de URL do GitHub em vez de `github.com`. As permissões do PAT permanecem inalteradas: pull requests: Read, Contents: Read, metadados: Read. Se a sua organização `GHE.com` exigir SAML SSO, autorize o PAT para SSO no GitHub antes de inseri-lo no New Relic — um token não autorizado falha com `403` no primeiro uso.

**Defina o escopo do seu PAT para os repositórios que você rastreia ativamente:** o Autopilot lê as descrições de PR e os metadados de alteração de arquivo de cada repositório que o token autoriza.
