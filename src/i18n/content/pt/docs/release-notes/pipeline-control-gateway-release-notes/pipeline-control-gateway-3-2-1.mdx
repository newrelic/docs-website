### Correções de bugs

* Corrigido um problema em que o agente APM Python registrava um erro de decodificação JSON a cada coleta ao enviar dados pelo gateway, o que causava logs duplicados e perda de dados de erro. O gateway agora responde aos requests de dados do agente APM com HTTP `202 Accepted` e um corpo vazio, conforme especifica o protocolo do agente.
* Corrigido um problema em que eventos de span de agentes APM eram registrados com o horário em que o gateway os recebeu, em vez do horário de início do span.

### Atualizações de segurança

* A dependência `golang.org/x/net` foi atualizada para `v0.62.0` para resolver vulnerabilidades de gravidade alta e média.
