## Notas

* Adicionado suporte para instâncias gerenciadas do AWS Lambda (LMI).
* `Updated NEW_RELIC_LABELS` configuração para suportar a propagação de atributo de transação e span.
* Adicionado suporte para `NEW_RELIC_DATA_COLLECTION_TIMEOUT` e `NEW_RELIC_HTTP_TIMEOUT` para o modo serverless
* Adicionado `entity.name` para logs

## Fixo

* Corrigido o tempo de envio de telemetria para enviar as cargas do agente imediatamente após a chegada, em vez de aguardar para emparelhar com `platform.report`
* Desativados os padrões smithy rustls legados
