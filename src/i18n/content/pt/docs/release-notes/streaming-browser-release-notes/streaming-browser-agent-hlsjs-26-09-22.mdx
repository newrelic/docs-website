### Novo recurso

* **Exportação de subcaminho`/browser`:** um ponto de entrada `@newrelic/video-hls/browser` agora está disponível, que exclui o código não utilizado do Vega/dispositivo conectado, reduzindo o tamanho do pacote para os consumidores do navegador. Um shim de sistema de arquivos `browser.js` também está incluído para empacotadores que não respeitam o campo `exports`.
* **Exportação nomeada:** `{ HLSTracker }` agora está disponível como uma exportação nomeada junto com a exportação padrão existente nos pontos de entrada raiz e `/browser`.

### Melhorias

* **`@newrelic/video-core` atualizado para 5.1.0**, que inclui arquivos de declaração do TypeScript, correções de bugs upstream e patches de dependência.
