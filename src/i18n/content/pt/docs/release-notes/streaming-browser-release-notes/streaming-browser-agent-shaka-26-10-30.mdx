### Mudado

* **Video Core:** Atualizamos a dependência `@newrelic/video-core` empacotada para a v5.1.1 e a fixamos nesta versão exata (anteriormente `^5.0.1`), para que cada build use a mesma versão do núcleo.
* **Fixação de dependência:** `dependencies` e `devDependencies` agora estão fixados nas versões exatas já resolvidas em `package-lock.json`, portanto, uma nova instalação não obtém mais as versões recém-publicadas das ferramentas de build.
