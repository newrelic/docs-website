### Correções de bugs

* Corrigido o `getSrc()` que retornava a URL temporária `blob:` do navegador em vez da URL real do manifesto assim que a reprodução HLS era iniciada. O rastreador agora lê a URL da instância subjacente do Hls.js, de modo que a URL real do manifesto é relatada de forma consistente durante a reprodução.
