### Novo recurso

* **Exportação de subcaminho`/browser`:** Agora está disponível um ponto de entrada `@newrelic/video-caf/browser` que exclui o pipeline de dispositivo conectado não utilizado da dependência `@newrelic/video-core` empacotada, mantendo o pacote enxuto. Um shim de sistema de arquivos `browser.js` também está incluído para empacotadores que não respeitam o campo `exports`.
* **Exportação nomeada:** `{ CAFTracker }` agora está disponível como uma exportação nomeada junto com a exportação padrão existente nos pontos de entrada raiz e `/browser`.

### Melhorias

* **`@newrelic/video-core` atualizado para 5.1.0**, que inclui arquivos de declaração do TypeScript, correções de bugs upstream e patches de dependência.
