### Novo recurso

* Adicionado `VegaTracker`, um rastreador HLS.js para dispositivos Amazon Vega (classe Kepler/Fire TV). Importe-o por meio do novo ponto de entrada de subcaminho `@newrelic/video-hls/vega`. `VegaTracker` estende `HLSTracker` e roteia a telemetria pelo pipeline de dispositivos conectados em vez do pipeline do navegador. Disponibilizado como CJS e ESM.

### Correções de bugs

* Corrigido o nome do rastreador relatado por `VegaTracker` de `'vega-hls'` para `'hls'` para que o atributo `trackerName` nos eventos do New Relic corresponda ao valor esperado.
