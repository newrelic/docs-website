### Novo recurso

* **Suporte ao THEOplayer Web SDK:** versão estável inicial do rastreador THEOplayer da New Relic para ambientes de browser. Importar via `@newrelic/video-theo/browser`.
* **Ponto de entrada do Browser:** subcaminho `@newrelic/video-theo/browser` dedicado que exclui o pipeline Vega/dispositivo conectado para pacotes apenas de browser.
* **Rastreamento de taxa de bits:** relata `contentBitrate`, `contentManifestBitrate`, `contentSegmentDownloadBitrate` e `contentNetworkDownloadBitrate`.
* **Rastreamento da qualidade de representação:** rastreia a altura, a largura e a largura de banda da representação ativa por meio de eventos de mudança de qualidade no nível da faixa.
* **Suporte multiformato:** streams HLS e DASH suportados por meio do streaming adaptativo nativo do THEOplayer.

### Melhorias

* **`@newrelic/video-core` atualizado para 5.1.0**, habilitando retornos de chamada de drenagem de QoE em `sendStart`/`sendEnd` via `getHarvester()`.
* **Nome do player:** o atributo `playerName` é reportado como `THEOplayer`.
* **Tratamento de código de erro:** `errorCode` é omitido dos eventos quando nenhum código fornecido pelo SDK está disponível, evitando valores sentinela sem sentido no NRDB.
