### Novo recurso

* Pacotes nativos agora estão disponíveis para o Debian 13 (Trixie).
* Pacotes nativos agora estão disponíveis para o Windows Server 2025 (LTSC).
* A [imagem Docker do plug-in de saída do Fluent Bit](https://hub.docker.com/r/newrelic/newrelic-fluentbit-output) agora publica uma variante do Windows Server 2025 (LTSC).

### Melhorias e aprimoramentos

* O Fluent Bit foi atualizado para a versão 5.1.5. Para mais detalhes, consulte os [anúncios do Fluent Bit](https://fluentbit.io/announcements/).
* Esta versão inclui o [plug-in de saída New Relic Fluent Bit 3.12.0](https://github.com/newrelic/newrelic-fluent-bit-output/releases/tag/v3.12.0).
* O agente de infraestrutura recomenda o Fluent Bit 5.1.5 em pacotes para Linux e Windows.
* A [imagem Docker do plug-in de saída do Fluent Bit](https://hub.docker.com/r/newrelic/newrelic-fluentbit-output) para Linux usa o Fluent Bit 5.1.5 com o plug-in de saída 3.12.0. As variantes de imagem do Windows incluem o plug-in de saída 3.12.0 e mantêm suas versões existentes do Fluent Bit: 5.1.2 para Windows Server 2022 e 2025, e 4.0.3 para Windows Server 2019.
* O [chart do Helm do New Relic Logging](https://github.com/newrelic/helm-charts/tree/master/charts/newrelic-logging) foi atualizado para a versão 1.44.0 e instala a nova imagem do plug-in.
* Os pacotes do Debian 11 (Bullseye) não são mais compilados porque a distribuição chegou ao fim da vida útil.

### Atualizações de segurança

* A versão do Go foi atualizada para 1.27.3 para correções de CVE, incluindo o bloqueio das chaves de CA intermediária comprometidas da eMudhra.
* A imagem Linux do Docker não confia mais nos certificados raiz emSign ECC Root CA - G3 e AAA Certificate Services.

### Notas

Para se manter atualizado com as correções e melhorias mais recentes, assine nosso [feed RSS de Logs](/docs/release-notes/logs-release-notes/).
