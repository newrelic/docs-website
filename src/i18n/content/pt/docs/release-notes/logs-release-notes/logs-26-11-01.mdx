### Atualizações de segurança

* O [AWS Unified Lambda](https://github.com/newrelic/aws-unified-lambda) foi atualizado para a versão 1.1.5, o que atualiza o Go para 1.27.3 para correções de CVE.
* O [Lambda AWS-log-ingestion](https://github.com/newrelic/aws-log-ingestion) foi atualizado para a versão 2.11.5 para corrigir o [CVE-2026-111064](https://nvd.nist.gov/vuln/detail/CVE-2026-111064) e o [CVE-2026-111066](https://nvd.nist.gov/vuln/detail/CVE-2026-111066). Esta versão atualiza a biblioteca aiohttp para 3.14.5 e o yarl para 1.25.1, junto com as dependências relacionadas.
* O [AWS\_s3\_log\_ingestion\_lambda](https://github.com/newrelic/aws_s3_log_ingestion_lambda) foi atualizado para a versão 1.4.4 para corrigir dependências vulneráveis do certifi. Esta versão atualiza a biblioteca certifi para 2026.10.23, junto com as dependências relacionadas.
