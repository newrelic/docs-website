### Melhorias e aprimoramentos

* A biblioteca aiohttp foi atualizada para &gt;= 3.14.4 e a urllib3 para &gt;= 2.8.0.

### Atualizações de segurança

* Com a versão mais recente (v1.4.5), as seguintes CVEs foram corrigidas no Lambda de ingestão de logs do AWS S3 (NewRelic-log-ingestion-s3): GHSA-2g87-pp6c-29x5, CVE-2026-111066, CVE-2026-111064 (aiohttp) e CVE-2026-97689, CVE-2026-97687 (urllib3).
