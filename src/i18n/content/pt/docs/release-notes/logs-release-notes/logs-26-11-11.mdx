### Alteração de compatibilidade

O [modelo do Dataflow do Google Cloud Pub/Sub para o New Relic](https://github.com/newrelic-forks/DataflowTemplates) foi atualizado para o Apache Beam 2.77.0, mantendo-o em um SDK com suporte do GCP. A compilação e a execução do modelo requerem o Java 11 ou posterior. Se você usa o Java 8 para compilar ou executar o modelo, é necessário atualizar o seu JDK antes de usar a versão atualizada.
