### Novo recurso

* Adicionado suporte ao gerenciador de pacote Swift.
* `NRMediaTailorTracker`: adicionado um novo rastreador de inserção de anúncios no lado do servidor (SSAI) do AWS MediaTailor para AVPlayer (iOS 12+ e tvOS 12+), oferecendo paridade de recurso com `NRIMATracker`.

### Correções de bugs

* `ios-publish`: modificada a lógica de repetição para sobreviver a falhas parciais do pipeline.
