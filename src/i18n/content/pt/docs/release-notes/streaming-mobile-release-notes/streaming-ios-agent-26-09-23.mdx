### ⚠ ALTERAÇÕES CRÍTICAS

* `NRVAVideo.addPlayer()`: agora retorna sem criar um rastreador quando não consegue identificar o tipo de player e nenhum `playerType` explícito foi definido, em vez de usar silenciosamente um rastreador AVPlayer por padrão. Se você passar um objeto de player personalizado ou encapsulado, defina `NRVAVideoPlayerConfiguration.playerType` explicitamente.

### Recurso

* `NRTHEOplayerTracker`: adicionado um novo rastreador para THEOplayer (Dolby OptiView Player) — eventos de ciclo de vida do conteúdo, rastreamento de QoE/representação e mapeamento de erros. Apenas iOS, iOS 13.0+. Disponível via CocoaPods, XCFrameworks e gerenciador de pacote Swift.
