### Correções de bugs

* **ExoPlayer/HLS:** `contentBitrate` sempre reportava `0` para streams HLS. O media3 classifica internamente os carregamentos de segmentos HLS mistos de áudio + vídeo como `TRACK_TYPE_DEFAULT` em vez de `TRACK_TYPE_VIDEO` (ao contrário dos streams DASH e progressivos, que não foram afetados). A lógica de captura de taxa de bits do rastreador era acionada apenas para `TRACK_TYPE_VIDEO`, portanto, os carregamentos HLS nunca preenchiam o campo. `contentBitrate` agora reflete corretamente a taxa de bits real do stream para conteúdo HLS.
