## Atualizações de tarefas

* K8s/AgentControl/Logs - Atualizado para coletar todas as linhas de log ([#267](https://github.com/newrelic/newrelic-diagnostics-cli/pull/267)).

## Novo recurso

* Adicionamos uma nova suíte e as seguintes tarefas para o Controle do agente ([#268](https://github.com/newrelic/newrelic-diagnostics-cli/pull/268)):

  * `onhost-agent-control` suite - Coleta informações sobre logs do agent-control, status, conectividade e recursos no host. Para utilizá-lo, execute `nrdiag -suites onhost-agent-control`.
  * AgentControl/Config/Agent - Detecta o agent-control via PATH, caminhos de instalação conhecidos e fallback de diretório de dados; coleta todos os arquivos YAML de fleet-data e local-data, preservando a estrutura de diretório original para todos os subagentes registrados
  * AgentControl/Config/DirTree - Grava uma árvore de diretórios formatada de todos os caminhos de instalação do agent-control no zip para inspeção de estrutura
  * AgentControl/Agent/Connect - Verifica a acessibilidade TCP/TLS do OpAMP, JWKS e dos endpoints de token OAuth2 (lendo URLs do local\_config.yaml); valida se a chave privada de identidade local é uma chave PKCS8 legível e analisável (RSA, Ed25519 ou ECDSA)
  * AgentControl/agente/Logs - No Linux, coleta logs via `journalctl -u newrelic-agent-control`; no Windows, busca todos os arquivos `*.newrelic-agent-control.log` rotacionados por data do diretório de log padrão
  * AgentControl/agente/StatusServer - Consulta o servidor de status local no host/porta configurado em local\_config.yaml (padrão 127.0.0.1:51200) e salva a resposta JSON no zip de diagnóstico
