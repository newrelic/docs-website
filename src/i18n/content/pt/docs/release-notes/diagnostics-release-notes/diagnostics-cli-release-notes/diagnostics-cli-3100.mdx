## Melhorias

* **`DotNet/Agent/Installed`:** atualizou a tarefa para detectar as DLLs do agente .NET quando `newrelic.config` estiver ausente e habilitou a correspondência sem distinção entre maiúsculas e minúsculas para `newrelic.config`. Anteriormente, um arquivo de configuração ausente impedia a detecção do agente e ignorava as tarefas .NET downstream ([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* **`DotNet/Config/Agent`:** atualizada a tarefa para emitir um aviso em vez de uma falha quando `newrelic.config` estiver ausente ([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* **Configuração do .NET Core:** coleção de arquivos atualizada para coletar e analisar arquivos de configuração específicos do ambiente (como `appsettings.Production.json`). Arquivos não relacionados com padrões de nomenclatura semelhantes (como `myappsettings.json`) não são mais coletados ([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* **Instrumentação personalizada do .NET Core:** tarefas do leitor de XML atualizadas para inspecionar os diretórios `extensions` e `extensions/netcore` do agente, alinhando-se à lógica de resolução de arquivos do profiler ([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* **Logs do agente .NET:** filtragem de logs atualizada para que o limite de 1 dia se aplique exclusivamente aos logs do profiler, preservando os logs do agente dos 7 dias anteriores. Os logs do profiler agora também respeitam a flag `-lastModifiedDate` ([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* **Verificações de versão e EOL do agente .NET:** atualizados os parâmetros de fim de vida útil (EOL) e versão compatível para o agente .NET. Adicionada detecção discreta para as versões 4.7.1, 4.7.2, 4.8 e 4.8.1 do framework .NET e habilitada a coleta de versão para o agente .NET Core ([#273](https://github.com/newrelic/newrelic-diagnostics-cli/pull/273)).
* **Nível de log do agente .NET:** atualizadas as configurações de nível de log para avaliar as definições sem diferenciar maiúsculas de minúsculas, correspondendo ao comportamento de tempo de execução do agente .NET ([#274](https://github.com/newrelic/newrelic-diagnostics-cli/pull/274)).
* **Verificação de TLS do .NET:** validação de registro atualizada para que uma chave `SchUseStrongCrypto` ausente não seja mais sinalizada como um erro, pois as versões compatíveis do framework .NET usam o TLS 1.2 por padrão quando a chave está ausente. Um erro agora é relatado apenas quando a chave existe e está definida com um valor diferente de `1` ([#275](https://github.com/newrelic/newrelic-diagnostics-cli/pull/275)).

## Correções de bugs

* Corrigido um problema em que os uploads para a região de dados do Japão falhavam devido a uma URL de upload não atribuída em builds de lançamento ([#277](https://github.com/newrelic/newrelic-diagnostics-cli/pull/277)).
* Corrigido um problema na validação da variável de ambiente de criação de perfil do framework .NET para verificar corretamente `COR_ENABLE_PROFILING`. Adicionado suporte para `NEW_RELIC_LOG_DIRECTORY` e `NEWRELIC_LOG_DIRECTORY` ao resolver os locais de log do agente .NET ([#272](https://github.com/newrelic/newrelic-diagnostics-cli/pull/272)).
* Corrigido um problema em que valores de variáveis de ambiente contendo sinais de igual (`=`) eram truncados durante a análise ([#272](https://github.com/newrelic/newrelic-diagnostics-cli/pull/272)).
