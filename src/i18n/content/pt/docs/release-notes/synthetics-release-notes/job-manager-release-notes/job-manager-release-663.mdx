<Callout variant="important">
A New Relic verifica a imagem do gerenciador de trabalhos de Sintéticos em busca de vulnerabilidades todos os dias e publica uma versão corrigida todas as quintas-feiras. Cada versão inclui correções para CVEs de sistema operacional e aplicativo identificadas até terça-feira às 18:29 UTC daquela semana. Se identificarmos uma CVE após esse horário, a correção será lançada na versão de quinta-feira da semana seguinte.

Publicamos todas as versões na tag `latest`, para que a localização privada que utiliza `latest` receba as correções automaticamente. Se você utilizar uma tag de versão específica, atualize manualmente para a versão mais recente para obter as correções atuais.

O gerenciador de jobs é lançado separadamente dos runtimes do Ping, da API do Node e do navegador Node. Consulte as notas de lançamento de cada runtime para verificar suas próprias correções.
</Callout>
