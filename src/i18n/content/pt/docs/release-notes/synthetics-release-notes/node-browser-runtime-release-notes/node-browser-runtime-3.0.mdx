### Correções de bugs

* Corrigidos atrasos de clique de 12–30 segundos em aplicativos Angular e Zone.js. A extensão de navegador do Sintéticos agora é carregada via CDP WebSocket (`Extensions.loadUnpacked`) em vez de BiDi (`webExtension.install`). O BiDi do Chrome 153+ introduziu uma verificação &quot;Waiting for pending navigations&quot; após cada clique que travava as respostas em aplicativos com macrotarefas pendentes. A mudança para o CDP mantém o BiDi fora da sessão, restaurando a verificação clássica de navegação `document.readyState` de submilissegundo do ChromeDriver.
