<Callout variant="important">
A New Relic verifica a imagem de tempo de execução do navegador Node em busca de vulnerabilidades todos os dias e publica uma versão corrigida todas as quintas-feiras. Cada versão inclui correções para CVEs de sistema operacional, aplicativo e Chrome identificados até as 18:29 UTC da terça-feira daquela semana. Se identificarmos uma CVE após esse horário, a correção será lançada na versão de quinta-feira da semana seguinte.

Publicamos todas as versões na tag `latest`, que executa o Node.js 22 e a versão estável mais recente do Chrome. As localizações privadas que usam `latest` recebem correções automaticamente. Se você usa uma tag de versão específica, é necessário atualizar manualmente para a versão mais recente para obter as correções atuais.
