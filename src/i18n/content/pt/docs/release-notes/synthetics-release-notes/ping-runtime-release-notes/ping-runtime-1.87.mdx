<Callout variant="important">
A New Relic verifica a imagem de tempo de execução do Ping em busca de vulnerabilidades todos os dias e publica uma versão corrigida todas as quintas-feiras. Cada versão inclui correções para CVEs de sistema operacional e aplicativo identificadas até as 18:29 UTC da terça-feira daquela semana. Se identificarmos uma CVE após esse horário, a correção será lançada na versão de quinta-feira da semana seguinte.

Publicamos todas as versões na tag `latest`, para que a localização privada que utiliza `latest` receba as correções automaticamente. Se você utilizar uma tag de versão específica, atualize manualmente para a versão mais recente para obter as correções atuais.
</Callout>
