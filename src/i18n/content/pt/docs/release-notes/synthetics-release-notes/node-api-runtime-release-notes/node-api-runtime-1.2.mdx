O New Relic verifica a imagem de tempo de execução da API do Node em busca de vulnerabilidades todos os dias e publica uma versão corrigida toda quinta-feira. Cada versão inclui correções para CVEs de sistema operacional e aplicativo identificadas até terça-feira às 18:29 UTC daquela semana. Se identificarmos uma CVE após esse horário, a correção será lançada na versão de quinta-feira da semana seguinte.

Publicamos todas as versões na tag `latest`, que executa o Node.js 22. As localizações privadas que usam `latest` recebem correções automaticamente. Se você utilizar uma tag de versão específica, atualize manualmente para a versão mais recente para obter as correções atuais.
</Callout>
