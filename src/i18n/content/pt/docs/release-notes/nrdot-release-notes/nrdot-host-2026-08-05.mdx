### Recurso

* Caso de uso de host verificado para funcionar com `nrdot-collector:2.0.0`

### Correções de bugs

* Nós de configuração `cumulativetodelta` renomeados para `cumulative_to_delta` após a renomeação do componente em `v0.157.0`<br />O nome original `cumulativetodelta` permanece disponível como um alias obsoleto.
* `system.cpu.logical.count` desabilitado na configuração do host<br />A atualização de `v0.157.0` para `receiver/host_metrics` habilitou esta métrica por padrão. Esta alteração restaura o comportamento anterior.
* Regra de agregação por média `system.cpu.utilization` removida da configuração do host<br />A atualização de `v0.157.0` para `receiver/host_metrics` alterou seu comportamento padrão para agregar `system.cpu.utilization` por média, tornando a regra removida redundante.
