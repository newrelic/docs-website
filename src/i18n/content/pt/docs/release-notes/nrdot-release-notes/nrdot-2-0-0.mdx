## Registro de alterações

Estamos lançando uma versão com quebra de compatibilidade para marcar a remoção de `jmxreceiver` dos manifestos de componentes tanto de `nrdot-collector` quanto de `nrdot-collector-experimental` após sua remoção de `opentelemetry-collector-contrib` em `0.157.0` (consulte a [issue 45740](https://github.com/open-telemetry/opentelemetry-collector-contrib/issues/45740) para referência). O componente era usado exclusivamente pelo caso de uso do [Monitoramento do Kafka](/docs/opentelemetry/integrations/kafka/overview/), que foi adaptado para não depender mais deste receptor. Caso implante `nrdot-collector` com uma configuração personalizada usando `jmxreceiver`, por gentileza, migre seguindo as orientações do [aviso de descontinuação do receptor](https://github.com/open-telemetry/opentelemetry-collector-contrib/tree/v0.156.0/receiver/jmxreceiver#deprecation-notice).

### Recurso

* Atualizou as versões dos componentes otel de v0.156.0 para v0.157.0 (#643)
* Atualizados `nroracledbreceiver` e `nrsqlserverreceiver` para a v0.157.2 (#643)
  * Para a lista de alterações nesses componentes, consulte [o changelog deles](https://github.com/newrelic-forks/opentelemetry-collector-contrib/blob/receiver/nrsqlserverreceiver/v0.157.2/NR_CHANGELOG.md).
* Adicionado o `sqlqueryreceiver` à distribuição `nrdot-collector-experimental`. (#632)

### Correções de bugs

* Removido `receiver/jmxreceiver` de `nrdot-collector` e `nrdot-collector-experimental`. (#635)
  * Este componente foi removido no upstream em `v0.157.0` após sua descontinuação em `v0.145.0`.
* Renomeou os nós de configuração `cumulativetodelta` para `cumulative_to_delta` após a renomeação do componente em `v0.157.0`. (#644)
  * O nome original `cumulativetodelta` permanece disponível como um alias descontinuado.
* Desabilitado `system.cpu.logical.count` na configuração do host. (#647)
  * A atualização de `v0.157.0` para `receiver/host_metrics` ativou esta métrica por padrão. Esta alteração restaura o comportamento anterior.
* Removida a regra de agregação de média de `system.cpu.utilization` da configuração do host. (#646)
  * A atualização de `v0.157.0` para `receiver/host_metrics` alterou seu comportamento padrão para agregar `system.cpu.utilization` por média, tornando a regra removida redundante.
* CVE-2026-56852 (#634)
