## Registro de alterações

Primeiras notas de versão dedicadas ao caso de uso [“Monitoramento de host”](https://github.com/newrelic/nrdot-collector-releases/blob/main/distributions/nrdot-collector/README.md#use-cases), que têm como escopo as alterações relevantes na configuração ou `nrdot-collector`. O [nrdot-collector](https://docs.newrelic.com/docs/release-notes/nrdot-release-notes/nrdot-1-12-0/) continuará a incluir a configuração necessária para viabilizar esse caso de uso. No entanto, com `nrdot-collector` oferecendo suporte a cada vez mais casos de uso, queremos fornecer notas de versão adicionais que sejam mais fáceis de consumir para quem usa o NRDOT para uma finalidade específica, como o Monitoramento de host.
