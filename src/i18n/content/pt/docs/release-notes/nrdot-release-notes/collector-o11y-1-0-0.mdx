### Recurso

* Suporte verificado de observabilidade do Collector para `nrdot-collector:2.8.1` e `opentelemetry-collector-contrib:0.163.2`
* Removido o atributo de recurso `newrelic.service.type` por não ser mais necessário para detecção automática
* Definido `temporality_preference: delta` para evitar conversão desnecessária durante a ingestão
