Quando algo falha em um sistema complexo, a parte mais difícil não é consertá-lo. É descobrir o que isso significa para os negócios e onde procurar primeiro.

O Pathpoint mapeia sua saúde técnica para as jornadas de negócios que seus clientes realmente realizam, como checkout, integração e pagamentos na loja. Em vez de observar uma lista de alertas de serviço, você vê exatamente qual estágio da jornada dos clientes está degradado e qual métrica de negócios está mudando por causa disso.

Quando a latência de pagamento atinge picos, o Pathpoint informa: o estágio de Checkout não está saudável, o abandono de carrinho está aumentando e aqui está qual microsserviço na cadeia de dependência está falhando e qual equipe é a proprietária. O SRE sabe exatamente para onde ir. Os comunicadores de incidentes e as partes interessadas dos negócios sabem o que foi impactado e por que isso é importante, sem esperar em uma chamada de conferência para descobrir.

O Pathpoint está disponível na seção <DNT>**All Capabilities**</DNT> da plataforma New Relic. Selecione <DNT>**Pathpoint**</DNT> para abrir a página <DNT>**Flows**</DNT>.

## Página Flows [#flows-page]

<img title="Pathpoint Flows page" alt="A screenshot showing the Pathpoint Flows page." src="/images/pathpoint-list-view.webp" />

A página <DNT>**Flows**</DNT> é sua base inicial para todos os fluxos configurados em sua conta. Cada linha representa uma jornada de negócios crítica que você configurou para monitorar.

Se nenhum fluxo tiver sido criado ainda, você receberá um prompt para criar o seu primeiro. Consulte [Criar e gerenciar fluxos](/docs/pathpoint/create-manage-flows) para obter mais detalhes.

<Callout title="Observação">
  O Pathpoint mostra os fluxos para a sua conta selecionada no momento. Para ver os fluxos de uma conta diferente, use o menu dropdown da conta na parte superior da tela.
</Callout>

Cada linha na lista representa um fluxo. De relance, você pode ver:

* <DNT>**Health status**</DNT>: o ícone de entidade ao lado do nome do fluxo indica sua saúde atual: verde (saudável), amarelo (aviso), vermelho (crítico) ou cinza (desconhecido).
* <DNT>**Name and tag**</DNT>: o nome do fluxo, com uma tag de categoria opcional (por exemplo, E-Commerce ou Fintech) para ajudar a organizar seus fluxos.
* <DNT>**Stages &amp; their health**</DNT>: o conjunto de estágios que compõem a jornada, mostrados como pílulas. Cada pílula reflete a saúde atual desse estágio. Por exemplo, uma jornada de compra pode mostrar: navegar → adicionar ao carrinho → checkout → pagamento → confirmação → atendimento.
* <DNT>**KPI indicator**</DNT>: passe o mouse sobre o ícone de KPI para ver os KPIs desse fluxo.

Clique em qualquer linha para abrir a visualização Flow, onde você pode ver o status de saúde de cada estágio em detalhes. Consulte [Visualização Flow](/docs/pathpoint/flow-view) para saber mais.

Use os filtros <DNT>**Team**</DNT> e <DNT>**Category**</DNT> na parte superior da lista para restringir os fluxos mostrados. Use a barra de pesquisa para encontrar um fluxo por nome.

Para compartilhar um fluxo, clique no menu <DNT>**...**</DNT> em qualquer linha da página <DNT>**Flows**</DNT> e selecione <DNT>**Share**</DNT>. Isso copia um link permanente do fluxo para a sua área de transferência. Apenas usuários com acesso à conta poderão visualizá-lo.
