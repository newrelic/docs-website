Esta página aborda problemas comuns com a integração da New Relic com o Google Cloud Platform (GCP) e como resolvê-los.

## Nenhum dado aparecendo após a configuração [#no-data]

### Verifique o básico [#no-data-basics]

* Aguarde 5 minutos após concluir a configuração. Os dados levam alguns minutos para chegar.
* Confirme se pelo menos um serviço foi selecionado durante a configuração.
* Verifique se o <DNT>**Stackdriver Monitoring API**</DNT> está habilitado em seu projeto do GCP.

### Integração do Workload Identity Federation [#no-data-wif]

Se a conexão foi feita com a [Workload Identity Federation (WIF)](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation):

* Verifique se todas as cinco [APIs necessárias](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation#step-2) estão ativadas.
* É necessário confirmar se a conta de serviço possui as funções <DNT>**Viewer**</DNT> e <DNT>**Service Usage Consumer**</DNT>.
* Verifique se o papel <DNT>**Workload Identity User**</DNT> foi concedido ao principal do pool na conta de serviço.

### Integração de conta de serviço [#no-data-sa]

Caso tenha se conectado com uma [conta de serviço da New Relic](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account):

* Verifique se o ID da conta de serviço da New Relic aparece no IAM do projeto.
* Confirme se possui as funções <DNT>**Viewer**</DNT> e <DNT>**Service Usage Consumer**</DNT>.
* Se utilizar [restrições de domínio](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account#reqs), certifique-se de que a New Relic seja permitida.

## Erros de autenticação [#auth-errors]

### Reautorizar o New Relic [#reauthorize]

Se observar erros de autenticação de API ao [integrar os serviços do Google Cloud Platform (GCP)](/docs/introduction-google-cloud-platform-integrations) com a New Relic, reautorize a New Relic a usar as APIs do GCP:

1. Vá para <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP**</DNT>.
2. Na página da sua conta do GCP, selecione <DNT>**Reauthorize New Relic**</DNT>.
3. Siga os procedimentos padrão para [conectar os serviços do GCP ao New Relic](/docs/infrastructure/google-cloud-platform-integrations/get-started/connect-google-cloud-platform-services-new-relic).

Se a reautorização não resolver os erros, é possível desvincular a integração e conectar novamente. Consulte as etapas de desvinculação no [guia de conexão](/docs/infrastructure/google-cloud-platform-integrations/get-started/connect-google-cloud-platform-services-new-relic).

Os motivos comuns para esses erros incluem:

* Um usuário revogou manualmente a autorização da New Relic para usar APIs do GCP a partir do aplicativo de gerenciamento de contas do Google.
* A autorização para New Relic usar API do GCP não inclui uma ou mais permissões ([escopos Google OAuth](https://developers.google.com/identity/protocols/googlescopes)) necessárias para consultar uma ou mais API do GCP.
* A autorização para New Relic usar API do GCP expirou.

## Métricas ausentes para um serviço específico [#missing-metrics]

* Confirme se o serviço está habilitado em <DNT>**Infrastructure &gt; GCP &gt; Manage services**</DNT>.
* Verifique se o próprio serviço do GCP está ativo e gerando métricas. Alguns serviços relatam métricas apenas quando estão em uso.
* Caso utilize uma [função personalizada do IAM](/docs/integrations/google-cloud-platform-integrations/get-started/integrations-custom-roles), verifique se possui as permissões específicas para esse serviço.

## Métricas obsoletas ou atrasadas [#stale-metrics]

* Verifique as cotas da API do monitoramento de nuvem do GCP em seu projeto do GCP. Se os limites de taxa estiverem sendo atingidos, a coleta de dados pode ficar mais lenta.
* Para integrações do WIF, verifique se o token da conta de serviço não foi revogado.
* Verifique o dashboard de status da conta em <DNT>**Infrastructure &gt; GCP**</DNT> para ver se há erros reportados.

## Projetos do GCP não visíveis durante a configuração [#no-projects]

* A conta autenticada precisa da permissão `resourcemanager.projects.get` para listar projetos.
* Como alternativa, use a API NerdGraph para vincular projetos por ID sem a necessidade de listá-los.

## Obter mais ajuda [#get-help]

Se nenhuma das opções acima resolver o problema, entre em contato com o suporte da New Relic com:

* Seu ID da conta New Relic.
* O ID do projeto do GCP.
* Qual método de conexão foi usado (WIF ou conta de serviço).
* Quaisquer mensagens de erro vistas na interface.
