Com este método de conexão, o New Relic chama as APIs do projeto GCP usando um ID de conta de serviço gerenciado pelo New Relic e o respectivo par de chaves pública/privada. Não é necessário criar ou gerenciar a conta de serviço ou a respectiva chave privada — basta adicionar o ID da conta de serviço como membro com permissões de visualização no projeto. O New Relic coleta tags e outros atributos sempre que possível usando este método.

<Callout variant="tip">
  Você pode usar o Terraform para automatizar o processo de habilitação da integração na nuvem. Leia como no [site de documentação oficial do Terraform](https://registry.terraform.io/providers/newrelic/newrelic/latest/docs/guides/cloud_integrations_guide).
</Callout>

## Conecte o GCP à New Relic [#connect]

<Callout variant="important">
  Se esta for a primeira vez que o GCP é configurado com o New Relic, é necessário garantir que a API de monitoramento de nuvem esteja ativada para o projeto. É possível fazer isso no [console do Google Cloud](https://console.cloud.google.com/apis/api/monitoring.googleapis.com/).
</Callout>

Para conectar o projeto do Google Cloud à New Relic com autorização de conta de serviço:

1. Vá para <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP**</DNT>. Na página <DNT>**Google Cloud Services**</DNT> integração, selecione <DNT>**Add a GCP account**</DNT>.

2. <DNT>**Choose Authorization Method**</DNT>: selecione <DNT>**Authorize a Service Account**</DNT> e siga as instruções na interface para autorizar o New Relic.

3. <DNT>**Add projects:**</DNT> Selecione os projetos dos quais você deseja que o New Relic receba dados.

4. <DNT>**Select services:**</DNT> Na lista de serviços disponíveis para sua conta do GCP, selecione os serviços individuais dos quais você deseja que o New Relic receba dados ou selecione todos os serviços.

   <Callout variant="tip">
     Esses serviços estão ativados para <DNT>**all**</DNT> dos projetos selecionados na etapa anterior. Após a conclusão do processo de configuração, será possível ajustar os serviços a serem monitorados para cada projeto individualmente.
   </Callout>

5. Para concluir o processo de configuração, selecione <DNT>**Finish**</DNT>.

Caso ocorram erros de autenticação de API, siga os [procedimentos de resolução de problemas](/docs/infrastructure/google-cloud-platform-integrations/troubleshooting/troubleshooting-gcp-integrations).

Novos recursos podem levar alguns minutos para serem detectados e sintetizados como entidades. Para obter mais informações, consulte os [limites do sistema](/docs/data-apis/manage-data/view-system-limits) de integração na nuvem.

## Ver seus dados do GCP [#find-data]

Após a conexão, o New Relic inicia o monitoramento dos dados do GCP em [intervalos de sondagem](/docs/infrastructure/google-cloud-platform-integrations/get-started/view-your-data/polling-intervals-gcp-integrations) regulares, e os dados aparecem na interface do New Relic após alguns minutos. Para saber como visualizar, consultar e explorar os dados — incluindo dashboards, alertas e entidades —, consulte [Visualizar e Consultar os Dados do GCP](/docs/infrastructure/google-cloud-platform-integrations/get-started/view-your-data/view-and-query-your-gcp-data).

## Vincule vários projetos do Google [#connect-multiple]

O processo de configuração permite selecionar mais de um projeto por vez.

Após a primeira configuração, para monitorar projetos adicionais do GCP com a New Relic, repetir o procedimento para [conectar os serviços do GCP](#connect) quantas vezes for necessário.

## Desative ou desvincule as integrações do GCP [#disconnect]

É possível desativar qualquer integração a qualquer momento e ainda manter o projeto do Google conectado à New Relic.

### Desativar um ou mais serviços do GCP [#disable-services]

Para desativar serviços enquanto mantém sua conta do GCP vinculada ao New Relic:

1. Vá para <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; Manage services**</DNT>.
2. Na página <DNT>**Edit GCP account**</DNT> , desmarque a caixa de seleção de cada serviço ativo que você deseja desativar.
3. Salve suas alterações.

### Desconectar e desvincular a conta [#unlink-account]

Para desconectar-se completamente da New Relic, desvincule a conta do GCP. Isso desativa todas as integrações da New Relic associadas a ela. Caso uma função personalizada seja excluída, observe que a função pode servir a propósitos além do acesso à New Relic.

Para um <DNT>**custom user role**</DNT>:

1. Faça login no New Relic e vá para <DNT>**Infrastructure &gt; Integrations &gt; Google Cloud Platform**</DNT>.
2. Vá para <DNT>**IAM &gt; admin &gt; Roles**</DNT>, pesquise a função, selecione-a e selecione <DNT>**DELETE**</DNT>.

Para um <DNT>**standard (non-custom) user role**</DNT>:

1. Faça login no New Relic e vá para <DNT>**Infrastructure &gt; Integrations &gt; Google Cloud Platform**</DNT>.
2. Selecione <DNT>**Manage services**</DNT> para a conta que deseja remover. Copie o valor de <DNT>**User**</DNT> e salve-o.
3. Faça login no [Google Cloud](https://console.cloud.google.com/) e selecione o projeto correto na caixa <DNT>**Select a project**</DNT> .
4. No menu de navegação, selecione <DNT>**IAM &amp; admin &gt; IAM**</DNT>.
5. Pesquise e selecione o valor do usuário que você salvou e selecione <DNT>**REMOVE**</DNT>.

### Limpeza do GCP após a desvinculação [#clean-up]

Para limpar o projeto do GCP após a desvinculação:

1. Abra o console IAM do GCP.
2. Selecione o projeto que deseja desvincular do New Relic e selecione <DNT>**Open**</DNT>.
3. Selecione a conta de serviço usada pelo New Relic.
4. Selecione o ícone <DNT>**Remove**</DNT>.
