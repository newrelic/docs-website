As integrações do Google Cloud Platform (GCP) da New Relic fazem parte da [New Relic Infrastructure](/docs/infrastructure/new-relic-infrastructure/getting-started/introduction-new-relic-infrastructure) e trazem as métricas dos seus serviços na nuvem para o [monitoramento de infraestrutura](/docs/infrastructure), onde é possível consultar dados, criar dashboards e definir alertas junto com o restante da sua telemetria. Caso ainda não tenha uma conta da New Relic, [crie uma](https://newrelic.com/signup) antes de começar.

## Compare as opções de conexão [#connect]

<Callout variant="important">
  \*Os intervalos de sondagem de 1 minuto para integrações WIF estão em visualização limitada e disponíveis apenas para serviços selecionados. Serviços aos quais o WIF oferece suporte atualmente: Managed Service for Apache Kafka, Cloud Dataflow, Cloud Dataproc, Cloud Spanner, Google Kubernetes Engine (GKE), BigQuery, AlloyDB for PostgreSQL, Cloud Load Balancing e Cloud Pub/Sub. Para solicitar acesso, entre em contato com o [suporte da New Relic](https://support.newrelic.com/).
</Callout>

Recomendamos <DNT>**Workload Identity Federation**</DNT> para novas integrações. Ela usa credenciais de curta duração para melhor segurança, abrange um conjunto mais amplo de métricas e coleta automaticamente novas métricas à medida que o GCP as adiciona. Caso já exista uma integração de conta de serviço, ela continuará funcionando — é possível adicionar novos projetos com WIF junto à configuração existente.

<Callout variant="important">
  * **Maior ingestão de dados:** o WIF coleta todas as métricas com disponibilidade geral (GA) e Beta, juntamente com rótulos nativos para serviços do Google Cloud suportados. A ingestão para o mesmo conjunto de serviços é normalmente maior do que com a integração baseada em conta de serviço.
  * **Cobranças da API do Google Cloud:** o Google Cloud cobra as chamadas de API do monitoramento de nuvem feitas pela integração WIF do projeto integrado do Google Cloud. Consulte os [preços da observabilidade do Google Cloud](https://cloud.google.com/products/observability/pricing) para obter detalhes.
</Callout>

Para saber mais sobre as permissões e funções de que a New Relic precisa para monitorar os serviços do GCP, consulte [Integrações e funções personalizadas](/docs/infrastructure/google-cloud-platform-integrations/get-started/integrations-custom-roles).

## Guias de configuração [#setup-guides]

* **Workload Identity Federation (Recomendado)**

  * [Integrar manualmente o projeto/pasta do GCP](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation) — usa credenciais de curta duração para maior segurança
  * [Automatizar com o Terraform](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation-terraform) — automatiza a configuração da WIF usando o Terraform

* [Conta de serviço da New Relic](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account) — usa uma conta de serviço gerenciada pela New Relic

* [Conta de usuário do Google](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-user-account) — usa as credenciais da conta de usuário do Google
