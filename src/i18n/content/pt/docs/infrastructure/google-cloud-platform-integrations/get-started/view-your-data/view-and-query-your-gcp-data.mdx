Após a conclusão do processo de configuração, os dados da conta do Google Cloud Platform são reportados diretamente ao New Relic em [intervalos de sondagem](/docs/infrastructure/google-cloud-platform-integrations/get-started/view-your-data/polling-intervals-gcp-integrations) regulares. Os dados aparecem na interface do New Relic em poucos minutos.

## Ver seus dados do GCP [#view]

Para visualizar seus dados do GCP:

1. Vá para <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities)**</DNT>.
2. Pesquise <DNT>**Google Cloud Platform**</DNT> e selecione o bloco.

Para [encontrar e usar os dados](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), incluindo links para <InlinePopover type="Dashboards" />e configurações de alerta, acesse <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP**</DNT>.

## Consulte seus dados [#query]

É possível visualizar e reutilizar as consultas NRQL tanto no <InlinePopover type="Dashboards" />pré-configurado quanto nos dashboards <DNT>**Events explorer**</DNT>. Isso permite adaptar as consultas às suas necessidades específicas.

Evento, painel e outros dados estão disponíveis para todos os serviços no New Relic.

## Entidades do GCP [#entities]

Os recursos do GCP também aparecem como entidades no explorador de entidades para serviços com suporte total a entidades. Cada entidade tem uma página de resumo com métricas clássicas e um dashboard pré-criado.

Novos recursos podem levar alguns minutos para serem detectados e sintetizados como entidades. Para obter mais informações, consulte [Limites do Sistema de Integração na Nuvem](/docs/data-apis/manage-data/view-system-limits).

## Qual é o próximo [#whats-next]

* Para consultar os nomes de métrica que o New Relic coleta para cada serviço, consulte as [métricas de integração do GCP](/docs/infrastructure/google-cloud-platform-integrations/get-started/gcp-integration-metrics).
* Para entender com que frequência o New Relic sonda os dados, consulte [Intervalos de sondagem para integrações do GCP](/docs/infrastructure/google-cloud-platform-integrations/get-started/view-your-data/polling-intervals-gcp-integrations).
* Se os dados não estiverem aparecendo como esperado, consulte [Solucionar problemas de integração do GCP](/docs/infrastructure/google-cloud-platform-integrations/troubleshooting/troubleshooting-gcp-integrations).
