[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma integração para reportar dados [Google Firebase Storage](https://firebase.google.com/products/storage) para New Relic. Este documento explica como ativar a integração do GCP Firebase Storage e descreve os dados reportados.

## Recurso

O Firebase Storage é o serviço de armazenamento de objetos do Google Cloud para conteúdo gerado pelo usuário em aplicativos do Firebase, com o suporte de buckets do Cloud Storage. A integração do Firebase Storage com a New Relic coleta a métrica de avaliação de regras de segurança do Firebase Storage para cada bucket.

## Ativar integração [#activate]

Para habilitar a integração, é necessário seguir os procedimentos padrão para [conectar o serviço do GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conecte-se com a Workload Identity Federation (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar com conta de serviço ou conta de usuário](/docs/connect-google-cloud-platform-services-infrastructure)

## Frequência de votação [#polling]

As integrações do New Relic consultam os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem para o Google Firebase Storage é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Após habilitar a integração, os buckets do Firebase Storage aparecem como entidades no explorador de entidades do New Relic. Para ver dashboards e gerenciar serviços, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas as métricas do Firebase Storage disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`. Consulte a [documentação de métricas do Firebase Storage do Google](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-firebasestorage) para obter a lista completa.
