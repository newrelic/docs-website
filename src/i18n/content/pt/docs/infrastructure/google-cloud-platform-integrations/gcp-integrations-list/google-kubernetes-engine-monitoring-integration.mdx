[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma integração para reportar dados [Google Kubernetes Engine](https://cloud.google.com/kubernetes-engine/) (GKE) para New Relic. Este documento explica como ativar a integração do GCP Kubernetes Engine e descreve os dados que ela reporta.

## Recurso

O Google Kubernetes Engine é o serviço gerenciado de Kubernetes do Google Cloud. A integração do GKE com o New Relic coleta métricas de CPU, memória, rede, volume e tempo de operação nos contêineres, nós e pods que compõem os clusters.

## Ativar integração [#activate]

Para habilitar a integração, é necessário seguir os procedimentos padrão para [conectar o serviço do GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conecte-se com a Workload Identity Federation (recomendado)](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation)
* [Conectar com conta de serviço ou conta de usuário](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account)

## Frequência de votação [#polling]

As integrações do New Relic consultam os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem para o Google Kubernetes Engine é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

<Callout variant="important">
  **Recomendado: usar a integração do Kubernetes da New Relic para GKE.** Com a Workload Identity Federation, a integração do GCP coleta métricas do GKE, mas não cria entidades. Para observabilidade total do GKE — entidades de cluster, nó, pod e contêiner, dashboards e alertas —, instale a [integração do Kubernetes da New Relic](https://docs.newrelic.com/docs/kubernetes-pixie/kubernetes-integration/installation/kubernetes-integration-install-configure/) no cluster GKE.

  O Google Kubernetes Engine (GKE) suporta intervalo de sondagem de 1 minuto para integração do WIF em visualização limitada. Para solicitar acesso, entre em contato com o [suporte da New Relic](https://support.newrelic.com/).
</Callout>

## Conta de serviço ou conta de usuário [#service-account]

### Encontre e use dados [#find-data]

Após ativar a integração e aguardar alguns minutos (com base na [frequência da votação](#polling)), os dados aparecerão na interface do New Relic . Para [encontrar e usar seus dados](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), incluindo links para seu <InlinePopover type="dashboards" />e configurações de alerta, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

Os dados que New Relic recebe de sua integração no Google Kubernetes Engine incluem os seguintes dados métricos. Para obter mais informações sobre essas métricas, consulte a documentação do Google sobre [métricas para Kubernetes Engine](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-container).

### GcpKubernetesContainerSample [#GcpKubernetesContainer]

O New Relic recebe os seguintes dados da sua integração do GCP Kubernetes Engine e os reporta para um tipo de evento `GcpKubernetesContainerSample` com o valor de provedor `GcpKubernetesContainer`. A métrica `container/accelerator` só está disponível se o modo experimental no Kubernetes estiver habilitado e a GPU tiver sido adicionada ao seu cluster e contêiner.
