[As integrações do New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [<DNT>Google Cloud Platform</DNT> (<DNT>GCP</DNT>)](https://cloud.google.com/) incluem uma que reporta dados do [<DNT>Gemini Enterprise</DNT>](https://cloud.google.com/gemini-enterprise) para o New Relic. Este documento explica como ativar a integração <DNT>GCP Gemini Enterprise</DNT> e descreve os dados que ela reporta.

## Recurso

<DNT>Gemini Enterprise</DNT> é a plataforma de <DNT>Google Cloud</DNT> para criar e executar aplicativos de pesquisa corporativa e agente de IA, desenvolvida no <DNT>Discovery Engine</DNT>. A integração <DNT>Gemini Enterprise</DNT> do New Relic coleta métrica de request, latência e sessão para aplicativos (engines), agentes, as ferramentas que esses agentes invocam e conectores de dados, juntamente com contagens de recursos e consumo de cota por local e por usuário.

## Ativar integração [#activate]

<Callout variant="important">
Esta integração está disponível apenas quando você conecta seu projeto <DNT>GCP</DNT> com <DNT>**Workload Identity Federation**</DNT>. Ela não está disponível para conexões de conta de serviço ou conta de usuário.
</Callout>

Para habilitar a integração, siga os procedimentos padrão para [conectar seu serviço <DNT>GCP</DNT> ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure) com <DNT>**Workload Identity Federation**</DNT>.

## Frequência de votação [#polling]

A integração do New Relic consulta seus serviços <DNT>GCP</DNT> de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem para <DNT>Gemini Enterprise</DNT> é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Após você habilitar a integração, seus recursos <DNT>Gemini Enterprise</DNT> aparecem como entidades no explorador de entidades do New Relic. Para visualizar os dashboards e gerenciar serviços, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

O New Relic coleta as métricas <DNT>Gemini Enterprise</DNT> disponíveis em <DNT>GCP Cloud Monitoring</DNT> como métricas dimensionais no tipo de evento `Metric`, por exemplo:

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'gcp.discoveryengine.%' FACET metricName
```

#### Métricas de localização

As métricas de local são agregações por local para o seu projeto. Elas incluem contagens de recursos, como o número de mecanismos, armazenamentos de dados, documentos e eventos de usuário, e o volume de requests de pesquisa. Elas também incluem o uso, os limites e as contagens de limite excedido para mais de 140 cotas de <DNT>Gemini Enterprise</DNT>, abrangendo áreas como agentes, geração de imagem e vídeo, fundamentação na Web e requests de pesquisa.

A maioria das métricas de localização são métricas de cota. Cada cota é relatada como até três métricas, nomeadas pela adição de um sufixo `usage`, `limit` ou `exceeded`, por exemplo, `gcp.discoveryengine.quota.search_requests_regional.usage`. As métricas de cota contêm os rótulos `metric.limit_name` e `metric.regional_location`.

A localização também define métricas não de cota, como `gcp.discoveryengine.engines_regional`. O <DNT>Google Cloud</DNT> não reporta dados para elas em todos os projetos e, quando não o faz, elas não aparecem no New Relic. As mesmas contagens também são reportadas como métricas de cota, por exemplo, `gcp.discoveryengine.quota.engines_regional.usage`.

Para a lista completa de métricas de Localização, consulte a seção `discoveryengine` da [referência de métricas do Cloud Monitoring do Google](https://docs.cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-discoveryengine). O New Relic coleta as métricas GA e beta listadas lá.
