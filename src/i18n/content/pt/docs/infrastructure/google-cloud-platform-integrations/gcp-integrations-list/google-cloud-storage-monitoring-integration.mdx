[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma integração para reportar dados [Google Cloud Storage](https://cloud.google.com/storage) para New Relic. Este documento explica como ativar a integração do GCP Cloud Storage e descreve os dados reportados.

## Recurso

O Google Cloud Storage é o serviço de armazenamento de objetos do GCP para servir conteúdo de sites, arquivamento e recuperação de desastres, e distribuir objetos de dados via download direto. A integração do New Relic Cloud Storage coleta métricas de solicitação de API, rede, contagem de objetos e bytes armazenados para cada bucket.

## Ativar integração [#activate]

Para habilitar a integração, é necessário seguir os procedimentos padrão para [conectar o serviço do GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conecte-se com a Workload Identity Federation (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar com conta de serviço ou conta de usuário](/docs/connect-google-cloud-platform-services-infrastructure)

## Frequência de votação [#polling]

As integrações do New Relic consultam os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem para o Google Cloud Storage é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Após habilitar a integração, os buckets do Cloud Storage aparecem como entidades no explorador de entidades da New Relic. Para ver dashboards e gerenciar serviços, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas as métricas do Cloud Storage disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`. Métricas adicionais além desta tabela são coletadas automaticamente. Consulte a [documentação de métricas do Cloud Storage do Google](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-storage) para obter a lista completa.

## Conta de serviço ou conta de usuário [#service-account]

### Encontre e use dados [#find-data]

Após conectar a integração ao New Relic e aguardar alguns minutos, os dados aparecerão na interface do New Relic. Para [encontrar e usar os dados de integração](/docs/telemetry-data-platform/understand-data/new-relic-data-types/), incluindo os <InlinePopover type="dashboards" />e as configurações de alerta, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; Google Cloud Storage</DNT>.

Para criar dashboard personalizado para integração, [crie uma consulta](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights) para o tipo de evento `GcpStorageBucketSample` com o valor do provedor `GcpStorageBucket`.

### GcpStorageBucketSample [#gcp-storage-bucket-sample]

A integração reporta [dados métricos](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics) para todos os valores de `method` e `response_code`:

* `response_code`: o código de resposta das solicitações.
* `method`: o nome do método API chamado.
