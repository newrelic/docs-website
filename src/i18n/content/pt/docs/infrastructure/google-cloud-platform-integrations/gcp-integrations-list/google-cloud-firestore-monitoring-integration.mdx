[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma integração que reporta dados [Google Cloud Firestore](https://cloud.google.com/firestore) para New Relic. Este documento explica como ativar a integração GCP Firestore e descreve os dados que ela reporta.

## Recurso

O Firestore é o banco de dados de documentos NoSQL sem servidor e totalmente gerenciado do Google Cloud. A integração do Firestore da New Relic coleta métricas de solicitação de API, leitura/gravação de documentos e cota no escopo da instância, além de métricas no nível da solicitação anexadas ao recurso de solicitação compatível com o armazenamento de dados.

## Ativar integração [#activate]

Para habilitar a integração, é necessário seguir os procedimentos padrão para [conectar o serviço do GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conecte-se com a Workload Identity Federation (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar com conta de serviço ou conta de usuário](/docs/connect-google-cloud-platform-services-infrastructure)

## Frequência de votação [#polling]

As integrações do New Relic consultam os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem do Google Cloud Firestore é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Após habilitar a integração, os recursos do Firestore aparecem como entidades no explorador de entidades da New Relic. Para ver dashboards e gerenciar serviços, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas as métricas do Firestore disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`. Métricas adicionais além desta tabela são coletadas automaticamente. Consulte a [documentação de métricas do Firestore do Google](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-firestore) para obter a lista completa.
