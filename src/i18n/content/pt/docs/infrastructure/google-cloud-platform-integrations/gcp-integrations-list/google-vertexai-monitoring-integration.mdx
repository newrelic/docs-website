[As integrações da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) incluem uma integração para reportar dados do [Google Cloud Vertex AI](https://cloud.google.com/vertex-ai) para a New Relic. Este documento explica como ativar a integração do GCP Vertex AI e descreve os dados que ela reporta.

## Recurso

O Vertex AI é a plataforma unificada do Google Cloud para criar, implantar e gerenciar modelos de machine learning e aplicativos de IA generativa. A integração New Relic Vertex AI coleta métricas de desempenho, taxas de transferência, latência e utilização de recursos em locais, endpoints, índices, armazenamentos de recursos e armazenamentos de recursos online.

## Ativar integração [#activate]

Para habilitar a integração, é necessário seguir os procedimentos padrão para [conectar o serviço do GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conecte-se com a Workload Identity Federation (recomendado)](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation)
* [Conectar com conta de serviço ou conta de usuário](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account)

## Frequência de votação [#polling]

As integrações do New Relic consultam os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem para o Google Cloud Vertex AI é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Após habilitar a integração, os recursos do Vertex AI aparecem como entidades no explorador de entidades da New Relic. Para ver dashboards e gerenciar serviços, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas as métricas do Vertex AI disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`. Métricas adicionais além desta tabela são coletadas automaticamente. Consulte a [documentação de métricas do Vertex AI do Google](https://cloud.google.com/monitoring/api/metrics_gcp_a_b#gcp-aiplatform) para ver a lista completa.
