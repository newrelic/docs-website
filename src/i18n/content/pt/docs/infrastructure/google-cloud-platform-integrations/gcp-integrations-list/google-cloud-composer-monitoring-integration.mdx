[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma que reporta dados do [Google Cloud Composer](https://cloud.google.com/composer) para New Relic. Este documento explica como ativar a integração do GCP Cloud Composer e descreve os dados que ela reporta.

## Recurso

O Cloud Composer é o serviço de orquestração de fluxo de trabalho totalmente gerenciado do Google Cloud, desenvolvido no Apache Airflow. A integração do New Relic Cloud Composer coleta métricas de ambiente, workload e fluxo de trabalho — execuções de DAG, instâncias de tarefas, heartbeats do agendador e uso de recursos do worker.

## Ativar integração [#activate]

Para habilitar a integração, é necessário seguir os procedimentos padrão para [conectar o serviço do GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conecte-se com a Workload Identity Federation (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar com conta de serviço ou conta de usuário](/docs/connect-google-cloud-platform-services-infrastructure)

## Frequência de votação [#polling]

As integrações do New Relic consultam os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem do Google Cloud Composer é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Após habilitar a integração, os recursos do Cloud Composer aparecem como entidades no explorador de entidades do New Relic. Para ver dashboards e gerenciar serviços, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas as métricas do Cloud Composer disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`. Métricas adicionais além desta tabela são coletadas automaticamente. Consulte a [documentação de métricas do Cloud Composer do Google](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-composer) para ver a lista completa.
