[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma que reporta dados [Google Cloud SQL](https://cloud.google.com/sql/docs/) para New Relic. Este documento explica como ativar a integração do GCP Cloud SQL e descreve os dados que ela reporta.

## Recurso

O Cloud SQL é o serviço de banco de dados totalmente gerenciado do Google Cloud para MySQL, PostgreSQL e SQL Server. A integração do New Relic com o Cloud SQL coleta métricas de CPU, memória, disco, conexão, replicação e em nível de banco de dados para cada instância do Cloud SQL e seus bancos de dados.

## Ativar integração [#activate]

Para habilitar a integração, é necessário seguir os procedimentos padrão para [conectar o serviço do GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conecte-se com a Workload Identity Federation (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar com conta de serviço ou conta de usuário](/docs/connect-google-cloud-platform-services-infrastructure)

## Frequência de votação [#polling]

As integrações do New Relic consultam os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem para o Google Cloud SQL é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Após habilitar a integração, os recursos do Cloud SQL aparecem como entidades no explorador de entidades do New Relic. Para ver dashboards e gerenciar serviços, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas as métricas do Cloud SQL disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`. Métricas adicionais além desta tabela são coletadas automaticamente. Consulte a [documentação de métricas do Cloud SQL do Google](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-cloudsql) para obter a lista completa.

## Conta de serviço ou conta de usuário [#service-account]

### Encontre e use dados [#find-data]

Após ativar a integração e aguardar alguns minutos (com base na [frequência da votação](#polling)), os dados aparecerão na interface do New Relic . Para [encontrar e usar seus dados](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), incluindo links para seu <InlinePopover type="dashboards" />e configurações de alerta, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

Para visualizar [dados métricos](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics) para sua integração SQL do GCP no New Relic, [crie uma consulta NRQL ](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql)para [o evento](/docs/data-apis/understand-data/new-relic-data-types/#event-data) `GcpCloudSqlSample` e seu atributo relacionado.
