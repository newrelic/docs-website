[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma integração que reporta dados [Google Cloud AlloyDB](https://cloud.google.com/alloydb) para New Relic. Este documento explica como ativar a integração GCP AlloyDB e descreve os dados que ela reporta.

## Recurso

O AlloyDB é um serviço de banco de dados totalmente gerenciado e compatível com PostgreSQL, criado para workloads transacionais e analíticos exigentes. A integração do New Relic AlloyDB coleta métricas de desempenho, disponibilidade e utilização de recursos em clusters, instâncias, bancos de dados e nós de instância.

## Ativar integração [#activate]

Para habilitar a integração, é necessário seguir os procedimentos padrão para [conectar o serviço do GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conecte-se com a Workload Identity Federation (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar com conta de serviço ou conta de usuário](/docs/connect-google-cloud-platform-services-infrastructure)

## Frequência de votação [#polling]

As integrações do New Relic consultam os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem para o Google Cloud AlloyDB é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

<Callout variant="important">
  O AlloyDB para PostgreSQL oferece suporte a intervalos de sondagem de 1 minuto para integrações WIF em versão prévia limitada. Para solicitar acesso, entre em contato com o [suporte da New Relic](https://support.newrelic.com/).
</Callout>

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Após habilitar a integração, os recursos do AlloyDB aparecem como entidades no explorador de entidades do New Relic. Para ver dashboards e gerenciar serviços, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas as métricas do AlloyDB disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`. Métricas adicionais além desta tabela são coletadas automaticamente. Consulte a [documentação de métricas do AlloyDB do Google](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-alloydb) para ver a lista completa.
