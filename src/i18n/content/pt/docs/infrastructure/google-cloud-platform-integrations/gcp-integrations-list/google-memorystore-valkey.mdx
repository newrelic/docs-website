[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma que reporta dados do [Google Memorystore for Valkey](https://cloud.google.com/memorystore/docs/valkey) para New Relic. Este documento explica como ativar a integração do GCP Memorystore for Valkey e descreve os dados que ela reporta.

## Recurso

O Memorystore for Valkey é o serviço Valkey totalmente gerenciado do Google Cloud, fornecendo um armazenamento de dados em memória compatível com Redis de código aberto. A integração do New Relic Memorystore for Valkey coleta métricas no nível da instância e por nó em CPU, memória, clientes, keyspace, persistência e rede para cada implantação do Valkey.

## Ativar integração [#activate]

Para habilitar a integração, é necessário seguir os procedimentos padrão para [conectar o serviço do GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar com Workload Identity Federation](/docs/connect-google-cloud-platform-services-infrastructure)

## Frequência de votação [#polling]

As integrações do New Relic consultam os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem do Google Memorystore para Valkey é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Após habilitar a integração, os recursos do Memorystore for Valkey aparecem como entidades no explorador de entidades do New Relic. Para ver dashboards e gerenciar serviços, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas as métricas do Memorystore for Valkey disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`. Métricas adicionais além desta tabela são coletadas automaticamente. Consulte a [documentação de métricas do Memorystore do Google](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-memorystore) para ver a lista completa.
