[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma que reporta dados [Google Memorystore for Redis](https://cloud.google.com/memorystore/docs/redis) para New Relic. Este documento explica como ativar a integração do GCP Memorystore for Redis e descreve os dados que ela reporta.

## Recurso

O Memorystore for Redis é o serviço Redis totalmente gerenciado do Google Cloud. A integração do New Relic Memorystore for Redis coleta métricas de CPU, memória, rede, keyspace, persistência, replicação e taxas de transferência de comandos para cada instância do Redis.

## Ativar integração [#activate]

Para habilitar a integração, é necessário seguir os procedimentos padrão para [conectar o serviço do GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conecte-se com a Workload Identity Federation (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar com conta de serviço ou conta de usuário](/docs/connect-google-cloud-platform-services-infrastructure)

## Frequência de votação [#polling]

As integrações do New Relic fazem consulta aos seus serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem para o Google Memorystore for Redis é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Após habilitar a integração, as instâncias do Memorystore for Redis aparecem como entidades no explorador de entidades do New Relic. Para ver dashboards e gerenciar serviços, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas as métricas do Memorystore for Redis disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`. Métricas adicionais além desta tabela são coletadas automaticamente. Consulte a [documentação de métricas do Memorystore for Redis do Google](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-redis) para obter a lista completa.
