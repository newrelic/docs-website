[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma integração para reportar dados [Google Firebase Authentication](https://firebase.google.com/products/auth) para New Relic. Este documento explica como ativar a integração GCP Firebase Authentication e descreve os dados que ela reporta.

## Recurso

O Firebase Authentication é o serviço de identidade do Google Cloud que fornece SDKs fáceis de usar e provedores de autenticação para login federado, telefone, e-mail/senha e autenticação anônima. A integração do Firebase Authentication da New Relic coleta métricas de verificação de telefone para cada locatário do Firebase Auth.

## Ativar integração [#activate]

Para habilitar a integração, é necessário seguir os procedimentos padrão para [conectar o serviço do GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar com Workload Identity Federation](/docs/connect-google-cloud-platform-services-infrastructure)

## Frequência de votação [#polling]

A integração do New Relic consulta os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem para o Google Cloud Firebase Authentication é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Após habilitar a integração, os recursos do Firebase Authentication aparecem como entidades no explorador de entidades do New Relic. Para ver dashboards e gerenciar serviços, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas as métricas do Firebase Authentication disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`. Métricas adicionais além desta tabela são coletadas automaticamente. Consulte a [documentação de métricas do Firebase Authentication do Google](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-firebaseauth) para obter a lista completa.
