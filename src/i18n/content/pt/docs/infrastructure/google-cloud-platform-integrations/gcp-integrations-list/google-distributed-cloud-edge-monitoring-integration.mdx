[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma que reporta dados [Google Distributed Cloud Edge](https://cloud.google.com/distributed-cloud/edge) para New Relic. Este documento explica como ativar a integração <DNT>GCP Distributed Cloud Edge</DNT> e descreve os dados que ela reporta.

## Recurso

<DNT>Google Distributed Cloud Edge</DNT> é a plataforma de edge computing gerenciada e local do <DNT>Google Cloud</DNT> para executar workload de <DNT>Kubernetes</DNT> em hardware de propriedade dos clientes. A integração <DNT>Distributed Cloud Edge</DNT> do New Relic coleta o inventário de hardware e métrica de integridade para as máquinas (nós) e cluster de borda na sua implantação: telemetria de CPU, memória, disco, rede, GPU e energia/PSU, juntamente com o ciclo de vida do cluster e o status da versão.

## Ativar integração [#activate]

<Callout variant="important">
  Esta integração está disponível apenas quando você conecta seu projeto <DNT>GCP</DNT> com <DNT>**Workload Identity Federation**</DNT>. Ela não está disponível para conexões de conta de serviço ou conta de usuário.
</Callout>

Para habilitar a integração, siga os procedimentos padrão para [conectar seu serviço GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure) com <DNT>**Workload Identity Federation**</DNT>.

## Frequência de votação [#polling]

A integração do New Relic consulta seus serviços <DNT>GCP</DNT> de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem para <DNT>Google Distributed Cloud Edge</DNT> é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

O New Relic coleta todas as métricas de <DNT>Distributed Cloud Edge</DNT> disponíveis em <DNT>GCP Cloud Monitoring</DNT> como métricas dimensionais no tipo de evento `Metric`.

Esta integração não cria entidades no explorador de entidades do New Relic. Realize a consulta das respectivas métricas diretamente no tipo de evento `Metric`, por exemplo:

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'gcp.edgecontainer.%' FACET metricName
```

As métricas carregam os rótulos de recursos da máquina subjacente ou cluster de borda, de modo que é possível agrupar por nome do cluster, ID da máquina e localização sem uma entidade.
