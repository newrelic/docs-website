[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma integração que reporta dados [Google Cloud Dataflow](https://cloud.google.com/dataflow) para New Relic. Este documento explica como ativar a integração do GCP Cloud Dataflow e descreve os dados que ela reporta.

## Recurso

O Cloud Dataflow é o serviço de processamento de dados em lote e streaming totalmente gerenciado do Google Cloud baseado no Apache Beam. A integração do New Relic Dataflow coleta métricas de recursos de worker, taxas de transferência, atraso e estado do job para cada job do Dataflow.

## Ativar integração [#activate]

Para habilitar a integração, é necessário seguir os procedimentos padrão para [conectar o serviço do GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conecte-se com a Workload Identity Federation (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar com conta de serviço ou conta de usuário](/docs/connect-google-cloud-platform-services-infrastructure)

## Frequência de votação [#polling]

As integrações do New Relic consultam os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem para o Google Cloud Dataflow é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

<Callout variant="important">
  O Cloud Dataflow oferece suporte a intervalos de sondagem de 1 minuto para integrações do WIF em versão prévia limitada. Para solicitar acesso, entre em contato com o [suporte da New Relic](https://support.newrelic.com/).
</Callout>

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Após ativar a integração, os recursos do Dataflow aparecem como entidades no explorador de entidades da New Relic. Para ver dashboards e gerenciar serviços, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas as métricas do Dataflow disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`. Métricas adicionais além desta tabela são coletadas automaticamente. Consultar a [documentação de métricas do Dataflow do Google](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-dataflow) para obter a lista completa.
