[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma que reporta dados [Google Cloud Run](https://cloud.google.com/run) para New Relic. Este documento explica como ativar a integração do GCP Cloud Run e descreve os dados que ela reporta.

## Recurso

O Cloud Run é a plataforma de contêiner sem servidor totalmente gerenciada do Google Cloud para executar serviços sem estado e trabalhos únicos. A integração do Cloud Run da New Relic coleta métricas de requests, latência, utilização de contêiner e execução em serviços (por meio de revisões) e trabalhos.

## Ativar integração [#activate]

Para habilitar a integração, é necessário seguir os procedimentos padrão para [conectar o serviço do GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conecte-se com a Workload Identity Federation (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar com conta de serviço ou conta de usuário](/docs/connect-google-cloud-platform-services-infrastructure)

## Frequência de votação [#polling]

As integrações do New Relic consultam os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem para o Google Cloud Run é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Após habilitar a integração, os recursos do Cloud Run aparecem como entidades no explorador de entidades do New Relic. Para ver dashboards e gerenciar serviços, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas as métricas do Cloud Run disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`. Métricas adicionais além desta tabela são coletadas automaticamente. Consulte a [documentação de métricas do Cloud Run do Google](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-run) para ver a lista completa.

## Conta de serviço ou conta de usuário [#service-account]

### Encontre e use dados [#find-data]

Após ativar a integração e aguardar alguns minutos (com base na [frequência da votação](#polling)), os dados aparecerão na interface do New Relic .     <tr>
      <td>
        `container.BillableInstanceTime`
      </td>

      <td>
        Segundos
      </td>

      <td>
        Tempo faturável agregado de toda instância da revisão. Para uma determinada instância de contêiner, o tempo faturável ocorre quando a instância de contêiner está sendo iniciada ou pelo menos uma solicitação está sendo processada. O tempo faturável é arredondado para os 100 milissegundos mais próximos. Exemplos: Se uma revisão com 2 instâncias de instância tiver atendido tráfego continuamente no último minuto, o valor será 2s/s com o alinhador &quot;rate&quot; padrão. Se uma única solicitação com duração de 30 ms foi recebida por uma revisão no último minuto, ela será arredondada para 100 ms e calculada em média para 1,7 ms/s ao longo do minuto com o alinhador de &quot;taxa&quot; padrão.
      </td>
    </tr>
