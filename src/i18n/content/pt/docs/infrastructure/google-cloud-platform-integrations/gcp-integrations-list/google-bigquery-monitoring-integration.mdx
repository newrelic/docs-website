[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma integração para reportar dados [Google BigQuery](https://cloud.google.com/bigquery/) para New Relic. Este documento explica como ativar a integração GCP BigQuery e descreve os dados que ela reporta.

## Recurso

O BigQuery é o data warehouse sem servidor do Google Cloud. A integração do New Relic com o BigQuery coleta métricas de consulta, execução, armazenamento e utilização de slots no escopo do projeto e do conjunto de dados.

## Ativar integração [#activate]

Para habilitar a integração, é necessário seguir os procedimentos padrão para [conectar o serviço do GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conecte-se com a Workload Identity Federation (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar com conta de serviço ou conta de usuário](/docs/connect-google-cloud-platform-services-infrastructure)

## Frequência de votação [#polling]

As integrações do New Relic consultam os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem para o Google BigQuery é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

<Callout variant="important">
  O BigQuery oferece suporte a intervalos de sondagem de 1 minuto para integrações do WIF em pré-visualização limitada. Para solicitar acesso, entre em contato com o [suporte da New Relic](https://support.newrelic.com/).
</Callout>

## Ativar tabela métrica [#table-metrics]

A coleta de métricas da tabela do BigQuery está desativada por padrão. Isso afeta a métrica listada em [GcpBigQueryTableSample](#table-sample). Para coletar essas métricas, ative a configuração &quot;Ativar métricas de tabela&quot; no menu de configuração da integração do BigQuery.

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Após habilitar a integração, os recursos do BigQuery aparecem como entidades no explorador de entidades do New Relic. Para ver dashboards e gerenciar serviços, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas as métricas do BigQuery disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`. Métricas adicionais além desta tabela são coletadas automaticamente. Consulte a [documentação de métricas do BigQuery do Google](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-bigquery) para ver a lista completa.

## Conta de serviço ou conta de usuário [#service-account]

### Encontre e use dados [#find-data]

Após ativar a integração e aguardar alguns minutos (com base na [frequência da votação](#polling)), os dados aparecerão na interface do New Relic . Para [encontrar e usar seus dados](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), incluindo links para seu <InlinePopover type="dashboards" />e configurações de alerta, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

Para visualizar [dados métricos](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics) para sua integração do Google BigQuery no New Relic, [crie uma consulta NRQL ](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql)para o [evento](/docs/using-new-relic/welcome-new-relic/getting-started/glossary#event) `GcpBigQueryProjectSample`, `GcpBigQueryDatasetSample` e `GcpBigQueryTableSample` e seu atributo.
