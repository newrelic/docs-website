[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma integração para reportar dados [Google Cloud Router](https://cloud.google.com/network-connectivity/docs/router) para New Relic. Este documento explica como ativar a integração do GCP Cloud Router e descreve os dados reportados.

## Recurso

O Cloud Router é o serviço de roteamento com suporte a BGP totalmente gerenciado do Google Cloud para Cloud VPN, Cloud Interconnect e Cloud NAT. A integração do Cloud Router da New Relic coleta métricas de sessão BGP, anúncio de rota e gateway NAT (conexões abertas, tráfego, pacotes descartados) para cada Cloud Router e NAT Gateway.

## Ativar integração [#activate]

Para habilitar a integração, é necessário seguir os procedimentos padrão para [conectar o serviço do GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conecte-se com a Workload Identity Federation (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar com conta de serviço ou conta de usuário](/docs/connect-google-cloud-platform-services-infrastructure)

## Frequência de votação [#polling]

As integrações do New Relic consultam os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem do Google Cloud Router é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Após ativar a integração, os recursos do Cloud Router aparecem como entidades no explorador de entidades do New Relic. Para ver dashboards e gerenciar serviços, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas as métricas do Cloud Router disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`. Métricas adicionais além desta tabela são coletadas automaticamente. Consulte a [documentação de métricas do Cloud Router do Google](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-router) para ver a lista completa.
