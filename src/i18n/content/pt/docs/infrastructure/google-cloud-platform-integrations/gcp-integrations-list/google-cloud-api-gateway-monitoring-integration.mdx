[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma integração para reportar dados [Google Cloud API Gateway](https://cloud.google.com/api-gateway) para New Relic. Este documento explica como ativar a integração GCP API Gateway e descreve os dados reportados.

## Recurso

O Google Cloud API Gateway é um serviço totalmente gerenciado para criação, proteção e monitoramento de APIs na frente dos serviços de backend do Google Cloud. A integração do New Relic API Gateway coleta métricas de tráfego de requests e de código de resposta para cada gateway, com detalhamentos por configuração de API e classe de código de resposta.

## Ativar integração [#activate]

Para habilitar a integração, é necessário seguir os procedimentos padrão para [conectar o serviço do GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar com Workload Identity Federation](/docs/connect-google-cloud-platform-services-infrastructure)

## Frequência de votação [#polling]

As integrações do New Relic consultam os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem do Google Cloud API Gateway é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Após habilitar a integração, os recursos do API Gateway aparecem como entidades no explorador de entidades do New Relic. Para ver dashboards e gerenciar serviços, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas as métricas do API Gateway disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`. Métricas adicionais além desta tabela são coletadas automaticamente. Consulte a [documentação de métricas do API Gateway do Google](https://cloud.google.com/monitoring/api/metrics_gcp_a_b#gcp-apigateway) para obter a lista completa.
