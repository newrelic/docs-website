[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma integração para reportar dados [Firebase App Hosting](https://firebase.google.com/docs/app-hosting) para New Relic. Este documento explica como ativar a integração do GCP Firebase App Hosting e descreve os dados reportados.

## Recurso

O Firebase App Hosting é o serviço de hospedagem gerenciada do Google para aplicativo web dinâmicos e renderizados no servidor, criados com framework como Next.js e Angular. A integração New Relic Firebase App Hosting coleta as taxas de transferência de solicitações e o volume de tráfego de resposta para cada backend do App Hosting.

## Ativar integração [#activate]

<Callout variant="important">
  Esta integração está disponível apenas ao conectar o projeto do GCP com o Workload Identity Federation. Não está disponível para conexões de conta de serviço ou de conta de usuário.
</Callout>

Para habilitar a integração, siga os procedimentos padrão para [conectar seu serviço GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure) com a Workload Identity Federation.

## Frequência de votação [#polling]

As integrações do New Relic consultam os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem para o Firebase App Hosting é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Todas as métricas do Firebase App Hosting disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`.

Esta integração não cria entidades no explorador de entidades do New Relic. Realize a consulta das respectivas métricas diretamente no tipo de evento `Metric`, por exemplo:

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'gcp.firebaseapphosting.%' FACET metricName
```
