[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma integração que reporta dados [Google Cloud Spanner](https://cloud.google.com/spanner/) para New Relic. Este documento explica como ativar a integração do GCP Cloud Spanner e descreve os dados que ela reporta.

## Recurso [#features]

O Google Cloud Spanner é um serviço de banco de dados relacional distribuído globalmente, criado para a cloud. A integração do New Relic Spanner coleta métricas de nó, CPU, armazenamento, sessão, solicitação de API e consulta para cada instância do Spanner e para os bancos de dados hospedados nela.

## Ativar integração [#activate]

Para habilitar a integração, é necessário seguir os procedimentos padrão para [conectar o serviço do GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conecte-se com a Workload Identity Federation (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar com conta de serviço ou conta de usuário](/docs/connect-google-cloud-platform-services-infrastructure)

## Frequência de votação [#polling]

As integrações do New Relic consultam os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem para o Google Cloud Spanner é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

<Callout variant="important">
  O Cloud Spanner oferece suporte a intervalos de sondagem de 1 minuto para integrações WIF em visualização limitada. Para solicitar acesso, entre em contato com o [suporte da New Relic](https://support.newrelic.com/).
</Callout>

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Após habilitar a integração, os recursos do Spanner aparecem como entidades no explorador de entidades do New Relic. Para ver dashboards e gerenciar serviços, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas as métricas do Spanner disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`. Métricas adicionais além desta tabela são coletadas automaticamente. Consulte a [documentação de métricas do Spanner do Google](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-spanner) para obter a lista completa.

#### Entidade

<CollapserGroup>
  <Collapser id="entities-table" title="Entidades do Spanner">
    Uma entidade `GCPSPANNERINSTANCE` é sintetizada para cada instância do Spanner, e uma entidade `GCPSPANNERDATABASE` para cada banco de dados dentro dela. ## Conta de serviço ou conta de usuário [#service-account]

### Encontre e use dados [#find-data]

Após ativar a integração e aguardar alguns minutos (com base na [frequência da votação](#polling)), os dados aparecerão na interface do New Relic . Para [encontrar e usar seus dados](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), incluindo links para seu <InlinePopover type="dashboards" />e configurações de alerta, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

Para visualizar [dados métricos](/docs/integrations/new-relic-integrations/getting-started/#metric) para sua integração do GCP Spanner no New Relic, [crie uma consulta NRQL ](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql)para [o evento](/docs/data-apis/understand-data/new-relic-data-types/#event-data) `GcpSpannerInstanceSample` e `GcpSpannerDatabaseSample` e seus atributos relacionados.
