[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma integração para reportar dados [Google Memorystore for Memcached](https://cloud.google.com/memorystore/docs/memcached) para New Relic. Este documento explica como ativar a integração do GCP Memorystore for Memcached e descreve os dados reportados.

## Recurso

O Memorystore for Memcached é o serviço de Memcached totalmente gerenciado do Google Cloud. A integração do Memorystore for Memcached da New Relic coleta métricas de CPU, memória, conexão, taxa de acertos e armazenamento de itens no nível do nó para cada nó do Memcached.

## Ativar integração [#activate]

Para habilitar a integração, é necessário seguir os procedimentos padrão para [conectar o serviço do GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conecte-se com a Workload Identity Federation (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar com conta de serviço ou conta de usuário](/docs/connect-google-cloud-platform-services-infrastructure)

## Frequência de votação [#polling]

As integrações do New Relic consultam os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem para o Google Memorystore for Memcached é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Após habilitar a integração, os recursos do Memorystore for Memcached aparecem como entidades no explorador de entidades do New Relic. Para ver dashboards e gerenciar serviços, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas as métricas do Memorystore for Memcached disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`. Métricas adicionais além desta tabela são coletadas automaticamente. Consulte a [documentação de métricas do Memorystore for Memcached do Google](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-memcache) para obter a lista completa.
