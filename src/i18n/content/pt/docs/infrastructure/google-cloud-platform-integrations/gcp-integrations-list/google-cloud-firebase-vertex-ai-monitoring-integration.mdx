[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma integração para reportar dados [Firebase AI Logic](https://firebase.google.com/docs/ai-logic) (anteriormente Vertex AI no Firebase) para New Relic. Este documento explica como ativar a integração GCP Firebase AI Logic e descreve os dados que ela reporta.

## Recurso

O Firebase AI Logic permite que aplicativos móveis e da web chamem os modelos Gemini e Imagen diretamente dos SDKs do cliente, sem um backend personalizado. A integração do New Relic Firebase AI Logic coleta telemetria de cliente de IA generativa para cada modelo: duração da operação, uso de token e contagens de uso por modalidade.

## Ativar integração [#activate]

<Callout variant="important">
  Esta integração está disponível apenas ao conectar o projeto do GCP com o Workload Identity Federation. Não está disponível para conexões de conta de serviço ou de conta de usuário.
</Callout>

Para habilitar a integração, siga os procedimentos padrão para [conectar seu serviço GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure) com a Workload Identity Federation.

## Frequência de votação [#polling]

As integrações do New Relic consultam os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem para o Firebase AI Logic é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Todas as métricas do modelo Firebase AI Logic disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`.

Esta integração não cria entidades no explorador de entidades do New Relic. Realize a consulta das respectivas métricas diretamente no tipo de evento `Metric`, por exemplo:

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'gcp.firebasevertexai.%' FACET metricName
```

`gen_ai_client_operation_duration` também está disponível como métricas de percentil `.p50`, `.p95` e `.p99`.

<Callout variant="tip">
  O Firebase AI Logic também expõe as métricas de modelo de prompt (`render_count` e `render_latency`) em um recurso monitorado separado. Esta integração não coleta essas métricas porque elas estão em pré-visualização.
</Callout>

Para a lista completa, consulte a [documentação de métricas do Firebase AI Logic do Google](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-firebasevertexai).
