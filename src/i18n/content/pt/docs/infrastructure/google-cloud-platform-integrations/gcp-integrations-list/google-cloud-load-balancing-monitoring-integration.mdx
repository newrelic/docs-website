[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma que reporta dados [Google Cloud Load Balancing](https://cloud.google.com/load-balancing/) para New Relic. Este documento explica como ativar a integração do GCP Cloud Load Balancing e descreve os dados que ela reporta.

## Recurso

O Cloud Load Balancing é o serviço gerenciado baseado em software do Google Cloud para distribuir tráfego entre regiões, com suporte para proxy HTTP(S), TCP/SSL e balanceamento de carga L4 (rede). A integração do New Relic Load Balancing coleta métricas de taxa de requests, latência, taxas de transferência de bytes e conexão para cada variante de balanceador de carga.

## Ativar integração [#activate]

Para habilitar a integração, é necessário seguir os procedimentos padrão para [conectar o serviço do GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conecte-se com a Workload Identity Federation (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar com conta de serviço ou conta de usuário](/docs/connect-google-cloud-platform-services-infrastructure)

## Frequência de votação [#polling]

As integrações do New Relic consultam os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem para o Google Cloud Load Balancing é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

<Callout variant="important">
  O Cloud Load Balancing oferece suporte a intervalo de sondagem de 1 minuto para integração do WIF em visualização limitada. Para solicitar acesso, entre em contato com o [suporte da New Relic](https://support.newrelic.com/).
</Callout>

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Após habilitar a integração, os recursos do Cloud Load Balancing aparecem como entidades no explorador de entidades do New Relic. Para ver dashboards e gerenciar serviços, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas as métricas do Cloud Load Balancing disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`. Métricas adicionais além desta tabela são coletadas automaticamente. Consulte [a documentação de métricas do Cloud Load Balancing do Google](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-loadbalancing) para obter a lista completa.

## Conta de serviço ou conta de usuário [#service-account]

### Encontre e use dados [#find-data]

Após ativar a integração e aguardar alguns minutos (com base na [frequência da votação](#polling)), os dados aparecerão na interface do New Relic . Para [encontrar e usar seus dados](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), incluindo links para seu <InlinePopover type="dashboards" />e configurações de alerta, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

Para visualizar [dados métricos](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics) para sua integração de balanceamento de carga do GCP no New Relic, [crie uma consulta NRQL ](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql)para [o evento](/docs/data-apis/understand-data/new-relic-data-types/#event-data) `GcpHttpLoadBalancerSample`, `GcpHttpExternalRegionalLoadBalancerSample`, `GcpInternalHttpLoadBalancerSample`, `GcpTcpSslProxyLoadBalancerSample` e `GcpInternalLoadBalancerSample` e seus atributos relacionados.
