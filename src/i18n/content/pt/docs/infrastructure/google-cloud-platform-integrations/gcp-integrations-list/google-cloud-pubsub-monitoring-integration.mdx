[A integração da New Relic](/docs/infrastructure/introduction-infra-monitoring) com o [Google Cloud Platform (GCP)](https://cloud.google.com/) inclui uma que reporta dados [Google Cloud Pub/Sub](https://cloud.google.com/pubsub/) para New Relic. Este documento explica como ativar a integração do GCP Pub/Sub e descreve os dados que ela reporta.

## Recurso

Como parte da Google Cloud [solução de análise](https://cloud.google.com/solutions/stream-analytics) de fluxo, o serviço Cloud Pub/Sub ingere e entrega fluxos de eventos para rápido processamento de dados e análise. A integração do New Relic Pub/Sub coleta métricas de publicação, entrega, backlog e retenção em tópicos, assinaturas e snapshots.

## Ativar integração [#activate]

Para habilitar a integração, é necessário seguir os procedimentos padrão para [conectar o serviço do GCP ao New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conecte-se com a Workload Identity Federation (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar com conta de serviço ou conta de usuário](/docs/connect-google-cloud-platform-services-infrastructure)

## Frequência de votação [#polling]

As integrações do New Relic consultam os serviços do GCP de acordo com um intervalo de sondagem que varia por integração. A frequência de sondagem do Google Cloud Pub/Sub é de 5 minutos. A resolução é 1 ponto de dados a cada minuto.

<Callout variant="important">
  O Cloud Pub/Sub oferece suporte a intervalos de sondagem de 1 minuto para integrações do WIF em pré-visualização limitada. Para solicitar acesso, entre em contato com o [suporte da New Relic](https://support.newrelic.com/).
</Callout>

## Workload Identity Federation [#wif]

### Encontre e use dados [#find-data-wif]

Após ativar a integração, os recursos do Pub/Sub aparecem como entidades no explorador de entidades do New Relic. Para ver dashboards e gerenciar serviços, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas as métricas do Pub/Sub disponíveis no monitoramento de nuvem do GCP são coletadas como métricas dimensionais no tipo de evento `Metric`. Métricas adicionais além desta tabela são coletadas automaticamente. Consulte a [documentação de métricas do Pub/Sub do Google](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-pubsub) para obter a lista completa.

## Conta de serviço ou conta de usuário [#service-account]

### Encontre e use dados [#find-data]

Após ativar a integração e aguardar alguns minutos (com base na [frequência da votação](#polling)), os dados aparecerão na interface do New Relic . Para [encontrar e usar seus dados](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), incluindo links para seu <InlinePopover type="dashboards" />e configurações de alerta, acesse <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

Os tópicos do Pub/Sub são nomeados entidade que representam feeds de mensagens, e assinatura são nomeados entidade que representam destinos de mensagens em um tópico específico.

Para visualizar [dados métricos](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics) para sua integração do GCP Pub/Sub no New Relic, [crie uma consulta NRQL ](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql)para [o evento](/docs/data-apis/understand-data/new-relic-data-types/#event-data) `GcpPubSubTopicSample` e `GcpPubSubSubscriptionSample` e seus atributos relacionados.
