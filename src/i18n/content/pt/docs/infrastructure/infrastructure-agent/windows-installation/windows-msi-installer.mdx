Com o agente de infraestrutura para Windows da New Relic, você pode monitor servidores individuais e também analisar o desempenho do seu serviço como um todo. O agente Windows pode ser executado em seu hardware ou em sistemas em nuvem, como Amazon EC2 ou Windows Azure, e [oferece suporte](/docs/infrastructure/install-infrastructure-agent/get-started/requirements-infrastructure-agent) ao Windows Server e ao Windows 10 e 11. Você também pode [instalar com Chef](/docs/infrastructure/new-relic-infrastructure/config-management-tools/configure-new-relic-infrastructure-using-chef). Antes da instalação, certifique-se de revisar os [requisitos](/docs/infrastructure/new-relic-infrastructure/getting-started/compatibility-requirements-new-relic-infrastructurets).

## Instalação manual [#install-manual]

Se desejar fazer uma instalação manual, siga as próximas etapas:

1. Revise os [requisitos do agente e do sistema operacional suportado](/docs/infrastructure/new-relic-infrastructure/getting-started/compatibility-requirements-new-relic-infrastructure).

2. Baixe a imagem mais recente do instalador .MSI em:

   * Para Windows de 64 bits (Intel/AMD):
     ```
     <a href="https://download.newrelic.com/infrastructure_agent/windows/newrelic-infra.msi">https://download.newrelic.com/infrastructure_agent/windows/newrelic-infra.msi</a>
     ```

   <Callout variant="important">
     Não clique duas vezes no instalador. Isso não instalará totalmente o agente local e poderá resultar em problemas de permissões.
   </Callout>

3. Open <DNT>PowerShell</DNT> as an administrator, and run the install script using an absolute path.

   **Note on v1.73.0 and above:** For silent installations using the `/qn` switch, you **must** supply `GENERATE_CONFIG=true` and `LICENSE_KEY` directly in the command. Running a parameter-less silent install will fail and roll back the installation with Error 1603.

   * Para Windows de 64 bits:

   ```shell
   msiexec.exe /qn /i PATH\TO\newrelic-infra.msi GENERATE_CONFIG=true LICENSE_KEY=YOUR_LICENSE_KEY
   ```

   * For a scripted installation, you can append additional configuration parameters directly to the command:

   ```shell
   msiexec.exe /qn /i PATH\TO\newrelic-infra.msi GENERATE_CONFIG=true LICENSE_KEY=YOUR_LICENSE_KEY DISPLAY_NAME=YOUR_DISPLAY_NAME PROXY=http://YOUR_PROXY_SERVER:PROXY_PORT CUSTOM_ATTRIBUTES="{'ATTRIBUTE_1':'VALUE_1','ATTRIBUTE_2':'VALUE_2'}" METRICS_SYSTEM_SAMPLE_RATE=30 METRICS_STORAGE_SAMPLE_RATE=30 METRICS_NETWORK_SAMPLE_RATE=30 METRICS_PROCESS_SAMPLE_RATE=30 PAYLOAD_COMPRESSION_LEVEL=6
   ```

   Advanced customization is available via `NRIA_` environment variables and the agent configuration file. Learn how to [configure the agent](/docs/infrastructure/install-infrastructure-agent/configuration/configure-infrastructure-agent/).

4. (Optional) If you did not pass the parameters during the MSI installation step, you must manually create and add your <InlinePopover type="licenseKey" />to the `license_key` attribute in your `newrelic-infra.yml` file, located in `C:\Program Files\New Relic\newrelic-infra\`. When you&apos;re finished, your `newrelic-infra.yml` file should look like the following:

   ```yml
   license_key: YOUR_LICENSE_KEY
   ```

5. Para iniciar o serviço `newrelic-infra` , execute:

   ```shell
   net start newrelic-infra
   ```

Aguarde alguns minutos e [visualize seu servidor na interface de infraestrutura](/docs/infrastructure/infrastructure-ui-pages/infra-ui-overview). Se nenhum dado aparecer após esperar alguns minutos, siga estas páginas de resolução de problemas:

* [Nenhum dado aparece na interface de infraestrutura](/docs/infrastructure/new-relic-infrastructure/troubleshooting/no-data-appears-infrastructure)
* [Instalação do Windows MSI falha com erro 1603](/docs/infrastructure/infrastructure-troubleshooting/troubleshoot-infrastructure/windows-msi-install-fails-error-1603)

## Instalar usando arquivos zip [#install-zip]

Para cenários de configuração personalizados, você pode instalar o agente de infraestrutura usando [nossos arquivos zip](https://download.newrelic.com/infrastructure_agent/binaries/windows/) nos modos [assistido](/docs/infrastructure/install-configure-infrastructure/windows-installation/assisted-install-infrastructure-windows) ou [manual](/docs/infrastructure/install-configure-infrastructure/windows-installation/manual-install-infrastructure-windows) . Isto é especialmente útil quando você precisa adaptar as configurações de instalação padrão ao seu ambiente.

<Callout variant="caution">
  Não há suporte para a instalação do agente de infraestrutura usando arquivos zip.
</Callout>

## Qual é o próximo? [#configure]

A única [opção de configuração](/docs/infrastructure/install-configure-infrastructure/configuration/configure-infrastructure-agent) obrigatória é a configuração [`license_key`](/docs/infrastructure-configure-your-agent#conf-license_key), que é criada como parte dos procedimentos de instalação. Você também pode querer:

* [Aprenda a usar os dados do seu host](/docs/tutorial-troubleshoot-infra-hosts/diagnose-app-infra-data) para solucionar problemas de um evento de alerta.
* [Adicione um atributo personalizado](/docs/Infrastructure-configure-your-agent#conf-custom_attributes) para anotar seus dados de infraestrutura.
* [Conecte sua conta AWS](/docs/infrastructure-amazon-aws-ec2-integration#connect) se seus servidores estiverem hospedados no Amazon EC2.
* Habilite [o encaminhamento de logs](/docs/logs/enable-new-relic-logs/1-enable-logs/forward-your-logs-using-new-relic-infrastructure-agent).
* Adicione outras [integrações da New Relic Infrastructure](/docs/infrastructure/introduction-infra-monitoring) para coletar dados de serviços externos.
