Com este lançamento, os [usuários core](/docs/accounts/accounts-billing/new-relic-one-user-management/user-type/#user-type-capabilities) podem gerenciar usuários e gerenciar faturamento. Eles podem:

* Realize tarefas de gerenciamento de usuários se eles tiverem a [função padrão de**Gerente de domínio de autenticação** ](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts#roles).
* Execute tarefas administrativas de faturamento se eles tiverem a [função padrão de**usuário de Faturamento** ](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts#roles).
