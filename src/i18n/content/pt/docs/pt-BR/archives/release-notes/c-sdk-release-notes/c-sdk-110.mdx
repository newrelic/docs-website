### Novo recurso

* **Suporte para Distributed Tracing**

  O distributed tracing permite ver o caminho que uma solicitação percorre ao viajar pelos sistemas distribuídos. Ao mostrar a atividade distribuída por meio de uma visualização unificada, é possível solucionar problemas e entender um sistema complexo melhor do que nunca.

  O distributed tracing está disponível com uma assinatura APM Pro ou equivalente. Para ver um distributed trace completo, é necessário habilitar o recurso em um conjunto de serviços vizinhos.

  Consulte a [documentação do C SDK](https://docs.newrelic.com/docs/agents/c-sdk/instrumentation/enable-distributed-tracing-your-c-applications) do New Relic para obter mais informações sobre como habilitar o distributed tracing para o C SDK.

### Aviso de Fim de Vida Útil

* Os campos `log_filename` e `log_level` de `newrelic_app_config_t` estão atualmente obsoletos. As versões futuras do C SDK removerão permanentemente esses campos. Para especificar o arquivo de log e o nível de log a serem usados com o C SDK, use `newrelic_configure_log()`.
