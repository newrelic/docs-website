### Novo recurso

* **Suporte para transmissão em tempo real**

  * Os dados de evento agora são enviados ao New Relic a cada cinco segundos, em vez de a cada minuto. Como resultado, os eventos de transação, de erro e eventos personalizados estarão agora disponíveis nos dashboards do New Relic em quase tempo real. Para obter mais informações sobre como visualizar os eventos com uma atualização de cinco segundos, consulte a [documentação de streaming em tempo real](/docs/agents/manage-apm-agents/agent-data/real-time-streaming).
  * Observe que os limites gerais de quantos eventos podem ser enviados por minuto não foram alterados. Além disso, os eventos de span, as métricas e os dados de trace não são afetados e continuarão sendo enviados a cada minuto.

### Correções de bugs

* Uma configuração padrão criada com `newrelic_create_app_config()` agora funcionará conforme o esperado com chaves de licença para contas fora dos EUA.

* Para carga de distributed tracing de entrada com valores inválidos ou ausentes para `pr` (prioridade) e/ou `sa` (amostrado), o agente atribuía uma prioridade padrão de -1 e/ou um valor amostrado padrão de `false` à transação.

  Isso foi corrigido: o agente agora mantém a prioridade inicial e os valores amostrados se os respectivos valores na carga de distributed tracing de entrada estiverem ausentes ou inválidos.
