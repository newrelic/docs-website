## O gerenciamento automatizado de usuário agora está disponível para a edição Pro

O recurso de [gerenciamento automatizado de usuário](/docs/accounts/accounts/automated-user-management/automated-user-provisioning-single-sign) da New Relic agora está disponível para organização com a [edição Pro](https://newrelic.com/pricing) da New Relic. Anteriormente, isso estava disponível apenas para organização com a edição Enterprise.

O gerenciamento automatizado de usuários permite utilizar o provisionamento SCIM para importar, atualizar e desativar os usuários do New Relic a partir de um provedor de identidade, como o Azure AD, Okta ou OneLogin. Também é possível gerenciar atributos sobre os usuários, incluindo o tipo de usuário e o fuso horário, por meio do provedor de identidade.
