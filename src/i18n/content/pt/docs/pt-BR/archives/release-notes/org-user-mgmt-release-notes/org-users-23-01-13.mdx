Alteramos a localização de algumas configurações de [domínio de autenticação](https://docs.newrelic.com/docs/accounts/accounts-billing/new-relic-one-user-management/authentication-domains-saml-sso-scim-more). As mudanças incluem:

* A interface de **Domínios de autenticação** foi colocada no [menu da interface de**Administração** ](https://docs.newrelic.com/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-ui-and-tasks/#where).
* As configurações de sessão do usuário e as configurações de atualização do usuário foram movidas para a página da interface de **Gerenciamento de usuários**.
