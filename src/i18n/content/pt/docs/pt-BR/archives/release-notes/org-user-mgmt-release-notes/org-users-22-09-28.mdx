Agora é possível consultar o nome, o ID do usuário, o tipo de usuário, o e-mail e a data da última atividade de um usuário com a nossa API NerdGraph. Também é possível atualizar o tipo de usuário e o endereço de e-mail de um usuário.

Para saber mais, consulte [a documentação do NerdGraph](/docs/apis/nerdgraph/examples/nerdgraph-manage-users).
