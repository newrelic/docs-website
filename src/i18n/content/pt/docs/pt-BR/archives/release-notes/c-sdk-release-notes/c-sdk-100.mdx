### Novo recurso

Este é o primeiro lançamento do C SDK da New Relic! Se o aplicativo não usar [outras linguagens de agente APM da New Relic](https://docs.newrelic.com/docs/agents/manage-apm-agents/installation/compatibility-requirements-new-relic-agents-products#apm-compatibility), é possível usar o C SDK para aproveitar as capacidades e os recursos de monitoramento da New Relic para instrumentar uma ampla variedade de aplicativos.

Para mais informações, veja:

* [Documentação](/docs/agents/c-sdk): como começar a usar o C SDK, instalá-lo e configurá-lo, instrumentar transações, segmentos e erros, usar a API do C SDK e realizar a resolução de problemas básica.
* [GitHub](https://newrelic.github.io/c-sdk/index.html): arquivos do SDK, estrutura de dados, definições de campos e parâmetros, exemplos de código, funções, variáveis.

### Aviso de Fim de Vida Útil

O SDK do agente APM anterior é um software beta obsoleto. Caso o SDK do agente tenha sido utilizado anteriormente, é possível mudar para o C SDK. Recomenda-se verificar a [compatibilidade e os requisitos](/docs/c-sdk-compatibility-requirements) e, em seguida, [aplicar o instrumento, compilar e vincular](/docs/install-c-sdk-compile-link-your-code) o código do aplicativo para utilizar o C SDK. Atualmente, o C SDK não oferece suporte ao recurso HSM da New Relic; isso pode afetar a forma como a transição do SDK do agente é programada.
