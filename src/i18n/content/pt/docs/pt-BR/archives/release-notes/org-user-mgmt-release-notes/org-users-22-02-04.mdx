Os usuários da plataforma New Relic One que são gerenciados por meio do [gerenciamento automatizado de usuários](/docs/accounts/accounts/automated-user-management/automated-user-provisioning-single-sign) anteriormente só podiam definir seu fuso horário por meio de seu provedor de identidade (IdP).

Agora todos os usuários podem substituir essas preferências de fuso horário atualizando-as no New Relic One. Isso é especialmente útil para clientes com IdPs que não podem enviar preferências de fuso horário para o New Relic.

Para fazer isso, basta acessar as preferências de usuário e atualizar o fuso horário. A nova preferência será salva automaticamente e substituirá o que está sendo enviado pelo provedor de identidade.

Para mais detalhes, consulte a [documentação de configuração de fuso horário](/docs/accounts/accounts-billing/general-account-settings/default-time-zone-setting).
