Lançamos a capacidade de exportar dados de usuário da interface de **User management**. Os dados são exportáveis via TSV. As colunas exportáveis incluem nomes de usuários, endereços de e-mail, tipo de usuário atual, grupos e ID de usuário. Os administradores podem escolher exportar todos os usuários ou selecionar um subconjunto de usuários.

Para mais detalhes, consulte [Exportar lista de usuários](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-ui-and-tasks).
