## Nova versão do modelo de preços do New Relic One com usuários core

Foi lançada uma nova versão do [modelo de preços do New Relic One](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/new-relic-one-pricing-billing) com um novo [tipo de usuário](/docs/accounts/accounts-billing/new-relic-one-user-management/user-type): o usuário core. As organizações nesta versão de preços têm acesso a três tipos de usuários: usuários básicos, usuários core e usuários completos da plataforma. O usuário core tem mais acesso do que os usuários básicos e custa menos do que um usuário completo da plataforma. Os usuários core têm acesso a alguns recursos poderosos centrados em desenvolvedores, como o New Relic CodeStream, nossa interface de logs e a capacidade de criar aplicativos do New Relic.

Esta versão de preços também [calcula os usuários faturáveis de forma diferente](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/user-count-billing#user-count) e possui [regras diferentes de downgrade de usuário](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/user-count-billing/#user-downgrade-rules).

Para obter mais informações sobre este lançamento e sobre a disponibilidade, consulte [Lançamento de Usuários Core](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/core-users-release).
