Boas-vindas ao guia de estilo da New Relic. Escrevemos estas diretrizes para os criadores de conteúdo em toda a New Relic e para os colaboradores dos nossos projetos de conteúdo de código aberto, como o Docs ou nossos outros repositórios do GitHub da New Relic.

Este guia não se destina a cobrir todas as dúvidas de uso. Para qualquer assunto não abordado explicitamente, remete-se ao [Microsoft Writing Style Guide](https://docs.microsoft.com/en-us/style-guide/welcome/) (em particular, à &quot;A–Z word list&quot; e ao guia [Formatting common text elements](https://docs.microsoft.com/en-us/style-guide/text-formatting/formatting-common-text-elements)) ou ao [Chicago Manual of Style](https://www.chicagomanualofstyle.org/home.html) (para diretrizes gerais de redação e edição).

As convenções do inglês americano são seguidas, embora, ao criar ativos específicos de um país, seja possível usar variações regionais do inglês. Por exemplo, um PDF com destino específico a clientes britânicos também poderia seguir as convenções do inglês britânico. Em caso de dúvida, recomenda-se o uso do inglês americano.

* Para a nossa estratégia de redação, consulte os documentos nesta seção sobre [voz](/docs/style-guide/writing-strategies/voice-strategies-docs-sound-new-relic/), [cinco perguntas para um ótimo conteúdo](/docs/style-guide/writing-strategies/five-questions-help-write-docs/), [como organizar o seu conteúdo](/docs/style-guide/writing-strategies/organize-doc) e muito mais.

* Para uma referência rápida sobre o uso de termos, consultar nosso [Dicionário de uso](/docs/style-guide/word-choice/usage-dictionary).
