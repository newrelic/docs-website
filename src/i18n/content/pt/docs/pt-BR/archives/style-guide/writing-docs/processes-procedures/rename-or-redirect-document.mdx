Este documento descreve como alterar o título de um documento e como criar, editar e excluir redirecionamentos. Os procedimentos são os mesmos tanto para documentos padrão (&quot;páginas básicas&quot;) quanto para notas de versão.

<Callout variant="caution">
  A alteração de títulos ou a atualização de redirecionamentos pode criar problemas na localização de conteúdo. Caso seja necessário alterar um título ou um redirecionamento, [crie uma issue no GitHub](https://github.com/newrelic/docs-website/issues/new/choose) ou, caso seja um funcionário da New Relic, entre em contato com o Docs hero por meio do canal #help-documentation no Slack.
</Callout>

## Formato de URL [#title-url]

A URL de um documento é baseada exclusivamente em seu nome de arquivo e caminho de arquivo no repositório do GitHub. Para mais informações, consulte [URL do documento](/docs/style-guide/processes-procedures/understand-edit-docs-site-structure#doc-url).

## Alterar títulos [#titles]

Para alterar o título de um documento, altere o título usado no campo `title` no frontmatter na parte superior do documento.

Caso deseje atualizar um título na barra lateral, altere o `title` para esse documento no arquivo de navegação.

## Alterar links de âncora [#anchors]

Sempre que possível, não altere o `[#anchor_ids]` de um H2 ou elemento expansível. Não há como redirecionar de uma âncora excluída para seu novo valor. Mesmo que a âncora `id` esteja desatualizada, isso não afeta a maioria dos usuários que não prestam atenção aos URLs.

## Editar Redirecionamentos [#redirects]

Ao alterar a URL de um documento, certifique-se de adicionar a URL antiga à seção de frontmatter `redirects` no topo do documento.
