Os expansores são elementos expansíveis que ocultam o conteúdo da página até que [sejam abertos](#trigger-collapser). Utilizamos expansores para ocultar o conteúdo em documentos muito longos, em consideração aos nossos leitores. Cada expansor possui um `title` (o que mostramos aos leitores), mas também um `id` que utilizamos para links de &quot;âncora&quot; profundos para expansores específicos.

Aqui está um exemplo de elemento retrátil:

<CollapserGroup>
  <Collapser id="collapser-1" title="Redutor 1">
    Este é o primeiro exemplo de redutor.
  </Collapser>

  <Collapser id="collapser-2" title="Redutor 2">
    Este é o nosso segundo colapsador de exemplo.
  </Collapser>
</CollapserGroup>

<Callout variant="tip">
  A macro do Keyboard Maestro para redutores é `kkcollapse`.
</Callout>

## Criar um agrupador [#create]

Para criar um collapser, será necessário usar o nosso código de collapser.

Aqui está um exemplo do código-fonte do collapser:

```jsx
<CollapserGroup>
  <Collapser
    id="collapser-1"
    title="Collapser 1"
  >
    This is our first example collapser.
  </Collapser>

  <Collapser
    id="collapser-2"
    title="Collapser 2"
  >
    This is our second example collapser.
  </Collapser>
</CollapserGroup>
```

## Gatilhos de Redutores [#trigger-collapser]

O site abre automaticamente as seções recolhíveis em alguns cenários:

* Chegar a um recolhedor individual por meio de um ID de âncora. Por exemplo, ir diretamente para o [Recolhedor 1 no exemplo acima](/docs/style-guide/quick-reference/collapsers#collapser-1).
* Deve-se usar **CMD+F** (ou **CTRL+F**) para localizar na página e todos os redutores serão abertos automaticamente.
* Digite a tecla de atalho `s` para **m**ostrar (abrir) todos os elementos recolhíveis na página.
