Esta página descreve a abordagem da equipe de documentação para documentar exemplos do OpenTelemetry.

## Fundo [#background]

Na documentação da New Relic para OpenTelemetry (OTel), fornecemos exemplos de AI Monitoring para demonstrar a configuração mais comum que esperamos que o usuário utilize. Historicamente, o site de documentação continha esses exemplos no site de documentação. No entanto, em maio de 2024, em um esforço conjunto com os Relics que trabalham no OTel, decidimos migrar esses exemplos do site de documentação para o repositório [newrelic-OpenTelemetry-examples](https://github.com/newrelic/newrelic-opentelemetry-examples/tree/main). Por exemplo, aqui está um PR onde movemos todos os exemplos de infraestrutura: [PR #17742](https://github.com/newrelic/docs-website/pull/17742).

## Por que oferecemos suporte a essa alteração [#why-we-support-this-change]

Os motivos para esta migração são:

* Reduzir a redundância tanto no repositório quanto no site de documentação: manter várias cópias incentiva (e quase garante) fontes de verdade divergentes e degradação de dados.
* Facilitar o consumo dos exemplos: escrever exemplos com texto, como &quot;Coloque o conteúdo X em um arquivo chamado Y&quot;, é uma experiência ruim para os desenvolvedores, pois consome muito tempo e é propensa a erros. É muito melhor clonar um repositório, atualizar uma ou duas variáveis de ambiente e executar um comando.
* Ênfase em exemplos de código funcionais para uso interno e externo: internamente, os dados desses exemplos são a fonte da verdade sobre a qual construímos experiências de produto. Externamente, esses exemplos são a fonte da verdade sobre como realizar uma tarefa específica com o New Relic e o OpenTelemetry (desviar-se desse caminho pode gerar resultados variados).
* Reduza a carga de manutenção: tanto a equipe do OTel quanto a de documentação são pequenas, com muita área de superfície.

## Como lidamos com requests para futuros exemplos do OTel [#how-we-handle-requests]

Daqui em diante, todos os exemplos de OTel são criados e mantidos no repositório [newrelic-opentelemetry-examples](https://github.com/newrelic/newrelic-opentelemetry-examples/tree/main), com uma referência mencionada no site de documentação.

Para propor um novo exemplo (de acordo com as [diretrizes de contribuição](https://github.com/newrelic/newrelic-opentelemetry-examples/tree/main?tab=readme-ov-file#contribute)), por gentileza, siga estas etapas:

1. Abrir uma issue para discussão: antes de enviar um pull request, abrir uma issue no repositório [newrelic-opentelemetry-examples](https://github.com/newrelic/newrelic-opentelemetry-examples/tree/main). Isso permite que a equipe do OTel discuta e garanta que o exemplo esteja alinhado com as áreas de foco da equipe.

2. Demonstrar valor mensurável: nosso foco está em exemplos que se traduzem diretamente no sucesso do usuário. Idealmente, estes mostrarão:

   * Dashboard acionáveis: o exemplo deve fornecer um dashboard pronto para uso para a visualização dos dados.
   * Experiências selecionadas: indo além dos dashboards, considere incluir a síntese de entidade pré-configurada ou outros elementos que aprimorem a proposta de valor.
