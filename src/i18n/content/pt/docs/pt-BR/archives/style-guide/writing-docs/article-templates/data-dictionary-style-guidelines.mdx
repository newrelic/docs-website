A equipe de documentação mantém um dicionário de dados que armazena informações de metadados sobre os tipos de dados padrão no banco de dados do New Relic (por exemplo, Transação, Métrica, Log) e seus atributos relacionados. Esses metadados são publicados pelo nosso serviço de dicionário de atributos em dois lugares:

* As experiências de consulta da interface do New Relic exibem essas informações ao passar o mouse sobre os tipos de dados e atributos.
* Os dados aparecem no [dicionário de atributos](https://docs.newrelic.com/attribute-dictionary/) do site de documentação.

<Callout variant="tip">
  A seguir, apresentam-se algumas limitações sobre o escopo dos dados:

  * Atualmente, a única informação relacionada à infraestrutura que temos no dicionário de atributos é para o Kubernetes.
  * Também temos muito poucos atributos para o tipo de dados de métrica — apenas alguns básicos padrão — apesar de muitos atributos potenciais que poderiam ser anexados a alguns tipos de dados.
</Callout>

Caso atue como redator na New Relic e precise fazer alterações no dicionário de dados, as alterações deverão ser feitas em nosso repositório privado no GitHub Enterprise. Recomenda-se consultar o drive da equipe no Google Docs interno sobre como configurar o repositório e onde encontrar as instruções do README.md.
