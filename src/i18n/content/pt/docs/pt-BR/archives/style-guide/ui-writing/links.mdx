Os links em nossa interface precisam ser concisos e corresponder ao nosso estilo e voz.

## Conceitos Básicos

* Mantenha o vincular texto curto para otimizar para leitores de tela.
* Comece com o benefício para o leitor, não com o local do link.
* Recomenda-se utilizar linguagem coloquial, pronomes e contrações, como é feito em nossos outros textos.
* Use o nome ou a descrição do local, em vez de simplesmente &quot;este link&quot;.
* Para links que levam os usuários para fora do produto (como para os nossos sites de Documentação ou Suporte), deve-se adicionar o ícone de link externo ao final.

## Código

Ao apresentar trechos de código aos clientes, formate-os com a fonte monoespaçada Menlo.

```js
var example = "This is an example string in a monospace font!";
```

## Listas

* A primeira letra de cada item da lista deve ser maiúscula.
* Para listas gerais de informações, use listas não ordenadas (com marcadores).
* Para listas com etapas específicas, use uma lista ordenada (numerada).
