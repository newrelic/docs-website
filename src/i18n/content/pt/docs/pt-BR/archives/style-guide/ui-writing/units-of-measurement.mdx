## Conceitos Básicos

* As unidades de medida devem ser separadas do seu valor com um único espaço.
* Para medições ao longo do tempo, deve-se inserir uma barra entre a unidade de medida e a unidade de tempo.

| Unidade de medida     | Faça      | Não      |
| --------------------- | --------- | -------- |
| requests por minuto   | 29,5K rpm | 29,5Krpm |
| requests por segundo  | 14 rps    | 14rps    |
| páginas por minuto    | 6,33 ppm  | 6,33ppm  |
| kilobytes por segundo | 16 KB/s   | 16 KB s  |
