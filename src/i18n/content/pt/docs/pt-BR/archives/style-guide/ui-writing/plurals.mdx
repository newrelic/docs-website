A pluralização de substantivos resulta em mudanças sutis na pontuação e ortografia que podem impactar a forma como as pessoas interpretam as palavras escritas.

## Conceitos Básicos

* Use apóstrofos para formar o plural de letras únicas.
* Não se devem usar apóstrofos para pluralizar siglas.

| Faça                                        | Não                                               |
| ------------------------------------------- | ------------------------------------------------- |
| Existem 2 &apos;u&apos;s na palavra vacuum. | Existem 2 us na palavra vacuum.                   |
| Não se esqueça de colocar os pingos nos is. | Não se deve esquecer de colocar os pingos nos is. |
| Abordaremos o básico dos IPs.               | Abordaremos os princípios básicos dos IPs.        |
