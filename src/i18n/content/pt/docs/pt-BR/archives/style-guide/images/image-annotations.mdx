As anotações de imagem são textos e formas em capturas de tela ou diagramas que ajudam a referenciar informações e focar a atenção nos aspectos mais importantes da captura de tela. Recomendamos que sejam usadas com cautela, pois às vezes podem ser uma distração e também são difíceis de manter atualizadas. É importante ter em mente que é possível usar alternativas como [legendas de imagens](/docs/style-guide/images/screenshots-images/#captions) ou instruções diretamente no texto.

Caso seja necessário utilizar anotações de imagem:

* Ser conciso.
* Certifique-se de que as anotações sejam fáceis de distinguir do texto da interface. Por exemplo, pode ser necessário deslocar as caixas para que não pareçam elementos da interface.
* As anotações não são traduzidas, portanto, devem ser usadas com moderação.
* Não se deve usar uma anotação na parte superior que atue como um título. Utilizar uma legenda.
* Garantir que as anotações estejam visíveis nos modos claro e escuro.
* Recomenda-se o uso do nosso [tema SnagIt da New Relic](https://github.com/newrelic/newrelic-doc-tools) (link disponível apenas para funcionários da New Relic) para manter as anotações consistentes.

## Instale o tema New Relic SnagIt [#install-theme]

Siga esses passos:

1. Certifique-se de estar executando a versão mais recente do SnagIt.

2. No GitHub Desktop, o [repositório](https://github.com/newrelic/newrelic-doc-tools) deve ser clonado localmente.

3. Deve-se abrir o SnagIt e selecionar qualquer ferramenta para abrir a navegação direita.

4. No painel **Quick Styles** na navegação à direita, selecionar o ícone de engrenagem no campo **Theme** e, em seguida, **Import**.

5. Na caixa de diálogo que abrir, vá para `YOUR_GIT_DIRECTORY/newrelic-doc-tools/themes`, selecione o arquivo `New-Relic-Docs.snagtheme` e clique em **Open**.

## Caixas de balões [#callout-boxes]

Usar caixas de chamada para destacar um elemento em uma captura de tela. Se possível, não adicionar texto à captura de tela, é para isso que serve a nossa documentação. As caixas de chamada não devem obstruir nenhum dos elementos que estão destacando. Por exemplo, uma caixa de chamada ao redor de um botão da interface não deve cobrir nenhuma parte do botão. Se possível, inserir um espaço de dois pixels entre o elemento da interface e a caixa de chamada.

Este é o formato para adicionar caixas de balões:

* Forma: quadrado ou retângulo, preenchimento transparente, sem raio de borda.
* Cor da borda: #00CE7C
* Largura da linha: 5pt
* Opacidade: 100%
* Estilo de linha: sólido
* Sem sombras

## Texto de balão [#callout-text]

As capturas de tela não devem exigir um texto explicativo em 99% das vezes; as tags `<figcaption>` e o conteúdo escrito antes ou depois da imagem devem ser suficientes para explicar a captura de tela. No entanto, se uma caixa de texto for necessária, ela não deve se sobrepor a nenhum texto ou elemento essencial da interface.

Caso seja necessário adicionar texto a uma captura de tela, as seguintes diretrizes devem ser seguidas:

* Forma: quadrado ou retângulo, cor de preenchimento #00CE7C.
* Cor da borda: #00CE7C
* Largura da linha: 5pt
* Opacidade: 100%
* Estilo de linha: sólido
* Sem sombras
* Fonte: Arial negrito #FFFFFF, tamanho 24pt, alinhado à esquerda

## Setas [#arrows]

Utilize uma seta de ponta única ou uma seta com pontas em cada extremidade na captura de tela quando desejar referenciar elementos dentro da interface.

Se uma seta for usada, deve-se tentar não sobrepor nenhum texto ou elemento essencial da interface.

Este é o formato para adicionar uma seta:

* Opacidade: 100%
* Largura da linha: 7 pt
* Cor: #00CE7C
* Estilo de linha: sólido, sem tamanho inicial, tamanho final para 5
* Sem sombras
