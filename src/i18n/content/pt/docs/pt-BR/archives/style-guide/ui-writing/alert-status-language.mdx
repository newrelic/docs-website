## Conceitos Básicos

São mostrados indicadores coloridos para o status de alerta na interface, e é importante utilizar uma linguagem consistente em todas as telas da interface e APIs. Também está sendo incluído mais neste status do que apenas alertas.

Deve-se incluir um estado de hover para explicar o significado da cor, quando necessário. Para os emblemas de status principais em uma página de entidade individual, o estado de hover listará o que contribui. Se isso não for possível, devem ser utilizados os estados de hover abaixo.

## Mapeamento entre a terminologia da interface e da API

| Cor      | Passar o mouse na interface (dica de ferramenta) | Rótulo de status da interface  | API             |
| -------- | ------------------------------------------------ | ------------------------------ | --------------- |
| Vermelho | Incidente crítico em andamento                   | Crítico                        | CRÍTICO         |
| Amarelo  | Incidente de aviso em andamento                  | Degradado                      | AVISO           |
| Verde    | Nenhum alerta em andamento                       | Operacional                    | NOT\_ALERTING   |
| Cinza    | Não reportando                                   | Status desconhecido            | NOT\_CONFIGURED |
| Sem cor  | -sem estado de passar o mouse-                   | -sem estado de passar o mouse- |                 |
