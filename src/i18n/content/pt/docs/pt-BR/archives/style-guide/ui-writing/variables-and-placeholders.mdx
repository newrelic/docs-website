## Variáveis

Recomenda-se o uso de variáveis quando for necessário inserir um valor calculado ou o resultado de uma consulta em uma frase de fácil leitura. A orientação é a mesma, independentemente de esses itens serem chamados de preenchimentos, reposições, substituições ou qualquer outro termo.

### O que é uma variável? Os itens em negrito abaixo.

| No código                                                                                            | Na interface                                                          |
| ---------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| Detectamos comportamento anômalo em **\[service name]**.                                             | Detectamos comportamento anômalo em **RPM-interface-production**.     |
| **\[% de falhas]** das falhas compartilham o sistema operacional **\[tipo de sistema operacional]**. | **80%** das falhas compartilham o sistema operacional **iOS 11.1.2**. |

### Conceitos Básicos

Se o valor inserido for curto, ele deve ser colocado no local mais lógico da frase para que soe natural. Se o valor for longo, não legível ou, de outra forma, fora de controle, ele deve ser colocado no final da frase. Se a variável puder ser qualquer parte do discurso ou, às vezes, singular e, às vezes, plural, ela deve ser separada por dois-pontos ou colocada em outra linha.

| Faça                                                                                    | Não                                                                                           |
| --------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Detectamos comportamento anômalo em **bob-long-name-32-october-service-legado-system**. | O serviço **bob-long-name-32-october-service-legado-system** apresenta comportamento anômalo. |
| **80%** das falhas compartilham o nome de usuário **pdiddybigdog**.                     | **80%** das falhas compartilham o nome de usuário **pdiddybigdog**.                           |
| Serviços com múltiplos erros: **1**                                                     | **1** serviços apresentam vários erros.                                                       |

## Texto de espaço reservado

Para texto de espaço reservado em campos de entrada, deve-se usar &quot;Exemplo:...&quot; E em lugares como documentação, onde são adicionados exemplos em linha, deve-se usar &quot;como,&quot;. Por exemplo, &quot;X requer uma ação para ser descartado (como, confirmar que um usuário deseja excluir um dashboard).&quot;
