O uso de letras maiúsculas ajuda a comunicar a importância de palavras específicas e pode ser usado para indicar uma mudança de significado. Para manter a eficácia, é necessário limitar o que é capitalizado.

## Conceitos Básicos

* A partir de fevereiro de 2023, deve-se utilizar iniciais maiúsculas para três tipos de conteúdo de interface:

  * Títulos de página
  * Navegação esquerda (navegação principal)
  * Títulos nos blocos da página All Capabilities

* Deve-se usar o formato de frase no restante do tempo.

* Coloque em maiúscula a primeira letra de nomes próprios (nomes de produtos, países, siglas e nomes de pessoas), independentemente de onde apareçam em uma frase.

* Os nomes de produtos devem ser iniciados com letra maiúscula conforme descrito na página [Produtos e recursos: letras maiúsculas, marcas comerciais e uso](/docs/style-guide/capitalization/product-capability-feature-usage).

* Não se deve usar letras maiúsculas em artigos (a, an, the) ou preposições (of, on, for, in, to, with, etc.), a menos que estejam no início de uma frase.

| Faça                                | Não                                 |
| ----------------------------------- | ----------------------------------- |
| Os 5 principais traces da transação | Top 5 Traces da Transação           |
| New Relic é um substantivo próprio. | New Relic é um substantivo próprio. |
| Experimente os novos dashboards.    | Experimente os novos Dashboards.    |
| Estátua da Liberdade                | Estátua da Liberdade                |

## Unidades de medida

As abreviações de memória, largura de banda e espaço em disco têm regras variadas para uso de maiúsculas.

* Sempre inclua um espaço entre o valor e a unidade de medida.
* Um único bit de dados é em letras minúsculas (b), enquanto 1.204+ bits é em formato de frase (13 Kb).
* Os bytes são sempre em maiúsculas (13 KB, 512 MB).

Pesos e distâncias estão em letras minúsculas, sem pontos após a abreviação (ft, lbs, km).

| Faça    | Não     |
| ------- | ------- |
| 32 Kb/s | 32 kb/s |
| 16 s    | 16s     |
| 0,43 MB | 0,43 MB |
| 15 pés  | 15 pés. |
