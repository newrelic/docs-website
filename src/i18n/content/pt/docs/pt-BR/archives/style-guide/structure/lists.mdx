As listas são uma maneira poderosa de organizar informações, mas nem sempre proporcionam uma experiência de leitura agradável. Tenha estes pontos em mente ao escrever uma lista:

* Deve-se sempre colocar em maiúscula a primeira letra da primeira palavra em cada item da lista.
* Utilizar listas ordenadas (numeradas) para procedimentos passo a passo, onde a ordem importa.
* Recomenda-se usar listas não ordenadas (com marcadores) para facilitar a leitura dinâmica de informações relacionadas pelo usuário.
* Deve-se usar OR em uma linha separada quando houver mais de uma opção para uma etapa numerada ou um marcador.
* Recomenda-se o uso de tabelas quando a lista ordenada ou não ordenada se beneficiar de alguns detalhes adicionais.

<Callout variant="tip">
  Para diretrizes de pontuação, recomenda-se seguir o **[Guia de Estilo de Redação da Microsoft](https://docs.microsoft.com/en-us/style-guide/scannable-content/lists),** que inclui considerações para localização.
</Callout>

## Listas em linha [#inline-lists]

Como alternativa ao uso de listas com marcadores, é possível fazer uma lista em linha, como esta: [C SDK](/docs/agents/c-sdk/instrumentation/enable-distributed-tracing-your-c-applications) | [Go](/docs/agents/go-agent/features/distributed-tracing-go#create-manually) | [Java](/docs/agents/java-agent/api-guides/guide-using-java-agent-api#trace-calls).

Pode ser útil usar uma lista em linha quando:

* Está sendo feito um link para documentação adicional.
* Os clientes provavelmente selecionarão uma única opção.
* O item da lista pode ser exibido com uma palavra ou frase curta (como Java ou infraestrutura).
* Pode-se considerar que uma lista de marcadores ocupa muito espaço vertical. Isso pode ocorrer em circunstâncias nas quais um procedimento deve incluir várias listas. Aqui está [um exemplo disso](/docs/understand-dependencies/distributed-tracing/enable-configure/enable-distributed-tracing#enable).
* Há apenas duas ou três opções potenciais de escolha e uma lista de marcadores parece desnecessária. Aqui está [um exemplo](/install/dotnet#requiremnts).
