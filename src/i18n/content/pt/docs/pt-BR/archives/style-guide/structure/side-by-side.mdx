O componente `SideBySide` permite dividir a tela pela metade, ou em mais seções. Um caso de uso comum é mostrar uma captura de tela na coluna da direita e o texto de acompanhamento na esquerda.

É necessário envolver o conteúdo de cada lado dentro de um componente `Side`, mas é possível adicionar quanto conteúdo for necessário dentro de cada `Side`.

Tecnicamente, o componente suporta mais de duas colunas `Side`, mas deve-se evitar o uso de mais de duas.

Aqui está um exemplo do componente:

<SideBySide>
  <Side>
    <img alt="example" src="/images/network_screenshot-full_device-performance.webp" />

    <figcaption>
      Acesse **[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Network**
    </figcaption>
  </Side>

  <Side>
    Este é um conteúdo excelente da incrível equipe de documentação.
  </Side>
</SideBySide>

## Criar um componente SideBySide [#create]

Aqui está um modelo de um componente `SideBySide`:

```jsx
<SideBySide>
    <Side>
        <img alt="Example" src="/images/example-image.webp" />
    </Side>

    <Side>
        This is some awesome content from the amazing documentation team.
    </Side>
</SideBySide>
```

<Callout variant="tip">
  A macro do Keyboard Maestro para o SideBySide é `kkside`.
</Callout>
