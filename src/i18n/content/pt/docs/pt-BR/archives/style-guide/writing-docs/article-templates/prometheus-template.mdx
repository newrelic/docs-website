## Habilite a integração

As métricas do Prometheus precisam ser integradas ao New Relic, é possível usar o agente do Prometheus ou a integração Remote Write, consulte [como enviar métricas do Prometheus](https://docs.newrelic.com/docs/infrastructure/prometheus-integrations/get-started/send-prometheus-metric-data-new-relic/).

Após a integração, utilize a seguinte consulta para confirmar se as métricas estão sendo ingeridas conforme o esperado:

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'integrationName_%' FACET metricName LIMIT MAX
```

As entidades de integração também são visíveis no [explorador de entidades](/docs/new-relic-solutions/new-relic-one/core-concepts/new-relic-explorer-view-performance-across-apps-services-hosts#find) com métricas clássicas associadas e um dashboard integrado.

## Encontre e use os dados

### Métrica

As métricas do Prometheus são armazenadas como métricas dimensionais. Você pode [consultar usando NRQL](/docs/telemetry-data-platform/get-data/apis/query-metric-data-type/) ou usar o [Data Explorer](/docs/query-your-data/explore-query-data/browse-data/introduction-data-explorer/) para navegar pelas métricas, facetas disponíveis e filtrar pelas dimensões associadas.

Os diferentes conjuntos de métricas expostos por \[adicione aqui o nome da integração] são definidos na \[documentação do nome\_da\_integração]\(adicione um link para a documentação do provedor).

Use a seguinte consulta NRQL para entender a métrica que está sendo ingerida no New Relic:

* Liste nomes de métricas exclusivos:

  ```sql
  FROM Metric SELECT uniques(metricName) WHERE metricName LIKE 'integrationName_%' LIMIT MAX
  ```

* Contar o número de atualizações métricas:

  ```sql
  FROM Metric SELECT datapointcount() WHERE metricName LIKE 'integrationName_%' FACET metricName
  ```

* Estimar a ingestão de dados (ingestão diária, em bytes):

  ```sql
  FROM Metric SELECT bytecountestimate() WHERE metricName LIKE 'integrationName_%' SINCE 1 day ago
  ```
