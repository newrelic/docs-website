As tabelas ajudam a organizar as informações para facilitar a leitura dinâmica pelos leitores. No entanto, se a tabela ficar muito longa, recomenda-se seguir a [diretriz de &quot;cinco a nove&quot;](/docs/style-guide/get-started/introduction-style-guide#organization) e considerar a reestruturação das informações de outras maneiras.

Usar maiúscula inicial para o texto em cada coluna da tabela, a menos que seja um nome de arquivo específico ou valor de código que exija letras minúsculas ou todas maiúsculas.

<Callout variant="tip">
  A macro do Keyboard Maestro para o componente Table é `kktable`
</Callout>

## Sintaxe de tabela

Nossas tabelas são criadas como componentes MDX React. Na prática, são bastante semelhantes às tabelas HTML:

```html
<table>
    <thead>
        <tr>
            <th style={{ width: "200px" }}>
                Item
            </th>
            <th>
                Description
            </th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>
                Item name
            </td>
            <td>
                Description of item
            </td>
        </tr>
    </tbody>
</table>
```

<Callout variant="tip">
  O site de documentação tecnicamente suporta [tabelas Markdown](https://www.markdownguide.org/extended-syntax/#tables), mas evita-se o uso delas por alguns motivos:

  * Existem várias variantes de Markdown, e diferentes variantes usam diferentes sintaxes de tabela. Isso ocorre porque a especificação original do Markdown de John Gruber não incluía tabelas.
  * As tabelas em Markdown não suportam elementos que ocupam várias linhas, e a maioria das nossas tabelas inclui blocos de código, listas com marcadores ou outros elementos que exigem várias linhas.
</Callout>

## Definindo a largura da coluna [#column-width]

É possível definir a largura da coluna com uma regra de estilo no elemento `<th>`:

```html
<th style={{ width: "200px" }}>
```

Em geral, para tabelas de duas colunas no site de documentação:

1. Defina a primeira coluna como 200 pixels: `style={{ width: "200px" }}`.
2. Para permitir que a tabela se ajuste automaticamente à largura restante da página, não se deve definir uma largura para a segunda coluna.

## Tabelas para descrever funções da interface [#tables-ui]

Ao usar tabelas para descrever as funções disponíveis, deve-se fornecer um roteiro aos leitores. Eles podem saber o que desejam encontrar ou realizar, mas podem não saber como isso é chamado ou como fazê-lo.

Por exemplo, para fornecer uma lista de recursos para uma página de interface específica, rotule a primeira coluna do cabeçalho como **Se desejar...** e rotule a segunda coluna como **Faça isso**.
