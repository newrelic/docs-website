Estes três elementos formam o núcleo que impulsiona o nosso negócio. Os clientes dependem de dados numéricos para medir o desempenho de seus sistemas, enquanto as datas e a hora fornecem o contexto muito necessário para essas informações.

## Conceitos Básicos

* Escreva os números como numerais, independentemente de onde apareçam em uma frase
* Devem-se usar vírgulas para números com 4 ou mais dígitos.
* Se a precisão numérica absoluta for menos importante do que dar aos clientes uma noção do número, não há problema em arredondá-los para algo como 1k (para 1.012) ou 324,5 milhões (para 324.501.082). Recomenda-se usar o melhor critério neste caso.
* Nunca se devem escrever números inteiros com uma casa decimal e zero à direita.

| Faça                                | Não                                     |
| ----------------------------------- | --------------------------------------- |
| 1.024 KB                            | 1.024 KB                                |
| Os 5 principais traces da transação | Os cinco principais traces da transação |
| 2 segundos                          | 2,0 segundos                            |

## Números grandes

Utilizamos o inglês americano comum para nossa interface, o que cria alguns desafios com números grandes. As convenções internacionais e do inglês americano para milhar são as mesmas: um k minúsculo. Mas milhão, bilhão e trilhão são mais complicados porque as abreviações diferem entre regiões e setores. Por esse motivo, abreviamos apenas milhar, nossa contagem mais comum.

* Abrevie milhar com um k minúsculo com um espaço entre o último número e a letra: 50 k.
* Ao lidar com números maiores, recomenda-se usar um espaço e, em seguida, escrever por extenso milhão, bilhão, trilhão, etc., em letras minúsculas. Se o espaço for muito restrito e for necessário abreviar, recomenda-se usar B, M, T, mas apenas se a grafia completa for fornecida em outro lugar na tela ou no gráfico e o número completo ao passar o mouse.
* Se possível, forneça o número completo ao passar o mouse.

| Na interface  | Ao passar o mouse (sempre que possível) | Não            |
| ------------- | --------------------------------------- | -------------- |
| 50,2 k        | 50.200                                  | 50,2k          |
| 50,2 milhões  | 50.200.000                              | 50,2m, 50,2M   |
| 50,2 bilhões  | 50.200.000.000                          | 50,2G, 50,2B   |
| 50,2 trilhões | 50.200.000.000.000                      | 50,2 T, 50,2 t |

## Data e hora

Utiliza-se a formatação automática de data e hora por navegador a partir do [formatador padrão](https://unicode-org.github.io/icu/userguide/format_parse/datetime/). Se esses valores estiverem sendo codificados no produto, deve-se consultar nosso sistema de design interno. Para extrair a formatação correta, recomenda-se usar os hooks usedate e usetime.

Nota: o único desvio feito do formatador padrão é com a opção de relógio de 24 horas (preciso e longo). Para 12:30 AM, utiliza-se 00:30 em vez de 24:30.

| Opções de useDate | Exemplo de saída        |
| ----------------- | ----------------------- |
| Básico (padrão)   | 24 de fevereiro de 2022 |
| curto             | 24 de fevereiro de 2022 |

| Opções de useTime | Exemplo de saída                 |
| ----------------- | -------------------------------- |
| Básico            | 00:16                            |
| Dia               | 24 de fevereiro às 00:16         |
| dia curto         | 24 de fevereiro, 00:16           |
| Preciso           | 00:16:36,969                     |
| Longo             | 00:16:36                         |
| (Em breve)        | 24 de fevereiro de 2022 às 00:16 |
| (Em breve)        | 24 de fevereiro de 2022, 00:16   |

## Abreviação de Unidades de Tempo

Todas as unidades devem ser escritas por extenso sempre que possível.

Se o espaço for muito limitado, as seguintes abreviações padrão devem ser usadas:

| Unidade      | Preferido       | Abreviação (quando necessário) |
| ------------ | --------------- | ------------------------------ |
| Milissegundo | 4 milissegundos | 4 ms                           |
| Segundos     | 5 segundos      | 5 s                            |
| Minutos      | 6 minutos       | 6 min                          |
| Horas        | 7 horas         | 7 h                            |
| Dias         | 8 dias          | 8 d                            |
| Semanas      | 9 semanas       | 9 semanas                      |
| Meses        | 10 meses        | 10 meses                       |
| Anos         | 11 anos         | 11 anos                        |

## Decimais e frações

* Escreva valores fracionários em formato decimal.
* Arredondar os números fracionários 2 casas decimais para a direita.
* Incluir um 0 à esquerda em números decimais menores que 1.

| Faça    | Não       |
| ------- | --------- |
| 0,92 ms | 0,92 ms   |
| 16,23 s | 16,2822 s |

## Dinheiro

* Deve-se omitir o decimal final e os zeros para valores inteiros em dólares.
* Deve-se colocar o símbolo de moeda apropriado antes do valor em dólares, sem espaços.
* Ao incluir a moeda com um preço, a moeda vem no final com um espaço entre ela e o valor em dólares.

| Faça        | Não         |
| ----------- | ----------- |
| $ 32        | $ 32,00     |
| $ 32,75     | ---         |
| $ 14,99 USD | USD $ 14,99 |

## Porcentagens

* Use o símbolo % sem espaço entre o número e o símbolo.
* Para valores fracionários em formato decimal, deve-se sempre incluir um zero à esquerda.

**EXCEÇÃO** - quando a precisão exata for necessária, como com dados de Sintéticos, é possível usar até três casas decimais em porcentagens.

| Faça                  | Não  |
| --------------------- | ---- |
| 25%                   | 25%  |
| 0,3%                  | 0,3% |
| **(EXCEÇÃO)** 62,356% | ---  |
