De forma semelhante à pontuação, a formatação do texto pode ter um grande impacto na maneira como as pessoas interpretam as nossas palavras. Por exemplo, é possível usar o texto em negrito como uma ferramenta simples para dar ênfase em uma mensagem, ou é possível usá-lo para guiar os olhos de uma pessoa pela interface para que ela saiba instintivamente o que é importante.

## Conceitos Básicos

* O texto em negrito é frequentemente utilizado para melhorar a escaneabilidade na interface e enfatizar palavras específicas em textos mais longos.
* O itálico é frequentemente usado para texto de dica contextual sob elementos de entrada e pode transmitir um tom focado ou um tom suave ao texto.
* O texto sublinhado na interface pode ser facilmente interpretado como um link, portanto, tenha cuidado ao usar o formato para uma finalidade diferente. Considere encontrar uma solução alternativa para palavras sublinhadas que não funcionarão como links.

## Código

Ao apresentar trechos de código aos clientes, formate-os com a fonte monoespaçada Menlo.

```javascript
var example = 'This is an example string in a monospace font!';
```

## Listas

* A primeira letra de cada item da lista deve ser maiúscula.
* Para listas gerais de informações, use listas não ordenadas (com marcadores).
* Para listas com etapas específicas, use uma lista ordenada (numerada).
