O New Relic One permite que os usuários criem e nomeiem os próprios gráficos, mas também possui alguns gráficos selecionados que fornecemos. Os nomes desses gráficos precisam ser claros e descritivos, para que os usuários saibam o que estão vendo.

## Conceitos Básicos

* Use palavras-chave claras.
* Fornecer informações suficientes para explicar a finalidade do gráfico; evitar nomes de uma palavra.
* Priorizar a precisão em vez da consistência. Preferimos ter nomes ligeiramente diferentes para gráficos semelhantes a seguir uma convenção de nomenclatura que seja perfeita para alguns gráficos, mas imprecisa para outros.
* Manter os nomes em formato de frase.

| Faça                        | Não                  |
| --------------------------- | -------------------- |
| As 5 transações mais lentas | Transação            |
| Detalhamento de erros por:  | Erros                |
| Agrupar trace por:          | Agrupamento de trace |
