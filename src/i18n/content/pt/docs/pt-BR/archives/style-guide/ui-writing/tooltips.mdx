Temos vários casos de uso para dicas de ferramentas, todos os quais precisam de linguagem e direção claras e acessíveis.

## Conceitos Básicos

* Deve-se pensar no que o usuário precisa saber, sentir e fazer em cada situação.
* Utilize linguagem coloquial.
* Para dicas de ferramentas de uma única linha, como nomes de ícones e ações, deve-se manter a linguagem curta e específica, e não terminar com um ponto final.
* Para tooltips mais ricos, como definições, incluir por que o elemento é importante para o usuário e terminar as frases completas com um ponto final.
* Deve-se incluir um link para mais informações onde disponível.
