O objetivo é ajudar a decidir para onde enviar o leitor quando ele quiser instalar algo e começar a enviar dados para a New Relic.

## Uma visão geral dos métodos de instalação [#overview]

Atualmente, existem três métodos que os clientes podem utilizar para instalar o New Relic e iniciar o monitoramento de algo:

1. Instalação guiada, nossa ferramenta interativa de linha de comando para instalar o New Relic em diferentes sistemas
2. Instalação manual por meio da página &quot;+ Add more data&quot; na interface
3. Instalação manual pelo site de documentação

A observabilidade instantânea (I/O) **não** é um método de instalação. Ela simplesmente fornece um catálogo de todas as coisas que alguém poderia monitorar por meio do New Relic. Uma página de observabilidade instantânea simplesmente aponta para um desses três métodos, dependendo do que estiver disponível.

O CodeStream possui seu próprio método de instalação.

## Instalação guiada [#guided]

A [instalação guiada](/docs/new-relic-one/install-configure/new-relic-guided-install-overview/) fornece um único comando que pode ser executado no sistema para instalar o New Relic e iniciar o monitoramento de diversas coisas.

Quando alguém executa o comando da CLI de instalação guiada, ele instala o agente de infraestrutura e ativa o envio de logs. Ele também detecta integrações em um sistema e exibe prompts para a escolha de monitorar ou não essas integrações. Se a instalação guiada detectar um aplicativo de uma linguagem compatível, ela poderá instalar o agente APM para essa linguagem.

Para a documentação, devemos direcionar as pessoas para a instalação guiada sempre que for apropriado fazê-lo. Ou seja, quando for provável que a instalação guiada leve a um resultado bem-sucedido.

## Instalação manual por meio de adicionar mais dados [#manual-add]

As páginas [Adicionar mais dados](https://one.newrelic.com/marketplace?state=7ca7c800-845d-8b31-4677-d21bcc061961) fornecem um caminho de instalação simples e direto para pessoas que desejam instalar agentes APM e que estão usando as integrações mais populares e as configurações de sistema mais comuns para essas integrações.

**Adicionar mais dados** preenche os arquivos de configuração de instalação com valores como o nome do aplicativo e a chave de API para que os clientes não precisem procurar essas informações. Eles também fornecem o caminho de instalação mais direto para casos de uso padrão.

Esse método é menos eficaz para clientes que têm itens mais complicados ou obscuros que estão tentando monitorar ou sistemas fora do padrão.

**Adicionar mais dados** também tem a vantagem de estar na interface.

## Instalação manual pelo site de documentação [#manual-docs]

Os procedimentos de instalação manual, como esta [instalação manual do Java](/docs/apm/agents/java-agent/installation/install-java-agent), devem ser o método de último recurso. As instruções de instalação no site de documentação provavelmente estão desatualizadas. Elas também são apresentadas de uma forma bastante confusa que pode, de fato, impedir as pessoas de instalar o New Relic. Do ponto de vista da documentação, esse é o padrão, porque é onde nossa energia e atenção estão concentradas. Também é o lugar onde podemos fazer alterações facilmente.

Em um esforço para ser universalmente abrangente, nossos documentos de instalação manual apresentam um processo que parece ser incrivelmente complexo. No entanto, a complexidade está na variedade de opções. Para qualquer processo de instalação, as etapas são bastante simples, uma vez que o usuário tenha identificado o processo de instalação que precisa usar.

## Observabilidade instantânea [#io]

A [observabilidade instantânea](https://newrelic.com/instant-observability) é um catálogo público de itens que podem ser monitorados pela New Relic e de dashboard e alertas padrão úteis. Nesse catálogo, há algumas tecnologias que não se encaixam nesse modelo, como o CodeStream ou o Atlassian Jira.

Para a maioria das páginas de início rápido, o botão **Instalar agora** leva à instalação guiada, a uma página de adicionar mais dados ou a uma página de documentos de instalação manual, dependendo do que estiver disponível para essa tecnologia específica.

## Integração &amp; agente na interface [#add-data]

Na interface, o [+ integração &amp; agente](https://one.newrelic.com/marketplace?state=7ca7c800-845d-8b31-4677-d21bcc061961) leva a uma versão do catálogo de observabilidade instantânea que conduz um usuário mais diretamente pelo processo de integração de uma tecnologia específica.
