Introdução: esta seção apresentará o agente e a API em termos gerais. Fale sobre quando um usuário desejaria a API e as alternativas ao uso da API (por exemplo, instrumentação via arquivo XML). Mencione que a API geralmente é desnecessária se o seu framework tiver suporte &quot;pronto para uso&quot;. Crie um link para a raiz da sua referência da API, seja ela no local ou externa. Avise o usuário que ele precisa estar na versão mais recente do agente.

## Instrumento faltando seções do seu código com transação [#creating-transactions]

Para instrumentar o aplicativo, o New Relic separa cada caminho pelo código em sua própria transação. O New Relic cronometra (ou mantém &quot;instrumentado&quot;) o método pai nestas transações para medir o desempenho geral do aplicativo e coleta o trace da transação de transações de longa duração para detalhes adicionais. Para obter mais informações sobre transações, consulte [transação](/docs/accounts-partnerships/education/getting-started-new-relic/glossary#transaction) e [trace da transação](/docs/apm/transactions/transaction-traces/introduction-transaction-traces).
