Os pop-overs fornecem muita orientação em um espaço pequeno para os nossos leitores. Os popovers fornecem definições rápidas em linha de conceitos-chave e oferecem um caminho para aprender mais na documentação ou experimentar na interface.

<img title="Popover" alt="A screenshot of a popover" src="/images/style-guide_screenshot-crop_popover.webp" />

## Uso de janelas emergentes [#use-pop]

Um pop-over é escrito em um [arquivo JSON](https://github.com/newrelic/docs-website/blob/develop/src/data/popovers_en.json) e pode ser inserido em qualquer documento desejado usando o seguinte formato:

```jsx
<InlinePopover type="title" />
```

Onde `title` é o nome do componente no arquivo JSON. Na captura de tela acima, `synthetics` é o pop-over utilizado.

<Callout variant="tip">
  A macro do Keyboard Maestro para pop-overs é `kkpopover`
</Callout>

## Criação ou edição de pop-overs

Os pop-overs estão contidos em um arquivo JSON editável. É possível editar o arquivo para criar os seus próprios pop-overs utilizando o procedimento abaixo:

<Steps>
  <Step>
    Abra o [arquivo JSON](https://github.com/newrelic/docs-website/blob/develop/src/data/popovers_en.json) no VS Code.
  </Step>

  <Step>
    Copie e cole um pop-over existente e modifique-o conforme necessário para o pop-over que deseja criar.

    * A primeira linha é o &quot;título&quot; do pop-over usado no exemplo de formato acima.

    * `inlineText` é o texto que aparece no documento em que o componente é inserido, antes que o usuário passe o mouse sobre o pop-over.

    * `header` é o título do pop-over assim que ele é exibido.

    * `text` é o texto exibido no corpo do pop-over.

    * `learnMoreUrl` é o URL do documento para o qual se deseja direcionar o leitor para obter mais informações.

    * `primaryButton` é o texto do botão principal conforme aparece no pop-over.

    * `primaryButtonUrl` é o link para o qual se deseja que o botão direcione o leitor ao ser clicado.

    * `secondaryButton` é o texto do botão mais à direita, conforme aparece no pop-over.

    * `secondaryButtonUrl` é o link para o qual se deseja que o botão mais à direita envie o leitor quando clicado.

      Mantenha a lista no arquivo JSON em ordem alfabética para facilitar a localização.
  </Step>

  <Step>
    Teste o popover localmente.
  </Step>

  <Step>
    Deve-se abrir um PR com base nas alterações realizadas e entrar em contato com alguém em Docs Eng para solicitar a revisão.
  </Step>

  <Step>
    Assim que o PR for revisado e mesclado, será possível usar o novo pop-over em qualquer documento desejado!
  </Step>
</Steps>
