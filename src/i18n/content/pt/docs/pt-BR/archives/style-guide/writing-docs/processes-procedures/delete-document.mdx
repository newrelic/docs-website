<Callout variant="caution">
  Ao excluir um documento, seu conteúdo e seus redirecionamentos ainda estarão disponíveis no histórico de commits do GitHub.
</Callout>

Para excluir um documento:

1. Localize o arquivo MDX do documento a ser excluído.

2. Cuidar dos redirecionamentos:

   1. Encontre o documento mais relevante para o qual redirecionar os leitores.
   2. [Adicione o URL do documento excluído como um redirecionamento](/docs/style-guide/rename-or-redirect-document).
   3. Copiar quaisquer redirecionamentos existentes do documento excluído e adicioná-los ao novo documento.

3. Excluir o título e o caminho do documento do arquivo de navegação apropriado.

4. Exclua o arquivo MDX do documento.

5. Exclua os arquivos MDX correspondentes do diretório `src/i18n/content`. Para cada documento em inglês, há um arquivo MDX para cada um dos idiomas localizados. É possível usar o script `i18n-utility` para fazer isso automaticamente:
   ```bash
   yarn i18n-utility delete-orphans
   ```
