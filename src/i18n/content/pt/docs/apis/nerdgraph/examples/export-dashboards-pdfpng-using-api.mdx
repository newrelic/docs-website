Você pode exportar seus dashboards e gráficos individuais como arquivos PDF ou PNG programaticamente usando as mutações `dashboardCreateSnapshotUrl` e `dashboardWidgetCreateSnapshotUrl` do NerdGraph. A API oferece suporte a opções não disponíveis na interface, como substituições de variáveis de template e filtros de entidade. Você também pode [exportar dashboards usando a interface](/docs/query-your-data/explore-query-data/dashboards/dashboards-charts-import-export-data/#export-dashboards-pdf).

## Exportar um dashboard como PDF ou PNG [#api-dashboard-snapshot]

A mutação `dashboardCreateSnapshotUrl` gera um URL de snapshot para uma página completa do dashboard.

<Callout variant="tip">
O parâmetro `guid` requer o GUID da **página**, não o GUID do dashboard. Um dashboard pode ter várias páginas. Para encontrar os GUIDs de página, use a consulta `entitySearch` ou abra a página do dashboard e selecione <DNT>**Manage JSON**</DNT> no menu <DNT>**...**</DNT>.

```graphql
{
  actor {
    entitySearch(query: "parentId ='YOUR_DASHBOARD_GUID' AND tags.isDashboardPage = 'true'") {
      results {
        entities {
          guid
          name
        }
      }
    }
  }
}
```
</Callout>

**Esquema de mutação:**

```graphql
mutation {
  dashboardCreateSnapshotUrl(
    guid: EntityGuid!
    params: SnapshotUrlInput
  ): String
}

input SnapshotUrlInput {
  timeWindow: SnapshotUrlTimeWindowInput
  display: SnapshotUrlDisplayInput
  variables: [SnapshotUrlVariableInput!]
  filter: String
  format: SnapshotUrlFormat
}

input SnapshotUrlTimeWindowInput {
  beginTime: EpochMilliseconds
  endTime: EpochMilliseconds
  duration: Milliseconds
}

input SnapshotUrlDisplayInput {
  width: Int
  height: Int
}

input SnapshotUrlVariableInput {
  name: String!
  values: [String!]!
}

enum SnapshotUrlFormat {
  PDF
  PNG
}
```

        height: 1080
      }
    }

<Collapser id="variables-filter" title="Exportar com substituições de variáveis e um filtro">
Use isso para fixar valores de variáveis e filtros específicos no snapshot, útil para a automação de relatórios agendados.

```graphql
mutation {
  dashboardCreateSnapshotUrl(
    guid: "YOUR_DASHBOARD_PAGE_GUID"
    params: {
      variables: [
        { name: "environment", values: ["production"] }
        { name: "region", values: ["us-east-1", "eu-west-1"] }
      ]
      filter: "env = 'production' AND service = 'checkout'"
    }
  )
}
```
</Collapser>
</CollapserGroup>

<Callout variant="important">
Os URLs de snapshot são acessíveis publicamente sem autenticação e expiram após 3 meses. Compartilhe-os com cuidado, de acordo com as políticas de dados da sua organização.
</Callout>

## Exportar um gráfico como imagem [#api-widget-snapshot]

A mutação `dashboardWidgetCreateSnapshotUrl` gera um URL para um snapshot em PDF ou PNG de um único widget de gráfico. O widget não precisa existir em um dashboard — você pode defini-lo inline, o que o torna útil para gerar snapshots de gráficos programaticamente.

**Esquema de mutação:**

```graphql
mutation {
  dashboardWidgetCreateSnapshotUrl(
    widget: DeclarativeUiWidget!
    params: DashboardWidgetSnapshotUrlInput
  ): WidgetSnapshotResult
}

type WidgetSnapshotResult {
  url: String!
}
```

O argumento `params` é opcional. Use-o para alterar o formato de saída ou o tamanho do snapshot.

O parâmetro `widget` aceita um `DeclarativeUiWidget` — um objeto JSON com três camadas aninhadas:

```
declarative/widget envelope
└── widget node        ← title and widget-level props
    └── visualization  ← visualization type and configuration
```

```json
{
  "type": "declarative/widget",
  "version": 1,
  "content": {
    "type": "widget",
    "props": {
      "title": "My Chart Title"
    },
    "content": {
      "type": "visualization",
      "id": "viz.line",
      "props": {
        // visualization-specific config (nrqlQueries, colors, thresholds, etc.)
      }
    }
  }
}
```

**Exemplos:**

<CollapserGroup>
<Collapser id="line-chart-snapshot" title="Exportar um gráfico de linhas">
```graphql
mutation {
  dashboardWidgetCreateSnapshotUrl(
    widget: {
      version: 1
      type: "declarative/widget"
      content: {
        type: "widget"
        props: { title: "Throughput by environment" }
        content: {
          type: "visualization"
          id: "viz.line"
          props: {
            nrqlQueries: [
              {
                accountIds: [YOUR_ACCOUNT_ID]
                query: "SELECT count(*) FROM Transaction TIMESERIES"
              }
            ]
            legend: { enabled: true }
          }
        }
      }
    }
  ) {
    url
  }
}
```
</Collapser>

<Collapser id="billboard-snapshot" title="Exportar um gráfico de outdoor com limites">
```graphql
mutation {
  dashboardWidgetCreateSnapshotUrl(
    widget: {
      version: 1
      type: "declarative/widget"
      content: {
        type: "widget"
        props: { title: "Error rate" }
        content: {
          type: "visualization"
          id: "viz.billboard"
          props: {
            nrqlQueries: [
              {
                accountIds: [YOUR_ACCOUNT_ID]
                query: "SELECT percentage(count(*), WHERE error IS true) AS 'Error rate' FROM Transaction SINCE 1 hour ago"
              }
            ]
            thresholds: [
              { alertSeverity: "WARNING", value: 1 }
              { alertSeverity: "CRITICAL", value: 5 }
            ]
          }
        }
      }
    }
  ) {
    url
  }
}
```
</Collapser>
</CollapserGroup>

<Callout variant="tip">
O campo `actor.account.nrql.staticChartUrl` legado no NerdGraph permanece disponível, mas não é compatível com os recursos de visualização mais recentes, como limites, formatação de cores e tipos de gráficos mais recentes. `dashboardWidgetCreateSnapshotUrl` é a abordagem recomendada daqui para a frente.
</Callout>

<Callout variant="important">
`dashboardWidgetCreateSnapshotUrl` URLs de snapshot são acessíveis publicamente sem autenticação e expiram após 3 meses.
</Callout>

## Resolução de problemas [#troubleshooting]

Veja o que fazer se você encontrar algum dos seguintes erros ao tentar exportar um dashboard:

* Na interface do New Relic: <DNT>**We ran into an error while creating the PDF. Please try again**</DNT>

* Do New Relic NerdGraph: <DNT>**Operation on dashboard entity failed with guid:YOUR\_GUID with cause: Error 504: upstream request timeout**</DNT>

Esses erros podem ocorrer se a exportação exceder o tempo de resposta máximo da API. Verifique se algum widget no seu dashboard usa uma janela de tempo grande — por exemplo, comparando dados de um mês inteiro. Se sim, tente reduzir a janela de tempo.

Outra causa possível é um dashboard com um grande número de widgets. Tente remover os widgets não utilizados para ver se isso resolve o erro.
