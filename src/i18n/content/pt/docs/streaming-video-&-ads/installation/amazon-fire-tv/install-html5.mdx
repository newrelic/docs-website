Instale o New Relic `VegaTracker` para monitorar a reprodução nativa do elemento de vídeo HTML5 no aplicativo Amazon Fire TV. O VegaTracker não requer SDK de player e se anexa ao elemento W3C `VideoPlayer`.

## Antes de você começar [#before-begin]

Conclua as [etapas comuns de instalação](/docs/streaming-video-&-ads/installation/amazon-fire-tv/get-started-with-amazon-fire-tv#install) primeiro para criar o aplicativo e recuperar o token do aplicativo móvel.

## Instalar o rastreador [#install]

<Steps>
  <Step>
    ### Instale o pacote HTML5

    ```shell
    npm install @newrelic/video-html5 --save
    ```
  </Step>

  <Step>
    ### Instalar informações do dispositivo

    Esta etapa é opcional. A biblioteca de informações do dispositivo fornece atributos reais do dispositivo — modelo, versão do sistema operacional e UUID — nos eventos de vídeo. Sem ela, os eventos usam valores de espaço reservado para `deviceModel` e `deviceUuid`.

    ```shell
    npm install @amazon-devices/react-native-device-info --save
    ```
  </Step>

  <Step>
    ### Inicializar VegaTracker

    Recomenda-se inicializar `VegaTracker` dentro do retorno de chamada `onSurfaceViewCreated`. Isso garante que a anexação assíncrona do player seja concluída antes da inicialização.

    O elemento `VideoPlayer` deve ser passado como o primeiro argumento. Não é necessária uma instância do SDK do player. O objeto `info` deve incluir o ID da conta, o token do aplicativo e o endpoint. Caso a biblioteca de informações do dispositivo tenha sido instalada, os atributos do dispositivo também devem ser passados como `info.deviceInfo`.

    Quando a reprodução terminar, `tracker.dispose()` deve ser chamado para liberar recursos.

    Para o exemplo de inicialização, use o trecho de código na [instalação guiada da New Relic](/docs/streaming-video-&-ads/installation/amazon-fire-tv/get-started-with-amazon-fire-tv#install).
  </Step>

  <Step>
    ### Ver seus dados

    Implante o aplicativo e reproduza um vídeo. Vá para <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Streaming Video &amp; Ads**</DNT> para verificar se os dados estão fluindo para o aplicativo.
  </Step>
</Steps>
