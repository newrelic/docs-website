O New Relic Observability for SAP - ABAP Hosted captura dados de telemetria do SAP (Métricas, Eventos, Logs e Traces) e os envia para a plataforma New Relic para análise e visualização.

## Sistema de monitoramento central vs. sistemas monitorados

Os sistemas SAP que fornecem dados de telemetria são conhecidos como sistemas monitorados. O sistema de monitoramento central é onde <DNT>**NRM4SAP**</DNT> está instalado — ele coleta, transforma e transmite dados de telemetria. Normalmente, <DNT>**NRM4SAP**</DNT> é instalado em um único sistema SAP, como <DNT>**SAP Solution Manager (SolMan)**</DNT>. <DNT>**NRM4SAP**</DNT> não tem dependências funcionais no SolMan — ele serve apenas como um ponto de referência aqui. <DNT>**NRM4SAP**</DNT> usa fontes de dados SAP padrão, como <DNT>**ST-PI**</DNT>, classes MTE (componentes dentro de <DNT>**CCMS**</DNT>) e dados de desempenho de <DNT>**STAD/ST03N**</DNT>, portanto, não é necessário instalar agentes adicionais em sistemas monitorados.

A partir da versão 3.0, <DNT>**NRM4SAP**</DNT> requer apenas componentes ABAP, que são implantados exclusivamente no sistema de monitoramento central.

## Arquitetura de fluxo de dados

<DNT>**RFC**</DNT> chamadas extraem dados de telemetria SAP para o sistema central de monitoramento. O <DNT>**ABAP Enterprise Connector**</DNT> processa os dados e os transmite com segurança para o New Relic via <DNT>**HTTPS**</DNT>.

## O que está incluído

Após a instalação, você pode usar dashboards e alertas prontos para uso:

* **Visibilidade de gerenciamento**: visualize a saúde e o desempenho do sistema SAP junto com outros sistemas de TI em dashboards centralizados.

* **Monitoramento personalizado**: adapte o monitoramento às necessidades específicas do negócio, como rastrear pontos de integração em fluxos de trabalho de processamento de pedidos. Crie dashboards personalizados e visualizações usando dados de telemetria coletados.

* **Alertas proativos**: configure alertas para receber notificações imediatas de interrupções de serviço. Isso ajuda a manter a continuidade e a resolver problemas prontamente.
