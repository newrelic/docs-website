Este guia mostra como desinstalar o <DNT>**New Relic ABAP component (NEWR)**</DNT> do seu sistema central SAP. Você pode precisar fazer isso ao desativar o monitoramento ou antes de atualizar para uma nova versão.

<Callout variant="caution">
  A desinstalação do <DNT>**New Relic ABAP component**</DNT> interrompe toda a coleta de dados de monitoramento e remove o componente do sistema SAP. A New Relic preserva os dados históricos, mas não coleta novos dados após a desinstalação. Não é possível desfazer esta ação.
</Callout>

## Pré-requisitos

* Acesso de administrador a <DNT>**SAP system**</DNT>
* Acesso a <DNT>**client 000**</DNT>
* Backup de quaisquer configurações personalizadas (se necessário para reinstalação futura)

## Remover artefatos de monitoramento da New Relic

Antes de desinstalar o <DNT>**ABAP component**</DNT>, limpar os artefatos de monitoramento no sistema de monitoramento central:

1. Interrompa e cancele o agendamento de quaisquer jobs de coleta agendados que executam programas `/NEWR/*`. Use a transação `SM37` para localizar e cancelar esses jobs.
2. Remover quaisquer funções com nomes prefixados com `/NEWR/*`.
3. Na transação `SM59`, remova quaisquer <DNT>**RFC connections**</DNT> para os sistemas monitorados que foram criados exclusivamente para a coleta de dados da New Relic. É possível identificar essas conexões pela conta de login de coleta de dados designada da New Relic ou consultando a listagem de registro do provedor de dados da New Relic.

## Desinstale o componente ABAP

Siga estas etapas para desinstalar o componente ABAP do sistema central:

1. Faça login em <DNT>**client 000**</DNT>.
2. Insira o código de transação `SAINT`.
3. Clique na guia <DNT>**Uninstallable Components**</DNT> .

<img title="ABAP component on central system" alt="The SAINT transaction showing the NEWR component in the Uninstallable Components list" src="/images/ABAP-component-on-cms.webp" width="700" />

4. Selecione o componente <DNT>**NEWR**</DNT> e verifique se o número da versão corresponde à sua versão instalada.
5. Clique em <DNT>**Start**</DNT>.
6. Clique na marca de seleção verde para confirmar em cada tela subsequente.
7. Clique em <DNT>**Finish**</DNT> quando o processo estiver concluído.
8. Verifique se o componente <DNT>**NEWR**</DNT> não aparece mais na guia <DNT>**Installed Components**</DNT>.

## Remova a New Relic dos sistemas monitorados

O componente ABAP <DNT>**NEWR**</DNT> é instalado apenas no sistema central, portanto, os sistemas monitorados não têm nenhum componente para desinstalar. Para desinstalar o New Relic de um sistema monitorado, remova o acesso criado para a coleta de dados:

1. Na transação `SU01`, exclua o New Relic <DNT>**ABAP user account**</DNT> designado usado para coleta de dados.
2. Remova a função de autorização associada do New Relic (nomes com o prefixo `/NEWR/*`).

## Verificar a desinstalação

Após concluir o processo de desinstalação:

* O componente <DNT>**NEWR**</DNT> não deve mais aparecer na aba <DNT>**Installed Components**</DNT>
* Os jobs de coleta de dados na transação `SM37` não serão mais executados
* O New Relic deixará de receber dados de monitoramento deste sistema

**Nota**: Os dados históricos de monitoramento no New Relic permanecerão acessíveis. Apenas o componente de coleta de dados é removido do sistema SAP.
