O monitoramento do New Relic para SAP inclui componentes de monitoramento prontos para uso: dashboards, políticas de alertas e o IDOC Explorer.

## Antes de você começar

Para executar essas tarefas, você deve ter privilégios de administrador da New Relic na conta.

<Callout variant="important">
  Para o dashboard <DNT>**SAP Cockpit**</DNT>, você deve [criar uma tabela de consulta](#create-lookup-table) chamada `NR_LKUP_SYSTEM` antes da instalação.
</Callout>

## Localize os componentes de monitoramento SAP [#locate-components]

1. Vá para <DNT>**[one.newrelic.com](https://one.newrelic.com)**</DNT>. Caso gerencie várias contas, selecione a subconta que coleta dados do SAP.
2. Selecione <DNT>**+ Integrations &amp; Agents**</DNT> &gt; <DNT>**Apps &amp; Visualizations**</DNT>.
3. Pesquise por <DNT>**SAP**</DNT>. Os resultados mostram todos os aplicativos, políticas de alertas e dashboards disponíveis para o monitoramento do SAP.

## Instalar painel

### Criar tabela de consulta [#create-lookup-table]

<Callout variant="tip">
  Necessário apenas para o dashboard <DNT>**SAP Cockpit**</DNT>.
</Callout>

O dashboard do <DNT>**SAP Cockpit**</DNT> usa um <DNT>**lookup table**</DNT> para <DNT>**SAP systems**</DNT> e seus ambientes.

1. Crie o <DNT>**lookup table**</DNT> com duas colunas: `SYS_ID` e `Env`, e salve-o como um <DNT>**CSV file**</DNT>. Aqui está um exemplo do arquivo de consulta:

   ```csv
   SYS_ID,Env
   GD1,DEV
   SD2,DEV
   AQ1,Testing
   AQ2,Testing
   SP1,Prod
   SP2,Prod
   ```

2. Vá para <DNT>**Log &gt; Lookup Tables**</DNT>.

3. Clique em <DNT>**Add a table**</DNT>.

4. Na barra lateral <DNT>**Add a lookup table**</DNT>, nomeie a tabela como <DNT>**NR\_LKUP\_SYSTEM**</DNT> e carregue o <DNT>**CSV file**</DNT>. Consulte [Tabelas de consulta](/docs/logs/ui-data/lookup-tables-ui/) para obter mais informações.

5. Para verificar o conteúdo da tabela, use o <DNT>**query builder**</DNT> com `FROM lookup(NR_LKUP_SYSTEM) SELECT *` e clique em <DNT>**Run**</DNT>.

### Instale os dashboards [#install-dashboards]

1. Vá para <DNT>**[one.newrelic.com](https://one.newrelic.com)**</DNT> &gt; <DNT>**Integrations &amp; Agents**</DNT> e pesquise por <DNT>**New Relic Monitoring for SAP Solutions**</DNT>. Alternativamente, vá para <DNT>**Dashboards &gt; Recommended Dashboards**</DNT>, clique em <DNT>**View all**</DNT> e pesquise por SAP. Consulte [Dashboards](/docs/query-your-data/explore-query-data/dashboards/introduction-dashboards/) para obter mais informações.

2. Selecione a guia <DNT>**Dashboards**</DNT> .

3. Clique em um dashboard e selecione a conta onde deseja instalá-lo. O dashboard é instalado automaticamente.

4. Instale estes dashboards:

   * <DNT>**SAP Dashboards**</DNT>
   * <DNT>**SAP Cockpit**</DNT>
   * <DNT>**SAP Data Collection Monitoring**</DNT>
   * <DNT>**SAP Data Ingestion Estimate**</DNT>

<Callout variant="tip">
  Após instalar o dashboard <DNT>**SAP Cockpit**</DNT>, abra-o e confirme se a página de destino reflete o status correto do sistema. Isso verifica se a tabela de consulta `NR_LKUP_SYSTEM` mapeia os ambientes para os sistemas corretamente.
</Callout>

### Adicionar filtro dashboard [#add-dashboard-filter]

1. Vá para <DNT>**[one.newrelic.com](https://one.newrelic.com)**</DNT> &gt; <DNT>**Dashboards**</DNT> e selecione um dashboard.
2. Clique nas reticências (<DNT>**…**</DNT>) no canto superior direito de um widget.
3. Selecione <DNT>**Edit**</DNT> para abrir a tela de edição.
4. Ative ou desative a chave <DNT>**Filter the current dashboard**</DNT>.

Ative a vinculação de facetas para widget de tabela, gráfico de pizza e gráfico de barras para filtrar por <DNT>**SAP system**</DNT>, <DNT>**instance**</DNT>, <DNT>**IDOC status**</DNT>, <DNT>**jobs**</DNT> e mais.

## Instalar políticas de alertas

1. Vá para <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Alerts &gt; Alert Policies**</DNT>.

2. Pesquise e clique em <DNT>**New Relic Monitoring for SAP Solutions alert policy**</DNT>.

   <img title="New Relic Monitoring for SAP Solutions alert policy" alt="A screenshot displaying the connection setup for New Relic Monitoring for SAP Solutions alert policy" src="/images/new-relic-monitoring-for-sap-solutions-alert-policy.webp" width="" />

3. Na guia <DNT>**Alert condition**</DNT>, selecione a conta e alterne <DNT>**alert policy**</DNT> para <DNT>**Enable**</DNT>. Consulte [Gerenciar suas políticas](/docs/alerts/organize-alerts/create-edit-or-find-alert-policy/) para obter instruções sobre como gerenciar políticas.

4. Volte e pesquise por <DNT>**Nr4sap default alert policy**</DNT>. Ative o <DNT>**alert condition**</DNT> que você gostaria de habilitar.

## Instalar o IDOC Explorer

1. Vá para <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents**</DNT>.

2. Selecione <DNT>**Apps &amp; Visualizations**</DNT> e pesquise <DNT>**IDOC Explorer**</DNT>.

3. Selecione <DNT>**Manage access**</DNT>. Escolha a conta para acessar o aplicativo.

   <img title="IDOC Explorer" alt="A screenshot displaying the manage access settings for IDOC Explorer" src="/images/idoc-explorer.webp" />

4. Clique em <DNT>**Update**</DNT>. O <DNT>**IDOC Explorer**</DNT> aparece ao visualizar <DNT>**IDOC entities**</DNT>.
