Após instalar o add-on ABAP, use o menu <DNT>**`/NEWR/INSTALL`**</DNT> para conectar os sistemas SAP à New Relic, configurar endpoints de API, definir grupos de monitoramento e verificar a configuração.

## Use o menu /NEWR/INSTALL [#menu-newr-install]

1. Efetue login no cliente de produção do sistema de monitoramento central.
2. Digite `/n` no campo de comando e pressione <DNT>**Enter**</DNT> para ir para o <DNT>**SAP Easy Access root menu**</DNT>.
3. Digite `/n/NEWR/INSTALL` no campo de comando para abrir o menu <DNT>**`/NEWR/INSTALL`**</DNT>.

Antes de configurar, é necessário garantir o seguinte:

* O instalador possui autorização adequada para realizar a configuração.
* O parâmetro `/NEWR/*` é adicionado ao objeto de autorização `S_TCODE` no `profile/role` do instalador.

<Callout variant="tip">
  Se estiver atualizando de uma versão anterior, consulte [Atualizar de Versão Anterior](/docs/sap-solutions/upgrade/install-upgrade-package) para determinar quais etapas são necessárias.
</Callout>

## Conectar sistemas [#connect-systems]

<Callout variant="important">
  Conclua quaisquer etapas de configuração pendentes antes de prosseguir.
</Callout>

No menu `/NEWR/INSTALL`, abra a pasta <DNT>**Install New Release and Patch**</DNT> e conclua as seguintes etapas.

### Configuração de destino RFC padrão

Use a transação `SM59` para configurar conexões <DNT>**RFC**</DNT> e <DNT>**HTTPS**</DNT> para sistemas monitorados locais:

* Para a configuração de RFC, consulte [Destino RFC padrão](/docs/sap-solutions/install-and-configure/additional-configuration/#standard-rfc-destination) e [Definir destino HTTP para a cloud da New Relic](/docs/sap-solutions/install-and-configure/additional-configuration/#set-http-destination-to-new-relic-cloud).

### Configuração de RFC do SAP Cloud / Business Technology Platform (BTP)

Use a transação `SM59` para configurar destinos HTTP para sistemas hospedados no BTP:

* Para autenticação BTP/CALM, consulte [Destino RFC do Cloud (BTP)](/docs/sap-solutions/install-and-configure/additional-configuration/#cloud-btp-rfc-destination).
* Caso monitore um <DNT>**SAP Cloud Connector**</DNT>, configure um destino RFC do tipo <DNT>**G**</DNT> (External HTTP) usando a porta <DNT>**8443**</DNT> (porta de administração HTTPS padrão do Cloud Connector). A conta de usuário deve ter as autorizações e a senha necessárias.

### Configurar a conexão com o banco de dados remoto

Caso não tenha concluído esta etapa durante a pré-instalação, conclua-a agora.

* Abrir a transação SAP `DBACOCKPIT` para verificar as conexões com <DNT>**HANA databases**</DNT> remoto.
* Crie uma conexão de banco de dados para cada banco de dados HANA remoto a ser monitorado.
* Para obter instruções detalhadas, consulte [Criar conexão com o banco de dados](/docs/sap-solutions/install-and-configure/additional-configuration/#create-database-connection).

### Configurar conexões com os endpoints de API da New Relic

É possível configurar várias contas da New Relic nesta seção.

1. Clique em <DNT>**New Entries**</DNT>.

2. Insira os detalhes da sua conta New Relic:

   * <DNT>**New Relic Account ID**</DNT> (opcionalmente prefixado com SAP-)
   * <DNT>**API Ingest Key**</DNT>
   * <DNT>**Metric Endpoint**</DNT> (consulte [Endpoints de rede](/docs/sap-solutions/before-you-begin/#network-endpoints))
   * <DNT>**Event Endpoint**</DNT>
   * <DNT>**Log Endpoint**</DNT>
   * <DNT>**Trace Endpoint**</DNT>

3. Clique em <DNT>**Save**</DNT>.

### Definir os sistemas monitorados

1. Clique em <DNT>**New Entries**</DNT> e insira o <DNT>**SAP System ID**</DNT> e o número do <DNT>**Client**</DNT>.

2. Em <DNT>**Data Provider Installation Information**</DNT>, forneça o seguinte:

   * <DNT>**RFC Destination**</DNT>
   * <DNT>**SAP Software Component**</DNT>
   * <DNT>**Database Vendor**</DNT>
   * <DNT>**DB Connection Name**</DNT> (apenas banco de dados HANA)
   * <DNT>**New Relic Account ID**</DNT> (opcional) — se fornecido, os dados deste sistema vão apenas para essa conta, substituindo a conta na variante de job do gerenciador de coleta. Se deixado em branco, o sistema usa a conta da variante de job do gerenciador de coleta.

3. Clique em <DNT>**Monitoring Group**</DNT> e selecione <DNT>**Yes**</DNT> para confirmar.

4. Escolha os grupos de monitoramento necessários e clique no ícone de geração.

5. Clique em <DNT>**BACK**</DNT> ou pressione <DNT>**F3**</DNT> para continuar.

### Contas BTP/CALM

Quando o monitoramento do BTP estiver ativo, adicione contas BTP/CALM como sistemas monitorados. Use os seguintes valores:

* <DNT>**SAP System ID**</DNT>: use um pseudônimo ou alias. Não use termos reservados, como `CALM` ou `BTP`.
* <DNT>**Client**</DNT>: deixe em branco.
* <DNT>**Destination**</DNT>: insira o destino HTTP de autenticação.
* <DNT>**Software Component**</DNT>: deixe em branco.
* <DNT>**Database Vendor**</DNT>: deixe em branco.
* <DNT>**DB Connection Name**</DNT>: deixe em branco.
* <DNT>**New Relic Account ID**</DNT>: insira a conta específica da New Relic designada para receber os dados.
* <DNT>**API Host**</DNT>: insira o nome do host da API. Isso corresponde ao valor `url` na chave de serviço.

Na próxima tela, clique em <DNT>**Monitoring Group**</DNT>. Escolha os grupos de monitoramento apropriados para o sistema e clique em <DNT>**Finish**</DNT>.

### Verifique os destinos RFC

Use esta opção para verificar os destinos RFC para os endpoints de API da New Relic e cada sistema monitorado. Este teste exclui o destino RFC designado como <DNT>**NONE**</DNT>.

## Gerar configuração [#generate-configurations]

### Gerar configurações para novos provedores de dados

* Execute esta opção para gerar todos os novos provedores de dados para uma nova versão ou patch. Para novas instalações, esta única etapa gera todos os provedores de dados.
* Na primeira tela, confirme os detalhes da versão e do patch. Se os campos de versão e patch da instalação estiverem em branco, a configuração já está estabelecida.
* Para regenerar a configuração, navegue até <DNT>**Maintain Monitored Systems**</DNT> e selecione <DNT>**Re-generate Data Provider Configurations**</DNT>. Também é possível selecionar <DNT>**Reset Installation Flag (For Re-install only)**</DNT> para limpar o sinalizador de instalação atual e regenerar.

<Callout variant="tip">
  Para provedores de dados baseados no CALM, consulte [Gerar Entradas de Registro para Provedores de Dados CALM](/docs/sap-solutions/monitor/data-providers-reference).
</Callout>

<img title="Maintain Monitored Systems" alt="A screenshot displaying the SAP maintain monitored systems" src="/images/maintain-monitored-systems.webp" width="500" />

### Verificar a integridade da instalação

Selecione <DNT>**Verify Installation Completeness**</DNT>. Se algum componente exibir um indicador vermelho, clique no botão de execução na coluna <DNT>**Action Needed**</DNT> para resolver o problema.

## Verifique a configuração [#verify-configuration]

1. Abra a pasta <DNT>**Data Provider Registry Maintenance**</DNT>.
2. Clique em <DNT>**Data Provider Registry**</DNT> ou use a transação `/n/NEWR/REGISTRY`.
3. Selecione um <DNT>**Data Provider Name**</DNT> e clique em <DNT>**Configure**</DNT> para verificar as definições de configuração, ou clique em <DNT>**Test**</DNT> para verificar a funcionalidade do provedor.
4. Clique em <DNT>**RuntimeStatus**</DNT> e remova todas as entradas na tela de status do Runtime.
