* Um servidor dedicado não é necessário quando o total de <DNT>**SIDs**</DNT> monitorados é inferior a 10 e as instâncias não excedem 50. Quando o <DNT>**SIDs**</DNT> exceder 10 ou as instâncias excederem 100, recomenda-se um servidor dedicado.
* Um servidor dedicado não deve ter mais de duas instâncias de <DNT>**App Server**</DNT>, cada uma com 96 GB de memória e CPUs de 12 núcleos. Se o sistema de monitoramento for executado em um <DNT>**HANA database**</DNT>, recomendamos separar as instâncias do servidor de banco de dados das instâncias do servidor de aplicativos.
