Este guia mostra como monitorar o processo de coleta de dados do New Relic Monitoring for SAP Solutions. Você pode usar vários métodos para verificar se a coleta de dados está funcionando corretamente.

## Pré-requisitos

* Acesso a <DNT>**SAP system**</DNT> com as permissões de transação apropriadas
* <DNT>**New Relic Monitoring for SAP Solutions**</DNT> instalado e configurado

## Status de tempo de execução e log de transmissão

Abra o <DNT>**Data Provider Registry**</DNT> (transação `/NEWR/REGISTRY`) para verificar o status de tempo de execução e os detalhes de transmissão para cada provedor de dados. Clique em <DNT>**RuntimeStatus**</DNT> para visualizar o último tempo de execução e o status atual. Clique em <DNT>**Transmission Log**</DNT> para visualizar o tempo de transmissão, o código de resposta HTTP e o estado de transmissão para cada registro enviado ao New Relic.

## Verifique o status do trabalho e o spool

1. Use a transação `SM37` para verificar o status dos trabalhos agendados. Digite `/NEWR/*` no campo <DNT>**ABAP Program Name**</DNT> e clique em <DNT>**Execute**</DNT>.
2. Revise a duração da execução. Um tempo de execução anormalmente longo indica um possível problema.
3. Verifique se há tarefas sobrepostas e ajuste o agendamento conforme necessário.
4. Abra o spool de trabalho a partir dos detalhes do trabalho. O spool mostra o timestamp de coleta, o estado de transmissão e o resultado para cada provedor de dados.
5. Utilize o número do job para correlacionar as entradas de spool com o log de transmissão no <DNT>**Data Provider Registry**</DNT>.

## Verifique o log do aplicativo

Os processos de coleta de dados são registrados no log do aplicativo (transação `SLG1`). Consulta com o <DNT>**Application Log Object**</DNT> `/NEWR/DP`.

Para provedores de dados assíncronos (aqueles com o sufixo `_COMPLETE`), o spool de trabalho não inclui seus registros. Verifique o log de aplicativo usando a subcategoria <DNT>**`/NEWR/DP_AGENT`**</DNT> para visualizar seus detalhes de coleta e transmissão.

## Dashboard de monitoramento de coleta de dados SAP

Os dados coletados métricos também são enviados ao New Relic para automonitoramento. Use o dashboard <DNT>**SAP Data Collection Monitoring**</DNT> pronto para uso para monitorar os processos de coleta de dados para cada provedor de dados. Para obter instruções de instalação, consulte [Instalar componentes de monitoramento](/docs/sap-solutions/install-and-configure/install-out-of-the-box).
