복합 공지 조건의 트리거 표현식이 true로 평가되면 뉴렐릭은 복합 공지 이벤트를 엽니다. 이벤트에는 런북 URL에 대한 링크가 포함되어 있습니다. 각 구성 요소 조건에 대한 특정 임계값 위반을 보려면 개별 공지 이벤트를 클릭하세요.

## 공지 이벤트 및 이슈 연관 [#alert-events-correlation]

복합 공지 조건은 여러 관련 공지 이벤트를 생성합니다:

* <DNT>**Multiple alert events**</DNT>: 복합 공지 조건은 자체 복합 공지 이벤트를 생성합니다. 기본적으로 각 구성 요소 조건은 임계값을 위반할 때 자체 공지 이벤트를 생성합니다. 노이즈를 줄이려면 공지 조건의 설정에서 이러한 이벤트를 무음으로 설정할 수 있습니다. 구성 요소 조건의 공지 이벤트를 무음으로 설정하면 해당 조건의 태그가 복합 공지 이벤트에 나타나지 않습니다.
* <DNT>**Issue correlation**</DNT>: 모든 관련 공지 이벤트(복합 및 구성 요소 모두)가 동일한 이슈로 그룹화되도록 하려면 구성 요소 조건이 복합 공지 조건과 동일한 정책을 사용하도록 설정하세요. 이렇게 하면 뉴렐릭의 이슈 연관이 이들을 함께 그룹화할 수 있습니다.
* <DNT>**Related events**</DNT>: 복합 공지 이벤트에서 개별 구성 요소 공지 이벤트로 이동하여 각 조건에 대한 임계값 위반 및 메트릭을 확인할 수 있습니다.

## 커스텀 제목 및 설명 [#custom-title-description]

복합 공지 조건에 [제목 또는 설명 템플릿](/docs/alerts/create-alert/create-alert-condition/compound-alerts/create-compound-alert#title-description-templates)을 설정하면, 해당 사용자 지정 내용이 생성되는 이슈에 반영됩니다:

* <DNT>**Issue title**</DNT>: 이슈의 제목은 기본 시스템 생성 제목 대신 복합 조건의 제목 템플릿에서 렌더링된 텍스트를 표시합니다.
* <DNT>**Issue description**</DNT>: 복합 조건의 설명 템플릿에서 렌더링된 텍스트는 복합 조건의 공지 이벤트 섹션 바로 아래에 표시됩니다.

이슈 페이지를 간결하게 유지하기 위해 개별 구성 요소(하위) 조건의 설명은 해당 위치에 표시되지 않으며 ― 복합 조건의 설명만 표시됩니다.

## 영향을 받는 엔티티 [#impacted-entities]

구성 요소 조건이 일치하는 패싯(예: 동일한 서비스 또는 호스트)을 공유하는 경우, 뉴렐릭은 이슈 페이지 하단의 [영향을 받는 엔티티](/docs/alerts/alert-event-management/Issues-and-alert-event-management-and-response/#impacted-entities-and-issue-map) 섹션에 일치하는 엔티티를 표시합니다. 공유된 패싯이 여러 엔티티와 일치하는 경우, 하나만 표시되는 것이 아니라 모두 표시됩니다.

엔티티 카드를 마우스로 가리키거나 클릭하여 응답 시간, 처리량 및 오류율과 같은 해당 엔티티의 주요 상태 및 성능 메트릭을 확인하십시오.
