Ground Truth는 뉴렐릭의 운영 인텔리전스 계층입니다. Model Context Protocol(MCP) 도구는 AI 에이전트가 기술 스택을 더 잘 이해할 수 있도록 옵저버빌리티 데이터를 구성하는 데 도움이 됩니다.

MCP는 AI 모델 또는 에이전트가 특정 시스템이나 환경에 대한 관련 정보(컨텍스트)를 수신하기 위한 표준 방법입니다. 이 컨텍스트는 AI가 현재 상황을 이해하고, 작업을 더 정확하게 수행하며, 더 유용한 응답을 제공하는 데 도움이 될 수 있습니다. MCP 서버를 사용하면 지원되는 AI 에이전트가 자연어로 뉴렐릭 데이터를 쿼리, 조사 또는 조치하는 데 도움이 될 수 있는 특정 도구를 호출할 수 있습니다. 이는 결과적으로 인시던트 대응 및 성능 분석의 속도를 높이는 데 도움이 될 수 있습니다.

## 잠재적 이점

MCP 서버는 다음과 같은 방식으로 엔지니어 및 운영 팀에 실질적인 이점을 제공합니다:

* **직접 통합:** 지원되는 개발 환경에서 뉴렐릭의 MCP 도구에 직접 액세스하십시오. 이를 통해 다른 AI 도구 간에 전환할 필요가 없습니다.
* **더 빠른 문제 진단, 해결:** MCP를 사용하여 옵저버빌리티 데이터에서 문제를 빠르게 찾아 해결하고, 오류 로그를 분석하며, AI가 제공하는 인사이트를 통해 예상 원인을 파악하십시오.
* **운영 쿼리:** AI 에이전트에게 공지 상태를 확인하거나, 공지 이벤트 보고서를 생성하거나, 배포가 시스템에 미치는 영향을 분석하도록 요청하십시오.
* **간단한 데이터 쿼리:** 일반 영어로 질문을 작성하면 서버가 이를 뉴렐릭 쿼리 언어(NRQL)로 변환하여 NRQL 에 익숙하지 않더라도 결과를 얻을 수 있습니다.

## 지원되는 AI 개발 도구 [#supported-tools]

뉴렐릭 MCP는 다음과 같은 AI 개발 환경(지원되는 MCP 클라이언트)과 연동됩니다:

* **Claude Code:** Claude용 명령줄 인터페이스
* **Antigravity CLI:** Antigravity용 명령줄 인터페이스
* **Kiro CLI:** Kiro용 명령줄 인터페이스
* **Claude Desktop:** 대화형 AI 개발을 위한 데스크톱 애플리케이션
* **VS Code:** MCP 지원이 포함된 통합 개발 환경

각 환경은 워크플로우 선호도에 따라 고유한 이점을 제공합니다. MCP 클라이언트별 설정 지침은 [설정 가이드](/docs/agentic-ai/mcp/setup)를 참조하십시오.

## 전제 조건 [#prerequisites]

뉴렐릭 MCP를 사용하려면 다음이 필요합니다.

* 뉴렐릭 계정(MCP는 모든 계정에서 사용할 수 있습니다: 모든 데이터 및 CCU 사용자는 핵심 도구에 액세스할 수 있으며, aCCU 사용자는 고급 도구를 포함한 모든 도구에 액세스할 수 있습니다.)
* `Node.js` 설치됨(일부 인증 방법에 필요)
* 앞서 언급한 지원되는 MCP 클라이언트 중 하나가 설치되어 있어야 합니다.

### 조직 액세스 [#org-access]

연결하기 전에 뉴렐릭 관리자가 다음을 수행해야 합니다:

**그룹 멤버십 및 역할**

기본 조직 역할(`Organization Read Only`, `Organization Manager` 또는 `Organization Product Admin`) 또는 MCP 서버를 읽을 수 있는 권한이 있는 사용자 지정 조직 범위 역할이 할당된 그룹의 구성원이어야 합니다. 그룹에 필요한 권한이 없는 경우, `Organization Manager` 또는 `Authentication Domain Manager` 역할이 있는 관리자에게 문의하여 권한을 부여받으십시오.

**기능 제어 관리자**

조직 관리자는 [기능 제어 관리자](/docs/accounts/accounts-billing/new-relic-one-user-management/feature-control-manager/)를 통해 MCP 액세스를 활성화해야 합니다. 다음 토글은 MCP 액세스를 제어합니다. **New Relic MCP Server** \[뉴렐릭 MCP 서버] 및 **Local Clients** \[로컬 클라이언트]는 기본적으로 활성화되어 있습니다. 기타 모든 하위 토글은 기본적으로 비활성화되어 있으며 필요에 따라 뉴렐릭 관리자가 활성화할 수 있습니다.

* **뉴렐릭 MCP 서버**: MCP 설정에 필요합니다. MCP 액세스가 작동하려면 켜져 있어야 하는 기본 토글입니다.
* **로컬 클라이언트**: 로컬 클라이언트 연결(Claude Code, Claude Desktop, VS Code, Kiro)에 필요합니다.
* **API 키**: 자동화된 스크립트를 포함한 API 키 연결에 필요합니다.
* **미리 보기 도구**: MCP 미리 보기(비 GA) 도구에 액세스하려는 경우 필요합니다.
* **Atlassian**: Atlassian 통합에 필요합니다.
* **AWS**: AWS 통합에 필요합니다.

### 인증 옵션 [#auth-options]

* **OAuth(권장)**: 뉴렐릭은 사전 구성된 OAuth 엔드포인트를 제공합니다.

  * 클라이언트 ID: `pUWGgnjsQ0bydqCbavTPpw==`
  * 승인 URL: `https://oauth2.service.newrelic.com/oauth2/auth`
  * 토큰 URL: `https://oauth2.service.newrelic.com/oauth2/token`
  * 범위: `["observability:read", "offline", "offline_access"]`

* **사용자 API 키**: **일부 MCP 도구는 OAuth를 통해서만 액세스할 수 있다**는 점에 유의하십시오.

  1. 뉴렐릭에 로그인하세요.
  2. **사용자 메뉴 -&gt; API keys** 선택하세요.
  3. 새로운 사용자 키를 생성하거나 기존 키를 복사하세요.
  4. 키 형식: `NRAK-XXXXXXXXXXXXXXXXXXXXX`.

<Callout variant="important">
  일부 도구는 OAuth를 통해서만 액세스할 수 있으며 API 키를 사용할 때는 사용할 수 없습니다. 여기에는 AI 기반 분석 도구(`natural_language_to_nrql_query`, `generate_alert_insights_report`, `generate_user_impact_report`, `analyze_deployment_impact`) 및 미리 보기 도구(`search_traces`, `analyze_trace_anomaly`, `analyze_service_dependencies`)가 포함됩니다. 자세한 내용은 [도구 참조](/docs/agentic-ai/mcp/tool-reference)를 확인해 주십시오.
</Callout>
