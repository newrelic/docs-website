This guide walks you through setting up New Relic&apos;s Model Context Protocol (MCP) server with your preferred supported MCP clients. Choose your environment below for platform-specific instructions.

<Callout variant="important">
  Your use of any AI tools, including but not limited to the ones listed on this page, with New Relic AI MCP servers means your AI will take actions in your New Relic account on your behalf. When using either of the methods described here, create and use appropriate New Relic accounts that have your desired role based access controls (RBAC) and the least privileged permissions appropriate for your use case, requirements, and internal policies.
</Callout>

뉴렐릭 MCP 설정을 시작하기 전에 인증 설정을 포함한 [필수 구성 요소를](/docs/agentic-ai/mcp/overview#prerequisites) 완료했는지 확인하세요. 그런 다음, 귀하의 특정 개발 환경에 맞는 지침을 따르세요.

## Filtering tools with include-tags [#filtering-tools]

The New Relic MCP tools are organized and categorized using internal tags (such as `alerting`, `discovery`, and `data-access`). For details, refer to [filter tools](/docs/agentic-ai/mcp/tool-reference##filter-tools)

다음과 같이 requests 과 함께 `include-tags` `HTTP` 헤더를 보내면 AI가 액세스하는 도구를 동적으로 필터링할 수 있습니다.

<Callout variant="important">
  **리전 알림:** 이 주제의 설정 예에서는 미국 리전(기본값) MCP 연결 URL인 [https://mcp.newrelic.com/mcp/](https://mcp.newrelic.com/mcp/)를 사용합니다. 뉴렐릭 계정이 다른 리전에 있는 경우, 모든 설정 파일 및 명령줄 인수에서 이 URL을 적절한 리전 엔드포인트로 교체하십시오:

  * EU: [https://mcp.eu.newrelic.com/mcp/](https://mcp.eu.newrelic.com/mcp/)
  * JP: [https://mcp.jp.newrelic.com/mcp/](https://mcp.jp.newrelic.com/mcp/)
</Callout>

```json
"servers": {
    "new-relic-mcp-server": {
        "url": "https://mcp.newrelic.com/mcp/",
        "type": "http",
        "headers": {
            "include-tags": "discovery,alerting"
        }
    }
}
```

사용 가능한 태그와 각 태그와 관련된 도구의 전체 목록은 [뉴렐릭 MCP 도구 참조](/docs/agentic-ai/mcp/tool-reference) 문서를 참조하세요.

<Callout variant="important">
  Unless expressly indicated otherwise in this Documentation, you should only set up your supported MCP clients with the OAuth method. Unless indicated otherwise, any setup with an API key will not work as described in this Documentation or as intended.
</Callout>

## 클로드 코드 설정 [#claude-code]

Claude Code supports OAuth authentication method. OAuth requires Claude Code version 2.1.186 or later. If you are on older versions, you should authenticate via `/mcp` inside Claude instead of claude MCP login.

1. Claude Code가 설치되고 구성되어 있는지 확인하세요.

2. 명령줄을 사용하여 MCP 서버를 추가합니다.

   ```shell
   claude mcp add --transport http newrelic https://mcp.newrelic.com/mcp/
   claude mcp login newrelic
   ```

   또는 여기에 표시된 대로 `~/.claude.json` 편집하세요.

   ```json
   {
     "mcpServers": {
       "newrelic": {
         "type": "http",
         "url": "https://mcp.newrelic.com/mcp/"
       }
     }
   }
   ```

3. 브라우저 OAuth 흐름을 따라 인증을 완료하십시오.

설정 후 연결 오류가 발생하는 경우 [Claude Code의 예기치 않은 연결 오류](/docs/agentic-ai/mcp/troubleshoot#connection-error) 및 [Claude Desktop의 오래된 OAuth 자격 증명](/docs/agentic-ai/mcp/troubleshoot#stale-creds)을 참조하십시오.

## Antigravity CLI 설정 [#antigravity-cli]

<Callout variant="important">
  현재 Antigravity CLI에서는 API 키 방법만 지원됩니다. OAuth 지원은 아직 사용할 수 없습니다.
</Callout>

1. 컴퓨터에 Antigravity CLI가 설치되어 있는지 확인하십시오.

2. 설정 파일을 열어(또는 생성하여) MCP 서버를 설정합니다:

   * macOS/Linux: `~/.gemini/config/mcp_config.json`
   * Windows: `%USERPROFILE%\.gemini\config\mcp_config.json`

   다음 설정을 추가합니다:

   ```json
   {
     "mcpServers": {
       "newrelic": {
         "serverUrl": "https://mcp.newrelic.com/mcp/",
         "headers": {
           "api-key": "NRAK-YOUR-KEY-HERE"
         }
       }
     }
   }
   ```

3. Antigravity CLI 시작:

   ```shell
   agy
   ```

4. `/mcp`을(를) 실행하여 뉴렐릭 서버가 연결되었는지 확인하십시오.

## 키로 CLI 설정 [#kiro-cli]

1. 컴퓨터에 [Kiro CLI 도구가 설치되어](https://kiro.dev/cli/) 있는지 확인하십시오.
2. `~/.kiro/settings/mcp.json` 에 있는 설정 파일을 열거나 생성하여 MCP 서버를 구성하고 다음 설정을 추가하십시오.

```json
{
  "mcpServers": {
    "newrelic-mcp-server": {
      "url": "https://mcp.newrelic.com/mcp/",
      "oauth": {
        "authorizationUrl": "https://oauth2.service.newrelic.com/oauth2/auth",
        "tokenUrl": "https://oauth2.service.newrelic.com/oauth2/token",
        "scopes": ["observability:read", "offline", "offline_access"],
        "usePKCE": true
      },
      "disabled": false
    }
  }
}
```

3. 인증 및 연결:

   * 터미널을 열고 `kiro-cli` 실행하세요.
   * 명령어 `/mcp` 입력하고 엔터를 누르세요.
   * URL과 함께 뉴렐릭 서버가 목록에 표시되는 것을 볼 수 있습니다. 해당 URL을 브라우저에서 여세요.
   * 뉴렐릭의 표준 로그인 절차를 완료하세요.
   * 인증이 완료되면 브라우저에서 성공을 확인하는 메시지가 표시됩니다.

## 클로드 데스크탑 설정 [#claude-desktop]

Claude Desktop은 `OAuth` 인증을 위해 `mcp-remote` 프록시가 필요합니다. npx가 작동하려면 컴퓨터에 `Node.js` 설치되어 있는지 확인하십시오.

1. (필요한 경우) 구성 디렉토리를 만듭니다.

```shell
mkdir -p "~/Library/Application Support/Claude"
```

2. 구성 파일을 편집하세요: `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) 또는 `%APPDATA%\Claude\claude_desktop_config.json` (Windows).

   ```json
   {
     "mcpServers": {
       "new-relic-mcp": {
         "command": "npx",
         "args": [
           "-y",
           "mcp-remote",
           "https://mcp.newrelic.com/mcp/"
         ]
       }
     }
   }
   ```

3. Claude Desktop을 다시 시작합니다.

## VS 코드 설정 [#vs-code]

You need VS Code (version 1.91 or later).

1. 여기에 표시된 대로 `.vscode/mcp.json` 편집하여 MCP 서버를 추가합니다.

```json
{
  "servers": {
    "new-relic-mcp": {
      "url": "https://mcp.newrelic.com/mcp/",
      "type": "http"
    }
  }
}
```

2. VS Code 작업 공간에서 `mcp.json` 만들거나 엽니다.

   * `.vscode` 디렉토리가 없으면 프로젝트 루트에 디렉토리를 만드세요.

     * `.vscode` 내부에 `mcp.json` 이라는 이름의 파일을 만듭니다.
     * Add your authentication configuration.

3. 서버 시작:

   * 편집기에서 `mcp.json` 파일이 열려 있는지 확인하세요.
   * 서버 설정 위에서 클릭 가능한 링크(CodeLens)를 찾으세요. 이를 클릭하면 MCP 서버가 시작됩니다.

연결되면 자연어를 사용하여 뉴렐릭 AI와 상호작용할 수 있습니다. MCP 서버는 귀하의 뉴렐릭 계정에서 인증 및 데이터 검색을 관리합니다.
