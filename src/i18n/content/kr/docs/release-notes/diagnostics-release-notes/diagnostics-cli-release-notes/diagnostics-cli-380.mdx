## 새로운 기능

* Diagnostics CLI는 이제 뉴렐릭의 일본 데이터 리전을 지원합니다. 계정이 일본 리전에 있는 경우 CLI를 실행할 때 `region` 플래그를 지정하십시오([#263](https://github.com/newrelic/newrelic-diagnostics-cli/pull/263)):

  ```bash
  ./nrdiag -region JP
  ```

  `region` 플래그는 `US`, `EU` 또는 `JP` (대소문자 구분 안 함)을 허용하며 기본값은 `US`입니다.
