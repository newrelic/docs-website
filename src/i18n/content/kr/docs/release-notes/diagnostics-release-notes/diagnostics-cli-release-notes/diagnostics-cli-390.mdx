## 작업 업데이트

* K8s/AgentControl/Logs - 모든 로그 라인을 수집하도록 업데이트되었습니다([#267](https://github.com/newrelic/newrelic-diagnostics-cli/pull/267)).

## 새로운 기능

* 에이전트 제어를 위한 새로운 제품군과 다음 작업을 추가했습니다([#268](https://github.com/newrelic/newrelic-diagnostics-cli/pull/268)):

  * `onhost-agent-control` suite - 호스트의 에이전트 제어 로그, 상태, 연결 및 리소스에 대한 정보를 수집합니다. 이를 사용하려면 `nrdiag -suites onhost-agent-control`을 실행합니다.
  * AgentControl/Config/Agent - PATH, 알려진 설치 경로 및 데이터 디렉터리 폴백을 통해 에이전트 제어를 감지하고, 등록된 모든 하위 에이전트의 원래 디렉터리 구조를 유지하면서 fleet-data 및 local-data에서 모든 YAML 파일을 수집합니다
  * AgentControl/Config/DirTree - 구조 검사를 위해 모든 에이전트 제어 설치 경로의 포맷된 디렉터리 트리를 zip 파일에 씁니다
  * AgentControl/Agent/Connect - OpAMP, JWKS 및 OAuth2 토큰 엔드포인트의 TCP/TLS 도달 가능성을 확인하고(local\_config.yaml에서 URL 읽기), 로컬 ID 개인 키가 읽기 및 구문 분석 가능한 PKCS8 키(RSA, Ed25519 또는 ECDSA)인지 검증합니다.
  * AgentControl/Agent/Logs - Linux에서는 `journalctl -u newrelic-agent-control`을(를) 통해 로그를 수집하고, Windows에서는 기본 로그 디렉터리에서 날짜별로 순환된 모든 `*.newrelic-agent-control.log` 파일을 글로빙합니다.
  * AgentControl/Agent/StatusServer - local\_config.yaml(기본값 127.0.0.1:51200)에 구성된 호스트/포트에서 로컬 상태 서버를 쿼리하고 JSON 응답을 진단 zip에 저장합니다.
