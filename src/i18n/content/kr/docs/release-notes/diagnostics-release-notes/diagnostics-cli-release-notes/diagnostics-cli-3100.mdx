## 개량

* **`DotNet/Agent/Installed`:** `newrelic.config`이(가) 없을 때 .NET 에이전트 DLL을 감지하도록 작업을 업데이트하고, `newrelic.config`에 대해 대소문자를 구분하지 않는 일치를 활성화했습니다. 이전에는 설정 파일이 누락되어 에이전트 감지가 차단되고 다운스트림 .NET 작업을 건너뛰었습니다([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* **`DotNet/Config/Agent`:** `newrelic.config`이(가) 누락된 경우 실패 대신 경고를 발생시키도록 작업을 업데이트했습니다([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* **.NET Core 설정:** 환경별 설정 파일(`appsettings.Production.json` 등)을 수집하고 분석하도록 파일 수집을 업데이트했습니다. 유사한 명명 패턴을 가진 관련 없는 파일(`myappsettings.json` 등)은 더 이상 수집되지 않습니다([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* **.NET Core 커스텀 측정:** 프로파일러 파일 확인 로직에 맞춰 에이전트 `extensions` 및 `extensions/netcore` 디렉터리를 검사하도록 XML 리더 작업을 업데이트했습니다([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* **.NET 에이전트 로그:** 1일 컷오프가 프로파일러 로그에만 적용되도록 로그 필터링을 업데이트하여, 이전 7일간의 에이전트 로그를 보존합니다. 이제 프로파일러 로그도 `-lastModifiedDate` 플래그를 준수합니다([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* **.NET 에이전트 버전 및 EOL 확인:** .NET 에이전트의 수명 종료(EOL) 및 지원되는 버전 파라미터를 업데이트했습니다. .NET 프레임워크 버전 4.7.1, 4.7.2, 4.8 및 4.8.1에 대한 개별 감지를 추가하고, .NET Core 에이전트에 대한 버전 수집을 활성화했습니다([#273](https://github.com/newrelic/newrelic-diagnostics-cli/pull/273)).
* **.NET 에이전트 로그 레벨:** .NET 에이전트 런타임 동작과 일치하도록 대소문자를 구분하지 않고 설정을 평가하도록 로그 레벨 설정을 업데이트했습니다([#274](https://github.com/newrelic/newrelic-diagnostics-cli/pull/274)).
* **.NET TLS 확인:** 지원되는 .NET 프레임워크 버전은 키가 없을 때 기본적으로 TLS 1.2를 사용하므로, 누락된 `SchUseStrongCrypto` 키가 더 이상 오류로 표시되지 않도록 레지스트리 유효성 검사를 업데이트했습니다. 이제 키가 존재하고 `1` 이외의 값으로 설정된 경우에만 오류가 보고됩니다([#275](https://github.com/newrelic/newrelic-diagnostics-cli/pull/275)).

## 버그 수정

* 릴리스 빌드에서 할당되지 않은 업로드 URL로 인해 일본 데이터 리전으로의 업로드가 실패하는 문제를 수정했습니다([#277](https://github.com/newrelic/newrelic-diagnostics-cli/pull/277)).
* `COR_ENABLE_PROFILING`을(를) 올바르게 확인하도록 .NET 프레임워크 프로파일링 환경 변수 유효성 검사의 문제를 수정했습니다. .NET 에이전트 로그 위치를 확인할 때 `NEW_RELIC_LOG_DIRECTORY` 및 `NEWRELIC_LOG_DIRECTORY`에 대한 지원을 추가했습니다([#272](https://github.com/newrelic/newrelic-diagnostics-cli/pull/272)).
* 구문 분석 중 등호(`=`)가 포함된 환경 변수 값이 잘리는 문제를 수정했습니다([#272](https://github.com/newrelic/newrelic-diagnostics-cli/pull/272)).
