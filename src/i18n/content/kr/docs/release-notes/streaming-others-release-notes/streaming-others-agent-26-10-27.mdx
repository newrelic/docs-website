### 새로운 기능

* `activeLogs`에 로그 레벨을 추가했습니다: `true` 대신 `"INFO"`, `"WARNING"` 또는 `"ERROR"`을(를) 최소 레벨로 전달하십시오. `true`은(는) 여전히 모든 로그를 활성화하고 `false`은(는) 여전히 로그를 비활성화합니다.
* 버퍼 드롭 로깅을 추가했습니다. 이벤트 버퍼가 85% 찼을 때 INFO 메시지, 90%일 때 WARNING 메시지를 기록하며, 드롭된 이벤트당 누적 드롭 횟수를 포함한 하나의 로그 줄을 기록합니다.
* 에이전트 로그 출력에 `QOE_AGGREGATE` 값을 추가했습니다.

### 버그 수정

* 광고가 종료된 후 MediaTailor SSAI 광고 속성이 `VideoAction` 이벤트에 추가되는 문제를 수정했습니다. 이제 해당 속성은 `VideoAdAction` 이벤트에만 추가되며, 각 광고가 종료될 때 에이전트에서 광고 수준 키가 제거됩니다.
* MediaTailor SSAI `adSrc`이(가) 비어 있는 문제를 수정했습니다. 이제 스트림 URL을 포함합니다.
* MediaTailor 트래커가 광고 타이밍 및 횟수 속성(`timeSinceAdStarted`, `timeSinceAdBreakBegin`, `numberOfAds`)을 재정의하는 문제를 수정했습니다.
* `contentRenditionHeight` 및 `contentRenditionWidth`이(가) 항상 720x480, 1280x720 또는 1920x1080을 보고하는 문제를 수정했습니다. 이제 `GetVideoMode()`에서 파생되므로 `videoMode`과(와) 일치합니다(예: `2160p`은(는) 2160 x 3840을 제공합니다).
* 기기가 동일한 초에 출시되었을 때 충돌하는 `nrSessionId` 및 `viewId` 값을 수정했습니다. 이제 세션 ID는 `GetRandomUUID()`을(를) 사용하며, 각 `NewRelicVideoStart()`마다 `nrVideoCounter`이(가) 더 이상 재설정되지 않습니다.
