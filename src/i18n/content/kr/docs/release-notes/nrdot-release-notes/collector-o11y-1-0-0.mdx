### 특징

* `nrdot-collector:2.8.1` 및 다음에 대한 Collector 옵저버빌리티 지원을 확인했습니다. `opentelemetry-collector-contrib:0.163.2`
* 자동 감지에 더 이상 필요하지 않으므로 `newrelic.service.type` 리소스 속성을 제거했습니다.
* 수집 중 불필요한 변환을 방지하도록 `temporality_preference: delta`을(를) 설정하십시오.
