## 변경 로그

`0.157.0` 의 `opentelemetry-collector-contrib` 에서 제거됨에 따라 `nrdot-collector` 및 `nrdot-collector-experimental` 의 구성 요소 매니페스트에서 `jmxreceiver` 이(가) 제거되었음을 알리기 위해 브레이킹 릴리스를 발행합니다(참고로 [이슈 45740](https://github.com/open-telemetry/opentelemetry-collector-contrib/issues/45740) 을 참조하십시오). 이 구성 요소는 더 이상 이 수신기에 의존하지 않도록 조정된 [Kafka 모니터링](/docs/opentelemetry/integrations/kafka/overview/) 사용 사례에서만 독점적으로 사용되었습니다. `jmxreceiver`을(를) 사용하여 사용자 지정 설정으로 `nrdot-collector` 을(를) 배포하는 경우 [수신기의 사용 중단 공지](https://github.com/open-telemetry/opentelemetry-collector-contrib/tree/v0.156.0/receiver/jmxreceiver#deprecation-notice)의 지침에 따라 마이그레이션해 주십시오.

### 특징

* otel 구성 요소 버전을 v0.156.0에서 v0.157.0으로 업데이트했습니다(#643)
* `nroracledbreceiver` 및 `nrsqlserverreceiver` 을(를) v0.157.2로 업데이트했습니다(#643)
  * 이러한 구성 요소의 변경 사항 목록은 [해당 변경 로그](https://github.com/newrelic-forks/opentelemetry-collector-contrib/blob/receiver/nrsqlserverreceiver/v0.157.2/NR_CHANGELOG.md)를 참조하십시오.
* `nrdot-collector-experimental` 배포판에 `sqlqueryreceiver` 을(를) 추가했습니다. (#632)

### 버그 수정

* `nrdot-collector` 및 `nrdot-collector-experimental`에서 `receiver/jmxreceiver` 을(를) 제거했습니다. (#635)
  * 이 구성 요소는 `v0.145.0`에서 더 이상 사용되지 않음에 따라 `v0.157.0` 의 업스트림에서 제거되었습니다.
* `v0.157.0`의 구성 요소 이름 변경에 따라 설정 노드 `cumulativetodelta` 의 이름을 `cumulative_to_delta` (으)로 변경했습니다. (#644)
  * 원래 이름인 `cumulativetodelta` 은(는) 더 이상 사용되지 않는 별칭으로 계속 사용할 수 있습니다.
* 호스트 구성에서 `system.cpu.logical.count` 을(를) 비활성화했습니다. (#647)
  * `receiver/host_metrics` 에 대한 `v0.157.0` 업데이트로 이 메트릭이 기본적으로 활성화되었습니다. 이 변경 사항은 이전 동작을 복원합니다.
* 호스트 구성에서 `system.cpu.utilization` 평균 집계 규칙을 제거했습니다. (#646)
  * `receiver/host_metrics` 에 대한 `v0.157.0` 업데이트로 인해 기본 동작이 평균을 기준으로 `system.cpu.utilization` 을(를) 집계하도록 변경되어, 제거된 규칙이 불필요해졌습니다.
* CVE-2026-56852 (#634)
