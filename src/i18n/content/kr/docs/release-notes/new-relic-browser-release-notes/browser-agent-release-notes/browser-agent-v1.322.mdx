## v1.322.0

### 특징

#### SPV 이벤트를 위한 옵저버 API를 포함합니다.

에이전트 로더 실행 전에 발생한 `securitypolicyviolation` 이벤트를 포착하려면 `ReportingObserver` API를 사용하십시오. 실제로는 기존 구성과 버그가 Firefox 및 Safari 수집에 영향을 미치므로, 이는 주로 크로미움 브라우저에 영향을 미칩니다.

#### MFE 매니페스트

마이크로 프론트엔드가 자체적으로 알려진 자산(스크립트, 스타일시트, 이미지, 글꼴)을 선언할 수 있도록 `register()` API에 선택적 `manifest`을(를) 추가하여, 에이전트가 오류, 로그, AJAX 호출, WebSocket 및 리소스 타이밍 이벤트를 해당 마이크로 프론트엔드에 정확하게 귀속시킬 수 있도록 합니다 ― `register()`을(를) 호출한 스크립트가 아닌 다른 스크립트에서 로드한 자산에 대해서도 마찬가지입니다. 또한 옵트인 `timingMethod`을(를) 사용하면 매니페스트가 선언된 자산 전체에서 `MicroFrontEndTiming` 가져오기/실행 기간을 확대할 수 있습니다.

#### 등록 유효성 검사 경고 추가

등록 API에 제공된 타겟에서 명백한 문제가 감지되면 로컬 디버깅 경고를 발생시킵니다.

### 버그 수정

#### 리스너 누수를 막기 위해 web-vitals를 4.2.4에서 6.2.1로 업그레이드하십시오.

번들로 제공되는 web-vitals 라이브러리를 4.2.4에서 6.2.1로 업그레이드하여 무제한 `document` `visibilitychange` 리스너 누수를 수정했습니다: web-vitals 4.x는 모든 INP 보고 주기마다 영구 리스너를 등록하므로 수명이 긴 페이지에는 수백 개의 리스너가 누적됩니다. 또한 에이전트가 내보내는 속성 이름의 변경 없이, 에이전트가 노출되는 v5/v6 기여도 API 변경 사항(`LCPAttribution.element` → `target` 이름 변경 및 새롭게 선택 사항이 된 INP/CLS 기여도 필드)을 수용했습니다.

## 지지 성명

뉴렐릭은 에이전트를 정기적으로 업그레이드하여 최신 기능과 성능 이점을 얻을 것을 권장합니다. 이전 릴리스는 지원 [종료](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/) 시점부터 더 이상 지원되지 않습니다. 출시일은 에이전트 버전의 원래 출판일을 반영합니다.

다음 기능은 현재 제한된 프리뷰로 제공되며 표준 지원을 받지 않습니다:

* [register() API](https://docs-preview.newrelic.com/docs/browser/register) [를](https://docs-preview.newrelic.com/docs/browser/micro-frontend-monitoring/)통한 마이크로 프런트엔드(MFE) 모니터링
* [BrowserPerformance &quot;resource&quot;](https://docs.newrelic.com/docs/browser/new-relic-browser/browser-pro-features/page-resources/) 유형 이벤트

새로운 브라우저 에이전트 릴리스는 일정 기간 동안 작은 단계로 고객에게 출시됩니다. 이로 인해, 귀하의 계정에서 해당 릴리스에 접근할 수 있는 날짜가 원래 게시 날짜와 일치하지 않을 수 있습니다. 자세한 내용은 이 [상태 대시보드를](https://newrelic.github.io/newrelic-browser-agent-release/) 참조하세요.

당사의 [브라우저 지원 정책](https://docs.newrelic.com/docs/browser/new-relic-browser/getting-started/compatibility-requirements-browser-monitoring/#browser-types)에 따라, 브라우저 에이전트 v1.322.0은 다음 브라우저 및 버전 범위에 맞게 빌드되고 테스트되었습니다: Chrome 142～152, Edge 141～151, Safari 18～27 및 Firefox 144～154. 모바일 기기의 경우, v1.322.0은 안드로이드 OS 16 및 iOS Safari 18～26.2에 맞게 빌드되고 테스트되었습니다.
