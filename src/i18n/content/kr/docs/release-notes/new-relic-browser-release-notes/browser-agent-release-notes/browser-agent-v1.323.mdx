## v1.323.0

전체 기술 변경 로그 및 빌드 크기 정보는 **[GitHub에서 이 릴리스 보기 →](https://github.com/newrelic/newrelic-browser-agent/releases/tag/v1.323.0)**를 확인하십시오.

### 특징

#### ERROR에서 FULL 모드로 전환 시 SR 수집

세션 리플레이를 세션 트레이스와 동일한 방식으로 처리하도록 에이전트를 업데이트하고, SR이 `error` 모드에서 `full` 모드로 전환될 때 리플레이 하베스트를 트리거합니다.

#### AJAX 페이로드에 대한 내부 채택 메트릭을 추가합니다.

품질 보증 및 개선 목적으로 AJAX 페이로드 추적의 채택을 측정하는 내부 메트릭을 추가합니다.

### 버그 수정

#### fix(ajax): DT 헤더 타임스탬프를 서버 시간으로 수정합니다.

AJAX requests에 대해 생성된 분산 추적 헤더(`traceparent`/`tracestate`/`newrelic`)는 이제 에이전트의 TimeKeeper가 RUM 기반 클럭 보정을 완료했을 때 브라우저의 원시 로컬 클럭 값 대신 뉴렐릭 서버에서 보정된 타임스탬프를 사용합니다. 이 타임스탬프는 수신하는 백앤드 APM 에이전트가 자체 스팬에 대해 컴퓨트하는 전송 기간 값에만 영향을 미치며, 다른 브라우저 텔레메트리에는 영향을 미치지 않습니다.

#### 커넥터 경합 조건에서 timeKeeper 준비 상태를 보장합니다.

RUM v2의 새로운 커넥터는 소수 사례의 경쟁 조건 분기에서 에이전트 타임스탬프 조정에 중요한 TimeKeeper를 준비하도록 패치되었습니다. 이는 기능 플래그 뒤에 있으며 현재 어떤 사용자에게도 영향을 미치지 않습니다.

## 지지 성명

뉴렐릭은 에이전트를 정기적으로 업그레이드하여 최신 기능과 성능 이점을 얻을 것을 권장합니다. 이전 릴리스는 지원 [종료](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/) 시점부터 더 이상 지원되지 않습니다. 출시일은 에이전트 버전의 원래 출판일을 반영합니다.

다음 기능은 현재 제한된 프리뷰로 제공되며 표준 지원을 받지 않습니다:

* [register() API](https://docs-preview.newrelic.com/docs/browser/register) [를](https://docs-preview.newrelic.com/docs/browser/micro-frontend-monitoring/)통한 마이크로 프런트엔드(MFE) 모니터링
* [BrowserPerformance &quot;resource&quot;](https://docs.newrelic.com/docs/browser/new-relic-browser/browser-pro-features/page-resources/) 유형 이벤트

새로운 브라우저 에이전트 릴리스는 일정 기간 동안 작은 단계로 고객에게 출시됩니다. 이로 인해, 귀하의 계정에서 해당 릴리스에 접근할 수 있는 날짜가 원래 게시 날짜와 일치하지 않을 수 있습니다. 자세한 내용은 이 [상태 대시보드를](https://newrelic.github.io/newrelic-browser-agent-release/) 참조하세요.

당사의 [브라우저 지원 정책](https://docs.newrelic.com/docs/browser/new-relic-browser/getting-started/compatibility-requirements-browser-monitoring/#browser-types)에 따라, 브라우저 에이전트 v1.323.0은 다음 브라우저 및 버전 범위에 대해 빌드 및 테스트되었습니다: Chrome 143～153, Edge 142～152, Safari 18～27 및 Firefox 145～155. 모바일 기기의 경우, v1.323.0은 안드로이드 OS 16 및 iOS Safari 18～26.2에 대해 빌드 및 테스트되었습니다.
