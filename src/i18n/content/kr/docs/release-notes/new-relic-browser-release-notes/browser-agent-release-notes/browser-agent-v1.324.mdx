## v1.324.1

전체 기술 변경 로그 및 빌드 크기 정보는 **[GitHub에서 이 릴리스 보기 →](https://github.com/newrelic/newrelic-browser-agent/releases/tag/v1.324.1)**를 확인하십시오.

### 버그 수정

#### 세션 리플레이 수집 시 hasMeta/hasSnapshot 플래그를 수정했습니다.

수집된 데이터에 유효한 스냅샷 노드가 포함되어 있음에도 불구하고 세션 리플레이 수집 작업 시 페이로드 메타데이터에서 `hasMeta` 및 `hasSnapshot`을(를) `false` (으)로 잘못 보고할 수 있는 문제를 수정했습니다 ― 이는 세션이 오류 전용에서 전체 기록으로 전환된 직후나 레코더가 다시 시작될 때마다 가장 두드러지게 나타납니다. 이 메타데이터는 다운스트림에서 특정 리플레이 청크가 독립적인지(즉, 자체적으로 리플레이를 부트스트랩할 수 있는지) 여부를 결정하는 데 사용되었으므로, 잘못된 `false` (으)로 인해 유효한 리플레이 데이터가 잘못 처리될 수 있었습니다.

### 보안 수정 사항

#### fflate를 0.8.3으로 업데이트합니다.

잘못된 형식의 ZIP64 아카이브를 구문 분석할 때 unzipSync가 무한 루프에 빠질 수 있는 문제(CVE-2026-45820)를 해결했습니다.

## 지지 성명

뉴렐릭은 에이전트를 정기적으로 업그레이드하여 최신 기능과 성능 이점을 얻을 것을 권장합니다. 이전 릴리스는 지원 [종료](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/) 시점부터 더 이상 지원되지 않습니다. 출시일은 에이전트 버전의 원래 출판일을 반영합니다.

다음 기능은 현재 제한된 프리뷰로 제공되며 표준 지원을 받지 않습니다:

* [register() API](https://docs-preview.newrelic.com/docs/browser/register) [를](https://docs-preview.newrelic.com/docs/browser/micro-frontend-monitoring/)통한 마이크로 프런트엔드(MFE) 모니터링
* [BrowserPerformance &quot;resource&quot;](https://docs.newrelic.com/docs/browser/new-relic-browser/browser-pro-features/page-resources/) 유형 이벤트

새로운 브라우저 에이전트 릴리스는 일정 기간 동안 작은 단계로 고객에게 출시됩니다. 이로 인해, 귀하의 계정에서 해당 릴리스에 접근할 수 있는 날짜가 원래 게시 날짜와 일치하지 않을 수 있습니다. 자세한 내용은 이 [상태 대시보드를](https://newrelic.github.io/newrelic-browser-agent-release/) 참조하세요.

당사의 [브라우저 지원 정책](https://docs.newrelic.com/docs/browser/new-relic-browser/getting-started/compatibility-requirements-browser-monitoring/#browser-types)에 따라, 브라우저 에이전트 v1.324.1은 다음 브라우저 및 버전 범위를 대상으로 구축 및 테스트되었습니다: Chrome 144～154, Edge 144～154, Safari 18～27 및 Firefox 146～156. 모바일 기기의 경우, v1.324.1은 안드로이드 OS 17 및 iOS Safari 18～26.2를 대상으로 구축 및 테스트되었습니다.
