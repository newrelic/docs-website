## v1.324.0

전체 기술 변경 로그 및 빌드 크기 정보는 **[GitHub에서 이 릴리스 보기 →](https://github.com/newrelic/newrelic-browser-agent/releases/tag/v1.324.0)**를 확인해 주십시오.

### 특징

#### 매니페스트에서 스크립트 일치를 개선합니다.

매니페스트에 등록된 마이크로 프런트엔드는 이제 매니페스트 매처와 일치하는 모든 리소스가 MicroFrontEndTiming 데이터에 반영됩니다. 이전에는 각 매니페스트 자산이 첫 번째로 일치하는 리소스에 의해 소비되었으므로, 해시된 청크에 대한 RegExp와 같은 광범위한 매처(예: /catalog-chunk-\[a-f0-9]+.js/) totalWeight, renderBlocking 및 가져오기/실행 타이밍 창에 하나의 청크만 반영했습니다. 이미 로드되었거나 register() 직후에 로드되었는지 여부에 관계없이 일치하는 모든 청크가 이제 반영됩니다. 별도로, 동일한 스크립트 URL이 두 번 이상 참조되는 경우(예: 중복된 `<script>` 태그, 일반적으로 브라우저 캐시에서 다시 제공됨), 에이전트는 이제 덮어쓰는 대신 첫 번째 로드의 타이밍을 유지하므로 캐시된 중복이 더 이상 가져오기 및 실행 타이밍을 실제 로드보다 짧게 보이게 할 수 없습니다.

#### 등록된 마이크로 프론트엔드에 대한 분산 추적을 활성화하십시오.

등록된 마이크로 프론트엔드(MFE)에 대한 분산 추적(DT)을 활성화합니다: 이제 등록된 MFE가 수행하는 AJAX 호출은 해당 MFE 자체 엔티티에 트레이스의 루트를 올바르게 지정하여, 처음으로 MFE 자체의 백앤드 호출에 대한 가시성을 제공합니다.

### 버그 수정

#### 과도한 속성 크기로 인한 로그 수집 폭주를 방지합니다.

커스텀 속성을 반복적으로 덮어쓰는 페이지로 인해 에이전트가 모든 로그 메시지에 대해 별도의 로그 요청을 전송하여 네트워크를 폭주시키고 브라우저 리소스를 고갈시킬 수 있는 버그를 수정했습니다. 이제 에이전트는 값을 덮어쓸 때 커스텀 속성 크기를 정확하게 추적하고, 각 기능이 조기에 수집할 수 있는 빈도를 제한하며, 이 과정에서 로그가 누락되지 않도록 대규모 배치를 신속하게 전송합니다.

#### fix(jserrors): 세션 재설정 시 스택 해시 메모리를 재설정합니다.

자세한 내용은 [https://new-relic.atlassian.net/browse/NR-626097](https://new-relic.atlassian.net/browse/NR-626097)을 참조하십시오. 캐시 TTL로 인해 백앤드가 더 이상 해석할 수 없는 해시 대신, 세션 재설정 후 전체 스택 추적을 한 번 다시 전송합니다.

#### 등록 시 iframe 엔티티 스크립트 타이밍을 확인합니다.

등록된 iframe 엔티티는 이제 상위 에이전트가 응답한 후가 아니라 생성될 때 register()를 호출한 스크립트를 식별합니다. 이전에는 등록 왕복 이후에 조회가 실행되었으며, 이때 호출 스크립트는 더 이상 호출 스택에 없었기 때문에 엔티티의 자산, 유형 및 가져오기 타이밍이 누락되거나 에이전트 자체 스크립트의 속성으로 지정될 수 있었습니다.

## 지지 성명

뉴렐릭은 에이전트를 정기적으로 업그레이드하여 최신 기능과 성능 이점을 얻을 것을 권장합니다. 이전 릴리스는 지원 [종료](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/) 시점부터 더 이상 지원되지 않습니다. 출시일은 에이전트 버전의 원래 출판일을 반영합니다.

다음 기능은 현재 제한된 프리뷰로 제공되며 표준 지원을 받지 않습니다:

* [register() API](https://docs-preview.newrelic.com/docs/browser/register) [를](https://docs-preview.newrelic.com/docs/browser/micro-frontend-monitoring/)통한 마이크로 프런트엔드(MFE) 모니터링
* [BrowserPerformance &quot;resource&quot;](https://docs.newrelic.com/docs/browser/new-relic-browser/browser-pro-features/page-resources/) 유형 이벤트

새로운 브라우저 에이전트 릴리스는 일정 기간 동안 작은 단계로 고객에게 출시됩니다. 이로 인해, 귀하의 계정에서 해당 릴리스에 접근할 수 있는 날짜가 원래 게시 날짜와 일치하지 않을 수 있습니다. 자세한 내용은 이 [상태 대시보드를](https://newrelic.github.io/newrelic-browser-agent-release/) 참조하세요.

당사의 [브라우저 지원 정책](https://docs.newrelic.com/docs/browser/new-relic-browser/getting-started/compatibility-requirements-browser-monitoring/#browser-types)에 따라, 브라우저 에이전트 v1.324.0은 다음 브라우저 및 버전 범위에 대해 빌드되고 테스트되었습니다: Chrome 144～154, Edge 144～154, Safari 18～27 및 Firefox 146～156. 모바일 기기의 경우, v1.324.0은 안드로이드 OS 17 및 iOS Safari 18～26.2에 대해 빌드되고 테스트되었습니다.
