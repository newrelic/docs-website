## v1.320.0

### 특징

#### MFE vitals에 합리적인 제한을 적용하는 기능을 개선합니다.

Register API의 마이크로 프런트엔드(MFE) 바이탈 추적에서 스크립트의 타이밍 상관관계가 오래된 후에도 재사용될 수 있어, 기본 스크립트를 다시 로드하지 않고 다시 마운트하는 MFE(예: 단일 페이지 애플리케이션)에 대해 First Contentful Paint(및 기타 바이탈)가 실제보다 최대 몇 초 더 느리게 잘못 보고되는 버그를 수정했습니다.

#### MFE iframe 지원 - 베타 액세스

iFrame에 캡슐화된 MFE 데이터를 캡처하기 위한 인터페이스를 추가합니다. 이는 실험적인 기능으로, 변경되거나 완전히 제거될 수 있으며 GA 상태에 도달할 때까지 운영 환경에서 사용해서는 안 됩니다.

### 버그 수정

#### 자동 계측된 MFE 이벤트 중복 제거

마이크로 프런트엔드가 `register()` API에 여러 번 등록될 때 자동 계측된 이벤트(AJAX requests, JS 오류, 콘솔 로그, WebSocket 활동 등)의 중복 보고를 수정합니다. 이전에는 반복적으로 등록된 MFE 스크립트에서 발생하는 단일 자동 계측된 이벤트가 등록당 한 번씩 보고되었습니다 ― 이제 자동 감지된 이벤트는 동일한 기본 스크립트 및 동일한 등록된 MFE `id`로 확인될 때 실제 발생당 단일 보고서로 축소됩니다. 명시적인 API 기반 호출(`.addPageAction()`, `.log()`, `.noticeError()` 등) 및 `MicroFrontEndTiming` 이벤트는 의도한 대로 등록당 유지되며, 스크립트를 공유하는 별개의 MFE(예: 동일한 인라인 `<script>` 블록에서 등록된 두 개의 다른 MFE)는 계속해서 독립적으로 보고됩니다.

## 지지 성명

뉴렐릭은 에이전트를 정기적으로 업그레이드하여 최신 기능과 성능 이점을 얻을 것을 권장합니다. 이전 릴리스는 지원 [종료](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/) 시점부터 더 이상 지원되지 않습니다. 출시일은 에이전트 버전의 원래 출판일을 반영합니다.

새로운 브라우저 에이전트 릴리스는 일정 기간 동안 작은 단계로 고객에게 출시됩니다. 이로 인해, 귀하의 계정에서 해당 릴리스에 접근할 수 있는 날짜가 원래 게시 날짜와 일치하지 않을 수 있습니다. 자세한 내용은 이 [상태 대시보드를](https://newrelic.github.io/newrelic-browser-agent-release/) 참조하세요.

당사의 [브라우저 지원 정책](https://docs.newrelic.com/docs/browser/new-relic-browser/getting-started/compatibility-requirements-browser-monitoring/#browser-types)에 따라, 브라우저 에이전트 v1.320.0은 다음 브라우저 및 버전 범위에 대해 빌드되고 테스트되었습니다: Chrome 140-150, Edge 140-150, Safari 18-27 및 Firefox 142-152. 모바일 디바이스의 경우, v1.320.0은 안드로이드 OS 16 및 iOS Safari 18-26.2용으로 빌드되고 테스트되었습니다.
