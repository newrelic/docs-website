### 특징

* Google IMA DAI(동적 광고 삽입) 지원 `NRTrackerIMA`
* INFO 수준으로 로깅을 활성화하고, iOS `enableLogging` API와 동일하게 버퍼가 거의 꽉 찬 상태와 삭제된 이벤트를 로그합니다.

### 버그 수정

* 브레이크 종료로 인해 중단된 광고가 종료되고, 잘못된 사분위수 및 클릭 이벤트가 무시되며, 광고별 타이머가 다음 브레이크로 이어지지 않고, 광고 지속 시간이 밀리초 단위로 보고되도록 IMA 광고 추적 기능을 수정했습니다.
