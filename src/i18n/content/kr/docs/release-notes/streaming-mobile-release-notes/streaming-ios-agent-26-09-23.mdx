### ⚠ 주요 변경 사항

* `NRVAVideo.addPlayer()`: 이제 플레이어 유형을 식별할 수 없고 명시적인 `playerType`이(가) 설정되지 않은 경우, 암묵적으로 AVPlayer 트래커를 기본값으로 사용하는 대신 트래커를 생성하지 않고 반환합니다. 사용자 지정 또는 래핑된 플레이어 객체를 전달하는 경우, `NRVAVideoPlayerConfiguration.playerType`을(를) 명시적으로 설정하십시오.

### 특징

* `NRTHEOplayerTracker`: THEOplayer(Dolby OptiView Player)용 새 트래커를 추가했습니다 — 콘텐츠 수명 주기 이벤트, QoE/렌디션 추적 및 오류 매핑. iOS 전용, iOS 13.0+. CocoaPods, XCFrameworks 및 스위프트 패키지 매니저를 통해 사용할 수 있습니다.
