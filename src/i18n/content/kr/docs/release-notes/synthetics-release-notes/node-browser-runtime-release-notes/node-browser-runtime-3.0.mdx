New Relic scans the Node browser runtime image for vulnerabilities every day and publishes a patched release every Thursday. Each release includes fixes for operating system, application, and Chrome CVEs identified by Tuesday 6:29 PM UTC of that week. If we identify a CVE after that time, the fix ships in the following week&apos;s Thursday release.

We publish every release to the `latest` tag, which runs Node.js 22 and the latest stable version of Chrome. Private locations that use `latest` get fixes automatically. If you use a specific version tag, manually update to the newest version to get current fixes.

### 보안 패치

**라이브러리 취약점:**

* undici를 7.30.1(npm 내부 6.29.1)로 업그레이드했습니다: CVE-2026-109383, CVE-2026-109829, CVE-2026-109841, CVE-2026-109869, CVE-2026-109924, CVE-2026-109932, CVE-2026-87018, CVE-2026-87029
* ip-address를 10.7.5(npm 내부 10.7.4)로 업그레이드했습니다: CVE-2026-111997
* nodemailer를 10.2.1로 업그레이드했습니다: GHSA-85x2-q946-cp5h, GHSA-8c8m-p3m8-cjg8, GHSA-m943-m63m-w62w, GHSA-4ffr-jq9g-5ffx, GHSA-g73g-hqqh-jr95
* qs를 6.16.1로 업그레이드: CVE-2026-110816

**OS 취약점:**

* zlib1g를 1:1.3.dfsg-3.1ubuntu2.3으로 업데이트했습니다: CVE-2026-85091
* libbrotli1 업데이트: CVE-2026-111497

**CA 인증서:**

* OS CA 번들 및 관련 키스토어에서 eMudhra(emSign) 루트 인증서와 Comodo AAA Certificate Services 루트에 대한 신뢰를 제거하여 eMudhra 인증 기관 침해 문제를 해결했습니다
