### 버그 수정

* Angular 및 Zone.js 애플리케이션에서 12～30초의 클릭 지연을 수정했습니다. 이제 신세틱스 브라우저 확장 프로그램은 BiDi(`webExtension.install`) 대신 CDP WebSocket(`Extensions.loadUnpacked`)을 통해 로드됩니다. Chrome 153+ BiDi는 모든 클릭 후 &quot;보류 중인 탐색 대기&quot; 확인을 도입하여 보류 중인 매크로태스크가 있는 앱의 응답을 지연시켰습니다. CDP로 전환하면 세션에서 BiDi가 제외되어 ChromeDriver의 기존 1밀리초 미만 `document.readyState` 탐색 확인이 복원됩니다.
