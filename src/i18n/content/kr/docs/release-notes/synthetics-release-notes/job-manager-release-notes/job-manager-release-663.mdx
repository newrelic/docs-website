뉴렐릭은 매일 신세틱스 작업 관리자 이미지의 취약점을 스캔하고 매주 목요일에 패치된 릴리스를 배포합니다. 각 릴리스에는 해당 주 화요일 18시 29분(UTC)까지 확인된 운영 시스템 및 애플리케이션 CVE에 대한 수정 사항이 포함됩니다. 해당 시간 이후에 CVE가 확인되는 경우, 수정 사항은 다음 주 목요일 릴리스를 통해 배포됩니다.

모든 릴리스를 `latest` 태그에 게시하므로, `latest`을(를) 사용하는 프라이빗 로케이션에는 수정 사항이 자동으로 적용됩니다. 특정 버전 태그를 사용하는 경우, 현재 수정 사항을 적용하려면 최신 버전으로 수동으로 업데이트해 주십시오.

작업 관리자는 Ping, Node API 및 Node 브라우저 런타임과 별도로 릴리스됩니다. 자체 수정 사항은 각 런타임의 릴리스 노트를 확인해 주십시오.
