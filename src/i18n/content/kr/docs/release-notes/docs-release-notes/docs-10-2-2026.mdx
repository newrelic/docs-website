### 새로운 문서

* KDC 및 SPNEGO 웹 서버 설정과 신세틱스 작업 관리자 설정을 포함하여 [프라이빗 로케이션에 대한 Kerberos(SPNEGO) 인증 지원](/docs/synthetics/synthetic-monitoring/private-locations/synthetics-kerberos-auth-support/)을 추가했습니다.
* 플릿별 범위 지정, 수명 주기 분리, 위임된 그룹 관리 및 비즈니스 단위 격리를 위한 역할 기반 액세스 패턴을 다루는 [플릿 컨트롤 액세스 관리](/docs/new-relic-control/fleet-control/access-management/)를 추가했습니다.
* 이전 재계측 페이지를 대체하며, 처음부터 계측을 설정하거나 Kubernetes, Linux 및 Windows에서 기존 에이전트를 마이그레이션하는 방법을 다루는 [에이전트 컨트롤로 시스템 계측하기](/docs/new-relic-control/agent-control/instrumentation/)를 추가했습니다.
* 흐름, 상태 지표, KPI 및 NerdGraph 관리를 다루는 퍼블릭 프리뷰용 [Pathpoint(업데이트됨)](/docs/pathpoint/get-started-pathpoint/) 문서를 추가했습니다.
* 보고하는 데이터, 활성화, 폴링 빈도 및 워크로드 아이덴티티 페더레이션을 다루는 [Google Distributed Cloud Edge 모니터링 통합](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-distributed-cloud-edge-monitoring-integration/)을 추가했습니다.
* [Autopilot RCA 워크플로우 템플릿](/docs/workflow-automation/workflow-examples/integrations/autopilot-rca/) 개요와 함께, 공지에 대한 Autopilot 근본 원인 분석을 [실행하고 이메일로 HTML 보고서를 전송하는 방법을 보여주기 위해 Autopilot 및 이메일을 사용한 공지 RCA](/docs/workflow-automation/workflow-examples/integrations/autopilot-email-rca/) 를 추가했습니다.
* 워크플로우 자동화 작업 카탈로그에 [Azure Monitor 로그 쿼리](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-monitor-querylogs/) 작업을 추가했습니다.
* 워크플로우 자동화 액션 카탈로그에 [Azure Cosmos DB 액션](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-cosmos-db/)을 추가했습니다.
* 워크플로우 자동화 작업 카탈로그에 [AWS 리소스 그룹 태그 API 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/resourcetagging/aws-resourcetagging/)을 추가했습니다.
* 뉴렐릭 엔티티의 태그를 추가, 교체 및 제거하기 위해 워크플로우 자동화 작업 카탈로그에 [뉴렐릭 태그 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging/)을 추가했습니다.

### 주요 변경 사항

* 업데이트된 엔터티 맵 환경을 위해 [트레이스 세부 정보 UI 페이지 이해하기](/docs/distributed-tracing/ui-data/trace-details/)를 다시 작성했습니다.
* `protocol_version` 필드, 각 변수 필드에 대한 참조, Kubernetes 및 온-호스트에 대한 별도의 배포 섹션으로 [에이전트 유형](/docs/new-relic-control/agent-control/agent-types/)을 확장했습니다.
* 지원되는 에이전트 및 버전의 호환성 매트릭스와 함께 뉴렐릭 APM 에이전트, OpenTelemetry Collector, eBPF 자동 연결 에이전트 및 인프라 에이전트에 대한 에이전트별 설정 예시를 [에이전트 설정 수정](/docs/new-relic-control/pipeline-control/gateway/modify-agent-configuration/)에 추가했습니다.
* Pipeline의 모든 단계에서 샘플 속도, 필터 및 변환 프로세서를 추가하고 삭제하는 방법을 문서화하기 위해 파이프라인 컨트롤 게이트웨이 [개요](/docs/new-relic-control/pipeline-control/gateway/overview/), [UI 가이드](/docs/new-relic-control/pipeline-control/gateway/ui-guide/) 및 [YAML 설정 참조](/docs/new-relic-control/pipeline-control/gateway/yaml-overview/)를 업데이트했습니다.
