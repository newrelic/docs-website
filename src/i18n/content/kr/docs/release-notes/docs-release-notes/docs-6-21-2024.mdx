### 새로운 문서

* 모든 에러스 인박스(errors inbox) 모바일 크래시 문서를 단일 [모바일 그룹 크래시 탭](/docs/triage-inbox/mobile-tab)으로 통합했습니다.
* 새로운 [모델 데이터 분석](/docs/ai-monitoring/explore-ai-data/view-model-data)은 AI 모니터링을 사용하여 모델 성능을 관찰할 수 있는 다양한 방법을 설명합니다.
* 새로운 [Google VertexAI 모니터링 통합](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-vertexai-monitoring-integration)은 통합을 활성화하고 모니터링을 시작하는 방법을 설명합니다.
* 새로운 [NVIDIA Jetson 통합](/docs/infrastructure/host-integrations/host-integrations-list/nvidia-jetson-integration)은 NVIDIA Jetson 디바이스를 모니터하는 방법을 설명합니다.

### 주요 변경 사항

* 파이썬 에이전트 설정에 [`STARTUP_DEBUG`](/docs/apm/agents/python-agent/configuration/python-agent-configuration/#NEW_RELIC_STARTUP_DEBUG) 정보를 추가했습니다.
* [모바일 모니터링 설정](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/configure-settings/#android-background-reporting)에 안드로이드용 백그라운드 및 `ApplicationExitInfo` 보고에 대한 활성화 및 비활성화 정보를 추가했습니다.
* 알림 탐색의 대대적인 개편을 통해 알림 생성, 설정, 관리 및 사용에 이르는 사용자 여정을 더욱 명확하게 보여줍니다.

### 사소한 변경 사항

* 두 문서를 더 비슷하게 구성해 달라는 고객 피드백에 따라 [iOS](/docs/mobile-monitoring/new-relic-mobile-ios/configuration/app-launch-times-ios-apps) 및 [안드로이드](/docs/mobile-monitoring/new-relic-mobile-android/install-configure/configure-app-launch-time-android-apps) 앱 출시 시간 문서의 구조를 일치시켰습니다.
* [인프라 로그](/docs/infrastructure/install-infrastructure-agent/get-started/requirements-infrastructure-agent)가 이제 Ubuntu 24.04(Noble Numbat)를 지원합니다.
* [Node.js](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent) 및 [.NET Core 및 프레임워크](/docs/apm/agents/net-agent/configuration/net-agent-configuration/) 호환성을 업데이트했습니다.
* AI 모니터링 설치 가이드에 [자바 에이전트 설정](/install/ai-monitoring/?agent-lang=java) 및 기타 편의성 개선 사항을 추가했습니다.
* [AWS PrivateLink](/docs/data-apis/custom-data/aws-privatelink/#us-endpoints-use1) 뉴렐릭 REST API 엔드포인트가 추가되었습니다.
* 당사의 [오라클 데이터베이스 통합](/docs/infrastructure/host-integrations/host-integrations-list/oracle-database-monitoring-integration/#comp-req)은 이제 버전 23까지 지원합니다.
* [HAProxy 통합](/docs/infrastructure/host-integrations/host-integrations-list/haproxy-monitoring-integration)은 이제 최대 버전 3.x를 지원합니다.
* [.NET 에이전트](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements/)는 just-in-time(JIT) 컴파일이 필요하며, 이는 Native Ahead of Time(AOT) 배포를 지원하지 않음을 의미한다는 점을 명확히 했습니다.
* [Linkerd 통합 메트릭을 노출하는 방법](/docs/infrastructure/host-integrations/host-integrations-list/linkerd-integration/#expose-linkerd-metrics)에 대한 새로운 지침을 추가했습니다.
* 새로운 Jira UI를 표시하도록 [Atlassian Jira 통합](/docs/more-integrations/open-source-telemetry-integrations/atlassian/atlassian-integration/#different-organization)의 스크린샷을 업데이트했습니다.
* [신세틱 모니터링](/docs/synthetics/synthetic-monitoring/private-locations/monitor-private-locations/#minion-status) 프라이빗 로케이션 작업 관리자 엔드포인트를 추가했습니다.
* [.NET 에이전트 설정](/docs/apm/agents/net-agent/configuration/net-agent-configuration)의 코드 블록 스타일을 업데이트했습니다.
