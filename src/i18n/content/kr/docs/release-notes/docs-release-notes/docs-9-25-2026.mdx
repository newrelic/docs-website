### 새로운 문서

* 분산 추적 및 서비스 관계에 대한 HAProxy OTel 필터 설정을 다루기 위해 [HAProxy 분산 추적](/docs/opentelemetry/integrations/haproxy/distributed-tracing/)을 추가했습니다.
* `ngx_otel_module`을(를) 사용한 NGINX용 OTel 기반 분산 추적 설정을 다루는 [NGINX 분산 추적](/docs/opentelemetry/integrations/nginx/nginx-otel-distributed-tracing/)을 추가했습니다.
* 개요, Kubernetes 설정, 분산 추적 및 전체 메트릭 참조를 다루는 [OpenTelemetry를 통한 Linkerd 모니터링](/docs/opentelemetry/integrations/linkerd/introduction/)을 추가했습니다.
* `es.cluster.name` 하드코딩에 대한 더 원활한 대안인 [APM ↔ Elasticsearch 분산 추적 상관관계](/docs/opentelemetry/integrations/elasticsearch/distributed-tracing/)를 추가했습니다.
* OpenTelemetry를 통한 MSSQL 모니터링을 위한 [다중 수신기 설정](/docs/opentelemetry/database/mssql/multi-receiver/) 가이드를 추가했습니다.
* 워크플로우 자동화 작업 카탈로그에 [AWS Step Function 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/stepfunctions/aws-stepfunctions/)을 추가했습니다.

### 주요 변경 사항

* 새로운 인라인 필터 필(pill) 및 토글을 포함하여 재설계된 트레이스 목록 인터페이스에 맞게 [분산 추적 UI 데이터](/docs/distributed-tracing/ui-data/understand-use-distributed-tracing-ui/) 페이지를 다시 작성했습니다.
* [OpenTelemetry를 통한 오라클 DB 모니터링](/docs/opentelemetry/database/oracle/introduction/) 문서를 재구성했습니다.
* [워크플로우 자동화 작업 카탈로그](/docs/workflow-automation/setup-and-configure/actions-catalog/actions-catalog/)를 작업별 페이지로 재구성하고 뉴렐릭 알림 작업을 추가했습니다.
* NRQL, 쿼리 빌더 및 NerdGraph 문서 전반에 걸쳐 12개 페이지를 업데이트하여 명시적인 교차 계정 쿼리 한도가 5개 계정에서 30개 계정으로 증가했음을 명시했습니다.
* 일반 공급을 위해 [복합 알림](/docs/alerts/create-alert/create-alert-condition/compound-alerts/compound-alerts/) 문서를 업데이트했습니다.
* [작업 카탈로그](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/ec2/aws-ec2/)에 AWS EC2 작업을 추가했습니다.

### 새로워진 사항

* [뉴렐릭 복합 알림은 더 정확한 공지를 위해 여러 조건을 하나로 통합합니다](/whats-new/2026/09/whats-new-09-22-compound-alerts): 최대 5개의 공지 조건을 AND/OR 논리와 결합하여 팀의 주의가 필요한 정확한 신호를 정의하십시오.
* [이제 한 번에 최대 30개의 뉴렐릭 계정을 쿼리하십시오!](/whats-new/2026/09/whats-new-09-22-cross-account-query-limit-30): 한 번에 쿼리할 수 있는 최대 계정 수가 5개에서 30개로 증가하며, UI 또는 API를 통해 사용할 수 있습니다.
