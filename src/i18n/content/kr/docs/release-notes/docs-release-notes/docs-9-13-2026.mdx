### 새로운 문서

* Amazon EventBridge에 이벤트를 게시하기 위한 [AWS EventBridge 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/aws-eventbridge)을 워크플로우 자동화 작업 카탈로그에 추가했습니다.
* 워크플로우에서 서비스 수준 목표(SLO)를 생성하고 관리하기 위한 [뉴렐릭 서비스 수준 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/newrelic-service-level)을 워크플로우 자동화 작업 카탈로그에 추가했습니다.

### 주요 변경 사항

* 권장 사항을 통한 일괄 생성, 제외 필터 섹션, 분산 추적 활성화를 위한 새로운 전제 조건 섹션을 포함하여 [지능형 워크로드 생성](/docs/new-relic-solutions/new-relic-one/workloads/create-intelligent-workload)을 업데이트했습니다.
* 추가 설정 옵션 및 확장된 참조 콘텐츠를 포함하여 워크플로우 자동화 작업 카탈로그의 [AWS SQS 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/aws-sqs)을 확장했습니다.
* 간소화된 쿼리 예제와 단순화된 설명을 포함하여 [CCI 재무 인텔리전스용 NRQL](/docs/cci/financial-intelligence/nrql-for-cci)을 업데이트했습니다.
* [eBPF 에이전트](/docs/ebpf/requirements)에 오라클 Kubernetes 엔진(OKE) 항목 및 MariaDB/Aurora MySQL 지원을 추가했습니다.
* [eBPF Kubernetes 설치](/docs/ebpf/k8s-installation) 및 [eBPF Linux 설치](/docs/ebpf/linux-installation)에 `agentMetadataReporting` 및 생성형 AI 모니터링 설정 파라미터를 추가했습니다.
* [Grafana에서 Prometheus 데이터 보기 및 쿼리](/docs/infrastructure/prometheus-integrations/view-query-data/grafana)의 Grafana 대시보드 변환 엔드포인트 URL을 업데이트했습니다.
* [MySQL](/docs/opentelemetry/database/mysql/hosted) 및 [PostgreSQL 호스팅 및 RDS 모니터링 문서](/docs/opentelemetry/database/postgresql/hosted)의 NRDOT Collector 설정 경로 업데이트 명령을 업데이트했습니다.
* OCI 미러 및 에이전트 유형 정의에 대한 서명 확인 요구 사항을 반영하여 [에이전트 유형](/docs/new-relic-control/agent-control/agent-types) 및 [미러 설정](/docs/new-relic-control/agent-control/mirror-setup)을 업데이트했습니다.
* 액세스 거부 오류를 방지하기 위해 자바 9+ 환경에 필요한 권한에 대한 내용을 포함하여 [자바 2 보안으로 자바 에이전트 설치](/docs/apm/agents/java-agent/additional-installation/install-java-agent-java-2-security)를 업데이트했습니다.
* 새로운 OAuth 범위 및 API 키를 사용하여 [MCP 개요](/docs/agentic-ai/mcp/overview) 및 [뉴렐릭 MCP 설정](/docs/agentic-ai/mcp/setup)을 업데이트했습니다.
* EKS Fargate 노드에 Kubernetes APM 자동 연결 지원을 추가하도록 [Kubernetes 통합 설치 문서](/docs/kubernetes-pixie/kubernetes-integration/installation/k8s-agent-operator)를 업데이트했습니다.

### 사소한 변경 사항

* 풀 및 공급자 이름은 사용자 지정 가능한 제안 사항임을 명확히 하는 콜아웃을 [GCP 워크로드 아이덴티티 연합 연결](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation)에 추가했습니다.
* [CNCF 수집기로 Microsoft SQL Server 모니터](/docs/opentelemetry/database/mssql/cncf)에서 데이터베이스 쿼리 성능 설명을 업데이트했습니다.

### 새로워진 사항

* [카탈로그의 태그 기반 그룹화, 사용자 지정 열 및 열 재정렬](/whats-new/2026/09/whats-new-09-07-catalogs-tag-grouping): 이제 뉴렐릭에서 정의하거나 사용자 지정한 모든 태그를 사용하여 엔티티를 그룹화하고 열을 추가할 수 있으며, 워크플로우에 맞게 재정렬할 수 있습니다. 레이아웃은 자동으로 저장됩니다.
