## 새로운 문서

* 수동 필터 재구축 없이 지연시간 또는 오류 스파이크에서 비정상적인 트레이스를 표면화하는 공개 프리뷰 기능을 위한 [Intelligent Exemplar](/docs/distributed-tracing/ui-data/intelligent-exemplar) 문서를 추가했습니다.
* 지연시간 또는 오류 급증을 유발하는 속성-값 쌍을 자동으로 식별하는 퍼블릭 프리뷰 기능에 대한 [속성 상관관계 분석](/docs/distributed-tracing/ui-data/attribute-correlation-analysis) 문서를 추가했습니다.
* 운영 우수성을 향한 서비스 진행 상황을 추적하기 위한 스코어카드 성숙도 수준 및 가중치 점수 산정에 대한 [서비스 성숙도](/docs/service-architecture-intelligence/scorecards/service-maturity) 문서를 추가했습니다.
* Kubernetes 네임스페이스별로 eBPF 텔레메트리를 다른 뉴렐릭 계정으로 라우팅하기 위한 [뉴렐릭 eBPF 에이전트용 다중 계정 라우팅 설정](/docs/ebpf/multi-account-routing) 문서를 추가했습니다.
* 스레드 내 인시던트 조사를 위해 Autopilot을 Slack에 연결하는 [Autopilot Slack 통합](/docs/agentic-ai/autopilot/connect-to-slack) 문서를 추가했습니다.
* 권장 표준에 대비하여 엔티티 공지 커버리지를 모니터하고 조건을 일괄 생성하는 퍼블릭 프리뷰 기능에 대한 [스마트 알림 소개](/docs/alerts/smart-alerts) 문서를 추가했습니다.
* 반복 가능한 조사 런북을 위해 동적 변수로 노트북을 매개변수화하는 [노트북의 변수](/docs/query-your-data/explore-query-data/notebooks/notebook-variables) 문서를 추가했습니다.
* 타임슬라이스 메트릭으로 보고되는 Puma 서버 통계의 루비 에이전트 샘플링에 대한 [Puma 계측](/docs/apm/agents/ruby-agent/instrumented-gems/puma-instrumentation) 문서를 추가했습니다.
* Windows에서 NRDOT 수집기를 사용하여 AWS RDS의 SQL Server를 모니터링하기 위한 [NRDOT를 사용한 Windows RDS MSSQL 모니터링](/docs/opentelemetry/database/mssql/windows-rds) 문서를 추가했습니다.

### 주요 변경 사항

* GA 릴리스와 함께 [개요](/docs/agentic-ai/autopilot/overview), [설정](/docs/agentic-ai/autopilot/setup), [Autopilot 사용](/docs/agentic-ai/autopilot/use-autopilot) 및 [메모리](/docs/agentic-ai/autopilot/memories) 전반에 걸쳐 Autopilot 문서를 업데이트하여 SRE 에이전트에서 Autopilot으로 이름을 변경하고 HIPAA 가용성을 반영하도록 규정 준수 정보를 업데이트했습니다.
* 확장된 커널 버전 지원(`v5.8` ～ `v7.1`), 새로 지원되는 Linux 배포판(AlmaLinux 9.7+, 오라클 Linux 8+, openSUSE Leap 15.5+, SLES 15.7+) 및 업데이트된 Kubernetes 및 Linux 설치 절차를 포함하여 1.5.0 릴리스에 대한 [eBPF 에이전트 문서](/docs/ebpf/k8s-installation) 를 업데이트했습니다.
* 데이터 볼륨 및 비용 제어를 위해 각 텔레메트리 유형이 샘플링되는 방법을 설명하는 새로운 데이터 샘플링 및 미세 조정 섹션으로 [eBPF 모범 사례](/docs/ebpf/best-practices) 를 업데이트했습니다.
* 3개의 중복 제거 값을 통합하는 새로운 빠른 참조 표와 업데이트된 소개 콜아웃으로 [Prometheus 고가용성(HA)](/docs/infrastructure/prometheus-integrations/install-configure/prometheus-high-availability-ha) 을 업데이트했습니다.
* 수동 AWS CloudWatch Metric Streams 설정을 위한 Firehose 설정 섹션을 복원하여 [메트릭 수동 설정을 위한 AWS 통합](/docs/infrastructure/amazon-integrations/aws-integration-for-metrics/manual) 을 업데이트했습니다.
* 배포 빈도, 변경 리드 타임, MTTR, PR 주기 시간 및 열린 pull 요청 위젯에 대한 데이터 요구 사항을 문서화하는 새로운 Team Hub 생산성 위젯 섹션으로 [팀 관리](/docs/service-architecture-intelligence/teams/manage-teams) 를 업데이트했습니다.

### 사소한 변경 사항

* 지원되는 버전 범위에 Kubernetes 1.35를 추가하도록 [Kubernetes 통합 호환성 및 요구 사항](/docs/kubernetes-pixie/kubernetes-integration/get-started/kubernetes-integration-compatibility-requirements) 을 업데이트했습니다.
* `Mobile` 및 `MobileSession` 이벤트 세션 시간 초과를 10분에서 1분으로 수정하도록 [모바일 모니터링에서 보고된 이벤트](/docs/data-apis/understand-data/event-data/events-reported-mobile-monitoring) 를 수정했습니다.
* 이제 `TRACE` 로그 레벨을 사용할 수 있음을 명확히 하고 작업 출력 속성에 대한 동작을 문서화하도록 [워크플로우 실행 모니터](/docs/workflow-automation/manage-workflows/monitor-workflow-execution) 를 업데이트했습니다.
* 하이브리드 에이전트 접근 방식이 현재 Next.js 버전 16 이상만 지원한다는 점을 추가하도록 [하이브리드 에이전트를 사용한 Next.js 계측](/docs/apm/agents/nodejs-agent/extend-your-instrumentation/nextjs-instrumentation) 을 업데이트했습니다.
* 루비 10.x 및 최소 지원 버전(루비 2.6.0)을 추가하도록 [루비 에이전트 EOL 정책](/docs/apm/agents/ruby-agent/getting-started/ruby-agent-eol-policy) 을 업데이트했습니다.
* 조직의 인증 도메인에서 제거하는 것은 영구적이며 실행 취소할 수 없음을 명확히 하도록 [다중 사용자 레코드](/docs/accounts/accounts-billing/account-setup/multiple-user-records) 를 업데이트했습니다.
* 개정된 처리 위치 정보로 [디지털 운영 복원력법(DORA) 데이터 위치](/docs/security/security-privacy/compliance/certificates-standards-regulations/dora/dora-data-locations) 를 업데이트했습니다.
* 끊어진 링크를 수정하기 위해 [Fargate용 PHP 에이전트 문제 진단, 해결](/docs/apm/agents/php-agent/troubleshooting/fargate-nitro-clock-performance-impact) 을 수정했습니다.
* 자동화 및 계층 구조 설정 페이지에 대한 권한 설명을 명확히 하도록 [팀](/docs/service-architecture-intelligence/teams/teams) 을 업데이트했습니다.
* 상위 쿼리 수집 설정 파라미터에 대해 수정된 기본값으로 [NRDOT를 사용한 Windows 호스팅 MSSQL 모니터링](/docs/opentelemetry/database/mssql/windows-hosted) 을 업데이트했습니다.
