## 새로운 문서

* 설정 참조 및 모범 사례를 포함하여 [eBPF 로그 공개 프리뷰](/docs/ebpf/logs) 문서를 이제 사용할 수 있습니다.
* 이제 프라이빗 로케이션에서 사용자 지정 CA 인증서를 설정하기 위한 [사용자 지정 인증서 지원](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-configuration/#custom-ca-certificates) 문서를 사용할 수 있습니다.

### 주요 변경 사항

* 다중 요금제 지원(`FlexConsumption`, `ElasticPremium`, `Basic`, `Consumption`), FedRAMP/US Gov Cloud 엔드포인트 및 프라이빗 모드 아웃바운드 라우팅 문서를 포함하여 [Azure VNet Flow 로그](/docs/network-performance-monitoring/setup-performance-monitoring/cloud-flow-logs/azure-vnet-flow-log-monitoring) 모니터링 설정을 업데이트했습니다.
* Pay As You Go 하위의 임시 무료 평가 기간 조항과 &quot;평가 기능&quot; 정의를 포함하도록 [사용 계획 약관](/docs/licenses/license-information/usage-plans/new-relic-usage-plan) 을 업데이트했습니다.

### 사소한 변경 사항

* 계정 간의 관계를 확인하는 방법에 대한 참조 문서를 포함하도록 [계정 관리](/docs/accounts/accounts-billing/account-setup/downgradecancel-account) 를 업데이트했습니다.
* [자바 에이전트 호환성 요구 사항](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent)을 업데이트했습니다.
* 새로운 설정 세부 정보로 [OpenTelemetry MSSQL](/docs/opentelemetry/database/mssql/introduction) 문서를 업데이트했습니다.
* 더 빠른 온보딩을 위해 필수 및 선택 섹션을 분리하여 [변경 추적 이벤트 API](/docs/change-tracking/change-tracking-events) 속성 참조를 업데이트했습니다.
* 잘못된 명령을 바로잡기 위해 [에이전트 컨트롤 제거 명령](/docs/new-relic-solutions/new-relic-one/install-configure/uninstall-agent) 을 수정했습니다.

### 수명 종료

* **모바일 크래시 REST API v1** 문서 페이지를 사용 중단했습니다. 더 이상 사용되지 않는 v1 API는 v2로 대체되었습니다.
