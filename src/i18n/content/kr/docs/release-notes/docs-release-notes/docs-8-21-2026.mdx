### 새로운 문서

* 가이드 설정, 호스팅 및 Amazon RDS 설정, 다중 수신기 설정, 전체 메트릭 참조를 포함하는 퍼블릭 프리뷰 통합으로 [OpenTelemetry를 통한 MySQL 모니터링](/docs/opentelemetry/database/mysql/introduction)을 추가했습니다.
* 안내형 설정, 호스팅 및 Amazon RDS 설정, `EXPLAIN` 권한, 전체 메트릭 참조를 다루는 공개 프리뷰 통합으로 [OpenTelemetry를 통한 PostgreSQL 모니터링](/docs/opentelemetry/database/postgresql/introduction)을 추가했습니다.
* 사용자 지정 CA 인증서, mTLS 및 Terraform 자동화와 같은 신세틱 모니터링 프라이빗 로케이션 기능을 통합하기 위해 [프라이빗 로케이션 기능](/docs/synthetics/synthetic-monitoring/guides/private-location-capabilities)을 추가했습니다.
* 사용자별 월간 컴퓨트 예산을 설정할 수 있도록 이제 정식 출시된 [컴퓨트 사용자 제한](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/compute-budgets/compute-user-limits)을 추가했습니다.
* 크래시, 오류 또는 ANR로 이어지는 일련의 이벤트를 보여주는 [모바일 사용자 여정](/docs/mobile-monitoring/mobile-monitoring-ui/mobile-app-pages/user-journeys)을 추가했습니다.
* 오라클 또는 SQL Server 데이터베이스에 대해 커스텀 SQL 쿼리를 실행하고 그 결과를 메트릭으로 수집하기 위한 퍼블릭 프리뷰 기능으로 [SQL 쿼리 수신기 설정](/docs/opentelemetry/database/capabilities/sql-query-receiver)을 추가했습니다.

### 주요 변경 사항

* AlloyDB, Bigtable, Firestore 및 Vertex AI를 포함한 18개의 추가 서비스에 대한 권한으로 [GCP 통합 사용자 지정 역할](/docs/infrastructure/google-cloud-platform-integrations/get-started/integrations-custom-roles)을 업데이트했습니다.
* 설치, 권한 부여 및 다중 수신기 설정을 포함하여 오라클 자율운영 데이터베이스(ADB)를 완벽하게 지원하도록 [NRDOT를 사용한 오라클 데이터베이스 모니터링](/docs/opentelemetry/database/otel-oracledb)을 업데이트했습니다.

### 사소한 변경 사항

* 기본 모바일 이벤트 하베스트 주기가 600초가 아닌 60초임을 명시하도록 [커스텀 대시보드 및 속성 보고](/docs/data-apis/custom-data/custom-events/report-mobile-monitoring-custom-events-attributes) 및 [최대 이벤트 풀 크기 설정](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/set-max-event-pool-size)을 수정했습니다.
* 사용자 지정 조직 범위 역할이 새로운 조직 범위 기능에 대한 권한을 자동으로 받지 않는다는 점을 [사용자 관리 개념](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts)에서 명확히 했습니다.
* 동일한 이메일을 사용하는 사용자 레코드 간에 전환할 때 사용자 메뉴의 &quot;다른 사용자&quot; 옵션을 사용한다는 점을 [다중 사용자 레코드 관리](/docs/accounts/accounts-billing/account-setup/multiple-user-records)에 명확히 했습니다.
* 포함/제외 토글이 공유 변수 표시줄이 아닌 각 변수 자체의 드롭다운 메뉴에 위치한다는 점을 [대시보드 템플릿 변수](/docs/query-your-data/explore-query-data/dashboards/dashboard-template-variables)에 명확히 했습니다.
* 비용 데이터를 사용하려면 기존 Azure 통합을 활성화된 상태로 유지해야 한다는 점을 [Azure Cost Management 모니터링 통합](/docs/infrastructure/microsoft-azure-integrations/azure-integrations-list/azure-cost-management-monitoring-integration)에 명확히 했습니다.
* 노트북에 세부적인 권한 설정 기능이 없다는 오래된 참고 사항을 [노트북 공유](/docs/query-your-data/explore-query-data/notebooks/share-notebooks)에서 제거했습니다.
* [NerdGraph Teams 튜토리얼](/docs/apis/nerdgraph/examples/nerdgraph-teams-tutorial)에 `onCallMembers` 필드 커버리지를 추가했습니다.
* GCP 클라우드 모니터링 API 할당량 증가를 요청하기 위해 [GCP 통합 문제 해결](/docs/infrastructure/google-cloud-platform-integrations/troubleshooting/troubleshooting-gcp-integrations)에 단계를 추가했습니다.
* [팀 관리](/docs/service-architecture-intelligence/teams/manage-teams)에 팀원에게 온콜 역할을 할당하기 위한 지침을 추가했습니다.
* `ApplicationHost.config`을(를) 통해 IIS 호스팅 애플리케이션에 대한 [.NET 에이전트 환경 변수](/docs/apm/agents/net-agent/other-installation/understanding-net-agent-environment-variables)를 설정하는 섹션을 추가했습니다.
* 누락된 필수 `GENERATE_CONFIG` 및 `LICENSE_KEY` 파라미터를 가장 일반적인 원인으로 우선적으로 다루도록 [Windows MSI 설치가 1603 오류와 함께 실패함](/docs/infrastructure/infrastructure-troubleshooting/troubleshoot-infrastructure/windows-msi-install-fails-error-1603)을 재구성했습니다.
* 기본 자동 설치 명령에 필수 `GENERATE_CONFIG` 및 `LICENSE_KEY` 파라미터가 포함되도록 [Windows MSI 인스톨러](/docs/infrastructure/infrastructure-agent/windows-installation/windows-msi-installer)를 업데이트했습니다.
