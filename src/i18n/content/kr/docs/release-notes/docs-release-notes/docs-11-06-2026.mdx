### 새로운 문서

* 실패한 AJAX 및 fetch requests를 그룹화, 정렬 및 필터링하는 방법을 보여주기 위해 [Browser: Group request errors tab \[브라우저: 그룹 requests 오류 탭\]](/docs/triage-inbox/group-request-errors-browser/)을 추가했습니다.
* 최근 보안 권고의 영향을 받는 PHP 또는 Node.js 버전을 실행하는 APM 엔티티를 나열하도록 [Exposure check \[노출 검사\](시큐리티 RX 미리 보기)](/docs/vulnerability-management/exposure-check/)를 추가했습니다.
* 자체 자격 증명을 사용하여 뉴렐릭에 인증하는 사람이 아닌 ID를 프로비저닝하는 방법을 설명하기 위해 [시스템 ID](/docs/accounts/accounts-billing/new-relic-one-user-management/system-identities/)를 추가했습니다.
* 통합을 활성화하는 방법과 앱, 에이전트, 도구 및 데이터 커넥터에 대해 수집하는 요청, 지연시간, 세션 및 할당량 메트릭을 다루는 [Google Gemini Enterprise 모니터링 통합](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-gemini-enterprise-monitoring-integration/)을 추가했습니다.
* 로그 구문 분석, 파티션 및 난독화 룰을 쿼리하고 업데이트하기 위해 워크플로우 자동화 작업 카탈로그에 [뉴렐릭 Logs 설정 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/log-configurations/newrelic-log-configurations/)을 추가했습니다.
* eMudhra 인증 기관 침해 이후 업데이트된 신세틱스 프라이빗 로케이션 컨테이너 이미지를 가져오는 단계가 포함된 [보안 공지 NR26-12](/docs/security/new-relic-security/security-bulletins/security-bulletin-nr26-12/)를 추가했습니다.

### 주요 변경 사항

* 이전의 교차 클러스터 페이지였던 [Triage your Kubernetes fleet](/docs/kubernetes-pixie/kubernetes-integration/understand-use-data/explore-k8s/)\[Kubernetes 플릿 트리아지]를 클러스터 전반의 문제 순위를 매기는 플릿 전체 트리아지 뷰로 업데이트했습니다.
* 설치를 세 단계로 간소화하기 위해 [루비 에이전트 설치](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent/)를 업데이트했으며, 옵션을 카테고리별로 찾을 수 있도록 [루비 에이전트 설정](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration-overview/) 항목을 주제 페이지로 분할했습니다.
* 2026년 11월 5일 지원 종료에 따라 CodeStream 문서를 삭제하고, 에이전트 코드 레벨 메트릭 페이지를 다시 작성하여 CodeStream 참조를 제거했으며, 기존 링크가 계속 작동하도록 리디렉션을 추가했습니다.
* OAuth 토큰 취소 및 `NrAuditEvent`을(를) 사용한 로그인 활동 감사를 포함하여 MCP 액세스를 보호하는 방법에 대한 섹션으로 [뉴렐릭 Ground Truth](/docs/agentic-ai/mcp/overview/)를 업데이트했습니다.
* NerdGraph 또는 Terraform을 통해 카디널리티 예산을 변경하는 데 필요한 권한에 대한 내용으로 [카디널리티 관리를 위한 액세스 관리](/docs/data-apis/ingest-apis/metric-api/cardinality-access-management/)를 업데이트했습니다.
* 액세스 전제 조건 및 권한 참조 테이블을 포함하여 클라우드 비용 인텔리전스의 [권한 및 역할](/docs/cci/configure-cci/cci-permissions/)을 업데이트했습니다.
* iOS 에이전트 v7.4.8에서 제거된 파이썬 업로드 스크립트를 대체하는 `run-symbol-tool` Run Script\[스크립트 실행] 빌드 단계를 포함하도록 [dSYM 파일 업로드](/docs/mobile-monitoring/new-relic-mobile-ios/configuration/upload-dsyms-bitcode-apps/)를 업데이트했습니다.
* 샘플 오류 메시지 및 API 응답 객체를 포함하여 출력 필드에 대한 구체적인 예제 값으로 워크플로우 자동화 작업 카탈로그의 [AWS Lambda 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/lambda/aws-lambda/)을 업데이트했습니다.
* Node.js 22.23.4 런타임 및 지원되는 서드파티 모듈을 포함하도록 [모니터 런타임 관리](/docs/synthetics/synthetic-monitoring/using-monitors/manage-monitor-runtimes/)를 업데이트했습니다.

### 사소한 변경 사항

* **Errors (errors inbox) \[오류 (에러스 인박스(errors inbox))]** 를 **JavaScript errors \[자바스크립트** 오류] 로 이름을 변경하도록 [Browser \[브라우저\]: JavaScript errors \[자바스크립트 오류\] 탭](/docs/triage-inbox/browser-tab/) 을 업데이트했습니다.
* `Application` 클래스의 `onCreate()` 메서드에서 에이전트를 시작하도록 권장하기 위해 [안드로이드 에이전트 설치](/docs/mobile-monitoring/new-relic-mobile-android/install-configure/install-android-agent-gradle/)를 업데이트했습니다.
* 각 제품 영역에서 사용할 수 있는 Autopilot 스킬에 대한 링크를 추가하여 [뉴렐릭 AI 도구](/docs/agentic-ai/tools/) 및 모바일 모니터링 UI 페이지를 업데이트했습니다.
* 활성화 및 비활성화된 조건이 제한에 어떻게 계산되는지 명확히 하기 위해 [알림 규칙 및 제한](/docs/alerts/admin/rules-limits-alerts/)을 업데이트했습니다.
* 이제 뮤팅 규칙이 복합 알림에 적용된다는 점을 설명하도록 [복합 알림 소개](/docs/alerts/create-alert/create-alert-condition/compound-alerts/compound-alerts/) 및 [뮤팅 규칙](/docs/alerts/get-notified/muting-rules-suppress-notifications/)을 업데이트했습니다.
* VPC 엔드포인트를 생성할 때 **PrivateLink Ready partner services** \[PrivateLink 지원 파트너 서비스]를 선택해야 한다는 점을 명확히 하도록 [AWS PrivateLink를 통해 뉴렐릭 데이터 보내기 를 업데이트했습니다.](/docs/data-apis/custom-data/aws-privatelink/)
* [인프라 에이전트 구성 설정](/docs/infrastructure/infrastructure-agent/configuration/infrastructure-agent-configuration-settings/)에 `safe_dir_check_enabled` 설정을 추가했습니다. 인프라 에이전트 v2.0.1에서는 이 설정의 기본값이 `true`로 지정되며, 이전 기본값을 사용한 경우에는 호환성을 깨는 변경 사항입니다.
* `enable_process_metrics` 및 `metrics_process_sample_rate: -1`이(가) 프로세스 샘플링을 중지하는 방법을 명확히 하기 위해 [수집 데이터 최적화](/docs/tutorial-optimize-telemetry/data-optimize-techniques/) 및 [데이터 수집 최적화](/docs/new-relic-solutions/observability-maturity/operational-efficiency/data-governance-optimize-ingest-guide/)를 업데이트했습니다.
* Debian 12 및 13과 Windows Server 2025를 나열하고 Debian 11을 제거하도록 [인프라 에이전트를 사용하여 로그 전달](/docs/logs/forward-logs/forward-your-logs-using-infrastructure-agent/)을 업데이트했습니다.
* 14일 후에 오류가 재발하면 해결되지 않은 오류 그룹이 새로운 Slack 공지를 보낸다는 점을 설명하도록 [APM의 에러스 인박스(errors inbox)](/docs/apm/errors-inbox/errors-inbox-ui/) 및 [에러스 인박스(errors inbox) 외부 서비스](/docs/triage-inbox/error-external-services/)를 업데이트했습니다.
* 차원 메트릭 유형이 `summary`, `gauge` 또는 `count`와 같이 Azure가 반환하는 데이터에 따라 다르다는 점을 설명하도록 [Azure Monitor 통합](/docs/infrastructure/microsoft-azure-integrations/azure-integrations-list/azure-monitor/)을 업데이트했습니다.
* 수집기 트레이스를 실험할 때 `INTERNAL_TELEMETRY_TRACE_LEVEL=basic`을(를) 설정하도록 [수집기 옵저버빌리티 시작하기](/docs/opentelemetry/collector-observability/collector-observability-setup/)를 업데이트했습니다.
* .NET 에이전트 v10.54.0 이상을 요구하도록 [NRDOT를 사용한 데이터베이스 서비스 식별](/docs/opentelemetry/db360/capabilities/db-apm/)을 업데이트했습니다.
* 커넥터 이름에 하이픈(`nrlens-`) 대신 밑줄 접두사(`nrlens_`)를 사용한다는 점을 반영하여 [커넥터 설정](/docs/new-relic-lens/set-up-connectors/)을 업데이트했습니다.
* Advantage Plan 섹션과 종량제(PAYG) 전환 표를 포함하도록 [Usage plan \[사용 계획\]](/docs/licenses/license-information/usage-plans/new-relic-usage-plan/)을 업데이트했습니다.
* [보안 취약점 신고](/docs/security/security-privacy/information-security/report-security-vulnerabilities/) 문서를 업데이트하여 취약점 보고서 및 CVE 영향에 대한 섹션을 추가했습니다.
* 올바른 Dataflow 템플릿 이름으로 `PubSubToNewRelic`을(를) 사용하도록 [Google Cloud Platform에서 로그 전달](/docs/logs/forward-logs/google-cloud-platform-log-forwarding/)을 업데이트했습니다.
* 최신 검증된 라이브러리 버전으로 [Node.js 에이전트](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent/) 및 [.NET 에이전트](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements/) 호환성 및 요구 사항 페이지를 업데이트했습니다.
* Microsoft 에이전트 프레임워크 및 CrewAI를 포함하도록 [AI 모니터링에 대한 호환성 및 요구 사항](/docs/ai-monitoring/compatibility-requirements-ai-monitoring/) 및 [계측된 파이썬 패키지](/docs/apm/agents/python-agent/getting-started/instrumented-python-packages/)를 업데이트했습니다.
* Publisher Model을 Vertex AI 엔티티로 나열하도록 [Google VertexAI 모니터링 통합](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-vertexai-monitoring-integration/)을 업데이트했습니다.
