### 새로운 문서

* 뉴렐릭을 사용하여 OCI 메트릭 및 로그를 모니터링하는 것에 대한 개요를 제공하기 위해 [오라클 클라우드 인프라(OCI) 모니터링](/docs/infrastructure/oci/introduction/)을 추가했습니다.
* AWS 및 Azure에 대한 설정, 지원되는 엔티티 및 요구 사항, 문제 진단, 해결을 다루며 클라우드 인프라를 자동으로 검색하고, 리소스 간의 관계를 매핑하고, 설정 변경 사항을 추적하는 데 도움이 되는 [인프라 360](/docs/infrastructure/infrastructure-360/introduction-infrastructure-360/)을 추가했습니다.
* NRQL 표현식을 재사용 가능하고 명명된 바로 가기로 저장하고 `$` 기호와 함께 쿼리에서 참조하는 방법을 보여주기 위해 [NRQL 매크로](/docs/nrql/nrql-macros/nrql-macros-overview/)를 추가했습니다.
* 각 배포를 모니터하고 Slack 및 GitHub에서 회귀를 보고받는 방법을 보여드리기 위해 [GitHub Copilot용 뉴렐릭 변경 추적으로 배포 모니터하기](/docs/agentic-ai/autopilot/change-tracking-for-github-copilot/)를 추가했습니다.
* 각 릴리스에 대한 심볼 파일을 생성하고, 스택 추적을 심볼화하고, 심볼을 저장하는 방법을 설명하기 위해 [플러터 Dart 오류 심볼화](/docs/mobile-monitoring/new-relic-mobile-flutter/symbolicate-dart-errors/) 및 [.NET MAUI C# 오류 심볼화](/docs/mobile-monitoring/new-relic-mobile-maui-dotnet/symbolicate-csharp-errors/)를 추가했습니다.
* LaunchDarkly 데이터를 파이썬 에이전트와 연결하여 기능 플래그 및 릴리스가 애플리케이션에 미치는 영향을 관찰하는 방법을 확인할 수 있도록 [파이썬 에이전트와 함께 LaunchDarkly](/docs/apm/agents/python-agent/supported-features/launchdarkly-release-observability/)를 추가했습니다.
* [AWS Athena,](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/athena/aws-athena/) [AWS DynamoDB,](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/dynamodb/aws-dynamodb/) [Azure App Service,](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-appservice/)[GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run/) [워크플로우](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/secret/newrelic-secret/) 실행, 뉴렐릭 시크릿 및 [뉴렐릭 Synthetics](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/synthetics/newrelic-synthetics/) 에 대한 작업을 [워크플로우 자동화](/docs/workflow-automation/setup-and-configure/actions-catalog/actions-catalog/) 작업 카탈로그 에 추가했으며,[공지 상태 대기 작업을 추가했습니다.](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/notification/newrelic-notification-waitforstatus/)
* 신세틱 모니터링 퍼블릭 및 프라이빗 로케이션에 영향을 미치는 원격 코드 실행(CVE-2026-111497) 등 심각한 Node.js 취약점을 해결하기 위한 절차가 포함된 [보안 게시판 NR26-11](/docs/security/new-relic-security/security-bulletins/security-bulletin-nr26-11/)이 추가되었습니다.

### 주요 변경 사항

* 프로젝트에서 누락된 뉴렐릭 계측을 확인하는 `analyze_github_newrelic_gaps` 도구에 대한 갭 분석 섹션을 추가하여 [MCP 도구 참조](/docs/agentic-ai/mcp/tool-reference/)를 업데이트했습니다.
* Autopilot이 인시던트 기간 동안 열린 핫픽스 및 pull 요청을 표시하는 방법과 릴리스 버전을 조정하는 방법에 대한 새로운 섹션으로 [GitHub와 함께 Autopilot 사용](/docs/agentic-ai/autopilot/use-autopilot-with-github/)을 업데이트했습니다.
* 뉴렐릭이 태그 기반 소유권을 통해 팀에 자동으로 할당하는 도메인 및 유형별 엔티티 유형 목록으로 서비스 아키텍처 인텔리전스의 [엔티티 소유권 설정](/docs/service-architecture-intelligence/teams/team-ownership/)을 업데이트했습니다.
* 온호스트 에이전트 컨트롤이 OCI 레지스트리에서 에이전트 패키지를 다운로드하는 데 사용하는 도커 Hub 레지스트리 도메인으로 [네트워크 트래픽](/docs/new-relic-solutions/get-started/networks/)을 업데이트하고, 나열된 수집기 도메인을 `collector.newrelic.com`(으)로 변경했습니다.
* 이메일 대상을 선택하거나 생성하는 데 필요한 응용 인텔리전스 대상 읽기 및 수정 기능에 대한 내용을 포함하여 [NRQL 검색 예약](/docs/nrql/using-nrql/schedule-nrql-searches/)을 업데이트했습니다.
* 일관된 설명, 파라미터 테이블 및 섹션 앵커를 포함하도록 워크플로우 및 일정에 대한 [워크플로우 자동화 API](/docs/workflow-automation/workflow-automation-apis/using-workflow-automation-api/) 참조 페이지를 업데이트했습니다.
* 자바 스택 추적과 같은 여러 줄 항목을 단일 로그 레코드로 결합할 수 있도록, 인프라 에이전트 v1.53.0 이상에서 사용할 수 있는 `multilineParser` 파라미터에 대한 내용으로 [인프라 에이전트를 사용하여 로그 전달하기](/docs/logs/forward-logs/forward-your-logs-using-infrastructure-agent/)를 업데이트했습니다.
* Windows Server 2025 및 Windows Azure Guest OS Family 5 이상을 포함하여 현재 지원되는 Windows 버전을 나열하도록 [.NET 에이전트 호환성 및 요구 사항](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements/)을 업데이트했습니다.
* 지원되는 최신 타사 패키지 버전으로 [Node.js 에이전트의 호환성 및 요구 사항](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent/)을 업데이트했습니다.

### 사소한 변경 사항

* 평가 오프셋 대신 이벤트 타이머 스트리밍 방식을 사용하도록 [Azure Monitor 통합](/docs/infrastructure/microsoft-azure-integrations/azure-integrations-list/azure-monitor/) 공지 가이드를 업데이트했습니다.
* 평가 오프셋이 지연/타이머 설정으로 대체되어 더 이상 사용되지 않음을 설명하도록 [공지 이벤트 속성](/docs/alerts/create-alert/condition-details/alert-event-attributes/)을 업데이트했습니다.
* `CLUSTER_NAME`을(를) 변경하면 새로운 브로커 및 토픽 엔티티가 생성되고, APM 애플리케이션이 약 하루 동안 이전 토픽에 계속 연결된다는 점을 설명하도록 [Kafka 통합 설정](/docs/infrastructure/host-integrations/host-integrations-list/kafka/kafka-config/)을 업데이트했습니다.
* 예제 설정에 필수 `NEW_RELIC_APP_NAME` 변수를 추가하도록 [자체 Lambda 함수 계측하기](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/instrument-your-own/)를 업데이트했습니다.
* 서버리스 모드 재시도 예산 설정 및 `NEW_RELIC_EXTENSION_SYNCHRONOUS_FLUSH` 변수를 포함하여 [Lambda 확장 환경 변수](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/env-variables-lambda/)를 업데이트했습니다.
* 설정해야 하는 환경 변수를 나열하도록 [Lambda에 대한 자바 에이전트 접근 방식](/docs/apm/agents/java-agent/getting-started/java-agent-approaches-lambda/)을 업데이트했습니다.
* Autopilot이 최대 1,000자의 메시지를 허용한다는 점을 설명하도록 [Autopilot을 Slack에 연결](/docs/agentic-ai/autopilot/connect-to-slack/)을 업데이트했습니다.
* 브라우저 내 심볼리케이션이 처리된 예외에만 적용된다는 점을 설명하도록 [플러터 애플리케이션 모니터하기](/docs/mobile-monitoring/new-relic-mobile-flutter/monitor-your-flutter-application/) 및 [.NET MAUI 애플리케이션 모니터하기](/docs/mobile-monitoring/new-relic-mobile-maui-dotnet/monitor-your-net-maui-application/)를 업데이트했습니다.
* &quot;Default account key&quot;를 &quot;Original account key&quot;로 이름을 변경하도록 [뉴렐릭 API 키](/docs/apis/intro-apis/new-relic-api-keys/)를 업데이트했습니다.
* &quot;eAPM&quot;을 &quot;eBPF 옵저버빌리티&quot;로 이름을 변경하도록 [eBPF 옵저버빌리티 설치](/docs/ebpf/linux-installation/) 및 [가격 책정 및 청구](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/new-relic-one-pricing-billing/) 문서를 업데이트했습니다.
* 더 높은 소스 맵 크기 제한을 요청하기 위해 뉴렐릭 지원팀으로 안내하도록 [리액트 네이티브 JavaScript 오류 보고](/docs/mobile-monitoring/new-relic-monitoring-react-native/react-native-agent-js-error-reporting/)를 업데이트했습니다.
