### 새로운 문서

* 조사 중 변경 추적 배포 이면의 pull 요청을 검색하는 공개 프리뷰 기능인 새로운 Autopilot GitHub 통합을 [연결](/docs/agentic-ai/autopilot/connect-to-github), [사용](/docs/agentic-ai/autopilot/use-autopilot-with-github) 및 [문제 해결](/docs/agentic-ai/autopilot/troubleshoot-github-connection) 하는 방법을 추가했습니다.
* Jira Cloud 이슈에 대한 생성, 업데이트, 검색 및 전환 작업을 다루는 [Jira 이슈 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/jira/jira-issue)을 워크플로우 자동화 작업 카탈로그에 추가했습니다.
* Ansible Automation 플랫폼 작업 템플릿을 시작하고 상태를 확인하기 위한 [Ansible 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job-launch)을 워크플로우 자동화 작업 카탈로그에 추가했습니다.
* 워크플로우에서 Autopilot 조사를 실행하기 위한 전용 작업 카탈로그 참조를 제공하기 위해 [Autopilot 실행 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/autopilot/newrelic-autopilot)을 추가했습니다.
* 공지에서 Autopilot 근본 원인 분석을 트리거하고 그 결과를 Slack에 게시하는 방법을 보여주기 위해 [Autopilot 및 Slack을 사용한 공지 RCA](/docs/workflow-automation/workflow-examples/integrations/autopilot-slack-rca)를 추가했습니다.
* 쿼리당 비용과 같은 단일 가치 단위 제공 비용을 측정하고 벤치마크 대비 효율성을 추적하는 방법을 설명하기 위해 클라우드 비용 인텔리전스에 [단위 경제학](/docs/cci/financial-intelligence/unit-economics)을 추가했습니다.
* 교차 계정 대상이 뉴렐릭 UI의 어디에 표시되고 워크플로우에서 어떻게 사용하는지 보여주기 위해 [UI에서 교차 계정 대상 사용](/docs/apis/nerdgraph/examples/cross-account-destinations/use-cross-account-destinations-in-the-ui)을 추가했습니다.

### 주요 변경 사항

* 새로운 `safe_bin_dir`, `agent_temp_dir` 및 로깅 디렉터리 설정으로 [인프라 에이전트 설정](/docs/infrastructure/infrastructure-agent/configuration/infrastructure-agent-configuration-settings)을 업데이트했습니다.
* APM 데이터를 쿼리 성능 모니터링과 상호 연관시키기 위해 에이전트가 계측된 SQL 문에 서비스 엔티티 GUID 주석을 추가할 수 있게 해주는 새로운 `sqlMetadataCommentsEnabled` 옵션으로 [.NET 에이전트 설정](/docs/apm/agents/net-agent/configuration/net-agent-configuration)을 업데이트했습니다.
* 퍼블릭 프리뷰 콜아웃을 제거하고 조직 수준 역할(풀 액세스, 생성자) 및 노트북 수준 역할(소유자, 편집자, 읽기 권한자)을 포함한 새로운 세분화된 액세스 모델을 설명하도록 [노트북 소개](/docs/query-your-data/explore-query-data/notebooks/introduction-notebooks)를 재구성했습니다.
* 기본 최적화 엔진의 적정 규모 권장 사항을 Azure 리소스로 확장하도록 [클라우드 비용 인텔리전스: 권장 사항](/docs/cci/financial-intelligence/cci-recommendations)을 업데이트하고, 텔레메트리 커버리지 전제 조건 및 권장 사항 새로 고침 주기에 대한 지침을 추가했습니다.
* 가장 큰 시리즈를 기준으로 시리즈 순위를 매기는 새롭고 단순화된 바 차트 섹션과 게이지 차트를 위한 중립 임계값 옵션을 [차트 유형](/docs/query-your-data/explore-query-data/use-charts/chart-types)에 추가했습니다.
* 상태 지연 및 공지 조건의 자동 연결 해제 및 재연결을 포함하여 설정 방법 전환의 영향에 대한 지침으로 [워크로드 상태 설정](/docs/new-relic-solutions/new-relic-one/workloads/workload-status-configuration)을 업데이트했습니다.

### 사소한 변경 사항

* Percona가 Windows 바이너리 게시를 중단했기 때문에 번들로 제공되는 익스포터를 현재 버전으로 동결했다는 점을 언급하며, [MongoDB 통합 설치 가이드](/install/mongodb/)에 Windows 지원 제한 콜아웃을 추가했습니다.
* JBoss의 로그 관리자로 인해 발생하는 시작 실패에 대한 새로운 문제 진단, 해결 섹션으로 [JBoss 및 WildFly의 클래스 로딩 문제](/docs/apm/agents/java-agent/troubleshooting/classloading-issues-from-jboss-and-wildfly)를 업데이트했습니다.
* 미국 및 EU 데이터센터를 위한 추가 듀얼스택 데이터 수집 IP 블록으로 [네트워크](/docs/new-relic-solutions/get-started/networks)를 업데이트했습니다.
* 새로운 gem 계측에 기여하는 방법을 명확히 하고 `extends_newrelic_rpm`이(가) 이제 보관됨을 알리기 위해 루비 에이전트용 [타사 계측](/docs/apm/agents/ruby-agent/api-guides/third-party-instrumentation)을 업데이트했습니다.
* 새로운 FedRAMP Class C(Moderate) 인증 상태를 반영하도록 [FedRAMP](/docs/security/security-privacy/compliance/certificates-standards-regulations/fedramp)를 업데이트했습니다.
* FIPS 140-2에서 FIPS 140-3 호환 암호화 표준으로의 전환을 반영하도록 [데이터 암호화](/docs/security/security-privacy/compliance/data-encryption)를 업데이트했습니다.
* 새로운 `idempotencyKey` 입력으로 [워크플로우 실행 시작](/docs/workflow-automation/workflow-automation-apis/start-workflow-run)을 업데이트하고, [작업 카탈로그](/docs/workflow-automation/setup-and-configure/actions-catalog/actions-catalog)의 Azure 및 뉴렐릭 공지 작업 전반에서 `idempotencyKey`에 대한 UUID 형식 유효성 검사를 명확히 했습니다.
* 그룹 관리 서비스 계정(gMSA) 지원을 포함하여 Windows 서비스 계정 요구 사항을 문서화하기 위해 [인프라 에이전트 보안](/docs/infrastructure/infrastructure-agent/infrastructure-security)을 업데이트했습니다.
* 미국 리전이 기본값임을 명확히 하기 위해 [데이터센터 선택](/docs/accounts/accounts-billing/account-setup/choose-your-data-center)을 업데이트했습니다.
* 현재 Azure Marketplace 목록 URL로 [Azure Native 뉴렐릭 서비스](/docs/infrastructure/microsoft-azure-integrations/get-started/azure-native)를 업데이트하고 오래된 HIPAA 가용성 참고 사항을 제거했습니다.
* 지원되는 Kubernetes 버전 1.31-1.35를 반영하도록 [Kubernetes 통합 호환성 및 요구 사항](/docs/kubernetes-pixie/kubernetes-integration/get-started/kubernetes-integration-compatibility-requirements)을 업데이트했습니다.
* 기본 Apdex 점수를 0.4초로 수정하기 위해 [NRQL 구문, 절 및 함수](/docs/nrql/nrql-syntax-clauses-functions)를 수정했습니다.
* [뉴렐릭 Lens용 커넥터 설정](/docs/new-relic-lens/set-up-connectors)에 Databricks(Azure) 커넥터 옵션을 추가했습니다.
