### 새로운 문서

* EAS Build로 빌드할 때 자동 소스 맵, dSYM 및 매핑 파일 업로드에 대한 지침을 제공하기 위해 [EAS Build용 리액트 네이티브 에이전트 구성](/docs/mobile-monitoring/new-relic-monitoring-react-native/configure-eas-build-react-native)을 추가했습니다.
* 인스턴스, 원하는 용량, 인스턴스 새로 고침 및 예약된 작업 관리를 위한 작업을 다루는 [AWS Auto Scaling 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/aws-autoscaling)을 워크플로우 자동화 작업 카탈로그에 추가했습니다.

### 주요 변경 사항

* 일반 공급을 위해 [뉴렐릭 Ground Truth](/docs/agentic-ai/mcp/overview) (이전의 뉴렐릭 AI MCP)로 이름을 변경하고 설정을 OAuth 전용으로 변경했습니다.
* 일반 공급을 위해 [뉴렐릭 Lens 개요](/docs/new-relic-lens/overview), [커넥터 설정](/docs/new-relic-lens/set-up-connectors), [Lens로 데이터 쿼리](/docs/new-relic-lens/query-data) 및 [구체화된 뷰](/docs/new-relic-lens/materialized-views)를 업데이트했습니다.
* 새로운 값 제공자 시스템으로 [설정 관리](/docs/new-relic-control/agent-control/configuration)를 업데이트하고, 수정된 설정 이름과 새로운 NRDiag 문제 진단, 해결 섹션으로 [일반적인 문제 해결](/docs/new-relic-control/agent-control/troubleshooting)을 업데이트했습니다.
* [작업 카탈로그](/docs/workflow-automation/setup-and-configure/actions-catalog/actions-catalog)의 AWS 작업 페이지를 일관된 형식, 새로운 AWS Bedrock 작업 및 3개의 새로운 Lambda 작업으로 업데이트했습니다.
* 워크플로우 공지를 통해 대시보드 스냅샷을 전송하기 위한 `DASHBOARD_SNAPSHOT` 첨부 파일 유형을 추가하도록 [뉴렐릭 공지 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/newrelic-notification)을 재구성했습니다.
* 손상된 응답 구문 분석 선택기를 수정하고 [Autopilot 및 Slack을 사용한 공지 RCA](/docs/workflow-automation/workflow-examples/integrations/autopilot-slack-rca)에 문제 진단, 해결 섹션을 추가했습니다.
* [Maps 이해 및 사용](/docs/service-architecture-intelligence/maps/advanced-maps)에 범례 컨트롤과 &quot;관계 시각화&quot; 섹션을 추가하고, 노드 및 아이콘 참조 테이블을 타일 그리드로 변환했습니다.
* [.NET 에이전트 설정](/docs/apm/agents/net-agent/configuration/net-agent-configuration)에 Kafka 메트릭 설정 섹션을 추가했습니다.
* 사용자가 더 이상 사용되지 않는 REST API v2 및 v0 배포 엔드포인트에서 마이그레이션할 수 있도록 [뉴렐릭에서 변경 사항을 보고 분석하는 방법](/docs/change-tracking/view-analyze-data)에 전체 환경의 변경 사항 추적에 대한 섹션을 추가하고 [NerdGraph를 사용하여 변경 사항 추적](/docs/change-tracking/config/nerdgraph)을 재구성했습니다.
* [Google 컴퓨트 엔진 모니터링 통합](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-compute-engine-monitoring-integration)에 새로운 주요 메트릭 테이블과 함께 Service Attachment 및 Private Service Connect 엔드포인트 엔티티 유형을 다시 도입했습니다.

### 사소한 변경 사항

* 자동 APM-데이터베이스 엔티티 연결이 실패할 수 있는 경우를 명확히 설명하는 콜아웃을 [NRDOT를 사용한 데이터베이스 서비스 식별](/docs/opentelemetry/database/capabilities/db-apm)에 추가했습니다.
* yum 기반 설치 명령이 `newrelic-infra.repo`을(를) 덮어쓴다는 경고를 [Linux 호스트용 뉴렐릭 eBPF 에이전트 설치](/docs/ebpf/linux-installation)에 추가했습니다.
* .NET 10 지원을 추가하고 인프로세스 모델 버전 요구 사항을 수정하기 위해 [Azure Functions 계측을 위한 호환성 및 요구 사항](/docs/serverless-function-monitoring/azure-function-monitoring/compatibility-requirement-azure-monitoring)을 업데이트했습니다.
* 퍼블릭 인터넷을 통한 내보내기 시 gRPC보다 OTLP/HTTP를 권장하도록 [뉴렐릭 OTLP 엔드포인트](/docs/opentelemetry/best-practices/opentelemetry-otlp)를 업데이트했습니다.
* [대시보드 관리](/docs/query-your-data/explore-query-data/dashboards/manage-your-dashboard)에 TV 모드용 &quot;주기 간격&quot; 드롭다운 메뉴 옵션을 추가했습니다.
* 오래된 호환성 표를 제거하기 위해 [워크로드 상태 설정](/docs/new-relic-solutions/new-relic-one/workloads/workload-status-configuration)을 업데이트했습니다.
* [AWS Lambda 모니터링에 대한 호환성 및 요구 사항](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/compatibility-requirement-lambda-monitoring)에 `ruby4.0` 런타임 지원을 추가하고 [뉴렐릭에 Lambda 모니터링 설치 및 구성](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/configure-serverless-aws-monitoring)의 끊어진 링크를 수정했습니다.
* [Node.js 에이전트의 호환성 및 요구 사항](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent)에서 지원되는 패키지 버전 번호를 업데이트했습니다.
* [뉴렐릭 MCP 도구 참조](/docs/agentic-ai/mcp/tool-reference)에 어떤 도구가 CCU와 aCCU로 측정되는지 명확히 설명하는 청구 관련 콜아웃을 추가했습니다.
* [뉴렐릭 MCP 설정](/docs/agentic-ai/mcp/setup)에 Codex CLI 설정 지침을 추가했습니다.
* 거부 목록 변경 사항이 NPM으로 설치된 브라우저 에이전트에 자동으로 적용되지 않는다는 점을 명확히 하기 위해 [AjaxRequest 이벤트 설정](/docs/browser/new-relic-browser/configuration/configure-ajax-request-events)에 콜아웃을 추가했습니다.
* [.NET 에이전트 호환성 및 요구 사항](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements)에서 타사 라이브러리 호환성 버전을 업데이트했습니다.
* [라이브 아카이브를 사용한 장기 로그 스토리지](/docs/logs/get-started/live-archives)에서 라이브 아카이브 파티션에 대한 오래된 팁을 제거했습니다.
* [루비 에이전트 설정](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration)에 `browser_monitoring.version` 설정 옵션과 새로운 &quot;에러스 인박스(errors inbox) 설정&quot; 섹션을 추가했습니다.

* [HIPAA](/docs/security/security-privacy/compliance/certificates-standards-regulations/hipaa) 및 [FedRAMP](/docs/security/security-privacy/compliance/certificates-standards-regulations/fedramp)에서 규정 준수 날짜를 업데이트하고 오래된 제외 행을 제거했습니다.

### 새로워진 사항

* [뉴렐릭 Ground Truth가 이제 정식 출시되었습니다](/whats-new/2026/09/whats-new-09-15-ground-truth): Ground Truth는 MCP를 통해 AI 도구 및 에이전트에 뉴렐릭 운영 인텔리전스에 대한 관리되는 액세스를 제공하여, 기업이 요구하는 제어 기능을 통해 더 풍부한 운영 컨텍스트에서 추론할 수 있도록 지원합니다.
* [뉴렐릭 Lens 정식 출시](/whats-new/2026/09/whats-new-09-15-nr-lens-ga): Lens를 사용하면 추가 데이터 수집 비용을 지불하지 않고도 SQL을 사용하여 텔레메트리와 함께 Snowflake, Iceberg 및 Google Sheets와 같은 외부 데이터 소스를 연결하고 쿼리할 수 있습니다.
