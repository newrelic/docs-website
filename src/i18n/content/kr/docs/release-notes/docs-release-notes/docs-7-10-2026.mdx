### 새로운 문서

* 호스트, Kubernetes, 메트릭 및 문제 진단, 해결 설정을 포함하여 OpenTelemetry로 IBM MQ를 모니터링하기 위한 [IBM MQ OpenTelemetry 통합](/docs/opentelemetry/integrations/ibm-mq/overview) 을 추가했습니다.
* 도커, 호스트 및 Kubernetes 설정을 포함하여 OpenTelemetry로 레디스를 모니터링하기 위한 [레디스 OpenTelemetry 통합](/docs/opentelemetry/integrations/redis/overview) 을 추가했습니다.
* 자체 호스팅 및 Kubernetes 설정을 포함하여 OpenTelemetry로 HAProxy를 모니터링하기 위한 [HAProxy OpenTelemetry 통합](/docs/opentelemetry/integrations/haproxy/overview) 을 추가했습니다.
* Azure 가상 네트워크 흐름 로그 데이터를 전달하고 쿼리하기 위해 [Azure VNet 흐름 로그 모니터링](/docs/network-performance-monitoring/setup-performance-monitoring/cloud-flow-logs/azure-vnet-flow-log-monitoring) 을 추가했습니다.

### 주요 변경 사항

* 이제 [교차 계정 대상](/docs/apis/nerdgraph/examples/cross-account-destinations/overview) 을 정식으로 사용할 수 있습니다.

### 사소한 변경 사항

* 지원되는 블록 유형의 표와 함께 Slack Block Kit 메시지를 전송하기 위한 `sendSlack` [워크플로우 자동화 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/newrelic-notification) 에 `blocks` 파라미터 문서를 추가했습니다.
* 최신 자동화된 호환성 보고서로 [Node.js 에이전트 호환성 요구 사항](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent) 을 업데이트했습니다.
* 최신 버전 대신 특정 버전을 설치하는 지침이 포함된 .NET 에이전트용 [도커 Linux 설치](/install/dotnet/?deployment=linux&docker=yesDocker) 및 [도커 Windows 설치](/install/dotnet/?deployment=windowsInstall&docker=yesDocker) 예제를 업데이트했습니다.
* [Intelligent 워크로드](/docs/new-relic-solutions/new-relic-one/workloads/create-intelligent-workload) 멤버십 업데이트 간격을 5분에서 10분으로 수정했으며, 퍼블릭 프리뷰 기간 동안 변경될 수 있습니다.
* [NRQL 쿼리 시간 범위](/docs/nrql/using-nrql/query-time-range) 에서 원시 메트릭 데이터 포인트 포함 여부는 데이터 포인트의 종료 시간이 아닌 시작 시간에 따라 달라진다는 점을 명확히 했습니다.
* 표준 워크로드와 지능형 워크로드에 사용할 수 있는 상태 메서드를 명확히 하기 위해 [워크로드 상태 설정](/docs/new-relic-solutions/new-relic-one/workloads/workload-status-configuration) 을 업데이트했습니다.
* 인증 도메인 또는 조직에서 사용자를 제거하는 방법에 대한 지침을 [다중 사용자 레코드](/docs/accounts/accounts-billing/account-setup/multiple-user-records)에 추가했습니다.
* .NET Core 및 .NET 프레임워크 모두에 대한 IBM DB2 지원 및 제한 사항을 명확히 하기 위해 [.NET 에이전트 호환성 요구 사항](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements) 을 업데이트했습니다.
* Fluent Bit 5.0.6을 통해 [인프라 에이전트를 통한 로그 포워딩](/docs/logs/forward-logs/forward-your-logs-using-infrastructure-agent)에 Ubuntu 26.04(Resolute)에 대한 지원이 추가되었습니다.
