### 새로운 문서

* Grafana 대시보드를 뉴렐릭 대시보드로 변환하기 위한 [Grafana 대시보드 변환기 REST API](/docs/infrastructure/prometheus-integrations/view-query-data/grafana-to-nr-dashboard-translation-rest-api/) 를 추가했습니다.
* 자바 에이전트를 사용한 서버리스 모니터링 옵션을 문서화하는 [AWS Lambda용 자바 에이전트 접근 방식](/docs/apm/agents/java-agent/getting-started/java-agent-approaches-lambda/) 을 추가했습니다.

### 주요 변경 사항

* 안드로이드, iOS, 브라우저 및 Roku를 위한 새로운 플랫폼별 설치 가이드와 업데이트된 API 참조 문서 및 향상된 탐색 기능을 포함하여 재구성된 [스트리밍 비디오 및 광고 문서](/docs/streaming-video-&-ads/introduction-to-streaming-video-&-ads/) 입니다.
* [데이터 수집 예산 문서](/docs/data-apis/manage-data/data-ingest-budgets/overview/) 를 멀티 테넌트 지원을 포함하여 계정 수준 및 조직 수준 예산을 위한 별도의 페이지로 재구성했습니다.

### 사소한 변경 사항

* UI 변경 사항에 맞게 수정된 메트릭 이름으로 [Kubernetes 클러스터 탐색기 문서](/docs/kubernetes-pixie/kubernetes-integration/understand-use-data/kubernetes-cross-cluster/) 를 업데이트했습니다.
* 재구성된 SSO/SAML 이메일 변경 지침을 적절한 하위 섹션으로 포함하도록 [계정 이메일 설정](/docs/accounts/accounts/account-maintenance/account-email-settings/) 을 업데이트했습니다.
* 단일 배포판 모델로 문서를 단순화하도록 [NRDOT 수집기 문서](/docs/opentelemetry/nrdot/nrdot-collector/) 를 업데이트했습니다.
* RBAC 권한 정보를 포함한 최신 [워크플로우 자동화 소개입니다](/docs/workflow-automation/introduction-to-workflow/).
* 업데이트된 패키지 버전으로 [Node.js 에이전트 호환성 요구 사항](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent/) 을 업데이트했습니다.
* 최신 검증된 호환 버전으로 [자바 에이전트 호환성 요구 사항](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent/) 을 업데이트했습니다.
* 추가 Grafana 변환 지원 정보로 [지원되는 PromQL 기능](/docs/infrastructure/prometheus-integrations/view-query-data/supported-promql-features/) 을 업데이트했습니다.
* [에러스 인박스(errors inbox) 브라우저 탭](/docs/triage-inbox/browser-tab/)에 `SecurityPolicyViolation` 이벤트 처리 섹션을 업데이트했습니다.
* ANSI SQL에서 `FROM` 절을 `SELECT` 앞에 사용할 수 없다는 점을 명확히 하기 위해 [뉴렐릭 렌즈 쿼리 데이터](/docs/new-relic-lens/query-data/) 를 업데이트했습니다.
* 컴퓨트 풀(Flink) 데이터 테이블로 [Confluent 클라우드 통합](/docs/message-queues-streaming/installation/confluent-cloud-integration/) 을 업데이트했습니다.
* 데이터베이스 설정 업데이트를 반영하여 [NRDOT MSSQL](/docs/opentelemetry/database/otel-mssql/) 및 [Oracle DB](/docs/opentelemetry/database/otel-oracledb/) 문서를 업데이트했습니다.
* 키 순환 업데이트로 [PHP 에이전트 설치 RPM 키 순환](/docs/apm/agents/php-agent/installation/php-agent-installation-rpm-key-rotation/) 을 업데이트했습니다.
* 추가 설치 안내와 함께 [AWS Linux/RedHat/CentOS용 PHP 에이전트 설치](/docs/apm/agents/php-agent/installation/php-agent-installation-aws-linux-redhat-centos/) 를 업데이트했습니다.
* 글머리 기호 형식 수정 사항을 반영하여 [Kubernetes 통합 호환성 요구 사항](/docs/kubernetes-pixie/kubernetes-integration/get-started/kubernetes-integration-compatibility-requirements/) 을 업데이트했습니다.
* QoE 인덱스 이미지 및 콜아웃으로 [스트리밍 비디오 및 광고 애플리케이션 보기](/docs/streaming-video-&-ads/view-data-in-newrelic/streaming-video-&-ads-all-platform-view/application/) 가 업데이트되었습니다.
