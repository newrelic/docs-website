## 새로운 문서

* 대시보드 마이그레이션 워크플로우를 지원하기 위해 [Grafana 대시보드 번역 API](/docs/infrastructure/prometheus-integrations/view-query-data/grafana) 기능을 추가했습니다.
* **뉴렐릭 일본 데이터 리전** 을 출시하고 모든 제품에 걸쳐 새로운 리전과 그 기능을 반영하도록 다양한 문서 페이지를 업데이트했습니다.

### 주요 변경 사항

* 플랫폼 전반에 걸쳐 업데이트된 용어 및 참조를 반영하여 모든 문서에서 **SRE 에이전트를 뉴렐릭 Autopilot으로 리브랜딩** 했습니다.
* 더 나은 정확성을 위해 잘못된 NRQL 함수를 제거하고 쿼리 패턴을 수정하도록 [취약점 관리](/docs/vulnerability-management/advanced/query-examples) 문서를 업데이트했습니다.
* 기능이 핵심 플랫폼 기능에 통합됨에 따라 **취약점 관리 애드온 문서를 제거했습니다**.
* 사용 가능한 모든 템플릿에 대한 포괄적인 커버리지와 개선된 조직 구조를 포함하여 [스코어카드 템플릿 라이브러리](/docs/service-architecture-intelligence/scorecards/templates) 를 업데이트했습니다.
* 최신 지원 버전을 포함하고 다양한 Node.js 릴리스와의 호환성을 명확히 하기 위해 Node.js [호환성 매트릭스](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent) 를 업데이트했습니다.
* HIPAA 규정을 준수하도록 [뉴렐릭 MCP 서버](/docs/agentic-ai/mcp/overview) 문서를 업데이트했습니다.

### 사소한 변경 사항

* 워크플로우에서 직접 AKS 클러스터를 관리할 수 있도록 [AKS 에이전트 풀 확장](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-aks-scalepool) 작업을 추가했습니다.
* [Terraform 통합 설정](/docs/infrastructure/amazon-integrations/aws-integration-for-metrics/terraform)을 업데이트했습니다.
* 업데이트된 설정 링크와 개선된 설정 안내로 [Microsoft SQL Server 통합](/docs/opentelemetry/database/mssql/introduction) 을 강화했습니다.
* 정확성과 명확성을 높이기 위해 [HAProxy 통합 엔드포인트](/docs/infrastructure/host-integrations/host-integrations-list/haproxy-monitoring-integration) 문서를 수정했습니다.
* 안전한 모니터링을 위한 상세한 설정 지침 및 설정 옵션과 함께 [프라이빗 로케이션에 대한 포괄적인 사용자 지정 인증서 지원](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-configuration/#custom-ca-certificates) 을 추가했습니다.
* 프로그램 세부 정보를 포함하여 [학생 프로그램 문서](/docs/accounts/accounts-billing/account-setup/student-program) 를 업데이트했습니다.
