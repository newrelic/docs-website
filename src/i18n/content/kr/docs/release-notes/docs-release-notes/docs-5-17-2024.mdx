### 새로운 문서

* 당사의 [NVIDIA Management 라이브러리(NVML) 통합](/docs/infrastructure/host-integrations/host-integrations-list/nvml-integration)에 대한 새 문서에서는 인프라 에이전트와 NRI-Flex를 사용하여 GPU 사용량 및 성능 메트릭을 모니터링하는 방법을 설명합니다.

* 취약점 관리가 너무 잘 작동하는 경우, 최근 업데이트를 통해 관심 없는 [취약점을 무시](/docs/vulnerability-management/change-vulnerability-status) 할 수 있습니다.

* 확실한 시작점을 제공하기 위해 새로운 [APM: OpenTelemetry로 앱 및 서비스 모니터](/docs/more-integrations/open-source-telemetry-integrations/opentelemetry/get-started/apm-monitoring/opentelemetry-apm-intro)를 포함하여 OpenTelemetry 문서 카테고리를 대대적으로 개편했습니다. 기타 변경 사항:

  * **OpenTelemetry &gt; Get started** 카테고리를 재구성하여 하위 카테고리에 일관된 **개요** 문서를 추가했습니다.
  * 문서 내용을 명확히 하기 위해 문서 제목을 변경했습니다.
  * 관련 정보를 더 쉽게 찾을 수 있도록 관련 문서를 통합했습니다.

* 로그를 파싱하기 위해 정규 표현식이나 Grok 패턴을 작성하지 않으려는 사용자에게 [쿼리 시간 파싱](/docs/logs/ui-data/query-time-parsing)은 UI에서 직접 로그를 파싱할 수 있는 강력한 도구입니다. (이 문서에는 훌륭한 스크린샷이 많이 포함되어 있습니다.)

### 주요 변경 사항

* 설치를 더 쉽게 하고 문서가 정확하고 최신 상태로 유지되도록 온-호스트 통합 문서를 계속해서 다시 작성했습니다. 이번 주: [포트](/docs/infrastructure/host-integrations/host-integrations-list/port-monitoring-integration) 및 [Unix](/docs/infrastructure/host-integrations/host-integrations-list/unix-monitoring-integration) 모니터링 통합.
* 단일 및 다중 계정 조직을 위한 [데이터 보존 규칙](/docs/data-apis/manage-data/manage-data-retention)을 관리하고 사용하는 방법을 명확히 했습니다.
* 버전 추적 정보를 [오류 추적](/docs/triage-inbox/errors-inbox)에서 [버전 추적](/docs/triage-inbox/version-tracking)으로 이동하고 그 과정에서 몇 가지 편의성을 개선했습니다.
* 2024년 10월에 컨테이너화된 프라이빗 미니언(CPM) 및 구형 신세틱스 런타임 버전을 수명 종료(EOL)합니다. 6월에는 이러한 구형 런타임을 사용하는 새로운 모니터의 생성을 차단합니다. 이 [EOL 공지](/docs/apis/synthetics-rest-api/monitor-examples/manage-synthetics-monitors-rest-api/#before-you-start)와 같이 이와 관련된 참고 사항을 추가했습니다.

### 사소한 변경 사항

* [NerdGraph 워크플로우 튜토리얼](/docs/apis/nerdgraph/examples/nerdgraph-api-workflows/#update-workflow)에 워크플로우 이름과 두 개의 채널을 추가하는 GraphQL 예제를 추가했습니다.
* [사용자 지정 로그 구문 분석 규칙을 생성](/docs/logs/ui-data/parsing/#custom-parsing) 할 때 형식이 지정되지 않은 로그를 구문 분석 UI에 붙여넣어야 한다는 참고 사항을 추가했습니다.
* 브라우저 사용자 [권한](/docs/accounts/accounts-billing/new-relic-one-user-management/user-permissions/#browser) **목록에** 세션 리플레이 보기 를 추가했습니다.
* 잘못된 [Sonarqube 구성](/docs/infrastructure/host-integrations/host-integrations-list/sonarqube-monitoring-integration) 파일 예제를 수정했습니다.
* `LlmChatCompletionMessage`, `LlmChatCompletionSummary` 및 `LlmEmbedding` 이벤트 유형에 대한 속성을 데이터 딕셔너리에 추가했습니다.
* [스타일 가이드](/docs/style-guide/capitalization/product-capability-feature-usage)에 세션 리플레이 대문자 표기 지침을 추가했습니다.
* 소개 단락에 [로그 구문 분석](/docs/logs/ui-data/parsing)의 더 명확한 정의를 추가했습니다.
* [FedRAMP 호환 엔드포인트](/docs/security/security-privacy/compliance/fedramp-compliant-endpoints) 목록에 `gov-aws-api.newrelic.com`을(를) 추가했습니다.
* [Azure 클라이언트 시크릿 토큰을 순환](/docs/apis/nerdgraph/examples/nerdgraph-cloud-integrations-api-tutorial/#rotate-azure-token)하는 방법을 보여주는 NerdGraph 뮤테이션 예제를 추가했습니다.
* 고객 피드백을 반영하여, UI의 **Numeric,** ****Date, **Duration** 및 [](/docs/query-your-data/explore-query-data/use-charts/use-your-charts)**Time to Now** 차트 옵션을 명확히 하도록 차트 사용 을 업데이트했습니다.
* UI의 [에러스 인박스(errors inbox) OpenTelemetry](/docs/more-integrations/open-source-telemetry-integrations/opentelemetry/view-your-data/opentelemetry-errors-inbox-page) 페이지에 새로운 `http.response.status_code` 그룹 메시지 값이 있습니다.
* 이제 당사의 [알림 공지 메시지 템플릿](/docs/alerts-applied-intelligence/notifications/message-templates/#escape)은 JSON을 손상시키는 문자 등을 피할 수 있도록 이스케이프 문자를 지원합니다.
* 코드 블록이 훨씬 더 좋아진 것을 확인하셨을 것입니다. 더 보기 좋고 읽기 쉽도록 언어별 구문 강조 표시를 적용하여 많은 코드 블록을 업데이트했습니다.
* 파이썬 APM 에이전트 [data\_source\_generator](/docs/apm/agents/python-agent/python-agent-api/datasourcegenerator-python-agent-api/#example) 및 [register\_data\_source](/docs/apm/agents/python-agent/python-agent-api/registerdatasource-python-agent-api/#examples) API 문서의 코드 예제를 업데이트했습니다.
* [Azure 로그 포워딩 문제 진단, 해결](/docs/logs/forward-logs/azure-log-forwarding/#troubleshoot) 도움말을 확장했습니다.
