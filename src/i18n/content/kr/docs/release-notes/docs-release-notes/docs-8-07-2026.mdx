### 새로운 문서

* GCP 통합을 연결하는 권장 기본 방법으로 [워크로드 Identity Federation](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation) 을 도입했습니다.

### 주요 변경 사항

* APM, 인프라, 브라우저 및 모바일 에이전트용 [FedRAMP 호환 엔드포인트](/docs/security/security-privacy/compliance/fedramp-compliant-endpoints) 를 추가했습니다.
* 두 가지 새로운 Fargate 전달 전용 모드인 `NRIA_IS_FORWARD_ONLY` 및 `NRIA_IS_SECURE_FORWARD_ONLY`을(를) 사용하여 [ECS 통합 설치](/docs/infrastructure/elastic-container-service-integration/install-ecs-integration) 를 업데이트했습니다.
* `transaction_tracer.cap_segment_artifacts`, Puma 계측 설정 및 Google Cloud Run 호스트명 옵션을 포함하여 루비 에이전트 10.7.0의 새로운 옵션으로 [루비 에이전트 설정](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration) 을 업데이트했습니다.

### 사소한 변경 사항

* 권한 정의 섹션을 복원하여 [사용자 권한](/docs/accounts/accounts-billing/new-relic-one-user-management/user-permissions) 을 수정했습니다.
* “응용 인텔리전스”를 “알림”으로 대체하도록 [사용자 유형](/docs/accounts/accounts-billing/new-relic-one-user-management/user-type) 을 업데이트했습니다.
* 워크플로우를 실행하는 데 필요한 `account.create.own_api_keys` 권한으로 [워크플로우 자동화](/docs/workflow-automation/introduction-to-workflow) 문서를 업데이트했습니다.
* 환경 그룹화가 채워지는 방식을 명확히 하기 위해 [애플리케이션 카탈로그](/docs/service-architecture-intelligence/catalogs/applications-catalog) 및 [인프라 카탈로그](/docs/service-architecture-intelligence/catalogs/infrastructure-catalog) 를 업데이트했습니다.
* Cloud Resource Manager API 설명을 수정하기 위해 [통합 및 사용자 지정 역할](/docs/infrastructure/google-cloud-platform-integrations/get-started/integrations-custom-roles) 을 수정했습니다.
* 정확한 GB당 수집 요금 대신 정성적 비용 비교를 포함하도록 [클라우드 비용 인텔리전스: 가격 책정](/docs/cci/cci-pricing) 을 업데이트했습니다.
* 더 간단한 바 차트 지침을 복원하도록 [차트 유형](/docs/query-your-data/explore-query-data/use-charts/chart-types) 을 업데이트했습니다.
* 기본적으로 활성화된 이벤트 지속성을 반영하도록 [모바일 모니터링 설정 구성](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/configure-settings) 을 업데이트했습니다.
* 더 이상 특정 네임스페이스가 필요하지 않으므로 [Kubernetes APM 자동 연결](/docs/kubernetes-pixie/kubernetes-integration/installation/k8s-agent-operator) 계측을 수정했습니다.
* 새로운 “통합 모니터링 접근 방식” 섹션으로 [eBPF 에이전트 모범 사례 가이드](/docs/ebpf/best-practices) 를 업데이트했습니다.
* CloudWatch Metric Streams를 수집 방법으로 문서화하도록 [Amazon API Gateway REST(v1) 모니터링 통합](/docs/infrastructure/amazon-integrations/aws-integrations-list/aws-api-gateway-v1-monitoring-integration) 을 업데이트했습니다.
* [SDK 기반 계측](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/sdk-based-instrumentation) CloudWatch 대체 링크를 수정했습니다.
* [Google BigQuery 모니터링 통합](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-bigquery-monitoring-integration)에 테이블 수준 엔티티 지원 및 새로운 스토리지 메트릭을 추가했습니다.
* 가격 책정 요구 사항을 Advanced 컴퓨트로 단순화하도록 [뉴렐릭 Autopilot](/docs/agentic-ai/autopilot/setup) 문서를 업데이트했습니다.
* Intelligent 워크로드의 이름을 [Intelligent 워크로드](/docs/new-relic-solutions/new-relic-one/workloads/create-intelligent-workload)로 변경했습니다.
