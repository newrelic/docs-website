### 새로운 문서

* 뉴렐릭 에이전트 없이 LLM 호출, 도구 호출 및 에이전트 단계를 포함한 OTel 생성형 AI 트레이스를 뉴렐릭 AI 모니터링으로 보내는 방법을 설명하는 [OpenTelemetry를 사용하여 뉴렐릭으로 생성형 AI 트레이스 보내기](/docs/ai-monitoring/opentelemetry-ai-monitoring)를 추가했습니다.

* 코드 변경 없이 Linux 호스트 및 쿠버네티스 클러스터에서 eBPF 에이전트가 생성형 AI 및 LLM 워크로드를 자동으로 감지하고 모니터링하는 방법을 다루는 [eBPF AI 모니터링](/docs/ebpf/ai-monitoring)을 추가했습니다.

* 브라우저 에이전트를 사용하여 전송 및 수신된 메시지, 연결 지속 시간, 종료 이벤트를 포함한 WebSocket 연결 상태 추적을 다루는 [웹소켓 자동 모니터링](/docs/browser/new-relic-browser/browser-pro-features/websockets)을 추가했습니다.

* 가벼운 핑 검사부터 완전히 스크립트화된 API 및 브라우저 여정에 이르기까지 올바른 모니터 유형을 선택하는 데 도움이 되는 [신세틱 모니터링 사용 사례](/docs/synthetics/synthetic-monitoring/guides/synthetic-monitoring-use-cases)를 추가했습니다.

* 에이전트 제어 에이전트 유형 정의, 작동 방식 및 지원되는 에이전트를 다루는 [에이전트 유형](/docs/new-relic-control/agent-control/agent-types)을 추가했습니다.

* VegaTracker를 사용하여 Amazon Fire TV에서 비디오 재생을 모니터링하는 방법을 설명하는 [Amazon Fire TV 시작하기](/docs/streaming-video-&-ads/installation/amazon-fire-tv/get-started-with-amazon-fire-tv) 및 [Shaka Player](/docs/streaming-video-&-ads/installation/amazon-fire-tv/install-shaka-player), [Dash.js](/docs/streaming-video-&-ads/installation/amazon-fire-tv/install-dashjs), [HTML5](/docs/streaming-video-&-ads/installation/amazon-fire-tv/install-html5)에 대한 설치 가이드를 추가했습니다.

* `OTEL_SERVICE_NAME`을(를) 사용하여 여러 OTel 계측된 Lambda 함수를 단일 뉴렐릭 엔티티로 통합하는 방법을 다루는 [단일 OTel 엔티티 아래에 Lambda 함수 그룹화하기](/docs/serverless-function-monitoring/aws-lambda-monitoring/opentelemetry/otel-service-name-lambda)를 추가했습니다.

* 리액트 네이티브 에이전트 v1.9.0에 도입된 `MobileJSError` 이벤트 유형으로의 마이그레이션을 안내하기 위해 [리액트 네이티브 JavaScript 오류 보고](/docs/mobile-monitoring/new-relic-monitoring-react-native/react-native-agent-js-error-reporting), [리액트 네이티브 소스 맵 나열 및 삭제](/docs/mobile-monitoring/new-relic-monitoring-react-native/list-delete-react-native-source-maps), 및 [리액트 네이티브 소스 맵 문제 해결](/docs/mobile-monitoring/new-relic-monitoring-react-native/troubleshoot-react-native-source-maps)을 추가했습니다.

* 다음 워크플로우 자동화 작업 카탈로그 문서를 추가했습니다:

  * [뉴렐릭 이슈 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/newrelic-issue): 워크플로우에서 뉴렐릭 이슈를 생성, 업데이트 및 관리합니다.
  * [뉴렐릭 Lens 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/newrelic-lens): 워크플로우에서 뉴렐릭 Lens 쿼리 및 분석을 실행합니다.
  * [Azure 함수 호출](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-functions-invoke): 워크플로우에서 Azure 함수를 호출합니다.
  * [Azure DevOps API 실행](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-devops-api): 워크플로우에서 Azure DevOps API 호출을 실행합니다.
  * [GitHub 이슈 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-issue): 워크플로우에서 GitHub 이슈를 생성, 업데이트, 가져오기, 나열, 댓글 작성, 잠금 및 잠금 해제합니다.

### 주요 변경 사항

* 새로운 BTP 클라우드 통합 리소스, 업데이트된 설정 단계 및 확장된 Cloud ALM API 인스턴스 설정을 포함하여 v3 지원과 함께 여러 페이지에 걸쳐 [SAP ABAP 애드온 문서](/docs/sap-solutions/install-and-configure/install-new-relic-sap-abap-add-on-package)를 업데이트했습니다.
* [BigQuery](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-bigquery-monitoring-integration), [Bigtable](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-cloud-bigtable-monitoring-integration), [Dataproc](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-cloud-dataproc-monitoring-integration), [Firebase App Hosting](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-cloud-firebase-app-hosting-monitoring-integration), [Firebase Vertex AI](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-cloud-firebase-vertex-ai-monitoring-integration), 및 [Firestore](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-cloud-firestore-monitoring-integration) 통합에 대한 메트릭 전용 리소스 유형 테이블로 GCP 워크로드 아이덴티티 페더레이션 통합 문서를 업데이트했습니다.
* 업데이트된 탐색, APM 용어 및 서비스 이름별 함수 그룹화에 대한 새로운 가이드를 포함하여 OTel Lambda UI 통합을 위해 [OpenTelemetry를 사용한 Lambda 모니터링](/docs/serverless-function-monitoring/aws-lambda-monitoring/opentelemetry/otel-service-name-lambda) 및 관련 페이지를 업데이트했습니다.
* 확장된 OAuth 설정 단계, 리포지터리 선택 지침 및 법적 규정 준수 수정 사항을 포함하여 Autopilot 2.2에 대한 [GitHub에 Autopilot 연결](/docs/agentic-ai/autopilot/connect-to-github) 및 관련 페이지를 업데이트했습니다.

### 사소한 변경 사항

* **새로운 대시보드 다운로드** 작업에 대한 수정된 [](/docs/query-your-data/explore-query-data/dashboards/dashboards-charts-import-export-data)[내보내기 및 가져오기 단계로](/docs/query-your-data/explore-query-data/dashboards/manage-your-dashboard) 대시보드 관리 및 대시보드 가져오기 및 내보내기 를 업데이트했습니다.
* 지원되는 리전 옵션으로 일본(`jp`)을 추가하기 위해 [뉴렐릭 CLI 튜토리얼](/docs/new-relic-solutions/tutorials/new-relic-cli)을 업데이트했습니다.
* 별칭 변경 사항이 적용되려면 에이전트 재시작이 필요하다는 점을 명확히 하기 위해 [애플리케이션의 별칭 변경(v2)](/docs/apis/rest-api-v2/application-examples-v2/change-alias-your-application-v2)에 콜아웃을 추가했습니다.
* 사용자 레코드 간 전환 경로에 대한 사소한 문구 수정을 포함하여 [다중 사용자 레코드 관리](/docs/accounts/accounts-billing/account-setup/multiple-user-records)를 업데이트했습니다.
* 오래된 옵션을 제거하고 현재 기본값에 맞추기 위해 [루비 에이전트 설정](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration)을 업데이트했습니다.
* 복원된 `GCPSPANNERDATABASE` 엔티티 유형 및 관련 메트릭을 문서화하기 위해 [Google Cloud Spanner 모니터링 통합](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-cloud-spanner-monitoring-integration)을 업데이트했습니다.
* AI 모니터링 GA 릴리스 이후 사소한 콘텐츠 문제를 해결하기 위해 [AI 에이전트 보기](/docs/ai-monitoring/explore-ai-data/view-ai-agents)를 업데이트했습니다.
