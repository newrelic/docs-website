### 새로운 문서

* [OpenTelemetry 수집기를 사용하여 SingleStore 메트릭을 모니터](/docs/more-integrations/open-source-telemetry-integrations/opentelemetry/collector/collector-configuration-examples/opentelemetry-collector-singlestore)하는 방법에 대한 가이드입니다.

### 주요 변경 사항

* 이제 신세틱 모니터링 작업 관리자 문서에서 [스크립팅된 모니터에 대한 사용자 정의 변수](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-configuration)를 구성하는 방법과 이를 지원하는 [작업 관리자 버전](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-transition-guide)을 설명합니다.
* 설치를 더 쉽게 하고 문서가 정확하고 최신 상태로 유지되도록 온-호스트 통합 문서의 재작성을 계속 진행했습니다. 이번 주 업데이트: [Sonarqube](/docs/infrastructure/host-integrations/host-integrations-list/sonarqube-monitoring-integration) 및 [Windows 서비스](/docs/infrastructure/host-integrations/host-integrations-list/windows-services-integration).
* 크로스 애플리케이션 추적은 더 이상 사용되지 않으며 향후 APM 에이전트 버전에서는 지원되지 않습니다. 이를 반영하여 문서를 업데이트했습니다.
* 2023년에 사용 중단된 OpenTelemetry 누적 메트릭과 관련된 문서를 삭제했습니다.

### 사소한 변경 사항

* Node.js [AI 모니터링 사용자 정의](/docs/ai-monitoring/customize-agent-ai-monitoring)와 관련된 API 문서 링크를 업데이트했습니다.
* Standard, Pro 및 Enterprise 계정에 어떤 [Data Plus 기능](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/data-ingest-billing/#data-prices)이 적용되는지 명확히 했습니다.
* [자바 APM 에이전트를 업데이트](/docs/apm/agents/java-agent/installation/update-java-agent) 하고 당사의 [자바 에이전트 API](/docs/apm/agents/java-agent/api-guides/guide-using-java-agent-api) 중 하나를 사용하는 경우, API 종속성도 업데이트해야 한다는 점을 명확히 했습니다.
* [AI 라이브러리 및 프레임워크](/docs/apm/agents/python-agent/getting-started/compatibility-requirements-python-agent/#digital-intelligence-platform)를 모니터하기 위해 파이썬 APM 에이전트 지원 버전을 9.8.0(기존 9.9.0)으로 업데이트했습니다.
* [대상 공지](/docs/alerts-applied-intelligence/notifications/notification-integrations) 지침에서 ServiceNow에 대한 링크를 업데이트했습니다.
* 당사의 인프라 에이전트는 이제 Elastic 컨테이너 서비스를 모니터링할 때 Cgroup 버전 V2를 사용하여 [도커 API에서 모든 EC2 노드 컨테이너 메트릭](/docs/infrastructure/install-infrastructure-agent/linux-installation/container-instrumentation-infrastructure-monitoring)을 수집합니다.
* UI에서 [OpenTelemetry `singlestore` 데이터를 찾는 방법](/docs/more-integrations/open-source-telemetry-integrations/opentelemetry/collector/collector-configuration-examples/opentelemetry-collector-singlestore/#view-data)에 대한 정보를 업데이트했습니다.
* [로그 검색](/docs/codestream/observability/log-search) 및 [성능 모니터링](/docs/codestream/observability/performance-monitoring)과 관련된 CodeStream 문서를 업데이트했습니다.
* 에러스 인박스(errors inbox)에서 지원하는 [자바 에이전트 사용자 속성](/docs/triage-inbox/error-users-impacted)에 대한 링크를 추가했습니다.
* [NRQL 공지 조건](/docs/alerts-applied-intelligence/new-relic-alerts/alert-conditions/queries-nrql_screenshot-full_nrql-alert-conditions/#condition-tips)이 평가할 데이터를 집계할 때, 이제 30초에서 최대 6시간까지의 시간 단위로 데이터를 평가할 수 있습니다.
