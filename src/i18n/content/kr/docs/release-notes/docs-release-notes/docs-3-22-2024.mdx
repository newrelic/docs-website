  저희는 매주 문서 변경 사항을 알려드리기 위해 릴리스 노트를 시범 운영하고 있습니다. 이것은 실험적인 기능이므로 유용하다고 생각되시면 [GitHub 이슈를 통해 알려주세요](https://github.com/newrelic/docs-website/issues/new/choose) !

### 주요 변경 사항

* 설치를 더 쉽게 만들고 문서가 정확하고 최신 상태인지 확인하기 위해 [RabbitMQ](/install/rabbitmq/), [JMX](/install/jmx/), [아파치 Flink](/install/apache-flink/) 및 [HAProxy](/install/haproxy/)에 대한 온-호스트 통합 문서를 검토하고 다시 작성했습니다.
* [AWS Lambda 서버리스 모니터링](/docs/serverless-function-monitoring/aws-lambda-monitoring/get-started/compatibility-requirements-aws-lambda-monitoring/)의 경우, 지원되는 런타임 버전, 종속성 및 더 이상 사용되지 않는 .NET NuGet 패키지 SDK에 대한 정보를 업데이트했습니다.
* 뉴렐릭의 2024년 규정 준수 상태를 반영하도록 [FedRAMP](/docs/security/security-privacy/compliance/certificates-standards-regulations/fedramp/), [HIPAA](/docs/security/security-privacy/compliance/certificates-standards-regulations/hipaa/), [ISO-27001](/docs/security/security-privacy/compliance/certificates-standards-regulations/iso-27001/), [SOC2](/docs/security/security-privacy/compliance/certificates-standards-regulations/soc2/), [TISAX](/docs/security/security-privacy/compliance/certificates-standards-regulations/tisax/), [데이터 암호화](/docs/security/security-privacy/compliance/data-encryption/) 및 [HITRUST CSF](/docs/security/security-privacy/compliance/hitrust/) 규정 준수 문서를 업데이트했습니다.
* 가독성과 품질을 개선하기 위해 [NRQL 문서](/docs/nrql/get-started/introduction-nrql-new-relics-query-language)의 전면 개편 및 재구성을 계속 진행했습니다.
* 안드로이드 [모바일 모니터링 오프라인 스토리지](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/configure-settings/#android-offline-storage)가 기본적으로 비활성화되어 있음을 명확히 하고 [오프라인 스토리지 설정](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/set-max-offline-storage/#android) 문서를 업데이트했습니다.
* [Unity 모바일 모니터링 설정](https://docs.newrelic.com/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/configure-settings/#unity) 정보를 추가했습니다.
* [AWS PrivateLink](/docs/data-apis/custom-data/aws-privatelink)용 신세틱 모니터링 엔드포인트를 추가했습니다.
* [Statsd 통합](/docs/more-integrations/open-source-telemetry-integrations/statsd/statsd-monitoring-integration/#troubleshooting) 문서에 문제 진단, 해결 섹션을 추가했습니다.
* 새로운 [규칙 요소 계측](/docs/apm/agents/net-agent/configuration/net-agent-configuration/#instrumentation-rules) .NET 설정 옵션 섹션을 추가했습니다.
* 신세틱 모니터링 [작업 관리자 전환 버전 요구 사항](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-transition-guide)을 업데이트했습니다.

### 소규모 업데이트

* 신세틱 모니터링 [Kubernetes `vsePassphrase`](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-configuration/#kubernetes-env-config) 환경 변수를 추가했습니다.
* 일부 끊어진 내부 링크를 수정했습니다.
* 새로운 이미지와 UI에 대한 더 자세한 내용으로 [에러스 인박스(errors inbox) 오류 상태](/docs/triage-inbox/errors-inbox) 섹션을 업데이트했습니다.
* [신세틱 모니터링 런타임 모듈](/docs/synthetics/synthetic-monitoring/using-monitors/manage-monitor-runtimes) 버전을 업데이트했습니다.
* [Fluent Bit 플러그인과 함께 여러 로그 소스](/docs/logs/forward-logs/fluent-bit-plugin-log-forwarding)를 사용하는 방법에 대한 정보를 추가했습니다.
* [NerdGraph API를 통해 로그 라이브 아카이브를 쿼리](/docs/logs/get-started/live-archives)하는 방법을 추가했습니다.
* 다양한 사소한 스타일 및 이미지 문제를 업데이트하고 수정했습니다.
* NerdGraph 응용 인텔리전스 [커서 페이지네이션 예제](/docs/apis/nerdgraph/examples/nerdgraph-api-notifications-channels/#paginate)를 추가했습니다.
* 잘못된 [NVIDIA GPU 통합](/docs/infrastructure/host-integrations/host-integrations-list/nvidia-gpu-integration) 설정을 수정했습니다.
* 안드로이드 모바일 모니터링 [매핑 업로드 호스트](/docs/mobile-monitoring/new-relic-mobile-android/install-configure/android-agent-crash-reporting) 설정에 대한 섹션을 추가했습니다.
* 자바용 [Temporal 모니터링 통합](/docs/infrastructure/host-integrations/host-integrations-list/temporal-monitoring-integration)에 대한 설정 세부 정보를 추가했습니다.
* [GCP Cloud Functions](/docs/infrastructure/google-cloud-platform-integrations/get-started/integrations-custom-roles)에 누락된 권한을 추가했습니다.
* [보안 취약점 보고](/docs/security/security-privacy/information-security/security-bulletins/#report)와 관련된 문서 링크를 업데이트했습니다.
* [조정된 공개 프로세스](/docs/security/security-privacy/information-security/software-development-lifecycle)에 더 이상 사용하지 않는 HackerOne에 대한 언급을 제거하도록 보안 문서를 업데이트했습니다.
* [브라우저 모니터링 프록시 방법](/docs/browser/new-relic-browser/configuration/proxy-agent-requests) 사용의 법적 의미에 대한 정보를 추가했습니다.
* Windows의 `SystemSample` 이벤트에 대한 [`coreCount`](https://docs.newrelic.com/attribute-dictionary/?event=SystemSample&attribute=coreCount) 속성이 프로세서의 현재 인스턴스에 대한 프로세서 수를 계산한다는 점을 명확히 했습니다.
* Meraki API 및 네트워크 디바이스 syslog와 관련된 변경 사항을 설명하도록 [네트워크 성능 모니터링 설정](/docs/network-performance-monitoring/advanced/advanced-config) 문서를 업데이트했습니다.
* [Kubernetes의 Prometheus OpenMetrics 통합](/docs/infrastructure/prometheus-integrations/install-configure-prometheus-agent/migration-guide) EOL 날짜를 제거했습니다.
* 왼쪽 탐색에서 Serverless 구형 수동 계측을 [레이어 없는 수동 계측](/docs/serverless-function-monitoring/aws-lambda-monitoring/enable-lambda-monitoring/enable-serverless-monitoring-aws-lambda-layerless/)으로 이름을 변경했습니다.
* 명확성을 높이고 스타일 가이드와의 일관성을 개선하기 위해 여러 가지 사소한 교정 작업을 진행했습니다.
