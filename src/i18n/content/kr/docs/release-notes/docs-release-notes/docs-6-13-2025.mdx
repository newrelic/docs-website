### 새로운 문서

* 뉴렐릭의 변경 추적 기능을 사용하여 애플리케이션 및 인프라 전반의 변경 사항을 추적할 수 있도록 [변경 추적 이벤트](/docs/change-tracking/change-tracking-events/)를 추가했습니다. 시스템에 미치는 영향을 파악할 수 있도록 변경 사항을 캡처, 시각화 및 분석합니다.
* 프로메테우스 에이전트를 버전 2로 업그레이드하는 [절차](/docs/infrastructure/prometheus-integrations/migrations/v2-upgrade/)를 추가했습니다.
* 중첩 변수가 무엇인지, 그리고 대시보드에서 이를 어떻게 사용하는지 설명하는 [문서](/docs/query-your-data/explore-query-data/dashboards/nested-variables/)를 추가했습니다.

### 주요 변경 사항

* .NET 에이전트용 [시작 시 애플리케이션 멈춤](/docs/apm/agents/net-agent/troubleshooting/app-hangs-on-startup/) 문제 진단, 해결 가이드를 추가했습니다.

* Windows - Microsoft SQL Server(관리자 powershell에서 실행)에 대한 [수동으로 온-호스트 통합 실행(dry-run)](/docs/infrastructure/host-integrations/troubleshooting/run-integrations-manually/) 예제를 추가했습니다.

* [브라우저 API용 Measure API](/docs/browser/new-relic-browser/browser-apis/measure/)를 추가했습니다.

* 8.21.0 자바 에이전트 릴리스용 [자바 에이전트 구성 파일 템플릿](/docs/apm/agents/java-agent/configuration/java-agent-config-file-template/)을 추가했습니다.

* [보안 및 액세스 문서](/docs/query-your-data/explore-query-data/dashboards/prerequisites-to-share-dashboards-charts/)에서 대시보드와 차트를 공유하는 데 필요한 사용자 유형을 업데이트했습니다.

* Github Copilot 및 Gemini용 뉴렐릭 AI 에이전트 통합이 이제 정식 버전으로 제공됩니다. 문서를 다음과 같이 업데이트했습니다:

  * [GitHub Copilot과의 뉴렐릭 AI 에이전트 통합](/docs/agentic-ai/agentic-integration/github-copilot-integration/)
  * [Gemini와의 뉴렐릭 AI 에이전트 통합](/docs/agentic-ai/agentic-integration/gemini-integration/)

* 브라우저 에이전트 버전 1.259.0 이상에서 세션 리플레이 설정에 대한 서버 측 설정 변경 사항을 반영하도록 [뉴렐릭에서 세션 리플레이 보기](/docs/browser/browser-monitoring/browser-pro-features/session-replay/view-session-replays/) 문서를 업데이트했습니다.

* 퇴사한 직원의 계정 비활성화 및 정기 감사에 대한 정보를 [뉴렐릭 데이터 개인정보 보호](https://docs.newrelic.com/docs/security/security-privacy/data-privacy/data-privacy-new-relic/#account-security) 및 [보안 정책](/docs/licenses/license-information/referenced-policies/security-policy/) 문서에 추가했습니다.

* [브라우저 애플리케이션용 미디어 비디오 에이전트를 설치](/install/browser-media/)하는 방법을 설명하는 문서에 업데이트된 설정을 추가했습니다.

### 사소한 변경 사항

* 자바 에이전트의 [호환성 요구 사항](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent/)을 업데이트했습니다.
* 브라우저 에이전트 `start()` API 기능 목록에 [로깅](/docs/browser/new-relic-browser/browser-apis/start/#feature-names)을 추가했습니다.
* `NEW_RELIC_ATTRIBUTES_HTTP_ATTRIBUTE_MODE=both`(으)로 [자바 에이전트 설정: 설정 파일](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file/)을 업데이트했습니다.
* [자바 에이전트 라이선스](/docs/licenses/product-or-service-licenses/new-relic-apm/java-agent-licenses/)를 업데이트했습니다.
* 색인된 문서의 가시성이 조직의 정책을 준수하도록 [뉴렐릭 AI Knowledge Connector](/docs/agentic-ai/knowledge-integration/overview/) 및 [RAG 도구 및 문서 설정](/docs/apis/nerdgraph/examples/nerdgraph-rag/) 문서에 콜아웃을 추가했습니다.
* [SDK 기반 계측](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/sdk-based-instrumentation/) 문서에서 뉴렐릭 AWS Lambda OpenTracing 자바 SDK 라이브러리 3.0.0 버전에 대한 AWS 종속성 버전을 업데이트했습니다.
* <DNT>**[Predictive alerts](/docs/alerts/create-alert/set-thresholds/predictive-alerts)**</DNT> 문서의 제목을 업데이트했습니다. 이전 제목은 <DNT>**Predictive capability**</DNT>이었습니다.
* 수정된 최대 소스 맵 업로드 한도를 반영하여 [소스 맵 API](/docs/browser/new-relic-browser/browser-pro-features/upload-source-maps-api/) 문서를 업데이트했습니다.
* [.Net 에이전트 호환성 및 요구 사항](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements/) 문서를 최신 호환 버전으로 업데이트했습니다.
* Consumption 요금제 및 In-Process 함수 모델에서 Linux OS가 지원되지 않는다는 정보를 포함하여 [Azure Functions 모니터링](/docs/serverless-function-monitoring/azure-function-monitoring/install-serverless-azure-monitoring/) 문서를 업데이트했습니다.
* [호환성 및 요구 사항](/docs/serverless-function-monitoring/azure-function-monitoring/compatibility-requirement-azure-monitoring/) 문서에서 계측된 Azure Functions의 설치 방법을 업데이트했으며, 특히 Azure Site Extension을 사용하는 Windows용 환경 변수 지침을 조정했습니다.
* 사용자 지정 태그를 지원하는 자바 에이전트 버전을 포함하도록 [애플리케이션 로그를 위한 사용자 지정 태그](/docs/logs/logs-context/custom-tags-agent-forwarder-logs/) 문서를 업데이트했습니다.
* [addToTrace](/docs/browser/new-relic-browser/browser-apis/addtotrace/) API 문서에 Unix 타임스탬프 요구 사항을 추가했습니다.
* [Node.js 에이전트의 호환성 및 요구 사항](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent/)을 업데이트했습니다.
