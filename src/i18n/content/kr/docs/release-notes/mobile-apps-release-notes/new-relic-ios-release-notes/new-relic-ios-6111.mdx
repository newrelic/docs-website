### 기능, 개선 사항 및 수정 사항

* 뉴렐릭 AI V2 — 인라인 차트, 스레드 기록, 권한 게이팅
* 대시보드: 세부 정보의 당겨서 새로 고침, 컴팩트 목록+시머, 더 얇은 선
* 대시보드: 로그 테이블 타임스탬프 형식(MMM DD, HH:mm:ss.SSS)
* 공지 상태 UI ― 배너 문구, 수정 버튼 스타일, 권한 카드 레이아웃
* `MobileBreadcrumb` 쿼리 편집기 편집 시 기록됨
* 수정됨: 공지 설정 화면 ― 오래된 코디네이터 의존성 제거됨
* 수정됨: 푸시 공지 상호작용이 이제 동기적으로 기록되며, 닫기가 안드로이드와 정렬됨
