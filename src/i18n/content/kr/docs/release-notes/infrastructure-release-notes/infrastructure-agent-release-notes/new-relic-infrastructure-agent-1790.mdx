에이전트의 새 버전이 출시되었습니다. [인프라 에이전트를 업데이트](/docs/infrastructure/install-configure-manage-infrastructure/update-or-uninstall/update-infrastructure-agent)하려면 표준 절차를 따르십시오. 뉴렐릭은 에이전트를 정기적으로, 최소 3개월마다 업그레이드할 것을 권장합니다. 이번 릴리스 기준으로 지원되는 가장 오래된 버전은 [인프라 에이전트 1.65.3](/docs/release-notes/infrastructure-release-notes/infrastructure-agent-release-notes/new-relic-infrastructure-agent-1653/)입니다.

## 변경됨

* AWS 태그와 일치하도록 추가 OCI 태그를 추가했습니다. [#2295](https://github.com/newrelic/infrastructure-agent/pull/2295)
* `disable_plugin_default_dir_scan`을(를) 통해 기본 통합 위치를 무시할 수 있도록 지원을 추가했습니다. [#2290](https://github.com/newrelic/infrastructure-agent/pull/2290)
* 에이전트 제어(AC)에서 사용하는 환경 변수를 공개로 노출했습니다. [#2293](https://github.com/newrelic/infrastructure-agent/pull/2293)
* 경로 탐색으로 인해 발생하는 원격 코드 실행(RCE) 취약점을 수정했습니다. [#2292](https://github.com/newrelic/infrastructure-agent/pull/2292)
* Trivy 스캔에서 플래그가 지정된 취약한 종속성을 상향 조정하고, CVE를 수정하기 위해 내장된 OHI 버전(`nri-docker`, `nri-flex`)을 업데이트했습니다. [#2301](https://github.com/newrelic/infrastructure-agent/pull/2301) [#2302](https://github.com/newrelic/infrastructure-agent/pull/2302)
