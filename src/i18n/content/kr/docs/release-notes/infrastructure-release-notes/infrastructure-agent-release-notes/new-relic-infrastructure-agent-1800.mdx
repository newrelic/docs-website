에이전트의 새 버전이 출시되었습니다. [인프라 에이전트를 업데이트](/docs/infrastructure/install-configure-manage-infrastructure/update-or-uninstall/update-infrastructure-agent)하려면 표준 절차를 따르십시오. 뉴렐릭은 에이전트를 정기적으로, 최소 3개월마다 업그레이드할 것을 권장합니다. 이번 릴리스 기준으로 지원되는 가장 오래된 버전은 [인프라 에이전트 1.65.3](/docs/release-notes/infrastructure-release-notes/infrastructure-agent-release-notes/new-relic-infrastructure-agent-1653/)입니다.

## 변경됨

* Azure Key Vault를 또 다른 데이터바인드 시크릿 소스로 추가했습니다. [#2304](https://github.com/newrelic/infrastructure-agent/pull/2304)
* 예측 가능한 Fluent Bit 구성 디렉터리 재사용으로 인해 발생하는 로컬 권한 상승 취약점을 수정했습니다. [#2306](https://github.com/newrelic/infrastructure-agent/pull/2306)
* 여러 Go stdlib CVE를 수정하기 위해 Go를 1.26.6으로 업데이트했습니다. [#2308](https://github.com/newrelic/infrastructure-agent/pull/2308)
* CVE를 수정하기 위해 내장된 OHI 버전(`nri-docker`, `nri-flex`, `nri-winservices`, `nri-prometheus`)을 업데이트했습니다. [#2316](https://github.com/newrelic/infrastructure-agent/pull/2316)
