## Notes

에이전트의 새 버전이 릴리스되었습니다. [인프라 에이전트를 업데이트](/docs/infrastructure/install-configure-manage-infrastructure/update-or-uninstall/update-infrastructure-agent)하려면 표준 절차를 따르십시오.

뉴렐릭은 에이전트를 정기적으로, 최소 3개월마다 업그레이드할 것을 권장합니다.

## 변경됨

* `nri-docker` [v1.6.0](https://github.com/newrelic/nri-docker/releases/tag/v1.6.0)으로. 새로운 메모리 및 스토리지 메트릭이 추가되었습니다. `memoryUsageBytes` 및 `memoryUsageLimitPercent` 계산이 변경되었습니다. 자세한 내용은 이 [제품 업데이트 게시물](https://support.newrelic.com/s/hubtopic/aAX8W0000008bmH/dockercontainers-memory-metric-updates) 및 [nri-docker 릴리스 노트](https://github.com/newrelic/nri-docker/releases/edit/v1.6.0)를 참조하십시오.
* `nri-winservices` [v0.2.0-beta](https://github.com/newrelic/nri-winservices/releases/tag/v0.2.0-beta)(으)로.
