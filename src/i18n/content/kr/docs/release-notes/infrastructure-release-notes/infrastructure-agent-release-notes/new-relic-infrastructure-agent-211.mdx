## Notes

### 🛡️ 보안 공지

* [#2410](https://github.com/newrelic/infrastructure-agent/pull/2410)에서 Go 버전을 1.27.4로 업데이트
* [#2411](https://github.com/newrelic/infrastructure-agent/pull/2411)에서 내장된 OHI 버전(nri-docker v2.10.1, nri-flex v1.18.19, nri-winservices v1.5.8, nri-prometheus v2.31.1)을 업데이트했습니다.

### 🚀 개선 사항

* [#2381](https://github.com/newrelic/infrastructure-agent/pull/2381)에서 SUSE 16 OS 지원을 추가합니다.
* [#2367](https://github.com/newrelic/infrastructure-agent/pull/2367)에서 에이전트 제어 패키지 및 에이전트 유형의 nrjmx 래퍼 스크립트를 노출했습니다.

### 🐞 버그 수정

* [#2348](https://github.com/newrelic/infrastructure-agent/pull/2348)에서 다중 리전(스테이징/EU/JP)을 지원하기 위한 카나리 프루닝
* [#2406](https://github.com/newrelic/infrastructure-agent/pull/2406)에서 rpm 플러그인이 SLES 16.0에서 작동하도록 rpm ndb 데이터베이스 파일 추가
* [#2407](https://github.com/newrelic/infrastructure-agent/pull/2407)에서 SLES 16에 /etc/ssh/sshd\_config가 누락된 경우 /usr/etc/ssh에서 sshd 구성 읽기
* [#2409](https://github.com/newrelic/infrastructure-agent/pull/2409)에서 OpenProcess를 사용하여 에이전트를 Windows 작업 개체에 추가

### 지지 성명:

에이전트의 새 버전이 릴리스되었습니다. [인프라 에이전트를 업데이트](/docs/infrastructure/install-configure-manage-infrastructure/update-or-uninstall/update-infrastructure-agent)하려면 표준 절차를 따르십시오.

최신 에이전트 버전이 출시되는 대로 업데이트하는 것을 권장합니다. 최신 버전으로 업그레이드할 수 없는 경우, 에이전트를 90일이 넘지 않은 버전으로 업데이트하십시오. [에이전트를 최신 상태로 유지하는 방법](https://docs.newrelic.com/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent/)에 대해 자세히 알아보십시오.

에이전트 릴리스 및 지원 날짜에 대한 정보는 [뉴렐릭 인프라 에이전트 EOL 정책](https://docs.newrelic.com/docs/infrastructure/infrastructure-agent/infrastructure-agent-eol-policy/)을 참조하십시오.
