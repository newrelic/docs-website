## 업데이트됨

[이전에 발표한 바와 같이](https://support.newrelic.com/s/hubtopic/aAX8W0000008cts/important-upcoming-changes-to-capabilities-and-support-across-errors-classic), 클라우드 통합(AWS, Azure, GCP)에서 푸시되는 인벤토리 데이터에 대한 지원을 종료합니다.

### 무엇이 변경됩니까?

인벤토리 데이터는 현재 많은 AWS, Azure 및 GCP 통합에서 수집됩니다. 이는 정적 설정 데이터 또는 리소스 메타데이터를 나타냅니다. 인벤토리의 호스트 또는 온-호스트 통합 정보는 이 변경 사항의 영향을 받지 않습니다.

### Inventory란 무엇입니까?

인벤토리 데이터는 서비스의 상태 및 설정에 대한 정보입니다(예: 서비스 설정). 데이터는 원래 인프라 환경의 인벤토리 페이지 및 일부 통합 대시보드에 나타납니다. 인벤토리 데이터의 변경 사항은 쿼리하고 알림을 받을 수 있는 뉴렐릭 `InfrastructureEvent` 이벤트를 생성합니다.

### 더 이상 사용할 수 없는 기능

* Infrastructure &gt; Inventory 리로 이동할 때 `aws/*`, `azure/*` 또는 `gcp/*`의 소스는 더 이상 사용할 수 없습니다.
* 인벤토리 또는 인프라 이벤트 위젯이 포함된 Infrastructure &gt; AWS | Azure | GCP | GovCloud에서 사용할 수 있는 내장 대시보드는 더 이상 데이터를 표시하지 않습니다. 이러한 대시보드는 인프라 모니터링을 위한 원래 대시보드 환경에서는 사용할 수 없는 모든 새로운 기능(편집, 공유, 새로운 시각화 등)을 활성화하는 표준 뉴렐릭 대시보드로 마이그레이션될 예정입니다.
* `InfrastructureEvent`의 `aws`, `azure` 또는 `gcp` 소스를 사용하는 쿼리는 더 이상 데이터를 보고하지 않습니다.

### 이 기능이 지원 중단되는 이유는 무엇입니까?

* 고객은 지원 중단되지 않는 호스트 인벤토리에서 더 많은 가치를 찾지만, 클라우드 통합에서는 더 적은 가치를 찾습니다.

### 대안

* 폴링 통합에서 Inventory로 사용할 수 있는 대부분의 속성은 메트릭 메타데이터 또는 태그로도 사용할 수 있으므로 이 정보를 쿼리할 수 있습니다.
* 일부 제한된 통합은 인벤토리에서 사용할 수 있는 동일한 정보를 표준 뉴렐릭 이벤트로도 게시했습니다. 예를 들어, AWS Health 통합이 있습니다.

### 이것이 AWS CloudWatch Metric Streams와 Azure &amp; GCP의 향후 통합에 어떤 영향을 미칩니까?

* AWS CloudWatch Metric Streams에서는 인벤토리를 사용할 수 없으므로 이 기능에는 영향을 미치지 않습니다.
* Azure 및 GCP를 위한 새로운 통합은 MELT 텔레메트리: 메트릭, 이벤트, 로그 &amp; 트레이스에 중점을 두며, 특히 메트릭에 중점을 둡니다.

### 피드백

이 기능이 지원 중단된 후 문제가 발생하는 경우, UI에서 다음 단계를 따라 도움을 받을 수 있습니다:

1. New Relic 계정에 로그인하세요.
2. 포괄적인 [도움말 센터](https://one.newrelic.com/help-xp)를 방문하십시오. 여기에는 풍부한 정보와 리소스가 포함되어 있습니다.
3. 추가 지원이 필요한 경우 **Create a Support Case** \[지원 케이스 생성]을 클릭하시면 저희 팀이 기꺼이 도와드리겠습니다.
