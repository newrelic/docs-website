### 호환성 변경

[Google Cloud Pub/Sub to 뉴렐릭 Dataflow 템플릿](https://github.com/newrelic-forks/DataflowTemplates)이 아파치 Beam 2.77.0으로 업그레이드되어 GCP 지원 SDK를 계속 유지합니다. 템플릿을 빌드하고 실행하려면 자바 11 이상이 필요합니다. 자바 8을 사용하여 템플릿을 빌드하거나 실행하는 경우, 업데이트된 버전을 사용하기 전에 JDK를 업그레이드하십시오.
