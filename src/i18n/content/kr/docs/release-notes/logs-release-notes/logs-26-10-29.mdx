### 새로운 기능

* 이제 데비안 13(Trixie)용 네이티브 패키지를 사용할 수 있습니다.
* 이제 Windows Server 2025(LTSC)용 네이티브 패키지를 사용할 수 있습니다.
* 이제 [Fluent Bit 출력 플러그인 도커 이미지](https://hub.docker.com/r/newrelic/newrelic-fluentbit-output)가 Windows Server 2025(LTSC) 변형을 게시합니다.

### 개선 및 향상

* Fluent Bit가 버전 5.1.5로 업그레이드되었습니다. 자세한 내용은 [Fluent Bit 공지 사항](https://fluentbit.io/announcements/)을 참조하십시오.
* 이번 릴리스에는 [뉴렐릭 Fluent Bit 출력 플러그인 3.12.0](https://github.com/newrelic/newrelic-fluent-bit-output/releases/tag/v3.12.0)이 포함되어 있습니다.
* 인프라 에이전트는 Fluent Bit 5.1.5 Linux 및 Windows용 패키지를 권장합니다.
* Linux용 [Fluent Bit 출력 플러그인 도커 이미지](https://hub.docker.com/r/newrelic/newrelic-fluentbit-output)는 Fluent Bit 5.1.5를 사용하며, 출력 플러그인 3.12.0이 포함되어 있습니다. Windows 이미지 변형에는 출력 플러그인 3.12.0이 포함되며, 기존 Fluent Bit 버전을 유지합니다. 버전: 5.1.2 (Windows Server 2022 및 2025용) 및 4.0.3(Windows Server 2019용).
* [뉴렐릭 로깅 Helm 차트](https://github.com/newrelic/helm-charts/tree/master/charts/newrelic-logging)가 버전 1.44.0으로 업데이트되었으며 새로운 플러그인 이미지를 설치합니다.
* 배포판의 수명이 종료되었기 때문에 Debian 11(Bullseye) 패키지는 더 이상 빌드되지 않습니다.

### 보안 업데이트

* 손상된 eMudhra 중간 CA 키 차단을 포함한 CVE 수정을 위해 Go 버전이 1.27.3으로 업그레이드되었습니다.
* Linux 도커 이미지는 더 이상 emSign ECC Root CA - G3 및 AAA Certificate Services 루트 인증서를 신뢰하지 않습니다.
