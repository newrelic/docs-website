### 보안 업데이트

* [AWS Unified Lambda](https://github.com/newrelic/aws-unified-lambda)가 버전 1.1.5로 업데이트되었으며, CVE 수정을 위해 Go를 1.27.3으로 업그레이드합니다.
* [CVE-2026-111064](https://nvd.nist.gov/vuln/detail/CVE-2026-111064) 및 [CVE-2026-111066 을](https://nvd.nist.gov/vuln/detail/CVE-2026-111066) 수정하기 위해 [AWS 로그 수집용 aws-log-ingestion Lambda](https://github.com/newrelic/aws-log-ingestion) 가 버전 2.11.5로 업데이트되었습니다. 이 버전은 aiohttp 라이브러리를 3.14.5로, yarl을 1.25.1로 업데이트하며, 관련 종속성도 함께 업데이트합니다.
* 취약한 certifi 종속성을 수정하기 위해 AWS S3 로그 수집용 [aws\_s3\_log\_ingestion\_lambda](https://github.com/newrelic/aws_s3_log_ingestion_lambda)가 버전 1.4.4로 업데이트되었습니다. 이 버전은 certifi 라이브러리를 2026.10.23으로 업데이트하며, 관련 종속성도 함께 업데이트합니다.
