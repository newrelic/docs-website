## 3.45.0

### 추가됨

* 새로운 통합 nrecho-v5를 추가했습니다. 이전 주요 버전(v3, v4)은 여전히 각각의 폴더에서 사용할 수 있음을 참고하시기 바랍니다
* 생성형 AI 패키지를 계측하는 새로운 통합 nrgemini를 추가했습니다.
* 연속 프로파일링 지원이 추가되었습니다   \* 참고: 연속 프로파일링은 아직 일반적으로 사용할 수 없는 새로운 기능입니다. 에이전트 측 구성 요소 코드가 이제 에이전트에 포함되어 있지만, 일반 공급 릴리스 전에 실제로 사용하려면 뉴렐릭 영업 담당자에게 문의하여 프리뷰에 조기 참여해야 합니다

### 결정된

* LLM 메시지가 잘못 잘리는 버그를 수정했습니다.

### 보안

* Dependabot 보안 업데이트

  * v3/integrations/nrgrpc 및 /v3에서 grpc를 1.82.1에서 1.83.1로 업데이트했습니다.
  * v3/integrations/nramqp에서 amqp091-go를 1.9.0에서 1.13.0으로 업데이트했습니다.
  * v3/integrations/nrecho-v4에서 echo/v4를 4.9.0에서 4.15.3으로 업데이트했습니다.

### 지지 성명

우리는 최신 버전의 Go 언어를 사용합니다. 최소한 Go 팀에서 지원하는 것보다 오래된 Go 버전은 사용해서는 안 됩니다. 지원되는 Go 에이전트 버전과 타사 구성 요소에 대한 자세한 내용은 [Go 에이전트 EOL 정책을](https://docs.newrelic.com/docs/apm/agents/go-agent/get-started/go-agent-eol-policy/) 참조하세요.
