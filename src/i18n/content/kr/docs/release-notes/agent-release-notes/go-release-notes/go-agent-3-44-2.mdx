## 3.44.2

### 추가됨

* `aws.lambda.eventSource.eventType` `nrlambda` 통합에 대한 속성 지원

### 결정된

* `TransactionTrace` 수정 사항

  * `backtrace` UI에 올바르게 표시됨-&gt;NR1에서 역추적이 올바르게 표시되지 않는 문제를 수정했습니다
  * `timestamp` 더 이상 null이 아님-&gt;타임스탬프가 항상 null로 표시되는 문제를 수정했습니다
  * `exclusive_duration_millis` 더 이상 null이 아님 -&gt; `exclusive_duration_millis`이(가) 항상 null로 표시되는 문제를 수정했습니다.

### 보안

* Dependabot 보안 업데이트

  * `nrgrpc` google.golang.org/grpc를 1.82.1로 업데이트
  * `nrconnect` golang.org/x/net을 0.55.0으로 업데이트합니다

### 지지 성명

최신 버전의 Go 언어를 사용합니다. 최소한 Go 팀에서 계속 지원하는 Go 버전을 사용하십시오. 지원되는 Go 에이전트 및 타사 구성 요소 버전에 대한 자세한 내용은 [Go 에이전트 EOL 정책](/docs/apm/agents/go-agent/get-started/go-agent-eol-policy) 을 참조하십시오.
