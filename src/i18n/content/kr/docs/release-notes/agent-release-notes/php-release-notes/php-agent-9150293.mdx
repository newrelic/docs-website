### 지원 종료 공지

* 뉴렐릭 PHP 에이전트의 PHP 5.3 및 PHP 5.4에 대한 지원은 중단되었으며 향후 버전에서 제거됩니다. 뉴렐릭은 이 릴리스 날짜를 기준으로 7.3 이상의 [지원되는 PHP 버전](https://www.php.net/supported-versions.php)으로 업그레이드할 것을 강력히 권장합니다. PHP 5.3 및 5.4에서 뉴렐릭 PHP 에이전트를 계속 실행하려면, 최대의 호환성을 위해 에이전트 9.15 버전을 사용하는 것을 권장합니다. 하지만 이 경우 제한적인 지원만 제공해 드릴 수 있다는 점에 유의해 주십시오.
* 이번 릴리스는 CentOS 5에 대해 공식적으로 지원되는 마지막 뉴렐릭 PHP 에이전트입니다.
* 뉴렐릭 PHP 에이전트의 MacOS 빌드는 더 이상 제공되지 않으며, MacOS 플랫폼에서의 호환성도 더 이상 보장하지 않습니다.
* 이러한 EOL 공지에 대한 자세한 내용은 [Explorers Hub 게시물](https://support.newrelic.com/s/hubtopic/aAX8W0000008bKn/important-upcoming-changes-to-capabilities-across-browser-php-python-mobile)을 참조하십시오.

### 새로운 기능

* [라미나스 3.x에 대한 지원이 추가되었습니다.](https://github.com/newrelic/newrelic-php-agent/pull/36)
* [라라벨 Lumen 6.x, 7.x 및 8.x에 대한 지원이 추가되었습니다.](https://github.com/newrelic/newrelic-php-agent/pull/38)
* [Wordpress 계측에서 하위 경로를 제외하기 위한 실험적 지원이 추가되었습니다.](https://github.com/newrelic/newrelic-php-agent/pull/37) 이는 계측되는 파일 수를 줄여 전반적인 Wordpress 계측 오버헤드를 낮추지만, 제외된 하위 경로의 코드에 대한 가시성을 잃는 단점이 있습니다. 이는 ini 파일 설정 `newrelic.framework.wordpress.hooks_skip_filename`을(를) 사용하여 활성화할 수 있습니다.

### 버그 수정

### 지지 성명

* 뉴렐릭은 에이전트를 정기적으로, 최소 3개월마다 업그레이드할 것을 권장합니다. 이 릴리스를 기준으로 지원되는 가장 오래된 버전은 [8.4.0](https://docs.newrelic.com/docs/release-notes/agent-release-notes/php-release-notes/php-agent-840231)입니다.
