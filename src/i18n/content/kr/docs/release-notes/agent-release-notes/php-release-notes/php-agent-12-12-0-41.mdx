## 뉴렐릭 PHP 에이전트 v12.12.0.41

### 버그 수정

* MongoDB 라이브러리 버전 1.21.4 및 2.4.1 이상에서 MongoDB 데이터베이스 및 컬렉션 이름 조회를 수정했습니다. ([#1301](https://github.com/newrelic/newrelic-php-agent/pull/1301))
* 여러 에이전트가 하나의 데몬에 보고할 때 데몬의 충돌을 유발할 수 있는 데몬 메트릭 수집의 데이터 경합을 수정했습니다. ([#1310](https://github.com/newrelic/newrelic-php-agent/pull/1310))
* 포착되지 않은 예외 발생 후에도 소멸자가 실행되도록 `E_DONT_BAIL`을(를) PHP 오류 핸들러에 전달합니다. ([#1317](https://github.com/newrelic/newrelic-php-agent/pull/1317))
* 충돌이나 잘못된 오류 그룹 이름을 방지하기 위해 `newrelic_set_error_group_callback()`에 전달된 콜백에 대한 참조를 유지합니다. ([#1329](https://github.com/newrelic/newrelic-php-agent/pull/1329))
* 응답을 읽은 후 Predis 명령어 시작 시간을 제거합니다. ([#1315](https://github.com/newrelic/newrelic-php-agent/pull/1315))

### 보안 업데이트

* 데몬을 빌드하는 데 사용되는 Go 버전을 1.27.3으로 업그레이드했습니다. ([#1304](https://github.com/newrelic/newrelic-php-agent/pull/1304), [#1320](https://github.com/newrelic/newrelic-php-agent/pull/1320), [#1336](https://github.com/newrelic/newrelic-php-agent/pull/1336))

  * Drupal 7: 2026년 10월 15일부터 모든 PHP 에이전트 버전에서 지원이 중단되었습니다

  * Amazon Linux 2(AL2): 2026년 11월 15일에 지원이 종료됩니다.
  * Red Hat Enterprise Linux 8(RHEL 8): 2026년 11월 15일에 지원이 종료됩니다.
  * PHP 7.2/7.3: 2026년 12월 15일에 지원이 종료됩니다.

* 뉴렐릭은 에이전트를 정기적으로, 그리고 최소 3개월마다 업그레이드할 것을 권장합니다. 지원되는 에이전트 버전 및 EOL 타임라인에 대한 자세한 내용은 [뉴렐릭 PHP 에이전트 EOL 정책 을](https://docs.newrelic.com/docs/apm/agents/php-agent/getting-started/php-agent-eol-policy/) 확인하세요.

* 지원되는 PHP 버전 및 플랫폼에 대한 최신 정보는 [PHP 에이전트 호환성 및 요구 사항](https://docs.newrelic.com/docs/apm/agents/php-agent/getting-started/php-agent-compatibility-requirements/) 페이지를 참조하세요.

<Callout variant="important">
**지원되지 않는 PHP 버전이나 플랫폼을 사용하여 설치하는 경우, PHP 에이전트 패키지의 자동 업데이트 메커니즘을 비활성화하는 것이 좋습니다.** 패키지 업그레이드를 위한 제외 목록에 PHP 에이전트 패키지를 추가하면 됩니다. 또는 PHP 에이전트 패키지를 오래되고 지원되지 않는 기능을 지원하는 에이전트 버전으로 고정할 수도 있습니다. 업그레이드를 막지 못하면 최신 에이전트 릴리스가 설치되고 필수이지만 지원되지 않는 기능에 대한 지원이 중단될 수 있습니다. 이로 인해 APM 데이터 수집이 중단됩니다.

영향을 받는 PHP 에이전트 패키지는 다음과 같습니다.

* newrelic-php5
* newrelic-php5-common
* newrelic 데몬
</Callout>
