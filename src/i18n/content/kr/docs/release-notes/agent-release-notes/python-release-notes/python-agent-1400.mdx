## Notes

이번 파이썬 에이전트 릴리스에서는 Azure App Services에 대한 활용, Azure Service Bus에 대한 계측, 새로운 Kinesis 메서드에 대한 지원 및 v2.10.0 이상에 대한 Google ADK 지원을 추가합니다. 이번 릴리스에서는 `setup.py` 설치 파일뿐만 아니라 httplib에서 분산 트레이스 헤더가 중복되는 문제도 수정합니다.

`easy_install/pip/distribute` 사용하여 에이전트를 설치하세요. [파이썬 패키지 인덱스를](https://pypi.python.org/pypi/newrelic) 통해 `conda` 사용하거나, [Conda-Forge 패키지 인덱스를](https://anaconda.org/conda-forge/newrelic) 통해 을 사용하거나, [뉴렐릭 다운로드 사이트](https://download.newrelic.com/python_agent/release) 에서 직접 다운로드하세요.

## 제거된 기능

* 파이썬 3.9에 대한 지원을 제거했습니다.

  * Python 3.9 reached End-of-Life on October 31, 2025 and is no longer supported by the agent. Please consider upgrading your application to a supported version of Python in order to continue to receive updates to the Python Agent.

## 새로운 기능

* Azure App Service 사용률

  * 엔티티 관계 매핑을 활성화하기 위해 Azure App Service 사용률이 추가되었습니다.
  * 또한 새로운 설정이 추가되었습니다, `utilization.detect_azureappservice`

* [Azure Service Bus](https://pypi.org/project/azure-servicebus/)에 대한 새로운 계측

  * Microsoft Azure Service Bus에 대한 계측이 추가되었습니다.

* 새로운 [Kinesis](https://pypi.org/project/kinesis-python/) 메서드를 위한 새로운 계측

  * 이제 Kinesis에서 `update_stream_record_distribution_strategy` 메서드가 지원됩니다.

## 보안 업데이트

* `urllib3`의 모든 현재 CVE를 해결하기 위해 내부 [urllib3](https://pypi.org/project/urllib3/) 패키지가 `2.8.0` (으)로 업데이트되었습니다.

  * 이는 현재까지 에이전트에 알려진 모든 CVE를 해결합니다.

## 향상된 기능

* [Google ADK](https://pypi.org/project/google-adk/) v2.10.0 이상 버전을 지원합니다.

  * 버전 2.10.0 이상의 Google ADK에 대한 계측이 업데이트되었습니다.

## 벌레

* [httplib](https://github.com/python/cpython/blob/main/Lib/http/client.py)의 중복된 분산 추적 헤더

  * `httplib` 계측이 `traceparent`에 대해 중복 헤더를 생성하여 잘못된 형식의 값을 초래할 수 있는 문제를 수정했습니다.

* `setup.py` 이제 설치 파일이 지원되는 모든 파이썬 버전에서 작동합니다

  * 사용자가 `setup.py` 파일을 직접 사용하여 파이썬 3.12 이상에 파이썬 에이전트를 설치하려는 경우 `ImportError`에 직면하게 됩니다. 이는 파이썬 3.10부터 `distutils`이(가) 더 이상 사용되지 않으며 파이썬 3.12의 표준 라이브러리에서 완전히 제거되었기 때문입니다.

## 지지 성명

최신 에이전트 버전이 출시되면 즉시 업데이트하는 것이 좋습니다. 최신 버전으로 업그레이드할 수 없는 경우, 에이전트를 90일 이내 버전으로 업데이트하세요. 에이전트에게 최신 정보를 제공하는 방법에 대해 [자세히](/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent/) 알아보세요.

에이전트 릴리스 및 지원 날짜에 대한 정보는 뉴렐릭 끌어 당기는 에이전트 [EOL 정책을](/docs/apm/agents/python-agent/getting-started/python-agent-eol-policy/) 참조하세요.
