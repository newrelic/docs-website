## Notes

파이썬 에이전트의 이번 릴리스에서는 새로운 `ai_monitoring.basic_telemetry.enabled` 설정을 통해 AI 모니터링을 기본적으로 활성화하고, `ai_monitoring.enabled` 설정을 지원 중단하며, LangChain 도구 계측에서 발생하는 충돌 문제를 수정했습니다.

`easy_install/pip/distribute` 사용하여 에이전트를 설치하세요. [파이썬 패키지 인덱스를](https://pypi.python.org/pypi/newrelic) 통해 `conda` 사용하거나, [Conda-Forge 패키지 인덱스를](https://anaconda.org/conda-forge/newrelic) 통해 을 사용하거나, [뉴렐릭 다운로드 사이트](https://download.newrelic.com/python_agent/release) 에서 직접 다운로드하세요.

## 변화

* 이제 AI 모니터링이 기본적으로 활성화됩니다.

  * 이제 LLM 계측이 기본적으로 활성화되며, 달리 설정하지 않는 한 에이전트는 `Llm*` 커스텀 대시보드, 스팬 및 메트릭(메시지 콘텐츠 제외)을 전송합니다.
  * 프롬프트 및 응답 콘텐츠를 기록하려면 [`ai_monitoring.record_content.enabled`](/docs/apm/agents/python-agent/configuration/python-agent-configuration/#ai-monitoring-record-content)을(를) `true`(으)로 설정하십시오.
  * 옵트아웃하려면 newrelic.ini에서 [`ai_monitoring.basic_telemetry.enabled`](/docs/apm/agents/python-agent/configuration/python-agent-configuration/#ai-monitoring-basic-telemetry-enabled)을(를) `false` (으)로 설정하거나, 환경 변수 `NEW_RELIC_AI_MONITORING_BASIC_TELEMETRY_ENABLED=false`을(를) 설정하십시오.
  * [`ai_monitoring.enabled`](/docs/apm/agents/python-agent/configuration/python-agent-configuration/#ai-monitoring-enabled) 설정과 `NEW_RELIC_AI_MONITORING_ENABLED` 환경 변수는 지원 중단되었지만, 둘 중 하나를 `false` (으)로 설정해도 AI 모니터링에서 옵트아웃됩니다.

## 버그 수정

* `config` 또는 해당 `metadata`이(가) `None`일 때 [LangChain](https://pypi.org/project/langchain/) `StructuredTool.invoke` 및 `StructuredTool.ainvoke` 계측에서 발생하는 충돌 문제를 수정했습니다.

## 지지 성명

최신 에이전트 버전이 출시되면 즉시 업데이트하는 것이 좋습니다. 최신 버전으로 업그레이드할 수 없는 경우, 에이전트를 90일 이내 버전으로 업데이트하세요. 에이전트에게 최신 정보를 제공하는 방법에 대해 [자세히](/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent/) 알아보세요.

에이전트 릴리스 및 지원 날짜에 대한 정보는 뉴렐릭 끌어 당기는 에이전트 [EOL 정책을](/docs/apm/agents/python-agent/getting-started/python-agent-eol-policy/) 참조하세요.
