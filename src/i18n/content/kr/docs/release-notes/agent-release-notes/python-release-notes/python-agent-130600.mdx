## Notes

이번 파이썬 에이전트 릴리스에서는 OpenSearch, Microsoft Azure SQL, 새로운 Kinesis 메서드 및 새로운 `browser_monitoring.version` 설정에 대한 지원이 추가되었습니다. 또한, Anthropic, MCP 및 Google ADK 계측이 개선되었습니다. 이번 릴리스에서는 botocore(SigV4)의 서명된 헤더 및 Gemini 도구 구문 분석과 관련된 문제도 수정되었습니다.

`easy_install/pip/distribute` 사용하여 에이전트를 설치하세요. [파이썬 패키지 인덱스를](https://pypi.python.org/pypi/newrelic) 통해 `conda` 사용하거나, [Conda-Forge 패키지 인덱스를](https://anaconda.org/conda-forge/newrelic) 통해 을 사용하거나, [뉴렐릭 다운로드 사이트](https://download.newrelic.com/python_agent/release) 에서 직접 다운로드하세요.

## 새로운 기능

* [opensearch-py](https://pypi.org/project/opensearch-py/)를 위한 새로운 계측

  * 공식 OpenSearch 데이터베이스 커넥터에 대한 계측이 추가되었습니다.

* [mssql-python](https://pypi.org/project/mssql-python/)에 대한 새로운 계측

  * Microsoft Azure SQL에 대한 계측이 추가되었습니다.

* 새로운 [Kinesis](https://pypi.org/project/kinesis-python/) 메서드를 위한 새로운 계측

  * 이제 Kinesis에서 다음 메서드가 지원됩니다:

    * `create_channel`
    * `delete_channel`
    * `describe_channel`
    * `list_channels`
    * `update_channel`

* 다음에 대한 새로운 설정 `browser_monitoring.version`

  * 새로운 설정 `browser_monitoring.version`을(를) 통해 사용자는 삽입할 [브라우저 모니터링 에이전트](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/introduction-browser-monitoring/)의 특정 버전을 지정할 수 있습니다.
  * 선택할 수 있는 [지원되는 브라우저 에이전트 버전](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/) 목록을 참조하십시오.

## 개선된 기능

* [anthropic](https://pypi.org/project/anthropic/) 지원 개선.

  * 버전 1.0.0 이상의 Anthropic SDK에 대한 요청 파라미터 파싱이 개선되었습니다.
  * `Messages.with_raw_response.create`을(를) 통한 응답에 대한 새로운 파싱을 통해 LangChain과의 호환성이 향상되었습니다.

* [mcp](https://pypi.org/project/mcp/) v2.0.0 이상을 지원합니다.

  * `mcp` v2.0.0에서 수행된 주요 리팩터링에 따라 계측이 업데이트되었으며 다시 예상대로 작동합니다.

* [Google ADK](https://pypi.org/project/google-adk/) v2.9.0 이상 지원.

  * 버전 2.9.0 이상에서 Google ADK에 대한 계측이 업데이트되었습니다.

## 벌레

* [botocore](https://pypi.org/project/botocore/) (SigV4)의 서명된 헤더 문제를 수정했습니다

  * 이전에는 다른 추적 라이브러리에서 생성된 분산 추적 헤더가 헤더 서명으로 인해 botocore의 계측에 문제를 일으킬 수 있었습니다. 이 문제가 수정되었으며, 이제 서명 전에 분산 추적 헤더가 변경됩니다.

* [Gemini](https://pypi.org/project/google-genai/) 도구 파싱 수정

  * 이전에는 Gemini로 생성된 도구의 일부 인스턴스가 파싱에 실패하고 조용히 실패하여 해당 특정 요청에 대한 응답이 없었습니다. 이 문제가 수정되었습니다.

## 지지 성명

최신 에이전트 버전이 출시되면 즉시 업데이트하는 것이 좋습니다. 최신 버전으로 업그레이드할 수 없는 경우, 에이전트를 90일 이내 버전으로 업데이트하세요. 에이전트에게 최신 정보를 제공하는 방법에 대해 [자세히](/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent/) 알아보세요.

에이전트 릴리스 및 지원 날짜에 대한 정보는 뉴렐릭 끌어 당기는 에이전트 [EOL 정책을](/docs/apm/agents/python-agent/getting-started/python-agent-eol-policy/) 참조하세요.
