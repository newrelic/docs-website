## Notes

이번 파이썬 에이전트 릴리스는 Microsoft 에이전트 프레임워크 및 CrewAI에 대한 계측을 추가하고, LaunchDarkly 기능 플래그 계측 및 스팬 포워딩 지원을 개선하며, 여러 크래시를 수정합니다.

`easy_install/pip/distribute` 사용하여 에이전트를 설치하세요. [파이썬 패키지 인덱스를](https://pypi.python.org/pypi/newrelic) 통해 `conda` 사용하거나, [Conda-Forge 패키지 인덱스를](https://anaconda.org/conda-forge/newrelic) 통해 을 사용하거나, [뉴렐릭 다운로드 사이트](https://download.newrelic.com/python_agent/release) 에서 직접 다운로드하세요.

## 새로운 기능

* [Microsoft 에이전트 프레임워크](https://pypi.org/project/agent-framework/)를 위한 새로운 계측

  * `agent-framework` 패키지의 도구 및 에이전트에 대한 계측이 추가되었습니다.
  * 다중 에이전트 설정은 아직 계측되지 않았습니다.

* [CrewAI](https://pypi.org/project/crewai/)에 대한 새로운 계측

  * `crewai` 패키지의 에이전트, 크루 및 도구에 대한 계측이 추가되었습니다.

## 향상된 기능

* [LaunchDarkly](https://pypi.org/project/launchdarkly-server-sdk/) 기능 플래그 통합을 개선했습니다.

  <Callout title="시사">
  이 기능은 아직 개발 중이지만 꼭 사용해 보시기 바랍니다!

  이 기능은 현재 [출시 전 정책](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy) 에 따라 미리보기 프로그램의 일부로 제공됩니다.
  </Callout>

  * LaunchDarkly와의 공개 프리뷰 통합을 사용하려면 설정 파일에서 `launch_darkly_integration.enabled` 및 `opentelemetry.enabled` 설정을 활성화하십시오.

  * [ldclient](https://pypi.org/project/launchdarkly-server-sdk/)의 기능 플래그 계측을 개선했습니다.

    * 딥 UI 링크를 활성화하기 위해 새로운 `feature_flag.url.full` 속성이 추가되었습니다.
    * LaunchDarkly와 일치하도록 `inExperiment` 키의 대소문자가 변경되었습니다.
    * 기능 플래그 속성에서 falsy 값에 대한 지원을 추가했습니다.
    * 모든 LaunchDarkly 통합 경고가 한 번만 표시되도록 줄였습니다.

  * [ldobserve](https://pypi.org/project/launchdarkly-observability/)에 대한 스팬 포워딩이 개선되었습니다.

    * 딥 UI 링크를 활성화하기 위해 `nr.entity.guid` 및 `nr.entity.url` 스팬 속성이 추가되었습니다.
    * UI에서 올바르게 중첩되도록 스팬 부모 지정을 수정했습니다.

## 버그 수정

* `_add_span_event_event`에서 속성이 `None` 일 때 `TimeTrace`에서 발생하는 크래시가 수정되었습니다.
* 기본값으로 대체할 때 LaunchDarkly `Config` 래퍼에서 발생하는 충돌을 수정했습니다.

## 지지 성명

최신 에이전트 버전이 출시되면 즉시 업데이트하는 것이 좋습니다. 최신 버전으로 업그레이드할 수 없는 경우, 에이전트를 90일 이내 버전으로 업데이트하세요. 에이전트에게 최신 정보를 제공하는 방법에 대해 [자세히](/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent/) 알아보세요.

에이전트 릴리스 및 지원 날짜에 대한 정보는 뉴렐릭 끌어 당기는 에이전트 [EOL 정책을](/docs/apm/agents/python-agent/getting-started/python-agent-eol-policy/) 참조하세요.
