## Notes

이번 파이썬 에이전트 릴리스에서는 레디스 v8.10.0 및 redis-py v8.1.0에 도입된 레디스 명령에 대한 지원이 추가되었습니다. 이번 릴리스에서는 MCP 도구를 사용할 때 LangChain에서 LlmChatCompletion 이벤트가 누락되는 문제도 해결되었습니다.

`easy_install/pip/distribute` 사용하여 에이전트를 설치하세요. [파이썬 패키지 인덱스를](https://pypi.python.org/pypi/newrelic) 통해 `conda` 사용하거나, [Conda-Forge 패키지 인덱스를](https://anaconda.org/conda-forge/newrelic) 통해 을 사용하거나, [뉴렐릭 다운로드 사이트](https://download.newrelic.com/python_agent/release) 에서 직접 다운로드하세요.

## 새로운 기능

* 레디스 v8.10.0 및 redis-py v8.1.0에 도입된 레디스 명령을 추가했습니다.

  * 이제 파이썬 에이전트는 [레디스](https://pypi.org/project/redis/)에서 최근 추가된 다음 명령을 지원합니다:

    * `himport_discard_all`
    * `himport_discard`
    * `himport_prepare`
    * `lmovem`
    * `nrange`
    * `nrevrange`
    * `querylabels`
    * `read`
    * `sdiffcard`
    * `sunioncard`
    * `aliaslist`

## 벌레

* MCP 도구를 사용할 때 Gemini에서 누락된 LlmChatCompletion 이벤트를 수정했습니다.

  * 이전에는`LlmChatCompletionMessages` `LlmChatCompletionSummary` 응답 형식이 기본 JSON이 아닌 경우 [LangChain 에이전트에서 도구를](https://pypi.org/project/langchain/) [사용할 때 Gemini 에서](https://pypi.org/project/google-genai/) 및 이벤트가 누락되었습니다. 이 문제가 해결되었습니다.

* LangChain 및 에이전트 프레임워크에서 트레이스 캐시 ID로 교체되었습니다.

  * 컨텍스트 전파 목적으로 [LangChain](https://pypi.org/project/langchain/) 및 [에이전트 프레임워크](https://pypi.org/project/agent-framework/) 계측을 교체하여 참조 속성에 전체 트레이스 대신 트레이스 캐시 ID만 저장하십시오. 이는 누출이 발생할 경우 이러한 객체가 예기치 않게 직렬화되는 것을 방지하기 위함입니다. 트레이스에는 수 MB의 데이터가 포함될 수 있는 반면 ID는 훨씬 작은 객체입니다.

## 지지 성명

최신 에이전트 버전이 출시되면 즉시 업데이트하는 것이 좋습니다. 최신 버전으로 업그레이드할 수 없는 경우, 에이전트를 90일 이내 버전으로 업데이트하세요. 에이전트에게 최신 정보를 제공하는 방법에 대해 [자세히](/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent/) 알아보세요.

에이전트 릴리스 및 지원 날짜에 대한 정보는 뉴렐릭 끌어 당기는 에이전트 [EOL 정책을](/docs/apm/agents/python-agent/getting-started/python-agent-eol-policy/) 참조하세요.
