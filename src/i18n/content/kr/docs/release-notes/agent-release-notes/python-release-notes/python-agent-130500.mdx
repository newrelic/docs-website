## Notes

이번 파이썬 에이전트 릴리스에서는 Azure CosmosDB에 대한 지원을 추가하고, HTTPX2 및 새로운 LangChain/LangGraph 스트리밍 이벤트 API에 대한 계측을 추가하며, 최신 OpenTelemetry 데이터베이스 시맨틱 규칙에 대한 지원을 추가하고, 불완전한 패키지 보고, 패키지 조회 성능 저하, MySQL 데이터베이스 이름 보고 버그를 포함한 여러 문제를 해결합니다.

`easy_install/pip/distribute` 사용하여 에이전트를 설치하세요. [파이썬 패키지 인덱스를](https://pypi.python.org/pypi/newrelic) 통해 `conda` 사용하거나, [Conda-Forge 패키지 인덱스를](https://anaconda.org/conda-forge/newrelic) 통해 을 사용하거나, [뉴렐릭 다운로드 사이트](https://download.newrelic.com/python_agent/release) 에서 직접 다운로드하세요.

## 새로운 기능

* Azure CosmosDB 지원 추가

  * 이제 파이썬 에이전트는 [Azure Cosmos DB](https://pypi.org/project/azure-cosmos/) 클라이언트 작업을 계측하여 `azure-cosmos` SDK를 통해 수행되는 데이터베이스, 컨테이너 및 사용자 작업에 대한 데이터스토어 메트릭과 트레이스를 보고합니다.

* HTTPX2 지원을 추가했습니다.

  * 이제 파이썬 에이전트는 Pydantic 팀에서 적극적으로 유지 관리하는 [HTTPX2](https://pypi.org/project/httpx2/)의 포크인 [HTTPX](https://pypi.org/project/httpx/)를 지원합니다. HTTPX2에 대한 외부 호출 계측은 동기 및 비동기 클라이언트 모두에 대한 에이전트의 기존 HTTPX 지원을 반영합니다.

* LangChain/LangGraph 스트리밍 이벤트 계측을 추가했습니다.

  * [LangChain](https://pypi.org/project/langchain/) 에이전트에 대한 `astream_events` 계측 지원이 추가되었습니다.
  * `GraphRunStream` 객체에 대한 반복을 포함하여 [LangChain](https://pypi.org/project/langchain/)/[LangGraph](https://pypi.org/project/langgraph/) v3에 대한 `stream_events`/`astream_events` 계측을 추가했습니다.

* 최신 OpenTelemetry 데이터베이스 시맨틱 규칙 지원 추가

  * OpenTelemetry와 함께 파이썬 에이전트를 실행할 때(하이브리드 에이전트 모드), 에이전트는 이제 구형 및 최신 OpenTelemetry 데이터베이스 스팬 속성 이름(`db.name`/`db.namespace`, `db.statement`/`db.query.text`, `db.mongodb.collection`/`db.collection.name`)을 모두 읽으므로 OpenTelemetry 계측 라이브러리가 내보내는 시맨틱 규칙 버전에 관계없이 데이터베이스 트레이싱이 계속 올바르게 작동합니다.

## 벌레

* 뉴렐릭에 대한 불완전한 패키지 보고를 수정했습니다.

  * 이전에는 느린 하베스트 주기 동안 할당된 고정 시간 창보다 모듈 검색에 시간이 더 오래 걸리고 에이전트 재시작 후 패키지 목록이 새로 고쳐지지 않은 경우, 파이썬 에이전트가 뉴렐릭에 보고된 환경 데이터에서 일부 설치된 패키지를 누락할 수 있었습니다. 이제 패키지 캡처가 빠른 하베스트 주기 동안 실행되고 에이전트 종료/재시작 시 완전히 다시 캡처되므로 보고된 패키지 목록이 완전합니다.

* 패키지 버전 조회의 오버헤드를 줄였습니다.

  * 이전에는 설치된 패키지 버전을 조회할 때마다 모든 패키지에 대해 파일 시스템을 다시 스캔하여 에이전트 초기화 중 설치된 패키지 수에 비례하는 O(n^2) 시간 페널티가 발생했습니다. 이 오버헤드를 방지하기 위해 이제 첫 번째 조회 후 `importlib.metadata.packages_distributions()`의 결과가 캐시됩니다.

* 지정된 애플리케이션을 올바르게 통과하도록 `get_linking_metadata`을(를) 수정했습니다.

  * 이전에는 `newrelic.agent.get_linking_metadata(application=...)`을(를) 호출하면 `application` 인수를 무시하고 항상 기본 애플리케이션에 대한 연결 메타데이터를 반환했습니다. 이는 둘 이상의 애플리케이션에 보고하는 프로세스에 영향을 미쳤습니다. 지정된 애플리케이션이 이제 올바르게 전달됩니다.
  * 기여해 주신 [ckarnell](https://github.com/ckarnell) 님께 감사드립니다!

* `database` 키워드 인수를 사용할 때 MySQL 데이터베이스 이름 보고를 수정했습니다.

  * 이전에는 에이전트가 [mysql-connector-python](https://pypi.org/project/mysql-connector-python/) 연결 인수에서 데이터베이스 이름을 구문 분석할 때 구형 `db` 키워드 인수만 확인했기 때문에 최신 `database` 키워드 인수를 사용하여 만든 연결은 데이터스토어 메트릭에 데이터베이스 이름을 보고하지 않았습니다. 이제 에이전트는 `database`을(를) 먼저 확인하고 `db`(으)로 대체합니다.

* LangGraph v1.1+ `GraphOutput` 값에 액세스할 때 발생하는 경고 수정

  * 이전에는 [LangGraph](https://pypi.org/project/langgraph/) v1.1+ 계측이 더 이상 사용되지 않는 항목 액세스 구문을 사용하여 `GraphOutput` 반환 값에 액세스하여 사용 중단 경고를 트리거했습니다. 이제 에이전트는 `GraphOutput.value`을(를) 직접 읽습니다.

## 지지 성명

최신 에이전트 버전이 출시되면 즉시 업데이트하는 것이 좋습니다. 최신 버전으로 업그레이드할 수 없는 경우, 에이전트를 90일 이내 버전으로 업데이트하세요. 에이전트에게 최신 정보를 제공하는 방법에 대해 [자세히](/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent/) 알아보세요.

에이전트 릴리스 및 지원 날짜에 대한 정보는 뉴렐릭 끌어 당기는 에이전트 [EOL 정책을](/docs/apm/agents/python-agent/getting-started/python-agent-eol-policy/) 참조하세요.
