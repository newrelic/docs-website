## Notes

#### 특징

* `ai_monitoring.basic_telemetry.enabled`을(를) 추가하고 기본 AI 모니터링을 기본값으로 활성화했습니다 ([#4330](https://github.com/newrelic/node-newrelic/pull/4330)) ([c126335](https://github.com/newrelic/node-newrelic/commit/c1263354150cd30349d316acc162f5388bc3449a))

  * LLM 계측은 이제 기본적으로 활성화되며, 별도로 구성하지 않는 한 `Llm*` 커스텀 대시보드, 스팬 및 메트릭(메시지 내용 제외)을 전송합니다. 옵트아웃하려면 `newrelic.js`에서 `ai_monitoring.basic_telemetry.enabled`을(를) `false` (으)로 설정하거나 `NEW_RELIC_AI_MONITORING_BASIC_TELEMETRY_ENABLED` 환경 변수를 `false`(으)로 설정하십시오.
  * `ai_monitoring.enabled` 및 `NEW_RELIC_AI_MONITORING_ENABLED` 환경 변수는 더 이상 사용되지 않으며 향후 주요 버전에서 제거될 예정이지만, 둘 중 하나를 false로 설정해도 옵트아웃됩니다.
