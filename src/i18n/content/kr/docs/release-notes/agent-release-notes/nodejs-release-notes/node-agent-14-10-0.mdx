### 특징

* `@opentelemetry/api@1.10.0`에 대한 지원이 추가되었습니다 ([#4392](https://github.com/newrelic/node-newrelic/pull/4392)) ([504490d](https://github.com/newrelic/node-newrelic/commit/504490dd9540e6d5312441d9feec29b47bfe959a))

  * `@opentelemetry/api-logs`을(를) 직접 사용하는 고객은 이를 제거하고 `@opentelemetry/api` 1.10.0+를 사용하도록 업데이트해야 합니다. 자세한 내용은 [OpenTelemetry API 변경 로그](https://github.com/open-telemetry/opentelemetry-js/blob/main/api/CHANGELOG.md#1100)를 참조하십시오.
  * 로깅 라이브러리에 대한 서드파티 계측을 등록하는 고객은 다음과 같이 업데이트해야 합니다: `@opentelemetry/instrumentation-pino`을(를) 0.70.0+로, `@opentelemetry/instrumentation-bunyan`을(를) 0.69.0+로, `@opentelemetry/instrumentation-console`을(를) 0.6.0+로, 또는 `@opentelemetry/instrumentation-winston`을(를) 0.69.0+로

### 지지 성명

최신 에이전트 버전이 출시되면 즉시 업데이트하는 것이 좋습니다. 최신 버전으로 업그레이드할 수 없는 경우, 에이전트를 90일 이내 버전으로 업데이트하세요. [에이전트에게 최신 정보를 제공하는 방법](/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent/) 에 대해 자세히 알아보세요.

에이전트 릴리스 및 지원 날짜에 대한 정보는 뉴렐릭 Node.js 에이전트 [EOL 정책](/docs/apm/agents/nodejs-agent/getting-started/nodejs-agent-eol-policy/) 을 참조하세요.
