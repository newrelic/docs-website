### 알아채다

* LLM 계측은 이제 기본적으로 활성화되며, 다르게 구성되지 않는 한 `Llm*` 커스텀 대시보드, 스팬 및 메트릭(메시지 콘텐츠 제외)을 전송합니다. 옵트아웃하려면 `newrelic.config`에 `<aiMonitoring><basicTelemetry enabled="false" /></aiMonitoring>`을(를) 추가하거나 `NEW_RELIC_AI_MONITORING_BASIC_TELEMETRY_ENABLED` 환경 변수를 `false`(으)로 설정하십시오. `<aiMonitoring>`의 `enabled` 속성과 `NEW_RELIC_AI_MONITORING_ENABLED` 환경 변수는 더 이상 사용되지 않으며 향후 메이저 릴리스에서 제거될 예정이지만, 둘 중 하나를 `false` (으)로 설정해도 옵트아웃됩니다. ([0b65f33](https://github.com/newrelic/newrelic-dotnet-agent/commit/0b65f338448a6a6213a1db59c4a55844cb4c63af))
* 이번 릴리스부터 download.newrelic.com에 게시되는 모든 파일에는 빌드 출처 증명이 포함되며, `gh attestation verify <file> --repo newrelic/newrelic-dotnet-agent`을(를) 사용하여 확인할 수 있습니다. download.newrelic.com에 있는 모든 버전의 파일에 대한 SHA-256 해시는, 이전 버전을 포함하여 에이전트 저장소의 `release-data/download-site-hashes.json`에 게시됩니다. ([99335b1](https://github.com/newrelic/newrelic-dotnet-agent/commit/99335b1f2500ead5e0662b0f6646e86bc68caaba))
* 이번 릴리스부터 모든 패키지(MSI, ZIP, NuGet, deb, rpm 및 tar.gz) 내의 뉴렐릭 바이너리는 Authenticode로 서명되며, MSI 서명을 포함한 서명에는 타임스탬프가 포함됩니다. 타임스탬프는 서명 인증서가 만료된 후에도 서명을 유효하게 유지합니다. ([99335b1](https://github.com/newrelic/newrelic-dotnet-agent/commit/99335b1f2500ead5e0662b0f6646e86bc68caaba))
