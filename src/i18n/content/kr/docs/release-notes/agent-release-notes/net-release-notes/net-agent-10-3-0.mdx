### 새로운 기능

* 커스텀 대시보드 한도 증가
  * 이 버전은 커스텀 대시보드의 기본 제한을 분당 10,000개 이벤트에서 분당 30,000개 이벤트로 늘립니다. 커스텀 대시보드가 제한되는 시나리오에서, 이 변경 사항을 통해 더 많은 커스텀 대시보드를 뉴렐릭으로 보낼 수 있습니다. 또한 분당 100,000개의 이벤트라는 구성 가능한 새로운 최대 한도가 있습니다. 한도를 변경하려면 [max\_samples\_stored에 대한 문서](https://docs.newrelic.com/docs/apm/agents/net-agent/configuration/net-agent-configuration/#custom_events)를 참조하십시오. 변경 사항과 커스텀 대시보드가 삭제되는지 확인하는 방법에 대해 자세히 알아보려면 [Explorers Hub 게시물](https://support.newrelic.com/s/hubtopic/aAX8W0000008dby/send-more-custom-events-with-the-latest-apm-agents)을 참조하십시오. [#1284](https://github.com/newrelic/newrelic-dotnet-agent/pull/1284)
