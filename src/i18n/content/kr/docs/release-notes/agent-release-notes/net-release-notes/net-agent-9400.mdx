### 새로운 기능

([#799](https://github.com/newrelic/newrelic-dotnet-agent/pull/799))

## 지지 성명

뉴렐릭은 에이전트를 정기적으로, 최소 3개월마다 업그레이드할 것을 권장합니다. 이 릴리스를 기준으로 지원되는 가장 오래된 버전은 [.NET 에이전트 8.24.244.0](/docs/release-notes/agent-release-notes/net-release-notes/net-agent-8242440)입니다.

## 업그레이드

* [.NET 에이전트를 업데이트](/docs/agents/net-agent/installation-configuration/update-net-agent) 하려면 표준 절차를 따르세요.
* 특히 오래된 에이전트에서 업그레이드하는 경우, 주요 변경 사항 목록과 [구형 .NET 에이전트 업그레이드](/docs/agents/net-agent/troubleshooting/upgrade-legacy-net-agents) 절차를 검토하십시오.
