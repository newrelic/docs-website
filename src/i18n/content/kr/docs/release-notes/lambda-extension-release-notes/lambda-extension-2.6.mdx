## Notes

* 원활한 교차 텔레메트리 탐색을 지원하기 위해 모든 AWS Lambda 로그 항목에 `trace.id` 상관관계를 추가했습니다.
* * APM 연결 실패 복원력을 개선하고 프로세스 종료 중 텔레메트리 삭제에 대한 상세한 진단 보고를 추가했습니다.

## 결정된

* 일시적인 네트워크 문제 중 조용한 페이로드 삭제를 제거하기 위해 안정적인 텔레메트리 전달을 보장했습니다.
* APM 연결 재시도가 지정된 APM 경로에 유지되도록 문제를 해결했습니다.
* APM 재시도가 APM 경로에 유지됩니다.
