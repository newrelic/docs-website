### 버그 수정

* **더 빠르고 복원력이 뛰어난 채팅 패널:** 이제 채팅이 더 빠르게 열리고, 폭증하는 requests를 대기열에 추가하며, 처음에 오류를 표시하는 대신 일시적인 네트워크 문제로 인해 실패한 호출을 자동으로 재시도합니다.
* **사용량 한도 도달 시 더 명확한 메시지 제공:** 이제 일반적인 오류 대신, 시간당 요청 한도 또는 일일 사용량 한도에 도달했을 때 Autopilot이 구체적으로 알려줍니다.
* **더욱 안정적인 엔티티 검색:** 이제 엔티티 조회 시 퍼지 매칭을 올바르게 수행하며, 사용자가 요청하는 계정의 엔티티를 우선적으로 선택할 가능성이 높아져 첫 번째 시도에서 올바른 엔티티를 찾을 가능성이 더 커졌습니다.
* **잘못된 시간 범위 수정:** 이전에는 &quot;IST&quot;가 인도 표준시 대신 이스라엘 표준시로 잘못 인식되어, 분석 시간 범위가 몇 시간씩 어긋나거나 예기치 않은 유효성 검사 오류가 발생할 수 있었습니다. 이제 IST가 올바르게 해석되며, 다른 여러 자연어 시간 구문 분석 수정 사항도 함께 적용되었습니다.
* **More accurate chart results:** Valid chart values are no longer stripped from a visualization when it shouldn&apos;t have been.
* **커버리지 격차 질문에 대해 이제 더 완전한 답변이 제공됩니다:** 모니터링 커버리지 격차(예: 누락된 공지 또는 엔티티 커버리지)에 대해 질문할 때 Autopilot의 전용 커버리지 격차 분석을 실제로 사용하지 않아 덜 완전한 답변이 제공되던 문제를 수정했습니다.
* **첨부된 컨텍스트가 불완전할 때 실패하는 requests가 줄어듭니다:** 첨부된 컨텍스트가 불완전한 request가 원래 질문으로 돌아가는 대신 완전히 실패할 수 있던 문제를 수정했습니다.
