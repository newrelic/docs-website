### 새로운 기능

* **호출 시 더 심층적인 근본 원인 분석:** 이제 Autopilot은 인시던트 및 Slack에서 트리거된 조사를 포함한 더 많은 진입점에서 공지를 발생시킨 코드 변경 사항까지 트레이스하도록 지원하므로, 전체 배포 기록을 일일이 확인하지 않고도 문제를 정확히 찾아낼 수 있습니다.
* **차트뿐만 아니라 전체 데이터 확인:** 이제 도구 결과에 시각화와 함께 기본 데이터가 표시되므로 Autopilot이 답변의 근거로 삼은 내용을 더 쉽게 확인할 수 있습니다.
* **단순한 평균이 아닌 간헐적인 스파이크 발견:** 이제 메트릭 분석에서 백분위수 세부 정보와 추세 기록을 표시하므로 평균만으로 파악할 때보다 짧은 스파이크를 더 쉽게 포착할 수 있습니다.
* **단일 요청으로 한 달 전체의 알림에 대해 문의하십시오:** 엔티티 범위 쿼리에 대한 공지 룩백 기간이 7일에서 30일로 확대되었으며, 이제 크기가 초과된 요청은 완전히 거부되는 대신 자동으로 축소됩니다.
* **세션으로 바로 이동:** 이제 응답에 브라우저 및 모바일용 직접 세션 링크가 포함되므로, 찾아다닐 필요 없이 Autopilot이 중단한 부분부터 다시 시작할 수 있습니다.

**GitHub MCP 통합 기능 업데이트(퍼블릭 프리뷰)**

이제 Autopilot의 GitHub 통합은 활성 알림을 배포 및 릴리스 기록에 더 직접적으로 연결하므로 도구를 전환하지 않고도 분류할 수 있습니다.

* **작업을 중복하기 전에 진행 중인 수정 사항 확인:** 공지 분류 중에 Autopilot은 이제 영향을 받는 서비스를 이미 대상으로 하는 열려 있는 pull 요청에 대해 GitHub를 확인하므로, 자체 작업을 시작하기 전에 핫픽스 또는 관련 수정 사항이 이미 진행 중인지 확인할 수 있습니다.
* **공지가 발생하는 즉시 버전 드리프트 발견:** Autopilot은 이제 실제로 배포된 릴리스를 인시던트가 시작되었을 때 실행 중이던 버전과 비교하여, 문제의 원인이 될 수 있는 최근 롤아웃 또는 확인되지 않은 배포를 표시합니다.

### 버그 수정

* **고유값을 계산할 때 실패할 수 있는 쿼리 수정:** 고유한 항목을 계산해야 하는 질문 ― 특정 오류가 발생한 고유 사용자가 몇 명인지 등 ― 은 Autopilot이 잘못된 NRQL 쿼리를 작성하여 응답하지 못하게 할 수 있었습니다. 이제 Autopilot이 이를 더 잘 처리하도록 안내되어, 이러한 질문에서 오류가 발생할 가능성이 줄어듭니다.
* **거부되는 오류 분석 응답 감소:** 자세한 오류 내역을 요청할 때 전달하기에 너무 커서 거부될 수 있는 문제를 수정했습니다.
* **대용량 로그 분석 시 시간 초과 감소:** 로그 분석에 할당된 시간을 늘려 로그 볼륨이 큰 계정에서 시간 초과가 발생할 가능성을 줄였습니다.
* **실행을 중지하려면 취소하십시오:** 이제 채팅 패널에서 조사를 취소하면 백앤드에서의 실행이 중지됩니다.
* **더 빠르고 깔끔한 채팅 패널 로드:** 이제 채팅 패널은 전체 에이전트 목록을 기다리는 대신 Ask AI 및 Autopilot을 먼저 로드하며, 에이전트 드롭다운 메뉴에서 더 이상 두 항목을 중복으로 표시하지 않습니다.
* **더욱 일관된 지식 기반 근거:** 이제 빠르고 직접적인 답변과 공지 분류 조사는 답변하기 전에 지식 기반을 더욱 일관되게 활용합니다.
* **GitHub 조사에서 더 정확한 배포 상태:** 서비스 릴리스 상태 보고가 개선되었습니다.
* **Autopilot이 답변을 찾을 수 없을 때 더 명확한 안내 제공:** 일반적인 &quot;문제가 발생했습니다&quot; 메시지를 질문을 바꿔서 다시 시도하라는 더 유용한 안내로 대체했습니다.
* **오해의 소지가 있는 연결 오류 수정:** 로그인 관련 리디렉션이 만료된 연결로 보고되고 있었으나, 이제 올바르게 식별됩니다.
