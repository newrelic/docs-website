## 새로워진 사항

### Autopilot: 더 안정적인 분석

* **더욱 정확해진 이상 징후 탐지:** 트랜잭션 종속성 분석에 이제 더 엄격한 임계값이 사용됩니다. 이전 설정은 지나치게 민감하여 노이즈를 이상 징후로 표시했습니다. 또한 다운스트림 종속성 분석은 상관관계와 인과관계를 더 명확하게 구분하여 추측에 기반한 근본 원인 기여를 줄입니다.
* **실제 데이터에 기반한 추세 비교:** Autopilot이 현재 오류율 또는 개수를 이전 기간과 비교할 때, 이제 해당 기준은 검증된 NRQL 쿼리에서 가져옵니다.
* **더 긴 조사를 안정적으로 완료:** 일부 조사 흐름에서 컨텍스트 창 압축이 필요할 때 제대로 수행되지 않던 버그를 수정했습니다. 압축 중 오류가 발생하더라도 조사 진행 상황이 손실되지 않고 보존됩니다. 또한 다른 페이지로 이동할 때 조사가 제대로 중지되어 브라우저 리소스를 확보합니다.
* **정확한 활성 이슈 수:** 계정의 활성 이슈 수를 요청할 때 더 정확한 이슈 수를 반환하도록 수정 사항을 추가했습니다.
* **깔끔하게 렌더링되는 Slack 응답:** 이제 Slack 공지 및 워크플로우 응답에서 마크다운 테이블과 구조화된 형식(헤더, 구분선 및 목록)이 올바르게 표시됩니다.
* **EU 엔티티 확인 수정:** EU에서 실행되는 Autopilot이 Kubernetes 에이전트를 찾기 어렵게 만들었던 버그를 수정했습니다.
* **시간대 및 컨텍스트 유지:** 조사 중인 시간대와 엔티티 컨텍스트가 이제 전체 세션 동안 올바르게 유지됩니다. 이전에는 여러 컨텍스트 소스가 있을 때 컨텍스트가 손실될 수 있었습니다.
* **비교 연산자 및 특수 문자 사용 시 UI 렌더링에 대한 일반적인 수정:** 비교 연산자나 기타 특수 문자가 포함된 NRQL 쿼리가 응답 시각화에서 더 이상 깨지지 않습니다.
* **오탐이 줄어든 개선된 프롬프트 주입 식별:** Autopilot은 더 이상 오해의 소지가 있는 &quot;프롬프트 주입&quot; 경고와 함께 무해한 채팅 내 메모(예: 컨텍스트 제공 또는 세부 정보 명확화)를 잘못 거부하지 않습니다. 이제 가드레일의 범위가 적절하게 지정되어 유효한 requests가 정상적으로 진행됩니다.
* **메모리 리콜 개선:** Autopilot이 다중 메모리 조회에서 사실을 찾지 못하게 하는 버그와 유효한 메모리에 대한 부적절한 플래그를 수정했습니다.
* **기본 설정의 올바른 적용:** Autopilot은 더 이상 명시된 기본 설정(예: 선호하는 호칭)을 기억할 수 없다고 잘못 안내하지 않습니다. 이제 대화 기본 설정이 인식되고 존중됩니다.
* **올바른 계정을 참조하는 문서 인용:** Autopilot이 RAG 조회에서 문서 또는 엔티티 정보를 인용할 때, 이제 귀하의 계정에 속한 엔티티 GUID를 참조합니다.
* **정확한 시계열 결과 보고:** 유효한 데이터를 반환하는 TIMESERIES NRQL 쿼리가 더 이상 결과가 없는 것으로 잘못 보고되지 않습니다.
* **반복되는 추론 텍스트 제거:** 조사 중 Autopilot의 사고 표시에서 동일한 추론 텍스트가 여러 번 나타날 수 있는 버그를 수정했습니다.
* **브라우저 내 채팅 패널의 안정성 향상:** 대화가 많은 계정에서 채팅 기록을 로드할 때 브라우저 탭 충돌을 일으킬 수 있는 메모리 누수를 수정했습니다. 또한 여러 브라우저 탭에서 AI 채팅 패널을 동시에 열었을 때 발생하는 충돌을 수정했으며, 스트림 중간에 새 대화를 시작할 때 동시 에이전트 스트림이 충돌하는 것을 방지했습니다.
* **더 나은 시각화 요약:** 이제 조사 응답에서 NRQL 쿼리와 그에 따른 시각화를 더 완벽하게 캡처하여 요약 카드에서 더 풍부한 컨텍스트를 제공합니다.
* **인시던트 조사가 관련 이슈를 따름:** 여러 계정에 걸쳐 관련 이슈가 있는 주요 인시던트를 조사할 때, 이제 Autopilot은 상위 인시던트의 계정을 기본값으로 사용하는 대신 자체 계정 ID를 사용하여 각 관련 이슈를 해결합니다.
* **UI 개선:** 이제 피드백 평가는 명시적으로 제출할 때만 유지됩니다. 작업 아이콘이 항상 표시됩니다(더 이상 마우스 오버 시 숨겨지지 않습니다). 복사할 콘텐츠가 있을 때까지 대화 복사가 올바르게 비활성화됩니다. 슬래시 명령 커넥터 이름이 올바르게 표시됩니다.

### GitHub MCP 통합 기능(퍼블릭 프리뷰)

<Callout title="시사">
  이 기능은 아직 개발 중이지만 꼭 사용해 보시기 바랍니다!

  이 기능은 현재 [출시 전 정책](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy) 에 따라 미리보기 프로그램의 일부로 제공됩니다.
</Callout>

공지가 배포 관련 회귀를 가리킬 때 첫 번째 질문은 거의 항상 &quot;무엇이 배포되었습니까?&quot;입니다. 결국 뉴렐릭 인시던트, 변경 추적 이벤트 및 GitHub PR 사이를 전환하여 스토리를 종합하게 됩니다. Autopilot을 GitHub에 연결하여 변경 추적 배포 이면의 pull 요청을 가져오고 &quot;배포된 내용&quot; 스토리를 인라인으로 반환할 수 있습니다.

* **배포를 PR에 연결:** 조사 중 Autopilot이 커밋 SHA가 있는 변경 추적 이벤트를 식별하면, 연결된 pull 요청을 가져와 조사 응답의 일부로 번호, 제목, 설명, 작성자 및 URL을 반환합니다. 탭을 전환할 필요가 없습니다.
* **변경된 내용 요약:** Autopilot은 인시던트 인접 배포를 제공한 PR에 대해 터치된 파일과 추가 및 삭제된 줄 수를 보고합니다.
* **동일한 스레드에서 후속 질문:** PR이 기록되면 Autopilot에 이전 배포와 비교하거나 변경 사항을 실패 신호와 연관시키도록 요청할 수 있습니다. GitHub 컨텍스트는 해당 조사에서 활성 상태로 유지됩니다.
* **모든 진입점에서 작동:** GitHub 컨텍스트는 SRE 공지 대상, Slack 메시지 또는 AI 채팅 패널에 의해 트리거된 조사로 흐릅니다. Autopilot은 커밋 SHA가 있는 변경 추적 이벤트가 있을 때마다 자동으로 PR을 가져옵니다.
* **개인 액세스 토큰을 통한 읽기 전용 액세스:** Autopilot은 `Pull requests: Read`, `Contents: Read` 및 `Metadata: Read`로 범위가 지정된 구성된 GitHub PAT를 사용합니다. PR을 생성하거나, 댓글을 게시하거나, 브랜치를 병합하거나, 소스 코드를 저장하지 않습니다. 이 프리뷰는 퍼블릭 **github.com만** 지원합니다. **GitHub Enterprise Server(자체 호스팅) 및 GitHub Enterprise Cloud**는 아직 지원되지 않습니다.
* **조직 수준 설정:** 뉴렐릭 조직 관리자가 **Configure → Autopilot → External MCP connections**에서 GitHub를 한 번 연결합니다. PAT는 뉴렐릭 Secrets Service에서 저장 시 암호화되고, 조직에 격리되며, 단일 조사 기간 동안에만 요청 범위 메모리로 검색됩니다.

**전제 조건:** 활성 Autopilot 설정, 뉴렐릭으로 흐르는 커밋 SHA로 구성된 변경 추적, 세분화된 PAT를 생성하기 위한 GitHub 조직 관리자 액세스 권한, 뉴렐릭 조직 관리자 액세스 권한 및 계정에서 활성화된 `sre_agent_github_integration` 기능 플래그가 필요합니다. 플래그를 확인하려면 뉴렐릭 계정 팀에 문의하십시오.
