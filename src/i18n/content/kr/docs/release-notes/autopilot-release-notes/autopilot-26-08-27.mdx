## 새로워진 사항

### Autopilot: 더 빠르고 안정적인 조사

* **더 빠른 조사:** 이제 Autopilot이 단계를 병렬로 디스패치하므로, 특히 여러 하위 조사로 분산되는 requests에서 처리 시간이 단축되고 시간 초과가 줄어듭니다.
* **Fast Path Routing:** 단순한 requests에 대해 즉각적인 답변을 얻을 수 있습니다. 새로운 fast-path 엔진이 간단한 질문을 인식하고 불필요한 단계를 건너뛰어 더 빠르게 응답을 확인할 수 있습니다.
* **스레드에 메모리 저장:** 채팅에서 Autopilot에게 정보를 메모리에 저장하도록 지시하면 해당 컨텍스트가 장기 메모리에 자동으로 추가됩니다.
* **원클릭 NRQL 복사:** 채팅 패널에서 한 번의 클릭으로 생성된 NRQL 쿼리를 클립보드에 직접 복사하십시오.
* **원클릭 채팅 확장:** 한 번의 클릭으로 채팅 패널을 즉시 최대화하여 더 크고 깔끔한 작업 공간을 확보하십시오.
* **쿼리 탐색 바로 가기:** 프롬프트 상자에서 위쪽(↑) 및 아래쪽(↓) 화살표 키를 사용하여 과거 쿼리를 순환하고 다시 선택하십시오.
* **더욱 안정적인 응답:** 조사를 개선하고 더 완전한 답변을 제공하기 위해 여러 문제를 수정했습니다. 이제 시간당 사용 한도에 도달하면 원시 오류 대신 명확한 메시지가 표시되며, 조사가 실제로 완료되기 전에 완료된 것처럼 보일 수 있는 드문 문제를 수정했습니다.

### GitHub MCP 통합 기능 업데이트(퍼블릭 프리뷰)

<Callout title="시사">
  이 기능은 아직 개발 중이지만 꼭 사용해 보시기 바랍니다!

  이 기능은 현재 [출시 전 정책](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy) 에 따라 미리보기 프로그램의 일부로 제공됩니다.
</Callout>

**이제 GitHub Enterprise Cloud 지원:** 이제 GitHub MCP 통합이 퍼블릭 GitHub 외에도 GitHub Enterprise Cloud와 함께 작동합니다. 조직에서 `YOURSUBDOMAIN.ghe.com` 인스턴스를 사용하는 경우 동일한 PAT 흐름을 사용하여 Autopilot에 연결하십시오. 유일한 새로운 단계는 설정 중에 GHE 하위 도메인 URL을 입력하는 것입니다. 두 가지 조사 사용 사례 모두 `GHE.com`에서 작동합니다: 변경으로 트리거된 근본 원인 식별 및 수동 PR/커밋 조회.

지원되는 GitHub 환경:

| 연결 유형                   | URL 형식                  | 유효성               |
| ----------------------- | ----------------------- | ----------------- |
| 퍼블릭 GitHub              | `github.com`            | 프리뷰(2.1부터)        |
| GitHub Enterprise Cloud | `YOURSUBDOMAIN.ghe.com` | 프리뷰 ― 2.2의 새로운 기능 |

**`GHE.com` 사용자를 위한 설정 변경:** **Configure &gt; Autopilot &gt; External MCP connections**에서 GitHub를 연결할 때 GitHub URL 필드에 `github.com` 대신 `YOURSUBDOMAIN.ghe.com`을(를) 입력하십시오. PAT 권한은 변경되지 않습니다: pull 요청: Read, Contents: Read, 메타데이터: Read. `GHE.com` 조직에서 SAML SSO를 적용하는 경우 뉴렐릭에 입력하기 전에 GitHub에서 SSO에 대한 PAT를 승인하십시오 ― 승인되지 않은 토큰은 처음 사용할 때 `403`과(와) 함께 실패합니다.

**적극적으로 추적하는 리포지터리로 PAT 범위 지정:** Autopilot은 토큰이 승인하는 모든 저장소에서 PR 설명 및 파일 변경 메타데이터를 읽습니다.
