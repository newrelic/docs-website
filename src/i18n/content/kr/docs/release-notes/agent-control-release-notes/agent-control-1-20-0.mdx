### 새로운 기능

* Kubernetes: 이제 `uninstall-agent-control`에서 `--release-name`은(는) 선택 사항이며, 이를 생략하면 릴리스 자체의 HelmRelease/HelmRepository CR 삭제를 건너뜁니다.
* 온호스트: nri-apache 및 nri-nginx 에이전트 유형을 추가했습니다.
* 온호스트: nri-postgresql agentType을 추가했습니다.
* 온호스트: nri-MySQL agentType을 추가했습니다.
* 온호스트: nri-memcached 에이전트 유형을 추가했습니다.
* 교체된 로그 파일은 이제 30일 동안 보존됩니다.
* 에이전트 유형 정의 파일의 스키마 수준 유효성 검사를 위해 `newrelic-agent-control-cli` 및 `newrelic-agent-control-k8s-cli`에 `agent-type validate --file <path>` 하위 명령을 추가했습니다.
* 의미론적 유효성 검사를 통해 `agent-type validate`을(를) 확장했습니다: `deployment`의 모든 `${nr-var:X}` 참조에는 일치하는 `variables` 선언이 있어야 합니다.
* 원격 에이전트 유형 레지스트리에 대한 캐시를 활성화합니다.
