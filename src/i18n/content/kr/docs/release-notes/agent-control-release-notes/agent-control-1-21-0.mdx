### 새로운 기능

* Windows 파일 시스템: 사용하지 않는 코드를 제거하고 Windows 상호작용을 위해 상위 수준 API를 사용했습니다.
* 시작 시 구성된 에이전트 유형 OCI 저장소에 연결할 수 있을 때 `com.newrelic.remoteAgentTypeRepoReachable` OpAMP 사용자 지정 기능을 보고합니다.
* 온호스트: nri-flex agentType을 추가했습니다.

### 버그 수정

* Windows: 에이전트 컨트롤의 관리 디렉터리 하위에 있는 파일이 사용할 수 없는 권한으로 남겨지는 문제를 수정했습니다. 이제 관리 디렉터리는 상속 가능한 관리자 ACE를 사용하며, 에이전트 컨트롤은 시작 시 ACE 복구를 시도합니다.
