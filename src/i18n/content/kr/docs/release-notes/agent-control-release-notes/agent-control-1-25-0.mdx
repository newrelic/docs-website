### 새로운 기능

* Linux: 지원/게시되는 플랫폼으로 Debian 13(trixie)을 추가했습니다.
* Linux: v1.2.0 이전 구형 온호스트 폴더 마이그레이션을 다음에서 제거했습니다. `newrelic-agent-control-cli`
* 서버 측 &quot;governance&quot; 플로우를 위해 Variants 지원이 제거되었습니다.
* 서버 측의 &quot;거버넌스&quot; 흐름을 위해 정규식 기반 원격 구성 유효성 검사가 제거되었습니다.

### 버그 수정

* On-host: 정상적인 종료 시마다 발생하는 불필요한 `error`수준 로그 `"cannot forward agent control event"`을(를) 수정했습니다, 상태 서버 브리지는 이제 명시적인 중지 신호를 통해서만 종료되며, 닫힌 채널은 종료를 유발하는 대신 조용히 비활성화되고, 중지 신호가 발생할 때까지 채널을 열어 두도록 게시자 수명이 연장됩니다.
* Linux: `uninstall.sh`은(는) 이제 `apt-get remove` 대신 `apt-get purge`을(를) 사용하여 재설치 실패를 유발하는 dpkg 상태 불일치를 방지합니다. 패키지 매니저가 `systemd-env.conf` conffile을 다시 생성하지 않아 서비스가 시작될 수 없었습니다.
* Windows: 설치 또는 런타임 데이터 디렉터리를 제거할 수 없는 경우 이제 제거 스크립트가 조용히 성공하는 대신 경고를 표시합니다(예: Windows 탐색기에서 열려 있음), 잠금이 해제되면 다시 실행할 수 있도록 스크립트 자체를 보존합니다.
* 온호스트: `filesystem:`/`shared_filesystem:` 아래의 파일 시스템 항목은 이제 알파벳 순서로 디스크에 기록되고 각 쓰기 후에 fsync 처리되어 쓰기 순서를 결정론적으로 만듭니다.
* On-host: 자체 업데이트 시 실행 중인 바이너리를 교체할 때 다운로드한 패키지의 바이너리를 더 이상 삭제하지 않으며, 자체 업데이트 후 롤백 및 동일 버전 재설치 문제를 해결합니다.
* On-host: 에이전트 컨트롤 또는 하위 에이전트의 로그 디렉터리가 처음 생성될 때 stderr에 출력되는 불필요한 `Error reading the log directory/files: No such file or directory` 메시지를 수정했습니다.
* On-host: 실행 파일 출력 및 수명 주기 로그는 더 이상 에이전트 프로세스 및 감독자의 전체 수명 동안 `start_agent` 스팬으로 잘못 태그되지 않으며, 대신 명시적인 필드를 전달합니다.
* 종료 시 프로세스 종료 로그 줄(성공 또는 오류)이 더 이상 로그 파일에서 누락되지 않습니다. 이전에는 파일 로거가 이미 종료된 후에 내보내졌기 때문에 `journalctl`/stderr에만 도달했습니다.
