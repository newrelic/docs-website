### 새로운 기능

* 관리형 ID 및 서비스 주체 인증을 모두 지원하는 Azure Key Vault 값 공급자를 추가했습니다.
* 이제 모든 시스템에 설정된 것이 없는 경우 자체 계측은 주입된 라이선스 키를 헤더로 가져옵니다.

### 버그 수정

* Windows: 이제 `install.ps1`은(는) 중복 호스트 보고를 방지하기 위해 독립 실행형 뉴렐릭 인프라 에이전트 설치를 감지하고 제거하며, 여전히 필요한 경우 나중에 에이전트 제어 관리 하위 에이전트로 다시 구성해야 합니다.
* 온호스트: OHI 구성 파일을 공유 파일 시스템에 쓸 때 불필요한 파일 시스템 동기화 및 전체 디렉터리 재생성으로 인해 발생하는 통합 재시작 문제를 수정했습니다.
* 정상 종료 시 유휴 대기 시간을 줄이기 위해 상태 확인 스레드의 초기 지연을 취소할 수 있도록 변경했습니다.
* 사소한 로깅 문제를 수정했습니다: 중복 필드, 중복된 로그, 잘못된 로그 레벨 및 일관되지 않은 메시지 대소문자.
* 이제 에이전트 제어는 시작 시 항상 원격 구성 상태를 다시 보고하여, 서버가 전체 상태 동기화 requests를 보낼 때 재시작 후 누락된 재전송 문제를 수정했습니다.
* Windows: 시스템 종료/재부팅 시 ctrl 신호 처리 대신 수동 서비스 중지와 동일한 서비스 정상 중지 경로를 거치도록 수정했습니다.
