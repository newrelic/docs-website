### 새로운 기능

* 원격 설정 키에서 `variable.agentConfig` 구문을 통한 변수 재정의 지원을 추가했습니다.
* 원격 설정 키에서 `variable.agentConfig.<variable>:<map-key>` 구문을 통한 단일 `string_map` 변수 재정의 항목에 대한 지원을 추가합니다.
* 온호스트 인프라 에이전트 유형(linux): 새로운 `config_docker` 변수를 통해 `nri-docker` 통합 설정을 노출합니다.
* 에이전트 유형: 변수 이름 형식을 문자로 시작하고 최대 길이가 64자인 `[A-Za-z0-9_-]` (으)로 강제합니다.
* 온호스트: 기본적으로 셀프 업데이트 기능을 활성화합니다. 셀프 업데이트는 플릿 컨트롤에서 명령할 때만 실행됩니다.

### 버그 수정

* K8s supervisor: 새로운 원격 구성이 도착하여 하위 에이전트 supervisor를 다시 시작할 때 중단된 HelmReleases(예: 설치/업그레이드 재시도를 모두 소진한 후)에 대해 Flux 조정을 강제합니다.
* 온호스트: 재시작 정책이 초과되면 일반적인 &quot;재시작 정책 초과&quot; 메시지 대신 비정상 상태의 `lastErrorMessage`에 실제 마지막 실패(출시 오류 또는 0이 아닌 종료)를 보고합니다.
* 온호스트: 교체된 패키지 디렉터리에 저장하는 대신 인프라 에이전트 패키지 업데이트 시 fluent-bit의 홈 디렉터리(`fb.db`)를 유지합니다.
