### 새로운 기능

* 온호스트: Linux에서 systemd `MemoryMax`을(를) 통해 에이전트 제어 프로세스 트리(AC+모든 하위 에이전트)에 2400MiB의 하드 메모리 제한을 적용합니다.

### 버그 수정

* Linux: RPM 패키지 업데이트 후 systemd 서비스 비활성화 방지

### 보안 업데이트

* rust crate futures를 0.3.34로 업데이트했습니다.
* alpine/helm을 v4.2.4로 업데이트했습니다
* rust crate serde-saphyr를 1.1.0으로 업데이트했습니다.

변경 사항에 대한 자세한 내용은 [릴리스 노트](https://github.com/newrelic/newrelic-agent-control/releases/tag/1.22.0)를 참조하십시오.
