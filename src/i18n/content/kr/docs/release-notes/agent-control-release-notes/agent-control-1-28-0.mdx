### 새로운 기능

* 이제 빈 맵에 대한 YAML 구문 분석이 더 엄격해졌습니다. 저장된 원격 구성의 단독 `config:`와 같이 맵이 필요한 곳에 널 값(빈 값, `~` 또는 `null`)이 사용되면 빈 맵으로 처리되는 대신 거부됩니다. 빈 맵에는 `{}`을(를) 사용하십시오. 빈 문서는 여전히 허용됩니다.

### 버그 수정

* 온호스트: 공유 파일 시스템 정리가 더 이상 심볼릭 링크를 따르지 않으므로 공유 파일 시스템 외부의 콘텐츠가 절대 삭제되지 않으며, 연결이 끊긴 심볼릭 링크는 제거됩니다.
* 온호스트: 로깅이 구성되기 전에 발생하는 시작 실패(예: 잘못된 `local_config.yaml`)는 이제 기본 에이전트 제어 로그 파일에 기록되므로, Windows 서비스로 실행할 때 확인할 수 있습니다.
* 온호스트: OCI 레지스트리 requests는 이제 프록시 URL 체계와 관계없이 구성된 프록시를 통과하므로, `http://` 프록시가 더 이상 우회되지 않습니다.
* On-host \[온호스트]: 신호에 의해(예: OOM 킬러에 의해) 종료된 하위 에이전트는 이제 &quot;process exited with code: 0&quot; 대신 해당 신호에 의해 종료된 것으로 보고됩니다.
