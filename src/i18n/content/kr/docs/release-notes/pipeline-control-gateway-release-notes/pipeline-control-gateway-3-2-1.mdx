### 버그 수정

* 게이트웨이를 통해 데이터를 전송할 때 파이썬 APM 에이전트가 모든 수집 시 JSON 디코딩 오류 로그를 남겨 중복 로그가 발생하고 오류 데이터가 손실되는 문제를 수정했습니다. 이제 게이트웨이는 에이전트 프로토콜에 명시된 대로 APM 에이전트 데이터 requests에 대해 HTTP `202 Accepted` 및 빈 본문으로 응답합니다.
* APM 에이전트의 스팬 이벤트가 스팬의 시작 시간 대신 게이트웨이가 수신한 시간으로 기록되는 문제를 수정했습니다.

### 보안 업데이트

* 높은 심각도 및 중간 심각도의 취약점을 해결하기 위해 `golang.org/x/net` 종속성을 `v0.62.0` (으)로 업데이트했습니다.
