### 새로운 기능

* 에이전트가 `console.*` 호출을 로그로 캡처하는 것을 중지할 수 있는 `consoleCaptureEnabled` 설정 옵션(기본값 `true`)을 추가했습니다. ([#342](https://github.com/newrelic/newrelic-react-native-agent/pull/342))

### 개선 및 향상

* 노출된 뉴렐릭 애플리케이션 토큰을 제거했습니다. ([#338](https://github.com/newrelic/newrelic-react-native-agent/pull/338))
* 네이티브 안드로이드 에이전트를 버전 7.8.5로 업데이트했습니다. ([#346](https://github.com/newrelic/newrelic-react-native-agent/pull/346))
* 스위프트 패키지 매니저(`NEWRELIC_USE_SPM=1`)용 네이티브 iOS 에이전트를 버전 7.7.10으로 업데이트했습니다. 7.7.10 버전은 CocoaPods에서 사용할 수 없으므로 CocoaPods 설치는 7.7.9 버전으로 유지됩니다. ([#346](https://github.com/newrelic/newrelic-react-native-agent/pull/346))

### 버그 수정

* 예외를 발생시키는 getter가 있는 객체와 같이 인수를 직렬화할 수 없을 때 `console.log/warn/error/debug`이(가) 예외를 발생시켜 크래시가 일어나는 문제를 수정했습니다. ([#341](https://github.com/newrelic/newrelic-react-native-agent/pull/341))
