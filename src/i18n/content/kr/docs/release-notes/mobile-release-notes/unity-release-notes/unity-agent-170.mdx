## 개량

* `Library not loaded: @rpath/NewRelic.framework/NewRelic`과(와) 함께 출시 시 iOS 앱이 충돌하는 문제를 수정했습니다. 1.6.0에 추가된 스위프트 패키지 매니저 선언이 제거되었으며, 이제 iOS 종속성은 CocoaPods를 통해서만 해결됩니다. 1.6.0부터 1.6.4까지의 빌드는 EDM4U iOS Resolver 설정에서 스위프트 패키지 매니저를 수동으로 비활성화하지 않는 한 영향을 받았습니다.
* Unity 2019.1부터 2021.2까지의 빌드에서 뉴렐릭 iOS 에이전트가 완전히 누락되는 문제를 수정했으며, 해당 빌드에서 EDM4U는 `NewRelicAgent` 파드를 억제했지만, 스위프트 패키지 매니저 주입은 Unity 2021.3 이상이 필요하기 때문에 건너뛰었습니다.
* 네이티브 안드로이드 에이전트가 버전 7.8.2로 업데이트되었습니다.
* 네이티브 안드로이드 NDK 에이전트가 버전 1.1.5로 업데이트되었습니다.
* 네이티브 iOS 에이전트가 버전 7.7.6으로 업데이트되었습니다
* 이제 iOS 의존성은 CocoaPods를 통해서만 해결됩니다. EDM4U가 자동으로 `NewRelicAgent` 파드로 폴백하고 **Swift Package Manager Enabled** 설정을 선택된 상태로 유지할 수 있으므로, 이전에 스위프트 패키지 매니저를 사용한 경우 아무런 조치도 필요하지 않습니다.
* 생성된 Xcode 프로젝트에 이전 빌드의 `newrelic-ios-agent-spm` 패키지 참조가 여전히 포함되어 있는 경우, 생성된 프로젝트를 삭제하고 Unity에서 다시 빌드하여 지우십시오.
