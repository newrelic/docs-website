## 버그 수정

* `MobileRequest`/`MobileRequestError` 이벤트에서 사용자 지정 `httpParams` 및 추적된 헤더 값을 조용히 삭제하는 iOS 브리지 하드코딩 `andParams: nil`을(를) 수정했습니다. 안드로이드는 이미 매개변수를 올바르게 전달했습니다.

## 개선 사항

* 네이티브 안드로이드 에이전트를 버전 7.8.1로 업데이트했습니다.
* 네이티브 iOS 에이전트를 버전 7.7.6으로 업데이트했습니다.
