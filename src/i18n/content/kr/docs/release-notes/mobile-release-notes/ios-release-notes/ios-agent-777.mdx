### 새로운 기능

* 문서화된 최소 플랫폼 요구 사항에 맞춰 iOS 15.0 및 tvOS 15.0의 최소 배포 버전을 타겟으로 하도록 XCFramework 빌드 설정을 업데이트했습니다.

### 버그 수정

* 수집 설정 읽기 중 발생하는 크래시(`objc_msgSend` 내의 `SIGSEGV`)를 해결했습니다. `/connect` 응답 또는 `NSUserDefaults` 딕셔너리에서 자동 해제 풀이 비워진 후 `assign` (으)로 선언된 `NRMAHarvesterConfiguration`의 8개 객체 속성이 댕글링 포인터를 유지했습니다.

* `/connect` 응답에서 `at_capture` 속성이 누락된 경우 세션에 대한 모든 활동 트레이스가 삭제되는 문제를 해결했습니다.

* 리액트 네이티브 오류와 함께 보고된 `platform` 값을 `ReactNative`(으)로 보고하도록 수정했습니다.

* 호스트 플랫폼 버전 대신 iOS 에이전트 버전을 정확하게 보고하도록 JavaScript 오류 페이로드의 `agentVersion` 필드를 수정했습니다.

* 커스텀 속성 유효성 검사 업데이트: `NSArray` 또는 `NSDictionary` 객체를 이벤트 속성으로 전달하면 이제 일반적인 `"value must be an NSString, NSNumber, or BOOL"` 경고 메시지를 대체하여 지원되지 않는 유형을 식별하는 명시적 오류를 로그에 기록합니다.
