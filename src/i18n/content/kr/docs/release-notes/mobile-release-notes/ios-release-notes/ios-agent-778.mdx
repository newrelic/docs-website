### 버그 수정

* 메모리 부족 환경에서 `recordError`을(를) 호출할 때 호스트 애플리케이션이 종료될 수 있는 문제를 수정했습니다. 이제 오류 보고서는 삭제되고 로그에 기록되며, 기록된 스택의 맨 위에서 뉴렐릭 에이전트 프레임이 잘립니다.
* 세션 속성을 제거할 때 로그 형식 문자열의 인수 누락으로 인해 발생하는 `NRMALoggerBridge::log`의 크래시를 수정했습니다. 동일한 구성 요소에서 두 개의 잘못된 형식 문자열을 추가로 수정했습니다.
* 새로운 이벤트 시스템을 사용할 때 분산 추적 타임스탬프(`tracestate` 및 페이로드 `ti`)가 밀리초 대신 초 단위로 전송되던 문제를 수정했습니다.
* 크로스 플랫폼 SDK가 `traceHeaders`을(를) 전달할 때 성공한 `MobileRequest` 이벤트의 모든 분산 추적 속성이 손실되는 문제를 수정했습니다.
* 플러터, 리액트 네이티브 또는 기타 하이브리드 에이전트가 `traceHeaders` (으)로 보고한 requests에 중복된 분산 트레이스가 추가되는 것을 방지하도록 네이티브 에이전트를 업데이트했습니다. 이는 두 이벤트 시스템의 `MobileRequest` 및 `MobileRequestError` 모두에 적용됩니다.
* `MaxEventPoolSize` 및 `MaxEventBufferTime` 설정에 대한 최소 및 최대 경계 제한을 적용했습니다(최대 버퍼 시간은 600초로 제한됨).
* 새로운 이벤트 시스템을 사용할 때 항상 `YES`을(를) 반환하는 대신 이벤트가 성공적으로 추가되었는지 여부를 나타내는 부울을 반환하도록 `recordCustomEvent`을(를) 업데이트했습니다.
* 안드로이드 에이전트 동작과 일치하도록, 대소문자가 올바르게 지정된 `ReactNative` 플랫폼 값을 전달하도록 리액트 네이티브 JavaScript 오류 업로드를 업데이트했습니다.
