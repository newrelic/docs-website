### 새로운 기능

* 안드로이드 및 iOS의 CoreCLR 런타임을 포함하여 .NET 11에 대한 지원을 추가하고 .NET 9 타겟을 제거했으며, CoreCLR 환경에서 처리되지 않은 iOS 예외는 이제 관리되는 스택 추적과 함께 보고됩니다. ([#87](https://github.com/newrelic/newrelic-maui-plugin/pull/87))
* .NET MAUI 뷰를 위한 세션 리플레이 개인정보 보호 확장 기능을 추가했습니다. ([#102](https://github.com/newrelic/newrelic-maui-plugin/pull/102))

### 개선 및 향상

* 네이티브 안드로이드 에이전트를 버전 7.8.6으로 업데이트했습니다.
* 네이티브 iOS 에이전트를 버전 7.7.11로 업데이트했습니다.
