### 개선 및 향상

* AGP 9.4 지원: 뉴렐릭 Gradle 플러그인에 안드로이드 Gradle 플러그인(AGP) 9.4.x에 대한 지원을 추가했습니다.

* 분산 추적 헤더 최적화: 독점적인 newrelic 요청 헤더를 제거하고 W3C 표준 traceparent 및 tracestate 헤더에만 의존하여 분산 추적을 간소화했습니다.

* WebView 브라우저 에이전트 감지: 활성 WebView가 뉴렐릭 브라우저 에이전트를 활용하고 있는지 감지하고 추적하는 지원 가능성 메트릭을 추가했습니다.

* SDK 크기 최적화 지침: 개발자가 비활성화된 기능에 대해 사용되지 않는 에이전트 코드를 제거할 수 있도록 ProGuard/R8 트리 셰이킹 규칙을 다루는 문서를 추가했습니다.

### 버그 수정

* 세션 리플레이 크래시 수정: 세션 리플레이에서 Curtains를 초기화할 때 메인 스레드에서 NullPointerException을 일으키는 멀티스레딩 경합 조건을 수정했습니다.

* HTTP2 페이로드 크기 추적: 헤더가 없는 HTTP/2 및 Ktor 스트림에 대해 네트워크 요청 페이로드 크기(bytesReceived)가 0바이트로 잘못 보고되는 문제를 해결했습니다.

* 리소스 누수 해결: SessionReplayFileManager 내에서 BufferedWriter 인스턴스를 올바르게 닫아 정적 분석 관찰 결과(CWE-404)를 해결했습니다.
