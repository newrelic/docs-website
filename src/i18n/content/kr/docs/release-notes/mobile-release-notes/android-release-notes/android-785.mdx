### 개선 및 향상

* 이제 에이전트가 앱의 기본 프로세스에서만 시작되므로, `android:process` (으)로 추가 프로세스를 선언하는 앱은 더 이상 해당 프로세스에서 빈 세션을 보고하지 않습니다. ([#648](https://github.com/newrelic/newrelic-android-agent/pull/648))

### 버그 수정

* 앱이 백그라운드에 있는 동안 발생했을 때 다음 출시에 보고된 ANR 및 기타 앱 종료에서 `background` 속성이 누락되는 문제를 수정했으며, 이제 프로세스가 종료될 때의 앱 상태에 따라 속성이 `true` 또는 `false`이(가) 됩니다. ([#653](https://github.com/newrelic/newrelic-android-agent/pull/653))
* 앱이 백그라운드로 이동한 후 수집된 배치로 전송될 때, 포그라운드에 있는 동안 기록된 이벤트가 `background = true` (으)로 보고되는 문제를 수정했습니다. Background Reporting\[백그라운드 보고]가 활성화되면, 이제 모든 이벤트는 기록된 순간의 앱 상태에 대해 `background = true` 또는 `background = false`을(를) 전달합니다. 이전에는 포그라운드 이벤트에 `background` 속성이 없었습니다. ([#655](https://github.com/newrelic/newrelic-android-agent/pull/655))
* `WebView` 하위 클래스가 `setWebViewClient`을(를) 재정의하여 클라이언트를 저장하고 자체 내부 클라이언트에서 해당 클라이언트로 전달하는 앱에서 페이지 로드 시 발생하는 `StackOverflowError` 크래시를 수정했으며, 에이전트는 더 이상 이러한 WebView에 WebView 클라이언트 래퍼를 설치하지 않습니다. ([#660](https://github.com/newrelic/newrelic-android-agent/pull/660))
* 에이전트가 메인 스레드의 디스크에서 저장된 이벤트를 읽을 때 앱 시작 시 발생하는 ANR을 수정했으며, 이제 백그라운드에서 로드됩니다. ([#661](https://github.com/newrelic/newrelic-android-agent/pull/661))
