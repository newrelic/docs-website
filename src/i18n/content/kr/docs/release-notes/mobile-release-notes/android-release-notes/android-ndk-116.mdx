### 버그 수정

* 포인터 인증(PAC)을 사용하는 arm64 기기에서 네이티브 크래시 보고서가 누락되는 문제를 수정했습니다. 이러한 기기에서는 크래시 핸들러가 이전 번들 언와인더 내부에서 실패하여 보고서나 툼스톤이 생성되지 않았습니다. 이제 에이전트는 NDK r25로 빌드됩니다.
* 앱이 백그라운드에서 복귀한 후 `NR_AppStateMon` 스레드 또는 메인 스레드에서 간헐적으로 발생하는 &quot;stack corruption detected (-fstack-protector)&quot; 크래시를 수정했습니다.
* 앱이 포그라운드로 복귀한 후 발생하는 use-after-free 크래시를 수정했습니다. 이는 앱이 백그라운드로 이동할 때 에이전트가 대체 시그널 스택을 먼저 비활성화하지 않고 해제했기 때문에 발생했습니다.

## 지지 성명

* 안드로이드 NDK 에이전트 버전 1.1.5 이상은 안드로이드 에이전트 7.7.6 이상이 필요합니다.
* Android NDK 에이전트 버전 1.1.1 이상을 사용하려면 Android 에이전트 7.5.1 이상이 필요합니다.
* 안드로이드 NDK 에이전트 버전 1.1.0 이상 버전에는 Android 에이전트 7.5.0 이상이 필요합니다.
* Android NDK 에이전트 버전 1.0.3 이상을 사용하려면 Android 에이전트 6.11.0 이상이 필요합니다.
* 버전 1.0.0～1.0.2는 안드로이드 에이전트 6.10.0 이하 버전과 호환됩니다.

에이전트를 정기적으로, 최소 3개월마다 업그레이드할 것을 권장합니다.
