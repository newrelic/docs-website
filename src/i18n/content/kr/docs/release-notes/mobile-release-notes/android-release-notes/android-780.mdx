## 새로운 기능 및 개선 사항

* 세션 리플레이를 위한 오프라인 스토리지를 추가했습니다: 네트워크 연결 없음, 앱 강제 종료, 프로세스 종료 또는 메모리 부족으로 인한 종료로 인해 즉시 전송할 수 없는 리플레이 페이로드는 이제 손실되지 않고 디스크에 유지되며 다음 번 성공적인 수집 시에 전달됩니다.
* 리액트 네이티브 앱의 하이브리드 오류 보고를 위한 기본 지원을 추가했으며, 이는 곧 출시될 리액트 네이티브 에이전트 릴리스와 함께 활성화될 예정입니다. 처리되지 않은 JavaScript 오류는 에이전트 이벤트로 캡처되고, 세션 리플레이와 연관되며, 정확한 심볼리케이션을 위해 앱 버전으로 태그가 지정됩니다.
* Gradle 빌드 중 리액트 네이티브 JavaScript 소스 맵의 자동 업로드를 위한 기본 지원을 추가했으며, 이는 다가오는 리액트 네이티브 에이전트 출시와 함께 활성화될 예정입니다.
* 빌드 타겟별 ProGuard/DexGuard 매핑 파일 업로드를 추가하여, 여러 DexGuard 패키징 타겟이 있는 애플리케이션이 각 타겟에 대해 올바르게 일치하는 크래시 난독화 해제를 받을 수 있도록 했습니다.
* 애플리케이션 종료 정보(AEI) 이벤트가 재시작 후 생성된 세션이 아닌 실제로 크래시가 발생한 세션의 세션 속성을 전달하도록 세션 범위의 속성 저장소를 추가했습니다.
* 이제 이벤트 지속성이 기본적으로 활성화되므로, 버퍼링된 이벤트 및 분석 데이터가 앱 종료 시에도 유지되며 다음 출시 시 복구됩니다.
* 안드로이드 Gradle 플러그인(AGP) 9.x에 대한 지원을 추가하여 지원 상한선을 9.3.0으로 높였습니다.

## 버그 수정

* Activity 재개 시점이 아닌 출시부터 첫 번째 렌더링된 프레임까지의 초기 디스플레이 시간(TTID)을 측정하도록 콜드 스타트 타이밍을 수정했습니다.
* 이전 크래시 이후 오래된 백업 파일로 인해 크래시 스토어가 복구되지 못하는 크래시 복구 문제를 수정했습니다.
* 예외 저장소에 기록할 때 발생할 수 있는 잠재적인 속도 저하를 방지하기 위해, 처리된 예외가 호출 스레드 외부에서 유지되도록 수정했습니다.
* 빌드별 빌드 ID 및 메트릭 값을 컴파일된 소스에 직접 포함하여 발생하는 Gradle 빌드 캐시 무효화 문제를 수정했습니다 — 이제 이러한 값은 안드로이드 리소스로 대신 생성되어 불필요한 재컴파일 및 다시 빌드 시간을 줄여주며, shrinkResources가 활성화된 경우 리소스가 제거되지 않도록 보호됩니다.
