### 버그 수정

* `EventPersistence`이(가) 비활성화되었을 때 매 출시마다 유지된 이벤트가 다시 로드되고 다시 전송되는 문제를 해결했습니다.

* 이제 에이전트가 이벤트 버퍼 시간의 최소/최대 범위를 따르도록 이벤트 버퍼 동작을 수정했습니다.

* 셀룰러 하위 유형을 확인할 수 없을 때 `connectionType`이(가) &quot;unknown&quot;으로 보고되는 문제를 수정했습니다.
