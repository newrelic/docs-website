* HLS 재생이 시작된 후 `getSrc()`이(가) 실제 매니페스트 URL 대신 브라우저의 임시 `blob:` URL을 반환하던 문제를 수정했습니다. 이제 트래커가 기본 Hls.js 인스턴스에서 URL을 읽어오므로, 재생 중에 실제 매니페스트 URL이 일관되게 보고됩니다.
