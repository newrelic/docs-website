### 새로운 기능

* Amazon Vega(Kepler/Fire TV 클래스) 디바이스용 HLS.js 트래커인 `VegaTracker`을(를) 추가했습니다. 새로운 `@newrelic/video-hls/vega` 하위 경로 진입점을 통해 가져오십시오. `VegaTracker`은(는) `HLSTracker`을(를) 확장하며 브라우저 파이프라인 대신 연결된 디바이스 파이프라인을 통해 텔레메트리를 라우팅합니다. CJS 및 ESM 모두로 제공됩니다.

### 버그 수정

* 뉴렐릭 이벤트의 `trackerName` 속성이 예상 값과 일치하도록 `VegaTracker`이(가) 보고한 트래커 이름을 `'vega-hls'`에서 `'hls'` (으)로 수정했습니다.
