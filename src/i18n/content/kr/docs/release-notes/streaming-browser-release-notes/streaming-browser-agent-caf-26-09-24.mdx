### 새로운 기능

* **`/browser` 하위 경로 내보내기:** 번들로 제공되는 `@newrelic/video-core` 종속성에서 사용되지 않는 연결된 디바이스 파이프라인을 제외하여 번들을 가볍게 유지하는 `@newrelic/video-caf/browser` 진입점을 이제 사용할 수 있습니다. `exports` 필드를 인식하지 않는 번들러를 위해 `browser.js` 파일 시스템 shim도 포함되어 있습니다.
* **네임드 익스포트:** 이제 루트 및 `/browser` 엔트리 포인트 모두에서 기존 기본 내보내기와 함께 `{ CAFTracker }`을(를) 네임드 익스포트로 사용할 수 있습니다.

### 개량

* **`@newrelic/video-core`이(가) 5.1.0으로 업데이트되었으며**, 여기에는 TypeScript 선언 파일, 업스트림 버그 수정 및 종속성 패치가 포함됩니다.
