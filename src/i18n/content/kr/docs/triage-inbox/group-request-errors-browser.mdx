중단된 타사 통합이나 500을 반환하는 백앤드 API와 같은 실패한 AJAX 및 fetch 호출은 종종 손상된 페이지와 혼란스러운 사용자 경험을 초래합니다. <DNT>**Request errors**</DNT> 페이지는 이러한 실패한 requests를 그룹화하여 손상된 페이지 이면의 API 호출을 찾고, 얼마나 자주 실패하는지 확인하며, 디버깅을 시작할 위치를 파악할 수 있도록 합니다.

요청 오류는 브라우저 에이전트가 이미 수집하는 [`AjaxRequest`](/attribute-dictionary/?event=AjaxRequest) 이벤트를 기반으로 하므로, 사용을 시작하기 위해 설치하거나 활성화할 필요가 없습니다.

## 요청 오류 페이지 보기 [#request-errors-page]

요청 오류 페이지를 보려면 <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Browser &gt; (select an app) &gt; Request errors**</DNT>(으)로 이동하십시오.

## 추천 플리우스 [#suggested-workflow]

오류를 파악하고, 원인 요소를 식별하며, 디버깅을 시작할 수 있도록 요청 오류를 조사할 때 다음과 같은 접근 방식을 권장합니다:

1. **전반적인 추세 확인**: <DNT>**Error count**</DNT> 및 <DNT>**Errors by page**</DNT> 차트를 먼저 살펴보고 예상치 못한 급증, 급감 또는 패턴이 있는지 한눈에 확인하십시오.
2. **그룹화 및 필터링**: <DNT>**Group by**</DNT> 및 필터 옵션을 사용하여 특정 요청 도메인, 요청 경로, 응답 코드 또는 코드 범위에 집중하십시오.
3. **단일 오류 심층 분석**: 요청 오류 테이블에서 행을 선택하여 요청 URL, 응답 코드, 응답 본문 등을 포함한 전체 요청 세부 정보를 확인하십시오.
4. **세션 리플레이 및 이벤트 추적 검토**: 특정 오류에서 [이벤트 추적](#event-trail)과 가능한 경우 해당 발생 중에 기록된 [세션 리플레이](#session-replay)를 검토하십시오.
5. **데이터 쿼리 및 공유**: 쿼리 빌더에서 기본 `AjaxRequest` 데이터를 탐색하거나 대시보드에 추가하려면 어느 차트에서든 <DNT>**…**</DNT> 메뉴를 선택한 다음 <DNT>**View query**</DNT>을(를) 선택하십시오.
6. **시간대 변경**: 타임 피커 드롭다운 메뉴에서 새로운 시간대를 선택하세요.

## 오류 세부 정보 요청 [#error-details]

요청 오류 테이블에서 행을 선택하여 요청 세부 정보를 스택 패널로 여십시오. 이 패널에는 해당 오류에 대한 전체 요청 정보, 요청 속성 및 응답 본문이 표시됩니다.

### 프로필 [#error-profiles]

요청 오류 테이블에서 <DNT>**View profiles**</DNT>을(를) 선택하여 어떤 속성이 이 요청 오류 그룹을 다른 트래픽과 가장 잘 구분하는지 확인하십시오. 프로필을 사용하여 영향을 받는 requests의 공통점을 빠르게 파악하십시오.

### 이벤트 트레일 [#event-trail]

특정 오류를 선택하면 이벤트 추적에 해당 오류로 이어진 브라우저 상호작용 및 AJAX 호출이 표시됩니다. 이를 통해 요청이 실패했을 때 사용자가 무엇을 하고 있었는지, 그리고 같은 시간대의 다른 호출도 영향을 받았는지 파악할 수 있습니다.

### 세션 재생 [#session-replay]

보고 있는 발생에 대해 세션 리플레이가 기록된 경우, 오류 세부 정보에서 이를 열어 요청이 실패했을 때 사용자가 정확히 무엇을 경험했는지 확인할 수 있습니다.

## 요청 오류 데이터 쿼리 및 시각화 [#insights]

뉴렐릭은 요청 오류 데이터를 `AjaxRequest` 이벤트로 저장합니다. NRQL 쿼리를 실행하고 요청 오류 데이터로 대시보드를 생성하려면 [쿼리 빌더](/docs/query-your-data/explore-query-data/query-builder/introduction-query-builder)에서 `AjaxRequest` 이벤트 유형을 쿼리하십시오.
