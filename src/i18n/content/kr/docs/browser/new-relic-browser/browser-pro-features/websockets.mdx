[WebSocket API](https://developer.mozilla.org/en-US/docs/Web/API/WebSockets_API)를 사용하면 사용자 브라우저와 서버 간에 양방향 대화형 통신 세션을 열 수 있습니다. 이 세션을 사용하면 서버 응답을 폴링하지 않고도 데이터를 보내고 받을 수 있습니다. 뉴렐릭 브라우저 모니터링을 사용하면 웹소켓 세션의 트래픽과 상태를 모니터하고 추적할 수 있습니다.

API의 웹소켓 데이터는 브라우저 에이전트에 의해 [WebSocket](https://docs.newrelic.com/attribute-dictionary/?dataSource=Browser+agent&event=WebSocket) 이벤트로 기록됩니다. 이러한 이벤트에는 연결, 수신된 메시지, 전송된 데이터 및 웹소켓의 수명 주기 동안 연결이 닫힌 방법에 대한 메트릭이 포함됩니다.

## 웹소켓 모니터링을 사용하는 이유는 무엇입니까?

뉴렐릭을 사용한 웹소켓 자동 추적은 웹소켓이 예상대로 작동하는지 확인하는 데 필요한 도구와 인사이트를 제공합니다. `WebSocket` 이벤트를 통해 다음을 수행할 수 있습니다:

* 네트워크 연결에서 송수신된 바이트를 모니터하십시오
* 웹소켓이 성공적으로 닫히는지 여부와 그 이유를 검토하십시오.
* 웹소켓의 수명 주기 동안 발생하는 JavaScript 오류를 해결하십시오.
* 웹소켓을 기반으로 커스텀 대시보드 및 알림을 구축하십시오.

## 전제 조건 [#prerequisites]

* **Pro** 또는 **Pro + SPA** 브라우저 에이전트, 버전 1.318.0 이상.

<Callout variant="important">
  Lite 브라우저 에이전트에서는 웹소켓 모니터링을 사용할 수 없습니다.
</Callout>

## 자동 수집 활성화 [#enable-collection]

다음의 간단한 설정 지침에 따라 귀하의 옵저버빌리티 및 디버깅 기능을 향상시키십시오.

<Steps>
  <Step>
    **[one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Browser** 로 이동합니다.
  </Step>

  <Step>
    브라우저 앱을 선택하세요.
  </Step>

  <Step>
    왼쪽 메뉴에서 **Application settings** \[애플리케이션 설정 을] 클릭합니다.
  </Step>

  <Step>
    **Pro** 또는 **Pro + SPA** 브라우저 에이전트가 선택되었는지 확인하세요.
  </Step>

  <Step>
    **Enable websockets**를 켜십시오.
  </Step>
</Steps>

## 웹소켓 수집 비활성화 [#disable-websockets]

기존 브라우저 앱에 대해 웹소켓을 비활성화하려면:

<Steps>
  <Step>
    **[one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Browser** 로 이동합니다.
  </Step>

  <Step>
    브라우저 앱을 선택하세요.
  </Step>

  <Step>
    왼쪽 메뉴에서 **Application settings** \[애플리케이션 설정 을] 클릭합니다.
  </Step>

  <Step>
    웹소켓을 비활성화하려면 **Enable websockets**\[웹소켓 활성화를] 끕니다.
  </Step>
</Steps>

## 데이터 소비

`WebSocket` 이벤트는 다른 브라우저 바이트와 동일한 소비 가격을 따릅니다. 생성되는 바이트 양은 데이터의 개수와 속성에 따라 달라집니다.

활성화되면 에이전트는 애플리케이션에서 발생하는 웹소켓을 자동으로 캡처합니다.

## 뉴렐릭에서 데이터 찾기 [#find-data]

웹소켓은 뉴렐릭에 `WebSocket` 이벤트로 저장됩니다. `WebSocket` 이벤트와 함께 사용할 수 있는 필드에 대한 자세한 내용은 [데이터 사전](https://docs.newrelic.com/attribute-dictionary/?dataSource=Browser+agent&event=WebSocket)을 참조하십시오. 빠르고 유용한 대시보드를 보려면 이 [퀵스타트](https://newrelic.com/instant-observability/browser-web-sockets)를 참조하십시오. 이 데이터를 쿼리하고 시각화하여 애플리케이션의 성능에 대한 인사이트를 얻을 수 있습니다:

**시간 경과에 따른 웹소켓 인스턴스의 총량을 측정합니다**

```nrql
FROM WebSocket
SELECT count(*)
TIMESERIES
```

**웹소켓이 예기치 않게 닫히는 이유를 확인하십시오.**

```nrql
FROM WebSocket
SELECT count(*)
FACET closeReason
```

**오류가 있는 웹소켓 추적**

```nrql
FROM WebSocket
SELECT count(*) AS 'Errors'
WHERE hasErrors IS true
TIMESERIES
```

**전송 및 수신된 평균 바이트 보기**

```nrql
FROM WebSocket
SELECT average(sendBytes), average(messageBytes)
WHERE messageCount IS NOT null
TIMESERIES 
```

**웹소켓 평균 지속 시간 모니터링**

```nrql
FROM WebSocket
SELECT average(connectedDuration)
FACET cases(
  WHERE closeWasClean IS true AS 'Connected - Clean',
  WHERE closeWasClean IS NOT true AS 'Connected - Dirty'
)
TIMESERIES
```

이러한 쿼리를 사용하거나 직접 생성하여 맞춤형 대시보드를 구축하고, 알림을 설정하고, 웹의 실제 성능을 정밀하게 모니터링하세요.
