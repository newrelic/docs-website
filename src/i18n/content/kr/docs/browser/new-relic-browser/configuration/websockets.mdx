## 이 기능은 무슨 역할을 하나요?

이를 통해 웹소켓 연결의 상태와 트래픽을 모니터링할 수 있습니다.

브라우저 에이전트의 init 객체에서 `web_sockets`이라는 새로운 속성을 사용할 수 있습니다. 이 설정은 에이전트에서 웹소켓 기능을 사용할지 여부를 제어합니다. 브라우저 Pro 또는 Pro + SPA 에이전트, [버전 1.318.0](/docs/release-notes/new-relic-browser-release-notes/browser-agent-release-notes/browser-agent-v1.318.0) 이상에서 사용할 수 있습니다.

## 어떻게 사용하나요?

이 기능을 사용하려면 앱 설정 페이지를 방문하여 `"Enable websockets"` 토글을 켜야 합니다. 이 설정은 기본적으로 꺼져 있습니다.

NerdGraph를 사용하면 설정을 켜고 끌 수 있습니다. 이렇게 하려면 `browserWebSockets` 속성에 대해 `browserSettings` graphQL 개체에 대한 뮤테이션 쿼리를 실행하고 `enabled` `true` 또는 `false` 로 설정합니다.

활성화되면 에이전트를 다시 배포한 후 웹소켓에 대한 데이터 수집이 자동으로 이루어집니다. 웹소켓 데이터는 연결 메트릭, 수신된 메시지, 전송된 데이터 및 연결 종료 방법을 포함하는 [WebSocket](https://docs.newrelic.com/attribute-dictionary/?dataSource=Browser+agent&event=WebSocket) 이벤트로 수집됩니다. 각 `WebSocket` 인스턴스는 독립적으로 추적되며 연결 수명당 하나의 이벤트를 내보냅니다.

## 추가 고려 사항

* [세션 트레이스](/docs/browser/browser-monitoring/browser-pro-features/session-traces-explore-webpages-life-cycle)가 활성화된 경우, 세션 트레이스의 일부로 `sessionTraceId` 속성을 통해 WebSocket 이벤트를 연결할 수 있습니다.
