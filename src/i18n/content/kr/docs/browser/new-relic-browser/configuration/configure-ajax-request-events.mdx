[에이전트 버전 1211](/docs/release-notes/new-relic-browser-release-notes/browser-agent-release-notes/browser-agent-v1211/) 이상에서는 페이지에서 수행된 모든 네트워크 requests가 `AjaxRequest` 이벤트로 기록됩니다. 어떤 requests를 기록하고 어떤 데이터를 캡처할지 설정할 수 있습니다:

* **[거부 목록](#deny-list)**: AJAX 추적에서 제외할 도메인 및 URL을 필터링합니다.
* **[페이로드 캡처](#enable-payload-capture)**: 실패 디버깅을 위해 전체 요청 및 응답 데이터를 기록합니다.

## 거부 목록 [#deny-list]

기본적으로 귀하의 모든 네트워크 requests 에 대해 `AjaxRequest` 이벤트를 기록합니다.

* 모든 이벤트 기록을 중지하려면 와일드카드 문자 `*` (별표)을 추가하세요.
  * 예시: `*`
* 특정 사이트 전체의 이벤트 기록을 중지하려면 도메인 이름을 추가하세요.
  * 예시: `mywebsite.com`
* 특정 페이지에 대한 이벤트 기록을 중지하려면 도메인과 경로를 추가하세요.
  * 예시: `mywebsite.com/photos`
* [에이전트 버전 1.307.0](/docs/release-notes/new-relic-browser-release-notes/browser-agent-release-notes/browser-agent-v1.307.0/) 부터, `*` (별표)이 있는 곳에서는 어떤 길이의 문자열이든 일치시킵니다.
  * 예시: `mywebsite.com/shop/*` (경로용), `*.mywebsite.com` (하위 도메인용), `mywebsite.com/*/shop/*/checkout` (URL 중간 문자열용).

URL의 프로토콜, 포트, 검색 및 해시는 거부 목록에서 무시됩니다.

### 거부 목록에 액세스 [#access-deny-list]

애플리케이션이 이벤트 생성에서 필터링할 URL의 거부 목록을 업데이트하려면 앱 설정 페이지로 이동하십시오.

1. <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Browser &gt; (select an app) &gt; Settings &gt; Application settings**</DNT> 으)로 이동합니다.
2. <DNT>**AJAX data capture settings**</DNT> 섹션의 <DNT>**Deny list**</DNT> 필드에 앱에 적용할 필터를 추가하십시오.
3. 에이전트 설정을 업데이트하려면 <DNT>**Save**</DNT> 선택하세요.
4. [브라우저 에이전트를 다시 배포합니다](/docs/browser/new-relic-browser/installation/upgrade-browser-agent) (연결된 <InlinePopover type="apm" />에이전트를 다시 시작하거나 브라우저 설치 복사/붙여넣기 업데이트).

<Callout variant="important">
  여기서 변경 사항을 저장하면 <DNT>**Application settings**</DNT> 페이지에 표시되는 `NREUM.init` 설정만 업데이트됩니다. NPM을 통해 설치된 에이전트에는 자동으로 적용되지 않습니다.

  [NPM 패키지](https://www.npmjs.com/package/@newrelic/browser-agent)를 사용하여 브라우저 에이전트를 설치한 경우, 애플리케이션의 `init` 설정에서 `ajax.deny_list` 값을 수동으로 업데이트(또는 UI에서 다시 복사)한 다음, 변경 사항이 적용되도록 애플리케이션을 다시 빌드하고 다시 배포해야 합니다.
</Callout>

### 거부 목록 필터를 검증합니다. [#validation]

추가한 필터가 예상대로 작동하는지 확인하려면 필터와 일치하는 `AjaxRequest` 이벤트에 대해 NRQL 쿼리를 실행하세요.

```sql
FROM AjaxRequest SELECT * WHERE requestUrl LIKE '%example.com%'
```

## 페이로드 캡처 데이터 [#payload-capture]

<Callout variant="important">
  페이로드 캡처에는 [브라우저 에이전트 버전 1.317.0 이상](/docs/release-notes/new-relic-browser-release-notes/browser-agent-release-notes) 이 필요합니다.
</Callout>

모든 requests 또는 실패한 requests에 대해서만 페이로드 캡처를 활성화할 수 있습니다. 활성화되면 브라우저 에이전트는 허용된 모든 도메인에 대한 모든 AJAX 호출의 요청 및 응답 페이로드를 캡처합니다. 이는 응답 본문에 숨겨진 오류와 같이 메타데이터만으로는 보이지 않는 실패를 디버깅하는 데 유용합니다.

AJAX 페이로드 캡처를 활성화하면 브라우저 에이전트가 `AjaxRequest` 이벤트에 다음 속성을 추가합니다:

* `requestBody`: 요청 페이로드입니다.
* `requestHeaders`: JSON 형식의 요청 헤더입니다.
* `requestQuery`: JSON 형식의 URL 쿼리 파라미터입니다.
* `responseBody`: 응답 페이로드.
* `responseHeaders`: JSON 형식의 응답 헤더입니다.
* `ajaxRequest.id`: 각 AJAX 요청에 대한 고유 식별자입니다.

모든 페이로드 데이터 속성은 4096바이트에서 잘립니다. 잘림이 발생하면 마지막 4바이트가 `...` (으)로 대체되어 내용이 잘렸음을 나타냅니다.

### 페이로드 캡처 활성화 [#enable-payload-capture]

다음 방법 중 하나를 사용하여 페이로드 캡처를 활성화할 수 있습니다:

<CollapserGroup>
  <Collapser id="enable-ui" title="뉴렐릭 플랫폼을 통해 활성화">
    페이로드 캡처를 활성화하려면:

    1. <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Browser &gt; (select an app) &gt; Settings &gt; Application settings**</DNT> 으)로 이동합니다.

    2. <DNT>**AJAX data capture settings**</DNT> 섹션에서 <DNT>**Capture payload for allowed domains**</DNT> 토글을 활성화한 다음 캡처 모드를 선택하십시오:

       * <DNT>**Capture only failure responses**</DNT>: 상태 코드가 `0`이거나 `400` 이상인 requests 또는 `response body`에 GraphQL 오류 서명이 있는 requests에 대해서만 페이로드를 캡처합니다.
       * <DNT>**Capture all responses**</DNT>: 성공한 항목을 포함하여 모든 requests에 대한 페이로드를 캡처합니다. 성공 상태로 반환된 GraphQL 오류와 같이 응답 본문에 숨겨진 실패를 디버깅하려면 이를 사용합니다.

       <Callout variant="important">
         <DNT>**Capture all responses**</DNT> requests에 대한 페이로드 캡처를 활성화하면 데이터 수집량이 증가할 수 있습니다. 성공적인 응답을 캡처해야 하는 특별한 경우가 아니라면 <DNT>**Capture only failure responses**</DNT> 모드를 사용하십시오.
       </Callout>

    3. <DNT>**Save**</DNT> 클릭하여 변경 사항을 적용하세요.
  </Collapser>

  <Collapser id="configure-nerdgraph" title="NerdGraph를 통한 구성">
    [NerdGraph API를 사용하여 페이로드 캡처 설정을 쿼리하고 업데이트](/docs/apis/nerdgraph/examples/browser-monitoring-config-nerdgraph/#configure-payload-capture) 할 수 있습니다.

    `capture_payloads` 설정에 사용할 수 있는 값은 다음과 같습니다:

    * `"none"`: 페이로드 데이터를 캡처하지 않습니다. 이것은 기본 설정입니다.
    * `"failures"`: 상태 코드가 `0`이거나 `400` 이상인 requests 또는 `response body`에 GraphQL 오류 서명이 있는 requests에 대해서만 페이로드를 캡처합니다.
    * `"all"`: 상태 코드에 관계없이 모든 requests에 대한 페이로드 데이터를 캡처합니다.
  </Collapser>

  <Collapser id="configure-init" title="JavaScript를 통한 설정">
    복사/붙여넣기 또는 NPM 설치 방법을 사용하는 경우 JavaScript 설정에서 직접 페이로드 캡처를 설정할 수 있습니다.

    #### 복사/붙여넣기 설치

    에이전트 로더 앞의 브라우저 설정에 `ajax.capture_payloads` 설정을 추가하십시오:

    ```js
    window.NREUM.init = {
        ...<other init properties>...,
        ajax: {
          deny_list: ["bam.nr-data.net"],
          capture_payloads: 'failures' // or 'none', 'all'
        }
    }
    ```

    #### NPM 설치

    브라우저 에이전트를 초기화할 때 `ajax.capture_payloads` 설정을 추가하십시오:

    ```js
    import { BrowserAgent } from '@newrelic/browser-agent/loaders/browser-agent'

    const options = {
      init: {
        ...<other init properties>...,
        ajax: {
          deny_list: ["bam.nr-data.net"],
          capture_payloads: 'failures' // or 'none', 'all'
        }
      },
      info: { ... },
      loader_config: { ... }
    }

    new BrowserAgent(options)
    ```

    #### 캡처 모드

    `capture_payloads` 설정에 사용할 수 있는 값은 다음과 같습니다:

    * `"none"`: 페이로드 데이터를 캡처하지 않습니다. 이것은 기본 설정입니다.
    * `"failures"`: 상태 코드가 `0`이거나 `400` 이상인 requests 또는 `response body`에 GraphQL 오류 서명이 있는 requests에 대해서만 페이로드를 캡처합니다.
    * `"all"`: 상태 코드에 관계없이 모든 requests에 대한 페이로드 데이터를 캡처합니다.
  </Collapser>
</CollapserGroup>

페이로드 캡처를 처음 활성화하면 뉴렐릭은 일반적인 민감한 데이터를 보호하기 위해 기준 난독화 룰을 자동으로 추가합니다:

* [**신용카드 번호**](/docs/browser/new-relic-browser/configuration/obfuscate-browser-agent-data/#ccn): 주요 신용카드 형식(Visa, MasterCard, American Express, Discover 등)을 감지하고 마스크 처리합니다.
* [**사회 보장 번호**](/docs/browser/new-relic-browser/configuration/obfuscate-browser-agent-data/#ssn): SSN 패턴을 감지하고 마스크합니다.

뉴렐릭 플랫폼에서 난독화 룰을 설정하여 민감한 데이터가 뉴렐릭으로 전송되기 전에 마스크할 수 있습니다. 난독화 룰에 대한 자세한 내용은 [브라우저 에이전트 데이터 난독화](/docs/browser/new-relic-browser/configuration/obfuscate-browser-agent-data)를 참조하십시오.

페이로드 캡처 설정을 활성화한 후, 다음 페이지에서 캡처된 페이로드 데이터를 확인할 수 있습니다:

* [AJAX 요청 세부 정보](/docs/browser/browser-monitoring/browser-pro-features/ajax-page-identify-time-consuming-calls)
* [페이지 보기](/docs/browser/new-relic-browser/browser-pro-features/page-views-examine-page-performance)
* [세션 재생](/docs/browser/browser-monitoring/browser-pro-features/session-replay/get-started)

### 페이로드 캡처가 거부 목록과 상호 작용하는 방식 [#payload-deny-list]

페이로드 캡처는 기존 거부 목록을 준수합니다. 모든 AJAX 요청의 경우:

* URL이 거부 목록에 있는 경우 이벤트는 완전히 삭제되며 메타데이터나 페이로드는 캡처되지 않습니다.
* URL이 거부 목록에 없는 경우, 페이로드 캡처 설정에 따라 에이전트는 request 및 응답 페이로드를 캡처하고 데이터를 뉴렐릭으로 보내기 전에 난독화 룰을 적용합니다.
