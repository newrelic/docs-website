뉴렐릭 Elasticsearch 통합은 OpenTelemetry Collector를 사용하여 단일 공급업체 비종속 파이프라인을 통해 Elasticsearch 클러스터를 모니터링하므로, 메트릭과 로그를 위한 별도의 에이전트나 익스포터를 유지 관리할 필요가 없습니다. 연결되면 클러스터가 정상인지 확인하고, 중단이 발생하기 전에 문제를 파악하며, Elasticsearch에서 확인한 내용을 뉴렐릭의 나머지 스택과 상호 연관시킬 수 있습니다.

## 기능 [#capabilities]

* **메트릭**: 클러스터 상태, 샤드 분포, 노드 및 JVM 성능, 호스트 리소스 사용률(CPU, 메모리, 디스크, 네트워크)
* **로그**: 메트릭과 동일한 클러스터 및 노드 메타데이터와 상관관계가 있는 Elasticsearch 서버 로그입니다.
* **분산 추적**: Elasticsearch의 기본 OpenTelemetry 트레이스를 사용하여 APM 애플리케이션을 해당 애플리케이션이 호출하는 Elasticsearch 클러스터와 상관관계를 지정하십시오. [분산 추적을 사용하여 APM과 Elasticsearch 상관관계 지정](/docs/opentelemetry/integrations/elasticsearch/distributed-tracing)을 참조하십시오.

## 설치 경로 선택 [#choose]

**Self-hosted \[자체 호스팅]**: 서버 또는 VM에서 직접 실행되는 Elasticsearch용입니다.

* **NRDOT** (권장): 뉴렐릭의 OpenTelemetry Collector 배포판으로, 기존 수집기가 없는 경우 가장 직접적인 경로입니다.
* **OTel Collector Contrib**: 커뮤니티 OpenTelemetry Collector 배포판이며, 환경이 이미 이를 표준으로 사용하는 경우 선택하십시오.
* **Prometheus receiver \[Prometheus 수신기]**: 이미 [Prometheus Elasticsearch exporter](https://github.com/prometheus-community/elasticsearch_exporter)를 실행 중이며 수집기를 Elasticsearch에 직접 연결하는 대신 이를 재사용하려는 경우에만 선택하십시오.

**Kubernetes**: 자동 파드 검색을 지원하며 쿠버네티스 클러스터에서 실행되는 Elasticsearch용입니다.

* **NRDOT** (권장): 뉴렐릭의 OpenTelemetry Collector 배포판이며, 기존 수집기가 없는 경우 가장 직접적인 경로입니다. 기본 Kubernetes OpenTelemetry 매니페스트 설치를 이미 완료한 경우 [manifest install \[매니페스트 설치\]](/docs/opentelemetry/integrations/elasticsearch/install-configure/kubernetes/nrdot-manifest-install)를 선택하고, 더 간단한 단일 명령 배포를 원할 경우 [Helm install \[Helm 설치\]](/docs/opentelemetry/integrations/elasticsearch/install-configure/kubernetes/nrdot-helm-install)를 선택하십시오.
* **OTel Collector Contrib**: 커뮤니티 OpenTelemetry Collector 배포판이며, 환경이 이미 이를 표준으로 사용하는 경우 선택하십시오.
* **Prometheus receiver**: 위와 동일한 조건이며, 이미 클러스터 내에서 익스포터를 실행 중인 경우에만 해당합니다.

## 안내 설치 [#ui-install]

대신 뉴렐릭 UI를 통해 이를 설치하려면 <DNT>**[one.newrelic.com](https://onenr.io/0qwyANKOOwn) &gt; Integrations &amp; Agents &gt; Elasticsearch (OpenTelemetry Collector)**</DNT>로 이동하십시오. 화면의 지시에 따라 통합을 설정하십시오.

## 한눈에 보는 설치 [#at-a-glance]

1. 호환성을 확인하고 사전 요구 사항을 수집하십시오
2. 수집기를 설정하십시오.
3. 최소 설정을 적용하십시오
4. 수집기를 재시작하세요
5. 데이터가 뉴렐릭으로 전송되는지 확인하십시오
