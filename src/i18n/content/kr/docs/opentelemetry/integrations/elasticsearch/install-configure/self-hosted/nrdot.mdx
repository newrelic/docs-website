Linux 서버 또는 VM에서 자체 호스팅 Elasticsearch 클러스터를 모니터하도록 NRDOT을 설치하고 설정하려면 이 가이드를 사용하십시오. 설정을 완료하면 수집기는 Elasticsearch 클러스터 메트릭을 뉴렐릭으로 내보냅니다. 호스트 메트릭, 로그 및 사용자 지정 태그에 대해서는 [고급 설정](/docs/opentelemetry/integrations/elasticsearch/advanced-configuration)을 참조하십시오.

## 호환성 및 요구 사항 [#requirements]

### 지원

* Elasticsearch 7.16 이상

### 필요한 사항

* 뉴렐릭 [라이선스 키](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)
* 호스트의 root 또는 sudo 권한
* `monitor` 또는 `manage` 클러스터 권한이 있는 Elasticsearch 클러스터 관리자 권한([Elasticsearch 보안 권한](https://www.elastic.co/guide/en/elasticsearch/reference/current/security-privileges.html) 참조)
* 뉴렐릭의 [OTLP 엔드포인트](/docs/opentelemetry/best-practices/opentelemetry-otlp)에 대한 아웃바운드 HTTPS(포트 443) 연결
* Elasticsearch 사용자 이름 및 비밀번호(클러스터에 인증이 필요한 경우)

<Steps>
<Step>
## NRDOT 수집기 설치 [#install]

NRDOT 수집기를 설치하고 systemd 서비스로 실행하십시오. [NRDOT 설치](/docs/opentelemetry/nrdot/nrdot-collector/)를 참조하십시오.
</Step>

<Step>
## NRDOT 수집기를 구성합니다. [#configure]

Elasticsearch 모니터링을 활성화하려면 수집기의 기본 설정을 업데이트하십시오.

1. 수집기의 기본 설정을 백업한 다음, 편집을 위해 여십시오:

   ```bash
   sudo cp /etc/nrdot-collector/config.yaml /etc/nrdot-collector/config.yaml.backup
   sudo nano /etc/nrdot-collector/config.yaml
   ```

### 구성 매개변수 [#configuration-parameters]

다음 표는 위 설정에서 사용된 주요 설정 파라미터를 설명합니다:

| 매개변수                         | 설명                                                                                                    |
| ---------------------------- | ----------------------------------------------------------------------------------------------------- |
| `endpoint`                   | Elasticsearch 클러스터의 URL입니다.                                                                           |
| `collection_interval`        | 메트릭 스크랩 간격입니다. 기본값은 15s입니다.                                                                           |
| `elasticsearch.cluster.name` | 뉴렐릭에서 이 클러스터를 식별하는 고유한 이름입니다.                                                                         |
| `NEW_RELIC_MEMORY_LIMIT_MIB` | 사용자 환경에 맞게 설정된 수집기의 `memory_limiter` 프로세서에 대한 메모리 제한(MiB)입니다.                                         |
| `NEWRELIC_LICENSE_KEY`       | 귀하의 뉴렐릭 라이선스 키입니다.                                                                                    |
| `NEWRELIC_OTLP_ENDPOINT`     | [뉴렐릭 OTLP 엔드포인트](/docs/opentelemetry/best-practices/opentelemetry-otlp)에 따른 계정 지역의 뉴렐릭 OTLP 엔드포인트입니다. |

3. 설정 파일을 저장합니다.

보안 클러스터 인증, 호스트 메트릭, 로그 수집 또는 사용자 지정 메타데이터 태그를 선택적으로 추가할 수 있습니다. [고급 설정](/docs/opentelemetry/integrations/elasticsearch/advanced-configuration)을 참조하십시오.
</Step>

<Step>
## 환경 변수를 설정하십시오 [#env-vars]

수집기가 뉴렐릭으로 데이터를 전송하는 데 필요한 자격 증명 및 연결 세부 정보를 설정하십시오.

```bash
sudo mkdir -p /etc/systemd/system/nrdot-collector.service.d
cat <<EOF | sudo tee /etc/systemd/system/nrdot-collector.service.d/environment.conf
[Service]
Environment="NEWRELIC_OTLP_ENDPOINT=<YOUR_NEWRELIC_OTLP_ENDPOINT>"
Environment="NEWRELIC_LICENSE_KEY=<YOUR_NEWRELIC_LICENSE_KEY>"
Environment="NEW_RELIC_MEMORY_LIMIT_MIB=100"
EOF
```
</Step>

<Step>
## NRDOT 수집기 다시 시작 [#restart]

변경 사항을 적용하려면 수집기를 다시 시작하십시오:

```bash
sudo systemctl daemon-reload
sudo systemctl restart nrdot-collector.service
```
</Step>

<Step>
## 데이터 수집 확인 [#verify]

수집기를 다시 시작한 후 약 5분 이내에 뉴렐릭에서 이 쿼리를 실행하여 데이터가 흐르고 있는지 확인하십시오(`<YOUR_ELASTICSEARCH_CLUSTER_NAME>`을(를) 클러스터 이름으로 바꾸십시오):

```sql
FROM Metric SELECT count(*)
WHERE metricName LIKE 'elasticsearch.%'
AND elasticsearch.cluster.name = '<YOUR_ELASTICSEARCH_CLUSTER_NAME>'
SINCE 10 minutes ago
```

<Callout variant="tip">
수집기 자체를 확인할 수도 있습니다. `nrdot-collector.service`은(는) `active (running)` (`sudo systemctl status nrdot-collector.service`)을(를) 보고해야 하며, 로그(`sudo journalctl -u nrdot-collector.service -f`)에 연결 오류가 없어야 합니다.
</Callout>

약 5분 내에 데이터가 표시되지 않으면 [Elasticsearch 문제 진단, 해결](/docs/opentelemetry/integrations/elasticsearch/troubleshooting)을 참조하십시오.
</Step>

<Step>
## 데이터 찾기 및 사용 [#find-and-use]

뉴렐릭이 데이터를 수집하면 뉴렐릭 UI를 통해 Elasticsearch 모니터링에 액세스할 수 있습니다.

뉴렐릭에서 Elasticsearch 대시보드를 찾으려면:

1. <DNT>**one.newrelic.com &gt; Integrations &amp; Agents**</DNT> 으)로 이동합니다.
2. <DNT>**All**</DNT> 탭에서 <DNT>**Dashboards**</DNT>을(를) 클릭한 다음, <DNT>**Elasticsearch (OpenTelemetry Collector)**</DNT>을(를) 검색하여 대시보드를 확인하십시오.

또는 왼쪽 탐색 메뉴에서:

1. <DNT>**Dashboards**</DNT> 을(를) 클릭합니다.
2. <DNT>**Elasticsearch (OpenTelemetry Collector)**</DNT> 대시보드를 검색하여 확인하십시오.

NRDOT로 Elasticsearch 모니터링을 설정한 후 다음을 수행할 수 있습니다:

* Elasticsearch 메트릭을 시각화하기 위한 [커스텀 대시보드 생성](/docs/query-your-data/explore-query-data/dashboards/introduction-dashboards/)
* 중요한 클러스터 상태 및 성능 임계값에 대한 [알림 설정](/docs/alerts/create-alert/create-alert-condition/alert-conditions/)
* 뉴렐릭 쿼리 기능을 사용하여 [데이터 탐색](/docs/query-your-data/explore-query-data/browse-data/introduction-data-explorer/)
</Step>
</Steps>

<Callout variant="tip">
**APM과 Elasticsearch 연관시키기**: APM 애플리케이션과 Elasticsearch 클러스터를 연결하려면 APM 메트릭에 리소스 속성 `es.cluster.name="your-cluster-name"`을(를) 포함하십시오. 이를 통해 뉴렐릭에서 APM 및 Elasticsearch 데이터를 함께 볼 수 있습니다.
</Callout>
