도커 OpenTelemetry 통합은 도커 엔진에서 직접 실시간 메트릭을 수집하여 컨테이너화된 애플리케이션의 상태와 성능을 모니터합니다. 실행 중인 모든 컨테이너의 CPU 사용량, 메모리, 네트워크 I/O 및 디스크 I/O에 대한 가시성을 확보할 수 있으므로 서비스에 영향을 미치기 전에 리소스 병목현상과 컨테이너 장애를 발견할 수 있습니다.

## 기능 [#capabilities]

이 통합은 다음을 제공합니다:

* **메트릭**: CPU 사용량 및 활용도, 메모리 사용량 및 백분율, 네트워크 I/O(송수신된 바이트 및 패킷, 드롭 및 오류), 블록 I/O 및 프로세스(PID) 수
* **엔티티**: 도커 컨테이너는 뉴렐릭에서 호스트에 연결된 모니터 엔티티로 표시됩니다.
* **로그**: 컨테이너에서 로그를 수집합니다. 설정 단계는 [고급 설정](/docs/opentelemetry/integrations/docker/advanced-configuration#logs)을 참조하십시오.

## 설치 경로 선택 [#choose]

* **[NRDOT Collector](/docs/opentelemetry/integrations/docker/install-nrdot) (권장)**: 뉴렐릭으로 데이터를 전송하도록 사전 구성된 뉴렐릭의 OpenTelemetry 배포판입니다. 아직 다른 OpenTelemetry Collector를 실행하고 있지 않은 경우 이를 사용하십시오.
* **[OpenTelemetry Collector Contrib](/docs/opentelemetry/integrations/docker/install-otelcol-contrib)**: 업스트림 커뮤니티 수집기입니다. 이미 다른 워크로드에 대해 OpenTelemetry Collector Contrib을 실행 중이고 동일한 인스턴스에 도커 모니터링을 추가하려는 경우 이를 사용하십시오.

## 한눈에 보는 설치 [#at-a-glance]

설치 페이지에서 다음 과정을 안내합니다:

1. 호환성을 확인하고 사전 요구 사항을 수집하십시오
2. 선택한 수집기를 설치하십시오
3. 도커 소켓 권한을 설정하십시오.
4. 수집기 구성
5. 수집기를 재시작하세요
6. 데이터가 뉴렐릭으로 전송되는지 확인하십시오
