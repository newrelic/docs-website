Linkerd OTel 통합은 OpenTelemetry Collector의 [Prometheus 수신자](https://github.com/open-telemetry/opentelemetry-collector-contrib/tree/main/receiver/prometheusreceiver)를 사용하여 Linkerd 프록시 관리자 포트(`:4191`) 및 컨트롤 플레인 파드를 스크랩하여 메트릭을 수집합니다.

## 기본 비활성화 메트릭 [#default-off]

<Callout variant="tip">
  이러한 그룹은 안정 상태에서 운영상의 가치를 제공하지 않으므로 기본적으로 비활성화되어 있습니다. 설명된 특정 문제를 적극적으로 디버깅할 때만 활성화하십시오.
</Callout>
