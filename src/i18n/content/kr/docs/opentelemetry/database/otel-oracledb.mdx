  이 기능은 현재 [사전 출시 정책](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy/) 에 따라 미리보기의 일부로 제공됩니다.

이제 뉴렐릭은 뉴렐릭 데이터베이스 모니터링 기능과 함께 뉴렐릭 NRDOT(Distribution of OpenTelemetry)를 사용하여 팀이 오라클 데이터베이스 성능을 모니터링할 수 있도록 지원합니다. 이 통합은 NRDOT 수집기를 사용하여 데이터베이스 메트릭, 쿼리 성능 및 시스템 상태에 대한 포괄적인 인사이트를 제공합니다.

이 NRDOT 기반 접근 방식은 모니터링을 위한 OpenTelemetry 데이터베이스 표준을 활용하여 기존 온호스트 통합(OHI)을 보완하고 기존 옵저버빌리티 그리드와 통합을 더 쉽게 만듭니다.

## 전제 조건 [#prerequisites]

시작하기 전에 다음 사항이 있는지 확인하세요.

* 유효한 뉴렐릭 [클러스터](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)
* 지원 아키텍처: AMD64 및 ARM64 기반의 Linux
* 뉴렐릭 OTLP 엔드포인트에 대한 네트워크 연결
* 작업 데이터베이스 19c 이상
* 이 통합은 뉴렐릭 퍼블릭 프리뷰 프로그램의 일환으로 제공됩니다. [미리 보기 및 평가판](https://one.newrelic.com/admin-portal/promotion-management/home) 페이지에서 옵트인하려면 조직 관리자에게 문의하세요.

## 작업 데이터베이스 모니터링을 위한 NRDOT Collector 설정 [#install-collector]

온호스트(멀티테넌트) 또는 RDS 환경에서 NRDOT Collector를 사용하여 오라클 데이터베이스 모니터링을 설정할 수 있습니다. 다음 방법을 사용하여 NRDOT Collector를 구성할 수 있습니다:

* [안내 설치](/docs/opentelemetry/database/otel-oracledb/#guided): 안내 설치 방법은 오라클 데이터베이스 모니터링을 위해 NRDOT Collector를 설치하고 구성하는 데 도움이 되도록 뉴렐릭 플랫폼에서 단계별 지침을 제공합니다.

* **수동 설치**: 수동 설치 방법을 사용하면 이 문서의 지침에 따라 NRDOT Collector를 직접 설정할 수 있습니다. 다음 환경에서 수동으로 구성할 수 있습니다:

  * [호스트 내(멀티테넌트) 환경](/docs/opentelemetry/database/otel-oracledb/#host): 인프라 및 데이터베이스 텔레메트리 데이터를 모두 수집하려면 오라클 데이터베이스 인스턴스와 동일한 호스트에 NRDOT Collector를 설치하십시오.
  * [RDS 환경](/docs/opentelemetry/database/otel-oracledb/#rds): Amazon RDS에서 실행되는 오라클 데이터베이스 인스턴스를 모니터링하려면 RDS 환경에 NRDOT Collector를 설치하십시오.

<Callout variant="tip">
  NRDOT Collector는 인프라 및 데이터베이스 관련 텔레메트리 데이터를 모두 수집하므로, 뉴렐릭에서 오라클 데이터베이스 환경을 위한 통합 옵저버빌리티 솔루션을 구축할 수 있습니다.
</Callout>

              <Step>
                ### 데이터베이스 사용자 구성 [#mdatabase-user]

                멀티테넌트 오라클 데이터베이스에 필요한 권한을 가진 모니터링 사용자를 생성하십시오. 이를 위해서는 `C##` 접두사를 가진 공통 사용자를 생성해야 합니다.

                1. 데이터베이스 사용자를 생성하거나 할당 권한을 부여하기 전에, `SYS` 사용자로 다음 문을 실행하여 현재 활성 컨테이너 컨텍스트를 `CDB$ROOT`(으)로 설정해야 합니다:

                   ```sql
                   ALTER SESSION SET CONTAINER = CDB$ROOT;
                   ```

                2. 멀티테넌트 데이터베이스의 경우 관리자로 루트 데이터베이스에 로그인합니다. CREATE USER를 사용하여 데이터베이스에 새 사용자를 추가합니다. 지정된 사용자 이름은 &apos;공통 사용자&apos;가 되며 오라클에서 권장하는 대로 `c##`을(를) 접두사로 사용해야 합니다.

                   ```sql
                   CREATE USER c##<YOUR_DB_USERNAME> IDENTIFIED BY "<USER_PASSWORD>" CONTAINER=ALL;
                   GRANT CREATE SESSION TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
                   ```

                3. CDB 루트에서 SYSDBA로 다음 문을 실행하십시오. 이를 통해 모니터링 사용자는 컨테이너 데이터 뷰에서 모든 PDB의 행을 볼 수 있으며, 이는 PDB별 메트릭 및 이벤트에 필요합니다.

                   ```sql
                   ALTER USER c##<YOUR_DB_USERNAME> SET CONTAINER_DATA=ALL CONTAINER=CURRENT;
                   ```

                   <Callout variant="tip">
                     `USER_PASSWORD`이(가) 오라클 [새 사용자 비밀번호](https://docs.oracle.com/en/database/oracle/oracle-database/12.2/dbseg/keeping-your-oracle-database-secure.html#GUID-451679EB-8676-47E6-82A6-DF025FD65156) 요구 사항을 충족하는지 확인하십시오.
                   </Callout>
              </Step>

                ```sql

                GRANT SELECT ON V_$DATAFILE   TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON V_$SYSSTAT                    TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON V_$CON_SYSSTAT                TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON V_$SYSMETRIC                  TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON V_$CON_SYSMETRIC              TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON V_$SESSION                    TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON V_$RESOURCE_LIMIT             TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON V_$OSSTAT                     TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON V_$SGAINFO                    TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON V_$ROWCACHE                   TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON V_$PARAMETER                  TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON CDB_TABLESPACE_USAGE_METRICS  TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON CDB_TABLESPACES               TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON DBA_DATA_FILES                TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON DBA_FREE_SPACE                TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON DBA_RECYCLEBIN                TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON V_$SQL            TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON V_$SQL_PLAN_STATISTICS_ALL       TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON V_$LOCK           TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON V_$SESSION_EVENT  TO c##<USER_NAME> CONTAINER=ALL;

                GRANT SELECT ON DBA_OBJECTS       TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON V_$PDBS           TO c##<USER_NAME> CONTAINER=ALL;
                GRANT SELECT ON CDB_SERVICES      TO c##<USER_NAME> CONTAINER=ALL;
                ```

          ### Autonomous Database에 대한 모니터링 권한 부여 [#adb-database-grants]

          GRANT SELECT ON SYS.V_$INSTANCE   TO <USER_NAME>;
          GRANT SELECT ON SYS.V_$DATABASE   TO <USER_NAME>;

## NRDOT 수집기 지원 명령 [#commands]

이 섹션에서는 시스템에서 NRDOT Collector 서비스를 관리하는 데 사용되는 일반적인 명령 목록을 제공합니다.

<CollapserGroup>
  <Collapser title="NRDOT Collector 명령" id="command">
    * 설치 상태를 확인하려면:

      * 데비안/우분투 기반 배포판의 경우:

        ```bash
        dpkg -l | grep nrdot-collector
        ```

      * RHEL/CentOS 기반 배포판의 경우:

        ```bash
        rpm -q nrdot-collector || ls /etc/nrdot-collector
        ```

    * NRDOT Collector를 다시 시작하려면:

    ```bash
    sudo systemctl restart nrdot-collector.service
    ```

    * NRDOT Collector 상태를 확인하려면 다음을 참조하십시오.

    ```bash
    sudo systemctl status nrdot-collector.service
    ```

    * NRDOT Collector 로그를 보려면:

    ```bash
    sudo journalctl -u nrdot-collector -n 50 --no-pager
    ```

    * NRDOT Collector 서비스를 삭제하려면:

      * 데비안/우분투 기반 배포판의 경우:

        ```bash
        sudo apt purge nrdot-collector
        ```

      * RHEL/CentOS 기반 배포판의 경우:

        ```bash
        sudo yum erase nrdot-collector
        ```

    * 설정 파일을 정리하려면:

    ```bash
    # Clean up configuration and reload systemd
    sudo rm -rf /etc/nrdot-collector/
    sudo systemctl daemon-reload
    ```
  </Collapser>
</CollapserGroup>

## 문제점 해결 [#troubleshoot]

설치 중에 문제가 발생하면 이 문제 진단 및 해결 가이드를 사용하여 일반적인 문제를 진단하고 해결하십시오.

<CollapserGroup>
  <Collapser id="test-connection" title="네트워크 연결 테스트">
    다음 명령을 실행하여 이 호스트에서 오라클 데이터베이스 포트에 연결할 수 있는지 확인합니다.

    ```bash
    (timeout 3 bash -c '</dev/tcp/<YOUR_ENDPOINT>/<YOUR_PORT>' && echo "PORT OPEN - Network connection successful!") || echo "CONNECTION FAILED - Port closed or firewall blocking"
    ```

    **예상 출력:** `PORT OPEN - Network connection successful!`
  </Collapser>

  <Collapser id="otlp-endpoint-connection" title="OTLP 엔드포인트 연결 테스트">
    호스트가 선택한 뉴렐릭 OTLP 엔드포인트에 도달할 수 있는지 확인하려면 다음 명령을 실행하십시오.

    ```bash
    ENDPOINT="<YOUR_OTLP_ENDPOINT>"
    HOST=$(echo "$ENDPOINT" | sed 's|https://||' | cut -d: -f1)
    PORT=$(echo "$ENDPOINT" | awk -F: '{print $NF}')
    (timeout 2 bash -c "</dev/tcp/$HOST/$PORT" && echo "✅ SUCCESS") || echo "❌ FAILED"
    ```

    **예상 출력:** `✅ SUCCESS`
  </Collapser>
</CollapserGroup>
