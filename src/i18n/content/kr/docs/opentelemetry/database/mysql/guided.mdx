<Callout title="시사">
  이 기능은 아직 개발 중이지만 꼭 사용해 보시기 바랍니다!

  이 기능은 현재 [사전 출시 정책](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy/) 에 따라 미리보기의 일부로 제공됩니다.
</Callout>

뉴렐릭 플랫폼의 안내 설치를 사용하여 MySQL 모니터링용 NRDOT Collector를 설치할 수 있으며, 이는 뉴렐릭의 UI를 통해 플랫폼 안내 설정을 제공합니다. 이는 빠른 시작을 위해 권장되는 방법입니다.

<Steps>
  <Step>
    ### 전제 조건 [#prerequisites]

    사용 중인 환경이 [호환성 및 사전 요구 사항](/docs/opentelemetry/database/mysql/compatibility)을 충족하는지 확인하십시오.
  </Step>

  <Step>
    ### 안내 설치 [#guided]

    안내 설치를 사용하여 NRDOT Collector를 설치하려면:

    1. [뉴렐릭 계정](https://one.newrelic.com/)에 로그인하세요.

    2. <DNT>**left navigation pane &gt; + Integration &amp; Agents &gt; MySQL (OpenTelemetry)**</DNT> 으)로 이동합니다.

    3. <DNT>Select an account</DNT> 화면에서 MySQL 통합을 설치할 계정을 선택하고 <DNT>**Continue**</DNT>을(를) 클릭합니다.

    4. <DNT>Enter your credential</DNT> 화면에서 다음 옵션 중 하나를 선택한 다음 **Continue** \[계속을] 클릭합니다:

       * **기존 키 사용**: 이미 라이선스 키가 있는 경우, 라이선스 키를 제공하십시오. 자세한 내용은 [사용자 키를](/docs/apis/intro-apis/new-relic-api-keys/#user-key) 참조하세요.
       * **새 키 만들기**: 라이선스 키가 없으면 **Create a new key** \[새 키 만들기를] 클릭하여 키를 만듭니다.

    5. <DNT>Select platform</DNT> 화면에서 MySQL 통합을 설치할 플랫폼을 선택하고 <DNT>**Continue**</DNT>을(를) 클릭합니다.

    6. 화면의 지시에 따라 선택한 플랫폼에 대한 통합을 설정하세요.

    7. 설치 후 <DNT>Test your integration</DNT> 화면에서 **Test connection** \[연결 테스트]을 클릭하여 NRDOT Collector가 MySQL 인스턴스에 연결하고 뉴렐릭으로 데이터를 전송할 수 있는지 확인합니다.
  </Step>

  <Step>
    ### (선택 사항) APM-데이터베이스 상관 관계 설정 [#optional-service-id]

    애플리케이션 성능을 데이터베이스 작업과 연관시키려면 데이터베이스 서비스 식별을 설정할 수 있습니다. 이 기능을 사용하면 어떤 애플리케이션이 특정 데이터베이스 워크로드를 생성하는지 정확히 확인할 수 있습니다. 자세한 내용은 뉴렐릭에서 APM-데이터베이스 상관관계를 얻기 위한 [데이터베이스 서비스 식별 설정](/docs/opentelemetry/database/capabilities/db-apm/)을 참조하십시오.

    <Callout variant="important">
      APM 에서 데이터베이스 성능 데이터를 보려면 두 가지 모두 동일한 뉴렐릭 계정에 있어야 합니다. 만약 데이터가 서로 다른 뉴럴릭 계정에 있다면, 데이터를 보려면 두 계정 모두에 접근 권한이 있어야 합니다.
    </Callout>
  </Step>

  <Step>
    ### 데이터 찾기 및 사용 [#find-use-data]

    데이터가 수집되면 뉴렐릭의 UI를 통해 포괄적인 MySQL 데이터베이스 모니터링에 액세스할 수 있습니다.

    뉴렐릭에서 MySQL 데이터베이스 엔티티를 찾으려면 다음을 수행하십시오:

    1. <DNT>**[https://one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT> 으)로 이동합니다.
    2. **<DNT>Entity type</DNT>** 드롭다운 메뉴에서 <DNT>**MySQL instance**</DNT>을(를) 선택한 다음 <DNT>**Apply**</DNT>을(를) 클릭합니다.
    3. 엔티티 목록에서 MySQL 데이터베이스를 선택하십시오.
  </Step>
</Steps>

## 무엇 향후 계획

NRDOT를 사용하여 MySQL 데이터베이스 모니터링을 설정한 후:

* [사용자 정의 대시보드를 만들어](/docs/query-your-data/explore-query-data/dashboards/introduction-dashboards/) 데이터베이스 지표를 시각화하세요.
* 중요한 데이터베이스 성능에 대한 [알림 설정](/docs/alerts/create-alert/create-alert-condition/alert-conditions/), 참조 값
* NRDOT 수집기가 수집한 [사용 가능한 메트릭을 탐색하십시오](/docs/opentelemetry/database/mysql/metrics-reference)
* 모니터링 설정과 관련된 [일반적인 문제를 해결하십시오](/docs/opentelemetry/database/mysql/troubleshooting)
