NRDOT Collector가 수집한 포괄적인 메트릭으로 오라클 데이터베이스 성능을 모니터링하십시오. NRDOT를 사용한 오라클 데이터베이스 모니터링에 다음 메트릭을 사용할 수 있습니다. 이를 수집하려면 설정에서 관련 스크레이퍼를 활성화하십시오.
