<Callout title="시사">
  이 기능은 아직 개발 중이지만 꼭 사용해 보시기 바랍니다!

  이 기능은 현재 [사전 출시 정책](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy/) 에 따라 미리보기의 일부로 제공됩니다.
</Callout>

하나의 수집기에서 여러 오라클 데이터베이스 인스턴스를 모니터하도록 NRDOT Collector를 구성할 수 있습니다. 이는 서로 다른 호스트에서 실행되는 여러 오라클 데이터베이스가 있고 단일 NRDOT Collector 인스턴스를 사용하여 이들 모두에서 메트릭을 수집하려는 경우에 유용합니다.

<Steps>
  <Step>
    ## 전제 조건 [#prerequisites]

    * 오라클 데이터베이스 인스턴스에 NRDOT가 설치 및 구성되었습니다:

      * [CDB](/docs/opentelemetry/database/oracle/host-cdb)
      * [PDB](/docs/opentelemetry/database/oracle/host-pdb)
      * [RDS](/docs/opentelemetry/database/oracle/rds)
      * [ADB](/docs/opentelemetry/database/oracle/adb)
  </Step>

  <Step>
    ## 다중 수신기 설정 추가 [#multi]

    다음 예제는 다중 수신기 설정을 사용하여 여러 오라클 데이터베이스 인스턴스를 모니터하도록 NRDOT Collector를 설정하는 방법을 보여줍니다. 환경에 맞는 배포 유형을 선택하십시오. 추가 인스턴스를 위해 필요에 따라 수신기를 더 추가할 수 있습니다.

        ```yaml
            endpoint: "<YOUR_DB_HOST>:<YOUR_DB_PORT>"
            username: "C##<user_name>"
            password: "<password>"
            service: "<YOUR_CDB1_SERVICE_NAME>"

              db.server.query_sample:
                enabled: true
              db.server.top_query:
                enabled: true
              db.server.session.wait_sample:
                enabled: true

              max_query_sample_count: 1000
              top_query_count: 200
              collection_interval: 60s
              allowed_comment_keys:
                - nr_service_guid

              max_rows_per_query: 100
              allowed_comment_keys:
                - nr_service_guid

            session_wait_event_collection:
              max_rows_per_query: 100

                enabled: true
              oracle.db.open_mode:
                enabled: true
              oracle.db.pdb:
                enabled: true
              oracle.db.role:
                enabled: true
              oracle.db.version:
                enabled: true
              oracledb.instance.name:
                enabled: true
              service.instance.id:
                enabled: true

          # First CDB's PDB configuration
          nroracledb/pdb1:
            <<: *nroracledb-common
            service: "<YOUR_PDB1_SERVICE_NAME>"

          # Second CDB configuration
          nroracledb/cdb2:
            <<: *nroracledb-common
            endpoint: "<YOUR_DB2_HOST>:<YOUR_DB2_PORT>"
            service: "<YOUR_CDB2_SERVICE_NAME>"

          # Second CDB's PDB configuration
          nroracledb/pdb2:
            <<: *nroracledb-common
            endpoint: "<YOUR_DB2_HOST>:<YOUR_DB2_PORT>"
            service: "<YOUR_PDB2_SERVICE_NAME>"

        processors:
          batch:
          resource/add_event_name:
            attributes:
              - key: host.address
                value: "<host_address>"
                action: upsert

        exporters:
          otlp/newrelic:
            endpoint: "<otlp_endpoint>"
            headers:
              api-key: "<license_key>"
            compression: gzip
            retry_on_failure:
              enabled: true
              initial_interval: 5s
              max_interval: 30s
              max_elapsed_time: 300s

        service:
          pipelines:
            metrics/oracledb:
              receivers: [nroracledb/cdb1, nroracledb/pdb1, nroracledb/cdb2, nroracledb/pdb2]
              processors: [resource/add_event_name, batch]
              exporters: [otlp/newrelic]
            logs/oracledb:
              receivers: [nroracledb/cdb1, nroracledb/pdb1, nroracledb/cdb2, nroracledb/pdb2]
              processors: [resource/add_event_name, batch]
              exporters: [otlp/newrelic]
        ```

      <Collapser id="adb" title="Autonomous Database(ADB)용">
        동일한 수집기에서 여러 오라클 ADB 인스턴스를 모니터링하려면, 다른 이름과 연결 세부 정보가 있는 추가 수신기 블록을 추가하여 설정 파일에 여러 수신기를 설정할 수 있습니다.
      </Collapser>
    </CollapserGroup>

    <Callout variant="tip">
      이 설정을 통해 여러 오라클 데이터베이스 인스턴스를 동시에 모니터할 수 있습니다. 각 인스턴스는 고유한 자격 증명이 있는 자체 수신기 설정을 가지며, 공통 프로세서와 익스포터를 공유합니다. 모니터링 요구 사항에 따라 `collection_interval` 및 기타 파라미터를 조정하십시오.
    </Callout>
  </Step>

  <Step>
    ## NRDOT Collector를 다시 시작하십시오 [#restart]

    다시 시작하는 것은 선택 사항이 아니라 필수입니다 — 수집기는 시작 시 설정을 한 번 로드하며 핫 리로드하지 않습니다. 프로세스를 다시 시작할 때까지 모든 설정 변경 사항은 적용되지 않습니다.

    ```bash
    sudo systemctl restart nrdot-collector.service
    ```
  </Step>
