  이 기능은 현재 [사전 출시 정책](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy/) 에 따라 미리보기의 일부로 제공됩니다.

오라클 데이터베이스용 OpenTelemetry Collector Contribution을 사용하여 인스턴스를 모니터할 수 있습니다. OpenTelemetry Collector Contribution은 오라클 데이터베이스에서 텔레메트리 데이터를 수집하여 뉴렐릭으로 전송하는 방법을 제공하는 커뮤니티 지원 프로젝트입니다.

기본적으로 OpenTelemetry Collector Contribution은 오라클 데이터베이스에서 메트릭을 수집하여 뉴렐릭으로 전송합니다. 하지만 이는 제한된 메트릭입니다. 쿼리 성능 메트릭, 대기 시간 메트릭, 세션 메트릭, ASM 스토리지 메트릭 및 기타 고급 메트릭을 전송하려면 OpenTelemetry Collector Contribution을 설정해야 합니다. 이 가이드는 오라클 데이터베이스에서 고급 메트릭을 수집하여 뉴렐릭으로 전송하도록 OpenTelemetry Collector Contribution을 설정하는 방법에 대한 지침을 제공합니다.

<Steps>
  <Step>
    ## 전제 조건 [#prerequisites]

    * 시스템에 OpenTelemetry Collector Contrib(`otelcol-contrib`)이(가) 설치 및 설정되었습니다. [OpenTelemetry Collector 릴리스](https://github.com/open-telemetry/opentelemetry-collector-releases/releases) 페이지에서 최신 릴리스를 다운로드할 수 있습니다.
  </Step>

  <Step>
    ## UI 메트릭 활성화 [#enable]

    `otelcol-contrib` 설정 파일에 다양한 메트릭을 추가하고 활성화하여 뉴렐릭 플랫폼 환경을 개선할 수 있습니다. 이 섹션에 제공된 설정을 사용하면 뉴렐릭 플랫폼의 다음 페이지에 데이터를 채울 수 있습니다:

    * <DNT>Overview</DNT>
    * <DNT>Query performance</DNT>
    * <DNT>Wait events</DNT>
    * <DNT>Sessions</DNT>

    <CollapserGroup>
      <Collapser id="overview" title="개요 페이지 메트릭 활성화">
        <DNT>Overview</DNT> 페이지는 CPU 사용률, 대기 시간, I/O, 메모리 및 세션 사용량과 같은 주요 메트릭을 포함하여 오라클 데이터베이스 인스턴스의 상위 수준 뷰를 표시합니다.

        뉴렐릭 플랫폼의 <DNT>Overview</DNT> 페이지에 데이터를 채우려면 `otelcol-contrib` 설정 파일에 다음 설정을 추가하십시오:

        ```yaml
        receivers:
          oracledb:
            # Metrics required by the "Oracle Database Monitoring (OTel)" dashboard
            metrics:
              oracledb.buffer_cache.utilization:
                enabled: true
              oracledb.consistent_gets:
                enabled: true
              oracledb.cpu_time:
                enabled: true
              oracledb.database.cpu.utilization:
                enabled: true
              oracledb.database.wait.utilization:
                enabled: true
              oracledb.db_block_gets:
                enabled: true
              oracledb.enqueue_deadlocks:
                enabled: true
              oracledb.execution.utilization:
                enabled: true
              oracledb.executions:
                enabled: true
              oracledb.hard_parses:
                enabled: true
              oracledb.host.cpu.utilization:
                enabled: true
              oracledb.library_cache.utilization:
                enabled: true
              oracledb.logical_reads:
                enabled: true
              oracledb.logons:
                enabled: true
              oracledb.parse.rate:
                enabled: true
              oracledb.parse_calls:
                enabled: true
              oracledb.pga_memory:
                enabled: true
              oracledb.physical_io.requests:
                enabled: true
              oracledb.physical_reads:
                enabled: true
              oracledb.physical_writes:
                enabled: true
              oracledb.processes.usage:
                enabled: true
              oracledb.sessions.usage:
                enabled: true
              oracledb.sga.usage:
                enabled: true
              oracledb.shared_pool.utilization:
                enabled: true
              oracledb.sql_service.response.duration:
                enabled: true
              oracledb.sqlnet.io.transferred:
                enabled: true
              oracledb.tablespace_size.usage:
                enabled: true
              oracledb.transactions.usage:
                enabled: true
              oracledb.user_commits:
                enabled: true
              oracledb.user_rollbacks:
                enabled: true
        ```
      </Collapser>

      <Collapser id="query-performance" title="쿼리 성능, 세션 및 대기 메트릭 활성화">
        <DNT>Query performance</DNT>, <DNT>Wait events</DNT> 및 <DNT>Sessions</DNT> 페이지에 데이터를 채우려면 `otelcol-contrib` 설정 파일에 다음 설정을 추가하십시오:

        ```yaml
        receivers:
          oracledb:
            events:
              db.server.query_sample:
                enabled: true
              db.server.top_query:
                enabled: true
              db.server.session.wait_sample:
                enabled: true

            top_query_collection:
              max_query_sample_count: 1000
              top_query_count: 200
              collection_interval: 60s
              allowed_comment_keys:
                - nr_service_guid

            query_sample_collection:
              max_rows_per_query: 100
              allowed_comment_keys:
                - nr_service_guid

            session_wait_event_collection:
              max_rows_per_query: 100
        ```
      </Collapser>

      <Collapser id="asm" title="ASM 디스크 그룹 및 디스크 메트릭을 활성화하십시오.">
        오라클 데이터베이스 리시버는 ASM(Automatic Storage Management) 인스턴스 모니터링을 지원합니다. 리시버는 디스크 그룹 용량, 사용 가능한 여유 공간, 오프라인 디스크 및 물리적 디스크 읽기/쓰기 오류를 포함한 중요한 스토리지 상태 메트릭을 수집합니다.

        액세스 권한을 부여하려면 권한이 있는 오라클 사용자로 다음을 실행하십시오:

        ```sql
        GRANT SELECT ON V_$ASM_DISKGROUP_STAT TO <username>;
        GRANT SELECT ON V_$ASM_DISK_STAT TO <username>;
        ```

        다음 설정을 `otelcol-contrib` 설정 파일에 추가하십시오. 5개의 메트릭은 모두 **기본적으로 비활성화** 되어 있습니다(옵트인):

        ```yaml
        receivers:
          oracledb:
            datasource: "oracle://otel:password@localhost:51521/XE"
            metrics:
              oracledb.asm.disk_group.free:
                enabled: true
              oracledb.asm.disk_group.capacity:
                enabled: true
              oracledb.asm.disk_group.usable_free:
                enabled: true
              oracledb.asm.disk_group.offline_disks:
                enabled: true
              oracledb.asm.disk.errors:
                enabled: true
        ```

        이러한 메트릭에 대한 설명은 [메트릭 참조](/docs/opentelemetry/database/oracle/metrics-reference/#asm)를 참고하십시오.
      </Collapser>
    </CollapserGroup>
  </Step>

  <Step>
    ## OpenTelemetry Collector 다시 시작 [#restart]

    설정 변경 사항을 적용하려면 OpenTelemetry Collector를 다시 시작합니다:

    ```bash
    sudo systemctl restart otelcol-contrib
    ```
  </Step>
</Steps>
