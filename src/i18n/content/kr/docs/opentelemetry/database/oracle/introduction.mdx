OpenTelemetry 기반 모니터링 솔루션으로 오라클 데이터베이스 성능에 대한 깊은 인사이트를 얻으십시오. 데이터베이스 메트릭을 추적하고, 쿼리 성능을 분석하며, 리소스 사용량을 모니터하고, 데이터베이스 성능을 애플리케이션과 연관시키십시오.

이 NRDOT 기반 접근 방식은 모니터링을 위한 OpenTelemetry 데이터베이스 표준을 활용하여 기존 온호스트 통합(OHI)을 보완하고 기존 옵저버빌리티 그리드와 통합을 더 쉽게 만듭니다.

## 기능 [#capabilities]

* **OpenTelemetry 표준**: 기존 옵저버빌리티 도구와 원활하게 통합됩니다.
* **포괄적인 메트릭**: 데이터베이스 성능, 대기 이벤트 및 리소스 사용량에 대한 심층적인 인사이트
* **쿼리 수준 인사이트**: 느리게 실행되는 쿼리 및 세션 활동을 식별하고 분석합니다.
* **유연한 배포**: 온호스트 CDB/PDB 및 Amazon RDS 환경에서 작동합니다.
* **APM 상관관계**: 데이터베이스 성능을 애플리케이션 트레이스에 연결합니다.

## 설치 경로 선택 [#choose]

다음과 같은 방법으로 오라클 데이터베이스 모니터링을 위한 NRDOT Collector를 설치할 수 있습니다:

* 자체 호스팅 환경: 자체 인프라에 수동 설치

  * [온호스트 컨테이너 데이터베이스(CDB)](/docs/opentelemetry/database/oracle/host-cdb): 하위의 모든 플러거블 데이터베이스를 포함하여 전체 컨테이너 데이터베이스를 모니터합니다.
  * [온호스트 플러거블 데이터베이스(PDB)](/docs/opentelemetry/database/oracle/host-pdb): 개별 플러거블 데이터베이스를 모니터합니다.

* AWS RDS 환경: 클라우드 관리형 오라클 데이터베이스 모니터링
  * [RDS 모니터링](/docs/opentelemetry/database/oracle/rds): Amazon RDS에서 실행되는 오라클 데이터베이스 인스턴스를 모니터링합니다.

* 오라클 클라우드 환경: 완전 관리형 오라클 데이터베이스 모니터링
  * [Autonomous Database(ADB) 모니터링](/docs/opentelemetry/database/oracle/adb): 오라클 Autonomous Database 인스턴스를 모니터하십시오.

## 가이드 설치 [#ui-install]

<DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; Oracle (OpenTelemetry)**</DNT>에서 가이드 설치를 사용할 수 있습니다. UI는 가이드가 포함된 엔드투엔드 워크플로우를 제공합니다.

## 한눈에 보는 설치 [#at-a-glance]

<Steps>
  <Step>
    ### 전제 조건 [#prerequisites]

    * 유효한 뉴렐릭 [클러스터](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)
    * 지원 아키텍처: AMD64 및 ARM64 기반의 Linux
    * [뉴렐릭 OTLP 엔드포인트](/docs/opentelemetry/best-practices/opentelemetry-otlp/)에 대한 네트워크 연결
    * 작업 데이터베이스 19c 이상
  </Step>

  <Step>
    ### NRDOT Collector설치하세요 [#install-step]

    특정 환경에 대한 지침에 따라 시스템에 NRDOT Collector를 설치하십시오.

    * [CDB](/docs/opentelemetry/database/oracle/host-cdb)
    * [PDB](/docs/opentelemetry/database/oracle/host-pdb)
    * [RDS](/docs/opentelemetry/database/oracle/rds)
    * [ADB](/docs/opentelemetry/database/oracle/adb)
  </Step>

  <Step>
    ### 모니터링 사용자 구성 [#user]

    NRDOT Collector가 메트릭 및 쿼리 성능 데이터를 수집할 수 있도록 필요한 읽기 전용 권한을 가진 전용 오라클 데이터베이스 사용자를 생성하십시오.
  </Step>

  <Step>
    ### NRDOT Collector구성 [#configure]

    오라클 데이터베이스 인스턴스에 연결하도록 NRDOT Collector를 구성하십시오. 여기에는 환경에 필요한 연결 세부 정보, 인증 방법 및 추가 설정 옵션을 지정하는 것이 포함됩니다.
  </Step>

  <Step>
    ### NRDOT Collector를 다시 시작하십시오 [#restart]

    NRDOT Collector를 구성한 후 서비스를 다시 시작하여 변경 사항을 적용하고 Oracle Database 인스턴스에서 데이터 수집을 시작하십시오.
  </Step>

  <Step>
    ### 데이터 찾기 및 사용 [#find]

    데이터가 수집되면 뉴렐릭 UI를 통해 포괄적인 오라클 데이터베이스 모니터링에 액세스할 수 있습니다.

    뉴렐릭에서 오라클 데이터베이스 엔티티를 찾으려면 다음을 수행하세요:

    1. <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT> 으)로 이동합니다.
    2. 검색 기준을 <DNT>`instrumentation.provider = opentelemetry`</DNT> 으로 설정합니다.
    3. 엔티티 목록에서 오라클 데이터베이스를 선택합니다.
  </Step>
</Steps>
