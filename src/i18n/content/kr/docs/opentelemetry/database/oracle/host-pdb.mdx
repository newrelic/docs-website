<Callout title="시사">
  이 기능은 아직 개발 중이지만 꼭 사용해 보시기 바랍니다!

  이 기능은 현재 [사전 출시 정책](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy/) 에 따라 미리보기의 일부로 제공됩니다.
</Callout>

뉴렐릭 Distribution of OpenTelemetry(NRDOT) 수집기를 사용하여 데이터베이스 모니터링, 쿼리 분석 및 시스템 상태 메트릭을 통해 오라클 플러거블 데이터베이스(PDB) 성능에 대한 포괄적인 인사이트를 얻으십시오.

<Callout variant="tip" title="가이드 설치">
  대신 뉴렐릭 UI를 통해 설치하려면 <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; Oracle (OpenTelemetry)** </DNT>(으)로 이동하십시오. 이 페이지에서는 CLI 설치 경로만 다룹니다.
</Callout>

<Callout variant="tip">
  개별 플러거블 데이터베이스가 아닌 전체 컨테이너 데이터베이스를 모니터해야 하는 경우, [CDB 계측](/docs/opentelemetry/database/oracle/host-cdb)을 참조하십시오.
</Callout>

## 전제 조건 [#prerequisites]

시작하기 전에 다음 사항이 있는지 확인하세요.

* 유효한 뉴렐릭 [클러스터](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)
* 지원 아키텍처: AMD64 및 ARM64 기반의 Linux
* [뉴렐릭 OTLP 엔드포인트](/docs/opentelemetry/best-practices/opentelemetry-otlp)에 대한 네트워크 연결
* 오라클 데이터베이스 `19c` 이상

### 미리보기에 등록하십시오 [#enroll]

이 통합은 뉴렐릭 공개 프리뷰 프로그램의 일환으로 제공됩니다. [Previews &amp; Trials](https://one.newrelic.com/admin-portal/promotion-management/home) 페이지에서 옵트인하려면 조직 관리자에게 문의하십시오.

  <Step>
    ## NRDOT Collector설치하세요 [#installation]

    사용 중인 Linux 환경에 맞는 설치 배포 방법을 선택하십시오.

    <CollapserGroup>
      <Collapser title="AMD64 아키텍처용" id="amd">
        * Debian/Ubuntu 시스템의 경우 다음 명령을 실행하십시오.

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_amd64.deb" --output nrdot-collector.deb && sudo dpkg -i nrdot-collector.deb
          ```

        * RHEL/CentOS/OEL 시스템의 경우 다음 명령을 실행하십시오.

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_x86_64.rpm" --output nrdot-collector.rpm && sudo rpm -ivh nrdot-collector.rpm
          ```

      </Collapser>

      <Collapser title="ARM64 아키텍처용" id="arm">

  <Step>
    ## 데이터베이스 사용자 구성 [#database-user]

    PDB 오라클 데이터베이스 인스턴스에 필요한 권한을 가진 모니터링 사용자를 생성하십시오.

    1. 사용자를 생성하거나 권한을 부여하기 전에 SYS로 다음 문을 실행하십시오:
       ```sql
       ALTER SESSION SET CONTAINER = "<YOUR_PDB>";
       ```
    2. 로컬 모니터링 사용자를 생성하려면 타겟 PDB 내에서 SYS로 다음 명령문을 실행하십시오:
       ```sql
       CREATE USER <USER_NAME> IDENTIFIED BY "<YOUR_PASSWORD>";
       GRANT CREATE SESSION TO <USER_NAME>;
       ```
  </Step>

  <Step>
    ## 멀티테넌트 데이터베이스에 대한 모니터링 권한을 부여합니다. [#grant-privileges]

    PDB 내에서 SYS 사용자로 이 명령을 실행하십시오. 이를 통해 모니터링 도구가 메트릭을 수집하고, 이벤트를 추적하며, 데이터베이스 인스턴스를 찾는 데 필요한 기본 액세스 권한을 얻습니다.

    ```sql
    GRANT SELECT ON V_$INSTANCE   TO <USER_NAME>;
    GRANT SELECT ON V_$DATABASE   TO <USER_NAME>;
    GRANT SELECT ON V_$CONTAINERS TO <USER_NAME>;
    GRANT SELECT ON V_$DATAFILE   TO <USER_NAME>;
    GRANT SELECT ON V_$SYSSTAT                    TO <USER_NAME>;
    GRANT SELECT ON V_$SYSMETRIC                  TO <USER_NAME>;
    GRANT SELECT ON V_$SESSION                    TO <USER_NAME>;
    GRANT SELECT ON V_$RESOURCE_LIMIT             TO <USER_NAME>;
    GRANT SELECT ON V_$OSSTAT                     TO <USER_NAME>;
    GRANT SELECT ON V_$SGAINFO                    TO <USER_NAME>;
    GRANT SELECT ON V_$ROWCACHE                   TO <USER_NAME>;
    GRANT SELECT ON V_$PARAMETER                  TO <USER_NAME>;
    GRANT SELECT ON DBA_TABLESPACE_USAGE_METRICS  TO <USER_NAME>;
    GRANT SELECT ON DBA_TABLESPACES               TO <USER_NAME>;
    GRANT SELECT ON DBA_DATA_FILES                TO <USER_NAME>;
    GRANT SELECT ON DBA_FREE_SPACE                TO <USER_NAME>;
    GRANT SELECT ON DBA_RECYCLEBIN                TO <USER_NAME>;
    GRANT SELECT ON V_$SQL            TO <USER_NAME>;
    GRANT SELECT ON V_$SQL_PLAN_STATISTICS_ALL       TO <USER_NAME>;
    GRANT SELECT ON V_$LOCK           TO <USER_NAME>;
    GRANT SELECT ON V_$SESSION_EVENT  TO <USER_NAME>;
    GRANT SELECT ON DBA_PROCEDURES    TO <USER_NAME>;
    GRANT SELECT ON DBA_OBJECTS       TO <USER_NAME>;
    GRANT SELECT ON V_$PDBS      TO <USER_NAME>;
    GRANT SELECT ON CDB_SERVICES TO <USER_NAME>;
    ```
  </Step>

  <Step>
    ## NRDOT Collector 설정 업데이트 [#update]

    `oracle-config.yaml` 파일을 사용하도록 NRDOT Collector 설정을 업데이트하십시오:

    ```bash
    sudo sed -i 's|OTELCOL_OPTIONS="--config=/etc/nrdot-collector/config.yaml"|OTELCOL_OPTIONS="--config=/etc/nrdot-collector/oracle-config.yaml"|' /etc/nrdot-collector/nrdot-collector.conf
    ```

    <Callout variant="tip">
      당신은 또한 수:

      * [여러 수집기 구성](/docs/opentelemetry/database/oracle/multi-receiver): 하나의 수집기에서 여러 오라클 데이터베이스 인스턴스를 모니터합니다.
      * [SQL 쿼리 수신기 구성](/docs/opentelemetry/database/capabilities/sql-query-receiver/): 오라클 데이터베이스에서 커스텀 지표를 수집합니다.
      * [오라클 데이터베이스를 APM과 연결하십시오](/docs/opentelemetry/database/capabilities/db-apm): 애플리케이션 성능을 데이터베이스 작업과 연관시킬 수 있습니다. 이를 통해 정확히 어떤 애플리케이션이 특정 데이터베이스 워크로드를 생성하고 있는지 확인할 수 있습니다.
      * [시크릿 관리 설정](/docs/opentelemetry/database/capabilities/db-apm/#secret-management): 데이터베이스 자격 증명과 같은 민감한 정보를 안전하게 관리하기 위함입니다. 이는 설정 파일에 민감한 데이터를 하드코딩하는 것을 방지하여 모니터링 설정의 보안을 강화하는 데 도움이 됩니다.
    </Callout>
  </Step>

  <Step>
    ## NRDOT Collector를 다시 시작하십시오 [#restart-collector]

    설정을 업데이트한 후 NRDOT Collector를 다시 시작하십시오:

    ```bash
    sudo systemctl restart nrdot-collector.service
    sudo systemctl status nrdot-collector.service
    ```

    <Callout variant="tip">
      새 설정이 적용되도록 설정을 변경한 후에는 항상 NRDOT Collector를 다시 시작하십시오.
    </Callout>
  </Step>

  <Step>
    ## 데이터 찾기 및 사용 [#find-use-data]

    데이터가 수집되면 뉴렐릭의 UI를 통해 포괄적인 오라클 데이터베이스 모니터링에 액세스할 수 있습니다.

    뉴렐릭에서 오라클 데이터베이스 엔티티를 찾으려면 다음을 수행하세요:

    1. <DNT>**[https://one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT> 으)로 이동합니다.
    2. 검색 기준을 <DNT>`instrumentation.provider = opentelemetry`</DNT> 으로 설정합니다.
    3. 엔티티 목록에서 오라클 데이터베이스를 선택합니다.
  </Step>
