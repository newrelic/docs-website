NRDOT Collector로 PostgreSQL을 모니터링할 때 발생할 수 있는 일반적인 문제를 해결하십시오.

## 연결 테스트

### PostgreSQL에 대한 네트워크 연결을 테스트하십시오.

```bash
psql --host=<YOUR_DB_HOST> --port=<YOUR_DB_PORT> --username=<YOUR_DB_USERNAME> --dbname=<YOUR_DATABASE_NAME> --command 'SELECT 1;'
```

성공적인 연결 및 결과는 수집기 자체의 문제를 진단, 해결하기 전에 모니터링 사용자, 호스트 및 포트에 연결할 수 있음을 확인합니다.

### OTLP 엔드포인트 연결 테스트

NRDOT Collector가 뉴렐릭의 OTLP 엔드포인트에 도달할 수 있는지 확인하십시오:

```bash
curl -v <YOUR_NEWRELIC_OTLP_ENDPOINT>
```

## 일반적인 증상

| 징후                                                                                     | 가능한 원인                                                                                                                                   |
| -------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `db.server.query_sample` / `db.server.top_query` 이벤트 없음                                | 수신자 설정에서 `events` 블록이 활성화되지 않음(둘 다 기본적으로 비활성화되어 있음)                                                                                      |
| `db.server.top_query` 이벤트가 완전히 누락됨                                                     | `pg_stat_statements` 해당 데이터베이스에 확장 프로그램이 생성되지 않았습니다.                                                                                     |
| `db.server.query_sample` 차단 세션 세부 정보 누락                                                | 모니터링 사용자에게 권한이 부족합니다. `pg_monitor`                                                                                                       |
| 다음에서 긴 쿼리가 잘림 `db.server.query_sample`                                                 | 기본값 `track_activity_query_size` (1024바이트) — 값을 높이려면 [호환성 및 전제 조건](/docs/opentelemetry/database/postgresql/compatibility#params)을 참조하십시오. |
| `postgresql.function.calls` 항상 비어 있거나 대시보드 &quot;Function Calls/min&quot; 위젯이 비어 있습니다. | `track_functions` -에서 `pl` 또는 `all` (으)로 설정되지 않았습니다. `postgresql.conf`                                                                   |
| 메트릭이 수집되고 있음에도 불구하고 여러 대시보드 위젯이 비어 있습니다.                                               | 해당 메트릭은 기본적으로 비활성화되어 있습니다 ― [메트릭 참조](/docs/opentelemetry/database/postgresql/metrics-reference#dashboard)를 확인하십시오.                       |
| `db.query.comment_tags.nr_service_guid` 항상 비어 있음                                       | `allowed_comment_keys: [nr_service_guid]` `query_sample_collection` / `top_query_collection`에 설정되지 않음 ― 기본적으로 비어 있음                      |
| 일부 테이블에서 테이블/인덱스/함수 메트릭이 누락되었습니다.                                                      | 모니터링 사용자에게 해당 테이블/스키마에 대한 `SELECT` 권한이 없습니다 — `pg_monitor`은(는) 객체 수준이 아닌 통계 가시성을 부여합니다. `SELECT`                                         |
| `postgresql.wal.lag` / `.wal.age` 누락됨                                                  | 하나 이상의 연결된 복제본이 있는 상태에서 WAL을 활성화해야 함 ― 독립 실행형/소스 전용 인스턴스에서는 0으로 설정되지 않고 조용히 생략됨                                                          |
| PostgreSQL 엔티티가 나타나지 않거나 엔티티 탐색기에서 앱→PostgreSQL 관계가 확인되지 않습니다.                         | `server.address`리소스에 /`server.port`이(가) 없으며, 수신자만으로는 기본(구형) 리소스 모델에서 이를 내보내지 않습니다.                                                       |
