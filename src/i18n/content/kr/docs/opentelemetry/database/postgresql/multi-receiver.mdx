<Callout title="시사">
  이 기능은 아직 개발 중이지만 꼭 사용해 보시기 바랍니다!

  이 기능은 현재 [사전 출시 정책](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy/) 에 따라 미리보기의 일부로 제공됩니다.
</Callout>

하나의 수집기에서 여러 PostgreSQL 인스턴스를 모니터하도록 NRDOT Collector를 설정할 수 있습니다. 이는 서로 다른 호스트나 포트에서 실행되는 여러 PostgreSQL 데이터베이스가 있고 단일 NRDOT Collector 인스턴스를 사용하여 모든 데이터베이스에서 메트릭을 수집하려는 경우에 유용합니다.

<Steps>
  <Step>
    ## 전제 조건 [#prerequisites]

    * NRDOT가 PostgreSQL 인스턴스에 설치 및 구성됩니다:
      * [자체 호스팅 PostgreSQL](/docs/opentelemetry/database/postgresql/hosted)
  </Step>

  <Step>
    ## 다중 수신기 설정 추가 [#multi]

    다음 예는 다중 수신자 설정을 사용하여 두 개의 PostgreSQL 인스턴스를 모니터하도록 NRDOT Collector를 설정하는 방법을 보여줍니다. 추가 PostgreSQL 인스턴스에 대해 필요에 따라 수신자를 더 추가할 수 있습니다.

    ```yaml
    receivers:
      nrpostgresql/db1: &nrpostgresql-common
        endpoint: "<YOUR_DB1_HOST>:<YOUR_DB1_PORT>"
        username: "<YOUR_DB_USERNAME>"
        password: "<YOUR_DB_PASSWORD>"
        databases:
          - <YOUR_DB1_DATABASE_NAME>
        collection_interval: 10s
      nrpostgresql/db2:
        <<: *nrpostgresql-common
        endpoint: "<YOUR_DB2_HOST>:<YOUR_DB2_PORT>"
        databases:
          - <YOUR_DB2_DATABASE_NAME>

    service:
      pipelines:
        metrics:
          receivers: [nrpostgresql/db1, nrpostgresql/db2]
          exporters: [otlp/newrelic]
    ```
  </Step>

  <Step>
    ## NRDOT Collector를 다시 시작하십시오 [#restart]

    다시 시작하는 것은 선택 사항이 아니라 필수입니다 — 수집기는 시작 시 설정을 한 번 로드하며 핫 리로드하지 않습니다. 프로세스를 다시 시작할 때까지 모든 설정 변경 사항은 적용되지 않습니다.

    ```bash
    sudo systemctl restart nrdot-collector
    ```
  </Step>
</Steps>
