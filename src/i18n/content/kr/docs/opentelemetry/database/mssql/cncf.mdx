Microsoft SQL Server용 OpenTelemetry Collector Contribution을 사용하여 인스턴스를 모니터할 수 있습니다. OpenTelemetry Collector Contribution은 Microsoft SQL Server에서 텔레메트리 데이터를 수집하여 뉴렐릭으로 전송하는 방법을 제공하는 커뮤니티 지원 프로젝트입니다.

기본적으로 OpenTelemetry Collector Contribution은 Microsoft SQL Server에서 메트릭을 수집하여 뉴렐릭으로 전송합니다. 하지만 이는 제한된 메트릭입니다. 쿼리 성능 메트릭, 대기 시간 메트릭, 세션 메트릭 및 기타 고급 메트릭을 전송하려면 OpenTelemetry Collector Contribution을 구성해야 합니다. 이 가이드는 Microsoft SQL Server에서 고급 메트릭을 수집하여 뉴렐릭으로 전송하도록 OpenTelemetry Collector Contribution을 구성하는 방법에 대한 지침을 제공합니다.

<Steps>
  <Step>
    ## 전제 조건 [#prerequisites]

    * 시스템에 OpenTelemetry Collector Contrib(`otelcol-contrib`)이(가) 설치 및 설정되었습니다. [OpenTelemetry Collector 릴리스](https://github.com/open-telemetry/opentelemetry-collector-releases/releases) 페이지에서 최신 릴리스를 다운로드할 수 있습니다.
  </Step>

  <Step>
    ## UI 메트릭 활성화 [#enable]

    `otelcol-contrib` 설정 파일에 다양한 메트릭을 추가하고 활성화하여 뉴렐릭 플랫폼 환경을 개선할 수 있습니다. 이 섹션에 제공된 설정을 사용하면 뉴렐릭 플랫폼의 다음 페이지에 데이터를 채울 수 있습니다:

    * <DNT>Overview</DNT>
    * <DNT>Query performance</DNT>
    * <DNT>Wait events</DNT>
    * <DNT>Sessions</DNT>
    * <DNT>Clients</DNT>

    <CollapserGroup>
      <Collapser id="overview" title="개요 페이지 메트릭 활성화">
        <DNT>Overview</DNT> 페이지는 데이터베이스 수, I/O, 지연시간, 작업, tempdb 공간, 교착 상태 비율 등과 같은 주요 메트릭을 포함하여 Microsoft SQL Server 인스턴스의 상위 수준 보기를 표시합니다.

        뉴렐릭 플랫폼의 <DNT>Overview</DNT> 페이지에 데이터를 채우려면 `otelcol-contrib` 설정 파일에 다음 설정을 추가하십시오:

        ```yaml
        receivers:
            sqlserver:

                # Enable comprehensive database metrics
              metrics:
                sqlserver.database.count:
                  enabled: true
                sqlserver.database.io:
                  enabled: true
                sqlserver.database.latency:
                  enabled: true
                sqlserver.database.operations:
                  enabled: true
                sqlserver.database.tempdb.space:
                  enabled: true
                sqlserver.database.tempdb.version_store.size:
                  enabled: true
                sqlserver.deadlock.rate:
                  enabled: true
                sqlserver.os.wait.duration:
                  enabled: true
                sqlserver.processes.blocked:
                  enabled: true
                sqlserver.memory.grants.pending.count:
                  enabled: true
                sqlserver.memory.area:
                  enabled: true
        ```
      </Collapser>

      <Collapser id="query-performance" title="쿼리 성능, 세션, 대기 및 클라이언트 메트릭 활성화">
        뉴렐릭 플랫폼의 다음 페이지에 데이터를 채울 수 있습니다:

        * <DNT>Query performance</DNT>: 다음 탭에서 Microsoft SQL Server 인스턴스에서 실행 중인 쿼리에 대한 자세한 정보를 표시합니다:

          * <DNT>Normalized queries</DNT>: 실행 및 평균 CPU 시간 그래프를 표시합니다.
          * <DNT>Query samples</DNT>: 시작 시간, 기간, 대기 유형, 대기 시간, 데이터베이스, DB 사용자 및 클라이언트 호스트를 포함한 개별 쿼리 실행을 표시합니다.

        * <DNT>Wait events</DNT>: Microsoft SQL Server 인스턴스에서 발생하는 대기 이벤트에 대한 정보를 표시합니다. 쿼리 샘플 보기에는 현재 대기 중인 쿼리가 대기 유형 및 대기 시간과 함께 표시됩니다.

        * <DNT>Sessions</DNT>: 세션 수, 세션 상태, 평균 활성 세션 기간, 차단된 세션 및 개별 세션 세부 정보를 포함하여 Microsoft SQL Server 인스턴스에 연결된 세션에 대한 정보를 표시합니다.

        * <DNT>Clients</DNT>: 활성 세션, 차단된 세션, 연결된 DB 사용자 및 클라이언트 호스트 세부 정보를 포함하여 Microsoft SQL Server 인스턴스에 연결된 클라이언트에 대한 정보를 표시합니다.

        이러한 페이지에 데이터를 채우려면 `otelcol-contrib` 설정 파일에 다음 설정을 추가하십시오:

        ```yaml
        receivers:
            sqlserver:

                events:
                    db.server.query_sample:
                        enabled: true
                    db.server.top_query:
                        enabled: true

                top_query_collection:
                    lookback_time: 45s
                    max_query_sample_count: 100
                    top_query_count: 30
                    collection_interval: 30s

                query_sample_collection:
                    max_rows_per_query: 100
        ```
      </Collapser>

      <Collapser id="waits" title="대기 이벤트 탭에서 모든 대기 활성화">
        모든 대기 보기에는 대기 범주 및 개별 대기 유형별로 분류된 인스턴스 수준 대기 시간이 표시됩니다.

        뉴렐릭 플랫폼 <DNT>Wait event</DNT> 탭에서 <DNT>All waits</DNT>을(를) 활성화하려면 `otelcol-contrib` 설정 파일에 다음 설정을 추가하십시오:

        ```yaml

        receivers:
            sqlserver:

                metrics:
                    sqlserver.os.wait.duration:
                        enabled: true

        ```
      </Collapser>
    </CollapserGroup>
  </Step>

  <Step>
    ### OpenTelemetry Collector 다시 시작

    설정 변경 사항을 적용하려면 OpenTelemetry Collector를 다시 시작하십시오. 다음 명령을 실행하여 이 작업을 수행할 수 있습니다:

    ```bash
    Restart-Service -Name "otelcol-contrib"
    ```
  </Step>
</Steps>
