이 참조는 OpenTelemetry의 뉴렐릭 배포판(NRDOT) Collector를 사용한 Microsoft SQL Server 모니터링을 위한 포괄적인 YAML 설정을 제공합니다. 이 모든 기능을 갖춘 설정에는 Linux 및 Windows 전반의 자체 호스팅 및 AWS RDS 배포 모두에서 운영 환경을 위한 모든 사용 가능한 메트릭, 고급 프로세서 설정 및 최적화된 파이프라인이 포함되어 있습니다.

<Callout variant="important">
  **빠르게 시작하고 싶으십니까?** 프로덕션 사용을 위한 고급 설정입니다. SQL Server 모니터링을 처음 설정하는 경우, 설정 가이드의 표준 설정으로 시작하여 기본 기능을 확인한 후 이 포괄적인 설정으로 돌아오는 것을 권장합니다.
</Callout>

## 수신기 설정 [#receiver]

`max_concurrent_queries`을(를) 사용하여 각 스크랩 주기 동안 수신기가 SQL Server에 대해 병렬로 실행하는 메트릭 쿼리 수를 제어할 수 있습니다. 생략하거나 0으로 설정하면 기본값은 4입니다.

```yaml
    receivers:
    nrsqlserver:
        max_concurrent_queries: 4  # default is 4 if omitted or set to 0
```
