  이 기능은 현재 [사전 출시 정책](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy/) 에 따라 미리보기의 일부로 제공됩니다.

당사의 OpenTelemetry 기반 모니터링 솔루션을 통해 SQL Server 성능에 대한 깊은 인사이트를 얻으십시오. 데이터베이스 메트릭을 추적하고, 느린 쿼리를 분석하고, 리소스 사용량을 모니터링하며, 데이터베이스 성능을 애플리케이션과 연관시킵니다.

이 NRDOT 기반 접근 방식은 모니터링을 위한 OpenTelemetry 데이터베이스 표준을 활용하여 기존 온호스트 통합(OHI)을 보완하고 기존 옵저버빌리티 그리드와 통합을 더 쉽게 만듭니다.

주요 기능:

* **OpenTelemetry 표준**: 기존 옵저버빌리티 도구와 원활하게 통합됩니다.
* **포괄적인 메트릭**: 50개 이상의 데이터베이스 성능 지표
* **쿼리 수준 인사이트**: 성능이 느린 쿼리를 식별하고 최적화합니다.
* **유연한 배포**: 자체 호스팅 및 cloud 환경에서 작동합니다.
* **APM 상관관계**: 데이터베이스 성능을 애플리케이션 트레이스에 연결합니다.

## 설치 방법을 선택하세요 [#install]

다음과 같은 방법으로 SQL Server 모니터링용 NRDOT Collector를 설치할 수 있습니다:

* 자체 호스팅 환경: 자체 인프라에 수동 설치

  * [Windows 자체 호스팅](/docs/opentelemetry/database/mssql/windows-hosted)
  * [Linux 자체 호스팅](/docs/opentelemetry/database/mssql/linux-hosted)

* AWS RDS 환경: 클라우드 관리형 SQL Server 모니터링:

  * [Windows RDS 모니터링](/docs/opentelemetry/database/mssql/windows-rds)
  * [Linux RDS 모니터링](/docs/opentelemetry/database/mssql/linux-rds)

## 안내 설치 [#ui-install]

대신 뉴렐릭 UI를 통해 이를 설치하려면 <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; MSSQL (OpenTelemetry)** </DNT>로 이동하십시오. 화면의 지시에 따라 통합을 설정하십시오.

## 한눈에 보는 설치 [#at-a-glance]

<Steps>
  <Step>
    ### 전제 조건 [#prerequisites]

    * 유효한 [라이선스 키](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)가 있는 뉴렐릭 계정

    * NRDOT Collector를 설치하는 호스트와 Microsoft SQL Server 간의 네트워크 연결.

    * [뉴렐릭 OTLP 엔드포인트 문서](/docs/opentelemetry/best-practices/opentelemetry-otlp/)에 대한 네트워크 연결

    * SQL Server 요구 사항, 다음이 필요합니다:

      * SQL Server 2017 이상
      * SQL Server에 대한 관리자 액세스 권한(`sysadmin` 역할 또는 동등한 권한)
      * 포트 `1433` 또는 사용자 지정 포트에서의 수집기와 SQL Server 간 네트워크 연결

    * 이 통합은 뉴렐릭 퍼블릭 프리뷰 프로그램의 일환으로 제공됩니다. [미리 보기 및 평가판](https://one.newrelic.com/admin-portal/promotion-management/home) 페이지에서 옵트인하려면 조직 관리자에게 문의하세요.

    지원되는 자세한 전제 조건은 설치 문서의 전용 전제 조건 섹션을 참조하십시오.
  </Step>

  <Step>
    ### NRDOT Collector설치하세요 [#install]

    인프라에 따라 설치 경로를 선택하세요:

    * **안내 설치**: 뉴렐릭 UI를 통해 설치하려면 <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; MSSQL (OpenTelemetry)** </DNT>(으)로 이동하십시오. 화면의 지시에 따라 통합을 설정하십시오. 이 페이지는 CLI 설치 경로만 다룹니다.

    * **자체 호스팅 환경**: 자체 인프라에 수동 설치

      * [Windows 자체 호스팅](/docs/opentelemetry/database/mssql/windows-hosted)
      * [Linux 자체 호스팅](/docs/opentelemetry/database/mssql/linux-hosted)

    * **AWS RDS 환경**: 클라우드 관리형 SQL Server 모니터링

      * [Windows RDS 모니터링](/docs/opentelemetry/database/mssql/windows-rds)
      * [Linux RDS 모니터링](/docs/opentelemetry/database/mssql/linux-rds)
  </Step>

  <Step>
    ### 모니터링 사용자 구성 [#user]

    NRDOT Collector가 메트릭을 수집하고 성능 데이터를 쿼리할 수 있도록 필요한 권한을 가진 전용 Microsoft SQL Server 사용자를 생성하십시오. 사용자는 필요한 항목에 대한 읽기 전용 액세스 권한이 있어야 합니다.
  </Step>

  <Step>
    ### NRDOT Collector구성 [#configure]

    Microsoft SQL Server 인스턴스에 연결하도록 NRDOT Collector를 설정하십시오. 여기에는 환경에 필요한 연결 세부 정보, 인증 방법 및 추가 설정 옵션을 지정하는 것이 포함됩니다.
  </Step>

  <Step>
    ### NRDOT Collector를 다시 시작하십시오 [#restart]

    NRDOT Collector를 설정한 후 서비스를 다시 시작하여 변경 사항을 적용하고 Microsoft SQL Server 인스턴스에서 데이터 수집을 시작하십시오.
  </Step>

  <Step>
    ### 데이터 찾기 및 사용 [#find]

    데이터가 수집되면 뉴렐릭 UI를 통해 포괄적인 SQL Server 데이터베이스 모니터링에 액세스할 수 있습니다.

    뉴렐릭에서 SQL Server 데이터베이스를 찾으려면 다음을 수행하세요.

    1. <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; All capabilities &gt; Databases**</DNT> 으)로 이동합니다.
    2. **<DNT>Entity type</DNT>** 드롭다운 메뉴에서 <DNT>**MSSQL instance**</DNT>을(를) 선택한 다음 <DNT>**Apply**</DNT>을(를) 클릭합니다.
    3. 엔티티 목록에서 SQL Server 데이터베이스를 선택하여 대시보드, 메트릭 및 쿼리 성능 데이터를 확인하십시오.
  </Step>
</Steps>
