`newrelic-install` Chef 쿡북을 사용하여 오라클 데이터베이스 모니터링을 위한 NRDOT Collector를 설치하고 구성할 수 있습니다. `newrelic-install::default` 레시피를 실행하면 쿡북이 수집기를 설치하고, 모니터링 데이터베이스 사용자를 생성하며, 수집기를 구성합니다.

<Callout variant="tip" title="가이드 설치">
  대신 뉴렐릭 UI를 통해 설치하려면 <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; Oracle (Database 360)](https://onenr.io/0kjnebKW7Ro)**</DNT>(으)로 이동하십시오. 이 페이지는 수동 설치만 다룹니다.
</Callout>

<Steps>
  <Step>
    ## 전제 조건 [#prerequisites]

    * 유효한 [라이선스 키](/docs/apis/intro-apis/new-relic-api-keys/#overview-keys)가 있는 뉴렐릭 계정.
    * 뉴렐릭 [계정 ID](/docs/accounts/accounts-billing/account-structure/account-id).
    * 오라클 데이터베이스 19c 이상입니다.
    * Chef 15 이상이 필요합니다.
    * 자체 호스팅 오라클의 경우: SSH 사용자가 비밀번호 프롬프트 없이 `sudo su - oracle`을(를) 실행할 수 있는 오라클 데이터베이스 호스트에 대한 SSH 액세스(에이전트 포워딩 포함)가 있는 오라클 Linux 7, 8 또는 9여야 합니다.
    * AWS RDS의 오라클의 경우: Debian/Ubuntu 또는 CentOS/RHEL/OEL을 실행하는 수집기 호스트.
    * 오라클 자율운영 데이터베이스(ADB)의 경우: Debian/Ubuntu 또는 CentOS/RHEL/OEL을 실행하고 오라클 인스턴트 클라이언트(`sqlplus`)가 설치되어 있으며 `PATH`에 있는 수집기 호스트, ADB 액세스 제어 목록에 허용된 각 인스턴스의 이그레스 IP, 노드의 자체 디렉터리에 다운로드되고 압축이 해제된 각 인스턴스의 오라클 월렛.
  </Step>

  <Step>
    ## Chef 쿡북을 다운로드합니다. [#download-cookbook]

    Chef Supermarket에서 `newrelic-install` [Chef 쿡북](https://supermarket.chef.io/cookbooks/newrelic-install)을 chef-repo 디렉터리로 다운로드하십시오:

    ```bash
    knife supermarket install newrelic-install
    ```
  </Step>

  <Step>
    ## 기본 속성을 교체하십시오. [#configure]

    `attributes/default.rb`의 기본 속성을 계정 세부 정보로 변경하십시오:

    <CollapserGroup>
      <Collapser id="chef-host" title="자체 호스팅 오라클 데이터베이스">
        이 쿡북은 단일 수집기에서 하나 이상의 오라클 데이터베이스 인스턴스(각각 SSH를 통해 연결 가능)를 모니터링합니다. 단일 호스트/컨테이너/자격 증명 세트 대신, 모니터링할 모든 인스턴스를 나열하며 노드에 이미 존재해야 하는 인스턴스 파일(YAML)과, 선택적으로 모니터링 사용자 비밀번호를 자동 생성하는 대신 고정하기 위한 비밀 파일을 읽습니다. 정확한 파일 형식은 [CLI 설치](/docs/opentelemetry/db360/oracle/cli/#install)를 참조하십시오.

        ```ruby
        default['newrelic_install']['NEW_RELIC_API_KEY']    = <API key>
        default['newrelic_install']['NEW_RELIC_ACCOUNT_ID'] = <Account ID>
        default['newrelic_install']['NEW_RELIC_REGION']     = <Region>
        default['newrelic_install']['targets'] = [
          'nrdot-collector-oracle'
        ]
        default['newrelic_install']['env']['NR_CLI_ORACLE_INSTANCES_FILE'] = <path to the instances YAML file on the node>
        default['newrelic_install']['env']['NR_CLI_ORACLE_SECRETS_FILE']   = <optional path to a secrets file pinning monitoring passwords, on the node>
        default['newrelic_install']['env']['NR_CLI_ORACLE_CONFIG_PRESET']  = <1 Basic, 2 Advanced, default 1>
        # See all available targets at: https://github.com/newrelic/chef-install
        ```
