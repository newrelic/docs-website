NRDOT Collector가 수집한 포괄적인 메트릭으로 오라클 데이터베이스 성능을 모니터하십시오. 기본적으로 뉴렐릭은 [Default metrics and events](#default) 섹션에 참조된 메트릭 및 쿼리 수준 이벤트를 수집합니다. [Full-feature metrics](#full-feature) 섹션에 나열된 원하는 메트릭을 활성화하여 모니터링을 향상할 수 있습니다.

### 쿼리 이벤트 [#query-events]

다음 이벤트는 OpenTelemetry 로그 레코드로 수집되며 기본적으로 활성화되어 있습니다. 쿼리 수준의 가시성을 제공합니다.

<CollapserGroup>
<Collapser id="db-server-query-sample" title="쿼리 샘플">
세션당 활성 쿼리 샘플입니다. 수집 시점에 활성 오라클 세션의 현재 실행 상태를 캡처합니다. 이 이벤트는 기본적으로 활성화되어 있습니다.

이러한 속성은 `DbServerQuerySample` 이벤트를 쿼리하여 찾을 수 있습니다.

동작을 조정하려면 `query_sample_collection` 블록을 사용하십시오:

```yaml
query_sample_collection:
  max_rows_per_query: 100
  allowed_comment_keys:
    - nr_service_guid
```
