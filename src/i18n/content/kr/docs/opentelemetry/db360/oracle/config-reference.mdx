이 참조는 뉴렐릭 OpenTelemetry 배포판(NRDOT) Collector를 사용한 오라클 데이터베이스 모니터링을 위한 포괄적인 YAML 설정을 제공합니다. 이 모든 기능을 갖춘 설정에는 온호스트, RDS 및 ADB 배포 전반의 운영 환경을 위한 완전한 오라클 데이터베이스 메트릭 카탈로그가 포함되어 있습니다.

<Callout variant="important">
  **빠르게 시작하고 싶으십니까?** 프로덕션 사용을 위한 고급 설정입니다. 오라클 데이터베이스 모니터링을 처음 설정하는 경우, 설정 가이드의 표준 설정으로 시작하여 기본 기능을 확인한 후 이러한 포괄적인 설정으로 돌아올 것을 권장합니다.
</Callout>
