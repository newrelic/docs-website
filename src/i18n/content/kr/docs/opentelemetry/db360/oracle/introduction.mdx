OpenTelemetry 기반 모니터링 솔루션으로 오라클 데이터베이스 성능에 대한 깊은 인사이트를 얻으십시오. 데이터베이스 메트릭을 추적하고, 쿼리 성능을 분석하며, 리소스 사용량을 모니터하고, 데이터베이스 성능을 애플리케이션과 연관시키십시오.

이 NRDOT 기반 접근 방식은 모니터링을 위한 OpenTelemetry 데이터베이스 표준을 활용하여 기존 온호스트 통합(OHI)을 보완하고 기존 옵저버빌리티 그리드와 통합을 더 쉽게 만듭니다.

온-호스트 통합과 달리, NRDOT는 인프라 에이전트와 독립적으로 작동합니다. 데이터베이스 텔레메트리를 수집하는 데 인프라 에이전트가 필요하지 않습니다. NRDOT에는 네이티브 호스트 모니터링 기능도 포함되어 있으므로 다음과 같이 선택할 수 있습니다:

* 데이터베이스 모니터링을 위한 NRDOT와 함께 호스트 모니터링을 위해 인프라 에이전트를 사용하거나,
* NRDOT를 사용하여 데이터베이스와 호스트를 모두 모니터하십시오.

## 기능 [#capabilities]

* **OpenTelemetry 표준**: 기존 옵저버빌리티 도구와 원활하게 통합됩니다.
* **포괄적인 메트릭**: 데이터베이스 성능, 대기 이벤트 및 리소스 사용량에 대한 심층적인 인사이트
* **쿼리 수준 인사이트**: 느리게 실행되는 쿼리 및 세션 활동을 식별하고 분석합니다.
* **유연한 배포**: 온호스트 CDB/PDB 및 Amazon RDS 환경에서 작동합니다.
* **APM 상관관계**: 데이터베이스 성능을 애플리케이션 트레이스에 연결합니다.

## 설치 경로 선택 [#choose]

다음과 같은 방법으로 오라클 데이터베이스 모니터링을 위한 NRDOT Collector를 설치할 수 있습니다:

* 자체 호스팅 환경: 자체 인프라에 수동 설치

  * [온호스트 컨테이너 데이터베이스(CDB)](/docs/opentelemetry/db360/oracle/host-cdb): 하위의 모든 플러거블 데이터베이스를 포함하여 전체 컨테이너 데이터베이스를 모니터합니다.
  * [온호스트 플러거블 데이터베이스(PDB)](/docs/opentelemetry/db360/oracle/host-pdb): 개별 플러거블 데이터베이스를 모니터합니다.

* AWS RDS 환경: 클라우드 관리형 오라클 데이터베이스 모니터링
  * [RDS 모니터링](/docs/opentelemetry/db360/oracle/rds): Amazon RDS에서 실행 중인 오라클 데이터베이스 인스턴스를 모니터링합니다.

* 오라클 클라우드 환경: 완전 관리형 오라클 데이터베이스 모니터링
  * [Autonomous 데이터베이스(ADB) 모니터링](/docs/opentelemetry/db360/oracle/adb): 오라클 Autonomous 데이터베이스 인스턴스를 모니터합니다.

* [뉴렐릭 CLI](/docs/opentelemetry/db360/oracle/cli): 단일 명령으로 수집기를 설치하고 구성하십시오

* [Ansible](/docs/opentelemetry/db360/oracle/ansible): `newrelic.newrelic_install` Ansible 역할을 사용하여 대규모로 수집기를 설치하고 구성하십시오.

* [Chef](/docs/opentelemetry/db360/oracle/chef): `newrelic-install` Chef 쿡북을 사용하여 대규모로 수집기를 설치하고 구성합니다.

* [Helm 차트](/docs/opentelemetry/db360/oracle/helm): `oracle-otel` Helm 차트를 사용하여 Kubernetes에서 오라클 데이터베이스 모니터링을 설치하고 구성하십시오.

* [도커](/docs/opentelemetry/db360/oracle/docker): 도커에서 이미 실행 중인 오라클 데이터베이스 인스턴스의 형제 컨테이너로 수집기를 실행하십시오.
