NRDOT Collector를 사용하여 오라클 데이터베이스를 모니터링할 때 발생할 수 있는 일반적인 문제를 해결하십시오.

## 일반적인 문제 [#common-issues]

<CollapserGroup>
  <Collapser id="test-connection" title="네트워크 연결 테스트">
    다음 명령을 실행하여 이 호스트에서 오라클 데이터베이스 포트에 연결할 수 있는지 확인합니다.

    ```bash
    (timeout 3 bash -c '</dev/tcp/<YOUR_ENDPOINT>/<YOUR_PORT>' && echo "PORT OPEN - Network connection successful!") || echo "CONNECTION FAILED - Port closed or firewall blocking"
    ```

    **예상 출력:** `PORT OPEN - Network connection successful!`
  </Collapser>

  <Collapser id="otlp-endpoint-connection" title="OTLP 엔드포인트 연결 테스트">
    호스트가 선택한 뉴렐릭 OTLP 엔드포인트에 도달할 수 있는지 확인하려면 다음 명령을 실행하십시오.

    ```bash
    ENDPOINT="<YOUR_OTLP_ENDPOINT>"
    HOST=$(echo "$ENDPOINT" | sed 's|https://||' | cut -d: -f1)
    PORT=$(echo "$ENDPOINT" | awk -F: '{print $NF}')
    (timeout 2 bash -c "</dev/tcp/$HOST/$PORT" && echo "SUCCESS") || echo "FAILED"
    ```

    **예상 출력:** `SUCCESS`
  </Collapser>
</CollapserGroup>

## 뉴렐릭에 데이터가 표시되지 않음 [#data-not-flowing]

* 속도 제한 관련 문제를 확인하려면 다음을 실행하십시오:

  ```sql
  SELECT * FROM NrIntegrationError
  ```

* 데이터가 여전히 유입되지 않는 경우, 메트릭 및 로그 이벤트에 설정된 드롭 규칙이 있는지 확인하십시오. [드롭 필터 규칙으로 로그 데이터 삭제](/docs/logs/ui-data/drop-data-drop-filter-rules/) 및 [Pipeline 제어](/docs/new-relic-control/pipeline-control/overview/)를 참조하십시오.

* NRDOT Collector 로그를 확인합니다:

  ```bash
  journalctl -u nrdot-collector -f
  ```
