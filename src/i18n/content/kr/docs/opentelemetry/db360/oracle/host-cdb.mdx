OpenTelemetry 뉴렐릭 배포판(NRDOT) 수집기를 사용하여 데이터베이스 모니터링, 쿼리 분석 및 시스템 상태 메트릭을 통해 오라클 컨테이너 데이터베이스(CDB) 성능에 대한 포괄적인 인사이트를 얻으십시오. 구성된 CDB 하위의 모든 플러거블 데이터베이스(PDB)가 모니터됩니다.

<Callout variant="tip" title="가이드 설치">
  대신 뉴렐릭 UI를 통해 설치하려면 <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; Oracle (Database 360)](https://onenr.io/0kjnebKW7Ro)**</DNT>(으)로 이동하십시오. 이 페이지는 수동 설치만 다룹니다.
</Callout>

## 전제 조건 [#prerequisites]

시작하기 전에 다음 사항이 있는지 확인하세요.

* 유효한 뉴렐릭 [라이선스 키](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)
* 지원 아키텍처: AMD64 및 ARM64 기반의 Linux
* [뉴렐릭 OTLP 엔드포인트](/docs/opentelemetry/best-practices/opentelemetry-otlp)에 대한 네트워크 연결
* 오라클 데이터베이스 `19c` 이상

    ## NRDOT Collector설치하세요 [#installation]

    사용 중인 Linux 환경에 맞는 설치 배포 방법을 선택하십시오.

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_amd64.deb" --output nrdot-collector.deb && sudo dpkg -i nrdot-collector.deb
          ```

  <Step>
    ## 데이터베이스 사용자 구성 [#database-user]

    멀티테넌트 오라클 데이터베이스에 필요한 권한을 가진 모니터링 사용자를 생성하십시오. 이를 위해서는 `C##` 접두사를 가진 공통 사용자를 생성해야 합니다.

    1. 현재 활성 컨테이너 컨텍스트를 `CDB$ROOT`(으)로 설정하려면 `SYS` 사용자로 다음 구문을 실행하십시오:

       ```sql
       ALTER SESSION SET CONTAINER = CDB$ROOT;
       ```

    2. 멀티테넌트 데이터베이스의 경우:

       1. 관리자로 루트 데이터베이스에 로그인하십시오.

       2. 새 사용자를 생성하려면 다음 `CREATE USER` 구문을 실행하십시오:

          ```sql
          CREATE USER c##<YOUR_DB_USERNAME> IDENTIFIED BY "<YOUR_DB_PASSWORD>" CONTAINER=ALL;
          GRANT CREATE SESSION TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
          ```

          <Callout variant="tip">
            새로 생성된 사용자는 `C##` 접두사가 있는 공통 사용자가 됩니다. 오라클에서는 공통 사용자에게 `C##` 접두사가 필요합니다.
          </Callout>

    3. 모니터링 사용자가 컨테이너 데이터 뷰에서 모든 PDB의 행을 볼 수 있도록 하려면 CDB 루트에서 `SYSDBA` (으)로 다음 구문을 실행하십시오. 이는 PDB별 메트릭 및 이벤트에 필요합니다.

       ```sql
       ALTER USER c##<YOUR_DB_USERNAME> SET CONTAINER_DATA=ALL CONTAINER=CURRENT;
       ```

       <Callout variant="tip">
         `USER_PASSWORD`이(가) 오라클 [새 사용자 비밀번호](https://docs.oracle.com/en/database/oracle/oracle-database/12.2/dbseg/keeping-your-oracle-database-secure.html#GUID-451679EB-8676-47E6-82A6-DF025FD65156) 요구 사항을 충족하는지 확인하십시오.
       </Callout>
  </Step>

  <Step>
    ## 멀티테넌트 데이터베이스에 대한 모니터링 권한을 부여합니다. [#grant-privileges]

    CDB 루트에서 `SYSDBA` (으)로 다음 `GRANT` 문을 실행하십시오. 이 항목들은 인스턴스 감지, 메트릭 수집, PDB별 모니터링 및 이벤트 수집을 포함합니다. 단일 스크립트로 함께 실행하거나 각 문을 개별적으로 실행할 수 있습니다.

    ```sql

    GRANT SELECT ON V_$DATABASE   TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON V_$CONTAINERS TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON V_$DATAFILE   TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON V_$SYSSTAT                    TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON V_$CON_SYSSTAT                TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON V_$SYSMETRIC                  TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON V_$CON_SYSMETRIC              TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON V_$SESSION                    TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON V_$RESOURCE_LIMIT             TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON V_$OSSTAT                     TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON V_$SGAINFO                    TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON V_$ROWCACHE                   TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON V_$PARAMETER                  TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON CDB_TABLESPACE_USAGE_METRICS  TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON CDB_TABLESPACES               TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON DBA_DATA_FILES                TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON DBA_FREE_SPACE                TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON DBA_RECYCLEBIN                TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON V_$SQL            TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON V_$SQL_PLAN_STATISTICS_ALL       TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON V_$LOCK           TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON V_$SESSION_EVENT  TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON DBA_PROCEDURES    TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON DBA_OBJECTS       TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON V_$PDBS           TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON CDB_SERVICES      TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON CDB_DATA_FILES    TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON CDB_PROCEDURES    TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON CDB_OBJECTS       TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON V_$ASM_DISKGROUP_STAT TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    GRANT SELECT ON V_$ASM_DISK_STAT      TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
    ```

    <Callout variant="tip">
      [ASM 디스크 그룹 및 디스크 메트릭](/docs/opentelemetry/db360/oracle/metrics-reference/#asm)을 수집하려는 경우에만 `V_$ASM_DISKGROUP_STAT` 및 `V_$ASM_DISK_STAT` 권한이 필요합니다.
    </Callout>
  </Step>

  <Step>
    ## NRDOT Collector 설정 업데이트 [#update]

    `oracle-config.yaml` 파일을 사용하도록 NRDOT Collector 설정을 업데이트하십시오:

    ```bash
    sudo sed -i 's|OTELCOL_OPTIONS="--config=/etc/nrdot-collector/config.yaml"|OTELCOL_OPTIONS="--config=/etc/nrdot-collector/oracle-config.yaml"|' /etc/nrdot-collector/nrdot-collector.conf
    ```

    <Callout variant="tip">
      당신은 또한 수:

      * [여러 수신자 구성](/docs/opentelemetry/db360/oracle/multi-receiver): 하나의 수집기에서 여러 오라클 데이터베이스 인스턴스를 모니터할 때 사용합니다.
      * [SQL 쿼리 수신기 구성](/docs/opentelemetry/db360/capabilities/sql-query-receiver/): 오라클 데이터베이스에서 커스텀 지표를 수집합니다.
      * [오라클 데이터베이스를 APM과 연결](/docs/opentelemetry/db360/capabilities/db-apm): 애플리케이션 성능을 데이터베이스 작업과 연관시킵니다. 이를 통해 어떤 애플리케이션이 특정 데이터베이스 워크로드를 생성하는지 정확히 확인할 수 있습니다.
      * [시크릿 관리 설정](/docs/opentelemetry/db360/capabilities/db-apm/#secret-management): 데이터베이스 자격 증명과 같은 민감한 정보를 안전하게 관리할 수 있습니다. 이는 설정 파일에 민감한 데이터를 하드코딩하는 것을 방지하여 모니터링 설정의 보안을 강화하는 데 도움이 됩니다.
    </Callout>
  </Step>

  <Step>
    ## NRDOT Collector를 다시 시작하십시오 [#restart-collector]

    설정을 업데이트한 후 NRDOT Collector를 다시 시작하십시오:

    ```bash
    sudo systemctl restart nrdot-collector.service
    sudo systemctl status nrdot-collector.service
    ```

    <Callout variant="tip">
      설정을 변경한 후에는 항상 NRDOT Collector를 다시 시작하여 새 설정이 적용되도록 하십시오.
    </Callout>
  </Step>

  <Step>
    ## 데이터 찾기 및 사용 [#find-use-data]

    데이터가 수집되면 뉴렐릭 UI를 통해 포괄적인 오라클 데이터베이스 모니터링에 액세스할 수 있습니다.

    뉴렐릭에서 오라클 데이터베이스 엔티티를 찾으려면 다음을 수행하세요:

    1. <DNT>**[https://one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT> 으)로 이동합니다.
    2. 검색 기준을 <DNT>`instrumentation.provider = opentelemetry`</DNT> 으로 설정합니다.
    3. 엔티티 목록에서 오라클 데이터베이스를 선택합니다.
  </Step>
