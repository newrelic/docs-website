OpenTelemetry 뉴렐릭 배포판(NRDOT) 수집기를 사용하여 데이터베이스 모니터링, 쿼리 분석 및 시스템 상태 메트릭을 통해 오라클 Autonomous Database(ADB) 성능에 대한 포괄적인 인사이트를 얻으십시오.

<Callout variant="tip" title="가이드 설치">
  대신 뉴렐릭 UI를 통해 설치하려면 <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; Oracle (Database 360)](https://onenr.io/0kjnebKW7Ro)**</DNT>(으)로 이동하십시오. 이 페이지는 수동 설치만 다룹니다.
</Callout>

## 전제 조건 [#prerequisites]

시작하기 전에 다음 사항이 있는지 확인하세요.

* 유효한 뉴렐릭 [라이선스 키](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)
* 지원 아키텍처: AMD64 및 ARM64 기반의 Linux
* [뉴렐릭 OTLP 엔드포인트](/docs/opentelemetry/best-practices/opentelemetry-otlp)에 대한 네트워크 연결
* 오라클 데이터베이스 `19c` 이상

<Steps>
  <Step>
    ## NRDOT Collector설치하세요 [#installation]

    사용 중인 Linux 환경에 맞는 설치 배포 방법을 선택하십시오.

    <CollapserGroup>
      <Collapser title="AMD64 아키텍처용" id="amd">
        * Debian/Ubuntu 시스템의 경우 다음 명령을 실행하십시오.

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_amd64.deb" --output nrdot-collector.deb && sudo dpkg -i nrdot-collector.deb
          ```

        * RHEL/CentOS/OEL 시스템의 경우 다음 명령을 실행하십시오.

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_x86_64.rpm" --output nrdot-collector.rpm && sudo rpm -ivh nrdot-collector.rpm
          ```
      </Collapser>

      <Collapser title="ARM64 아키텍처용" id="arm">
        * Debian/Ubuntu 시스템의 경우 다음 명령을 실행하십시오.

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_arm64.deb" --output nrdot-collector.deb && sudo dpkg -i nrdot-collector.deb
          ```

        * RHEL/CentOS/OEL 시스템의 경우 다음 명령을 실행하십시오.

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_aarch64.rpm" --output nrdot-collector.rpm && sudo rpm -ivh nrdot-collector.rpm
          ```
      </Collapser>
    </CollapserGroup>
  </Step>

  <Step>
    ## 데이터베이스 사용자 구성 [#database-user]

    ADB 오라클 데이터베이스 인스턴스에 필요한 권한을 가진 모니터링 사용자를 생성합니다. 타겟 ADB 내에서 SYS로 다음 문을 실행하여 로컬 모니터링 사용자를 생성합니다:

    ```sql
    CREATE USER <YOUR_DB_USERNAME> IDENTIFIED BY "<YOUR_DB_PASSWORD>";
    GRANT CREATE SESSION TO <YOUR_DB_USERNAME>;
    ```
  </Step>

  <Step>
    ## Autonomous Database에 대한 모니터링 권한 부여 [#grant-privileges]

    ADB 내에서 관리자 권한으로 이 명령을 실행하십시오. 이를 통해 모니터링 도구가 메트릭을 수집하고, 이벤트를 추적하며, 데이터베이스 인스턴스를 찾는 데 필요한 기본 액세스 권한을 얻습니다.

    ```sql
    GRANT SELECT ON SYS.V_$INSTANCE   TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$DATABASE   TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$CONTAINERS TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$DATAFILE   TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$PDBS       TO <YOUR_DB_USERNAME>; 
    GRANT SELECT ON SYS.V_$SYSSTAT                    TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$SYSMETRIC                  TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$SESSION                    TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$RESOURCE_LIMIT             TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$OSSTAT                     TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$SGAINFO                    TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$ROWCACHE                   TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$PARAMETER                  TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.DBA_TABLESPACE_USAGE_METRICS  TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.DBA_TABLESPACES               TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.DBA_DATA_FILES                TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.DBA_FREE_SPACE                TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.DBA_RECYCLEBIN                TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$SQL            TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$SQL_PLAN_STATISTICS_ALL       TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$LOCK           TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$SESSION_EVENT  TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.DBA_PROCEDURES    TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.DBA_OBJECTS       TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$PROCESS        TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.V_$TRANSACTION    TO <YOUR_DB_USERNAME>;
    GRANT SELECT ON SYS.CDB_SERVICES      TO <YOUR_DB_USERNAME>;
    ```
  </Step>

  <Step>
    ## NRDOT Collector를 다시 시작하십시오 [#restart-collector]

    수집기를 구성한 후 NRDOT Collector 서비스를 다시 시작하여 변경 사항을 적용합니다:

    ```bash
    sudo systemctl restart nrdot-collector
    ```

    수집기가 제대로 실행되고 있는지 확인하려면 서비스 상태를 확인하십시오:

    ```bash
    sudo systemctl status nrdot-collector
    ```

    <Callout variant="tip">
      새 설정이 적용되도록 설정을 변경한 후에는 항상 NRDOT Collector를 다시 시작하십시오.
    </Callout>
  </Step>

  <Step>
    ## 데이터 찾기 및 사용 [#find-use-data]

    데이터가 수집되면 뉴렐릭 UI를 통해 포괄적인 오라클 데이터베이스 모니터링에 액세스할 수 있습니다.

    뉴렐릭에서 오라클 데이터베이스 엔티티를 찾으려면 다음을 수행하세요:

    1. <DNT>**[https://one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT> 으)로 이동합니다.
    2. 검색 기준을 <DNT>`instrumentation.provider = opentelemetry`</DNT> 으로 설정합니다.
    3. 엔티티 목록에서 오라클 ADB 데이터베이스를 선택하십시오.
  </Step>
