이 참조 문서는 뉴렐릭 OpenTelemetry 배포판(NRDOT) Collector를 사용한 PostgreSQL 모니터링을 위한 포괄적인 YAML 설정을 제공합니다. 이러한 전체 기능 설정에는 자체 호스팅 및 Amazon RDS 배포 전반의 운영 환경을 위한 전체 PostgreSQL 메트릭 카탈로그가 포함됩니다.

<Callout variant="important">
  **빠르게 시작하고 싶으십니까?** 이는 프로덕션 환경을 위한 고급 설정입니다. PostgreSQL 모니터링을 처음 설정하는 경우, 설정 가이드의 표준 설정으로 시작하여 기본 기능을 확인한 후 이 포괄적인 설정으로 돌아오는 것을 권장합니다.
</Callout>
