데이터베이스 메트릭, 쿼리 성능 및 시스템 상태에 대한 포괄적인 인사이트를 제공하는 뉴렐릭 NRDOT(Distribution of OpenTelemetry)를 사용하여 PostgreSQL 데이터베이스 성능을 모니터링하십시오.

이 NRDOT 기반 접근 방식은 모니터링을 위한 OpenTelemetry 데이터베이스 표준을 활용하여 기존 온호스트 통합(OHI)을 보완하고 기존 옵저버빌리티 그리드와 통합을 더 쉽게 만듭니다.

온-호스트 통합과 달리, NRDOT는 인프라 에이전트와 독립적으로 작동합니다. 데이터베이스 텔레메트리를 수집하는 데 인프라 에이전트가 필요하지 않습니다. NRDOT에는 네이티브 호스트 모니터링 기능도 포함되어 있으므로 다음과 같이 선택할 수 있습니다:

* 데이터베이스 모니터링을 위한 NRDOT와 함께 호스트 모니터링을 위해 인프라 에이전트를 사용하거나,
* NRDOT를 사용하여 데이터베이스와 호스트를 모두 모니터하십시오.

## 설치 방법을 선택하세요 [#install]

다음과 같은 방법으로 PostgreSQL 모니터링을 위한 NRDOT Collector를 설치할 수 있습니다:

* **수동 설치**: 자체 인프라에 수집기를 직접 설정하십시오.

  * [자체 호스팅 설정](/docs/opentelemetry/db360/postgresql/hosted)
  * [AWS RDS 또는 Aurora 설정](/docs/opentelemetry/db360/postgresql/rds)

* **[뉴렐릭 CLI](/docs/opentelemetry/db360/postgresql/cli)**: 단일 명령으로 수집기를 설치하고 구성합니다

* **[Ansible](/docs/opentelemetry/db360/postgresql/ansible)**: `newrelic.newrelic_install` Ansible 역할을 사용하여 대규모로 수집기를 설치하고 구성하십시오.

* **[Chef](/docs/opentelemetry/db360/postgresql/chef)**: `newrelic-install` Chef 쿡북을 사용하여 대규모로 수집기를 설치하고 구성하십시오.

* **[Helm 차트](/docs/opentelemetry/db360/postgresql/helm)**: `postgresql-otel` Helm 차트를 사용하여 Kubernetes에 PostgreSQL 모니터링을 설치하고 구성하십시오.

* **[도커](/docs/opentelemetry/db360/postgresql/docker)**: 도커에서 이미 실행 중인 PostgreSQL 인스턴스의 형제 컨테이너로 수집기를 실행하십시오.

## 가이드 설치 [#guided-installation]

## 한눈에 보는 설치 [#glance]

1. 호환성을 확인하고 사전 요구 사항을 수집하십시오.
2. NRDOT Collector를 설치하십시오.
3. 모니터링 사용자를 구성하십시오.
4. NRDOT Collector를 구성하십시오.
5. NRDOT Collector를 다시 시작하십시오.
6. 데이터가 뉴렐릭으로 흐르고 있는지 확인하십시오.
