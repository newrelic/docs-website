`newrelic-install` Chef 쿡북을 사용하여 PostgreSQL 모니터링을 위한 NRDOT Collector를 설치하고 구성할 수 있습니다. `newrelic-install::default` 레시피를 실행하면 쿡북은 수집기를 설치하고, 모니터링 역할 및 해당 권한을 생성하며, 수집기를 구성합니다.

<Callout variant="tip" title="가이드 설치">
  대신 뉴렐릭 UI를 통해 설치하려면 <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; PostgreSQL (Database 360)](https://onenr.io/00jlEJKbdQW)**</DNT>(으)로 이동하십시오. 이 페이지는 수동 설치만 다룹니다.
</Callout>

<Steps>
  <Step>
    ## 전제 조건 [#prerequisites]

    * 유효한 [라이선스 키](/docs/apis/intro-apis/new-relic-api-keys/#overview-keys)가 있는 뉴렐릭 계정.
    * 뉴렐릭 [계정 ID](/docs/accounts/accounts-billing/account-structure/account-id).
    * PostgreSQL 14 이상.
    * Chef 15 이상이 필요합니다.
    * Debian/Ubuntu 또는 RHEL/CentOS를 실행하는 Linux 수집기 호스트.
    * `pg_stat_statements` `shared_preload_libraries`을(를) 통해 로드해야 하며, 데이터베이스 재시작이 필요합니다. 레시피를 실행하기 전에 [서버 수준 전제 조건](/docs/opentelemetry/db360/postgresql/cli/#server-prereqs)을 준비하십시오.
    * 자체 호스팅 PostgreSQL의 경우: 비밀번호가 설정되어 있고 `pg_hba.conf`에서 비밀번호 기반 호스트 인증을 허용하는 PostgreSQL 서버(`postgres` 슈퍼유저 또는 동급)에 대한 관리자 액세스 권한이 필요합니다.
    * AWS RDS의 PostgreSQL 또는 Aurora의 경우: 수집기 호스트에서 RDS 엔드포인트로의 네트워크 연결, 그리고 RDS 마스터 사용자 이름 및 비밀번호.
    * 해당 리전의 [뉴렐릭 OTLP 엔드포인트](/docs/opentelemetry/best-practices/opentelemetry-otlp)에 대한 네트워크 연결.

    자세한 요구 사항은 [호환성](/docs/opentelemetry/db360/postgresql/compatibility)을 참조하십시오.
  </Step>

  <Step>
    ## Chef 쿡북을 다운로드합니다. [#chef-download-cookbook]

    Chef Supermarket에서 `newrelic-install` [Chef 쿡북](https://supermarket.chef.io/cookbooks/newrelic-install)을 chef-repo 디렉터리로 다운로드하십시오:

    ```bash
    knife supermarket install newrelic-install
    ```
  </Step>

  <Step>
    ## 기본 속성을 교체하십시오. [#chef-configure]

    `attributes/default.rb`의 기본 속성을 계정 세부 정보로 변경하십시오:

    <CollapserGroup>
      <Collapser id="chef-host" title="자체 호스팅 PostgreSQL">
        이 쿡북은 단일 수집기에서 하나 이상의 PostgreSQL 인스턴스를 모니터합니다. 단일 호스트/포트/자격 증명 세트 대신, 노드에 이미 존재해야 하는 두 개의 파일을 읽습니다: 모니터할 모든 인스턴스와 각 인스턴스에서 모니터할 데이터베이스를 나열하는 인스턴스 파일(YAML)과 일치하도록 인덱싱된 각각에 대한 수퍼유저 로그인 및 비밀번호가 포함된 시크릿 파일(`KEY=VALUE`)입니다. 정확한 파일 형식은 [CLI 설치](/docs/opentelemetry/db360/postgresql/cli/#cli-install) 페이지를 참조하십시오.

        ```ruby
        default['newrelic_install']['NEW_RELIC_API_KEY']    = <API key>
        default['newrelic_install']['NEW_RELIC_ACCOUNT_ID'] = <Account ID>
        default['newrelic_install']['NEW_RELIC_REGION']     = <Region>
        default['newrelic_install']['targets'] = [
          'nrdot-collector-postgresql'
        ]
        default['newrelic_install']['env']['NR_CLI_POSTGRES_CONFIG_PRESET']         = <1 Basic, 2 Advanced, default 1>
        default['newrelic_install']['env']['NR_CLI_POSTGRES_INSTANCES_FILE']        = <path to the instances YAML file on the node>
        default['newrelic_install']['env']['NR_CLI_POSTGRES_SECRETS_FILE']          = <path to the secrets file (KEY=VALUE per instance) on the node>
        default['newrelic_install']['env']['NR_CLI_POSTGRES_ENABLE_EXPLAIN_HELPER'] = <y or N, default N; PREVIEW feature, see table below>
        # See all available targets at: https://github.com/newrelic/chef-install
        ```

        <Callout variant="important">
          쿡북은 비밀번호를 사용하여 TCP를 통해 PostgreSQL에 연결하므로, 각 인스턴스의 슈퍼유저에게는 비밀번호가 설정되어 있어야 하며 `pg_hba.conf`은(는) TCP 연결에 대해 비밀번호 기반 호스트 인증(`md5` 또는 `scram-sha-256`)을 허용해야 합니다:

          ```bash
          sudo -u postgres psql -c "ALTER USER postgres WITH PASSWORD '<password>';"
          ```
        </Callout>

        <Callout variant="tip">
          이 수집기에서 두 개 이상의 PostgreSQL 인스턴스를 모니터링하려면 인스턴스 파일에 항목을 더 추가하고 일치하는 번호가 지정된 자격 증명(`_2`, `_3`,...)을 secrets 파일에 추가하십시오. 검사에 실패한(또는 나열된 데이터베이스가 없는) 인스턴스는 전체 설치를 중단하는 대신 로그에 기록된 이유와 함께 건너뜁니다.

  <Step>
    ## Chef 쿡북을 업로드하십시오. [#chef-upload-cookbook]

    `newrelic-install` Chef 쿡북을 Chef 서버에 업로드하십시오:

    ```bash
    knife cookbook upload newrelic-install
    ```
  </Step>

  <Step>
    ## 실행 목록을 업데이트하십시오 [#chef-run-list]

    노드의 실행 목록에 `newrelic-install` 레시피를 추가하십시오:

    ```json
    "run_list": [
      "recipe[newrelic-install]"
    ]
    ```
  </Step>

  <Step>
    ## 데이터 찾기 및 사용 [#find]

    데이터가 수집되면 뉴렐릭 UI를 통해 포괄적인 PostgreSQL 데이터베이스 모니터링에 액세스할 수 있습니다.

    뉴렐릭에서 PostgreSQL 데이터베이스 엔티티를 찾으려면 다음을 수행하십시오:

    1. <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; All capabilities &gt; Databases**</DNT> 으)로 이동합니다.
    2. **<DNT>Entity type</DNT>** 드롭다운 메뉴에서 <DNT>**PostgreSQL instance**</DNT>을(를) 선택한 다음 <DNT>**Apply**</DNT>을(를) 클릭합니다.
    3. 엔티티 목록에서 PostgreSQL 데이터베이스를 선택하십시오.
  </Step>
</Steps>
