NRDOT Collector로 Microsoft SQL Server를 모니터링할 때 발생할 수 있는 일반적인 문제를 해결하십시오.

## 일반적인 문제 [#common-issues]

### 네트워크 연결 문제 [#network-connectivity]

NRDOT Collector에서 네트워크 연결 문제가 발생하는 경우, 다음 명령을 실행하여 SQL Server 인스턴스에 대한 연결을 테스트하십시오:

* Windows의 경우 다음 명령을 실행하세요.

  ```shell
  Test-NetConnection -ComputerName <YOUR_IP_ADDRESS> -Port <YOUR_PORT_NUMBER>
  ```

* 리눅스에서는 다음 명령을 실행하세요:

  ```bash
  nc -zv <YOUR_IP_ADDRESS> <YOUR_PORT_NUMBER>
  ```

## 뉴렐릭에 데이터가 표시되지 않음 [#data-not-flowing]

* 속도 제한 관련 문제를 확인하려면 다음을 실행하십시오:

  ```sql
  SELECT * FROM NrIntegrationError
  ```

* 데이터가 여전히 유입되지 않는 경우, 메트릭 및 로그 이벤트에 설정된 드롭 규칙이 있는지 확인하십시오. [드롭 필터 규칙으로 로그 데이터 삭제](/docs/logs/ui-data/drop-data-drop-filter-rules/) 및 [Pipeline 제어](/docs/new-relic-control/pipeline-control/overview/)를 참조하십시오.
