당사의 OpenTelemetry 기반 모니터링 솔루션을 통해 SQL Server 성능에 대한 깊은 인사이트를 얻으십시오. 데이터베이스 메트릭을 추적하고, 느린 쿼리를 분석하고, 리소스 사용량을 모니터링하며, 데이터베이스 성능을 애플리케이션과 연관시킵니다.

이 NRDOT 기반 접근 방식은 모니터링을 위한 OpenTelemetry 데이터베이스 표준을 활용하여 기존 온호스트 통합(OHI)을 보완하고 기존 옵저버빌리티 그리드와 통합을 더 쉽게 만듭니다.

온-호스트 통합과 달리, NRDOT는 인프라 에이전트와 독립적으로 작동합니다. 데이터베이스 텔레메트리를 수집하는 데 인프라 에이전트가 필요하지 않습니다. NRDOT에는 네이티브 호스트 모니터링 기능도 포함되어 있으므로 다음과 같이 선택할 수 있습니다:

* 데이터베이스 모니터링을 위한 NRDOT와 함께 호스트 모니터링을 위해 인프라 에이전트를 사용하거나,
* NRDOT를 사용하여 데이터베이스와 호스트를 모두 모니터하십시오.

주요 기능:

* **OpenTelemetry 표준**: 기존 옵저버빌리티 도구와 원활하게 통합됩니다.
* **포괄적인 메트릭**: 50개 이상의 데이터베이스 성능 지표
* **쿼리 수준 인사이트**: 성능이 느린 쿼리를 식별하고 최적화합니다.
* **유연한 배포**: 자체 호스팅 및 cloud 환경에서 작동합니다.
* **APM 상관관계**: 데이터베이스 성능을 애플리케이션 트레이스에 연결합니다.

## 안내 설치 [#ui-install]

대신 뉴렐릭 UI를 통해 이를 설치하려면 <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; Microsoft SQL Server (Database 360)](https://onenr.io/00jlEJX6EQW)** </DNT>로 이동하십시오. 화면의 지시에 따라 통합을 설정하십시오.

## 한눈에 보는 설치 [#at-a-glance]

1. 호환성을 확인하고 사전 요구 사항을 수집하십시오.
2. NRDOT Collector를 설치하십시오.
3. 모니터링 사용자를 구성하십시오.
4. NRDOT Collector를 구성하십시오.
5. NRDOT Collector를 다시 시작하십시오.
6. 데이터가 뉴렐릭으로 흐르고 있는지 확인하십시오.
