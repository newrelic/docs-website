OpenTelemetry의 뉴렐릭 배포판(NRDOT) 수집기를 사용하여 데이터베이스 모니터링, 쿼리 분석 및 시스템 상태 메트릭을 통해 SQL Server 성능에 대한 포괄적인 인사이트를 얻으십시오.

<Callout variant="tip" title="가이드 설치">
  대신 뉴렐릭 UI를 통해 설치하려면 <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; Microsoft SQL Server (Database 360)](https://onenr.io/00jlEJX6EQW)** </DNT>(으)로 이동하십시오. 화면의 지시에 따라 통합을 설정하십시오. 이 페이지에서는 수동 설치만 다룹니다.
</Callout>

<Callout variant="tip">
  Linux RDS 환경에서 SQL Server를 사용하는 경우, [RDS용 Linux 계측을](/docs/opentelemetry/db360/mssql/linux-rds) 참조하십시오.
</Callout>

<Steps>
  <Step>
    ## 전제 조건 [#prerequisites]

    * 유효한 [라이선스 키](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)가 있는 뉴렐릭 계정.

    * 해당 리전의 [뉴렐릭 OTLP 엔드포인트](/docs/opentelemetry/best-practices/opentelemetry-otlp)에 대한 네트워크 연결.

    * SQL Server 요구 사항:

      * SQL Server 2017 이상.
      * SQL Server에 대한 관리자 액세스 권한(`sysadmin` 역할 또는 동등한 권한).
      * 포트 `1433` 또는 사용자 지정 포트에서 수집기와 SQL Server 간의 네트워크 연결.
      * Linux 시스템에 설치된 `sqlcmd` 유틸리티입니다.
  </Step>

  <Step>
    ## NRDOT Collector설치하세요 [#setup]

    Linux 배포판용 NRDOT 패키지를 다운로드하고 설치하십시오. `<NRDOT_VERSION>`을(를) [nrdot-collector-releases](https://github.com/newrelic/nrdot-collector-releases/releases) 페이지의 최신 릴리스 태그로 교체하십시오.

    <Callout variant="tip">
      쿼리 성능 모니터링을 위한 인프라 수준 메트릭을 보려면 SQL Server 인스턴스와 동일한 호스트에 NRDOT Collector를 설치하는 것을 권장합니다.
    </Callout>

    <CollapserGroup>
      <Collapser id="deb" title="데비안/우분투용">
        * AMD64 아키텍처용:

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_amd64.deb" --output nrdot-collector.deb && sudo dpkg -i nrdot-collector.deb
          ```

        * ARM64 아키텍처용:

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_arm64.deb" --output nrdot-collector.deb && sudo dpkg -i nrdot-collector.deb
          ```
      </Collapser>

      <Collapser id="rpm" title="RHEL/CentOS용">
        * AMD64 아키텍처용:

          ```bash
            NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_x86_64.rpm" --output nrdot-collector.rpm && sudo rpm -ivh nrdot-collector.rpm
          ```

        * ARM64 아키텍처용:

          ```bash
            NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_arm64.rpm" --output nrdot-collector.rpm && sudo rpm -ivh nrdot-collector.rpm
          ```
      </Collapser>
    </CollapserGroup>

  <Step>
    ## 모니터링 사용자 생성 [#user]

    루트 사용자로 이 스크립트를 실행하여 `newrelic` 모니터링 사용자를 생성하고 SQL Server 메트릭 수집에 필요한 권한을 부여하십시오.

    1. `nr-grant-permission.sql`라는 이름의 설정 파일을 생성합니다.

    2. 다음 SQL 스크립트를 붙여넣어 `newrelic` 모니터링 사용자를 생성하고 `<YOUR_PASSWORD>`을(를) 원하는 비밀번호로 변경하십시오:

       ```sql
       USE [master];
       GO
       CREATE LOGIN [newrelic] WITH PASSWORD = '<YOUR_PASSWORD>';
       GO
       -- Instance-level permissions
       GRANT VIEW SERVER STATE TO [newrelic];
       GRANT VIEW ANY DEFINITION TO [newrelic];
       GRANT VIEW ANY DATABASE TO [newrelic];
       GO
       -- Grant read access privileges to all user databases
       DECLARE @name SYSNAME;
       DECLARE db_cursor CURSOR READ_ONLY FORWARD_ONLY FOR
       SELECT [name]
       FROM [master].[sys].[databases]
       WHERE [name] NOT IN ('master', 'msdb', 'model', 'rdsadmin', 'distribution')
       AND [state] = 0; -- Only online databases
       OPEN db_cursor;
       FETCH NEXT FROM db_cursor INTO @name;
       WHILE @@FETCH_STATUS = 0
       BEGIN
         BEGIN TRY
           EXEC('USE [' + @name + '];
             IF NOT EXISTS (SELECT 1 FROM sys.database_principals WHERE name = ''newrelic'')
             BEGIN
               CREATE USER [newrelic] FOR LOGIN [newrelic];
             END;
             GRANT VIEW DATABASE STATE TO [newrelic];');
         END TRY
         BEGIN CATCH
           PRINT 'Error on ' + @name + ': ' + ERROR_MESSAGE();
         END CATCH
         FETCH NEXT FROM db_cursor INTO @name;
       END
       CLOSE db_cursor;
       DEALLOCATE db_cursor;
       GO
       ```

    3. 로그인을 생성하고 서버 수준 권한을 부여할 수 있는 권한을 가진 로그인(예: `sa` 로그인 또는 `sysadmin` 역할을 가진 다른 계정)으로 `sqlcmd`을(를) 사용하여 스크립트를 실행하십시오. `<YOUR_ADMIN_USERNAME>` 및 `<YOUR_ADMIN_PASSWORD>`를 해당 로그인의 자격 증명으로 교체하십시오:

       ```bash
       sqlcmd -S <YOUR_DB_ENDPOINT> -U <YOUR_ADMIN_USERNAME> -P '<YOUR_ADMIN_PASSWORD>' -C -i nr-grant-permission.sql
       ```

    4. (선택 사항) 올바른 권한으로 사용자가 성공적으로 생성되었는지 확인하십시오:

       ```bash
       sqlcmd -S <YOUR_DB_ENDPOINT> -U <YOUR_ADMIN_USERNAME> -P '<YOUR_ADMIN_PASSWORD>' -C -Q "SELECT sp.name AS [User], p.permission_name AS [Permission_Granted] FROM sys.server_permissions p JOIN sys.server_principals sp ON p.grantee_principal_id = sp.principal_id WHERE sp.name = 'newrelic';"
       ```

       **예상 출력:**

       ```bash
       [output] User Permission_Granted
       [output] -------------------------------------------------------------------------------------
       [output] newrelic CONNECT SQL
       [output] newrelic VIEW ANY DEFINITION
       [output] newrelic VIEW ANY DATABASE
       [output] newrelic VIEW SERVER STATE
       ```

       이 출력은 필요한 서버 수준 권한을 가지고 사용자가 성공적으로 생성되었음을 확인시켜 줍니다.

       <Callout variant="tip">
         데이터베이스 자격 증명과 같은 민감한 정보를 안전하게 관리하려면 [시크릿 관리](/docs/opentelemetry/db360/capabilities/db-apm/#secret-management) 도구에 저장하십시오.
       </Callout>
  </Step>

[모니터링 사용자 생성](#user)에서 생성된 모니터링 사용자는 3가지 권한을 모두 포함합니다.

  <Step>
    ## NRDOT Collector 설정 업데이트 [#update]

    위의 대화형 입력으로 YAML 파일을 구성한 후, NRDOT Collector 설정을 완료하십시오:

    1. 서비스 설정 파일을 편집하십시오:

       ```bash
       sudo nano /etc/nrdot-collector/nrdot-collector.conf
       ```

    2. 새 `mssql-config.yaml` 파일을 가리키도록 설정 경로를 업데이트하십시오:

       ```bash
       OTELCOL_CONFIG="/etc/nrdot-collector/mssql-config.yaml"
       ```

    3. (선택 사항) NRDOT Collector 설정을 확인하십시오:

       ```bash
       sudo /usr/bin/nrdot-collector validate --config=/etc/nrdot-collector/mssql-config.yaml
       ```

       <Callout variant="tip">
         애플리케이션 성능을 데이터베이스 작업과 연관시키려면 데이터베이스 서비스 식별을 설정할 수 있습니다. 자세한 내용은 [데이터베이스 서비스 식별 설정 가이드를](/docs/opentelemetry/db360/capabilities/db-apm) 참조하십시오.
       </Callout>
  </Step>

  <Step>
    ## NRDOT Collector를 다시 시작하십시오 [#restart]

    설정을 업데이트한 후 NRDOT Collector 서비스를 다시 시작하십시오:

    ```bash
    sudo systemctl restart nrdot-collector
    ```

    <Callout variant="tip">
      새로운 설정이 적용되도록 설정 변경 후에는 항상 NRDOT Collector 서비스를 다시 시작하십시오.
    </Callout>
  </Step>

  <Step>
    ## 데이터 찾기 및 사용 [#find]

    데이터가 수집되면 뉴렐릭 UI를 통해 포괄적인 SQL Server 데이터베이스 모니터링에 액세스할 수 있습니다.

    뉴렐릭에서 SQL Server 데이터베이스를 찾으려면 다음을 수행하세요.

    1. <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; All capabilities &gt; Databases**</DNT> 으)로 이동합니다.

    2. **<DNT>Entity type</DNT>** 드롭다운 메뉴에서 <DNT>**MSSQL instance**</DNT>을(를) 선택한 다음 <DNT>**Apply**</DNT>을(를) 클릭합니다.

    3. 모임 목록에서 SQL Server 데이터베이스를 선택합니다.

       NRDOT로 SQL Server 모니터링을 설정한 후 다음을 수행할 수 있습니다:

       * [사용자 정의 대시보드를 만들어](/docs/query-your-data/explore-query-data/dashboards/introduction-dashboards/) 데이터베이스 지표를 시각화하세요.
       * 중요한 데이터베이스 성능에 대한 [알림 설정](/docs/alerts/create-alert/create-alert-condition/alert-conditions/), 참조 값
       * 뉴렐릭 쿼리 기능을 사용하여 [데이터 탐색](/docs/query-your-data/explore-query-data/browse-data/introduction-data-explorer/)
  </Step>
</Steps>
