NRDOT Collector가 수집한 포괄적인 메트릭으로 SQL Server 데이터베이스 성능을 모니터하십시오. 기본적으로 뉴렐릭은 [Default metrics and events \[기본 메트릭 및 이벤트\]](#default) 섹션에 참조된 메트릭 및 쿼리 수준 이벤트를 수집합니다. [Full-feature metrics \[전체 기능 메트릭\]](#full-feature) 섹션에 나열된 원하는 메트릭을 활성화하여 모니터링을 향상시킬 수 있습니다.

## 기본 메트릭 및 이벤트 [#default]

### 로그 이벤트 [#log-events]

다음 이벤트는 OpenTelemetry 로그 레코드로 수집되며, 옵트인 방식인 `db.server.procedure_definition`을(를) 제외하고 기본적으로 활성화됩니다. 쿼리 수준의 가시성을 제공합니다: 활성 쿼리 샘플, 상위 쿼리, 실행 계획, 상위 저장 프로시저 및 저장 프로시저 정의.

<CollapserGroup>

<Collapser id="db-server-top-query" title="상위 쿼리">
수집 간격 내에 소요된 최장 경과 시간을 기준으로 필터링된 상위 N개 쿼리에 대한 이벤트 메트릭 컬렉션입니다. 이 이벤트는 기본적으로 활성화되어 있습니다.

동작을 조정하려면 `top_query_collection` 블록을 사용하십시오:

```yaml
top_query_collection:
  lookback_time: 60s
  max_query_sample_count: 1000
  top_query_count: 250
  collection_interval: 60s
  allowed_comment_keys: [nr_service_guid]
```

<Collapser id="db-server-top-procedure" title="상위 프로시저">
수집 간격 동안의 델타로 컴퓨트된, 경과 시간 기준 상위 저장 프로시저에 대한 집계된 성능 메트릭입니다. `sqlserver.procedure_id`을(를) 통해 `db.server.top_query` 및 `db.server.query_sample`와(과) 상관관계를 갖습니다. 이 이벤트는 기본적으로 활성화되어 있습니다.

<Callout variant="tip">
`sys.dm_exec_procedure_stats.total_spills`에 대한 지원이 도입된 SQL Server 2017 CU3 이상이 필요합니다. 이전 버전에서는 이 이벤트가 데이터를 내보내지 않고 오류를 로그에 기록합니다. 다른 이벤트는 영향을 받지 않습니다.
</Callout>

동작을 조정하려면 `top_procedure_collection` 블록을 사용하십시오:

```yaml
top_procedure_collection:
  max_procedure_sample_count: 1000
  top_procedure_count: 250
  collection_interval: 60s
```

## Amazon RDS 제한 사항 [#rds-limitations]

Amazon RDS for SQL Server 인스턴스를 모니터링할 때, RDS 서비스 제한 및 SQL Server 에디션 제한으로 인해 특정 메트릭이 `0` 을(를) 보고하거나 수집되지 않을 수 있습니다.

<Callout variant="important">
다음 제한 사항은 Amazon RDS에서 실행되는 SQL Server 인스턴스에 특별히 적용됩니다. 자체 호스팅되는 SQL Server 배포는 이러한 제한 사항의 영향을 받지 않습니다.

## Azure SQL 데이터베이스 제한 사항 [#azure-sql-database-limitations]

Azure SQL 데이터베이스를 모니터링할 때, 수집기가 단일 데이터베이스에 연결되고 인스턴스 수준 또는 운영 시스템 데이터에 액세스할 수 없기 때문에 일부 메트릭은 사용할 수 없습니다.

<Callout variant="important">
다음 제한 사항은 Azure SQL 데이터베이스에만 적용됩니다. Azure SQL Managed 인스턴스 및 자체 호스팅 SQL Server는 이러한 메트릭을 지원합니다.
</Callout>
