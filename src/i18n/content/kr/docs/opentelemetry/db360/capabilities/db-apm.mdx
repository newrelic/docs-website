SQL 쿼리 주석 기능을 통해 애플리케이션과 데이터베이스 성능 간의 원활한 상관관계를 파악하십시오. 이 메커니즘을 통해 뉴렐릭의 NRDOT(Distribution of OpenTelemetry) 데이터베이스 수신기는 특정 데이터베이스 로드, 느린 쿼리 또는 차단 이벤트를 담당하는 서비스를 정확하게 식별할 수 있습니다.

<Callout variant="important">
뉴렐릭은 애플리케이션의 데이터베이스 연결 주소 및 포트를 데이터베이스 모니터링 에이전트의 연결 주소 및 포트와 일치시켜 뉴렐릭 애플리케이션 성능 모니터링(뉴렐릭 APM) 및 데이터베이스 엔티티를 연결합니다. 이 연결은 양쪽에서 정확히 동일한 주소와 포트를 보고할 때 안정적으로 작동합니다. 그러나 애플리케이션이 로드 밸런서나 프록시를 통해 트래픽을 라우팅하거나 두 구성 요소가 다른 주소 형식(예: IP 주소 대 도메인 이름)을 사용하는 경우 자동 연결이 실패할 수 있습니다.
</Callout>

## 전제 조건 [#prerequisites]

* 자바 에이전트: 버전 `9.4.0` 이상.
* .NET 에이전트: 버전 `10.54.0` 이상.

## APM-DB 상관관계를 활성화하십시오. [#enable-correlation]

뉴렐릭이 애플리케이션 서비스와 데이터베이스 활동을 연관시킬 수 있도록 APM 에이전트에서 SQL 쿼리 주석 처리를 활성화해 주십시오.

### 자바 에이전트용 [#enable-correlation-java]

이 상관관계를 활성화하려면 자바 에이전트 설정 파일(`newrelic.yml`)의 `transaction_tracer` 섹션에 `sql_metadata_comments` 속성을 추가합니다. 자세한 내용은 [자바 에이전트 설정 문서](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file/)를 참조하세요.

```yaml
transaction_tracer:
  sql_metadata_comments:
    enabled: true
```

### .NET 에이전트의 경우 [#enable-correlation-dotnet]

이 상관관계를 활성화하려면 .NET 에이전트 설정 파일(`newrelic.config`)의 `transactionTracer` 섹션에 `sqlMetadataComments` 속성을 추가하십시오. 자세한 내용은 [.NET 에이전트 설정 문서를](/docs/apm/agents/net-agent/configuration/net-agent-configuration/) 참조하십시오.

<CollapserGroup>
<Collapser id="option1" title="옵션 1: 환경 변수를 통해(스크립트)">
시작 또는 래퍼 스크립트를 사용하여 실행 파일을 출시하는 경우, `NEW_RELIC_TRANSACTION_TRACER_SQL_METADATA_COMMENTS_ENABLED` 변수를 `1`(으)로 설정하십시오.

```powershell
# Add this environment variable alongside your other CoreCLR / New Relic variables
$env:NEW_RELIC_TRANSACTION_TRACER_SQL_METADATA_COMMENTS_ENABLED = "1"
```
</Collapser>

<Collapser id="option2" title="옵션 2: newrelic.config를 통해">
또는 `newrelic.config` 파일의 `<transactionTracer>` 블록 내에서 이를 직접 활성화할 수 있습니다:

```xml
<transactionTracer enabled="true" sqlMetadataCommentsEnabled="true" />
```
</Collapser>
</CollapserGroup>

## 작동 원리 [#how-it-works]

애플리케이션이 데이터베이스에 쿼리를 전송하면 APM 에이전트가 자동으로 APM 엔티티 GUID를 SQL 텍스트 앞에 주석으로 추가합니다. 이러한 일반적인 업계 관행은 SQL 문의 실행 논리에 영향을 미치지 않습니다.

1. **주석 추가**: APM 에이전트는 나가는 SQL 앞에 주석 문자열을 추가합니다(예: `/* nr_service_guid="MTE2MDAzMTl8QVBNfEFQUExJ" */ SELECT * FROM orders...`).
2. **실행**: 데이터베이스는 평소와 같이 쿼리를 실행합니다. 댓글은 데이터베이스의 내부 성능 스키마(예: `sys.dm_exec_requests` 또는 `v$session`)에 저장됩니다.
3. **추출**: 데이터베이스 수신기는 이러한 쿼리(활성, 느린 또는 차단)를 가져옵니다.
4. **보강**: 수신자는 댓글을 구문 분석하고 `nr_service_guid` 을 추출하여 데이터베이스 메트릭에 차원으로 추가합니다.

## 서비스 혜택 [#benefits]

서비스 메타데이터를 앞에 추가하면 데이터베이스 생태계에 대한 높은 수준의 가시성을 확보할 수 있습니다.

* **서비스 수준 원인 파악**: 데이터베이스 CPU 또는 메모리 사용량 급증의 원인이 되는 마이크로서비스를 즉시 확인할 수 있습니다.
* **개선된 느린 쿼리 분석**: 데이터베이스 병목현상이 특정 애플리케이션 버전에 국한된 것인지 파악하려면 `client_name` (으)로 느린 쿼리 로그를 필터링하십시오.
* **블로킹 및 교착 상태 해결**: 블로킹의 &quot;소유자&quot;를 신속하게 식별하여 팀 간 협업을 가속화합니다. 문제 진단, 해결
