뉴렐릭 CLI를 사용하여 MySQL 모니터링을 위한 NRDOT Collector를 설치하고 구성할 수 있습니다. CLI는 단일 명령으로 수집기를 설치하고, 모니터링 사용자를 생성하며, 수집기를 구성합니다.

<Callout variant="tip" title="가이드 설치">
  대신 뉴렐릭 UI를 통해 설치하려면 <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; MySQL (Database 360)](https://onenr.io/0oQDYBNG1wy)** </DNT>(으)로 이동하십시오. 이 페이지는 수동 설치만 다룹니다.
</Callout>

<Steps>
  <Step>
    ## 전제 조건 [#prerequisites]

    * 유효한 [라이선스 키](/docs/apis/intro-apis/new-relic-api-keys/#overview-keys)가 있는 뉴렐릭 계정.
    * 뉴렐릭 [계정 ID](/docs/accounts/accounts-billing/account-structure/account-id).
    * MySQL 5.7 이상.
    * Debian/Ubuntu 또는 RHEL/CentOS를 실행하고 `curl` 및 `systemd`이(가) 설치되어 있으며 `mysql` 클라이언트를 사용할 수 있는 Linux 수집기 호스트.
    * 자체 호스팅 MySQL의 경우: MySQL 서버에 대한 관리자 액세스 권한(`root` 계정 또는 이에 상응하는 계정)이 필요합니다.
    * AWS RDS/Aurora MySQL의 경우: 수집기 호스트에서 RDS 엔드포인트로의 네트워크 연결(RDS 보안 그룹의 MySQL 포트에 대한 인바운드 액세스) 및 RDS 마스터 사용자 이름과 비밀번호가 필요합니다.
    * 해당 리전의 [뉴렐릭 OTLP 엔드포인트](/docs/opentelemetry/best-practices/opentelemetry-otlp)에 대한 네트워크 연결.

    자세한 요구 사항은 [호환성 및 필수 조건](/docs/opentelemetry/db360/mysql/compatibility)을 참조하십시오.
  </Step>

  <Step>
    ## NRDOT Collector를 설치하고 구성하십시오 [#cli-install]

    <CollapserGroup>
      <Collapser id="cli-host" title="자체 호스팅 MySQL">
        이 레시피는 단일 수집기에서 하나 이상의 MySQL 인스턴스를 모니터합니다. 단일 호스트/포트/자격 증명 세트를 묻는 대신, 미리 생성한 두 개의 파일을 읽습니다: 모니터할 모든 인스턴스를 나열하는 인스턴스 파일(YAML)과 일치하도록 인덱싱된, 각각에 대한 관리자 로그인 및 비밀번호가 포함된 시크릿 파일(`KEY=VALUE`)입니다.

        1. 인스턴스 파일을 생성합니다. 이 수집기가 모니터할 MySQL 인스턴스당 하나의 항목을 추가하고, 단일 인스턴스만 실행 중인 경우에는 하나의 항목만 추가합니다:

           ```bash
           cat > ~/mysql-instances.yml << 'EOF'
           instances:
             - host: localhost
               port: 3306
               login_name: newrelic
           EOF
           ```

        2. 인스턴스 파일의 순서와 일치하도록 인덱싱하여, 각 인스턴스에 대한 관리자 로그인(모든 전체 관리 사용자를 사용할 수 있으며, 반드시 `root`일 필요는 없음) 및 비밀번호를 포함하여 시크릿 파일을 생성하십시오:

           ```bash
           umask 077
           cat > ~/mysql-secrets.env << 'EOF'
           NR_CLI_MYSQL_ADMIN_USER_1=root
           NR_CLI_MYSQL_ADMIN_PASSWORD_1=YourRootPassword1
           EOF
           chmod 600 ~/mysql-secrets.env
           ```

        ```bash
        curl -Ls https://download.newrelic.com/install/newrelic-cli/scripts/install.sh | bash && sudo NEW_RELIC_API_KEY=INSERT_YOUR_API_KEY NEW_RELIC_ACCOUNT_ID=INSERT_YOUR_ACCOUNT_ID NEW_RELIC_REGION=INSERT_YOUR_REGION /usr/local/bin/newrelic install -n nrdot-collector-mysql
        ```

        <Callout variant="important">
          이 인스톨러는 비밀번호를 사용하여 TCP를 통해 MySQL에 연결하므로, secrets 파일의 관리자 계정은 비밀번호 기반 인증을 사용해야 합니다. 일부 Debian/Ubuntu 설치에서는 `root`@`localhost`이(가) 기본적으로 `auth_socket` 플러그인(비밀번호 없음, 로컬 소켓 전용)으로 설정되며, 이는 여기에서 작동하지 않습니다. 먼저 로컬에서 root로 다음을 실행하여 변경하십시오:

          ```bash
          mysql -u root -e "ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '<password>';"
          ```

          `Access denied`(으)로 실패하는 경우, `mysql-server` 패키지는 `/etc/mysql/debian.cnf`에 알려진 관리자 자격 증명이 있는 `debian-sys-maint` 계정도 생성합니다. 대신 이를 사용하십시오:

          ```bash
          mysql --defaults-file=/etc/mysql/debian.cnf -e "ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '<password>';"
          ```
        </Callout>

      <Collapser id="cli-rds" title="AWS RDS/Aurora MySQL">
        이 레시피는 셀프 호스팅과 동일한 인스턴스 파일/시크릿 파일 패턴을 사용하여 단일 수집기에서 하나 이상의 RDS MySQL 또는 Aurora 엔드포인트를 모니터합니다.

        1. RDS 엔드포인트를 `host`(으)로 사용하여 인스턴스 파일을 생성하며, 단일 RDS 인스턴스만 모니터링하는 경우 항목을 하나만 지정하십시오:

           ```bash
           cat > ~/mysql-instances.yml << 'EOF'
           instances:
             - host: mydb1.abcdefg12345.us-east-1.rds.amazonaws.com
               port: 3306
               login_name: newrelic
           EOF
           ```

        2. 인스턴스 파일의 순서와 일치하도록 인덱싱하여 각 인스턴스에 대한 RDS 마스터 사용자 이름과 비밀번호로 secrets 파일을 생성하십시오:

           ```bash
           umask 077
           cat > ~/mysql-secrets.env << 'EOF'
           NR_CLI_MYSQL_ADMIN_USER_1=admin
           NR_CLI_MYSQL_ADMIN_PASSWORD_1=YourMasterPassword1
           EOF
           chmod 600 ~/mysql-secrets.env
           ```

        ```bash
        curl -Ls https://download.newrelic.com/install/newrelic-cli/scripts/install.sh | bash && sudo NEW_RELIC_API_KEY=INSERT_YOUR_API_KEY NEW_RELIC_ACCOUNT_ID=INSERT_YOUR_ACCOUNT_ID NEW_RELIC_REGION=INSERT_YOUR_REGION /usr/local/bin/newrelic install -n nrdot-collector-mysql-rds
        ```

  <Step>
    ## 데이터 찾기 및 사용 [#find]

    데이터가 수집되면 뉴렐릭 UI를 통해 포괄적인 MySQL 데이터베이스 모니터링에 액세스할 수 있습니다.

    뉴렐릭에서 MySQL 데이터베이스 엔티티를 찾으려면 다음을 수행하십시오:

    1. <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; All capabilities &gt; Databases**</DNT> 으)로 이동합니다.
    2. **<DNT>Entity type</DNT>** 드롭다운 메뉴에서 <DNT>**MySQL instance**</DNT>을(를) 선택한 다음 <DNT>**Apply**</DNT>을(를) 클릭합니다.
    3. 엔티티 목록에서 MySQL 데이터베이스를 선택하십시오.

    데이터가 수신되는지 확인하려면 [쿼리 빌더](/docs/query-your-data/explore-query-data/query-builder/introduction-query-builder/)에서 다음 쿼리를 실행하십시오:

    ```sql
    SELECT count(*) FROM Metric
    WHERE metricName LIKE 'mysql.%'
    AND instrumentation.provider = 'opentelemetry'
    SINCE 10 minutes ago
    ```
