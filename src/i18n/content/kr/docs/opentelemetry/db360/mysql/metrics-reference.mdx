NRDOT Collector가 수집한 포괄적인 메트릭을 사용하여 MySQL 데이터베이스 성능을 모니터링하십시오. 기본적으로 뉴렐릭은 [Default metrics and events](#default) 섹션에 참조된 메트릭 및 쿼리 수준 이벤트를 수집합니다. [Full-feature metrics](#full-feature) 섹션에 나열된 원하는 메트릭을 활성화하여 모니터링을 향상할 수 있습니다.

### 쿼리 이벤트 [#query-events]

다음 이벤트는 OpenTelemetry 로그 레코드로 수집되며 기본적으로 활성화되어 있습니다. 쿼리 수준의 가시성을 제공합니다.

<CollapserGroup>
<Collapser id="query-sample" title="쿼리 샘플">
현재 실행 중인 데이터베이스 명령문에 대한 실시간 가시성: 완전한 실행 로그가 아니라 매 스크랩마다 캡처되는 특정 시점의 스냅샷입니다. 이 이벤트는 기본적으로 활성화되어 있습니다.

동작을 조정하려면 `query_sample_collection` 블록을 사용하십시오:

```yaml
query_sample_collection:
  max_rows_per_query: 100
  allowed_comment_keys: [nr_service_guid]
```

<Collapser id="top-query" title="상위 쿼리">
가장 많은 실행 시간을 소비하는 쿼리로, MySQL 자체 `performance_schema.events_statements_summary_by_digest`에 의해 서버 측에서 집계됩니다. 이는 샘플 수가 아닌 다이제스트별 실제 실행 카운터입니다. 이 이벤트는 기본적으로 활성화되어 있습니다.

동작을 조정하려면 `top_query_collection` 블록을 사용하십시오:

```yaml
top_query_collection:
  lookback_time: 60
  max_query_sample_count: 5000
  top_query_count: 200
  collection_interval: 60s
  query_plan_cache_size: 1000
  query_plan_cache_ttl: 1h
  allowed_comment_keys: [nr_service_guid]
```
