New Relic은 고객과 데이터의 보안을 위해 최선을 다하고 있습니다. 우리는 조정된 공개 프로그램을 통해 보안 연구원과 협력하는 것이 보안 목표를 달성하기 위한 중요한 수단이라고 믿습니다.

당사의 제품 또는 웹사이트에서 보안 취약점을 발견했다고 생각하시는 경우, 이 문서에 설명된 대로 당사의 통합 공개 프로그램을 통해 이를 신고해 주시면 감사하겠습니다. 다른 우려 사항이 있는 경우, [고객 보안 문제](#customer-issues)에 대한 정보를 확인해 주시기 바랍니다.

## 조정된 공개 프로그램 [#coordinated_disclosure_program]

뉴렐릭은 연구원들이 보안 취약점을 최대한 쉽게 보고할 수 있도록 기존 버그 바운티 플랫폼과 협력하고 있습니다. 이러한 문제를 찾는 데 드는 노력을 인정하여 적격한 신고에 포상금을 제공할 수 있습니다.

뉴렐릭은 공식적으로 조정된 공개 프로그램을 BugCrowd로 전환했습니다.

조정 공개 프로그램에 참여하려면:

1. 보안 테스트를 시작하기 전에 Bugcrowd Researcher 이용 약관에 동의하고 [Bugcrowd 정책을](https://bugcrowd.com/engagements/newrelic-mbb-og-public) 숙지하고 준수해야 합니다.
2. 허용된 테스트 활동에만 사용할 수 있는 뉴렐릭 계정을 만들고 해당 [서비스 약관을](https://newrelic.com/termsandconditions/terms) 준수해야 합니다.

## 취약점 보고서 &amp; CVE 영향 [#vulnerability_reports_and_cve_impact]

뉴렐릭에서 사용하는 취약점 스캐닝 도구는 오탐을 줄이는 데 도움이 되도록 당사 환경에 맞게 조정되었습니다. 이로 인해 당사의 스캐닝 도구와 다른 스캐닝 보고서에서 보고된 취약점 간에 차이가 있을 수 있습니다. 스캔 보고서 평가에 도움이 필요하신 경우, 뉴렐릭 [Support Portal \[지원 포털\]](https://support.newrelic.com/s/)을 통해 지원 케이스를 생성해 주시고 에이전트 버전, 스캔 수행 방법에 대한 자세한 설명, 사용된 스캐닝 도구, 특별한 설정 고려 사항 및 정확한 보고서 출력을 포함해 주시기 바랍니다.

고객을 안전하게 보호하는 것은 뉴렐릭의 최우선 과제입니다. 당사 에이전트에 영향을 미치는 심각한 CVE에 대한 최신 보고서를 확인하시려면 뉴렐릭의 보안 게시판을 검토하시고 [뉴렐릭의 보안 공지 커뮤니티 채널 또는 RSS 피드 구독](/docs/security/security-privacy/information-security/security-bulletins/)을 고려해 주시기 바랍니다.

## 고객 보안 문제 [#customer-issues]

뉴렐릭 고객이고 비밀번호, API 키 또는 계정 문제를 포함하여 서비스와 관련하여 보안 또는 기타 우려 사항이 있는 경우, 당사의 조정된 공개 프로그램을 사용하지 마십시오. 대신, [비밀번호, 이메일 및 로그인 문제](/docs/accounts/accounts-billing/account-setup/troubleshoot-new-relics-password-email-address-login-problems/)에 대한 당사의 표준 문제 진단, 해결 절차를 따르거나 뉴렐릭 [Support Portal \[지원 포털\]](https://support.newrelic.com/s/)을 통해 보안 지원 케이스를 생성해 주십시오.
