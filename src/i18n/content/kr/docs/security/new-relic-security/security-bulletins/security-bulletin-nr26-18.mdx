<DNT>**Priority:**</DNT> 비판적인

## 요약

PHP 런타임의 세션 확장 프로그램에서 심각한 취약점(CVSS 4.0 점수 9.2)이 발견되었습니다. PHP의 기본 파일 세션 핸들러를 사용하는 애플리케이션에 영향을 미칩니다. PHP 프로젝트는 2026년 11월 19일에 수정 사항을 발표했습니다.

CVE-2026-109618 및 CVE-2026-109619([NR26-10](/docs/security/new-relic-security/security-bulletins/security-bulletin-nr26-10))에 대한 2026년 10월 수정 릴리스에는 이 수정 사항이 포함되어 있지 않습니다. 기본 파일 핸들러 대신 데이터베이스나 레디스에 세션을 유지하는 애플리케이션은 이 취약점의 영향을 받지 않습니다.

**뉴렐릭에서 배포한 소프트웨어 및 서비스는 영향을 받지 않습니다.** 뉴렐릭은 고객에게 배포되는 어떠한 소프트웨어에도 PHP 런타임을 포함하여 제공하지 않습니다. 뉴렐릭 PHP 에이전트는 고객의 자체 PHP 환경 내에서 실행되며 취약점이 있는 구성 요소가 아닙니다. PHP 에이전트는 고객의 기존 PHP 인터프리터 내에서 확장 프로그램으로 실행되므로, PHP 자체를 업그레이드하여 문제를 해결해야 합니다. 뉴렐릭은 자사 환경에서 악용된 증거를 발견하지 못했습니다.

## 권장 조치

고객님의 뉴렐릭 소프트웨어 및 서비스와 관련하여 조치할 사항은 없습니다. 그럼에도 불구하고, 뉴렐릭은 뉴렐릭 측정, 계측 여부에 관계없이 PHP 애플리케이션을 실행하는 고객에게 해당 브랜치의 수정된 릴리스로 업그레이드하고 모든 PHP 워커를 다시 시작할 것을 강력히 권장합니다. 동일한 릴리스에서 17개의 권고 사항이 수정되므로 한 번의 업그레이드로 모두 해결됩니다.

### 권장 사항

* **배포 패키:**
  * 배포판은 PHP 버전 문자열을 변경하지 않고 수정 사항을 포함할 수 있습니다. 버전 번호에 의존하는 대신 공급업체의 보안 권고를 확인해 주십시오.
* **수명 종료 버전(PHP 8.1 및 이전 버전):**
  * 이러한 버전은 CVE 기록에 나열되어 있지 않으며 공식적인 수정 사항이 제공되지 않습니다. 패치되지 않은 빌드는 영향을 받는 것으로 간주하고, 배포판에서 수정 사항을 백포트했는지 확인하며, 지원되는 브랜치로의 업그레이드를 계획해 주십시오.
* **매니지드 호스팅:**
  * 개발, 테스트 및 미리 보기를 포함한 모든 환경에서 수정된 버전이 실행되는지 제공업체에 확인해 주십시오.

## 임시 완화 조치

PHP 런타임을 업그레이드해야만 이 취약점을 완전히 해결할 수 있습니다. 즉시 업그레이드할 수 없는 경우, 임시 조치로 해당 기능이 필요하지 않다면 관리자 권한으로 `session.upload_progress.enabled`을(를) 비활성화하고 세션에 저장되는 신뢰할 수 없는 데이터의 양을 제한해 주십시오. 업로드 진행률을 비활성화하면 해당 입력 경로가 제거되지만, 공격자가 제어하는 세션 데이터를 독립적으로 저장하는 애플리케이션은 수정되지 않습니다. 레코드를 원자적으로 대체하는 세션 스토리지 백앤드는 이러한 파일 쓰기 결함을 방지할 수 있습니다. 런타임에 대한 PHP 업데이트는 내장 파일 핸들러를 사용하는 애플리케이션에 여전히 권장되는 수정 사항입니다. 자세한 내용은 아래의 지원 문서를 참조하십시오.

## 자주 묻는 질문

1. **사용 중인 PHP 버전과 세션 설정은 어떻게 확인할 수 있습니까?**

   호스트 또는 컨테이너에서 `php -v`을(를) 실행해 주십시오. session.save\_handler 및 `phpinfo()` 또는 `php.ini`의 `session.upload_progress.enabled`을(를) 확인해 주십시오. 뉴렐릭이 인식하는 PHP 버전에 대해서는 뉴렐릭 UI에서 호스트 또는 애플리케이션 세부 정보를 확인해 주십시오.

2. **뉴렐릭 PHP 에이전트를 업데이트해야 합니까?**

   아닙니다. 취약점은 에이전트가 아니라 PHP 런타임에 있습니다. 이 취약점을 해결하려면 PHP 런타임을 수정된 버전으로 업데이트해 주시기 바랍니다.

3. **시스템이 타겟이 되었는지 어떻게 알 수 있습니까?**

   현재까지 공개된 침해 지표는 보고되지 않았습니다. 고객은 2026년 11월 19일 이후의 웹 로그를 검토하여 설명되지 않은 PHP 워커 크래시나 메모리 부족으로 인한 강제 종료가 있는지, 그리고 PHP 엔드포인트에 대한 인증되지 않은 멀티파트 POST requests가 있는지 확인해야 합니다. 또한 웹 디렉터리에서 새로 생성되거나 수정된 PHP 파일이 있는지도 확인하십시오.

4. **이 취약점에 대한 질문이나 우려 사항이 있습니다. 누구에게 연락해야 합니까?**

   고객님의 뉴렐릭 서비스와 관련된 이 취약점에 대해 질문이 있는 경우, 인앱 지원을 통해 [지원 케이스](/docs/new-relic-solutions/solve-common-issues/find-help-get-support/#file-ticket)를 열거나 뉴렐릭 계정 담당자에게 문의해 주십시오.
