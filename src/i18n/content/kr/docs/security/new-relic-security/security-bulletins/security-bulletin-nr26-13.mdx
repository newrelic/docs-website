<DNT>**Vulnerability Identifier:**</DNT> NR26-13

<DNT>**Priority:**</DNT> 높은

## 요약

2026년 10월 17일-2026년 10월 20일 사이에 연구원들은 eMudhra에서 발급한 8개의 중간 인증 기관(CA) 인증서에 대한 개인 키를 복구할 수 있다고 밝혔습니다(CVE-2026-111943). 해당 키를 가진 사람은 누구든 소프트웨어가 여전히 신뢰하는 경우 진짜로 인식할 인증서를 생성할 수 있습니다. 브라우저와 운영 시스템은 해당 인증서를 차단했지만, 일부 컨테이너 이미지를 포함하여 자체적으로 신뢰할 수 있는 CA 목록을 보유한 소프트웨어는 업데이트해야 합니다.

뉴렐릭은 더 이상 이러한 CA가 발급한 인증서를 허용하지 않도록 아래의 로그 컴포넌트를 업데이트했습니다. 업데이트된 버전은 자동으로 적용되지 않습니다. 고객은 아래 나열된 버전으로 업그레이드해야 합니다.

**FireLens 사용자 참고:** 이제 플러그인 자체에서 영향을 받는 CA가 발급한 인증서를 거부합니다. AWS(`aws-for-fluent-bit`)에서 제공하는 기본 이미지는 AWS가 다시 빌드된 이미지를 게시할 때까지 자체 CA 번들에 영향을 받는 루트 CA를 계속 나열할 수 있습니다. 사용 가능해지면 이 공지를 업데이트하겠습니다.

## 기술적 취약점 정보

[CVE-2026-111943](https://www.cve.org/CVERecord?id=CVE-2026-111943)

emSign ECC Root CA - G3에 체인으로 연결되고 교차 서명을 통해 AAA Certificate Services에 연결되는 8개의 중간 CA가 영향을 받습니다.

* 이 플러그인은 Go 1.27.3으로 빌드되었으며, 해당 TLS 라이브러리는 루트가 여전히 신뢰되더라도 영향을 받는 8개의 키가 포함된 인증서 체인을 거부합니다.
* Fluent Bit 5.1.5 기본 이미지는 CA 번들에서 영향을 받는 루트를 제거했습니다.
