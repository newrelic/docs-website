<DNT>**Vulnerability Identifier:**</DNT> NR26-15

<DNT>**Priority:**</DNT> 높은

## 요약

2026년 10월 17일-2026년 10월 20일 사이에 연구원들은 eMudhra에서 발급한 8개의 중간 인증 기관(CA) 인증서에 대한 개인 키를 복구할 수 있다고 밝혔습니다(CVE-2026-111943). 해당 키를 가진 사람은 누구든 소프트웨어가 여전히 신뢰하는 경우 진짜로 인식할 인증서를 생성할 수 있습니다. 브라우저와 운영 시스템은 해당 인증서를 차단했지만, 일부 컨테이너 이미지를 포함하여 자체적으로 신뢰할 수 있는 CA 목록을 보유한 소프트웨어는 업데이트해야 합니다.

뉴렐릭은 인프라 에이전트, 해당 컨테이너 이미지 및 아래의 온-호스트 통합이 이러한 CA에서 발급한 인증서를 더 이상 허용하지 않도록 업데이트했습니다. 업데이트된 버전은 자동으로 적용되지 않습니다. 고객은 아래 나열된 버전으로 업그레이드해야 합니다.

**\*업그레이드 참고 사항.**

* 인프라 에이전트 2.0은 메이저 버전입니다. 기본적으로 safe\_dir\_check\_enabled가 켜져 있으므로, 에이전트는 심볼릭 링크이거나, 에이전트의 사용자 또는 그룹이 소유하지 않거나, 그룹 또는 다른 사용자가 쓸 수 있는 작업 디렉터리를 더 이상 재사용하지 않습니다. 대신 디렉터리를 다시 생성합니다. 이전 동작을 유지하려면 safe\_dir\_check\_enabled를 false로 설정하십시오. 업그레이드하기 전에 릴리스 노트를 확인하십시오. 릴리스 노트는 아래 링크를 참조하십시오.
* Windows의 경우, 2.0은 인스톨러에서 구형 Fluent Bit 1.9를 제거합니다. 로그 포워딩은 Fluent Bit 5.1.5를 사용합니다.

## 기술적 취약점 정보

* emSign ECC Root CA - G3에 체인으로 연결되고 교차 서명을 통해 AAA Certificate Services에 연결되는 8개의 중간 CA가 영향을 받습니다.
* 인프라 에이전트와 온-호스트 통합은 Go 1.27.3 또는 Go 1.26.10으로 빌드되었습니다. 두 버전 모두 루트를 여전히 신뢰할 수 있더라도 영향을 받는 8개의 중간 인증서가 포함된 인증서 체인을 거부하는 `CVE-2026-111943: crypto/x509`에 대한 Go 수정 사항을 포함합니다.
* `newrelic/infrastructure` 2.0.1 및 `newrelic/infrastructure-bundle` 3.6.1 이미지는 ca-certificates 20261020-r0이 포함된 알파인 3.24.3을 기반으로 빌드되었으며, 이를 통해 CA 번들에서 emSign ECC Root CA - G3 및 AAA Certificate Services가 제거됩니다.
  * `newrelic/infrastructure-bundle` 3.6.1의 자바 트러스트 스토어는, JMX 기반 통합에서 사용되며, 두 루트 중 어느 것도 포함하지 않습니다.
* 호스트에서 에이전트와 통합은 운영 시스템의 트러스트 스토어를 사용합니다. OS 공급업체의 ca-certificates 업데이트도 적용하십시오.
* nri-jmx, nri-kafka 및 nri-cassandra는 자바 런타임에서 실행되며 자체 트러스트 스토어 또는 통합 설정에 지정된 트러스트 스토어를 사용하는 nr-jmx를 통해 JMX 메트릭을 수집합니다. 자바 공급업체의 업데이트도 적용하십시오.
* 노출은 퍼블릭 루트 저장소를 사용하는 연결로 제한됩니다: 뉴렐릭 엔드포인트 및 구성된 프록시에 대한 에이전트의 연결, 그리고 모니터하는 서비스에 대한 통합의 TLS 연결.

## 자주 묻는 질문

1. **에이전트 이미지의 CA 번들에서 영향을 받는 인증서를 제거해도 안전합니까?**

   예. 뉴렐릭 엔드포인트는 영향을 받는 CA에서 발급한 인증서를 사용하지 않으므로, 이를 제거해도 에이전트의 뉴렐릭 연결에 영향을 미치지 않습니다. 통합이 TLS를 통해 인증서 체인이 emSign ECC Root CA - G3 또는 AAA Certificate Services로 이어지는 서비스 중 하나에 연결되는 경우, 제거 후 해당 연결이 실패합니다. 해당 인증서를 먼저 확인하십시오.

2. **내 이미지에서 사용하기에 안전한 에이전트 버전은 무엇입니까?**

   인프라 에이전트 2.0.1 이상, `newrelic/infrastructure-bundle` 3.6.1 이상, 그리고 위에 나열된 온-호스트 통합 버전입니다.

3. **아직 질문이 있는 경우 누구에게 문의할 수 있습니까?**

   추가적인 도움이 필요하시면 뉴렐릭 플랫폼의 도움말 섹션을 통해 지원팀에 문의해 주세요.
