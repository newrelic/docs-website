<DNT>**Vulnerability Identifier:**</DNT> NR26-12

<DNT>**Priority:**</DNT> 높은

## 요약

2026년 10월 17일-2026년 10월 20일 사이에 연구원들은 eMudhra에서 발급한 8개의 중간 인증 기관(CA) 인증서에서 개인 키를 복구할 수 있다고 밝혔습니다. 해당 키를 가진 사람은 누구나 소프트웨어가 이를 계속 신뢰하는 경우 소프트웨어에서 진짜로 받아들일 인증서를 생성할 수 있습니다. 주요 운영 시스템과 웹 브라우저에서는 이미 이러한 인증서에 대한 신뢰를 철회했지만, 일부 컨테이너 이미지를 포함해 독립적인 CA 신뢰 저장소를 관리하는 애플리케이션은 업데이트해야 합니다.

뉴렐릭은 신세틱스 프라이빗 로케이션에 제공하는 컨테이너 이미지를 재구축하여 더 이상 이러한 인증서를 사용하지 않도록 했습니다. 이미지가 자동으로 업데이트되지 않으므로, 신세틱스 프라이빗 로케이션을 실행하는 고객은 새 이미지를 가져와서 컨테이너를 다시 시작해야 합니다.

### 중요 공지: Node.js 16.x 마이그레이션 필요(퍼블릭 및 프라이빗 로케이션) [#node-16-migration]

Node.js 16.10에서 실행되는 스크립팅된 API 모니터는 2026년 11월 18일에 [수명이 종료](/eol/2026/05/eol-05-18-26-node-16-chrome-134-runtimes/) 됩니다. 이 모니터는 eMudhra 취약점에 노출되어 있으며, 여전히 이러한 이전 버전에서 실행 중인 모니터는 Node.js 22.23.0으로 마이그레이션해야 합니다. 이는 모니터가 Public \[퍼블릭] 또는 Private locations \[프라이빗 로케이션]에서 실행되는지 여부에 관계없이 적용됩니다.

**권장 조치:** 2026년 11월 18일부터 뉴렐릭은 여전히 Node.js 16.x에서 실행 중인 공개 위치 모니터를 현재 런타임으로 자동 업그레이드합니다. 모니터가 새로운 런타임에서 의도한 대로 계속 작동하는지 테스트하고 취약한 버전에서 벗어날 수 있도록 해당 날짜 이전인 가능한 한 빨리 마이그레이션할 것을 강력히 권장합니다. 지침은 [스크립팅된 API 모니터를 Node.js 22로 업그레이드](/docs/synthetics/synthetic-monitoring/scripting-monitors/synthetics-scripted-api-monitors-to-node-22/)를 참조하십시오.

## 기술적 취약점 정보

이 문제에 할당된 CVE가 없습니다.

## 자주 묻는 질문

1. **뉴렐릭의 공개 위치 인프라가 영향을 받았습니까?**

   뉴렐릭은 최신 런타임에서 실행되는 공개 위치 인프라를 패치했습니다. 그러나 Node.js 16.x에 명시적으로 고정된 모니터는 계정 소유자가 업데이트할 때까지 해당 버전에서 계속 실행됩니다.

2. **모니터 결과가 변조되었습니까?**

   뉴렐릭은 당사의 신세틱 이미지가 변조되었다는 증거가 없습니다.

3. **신세틱스 secure credentials \[보안 자격 증명]에 저장된 자격 증명을 교체해야 합니까?**

   네트워크 및 인프라가 손상되었다고 판단할 만한 특별한 이유가 없는 한 조치가 필요하지 않습니다.

4. **여전히 궁금한 점이 있는 경우 누구에게 문의할 수 있습니까?**

   뉴렐릭 플랫폼의 도움말 섹션을 통해 당사 지원 팀에 케이스를 오픈해 주십시오.

## 출판 이력

2026년 10월 17일-2026년 10월 20일에 eMudhra 중간 CA 인증서 손상이 공개되었습니다.
