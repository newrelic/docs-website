<DNT>**Vulnerability Identifier:**</DNT> NR26-11

<DNT>**Priority:**</DNT> 높은

## 요약

퍼블릭 및 프라이빗 로케이션을 사용하는 뉴렐릭 신세틱 모니터링 고객의 조치가 필요할 수 있는 [Node.js](https://nodejs.org/) 버전(22.x, 24.x, 26.x)의 심각한 보안 취약점을 알려드리기 위해 본 공지를 발행합니다.

**수정된 버전:** 수정된 Node.js 버전은 22.23.4, 24.22.1 및 26.12.1입니다.

**수명 종료(EOL) 버전:** Node.js 16.x를 포함한 Node.js 20 및 그 이전 버전은 수명이 종료되었으며 Node.js 프로젝트에서 패치를 받지 못합니다. Node.js EOL 버전에 대한 유일한 해결 방법은 지원되는 릴리스로 마이그레이션하는 것입니다.

## 조치 필요

이 취약점은 퍼블릭 및 프라이빗 로케이션을 모두 사용하는 신세틱 모니터링 고객에게 영향을 미칩니다. 각각에 대한 고객 조치는 다음과 같습니다.

### 퍼블릭(공공) 위치

고객의 조치는 모니터가 최신 런타임에 있는지 여부에 따라 달라집니다.

1. **조치 불필요:** 최신 지원 런타임에 있는 공개 위치에 배포된 모니터의 경우 조치가 필요하지 않습니다.

### 개인 위치

**조치 필요:** 프라이빗 로케이션의 경우, 이러한 CVE를 해결하려면 최신 런타임 이미지를 가져와야 합니다. `latest` 태그를 사용하지 않는 경우 프라이빗 로케이션에 배포된 모니터에 대한 조치가 필요합니다.

`node-api-runtime` 및 `node-browser-runtime` 컨테이너 이미지는 Node.js를 번들로 제공하며 이 취약점의 직접적인 영향을 받습니다. 보안 스캐너가 신세틱스 작업 관리자(SJM) 및 ping-runtime 이미지 내에서 CVE를 탐지할 수 있지만, 이러한 런타임은 악용될 수 없습니다. 이를 제거하기 위해 이러한 CVE는 SJM v642 및 ping-runtime 1.87.0의 다음 릴리스에서 해결될 예정입니다.

프라이빗 로케이션을 실행 중인 경우 다음 단계를 수행하십시오.

1. 영향을 받는 런타임 이미지의 최신 버전을 가져옵니다:

   ```shell
   # Node API runtime
   docker pull newrelic/synthetics-node-api-runtime:latest

   # Node browser runtime
   docker pull newrelic/synthetics-node-browser-runtime:latest
   ```

2. 수정 사항을 적용하려면 업데이트된 이미지를 가져온 후 컨테이너를 다시 시작하십시오.

자세한 내용은 [런타임 전환 가이드](/docs/synthetics/synthetic-monitoring/private-locations/runtime-transition-guide/)를 참조하십시오.

### 중요 공지: Node.js 16.x 스크립트 API 모니터

Node.js 16.x에서 실행되도록 구성된 스크립트 API 모니터가 있는 경우 다음 사항에 유의하십시오:

* Node.js 16.x는 이미 [수명 종료](/eol/2026/05/eol-05-18-26-node-16-chrome-134-runtimes/)에 도달했기 때문에 Node.js 프로젝트로부터 이러한 CVE에 대한 보안 패치를 받지 못합니다.
* 뉴렐릭은 스크립트 호환성을 보장할 수 없기 때문에 Node.js 16.x 모니터를 Node 22.x로 자동으로 강제 업그레이드하지 않았습니다. 일부 모니터 스크립트가 Node 22.x에서 올바르게 실행되려면 코드 변경이 필요할 수 있습니다.

2026년 11월 18일까지 기다리지 마시고, 가능한 한 빨리 Node 16.x 모니터를 검토하여 Node 22.23.4로 마이그레이션하실 것을 강력히 권장합니다. 자세한 마이그레이션 지침은 [스크립트화된 API 모니터를 Node.js 22로 업그레이드](/docs/synthetics/synthetic-monitoring/scripting-monitors/synthetics-scripted-api-monitors-to-node-22/)를 참조하십시오.

## 자주 묻는 질문

1. **신세틱스 작업 관리자(SJM) 및 ping-runtime을 업데이트해야 합니까?**

   조치를 위한 즉각적인 업데이트는 필요하지 않습니다. 취약점 스캐너가 SJM 및 ping-runtime에서 CVE를 탐지할 수 있지만, 이러한 구성 요소는 악용될 위험이 없습니다. 그러나 예정된 릴리스(SJM v642 및 ping-runtime 1.87.0)에서 이 CVE를 해결할 예정입니다. 무결점 규정 준수 보고서를 유지하려면 이러한 릴리스로 업데이트하는 것이 좋습니다.

2. **런타임 이미지를 업데이트하면 실행 중인 모니터에 영향을 미칩니까?**

   런타임 이미지 업데이트 후에도 모니터는 계속 정상적으로 실행됩니다. Node 22.x에서 실행되는 모니터에는 동작 변경 사항이 없습니다.

3. **CVE-2026-111497은 원격으로 악용될 수 있습니까?**

   예. 이것은 원격 코드 실행 취약점입니다. 공격자가 제어하는 서버에서 Node.js 프로세스가 Brotli로 압축된 HTTP 응답을 받을 때 트리거될 수 있습니다. 로컬 액세스는 필요하지 않습니다.

4. **Node 16.x 모니터를 실행 중입니다. 위험에 노출되어 있습니까?**

   네. Node 16.x는 수명 주기가 종료되어 패치되지 않습니다. Node 22.23.4로 마이그레이션할 때까지 모니터는 취약한 상태로 유지됩니다. 런타임 업그레이드 도구를 사용하여 직접 이 작업을 수행할 수 있습니다. 자세한 내용은 [모니터 런타임 관리](/docs/synthetics/synthetic-monitoring/using-monitors/manage-monitor-runtimes/)를 참조하십시오.

5. **제 Node 16.x 모니터가 자동으로 업그레이드되지 않은 이유는 무엇입니까?**

   Node 22.x에는 Node 16.x의 주요 변경 사항이 포함되어 있으며, 이는 뉴렐릭이 [이전에 안내한 바 있습니다](/eol/2026/05/eol-05-18-26-node-16-chrome-134-runtimes/). 여전히 Node 16.x에 있는 스크립팅된 API 모니터는 오류 없이 자동으로 업그레이드할 수 없는 모니터입니다. 따라서 뉴렐릭은 의도하지 않은 모니터 손상을 방지하기 위해 이를 고객이 시작하는 업그레이드로 만들었습니다. 당사는 [이전에 안내한](/eol/2026/05/eol-05-18-26-node-16-chrome-134-runtimes/) 수명 종료(EOL) 일정을 따를 것이며, 2026년 11월 18일에 Node 16.x 모니터를 강제 업그레이드할 예정입니다.

6. **프라이빗 로케이션 런타임을 업데이트한 후 재부팅하거나 다시 시작해야 하는 항목이 있습니까?**

   컨테이너 재시작만 필요합니다. 호스트 재부팅은 필요하지 않습니다.

7. **여전히 궁금한 점이 있는 경우 누구에게 문의할 수 있습니까?**

   뉴렐릭 플랫폼의 도움말 섹션을 통해 당사 지원 팀에 케이스를 오픈해 주십시오.
