Node.js 애플리케이션 모니터링을 시작하려면 뉴렐릭 Node.js 에이전트를 설치합니다. 왼쪽 내비게이션에서 환경에 맞는 방법을 선택합니다.

설치를 완료하려면 [뉴렐릭 계정](https://newrelic.com/signup)과 <InlinePopover type="licenseKey" />이(가) 필요합니다. 시작하기 전에 [Node.js 에이전트 호환성 및 요구 사항](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent)을 확인하십시오.

| 메서드                                                                                                                              | 사용하는 경우                                             |
| -------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| [표준(npm)](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent)                                         | 대부분의 Node.js 앱은 npm을 통해 설치하고 다음으로 로드: `-r newrelic` |
| [Docker](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent-docker)                                   | 컨테이너화된 Node.js 애플리케이션                               |
| [Azure App Service(Windows)](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent-azure-site-extension) | 뉴렐릭 사이트 확장을 사용하여 Windows용 Azure App Service에 배포된 앱  |
