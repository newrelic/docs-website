## 교차 애플리케이션 추적(지원 중단됨) [#cross-app-tracing]

[교차 애플리케이션 추적](/docs/apm/transactions/cross-application-traces/introduction-cross-application-traces) 을 제어하는 Node.js 에이전트 변수는 일반적으로 앱 `newrelic.js` 구성 파일의 `cross_application_tracer` 섹션에 나타납니다.

<Callout variant="important">
잡아당겨 [추적](/docs/enable-distributed-tracing) 기능은 더 이상 사용되지 않으며 향후 요원 버전에서 제거될 예정입니다.
</Callout>

## 분산 추적 [#dt-main]

[분산 추적을 사용하면](/docs/intro-distributed-tracing) 요청이 분산 시스템을 통해 이동하는 경로를 확인할 수 있습니다. 구성 파일을 통해 구성하는 경우 `distributed_tracing` 섹션에 다음 옵션을 배치하세요. Node.js 에이전트 8.3.0 이상에서는 기본적으로 켜져 있습니다.

<Callout variant="important">
분산 추적을 활성화하면 [교차 애플리케이션 추적](#cross-app-tracing) 이 비활성화되고 다른 APM 기능에 영향을 미칩니다. 활성화하기 전에 [전환 가이드](/docs/transition-guide-distributed-tracing) 를 읽으십시오. [Node.js 에이전트 버전 4.7.0 이상이](/docs/agents/nodejs-agent/installation-configuration/upgrade-nodejs-agent) 필요합니다.
</Callout>

분산 추적 설정에 대한 자세한 내용은 [Node.js 애플리케이션에 대한 분산 추적 활성화 를](/docs/apm/agents/nodejs-agent/installation-configuration/distributed-tracing-nodejs-agent) 참조하십시오.

원격 상위 항목이 없는 루트 스팬-트랜잭션(수신되는 `traceparent` 또는 `newrelic` 분산 추적 헤더가 없음)에 대한 샘플링 결정 방식을 제어합니다. 유효한 값은 다음과 같습니다:

* `adaptive` (기본값): 내장된 뉴렐릭의 적응형 샘플링 알고리즘을 사용합니다.
* `always_on`: 모든 스팬을 샘플링합니다.
* `always_off`: 스팬을 샘플링하지 않습니다.
* `trace_id_ratio_based`: 트레이스 ID에 의해 결정된 일정 비율의 트레이스를 샘플링합니다.

예를 들어 구성 파일에서 이를 설정하려면 다음을 사용합니다.

```js
distributed_tracing: {
  enabled: true,
  sampler: {
    root: 'always_on'
  }
}
```

`trace_id_ratio_based`로 설정된 경우 `ratio` (`0` 에서 `1` 사이의 숫자)도 제공해야 합니다.

```js
distributed_tracing: {
  enabled: true,
  sampler: {
    root: {
      trace_id_ratio_based: {
        ratio: 0.5
      }
    }
  }
}
```

또는 환경 변수를 통해:

```ini
NEW_RELIC_DISTRIBUTED_TRACING_SAMPLER_ROOT=trace_id_ratio_based
NEW_RELIC_DISTRIBUTED_TRACING_SAMPLER_ROOT_TRACE_ID_RATIO_BASED_RATIO=0.5
```

이 값을 `adaptive`로 설정하면, 선택적으로 이 샘플러에 대해서만 샘플링 타깃(분당 1-120개 트랜잭션)을 재정의할 수 있습니다:

```js
distributed_tracing: {
  enabled: true,
  sampler: {
    root: {
      adaptive: {
        sampling_target: 50
      }
    }
  }
}
```

또는 환경 변수를 통해:

```ini
NEW_RELIC_DISTRIBUTED_TRACING_SAMPLER_ROOT=adaptive
NEW_RELIC_DISTRIBUTED_TRACING_SAMPLER_ROOT_ADAPTIVE_SAMPLING_TARGET=50
```
</Collapser>

traceparent 헤더에 샘플링 플래그 `01`이 있는 경우, 이를 통해 스팬 샘플링을 처리하는 방법을 제어할 수 있습니다. 허용되는 문자열 값은 다음과 같습니다:

* `adaptive` (기본값): 내장된 뉴렐릭의 적응형 샘플링 알고리즘을 사용합니다.
* `always_on`: 모든 스팬을 샘플링합니다.
* `always_off`: 스팬을 샘플링하지 않습니다.
* `trace_id_ratio_based`: 트레이스 ID에 의해 결정된 일정 비율의 트레이스를 샘플링합니다.

두 설정이 모두 적용될 수 있는 경우 이 설정이 [`remote_parent_not_sampled`](#dt-sampler-remote-parent-not-sampled)보다 우선합니다.

예를 들어 구성 파일에서 이를 활성화하려면 다음을 사용합니다.

```js
distributed_tracing: {
  enabled: true,
  sampler: {
    remote_parent_sampled: 'always_on'
  }
}
```

이 값을 `trace_id_ratio_based`로 설정하는 경우, `0`-`1`의 `ratio` 값을 제공해야 합니다. 이 값을 `adaptive`로 설정하면, 선택적으로 이 샘플러에 대해서만 샘플링 타깃을 재정의할 수 있습니다. 동일한 구문에 대해서는, [`sampler.root`](#dt-sampler-root) 아래의 객체 형식 및 환경 변수 예시를 참조하고 `root`를 `remote_parent_sampled` 로 대체합니다.
</Collapser>
