<Steps>
<Step>
## 에이전트 설치 [#install]

애플리케이션 디렉터리에 에이전트 패키지를 설치합니다:

```bash
npm install newrelic
```

<Callout variant="important">
Next.js를 사용하는 경우, [Next.js 하이브리드 에이전트 측정 가이드](/docs/apm/agents/nodejs-agent/extend-your-instrumentation/nextjs-instrumentation/)를 참조하십시오.
</Callout>

그런 다음 패키지의 기본 설정 파일을 애플리케이션의 루트로 복사합니다:

```bash
cp node_modules/newrelic/newrelic.js .
```
</Step>

<Step>
## 에이전트 구성 [#configure]

애플리케이션의 루트에서 `newrelic.js`를 엽니다. 라이브 환경으로 전환하기 전에 **반드시** 변경해야 하는 두 가지 설정은 다음과 같습니다:

1. `license_key`를 <InlinePopover type="licenseKey" />(으)로 설정합니다.
2. `app_name`을 애플리케이션에 적합한 이름으로 설정합니다.

```js
exports.config = {
  app_name: ['Your Application Name'],
  license_key: 'YOUR_LICENSE_KEY',
  // ...
}
```

파일을 수정하지 않고 대신 환경 변수를 통해 이를 설정할 수도 있습니다:

```bash
NEW_RELIC_APP_NAME="Your Application Name"
NEW_RELIC_LICENSE_KEY="YOUR_LICENSE_KEY"
```
</Step>

<Step>
## 에이전트 시작하기 [#start]

시작 명령에 `-r newrelic`을 추가하여 다른 `require` 문보다 먼저 에이전트를 로드합니다:

```bash
node -r newrelic ./your-app.js
```

애플리케이션이 ESM을 사용하는 경우 `--import newrelic/esm-loader.mjs` 옵션을 추가합니다:

```bash
node --import newrelic/esm-loader.mjs -r newrelic ./your-app.js
```

Next.js 앱의 경우 `NODE_OPTIONS='-r newrelic' next start`를 통해 에이전트를 로드합니다.

Nest.js 및 `nest start` 명령을 사용하여 애플리케이션을 시작하는 경우 시작 바이너리를 수정하여 뉴렐릭 에이전트: `nest start --exec 'node -r newrelic'`을 로드합니다. [다음은 Nest.js 애플리케이션의 예입니다](https://github.com/newrelic/newrelic-node-examples/tree/main/nestjs).
</Step>

<Step>
## 데이터 전송 여부 확인 [#verify]

에이전트 버전이 14.9.0 이상인 경우 다음 명령을 실행하여 설정을 확인할 수 있습니다:

```bash
npx newrelic validate-config --config-file ./newrelic.js
```

1. 애플리케이션에 최소 두 개의 requests를 보냅니다.

2. 2-3분 정도 기다린 후 [one.newrelic.com &gt; APM](https://one.newrelic.com/apm)을 열고 이름으로 앱을 찾습니다.

<Callout variant="tip">
앱이 표시되지 않나요? [Node.js 설치 문제 해결](/docs/apm/agents/nodejs-agent/troubleshooting/troubleshooting-your-nodejs-installation)을 참조하십시오.
</Callout>
</Step>
