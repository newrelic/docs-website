Node.js 에이전트를 사용하여 docker 컨테이너에서 Node.js 기능 구현, 배포할 수 있습니다. 이 문서에서는 뉴렐릭으로 제공한 Dockerized Node.js를 빌드, 구성, 구현, 배포하는 방법을 설명합니다.

Node.js 에이전트 설치에 대한 일반적인 도움이 필요한 경우 [기본 설치 지침을](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent) 참조하세요.

## 컨테이너 계측 [#instrument]

<Callout variant="caution">
  Dockerfile 또는 Docker 이미지에 라이선스 키를 포함하지 마세요. 자세한 내용 [은 라이선스 키 보안에 대한 설명서를](/docs/accounts/install-new-relic/account-setup/license-key#license-key-security) 참조하십시오.
</Callout>

몇 가지 설정을 변경하고 기존 Dockerfile에 뉴렐릭 환경 변수를 추가하면 Node.js 에이전트를 사용하여 Docker화된 앱을 로그아웃할 수 있습니다.

1. `package.json` 에 `newrelic` 추가:

   ```json
   npm install newrelic --save
   ```

2. 애플리케이션을 계측하려면 `node` 시작 명령에 에이전트를 주입하십시오.

<CollapserGroup>
  <Collapser id="docker-cjs" title="CommonJS를 사용하는 앱">
    Node.js 애플리케이션을 실행하는 방법에 따라 에이전트를 주입하는 방법이 다를 수 있습니다.

    * `ENTRYPOINT`

      ```bash
      ENTRYPOINT ["node", "-r", "newrelic", "YOUR_PROGRAM.js"]
      ```

    * `CMD`

      ```bash
      CMD ["node", "-r", "newrelic", "YOUR_PROGRAM.js"]
      ```

    * 다음과 같은 npm 스크립트 `npm start`

      ```bash
      npm pkg set scripts.start="node -r newrelic your-program.js"
      ```
  </Collapser>

  <Collapser id="docker-esm" title="ESM을 사용하는 앱">
    Node.js 애플리케이션을 실행하는 방법에 따라 에이전트를 주입하는 방법이 다를 수 있습니다.

    * `ENTRYPOINT`

      ```bash
      ENTRYPOINT ["node", "--import", "newrelic/esm-loader.mjs", "-r", "newrelic", "YOUR_PROGRAM.js"]
      ```

    * `CMD`

      ```bash
      CMD ["node", "--import", "newrelic/esm-loader.mjs", "-r", "newrelic", "YOUR_PROGRAM.js"]
      ```

    * 다음과 같은 npm 스크립트 `npm start`

      ```bash
      npm pkg set scripts.start="node --import newrelic/esm-loader.mjs -r newrelic your-program.js"
      ```
  </Collapser>
</CollapserGroup>

3. 평소와 같이 Docker 이미지를 빌드합니다.

4. 에이전트가 활성화된 상태로 docker 앱을 실행하려면 <InlinePopover type="licenseKey" />및 [앱 이름을](/docs/agents/manage-apm-agents/app-naming/name-your-application) 환경 변수로 `docker run` 명령에 추가하세요.

   ```bash
   docker run -e NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
           -e NEW_RELIC_APP_NAME="YOUR_APP_NAME" \
           YOUR_IMAGE_NAME:latest
   ```

<InstallFeedback />

## 기타 구성 옵션 [#configure]

애플리케이션 이름이나 라이선스 키를 설정하는 것 외에도 `-e` 옵션으로 컨테이너를 시작하여 [다른 설정 옵션](/docs/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration)을 설정할 수 있습니다.
