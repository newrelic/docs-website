<Step>
## 애플리케이션에 에이전트를 추가합니다. [#install]

`package.json` 에 `newrelic` 추가:

```json
"newrelic": "latest"
```

그런 다음 에이전트를 로드하도록 Dockerfile 또는 시작 명령을 업데이트하십시오. 이를 수행하는 방법은 앱이 CommonJS를 사용하는지 또는 ESM을 사용하는지에 따라 다릅니다:

<CollapserGroup>
<Collapser id="docker-cjs" title="CommonJS를 사용하는 앱">
* `ENTRYPOINT`

  ```bash
  ENTRYPOINT ["node", "-r", "newrelic", "YOUR_PROGRAM.js"]
  ```

* `CMD`

  ```bash
  CMD ["node", "-r", "newrelic", "YOUR_PROGRAM.js"]
  ```

* 다음과 같은 npm 스크립트 `npm start`

  ```bash
  npm pkg set scripts.start="node -r newrelic your-program.js"
  ```
</Collapser>

<Collapser id="docker-esm" title="ESM을 사용하는 앱">
* `ENTRYPOINT`

  ```bash
  ENTRYPOINT ["node", "--import", "newrelic/esm-loader.mjs", "-r", "newrelic", "YOUR_PROGRAM.js"]
  ```

* `CMD`

  ```bash
  CMD ["node", "--import", "newrelic/esm-loader.mjs", "-r", "newrelic", "YOUR_PROGRAM.js"]
  ```

* 다음과 같은 npm 스크립트 `npm start`

  ```bash
  npm pkg set scripts.start="node --import newrelic/esm-loader.mjs -r newrelic your-program.js"
  ```
</Collapser>
</CollapserGroup>

<Callout variant="important">
`-r` 플래그를 사용할 수 없는 경우, 앱의 기본 모듈의 **첫 번째 줄**에 `require('newrelic')`을(를) 추가하십시오. Babel 또는 기타 트랜스파일러와 함께 이 방식을 사용하지 마십시오. 계측 문제가 발생합니다.
</Callout>
</Step>

<Step>
## 에이전트 구성 [#configure]

컨테이너를 실행할 때 앱 이름과 라이선스 키를 환경 변수로 전달하십시오. 다음 항목만 필수 설정입니다:

```bash
docker run -e NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
           -e NEW_RELIC_APP_NAME="Your Application Name" \
           YOUR_IMAGE_NAME:latest
```

또한 Dockerfile의 `ENV` 지시문을 통해 설정을 지정할 수도 있습니다:

```dockerfile
ENV NEW_RELIC_APP_NAME="Your Application Name"
```

기타 모든 설정 옵션에 대해서는 [Node.js 에이전트 설정](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration)을 참조하십시오.
</Step>

<Step>
## 데이터가 흐르고 있는지 확인 [#verify]

컨테이너를 빌드하고 실행한 다음 애플리케이션에 최소 2개의 requests를 전송하십시오. 2～3분 기다린 후 [one.newrelic.com &gt; APM](https://one.newrelic.com/apm)을 열어 이름으로 앱을 검색하십시오.

<Callout variant="tip">
앱이 표시되지 않습니까? [Node.js 설치 문제 진단, 해결](/docs/apm/agents/nodejs-agent/troubleshooting/troubleshooting-your-nodejs-installation)을 참조하십시오.
</Callout>
</Step>
