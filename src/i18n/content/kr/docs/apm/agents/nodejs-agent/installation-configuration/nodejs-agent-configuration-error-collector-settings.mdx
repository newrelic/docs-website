이 페이지에서는 무시하거나 예상된 것으로 표시할 HTTP 상태 코드 및 오류 클래스, 분당 샘플링할 오류 이벤트 수를 포함하여 오류 수집을 위한 Node.js 에이전트 설정에 대해 설명합니다.

<Callout variant="tip">
전체 설정 인덱스로 돌아가기: [Node.js 에이전트 설정](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration)

## 오류 수집기 변수 [#error_config]

New Relic에서 [오류 처리 방법을 관리할](/docs/agents/manage-apm-agents/agent-data/manage-errors-apm-collect-ignore-mark-expected) 수 있습니다. 이 섹션에서는 앱 `newrelic.js` 구성 파일의 `error_collector: {` 섹션에 일반적으로 나타나는 순서대로 Node.js 에이전트 변수를 정의합니다.

수집기가 무시할 오류 메시지와 관련된 클래스 목록을 설명하는 JavaScript 개체입니다. 다음 설정은 `Undefined` 및 `Out of time` 의 정확한(대소문자 구분) 메시지 문자열을 포함하는 `Error` 유형의 모든 오류를 무시합니다.

```js
error_collector: {
  /* ... */
  ignore_messages: {"Error":["Undefined", "Out of time"]}
}
```

`Undefined` 및 `Out of time` 의 정확한(대소문자 구분) 메시지 문자열을 사용하여 `Error` 유형의 모든 오류를 무시합니다.

<Callout variant="caution">
[`newrelic.noticeError()`](https://newrelic.github.io/node-newrelic/API.html#noticeError)를 사용하여 기록된 오류는 이 설정 값을 따르지 않습니다.
</Callout>
</Collapser>
