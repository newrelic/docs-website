이 페이지에서는 LLM 텔레메트리, 스트리밍 및 콘텐츠 기록을 포함한 AI 모니터링을 위한 Node.js 에이전트 설정을 다룹니다.

<Callout variant="tip">
전체 설정 인덱스로 돌아가기: [Node.js 에이전트 설정](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration)
</Callout>

## AI 모니터링 [#ai-monitoring]

LLM 계측은 기본적으로 활성화되어 있습니다. 에이전트는 메시지 콘텐츠 없이 `Llm*` 커스텀 대시보드, 스팬 및 메트릭을 전송합니다.

옵트아웃하려면 다음 중 하나를 `false`(으)로 설정하십시오:

* `ai_monitoring.basic_telemetry.enabled` in `newrelic.js`
* `NEW_RELIC_AI_MONITORING_BASIC_TELEMETRY_ENABLED` 환경 변수
* `ai_monitoring.enabled` `newrelic.js`에서(더 이상 사용되지 않지만 여전히 작동함)
* `NEW_RELIC_AI_MONITORING_ENABLED` 환경 변수(더 이상 사용되지 않지만 여전히 작동함)

<Callout variant="important">
AI 데이터를 캡처하려면 [분산 추적을](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration/#dt-main) 활성화해야 합니다. Node.js 에이전트 8.3.0 이상에서는 기본적으로 켜져 있습니다. 높은 보안 모드를 활성화한 경우 AI 모니터링이 작동하지 않습니다.
</Callout>

<Callout variant="important">
AI 모니터링을 활성화하면, 모니터링하기로 선택한 모델에서 송수신하는 입력 및 출력의 스트리밍 사본이 기록되며, 여기에는 여기에 포함된 모든 개인 정보가 포함됩니다. AI 모니터링을 사용할 때, AI 모니터링 기능을 제공할 목적으로 제3자(뉴렐릭)가 해당 모델의 복합체 합성을 기록할 수 있다는 점에 대해 모델 사용자의 동의를 얻을 책임은 귀하에게 있습니다.
</Callout>
