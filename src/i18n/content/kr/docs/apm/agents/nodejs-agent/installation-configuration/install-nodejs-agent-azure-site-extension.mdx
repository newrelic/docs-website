뉴렐릭 Azure 사이트 확장 프로그램을 사용하여 Windows용 Azure App Service에 뉴렐릭 Node.js 에이전트를 설치합니다.

<Callout variant="important">
이 방법은 코드로만 배포된 **Windows 기반** Azure App Service 앱을 위한 것입니다. Azure의 Linux 컨테이너의 경우 표준 [npm 설치 방법](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent)을 사용하고 `NEW_RELIC_LICENSE_KEY`를 앱 설정으로 전달합니다. 수동으로 배포된 Linux 기반 애플리케이션의 경우 [Microsoft Azure App Services의 Node.js 에이전트](/docs/apm/agents/nodejs-agent/hosting-services/nodejs-agent-microsoft-azure)를 참조하십시오.

Windows 32에서 실행되는 애플리케이션의 경우, 전체 코드 레벨 메트릭 지원(파일 경로, 줄, 열)을 사용할 수 없으며 프로파일링은 함수 이름으로만 대체됩니다.
</Callout>

<Steps>
<Step>
## 사이트 확장 프로그램 설치 [#install]

1. Azure 홈 페이지에서 **App Services**\[앱 서비스]를 클릭하고 타깃 애플리케이션을 선택합니다.
2. 왼쪽 메뉴의 **Development Tools**\[개발 도구]에서 **Extensions**\[확장]을 선택합니다.
3. 페이지 상단의 **+ Add**\[+ 추가]를 클릭한 다음, 드롭다운 메뉴에서 **New Relic Node Agent**\[뉴렐릭 Node 에이전트]를 선택합니다.
4. 법적 약관에 동의하고 **OK**\[확인]을 클릭합니다.

설치가 완료되면 확장 프로그램은 다음을 생성합니다:

* 에이전트 파일 및 종속성: `C:\home\site\wwwroot\node_modules`
* 애플리케이션 시작 시 자동으로 `NODE_OPTIONS=-r newrelic`을 주입하는 XDT 변환(`applicationHost.xdt`)
</Step>

<Step>
## 에이전트 구성 [#configure]

애플리케이션의 왼쪽 메뉴에서 **Settings &gt; Environment variables**\[설정 &gt; 환경 변수]로 이동하여 다음을 추가합니다:

| Setting                 | 가치          |
| ----------------------- | ----------- |
| `NEW_RELIC_LICENSE_KEY` | 뉴렐릭 라이선스 키  |
| `NEW_RELIC_APP_NAME`    | 뉴렐릭에 표시될 이름 |

확장 프로그램은 자동으로 `NODE_OPTIONS`를 `-r newrelic`으로 설정합니다. 이전에 정의된 `NODE_OPTIONS`는 재설정됩니다. 기타 모든 설정 옵션은 [Node.js 에이전트 설정](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration)을 참조하십시오.
</Step>

<Step>
## 데이터 전송 여부 확인 [#verify]

애플리케이션을 시작하고 최소 두 개의 requests를 보냅니다. 2-3분 정도 기다린 후 [one.newrelic.com &gt; APM](https://one.newrelic.com/apm)을 열고 이름으로 앱을 검색합니다.

확장 프로그램이 설치되지 않으면 로그를 확인하십시오:

```
C:\home\SiteExtensions\NewRelic.Azure.Websites.Extension.NodeAgent\install.log
```

에이전트가 설치되었지만 데이터가 표시되지 않는 경우 다음을 확인하십시오:

```
C:\home\site\wwwroot\newrelic_agent.log
```

<Callout variant="tip">
앱이 표시되지 않나요? [Node.js 설치 문제 해결](/docs/apm/agents/nodejs-agent/troubleshooting/troubleshooting-your-nodejs-installation)을 참조하십시오.
</Callout>
</Step>
</Steps>
