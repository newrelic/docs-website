뉴렐릭의 Node.js 모니터링을 통해 코드 라인 수준까지 문제를 정확히 파악하고 해결하십시오. [서비스 맵](/docs/data-analysis/service-maps/get-started/introduction-service-maps), [에러스 인박스(errors inbox)](/docs/triage-inbox/errors-inbox), [컨텍스트 내 로그](/docs/apm/new-relic-apm/getting-started/get-started-logs-context) 등과 같은 기능을 통해 당사의 Node.js 에이전트는 앱 환경의 전체적인 상황을 파악할 수 있도록 지원합니다.

## 중요한 이유 [#why]

많은 Node.js 애플리케이션 요청은 원시 URL을 기반으로 합니다. 우리의 솔루션은 다릅니다. New Relic for Node.js는 애플리케이션에 대한 요청을 HTTP 요청 대신 트랜잭션으로 그룹화할 수 있다고 가정합니다. 트랜잭션은 하나 이상의 요청 경로에 이름을 지정하여 정의됩니다. 이러한 이름은 다음 용도로 사용됩니다.

* 앱이 시간을 소비하는 위치를 시각화합니다(트랜잭션 분석에서).
* 느린 요청을 식별합니다.
* 그룹 메트릭.
* 애플리케이션의 어느 부분이 느린 데이터베이스 성능으로 고통받고 있는지 보여주십시오.

## 설치 [#install]

* [시스템 요구 사항](/docs/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent) 을 검토합니다.
* Sign up for a [New Relic account](https://newrelic.com/signup).
* Read the [install docs](/docs/agents/nodejs-agent/installation-configuration/install-nodejs-agent).
* 뉴렐릭 UI 로 바로 가서 [Node.js 데이터를 추가하세요](https://one.newrelic.com/marketplace/install-data-source?account=1&state=587d34b2-20cc-4d04-b1fa-6b76dfbae911).

## APM 및 인프라 데이터에 대한 로그 보기 [#logs-context]

You can also bring your logs and application&apos;s data together to make troubleshooting easier and faster. With [APM logs in context](/docs/logs/logs-context/get-started-logs-context), you can see log messages related to your errors and traces directly in your app&apos;s UI. You can also see logs in context of your [infrastructure data](/docs/logs/forward-logs/forward-your-logs-using-infrastructure-agent/), such as Kubernetes clusters. No need to switch to another UI page in New Relic.

## 설치 문제 해결 [#troubleshooting]

Node.js 에이전트에 문제가 발생하면 문제 해결 문서를 참조하세요. 해당 섹션에서 가장 중요한 문제 해결 문서는 다음과 같습니다.

* [대용량 메모리 사용량](/docs/agents/nodejs-agent/troubleshooting/troubleshooting-large-memory-usage-nodejs) : Node.js 에이전트를 설치하고 메모리 사용량이 증가한 경우 가능한 해결 방법을 확인하세요.
* [Node.js 설치 문제 해결](/docs/agents/nodejs-agent/troubleshooting/troubleshooting-your-nodejs-installation) : 데이터가 표시되지 않거나 파일을 기록할 수 없거나 Node.js 에이전트에 다른 설치 문제가 발생한 경우 다음 단계를 시도하십시오.
* [브라우저 계측 문제 해결](/docs/agents/nodejs-agent/troubleshooting/troubleshooting-page-load-timing-nodejs) : 브라우저 데이터에 문제가 발생하면 Node.js에 대한 다음 추가 팁을 참조하세요.

도움이 더 필요하면 [support.newrelic.com](https://support.newrelic.com) 에서 지원을 받으십시오.

## 소스 코드 확인 [#source-code]

Node.js 에이전트는 오픈 소스 소프트웨어입니다. [소스 코드를 탐색하고](https://github.com/newrelic/node-newrelic) 개선 사항을 보내거나 자신의 포크를 만들어 빌드할 수 있습니다. 자세한 내용 [은 GitHub의 node-newrelic README를](https://github.com/newrelic/node-newrelic/blob/main/README.md) 참조하십시오.
