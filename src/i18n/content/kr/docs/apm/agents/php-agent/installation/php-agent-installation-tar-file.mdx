지원되는 프로세서의 모든 지원 운영 시스템에 압축된 tar 파일을 통해 뉴렐릭의 PHP 에이전트를 설치할 수 있습니다. 그러나 x86\_64 기반 RedHat 또는 CentOS의 경우 [RPM 패키지를](/docs/agents/php-agent/installation/php-agent-installation-aws-linux-redhat-centos/) 사용하는 것이 더 일반적입니다. x86\_64의 Ubuntu 또는 Debian의 경우 [Debian 패키지를](/docs/agents/php-agent/installation/php-agent-installation-ubuntu-debian) 사용하는 것이 더 일반적입니다.

## tar 배포판 다운로드 [#download]

다른 설치 옵션과 달리 tar 아카이브는 특별한 저장소 설정이 필요하지 않습니다. 아카이브를 다운로드하고 이 지침을 따르기만 하면 됩니다.

<DNT>**[download.newrelic.com/php\_agent/release/](https://download.newrelic.com/php_agent/release/)**</DNT> 에서 적절한 tar 배포 파일을 다운로드합니다.

* GNU libc를 사용하는 Linux(대부분의 Linux 배포판)의 경우 `newrelic-php5-X.X.X.X-linux.tar.gz` 다운로드하세요.
* musl libc가 있는 Linux(Alpine Linux)의 경우 `newrelic-php5-X.X.X.X-linux-musl.tar.gz`(를) 다운로드하세요.

<Callout variant="tip">
PHP 에이전트의 패키지 이름은 `newrelic-php5` 입니다. 패키지 이름은 PHP 5를 참조하지만 이 패키지는 [지원되는 모든 PHP 버전](/docs/agents/php-agent/getting-started/php-agent-compatibility-requirements#php-release) 에서 작동합니다.
</Callout>

## 설치 또는 업데이트 [#install]

tar 파일을 설치하는 경우 처음 설치하는 단계와 업데이트하는 단계는 동일합니다. XXXX를 올바른 New Relic 버전으로 바꾸십시오. 에이전트를 설치하거나 업데이트하려면:

1. [New Relic 웹사이트](https://download.newrelic.com/php_agent/release/) 에서 적절한 tar 파일을 다운로드하고 편리한 위치의 로컬 디스크에 저장합니다. `/tmp` 폴더를 사용하지 마십시오.

2. 아카이브 압축을 풀고 압축을 풉니다.

   ```bash
   gzip -dc newrelic-php5-X.X.X.X-OS.tar.gz | tar xf -
   ```

3. 새로 생성된 디렉토리로 변경:

   ```bash
   cd newrelic-php5-X.X.X.X-OS
   ```

4. 설치 스크립트를 실행합니다.

   ```bash
   ./newrelic-install
   ```

5. 기본 [응용 프로그램 이름](/docs/site/naming-your-application) 을 의미 있는 이름으로 변경합니다.

6. 웹 서버(Apache, Nginx, PHP-FPM 등)를 다시 시작합니다.

7. 애플리케이션에서 데이터를 보낼 때까지 몇 분 정도 기다린 다음 [UI에서 앱의 성능을 확인합니다](/docs/apm/applications-menu/monitoring/apm-overview-page) .

## tar 파일을 확인하십시오. [#verify]

PHP 에이전트 버전 12.13.0.43부터 서명 키의 지문과 tar 파일의 SHA-256 해시를 사용하여 다운로드 사이트의 각 tar 파일을 확인할 수 있습니다. 두 가지 모두 PHP 에이전트의 GitHub 저장소에 있는 [`release-data` 디렉터리](https://github.com/newrelic/newrelic-php-agent/tree/main/release-data)에 게시됩니다.

tar 파일을 확인하려면:

1. tar 파일, 해당 `.asc` 파일(동일한 폴더에 위치하며 tar 파일 이름에 `.asc`을(를) 추가한 이름) 및 공개 키를 다운로드하십시오. 이 명령은 공개 키의 URL과 해당 지문을 출력합니다:

   ```bash
   curl -s https://raw.githubusercontent.com/newrelic/newrelic-php-agent/main/release-data/signing-key-fingerprints.json | jq -r '.keys[] | select(.purpose == "tarball" and .status == "active") | .public_key_url, (.fingerprint | [scan(".{4}")] | join(" "))'
   ```

2. 키 파일의 지문을 표시하고 1단계의 지문과 비교하십시오. 일치하면 키를 가져오십시오:

   ```bash
   gpg --show-keys --with-fingerprint NEWRELIC_TARBALL_XXXXXXXX.public
   gpg --import NEWRELIC_TARBALL_XXXXXXXX.public
   ```

3. 서명을 확인하십시오:

   ```bash
   gpg --verify newrelic-php5-X.X.X.X-OS.tar.gz.asc newrelic-php5-X.X.X.X-OS.tar.gz
   ```

   출력은 `Good signature`이라고 표시되어야 하며, 해당 `Primary key fingerprint` 줄은 1단계의 핑거프린트와 일치해야 합니다. 또한 `gpg`은(는) 키가 신뢰할 수 있는 서명으로 인증되지 않았다는 경고를 출력합니다. 이는 예상된 동작입니다.

4. tar 파일의 SHA-256 해시를 `tarball-hashes.json`에 명시된 해시와 비교하십시오. 두 해시는 동일해야 합니다:

   ```bash
   sha256sum newrelic-php5-X.X.X.X-OS.tar.gz
   curl -s https://raw.githubusercontent.com/newrelic/newrelic-php-agent/main/release-data/tarball-hashes.json | jq -r '.releases[].files[] | select(.filename == "newrelic-php5-X.X.X.X-OS.tar.gz") | .sha256'
   ```
