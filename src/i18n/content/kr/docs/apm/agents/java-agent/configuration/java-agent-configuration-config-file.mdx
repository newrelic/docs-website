뉴렐릭 Java 에이전트는 `newrelic.yml` 파일에서 구성을 읽습니다. 기본적으로 에이전트는 `newrelic.jar`가 포함된 [디렉토리](/docs/agents/manage-apm-agents/troubleshooting/find-agent-root-directory#java-agent)에서 이 파일을 찾습니다. [`newrelic.config.file`](#newrelic-config-file) 시스템 속성을 정규화된 파일 이름으로 설정하여 구성 파일의 위치를 재정의할 수 있습니다.

[뉴렐릭 계정을 생성하고](https://newrelic.com/signup)(영구 무료), [Java 에이전트를 설치하면](/docs/apm/agents/java-agent/installation/install-java-agent/) 사용 환경에 맞게 Java 에이전트를 구성할 수 있습니다.

## 구성 파일 구조 [#Structure]

`newrelic.yml` 파일에는 다양한 환경별로 섹션이 마련되어 있습니다.

* 테스트
* 개발
* 스테이징
* 프로덕션(기본값)

뉴렐릭은 이러한 각 환경에 `common` 섹션에 나와 있는 설정을 적용합니다. [`newrelic.environment`](#newrelic-environment) 시스템 속성을 환경 이름으로 설정함으로써 다른 환경을 기본값으로 선택할 수 있습니다.

<Callout variant="tip">
  [`newrelic.yml` 템플릿](/docs/java/java-agent-config-file-template)을 사용할 수 있습니다.
</Callout>

`newrelic.yml`을 편집하는 경우, [YAML 형식](https://en.wikipedia.org/wiki/YAML)을 준수하도록 주의하십시오. 뉴렐릭의 Java 에이전트와 함께 파일을 사용하기 전에 YAML 유효성 검사기를 사용하여 구문이 정확한지 확인하고 다음 규칙을 따릅니다.

## 구성 설정 우선순위 [#config-options-precedence]

구성 파일의 설정을 재정의하려면 [시스템 속성 재정의](#System_Properties)를 사용합니다. 특정 환경에서는 [환경 변수](#Environment_Variables)를 사용하여 구성 파일과 시스템 속성을 모두 재정의할 수도 있습니다. 환경 변수는 주로 Heroku를 지원하기 위해 존재합니다. 사용하면 [서버 측 구성](/docs/agents/manage-apm-agents/configuration/server-side-agent-configuration)이 다른 모든 구성 설정보다 우선 적용됩니다.

<img title="java-config-order.png" alt="java-config-order.png" src="/images/apm_diagram_Java-config-precedence.webp" />

<figcaption>
  Java 에이전트를 사용하면 서버 측 구성이 다른 모든 설정을 재정의합니다. 환경 변수는 Java 시스템 속성을 재정의합니다. 자바 속성은 `newrelic.yml` 파일의 사용자 구성 설정을 재정의합니다. 사용자 설정은 `newrelic.yml` 기본 설정보다 우선합니다.

## Java 확장 디렉터리 구성 [#extensions-directory]

Java 에이전트는 프로세스 시작 시 구성 파일을 읽습니다. 파일이 있는 디렉터리를 식별하려면 새 디렉터리를 생성하거나 기존 확장 디렉터리를 지정하십시오.

<CollapserGroup>
  <Collapser id="create-extensions-directory" title="확장 디렉터리 생성">
    확장 디렉터리를 생성하려면:

    1. `newrelic.jar` 및 `newrelic.yml`이 있는 디렉터리로 이동합니다. 이름이 `extensions`인 디렉터리를 만듭니다.
    2. `newrelic.yml`에서 [`extensions.dir`](#cfg-extensions-dir) 속성이 설정되지 않았는지 확인합니다.
  </Collapser>

  <Collapser id="specify-extensions-directory" title="기존 확장 디렉터리 지정">
    기존 Java 확장 디렉터리를 사용하려면:

    1. `newrelic.yml` 파일에서 `common` 섹션을 찾습니다.
    2. [`extensions.dir`](#cfg-extensions-dir) 속성을 사용하여 파일 위치를 지정합니다.
  </Collapser>
</CollapserGroup>
