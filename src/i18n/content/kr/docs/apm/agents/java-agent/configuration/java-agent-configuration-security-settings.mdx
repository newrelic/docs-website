보안 설정은 취약점 탐지 및 실시간 애플리케이션 보안 모니터링(IAST)을 위해 뉴렐릭 보안 에이전트를 구성합니다.

<Callout variant="tip">
  전체 설정 인덱스로 돌아가기: [자바 에이전트 설정](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file)
</Callout>

## 보안 에이전트 [#sec-agent]

[뉴렐릭의 보안 에이전트인 인터랙티브 애플리케이션 보안 테스트](/docs/iast/introduction/)(IAST)는 생성된 HTTP 요청을 취약한 페이로드와 함께 재생하여 악용 가능한 취약점이 있는지 애플리케이션을 테스트합니다.

<Callout variant="important">
  프로덕션 소프트웨어에 취약성이 노출되지 않도록 하려면 비프로덕션 배포에서만 IAST를 실행하십시오.
</Callout>

`security` 섹션에서 뉴렐릭 Security 에이전트를 설정할 수 있습니다. 이러한 설정은 `newrelic.config.security` 접두어가 붙은 시스템 속성으로 [재정의](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file#System_Properties) 할 수 있습니다. 옵션은 다음과 같습니다:

  뉴렐릭 보안 에이전트 IAST(Interactive Applications Security Testing) 모드는 [Java 에이전트 버전 8.4.0 이상](/docs/agents/java-agent/installation/upgrade-java-agent)이 필요합니다.
</Callout>
