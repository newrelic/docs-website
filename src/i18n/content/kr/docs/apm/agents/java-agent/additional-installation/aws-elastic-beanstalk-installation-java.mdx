이 페이지에서는 애플리케이션 번들에 에이전트를 추가하고 Elastic Beanstalk 콘솔을 통해 `-javaagent` JVM 인수를 구성하여 AWS Elastic Beanstalk에 뉴렐릭 자바 에이전트를 설치하는 방법을 다룹니다.

## 호환성 및 요구 사항 [#requirements]

### 지원

* 자바 8, 11, 17, 21, 24, 25 및 26 *(자바 7은 에이전트 v6.5.4 및 이전 버전에서만 지원됩니다.)*
* Elastic Beanstalk Tomcat 플랫폼
* Elastic Beanstalk 자바 SE 플랫폼
* 지원되는 프레임워크 및 라이브러리 버전 범위는 [호환성 및 요구 사항](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent)을 참조하십시오.

### 지원되지 않음

* Elastic Beanstalk의 도커 컨테이너 ― 대신 [도커 설치 방법](/docs/apm/agents/java-agent/additional-installation/install-new-relic-java-agent-docker)을 사용하십시오.
* 다른 APM 에이전트와 함께 실행 — 동일한 JVM에서 다른 APM 에이전트가 활성화되어 있으면 자바 에이전트의 올바른 동작을 보장할 수 없습니다.

### 필요한 사항

* 뉴렐릭 계정 및<InlinePopover type="licenseKey" />
* SHA-2(256비트) SSL을 지원하는 JVM
* Elastic Beanstalk에 자바 앱이 배포된 [AWS 계정](http://aws.amazon.com/elasticbeanstalk/)

## 설치 [#install]

`newrelic-java.zip`을(를) 다운로드하고 `newrelic.jar` 및 `newrelic.yml`을(를) 추출합니다: \[#install-step-1]

```bash
curl -O https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip
unzip newrelic-java.zip
```

## 구성 [#configure]

`newrelic.yml`을(를) 편집하고 두 가지 필수 값을 설정하십시오:

1. <InlinePopover type="licenseKey" />에 `license_key`을(를) 설정합니다.
2. `app_name`을(를) 애플리케이션의 의미 있는 이름으로 설정해 주십시오.

**Tomcat 플랫폼 전용** ― Elastic Beanstalk 콘솔을 통해 `-javaagent` 플래그를 전달하십시오:

1. Elastic Beanstalk 콘솔을 열고 환경을 선택합니다.

2. 왼쪽 창에서 **구성** 을 선택합니다.

3. **Updates, monitoring, and logging** \[업데이트, 모니터링 및 로깅]으로 스크롤하고 **Edit** \[편집]을 클릭하십시오.

4. **Platform Software** \[플랫폼 소프트웨어] 아래에서 **JVM Options** \[JVM 옵션] 필드에 다음을 추가합니다:

   ```
   -javaagent:/full/path/to/newrelic.jar
   ```

   EC2 인스턴스에서 `newrelic.jar`의 경로를 찾으려면 인스턴스에 연결하고 다음을 실행하십시오:

   ```bash
   sudo find /var -name "newrelic.jar"
   sudo find /usr -name "newrelic.jar"
   ```

5. **Apply** \[적용을] 클릭하세요.

다른 모든 설정 옵션은 [자바 에이전트 설정](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file)을 참조하십시오.

## 설치 확인 [#verify]

Elastic Beanstalk가 환경을 업데이트합니다. 최소 2개의 requests를 보낸 후 2～3분 정도 기다리면 [APM &amp; services](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29)에 앱이 표시됩니다.

5분 후에도 데이터가 나타나지 않으면 [데이터가 나타나지 않음(자바)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java)을 참조하십시오.
