이 페이지에서는 Maven을 사용하여 뉴렐릭 자바 에이전트를 설치하는 방법을 다룹니다. Maven은 `newrelic-java.zip`을(를) 빌드 종속성으로 다운로드하고 압축을 해제하여 에이전트 파일을 빌드 디렉터리에 자동으로 배치합니다.

## 호환성 및 요구 사항 [#requirements]

### 지원

* 자바 8, 11, 17, 21, 24, 25 및 26 *(자바 7은 에이전트 v6.5.4 및 이전 버전에서만 지원됩니다.)*
* Maven 3.x
* `maven-dependency-plugin` 3.1.1 이상
* `-javaagent` 인수를 허용하는 지원되는 모든 앱 서버 또는 독립 실행형 JVM 프로세스
* 지원되는 프레임워크 및 라이브러리 버전 범위는 [호환성 및 요구 사항](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent)을 참조하십시오.

### 지원되지 않음

* 다른 APM 에이전트와 함께 실행 — 동일한 JVM에서 다른 APM 에이전트가 활성화되어 있으면 자바 에이전트의 올바른 동작을 보장할 수 없습니다.

### 필요한 사항

* 뉴렐릭 계정 및<InlinePopover type="licenseKey" />
* SHA-2(256비트) SSL을 지원하는 JVM
* 다음을 포함하는 Maven 프로젝트 `pom.xml`

## 설치 [#install]

<Steps>
  <Step>
    ### 다운로드하도록 Maven을 구성하십시오. `newrelic-java.zip` [#install-step-1]

    `pom.xml`에 자바 에이전트를 `provided` 종속성으로 추가하십시오. `JAVA_AGENT_VERSION`를 [최신 자바 에이전트 버전](/docs/release-notes/agent-release-notes/java-release-notes/current)으로 교체하십시오:

    ```xml
    <dependency>
        <groupId>com.newrelic.agent.java</groupId>
        <artifactId>newrelic-java</artifactId>
        <version>JAVA_AGENT_VERSION</version>
        <scope>provided</scope>
        <type>zip</type>
    </dependency>
    ```
  </Step>

  <Step>
    ### 에이전트 압축을 해제하도록 Maven 구성 [#install-step-2]

    빌드 디렉터리에 에이전트 zip의 압축을 풀려면 `pom.xml`의 `<build><plugins>` 섹션에 `maven-dependency-plugin`을(를) 추가하십시오:

    ```xml
    <plugin>
        <groupId>org.apache.maven.plugins</groupId>
        <artifactId>maven-dependency-plugin</artifactId>
        <version>3.1.1</version>
        <executions>
            <execution>
                <id>unpack-newrelic</id>
                <phase>package</phase>
                <goals>
                    <goal>unpack-dependencies</goal>
                </goals>
                <configuration>
                    <includeGroupIds>com.newrelic.agent.java</includeGroupIds>
                    <includeArtifactIds>newrelic-java</includeArtifactIds>
                    <overWriteReleases>false</overWriteReleases>
                    <overWriteSnapshots>false</overWriteSnapshots>
                    <overWriteIfNewer>true</overWriteIfNewer>
                    <outputDirectory>${project.build.directory}</outputDirectory>
                </configuration>
            </execution>
        </executions>
    </plugin>
    ```

    `mvn package`을(를) 실행한 후, `target/`에 다음 항목이 포함된 `newrelic/` 폴더가 나타납니다:

    * `newrelic.jar` — 자바 에이전트
    * `newrelic.yml` — 에이전트 설정 파일
    * `newrelic-api.jar` — 자바 에이전트 API jar
    * `README`

    <CollapserGroup>
      <Collapser id="full-pom-example" title="전체 pom.xml 예제">
        ```xml
        <project xmlns="http://maven.apache.org/POM/4.0.0"
            xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
            xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/maven-v4_0_0.xsd">
            <modelVersion>4.0.0</modelVersion>
            <groupId>com.example.application</groupId>
            <artifactId>my-example-app</artifactId>
            <packaging>war</packaging>
            <version>1.0</version>
            <name>My Example Application</name>
            <dependencies>
                <dependency>
                    <groupId>com.newrelic.agent.java</groupId>
                    <artifactId>newrelic-java</artifactId>
                    <version>JAVA_AGENT_VERSION</version>
                    <scope>provided</scope>
                    <type>zip</type>
                </dependency>
            </dependencies>
            <build>
                <finalName>my-example-app</finalName>
                <plugins>
                    <plugin>
                        <groupId>org.apache.maven.plugins</groupId>
                        <artifactId>maven-war-plugin</artifactId>
                        <version>3.2.2</version>
                        <configuration>
                            <failOnMissingWebXml>false</failOnMissingWebXml>
                        </configuration>
                    </plugin>
                    <plugin>
                        <groupId>org.apache.maven.plugins</groupId>
                        <artifactId>maven-dependency-plugin</artifactId>
                        <version>3.1.1</version>
                        <executions>
                            <execution>
                                <id>unpack-newrelic</id>
                                <phase>package</phase>
                                <goals>
                                    <goal>unpack-dependencies</goal>
                                </goals>
                                <configuration>
                                    <includeGroupIds>com.newrelic.agent.java</includeGroupIds>
                                    <includeArtifactIds>newrelic-java</includeArtifactIds>
                                    <overWriteReleases>false</overWriteReleases>
                                    <overWriteSnapshots>false</overWriteSnapshots>
                                    <overWriteIfNewer>true</overWriteIfNewer>
                                    <outputDirectory>${project.build.directory}</outputDirectory>
                                </configuration>
                            </execution>
                        </executions>
                    </plugin>
                </plugins>
            </build>
        </project>
        ```
      </Collapser>
    </CollapserGroup>
  </Step>

  <Step>
    ### 전달하십시오 `-javaagent` [#install-step-3]

    애플리케이션을 시작할 때 `newrelic.jar`을(를) 가리키는 `-javaagent` JVM 인수를 추가합니다. 정확한 방법은 앱 서버에 따라 다릅니다 — 서버별 지침은 [서버에 대한 JVM 인수 전달](/docs/apm/agents/java-agent/installation/java-agent-installation-app-servers#install-step-3)을 참조하십시오.

    예를 들어 Spring Boot jar의 경우 다음과 같습니다:

    ```bash
    java -javaagent:/path/to/target/newrelic/newrelic.jar -jar my-example-app.jar
    ```
  </Step>
</Steps>

## 구성 [#configure]

`target/newrelic/newrelic.yml`을(를) 편집하고 두 가지 필수 값을 설정하십시오:

```yaml
license_key: 'YOUR_LICENSE_KEY'
app_name: 'My Application'
```

에이전트는 시작 시 `newrelic.jar`과(와) 동일한 디렉터리에서 `newrelic.yml`을(를) 읽습니다. 또한 자바 시스템 속성을 사용하여 모든 설정을 재정의할 수 있습니다(예: `-Dnewrelic.config.license_key=YOUR_KEY`) 또는 환경 변수를 사용할 수도 있습니다.

사용 가능한 모든 옵션은 [자바 에이전트 설정](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file)을 참조하십시오.

## 설치 확인 [#verify]

애플리케이션을 다시 시작합니다. 최소 2개의 requests를 보낸 다음 2～3분 기다리면 [APM &amp; 서비스](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29)에 앱이 표시됩니다.

5분 후에도 데이터가 나타나지 않으면 [데이터가 나타나지 않음(자바)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java)을 참조하십시오.
