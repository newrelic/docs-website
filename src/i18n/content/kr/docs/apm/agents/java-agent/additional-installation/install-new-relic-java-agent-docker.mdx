이 페이지는 이미지에 에이전트 jar를 추가하고 시작 시 `-javaagent` JVM 인수를 전달하여 도커 컨테이너에 뉴렐릭 자바 에이전트를 설치하는 방법을 다룹니다.

## 호환성 및 요구 사항 [#requirements]

### 지원

* 자바 8, 11, 17, 21, 24, 25 및 26 *(자바 7은 에이전트 v6.5.4 및 이전 버전에서만 지원됩니다.)*
* `-javaagent` JVM 인수를 허용하는 자바 애플리케이션(Tomcat, Spring Boot 등)을 실행하는 모든 도커 이미지
* 지원되는 프레임워크 및 라이브러리 버전 범위는 [호환성 및 요구 사항](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent)을 참조하십시오.

### 지원되지 않음

* 다른 APM 에이전트와 함께 실행 — 동일한 JVM에서 다른 APM 에이전트가 활성화되어 있으면 자바 에이전트의 올바른 동작을 보장할 수 없습니다.

### 필요한 사항

* 뉴렐릭 계정 및<InlinePopover type="licenseKey" />
* SHA-2(256비트) SSL을 지원하는 JVM
* 자바 애플리케이션 컨테이너와 함께 설치된 도커

## 설치 [#install]

`newrelic-java.zip` 다운로드: \[#install-step-1]

```bash
curl -O https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip
unzip newrelic-java.zip
```

`Dockerfile`에 에이전트 jar를 추가합니다. 아래 예제는 Tomcat을 사용합니다 — 앱 서버에 맞게 경로를 조정하십시오:

```dockerfile
RUN mkdir -p /usr/local/tomcat/newrelic
ADD ./newrelic/newrelic.jar /usr/local/tomcat/newrelic/newrelic.jar
ENV JAVA_OPTS="$JAVA_OPTS -javaagent:/usr/local/tomcat/newrelic/newrelic.jar"
```

평소와 같이 도커 이미지를 빌드합니다.

## 구성 [#configure]

컨테이너를 실행할 때 앱 이름과 라이선스 키를 환경 변수로 전달하십시오:

```bash
docker run -e NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
           -e NEW_RELIC_APP_NAME="Your Application Name" \
           YOUR_IMAGE_NAME:latest
```

`Dockerfile`에서 `ENV` 지시문을 사용할 수도 있습니다:

```dockerfile
ENV NEW_RELIC_APP_NAME="Your Application Name"
```

다른 모든 설정 옵션은 [자바 에이전트 설정](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file)을 참조하십시오.

## 설치 확인 [#verify]

컨테이너를 실행하고 애플리케이션에 최소 두 개의 requests를 보내십시오. 2～3분 정도 기다리시면 [APM &amp; services](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29)에 앱이 나타납니다.

5분 후에도 데이터가 나타나지 않으면 [데이터가 나타나지 않음(자바)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java)을 참조하십시오.
