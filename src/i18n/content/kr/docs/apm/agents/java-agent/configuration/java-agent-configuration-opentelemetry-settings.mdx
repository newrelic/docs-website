OpenTelemetry 설정은 OpenTelemetry 계측과의 에이전트 통합 및 OTLP 데이터 내보내기를 구성합니다.

  전체 설정 인덱스로 돌아가기: [자바 에이전트 설정](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file)
</Callout>

## 오픈 텔레메트리 [#opentelemetry]

자바 에이전트 버전 `9.1.0`부터는 OpenTelemetry Tracing, 메트릭 및 로그 API 호환성이 추가되어, 뉴렐릭의 심층적인 가시성과 OpenTelemetry 신호의 이점을 두루 활용할 수 있습니다.

이 기능을 사용하면, 뉴렐릭 자바 에이전트 API와 OpenTelemetry Tracing, 메트릭 및 로그 API를 결합하여 애플리케이션을 바로 원하는 대로 계측할 수 있습니다. 자바 에이전트는 이 모든 것을 익숙한 APM 환경으로 결합해줍니다. 또한 OpenTelemetry 네이티브를 지원하는 라이브러리나 독립 실행형 라이브러리를 사용하여 애플리케이션에 대해 더 나은 가시성을 확보할 수 있습니다.

다음은 어떤 OpenTelemetry 신호를 포착해 뉴렐릭 APM 환경에 통합할지 결정하는 설정 옵션입니다.

```yml
  opentelemetry:
    enabled: false
    logs:
      enabled: true
    metrics:
      enabled: true
      include: "MeterName1,MeterName2"
      exclude: "MeterName3,MeterName4"
    traces:
      enabled: true
      include: "TracerName1,TracerName2"
      exclude: "TracerName3,TracerName4"
```

    개별 OpenTelemetry 신호를 활성화하려면 true로 설정하고, 모든 OpenTelemetry 신호를 비활성화하려면 false로 설정합니다. 기본값은 false입니다.

    시스템 속성을 통해 설정할 수 있습니다.

    ```ini
    -Dnewrelic.config.opentelemetry.enabled=false
    ```

    환경 변수를 통해 설정 가능:

    ```ini
    NEW_RELIC_OPENTELEMETRY_ENABLED
    ```
