AI 모니터링 설정은 에이전트가 대규모 언어 모델(LLM) 호출을 계측하고 AI 응답 데이터를 캡처하는 방식을 제어합니다.

<Callout variant="tip">
전체 설정 인덱스로 돌아가기: [자바 에이전트 설정](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file)
</Callout>

## AI 모니터링 [#ai-monitoring]

이 섹션에서는 [AI 모니터링](/docs/ai-monitoring/intro-to-ai-monitoring)을 위한 Java 에이전트 설정 옵션에 대해 자세히 설명합니다. 이 기능은 `newrelic.config.ai_monitoring.` 접두사가 붙은 시스템 속성 또는 `NEW_RELIC_AI_MONITORING_` 접두사가 붙은 환경 변수를 사용하여 `ai_monitoring` yaml 구성 파일 스탠자에서 설정할 수 있습니다.

<Callout variant="important">
분산 추적이 비활성화되었거나 높은 보안 모드가 활성화된 경우 AI 모니터링은 AI 데이터를 수집하지 않습니다.
</Callout>

<Callout variant="important">
AI 모니터링을 활성화하면 모니터링하기로 선택한 모델에서 송수신하는 입력 및 출력의 스트리밍 사본이 기록되며, 여기에는 여기에 포함된 모든 개인 정보도 포함됩니다. AI 모니터링 기능을 제공할 목적으로 제3자(뉴렐릭)가 자신의 모델 사용자의 복합체 합성을 기록할 수 있다는 점에 대해 모델 사용자의 동의를 얻을 책임은 귀하에게 있습니다.
</Callout>
