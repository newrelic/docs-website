뉴렐릭 Java 에이전트는 Java 애플리케이션을 자동으로 계측하여 애플리케이션 코드를 변경하지 않고도 트랜잭션, 오류 및 JVM 성능에 대한 가시성을 제공합니다. 설치가 완료되면 몇 분 안에 뉴렐릭 플랫폼에서 앱의 응답 시간, 처리량, 오류율 및 JVM 상태를 확인할 수 있습니다. Java 에이전트를 사용하여 성능의 병목 지점을 찾고, 컨텍스트 내에서 오류를 진단하며, 실제 트래픽에서 애플리케이션이 어떻게 작동하는지 파악할 수 있습니다.

## 기능 [#capabilities]

* **메트릭** — 애플리케이션 및 트랜잭션별 응답 시간, 처리량, 오류율, Apdex 점수, JVM 메트릭(힙, 가비지 컬렉션, 스레드 수)
* **이벤트** — NRQL을 통해 쿼리할 수 있는 트랜잭션 이벤트, 오류 이벤트, 커스텀 대시보드
* **로그** — [문맥적 로그](/docs/logs/logs-context/java-configure-logs-context-all/)를 통해 트레이스 및 오류와 상관관계가 있는 애플리케이션 로그 데이터
* **트레이스** — 서비스 전반의 요청을 연결하는 분산 트레이스, 트랜잭션 트레이스 및 느린 쿼리에 대한 SQL 실행 계획
* **엔터티** — 애플리케이션은 뉴렐릭에서 서비스 엔터티로 표시되며, APM &amp; 서비스 및 엔티티 탐색기에서 조회 가능

## 설치 경로 선택 [#choose]

* **앱 서버 및 독립 실행형 JVM**(권장) — Tomcat, Spring Boot, JBoss/WildFly, Glassfish, Jetty, WebLogic, WebSphere, `-javaagent` 인수를 허용하는 모든 JVM을 위한 표준 경로
* **Maven** — 빌드에서 이미 Maven을 사용하는 경우에 사용하며, 에이전트는 다음을 통해 빌드 종속성으로 다운로드되고 압축이 풀립니다: `maven-dependency-plugin`
* **Gradle** — 빌드에서 이미 Gradle을 사용하는 경우에 사용하며, `de.undercouch.download` 기반의 다운로드 작업이 에이전트를 자동으로 가져와서 압축을 풉니다.
* **Azure App Service(Windows)** — Java 앱이 Azure Windows App Service에서 실행되는 경우에 사용합니다. 뉴렐릭 사이트 확장은 시작 스크립트를 수정하지 않고 에이전트를 주입합니다
* **Docker** — 컨테이너화된 Java 애플리케이션에 사용하며, 다음을 통해 `-javaagent`를 전달합니다: `JAVA_TOOL_OPTIONS`
* **AWS Elastic Beanstalk** — Elastic Beanstalk에 배포된 Tomcat 또는 Java SE 앱에 사용합니다.
* **Google App Engine** — 사용자 지정 docker 런타임을 통해 GAE 가변 환경에서 실행되는 앱에 사용합니다.
* **AWS Lambda** — 표준 에이전트와 다른 설치 경로를 사용합니다. [서버리스 기능 모니터링](/docs/serverless-function-monitoring/aws-lambda-monitoring/enable-lambda-monitoring/enable-serverless-monitoring-aws-lambda-legacy#java)을 참조하십시오.
