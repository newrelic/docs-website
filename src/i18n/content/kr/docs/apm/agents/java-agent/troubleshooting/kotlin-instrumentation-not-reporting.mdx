## 문제

코틀린 앱에서 계측이 누락된 경우, [에이전트 로그를 가장 상세한 수준으로 설정](/docs/agents/java-agent/troubleshooting/generating-logs-troubleshooting-java)해 주십시오.

로그에는 `ArrayIndexOutOfBoundsException`이(가) 언급되어야 합니다. 에이전트 버전 8.2.0 이상을 사용하는 고객에게는 다음 메시지가 표시됩니다:

```
Unexpected ArrayIndexOutOfBoundsException thrown during class transformation. Try restarting the Java Agent with flag -Dnewrelic.config.class_transformer.clear_return_stacks=true
```

## 해결책

자바 에이전트 버전이 8.20 이상인지 확인해 주십시오. 설치된 버전이 8.20 이전인 경우, 자바 에이전트를 지원되는 버전으로 업그레이드해 주십시오(최신 버전 권장).

다음 시스템 속성을 사용하여 자바 에이전트 또는 자바 앱을 다시 시작해 주십시오:

```
-Dnewrelic.config.class_transformer.clear_return_stacks=true
```
