이 페이지는 뉴렐릭 자바 에이전트 사이트 확장을 사용하여 Windows용 Azure App Service에 뉴렐릭 자바 에이전트를 설치하는 방법을 다룹니다. 이 확장은 앱의 시작 스크립트를 수정하지 않고도 에이전트를 자동으로 주입합니다.

## 호환성 및 요구 사항 [#requirements]

### 지원

* Azure Windows App Service에서 실행되는 자바 애플리케이션
* 자바 8 이상과 호환되는 뉴렐릭 자바 에이전트 버전 *(자바 7은 에이전트 v6.5.4 이하에서만 지원됨)*
* 지원되는 프레임워크 및 라이브러리 버전 범위는 [호환성 및 요구 사항](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent)을 참조하십시오.

### 지원되지 않음

* Azure의 Linux 컨테이너 — [도커 설치 방법](/docs/apm/agents/java-agent/additional-installation/install-new-relic-java-agent-docker)을 사용하고 다음을 통해 `-javaagent`을(를) 전달하십시오. `JAVA_TOOL_OPTIONS`
* 다른 APM 에이전트와 함께 실행 — 동일한 JVM에서 다른 APM 에이전트가 활성화되어 있으면 자바 에이전트의 올바른 동작을 보장할 수 없습니다.

### 필요한 사항

* 뉴렐릭 계정 및<InlinePopover type="licenseKey" />
* SHA-2(256비트) SSL을 지원하는 JVM
* Azure Windows App Service에서 실행되는 자바 애플리케이션
* 부분적인 계측을 방지하려면 확장을 설치하기 전에 타겟 애플리케이션을 중지해야 합니다.

## 설치 [#install]

<Steps>
<Step>
### 사이트 확장 프로그램을 설치하십시오. [#install-step-1]

1. Azure 홈 페이지에서 **App Services**를 선택한 다음, 타겟 애플리케이션을 선택합니다.
2. 왼쪽 메뉴에서 **Development Tools**로 스크롤하여 **Extensions**를 선택하십시오.
3. 확장 프로그램 드롭다운 메뉴를 열려면 페이지 상단의 **+ Add**를 선택하십시오.
4. **New Relic Java Agent** \[뉴렐릭 자바 에이전트]를 선택하십시오.
5. 법적 약관에 동의하고 **OK**를 선택하여 설치를 시작하십시오.

설치가 완료되면 확장은 다음을 생성합니다:

* `C:\home\NewRelic\JavaAgent\newrelic\`에 있는 **에이전트 파일** (jar, 구성, 소스)
* 애플리케이션 시작 시 `JAVA_TOOL_OPTIONS` 환경 변수를 자동으로 주입하는 **XDT 변환** (`applicationHost.xdt`)

*확장 프로그램이 설치되지 않으면 `C:\home\SiteExtensions\NewRelic.Azure.WebSites.Extension.JavaAgent\install.log`에서 로그를 확인하십시오.*
</Step>

<Step>
### 에이전트 구성 [#install-step-2]

1. 애플리케이션의 왼쪽 메뉴에서 **Settings &gt; Configuration**으로 이동합니다.
2. 다음 애플리케이션 설정을 추가합니다:

| 환경                      | 값                |
| ----------------------- | ---------------- |
| `NEW_RELIC_LICENSE_KEY` | 귀하의 뉴렐릭 클러스터     |
| `NEW_RELIC_APP_NAME`    | 뉴렐릭 플랫폼에 표시되는 이름 |

또한 [추가 설정](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file/#Environment_Variables)을 앱 설정으로 추가하여 에이전트를 추가로 사용자 지정할 수 있습니다.
</Step>
</Steps>

## 설치 확인 [#verify]

애플리케이션을 시작하십시오. 최소 두 개의 requests를 보낸 후 2～3분 정도 기다리면 [APM &amp; services](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29)에 앱이 나타납니다.

5분 후에도 데이터가 나타나지 않으면 [데이터가 나타나지 않음(자바)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java)을 참조하십시오.
