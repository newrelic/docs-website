<Callout variant="tip">
전체 설정 인덱스로 돌아가기: [자바 에이전트 설정](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file)
</Callout>

## 속성 [#attributes]

이러한 옵션을 설정하려면 `attributes` 섹션을 사용하십시오. 이를 [재정의](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file#System_Properties) 하려면 `newrelic.config.attributes` 접두사가 붙은 시스템 속성을 사용하십시오.

속성은 트랜잭션 트레이스, 트레이스 오류, <InlinePopover type="browser" />및 트랜잭션 이벤트와 관련된 핵심 가치 쌍입니다. 각 대상 아래에는 `attribute` 섹션이 있습니다. 자세한 내용은 [자바 에이전트 속성](/docs/apm/agents/java-agent/attributes/java-agent-attributes), [속성 활성화 및 비활성화](/docs/apm/agents/java-agent/attributes/java-agent-attributes) 및 [속성 예제](/docs/apm/agents/java-agent/attributes/java-agent-attributes)를 참조하십시오.

속성 보고는 다음 방법을 통해 구성할 수 있습니다.

YAML:

```yml
attributes:
  http_attribute_mode: both
```

시스템 속성:

```properties
-Dnewrelic.config.attributes.http_attribute_mode=both
```

환경 변수:

```properties
NEW_RELIC_ATTRIBUTES_HTTP_ATTRIBUTE_MODE=both
```

설정 옵션은 다음과 같습니다:

* `standard` : 보고에서는 standard(예: OTEL) 속성을 사용합니다. 이 구성이 권장됩니다. 기능에 대한 영향을 최소화하고 속성 보고를 위해 가장 낮은 수준의 수집을 유지하기 때문입니다.
* `legacy` : 보고는 재도입된 HTTP 속성을 통해 수행되며, 이 설정은 현재 또는 향후 기능에 영향을 미칠 수 있습니다.
* `both` : 이는 기본 설정이며, 보고는 재도입된 HTTP 속성과 OTEL 속성을 통해 수행됩니다. 이 설정은 또한 데이터 수집을 증가시킵니다.

<Callout variant="important">
[Java 에이전트 버전 8.8.0](/docs/release-notes/agent-release-notes/java-release-notes/java-agent-880)부터 사용 가능합니다. 기본 구성인 `both`는 데이터 수집을 증가시킵니다. 데이터 수집 증가를 방지하려면 `http_attribute_mode` `legacy` 또는 `standard`로 기본값을 재설정해야 합니다.
</Callout>
