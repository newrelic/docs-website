비동기 계측 설정은 에이전트가 애플리케이션의 비동기 활동을 추적하는 방식을 제어합니다.

<Callout variant="tip">
전체 설정 인덱스로 돌아가기: [자바 에이전트 설정](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file)
</Callout>

## 비동기 계측 [#async_config]

이러한 옵션은 `common` 섹션에서 직접 설정되며 접두사가 붙은 시스템 속성을 사용하여 [재정의](#System_Properties)할 수 있습니다.

에이전트가 `token.expire()` 으로 명시적으로 만료되지 않은 비동기 토큰을 자동으로 만료하는 시간(초)입니다. 사용 지침은 [토큰: 비동기 스레드 연결](/docs/agents/java-agent/java-agent-api/java-agent-api-asynchronous-applications#tokens) 을 참조하세요.

<Callout variant="important">
이 값을 늘리면 에이전트가 사용하는 메모리 양이 증가하고 만료되지 않은 토큰으로 인해 트랜잭션이 보고되지 않기 때문에 성능에 영향을 미칠 수 있습니다.
</Callout>
</Collapser>

에이전트가 `segment.end()` 또는 `segment.ignore()` 로 명시적으로 종료되지 않은 세그먼트를 자동으로 종료하는 시간(초)입니다. 사용 지침은 [세그먼트: 시간 임의 비동기 활동](/docs/agents/java-agent/java-agent-api/java-agent-api-asynchronous-applications#segments) 을 참조하십시오.

<Callout variant="important">
이 값을 늘리면 에이전트가 사용하는 메모리 양이 증가하고 끝나지 않은 세그먼트로 인해 트랜잭션이 보고되지 않기 때문에 성능에 영향을 줄 수 있습니다.
</Callout>
