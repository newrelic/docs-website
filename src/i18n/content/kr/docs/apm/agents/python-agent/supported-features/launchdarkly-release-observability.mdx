<Callout title="시사">
이 기능은 아직 개발 중이지만 꼭 사용해 보시기 바랍니다!

이 기능은 현재 [출시 전 정책](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy) 에 따라 미리보기 프로그램의 일부로 제공됩니다.
</Callout>

뉴렐릭 파이썬 에이전트는 LaunchDarkly 기능 관리와 통합되어 기능 플래그 및 릴리스가 애플리케이션에 미치는 영향을 관찰할 수 있습니다. 이 통합은 LaunchDarkly 옵저버빌리티 플러그인과 파이썬 에이전트의 OpenTelemetry 지원을 사용하여 LaunchDarkly 데이터를 뉴렐릭 APM 데이터와 연결합니다.

이 문서에서는 필수 패키지를 설치하고 통합을 활성화하는 방법을 설명합니다.

## 전제 조건 [#prerequisites]

시작하기 전에 다음 사항을 확인하십시오:

* New Relic [라이선스 키](/docs/apis/intro-apis/new-relic-api-keys/#license-key)
* LaunchDarkly 계정 및 라이선스
* 파이썬으로 작성되고 [뉴렐릭 파이썬 APM 에이전트](/docs/apm/agents/python-agent/installation/install-new-relic-python-agent)로 모니터되는 애플리케이션
* LaunchDarkly OpenTelemetry(OTel) 베타 액세스

## 설치 및 구성 [#install]

<Steps>
<Step>
### 필수 패키지를 설치하십시오. [#install-packages]

애플리케이션과 동일한 환경에 다음 파이썬 패키지를 설치하십시오:

* `newrelic`
* `launchdarkly-observability`

```bash
pip install newrelic launchdarkly-observability
```

다음 패키지도 필요하며, 일반적으로 `launchdarkly-observability`의 종속성으로 자동 설치됩니다:

* `opentelemetry-api`
* `launchdarkly-eventsource`
* `launchdarkly-server-sdk`
* `launchdarkly-server-sdk-otel`

이러한 종속성이 자동으로 설치되지 않는 경우, `pip`을(를) 사용하여 수동으로 설치하십시오:

```bash
pip install opentelemetry-api launchdarkly-eventsource launchdarkly-server-sdk launchdarkly-server-sdk-otel
```
</Step>

<Step>
### 통합 활성화 [#enable-integration]

통합을 활성화하려면 `launch_darkly_integration.enabled` 및 `opentelemetry.enabled`을(를) 모두 `true`(으)로 설정하십시오. 애플리케이션을 설정하려면 다음 설정 방법 중 하나를 선택하십시오:

<CollapserGroup>
<Collapser id="use-newrelic-ini" title="newrelic.ini를 사용하십시오.">
`newrelic.ini` 파일에 다음을 추가합니다.

```ini
launch_darkly_integration.enabled = true
opentelemetry.enabled = true
```
</Collapser>

<Collapser id="use-pyproject-toml" title="pyproject.toml을 사용하십시오">
`pyproject.toml` 파일에 다음을 추가합니다.

```toml
[tool.newrelic]
launch_darkly_integration.enabled = true
opentelemetry.enabled = true
```
</Collapser>

<Collapser id="use-environment-variables" title="환경 변수를 사용하십시오.">
다음 환경 변수를 설정하십시오:

```bash
export NEW_RELIC_LAUNCH_DARKLY_ENABLED=true
export NEW_RELIC_OPENTELEMETRY_ENABLED=true
```

<Callout variant="tip">
OpenTelemetry 설정에 대한 자세한 내용은 [파이썬 에이전트 설정](/docs/apm/agents/python-agent/configuration/python-agent-configuration#opentelemetry-enabled) 문서를 참조하십시오.
</Callout>
</Collapser>
</CollapserGroup>
</Step>

<Step>
### 통합을 확인하십시오. [#verify]

이러한 설정을 활성화한 후, 파이썬 에이전트가 업데이트된 설정을 로드하도록 애플리케이션을 다시 시작하십시오. 다음으로, 테스트 트래픽을 생성하고 애플리케이션이 [<DNT>**APM &amp; services**</DNT>](/docs/apm/apm-ui-pages/monitoring/apm-summary-page-view-transaction-apdex-usage-data)에 데이터를 계속 보고하는지 확인하십시오.
</Step>
</Steps>
