엔드투엔드 요청 추적, Infinite Tracing 테일 기반 샘플링 및 스팬 이벤트 수집을 활성화하도록 루비 에이전트의 분산 추적 설정을 구성하십시오.

## 분산 추적 [#distributed-tracing]

분산 추적을 사용하면 요청이 분산 시스템을 통과하는 경로를 볼 수 있습니다. 분산 추적을 활성화하면 일부 New Relic 기능의 동작이 변경되므로 이 기능을 활성화하기 전에 [전환 가이드](/docs/transition-guide-distributed-tracing) 를 주의 깊게 참조하십시오.
</Collapser>

이 설정은 원격 상위가 없는 트랜잭션(뉴렐릭 에이전트의 이 인스턴스 내에서 시작되는 트레이스)에 대한 트랜잭션 샘플링 동작을 제어합니다. 사용 가능한 값은 `adaptive` (기본값), `always_on`, `always_off` 및 `trace_id_ratio_based`입니다.
</Collapser>
