<Steps>
<Step>
## Gemfile에 gem을 추가하십시오. [#install]

`Gemfile`에 루비 에이전트 gem을 추가하십시오:

```ruby
gem 'newrelic_rpm'
```

`Dockerfile`은(는) 빌드의 일부로 `bundle install`을(를) 실행해야 합니다:

```dockerfile
COPY Gemfile Gemfile.lock ./
RUN bundle install
```

**프레임워크별 참고 사항:**

* **Rails**: Rails는 자동으로 `Bundler.require`을(를) 호출하므로 추가 단계 없이 시작 시 `newrelic_rpm`이(가) 필요합니다.
* **Roda 또는 Sinatra**: 애플리케이션에서 수동으로 `require 'newrelic_rpm'`을(를) 호출해야 합니다.
* **기타 Rack 앱**: 자동 브라우저 모니터링을 사용하려면 에이전트에서 제공하는 [Rack 미들웨어](/docs/agents/ruby-agent/frameworks/rack-middlewares#manual)를 수동으로 포함하십시오.
</Step>

<Step>
## 에이전트 구성 [#configure]

컨테이너를 실행할 때 앱 이름과 라이선스 키를 환경 변수로 전달하십시오 ― 이미지에 하드코딩하지 마십시오:

```bash
docker run -e NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
           -e NEW_RELIC_APP_NAME="Your Application Name" \
           YOUR_IMAGE_NAME:latest
```

`Dockerfile`에서 `ENV`을(를) 통해 설정할 수도 있습니다:

```dockerfile
ENV NEW_RELIC_APP_NAME="Your Application Name"
```

기타 모든 설정 옵션은 [루비 에이전트 설정](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration)을 참조하십시오.
</Step>

<Step>
## 데이터가 흐르고 있는지 확인 [#verify]

컨테이너를 실행하고 애플리케이션에 최소 두 개의 requests를 보내십시오. 2～3분 기다린 후, [one.newrelic.com &gt; APM](https://one.newrelic.com/apm)을 열고 이름으로 앱을 찾으십시오.

<Callout variant="tip">
앱이 표시되지 않습니까? [데이터가 표시되지 않음(루비)](/docs/apm/agents/ruby-agent/troubleshooting/no-data-appears-ruby)을 참조하십시오.
</Callout>
</Step>
</Steps>
