루비 애플리케이션 모니터링을 시작하려면 뉴렐릭 루비 에이전트를 설치하십시오. 왼쪽 탐색 메뉴에서 환경에 맞는 방법을 선택하십시오.

설치를 완료하려면 [뉴렐릭 계정](https://newrelic.com/signup)과 <InlinePopover type="licenseKey" />이(가) 필요합니다. 시작하기 전에 [루비 에이전트 요구 사항 및 지원되는 프레임워크](/docs/apm/agents/ruby-agent/getting-started/ruby-agent-requirements-supported-frameworks)를 확인하십시오.

| 방법                                                                                                                  | 사용 시기                                                  |
| ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| [표준(Bundler/Gemfile)](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent)                        | 대부분의 루비 앱 — Rails, Sinatra, Roda, Rack 및 기타 UNIX 기반 환경 |
| [Rails 플러그인](/docs/apm/agents/ruby-agent/installation/ruby-agent-installation-rails-plugin)                         | 구형 플러그인 설치 방법을 사용하는 Rails 2+ 앱                         |
| [도커](/docs/apm/agents/ruby-agent/installation/ruby-agent-installation-docker)                                       | 컨테이너화된 루비 애플리케이션                                       |
| [헤로쿠](/docs/apm/agents/ruby-agent/installation/ruby-agent-heroku)                                                   | 뉴렐릭 애드온을 사용하여 Heroku에 배포된 앱                            |
| [Google App Engine](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent-gae-flexible-environment) | GAE 가변형 환경에서 실행되는 앱                                    |
