루비 에이전트의 AI 모니터링 설정을 구성하여 LLM 계측을 활성화하고 입력 및 출력 콘텐츠가 AI 이벤트에 캡처되는지 여부를 제어하십시오.

## AI 모니터링 [#ai-monitoring]

이 섹션에는 AI 시뮬레이션 설정을 위한 루비 에이전트 설정이 포함되어 있습니다.

<Callout variant="important">추적 및 피드백 데이터를 캡처하려면 제외 추적을 활성화해야 합니다. 루비 에이전트 8.0.0 이상에서는 기본적으로 켜져 있습니다.</Callout>

`false` 인 경우 모든 LLM 측정, 로그(현재는 OpenAI만 해당)가 비활성화되고 지표, 이벤트 또는 범위가 전송되지 않습니다. `high_security` 모드가 활성화되면 AI 모니터링이 자동으로 비활성화됩니다.
</Collapser>

`false`인 경우, LLM 계측(현재는 OpenAI만 해당)은 LlmChatCompletionMessage 이벤트의 `content` 속성이나 LlmEmbedding 이벤트의 `input` 속성을 캡처하지 않습니다. 이는 LLM과 송수신되는 민감한 데이터가 기록되는 것을 방지하기 위한 선택적 보안 설정입니다.
