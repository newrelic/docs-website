로그 포워딩, 로컬 데코레이션, 로그 이벤트의 커스텀 속성 및 로그 메트릭 수집을 제어하려면 루비 에이전트의 애플리케이션 로깅 설정을 구성하십시오.

## 애플리케이션 로깅 [#application-logging]

Ruby 에이전트는 [컨텍스트에서 APM 로그를](/docs/apm/new-relic-apm/getting-started/get-started-logs-context) 지원합니다. Ruby 에이전트에 대한 로그 구성에 대한 몇 가지 팁 [은 컨텍스트에서 Ruby 로그 구성](/docs/logs/logs-context/configure-logs-context-ruby) 을 참조하십시오.

사용 가능한 로깅 관련 구성 옵션은 다음과 같습니다.

로그 이벤트가 뉴렐릭으로 전달되기 위해 가져야 하는 최소 레벨을 설정합니다. 구성된 레벨 및 더 높은 심각도의 로그가 전달됩니다. 예를 들어 `debug`은(는) 모든 로그 이벤트를 전달하는 반면, `error`은(는) `error`, `fatal` 및 `unknown` 이벤트만 전달합니다. 유효한 값, 가장 낮은 심각도부터 가장 높은 심각도 순: `debug`, `info`, `warn`, `error`, `fatal`, `unknown` (대소문자 구분 안 함).

이 순서는 루비의 `Logger::Severity` 상수의 정수 값을 기반으로 합니다([https://github.com/ruby/logger/blob/113b82a06b3076b93a71cd467e1605b23afb3088/lib/logger/severity.rb](https://github.com/ruby/logger/blob/113b82a06b3076b93a71cd467e1605b23afb3088/lib/logger/severity.rb) 참조).
</Collapser>
