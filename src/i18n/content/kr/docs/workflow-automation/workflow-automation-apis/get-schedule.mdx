## 샘플 요청 [#sample-request]

```graphql
    {
      actor {
        account(id: 12345678) {
          workflowAutomation {
            schedule(id: "schedule-id") {
              id
            }
          }
        }
      }
    }
```

## 샘플 응답 [#sample-response]
