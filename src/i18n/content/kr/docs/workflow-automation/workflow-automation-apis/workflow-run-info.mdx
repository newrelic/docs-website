## 샘플 요청

쿼리플로우를 생성하고 편집하려면 [쿼리빌더를](https://one.newrelic.com/nerdgraph-graphiql?state=03119d23-7b51-7b7a-1c99-d2cd026300e5) 사용하세요. [NerdGraph API 탐색기를](/docs/apis/nerdgraph/get-started/nerdgraph-explorer) 참조하세요.

```graphql
{
  actor {
    account(id: 11933347) {
      workflowAutomation {
        workflowRunInfo(runId: "8911c7e4-5a1f-4316-90c8-67adde72dd1c") {
          state(keys: ["foo", "count"]) {
            key
            value
          }
          logUrl
          status
        }
      }
    }
  }
}
```

## 샘플 응답

쿼리 결과는 다음과 같습니다.

* `logUrl`: 워크플로우 실행 로그를 볼 수 있는 URL입니다.
* `status`: 워크플로우 실행의 현재 상태입니다. 가능한 값: `STARTED`, `COMPLETED`, `FAILED`, `TIMED_OUT`, `STOPPED`.
* `state`: 워크플로우 상태에서 찾은 요청된 각 키에 대한 `{ key, value }` 객체의 어레이입니다. 워크플로우 상태에 없는 키는 생략됩니다.

```graphql
{
  "data": {
    "actor": {
      "account": {
        "workflowAutomation": {
          "workflowRunInfo": {
            "logUrl": "https://one.newrelic.com/...",
            "status": "COMPLETED",
            "state": [
              { "key": "foo", "value": "bar" },
              { "key": "count", "value": "2" }
            ]
          }
        }
      }
    }
  }
}
```
