## 샘플 요청 [#sample-request]

쿼리플로우를 생성하고 편집하려면 [쿼리빌더를](https://one.newrelic.com/nerdgraph-graphiql?state=c8579e50-f154-fec6-22b8-f9fdcfc1990a) 사용하세요. [NerdGraph API 탐색기를](/docs/apis/nerdgraph/get-started/nerdgraph-explorer) 참조하세요.

```graphql
{
  actor {
    account(id: 12345678) {
      workflowAutomation {
        workflow(name: "my-workflow", version: 1) {
          definition {
            name
            version
            yaml
          }
        }
      }
    }
  }
}
```

## 샘플 응답 [#sample-response]

쿼리 결과는 다음과 같습니다.

* `definition.name`: 워크플로우 정의의 이름
* `definition.version`: 참조우 정의의 버전 번호
* `definition.yaml`: base64로 인코딩된 워크플로우 정의 YAML
