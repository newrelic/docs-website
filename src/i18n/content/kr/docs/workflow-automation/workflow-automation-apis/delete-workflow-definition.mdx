지정된 이름의 워크플로우 정의의 모든 버전을 삭제하려면 `workflowAutomationDeleteWorkflowDefinition` 뮤테이션을 사용하십시오.

<Callout variant="important">
* 정의를 삭제하려면 해당 정의를 사용하는 일정이 없어야 합니다. 정의가 현재 일정에서 사용 중인 경우 삭제가 실패하고 오류가 반환됩니다.
* 정의가 삭제되더라도 실행 중인 모든 워크플로우 실행은 완료될 때까지 계속됩니다.
</Callout>

## 샘플 요청 [#sample-request]

```graphql
mutation {
  workflowAutomationDeleteWorkflowDefinition(
    definition: {name: "my-workflow"}
    scope: {id: "12345678", type: ACCOUNT}
  ) {
    definition {
      name
    }
  }
}
```
