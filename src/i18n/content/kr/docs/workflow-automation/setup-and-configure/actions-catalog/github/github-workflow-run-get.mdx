숫자형 Run ID로 특정 GitHub Actions 워크플로우 실행의 세부 정보, 상태 및 결과를 조회합니다. Run ID는 일반적으로 이전 `gitHub.workflowRun.trigger` 또는 `gitHub.workflowRun.list` 단계에서 가져옵니다.

인증 설정에 대해서는 [GitHub 워크플로우 실행 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run)을 참조하십시오.

<tr>
<td>
```yaml
name: poll_workflow_run
description: Get the status of a specific GitHub Actions workflow run
steps:
  - name: get_run
    type: action
    action: gitHub.workflowRun.get
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      runId: ${{ .steps.trigger_run.outputs.response.workflow_run_id }}
      selectors:
        - name: status
          expression: ".status"
        - name: conclusion
          expression: ".conclusion"
        - name: htmlUrl
          expression: ".html_url"
    next: end
```
