이 페이지는 워크플로우 자동화 액션 카탈로그에서 사용할 수 있는 Jenkins 큐 액션에 대한 참조를 제공합니다. 이 액션을 사용하여 Jenkins 빌드 큐에서 대기 중인 빌드를 검사하고 관리하십시오.

## 전제 조건

워크플로우 자동화에서 Jenkins 큐 액션을 사용하기 전에 다음이 필요합니다:

* HTTPS를 통해 뉴렐릭 워크플로우 자동화에서 연결할 수 있는 Jenkins 서버입니다. Jenkins 인스턴스가 방화벽 뒤에 있거나 프라이빗 네트워크에 있는 경우, 뉴렐릭 워크플로우 자동화로부터의 인바운드 액세스를 허용하십시오.
* 워크플로우가 실행되는 계정의 Jenkins API 토큰입니다. Jenkins 사용자 프로필에서 생성하십시오: **Configure &gt; API Token &gt; Add new Token**.
* `username:apiToken`의 Base64 인코딩 값을 포함하는 뉴렐릭 Secrets Service의 시크릿입니다. 워크플로우에서 이를 `${{ :secrets:<keyName> }}`(으)로 참조하십시오.

## Jenkins 대기열 항목 가져오기

작업 식별자는 `jenkins.queue.getItem`입니다.

실행이 시작되면 빌드 번호를 포함한 대기열 항목 세부 정보를 가져옵니다. 다른 작업 액션에 필요한 빌드 번호를 검색하려면 [`jenkins.job.trigger`](/docs/workflow-automation/setup-and-configure/actions-catalog/jenkins/jenkins-job#trigger-a-jenkins-job) (으)로 빌드를 트리거한 후 이 액션을 사용하여 대기열을 폴링하십시오.

빌드 실행이 시작되면 응답의 `executable.number` 필드에 빌드 번호가 포함됩니다. 항목이 아직 대기열에 있는 동안에는 `null` 입니다.

              ```yaml
              name: poll-jenkins-queue
              description: 'Trigger a build and poll the queue until the build number is available'
              steps:
                - name: trigger_build
                  type: action
                  action: jenkins.job.trigger
                  version: 1
                  inputs:
                    authToken: ${{ :secrets:jenkinsAuthToken }}
                    url: "https://jenkins.example.com"
                    jobName: "my-application-build"
                    selectors:
                      - name: "queueId"
                        expression: ".queueId"
                  next: poll_queue

                - name: poll_queue
                  type: loop
                  for:
                    in: ${{ [range(0; 10)] }}
                    steps:
                      - name: get_queue_item
                        type: action
                        action: jenkins.queue.getItem
                        version: 1
                        inputs:
                          authToken: ${{ :secrets:jenkinsAuthToken }}
                          url: "https://jenkins.example.com"
                          queueId: ${{ .steps.trigger_build.outputs.queueId }}
                          selectors:
                            - name: "buildNumber"
                              expression: ".responseBody | fromjson.executable.number // null"

                      - name: check_if_started
                        type: switch
                        switch:
                          - condition: ${{ .steps.get_queue_item.outputs.buildNumber != null }}
                            next: end
                        next: wait_and_retry

                      - name: wait_and_retry
                        type: wait
                        seconds: 2
                        next: continue
              ```

## 대기열에 있는 Jenkins 빌드 취소

작업 식별자는 `jenkins.queue.cancel`입니다.

대기 중인 Jenkins 빌드가 실행되기 전에 취소합니다. 이전 `jenkins.job.trigger` 호출에서 얻은 `queueId`이(가) 필요합니다.

빌드가 이미 실행되기 시작한 경우 이 액션은 실패합니다. 이미 실행 중인 빌드를 중지하려면 대신 [`jenkins.job.stop`](/docs/workflow-automation/setup-and-configure/actions-catalog/jenkins/jenkins-job#stop-a-running-jenkins-build)을(를) 사용하십시오.
