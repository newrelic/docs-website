이 페이지는 워크플로우 자동화 액션 카탈로그에서 사용할 수 있는 AWS Athena 액션에 대한 참조를 제공합니다. 이러한 액션을 사용하여 Amazon Athena를 대상으로 SQL 쿼리를 실행하고, 실행 상태를 확인하며, 워크플로우 정의에서 직접 결과를 가져오십시오.

## 전제 조건

사전 요구 사항 및 자격 증명 설정에 대해서는 [AWS 자격 증명 설정](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials)을 참조하십시오.

## 쿼리 실행을 시작합니다. [#start-query-execution]

작업 식별자는 `aws.athena.startQueryExecution`입니다.

Amazon Athena를 대상으로 SQL 쿼리를 실행하고 쿼리 실행 ID를 반환합니다. 이 작업은 쿼리가 완료될 때까지 기다리지 않습니다 — 상태를 폴링하려면 `aws.athena.getQueryExecution`을(를) 사용하고, 결과를 가져오려면 `aws.athena.getQueryResults`을(를) 사용하십시오.

**예시**

```yaml
name: start-athena-query
description: Run a SQL query against Athena
steps:
  - name: startQuery
    type: action
    action: aws.athena.startQueryExecution
    version: '1'
    inputs:
      awsRoleArn: ${{ :secrets:awsRoleArn }}
      region: us-east-2
      queryString: "SELECT * FROM my_table LIMIT 10"
      database: "my-database"
      catalog: "AwsDataCatalog"
      outputLocation: "s3://my-athena-results-bucket/path/"
      workGroup: "primary"
      selectors:
        - name: queryExecutionId
          expression: ".response.QueryExecutionId"
    next: end
```

**예시**

```yaml
name: get-athena-query-results
description: Fetch results of a completed Athena query
steps:
  - name: getResults
    type: action
    action: aws.athena.getQueryResults
    version: '1'
    inputs:
      awsRoleArn: ${{ :secrets:awsRoleArn }}
      region: us-east-2
      queryExecutionId: "8d0105c1-30b5-4b8f-a23e-a1b60047c43f"
      maxResults: 100
      selectors:
        - name: rows
          expression: ".response.ResultSet.Rows"
        - name: columnInfo
          expression: ".response.ResultSet.ResultSetMetadata.ColumnInfo"
        - name: nextToken
          expression: ".response.NextToken"
    next: end
```
