뉴렐릭 엔티티의 전체 태그 세트를 제공된 태그로 교체합니다.

전제조건은 [뉴렐릭 태그 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites)을 참조하십시오.

## 태그 교체

작업 식별자는 `newrelic.tagging.replaceTags`입니다.

뉴렐릭 엔티티의 전체 태그 세트를 제공된 태그로 대체합니다. 이 작업은 파괴적입니다: `tags` 입력에 포함되지 않은 기존 태그를 모두 제거합니다. 기존 태그를 제거하지 않고 태그를 추가하려면 대신 [`newrelic.tagging.addTags`](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging-addtags)을(를) 사용하십시오. `newrelic.nerdgraph.execute`을(를) 기반으로 구축되었습니다.
