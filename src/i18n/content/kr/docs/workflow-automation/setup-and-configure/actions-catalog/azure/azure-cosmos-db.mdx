Azure Cosmos DB 작업을 통해 워크플로우에서 직접 Azure Cosmos DB의 문서 및 데이터베이스를 읽고, 쓰고, 관리할 수 있습니다. 모든 작업은 Azure AD 서비스 주체를 사용하여 인증하고 Cosmos DB 데이터 평면과 통신합니다.
