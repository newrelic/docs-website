작업 식별자는 `newrelic.alerts.createPolicy`입니다.

새로운 공지 정책을 생성합니다. 정책은 관련된 공지 조건을 그룹화하고 위반이 인시던트를 생성하는 방식을 제어합니다.

    <TabsPageItem id="policy-create-example">
      다음 예제는 공지 정책을 생성하고 이후 단계에서 사용하기 위해 새 정책 ID를 캡처합니다.

      <table>
        <thead>
          <tr>
            <th>
              워크플로 예
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: create_alert_policy
              description: Create an alert policy
              steps:
                - name: createPolicy
                  type: action
                  action: newrelic.alerts.createPolicy
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    name: "Production Services"
                    incidentPreference: "PER_CONDITION"
                    selectors:
                      - name: policyId
                        expression: ".data.alertsPolicyCreate.id"
                  next: end
              ```
            </td>
          </tr>
