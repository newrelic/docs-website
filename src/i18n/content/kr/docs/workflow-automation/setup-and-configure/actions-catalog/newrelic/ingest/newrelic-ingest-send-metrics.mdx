      ### 필수 핵심 가치 쌍 `metrics` [#metrics-key-value-pairs]

      `metrics` 목록의 각 지표 데이터 포인트 맵은 다음 핵심 가치 구조를 사용합니다.

      <table>
        <thead>
          <tr>
            <th>
              기인하다
            </th>

            <th>
              유형
            </th>

            <th>
              설명
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              **이름**
            </td>

            <td>
              문자열
            </td>

            <td>
              **필수 항목입니다.**

               메트릭의 이름. 값은 255자 미만이어야 합니다.
            </td>
          </tr>

          <tr>
            <td>
              **값**
            </td>

            <td>
              숫자 또는 지도
            </td>

            <td>
              **필수 항목입니다.**

               값은 

              [메트릭 유형](/docs/data-apis/understand-data/metric-data/metric-data-type/)

              에 따라 다릅니다. 

              `gauge`

               및 

              `count`

              의 경우 값은 단일 숫자여야 합니다. 

              `summary`

              의 경우 값은 개수, 합계, 최솟값 및 최댓값을 지정하는 핵심 가치 쌍이 있는 맵이어야 합니다.
            </td>
          </tr>

          <tr>
            <td>
              **타임스탬프**
            </td>

            <td>
              긴
            </td>

            <td>
              **선택 사항.**

               

              [유닉스 시간](https://currentmillis.com/)

              으로 표시된 메트릭의 시작 시간입니다. 기본값은 UTC 시간대를 사용합니다. 이 필드는 초, 마이크로초 및 나노초도 지원합니다. 하지만 데이터는 저장 및 쿼리를 위해 밀리초로 변환됩니다. 보고된 시간으로부터 48시간 이상 과거이거나 24시간 이상 미래인 타임스탬프가 있는 메트릭은 삭제됩니다.
            </td>
          </tr>

          <tr>
            <td>
              **간격.ms**
            </td>

            <td>
              긍정적 장기
            </td>

            <td>
              ****

              `count`

               및 

              `summary`

               

              [메트릭 유형](/docs/data-apis/understand-data/metric-data/metric-data-type/)

               에 필수 입니다. 시간 범위의 길이입니다.
            </td>
          </tr>

          <tr>
            <td>
              **type**

            <td>

              [지원되는 메트릭 유형](/docs/data-apis/understand-data/metric-data/metric-data-type/)

              을 참조하십시오. 유형을 지정하지 않으면 

              `gauge`

              (으)로 기본 설정됩니다.
            </td>
          </tr>

          <tr>
            <td>
              **속성**

            <td>
              문자열, JSON 숫자 또는 부울

               이 특정 메트릭과 연결된 핵심 가치 쌍의 맵입니다. 값은 문자열, JSON 숫자 또는 부울일 수 있습니다. 키는 대소문자를 구분하며 255자 미만이어야 합니다.
            </td>
          </tr>
        </tbody>
      </table>

      <Callout variant="important">
        메트릭 API는 `timestamp` 을 필수로 요구합니다. 액션 내에서 `timestamp` 은 선택 사항이며, 메트릭 수집 전에 제공되지 않으면 현재 시간으로 기본 설정됩니다.
      </Callout>

      ### 메트릭 간에 속성 공유 `common` [#common-attributes]

      여러 참조에 속성 세트를 포함시키려면(각 참조에 동일한 속성을 추가하지 않으려면) `common` 블록을 사용할 수 있습니다. 이는 모든 관련 데이터 포인트에 적용되는 정보를 지정하는 선택적 맵입니다. `common` 섹션의 값은 메트릭 데이터 포인트에 동일한 키가 있는 경우 덮어쓰여집니다.

      블록에는 다음이 포함될 수 있습니다.

              유형
            </th>

            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              **타임스탬프**
            </td>

            <td>
              긴
            </td>

            <td>
              측정항목의 시작 시간( 

              [Unix 시간](https://currentmillis.com/)

               )입니다. UTC 표준 시간대의 현재 시간이 기본값입니다. 이 필드는 초, 마이크로초 및 나노초도 지원합니다. 그러나 데이터는 저장 및 나중에 쿼리하기 위해 밀리초로 변환됩니다.
            </td>
          </tr>

          <tr>

            </td>

            <td>
              `count`

              `summary`

              의 경우 

              **필수 항목입니다**

              . 시간 창의 길이입니다.
            </td>
          </tr>

          <tr>
            <td>

            </td>

            <td>
              문자열, JSON 숫자 또는 부울

            <td>
              이 특정 측정항목과 연결된 키-값 쌍의 맵입니다. 값은 문자열, JSON 숫자 또는 부울일 수 있습니다.
            </td>
          </tr>

                        value: 9
                        timestamp: 1531414060739
