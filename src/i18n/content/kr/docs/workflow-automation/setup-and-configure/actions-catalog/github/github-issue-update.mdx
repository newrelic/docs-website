GitHub 저장소의 기존 이슈(제목, 본문, 상태, 담당자, 레이블 및 마일스톤)를 업데이트합니다.

인증 설정에 대해서는 [GitHub 이슈 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-issue)을 참조하십시오.

              ```yaml
              name: github_update_issue_workflow
              description: Update a GitHub issue
              steps:
                - name: update_issue
                  type: action
                  action: gitHub.issue.update
                  version: 1
                  inputs:
                    token: ${{ :secrets:github-PAT-token }}
                    owner: your_user_name
                    repo: test-workflow
                    issueNumber: 7
                    title: Issue has been resolved
                    body: Investigation complete. Closing this issue.
                    state: closed
                    state_reason: completed
                    labels:
                      - resolved
                  next: end
              ```
