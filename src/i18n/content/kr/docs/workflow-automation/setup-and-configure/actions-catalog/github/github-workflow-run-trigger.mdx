`workflow_dispatch` 이벤트를 통해 GitHub Actions 워크플로우 실행을 트리거합니다. 타겟 워크플로우에는 `workflow_dispatch` 트리거가 구성되어 있어야 합니다. 성공 시 GitHub는 HTTP 204 No Content를 반환합니다.

인증 설정에 대해서는 [GitHub 워크플로우 실행 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run)을 참조하십시오.

<td>
```yaml
name: trigger_github_workflow
description: Trigger a GitHub Actions workflow run
steps:
  - name: trigger_run
    type: action
    action: gitHub.workflowRun.trigger
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      workflowId: deploy.yml
      ref: main
      inputs:
        environment: staging
        version: "1.2.3"
    next: end
```
