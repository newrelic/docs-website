이 페이지는 워크플로우 자동화 액션 카탈로그에서 사용할 수 있는 AWS Auto Scaling 액션에 대한 참조를 제공합니다. 이러한 액션을 사용하여 Auto Scaling 그룹(ASG)을 관리하십시오 — 인스턴스 연결 및 분리, 용량 조정, 스케일링 정책 실행, 인스턴스 새로 고침 관리, 스케일링 프로세스 제어 및 ASG 상태 쿼리.

## 전제 조건

워크플로우 자동화에서 AWS Auto Scaling 작업을 사용하기 전에 다음이 필요합니다:

* Auto Scaling 서비스에 대한 권한이 있는 AWS 계정입니다.
* IAM 역할 ARN 또는 정적 액세스 키 자격 증명으로 구성된 AWS 자격 증명입니다.
* 모든 정적 자격 증명을 위한 뉴렐릭 Secrets Service의 시크릿입니다. 워크플로우에서 `${{ :secrets:<keyName> }}`(으)로 참조하십시오.

IAM 사용자 및 IAM 역할을 생성하고 정적 및 세션 AWS 자격 증명을 설정하는 방법은 [AWS 자격 증명 설정](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials/)을 참조하십시오.

## 인스턴스 연결

작업 식별자는 `aws.autoscaling.attachInstances`입니다.

기존 Auto Scaling 그룹에 하나 이상의 EC2 인스턴스를 연결하십시오. 인스턴스를 연결하면 연결된 수만큼 원하는 용량이 증가합니다. 호출당 최대 20개의 인스턴스를 연결할 수 있습니다. 인스턴스는 실행 중이거나 중지된 상태여야 하며, 연결 시 그룹의 최대 크기를 초과해서는 안 됩니다.

## 인스턴스 분리

## 원하는 용량 설정

## 인스턴스 새로 고침 롤백

작업 식별자는 `aws.autoscaling.rollbackInstanceRefresh`입니다.

진행 중인 인스턴스 새로 고침을 롤백하여, 교체된 인스턴스를 이전 출시 템플릿 또는 설정으로 되돌립니다. 롤백을 지원하려면 그룹에 체크포인트가 활성화되어 있어야 합니다. 롤백할 수 있는 새로 고침이 없으면 호출이 `ActiveInstanceRefreshNotFound`(으)로 실패합니다.

                  inputs:
                    awsRoleArn: ${{ .workflowInputs.arnRole }}
