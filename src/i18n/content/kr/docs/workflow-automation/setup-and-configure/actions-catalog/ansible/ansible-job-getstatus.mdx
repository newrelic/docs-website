이 페이지는 워크플로우 자동화 액션 카탈로그에서 사용할 수 있는 `ansible.job.getStatus` 액션에 대한 참조를 제공합니다. [`ansible.job.launch`](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job-launch)에서 생성한 작업이 종료 상태에 도달할 때까지 폴링하려면 이 액션을 사용하십시오.

사전 요구 사항은 [Ansible 작업 액션](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job#prerequisites)을 참조하십시오.

## Ansible 작업 상태 가져오기

작업 식별자는 `ansible.job.getStatus`입니다.

Automation Controller 작업의 상태 및 세부 정보를 가져옵니다. 작업 상태는 `pending`에서 `waiting`, `running`로 진행된 후 종료 상태인 `successful`, `failed`, `error` 또는 `canceled`에 도달합니다. 엔드포인트는 `GET https://{host}/api/controller/v2/jobs/{jobId}/`입니다.

              steps:
                - name: get_status
                  type: action
                  action: ansible.job.getStatus
                  version: 1
                  inputs:
                    host: ${{ :secrets:host }}
                    authToken: ${{ :secrets:ansibleControllerToken }}
                    jobId: "128"
                    selectors:

                        expression: ".status"
                      - name: failed
