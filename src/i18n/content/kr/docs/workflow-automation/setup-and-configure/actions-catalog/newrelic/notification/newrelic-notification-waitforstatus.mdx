작업 식별자는 `newrelic.notification.waitForStatus`입니다.

이전 `newrelic.notification.send` 단계에서 보낸 공지의 전송 결과를 폴링합니다. `sessionId`이(가) 주어지면, 이 작업은 공지가 최종 상태(`SUCCESS` 또는 `FAIL`)에 도달하거나 지정된 `timeout`이(가) 경과할 때까지 `NrNotificationsEvent`을(를) 폴링합니다. Slack 대상의 경우, 공지가 생성한 스레드에 회신하는 데 필요한 `thread_ts` 값도 반환합니다.

<th>
워크플로우 예시: Slack 공지를 전송하고 수신 확인을 대기합니다.
</th>
</tr>
</thead>

<tbody>
<tr>
<td>
```yaml
name: notify_and_wait
description: Send a Slack notification then wait for its delivery status
steps:
  - name: sendNotification
    type: action
    action: newrelic.notification.send
    version: 1
    inputs:
      type: slack
      destinationId: "your-destination-id"
      parameters:
        channel: "your-slack-channel"
        text: "Deployment finished"
      selectors:
        - name: sessionId
          expression: ".response.sessionId"
    next: waitForStatus

  - name: waitForStatus
    type: action
    action: newrelic.notification.waitForStatus
    version: 1
    inputs:
      sessionId: ${{ .steps.sendNotification.outputs.sessionId }}
      timeout: 15
      selectors:
        - name: deliveryStatus
          expression: ".notificationStatus.status"
        - name: threadTs
          expression: ".notificationStatus.threadTs"
    next: end
```
