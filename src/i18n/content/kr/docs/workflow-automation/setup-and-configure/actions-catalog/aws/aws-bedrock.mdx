이 페이지는 워크플로우 자동화 액션 카탈로그에서 사용할 수 있는 AWS Bedrock 액션에 대한 참조를 제공합니다. 이 액션을 사용하여 워크플로우 정의의 일부로 Bedrock 에이전트를 호출하십시오.

## 전제 조건

워크플로우 자동화에서 AWS Bedrock 액션을 사용하기 전에 다음을 갖추고 있는지 확인하십시오:

* 적절한 권한이 있는 AWS 계정.
* AWS 자격 증명이 구성되었습니다(IAM 사용자 자격 증명, IAM 역할 ARN 또는 세션 자격 증명). 최소 하나의 자격 증명 옵션을 제공해야 합니다 — 정적 액세스 키보다 IAM 역할이 우선합니다.
* Bedrock 작업(`bedrock:InvokeAgent`, `bedrock:InvokeModel`)에 필요한 IAM 권한입니다.

IAM 사용자 및 IAM 역할을 생성하는 방법과 AWS 작업 자동화와의 통합을 위한 정적 및 세션 AWS 자격 증명을 설정하는 방법에 대한 자세한 내용은 [AWS 자격 증명 설정하기를](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials/) 참조하세요.

## 베드락 에이전트를 호출합니다

작업 식별자는 `aws.bedrock.invokeAgent`입니다.

프롬프트를 사용하여 AWS Bedrock 에이전트를 호출하고 에이전트의 응답을 반환합니다.
