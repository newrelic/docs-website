특정 워크플로우에 대한 가장 최근의 GitHub Actions 워크플로우 실행을 가져옵니다. 정확한 실행 ID를 알 수 없는 경우 ― 예를 들어, 실행을 트리거한 직후에 유용합니다. 항상 최대 하나의 실행을 반환합니다.

인증 설정에 대해서는 [GitHub 워크플로우 실행 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run)을 참조하십시오.

<td>
```yaml
name: get_latest_workflow_run
description: Retrieve the most recent workflow run for a specific workflow
steps:
  - name: get_latest_run
    type: action
    action: gitHub.workflowRun.getLatest
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      workflowId: deploy.yml
      branch: main
      event: workflow_dispatch
      selectors:
        - name: runId
          expression: ".workflow_runs[0].id"
        - name: conclusion
          expression: ".workflow_runs[0].conclusion"
        - name: htmlUrl
          expression: ".workflow_runs[0].html_url"
    next: end
```
