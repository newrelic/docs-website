뉴렐릭 액션 카탈로그는 cloud 제공업체, DevOps 도구, ITSM 플랫폼 및 뉴렐릭 자체 플랫폼을 위해 사전 구축된 액션을 제공합니다. 이러한 액션을 워크플로우 자동화의 단계로 사용하여 도구 및 서비스 전반에서 배포를 트리거하고, 인시던트를 관리하며, 운영 작업을 자동화하십시오.

동작은 계층적 명명 규칙을 따릅니다. `company.product.action`
