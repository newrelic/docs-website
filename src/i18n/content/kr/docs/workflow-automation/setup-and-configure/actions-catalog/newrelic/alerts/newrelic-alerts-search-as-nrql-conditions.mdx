작업 식별자는 `newrelic.alerts.searchAsNrqlConditions`입니다.

NRQL로 변환된 형식의 클래식(구형) 공지 조건을 검색합니다. 이름, 정책 또는 소스 제품별 선택적 필터링과 커서 기반 페이지네이션을 지원합니다.

    <TabsPageItem id="condition-search-as-nrql-example">
      다음 예제는 이름의 일부로 클래식 조건을 찾습니다.

      <table>
        <thead>
          <tr>
            <th>
              워크플로 예
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: search_as_nrql_conditions
              description: Search classic conditions in NRQL format
              steps:
                - name: searchAsNrqlConditions
                  type: action
                  action: newrelic.alerts.searchAsNrqlConditions
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    nameLike: "error rate"
                    selectors:
                      - name: nrqlConditions
                        expression: ".data.actor.account.alerts.asNrqlConditionsSearch.nrqlConditions"
                  next: end
              ```
