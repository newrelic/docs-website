이 페이지는 워크플로우 자동화 액션 카탈로그에서 사용할 수 있는 모든 뉴렐릭 공지 액션에 대한 참조를 제공합니다. 이러한 액션을 사용하면 구성된 대상으로 메시지를 전송하고, human-in-the-loop 신호 URL을 생성하며, 다른 워크플로우 실행을 트리거할 수 있습니다.

## 전제 조건

워크플로우 자동화에서 뉴렐릭 공지 작업을 사용하기 전에 다음을 갖추었는지 확인하십시오:

* 적절한 권한이 있는 뉴렐릭 계정.
* 뉴렐릭 클러스터 키(데이터를 다른 계정으로 보내는 경우).
* 사용하려는 특정 뉴렐릭 서비스에 필요한 권한입니다.

블루렐릭 계정 키를 생성하고 관리하는 방법에 대한 자세한 내용은 [볼륨 키를](/docs/apis/intro-apis/new-relic-api-keys#license-key) 참조하세요.
