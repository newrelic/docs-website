이 페이지는 워크플로우 자동화 액션 카탈로그에서 사용할 수 있는 GitHub 이슈 액션에 대한 참조를 제공합니다. 이러한 액션을 사용하면 워크플로우 정의에서 직접 GitHub 저장소의 이슈를 생성, 업데이트, 나열 및 관리할 수 있습니다.

## 전제 조건

워크플로우 자동화에서 GitHub 이슈 작업을 사용하기 전에 다음을 갖추고 있는지 확인하십시오:

* 타겟 저장소에 액세스할 수 있는 GitHub 계정.
* 필요한 권한이 있는 GitHub 개인 액세스 토큰(PAT).
* 뉴렐릭 Secrets Service에 저장된 PAT입니다.

## PAT 인증 설정

GitHub 이슈 작업은 Bearer 자격 증명으로 전달되는 개인 액세스 토큰(PAT)을 사용하여 인증합니다. 이 작업은 두 가지 토큰 유형을 지원합니다:

* **세분화된 PAT** — **Issues: Read and write** 저장소 권한이 필요합니다.
* **Classic PAT** — **리포지터리** 범위가 필요합니다.

<Steps>
  <Step>
    ### GitHub 개인 액세스 토큰을 생성하십시오.

    1. GitHub에서 **Settings &gt; Developer settings &gt; Personal access tokens**으로 이동하십시오.
    2. **Fine-grained tokens** \[세분화된 토큰] 또는 **Tokens (classic)** \[토큰(클래식)]을 선택하고 **Generate new token** \[새 토큰 생성]을 클릭하십시오.
    3. 필요한 권한을 설정하십시오: 세분화된 토큰의 경우 **Issues: Read and write**, 또는 클래식 토큰의 경우 **리포지터리** 범위.
    4. 생성된 토큰을 복사하십시오 ― GitHub는 이를 한 번만 표시합니다.
  </Step>

  <Step>
    ### 토큰을 시크릿으로 저장하십시오

    뉴렐릭 시크릿 서비스에 토큰을 저장하고 `${{ :secrets:keyName }}` 구문을 사용하여 워크플로우 YAML에서 참조하십시오:

    ```yaml
    token: ${{ :secrets:github-PAT-token }}
    ```
  </Step>
</Steps>
