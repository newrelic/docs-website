이 페이지는 워크플로우 자동화 액션 카탈로그에서 사용할 수 있는 Jenkins 작업 액션에 대한 참조를 제공합니다. 이러한 액션을 사용하여 Jenkins 빌드를 트리거하고 관리하십시오.

## 전제 조건

워크플로우 자동화에서 Jenkins 작업 액션을 사용하기 전에 다음이 필요합니다:

* HTTPS를 통해 뉴렐릭 워크플로우 자동화에서 연결할 수 있는 Jenkins 서버입니다. Jenkins 인스턴스가 방화벽 뒤에 있거나 프라이빗 네트워크에 있는 경우, 뉴렐릭 워크플로우 자동화로부터의 인바운드 액세스를 허용하십시오.
* 워크플로우가 실행되는 계정의 Jenkins API 토큰입니다. Jenkins 사용자 프로필에서 생성하십시오: **Configure &gt; API Token &gt; Add new Token**.
* `username:apiToken`의 Base64 인코딩 값을 포함하는 뉴렐릭 Secrets Service의 시크릿입니다. 워크플로우에서 이를 `${{ :secrets:<keyName> }}`(으)로 참조하십시오.
* 폴더 기반 작업의 경우 `/`을(를) 구분 기호로 사용하는 작업의 전체 폴더 경로입니다(예: `deployments/production/my-job`).

## Jenkins 작업 트리거

작업 식별자는 `jenkins.job.trigger`입니다.

## 실행 중인 Jenkins 빌드 중지

작업 식별자는 `jenkins.job.stop`입니다.

실행 중인 Jenkins 빌드를 중지하거나 중단합니다. 중지되면 Jenkins는 빌드를 `ABORTED` (으)로 표시합니다.

실행 중인 빌드의 `buildNumber`이(가) 필요합니다. `jenkins.job.trigger`을(를) 사용하여 빌드를 트리거한 다음 `jenkins.queue.getItem`을(를) 폴링하여 가져오십시오.
