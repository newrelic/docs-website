작업 식별자는 `newrelic.alerts.updatePolicy`입니다.

기존 공지 정책을 업데이트합니다. 정책 이름, 인시던트 기본 설정 또는 두 가지 모두를 변경할 수 있습니다. 필드를 생략하면 변경되지 않은 상태로 유지됩니다.
