선택적 필터링 및 페이지 매김을 사용하여 계정에 대한 뉴렐릭 공지 인텔리전스 이슈를 쿼리하고 나열합니다.

전제조건은 [뉴렐릭 이슈 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/issue/newrelic-issue#prerequisites)을 참조하십시오.

## 문제 나열

작업 식별자는 `newrelic.issue.list`입니다.

계정에 대한 뉴렐릭 이슈(AI 이슈)를 쿼리하고 나열하여 활성 또는 과거 이슈에 대한 실시간 상태, 타임라인, 상관된 엔티티 및 영향 세부 정보를 반환합니다. 상태, 우선순위, 소스, 엔티티, 조건, 정책, 상관관계 및 승인 상태, 시간 창, 커서 기반 페이지 매김에 의한 필터링을 지원합니다. `newrelic.nerdgraph.execute`을(를) 기반으로 구축되었습니다.

      다음 예는 다양한 필터 설정과 함께 이 작업을 사용하는 방법을 보여줍니다.

      <table>
        <thead>
          <tr>
            <th>
              워크플로 예
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              필터 없음 — 상태, 우선순위 또는 기타 필터와 관계없이 계정의 모든 이슈를 나열합니다. `accountId`만 필요합니다:

              ```yaml
              name: newrelic_issue_list_all
              description: list all issues for an account with no filters
              steps:
                - name: newrelic_issue_list
                  type: action
                  action: newrelic.issue.list
                  version: 1
                  inputs:
                    accountId: 123456
                  next: end
              ```

              다음 예제에서는 기본 필터를 사용하여 계정의 활성 상태인 우선순위가 높은 이슈를 나열합니다:

              ```yaml
              name: newrelic_issue_list_workflow
              description: list newrelic issues
              steps:
                - name: newrelic_issue_list
                  type: action
                  action: newrelic.issue.list
                  version: 1
                  inputs:
                    accountId: 123456
                    states: ["ACTIVATED", "CREATED"]
                    priority: ["CRITICAL", "HIGH"]
                  next: end
              ```

              다음 예제에서는 특정 시간 범위 내의 확인되지 않고, 음소거되지 않은, 심각한 문제에 대해 여러 필터를 사용하며, 페이지네이션을 위해 응답을 평면화하는 선택기를 사용합니다:

              ```yaml
              name: newrelic_issue_list_advanced
              description: list unacknowledged critical issues in a time window
              steps:
                - name: newrelic_issue_list
                  type: action
                  action: newrelic.issue.list
                  version: 1
                  inputs:
                    accountId: 123456
                    states: ["ACTIVATED"]
                    priority: ["CRITICAL"]
                    isAcknowledged: false
                    mutingStates: ["NOT_MUTED"]
                    startTime: 1785900000000
                    endTime: 1785998400000
                    selectors:
                      - name: issues
                        expression: ".data.actor.account.aiIssues.issues.issues"
                      - name: nextCursor
                        expression: ".data.actor.account.aiIssues.issues.nextCursor"
                  next: end
              ```

              세 번째 예제에서 추가 결과를 페이지 단위로 확인하려면, `nextCursor` 출력을 가져와 후속 호출 시 `cursor` 입력으로 다시 전달하십시오.
