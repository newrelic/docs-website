뉴렐릭 엔티티에서 특정 태그 값을 제거하고, 동일한 키의 다른 값은 그대로 유지합니다.

전제조건은 [뉴렐릭 태그 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites)을 참조하십시오.

## 태그 값 삭제

작업 식별자는 `newrelic.tagging.deleteTagValues`입니다.

뉴렐릭 엔티티의 태그에서 특정 핵심 가치 쌍을 제거합니다. 동일한 키 아래의 다른 값은 유지합니다. 전체 태그 키와 모든 값을 제거하려면 대신 [`newrelic.tagging.deleteTags`](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging-deletetags)을(를) 사용하십시오. `newrelic.nerdgraph.execute`을(를) 기반으로 구축되었습니다.
