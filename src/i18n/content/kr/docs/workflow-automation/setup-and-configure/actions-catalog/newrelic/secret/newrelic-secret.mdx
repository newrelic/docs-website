이 페이지는 워크플로우 자동화 액션 카탈로그에서 사용할 수 있는 뉴렐릭 시크릿 관리 액션에 대한 참조를 제공합니다. 이러한 액션을 사용하면 워크플로우 정의에서 직접 시크릿을 나열하고 버전 기록을 검사할 수 있습니다.

<Callout variant="important">
시크릿의 값을 가져오는 작업은 없습니다. 워크플로우 작업을 통해 시크릿을 복호화하면 실행 기록 및 로그에 값이 노출됩니다. 시크릿의 값을 워크플로우 단계의 입력으로 사용하려면, 대신 `${{ :secrets:keyName }}` 구문을 사용하여 직접 참조하십시오.
</Callout>

## 전제 조건

워크플로우 자동화에서 뉴렐릭 시크릿 작업을 사용하기 전에 다음을 갖추었는지 확인하십시오:

* 시크릿 관리를 읽을 수 있는 적절한 권한이 있는 뉴렐릭 계정입니다.
* 쿼리하려는 범위에 대한 `scopeId` (계정 ID 또는 조직 ID) 및 `scopeType` (`ACCOUNT` 또는 `ORGANIZATION`).

```yaml
name: list_secret_versions
description: List all versions of a New Relic secret
steps:
  - name: listSecretVersions
    type: action
    action: newrelic.secret.listVersions
    version: 1
    inputs:
      key: "jira_auth_token"
      scopeId: "11933347"
      scopeType: "ACCOUNT"
      fetchDeleted: true
      selectors:
        - name: latestVersion
          expression: ".data.customerAdministration.secretVersions.latestVersion"
    next: end
```
