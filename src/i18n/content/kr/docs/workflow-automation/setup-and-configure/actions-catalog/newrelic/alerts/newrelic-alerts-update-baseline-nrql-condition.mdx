작업 식별자는 `newrelic.alerts.updateBaselineNrqlCondition`입니다.

기존 기준 NRQL 공지 조건을 업데이트합니다. `accountId` 및 `id`을(를) 제외한 모든 필드는 선택 사항입니다 — 제공한 필드만 변경되며, 생략된 필드는 현재 값을 유지합니다.

              steps:

                  action: newrelic.alerts.updateBaselineNrqlCondition
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    id: ${{ .workflowInputs.conditionId }}
