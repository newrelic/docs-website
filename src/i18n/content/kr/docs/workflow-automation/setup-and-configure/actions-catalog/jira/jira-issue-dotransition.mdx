Jira 이슈를 다른 상태로 전환합니다. 이 작업을 호출하기 전에 [Get Jira issue transitions](/docs/workflow-automation/setup-and-configure/actions-catalog/jira/jira-issue-gettransitions) 작업을 사용하여 사용 가능한 전환 ID를 검색하십시오.

인증 설정은 [Jira 문제 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/jira/jira-issue)을 참조하십시오.
