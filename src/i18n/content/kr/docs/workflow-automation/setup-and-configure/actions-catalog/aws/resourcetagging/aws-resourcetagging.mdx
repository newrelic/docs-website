이 페이지는 워크플로우 자동화 액션 카탈로그에서 사용할 수 있는 AWS 리소스 그룹 태그 API 액션에 대한 참조를 제공합니다. 이러한 액션을 사용하여 여러 서비스에 걸쳐 AWS 리소스의 태그를 가져오고, 추가하고, 업데이트하고, 제거하십시오.

## 전제 조건

사전 요구 사항 및 자격 증명 설정에 대해서는 [AWS 자격 증명 설정](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials)을 참조하십시오.

## ARN으로 태그 가져오기

작업 식별자는 `aws.resourceGroupsTaggingApi.getResourceTags`입니다.

ARN으로 지정된 하나 이상의 AWS 리소스에 대한 태그를 반환합니다.

<Callout variant="important">
  `resourceArnList`을(를) `tagFilters`, `resourceTypeFilters` 또는 페이지네이션 입력과 결합할 수 없습니다. AWS는 `InvalidParameterException`(으)로 해당 조합을 거부합니다. 태그 또는 유형별로 리소스를 찾으려면 대신 [`aws.resourceGroupsTaggingApi.getResourcesByTag`](#get-resources-by-tag)을(를) 사용하십시오.
</Callout>

**예제 워크플로우**

```yaml
name: get-resource-tags-by-arn
description: 'Get tags for AWS resources by ARN'
steps:
  - name: getResourceTagsByArn
    type: action
    action: aws.resourceGroupsTaggingApi.getResourceTags
    version: '1'
    inputs:
      awsRoleArn: "arn:aws:iam::123456789012:role/my-workflow-role"
      region: "us-east-2"
      resourceArnList:
        - "arn:aws:dynamodb:us-east-2:123456789012:table/my-table"
      selectors:
        - name: tags
          expression: ".response.ResourceTagMappingList"
    next: end
```

## 리소스에 태그를 추가하거나 업데이트하십시오

작업 식별자는 `aws.resourceGroupsTaggingApi.tagResources`입니다.

단일 호출로 여러 서비스에 걸쳐 1～20개의 AWS 리소스에 최대 50개의 태그를 추가하거나 업데이트합니다.

<Callout variant="important">
  이 작업은 최상위 오류가 아닌 `response.FailedResourcesMap`에서 ARN별 부분 실패를 보고합니다. 일괄 처리에서 하나의 ARN이 실패하더라도 전체 호출이 실패하지는 않으므로 `success`이(가) `true`인 경우에도 `response.FailedResourcesMap`을(를) 확인하십시오.
</Callout>

## 리소스에서 태그 제거

작업 식별자는 `aws.resourceGroupsTaggingApi.untagResources`입니다.

단일 호출로 여러 서비스에 걸쳐 최대 20개의 AWS 리소스에서 하나 이상의 태그를 제거합니다. 리소스에 존재하지 않는 태그 키를 제거해도 오류 없이 성공합니다.

<Callout variant="important">
  이 작업은 최상위 오류가 아닌 `response.FailedResourcesMap`에서 ARN별 부분 실패를 보고합니다. 일괄 처리에서 하나의 ARN이 실패하더라도 전체 호출이 실패하지는 않으므로 `success`이(가) `true`인 경우에도 `response.FailedResourcesMap`을(를) 확인하십시오.
</Callout>
