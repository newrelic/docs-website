기존 태그를 유지하면서 뉴렐릭 엔티티에 하나 이상의 태그를 추가합니다.

전제조건은 [뉴렐릭 태그 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites)을 참조하십시오.

## 태그 추가

작업 식별자는 `newrelic.tagging.addTags`입니다.

뉴렐릭 엔티티에 하나 이상의 태그를 추가합니다. 이미 존재하는 키에 값을 추가하면 기존 값을 대체하는 대신 덧붙입니다. `newrelic.nerdgraph.execute` 기반으로 구축되었습니다.
