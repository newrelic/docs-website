      다음 예제는 서비스, 긴급도, 본문 및 에스컬레이션 정책을 사용하여 새로운 PagerDuty 인시던트를 생성합니다.

        <tbody>
          <tr>
            <td>
              ```yaml
              name: create-pagerduty-incident
              description: Create a new PagerDuty incident
              steps:
                - name: create
                  type: action
                  action: pagerduty.incident.create
                  version: 1
                  inputs:
                    token: ${{ :secrets:pagerdutyApiToken }}
                    type: incident
                    title: Test incident
                    service:
                      id: P123456
                      type: service_reference
                    urgency: low
                    body:
                      type: incident_body
                      details: Test Body
                    incidentKey: a12345-b678910-c111213
                    escalationPolicy:
                      id: P54321
                      type: escalation_policy_reference
                    selectors:
                      - name: incidentId
                        expression: .responseBody | fromjson.incident.id
                  next: end
              ```
