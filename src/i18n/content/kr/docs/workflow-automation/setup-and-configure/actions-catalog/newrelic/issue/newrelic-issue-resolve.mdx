조치가 완료되면 열려 있는 뉴렐릭 공지 인텔리전스 이슈를 종료합니다.

전제조건은 [뉴렐릭 이슈 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/issue/newrelic-issue#prerequisites)을 참조하십시오.

## 이슈 해결

작업 식별자는 `newrelic.issue.resolve`입니다.

열려 있는 뉴렐릭 이슈(AI 이슈)를 해결하고, 문제 해결 단계가 완료되면 이슈를 닫습니다. 이슈의 상태가 `CLOSED` (으)로 전환되고 뉴렐릭은 이슈 레코드에 해결 방법을 기록합니다. `newrelic.nerdgraph.execute`을(를) 기반으로 구축되었습니다.
