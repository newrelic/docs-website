이 페이지는 워크플로우 자동화 액션 카탈로그에서 사용할 수 있는 AWS Simple Email Service(SES) 액션에 대한 참조를 제공합니다. 이러한 액션을 사용하여 이메일 템플릿을 생성, 업데이트, 검색 및 삭제하고 Amazon SES를 통해 이메일을 전송하십시오.

## 전제 조건

사전 요구 사항 및 자격 증명 설정에 대해서는 [AWS 자격 증명 설정](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials)을 참조하십시오.

## 템플릿 생성

작업 식별자는 `aws.ses.createTemplate`입니다.

템플릿화된 이메일을 전송하기 위해 Amazon SES에서 이메일 템플릿을 생성합니다.

<Callout variant="important">
`textPart` 또는 `htmlPart` 중 하나 이상을 제공해야 합니다. SES는 템플릿에 하나 이상의 형식으로 된 본문 콘텐츠가 포함되어야 합니다.
</Callout>

```yaml
name: create-ses-template
description: 'Create an email template in Amazon SES'
steps:
  - name: createWelcomeTemplate
    type: action
    action: aws.ses.createTemplate
    version: '1'
    inputs:
      awsRoleArn: "arn:aws:iam::123456789012:role/my-workflow-role"
      region: us-east-2
      templateName: WelcomeEmailTemplate
      subjectPart: "Welcome to Our Service"
      textPart: "Hello, welcome aboard."
      htmlPart: "<h1>Hello</h1><p>Welcome aboard.</p>"
    next: end
```

## 대량 템플릿 이메일 전송

작업 식별자는 `aws.ses.sendBulkTemplatedEmail`입니다.

수신자별 템플릿 데이터 대체를 사용하여 단일 호출로 여러 수신자에게 템플릿화된 이메일을 전송합니다. `source` 주소와 참조된 `template`이(가) 이미 존재해야 합니다.

<Callout variant="important">
AWS는 이 작업을 호출당 50개의 `destinations` 항목으로 제한하며, 대상당 최대 50명의 수신자(To/Cc/Bcc 합계)와 최대 10MB의 생성된 메시지 크기를 허용합니다. 이러한 제한 중 하나라도 초과하면 전송 시 AWS API 오류가 발생합니다.
</Callout>

`destinations`의 각 항목은 다음 필드를 허용합니다:

* `destination` ― **필수 항목입니다.** `toAddresses`, `ccAddresses` 및/또는 `bccAddresses` (각각 문자열 목록)가 포함된 객체입니다.
* `replacementTemplateData` — **옵션.** 수신자별 플레이스홀더 값의 JSON 문자열입니다. 이 수신자에 대해 `defaultTemplateData`을(를) 재정의합니다.
* `replacementTags` — **옵션.** 이 수신자에 대해 `defaultTags`을(를) 재정의하는 `{"name": "...", "value": "..."}` 객체의 목록입니다.
