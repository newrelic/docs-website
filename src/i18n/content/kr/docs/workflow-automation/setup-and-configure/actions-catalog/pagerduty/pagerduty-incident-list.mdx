## PagerDuty 목록 인시던트

작업 식별자는 `pagerduty.incident.list`입니다.

날짜 범위 및 상태와 같은 선택적 필터링 파라미터를 사용하여 PagerDuty에서 인시던트 목록을 가져옵니다. `parameters` 맵을 통해 [PagerDuty 인시던트 목록 API](https://developer.pagerduty.com/api-reference/9d0b4b12e36f9-list-incidents)에서 사용할 수 있는 모든 쿼리 파라미터를 지원합니다.
