작업 식별자는 `newrelic.alerts.createMutingRule`입니다.

조건과 일치하는 위반에 대한 공지를 억제하는 새 뮤팅 규칙을 생성합니다. 선택적으로 규칙을 반복 또는 일회성 유지 관리 기간으로 예약합니다.

      다음 예제는 반복되는 주말 유지보수 기간 동안 정책에 대한 알림을 억제하는 뮤팅 규칙을 생성합니다.

      <table>
        <thead>
          <tr>
            <th>
              워크플로 예
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: create_muting_rule
              description: Create a muting rule for a maintenance window
              steps:
                - name: createMutingRule
                  type: action
                  action: newrelic.alerts.createMutingRule
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    name: "Deploy window - checkout service"
                    enabled: true
                    condition:
                      operator: "AND"
                      conditions:
                        - attribute: "policyName"
                          operator: "EQUALS"
                          values:
                            - "Checkout Service"
                    schedule:
                      startTime: "2026-09-01T02:00:00"
                      endTime: "2026-09-01T04:00:00"
                      timeZone: "America/Los_Angeles"
                      repeat: "WEEKLY"
                      weeklyRepeatDays:
                        - "SATURDAY"
                        - "SUNDAY"
                    selectors:
                      - name: mutingRuleId
                        expression: ".data.alertsMutingRuleCreate.id"
                  next: end
              ```
            </td>
          </tr>
