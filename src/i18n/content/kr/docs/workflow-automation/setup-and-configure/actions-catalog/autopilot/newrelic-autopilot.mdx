이 페이지는 워크플로우 자동화 액션 카탈로그에서 사용할 수 있는 **Run Autopilot** 액션(`newrelic.autopilot.run`)에 대한 참조를 제공합니다.

## Autopilot 실행 [#newrelic-autopilot-run]

뉴렐릭 Autopilot을 실행합니다 ― 알림을 분석하고, 잠재적인 근본 원인을 조사하며, 문제 해결 작업을 제안하는 AI 에이전트입니다. 워크플로우 편집기의 작업 카탈로그에서 **Run Autopilot**을 선택합니다 ― 에이전트 ID를 지정할 필요가 없습니다.

    <TabsPageItem id="runautopilotexample">
      ```yaml
      name: demo-run-autopilot
      description: Run Autopilot to analyze an issue
      steps:
        - name: runAutopilot
          type: action
          action: newrelic.autopilot.run
          version: '1'
          inputs:
            prompt: Summarize recent alert activity for my account
            context:
              - description: accountId
                value: "12345678"
              - description: slack_channel_id
                value: "CXXXXXXXXX"
            selectors:
              - name: success
                expression: .success
              - name: error
                expression: .errorMessage
              - name: response
                expression: .response
      ```
