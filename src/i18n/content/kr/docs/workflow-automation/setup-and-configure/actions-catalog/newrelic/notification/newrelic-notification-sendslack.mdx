      ## 지원되는 블록 유형 [#supported-block-types]

      `sendSlack` 작업은 두 가지 블록 유형만 지원하며 유효성 검사 중 다른 모든 유형을 거부합니다.

          <tr>

          <tr>
            <td>
              `section`
            </td>

            <td>
              텍스트를 렌더링하는 유일한 블록 유형입니다. 

              `text`

               객체의 

              `type`

              은(는) 

              `mrkdwn`

               또는 

              `plain_text`

              이어야 하며, 

              `text`

              은(는) 비어 있지 않은 문자열이어야 합니다.
            </td>

              `type`

              , 

              `text`

            </td>

            <td>
              `type`
            </td>

            <td>
              `{"type":"divider"}`
            </td>
          </tr>
