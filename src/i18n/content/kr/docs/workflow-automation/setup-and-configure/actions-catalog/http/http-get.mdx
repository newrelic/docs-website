이 페이지는 자동화 액션 카탈로그에서 사용 가능한 HTTP Get에 대한 포괄적인 참조 정보를 제공합니다. 이러한 작업을 통해 HTTP GET 요청 작업을 수행할 수 있습니다.

## 전제 조건

사전 요구 사항은 [HTTP 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/http/http#prerequisites)을 참조하십시오.

## 웹 데이터 GET [#http-get]

API 엔드포인트에서 데이터를 검색하려면 HTTP GET 호출을 수행합니다.

<Callout variant="important">
  입력에 민감한 데이터(예: `Api-Key` 헤더)를 전달해야 하는 경우 [secretsManagementCreateSecret](https://onenr.io/0KQXX6BmdQa) NerdGraph 뮤테이션을 통해 저장된 값을 사용할 수 있습니다.

  **예시**

  ```yaml
  {
    "inputs": [
      {
        "key": "headers",
        "value": "{\"Api-Key\": \"${{ :secrets:NR_API_KEY }}\"}"
      }
    ]
  }
  ```
</Callout>

      ### 선택기

      **목적:** API 응답에서 특정 데이터를 추출합니다.

      **구조:**

      * `name`추출된 값을 저장할 변수 이름
      * `expression`응답을 파싱할 JSONPath 또는 표현식
      * JSON 응답을 구문 분석하려면 `responseBody | fromjson` 사용하세요.
      * 점 표기법(예: `.abbreviation`)을 사용한 추가 필터
