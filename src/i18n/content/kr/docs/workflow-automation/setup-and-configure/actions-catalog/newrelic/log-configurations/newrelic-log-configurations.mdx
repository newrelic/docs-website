이 페이지는 워크플로우 자동화 액션 카탈로그에서 사용할 수 있는 뉴렐릭 Logs 설정 액션에 대한 참조를 제공합니다. 이러한 액션을 사용하여 로그 설정 리소스 — 파싱 규칙, 데이터 파티션 규칙, 난독화 표현식 및 규칙, 파이프라인 설정 — 를 쿼리하고, 워크플로우 정의에서 직접 Grok 패턴 검증 및 파이프라인 설정 업데이트와 같은 작업을 수행하십시오.

## 전제 조건

워크플로우 자동화에서 뉴렐릭 Logs 설정 작업을 사용하기 전에 다음을 확인해 주십시오:

* 로그 관리 설정에 액세스할 수 있는 적절한 권한을 가진 뉴렐릭 계정입니다.
* 로그 설정을 쿼리하거나 업데이트하려는 각 계정의 계정 ID입니다.
