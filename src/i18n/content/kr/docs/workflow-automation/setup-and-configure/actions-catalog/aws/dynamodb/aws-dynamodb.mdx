이 페이지는 워크플로우 자동화 액션 카탈로그에서 사용할 수 있는 AWS DynamoDB 액션에 대한 참조를 제공합니다. 이러한 액션을 사용하여 DynamoDB 테이블의 항목을 읽고, 쓰고, 업데이트하고, 삭제하며, 워크플로우 정의에서 직접 테이블 설정을 검사하거나 수정하십시오.

## 전제 조건

사전 요구 사항 및 자격 증명 설정에 대해서는 [AWS 자격 증명 설정](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials)을 참조하십시오.

모든 DynamoDB 작업은 동일한 인증 입력을 허용합니다. `awsRoleArn` (권장) 또는 액세스 키 쌍을 사용하십시오.

**예시**

```yaml
name: put-dynamodb-item
description: Write an order item to DynamoDB
steps:
  - name: putOrderItem
    type: action
    action: aws.dynamodb.putItem
    version: '1'
    inputs:
      awsRoleArn: ${{ :secrets:awsRoleArn }}
      region: us-east-2
      tableName: Orders
      item:
        orderId: { "S": "123" }
        status: { "S": "PLACED" }
    next: end
```

    version: '1'
    inputs:
      awsRoleArn: ${{ :secrets:awsRoleArn }}
