작업 식별자는 `newrelic.alerts.createBaselineNrqlCondition`입니다.

공지 정책 아래에 새로운 기준 NRQL 공지 조건을 생성합니다. 기준 조건은 과거 동작을 기반으로 신호의 예상 범위를 동적으로 예측하며, 실시간 신호가 구성된 임계값 이상으로 예측된 기준에서 벗어날 때 위반을 엽니다.

`terms` 또는 `expiration` (`openViolationOnExpiration: true` 포함) 중 적어도 하나를 제공해야 합니다. 둘 다 생략하면 NerdGraph 유효성 검사에 실패합니다.

    <TabsPageItem id="condition-baseline-create-example">
      다음 예제는 처리량이 예상 범위를 상회할 때 알림을 보내는 기준 NRQL 조건을 생성합니다.

      <table>
        <thead>
          <tr>
            <th>
              워크플로 예
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: create_baseline_nrql_condition
              description: Create a baseline NRQL alert condition
              steps:
                - name: createBaselineCondition
                  type: action
                  action: newrelic.alerts.createBaselineNrqlCondition
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    policyId: ${{ .workflowInputs.policyId }}
                    name: "Anomalous throughput"
                    nrqlQuery: "SELECT count(*) FROM Transaction WHERE appName = 'MyApp'"
                    enabled: true
                    baselineDirection: "UPPER_ONLY"
                    terms:
                      - priority: "WARNING"
                        operator: "ABOVE"
                        threshold: 20
                        thresholdDuration: 600
                        thresholdOccurrences: "ALL"
                    selectors:
                      - name: conditionId
                        expression: ".data.alertsNrqlConditionBaselineCreate.id"
                  next: end
              ```
            </td>
