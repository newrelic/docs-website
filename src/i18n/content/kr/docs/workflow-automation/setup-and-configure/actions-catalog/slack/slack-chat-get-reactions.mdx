구성 가능한 타임아웃까지 대기하여 Slack 메시지의 이모지 반응을 가져옵니다.

전제 조건은 [Slack 채팅 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/slack/slack-chat#prerequisites)을 참조하십시오.

## 메시지 반응 받기

작업 식별자는 `slack.chat.getReactions`입니다.

Slack 채널에서 메시지의 반응을 가져옵니다.

      **예시: Slack 메시지 반응 가져오기**

      <table>
        <thead>
          <tr>
            <th>
              워크플로 예

          <tr>
            <td>
              ```yaml
              name: GetReactions

              steps:
                - name: getReactions
                  type: action
                  action: slack.chat.getReactions
                  version: 1
                  inputs:
                    token: ${{ :secrets:dn_staging_slack_token }}
                    channelID: ${{ .steps.promptUser.outputs.channelID }}
                    threadTs: ${{ .steps.promptUser.outputs.threadTs }}
                    timeout: ${{ .workflowInputs.timeout }}
                    selectors: ${{ .workflowInputs.selectors }}
              ```

              **입력값:**

              ```json
              {
                "inputs": [
                  {
                    "key" : "channelID",
                    "value" : "C063JK1RHN1"
                  },
                  {
                    "key" : "threadTs",
                    "value" : "1718897637.400609"
                  },
                  {
                    "key" : "selectors",
                    "value" : "[{\"name\": \"reactions\", \"expression\": \".reactions \"}]"
                  }
                ]
              }
              ```

              **출력:**

              ```json
              [
                {
                  "name": "grinning",
                  "users": ["W222222"],
                  "count": 1
                },
                {
                  "name": "question",
                  "users": ["W333333"],
                  "count": 1
                }
              ]
              ```

              반응이 추가되기 전에 타임아웃이 만료되면 출력은 빈 목록입니다: `[]`
            </td>
