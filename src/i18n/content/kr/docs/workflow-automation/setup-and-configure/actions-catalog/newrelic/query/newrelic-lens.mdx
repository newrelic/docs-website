이 페이지는 워크플로우 자동화 액션 카탈로그에서 사용할 수 있는 뉴렐릭 Lens 액션에 대한 참조를 제공합니다. 이러한 액션을 사용하면 워크플로우 단계에서 직접 뉴렐릭 Lens를 통해 연결된 데이터 소스에 대해 ANSI SQL 쿼리를 실행할 수 있습니다.

## 전제 조건

워크플로우 자동화에서 뉴렐릭 Lens 작업을 사용하기 전에 다음을 갖추고 있는지 확인하십시오:

* 적절한 권한이 있는 뉴렐릭 계정.
* 뉴렐릭 Lens에 연결된 하나 이상의 데이터 소스입니다.
* 뉴렐릭 Lens 서비스에 필요한 권한

## 쿼리 Lens

작업 식별자는 `newrelic.lens.query`입니다.

뉴렐릭 Lens를 통해 연결된 데이터 소스에 대해 ANSI SQL 쿼리를 실행합니다.
