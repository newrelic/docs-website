저장소의 GitHub Actions 워크플로우 실행 목록을 나열하며, 워크플로우, 브랜치, 이벤트, 상태 등을 기준으로 선택적 필터링을 제공합니다. `workflowId`이(가) 제공되는 경우 목록은 해당 특정 워크플로우로 범위가 지정되며, 그렇지 않은 경우 저장소의 모든 워크플로우에 대한 실행을 반환합니다.

인증 설정에 대해서는 [GitHub 워크플로우 실행 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run)을 참조하십시오.

<tr>
<td>
```yaml
name: list_workflow_runs
description: List GitHub Actions workflow runs for a specific workflow
steps:
  - name: list_runs
    type: action
    action: gitHub.workflowRun.list
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      workflowId: deploy.yml
      branch: main
      status: completed
      resultsPerPage: 10
      selectors:
        - name: totalCount
          expression: ".total_count"
        - name: latestRunId
          expression: ".workflow_runs[0].id"
        - name: latestConclusion
          expression: ".workflow_runs[0].conclusion"
    next: end
```
