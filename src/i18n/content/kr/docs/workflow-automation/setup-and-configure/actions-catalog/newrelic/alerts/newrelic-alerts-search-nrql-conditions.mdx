작업 식별자는 `newrelic.alerts.searchNrqlConditions`입니다.

이름, 정책, NRQL 쿼리 텍스트 또는 terms 연산자로 선택적으로 필터링하여 NRQL 공지 조건(정적 또는 기준)을 검색합니다. 커서 기반 페이지네이션을 지원합니다. 모든 필터를 생략하면 계정의 모든 조건을 반환합니다.

      <table>
        <thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: search_nrql_conditions
              description: Search NRQL alert conditions
              steps:
                - name: searchConditions
                  type: action
                  action: newrelic.alerts.searchNrqlConditions
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    policyId: ${{ .workflowInputs.policyId }}
                    nameLike: "error rate"
                    selectors:
                      - name: nrqlConditions
                        expression: ".data.actor.account.alerts.nrqlConditionsSearch.nrqlConditions"
                  next: end
              ```
