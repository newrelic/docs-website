이 페이지는 워크플로우 자동화 액션 카탈로그에서 사용할 수 있는 AWS Bedrock 액션에 대한 참조를 제공합니다. 이 액션을 사용하여 워크플로우 정의의 일부로 Bedrock 에이전트를 호출하십시오.

## 전제 조건

사전 요구 사항 및 자격 증명 설정에 대해서는 [AWS 자격 증명 설정](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials)을 참조하십시오.

## 베드락 에이전트를 호출합니다

작업 식별자는 `aws.bedrock.invokeAgent`입니다.

프롬프트를 사용하여 AWS Bedrock 에이전트를 호출하고 에이전트의 응답을 반환합니다.
