뉴렐릭 엔티티에서 하나 이상의 태그 키와 그 아래의 모든 값을 제거합니다.

전제조건은 [뉴렐릭 태그 작업](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites)을 참조하십시오.

## 태그 삭제

작업 식별자는 `newrelic.tagging.deleteTags`입니다.

뉴렐릭 엔티티에서 하나 이상의 태그 키와 그 아래의 모든 값을 제거합니다. 동일한 키 아래의 다른 값을 유지하면서 특정 값만 제거하려면 대신 [`newrelic.tagging.deleteTagValues`](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging-deletetagvalues)을(를) 사용하십시오. `newrelic.nerdgraph.execute`을(를) 기반으로 구축되었습니다.
