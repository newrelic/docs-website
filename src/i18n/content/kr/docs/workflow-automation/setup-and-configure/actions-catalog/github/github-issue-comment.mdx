            <td>

            <td>
              문자열

            <td>
              **필수 항목입니다.**

               시크릿으로 저장된 GitHub 개인 액세스 토큰(세분화된 또는 클래식). 세분화된 PAT는 Issues: Read and write 권한이 필요합니다. 클래식 PAT는 리포지터리 범위가 필요합니다.
            </td>

            <td>
              `"${{ :secrets:github-PAT-token }}"`
            </td>
          </tr>

          <tr>
            <td>
              **owner**
            </td>

            <td>
              문자열
            </td>

            <td>

               저장소의 계정 소유자(사용자 또는 조직 로그인). 대소문자를 구분하지 않습니다.
            </td>

            <td>
              `"octocat"`
            </td>
          </tr>

          <tr>

              **repo**
            </td>

            </td>

               .git 접미사가 없는 접미사. 대소문자를 구분하지 않습니다.
            </td>

            <td>
              `"Hello-World"`
            </td>
          </tr>

          <tr>
            <td>
              **issueNumber**
            </td>

            <td>
              Int
            </td>

               이슈를 식별하는 번호입니다.
            </td>

            <td>
              `1347`

            </td>

            <td>

              ```yaml
              name: github_comment_issue_workflow
              description: Add a comment to a GitHub issue
              steps:
                - name: add_comment
                  type: action
                  action: gitHub.issue.comment
                  version: 1
                  inputs:
                    token: ${{ :secrets:github-PAT-token }}
                    owner: your_user_name
                    repo: test-workflow
                    issueNumber: 7
                    body: |
                      This issue has been investigated.
                      Runbook: https://runbooks.example.com/checkout-5xx
                  next: end
              ```
