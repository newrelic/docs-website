이 페이지는 워크플로우 자동화 액션 카탈로그에서 사용할 수 있는 모든 PagerDuty 인시던트 액션에 대한 참조를 제공합니다. 이러한 액션을 사용하여 워크플로우에서 직접 PagerDuty 인시던트를 생성, 검색, 나열, 업데이트 및 해결하십시오.

## 전제 조건

워크플로우 자동화에서 PagerDuty 작업을 사용하기 전에 다음이 필요합니다:

* 인시던트를 관리할 수 있는 적절한 권한을 가진 PagerDuty 계정.
* PagerDuty API 토큰(사용자 토큰 또는 계정 토큰).
* 요청하는 사용자의 `from` 이메일 주소입니다(관련 작업의 계정 토큰에 필요합니다).
