뉴렐릭 사용자로서, 여러 대시보드에 걸쳐 복잡한 NRQL 쿼리를 반복적으로 작성하는 경우가 있을 수 있습니다. 매번 여러 줄의 쿼리를 기억하고 다시 작성하는 것은 시간이 많이 소요되며 오류가 발생하기 쉽습니다. 데이터가 변경되어 쿼리를 조정해야 하는 경우, 조직 전체에서 해당 쿼리의 각 인스턴스를 수동으로 업데이트해야 하므로 유지 관리 부담이 크게 증가합니다.

NRQL 매크로는 NRQL 표현식을 재사용 가능한 명명된 바로 가기로 저장할 수 있도록 하여 이 문제를 해결합니다. 쿼리에서 `$` 기호 뒤에 매크로 이름(예: `$prod_filter`)을 붙여 매크로를 참조하면, 쿼리가 실행되기 전에 뉴렐릭이 저장된 표현식으로 대체합니다. [쿼리 빌더](/docs/query-your-data/explore-query-data/query-builder/introduction-query-builder/) 및 대시보드에서 매크로를 사용할 수 있습니다.

## 매크로를 활용하여 할 수 있는 일 [#macros-features]

NRQL 매크로를 사용하여 다음을 수행할 수 있습니다:

* **재사용 가능한 표현식 생성**: NRQL 쿼리의 표현식을 기술적인 이름을 가진 매크로로 변환하여, 매번 전체 표현식을 다시 입력하거나 기억할 필요가 없도록 하십시오.
* **계정 간 표현식 재사용**: 매크로는 조직 수준의 엔티티입니다. 조직의 모든 계정은 매크로를 재정의하지 않고도 사용할 수 있으며, 적절한 역할을 가진 모든 사용자는 조직 내에서 생성된 모든 매크로에 액세스하고 사용할 수 있습니다.
* **중앙에서 쿼리 업데이트**: 매크로를 편집하면 모든 쿼리를 개별적으로 찾아 업데이트할 필요 없이 해당 매크로를 사용하는 모든 쿼리에 변경 사항이 자동으로 반영됩니다.

## 전제 조건 [#prerequisites]

NRQL 매크로를 사용하려면 다음이 필요합니다:

* **계정 액세스**: 매크로를 사용하려는 조직의 계정에 대한 액세스 권한입니다. 매크로는 조직 수준의 엔티티이므로, 한 번 생성되면 조직 내 모든 계정에서 사용할 수 있습니다.
* **NRQL 지식**: 매크로의 표현식은 NRQL 표현식이므로 [NRQL 구문](/docs/nrql/get-started/introduction-nrql-how-nrql-works/)에 대한 기본 지식이 필요합니다.

## 매크로 권한 [#macro-permissions]

매크로를 생성하거나 사용하기 전에 권한이 어떻게 작동하며 누가 매크로에 액세스할 수 있는지 이해하는 것이 중요합니다.

### 조직 협회 [#organization-association]

모든 매크로는 생성된 조직에 속하는 리소스입니다. 이런 연동은 영구적이며 변경할 수 없습니다. 매크로는 다른 조직 간에 공유할 수 없습니다. 조직이 삭제되면 매크로도 삭제됩니다. 사용자가 다른 조직으로 이동하면 이전 조직의 매크로에 액세스할 수 없습니다.

### 현재 권한 모델 [#current-permissions-model]

뉴렐릭 매크로는 액세스를 제어하기 위해 CRUD 기능이 있는 기본 제공 역할을 사용합니다. 매크로 액세스는 조직 수준에서만 가능하며 관리자가 설정합니다.
