<Callout variant="important">
  **인프라 에이전트 v1.73.0 이상에 대한 알려진 문제:** 필수 설정 파라미터가 누락되었거나 엄격한 Windows 그룹 정책 제한이 있는 시스템에서는 MSI 무인 설치(`/qn`)가 오류 **1603**으로 실패합니다.
</Callout>

## 문제 [#problem]

* v1.72.x에서는 설치가 작동했지만 v1.73.0 이상 버전에서는 실패합니다
* MSI 무인 설치가 오류 **1603**으로 종료됩니다.
* 강화되거나 CIS를 준수하는 Windows 시스템에서 발생합니다
* 서비스 `newrelic-infra` 이(가) 생성되지 않았습니다

## 원인 [#cause]

버전 v1.73.0부터 <DNT>Windows MSI</DNT> 인스톨러는 설치 단계에서 에이전트의 설정 파일을 자동으로 검증하고 생성하기 위해 지연된 <DNT>PowerShell</DNT> 사용자 지정 작업을 사용합니다.

이 오류는 일반적으로 다음 두 가지 원인 중 하나로 인해 발생합니다:

* **필수 설치 파라미터 누락(가장 일반적):** `/qn` (무인) 스위치를 사용할 때, `GENERATE_CONFIG=true` 및 `LICENSE_KEY=YOUR_LICENSE_KEY`를 명령줄 인수로 명시적으로 전달하지 않으면 인스톨러의 사용자 지정 작업 스크립트가 즉시 실패하고 설치를 롤백합니다(오류 1603).
* **Windows 그룹 정책 제한:** 강화되거나 CIS를 준수하는 <DNT>Windows</DNT> 시스템에서 그룹 정책 설정 `HKLM\SOFTWARE\Policies\Microsoft\Windows\Installer\DisableMSI` (`1` 또는 `2`으로 설정된 경우)은 이러한 지연된 <DNT>PowerShell</DNT> 사용자 지정 작업의 실행을 차단하여 1603 오류를 발생시킵니다.

## 해결책 [#solution]

### 1단계: 필수 파라미터가 전달되었는지 확인(주요 해결 방법)

무인 설치를 수행하는 경우 `msiexec.exe` 명령줄에서 직접 필수 설정 파라미터를 **반드시** 제공해야 합니다.

다음 파라미터가 포함된 구문을 사용하여 설치를 실행하고 있는지 확인하십시오:

```powershell
msiexec.exe /qn /i PATH\TO\newrelic-infra.msi GENERATE_CONFIG=true LICENSE_KEY=YOUR_LICENSE_KEY
```

<Callout title="메모">
  인스톨러가 무인 설치 루프를 성공적으로 완료하려면 이러한 파라미터가 필요합니다. 설치 후 외부 설정 관리 도구를 통해 `newrelic-infra.yml` 파일을 관리하거나 덮어쓰려는 경우에도 <DNT>MSI</DNT>이(가) 성공적으로 완료될 수 있도록 이러한 파라미터를 전달해야 합니다.
</Callout>

### 2단계: MSI 제한을 일시적으로 비활성화(강화된 시스템의 경우)

1단계에서 필수 파라미터를 전달한 후에도 설치가 오류 1603으로 계속 실패하는 경우, OS 보안 정책이 인스톨러의 사용자 지정 작업을 차단하고 있을 가능성이 높습니다.

설치 중 <DNT>DisableMSI</DNT> 제한을 일시적으로 비활성화하고 설치 후 즉시 복원하려면 다음 스크립트를 실행하십시오:

```powershell
# Store original value
$regPath = "HKLM:\SOFTWARE\Policies\Microsoft\Windows\Installer"
$origValue = (Get-ItemProperty -Path $regPath -Name DisableMSI -ErrorAction SilentlyContinue).DisableMSI

try {
    # Temporarily allow MSI custom actions
    if (-not (Test-Path $regPath)) { 
        New-Item -Path $regPath -Force | Out-Null 
    }
    Set-ItemProperty -Path $regPath -Name DisableMSI -Value 0 -Type DWord -Force
    
    # Run the installation with mandatory parameters
    msiexec.exe /qn /i PATH\TO\newrelic-infra.msi GENERATE_CONFIG=true LICENSE_KEY=YOUR_LICENSE_KEY
    
} finally {
    # Restore original value
    if ($null -ne $origValue) {
        Set-ItemProperty -Path $regPath -Name DisableMSI -Value $origValue -Type DWord -Force
    } else {
        Remove-ItemProperty -Path $regPath -Name DisableMSI -ErrorAction SilentlyContinue
    }
}
```

<DNT>DisableMSI</DNT> 정책이 존재하고 문제를 일으킬 가능성이 있는지 사전에 확인하려면 이 <DNT>PowerShell</DNT> 스크립트를 사용할 수 있습니다:

```powershell
$regPath = "HKLM:\SOFTWARE\Policies\Microsoft\Windows\Installer"
$disableMsi = (Get-ItemProperty -Path $regPath -Name DisableMSI -ErrorAction SilentlyContinue).DisableMSI

if ($null -eq $disableMsi -or $disableMsi -eq 0) {
    Write-Host "DisableMSI not set or set to 0 - Installation should work if mandatory parameters are supplied."
} else {
    Write-Host "WARNING: DisableMSI is set to $disableMsi - Installation will likely fail with error 1603 due to OS security policy."
    Write-Host "Use the Step 2 workaround script above to install successfully."
}
```
