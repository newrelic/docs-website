AWS 계정을 뉴렐릭과 원활하게 통합하려면 [CloudFormation 및 CloudWatch Metric Streams를 통한 통합](/docs/infrastructure/amazon-integrations/aws-integration-for-metrics/via-cloudformation) 을 권장합니다. CloudFormation 템플릿을 사용할 수 없고 Terraform을 사용하고 싶지 않은 경우, 다음 절차에 따라 AWS 콘솔에서 수동으로 통합하십시오.

<Callout variant="tip">
  * 여러 AWS 계정을 관리하는 경우, [각 계정을 단일 뉴렐릭 계정에 연결](/docs/infrastructure/amazon-integrations/manage-aws-data/aws-multi-account)하십시오.
  * 해당 계정 내에서 여러 리전을 관리하는 경우, 각 리전마다 별도의 [Kinesis Data Firehose](#create-firehose) 를 생성하십시오.
</Callout>

<Steps>
  <Step>
    ## 전제 조건 [#prerequisites]

    AWS 계정을 뉴렐릭과 통합하기 전에 다음 필수 조건을 충족하는지 확인하세요.

    * **A 뉴렐릭 [Ingest - 볼륨 키 및 사용자 키](https://one.newrelic.com/api-keys)**: AWS 서비스를 뉴렐릭 계정에 연결하려면 이 키가 필요합니다.
    * 새로운 AWS 리소스를 배포하기 위한 **[권한](https://docs.aws.amazon.com/ARG/latest/userguide/gettingstarted-prereqs-permissions.html)** 및 **[IAM 역할](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_roles.html)**: AWS 계정에 이 권한이 필요합니다.
    * 클라우드 통합을 위한 **[권한](/docs/accounts/accounts-billing/new-relic-one-user-management/user-permissions/#infrastructure)**: 뉴렐릭 계정에 이러한 권한이 필요합니다.
  </Step>

  <Step>
    ## Kinesis Data Firehose 전송 스트림 생성 [#create-firehose]

    AWS 콘솔에서 전송 스트림에 대해 다음 대상 파라미터를 설정하십시오:

    * 소스: <DNT>Direct PUT</DNT> 또는 기타 소스

    * 목적지: New Relic

    * 데이터 변환: <DNT>Disabled</DNT>

    * 레코드 포맷 변환: <DNT>Disabled</DNT>

    * 다음 설정이 정의되어 있는지 확인하십시오.

      * 뉴렐릭 설정(대상 설정):

        * HTTP 엔드포인트 URL:

          * 미국 데이터 센터: `https://aws-api.newrelic.com/cloudwatch-metrics/v1`
          * EU 데이터 센터: `https://aws-api.eu01.nr-data.net/cloudwatch-metrics/v1`
          * JP 데이터 센터: `https://aws-api.jp.nr-data.net/cloudwatch-metrics/v1`

        * API 키:<InlinePopover type="licenseKey" />

        * 콘텐츠 인코딩: `GZIP`

        * 재시도 기간: `60`

        * 뉴렐릭 버퍼 조건:

          * 버퍼 크기: `1 MB`
          * 버퍼 간격: `60 (seconds)`

      * S3 백업 모드: <DNT>Failed data only</DNT>

      * S3 백업 버킷: 전송에 실패한 메트릭을 저장할 버킷을 선택하거나 새로 만듭니다.

      * 고급 설정:
        * 서비스 액세스: IAM 역할에 대한 권한을 제공합니다:
          * <DNT>Create or update IAM role</DNT>
  </Step>

  <Step>
    ## CloudWatch Metric Streams 생성 [#create-metric-stream]

    1. AWS 콘솔에서 <DNT>**CloudWatch service**</DNT>(으)로 이동하여 <DNT>**Metrics**</DNT> 메뉴 아래의 <DNT>**Streams**</DNT> 을(를) 선택하고 <DNT>**Create metric stream**</DNT>을(를) 클릭하십시오.
    2. 어떤 AWS 서비스가 뉴렐릭으로 메트릭을 전송할지 제어하려면, 포함 및 제외 필터를 구성하십시오.
    3. Firehose 전송 스트림 목록에서 생성한 스트림을 선택한 다음, 메트릭 스트림에 의미 있는 이름(예: `newrelic-metric-stream`)을 입력하십시오.
    4. 출력 형식 필드에서 `Open Telemetry 0.7` 또는 `Open Telemetry 1.0`을(를) 선택합니다. JSON은 지원되지 않습니다.
  </Step>

  <Step>
    ## AWS 계정을 뉴렐릭에 연결 [#connect-aws-account]

    1. 뉴렐릭에서 [<DNT>**Infrastructure &gt; AWS**</DNT>](https://one.newrelic.com/infra/infrastructure/cloud-aws)(으)로 이동하세요.

    2. 올바른 계정을 선택하세요.

    3. <DNT>**Set up integration**</DNT> 을(를) 클릭합니다.

    4. 각 화면에서 해당되는 필드를 작성합니다. 이 통합을 위해 다음 옵션을 선택하세요:

       * <DNT>**Choose Data type(s)**</DNT>: <DNT>Metrics</DNT>
       * <DNT>**Choose a setup method**</DNT>: <DNT>Manually integrate your AWS account</DNT>

    5. <DNT>**Select services**</DNT> 화면에서 필요한 경우 <DNT>**Show resources not supported by CloudWatch Metric Streams**</DNT> 을(를) 전환하고 모니터할 서비스를 선택한 후 계속합니다.

    6. <DNT>**Choose data integration type**</DNT> 화면에서 다음 옵션 중에서 선택할 수 있습니다:

       * **실시간 AWS 모니터링(권장)**: 이 옵션은 CloudWatch Metric Streams를 지원하는 서비스를 위한 것입니다.
       * **API 폴링**: 이 옵션은 CloudWatch Metric Streams에서 지원하지 않는 서비스를 위한 것입니다.

    7. <DNT>**Create role**</DNT> 페이지에서 <DNT>**Configure budgets policy**</DNT> 페이지까지 화면의 지침을 따르고 AWS 콘솔에서 단계를 완료하십시오.
  </Step>

  <Step>
    ## 데이터 검증 [#validate]

    메트릭 스트림에서 데이터를 수신하고 있는지 확인하려면:

    1. 뉴렐릭에서 <DNT>**[one.newrelic.com &gt; All capabilities &gt; Infrastructure &gt; AWS](https://one.newrelic.com/infra/infrastructure/cloud-aws)**</DNT>(으)로 이동하여 연결된 AWS 계정을 검색하고 **Stream** 계정을 찾으십시오.
    2. 계정 상태 대시보드에서 뉴렐릭이 오류와 수집된 네임스페이스 및 메트릭 수를 포함한 메트릭 데이터를 수신하고 있는지 확인합니다.
    3. 특정 메트릭을 탐색하려면 분석하려는 메트릭 세트에 대한 쿼리를 작성합니다.

    뉴렐릭이 새로운 리소스를 감지하고 이를 합성하는 데 몇 분이 걸릴 수 있습니다.

    <Callout variant="tip">
      AWS Billing과 같은 글로벌 서비스에 대한 AWS CloudWatch 지표는 <DNT>**us-east-1**</DNT> 리전에서만 사용할 수 있습니다. 해당 리전에 구성된 활성 CloudWatch Metric Streams가 있는지 확인합니다.
    </Callout>
  </Step>
</Steps>
