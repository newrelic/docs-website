설정 프로세스를 완료하면 Google Cloud Platform 계정의 데이터가 정기적인 [폴링 간격](/docs/infrastructure/google-cloud-platform-integrations/get-started/view-your-data/polling-intervals-gcp-integrations)으로 뉴렐릭에 직접 보고됩니다. 몇 분 안에 뉴렐릭 UI에 데이터가 표시됩니다.

## GCP 데이터 보기 [#view]

GCP 데이터를 보려면 다음 안내를 따르세요.

1. <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities)**</DNT> 으)로 이동합니다.
2. <DNT>**Google Cloud Platform**</DNT> 을(를) 검색하고 타일을 선택하십시오.

<InlinePopover type="Dashboards" />및 공지 설정에 대한 링크를 포함하여 [데이터를 찾고 사용](/docs/infrastructure/integrations/find-use-infrastructure-integration-data)하려면 <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP**</DNT>(으)로 이동하십시오.

## 데이터 쿼리 [#query]

사전 구성된 <InlinePopover type="Dashboards" />및 <DNT>**Events explorer**</DNT> 대시보드 모두에서 NRQL 쿼리를 확인하고 재사용할 수 있습니다. 이를 통해 특정 요구 사항에 맞게 쿼리를 조정할 수 있습니다.

이벤트, 대시보드 및 기타 데이터는 New Relic의 모든 서비스에서 사용할 수 있습니다.

## GCP 엔티티 [#entities]

전체 엔티티를 지원하는 서비스의 경우 GCP 리소스도 엔티티 탐색기에 엔티티로 표시됩니다. 각 엔티티에는 골든 메트릭과 사전 구축된 대시보드가 있는 요약 페이지가 있습니다.

새로운 리소스가 감지되어 엔티티로 합성되는 데 몇 분 정도 걸릴 수 있습니다. 자세한 내용은 [클라우드 통합 시스템 제한](/docs/data-apis/manage-data/view-system-limits)을 참조하십시오.

## 무엇 향후 계획 [#whats-next]

* 뉴렐릭이 각 서비스에 대해 수집하는 메트릭 이름을 찾아보려면 [GCP 통합 메트릭](/docs/infrastructure/google-cloud-platform-integrations/get-started/gcp-integration-metrics)을 참조하십시오.
* 뉴렐릭이 데이터를 폴링하는 빈도를 이해하려면 [GCP 통합의 폴링 간격](/docs/infrastructure/google-cloud-platform-integrations/get-started/view-your-data/polling-intervals-gcp-integrations)을 참조하십시오.
* 데이터가 예상대로 표시되지 않는 경우 [GCP 통합 문제 해결](/docs/infrastructure/google-cloud-platform-integrations/troubleshooting/troubleshooting-gcp-integrations)을 참조하십시오.
