이 연결 방법을 사용하면 뉴렐릭은 뉴렐릭에서 관리하는 서비스 계정 ID와 연결된 공개/비공개 키 쌍을 사용하여 GCP 프로젝트 API를 호출합니다. 서비스 계정이나 비공개 키를 생성하거나 관리할 필요가 없습니다 ― 프로젝트에 보기 권한이 있는 멤버로 서비스 계정 ID를 추가하기만 하면 됩니다. 뉴렐릭은 이 방법을 사용하여 가능한 한 태그 및 기타 속성을 수집합니다.

</Callout>

## GCP를 뉴렐릭에 연결하는 방법 [#connect]

<Callout variant="important">
  뉴렐릭에서 GCP를 처음 설정하는 경우 프로젝트에 클라우드 모니터링 API를 활성화했는지 확인하십시오. 이 작업은 [Google Cloud 콘솔](https://console.cloud.google.com/apis/api/monitoring.googleapis.com/)에서 수행할 수 있습니다.
</Callout>

서비스 계정 권한 부여를 사용하여 Google Cloud 프로젝트를 뉴렐릭에 연결하려면:

1. <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP**</DNT> 으)로 이동합니다. <DNT>**Google Cloud Services**</DNT> 통합 페이지에서 <DNT>**Add a GCP account**</DNT> 선택합니다.

2. <DNT>**Choose Authorization Method**</DNT>: <DNT>**Authorize a Service Account**</DNT>을(를) 선택하고 UI의 지침에 따라 뉴렐릭을 승인하십시오.

3. <DNT>**Add projects:**</DNT> 뉴렐릭이 데이터를 수신할 프로젝트를 선택하세요.

4. <DNT>**Select services:**</DNT> GCP 계정에 사용 가능한 서비스 목록에서 뉴렐릭이 데이터를 수신할 개별 서비스를 선택하거나 모든 서비스를 선택하세요.

   <Callout variant="tip">
     이전 단계에서 선택한 프로젝트 중 <DNT>**all**</DNT> 에 대해 이러한 서비스가 활성화됩니다. 설정 프로세스가 완료되면 각 프로젝트에 대해 개별적으로 모니터할 서비스를 미세 조정할 수 있습니다.
   </Callout>

5. 설정 프로세스를 완료하려면 <DNT>**Finish**</DNT> 선택합니다.

API 인증 오류가 표시되면 [문제 진단, 해결 절차](/docs/infrastructure/google-cloud-platform-integrations/troubleshooting/troubleshooting-gcp-integrations)를 따르십시오.

새로운 리소스가 감지되어 엔티티로 합성되는 데 몇 분 정도 걸릴 수 있습니다. 자세한 내용은 클라우드 통합 [시스템 제한](/docs/data-apis/manage-data/view-system-limits)을 참조하십시오.

## GCP 데이터 보기 [#find-data]

연결 후 뉴렐릭은 정기적인 [폴링 간격](/docs/infrastructure/google-cloud-platform-integrations/get-started/view-your-data/polling-intervals-gcp-integrations)으로 GCP 데이터 모니터링을 시작하며, 몇 분 후에 뉴렐릭 UI에 데이터가 표시됩니다. 데이터를 보고, 쿼리하고, 탐색하는 방법을 알아보려면 ― 대시보드, 알림 및 엔티티 포함 ― [GCP 데이터 보기 및 쿼리](/docs/infrastructure/google-cloud-platform-integrations/get-started/view-your-data/view-and-query-your-gcp-data)를 참조하십시오.

## 여러 Google 프로젝트 연결 [#connect-multiple]

설정 프로세스에서 한 번에 두 개 이상의 프로젝트를 선택할 수 있습니다.

첫 번째 설정 후 뉴렐릭으로 추가 GCP 프로젝트를 모니터하려면 필요한 만큼 [GCP 서비스 연결](#connect) 절차를 반복하십시오.

## GCP 통합 비활성화 또는 연결 해제 [#disconnect]

언제든지 통합을 비활성화할 수 있으며 Google 프로젝트를 뉴렐릭에 계속 연결된 상태로 유지할 수 있습니다.

### 하나 이상의 GCP 서비스 비활성화 [#disable-services]

GCP 계정을 New Relic에 연결된 상태로 유지하면서 서비스를 비활성화하려면:

1. <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; Manage services**</DNT> 으)로 이동합니다.
2. <DNT>**Edit GCP account**</DNT> 페이지에서 비활성화하려는 각 활성 서비스의 확인란을 선택 취소하세요.
3. 변경 사항을 저장합니다.

### 계정 연결 및 연동을 해제하십시오. [#unlink-account]

뉴렐릭과의 연결을 완전히 해제하려면, GCP 계정의 연결을 해제하십시오. 이렇게 하면 이와 연결된 모든 뉴렐릭 통합이 비활성화됩니다. 사용자 지정 역할을 삭제하는 경우, 해당 역할이 뉴렐릭 액세스 이외의 목적으로 사용될 수 있다는 점에 유의하십시오.

<DNT>**custom user role**</DNT> 의 경우:

1. 뉴렐릭에 로그인하고 <DNT>**Infrastructure &gt; Integrations &gt; Google Cloud Platform**</DNT> 로 이동합니다.
2. <DNT>**IAM &gt; admin &gt; Roles**</DNT> 으로 이동하여 역할을 검색하여 선택한 후 <DNT>**DELETE**</DNT> 을 선택합니다.

<DNT>**standard (non-custom) user role**</DNT> 의 경우:

1. 뉴렐릭에 로그인하고 <DNT>**Infrastructure &gt; Integrations &gt; Google Cloud Platform**</DNT> 로 이동합니다.
2. 제거하려는 계정에 대해 <DNT>**Manage services**</DNT> 선택합니다. <DNT>**User**</DNT> 값을 복사하고 저장합니다.
3. [Google Cloud](https://console.cloud.google.com/) 에 로그인하고 <DNT>**Select a project**</DNT> 상자에서 올바른 프로젝트를 선택합니다.
4. 탐색 메뉴에서 <DNT>**IAM &amp; admin &gt; IAM**</DNT> 선택합니다.
5. 저장한 사용자 값을 검색하여 선택한 다음 <DNT>**REMOVE**</DNT> 선택합니다.

### 연결 해제 후 GCP를 정리하십시오. [#clean-up]

연결 해제 후 GCP 프로젝트를 정리하려면:

1. GCP IAM 콘솔을 엽니다.
2. 뉴렐릭에서 연결을 해제할 프로젝트를 선택하고 <DNT>**Open**</DNT>을(를) 선택합니다.
3. 뉴렐릭에서 사용하는 서비스 계정을 선택하십시오.
4. <DNT>**Remove**</DNT> 아이콘을 선택하십시오.
