이 페이지는 뉴렐릭의 Google Cloud Platform(GCP) 통합과 관련된 일반적인 문제 및 해결 방법을 다룹니다.

## 설정 후 데이터가 표시되지 않음 [#no-data]

### 기본 사항을 확인하십시오. [#no-data-basics]

* 설정을 완료한 후 5분 동안 기다리십시오. 데이터가 도착하는 데 몇 분 정도 소요됩니다.
* 설정 중에 하나 이상의 서비스를 선택했는지 확인하십시오.
* GCP 프로젝트에서 <DNT>**Stackdriver Monitoring API**</DNT> 이(가) 활성화되어 있는지 확인하십시오.

### 워크로드 아이덴티티 페더레이션 통합 [#no-data-wif]

[워크로드 아이덴티티 연합(WIF)](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation)으로 연결한 경우:

* 5개의 [필수 API](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation#step-2) 가 모두 활성화되어 있는지 확인하십시오.
* 서비스 계정에 <DNT>**Viewer**</DNT> 및 <DNT>**Service Usage Consumer**</DNT> 역할이 있는지 확인하십시오.
* 서비스 계정의 풀 주 구성원에게 <DNT>**Workload Identity User**</DNT> 역할이 부여되었는지 확인하십시오.

### 서비스 계정 통합 [#no-data-sa]

[뉴렐릭 서비스 계정](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account)으로 연결한 경우:

* 프로젝트의 IAM에 뉴렐릭 서비스 계정 ID가 표시되는지 확인하십시오.
* <DNT>**Viewer**</DNT> 및 <DNT>**Service Usage Consumer**</DNT> 역할이 있는지 확인하십시오.
* [도메인 제한 제약 조건](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account#reqs)을 사용하는 경우 뉴렐릭이 허용되는지 확인하십시오.

## 인증 오류 [#auth-errors]

### 뉴렐릭 재인증 [#reauthorize]

[Google Cloud Platform(GCP) 서비스](/docs/introduction-google-cloud-platform-integrations) 를 뉴렐릭과 통합할 때 API 인증 오류가 표시되는 경우, 뉴렐릭이 GCP API를 사용하도록 다시 승인해 주십시오:

1. <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP**</DNT> 으)로 이동합니다.
2. GCP 계정 페이지에서 <DNT>**Reauthorize New Relic**</DNT> 선택합니다.
3. [GCP 서비스를 뉴렐릭에 연결](/docs/infrastructure/google-cloud-platform-integrations/get-started/connect-google-cloud-platform-services-new-relic)하려면 표준 절차를 따르십시오.

재인증으로 오류가 해결되지 않는 경우, 통합 연결을 해제하고 다시 연결할 수 있습니다. [연결 가이드](/docs/infrastructure/google-cloud-platform-integrations/get-started/connect-google-cloud-platform-services-new-relic)에서 연결 해제 단계를 확인하십시오.

이러한 오류의 일반적인 원인은 다음과 같습니다:

* 사용자가 Google 계정 관리 애플리케이션에서 뉴렐릭의 GCP API 사용 권한을 수동으로 취소했습니다.
* GCP API를 사용하기 위한 New Relic의 승인에는 하나 이상의 GCP API를 쿼리하는 데 필요한 하나 이상의 권한( [Google OAuth 범위](https://developers.google.com/identity/protocols/googlescopes) )이 포함되어 있지 않습니다.
* New Relic에 대한 GCP API 사용 권한이 만료되었습니다.

## 특정 서비스의 누락된 메트릭 [#missing-metrics]

* <DNT>**Infrastructure &gt; GCP &gt; Manage services**</DNT>에서 서비스가 활성화되어 있는지 확인하십시오.
* GCP 서비스 자체가 활성화되어 있고 메트릭을 생성하고 있는지 확인하십시오. 일부 서비스는 사용 중일 때만 메트릭을 보고합니다.
* [사용자 지정 IAM 역할](/docs/integrations/google-cloud-platform-integrations/get-started/integrations-custom-roles)을 사용하는 경우 해당 서비스에 대한 서비스별 권한이 있는지 확인하십시오.

## 오래되거나 지연된 메트릭 [#stale-metrics]

* Check the GCP Cloud Monitoring API quotas in your GCP project. If you&apos;re hitting rate limits, data collection can slow down. To request a higher quota:

  1. In the Google Cloud console, go to <DNT>**IAM &amp; Admin &gt; Quotas &amp; System Limits**</DNT>.
  2. <DNT>**Service: Cloud Monitoring API**</DNT> 기준으로 필터링합니다.
  3. Find the quota named <DNT>**Time series queries per minute**</DNT>, select it, and click <DNT>**Edit Quotas**</DNT> to request an increase.

* WIF 통합의 경우, 서비스 계정의 토큰이 철회되지 않았는지 확인하십시오.

* 보고된 오류가 있는지 <DNT>**Infrastructure &gt; GCP**</DNT> 의 계정 상태 대시보드를 확인하십시오.

## 설정 중 GCP 프로젝트가 표시되지 않음 [#no-projects]

* 인증된 계정은 프로젝트를 나열하기 위해 `resourcemanager.projects.get` 권한이 필요합니다.
* 또는 NerdGraph API를 사용하여 프로젝트를 나열할 필요 없이 ID로 연결하십시오.

## 추가 도움말 얻기 [#get-help]

위의 방법으로도 문제가 해결되지 않으면 다음 정보를 포함하여 뉴렐릭 지원팀에 문의하십시오:

* 귀하의 뉴렐릭 계정 ID입니다.
* GCP 프로젝트 ID입니다.
* 사용한 연결 방법(WIF 또는 서비스 계정)입니다.
* UI에 표시되는 모든 오류 메시지.
