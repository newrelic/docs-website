[뉴렐릭 통합](/docs/infrastructure/introduction-infra-monitoring) 에는 [Google Cloud Platform(GCP)](https://cloud.google.com/) 과의 [Google 클라우드 SQL](https://cloud.google.com/sql/docs/) 데이터를 뉴렐릭에 보고하는 통합이 포함되어 있습니다. 이 문서에서는 GCP 클라우드 SQL 통합을 활성화하는 방법과 보고되는 데이터에 대해 설명합니다.

## 특징

클라우드 SQL은 MySQL, PostgreSQL 및 SQL Server를 위한 Google Cloud의 완전 관리형 데이터베이스 서비스입니다. 뉴렐릭 클라우드 SQL 통합은 각 클라우드 SQL 인스턴스와 해당 데이터베이스에 대한 CPU, 메모리, 디스크, 연결, 복제 및 데이터베이스 수준 메트릭을 수집합니다.

## 통합 활성화 [#activate]

통합을 활성화하려면 표준 절차에 따라 [GCP 서비스를 뉴렐릭에 연결하십시오](/docs/connect-google-cloud-platform-services-infrastructure):

* [워크로드 아이덴티티 연합으로 연결(권장)](/docs/connect-google-cloud-platform-services-infrastructure)
* [서비스 계정 또는 사용자 계정으로 연결합니다.](/docs/connect-google-cloud-platform-services-infrastructure)

## 폴링 빈도 [#polling]

뉴렐릭 통합은 통합에 따라 달라지는 폴링 간격에 따라 GCP 서비스를 쿼리합니다. Google Cloud SQL의 폴링 주기는 5분입니다. 해상도는 1분마다 1개의 데이터 포인트입니다.

## 워크로드 아이덴티티 페더레이션 [#wif]

### 데이터 찾기 및 사용 [#find-data-wif]

통합을 활성화하면 클라우드 SQL 리소스가 뉴렐릭 엔티티 탐색기에 엔티티로 표시됩니다. 대시보드를 확인하고 서비스를 관리하려면 <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>(으)로 이동하십시오.

GCP 클라우드 모니터링에서 사용할 수 있는 모든 클라우드 SQL 메트릭은 `Metric` 이벤트 유형의 차원 메트릭으로 수집됩니다. 이 표 이외의 추가 메트릭은 자동으로 수집됩니다. 전체 목록은 [Google의 클라우드 SQL 메트릭 문서](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-cloudsql) 를 확인하십시오.

## 서비스 계정 또는 사용자 계정 [#service-account]

### 데이터 찾기 및 사용 [#find-data]

통합을 활성화하고 몇 분 정도 기다리면( [폴링 빈도](#polling) 에 따라) New Relic UI 에 데이터가 표시됩니다. <InlinePopover type="dashboards" />및 공지 설정에 대한 링크를 포함하여 [데이터를 찾고 사용](/docs/infrastructure/integrations/find-use-infrastructure-integration-data) 하려면 <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>)로 이동하세요.

New Relic에서 GCP SQL 통합에 대한 [측정항목 데이터](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics) 를 보려면 `GcpCloudSqlSample` [이벤트](/docs/data-apis/understand-data/new-relic-data-types/#event-data) 및 관련 속성에 대한 [NRQL 쿼리](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql) 를 만듭니다.
