[뉴렐릭 통합](/docs/infrastructure/introduction-infra-monitoring) 에는 [Google Cloud Platform(GCP)](https://cloud.google.com/) 과의 [Google Cloud Spanner](https://cloud.google.com/spanner/) 데이터를 뉴렐릭에 보고하는 통합이 포함됩니다. 이 문서에서는 GCP Cloud Spanner 통합을 활성화하는 방법과 보고되는 데이터에 대해 설명합니다.

## 특징 [#features]

Google Cloud Spanner는 cloud를 위해 구축된 전 세계적으로 분산된 관계형 데이터베이스 서비스입니다. 뉴렐릭 Spanner 통합은 각 Spanner 인스턴스와 해당 인스턴스에 호스팅된 데이터베이스에 대한 노드, CPU, 스토리지, 세션, API 요청 및 쿼리 메트릭을 수집합니다.

## 통합 활성화 [#activate]

통합을 활성화하려면 표준 절차에 따라 [GCP 서비스를 뉴렐릭에 연결하십시오](/docs/connect-google-cloud-platform-services-infrastructure):

* [워크로드 아이덴티티 연합으로 연결(권장)](/docs/connect-google-cloud-platform-services-infrastructure)
* [서비스 계정 또는 사용자 계정으로 연결합니다.](/docs/connect-google-cloud-platform-services-infrastructure)

## 폴링 빈도 [#polling]

뉴렐릭 통합은 통합에 따라 달라지는 폴링 간격에 따라 GCP 서비스를 쿼리합니다. Google Cloud Spanner의 폴링 주기는 5분입니다. 해상도는 1분마다 1개의 데이터 포인트입니다.

<Callout variant="important">
  Cloud Spanner는 제한된 프리뷰에서 WIF 통합을 위한 1분 폴링 간격을 지원합니다. 액세스를 요청하려면 [뉴렐릭 지원팀](https://support.newrelic.com/)에 문의하십시오.
</Callout>

## 워크로드 아이덴티티 페더레이션 [#wif]

### 데이터 찾기 및 사용 [#find-data-wif]

통합을 활성화하면 Spanner 리소스가 뉴렐릭 엔티티 탐색기에 엔티티로 표시됩니다. 대시보드를 확인하고 서비스를 관리하려면 <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>(으)로 이동하십시오.

GCP 클라우드 모니터링에서 사용할 수 있는 모든 Spanner 메트릭은 `Metric` 이벤트 유형에서 차원 메트릭으로 수집됩니다. 이 테이블 이외의 추가 메트릭은 자동으로 수집됩니다. 전체 목록은 [Google의 Spanner 메트릭 문서](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-spanner) 를 참조하십시오.

## 서비스 계정 또는 사용자 계정 [#service-account]

### 데이터 찾기 및 사용 [#find-data]

통합을 활성화하고 몇 분 정도 기다리면( [폴링 빈도](#polling) 에 따라) New Relic UI 에 데이터가 표시됩니다. <InlinePopover type="dashboards" />및 공지 설정에 대한 링크를 포함하여 [데이터를 찾고 사용](/docs/infrastructure/integrations/find-use-infrastructure-integration-data) 하려면 <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>)로 이동하세요.

New Relic에서 GCP Spanner 통합에 대한 [측정항목 데이터](/docs/integrations/new-relic-integrations/getting-started/#metric) 를 보려면 `GcpSpannerInstanceSample` 및 `GcpSpannerDatabaseSample` [이벤트](/docs/data-apis/understand-data/new-relic-data-types/#event-data) 와 관련 속성에 대한 [NRQL 쿼리](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql) 를 만듭니다.
