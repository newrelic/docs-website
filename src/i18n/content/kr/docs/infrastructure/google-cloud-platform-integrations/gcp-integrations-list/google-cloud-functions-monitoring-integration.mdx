[뉴렐릭 통합](/docs/infrastructure/introduction-infra-monitoring) 중 [Google Cloud Platform(GCP)](https://cloud.google.com/) 과의 통합에는 [Google Cloud Functions](https://cloud.google.com/functions/) 데이터를 뉴렐릭에 보고하는 통합이 포함됩니다. 이 문서에서는 GCP Cloud Functions 통합을 활성화하는 방법과 보고되는 데이터에 대해 설명합니다.

## 특징

Cloud Functions는 이벤트 기반 함수를 위한 Google Cloud의 서버리스 컴퓨트 서비스입니다. 뉴렐릭 Cloud Functions 통합은 각 함수의 실행 횟수, 실행 시간, 메모리 사용량 및 오류율 메트릭을 수집합니다.

## 통합 활성화 [#activate]

통합을 활성화하려면 표준 절차에 따라 [GCP 서비스를 뉴렐릭에 연결하십시오](/docs/connect-google-cloud-platform-services-infrastructure):

* [워크로드 아이덴티티 연합으로 연결(권장)](/docs/connect-google-cloud-platform-services-infrastructure)
* [서비스 계정 또는 사용자 계정으로 연결합니다.](/docs/connect-google-cloud-platform-services-infrastructure)

## 폴링 빈도 [#polling]

뉴렐릭 통합은 통합에 따라 달라지는 폴링 간격에 따라 GCP 서비스를 쿼리합니다. Google Cloud Functions의 폴링 주기는 5분입니다. 해상도는 1분마다 1개의 데이터 포인트입니다.

## 워크로드 아이덴티티 페더레이션 [#wif]

### 데이터 찾기 및 사용 [#find-data-wif]

통합을 활성화하면 Cloud Functions 리소스가 뉴렐릭 엔티티 탐색기에 엔티티로 표시됩니다. 대시보드를 확인하고 서비스를 관리하려면 <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>(으)로 이동하십시오.

GCP 클라우드 모니터링에서 사용할 수 있는 모든 Cloud Functions 메트릭은 `Metric` 이벤트 유형에서 차원 메트릭으로 수집됩니다. 이 표 이외의 추가 메트릭은 자동으로 수집됩니다. 전체 목록은 [Google의 Cloud Functions 메트릭 문서](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-cloudfunctions) 를 참조하십시오.

### 데이터 찾기 및 사용 [#find-data]

통합을 활성화한 후 ( [폴링 빈도](#polling) 에 따라) 몇 분 정도 기다리면 데이터가 UI에 표시됩니다. <InlinePopover type="dashboards" />링크 및 공지 설정을 포함한 [데이터를 보고 사용](/docs/infrastructure/integrations/find-use-infrastructure-integration-data) 하려면 <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT> 로 이동한 다음 통합을 선택하세요.
