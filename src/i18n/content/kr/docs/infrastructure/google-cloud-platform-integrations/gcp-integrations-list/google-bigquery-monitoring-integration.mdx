[뉴렐릭 통합](/docs/infrastructure/introduction-infra-monitoring) 과의 [Google Cloud Platform(GCP)](https://cloud.google.com/) 에는 [Google BigQuery](https://cloud.google.com/bigquery/) 데이터를 뉴렐릭에 보고하는 통합이 포함됩니다. 이 문서에서는 GCP BigQuery 통합을 활성화하는 방법과 보고되는 데이터에 대해 설명합니다.

## 특징

BigQuery는 Google Cloud의 서버리스 데이터 웨어하우스입니다. 뉴렐릭 BigQuery 통합은 프로젝트 및 데이터 세트 범위 모두에서 쿼리, 실행, 스토리지 및 슬롯 사용률 메트릭을 수집합니다.

## 통합 활성화 [#activate]

통합을 활성화하려면 표준 절차에 따라 [GCP 서비스를 뉴렐릭에 연결하십시오](/docs/connect-google-cloud-platform-services-infrastructure):

* [워크로드 아이덴티티 연합으로 연결(권장)](/docs/connect-google-cloud-platform-services-infrastructure)
* [서비스 계정 또는 사용자 계정으로 연결합니다.](/docs/connect-google-cloud-platform-services-infrastructure)

## 폴링 빈도 [#polling]

뉴렐릭 통합은 통합에 따라 달라지는 폴링 간격에 따라 GCP 서비스를 쿼리합니다. Google BigQuery의 폴링 주기는 5분입니다. 해상도는 1분마다 1개의 데이터 포인트입니다.

<Callout variant="important">
  BigQuery는 제한된 미리보기에서 WIF 통합을 위해 1분 폴링 간격을 지원합니다. 액세스를 요청하려면 [뉴렐릭 지원팀](https://support.newrelic.com/)에 문의하십시오.
</Callout>

## 테이블 측정항목 활성화 [#table-metrics]

BigQuery 테이블 측정항목 수집은 기본적으로 사용 중지되어 있습니다. 이는 [GcpBigQueryTableSample](#table-sample) 아래에 나열된 측정항목에 영향을 줍니다. 이러한 측정항목을 수집하려면 BigQuery 통합의 구성 메뉴에서 &apos;테이블 측정항목 사용&apos; 설정을 사용 설정하세요.

## 워크로드 아이덴티티 페더레이션 [#wif]

### 데이터 찾기 및 사용 [#find-data-wif]

통합을 활성화하면 BigQuery 리소스가 뉴렐릭 엔티티 탐색기에 엔티티로 표시됩니다. 대시보드를 확인하고 서비스를 관리하려면 <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>(으)로 이동하십시오.

GCP 클라우드 모니터링에서 사용할 수 있는 모든 BigQuery 메트릭은 `Metric` 이벤트 유형에서 차원 메트릭으로 수집됩니다. 이 표 이외의 추가 메트릭은 자동으로 수집됩니다. 전체 목록은 [Google의 BigQuery 메트릭 문서](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-bigquery) 를 참조하십시오.

### 데이터 찾기 및 사용 [#find-data]

통합을 활성화하고 몇 분 정도 기다리면( [폴링 빈도](#polling) 에 따라) New Relic UI 에 데이터가 표시됩니다. <InlinePopover type="dashboards" />및 공지 설정에 대한 링크를 포함하여 [데이터를 찾고 사용](/docs/infrastructure/integrations/find-use-infrastructure-integration-data) 하려면 <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>)로 이동하세요.

New Relic에서 Google BigQuery 통합에 대한 [측정항목 데이터](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics) 를 보려면 `GcpBigQueryProjectSample` , `GcpBigQueryDatasetSample` 및 `GcpBigQueryTableSample` [이벤트](/docs/using-new-relic/welcome-new-relic/getting-started/glossary#event) 와 해당 속성에 대한 [NRQL 쿼리를 만듭니다](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql) .
