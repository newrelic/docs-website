[Google Cloud Platform(GCP)](https://cloud.google.com/) 과의[뉴렐릭 통합](/docs/infrastructure/introduction-infra-monitoring) 에는 [Google Distributed Cloud Edge](https://cloud.google.com/distributed-cloud/edge) 데이터를 뉴렐릭에 보고하는 통합이 포함됩니다. 이 문서에서는 <DNT>GCP Distributed Cloud Edge</DNT> 통합을 활성화하는 방법과 보고되는 데이터에 대해 설명합니다.

## 특징

<DNT>Google Distributed Cloud Edge</DNT> 고객 소유 하드웨어에서 <DNT>Kubernetes</DNT> 워크로드를 실행하기 위한 <DNT>Google Cloud</DNT>의 관리형 온프레미스 에지 컴퓨팅 플랫폼입니다. 뉴렐릭의 <DNT>Distributed Cloud Edge</DNT> 통합은 배포 환경의 머신(노드) 및 에지 클러스터에 대한 하드웨어 인벤토리 및 상태 메트릭을 수집합니다: CPU, 메모리, 디스크, 네트워크, GPU 및 전원/PSU 텔레메트리, 그리고 클러스터 수명 주기 및 버전 상태.

## 통합 활성화 [#activate]

<Callout variant="important">
  이 통합은 <DNT>GCP</DNT> 프로젝트를 <DNT>**Workload Identity Federation**</DNT>과(와) 연결할 때만 사용할 수 있습니다. 서비스 계정 또는 사용자 계정 연결에는 사용할 수 없습니다.
</Callout>

통합을 활성화하려면 표준 절차에 따라 <DNT>**Workload Identity Federation**</DNT>을(를) 사용하여 [GCP 서비스를 뉴렐릭에 연결](/docs/connect-google-cloud-platform-services-infrastructure) 하십시오.

## 폴링 빈도 [#polling]

뉴렐릭 통합은 통합에 따라 달라지는 폴링 간격에 따라 <DNT>GCP</DNT> 서비스를 쿼리합니다. <DNT>Google Distributed Cloud Edge</DNT>의 폴링 빈도는 5분입니다. 해상도는 1분마다 1개의 데이터 포인트입니다.

## 워크로드 아이덴티티 페더레이션 [#wif]

### 데이터 찾기 및 사용 [#find-data-wif]

뉴렐릭은 <DNT>GCP Cloud Monitoring</DNT>에서 사용할 수 있는 모든 <DNT>Distributed Cloud Edge</DNT> 메트릭을 `Metric` 이벤트 유형의 차원 메트릭으로 수집합니다.

이 통합은 뉴렐릭 엔티티 탐색기에서 엔티티를 생성하지 않습니다. 예를 들어 `Metric` 이벤트 유형에서 직접 메트릭을 쿼리하십시오:

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'gcp.edgecontainer.%' FACET metricName
```

메트릭은 기본 머신 또는 에지 클러스터의 리소스 레이블을 포함하므로, 엔티티 없이도 클러스터 이름, 머신 ID 및 위치를 기준으로 패싯할 수 있습니다.
