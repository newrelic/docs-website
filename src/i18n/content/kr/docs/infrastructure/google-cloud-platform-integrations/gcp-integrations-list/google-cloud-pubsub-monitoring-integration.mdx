[뉴렐릭 통합](/docs/infrastructure/introduction-infra-monitoring) 에는 [Google Cloud Platform(GCP)](https://cloud.google.com/) 과의 [Google Cloud Pub/Sub](https://cloud.google.com/pubsub/) 데이터를 뉴렐릭에 보고하는 통합이 포함됩니다. 이 문서에서는 GCP Pub/Sub 통합을 활성화하는 방법과 보고하는 데이터에 대해 설명합니다.

## 특징

Google Cloud [스트림 분석 솔루션](https://cloud.google.com/solutions/stream-analytics)의 일환으로, Cloud Pub/Sub 서비스는 빠른 데이터 처리 및 분석을 위해 이벤트 스트림을 수집하고 전송합니다. 뉴렐릭 Pub/Sub 통합은 토픽, 구독 및 스냅샷 전반에 걸쳐 게시, 전송, 백로그 및 보존 메트릭을 수집합니다.

## 통합 활성화 [#activate]

통합을 활성화하려면 표준 절차에 따라 [GCP 서비스를 뉴렐릭에 연결하십시오](/docs/connect-google-cloud-platform-services-infrastructure):

* [워크로드 아이덴티티 연합으로 연결(권장)](/docs/connect-google-cloud-platform-services-infrastructure)
* [서비스 계정 또는 사용자 계정으로 연결합니다.](/docs/connect-google-cloud-platform-services-infrastructure)

## 폴링 빈도 [#polling]

뉴렐릭 통합은 통합에 따라 달라지는 폴링 간격에 따라 GCP 서비스를 쿼리합니다. Google Cloud Pub/Sub의 폴링 주기는 5분입니다. 해상도는 1분마다 1개의 데이터 포인트입니다.

<Callout variant="important">
  Cloud Pub/Sub는 제한된 미리 보기에서 WIF 통합을 위한 1분 폴링 간격을 지원합니다. 액세스를 요청하려면 [뉴렐릭 지원팀](https://support.newrelic.com/)에 문의하십시오.
</Callout>

## 워크로드 아이덴티티 페더레이션 [#wif]

### 데이터 찾기 및 사용 [#find-data-wif]

통합을 활성화하면 Pub/Sub 리소스가 뉴렐릭 엔티티 탐색기에 엔티티로 표시됩니다. 대시보드를 확인하고 서비스를 관리하려면 <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>(으)로 이동하십시오.

## 서비스 계정 또는 사용자 계정 [#service-account]

### 데이터 찾기 및 사용 [#find-data]

통합을 활성화하고 몇 분 정도 기다리면( [폴링 빈도](#polling) 에 따라) New Relic UI 에 데이터가 표시됩니다. <InlinePopover type="dashboards" />및 공지 설정에 대한 링크를 포함하여 [데이터를 찾고 사용](/docs/infrastructure/integrations/find-use-infrastructure-integration-data) 하려면 <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>)로 이동하세요.

Pub/Sub 주제는 메시지 피드를 나타내는 명명된 엔터티이고 구독은 특정 주제의 메시지 대상을 나타내는 명명된 엔터티입니다.

New Relic에서 GCP Pub/Sub 통합에 대한 [측정항목 데이터](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics) 를 보려면 `GcpPubSubTopicSample` 및 `GcpPubSubSubscriptionSample` [이벤트](/docs/data-apis/understand-data/new-relic-data-types/#event-data) 와 관련 속성에 대한 [NRQL 쿼리](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql) 를 만듭니다.
