[<DNT>Google Cloud Platform</DNT> () 와(과)의<DNT>GCP</DNT> ](https://cloud.google.com/)[뉴렐릭 통합](/docs/infrastructure/introduction-infra-monitoring) 에는 [<DNT>Gemini Enterprise</DNT>](https://cloud.google.com/gemini-enterprise) 데이터를 뉴렐릭에 보고하는 통합이 포함됩니다. 이 문서에서는 <DNT>GCP Gemini Enterprise</DNT> 통합을 활성화하는 방법과 보고되는 데이터에 대해 설명합니다.

## 특징

<DNT>Gemini Enterprise</DNT> <DNT>Discovery Engine</DNT>을(를) 기반으로 구축된, 엔터프라이즈 검색 및 AI 에이전트 애플리케이션을 빌드하고 실행하기 위한 <DNT>Google Cloud</DNT>의 플랫폼입니다. 뉴렐릭의 <DNT>Gemini Enterprise</DNT> 통합은 위치 및 사용자별 리소스 수와 할당량 소비와 함께 앱(엔진), 에이전트, 해당 에이전트가 호출하는 도구 및 데이터 커넥터에 대한 요청, 지연시간 및 세션 메트릭을 수집합니다.

## 통합 활성화 [#activate]

<Callout variant="important">
이 통합은 <DNT>GCP</DNT> 프로젝트를 <DNT>**Workload Identity Federation**</DNT>과(와) 연결할 때만 사용할 수 있습니다. 서비스 계정 또는 사용자 계정 연결에는 사용할 수 없습니다.
</Callout>

통합을 활성화하려면 표준 절차에 따라 <DNT>**Workload Identity Federation**</DNT>을(를) 사용하여 [<DNT>GCP</DNT> 서비스를 뉴렐릭에 연결](/docs/connect-google-cloud-platform-services-infrastructure) 하십시오.

## 폴링 빈도 [#polling]

뉴렐릭 통합은 통합에 따라 달라지는 폴링 간격에 따라 <DNT>GCP</DNT> 서비스를 쿼리합니다. <DNT>Gemini Enterprise</DNT>의 폴링 빈도는 5분입니다. 해상도는 1분마다 1개의 데이터 포인트입니다.

## 워크로드 아이덴티티 페더레이션 [#wif]

### 데이터 찾기 및 사용 [#find-data-wif]

통합을 활성화하면 <DNT>Gemini Enterprise</DNT> 리소스가 뉴렐릭 엔티티 탐색기에 엔티티로 표시됩니다. 대시보드를 확인하고 서비스를 관리하려면 <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>(으)로 이동하십시오.

뉴렐릭은 <DNT>GCP Cloud Monitoring</DNT>에서 사용 가능한 <DNT>Gemini Enterprise</DNT> 메트릭을 `Metric` 이벤트 유형의 차원 메트릭으로 수집합니다. 예를 들면 다음과 같습니다.

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'gcp.discoveryengine.%' FACET metricName
```

#### 위치 메트릭

위치 메트릭은 프로젝트의 위치별 집계입니다. 여기에는 엔진, 데이터 저장소, 문서 및 사용자 이벤트 수와 같은 리소스 수와 검색 요청 볼륨이 포함됩니다. 또한 에이전트, 이미지 및 비디오 생성, 웹 그라운딩, 검색 requests 등과 같은 영역을 포괄하는 140개 이상의 <DNT>Gemini Enterprise</DNT> 할당량에 대한 사용량, 한도 및 한도 초과 횟수도 포함됩니다.

대부분의 위치 메트릭은 할당량 메트릭입니다. 각 할당량은 `usage`, `limit` 또는 `exceeded` 접미사를 추가하여 명명된 최대 3개의 메트릭으로 보고됩니다(예: `gcp.discoveryengine.quota.search_requests_regional.usage`). 할당량 메트릭에는 `metric.limit_name` 및 `metric.regional_location` 레이블이 포함됩니다.

위치는 `gcp.discoveryengine.engines_regional`와(과) 같은 할당량 외 메트릭도 정의합니다. <DNT>Google Cloud</DNT>은(는) 모든 프로젝트에서 이에 대한 데이터를 보고하지 않으며, 보고하지 않는 경우 뉴렐릭에 표시되지 않습니다. 동일한 수가 할당량 메트릭(예: `gcp.discoveryengine.quota.engines_regional.usage`)으로도 보고됩니다.

위치 메트릭의 전체 목록은 [Google 클라우드 모니터링 메트릭 참조](https://docs.cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-discoveryengine)의 `discoveryengine` 섹션을 참조하십시오. 뉴렐릭은 여기에 나열된 GA 및 베타 메트릭을 수집합니다.
