[뉴렐릭 통합](/docs/infrastructure/introduction-infra-monitoring) 에는 [Google Cloud Platform(GCP)](https://cloud.google.com/) 과의 [Google Cloud Storage](https://cloud.google.com/storage) 데이터를 뉴렐릭으로 보고하는 통합이 포함됩니다. 이 문서에서는 GCP Cloud Storage 통합을 활성화하는 방법과 보고하는 데이터에 대해 설명합니다.

## 특징

Google Cloud Storage는 웹사이트 콘텐츠 제공, 보관 및 재해 복구, 직접 다운로드를 통한 데이터 객체 배포를 위한 GCP의 객체 스토리지 서비스입니다. 뉴렐릭 Cloud Storage 통합은 각 버킷에 대한 API 요청, 네트워크, 객체 수 및 저장된 바이트 메트릭을 수집합니다.

## 통합 활성화 [#activate]

통합을 활성화하려면 표준 절차에 따라 [GCP 서비스를 뉴렐릭에 연결하십시오](/docs/connect-google-cloud-platform-services-infrastructure):

* [워크로드 아이덴티티 연합으로 연결(권장)](/docs/connect-google-cloud-platform-services-infrastructure)
* [서비스 계정 또는 사용자 계정으로 연결합니다.](/docs/connect-google-cloud-platform-services-infrastructure)

## 폴링 빈도 [#polling]

뉴렐릭 통합은 통합에 따라 달라지는 폴링 간격에 따라 GCP 서비스를 쿼리합니다. Google Cloud Storage의 폴링 주기는 5분입니다. 해상도는 1분마다 1개의 데이터 포인트입니다.

## 워크로드 아이덴티티 페더레이션 [#wif]

### 데이터 찾기 및 사용 [#find-data-wif]

통합을 활성화하면 Cloud Storage 버킷이 뉴렐릭 엔티티 탐색기에 엔티티로 표시됩니다. 대시보드를 확인하고 서비스를 관리하려면 <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>(으)로 이동하십시오.

GCP 클라우드 모니터링에서 사용할 수 있는 모든 Cloud Storage 메트릭은 `Metric` 이벤트 유형의 디멘셔널 메트릭으로 수집됩니다. 이 표 이외의 추가 메트릭은 자동으로 수집됩니다. 전체 목록을 보려면 [Google의 Cloud Storage 메트릭 문서](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-storage) 를 참조하십시오.

## 서비스 계정 또는 사용자 계정 [#service-account]

### 데이터 찾기 및 사용 [#find-data]

통합을 뉴렐릭에 연결하고 몇 분 정도 기다리면 뉴렐릭 UI에 데이터가 표시됩니다. <InlinePopover type="dashboards" />및 공지 설정을 포함하여 [통합 데이터를 찾고 사용](/docs/telemetry-data-platform/understand-data/new-relic-data-types/)하려면 <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; Google Cloud Storage</DNT>(으)로 이동하십시오.

통합을 위한 사용자 정의 대시보드를 만들려면 공급자 값이 `GcpStorageBucket` 인 `GcpStorageBucketSample` 이벤트 유형에 대한 [쿼리](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights) 를 만듭니다.

### GcpStorageBucketSample [#gcp-storage-bucket-sample]

통합은 `method` 및 `response_code` 의 모든 값에 대한 [측정항목 데이터](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics) 를 보고합니다.

* `response_code`: 요청의 응답 코드입니다.
* `method`: 호출된 API 메서드의 이름입니다.
