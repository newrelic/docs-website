[뉴렐릭 통합](/docs/infrastructure/introduction-infra-monitoring) 과의 [Google Cloud Platform(GCP)](https://cloud.google.com/) 에는 [Google Cloud AlloyDB](https://cloud.google.com/alloydb) 데이터를 뉴렐릭에 보고하는 통합이 포함됩니다. 이 문서에서는 GCP AlloyDB 통합을 활성화하는 방법과 보고되는 데이터에 대해 설명합니다.

## 특징

AlloyDB는 까다로운 트랜잭션 및 분석 워크로드를 위해 구축된 완전 관리형, PostgreSQL 호환 데이터베이스 서비스입니다. 뉴렐릭 AlloyDB 통합은 클러스터, 인스턴스, 데이터베이스 및 인스턴스 노드 전반의 성능, 가용성 및 리소스 사용률 메트릭을 수집합니다.

## 통합 활성화 [#activate]

통합을 활성화하려면 표준 절차에 따라 [GCP 서비스를 뉴렐릭에 연결하십시오](/docs/connect-google-cloud-platform-services-infrastructure):

* [워크로드 아이덴티티 연합으로 연결(권장)](/docs/connect-google-cloud-platform-services-infrastructure)
* [서비스 계정 또는 사용자 계정으로 연결합니다.](/docs/connect-google-cloud-platform-services-infrastructure)

## 폴링 빈도 [#polling]

뉴렐릭 통합은 통합에 따라 달라지는 폴링 간격에 따라 GCP 서비스를 쿼리합니다. Google Cloud AlloyDB의 폴링 주기는 5분입니다. 해상도는 1분마다 1개의 데이터 포인트입니다.

<Callout variant="important">
  PostgreSQL용 AlloyDB는 제한된 미리 보기에서 WIF 통합을 위해 1분 폴링 간격을 지원합니다. 액세스를 요청하려면 [뉴렐릭 지원팀](https://support.newrelic.com/)에 문의하십시오.
</Callout>

## 워크로드 아이덴티티 페더레이션 [#wif]

### 데이터 찾기 및 사용 [#find-data-wif]

통합을 활성화하면 AlloyDB 리소스가 뉴렐릭 엔티티 탐색기에 엔티티로 표시됩니다. 대시보드를 확인하고 서비스를 관리하려면 <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>(으)로 이동하십시오.

GCP 클라우드 모니터링에서 사용할 수 있는 모든 AlloyDB 메트릭은 `Metric` 이벤트 유형에서 차원 메트릭으로 수집됩니다. 이 표 이외의 추가 메트릭은 자동으로 수집됩니다. 전체 목록은 [Google의 AlloyDB 메트릭 문서](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-alloydb) 를 참조하십시오.
