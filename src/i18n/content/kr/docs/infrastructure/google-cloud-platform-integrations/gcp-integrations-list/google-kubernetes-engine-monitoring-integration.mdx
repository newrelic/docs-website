[뉴렐릭 통합](/docs/infrastructure/introduction-infra-monitoring) 에는 [Google Cloud Platform(GCP)](https://cloud.google.com/) 과의 [Google Kubernetes Engine](https://cloud.google.com/kubernetes-engine/) (GKE) 데이터를 뉴렐릭에 보고하는 통합이 포함되어 있습니다. 이 문서에서는 GCP Kubernetes Engine 통합을 활성화하는 방법과 보고되는 데이터에 대해 설명합니다.

## 특징

Google Kubernetes Engine은 Google Cloud의 관리형 Kubernetes 서비스입니다. 뉴렐릭 GKE 통합은 클러스터를 구성하는 컨테이너, 노드 및 파드 전반에서 CPU, 메모리, 네트워크, 볼륨 및 업타임 메트릭을 수집합니다.

## 통합 활성화 [#activate]

통합을 활성화하려면 표준 절차에 따라 [GCP 서비스를 뉴렐릭에 연결하십시오](/docs/connect-google-cloud-platform-services-infrastructure):

* [워크로드 아이덴티티 연합으로 연결(권장)](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation)
* [서비스 계정 또는 사용자 계정으로 연결합니다.](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account)

## 폴링 빈도 [#polling]

뉴렐릭 통합은 통합에 따라 달라지는 폴링 간격에 따라 GCP 서비스를 쿼리합니다. Google Kubernetes Engine의 폴링 주기는 5분입니다. 해상도는 1분마다 1개의 데이터 포인트입니다.

<Callout variant="important">
  **권장 사항: GKE용 뉴렐릭 Kubernetes 통합을 사용하십시오.** 워크로드 아이덴티티 페더레이션을 사용하면 GCP 통합은 GKE 메트릭을 수집하지만 엔티티를 생성하지 않습니다. 전체 GKE 옵저버빌리티를 위해 ― 클러스터, 노드, 파드 및 컨테이너 엔티티, 대시보드 및 알림 ― GKE 클러스터에 [뉴렐릭 Kubernetes 통합을](https://docs.newrelic.com/docs/kubernetes-pixie/kubernetes-integration/installation/kubernetes-integration-install-configure/) 설치하십시오.

  Google Kubernetes Engine(GKE)은 제한된 미리 보기에서 WIF 통합에 대해 1분 폴링 간격을 지원합니다. 액세스를 요청하려면 [뉴렐릭 지원팀](https://support.newrelic.com/)에 문의하십시오.
</Callout>

## 워크로드 아이덴티티 페더레이션 [#wif]

### 데이터 찾기 및 사용 [#find-data-wif]

GCP 클라우드 모니터링에서 사용할 수 있는 모든 Google Kubernetes Engine 메트릭은 `gcp.kubernetes.io.*` 네임스페이스 아래의 `Metric` 이벤트 유형에서 차원 메트릭으로 수집됩니다. 예를 들어 `Metric` 이벤트 유형에서 직접 쿼리하십시오:

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'gcp.kubernetes.io.%' FACET metricName
```

메트릭은 기본 Kubernetes 객체의 리소스 레이블을 전달하므로 클러스터 이름, 네임스페이스, 노드 이름, 파드 이름 및 컨테이너 이름별로 패싯할 수 있습니다.
