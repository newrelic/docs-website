<DNT>**Infrastructure 360**</DNT> cloud 계정의 인프라를 자동으로 검색하고, 리소스 간의 관계를 매핑하며, 리소스 전반의 설정 변경 사항을 추적합니다. 이들을 함께 사용하면 현재 무엇을 실행 중인지, 얼마나 잘 모니터링하고 있는지, 어떻게 연결되어 있는지, 그리고 환경 전반에 걸쳐 무엇이 변경되고 있는지에 대한 최신 상황을 파악할 수 있습니다.

## 기능 [#capabilities]

<DNT>Infrastructure 360</DNT> 다음과 같은 기능을 제공하므로 다음을 수행할 수 있습니다:

* **안정성 커버리지 확인**: 메트릭 스트리밍이나 폴링을 먼저 설정하지 않고도 연결된 cloud 계정의 리소스를 자동 검색하므로, 환경이 변경됨에 따라 인벤토리를 최신 상태로 유지하고 각 리소스를 얼마나 잘 모니터링하고 있는지 한눈에 확인할 수 있습니다. 가이드 넛지는 cloud 계정을 연결하거나 리소스가 완전히 계측된 상태가 아닌 곳에 에이전트를 설치하는 등 모니터링 격차를 해소하는 데 도움이 됩니다.

  자동 검색은 텔레메트리가 아닌 엔티티와 관계를 생성합니다. 검색된 리소스는 엔티티, 태그, cloud 설정 및 맵의 위치를 얻지만, 차트와 알림을 구동하는 데이터를 수집하려면 여전히 메트릭을 연결하거나 에이전트를 설치해야 합니다.

* **리소스 연관성 확인**: 리소스 간의 관계를 확인하여 애플리케이션과 인프라가 어떻게 연결되고 서로 의존하는지 이해하고, 성능이 저하될 때 공유 종속성으로 인한 영향을 트레이스할 수 있습니다.

* **설정 변경 추적**: 각 엔티티의 설정 탐색기와 변경 추적 타임라인을 사용하여 검색된 리소스 전반의 설정 변경 사항(무엇이 언제 변경되었는지)을 추적하십시오.

  <Callout title="메모">
  <DNT>Infrastructure 360</DNT> 엔티티당 하루 100개의 변경 추적 이벤트라는 내장 임계값을 적용합니다. 이 임계값은 데이터 수집을 제한하지 않습니다. 뉴렐릭은 항상 최신 설정 파일과 모든 구조적 변경 사항을 수집합니다.
  </Callout>

* **하나의 연결된 뷰 확보**: 액세스할 수 있는 뉴렐릭 계정에서 모든 인프라(cloud 리소스, 호스트, <DNT>Kubernetes</DNT> 및 데이터베이스)를 한곳에서 확인하고, 인프라에 대한 알림, 비용 및 보안 신호를 단일 뷰로 통합하십시오.

## 시작하다 [#get-started]

<DNT>Infrastructure 360</DNT> <DNT>Amazon Web Services</DNT> 및 <DNT>Microsoft Azure</DNT>을(를) 지원합니다. 특정 공급자로 시작하려면 다음을 참조하십시오:

* [<DNT>AWS</DNT> 사전 요구 사항](/docs/infrastructure/infrastructure-360/aws/prerequisites-infrastructure-360-aws) 및 [<DNT>AWS</DNT> 온보딩](/docs/infrastructure/infrastructure-360/aws/onboarding-infrastructure-360-aws)을 참조하십시오.
* 사전 요구 사항이 포함된 [<DNT>Azure</DNT>에 대한 <DNT>Infrastructure 360</DNT> 설정](/docs/infrastructure/infrastructure-360/azure/onboarding-infrastructure-360-azure)을 참조하십시오.
