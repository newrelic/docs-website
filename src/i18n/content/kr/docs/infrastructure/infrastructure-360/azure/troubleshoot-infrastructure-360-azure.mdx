<Callout title="시사">
이 기능은 아직 개발 중이지만 꼭 사용해 보시기 바랍니다!

이 기능은 현재 [출시 전 정책](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy) 에 따라 미리보기 프로그램의 일부로 제공됩니다.
</Callout>

<DNT>Azure</DNT>에서 [<DNT>Infrastructure 360</DNT>](/docs/infrastructure/infrastructure-360/introduction-infrastructure-360)에 문제가 발생하는 경우, 다음 문제 진단, 해결 시나리오를 확인해 주십시오.

<CollapserGroup>
<Collapser id="no-entities-appear" title="자동 검색을 활성화한 후 Azure 엔티티가 나타나지 않습니다">
자동 검색을 활성화한 후 엔티티가 표시되지 않으면 다음을 확인하십시오:

* **권한 확인**: <DNT>Azure</DNT> 앱 등록에 구독 및 필요한 리소스 그룹에 대한 읽기 권한이 있는지 확인하십시오.
* **구독 확인**: 뉴렐릭 통합에 올바른 <DNT>Azure</DNT> 구독 ID를 구성했는지 확인하십시오.
* **첫 번째 스캔 대기**: 초기 검색에는 시간이 걸릴 수 있습니다. 다음 예약된 스캔(기본값은 하루 3회) 이후에 다시 확인해 주십시오.
* **미리 보기 액세스 확인**: <DNT>**Administration &gt; Preview &amp; Trials**</DNT>을(를) 확인하여 뉴렐릭 계정을 <DNT>Infrastructure 360</DNT> 미리 보기에 등록했는지 확인하십시오.
</Collapser>

<Collapser id="missing-relationships" title="엔티티 관계가 표시되지 않습니다">
엔티티 간의 관계가 표시되지 않는 경우 다음을 확인하십시오:

* **적절한 APM 에이전트가 설치되어 있는지 확인**: 많은 관계에서 애플리케이션의 데이터를 적극적으로 보고하는 뉴렐릭 APM 에이전트를 설치해야 합니다.
* **엔티티 명명 확인**: 자동 검색이 APM 엔티티와 일치시킬 수 있도록 <DNT>Azure</DNT> 리소스에 일관된 명명을 사용하는지 확인하십시오.
* **네트워크 연결 확인**: <DNT>Azure</DNT> 리소스가 뉴렐릭의 데이터 수집기에 도달할 수 있는지 확인하십시오.
* **리소스 태그 검토**: 일부 관계는 <DNT>Azure</DNT> 및 APM 설정 모두에서 적절한 태그 전략에 따라 달라집니다.
</Collapser>

<Collapser id="scan-failures" title="자동 검색 스캔이 실패하고 있습니다.">
자동 검색 스캔이 지속적으로 실패하는 경우 다음을 확인하십시오:

* **API 제한 확인**: <DNT>Azure</DNT> API 속도 제한을 초과하지 않았는지 확인하십시오. 일시적으로 스캔 빈도를 줄이는 것을 고려하십시오.
* **앱 등록 확인**: <DNT>Azure</DNT> 앱 등록이 여전히 유효하고 만료되지 않았는지 확인하십시오.
* **권한 검토**: <DNT>Azure</DNT> 정책 변경 후에도 앱 등록에 필요한 권한이 여전히 있는지 확인하십시오.
* **구독 상태 확인**: <DNT>Azure</DNT> 구독이 활성화되어 있고 액세스 가능한지 확인해 주십시오.
</Collapser>
</CollapserGroup>
