모바일 사용자 여정은 최종 사용자가 모바일 애플리케이션을 탐색하는 방법을 종합적으로 시각화합니다. 사용자 행동의 패턴 ― 사용자가 애플리케이션을 연 후 어디로 가는지, 어디서 막히는지, 어떤 경로가 관심 있는 결과로 이어지는지 ― 을 보여줍니다.

<img title="Mobile User Journeys Sankey diagram" alt="A Sankey diagram showing user navigation paths through a mobile app, with nodes representing screens and paths sized by user volume" src="/images/mobile_screenshot-full_user-journeys-sankey.png" />

<Callout variant="important">
  <DNT>Mobile User Journeys</DNT> 현재 뉴렐릭 모바일 모니터링 UI의 <DNT>**Errors**</DNT> 환경에서 사용할 수 있습니다. 독립 실행형 <DNT>Mobile User Journeys</DNT> 보기([Browser User Journeys \[브라우저 사용자 여정\]](/docs/browser/browser-monitoring/browser-pro-features/user-journeys/) 기능과 유사)가 향후 릴리스에 계획되어 있습니다.
</Callout>

## 접근 방법 [#access]

<DNT>Mobile User Journeys</DNT> 왼쪽 탐색 메뉴의 <DNT>**Triage**</DNT> 아래에 있는 4개의 모든 섹션( <DNT>**Crashes**</DNT>, <DNT>**Request errors**</DNT>, <DNT>**Handled exceptions**</DNT>, <DNT>**ANRs**</DNT>)에서 사용할 수 있습니다. 접근 방법은 현재 위치에 따라 다릅니다:

<img title="Mobile Triage navigation showing Crashes, Request errors, Handled exceptions, and ANRs" alt="The New Relic Mobile left navigation with the Triage section expanded, showing Crashes, Request errors, Handled exceptions, and ANRs" src="/images/mobile_screenshot-full_user-journeys-triage-nav.png" />

**Triage 탭에서:**

1. **[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; <DNT>Mobile</DNT>**으로 이동합니다.
2. 모바일 애플리케이션을 선택하십시오.
3. 왼쪽 탐색의 <DNT>**Triage**</DNT> 아래에서 <DNT>**Crashes**</DNT> 또는 <DNT>**Request errors**</DNT>를 클릭합니다.
4. <DNT>error groups</DNT>에서 조사할 항목을 선택하여 오류 세부 정보 보기를 여십시오.
5. 세부 정보 뷰에서 <DNT>**User Journeys**</DNT> 링크를 클릭하여 오류를 발생시킨 탐색 경로를 확인합니다.

**&quot;Group crashes or error&quot; \[크래시 또는 오류 그룹화] 탭에서:**

1. **[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; <DNT>Mobile</DNT>**으로 이동합니다.
2. 모바일 애플리케이션을 선택하십시오.
3. 왼쪽 탐색의 <DNT>**Triage**</DNT> 아래에서 <DNT>**Crashes**</DNT> 또는 <DNT>**Request errors**</DNT>를 클릭합니다.
4. <DNT>**Group crashes**</DNT> 또는 <DNT>**Group request errors**</DNT> 탭을 클릭하십시오.
5. 조사할 크래시 또는 오류 그룹을 선택하여 그룹 세부 정보 뷰를 엽니다.
6. <DNT>**Triage**</DNT> 아래에서 <DNT>**User Journeys**</DNT> 링크를 클릭하여 오류를 발생시킨 탐색 경로를 확인하십시오.

## 모바일 사용자 여정 사용 방법 [#how-to-use]

### 생키 다이어그램 [#sankey]

<DNT>User Journeys</DNT> 시각화는 Sankey 다이어그램을 사용하여 화면 간의 사용자 흐름을 보여줍니다. 각 노드는 앱의 화면 또는 상호작용을 나타내며, 각 연결 경로의 너비는 해당 경로를 따른 사용자 수를 반영합니다.

다이어그램의 주요 요소:

* **노드**: 애플리케이션의 개별 화면 또는 상호작용입니다.
* **경로**: 노드 간의 연결로, 해당 경로를 따른 사용자 수에 비례하여 크기가 지정됩니다.
* **진입점**: 사용자 세션이 시작되는 화면입니다.
* **이탈점**: 사용자가 세션을 종료하거나 오류를 발생시킨 화면입니다.

오류 그룹 내에서 볼 때 시각화는 해당 오류를 경험한 세션에 자동으로 고정되므로 크래시 이전의 탐색 경로를 트레이스할 수 있습니다.

### 경로 및 이벤트 세부 정보 [#path-details]

다이어그램의 노드나 경로를 클릭하여 해당 경로를 따른 세션을 자세히 살펴볼 수 있습니다. 그러면 두 개의 패널이 있는 분할 뷰가 열립니다:

<img title="Mobile User Journeys crash detail view" alt="Split view showing the Profiles panel on the left with attribute distribution and the Sessions table on the right listing affected sessions" src="/images/mobile_screenshot-full_user-journeys-crash-detail.png" />

* <DNT>**Profiles**</DNT>: 선택한 경로를 따른 세션 전반에 걸친 속성 값(애플리케이션 버전, 기기, OS, 아키텍처, 크래시 세부 정보 등)의 분포를 보여줍니다. 이를 사용하여 영향을 받는 사용자 간의 공통점을 식별하십시오.
* <DNT>**Sessions that include this event**</DNT>: 사용자 ID, 날짜, 발생 횟수, 애플리케이션 버전, 기기, OS 버전, 통신사를 포함하여 개별 세션을 나열하는 테이블입니다. 세션을 클릭하여 <DNT>Event Trail Drilldown</DNT> 페이지를 엽니다.

### 이벤트 추적 드릴다운 [#event-trail]

세션 테이블에서 세션을 클릭하여 <DNT>**Event Trail Drilldown**</DNT> 페이지 ― 해당 세션에 기록된 모든 이벤트의 연대순 타임라인 ― 를 엽니다.

<img title="Mobile User Journeys Event Trail Drilldown" alt="The Event Trail Drilldown showing a chronological list of Interaction and Crash events with expandable attribute details" src="/images/mobile_screenshot-full_user-journeys-event-trail.png" />

<DNT>Event Trail Drilldown</DNT>에서 다음을 수행할 수 있습니다:

* <DNT>**Filter by event type**</DNT>: <DNT>**Interaction**</DNT> 및 <DNT>**Crash**</DNT> 버튼을 사용하여 특정 이벤트 유형에 집중합니다.
* <DNT>**Expand event details**</DNT>: 이벤트를 클릭하여 `diskAvailable`, `osBuild`, `processName`, `timeSinceLastInteraction` 및 `interactionHistory`와 같은 충돌 메타데이터를 포함한 전체 속성 페이로드를 확인하십시오.

이 뷰를 사용하면 크래시가 발생하기 전에 사용자가 수행한 정확한 단계를 개별 화면 상호작용까지 재구성할 수 있습니다.

## 시각화 맞춤화 방법 [#customize]

### 이벤트 유형 필터 [#event-type]

<img title="Mobile User Journeys event type filter" alt="The event type filter dropdown showing options: Crash, Breadcrumb, Interaction, User action, Handled exception, JavaScript error, Request error, Custom, ANR" src="/images/mobile_screenshot-crop_user-journeys-event-type-filter.png" />

<DNT>**Event type**</DNT> 필터를 사용하여 다이어그램에 노드로 표시할 이벤트 유형을 선택하십시오. 다음의 모든 조합을 포함할 수 있습니다:

* Crash \[충돌]
* 빵 부스러기
* Interaction \[상호작용]
* User action \[사용자 조치]
* Handled exception \[처리된 예외]
* JavaScript error \[JavaScript 오류]
* Request error \[요청 오류]
* 관습
* ANR

### 앱 버전 [#app-version]

<DNT>**App version**</DNT> 필터를 사용하여 특정 릴리스의 여정에 집중합니다. 이는 배포 전후의 사용자 동작을 비교하여 회귀 또는 개선 사항을 식별하는 데 유용합니다.

### 사용자 속성으로 필터링 [#user-attributes]

필터 표시줄을 사용하여 기기 유형, OS 버전, 지역 또는 [Mobile SDK](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/mobile-sdk-api-guide/)로 계측된 커스텀 속성과 같은 추가 속성으로 결과를 좁히십시오.
