<Callout variant="important">
<DNT>Cloud Cost Intelligence</DNT>에 액세스하려면 **Advanced CCU SKU**와 **전체 플랫폼 사용자** 라이선스가 필요하며, [Feature Control Manager \[기능 제어 관리자\]](/docs/accounts/accounts-billing/new-relic-one-user-management/feature-control-manager/)를 통해 액세스가 활성화되어야 합니다. 이 페이지에서는 설정 액세스 ― 조직에 제품이 활성화된 후 누가 CCI 설정을 수정할 수 있는지를 다룹니다.
</Callout>

당사의 표준 권한 부여 시스템은 <DNT>Cloud Cost Intelligence</DNT> 영역(<DNT>Settings</DNT>, <DNT>Integrations</DNT> 및 <DNT>Custom Facets</DNT>)에 대한 액세스를 제어합니다. 이 시스템은 조직 전체가 아닌 계정별로 액세스를 읽기(설정 보기) 및 쓰기(생성, 업데이트, 삭제)로 분할합니다.

## 기본 액세스 [#default-access]

계정 액세스 권한이 있는 모든 사용자에게는 기본적으로 보기 전용 액세스 권한이 부여됩니다.

<DNT>Organization Admin</DNT>만 자신, 다른 개별 사용자 또는 역할에 수정 또는 삭제 권한을 부여할 수 있습니다.

## 권한 참조 [#permissions-reference]

다음 표에는 각 CCI 영역에 대해 사용 가능한 권한이 나열되어 있습니다. 모든 사용자에게는 기본적으로 읽기 권한이 부여됩니다. Modify \[수정] 및 Delete \[삭제] 권한에는 [커스텀 역할](#grant-modify-access)이 필요합니다.

| CCI surface \[CCI 표면]    | Read \[읽기]                          | Modify \[수정]   | 삭제             |
| ------------------------ | ----------------------------------- | -------------- | -------------- |
| <DNT>Custom Facets</DNT> | Default for all users \[모든 사용자 기본값] | 커스텀 역할이 필요합니다. | 커스텀 역할이 필요합니다. |
| <DNT>Integrations</DNT>  | Default for all users \[모든 사용자 기본값] | 커스텀 역할이 필요합니다. | —              |
| <DNT>Settings</DNT>      | Default for all users \[모든 사용자 기본값] | 커스텀 역할이 필요합니다. | —              |

## 수정 액세스 권한 부여 [#grant-modify-access]

<DNT>Organization Admin</DNT>은(는) [사용자 지정 역할](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/#roles)을 통해 CCI 쓰기 액세스 권한을 부여합니다. 사용 가능한 두 가지 옵션은 다음과 같습니다.

### 기존 사용자 지정 역할에 CCI 권한 추가 [#option-existing-role]

팀을 위한 사용자 지정 역할(예: &quot;FinOps&quot; 역할)이 이미 존재하는 경우, 해당 역할에 CCI 쓰기 권한을 추가하십시오. 해당 역할이 이미 할당된 모든 사람은 자동으로 CCI 쓰기 액세스 권한을 얻습니다. 개별 사용자를 다시 할당할 필요가 없습니다.

### CCI용 전용 커스텀 역할 만들기 [#option-new-role]

CCI 수정 권한(<DNT>Settings</DNT>, <DNT>Integrations</DNT>, <DNT>Custom Facets</DNT>)만 포함하는 사용자 지정 역할을 생성한 다음, 권한이 필요한 특정 사용자, 그룹 또는 본인에게 할당하십시오. CCI 관리를 다른 역할의 책임과 분리하여 유지하려면 이 옵션을 사용하십시오.
