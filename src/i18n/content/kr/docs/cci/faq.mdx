## 클라우드 비용 인텔리전스에 &quot;지난 48시간 동안의 비용 데이터를 사용할 수 없습니다&quot;라고 표시되는 이유는 무엇입니까? [#48-hour-buffer]

클라우드 비용 인텔리전스는 선택한 시간 범위에 48시간 데이터 버퍼를 적용합니다. CCI 대시보드를 열면 CCI는 선택한 시간 범위가 48시간 전에 종료되도록 자동으로 조정하고 다음 공지를 표시합니다:

> 지난 48시간 동안의 비용 데이터를 사용할 수 없습니다. 선택한 시간 범위가 48시간 전에 종료되도록 조정했습니다.

이는 예상되는 플랫폼 동작이며 지원되는 모든 cloud 제공업체 — AWS, Azure 및 GCP에 동일하게 적용됩니다. CCI는 cloud 제공업체의 비용 내보내기가 얼마나 빨리 완료되는지에 관계없이 플랫폼 수준에서 이 버퍼를 적용합니다. 제공업체의 내보내기가 더 일찍 완료되더라도 CCI는 여전히 표시되는 시간 범위가 48시간 전에 종료되도록 제한합니다.

## 현재 프리뷰로 제공되는 기능에 어떻게 액세스합니까? [#preview-access]

FinOps 에이전트 및 CCI 알림과 같은 일부 CCI 기능은 프리뷰 기능으로 사용할 수 있습니다. 이를 활성화하려면:

1. New Relic 계정에 로그인하세요.

2. 왼쪽 하단 모서리에서 **사용자 프로필** 아이콘을 선택합니다.

3. **Administration &gt; Previews and Trials** 로 이동합니다.

4. 활성화하려는 기능을 찾습니다:

   * **FinOps 에이전트 프리뷰:** 자연어 비용 쿼리 및 cloud 지출 분석을 활성화하려면 이 기능을 켜십시오.
   * **CCI 알림 미리 보기:** CCI 에코시스템 내에서 직접 알림을 생성하고 관리하려면 이 기능을 켜십시오.

5. Ask AI 인터페이스에 반영된 새로운 기능을 보려면 브라우저를 새로 고치세요.
