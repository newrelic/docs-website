<DNT>**Kubernetes Costs**</DNT> 페이지는 CPU, 메모리, 미사용 및 미할당 리소스별로 분류하여 각 쿠버네티스 클러스터의 비용이 얼마나 되는지 보여줍니다. 뉴렐릭의 Kubernetes 텔레메트리 데이터를 사용하여 cloud 청구와 클러스터 수준 사용량을 연관시키므로, 지출이 어디에서 발생하고 어디에서 비용을 절감할 수 있는지 확인할 수 있습니다.

<img title="Kubernetes Cost Insights highlighted on the Cloud Cost Intelligence Kubernetes Cost Insights page" alt="Kubernetes Cost Insights highlighted on the Cloud Cost Intelligence Kubernetes Cost Insights page" src="/images/k8s-cci.webp" />

## 전제 조건 [#prerequisites]

<DNT>**Kubernetes Costs**</DNT> 페이지에 데이터가 표시되려면 Kubernetes 텔레메트리가 있는 뉴렐릭 계정을 추가해야 합니다. CCI는 해당 계정의 `K8sContainerSample` 이벤트를 사용하여 인스턴스 ID를 기준으로 cloud 청구 데이터와 결합합니다. 이 단계를 건너뛰면 CCI에 cloud 비용은 표시되지만 Kubernetes 비용은 표시되지 않을 수 있습니다.

이 계정을 추가하려면 다음 단계를 완료하십시오:

1. <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Cloud Cost Intelligence &gt; Settings &gt; Telemetry Accounts**</DNT> 으)로 이동합니다.

2. <DNT>**Accounts**</DNT> 드롭다운 메뉴에서 `K8sContainerSample` 데이터가 있는 모든 뉴렐릭 계정을 선택하십시오. 계정을 확인하려면 해당 계정에서 다음 쿼리를 실행하십시오:

   ```sql
   SELECT count(*) FROM K8sContainerSample SINCE 1 day ago
   ```

3. <DNT>**Apply**</DNT> 을(를) 클릭합니다.

계정을 추가하면 CCI가 `K8sContainerSample` 데이터를 가져와 Kubernetes 비용 할당을 시작합니다.

<Callout variant="important">
쿠버네티스 클러스터가 두 개 이상의 뉴렐릭 계정에 보고하는 경우, 각각 추가하십시오. 추가하지 않은 계정에 있는 클러스터의 비용은 <DNT>**Kubernetes Costs**</DNT> 페이지에 표시되지 않습니다.
</Callout>

올바른 계정을 추가했는데도 Kubernetes 비용이 표시되지 않으면 [Troubleshoot \[문제 해결\]](#troubleshoot)을 참조하십시오.

## 필터 및 사용자 정의

### 클라우드 공급자 필터

cloud 제공업체별로 비용 데이터를 필터링하려면 페이지 왼쪽 상단의 드롭다운 메뉴에서 옵션을 선택하세요:

* <DNT>**All**</DNT>: 모든 cloud 공급자
* <DNT>**AWS**</DNT>: Amazon Web Services 전용
* <DNT>**Azure**</DNT>: Microsoft Azure 전용

### 날짜 범위 선택기

페이지 오른쪽 상단에서 date range selector \[날짜 범위 선택기]를 사용하여 다음 중 하나를 수행하십시오:

* 사전 정의된 기간 선택
* 커스텀 시작 및 종료 날짜 설정
* 선호하는 시간대로 비용 보기(기본적으로 UTC 표시)

### 엔지니어링 비용 필터

조직에서 비용 할당 태그를 사용하는 경우, <DNT>**Engineering costs**</DNT> 태그로 필터링하여 cloud 환경에서 태그가 지정된 특정 팀, 프로젝트 또는 비용 센터로 분석 범위를 좁힐 수 있습니다.

## 요약

Summary \[요약] 섹션에는 선택한 기간에 대한 4가지 비용 메트릭이 표시됩니다:

| 미터법                                 | 설명                                             |
| ----------------------------------- | ---------------------------------------------- |
| <DNT>**Total cost**</DNT>           | 이전 기간 대비 증감률을 포함한 모든 쿠버네티스 클러스터의 총 지출          |
| <DNT>**Average cost (Daily)**</DNT> | 증감률을 포함한 일일 평균 지출                              |
| <DNT>**Unused cost**</DNT>          | 클러스터가 할당했지만 requests를 수신하지 않는 리소스의 비용 및 백분율 변화 |
| <DNT>**Unallocated cost**</DNT>     | 증감률을 포함한, 어떤 소스에도 할당되지 않은 클러스터 리소스 비용          |

## 인사이트

Insights 섹션은 Kubernetes 비용을 분석하는 데 도움이 되는 두 개의 시각화 위젯을 제공합니다.

### 비용 트렌드

<DNT>**Cost Trends**</DNT> 위젯은 시간 경과에 따라 Kubernetes 비용이 어떻게 변하는지 보여주는 라인 차트를 표시합니다. 보기 옵션을 사용하여 <DNT>**Hourly**</DNT>, <DNT>**Daily**</DNT>, <DNT>**Weekly**</DNT> 또는 <DNT>**Monthly**</DNT> 보기 간에 전환할 수 있습니다.

### 상위 20

<DNT>**Top 20**</DNT> 위젯은 트리 차트 시각화를 사용하여 비용이 가장 많이 드는 영역을 표시합니다. 기본적으로 비용순으로 상위 20개 클러스터를 표시합니다. 다음 옵션을 사용하여 보기를 맞춤 설정할 수 있습니다:

* <DNT>**Dropdown filter**</DNT>: 표시할 항목 선택(<DNT>**Cluster name, by cost**</DNT>)
* <DNT>**Group by**</DNT>: 비용 데이터를 그룹화할 측정기준을 선택하세요
* <DNT>**View by**</DNT>: <DNT>**Tree chart**</DNT> 및 다른 시각화 형식 간에 전환

## 비용 및 사용량 분석

<DNT>**Cost &amp; Usage Analysis**</DNT> 섹션은 클러스터 이름별 리소스 사용량 및 비용 내역을 보여주는 테이블을 제공합니다:

| 열                               | 설명                                  |
| ------------------------------- | ----------------------------------- |
| <DNT>**Cluster name**</DNT>     | 쿠버네티스 클러스터의 이름                      |
| <DNT>**CPU cost**</DNT>         | 각 클러스터의 CPU 사용량에 속성된 비용             |
| <DNT>**CPU usage**</DNT>        | 각 클러스터가 소비한 CPU 리소스 비율              |
| <DNT>**Memory cost**</DNT>      | 각 클러스터의 메모리 사용량과 관련된 비용             |
| <DNT>**Memory usage**</DNT>     | 각 클러스터가 사용한 메모리 리소스 비율              |
| <DNT>**Unused cost**</DNT>      | 클러스터가 할당했지만 requests를 받지 않는 리소스의 비용 |
| <DNT>**Unallocated cost**</DNT> | 어떤 소스에도 할당되지 않은 클러스터 리소스 비용         |
| <DNT>**Total cost**</DNT>       | 모든 리소스 사용량에 대한 각 클러스터의 합산 비용(정렬 가능) |

클러스터의 미사용 또는 미할당 비용이 지속적으로 높다면 초과 프로비저닝되었을 수 있습니다. cloud 환경 전반에서 지출을 줄이는 방법은 [Cost optimization recommendations \[비용 최적화 권장 사항\]](/docs/cci/financial-intelligence/cci-recommendations)을 참조하십시오.

## 미사용 대 미할당 비용

이러한 비용 지표는 클러스터 효율성을 측정하는 데 도움이 됩니다.

| 비용 유형  | 정의                                  | 예시                                             |
| ------ | ----------------------------------- | ---------------------------------------------- |
| 미사용 비용 | 클러스터가 할당했지만 requests를 받지 않는 리소스입니다. | 총 비용: $5.60, 사용됨: $4.64, 미사용 비용: $0.96         |
| 미배정 비용 | 어떤 소스에도 할당되지 않은 Cluster 리소스입니다.     | 노드 비용: $10.00, 워크로드에 할당됨: $7.50, 미할당 비용: $2.50 |

<Callout variant="tip">
클러스터를 선택하여 <DNT>**Cost Trends**</DNT>, <DNT>**Cost Breakdown (Total vs Used)**</DNT> 및 사용되지 않거나 할당되지 않은 비용에 대한 정보를 확인하십시오.
</Callout>

## 문제 해결 [#troubleshoot]

### AWS 비용은 표시되지만 Kubernetes 비용은 표시되지 않습니다

아직 텔레메트리 계정을 추가하지 않았거나 일부만 추가했습니다. [Prerequisites \[전제 조건\]](#prerequisites)을 참조하십시오.

### 페이지에서 일부 클러스터가 누락되었습니다

쿠버네티스 클러스터가 두 개 이상의 뉴렐릭 계정에 보고할 수 있습니다. <DNT>**Settings &gt; Telemetry data**</DNT> 아래에 모든 보고 계정을 추가했는지 확인하십시오.

### 올바른 계정을 추가했지만 여전히 비용이 표시되지 않습니다

뉴렐릭 고객 지원팀에 문의하십시오.

CCI 설정, 통합 또는 권한과 관련된 문제에 대해서는 [Troubleshoot Cloud Cost Intelligence setup \[클라우드 비용 인텔리전스 설정 문제 해결\]](/docs/cci/troubleshooting/troubleshooting)을 참조하십시오.
