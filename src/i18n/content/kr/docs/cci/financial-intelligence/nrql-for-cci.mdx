## CloudSpend [#cloudspend]

`CloudSpend` 그리고 `CloudCost`은(는) cloud 제공업체의 동일한 청구 데이터를 포함하지만 NRQL 기능이 다릅니다. `CloudSpend`은(는) 전체 NRQL 언어를 지원하며 모든 새 쿼리에 권장되는 선택 사항입니다. `CloudCost`은(는) NRQL 절의 하위 세트만 지원하며 더 이상 사용되지 않을 예정입니다.

`CloudSpend` 매시간 업데이트되는 AWS 비용 및 사용 보고서(CUR), Azure FOCUS 내보내기 및 GCP BigQuery 내보내기에서 원시 청구 항목을 수집합니다. `line_item_net_unblended_cost`, `line_item_product_code` 및 `line_item_usage_account_id`을(를) 포함하여 `CloudCost`와(과) 주요 속성을 공유합니다. 전체 속성 참조는 [데이터 사전](/attribute-dictionary)을 참조하십시오.

쿼리 예:

```sql
FROM CloudSpend SELECT * SINCE 24 hours ago
```

지난 달 서비스별로 분류된 총 cloud 지출을 확인하십시오:

```sql
FROM CloudSpend SELECT SUM(line_item_net_unblended_cost) FACET line_item_product_code SINCE 1 month ago
```

시간에 따른 일일 cloud 지출 추세를 확인하십시오.

```sql
FROM CloudSpend SELECT SUM(line_item_net_unblended_cost) TIMESERIES 1 day SINCE 30 days ago
```

## KubernetesSpend [#kubernetesspend]

`KubernetesSpend` Kubernetes 워크로드에 대한 개별 비용 할당 레코드를 저장합니다. 뉴렐릭 Infrastructure 텔레메트리와 cloud 청구 내보내기를 결합하여 클러스터, 네임스페이스, 파드 및 컨테이너별로 비용을 분류하고 전체 NRQL 언어를 지원합니다.

Kubernetes 노드 비용은 워크로드 간에 공유되므로 `KubernetesSpend`은(는) `cpu_weightage` 및 `memory_weightage`을(를) 사용하여 비용을 비례적으로 분배합니다. 정확한 워크로드당 총 비용을 구하려면 `net_unblended_cost`에 `(cpu_weightage + memory_weightage)`을(를) 곱하십시오. 전체 속성 참조는 [데이터 사전](/attribute-dictionary)을 참조하십시오.

쿼리 예:

```sql
FROM KubernetesSpend SELECT * SINCE 1 week ago
```

## 클라우드 비용 [#cloudcost]

<Callout variant="important">
  모든 비용 및 사용량 분석에 `CloudSpend`를 사용하는 것이 좋습니다. 완벽한 NRQL 지원과 함께 `CloudCost`과(와) 동일한 청구 데이터를 제공합니다.
</Callout>

`CloudCost` cloud 제공업체의 비용 및 사용 보고서(CUR)에서 클라우드 비용 인텔리전스가 생성한 요약 이벤트입니다. 매시간 업데이트되며 AWS 및 Azure 계정 전반의 리소스 사용량, 비용 및 계정 메타데이터를 포함한 청구 항목 데이터를 제공합니다. `CloudCost`은(는) 사전 집계되므로 NRQL 절의 하위 집합만 지원합니다. 완전한 NRQL 유연성을 원하시면 `CloudSpend`을(를) 사용하십시오.

### 주요 속성

다음 속성은 CloudCost 쿼리를 작성하는 데 가장 유용합니다:

| 기인하다                           | 설명                                                                                  |
| ------------------------------ | ----------------------------------------------------------------------------------- |
| `line_item_net_unblended_cost` | 개별 계정에 고유한 라인 항목의 할인 후 비용입니다.                                                       |
| `line_item_product_code`       | cloud 공급자 서비스 코드(예: AWS의 경우 `AmazonEC2` 또는 Azure의 경우 `Virtual Machine Scale Sets`). |
| `line_item_usage_account_id`   | 이 항목을 사용한 계정의 12자리 AWS 계정 ID입니다.                                                    |
| `line_item_usage_account_name` | cloud 계정 또는 구독의 표시 이름입니다.                                                           |
| `line_item_unblended_cost`     | 예약 인스턴스, Savings Plan 또는 볼륨 할인이 적용되기 전의 표준 온디맨드 요금 기준 비용입니다.                        |
| `amortised_cost`               | 사용 기간 동안 분산된 선결제 예약 또는 세이빙스 플랜 요금을 포함한 상각 비용입니다.                                    |
| `is_k8s`                       | 비용이 Kubernetes 워크로드와 연결되어 있는지 여부를 나타내는 플래그입니다.                                      |

쿼리 예:

```sql
FROM CloudCost SELECT * SINCE 24 hours ago
```

## 쿠버네티스 비용 [#kubernetescost]

`KubernetesCost` 클라우드 비용 인텔리전스에서 생성된 비용 할당 이벤트입니다. cloud 비용을 쿠버네티스 클러스터, 네임스페이스, 파드 및 컨테이너별로 분류합니다. 이 이벤트 유형은 NRQL 절의 하위 집합만 지원합니다.

### 주요 속성

다음 속성은 KubernetesCost 쿼리를 작성하는 데 가장 유용합니다:

| 기인하다                 | 설명                                                  |
| -------------------- | --------------------------------------------------- |
| `total_cost`         | `cpu_costs` 및 `memory_costs`의 합계로 계산된 총 비용입니다.      |
| `cpu_costs`          | CPU 사용량 속성으로 할당된 비용의 일부입니다.                         |
| `memory_costs`       | 메모리 사용량에 속성된 비용의 일부입니다.                             |
| `net_unblended_cost` | 기본 EC2 노드 비용에 대한 리소스의 사용량 점유율을 기반으로 한 할인 후 순 비용입니다. |
| `cpu_usage`          | 할당된 CPU 코어 대비 사용 중인 CPU 코어의 비율입니다(0에서 1 사이의 값).     |
| `memory_usage`       | 할당된 메모리 대비 사용 중인 메모리의 비율입니다(0과 1 사이의 값).            |
| `cluster_name`       | 노드와 파드를 호스팅하는 클러스터의 이름입니다.                          |
| `namespace_name`     | Kubernetes 네임스페이스 ― 서비스 및 배포 노드의 논리적 분리입니다.         |
| `pod_name`           | Kubernetes 파드 이름입니다. 파드는 하나 이상의 컨테이너를 호스팅할 수 있습니다.  |
| `container_name`     | 도커 컨테이너 이름입니다.                                      |
| `node_name`          | 파드가 배포된 EC2 노드입니다.                                  |
| `deployment_name`    | 파드를 관리하는 Kubernetes 배포의 이름입니다.                      |

쿼리 예:

```sql
FROM KubernetesCost SELECT * SINCE 1 week ago
```

정확한 Kubernetes 비용을 확인하려면 쿼리에 `cpu_weightage + memory_weightage` 곱하세요.

```sql
SELECT SUM(net_unblended_cost * (cpu_weightage + memory_weightage) + network_net_unblended_cost) FROM KubernetesCost SINCE '2026-09-01' UNTIL '2026-09-10'
```

쿼리는 리소스 사용량을 기반으로 한 정확한 비용 할당을 위해 `net_unblended_cost`에 CPU 및 메모리 가중치의 합을 곱합니다.

<img title="Query Console showing KubernetesCost event attributes" alt="Query Console showing KubernetesCost event attributes" src="/images/kubernetes-cost-cci.webp" />

가장 비용이 많이 드는 Kubernetes 네임스페이스 식별:

```sql
FROM KubernetesCost SELECT SUM(total_cost) FACET namespace_name SINCE 1 week ago LIMIT 10
```

클러스터별 CPU 비용과 메모리 비용 비교:

```sql
FROM KubernetesCost SELECT SUM(cpu_costs), SUM(memory_costs) FACET cluster_name SINCE 1 week ago
```

CPU 사용량이 낮은 활용도가 떨어지는 컨테이너를 찾습니다:

```sql
FROM KubernetesCost SELECT average(cpu_usage) FACET container_name WHERE cpu_usage < 0.2 SINCE 3 days ago
```

## 클라우드 비용 추정 [#cloudcostestimate]

`CloudCostEstimate` 클라우드 비용 인텔리전스에서 생성된 실시간 이벤트입니다. 팀 소유권, 환경 및 서비스 이름과 같은 메타데이터와 AWS 인스턴스 세부 정보를 포함하여 리소스 수준에서 예상 cloud 비용을 제공합니다. 이 이벤트 유형은 NRQL 절의 하위 집합만 지원합니다.

### 주요 속성

다음 속성은 CloudCostEstimate 쿼리를 작성하는 데 가장 유용합니다:

| 기인하다            | 설명                                                     |
| --------------- | ------------------------------------------------------ |
| `cost`          | 사용 기간 동안 리소스에 대한 cloud 청구서 통화 기준 예상 비용입니다.             |
| `owning_team`   | 리소스에 적용된 `owning_team` 태그의 값입니다(있는 경우).                |
| `product_code`  | Cloud 공급자 서비스 코드(예: `EC2`)입니다.                         |
| `service_name`  | 예상치에 해당하는 서비스입니다.                                      |
| `instance_type` | AWS EC2 인스턴스 유형입니다(예: `m6g.8xlarge`). AWS 리소스에만 적용됩니다. |
| `aws_region`    | 리소스가 배포된 AWS 리전입니다(예: `us-east-2`).                    |
| `department`    | 리소스에 적용된 `department` 태그의 값입니다(있는 경우).                 |
| `environment`   | 리소스의 `environment` 태그에서 가져온 리소스의 배포 환경입니다.             |

쿼리 예:

```sql
FROM CloudCostEstimate SELECT * SINCE 24 hours ago
```

<img title="Query Console showing CloudCostEstimate event attributes" alt="Query Console showing CloudCostEstimate event attributes" src="/images/cloud-cost-estimate.webp" />

소유 팀별 예상 비용 검토:

```sql
FROM CloudCostEstimate SELECT SUM(cost) FACET owning_team SINCE 24 hours ago
```
