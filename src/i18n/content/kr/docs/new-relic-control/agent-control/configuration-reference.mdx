이 페이지에서는 수정할 수 있는 Agent Control 설정과 기본값을 안내합니다. 로컬 및 원격 설정에 대한 개요와 Agent Control이 관리하는 에이전트를 설정하는 방법의 예는 [설정 관리](/docs/new-relic-control/agent-control/configuration)를 참조하십시오.

플릿 컨트롤 연결(`fleet_control`), `host_id`, 관리되는 `agents` 및 값 제공자에 대한 내용은 [설정 관리](/docs/new-relic-control/agent-control/configuration)에서 다룹니다.

### 환경 변수로 설정 재정의 [#environment-variables]

모든 설정을 환경 변수로 설정할 수 있습니다. `NR_AC_` 접두사를 사용하고 설정 이름은 대문자로 작성하며, 중첩된 키를 구분하려면 이중 밑줄(`__`)을 사용하십시오. 환경 변수는 로컬 설정 파일보다 우선합니다.

```bash
# log.level
NR_AC_LOG__LEVEL=DEBUG

# fleet_control.auth_config.client_id
NR_AC_FLEET_CONTROL__AUTH_CONFIG__CLIENT_ID="some-client-id"
```

호스트에서는 서비스 환경 파일 또는 로컬 설정 디렉터리(Linux의 경우 `/etc/newrelic-agent-control/`, Windows의 경우 `C:\Program Files\New Relic\newrelic-agent-control\`)의 `environment_variables.yaml` 파일에서 이러한 변수를 정의할 수 있습니다. 파일은 문자열 키를 문자열 값으로 매핑하는 플랫 YAML 맵이어야 합니다:

```yaml
NR_AC_LOG__LEVEL: "DEBUG"
HTTPS_PROXY: "http://proxy.local:8443"
```

* 키는 문자나 밑줄로 시작해야 하며 문자, 숫자, 밑줄만 포함해야 합니다.
* 에이전트 제어는 이 파일을 감시하지 않습니다. 변경 후 에이전트 제어를 다시 시작하십시오.
* Agent Control은 이러한 변수를 관리하는 에이전트에 전달합니다.
* 파일에 유효하지 않은 항목이 있는 경우, 에이전트 컨트롤이 시작되지 않습니다.

## 로깅: `log` [#log]

`log` 설정을 사용하여 로그 레벨을 변경하거나, 파일 로깅을 활성화하거나, 로그 형식을 변경하십시오.

```yaml
log:
  level: debug
  format:
    formatter: pretty
    target: true
  file:
    enabled: true
    path: /var/log/my-folder/agent-control.log
```

## 프록시: `proxy` [#proxy]

에이전트 컨트롤은 시스템의 `HTTP_PROXY` 및 `HTTPS_PROXY` 환경 변수를 사용합니다. `proxy` 설정으로 프록시를 설정할 수도 있습니다. 하나 이상 정의된 경우 Agent Control은 다음 우선순위에 따라 이를 사용합니다:

1. `proxy` 설정
2. `HTTP_PROXY` 환경 변수
3. `HTTPS_PROXY` 환경 변수

```yaml
proxy:
  url: https://user:password@proxy.example.com:8080
  ca_bundle_file: /etc/ssl/certs/proxy-ca.pem
```

      interval: 120s

## 패키지 및 에이전트 유형 검증 [#verification]
