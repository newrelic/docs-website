[자동화된 사용자 관리](/docs/accounts/accounts/automated-user-management/automated-user-provisioning-single-sign)를 통해 관리되는 뉴렐릭 One 플랫폼 사용자는 이전에 자격 증명 공급자(IdP)를 통해서만 시간대를 설정할 수 있었습니다.

이제 모든 사용자는 뉴렐릭 One에서 이를 업데이트하여 이러한 시간대 기본 설정을 재정의할 수 있습니다. 이는 시간대 기본 설정을 뉴렐릭으로 보낼 수 없는 IdP를 사용하는 고객에게 특히 유용합니다.

이를 수행하려면 사용자 환경설정으로 이동하여 시간대를 업데이트하십시오. 새로운 환경설정을 자동으로 저장하고 ID 제공자를 통해 전송되는 내용을 재정의합니다.

자세한 내용은 [시간대 설정 문서](/docs/accounts/accounts-billing/general-account-settings/default-time-zone-setting)를 참조하십시오.
