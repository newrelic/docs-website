### 새로운 기능

* **분산 추적 지원**

  분산 추적은 요청이 분산 시스템을 통해 이동하는 경로를 확인할 수 있도록 해줍니다. 통합된 뷰를 통해 분산된 활동을 보여줌으로써, 이전보다 더 잘 복잡한 시스템의 문제를 해결하고 이해할 수 있습니다.

  분산 추적은 APM Pro 또는 이에 상응하는 구독으로 이용할 수 있습니다. 완전한 분산 트레이스를 보려면 인접한 서비스 세트에서 해당 기능을 활성화해야 합니다.

  C SDK에 대한 분산 추적을 활성화하는 방법에 대한 자세한 내용은 뉴렐릭 [C SDK 문서](https://docs.newrelic.com/docs/agents/c-sdk/instrumentation/enable-distributed-tracing-your-c-applications)를 참조하십시오.

### 수명 종료 공지

* `newrelic_app_config_t`의 `log_filename` 및 `log_level` 필드는 현재 더 이상 사용되지 않습니다. C SDK의 향후 버전에서는 이러한 필드가 영구적으로 제거됩니다. C SDK와 함께 사용할 로그 파일 및 로그 레벨을 지정하려면 `newrelic_configure_log()`을(를) 사용하십시오.
