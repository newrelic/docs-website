이제 NerdGraph API를 사용하여 사용자의 이름, 사용자 ID, 사용자 유형, 이메일 및 마지막 활성 날짜를 쿼리할 수 있습니다. 또한 사용자의 사용자 유형과 이메일 주소를 업데이트할 수 있습니다.

자세한 내용은 [NerdGraph 문서](/docs/apis/nerdgraph/examples/nerdgraph-manage-users)를 참조하십시오.
