뉴렐릭에 대한 사용자의 액세스 관리가 더 쉬워졌습니다. 그룹에 더 초점을 맞추도록 [**액세스 관리** UI 페이지](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-ui-and-tasks#where)를 개선했습니다. 이제 그룹이 액세스할 수 있는 역할과 계정을 더 빠르게 파악하고, 그룹을 생성하며, 그룹 액세스를 편집할 수 있습니다.

또한 상위 수준의 관리 기능을 관리하는 방법도 간소화했습니다. 이전에는 이러한 기능에 대해 별도의 조직 범위 역할이 있었습니다. 이제 **Groups** UI 페이지에서 조직 수준의 관리 설정(결제, 조직 설정, 인증 도메인 설정 등)을 그룹에 쉽게 할당할 수 있습니다.

자세히 알아보려면:

* **액세스 관리** UI 페이지를 참조하십시오.
* [그룹 액세스를 할당하는 방법을 읽어 보십시오.](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial#group-access)
* [관리 설정에 대해 읽어 보십시오.](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts#admin-settings)
