**User management** \[사용자 관리] UI에서 사용자 데이터를 내보내는 기능을 출시했습니다. 데이터는 TSV를 통해 내보낼 수 있습니다. 내보낼 수 있는 열에는 사용자의 이름, 이메일 주소, 현재 사용자 유형, 그룹 및 사용자 ID가 포함됩니다. 관리자는 모든 사용자를 내보내거나 일부 사용자를 선택할 수 있습니다.

자세한 내용은 [사용자 목록 내보내기](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-ui-and-tasks)를 참조하십시오.
