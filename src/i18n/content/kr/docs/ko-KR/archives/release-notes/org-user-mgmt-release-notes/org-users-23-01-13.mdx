일부 [인증 도메인](https://docs.newrelic.com/docs/accounts/accounts-billing/new-relic-one-user-management/authentication-domains-saml-sso-scim-more) 설정의 위치를 변경했습니다. 변경 사항은 다음과 같습니다:

* **인증 도메인** UI를 [**관리** UI 메뉴](https://docs.newrelic.com/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-ui-and-tasks/#where)에 배치했습니다.
* 사용자 세션 설정 및 사용자 업그레이드 설정을 **사용자 관리** UI 페이지로 이동했습니다.
