### 새로운 기능

* **실시간 스트리밍 지원**

  * 이제 이벤트 데이터가 매 분 대신 5초마다 뉴렐릭으로 전송됩니다. 결과적으로 트랜잭션, 오류 및 커스텀 대시보드를 이제 뉴렐릭 대시보드에서 거의 실시간으로 사용할 수 있습니다. 5초 새로 고침으로 이벤트를 보는 방법에 대한 자세한 내용은 [실시간 스트리밍 문서](/docs/agents/manage-apm-agents/agent-data/real-time-streaming)를 참조하십시오.
  * 분당 전송할 수 있는 이벤트 수에 대한 전체 제한은 변경되지 않았음을 참고하십시오. 또한, 스팬 이벤트, 메트릭 및 트레이스 데이터는 영향을 받지 않으며 여전히 매분 전송됩니다.

### 버그 수정

* `newrelic_create_app_config()` (으)로 생성된 기본 설정은 이제 미국 외 계정의 라이선스 키와 함께 예상대로 작동합니다.

* `pr` (우선순위) 및/또는 `sa` (샘플링됨)에 대해 유효하지 않거나 누락된 값이 있는 인바운드 분산 추적 페이로드의 경우, 에이전트는 트랜잭션에 기본 우선순위 -1 및/또는 기본 샘플링된 값 `false`를 할당했습니다.

  이 문제가 수정되었습니다: 이제 인바운드 분산 추적 페이로드의 해당 값이 누락되거나 유효하지 않은 경우 에이전트가 초기 우선순위 및 샘플링된 값을 유지합니다.
