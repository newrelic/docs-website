당사의 교차 도메인 ID 관리 시스템(SCIM) API는 이제 사용자의 [사용자 유형](/docs/accounts/accounts-billing/new-relic-one-user-management/user-type) 관리를 지원합니다. 이를 통해 최신 사용자 모델의 사용자를 보유한 엔터프라이즈 고객은 ID 공급자(IdP) 또는 SCIM을 지원하는 모든 커스텀 통합을 통해 사용자 유형을 관리할 수 있습니다. 이는 (항상 사용자를 풀 사용자로 프로비저닝하는 대신) 사용자를 베이직 또는 풀 사용자로 프로비저닝하고, 롤링 기준 12개월 동안 사용자당 2회의 다운그레이드를 허용하는 뉴렐릭 [청구 정책](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/new-relic-one-pricing-billing/#user-count) 내에서 자동으로 업그레이드 및 다운그레이드하는 데 특히 유용합니다.

이 릴리스에는 [SCIM 튜토리얼](/docs/accounts/accounts/automated-user-management/tutorial-manage-users-groups-scim)과 관리자가 API를 통해 사용자 유형을 관리하는 고객을 위해 고객별 업그레이드 요청 프로세스를 전달하는 사용자 지정 메시지 및/또는 URL을 셀프 업그레이드 페이지에 추가할 수 있는 기능이 포함되어 있습니다.

사전 구축된 [Okta 통합](/docs/accounts/accounts/automated-user-management/okta-scimsso-application-configuration/)을 사용하여 이를 활성화하는 방법에 대한 지침이 있습니다. 현재 OneLogin 또는 Azure AD 통합에 대한 단계별 지침은 없습니다. 이 중 하나를 사용하는 경우, 새로운 속성인 [`nrUserType`](/docs/accounts/accounts/automated-user-management/scim-support-automated-user-management/#user-type)을(를) 전송하도록 ID 공급자를 구성해야 합니다.

자세한 내용은 다음을 참조하세요.

* [**사용자 유형 관리** 옵션.](/docs/accounts/accounts-billing/new-relic-one-user-management/authentication-domains-saml-sso-scim-more/#user-upgrade)
* 사용자 유형에 대한 [SCIM API 지침](/docs/accounts/accounts/automated-user-management/scim-support-automated-user-management/#user-type)입니다.
