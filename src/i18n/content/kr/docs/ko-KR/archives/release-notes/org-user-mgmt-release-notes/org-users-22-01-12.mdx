## 코어 사용자가 있는 뉴렐릭 One 요금 모델의 새 버전

[새로운 사용자 유형 인 코어 사용자가](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/new-relic-one-pricing-billing) 포함된 새로운 버전의 New Relic One 요금 모델 [](/docs/accounts/accounts-billing/new-relic-one-user-management/user-type)을 출시했습니다. 이 요금 버전을 사용하는 조직은 세 가지 사용자 유형: 기본 사용자, 코어 사용자, 전체 플랫폼 사용자에 액세스할 수 있습니다. 코어 사용자는 기본 사용자보다 더 많은 액세스 권한을 가지며 전체 플랫폼 사용자보다 비용이 적게 듭니다. 코어 사용자는 뉴렐릭 CodeStream, 로그 UI, 뉴렐릭 앱 빌드 기능 같은 강력한 개발자 중심 기능에 액세스할 수 있습니다.

이 요금제 버전은 또한 [청구 대상 사용자를 다르게 계산](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/user-count-billing#user-count) 하며 [다른 사용자 다운그레이드 규칙](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/user-count-billing/#user-downgrade-rules)을 적용합니다.

이 릴리스 및 가용성에 대한 자세한 내용은 [코어 사용자 릴리스](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/core-users-release)를 참조하십시오.
