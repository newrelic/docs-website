## 이제 프로 에디션에서 자동화된 사용자 관리를 사용할 수 있습니다.

뉴렐릭의 [자동화된 사용자 관리](/docs/accounts/accounts/automated-user-management/automated-user-provisioning-single-sign) 기능은 이제 뉴렐릭의 [프로 에디션](https://newrelic.com/pricing)을 사용하는 조직에서 사용할 수 있습니다. 이전에는 엔터프라이즈 에디션을 사용하는 조직에서만 사용할 수 있었습니다.

자동화된 사용자 관리를 사용하면 SCIM 프로비저닝을 사용하여 Azure AD, Okta 또는 OneLogin과 같은 ID 공급자에서 뉴렐릭 사용자를 가져오고, 업데이트하고, 비활성화할 수 있습니다. 또한 ID 공급자를 통해 사용자 유형 및 시간대를 포함하여 사용자에 대한 속성을 관리할 수 있습니다.
