### 새로운 기능

뉴렐릭 C SDK의 첫 번째 릴리스입니다! 애플리케이션이 [다른 뉴렐릭 APM 에이전트 언어](https://docs.newrelic.com/docs/agents/manage-apm-agents/installation/compatibility-requirements-new-relic-agents-products#apm-compatibility)를 사용하지 않는 경우, C SDK를 사용하여 뉴렐릭의 모니터링 역량과 기능을 활용해 다양한 애플리케이션을 계측할 수 있습니다.

자세한 내용은 다음을 참조하세요.

* [문서](/docs/agents/c-sdk): C SDK를 시작하고, 설치 및 구성하고, 트랜잭션, 세그먼트 및 오류를 계측하고, C SDK API를 사용하고, 몇 가지 기본적인 문제 진단, 해결을 수행하는 방법입니다.
* [GitHub](https://newrelic.github.io/c-sdk/index.html): SDK 파일, 데이터 구조, 필드 정의 및 파라미터, 코드 예제, 함수, 변수.

### 수명 종료 공지

이전 APM 에이전트 SDK는 더 이상 사용되지 않는 베타 소프트웨어입니다. 이전에 에이전트 SDK를 사용한 경우 C SDK로 전환할 수 있습니다. [호환성 및 요구 사항](/docs/c-sdk-compatibility-requirements)을 확인한 다음, C SDK를 사용하도록 애플리케이션의 코드를 [계측, 컴파일 및 연결](/docs/install-c-sdk-compile-link-your-code) 하십시오. C SDK는 현재 뉴렐릭의 HSM 기능을 지원하지 않으며, 이는 에이전트 SDK에서 전환하는 일정에 영향을 미칠 수 있습니다.
