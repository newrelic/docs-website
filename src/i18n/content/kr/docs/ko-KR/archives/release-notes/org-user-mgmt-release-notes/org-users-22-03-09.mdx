이번 릴리스를 통해 [핵심 사용자](/docs/accounts/accounts-billing/new-relic-one-user-management/user-type/#user-type-capabilities)는 사용자를 관리하고 결제를 관리할 수 있습니다. 수행할 수 있는 작업은 다음과 같습니다:

* [**인증 도메인 관리자** 표준 역할](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts#roles)이 있는 경우 사용자 관리 작업을 수행하십시오.
* [**결제 사용자** 표준 역할](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts#roles)이 있는 경우 결제 관리 작업을 수행합니다.
