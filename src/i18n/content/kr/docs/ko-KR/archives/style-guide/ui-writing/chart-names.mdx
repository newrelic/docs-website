title: 차트 이름
translationType: machine
---

뉴렐릭 One에서는 사용자가 직접 차트를 생성하고 이름을 지정할 수 있지만, 당사에서 제공하는 일부 선별된 차트도 있습니다. 사용자가 무엇을 보고 있는지 알 수 있도록 이러한 차트의 이름은 명확하고 기술적이어야 합니다.

## 기본 사항

* 명확한 키워드를 사용하십시오.
* 차트의 목적을 설명할 수 있는 충분한 정보를 제공하고, 한 단어로 된 이름은 피하십시오.
* 일관성보다 정확성을 목표로 하십시오. 일부 차트에는 완벽하지만 다른 차트에는 부정확한 명명 규칙을 따르는 것보다 유사한 차트에 대해 약간 다른 이름을 사용하는 것이 좋습니다.
* 이름을 문장 대소문자로 유지하십시오.

| 권장 사항          | 하지 마십시오  |
| -------------- | -------- |
| 가장 느린 5개의 트랜잭션 | 업무       |
| 오류 분류 기준:      | 오류       |
| 트레이스 그룹화 기준:   | 트레이스 그룹화 |
