축약형은 글에 대화체와 개인적인 느낌을 더해 주는 좋은 방법입니다. 자연스럽게 느껴질 때 사용하십시오.

## 기본 사항

* 누군가에게 말할 때 사용하는 것과 같은 위치에 일반적인 축약형을 사용하십시오.
* 흔하지 않거나 부자연스럽게 들리는 축약어 사용을 피하십시오.

| 권장 사항               | 하지 마십시오                |
| ------------------- | ---------------------- |
| 애플리케이션을 업데이트했습니다.   | 애플리케이션을 업데이트했습니다.      |
| 오류가 4개인 경우에만 해당합니다. | 4개의 오류가 있는 경우에만 해당합니다. |
| 말씀드릴 수 없습니다.        | 말씀드릴 권한이 없습니다.         |
