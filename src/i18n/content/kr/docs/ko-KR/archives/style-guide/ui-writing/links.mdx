UI의 링크는 간결해야 하며 당사의 스타일 및 어조와 일치해야 합니다.

## 기본 사항

* 화면 판독기에 최적화할 수 있도록 링크 텍스트를 짧게 유지하십시오.
* 링크 위치가 아니라 독자가 얻을 수 있는 이점부터 시작하십시오.
* 다른 카피에서와 마찬가지로 대화형 언어, 대명사 및 축약형을 사용하십시오.
* 단순히 &quot;이 링크&quot; 대신 위치의 이름이나 설명을 사용하십시오.
* 사용자를 제품 외부로 안내하는 링크(예: 문서 또는 지원 사이트)의 경우 끝에 외부 링크 아이콘을 추가하십시오.

## 암호

고객에게 코드 스니펫을 제공할 때는 Menlo 고정폭 글꼴로 서식을 지정하십시오.

```js
var example = "This is an example string in a monospace font!";
```

## 목록

* 각 목록 항목의 첫 글자는 대문자로 작성하십시오.
* 일반적인 정보 목록에는 정렬되지 않은(글머리 기호) 목록을 사용하십시오.
* 특정 단계가 있는 목록의 경우 정렬된(숫자) 목록을 사용하십시오.
