콜랩서는 [트리거하여 열](#trigger-collapser) 때까지 페이지 콘텐츠를 숨기는 확장 가능한 요소입니다. 독자를 배려하여 매우 긴 문서의 콘텐츠를 숨기기 위해 콜랩서를 사용합니다. 각 콜랩서에는 `title` (독자에게 표시되는 내용)이 있지만, 특정 콜랩서에 대한 딥 “앵커” 링크에 사용하는 `id`도 있습니다.

다음은 예제 접기입니다:

<CollapserGroup>
  <Collapser id="collapser-1" title="접기 1">
    이것은 첫 번째 예제 콜랩서입니다.
  </Collapser>

  <Collapser id="collapser-2" title="접기 2">
    이것은 두 번째 예제 축소기입니다.
  </Collapser>
</CollapserGroup>

<Callout variant="tip">
  축소기를 위한 키보드 마에스트로 매크로는 `kkcollapse`입니다.
</Callout>

## 축소기 생성 [#create]

접기를 생성하려면 접기 코드를 사용해야 합니다.

다음은 collapser 소스 예제입니다:

```jsx
<CollapserGroup>
  <Collapser
    id="collapser-1"
    title="Collapser 1"
  >
    This is our first example collapser.
  </Collapser>

  <Collapser
    id="collapser-2"
    title="Collapser 2"
  >
    This is our second example collapser.
  </Collapser>
</CollapserGroup>
```

## 접기 트리거 [#trigger-collapser]

사이트는 몇 가지 시나리오에서 자동으로 축소기를 엽니다:

* 앵커 ID를 통해 개별 콜랩서에 도달합니다. 예를 들어, [위 예시의 콜랩서 1](/docs/style-guide/quick-reference/collapsers#collapser-1)로 직접 이동하십시오.
* 페이지에서 찾으려면 **CMD+F** (또는 **CTRL+F**)를 사용하십시오. 그러면 모든 콜랩서가 자동으로 열립니다.
* 페이지의 모든 축소기를 **표**시(열기)하려면 바로 가기 키 `s`을(를) 입력하십시오.
