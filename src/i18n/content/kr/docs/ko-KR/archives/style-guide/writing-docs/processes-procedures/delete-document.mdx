---
title: 문서 삭제
translationType: machine
---

<Callout variant="caution">
  문서를 삭제해도 해당 콘텐츠와 리디렉션은 GitHub 커밋 기록에서 계속 사용할 수 있습니다.
</Callout>

문서를 삭제하려면:

1. 삭제하려는 문서의 MDX 파일을 찾으십시오.

2. 리디렉션에 주의하십시오:

   1. 독자를 리디렉션할 가장 관련성 높은 문서를 찾으십시오.
   2. [삭제된 문서의 URL을 리디렉션으로 추가하십시오](/docs/style-guide/rename-or-redirect-document).
   3. 삭제된 문서에서 기존 리디렉션을 복사하여 새 문서에 추가하십시오.

3. 적절한 nav 파일에서 문서의 제목과 경로를 삭제하십시오.

4. 문서 MDX 파일을 삭제하십시오.

5. `src/i18n/content` 디렉터리에서 해당 MDX 파일을 삭제하십시오. 각 영어 문서에는 현지화된 각 언어에 대한 MDX 파일이 있습니다. `i18n-utility` 스크립트를 사용하여 이 작업을 자동으로 수행할 수 있습니다:
   ```bash
   yarn i18n-utility delete-orphans
   ```
