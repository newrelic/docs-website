UI를 위해 작성할 때, 당사는 회사의 다른 부서와 동일한 가이드라인을 많이 따릅니다. 자주 묻는 질문이나 더 광범위한 뉴렐릭 스타일 가이드라인과의 약간의 차이점을 다루기 위해 이 섹션에서 몇 가지 특정 요소를 강조했습니다.

## 당사 어조

뉴렐릭은 제품, 문서, 메시징 및 영업 자료 등 카피를 작성하는 모든 곳에서 사용하는 보이스를 가지고 있습니다.

당사는 미국 영어를 사용하며 **정직하고**, **힘을 실어주며**, **독창적인** 방식으로 글을 작성합니다.

뉴렐릭은 신뢰할 수 있는 친구처럼 느껴집니다. 투명하고 낙관적이며 직관적이고 혁신적입니다. 뉴렐릭 보이스로 작성하는 방법에 대한 자세한 내용은 [보이스에 대한 뉴렐릭 스타일 지침](/docs/style-guide/writing-strategies/voice-strategies-docs-sound-new-relic#voice-strategies)을 참조하십시오.

몇 가지 팁:

* 격식 있는 언어가 아닌 대화형 어조를 사용하십시오.
* 대명사와 축약형을 사용하십시오.
* 독자에게 직접 이야기하십시오.
* 복잡한 개념을 간단하고 명확하게 설명하고 전문 용어 사용을 제한하십시오.
* 해당 작업이나 기능에서 사용자가 얻는 것이 무엇인지 스스로에게 질문한 다음, 그 관점에서 작성하십시오.
* 사용자에게 가치나 이점을 먼저 제시한 다음, 이를 달성하는 방법을 설명하십시오.
* 사용자가 해야 할 일을 더 잘 표현할 수 있다면 대담하고 혁신적인 단어를 사용하십시오. 일반적인 업계 용어에 얽매이지 마십시오.

| 권장 사항                                                     | 하지 마십시오                                                                  |
| --------------------------------------------------------- | ------------------------------------------------------------------------ |
| 로그인부터 데이터베이스 호출까지 모든 유형의 트랜잭션에 대한 보고서를 확인하십시오.            | 뉴렐릭은 웹 트랜잭션 및 비 웹 트랜잭션에 대한 정보를 수집하고 보고합니다.                               |
| 알림을 사용하여 이벤트 또는 인시던트를 추적하십시오. 또는 알림으로 이벤트 및 인시던트를 추적하십시오. | 공지는 지정된 담당자가 뉴렐릭 알림을 통해 추적할 수 있는 이벤트 또는 인시던트를 전달합니다.                     |
| 실시간 메트릭과 강력한 분석을 통해 문제를 더 빠르게 찾고 해결하십시오.                  | 뉴렐릭의 실시간 메트릭과 강력한 분석은 호스트 성능의 변경 사항을 설정 변경 사항에 연결하여 평균해결시간(MTTR)을 줄여줍니다. |
| 미국식 철자를 사용하십시오. 예: *방어 카탈로그 라이선스를 최적화하십시오.*               | 영국식 철자를 사용하십시오. 예: *Optimise the defence catalogue licence.*             |
