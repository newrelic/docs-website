이미지 주석은 화면 캡처나 다이어그램의 텍스트 및 도형으로, 정보를 참조하고 스크린샷의 가장 중요한 측면에 주의를 집중시키는 데 도움이 됩니다. 때로는 주의를 산만하게 할 수 있고 최신 상태로 유지하기도 어려울 수 있으므로 주의해서 사용하시기 바랍니다. [이미지 캡션](/docs/style-guide/images/screenshots-images/#captions)이나 텍스트 내 지침과 같은 대안을 사용할 수 있다는 점을 명심하십시오.

이미지 주석을 사용해야 하는 경우:

* 간결하게 작성하십시오.
* 주석이 UI 텍스트와 쉽게 구별되도록 하십시오. 예를 들어, 상자가 UI 요소처럼 보이지 않도록 오프셋을 조정해야 할 수 있습니다.
* 주석은 번역되지 않으므로 적게 사용하십시오.
* 상단에 제목처럼 작동하는 주석을 사용하지 마십시오. 캡션을 사용하십시오.
* 다크 모드와 라이트 모드에서 주석이 보이는지 확인하십시오.
* 주석의 일관성을 유지하려면 [뉴렐릭 SnagIt 테마](https://github.com/newrelic/newrelic-doc-tools) (뉴렐릭 직원에게만 제공되는 링크)를 사용하십시오.

## 뉴렐릭 SnagIt 테마 설치 [#install-theme]

이 단계를 따르세요:

1. 최신 버전의 SnagIt을 실행 중인지 확인하십시오.

2. GitHub Desktop에서 [리포지터리](https://github.com/newrelic/newrelic-doc-tools)를 로컬로 복제하십시오.

3. SnagIt을 열고 아무 도구나 선택하여 오른쪽 탐색 창을 여십시오.

4. 오른쪽 탐색 메뉴의 **Quick Styles** 창 아래에 있는 **Theme** 필드에서 톱니바퀴 아이콘을 선택한 다음 **Import**를 선택하십시오.

5. 열리는 대화 상자에서 `YOUR_GIT_DIRECTORY/newrelic-doc-tools/themes`(으)로 이동하여 `New-Relic-Docs.snagtheme` 파일을 선택하고 **Open** \[열기]를 클릭하십시오.

6. 가져온 테마가 테마 필드에 이미 선택되어 있습니다.

## 콜아웃 상자 [#callout-boxes]

스크린샷 내의 요소를 강조하려면 콜아웃을 사용하십시오. 가능하면 스크린샷에 텍스트를 추가하지 마십시오. 텍스트는 문서에서 제공해야 합니다. 콜아웃 상자는 가리키는 요소를 가려서는 안 됩니다. 예를 들어, UI 버튼 주위의 콜아웃 상자는 버튼의 어떤 부분도 가려서는 안 됩니다. 가능하면 UI 요소와 콜아웃 상자 사이에 2픽셀의 여백을 두십시오.

콜아웃 상자를 추가하는 형식은 다음과 같습니다:

* 모양: 정사각형 또는 직사각형, 투명한 채우기, 테두리 반경 없음.
* 테두리 색상: #00CE7C
* 선 너비: 5pt
* 불투명도: 100%
* 선 스타일: 실선
* 그림자가 없습니다.

## 콜아웃 텍스트 [#callout-text]

스크린샷은 99%의 경우 텍스트 콜아웃이 필요하지 않으며, 이미지 앞이나 뒤의 `<figcaption>` 태그와 작성된 콘텐츠만으로도 스크린샷을 설명하기에 충분해야 합니다. 하지만 텍스트 상자가 필요한 경우, 필수 UI 텍스트나 요소와 겹치지 않아야 합니다.

스크린샷에 텍스트를 추가해야 하는 경우 다음 지침을 따르십시오:

* 모양: 정사각형 또는 직사각형, 채우기 색상 #00CE7C.
* 테두리 색상: #00CE7C
* 선 너비: 5pt
* 불투명도: 100%
* 선 스타일: 실선
* 그림자가 없습니다.
* 글꼴: Arial 굵게 #FFFFFF, 크기 24pt, 왼쪽 정렬

## 화살표 [#arrows]

UI 내의 요소를 참조하려는 경우 스크린샷에 단방향 화살표 또는 양방향 화살표를 사용하십시오.

화살표를 사용하는 경우, 필수 UI 텍스트 또는 요소와 겹치지 않도록 하십시오.

화살표를 추가하는 형식은 다음과 같습니다:

* 불투명도: 100%
* 선 너비: 7pt
* 색상: #00CE7C
* 선 스타일: 실선, 시작 크기 없음, 끝 크기 5
* 그림자가 없습니다.
