소개: 이 섹션에서는 에이전트와 API에 대해 전반적으로 소개합니다. 사용자가 API를 필요로 하는 경우와 API 사용에 대한 대안(예: XML 파일을 통한 계측)에 대해 설명하십시오. 프레임워크에서 “기본적으로” 지원하는 경우 API가 불필요한 경우가 많다는 점을 언급하십시오. 온사이트 또는 오프사이트 여부에 관계없이 API 참조의 루트로 링크하십시오. 사용자에게 최신 에이전트 버전을 사용해야 한다고 경고하십시오.

## 트랜잭션으로 코드의 누락된 섹션 계측 [#creating-transactions]

앱을 계측하기 위해 뉴렐릭은 코드를 통과하는 각 경로를 자체 트랜잭션으로 분리합니다. 뉴렐릭은 앱의 전반적인 성능을 측정하기 위해 이러한 트랜잭션에서 상위 메서드의 시간을 측정(또는 “계측”)하고, 추가 세부 정보를 위해 장기 실행 트랜잭션에서 트랜잭션 트레이스를 수집합니다. 트랜잭션에 대한 자세한 내용은 [트랜잭션](/docs/accounts-partnerships/education/getting-started-new-relic/glossary#transaction) 및 [트랜잭션 트레이스](/docs/apm/transactions/transaction-traces/introduction-transaction-traces)를 참조하십시오.

New Relic이 코드의 특정 부분을 전혀 계측하지 않을 때 다음 방법을 사용하십시오.

      </th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>
        뉴렐릭이 자동으로 계측하지 않는 메서드의 타이밍 측정을 시작하십시오...
      </td>

      <td>
        새 트랜잭션을 생성합니다. \[startTransaction()에 해당하는 참조 또는 튜토리얼 문서 링크]를 참조하십시오.
      </td>
    </tr>

    <tr>

      </td>

      </td>

      </td>
    </tr>
  </tbody>
</table>

## 세그먼트를 사용한 시간별 방법 [#segments]

트랜잭션이 이미 뉴렐릭 UI에 표시되어 있지만 해당 트랜잭션 중에 호출된 특정 메서드에 대한 데이터가 충분하지 않은 경우, 세그먼트를 생성하여 이러한 개별 메서드의 시간을 더 자세히 측정할 수 있습니다. 예를 들어, 복잡한 로직이 포함된 특히 중요한 메서드의 시간을 측정하고자 할 수 있습니다.

기존 트랜잭션 내에서 메소드를 계측하려면 다음 메소드를 사용하십시오.

  <thead>
    <tr>
      <th>
        원하는 경우...
      </th>

      <th>
        이게 ...
      </th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>
        특정 메서드 시간 측정...
      </td>

      <td>

      </td>
    </tr>
  </tbody>
</table>

## 트랜잭션의 메타데이터 향상 [#metadata]

때로는 타겟팅하는 코드가 뉴렐릭 UI에 표시되지만, 메서드의 일부 세부 정보가 유용하지 않을 수 있습니다. 예를 들어, 기본 이름이 도움이 되지 않거나(아마도 [메트릭 그룹화 문제](/docs/agents/manage-apm-agents/troubleshooting/metric-grouping-issues#video)를 일으킬 수 있음), 쿼리할 때 더 잘 필터링할 수 있도록 트랜잭션에 [커스텀 속성](/docs/agents/manage-apm-agents/agent-data/collect-custom-attributes)을 추가하고 싶을 수 있습니다.

뉴렐릭 UI에 이미 표시된 트랜잭션을 뉴렐릭이 계측하는 방식을 변경하려면 다음 방법을 사용하십시오:

      </th>

      <th>
        이게 ...
      </th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>
        트랜잭션의 이름을 변경합니다...
      </td>

      <td>
        \[setTransactionName()에 해당하는 참조 문서 또는 튜토리얼 문서 링크]를 참조하십시오.
      </td>
    </tr>

    <tr>
      <td>
        트랜잭션에 메타데이터(고객의 계정 이름 또는 구독 단계 등)를 추가합니다...
      </td>

      <td>
        [커스텀 속성](/docs/agents/manage-apm-agents/agent-data/collect-custom-attributes)을 사용하십시오. \[addCustomParameter()에 해당하는 참조 문서 또는 튜토리얼 문서 링크]를 참조하십시오.

      <td>

    </tr>

    <tr>
      <td>

## 오류 수집 또는 무시 [#errors]
