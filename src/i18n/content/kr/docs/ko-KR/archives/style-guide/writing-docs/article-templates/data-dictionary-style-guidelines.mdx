문서 팀은 뉴렐릭 데이터베이스의 기본 데이터 유형(예: 트랜잭션, 메트릭, 로그) 및 관련 속성에 대한 메타데이터 정보를 저장하는 데이터 사전을 유지 관리합니다. 이 메타데이터는 당사의 속성 사전 서비스에 의해 다음 두 곳에 게시됩니다:

* 뉴렐릭 UI 쿼리 환경에서는 데이터 유형 및 속성 위에 마우스를 올리면 이 정보를 표시합니다.
* 데이터는 문서 사이트의 [속성 사전](https://docs.newrelic.com/attribute-dictionary/)에 나타납니다.

<Callout variant="tip">
  데이터 범위에 대한 몇 가지 제한 사항은 다음과 같습니다.

  * 현재 속성 사전에서 보유하고 있는 유일한 인프라 관련 정보는 Kubernetes에 대한 것입니다.
  * 또한 일부 데이터 유형에 연결할 수 있는 잠재적인 속성이 많음에도 불구하고 메트릭 데이터 유형에 대한 속성은 매우 적습니다 ― 단지 몇 가지 기본 속성만 있습니다.
</Callout>

뉴렐릭의 작성자로서 데이터 사전을 변경해야 하는 경우, GitHub Enterprise의 비공개 저장소에서 변경 작업을 수행합니다. 저장소를 설정하는 방법과 README.md 지침을 찾는 위치에 대해서는 내부 Google Doc 팀 드라이브를 참조하십시오.
