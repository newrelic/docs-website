---
title: 문서 번역
translationType: machine
---

뉴렐릭 문서는 다음 사이트에 있습니다:

* [**docs.newrelic.com**](https://docs.newrelic.com): 영어
* [**docs.newrelic.com/jp/**](https://docs.newrelic.com/jp/): 일본어
* [**docs.newrelic.com/kr/**](https://docs.newrelic.com/kr/): 한국어
* [**docs.newrelic.com/es/**](https://docs.newrelic.com/es/): 스페인어
* [**docs.newrelic.com/pt/**](https://docs.newrelic.com/pt/): 포르투갈어
* [**docs.newrelic.com/fr/**](https://docs.newrelic.com/fr/): 프랑스어

상단 메뉴 표시줄의 버튼을 사용하여 언어를 전환할 수 있습니다.

## 번역 상태 보기 [#translation-status]

모든 문서의 프런트매터에는 사람의 번역 상태가 포함되어 있습니다.

프런트매터에 `translate:` 요소가 없으면 문서는 어떤 언어로도 사람이 번역하지 않습니다. 여전히 당사의 모든 기계 번역 언어로 자동 번역됩니다.

`translate:` 요소에 `jp`과(와) 같은 언어 약어가 있는 경우, 해당 문서는 번역되었거나, 번역될 예정이거나, 번역을 고려 중인 것입니다. 예:

```md
---
title: 'NRQL reference'
translate:
  - jp
  - kr
  - es
  - pt
  - fr
metaDescription: "A detailed reference list of clauses and functions in NRQL, the New Relic query language."
redirects:
  - /docs/insights/using-nrql
```

## 번역된 문서 업데이트 [#update-translation]

이 사이트는 하루에 한 번 자동 작업을 실행하여 문서의 변경 사항을 타겟 언어로 자동 번역합니다.

## 번역된 문서의 SEO 상태 표시 [#translation-seo]

사이트의 프런트엔드는 문서의 [번역 상태](#translation-status) 정보를 사용하여 페이지의 SEO `hreflang` 요소를 표시합니다. 이는 검색 엔진에 해당 페이지가 특정 언어로 제공되는 버전도 있음을 알려줍니다.

```html
<link rel="alternate" href="https://docs.newrelic.com/jp/" hreflang="ja" />
```

## 문서 삭제 및 이동 [#delete]

영어 문서를 변경할 때 GitHub에서 쌍이 맞지 않는 번역 오류가 발생할 수 있습니다. i18n 폴더를 변경하는 시나리오는 다음과 같습니다:

* mdx 파일을 삭제할 때 `/kr/` 및 `/jp/` 폴더에 있는 해당 mdx 파일도 삭제하십시오. yaml 파일은 업데이트하지 **않습니다**.
* mdx 파일을 폴더 X에서 폴더 Y로 이동할 때 `/kr/` 및 `/jp/`의 폴더 Y로 동일한 mdx 파일을 이동해야 합니다. yaml 파일은 업데이트하지 **않습니다**.
* mdx 파일을 새 폴더로 이동할 때 `/kr/` 및 `/jp/`에 해당 새 폴더를 만든 다음 mdx 파일을 그 안으로 이동해야 합니다. yaml 파일은 업데이트하지 **않습니다**.

파일을 수동으로 삭제하거나 이동하는 대신 다음 명령 시퀀스를 실행하십시오:

* 번역된 파일을 이동/이름 바꾸기하려면:

  ```bash
  yarn i18n-utility list-renames
  yarn i18n-utility make-renames
  ```

* 번역된 파일을 삭제하려면:

  ```bash
  yarn i18n-utility list-orphans
  yarn i18n-utility delete-orphans
  ```
