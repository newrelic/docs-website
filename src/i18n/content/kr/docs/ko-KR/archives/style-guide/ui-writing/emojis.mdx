메시지에서 감정적인 의도를 명확히 하는 데는 유용할 수 있지만, 모든 고객에게 일관된 메시지를 전달하고자 합니다. 여기에 명시되어 있거나 아이콘 규칙에 명시된 경우가 아니라면, UI 텍스트에서 이모지 사용을 피하십시오.

## 기본 사항

UI 텍스트에서는 이모지를 사용하지 마십시오. 작성한 텍스트(예: 오류 메시지)에 긍정적인 느낌을 주기 위해 이모지를 사용하고 싶다면, 당사의 음성 및 어조 규칙을 참조하여 목표를 달성할 때까지 메시지를 다시 작성하십시오.

## 이메일

이메일을 통해 고객과 소통할 때, 고객이 먼저 이모지를 사용하거나 이미 고객과 관계가 형성된 경우가 아니라면 이모지 사용을 피하십시오.

## 인앱 메시징

Intercom.io와 같은 인앱 서비스를 통해 고객에게 연락할 때, 적절하다고 판단되는 경우 메시지에 간단한 웃는 얼굴을 추가해도 안전합니다.
