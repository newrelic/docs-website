`SideBySide` 구성 요소를 사용하면 화면을 반이나 그 이상의 섹션으로 분할할 수 있습니다. 일반적인 사용 사례는 오른쪽 열에 스크린샷을 표시하고 왼쪽에 관련 텍스트를 표시하는 것입니다.

각 측면의 콘텐츠를 `Side` 컴포넌트 안에 래핑해야 하지만, 각 `Side` 안에는 필요한 만큼 콘텐츠를 추가할 수 있습니다.

기술적으로 구성 요소는 두 개 이상의 `Side` 열을 지원하지만, 두 개를 초과하여 사용하지 않아야 합니다.

다음은 구성 요소의 예입니다:

<SideBySide>
  <Side>
    <img alt="example" src="/images/network_screenshot-full_device-performance.webp" />

    <figcaption>
      **[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Network**로 이동합니다.
    </figcaption>
  </Side>

  <Side>
    이것은 훌륭한 문서화 팀이 제공하는 멋진 콘텐츠입니다.
  </Side>
</SideBySide>

## SideBySide 컴포넌트 생성 [#create]

다음은 `SideBySide` 구성 요소의 템플릿입니다:

```jsx
<SideBySide>
    <Side>
        <img alt="Example" src="/images/example-image.webp" />
    </Side>

    <Side>
        This is some awesome content from the amazing documentation team.
    </Side>
</SideBySide>
```

<Callout variant="tip">
  SideBySide용 Keyboard Maestro 매크로는 `kkside`입니다.
</Callout>
