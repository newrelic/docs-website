약어는 길고 자주 사용되는 단어나 구를 나타내는 단어나 구의 축약된 형태입니다. 공간, 노력, 시간을 절약하기 위해 사용됩니다.

## 기본 사항

* 독자가 두문자어나 약어를 이해할 수 있을지 확실하지 않은 경우, 텍스트에서 처음 사용할 때 단어를 모두 쓴 다음 괄호 안에 두문자어를 표기하십시오. 그 이후부터는 두문자어만 사용할 수 있습니다.

* 제품 이름, 팀 이름 또는 회사 이름과 같은 고유 명사가 포함된 경우에만 풀어쓴 약어를 대문자로 표기하십시오.

* 달리 명시되지 않는 한 항상 측정 단위를 약어로 표기하십시오.

* 가능한 한 &quot;average&quot;와 같은 일반적인 단어는 축약하지 말고 모두 쓰십시오.

* 일반적인 단어를 축약해야 하는 경우:

  * 문장 시작 부분에 약어를 사용하지 마십시오.
  * 약어 뒤에 마침표를 추가하십시오.

* 공간이 매우 협소하지 않은 한 thousand, million, billion, trillion은 풀어서 씁니다. 약어로 표기해야 하는 경우 공백 없이 대문자를 사용합니다: 30K, 30M, 30B, 30T.

* 약어를 복수형으로 만들 때 아포스트로피를 사용하지 마십시오. &quot;ABC&apos;s&quot;가 아니라 &quot;ABCs&quot;입니다. [복수형](../plurals/) 페이지를 참조하십시오.
