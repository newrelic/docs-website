툴팁에 대한 다양한 사용 사례가 있으며, 이들 모두 이해하기 쉽고 명확한 언어와 지침이 필요합니다.

## 기본 사항

* 각 상황에서 사용자가 무엇을 알고, 느끼고, 해야 하는지 생각해 보십시오.
* 대화형 언어를 사용하십시오.
* 아이콘 이름 및 작업과 같은 한 줄 툴팁의 경우 언어를 짧고 구체적으로 유지하고 마침표로 끝내지 마십시오.
* 정의와 같은 더 풍부한 툴팁의 경우, 해당 요소가 사용자에게 중요한 이유를 포함하고 완전한 문장은 마침표로 끝내십시오.
* 가능한 경우 더 많은 정보에 대한 링크를 포함하십시오.
