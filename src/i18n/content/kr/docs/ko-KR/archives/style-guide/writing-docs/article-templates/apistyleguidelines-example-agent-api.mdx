## 통사론

```
newrelic.apiStyleGuidelines(data type $parameter_name[, integer $optional_param])
newrelic.apiStyleGuidelines(data type $parameter_name, array $different_param, string $third_param)
```

호출에 대해 간략하게 설명해 주십시오. 이상적으로는 &quot;모든 메서드 보기&quot; 페이지에서 한 줄 이하로 작성하십시오.

## 요구 사항

에이전트 버전 1.2.3.4 이상.

자체 줄에 있는 추가 요구 사항입니다(글머리 기호를 사용하지 마십시오).

콜아웃을 사용하지 마십시오.

특별한 요구 사항이 없으면 다음과 같이 작성하십시오: `Compatible with all agent versions.`

## 설명

호출의 동작을 가능한 한 자세히 설명하십시오. 개별 파라미터가 수행하는 작업은 대략적으로만 설명하고, 파라미터 및 호출 변형에 대한 세부 정보는 `Parameters` 제목 아래에 기재하십시오. 마찬가지로 반환 값도 설명하지 마십시오.

다른 API 호출을 상호 참조할 때 코드 블록으로 이름의 형식을 지정하고 다음과 같이 괄호 `()`을(를) 포함합니다: `anotherCoolMethod()`.

<Callout variant="tip">
  콜아웃을 포함할 수 있지만 신중하게 사용하십시오. 이 페이지들은 이미 시각적으로 복잡합니다.
</Callout>

## 반환 값

이 호출은 무엇을 반환하며, 어떤 상황에서 반환합니까? 고객이 해당 반환 값으로 수행할 것으로 예상되는 작업이 있습니까? 호출이 아무것도 반환하지 않으면 이 섹션을 비워 두십시오.

## 예

이 섹션에서는 자체적으로 문서화되지 않는 특이한 항목에 대한 규칙을 문서화합니다. 나머지 예시는 페이지 자체에 포함되어 있습니다. 일반적으로 이 페이지는 스타일 참조용입니다. 좋은 API 메서드 페이지를 작성하는 방법의 예시는 [PHP API](/docs/agents/php-agent/php-agent-api)와 같은 기존 API 문서를 확인하십시오.

### URL 지침

문서 URL의 경우:

* URL 슬러그를 수동으로 편집하여 에이전트 이름을 제거하십시오.
* API 호출에 구분 기호가 아직 포함되어 있지 않은 경우(`newrelic_awesome_call`의 경우와 같이), 하이픈 `-`을(를) 사용하여 부분을 구분하십시오.

예를 들어:

```
https://docs.newrelic.com/docs/new-relic-only/advanced-style-guide/writing-guidelines/api-style-guidelines
```

### 제목 지침

문서 제목의 경우:

* 괄호 안에 메서드 이름과 에이전트 이름을 포함하십시오.
* 호출 이름에 필수적인 경우가 아니라면(PHP 에이전트에서와 같이) `newrelic.` 접두사를 포함하지 마십시오.
* 호출 자체에 괄호 `()`을 포함하지 마십시오.

예를 들어:

```
apiStyleGuidelines (Example agent API)
```

### 짧은 제목 지침 [#short-title-guideliens]

문서의 짧은 제목의 경우:

* 메서드 이름만 포함하십시오.
* 호출 이름에 필수적인 경우가 아니라면(PHP 에이전트에서와 같이) `newrelic.` 접두사를 포함하지 마십시오.
* 괄호 `()`를 포함하지 마십시오.
* 필요한 경우 카테고리의 사이드바에서 한 줄에 맞게 조정하십시오.

예를 들어:

```
apiStyleGuidelines
```

### 구문 지침

<Callout variant="important">
  파이썬 및 iOS 에이전트는 자체 가이드라인을 사용합니다. 해당 가이드라인에 대해서는 해당 언어의 기존 메서드를 참조하십시오.
</Callout>

* 호출의 각 변형을 자체 줄에 문서화하십시오.
* 데이터 유형을 기울임꼴로 표시하는 것 외에는 어떠한 서식도 사용하지 마십시오.
* 선택적 파라미터(쉼표 구분 기호 포함)를 대괄호 `[]`로 묶으십시오.
* 달러 기호 `$`을(를) 앞에 붙여 변수 부분을 나타내십시오.
* 호출에 `newrelic.` 또는 유사한 접두사를 붙여야 하는 경우 구문에 이를 포함하십시오.
* 선택 사항: 특정 에이전트에 중요하다고 판단되는 경우 반환 값을 포함하십시오. 포함하는 경우 언어 규칙을 따르십시오.
