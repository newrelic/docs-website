문장 부호와 마찬가지로 텍스트 서식은 사람들이 단어를 해석하는 방식에 큰 영향을 미칠 수 있습니다. 예를 들어, 메시지에서 강조를 위한 간단한 도구로 굵은 텍스트를 사용하거나, 사람들이 무엇이 중요한지 본능적으로 알 수 있도록 UI 주변으로 시선을 유도하는 데 사용할 수 있습니다.

## 기본 사항

* 굵은 텍스트는 종종 UI에서 가독성을 높이고 긴 텍스트에서 특정 단어를 강조하는 데 사용됩니다.
* 기울임꼴은 입력 요소 아래의 상황별 힌트 텍스트에 자주 사용되며 텍스트에 집중된 어조나 차분한 어조를 전달할 수 있습니다.
* UI의 밑줄 친 텍스트는 링크로 쉽게 해석될 수 있으므로 다른 목적으로 형식을 사용할 때 주의하십시오. 링크로 기능하지 않는 밑줄 친 단어에 대한 대안을 찾는 것을 고려해 보십시오.

## 암호

고객에게 코드 스니펫을 제공할 때는 Menlo 고정폭 글꼴로 서식을 지정하십시오.

```javascript
var example = 'This is an example string in a monospace font!';
```
