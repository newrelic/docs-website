## 변수

읽기 쉬운 문장에 계산된 값이나 쿼리 결과를 삽입해야 할 때 변수를 사용하십시오. 이를 채우기, 바꾸기, 대체 또는 기타 다른 용어로 부르든 지침은 동일합니다.

### 변수란 무엇입니까? 아래의 굵은 글씨 항목입니다.

| 코드에서                                                                    | UI에서                                        |
| ----------------------------------------------------------------------- | ------------------------------------------- |
| **\[service name]**에서 이상 동작을 감지했습니다.                                    | **RPM-UI-production**에서 비정상적인 동작을 감지했습니다.   |
| 충돌의 **\[% of crashes]**가 운영 시스템 **\[operating system type]**을(를) 공유합니다. | 크래시의 **80%**가 **iOS 11.1.2** 운영 시스템을 공유합니다. |

### 기본 사항

삽입할 값이 짧은 경우, 문장이 자연스럽게 들리도록 문장에서 가장 논리적인 위치에 배치하십시오. 값이 길거나, 읽기 어렵거나, 통제할 수 없는 경우 문장의 끝에 배치하십시오. 변수가 어떤 품사든 될 수 있거나 때로는 단수이고 때로는 복수인 경우, 콜론으로 구분하거나 다른 줄에 배치하십시오.

| 권장 사항                                                                  | 하지 마십시오                                                                   |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| **bob-long-name-32-october-service-legacy-system**에서 비정상적인 동작을 감지했습니다. | **bob-long-name-32-october-service-legacy-system** 서비스에 비정상적인 동작이 발생했습니다. |
| 충돌의 **80%**는 사용자 이름 **pdiddybigdog**을 공유합니다.                           | 크래시의 **80%**가 **pdiddybigdog** 사용자 이름을 공유합니다.                             |
| 여러 오류가 있는 서비스: **1**                                                   | **1** 개의 서비스에 여러 오류가 있습니다.                                                |

## 플레이스홀더 텍스트

입력 필드의 플레이스홀더 텍스트에는 “Example: ...”을 사용하십시오. 그리고 인라인으로 예제를 추가하는 문서와 같은 곳에서는 “such as,”를 사용하십시오. 예를 들어 “X requires an action to be dismissed (such as, confirming a user wants to delete a dashboard).”와 같이 사용하십시오.
