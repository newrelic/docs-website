팝오버는 좁은 공간에서 독자에게 많은 방향을 제시합니다. 팝오버는 주요 개념에 대한 빠른 인라인 정의를 제공하고, 문서에서 자세히 알아보거나 UI에서 사용해 볼 수 있는 경로를 제공합니다.

<img title="Popover" alt="A screenshot of a popover" src="/images/style-guide_screenshot-crop_popover.webp" />

## 팝오버 사용 [#use-pop]

팝오버는 [JSON 파일](https://github.com/newrelic/docs-website/blob/develop/src/data/popovers_en.json)에 작성되며, 다음 형식을 사용하여 원하는 문서에 삽입할 수 있습니다:

```jsx
<InlinePopover type="title" />
```

여기서 `title`은(는) JSON 파일의 구성 요소 이름입니다. 위 스크린샷에서 `synthetics`은(는) 사용된 팝오버입니다.

<Callout variant="tip">
  팝오버용 Keyboard Maestro 매크로는 다음과 같습니다. `kkpopover`
</Callout>

## 팝오버 생성 또는 편집

팝오버는 편집 가능한 JSON 파일에 포함되어 있습니다. 아래 절차를 사용하여 파일을 편집하여 고유한 팝오버를 생성할 수 있습니다:

<Steps>
  <Step>
    VS Code에서 [JSON 파일](https://github.com/newrelic/docs-website/blob/develop/src/data/popovers_en.json)을 여십시오.
  </Step>

  <Step>
    기존 팝오버를 복사하여 붙여넣고, 만들려는 팝오버에 맞게 필요에 따라 수정하십시오.

    * 첫 번째 줄은 위의 형식 예제에서 사용된 팝오버의 &quot;제목&quot;입니다.

    * `inlineText` 은(는) 사용자가 팝오버 위로 마우스를 가져가기 전에 구성 요소를 넣은 문서에 나타나는 텍스트입니다.

    * `header` 은(는) 팝오버가 표시될 때의 제목입니다.

    * `text` 팝오버의 본문에 표시되는 문구입니다.

    * `learnMoreUrl` 독자에게 더 많은 정보를 제공하기 위해 보낼 문서의 URL입니다.

    * `primaryButton` 은(는) 팝오버에 나타나는 기본 버튼의 텍스트입니다.

    * `primaryButtonUrl` 버튼을 클릭했을 때 독자를 보낼 링크입니다.

    * `secondaryButton` 팝오버에 표시되는 가장 오른쪽 버튼의 텍스트입니다.

    * `secondaryButtonUrl` 클릭 시 가장 오른쪽 버튼이 독자를 이동시키려는 링크입니다.

      항목을 더 쉽게 찾을 수 있도록 JSON 파일의 목록을 알파벳순으로 유지하십시오.
  </Step>

  <Step>
    로컬에서 팝오버를 테스트하십시오.
  </Step>

  <Step>
    변경 사항을 기반으로 PR을 열고 Docs Eng 팀의 담당자에게 연락하여 검토를 요청하십시오.
  </Step>

  <Step>
    PR이 검토되고 병합되면, 원하는 문서에서 새 팝오버를 사용할 수 있습니다!
  </Step>
</Steps>
