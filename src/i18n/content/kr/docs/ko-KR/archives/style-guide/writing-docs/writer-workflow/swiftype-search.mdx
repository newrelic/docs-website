title: Swiftype 검색

Swiftype은 `docs.newrelic.com`의 검색을 구동하는 Elastic 기반 검색 엔진입니다.

뉴렐릭의 테크니컬 라이터로서 내부 검색 중에 문서가 인식되도록 Swiftype에 로그인하여 다양한 작업을 수행해야 할 수 있습니다.

## Swiftype 크롤러 정보 [#crawler-info]

크롤러는 12시간마다 크롤링한다고 합니다. 크롤링 속도가 상대적으로 느리기 때문에 페이지 변경 사항을 반영하는 데 그보다 더 오래 걸릴 수 있습니다. 또한 크롤링할 때 `sitemap.xml` 및 링크 수집의 조합을 사용합니다.

필요한 경우 12시간마다 한 번씩 수동 크롤링을 트리거할 수 있습니다. 또는 필요한 경우 Swiftype이 특정 페이지를 크롤링하도록 할 수 있습니다.

문서의 평균 재색인 시간은 4일입니다.

## Swiftype 인덱스에 새 페이지 수동 추가 [#manually-index]

크롤링이 너무 느리고 페이지를 즉시 사용할 수 있게 하려면 Swiftype 인덱스에 새 페이지를 수동으로 추가할 수 있습니다.

Swiftype에 새 페이지를 수동으로 추가하려면:

1. **Domains &gt; [https://docs.newrelic.com/](https://docs.newrelic.com/)**으로 이동하여 문서 유형이 무시 목록에 없는지 확인하십시오.

2. **뉴렐릭 &gt; Content**로 이동하십시오.

3. **Filter pages**라고 표시된 텍스트 입력 상자에 인덱싱할 페이지의 URL을 붙여넣으십시오.

4. 페이지가 인덱스에 없는 경우, Swiftype은 **Add this URL** \[이 URL 추가] 옵션을 제공합니다. 해당 옵션을 클릭하여 페이지를 인덱스에 추가하십시오.

5. URL을 삽입하고 다음을 확인하십시오:

   * 다음과 같이 전체 URL을 사용하십시오: `https://docs.newrelic.com/docs/path/to/doc/`
   * URL에 후행 슬래시가 있는지 확인하십시오.

Swiftype은 약 1분 내에 이를 인덱싱합니다. 인덱싱되었는지 확인하려면 페이지를 새로 고치고 URL을 붙여넣으십시오. 때때로 관리자 UI가 캐시되거나 지연될 수 있습니다. 동료에게 확인을 요청하거나, REST API를 사용하여 확인하거나, 캐시를 지우거나, 페이지를 다시 로드하고 다시 확인할 수 있습니다.

## 기존 Swiftype 레코드를 수동으로 업데이트합니다. [#manual-index]

인덱스에 새 페이지를 수동으로 추가하는 것과 유사하게, 크롤링이 너무 느리고 인덱스를 즉시 업데이트하려는 경우 기존 레코드를 업데이트할 수 있습니다. 페이지의 URL을 변경했고 이전 URL이 새 URL로 리디렉션되는 경우 이 방법을 사용하십시오. 이에 대한 자세한 내용은 아래의 [URL 변경](#url-changes) 섹션을 참조하십시오.

기존 레코드를 수동으로 업데이트하거나 다시 색인화하려면:

1. **뉴렐릭 &gt; Content**로 이동하십시오.
2. 이전 URL(페이지가 마지막으로 색인된 URL)을 붙여넣으십시오.
3. 인덱스에서 발견되면 해당 항목이 표시되므로 **Details**를 선택하십시오.
4. 레코드 세부 정보 페이지에서 **Reindex**를 선택하십시오.
5. [특정 검색어에 대한 결과 순위 지정](#rank-results)의 단계를 따라 이 문서의 순위를 다시 추가하십시오.

Swiftype은 1분 이내에 다시 인덱싱됩니다. 해당 레코드는 설정한 사용자 지정 순위와 함께 인덱스에서 제거되며, 크롤러가 리디렉션된 새 URL에 대한 새 레코드가 생성된다는 점에 유의하십시오. 따라서 결과 순위를 업데이트할 준비를 하십시오.

## 기존 swiftype 레코드를 수동으로 제거하십시오. [#remove-records]

다음과 같은 경우 인덱스에서 기존 레코드를 수동으로 제거할 수 있습니다:

* 리디렉션 없이 삭제된 페이지의 레코드를 빠르게 제거하려는 경우
* 최근에 URL이 변경된 페이지에 대해 두 개 이상의 레코드(이전 URL에 대한 레코드 하나, 리디렉션 외부에서 발견된 새 URL에 대한 레코드 하나)가 있는 것을 발견한 경우입니다.

인덱스에서 레코드를 수동으로 제거하려면:

1. **뉴렐릭 &gt; Content**로 이동하십시오.
2. 제거할 레코드의 URL을 붙여넣으십시오.
3. **Details**를 선택하십시오.
4. **Details** 페이지 하단에서 **Delete this Document**를 선택하십시오.

## 주어진 검색어에 대한 결과 순위를 지정합니다. [#rank-results]

주어진 검색어에 대한 결과의 순위를 매겨 결과에서 특정 페이지를 더 높거나 낮게 이동합니다. 또한 주어진 검색어에 대한 결과에서 레코드를 제외할 수도 있습니다.

모든 웹사이트의 페이지가 하나의 엔진에서 처리되므로 순위 목록이 복잡해집니다. 관련 페이지 URL을 탐색하는 대신 특정 URL을 검색하는 것이 좋습니다.

<Callout variant="tip">
  주어진 레코드의 URL이 변경되면 결과 순위가 손실되며 새 URL과 연결된 새 레코드에 대해 추가해야 합니다.
</Callout>

결과 순위 지정:

1. **뉴렐릭 &gt; Result Rankings**(으)로 이동하십시오.
2. 순위를 매기고자 하는 검색어를 텍스트 입력란에 입력하십시오(대소문자는 구분하지 않습니다).
3. 결과를 위나 아래로 드래그하십시오. 페이지 URL을 검색하고, 고정하고, 이리저리 이동하기를 원하실 것입니다.
4. 결과에서 **X** 버튼을 선택하여 결과를 제거하십시오.

자세한 내용은 [공식 Swiftype 문서](https://swiftype.com/documentation/site-search/guides/result-rankings)를 참조하십시오.

## 별칭 추가 [#add-alias]

결과 순위를 설정할 때 별칭도 추가할 수 있습니다. 별칭은 [동의어](#add-synonym)와 유사하지만 특정 결과 집합에만 적용됩니다.

별칭을 추가하려면:

1. **뉴렐릭 &gt; Result Rankings**(으)로 이동하십시오.
2. 검색어를 입력하십시오.
3. 텍스트 입력에 별칭을 추가하십시오.

## 동의어 추가 [#add-synonym]

한 검색어가 다른 검색어와 동일한 결과를 표시하도록 하려면 동의어를 추가하십시오. 이전 예는 다음과 같습니다:

* RBAC=역할 기반 액세스 제어
* servers = 뉴렐릭 Infrastructure

동의어를 추가하려면 **New Relic &gt; Synonyms**로 이동하십시오.

보다 자세한 내용은 [공식 문서](https://swiftype.com/documentation/site-search/guides/synonyms)를 참조하십시오.

## 모범 사례: 중요한 검색어 [#important-search-terms]

아마도 다음과 같은 검색어에 대해 결과의 순위가 매겨지고 정확한지 확인해야 할 것입니다:

* 결과가 노이즈가 많고 매우 모호한 것으로 알려져 있습니다(예: 브라우저)
* 당사 사이트에서 가장 인기 있는 검색어
* 용어집 용어

## 모범 사례: URL 변경 [#url-changes]

이미 인덱싱된 페이지의 URL이 변경되면, Swiftype은 이전 URL과 연결된 해당 레코드를 제거합니다. 그리고 새 URL로의 리디렉션이 존재하는 경우, Swiftype은 새 URL과 연결된 페이지에 대한 새 레코드를 생성합니다. 이러한 경우, 이전 레코드에 대한 결과 순위가 손실되며 새 URL이 있는 새 레코드에 대해 다시 추가해야 합니다.

Swiftype에서 재크롤링을 트리거하면 결국 이 문제가 해결되지만, 시간이 오래 걸릴 수 있습니다. 또는 이전 페이지에 대한 특정 결과를 삭제하고 수동으로 새 페이지를 인덱싱하도록 지시할 수 있습니다. 이것은 다음에 특정 검색어에 대한 캐시를 업데이트할 때 `docs-library-service` (으)로 동기화되어야 *합니다*.
