때로는 동료 작성자나 기여자가 변경하기 전에 MDX 문서 파일의 일부 측면에 대해 알려 주의를 끌어야 할 때가 있습니다. `<CONTRIBUTOR_NOTE>` 구성요소를 사용하여 주석을 삽입하여 이 작업을 수행할 수 있습니다.

이 구성 요소를 사용할 수 있는 두 가지 예는 다음과 같습니다.

* 사이트의 민감한 정보를 변경하는 것에 대해 다른 사람에게 경고합니다.
* 사이트의 해당 위치에 정보가 존재하는 이유를 설명합니다.

`<CONTRIBUTOR_NOTE>` 구성 요소를 사용하여 노트를 작성할 때, 해당 노트는 HTML로 변환되지 않으며 독자가 웹사이트에서 직접 볼 수 없습니다(**소스 보기** 포함). 하지만 사이트를 편집하려는 사람들은 볼 수 있으므로 항상 어조와 톤을 고려하십시오.

다음은 예입니다.

```jsx
<CONTRIBUTOR_NOTE>
  Do not change this URL unless you have explicit permission from a manager at New Relic.
</CONTRIBUTOR_NOTE>
```
