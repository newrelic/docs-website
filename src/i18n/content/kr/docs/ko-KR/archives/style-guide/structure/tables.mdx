표는 정보를 구성하여 독자가 쉽게 훑어볼 수 있도록 도와줍니다. 그러나 표가 너무 길어지면 [&quot;5-9&quot; 지침](/docs/style-guide/get-started/introduction-style-guide#organization)을 따르고 다른 방식으로 정보를 재구성하는 것을 고려하십시오.

소문자나 모두 대문자가 필요한 특정 파일 이름이나 코드 값이 아닌 한, 모든 표 열의 텍스트에는 문장 대소문자를 사용하십시오.

<Callout variant="tip">
  Table 컴포넌트의 Keyboard Maestro 매크로는 다음과 같습니다. `kktable`
</Callout>

## 표 구문

당사의 테이블은 MDX React 컴포넌트로 구축됩니다. 실제로는 HTML 테이블과 매우 유사합니다:

```html
<table>
    <thead>
        <tr>
            <th style={{ width: "200px" }}>
                Item
            </th>
            <th>
                Description
            </th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>
                Item name
            </td>
            <td>
                Description of item
            </td>
        </tr>
    </tbody>
</table>
```

<Callout variant="tip">
  문서 사이트는 기술적으로 [마크다운 테이블](https://www.markdownguide.org/extended-syntax/#tables)을 지원하지만, 몇 가지 이유로 사용을 피하고 있습니다:

  * 마크다운에는 여러 종류가 있으며, 종류마다 다른 테이블 구문을 사용합니다. 이는 존 그루버(John Gruber)의 원래 마크다운 사양에 테이블이 포함되지 않았기 때문입니다.
  * 마크다운 테이블은 여러 줄에 걸친 요소를 지원하지 않으며, 대부분의 테이블에는 코드 블록, 글머리 기호 목록 또는 여러 줄이 필요한 기타 요소가 포함되어 있습니다.
</Callout>

## 열 너비 설정 [#column-width]

`<th>` 요소의 스타일 규칙으로 열 너비를 설정할 수 있습니다:

```html
<th style={{ width: "200px" }}>
```

일반적으로 문서 사이트의 2열 테이블의 경우:

1. 첫 번째 열을 200픽셀로 설정하십시오: `style={{ width: "200px" }}`.
2. 표가 남은 페이지 너비에 맞게 자동으로 조정되도록 하려면 두 번째 열의 너비를 설정하지 마십시오.

## UI 기능을 설명하는 테이블 [#tables-ui]

표를 사용하여 사용 가능한 기능을 설명할 때는 독자에게 로드맵을 제공하십시오. 독자는 자신이 찾거나 달성하고자 하는 것이 무엇인지 알 수 있지만, 그것을 무엇이라고 부르는지 또는 어떻게 하는지는 모를 수 있습니다.

예를 들어, 특정 UI 페이지의 기능 목록을 제공하려면 헤더의 첫 번째 열을 **다음을 수행하려는 경우...**로 지정하고 두 번째 열을 **수행할 작업**으로 지정하십시오.
