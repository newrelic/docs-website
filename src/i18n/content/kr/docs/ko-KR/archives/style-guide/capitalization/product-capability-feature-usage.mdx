이 페이지는 모든 뉴렐릭 콘텐츠 제작자가 사용할 제품, 기능 및 역량의 대문자 표기에 대한 확정적인 리소스입니다. 이 가이드라인은 뉴렐릭 전반의 리더들뿐만 아니라 법무, 콘텐츠 디자인, 제품 마케팅 및 문서 팀의 구성원들에 의해 검토되었습니다.

일반적으로 회사 이름, 제품/플랫폼 이름, 법적인 이유로 필요한 몇 가지 기능 및 통합에 [타이틀 케이스](https://en.wikipedia.org/wiki/Title_case)를 사용합니다. 다음 섹션에서는 용어의 첫 번째 사용과 후속 사용에 대해서도 설명합니다. 첫 번째 사용은 본문에서 처음 언급되는 것을 의미합니다. 제목, 헤더, 테이블, 웹 탐색, UI, 소셜 미디어 게시물 등과 같이 공간이 제한된 영역에서는 후속 버전을 사용해도 무방합니다. UI 문구를 작성하는 경우 [UI 대문자 표기 지침](/docs/style-guide/ui-writing/capitalization/)을 참조하십시오.

일반적으로 이러한 제품 및 UI 가이드라인 외에는 문장 첫 글자 대문자 표기를 사용하십시오.

## 약어

일반적으로 약어에 대해서는 한 가지 예외를 제외하고 [Microsoft 글쓰기 스타일 가이드 권장 사항](https://learn.microsoft.com/en-us/style-guide/acronyms)을 따릅니다. Microsoft 스타일과 달리, 당사의 일부 제품, 역량 및 기능 이름은 처음 등장할 때 전체 이름을 쓴 후 약어로 사용됩니다. 예를 들어, 뉴렐릭 애플리케이션 성능 모니터링(뉴렐릭 APM) 및 뉴렐릭 쿼리 언어(NRQL)가 있습니다.

약어를 사용할 때의 몇 가지 주요 지침은 다음과 같습니다:

* 약어가 처음 등장할 때는 전체 이름을 쓰고 괄호 안에 약어를 표기하십시오.
* 약어를 풀어쓸 때 고유 명사를 제외한 모든 단어는 소문자로 작성하십시오.
* 처음 등장하는 경우라도 제목이나 머리글에서는 약어 사용을 피하십시오. 예외: 간결성을 위해 공간을 고려하여 제목이나 머리글에 처음 등장할 때 약어를 사용해야 할 수도 있습니다.
* 외부적으로 뉴렐릭에만 해당하거나 뉴렐릭이 만든 약어를 사용하지 마시고, 외부적으로는 APM과 같이 업계에서 인정하는 약어만 사용하십시오.

## 상표 정의

상표는 특정 제품이나 서비스를 식별하는 단어, 이름, 기호 또는 이 세 가지의 조합입니다. [상표](https://www.uspto.gov/trademarks/basics/what-trademark#:~:text=A%20trademark%20can%20be%20any,both%20trademarks%20and%20service%20marks)는 시장에서 고객이 귀사를 인식하고 해당 상품 및 서비스에 대해 경쟁업체와 귀사를 구별하는 수단입니다.

상표명은 비즈니스를 수행하는 회사의 이름입니다. 뉴렐릭 상표명은 New Relic, Inc.입니다.

## 뉴렐릭 브랜드 이름 사용 방법

뉴렐릭 브랜드 이름을 사용할 때의 일반적인 상표 가이드라인은 다음과 같습니다:

* 아포스트로피를 사용하여 뉴렐릭 또는 해당 플랫폼, 기능 등을 소유격으로 만들지 마십시오. 예를 들어, “New Relic&apos;s platform functions” 또는 “New Relic&apos;s functionality.” 대신 “New Relic platform functions” 또는 “New Relic functionality”를 사용하십시오.
* 뉴렐릭 또는 해당 플랫폼, 기능 등을 복수형으로 사용하지 마십시오.
* 뉴렐릭 또는 그 플랫폼, 역량 등을 약어로 쓰거나 결합하지 마십시오.
* 뉴렐릭 또는 해당 플랫폼, 기능 등에 하이픈을 사용하지 마십시오. 또한 텍스트에 사용될 때 페이지 줄 바꿈이 발생하지 않도록 하십시오.
* 뉴렐릭 상표를 다른 회사의 이름 및/또는 상표와 명확하게 분리하고 식별하여 혼동을 피하십시오.

해당 회사의 상표 정책에서 다른 접근 방식을 요구하지 않는 한, 이러한 상표 가이드라인을 다른 회사의 상표명 및 제품에도 적용하는 것이 일반적으로 모범 사례라는 점에 유의하십시오.

newrelic.com 웹페이지의 머리글 및 텍스트에서 제품 이름 뒤에 상표 문자를 사용할 필요는 없습니다.

## 타사 상표

일반적으로 newrelic.com 웹페이지나 문서(PDF 포함)에서 타사 제품 이름 뒤에 상표 문자를 사용하는 것은 필요하지 않거나 권장되지 않습니다. 뉴렐릭은 일반적으로 특정 마크가 등록되어 있는지 알 수 있는 위치에 있지 않습니다. 타사 제품 이름이나 기타 타사 마크가 등록되어 있다고 가정하면 뉴렐릭에 의도하지 않은 원치 않는 결과가 발생할 수 있습니다. 따라서 뉴렐릭이 파트너 관계를 맺거나 협력하는 타사가 상표 정책의 일부로 해당 기호의 사용을 특별히 요구하지 않는 한 ® 또는 ™ 기호의 사용을 피하십시오.

일부 인스턴스에서는 타사가 계약 또는 상표 정책을 통해 ® 또는 ™ 기호의 사용을 요구합니다. 예를 들어, LEGO가 있습니다. 최근 FutureStack 이벤트에서는 LEGO 마스터가 LEGO 모델을 만드는 활동을 홍보했습니다. 이 경우, LEGO는 뉴렐릭 카피에서 LEGO가 처음 나타날 때 ®가 뒤따라야 한다고 요구했습니다. 예를 들어, &quot;뉴렐릭 Data Nerd Knuckles의 세상에 하나뿐인 LEGO® 모델을 받을 수 있습니다.&quot;

당사와 협력하는 회사가 상표 정책을 공개적으로 제공하거나 뉴렐릭에 비공개로 정책을 제공한 경우, 해당 정책을 참조하고 ® 또는 ™ 기호 사용에 대한 해당 회사의 정책을 따르십시오. 사본에서 타사 상표를 인정해야 하는지 확실하지 않은 경우, Slack의 #suplegal 채널에서 법무팀에 문의하십시오.

## 제목 대소문자 사용이 필요한 경우

회사 이름, 제품/플랫폼 이름, 일부 기능 및 통합 이름을 포함하여 상표로 등록된 이름에는 제목 대소문자를 사용해야 합니다.

이 테이블은 최신 상태로 유지되며 대문자 표기에 대한 신뢰할 수 있는 출처입니다. 뉴렐릭은 하나의 플랫폼이므로 대부분의 기능 이름은 소문자로 표기합니다. 그러나 상표 또는 가격 책정상의 이유로 일부 용어와 기능은 대문자로 표기합니다(예: 별도의 SKU인 경우). 여기서 “capability”의 사용은 [사용자 관리 공간](/docs/accounts/accounts-billing/new-relic-one-user-management/user-permissions)에서 해당 단어를 사용하는 것과 다릅니다.
