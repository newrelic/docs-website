이 세 가지 요소는 비즈니스를 주도하는 핵심을 형성합니다. 고객은 시스템이 얼마나 잘 작동하는지 게이지하기 위해 수치 데이터에 의존하며, 날짜와 시간은 해당 정보에 필요한 컨텍스트를 제공합니다.

## 기본 사항

* 문장 내 위치에 관계없이 숫자는 아라비아 숫자로 작성하십시오.
* 4자리 이상의 숫자에는 쉼표를 사용하십시오.
* 절대적인 수치의 정확성이 고객에게 수치에 대한 감을 제공하는 것보다 덜 중요하다면, 1k(1,012의 경우) 또는 3억 2,450만(324,501,082의 경우)과 같이 반올림해도 무방합니다. 이 경우에는 최선의 판단을 내리십시오.
* 정수를 소수점과 후행 0을 포함하여 작성하지 마십시오.

| 권장 사항           | 하지 마십시오         |
| --------------- | --------------- |
| 1,024 KB        | 1024 KB         |
| 상위 5개 트랜잭션 트레이스 | 상위 5개 트랜잭션 트레이스 |
| 2초              | 2.0초            |

## 큰 숫자

당사는 UI에 일반적인 미국 영어를 사용하며, 이로 인해 큰 숫자를 표기할 때 몇 가지 문제가 발생합니다. 천 단위에 대한 국제 및 미국 영어 표기법은 소문자 k로 동일합니다. 하지만 백만, 십억, 조 단위는 지역과 산업에 따라 약어가 다르기 때문에 더 까다롭습니다. 이러한 이유로 당사는 가장 일반적인 단위인 천 단위만 약어로 표기합니다.

* 천 단위는 마지막 숫자와 문자 사이에 공백을 두고 소문자 k로 축약하십시오: 50 k.
* 더 큰 숫자를 다룰 때는 공백을 사용한 다음 million, billion, trillion 등을 소문자로 표기하십시오. 공간이 너무 좁아 축약해야 하는 경우 B, M, T를 사용하되, 화면이나 차트의 다른 곳에 전체 철자를 제공하고 마우스를 올렸을 때 전체 숫자를 제공하는 경우에만 사용하십시오.
* 가능한 경우 마우스를 올렸을 때 전체 숫자를 제공하십시오.

| UI에서   | 마우스를 올렸을 때(가능한 경우) | 하지 마십시오       |
| ------ | ------------------ | ------------- |
| 50.2 k | 50,200             | 50.2k         |
| 5,020만 | 50,200,000         | 50.2m, 50.2M  |
| 502억   | 50,200,000,000     | 50.2G, 50.2B  |
| 50.2조  | 50,200,000,000,000 | 50.2T, 50.2 t |

## 날짜 및 시간

[표준 포맷터](https://unicode-org.github.io/icu/userguide/format_parse/datetime/)의 브라우저별 자동 날짜 및 시간 형식을 사용합니다. 제품에서 이러한 값을 코딩하는 경우 내부 디자인 시스템을 참조하십시오. 올바른 형식을 가져오려면 usedate 및 usetime 후크를 사용하십시오.

참고: 표준 포매터와의 유일한 편차는 24시간제 옵션(정확하고 긴 형식)입니다. 오전 12:30의 경우 24:30 대신 00:30을 사용합니다.

| useDate options \[useDate 옵션] | 샘플 출력        |
| ----------------------------- | ------------ |
| 기본(기본값)                       | 2022년 2월 24일 |
| 짧음                            | 2022년 2월 24일 |

| useTime 옵션 | 샘플 출력                 |
| ---------- | --------------------- |
| 기초적인       | 오전 12:16              |
| Day        | 2월 24일 오전 12:16       |
| 짧은 날       | 2월 24일 오전 12:16       |
| 정확함        | 00:16:36.969          |
| 긴          | 00:16:36              |
| (출시 예정)    | 2022년 2월 24일 오전 12:16 |
| (출시 예정)    | 2022. 2. 24. 00:16    |

## 소수 및 분수

* 분수 값은 소수 형태로 작성하십시오.
* 소수를 소수점 이하 두 자리까지 반올림하십시오.
* 1보다 작은 소수에는 앞에 0을 포함하십시오.

| 권장 사항  | 하지 마십시오   |
| ------ | --------- |
| 0.92ms | 0.92ms    |
| 16.23s | 16.2822 s |

## 금액

* 전체 달러 금액의 경우 후행 소수점과 0을 생략하십시오.
* 달러 금액 앞에 공백 없이 적절한 통화 기호를 배치하십시오.
* 가격에 통화를 포함할 때 통화는 달러 금액과 공백을 두고 맨 끝에 옵니다.

| 권장 사항      | 하지 마십시오    |
| ---------- | ---------- |
| $32        | $32.00     |
| $32.75     | ---        |
| $14.99 USD | USD $14.99 |

## 백분율

* 숫자와 기호 사이에 공백 없이 % 기호를 사용하십시오.
* 소수 형태의 분수 값의 경우 항상 앞에 0을 포함하십시오.

**예외** - 신세틱스 데이터와 같이 정밀도가 필요한 경우 백분율에서 소수점 이하 3자리까지 사용할 수 있습니다.

| 권장 사항            | 하지 마십시오 |
| ---------------- | ------- |
| 25%              | 25%     |
| 0.3%             | 0.3%    |
| **(예외)** 62.356% | ---     |
