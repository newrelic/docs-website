## 기본 사항

UI에 공지 상태에 대한 색상 표시기를 표시하며, UI 화면과 API 전반에 걸쳐 일관된 언어를 사용하는 것이 중요합니다. 또한 이 상태에는 단순한 알림 이상의 더 많은 내용을 포함하기 시작했습니다.

필요한 경우 색상의 의미를 설명하는 호버 상태를 포함하십시오. 개별 엔티티 페이지의 기본 상태 배지의 경우, 호버 상태에 기여하는 요소가 나열됩니다. 이것이 불가능한 경우 아래의 호버 상태를 사용하십시오.

## UI 및 API 문구 간의 매핑

| 색깔    | UI 호버(툴팁)         | UI 상태 레이블  | API             |
| ----- | ----------------- | ---------- | --------------- |
| 빨간색   | 심각한 인시던트가 진행 중입니다 | 비판적인       | 위독한             |
| 노란색   | 경고 인시던트 진행 중      | 저하됨        | 경고              |
| 녹색    | 진행 중인 알림이 없습니다    | 운영         | NOT\_ALERTING   |
| 회색    | 보고하지 않음           | 상태 알 수 없음  | NOT\_CONFIGURED |
| 색상 없음 | -호버 상태 없음-        | -호버 상태 없음- |                 |
