translationType: machine

명사를 복수형으로 표기하면 사람들이 글을 해석하는 방식에 영향을 미칠 수 있는 구두점 및 철자의 미묘한 변화가 발생합니다.

## 기본 사항

* 단일 문자를 복수형으로 만들려면 아포스트로피를 사용하십시오.
* 약어를 복수형으로 만들 때 아포스트로피를 사용하지 마십시오.

| 권장 사항                          | 하지 마십시오                     |
| ------------------------------ | --------------------------- |
| vacuum이라는 단어에는 u가 2개 있습니다.     | vacuum이라는 단어에는 u가 2개 있습니다.  |
| 세세한 부분까지 꼼꼼하게 확인하는 것을 잊지 마십시오. | 세부 사항을 꼼꼼히 확인하는 것을 잊지 마십시오. |
| IP의 기본에 대해 이야기해 보겠습니다.         | IP의 기본 사항에 대해 이야기해 보겠습니다.   |
