**이 문서는 Prometheus 통합 문서의 템플릿입니다**: 이 유형의 문서에 예상되는 구조를 이해하려면 먼저 전체 템플릿을 훑어보십시오. **소개(이 제목은 표시되지 않음)**까지의 모든 콘텐츠를 삭제하십시오.

**제목의 경우** (페이지 상단의 필드): 특정 통합에 초점을 맞춘 실용적인 이름을 문서에 지정하십시오.

## 소개(이 제목은 표시되지 않습니다) [#intro]

이 통합이 수행하는 작업과 이를 사용해야 하는 이유에 대한 간략한 설명을 제공해 주십시오. 주요 사용 사례, 고객 가치, 이 통합을 사용하는 이유 및 사용 시기를 언급해 주십시오.

통합의 스크린샷을 찍을 수 있는 곳에 링크를 추가하십시오.

## 요구 사항

* Prometheus가 메트릭 엔드포인트를 검색하는 데 필요한 파드 주석을 추가하는 방법을 알아보려면 공급자 사이트에 대한 링크를 추가하십시오.

## 통합 활성화

Prometheus 메트릭은 뉴렐릭과 통합되어야 하며, Prometheus 에이전트 또는 Remote Write 통합을 사용할 수 있습니다, [Prometheus 메트릭 전송 방법](https://docs.newrelic.com/docs/infrastructure/prometheus-integrations/get-started/send-prometheus-metric-data-new-relic/)을 참조하십시오.

통합이 완료되면 다음 쿼리를 사용하여 메트릭이 예상대로 수집되는지 확인하십시오:

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'integrationName_%' FACET metricName LIMIT MAX
```

통합 엔티티는 연관된 골든 메트릭 및 기본 제공 대시보드와 함께 [엔티티 탐색기](/docs/new-relic-solutions/new-relic-one/core-concepts/new-relic-explorer-view-performance-across-apps-services-hosts#find) 에서도 볼 수 있습니다.

## 대시보드 및 알림 설치

기본 제공 대시보드 및 알림에 액세스하려면 \[통합 퀵스타트]\(add a link to the quickstart guide)를 설치하십시오. 대시보드를 가져온 후에는 특정 요구 사항에 따라 자산을 조정(편집 또는 복제)할 수 있습니다.

## 데이터 찾기 및 사용

### 메트릭

Prometheus 메트릭은 차원 메트릭으로 저장됩니다. [NRQL을 사용하여 쿼리](/docs/telemetry-data-platform/get-data/apis/query-metric-data-type/) 하거나 [데이터 탐색기를](/docs/query-your-data/explore-query-data/browse-data/introduction-data-explorer/) 사용하여 사용 가능한 메트릭, 패싯을 찾아보고 관련 차원별로 필터링할 수 있습니다.

\[여기에 통합 이름 추가]에서 노출하는 다양한 메트릭 세트는 \[통합\_이름 문서]\(제공업체의 문서에 대한 링크 추가)에 정의되어 있습니다.

다음 NRQL 쿼리를 사용하여 New Relic에서 수집되는 메트릭을 이해하십시오.

* 고유한 측정항목 이름 나열:

  ```sql
  FROM Metric SELECT uniques(metricName) WHERE metricName LIKE 'integrationName_%' LIMIT MAX
  ```

* 메트릭 업데이트 수 계산:

  ```sql
  FROM Metric SELECT datapointcount() WHERE metricName LIKE 'integrationName_%' FACET metricName
  ```

* 데이터 수집 추정(일일 수집, 바이트 단위):

  ```sql
  FROM Metric SELECT bytecountestimate() WHERE metricName LIKE 'integrationName_%' SINCE 1 day ago
  ```

### 엔티티

이 통합은 골든 메트릭, 엔티티 대시보드, 워크로드 및 Lookout과 같은 전체 [엔티티 기능](/docs/new-relic-solutions/new-relic-one/core-concepts/what-entity-new-relic/) 세트를 구동하는 통합 엔티티를 활성화합니다.

## 문제점 해결

\[integrationName documentation]\(제공업체의 문서에 대한 링크 추가)의 문제 진단, 해결 팁을 따라 클러스터에서 메트릭이 예상대로 구성되었는지 확인하십시오.

Prometheus 통합에 대한 특정 [문제 해결 지침을](/docs/infrastructure/prometheus-integrations/troubleshooting/no-data-appears-prometheus-integration) 확인할 수도 있습니다.
