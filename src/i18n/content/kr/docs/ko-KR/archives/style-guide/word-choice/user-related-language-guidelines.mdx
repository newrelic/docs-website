이 문서는 사용자 역할/권한 관련 문서에 필요한 스타일과 권장되는 표현을 설명합니다.

## 사용자 모델에 대한 참고 사항

이 스타일 가이드는 주로 기존 사용자 모델이 아닌 최신 사용자 모델의 사용자에 대해 작성할 때 적용됩니다. 두 사용자 모델이 특정 용어(예: **관리자**)를 공유하더라도, 이는 완전히 다른 구조, 권장 표현 및 스타일을 가진 완전히 다른 사용자 모델입니다. 사용자 모델의 차이점을 이해하려면 [사용자 모델 개요](/docs/accounts/original-accounts-billing/original-product-based-pricing/overview-user-models)를 참조하십시오.

원래 사용자 모델은 점차 더 이상 사용되지 않을 것이므로, 해당 사용자 모델에 대해 너무 많이 생각하거나 해당 문서를 자주 업데이트할 필요가 없습니다.

## 사용자 권한/역할 문서화 가이드라인 [#user-language-philosophy]

뉴렐릭 사용자가 뉴렐릭 기능에 액세스하는 기능에 영향을 미치는 두 가지 주요 요인은 다음과 같습니다:

* 사용자 유형: 사용자 유형에 대한 정보는 거의 전적으로 [사용자 유형 문서](/docs/accounts/accounts-billing/new-relic-one-user-management/user-type)로 제한합니다.

* 역할 및 기능: 이에 대한 정보는 거의 전적으로 전용 사용자 관리 문서로 제한합니다:

  * [원래 사용자 모델 문서](/docs/accounts/original-accounts-billing/original-users-roles/users-roles-original-user-model)
  * [최신 사용자 모델 문서](/docs/accounts/accounts-billing/new-relic-one-user-management/introduction-managing-users)

즉, 다음 예외를 제외하고 **제품 기능 관련 문서에 사용자 유형 및 역할/기능에 대한 정보를 배치하지 않습니다**:

* 사용자 유형의 경우: 대부분의 제품 기능에서 사용자 유형으로 인해 제한되는 항목이 있으면 사용자에게 명확하게 표시됩니다(예: 사용자 유형에 대한 UI 메시지가 표시됨). 사용자 유형으로 인해 제한되는 항목이 명확하지 않은 경우, 기능 문서의 요구 사항 섹션에 이를 문서화할 수 있습니다. 예를 들어, NerdGraph 사용자에게 특정 requests를 수행할 수 없는 이유가 즉시 명확하지 않을 수 있으므로, 이러한 상황에서는 기본 NerdGraph 문서에 사용자 유형을 문서화합니다.
* 역할 및 권한의 경우: 기능 문서의 요구 사항 섹션에 사용자 유형이나 역할/권한을 포함해야 할 특별한 이유가 있다면 포함할 수 있습니다. 예를 들어: 기능에 대한 액세스를 제어하는 [권한](/docs/accounts/accounts-billing/new-relic-one-user-management/user-permissions)이 권한 이름([서비스 수준 관리 권한](/docs/service-level-management/faqs-slm#permissions) 등)에서 명확하게 드러나지 않는 경우, 이를 문서화해야 합니다.
* 조직 및 사용자 관리 권한의 경우, 필요한 역할을 문서화합니다. 이는 그 수가 많지 않고, 이를 관리하는 권한이 역할 및 권한 UI에 노출되지 않아 고객에게 덜 명확하기 때문입니다.

## 원래 사용자 모델과 새 사용자 모델을 모두 문서화하기 위한 고려 사항 [#user-model-requirements]

최신 사용자 모델 역할 또는 권한에 대한 요구 사항을 포함해야 하는 경우, 원래 사용자 모델에 대한 세부 정보도 포함해야 할 수 있습니다(해당 대상에게 해당 기능을 사용할 수 있다고 가정할 때). 다음은 이를 수행하는 방법의 예입니다:

```md
Permissions requirements differ depending on your user model:

* For users on the [original user model](/docs/accounts/original-accounts-billing/original-product-based-pricing/overview-user-models): the [**Data retention manager** role](/docs/accounts/original-accounts-billing/original-users-roles/users-roles-original-user-model/#roles).
* For users on [our newer user model](/docs/accounts/original-accounts-billing/original-product-based-pricing/overview-user-models): the [**Billing** administration setting](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts#admin-settings).
```
