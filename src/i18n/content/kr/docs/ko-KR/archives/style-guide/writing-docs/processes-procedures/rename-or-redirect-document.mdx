이 문서는 문서의 제목을 변경하는 방법과 리디렉션을 생성, 편집 및 삭제하는 방법을 설명합니다. 절차는 표준 문서(&quot;기본 페이지&quot;)와 릴리스 노트 모두 동일합니다.

<Callout variant="caution">
  제목을 변경하거나 리디렉션을 업데이트하면 콘텐츠를 찾는 데 문제가 발생할 수 있습니다. 제목이나 리디렉션을 변경해야 하는 경우 [GitHub 이슈를 생성](https://github.com/newrelic/docs-website/issues/new/choose) 하거나, 뉴렐릭 직원인 경우 #help-documentation Slack 채널을 통해 Docs hero에게 문의하십시오.
</Callout>

## URL 형식 [#title-url]

문서의 URL은 전적으로 GitHub 리포지터리의 파일 이름과 파일 경로를 기반으로 합니다. 자세한 내용은 [문서 URL](/docs/style-guide/processes-procedures/understand-edit-docs-site-structure#doc-url)을 참조하십시오.

## 제목 변경 [#titles]

문서 제목을 변경하려면 문서 상단의 프런트매터에 있는 `title` 필드에서 사용 중인 제목을 변경하십시오.

사이드바에서 제목을 업데이트하려면 nav 파일에서 해당 문서의 `title`을(를) 변경하십시오.

## 앵커 링크 변경 [#anchors]

가능한 한 H2 또는 축소기의 `[#anchor_ids]`을(를) 변경하지 마십시오. 삭제된 앵커에서 새 값으로 리디렉션할 수 있는 방법은 없습니다. 앵커 `id`이(가) 오래되었더라도 URL에 주의를 기울이지 않는 대다수의 사용자에게는 영향을 미치지 않습니다.

## 리디렉션 편집 [#redirects]

문서의 URL을 변경하는 경우 문서 상단의 `redirects` 프런트매터 섹션에 이전 URL을 추가하십시오.
