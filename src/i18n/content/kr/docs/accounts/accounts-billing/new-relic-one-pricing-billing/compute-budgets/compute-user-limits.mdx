컴퓨트 사용자 제한을 사용하면 조직 내 개별 사용자에 대한 월별 예산을 설정하고 컴퓨트 소비량에 따라 뉴렐릭 리소스에 대한 액세스를 관리할 수 있습니다. 사용자가 할당된 예산에 도달하면 월말까지 또는 예산을 늘릴 때까지 대시보드, 쿼리 빌더 및 API 호출에 대한 액세스를 차단할 수 있습니다.

또한 모든 사용자에게 적용되는 글로벌 사용자 예산을 통해 대규모 예산 관리를 간소화하므로, 모든 사용자에 대해 개별적으로 예산을 설정할 필요가 없습니다. 특정 요구 사항이 있는 사용자의 경우, 사용자 지정 재정의 예산을 생성할 수 있습니다.

이를 사용하여 다음을 수행합니다:

* 사용자별 소비량을 제한하여 컴퓨트 비용 제어
* 사용자 수준의 컴퓨트 소비량 모니터
* 조직 전체의 사용 패턴에 대한 가시성을 유지하십시오.
* 대규모 조직 전체의 예산 관리

## 핵심 역량

두 가지 예산 유형을 사용할 수 있습니다:

* **글로벌 사용자 예산**: 조직의 모든 사용자에게 적용되는 기본 예산을 설정합니다. 다음 중 하나로 구성하십시오:

  * **조직 예산 비율**: 조직 수준 컴퓨트 예산의 일정 비율(최소 약정 기준)을 각 사용자에게 할당합니다.
  * **실제 컴퓨트 값**: 각 사용자에 대한 정확한 컴퓨팅 용량 단위(CCU) 수를 지정하십시오.

* **사용자 지정 재정의 예산**: 글로벌 예산보다 높거나 낮은 한도가 필요한 개별 사용자에게 특정 예산을 할당합니다.

예산 추적은 글로벌 예산 또는 사용자 지정 재정의 예산을 구성할 때만 적용됩니다.

글로벌 예산을 구성한 경우 모든 사용자가 자동으로 해당 예산을 받습니다. 글로벌 예산 없이 사용자 지정 재정의 예산만 생성한 경우, 사용자 지정 예산이 없는 사용자는 무제한으로 액세스할 수 있습니다.

## 사용자 한도 작동 원리

사용자 한도는 각 사용자의 컴퓨트 소비를 추적합니다. 사용자에게 예산을 할당하면, 해당 사용자의 모든 컴퓨트 활동이 해당 예산에 계산됩니다. 사용자가 CCU와 CoreCCU를 모두 가지고 있는 경우, CCU만 예산 한도에 계산됩니다.

예를 들어, 사용자의 월간 예산이 1,000 CCU인 경우, 해당 사용자 ID 또는 API 키에 속성된 모든 컴퓨트 소비량이 해당 한도에 계산됩니다.

사용자가 할당된 예산에 도달하면 구성된 차단 또는 모니터링 규칙이 적용됩니다.

### 예산 공지

다음 임계값에서 인앱 배너 공지를 받습니다:

* **예산의 50% 소비됨**: 노란색 정보 배너
* **예산의 75% 소비**: 노란색 경고 배너
* **예산의 95% 소비**: 빨간색 위험 배너
* **예산 100% 소비**: 사용자가 예산을 초과했음을 나타내는 정보 배너

이러한 공지는 사용자가 소비 상태를 알 수 있도록 뉴렐릭 플랫폼에 배너로 표시됩니다.

### 예산 집행

조직 관리자는 사용자가 할당된 예산의 100%에 도달했을 때 발생하는 작업을 선택할 수 있습니다:

* **사용자 차단**: 차단하면 사용자가 다음에 액세스할 수 없습니다:

  * 대시보드 액세스
  * 쿼리 빌더 액세스
  * 사용자 ID 또는 API 키를 통한 API 액세스

  차단된 경우, 사용자는 액세스하려는 기능에 따라 오류 메시지를 보게 됩니다:

  * **쿼리 빌더**: 예산 초과로 인해 차단되었다는 메시지와 예산을 조회할 수 있는 옵션
  * **Dashboards**: 대시보드 보기에 대한 액세스를 방지하는 유사한 메시지
  * **API 호출**: *계정이 허용된 소비 예산을 초과했습니다*라는 오류 응답

* **모니터만 가능**: 액세스를 차단하지 않고 사용자에게 예산 소비에 대해 계속 알립니다.

<Callout variant="important">
  차단은 해당 월의 말일(UTC)까지 또는 사용자의 예산을 늘릴 때까지 유지됩니다. 소비 데이터는 몇 시간 내에 업데이트되므로 정확히 100%에서 차단이 발생하지는 않습니다. 차단이 적용되기 전에 사용자가 예산을 약간 초과할 수 있습니다.
</Callout>

## 글로벌 사용자 예산 설정

조직이 여러 뉴렐릭 조직에 걸쳐 있는 경우, 각 조직에 개별적으로 로그인하여 해당 사용자에 대한 사용자 한도를 생성하고 관리하십시오.

<Steps>
  <Step>
    ### 컴퓨트 예산 액세스

    1. <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; [user menu](/docs/accounts/accounts-billing/general-account-settings/intro-account-settings)**</DNT> 으)로 이동합니다.
    2. <DNT>**Administration &gt; Compute Budgets**</DNT> 선택합니다.
  </Step>

  <Step>
    ### 글로벌 예산 추가

    로그인한 조직의 모든 사용자에게 적용되는 예산을 생성하려면 <DNT>**Create a global user budget**</DNT>을(를) 클릭하십시오.
  </Step>

  <Step>
    ### 예산 설정

    1. 예산 할당 방법을 선택합니다:

       * **조직 예산의 비율**: 조직 수준 컴퓨트 예산(최소 약정 기준)의 일정 비율을 각 사용자에게 할당합니다. 예를 들어, 조직에 800,000개의 코어 CCU가 있고 사용자당 1%를 설정하면 각 사용자는 8,000개의 코어 CCU를 받습니다. 모든 사용자의 총 비율이 100%일 필요는 없습니다. 총합을 100% 미만(일부 예산을 할당하지 않은 상태로 둠) 또는 100% 초과로 설정할 수 있습니다. 총합을 100% 초과로 설정하는 것도 허용됩니다.
       * **실제 값**: 각 사용자에 대해 정확한 CCU 수를 지정합니다.

    2. 예산 금액을 입력하고 **Next** \[다음]을 클릭하십시오.
  </Step>

  <Step>
    ### 글로벌 예산 공지 검토

    이 페이지는 사용자가 받는 공지 임계값을 확인합니다. 설정이 필요하지 않습니다. 계속하려면 <DNT>**Next**</DNT>을(를) 클릭하십시오.
  </Step>

  <Step>
    ### 글로벌 예산 차단 구성

    1. 사용자가 CCU 예산을 초과할 때 사용량을 제한하는 방법을 선택하십시오. 제한은 예산이 소진될 때 시작되며 월말까지 또는 변경할 때까지 지속됩니다. 제한이 적용되면 공지가 수신됩니다.

       * **추가 CCU 사용 차단**: 사용자가 예산 한도에 도달하면 대시보드, 쿼리 빌더 또는 API 호출에 액세스할 수 없습니다. 사용자가 예산을 모두 소진하면 쿼리 실행이나 대시보드 새로 고침과 같이 CCU를 소비하는 작업에 차단이 적용됩니다.
       * **사용량 제한 안 함**: 사용자는 공지를 받지만 모든 기능에 대한 풀 액세스를 유지합니다. 이는 초과를 방지하지 않습니다.

    2. 글로벌 사용자 예산을 생성하려면 <DNT>**Finish**</DNT>을 클릭합니다.
  </Step>
</Steps>

## 사용자 지정 재정의 예산 설정

글로벌 예산과 다른 제한이 필요한 사용자를 위해 사용자 지정 재정의 예산을 생성하십시오. 각 사용자를 개별적으로 구성하지 않고 팀을 온보딩하거나 그룹에 일관된 제한을 적용할 때 이 방법을 사용하십시오.

<Steps>
  <Step>
    ### 사용자 예산 추가

    <DNT>**User Limits**</DNT> 페이지에서 <DNT>**+ Create a user budget**</DNT>를 클릭합니다.
  </Step>

  <Step>
    ### 사용자 선택

    드롭다운 메뉴에서 사용자 지정 재정의 예산을 할당할 사용자를 한 명 이상 선택합니다. 여러 사용자를 선택하면, 동일한 예산 금액이 각 사용자에게 개별적으로 적용됩니다. 예를 들어, 40,000 CCU를 설정하고 5명의 사용자를 선택하면, 각 사용자는 공유된 부분이 아니라 40,000 CCU를 받습니다.
  </Step>

  <Step>
    ### 사용자 지정 예산을 구성하십시오.

    1. 특정 백분율 또는 실제 값을 설정하십시오.
    2. <DNT>**Next**</DNT> 을(를) 클릭합니다.
  </Step>

  <Step>
    ### 사용자 지정 예산 공지 검토

    이 사용자에게 적용되는 공지 임계값을 검토합니다. 계속하려면 <DNT>**Next**</DNT>을 클릭합니다.
  </Step>

  <Step>
    ### 사용자 지정 예산 차단 구성

    1. 이 특정 사용자의 차단 기본 설정을 선택하십시오. 이는 글로벌 예산 설정과 다를 수 있습니다.

    2. 사용자 지정 재정의 예산을 생성하려면 <DNT>**Finish**</DNT>을(를) 클릭하십시오.
  </Step>
</Steps>

생성 후, 사용자 지정 재정의 예산은 예산 테이블에 별도의 항목으로 표시됩니다. 개별적으로 업데이트하거나 그룹 보기를 사용하여 그룹의 모든 사용자를 한 번에 업데이트할 수 있습니다.

## 사용자 한도 관리

### 예산 소비량 확인

글로벌 예산은 기본 <DNT>**User Limits**</DNT> 페이지 상단에 카드로 표시됩니다. 사용자 지정 재정의 예산은 아래의 예산 표에 표시됩니다.

**조직 관리자는 다음을 수행할 수 있습니다:**

* 전체 세부 정보가 포함된 테이블에서 글로벌 예산 카드 및 모든 사용자 지정 재정의 예산을 확인하십시오.

* 각 예산 옆의 점 3개 메뉴(**⋯**)에 액세스하여 다음 옵션을 사용할 수 있습니다:

  * <DNT>**View**</DNT>: 상세한 예산 정보, 소비량 및 추세 확인
  * <DNT>**Edit**</DNT>: 예산 설정 수정
  * <DNT>**Delete**</DNT>: 예산을 삭제합니다.

**읽기 전용 사용자는 다음을 수행할 수 있습니다:**

* 사용자 지정 재정의 예산이 있는 경우 테이블에서 자신의 예산 항목만 볼 수 있습니다.
* 글로벌 예산만 있는 경우 상단에서 글로벌 예산 카드만 볼 수 있습니다.
* 점 3개 메뉴에서 <DNT>**View**</DNT> 옵션에만 액세스할 수 있습니다
* 다른 사용자의 예산을 보거나 <DNT>**Edit**</DNT> 또는 <DNT>**Delete**</DNT> 옵션에 액세스할 수 없습니다.

### 예산 세부 정보 보기 [#budget-details]

예산을 볼 때(모든 사용자가 자신의 예산에 대해 사용 가능), 다음을 확인할 수 있습니다:

* 현재 예산 소비량
* 사용된 예산의 백분율
* 해당 월의 소비 추세
* 100%에서 차단 상태
* 공지 상태

### 예산 조정 [#adjust-budgets]

조직 관리자는 언제든지 예산을 수정할 수 있습니다:

* <DNT>**Edit existing budgets**</DNT>: 단일 사용자에 대한 예산 금액 또는 차단 기본 설정을 업데이트하거나, 그룹 보기를 사용하여 그룹의 모든 사용자에 대한 예산을 한 번에 업데이트하십시오.
* <DNT>**Increase a user&apos;s budget**</DNT>: 차단된 사용자에게 액세스를 복원하거나 추가 용량을 제공합니다.
* <DNT>**Decrease budgets**</DNT>: 현재 및 향후 청구 기간에 대해 약 15분 이내에 적용되도록 예산 금액을 조정합니다.
* <DNT>**Delete budgets**</DNT>: 글로벌 및 사용자 지정 재정의 예산을 모두 삭제합니다. 사용자 지정 재정의 예산을 삭제하면 사용자는 자동으로 글로벌 사용자 예산(구성된 경우)으로 돌아갑니다.

예산 변경 사항은 약 15분 이내에 적용됩니다.

<Callout variant="important">
  사용자 지정 예산을 삭제해도 예산 추적은 제거되지 않습니다. 예산 추적은 글로벌 예산(구성된 경우)에 따라 계속됩니다.
</Callout>

### 차단된 사용자 처리

사용자가 예산 소비로 인해 차단되는 경우:

* 대시보드 또는 쿼리 빌더에 액세스하려고 할 때 차단 메시지를 볼 수 있습니다.
* 예산 세부 정보를 조회하여 소비 정보를 확인합니다.
* 예산 증액을 요청하기 위해 귀하에게 연락

차단된 사용자의 액세스를 복원하려면 다음을 수행할 수 있습니다:

* 예산 증액 — [예산 조정](#adjust-budgets)을 참조하십시오.
* 예산이 재설정되고 액세스가 자동으로 복원되는 월말까지 기다리십시오

<Callout variant="tip">
  사용자가 제한 상향을 위해 연락할 사람을 알 수 있도록 조직 관리자의 내부 목록을 게시하고, 서비스 인시던트 중에 상향을 신속하게 승인할 수 있는 관리자가 한 명 이상 있는지 확인하십시오.
</Callout>

## 일반적인 시나리오

**예산은 언제 재설정됩니까?** 예산은 UTC를 기준으로 매월 초에 재설정됩니다.

**사용자가 예산의 100%에 도달하면 진행 중인 쿼리는 어떻게 됩니까?** 쿼리 실행이 완료되었습니다. 차단은 새로운 쿼리, 대시보드 로드 및 API 호출이 시작되는 것만 방지합니다.
