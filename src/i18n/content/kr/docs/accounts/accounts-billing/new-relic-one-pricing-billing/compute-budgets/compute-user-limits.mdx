Compute User Limits \[컴퓨트 사용자 한도]를 사용하면 조직의 개별 사용자에 대해 일일 또는 월간 예산을 설정하고 컴퓨트 소비량에 따라 뉴렐릭 리소스에 대한 액세스를 관리할 수 있습니다. 각 예산은 코어 컴퓨트(core CCUs)와 고급 컴퓨트(advanced CCUs)를 별도의 미터로 추적합니다. 사용자가 미터에 대해 할당된 예산에 도달하면 예산 기간이 끝나거나 예산을 늘릴 때까지 관련 리소스에 대한 액세스를 차단할 수 있습니다.

또한 모든 사용자에게 적용되는 글로벌 사용자 예산을 통해 대규모 예산 관리를 간소화하므로, 모든 사용자에 대해 개별적으로 예산을 설정할 필요가 없습니다. 특정 요구 사항이 있는 사용자의 경우, 사용자 지정 재정의 예산을 생성할 수 있습니다.

컴퓨트 사용자 한도를 사용하여 다음을 수행하십시오:

* 사용자별 소비량을 제한하여 컴퓨트 비용 제어
* 사용자 수준의 컴퓨트 소비량 모니터
* 조직 전체의 사용자 컴퓨트 사용 패턴에 대한 가시성을 유지하십시오.
* 대규모 조직 전체에서 사용자 컴퓨트 예산을 관리하십시오.

## 핵심 역량

두 가지 예산 유형을 사용할 수 있습니다:

* **Global user budget \[글로벌 사용자 예산]**: 조직의 모든 사용자에게 적용되는 기본 예산을 설정하십시오.
* **사용자 지정 재정의 예산**: 글로벌 예산보다 높거나 낮은 한도가 필요한 개별 사용자에게 특정 예산을 할당합니다.

두 예산 유형 모두에 대해 미터당 다음을 구성합니다:

* **Core CCU limit** \[핵심 CCU 한도]: 조직 수준의 컴퓨트 예산에 대한 백분율로 설정하며, 해당하는 CCU 값이 자동으로 계산됩니다. 이 미터의 한도 유형으로 **Block CCU usage** \[CCU 사용 차단] 또는 **Do not block CCU usage** \[CCU 사용 차단 안 함]을 선택하십시오.
* **Advanced CCU limit** \[고급 CCU 한도]: 조직 수준 컴퓨트 예산의 백분율로 설정하며, 해당하는 CCU 값이 자동으로 계산됩니다. 이 미터의 한도 유형으로 **Block CCU usage** \[CCU 사용 차단] 또는 **Do not block CCU usage** \[CCU 사용 차단 안 함]을 선택하십시오.

예산 추적은 글로벌 예산 또는 사용자 지정 재정의 예산을 구성할 때만 적용됩니다.

글로벌 예산을 구성한 경우 모든 사용자가 자동으로 해당 예산을 받습니다. 글로벌 예산 없이 사용자 지정 재정의 예산만 생성한 경우, 사용자 지정 예산이 없는 사용자는 무제한으로 액세스할 수 있습니다.

뉴렐릭 Autopilot의 사용량을 관리해야 하는 경우, 대신 [Autopilot compute limits](/docs/agentic-ai/autopilot/autopilot-compute-limits/) \[Autopilot 컴퓨트 한도] 기능을 사용해 주십시오.

## 사용자 한도 작동 원리

사용자 한도는 두 개의 독립적인 측정기에서 각 사용자의 컴퓨트 소비를 추적합니다: 핵심 컴퓨트(core CCUs) 및 고급 컴퓨트(advanced CCUs). 사용자에게 예산을 할당하면, 해당 사용자의 컴퓨트 활동이 적절한 측정기에 반영됩니다. 각 측정기에는 자체 예산 값과 한도 유형이 있습니다.

예를 들어, 사용자에게 10,000 코어 CCU 예산과 5,000 고급 CCU 예산이 있는 경우, 쿼리 실행 및 대시보드 새로 고침과 같은 표준 컴퓨트 활동은 코어 CCU 한도에 반영되며, Ask AI, Live Archives 및 MCP와 같은 고급 컴퓨트 활동은 고급 CCU 한도에 반영됩니다.

사용자가 미터에 할당된 예산에 도달하면 해당 미터에 대해 구성된 제한 유형이 적용됩니다.

### 코어 및 고급 컴퓨트 미터

코어 컴퓨트(core CCUs)는 대시보드, 쿼리 빌더 및 API 호출을 포함합니다. 고급 컴퓨트(advanced CCUs)는 Live Archives \[라이브 아카이브] 및 AI 기반 기능과 같은 기능을 포함합니다.

사용자의 핵심 CCU 예산이 소진되고 한도 유형이 **Block CCU usage** \[CCU 사용 차단]으로 설정된 경우, 다음 항목에 대한 액세스 권한을 잃게 됩니다:

* [대시보드](/docs/query-your-data/explore-query-data/dashboards/introduction-dashboards)
* [쿼리 빌더](/docs/query-your-data/explore-query-data/query-builder/introduction-query-builder)
* API 호출

사용자의 고급 CCU 예산이 소진되고 제한 유형이 **Block CCU usage** \[CCU 사용 차단]으로 설정된 경우, 다음에 대한 액세스 권한을 상실합니다:

* [Ask AI \[AI에게 묻기\]](/docs/agentic-ai/new-relic-ai) (V1 및 V2)
* [Live Archives \[라이브 아카이브\]](/docs/logs/get-started/live-archives) (query builder \[쿼리 빌더]의 Query Live Archives \[라이브 아카이브 쿼리] 버튼 및 Use live archives \[라이브 아카이브 사용] 토글)
* [MCP](/docs/agentic-ai/mcp/overview)
* [에러스 인박스(errors inbox)](/docs/apm/errors-inbox/errors-inbox-ui) (Explain Error \[오류 설명] 및 Generate Insights \[Insights 생성])

다음 고급 CCU 소비 제품은 이 컴퓨트 사용자 한도 기능에서 지원되지 않으며, 사용자의 고급 CCU 예산이 100%에 도달하더라도 계속 액세스할 수 있습니다:

* 파이프라인 컨트롤
* 무제한 기수
* 트랜잭션 360
* 시큐리티 RX
* 뉴렐릭 AI 지식
* Autopilot

<Callout variant="tip">
더 많은 제품이 정식 출시됨에 따라 적용 대상인 고급 CCU 제품 목록이 늘어날 수 있습니다. 지원되는 고급 CCU 제품에 대한 업데이트는 여기에서 다시 확인해 주십시오.
</Callout>

### 예산 주기

예산을 생성할 때 매일 또는 매월 재설정할지 여부를 선택합니다. 올바른 선택은 사용자의 작업 패턴과 비용을 얼마나 엄격하게 제어해야 하는지에 따라 다릅니다.

다음 표는 월간 및 일간 예산을 비교합니다:

| 행동        | 월별           | 일일            |
| --------- | ------------ | ------------- |
| **재설정**   | 매월 시작(UTC)   | 각 역일의 시작(UTC) |
| **차단 해제** | 다음 달 시작(UTC) | 다음 역일 시작(UTC) |

다음 중 하나라도 해당하는 경우 월별 예산을 선택하십시오:

* 사용자는 청구 기간에 걸쳐 평균화되는 변동성 있는 일일 사용량을 보입니다 — 예를 들어, 스프린트가 끝날 때 집중적인 쿼리를 실행하지만 그 외에는 사용량이 적은 개발자가 있습니다
* 예산 기간을 청구 주기와 일치시키는 것이 좋습니다.
* 월 1회만 재설정하기를 원합니다.

다음 중 하나라도 해당하는 경우 일일 예산을 선택하십시오:

* 폭주하는 쿼리 또는 스크립트가 하루에 소비할 수 있는 양을 제한하고자 합니다.
* 사용자의 일일 사용량이 일정하며 고정된 일일 한도를 원합니다.
* 더 짧은 복구 기간을 원합니다: 일일 예산에 따라 차단된 사용자는 월말까지 기다리는 대신 다음 날 다시 액세스할 수 있습니다.

<Callout variant="tip">
일일 한도는 총 사용량이 월간 예산 내에 유지되었을 경우에도 사용량이 많은 날에 사용자를 차단할 수 있습니다. 일일 한도를 광범위하게 적용하기 전에 사용자의 일반적인 사용 패턴을 검토하십시오.
</Callout>

### 예산 공지

공지는 각 컴퓨트 미터에 대해 독립적으로 발생합니다. 인앱 공지는 4개의 모든 임계값에서 발생하며, 이메일 공지는 75% 및 100%에서만 발생합니다.

| 한계점      | Urgency \[긴급도] | 앱 내 공지 | 이메일 |
| -------- | -------------- | ------ | --- |
| **50%**  | 정보             | ✓      | —   |
| **75%**  | 경고             | ✓      | ✓   |
| **95%**  | 비판적인           | ✓      | —   |
| **100%** | 비판적인           | ✓      | ✓   |

예를 들어, 100,000 코어 CCU 예산과 200,000 고급 CCU 예산을 가진 사용자는 50,000, 75,000, 95,000 및 100,000 코어 CCU에서 코어 CCU 공지를 받고, 100,000, 150,000, 190,000 및 200,000 고급 CCU에서 별도의 고급 CCU 공지를 받습니다. 이메일 공지는 각 미터의 75% 및 100% 임계값에서 전송됩니다.

### 예산 집행

조직 관리자는 각 컴퓨트 미터에 대해 독립적으로 한도 유형을 구성합니다. 즉, 예를 들어 사용자의 코어 컴퓨트에 **Block CCU usage** \[CCU 사용 차단]을 적용하고 고급 컴퓨트에는 **Do not block CCU usage** \[CCU 사용 차단 안 함]을 설정하거나, 두 가지 모두에 동일한 한도 유형을 적용할 수 있습니다.

**코어 컴퓨트의 경우, 다음 중 하나를 선택하십시오:**

* **Block CCU usage** \[CCU 사용 차단]: 사용자가 예산을 모두 소진하면 사용자에게 알리고 Query Builder \[쿼리 빌더], Dashboards 및 API 호출에 대한 액세스를 차단합니다: 쿼리 실행, 대시보드 새로 고침 및 API 호출.
* **Do not block CCU usage** \[CCU 사용 차단 안 함]: 사용자가 예산을 소진하면 알림을 보내지만, CCU를 소비하는 제품에 대한 액세스는 차단하지 않습니다. 이 옵션은 전체 플랫폼 액세스를 유지하지만 초과 사용을 방지하지는 않습니다.

**고급 컴퓨트의 경우 다음 중 하나를 선택하십시오:**

* **Block CCU usage** \[CCU 사용 차단]: 사용자가 예산을 모두 소진하면 사용자에게 공지하고 다음과 같은 액세스를 차단합니다: [Ask AI](/docs/agentic-ai/new-relic-ai), [Live Archives \[라이브 아카이브\]](/docs/logs/get-started/live-archives), [MCP](/docs/agentic-ai/mcp/overview) 및 [Errors Inbox \[에러스 인박스(errors inbox)\]](/docs/apm/errors-inbox/errors-inbox-ui).
* **Do not block CCU usage \[CCU 사용 차단 안 함]**: 사용자가 예산을 모두 소진하면 공지하지만 CCU 소비 작업에 대한 액세스는 차단하지 않습니다. 이 옵션은 플랫폼 풀 액세스를 유지하지만 초과 사용을 방지하지는 않습니다.

차단되면 사용자는 해당 기간의 예산을 모두 사용했으며 질문이 있는 경우 조직 관리자에게 문의할 수 있다는 내용의 화면을 보게 됩니다.

<Callout variant="tip">
예산 한도를 처음 도입하는 경우, 두 미터 모두 **Do not block CCU usage** \[CCU 사용 차단 안 함]으로 시작하십시오. 이를 통해 차단을 활성화하기 전에 실제 사용 패턴을 관찰할 수 있으며, 예기치 않은 액세스 중단 가능성을 줄일 수 있습니다.
</Callout>

<Callout variant="important">
월간 예산의 경우, 차단은 해당 역월이 끝날 때(UTC)까지 유지됩니다. 일일 예산의 경우, 차단은 해당 역일이 끝날 때(UTC)까지 유지됩니다. 두 경우 모두 사용자의 예산을 늘려 더 일찍 액세스를 복원할 수 있습니다. 소비 데이터는 몇 시간(일반적으로 2～4시간) 내에 업데이트되므로, 차단이 정확히 100%에서 발생하지는 않습니다. 사용자는 차단이 적용되기 전에 예산을 초과할 수 있습니다.
</Callout>

## 시작하기 전에

예산을 생성할 때 네 가지 설정을 구성합니다. 시작하기 전에 이를 검토하면 설정 마법사에서 올바른 선택을 하는 데 도움이 됩니다.

| 환경            | 옵션                                                                                  | 고려해야 할 사항                                                                                                                                     |
| ------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **예산 유형**     | 전역 또는 사용자 지정 재정의                                                                    | 글로벌 예산을 기준으로 시작하십시오. 다른 한도가 필요한 사용자를 위해 사용자 지정 재정의를 추가하십시오.                                                                                   |
| **빈도**        | 월간 또는 일일                                                                            | 이 둘 중 하나를 선택하는 방법에 대한 지침은 [예산 빈도](#budget-frequency)를 참조하십시오.                                                                                 |
| **핵심 CCU 할당** | 조직 예산의 백분율, Block CCU usage \[CCU 사용 차단] 또는 Do not block CCU usage \[CCU 사용 차단 안 함] | 백분율을 입력하면 마법사가 해당하는 CCU 값을 계산합니다. 이 미터의 경우 제한 유형도 선택합니다. 차단을 활성화하기 전에 실제 사용 패턴을 관찰하려면 **Do not block CCU usage \[CCU 사용 차단 안 함]** (으)로 시작합니다. |
| **고급 CCU 할당** | 조직 예산의 백분율, Block CCU usage \[CCU 사용 차단] 또는 Do not block CCU usage \[CCU 사용 차단 안 함] | 백분율을 입력하면 마법사가 해당하는 CCU 값을 계산합니다. 이 미터의 경우 제한 유형도 선택합니다. 차단을 활성화하기 전에 실제 사용 패턴을 관찰하려면 **Do not block CCU usage \[CCU 사용 차단 안 함]** (으)로 시작합니다. |

## 글로벌 사용자 예산 설정

조직이 여러 뉴렐릭 조직에 걸쳐 있는 경우, 각 조직에 개별적으로 로그인하여 해당 사용자에 대한 사용자 한도를 생성하고 관리하십시오.

<Steps>
<Step>
### 컴퓨트 예산 액세스

1. <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; [user menu](/docs/accounts/accounts-billing/general-account-settings/intro-account-settings)**</DNT> 으)로 이동합니다.
2. <DNT>**Administration &gt; Compute Budgets**</DNT> 선택합니다.
</Step>

<Step>

</Step>

<Step>

<DNT>**Set the frequency**</DNT>에서 예산 재설정 빈도를 선택하십시오:

* <DNT>**Monthly**</DNT>: 역월을 기준으로 사용량을 추적하고 매월 초(UTC)에 재설정합니다.

<DNT>**Next**</DNT> 을(를) 클릭합니다.

<Step>

   * <DNT>**Do not block CCU usage**</DNT>: 사용자에게 공지하지만 전체 플랫폼 액세스는 유지합니다. 이는 초과 사용을 방지하지 않습니다.

<DNT>**Next**</DNT> 을(를) 클릭합니다.
</Step>

</Steps>

## 사용자 한도 관리

### 예산 소비량 확인

조직 관리자는 <DNT>**Compute Budgets**</DNT> 페이지 상단에서 <DNT>**Global user budget**</DNT> 카드를 볼 수 있습니다. 이 카드는 구성된 코어 CCU 및 고급 CCU 양, 사용자당 할당된 백분율 및 각 미터의 제한 유형을 표시합니다.

카드 아래의 <DNT>**User budgets**</DNT> 테이블에는 다음 열과 함께 사용자 지정 재정의 예산이 표시됩니다:

| 열                            | 설명                                                                                                                   |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **사용자**                      | 사용자의 이메일 주소                                                                                                          |
| **빈도**                       | 예산이 매일 또는 매월 초기화되는지 여부                                                                                               |
| **Core usage \[코어 사용량]**     | 할당량의 백분율로 표시된 현재 코어 CCU 소비량이며, Block CCU usage \[CCU 사용 차단]이 활성화된 상태에서 사용자가 예산을 초과한 경우에는 **Blocked \[차단됨]**으로 표시됩니다. |
| **Core allocation \[코어 할당]** | 코어 CCU 예산 금액 및 구성된 한도 유형(Block \[차단] 또는 Do not block \[차단 안 함])                                                      |
| **고급 사용법**                   | 할당량의 백분율로 나타낸 현재 고급 CCU 소비량, 또는 임계값에 근접할 경우 **Close to limit \[한도 근접]**                                              |
| **고급 할당**                    | 고급 CCU 예산 금액 및 구성된 제한 유형(Block \[차단] 또는 Do not block \[차단 안 함])                                                      |

동일한 예산 설정을 공유하는 사용자를 클러스터하려면 <DNT>**Group by &gt; Allocation, limit, and frequency**</DNT>을(를) 사용하십시오. 각 그룹 헤더는 설정을 요약합니다. 예: `Core CCU 45,000 CCU · Block | Advanced CCU 100,000 CCU · Do not block | Monthly`.

**조직 관리자**는 다음을 수행할 수 있습니다:

* 테이블에서 모든 사용자 지정 재정의 예산을 전체 세부 정보와 함께 확인하십시오.

* 각 예산 옆에 있는 점 3개 메뉴(**⋯**)에 액세스하십시오. 메뉴에는 다음 옵션이 포함되어 있습니다:

  * <DNT>**View**</DNT>: 상세한 예산 정보, 소비량 및 추세 확인
  * <DNT>**Edit**</DNT>: 예산 설정 수정
  * <DNT>**Delete**</DNT>: 예산을 삭제합니다.

**읽기 전용 사용자**는 다음을 수행할 수 있습니다:

* 사용자 지정 재정의 예산이든 전역 예산이든 관계없이 테이블에서 자신의 예산을 항목으로 확인합니다.
* 점 3개 메뉴에서 <DNT>**View**</DNT> 옵션에만 액세스합니다.

읽기 전용 사용자는 다른 사용자의 예산을 보거나 <DNT>**Edit**</DNT> 또는 <DNT>**Delete**</DNT>을(를) 사용할 수 없습니다.

### 예산 세부 정보 보기 [#budget-details]

예산을 볼 때(모든 사용자가 자신의 예산에 대해 사용 가능), 다음을 확인할 수 있습니다:

* 현재 핵심 CCU 및 고급 CCU 소비량
* 사용된 각 예산의 백분율
* 해당 기간의 소비 추세
* 각 미터에 대한 100% 도달 시 차단 상태
* 공지 상태

### 예산 조정 [#adjust-budgets]

조직 관리자는 언제든지 예산을 수정할 수 있습니다:

* <DNT>**Edit existing budgets**</DNT>: 단일 사용자의 예산 금액, 주기 또는 제한 유형을 업데이트하거나, group view \[그룹 보기]를 사용하여 그룹 내 모든 사용자의 예산을 한 번에 업데이트합니다.
* <DNT>**Increase a user&apos;s budget**</DNT>: 차단된 사용자에게 액세스를 복원하거나 추가 용량을 제공합니다.
* <DNT>**Decrease budgets**</DNT>: 현재 및 향후 예산 기간에 대한 예산 금액을 조정합니다.
* <DNT>**Delete budgets**</DNT>: 전역 및 사용자 지정 재정의 예산을 모두 삭제합니다. 사용자 지정 재정의 예산을 삭제하면 사용자는 자동으로 전역 사용자 예산(구성한 경우)으로 돌아갑니다.

예산 변경 사항은 약 15분 이내에 적용됩니다.

<Callout variant="important">
사용자 지정 예산을 삭제해도 예산 추적은 제거되지 않습니다. 예산 추적은 글로벌 예산(구성한 경우)에 따라 계속됩니다.
</Callout>

### 차단된 사용자 처리

예산 소진으로 인해 사용자가 차단된 경우 다음을 수행할 수 있습니다:

* 해당 기간의 예산을 모두 사용했다는 메시지를 확인합니다.
* 예산 세부 정보를 조회하여 소비를 확인합니다.
* 예산 증액을 요청하기 위해 귀하에게 연락

차단된 사용자의 액세스를 복원하려면 다음 옵션 중 하나를 선택하십시오:

* 예산을 늘립니다. [예산 조정](#adjust-budgets)을 참조하십시오.
* 다음 예산 기간의 시작 시 예산이 재설정될 때까지 기다리십시오. [예산 주기](#budget-frequency)를 참조하십시오.

<Callout variant="tip">
사용자가 제한 상향을 위해 연락할 사람을 알 수 있도록 조직 관리자의 내부 목록을 게시하고, 서비스 인시던트 중에 상향을 신속하게 승인할 수 있는 관리자가 한 명 이상 있는지 확인하십시오.
</Callout>

## 일반적인 시나리오

**예산은 언제 재설정됩니까?** 예산을 설정할 때 선택한 빈도에 따라 다릅니다:

* **월간**: 예산은 각 달력 기준 월의 시작 시점(UTC)에 재설정됩니다.
* **일간**: 예산은 각 역일의 시작(UTC) 시 재설정됩니다.

**사용자가 핵심 CCU 예산의 100%에 도달하면 진행 중인 쿼리는 어떻게 됩니까?** 실행 중인 쿼리는 완료됩니다. 차단은 차단 시행 이후에 새로운 쿼리, 대시보드 로드 및 API 호출이 시작되는 것만 방지합니다. 소비 데이터 보고 지연에 대한 위의 참고 사항을 참조하십시오.

**사용자가 고급 CCU 예산의 100%에 도달하면 어떻게 됩니까?** 고급 CCU 제한 유형이 **Block CCU usage \[CCU 사용 차단]**으로 설정된 경우 사용자는 [Ask AI \[AI에게 묻기\]](/docs/agentic-ai/new-relic-ai), [Live Archives \[라이브 아카이브\]](/docs/logs/get-started/live-archives), [MCP](/docs/agentic-ai/mcp/overview) 및 [Errors Inbox \[에러스 인박스(errors inbox)\]](/docs/apm/errors-inbox/errors-inbox-ui)에 대한 액세스 권한을 잃게 됩니다. 제한 유형이 **Do not block CCU usage \[CCU 사용 차단 안 함]**인 경우 사용자는 계속해서 풀 액세스를 유지하지만 공지를 받게 됩니다.

**사용자의 사용자 지정 재정의 예산을 삭제하면 어떻게 됩니까?** 글로벌 사용자 예산을 구성한 경우 사용자는 자동으로 해당 예산으로 돌아갑니다. 글로벌 예산이 존재하지 않는 경우 사용자는 무제한으로 액세스할 수 있습니다.

**예산이 할당되지 않은 사용자는 어떻게 됩니까?** 예산이 할당되지 않은 사용자는 대시보드, 쿼리 빌더, API 호출 및 AI 기능에 무제한으로 액세스할 수 있습니다.

**예산 변경 사항은 얼마나 빨리 적용됩니까?** 예산 변경 사항은 약 15분 이내에 적용됩니다.
