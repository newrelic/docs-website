  이 기능은 아직 개발 중이지만 꼭 사용해 보시기 바랍니다!

  이 기능은 현재 [출시 전 정책](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy) 에 따라 미리보기 프로그램의 일부로 제공됩니다.
</Callout>

기존 모니터링은 종종 엔지니어링 팀이 고립된 서비스 레벨 메트릭을 추적하도록 강제하여, 중요한 사용자 여정이 저하될 때 단편적이고 &quot;회전의자&quot;식 디버깅 경험을 초래합니다. 지능형 워크로드는 트랜잭션 360의 사후 대응적인 문제 진단 및 해결을 사전 예방적이고 자체 업데이트되는 모니터링 허브로 발전시킵니다. 분산 추적을 활용하여 전체 아키텍처 자산을 단일 비즈니스 트랜잭션에 자동으로 매핑함으로써, 시스템이 변경됨에 따라 풀스택 종속성을 지속적으로 추적하고 기술적 성능을 실시간 비즈니스 성과(KPI)와 일치시킵니다.

시작할 준비가 되셨습니까? 계정에 [분산 추적](/docs/distributed-tracing/enable-configure/quick-start) 이 활성화되어 있는지 확인하십시오.

## 지능형 워크로드 생성 방법 [#create]

지능형 워크로드는 세 가지 방법으로 생성할 수 있으며, 각각 설정하는 데 몇 분밖에 걸리지 않습니다:

<CollapserGroup>
  <Collapser id="create-from-recommendations" title="권장 워크로드에서 생성">
    어떤 APM 트랜잭션을 우선시해야 할지 확실하지 않은 경우에 이상적입니다. 뉴렐릭은 자동으로 계정 데이터를 분석하고 영향력이 큰 트랜잭션 흐름을 강조 표시합니다.

    ### 추천 상품 보기

    워크로드 페이지로 이동할 때 뉴렐릭이 추천 워크로드를 찾은 경우 상단에 배너가 표시됩니다:

    <img title="Workloads page with Review recommendations banner" alt="Screenshot of the Workloads page showing the Review recommendations banner and button" src="/images/intelligent-workload-review-recs.webp" />

    <DNT>**Review recommendations**</DNT> 클릭하여 추천 모달을 여세요.

    ### 검토 후 추천 사항을 기반으로 생성

    **Recommended Intelligent Workloads** \[권장 지능형 워크로드] 모달은 모니터링을 통해 이점을 얻을 수 있는 트랜잭션을 보여줍니다.

    1. **카테고리별 필터링**: 탭을 사용하여 카테고리를 전환하세요.

       * **Key Transactions** \[주요 프로세서]: 트래픽이 많거나 비즈니스에 중요한 트랜잭션
       * **Impacted Transactions** \[영향받는 거래]: 성능 문제 또는 오류가 발생한 거래

    2. **정렬 기준**: 드롭다운 메뉴를 사용하여 다음 기준으로 정렬하세요.

       * 가장 높은 오류율
       * 가장 느린 평균 응답 시간
       * 가장 시간이 많이 걸리는 부분

    3. **프로세서 세부 정보 검토**: 각 권장 사항에는 다음이 표시됩니다.

       * **Transaction name** \[프로세서 이]름: 워크로드의 초점 프로세서
       * **Focal entity** \[초점(Focal)]: 프로세서를 처리하는 기본 서비스입니다.
       * **Response Time** \[응답 시간]: 평균 지연 시간 (예: &quot;0.57s&quot;)
       * **Error Rate** \[오류율]: 실패한 requests 비율 (예: &quot;0.6%&quot;)
       * **Total Duration** \[총 소요 시간]: 처리 시간 합계 (예: &quot;77.60초&quot;)

    4. **생성하기**: 추천 항목 옆에 있는 <DNT>**Create**</DNT> 클릭하세요.

    추천을 기반으로 생성할 때 뉴렐릭은 자동으로 참조 및 참조 선택 항목을 미리 채워주고, **Add details** \[세부 정보 추가] 단계로 바로 이동하여 다음을 수행할 수 있습니다.

    * 워크로드 이름을 지정하세요
    * 설명을 추가하세요 (선택 사항)
    * 초점 서비스 및 프로세서 확인
    * 설정을 완료하세요

    <Callout variant="tip">
      지능형 워크로드를 처음 사용하거나 전용 모니터링을 통해 가장 큰 이점을 얻을 수 있는 트랜잭션을 신속하게 파악하려는 경우, 권장 사항을 기반으로 생성하는 것이 이상적입니다.
    </Callout>
  </Collapser>

  <Collapser id="create-workloads-page" title="워크로드 페이지에서 생성">
    표준 설정 마법사를 사용하여 워크로드를 구축하고자 하는 특정 계정, 서비스 및 트랜잭션을 이미 알고 있는 경우에 이상적입니다.

    1. <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Workloads**</DNT> 으)로 이동합니다.
    2. <DNT>**Create a workload**</DNT> 을(를) 클릭합니다.
    3. <DNT>**Intelligent Workload**</DNT> 유형을 선택하세요.
    4. 마법사를 시작하려면 <DNT>**Setup**</DNT> 클릭하세요.

    <img title="Select Intelligent Workload type" alt="Screenshot showing workload type selection with Standard and Intelligent options" src="/images/create_intelligent_workload.webp" />

    ### 1단계: 엔티티를 선택합니다 [#select-entity]

    귀하의 중요한 프로세서가 포함된 서비스 또는 미팅을 선택하십시오:

    1. 이름으로 해당 항목을 검색하거나 찾아보세요.
    2. 필요한 경우 엔티티 유형별로 필터링하세요(APM 서비스, 브라우저 앱 등).
    3. 귀하의 주요 프로세서를 처리하는 프로세서를 선택하세요.
    4. <DNT>**Next**</DNT> 을(를) 클릭합니다.

    <Callout variant="tip">
      귀하의 프로세서 흐름의 중심이 되는 파티션을 선택하세요. 예를 들어, 결제 과정을 모니터링하는 경우 주변 로깅 서비스 대신 결제 서비스를 선택하십시오.
    </Callout>

    ### 2단계: 프로세서 선택 [#pick-transaction]

    모니터하려는 특정 프로세서를 선택하십시오:

    1. 선택한 엔티티의 트랜잭션 목록을 찾아보십시오.
    2. 검색을 사용하여 특정 트랜잭션 이름을 찾으십시오.
    3. 비즈니스 워크플로우를 나타내는 트랜잭션을 선택하십시오.
    4. <DNT>**Next**</DNT> 을(를) 클릭합니다.

    워크로드는 이 프로세서에 참여하는 모든 행위를 추적트레이스를 기반으로 추적합니다.

    <Callout variant="important">
      인프라 엔티티는 플랫폼 제한으로 인해 현재 상태 추적에서 제외됩니다. APM 서비스, 브라우저 앱 및 기타 계측된 엔티티만 워크로드 상태 계산에 포함됩니다.
    </Callout>

    ### 3단계: 세부 정보 추가 [#add-details]

    귀하의 상황에 대한 정보를 제공하십시오:

    1. **Name** \[이]름: 기술 이름을 입력합니다(예: &quot;Checkout 프로세서&quot;, &quot;사용자 인증 흐름&quot;)
    2. **Description** \[설명] (선택 사항): 이 워크로드가 모니터링하는 내용과 그 중요성에 대한 맥락을 추가하십시오.
    3. **Account** \[계정]: 워크로드가 생성될 계정을 선택하십시오. 기본적으로 현재 활성화된 계정이 미리 선택되어 있습니다. 다른 계정에 워크로드를 생성하려면 드롭다운 메뉴를 사용하여 변경하십시오.
    4. <DNT>**Next**</DNT> 을(를) 클릭합니다.

    ### 4단계: 미리 보기 및 최종 확정 [#preview-finalize]

    워크로드 설정을 검토하세요.

    1. **Focal entity** 가 올바른지 확인하십시오.
    2. **Focal 트랜잭션** 이 의도한 워크플로우와 일치하는지 확인하십시오.
    3. 워크로드 **Name** (이름) 및 **Description**(설명)을 검토하십시오.
    4. <DNT>**Create Workload**</DNT> 을(를) 클릭합니다.

    지능형 워크로드는 트랜잭션에 참여하는 엔티티 추적을 즉시 시작합니다.
  </Collapser>

  <Collapser id="create-from-t360" title="트랜잭션 360에서 생성">
    인시던트를 적극적으로 조사 중이며 현재 트랜잭션 뷰를 영구적이고 사전 예방적인 워크로드로 원활하게 저장하려는 경우에 이상적입니다.

    <img title="Save as Intelligent Workload from Transaction 360" alt="Screenshot of Transaction 360 showing the Save as workload button" src="/images/intelligent-workload-save-as-workload.webp" />

    1. <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; APM &amp; Services**</DNT> 으)로 이동합니다.
    2. 중요한 트랜잭션 흐름의 일부인 서비스를 선택하십시오.
    3. 모니터하려는 특정 프로세서로 이동하여 <DNT>**Transaction 360**</DNT> 클릭합니다.
    4. <DNT>**Save as Intelligent Workload**</DNT> 을(를) 클릭합니다.
    5. 워크로드의 기술 이름을 입력하세요.
    6. <DNT>**Save**</DNT> 을(를) 클릭합니다.

    <Callout variant="tip">
      개별 API 호출보다는 완전한 비즈니스 흐름흐름(예: &quot;checkout&quot;, &quot;사용자-인증&quot;)을 나타내는 데스크탑 이름을 선택하세요.
    </Callout>
  </Collapser>
</CollapserGroup>

## 무엇 향후 계획 [#next-steps]

지능형 워크로드가 생성되면, 핵심 뷰와 도구를 탐색하여 중요한 고객 여정 모니터링에 익숙해지십시오:

* **[통합된 경험으로 조사](/docs/new-relic-solutions/new-relic-one/workloads/intelligent-workload-integrated-experiences)**: 에러스 인박스(errors inbox), 성능 위험, 트랜잭션 360 및 종속성 맵을 포함하여 범위가 지정된 하위 뷰를 자세히 살펴보십시오 ― 워크로드 컨텍스트에 직접 구축되어 있습니다.
* **[사용자 지정 KPI 관리](/docs/new-relic-solutions/new-relic-one/workloads/intelligent-workload-kpis)**: 기술적 성능 지표와 함께 사용자 지정 비즈니스 메트릭(결제 성공률 등)을 정의하고 추적합니다.
