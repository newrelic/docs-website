Claude Code, Cursor, GitHub Copilot 또는 Codex와 같은 AI 코딩 에이전트에 프로젝트에 뉴렐릭을 추가하도록 요청할 수 있습니다. 에이전트는 설치 문서를 읽고 프로젝트에 필요한 뉴렐릭 에이전트를 결정한 후 변경 사항을 대신 적용합니다.

## 시작하기 전에 [#before-you-begin]

* **뉴렐릭 계정**: 아직 계정이 없으신 경우 [뉴렐릭 계정에 가입하십시오](https://newrelic.com/signup).
* **라이선스 키**: <InlinePopover type="licenseKey" />이(가) 필요합니다. 이를 찾으려면 [라이선스 키](/docs/apis/intro-apis/new-relic-api-keys#license-key)를 참조하십시오.

<Callout variant="important">
라이선스 키가 에이전트의 컨텍스트에 포함되지 않도록 하십시오. 채팅에 붙여넣지 마십시오. 앱이 실행되는 위치에서 `NEW_RELIC_LICENSE_KEY` 환경 변수로 직접 설정하십시오.
</Callout>

## 이 프롬프트를 복사하십시오. [#prompt]

프로젝트 폴더에서 AI 코딩 에이전트를 열고 다음 프롬프트를 붙여넣으십시오:

<Callout variant="tip">
[https://docs.newrelic.com/docs/new-relic-solutions/get-started/install-with-ai.md](https://docs.newrelic.com/docs/new-relic-solutions/get-started/install-with-ai.md)의 지침에 따라 이 프로젝트에 뉴렐릭을 추가하십시오.
</Callout>

에이전트가 실행된 후 어떤 파일이 변경되었는지 확인하고 데이터가 뉴렐릭에 도달하고 있는지 확인하십시오.

## AI 에이전트를 위한 지침 [#agent-instructions]

뉴렐릭을 설치하는 AI 에이전트인 경우 다음 단계를 따르십시오.

1. **스택 찾기:** `package.json`, `pom.xml`, `build.gradle`, `requirements.txt`, `pyproject.toml`, `go.mod`, `*.csproj`, `composer.json`, `Gemfile`, `Dockerfile`, Kubernetes 매니페스트 또는 Helm 차트와 같은 프로젝트의 파일을 확인하십시오. 스택이 불분명한 경우, 사용자에게 무엇을 모니터할지 물어보십시오.

2. **설치 가이드 선택:** 아래의 [설치 가이드](#install-guides)에서 일치하는 가이드를 선택하십시오. `/docs/` 하위의 URL인 경우 끝에 `.md`을(를) 추가하여 마크다운 버전을 가져오십시오.

3. **컨텍스트에서 라이선스 키 제외:** 키는 기밀 정보입니다. 이 값은 전혀 필요하지 않습니다.

   * 사용자에게 키를 요구하지 마십시오. 채팅에 붙여넣는 경우, 이를 해지하고 새 키를 생성하도록 안내하십시오.
   * `NEW_RELIC_LICENSE_KEY` 이름으로만 키를 참조하십시오. 가이드에서 키를 구성 파일에 넣는 경우, 대신 해당 환경 변수에서 키를 읽으십시오.
   * 키를 표시할 수 있는 명령을 실행하거나 `env`, `printenv`, `echo $NEW_RELIC_LICENSE_KEY`, `.env` 파일 또는 시크릿 저장소와 같은 파일을 읽지 마십시오.
   * `test -n "$NEW_RELIC_LICENSE_KEY" && echo set || echo missing`을(를) 실행하여 키를 노출하지 않고 설정되어 있는지 확인하십시오.

4. **가이드를 따르십시오:**

   * 사용자에게 앱 이름을 요청하거나 프로젝트 이름을 기반으로 앱 이름을 제안하십시오.
   * 사용자의 계정이 EU 또는 JP [데이터센터 리전](/docs/accounts/accounts-billing/account-setup/choose-your-data-center)에 있는 경우, 가이드에서 해당 리전에 대해 제공하는 엔드포인트를 사용하십시오.

5. **확인:** 사용자에게 `NEW_RELIC_LICENSE_KEY`을(를) 설정하고 앱을 다시 시작하도록 요청한 다음, [설치 확인](#verify)을 따르십시오. 데이터가 표시되지 않으면 해당 기술에 대해 나열된 문제 진단, 해결 페이지를 참조하십시오.

6. **요약:** 사용자에게 변경한 파일과 뉴렐릭에서 앱을 찾을 수 있는 위치를 알려주십시오. 앱의 경우 <DNT>**APM &amp; Services**</DNT>, 프런트엔드의 경우 <DNT>**Browser**</DNT> 또는 <DNT>**Mobile**</DNT>, 호스트의 경우 <DNT>**Infrastructure**</DNT> 입니다.

## 설치 확인 [#verify]

두 단계로 확인하십시오. 먼저 에이전트가 실행 중인지 확인하고, 그 다음 데이터가 뉴렐릭에 도달했는지 확인하십시오.

### 데이터가 뉴렐릭에 도달했는지 확인 [#check-data]

설치한 기술에 대한 쿼리를 실행하고, 각 플레이스홀더를 구성한 값으로 대체하십시오. 데이터가 표시되는 데 몇 분 정도 걸릴 수 있으며, 일부 쿼리는 앱이 트래픽을 처리한 후에만 결과를 반환합니다.

개수가 0보다 크면 데이터가 흐르고 있음을 의미합니다. 쿼리를 실행하는 방법에는 두 가지가 있으며, 어느 것도 시크릿을 노출하지 않습니다:

* **사용자에게** 뉴렐릭의 [쿼리 빌더](/docs/query-your-data/explore-query-data/query-builder/introduction-query-builder)에 붙여넣고 결과를 알려달라고 요청하십시오.
* 사용자가 이를 설치하고 <InlinePopover type="userKey" />을(를) `NEW_RELIC_API_KEY` 환경 변수로 설정한 경우 **[뉴렐릭 CLI](https://github.com/newrelic/newrelic-cli)를 사용하십시오**. `newrelic nrql query --accountId ACCOUNT_ID --query 'QUERY'`을(를) 실행합니다. 사용자 API 키도 기밀이므로 라이선스 키와 동일한 방식으로 처리하십시오.
