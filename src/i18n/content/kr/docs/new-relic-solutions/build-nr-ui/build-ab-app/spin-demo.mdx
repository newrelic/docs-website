<Callout variant="tip">
이 강의는 처음부터 New Relic 제작 방법을 가르치는 과정의 일부입니다. 아직 확인하지 않았다면 개요를 확인하세요.
</Callout>

New Relic 피규어를 구축하기 전에 데모 서비스를 시작해야 합니다. 이 교과 과정은 두 가지 중요한 서비스에 따라 달라집니다.

* 뉴스레터 가입 양식을 보여주는 웹 서비스입니다. 어떤 텍스트가 더 높은 품질의 구독으로 이어지는지 결정하기 위해 A/B 테스트를 수행하고 있기 때문에 양식의 제목 텍스트가 두 버전 간에 번갈아 표시됩니다.
* 수동으로 데이터를 생성할 필요가 없도록 웹사이트에 꾸준한 트래픽을 보내는 시뮬레이터 서비스

데모 서비스를 실행하려면 먼저 [Docker](https://docs.docker.com/get-docker/) 및 [Docker compose를](https://docs.docker.com/compose/install/) 설치해야 합니다.

## 데모 서비스를 강화하세요 [#spin]

<Steps>
<Step>
GitHub에서 [교과 과정 저장소를](https://github.com/newrelic-experimental/nru-programmability-course) 복제합니다.

```sh
git clone https://github.com/newrelic-experimental/nru-programmability-course
```

이 글에는 NodeJS New Relic 자동화를 생성하기 위한 코드가 포함되어 있습니다. 또한 코스의 각 강의에 대한 앱 코드 디렉터리도 포함되어 있습니다. 이 디렉토리를 사용하여 강좌 내용을 따라가게 됩니다.
</Step>

<Step>
`ab-test-app` 이라는 데모 디렉토리로 변경합니다.

```sh
cd nru-programmability-course/ab-test-app
```

이 디렉토리에는 데모 사용을 위한 설정 파일과 README가 포함되어 있습니다.
</Step>

<Step>
`docker-compose` 사용하여 웹 서비스 및 시뮬레이터 컨테이너를 빌드하고 실행합니다.

```sh
NEW_RELIC_LICENSE_KEY=YOUR_NEW_RELIC_LICENSE_KEY docker-compose up -d
```

<Callout variant="important">
`YOUR_NEW_RELIC_LICENSE_KEY` 실제 [인스턴스 키로](/docs/accounts/accounts-billing/account-setup/new-relic-license-key/) 바꿔야 합니다.
</Callout>

완료되면 `localhost:3001` 에서 웹사이트를 확인하세요.
</Step>

<Step>
[New Relic](https://one.newrelic.com) 방문하여 상단 탐색 메뉴에서 **APM** 으로 이동하세요. 계측된 서비스 목록에서 **Newsletter** \[뉴스레터를] 선택합니다.

New Relic이 데모 서비스로부터 데이터를 받을 때까지 1-2분 정도 기다려야 할 수도 있습니다. 준비가 되면 성능, 처리량, Apdex 점수와 같은 트랜잭션 데이터가 표시됩니다.
</Step>

<Step>
데모 서비스를 종료하려면 `ab-test-app` 디렉터리에서 `docker-compose down` 실행하세요.

```sh
docker-compose down
```
</Step>
</Steps>

이제 New Relic을 구축할 준비가 되었습니다!
