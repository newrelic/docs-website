<Callout variant="tip">
이 강의는 처음부터 New Relic 제작 방법을 가르치는 과정의 일부입니다.

과정의 각 단원은 마지막 단원을 기반으로 하므로 이 단원을 시작하기 전에 마지막 단원인 원형 차트 추가를 완료했는지 확인하세요.
</Callout>

이 과정의 각 실습 수업에서는 A/B 테스트 애플리케이션에 새로운 내용을 추가했습니다. 새로운 실행 프로그램을 실행하고 Nerdlet에 여러 차트 구성 요소를 추가했습니다. 이 강의에서는 구독 고객과 구독 취소 고객의 비율 등 웹사이트의 각 버전에 대한 정보를 표시하는 두 개의 새로운 `TableChart` 구성요소를 만듭니다.

<Steps>
<Step>
[교과 과정 저장소](https://github.com/newrelic-experimental/nru-programmability-course) 의 `add-tables/ab-test` 디렉터리로 변경합니다.

```sh
cd nru-programmability-course/add-tables/ab-test
```

이 디렉토리에는 과정의 이 시점에서 귀하의 애플리케이션이 가질 것으로 예상되는 코드가 포함되어 있습니다. 각 레슨을 시작할 때 올바른 디렉토리로 이동하면 사용자 정의 코드를 남겨두어 한 레슨에서 다음 레슨으로 잘못된 코드가 전달되는 것을 방지할 수 있습니다.
</Step>

<Step>
`nerdlets/ab-test-nerdlet` 에서 `totals.js` 이라는 새 자바스크립트 파일을 추가합니다.

```sh
touch totals.js
```
</Step>

<Step>
이 새 파일에서 첫 번째 `TableChart` 및 일부 모의 데이터를 보관할 `VersionTotals` 라는 구성요소를 만듭니다.

```jsx fileName=nerdlets/ab-test-nerdlet/totals.js
import React from "react";
import { TableChart } from "nr1";

export default class VersionTotals extends React.Component {
constructor(props) {
  super(props);
}

render() {
  const versionATotals = {
    metadata: {
      id: `totals-${this.props.version}`,
      name: `Version ${this.props.version}`,
      columns: ["name", "count"],
    },
    data: [
      {
        name: "Subscriptions",
        count: 0,
      },
      {
        name: "Page views",
        count: 0,
      },
    ],
  };
  return <TableChart data={[versionATotals]} fullWidth />;
}
}
```

`TableChart` 세 가지 측면에서 `PieChart` 및 `LineChart` 과 다릅니다. 우선, 해당 시리즈에는 `color` 또는 `viz` 메타데이터 속성이 없습니다. `TableChart` 에는 표준 시각화가 있으므로 적용되지 않는 `color` 와 같은 항목을 무시합니다. 둘째, `TableChart` 시리즈에는 `columns` 메타데이터 속성이 있습니다. `columns` 테이블의 열 이름을 결정합니다. 마지막으로, `TableChart` 계열 데이터는 x 값과 y 값을 사용하지 않습니다. 대신 테이블 열과 일치하는 키와 행에 들어갈 내용을 결정하는 값을 사용합니다.

`VersionTotals` 는 `version` 속성을 가져와 차트 메타데이터의 `id` 및 `name` 필드에 제공합니다. 이를 통해 동일한 구성 요소를 사용하여 버전 A와 B에 대한 테이블을 만들고 중복 코드를 제거할 수 있습니다.
</Step>

<Step>
Nerdlet의 `index.js` 파일에서 새 구성요소를 가져오고 Nerdlet의 `render()` 메서드를 업데이트합니다.

```jsx fileName=nerdlets/ab-test-nerdlet/index.js lineHighlight=5,13-14
import React from 'react';
import NewsletterSignups from './newsletter-signups';
import TotalCancellations from './total-cancellations';
import TotalSubscriptions from './total-subscriptions';
import VersionTotals from './totals';

export default class AbTestNerdletNerdlet extends React.Component {
  render() {
    return <div>
      <NewsletterSignups />
      <TotalSubscriptions />
      <TotalCancellations />
      <VersionTotals version='a' />
      <VersionTotals version='b' />
    </div>
  }
}
```
</Step>

<Step>
`nru-programmability-course/add-tables/ab-test` 에서 Nerdpack의 루트로 이동합니다.
</Step>

<Step>
Nerdpack에 대한 새 UUID를 생성하십시오.

```sh
nr1 nerdpack:uuid -gf
```

기존 Nerdpack이 포함된 교과 과정 저장소를 복제했으므로 고유한 식별자를 생성해야 합니다. 이 UUID는 Nerdpack을 New Relic 계정에 매핑합니다.
</Step>

<Step>
애플리케이션을 로컬로 제공합니다.

```sh
nr1 nerdpack:serve
```
</Step>

<Step>
[New Relic](https://one.newrelic.com?nerdpacks=local) 에서 변경사항을 확인하세요.

여기에서는 애플리케이션에 표시된 `TableChart` 구성요소를 볼 수 있습니다.

작업이 끝나면 로컬 서버의 터미널 창에서 `CTRL+C` 눌러 New Relic 피규어 제공을 중지하세요.
</Step>
</Steps>

<Callout variant="tip">
설계 가이드에는 지난 테스트를 기록하는 테이블이 하나 더 있습니다. 이 테이블의 열은 다음과 같습니다.

* **End Date** \[종료 날짜]: 테스트 종료 날짜
* **Version A Description** \[버전 A 설명]: 버전 A에 대한 설명입니다.
* **Version B Description** \[버전 B 설명]: 버전 B에 대한 설명입니다.
* **Winner** \[우승자]: 최종 디자인으로 선정된 버전

코드 샘플을 보지 않고 이러한 열 이름과 일부 가짜 데이터를 사용하여 애플리케이션에서 이 테이블을 구축해 보세요. 이 연습을 통해 이번 단원에서 배운 내용을 더욱 강화할 수 있습니다.

도움이 필요하면 이 과정의 다음 강의에 해당하는 [교과 과정 저장소](https://github.com/newrelic-experimental/nru-programmability-course) 의 `add-a-chart-group` 디렉토리를 검토하세요. 여기에는 `PastTests` 구성요소에 대한 코드가 있습니다.
</Callout>

이 과정 전체에서 애플리케이션에 추가할 각 차트는 해당 유형이나 표시되는 데이터가 고유합니다. 지금까지 테이블, 원형 차트, 꺾은선형 차트를 만들었으며 모두 서로 독립적으로 작동합니다. 다음 단원에서는 선 차트를 몇 개 더 만들지만 이번에는 함께 작동하게 됩니다.
