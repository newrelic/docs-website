Amazon Fire TV 애플리케이션에서 Dash.js 비디오 재생을 모니터링하려면 뉴렐릭 `VegaTracker`을(를) 설치하십시오.

## 시작하기 전에 [#before-begin]

먼저 [일반적인 설치 단계](/docs/streaming-video-&-ads/installation/amazon-fire-tv/get-started-with-amazon-fire-tv#install)를 완료하여 애플리케이션을 생성하고 모바일 애플리케이션 토큰을 가져오십시오.

## 트래커 설치 [#install]

<Steps>
  <Step>
    ### Dash.js 패키지를 설치하십시오.

    ```shell
    npm install @newrelic/video-dash --save
    ```
  </Step>

  <Step>
    ### 디바이스 정보 설치

    이 단계는 선택 사항입니다. 디바이스 정보 라이브러리는 비디오 이벤트에서 실제 디바이스 속성 — 모델, OS 버전 및 UUID — 을 제공합니다. 이 라이브러리가 없으면 이벤트는 `deviceModel` 및 `deviceUuid`에 플레이스홀더 값을 사용합니다.

    ```shell
    npm install @amazon-devices/react-native-device-info --save
    ```
  </Step>

  <Step>
    ### VegaTracker를 초기화합니다.

    `onSurfaceViewCreated` 콜백 내에서 `VegaTracker`을(를) 초기화합니다. 이는 초기화 전에 플레이어의 비동기 연결이 완료되도록 보장합니다.

    Dash.js 플레이어 인스턴스와 `info` 객체를 전달하십시오. `info` 객체에는 계정 ID, 애플리케이션 토큰 및 엔드포인트가 포함되어야 합니다. 기기 정보 라이브러리를 설치한 경우, 기기 속성도 `info.deviceInfo`(으)로 전달하십시오.

    재생이 끝나면 `tracker.dispose()`을(를) 호출하여 리소스를 해제하십시오.

    초기화 예제는 [뉴렐릭 안내 설치](/docs/streaming-video-&-ads/installation/amazon-fire-tv/get-started-with-amazon-fire-tv#install)의 코드 스니펫을 사용하십시오.
  </Step>

  <Step>
    ### 데이터 보기

    애플리케이션을 배포하고 비디오를 재생하십시오. <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Streaming Video &amp; Ads**</DNT> (으)로 이동하여 애플리케이션에 데이터가 흐르고 있는지 확인하십시오.
  </Step>
</Steps>
