## 지원되는 트리거 및 분산 추적

<CollapserGroup>
  <Collapser id="node" title="NodeJS의 경우">
    다음 트리거 유형을 모니터링할 수 있습니다.

    * Http 트리거
    * 응답 스트리밍을 위한 HTTPTrigger
    * 타이머 트리거
  </Collapser>

  <Collapser id="python" title="파이썬의 경우">
    다음 트리거 유형을 모니터링할 수 있습니다.

    * Http 트리거
  </Collapser>

  <Collapser id=".net" title=".NET의 경우">
    모든 트리거 유형을 계측할 수 있습니다. 분산 추적은 다음 경우에 지원됩니다:

    * 격리된 작업자 모델:
      * Http 트리거
        * 에이전트는 인바운드 HTTP 요청에서 분산 트레이스 헤더를 읽습니다.

    * 인프로세스 모델(.NET 에이전트 버전 10.39.0 이상):

      * Http 트리거
        * 함수 메서드에 `Microsoft.AspNetCore.Http.DefaultHttpRequest`, `Microsoft.AspNetCore.Http.HttpRequest` 또는 `System.Net.Http.HttpRequestMessage` 유형의 파라미터가 있는 경우 에이전트는 분산 트레이스 헤더를 읽습니다.

      * ServiceBusTrigger

        * 에이전트는 수신된 메시지의 `ApplicationProperties` 컬렉션에서 인바운드 분산 트레이스 헤더를 읽습니다.
        * 에이전트는 아웃바운드 Service Bus 메시지의 `ApplicationProperties` 컬렉션에 분산 트레이스 헤더를 삽입합니다.
        * Service Bus 분산 추적에는 `Azure.Messaging.ServiceBus` 라이브러리가 필요합니다. 이전 `Microsoft.Azure.ServiceBus` 라이브러리를 사용하는 앱은 지원되지 않습니다.
  </Collapser>
</CollapserGroup>
