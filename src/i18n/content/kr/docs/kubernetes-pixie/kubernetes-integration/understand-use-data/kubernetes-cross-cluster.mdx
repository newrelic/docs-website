최신 Kubernetes 환경은 복잡한 **다중 클러스터 플릿** 으로 발전했지만 기존의 옵저버빌리티 도구는 개별 클러스터에 대해 분리되고 사일로화된 보기만 제공하는 경우가 많습니다. 이 Kubernetes 크로스 클러스터 UI는 다중 클러스터의 복잡성을 전체 클러스터에 걸쳐 명확하게 파악할 수 있도록 통합된 명령 센터를 제공합니다.

이러한 통합된 관점은 플랫폼 엔지니어와 SRE에게 다음과 같은 도움을 줍니다.

* 뉴렐릭 에이전트 또는 OpenTelemetry 통해 클러스터 모니터와 호환되는 단일 대시보드에 **전체 옵저버빌리티를 통합합니다**.
* 가이드형 분류를 통해 **근본 원인 분석을 가속화하세요**.
* 전체 항공기단에서 낭비되는 자원을 파악하여 **비용을 절감하십시오**.
* **개발자에게 애플리케이션 중심적인 관점을 제공하여 셀프 서비스를 지원합니다**.

## 새로운 UI에 접속하세요 [#access]

뉴렐릭 플랫폼의 왼쪽 탐색에 있는 Kubernetes 옵션에서 새로운 Kubernetes 크로스 클러스터 UI 액세스할 수 있습니다.

Kubernetes 클러스터 간 UI에 액세스하려면 다음 단계를 따르세요.

1. 이동 <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Kubernetes**</DNT>
2. 페이지 오른쪽 상단에 있는 **Try it out** \[직접 사용해 보기] 버튼을 클릭하세요.

## 스코어카드 및 테이블 [#scorecards]

스코어카드는 전체 플릿의 각 메트릭을 요약하며, 분류 테이블은 클러스터, 노드 또는 워크로드별로 값을 분류합니다. 값이 [심각도 임계값](#tab)을 충족하면 스코어카드와 테이블 행이 모두 주황색(경고) 또는 빨간색(위험)으로 바뀝니다. `2/436`과(와) 같은 비율은 백분율에 따라 색상이 변경됩니다.

* 스코어카드와 꺾은선형 차트를 업데이트하려면 **`avg`**, **`p95`**, **`p99`** 또는 **`max`**을(를) 선택하십시오. 분류 테이블은 항상 평균값을 표시합니다.
* **Include healthy entities** \[정상 엔티티 포함]을 비활성화하여 활성 주황색 또는 빨간색 상태 임계값이 있는 엔티티로 목록을 필터링하십시오.
* 보고를 중단한 엔티티는 목록에 유지되며, 선택한 시간 범위에 대한 이력 데이터를 표시합니다.

## 환자 분류를 위한 상세 분석 기능 [#drill-down]

전체 플릿 메트릭에서 개별 엔티티로 이동하는 안내식 심사 워크플로우를 사용하여 교차 클러스터 UI를 통해 근본 원인 분석을 가속화할 수 있습니다:

* **스코어카드에서 엔티티 순위로:** 스코어카드를 선택하여 해당 메트릭을 기준으로 테이블을 심각도 내림차순으로 정렬하고 꺾은선형 차트에 상위 10개 엔티티를 표시하십시오.
* **테이블 메트릭에서 Kubernetes 내비게이터로:** 메트릭 값 위로 마우스 포인터를 올려 엔티티 추세선을 표시한 다음, <DNT>**View in navigator**</DNT>을(를) 선택하여 [Kubernetes 내비게이터](/docs/kubernetes-pixie/kubernetes-integration/understand-use-data/kubernetes-cluster-explorer/#navigator-preview)를 여십시오.
* **엔티티에서 세부 정보로:** 엔티티 이름 위에 마우스를 올려 골든 메트릭 및 관련 엔티티를 확인하거나, 클릭하여 개요 페이지를 여십시오.
