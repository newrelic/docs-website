최신 Kubernetes 환경은 복잡한 **다중 클러스터 플릿**으로 발전했지만, 기존 옵저버빌리티 도구는 종종 개별 클러스터의 단편적이고 사일로화된 뷰만 제공합니다. 뉴렐릭의 Kubernetes 모니터링은 이러한 복잡성을 명확성으로 바꿔주는 플릿 전체 뷰에서 열립니다.

이 통합 뷰는 플랫폼 엔지니어와 SRE가 다음을 수행하도록 지원합니다:

* 뉴렐릭 에이전트 또는 OpenTelemetry 통해 클러스터 모니터와 호환되는 단일 대시보드에 **전체 옵저버빌리티를 통합합니다**.
* 가이드형 분류를 통해 **근본 원인 분석을 가속화하세요**.
* 전체 항공기단에서 낭비되는 자원을 파악하여 **비용을 절감하십시오**.
* **개발자에게 애플리케이션 중심적인 관점을 제공하여 셀프 서비스를 지원합니다**.

이동 <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Kubernetes**</DNT>

## UI의 주요 구성 요소 [#components]

UI는 전체 Kubernetes 플릿에 대한 높은 수준의 개요와 심층적인 분석 기능을 모두 제공하도록 구성되어 있습니다. 주요 구성 요소는 다음과 같습니다:

* **엔티티 필터**: **클러스터 또는 노드 수준** 에서 **태그와 값을** 사용하여 문제를 필터링하고 분류합니다.
  * **Cluster 필터**: UI 를 단일 또는 더 작은 쿠버네티스 클러스터 세트로 분리하는 필터입니다.

* **색상별 성과표**: 전체 함대에서 주의가 필요한 가장 중요한 문제를 파악하기 위해 관련성이 높은 수준의 지표를 표시합니다.

  * scorecard \[스코어카드]를 클릭하여 해당 메트릭의 컨텍스트에서 **테이블을 정렬** 하고, 가장 심각한 문제가 있는 클러스터 및 노드를 맨 위에 표시하십시오.
  * 또한 선택한 시간 범위에 걸쳐 변화 추이를 **선 그래프** 로 시각화할 수 있습니다.
  * 스코어카드와 선형 차트를 업데이트하려면 <DNT>**`avg`**</DNT>, <DNT>**`p95`**</DNT>, <DNT>**`p99`**</DNT> 또는 <DNT>**`max`**</DNT>을(를) 선택해 주십시오. 분류 테이블은 항상 평균값을 표시합니다.

* **선 그래프**: 선택한 기간 동안 **의 변화 추이를** 보여주어 추세 분석에 활용할 수 있습니다.

* **Table** \[테이블]: 플릿의 모든 엔티티를 나열하고 5개의 기본 [tabs \[탭\] 아래에](#tab) **각 클러스터에 대한 상세 메트릭 데이터** 를 제공합니다.

  * **건강 집중**: 이 표는 &quot;건강에 좋지 않은&quot; 항목만 나열하는 필터를 제공하여 정말 필요한 부분에 집중할 수 있도록 도와줍니다.
  * **검색**: 텍스트 검색창을 사용하면 입력한 **텍스트를** 기준으로 테이블 행을 필터링할 수 있습니다.
  * **Color-coding \[색상 코딩]**: 스코어카드와 마찬가지로 테이블 셀은 특정 [심각도 임계값](#tab)을 충족하는 문제가 있는 엔티티에 신속하게 주의를 끌 수 있도록 색상(Yellow \[노란색], Red \[빨간색])으로 구분됩니다.
  * **Column chooser \[열 선택기]**: Workloads \[워크로드] 탭은 간결한 기본 열 세트를 제공하며 열을 추가하거나 제거할 수 있습니다. 열 선택 항목은 세션 간에 유지됩니다.

* **Workload type selector\[워크로드 유형 선택기]**: Workloads\[워크로드] 탭을 구현, 배포, DaemonSets 또는 StatefulSets와 같은 특정 워크로드 유형으로 좁힙니다.

* **피드백 버튼**: 사용자 UI 사용 경험에 대한 피드백을 간편하게 공유할 수 있습니다.

## 다중 계정 플릿 가시성 [#multi-account]

액세스할 수 있는 뉴렐릭 계정의 클러스터가 동일한 플릿 뷰에 함께 표시되므로 여러 계정에 걸쳐 있는 플릿을 모니터링할 때 계정 컨텍스트를 전환할 필요가 없습니다.

둘 이상의 계정에서 클러스터를 보려면 다음을 수행하십시오:

1. account picker \[계정 선택기]에서 <DNT>**All accounts**</DNT>을(를) 선택하십시오.
2. entity filter bar \[엔티티 필터 표시줄]의 account filter \[계정 필터]를 사용하여 필요한 특정 계정으로 뷰를 좁히십시오.

## Entity \[엔티티] 팝오버 [#popover]

테이블에서 엔티티를 선택하면 플릿 뷰를 벗어나지 않고도 해당 엔티티에 대한 컨텍스트를 제공하는 팝오버가 열립니다:

* **Golden metrics\[골든 메트릭]**, 엔티티의 주요 성능 메트릭에 대한 스냅샷입니다.
* 유형별로 그룹화되고 정렬된 **Related entities \[관련 엔티티]**로, 현재 컨텍스트와 함께 누적 뷰에서 열 수 있습니다.
* **Links to related applications \[관련 애플리케이션에 대한 링크]**로, 누적 뷰가 아닌 APM 환경을 여는 외부 링크 아이콘으로 표시됩니다.
* **Object description\[오브젝트 설명]**, 선택한 Kubernetes 오브젝트의 매니페스트를 엽니다.
* **Team** \[팀], 엔티티에 설정된 경우입니다.
* **Dashboard\[대시보드]**, 해당 엔티티의 대시보드로 연결되는 링크입니다.

## APM, 이벤트, 로그 및 알림과 상관관계 분석 [#correlate]

fleet view\[플릿 뷰]는 신호를 상호 연관시키고 MTTR을 단축하기 위해 화면을 벗어날 필요가 없도록 설계되었습니다:

* **APM insights \[APM 인사이트]**: Workloads \[워크로드] 뷰는 워크로드에서 실행 중인 애플리케이션에 대한 애플리케이션 성능 데이터를 표시하므로, 한 곳에서 인프라 상태와 애플리케이션 성능 간에 이동할 수 있습니다.
* **Alerts\[알림]**: 열린 알림은 Workloads\[워크로드] 탭의 공지 표시기를 포함하여 클러스터, 노드 및 워크로드에 표시되며, 즉각적인 컨텍스트 확인을 위해 스택 뷰로 열립니다. 선택한 시간 범위와 관계없이 열린 알림이 표시되므로 좁은 타임 피커에 의해 활성 공지가 절대 숨겨지지 않습니다.
* **Events and logs \[이벤트 및 로그]**: 엔티티에 대한 Kubernetes 이벤트 및 로그가 현재 컨텍스트와 함께 누적된 뷰로 열리므로, 분류 흐름에서 현재 위치를 잃지 않고 신호를 상호 연관시킬 수 있습니다.
