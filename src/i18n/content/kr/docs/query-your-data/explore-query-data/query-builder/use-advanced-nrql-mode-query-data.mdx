      </td>

      </td>

      <td>
        NRQL 쿼리에서 이벤트 유형별로 여러 속성을 사용할 수 있습니다.
      </td>
    </tr>

    <tr>
      <td>
        이전 쿼리 보기
      </td>

      <td>
        NRQL 쿼리를 실행한 후, <DNT>**My recent queries**</DNT> 드롭다운 메뉴를 사용하여 실행한 최근 1,000개의 쿼리를 확인하십시오. 드롭다운 메뉴에는 쿼리를 찾는 데 도움이 되는 검색 창이 있습니다.
      </td>
    </tr>

    <tr>
      <td>
        자동 완성
      </td>

      <td>
        쿼리 작성기의 자동 완성기는 지난 60분 이내에 보고된 이벤트와 속성을 표시합니다. 예를 들어 매일 아침 6시에 시작하는 표준 시스템 상태 확인과 같이 하루에 한 번 실행되는 프로세스가 있습니다. 오전 7시 5분에 이벤트를 쿼리하려고 하면 이벤트 및 후속 속성이 자동 완성 드롭다운에 표시되지 않습니다.

        이러한 이벤트 및 속성은 정확한 문자열을 입력하여 계속 쿼리할 수 있습니다.
      </td>
    </tr>

    <tr>
      <td>
        다중 쿼리
      </td>

      <td>
        [`TIMESERIES`](/docs/query-data/nrql-new-relic-query-language/getting-started/nrql-syntax-clauses-functions#sel-timeseries) 절을 사용하면 다른 계정에서 최대 10개의 쿼리를 실행하고 비교할 수 있습니다.

        다중 쿼리를 사용하려면 `TIMESERIES`에 첫 번째 쿼리를 입력하고 실행하십시오. 결과가 렌더링되면 <DNT>**Add another query**</DNT> 버튼이 활성화되어 다른 쿼리를 추가할 수 있습니다.
      </td>
    </tr>

    <tr>
      <td>
        계정 간 쿼리
      </td>

      <td>
        계정 드롭다운 메뉴에서 쿼리를 실행할 계정을 선택할 수 있습니다:

        * 기본적으로 드롭다운 메뉴 목록에서 단일 계정을 선택하십시오.
        * 여러 계정에 걸쳐 쿼리하려면 드롭다운 메뉴에서 <DNT>**Multi-account (up to 30)**</DNT> 스위치를 켠 다음, 쿼리에 포함할 계정을 최대 30개까지 선택하십시오.
      </td>
    </tr>
