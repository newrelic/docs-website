<DNT>Autopilot</DNT> 메모리를 사용하면 <DNT>Autopilot</DNT> 이(가) 대화 전반에 걸쳐 컨텍스트를 유지하고 저장된 컨텍스트를 읽고, 생성하고, 업데이트하거나 삭제할 수 있는 사람을 제어할 수 있습니다.

## NerdGraph API를 통해 사용자 지정 역할 생성 [#create-role]

다음의 각 API 호출은 메모리에 대한 사용자 지정 역할을 생성하고 할당하는 작업의 한 부분을 처리합니다. 입력 파라미터와 샘플 요청 및 응답을 확인하려면 각각을 확장하세요.

<CollapserGroup>
  <Collapser id="find-permission-ids" title="메모리에 필요한 권한 ID 찾기">
    `customerAdministration` 쿼리를 사용하여 기능 목록, 해당 권한 ID 및 관련 정보를 검색합니다. 기능별로 필터링하여 메모리 권한을 가져옵니다.

    **입력스피커, 변수**

    <table>
      <thead>
        <tr>
          <th>
            매개변수
          </th>

          <th>
            데이터 형식
          </th>

          <th>
            설명
          </th>
        </tr>
      </thead>

      <tbody>
        <tr>
          <td>
            `eq`

             (필수의)
          </td>

          <td>
            문자열
          </td>

          <td>
            일치하는 권한을 검색하려면 값을 

            `Memory`

             (계정 범위) 또는 

            `Memory For Organization`

             (조직 범위)로 설정합니다.
          </td>
        </tr>
      </tbody>
    </table>

    **샘플 요청 ― 계정 범위**

    ```graphql
    {
      customerAdministration {
        permissions(filter: { feature: { eq: "Memory" } }) {
          items {
            feature
            category
            id
            product
          }
        }
      }
    }
    ```

    **샘플 응답**

    ```json
    {
      "data": {
        "customerAdministration": {
          "permissions": {
            "items": [
              {
                "category": "READ",
                "feature": "Memory",
                "id": "xxxxx",
                "product": "New Relic AI"
              },
              {
                "category": "MODIFY",
                "feature": "Memory",
                "id": "xxxxxx",
                "product": "New Relic AI"
              },
              {
                "category": "DELETE",
                "feature": "Memory",
                "id": "xxxxxx",
                "product": "New Relic AI"
              }
            ]
          }
        }
      }
    }
    ```

    조직 범위 권한 ID(조직용 메모리에 대한 READ, MODIFY, DELETE)를 검색하려면 `feature: { eq: "Memory For Organization" }` 을(를) 사용하여 동일한 쿼리를 실행합니다.

    응답에서 부여하려는 액세스 수준과 일치하는 `feature` 이(가) `Memory` 또는 `Memory For Organization`인 권한 ID를 복사합니다. 사용자 지정 역할을 생성하려면 이 ID가 필요합니다.
  </Collapser>

  <Collapser id="retrieve-organization-id" title="귀하의 조직 ID를 검색하세요">
    이후 뮤테이션에서 사용할 조직 ID를 검색합니다. 계정 범위 역할의 경우 계정 ID도 검색합니다.

    **샘플 요청**

    ```graphql
    {
      actor {
        organization {
          id
        }
        accounts {
          id
          name
        }
      }
    }
    ```

    **샘플 응답**

    ```json
    {
      "data": {
        "actor": {
          "organization": {
            "id": "YOUR_ORGANIZATION_ID"
          },
          "accounts": [
            {
              "id": "YOUR_ACCOUNT_ID",
              "name": "Your Account Name"
            }
          ]
        }
      }
    }
    ```

    응답에서 필요한 ID를 복사합니다. 사용자 지정 역할을 생성하는 데 사용합니다.
  </Collapser>

  <Collapser id="create-custom-role" title="사용자 지정 역할을 생성합니다">
    `customRoleCreate` 뮤테이션을 사용하여 메모리 관리를 위한 사용자 정의 역할을 생성합니다.

    **입력스피커, 변수**

    <table>
      <thead>
        <tr>
          <th>
            매개변수
          </th>

          <th>
            데이터 형식
          </th>

          <th>
            설명
          </th>
        </tr>
      </thead>

      <tbody>
        <tr>
          <td>
            `id`

             (필수의)
          </td>

          <td>
            문자열
          </td>

          <td>
            이전 호출의 조직 ID(조직 범위) 또는 계정 ID(계정 범위)입니다.
          </td>
        </tr>

        <tr>
          <td>
            `type`

             (필수의)
          </td>

          <td>
            문자열
          </td>

          <td>
            조직 범위 역할의 경우 

            `organization`

             (으)로 설정하고, 계정 범위 역할의 경우 

            `account`

             (으)로 설정합니다.
          </td>
        </tr>

        <tr>
          <td>
            `name`

             (필수의)
          </td>

          <td>
            문자열
          </td>

          <td>
            사용자 지정 역할의 표시 이름입니다.
          </td>
        </tr>

        <tr>
          <td>
            `permissionIds`

             (필수의)
          </td>

          <td>
            정수 배열
          </td>

          <td>
            위에서 식별된 메모리 권한 ID입니다.
          </td>
        </tr>

        <tr>
          <td>
            `scope`

             (필수의)
          </td>

          <td>
            문자열
          </td>

          <td>
            `type`

            에 맞춰 

            `organization`

             또는 

            `account`

            로 설정합니다.
          </td>
        </tr>
      </tbody>
    </table>

    **샘플 요청 ― 계정 범위 역할**

    ```graphql
    mutation {
      customRoleCreate(
        container: { id: "YOUR_ACCOUNT_ID", type: "account" }
        name: "Memory manager"
        permissionIds: [xxxxx, xxxxx]
        scope: "account"
      ) {
        id
      }
    }
    ```

    **샘플 요청 ― 조직 범위 역할**

    ```graphql
    mutation {
      customRoleCreate(
        container: { id: "YOUR_ORGANIZATION_ID", type: "organization" }
        name: "Memory manager (org-wide)"
        permissionIds: [xxxxx, xxxxx]
        scope: "organization"
      ) {
        id
      }
    }
    ```

    **샘플 응답**

    ```json
    {
      "data": {
        "customRoleCreate": {
          "id": 9999999
        }
      }
    }
    ```

    반환된 역할 ID를 저장합니다 ― 이 역할을 사용자 그룹에 할당하려면 이 ID가 필요합니다.
  </Collapser>

  <Collapser id="add-role-to-group" title="사용자 그룹에 사용자 정의 역할 추가">
    사용자 지정 역할을 생성한 후 사용자 그룹에 할당합니다.

    **그룹 ID 검색**

    `customerAdministration` 쿼리를 사용하여 사용 가능한 사용자 그룹 목록을 가져옵니다.

    **입력스피커, 변수**

    <table>
      <thead>
        <tr>
          <th>
            매개변수
          </th>

          <th>
            데이터 형식
          </th>

          <th>
            설명
          </th>
        </tr>
      </thead>

      <tbody>
        <tr>
          <td>
            `id`

             (필수의)
          </td>

          <td>
            문자열
          </td>

          <td>
            귀하의 조직 ID입니다.
          </td>
        </tr>
      </tbody>
    </table>

    **샘플 요청**

    ```graphql
    {
      customerAdministration {
        groups(filter: { organizationId: { eq: "YOUR_ORGANIZATION_ID" } }) {
          nextCursor
          items {
            id
            name
            users {
              items {
                id
                email
              }
            }
          }
        }
      }
    }
    ```

    응답에서 메모리 역할을 할당하려는 그룹의 그룹 ID를 복사합니다.

    **그룹에 역할을 할당합니다.**

    `authorizationManagementGrantAccess` 변형을 사용하여 사용자 그룹에 사용자 정의 역할을 할당합니다.

    **입력스피커, 변수**

    <table>
      <thead>
        <tr>
          <th>
            매개변수
          </th>

          <th>
            데이터 형식
          </th>

          <th>
            설명
          </th>
        </tr>
      </thead>

      <tbody>
        <tr>
          <td>
            `roleId`

             (필수의)
          </td>

          <td>
            문자열
          </td>

          <td>
            이전 호출의 사용자 정의 역할 ID입니다.
          </td>
        </tr>

        <tr>
          <td>
            `groupId`

             (필수의)
          </td>

          <td>
            문자열
          </td>

          <td>
            위에서 조회한 그룹 ID입니다.
          </td>
        </tr>
      </tbody>
    </table>

    **샘플 요청 ― 계정 범위 역할**

    ```graphql
    mutation {
      authorizationManagementGrantAccess(
        grantAccessOptions: {
          accountAccessGrants: { accountId: "YOUR_ACCOUNT_ID", roleId: "YOUR_ROLE_ID" }
        }
        groupId: "YOUR_GROUP_ID"
      ) {
        roles {
          id
          name
          accountId
          roleId
          groupId
          displayName
        }
      }
    }
    ```

    **샘플 요청 ― 조직 범위 역할**

    ```graphql
    mutation {
      authorizationManagementGrantAccess(
        grantAccessOptions: {
          organizationAccessGrants: { roleId: "YOUR_ROLE_ID" }
        }
        groupId: "YOUR_GROUP_ID"
      ) {
        roles {
          id
          name
          organizationId
          roleId
          groupId
          displayName
        }
      }
    }
    ```

    **샘플 응답**

    ```json
    {
      "data": {
        "authorizationManagementGrantAccess": {
          "roles": [
            {
              "displayName": "Memory manager",
              "groupId": null,
              "id": "99999999",
              "name": "memory_manager",
              "organizationId": "YOUR_ORGANIZATION_ID",
              "roleId": 99999
            }
          ]
        }
      }
    }
    ```
