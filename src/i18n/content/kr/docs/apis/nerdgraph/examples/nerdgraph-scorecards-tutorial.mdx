뉴렐릭을 사용하면 NerdGraph [Scorecards](/docs/service-architecture-intelligence/scorecards/getting-started) GraphQL 변형을 사용하여 Scorecards와 규칙을 관리할 수 있습니다. 이러한 변형을 통해 기존의 스텔라우 및 통합에서 스코어카드와 관련 규칙을 만들고, 업데이트하고, 삭제하고, 검색할 수 있습니다.

이 튜토리얼에서는 NerdGraph를 사용하여 스코어카드와 규칙을 관리하는 방법에 대한 예제를 제공합니다. 이러한 예제를 사용하여 스코어카드 생성, 규칙 추가 및 스코어카드 세부 정보 업데이트와 같은 스코어카드 관리 작업을 자동화할 수 있습니다. 스코어카드 관리를 위한 사용자 지정 권한을 설정해야 하는 경우 [스코어카드용 사용자 지정 역할 생성](/docs/apis/nerdgraph/examples/nerdgraph-scorecards-custom-tutorial)을 참조하십시오.

## 돌연변이 [#mutations]

뉴렐릭은 스코어카드와 관련 규칙을 만들고 관리하기 위한 다양한 NerdGraph 변형을 제공합니다.

또한 스코어카드 규칙을 [성숙도 수준](/docs/service-architecture-intelligence/scorecards/service-maturity) 으로 구성하고 각 규칙에 가중치를 부여할 수 있습니다. API에서 성숙도 수준은 <DNT>**progress levels**</DNT>(이)라고 합니다:

* 스코어카드는 `progressLevels` 필드로 성숙도 수준을 정의합니다. 사용자 지정(기본값이 아닌) 수준 생성은 API를 통해서만 가능하며, [성숙도 수준 생성 또는 업데이트](#maturity-levels)를 참조하십시오.
* 규칙은 `progressLevel` 필드를 사용하여 수준에 할당되며, 이 필드는 스코어카드 진행 수준 중 하나의 `id` 을(를) 취합니다.
* Scorecard의 가중 평균 점수에서 규칙의 가중치는 `impactWeight` 필드로 설정됩니다. 가중치 부여 방식에 대한 자세한 내용은 [가중치 점수](/docs/service-architecture-intelligence/scorecards/service-maturity#weighted-scoring)를 참조하십시오.

  <Collapser id="maturity-levels" title="성숙도 수준 생성 또는 업데이트">
    성숙도 수준은 스코어카드의 `progressLevels`에 의해 정의됩니다. [스코어카드를 생성](#create-scorecard)할 때 설정하거나 나중에 `entityManagementUpdateScorecard` 뮤테이션을 사용하여 업데이트하십시오.

    UI는 기본 3개만 지원하므로 사용자 지정 수준을 생성(예: 4번째 수준 추가 또는 기본값 이름 변경)하는 유일한 방법은 API를 사용하는 것입니다.

    **기존 스코어카드에 새 성숙도 수준을 추가하려면:**

    1. 현재 수준을 확인하려면 [스코어카드 읽기 쿼리](#fetch-scorecards) 를 실행하십시오.
    2. *전체* `progressLevels` 어레이를 사용하여 `entityManagementUpdateScorecard` 뮤테이션을 호출하십시오. 유지하려는 기존 수준과 새 수준을 포함해야 합니다.

    <Callout variant="important">
      업데이트 뮤테이션은 Scorecard의 전체 레벨 세트를 대체합니다. 어레이에서 제외한 레벨은 영구적으로 삭제됩니다.
    </Callout>

    다음 사항에 유의하십시오:

    * **한도:** 스코어카드는 1-5개의 레벨을 가질 수 있습니다.
    * **계층 구조:** 어레이의 순서는 가장 낮은 성숙도부터 가장 높은 성숙도까지 계층 구조를 설정합니다.

    #### 샘플 요청

    ```graphql
    mutation CreateRule(
      $name: String!
      $description: String
      $query: String!
      $accounts: [Int!]!
      $joinAccounts: [Int!]
      $organizationId: ID!
      $progressLevel: ID
      $impactWeight: Int
      $runInterval: Int
    ) {
      entityManagementCreateScorecardRule(
        scorecardRuleEntity: {
          name: $name
          description: $description
          enabled: true
          progressLevel: $progressLevel
          impactWeight: $impactWeight
          runInterval: $runInterval
          nrqlEngine: {
            accounts: $accounts
            joinAccounts: $joinAccounts
            query: $query
          }
          scope: { id: $organizationId, type: ORGANIZATION }
        }
      ) {
        entity {
          id # RULE Id
        }
      }
    }
    ```

    ```json
    // PARAMETERS
    {
      "name": "APM Services Have Alerts Defined",
      "description": "Check that APM services have alerts associated with them",
      "accounts": [1, 2, 3],
      "query": "SELECT if(latest(alertSeverity) != 'NOT_CONFIGURED', 1, 0) AS 'score' FROM Entity WHERE type = 'APM-APPLICATION' AND tags.nr.team IS NOT NULL AND tags.environment IS NOT NULL FACET id AS 'entityGuid', tags.nr.team AS 'team', tags.environment AS 'environment' LIMIT MAX SINCE 1 day ago",
      "organizationId": "xxxxxxxx-yyyy-0000-aaaa-0123456789qwe",
      "progressLevel": "BASIC",
      "impactWeight": 2,
      "runInterval": 1440
    }
    ```
