<Callout title="시사">
이 기능은 아직 개발 단계에 있지만, 시험적으로 사용해 보시길 권합니다. 이 기능은 현재 [출시 전 정책](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy)에 따라 프리뷰 프로그램의 일부로 제공됩니다.
</Callout>

뉴렐릭에서 [NerdGraph](/docs/apis/nerdgraph/get-started/introduction-new-relic-nerdgraph/) 뮤테이션을 사용하여 [메트릭 정규화 규칙](/docs/new-relic-solutions/new-relic-one/ui-data/metric-normalization-rules)을 관리할 수 있습니다. 이러한 뮤테이션을 활용하여 뉴렐릭 계정에서 직접 이러한 규칙을 생성, 편집, 활성화 및 비활성화할 수 있습니다. 이는 [메트릭 그룹화 문제(MGI)](/docs/new-relic-solutions/solve-common-issues/troubleshooting/metric-grouping-issues)를 해결하기 위한 간소화되고 프로그래밍 방식의 접근 방식을 제공합니다.

메트릭 정규화 규칙은 다음과 같은 목적으로 사용됩니다:

* [메트릭 타임슬라이스 데이터](/docs/data-apis/understand-data/new-relic-data-types/#timeslice-data)를 그룹화하거나 필터링하십시오.
* 높은 카디널리티 메트릭이 뉴렐릭에 수집되기 전에 이름을 바꾸거나, 삭제하거나, 변환하여 관리하십시오.
* 메트릭을 체계적이고 유의미하게 유지하려면 [MGI](/docs/new-relic-solutions/solve-common-issues/troubleshooting/metric-grouping-issues)를 방지하십시오.
* 뉴렐릭에 보고되는 고유 메트릭 이름의 수를 줄입니다.

## 전제 조건 [#prerequisites]

* [뉴렐릭 계정](https://newrelic.com/signup)이 있어야 하며, 해당 계정을 통해 [쿼리 및 변형](/docs/apis/nerdgraph/get-started/introduction-new-relic-nerdgraph)에 포함해야 하는 API 사용자 키에 액세스할 수 있습니다.

* 사용자 유형 및 할당된 역할은 NerdGraph 권한에 영향을 줄 수 있습니다. 자세한 내용은 [액세스에 영향을 미치는 요소](/docs/accounts/accounts-billing/account-structure/factors-affecting-access-features-data#user-permissions) 를 참조하십시오.

<Callout variant="tip">
또한 뉴렐릭 플랫폼을 사용하여 메트릭 정규화 규칙을 생성할 수 있습니다. 자세한 내용은 [메트릭 정규화 규칙](/docs/new-relic-solutions/new-relic-one/ui-data/metric-normalization-rules)을 참조하십시오.
</Callout>

## 메트릭 정규화 규칙 조회 [#nerdgraph-query]

계정과 연결된 모든 메트릭 정규화 규칙을 조회하려면 `metricNormalizationRules` 쿼리를 사용하십시오. 이 쿼리는 상태 및 설정을 포함하여 기존 규칙에 대한 포괄적인 개요를 제공합니다.

## 돌연변이 [#nerdgraph-mutations]

다음 [NerdGraph 뮤테이션](https://docs.newrelic.com/docs/apis/nerdgraph/get-started/introduction-new-relic-nerdgraph/#terminology)을 사용하여 메트릭 정규화 규칙을 관리하십시오:

* `DENY_NEW_METRICS`: `matchExpression`와(과) 일치하는 새로운 메트릭 이름의 생성을 방지하는 동시에, 기존 메트릭 이름은 계속 보고되도록 허용합니다.

```graphql

    mutation {
        metricNormalizationCreateRule(
            accountId: xxxxxx
            rule: {action: REPLACE, applicationGuid: "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxx", enabled: false, evalOrder: 2000, matchExpression: "^WebTransaction/Uri/MGIGenerator_war_exploded/api/MGI/pattern/[a-f0-9]+$", notes: "rules to replace", replacement: "WebTransaction/Uri/MGIGenerator_war_exploded/api/MGI/pattern/{guid}", terminateChain: true}
        ) {
            errors {
                message
                type
            }
            rule {
                action
                applicationGuid
                applicationName
                createdAt
                enabled
                evalOrder
                id
                matchExpression
                notes
                replacement
                terminateChain
            }
        }
    }

```
