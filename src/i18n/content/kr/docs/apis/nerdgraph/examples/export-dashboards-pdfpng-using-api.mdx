NerdGraph `dashboardCreateSnapshotUrl` 및 `dashboardWidgetCreateSnapshotUrl` 뮤테이션을 사용하여 프로그래밍 방식으로 대시보드와 개별 차트를 PDF 또는 PNG 파일로 내보낼 수 있습니다. API는 템플릿 변수 재정의 및 엔티티 필터와 같이 UI에서 사용할 수 없는 옵션을 지원합니다. 또한 [UI를 사용하여 대시보드를 내보낼](/docs/query-your-data/explore-query-data/dashboards/dashboards-charts-import-export-data/#export-dashboards-pdf) 수도 있습니다.

## 대시보드를 PDF 또는 PNG로 내보내기 [#api-dashboard-snapshot]

`dashboardCreateSnapshotUrl` 뮤테이션은 전체 대시보드 페이지에 대한 스냅샷 URL을 생성합니다.

<Callout variant="tip">
`guid` 파라미터에는 대시보드 GUID가 아닌 **페이지** GUID가 필요합니다. 대시보드에는 여러 페이지가 있을 수 있습니다. 페이지 GUID를 찾으려면 `entitySearch` 쿼리를 사용하거나 대시보드 페이지를 열고 <DNT>**...**</DNT> 메뉴에서 <DNT>**Manage JSON**</DNT> 을(를) 선택합니다.

```graphql
{
  actor {
    entitySearch(query: "parentId ='YOUR_DASHBOARD_GUID' AND tags.isDashboardPage = 'true'") {
      results {
        entities {
          guid
          name
        }
      }
    }
  }
}
```
</Callout>

**뮤테이션 스키마:**

```graphql
mutation {
  dashboardCreateSnapshotUrl(
    guid: EntityGuid!
    params: SnapshotUrlInput
  ): String
}

input SnapshotUrlInput {
  timeWindow: SnapshotUrlTimeWindowInput
  display: SnapshotUrlDisplayInput
  variables: [SnapshotUrlVariableInput!]
  filter: String
  format: SnapshotUrlFormat
}

input SnapshotUrlTimeWindowInput {
  beginTime: EpochMilliseconds
  endTime: EpochMilliseconds
  duration: Milliseconds
}

input SnapshotUrlDisplayInput {
  width: Int
  height: Int
}

input SnapshotUrlVariableInput {
  name: String!
  values: [String!]!
}

enum SnapshotUrlFormat {
  PDF
  PNG
}
```

## 차트를 이미지로 내보내기 [#api-widget-snapshot]

`dashboardWidgetCreateSnapshotUrl` 뮤테이션은 단일 차트 위젯의 PDF 또는 PNG 스냅샷에 대한 URL을 생성합니다. 위젯이 대시보드에 있을 필요는 없으며, 인라인으로 정의할 수 있어 프로그래밍 방식으로 차트 스냅샷을 생성하는 데 유용합니다.

**뮤테이션 스키마:**

```graphql
mutation {
  dashboardWidgetCreateSnapshotUrl(
    widget: DeclarativeUiWidget!
    params: DashboardWidgetSnapshotUrlInput
  ): WidgetSnapshotResult
}

type WidgetSnapshotResult {
  url: String!
}
```

`params` 인수는 선택 사항입니다. 이 인수를 사용하여 스냅샷의 출력 형식이나 크기를 변경할 수 있습니다.

`widget` 파라미터는 `DeclarativeUiWidget` 을(를) 허용합니다 — 세 개의 중첩된 계층이 있는 JSON 객체:

```
declarative/widget envelope
└── widget node        ← title and widget-level props
    └── visualization  ← visualization type and configuration
```

```json
{
  "type": "declarative/widget",
  "version": 1,
  "content": {
    "type": "widget",
    "props": {
      "title": "My Chart Title"
    },
    "content": {
      "type": "visualization",
      "id": "viz.line",
      "props": {
        // visualization-specific config (nrqlQueries, colors, thresholds, etc.)
      }
    }
  }
}
```

<Callout variant="tip">
NerdGraph의 구형 `actor.account.nrql.staticChartUrl` 필드는 계속 사용할 수 있지만 임계값, 색상 형식 지정 및 최신 차트 유형과 같은 최신 시각화 기능을 지원하지 않습니다. 앞으로는 `dashboardWidgetCreateSnapshotUrl`이(가) 권장되는 접근 방식입니다.
</Callout>

<Callout variant="important">
`dashboardWidgetCreateSnapshotUrl` 스냅샷 URL은 인증 없이 공개적으로 접근할 수 있으며 3개월 후에 만료됩니다.
</Callout>

## 문제점 해결 [#troubleshooting]

대시보드를 내보내는 동안 다음 오류가 발생하는 경우 수행할 작업은 다음과 같습니다.

* 뉴렐릭 UI에서: <DNT>**We ran into an error while creating the PDF. Please try again**</DNT>

* 뉴렐릭 NerdGraph에서: <DNT>**Operation on dashboard entity failed with guid:YOUR\_GUID with cause: Error 504: upstream request timeout**</DNT>

내보내기가 API 최대 응답 시간을 초과하는 경우 이러한 오류가 발생할 수 있습니다. 대시보드의 위젯이 큰 시간 창을 사용하는지 확인합니다 ― 예를 들어, 한 달 전체의 데이터를 비교하는 경우입니다. 그렇다면 시간 창을 줄여보십시오.

또 다른 가능한 원인은 위젯 수가 많은 대시보드입니다. 사용하지 않는 위젯을 제거하여 오류가 해결되는지 확인하십시오.
