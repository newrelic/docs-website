이 가이드에서는 뉴렐릭 모니터링 for SAP Solutions의 데이터 수집 프로세스를 모니터링하는 방법을 보여줍니다. 여러 방법을 사용하여 데이터 수집이 올바르게 작동하는지 확인할 수 있습니다.

## 전제 조건

* 적절한 트랜잭션 권한이 있는 <DNT>**SAP system**</DNT> 에 대한 액세스
* <DNT>**New Relic Monitoring for SAP Solutions**</DNT> 설치 및 구성됨

## 런타임 상태 및 전송 로그

각 데이터 제공자의 런타임 상태 및 전송 세부 정보를 확인하려면 <DNT>**Data Provider Registry**</DNT> (트랜잭션 `/NEWR/REGISTRY`)을(를) 여십시오. 마지막 실행 시간 및 현재 상태를 보려면 <DNT>**RuntimeStatus**</DNT>을(를) 클릭하십시오. 뉴렐릭으로 전송된 각 레코드의 전송 시간, HTTP 응답 코드 및 전송 상태를 보려면 <DNT>**Transmission Log**</DNT>을(를) 클릭하십시오.

## 작업 상태 및 스풀 확인

1. 트랜잭션 `SM37` 을 사용하여 예약된 작업의 상태를 확인합니다. <DNT>**ABAP Program Name**</DNT> 필드에 `/NEWR/*` 을(를) 입력하고 <DNT>**Execute**</DNT>을(를) 클릭합니다.
2. 실행 기간을 검토하십시오. 비정상적으로 긴 실행 시간은 잠재적인 문제가 있음을 나타냅니다.
3. 중복되는 작업을 확인하고 필요에 따라 일정을 조정하십시오.
4. 작업 세부 정보에서 작업 스풀을 엽니다. 스풀은 각 데이터 제공자에 대한 수집 타임스탬프, 전송 상태 및 결과를 보여줍니다.
5. 작업 번호를 사용하여 스풀 항목을 <DNT>**Data Provider Registry**</DNT>의 전송 로그와 연관시키십시오.

## 애플리케이션 로그 확인

데이터 수집 프로세스는 애플리케이션 로그(트랜잭션 `SLG1`)에 기록됩니다. <DNT>**Application Log Object**</DNT> `/NEWR/DP`를 사용하여 쿼리합니다.

비동기 데이터 공급자(`_COMPLETE` 접미사가 있는 공급자)의 경우 작업 스풀에 해당 레코드가 포함되지 않습니다. 수집 및 전송 세부 정보를 보려면 하위 범주 <DNT>**`/NEWR/DP_AGENT`**</DNT>을(를) 사용하여 애플리케이션 로그를 확인하십시오.

## SAP 데이터 수집 모니터링 대시보드

데이터 수집 지표는 자체 모니터링을 위해 뉴렐릭에도 전송됩니다. 기본 제공되는 <DNT>**SAP Data Collection Monitoring**</DNT> 대시보드를 사용하여 각 데이터 공급자에 대한 데이터 수집 프로세스를 모니터링합니다. 설치 지침은 [모니터링 구성 요소 설치](/docs/sap-solutions/install-and-configure/install-out-of-the-box)를 참조하십시오.
