New Relic Observability for SAP - ABAP Hosted captures SAP telemetry data (Metrics, Events, Logs, and Traces) and sends it to the New Relic platform for analysis and visualization.

## 중앙 모니터링 시스템 vs. 모니터 시스템

SAP systems that provide telemetry data are known as monitored systems. The central monitoring system is where <DNT>**NRM4SAP**</DNT> is installed—it collects, transforms, and transmits telemetry data. Typically, you install <DNT>**NRM4SAP**</DNT> on a single SAP system such as <DNT>**SAP Solution Manager (SolMan)**</DNT>. <DNT>**NRM4SAP**</DNT> has no functional dependencies on SolMan—it serves only as a reference point here. <DNT>**NRM4SAP**</DNT> uses standard SAP data sources like <DNT>**ST-PI**</DNT>, MTE Classes (components within <DNT>**CCMS**</DNT>), and performance data from <DNT>**STAD/ST03N**</DNT>, so you don&apos;t need to install additional agents on monitored systems.

Starting with version 3.0, <DNT>**NRM4SAP**</DNT> only requires ABAP components, which are deployed exclusively on the central monitoring system.

## 데이터 흐름 아키텍처

<DNT>**RFC**</DNT> 호출은 SAP 텔레메트리 데이터를 중앙 모니터링 시스템으로 가져옵니다. <DNT>**ABAP Enterprise Connector**</DNT> 은(는) 데이터를 처리하고 <DNT>**HTTPS**</DNT>을(를) 통해 뉴렐릭으로 안전하게 전송합니다.

## 포함 사항

설치 후 즉시 사용 가능한 대시보드와 알림을 사용할 수 있습니다:

* **관리 가시성**: 중앙 집중식 대시보드에서 다른 IT 시스템과 함께 SAP 시스템 상태 및 성능을 확인하세요.

* **커스텀 모니터링**: 주문 처리 워크플로우의 통합 지점 추적과 같은 특정 비즈니스 요구 사항에 맞게 모니터링을 맞춤 설정합니다. 수집된 텔레메트리 데이터를 사용하여 커스텀 대시보드 및 시각화를 구축하세요.

* **Proactive alerting**: Set alerts to receive immediate notifications of service disruptions. This helps you maintain continuity and promptly address issues.
