After installing the ABAP add-on, use the <DNT>**`/NEWR/INSTALL`**</DNT> menu to connect your SAP systems to New Relic, configure API endpoints, define monitoring groups, and verify the setup.

## /NEWR/INSTALL 메뉴를 사용하십시오 [#menu-newr-install]

1. 중앙 모니터링 시스템의 프로덕션 클라이언트에 로그인합니다.
2. Type `/n` in the command field and press <DNT>**Enter**</DNT> to go to the <DNT>**SAP Easy Access root menu**</DNT>.
3. Type `/n/NEWR/INSTALL` in the command field to open the <DNT>**`/NEWR/INSTALL`**</DNT> menu.

Before configuring, ensure the following:

* The installer has proper authorization to perform the configuration.
* The `/NEWR/*` parameter is added to the `S_TCODE` authorization object in the installer&apos;s `profile/role`.

<Callout variant="tip">
  이전 버전에서 업그레이드하는 경우 [이전 버전에서 업그레이드](/docs/sap-solutions/upgrade/install-upgrade-package) 를 참조하여 필요한 단계를 확인하십시오.
</Callout>

## 시스템 연결 [#connect-systems]

<Callout variant="important">
  계속 진행하기 전에 보류 중인 설정 단계를 완료하십시오.
</Callout>

In the `/NEWR/INSTALL` menu, open the <DNT>**Install New Release and Patch**</DNT> folder and complete the following steps.

### Standard RFC destination configuration

Use transaction `SM59` to set up <DNT>**RFC**</DNT> and <DNT>**HTTPS**</DNT> connections for on-premises monitored systems:

* For RFC setup, see [Standard RFC Destination](/docs/sap-solutions/install-and-configure/additional-configuration/#standard-rfc-destination) and [Set HTTP destination to New Relic cloud](/docs/sap-solutions/install-and-configure/additional-configuration/#set-http-destination-to-new-relic-cloud).

### SAP Cloud / Business Technology Platform (BTP) RFC configuration

Use transaction `SM59` to set up HTTP destinations for BTP-hosted systems:

* For BTP/CALM authentication, see [Cloud (BTP) RFC Destination](/docs/sap-solutions/install-and-configure/additional-configuration/#cloud-btp-rfc-destination).
* If you monitor an <DNT>**SAP Cloud Connector**</DNT>, configure an RFC destination of type <DNT>**G**</DNT> (External HTTP) using port <DNT>**8443**</DNT> (default Cloud Connector HTTPS admin port). The user account must have the required authorizations and password.

### Set up connection to remote database

If you didn&apos;t complete this step during pre-installation, complete it now.

* Open SAP transaction `DBACOCKPIT` to verify connections to remote <DNT>**HANA databases**</DNT>.
* Create a database connection for each remote HANA database you want to monitor.
* 자세한 지침은 [데이터베이스 연결 생성](/docs/sap-solutions/install-and-configure/additional-configuration/#create-database-connection)을 참조하십시오.

### Configure connections to New Relic API endpoints

You can configure multiple New Relic accounts in this section.

1. <DNT>**New Entries**</DNT> 을(를) 클릭합니다.

2. 뉴렐릭 계정 세부 정보를 입력하세요:

   * <DNT>**New Relic Account ID**</DNT> (선택적으로 SAP- 접두어가 붙을 수 있음)
   * <DNT>**API Ingest Key**</DNT>
   * <DNT>**Metric Endpoint**</DNT> ([네트워크 엔드포인트](/docs/sap-solutions/before-you-begin/#network-endpoints) 참조)
   * <DNT>**Event Endpoint**</DNT>
   * <DNT>**Log Endpoint**</DNT>
   * <DNT>**Trace Endpoint**</DNT>

3. <DNT>**Save**</DNT> 을(를) 클릭합니다.

### Define the monitored systems

1. Click <DNT>**New Entries**</DNT> and enter the <DNT>**SAP System ID**</DNT> and <DNT>**Client**</DNT> number.

2. In <DNT>**Data Provider Installation Information**</DNT>, provide the following:

   * <DNT>**RFC Destination**</DNT>
   * <DNT>**SAP Software Component**</DNT>
   * <DNT>**Database Vendor**</DNT>
   * <DNT>**DB Connection Name**</DNT> (HANA databases only)
   * <DNT>**New Relic Account ID**</DNT> (optional) — if provided, data from this system goes only to that account, overriding the account in the collection manager job variant. If left blank, the system uses the collection manager job variant account.

3. Click <DNT>**Monitoring Group**</DNT> and select <DNT>**Yes**</DNT> to confirm.

4. Choose the required monitoring groups and click the generate icon.

5. Click <DNT>**BACK**</DNT> or press <DNT>**F3**</DNT> to continue.

<img title="Define monitored system" alt="A screenshot displaying the monitored system configuration details" src="/images/details-of-added-entry.webp" width="600" />

### BTP/CALM accounts

When BTP monitoring is active, add BTP/CALM accounts as monitored systems. Use the following values:

* <DNT>**SAP System ID**</DNT>: Use a pseudonym or alias. Do not use reserved terms such as `CALM` or `BTP`.
* <DNT>**Client**</DNT>: Leave blank.
* <DNT>**Destination**</DNT>: Enter the authentication HTTP destination.
* <DNT>**Software Component**</DNT>: Leave blank.
* <DNT>**Database Vendor**</DNT>: Leave blank.
* <DNT>**DB Connection Name**</DNT>: Leave blank.
* <DNT>**New Relic Account ID**</DNT>: Enter the specific New Relic account designated to receive the data.
* <DNT>**API Host**</DNT>: Enter the API host name. This corresponds to the `url` value in the service key.

On the next screen, click <DNT>**Monitoring Group**</DNT>. Choose the appropriate monitoring groups for the system and click <DNT>**Finish**</DNT>.

### Check RFC destinations

Use this option to verify the RFC destinations for the New Relic API endpoints and each monitored system. This test excludes the RFC destination designated as <DNT>**NONE**</DNT>.

## 설정 생성 [#generate-configurations]

### Generate configurations for new data providers

* Run this option to generate all new data providers for a new release or patch. For fresh installations, this single step generates all data providers.
* On the first screen, confirm the release and patch details. If the installation release and patch fields are blank, the configuration is already established.
* To regenerate configurations, navigate to <DNT>**Maintain Monitored Systems**</DNT> and select <DNT>**Re-generate Data Provider Configurations**</DNT>. You can also select <DNT>**Reset Installation Flag (For Re-install only)**</DNT> to clear the current installation flag and regenerate.

<Callout variant="tip">
  For data providers based on CALM, see [Generate Registry Entries for CALM Data Providers](/docs/sap-solutions/monitor/data-providers-reference).
</Callout>

<img title="Maintain Monitored Systems" alt="A screenshot displaying the SAP maintain monitored systems" src="/images/maintain-monitored-systems.webp" width="500" />

### Verify installation completeness

Select <DNT>**Verify Installation Completeness**</DNT>. If any component shows a red indicator, click the execution button in the <DNT>**Action Needed**</DNT> column to resolve the issue.

## 설정 확인 [#verify-configuration]

1. Open the <DNT>**Data Provider Registry Maintenance**</DNT> folder.
2. <DNT>**Data Provider Registry**</DNT>을(를) 클릭하거나 트랜잭션 `/n/NEWR/REGISTRY`을(를) 사용합니다.
3. Select a <DNT>**Data Provider Name**</DNT> and click <DNT>**Configure**</DNT> to check the configuration settings, or click <DNT>**Test**</DNT> to verify the provider&apos;s functionality.
4. Click <DNT>**RuntimeStatus**</DNT> and remove all entries in the Runtime status screen.
