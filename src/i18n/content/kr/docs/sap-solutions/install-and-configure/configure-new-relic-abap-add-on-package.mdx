ABAP 애드온을 설치한 후 <DNT>**`/NEWR/INSTALL`**</DNT> 메뉴를 사용하여 SAP 시스템을 뉴렐릭에 연결하고, API 엔드포인트를 구성하고, 모니터링 그룹을 정의하고, 설정을 확인하십시오.

## /NEWR/INSTALL 메뉴를 사용하십시오 [#menu-newr-install]

1. 중앙 모니터링 시스템의 프로덕션 클라이언트에 로그인합니다.
2. 명령 필드에 `/n`을(를) 입력하고 <DNT>**Enter**</DNT>을(를) 눌러 <DNT>**SAP Easy Access root menu**</DNT>(으)로 이동하십시오.
3. 명령 필드에 `/n/NEWR/INSTALL`을(를) 입력하여 <DNT>**`/NEWR/INSTALL`**</DNT> 메뉴를 여십시오.

구성하기 전에 다음을 확인하십시오:

* 인스톨러는 설정을 수행할 수 있는 적절한 권한을 가지고 있습니다.
* `/NEWR/*` 파라미터는 인스톨러의 `profile/role`에 있는 `S_TCODE` 권한 부여 개체에 추가됩니다.

<Callout variant="tip">
  이전 버전에서 업그레이드하는 경우 [이전 버전에서 업그레이드](/docs/sap-solutions/upgrade/install-upgrade-package) 를 참조하여 필요한 단계를 확인하십시오.
</Callout>

## 시스템 연결 [#connect-systems]

<Callout variant="important">
  계속 진행하기 전에 보류 중인 설정 단계를 완료하십시오.
</Callout>

`/NEWR/INSTALL` 메뉴에서 <DNT>**Install New Release and Patch**</DNT> 폴더를 열고 다음 단계를 완료합니다.

### 표준 RFC 대상 설정

온프레미스 모니터 시스템에 대한 <DNT>**RFC**</DNT> 및 <DNT>**HTTPS**</DNT> 연결을 설정하려면 트랜잭션 `SM59`을(를) 사용하십시오:

* RFC 설정에 대해서는 [표준 RFC 대상](/docs/sap-solutions/install-and-configure/additional-configuration/#standard-rfc-destination) 및 [뉴렐릭 cloud로 HTTP 대상 설정](/docs/sap-solutions/install-and-configure/additional-configuration/#set-http-destination-to-new-relic-cloud)을 참조하십시오.

### SAP Cloud/Business Technology Platform (BTP) RFC 설정

트랜잭션 `SM59`을(를) 사용하여 BTP 호스팅 시스템에 대한 HTTP 대상을 설정하십시오:

* BTP/CALM 인증에 대해서는 [Cloud (BTP) RFC Destination](/docs/sap-solutions/install-and-configure/additional-configuration/#cloud-btp-rfc-destination)을 참조하십시오.
* <DNT>**SAP Cloud Connector**</DNT>을(를) 모니터하는 경우, 포트 <DNT>**8443**</DNT> (기본 Cloud Connector HTTPS 관리자 포트)를 사용하여 유형 <DNT>**G**</DNT> (외부 HTTP)의 RFC 대상을 구성하십시오. 사용자 계정에는 필요한 권한과 비밀번호가 있어야 합니다.

### 원격 데이터베이스 연결 설정

사전 설치 중에 이 단계를 완료하지 않았다면 지금 완료하십시오.

* SAP 트랜잭션 `DBACOCKPIT`을(를) 열어 원격 <DNT>**HANA databases**</DNT>에 대한 연결을 확인하십시오.
* 모니터하려는 각 원격 HANA 데이터베이스에 대한 데이터베이스 연결을 생성하십시오.
* 자세한 지침은 [데이터베이스 연결 생성](/docs/sap-solutions/install-and-configure/additional-configuration/#create-database-connection)을 참조하십시오.

### 뉴렐릭 API 엔드포인트에 대한 연결 구성

이 섹션에서 여러 뉴렐릭 계정을 구성할 수 있습니다.

1. <DNT>**New Entries**</DNT> 을(를) 클릭합니다.

2. 뉴렐릭 계정 세부 정보를 입력하세요:

   * <DNT>**New Relic Account ID**</DNT> (선택적으로 SAP- 접두어가 붙을 수 있음)
   * <DNT>**API Ingest Key**</DNT>
   * <DNT>**Metric Endpoint**</DNT> ([네트워크 엔드포인트](/docs/sap-solutions/before-you-begin/#network-endpoints) 참조)
   * <DNT>**Event Endpoint**</DNT>
   * <DNT>**Log Endpoint**</DNT>
   * <DNT>**Trace Endpoint**</DNT>

3. <DNT>**Save**</DNT> 을(를) 클릭합니다.

### 모니터 시스템을 정의하십시오.

1. <DNT>**New Entries**</DNT>을(를) 클릭하고 <DNT>**SAP System ID**</DNT> 및 <DNT>**Client**</DNT> 번호를 입력하십시오.

2. <DNT>**Data Provider Installation Information**</DNT>에서 다음을 제공하십시오:

   * <DNT>**RFC Destination**</DNT>
   * <DNT>**SAP Software Component**</DNT>
   * <DNT>**Database Vendor**</DNT>
   * <DNT>**DB Connection Name**</DNT> (HANA 데이터베이스 전용)
   * <DNT>**New Relic Account ID**</DNT> (선택 사항) ― 제공된 경우 이 시스템의 데이터는 해당 계정으로만 전송되며 수집 관리자 작업 변형의 계정을 재정의합니다. 비워 두면 시스템에서 컬렉션 관리자 작업 변형 계정을 사용합니다.

3. 확인하려면 <DNT>**Monitoring Group**</DNT>을(를) 클릭하고 <DNT>**Yes**</DNT>을(를) 선택하십시오.

4. 필요한 모니터링 그룹을 선택하고 생성 아이콘을 클릭하십시오.

5. 계속하려면 <DNT>**BACK**</DNT>을(를) 클릭하거나 <DNT>**F3**</DNT>을(를) 누르십시오.

### BTP/CALM 계정

BTP 모니터링이 활성화되면 BTP/CALM 계정을 모니터 시스템으로 추가하십시오. 다음 값을 사용합니다.

* <DNT>**SAP System ID**</DNT>: 가명 또는 별칭을 사용하십시오. `CALM` 또는 `BTP`과(와) 같은 예약어를 사용하지 마십시오.
* <DNT>**Client**</DNT>: 비워 두십시오.
* <DNT>**Destination**</DNT>: 인증 HTTP 대상을 입력하십시오.
* <DNT>**Software Component**</DNT>: 비워 두십시오.
* <DNT>**Database Vendor**</DNT>: 비워 두십시오.
* <DNT>**DB Connection Name**</DNT>: 비워 두십시오.
* <DNT>**New Relic Account ID**</DNT>: 데이터를 수신하도록 지정된 특정 뉴렐릭 계정을 입력하십시오.
* <DNT>**API Host**</DNT>: API 호스트 이름을 입력하십시오. 이는 서비스 키의 `url` 값에 해당합니다.

다음 화면에서 <DNT>**Monitoring Group**</DNT>을(를) 클릭하십시오. 시스템에 적절한 모니터링 그룹을 선택하고 <DNT>**Finish**</DNT>을(를) 클릭하십시오.

### RFC 대상을 확인하십시오

이 옵션을 사용하여 뉴렐릭 API 엔드포인트 및 각 모니터 시스템에 대한 RFC 대상을 확인하십시오. 이 테스트는 <DNT>**NONE**</DNT>(으)로 지정된 RFC 대상을 제외합니다.

## 설정 생성 [#generate-configurations]

### 새로운 데이터 제공자를 위한 설정 생성

* 새 릴리스 또는 패치에 대한 모든 새 데이터 공급자를 생성하려면 이 옵션을 실행하십시오. 새로운 설치의 경우, 이 단일 단계로 모든 데이터 공급자가 생성됩니다.
* 첫 번째 화면에서 릴리스 및 패치 세부 정보를 확인하십시오. 설치 릴리스 및 패치 필드가 비어 있으면 설정이 이미 완료된 것입니다.
* 설정을 다시 생성하려면 <DNT>**Maintain Monitored Systems**</DNT> (으)로 이동하여 <DNT>**Re-generate Data Provider Configurations**</DNT>을(를) 선택하십시오. 또한 <DNT>**Reset Installation Flag (For Re-install only)**</DNT>을(를) 선택하여 현재 설치 플래그를 지우고 다시 생성할 수 있습니다.

  CALM 기반 데이터 제공자의 경우 [CALM 데이터 제공자에 대한 레지스트리 항목 생성](/docs/sap-solutions/monitor/data-providers-reference)을 참조하십시오.
</Callout>

### 설치 완료 확인

<DNT>**Verify Installation Completeness**</DNT>을(를) 선택합니다. 구성 요소에 빨간색 표시가 나타나면 <DNT>**Action Needed**</DNT> 열에서 실행 버튼을 클릭하여 문제를 해결하십시오.

## 설정 확인 [#verify-configuration]

1. <DNT>**Data Provider Registry Maintenance**</DNT> 폴더를 여십시오.
2. <DNT>**Data Provider Registry**</DNT>을(를) 클릭하거나 트랜잭션 `/n/NEWR/REGISTRY`을(를) 사용합니다.
3. <DNT>**Data Provider Name**</DNT>을(를) 선택하고 <DNT>**Configure**</DNT>을(를) 클릭하여 설정을 확인하거나, <DNT>**Test**</DNT>을(를) 클릭하여 공급자의 기능을 확인하십시오.
4. <DNT>**RuntimeStatus**</DNT>을(를) 클릭하고 런타임 상태 화면의 모든 항목을 제거하십시오.
