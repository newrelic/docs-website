* 총 모니터 <DNT>**SIDs**</DNT>이(가) 10개 미만이고 인스턴스가 50개를 초과하지 않으면 전용 서버가 필요하지 않습니다. <DNT>**SIDs**</DNT>이(가) 10개를 초과하거나 인스턴스가 100개를 초과하는 경우 전용 서버를 권장합니다.
* 전용 서버에는 각각 96G의 메모리와 12코어 CPU가 있는 <DNT>**App Server**</DNT> 인스턴스가 2개를 초과해서는 안 됩니다. 모니터링 시스템이 <DNT>**HANA database**</DNT>에서 실행되는 경우 데이터베이스 서버 인스턴스를 애플리케이션 서버 인스턴스와 분리하는 것이 좋습니다.
