<DNT>**Vulnerability Identifier:**</DNT> NR26-13

<DNT>**Priority:**</DNT> Haut

## Résumé

Entre le 17 octobre et le 20 octobre 2026, des chercheurs ont révélé que les clés privées de huit certificats d’autorité de certification (CA) intermédiaires émis par eMudhra peuvent être récupérées (CVE-2026-111943). Toute personne possédant ces clés peut créer des certificats que les logiciels accepteraient comme authentiques s’ils leur font toujours confiance. Les navigateurs et les systèmes d’exploitation ont bloqué les certificats, mais les logiciels qui intègrent leur propre liste d’autorités de certification de confiance, y compris certaines images de conteneurs, doivent être mis à jour.

New Relic a mis à jour les composants de Logs ci-dessous afin qu&apos;ils n&apos;acceptent plus les certificats émis par ces CA. Les versions mises à jour ne sont pas récupérées automatiquement. Les clients doivent effectuer une mise à niveau vers les versions répertoriées ci-dessous.

**Note pour les utilisateurs de FireLens :** le plug-in lui-même rejette désormais les certificats émis par les AC affectées. L’image de base fournie par AWS (`aws-for-fluent-bit`) peut toujours répertorier les AC racines affectées dans son propre bundle d’AC jusqu’à ce qu’AWS publie une image reconstruite. Nous mettrons à jour ce bulletin lorsqu’il sera disponible.

## Informations sur les vulnérabilités techniques

[CVE-2026-111943](https://www.cve.org/CVERecord?id=CVE-2026-111943)

Huit autorités de certification intermédiaires qui forment une chaîne vers emSign ECC Root CA - G3 et, par signature croisée, vers AAA Certificate Services, sont concernées.

* Le plug-in est compilé avec Go 1.27.3, dont la bibliothèque TLS refuse les chaînes de certificats qui contiennent les huit clés affectées, même si la racine est toujours de confiance.
* Pour Fluent Bit 5.1.5, les images de base ont supprimé les racines affectées de leur bundle d’AC.
