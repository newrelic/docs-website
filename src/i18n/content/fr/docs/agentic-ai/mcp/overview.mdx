Ground Truth est la couche d’intelligence opérationnelle de New Relic. Les outils Model Context Protocol (MCP) aident à organiser vos données d’observabilité afin que les agents d’IA puissent mieux comprendre votre stack technologique.

MCP est un moyen standard pour les modèles d’IA ou les agents de recevoir des informations pertinentes (contexte) sur un système ou un environnement spécifique. Ce contexte peut aider l’IA à comprendre la situation actuelle, à effectuer des tâches avec plus de précision, et à fournir des réponses plus utiles. Le serveur MCP permet aux agent(s) d’IA pris en charge d’appeler certains outils qui peuvent vous aider à effectuer des requêtes, à enquêter, ou à agir sur les données New Relic en langage naturel. Cela peut à son tour aider à accélérer la réponse aux incidents et l’analyse des performances.

## Avantages potentiels

Le serveur MCP offre des avantages pratiques pour les ingénieurs et les équipes opérationnelles de la manière suivante :

* **Intégration directe :** accédez aux outils MCP de New Relic directement depuis votre environnement de développement pris en charge. Cela évite de basculer entre différents outils d’IA.
* **Dépannage plus rapide :** utilisez MCP pour vous aider à trouver et corriger rapidement les problèmes à partir de vos données d’observabilité, analyser les logs d’erreurs et déterminer les causes probables grâce aux informations détaillées fournies par l’IA.
* **Requêtes opérationnelles :** demandez à votre agent d’IA de vérifier les statuts d’alerte, de générer des rapports d’événements d’alerte, ou d’analyser l’impact des déploiements sur vos systèmes.
* **Requête de données simple :** formulez des questions en anglais courant, et le serveur les convertit en langage de requête New Relic (NRQL) pour obtenir des résultats, même si vous n’êtes pas familier avec NRQL.

## Outils de développement d&apos;IA pris en charge [#supported-tools]

New Relic MCP fonctionne avec ces environnements de développement d’IA (clients MCP pris en charge) :

* **Claude Code :** interface de ligne de commande pour Claude
* **Antigravity CLI :** interface de ligne de commande pour Antigravity
* **Kiro CLI :** interface de ligne de commande pour Kiro
* **Claude Desktop :** Application de bureau pour le développement d&apos;IA interactive
* **VS Code :** environnement de développement intégré avec prise en charge de MCP

Chaque environnement offre des avantages uniques en fonction de vos préférences workflow. Consultez notre [guide d’installation](/docs/agentic-ai/mcp/setup) pour obtenir les instructions de configuration spécifiques au client MCP.

## Prérequis [#prerequisites]

Pour utiliser New Relic MCP, vous avez besoin de :

* Un compte New Relic (MCP est disponible pour tous les comptes : tous les utilisateurs de données et CCU peuvent accéder aux outils de base, les utilisateurs aCCU peuvent accéder à tous les outils, y compris les outils avancés)
* `Node.js` installé (requis pour certaines méthodes d&apos;authentification)
* L’un des clients MCP pris en charge mentionnés précédemment installé

### Accès à l’organisation [#org-access]

Avant de pouvoir vous connecter, un administrateur New Relic doit effectuer les opérations suivantes :

**Appartenance au groupe et rôles**

Vous devez être membre d’un groupe auquel est attribué soit un rôle d’organisation par défaut (`Organization Read Only`, `Organization Manager`, ou `Organization Product Admin`), soit un rôle personnalisé à l’échelle de l’organisation avec l’autorisation de lire le serveur MCP. Si votre groupe ne dispose pas de l’autorisation requise, contactez un administrateur avec le rôle `Organization Manager`, ou `Authentication Domain Manager` pour qu’elle vous soit accordée.

**gestionnaire de contrôle des fonctionnalités**

L’administrateur de votre organisation doit activer l’accès MCP via le [gestionnaire de contrôle des fonctionnalités](/docs/accounts/accounts-billing/new-relic-one-user-management/feature-control-manager/). Les commutateurs suivants contrôlent l’accès MCP. **New Relic MCP Server** et **Local Clients** sont activés par défaut. Tous les autres sous-commutateurs sont désactivés par défaut et peuvent être activés par votre administrateur New Relic selon les besoins.

* **Serveur MCP New Relic**: requis pour la configuration de MCP. Bouton d’activation principal qui doit être activé pour que tout accès MCP fonctionne.
* **Clients locaux**: requis pour les connexions de clients locaux (Claude Code, Claude Desktop, VS Code, Kiro).
* **Clés API**: requises pour les connexions par clé API, y compris les scripts automatisés.
* **Outils en préversion**: requis si vous souhaitez accéder aux outils MCP en préversion (non-GA).
* **Atlassian**: requis pour l’intégration Atlassian
* **AWS**: requis pour l’intégration AWS

### Options d&apos;authentification [#auth-options]

* **OAuth (recommandé)**: New Relic fournit des points de terminaison OAuth préconfigurés :

  * ID client : `pUWGgnjsQ0bydqCbavTPpw==`
  * URL d&apos;autorisation : `https://oauth2.service.newrelic.com/oauth2/auth`
  * URL du jeton : `https://oauth2.service.newrelic.com/oauth2/token`
  * Portées : `["observability:read", "offline", "offline_access"]`

* **Clé API utilisateur**: notez que **certains outils MCP ne sont accessibles que via OAuth**.

  1. Connectez-vous à New Relic.
  2. Sélectionnez **menu utilisateur -&gt; API keys**.
  3. Créez une nouvelle clé utilisateur ou copiez-en une existante.
  4. Format de clé : `NRAK-XXXXXXXXXXXXXXXXXXXXX`.

<Callout variant="important">
  Certains outils sont uniquement accessibles via OAuth, et ne sont pas disponibles lors de l’utilisation d’une clé API. Ceux-ci incluent les outils d’analyse basés sur l’IA (`natural_language_to_nrql_query`, `generate_alert_insights_report`, `generate_user_impact_report`, `analyze_deployment_impact`), et les outils en préversion (`search_traces`, `analyze_trace_anomaly`, `analyze_service_dependencies`). Consultez la [référence des outils](/docs/agentic-ai/mcp/tool-reference) pour plus de détails.
</Callout>
