Ce guide vous accompagne dans la configuration du serveur Model Context Protocol (MCP) de New Relic avec vos clients MCP pris en charge préférés. Choisissez votre environnement ci-dessous pour obtenir des instructions spécifiques à la plateforme.

<Callout variant="important">
  Votre utilisation de tout outil d&apos;IA, y compris, mais sans s&apos;y limiter, ceux répertoriés sur cette page, avec les serveurs MCP de New Relic AI signifie que votre IA effectuera des actions dans votre compte New Relic en votre nom. Lorsque vous utilisez l&apos;une des méthodes décrites ici, créez et utilisez des comptes New Relic appropriés qui disposent des contrôles d&apos;accès basés sur les rôles (RBAC) souhaités, et des autorisations du moindre privilège adaptées à votre cas d&apos;utilisation, à vos exigences, et à vos politiques internes.
</Callout>

Avant de commencer la configuration de New Relic MCP, assurez-vous d&apos;avoir rempli les [conditions préalables](/docs/agentic-ai/mcp/overview#prerequisites), y compris la configuration de l&apos;authentification. Suivez ensuite les instructions correspondant à votre environnement de développement spécifique.

## Outils de filtrage avec include-tags [#filtering-tools]

Les outils MCP de New Relic sont organisés et catégorisés à l’aide de tags internes (tels que `alerting`, `discovery`, et `data-access`). Pour plus de détails, consultez les [outils de filtrage](/docs/agentic-ai/mcp/tool-reference##filter-tools)

Vous pouvez filtrer dynamiquement les outils auxquels votre agent d&apos;IA accède en envoyant l&apos;en-tête `include-tags` `HTTP` avec vos requests comme indiqué ici :

<Callout variant="important">
  **Avis sur la région :** Les exemples de configuration de cette rubrique utilisent l’URL de connexion MCP de la région américaine (par défaut) : [https://mcp.newrelic.com/mcp/](https://mcp.newrelic.com/mcp/). Si votre compte New Relic se trouve dans une autre région, remplacez cette URL par le point de terminaison régional approprié dans tous les fichiers de configuration et arguments de ligne de commande :

  * UE : [https://mcp.eu.newrelic.com/mcp/](https://mcp.eu.newrelic.com/mcp/)
  * JP : [https://mcp.jp.newrelic.com/mcp/](https://mcp.jp.newrelic.com/mcp/)
</Callout>

```json
"servers": {
    "new-relic-mcp-server": {
        "url": "https://mcp.newrelic.com/mcp/",
        "type": "http",
        "headers": {
            "include-tags": "discovery,alerting"
        }
    }
}
```

Pour obtenir la liste complète des balises disponibles et des outils associés à chacune, reportez-vous à la documentation [de référence des outils New Relic MCP](/docs/agentic-ai/mcp/tool-reference).

<Callout variant="important">
  Sauf indication contraire expresse dans cette Documentation, vous ne devez configurer vos clients MCP pris en charge qu’avec la méthode OAuth. Sauf indication contraire, toute configuration avec une clé API ne fonctionnera pas comme décrit dans cette Documentation, ou comme prévu.
</Callout>

## Configuration du code Claude [#claude-code]

Claude Code prend en charge la méthode d&apos;authentification OAuth. OAuth nécessite la version 2.1.186 de Claude Code ou plus tard. Si vous utilisez des versions antérieures, vous devez vous authentifier via `/mcp` dans Claude au lieu de la connexion MCP claude.

1. Assurez-vous que Claude Code est installé et configuré.

2. Ajoutez le serveur MCP à l&apos;aide de la ligne de commande :

   ```shell
   claude mcp add --transport http newrelic https://mcp.newrelic.com/mcp/
   claude mcp login newrelic
   ```

   Ou modifiez `~/.claude.json` comme indiqué ici :

   ```json
   {
     "mcpServers": {
       "newrelic": {
         "type": "http",
         "url": "https://mcp.newrelic.com/mcp/"
       }
     }
   }
   ```

3. Suivez le flux OAuth du navigateur pour terminer l’authentification.

Si vous rencontrez des erreurs de connexion après la configuration, consultez [Erreur de connexion inattendue dans Claude Code](/docs/agentic-ai/mcp/troubleshoot#connection-error), et [Identifiants OAuth obsolètes dans Claude Desktop](/docs/agentic-ai/mcp/troubleshoot#stale-creds).

## Configuration de Codex [#codex]

Codex prend en charge la méthode d&apos;authentification OAuth. OAuth nécessite la version 0.154.0 ou ultérieure de Codex.

1. Assurez-vous que Codex est installé et configuré.

2. Ajoutez le serveur MCP à l&apos;aide de la ligne de commande :

   ```shell
   codex mcp add newrelic --url https://mcp.newrelic.com/mcp/
   ```

   Ou modifiez `~/.codex/config.toml` comme indiqué ici :

   ```shell
   [mcp_servers.newrelic]
   url = "https://mcp.newrelic.com/mcp/"
   ```

3. Suivez le flux OAuth du navigateur pour terminer l’authentification.

## Configuration d’Antigravity CLI [#antigravity-cli]

<Callout variant="important">
  Seule la méthode par clé API est actuellement prise en charge pour Antigravity CLI. La prise en charge d’OAuth n’est pas encore disponible.
</Callout>

1. Assurez-vous qu’Antigravity CLI est installé sur votre machine.

2. Configurez le serveur MCP en ouvrant (ou en créant) le fichier de configuration :

   * macOS/Linux : `~/.gemini/config/mcp_config.json`
   * Windows: `%USERPROFILE%\.gemini\config\mcp_config.json`

   Ajoutez la configuration suivante :

   ```json
   {
     "mcpServers": {
       "newrelic": {
         "serverUrl": "https://mcp.newrelic.com/mcp/",
         "headers": {
           "api-key": "NRAK-YOUR-KEY-HERE"
         }
       }
     }
   }
   ```

3. Démarrez la CLI Antigravity :

   ```shell
   agy
   ```

4. Exécutez `/mcp` pour vérifier que le serveur New Relic est connecté.

## Configuration de l&apos;interface de ligne de commande Kiro [#kiro-cli]

1. Assurez-vous d&apos;avoir [installé l&apos;outil Kiro CLI](https://kiro.dev/cli/) sur votre machine.
2. Configurez le serveur MCP en ouvrant (ou en créant) le fichier de configuration situé à `~/.kiro/settings/mcp.json` et ajoutez la configuration suivante :

```json
{
  "mcpServers": {
    "newrelic-mcp-server": {
      "url": "https://mcp.newrelic.com/mcp/",
      "oauth": {
        "authorizationUrl": "https://oauth2.service.newrelic.com/oauth2/auth",
        "tokenUrl": "https://oauth2.service.newrelic.com/oauth2/token",
        "scopes": ["observability:read", "offline", "offline_access"],
        "usePKCE": true
      },
      "disabled": false
    }
  }
}
```

3. Authentifiez-vous et connectez-vous :

   * Ouvrez votre terminal et exécutez `kiro-cli`.
   * Tapez la commande `/mcp` et appuyez sur Entrée.
   * Vous verrez le serveur New Relic listé avec une URL. Ouvrez cette URL dans votre navigateur.
   * Suivez la procédure de connexion standard de New Relic.
   * Une fois l&apos;authentification effectuée, le navigateur confirmera la réussite de l&apos;opération.

## Configuration du bureau Claude [#claude-desktop]

Claude Desktop nécessite le proxy `mcp-remote` pour l&apos;authentification `OAuth`. Assurez-vous que `Node.js` est installé sur votre ordinateur pour que npx fonctionne.

1. Créez le répertoire de configuration (si nécessaire) :

```shell
mkdir -p "~/Library/Application Support/Claude"
```

2. Modifiez le fichier de configuration : `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) ou `%APPDATA%\Claude\claude_desktop_config.json` (Windows).

   ```json
   {
     "mcpServers": {
       "new-relic-mcp": {
         "command": "npx",
         "args": [
           "-y",
           "mcp-remote",
           "https://mcp.newrelic.com/mcp/"
         ]
       }
     }
   }
   ```

3. Redémarrez Claude Desktop.

## Configuration de VS Code [#vs-code]

Vous avez besoin de VS Code (version 1.91 ou ultérieure).

1. Ajoutez le serveur MCP en modifiant `.vscode/mcp.json` comme indiqué ici :

```json
{
  "servers": {
    "new-relic-mcp": {
      "url": "https://mcp.newrelic.com/mcp/",
      "type": "http"
    }
  }
}
```

2. Créez ou ouvrez `mcp.json` dans votre espace de travail VS Code :

   * Si vous n&apos;avez pas de répertoire `.vscode`, créez-en un à la racine de votre projet.

     * Dans `.vscode`, créez un fichier nommé `mcp.json`.
     * Ajoutez votre configuration d&apos;authentification.

3. Démarrer le serveur :

   * Assurez-vous que votre fichier `mcp.json` est ouvert dans l&apos;éditeur.
   * Recherchez un lien cliquable (CodeLens) au-dessus de la configuration de votre serveur. Cliquez dessus pour démarrer le serveur MCP.

Une fois connecté, vous pouvez interagir avec New Relic AI en utilisant des instructions en langage naturel. Le serveur MCP gérera l&apos;authentification et la récupération des données depuis votre compte New Relic.
