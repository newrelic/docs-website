En tant que [<DNT>Full platform user</DNT>](/docs/accounts/accounts-billing/new-relic-one-user-management/user-type/#user-type-capabilities), vous pouvez utiliser **NRQL pour requêter directement les données d’entité et de relation dans NRDB** aux côtés de vos données télémétriques. Cet accès unifié facilite le dépannage et l’analyse du système.

Ce document couvre les sujets suivants :

* Interroger les données d&apos;entités et de relations avec NRQL
* Corréler l&apos;entité avec la télémétrie pour une analyse complète
* Explorer des exemples pratiques, tels que le suivi des changements d’état et la recherche de relations application-hôte

## Principaux avantages

Nous avons centralisé vos données en intégrant les entités et leurs relations directement dans NRDB. Cela signifie que vous pouvez utiliser NRQL pour interroger les données d’entité, les données de relation et la télémétrie ensemble en un seul endroit.

Voici comment vous en bénéficiez :

* **Accédez à toutes vos données d’entité directement dans NRDB :** NRDB ingère et stocke vos données d’entité et de relation. Cela crée un datastore unifié, ce qui en fait l’emplacement central pour ces informations critiques aux côtés de vos données télémétriques.
* **Interrogez les données d’entité à l’aide du NRQL familier :** vous pouvez utiliser le NRQL que vous connaissez déjà pour interroger ces données d’entité et de relation. Vous n’avez pas besoin d’apprendre de nouveaux langages de requête ou d’effectuer des jointures complexes sur différents magasins de données.
* **Analysez les données d’entité dans leur fenêtre de rétention de 24 heures :** NRDB conserve ces données d’entité et de relation pendant 24 heures, vous pouvez donc effectuer une analyse en temps opportun et récupérer les informations nécessaires pour comprendre le comportement du système et identifier les dépendances.

<Callout variant="important">
  Les données de relation entre entités sont conservées pendant 24 heures.
</Callout>

* **Corrélez les entités, les relations et la télémétrie dans une seule requête :** vous pouvez relier les entités, leurs relations et vos données télémétriques associées (comme les métriques, les événements, les logs et les traces). Cette capacité de corrélation vous permet de connecter la santé de l’entité, les relations et les données de performance dans une seule requête.
