Microsoft va supprimer le service de connecteur basé sur le webhook Microsoft 365 dans Teams d&apos;ici la fin de l&apos;année 2025. Pour continuer à recevoir les notifications d’alerte New Relic , vous pouvez créer un workflow dans Microsoft Teams à l’aide de l’application de workflow. Ce document fournit des instructions pour mettre à jour vos destinations d&apos;alerte et votre workflow New Relic afin de garantir une transition en douceur et des alertes ininterrompues dans vos canaux Teams. Pour plus d&apos;informations sur le retrait des services de connecteur Office 365, consultez [le blog des développeurs Microsoft](https://devblogs.microsoft.com/microsoft365dev/retirement-of-office-365-connectors-within-microsoft-teams/).

**Prérequis :**

* Créez un nouveau workflow dans Microsoft Teams pour les alertes New Relic . Après avoir créé le workflow, copiez l’URL de la requête POST. Vous aurez besoin de cette URL dans New Relic. Pour plus d’informations, reportez-vous à [la documentation de Microsoft pour créer un workflow dans Teams](https://support.microsoft.com/en-us/office/create-incoming-webhooks-with-workflows-for-microsoft-teams-8ae491c7-0394-4861-ba59-055e33f75498).

**Pour ajouter un webhook New Relic pour workflow Microsoft Teams :**

1. Mettre à jour la destination du webhook existant :

   1. Accédez à **[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Alerts &gt; Enrich and Notify &gt; Destinations**.
   2. Cliquez sur la destination du webhook requise liée à Microsoft Teams pour la modifier.
   3. Après avoir créé un workflow dans Teams, dans le champ **Endpoint URL**, remplacez l’URL existante par une nouvelle URL.
      <img title="Destinations update page" alt="Destinations update page." src="/images/alerts_destination_enpointurl.webp" />
   4. Cliquez sur **Update destination**.

2. Mettre à jour le workflow webhook existant :

   1. Accédez à **[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Alerts &gt; Enrich and Notify &gt; Workflows**.
   2. Pour modifier la charge utile de notification, cliquez sur le workflow requis lié à la destination.
      <img title="Workflow update page" alt="Workflow update page." src="/images/alerts_workflow_payload.webp" />
