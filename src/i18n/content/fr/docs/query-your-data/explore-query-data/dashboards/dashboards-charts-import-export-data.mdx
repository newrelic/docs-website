Vous pouvez utiliser [le dashboard](/docs/query-your-data/explore-query-data/dashboards/introduction-dashboards/) pour visualiser et suivre l&apos;état de votre système, résoudre les problèmes et planifier les étapes ultérieures. Apprenez à partager toutes ces informations avec votre équipe, vos clients ou d’autres parties prenantes grâce à diverses options d’importation et d’exportation.

## Importer un dashboard au format JSON [#import-json]

Vous pouvez importer un dashboard au format JSON lorsque vous souhaitez modifier un dashboard prêt à l&apos;emploi au niveau du code. Par exemple, si vous souhaitez créer un dashboard personnalisé en fusionnant deux dashboards existants, vous pouvez modifier le JSON d&apos;un dashboard de base, puis le réimporter dans New Relic.

Pour importer un dashboard au format JSON :

1. Allez à <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Dashboards**</DNT>.

2. Open an existing dashboard&apos;s JSON by clicking the <DNT>**...**</DNT> icon and selecting <DNT>**Download dashboard**</DNT>.

3. Choose <DNT>**JSON**</DNT> from the format options and select <DNT>**Copy to clipboard**</DNT>.

4. Retournez à la page <DNT>**Dashboards**</DNT> .

5. Dans le coin supérieur droit, cliquez sur <DNT>**Import dashboard**</DNT>.

6. Collez votre code JSON.

7. Choisissez les paramètres de compte et d&apos;autorisation pour le dashboard. Vous ne pouvez pas modifier le compte une fois que vous l&apos;avez configuré, mais vous pouvez [modifier les autorisations](/docs/query-your-data/explore-query-data/dashboards/manage-your-dashboard/#dash-settings) à tout moment.

8. Cliquez sur <DNT>**Save**</DNT>.

## Exporter un dashboard [#export-dashboards-pdf]

To export a dashboard as a JSON, PDF, or PNG file:

1. In the dashboard&apos;s top right corner, click the <DNT>**...**</DNT> icon and select <DNT>**Download dashboard**</DNT>.

2. Choose <DNT>**JSON**</DNT>, <DNT>**PDF**</DNT>, or <DNT>**PNG**</DNT> as the output format.

3. (Optional) For <DNT>**PDF**</DNT> or <DNT>**PNG**</DNT>, set the export width and height, in pixels. Both default to 1920 x 1080.

4. Cliquez sur <DNT>**Download**</DNT>.

New Relic doesn&apos;t support [custom visualizations](/docs/query-your-data/explore-query-data/dashboards/add-custom-visualizations-your-dashboards/) when exporting a dashboard as PDF or PNG via the UI.

To export as PDF or PNG with additional options such as template variable overrides and entity filters, use the [NerdGraph API](#export-api).

## Exporter des dashboards et des graphiques via l&apos;API NerdGraph [#export-api]

Utilisez l&apos;API NerdGraph pour exporter par programmation des dashboards et des widgets de graphiques individuels sous forme d&apos;images instantanées. L&apos;API prend en charge des options non disponibles dans l&apos;interface utilisateur, notamment les dimensions personnalisées, les surcharges de variables de modèle et les filtres d&apos;entité.

### Exporter un dashboard au format PDF ou PNG [#api-dashboard-snapshot]

La mutation `dashboardCreateSnapshotUrl` génère une URL d’instantané pour une page de dashboard complète.

<Callout variant="tip">
  Le paramètre `guid` nécessite le GUID de la **page**, et non le GUID du dashboard. Un dashboard peut avoir plusieurs pages. Pour trouver les GUID de page, utilisez la requête `entitySearch` ou ouvrez la page du dashboard et sélectionnez <DNT>**Manage JSON**</DNT> dans le menu <DNT>**...**</DNT>.

  ```graphql
  {
    actor {
      entitySearch(query: "parentId ='YOUR_DASHBOARD_GUID' AND tags.isDashboardPage = 'true'") {
        results {
          entities {
            guid
            name
          }
        }
      }
    }
  }
  ```
</Callout>

**Schéma de mutation :**

```graphql
mutation {
  dashboardCreateSnapshotUrl(
    guid: EntityGuid!
    params: SnapshotUrlInput
  ): String
}

input SnapshotUrlInput {
  timeWindow: SnapshotUrlTimeWindowInput
  display: SnapshotUrlDisplayInput
  variables: [SnapshotUrlVariableInput!]
  filter: String
  format: SnapshotUrlFormat
}

input SnapshotUrlTimeWindowInput {
  beginTime: EpochMilliseconds
  endTime: EpochMilliseconds
  duration: Milliseconds
}

input SnapshotUrlDisplayInput {
  width: Int
  height: Int
}

input SnapshotUrlVariableInput {
  name: String!
  values: [String!]!
}

enum SnapshotUrlFormat {
  PDF
  PNG
}
```

### Obtenir une image de graphique [#api-widget-snapshot]

The `dashboardWidgetCreateSnapshotUrl` mutation generates a PNG snapshot URL for a single chart widget. The widget doesn&apos;t need to exist on a dashboard — you can define it inline, which makes this useful for generating chart images programmatically.

**Schéma de mutation :**

```graphql
mutation {
  dashboardWidgetCreateSnapshotUrl(
    widget: DeclarativeUiWidget!
  ): WidgetSnapshotResult
}

type WidgetSnapshotResult {
  url: String!
}
```

Le paramètre `widget` accepte un `DeclarativeUiWidget` — un objet JSON avec trois couches imbriquées :

```
declarative/widget envelope
└── widget node        ← title and widget-level props
    └── visualization  ← visualization type and configuration
```

```json
{
  "type": "declarative/widget",
  "version": 1,
  "content": {
    "type": "widget",
    "props": {
      "title": "My Chart Title"
    },
    "content": {
      "type": "visualization",
      "id": "viz.line",
      "props": {
        // visualization-specific config (nrqlQueries, colors, thresholds, etc.)
      }
    }
  }
}
```

Si vous créez la définition du widget à partir d’un dashboard que vous avez exporté au format JSON, utilisez cette modélisation de champ :

<Callout variant="tip">
  The legacy `actor.account.nrql.staticChartUrl` field in NerdGraph remains available but doesn&apos;t support the latest visualization features such as thresholds, color formatting, and newer chart types. `dashboardWidgetCreateSnapshotUrl` is the recommended approach going forward.
</Callout>

<Callout variant="important">
  `dashboardWidgetCreateSnapshotUrl` generates PNG image snapshot URLs. These are publicly accessible without authentication and expire after 3 months.
</Callout>
