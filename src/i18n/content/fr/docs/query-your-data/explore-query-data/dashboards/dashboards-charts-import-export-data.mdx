Vous pouvez utiliser [le dashboard](/docs/query-your-data/explore-query-data/dashboards/introduction-dashboards/) pour visualiser et suivre l&apos;état de votre système, résoudre les problèmes et planifier les étapes ultérieures. Apprenez à partager toutes ces informations avec votre équipe, vos clients ou d’autres parties prenantes grâce à diverses options d’importation et d’exportation.

## Importer les dashboards [#import-json]

Importez un dashboard à partir de son JSON pour le déplacer vers un autre compte ou pour le modifier au niveau du code. Par exemple, vous pouvez créer un dashboard personnalisé en fusionnant deux dashboard existants dans le JSON d’un dashboard de base. Pour obtenir le JSON, [téléchargez le dashboard](#export-dashboards-pdf).

Depuis <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Dashboards**</DNT>, utilisez l’action <DNT>**Import dashboard**</DNT> et collez le JSON. Vous choisissez le compte et les autorisations lors de l’importation. Vous ne pouvez pas modifier le compte par la suite, mais vous pouvez [modifier les autorisations](/docs/query-your-data/explore-query-data/dashboards/manage-your-dashboard/#dash-settings) à tout moment. L’importation nécessite l’autorisation de créer des dashboards dans le compte cible, et les widgets qui effectuent des requêtes sur des comptes auxquels vous n’avez pas accès ne s’affichent pas.

<Callout title="Note">
Un dashboard importé est une copie. Il ne reste pas synchronisé avec l’original, les modifications ultérieures s’appliquent donc uniquement au dashboard que vous modifiez.
</Callout>

## Exporter les dashboards [#export-dashboards]

### Télécharger au format JSON, PDF ou PNG [#export-dashboards-pdf]

Utilisez l’action <DNT>**Download dashboard**</DNT> dans le menu <DNT>**...**</DNT> du dashboard pour enregistrer un dashboard dans l’un de ces formats :

* **JSON**: déplacez un dashboard vers un autre compte ou gérez-le sous forme de code, par exemple dans Terraform. Vous pouvez télécharger le JSON ou le copier dans votre presse-papiers. Le JSON inclut la requête NRQL de chaque widget et les ID de compte, que vous exportiez ou non les GUID d&apos;entité.
* **PDF et PNG**: partagez un instantané statique d&apos;un dashboard dans des e-mails, des pages Confluence ou sur Slack, comme les ventes de la semaine dernière ou les utilisateurs affectés lors d&apos;un incident. Définissez la largeur et la hauteur en pixels. Les deux sont définis par défaut sur 1920 x 1080.

New Relic ne prend pas en charge les [visualisations personnalisées](/docs/query-your-data/explore-query-data/dashboards/add-custom-visualizations-your-dashboards/) lors de l’exportation d’un dashboard au format PDF ou PNG via l’interface utilisateur.

### Exporter les dashboards via NerdGraph [#export-api]

Pour exporter des dashboard par programmation avec des options que l’interface utilisateur ne propose pas, telles que les surcharges de variables de modèle et les filtres d’entité, consultez le [tutoriel NerdGraph : exporter des dashboard et des graphiques sous forme de fichiers](/docs/apis/nerdgraph/examples/export-dashboards-pdfpng-using-api/#api-dashboard-snapshot).

## Exporter les graphiques [#export-charts]

### Exporter au format CSV [#export-charts-csv]

Exportez les données d’un graphique de type tableau sous forme de fichier CSV à l’aide de l’action de graphique <DNT>**Export as CSV**</DNT>.

<img title="Export chart as CSV" alt="Screenshot of how to export a table chart as a CSV file" src="/images/dashboards_screenshot-crop_export-csv.webp" />

### Obtenir les données d’un graphique au format JSON [#export-charts-json]

Pour obtenir la réponse brute à la requête d&apos;un graphique au format JSON, ouvrez <DNT>**View query**</DNT> à partir du menu <DNT>**...**</DNT> du graphique, exécutez la requête, puis définissez le type de graphique sur JSON. Vous pouvez copier la réponse à partir de là. Il s&apos;agit de la sortie de la requête, et non de la configuration du graphique.

### Obtenir un graphique sous forme d’image ou de lien [#chart-image-link]

Partagez un graphique en dehors du dashboard de l&apos;une des deux manières suivantes :

* **Obtenir sous forme d’image**: copiez un lien vers un PNG du graphique. Le lien expire après 90 jours.
* **Obtenir le lien du graphique**: créez une URL de graphique en direct que n’importe qui peut consulter sans compte New Relic. Vous avez besoin de l’autorisation `Live Url (individual) > Modify`. Consultez [Partager un graphique](/docs/query-your-data/explore-query-data/dashboards/share-charts-publicly/#share-chart).

Pour créer, répertorier et révoquer des liens de graphique avec NerdGraph, consultez [Tutoriel NerdGraph : créer, répertorier et révoquer des URL de partage public de graphiques](/docs/apis/nerdgraph/examples/manage-live-chart-urls-via-api/).

### Exporter les graphiques via NerdGraph [#export-charts-api]

Pour générer des images de graphiques par programmation, consultez le [tutoriel NerdGraph : exporter des dashboard et des graphiques sous forme de fichiers](/docs/apis/nerdgraph/examples/export-dashboards-pdfpng-using-api/#api-widget-snapshot).
