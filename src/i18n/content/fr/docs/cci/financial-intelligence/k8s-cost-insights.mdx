La page <DNT>**Kubernetes Costs**</DNT> indique le coût de chacun de vos clusters Kubernetes, réparti par CPU, mémoire, et ressources inutilisées et non allouées. Elle utilise vos données télémétriques Kubernetes dans New Relic pour corréler la facturation cloud avec l&apos;utilisation au niveau du cluster, afin que vous puissiez voir où vont vos dépenses, et où vous pouvez réduire les coûts.

<img title="Kubernetes Cost Insights highlighted on the Cloud Cost Intelligence Kubernetes Cost Insights page" alt="Kubernetes Cost Insights highlighted on the Cloud Cost Intelligence Kubernetes Cost Insights page" src="/images/k8s-cci.webp" />

## Prérequis [#prerequisites]

Avant que la page <DNT>**Kubernetes Costs**</DNT> puisse afficher des données, vous devez ajouter les comptes New Relic qui contiennent votre télémétrie Kubernetes. CCI utilise les événements `K8sContainerSample` de ces comptes et les associe à vos données de facturation cloud sur l&apos;ID d’instance. Si vous ignorez cette étape, vous pourriez voir des coûts cloud dans CCI, mais aucun coût Kubernetes.

Pour ajouter ces comptes, suivez les étapes suivantes :

1. Allez à <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Cloud Cost Intelligence &gt; Settings &gt; Telemetry Accounts**</DNT>.

2. Dans la liste déroulante <DNT>**Accounts**</DNT>, sélectionnez chaque compte New Relic qui contient des données `K8sContainerSample`. Pour vérifier un compte, exécutez-y cette requête :

   ```sql
   SELECT count(*) FROM K8sContainerSample SINCE 1 day ago
   ```

3. Cliquez sur <DNT>**Apply**</DNT>.

Une fois que vous avez ajouté les comptes, CCI extrait les données `K8sContainerSample` et commence à allouer les coûts Kubernetes.

<Callout variant="important">
Si vos cluster Kubernetes envoient des données à plus d’un compte New Relic, ajoutez chacun d’entre eux. Les coûts des cluster des comptes que vous n’avez pas ajoutés n’apparaîtront pas sur la page <DNT>**Kubernetes Costs**</DNT>.
</Callout>

Si vous avez ajouté les bons comptes et que vous ne voyez toujours aucun coût Kubernetes, consultez la section [Dépannage](#troubleshoot).

## Filtres et personnalisation

### Filtres de fournisseur de cloud

Pour filtrer vos données de coûts par fournisseur cloud, sélectionnez une option dans le menu déroulant en haut à gauche de la page :

* <DNT>**All**</DNT>: Tous les fournisseurs de cloud
* <DNT>**AWS**</DNT>: Amazon Web Services uniquement
* <DNT>**Azure**</DNT>: Microsoft Azure uniquement

### Sélecteur de plage de dates

En haut à droite de la page, utilisez le sélecteur de plage de dates pour effectuer l’une des actions suivantes :

* Choisissez une période prédéfinie
* Définir des dates de début et de fin personnalisées
* Affichez les coûts dans votre fuseau horaire préféré (UTC affiché par défaut)

### Filtre des coûts d&apos;ingénierie

Si votre organisation utilise des tags d&apos;allocation des coûts, vous pouvez filtrer par le tag <DNT>**Engineering costs**</DNT> pour restreindre l&apos;analyse à des équipes, projets ou centres de coûts spécifiques taggés dans votre environnement cloud.

## Résumé

La section Résumé affiche quatre métriques de coûts pour la période que vous avez sélectionnée :

| métrique                            | Description                                                                                                             |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| <DNT>**Total cost**</DNT>           | Dépenses globales pour tous les cluster Kubernetes, avec l’évolution en pourcentage par rapport à la période précédente |
| <DNT>**Average cost (Daily)**</DNT> | Dépenses moyennes quotidiennes, avec l’évolution en pourcentage                                                         |
| <DNT>**Unused cost**</DNT>          | Coût des ressources que votre cluster a allouées mais qui ne reçoivent pas de requests, avec l’évolution en pourcentage |
| <DNT>**Unallocated cost**</DNT>     | Coût des ressources de cluster non allouées à une source, avec variation en pourcentage                                 |

## Insights

La section Insights fournit deux widgets de visualisation pour vous aider à analyser vos coûts Kubernetes.

### Tendances des coûts

Le widget <DNT>**Cost Trends**</DNT> affiche un graphique linéaire montrant l&apos;évolution de vos coûts Kubernetes au fil du temps. Utilisez les options d&apos;affichage pour basculer entre les vues <DNT>**Hourly**</DNT>, <DNT>**Daily**</DNT>, <DNT>**Weekly**</DNT> ou <DNT>**Monthly**</DNT>.

### Top 20

Le widget <DNT>**Top 20**</DNT> affiche vos zones les plus coûteuses à l&apos;aide d&apos;une visualisation en arborescence. Par défaut, il affiche les 20 clusters les plus coûteux. Vous pouvez personnaliser la vue avec les options suivantes :

* <DNT>**Dropdown filter**</DNT>: sélectionner ce qu&apos;il faut afficher (<DNT>**Cluster name, by cost**</DNT>)
* <DNT>**Group by**</DNT>: Choisissez des dimensions pour regrouper les données de coût
* <DNT>**View by**</DNT>: Basculer entre <DNT>**Tree chart**</DNT> et d&apos;autres formats de visualisation

## Cost &amp; Usage Analysis

La section <DNT>**Cost &amp; Usage Analysis**</DNT> présente un tableau avec une répartition de l&apos;utilisation des ressources et des coûts par nom de cluster :

| Colonne                         | Description                                                                                |
| ------------------------------- | ------------------------------------------------------------------------------------------ |
| <DNT>**Cluster name**</DNT>     | Nom de votre cluster Kubernetes                                                            |
| <DNT>**CPU cost**</DNT>         | Coût attribué à l’utilisation du CPU pour chaque cluster                                   |
| <DNT>**CPU usage**</DNT>        | Pourcentage des ressources CPU consommées par chaque cluster                               |
| <DNT>**Memory cost**</DNT>      | Coût associé à l&apos;utilisation de la mémoire pour chaque cluster                        |
| <DNT>**Memory usage**</DNT>     | Pourcentage des ressources mémoire utilisées par chaque cluster                            |
| <DNT>**Unused cost**</DNT>      | Coût des ressources que votre cluster a allouées mais qui ne reçoivent pas de requests     |
| <DNT>**Unallocated cost**</DNT> | Coût des ressources de cluster non allouées à une source                                   |
| <DNT>**Total cost**</DNT>       | Coût combiné pour chaque cluster pour l’ensemble de l’utilisation des ressources (triable) |

Si les coûts inutilisés ou non alloués sont constamment élevés pour un cluster, celui-ci est peut-être surdimensionné. Consultez les [Recommandations d&apos;optimisation des coûts](/docs/cci/financial-intelligence/cci-recommendations) pour découvrir des moyens de réduire les dépenses dans l&apos;ensemble de votre environnement cloud.

## Coûts inutilisés vs non alloués

Ces dimensions de coût vous aident à mesurer l&apos;efficacité du cluster :

| Type de coût    | Définition                                                                     | Exemple                                                                        |
| --------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------ |
| Coût inutilisé  | Ressources que votre cluster a allouées mais qui ne reçoivent pas de requests. | Coût total : 5,60 $, utilisé : 4,64 $, coût inutilisé : 0,96 $                 |
| Coût non alloué | Ressources de cluster non allouées à une source.                               | Coût du nœud : 10,00 $, alloué aux workload : 7,50 $, coût non alloué : 2,50 $ |

<Callout variant="tip">
Sélectionnez un cluster pour afficher ses <DNT>**Cost Trends**</DNT>, <DNT>**Cost Breakdown (Total vs Used)**</DNT>, et des informations sur les coûts inutilisés et non alloués.
</Callout>

## Dépannage [#troubleshoot]

### Les coûts AWS apparaissent mais aucun coût Kubernetes ne s’affiche

Vous n’avez pas encore ajouté vos comptes de télémétrie, ou vous n’en avez ajouté que certains. Consultez les [Prérequis](#prerequisites).

### Certains clusters sont manquants sur la page

Vos cluster Kubernetes peuvent remonter des données à plus d’un compte New Relic. Assurez-vous d’avoir ajouté chaque compte qui remonte des données sous <DNT>**Settings &gt; Telemetry data**</DNT>.

### Vous avez ajouté les bons comptes, mais les coûts n&apos;apparaissent toujours pas

Contactez le service clients de New Relic.

Pour les problèmes liés à la configuration, aux intégrations, ou aux autorisations de CCI, consultez [Dépanner la configuration de l’Intelligence Coûts du cloud](/docs/cci/troubleshooting/troubleshooting).
