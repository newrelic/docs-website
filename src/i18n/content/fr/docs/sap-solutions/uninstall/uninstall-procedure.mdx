Ce guide vous montre comment désinstaller le <DNT>**New Relic ABAP component (NEWR)**</DNT> de votre système central SAP. Vous devrez peut-être le faire lors de la mise hors service du monitoring ou avant de mettre à niveau vers une nouvelle version.

<Callout variant="caution">
  La désinstallation du <DNT>**New Relic ABAP component**</DNT> arrête toute collecte de données de monitoring, et supprime le composant de votre système SAP. New Relic conserve vos données historiques, mais ne collecte pas de nouvelles données après la désinstallation. Vous ne pouvez pas annuler cette action.
</Callout>

## Prérequis

* Accès administrateur à <DNT>**SAP system**</DNT>
* Accès à <DNT>**client 000**</DNT>
* Sauvegarde de toute configuration personnalisée (si nécessaire pour une réinstallation future)

## Supprimer les artefacts de monitoring New Relic

Avant de désinstaller le <DNT>**ABAP component**</DNT>, nettoyez les artefacts de monitoring sur le système de monitoring central :

1. Arrêtez et déprogrammez toutes les tâches de collecte planifiées qui exécutent des programmes `/NEWR/*`. Utilisez la transaction `SM37` pour trouver et annuler ces tâches.
2. Supprimez tous les rôles dont le nom est préfixé par `/NEWR/*`.
3. Dans la transaction `SM59`, supprimez tous les <DNT>**RFC connections**</DNT> vers les systèmes monitorés qui ont été créés uniquement pour la collecte de données New Relic. Vous pouvez identifier ces connexions par le compte de connexion de collecte de données New Relic désigné, ou en consultant la liste du registre du fournisseur de données New Relic.

## Désinstaller le composant ABAP

Suivez ces étapes pour désinstaller le composant ABAP du système central :

1. Connectez-vous à <DNT>**client 000**</DNT>.
2. Entrez le code de transaction `SAINT`.
3. Cliquez sur l’onglet <DNT>**Uninstallable Components**</DNT>.

<img title="ABAP component on central system" alt="The SAINT transaction showing the NEWR component in the Uninstallable Components list" src="/images/ABAP-component-on-cms.webp" width="700" />

4. Sélectionnez le composant <DNT>**NEWR**</DNT> et vérifiez que le numéro de version correspond à votre version installée.
5. Cliquez sur <DNT>**Start**</DNT>.
6. Cliquez sur la coche verte pour confirmer sur chaque écran suivant.
7. Cliquez sur <DNT>**Finish**</DNT> lorsque le processus est terminé.
8. Vérifiez que le composant <DNT>**NEWR**</DNT> n’apparaît plus dans l’onglet <DNT>**Installed Components**</DNT>.

## Supprimer New Relic des systèmes monitorés

Le composant ABAP <DNT>**NEWR**</DNT> est installé uniquement sur le système central, de sorte que les systèmes monitorés n’ont aucun composant à désinstaller. Pour désinstaller New Relic d’un système monitoré, supprimez l’accès créé pour la collecte de données :

1. Dans la transaction `SU01`, supprimez le <DNT>**ABAP user account**</DNT> New Relic désigné utilisé pour la collecte de données.
2. Supprimez le rôle d&apos;autorisation New Relic associé (noms préfixés par `/NEWR/*`).

## Vérifier la désinstallation

Une fois le processus de désinstallation terminé :

* Le composant <DNT>**NEWR**</DNT> ne devrait plus apparaître dans l&apos;onglet <DNT>**Installed Components**</DNT>
* Les tâches de collecte de données dans la transaction `SM37` ne s&apos;exécuteront plus
* New Relic cessera de recevoir des données de monitoring de ce système.

**Remarque**: les données de monitoring historiques dans New Relic resteront accessibles. Seul le composant de collecte de données est supprimé du système SAP.
