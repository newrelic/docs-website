L&apos;observabilité New Relic pour SAP - ABAP Hosted capture les données télémétriques SAP (Métriques, événement, log et trace) et les envoie à la plateforme New Relic pour analyse et visualisation.

## Système de monitoring central vs systèmes monitorés

Les systèmes SAP qui fournissent des données télémétriques sont appelés systèmes monitorés. Le système de monitoring central est le système sur lequel <DNT>**NRM4SAP**</DNT> est installé ; il collecte, transforme et transmet des données télémétriques. En règle générale, vous installez <DNT>**NRM4SAP**</DNT> sur un seul système SAP, tel que <DNT>**SAP Solution Manager (SolMan)**</DNT>. <DNT>**NRM4SAP**</DNT> n’a aucune dépendance fonctionnelle vis-à-vis de SolMan ; il sert uniquement de point de référence ici. <DNT>**NRM4SAP**</DNT> utilise des sources de données SAP standard telles que <DNT>**ST-PI**</DNT>, les classes MTE (composants au sein de <DNT>**CCMS**</DNT>) et les données de performance de <DNT>**STAD/ST03N**</DNT>, vous n’avez donc pas besoin d’installer d’agents supplémentaires sur les systèmes monitorés.

À partir de la version 3,0, <DNT>**NRM4SAP**</DNT> nécessite uniquement des composants ABAP, qui sont déployés exclusivement sur le système de monitoring central.

## Architecture des flux de données

<DNT>**RFC**</DNT> les appels récupèrent les données télémétriques SAP dans le système de monitoring central. Le <DNT>**ABAP Enterprise Connector**</DNT> traite les données et les transmet de manière sécurisée à New Relic via <DNT>**HTTPS**</DNT>.

## Ce qui est inclus

Après l&apos;installation, vous pouvez utiliser des dashboards et des alertes prêts à l&apos;emploi :

* **Visibilité de la gestion**: affichez la santé et les performances du système SAP ainsi que d&apos;autres systèmes informatiques dans des dashboard centralisés.

* **Monitoring personnalisé**: adaptez le monitoring aux besoins commerciaux spécifiques, tels que le suivi des points d&apos;intégration dans les workflows de traitement des commandes. Créez des dashboards personnalisés et des visualisations à partir des données télémétriques collectées.

* **Alertes proactives**: configurez des alertes pour recevoir des notifications immédiates d’interruptions de service. Cela vous aide à maintenir la continuité, et à résoudre rapidement les problèmes.
