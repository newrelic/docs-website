Ce guide vous montre comment monitorer le processus de collecte de données pour New Relic Monitoring for SAP Solutions. Vous pouvez utiliser plusieurs méthodes pour vérifier que la collecte de données fonctionne correctement.

## Prérequis

* Accès à <DNT>**SAP system**</DNT> avec les permissions de transaction appropriées
* <DNT>**New Relic Monitoring for SAP Solutions**</DNT> installé et configuré

## État d&apos;exécution et logde transmission

Ouvrez le <DNT>**Data Provider Registry**</DNT> (transaction `/NEWR/REGISTRY`) pour vérifier l’état d’exécution et les détails de transmission pour chaque fournisseur de données. Cliquez sur <DNT>**RuntimeStatus**</DNT> pour afficher la dernière heure d’exécution et l’état actuel. Cliquez sur <DNT>**Transmission Log**</DNT> pour afficher l’heure de transmission, le code de réponse HTTP, et l’état de transmission pour chaque enregistrement envoyé à New Relic.

## Vérifier l&apos;état du travail et le spool

1. Utilisez la transaction `SM37` pour vérifier l’état des tâches planifiées. Saisissez `/NEWR/*` dans le champ <DNT>**ABAP Program Name**</DNT> et cliquez sur <DNT>**Execute**</DNT>.
2. Examiner la durée d&apos;exécution. Un temps d&apos;exécution anormalement long indique un problème potentiel.
3. Vérifiez les tâches qui se chevauchent et ajustez la planification si nécessaire.
4. Ouvrez le spool du job à partir des détails du job. Le spool affiche l’horodatage de collecte, l’état de transmission, et le résultat pour chaque fournisseur de données.
5. Utilisez le numéro de job pour corréler les entrées de spool avec le log de transmission dans le <DNT>**Data Provider Registry**</DNT>.

## Vérifier log d&apos;application

Les processus de collecte de données sont enregistrés dans le log d&apos;application (transaction `SLG1`). Requête avec le <DNT>**Application Log Object**</DNT> `/NEWR/DP`.

Pour les fournisseurs de données asynchrones (ceux avec le suffixe `_COMPLETE`), le spool de travaux n’inclut pas leurs enregistrements. Vérifiez le log d&apos;application en utilisant la sous-catégorie <DNT>**`/NEWR/DP_AGENT`**</DNT> pour afficher leurs détails de collecte, et de transmission.

## dashboard monitoring de la collecte de données SAP

Les métriques de collecte de données sont également envoyées à New Relic pour l&apos;auto-monitoring. Utilisez le dashboard <DNT>**SAP Data Collection Monitoring**</DNT> prêt à l&apos;emploi pour monitorer les processus de collecte de données pour chaque fournisseur de données. Pour obtenir des instructions d&apos;installation, consultez [Installer les composants de monitoring](/docs/sap-solutions/install-and-configure/install-out-of-the-box).
