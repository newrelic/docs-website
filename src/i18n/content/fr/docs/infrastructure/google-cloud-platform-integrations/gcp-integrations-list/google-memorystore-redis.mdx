Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec la [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données [Google Memorystore pour Redis](https://cloud.google.com/memorystore/docs/redis) à New Relic. Ce document explique comment activer l&apos;intégration GCP Memorystore pour Redis et décrit les données qu&apos;elle signale.

## Caractéristiques

Memorystore for Redis est le service Redis entièrement géré de Google Cloud. L’intégration New Relic Memorystore for Redis collecte les métriques de CPU, de mémoire, de réseau, d’espace clé, de persistance, de réplication et de débit des commandes pour chaque instance Redis.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

Les intégrations New Relic interrogent vos services GCP selon un intervalle d’interrogation qui varie selon l&apos;intégration. La fréquence d&apos;interrogation pour Google Memorystore pour Redis est de 5 minutes. La résolution est de 1 point de données par minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Une fois que vous avez activé l’intégration, vos instances Memorystore pour Redis apparaissent en tant qu’entités dans l’explorateur d’entités de New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques Memorystore pour Redis disponibles dans le monitoring cloud de GCP sont collectées en tant que métriques dimensionnelles dans le type d’événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation de Google sur les métriques Memorystore pour Redis](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-redis) pour obtenir la liste complète.
