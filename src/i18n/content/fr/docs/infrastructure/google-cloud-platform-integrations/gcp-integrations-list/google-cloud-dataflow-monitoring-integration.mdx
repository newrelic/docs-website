Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de [Google Cloud Dataflow](https://cloud.google.com/dataflow) à New Relic. Ce document explique comment activer l&apos;intégration GCP Cloud Dataflow et décrit les données qu&apos;elle signale.

## Caractéristiques

Cloud Dataflow est le service de traitement des données en continu et par lots entièrement géré de Google Cloud basé sur Apache Beam. L’intégration New Relic Dataflow collecte les métriques de ressources des workers, de débit, de décalage et d’état des tâches pour chaque tâche Dataflow.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

Les intégrations de New Relic interrogent vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d&apos;interrogation pour Google Cloud Dataflow est de 5 minutes. La résolution est de 1 point de données par minute.

<Callout variant="important">
  Cloud Dataflow prend en charge des intervalles d’interrogation de 1 minute pour les intégrations WIF en version préliminaire limitée. Pour demander l’accès, contactez le [support New Relic](https://support.newrelic.com/).
</Callout>

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Après avoir activé l’intégration, vos ressources Dataflow apparaissent en tant qu’entités dans l’explorateur d’entités New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques Dataflow disponibles dans le monitoring cloud de GCP sont collectées en tant que métriques dimensionnelles dans le type d’événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation sur les métriques Dataflow de Google](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-dataflow) pour obtenir la liste complète.
