Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec la [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de [Firebase AI Logic](https://firebase.google.com/docs/ai-logic) (anciennement Vertex AI dans Firebase) à New Relic. Ce document explique comment activer l’intégration GCP Firebase AI Logic et décrit les données qu’elle signale.

## Caractéristiques

Firebase AI Logic permet aux applications mobiles et web d’appeler les modèles Gemini et Imagen directement depuis les SDK clients, sans backend personnalisé. L’intégration New Relic Firebase AI Logic collecte la télémétrie client de l’IA générative pour chaque modèle : durée de l’opération, utilisation des jetons et nombre d’utilisations par modalité.

## Activer l&apos;intégration [#activate]

<Callout variant="important">
  Cette intégration est disponible uniquement lorsque vous connectez votre projet GCP avec Workload Identity Federation. Elle n’est pas disponible pour les connexions de compte de service ou de compte utilisateur.
</Callout>

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure) avec Workload Identity Federation.

## Fréquence des sondages [#polling]

L’intégration New Relic interroge vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d&apos;interrogation pour Firebase AI Logic est de 5 minutes. La résolution est de 1 point de données chaque minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Toutes les métriques de modèle Firebase AI Logic disponibles dans le monitoring cloud GCP sont collectées en tant que métriques dimensionnelles dans le type d’événement `Metric`.

Cette intégration ne crée pas d’entités dans l’explorateur d’entités de New Relic. Interrogez ses métriques directement sur le type d’événement `Metric`, par exemple :

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'gcp.firebasevertexai.%' FACET metricName
```

`gen_ai_client_operation_duration` est également disponible en tant que métriques de percentile `.p50`, `.p95`, et `.p99`.

<Callout variant="tip">
  Firebase AI Logic expose également les métriques de modèle de prompt (`render_count` et `render_latency`) sur une ressource monitorée distincte. Cette intégration ne collecte pas ces métriques car elles sont en preview.
</Callout>

Pour la liste complète, consultez la [documentation sur les métriques Firebase AI Logic de Google](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-firebasevertexai).
