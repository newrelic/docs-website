Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec la [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de [Google Cloud Pub/Sub](https://cloud.google.com/pubsub/) à New Relic. Ce document explique comment activer l’intégration GCP Pub/Sub et décrit les données qu’elle signale.

## Caractéristiques

Dans le cadre de la [solution d’analyse de flux](https://cloud.google.com/solutions/stream-analytics) Google Cloud, le service Cloud Pub/Sub ingère et distribue des flux d’événements pour un traitement des données et une analyse rapides. L’intégration New Relic Pub/Sub collecte les métriques de publication, de distribution, de backlog et de rétention sur les rubriques, les abonnements et les instantanés.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

Les intégrations New Relic interrogent vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d&apos;interrogation pour Google Cloud Pub/Sub est de 5 minutes. La résolution est de 1 point de données par minute.

<Callout variant="important">
  Cloud Pub/Sub prend en charge des intervalles d’interrogation de 1 minute pour les intégrations WIF en version préliminaire limitée. Pour demander l’accès, contactez le [support New Relic](https://support.newrelic.com/).
</Callout>

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Une fois que vous avez activé l’intégration, vos ressources Pub/Sub apparaissent sous forme d’entités dans l’explorateur d’entités de New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques Pub/Sub disponibles dans le monitoring cloud de GCP sont collectées en tant que métriques dimensionnelles dans le type d’événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation de Google sur les métriques Pub/Sub](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-pubsub) pour obtenir la liste complète.

## Compte de service ou compte utilisateur [#service-account]

### Rechercher et utiliser des données [#find-data]

Après avoir activé l&apos;intégration et attendu quelques minutes (en fonction de la [fréquence d&apos;interrogation](#polling)), les données apparaîtront dans l&apos;UI de New Relic. Pour [rechercher et utiliser vos données](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), y compris les liens vers vos <InlinePopover type="dashboards" />et vos paramètres d&apos;alerte, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

Les sujets Pub/Sub sont des entités nommées qui représentent des flux de messages, et les abonnements sont des entités nommées qui représentent des destinations de messages sur un sujet particulier.

Pour afficher [les données métriques](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics) de votre intégration GCP Pub/Sub dans New Relic, [créez une requête NRQL ](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql)pour [l&apos;événement](/docs/data-apis/understand-data/new-relic-data-types/#event-data) `GcpPubSubTopicSample` et `GcpPubSubSubscriptionSample` et leur attribut associé.
