Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec la [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de [Google Kubernetes Engine](https://cloud.google.com/kubernetes-engine/) (GKE) à New Relic. Ce document explique comment activer l’intégration GCP Kubernetes Engine et décrit les données qu’elle signale.

## Caractéristiques

Google Kubernetes Engine est le service Kubernetes géré de Google Cloud. L&apos;intégration GKE de New Relic collecte les métriques de processeur, de mémoire, de réseau, de volume et de temps de disponibilité sur les conteneurs, les nœuds et les pods qui composent vos clusters.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account)

## Fréquence des sondages [#polling]

L’intégration New Relic interroge vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d&apos;interrogation pour Google Kubernetes Engine est de 5 minutes. La résolution est de 1 point de données chaque minute.

<Callout variant="important">
  **Recommandé : utilisez l’intégration New Relic Kubernetes pour GKE.** Avec Workload Identity Federation, l’intégration GCP collecte les métriques GKE, mais ne crée pas d’entités. Pour une observabilité complète de GKE — entités de cluster, de nœud, de pod et de conteneur, dashboards et alertes —, installez l’ [intégration New Relic Kubernetes](https://docs.newrelic.com/docs/kubernetes-pixie/kubernetes-integration/installation/kubernetes-integration-install-configure/) sur votre cluster GKE.

  Google Kubernetes Engine (GKE) prend en charge des intervalles d’interrogation de 1 minute pour les intégrations WIF en version préliminaire limitée. Pour demander l’accès, contactez le [support New Relic](https://support.newrelic.com/).
</Callout>

## Compte de service ou compte utilisateur [#service-account]

### Rechercher et utiliser des données [#find-data]

Après avoir activé l&apos;intégration et attendu quelques minutes (en fonction de la [fréquence d&apos;interrogation](#polling)), les données apparaîtront dans l&apos;UI de New Relic. Pour [rechercher et utiliser vos données](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), y compris les liens vers vos <InlinePopover type="dashboards" />et vos paramètres d&apos;alerte, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

Les données que New Relic reçoit de votre intégration Google Kubernetes Engine incluent les données métriques suivantes. Pour en savoir plus sur ces métriques, consultez la documentation de Google sur [Métriques pour Kubernetes Engine](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-container).
