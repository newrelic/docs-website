Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données [Google Cloud Load Balancing](https://cloud.google.com/load-balancing/) à New Relic. Ce document explique comment activer l’intégration GCP Cloud Load Balancing et décrit les données qu’elle signale.

## Caractéristiques

Cloud Load Balancing est le service géré basé sur un logiciel de Google Cloud pour distribuer le trafic entre les régions, avec la prise en charge de l&apos;équilibrage de charge HTTP(S), du proxy TCP/SSL et de l&apos;équilibrage de charge L4 (réseau). L&apos;intégration New Relic Load Balancing collecte le taux de requêtes, la latence, le débit en octets et les métriques de connexion pour chaque variante d&apos;équilibreur de charge.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

Les intégrations New Relic interrogent vos services GCP selon un intervalle d’interrogation qui varie selon l&apos;intégration. La fréquence d&apos;interrogation pour Google Cloud Load Balancing est de 5 minutes. La résolution est de 1 point de données par minute.

<Callout variant="important">
  Cloud Load Balancing prend en charge des intervalles d’interrogation de 1 minute pour les intégrations WIF en version préliminaire limitée. Pour demander l&apos;accès, contactez le [support New Relic](https://support.newrelic.com/).
</Callout>

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Une fois que vous avez activé l&apos;intégration, vos ressources d&apos;équilibrage de charge dans le cloud apparaissent sous forme d&apos;entités dans l&apos;explorateur d&apos;entités New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques Cloud Load Balancing disponibles dans le monitoring cloud GCP sont collectées en tant que métriques dimensionnelles dans le type d’événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation sur les métriques Cloud Load Balancing de Google](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-loadbalancing) pour obtenir la liste complète.

## Compte de service ou compte utilisateur [#service-account]

### Rechercher et utiliser des données [#find-data]

Après avoir activé l&apos;intégration et attendu quelques minutes (en fonction de la [fréquence d&apos;interrogation](#polling)), les données apparaîtront dans l&apos;UI de New Relic. Pour [rechercher et utiliser vos données](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), y compris les liens vers vos <InlinePopover type="dashboards" />et vos paramètres d&apos;alerte, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

Pour afficher [les données métriques](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics) de votre intégration GCP Load Balancing dans New Relic, [créez une requête NRQL ](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql)pour [les événements](/docs/data-apis/understand-data/new-relic-data-types/#event-data) `GcpHttpLoadBalancerSample`, `GcpHttpExternalRegionalLoadBalancerSample`, `GcpInternalHttpLoadBalancerSample`, `GcpTcpSslProxyLoadBalancerSample` et `GcpInternalLoadBalancerSample` et leur attribut associé.
