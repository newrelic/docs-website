Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec la [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de [Google Distributed Cloud Edge](https://cloud.google.com/distributed-cloud/edge) à New Relic. Ce document explique comment activer l&apos;intégration <DNT>GCP Distributed Cloud Edge</DNT> et décrit les données qu&apos;elle signale.

## Caractéristiques

<DNT>Google Distributed Cloud Edge</DNT> est la plateforme d’edge computing gérée sur site de <DNT>Google Cloud</DNT> pour exécuter des workloads <DNT>Kubernetes</DNT> sur du matériel appartenant aux clients. L’intégration <DNT>Distributed Cloud Edge</DNT> de New Relic collecte l’inventaire matériel et les métriques de santé pour les machines (nœuds) et les clusters edge de votre déploiement : la télémétrie du CPU, de la mémoire, du disque, du réseau, du GPU et de l’alimentation/PSU, ainsi que le cycle de vie du cluster et l’état de la version.

## Activer l&apos;intégration [#activate]

<Callout variant="important">
  Cette intégration est disponible uniquement lorsque vous connectez votre projet <DNT>GCP</DNT> avec <DNT>**Workload Identity Federation**</DNT>. Elle n’est pas disponible pour les connexions de compte de service ou de compte utilisateur.
</Callout>

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure) avec <DNT>**Workload Identity Federation**</DNT>.

## Fréquence des sondages [#polling]

Les intégrations New Relic interrogent vos services <DNT>GCP</DNT> selon un intervalle d’interrogation qui varie selon l&apos;intégration. La fréquence d&apos;interrogation pour <DNT>Google Distributed Cloud Edge</DNT> est de 5 minutes. La résolution est de 1 point de données par minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

New Relic collecte toutes les métriques <DNT>Distributed Cloud Edge</DNT> disponibles dans <DNT>GCP Cloud Monitoring</DNT> en tant que métriques dimensionnelles dans le type d&apos;événement `Metric`.

Cette intégration ne crée pas d’entités dans l’explorateur d’entités de New Relic. Interrogez ses métriques directement sur le type d’événement `Metric`, par exemple :

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'gcp.edgecontainer.%' FACET metricName
```

Les métriques contiennent les labels de ressource de la machine ou du cluster edge sous-jacent, ce qui vous permet de créer des facettes par nom de cluster, ID de machine, et emplacement sans entité.
