Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec la [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de [Firebase App Hosting](https://firebase.google.com/docs/app-hosting) à New Relic. Ce document explique comment activer l&apos;intégration GCP Firebase App Hosting et décrit les données qu&apos;elle signale.

## Caractéristiques

Firebase App Hosting est le service d’hébergement géré de Google pour les applications web dynamiques avec rendu côté serveur, créées avec des frameworks tels que Next.js et Angular. L’intégration New Relic Firebase App Hosting collecte le débit des requêtes et le volume de trafic des réponses pour chaque backend App Hosting.

## Activer l&apos;intégration [#activate]

<Callout variant="important">
  Cette intégration est disponible uniquement lorsque vous connectez votre projet GCP avec Workload Identity Federation. Elle n’est pas disponible pour les connexions de compte de service ou de compte utilisateur.
</Callout>

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure) avec Workload Identity Federation.

## Fréquence des sondages [#polling]

L’intégration New Relic interroge vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d’interrogation pour Firebase App Hosting est de 5 minutes. La résolution est de 1 point de données chaque minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Toutes les métriques Firebase App Hosting disponibles dans le monitoring cloud GCP sont collectées en tant que métriques dimensionnelles dans le type d&apos;événement `Metric`.

Cette intégration ne crée pas d’entités dans l’explorateur d’entités de New Relic. Interrogez ses métriques directement sur le type d’événement `Metric`, par exemple :

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'gcp.firebaseapphosting.%' FACET metricName
```
