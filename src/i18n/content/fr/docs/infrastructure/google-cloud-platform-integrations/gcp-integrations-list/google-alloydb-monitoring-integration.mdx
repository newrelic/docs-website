Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec la [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de [Google Cloud AlloyDB](https://cloud.google.com/alloydb) à New Relic. Ce document explique comment activer l’intégration GCP AlloyDB et décrit les données qu’elle signale.

## Caractéristiques

AlloyDB est un service de bases de données entièrement géré, compatible avec PostgreSQL, conçu pour les workload transactionnels et analytiques exigeants. L’intégration New Relic AlloyDB collecte des métriques de performances, de disponibilité et d’utilisation des ressources sur les cluster, les instance, les base de données et les nœuds d’instance.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

Les intégrations New Relic interrogent vos services GCP selon un intervalle d&apos;interrogation qui varie selon l&apos;intégration. La fréquence d&apos;interrogation pour Google Cloud AlloyDB est de 5 minutes. La résolution est de 1 point de données par minute.

<Callout variant="important">
  AlloyDB for PostgreSQL prend en charge des intervalles d’interrogation de 1 minute pour les intégrations WIF en version préliminaire limitée. Pour demander l’accès, contactez [le support New Relic](https://support.newrelic.com/).
</Callout>

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Une fois que vous avez activé l&apos;intégration, vos ressources AlloyDB apparaissent sous forme d&apos;entité dans l&apos;explorateur d&apos;entités de New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques AlloyDB disponibles dans le monitoring cloud de GCP sont collectées en tant que métriques dimensionnelles dans le type d’événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation sur les métriques AlloyDB de Google](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-alloydb) pour obtenir la liste complète.
