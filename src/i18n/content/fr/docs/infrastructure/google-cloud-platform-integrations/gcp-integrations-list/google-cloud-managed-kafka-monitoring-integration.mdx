[Les intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de [Google Cloud Managed Service for Apache Kafka](https://cloud.google.com/managed-service-for-apache-kafka) à New Relic. Ce document explique comment activer l&apos;intégration GCP Managed Kafka et décrit les données qu&apos;elle signale.

## Caractéristiques

Managed Service for Apache Kafka est la plateforme de streaming entièrement gérée de Google Cloud, compatible avec Apache Kafka, incluant Kafka Connect. L’intégration New Relic Managed Kafka collecte les métriques de débit, de décalage, de rétention et de santé des connecteurs à travers les clusters, les topics, les partitions, les groupes de consommateurs, ainsi que les clusters et connecteurs Kafka Connect.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec workload Identity Federation](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

Les intégrations New Relic interrogent vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d&apos;interrogation pour Google Cloud Managed Kafka est de 5 minutes. La résolution est de 1 point de données par minute.

<Callout variant="important">
  Managed Service for Apache Kafka prend en charge des intervalles d’interrogation de 1 minute pour les intégrations WIF en version préliminaire limitée. Pour demander l&apos;accès, contactez le [support New Relic](https://support.newrelic.com/).
</Callout>

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Après avoir activé l’intégration, vos ressources Managed Kafka apparaissent en tant qu’entités dans l’explorateur d’entités de New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques Managed Kafka disponibles dans le monitoring cloud GCP sont collectées en tant que métriques dimensionnelles dans le type d&apos;événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation sur les métriques Managed Kafka de Google](https://cloud.google.com/monitoring/api/metrics_gcp_i_o#gcp-managedkafka) pour obtenir la liste complète.
