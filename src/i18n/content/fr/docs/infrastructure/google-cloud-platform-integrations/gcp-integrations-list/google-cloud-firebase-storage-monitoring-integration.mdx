Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de [Google Firebase Storage](https://firebase.google.com/products/storage) à New Relic. Ce document explique comment activer l’intégration GCP Firebase Storage et décrit les données qu’elle signale.

## Caractéristiques

Firebase Storage est le service de stockage d&apos;objets de Google Cloud pour le contenu généré par l&apos;utilisateur dans les applications Firebase, soutenu par des buckets Cloud Storage. L&apos;intégration Firebase Storage de New Relic collecte la métrique d&apos;évaluation des règles de sécurité Firebase Storage pour chaque bucket.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

Les intégrations New Relic interrogent vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d’interrogation pour Google Firebase Storage est de 5 minutes. La résolution est de 1 point de données par minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Une fois que vous avez activé l&apos;intégration, vos buckets Firebase Storage apparaissent sous forme d&apos;entité dans l&apos;explorateur d&apos;entités de New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques Firebase Storage disponibles dans le monitoring cloud de GCP sont collectées en tant que métriques dimensionnelles dans le type d&apos;événement `Metric`. Consultez la [documentation sur les métriques Firebase Storage de Google](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-firebasestorage) pour obtenir la liste complète.
