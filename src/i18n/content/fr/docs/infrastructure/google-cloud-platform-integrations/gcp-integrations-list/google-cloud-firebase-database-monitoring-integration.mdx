[Les intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de la [base de données Google Firebase Realtime](https://firebase.google.com/products/realtime-database) à New Relic. Ce document explique comment activer l’intégration de la base de données GCP Firebase et décrit les données qu’elle signale.

## Caractéristiques

Firebase Realtime Database est la base de données cloud NoSQL de Google Cloud qui vous permet de stocker et de synchroniser des données entre les utilisateurs en temps réel. L’intégration New Relic de la base de données Firebase collecte les métriques d’I/O, de réseau, de stockage, de connexion et de règles de sécurité pour chaque espace de nommage de base de données.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

Les intégrations New Relic interrogent vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d’interrogation pour la base de données Google Cloud Firebase est de 5 minutes. La résolution est de 1 point de données chaque minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Après avoir activé l&apos;intégration, vos ressources de base de données Firebase apparaissent en tant qu&apos;entités dans l&apos;explorateur d&apos;entités de New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques de base de données Firebase disponibles dans le monitoring cloud de GCP sont collectées en tant que métriques dimensionnelles dans le type d’événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation de Google sur les métriques de base de données Firebase](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-firebasedatabase) pour obtenir la liste complète.
