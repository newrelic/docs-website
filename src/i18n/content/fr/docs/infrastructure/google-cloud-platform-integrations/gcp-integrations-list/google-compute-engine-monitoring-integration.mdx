[Les intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec la [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de [Google Compute Engine](https://cloud.google.com/compute) à New Relic. Ce document explique comment activer l&apos;intégration GCP Compute Engine et décrit les données qu&apos;elle signale.

## Caractéristiques

Compute Engine est l&apos;infrastructure en tant que service principale de Google Cloud pour les machines virtuelles et les disques attachés. L&apos;intégration New Relic Compute Engine collecte les métriques de CPU, de mémoire, de disque, de réseau et de temps de disponibilité pour chaque instance de machine virtuelle et ses disques persistants.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/connect-google-cloud-platform-services-infrastructure)

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Une fois que vous avez activé l&apos;intégration, vos ressources Compute Engine apparaissent sous forme d&apos;entités dans l&apos;explorateur d&apos;entités de New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques Compute Engine disponibles dans le monitoring cloud de GCP sont collectées en tant que métriques dimensionnelles dans le type d&apos;événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation de Google sur les métriques Compute Engine](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-compute) pour obtenir la liste complète.
