[Les intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec la [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de [Google Cloud Storage](https://cloud.google.com/storage) à New Relic. Ce document explique comment activer l&apos;intégration GCP Cloud Storage et décrit les données qu&apos;elle signale.

## Caractéristiques

Google Cloud Storage est le service de stockage d’objets de GCP pour la diffusion de contenu de site Web, l’archivage et la reprise après sinistre, et la distribution d’objets de données via un téléchargement direct. L’intégration New Relic Cloud Storage collecte les métriques de requête d’API, de réseau, de nombre d’objets et d’octets stockés pour chaque bucket.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

Les intégrations New Relic interrogent vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d’interrogation pour Google Cloud Storage est de 5 minutes. La résolution est de 1 point de données par minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Une fois que vous avez activé l&apos;intégration, vos buckets Cloud Storage apparaissent sous forme d&apos;entité dans l&apos;explorateur d&apos;entités de New Relic. Pour voir les dashboards et gérer les services, allez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques Cloud Storage disponibles dans le monitoring cloud de GCP sont collectées en tant que métriques dimensionnelles dans le type d’événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation sur les métriques Cloud Storage de Google](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-storage) pour obtenir la liste complète.

## Compte de service ou compte utilisateur [#service-account]

### Rechercher et utiliser des données [#find-data]

Après avoir connecté l&apos;intégration à New Relic et attendu quelques minutes, les données apparaîtront dans l&apos;UI de New Relic. Pour [rechercher et utiliser les données d&apos;intégration](/docs/telemetry-data-platform/understand-data/new-relic-data-types/), y compris vos <InlinePopover type="dashboards" />et vos paramètres d&apos;alerte, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; Google Cloud Storage</DNT>.

Pour créer un dashboard personnalisé pour l&apos;intégration, [créez une requête](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights) pour le type d&apos;événement `GcpStorageBucketSample` avec la valeur du fournisseur `GcpStorageBucket`.

### GcpStorageBucketSample [#gcp-storage-bucket-sample]

L&apos;intégration rapporte [des données métriques](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics) pour toutes les valeurs de `method` et `response_code`:

* `response_code`: Le code de réponse des requests.
* `method`: Le nom de la méthode API appelée.
