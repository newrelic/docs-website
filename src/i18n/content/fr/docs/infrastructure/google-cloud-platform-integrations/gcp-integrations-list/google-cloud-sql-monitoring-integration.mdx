Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec la [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données [Google Cloud SQL](https://cloud.google.com/sql/docs/) à New Relic. Ce document explique comment activer l’intégration GCP Cloud SQL et décrit les données qu’elle signale.

## Caractéristiques

Cloud SQL est le service de bases de données entièrement géré de Google Cloud pour MySQL, PostgreSQL et SQL Server. L’intégration Cloud SQL de New Relic collecte les métriques de CPU, de mémoire, de disque, de connexion, de réplication et au niveau de la base de données pour chaque instance Cloud SQL et ses bases de données.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

Les intégrations de New Relic interrogent vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d’interrogation pour Google Cloud SQL est de 5 minutes. La résolution est de 1 point de données chaque minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Une fois que vous avez activé l’intégration, vos ressources Cloud SQL apparaissent sous forme d’entité dans l’explorateur d’entités de New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques Cloud SQL disponibles dans le monitoring cloud GCP sont collectées en tant que métriques dimensionnelles dans le type d&apos;événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation des métriques Cloud SQL de Google](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-cloudsql) pour obtenir la liste complète.

## Compte de service ou compte utilisateur [#service-account]

### Rechercher et utiliser des données [#find-data]

Après avoir activé l&apos;intégration et attendu quelques minutes (en fonction de la [fréquence d&apos;interrogation](#polling)), les données apparaîtront dans l&apos;UI de New Relic. Pour [rechercher et utiliser vos données](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), y compris les liens vers vos <InlinePopover type="dashboards" />et vos paramètres d&apos;alerte, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

Pour afficher [les données métriques](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics) de votre intégration GCP SQL dans New Relic, [créez une requête NRQL ](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql)pour [l&apos;événement](/docs/data-apis/understand-data/new-relic-data-types/#event-data) `GcpCloudSqlSample` et son attribut associé.
