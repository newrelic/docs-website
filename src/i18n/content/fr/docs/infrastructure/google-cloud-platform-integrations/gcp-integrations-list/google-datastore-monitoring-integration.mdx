Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de [Google Cloud datastore](https://cloud.google.com/datastore) à New Relic. Ce document explique comment activer l&apos;intégration GCP datastore et décrit les données qu&apos;elle signale.

## Caractéristiques

Cloud Datastore est la base de données de documents NoSQL de Google Cloud pour les applications web et mobiles. L&apos;intégration de Datastore de New Relic collecte les métriques de requête d&apos;API, de lecture/écriture d&apos;entité et d&apos;écriture d&apos;index, avec des répartitions par méthode d&apos;API, code de réponse et type d&apos;entité.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

Les intégrations New Relic interrogent vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d’interrogation pour Google Cloud datastore est de 5 minutes. La résolution est de 1 point de données par minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Après avoir activé l&apos;intégration, vos ressources datastore apparaissent en tant qu&apos;entités dans l&apos;explorateur d&apos;entités New Relic. Pour consulter les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques datastore disponibles dans le monitoring cloud GCP sont collectées en tant que métriques dimensionnelles dans le type d&apos;événement `Metric`. Des métriques supplémentaires en dehors de ce tableau sont collectées automatiquement. Consultez la [documentation sur les métriques datastore de Google](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-datastore) pour obtenir la liste complète.

## Compte de service ou compte utilisateur [#service-account]

### Rechercher et utiliser des données [#find-data]

Après avoir activé l&apos;intégration et attendu quelques minutes (en fonction de la [fréquence d&apos;interrogation](#polling)), les données apparaîtront dans l&apos;UI de New Relic. Pour [rechercher et utiliser vos données](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), y compris les liens vers vos <InlinePopover type="dashboards" />et vos paramètres d&apos;alerte, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.
