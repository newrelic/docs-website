Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec la [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données [Google Cloud Dataproc](https://cloud.google.com/dataproc) à New Relic. Ce document explique comment activer l&apos;intégration GCP Dataproc et décrit les données qu&apos;elle signale.

## Caractéristiques

Cloud Dataproc est le service géré de Google Cloud pour exécuter Apache Hadoop, Apache Spark et d&apos;autres workloads open source de traitement des données. L&apos;intégration New Relic Dataproc collecte les métriques HDFS, YARN, de job et d&apos;opération pour chaque cluster Dataproc.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

Les intégrations New Relic interrogent vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d&apos;interrogation pour Google Cloud Dataproc est de 5 minutes. La résolution est de 1 point de données par minute.

<Callout variant="important">
  Cloud Dataproc prend en charge des intervalles d’interrogation de 1 minute pour les intégrations WIF en version préliminaire limitée. Pour demander l’accès, contactez le [support New Relic](https://support.newrelic.com/).
</Callout>

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Une fois que vous avez activé l’intégration, vos ressources Dataproc apparaissent sous forme d’entités dans l’explorateur d’entités de New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques Dataproc disponibles dans le monitoring cloud GCP sont collectées en tant que métriques dimensionnelles dans le type d&apos;événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation de Google sur les métriques Dataproc](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-dataproc) pour obtenir la liste complète.
