[Les intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec la [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de [Google Memorystore for Valkey](https://cloud.google.com/memorystore/docs/valkey) à New Relic. Ce document explique comment activer l&apos;intégration GCP Memorystore for Valkey et décrit les données qu&apos;elle signale.

## Caractéristiques

Memorystore pour Valkey est le service Valkey entièrement géré de Google Cloud, fournissant un magasin de données en mémoire open source compatible avec Redis. L’intégration New Relic Memorystore pour Valkey collecte des métriques au niveau de l’instance et par nœud sur le processeur, la mémoire, les clients, l’espace clé, la persistance et le réseau pour chaque déploiement Valkey.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec workload Identity Federation](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

Les intégrations New Relic interrogent vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d’interrogation de Google Memorystore pour Valkey est de 5 minutes. La résolution est de 1 point de données par minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Une fois que vous avez activé l’intégration, vos ressources Memorystore for Valkey apparaissent sous forme d’entité dans l’explorateur d’entités New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques Memorystore pour Valkey disponibles dans le monitoring cloud de GCP sont collectées en tant que métriques dimensionnelles dans le type d’événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation sur les métriques Memorystore de Google](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-memorystore) pour obtenir la liste complète.
