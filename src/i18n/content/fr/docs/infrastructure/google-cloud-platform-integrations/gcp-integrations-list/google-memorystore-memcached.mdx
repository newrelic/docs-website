Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec la [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de [Google Memorystore for Memcached](https://cloud.google.com/memorystore/docs/memcached) à New Relic. Ce document explique comment activer l’intégration GCP Memorystore for Memcached et décrit les données qu’elle signale.

## Caractéristiques

Memorystore for Memcached est le service Memcached entièrement géré de Google Cloud. L’intégration New Relic Memorystore for Memcached collecte les métriques de CPU, de mémoire, de connexion, de taux de réussite et de stockage d’éléments au niveau du nœud pour chaque nœud Memcached.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

Les intégrations de New Relic interrogent vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d’interrogation de Google Memorystore for Memcached est de 5 minutes. La résolution est de 1 point de données par minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Une fois que vous avez activé l&apos;intégration, vos ressources Memorystore for Memcached apparaissent sous forme d&apos;entité dans l&apos;explorateur d&apos;entités de New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques Memorystore pour Memcached disponibles dans le monitoring cloud de GCP sont collectées en tant que métriques dimensionnelles dans le type d’événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation de Google sur les métriques Memorystore for Memcached](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-memcache) pour obtenir la liste complète.
