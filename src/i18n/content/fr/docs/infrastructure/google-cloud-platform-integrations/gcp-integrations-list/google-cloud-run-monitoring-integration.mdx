Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec la [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de [Google Cloud Run](https://cloud.google.com/run) à New Relic. Ce document explique comment activer l’intégration GCP Cloud Run et décrit les données qu’elle signale.

## Caractéristiques

Cloud Run est la plateforme de conteneurs sans serveur entièrement gérée de Google Cloud pour l’exécution de services sans état et de tâches ponctuelles. L’intégration New Relic Cloud Run collecte les métriques de requête, de latence, d’utilisation des conteneurs et d’exécution sur les services (via les révisions) et les tâches.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

Les intégrations New Relic interrogent vos services GCP selon un intervalle d’interrogation qui varie selon l&apos;intégration. La fréquence d&apos;interrogation pour Google Cloud Run est de 5 minutes. La résolution est de 1 point de données par minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Une fois que vous avez activé l’intégration, vos ressources Cloud Run apparaissent sous forme d’entités dans l’explorateur d’entités de New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques Cloud Run disponibles dans le monitoring cloud de GCP sont collectées en tant que métriques dimensionnelles dans le type d’événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation sur les métriques Cloud Run de Google](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-run) pour obtenir la liste complète.

Après avoir activé l&apos;intégration et attendu quelques minutes (en fonction de la [fréquence d&apos;interrogation](#polling)), les données apparaîtront dans l&apos;UI de New Relic.     <tr>
      <td>
        `container.BillableInstanceTime`
      </td>

      <td>
        Secondes
      </td>

      <td>
        Temps facturable agrégé à partir de toutes les instances de conteneur de la révision. Pour une instance de conteneur donnée, le temps facturable se produit lorsque l&apos;instance de conteneur démarre ou qu&apos;au moins une demande est en cours de traitement. Le temps facturable est arrondi aux 100 millisecondes les plus proches. Exemples : si une révision avec 2 instances de conteneur a diffusé du trafic en continu au cours de la dernière minute, la valeur est de 2 s/s avec l&apos;aligneur « rate » par défaut. Si une seule requête d&apos;une durée de 30 ms a été reçue par une révision au cours de la dernière minute, elle est arrondie à 100 ms et ramenée en moyenne à 1,7 ms/s sur la minute avec l&apos;aligneur « taux » par défaut.
      </td>
