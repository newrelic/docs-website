Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec la [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données [Google Cloud Firestore](https://cloud.google.com/firestore) à New Relic. Ce document explique comment activer l&apos;intégration GCP Firestore et décrit les données qu&apos;elle signale.

## Caractéristiques

Firestore est la base de données de documents NoSQL sans serveur et entièrement gérée de Google Cloud. L&apos;intégration Firestore de New Relic collecte les métriques de requests d&apos;API, de lecture/écriture de documents et de quotas au niveau de l&apos;instance, ainsi que les métriques au niveau de la request attachées à la ressource de request compatible avec datastore.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

Les intégrations New Relic interrogent vos services GCP selon un intervalle d’interrogation qui varie selon l&apos;intégration. La fréquence d’interrogation pour Google Cloud Firestore est de 5 minutes. La résolution est de 1 point de données par minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Après avoir activé l&apos;intégration, vos ressources Firestore apparaissent en tant qu&apos;entités dans l&apos;explorateur d&apos;entités New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques Firestore disponibles dans le monitoring cloud GCP sont collectées en tant que métriques dimensionnelles dans le type d’événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation sur les métriques Firestore de Google](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-firestore) pour obtenir la liste complète.
