Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de [Google Cloud API Gateway](https://cloud.google.com/api-gateway) à New Relic. Ce document explique comment activer l’intégration GCP API Gateway et décrit les données qu’elle signale.

## Caractéristiques

Google Cloud API Gateway est un service entièrement géré pour créer, sécuriser et monitorer des API devant les services backend de Google Cloud. L’intégration New Relic API Gateway collecte le trafic des requêtes et les métriques de code de réponse pour chaque gateway, avec des répartitions par configuration d’API et classe de code de réponse.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec workload Identity Federation](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

L’intégration New Relic interroge vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d&apos;interrogation pour Google Cloud API Gateway est de 5 minutes. La résolution est de 1 point de données chaque minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Après avoir activé l&apos;intégration, vos ressources API Gateway apparaissent en tant qu&apos;entités dans l&apos;explorateur d&apos;entités de New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques API Gateway disponibles dans le monitoring cloud GCP sont collectées en tant que métriques dimensionnelles dans le type d&apos;événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation sur les métriques API Gateway de Google](https://cloud.google.com/monitoring/api/metrics_gcp_a_b#gcp-apigateway) pour obtenir la liste complète.
