Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de [Google Cloud Composer](https://cloud.google.com/composer) à New Relic. Ce document explique comment activer l’intégration GCP Cloud Composer et décrit les données qu’elle signale.

## Caractéristiques

Cloud Composer est le service d&apos;orchestration de workflow entièrement géré de Google Cloud basé sur Apache Airflow. L&apos;intégration New Relic Cloud Composer collecte les métriques d&apos;environnement, de workload et de workflow — exécutions de DAG, instances de tâche, pulsations du planificateur et utilisation des ressources des workers.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

Les intégrations de New Relic interrogent vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d’interrogation de Google Cloud Composer est de 5 minutes. La résolution est de 1 point de données par minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Après avoir activé l’intégration, vos ressources Cloud Composer apparaissent en tant qu’entités dans l’explorateur d’entités New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques Cloud Composer disponibles dans le monitoring cloud GCP sont collectées en tant que métriques dimensionnelles dans le type d’événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation sur les métriques Cloud Composer de Google](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-composer) pour obtenir la liste complète.
