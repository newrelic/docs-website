Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec la [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de [Google Firebase Authentication](https://firebase.google.com/products/auth) à New Relic. Ce document explique comment activer l’intégration GCP Firebase Authentication et décrit les données qu’elle signale.

## Caractéristiques

Firebase Authentication est le service d’identité de Google Cloud qui fournit des SDK et des fournisseurs d’authentification faciles à utiliser pour la connexion fédérée, par téléphone, par e-mail/mot de passe et l’authentification anonyme. L’intégration New Relic Firebase Authentication collecte des métriques de vérification par téléphone pour chaque locataire Firebase Auth.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec workload Identity Federation](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

L’intégration New Relic interroge vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d’interrogation pour Google Cloud Firebase Authentication est de 5 minutes. La résolution est de 1 point de données chaque minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Après avoir activé l&apos;intégration, vos ressources Firebase Authentication apparaissent en tant qu&apos;entités dans l&apos;explorateur d&apos;entités de New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques Firebase Authentication disponibles dans le monitoring cloud GCP sont collectées en tant que métriques dimensionnelles dans le type d’événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation de Google sur les métriques Firebase Authentication](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-firebaseauth) pour obtenir la liste complète.
