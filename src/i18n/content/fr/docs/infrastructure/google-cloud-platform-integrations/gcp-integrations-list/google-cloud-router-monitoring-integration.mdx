[Les intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec la [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de [Google Cloud Router](https://cloud.google.com/network-connectivity/docs/router) à New Relic. Ce document explique comment activer l&apos;intégration GCP Cloud Router et décrit les données qu&apos;elle signale.

## Caractéristiques

Cloud Router est le service de routage BGP entièrement géré de Google Cloud pour Cloud VPN, Cloud Interconnect et Cloud NAT. L’intégration New Relic Cloud Router collecte les métriques de session BGP, d’annonce de route et de gateway NAT (connexions ouvertes, trafic, paquets abandonnés) pour chaque Cloud Router et Gateway NAT.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

L’intégration New Relic interroge vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d&apos;interrogation de Google Cloud Router est de 5 minutes. La résolution est de 1 point de données chaque minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Une fois que vous avez activé l’intégration, vos ressources Cloud Router apparaissent sous forme d’entité dans l’explorateur d’entités de New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques de Cloud Router disponibles dans le monitoring cloud de GCP sont collectées en tant que métriques dimensionnelles dans le type d&apos;événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation sur les métriques de Cloud Router de Google](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-router) pour obtenir la liste complète.
