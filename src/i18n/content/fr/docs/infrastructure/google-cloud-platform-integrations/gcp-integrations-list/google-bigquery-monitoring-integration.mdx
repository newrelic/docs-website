Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données [Google BigQuery](https://cloud.google.com/bigquery/) à New Relic. Ce document explique comment activer l&apos;intégration GCP BigQuery et décrit les données qu&apos;elle signale.

## Caractéristiques

BigQuery est l’entrepôt de données sans serveur de Google Cloud. L’intégration BigQuery de New Relic collecte les métriques de requête, d’exécution, de stockage et d’utilisation des slots à l’échelle du projet et du jeu de données.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

Les intégrations New Relic interrogent vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d’interrogation pour Google BigQuery est de 5 minutes. La résolution est de 1 point de données chaque minute.

<Callout variant="important">
  BigQuery prend en charge des intervalles d’interrogation de 1 minute pour les intégrations WIF en version préliminaire limitée. Pour demander l’accès, contactez le [support New Relic](https://support.newrelic.com/).
</Callout>

## Activer les métriques du tableau [#table-metrics]

La collecte des métriques de table BigQuery est désactivée par défaut. Cela affecte les métriques répertoriées sous [GcpBigQueryTableSample](#table-sample). Pour collecter ces métriques, activez le paramètre « Activer les métriques de table » dans le menu de configuration de l&apos;intégration BigQuery.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Une fois que vous avez activé l’intégration, vos ressources BigQuery apparaissent sous forme d’entité dans l’explorateur d’entités New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques BigQuery disponibles dans le monitoring cloud GCP sont collectées en tant que métriques dimensionnelles dans le type d’événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation sur les métriques BigQuery de Google](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-bigquery) pour obtenir la liste complète.

## Compte de service ou compte utilisateur [#service-account]

### Rechercher et utiliser des données [#find-data]

Après avoir activé l&apos;intégration et attendu quelques minutes (en fonction de la [fréquence d&apos;interrogation](#polling)), les données apparaîtront dans l&apos;UI de New Relic. Pour [rechercher et utiliser vos données](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), y compris les liens vers vos <InlinePopover type="dashboards" />et vos paramètres d&apos;alerte, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

Pour afficher [les données métriques](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics) de votre intégration Google BigQuery dans New Relic, [créez une requête NRQL ](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql)pour `GcpBigQueryProjectSample`, `GcpBigQueryDatasetSample` et `GcpBigQueryTableSample` [événement](/docs/using-new-relic/welcome-new-relic/getting-started/glossary#event) et leur attribut.
