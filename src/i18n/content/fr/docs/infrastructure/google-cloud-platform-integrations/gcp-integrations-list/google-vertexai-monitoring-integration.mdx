[Les intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec la [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui transmet les données de [Google Cloud Vertex AI](https://cloud.google.com/vertex-ai) à New Relic. Ce document explique comment activer l&apos;intégration GCP Vertex AI et décrit les données qu&apos;elle signale.

## Caractéristiques

Vertex AI est la plateforme unifiée de Google Cloud pour créer, déployer et gérer des modèles d’apprentissage automatique et des applications d’IA générative. L’intégration de New Relic Vertex AI collecte des métriques de performance, de débit, de latence et d’utilisation des ressources à travers les emplacements, les points de terminaison, les index, les magasins de fonctionnalités et les magasins de fonctionnalités en ligne.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account)

## Fréquence des sondages [#polling]

Les intégrations New Relic interrogent vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d’interrogation pour Google Cloud Vertex AI est de 5 minutes. La résolution est de 1 point de données chaque minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Une fois que vous avez activé l’intégration, vos ressources Vertex AI apparaissent sous forme d’entités dans l’explorateur d’entités New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques Vertex AI disponibles dans le monitoring cloud de GCP sont collectées en tant que métriques dimensionnelles dans le type d&apos;événement `Metric`. Des métriques supplémentaires en dehors de ce tableau sont collectées automatiquement. Consultez la [documentation de Google sur les métriques Vertex AI](https://cloud.google.com/monitoring/api/metrics_gcp_a_b#gcp-aiplatform) pour obtenir la liste complète.
