Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec le [<DNT>Google Cloud Platform</DNT> (<DNT>GCP</DNT>)](https://cloud.google.com/) en incluent une qui rapporte les données [<DNT>Gemini Enterprise</DNT>](https://cloud.google.com/gemini-enterprise) à New Relic. Ce document explique comment activer l’intégration <DNT>GCP Gemini Enterprise</DNT>, et décrit les données qu’elle rapporte.

## Caractéristiques

<DNT>Gemini Enterprise</DNT> est la plateforme de <DNT>Google Cloud</DNT> pour créer et exécuter des applications de recherche d’entreprise et d’agents d’IA, construite sur <DNT>Discovery Engine</DNT>. L’intégration <DNT>Gemini Enterprise</DNT> de New Relic collecte les métriques de requêtes, de latence, et de session pour les applications (moteurs), les agents, les outils que ces agents invoquent, et les connecteurs de données, ainsi que le nombre de ressources et la consommation de quotas par emplacement et par utilisateur.

## Activer l&apos;intégration [#activate]

<Callout variant="important">
Cette intégration est disponible uniquement lorsque vous connectez votre projet <DNT>GCP</DNT> avec <DNT>**Workload Identity Federation**</DNT>. Elle n’est pas disponible pour les connexions de compte de service ou de compte utilisateur.
</Callout>

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service <DNT>GCP</DNT> à New Relic](/docs/connect-google-cloud-platform-services-infrastructure) avec <DNT>**Workload Identity Federation**</DNT>.

## Fréquence des sondages [#polling]

Les intégrations New Relic interrogent vos services <DNT>GCP</DNT> selon un intervalle d’interrogation qui varie selon l&apos;intégration. La fréquence d&apos;interrogation pour <DNT>Gemini Enterprise</DNT> est de 5 minutes. La résolution est de 1 point de données par minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Après avoir activé l&apos;intégration, vos ressources <DNT>Gemini Enterprise</DNT> apparaissent en tant qu&apos;entités dans l&apos;explorateur d&apos;entités de New Relic. Pour consulter les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

New Relic collecte <DNT>Gemini Enterprise</DNT> métriques disponibles dans <DNT>GCP Cloud Monitoring</DNT> en tant que métriques dimensionnelles dans le type d&apos;événement `Metric`, par exemple :

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'gcp.discoveryengine.%' FACET metricName
```

#### Métriques d’emplacement

Les métriques d’emplacement sont des agrégats par emplacement pour votre projet. Elles incluent le nombre de ressources, comme le nombre de moteurs, de data stores, de documents, et d’événements utilisateur, et le volume de requests de recherche. Elles incluent également l’utilisation, les limites, et le nombre de dépassements de limite pour plus de 140 quotas <DNT>Gemini Enterprise</DNT>, couvrant des domaines tels que les agents, la génération d’images et de vidéos, l’ancrage sur le Web, et les requests de recherche.

La plupart des métriques d’emplacement sont des métriques de quota. Chaque quota est rapporté sous forme d’un maximum de trois métriques, nommées en ajoutant un suffixe `usage`, `limit`, ou `exceeded`, par exemple `gcp.discoveryengine.quota.search_requests_regional.usage`. Les métriques de quota portent les étiquettes `metric.limit_name`, et `metric.regional_location`.

L’emplacement définit également des métriques hors quota, telles que `gcp.discoveryengine.engines_regional`. <DNT>Google Cloud</DNT> ne rapporte pas de données pour celles-ci dans chaque projet, et lorsqu’il ne le fait pas, elles n’apparaissent pas dans New Relic. Les mêmes décomptes sont également signalés comme métriques de quota, par exemple `gcp.discoveryengine.quota.engines_regional.usage`.

Pour obtenir la liste complète des métriques d’emplacement, consultez la section `discoveryengine` de la [référence des métriques de Cloud Monitoring de Google](https://docs.cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-discoveryengine). New Relic collecte les métriques GA et bêta qui y sont répertoriées.
