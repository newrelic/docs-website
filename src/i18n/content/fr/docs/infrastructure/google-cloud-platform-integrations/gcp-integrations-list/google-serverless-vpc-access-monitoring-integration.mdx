Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec la [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données [Google Cloud Serverless VPC Access](https://cloud.google.com/vpc/docs/serverless-vpc-access) à New Relic. Ce document explique comment activer l’intégration GCP Serverless VPC Access et décrit les données qu’elle signale.

## Caractéristiques

L&apos;accès au VPC Serverless permet aux services Serverless sur Google Cloud (Cloud Run, Cloud Functions, App Engine) d&apos;accéder aux ressources à IP interne au sein d&apos;un réseau VPC via des connecteurs gérés. L&apos;intégration New Relic VPC Access collecte les métriques de nombre d&apos;instances, de CPU, de mémoire et de débit réseau pour chaque connecteur.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

L’intégration New Relic interroge vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d&apos;interrogation pour Google Cloud Serverless VPC Access est de 5 minutes. La résolution est de 1 point de données chaque minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Une fois que vous avez activé l’intégration, vos connecteurs VPC Access apparaissent sous forme d’entité dans l’explorateur d’entités de New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques Serverless VPC Access disponibles dans le monitoring cloud de GCP sont collectées en tant que métriques dimensionnelles dans le type d’événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation de Google sur les métriques Serverless VPC Access](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-vpcaccess) pour obtenir la liste complète.

## Compte de service ou compte utilisateur [#service-account]

### Rechercher et utiliser des données [#find-data]

Après avoir activé l&apos;intégration et attendu quelques minutes (en fonction de la [fréquence d&apos;interrogation](#polling)), les données apparaîtront dans l&apos;UI de New Relic. Pour [rechercher et utiliser vos données](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), y compris les liens vers vos <InlinePopover type="dashboards" />et vos paramètres d&apos;alerte, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

Les données sont jointes au [type d’événement](/docs/data-apis/understand-data/new-relic-data-types/#event-data) suivant :
