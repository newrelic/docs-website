Les [intégrations New Relic](/docs/infrastructure/introduction-infra-monitoring) avec la [Google Cloud Platform (GCP)](https://cloud.google.com/) en incluent une qui signale les données de [Google App Engine](https://cloud.google.com/appengine/) à New Relic. Ce document explique comment activer l’intégration GCP App Engine et décrit les données qu’elle signale.

Pour plus d’informations sur le monitoring des applications qui résident dans un environnement Google App Engine avec <InlinePopover type="apm" />(au lieu de monitorer vos services Google App Engine eux-mêmes), consultez [Environnement Google App Engine](/docs/accounts/install-new-relic/partner-based-installation/google-app-engine-environment).

## Caractéristiques

App Engine est un service Google Cloud Platform qui fait abstraction de l’infrastructure sous-jacente pour vos applications mobiles et web. L’intégration App Engine de New Relic collecte les métriques de requête, de réponse, de latence, de mémoire et d’instance pour chaque service App Engine. Les environnements Standard et Flexible sont tous deux pris en charge.

## Activer l&apos;intégration [#activate]

Pour activer l’intégration, suivez les procédures standard pour [connecter votre service GCP à New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Se connecter avec la fédération d&apos;identité de workload (Workload Identity Federation) (recommandé)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Se connecter avec un compte de service ou un compte utilisateur](/docs/connect-google-cloud-platform-services-infrastructure)

## Fréquence des sondages [#polling]

L’intégration New Relic interroge vos services GCP selon un intervalle d’interrogation qui varie selon l’intégration. La fréquence d’interrogation pour Google App Engine est de 5 minutes. La résolution est de 1 point de données chaque minute.

## Fédération d&apos;identité de workload (Workload Identity Federation) [#wif]

### Rechercher et utiliser des données [#find-data-wif]

Après avoir activé l’intégration, vos ressources App Engine apparaissent en tant qu’entités dans l’explorateur d’entités New Relic. Pour voir les dashboards et gérer les services, accédez à <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toutes les métriques App Engine disponibles dans le monitoring cloud de GCP sont collectées en tant que métriques dimensionnelles dans le type d’événement `Metric`. Des métriques supplémentaires au-delà de ce tableau sont collectées automatiquement. Consultez la [documentation sur les métriques App Engine de Google](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-appengine) pour obtenir la liste complète.

## données métriques [#metrics]

Pour afficher [les données métriques](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics) de votre intégration de Google App Engine dans New Relic, [créez une requête NRQL ](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql)pour [l&apos;événement](/docs/data-apis/understand-data/new-relic-data-types/#event-data) `GcpAppEngineServiceSample` et `GcpCloudTasksQueueSample` et leur attribut associé.

<Callout variant="important">
  Différentes métriques sont disponibles selon que votre application s&apos;exécute dans un [environnement standard ou flexible](#environments), donc certaines métriques peuvent ne pas être disponibles pour votre application.
</Callout>
