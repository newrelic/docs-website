Cette page couvre les problèmes courants avec les intégrations Google Cloud Platform (GCP) de New Relic et comment les résoudre.

## Aucune donnée n’apparaît après la configuration [#no-data]

### Vérifiez les bases [#no-data-basics]

* Attendez 5 minutes après avoir terminé la configuration. Les données mettent quelques minutes à arriver.
* Confirmez que vous avez sélectionné au moins un service lors de la configuration.
* Vérifiez que <DNT>**Stackdriver Monitoring API**</DNT> est activé dans votre projet GCP.

### Intégration de Workload Identity Federation [#no-data-wif]

Si vous vous êtes connecté avec la [fédération d&apos;identité de workload (WIF)](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation):

* Vérifiez que les cinq [API requises](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation#step-2) sont activées.
* Confirmez que le compte de service possède les rôles <DNT>**Viewer**</DNT> et <DNT>**Service Usage Consumer**</DNT>.
* Vérifiez que le rôle <DNT>**Workload Identity User**</DNT> est accordé au principal du pool sur votre compte de service.

### Intégration du compte de service [#no-data-sa]

Si vous vous êtes connecté avec un [compte de service New Relic](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account):

* Vérifiez que l&apos;ID du compte de service New Relic apparaît dans l&apos;IAM de votre projet.
* Confirmez qu&apos;il possède les rôles <DNT>**Viewer**</DNT> et <DNT>**Service Usage Consumer**</DNT>.
* Si vous utilisez des [contraintes de restriction de domaine](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account#reqs), assurez-vous que New Relic est autorisé.

## Erreurs d’authentification [#auth-errors]

### Réautoriser New Relic [#reauthorize]

Si vous voyez des erreurs d’authentification API lorsque vous [intégrez vos services Google Cloud Platform (GCP)](/docs/introduction-google-cloud-platform-integrations) à New Relic, autorisez à nouveau New Relic à utiliser vos API GCP :

1. Allez à <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP**</DNT>.
2. Depuis la page de votre compte GCP, sélectionnez <DNT>**Reauthorize New Relic**</DNT>.
3. Suivez les procédures standards pour [connecter vos services GCP à New Relic](/docs/infrastructure/google-cloud-platform-integrations/get-started/connect-google-cloud-platform-services-new-relic).

Si la réautorisation ne résout pas les erreurs, vous pouvez dissocier l’intégration et vous connecter à nouveau. Consultez les étapes de dissociation dans votre [guide de connexion](/docs/infrastructure/google-cloud-platform-integrations/get-started/connect-google-cloud-platform-services-new-relic).

Les raisons courantes de ces erreurs incluent :

* Un utilisateur a révoqué manuellement l’autorisation de New Relic d’utiliser les API GCP depuis l’application de gestion de compte Google.
* L&apos;autorisation pour New Relic d&apos;utiliser les API GCP n&apos;inclut pas une ou plusieurs des autorisations ([étendues Google OAuth](https://developers.google.com/identity/protocols/googlescopes)) nécessaires pour interroger une ou plusieurs des API GCP.
* L&apos;autorisation pour New Relic d&apos;utiliser les API GCP a expiré.

## Métriques manquantes pour un service spécifique [#missing-metrics]

* Confirmez que le service est activé dans <DNT>**Infrastructure &gt; GCP &gt; Manage services**</DNT>.
* Vérifiez que le service GCP lui-même est actif et génère des métriques. Certains services ne rapportent des métriques que lorsqu’ils sont utilisés.
* Si vous utilisez un [rôle IAM personnalisé](/docs/integrations/google-cloud-platform-integrations/get-started/integrations-custom-roles), vérifiez que vous disposez des autorisations spécifiques à ce service.

## Métriques obsolètes ou retardées [#stale-metrics]

* Vérifiez les quotas de l’API de monitoring cloud GCP dans votre projet GCP. Si vous atteignez les limites de débit, la collecte de données peut ralentir.
* Pour les intégrations WIF, vérifiez que le jeton du compte de service n’a pas été révoqué.
* Vérifiez le dashboard d’état du compte dans <DNT>**Infrastructure &gt; GCP**</DNT> pour toute erreur signalée.

## Projets GCP non visibles lors de la configuration [#no-projects]

* Le compte authentifié a besoin de l’autorisation `resourcemanager.projects.get` pour lister les projets.
* Vous pouvez également utiliser l’API NerdGraph pour lier des projets par ID sans avoir besoin de les lister.

## Obtenir plus d&apos;aide [#get-help]

Si aucune des solutions ci-dessus ne résout votre problème, contactez le support New Relic avec :

* Votre ID de compte New Relic.
* L’ID du projet GCP.
* Quelle méthode de connexion vous avez utilisée (WIF ou compte de service).
* Tous les messages d’erreur que vous voyez dans l&apos;interface utilisateur.
