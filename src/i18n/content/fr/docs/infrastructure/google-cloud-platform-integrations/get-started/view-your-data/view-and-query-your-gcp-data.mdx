Une fois que vous avez terminé le processus de configuration, les données de votre compte Google Cloud Platform sont transmises directement à New Relic à des [intervalles d’interrogation](/docs/infrastructure/google-cloud-platform-integrations/get-started/view-your-data/polling-intervals-gcp-integrations) réguliers. Vos données apparaissent dans l’UI de New Relic en quelques minutes.

## Afficher vos données GCP [#view]

Pour afficher vos données GCP :

1. Allez à <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities)**</DNT>.
2. Recherchez <DNT>**Google Cloud Platform**</DNT> et sélectionnez la tuile.

Pour [rechercher et utiliser vos données](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), y compris les liens vers <InlinePopover type="Dashboards" />et les paramètres d&apos;alerte, accédez à <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP**</DNT>.

## Interrogez vos données [#query]

Vous pouvez afficher et réutiliser les requêtes NRQL à la fois dans le dashboard préconfiguré <InlinePopover type="Dashboards" />et dans le dashboard <DNT>**Events explorer**</DNT>. Cela vous permet d&apos;adapter les requêtes à vos besoins spécifiques.

événement, dashboard et autres données sont disponibles pour tous les services dans New Relic.

## Entités GCP [#entities]

Vos ressources GCP apparaissent également en tant qu’entités dans l’explorateur d’entités pour les services avec une prise en charge complète des entités. Chaque entité possède une page de résumé avec des métriques dorées et un dashboard préconfiguré.

Les nouvelles ressources peuvent prendre quelques minutes pour être détectées et synthétisées en tant qu&apos;entités. Pour plus d&apos;informations, consultez [Limites du système des intégrations cloud](/docs/data-apis/manage-data/view-system-limits).

## Et ensuite ? [#whats-next]

* Pour rechercher les noms de métriques que New Relic collecte pour chaque service, consultez les [métriques d’intégration GCP](/docs/infrastructure/google-cloud-platform-integrations/get-started/gcp-integration-metrics).
* Pour comprendre à quelle fréquence New Relic interroge vos données, consultez les [intervalles d’interrogation pour les intégrations GCP](/docs/infrastructure/google-cloud-platform-integrations/get-started/view-your-data/polling-intervals-gcp-integrations).
* Si vos données n&apos;apparaissent pas comme prévu, consultez [Dépanner les intégrations GCP](/docs/infrastructure/google-cloud-platform-integrations/troubleshooting/troubleshooting-gcp-integrations).
