Les intégrations New Relic Google Cloud Platform (GCP) font partie de [New Relic Infrastructure](/docs/infrastructure/new-relic-infrastructure/getting-started/introduction-new-relic-infrastructure) et intègrent les métriques de vos services cloud dans le [monitoring d&apos;infrastructure](/docs/infrastructure), où vous pouvez effectuer des requêtes sur les données, créer des dashboards et configurer des alertes avec le reste de votre télémétrie. Si vous n&apos;avez pas encore de compte New Relic, [créez-en un](https://newrelic.com/signup) avant de commencer.

<Callout variant="important">
  \* Les intervalles d’interrogation de 1 minute pour les intégrations WIF sont en version préliminaire limitée et disponibles uniquement pour certains services. Services actuellement pris en charge par WIF : Managed Service for Apache Kafka, Cloud Dataflow, Cloud Dataproc, Cloud Spanner, Google Kubernetes Engine (GKE), BigQuery, AlloyDB for PostgreSQL, Cloud Load Balancing et Cloud Pub/Sub. Pour demander l&apos;accès, contactez le [support New Relic](https://support.newrelic.com/).
</Callout>

Nous recommandons <DNT>**Workload Identity Federation**</DNT> pour les nouvelles intégrations. Elle utilise des identifiants à courte durée de vie pour une meilleure sécurité, couvre un ensemble plus large de métriques et collecte automatiquement de nouvelles métriques à mesure que GCP les ajoute. Si vous avez déjà une intégration de compte de service, elle continue de fonctionner — vous pouvez ajouter de nouveaux projets avec WIF en parallèle de votre configuration existante.

<Callout variant="important">
  * **Ingestion de données plus élevée :** WIF collecte toutes les métriques généralement disponibles (GA) et bêta ainsi que les étiquettes natives pour les services Google Cloud pris en charge. L’ingestion pour le même ensemble de services est généralement plus élevée qu’avec l’intégration basée sur un compte de service.
  * **Frais d&apos;API Google Cloud :** Google Cloud facture les appels d&apos;API de monitoring cloud effectués par l&apos;intégration WIF au projet Google Cloud intégré. Consultez la [tarification de l&apos;observabilité Google Cloud](https://cloud.google.com/products/observability/pricing) pour plus de détails.
</Callout>

Pour en savoir plus sur les autorisations et les rôles dont New Relic a besoin pour monitorer vos services GCP, consultez [Intégrations et rôles personnalisés](/docs/infrastructure/google-cloud-platform-integrations/get-started/integrations-custom-roles).

## Guides de configuration [#setup-guides]

* **Workload Identity Federation (recommandé)**

  * [Intégrez manuellement votre projet/dossier GCP](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation) — utilise des identifiants à courte durée de vie pour une meilleure sécurité
  * [Automatiser avec Terraform](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation-terraform) — automatise la configuration de WIF à l’aide de Terraform

* [Compte de service New Relic](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account) — utilise un compte de service géré par New Relic

* [Compte utilisateur Google](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-user-account) — utilise les identifiants de votre compte utilisateur Google
