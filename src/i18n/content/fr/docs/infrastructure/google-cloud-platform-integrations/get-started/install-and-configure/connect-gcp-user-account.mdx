Si vous autorisez New Relic à récupérer des données via un compte utilisateur, New Relic accède aux données de monitoring de votre projet GCP au nom d’un utilisateur Google particulier.

New Relic utilise un workflow OAuth pour l’autorisation, qui vous redirige de l’UI de New Relic vers une interface d’autorisation Google. Cependant, comme l’autorisation est liée à un utilisateur Google particulier, nous ne recommandons pas cette méthode pour les projets GCP que de grandes équipes gèrent.

<Callout variant="tip">
  Cette méthode d’autorisation ne permet pas à New Relic de collecter des tags et d’autres attributs qui peuvent être utiles pour affiner vos requêtes NRQL, vos dashboards et vos alertes. Vous pouvez migrer la méthode d’autorisation du compte utilisateur vers le compte de service à partir du lien <DNT>**Manage services**</DNT> dans l’interface utilisateur de New Relic.
</Callout>

## Connecter GCP au monitoring d&apos;infrastructure New Relic [#connect]

<Callout variant="important">
  Si c’est la première fois que vous configurez GCP avec New Relic, assurez-vous que vous avez activé l’API de monitoring cloud pour votre projet. Vous pouvez le faire dans la [console Google Cloud](https://console.cloud.google.com/apis/api/monitoring.googleapis.com/).
</Callout>

Pour connecter votre compte Google à New Relic avec l&apos;autorisation du compte utilisateur :

1. Aller à <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP**</DNT>. Sur la page d&apos;intégration <DNT>**Google Cloud Services**</DNT> , sélectionnez <DNT>**Add a GCP account**</DNT>.

2. <DNT>**Choose Authorization Method**</DNT>: sélectionnez <DNT>**Authorize a User Account**</DNT> et suivez les instructions dans l&apos;UI pour autoriser New Relic.

3. <DNT>**Add projects:**</DNT> Sélectionnez les projets pour lesquels vous souhaitez que New Relic reçoive des données.

4. <DNT>**Select services:**</DNT> Dans la liste des services disponibles pour votre compte GCP, sélectionnez les services individuels à partir desquels vous souhaitez que New Relic reçoive des données, ou sélectionnez tous les services.

   <Callout variant="important">
     New Relic active ces services pour <DNT>**all**</DNT> des projets que vous avez sélectionnés à l’étape précédente. Une fois la configuration terminée, vous pouvez affiner les services que vous souhaitez monitorer pour chaque projet individuellement.
   </Callout>

5. Pour terminer le processus de configuration, sélectionnez <DNT>**Finish**</DNT>.

Si vous rencontrez des erreurs d&apos;authentification d&apos;API, suivez les [procédures de dépannage](/docs/infrastructure/google-cloud-platform-integrations/troubleshooting/troubleshooting-gcp-integrations).

Les nouvelles ressources peuvent prendre quelques minutes pour être détectées et synthétisées en tant qu&apos;entités. Pour plus d’informations, consultez les [limites du système](/docs/data-apis/manage-data/view-system-limits) des intégrations cloud.

## Afficher vos données GCP [#find-data]

Après vous être connecté, New Relic commence à monitorer vos données GCP à des [intervalles d’interrogation](/docs/infrastructure/google-cloud-platform-integrations/get-started/view-your-data/polling-intervals-gcp-integrations) réguliers, et vos données apparaissent dans l&apos;UI de New Relic après quelques minutes. Pour apprendre comment les afficher, les interroger et les explorer — y compris les dashboards, les alertes et les entités —, consultez [Afficher et interroger vos données GCP](/docs/infrastructure/google-cloud-platform-integrations/get-started/view-your-data/view-and-query-your-gcp-data).

## Lier plusieurs projets Google [#connect-multiple]

Le processus de configuration vous permet de sélectionner plus d’un projet à la fois.

Après la première configuration, pour monitorer des projets GCP supplémentaires avec New Relic, répétez la procédure pour [connecter vos services GCP](#connect) autant de fois que vous le souhaitez.

## Désactiver ou dissocier vos intégrations GCP [#disconnect]

Vous pouvez désactiver n’importe laquelle de vos intégrations GCP à tout moment et garder votre projet Google connecté à New Relic.

### Désactiver un ou plusieurs services GCP [#disable-services]

Pour désactiver les services tout en conservant votre compte GCP lié à New Relic :

1. Allez à <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; Manage services**</DNT>.
2. Depuis votre page <DNT>**Edit GCP account**</DNT> , décochez la case de chaque service actif que vous souhaitez désactiver.
3. Enregistrez vos modifications.

### Déconnectez et dissociez votre compte [#unlink-account]

Pour vous déconnecter complètement de New Relic, dissociez votre compte GCP. Cela désactive toutes les intégrations New Relic qui y sont associées.

1. Allez à <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; Manage services**</DNT>.
2. Depuis votre page <DNT>**Edit GCP account**</DNT> , sélectionnez <DNT>**Unlink this account**</DNT>.
3. Enregistrez vos modifications.

### Nettoyer GCP après la dissociation [#clean-up]

Pour nettoyer votre projet GCP après la dissociation :

1. Ouvrez les paramètres de votre compte utilisateur Google.
2. Ouvrez la section <DNT>**Apps with access to your account**</DNT> .
3. Sélectionnez l&apos;application <DNT>**New Relic**</DNT>.
4. Sélectionnez <DNT>**Remove Access**</DNT>.
