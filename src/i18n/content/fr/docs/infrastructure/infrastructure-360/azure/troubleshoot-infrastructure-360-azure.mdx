Nous travaillons toujours sur cette fonctionnalité, mais nous aimerions que vous l&apos;essayiez !

Cette fonctionnalité est actuellement fournie dans le cadre d&apos;un programme d&apos;aperçu conformément à nos [politiques de pré-sortie](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy).

Si vous rencontrez des problèmes avec [<DNT>Infrastructure 360</DNT>](/docs/infrastructure/infrastructure-360/introduction-infrastructure-360) sur <DNT>Azure</DNT>, consultez les scénarios de dépannage suivants.

<CollapserGroup>
<Collapser id="no-entities-appear" title="Aucune entité Azure n’apparaît après l’activation de la découverte automatique">
Si aucune entité n’apparaît après avoir activé la découverte automatique, vérifiez les éléments suivants :

* **Vérifiez les autorisations**: assurez-vous que l’inscription de votre application <DNT>Azure</DNT> dispose des autorisations Lecteur pour l’abonnement et les groupes de ressources nécessaires.
* **Vérifiez l’abonnement**: confirmez que vous avez configuré l’ID d’abonnement <DNT>Azure</DNT> correct dans votre intégration New Relic.
* **Attendez la première analyse**: la découverte initiale peut prendre du temps. Vérifiez à nouveau après la prochaine analyse programmée (par défaut, 3 fois par jour).
* **Vérifiez l’accès à la préversion**: confirmez que vous avez inscrit votre compte New Relic à la préversion <DNT>Infrastructure 360</DNT> en vérifiant <DNT>**Administration &gt; Preview &amp; Trials**</DNT>.
</Collapser>

<Collapser id="missing-relationships" title="Les relations entre entités ne s’affichent pas">
Si les relations entre les entités ne s’affichent pas, vérifiez les éléments suivants :

* **Vérifiez si l’agent APM approprié est installé**: de nombreuses relations exigent que vous installiez des agents New Relic APM qui remontent activement les données de vos applications.
* **Vérifiez le nommage des entités**: assurez-vous que vos ressources <DNT>Azure</DNT> utilisent un nommage cohérent qui permet à la découverte automatique de les associer aux entités APM.
* **Vérifiez la connectivité réseau**: confirmez que vos ressources <DNT>Azure</DNT> peuvent atteindre les collecteurs de données de New Relic.
* **Vérifiez les tags de ressources**: certaines relations dépendent de stratégies de tag appropriées à la fois dans <DNT>Azure</DNT> et dans votre configuration APM.
</Collapser>

<Collapser id="scan-failures" title="Les scans de découverte automatique échouent">
Si vos analyses de découverte automatique échouent systématiquement, vérifiez les éléments suivants :

* **Vérifiez les limites d’API**: assurez-vous de ne pas avoir dépassé les limites de débit d’API de <DNT>Azure</DNT>. Envisagez de réduire temporairement la fréquence d’analyse.
* **Vérifiez l’enregistrement de l’application**: confirmez que l’enregistrement de votre application <DNT>Azure</DNT> est toujours valide et n’a pas expiré.
* **Passez en revue les autorisations**: assurez-vous que l’inscription de l’application dispose toujours des autorisations nécessaires après toute modification de stratégie <DNT>Azure</DNT>.
* **Vérifier le statut de l’abonnement**: vérifiez que votre abonnement <DNT>Azure</DNT> est actif et accessible.
</Collapser>
</CollapserGroup>
