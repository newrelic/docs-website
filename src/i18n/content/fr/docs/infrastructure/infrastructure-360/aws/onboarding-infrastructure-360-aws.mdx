<Callout title="Aperçu">
Nous travaillons toujours sur cette fonctionnalité, mais nous aimerions que vous l&apos;essayiez !

Cette fonctionnalité est actuellement fournie dans le cadre d&apos;un programme d&apos;aperçu conformément à nos [politiques de pré-sortie](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy).
</Callout>

Avant de commencer, consultez [les exigences et les entités prises en charge](/docs/infrastructure/infrastructure-360/aws/prerequisites-infrastructure-360-aws). L&apos;accès à <DNT>Infrastructure 360</DNT> nécessite une inscription à la préversion. Accédez à <DNT>**one.newrelic.com &gt; Administration &gt; Preview &amp; Trials**</DNT> et inscrivez-vous à <DNT>**Infrastructure 360**</DNT>.

Il existe trois façons d’activer <DNT>Infrastructure 360</DNT> pour <DNT>AWS</DNT>.

## Activer lors de l’intégration AWS [#onboarding-enable]

Si vous connectez <DNT>AWS</DNT> à New Relic pour la première fois, activez <DNT>Infrastructure 360</DNT> directement dans le processus d’intégration lorsque vous configurez votre intégration <DNT>AWS</DNT>.

## Activer pour une intégration AWS existante [#existing-enable]

Si vous avez déjà intégré <DNT>AWS</DNT> à New Relic, suivez ces étapes :

<Steps>
<Step>
### Gérer les intégrations AWS [#manage-aws-integrations]

Pour installer <DNT>Infrastructure 360</DNT> via votre intégration <DNT>AWS</DNT> existante :

1. Allez à <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Infrastructure &gt; AWS**</DNT>.
2. Cliquez sur <DNT>**Manage AWS Integrations**</DNT>.
3. Trouvez le compte où vous souhaitez activer <DNT>Infrastructure 360</DNT> et cliquez sur <DNT>**Install**</DNT>.
4. Pour <DNT>**Infrastructure 360**</DNT>, cliquez sur <DNT>**Install**</DNT>, puis sur <DNT>**Launch CloudFormation Template**</DNT>.
</Step>

<Step>
### déployer la stackCloudFormation [#deploy-cloudformation-stack]

Déployez le modèle <DNT>CloudFormation</DNT> que New Relic a généré :

1. Sur la console <DNT>AWS</DNT>, reconnaissez la stack <DNT>CloudFormation</DNT> et cliquez sur <DNT>**Create stack**</DNT>.
2. Attendez que la création des ressources de la stack soit terminée (cela peut prendre plusieurs minutes), puis retournez à New Relic.
</Step>

<Step>
### Configurez la région et la fréquence d&apos;analyse [#select-region-and-frequency]

Par défaut, New Relic analyse toutes les régions activées dans votre compte une fois par jour. Sur le panneau latéral, vous pouvez personnaliser ceci :

* Pour scanner uniquement des régions spécifiques, sélectionnez, ou supprimez des régions selon vos besoins.
* Pour modifier la fréquence d’analyse, sélectionnez un intervalle de 8, 12 ou 16 heures. La durée minimale de l’intervalle est de 8 heures. Les intervalles inférieurs à 8 heures sont automatiquement définis sur 8 heures par défaut.
</Step>

<Step>
### Activer la découverte automatique [#enable-auto-discovery]

Sur l’écran de confirmation, cliquez sur <DNT>**Save**</DNT> pour activer <DNT>Infrastructure 360</DNT> pour ce compte.
</Step>
</Steps>

## Activer depuis la page infrastructure 360 [#landing-page-enable]

Pour activer <DNT>Infrastructure 360</DNT> depuis cette page :

1. Allez à <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Infrastructure &gt; Infrastructure 360**</DNT>.
2. Activez la fonctionnalité pour vos comptes fournisseurs <DNT>AWS</DNT> sous ce compte New Relic.

Si cette page est vide (vous n’avez encore activé <DNT>Infrastructure 360</DNT> pour aucun fournisseur), cliquez sur <DNT>**Setup Infrastructure 360**</DNT>, puis activez la fonctionnalité.

## Utiliser infrastructure 360 [#using-infrastructure-360]

Une fois activé, vous pouvez explorer votre infrastructure <DNT>AWS</DNT> dans New Relic.

### Afficher les entités et les relations découvertes [#view-entities]

Une fois la stack créée, accédez à <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Infrastructure &gt; AWS**</DNT> pour afficher tous les services <DNT>AWS</DNT> de l’étape d’intégration ci-dessus. Lorsqu’une application monitorée s’exécute sur des ressources <DNT>AWS</DNT>, vous pouvez explorer les relations dans les cartes New Relic, y compris les relations entre les entités <DNT>AWS</DNT>, entre les entités APM, et entre <DNT>AWS</DNT> et les entités APM.

### Afficher la configuration de l&apos;entité [#view-configuration]

Pour afficher la configuration d’une entité :

1. Allez à <DNT>**All capabilities**</DNT> et sélectionnez <DNT>**Amazon Web Services**</DNT>.
2. Sélectionnez une entité dans la liste, et cliquez sur <DNT>**Configuration explorer**</DNT> pour voir ses paramètres, tags, et propriétés actuels.

## Gérer les paramètres d&apos;infrastructure 360 [#manage-settings]

### Ajuster la région et la fréquence d’analyse [#adjust-frequency]

Pour ajuster les régions analysées ou la fréquence d&apos;analyse :

1. Allez à <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Infrastructure &gt; AWS**</DNT>.
2. Cliquez sur <DNT>**Manage Infrastructure 360**</DNT>.
3. Trouvez le compte que vous souhaitez mettre à jour, et cliquez sur <DNT>**Edit**</DNT>.
4. Mettez à jour les régions analysées ou la fréquence d’analyse, puis cliquez sur <DNT>**Save**</DNT>.

### Désactiver Infrastructure 360 [#disable]

<Callout variant="caution">
Lorsque vous désactivez <DNT>Infrastructure 360</DNT>, vous perdez l’accès aux entités qu’il a découvertes et à leurs configurations. La carte de l’infrastructure n’affiche plus les relations découvertes par la découverte automatique.
</Callout>

Si vous réactivez <DNT>Infrastructure 360</DNT> plus tard, il recrée toutes les entités et relations qui n’existent plus, lors de sa prochaine analyse programmée.

Pour désactiver <DNT>Infrastructure 360</DNT>:

1. Allez à <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Infrastructure &gt; AWS**</DNT>.
2. Cliquez sur <DNT>**Manage Infrastructure 360**</DNT>.
3. Trouvez le compte où vous souhaitez désactiver <DNT>Infrastructure 360</DNT>, et cliquez sur <DNT>**Edit**</DNT>.
4. Sur le panneau latéral, désactivez l’analyse.
5. Cliquez sur <DNT>**Save**</DNT> pour désactiver <DNT>Infrastructure 360</DNT>.
