L’intégration OCI de New Relic connecte votre environnement d’infrastructure cloud Oracle à New Relic, afin que vous puissiez monitorer les ressources et les applications OCI depuis la même plateforme d’observabilité que vous utilisez pour le reste de votre stack. New Relic collecte les métriques et les logs OCI à l’aide d’agents d’infrastructure spécialisés, d’intégrations sur hôte et d’intégrations cloud conçus spécifiquement pour OCI. Une fois connectées, vos ressources OCI apparaissent en tant qu’entités dans New Relic, aux côtés des applications et des hôtes qui s’y exécutent.

## Capacités [#capabilities]

New Relic collecte deux types de données OCI :

* **Métriques**: métriques en temps réel suivant la santé, la capacité, et les performances de vos ressources OCI
* **Logs**: logs de service et d&apos;audit OCI

## Choisissez votre configuration [#choose-setup]

L&apos;installation guidée est disponible sur <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; Oracle Cloud Infrastructure**</DNT>. L’interface utilisateur vous demande quels types de données vous souhaitez ingérer, puis vous guide pour connecter votre compte OCI, et instrumenter les espaces de nommage, et les groupes de log que vous souhaitez monitorer. Les étapes diffèrent selon ce que vous sélectionnez, donc suivez le guide qui correspond à votre choix :

* **Métriques uniquement**: [monitorez les métriques OCI](/docs/infrastructure/oci/install-metrics) pour les statistiques de performances et d’utilisation.
* **Logs uniquement**: [transférez les logs OCI vers New Relic](/docs/logs/forward-logs/oci-log-forwarding) pour des enregistrements détaillés d’événements et d’audit.
* **Métriques et logs**: [monitorez les métriques et les logs OCI](/docs/infrastructure/oci/install-metrics-and-logs) pour envoyer les deux ensemble, afin que vous puissiez les corréler pour les mêmes ressources OCI.
