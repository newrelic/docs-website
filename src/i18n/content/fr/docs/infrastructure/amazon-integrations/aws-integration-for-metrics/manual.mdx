For a seamless integration of your AWS account with New Relic, [integration via CloudFormation and CloudWatch metric stream](/docs/infrastructure/amazon-integrations/aws-integration-for-metrics/via-cloudformation) is the recommended approach. If you can&apos;t use CloudFormation templates and don&apos;t want to use Terraform, follow this procedure to integrate manually from the AWS console.

<Callout variant="tip">
  * If you manage multiple AWS accounts, [connect each account to a single New Relic account](/docs/infrastructure/amazon-integrations/manage-aws-data/aws-multi-account).
  * If you manage multiple regions within those accounts, create a separate [Kinesis Data Firehose](#create-firehose) for each region.
</Callout>

<Steps>
  <Step>
    ## Prérequis [#prerequisites]

    Avant de commencer à intégrer votre compte AWS à New Relic, assurez-vous de remplir les conditions préalables suivantes :

    * **Une [clé de licence New Relic Ingest et une clé utilisateur](https://one.newrelic.com/api-keys)**: vous aurez besoin de ces clés pour connecter vos services AWS à votre compte New Relic.
    * **[Permissions](https://docs.aws.amazon.com/ARG/latest/userguide/gettingstarted-prereqs-permissions.html)** to deploy new AWS resources and **[IAM roles](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_roles.html)**: You&apos;ll need this permission for your AWS account.
    * **[Permissions](/docs/accounts/accounts-billing/new-relic-one-user-management/user-permissions/#infrastructure)** pour l’intégration cloud : vous aurez besoin de ces permissions pour votre compte New Relic.
  </Step>

  <Step>
    ## Create a Kinesis Data Firehose delivery stream [#create-firehose]

    In the AWS console, set the following destination parameters for the delivery stream:

    * Source : <DNT>Direct PUT</DNT> ou d&apos;autres sources

    * Destination : New Relic

    * Data transformation: <DNT>Disabled</DNT>

    * Record format conversion: <DNT>Disabled</DNT>

    * Assurez-vous que les paramètres suivants sont définis :

      * Configuration de New Relic (paramètres de destination) :

        * URL du point de terminaison HTTP :

          * Datacenter américain : `https://aws-api.newrelic.com/cloudwatch-metrics/v1`
          * Datacenter de l’UE : `https://aws-api.eu01.nr-data.net/cloudwatch-metrics/v1`
          * Datacenter JP : `https://aws-api.jp.nr-data.net/cloudwatch-metrics/v1`

        * Clé API : entrez votre<InlinePopover type="licenseKey" />

        * Encodage du contenu : `GZIP`

        * Durée de réessai : `60`

        * Conditions de tampon New Relic :

          * Taille du tampon : `1 MB`
          * Intervalle du tampon : `60 (seconds)`

      * S3 backup mode: <DNT>Failed data only</DNT>

      * Bucket de sauvegarde S3 : sélectionnez un bucket ou créez-en un nouveau pour stocker les métriques qui n’ont pas pu être envoyées.

      * Paramètres avancés :
        * Accès au service : fournissez les autorisations pour le rôle IAM :
          * <DNT>Create or update IAM role</DNT>
  </Step>

  <Step>
    ## Créer un flux de métriques CloudWatch [#create-metric-stream]

    1. In the AWS console, go to <DNT>**CloudWatch service**</DNT>, select <DNT>**Streams**</DNT> under the <DNT>**Metrics**</DNT> menu, and click <DNT>**Create metric stream**</DNT>.
    2. To control which AWS services send metrics to New Relic, configure inclusion and exclusion filters.
    3. From the Firehose delivery stream list, select the stream you created, then enter a meaningful name for the metric stream, for example, `newrelic-metric-stream`.
    4. Dans le champ de format de sortie, sélectionnez `Open Telemetry 0.7` ou `Open Telemetry 1.0`. JSON n’est pas pris en charge.
  </Step>

  <Step>
    ## Connect your AWS account to New Relic [#connect-aws-account]

    1. Dans New Relic, accédez à [<DNT>**Infrastructure &gt; AWS**</DNT>](https://one.newrelic.com/infra/infrastructure/cloud-aws).

    2. Sélectionnez le bon compte.

    3. Cliquez sur <DNT>**Set up integration**</DNT>.

    4. Sur chaque écran, remplissez les champs qui s&apos;appliquent à vous. Pour cette intégration, choisissez les options suivantes :

       * <DNT>**Choose Data type(s)**</DNT>: <DNT>Metrics</DNT>
       * <DNT>**Choose a setup method**</DNT>: <DNT>Manually integrate your AWS account</DNT>

    5. Sur l’écran <DNT>**Select services**</DNT>, utilisez le bouton bascule <DNT>**Show resources not supported by CloudWatch Metric Streams**</DNT> si nécessaire, sélectionnez les services que vous souhaitez monitorer, et continuez.

    6. Sur l’écran <DNT>**Choose data integration type**</DNT>, choisissez parmi les options suivantes :

       * **Real-time AWS monitoring (Recommended)**: This option is for services that support CloudWatch Metric Streams.
       * **Interrogation d’API**: cette option est destinée aux services qui ne sont pas pris en charge par les flux de métriques CloudWatch.

    7. From the <DNT>**Create role**</DNT> page to the <DNT>**Configure budgets policy**</DNT> page, follow the on-screen instructions and complete the steps in the AWS console.
  </Step>

  <Step>
    ## Validez vos données [#validate]

    Pour confirmer que vous recevez des données de Metric Streams :

    1. In New Relic, go to <DNT>**[one.newrelic.com &gt; All capabilities &gt; Infrastructure &gt; AWS](https://one.newrelic.com/infra/infrastructure/cloud-aws)**</DNT>, search for your connected AWS account, and look for **Stream** accounts.
    2. Dans le dashboard du statut du compte, confirmez que New Relic reçoit des données de métrique, y compris les erreurs et le nombre d&apos;espaces de nommage et de métriques ingérés.
    3. Pour explorer des métriques spécifiques, écrivez des requêtes pour les ensembles de métriques que vous souhaitez analyser.

    Il faudra peut-être quelques minutes à New Relic pour détecter de nouvelles ressources et les synthétiser en tant qu&apos;entité.

    <Callout variant="tip">
      AWS CloudWatch metrics for global services, such as AWS Billing, are only available in the <DNT>**us-east-1**</DNT> region. Make sure there&apos;s an active CloudWatch metric stream configured in that region.
    </Callout>
  </Step>
</Steps>
