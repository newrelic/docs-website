Installez le `VegaTracker` New Relic pour monitorer la lecture d’éléments vidéo HTML5 natifs dans votre application Amazon Fire TV. VegaTracker ne nécessite aucun SDK de lecteur et s’attache à l’élément W3C `VideoPlayer`.

## Avant de commencer [#before-begin]

Effectuez d’abord les [étapes d’installation communes](/docs/streaming-video-&-ads/installation/amazon-fire-tv/get-started-with-amazon-fire-tv#install) pour créer votre application et récupérer le jeton de votre application mobile.

## Installer le tracker [#install]

<Steps>
  <Step>
    ### Installez le package HTML5

    ```shell
    npm install @newrelic/video-html5 --save
    ```
  </Step>

  <Step>
    ### Informations sur l’appareil d’installation

    Cette étape est facultative. La bibliothèque d’informations sur l’appareil fournit de véritables attributs d’appareil — modèle, version de l’OS, et UUID — dans vos événements vidéo. Sans elle, les événements utilisent des valeurs d’espace réservé pour `deviceModel` et `deviceUuid`.

    ```shell
    npm install @amazon-devices/react-native-device-info --save
    ```
  </Step>

  <Step>
    ### Initialiser VegaTracker

    Initialisez `VegaTracker` à l’intérieur du rappel `onSurfaceViewCreated`. Cela garantit que l’attachement asynchrone du lecteur est terminé avant l’initialisation.

    Passez l&apos;élément `VideoPlayer` comme premier argument. Vous n&apos;avez pas besoin d&apos;une instance de SDK de lecteur. L&apos;objet `info` doit inclure votre ID de compte, votre jeton d&apos;application, et votre point de terminaison. Si vous avez installé la bibliothèque d&apos;informations sur l&apos;appareil, passez également les attributs de l&apos;appareil en tant que `info.deviceInfo`.

    Lorsque la lecture se termine, appelez `tracker.dispose()` pour libérer les ressources.

    Pour l’exemple d’initialisation, utilisez le snippet de code dans l’ [installation guidée de New Relic](/docs/streaming-video-&-ads/installation/amazon-fire-tv/get-started-with-amazon-fire-tv#install).
  </Step>

  <Step>
    ### Visualisez vos données

    Déployer votre application et lire une vidéo. Accéder à <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Streaming Video &amp; Ads**</DNT> pour vérifier que les données circulent pour votre application.
  </Step>
</Steps>
