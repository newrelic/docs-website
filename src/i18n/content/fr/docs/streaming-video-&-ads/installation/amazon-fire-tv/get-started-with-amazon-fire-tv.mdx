Utilisez VegaTracker pour monitorer la lecture vidéo dans votre application Amazon Fire TV (Vega OS). VegaTracker capture les événements vidéo et les envoie à New Relic en tant qu’entités, vous donnant une visibilité sur la qualité de lecture sur les appareils Fire TV. Avec les informations sur l’appareil activées, vous pouvez filtrer et facetter vos données vidéo par modèle d’appareil Fire TV réel et version du système d’exploitation dans NRDB.

<Callout variant="important">
  VegaTracker envoie des données via le pipeline mobile de New Relic. Le `applicationToken` est un jeton d’application mobile, distinct d’une clé de licence de navigateur. Vous l’obtenez séparément dans [Installer le tracker](#install).
</Callout>

## Prérequis [#prerequisites]

Assurez-vous d&apos;avoir :

* Un [ID de compte](/docs/accounts/accounts-billing/account-setup/account-id)New Relic
* Familiarité avec les [exigences de compatibilité de Streaming vidéo et publicitaire](/docs/streaming-video-&-ads/installation/compatibility-requirements)

## Installer le tracker [#install]

<Steps>
  <Step>
    ### Accéder à New Relic

    Allez à <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents**</DNT>.
  </Step>

  <Step>
    ### Sélectionner Vidéo en streaming &amp; Publicités

    Sélectionnez la tuile <DNT>**Streaming Video &amp; Ads**</DNT>.
  </Step>

  <Step>
    ### Sélectionnez un compte

    Sélectionnez un <DNT>**Account**</DNT> dans le menu déroulant et cliquez sur <DNT>**Continue**</DNT>.
  </Step>

  <Step>
    ### Sélectionner la plateforme

    Sélectionnez <DNT>**Amazon Vega / Fire TV**</DNT> et cliquez sur <DNT>**Continue**</DNT>.
  </Step>

  <Step>
    ### Sélectionner le lecteur vidéo

    Sélectionnez votre lecteur vidéo et cliquez sur <DNT>**Continue**</DNT>. VegaTracker prend en charge Shaka Player, Dash.js et HTML5.
  </Step>

  <Step>
    ### Nommez votre application

    Entrez un nom pour votre application et cliquez sur <DNT>**Create**</DNT>. Cela génère le jeton d’application mobile que vous utiliserez pour initialiser `VegaTracker`.
  </Step>

  <Step>
    ### Terminez l’installation spécifique au lecteur

    Suivez le guide d’installation pour votre lecteur sélectionné :

    <DocTiles>
      <DocTile title="Shaka Player" path="/docs/streaming-video-&-ads/installation/amazon-fire-tv/install-shaka-player">
        Installez VegaTracker pour Shaka Player.
      </DocTile>

      <DocTile title="Dash.js" path="/docs/streaming-video-&-ads/installation/amazon-fire-tv/install-dashjs">
        Installez VegaTracker pour Dash.js.
      </DocTile>

      <DocTile title="HTML5" path="/docs/streaming-video-&-ads/installation/amazon-fire-tv/install-html5">
        Installer VegaTracker pour l’élément vidéo HTML5 natif.
      </DocTile>
    </DocTiles>
  </Step>

  <Step>
    ### Visualisez vos données

    Déployer votre application et lire une vidéo. Accéder à <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Streaming Video &amp; Ads**</DNT> pour vérifier que les données circulent pour votre application.
  </Step>
</Steps>
