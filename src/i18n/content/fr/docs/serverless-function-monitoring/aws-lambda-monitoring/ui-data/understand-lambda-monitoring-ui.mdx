## Visualisez vos données [#find-data]

<img title="new-relic-lambda-entities-screenshot.png" alt="new-relic-lambda-entities-screenshot.png" src="/images/lambda_screenshot-full_all-entities.webp" />

<figcaption>
  <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; All entities &gt; Amazon Web Services &gt; Lambda functions**</DNT>:Cliquez sur la fonction Lambda pour voir les graphiques et les détails.
</figcaption>

Pour afficher vos données Lambda dans New Relic : Accédez à <DNT>**[one.newrelic.com](https://one.newrelic.com/all-capabilities)**</DNT>, cliquez sur <DNT>**Explorer.**</DNT> Dans le menu de navigation de gauche sous <DNT>**Amazon Web Services**</DNT>, cliquez sur <DNT>**Lambda functions.**</DNT>

Pour en savoir plus sur notre interface utilisateur, consultez [Présentation de la plateforme New Relic](/docs/project-wanda-early-access-future-new-relic-platform).

<Callout variant="important">
  Si vous ne trouvez pas vos données Lambda :

  * Assurez-vous d&apos;avoir suivi les [instructions pour activer le monitoring Lambda](/docs/install-enable-new-relics-monitoring-aws-lambda).
  * Notez que cette fonctionnalité est différente de notre [monitoring d&apos;infrastructure Lambda intégration](/docs/integrations/amazon-integrations/aws-integrations-list/aws-lambda-monitoring-integration).
</Callout>

Si disponible, cela présentera des données recueillies à partir de l’ [instrumentation d’agent APM](/docs/serverless-function-monitoring/aws-lambda-monitoring/get-started/enable-new-relic-monitoring-aws-lambda#instrument-lambda). Les fonctions Lambda instrumentées via OpenTelemetry (couche ADOT) affichent désormais la même expérience de page de résumé que les fonctions Lambda instrumentées par APM, avec des métriques normalisées au format `apm.*` via une couche de synthèse de métrique.
      </td>

    <tr>

        métriques CloudWatch
      </td>

      <td>
        L’onglet <DNT>**CloudWatch metrics**</DNT> affiche les données de performances Lambda provenant d’AWS CloudWatch via la couche de synthèse de métriques de New Relic. Les graphiques incluent : le nombre d’invocations, la durée, les limitations, et le nombre d’erreurs. Cet onglet est disponible pour les fonctions Lambda instrumentées par APM, et instrumentées par OpenTelemetry (ADOT).
      </td>
    </tr>

    <tr>
      <td>
        Transactions
      </td>

      <td>
        L’onglet <DNT>**Transactions**</DNT> répertorie les transactions Lambda, ainsi que les données de performances telles que la durée, et le débit. La colonne <DNT>**AWS Request ID**</DNT> identifie chaque exécution Lambda par son identifiant de requête AWS unique, ce qui vous permet d’explorer la trace de transaction APM d’une invocation spécifique.
      </td>
    </tr>

    <tr>
      <td>

      </td>

      <td>

      </td>
    </tr>

    <tr>
      <td>
        Erreurs
      </td>

      <td>
        La page <DNT>**Errors**</DNT> affiche les erreurs (`AwsLambdaInvocationError` événement). Vous pouvez filtrer par taux d’erreur, pourcentage d’erreur ou classe d’erreur. Vous pouvez explorer en profondeur les erreurs et voir [les attributs](/docs/using-new-relic/welcome-new-relic/getting-started/glossary#attribute) et, si disponibles, la trace des appels.
