Cette page liste les paramètres d’Agent Control que vous pouvez modifier, avec leurs valeurs par défaut. Pour un aperçu de la configuration locale et distante, et pour obtenir des exemples de configuration des agents gérés par Agent Control, consultez la section [Gestion de la configuration](/docs/new-relic-control/agent-control/configuration).

La connexion au contrôle de la flotte (`fleet_control`), `host_id`, les `agents` gérés, et les fournisseurs de valeurs sont abordés dans [Gestion de la configuration](/docs/new-relic-control/agent-control/configuration).

### Remplacez les paramètres par des variables d’environnement [#environment-variables]

Vous pouvez définir n&apos;importe quel paramètre comme variable d&apos;environnement. Utilisez le préfixe `NR_AC_`, écrivez le nom du paramètre en majuscules, et utilisez un double tiret du bas (`__`) pour séparer les clés imbriquées. Les variables d&apos;environnement ont priorité sur le fichier de configuration local.

```bash
# log.level
NR_AC_LOG__LEVEL=DEBUG

# fleet_control.auth_config.client_id
NR_AC_FLEET_CONTROL__AUTH_CONFIG__CLIENT_ID="some-client-id"
```

Sur les hôtes, vous pouvez définir ces variables dans le fichier d’environnement du service ou dans un fichier `environment_variables.yaml` dans le répertoire de configuration local (`/etc/newrelic-agent-control/` sous Linux, `C:\Program Files\New Relic\newrelic-agent-control\` sous Windows). Le fichier doit être une map YAML plate associant des clés de chaîne à des valeurs de chaîne :

```yaml
NR_AC_LOG__LEVEL: "DEBUG"
HTTPS_PROXY: "http://proxy.local:8443"
```

* Les clés doivent commencer par une lettre ou un trait de soulignement, et ne contenir que des lettres, des chiffres, et des traits de soulignement.
* Le contrôle de l’Agent ne surveille pas ce fichier. Redémarrez le contrôle de l’Agent après l’avoir modifié.
* Agent Control transmet ces variables aux agents qu’il gère.
* Si le fichier comporte une entrée non valide, Agent Control ne parvient pas à démarrer.

## Proxy : `proxy` [#proxy]

Agent Control utilise les variables d’environnement `HTTP_PROXY` et `HTTPS_PROXY` de votre système. Vous pouvez également définir un proxy avec le paramètre `proxy`. Si plusieurs sont définies, Agent Control les utilise dans cet ordre de priorité :

1. Le paramètre `proxy`
2. La variable d’environnement `HTTP_PROXY`
3. La variable d’environnement `HTTPS_PROXY`

```yaml
proxy:
  url: https://user:password@proxy.example.com:8080
  ca_bundle_file: /etc/ssl/certs/proxy-ca.pem
```

```yaml
  signature_verification_enabled: true

  default_remote:
```
