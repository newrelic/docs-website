Installez l&apos;agent Ruby New Relic pour commencer le monitoring de votre application Ruby. Choisissez la méthode qui correspond à votre environnement dans la navigation de gauche.

Vous avez besoin d’un [compte New Relic](https://newrelic.com/signup) et de votre <InlinePopover type="licenseKey" />pour terminer l’installation. Consultez les [exigences de l’agent Ruby et les framework pris en charge](/docs/apm/agents/ruby-agent/getting-started/ruby-agent-requirements-supported-frameworks) avant de commencer.

| Méthode                                                                                                             | À utiliser lorsque                                                                                       |
| ------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| [Standard (Bundler/Gemfile)](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent)                 | La plupart des applications Ruby : Rails, Sinatra, Roda, Rack, et d’autres environnements basés sur UNIX |
| [Plug-in Rails](/docs/apm/agents/ruby-agent/installation/ruby-agent-installation-rails-plugin)                      | Applications Rails 2+ utilisant la méthode d’installation de plug-in legacy                              |
| [Docker](/docs/apm/agents/ruby-agent/installation/ruby-agent-installation-docker)                                   | Applications Ruby conteneurisées                                                                         |
| [Heroku](/docs/apm/agents/ruby-agent/installation/ruby-agent-heroku)                                                | Applications déployées sur Heroku utilisant l’add-on New Relic                                           |
| [Google App Engine](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent-gae-flexible-environment) | Applications s&apos;exécutant dans l&apos;environnement flexible GAE                                     |
