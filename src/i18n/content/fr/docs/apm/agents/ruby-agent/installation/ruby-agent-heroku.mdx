<Steps>
<Step>
## Installer le module complémentaire New Relic [#install]

<Tabs>
<TabsBar>
<TabsBarItem id="heroku-website">Site web Heroku</TabsBarItem> <TabsBarItem id="heroku-toolbelt">Heroku toolbelt</TabsBarItem>
</TabsBar>

<TabsPages>
<TabsPageItem id="heroku-website">
1. Accédez à [la page du module complémentaire Heroku pour New Relic](https://elements.heroku.com/addons/newrelic#pricing) et sélectionnez un plan d’abonnement.
2. Sous **Select an app**, sélectionnez votre application.
3. Cliquez sur **Submit Order Form**.
</TabsPageItem>

<TabsPageItem id="heroku-toolbelt">
Exécutez la commande suivante, en remplaçant `$planlevel` par le [plan d’abonnement approprié](https://elements.heroku.com/addons/newrelic#pricing):

```bash
heroku addons:create newrelic:$planlevel
```
</TabsPageItem>
</TabsPages>
</Tabs>

L’installation du module complémentaire crée automatiquement un compte New Relic et configure l’accès pour les hôtes Heroku.
</Step>

<Step>
## Configurer l&apos;agent [#configure]

Ajoutez la gem `newrelic_rpm` à votre `Gemfile`:

```ruby
gem 'newrelic_rpm'
```

Définissez le nom de votre application en utilisant la toolbelt Heroku :

```bash
heroku config:set NEW_RELIC_APP_NAME='Your Application Name'
```

La clé de licence est définie automatiquement par le module complémentaire. Pour toutes les autres options de configuration, consultez la [configuration de l’agent Ruby](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration).
</Step>

<Step>
## Vérifiez que les données circulent [#verify]

Redémarrez votre dyno et générez du trafic vers votre application :

```bash
heroku restart
```

Patientez 2 à 3 minutes et ouvrez [one.newrelic.com &gt; APM](https://one.newrelic.com/apm) pour rechercher votre application par son nom.

<Callout variant="tip">
L’application n’apparaît pas ? Consultez [Aucune donnée n’apparaît (Ruby)](/docs/apm/agents/ruby-agent/troubleshooting/no-data-appears-ruby).
</Callout>
</Step>
</Steps>
