Configurez les paramètres de logging de l’application de l’agent Ruby pour contrôler le transfert de logs, la décoration locale, les attributs personnalisés sur les événements de log, et la collecte de métriques de log.

## Logging des applications [#application-logging]

L&apos;agent Ruby prend en charge [les logs APM dans ce contexte](/docs/apm/new-relic-apm/getting-started/get-started-logs-context). Pour quelques conseils sur la configuration du log pour l&apos;agent Ruby , voir [Configurer les logs Ruby en contexte](/docs/logs/logs-context/configure-logs-context-ruby).

Les options de configuration liées au logging disponibles incluent :

Définit le niveau minimum qu’un événement de log doit avoir pour être transféré à New Relic. Les logs au niveau configuré et de toute gravité supérieure sont transférés, par exemple, `debug` transfère tous les événements de log, tandis que `error` transfère uniquement les événements `error`, `fatal`, et `unknown`. Valeurs valides, de la gravité la plus faible à la plus élevée : `debug`, `info`, `warn`, `error`, `fatal`, `unknown` (insensibles à la casse).

Cet ordre est basé sur les valeurs entières des constantes `Logger::Severity` de Ruby (voir [https://github.com/ruby/logger/blob/113b82a06b3076b93a71cd467e1605b23afb3088/lib/logger/severity.rb](https://github.com/ruby/logger/blob/113b82a06b3076b93a71cd467e1605b23afb3088/lib/logger/severity.rb)).
</Collapser>
