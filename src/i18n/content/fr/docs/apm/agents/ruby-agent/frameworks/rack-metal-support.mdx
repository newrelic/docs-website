[Les middlewaresRack ](/docs/agents/ruby-agent/frameworks/rack-middlewares)sont automatiquement instrumentés avec l&apos;agent Ruby version 3.9.0 ou supérieure.

Le module `NewRelic::Agent::Instrumentation::Rack` a été supprimé dans la version 4.0.0 de l’agent Ruby. Supprimez toutes les références à ce module de votre code. Pour plus d’informations, voir [Contrôleurs Metal instrumentés](/docs/agents/ruby-agent/frameworks/instrumenting-metal-controllers).
