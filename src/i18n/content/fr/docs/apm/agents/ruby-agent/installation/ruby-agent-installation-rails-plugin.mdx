Cette méthode permet d’installer l’agent Ruby en tant que plug-in Rails pour **Rails 2 ou une version ultérieure**.

<Callout variant="important">
Pour la plupart des cas d’utilisation, [installez plutôt l’agent Ruby sous forme de gem](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent). La méthode par gem offre un meilleur contrôle sur les versions et les dépendances.
</Callout>

<Steps>
<Step>
## Installez le plug-in Rails [#install]

Installez le plug-in depuis GitHub dans le répertoire `vendor/plugins` de votre application :

```sh
script/plugin install git://github.com/newrelic/newrelic-ruby-agent.git
mv vendor/plugins/rpm vendor/plugins/newrelic-ruby-agent
```

Si vous ne pouvez pas installer directement à partir de l&apos;URL git, clonez manuellement le référentiel dans le répertoire `vendor/plugins`.
</Step>

<Step>
## Configurer l&apos;agent [#configure]

Copiez le fichier `newrelic.yml` du répertoire du plug-in dans le sous-répertoire `config` de votre application :

```sh
cp vendor/plugins/newrelic-ruby-agent/newrelic.yml config/newrelic.yml
```

Modifiez `config/newrelic.yml`, et définissez les deux valeurs requises :

1. Définissez `license_key` sur votre <InlinePopover type="licenseKey" />.
2. Définissez `app_name` sur un nom significatif pour votre application.

Pour toutes les autres options de configuration, consultez la [configuration de l’agent Ruby](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration).
</Step>

<Step>
## Vérifiez que les données circulent [#verify]

Redémarrez votre serveur web, puis envoyez au moins deux requests à votre application. Patientez 2 - 3 minutes et ouvrez [one.newrelic.com &gt; APM](https://one.newrelic.com/apm) pour rechercher votre application par son nom.

<Callout variant="tip">
L’application n’apparaît pas ? Consultez [Aucune donnée n’apparaît (Ruby)](/docs/apm/agents/ruby-agent/troubleshooting/no-data-appears-ruby).
</Callout>
</Step>
</Steps>
