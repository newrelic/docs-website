<Steps>
<Step>
## Installer la gem [#install]

Ajoutez la gem de l’agent Ruby à votre Gemfile :

```ruby
gem 'newrelic_rpm'
```

Exécutez ensuite :

```sh
bundle install
```

<Callout variant="important">
Si vous utilisez l’agent dans un conteneur Docker, installez l’agent dans chaque conteneur. Consultez [Installer l’agent Ruby dans Docker](/docs/apm/agents/ruby-agent/installation/ruby-agent-installation-docker) pour un exemple de déploiement basé sur Docker.
</Callout>

**Notes spécifiques au framework :**

* **Rails**: Rails appelle automatiquement `Bundler.require`, donc `newrelic_rpm` est requis lors du démarrage sans étape supplémentaire.
* **Roda ou Sinatra**: vous devez appeler manuellement `require 'newrelic_rpm'` dans votre application.
* **Autres applications Rack**: pour utiliser le monitoring de navigateurs automatique, incluez manuellement les [middlewares Rack](/docs/agents/ruby-agent/frameworks/rack-middlewares#manual) fournis par l’agent.
</Step>

<Step>
## Configurer l&apos;agent [#configure]

Téléchargez [`newrelic.yml`](https://github.com/newrelic/newrelic-ruby-agent/blob/dev/newrelic.yml) depuis le référentiel GitHub de New Relic et copiez-le dans le répertoire `config` de votre application.

Les deux seuls paramètres que vous **devez** modifier avant la mise en production :

1. Définissez `license_key` sur votre <InlinePopover type="licenseKey" />.
2. Définissez `app_name` sur un nom significatif pour votre application.

Sinon, générez le fichier de configuration avec la CLI :

```sh
bundle exec newrelic_rpm install --license_key="YOUR_LICENSE_KEY" "YOUR_APP_NAME"
```
</Step>

<Step>
## Vérifiez que les données circulent [#verify]

1. Redémarrez votre serveur Web.

2. Envoyez au moins deux requests à votre application.

3. Patientez 2 à 3 minutes, puis ouvrez [one.newrelic.com &gt; APM](https://one.newrelic.com/apm), et recherchez votre application par son nom.

<Callout variant="tip">
L’application n’apparaît pas ? Consultez [Aucune donnée n’apparaît (Ruby)](/docs/apm/agents/ruby-agent/troubleshooting/no-data-appears-ruby).
</Callout>
</Step>
</Steps>
