<Steps>
<Step>
## Ajoutez la gem à votre Gemfile [#install]

Ajoutez la gem de l&apos;agent Ruby à votre `Gemfile`:

```ruby
gem 'newrelic_rpm'
```

Votre `Dockerfile` doit exécuter `bundle install` dans le cadre du build :

```dockerfile
COPY Gemfile Gemfile.lock ./
RUN bundle install
```

**Notes spécifiques au framework :**

* **Rails**: Rails appelle automatiquement `Bundler.require`, donc `newrelic_rpm` est requis lors du démarrage sans étape supplémentaire.
* **Roda ou Sinatra**: vous devez appeler manuellement `require 'newrelic_rpm'` dans votre application.
* **Autres applications Rack**: pour utiliser le monitoring de navigateurs automatique, incluez manuellement les [middlewares Rack](/docs/agents/ruby-agent/frameworks/rack-middlewares#manual) fournis par l’agent.
</Step>

<Step>
## Configurer l&apos;agent [#configure]

Passez le nom de votre application et votre clé de licence comme variables d’environnement lors de l’exécution du conteneur ; ne les codez pas en dur dans votre image :

```bash
docker run -e NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
           -e NEW_RELIC_APP_NAME="Your Application Name" \
           YOUR_IMAGE_NAME:latest
```

Vous pouvez également les définir via `ENV` dans votre `Dockerfile`:

```dockerfile
ENV NEW_RELIC_APP_NAME="Your Application Name"
```

Pour toutes les autres options de configuration, consultez la [configuration de l’agent Ruby](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration).
</Step>

<Step>
## Vérifiez que les données circulent [#verify]

Exécutez votre conteneur et envoyez au moins deux requests à votre application. Patientez 2 à 3 minutes, puis ouvrez [one.newrelic.com &gt; APM](https://one.newrelic.com/apm), et recherchez votre application par son nom.

<Callout variant="tip">
L’application n’apparaît pas ? Consultez [Aucune donnée n’apparaît (Ruby)](/docs/apm/agents/ruby-agent/troubleshooting/no-data-appears-ruby).
</Callout>
</Step>
</Steps>
