Configurez les paramètres de monitoring de l’IA de l’agent Ruby pour activer l’instrumentation LLM et contrôler si le contenu d’entrée et de sortie est capturé dans les événements d’IA.

## Monitoring de l&apos;IA [#ai-monitoring]

Cette section comprend la configuration de l&apos;agent Ruby pour la mise en place monitoring de l&apos;IA.

<Callout variant="important">Vous devez activer le tracing distribué pour capturer les données trace et de commentaires. Il est activé par défaut dans les agents Ruby 8.0.0 et supérieurs.</Callout>

Si `false`, toute instrumentation LLM (OpenAI uniquement pour l&apos;instant) sera désactivée et aucune métrique, événement ou span ne sera envoyé. Le monitoring de l&apos;IA est automatiquement désactivée si le mode `high_security` est activé.

Si `false`, l&apos;instrumentation LLM (OpenAI uniquement pour le moment) ne capturera pas l&apos;attribut `content` sur les événements LlmChatCompletionMessage ou l&apos;attribut `input` sur les événements LlmEmbedding. Il s&apos;agit d&apos;un paramètre de sécurité facultatif pour empêcher l&apos;enregistrement des données sensibles envoyées à vos LLM et reçues de ces derniers.
