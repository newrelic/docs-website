<Steps>
<Step>
## Installer l&apos;agent [#install]

Installez le package de l’agent dans le répertoire de votre application :

```bash
npm install newrelic
```

<Callout variant="important">
Si vous utilisez Next.js, consultez le [guide d’instrumentation d’agent hybride Next.js](/docs/apm/agents/nodejs-agent/extend-your-instrumentation/nextjs-instrumentation/).
</Callout>

Copiez ensuite le fichier de configuration par défaut du package à la racine de votre application :

```bash
cp node_modules/newrelic/newrelic.js .
```
</Step>

<Step>
## Configurer l&apos;agent [#configure]

Ouvrez `newrelic.js` à la racine de votre application. Les deux seuls paramètres que vous **devez** modifier avant la mise en production :

1. Définissez `license_key` sur votre <InlinePopover type="licenseKey" />.
2. Définissez `app_name` sur un nom significatif pour votre application.

```js
exports.config = {
  app_name: ['Your Application Name'],
  license_key: 'YOUR_LICENSE_KEY',
  // ...
}
```

Vous pouvez également les définir via des variables d’environnement au lieu de modifier le fichier :

```bash
NEW_RELIC_APP_NAME="Your Application Name"
NEW_RELIC_LICENSE_KEY="YOUR_LICENSE_KEY"
```
</Step>

<Step>
## Démarrez l’agent [#start]

Chargez l’agent avant toute autre instruction `require` en ajoutant `-r newrelic` à votre commande de démarrage :

```bash
node -r newrelic ./your-app.js
```

Si votre application utilise ESM, ajoutez l’option `--import newrelic/esm-loader.mjs` :

```bash
node --import newrelic/esm-loader.mjs -r newrelic ./your-app.js
```

Pour une application Next.js, chargez notre agent via `NODE_OPTIONS='-r newrelic' next start`.

Si vous utilisez Nest.js et la commande `nest start` pour démarrer l’application, modifiez son binaire de démarrage pour charger l’agent New Relic : `nest start --exec 'node -r newrelic'`. [Voici un exemple d’application Nest.js](https://github.com/newrelic/newrelic-node-examples/tree/main/nestjs).
</Step>

<Step>
## Vérifiez que les données circulent [#verify]

Si la version de votre agent est 14.9.0 ou supérieure, vous pouvez exécuter cette commande pour valider votre configuration :

```bash
npx newrelic validate-config --config-file ./newrelic.js
```

1. Envoyez au moins deux requests à votre application.

2. Patientez 2 à 3 minutes, puis ouvrez [one.newrelic.com &gt; APM](https://one.newrelic.com/apm), et recherchez votre application par son nom.

<Callout variant="tip">
L’application n’apparaît pas ? Consultez [Dépannage de votre installation Node.js](/docs/apm/agents/nodejs-agent/troubleshooting/troubleshooting-your-nodejs-installation).
</Callout>
</Step>
</Steps>
