<Steps>
<Step>
## Ajoutez l’agent à votre application [#install]

Ajoutez `newrelic` à votre `package.json`:

```json
"newrelic": "latest"
```

Mettez ensuite à jour votre Dockerfile ou votre commande de démarrage pour charger l&apos;agent. La façon de procéder dépend de l&apos;utilisation de CommonJS ou d&apos;ESM par votre application :

<CollapserGroup>
<Collapser id="docker-cjs" title="Application utilisant CommonJS">
* `ENTRYPOINT`

  ```bash
  ENTRYPOINT ["node", "-r", "newrelic", "YOUR_PROGRAM.js"]
  ```

* `CMD`

  ```bash
  CMD ["node", "-r", "newrelic", "YOUR_PROGRAM.js"]
  ```

* script npm tel que `npm start`

  ```bash
  npm pkg set scripts.start="node -r newrelic your-program.js"
  ```
</Collapser>

<Collapser id="docker-esm" title="Application utilisant ESM">
* `ENTRYPOINT`

  ```bash
  ENTRYPOINT ["node", "--import", "newrelic/esm-loader.mjs", "-r", "newrelic", "YOUR_PROGRAM.js"]
  ```

* `CMD`

  ```bash
  CMD ["node", "--import", "newrelic/esm-loader.mjs", "-r", "newrelic", "YOUR_PROGRAM.js"]
  ```

* script npm tel que `npm start`

  ```bash
  npm pkg set scripts.start="node --import newrelic/esm-loader.mjs -r newrelic your-program.js"
  ```
</Collapser>
</CollapserGroup>

<Callout variant="important">
Si vous ne pouvez pas utiliser l’indicateur `-r`, ajoutez `require('newrelic')` comme **première ligne** du module principal de votre application. N’utilisez pas cette approche avec Babel ou d’autres transpileurs : cela causera des problèmes d’instrumentation.
</Callout>
</Step>

<Step>
## Configurer l&apos;agent [#configure]

Passez le nom de votre application et votre clé de licence comme variables d&apos;environnement lors de l&apos;exécution du conteneur. Il s&apos;agit des seuls paramètres requis :

```bash
docker run -e NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
           -e NEW_RELIC_APP_NAME="Your Application Name" \
           YOUR_IMAGE_NAME:latest
```

Vous pouvez également définir la configuration via des directives `ENV` dans votre Dockerfile :

```dockerfile
ENV NEW_RELIC_APP_NAME="Your Application Name"
```

Pour toutes les autres options de configuration, consultez la [configuration de l’agent Node.js](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration).
</Step>

<Step>
## Vérifiez que les données circulent [#verify]

Construisez et exécutez votre conteneur, puis envoyez au moins deux requests à votre application. Patientez 2 à 3 minutes et ouvrez [one.newrelic.com &gt; APM](https://one.newrelic.com/apm) pour rechercher votre application par son nom.

<Callout variant="tip">
L’application n’apparaît pas ? Consultez [Dépannage de votre installation Node.js](/docs/apm/agents/nodejs-agent/troubleshooting/troubleshooting-your-nodejs-installation).
</Callout>
</Step>
</Steps>
