Installez l’agent Node.js New Relic sur Azure App Service pour Windows à l’aide de l’extension de site Azure New Relic.

<Callout variant="important">
Cette méthode est destinée uniquement aux applications Azure App Service **basées sur Windows** déployées sous forme de code. Pour les conteneurs Linux sur Azure, utilisez la [méthode d&apos;installation npm](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent) standard et transmettez `NEW_RELIC_LICENSE_KEY` comme paramètre d&apos;application. Pour une application basée sur Linux déployée manuellement, consultez [Agent Node.js sur Microsoft Azure App Services](/docs/apm/agents/nodejs-agent/hosting-services/nodejs-agent-microsoft-azure).

Pour les applications s’exécutant sur Windows 32, la prise en charge complète des Métriques de niveau du code (chemin du fichier, ligne, colonne) n’est pas disponible : le profilage se limite au nom de la fonction.
</Callout>

<Steps>
<Step>
## Installez l’extension de site [#install]

1. Depuis la page d’accueil Azure, cliquez sur **App Services** et sélectionnez votre application cible.
2. Dans le menu de gauche sous **Development Tools**, sélectionnez **Extensions**.
3. Cliquez sur **+ Add** en haut de la page, puis sélectionnez **New Relic Node Agent** dans la liste déroulante.
4. Acceptez les conditions légales et cliquez sur **OK**.

Une fois installée, l’extension crée :

* Fichiers de l&apos;agent et dépendances sous `C:\home\site\wwwroot\node_modules`
* Une transformation XDT (`applicationHost.xdt`) qui injecte automatiquement `NODE_OPTIONS=-r newrelic` au démarrage de l&apos;application
</Step>

<Step>
## Configurer l&apos;agent [#configure]

Dans le menu de gauche de votre application, accédez à **Settings &gt; Environment variables** et ajoutez :

| Paramètre               | Valeur                               |
| ----------------------- | ------------------------------------ |
| `NEW_RELIC_LICENSE_KEY` | Votre clé de licence New Relic       |
| `NEW_RELIC_APP_NAME`    | Le nom qui apparaîtra dans New Relic |

L&apos;extension définit automatiquement `NODE_OPTIONS` sur `-r newrelic`. Tout `NODE_OPTIONS` défini précédemment sera réinitialisé. Pour toutes les autres options de configuration, consultez la [configuration de l&apos;agent Node.js](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration).
</Step>

<Step>
## Vérifiez que les données circulent [#verify]

Démarrez votre application et envoyez au moins deux requests. Patientez 2 à 3 minutes et ouvrez [one.newrelic.com &gt; APM](https://one.newrelic.com/apm) pour rechercher votre application par son nom.

Si l’installation de l’extension échoue, vérifiez le log à l’adresse :

```
C:\home\SiteExtensions\NewRelic.Azure.Websites.Extension.NodeAgent\install.log
```

Si l’agent est installé mais que les données n’apparaissent pas, vérifiez :

```
C:\home\site\wwwroot\newrelic_agent.log
```

<Callout variant="tip">
L’application n’apparaît pas ? Consultez [Dépannage de votre installation Node.js](/docs/apm/agents/nodejs-agent/troubleshooting/troubleshooting-your-nodejs-installation).
</Callout>
</Step>
</Steps>
