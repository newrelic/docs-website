Installez l’agent Node.js New Relic pour commencer à monitorer votre application Node.js. Choisissez la méthode qui correspond à votre environnement dans le menu de navigation de gauche.

Vous avez besoin d’un [compte New Relic](https://newrelic.com/signup) et de votre <InlinePopover type="licenseKey" />pour terminer l’installation. Consultez la [compatibilité de l’agent Node.js et les exigences](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent) avant de commencer.

| Méthode                                                                                                                           | À utiliser lorsque                                                                                            |
| --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| [Standard (npm)](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent)                                   | La plupart des applications Node.js : installez via npm, chargez avec `-r newrelic`                           |
| [Docker](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent-docker)                                    | Applications Node.js conteneurisées                                                                           |
| [Azure App Service (Windows)](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent-azure-site-extension) | Applications déployées sur Azure App Service pour Windows à l&apos;aide de l&apos;extension de site New Relic |
