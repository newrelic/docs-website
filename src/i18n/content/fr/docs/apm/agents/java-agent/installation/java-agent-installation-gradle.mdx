Cette page explique comment installer l’agent Java New Relic à l’aide de Gradle. Les tâches Gradle optimisées par le plug-in `de.undercouch.download` récupèrent et décompressent `newrelic-java.zip` dans le répertoire de votre projet.

## Compatibilité et exigences [#requirements]

### Soutenu

* Java 8, 11, 17, 21, 24, 25, et 26 *(Java 7 pris en charge sur l’agent v6.5.4, et versions antérieures uniquement)*
* Gradle 6.x ou supérieur
* `de.undercouch.download` plug-in version 5.3.0 ou supérieure
* Tout serveur d&apos;applications pris en charge ou processus JVM autonome qui accepte un argument `-javaagent`
* Consultez la [compatibilité et les exigences](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent) pour les plages de versions de framework et de bibliothèque prises en charge

### Non pris en charge

* Exécution aux côtés d’autres agents APM : l’agent Java ne peut pas garantir un comportement correct lorsqu’un autre agent APM est actif dans la même JVM

### Vous avez besoin de

* Un compte New Relic et<InlinePopover type="licenseKey" />
* Une JVM avec prise en charge de SSL SHA-2 (256 bits)
* Un projet Gradle avec `build.gradle`

## Installation [#install]

<Steps>
  <Step>
    ### Ajoutez le plug-in de téléchargement [#install-step-1]

    Ajoutez le plug-in `de.undercouch.download` au bloc `plugins` de votre `build.gradle`:

    ```groovy
    plugins {
        id "de.undercouch.download" version "5.3.0"
    }
    ```
  </Step>

  <Step>
    ### Ajoutez des tâches de téléchargement et de décompression [#install-step-2]

    Ajoutez deux tâches à `build.gradle`, une pour télécharger le zip de l’agent et une pour le décompresser :

    ```groovy
    task downloadNewrelic(type: Download) {
        mkdir 'newrelic'
        src 'https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip'
        dest file('newrelic')
    }

    task unzipNewrelic(type: Copy) {
        from zipTree(file('newrelic/newrelic-java.zip'))
        into rootDir
    }
    ```

    Cela place les fichiers de l&apos;agent dans un répertoire `newrelic/` à la racine du projet, contenant :

    * `newrelic.jar` — l’agent Java
    * `newrelic.yml` — le fichier de configuration de l’agent
    * `newrelic-api.jar` — le jar de l’API d’agent Java
    * `README`
  </Step>

  <Step>
    ### Exécutez les tâches [#install-step-3]

    Exécutez les deux tâches pour télécharger et décompresser l’agent :

    ```bash
    ./gradlew downloadNewrelic
    ./gradlew unzipNewrelic
    ```
  </Step>

  <Step>
    ### Passez le `-javaagent` [#install-step-4]

    Ajoutez l’argument JVM `-javaagent` pointant vers `newrelic.jar` lors du démarrage de votre application. La méthode exacte dépend de votre serveur d’applications : consultez [Passez l’argument JVM pour votre serveur](/docs/apm/agents/java-agent/installation/java-agent-installation-app-servers#install-step-3) pour des instructions spécifiques au serveur.

    Pour un jar Spring Boot, par exemple :

    ```bash
    java -javaagent:/path/to/newrelic/newrelic.jar -jar my-app.jar
    ```
  </Step>
</Steps>

## Configure [#configure]

Modifiez `newrelic/newrelic.yml` et définissez deux valeurs requises :

```yaml
license_key: 'YOUR_LICENSE_KEY'
app_name: 'My Application'
```

L’agent lit `newrelic.yml` depuis le même répertoire que `newrelic.jar` au démarrage. Vous pouvez également remplacer n’importe quel paramètre à l’aide des propriétés système Java (par exemple `-Dnewrelic.config.license_key=YOUR_KEY`) ou des variables d’environnement.

Consultez la [configuration de l’agent Java](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file) pour toutes les options disponibles.

## Vérifiez votre installation [#verify]

Redémarrez votre application. Envoyez au moins deux requests, puis patientez 2 - 3 minutes et votre application apparaît dans [APM &amp; services](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29).

Si aucune donnée n’apparaît après cinq minutes, consultez [Aucune donnée n’apparaît (Java)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java).
