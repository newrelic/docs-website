Cette page explique comment installer l’agent Java New Relic sur AWS Elastic Beanstalk en ajoutant l’agent à votre bundle d’application, et en configurant l’argument JVM `-javaagent` via la console Elastic Beanstalk.

## Compatibilité et exigences [#requirements]

### Soutenu

* Java 8, 11, 17, 21, 24, 25, et 26 *(Java 7 pris en charge sur l’agent v6.5.4, et versions antérieures uniquement)*
* Plateforme Tomcat Elastic Beanstalk
* Plateforme Elastic Beanstalk Java SE
* Consultez la [compatibilité et les exigences](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent) pour les plages de versions de framework et de bibliothèque prises en charge

### Non pris en charge

* Conteneurs Docker sur Elastic Beanstalk : utilisez plutôt la [méthode d’installation Docker](/docs/apm/agents/java-agent/additional-installation/install-new-relic-java-agent-docker)
* Exécution aux côtés d’autres agents APM : l’agent Java ne peut pas garantir un comportement correct lorsqu’un autre agent APM est actif dans la même JVM

### Vous avez besoin de

* Un compte New Relic et<InlinePopover type="licenseKey" />
* Une JVM avec prise en charge de SSL SHA-2 (256 bits)
* Un [compte AWS](http://aws.amazon.com/elasticbeanstalk/) avec votre application Java déployée sur Elastic Beanstalk

## Installation [#install]

Téléchargez `newrelic-java.zip` et extrayez `newrelic.jar` et `newrelic.yml`: \[#install-step-1]

```bash
curl -O https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip
unzip newrelic-java.zip
```

## Configure [#configure]

Modifiez `newrelic.yml`, et définissez les deux valeurs requises :

1. Définissez `license_key` sur votre <InlinePopover type="licenseKey" />.
2. Définissez `app_name` sur un nom significatif pour votre application.

**Plateforme Tomcat uniquement** — Passez l’indicateur `-javaagent` via la console Elastic Beanstalk :

1. Ouvrez la console Elastic Beanstalk et sélectionnez votre environnement.

2. Dans le volet de gauche, sélectionnez **Configurations**.

3. Faites défiler jusqu’à **Updates, monitoring, and logging** et cliquez sur **Edit**.

4. Sous **Platform Software**, ajoutez au champ **JVM Options** :

   ```
   -javaagent:/full/path/to/newrelic.jar
   ```

   Pour trouver le chemin d’accès à `newrelic.jar` sur l’instance EC2, connectez-vous à l’instance et exécutez :

   ```bash
   sudo find /var -name "newrelic.jar"
   sudo find /usr -name "newrelic.jar"
   ```

5. Cliquez sur **Appliquer**.

Pour toutes les autres options de configuration, consultez la [configuration de l’agent Java](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file).

## Vérifiez votre installation [#verify]

Elastic Beanstalk mettra à jour votre environnement. Envoyez au moins deux requests, puis attendez 2 - 3 minutes, et votre application apparaît dans [APM &amp; services](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29).

Si aucune donnée n’apparaît après cinq minutes, consultez [Aucune donnée n’apparaît (Java)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java).
