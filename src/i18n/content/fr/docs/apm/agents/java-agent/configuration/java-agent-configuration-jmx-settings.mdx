Les paramètres JMX contrôlent la façon dont l’agent collecte les métriques à partir des serveurs d’applications et des services compatibles JMX.

<Callout variant="tip">
  Retour à l’index complet des paramètres : [configuration de l’agent Java](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file)
</Callout>

## JMX

Pour définir ces options, utilisez la section `jmx`. Pour les [remplacer](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file#System_Properties), utilisez une propriété système préfixée par `newrelic.config.jmx`.

L&apos;agent Java utilise JMX pour collecter les données JVM. De plus, l&apos;agent peut exposer des métadonnées de liaison via JMX qui peuvent être utilisées par d&apos;autres systèmes de tracing.
