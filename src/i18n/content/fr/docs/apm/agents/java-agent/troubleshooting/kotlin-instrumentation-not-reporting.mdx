## Problème

Si l’instrumentation est manquante dans votre application Kotlin, configurez [les logs de l’agent sur le niveau le plus fin](/docs/agents/java-agent/troubleshooting/generating-logs-troubleshooting-java).

Les logs doivent mentionner `ArrayIndexOutOfBoundsException`. Les clients disposant de la version 8.2.0 et ultérieure de l&apos;agent verront le message suivant :

```
Unexpected ArrayIndexOutOfBoundsException thrown during class transformation. Try restarting the Java Agent with flag -Dnewrelic.config.class_transformer.clear_return_stacks=true
```

## Solution

Assurez-vous que la version de l&apos;agent Java est 8.20 ou ultérieure. Si la version installée est antérieure à 8.20, mettez à niveau l&apos;agent Java vers une version prise en charge (la dernière version est recommandée).

Redémarrez l&apos;agent Java ou votre application Java avec la propriété système :

```
-Dnewrelic.config.class_transformer.clear_return_stacks=true
```
