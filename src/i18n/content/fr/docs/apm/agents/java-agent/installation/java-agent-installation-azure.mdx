Cette page couvre l’installation de l’agent Java New Relic sur Azure App Service pour Windows à l’aide de l’extension de site New Relic Java Agent. L’extension injecte l’agent automatiquement sans modifier le script de démarrage de votre application.

## Compatibilité et exigences [#requirements]

### Soutenu

* Applications Java s’exécutant sur Azure Windows App Service
* Versions de l’agent Java New Relic compatibles avec Java 8 et supérieur *(Java 7 pris en charge sur l’agent v6.5.4 et versions antérieures uniquement)*
* Consultez la [compatibilité et les exigences](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent) pour les plages de versions de framework et de bibliothèque prises en charge

### Non pris en charge

* Conteneurs Linux sur Azure : utilisez la [méthode d&apos;installation Docker](/docs/apm/agents/java-agent/additional-installation/install-new-relic-java-agent-docker), et passez `-javaagent` via `JAVA_TOOL_OPTIONS`
* Exécution aux côtés d’autres agents APM : l’agent Java ne peut pas garantir un comportement correct lorsqu’un autre agent APM est actif dans la même JVM

### Vous avez besoin de

* Un compte New Relic et<InlinePopover type="licenseKey" />
* Une JVM avec prise en charge de SSL SHA-2 (256 bits)
* Une application Java s&apos;exécutant sur Azure Windows App Service
* L&apos;application cible doit être arrêtée avant d&apos;installer l&apos;extension pour éviter une instrumentation partielle

## Installation [#install]

<Steps>
  <Step>
    ### Installez l’extension de site [#install-step-1]

    1. Depuis la page d’accueil Azure, sélectionnez **App Services**, puis sélectionnez votre application cible.
    2. Dans le menu de gauche, faites défiler jusqu&apos;à **Development Tools**, et sélectionnez **Extensions**.
    3. Sélectionnez **+ Add** en haut de la page pour ouvrir la liste déroulante de l’extension.
    4. Sélectionnez **New Relic Java Agent**.
    5. Acceptez les conditions légales et sélectionnez **OK** pour commencer l’installation.

    Une fois installée, l’extension crée :

    * **Fichiers de l’agent** à `C:\home\NewRelic\JavaAgent\newrelic\` (fichiers jar, configuration, sources)
    * **Transformation XDT** (`applicationHost.xdt`) qui injecte automatiquement la variable d’environnement `JAVA_TOOL_OPTIONS` au démarrage de l’application

    *Si l’installation de l’extension échoue, vérifiez le log à l’adresse `C:\home\SiteExtensions\NewRelic.Azure.WebSites.Extension.JavaAgent\install.log`.*
  </Step>

  <Step>
    ### Configurer l&apos;agent [#install-step-2]

    1. Dans le menu de gauche de votre application, accédez à **Settings &gt; Configuration**.
    2. Ajoutez les paramètres d’application suivants :

    | Paramètre               | Valeur                                           |
    | ----------------------- | ------------------------------------------------ |
    | `NEW_RELIC_LICENSE_KEY` | Votre clé de licence New Relic                   |
    | `NEW_RELIC_APP_NAME`    | Le nom qui apparaît dans la plateforme New Relic |

    Vous pouvez également ajouter des [paramètres de configuration supplémentaires](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file/#Environment_Variables) en tant que paramètres d&apos;application pour personnaliser davantage l&apos;agent.
  </Step>
</Steps>

## Vérifiez votre installation [#verify]

Démarrer votre application. Envoyez au moins deux requests, puis attendez 2 - 3 minutes, et votre application apparaît dans [APM &amp; services](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29).

Si aucune donnée n’apparaît après cinq minutes, consultez [Aucune donnée n’apparaît (Java)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java).
