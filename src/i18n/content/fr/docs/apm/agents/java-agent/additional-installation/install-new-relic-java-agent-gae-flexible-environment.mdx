Cette page explique comment installer l’agent Java New Relic dans un [environnement flexible Google App Engine (GAE)](https://cloud.google.com/appengine/docs/flexible/java/) à l’aide d’un environnement d’exécution Docker personnalisé.

<Callout variant="important">
N’utilisez pas l’environnement standard GAE ni le [« mode natif »](https://cloud.google.com/appengine/docs/flexible/java/) de Google App Engine : l’agent Java nécessite un environnement d’exécution personnalisé.
</Callout>

## Compatibilité et exigences [#requirements]

### Soutenu

* Java 8, 11, 17, 21, 24, 25, et 26 *(Java 7 pris en charge sur l’agent v6.5.4, et versions antérieures uniquement)*
* Environnement flexible Google App Engine avec un environnement d’exécution Docker personnalisé
* Consultez la [compatibilité et les exigences](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent) pour les plages de versions de framework et de bibliothèque prises en charge

### Non pris en charge

* Environnement standard GAE : nécessite un environnement d’exécution personnalisé ; l’environnement standard ne le prend pas en charge
* Mode natif GAE : l’agent Java nécessite un environnement d’exécution personnalisé
* Exécution aux côtés d’autres agents APM : l’agent Java ne peut pas garantir un comportement correct lorsqu’un autre agent APM est actif dans la même JVM

### Vous avez besoin de

* Un compte New Relic et<InlinePopover type="licenseKey" />
* Une JVM avec prise en charge de SSL SHA-2 (256 bits)
* Un projet Google Cloud Platform avec une application App Engine créée (voir les [procédures Google App Engine pour Java](https://cloud.google.com/appengine/docs/flexible/java/managing-projects-apps-billing#create))
* La CLI `gcloud` installée et initialisée (voir la [documentation du SDK Google Cloud](https://cloud.google.com/sdk/gcloud/))
* Maven ou Gradle avec le [plug-in App Engine](https://cloud.google.com/appengine/docs/flexible/java/using-maven) configuré

## Installation [#install]

Téléchargez `newrelic-java.zip` et décompressez-le dans votre projet : \[#install-step-1]

```bash
curl -O https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip
unzip newrelic-java.zip
```

Configurez votre `app.yaml` pour un environnement d’exécution personnalisé :

```yaml
runtime: custom
env: flex
```

Configurez votre `Dockerfile` pour ajouter l’agent et passer l’argument `-javaagent`. L’exemple ci-dessous utilise Tomcat :

```dockerfile
ADD ./newrelic/newrelic.jar /usr/local/tomcat/newrelic/newrelic.jar
ENV JAVA_OPTS="$JAVA_OPTS -javaagent:/usr/local/tomcat/newrelic/newrelic.jar"
```

Construisez votre projet :

```bash
mvn clean install
```

## Configure [#configure]

Modifiez `newrelic/newrelic.yml`, et définissez les deux valeurs requises :

1. Définissez `license_key` sur votre <InlinePopover type="licenseKey" />.
2. Définissez `app_name` sur un nom significatif pour votre application.

Pour toutes les autres options de configuration, consultez la [configuration de l’agent Java](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file).

## Vérifiez votre installation [#verify]

Déployer sur GAE :

```bash
gcloud --project YOUR_PROJECT_NAME app deploy
```

Patientez jusqu’à ce que le déploiement soit terminé. Envoyez au moins deux requests, puis patientez 2 - 3 minutes et votre application apparaît dans [APM &amp; services](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29).

Si aucune donnée n’apparaît après cinq minutes, consultez [Aucune donnée n’apparaît (Java)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java).
