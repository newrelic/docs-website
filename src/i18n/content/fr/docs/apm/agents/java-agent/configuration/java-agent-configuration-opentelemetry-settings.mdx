Les paramètres OpenTelemetry configurent l’intégration de l’agent avec l’instrumentation OpenTelemetry et l’exportation de données OTLP.

Retour à l’index complet des paramètres : [configuration de l’agent Java](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file)
</Callout>

## OpenTelemetry [#opentelemetry]

À partir de la version `9.1.0` de l’agent Java, la compatibilité avec l’API de tracing, de Métriques, et de logs OpenTelemetry a été ajoutée, offrant une expérience &quot;le meilleur des deux mondes&quot; en combinant la visibilité approfondie de New Relic aux signaux OpenTelemetry.

Grâce à cette fonctionnalité, les API de tracing, de métriques et de logs OpenTelemetry peuvent être utilisées pour instrumenter votre application de manière personnalisée, en combinaison avec les API de l&apos;agent Java New Relic, tandis que l&apos;agent Java combine le tout de façon transparente pour offrir une expérience APM familière. De plus, certaines bibliothèques fournissant une instrumentation native OpenTelemetry ou une instrumentation de bibliothèque autonome peuvent être utilisées pour offrir une visibilité accrue sur votre application.

Les options de configuration suivantes déterminent quels signaux OpenTelemetry doivent être capturés et intégrés à l&apos;expérience New Relic APM.

```yml
  opentelemetry:
    enabled: false
    logs:
      enabled: true
    metrics:
      enabled: true
      include: "MeterName1,MeterName2"
      exclude: "MeterName3,MeterName4"
    traces:
      enabled: true
      include: "TracerName1,TracerName2"
      exclude: "TracerName3,TracerName4"
```

Définissez sur true pour permettre l&apos;activation de signaux OpenTelemetry individuels, et sur false pour désactiver tous les signaux OpenTelemetry. La valeur par défaut est false.

Peut être défini via la propriété système :

```ini
-Dnewrelic.config.opentelemetry.enabled=false
```

Peut être défini via la variable d&apos;environnement :

```ini
NEW_RELIC_OPENTELEMETRY_ENABLED
```

Une chaîne de Meters OpenTelemetry délimitée par des virgules (par ex. &quot;MeterName1,MeterName2&quot;) dont les signaux doivent être inclus. Par défaut, tous les compteurs sont inclus. Cela écrasera toutes les exclusions de Meter par défaut dans l&apos;agent, ce qui aura pour effet de les réactiver.

La valeur par défaut est une chaîne vide.

Peut être défini via la propriété système :

```ini
-Dnewrelic.config.opentelemetry.metrics.include=MeterName1,MeterName2
```

Peut être défini via la variable d&apos;environnement :

```ini
NEW_RELIC_OPENTELEMETRY_METRICS_INCLUDE
```
</Collapser>
