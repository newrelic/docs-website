Les paramètres de sécurité configurent l’agent de sécurité New Relic pour la détection des vulnérabilités et le monitoring de la sécurité des applications en temps réel (IAST).

<Callout variant="tip">
Retour à l’index complet des paramètres : [configuration de l’agent Java](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file)
</Callout>

## Agent de sécurité [#sec-agent]

[New Relic sécurité agent interactif de test de sécurité](/docs/iast/introduction/) des (IAST) de New Relic Security teste votre application pour détecter toute vulnérabilité exploitable en rejouant la requête HTTP générée avec une charge vulnérable.

<Callout variant="important">
Exécutez IAST avec une déploiement de non-production uniquement pour éviter d&apos;exposer les vulnérabilités de votre logiciel de production.
</Callout>

Vous pouvez définir la configuration de l’agent de sécurité New Relic dans la section `security`. Ces paramètres peuvent être [remplacés](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file#System_Properties) par une propriété système préfixée `newrelic.config.security`. Les options incluent :
