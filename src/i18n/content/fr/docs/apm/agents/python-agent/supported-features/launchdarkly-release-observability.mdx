<Callout title="Aperçu">
Nous travaillons toujours sur cette fonctionnalité, mais nous aimerions que vous l&apos;essayiez !

Cette fonctionnalité est actuellement fournie dans le cadre d&apos;un programme d&apos;aperçu conformément à nos [politiques de pré-sortie](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy).
</Callout>

L’agent Python New Relic s’intègre à la gestion des fonctionnalités de LaunchDarkly, afin que vous puissiez observer comment les indicateurs de fonctionnalité, et les sorties affectent votre application. Cette intégration utilise le plug-in d’observabilité LaunchDarkly, et la prise en charge d’OpenTelemetry dans l’agent Python pour connecter vos données LaunchDarkly à vos données New Relic APM.

Ce document explique comment installer les packages requis et activer l&apos;intégration.

## Prérequis [#prerequisites]

Avant de commencer, assurez-vous d&apos;avoir :

* Une [clé de licence](/docs/apis/intro-apis/new-relic-api-keys/#license-key) New Relic
* Un compte et une licence LaunchDarkly
* Une application écrite en Python et monitorée avec l’ [agent APM Python New Relic](/docs/apm/agents/python-agent/installation/install-new-relic-python-agent)
* Accès à la bêta de LaunchDarkly OpenTelemetry (OTel)

## Installation et configuration [#install]

<Steps>
<Step>
### Installez les packages requis [#install-packages]

Installez les packages Python suivants dans le même environnement que l&apos;application :

* `newrelic`
* `launchdarkly-observability`

```bash
pip install newrelic launchdarkly-observability
```

Les packages suivants sont également requis, et s’installent généralement automatiquement en tant que dépendances de `launchdarkly-observability`:

* `opentelemetry-api`
* `launchdarkly-eventsource`
* `launchdarkly-server-sdk`
* `launchdarkly-server-sdk-otel`

Si ces dépendances ne sont pas installées automatiquement, installez-les manuellement à l’aide de `pip`:

```bash
pip install opentelemetry-api launchdarkly-eventsource launchdarkly-server-sdk launchdarkly-server-sdk-otel
```
</Step>

<Step>
### Activer l&apos;intégration [#enable-integration]

Pour activer l&apos;intégration, définissez `launch_darkly_integration.enabled` et `opentelemetry.enabled` sur `true`. Sélectionnez l&apos;une des méthodes de configuration suivantes pour configurer l&apos;application :

<CollapserGroup>
<Collapser id="use-newrelic-ini" title="Utilisez newrelic.ini">
Ajoutez ce qui suit à votre fichier `newrelic.ini` :

```ini
launch_darkly_integration.enabled = true
opentelemetry.enabled = true
```
</Collapser>

<Collapser id="use-pyproject-toml" title="Utilisez pyproject.toml">
Ajoutez ce qui suit à votre fichier `pyproject.toml` :

```toml
[tool.newrelic]
launch_darkly_integration.enabled = true
opentelemetry.enabled = true
```
</Collapser>

<Collapser id="use-environment-variables" title="Utilisez des variables d'environnement">
Définissez les variables d’environnement suivantes :

```bash
export NEW_RELIC_LAUNCH_DARKLY_ENABLED=true
export NEW_RELIC_OPENTELEMETRY_ENABLED=true
```

<Callout variant="tip">
Pour plus d&apos;informations sur le paramètre OpenTelemetry, consultez la documentation de la [configuration de l&apos;agent Python](/docs/apm/agents/python-agent/configuration/python-agent-configuration#opentelemetry-enabled).
</Callout>
</Collapser>
</CollapserGroup>
</Step>

<Step>
### Vérifier l’intégration [#verify]

Après avoir activé ces paramètres, redémarrez l&apos;application pour que l&apos;agent Python charge la configuration mise à jour. Ensuite, générez du trafic de test et vérifiez que l&apos;application continue de rapporter des données dans [<DNT>**APM &amp; services**</DNT>](/docs/apm/apm-ui-pages/monitoring/apm-summary-page-view-transaction-apdex-usage-data).
</Step>
</Steps>
