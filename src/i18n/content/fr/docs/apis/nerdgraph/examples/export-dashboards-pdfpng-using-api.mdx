Vous pouvez exporter votre dashboard et vos graphiques individuels sous forme de fichiers PDF ou PNG par programmation à l’aide des mutations NerdGraph `dashboardCreateSnapshotUrl` et `dashboardWidgetCreateSnapshotUrl`. L’API prend en charge des options qui ne sont pas disponibles dans l’UI, telles que les remplacements de variables de modèle et les filtres d’entité. Vous pouvez également [exporter le dashboard à l’aide de l’UI](/docs/query-your-data/explore-query-data/dashboards/dashboards-charts-import-export-data/#export-dashboards-pdf).

## Exporter un dashboard au format PDF ou PNG [#api-dashboard-snapshot]

La mutation `dashboardCreateSnapshotUrl` génère une URL d’instantané pour une page de dashboard complète.

<Callout variant="tip">
Le paramètre `guid` nécessite le GUID de la **page**, et non le GUID du dashboard. Un dashboard peut avoir plusieurs pages. Pour trouver les GUID de page, utilisez la requête `entitySearch` ou ouvrez la page du dashboard et sélectionnez <DNT>**Manage JSON**</DNT> dans le menu <DNT>**...**</DNT>.

```graphql
{
  actor {
    entitySearch(query: "parentId ='YOUR_DASHBOARD_GUID' AND tags.isDashboardPage = 'true'") {
      results {
        entities {
          guid
          name
        }
      }
    }
  }
}
```
</Callout>

**Schéma de mutation :**

```graphql
mutation {
  dashboardCreateSnapshotUrl(
    guid: EntityGuid!
    params: SnapshotUrlInput
  ): String
}

input SnapshotUrlInput {
  timeWindow: SnapshotUrlTimeWindowInput
  display: SnapshotUrlDisplayInput
  variables: [SnapshotUrlVariableInput!]
  filter: String
  format: SnapshotUrlFormat
}

input SnapshotUrlTimeWindowInput {
  beginTime: EpochMilliseconds
  endTime: EpochMilliseconds
  duration: Milliseconds
}

input SnapshotUrlDisplayInput {
  width: Int
  height: Int
}

input SnapshotUrlVariableInput {
  name: String!
  values: [String!]!
}

enum SnapshotUrlFormat {
  PDF
  PNG
}
```

<Collapser id="variables-filter" title="Exporter avec des remplacements de variables et un filtre">
Utilisez ceci pour épingler des valeurs de variables et des filtres spécifiques dans l’instantané, ce qui est utile pour l’automatisation des rapports planifiés.

```graphql
mutation {
  dashboardCreateSnapshotUrl(
    guid: "YOUR_DASHBOARD_PAGE_GUID"
    params: {
      variables: [
        { name: "environment", values: ["production"] }
        { name: "region", values: ["us-east-1", "eu-west-1"] }
      ]
      filter: "env = 'production' AND service = 'checkout'"
    }
  )
}
```
</Collapser>
</CollapserGroup>

<Callout variant="important">
Les URL de snapshot sont accessibles publiquement sans authentification et expirent après 3 mois. Partagez-les avec précaution conformément aux politiques de données de votre organisation.
</Callout>

## Exporter un graphique sous forme d’image [#api-widget-snapshot]

La mutation `dashboardWidgetCreateSnapshotUrl` génère une URL vers un instantané PDF ou PNG d’un seul widget de graphique. Le widget n’a pas besoin d’exister sur un dashboard ; vous pouvez le définir en ligne, ce qui est utile pour générer des instantanés de graphiques par programmation.

**Schéma de mutation :**

```graphql
mutation {
  dashboardWidgetCreateSnapshotUrl(
    widget: DeclarativeUiWidget!
    params: DashboardWidgetSnapshotUrlInput
  ): WidgetSnapshotResult
}

type WidgetSnapshotResult {
  url: String!
}
```

L’argument `params` est facultatif. Utilisez-le pour modifier le format de sortie ou la taille de l’instantané.

Le paramètre `widget` accepte un `DeclarativeUiWidget` — un objet JSON avec trois couches imbriquées :

```
declarative/widget envelope
└── widget node        ← title and widget-level props
    └── visualization  ← visualization type and configuration
```

```json
{
  "type": "declarative/widget",
  "version": 1,
  "content": {
    "type": "widget",
    "props": {
      "title": "My Chart Title"
    },
    "content": {
      "type": "visualization",
      "id": "viz.line",
      "props": {
        // visualization-specific config (nrqlQueries, colors, thresholds, etc.)
      }
    }
  }
}
```

<CollapserGroup>
<Collapser id="line-chart-snapshot" title="Exporter un graphique linéaire">
```graphql
mutation {
  dashboardWidgetCreateSnapshotUrl(
    widget: {
      version: 1
      type: "declarative/widget"
      content: {
        type: "widget"
        props: { title: "Throughput by environment" }
        content: {
          type: "visualization"
          id: "viz.line"
          props: {
            nrqlQueries: [
              {
                accountIds: [YOUR_ACCOUNT_ID]
                query: "SELECT count(*) FROM Transaction TIMESERIES"
              }
            ]
            legend: { enabled: true }
          }
        }
      }
    }
  ) {
    url
  }
}
```
</Collapser>

<Collapser id="billboard-snapshot" title="Exporter un graphique billboard avec des seuils">
```graphql
mutation {
  dashboardWidgetCreateSnapshotUrl(
    widget: {
      version: 1
      type: "declarative/widget"
      content: {
        type: "widget"
        props: { title: "Error rate" }
        content: {
          type: "visualization"
          id: "viz.billboard"
          props: {
            nrqlQueries: [
              {
                accountIds: [YOUR_ACCOUNT_ID]
                query: "SELECT percentage(count(*), WHERE error IS true) AS 'Error rate' FROM Transaction SINCE 1 hour ago"
              }
            ]
            thresholds: [
              { alertSeverity: "WARNING", value: 1 }
              { alertSeverity: "CRITICAL", value: 5 }
            ]
          }
        }
      }
    }
  ) {
    url
  }
}
```
</Collapser>
</CollapserGroup>

<Callout variant="tip">
Le champ legacy `actor.account.nrql.staticChartUrl` dans NerdGraph reste disponible, mais ne prend pas en charge les dernières fonctionnalités de visualisation telles que les seuils, le formatage des couleurs, et les nouveaux types de graphiques. `dashboardWidgetCreateSnapshotUrl` est l’approche recommandée à l’avenir.
</Callout>

<Callout variant="important">
`dashboardWidgetCreateSnapshotUrl` les URL d’instantané sont accessibles publiquement sans authentification et expirent après 3 mois.
</Callout>

## Dépannage [#troubleshooting]

Voici ce qu&apos;il faut faire si vous rencontrez l&apos;une des erreurs suivantes lorsque vous essayez d&apos;exporter un dashboard:

* Depuis New Relic UI: <DNT>**We ran into an error while creating the PDF. Please try again**</DNT>

* Extrait de New Relic NerdGraph : <DNT>**Operation on dashboard entity failed with guid:YOUR\_GUID with cause: Error 504: upstream request timeout**</DNT>

Ces erreurs peuvent se produire si l&apos;exportation dépasse le temps de réponse maximal de l&apos;API. Vérifiez si des widgets sur votre dashboard utilisent une grande fenêtre de temps — par exemple, en comparant des données sur un mois entier. Si c&apos;est le cas, essayez de réduire la fenêtre de temps.

Une autre cause possible est un dashboard avec un grand nombre de widgets. Essayez de supprimer les widgets inutilisés pour voir si cela résout l&apos;erreur.
