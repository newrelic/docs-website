Arrête une application web Azure App Service en cours d’exécution. Utilisez cette action pour arrêter une application de manière planifiée, pendant une maintenance, ou dans le cadre d’un workflow de contrôle des coûts.

Pour la configuration de l’authentification, consultez les [actions Azure App Service](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-appservice).

<TabsPageItem id="azureappservicestopexample">
```yaml
name: stopAzureAppService
description: Stop a running Azure App Service
steps:
  - name: stop_app_service
    type: action
    action: azure.appService.stop
    version: 1
    inputs:
      clientId: ${{ :secrets:azure-client-id }}
      clientSecret: ${{ :secrets:azure-client-secret }}
      tenantId: ${{ :secrets:azure-client-tenant }}
      subscriptionId: "12345678-1234-1234-1234-123456789abc"
      resourceGroupName: "my-resource-group"
      appServiceName: "my-web-app"
    next: end
```
