Cette page fournit une référence pour toutes les actions d&apos;alerte New Relic disponibles dans le catalogue des actions d&apos;automatisation workflow. Ces actions vous permettent de créer, de mettre à jour, de supprimer, d&apos;obtenir, et de rechercher des règles d’alerte, des conditions NRQL (statiques et de base de référence), des conditions composées, et des règles de mise en sourdine directement depuis un workflow.

## Prérequis

Avant d&apos;utiliser les actions d&apos;alerte New Relic dans l&apos;automatisation workflow, assurez-vous de disposer de :

* Un compte New Relic avec les permissions appropriées pour gérer les alertes.
* Un ID de compte New Relic pour le compte où résident les ressources d&apos;alerte.
