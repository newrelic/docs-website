Ferme un problème New Relic Alert Intelligence ouvert une fois la remédiation terminée.

Pour les prérequis, consultez [Actions de New Relic Issue](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/issue/newrelic-issue#prerequisites).

## Résoudre le problème

L’identifiant de l’action est `newrelic.issue.resolve`.

Résout un problème New Relic ouvert (AI Issues), en le fermant une fois que les étapes de remédiation sont terminées. L’état du problème passe à `CLOSED`, et New Relic enregistre la résolution sur l’enregistrement du problème. Construit sur `newrelic.nerdgraph.execute`.
