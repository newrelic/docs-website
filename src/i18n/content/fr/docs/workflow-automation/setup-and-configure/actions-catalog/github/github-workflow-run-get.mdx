Récupère les détails, le statut, et la conclusion d&apos;une exécution de workflow GitHub Actions spécifique par son Run ID numérique. Le Run ID est généralement obtenu à partir d&apos;une étape `gitHub.workflowRun.trigger`, ou `gitHub.workflowRun.list` précédente.

Pour la configuration de l’authentification, consultez [les actions d’exécution de workflow GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run).

<td>
```yaml
name: poll_workflow_run
description: Get the status of a specific GitHub Actions workflow run
steps:
  - name: get_run
    type: action
    action: gitHub.workflowRun.get
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      runId: ${{ .steps.trigger_run.outputs.response.workflow_run_id }}
      selectors:
        - name: status
          expression: ".status"
        - name: conclusion
          expression: ".conclusion"
        - name: htmlUrl
          expression: ".html_url"
    next: end
```
