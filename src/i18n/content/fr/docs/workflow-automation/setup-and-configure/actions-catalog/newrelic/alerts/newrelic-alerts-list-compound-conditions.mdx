L’identifiant de l’action est `newrelic.alerts.listCompoundConditions`.

Répertorie les conditions d’alerte composées pour un compte avec un filtrage facultatif par ID et une pagination basée sur un curseur. Les conditions composées ne sont pas disponibles via une action get distincte : il s’agit de la seule action qui expose la structure de leurs composants.
