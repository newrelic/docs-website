Cette page fournit une référence pour toutes les actions de problème New Relic disponibles dans le catalogue des actions d’automatisation workflow. Ces actions vous permettent d’acquitter, de désacquitter et de résoudre les problèmes d’Alert Intelligence, et d’effectuer une requête sur les problèmes pour activer la logique conditionnelle dans vos workflow.

## Prérequis

Avant d’utiliser les actions d’incident New Relic dans l’automatisation workflow, assurez-vous de disposer de :

* Un compte New Relic avec les permissions appropriées pour gérer les problèmes d’Alert Intelligence.
* Les autorisations nécessaires pour les services New Relic spécifiques que vous prévoyez d&apos;utiliser.

## Actions d’incident

<CollapserGroup>
  <Collapser id="newrelic.issue.acknowledge" title="Accuser réception du problème">
    Acquitte un problème New Relic ouvert (AI Issues), en le marquant comme `ACKNOWLEDGED`. New Relic enregistre qui l’a acquitté et l’horodatage sur l’enregistrement du problème (`acknowledgedBy` / `acknowledgedAt`) comme effet secondaire de la mutation. Construit sur `newrelic.nerdgraph.execute`.
