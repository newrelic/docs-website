L’identifiant de l’action est `newrelic.alerts.updateMutingRule`.

Met à jour une règle de mise en sourdine existante. Tous les champs, à l&apos;exception de `accountId` et `id`, sont facultatifs : seuls les champs que vous renseignez sont modifiés.

    <TabsPageItem id="muting-update-example">
      L&apos;exemple suivant désactive une règle de mise en sourdine après la fin d&apos;une fenêtre de déploiement.

      <table>
        <thead>
          <tr>
            <th>
              Exemple de workflow
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: update_muting_rule
              description: Disable a muting rule
              steps:
                - name: updateMutingRule
                  type: action
                  action: newrelic.alerts.updateMutingRule
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    id: ${{ .workflowInputs.mutingRuleId }}
                    enabled: false
                  next: end
              ```
