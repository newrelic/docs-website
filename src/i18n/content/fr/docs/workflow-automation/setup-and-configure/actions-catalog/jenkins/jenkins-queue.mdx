Cette page fournit une référence pour les actions de file d’attente Jenkins disponibles dans le catalogue des actions d’automatisation de workflow. Utilisez ces actions pour inspecter et gérer les builds en attente dans la file d’attente de build Jenkins.

## Prérequis

Avant d’utiliser les actions de file d’attente Jenkins dans l’automatisation workflow, vous avez besoin de :

* Un serveur Jenkins accessible depuis New Relic Workflow Automation via HTTPS. Si votre instance Jenkins est derrière un pare-feu ou dans un réseau privé, autorisez l’accès entrant depuis New Relic Workflow Automation.
* Un jeton d’API Jenkins pour le compte sous lequel le workflow s’exécute. Générez-en un depuis votre profil utilisateur Jenkins : **Configure &gt; API Token &gt; Add new Token**.
* Un secret dans le New Relic Secrets Service contenant la valeur encodée en Base64 de `username:apiToken`. Référencez-le dans le workflow en tant que `${{ :secrets:<keyName> }}`.

## Obtenir un élément de la file d’attente Jenkins

L’identifiant de l’action est `jenkins.queue.getItem`.

Obtient les détails de l’élément de la file d’attente, y compris le numéro de build une fois que l’exécution commence. Utilisez cette action pour interroger la file d’attente après avoir déclenché un build avec [`jenkins.job.trigger`](/docs/workflow-automation/setup-and-configure/actions-catalog/jenkins/jenkins-job#trigger-a-jenkins-job) afin de récupérer le numéro de build nécessaire pour d’autres actions de job.

Le champ `executable.number` de la réponse contient le numéro de build une fois que le build commence à s’exécuter. Il est `null` tant que l’élément est encore dans la file d’attente.

      L’exemple suivant déclenche un build et interroge la file d’attente jusqu’à ce que le numéro de build soit disponible.

      <table>
        <thead>
          <tr>
            <th>
              Exemple de workflow
            </th>

          <tr>
            <td>
              ```yaml
              name: poll-jenkins-queue
              description: 'Trigger a build and poll the queue until the build number is available'
              steps:
                - name: trigger_build
                  type: action
                  action: jenkins.job.trigger
                  version: 1
                  inputs:
                    authToken: ${{ :secrets:jenkinsAuthToken }}
                    url: "https://jenkins.example.com"
                    jobName: "my-application-build"
                    selectors:
                      - name: "queueId"
                        expression: ".queueId"
                  next: poll_queue

                - name: poll_queue
                  type: loop
                  for:
                    in: ${{ [range(0; 10)] }}
                    steps:
                      - name: get_queue_item
                        type: action
                        action: jenkins.queue.getItem
                        version: 1
                        inputs:
                          authToken: ${{ :secrets:jenkinsAuthToken }}
                          url: "https://jenkins.example.com"
                          queueId: ${{ .steps.trigger_build.outputs.queueId }}
                          selectors:
                            - name: "buildNumber"
                              expression: ".responseBody | fromjson.executable.number // null"

                      - name: check_if_started
                        type: switch
                        switch:
                          - condition: ${{ .steps.get_queue_item.outputs.buildNumber != null }}
                            next: end
                        next: wait_and_retry

                      - name: wait_and_retry
                        type: wait
                        seconds: 2
                        next: continue
              ```
            </td>
          </tr>

## Annuler un build Jenkins en file d’attente

L’identifiant de l’action est `jenkins.queue.cancel`.

Annule un build Jenkins en file d’attente avant qu’il ne commence à s’exécuter. Nécessite un `queueId` obtenu lors d’un appel `jenkins.job.trigger` précédent.

Cette action échoue si le build a déjà commencé à s&apos;exécuter. Pour arrêter un build déjà en cours d’exécution, utilisez plutôt [`jenkins.job.stop`](/docs/workflow-automation/setup-and-configure/actions-catalog/jenkins/jenkins-job#stop-a-running-jenkins-build).
