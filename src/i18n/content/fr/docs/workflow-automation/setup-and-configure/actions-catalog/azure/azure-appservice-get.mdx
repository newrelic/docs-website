Récupère les détails et l&apos;état actuel d&apos;une application web Azure App Service. Utile pour vérifier si une application est en cours d&apos;exécution avant de décider de la démarrer, de l&apos;arrêter, ou de la redémarrer.

Pour la configuration de l’authentification, consultez les [actions Azure App Service](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-appservice).

<TabsPageItem id="azureappservicegetexample">
```yaml
name: getAzureAppService
description: Get the current state of an Azure App Service
steps:
  - name: get_app_service
    type: action
    action: azure.appService.get
    version: 1
    inputs:
      clientId: ${{ :secrets:azure-client-id }}
      clientSecret: ${{ :secrets:azure-client-secret }}
      tenantId: ${{ :secrets:azure-client-tenant }}
      subscriptionId: "12345678-1234-1234-1234-123456789abc"
      resourceGroupName: "my-resource-group"
      appServiceName: "my-web-app"
      selectors:
        - name: appState
          expression: ".response.properties.state"
    next: end
```
