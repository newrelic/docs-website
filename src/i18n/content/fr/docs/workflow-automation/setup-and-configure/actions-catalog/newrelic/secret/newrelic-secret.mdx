Cette page fournit une référence pour les actions New Relic Secrets Management disponibles dans le catalogue des actions d’automatisation de workflow. Ces actions vous permettent de lister les secrets et d’inspecter l’historique de leurs versions directement depuis une définition de workflow.

<Callout variant="important">
Il n’y a aucune action pour récupérer la valeur d’un secret. Déchiffrer un secret via une action de workflow exposerait la valeur dans l’historique et les logs de l’exécution. Pour utiliser la valeur d’un secret comme entrée d’une étape de workflow, référencez-la directement en utilisant la syntaxe `${{ :secrets:keyName }}` à la place.
</Callout>

## Prérequis

Avant d&apos;utiliser les actions secrètes New Relic dans l&apos;automatisation workflow, assurez-vous de disposer de :

* Un compte New Relic avec les autorisations appropriées pour lire Secrets Management.
* Le `scopeId` (ID de compte ou ID d’organisation) et `scopeType` (`ACCOUNT` ou `ORGANIZATION`) pour le périmètre sur lequel vous souhaitez faire une requête.

L’identifiant de l’action est `newrelic.secret.listVersions`.

Liste toutes les versions d’un secret New Relic Secrets Management, y compris les versions supprimées logiquement lorsque cela est demandé.

```yaml

steps:
  - name: listSecretVersions
    type: action
    action: newrelic.secret.listVersions
    version: 1
    inputs:
      key: "jira_auth_token"
      scopeId: "11933347"
      scopeType: "ACCOUNT"
      fetchDeleted: true
      selectors:
        - name: latestVersion
          expression: ".data.customerAdministration.secretVersions.latestVersion"
    next: end
```

## Lister les secrets [#list-secrets]

L’identifiant de l’action est `newrelic.secret.list`.
