Cette page fournit une référence pour les actions AWS Bedrock disponibles dans le catalogue des actions d&apos;automatisation des workflows. Utilisez ces actions pour invoquer des agents Bedrock dans le cadre de vos définitions de workflow.

## Prérequis

Avant d&apos;utiliser les actions AWS Bedrock dans l&apos;automatisation workflow, assurez-vous de disposer de :

* Un compte AWS disposant des autorisations appropriées.
* Informations d’identification AWS configurées (informations d’identification de l’utilisateur IAM, ARN du rôle IAM, ou informations d’identification de session). Au moins une option d’informations d’identification doit être fournie : le rôle IAM est prioritaire sur les clés d’accès statiques.
* Les autorisations IAM nécessaires pour les opérations Bedrock (`bedrock:InvokeAgent`, `bedrock:InvokeModel`).

Consultez la section [Configurer les identifiants AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials/) pour savoir comment créer des utilisateurs et des rôles IAM, et configurer des identifiants AWS statiques et de session pour l&apos;intégration aux actions AWS de Workflow Automation.

## Invoquer un agent Bedrock

L’identifiant de l’action est `aws.bedrock.invokeAgent`.

Invoque un agent AWS Bedrock avec un prompt et renvoie la réponse de l’agent.
