Signale des événements personnalisés à New Relic.

Pour les prérequis, voir [Actions New Relic Ingest](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/ingest/newrelic-ingest#prerequisites).

## Envoyer des événements à New Relic

L’identifiant de l’action est `newrelic.ingest.sendEvents`.

Signale un événement personnalisé à New Relic.

    <TabsPageItem id="newrelic-ingest-send-events-example">
      L’exemple suivant envoie plusieurs événements personnalisés avec des attributs partagés et par événement, puis les récupère avec une requête NRQL.

      <table>
        <thead>
          <tr>
            <th>
              Exemple de workflow
            </th>
          </tr>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: heartbeat_newrelicIngestSendEvents

              workflowInputs:
                cellName:
                  type: String

              steps:
                - name: runAction
                  type: action
                  action: newrelic.ingest.sendEvents
                  version: 1
                  inputs:
                    attributes:
                      colour: red
                      id: 1234
                    events:
                      - eventType: HeartBeat
                        test: "OK"
                        attributes:
                          foo: bar
                      - eventType: HeartBeat1234
                        test: "OK1234"
                        attributes:
                          foo: bar
                      - eventType: HeartBeat12345
                        test: "OK12345"
                        attributes:
                          foo: bar
                          colour: yellow
                      - eventType: HeartBeat12345678
                        test: "OK12345678"
                    selectors:
                      - name: success
                        expression: ".success"
              ```

              **Résultat attendu :**

              ```yaml
                {
                  "success": true
                }
              ```

              **Récupérer l&apos;événement :**

              Une fois un workflow exécuté avec succès, vous pouvez récupérer l&apos;événement associé en exécutant une requête sous le compte qui a exécuté le workflow:

              ```sql
              SELECT * FROM HeartBeat
              ```
