Le catalogue d’actions New Relic fournit des actions prédéfinies pour les fournisseurs cloud, les outils DevOps, les plateformes ITSM et la propre plateforme de New Relic. Utilisez ces actions comme étapes dans vos automatisations de workflow pour déclencher des déploiements, gérer les incidents et automatiser les tâches opérationnelles à travers vos outils et services.

Les actions suivent une convention de dénomination hiérarchique : `company.product.action`
