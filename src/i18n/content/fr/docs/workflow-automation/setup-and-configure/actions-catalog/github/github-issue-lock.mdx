Verrouille un ticket GitHub, restreignant qui peut ajouter de nouveaux commentaires.

Pour la configuration de l’authentification, consultez les [actions de ticket GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-issue).

              description: Lock a GitHub issue
              steps:
                - name: lock_issue
                  type: action
                  action: gitHub.issue.lock
                  version: 1
                  inputs:
                    token: ${{ :secrets:github-PAT-token }}
                    owner: your_user_name
                    repo: test-workflow
                    issueNumber: 7
                    lockReason: resolved
                  next: end
