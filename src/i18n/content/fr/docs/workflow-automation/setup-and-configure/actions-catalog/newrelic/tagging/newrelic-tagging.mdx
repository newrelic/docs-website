Cette page fournit une référence pour toutes les actions de tag New Relic disponibles dans le catalogue des actions d&apos;automatisation des workflows. Ces actions vous permettent d&apos;ajouter, de remplacer, et de supprimer des tags sur les entités New Relic directement depuis vos workflows.

## Prérequis

Avant d&apos;utiliser les actions de tag New Relic dans l&apos;automatisation workflow, assurez-vous de disposer de :

* Un compte New Relic avec les autorisations appropriées pour gérer les tags d&apos;entité.
