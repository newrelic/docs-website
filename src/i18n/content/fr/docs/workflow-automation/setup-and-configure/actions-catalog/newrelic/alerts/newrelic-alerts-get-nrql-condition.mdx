L’identifiant de l’action est `newrelic.alerts.getNrqlCondition`.

Récupère les détails d&apos;une seule condition d’alerte NRQL. Fonctionne à la fois pour les types de conditions statiques et de base de référence.

              steps:
                - name: getCondition
                  type: action
                  action: newrelic.alerts.getNrqlCondition
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    id: ${{ .workflowInputs.conditionId }}
                    selectors:
                      - name: conditionName
                        expression: ".data.actor.account.alerts.nrqlCondition.name"
