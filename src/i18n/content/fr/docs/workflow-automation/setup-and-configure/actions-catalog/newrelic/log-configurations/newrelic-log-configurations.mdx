Cette page fournit une référence pour les actions de configuration de New Relic Logs disponibles dans le catalogue des actions d’automatisation des workflows. Utilisez ces actions pour effectuer des requêtes sur les ressources de configuration de log (règles d’analyse, règles de partition des données, expressions et règles d’obfuscation, et paramètres de pipeline), et exécuter des opérations telles que la validation des modèles Grok et la mise à jour de la configuration de pipeline, directement depuis une définition de workflow.

## Prérequis

Avant d’utiliser les actions de configuration de New Relic Logs dans l’automatisation des workflows, assurez-vous de disposer de :

* Un compte New Relic avec les permissions appropriées pour accéder à la configuration de la gestion des logs.
* L’ID de compte pour chaque compte dont vous souhaitez interroger ou mettre à jour la configuration de log.

## Mettre à jour la configuration de pipeline [#update-pipeline-configuration]
