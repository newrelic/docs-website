L’identifiant de l’action est `newrelic.alerts.createMutingRule`.

Crée une nouvelle règle de mise en sourdine pour supprimer les notifications d’alerte pour les violations correspondant à une condition. Planifie facultativement la règle en tant que fenêtre de maintenance récurrente ou ponctuelle.

    <TabsPageItem id="muting-create-example">
      L&apos;exemple suivant crée une règle de mise en sourdine qui supprime les alertes pour une politique pendant les fenêtres de maintenance récurrentes du week-end.

      <table>
        <thead>
          <tr>
            <th>
              Exemple de workflow
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: create_muting_rule
              description: Create a muting rule for a maintenance window
              steps:
                - name: createMutingRule
                  type: action
                  action: newrelic.alerts.createMutingRule
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    name: "Deploy window - checkout service"
                    enabled: true
                    condition:
                      operator: "AND"
                      conditions:
                        - attribute: "policyName"
                          operator: "EQUALS"
                          values:
                            - "Checkout Service"
                    schedule:
                      startTime: "2026-09-01T02:00:00"
                      endTime: "2026-09-01T04:00:00"
                      timeZone: "America/Los_Angeles"
                      repeat: "WEEKLY"
                      weeklyRepeatDays:
                        - "SATURDAY"
                        - "SUNDAY"
                    selectors:
                      - name: mutingRuleId
                        expression: ".data.alertsMutingRuleCreate.id"
                  next: end
              ```
            </td>
          </tr>
