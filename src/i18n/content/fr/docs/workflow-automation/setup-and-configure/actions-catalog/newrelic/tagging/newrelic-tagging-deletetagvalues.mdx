Supprime des valeurs de tag spécifiques d&apos;une entité New Relic, en laissant intactes les autres valeurs sous la même clé.

Pour les prérequis, consultez les [actions de tag de New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites).

## Supprimer les valeurs de tag

L’identifiant de l’action est `newrelic.tagging.deleteTagValues`.

Supprime des paires valeur clé spécifiques des tags d’une entité New Relic. Nous conservons les autres valeurs sous la même clé. Pour supprimer une clé de tag entière et toutes ses valeurs, utilisez plutôt [`newrelic.tagging.deleteTags`](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging-deletetags). Basé sur `newrelic.nerdgraph.execute`.

workflowInputs:
  entityGuid:
    type: String

  - name: removeUiTagValue
    type: action
    action: newrelic.tagging.deleteTagValues
    version: 1
    inputs:
      entityGuid: ${{ .workflowInputs.entityGuid }}
      tagValues:

          value: ui
