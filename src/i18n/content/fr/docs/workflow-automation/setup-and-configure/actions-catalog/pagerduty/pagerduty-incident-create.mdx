## Créer un incident PagerDuty

L’identifiant de l’action est `pagerduty.incident.create`.

Crée un nouvel incident dans PagerDuty avec le service, le titre, la priorité et d&apos;autres attributs optionnels spécifiés.

      L&apos;exemple suivant crée un nouvel incident PagerDuty avec un service, une urgence, un corps, et une politique d&apos;escalade.

      <table>
        <thead>
          <tr>

              Exemple de workflow
            </th>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: create-pagerduty-incident
              description: Create a new PagerDuty incident
              steps:
                - name: create
                  type: action
                  action: pagerduty.incident.create
                  version: 1
                  inputs:
                    token: ${{ :secrets:pagerdutyApiToken }}
                    type: incident
                    title: Test incident
                    service:
                      id: P123456
                      type: service_reference
                    urgency: low
                    body:
                      type: incident_body
                      details: Test Body
                    incidentKey: a12345-b678910-c111213
                    escalationPolicy:
                      id: P54321
                      type: escalation_policy_reference
                    selectors:
                      - name: incidentId
                        expression: .responseBody | fromjson.incident.id
                  next: end
              ```
            </td>
