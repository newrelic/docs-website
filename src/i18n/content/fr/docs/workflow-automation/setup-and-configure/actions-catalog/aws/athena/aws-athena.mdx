Cette page fournit une référence pour les actions AWS Athena disponibles dans le catalogue des actions d&apos;automatisation des workflows. Utilisez ces actions pour exécuter des requêtes SQL sur Amazon Athena, vérifier leur statut d&apos;exécution, et récupérer les résultats directement depuis une définition de workflow.

## Prérequis

Pour les prérequis et la configuration des identifiants, consultez [Configurer les identifiants AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials).

## Démarrer l’exécution d’une requête [#start-query-execution]

L’identifiant de l’action est `aws.athena.startQueryExecution`.

Exécute une requête SQL sur Amazon Athena et renvoie l&apos;ID d&apos;exécution de la requête. Cette action n&apos;attend pas que la requête soit terminée : utilisez `aws.athena.getQueryExecution` pour vérifier le statut et `aws.athena.getQueryResults` pour récupérer les résultats.

**Exemple**

```yaml
name: start-athena-query
description: Run a SQL query against Athena
steps:
  - name: startQuery
    type: action
    action: aws.athena.startQueryExecution
    version: '1'
    inputs:
      awsRoleArn: ${{ :secrets:awsRoleArn }}
      region: us-east-2
      queryString: "SELECT * FROM my_table LIMIT 10"
      database: "my-database"
      catalog: "AwsDataCatalog"
      outputLocation: "s3://my-athena-results-bucket/path/"
      workGroup: "primary"
      selectors:
        - name: queryExecutionId
          expression: ".response.QueryExecutionId"
    next: end
```

## Obtenir les résultats de la requête [#get-query-results]

L’identifiant de l’action est `aws.athena.getQueryResults`.

Renvoie les lignes et les métadonnées de colonne de l’exécution d’une requête Athena terminée. Les résultats sont paginés ; lorsque la réponse inclut un `NextToken`, transmettez-le en tant que `nextToken` lors de l’appel suivant pour récupérer la page suivante. La première ligne de `ResultSet.Rows` est toujours la ligne d’en-tête (noms des colonnes).
