Récupère les réactions emoji sur un message Slack, en attendant jusqu&apos;à un délai d&apos;expiration configurable.

Pour les prérequis, consultez les [actions de chat Slack](/docs/workflow-automation/setup-and-configure/actions-catalog/slack/slack-chat#prerequisites).

## Récupérer les réactions aux messages

L’identifiant de l’action est `slack.chat.getReactions`.

Obtient une réaction d&apos;un message depuis un canal Slack.

            <td>
              ```yaml
              name: GetReactions

              steps:
                - name: getReactions
                  type: action
                  action: slack.chat.getReactions
                  version: 1
                  inputs:
                    token: ${{ :secrets:dn_staging_slack_token }}
                    channelID: ${{ .steps.promptUser.outputs.channelID }}
                    threadTs: ${{ .steps.promptUser.outputs.threadTs }}
                    timeout: ${{ .workflowInputs.timeout }}
                    selectors: ${{ .workflowInputs.selectors }}
              ```

              **Entrées :**

              ```json
              {
                "inputs": [
                  {
                    "key" : "channelID",
                    "value" : "C063JK1RHN1"
                  },
                  {
                    "key" : "threadTs",
                    "value" : "1718897637.400609"
                  },
                  {
                    "key" : "selectors",
                    "value" : "[{\"name\": \"reactions\", \"expression\": \".reactions \"}]"
                  }
                ]
              }
              ```

              **Sorties :**

              ```json
              [
                {
                  "name": "grinning",
                  "users": ["W222222"],
                  "count": 1
                },
                {
                  "name": "question",
                  "users": ["W333333"],
                  "count": 1
                }
              ]
              ```

              Si le délai d&apos;attente expire avant que des réactions ne soient ajoutées, la sortie est une liste vide : `[]`
            </td>
