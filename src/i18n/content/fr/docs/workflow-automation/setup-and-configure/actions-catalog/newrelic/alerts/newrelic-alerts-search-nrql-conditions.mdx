L’identifiant de l’action est `newrelic.alerts.searchNrqlConditions`.

Recherche les conditions d’alerte NRQL (statiques ou de base de référence) avec un filtrage facultatif par nom, règle, texte de requête NRQL, ou opérateur de termes. Prend en charge la pagination basée sur un curseur. L’omission de tous les filtres renvoie toutes les conditions du compte.

              ```yaml
              name: search_nrql_conditions
              description: Search NRQL alert conditions
              steps:
                - name: searchConditions
                  type: action
                  action: newrelic.alerts.searchNrqlConditions
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    policyId: ${{ .workflowInputs.policyId }}
                    nameLike: "error rate"
                    selectors:
                      - name: nrqlConditions
                        expression: ".data.actor.account.alerts.nrqlConditionsSearch.nrqlConditions"
                  next: end
              ```
