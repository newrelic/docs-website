Récupère les détails d’un ticket Jira spécifique à l’aide de sa clé.

Pour la configuration de l’authentification, consultez les [actions de ticket Jira](/docs/workflow-automation/setup-and-configure/actions-catalog/jira/jira-issue).

        <tbody>
          <tr>
            <td>
              ```yaml
              name: get-jira-issue-details
              description: 'Retrieves the summary and status of a specific Jira issue.'
              steps:
                - name: get_issue
                  type: action
                  action: jira.issue.get
                  version: 1
                  inputs:
                    authToken: ${{ :secrets:jiraAuthToken }}
                    domain: mycompany
                    issueKey: PROJ-567
                    parameters:
                      fields: "summary,status,issuetype"
                  next: end
              ```
