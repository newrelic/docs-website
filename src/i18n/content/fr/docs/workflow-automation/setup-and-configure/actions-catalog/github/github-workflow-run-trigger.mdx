Déclenche l’exécution d’un workflow GitHub Actions via un événement `workflow_dispatch`. Le workflow cible doit avoir un déclencheur `workflow_dispatch` configuré. GitHub renvoie HTTP 204 No Content en cas de réussite.

Pour la configuration de l’authentification, consultez [les actions d’exécution de workflow GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run).

```yaml
description: Trigger a GitHub Actions workflow run
steps:
  - name: trigger_run
    type: action
    action: gitHub.workflowRun.trigger
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      workflowId: deploy.yml
      ref: main
      inputs:
        environment: staging
        version: "1.2.3"
    next: end
```
