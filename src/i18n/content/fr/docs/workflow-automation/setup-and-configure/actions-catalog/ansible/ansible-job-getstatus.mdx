Cette page fournit une référence pour l&apos;action `ansible.job.getStatus` disponible dans le catalogue des actions d&apos;automatisation workflow. Utilisez cette action pour récupérer le statut et les détails d&apos;un job de la plateforme Ansible Automation (Automation Controller). Utilisez cette action pour interroger un job créé par [`ansible.job.launch`](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job-launch). Cette action s&apos;appuie sur l&apos;action de base `http.get`.

**Point de terminaison :** `GET https://{host}/api/controller/v2/jobs/{jobId}/`

## Prérequis

Avant d&apos;utiliser cette action dans l&apos;automatisation workflow, assurez-vous de disposer de :

* Une instance de la plateforme Ansible Automation (Automation Controller) accessible via HTTPS.
* Un jeton OAuth2 avec une portée d’écriture (créez-en un sous **Automation Controller → Utilisateurs → Jetons**)
* L&apos;ID de tâche numérique à interroger (généralement le champ `id` renvoyé par `ansible.job.launch`).
