Cette page fournit une référence pour l’action `ansible.job.getStatus` disponible dans le catalogue d’actions d’automatisation de workflow. Utilisez cette action pour interroger un job créé par [`ansible.job.launch`](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job-launch) jusqu’à ce qu’il atteigne un état terminal.

Pour les prérequis, voir [Actions de tâche Ansible](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job#prerequisites).

## Obtenir le statut d&apos;un job Ansible

L’identifiant de l’action est `ansible.job.getStatus`.

Obtient le statut et les détails d&apos;un job Automation Controller. Les statuts des jobs passent de `pending` à `waiting` puis à `running` avant d&apos;atteindre un état terminal : `successful`, `failed`, `error`, ou `canceled`. Le point de terminaison est `GET https://{host}/api/controller/v2/jobs/{jobId}/`.

                  action: ansible.job.getStatus
                  version: 1
                  inputs:
                    host: ${{ :secrets:host }}
                    authToken: ${{ :secrets:ansibleControllerToken }}
                    jobId: "128"
