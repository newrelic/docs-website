Cette page fournit une référence pour les actions AWS CloudWatch disponibles dans le catalogue des actions d&apos;automatisation des workflows. Utilisez ces actions pour récupérer et charger des données de log dans AWS CloudWatch.

## Prérequis

Pour les prérequis et la configuration des identifiants, consultez [Configurer les identifiants AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials).

L&apos;exemple de workflow suivant montre comment utiliser cette action.

```yaml
name: get-lambda-logs
description: 'Retrieve log events from an AWS Lambda function'
workflowInputs:
  region:
    type: String
    defaultValue: us-east-2
  logGroupName:
    type: String
    defaultValue: /aws/lambda/my-function
  logStreamName:
    type: String
    defaultValue: 2023/10/27/[$LATEST]abcdef123456
steps:
  - name: get_events_step
    type: action
    action: aws.cloudwatch.getLogEvents
    version: '1'
    inputs:
      region: ${{ .workflowInputs.region }}
      logGroupName: ${{ .workflowInputs.logGroupName }}
      logStreamName: ${{ .workflowInputs.logStreamName }}
      limit: 100
    next: end
```

L&apos;exemple de workflow suivant montre comment utiliser cette action.

```yaml
name: put-custom-logs
description: 'Upload a batch of custom log events to CloudWatch'
workflowInputs:
  region:
    type: String
    defaultValue: us-east-2
  logGroupName:
    type: String
    defaultValue: my-custom-app-logs
  logStreamName:
    type: String
    defaultValue: instance-01-thread-01
steps:
  - name: upload_logs
    type: action
    action: aws.cloudwatch.putLogEvents
    version: '1'
    inputs:
      region: ${{ .workflowInputs.region }}
      logGroupName: ${{ .workflowInputs.logGroupName }}
      logStreamName: ${{ .workflowInputs.logStreamName }}
      logEvents:
        - timestamp: 1698384000000
          message: "Workflow started successfully"
        - timestamp: 1698384005000
          message: "Step 1 completed"
    next: end
```
