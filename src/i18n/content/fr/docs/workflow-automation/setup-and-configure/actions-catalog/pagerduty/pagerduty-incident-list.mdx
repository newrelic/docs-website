## Liste des incidents PagerDuty

L’identifiant de l’action est `pagerduty.incident.list`.

Récupère une liste d&apos;incidents depuis PagerDuty avec des paramètres de filtrage facultatifs tels que les plages de dates et le statut. Prend en charge tous les paramètres de requête disponibles dans l&apos;[API de liste d&apos;incidents PagerDuty](https://developer.pagerduty.com/api-reference/9d0b4b12e36f9-list-incidents) via la map `parameters`.
