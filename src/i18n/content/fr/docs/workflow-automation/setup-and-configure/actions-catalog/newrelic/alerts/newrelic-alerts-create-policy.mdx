L’identifiant de l’action est `newrelic.alerts.createPolicy`.

Crée une nouvelle règle d’alerte. Une règle regroupe des conditions d’alerte associées et contrôle la façon dont les violations créent des incidents.

          <tr>
            <td>
              ```yaml
              name: create_alert_policy
              description: Create an alert policy
              steps:
                - name: createPolicy
                  type: action
                  action: newrelic.alerts.createPolicy
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    name: "Production Services"
                    incidentPreference: "PER_CONDITION"
                    selectors:
                      - name: policyId
                        expression: ".data.alertsPolicyCreate.id"
                  next: end
              ```
