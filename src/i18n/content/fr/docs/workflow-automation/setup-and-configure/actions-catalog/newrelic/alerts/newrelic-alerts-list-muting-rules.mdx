L’identifiant de l’action est `newrelic.alerts.listMutingRules`.

Liste les règles de mise en sourdine pour un compte. Filtre facultativement par état d’activation. Cette action n’est pas paginée par curseur et renvoie toutes les règles correspondantes dans une seule réponse.

                  action: newrelic.alerts.listMutingRules
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    enabled: true
                    selectors:
