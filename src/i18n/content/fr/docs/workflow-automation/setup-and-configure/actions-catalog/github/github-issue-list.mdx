Répertorie les tickets dans un référentiel GitHub avec un filtrage facultatif par état, étiquettes, personne assignée, et jalon.

Pour la configuration de l’authentification, consultez les [actions de ticket GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-issue).

              ```yaml
              name: github_list_issues_workflow
              description: List open GitHub issues
              steps:
                - name: list_issues
                  type: action
                  action: gitHub.issue.list
                  version: 1
                  inputs:
                    token: ${{ :secrets:github-PAT-token }}
                    owner: your_user_name
                    repo: test-workflow
                    state: open
                    assignee: your_user_name
                    labels: "incident"
                    sort: created
                    direction: desc
                    perPage: 30
                    page: 1
                  next: end
              ```
