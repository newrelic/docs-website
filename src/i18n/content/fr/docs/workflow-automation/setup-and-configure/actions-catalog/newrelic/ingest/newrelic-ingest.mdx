Cette page fournit une référence pour toutes les actions New Relic Ingest disponibles dans le catalogue des actions d’automatisation workflow. Ces actions vous permettent d’envoyer des événements, des logs, et des métriques à New Relic depuis vos workflow.

## Prérequis

Avant d’utiliser les actions New Relic Ingest dans l’automatisation workflow, assurez-vous de disposer de :

* Un compte New Relic disposant des autorisations appropriées.
* Une clé de licence New Relic (requise lors de l’envoi de données à un compte autre que le compte d’exécution du workflow).

Consultez [Clé de licence](/docs/apis/intro-apis/new-relic-api-keys#license-key) pour savoir comment créer et gérer la clé de licence de votre compte New Relic.
