Cette page fournit une référence pour l’action `ansible.job.launch` disponible dans le catalogue d’actions d’automatisation de workflow. Utilisez cette action pour le lancement d’un modèle de tâche de la plateforme Ansible Automation (Automation Controller) à partir d’une étape de workflow.

Pour les prérequis, voir [Actions de tâche Ansible](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job#prerequisites).

## Lancement d&apos;un modèle de tâche Ansible

L’identifiant de l’action est `ansible.job.launch`.

Lancement d’un modèle de tâche de la plateforme Ansible Automation (Automation Controller) et renvoi de la tâche créée. En cas de réussite, renvoie une tâche `id` que vous pouvez utiliser avec [`ansible.job.getStatus`](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job-getstatus) pour interroger la tâche jusqu’à ce qu’elle atteigne un état terminal. Le point de terminaison est `POST https://{host}/api/controller/v2/job_templates/{jobTemplateId}/launch/`.

              ```yaml
              name: launch-ansible-remediation
              description: Launch an Ansible job template to remediate an incident
              steps:
                - name: launch_job
                  type: action
                  action: ansible.job.launch
                  version: 1
                  inputs:
                    host: ${{ :secrets:host }}
                    authToken: ${{ :secrets:ansibleControllerToken }}
                    jobTemplateId: "42"
                    extraVars:
                      target_env: staging
                      app_version: "1.2.3"
                    selectors:
                      - name: jobId
                        expression: ".id"
                  next: end
              ```
