Cette page fournit une référence complète des actions de tâche Ansible disponibles dans le catalogue des actions d&apos;automatisation workflow. Ces actions vous permettent de lancer et de gérer les modèles de tâches de la plateforme Ansible Automation (Automation Controller).

## Prérequis

Avant d&apos;utiliser les actions Ansible dans l&apos;automatisation workflow, assurez-vous de disposer de :

* Une instance de la plateforme Ansible Automation (Automation Controller) accessible via HTTPS.
* Un jeton OAuth2 avec une portée d&apos;écriture pour le lancement de tâches (créez-en un sous **Automation Controller &gt; Users &gt; Tokens**).
* L’ID numérique du modèle de tâche que vous souhaitez lancer.
* Le paramètre `ask_*_on_launch` activé sur le modèle de tâche pour chaque entrée facultative que vous prévoyez d’utiliser (`extraVars`, `limit`, `inventory`).

    Le point de terminaison est `POST https://{host}/api/controller/v2/job_templates/{jobTemplateId}/launch/`
