Cette page fournit une référence pour l’action **Run Autopilot** (`newrelic.autopilot.run`) disponible dans le catalogue d’actions d’automatisation de workflow.

## Exécutez Autopilot [#newrelic-autopilot-run]

Exécute New Relic <DNT>Autopilot</DNT>, un agent d’IA qui analyse les alertes, recherche les causes profondes potentielles, et suggère des actions de remédiation. Vous sélectionnez **Run <DNT>Autopilot</DNT>** dans le catalogue d’actions de l’éditeur de workflow : vous n’avez pas besoin de spécifier un ID d’agent.

    <TabsPageItem id="runautopilotexample">
      ```yaml
      name: demo-run-autopilot
      description: Run Autopilot to analyze an issue
      steps:
        - name: runAutopilot
          type: action
          action: newrelic.autopilot.run
          version: '1'
          inputs:
            prompt: Summarize recent alert activity for my account
            context:
              - description: accountId
                value: "12345678"
              - description: slack_channel_id
                value: "CXXXXXXXXX"
            selectors:
              - name: success
                expression: .success
              - name: error
                expression: .errorMessage
              - name: response
                expression: .response
      ```
