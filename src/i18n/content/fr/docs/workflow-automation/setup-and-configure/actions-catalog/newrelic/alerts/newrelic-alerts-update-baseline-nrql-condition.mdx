L’identifiant de l’action est `newrelic.alerts.updateBaselineNrqlCondition`.

Met à jour une condition d’alerte NRQL de base de référence existante. Tous les champs, à l&apos;exception de `accountId` et `id`, sont facultatifs : seuls les champs que vous fournissez sont modifiés ; les champs omis conservent leur valeur actuelle.

          <tr>
            <td>
              ```yaml
              name: update_baseline_nrql_condition
              description: Update a baseline NRQL alert condition
              steps:
                - name: updateBaselineCondition
                  type: action
                  action: newrelic.alerts.updateBaselineNrqlCondition
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    id: ${{ .workflowInputs.conditionId }}
                    baselineDirection: "UPPER_ONLY"
                  next: end
              ```
