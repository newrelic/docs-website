Fait passer un ticket Jira à un statut différent. Utilisez l’action [Obtenir les transitions de ticket Jira](/docs/workflow-automation/setup-and-configure/actions-catalog/jira/jira-issue-gettransitions) pour récupérer les identifiants de transition disponibles avant d’appeler cette action.

Pour la configuration de l’authentification, consultez les [actions de ticket Jira](/docs/workflow-automation/setup-and-configure/actions-catalog/jira/jira-issue).

              steps:
                - name: transitionJiraIssue
                  type: action
                  action: jira.issue.doTransition
                  version: 1
                  inputs:
                    authToken: ${{ :secrets:jiraAuthToken }}
                    domain: mycompany
                    issueKey: "PROJ-123"
                    transitionId: "181"
