Cette page fournit une référence pour toutes les actions de tâche Ansible disponibles dans le catalogue d&apos;actions d&apos;automatisation de workflow. Utilisez ces actions pour lancer et monitorer les modèles de tâches de la plateforme Ansible Automation (Automation Controller) depuis vos workflows.

## Prérequis

Avant d&apos;utiliser les actions Ansible dans l&apos;automatisation workflow, vous avez besoin de :

* Une instance de la plateforme Ansible Automation (Automation Controller) accessible via HTTPS.
* Un jeton OAuth2 avec une portée d&apos;écriture pour le lancement de tâches (créez-en un sous **Automation Controller &gt; Users &gt; Tokens**).
* Un ID numérique de modèle de job pour le modèle dont vous souhaitez le lancement.
* Le paramètre `ask_*_on_launch` activé sur le modèle de tâche pour chaque entrée facultative que vous prévoyez d’utiliser (`extraVars`, `limit`, `inventory`).
