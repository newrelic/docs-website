Cette page fournit une référence pour les actions AWS Simple Email Service (SES) disponibles dans le catalogue des actions d’automatisation des workflows. Utilisez ces actions pour créer, mettre à jour, récupérer, et supprimer des modèles d’e-mails, et pour envoyer des e-mails via Amazon SES.

## Prérequis

Pour les prérequis et la configuration des identifiants, consultez [Configurer les identifiants AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials).

## Créer un modèle

L’identifiant de l’action est `aws.ses.createTemplate`.

Crée un modèle d’e-mail dans Amazon SES pour l’envoi d’e-mails basés sur un modèle.

<Callout variant="important">
  Au moins `textPart` ou `htmlPart` doit être fourni. SES exige que le modèle contienne un corps de texte dans au moins un format.
</Callout>

```yaml
name: create-ses-template
description: 'Create an email template in Amazon SES'
steps:
  - name: createWelcomeTemplate
    type: action
    action: aws.ses.createTemplate
    version: '1'
    inputs:
      awsRoleArn: "arn:aws:iam::123456789012:role/my-workflow-role"
      region: us-east-2
      templateName: WelcomeEmailTemplate
      subjectPart: "Welcome to Our Service"
      textPart: "Hello, welcome aboard."
      htmlPart: "<h1>Hello</h1><p>Welcome aboard.</p>"
    next: end
```

## Envoyer des e-mails en masse basés sur des modèles

L’identifiant de l’action est `aws.ses.sendBulkTemplatedEmail`.

Envoie un e-mail basé sur un modèle à plusieurs destinataires en un seul appel, avec substitution des données du modèle par destinataire. L’adresse `source` et le `template` référencé doivent déjà exister.

<Callout variant="important">
  AWS limite cette action à 50 entrées `destinations` par appel, avec jusqu’à 50 destinataires (À/Cc/Cci combinés) par destination, et une taille maximale de message généré de 10 Mo. Le dépassement de l’une de ces limites produit une erreur d’API AWS au moment de l’envoi.
</Callout>

Chaque entrée dans `destinations` accepte les champs suivants :

* `destination` — **Obligatoire.** Objet avec `toAddresses`, `ccAddresses`, et/ou `bccAddresses` (chacun étant une liste de chaînes).
* `replacementTemplateData` — **Facultatif.** Chaîne JSON des valeurs d’espace réservé par destinataire. Remplace `defaultTemplateData` pour ce destinataire.
* `replacementTags` — **Facultatif.** Liste d’objets `{"name": "...", "value": "..."}` qui remplacent `defaultTags` pour ce destinataire.
