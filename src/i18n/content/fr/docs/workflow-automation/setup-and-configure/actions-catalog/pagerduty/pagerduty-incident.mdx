Cette page fournit une référence pour toutes les actions d&apos;incident PagerDuty disponibles dans le catalogue des actions d&apos;automatisation des workflows. Utilisez ces actions pour créer, récupérer, lister, mettre à jour, et résoudre des incidents PagerDuty directement depuis un workflow.

## Prérequis

Avant d&apos;utiliser les actions PagerDuty dans l&apos;automatisation workflow, vous avez besoin de :

* Un compte PagerDuty avec les permissions appropriées pour gérer les incidents.
* Un jeton d&apos;API PagerDuty (jeton d&apos;utilisateur ou jeton de compte).
* L&apos;adresse e-mail `from` de l&apos;utilisateur effectuant la demande (requise pour les jetons de compte sur les actions concernées).
