Cette page fournit une référence pour les actions New Relic Lens disponibles dans le catalogue des actions d’automatisation workflow. Ces actions vous permettent d’exécuter des requêtes ANSI SQL sur des sources de données connectées via New Relic Lens directement depuis une étape de workflow.

## Prérequis

Avant d’utiliser les actions New Relic Lens dans l’automatisation workflow, assurez-vous de disposer de :

* Un compte New Relic disposant des autorisations appropriées.
* Une ou plusieurs sources de données connectées dans New Relic Lens.
* Les permissions nécessaires pour le service New Relic Lens.
