Liste les applications web Azure App Service dans un groupe de ressources. Renvoie des résultats paginés : si le groupe de ressources contient suffisamment d&apos;applications pour s&apos;étendre sur plusieurs pages, un champ `nextLink` est inclus dans la réponse pour récupérer la page suivante.

Pour la configuration de l’authentification, consultez les [actions Azure App Service](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-appservice).

Si la réponse inclut un champ `nextLink`, il y a des pages de résultats supplémentaires. Capturez-le avec un sélecteur et appelez `azure.execute.api` directement avec cette URL en tant que `urlPath` pour récupérer la page suivante.

<TabsPageItem id="azureappservicelistexample">
```yaml
name: listAzureAppServices
description: List Azure App Services in a resource group
steps:
  - name: list_app_services
    type: action
    action: azure.appService.list
    version: 1
    inputs:
      clientId: ${{ :secrets:azure-client-id }}
      clientSecret: ${{ :secrets:azure-client-secret }}
      tenantId: ${{ :secrets:azure-client-tenant }}
      subscriptionId: "12345678-1234-1234-1234-123456789abc"
      resourceGroupName: "my-resource-group"
      selectors:
        - name: appNames
          expression: "[.response.value[].name]"
        - name: nextLink
          expression: ".response.nextLink // \"\""
    next: end
```
