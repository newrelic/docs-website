Liste les exécutions de workflow GitHub Actions pour un référentiel, avec un filtrage facultatif par workflow, branche, événement, statut, et plus. Si `workflowId` est fourni, la liste est limitée à ce workflow spécifique ; sinon, elle renvoie les exécutions de tous les workflow du référentiel.

Pour la configuration de l’authentification, consultez [les actions d’exécution de workflow GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run).

<tr>
<td>
```yaml
name: list_workflow_runs
description: List GitHub Actions workflow runs for a specific workflow
steps:
  - name: list_runs
    type: action
    action: gitHub.workflowRun.list
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      workflowId: deploy.yml
      branch: main
      status: completed
      resultsPerPage: 10
      selectors:
        - name: totalCount
          expression: ".total_count"
        - name: latestRunId
          expression: ".workflow_runs[0].id"
        - name: latestConclusion
          expression: ".workflow_runs[0].conclusion"
    next: end
```
