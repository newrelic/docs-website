L’identifiant de l’action est `newrelic.alerts.searchAsNrqlConditions`.

Recherche les conditions d’alerte classiques (legacy) dans leur format converti en NRQL. Prend en charge le filtrage facultatif par nom, politique, ou produit source, et la pagination par curseur.

              ```yaml
              name: search_as_nrql_conditions
              description: Search classic conditions in NRQL format
              steps:
                - name: searchAsNrqlConditions
                  type: action
                  action: newrelic.alerts.searchAsNrqlConditions
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    nameLike: "error rate"
                    selectors:
                      - name: nrqlConditions
                        expression: ".data.actor.account.alerts.asNrqlConditionsSearch.nrqlConditions"
                  next: end
              ```
