Cette page fournit une référence pour les actions New Relic NerdGraph disponibles dans le catalogue des actions d&apos;automatisation des workflows. Ces actions vous permettent d&apos;exécuter des requêtes et des mutations NerdGraph.

## Prérequis

Avant d&apos;utiliser les actions New Relic NerdGraph dans l&apos;automatisation des workflows, assurez-vous de disposer de :

* Un compte New Relic disposant des autorisations appropriées.
* Une clé de licence New Relic (si vous envoyez des données vers un compte différent).
* Les autorisations nécessaires pour les services New Relic spécifiques que vous prévoyez d&apos;utiliser.

Consultez [Clé de licence](/docs/apis/intro-apis/new-relic-api-keys#license-key) pour savoir comment créer et gérer la clé de licence de votre compte New Relic.

## Exécuter la requête NerdGraph

L’identifiant de l’action est `newrelic.nerdgraph.execute`.

Exécute une commande GraphQL sur l&apos;API NerdGraph de New Relic. La commande peut être soit une requête, soit une mutation.
