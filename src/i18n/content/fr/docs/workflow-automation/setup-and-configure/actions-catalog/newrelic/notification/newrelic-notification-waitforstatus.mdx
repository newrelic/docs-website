L’identifiant de l’action est `newrelic.notification.waitForStatus`.

Interroge sur le résultat de la distribution d&apos;une notification envoyée par une étape `newrelic.notification.send` précédente. À partir d&apos;un `sessionId`, cette action interroge `NrNotificationsEvent` jusqu&apos;à ce que la notification atteigne un état terminal (`SUCCESS` ou `FAIL`) ou que le `timeout` spécifié s&apos;écoule. Pour les destinations Slack, renvoie également la valeur `thread_ts` nécessaire pour répondre dans le fil de discussion créé par la notification.

Exemple de workflow : envoyer une notification Slack et attendre la confirmation de livraison

<td>
```yaml
name: notify_and_wait
description: Send a Slack notification then wait for its delivery status
steps:
  - name: sendNotification
    type: action
    action: newrelic.notification.send
    version: 1
    inputs:
      type: slack
      destinationId: "your-destination-id"
      parameters:
        channel: "your-slack-channel"
        text: "Deployment finished"
      selectors:
        - name: sessionId
          expression: ".response.sessionId"
    next: waitForStatus

  - name: waitForStatus
    type: action
    action: newrelic.notification.waitForStatus
    version: 1
    inputs:
      sessionId: ${{ .steps.sendNotification.outputs.sessionId }}
      timeout: 15
      selectors:
        - name: deliveryStatus
          expression: ".notificationStatus.status"
        - name: threadTs
          expression: ".notificationStatus.threadTs"
    next: end
```
</td>
