Cette page fournit une référence pour les actions AWS EventBridge disponibles dans le catalogue des actions d’automatisation des workflows. Utilisez ces actions pour émettre des événements, gérer l’état des règles et exécuter des opérations d’archivage, de relecture et de source d’événements partenaire.

## Prérequis

Avant d&apos;utiliser AWS Actions dans l&apos;automatisation workflow, assurez-vous de disposer des éléments suivants :

* Un compte AWS disposant des autorisations appropriées.
* Informations d&apos;identification AWS configurées (informations d&apos;identification de l&apos;utilisateur IAM, ARN du rôle IAM ou informations d&apos;identification de session).
* Les autorisations IAM nécessaires pour EventBridge. Au minimum, le rôle IAM ou l’utilisateur nécessite `events:*` sur les ressources cibles.

Consultez la section [Configurer les identifiants AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials/) pour savoir comment créer des utilisateurs et des rôles IAM, et configurer des identifiants AWS statiques et de session pour l&apos;intégration aux actions AWS de Workflow Automation.

## Envoyez un seul événement à un bus d’événements

L’identifiant de l’action est `aws.eventBridge.putEvent`.

Envoie un seul événement personnalisé à un bus d’événements AWS EventBridge afin qu’il puisse être mis en correspondance avec des règles. Il s’agit d’un wrapper pratique à entrée unique : utilisez `aws.eventBridge.putEvents` pour envoyer plusieurs événements en un seul appel.
