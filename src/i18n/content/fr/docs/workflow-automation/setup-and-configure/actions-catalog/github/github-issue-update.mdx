Met à jour un ticket existant dans un référentiel GitHub (titre, corps, état, personnes assignées, étiquettes, et jalon).

Pour la configuration de l’authentification, consultez les [actions de ticket GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-issue).

              ```yaml
              name: github_update_issue_workflow
              description: Update a GitHub issue
              steps:
                - name: update_issue
                  type: action
                  action: gitHub.issue.update
                  version: 1
                  inputs:
                    token: ${{ :secrets:github-PAT-token }}
                    owner: your_user_name
                    repo: test-workflow
                    issueNumber: 7
                    title: Issue has been resolved
                    body: Investigation complete. Closing this issue.
                    state: closed
                    state_reason: completed
                    labels:
                      - resolved
                  next: end
              ```
