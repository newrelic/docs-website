Récupère l&apos;exécution du workflow GitHub Actions la plus récente pour un workflow spécifique. Utile lorsque l&apos;ID d&apos;exécution exact est inconnu, par exemple, immédiatement après le déclenchement d&apos;une exécution. Renvoie toujours au plus une exécution.

Pour la configuration de l’authentification, consultez [les actions d’exécution de workflow GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run).

<tr>
<td>
```yaml
name: get_latest_workflow_run
description: Retrieve the most recent workflow run for a specific workflow
steps:
  - name: get_latest_run
    type: action
    action: gitHub.workflowRun.getLatest
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      workflowId: deploy.yml
      branch: main
      event: workflow_dispatch
      selectors:
        - name: runId
          expression: ".workflow_runs[0].id"
        - name: conclusion
          expression: ".workflow_runs[0].conclusion"
        - name: htmlUrl
          expression: ".workflow_runs[0].html_url"
    next: end
```
</td>
