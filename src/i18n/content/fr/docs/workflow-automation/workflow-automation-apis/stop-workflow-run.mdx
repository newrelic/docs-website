Utilisez la mutation `workflowAutomationStopWorkflowRun` pour arrêter un workflow en cours d&apos;exécution.

`runId`
</td>

<td>
Chaîne
</td>

<td>
(Requis) L&apos;identifiant unique de l&apos;exécution du workflow à arrêter. Obtenu à partir de l&apos;API `StartWorkflowRun`.
</td>

## Demande d&apos;échantillon [#sample-request]

```graphql
mutation {
  workflowAutomationStopWorkflowRun(
    accountId: 12345678
    runId: "7ffbe082-8efa-4d3d-901a-a08bcf22bcd3"
  ) {
    runId
  }
}
```

## Exemple de réponse [#sample-response]

La mutation retourne :

* `runId`: L&apos;identifiant unique de l&apos;exécution du workflow arrêté. Renvoie un `runId` vide si le workflow est introuvable.
