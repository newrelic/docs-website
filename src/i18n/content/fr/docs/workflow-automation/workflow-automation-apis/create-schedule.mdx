Utilisez la mutation `workflowAutomationCreateSchedule` pour créer une planification pour une définition de workflow.

<Callout variant="tip">
Le nombre de planifications et la durée minimale d’une planification donnée sont définis dans [les limites du système de workflow](/docs/workflow-automation/limitations-and-faq/workflow-limits).
</Callout>

### option logLevel [#loglevel-option]

L&apos;option `logLevel` contrôle la quantité d&apos;informations de logging générées pendant l&apos;exécution du workflow.

* `NONE` (par défaut) : ne génère aucune sortie de log.
* `INFO`: fournit des informations au niveau de l&apos;étape.
* `DEBUG`: Ajoute un attribut aux logs de l’étape démarrée avec toutes les entrées de l’étape d’action, en utilisant le format `workflowAutomation.inputs.<inputName>: <inputValue>`.
* `TRACE`: En plus de la sortie `DEBUG`, ajoute un attribut aux logs de l’étape démarrée avec toutes les sorties de l’étape d’action, en utilisant le format `workflowAutomation.outputs.<outputName>: <outputValue>`.

## Demande d&apos;échantillon [#sample-request]

Utilisez le [générateur de requêtes](https://one.newrelic.com/nerdgraph-graphiql?state=b8f3b3a9-8d3e-c03e-5da4-34b98a57ff8f) pour créer et éditer un workflow. Voir [l&apos;explorateur d&apos;API NerdGraph](/docs/apis/nerdgraph/get-started/nerdgraph-explorer).

```graphql
  mutation {
    workflowAutomationCreateSchedule(
      scope: {id: "12345678", type: ACCOUNT}
      definition: {name: "healthyHeartbeat", version: 1}
      cronExpression: "0 0 * * *"
      timezone: "Asia/Kolkata"
      options: {logLevel: DEBUG}
      tags: [{key: "environment", values: ["production"]}]
    ) {
      scheduleId
    }
  }
```
