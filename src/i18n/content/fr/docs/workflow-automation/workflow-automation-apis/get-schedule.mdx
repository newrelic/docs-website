## Demande d&apos;échantillon [#sample-request]

```graphql
    {
      actor {
        account(id: 12345678) {
          workflowAutomation {
            schedule(id: "schedule-id") {
              id
            }
          }
        }
      }
    }
```

## Exemple de réponse [#sample-response]

La requête retourne :

* `schedule.id`: L&apos;identifiant unique de la planification.
