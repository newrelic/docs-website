Utilisez la requête `workflowAutomation.workflowRunInfo` pour récupérer des informations sur une exécution de workflow spécifique, y compris son statut, l&apos;URL du log, et tout état de workflow enregistré pendant l&apos;exécution.

## Demande d&apos;échantillon [#sample-request]

Utilisez le [générateur de requêtes](https://one.newrelic.com/nerdgraph-graphiql?state=03119d23-7b51-7b7a-1c99-d2cd026300e5) pour créer et éditer un workflow. Voir [l&apos;explorateur d&apos;API NerdGraph](/docs/apis/nerdgraph/get-started/nerdgraph-explorer).

```graphql
{
  actor {
    account(id: 12345678) {
      workflowAutomation {
        workflowRunInfo(runId: "8911c7e4-5a1f-4316-90c8-67adde72dd1c") {
          state(keys: ["foo", "count"]) {
            key
            value
          }
          logUrl
          status
        }
      }
    }
  }
}
```

## Exemple de réponse [#sample-response]

La requête retourne :

* `logUrl`: URL pour afficher les logs d&apos;exécution du workflow.
* `status`: L’état actuel de l’exécution du workflow. Valeurs possibles : `STARTED`, `COMPLETED`, `FAILED`, `TIMED_OUT`, `STOPPED`.
* `state`: un éventail d&apos;objets `{ key, value }` pour chaque clé demandée trouvée dans l&apos;état du workflow. Les clés qui ne sont pas présentes dans l&apos;état du workflow sont omises.

```graphql
{
  "data": {
    "actor": {
      "account": {
        "workflowAutomation": {
          "workflowRunInfo": {
            "logUrl": "https://one.newrelic.com/...",
            "status": "COMPLETED",
            "state": [
              { "key": "foo", "value": "bar" },
              { "key": "count", "value": "2" }
            ]
          }
        }
      }
    }
  }
}
```
