Utilisez la mutation `workflowAutomationDeleteWorkflowDefinition` pour supprimer toutes les versions d&apos;une définition de workflow portant le nom spécifié.

<Callout variant="important">
* Pour supprimer une définition, aucune planification ne doit l&apos;utiliser. Si la définition est actuellement utilisée par une planification, la suppression échoue et renvoie une erreur.
* Toutes les exécutions de workflow en cours se poursuivent jusqu&apos;à leur terme même si la définition est supprimée.
</Callout>

```graphql

  workflowAutomationDeleteWorkflowDefinition(

      name
    }
  }
}
```
