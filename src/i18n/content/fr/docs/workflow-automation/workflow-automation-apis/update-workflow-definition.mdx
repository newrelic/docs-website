Utilisez la mutation `workflowAutomationUpdateWorkflowDefinition` pour mettre à jour une définition de workflow existante. Elle renvoie une erreur si la définition du workflow n&apos;existe pas déjà.

## Demande d&apos;échantillon [#sample-request]

```graphql
  mutation {
    workflowAutomationUpdateWorkflowDefinition(
      definition: {yaml: "<workflow definition YAML>"}
      scope: {id: "12345678", type: ACCOUNT}
    ) {
      definition {
        name
        version
        yaml
      }
    }
  }
```

## Exemple de réponse [#sample-response]

La mutation retourne :

* `definition.name`: Le nom de la définition de workflow mise à jour
* `definition.version`: Le nouveau numéro de version de la définition du workflow
* `definition.yaml`: La définition de workflow YAML encodée en base64
