Utilisez la mutation `workflowAutomationDeleteSchedule` pour supprimer la planification d’une définition de workflow. Cette mutation n’arrête aucune exécution de workflow en cours (utilisez la mutation `StopWorkflowRun`).

## Demande d&apos;échantillon [#sample-request]

Utilisez le [générateur de requêtes](https://one.newrelic.com/nerdgraph-graphiql?state=fc314f67-101e-a54a-169a-191d1fd41fd) pour créer et éditer un workflow. Voir [l&apos;explorateur d&apos;API NerdGraph](/docs/apis/nerdgraph/get-started/nerdgraph-explorer).

```graphql
mutation {
  workflowAutomationDeleteSchedule(
    accountId: 12345678
    schedule: {id: "1a71d299-82c2-4b4d-9803-b14523e3a9e7"}
  ) {
    scheduleId
  }
}
```

## Exemple de réponse [#sample-response]

Si le `schedule.id` est introuvable, la structure suivante est renvoyée :

```graphql
{
    "data": {
        "workflowAutomationDeleteSchedule": null
    },
    "errors": [{
        "message": "Could not find schedule with ID MTE2NDk5MDB8TkdFUHxXT1JLRkxPV19TQ0hFRFVMRXwwMTk5MGUzYi04NzAyLTc2M2QtOWUzMy01ZTU1ZThmZTYzYjkl",
        "path": ["workflowAutomationDeleteSchedule"]
    }]
}
```
