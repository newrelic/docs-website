Utilisez la mutation `workflowAutomationSignalWorkflowRun` pour déclencher un signal vers un workflow existant en cours d&apos;exécution. Utilisez ceci pour envoyer un rappel évalué par le workflow pour passer à différentes étapes suivantes. Vous pouvez transmettre des paramètres avec le signal.

## Demande d&apos;échantillon [#sample-request]

Étant donné la définition workflow ci-dessous et un workflow déjà en cours d&apos;exécution

```yaml
name: signalDemo

steps:
  - name: waitStep
    type: wait
    seconds: 300
    signals:
      - name: approve
        next: signalHandler
      - name: cancel
        next: signalHandler

  - name: NoSignalReceived
    type: action
    action: newrelic.ingest.sendLogs
    version: 1
    inputs:
      logs:
        - message: "no signals received"
    next: end

  - name: signalHandler
    type: action
    action: newrelic.ingest.sendLogs
    version: 1
    inputs:
      logs:
        - message: "signal '${{ .steps.waitStep.outputs.signalName }}' was received with: '${{ .steps.waitStep.outputs.signalInputs | tostring }}'"
```

Après le démarrage de ce workflow, cet identifiant d&apos;exécution est renvoyé au démarrage. `107e6df2-aa17-41bc-8065-bfa46bde810b`

Le workflow peut alors être signalé par cette mutation.

```graphql
mutation {
  workflowAutomationSignalWorkflowRun(
    accountId: 12345678
    runId: "107e6df2-aa17-41bc-8065-bfa46bde810b"
    signalName: "approve"
    signalInputs: [
      {key: "foo", value: "bar"}
    ]
  ) {
    runId
  }
}
```
