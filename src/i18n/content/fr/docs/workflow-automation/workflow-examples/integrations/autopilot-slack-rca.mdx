Ce modèle exécute <DNT>[Autopilot](/docs/agentic-ai/autopilot/overview)</DNT> sur une alerte New Relic et publie l’analyse de la cause racine sur un canal Slack. Si <DNT>Autopilot</DNT> ne renvoie aucune réponse utilisable, le workflow envoie une notification d’erreur à la place. Pour les prérequis partagés et les notes de configuration, consultez les [modèles de workflow Autopilot RCA](/docs/workflow-automation/workflow-examples/integrations/autopilot-rca).

Avant d&apos;utiliser ce workflow, assurez-vous d&apos;avoir :

* Destination Slack configurée dans New Relic — voir [Créer des destinations](/docs/workflow-automation/setup-and-configure/create-destinations)
* L’UUID de la destination et le nom du canal Slack cible

Ce workflow effectue les étapes suivantes :

1. Envoie un message Slack initial pour accuser réception de l&apos;alerte et informer l&apos;équipe que la RCA est en cours
2. Exécute <DNT>Autopilot</DNT> avec un prompt d&apos;analyse des causes profondes limité à l&apos;ID du problème de l&apos;alerte
3. Vérifie si <DNT>Autopilot</DNT> a renvoyé une réponse utilisable
4. Reformate la réponse sous forme de blocs Slack Block Kit et publie les résultats sur Slack (si <DNT>Autopilot</DNT> renvoie une réponse)
5. Publie un message d’erreur avec l&apos;ID du problème (si <DNT>Autopilot</DNT> ne renvoie aucune réponse)

Ce workflow utilise `newrelic.autopilot.run` et `newrelic.notification.sendSlack`.

```yaml
name: autopilotSlackRCA
description: Automatically analyze New Relic alerts with Autopilot and send cleanly formatted findings to Slack
workflowInputs:
  issueId:
    type: String
    required: true
    validations:
      - errorMessage: Must be a valid New Relic issue ID in UUID format
        pattern: '^[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}$'
        type: regex
  slackDestinationId:
    type: String
    required: true
    validations:
      - pattern: ^[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}$
        errorMessage: "Invalid format. Please provide a valid UUID."
        type: regex
  channel:
    type: String
    required: true
steps:
  - name: notifyAlertReceived
    type: action
    action: newrelic.notification.sendSlack
    version: 1
    inputs:
      destinationId: ${{ .workflowInputs.slackDestinationId }}
      channel: ${{ .workflowInputs.channel }}
      text: |-
        🔔 *Alert Received — Starting Root Cause Analysis*

        ⏳ Running Autopilot for RCA, please wait...

  - name: runAutopilot
    type: action
    action: newrelic.autopilot.run
    version: 1
    inputs:
      prompt: >-
        Perform a root cause analysis for the following New Relic alert:
        Issue ID: ${{ .workflowInputs.issueId }}
        Provide your comprehensive analysis including Summary, Root Cause, and Remediation Actions.
      selectors:
        - name: analysisRaw
          expression: .response.finalAnswer
        - name: analysisText
          expression: '(.response.finalAnswer | if type=="string" then fromjson else . end).card.body | map(.value) | join("\n\n")'
    ignoreErrors: true

  - name: checkAgentResponse
    type: switch
    switch:
      - condition: ${{ (.steps.runAutopilot.outputs.analysisRaw // "") != "" }}
        next: buildSlackBlocks
    next: sendAutopilotError

  - name: buildSlackBlocks
    type: assign
    inputs:
      blocks: '${{ (.steps.runAutopilot.outputs.analysisText // "") | gsub("\\*\\*"; "*") | gsub("### "; "*") | gsub("## "; "*") as $text | ([ $text / "\n" ]) as $lines | [ { "type": "header", "text": { "type": "plain_text", "text": "✅ Autopilot RCA Complete" } }, { "type": "divider" } ] + [ $lines[][] | select(. != "") | { "type": "section", "text": { "type": "mrkdwn", "text": . } } ] }}'
    next: sendRcaFindings

  - name: sendRcaFindings
    type: action
    action: newrelic.notification.sendSlack
    version: 1
    inputs:
      destinationId: ${{ .workflowInputs.slackDestinationId }}
      channel: ${{ .workflowInputs.channel }}
      blocks: ${{ .steps.buildSlackBlocks.outputs.blocks }}
    next: end

  - name: sendAutopilotError
    type: action
    action: newrelic.notification.sendSlack
    version: 1
    inputs:
      destinationId: ${{ .workflowInputs.slackDestinationId }}
      channel: ${{ .workflowInputs.channel }}
      text: |-
        🟥 *Autopilot RCA Failed*

        Could not extract findings from Autopilot response for issue: ${{ .workflowInputs.issueId }}
        Please investigate manually.
    next: end
```

## Comment ça marche [#how-it-works]

L’étape `runAutopilot` utilise deux sélecteurs pour gérer la variabilité de forme de `finalAnswer` au niveau de la couche d’extraction de données :

* **`analysisRaw`** capture la valeur brute de `finalAnswer`. L’étape `checkAgentResponse` utilise cela pour déterminer si <DNT>Autopilot</DNT> a renvoyé quelque chose.
* **`analysisText`** normalise la valeur — si `finalAnswer` est une chaîne encodée en JSON, il l’analyse d’abord, puis extrait le contenu textuel de `.card.body`. L&apos;étape `buildSlackBlocks` utilise directement `analysisText`, sans aucune analyse supplémentaire.

`buildSlackBlocks` convertit les marqueurs d’en-tête `**bold**`, et `###`/`##` au format mrkdwn de Slack, divise le résultat au niveau des sauts de ligne, et enveloppe chaque ligne non vide dans un bloc Block Kit `section`.
