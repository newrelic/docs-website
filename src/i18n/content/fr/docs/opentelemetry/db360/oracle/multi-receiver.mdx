Vous pouvez configurer le NRDOT Collector pour monitorer plusieurs instances de base de données Oracle à partir d&apos;un seul collecteur. Cela est utile si vous avez plusieurs bases de données Oracle en cours d&apos;exécution sur différents hôtes et que vous souhaitez collecter des métriques à partir de toutes celles-ci à l&apos;aide d&apos;une seule instance NRDOT Collector.

<Steps>
  <Step>
    ## Prérequis [#prerequisites]

    * NRDOT est installé et configuré pour vos instances de base de données Oracle :

      * [CDB](/docs/opentelemetry/db360/oracle/host-cdb)
      * [PDB](/docs/opentelemetry/db360/oracle/host-pdb)
      * [RDS](/docs/opentelemetry/db360/oracle/rds)
      * [ADB](/docs/opentelemetry/db360/oracle/adb)
  </Step>

  <Step>
    ## Ajouter une configuration multi-récepteur [#multi]

    Les exemples suivants montrent comment configurer le Collector NRDOT pour monitorer plusieurs instances de base de données Oracle à l’aide d’une configuration multi-Récepteur. Sélectionnez le type de déploiement qui correspond à votre environnement. Vous pouvez ajouter d’autres Récepteurs selon les besoins pour des instances supplémentaires.

    <CollapserGroup>

  <Step>
    ## Redémarrer NRDOT Collector [#restart]

    Redémarrez le service <DNT>NRDOT Collector</DNT> pour que les modifications de configuration prennent effet. Le collecteur charge les paramètres de configuration une fois au démarrage et ne prend pas en charge le rechargement à chaud. Toutes les modifications apportées à la configuration pendant que le collecteur est en cours d’exécution restent inactives jusqu’à ce que le processus redémarre.

    ```bash
    sudo systemctl restart nrdot-collector.service
    ```
