Vous pouvez utiliser la contribution OpenTelemetry Collector pour la base de données Oracle afin de monitorer votre instance. La contribution OpenTelemetry Collector est un projet soutenu par la communauté qui offre un moyen de collecter des données télémétriques à partir de la base de données Oracle, et de les envoyer à New Relic.

Par défaut, la contribution OpenTelemetry Collector collecte des métriques limitées à partir de la base de données Oracle. Pour envoyer les performances de requête, le temps d’attente, la session, et d’autres métriques avancées, vous devrez configurer la contribution OpenTelemetry Collector. Ce guide vous montre comment la configurer pour collecter des métriques avancées à partir de la base de données Oracle, et les envoyer à New Relic.

<Steps>
  <Step>
    ## Prérequis [#prerequisites]

    * OpenTelemetry Collector Contrib (`otelcol-contrib`) installé et configuré sur votre système. Vous pouvez télécharger la dernière sortie depuis la page des [sorties de l’OpenTelemetry Collector](https://github.com/open-telemetry/opentelemetry-collector-releases/releases).
  </Step>

  <Step>
    ## Activer les métriques UI [#enable]

    Vous pouvez enrichir votre expérience de la plateforme New Relic en ajoutant, et en activant des métriques dans votre fichier de configuration `otelcol-contrib`. En utilisant la configuration fournie dans cette section, vous pouvez alimenter les données pour les pages suivantes dans la plateforme New Relic :

    * <DNT>Overview</DNT>
    * <DNT>Query performance</DNT>
    * <DNT>Wait events</DNT>
    * <DNT>Sessions</DNT>

    <CollapserGroup>
      <Collapser id="overview" title="Activer les métriques de la page Overview">
        La page <DNT>Overview</DNT> affiche une vue d’ensemble de votre instance de base de données Oracle, y compris des métriques clés telles que l’utilisation du CPU, le temps d’attente, les I/O, la mémoire, et l’utilisation des sessions.

        Pour renseigner les données de la page <DNT>Overview</DNT> dans la plateforme New Relic, ajoutez la configuration suivante à votre fichier de configuration `otelcol-contrib` :

        ```yaml
        receivers:
          oracledb:
            # Metrics required by the "Oracle Database Monitoring (OTel)" dashboard
            metrics:
              oracledb.buffer_cache.utilization:
                enabled: true
              oracledb.consistent_gets:
                enabled: true
              oracledb.cpu_time:
                enabled: true
              oracledb.database.cpu.utilization:
                enabled: true
              oracledb.database.wait.utilization:
                enabled: true
              oracledb.db_block_gets:
                enabled: true
              oracledb.enqueue_deadlocks:
                enabled: true
              oracledb.execution.utilization:
                enabled: true
              oracledb.executions:
                enabled: true
              oracledb.hard_parses:
                enabled: true
              oracledb.host.cpu.utilization:
                enabled: true
              oracledb.library_cache.utilization:
                enabled: true
              oracledb.logical_reads:
                enabled: true
              oracledb.logons:
                enabled: true
              oracledb.parse.rate:
                enabled: true
              oracledb.parse_calls:
                enabled: true
              oracledb.pga_memory:
                enabled: true
              oracledb.physical_io.requests:
                enabled: true
              oracledb.physical_reads:
                enabled: true
              oracledb.physical_writes:
                enabled: true
              oracledb.processes.usage:
                enabled: true
              oracledb.sessions.usage:
                enabled: true
              oracledb.sga.usage:
                enabled: true
              oracledb.shared_pool.utilization:
                enabled: true
              oracledb.sql_service.response.duration:
                enabled: true
              oracledb.sqlnet.io.transferred:
                enabled: true
              oracledb.tablespace_size.usage:
                enabled: true
              oracledb.transactions.usage:
                enabled: true
              oracledb.user_commits:
                enabled: true
              oracledb.user_rollbacks:
                enabled: true
            resource_attributes:
              oracle.db.edition:
                enabled: true
        ```
      </Collapser>

      <Collapser id="query-performance" title="Activez les métriques de performance des requêtes, de session, et d'attente">
        Pour alimenter les données des pages <DNT>Query performance</DNT>, <DNT>Wait events</DNT>, et <DNT>Sessions</DNT>, ajoutez la configuration suivante à votre fichier de configuration `otelcol-contrib` :

        ```yaml
        receivers:
          oracledb:
            events:
              db.server.query_sample:
                enabled: true
              db.server.top_query:
                enabled: true
              db.server.session.wait_sample:
                enabled: true
              db.server.top_procedure:
                enabled: true
              db.server.query_plan:
                enabled: true

            top_query_collection:
              max_query_sample_count: 1000
              top_query_count: 200
              collection_interval: 60s
              allowed_comment_keys:
                - nr_service_guid

            query_sample_collection:
              max_rows_per_query: 100
              allowed_comment_keys:
                - nr_service_guid

            session_wait_event_collection:
              max_rows_per_query: 100

            top_procedure_collection:
              max_procedure_sample_count: 1000
              top_procedure_count: 250
              collection_interval: 60s
        ```
      </Collapser>
    </CollapserGroup>
  </Step>

  <Step>
    ## Redémarrez le Collector OpenTelemetry [#restart]

    Redémarrez l&apos;OpenTelemetry Collector pour appliquer les modifications de configuration :

    ```bash
    sudo systemctl restart otelcol-contrib
    ```
  </Step>
</Steps>
