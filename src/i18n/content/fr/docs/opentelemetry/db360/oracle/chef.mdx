Vous pouvez installer et configurer le Collector NRDOT pour le monitoring de la base de données Oracle à l&apos;aide du cookbook Chef `newrelic-install`. Le cookbook installe le collecteur, crée l&apos;utilisateur de la base de données de monitoring, et configure le collecteur lorsque vous exécutez la recette `newrelic-install::default`.

<Callout variant="tip" title="Installation guidée">
Pour installer plutôt via l’UI de New Relic, accédez à <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; Oracle (Database 360)](https://onenr.io/0kjnebKW7Ro)**</DNT>. Cette page traite uniquement de l’installation manuelle.
</Callout>

<Steps>
<Step>
## Prérequis [#prerequisites]

* Un compte New Relic avec une [clé de licence](/docs/apis/intro-apis/new-relic-api-keys/#overview-keys) valide.
* Un [ID de compte](/docs/accounts/accounts-billing/account-structure/account-id) New Relic.
* Oracle Database 19c ou version ultérieure.
* Chef 15 ou version ultérieure.
* Pour Oracle auto-hébergé : Oracle Linux 7, 8, ou 9, avec un accès SSH (avec transfert d’agent) à l’hôte Oracle Database où l’utilisateur SSH peut exécuter `sudo su - oracle` sans prompt de mot de passe.
* Pour Oracle sur AWS RDS : un hôte collecteur exécutant Debian/Ubuntu ou CentOS/RHEL/OEL.
* Pour la base de données Oracle Autonomous (ADB) : un hôte collecteur exécutant Debian/Ubuntu, ou CentOS/RHEL/OEL, avec Oracle Instant Client (`sqlplus`) installé, et sur `PATH`; l’adresse IP de sortie de chaque instance autorisée dans sa liste de contrôle d’accès ADB ; et l’Oracle Wallet de chaque instance téléchargé, et décompressé dans son propre répertoire sur le nœud.
</Step>

<Step>
## Télécharger le cookbook Chef [#download-cookbook]

Téléchargez le `newrelic-install` [livre de recettes Chef](https://supermarket.chef.io/cookbooks/newrelic-install) depuis le Chef Supermarket dans votre répertoire chef-repo :

```bash
knife supermarket install newrelic-install
```
</Step>

<Step>
## Remplacez les attributs par défaut [#configure]

Remplacez les attributs par défaut dans `attributes/default.rb` par les détails de votre compte :

<CollapserGroup>
<Collapser id="chef-host" title="Base de données Oracle auto-hébergée">
Ce cookbook monitore une ou plusieurs instances de base de données Oracle (chacune accessible via SSH) depuis un seul collecteur. Au lieu d’un seul ensemble hôte/conteneur/identifiants, il lit un fichier d’instances (YAML) qui doit déjà exister sur le nœud, listant chaque instance à monitorer, et facultativement un fichier de secrets pour épingler les mots de passe de l’utilisateur de monitoring au lieu de les générer automatiquement. Consultez l’ [installation de la CLI](/docs/opentelemetry/db360/oracle/cli/#install) pour les formats de fichiers exacts.

```ruby
default['newrelic_install']['NEW_RELIC_API_KEY']    = <API key>
default['newrelic_install']['NEW_RELIC_ACCOUNT_ID'] = <Account ID>
default['newrelic_install']['NEW_RELIC_REGION']     = <Region>
default['newrelic_install']['targets'] = [
  'nrdot-collector-oracle'
]
default['newrelic_install']['env']['NR_CLI_ORACLE_INSTANCES_FILE'] = <path to the instances YAML file on the node>
default['newrelic_install']['env']['NR_CLI_ORACLE_SECRETS_FILE']   = <optional path to a secrets file pinning monitoring passwords, on the node>
default['newrelic_install']['env']['NR_CLI_ORACLE_CONFIG_PRESET']  = <1 Basic, 2 Advanced, default 1>
# See all available targets at: https://github.com/newrelic/chef-install
```

```ruby
default['newrelic_install']['NEW_RELIC_API_KEY']    = <API key>

  'nrdot-collector-oracle-rds'

default['newrelic_install']['env']['NR_CLI_ORACLE_CONFIG_PRESET']  = <1 Basic, 2 Advanced, default 1>
```

<Collapser id="chef-adb" title="Oracle Autonomous Database (ADB)">

```ruby
default['newrelic_install']['NEW_RELIC_API_KEY']    = <API key>
default['newrelic_install']['NEW_RELIC_ACCOUNT_ID'] = <Account ID>
default['newrelic_install']['NEW_RELIC_REGION']     = <Region>
default['newrelic_install']['targets'] = [
  'nrdot-collector-oracle-adb'

default['newrelic_install']['env']['NR_CLI_ORACLE_INSTANCES_FILE'] = <path to the instances YAML file on the node>
default['newrelic_install']['env']['NR_CLI_ORACLE_SECRETS_FILE']   = <path to the secrets file (KEY=VALUE per instance) on the node>
# See all available targets at: https://github.com/newrelic/chef-install
```
