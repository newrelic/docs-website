Résolvez les problèmes courants que vous pouvez rencontrer lors du monitoring de votre Microsoft SQL Server avec le NRDOT Collector.

## Problèmes courants [#common-issues]

### Problèmes de connectivité réseau [#network-connectivity]

Si vous rencontrez des problèmes de connectivité réseau avec le Collector NRDOT, exécutez les commandes suivantes pour tester la connectivité vers votre instance SQL Server :

* Pour Windows, exécutez :

  ```shell
  Test-NetConnection -ComputerName <YOUR_IP_ADDRESS> -Port <YOUR_PORT_NUMBER>
  ```

* Pour Linux, exécutez :

  ```bash
  nc -zv <YOUR_IP_ADDRESS> <YOUR_PORT_NUMBER>
  ```

## Les données n&apos;apparaissent pas dans New Relic [#data-not-flowing]

* Pour vérifier les problèmes liés aux limites de débit, exécutez :

  ```sql
  SELECT * FROM NrIntegrationError
  ```

* Si les données ne circulent toujours pas, vérifiez si des règles de suppression sont définies sur vos événements de métrique et de log. Consultez [Supprimer les données de log avec des règles de filtre de suppression](/docs/logs/ui-data/drop-data-drop-filter-rules/) et [Contrôle du Pipeline](/docs/new-relic-control/pipeline-control/overview/).
