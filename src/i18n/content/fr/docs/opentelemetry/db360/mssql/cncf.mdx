Vous pouvez utiliser le OpenTelemetry Collector pour Microsoft SQL Server pour monitorer votre instance. Le OpenTelemetry Collector est un projet soutenu par la communauté qui collecte des données télémétriques depuis Microsoft SQL Server et les envoie à New Relic.

Par défaut, l’OpenTelemetry Collector collecte des métriques limitées à partir de Microsoft SQL Server. Pour envoyer les métriques de performances de requête, de temps d’attente, de session, et d’autres métriques avancées, vous devrez configurer l’OpenTelemetry Collector. Ce guide vous montre comment le configurer pour collecter des métriques avancées à partir de Microsoft SQL Server, et les envoyer à New Relic.

<Steps>
  <Step>
    ## Prérequis [#prerequisites]

    * OpenTelemetry Collector Contrib (`otelcol-contrib`) installé et configuré sur votre système. Vous pouvez télécharger la dernière sortie depuis la page des [sorties de l’OpenTelemetry Collector](https://github.com/open-telemetry/opentelemetry-collector-releases/releases).
  </Step>

  <Step>
    ## Activer les métriques UI [#enable]

    Vous pouvez enrichir votre expérience de la plateforme New Relic en ajoutant, et en activant des métriques dans votre fichier de configuration `otelcol-contrib`. En utilisant la configuration fournie dans cette section, vous pouvez alimenter les données pour les pages suivantes dans la plateforme New Relic :

    * <DNT>Overview</DNT>
    * <DNT>Query performance</DNT>
    * <DNT>Wait events</DNT>
    * <DNT>Sessions</DNT>
    * <DNT>Clients</DNT>
    * <DNT>Stored procedures</DNT>

    <CollapserGroup>
      <Collapser id="overview" title="Activer les métriques de la page Overview">
        La page <DNT>Overview</DNT> affiche une vue d’ensemble de votre instance Microsoft SQL Server, y compris des métriques clés telles que le nombre de bases de données, les I/O, la latence, les opérations, l’espace tempdb, le taux d’interblocage, et plus encore.

        Pour renseigner les données de la page <DNT>Overview</DNT> dans la plateforme New Relic, ajoutez la configuration suivante à votre fichier de configuration `otelcol-contrib` :

        ```yaml
        receivers:
            sqlserver:

                # Enable comprehensive database metrics
              metrics:
                sqlserver.database.count:
                  enabled: true
                sqlserver.database.io:
                  enabled: true
                sqlserver.database.latency:
                  enabled: true
                sqlserver.database.operations:
                  enabled: true
                sqlserver.database.tempdb.space:
                  enabled: true
                sqlserver.database.tempdb.version_store.size:
                  enabled: true
                sqlserver.deadlock.rate:
                  enabled: true
                sqlserver.os.wait.duration:
                  enabled: true
                sqlserver.processes.blocked:
                  enabled: true
                sqlserver.memory.grants.pending.count:
                  enabled: true
                sqlserver.memory.area:
                  enabled: true
        ```
      </Collapser>

      <Collapser id="query-performance" title="Activer les métriques de performance de requête, de session, d'attente, de client, et de procédure stockée">
        Vous pouvez renseigner des données pour les pages suivantes de la plateforme New Relic :

        * <DNT>Query performance</DNT>: affiche des informations détaillées sur les requêtes en cours d&apos;exécution sur votre instance Microsoft SQL Server dans les onglets suivants :

          * <DNT>Normalized queries</DNT>: affiche les graphiques d&apos;exécution et de temps CPU moyen.
          * <DNT>Query samples</DNT>: affiche les exécutions individuelles de requêtes, y compris l&apos;heure de début, la durée, le type d&apos;attente, le temps d&apos;attente, la base de données, l&apos;utilisateur de la base de données, et l&apos;hôte client.
          * <DNT>Stored procedures</DNT>: Affiche les métriques de performance pour les principales procédures stockées.

        * <DNT>Wait events</DNT>: affiche des informations sur les événements d’attente se produisant sur votre instance Microsoft SQL Server. La vue des exemples de requête affiche les requêtes actuellement en attente ainsi que leur type d’attente et leur temps d’attente.

        * <DNT>Sessions</DNT>: affiche des informations sur les sessions connectées à votre instance Microsoft SQL Server, y compris le nombre de sessions, les états des sessions, la durée moyenne des sessions actives, les sessions bloquées, et les détails des sessions individuelles.

        * <DNT>Clients</DNT>: affiche des informations sur les clients connectés à votre instance Microsoft SQL Server, y compris les sessions actives, les sessions bloquées, les utilisateurs de base de données connectés, et les détails de l&apos;hôte client.

        * <DNT>Stored procedures</DNT>: Affiche les métriques de performance pour les principales procédures stockées.

        Pour renseigner les données dans ces pages, ajoutez la configuration suivante à votre fichier de configuration `otelcol-contrib` :

        ```yaml
        receivers:
            sqlserver:

                events:
                    db.server.query_sample:
                        enabled: true
                    db.server.top_query:
                        enabled: true
                    db.server.query_plan:
                        enabled: true
                    db.server.top_procedure:
                        enabled: true

                # Top query collection configuration
                top_query_collection:
                    lookback_time: 60s
                    max_query_sample_count: 1000
                    top_query_count: 250
                    collection_interval: 60s

                # Query sample collection configuration
                query_sample_collection:
                    max_rows_per_query: 100

                # Top stored procedure collection configuration
                top_procedure_collection:
                    max_procedure_sample_count: 1000
                    top_procedure_count: 250
                    collection_interval: 60s
        ```
      </Collapser>

      <Collapser id="waits" title="Activez toutes les attentes dans l’onglet des événements d’attente">
        La vue Toutes les attentes affiche le temps d’attente au niveau de l’instance, réparti par catégorie d’attente et par type d’attente individuel.

        Pour activer <DNT>All waits</DNT> dans l&apos;onglet <DNT>Wait event</DNT> de la plateforme New Relic, ajoutez la configuration suivante à votre fichier de configuration `otelcol-contrib` :

        ```yaml
        receivers:
            sqlserver:

                metrics:
                    sqlserver.os.wait.duration:
                        enabled: true
        ```
      </Collapser>
    </CollapserGroup>
  </Step>

  <Step>
    ## Redémarrez le Collector OpenTelemetry

    Redémarrez le Collector OpenTelemetry pour appliquer les modifications de configuration en exécutant la commande suivante :

    ```powershell
    Restart-Service -Name "otelcol-contrib"
    ```
  </Step>
</Steps>
