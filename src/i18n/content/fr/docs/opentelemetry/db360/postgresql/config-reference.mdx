Cette référence fournit des configurations YAML complètes pour le monitoring de PostgreSQL avec le Collector New Relic Distribution of OpenTelemetry (NRDOT). Ces configurations aux fonctionnalités complètes incluent le catalogue complet de métriques PostgreSQL pour les environnements de production sur les déploiements auto-hébergés et Amazon RDS.

<Callout variant="important">
  **Vous souhaitez commencer rapidement ?** Ce sont des configurations avancées pour une utilisation en production. Si vous configurez le monitoring de PostgreSQL pour la première fois, nous vous recommandons de commencer par la configuration standard de nos guides d’installation et de revenir à ces configurations complètes une fois que vous aurez vérifié le fonctionnement de base.
</Callout>
