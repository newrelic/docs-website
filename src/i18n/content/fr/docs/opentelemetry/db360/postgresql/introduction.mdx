Monitorez les performances de votre base de données PostgreSQL à l&apos;aide de la distribution New Relic d&apos;OpenTelemetry (NRDOT) avec des informations détaillées complètes sur les métriques de base de données, les performances des requêtes et la santé du système.

Cette approche basée sur NRDOT complète notre On-Host Integration (OHI) existante en s&apos;appuyant sur les standards OpenTelemetry pour le monitoring des bases de données, facilitant ainsi l&apos;intégration avec votre pile d&apos;observabilité existante.

Contrairement aux intégrations sur hôte, NRDOT fonctionne indépendamment de l’agent d’infrastructure. Il ne nécessite pas l’agent d’infrastructure pour collecter la télémétrie de la base de données. NRDOT inclut également des capacités natives de monitoring d’hôte, vous pouvez donc choisir de :

* Utilisez l&apos;agent d&apos;infrastructure pour le monitoring de l&apos;hôte en parallèle de NRDOT pour le monitoring de la base de données, ou
* Utilisez NRDOT pour monitorer à la fois la base de données et l&apos;hôte.

## Choisissez votre méthode d&apos;installation [#install]

Vous pouvez installer le Collector NRDOT pour le monitoring de PostgreSQL des manières suivantes :

* **Installation manuelle**: configurez le collecteur vous-même sur votre propre infrastructure

  * [Configuration auto-hébergée](/docs/opentelemetry/db360/postgresql/hosted)
  * [Configuration d&apos;AWS RDS ou Aurora](/docs/opentelemetry/db360/postgresql/rds)

* **[New Relic CLI](/docs/opentelemetry/db360/postgresql/cli)**: installez et configurez le collecteur avec une seule commande

* **[Ansible](/docs/opentelemetry/db360/postgresql/ansible)**: installez et configurez le collecteur à grande échelle à l’aide du rôle Ansible `newrelic.newrelic_install`

* **[Chef](/docs/opentelemetry/db360/postgresql/chef)**: installez et configurez le collecteur à grande échelle à l’aide du cookbook Chef `newrelic-install`

* **[Chart Helm](/docs/opentelemetry/db360/postgresql/helm)**: installez et configurez le monitoring PostgreSQL sur Kubernetes à l&apos;aide du chart Helm `postgresql-otel`

* **[Docker](/docs/opentelemetry/db360/postgresql/docker)**: exécutez le collecteur en tant que conteneur frère d&apos;une instance PostgreSQL déjà en cours d&apos;exécution dans Docker

## Installation guidée [#guided-installation]

L&apos;installation guidée est disponible sur <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; PostgreSQL (Database 360)](https://onenr.io/00jlEJKbdQW)**</DNT>. L&apos;UI fournit un workflow guidé de bout en bout.

## Installation en un coup d&apos;œil [#glance]

1. Vérifiez la compatibilité et rassemblez les prérequis.
2. Installez le Collector NRDOT.
3. Configurer l&apos;utilisateur de monitoring.
4. Configurer le Collector NRDOT.
5. Redémarrez le Collector NRDOT.
6. Vérifiez que les données circulent vers New Relic.
