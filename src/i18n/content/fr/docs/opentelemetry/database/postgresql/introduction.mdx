Monitorez les performances de votre base de données PostgreSQL à l&apos;aide de la distribution New Relic d&apos;OpenTelemetry (NRDOT) avec des informations détaillées complètes sur les métriques de base de données, les performances des requêtes et la santé du système.

Cette approche basée sur NRDOT complète notre On-Host Integration (OHI) existante en s&apos;appuyant sur les standards OpenTelemetry pour le monitoring des bases de données, facilitant ainsi l&apos;intégration avec votre pile d&apos;observabilité existante.

## Choisissez votre méthode d&apos;installation [#install]

Vous pouvez installer NRDOT Collector pour le monitoring de PostgreSQL des manières suivantes :

* [Configuration auto-hébergée](/docs/opentelemetry/database/postgresql/hosted)
* [Configuration d&apos;AWS RDS ou Aurora](/docs/opentelemetry/database/postgresql/rds)

## Installation en un coup d&apos;œil [#glance]

Les tâches principales pour l’installation de NRDOT Collector pour le monitoring de PostgreSQL sont :

<Steps>
  <Step>
    ### Prérequis [#prerequisites]

    Avant d’installer, assurez-vous d’avoir :

    * PostgreSQL `14` et versions ultérieures
    * Une [clé de licence](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key) New Relic.
    * Connectivité réseau entre l&apos;hôte où vous installez le Collector NRDOT et votre base de données PostgreSQL.
    * Connectivité réseau vers la [documentation sur les points de terminaison OTLP de New Relic](/docs/opentelemetry/best-practices/opentelemetry-otlp/)
    * Cette intégration est disponible dans le cadre du programme de préversion publique de New Relic. Vérifiez auprès de votre responsable d’organisation pour vous inscrire depuis la page [Préversions et essais](https://one.newrelic.com/admin-portal/promotion-management/home).

    Pour les prérequis détaillés pris en charge, consultez le document [Compatibilité](/docs/opentelemetry/database/postgresql/compatibility).
  </Step>

  <Step>
    ### Installer le collecteur NRDOT [#install]

    Choisissez votre parcours d’installation en fonction de votre infrastructure :

    * **[PostgreSQL auto-hébergé](/docs/opentelemetry/database/postgresql/hosted)**
    * **[Monitoring de RDS PostgreSQL](/docs/opentelemetry/database/postgresql/rds)**
  </Step>

  <Step>
    ### Configurer l&apos;utilisateur de monitoring de PostgreSQL [#user]

    Crée et fournit les autorisations nécessaires à l&apos;utilisateur de monitoring pour que NRDOT Collector collecte des métriques et des échantillons de requêtes.
  </Step>

  <Step>
    ### Configurer le collecteur NRDOT [#configure]

    Configurez le Collector NRDOT pour vous connecter à votre base de données PostgreSQL et à votre compte New Relic. Cela inclut la configuration des détails de connexion, de l&apos;authentification et de toute option de configuration supplémentaire.
  </Step>

  <Step>
    ### Trouvez et utilisez vos données [#find]

    Une fois vos données collectées, vous pouvez accéder à un monitoring complet de la base de données PostgreSQL via l’interface utilisateur de New Relic.

    Pour trouver votre entité de base de données PostgreSQL dans New Relic :

    1. Allez à <DNT>**[https://one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT>.
    2. Dans la liste déroulante **<DNT>Entity type</DNT>**, sélectionnez <DNT>**PostgreSQL instance**</DNT>, puis cliquez sur <DNT>**Apply**</DNT>.
    3. Sélectionnez votre base de données PostgreSQL dans la liste des entités.
  </Step>
</Steps>
