Monitorez les performances de votre base de données Oracle avec des métriques complètes collectées par le NRDOT Collector. Les métriques suivantes sont disponibles pour le monitoring de base de données Oracle avec NRDOT. Activez les scrapers appropriés dans votre configuration pour les collecter.
