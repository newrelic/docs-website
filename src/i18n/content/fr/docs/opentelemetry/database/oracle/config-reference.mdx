Cette référence fournit des configurations YAML complètes pour le monitoring d’Oracle Database avec le Collector New Relic Distribution of OpenTelemetry (NRDOT). Ces configurations aux fonctionnalités complètes incluent des métriques d’infrastructure de l’hôte ainsi que le monitoring de base de données pour les environnements de production.

<Callout variant="important">
  **Vous cherchez à démarrer rapidement ?** Ce sont des configurations avancées pour une utilisation en production. Si vous configurez le monitoring de la base de données Oracle pour la première fois, nous vous recommandons de commencer par la configuration standard dans nos guides d’installation et de revenir à ces configurations complètes une fois que vous avez vérifié les fonctionnalités de base.
</Callout>
