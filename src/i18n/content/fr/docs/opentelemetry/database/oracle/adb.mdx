  Nous travaillons toujours sur cette fonctionnalité, mais nous aimerions que vous l&apos;essayiez !

Obtenez des informations détaillées complètes sur les performances de votre Oracle Autonomous Database (ADB) avec le monitoring de base de données, l&apos;analyse des requêtes, et les métriques de santé du système à l&apos;aide du collecteur New Relic Distribution of OpenTelemetry (NRDOT).

<Callout variant="tip" title="Installation guidée">
  Pour installer plutôt via l&apos;UI de New Relic, accédez à <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; Oracle (OpenTelemetry)** </DNT>. Cette page couvre uniquement l&apos;installation via la CLI.
</Callout>

## Prérequis [#prerequisites]

Avant de commencer, assurez-vous d’avoir les éléments suivants :

* [Clé de licence](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)New Relic valide
* Architecture prise en charge : Linux avec AMD64 et ARM64
* Connectivité réseau vers le [point de terminaison OTLP de New Relic](/docs/opentelemetry/best-practices/opentelemetry-otlp)
* Oracle Database `19c` ou version ultérieure

### Inscrivez-vous à la préversion [#enroll]

Cette intégration est disponible dans le cadre du programme d&apos;aperçu public de New Relic. Contactez le responsable de votre organisation pour vous inscrire à partir de la page [Previews &amp; Trials](https://one.newrelic.com/admin-portal/promotion-management/home).

<Steps>
  <Step>
    ## Installer le collecteur NRDOT [#installation]

    Sélectionnez la méthode de distribution de l&apos;installation appropriée pour votre environnement Linux :

    <CollapserGroup>
      <Collapser title="Pour l'architecture AMD64" id="amd">
        * Pour les systèmes Debian/Ubuntu, exécutez :

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_amd64.deb" --output nrdot-collector.deb && sudo dpkg -i nrdot-collector.deb
          ```

        * Pour les systèmes RHEL/CentOS/OEL, exécutez :

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_x86_64.rpm" --output nrdot-collector.rpm && sudo rpm -ivh nrdot-collector.rpm
          ```
      </Collapser>

      <Collapser title="Pour l'architecture ARM64" id="arm">
        * Pour les systèmes Debian/Ubuntu, exécutez :

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_arm64.deb" --output nrdot-collector.deb && sudo dpkg -i nrdot-collector.deb
          ```

        * Pour les systèmes RHEL/CentOS/OEL, exécutez :

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_aarch64.rpm" --output nrdot-collector.rpm && sudo rpm -ivh nrdot-collector.rpm
          ```
      </Collapser>
    </CollapserGroup>
  </Step>

  <Step>
    ## Configurer l&apos;utilisateur de la base de données [#database-user]

    Créez un utilisateur de monitoring avec les privilèges nécessaires pour votre instance de base de données Oracle ADB. Exécutez les instructions suivantes en tant que SYS dans votre ADB cible pour créer un utilisateur de monitoring local :

    ```sql
    CREATE USER <USER_NAME> IDENTIFIED BY "<YOUR_PASSWORD>";
    GRANT CREATE SESSION TO <USER_NAME>;
    ```
  </Step>

  <Step>
    ## Accorder des privilèges de monitoring pour Autonomous Database [#grant-privileges]

    Exécutez ces commandes en tant qu’administrateur dans votre ADB. Cela donne à l’outil de monitoring l’accès de base dont il a besoin pour collecter des métriques, suivre des événements, et trouver vos instances de base de données.

    ```sql
    GRANT SELECT ON SYS.V_$INSTANCE   TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$DATABASE   TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$CONTAINERS TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$DATAFILE   TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$PDBS       TO <USER_NAME>; 
    GRANT SELECT ON SYS.V_$SYSSTAT                    TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$SYSMETRIC                  TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$SESSION                    TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$RESOURCE_LIMIT             TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$OSSTAT                     TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$SGAINFO                    TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$ROWCACHE                   TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$PARAMETER                  TO <USER_NAME>;
    GRANT SELECT ON SYS.DBA_TABLESPACE_USAGE_METRICS  TO <USER_NAME>;
    GRANT SELECT ON SYS.DBA_TABLESPACES               TO <USER_NAME>;
    GRANT SELECT ON SYS.DBA_DATA_FILES                TO <USER_NAME>;
    GRANT SELECT ON SYS.DBA_FREE_SPACE                TO <USER_NAME>;
    GRANT SELECT ON SYS.DBA_RECYCLEBIN                TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$SQL            TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$SQL_PLAN_STATISTICS_ALL       TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$LOCK           TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$SESSION_EVENT  TO <USER_NAME>;
    GRANT SELECT ON SYS.DBA_PROCEDURES    TO <USER_NAME>;
    GRANT SELECT ON SYS.DBA_OBJECTS       TO <USER_NAME>;
    ```
  </Step>

  <Step>
    ## Redémarrer NRDOT Collector [#restart-collector]

    Après avoir configuré le collecteur, redémarrez le service NRDOT Collector pour appliquer les modifications :

    ```bash
    sudo systemctl restart nrdot-collector
    ```

    Pour vérifier que le collecteur fonctionne correctement, vérifiez l&apos;état du service :

    ```bash
    sudo systemctl status nrdot-collector
    ```

    <Callout variant="tip">
      Redémarrez toujours le Collector NRDOT après avoir modifié la configuration pour garantir la prise en compte des nouveaux paramètres.
    </Callout>
  </Step>

  <Step>
    ## Trouvez et utilisez vos données [#find-use-data]

    Après avoir configuré l’intégration Oracle ADB, vous pouvez commencer à monitorer et à analyser les performances de votre base de données dans New Relic :

    1. Accédez à **[one.newrelic.com](https://one.newrelic.com) &gt; All Entities**.
    2. Filtrez par **Oracle** pour trouver les entités de votre base de données.
    3. Sélectionnez votre entité Oracle ADB pour afficher les dashboards, les métriques et les logs.

    Pour plus d’informations sur le monitoring des bases de données Oracle, consultez notre [documentation sur le monitoring de base de données](/docs/database-monitoring/oracle-monitoring/).
  </Step>
