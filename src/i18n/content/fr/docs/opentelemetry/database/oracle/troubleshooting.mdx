## Problèmes courants

<CollapserGroup>
  <Collapser id="test-connection" title="Tester la connectivité réseau">
    Exécutez la commande suivante pour vérifier que le port de la base de données Oracle est accessible depuis cet hôte.

    ```bash
    (timeout 3 bash -c '</dev/tcp/<YOUR_ENDPOINT>/<YOUR_PORT>' && echo "PORT OPEN - Network connection successful!") || echo "CONNECTION FAILED - Port closed or firewall blocking"
    ```

    **Résultat attendu :** `PORT OPEN - Network connection successful!`
  </Collapser>

  <Collapser id="otlp-endpoint-connection" title="Tester la connectivité du point de terminaison OTLP">
    Exécutez la commande suivante pour vérifier que votre hôte peut atteindre le point de terminaison OTLP New Relic sélectionné.

    ```bash
    ENDPOINT="<YOUR_OTLP_ENDPOINT>"
    HOST=$(echo "$ENDPOINT" | sed 's|https://||' | cut -d: -f1)
    PORT=$(echo "$ENDPOINT" | awk -F: '{print $NF}')
    (timeout 2 bash -c "</dev/tcp/$HOST/$PORT" && echo "✅ SUCCESS") || echo "❌ FAILED"
    ```

    **Résultat attendu :** `✅ SUCCESS`
  </Collapser>
</CollapserGroup>
