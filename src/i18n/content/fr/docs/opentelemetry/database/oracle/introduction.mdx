Obtenez des informations détaillées sur les performances de votre base de données Oracle avec notre solution de monitoring basée sur OpenTelemetry. Suivez les métriques de la base de données, analysez les performances des requêtes, monitorez l’utilisation des ressources, et corrélez les performances de la base de données avec vos applications.

Cette approche basée sur NRDOT complète notre On-Host Integration (OHI) existante en s&apos;appuyant sur les standards OpenTelemetry pour le monitoring des bases de données, facilitant ainsi l&apos;intégration avec votre pile d&apos;observabilité existante.

## Capacités [#capabilities]

* **Standards OpenTelemetry**: s’intègre parfaitement aux outils d’observabilité existants
* **Métriques exhaustives**: informations détaillées approfondies sur les performances de la base de données, les événements d&apos;attente, et l&apos;utilisation des ressources
* **Informations détaillées au niveau des requêtes**: identifiez et analysez les requêtes lentes et l’activité des sessions
* **Déploiement flexible**: fonctionne avec les environnements CDB/PDB sur hôte et Amazon RDS
* **Corrélation APM**: connectez les performances de la base de données aux traces de l’application

## Choisissez votre chemin d&apos;installation [#choose]

Vous pouvez installer le NRDOT Collector pour le monitoring d’Oracle Database des manières suivantes :

* Environnements auto-hébergés : installation manuelle sur votre propre infrastructure

  * [Base de données conteneur (CDB) sur l’hôte](/docs/opentelemetry/database/oracle/host-cdb): monitorer une base de données conteneur entière, y compris toutes les bases de données enfichables sous-jacentes.
  * [Base de données enfichable (PDB) sur l’hôte](/docs/opentelemetry/database/oracle/host-pdb): monitorez une base de données enfichable individuelle.

* Environnements AWS RDS : monitoring de la base de données Oracle gérée dans le cloud
  * [Monitoring RDS](/docs/opentelemetry/database/oracle/rds): monitorez une instance Oracle Database s’exécutant dans Amazon RDS.

* Environnements Oracle Cloud : monitoring de base de données Oracle entièrement géré
  * [Monitoring de la base de données autonome (ADB)](/docs/opentelemetry/database/oracle/adb): monitorez une instance de base de données autonome Oracle.

## Installation guidée [#ui-install]

L&apos;installation guidée est disponible sur <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; Oracle (OpenTelemetry)**</DNT>. L&apos;UI fournit un workflow guidé de bout en bout.

## Installation en un coup d&apos;œil [#at-a-glance]

<Steps>
  <Step>
    ### Prérequis [#prerequisites]

    * [Clé de licence](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)New Relic valide
    * Architecture prise en charge : Linux avec AMD64 et ARM64
    * Connectivité réseau vers le [point de terminaison OTLP de New Relic](/docs/opentelemetry/best-practices/opentelemetry-otlp/)
    * Oracle Database 19c ou version ultérieure
  </Step>

  <Step>
    ### Installer le collecteur NRDOT [#install-step]

    Installez le Collector NRDOT sur votre système en suivant les instructions pour votre environnement spécifique

    * [CDB](/docs/opentelemetry/database/oracle/host-cdb)
    * [PDB](/docs/opentelemetry/database/oracle/host-pdb)
    * [RDS](/docs/opentelemetry/database/oracle/rds)
    * [ADB](/docs/opentelemetry/database/oracle/adb)
  </Step>

  <Step>
    ### Configurer l&apos;utilisateur de monitoring [#user]

    Créez un utilisateur de base de données Oracle dédié avec les autorisations en lecture seule nécessaires pour permettre au Collector NRDOT de collecter des métriques et des données de performance des requêtes.
  </Step>

  <Step>
    ### Configurer le collecteur NRDOT [#configure]

    Configurez le NRDOT Collector pour se connecter à votre instance de base de données Oracle. Cela implique de spécifier les détails de connexion, la méthode d’authentification et toute option de configuration supplémentaire requise pour votre environnement.
  </Step>

  <Step>
    ### Redémarrer NRDOT Collector [#restart]

    Après avoir configuré le Collector NRDOT, redémarrez le service pour appliquer les modifications et commencer à collecter des données à partir de votre instance de base de données Oracle.
  </Step>

  <Step>
    ### Trouvez et utilisez vos données [#find]

    Une fois vos données collectées, vous pouvez accéder à un monitoring complet de la base de données Oracle via l&apos;UI de New Relic.

    Pour trouver votre entité de base de données Oracle dans New Relic :

    1. Allez à <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT>.
    2. Définissez les critères de recherche comme <DNT>`instrumentation.provider = opentelemetry`</DNT>.
    3. Sélectionnez votre base de données Oracle dans la liste des entités.
  </Step>
</Steps>
