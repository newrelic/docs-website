  Nous travaillons toujours sur cette fonctionnalité, mais nous aimerions que vous l&apos;essayiez !

  Cette fonctionnalité est actuellement fournie dans le cadre d&apos;un aperçu conformément à nos [politiques de pré-sortie](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy/).

Obtenez des informations détaillées complètes sur les performances de votre base de données Amazon RDS Oracle grâce au monitoring de base de données, à l&apos;analyse des requêtes, et aux métriques de santé du système à l&apos;aide du collecteur New Relic Distribution of OpenTelemetry (NRDOT).

<Callout variant="tip" title="Installation guidée">
  Pour installer plutôt via l&apos;UI de New Relic, accédez à <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; Oracle (OpenTelemetry)** </DNT>. Cette page couvre uniquement l&apos;installation via la CLI.
</Callout>

## Prérequis [#prerequisites]

Avant de commencer, assurez-vous d’avoir les éléments suivants :

* [Clé de licence](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)New Relic valide
* Architecture prise en charge : Linux avec AMD64 et ARM64
* Connectivité réseau vers le [point de terminaison OTLP de New Relic](/docs/opentelemetry/best-practices/opentelemetry-otlp)
* Oracle Database `19c` ou version ultérieure

### Inscrivez-vous à la préversion [#enroll]

Cette intégration est disponible dans le cadre du programme d&apos;aperçu public de New Relic. Contactez le responsable de votre organisation pour vous inscrire à partir de la page [Previews &amp; Trials](https://one.newrelic.com/admin-portal/promotion-management/home).

<Steps>
  <Step>
    ## Installer le collecteur NRDOT [#installation]

    Sélectionnez la méthode de distribution de l&apos;installation appropriée pour votre environnement Linux :

    <CollapserGroup>
      <Collapser title="Pour l'architecture AMD64" id="amd64-rds">
        * Pour les systèmes Debian/Ubuntu, exécutez :

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_amd64.deb" --output nrdot-collector.deb && sudo dpkg -i nrdot-collector.deb
          ```

        * Pour les systèmes RHEL/CentOS/OEL, exécutez :

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_x86_64.rpm" --output nrdot-collector.rpm && sudo rpm -ivh nrdot-collector.rpm
          ```
      </Collapser>

      <Collapser title="Pour l'architecture ARM64" id="arm64-rds">
        * Pour les systèmes Debian/Ubuntu, exécutez :

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_arm64.deb" --output nrdot-collector.deb && sudo dpkg -i nrdot-collector.deb
          ```

        * Pour les systèmes RHEL/CentOS/OEL, exécutez :

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_arm64.rpm" --output nrdot-collector.rpm && sudo rpm -ivh nrdot-collector.rpm
          ```
      </Collapser>
    </CollapserGroup>

  <Step>
    ## Configurer l&apos;utilisateur de la base de données [#database-user]

    Créez un utilisateur de monitoring avec les privilèges nécessaires pour votre base de données Oracle RDS.

    1. Connectez-vous à la base de données racine en tant qu&apos;administrateur :

       ```sql
       CREATE USER <USERNAME> IDENTIFIED BY "<USER_PASSWORD>";
       ```

    2. Accorder les privilèges `CONNECT` à l&apos;utilisateur nouvellement créé :

       ```sql
       GRANT CONNECT TO <USERNAME>;
       ```
  </Step>

  <Step>
    ## Mettre à jour la configuration du Collector NRDOT [#update-config]

    Mettez à jour la configuration du NRDOT Collector pour utiliser votre fichier `oracle-config.yaml`.

    ```bash
    sudo sed -i 's|OTELCOL_OPTIONS="--config=/etc/nrdot-collector/config.yaml"|OTELCOL_OPTIONS="--config=/etc/nrdot-collector/oracle-config.yaml"|' /etc/nrdot-collector/nrdot-collector.conf
    ```

    <Callout variant="tip">
      Vous pouvez également :

      * [Configurer plusieurs récepteurs](/docs/opentelemetry/database/oracle/multi-receiver): pour monitorer plusieurs instances de base de données Oracle à partir d’un seul collecteur.
      * [Configurer le Récepteur de requêtes SQL](/docs/opentelemetry/database/capabilities/sql-query-receiver/): pour collecter des métriques personnalisées à partir de votre base de données Oracle.
      * [Lier votre base de données Oracle à l&apos;APM](/docs/opentelemetry/database/capabilities/db-apm): pour corréler les performances de vos applications avec les opérations de base de données. Cela vous permet de voir exactement quelles applications génèrent des workloads de base de données spécifiques.
      * [Configurer la gestion des secrets](/docs/opentelemetry/database/capabilities/db-apm/#secret-management): pour gérer en toute sécurité des informations sensibles, telles que les identifiants de base de données. Cela permet de renforcer la sécurité de votre configuration de monitoring en évitant de coder en dur des données sensibles dans les fichiers de configuration.
    </Callout>
  </Step>

  <Step>
    ## Redémarrer NRDOT Collector [#restart-collector]

    Après avoir mis à jour votre configuration, redémarrez le Collector NRDOT :

    ```bash
    sudo systemctl restart nrdot-collector.service
    sudo systemctl status nrdot-collector.service
    ```

    <Callout variant="tip">
      Redémarrez toujours le Collector NRDOT après avoir modifié la configuration pour garantir la prise en compte des nouveaux paramètres.
    </Callout>
  </Step>

  <Step>
    ## Trouvez et utilisez vos données [#find-use-data]

    Une fois vos données collectées, vous pouvez accéder à un monitoring complet de la base de données Oracle via l&apos;interface utilisateur de New Relic.

    Pour trouver votre entité de base de données Oracle dans New Relic :

    1. Allez à <DNT>**[https://one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT>.
    2. Définissez les critères de recherche comme <DNT>`instrumentation.provider = opentelemetry`</DNT>.
    3. Sélectionnez votre base de données Oracle dans la liste des entités.
  </Step>
</Steps>
