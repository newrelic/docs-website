Cette référence fournit des configurations YAML complètes pour le monitoring de Microsoft SQL Server avec le Collector New Relic Distribution of OpenTelemetry (NRDOT). Ces configurations riches en fonctionnalités incluent toutes les métriques disponibles, des paramètres de processeur avancés et des pipelines optimisés pour les environnements de production sous Linux et Windows, à la fois pour les déploiements auto-hébergés et AWS RDS.

<Callout variant="important">
  **Vous cherchez à démarrer rapidement ?** Ce sont des configurations avancées pour une utilisation en production. Si vous configurez le monitoring SQL Server pour la première fois, nous vous recommandons de commencer par les configurations standard de nos guides de configuration et de revenir à ces configurations complètes une fois que vous avez vérifié les fonctionnalités de base.
</Callout>

## Configurez le Récepteur [#receiver]

Vous pouvez utiliser `max_concurrent_queries` pour contrôler combien de requêtes de métrique le Récepteur exécute en parallèle sur SQL Server pendant chaque cycle de grattage. La valeur par défaut est 4 si elle est omise ou définie sur 0.

```yaml
    receivers:
    nrsqlserver:
        max_concurrent_queries: 4  # default is 4 if omitted or set to 0
```
