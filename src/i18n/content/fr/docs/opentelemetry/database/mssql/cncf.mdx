Vous pouvez utiliser la contribution OpenTelemetry Collector pour Microsoft SQL Server afin de monitorer votre instance. La contribution OpenTelemetry Collector est un projet soutenu par la communauté qui fournit un moyen de collecter des données télémétriques à partir de Microsoft SQL Server, et de les envoyer à New Relic.

Par défaut, la contribution OpenTelemetry Collector collecte des métriques à partir de Microsoft SQL Server, et les envoie à New Relic. Cependant, il s’agit de métriques limitées. Afin d’envoyer des métriques de performances de requête, des métriques de temps d’attente, des métriques de session, et d’autres métriques avancées, vous devrez configurer la contribution OpenTelemetry Collector. Ce guide fournit des instructions pour configurer la contribution OpenTelemetry Collector afin de collecter des métriques avancées à partir de Microsoft SQL Server, et de les envoyer à New Relic.

<Steps>
  <Step>
    ## Prérequis [#prerequisites]

    * OpenTelemetry Collector Contrib (`otelcol-contrib`) installé &amp; configuré sur votre système. Vous pouvez télécharger la dernière sortie depuis la page des [sorties de l&apos;OpenTelemetry Collector](https://github.com/open-telemetry/opentelemetry-collector-releases/releases).
  </Step>

  <Step>
    ## Enable UI metrics [#enable]

    Vous pouvez enrichir votre expérience de la plateforme New Relic en ajoutant et en activant les différentes métriques dans votre fichier de configuration `otelcol-contrib`. En utilisant la configuration fournie dans cette section, vous pouvez alimenter les données des pages suivantes de la plateforme New Relic :

    * <DNT>Overview</DNT>
    * <DNT>Query performance</DNT>
    * <DNT>Wait events</DNT>
    * <DNT>Sessions</DNT>
    * <DNT>Clients</DNT>

    <CollapserGroup>
      <Collapser id="overview" title="Activer les métriques de la page Overview">
        La page <DNT>Overview</DNT> affiche une vue d’ensemble de votre instance Microsoft SQL Server, y compris des métriques clés telles que le nombre de bases de données, les I/O, la latence, les opérations, l’espace tempdb, le taux d’interblocage, et plus encore.

        Pour renseigner les données de la page <DNT>Overview</DNT> dans la plateforme New Relic, ajoutez la configuration suivante à votre fichier de configuration `otelcol-contrib` :

        ```yaml
        receivers:
            sqlserver:

                # Enable comprehensive database metrics
              metrics:
                sqlserver.database.count:
                  enabled: true
                sqlserver.database.io:
                  enabled: true
                sqlserver.database.latency:
                  enabled: true
                sqlserver.database.operations:
                  enabled: true
                sqlserver.database.tempdb.space:
                  enabled: true
                sqlserver.database.tempdb.version_store.size:
                  enabled: true
                sqlserver.deadlock.rate:
                  enabled: true
                sqlserver.os.wait.duration:
                  enabled: true
                sqlserver.processes.blocked:
                  enabled: true
                sqlserver.memory.grants.pending.count:
                  enabled: true
                sqlserver.memory.area:
                  enabled: true
        ```
      </Collapser>

      <Collapser id="query-performance" title="Activer les métriques de performance de requête, de session, d'attente et de client">
        Vous pouvez renseigner des données pour les pages suivantes de la plateforme New Relic :

        * <DNT>Query performance</DNT>: affiche des informations détaillées sur les requêtes en cours d’exécution sur votre instance Microsoft SQL Server dans les onglets suivants :

          * <DNT>Normalized queries</DNT>: affiche des statistiques agrégées par requête, y compris les exécutions, la durée moyenne, le temps CPU moyen, et les lectures logiques. Cliquez sur une requête pour afficher des informations détaillées sur la requête sélectionnée, y compris les statistiques de performance agrégées, les plans de requête observés, et les échantillons individuels récents avec une répartition par type d’attente.
          * <DNT>Query samples</DNT>: affiche les exécutions de requêtes individuelles, y compris l’heure de début, la durée, le type d’attente, le temps d’attente, la base de données, l’utilisateur de la base de données, la corrélation APM, et l’hôte client.

        * <DNT>Wait events</DNT>: affiche des informations sur les événements d’attente se produisant sur votre instance Microsoft SQL Server. La vue des exemples de requête affiche les requêtes actuellement en attente ainsi que leur type d’attente et leur temps d’attente.

        * <DNT>Sessions</DNT>: affiche des informations sur les sessions connectées à votre instance Microsoft SQL Server, y compris le nombre de sessions, les états des sessions, la durée moyenne des sessions actives, les sessions bloquées, et les détails des sessions individuelles.

        * <DNT>Clients</DNT>: affiche des informations sur les clients connectés à votre instance Microsoft SQL Server, y compris les sessions actives, les sessions bloquées, les utilisateurs de base de données connectés, et les détails de l&apos;hôte client.

        Pour renseigner les données dans ces pages, ajoutez la configuration suivante à votre fichier de configuration `otelcol-contrib` :

        ```yaml
        receivers:
            sqlserver:

                events:
                    db.server.query_sample:
                        enabled: true
                    db.server.top_query:
                        enabled: true

                top_query_collection:
                    lookback_time: 45s
                    max_query_sample_count: 100
                    top_query_count: 30
                    collection_interval: 30s

                query_sample_collection:
                    max_rows_per_query: 100
        ```
      </Collapser>

      <Collapser id="waits" title="Activez toutes les attentes dans l’onglet des événements d’attente">
        La vue Toutes les attentes affiche le temps d’attente au niveau de l’instance, réparti par catégorie d’attente et par type d’attente individuel.

        Pour activer <DNT>All waits</DNT> dans l&apos;onglet <DNT>Wait event</DNT> de la plateforme New Relic, ajoutez la configuration suivante à votre fichier de configuration `otelcol-contrib` :

        ```yaml

        receivers:
            sqlserver:

                metrics:
                    sqlserver.os.wait.duration:
                        enabled: true

        ```
      </Collapser>
    </CollapserGroup>
  </Step>

  <Step>
    ### Redémarrez le Collector OpenTelemetry

    Redémarrez l&apos;OpenTelemetry Collector pour appliquer les modifications de configuration. Vous pouvez le faire en exécutant la commande suivante :

    ```bash
    Restart-Service -Name "otelcol-contrib"
    ```
  </Step>
</Steps>
