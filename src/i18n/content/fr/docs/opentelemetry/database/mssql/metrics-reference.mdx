Monitorez les performances de votre base de données SQL Server avec des métriques complètes collectées par le Collector NRDOT. Par défaut, New Relic collecte les métriques référencées dans la section [Métriques disponibles](#default). Vous pouvez améliorer votre monitoring en activant les métriques souhaitées répertoriées dans la section [Métriques supplémentaires](#additional-metrics).

## Limitations d&apos;Amazon RDS [#rds-limitations]

Lors du monitoring d&apos;une instance Amazon RDS for SQL Server, certaines métriques peuvent signaler `0` ou ne pas être collectées en raison des restrictions du service RDS et des limitations de l&apos;édition SQL Server.

<Callout variant="important">
  Les limitations suivantes s’appliquent spécifiquement aux instances SQL Server s’exécutant sur Amazon RDS. Les déploiements SQL Server auto-hébergés ne sont pas affectés par ces restrictions.
</Callout>
