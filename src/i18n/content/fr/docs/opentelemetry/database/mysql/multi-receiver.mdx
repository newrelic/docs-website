Vous pouvez configurer le NRDOT Collector pour monitorer plusieurs instances MySQL à partir d’un seul collecteur. Cela est utile si vous avez plusieurs bases de données MySQL exécutées sur différents hôtes ou ports et que vous souhaitez collecter des métriques de toutes ces bases à l’aide d’une seule instance NRDOT Collector.

<Steps>
  <Step>
    ## Prérequis [#prerequisites]

    * NRDOT est installé et configuré pour vos instances MySQL :

      * [MySQL auto-hébergé](/docs/opentelemetry/database/mysql/hosted)
      * [Monitoring de RDS MySQL](/docs/opentelemetry/database/mysql/rds)
  </Step>

  <Step>
    ## Ajouter une configuration multi-récepteur [#multi]

    L’exemple suivant montre comment configurer le Collector NRDOT pour monitorer deux instances MySQL à l’aide d’une configuration multi-Récepteur. Vous pouvez ajouter d’autres Récepteurs selon vos besoins pour des instances MySQL supplémentaires.

    ```yaml
    receivers:
      nrmysql/instance1: &nrmysql-common
        endpoint: "<INSTANCE_1_HOST>:<PORT>"
        username: "<YOUR_DB_USERNAME>"
        password: "<YOUR_DB_PASSWORD>"
        collection_interval: 10s
      nrmysql/instance2:
        <<: *nrmysql-common
        endpoint: "<INSTANCE_2_HOST>:<PORT>"

    service:
      pipelines:
        metrics:
          receivers: [nrmysql/instance1, nrmysql/instance2]
          exporters: [otlp/newrelic]
    ```
  </Step>

  <Step>
    ## Redémarrer NRDOT Collector [#restart]

    Le redémarrage est requis, et non facultatif — le collecteur charge sa configuration une fois au démarrage et ne se recharge pas à chaud. Toute modification de la configuration n’a aucun effet tant que vous ne redémarrez pas le processus.

    ```bash
    sudo systemctl restart nrdot-collector
    ```
  </Step>
</Steps>
