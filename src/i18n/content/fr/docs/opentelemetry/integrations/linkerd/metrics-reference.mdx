L’intégration OTel de Linkerd collecte des métriques en scrapant le port d’administration du proxy Linkerd (`:4191`) et les pods du control plane à l’aide du [Récepteur Prometheus](https://github.com/open-telemetry/opentelemetry-collector-contrib/tree/main/receiver/prometheusreceiver) de l’OpenTelemetry Collector.

## Métriques désactivées par défaut [#default-off]

Les groupes de métriques suivants sont désactivés par défaut dans la configuration optimisée du collecteur pour réduire le volume d’ingestion. Supprimez la condition correspondante de `filter/drop_unused` pour réactiver.

<Callout variant="tip">
  Ces groupes sont désactivés par défaut car ils ne fournissent aucune valeur opérationnelle en régime permanent. Ne les activez que lorsque vous déboguez activement le problème spécifique décrit.
</Callout>
