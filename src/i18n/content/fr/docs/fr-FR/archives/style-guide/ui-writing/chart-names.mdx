title: Noms des graphiques
translationType: machine
---

New Relic One permet aux utilisateurs de créer et de nommer leurs propres graphiques, mais il propose également des graphiques sélectionnés que nous fournissons. Les noms de ces graphiques doivent être clairs et descriptifs, afin que les utilisateurs sachent ce qu&apos;ils voient.

## Bases

* Utilisez des mots-clés clairs.
* Fournissez suffisamment d’informations pour expliquer l’objectif du graphique ; évitez les noms d’un seul mot.
* Visez la précision plutôt que la cohérence. Nous préférons avoir des noms légèrement différents pour des graphiques similaires plutôt que de suivre une convention de nommage parfaite pour certains graphiques mais inexacte pour d’autres.
* Conservez les noms en casse de phrase.

| À faire                            | À ne pas faire        |
| ---------------------------------- | --------------------- |
| Les 5 transactions les plus lentes | Transactions          |
| Répartition des erreurs par :      | Erreurs               |
| Grouper les traces par :           | Regroupement de trace |
