## Activer l&apos;intégration

Les métriques Prometheus doivent être intégrées à New Relic, vous pouvez utiliser l’agent Prometheus ou l’intégration Remote Write, voir [comment envoyer des métriques Prometheus](https://docs.newrelic.com/docs/infrastructure/prometheus-integrations/get-started/send-prometheus-metric-data-new-relic/).

Une fois intégré, utilisez la requête suivante pour confirmer que les métriques sont ingérées comme prévu :

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'integrationName_%' FACET metricName LIMIT MAX
```

Les entités d&apos;intégration sont également visibles dans l&apos;[explorateur d&apos;entités](/docs/new-relic-solutions/new-relic-one/core-concepts/new-relic-explorer-view-performance-across-apps-services-hosts#find) avec les métriques dorées associées et un dashboard intégré.

## Rechercher et utiliser les données

### Métriques

Les métriques Prometheus sont stockées sous forme de métriques dimensionnelles. Vous pouvez [effectuer une requête à l&apos;aide de NRQL](/docs/telemetry-data-platform/get-data/apis/query-metric-data-type/) ou utiliser l&apos; [explorateur de données](/docs/query-your-data/explore-query-data/browse-data/introduction-data-explorer/) pour parcourir les métriques, les facettes et filtrer les dimensions associées disponibles.

Les différents ensembles de métriques exposés par \[ajoutez ici le nom de l&apos;intégration] sont définis dans la \[documentation de Integration\_name]\(ajoutez un lien vers la documentation du fournisseur).

Utilisez la requête NRQL suivante pour comprendre les métriques ingérées dans New Relic :

* Lister les noms métriques uniques :

  ```sql
  FROM Metric SELECT uniques(metricName) WHERE metricName LIKE 'integrationName_%' LIMIT MAX
  ```

* Compter le nombre de mises à jour métriques :

  ```sql
  FROM Metric SELECT datapointcount() WHERE metricName LIKE 'integrationName_%' FACET metricName
  ```

* Estimer l&apos;ingestion de données (ingestion quotidienne, en octets) :

  ```sql
  FROM Metric SELECT bytecountestimate() WHERE metricName LIKE 'integrationName_%' SINCE 1 day ago
  ```
