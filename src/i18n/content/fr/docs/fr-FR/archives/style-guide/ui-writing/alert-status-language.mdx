## Bases

Nous affichons des indicateurs colorés pour le statut des alertes dans l’interface utilisateur, et il est important pour nous d’utiliser un langage cohérent sur l’ensemble de nos écrans d’interface utilisateur et de nos API. Nous commençons également à inclure davantage d’éléments dans ce statut que de simples alertes.

Incluez un état de survol pour expliquer la signification de la couleur, si nécessaire. Pour les badges de statut principaux sur une page d&apos;entité individuelle, l&apos;état de survol indiquera ce qui y contribue. Si cela n&apos;est pas possible, utilisez les états de survol ci-dessous.

## Modélisation entre la formulation de l&apos;interface utilisateur et de l&apos;API

| Couleur        | Survol de l&apos;interface utilisateur (infobulle) | Libellé d’état de l’interface utilisateur | API             |
| -------------- | -------------------------------------------------- | ----------------------------------------- | --------------- |
| Rouge          | Incident critique en cours                         | Critique                                  | CRITIQUE        |
| Jaune          | Incident d&apos;avertissement en cours             | Dégradé                                   | AVERTISSEMENT   |
| Vert           | Aucune alerte en cours                             | Opérationnel                              | NOT\_ALERTING   |
| Gris           | Ne rapporte pas                                    | Statut inconnu                            | NOT\_CONFIGURED |
| Aucune couleur | -aucun état de survol-                             | -aucun état de survol-                    |                 |
