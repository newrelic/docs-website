title: Supprimer un document
translationType: machine
---

<Callout variant="caution">
  Lorsque vous supprimez un document, son contenu et ses redirections seront toujours disponibles dans l&apos;historique des commits GitHub.
</Callout>

Pour supprimer un document :

1. Localisez le fichier MDX du document que vous souhaitez supprimer.

2. Faites attention aux redirections :

   1. Trouvez la documentation la plus pertinente vers laquelle rediriger les lecteurs.
   2. [Ajoutez l&apos;URL du document supprimé comme redirection](/docs/style-guide/rename-or-redirect-document).
   3. Copiez toutes les redirections existantes du document supprimé et ajoutez-les au nouveau document.

3. Supprimez le titre et le chemin du document du fichier de navigation approprié.

4. Supprimez le fichier MDX du document.

5. Supprimez les fichiers MDX correspondants du répertoire `src/i18n/content`. Pour chaque document en anglais, il y a un fichier MDX pour chacune des langues localisées. Vous pouvez utiliser le script `i18n-utility` pour le faire automatiquement :
   ```bash
   yarn i18n-utility delete-orphans
   ```
