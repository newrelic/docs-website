Les infobulles fournissent beaucoup d’indications dans un espace restreint pour nos lecteurs. Les infobulles donnent des définitions en ligne rapides des concepts clés et fournissent un moyen d’en apprendre davantage dans la documentation ou de l’essayer dans l’interface utilisateur.

<img title="Popover" alt="A screenshot of a popover" src="/images/style-guide_screenshot-crop_popover.webp" />

## Utilisation des pop-overs [#use-pop]

Une fenêtre contextuelle est écrite dans un [fichier JSON](https://github.com/newrelic/docs-website/blob/develop/src/data/popovers_en.json), et peut être insérée dans n’importe quel document de votre choix en utilisant le format suivant :

```jsx
<InlinePopover type="title" />
```

Où `title` est le nom du composant dans le fichier JSON. Dans la capture d&apos;écran ci-dessus, `synthetics` est le pop-over utilisé.

<Callout variant="tip">
  La macro Keyboard Maestro pour les infobulles est `kkpopover`
</Callout>

## Création ou modification de fenêtres contextuelles

Les pop-overs sont contenus dans un fichier JSON modifiable. Vous pouvez modifier le fichier pour créer vos propres pop-overs en utilisant la procédure ci-dessous :

<Steps>
  <Step>
    Ouvrez le [fichier JSON](https://github.com/newrelic/docs-website/blob/develop/src/data/popovers_en.json) dans VS Code.
  </Step>

  <Step>
    Copiez et collez un pop-over existant, et modifiez-le selon vos besoins pour le pop-over que vous souhaitez créer.

    * La première ligne est le &quot;titre&quot; de l’infobulle utilisée dans l’exemple de format ci-dessus.

    * `inlineText` est le texte qui apparaît dans la documentation dans laquelle vous placez le composant, avant que l’utilisateur ne survole la fenêtre contextuelle.

    * `header` est le titre de l’infobulle une fois qu’elle s’affiche.

    * `text` est le texte qui s’affiche dans le corps du popover.

    * `learnMoreUrl` est l&apos;URL du document vers lequel vous souhaitez envoyer le lecteur pour plus d&apos;informations.

    * `primaryButton` est le texte du bouton principal tel qu&apos;il apparaît dans la fenêtre contextuelle.

    * `primaryButtonUrl` est le lien vers lequel vous souhaitez que le bouton envoie le lecteur lorsqu’il est cliqué.

    * `secondaryButton` est le texte du bouton le plus à droite tel qu’il apparaît dans la fenêtre contextuelle.

    * `secondaryButtonUrl` est le lien vers lequel vous souhaitez que le bouton le plus à droite renvoie le lecteur lorsqu’il est cliqué.

      Conservez la liste dans le fichier JSON par ordre alphabétique pour faciliter les recherches.
  </Step>

  <Step>
    Testez le popover localement.
  </Step>

  <Step>
    Ouvrez une PR basée sur vos modifications, et contactez quelqu’un de Docs Eng pour qu’il l’examine.
  </Step>

  <Step>
    Une fois la demande de tirage examinée et fusionnée, vous pouvez utiliser votre nouvelle fenêtre contextuelle dans n’importe quel document de votre choix !
  </Step>
</Steps>
