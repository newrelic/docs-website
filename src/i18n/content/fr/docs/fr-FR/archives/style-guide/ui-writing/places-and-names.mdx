En interne, nous désignons généralement les lieux par une forme abrégée (PDX plutôt que Portland, OR) et les personnes par leur prénom uniquement (Lew, plutôt que Lew Cirne). Pour les textes destinés aux clients, nous devons unifier la façon dont nous présentons ces informations afin d&apos;atténuer toute confusion.

## Bases

* Mettez les noms propres en majuscules.
* Utilisez le nom propre d’un emplacement lorsque vous y faites référence en tant que nom.
