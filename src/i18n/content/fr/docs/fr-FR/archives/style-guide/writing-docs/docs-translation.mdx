La documentation de New Relic existe sur ces sites :

* [**docs.newrelic.com**](https://docs.newrelic.com): Anglais
* [**docs.newrelic.com/jp/**](https://docs.newrelic.com/jp/): Japonais
* [**docs.newrelic.com/kr/**](https://docs.newrelic.com/kr/): Coréen
* [**docs.newrelic.com/es/**](https://docs.newrelic.com/es/): Espagnol
* [**docs.newrelic.com/pt/**](https://docs.newrelic.com/pt/): Portugais
* [**docs.newrelic.com/fr/**](https://docs.newrelic.com/fr/): Français

Vous pouvez basculer entre les langues à l’aide d’un bouton situé dans la barre de menu supérieure.

## Afficher le statut de traduction [#translation-status]

Le frontmatter de chaque document inclut son statut de traduction humaine.

S’il n’y a pas d’élément `translate:` dans le frontmatter, la documentation n’est traduite par un humain dans aucune langue. Elle sera tout de même traduite automatiquement dans toutes nos langues traduites par machine.

Si l’élément `translate:` a une abréviation de langue, telle que `jp`, alors le document a été traduit, sera traduit ou est en cours d’examen pour traduction. Par exemple :

```md
---
title: 'NRQL reference'
translate:
  - jp
  - kr
  - es
  - pt
  - fr
metaDescription: "A detailed reference list of clauses and functions in NRQL, the New Relic query language."
redirects:
  - /docs/insights/using-nrql
```

## Mettre à jour le document traduit [#update-translation]

Le site exécute une tâche automatique une fois par jour pour traduire automatiquement les modifications apportées à la documentation dans les langues cibles.

## Afficher le statut SEO pour les documents traduits [#translation-seo]

Le frontend du site utilise les informations du [statut de traduction](#translation-status) du document pour afficher l’élément SEO `hreflang` pour une page. Cela indique aux moteurs de recherche que la page a également une version disponible dans la langue spécifique.

```html
<link rel="alternate" href="https://docs.newrelic.com/jp/" hreflang="ja" />
```

## Supprimer et déplacer des documents [#delete]

Lorsque vous apportez des modifications à nos documents en anglais, vous pouvez obtenir une erreur de traduction non appariée sur GitHub. Voici des scénarios dans lesquels vous apporteriez des modifications à notre dossier i18n :

* Lorsque vous supprimez un fichier mdx, supprimez le fichier mdx correspondant dans les dossiers `/kr/` et `/jp/`. Vous ne mettez **pas** à jour le fichier yaml.
* Lorsque vous déplacez un fichier mdx du dossier X vers le dossier Y, vous devez déplacer ce même fichier mdx vers le dossier Y dans `/kr/` et `/jp/`. Vous ne mettez **pas** à jour le fichier yaml.
* Lorsque vous déplacez un fichier mdx vers un nouveau dossier, vous devez créer ce nouveau dossier dans `/kr/` et `/jp/`, puis y déplacer le fichier mdx. Vous ne mettez **pas** à jour le fichier yaml.

Au lieu de supprimer ou de déplacer manuellement des fichiers, exécutez ces séquences de commandes :

* Pour déplacer/renommer les fichiers traduits :

  ```bash
  yarn i18n-utility list-renames
  yarn i18n-utility make-renames
  ```

* Pour supprimer les fichiers traduits :

  ```bash
  yarn i18n-utility list-orphans
  yarn i18n-utility delete-orphans
  ```
