Parfois, vous devez attirer l’attention de vos collègues rédacteurs ou contributeurs, en les alertant sur un aspect des fichiers de documentation MDX avant qu’ils n’y apportent des modifications. Vous pouvez le faire en insérant un commentaire à l’aide du composant `<CONTRIBUTOR_NOTE>`.

Voici juste deux exemples d&apos;endroits où vous pourriez utiliser ce composant :

* Avertissez les autres concernant les modifications apportées aux informations sensibles sur le site.
* Expliquez la raison pour laquelle les informations se trouvent à cet endroit sur le site.

Lorsque vous utilisez le composant `<CONTRIBUTOR_NOTE>` pour rédiger des notes, ces notes ne seront jamais converties en HTML et ne seront jamais vues par nos lecteurs directement sur le site web (y compris dans **Code source**). Cependant, elles sont disponibles pour ceux qui choisissent de modifier le site, tenez donc toujours compte de votre voix et de votre ton.

Voici un exemple :

```jsx
<CONTRIBUTOR_NOTE>
  Do not change this URL unless you have explicit permission from a manager at New Relic.
</CONTRIBUTOR_NOTE>
```
