Les liens dans notre interface utilisateur doivent être concis et correspondre à notre style et à notre voix.

## Bases

* Gardez le texte de lien court pour optimiser la lecture par les lecteurs d&apos;écran.
* Commencez par l&apos;avantage pour le lecteur, et non par l&apos;emplacement du lien.
* Utilisez un langage conversationnel, des pronoms et des contractions, comme nous le faisons dans nos autres textes.
* Utilisez le nom ou la description de l’emplacement, au lieu de simplement « ce lien ».
* Pour les liens qui dirigent les utilisateurs hors du produit (comme vers nos sites de documentation ou d’assistance), ajoutez l’icône de lien externe à la fin.

## Code

Lorsque vous présentez des snippet de code aux clients, formatez-les avec la police à espacement fixe Menlo.

```js
var example = "This is an example string in a monospace font!";
```

## Listes

* Mettez en majuscule la première lettre de chaque élément de la liste.
* Pour les listes générales d&apos;informations, utilisez des listes non ordonnées (à puces).
* Pour les listes comportant des étapes spécifiques, utilisez une liste ordonnée (numérotée).
