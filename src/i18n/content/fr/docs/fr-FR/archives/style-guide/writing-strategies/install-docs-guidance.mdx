## Un aperçu des méthodes d&apos;installation [#overview]

Actuellement, nous proposons trois méthodes que nos clients peuvent utiliser pour installer New Relic et commencer le monitoring de quelque chose :

1. L’installation guidée, notre outil interactif en ligne de commande pour installer New Relic sur différents systèmes
2. Installation manuelle via la page « + Add more data » dans l’interface utilisateur
3. Installation manuelle via le site de documentation

Instant Observability (I/O) n’est **pas** une méthode d’installation. Il fournit simplement un catalogue de toutes les choses que quelqu’un pourrait potentiellement monitorer via New Relic. Une page d’observabilité instantanée pointe simplement vers l’une de ces trois méthodes, selon ce qui est disponible.

CodeStream a sa propre méthode d&apos;installation.

## Installation guidée [#guided]

[L&apos;installation guidée](/docs/new-relic-one/install-configure/new-relic-guided-install-overview/) fournit une commande unique que vous pouvez exécuter sur votre système pour installer New Relic et commencer le monitoring d&apos;une variété de choses.

Lorsque quelqu&apos;un exécute la commande CLI de l&apos;installation guidée, cela installe l&apos;agent d&apos;infrastructure et active l&apos;envoi de logs. Il détecte également les intégrations sur un système et vous invite à choisir de monitorer ou non ces intégrations. Si l&apos;installation guidée détecte une application d&apos;un langage pris en charge, elle peut installer l&apos;agent APM pour ce langage.

Pour la documentation, nous devrions diriger les personnes vers l&apos;installation guidée chaque fois que cela est approprié. C&apos;est-à-dire, lorsque l&apos;installation guidée est susceptible d&apos;aboutir à un résultat positif.

## Installation manuelle via l&apos;ajout de données supplémentaires [#manual-add]

Les pages [Add more data](https://one.newrelic.com/marketplace?state=7ca7c800-845d-8b31-4677-d21bcc061961) fournissent un chemin d&apos;installation simple et direct pour les personnes souhaitant installer des agents APM et qui utilisent les intégrations les plus populaires et les paramètres système les plus courants pour ces intégrations.

**Ajouter plus de données** remplit les fichiers de configuration d’installation avec des valeurs telles que le nom de l’application et la clé API afin qu’un client n’ait pas à rechercher ces informations. Ils fournissent également le chemin d’installation le plus simple pour les cas d’utilisation standard.

Cette méthode est moins efficace pour les clients qui ont des choses plus compliquées ou obscures qu&apos;ils essaient de monitorer ou des systèmes non standard.

**Ajouter plus de données** présente également l&apos;avantage de se trouver dans l&apos;UI.

## Installation manuelle via le site de documentation [#manual-docs]

Les procédures d’installation manuelle, telles que cette [installation manuelle de Java](/docs/apm/agents/java-agent/installation/install-java-agent), doivent être la méthode de dernier recours. Les instructions d’installation sur le site de la documentation sont très probablement obsolètes. Elles sont également présentées d’une manière assez confuse qui peut en fait empêcher les utilisateurs d’installer New Relic. Du point de vue de la documentation, il s’agit de la valeur par défaut, car c’est là que notre énergie et notre attention sont concentrées. C’est également l’endroit où nous pouvons facilement apporter des modifications.

Dans un effort pour être universellement exhaustifs, nos documents d’installation manuelle présentent un processus qui semble être incroyablement complexe. Cependant, la complexité réside dans la variété des options. Pour tout processus d’installation donné, les étapes sont assez simples, une fois qu’un utilisateur a identifié le processus d’installation qu’il doit utiliser.

## Observabilité instantanée [#io]

[L’observabilité instantanée](https://newrelic.com/instant-observability) est un catalogue public d’éléments qui peuvent être monitorés par New Relic et de dashboards et d’alertes par défaut utiles. Dans ce catalogue, il y a certaines technologies qui ne correspondent pas à ce modèle, telles que CodeStream ou Atlassian Jira.

Pour la plupart des pages de quickstart, le bouton **Installer maintenant** vous amène à une installation guidée, à une page d&apos;ajout de données supplémentaires, ou à une page de documentation d&apos;installation manuelle, selon ce qui est disponible pour cette technologie spécifique.

## Intégrations &amp; Agents dans l’UI [#add-data]

Dans l&apos;interface utilisateur, [+ Intégrations &amp; Agents](https://one.newrelic.com/marketplace?state=7ca7c800-845d-8b31-4677-d21bcc061961) vous amène à une version du catalogue d&apos;observabilité instantanée qui guide un utilisateur plus directement à travers le processus d&apos;intégration pour une technologie particulière.
