Les tableaux vous aident à organiser les informations pour faciliter la lecture rapide par les lecteurs. Cependant, si votre tableau devient trop long, suivez la [directive « cinq à neuf »](/docs/style-guide/get-started/introduction-style-guide#organization) et envisagez de restructurer les informations d’autres manières.

Utilisez la casse de phrase pour le texte de chaque colonne de tableau, à moins qu&apos;il ne s&apos;agisse d&apos;un nom de fichier spécifique ou d&apos;une valeur de code nécessitant des minuscules ou des majuscules.

<Callout variant="tip">
  La macro Keyboard Maestro pour le composant Table est `kktable`
</Callout>

## Syntaxe de tableau

Nos tableaux sont construits comme des composants MDX React. En pratique, ils sont assez similaires aux tableaux HTML :

```html
<table>
    <thead>
        <tr>
            <th style={{ width: "200px" }}>
                Item
            </th>
            <th>
                Description
            </th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>
                Item name
            </td>
            <td>
                Description of item
            </td>
        </tr>
    </tbody>
</table>
```

<Callout variant="tip">
  Le site de documentation prend techniquement en charge les [tableaux Markdown](https://www.markdownguide.org/extended-syntax/#tables), mais nous évitons de les utiliser pour plusieurs raisons :

  * Il existe plusieurs variantes de Markdown, et différentes variantes utilisent différentes syntaxes de tableau. Cela s’explique par le fait que la spécification Markdown originale de John Gruber n’incluait pas de tableaux.
  * Les tableaux Markdown ne prennent pas en charge les éléments qui s’étendent sur plusieurs lignes, et la plupart de nos tableaux incluent des blocs de code, des listes à puces ou d’autres éléments qui nécessitent plusieurs lignes.
</Callout>

## Définition de la largeur des colonnes [#column-width]

Vous pouvez définir la largeur de colonne avec une règle de style sur l’élément `<th>` :

```html
<th style={{ width: "200px" }}>
```

En général, pour les tableaux à deux colonnes sur le site de documentation :

1. Définissez la première colonne à 200 pixels : `style={{ width: "200px" }}`.
2. Pour permettre au tableau de s&apos;ajuster automatiquement à la largeur de page restante, ne définissez pas de largeur pour la deuxième colonne.

## Tableaux pour décrire les fonctions de l&apos;interface utilisateur [#tables-ui]

Lorsque vous utilisez des tableaux pour décrire les fonctions disponibles, donnez aux lecteurs une feuille de route. Ils peuvent savoir ce qu&apos;ils veulent trouver, ou accomplir, mais ils peuvent ne pas savoir comment cela s&apos;appelle, ou comment le faire.

Par exemple, pour fournir une liste de fonctionnalités pour une page d’interface utilisateur particulière, intitulez la première colonne de l’en-tête **Si vous voulez…** et la deuxième colonne **Faites ceci**.
