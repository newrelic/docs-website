La pluralisation des noms entraîne de subtils changements de ponctuation et d&apos;orthographe qui peuvent avoir un impact sur la façon dont les gens interprètent les mots écrits.

## Bases

* Utilisez des apostrophes pour mettre des lettres simples au pluriel.
* N’utilisez pas d’apostrophes pour mettre les acronymes au pluriel.

| À faire                                                               | À ne pas faire                                                        |
| --------------------------------------------------------------------- | --------------------------------------------------------------------- |
| Il y a 2 u dans le mot vacuum.                                        | Il y a 2 u dans le mot vacuum.                                        |
| N’oubliez pas de mettre les points sur les i et les barres sur les t. | N’oubliez pas de mettre les points sur les i et les barres sur les t. |
| Parlons des bases des adresses IP.                                    | Parlons de l’ABC des adresses IP.                                     |
