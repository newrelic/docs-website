Les éléments réductibles sont des éléments extensibles qui masquent le contenu de la page jusqu’à ce que vous [les ouvriez](#trigger-collapser). Nous utilisons des éléments réductibles pour masquer le contenu dans les documents très longs, par égard pour nos lecteurs. Chaque élément réductible possède un `title` (ce que nous montrons aux lecteurs), mais aussi un `id` que nous utilisons pour les liens d’« ancrage » profonds vers des éléments réductibles spécifiques.

Voici un exemple de section réductible :

<CollapserGroup>
  <Collapser id="collapser-1" title="Effondrement 1">
    Ceci est notre premier exemple d’effondrement.
  </Collapser>

  <Collapser id="collapser-2" title="Effondrement 2">
    Ceci est notre deuxième exemple de section réductible.
  </Collapser>
</CollapserGroup>

<Callout variant="tip">
  La macro Keyboard Maestro pour les éléments réductibles est `kkcollapse`.
</Callout>

## Créer une section réductible [#create]

Pour créer un élément réductible, vous devrez utiliser notre code d&apos;élément réductible.

Voici un exemple de la source de l&apos;élément réductible :

```jsx
<CollapserGroup>
  <Collapser
    id="collapser-1"
    title="Collapser 1"
  >
    This is our first example collapser.
  </Collapser>

  <Collapser
    id="collapser-2"
    title="Collapser 2"
  >
    This is our second example collapser.
  </Collapser>
</CollapserGroup>
```

## Déclencheurs des effondrements [#trigger-collapser]

Le site ouvre automatiquement les sections réductibles dans quelques scénarios :

* Accédez à un élément réductible individuel via un ID d&apos;ancrage. Par exemple, allez directement à [l&apos;élément réductible 1 dans l&apos;exemple ci-dessus](/docs/style-guide/quick-reference/collapsers#collapser-1).
* Utilisez **CMD+F** (ou **CTRL+F**) pour rechercher dans la page et toutes les sections réductibles s’ouvriront automatiquement.
* Tapez la touche de raccourci `s` pour **a**fficher (ouvrir) tous les éléments réductibles sur la page.
