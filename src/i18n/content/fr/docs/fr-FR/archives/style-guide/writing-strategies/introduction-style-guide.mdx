Bienvenue dans le guide de style de New Relic. Nous avons rédigé ces directives pour les créateurs de contenu de New Relic et pour les contributeurs à nos projets de contenu open source, comme la documentation ou nos autres référentiels GitHub New Relic.

Ce guide n’est pas destiné à couvrir toutes les questions d’utilisation. Pour tout ce qui n’est pas explicitement couvert, nous vous renvoyons au [Microsoft Writing Style Guide](https://docs.microsoft.com/en-us/style-guide/welcome/) (en particulier, la « A–Z word list » et le guide de [Formatting common text elements](https://docs.microsoft.com/en-us/style-guide/text-formatting/formatting-common-text-elements)) ou au [Chicago Manual of Style](https://www.chicagomanualofstyle.org/home.html) (pour les directives générales de rédaction et de révision).

Nous suivons les conventions de l’anglais américain, bien que si vous créez des ressources spécifiques à un pays, vous puissiez utiliser des variations régionales de l’anglais. Par exemple, un PDF cible destiné spécifiquement aux clients britanniques pourrait également suivre les conventions de l’anglais britannique. Si vous avez un doute, utilisez l’anglais américain.

Trouvez les informations dont vous avez besoin :

* Pour notre stratégie de rédaction, consultez les documents de cette section sur [la voix](/docs/style-guide/writing-strategies/voice-strategies-docs-sound-new-relic/), [les cinq questions pour un contenu de qualité](/docs/style-guide/writing-strategies/five-questions-help-write-docs/), [la façon d’organiser votre contenu](/docs/style-guide/writing-strategies/organize-doc), et plus encore.

* Pour une référence rapide sur l’utilisation des termes, consultez notre [dictionnaire d’utilisation](/docs/style-guide/word-choice/usage-dictionary).
