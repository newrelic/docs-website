Ce document explique la différence entre les titres et les titres courts. Il détaille également comment ceux-ci sont affectés et affectent les chemins et les redirections.

## Titres

Les titres sont le titre affiché en haut de chaque document. Le titre de ce document est **Titres, titres courts et chemins**.

Le titre d&apos;un document est défini dans le front matter. Le titre de ce document est défini ci-dessous :

```yaml
title: Titles, short titles, and paths
```

## Titres courts

Les titres courts sont affichés dans la navigation de gauche. Ils sont utilisés dans les cas où le titre est un peu trop long pour être facilement parcouru. Le titre court de ce document est **Titres, et titres courts**.

Le titre court est défini dans le fichier de navigation correspondant. Le titre court de ce document est défini dans `src/content/nav/style-guide.yml`:

```yaml
- title: Titles and short titles
  path: /docs/style-guide/structure/titles
```

Pour en savoir plus sur [la modification de la navigation de gauche](/docs/style-guide/processes-procedures/update-left-navigation-pane).

## Chemins et redirections

Le chemin et le nom de fichier d&apos;un document spécifique n&apos;ont aucune incidence sur le titre de ce document. Le chemin pour ce document est `/docs/style-guide/structure/titles`. Remarquez que bien que le fichier soit nommé `titles`, ni le titre ni le titre court ne s&apos;appellent `Titles`.

Les redirections ignorent complètement le titre, le titre court et le chemin d&apos;un document. Elle vous redirigera vers la cible de la redirection. [En savoir plus sur les redirections](/docs/style-guide/processes-procedures/rename-or-redirect-document).
