## Bases

* Séparez les unités de mesure de leur valeur par un seul espace.
* Pour les mesures dans le temps, insérez une barre oblique entre l’unité de mesure et l’unité de temps.

| Unité de mesure         | À faire    | À ne pas faire |
| ----------------------- | ---------- | -------------- |
| requests par minute     | 29,5 k rpm | 29,5Krpm       |
| requests par seconde    | 14 rps     | 14rps          |
| pages par minute        | 6,33 ppm   | 6,33 ppm       |
| kilo-octets par seconde | 16 Ko/s    | 16 Ko s        |
