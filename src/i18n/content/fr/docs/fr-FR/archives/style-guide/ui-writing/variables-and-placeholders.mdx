## Variables

Utilisez des variables lorsque vous devez insérer une valeur calculée ou le résultat d’une requête dans une phrase facile à lire. Les directives sont les mêmes, que vous appeliez cela des éléments de remplissage, des remplacements, des substitutions ou tout autre terme.

### Qu’est-ce qu’une variable ? Les éléments en gras ci-dessous.

| Dans le code                                                                                        | Dans l&apos;interface utilisateur                                          |
| --------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Nous avons détecté un comportement anormal dans **\[nom du service]**.                              | Nous avons détecté un comportement anormal dans **RPM-UI-production**.     |
| **\[% of crashes]** des plantages partagent le système d’exploitation **\[operating system type]**. | **80 %** des plantages partagent le système d’exploitation **iOS 11.1.2**. |

### Bases

Si la valeur insérée est courte, placez-la à l’endroit le plus logique de la phrase pour qu’elle paraisse naturelle. Si la valeur est longue, illisible ou hors de notre contrôle, placez-la à la fin de la phrase. Si la variable peut être n’importe quelle partie du discours ou parfois singulière et parfois plurielle, séparez-la par deux-points ou placez-la sur une autre ligne.

| À faire                                                                                              | À ne pas faire                                                                                  |
| ---------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| Nous avons détecté un comportement anormal dans **bob-long-name-32-october-service-legacy-système**. | Le service **bob-long-name-32-october-service-legacy-system** présente un comportement anormal. |
| **80 %** des plantages partagent le nom d&apos;utilisateur **pdiddybigdog**.                         | **80 %** des plantages partagent le nom d&apos;utilisateur **pdiddybigdog**.                    |
| Services avec de multiples erreurs : **1**                                                           | **1** services ont de multiples erreurs.                                                        |

## Texte d&apos;espace réservé

Pour le texte d&apos;espace réservé dans les champs de saisie, utilisez « Exemple : … » Et dans les endroits comme la documentation où nous ajoutons des exemples en ligne, utilisez « tel que, » Par exemple, « X nécessite une action pour être ignorée (tel que, confirmer qu&apos;un utilisateur souhaite supprimer un dashboard). »
