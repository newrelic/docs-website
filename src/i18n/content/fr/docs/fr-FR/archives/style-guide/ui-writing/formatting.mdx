À l’instar de la ponctuation, le formatage du texte peut avoir un impact énorme sur la façon dont les gens interprètent nos mots. Par exemple, vous pouvez utiliser le texte en gras comme un outil simple pour mettre l’accent dans un message, ou vous pouvez l’utiliser pour guider les yeux d’une personne dans l’interface utilisateur afin qu’elle sache instinctivement ce qui est important.

## Bases

* Le texte en gras est souvent utilisé pour améliorer la lisibilité dans l’interface utilisateur et souligner des mots spécifiques dans des textes plus longs.
* L’italique est souvent utilisé pour le texte d’indication contextuelle sous les éléments de saisie et peut conférer au texte un ton concentré ou un ton feutré.
* Le texte souligné dans l’interface utilisateur peut facilement être interprété comme un lien, soyez donc prudent lorsque vous utilisez ce format à d’autres fins. Envisagez de trouver une solution alternative aux mots soulignés qui ne fonctionneront pas comme des liens.

## Code

Lorsque vous présentez des snippet de code aux clients, formatez-les avec la police à espacement fixe Menlo.

```javascript
var example = 'This is an example string in a monospace font!';
```

## Listes

* Mettez en majuscule la première lettre de chaque élément de la liste.
* Pour les listes générales d&apos;informations, utilisez des listes non ordonnées (à puces).
* Pour les listes comportant des étapes spécifiques, utilisez une liste ordonnée (numérotée).
