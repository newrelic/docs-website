L&apos;équipe de documentation gère un dictionnaire de données qui stocke des informations de métadonnées sur les types de données par défaut dans la base de données New Relic (par exemple, transaction, métrique, log) et leurs attributs associés. Ces métadonnées sont publiées par notre service de dictionnaire d&apos;attributs à deux endroits :

* Les expériences de requête de l’UI de New Relic affichent ces informations lorsque vous survolez les types de données et les attributs.
* Les données apparaissent sur le [dictionnaire d&apos;attributs](https://docs.newrelic.com/attribute-dictionary/) du site de documentation.

<Callout variant="tip">
  Voici quelques limites concernant la portée des données :

  * Actuellement, les seules informations liées à l’infrastructure que nous avons dans le dictionnaire d’attributs concernent Kubernetes.
  * Nous avons également très peu d’attributs pour le type de données métrique — juste quelques-uns de base par défaut — malgré de nombreux attributs potentiels qui pourraient être rattachés à certains types de données.
</Callout>

Si vous êtes rédacteur chez New Relic et que vous devez apporter des modifications au dictionnaire de données, vous effectuerez vos modifications dans notre référentiel privé sur GitHub Enterprise. Consultez notre Drive d&apos;équipe Google Doc interne pour savoir comment configurer le référentiel et où trouver les instructions du fichier README.md.
