title: Les émojis
translationType: machine
---

Bien qu’ils puissent être utiles pour clarifier l’intention émotionnelle dans les messages, nous voulons assurer une communication cohérente à tous nos clients. Sauf indication contraire ici ou dans nos règles d’iconographie, évitez d’utiliser des emojis dans le texte de l’interface utilisateur.

## Bases

Évitez d’utiliser des emojis dans le texte de l’interface utilisateur. Si vous avez envie d’utiliser un emoji pour donner une tournure positive au texte que vous avez écrit (par exemple un message d’erreur), consultez nos règles sur la voix et le ton et réécrivez votre message jusqu’à ce qu’il atteigne votre objectif.

## E-mail

Lorsque vous communiquez avec des clients par e-mail, évitez d’utiliser des emojis à moins qu’ils ne le fassent en premier, ou si vous avez déjà établi une relation avec eux.

## Messagerie in-app

Lorsque vous contactez des clients via un service intégré à l’application comme Intercom.io, il devrait être sûr d’ajouter un simple smiley à votre message si vous jugez cela approprié.
