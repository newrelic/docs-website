Introduction : cette section présentera l&apos;agent et l&apos;API en termes généraux. Parlez du moment où un utilisateur voudrait l&apos;API, et des alternatives à l&apos;utilisation de l&apos;API (par exemple, l&apos;instrumentation via un fichier XML). Mentionnez que l&apos;API est souvent inutile si votre framework dispose d&apos;une prise en charge « prête à l&apos;emploi ». Créez un lien vers la racine de votre référence d&apos;API, qu&apos;elle soit sur site ou hors site. Avertissez l&apos;utilisateur qu&apos;il doit utiliser la version la plus récente de l&apos;agent.

## Instrumenter manquant des sections de votre code avec des transactions [#creating-transactions]

Pour instrumenter votre application, New Relic sépare chaque chemin à travers votre code dans sa propre transaction. New Relic chronomètre (ou « instrumente ») la méthode parent dans ces transactions pour mesurer les performances globales de votre application, et collecte des traces de transaction à partir des transactions de longue durée pour plus de détails. Pour plus d’informations sur les transactions, voir [transaction](/docs/accounts-partnerships/education/getting-started-new-relic/glossary#transaction) et [trace de transaction](/docs/apm/transactions/transaction-traces/introduction-transaction-traces).
