Ce document décrit comment modifier le titre d’un document et comment créer, modifier et supprimer des redirections. Les procédures sont les mêmes pour les documents standards (« pages de base ») et les notes de sortie.

<Callout variant="caution">
  La modification des titres ou la mise à jour des redirections peut créer des problèmes pour trouver du contenu. Si vous devez modifier un titre ou une redirection, [créez un ticket GitHub](https://github.com/newrelic/docs-website/issues/new/choose) ou, si vous êtes un collaborateur de New Relic, contactez le héros de la documentation via le canal Slack #help-documentation.
</Callout>

## Format d&apos;URL [#title-url]

L&apos;URL d&apos;un document est basée uniquement sur son nom de fichier et son chemin d&apos;accès dans le référentiel (repository) GitHub. Pour plus d&apos;informations, voir [URL du document](/docs/style-guide/processes-procedures/understand-edit-docs-site-structure#doc-url).

## Modifier les titres [#titles]

Pour modifier le titre d’un document, modifiez le titre utilisé dans le champ `title` dans le frontmatter en haut du document.

Si vous souhaitez mettre à jour un titre dans la barre latérale, modifiez le `title` pour ce document dans le fichier de navigation.

## Modifier les liens d’ancrage [#anchors]

Dans la mesure du possible, ne modifiez pas le `[#anchor_ids]` d’un H2 ou d’un élément réductible. Il n’y a aucun moyen de rediriger une ancre supprimée vers sa nouvelle valeur. Même si l’ancre `id` est obsolète, cela n’affecte pas la majorité des utilisateurs qui ne prêtent aucune attention aux URL.

## Modifier les redirections [#redirects]

Si vous modifiez l&apos;URL d&apos;un document, assurez-vous d&apos;ajouter l&apos;ancienne URL à la section frontmatter `redirects` en haut du document.
