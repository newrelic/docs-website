Le composant `SideBySide` vous permet de diviser l’écran en deux, ou en plusieurs sections. Un cas d’utilisation courant consiste à afficher une capture d’écran dans la colonne de droite, et le texte d’accompagnement à gauche.

Vous devez encapsuler le contenu de chaque côté dans un composant `Side`, mais vous pouvez ajouter autant de contenu que nécessaire dans chaque `Side`.

Techniquement, le composant prend en charge plus de deux colonnes `Side`, mais vous devriez éviter d&apos;en utiliser plus de deux.

Voici un exemple du composant :

<SideBySide>
  <Side>
    <img alt="example" src="/images/network_screenshot-full_device-performance.webp" />

    <figcaption>
      Accédez à **[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Network**
    </figcaption>
  </Side>

  <Side>
    Il s’agit d’un contenu fantastique de l’incroyable équipe de documentation.
  </Side>
</SideBySide>

## Créer un composant SideBySide [#create]

Voici un modèle d’un composant `SideBySide` :

```jsx
<SideBySide>
    <Side>
        <img alt="Example" src="/images/example-image.webp" />
    </Side>

    <Side>
        This is some awesome content from the amazing documentation team.
    </Side>
</SideBySide>
```

<Callout variant="tip">
  La macro Keyboard Maestro pour le SideBySide est `kkside`.
</Callout>
