Avec cette sortie, les [utilisateurs principaux](/docs/accounts/accounts-billing/new-relic-one-user-management/user-type/#user-type-capabilities) peuvent gérer les utilisateurs et gérer la facturation. Ils peuvent :

* Effectuez des tâches de gestion des utilisateurs s’ils disposent du [rôle standard**Gestionnaire de domaine d’authentification** ](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts#roles).
* Effectuez des tâches administratives de facturation s’ils ont le [rôle standard d’**utilisateur de facturation** ](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts#roles).
