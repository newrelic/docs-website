Nous avons annoncé la sortie de la possibilité d’exporter les données utilisateur depuis l’interface utilisateur de **User management**. Les données sont exportables via TSV. Les colonnes exportables incluent les noms des utilisateurs, les adresses e-mail, le type d’utilisateur actuel, les groupes et l’ID utilisateur. Les administrateurs peuvent choisir d’exporter tous les utilisateurs ou de sélectionner un sous-ensemble d’utilisateurs.

Pour plus de détails, voir [Exporter la liste d’utilisateurs](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-ui-and-tasks).
