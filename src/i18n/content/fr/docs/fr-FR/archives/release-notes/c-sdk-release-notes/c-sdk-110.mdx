### Nouvelle fonctionnalité

* **Prise en charge du tracing distribué**

  Le tracing distribué vous permet de voir le chemin emprunté par une requête lorsqu&apos;elle traverse votre système distribué. En montrant l&apos;activité distribuée à travers une vue unifiée, vous pouvez dépanner et comprendre un système complexe mieux que jamais.

  Le tracing distribué est disponible avec un abonnement APM Pro ou équivalent. Pour voir une trace distribuée complète, vous devez activer la fonctionnalité sur un ensemble de services voisins.

  Consultez la [documentation du SDK C](https://docs.newrelic.com/docs/agents/c-sdk/instrumentation/enable-distributed-tracing-your-c-applications) de New Relic pour plus d’informations sur l’activation du tracing distribué pour le SDK C.

### Avis de fin de vie

* Les champs `log_filename` et `log_level` de `newrelic_app_config_t` sont actuellement obsolètes. Les futures versions du SDK C supprimeront définitivement ces champs. Pour spécifier le fichier de log et le niveau de log à utiliser avec le SDK C, utilisez `newrelic_configure_log()`.
