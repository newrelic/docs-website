## La gestion automatisée des utilisateurs est désormais disponible pour l’édition Pro

La fonctionnalité de [gestion automatisée des utilisateurs](/docs/accounts/accounts/automated-user-management/automated-user-provisioning-single-sign) de New Relic est désormais disponible pour les organisations disposant de l&apos;[édition Pro](https://newrelic.com/pricing) de New Relic. Auparavant, cela n&apos;était disponible que pour les organisations disposant de l&apos;édition Enterprise.

La gestion automatisée des utilisateurs vous permet d’utiliser le provisionnement SCIM pour importer, mettre à jour et désactiver vos utilisateurs New Relic à partir d’un fournisseur d’identité, comme Azure AD, Okta ou OneLogin. Vous pouvez également gérer les attributs de vos utilisateurs, y compris le type d’utilisateur et le fuseau horaire, via votre fournisseur d’identité.
