Vous pouvez désormais interroger le nom, l’ID utilisateur, le type d’utilisateur, l’e-mail et la date de dernière activité d’un utilisateur avec notre API NerdGraph. Vous pouvez également mettre à jour le type d’utilisateur et l’adresse e-mail d’un utilisateur.

Pour en savoir plus, consultez [la documentation NerdGraph](/docs/apis/nerdgraph/examples/nerdgraph-manage-users).
