## Nouvelle version du modèle de tarification de New Relic One avec les utilisateurs de base

Nous avons sorti une nouvelle version du [modèle de tarification New Relic One](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/new-relic-one-pricing-billing) avec un nouveau [type d’utilisateur](/docs/accounts/accounts-billing/new-relic-one-user-management/user-type): le Core utilisateur. Les organisations sur cette version de tarification ont accès à trois types d’utilisateur : les utilisateurs de base, les Core utilisateurs et les plateformes utilisateurs complètes. Le Core utilisateur a plus d’accès que les utilisateurs de base et coûte moins cher qu’une plateforme utilisateur complète. Les Core utilisateurs ont accès à certaines fonctionnalités puissantes centrées sur les développeurs comme New Relic CodeStream, notre UI de log et la capacité de créer des applications New Relic.

Cette version de tarification [calcule également les utilisateurs facturables différemment](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/user-count-billing#user-count) et possède [différentes règles de rétrogradation d&apos;utilisateur](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/user-count-billing/#user-downgrade-rules).

Pour en savoir plus sur cette sortie et sur la disponibilité, consultez [Sortie des utilisateurs Core](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/core-users-release).
