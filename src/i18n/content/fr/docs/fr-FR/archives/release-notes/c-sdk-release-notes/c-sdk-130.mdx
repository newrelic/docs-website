### Nouvelle fonctionnalité

* **Prise en charge de la diffusion en temps réel**

  * Les données d&apos;événement sont désormais envoyées à New Relic toutes les cinq secondes, au lieu de chaque minute. Par conséquent, les événements de transaction, d&apos;erreur et les événements personnalisés seront désormais disponibles dans les dashboards New Relic en temps quasi réel. Pour plus d&apos;informations sur la façon de consulter vos événements avec une actualisation de cinq secondes, consultez la [documentation sur le streaming en temps réel](/docs/agents/manage-apm-agents/agent-data/real-time-streaming).
  * Notez que les limites globales sur le nombre d’événements pouvant être envoyés par minute n’ont pas changé. De plus, les événements de span, les métriques et les données de trace ne sont pas affectés et seront toujours envoyés chaque minute.

### Débogage

* Une configuration par défaut créée avec `newrelic_create_app_config()` fonctionnera désormais comme prévu avec les clés de licence pour les comptes non américains.

* Pour les charges de tracing distribué entrantes avec des valeurs invalides ou manquantes pour `pr` (priorité) et/ou `sa` (échantillonné), l’agent attribuait une priorité par défaut de -1 et/ou une valeur échantillonnée par défaut de `false` à la transaction.

  Cela a été corrigé : l&apos;agent conserve désormais la priorité initiale et les valeurs échantillonnées si les valeurs respectives dans la charge de tracing distribué entrante sont manquantes ou non valides.
