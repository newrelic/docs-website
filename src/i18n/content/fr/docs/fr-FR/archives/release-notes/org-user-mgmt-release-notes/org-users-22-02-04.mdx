Les utilisateurs de la plateforme New Relic One qui sont gérés via la [gestion automatisée des utilisateurs](/docs/accounts/accounts/automated-user-management/automated-user-provisioning-single-sign) ne pouvaient auparavant définir leur fuseau horaire que via leur fournisseur d’identité (IdP).

Désormais, tous les utilisateurs peuvent remplacer ces préférences de fuseau horaire en les mettant à jour dans New Relic One. Cela est particulièrement utile pour les clients avec des IdP qui ne peuvent pas envoyer de préférences de fuseau horaire à New Relic.

Pour ce faire, visitez simplement vos préférences utilisateur et mettez à jour votre fuseau horaire. Nous enregistrerons automatiquement votre nouvelle préférence et remplacerons ce qui est envoyé via votre fournisseur d’identité.

Pour plus de détails, consultez la [documentation sur les paramètres de fuseau horaire](/docs/accounts/accounts-billing/general-account-settings/default-time-zone-setting).
