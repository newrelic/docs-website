La gestion de l&apos;accès de vos utilisateurs à New Relic est désormais plus facile. Nous avons amélioré la [page de l&apos;interface utilisateur**Gestion des accès** ](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-ui-and-tasks#where)pour qu&apos;elle soit davantage axée sur les groupes. Vous pouvez désormais comprendre plus rapidement à quels rôles et comptes vos groupes ont accès, créer des groupes et modifier l&apos;accès des groupes.

Nous avons également simplifié la façon dont vous gérez les fonctionnalités administratives de niveau supérieur. Auparavant, nous avions des rôles distincts à l&apos;échelle de l&apos;organisation pour ces capacités. Désormais, les paramètres administratifs au niveau de l&apos;organisation (comme la facturation, les paramètres de l&apos;organisation et les paramètres du domaine d&apos;authentification) peuvent être facilement attribués à un groupe à partir de la page d&apos;interface utilisateur **Groups**.

Pour en savoir plus :

* Consultez la page de l&apos;UI de **gestion des accès**
* [Lisez comment attribuer l&apos;accès de groupe](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial#group-access)
* [En savoir plus sur les paramètres d’administration](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts#admin-settings)
