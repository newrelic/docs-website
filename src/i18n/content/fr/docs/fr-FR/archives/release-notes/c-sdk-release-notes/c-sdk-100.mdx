### Nouvelle fonctionnalité

Ceci est la première sortie du SDK C de New Relic ! Si votre application n&apos;utilise pas [d&apos;autres langages d&apos;agent New Relic APM](https://docs.newrelic.com/docs/agents/manage-apm-agents/installation/compatibility-requirements-new-relic-agents-products#apm-compatibility), vous pouvez utiliser le SDK C pour tirer parti des capacités de monitoring et des fonctionnalités de New Relic pour instrument une large gamme d&apos;applications.

Pour plus d&apos;informations, voir :

* [Documentation](/docs/agents/c-sdk): comment démarrer avec le SDK C, l&apos;installer et le configurer, instrument les transactions, les segments et les erreurs, utiliser l&apos;API du SDK C, et effectuer un dépannage de base.
* [GitHub](https://newrelic.github.io/c-sdk/index.html): fichiers SDK, structure de données, définitions de champs et paramètres, exemples de code, fonctions, variables.

### Avis de fin de vie

Le précédent SDK d’agent APM est un logiciel bêta déprécié. Si vous utilisiez précédemment le SDK d’agent, vous pouvez passer au SDK C. Consultez la [compatibilité et les exigences](/docs/c-sdk-compatibility-requirements), puis [instrument, compilez et liez](/docs/install-c-sdk-compile-link-your-code) le code de votre application pour utiliser le SDK C. Le SDK C ne prend actuellement pas en charge la fonctionnalité HSM de New Relic ; cela peut avoir un impact sur la façon dont vous planifiez votre transition depuis le SDK d’agent.
