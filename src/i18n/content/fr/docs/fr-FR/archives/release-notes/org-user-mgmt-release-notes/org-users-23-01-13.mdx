Nous avons modifié l&apos;emplacement de certains paramètres du [domaine d&apos;authentification](https://docs.newrelic.com/docs/accounts/accounts-billing/new-relic-one-user-management/authentication-domains-saml-sso-scim-more). Les changements incluent :

* Nous avons placé l’interface utilisateur **Domaines d’authentification** dans le [menu de l’interface utilisateur**Administration** ](https://docs.newrelic.com/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-ui-and-tasks/#where).
* Nous avons déplacé les paramètres de session utilisateur et les paramètres de mise à niveau utilisateur vers la page de l&apos;interface utilisateur **Gestion des utilisateurs**.
