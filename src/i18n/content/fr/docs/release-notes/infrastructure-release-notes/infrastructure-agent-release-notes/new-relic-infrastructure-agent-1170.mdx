## Remarques

Une nouvelle version de l’agent est sortie. Suivez les procédures standard pour [mettre à jour l’agent d’infrastructure](/docs/infrastructure/install-configure-manage-infrastructure/update-or-uninstall/update-infrastructure-agent).

New Relic recommande de mettre à jour l’agent régulièrement et au minimum tous les 3 mois.

## Modifié

* `nri-docker` vers la [v1.6.0](https://github.com/newrelic/nri-docker/releases/tag/v1.6.0). De nouvelles métriques de mémoire et de stockage ont été ajoutées. Le calcul de `memoryUsageBytes` et `memoryUsageLimitPercent` a changé. Veuillez vous référer à cet [article de mise à jour du produit](https://support.newrelic.com/s/hubtopic/aAX8W0000008bmH/dockercontainers-memory-metric-updates) et aux [notes de sortie de nri-docker](https://github.com/newrelic/nri-docker/releases/edit/v1.6.0) pour plus d’informations.
* `nri-winservices` vers [v0.2.0-beta](https://github.com/newrelic/nri-winservices/releases/tag/v0.2.0-beta).
