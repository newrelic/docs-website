## Remarques

### 🛡️ Avis de sécurité

* Correction d’une vulnérabilité d’exécution de code à distance causée par une traversée de chemin dans [#2292](https://github.com/newrelic/infrastructure-agent/pull/2292)
* Ajout d’autorisations explicites aux workflows GitHub Actions pour réduire la portée du jeton dans [#2232](https://github.com/newrelic/infrastructure-agent/pull/2232)
* Mise à jour de google.golang.org/grpc de 1.79.3 à 1.82.1 dans go.mod dans [#2296](https://github.com/newrelic/infrastructure-agent/pull/2296)
* Mise à jour des versions OHI intégrées (nri-docker, nri-flex) pour corriger des CVE connues dans [#2302](https://github.com/newrelic/infrastructure-agent/pull/2302)
* mise à jour des dépendances vulnérables signalées par l’analyse Trivy dans [#2301](https://github.com/newrelic/infrastructure-agent/pull/2301)

### 🚀 Améliorations

* Ajout de la prise en charge pour ignorer les emplacements d&apos;intégration par défaut via disable\_plugin\_default\_dir\_scan dans [#2290](https://github.com/newrelic/infrastructure-agent/pull/2290)
* Variables d’environnement utilisées par Agent Control rendues publiques dans [#2293](https://github.com/newrelic/infrastructure-agent/pull/2293)
* Ajout de la prise en charge des tags OCI pour correspondre aux tags AWS (Phase 1 + Phase 2) dans [#2295](https://github.com/newrelic/infrastructure-agent/pull/2295)
* Activation de NRIA\_DISABLE\_PLUGIN\_DEFAULT\_DIR\_SCAN par défaut pour les agents gérés par Agent-Control dans [#2300](https://github.com/newrelic/infrastructure-agent/pull/2300)
* Suppression de nri-flex des artefacts agent-control dans [#2291](https://github.com/newrelic/infrastructure-agent/pull/2291)

### 🐞 Débogage

* Restauration des autorisations de tâche manquantes pour les workflows de sortie et canary dans [#2303](https://github.com/newrelic/infrastructure-agent/pull/2303)

### Déclaration de soutien :

Une nouvelle version de l’agent est sortie. Suivez les procédures standard pour [mettre à jour l’agent d’infrastructure](/docs/infrastructure/install-configure-manage-infrastructure/update-or-uninstall/update-infrastructure-agent).

Nous recommandons de mettre à jour vers la dernière version de l&apos;agent dès qu&apos;elle est disponible. Si vous ne pouvez pas mettre à niveau vers la dernière version, mettez à jour vos agents vers une version datant de 90 jours maximum. En savoir plus sur [la mise à jour des agents](https://docs.newrelic.com/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent/).

Consultez la [politique EOL de l’agent New Relic Infrastructure](https://docs.newrelic.com/docs/infrastructure/infrastructure-agent/infrastructure-agent-eol-policy/) pour obtenir des informations sur la sortie de l’agent et les dates de support.
