## Mis à jour

Comme [annoncé précédemment](https://support.newrelic.com/s/hubtopic/aAX8W0000008cts/important-upcoming-changes-to-capabilities-and-support-across-errors-classic), nous mettons fin à la prise en charge des données d’inventaire poussées depuis nos intégrations cloud (AWS, Azure, GCP).

### Qu’est-ce qui change ?

Les données d’inventaire sont actuellement collectées sur de nombreuses intégrations AWS, Azure, et GCP. Cela représente des données de configuration statiques ou des métadonnées de ressources. Les informations provenant des hôtes ou des intégrations sur hôte dans l’inventaire ne sont pas affectées par ce changement.

### Qu’est-ce que l’Inventaire ?

Les données d’inventaire sont des informations sur l’état et la configuration d’un service, par ex. les paramètres du service. Les données apparaissent sur la page Inventaire et dans certains dashboards d’intégration de l’expérience d’infrastructure d’origine. Les modifications apportées aux données d’inventaire génèrent des événements New Relic `InfrastructureEvent` qui peuvent faire l’objet d’une requête et d’une alerte.

### Fonctionnalités qui ne seront plus disponibles

* Lors de la navigation vers Infrastructure &gt; Inventory, toute source provenant de `aws/*`, `azure/*`, ou `gcp/*` ne sera plus disponible.
* Les dashboards intégrés disponibles dans Infrastructure &gt; AWS | Azure | GCP | GovCloud qui contiennent des widgets d’inventaire ou d’événements d’infrastructure n’afficheront plus de données. Il est prévu que ces dashboards soient migrés en tant que dashboards New Relic standards, activant toutes les nouvelles fonctionnalités (édition, partage, nouvelles visualisations, et plus) qui ne sont pas disponibles dans l’expérience de dashboard d’origine pour le monitoring d’infrastructure.
* Les requêtes utilisant les sources `aws`, `azure`, ou `gcp` de `InfrastructureEvent` ne rapporteront plus de données.

### Pourquoi cette capacité est-elle dépréciée ?

* Les clients trouvent plus de valeur dans l’inventaire d’Hôte, qui n’est pas obsolète, mais moins de valeur dans l’intégration cloud.

### Alternatives

* La plupart des attributs disponibles en tant qu’inventaire dans les intégrations d’interrogation sont également disponibles en tant que métadonnées de métrique, ou tags, vous pouvez donc effectuer une requête pour ces informations.
* Un ensemble limité d’intégrations a également publié les mêmes informations disponibles dans Inventory sous forme d’événements New Relic standards. Par exemple, l’intégration AWS Health.

### Comment cela affecte-t-il les flux de métriques CloudWatch AWS et les futures intégrations pour Azure &amp; GCP ?

* L’inventaire n’est pas disponible dans le flux de métriques CloudWatch d’AWS, il n’y a donc aucun impact sur cette capacité.
* Les nouvelles intégrations pour Azure et GCP seront axées sur la télémétrie MELT : métriques, événements, logs &amp; traces, avec un accent particulier sur les métriques.

### Retour

1. connectez-vous à votre compte New Relic.
2. Visitez notre [Centre d’aide](https://one.newrelic.com/help-xp) complet. Il contient une mine d’informations et de ressources.
3. Si vous avez besoin d’aide supplémentaire, cliquez sur **Create a Support Case** et notre équipe se fera un plaisir de vous aider.
