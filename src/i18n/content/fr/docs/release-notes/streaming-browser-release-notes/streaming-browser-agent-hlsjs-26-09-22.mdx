### Nouvelles fonctionnalités

* **Export de sous-chemin`/browser` :** un point d’entrée `@newrelic/video-hls/browser` qui exclut le code Vega/appareil connecté inutilisé est désormais disponible, réduisant la taille du bundle pour les consommateurs sur navigateur. Un shim de système de fichiers `browser.js` est également inclus pour les bundlers qui ne respectent pas le champ `exports`.
* **Export nommé :** `{ HLSTracker }` est désormais disponible en tant qu’export nommé aux côtés de l’export par défaut existant sur les points d’entrée racine et `/browser`.

### Améliorations

* **`@newrelic/video-core` mis à jour en 5.1.0**, qui inclut des fichiers de déclaration TypeScript, du débogage en amont, et des correctifs de dépendance.
