### Nouvelles fonctionnalités

* Ajout de `VegaTracker`, un tracker HLS.js pour les appareils Amazon Vega (de classe Kepler / Fire TV). Importez-le via le nouveau point d’entrée de sous-chemin `@newrelic/video-hls/vega`. `VegaTracker` étend `HLSTracker` et achemine la télémétrie via le pipeline des appareils connectés au lieu du pipeline du navigateur. Livré aux formats CJS et ESM.

### Débogage

* Correction du nom du tracker signalé par `VegaTracker` de `'vega-hls'` à `'hls'` afin que l&apos;attribut `trackerName` dans les événements New Relic corresponde à la valeur attendue.
