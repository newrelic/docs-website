### Modifié

* **Video Core :** mise à jour de la dépendance `@newrelic/video-core` intégrée vers la v5.1.1, et épinglage à cette version exacte (précédemment `^5.0.1`), afin que chaque build utilise la même sortie du cœur.
* **Épinglage de dépendance :** `dependencies` et `devDependencies` sont désormais épinglés sur les versions exactes déjà résolues dans `package-lock.json`, de sorte qu’une nouvelle installation ne récupère plus les sorties nouvellement publiées des outils de compilation.
