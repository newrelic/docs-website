### Nouvelles fonctionnalités

* **Prise en charge du SDK Web THEOplayer :** première sortie stable du tracker THEOplayer de New Relic pour les environnements de navigateur. Importer via `@newrelic/video-theo/browser`.
* **Point d&apos;entrée Browser :** sous-chemin `@newrelic/video-theo/browser` dédié qui exclut le pipeline Vega / appareils connectés pour les bundles exclusivement pour navigateur.
* **Suivi du débit binaire :** signale `contentBitrate`, `contentManifestBitrate`, `contentSegmentDownloadBitrate`, et `contentNetworkDownloadBitrate`.
* **Suivi de la qualité de rendu :** suit la hauteur, la largeur, et la bande passante du rendu actif via des événements de changement de qualité au niveau de la piste.
* **Support multiformat :** les flux HLS et DASH sont pris en charge via le streaming adaptatif natif de THEOplayer.

### Améliorations

* **`@newrelic/video-core` mis à jour vers 5.1.0**, activant les rappels de drain QoE sur `sendStart`/`sendEnd` via `getHarvester()`.
* **Nom du lecteur :** l&apos;attribut `playerName` renvoie `THEOplayer`.
* **Gestion des codes d’erreur :** `errorCode` est omis des événements lorsqu’aucun code fourni par le SDK n’est disponible, évitant ainsi les valeurs sentinelles dénuées de sens dans NRDB.
