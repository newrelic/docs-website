  Nous testons les notes de version pour vous informer de ce qui change dans notre documentation chaque semaine. Il s&apos;agit d&apos;une expérience, alors [faites-le-nous savoir via une issue GitHub](https://github.com/newrelic/docs-website/issues/new/choose) si vous les trouvez utiles !

### Changements majeurs

* Revue et réécriture de la documentation des intégrations sur hôte pour [RabbitMQ](/install/rabbitmq/), [JMX](/install/jmx/), [Apache Flink](/install/apache-flink/) et [HAProxy](/install/haproxy/) afin de faciliter l’installation et de garantir que la documentation est précise et à jour.
* Pour le [monitoring serverless AWS Lambda](/docs/serverless-function-monitoring/aws-lambda-monitoring/get-started/compatibility-requirements-aws-lambda-monitoring/), mise à jour des informations sur les versions d’exécution prises en charge, les dépendances, et le SDK du package NuGet .NET obsolète.
* Mise à jour de notre documentation de conformité [FedRAMP](/docs/security/security-privacy/compliance/certificates-standards-regulations/fedramp/), [HIPAA](/docs/security/security-privacy/compliance/certificates-standards-regulations/hipaa/), [ISO-27001](/docs/security/security-privacy/compliance/certificates-standards-regulations/iso-27001/), [SOC2](/docs/security/security-privacy/compliance/certificates-standards-regulations/soc2/), [TISAX](/docs/security/security-privacy/compliance/certificates-standards-regulations/tisax/), [chiffrement des données](/docs/security/security-privacy/compliance/data-encryption/) et [HITRUST CSF](/docs/security/security-privacy/compliance/hitrust/) pour refléter le statut de conformité 2024 de New Relic.
* Poursuite de la refonte et de la réorganisation de notre [documentation NRQL](/docs/nrql/get-started/introduction-nrql-new-relics-query-language) afin d&apos;améliorer la lisibilité et la qualité.
* Précision indiquant que le [stockage hors ligne du monitoring des applications mobiles](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/configure-settings/#android-offline-storage) Android est désactivé par défaut et mise à jour du document sur la [configuration du stockage hors ligne](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/set-max-offline-storage/#android).
* Ajout d’informations sur les [paramètres du monitoring des applications mobiles Unity](https://docs.newrelic.com/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/configure-settings/#unity).
* Ajout d’un point de terminaison de monitoring synthétique pour [AWS PrivateLink](/docs/data-apis/custom-data/aws-privatelink).
* Ajout d’une section de dépannage à la documentation de l’ [intégration Statsd](/docs/more-integrations/open-source-telemetry-integrations/statsd/statsd-monitoring-integration/#troubleshooting).
* Ajout d’une nouvelle section d’option de configuration .NET pour l’ [instrumentation de l’élément rules](/docs/apm/agents/net-agent/configuration/net-agent-configuration/#instrumentation-rules) .
* Mise à jour des [exigences de version pour la transition du gestionnaire de tâches](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-transition-guide) du monitoring synthétique.

### Mises à jour mineures

* Ajout des variables d’environnement [Kubernetes `vsePassphrase`](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-configuration/#kubernetes-env-config) pour le monitoring synthétique.
* Correction de quelques liens internes rompus.
* Mise à jour de la section sur le [statut des erreurs d’Errors Inbox](/docs/triage-inbox/errors-inbox) avec une nouvelle image et plus de détails sur l’interface utilisateur.
* Mise à jour des versions du [module d’exécution du monitoring synthétique](/docs/synthetics/synthetic-monitoring/using-monitors/manage-monitor-runtimes).
* Ajout d&apos;informations sur la façon d&apos;utiliser [plusieurs sources de log avec le plug-in Fluent Bit](/docs/logs/forward-logs/fluent-bit-plugin-log-forwarding).
* Ajout de la procédure pour [effectuer une requête sur les Live Archives de log via l&apos;API NerdGraph](/docs/logs/get-started/live-archives).
* Mise à jour et correction de divers problèmes mineurs de style et d&apos;image.
* Ajout d’un [exemple de pagination par curseur](/docs/apis/nerdgraph/examples/nerdgraph-api-notifications-channels/#paginate) pour l’intelligence appliquée NerdGraph.
* Correction de la configuration défectueuse de l’ [intégration NVIDIA GPU](/docs/infrastructure/host-integrations/host-integrations-list/nvidia-gpu-integration).
* Ajout d&apos;une section sur la configuration de l&apos;[hôte de téléversement de modélisation](/docs/mobile-monitoring/new-relic-mobile-android/install-configure/android-agent-crash-reporting) pour le monitoring des applications mobiles Android.
* Ajout de détails de configuration pour l’ [intégration de monitoring Temporal](/docs/infrastructure/host-integrations/host-integrations-list/temporal-monitoring-integration) pour Java.
* Ajout de l&apos;autorisation manquante pour [GCP Cloud Functions](/docs/infrastructure/google-cloud-platform-integrations/get-started/integrations-custom-roles).
* Mise à jour du lien de la documentation lié au [signalement de vulnérabilités de sécurité](/docs/security/security-privacy/information-security/security-bulletins/#report).
* Mise à jour de la documentation de sécurité pour supprimer la mention de HackerOne, que nous n’utilisons plus pour notre [processus de divulgation coordonnée](/docs/security/security-privacy/information-security/software-development-lifecycle).
* Ajout d’informations sur les implications légales de l’utilisation des [méthodes de proxy du monitoring de navigateurs](/docs/browser/new-relic-browser/configuration/proxy-agent-requests).
* Clarification du fait que l’attribut [`coreCount`](https://docs.newrelic.com/attribute-dictionary/?event=SystemSample&attribute=coreCount) pour l’événement `SystemSample` sur Windows compte le nombre de Processeurs pour l’instance actuelle du Processeur.
* Mise à jour de la documentation de [configuration du monitoring des performances réseau](/docs/network-performance-monitoring/advanced/advanced-config) pour décrire les modifications liées à l’API Meraki et aux syslogs des périphériques réseau.
* Suppression de la date de fin de vie de l’ [intégration Prometheus OpenMetrics dans Kubernetes](/docs/infrastructure/prometheus-integrations/install-configure-prometheus-agent/migration-guide).
* Dans la navigation de gauche, renommage de l’instrumentation manuelle legacy Serverless en [instrumentation manuelle sans couche](/docs/serverless-function-monitoring/aws-lambda-monitoring/enable-lambda-monitoring/enable-serverless-monitoring-aws-lambda-layerless/).
* Diverses corrections mineures pour plus de clarté et une meilleure cohérence avec notre guide de style.
