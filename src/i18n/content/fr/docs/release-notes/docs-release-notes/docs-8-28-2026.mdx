### Nouveaux documents

* Ajout de [Envoyer vos traces d’IA générative (GenAI) à New Relic avec OpenTelemetry](/docs/ai-monitoring/opentelemetry-ai-monitoring), qui explique comment envoyer des traces d’IA générative (GenAI) OTel, y compris les appels LLM, les appels d’outils et les étapes d’agent, au monitoring de l’IA New Relic sans agent New Relic.

* Ajout du [monitoring de l&apos;IA eBPF](/docs/ebpf/ai-monitoring), qui explique comment l&apos;agent eBPF détecte et monitore automatiquement les workload d&apos;IA générative (GenAI) et de LLM sur les hôtes Linux et les cluster Kubernetes sans modification de code.

* Ajout de [Monitorer automatiquement vos websockets](/docs/browser/new-relic-browser/browser-pro-features/websockets), qui couvre le suivi de l’état de santé des connexions WebSocket, y compris les messages envoyés et reçus, la durée de connexion et les événements de fermeture, à l’aide de l’agent du navigateur.

* Ajout des [Cas d’utilisation du monitoring synthétique](/docs/synthetics/synthetic-monitoring/guides/synthetic-monitoring-use-cases), qui vous aide à choisir le bon type de monitoring, des simples vérifications de ping aux parcours d’API et de navigateur entièrement scriptés.

* Ajout de [Types d’agents](/docs/new-relic-control/agent-control/agent-types), qui couvre les définitions de type d’agent d’Agent Control, leur fonctionnement et les agents pris en charge.

* Ajout de [Démarrer avec Amazon Fire TV](/docs/streaming-video-&-ads/installation/amazon-fire-tv/get-started-with-amazon-fire-tv) et des guides d’installation pour [Shaka Player](/docs/streaming-video-&-ads/installation/amazon-fire-tv/install-shaka-player), [Dash.js](/docs/streaming-video-&-ads/installation/amazon-fire-tv/install-dashjs) et [HTML5](/docs/streaming-video-&-ads/installation/amazon-fire-tv/install-html5), qui expliquent comment monitorer la lecture vidéo sur Amazon Fire TV à l’aide de VegaTracker.

* Ajout de [Regrouper les fonctions Lambda sous une seule entité OTel](/docs/serverless-function-monitoring/aws-lambda-monitoring/opentelemetry/otel-service-name-lambda), qui couvre l’utilisation de `OTEL_SERVICE_NAME` pour consolider plusieurs fonctions Lambda instrumentées par OTel sous une seule entité New Relic.

* Ajout de [Signalement des erreurs JavaScript React Native](/docs/mobile-monitoring/new-relic-monitoring-react-native/react-native-agent-js-error-reporting), [Lister et supprimer les source maps React Native](/docs/mobile-monitoring/new-relic-monitoring-react-native/list-delete-react-native-source-maps) et [Dépanner les source maps React Native](/docs/mobile-monitoring/new-relic-monitoring-react-native/troubleshoot-react-native-source-maps) pour guider la migration vers le type d’événement `MobileJSError` introduit dans l’agent React Native v1.9.0.

* Ajout de la documentation suivante sur le catalogue d’actions d’automatisation de workflow :

  * [Actions New Relic Issue](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/newrelic-issue): créer, mettre à jour et gérer les problèmes New Relic à partir d’un workflow.
  * [Actions New Relic Lens](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/newrelic-lens): exécutez des requêtes et des analyses New Relic Lens à partir d’un workflow.
  * [Invoquer une Azure Function](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-functions-invoke): invoquez une Azure Function à partir d’un workflow.
  * [Exécuter une API Azure DevOps](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-devops-api): exécutez des appels d’API Azure DevOps à partir d’un workflow.
  * [Actions de ticket GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-issue): créer, mettre à jour, obtenir, lister, commenter, verrouiller et déverrouiller des tickets GitHub à partir d’un workflow.

    * Correction du point de terminaison de l’hôte de l’API de source map régional et par défaut pour les téléchargements de source map React Native.

  * [Application mobile pour Android v5.43.6](/docs/release-notes/mobile-apps-release-notes/new-relic-android-release-notes/new-relic-android-5436):

    * Corrections de bugs et améliorations.

  * [Intégration Kubernetes v4.7.0](/docs/release-notes/infrastructure-release-notes/kubernetes-integration-release-notes/kubernetes-integration-4-7-0):

    * Inclus dans les versions de chart `newrelic-infrastructure-4.6.0` et `nri-bundle-8.0.20`.

  * [Agent Node.js v14.3.9](/docs/release-notes/agent-release-notes/nodejs-release-notes/node-agent-14-3-9):

    * Correction de l’instrumentation `@google/adk` pour la v2.0.0.

  * [Agent .NET v10.54.0](/docs/release-notes/agent-release-notes/net-release-notes/net-agent-10-54-0):

    * Ajout d’un cache sans verrou pour les recherches d’agents dans le code injecté par le profileur, réduisant ainsi la surcharge de l’agent pour les applications .NET.
    * Correction de la contamination croisée de transaction dans `HybridHttpContextStorage`.
    * Correction d’une transaction client WCF bloquée lorsqu’un résultat asynchrone se termine avant un échange de rappel.
    * Correction d’une injection incorrecte de commentaire de métadonnées SQL pour `CommandType.StoredProcedure`.

  * [NRDOT Collector v2.4.0](/docs/release-notes/nrdot-release-notes/nrdot-2026-08-25):

  * [Agent média pour Roku v4.2.3](/docs/release-notes/streaming-others-release-notes/streaming-others-agent-26-08-27):

    * Ajout de l’attribut `contentIsLive` aux événements `VideoAction` et `VideoAdAction`, alignant Roku sur le modèle de données vidéo standard inter-agents.
    * Correction des événements `CONTENT_BUFFER_END` retardés jusqu’à la reprise de la lecture après une remise en mémoire tampon à l’état de pause.
    * Correction de `errorCode`, `errorMessage`, et `backtrace` apparaissant sur tous les événements, y compris les heartbeats. Ces attributs n’apparaissent désormais que sur les événements d’erreur.
    * Correction de la suppression silencieuse du logging de débogage MediaTailor SSAI (`nrActivateLogging`) depuis la v4.2.0.

  * [Job Manager v618](/docs/release-notes/synthetics-release-notes/job-manager-release-notes/job-manager-release-618):

    * Correction des vulnérabilités du système d’exploitation CVE-2026-11856 et CVE-2026-8932, et des vulnérabilités de la bibliothèque CVE-2026-54399, CVE-2026-54428, et CVE-2026-64607.

  * [Runtime Node API v1.2.262](/docs/release-notes/synthetics-release-notes/node-api-runtime-release-notes/node-api-runtime-1.2.262):
