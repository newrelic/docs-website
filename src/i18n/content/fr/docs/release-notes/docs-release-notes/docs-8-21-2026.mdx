### Nouveaux documents

* Ajout du [monitoring MySQL via OpenTelemetry](/docs/opentelemetry/database/mysql/introduction) en tant qu’intégration en préversion publique, couvrant la configuration guidée, la configuration hébergée, et Amazon RDS, les configurations multi-Récepteurs, et une référence complète des métriques.
* Ajout du [monitoring PostgreSQL via OpenTelemetry](/docs/opentelemetry/database/postgresql/introduction) en tant qu&apos;intégration en aperçu public, couvrant la configuration guidée, la configuration hébergée et Amazon RDS, les permissions `EXPLAIN` et une référence complète des métriques.
* Ajout des [capacités de site privé](/docs/synthetics/synthetic-monitoring/guides/private-location-capabilities) pour consolider les fonctionnalités de site privé du monitoring synthétique telles que les certificats CA personnalisés, le mTLS et l’automatisation Terraform.
* Ajout des [Limites d&apos;utilisateurs de calcul](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/compute-budgets/compute-user-limits), désormais généralement disponibles, pour définir des budgets de calcul mensuels par utilisateur.
* Ajout de [Parcours utilisateur mobile](/docs/mobile-monitoring/mobile-monitoring-ui/mobile-app-pages/user-journeys) pour montrer la séquence d&apos;événements menant à un plantage, une erreur, ou un ANR.
* Ajout de [Configurer le Récepteur de requêtes SQL](/docs/opentelemetry/database/capabilities/sql-query-receiver) en tant que fonctionnalité en préversion publique pour exécuter des requêtes SQL personnalisées sur des bases de données Oracle, ou SQL Server, et ingérer les résultats sous forme de métriques.

### Changements majeurs

* Mise à jour des [rôles personnalisés des intégrations GCP](/docs/infrastructure/google-cloud-platform-integrations/get-started/integrations-custom-roles) avec des autorisations pour 18 services supplémentaires, y compris AlloyDB, Bigtable, Firestore, et Vertex AI.
* Mise à jour du [monitoring de la base de données Oracle avec NRDOT](/docs/opentelemetry/database/otel-oracledb) avec une prise en charge complète d’Oracle Autonomous Database (ADB), y compris l’installation, l’octroi de privilèges, et la configuration multi-Récepteur.

### Modifications mineures

* Correction de [Signaler les événements personnalisés et les attributs](/docs/data-apis/custom-data/custom-events/report-mobile-monitoring-custom-events-attributes) et de [Définir la taille maximale du pool d’événements](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/set-max-event-pool-size) pour indiquer que le cycle de collecte d’événements mobiles par défaut est de 60 secondes, et non de 600.
* Clarification dans les [Concepts de gestion des utilisateurs](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts) du fait que les rôles personnalisés à l’échelle de l’organisation ne reçoivent pas automatiquement les autorisations pour les nouvelles fonctionnalités à l’échelle de l’organisation.
* Clarification dans [Gérer plusieurs enregistrements d&apos;utilisateur](/docs/accounts/accounts-billing/account-setup/multiple-user-records) du fait que le basculement entre les enregistrements d&apos;utilisateur avec le même e-mail utilise l&apos;option « Autres utilisateurs » dans le menu utilisateur.
* Clarification dans [Variables de modèle de dashboard](/docs/query-your-data/explore-query-data/dashboards/dashboard-template-variables) : le bouton Inclure/exclure se trouve dans la propre liste déroulante de chaque variable, et non dans la barre des variables partagées.
* Clarification de l’ [intégration du monitoring Azure Cost Management](/docs/infrastructure/microsoft-azure-integrations/azure-integrations-list/azure-cost-management-monitoring-integration) indiquant que les données de coût nécessitent de garder l’intégration Azure traditionnelle activée.
* Suppression d’une remarque obsolète dans [Partager des notebooks](/docs/query-your-data/explore-query-data/notebooks/share-notebooks) indiquant que les notebooks ne disposent pas de paramètres d’autorisation granulaires.
* Ajout de la couverture du champ `onCallMembers` au [tutoriel NerdGraph Teams](/docs/apis/nerdgraph/examples/nerdgraph-teams-tutorial).
* Ajout d’étapes à [Dépannage des intégrations GCP](/docs/infrastructure/google-cloud-platform-integrations/troubleshooting/troubleshooting-gcp-integrations) pour demander une augmentation du quota de l’API de monitoring cloud GCP.
* Ajout de conseils pour attribuer un rôle d’astreinte aux membres de l’équipe dans [Gérer les équipes](/docs/service-architecture-intelligence/teams/manage-teams).
* Ajout d’une section sur la configuration des [variables d’environnement de l’agent .NET](/docs/apm/agents/net-agent/other-installation/understanding-net-agent-environment-variables) pour les applications hébergées par IIS via `ApplicationHost.config`.
* Restructuration de [L&apos;installation MSI de Windows échoue avec l&apos;erreur 1603](/docs/infrastructure/infrastructure-troubleshooting/troubleshoot-infrastructure/windows-msi-install-fails-error-1603) pour prioriser les paramètres obligatoires `GENERATE_CONFIG`, et `LICENSE_KEY` manquants comme la cause la plus courante.
* Mise à jour du [programme d’installation MSI Windows](/docs/infrastructure/infrastructure-agent/windows-installation/windows-msi-installer) afin que la commande d’installation silencieuse par défaut inclue les paramètres `GENERATE_CONFIG` et `LICENSE_KEY` requis.
