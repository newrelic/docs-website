<Callout variant="important">
New Relic analyse l&apos;image du gestionnaire de tâches Synthetics à la recherche de vulnérabilités chaque jour et publie une sortie corrigée chaque jeudi. Chaque sortie inclut des correctifs pour les CVE du système d’exploitation et de l&apos;application identifiées au plus tard le mardi à 18:29 UTC de cette semaine-là. Si nous identifions une CVE après cette heure, le correctif est publié dans la sortie du jeudi de la semaine suivante.

Nous publions chaque sortie sur le tag `latest`, de sorte que les sites privés qui utilisent `latest` reçoivent automatiquement les correctifs. Si vous utilisez un tag de version spécifique, mettez à jour manuellement vers la version la plus récente pour obtenir les correctifs actuels.

La sortie du gestionnaire de tâches s’effectue séparément des environnements d’exécution Ping, Node API, et Node browser. Veuillez consulter les notes de sortie de chaque environnement d’exécution pour connaître ses propres correctifs.
</Callout>

### Correctifs de sécurité

**Vulnérabilités JDK/Runtime :**

* Correction de la vulnérabilité Java4Shell (CVE-2026-114938) par la mise à niveau de la distribution OpenJDK intégrée vers Corretto-21.0.13.1.2, éliminant la faille de corruption de mémoire dans le décodeur Base64 AVX-512 x86-64.

**Vulnérabilités du système d&apos;exploitation :**

* Mise à jour de libc-bin vers 2.39-0ubuntu8.12 : CVE-2026-18374, CVE-2026-84243, CVE-2026-8674, CVE-2026-86805, CVE-2026-95818, CVE-2026-97399
* Mise à jour de perl-base vers 5.38.2-3.2ubuntu0.7 : CVE-2026-82560
