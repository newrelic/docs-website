### Débogage

* Correction des délais de clic de 12 - 30 secondes sur les applications Angular et Zone.js. L’extension de navigateur Synthetics est désormais chargée via CDP WebSocket (`Extensions.loadUnpacked`) au lieu de BiDi (`webExtension.install`). Chrome 153+ BiDi a introduit une vérification &quot;Waiting for pending navigations&quot; après chaque clic qui bloquait les réponses sur les applications avec des macrotâches en attente. Le passage à CDP maintient BiDi hors de la session, rétablissant la vérification de navigation classique inférieure à la milliseconde `document.readyState` de ChromeDriver.
