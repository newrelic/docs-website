<Callout variant="important">
New Relic analyse l&apos;image d&apos;exécution du navigateur Node à la recherche de vulnérabilités chaque jour et publie une sortie corrigée chaque jeudi. Chaque sortie inclut des correctifs pour les CVE du système d’exploitation, de l’application, et de Chrome identifiées au plus tard le mardi à 18:29 UTC de cette semaine-là. Si nous identifions une CVE après cette heure, le correctif est publié dans la sortie du jeudi de la semaine suivante.

Nous publions chaque sortie sur le tag `latest`, qui exécute Node.js 22 et la dernière version stable de Chrome. Les sites privés qui utilisent `latest` reçoivent les correctifs automatiquement. Si vous utilisez un tag de version spécifique, mettez à jour manuellement vers la version la plus récente pour obtenir les correctifs actuels.
</Callout>
