### Caractéristiques

* Ajout de la prise en charge de `@opentelemetry/api@1.10.0` ([#4392](https://github.com/newrelic/node-newrelic/pull/4392)) ([504490d](https://github.com/newrelic/node-newrelic/commit/504490dd9540e6d5312441d9feec29b47bfe959a))

  * Pour les clients utilisant directement `@opentelemetry/api-logs`, ils doivent le supprimer et effectuer la mise à jour pour utiliser `@opentelemetry/api` 1.10.0+. Consultez le [changelog de l&apos;API OpenTelemetry](https://github.com/open-telemetry/opentelemetry-js/blob/main/api/CHANGELOG.md#1100) pour plus d&apos;informations.
  * Pour les clients enregistrant une instrumentation tierce pour les bibliothèques de logging, ils doivent mettre à jour vers ce qui suit : `@opentelemetry/instrumentation-pino` vers 0.70.0+, `@opentelemetry/instrumentation-bunyan` vers 0.69.0+, `@opentelemetry/instrumentation-console` vers 0.6.0+, ou `@opentelemetry/instrumentation-winston` vers 0.69.0+
