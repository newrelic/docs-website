## Remarques

#### Caractéristiques

* Ajout de `ai_monitoring.basic_telemetry.enabled` et activation du monitoring de l’IA de base par défaut ([#4330](https://github.com/newrelic/node-newrelic/pull/4330)) ([c126335](https://github.com/newrelic/node-newrelic/commit/c1263354150cd30349d316acc162f5388bc3449a))

  * L&apos;instrumentation LLM est désormais activée par défaut et envoie `Llm*` événements personnalisés, spans, et métriques (sans le contenu des messages), sauf configuration contraire. Pour vous désinscrire, définissez `ai_monitoring.basic_telemetry.enabled` sur `false` dans `newrelic.js`, ou définissez la variable d&apos;environnement `NEW_RELIC_AI_MONITORING_BASIC_TELEMETRY_ENABLED` sur `false`.
  * `ai_monitoring.enabled` et la variable d’environnement `NEW_RELIC_AI_MONITORING_ENABLED` sont obsolètes et seront supprimées dans une future version majeure, mais définir l’une ou l’autre sur false permet également de le désactiver.
