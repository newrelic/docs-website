## Remarques

#### Caractéristiques

* Ajout de l’option de configuration `browser_monitoring.version` ([#4269](https://github.com/newrelic/node-newrelic/pull/4269)) ([b62ca00](https://github.com/newrelic/node-newrelic/commit/b62ca002441bcae50b4fd235eb046cdfa6a55bbe))

  * Lorsque ce paramètre est défini, il épingle la version de l’agent de navigateur à la version sélectionnée lors de l’utilisation de `newrelic.getBrowserTimingHeader`.
  * Si vous spécifiez une version qui n’est plus prise en charge ou invalide, elle ne sera résolue vers aucun agent de navigateur lors de l’appel de `newrelic.getBrowserTimingHeader`.

### Déclaration de soutien :

Nous vous recommandons de mettre à jour vers la dernière version de l&apos;agent dès qu&apos;elle est disponible.
