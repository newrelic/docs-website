## Agent PHP New Relic v12.12.0.41

### Débogage

* Correction de la récupération des noms de base de données et de collection MongoDB pour les versions 1.21.4 et 2.4.1 et ultérieures de la bibliothèque MongoDB. ([#1301](https://github.com/newrelic/newrelic-php-agent/pull/1301))
* Correction d’une condition de concurrence dans la collecte de métriques du daemon qui pourrait faire planter le daemon lorsque plusieurs agents transmettent des données à un seul daemon. ([#1310](https://github.com/newrelic/newrelic-php-agent/pull/1310))
* Transmettez `E_DONT_BAIL` au gestionnaire d’erreurs PHP afin que les destructeurs s’exécutent après une exception non interceptée. ([#1317](https://github.com/newrelic/newrelic-php-agent/pull/1317))
* Conservez une référence au rappel transmis à `newrelic_set_error_group_callback()` pour éviter un plantage ou un nom de groupe d’erreurs incorrect. ([#1329](https://github.com/newrelic/newrelic-php-agent/pull/1329))
* Supprimez l’heure de début de la commande Predis une fois la réponse lue. ([#1315](https://github.com/newrelic/newrelic-php-agent/pull/1315))

### Mises à jour de sécurité

* Mettez à niveau la version de Go utilisée pour compiler le daemon vers la version 1.27.3. ([#1304](https://github.com/newrelic/newrelic-php-agent/pull/1304), [#1320](https://github.com/newrelic/newrelic-php-agent/pull/1320), [#1336](https://github.com/newrelic/newrelic-php-agent/pull/1336))
