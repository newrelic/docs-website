### Avis de fin de vie

* La prise en charge de PHP 5.3 et PHP 5.4 dans l’agent PHP New Relic est obsolète et sera supprimée dans une future version. New Relic vous encourage vivement à mettre à niveau vers une [version prise en charge de PHP](https://www.php.net/supported-versions.php) - 7.3 ou supérieure à la date de cette sortie. Si vous souhaitez continuer à exécuter l’agent PHP New Relic avec PHP 5.3 et 5.4, nous vous recommandons d’utiliser la version 9.15 de l’agent pour une compatibilité maximale. Cependant, veuillez noter que nous ne pouvons offrir qu’une assistance limitée dans ce cas.
* Cette sortie marque le dernier agent PHP New Relic officiellement pris en charge pour CentOS 5.
* Les builds MacOS de l&apos;agent PHP New Relic ne seront plus fournis, et nous n&apos;assurerons plus la compatibilité sur les plateformes MacOS.
* Pour plus d’informations sur ces avis d’EOL, consultez notre [publication sur l’Explorers Hub](https://support.newrelic.com/s/hubtopic/aAX8W0000008bKn/important-upcoming-changes-to-capabilities-across-browser-php-python-mobile).

### Nouvelles fonctionnalités

* [La prise en charge a été ajoutée pour Laminas 3.x.](https://github.com/newrelic/newrelic-php-agent/pull/36)
* [La prise en charge a été ajoutée pour Laravel Lumen 6.x, 7.x, et 8.x](https://github.com/newrelic/newrelic-php-agent/pull/38)
* [Une prise en charge expérimentale a été ajoutée pour exclure des sous-chemins de l’instrumentation Wordpress.](https://github.com/newrelic/newrelic-php-agent/pull/37) Cela réduit la surcharge globale de l’instrumentation Wordpress, car cela diminue le nombre de fichiers instrumentés, mais au prix d’une perte de visibilité sur le code dans les sous-chemins exclus. Cela peut être activé à l’aide du paramètre du fichier ini `newrelic.framework.wordpress.hooks_skip_filename`.
