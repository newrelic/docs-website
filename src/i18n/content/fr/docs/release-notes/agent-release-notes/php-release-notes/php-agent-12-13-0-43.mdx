### Nouvelle fonctionnalité

* Conservez les métadonnées du lien mysqli pendant toute la durée de vie du lien. ([#1325](https://github.com/newrelic/newrelic-php-agent/pull/1325))
* Instrumenter `mysqli_execute_query` et `mysqli::execute_query`. ([#1354](https://github.com/newrelic/newrelic-php-agent/pull/1354))
* Ubuntu 26.04 et Alpine 3.24 vérifiés et pris en charge.

### Mises à jour de sécurité

* Mettre à niveau la version de Go utilisée pour compiler le daemon vers 1.27.4. ([#1382](https://github.com/newrelic/newrelic-php-agent/pull/1382))
* Passer `golang.org/x/net` à 0.62.0 dans le daemon. ([#1305](https://github.com/newrelic/newrelic-php-agent/pull/1305), [#1353](https://github.com/newrelic/newrelic-php-agent/pull/1353))
* Ajouter des données de sortie pour les hacher de tarball, les condensats d’image et les empreintes de clé de signature. Vous pouvez l’utiliser pour vérifier un tarball que vous téléchargez. Voir [Vérifier le fichier tar](/docs/apm/agents/php-agent/installation/php-agent-installation-tar-file/#verify). ([#1374](https://github.com/newrelic/newrelic-php-agent/pull/1374))

* Conserver les options de connexion PDO pour la connexion explain à travers les transactions. ([#1322](https://github.com/newrelic/newrelic-php-agent/pull/1322))
* Lire le SQL d’une instruction PDO à partir de l’instruction. ([#1326](https://github.com/newrelic/newrelic-php-agent/pull/1326))

* Conserver le code SQL des instructions mysqli à travers les transactions. ([#1347](https://github.com/newrelic/newrelic-php-agent/pull/1347))
