## 3.45.0

### Ajouté

* Ajout de la nouvelle intégration nrecho-v5. Notez que les versions majeures précédentes (v3, v4) sont toujours disponibles dans leurs dossiers respectifs
* Ajout de la nouvelle intégration nrgemini qui instrumente le package IA générative (GenAI)
* Ajout de la prise en charge du profilage continu   \* REMARQUE : le profilage continu est une nouvelle fonctionnalité qui n’est pas encore disponible pour une utilisation générale. Le code du composant côté agent est désormais présent dans l’agent, mais pour l’utiliser réellement avant la sortie en disponibilité générale, vous devrez contacter votre représentant commercial New Relic pour rejoindre la préversion de manière anticipée

### Fixé

* Correction d&apos;un bug où les messages LLM étaient incorrectement tronqués

### Sécurité

* Mises à jour de sécurité Dependabot

  * Mise à jour de grpc de 1.82.1 à 1.83.1 dans v3/integrations/nrgrpc et /v3
  * Mise à jour d’amqp091-go de 1.9.0 à 1.13.0 dans v3/integrations/nramqp
  * Mise à jour d’echo/v4 de 4.9.0 à 4.15.3 dans l’intégration v3/integrations/nrecho-v4

### Déclaration de soutien

Nous utilisons la dernière version du langage Go. Au minimum, vous ne devriez pas utiliser de version de Go plus ancienne que celle prise en charge par l&apos;équipe Go elle-même. Consultez la [politique EOL de l&apos;agent Go](https://docs.newrelic.com/docs/apm/agents/go-agent/get-started/go-agent-eol-policy/) pour plus de détails sur les versions prises en charge de l&apos;agent Go et des composants tiers.
