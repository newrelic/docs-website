## 3.44.2

### Ajouté

* `aws.lambda.eventSource.eventType` Prise en charge de l&apos;attribut pour l&apos;intégration `nrlambda`

### Fixé

* `TransactionTrace` Corrections

  * `backtrace` s&apos;affiche correctement dans l&apos;interface utilisateur -&gt; Correction d&apos;un problème où les traces de la pile ne s&apos;affichaient pas correctement dans NR1
  * `timestamp` n’est plus null -&gt; correction d’un problème où l’horodatage s’affichait toujours comme null
  * `exclusive_duration_millis` N&apos;est plus null -&gt; Correction d&apos;un problème où `exclusive_duration_millis` s&apos;affichait toujours comme null

### Sécurité

* Mises à jour de sécurité Dependabot

  * `nrgrpc` Mise à jour de google.golang.org/grpc vers 1.82.1
  * `nrconnect` mise à jour de golang.org/x/net vers 0.55.0

### Déclaration de soutien

Nous utilisons la dernière version du langage Go. Au minimum, utilisez une version de Go que l’équipe Go prend encore en charge. Consultez la [politique de fin de vie de l’agent Go](/docs/apm/agents/go-agent/get-started/go-agent-eol-policy) pour plus de détails sur les versions prises en charge de l’agent Go et des composants tiers.
