## v8.12.0

La version 8.12.0 de l&apos;agent Ruby apporte une nouvelle instrumentation Elasticsearch. La version 8.12.0 de l&apos;agent Ruby augmente également le nombre par défaut d&apos;événements personnalisés enregistrés, annonce la dépréciation de Ruby 2.3, et apporte un nettoyage de code utile.

* **Prise en charge de l’instrumentation Elasticsearch**

  Cette sortie de l’agent Ruby ajoute la prise en charge pour instrument automatiquement le gem [elasticsearch](https://rubygems.org/gems/elasticsearch). Les versions 7.x et 8.x sont prises en charge. [PR#1525](https://github.com/newrelic/newrelic-ruby-agent/pull/1525)

  | Nom de la configuration           | Défaut | Comportement                                                                                                                             |
  | --------------------------------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
  | `instrumentation.elasticsearch`   | auto   | Contrôle l’auto-instrumentation de la bibliothèque elasticsearch au démarrage. Peut être l’un de `auto`, `prepend`, `chain`, `disabled`. |
  | `elasticsearch.capture_queries`   | vrai   | Si `true`, l&apos;agent capture la requête Elasticsearch dans la trace de transaction.                                                   |
  | `elasticsearch.obfuscate_queries` | vrai   | Si `true`, l&apos;agent obscurcit la requête Elasticsearch dans la trace de transaction.                                                 |

* **Augmentation de la limite des événements personnalisés**

  Cette version de l&apos;agent Ruby augmente la limite par défaut des événements personnalisés de 1000 événements par minute à 3000 événements par minute. Si vos événements personnalisés étaient limités, ce changement permettra d&apos;envoyer davantage d&apos;événements personnalisés à New Relic. Il existe également une nouvelle limite maximale configurable de 100 000 événements par minute. Pour modifier les limites, consultez la documentation de [max\_samples\_stored](https://docs.newrelic.com/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration/#custom_insights_events-max_samples_stored). Pour en savoir plus sur ce changement et comment déterminer si des événements personnalisés sont rejetés, consultez notre [publication](https://support.newrelic.com/s/hubtopic/aAX8W0000008dby/send-more-custom-events-with-the-latest-apm-agents) sur l&apos;Explorers Hub. [PR#1541](https://github.com/newrelic/newrelic-ruby-agent/pull/1541)

* **Déprécier la prise en charge de Ruby 2.3**

  Ruby 2.3 a atteint sa fin de vie le 31 mars 2019. L’agent Ruby a déprécié la prise en charge de Ruby 2.3 et apportera des changements majeurs pour cette version lors de sa prochaine sortie majeure, la v9.0.0 (date de sortie non encore planifiée). Toutes les versions 8.x.x de l’agent resteront compatibles avec Ruby 2.3.

* **Nettoyage : supprimez le code orphelin**

  Dans l’agent comme dans les tests unitaires, des changements ont eu lieu au fil des ans, rendant certaines parties du code inaccessibles. Ce code orphelin peut compliquer la maintenance du code et le refactoring, c’est pourquoi le nettoyer peut être très utile. Le membre de la communauté [@ohbarye](https://github.com/ohbarye) a soumis deux PR de nettoyage distinctes pour cette sortie ; une pour l’agent et une pour les tests. [PR#1537](https://github.com/newrelic/newrelic-ruby-agent/pull/1537) [PR#1548](https://github.com/newrelic/newrelic-ruby-agent/pull/1548)

  Merci à [@ohbarye](https://github.com/ohbarye) d&apos;avoir contribué à ce nettoyage utile !

## Déclaration de soutien

New Relic recommande de mettre à jour l’agent Ruby régulièrement et au minimum tous les 3 mois. À partir de cette version, la plus ancienne version prise en charge est [6.7.0.359](https://docs.newrelic.com/docs/release-notes/agent-release-notes/ruby-release-notes/ruby-agent-670359).
