## v10.7.1

* **Correction de bug : résolution de ArgumentError sur les opérations à clés multiples avec Dalli 5.1.0**

  Ce correctif met à jour l’instrumentation de Dalli pour accepter et transférer les arguments d’options de requête facultatifs dans les opérations multi et pipeline. Nos remerciements vont à [@dbackeus](https://github.com/dbackeus) pour avoir apporté un correctif ! [PR#3642](https://github.com/newrelic/newrelic-ruby-agent/pull/3642)

* **Correction de bug : les requests Async::HTTP ne lèvent plus `NoMethodError` lorsqu&apos;un segment ne parvient pas à démarrer**

  Si l&apos;agent rencontrait une erreur interne lors de la création du segment pour une requête `Async::HTTP`, l&apos;instrumentation continuait à utiliser ce segment manquant et pouvait lever une `NoMethodError`. C&apos;est désormais corrigé, merci à [@ydah](https://github.com/ydah). [PR#3640](https://github.com/newrelic/newrelic-ruby-agent/pull/3640)
