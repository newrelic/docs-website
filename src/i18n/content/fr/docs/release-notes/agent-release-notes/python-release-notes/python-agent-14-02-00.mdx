## Remarques

Cette sortie de l’agent Python ajoute l’instrumentation pour le framework Microsoft Agent et CrewAI, améliore l’instrumentation des indicateurs de fonctionnalité LaunchDarkly et la prise en charge du transfert de spans, et corrige plusieurs plantages.

Installez l&apos;agent en utilisant `easy_install/pip/distribute` via l&apos; [index des packagesPython ](https://pypi.python.org/pypi/newrelic), en utilisant `conda` via l&apos; [index des packages Conda-Forge](https://anaconda.org/conda-forge/newrelic), ou téléchargez-le directement depuis le [site de téléchargement de New Relic](https://download.newrelic.com/python_agent/release).

## Nouvelles fonctionnalités

* Nouvelle instrumentation pour le [framework Microsoft Agent](https://pypi.org/project/agent-framework/)

  * L’instrumentation a été ajoutée pour les outils et les agents dans le package `agent-framework`.
  * Les configurations multi-agents ne sont pas encore instrumentées.

* Nouvelle instrumentation pour [CrewAI](https://pypi.org/project/crewai/)

  * L&apos;instrumentation a été ajoutée pour les agents, les équipes, et les outils dans le package `crewai`.

## Fonctionnalités améliorées

* Intégration améliorée des flags de fonctionnalité [LaunchDarkly](https://pypi.org/project/launchdarkly-server-sdk/).

  <Callout title="Aperçu">
  Nous travaillons toujours sur cette fonctionnalité, mais nous aimerions que vous l&apos;essayiez !

  Cette fonctionnalité est actuellement fournie dans le cadre d&apos;un programme d&apos;aperçu conformément à nos [politiques de pré-sortie](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy).
  </Callout>

  * Pour participer à notre intégration en préversion publique avec LaunchDarkly, activez les paramètres `launch_darkly_integration.enabled`, et `opentelemetry.enabled` dans votre fichier de configuration.

  * Instrumentation des indicateurs de fonctionnalité améliorée dans [ldclient](https://pypi.org/project/launchdarkly-server-sdk/).

    * Le nouvel attribut `feature_flag.url.full` a été ajouté pour permettre les liens profonds dans l’interface utilisateur.
    * Modification de la casse de la clé `inExperiment` pour correspondre à LaunchDarkly.
    * Ajout de la prise en charge des valeurs fausses dans les attributs d&apos;indicateur de fonctionnalité.
    * Réduction de tous les avertissements d’intégration LaunchDarkly pour qu’ils ne s’affichent qu’une seule fois.

  * Le transfert de spans a été amélioré pour [ldobserve](https://pypi.org/project/launchdarkly-observability/).

    * Ajout des attributs de span `nr.entity.guid` et `nr.entity.url` pour permettre les liens profonds dans l’interface utilisateur.
    * Correction de la parenté des spans pour permettre une imbrication correcte dans l’interface utilisateur.

## Débogage

* Correction d’un plantage dans `TimeTrace` lorsque l’attribut était `None` dans `_add_span_event_event`.
* Correction d&apos;un plantage dans le wrapper `Config` de LaunchDarkly lors du retour aux valeurs par défaut.
