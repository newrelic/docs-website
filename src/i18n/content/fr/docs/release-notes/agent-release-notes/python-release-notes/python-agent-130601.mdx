## Remarques

Cette sortie de l&apos;agent Python corrige des problèmes liés aux en-têtes signés dans botocore (SigV4).

Installez l&apos;agent en utilisant `easy_install/pip/distribute` via l&apos; [index des packagesPython ](https://pypi.python.org/pypi/newrelic), en utilisant `conda` via l&apos; [index des packages Conda-Forge](https://anaconda.org/conda-forge/newrelic), ou téléchargez-le directement depuis le [site de téléchargement de New Relic](https://download.newrelic.com/python_agent/release).

## Bugs

* Corriger les problèmes avec les en-têtes signés dans [botocore](https://pypi.org/project/botocore/) (SigV4)

  * La modification précédente des en-têtes de tracing distribué de botocore a été annulée pour éviter l&apos;envoi d&apos;en-têtes en double.
  * Auparavant, tous les en-têtes de tracing distribué qui étaient générés par d&apos;autres bibliothèques de tracing pouvaient causer des problèmes avec l&apos;instrumentation dans botocore en raison de la signature des en-têtes. Cela a été corrigé en désactivant la signature pour ces en-têtes dans botocore.
