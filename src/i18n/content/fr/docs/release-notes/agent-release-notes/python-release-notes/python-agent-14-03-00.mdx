## Remarques

Cette sortie de l’agent Python active le monitoring de l’IA par défaut avec le nouveau paramètre `ai_monitoring.basic_telemetry.enabled`, déprécie le paramètre `ai_monitoring.enabled`, et corrige un plantage dans l’instrumentation de l’outil LangChain.

Installez l&apos;agent en utilisant `easy_install/pip/distribute` via l&apos; [index des packagesPython ](https://pypi.python.org/pypi/newrelic), en utilisant `conda` via l&apos; [index des packages Conda-Forge](https://anaconda.org/conda-forge/newrelic), ou téléchargez-le directement depuis le [site de téléchargement de New Relic](https://download.newrelic.com/python_agent/release).

## Changements

* Le monitoring de l’IA est désormais activé par défaut

  * L&apos;instrumentation LLM est désormais activée par défaut, et l&apos;agent envoie `Llm*` événements personnalisés, spans, et métriques (sans contenu de message) sauf configuration contraire.
  * Pour enregistrer le contenu du prompt et de la réponse, définissez [`ai_monitoring.record_content.enabled`](/docs/apm/agents/python-agent/configuration/python-agent-configuration/#ai-monitoring-record-content) sur `true`.
  * Pour vous désinscrire, définissez [`ai_monitoring.basic_telemetry.enabled`](/docs/apm/agents/python-agent/configuration/python-agent-configuration/#ai-monitoring-basic-telemetry-enabled) sur `false` dans newrelic.ini, ou définissez la variable d’environnement `NEW_RELIC_AI_MONITORING_BASIC_TELEMETRY_ENABLED=false`.
  * Le paramètre [`ai_monitoring.enabled`](/docs/apm/agents/python-agent/configuration/python-agent-configuration/#ai-monitoring-enabled) et la variable d’environnement `NEW_RELIC_AI_MONITORING_ENABLED` sont dépréciés, mais définir l’un ou l’autre sur `false` désactive également AI Monitoring.

## Débogage

* Correction d’un plantage dans l’instrumentation de [LangChain](https://pypi.org/project/langchain/) `StructuredTool.invoke` et `StructuredTool.ainvoke` lorsque `config` ou son `metadata` était `None`.
