## Remarques

Cette sortie de l’agent Python ajoute l’instrumentation pour les réponses OpenAI, et la nouvelle commande `hsetex` dans Valkey.

Installez l&apos;agent en utilisant `easy_install/pip/distribute` via l&apos; [index des packagesPython ](https://pypi.python.org/pypi/newrelic), en utilisant `conda` via l&apos; [index des packages Conda-Forge](https://anaconda.org/conda-forge/newrelic), ou téléchargez-le directement depuis le [site de téléchargement de New Relic](https://download.newrelic.com/python_agent/release).

## Nouvelles fonctionnalités

* Nouvelle instrumentation pour les [réponses OpenAI](https://pypi.org/project/openai/)

  * L’instrumentation a été ajoutée pour les méthodes `client.responses` du SDK `openai`, qui ciblent l’ [API Responses](https://developers.openai.com/api/reference/resources/responses).
  * Il s’agit d’un ajout à l’instrumentation existante des anciennes méthodes `client.chat.completions` et de l’ [API Chat Completions](https://developers.openai.com/api/reference/resources/chat), qui sont toujours prises en charge.

## Fonctionnalités améliorées

* Ajout de la prise en charge de la nouvelle commande [Valkey](https://pypi.org/project/valkey/) :

  * La commande `hsetex` est désormais prise en charge.
