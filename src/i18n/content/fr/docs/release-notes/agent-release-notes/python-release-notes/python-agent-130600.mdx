## Remarques

Cette sortie de l&apos;agent Python ajoute la prise en charge d&apos;OpenSearch, de Microsoft Azure SQL, de nouvelles méthodes Kinesis, et d&apos;un nouveau paramètre `browser_monitoring.version`. De plus, des améliorations ont été apportées à l&apos;instrumentation d&apos;Anthropic, de MCP, et de Google ADK. Les problèmes liés aux en-têtes signés dans botocore (SigV4), et à l&apos;analyse des outils Gemini ont également été corrigés pour cette sortie.

Installez l&apos;agent en utilisant `easy_install/pip/distribute` via l&apos; [index des packagesPython ](https://pypi.python.org/pypi/newrelic), en utilisant `conda` via l&apos; [index des packages Conda-Forge](https://anaconda.org/conda-forge/newrelic), ou téléchargez-le directement depuis le [site de téléchargement de New Relic](https://download.newrelic.com/python_agent/release).

## Nouvelle fonctionnalité

* Nouvelle instrumentation pour [opensearch-py](https://pypi.org/project/opensearch-py/)

  * L&apos;instrumentation a été ajoutée pour le connecteur de base de données officiel d&apos;OpenSearch.

* Nouvelle instrumentation pour [mssql-python](https://pypi.org/project/mssql-python/)

  * L’instrumentation a été ajoutée pour Microsoft Azure SQL.

* Nouvelle instrumentation pour les nouvelles méthodes [Kinesis](https://pypi.org/project/kinesis-python/)

  * Les méthodes suivantes sont désormais prises en charge dans Kinesis :

    * `create_channel`
    * `delete_channel`
    * `describe_channel`
    * `list_channels`
    * `update_channel`

* Nouveau paramètre pour `browser_monitoring.version`

  * Le nouveau paramètre `browser_monitoring.version` permet aux utilisateurs de spécifier des versions spécifiques de notre [agent de monitoring de navigateurs](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/introduction-browser-monitoring/) à injecter.
  * Consultez la liste des [versions de l’agent Browser prises en charge](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/) pour faire votre choix.

## Fonctionnalités améliorées

* Prise en charge améliorée d’ [anthropic](https://pypi.org/project/anthropic/).

  * Amélioration de l’analyse des paramètres de requête pour le SDK Anthropic sur les versions 1.0.0 et supérieures.
  * Nouvelle analyse des réponses via `Messages.with_raw_response.create` permettant une compatibilité améliorée avec LangChain.

* Prise en charge de [mcp](https://pypi.org/project/mcp/) v2.0.0 et versions ultérieures.

  * L&apos;instrumentation a été mise à jour à la suite du refactoring majeur effectué dans `mcp` v2.0.0 et devrait à nouveau fonctionner comme prévu.

* Prise en charge de [Google ADK](https://pypi.org/project/google-adk/) v2.9.0 et versions ultérieures.

  * L’instrumentation a été mise à jour pour Google ADK sur les versions 2.9.0 et ultérieures.

## Bugs

* Corriger les problèmes avec les en-têtes signés dans [botocore](https://pypi.org/project/botocore/) (SigV4)

  * Auparavant, tous les en-têtes de tracing distribué qui étaient générés par d&apos;autres bibliothèques de tracing pouvaient causer des problèmes avec l&apos;instrumentation dans botocore en raison de la signature des en-têtes. Cela a été corrigé, et les en-têtes de tracing distribué sont désormais modifiés avant la signature.

* Correction de l’analyse des outils [Gemini](https://pypi.org/project/google-genai/)

  * Auparavant, certaines instances d&apos;outils créés avec Gemini ne parvenaient pas à être analysées, et échouaient silencieusement, n&apos;entraînant aucune réponse pour cette requête spécifique. Ce problème a été résolu.
