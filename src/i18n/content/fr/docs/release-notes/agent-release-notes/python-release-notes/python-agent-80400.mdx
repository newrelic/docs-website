## Remarques

Cette sortie de l’agent Python augmente la limite des événements personnalisés et inclut un débogage.

Installez l&apos;agent à l&apos;aide de `easy_install/pip/distribute` via l&apos; [index du packagePython ](https://pypi.python.org/pypi/newrelic)ou téléchargez-le directement depuis le [site de téléchargement de New Relic](https://download.newrelic.com/python_agent/release).

## Changements

* **Augmentation de la limite d&apos;événements personnalisés**

  Cette version de l&apos;agent augmente la limite par défaut des événements personnalisés de 1200 événements par minute à 3600 événements par minute. Dans le cas où les événements personnalisés étaient limités, ce changement permettra d&apos;envoyer davantage d&apos;événements personnalisés à New Relic. Il existe également une nouvelle limite maximale configurable de 100 000 événements par minute. Pour modifier les limites, consultez la [documentation d&apos;event\_harvest](https://docs.newrelic.com/docs/apm/agents/python-agent/configuration/python-agent-configuration/#harvest-limits-custom-event-data). Pour en savoir plus sur ce changement et comment déterminer si des événements personnalisés sont rejetés, consultez notre [publication sur l&apos;Explorers Hub](https://support.newrelic.com/s/hubtopic/aAX8W0000008dby/send-more-custom-events-with-the-latest-apm-agents).

## Débogage

* **Corrige l’erreur d’attribut NewRelicContextFormatter**

  Un bug a été introduit dans la v8.3.0 qui provoquait une AttributeError lors de l’utilisation du NewRelicContextFormatter. Cela a été corrigé dans cette version de sortie.
