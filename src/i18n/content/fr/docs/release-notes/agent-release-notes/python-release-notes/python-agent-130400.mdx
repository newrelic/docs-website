## Remarques

Cette sortie de l&apos;agent Python ajoute la prise en charge des commandes Redis introduites dans Redis v8.10.0 et redis-py v8.1.0. Cette sortie résout également le problème des événements LlmChatCompletion manquants dans LangChain lors de l&apos;utilisation des outils MCP.

Installez l&apos;agent en utilisant `easy_install/pip/distribute` via l&apos; [index des packagesPython ](https://pypi.python.org/pypi/newrelic), en utilisant `conda` via l&apos; [index des packages Conda-Forge](https://anaconda.org/conda-forge/newrelic), ou téléchargez-le directement depuis le [site de téléchargement de New Relic](https://download.newrelic.com/python_agent/release).

## Nouvelles fonctionnalités

* Ajout des commandes Redis introduites dans Redis v8.10.0 et redis-py v8.1.0

  * L’agent Python prend désormais en charge les commandes récemment ajoutées suivantes dans [Redis](https://pypi.org/project/redis/):

    * `himport_discard_all`
    * `himport_discard`
    * `himport_prepare`
    * `lmovem`
    * `nrange`
    * `nrevrange`
    * `querylabels`
    * `read`
    * `sdiffcard`
    * `sunioncard`
    * `aliaslist`

## Bugs

* Correction des événements LlmChatCompletion manquants dans Gemini lors de l&apos;utilisation des outils MCP

  * Auparavant, les événements `LlmChatCompletionMessages` et `LlmChatCompletionSummary` manquaient dans [Gemini](https://pypi.org/project/google-genai/) lors de l&apos;utilisation d&apos;outils dans un agent [LangChain](https://pypi.org/project/langchain/), si le format de réponse n&apos;était pas le JSON par défaut. Ce problème a été résolu.

* Passage à l’ID de cache de trace dans LangChain et Agent framework

  * À des fins de propagation du contexte, échangez l&apos;instrumentation de [LangChain](https://pypi.org/project/langchain/) et d&apos;[Agent framework](https://pypi.org/project/agent-framework/) pour stocker uniquement l&apos;ID du cache de trace plutôt que la trace complète dans un attribut de référence. Cela permet d&apos;éviter que ces objets ne soient sérialisés de manière inattendue en cas de fuites. L&apos;ID est un objet beaucoup plus petit, tandis que la trace peut contenir des Mo de données.
