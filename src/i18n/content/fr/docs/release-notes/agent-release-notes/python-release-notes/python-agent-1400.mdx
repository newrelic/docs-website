## Remarques

Cette sortie de l’agent Python ajoute l’utilisation pour Azure App Services, l’instrumentation pour Azure Service Bus, la prise en charge d’une nouvelle méthode Kinesis, et la prise en charge de Google ADK pour la v2.10.0, et les versions ultérieures. Cette sortie corrige également un problème dans httplib où l’en-tête des traces distribuées était dupliqué, ainsi que le fichier d’installation `setup.py`.

Installez l&apos;agent en utilisant `easy_install/pip/distribute` via l&apos; [index des packagesPython ](https://pypi.python.org/pypi/newrelic), en utilisant `conda` via l&apos; [index des packages Conda-Forge](https://anaconda.org/conda-forge/newrelic), ou téléchargez-le directement depuis le [site de téléchargement de New Relic](https://download.newrelic.com/python_agent/release).

## Fonctionnalités supprimées

* Suppression de la prise en charge de Python 3.9

  * Python 3.9 reached End-of-Life on October 31, 2025 and is no longer supported by the agent. Please consider upgrading your application to a supported version of Python in order to continue to receive updates to the Python Agent.

## Nouvelle fonctionnalité

* Utilisation pour Azure App Service

  * L’utilisation pour Azure App Service a été ajoutée pour permettre la modélisation des relations entre entités.
  * Cela ajoute également un nouveau paramètre, `utilization.detect_azureappservice`

* Nouvelle instrumentation pour [Azure Service Bus](https://pypi.org/project/azure-servicebus/)

  * L’instrumentation a été ajoutée pour Microsoft Azure Service Bus.

* Nouvelle instrumentation pour la nouvelle méthode [Kinesis](https://pypi.org/project/kinesis-python/)

  * La méthode `update_stream_record_distribution_strategy` est désormais prise en charge dans Kinesis.

## Mises à jour de sécurité

* Le package interne [urllib3](https://pypi.org/project/urllib3/) a été mis à jour vers `2.8.0` pour résoudre toutes les CVE actuelles dans `urllib3`.

  * Cela résout toutes les CVE connues dans l’agent à ce jour.

## Fonctionnalités améliorées

* Prise en charge de [Google ADK](https://pypi.org/project/google-adk/) v2.10.0, et versions ultérieures.

  * L’instrumentation a été mise à jour pour Google ADK sur les versions 2.10.0 et supérieures.

## Bugs

* En-têtes de tracing distribué dupliqués dans [httplib](https://github.com/python/cpython/blob/main/Lib/http/client.py)

  * Correction des problèmes où l’instrumentation `httplib` pouvait produire des en-têtes en double pour `traceparent`, entraînant une valeur mal formée.

* `setup.py` le fichier d’installation fonctionne désormais pour toutes les versions de Python prises en charge

  * Si un utilisateur souhaitait utiliser le fichier `setup.py` directement pour installer l’agent Python sur Python 3.12, et versions ultérieures, il rencontrerait un `ImportError`. Cela est dû au fait que `distutils` est obsolète depuis Python 3.10, et a été entièrement retiré de la bibliothèque standard dans Python 3.12.
