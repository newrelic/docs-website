### Avis

* L&apos;instrumentation LLM est désormais activée par défaut et envoie `Llm*` événements personnalisés, spans et métriques (sans le contenu des messages) sauf configuration contraire. Pour vous désinscrire, ajoutez `<aiMonitoring><basicTelemetry enabled="false" /></aiMonitoring>` à `newrelic.config`, ou définissez la variable d&apos;environnement `NEW_RELIC_AI_MONITORING_BASIC_TELEMETRY_ENABLED` sur `false`. L&apos;attribut `enabled` sur `<aiMonitoring>` et la variable d&apos;environnement `NEW_RELIC_AI_MONITORING_ENABLED` sont obsolètes et seront supprimés dans une future sortie majeure, mais définir l&apos;un ou l&apos;autre sur `false` permet également de vous désinscrire. ([0b65f33](https://github.com/newrelic/newrelic-dotnet-agent/commit/0b65f338448a6a6213a1db59c4a55844cb4c63af))
* À partir de cette sortie, chaque fichier publié sur download.newrelic.com possède une attestation de provenance de build, que vous pouvez vérifier avec `gh attestation verify <file> --repo newrelic/newrelic-dotnet-agent`. Les hacher SHA-256 des fichiers de toutes les versions sur download.newrelic.com, y compris les précédentes, sont publiés dans `release-data/download-site-hashes.json` dans le référentiel de l&apos;agent. ([99335b1](https://github.com/newrelic/newrelic-dotnet-agent/commit/99335b1f2500ead5e0662b0f6646e86bc68caaba))
* À partir de cette sortie, les binaires New Relic à l&apos;intérieur de chaque package (MSI, ZIP, NuGet, deb, rpm, et tar.gz) sont signés Authenticode, et les signatures incluent un horodatage, y compris les signatures MSI. L&apos;horodatage garde les signatures valides après l&apos;expiration du certificat de signature. ([99335b1](https://github.com/newrelic/newrelic-dotnet-agent/commit/99335b1f2500ead5e0662b0f6646e86bc68caaba))

### Mise à jour de votre agent

* Suivez les procédures standard pour [mettre à jour l’agent .NET](/docs/agents/net-agent/installation-configuration/update-net-agent).
* Si vous utilisez un agent particulièrement ancien, consultez la liste des modifications majeures et des procédures de [mise à jour des agents .NET legacy](/docs/apm/agents/net-agent/installation/update-net-agent/#updating_older_net).

Nous vous recommandons de mettre à jour vers la dernière version de l&apos;agent dès qu&apos;elle est disponible. Si vous ne pouvez pas effectuer la mise à niveau vers la dernière version, mettez à jour vos agents vers une version datant de moins de 90 jours. En savoir plus sur [la façon de tenir votre agent informé](/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent). Consultez le [document de politique EOL](/docs/apm/agents/net-agent/getting-started/net-agent-eol-policy) de l&apos;agent New Relic .NET pour obtenir des informations sur la sortie de l&apos;agent et les dates de support.
