### Nouvelle fonctionnalité

* La modification des fichiers XML d’instrumentation personnalisée peut désormais être effectuée sans avoir à redémarrer l’application monitorée. Les mises à jour de l’instrumentation seront appliquées « dynamiquement » à l’exécution. Cette fonctionnalité nécessitait des fonctions fournies par de nouvelles API introduites dans le framework .NET 4.5 et versions ultérieures, que cette sortie traite également (voir la section « Support du framework » ci-dessous).

### Corrections

* Bulletin de sécurité [NR18-04](https://docs.newrelic.com/docs/accounts-partnerships/welcome-new-relic/security-bulletins/security-bulletin-nr18-04): corrige le problème où les messages d’erreur n&apos;étaient pas entièrement filtrés des traces d&apos;erreur et des événements d&apos;erreur lorsque le mode Haute sécurité était activé.
* Correction d&apos;un problème avec le monitoring de navigateurs automatique qui pouvait provoquer une exception de dépassement de stack.
* Pour l&apos;instrumentation personnalisée, le paramètre metricName sera pris en compte sans qu&apos;il soit nécessaire de définir transactionNamingPriority.
* Le programme d’installation scriptable s’installera, et se désinstallera désormais avec succès dans les scénarios où il y a un espace dans le chemin d’accès aux fichiers d’installation.

### Prise en charge des frameworks

* Cette sortie de l’agent supprime la prise en charge des versions du framework .NET antérieures à 4,5. Consultez notre [publication de la communauté](https://support.newrelic.com/s/hubtopic/aAX8W0000008ZIo/net-agent-security-enhancements-and-legacy-framework-deprecation) à ce sujet de novembre de l’année dernière, pour plus de détails.
* Il ne s&apos;agit pas d&apos;une fin de vie pour les agents 6.x (qui prennent en charge les anciens frameworks .NET), qui continueront à fonctionner et à transmettre des données à New Relic.

### Mise à niveau

* Suivez les procédures standard pour [mettre à jour l’agent .NET](/docs/agents/net-agent/installation-configuration/update-net-agent).
* Si vous effectuez une mise à niveau à partir d’un agent particulièrement ancien, consultez la liste des changements majeurs et des procédures pour [mettre à niveau les agents .NET legacy](/docs/agents/net-agent/troubleshooting/upgrade-legacy-net-agents).
