### Nouvelles fonctionnalités et améliorations :

* Le [profilage en temps réel pour Java à l’aide des métriques JFR](/docs/agents/java-agent/features/real-time-profiling-java-using-jfr-metrics/) est désormais entièrement intégré à l’agent Java. Consultez le [README de JFR core](https://github.com/newrelic/newrelic-jfr-core/blob/main/README.md) pour plus de détails.

Cette fonctionnalité nécessite une version prise en charge de Java 8 (spécifiquement la version `8u262` ou supérieure), ou Java 11 ou supérieure, et est actuellement désactivée par défaut. Pour l&apos;activer, définissez ce qui suit dans votre fichier yaml (indenté de 2 espaces sous la section common).

```
jfr:
  enabled: true
```

**Avis :** si vous utilisiez précédemment le [jar jfr-daemon](https://github.com/newrelic/newrelic-jfr-core) comme extension d’agent, ou processus autonome, vous devez supprimer cette option pour éviter les conflits potentiels avec le service JFR qui est désormais intégré à l’agent.

* Non compatible avec Java 7. Afin de continuer à innover et de fournir efficacement de nouvelles fonctionnalités à nos clients qui s’exécutent sur la JVM, cette version de l’agent et les versions futures ne sont pas compatibles avec Java 7. Si vous exécutez Java 7, vous pouvez continuer à utiliser l’agent Java 6.5.0 ou une version antérieure. Pour plus de détails, consultez ce sujet sur l’ [Explorers Hub](https://support.newrelic.com/s/hubtopic/aAX8W0000008bni/important-upcoming-changes-to-capabilities-across-synthetics-apm-java-php).
* Ajoute la prise en charge d’akka http avec Scala 2.13. [#271](https://github.com/newrelic/newrelic-java-agent/pull/271)
* Annotation de classe pour la trace des méthodes lambda. [#274](https://github.com/newrelic/newrelic-java-agent/pull/274)
* Annotation de classe pour la trace des méthodes par type de retour. [#275](https://github.com/newrelic/newrelic-java-agent/pull/275)

### Corrections :

* Corrige un problème qui pouvait entraîner l’application simultanée de plusieurs versions de l’instrumentation `akka-http-core`. [#208](https://github.com/newrelic/newrelic-java-agent/pull/208)
* L’agent va désormais enregistrer les événements rejetés à `FINE` au lieu de `WARN` pour réduire la verbosité. [#296](https://github.com/newrelic/newrelic-java-agent/pull/296)
* Corrige les commentaires Javadoc qui indiquaient de manière incorrecte que, lors de l’appel de l’API `noticeError` à plusieurs reprises, la première erreur serait signalée alors qu’en fait c’est la dernière erreur qui est signalée. [#313](https://github.com/newrelic/newrelic-java-agent/pull/313)

### Déclaration de soutien :

* New Relic recommande de mettre à jour l&apos;agent régulièrement pour vous assurer de bénéficier des dernières fonctionnalités et améliorations de performances.
