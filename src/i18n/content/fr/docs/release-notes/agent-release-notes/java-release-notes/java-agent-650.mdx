### Nouvelles fonctionnalités et améliorations :

* L’agent n’intègre plus de certificats SSL et l’option `use_private_ssl` qui configurait l’agent pour utiliser les certificats précédemment intégrés a été supprimée. Par défaut, l’agent utilisera le truststore SSL fourni par la JVM à moins qu’il ne soit explicitement configuré pour utiliser un truststore différent avec l’option ca\_bundle\_path. Consultez [Configurer vos certificats SSL](https://docs.newrelic.com/docs/agents/java-agent/configuration/configuring-your-ssl-certificates/) pour plus de détails.

### Corrections :

* Corrige un problème pouvant entraîner un nommage incorrect de la transaction lors de l’utilisation de sous-ressources JAX-RS.
* Améliorations et correctifs de l’instrumentation de Reactor Netty.

### Avis de dépréciation

* Dépréciation de la compatibilité Java 7

Afin de continuer à innover et de fournir efficacement de nouvelles fonctionnalités à nos clients qui utilisent la JVM, la prise en charge de Java 7 a été dépréciée et ce sera la dernière version de l&apos;agent compatible avec celle-ci.

Si vous exécutez Java 7, vous pouvez continuer à utiliser l’agent Java 6.5.0 ou inférieur.

Pour plus d’informations, consultez la [publication sur l’Explorers Hub](https://support.newrelic.com/s/hubtopic/aAX8W0000008bni/important-upcoming-changes-to-capabilities-across-synthetics-apm-java-php).

### Déclaration de soutien :

* New Relic vous recommande de mettre à niveau l&apos;agent régulièrement pour vous assurer de bénéficier des dernières fonctionnalités et avantages en termes de performances. De plus, les anciennes sorties ne seront plus prises en charge lorsqu&apos;elles atteindront leur [fin de vie](https://docs.newrelic.com/docs/using-new-relic/cross-product-functions/install-configure/notification-changes-new-relic-saas-features-distributed-software/).
