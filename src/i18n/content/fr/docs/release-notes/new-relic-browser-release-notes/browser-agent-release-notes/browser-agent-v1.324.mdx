## v1.324.1

**[Consultez cette sortie sur GitHub →](https://github.com/newrelic/newrelic-browser-agent/releases/tag/v1.324.1)** pour le changelog technique complet et les informations sur la taille du build.

### Débogage

#### Corriger les flags hasMeta/hasSnapshot sur les collectes de Session Replay

Correction d’un problème où les collectes de Session Replay pouvaient indiquer à tort `hasMeta` et `hasSnapshot` comme `false` dans les métadonnées de leur charge, même si les données collectées comprenaient des nœuds d’instantané valides, ce qui était particulièrement visible peu après le passage d’une session d’un enregistrement sur erreur uniquement à un enregistrement complet, ou à chaque redémarrage de l’enregistreur. Ces métadonnées étaient utilisées en aval pour déterminer si un fragment de replay donné était autonome (c’est-à-dire s’il pouvait bootstrap un replay par lui-même), de sorte qu’un `false` incorrect pouvait entraîner un traitement incorrect des données de replay valides.

### Correctifs de sécurité

#### Mettre à jour fflate vers 0.8.3

Correction de la CVE-2026-45820 : unzipSync pouvait entrer dans une boucle infinie lors de l’analyse d’archives ZIP64 mal formées
