## v1.323.0

**[Consultez cette sortie sur GitHub →](https://github.com/newrelic/newrelic-browser-agent/releases/tag/v1.323.0)** pour le changelog technique complet et les informations sur la taille de la compilation.

### Caractéristiques

#### Collecter SR lors du passage du mode ERROR au mode FULL

Mettez à jour l&apos;agent pour gérer les Session Replay de la même manière que les traces de session, et déclenchez une collecte de replay lorsque SR passe du mode `error` au mode `full`.

#### Ajouter des métriques d&apos;adoption interne pour les charges AJAX

Ajoute une métrique interne mesurant l&apos;adoption du suivi de la charge AJAX à des fins d&apos;assurance qualité et d&apos;amélioration.

### Débogage

#### fix(ajax) : corriger l’horodatage de l’en-tête DT sur l’heure du serveur

Les en-têtes de tracing distribué (`traceparent`/`tracestate`/`newrelic`) générés pour les requests AJAX utilisent désormais l&apos;horodatage corrigé par le serveur New Relic lorsque le TimeKeeper de l&apos;agent a terminé sa correction d&apos;horloge basée sur le RUM, plutôt que la valeur d&apos;horloge locale brute du navigateur. Cet horodatage affecte uniquement la valeur de durée de transport qu&apos;un agent APM backend récepteur calcule pour son propre span ; il n&apos;a aucun effet sur aucune autre télémétrie du navigateur.

#### Assurez-vous que timeKeeper est prêt lors d&apos;une condition de concurrence du connecteur.

Le nouveau connecteur dans RUM v2 est corrigé pour préparer le TimeKeeper, essentiel aux ajustements d’horodatage de l’agent, dans une branche de condition de concurrence de cas minoritaire. Ceci est derrière l’indicateur de fonctionnalité, et ne devrait avoir aucun impact sur aucun utilisateur pour le moment.

New Relic vous recommande de mettre à niveau l&apos;agent régulièrement pour vous assurer de bénéficier des dernières fonctionnalités et avantages en termes de performances. Les nouveaux agents de navigation sont déployés auprès des clients par petites étapes sur une période donnée. De ce fait, la date à laquelle la sortie devient accessible sur votre compte peut ne pas correspondre à la date de publication d&apos;origine. Veuillez consulter ce [dashboard d&apos;état](https://newrelic.github.io/newrelic-browser-agent-release/) pour plus d&apos;informations.
