## v1.319.0

### Caractéristiques

#### Améliorations des signaux vitaux MFE

Implémenter des améliorations de la qualité de vie sur la collecte des temps vitaux du MFE.

* Si aucune valeur FCP n&apos;est observée dans les 10 secondes, arrêtez les observateurs pour économiser de la mémoire et contrôler les valeurs hors norme.
* Décorer les arbres DOM observés avec l&apos;ID d’instance du MFE pour faciliter le débogage et empêcher la double instrumentation du même arbre DOM à partir de multiples instances pointant vers la même cible MFE.

#### Détecter automatiquement les Web Sockets MFE

Ajouter la prise en charge de l&apos;attribution automatique des événements `WebSocket` aux micro-frontends (MFE). Auparavant, les événements `WebSocket` étaient uniquement capturés *automatiquement* de manière globale par l&apos;application de navigateur conteneur. Avec cette modification, l&apos;agent compare la signature de la stack d&apos;appels de la méthode WebSocket à la signature de la stack d&apos;appels du module MFE qui s&apos;est enregistré auprès de l&apos;API `register`. Si le fichier responsable de l&apos;enregistrement auprès de l&apos;agent Browser se trouve dans la signature de la stack d&apos;appels de la méthode WebSocket déclenchée, cet événement sera attribué au MFE plutôt qu&apos;au conteneur.

#### Ne pas offusquer les clés d&apos;attribut

N&apos;obfusquez pas les clés d&apos;attribut dans notre méthode addCustomAttributes pour le sérialiseur BEL. Cette modification affecte les attributs dans les événements AjaxRequest, PageViewTiming et BrowserInteraction (navigation douce uniquement).

### Débogage

#### Éviter de capturer les charges AJAX de l&apos;agent

Empêchez la fonctionnalité AJAX `capture_payloads` de capturer les propres requests de télémétrie de l&apos;agent (collectes vers les points de terminaison de balise NR).

#### Garder la charge Ajax hors des événements non liés

Supprime les informations sur la request et la charge AJAX capturées des événements non liés (métriques de tranche de temps AJAX, trace de session) via un objet `params` partagé.
