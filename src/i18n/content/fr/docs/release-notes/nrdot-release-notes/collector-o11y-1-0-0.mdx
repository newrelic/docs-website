### Caractéristiques

* Prise en charge vérifiée de l&apos;observabilité du Collector pour `nrdot-collector:2.8.1` et `opentelemetry-collector-contrib:0.163.2`
* L’attribut de ressource `newrelic.service.type` a été supprimé car il n’est plus requis pour la détection automatique
* Définissez `temporality_preference: delta` pour éviter une conversion inutile lors de l’ingestion
