### Caractéristiques

* Cas d&apos;utilisation de l&apos;hôte vérifié pour fonctionner avec `nrdot-collector:2.0.0`

### Débogage

* Les nœuds de configuration `cumulativetodelta` ont été renommés en `cumulative_to_delta` suite au renommage du composant dans `v0.157.0`<br />Le nom d&apos;origine `cumulativetodelta` reste disponible en tant qu&apos;alias obsolète.
* Désactivation de `system.cpu.logical.count` dans la configuration de l&apos;hôte<br />La mise à jour de `v0.157.0` vers `receiver/host_metrics` a activé cette métrique par défaut. Ce changement restaure le comportement précédent.
* Suppression de la règle d&apos;agrégation par moyenne `system.cpu.utilization` de la configuration de l&apos;hôte<br />La mise à jour `v0.157.0` vers `receiver/host_metrics` a modifié son comportement par défaut pour agréger `system.cpu.utilization` par moyenne, rendant la règle supprimée redondante.
