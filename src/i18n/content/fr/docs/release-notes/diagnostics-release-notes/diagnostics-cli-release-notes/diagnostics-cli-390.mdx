## Nouvelle fonctionnalité

* Nous avons ajouté une nouvelle suite et les tâches suivantes pour Agent Control ([#268](https://github.com/newrelic/newrelic-diagnostics-cli/pull/268)) :

  * `onhost-agent-control` suite - Recueille des informations sur les logs d’agent-control, le statut, la connectivité et les ressources sur l’hôte. Pour l’utiliser, exécutez `nrdiag -suites onhost-agent-control`.
  * AgentControl/Config/Agent - Détecte agent-control via PATH, les chemins d’installation connus et le répertoire de données de secours ; collecte tous les fichiers YAML de fleet-data et local-data, en préservant la structure de répertoire d’origine pour tous les sous-agents enregistrés
  * AgentControl/Config/DirTree - Écrit une arborescence de répertoires formatée de tous les chemins d’installation d’agent-control dans le zip pour l’inspection de la structure
  * AgentControl/Agent/Connect - Vérifie l’accessibilité TCP/TLS de l’OpAMP, du JWKS et des points de terminaison de jeton OAuth2 (lecture des URL à partir de local\_config.yaml) ; valide que la clé privée d’identité locale est une clé PKCS8 lisible et analysable (RSA, Ed25519 ou ECDSA)
  * AgentControl/Agent/Logs - Sur Linux, collecte les logs via `journalctl -u newrelic-agent-control`; sur Windows, rassemble tous les fichiers `*.newrelic-agent-control.log` avec rotation de date à partir du répertoire de log par défaut
  * AgentControl/Agent/StatusServer - Effectue une requête sur le serveur de statut local à l’hôte/port configuré dans local\_config.yaml (par défaut 127.0.0.1:51200) et enregistre la réponse JSON dans le zip de diagnostic
