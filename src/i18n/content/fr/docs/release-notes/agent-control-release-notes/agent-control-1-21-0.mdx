### Nouvelles fonctionnalités

* Système de fichiers Windows : suppression du code inutilisé et utilisation d’API de niveau supérieur pour l’interaction avec Windows.
* Signale la capacité personnalisée OpAMP `com.newrelic.remoteAgentTypeRepoReachable` lorsque le référentiel OCI de type d’agent configuré est accessible au démarrage.
* Sur l&apos;hôte : ajout de l&apos;agentType nri-flex.

### Débogage

* Windows : correction des fichiers dans les répertoires gérés d’Agent Control qui étaient laissés avec des autorisations qu’il ne pouvait pas utiliser. Les répertoires gérés utilisent désormais une ACE administrateur héritable, et Agent Control tente de réparer les ACE au démarrage.
