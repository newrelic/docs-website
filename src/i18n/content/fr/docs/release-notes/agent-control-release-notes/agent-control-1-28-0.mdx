### Nouvelles fonctionnalités

* L’analyse YAML est désormais plus stricte concernant les maps vides : une valeur nulle (une valeur vide, `~`, ou `null`) là où une map est attendue, comme un simple `config:` dans une configuration distante stockée, est rejetée au lieu d’être traitée comme une map vide. Utilisez `{}` pour une map vide. Les documents vides sont toujours acceptés.

### Débogage

* Sur l’hôte : le nettoyage du système de fichiers partagé ne suit plus les liens symboliques, de sorte que le contenu en dehors du système de fichiers partagé n’est jamais supprimé, et les liens symboliques orphelins sont supprimés.
* Sur l’hôte : les échecs de démarrage qui se produisent avant la configuration du logging (par exemple un `local_config.yaml` non valide) sont désormais écrits dans le fichier de log par défaut d’Agent Control, afin qu’ils soient visibles lors de l’exécution en tant que service Windows.
* Sur l’hôte : les requests de registre OCI passent désormais par le proxy configuré quel que soit le schéma de l’URL du proxy, de sorte qu’un proxy `http://` n’est plus contourné.
* Sur l’hôte : un sous-agent tué par un signal (par ex. par l’OOM killer) est désormais signalé comme terminé par ce signal au lieu de &quot;process exited with code : 0&quot;.
