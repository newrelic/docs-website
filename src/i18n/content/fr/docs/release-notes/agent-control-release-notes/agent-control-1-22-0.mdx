### Nouvelles fonctionnalités

* Sur l&apos;hôte : appliquer une limite stricte de mémoire de 2400 MiB sur l&apos;arborescence des processus Agent Control (AC + tous les agents enfants) via systemd `MemoryMax` sur Linux.

### Débogage

* Linux : empêcher la désactivation du service systemd après la mise à jour du package RPM

### Mises à jour de sécurité

* Mise à jour du crate rust futures vers 0.3.34
* Mise à jour d&apos;alpine/helm vers v4.2.4
* Mise à jour de la crate rust serde-saphyr vers 1.1.0
