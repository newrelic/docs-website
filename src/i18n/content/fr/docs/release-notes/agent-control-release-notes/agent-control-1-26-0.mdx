### Nouvelles fonctionnalités

* Ajout du fournisseur de valeurs Azure Key Vault, prenant en charge l’authentification par identité gérée et par principal de service.
* L’auto-instrumentation récupère désormais la clé de licence injectée comme en-tête si aucune n’est définie dans tous les systèmes.

### Débogage

* Windows : `install.ps1` détecte et supprime désormais une installation autonome de l’agent New Relic Infrastructure pour éviter les rapports d’hôte en double ; il doit être reconfiguré par la suite en tant que sous-agent géré par Agent Control si cela est toujours nécessaire.
* Sur l’hôte : correction des redémarrages de l’intégration causés par la synchronisation redondante du système de fichiers et la recréation complète du répertoire lors de l’écriture des fichiers de configuration OHI sur le système de fichiers partagé.
* Rendez le délai initial des threads de vérification d’état annulable, afin de réduire les périodes d’attente d’inactivité lors d’un arrêt normal.
* Correction de problèmes mineurs de logging : un champ redondant, un log dupliqué, des niveaux de log incorrects, et une casse des messages incohérente.
* Agent Control rapporte désormais toujours à nouveau son statut de configuration distante au démarrage, corrigeant un renvoi manqué après un redémarrage lorsque le serveur requests une synchronisation complète de l’état.
* Windows : l’arrêt/redémarrage du système passe par le même chemin d’arrêt normal du service qu’un arrêt manuel du service au lieu de la gestion du signal ctrl.
