### Nouvelles fonctionnalités

* Ajout du fournisseur de valeurs AWS Secrets Manager (`nr-awssm`), prenant en charge les identifiants de clé d’accès, et les profils d’instances EC2.
* Linux et Windows : Agent Control et ses sous-agents signalent désormais `os.version` et `host.arch` en tant qu’attributs OpAMP. Linux signale également `os.name` (l’identifiant de la distribution, par ex. &quot;debian&quot;).

### Débogage

* Sur l’hôte : les sous-agents sans contrôle d’état défini n’enregistrent plus les erreurs provenant d’exécutables publiant leur état de santé dans un canal fermé.
* Les clients HTTP ne récupèrent plus les paramètres de proxy en dehors de la configuration de proxy d’Agent Control, et `ignore_system_proxy: true` est entièrement respecté.
* Sur l’hôte : la sortie du sous-agent contenant des octets non UTF-8 n’arrête plus le transfert de logs et ne met plus fin au sous-agent. Ces lignes sont maintenant enregistrées avec les octets invalides remplacés.
* Windows : une mise à jour automatique qui échoue lors de la simulation du nouveau binaire ne laisse plus Agent Control sans exécutable, ce qui empêchait le service de démarrer après le prochain redémarrage.
