### Débogage

* **ExoPlayer/HLS :** `contentBitrate` a toujours signalé `0` pour les flux HLS. media3 classe en interne les chargements de segments HLS mixtes audio + vidéo comme `TRACK_TYPE_DEFAULT` plutôt que `TRACK_TYPE_VIDEO` (contrairement aux flux DASH, et progressifs, qui n’ont pas été affectés). La logique de capture de débit du tracker ne s’est déclenchée que pour `TRACK_TYPE_VIDEO`, donc les chargements HLS n’ont jamais renseigné le champ. `contentBitrate` reflète désormais correctement le débit réel du flux pour le contenu HLS.
