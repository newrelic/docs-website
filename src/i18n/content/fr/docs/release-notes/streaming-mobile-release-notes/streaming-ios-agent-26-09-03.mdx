### Nouvelles fonctionnalités

* Ajout de la prise en charge du gestionnaire de paquets Swift.
* `NRMediaTailorTracker`: ajout d’un nouveau tracker d’insertion publicitaire côté serveur (SSAI) AWS MediaTailor pour AVPlayer (iOS 12+ et tvOS 12+), offrant une parité de fonctionnalités avec `NRIMATracker`.

### Débogage

* `ios-publish`: logique de nouvelle tentative modifiée pour survivre aux échecs partiels de pipeline.
