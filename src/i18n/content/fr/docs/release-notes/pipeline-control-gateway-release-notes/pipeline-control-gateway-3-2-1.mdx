### Débogage

* Correction d’un problème où l’agent APM Python a enregistré une erreur de décodage JSON à chaque collecte lors de l’envoi de données via le gateway, ce qui a entraîné des logs en double, et la perte de données d’erreur. Le gateway répond désormais aux requests de données de l’agent APM avec HTTP `202 Accepted`, et un corps vide, comme le spécifie le protocole de l’agent.
* Correction d’un problème où les événement de span des agents APM étaient enregistrés avec l’heure à laquelle le gateway les a reçus au lieu de l’heure de début du span.

### Mises à jour de sécurité

* Mise à jour de la dépendance `golang.org/x/net` vers `v0.62.0` pour résoudre des vulnérabilités de gravité élevée, et de gravité moyenne.
