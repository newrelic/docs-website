### Nouvelles fonctionnalités

* Des packages natifs sont désormais disponibles pour Debian 13 (Trixie).
* Des packages natifs sont désormais disponibles pour Windows Server 2025 (LTSC).
* L’ [image Docker du plug-in de sortie Fluent Bit](https://hub.docker.com/r/newrelic/newrelic-fluentbit-output) publie désormais une variante Windows Server 2025 (LTSC).

### Améliorations et optimisations

* Fluent Bit est mis à niveau vers la version 5.1.5. Pour plus de détails, consultez les [annonces Fluent Bit](https://fluentbit.io/announcements/).
* Cette sortie inclut [New Relic Fluent Bit Output Plugin 3.12.0](https://github.com/newrelic/newrelic-fluent-bit-output/releases/tag/v3.12.0).
* L’agent d’infrastructure recommande Fluent Bit 5.1.5 packages pour Linux et Windows.
* L’ [image Docker du plug-in de sortie Fluent Bit](https://hub.docker.com/r/newrelic/newrelic-fluentbit-output) pour Linux utilise Fluent Bit 5.1.5 avec le plug-in de sortie 3.12.0. Les variantes d’image Windows incluent le plug-in de sortie 3.12.0, et conservent leurs versions existantes de Fluent Bit : 5.1.2 pour Windows Server 2022 et 2025, et 4.0.3 pour Windows Server 2019.
* Le [chart Helm New Relic Logging](https://github.com/newrelic/helm-charts/tree/master/charts/newrelic-logging) passe à la version 1.44.0 et installe la nouvelle image du plug-in.
* Les packages Debian 11 (Bullseye) ne sont plus générés car la distribution a atteint sa fin de vie.

### Mises à jour de sécurité

* La version de Go est mise à niveau vers la version 1.27.3 pour des correctifs CVE, y compris le blocage des clés d’autorité de certification intermédiaire eMudhra compromises.
* L’image Docker Linux ne fait plus confiance aux certificats racines emSign ECC Root CA - G3 et AAA Certificate Services.

### Remarques

Pour rester au courant des correctifs et améliorations les plus récents, abonnez-vous à notre [flux RSS de Logs](/docs/release-notes/logs-release-notes/).
