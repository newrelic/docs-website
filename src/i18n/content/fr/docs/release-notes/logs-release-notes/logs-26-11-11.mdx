### Changement de compatibilité

Le [modèle Dataflow Google Cloud Pub/Sub vers New Relic](https://github.com/newrelic-forks/DataflowTemplates) est mis à niveau vers Apache Beam 2.77.0, le maintenant sur un SDK pris en charge par GCP. La compilation et l’exécution du modèle nécessitent Java 11 ou une version ultérieure. Si vous utilisez Java 8 pour compiler ou exécuter le modèle, mettez à niveau votre JDK avant d’utiliser la version mise à jour.
