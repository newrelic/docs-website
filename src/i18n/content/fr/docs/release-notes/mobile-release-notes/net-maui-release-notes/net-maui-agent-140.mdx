### Nouvelles fonctionnalités

* Ajout de la prise en charge de .NET 11, y compris le runtime CoreCLR sur Android et iOS, et suppression des cibles .NET 9 ; les exceptions iOS non gérées sous CoreCLR sont désormais signalées avec leur trace d’appels managée. ([#87](https://github.com/newrelic/newrelic-maui-plugin/pull/87))
* Ajout des extensions de confidentialité de Session Replay pour les vues .NET MAUI. ([#102](https://github.com/newrelic/newrelic-maui-plugin/pull/102))

### Améliorations et optimisations

* Mise à jour de l&apos;agent Android natif vers la version 7.8.6.
* Mise à jour de l&apos;agent iOS natif vers la version 7.7.11.
