<Callout variant="important" title="Changement majeur dans le signalement des erreurs">
  À partir de la version 1.9.0, Les erreurs JavaScript sont signalées via un nouveau type d’événement : `MobileJSError`. Avec le nouveau protocole d’erreurs mobiles, les erreurs JavaScript React Native ne sont plus stockées dans le type d’événement `MobileHandledException`.

  <DNT>**Action required:**</DNT>

  * <DNT>**Alerts:**</DNT> Mettez à jour vos conditions d’alerte NRQL pour cibler `MobileJSError`.
  * <DNT>**Dashboards:**</DNT> Mettez à jour tous les graphiques personnalisés qui effectuent une requête sur `MobileHandledException` pour les erreurs de la couche JavaScript.
  * <DNT>**Symbolication:**</DNT> Mettez à jour vos scripts de build vers la dernière version pour prendre en charge l’envoi de source maps pour le nouveau type d’événement. Consultez le [signalement des erreurs JavaScript React Native](/docs/mobile-monitoring/new-relic-monitoring-react-native/react-native-agent-js-error-reporting).

  Mettez à jour vos requêtes comme suit :

  ```sql
  -- Before (1.8.x and lower)
  SELECT count(*) FROM MobileHandledException WHERE platform = 'reactnative'

  -- After (1.9.0 and higher)
  SELECT count(*) FROM MobileJSError
  ```
</Callout>

## Améliorations

* Les erreurs JavaScript et les rejets de promesses non gérés sont désormais signalés comme un type d’événement `MobileJSError` de premier ordre via le nouveau protocole Mobile Errors, au lieu de `MobileHandledException`.
* Ajout de la prise en charge du téléchargement de source maps pour la symbolisation des traces d’appels `MobileJSError` (automatique, manuel et CodePush/OTA). Consultez le [signalement des erreurs JavaScript React Native](/docs/mobile-monitoring/new-relic-monitoring-react-native/react-native-agent-js-error-reporting).
* Ajout de l’option de configuration `jsErrorReportingEnabled` pour activer ou désactiver le signalement des erreurs JavaScript (activé par défaut).
* `recordError` accepte désormais les arguments optionnels `isFatal` et `attributes`, vous permettant de marquer une erreur comme fatale ou d’attacher des attributs personnalisés.
* Mise à jour de l’agent Android natif vers la version 7.8.2.
* Mise à jour de l&apos;agent iOS natif vers la version 7.7.6.
