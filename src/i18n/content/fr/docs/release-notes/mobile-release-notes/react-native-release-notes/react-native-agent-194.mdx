### Nouvelles fonctionnalités

* Ajout d’une option de configuration `consoleCaptureEnabled` (par défaut `true`) qui vous permet d’empêcher l’agent de capturer les appels `console.*` en tant que logs. ([#342](https://github.com/newrelic/newrelic-react-native-agent/pull/342))

### Améliorations et optimisations

* Suppression du jeton d’application New Relic exposé. ([#338](https://github.com/newrelic/newrelic-react-native-agent/pull/338))
* Mise à jour de l’agent Android natif vers la version 7.8.5. ([#346](https://github.com/newrelic/newrelic-react-native-agent/pull/346))
* Mise à jour de l’agent iOS natif vers la version 7.7.10 pour le gestionnaire de paquets Swift (`NEWRELIC_USE_SPM=1`). Les installations CocoaPods restent à la version 7.7.9, car la version 7.7.10 n’est pas disponible sur CocoaPods. ([#346](https://github.com/newrelic/newrelic-react-native-agent/pull/346))

### Débogage

* Correction d’un plantage où `console.log/warn/error/debug` levait une exception lorsqu’un argument ne pouvait pas être sérialisé, tel qu’un objet avec un getter qui lève une exception. ([#341](https://github.com/newrelic/newrelic-react-native-agent/pull/341))
