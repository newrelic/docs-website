### Nouvelle fonctionnalité

* Mise à jour de la configuration de build XCFramework pour cibler une version de déploiement minimale d’iOS 15.0 et de tvOS 15.0, en s’alignant sur les exigences minimales documentées de la plateforme.

### Débogage

* Résolution d&apos;un plantage (`SIGSEGV` dans `objc_msgSend`) survenant lors des lectures de configuration de la collecte. Huit propriétés d&apos;objet sur `NRMAHarvesterConfiguration` déclarées comme `assign` conservaient des pointeurs pendants après le vidage du pool d&apos;autorelease de la réponse `/connect` ou du dictionnaire `NSUserDefaults`.

* Résolution d’un problème où toutes les traces d’activité étaient abandonnées pour une session lorsque la réponse `/connect` omettait l’attribut `at_capture`.

* Correction de la valeur `platform` signalée avec les erreurs React Native pour qu’elle soit signalée comme `ReactNative`.

* Correction du champ `agentVersion` dans la charge d’erreur JavaScript pour signaler avec précision la version de l’agent iOS plutôt que la version de la plateforme hôte.

* Mise à jour de la validation de l’attribut personnalisé : le passage d’un objet `NSArray` ou `NSDictionary` en tant qu’attribut d’événement enregistre désormais un log d’erreur explicite identifiant le type non pris en charge, remplaçant le message d’avertissement générique `"value must be an NSString, NSNumber, or BOOL"`.
