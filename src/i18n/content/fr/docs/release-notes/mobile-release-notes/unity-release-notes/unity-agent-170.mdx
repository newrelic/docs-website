## Améliorations

* Correction du plantage des applications iOS au lancement avec `Library not loaded: @rpath/NewRelic.framework/NewRelic`. La déclaration du gestionnaire de paquets Swift ajoutée dans la version 1.6.0 a été supprimée, et les dépendances iOS se résolvent désormais uniquement via CocoaPods. Les builds sur la version 1.6.0 à 1.6.4 étaient affectés, à moins que le gestionnaire de paquets Swift n’ait été désactivé manuellement dans les paramètres de l’EDM4U iOS Resolver.
* Correction de l’absence totale de l’agent iOS New Relic dans les builds sur Unity 2019.1 à 2021.2, où EDM4U supprimait le pod `NewRelicAgent`, mais ignorait l’injection du gestionnaire de paquets Swift car cela nécessite Unity 2021.3 ou une version ultérieure.
* Agent Android natif mis à jour vers la version 7.8.2
* Agent Android NDK natif mis à jour vers la version 1.1.5
* Agent iOS natif mis à jour vers la version 7.7.6
* Les dépendances iOS sont désormais résolues uniquement via CocoaPods. Aucune action n’est requise si vous utilisiez précédemment le gestionnaire de paquets Swift, car EDM4U se rabat automatiquement sur le pod `NewRelicAgent` et le paramètre **Swift Package Manager Enabled** \[Gestionnaire de paquets Swift activé] peut rester coché.
* Si un projet Xcode généré contient toujours une référence de package `newrelic-ios-agent-spm` provenant d’un build antérieur, supprimez le projet généré, et recompilez-le à partir de Unity pour l’effacer.
