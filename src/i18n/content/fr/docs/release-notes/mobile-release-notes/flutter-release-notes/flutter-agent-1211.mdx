## Débogage

* Correction du pont iOS codant en dur `andParams: nil`, qui supprimait silencieusement les `httpParams` personnalisés et les valeurs d’en-tête suivies des événements `MobileRequest`/`MobileRequestError`. Android transmettait déjà correctement les paramètres.

## Améliorations

* Mise à jour de l&apos;agent Android natif vers la version 7.8.1.
* Mise à jour de l&apos;agent iOS natif vers la version 7.7.6.
