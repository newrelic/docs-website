### Débogage

* Correction des rapports de plantage natifs manquants sur les appareils arm64 qui utilisent l&apos;authentification par pointeur (PAC). Sur ces appareils, le gestionnaire de plantages échouait dans l&apos;ancien unwinder intégré, donc aucun rapport, ni tombstone n&apos;était produit. L&apos;agent est désormais compilé avec le NDK r25.
* Correction des plantages intermittents de type &quot;stack corruption detected (-fstack-protector)&quot; sur le thread `NR_AppStateMon` ou le thread principal après le retour de l’application depuis l’arrière-plan.
* Correction des plantages de type use-after-free après le retour de l’application au premier plan. Ils se produisaient car l’agent libérait la stack de signaux alternative lorsque l’application passait en arrière-plan sans la désactiver au préalable.

## Déclaration de soutien

* L&apos;agent Android NDK version 1.1.5 et supérieur nécessite l&apos;agent Android 7.7.6 ou supérieur.
* L&apos;agent Android NDK version 1.1.1 et supérieure nécessite l&apos;agent Android 7.5.1 et supérieur.
* L&apos;agent Android NDK version 1.1.0 et supérieur nécessite l&apos;agent Android 7.5.0 et supérieur.
* L&apos;agent Android NDK version 1.0.3 et supérieure nécessite l&apos;agent Android 6.11.0 et supérieur.
* Les versions 1.0.0 à 1.0.2 sont compatibles avec l&apos;agent Android 6.10.0 et les versions antérieures.

Nous vous recommandons de mettre à jour l&apos;agent régulièrement, au moins tous les trois mois.
