<Callout variant="tip">
Cette leçon fait partie d’un cours qui vous apprend à créer une application New Relic à partir de zéro. Si vous ne l’avez pas déjà fait, consultez la présentation.
</Callout>

Avant de créer votre application New Relic, vous devez lancer vos services de démonstration. Ce cursus dépend de deux services importants :

* Un service Web qui affiche un formulaire d&apos;inscription à une newsletter. Le texte de l&apos;en-tête du formulaire alterne entre deux versions car vous effectuez un test A/B pour déterminer quel texte mène à un abonnement de meilleure qualité.
* Un service de simulation qui envoie un trafic constant vers le site Web afin que vous n&apos;ayez pas à générer manuellement des données

Pour lancer vos services de démonstration, vous devez d’abord installer [Docker](https://docs.docker.com/get-docker/) et [Docker compose](https://docs.docker.com/compose/install/).

## Développez vos services de démonstration [#spin]

<Steps>
<Step>
Cloner le [référentiel de cours](https://github.com/newrelic-experimental/nru-programmability-course) depuis GitHub :

```sh
git clone https://github.com/newrelic-experimental/nru-programmability-course
```

Ce référentiel contient du code pour créer des automatisations NodeJS New Relic. Il contient également un répertoire de codes d&apos;application pour chaque leçon du cours. Vous utiliserez ces répertoires pour suivre le contenu du cours.
</Step>

<Step>
Accédez au répertoire de démonstration, appelé `ab-test-app`:

```sh
cd nru-programmability-course/ab-test-app
```

Ce répertoire contient les fichiers de configuration et les fichiers README pour utiliser la démo.
</Step>

<Step>
Créez et exécutez le service Web et le conteneur du simulateur, en utilisant `docker-compose`:

```sh
NEW_RELIC_LICENSE_KEY=YOUR_NEW_RELIC_LICENSE_KEY docker-compose up -d
```

<Callout variant="important">
Assurez-vous de remplacer `YOUR_NEW_RELIC_LICENSE_KEY` par votre [clé de licence](/docs/accounts/accounts-billing/account-setup/new-relic-license-key/) réelle.
</Callout>

Une fois terminé, consultez le site Web à `localhost:3001`.
</Step>

<Step>
Visitez [New Relic](https://one.newrelic.com) et accédez à **APM** dans le menu de navigation supérieur. Sélectionnez **Newsletter** dans la liste des services instrumentés.

Vous devrez peut-être attendre une minute ou deux pour que New Relic reçoive les données de vos services de démonstration. Une fois prêt, vous verrez les données de transaction, telles que les performances, le débit et un score Apdex.
</Step>

<Step>
Pour arrêter vos services de démonstration, exécutez `docker-compose down` depuis votre répertoire `ab-test-app` :

```sh
docker-compose down
```
</Step>
</Steps>

Vous êtes maintenant prêt à créer votre application New Relic !
