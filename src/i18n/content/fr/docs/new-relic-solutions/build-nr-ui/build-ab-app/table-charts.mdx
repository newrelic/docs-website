<Callout variant="tip">
Cette leçon fait partie d’un cours qui vous apprend à créer une application New Relic à partir de zéro.

Chaque leçon du cours s&apos;appuie sur la précédente, alors assurez-vous d&apos;avoir terminé la dernière leçon, Ajouter des graphiques à secteurs, avant de commencer celle-ci.
</Callout>

Dans chaque leçon pratique de ce cours, vous avez ajouté quelque chose de nouveau à votre application de test A/B. Vous avez lancé un nouveau lanceur et ajouté plusieurs composants graphiques à votre Nerdlet. Dans cette leçon, vous allez créer deux nouveaux composants `TableChart` qui affichent des informations sur chaque version de votre site Web, telles que le ratio de clients qui s&apos;abonnent à ceux qui se désabonnent.

<Steps>
<Step>
Accédez au répertoire `add-tables/ab-test` du [référentiel de cours](https://github.com/newrelic-experimental/nru-programmability-course):

```sh
cd nru-programmability-course/add-tables/ab-test
```

Ce répertoire contient le code que nous attendons de votre application à ce stade du cours. En naviguant vers le bon répertoire au début de chaque leçon, vous laissez votre code personnalisé derrière vous, vous protégeant ainsi du transport de code incorrect d&apos;une leçon à l&apos;autre.
</Step>

<Step>
Dans `nerdlets/ab-test-nerdlet`, ajoutez un nouveau fichier Javascript nommé `totals.js`:

```sh
touch totals.js
```
</Step>

<Step>
Dans ce nouveau fichier, créez un composant appelé `VersionTotals` pour contenir votre premier `TableChart` et quelques données fictives :

```jsx fileName=nerdlets/ab-test-nerdlet/totals.js
import React from "react";
import { TableChart } from "nr1";

export default class VersionTotals extends React.Component {
constructor(props) {
  super(props);
}

render() {
  const versionATotals = {
    metadata: {
      id: `totals-${this.props.version}`,
      name: `Version ${this.props.version}`,
      columns: ["name", "count"],
    },
    data: [
      {
        name: "Subscriptions",
        count: 0,
      },
      {
        name: "Page views",
        count: 0,
      },
    ],
  };
  return <TableChart data={[versionATotals]} fullWidth />;
}
}
```

`TableChart` est différent de `PieChart` et `LineChart` de trois manières principales. Tout d&apos;abord, il n&apos;y a pas d&apos;attribut `color` ou `viz` métadonnées dans sa série. `TableChart` a une visualisation standard, il ignore donc des choses comme `color`, qui ne s&apos;appliquent pas. Deuxièmement, les séries `TableChart` ont l&apos;attribut `columns` métadonnées. `columns` détermine les noms des colonnes de la table. Enfin, les données de la série `TableChart` n’utilisent ni les valeurs x ni les valeurs y. Au lieu de cela, ils utilisent des clés qui correspondent à la colonne du tableau et des valeurs qui déterminent ce qui entre dans la ligne.

Notez que `VersionTotals` prend un accessoire `version` et le fournit aux champs `id` et `name` des métadonnées du graphique. Cela vous permet d&apos;utiliser ce même composant pour créer une table pour les versions A et B et éliminer le code en double.
</Step>

<Step>
Dans le fichier `index.js` de votre Nerdlet, importez votre nouveau composant et mettez à jour la méthode `render()` de votre Nerdlet :

```jsx fileName=nerdlets/ab-test-nerdlet/index.js lineHighlight=5,13-14
import React from 'react';
import NewsletterSignups from './newsletter-signups';
import TotalCancellations from './total-cancellations';
import TotalSubscriptions from './total-subscriptions';
import VersionTotals from './totals';

export default class AbTestNerdletNerdlet extends React.Component {
  render() {
    return <div>
      <NewsletterSignups />
      <TotalSubscriptions />
      <TotalCancellations />
      <VersionTotals version='a' />
      <VersionTotals version='b' />
    </div>
  }
}
```
</Step>

<Step>
Accédez à la racine de votre Nerdpack à `nru-programmability-course/add-tables/ab-test`.
</Step>

<Step>
Générez un nouvel UUID pour votre Nerdpack :

```sh
nr1 nerdpack:uuid -gf
```

Étant donné que vous avez cloné le référentiel de cours qui contenait un Nerdpack existant, vous devez générer votre propre identifiant unique. Cet UUID mappe votre Nerdpack à votre compte New Relic.
</Step>

<Step>
Présentez votre demande localement :

```sh
nr1 nerdpack:serve
```
</Step>

<Step>
Affichez vos modifications dans [New Relic](https://one.newrelic.com?nerdpacks=local).

Ici, vous voyez les composants `TableChart` affichés dans votre application.

Une fois que vous avez terminé, arrêtez de diffuser votre application New Relic en appuyant sur `CTRL+C` dans la fenêtre de terminal de votre serveur local.
</Step>
</Steps>

<Callout variant="tip">
Il y a un autre tableau dans le guide de conception qui enregistre les tests passés. Les colonnes de ce tableau sont :

* **Date de fin :** La date de fin du test
* **Version A Description :** Une description pour la version A
* **Version B Description :** Une description pour la version B
* **Winner :** La version sélectionnée comme design final

Essayez de créer cette table dans votre application avec ces noms de colonnes et quelques fausses données, sans regarder un exemple de code. Cette pratique renforcera ce que vous avez appris dans cette leçon.

Si vous avez besoin d&apos;aide, consultez le répertoire `add-a-chart-group` du [référentiel de cours](https://github.com/newrelic-experimental/nru-programmability-course), qui correspond à la leçon suivante de ce cours. Ceci contient le code du composant `PastTests` .
</Callout>

Chaque graphique que vous ajouterez à votre application tout au long de ce cours est unique dans son type ou dans les données qu&apos;il présente. Jusqu’à présent, vous avez créé des tableaux, des graphiques à secteurs et un graphique linéaire, et ils fonctionnent tous indépendamment les uns des autres. Dans la prochaine leçon, vous créerez quelques graphiques linéaires supplémentaires, mais cette fois, ils fonctionneront ensemble.
