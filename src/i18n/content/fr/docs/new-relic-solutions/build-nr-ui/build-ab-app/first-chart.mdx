<Callout variant="tip">
Cette leçon fait partie d’un cours qui vous apprend à créer une application New Relic à partir de zéro. Si vous ne l’avez pas déjà fait, consultez la présentation.

Chaque leçon du cours s&apos;appuie sur la précédente, alors assurez-vous d&apos;avoir terminé la dernière leçon, Ajouter des composants de graphique à votre application de test A/B, avant de commencer celle-ci.
</Callout>

Dans ce cours, vous créez une application de test A/B pour la plateforme New Relic. Auparavant, vous avez découvert le SDK New Relic]\(/docs/new-relic-solutions/build-nr-ui/sdk-component/intro-to-sdk) et sa bibliothèque de composants. Il est maintenant temps pour vous de commencer à créer votre application en vous concentrant d&apos;abord sur les composants graphiques.

Vous devez créer plusieurs graphiques, ce qui peut sembler difficile au début, mais procédez-y étape par étape. Le graphique le plus haut, et le premier que vous créerez, est un graphique linéaire qui montre le nombre d&apos;utilisateurs qui s&apos;inscrivent à votre newsletter et la version de votre site Web qui leur a été présentée.

<Steps>
<Step>
Accédez au répertoire `add-your-first-chart/ab-test` du [référentiel de cours](https://github.com/newrelic-experimental/nru-programmability-course):

```sh
cd nru-programmability-course/add-your-first-chart/ab-test
```

Ce répertoire contient le code que votre application devrait avoir à ce stade du cours. En naviguant vers le bon répertoire au début de chaque leçon, vous laissez votre code personnalisé derrière vous, vous protégeant ainsi du transport de code incorrect d&apos;une leçon à l&apos;autre.
</Step>

<Step>
Dans `nerdlets/ab-test-nerdlet`, ajoutez un nouveau fichier Javascript nommé `newsletter-signups.js`:

```sh
touch newsletter-signups.js
```
</Step>

<Step>
Dans ce nouveau fichier, créez un composant appelé `NewsletterSignups` pour contenir votre premier `LineChart` et quelques données fictives :

```jsx fileName=nerdlets/ab-test-nerdlet/newsletter-signups.js
import React from "react";
import { LineChart } from "nr1";

export default class NewsletterSignups extends React.Component {
render() {
  const versionASignups = {
    metadata: {
      id: "version-a-newsletter-signups",
      name: "Version A",
      viz: "main",
      color: "blue",
    },
    data: [
      { x: 0, y: 0 },
      { x: 10, y: 10 },
      { x: 20, y: 15 },
      { x: 30, y: 5 },
      { x: 40, y: 30 },
      { x: 50, y: 25 },
    ],
  };
  const versionBSignups = {
    metadata: {
      id: "version-b-newsletter-signups",
      name: "Version B",
      viz: "main",
      color: "green",
    },
    data: [
      { x: 0, y: 20 },
      { x: 10, y: 5 },
      { x: 20, y: 25 },
      { x: 30, y: 45 },
      { x: 40, y: 50 },
      { x: 50, y: 35 },
    ],
  };
  return <LineChart data={[versionASignups, versionBSignups]} fullWidth />;
}
}
```

Ici, vous avez créé deux séries de données arbitraires qui représentent les versions A et B de votre test. À l’heure actuelle, vous utilisez des points de données créés manuellement. À l&apos;avenir, vous les remplacerez par des requêtes de données de New Relic.

Notez que vous avez spécifié une couleur pour chaque série du graphique. L&apos;attribut de métadonnées `color` prend n&apos;importe quel format de couleur acceptable par CSS. Le paramètre `viz: 'main'` signifie que vous souhaitez restituer la série `LineChart` sous forme de ligne, le style d&apos;affichage par défaut du composant. Pour l&apos;accessoire `data` dans le composant `LineChart` , vous avez passé les deux séries dans un éventail afin que les deux soient représentées ensemble. Enfin, vous avez utilisé l&apos;accessoire `fullWidth` du graphique pour étirer la largeur du graphique afin de remplir la vue.
</Step>

<Step>
Dans le fichier `index.js` de votre Nerdlet, importez votre nouveau composant et remplacez l&apos;en-tête par défaut de la méthode `render()` de votre Nerdlet par votre nouveau composant :

```jsx fileName=nerdlets/ab-test-nerdlet/index.js lineHighlight=2,6-8
import React from 'react';
import NewsletterSignups from './newsletter-signups';

export default class AbTestNerdletNerdlet extends React.Component {
  render() {
    return <div>
      <NewsletterSignups />
    </div>
  }
}
```
</Step>

<Step>
Accédez à la racine de votre Nerdpack à `nru-programmability-course/add-your-first-chart/ab-test`.
</Step>

<Step>
Générez un nouvel UUID pour votre Nerdpack :

```sh
nr1 nerdpack:uuid -gf
```

Étant donné que vous avez cloné le référentiel de cours qui contenait un Nerdpack existant, vous devez générer votre propre identifiant unique. Cet UUID mappe votre Nerdpack à votre compte New Relic.
</Step>

<Step>
Présentez votre demande localement :

```sh
nr1 nerdpack:serve
```
</Step>

<Step>
Affichez vos modifications dans [New Relic](https://one.newrelic.com?nerdpacks=local).

Ici, vous voyez le `LineChart` affiché dans votre application.

Une fois que vous avez terminé, arrêtez de diffuser votre application New Relic en appuyant sur `CTRL+C` dans la fenêtre de terminal de votre serveur local.
</Step>
</Steps>

En sept étapes, vous avez donné vie à votre application New Relic. Au lieu d’un message fade « Bonjour le monde », votre application affiche désormais un graphique linéaire coloré avec deux séries de données simulées. Ces séries de données représentent le trafic côté serveur pour chacune des conceptions concurrentes de votre site Web de démonstration. Dans la leçon suivante, vous vous baserez sur cette base en créant un autre type de graphique.
