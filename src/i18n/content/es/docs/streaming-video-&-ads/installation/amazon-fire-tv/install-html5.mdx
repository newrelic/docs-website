Instale el `VegaTracker` de New Relic para monitorear la reproducción del elemento de video HTML5 nativo en la aplicación de Amazon Fire TV. VegaTracker no requiere ningún SDK de reproductor y se adjunta al elemento `VideoPlayer` del W3C.

## Antes de que empieces [#before-begin]

Complete primero los [pasos de instalación comunes](/docs/streaming-video-&-ads/installation/amazon-fire-tv/get-started-with-amazon-fire-tv#install) para crear la aplicación y recuperar el token de la aplicación móvil.

## Instalar el rastreador [#install]

<Steps>
  <Step>
    ### Instale el paquete HTML5

    ```shell
    npm install @newrelic/video-html5 --save
    ```
  </Step>

  <Step>
    ### Información del dispositivo de instalación

    Este paso es opcional. La biblioteca de información del dispositivo proporciona atributos reales del dispositivo —modelo, versión del sistema operativo y UUID— en los eventos de video. Sin ella, los eventos usan valores de marcador de posición para `deviceModel` y `deviceUuid`.

    ```shell
    npm install @amazon-devices/react-native-device-info --save
    ```
  </Step>

  <Step>
    ### Inicializar VegaTracker

    Inicialice `VegaTracker` dentro de la devolución de llamada `onSurfaceViewCreated`. Esto garantiza que la vinculación asíncrona del reproductor se complete antes de la inicialización.

    Pase el elemento `VideoPlayer` como primer argumento. No necesita una instancia del SDK del reproductor. El objeto `info` debe incluir el ID de la cuenta, el token de la aplicación y el extremo. Si instaló la biblioteca de información del dispositivo, pase también los atributos del dispositivo como `info.deviceInfo`.

    Cuando finalice la reproducción, llame a `tracker.dispose()` para liberar recursos.

    Para el ejemplo de inicialización, use el fragmento de código de la [instalación guiada de New Relic](/docs/streaming-video-&-ads/installation/amazon-fire-tv/get-started-with-amazon-fire-tv#install).
  </Step>

  <Step>
    ### Ver tus datos

    Despliegue la aplicación y reproduzca un video. Vaya a <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Streaming Video &amp; Ads**</DNT> para verificar que los datos fluyen para la aplicación.
  </Step>
</Steps>
