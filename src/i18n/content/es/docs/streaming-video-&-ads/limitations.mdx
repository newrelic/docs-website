Esta página consolida las limitaciones conocidas, los comportamientos no compatibles y las restricciones en todo el conjunto de características de Streaming Video &amp; Ads. Para obtener el contexto completo sobre cada limitación, siga los enlaces al final de cada sección.

## Widgets personalizados [#custom-widgets]

### Límite de widget [#widget-limit]

Cada cuenta admite un límite flexible de **50 widgets personalizados por contexto de dashboard** —50 para <DNT>**Video quality metrics**</DNT> y 50 para <DNT>**Ad quality metrics**</DNT>, contados por separado. Si alcanza el límite, elimine un widget personalizado existente antes de agregar uno nuevo. Sus widgets existentes siguen funcionando normalmente.

### Patrones de consulta NRQL [#nrql-patterns]

La integración del filtro del dashboard funciona bien para los patrones de consulta comunes. Los siguientes patrones NRQL tienen un soporte limitado o no probado y pueden producir resultados inesperados cuando los filtros globales están activos:

* **Condiciones OR en `WHERE`** —Las consultas con lógica `OR` en la cláusula `WHERE` pueden producir resultados incorrectos cuando se aplican filtros globales, debido a la precedencia de operadores.
* **`COMPARE WITH`** —Las consultas de comparación de tiempo pueden no funcionar correctamente con la integración del selector de tiempo del dashboard.
* **Subconsultas** —Los patrones `FROM (SELECT …)` anidados pueden no comportarse como se espera cuando se aplican filtros globales.
* **Agregadores anidados complejos** —las construcciones avanzadas de `filter()` más allá de los ejemplos documentados pueden no manejar correctamente el estado sin filtro.
* **Cláusula`PREDICT` **—las consultas de la cláusula `PREDICT` pueden no funcionar correctamente con la integración del selector de tiempo del dashboard.

Si encuentra un patrón de consulta que no funciona como se espera, comuníquese con el equipo de cuenta de New Relic con los detalles de la consulta.

Para obtener el contexto completo, consulte [Crear widgets personalizados para dashboards de streaming](/docs/streaming-video-&-ads/custom-widget-support).

## Ofuscación [#obfuscation]

### Patrones de expresiones regulares de Roku [#roku-regex]

Roku usa `roRegex` para la coincidencia de patrones. Roku no admite aserciones complejas de lookahead/lookbehind. Los patrones que son válidos en las expresiones regulares de JavaScript o Java pueden necesitar simplificarse para Roku.

Para obtener el contexto completo, consulte [Ofuscar los datos del agente de medios de transmisión](/docs/streaming-video-&-ads/obfuscation) y [Reglas de ofuscación de Roku](/docs/streaming-video-&-ads/installation/roku/obfuscation-rules).

Vincular una entidad de streaming de medios a una entidad de Browser o Mobile requiere una coincidencia exacta de atributos. ### Tipos de eventos duales durante la migración [#dual-event-types]
