New Relic está comprometido con la seguridad de nuestros clientes y sus datos. Creemos que colaborar con investigadores de seguridad a través de nuestro programa de divulgación coordinada es una medida importante para lograr nuestros objetivos de seguridad.

Si cree que ha encontrado una vulnerabilidad de seguridad en alguno de nuestros productos o sitios web, le agradecemos que la informe a través de nuestro programa de divulgación coordinada, tal como se explica en este documento. Si tiene otras inquietudes, consulte la información sobre [los problemas de seguridad de los clientes](#customer-issues).

## Programa de divulgación coordinado [#coordinated_disclosure_program]

New Relic se asocia con una plataforma de recompensas por errores establecida para que a los investigadores les resulte lo más fácil posible informarnos sobre vulnerabilidades de seguridad. En reconocimiento al esfuerzo involucrado en encontrar estos problemas, podemos ofrecer recompensas por informes elegibles.

New Relic ha transferido oficialmente nuestro programa de divulgación coordinada a BugCrowd.

Para participar en el programa de divulgación coordinada:

1. Debe aceptar los Términos y condiciones para investigadores de Bugcrowd y asegurarse de conocer y cumplir con [nuestras políticas de Bugcrowd](https://bugcrowd.com/engagements/newrelic-mbb-og-public) antes de iniciar cualquier prueba de seguridad.
2. Se le solicitará que cree una cuenta de New Relic que solo podrá usarse para actividades de prueba permitidas y de conformidad con las [Condiciones de servicio](https://newrelic.com/termsandconditions/terms) aplicables.

## Informes de vulnerabilidades e impacto de CVE [#vulnerability_reports_and_cve_impact]

Las herramientas de escaneo de vulnerabilidades utilizadas por New Relic están ajustadas para nuestro entorno para ayudar a reducir los falsos positivos. Debido a esto, puede haber variaciones entre nuestras herramientas de escaneo y las vulnerabilidades reportadas por otro informe de escaneo. Para obtener ayuda para evaluar un informe de escaneo, abra un caso de soporte a través del [Portal de soporte](https://support.newrelic.com/s/) de New Relic e incluya la versión del agente, una descripción detallada de cómo se realizó el escaneo, la herramienta de escaneo utilizada, las consideraciones especiales de configuración y el resultado exacto del informe.

Mantener seguros a los clientes es la principal prioridad de New Relic. Para obtener los informes más actualizados sobre las CVE críticas que afectan a nuestros agentes, revise los boletines de seguridad de New Relic y considere [suscribirse al canal de la comunidad de notificaciones de seguridad de New Relic o a su fuente RSS](/docs/security/security-privacy/information-security/security-bulletins/).

## Problemas de seguridad de los clientes [#customer-issues]

Si es uno de los clientes de New Relic y tiene una inquietud de seguridad o de otro tipo con respecto a los servicios, lo que incluye cualquier problema de contraseña, clave de API o cuenta, no utilice nuestro programa de divulgación coordinada. En su lugar, siga nuestros procedimientos de resolución de problemas estándar para [problemas de contraseña, correo electrónico e inicio de sesión](/docs/accounts/accounts-billing/account-setup/troubleshoot-new-relics-password-email-address-login-problems/) o abra un caso de asistencia de seguridad a través del [portal de asistencia](https://support.newrelic.com/s/) de New Relic.
