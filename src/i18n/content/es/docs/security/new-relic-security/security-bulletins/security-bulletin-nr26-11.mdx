<DNT>**Vulnerability Identifier:**</DNT> NR26-11

<DNT>**Priority:**</DNT> Alto

## Resumen

We are issuing this bulletin to inform you of critical security vulnerabilities in [Node.js](https://nodejs.org/) versions (22.x, 24.x, 26.x) that may require customer action for New Relic Synthetic monitoring customers using Public and Private locations.

**Versiones corregidas:** las versiones corregidas de Node.js son 22.23.4, 24.22.1 y 26.12.1.

**Versiones al final de su vida útil (EOL):** Node.js 20 y anteriores, incluida Node.js 16.x, han llegado al final de su vida útil y no recibirán parches del proyecto Node.js. La única remediación para las versiones EOL de Node.js es la migración a una versión con soporte.

## Acción requerida

Estas vulnerabilidades afectan a los clientes de monitoreo sintético que usan tanto ubicaciones públicas como privadas. La acción de los clientes para cada una es la siguiente.

### Ubicación pública

La acción de los clientes depende de si los monitores están en el entorno de ejecución más reciente.

1. **No se requiere ninguna acción:** no se requiere ninguna acción para los monitores desplegados en ubicaciones públicas que utilizan el entorno de ejecución compatible más reciente.

### Ubicación privada

**Acción requerida:** para las ubicaciones privadas, debe descargar las imágenes de tiempo de ejecución más recientes para solucionar estas CVE. Se requiere una acción para los monitores desplegados en ubicaciones privadas si no utiliza la etiqueta `latest`.

The `node-api-runtime` and `node-browser-runtime` container images bundle Node.js and are directly impacted by this vulnerability. Although security scanners may detect the CVE within the Synthetics Job Manager (SJM) and ping-runtime images, these runtimes are not exploitable. To eliminate the same, these CVE&apos;s will be addressed in the next releases of SJM v642 and ping-runtime 1.87.0.

Si ejecuta ubicaciones privadas, siga los siguientes pasos:

1. Descargue las últimas versiones de las imágenes de tiempo de ejecución afectadas:

   ```shell
   # Node API runtime
   docker pull newrelic/synthetics-node-api-runtime:latest

   # Node browser runtime
   docker pull newrelic/synthetics-node-browser-runtime:latest
   ```

2. Reinicie los contenedores después de descargar las imágenes actualizadas para aplicar la corrección.

Para obtener más información, consulte la [guía de transición del entorno de ejecución](/docs/synthetics/synthetic-monitoring/private-locations/runtime-transition-guide/).

### Aviso importante: monitores de API con scripts de Node.js 16.x

Si tiene monitores de API programados configurados para ejecutarse en Node.js 16.x, tenga en cuenta que:

* Node.js 16.x will not receive a security patch for these CVEs from the Node.js project, because it has already reached [end-of-life](/eol/2026/05/eol-05-18-26-node-16-chrome-134-runtimes/).
* New Relic no ha forzado la actualización automática de los monitores de Node.js 16.x a Node 22.x, ya que no se puede garantizar la compatibilidad de los script. Es posible que algunos script de monitor requieran cambios de código para ejecutarse correctamente en Node 22.x.

Recomendamos encarecidamente que revise y migre los monitores de Node 16.x a Node 22.23.4 lo antes posible, y que no espere hasta el 18 de noviembre de 2026. Para obtener instrucciones detalladas de migración, consulte [Actualizar monitores de API con script a Node.js 22](/docs/synthetics/synthetic-monitoring/scripting-monitors/synthetics-scripted-api-monitors-to-node-22/).

## Preguntas frecuentes

1. **Do I need to update the Synthetics job manager (SJM) &amp; ping-runtime?**

   No immediate update is required for remediation. While vulnerability scanners may flag the CVE in SJM and ping-runtime, these components are not susceptible to exploitation. However, upcoming releases (SJM v642 and ping-runtime 1.87.0) will address this CVE. Updating to these releases is recommended if you wish to maintain zero-finding compliance reports.

2. **C¿La actualización de las imágenes de entorno de ejecución afectará mis monitores en ejecución?**

   Los monitores continúan ejecutándose normalmente después de la actualización de la imagen del entorno de ejecución. No hay cambios de comportamiento para los monitores que se ejecutan en Node 22.x.

3. **¿Se puede explotar el CVE-2026-111497 de forma remota?**

   Sí. Esta es una vulnerabilidad de ejecución remota de código. Se puede activar cuando un proceso de Node.js recibe una respuesta HTTP comprimida con Brotli desde un servidor controlado por un atacante. No se requiere acceso local.

4. **Estoy ejecutando monitores de Node 16.x. ¿Estoy en riesgo?**

   Sí. Node 16.x ha llegado al final de su vida útil y no recibirá parches. Los monitores seguirán siendo vulnerables hasta que los migre a Node 22.23.4. Puede hacerlo utilizando la herramienta de actualización del entorno de ejecución. Para obtener más información, consulte [Administrar los entornos de ejecución de los monitores](/docs/synthetics/synthetic-monitoring/using-monitors/manage-monitor-runtimes/).

5. **¿Por qué mi monitor de Node 16.x no se actualizó automáticamente?**

   Node 22.x includes breaking changes from Node 16.x, which New Relic [communicated earlier](/eol/2026/05/eol-05-18-26-node-16-chrome-134-runtimes/). Scripted API monitors still on Node 16.x are those that couldn&apos;t be automatically upgraded without failing. New Relic therefore made this a customer-initiated upgrade to avoid unintended monitor breakage. We&apos;ll follow the EOL timelines [communicated earlier](/eol/2026/05/eol-05-18-26-node-16-chrome-134-runtimes/) and will force-upgrade Node 16.x monitors on November 18, 2026.

6. **¿Debo reiniciar algo después de actualizar los tiempos de ejecución de la ubicación privada?**

   Solo se requiere reiniciar el contenedor. No es necesario reiniciar el host.

7. **¿Con quién puedo comunicarme si aún tengo preguntas?**

   Abra un caso con nuestro equipo de Soporte a través de la sección de ayuda en la plataforma de New Relic.
