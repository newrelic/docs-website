<DNT>**Vulnerability Identifier:**</DNT> NR26-13

<DNT>**Priority:**</DNT> Alto

## Resumen

Entre el 17 y el 20 de octubre de 2026, los investigadores revelaron que las claves privadas de ocho certificados de autoridad de certificación (CA) intermedia emitidos por eMudhra se pueden recuperar (CVE-2026-111943). Cualquier persona con esas claves puede crear certificados que el software aceptaría como genuinos si aún confía en ellos. Los navegadores y los sistemas operativos han bloqueado los certificados, pero el software que incluye su propia lista de CA de confianza, incluidas algunas imágenes de contenedor, debe actualizarse.

New Relic ha actualizado los siguientes componentes de Logs para que ya no acepten certificados emitidos por estas CA. Las versiones actualizadas no se detectan automáticamente. Los clientes deben actualizar a las versiones que se indican a continuación.

**Nota para el usuario de FireLens:** el plug-in en sí ahora rechaza los certificados emitidos por las CA afectadas. La imagen base proporcionada por AWS (`aws-for-fluent-bit`) aún puede enumerar las CA raíz afectadas en su propio paquete de CA hasta que AWS publique una imagen reconstruida. Actualizaremos este boletín cuando esté disponible.

## Información sobre vulnerabilidades técnicas

[CVE-2026-111943](https://www.cve.org/CVERecord?id=CVE-2026-111943)

Ocho CA intermedias que forman una cadena con la CA raíz ECC de emSign - G3 y, a través de la firma cruzada, con AAA Certificate Services, están afectadas.

* El plug-in está compilado con Go 1.27.3, cuya biblioteca TLS rechaza las cadenas de certificados que contienen las ocho claves afectadas, incluso si la raíz sigue siendo de confianza.
* Las imágenes base de Fluent Bit 5.1.5 han eliminado las raíces afectadas de su paquete de CA.
