<Callout variant="important">
Para acceder a <DNT>Cloud Cost Intelligence</DNT>, necesita un **SKU de CCU avanzado**, una licencia de **usuario completo de la plataforma** y el acceso habilitado a través del [Administrador de control de características](/docs/accounts/accounts-billing/new-relic-one-user-management/feature-control-manager/). Esta página aborda el acceso a la configuración —quién puede modificar los ajustes de CCI una vez que el producto está habilitado para la organización.
</Callout>

Nuestro sistema de autorización estándar controla el acceso a las superficies de <DNT>Cloud Cost Intelligence</DNT> (<DNT>Settings</DNT>, <DNT>Integrations</DNT> y <DNT>Custom Facets</DNT>). Divide el acceso en lectura (ver configuración) y escritura (crear, actualizar, eliminar), por cuenta, no en toda la organización.

## Acceso predeterminado [#default-access]

Todos los usuarios con acceso a la cuenta obtienen acceso de solo lectura de forma predeterminada.

Solo un <DNT>Organization Admin</DNT> puede otorgar acceso de modificación o eliminación —a sí mismo, a otros usuarios individuales o a un rol.

## Referencia de permisos [#permissions-reference]

La siguiente tabla enumera los permisos disponibles para cada superficie de CCI. Todos los usuarios reciben acceso de lectura de forma predeterminada. Los accesos de modificación y eliminación requieren un [rol personalizado](#grant-modify-access).

| Superficie de CCI        | Leer                                   | Modificar                     | Borrar                        |
| ------------------------ | -------------------------------------- | ----------------------------- | ----------------------------- |
| <DNT>Custom Facets</DNT> | Predeterminado para todos los usuarios | Requiere un rol personalizado | Requiere un rol personalizado |
| <DNT>Integrations</DNT>  | Predeterminado para todos los usuarios | Requiere un rol personalizado | —                             |
| <DNT>Settings</DNT>      | Predeterminado para todos los usuarios | Requiere un rol personalizado | —                             |

## Otorgar acceso de modificación [#grant-modify-access]

Un <DNT>Organization Admin</DNT> otorga acceso de escritura a CCI a través de un [rol personalizado](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/#roles). Hay dos opciones disponibles:

### Agregar permisos de CCI a un rol personalizado existente [#option-existing-role]

Si ya existe un rol personalizado para un equipo (por ejemplo, un rol &quot;FinOps&quot;), agréguele los permisos de escritura de CCI. Todos los usuarios que ya tienen asignado ese rol obtienen automáticamente acceso de escritura a CCI. No necesita reasignar usuarios individuales.

### Crear un rol personalizado dedicado para CCI [#option-new-role]

Cree un rol personalizado que contenga solo los permisos de modificación de CCI (<DNT>Settings</DNT>, <DNT>Integrations</DNT>, <DNT>Custom Facets</DNT>), y luego asígnelo a los usuarios específicos, grupos o a usted mismo que lo necesiten. Utilice esta opción para mantener la administración de CCI separada de las responsabilidades de cualquier otro rol.
