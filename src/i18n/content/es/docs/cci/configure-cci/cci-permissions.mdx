El sistema de autorización estándar de New Relic controla el acceso a las superficies de <DNT>Cloud Cost Intelligence</DNT> (<DNT>Settings</DNT>, <DNT>Integrations</DNT> y <DNT>Custom Facets</DNT>). Divide el acceso en lectura (ver configuración) y escritura (crear, actualizar, eliminar), por cuenta, no a nivel de toda la organización.

## Acceso predeterminado [#default-access]

Todos los usuarios con acceso a la cuenta obtienen acceso de solo lectura de forma predeterminada.

Solo un <DNT>Organization Admin</DNT> puede otorgar acceso de modificación, edición o eliminación —a sí mismo, a otros usuarios individuales o a un rol.

## Otorgar acceso de modificación [#grant-modify-access]

Un <DNT>Organization Admin</DNT> otorga acceso de escritura a CCI a través de un [rol personalizado](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/#roles). Hay dos opciones disponibles:

### Opción 1: agregar permisos de CCI a un rol personalizado existente [#option-existing-role]

Si ya existe un rol personalizado para un equipo (por ejemplo, un rol de &quot;FinOps&quot;), agréguele las capacidades de escritura de CCI. Todos los que ya tienen asignado ese rol obtienen automáticamente acceso de escritura a CCI. No es necesaria una reasignación por usuario.

### Opción 2: crear un rol personalizado dedicado para CCI [#option-new-role]

Cree un rol personalizado que contenga solo las capacidades de modificación de CCI (<DNT>Settings</DNT>, <DNT>Integrations</DNT>, <DNT>Custom Facets</DNT>), luego asígnelo a los usuarios específicos, grupos o a sí mismo que lo necesiten. Utilice esta opción para mantener la administración de CCI separada de las responsabilidades de cualquier otro rol.
