La página <DNT>**Kubernetes Costs**</DNT> muestra cuánto cuesta cada uno de sus clústeres de Kubernetes, desglosado por CPU, memoria, recursos no utilizados y no asignados. Utiliza sus telemetry data de Kubernetes en New Relic para correlacionar la facturación de cloud con el uso a nivel de clúster, de modo que pueda ver a dónde van sus gastos y dónde puede reducir costos.

<img title="Kubernetes Cost Insights highlighted on the Cloud Cost Intelligence Kubernetes Cost Insights page" alt="Kubernetes Cost Insights highlighted on the Cloud Cost Intelligence Kubernetes Cost Insights page" src="/images/k8s-cci.webp" />

## Requisitos previos [#prerequisites]

Antes de que la página <DNT>**Kubernetes Costs**</DNT> pueda mostrar datos, debe agregar las cuentas de New Relic que contienen la telemetría de Kubernetes. CCI utiliza los eventos `K8sContainerSample` de esas cuentas y los une con los datos de facturación de cloud mediante el ID de la instancia. Si omite este paso, es posible que vea los costos de cloud en CCI, pero no los costos de Kubernetes.

Para agregar estas cuentas, complete los siguientes pasos:

1. Vaya a <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Cloud Cost Intelligence &gt; Settings &gt; Telemetry Accounts**</DNT>.

2. En el desplegable <DNT>**Accounts**</DNT>, seleccione cada cuenta de New Relic que tenga datos de `K8sContainerSample`. Para verificar una cuenta, ejecute esta consulta en ella:

   ```sql
   SELECT count(*) FROM K8sContainerSample SINCE 1 day ago
   ```

3. Haga clic en <DNT>**Apply**</DNT>.

Una vez que agregue las cuentas, CCI extrae los datos de `K8sContainerSample` y comienza a asignar los costos de Kubernetes.

<Callout variant="important">
Si su clúster de Kubernetes informa a más de una cuenta de New Relic, agregue cada una. Los costos del clúster en las cuentas que no haya agregado no aparecerán en la página <DNT>**Kubernetes Costs**</DNT>.
</Callout>

Si agregó las cuentas correctas y aún no ve los costos de Kubernetes, consulte [Solución de problemas](#troubleshoot).

## Filtros y personalización

### Filtros de proveedor de la nube

Para filtrar sus datos de costos por proveedor de cloud, seleccione una opción del menú desplegable en la parte superior izquierda de la página:

* <DNT>**All**</DNT>: todos los proveedores de cloud
* <DNT>**AWS**</DNT>: solo Amazon Web Services
* <DNT>**Azure**</DNT>: solo Microsoft Azure

### Selector de rango de fechas

En la parte superior derecha de la página, use el selector de rango de fechas para hacer lo siguiente:

* Elige un período de tiempo predefinido
* Establecer fechas de inicio y finalización personalizadas
* Ver costos en su zona horaria preferida (UTC se muestra de forma predeterminada)

### Filtro de costos de ingeniería

Si su organización utiliza etiquetas de asignación de costos, puede filtrar por la etiqueta <DNT>**Engineering costs**</DNT> para limitar el análisis a equipos, proyectos o centros de costos específicos etiquetados en su entorno cloud.

## Resumen

La sección Resumen muestra cuatro métricas de costos para el período seleccionado:

| Métrica                             | Descripción                                                                                                        |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| <DNT>**Total cost**</DNT>           | Gasto agregado para todo el clúster de Kubernetes, con el cambio porcentual en comparación con el período anterior |
| <DNT>**Average cost (Daily)**</DNT> | Gasto promedio diario, con el cambio porcentual                                                                    |
| <DNT>**Unused cost**</DNT>          | Costo de los recursos que su clúster ha asignado pero que no reciben requests, con el cambio porcentual            |
| <DNT>**Unallocated cost**</DNT>     | Costo de los recursos del clúster no asignados a ninguna fuente, con el cambio porcentual                          |

## Insights

La sección Insights proporciona dos widgets de visualización para ayudarlo a analizar sus costos de Kubernetes.

### Tendencias de costos

El widget <DNT>**Cost Trends**</DNT> muestra un gráfico de líneas que ilustra cómo cambian sus costos de Kubernetes a lo largo del tiempo. Usa las opciones de vista para cambiar entre las vistas <DNT>**Hourly**</DNT>, <DNT>**Daily**</DNT>, <DNT>**Weekly**</DNT> o <DNT>**Monthly**</DNT>.

### Los 20 principales

El widget <DNT>**Top 20**</DNT> muestra las áreas de mayor costo mediante una visualización de gráfico de árbol. De forma predeterminada, muestra los 20 clústeres principales por costo. Puede personalizar la vista con las siguientes opciones:

* <DNT>**Dropdown filter**</DNT>: Seleccione qué mostrar (<DNT>**Cluster name, by cost**</DNT>)
* <DNT>**Group by**</DNT>: elija dimensiones para agrupar datos de costos
* <DNT>**View by**</DNT>: Alternar entre <DNT>**Tree chart**</DNT> y otros formatos de visualización

## Cost &amp; Usage Analysis

La sección <DNT>**Cost &amp; Usage Analysis**</DNT> presenta una tabla con un desglose del uso de recursos y los costos por nombre de clúster:

| Columna                         | Descripción                                                                   |
| ------------------------------- | ----------------------------------------------------------------------------- |
| <DNT>**Cluster name**</DNT>     | Nombre de su clúster de Kubernetes                                            |
| <DNT>**CPU cost**</DNT>         | Costo atribuido al uso de CPU para cada clúster                               |
| <DNT>**CPU usage**</DNT>        | Porcentaje de recursos de CPU consumidos por cada clúster                     |
| <DNT>**Memory cost**</DNT>      | Costo asociado al uso de memoria de cada clúster                              |
| <DNT>**Memory usage**</DNT>     | Porcentaje de recursos de memoria utilizados por cada clúster                 |
| <DNT>**Unused cost**</DNT>      | Costo de los recursos que el clúster ha asignado pero que no reciben requests |
| <DNT>**Unallocated cost**</DNT> | Costo de los recursos del clúster no asignados a ningún origen                |
| <DNT>**Total cost**</DNT>       | Costo combinado de cada clúster en todo el uso de recursos (ordenable)        |

Si los costos no utilizados o no asignados son consistentemente altos para un clúster, es posible que esté sobreaprovisionado. Consulte las [Recomendaciones de optimización de costos](/docs/cci/financial-intelligence/cci-recommendations) para conocer formas de reducir los gastos en todo su entorno cloud.

## Costos no utilizados frente a no asignados

Estas dimensiones de costos le ayudan a medir la eficiencia del clúster:

| Tipo de costo      | Definición                                                        | Ejemplo                                                                       |
| ------------------ | ----------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Costo no utilizado | Recursos que el clúster ha asignado pero que no reciben requests. | Costo total: $5.60, utilizado: $4.64, costo no utilizado: $0.96               |
| Costo no asignado  | Recursos del Cluster no asignados a ninguna fuente.               | Costo del nodo: $10.00, asignado a workloads: $7.50, costo no asignado: $2.50 |

<Callout variant="tip">
Seleccione cualquier clúster para ver su <DNT>**Cost Trends**</DNT>, <DNT>**Cost Breakdown (Total vs Used)**</DNT> e información sobre los costos no utilizados y no asignados.
</Callout>

## Solucionar problemas [#troubleshoot]

### Los costos de AWS aparecen, pero no se muestran los costos de Kubernetes

Aún no ha agregado las cuentas de telemetría o solo ha agregado algunas. Consulte [Requisitos previos](#prerequisites).

### Faltan algunos clúster en la página

Es posible que su clúster de Kubernetes informe a más de una cuenta de New Relic. Asegúrese de haber agregado todas las cuentas que informan en <DNT>**Settings &gt; Telemetry data**</DNT>.

### Agregó las cuentas correctas, pero los costos aún no aparecen

Comuníquese con el servicio de atención a clientes de New Relic.

Para problemas con la configuración, las integraciones o los permisos de CCI, consulte [Solucionar problemas de configuración de Inteligencia para costos en la nube](/docs/cci/troubleshooting/troubleshooting).
