Para ejecutar cualquiera de las consultas en esta página, vaya a <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Cloud Cost Intelligence**</DNT> y abra el <DNT>**Query your data**</DNT>.

## CloudSpend [#cloudspend]

`CloudSpend` y `CloudCost` contienen los mismos datos de facturación de su proveedor de cloud, pero difieren en sus capacidades de NRQL. `CloudSpend` admite el lenguaje NRQL completo y es la opción recomendada para todas las consultas nuevas. `CloudCost` solo admite un subconjunto de cláusulas de NRQL y está programado para su desuso.

`CloudSpend` ingiere artículos de línea de facturación sin procesar de AWS Cost and Usage Reports (CUR), exportaciones de Azure FOCUS y exportaciones de GCP BigQuery, actualizados cada hora. Comparte atributos clave con `CloudCost`, incluidos `line_item_net_unblended_cost`, `line_item_product_code` y `line_item_usage_account_id`. Para ver una referencia completa de los atributos, consulte el [diccionario de datos](/attribute-dictionary).

Ejemplo de consulta:

```sql
FROM CloudSpend SELECT * SINCE 24 hours ago
```

Encuentre el gasto total de cloud desglosado por servicio durante el último mes:

```sql
FROM CloudSpend SELECT SUM(line_item_net_unblended_cost) FACET line_item_product_code SINCE 1 month ago
```

Vea cómo evoluciona el gasto diario de cloud a lo largo del tiempo:

```sql
FROM CloudSpend SELECT SUM(line_item_net_unblended_cost) TIMESERIES 1 day SINCE 30 days ago
```

## KubernetesSpend [#kubernetesspend]

`KubernetesSpend` almacena registros de asignación de costos individuales para workloads de Kubernetes. Combina la telemetría de New Relic Infrastructure con las exportaciones de facturación cloud para desglosar los costos por clúster, namespace, pod y contenedor, y es compatible con todo el lenguaje NRQL.

Debido a que los costos de los nodos de Kubernetes se comparten entre las workloads, `KubernetesSpend` los distribuye proporcionalmente utilizando `cpu_weightage` y `memory_weightage`. Multiplique `net_unblended_cost` por `(cpu_weightage + memory_weightage)` para obtener totales de costos precisos por workload. Para ver una referencia completa de los atributos, consulte el [diccionario de datos](/attribute-dictionary).

Ejemplo de consulta:

```sql
FROM KubernetesSpend SELECT * SINCE 1 week ago
```

## Costo de la nube [#cloudcost]

<Callout variant="important">
  Recomendamos utilizar `CloudSpend` para todo el análisis de costos y uso. Proporciona los mismos datos de facturación que `CloudCost` con soporte completo de NRQL.
</Callout>

`CloudCost` es un evento de resumen generado por Inteligencia para costos en la nube a partir de los informes de costos y uso (CUR) del proveedor de cloud. Proporciona datos de líneas de pedido de facturación, incluido el uso de recursos, los costos y los metadatos de la cuenta en las cuentas de AWS y Azure, actualizados cada hora. Debido a que `CloudCost` está preagregado, solo admite un subconjunto de cláusulas NRQL. Para obtener total flexibilidad de NRQL, utilice `CloudSpend`.

### Atributos clave

Los siguientes atributos son más útiles para crear consultas de CloudCost:

| Atributo                       | Descripción                                                                                                                |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| `line_item_net_unblended_cost` | Costo después del descuento para la partida, específico de la cuenta individual.                                           |
| `line_item_product_code`       | Código de servicio del proveedor de la nube (por ejemplo, `AmazonEC2` para AWS o `Virtual Machine Scale Sets` para Azure). |
| `line_item_usage_account_id`   | ID de cuenta de AWS de 12 dígitos de la cuenta que utilizó esta línea de pedido.                                           |
| `line_item_usage_account_name` | Nombre para mostrar de la cuenta de cloud o suscripción.                                                                   |
| `line_item_unblended_cost`     | Costo a tarifas estándar bajo demanda antes de cualquier descuento por instancia reservada, Savings Plan o por volumen.    |
| `amortised_cost`               | Costo amortizado que incluye tarifas de reserva inicial o plan de ahorros distribuidas durante el período de uso.          |
| `is_k8s`                       | Indicador que señala si el costo está asociado con una workload de Kubernetes.                                             |

Ejemplo de consulta:

```sql
FROM CloudCost SELECT * SINCE 24 hours ago
```

## Costo de Kubernetes [#kubernetescost]

`KubernetesCost` es un evento de asignación de costos generado por Inteligencia para costos en la nube. Desglosa los costos de cloud por clúster de Kubernetes, namespace, pod y contenedor. Este tipo de evento solo admite un subconjunto de cláusulas de NRQL.

### Atributos clave

Los siguientes atributos son más útiles para crear consultas de KubernetesCost:

| Atributo             | Descripción                                                                                                          |
| -------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `total_cost`         | Costo total, calculado como la suma de `cpu_costs` y `memory_costs`.                                                 |
| `cpu_costs`          | Porción del costo atributo al uso de CPU.                                                                            |
| `memory_costs`       | Porción del costo atribuido al uso de la memoria.                                                                    |
| `net_unblended_cost` | Costo neto después de descuentos, basado en la proporción de uso del recurso sobre el costo del nodo EC2 subyacente. |
| `cpu_usage`          | Relación entre los núcleos de CPU en uso y los núcleos de CPU asignados (valor entre 0 y 1).                         |
| `memory_usage`       | Proporción de memoria en uso con respecto a la memoria asignada (valor entre 0 y 1).                                 |
| `cluster_name`       | Nombre del clúster que aloja los nodos y pods.                                                                       |
| `namespace_name`     | namespace de Kubernetes: una separación lógica de servicios y nodos de despliegue.                                   |
| `pod_name`           | Nombre del pod de Kubernetes, que puede alojar uno o más contenedores.                                               |
| `container_name`     | Nombre del contenedor Docker.                                                                                        |
| `node_name`          | Nodo EC2 en el que está desplegado el pod.                                                                           |
| `deployment_name`    | Nombre del despliegue de Kubernetes que administra el pod.                                                           |

Ejemplo de consulta:

```sql
FROM KubernetesCost SELECT * SINCE 1 week ago
```

Para obtener costos precisos de Kubernetes, multiplique `cpu_weightage + memory_weightage` en sus consultas:

```sql
SELECT SUM(net_unblended_cost * (cpu_weightage + memory_weightage) + network_net_unblended_cost) FROM KubernetesCost SINCE '2026-09-01' UNTIL '2026-09-10'
```

La consulta multiplica `net_unblended_cost` por la suma de la ponderación de CPU y memoria para asignaciones de costos precisas basadas en el uso de recursos.

<img title="Query Console showing KubernetesCost event attributes" alt="Query Console showing KubernetesCost event attributes" src="/images/kubernetes-cost-cci.webp" />

Identifique los namespaces de Kubernetes más costosos:

```sql
FROM KubernetesCost SELECT SUM(total_cost) FACET namespace_name SINCE 1 week ago LIMIT 10
```

Compare el costo de la CPU con el costo de la memoria por clúster:

```sql
FROM KubernetesCost SELECT SUM(cpu_costs), SUM(memory_costs) FACET cluster_name SINCE 1 week ago
```

Encuentre contenedores subutilizados donde el uso de CPU es bajo:

```sql
FROM KubernetesCost SELECT average(cpu_usage) FACET container_name WHERE cpu_usage < 0.2 SINCE 3 days ago
```

## Estimación del costo de la nube [#cloudcostestimate]

`CloudCostEstimate` es un evento en tiempo real generado por Inteligencia para costos en la nube. Proporciona costos de cloud estimados a nivel de recurso, incluidos los detalles de la instancia de AWS y metadatos como la propiedad del equipo, el entorno y el nombre del servicio. Este tipo de evento solo admite un subconjunto de cláusulas de NRQL.

### Atributos clave

Los siguientes atributos son más útiles para crear consultas de CloudCostEstimate:

| Atributo        | Descripción                                                                                      |
| --------------- | ------------------------------------------------------------------------------------------------ |
| `cost`          | Costo estimado en la moneda de su factura de la cloud para el recurso durante el período de uso. |
| `owning_team`   | Valor de la etiqueta `owning_team` aplicada al recurso, si está presente.                        |
| `product_code`  | Código de servicio del proveedor de la nube (por ejemplo, `EC2`).                                |
| `service_name`  | El servicio para el que es la estimación.                                                        |
| `instance_type` | Tipo de instancia EC2 de AWS (por ejemplo, `m6g.8xlarge`). Se aplica solo a los recursos de AWS. |
| `aws_region`    | Región de AWS donde se despliega el recurso (por ejemplo, `us-east-2`).                          |
| `department`    | Valor de la etiqueta `department` aplicada al recurso, si está presente.                         |
| `environment`   | Entorno de despliegue del recurso, obtenido de la etiqueta `environment` del recurso.            |

Ejemplo de consulta:

```sql
FROM CloudCostEstimate SELECT * SINCE 24 hours ago
```

<img title="Query Console showing CloudCostEstimate event attributes" alt="Query Console showing CloudCostEstimate event attributes" src="/images/cloud-cost-estimate.webp" />

Revise los costos estimados por equipo propietario:

```sql
FROM CloudCostEstimate SELECT SUM(cost) FACET owning_team SINCE 24 hours ago
```
