Esta guía le muestra cómo desinstalar el <DNT>**New Relic ABAP component (NEWR)**</DNT> de su sistema central de SAP. Es posible que necesite hacer esto al dar de baja el monitoreo o antes de actualizar a una nueva versión.

<Callout variant="caution">
  Desinstalar el <DNT>**New Relic ABAP component**</DNT> detiene toda la recopilación de datos de monitoreo y elimina el componente de su sistema SAP. New Relic conserva los datos históricos, pero no recopila datos nuevos después de la desinstalación. No puede deshacer esta acción.
</Callout>

## Requisitos previos

* Acceso de administrador a <DNT>**SAP system**</DNT>
* Acceso a <DNT>**client 000**</DNT>
* Respaldo de cualquier configuración personalizada (si es necesario para una futura reinstalación)

## Eliminar los artefactos de monitoreo de New Relic

Antes de desinstalar el <DNT>**ABAP component**</DNT>, limpie los artefactos de monitoreo en el sistema de monitoreo central:

1. Detenga y desprograme cualquier trabajo de recopilación programado que ejecute `/NEWR/*` programas. Utilice la transacción `SM37` para buscar y cancelar estos trabajos.
2. Elimine cualquier rol con nombres que tengan el prefijo `/NEWR/*`.
3. En la transacción `SM59`, elimine cualquier <DNT>**RFC connections**</DNT> a los sistemas monitoreados que se haya creado exclusivamente para la recopilación de datos de New Relic. Puede identificar estas conexiones por la cuenta de inicio de sesión de recopilación de datos de New Relic designada o consultando la lista del registro de proveedores de datos de New Relic.

## Desinstale el componente ABAP

Siga estos pasos para desinstalar el componente ABAP del sistema central:

1. Inicie sesión en <DNT>**client 000**</DNT>.
2. Ingrese el código de transacción `SAINT`.
3. Haga clic en la pestaña <DNT>**Uninstallable Components**</DNT> .

<img title="ABAP component on central system" alt="The SAINT transaction showing the NEWR component in the Uninstallable Components list" src="/images/ABAP-component-on-cms.webp" width="700" />

4. Seleccione el componente <DNT>**NEWR**</DNT> y verifique que el número de versión coincida con su versión instalada.
5. Haga clic en <DNT>**Start**</DNT>.
6. Haga clic en la marca de verificación verde para confirmar en cada pantalla subsiguiente.
7. Haga clic en <DNT>**Finish**</DNT> cuando se complete el proceso.
8. Verifique que el componente <DNT>**NEWR**</DNT> ya no aparezca en la pestaña <DNT>**Installed Components**</DNT>.

## Eliminar New Relic de los sistemas monitoreados

El componente ABAP <DNT>**NEWR**</DNT> se instala solo en el sistema central, por lo que los sistemas monitoreados no tienen ningún componente para desinstalar. Para desinstalar New Relic de un sistema monitoreado, elimine el acceso creado para la recopilación de datos:

1. En la transacción `SU01`, elimine el <DNT>**ABAP user account**</DNT> de New Relic designado que se utiliza para la recopilación de datos.
2. Elimine el rol de autorización de New Relic asociado (nombres con el prefijo `/NEWR/*`).

## Verificar la desinstalación

Después de completar el proceso de desinstalación:

* El componente <DNT>**NEWR**</DNT> ya no debería aparecer en la pestaña <DNT>**Installed Components**</DNT>
* Los trabajos de recopilación de datos en la transacción `SM37` ya no se ejecutarán
* New Relic dejará de recibir datos de monitoreo de este sistema

**Nota**: los datos históricos de monitoreo en New Relic permanecerán accesibles. Solo se elimina el componente de recopilación de datos del sistema SAP.
