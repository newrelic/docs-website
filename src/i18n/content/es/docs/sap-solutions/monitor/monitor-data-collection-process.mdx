Esta guía le muestra cómo monitorear el proceso de recopilación de datos para New Relic Monitoring for SAP Solutions. Puede usar múltiples métodos para verificar que la recopilación de datos esté funcionando correctamente.

## Requisitos previos

* Acceso a <DNT>**SAP system**</DNT> con los permisos de transacción apropiados
* <DNT>**New Relic Monitoring for SAP Solutions**</DNT> instalado y configurado

## Estado de ejecución y log de transmisión

Abra el <DNT>**Data Provider Registry**</DNT> (transacción `/NEWR/REGISTRY`) para comprobar el estado de tiempo de ejecución y los detalles de transmisión para cada proveedor de datos. Haga clic en <DNT>**RuntimeStatus**</DNT> para ver la hora de la última ejecución y el estado actual. Haga clic en <DNT>**Transmission Log**</DNT> para ver el tiempo de transmisión, el código de respuesta HTTP y el estado de transmisión para cada registro enviado a New Relic.

## Comprobar el estado del trabajo y el spool

1. Utilice la transacción `SM37` para comprobar el estado de los trabajos programados. Ingrese `/NEWR/*` en el campo <DNT>**ABAP Program Name**</DNT> y haga clic en <DNT>**Execute**</DNT>.
2. Revise la duración de la ejecución. Un tiempo de ejecución anormalmente largo indica un posible problema.
3. Verifique si hay trabajos superpuestos y ajuste la programación según sea necesario.
4. Abra el spool del trabajo desde los detalles del trabajo. El spool muestra el timestamp de recolección, el estado de transmisión y el resultado para cada proveedor de datos.
5. Utilice el número de trabajo para correlacionar las entradas de spool con el log de transmisión en el <DNT>**Data Provider Registry**</DNT>.

## Consultar log de aplicación

Los procesos de recopilación de datos se registran en el log de aplicación (transacción `SLG1`). Consulta con el <DNT>**Application Log Object**</DNT> `/NEWR/DP`.

Para los proveedores de datos asincrónicos (aquellos con el sufijo `_COMPLETE`), el spool de trabajos no incluye sus registros. Revise el log de aplicación usando la subcategoría <DNT>**`/NEWR/DP_AGENT`**</DNT> para ver sus detalles de recopilación y transmisión.

## Dashboard de monitoreo de recopilación de datos de SAP

Los datos métricos de recolección de datos también son enviados a New Relic para auto-monitoreo. Emplee el dashboard <DNT>**SAP Data Collection Monitoring**</DNT> listo para usar para monitorear los procesos de recopilación de datos para cada proveedor de datos. Para obtener instrucciones de instalación, consulte [Instalar componentes de monitoreo](/docs/sap-solutions/install-and-configure/install-out-of-the-box).
