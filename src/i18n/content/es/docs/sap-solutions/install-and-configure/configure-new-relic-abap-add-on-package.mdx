Después de instalar el complemento ABAP, use el menú <DNT>**`/NEWR/INSTALL`**</DNT> para conectar los sistemas SAP a New Relic, configurar los extremos de API, definir los grupos de monitoreo y verificar la configuración.

## Use el menú /NEWR/INSTALL [#menu-newr-install]

1. Inicie sesión en el cliente de producción del sistema de monitoreo central.
2. Escriba `/n` en el campo de comando y presione <DNT>**Enter**</DNT> para ir a <DNT>**SAP Easy Access root menu**</DNT>.
3. Escriba `/n/NEWR/INSTALL` en el campo de comandos para abrir el menú <DNT>**`/NEWR/INSTALL`**</DNT>.

Antes de configurar, asegúrese de lo siguiente:

* El instalador tiene la autorización adecuada para realizar la configuración.
* El parámetro `/NEWR/*` se agrega al objeto de autorización `S_TCODE` en el `profile/role` del instalador.

<Callout variant="tip">
  Si actualiza desde una versión anterior, consulte [Actualizar desde una versión anterior](/docs/sap-solutions/upgrade/install-upgrade-package) para determinar qué pasos son necesarios.
</Callout>

## Conectar sistemas [#connect-systems]

<Callout variant="important">
  Complete cualquier paso de configuración pendiente antes de continuar.
</Callout>

En el menú `/NEWR/INSTALL`, abra la carpeta <DNT>**Install New Release and Patch**</DNT> y complete los siguientes pasos.

### Configuración de destino RFC estándar

Emplee la transacción `SM59` para configurar conexiones <DNT>**RFC**</DNT> y <DNT>**HTTPS**</DNT> para sistemas monitoreados en las instalaciones:

* Para la configuración de RFC, consulte [Destino RFC estándar](/docs/sap-solutions/install-and-configure/additional-configuration/#standard-rfc-destination) y [Establecer el destino HTTP en New Relic cloud](/docs/sap-solutions/install-and-configure/additional-configuration/#set-http-destination-to-new-relic-cloud).

### Configuración de RFC de SAP Cloud/Business Technology Platform (BTP)

Emplee la transacción `SM59` para configurar destinos HTTP para sistemas alojados en BTP:

* Para la autenticación BTP/CALM, consulte [Destino RFC de Cloud (BTP)](/docs/sap-solutions/install-and-configure/additional-configuration/#cloud-btp-rfc-destination).
* Si monitorea un <DNT>**SAP Cloud Connector**</DNT>, configure un destino RFC de tipo <DNT>**G**</DNT> (HTTP externo) mediante el puerto <DNT>**8443**</DNT> (puerto de administración HTTPS predeterminado de Cloud Connector). La cuenta de usuario debe tener las autorizaciones y la contraseña requeridas.

### Configure la conexión a la base de datos remota

Si no completó este paso durante la preinstalación, complételo ahora.

* Abra la transacción de SAP `DBACOCKPIT` para verificar las conexiones a <DNT>**HANA databases**</DNT> remoto.
* Cree una conexión de base de datos para cada base de datos HANA remota que desee monitorear.
* Para obtener instrucciones detalladas, consulte [Crear conexión de base de datos](/docs/sap-solutions/install-and-configure/additional-configuration/#create-database-connection).

### Configurar conexiones a los extremos de API de New Relic

Puede configurar varias cuentas de New Relic en esta sección.

1. Haga clic en <DNT>**New Entries**</DNT>.

2. Ingresa los detalles de tu cuenta de New Relic:

   * <DNT>**New Relic Account ID**</DNT> (opcionalmente con el prefijo SAP-)
   * <DNT>**API Ingest Key**</DNT>
   * <DNT>**Metric Endpoint**</DNT> (consulte [Extremos de red](/docs/sap-solutions/before-you-begin/#network-endpoints))
   * <DNT>**Event Endpoint**</DNT>
   * <DNT>**Log Endpoint**</DNT>
   * <DNT>**Trace Endpoint**</DNT>

3. Haga clic en <DNT>**Save**</DNT>.

### Definir los sistemas monitoreados

1. Haga clic en <DNT>**New Entries**</DNT> e ingrese el <DNT>**SAP System ID**</DNT> y el número de <DNT>**Client**</DNT>.

2. En <DNT>**Data Provider Installation Information**</DNT>, proporcione lo siguiente:

   * <DNT>**RFC Destination**</DNT>
   * <DNT>**SAP Software Component**</DNT>
   * <DNT>**Database Vendor**</DNT>
   * <DNT>**DB Connection Name**</DNT> (Solo bases de datos HANA)
   * <DNT>**New Relic Account ID**</DNT> (opcional) —si se proporciona, los datos de este sistema van solo a esa cuenta, anulando la cuenta en la variante de trabajo del administrador de recopilación. Si se deja en blanco, el sistema usa la cuenta de la variante de trabajo del administrador de recopilación.

3. Haga clic en <DNT>**Monitoring Group**</DNT> y seleccione <DNT>**Yes**</DNT> para confirmar.

4. Seleccione los grupos de monitoreo requeridos y haga clic en el icono de generar.

5. Haga clic en <DNT>**BACK**</DNT> o presione <DNT>**F3**</DNT> para continuar.

### Cuentas de BTP/CALM

Cuando el monitoreo de BTP está activo, agregue las cuentas de BTP/CALM como sistemas monitoreados. Utilice los siguientes valores:

* <DNT>**SAP System ID**</DNT>: use un seudónimo o alias. No use términos reservados como `CALM` o `BTP`.
* <DNT>**Client**</DNT>: dejar en blanco.
* <DNT>**Destination**</DNT>: ingrese el destino HTTP de autenticación.
* <DNT>**Software Component**</DNT>: dejar en blanco.
* <DNT>**Database Vendor**</DNT>: dejar en blanco.
* <DNT>**DB Connection Name**</DNT>: dejar en blanco.
* <DNT>**New Relic Account ID**</DNT>: ingrese la cuenta específica de New Relic designada para recibir los datos.
* <DNT>**API Host**</DNT>: Ingrese el nombre de host de la API. Esto corresponde al valor `url` en la clave de servicio.

En la siguiente pantalla, haga clic en <DNT>**Monitoring Group**</DNT>. Elija los grupos de monitoreo adecuados para el sistema y haga clic en <DNT>**Finish**</DNT>.

### Verificar destinos RFC

Use esta opción para verificar los destinos de RFC para los extremos de API de New Relic y cada sistema monitoreado. Esta prueba excluye el destino de RFC designado como <DNT>**NONE**</DNT>.

## Generar configuración [#generate-configurations]

### Generar configuraciones para nuevos proveedores de datos

* Ejecute esta opción para generar todos los proveedores de datos nuevos para una nueva versión o parche. Para instalaciones nuevas, este único paso genera todos los proveedores de datos.
* En la primera pantalla, confirme los detalles de la versión y el parche. Si los campos de versión y parche de la instalación están en blanco, la configuración ya está establecida.
* Para regenerar las configuraciones, navegue hasta <DNT>**Maintain Monitored Systems**</DNT> y seleccione <DNT>**Re-generate Data Provider Configurations**</DNT>. También puede seleccionar <DNT>**Reset Installation Flag (For Re-install only)**</DNT> para borrar la marca de instalación actual y regenerar.

<Callout variant="tip">
  Para los proveedores de datos basados en CALM, consulte [Generar entradas de registro para proveedores de datos de CALM](/docs/sap-solutions/monitor/data-providers-reference).
</Callout>

<img title="Maintain Monitored Systems" alt="A screenshot displaying the SAP maintain monitored systems" src="/images/maintain-monitored-systems.webp" width="500" />

### Verificar la integridad de la instalación

Seleccione <DNT>**Verify Installation Completeness**</DNT>. Si algún componente muestra un indicador rojo, haga clic en el botón de ejecución en la columna <DNT>**Action Needed**</DNT> para resolver el problema.

## Verifique la configuración [#verify-configuration]

1. Abra la carpeta <DNT>**Data Provider Registry Maintenance**</DNT>.
2. Haga clic en <DNT>**Data Provider Registry**</DNT> o emplee la transacción `/n/NEWR/REGISTRY`.
3. Seleccione un <DNT>**Data Provider Name**</DNT> y haga clic en <DNT>**Configure**</DNT> para verificar los ajustes de configuración, o haga clic en <DNT>**Test**</DNT> para verificar la funcionalidad del proveedor.
4. Haga clic en <DNT>**RuntimeStatus**</DNT> y elimine todas las entradas en la pantalla de estado de Runtime.
