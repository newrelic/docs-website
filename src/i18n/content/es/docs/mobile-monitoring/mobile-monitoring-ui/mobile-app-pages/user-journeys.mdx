Trayectos del usuario móviles visualiza cómo el usuario final navega por su aplicación móvil en conjunto. Revela patrones en el comportamiento del usuario — a dónde va el usuario después de abrir la aplicación, dónde se atasca y qué rutas conducen a los resultados que le interesan.

<img title="Mobile User Journeys Sankey diagram" alt="A Sankey diagram showing user navigation paths through a mobile app, with nodes representing screens and paths sized by user volume" src="/images/mobile_screenshot-full_user-journeys-sankey.png" />

<Callout variant="important">
  <DNT>Mobile User Journeys</DNT> está disponible actualmente dentro de la experiencia <DNT>**Errors**</DNT> en la UI de monitoreo de móviles de New Relic. Se planea una vista <DNT>Mobile User Journeys</DNT> independiente (similar a la característica [Browser User Journeys](/docs/browser/browser-monitoring/browser-pro-features/user-journeys/)) para un lanzamiento futuro.
</Callout>

## Cómo acceder [#access]

<DNT>Mobile User Journeys</DNT> está disponible en las cuatro secciones bajo <DNT>**Triage**</DNT> en la navegación izquierda: <DNT>**Crashes**</DNT>, <DNT>**Request errors**</DNT>, <DNT>**Handled exceptions**</DNT> y <DNT>**ANRs**</DNT>. Cómo llegar depende de dónde provenga:

<img title="Mobile Triage navigation showing Crashes, Request errors, Handled exceptions, and ANRs" alt="The New Relic Mobile left navigation with the Triage section expanded, showing Crashes, Request errors, Handled exceptions, and ANRs" src="/images/mobile_screenshot-full_user-journeys-triage-nav.png" />

**Desde la pestaña Triage:**

1. Vaya a **[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; <DNT>Mobile</DNT>**.
2. Seleccione su aplicación móvil.
3. En la navegación izquierda, bajo <DNT>**Triage**</DNT>, haga clic en <DNT>**Crashes**</DNT> o <DNT>**Request errors**</DNT>.
4. Desde <DNT>error groups</DNT>, seleccione el que desea investigar para abrir la vista de detalles del error.
5. En la vista de detalles, haga clic en el enlace <DNT>**User Journeys**</DNT> para ver las rutas de navegación que llevaron al error.

**Desde la pestaña &quot;Group crashes or error&quot;:**

1. Vaya a **[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; <DNT>Mobile</DNT>**.
2. Seleccione su aplicación móvil.
3. En la navegación izquierda, bajo <DNT>**Triage**</DNT>, haga clic en <DNT>**Crashes**</DNT> o <DNT>**Request errors**</DNT>.
4. Haga clic en la pestaña <DNT>**Group crashes**</DNT> o <DNT>**Group request errors**</DNT>.
5. Seleccione el grupo de fallas o errores que desea investigar para abrir la vista de detalles del grupo.
6. En <DNT>**Triage**</DNT>, haga clic en el enlace <DNT>**User Journeys**</DNT> para ver las rutas de navegación que llevaron al error.

## Cómo usar Mobile User Journeys [#how-to-use]

### Diagrama de Sankey [#sankey]

La visualización <DNT>User Journeys</DNT> usa un diagrama de Sankey para mostrar el flujo de usuario entre pantallas. Cada nodo representa una pantalla o interacción en su aplicación, y el ancho de cada ruta de conexión refleja el número de usuario que siguió esa ruta.

Elementos clave del diagrama:

* **Nodos**: Pantallas individuales o interacción en la aplicación.
* **Rutas**: Conexiones entre nodos, dimensionadas proporcionalmente al volumen de usuario que siguió esa ruta.
* **Puntos de entrada**: Las pantallas donde comienzan las sesiones de usuario.
* **Puntos de salida**: Las pantallas donde el usuario terminó su sesión o desencadenó un error.

Cuando se ve desde dentro de un grupo de errores, la visualización se ancla automáticamente en las sesiones que experimentaron ese error, para que pueda trazar las rutas de navegación que precedieron a la falla.

### Detalles de ruta y evento [#path-details]

Haga clic en cualquier nodo o ruta en el diagrama para desglosar las sesiones que siguieron esa ruta exacta. Esto abre una vista dividida con dos paneles:

<img title="Mobile User Journeys crash detail view" alt="Split view showing the Profiles panel on the left with attribute distribution and the Sessions table on the right listing affected sessions" src="/images/mobile_screenshot-full_user-journeys-crash-detail.png" />

* <DNT>**Profiles**</DNT>: muestra la distribución de los valores de atributos (como la versión de la aplicación, el dispositivo, el sistema operativo, la arquitectura y los detalles del bloqueo) en las sesiones que siguieron la ruta seleccionada. Utilice esto para identificar puntos en común entre los usuarios afectados.
* <DNT>**Sessions that include this event**</DNT>: Una tabla que enumera las sesiones individuales, incluyendo el ID de usuario, la fecha, el recuento de ocurrencias, la versión de la aplicación, el dispositivo, la versión del sistema operativo y el operador. Haga clic en cualquier sesión para abrir la página <DNT>Event Trail Drilldown</DNT>.

### Desglose de la traza de evento [#event-trail]

Haga clic en una sesión en la tabla de sesiones para abrir la página <DNT>**Event Trail Drilldown**</DNT> — una línea de tiempo cronológica de cada evento registrado en esa sesión.

<img title="Mobile User Journeys Event Trail Drilldown" alt="The Event Trail Drilldown showing a chronological list of Interaction and Crash events with expandable attribute details" src="/images/mobile_screenshot-full_user-journeys-event-trail.png" />

En el <DNT>Event Trail Drilldown</DNT> puede:

* <DNT>**Filter by event type**</DNT>: utilice los botones <DNT>**Interaction**</DNT> y <DNT>**Crash**</DNT> para centrarse en tipos de eventos específicos.
* <DNT>**Expand event details**</DNT>: Haga clic en cualquier evento para ver su carga de atributo completa — incluyendo metadatos de fallas como `diskAvailable`, `osBuild`, `processName`, `timeSinceLastInteraction` y `interactionHistory`.

Esta vista le permite reconstruir los pasos exactos que dio un usuario antes de que ocurriera una falla, hasta la interacción de pantalla individual.

## Cómo personalizar la visualización [#customize]

### Filtro de tipo de evento [#event-type]

<img title="Mobile User Journeys event type filter" alt="The event type filter dropdown showing options: Crash, Breadcrumb, Interaction, User action, Handled exception, JavaScript error, Request error, Custom, ANR" src="/images/mobile_screenshot-crop_user-journeys-event-type-filter.png" />

Use el filtro <DNT>**Event type**</DNT> para elegir qué tipos de eventos aparecen como nodos en el diagrama. Puede incluir cualquier combinación de:

* Crash
* Breadcrumb
* Interaction
* User action
* Handled exception
* JavaScript error
* Request error
* Costumbre
* ANR

### Version de aplicacion [#app-version]

Use el filtro <DNT>**App version**</DNT> para enfocarse en los trayectos de un lanzamiento específico. Esto es útil para comparar el comportamiento del usuario antes y después de un despliegue para identificar regresiones o mejoras.

### Filtrar por atributo de usuario [#user-attributes]

Use la barra de filtros para reducir los resultados por atributos adicionales como el tipo de dispositivo, la versión del sistema operativo, la geografía o los atributos personalizados que ha instrumentado con el [Mobile SDK](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/mobile-sdk-api-guide/).
