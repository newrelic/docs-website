### Nueva característica

* **Soporte para rastreo distribuido**

  El rastreo distribuido le permite ver el camino que sigue una solicitud a medida que viaja a través de sus sistemas distribuidos. Al mostrar la actividad distribuida a través de una vista unificada, puede solucionar problemas y comprender un sistema complejo mejor que nunca.

  El rastreo distribuido está disponible con una suscripción APM Pro o equivalente. Para ver un rastreo distribuido completo, debe habilitar la característica en un conjunto de servicios vecinos.

  Consulte la [documentación del SDK de C](https://docs.newrelic.com/docs/agents/c-sdk/instrumentation/enable-distributed-tracing-your-c-applications) de New Relic para obtener más información sobre cómo habilitar el rastreo distribuido para el SDK de C.

### Aviso de fin de vida útil

* Los campos `log_filename` y `log_level` de `newrelic_app_config_t` están obsoletos actualmente. Las versiones futuras del SDK de C eliminarán estos campos de forma permanente. Para especificar el archivo de log y el nivel de logs que se utilizarán con el SDK de C, utilice `newrelic_configure_log()`.
