Administrar el acceso de sus usuarios a New Relic ahora es más fácil. Hemos mejorado la [página de la UI de**Access management** ](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-ui-and-tasks#where)para que esté más enfocada en los grupos. Ahora puede comprender más rápidamente a qué roles y cuentas tienen acceso sus grupos, crear grupos y editar el acceso de los grupos.

También hemos simplificado cómo administra las características administrativas de nivel superior. Anteriormente teníamos roles separados a nivel de organización para estas capacidades. Ahora, la configuración administrativa a nivel de organización (como la facturación, la configuración de la organización y la configuración del dominio de autenticación) se puede asignar fácilmente a un grupo desde la página de la UI **Grupos**.

Aprender más:

* Consulte la página de la UI de **administración de acceso**
* [Lea cómo asignar acceso de grupo](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial#group-access)
* [Lea sobre la configuración de administración](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts#admin-settings)
