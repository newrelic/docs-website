### Nueva característica

* **Soporte para streaming en tiempo real**

  * Los datos de eventos ahora se envían a New Relic cada cinco segundos, en lugar de cada minuto. Como resultado, los eventos de transacción, error y personalizados ahora estarán disponibles en los dashboards de New Relic casi en tiempo real. Para obtener más información sobre cómo ver sus eventos con una actualización de cinco segundos, consulte la [documentación de transmisión en tiempo real](/docs/agents/manage-apm-agents/agent-data/real-time-streaming).
  * Tenga en cuenta que los límites generales sobre cuántos eventos se pueden enviar por minuto no han cambiado. Además, los eventos de span, las métricas y los datos de traza no se ven afectados, y se seguirán enviando cada minuto.

### Corrección de errores

* Una configuración predeterminada creada con `newrelic_create_app_config()` ahora funcionará como se espera con las claves de licencia para cuentas que no son de EE. UU.

* Para las cargas de rastreo distribuido entrantes con valores no válidos o faltantes para `pr` (prioridad) y/o `sa` (muestreado), el agente solía asignar una prioridad predeterminada de -1 y/o un valor muestreado predeterminado de `false` a la transacción.

  Esto se ha solucionado: el agente ahora mantiene la prioridad inicial y los valores muestreados si los valores respectivos en la carga de rastreo distribuido entrante faltan o no son válidos.
