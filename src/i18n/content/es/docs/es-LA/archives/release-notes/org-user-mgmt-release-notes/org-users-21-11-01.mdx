## Gestión automatizada de usuarios ahora disponible para la edición Pro

La característica de [administración automatizada de usuarios](/docs/accounts/accounts/automated-user-management/automated-user-provisioning-single-sign) de New Relic ahora está disponible para las organizaciones con la [edición Pro](https://newrelic.com/pricing) de New Relic. Anteriormente, esto solo estaba disponible para las organizaciones con la edición Enterprise.

La administración automatizada de usuarios permite usar el aprovisionamiento de SCIM para importar, actualizar y desactivar sus usuarios de New Relic desde un proveedor de identidad, como Azure AD, Okta o OneLogin. También puede administrar atributos sobre sus usuarios, incluidos el tipo de usuario y la zona horaria, a través de su proveedor de identidad.
