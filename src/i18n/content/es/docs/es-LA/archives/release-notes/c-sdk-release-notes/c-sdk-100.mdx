### Nueva característica

¡Esta es la primera versión del SDK de C de New Relic! Si su aplicación no usa [otros lenguajes del agente APM de New Relic](https://docs.newrelic.com/docs/agents/manage-apm-agents/installation/compatibility-requirements-new-relic-agents-products#apm-compatibility), puede usar el SDK de C para aprovechar las capacidades de monitoreo y las características de New Relic para instrumentar una amplia gama de aplicaciones.

Para más información, ver:

* [Documentación](/docs/agents/c-sdk): cómo comenzar con el SDK de C, instalarlo y configurarlo, instrumentar transacciones, segmentos y errores, usar la API del SDK de C y realizar una resolución de problemas básica.
* [GitHub](https://newrelic.github.io/c-sdk/index.html): archivos del SDK, estructura de datos, definiciones de campos y parámetros, ejemplos de código, funciones, variables.

### Aviso de fin de vida útil

El SDK del agente APM anterior es un software beta obsoleto. Si usaba anteriormente el SDK del agente, puede cambiar al SDK de C. Consulte la [compatibilidad y los requisitos](/docs/c-sdk-compatibility-requirements), y luego [instrumente, compile y vincule](/docs/install-c-sdk-compile-link-your-code) el código de su aplicación para usar el SDK de C. Actualmente, el SDK de C no es compatible con la característica HSM de New Relic; esto puede afectar la forma en que programa su transición desde el SDK del agente.
