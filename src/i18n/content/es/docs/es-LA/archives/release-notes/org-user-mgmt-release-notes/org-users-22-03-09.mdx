Con esta versión, los [usuarios principales](/docs/accounts/accounts-billing/new-relic-one-user-management/user-type/#user-type-capabilities) pueden administrar usuarios y administrar la facturación. Pueden:

* Realice tareas de administración de usuarios si tienen el [rol estándar de**administrador de dominio de autenticación** ](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts#roles).
* Realice tareas administrativas de facturación si tienen el [rol estándar de**usuario de facturación** ](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts#roles).
