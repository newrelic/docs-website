Lanzamos la capacidad de exportar datos de usuario desde la UI de **User management**. Los datos son exportables a través de TSV. Las columnas exportables incluyen los nombres de los usuarios, las direcciones de correo electrónico, el tipo de usuario actual, los grupos y el ID de usuario. Los administradores pueden elegir exportar todos los usuarios o seleccionar un subconjunto de usuarios.

Para obtener más detalles, consulte [Exportar lista de usuarios](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-ui-and-tasks).
