## Nueva versión del modelo de precios de New Relic One con usuarios principales

Lanzamos una nueva versión del [modelo de precios de New Relic One](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/new-relic-one-pricing-billing) con un nuevo [tipo de usuario](/docs/accounts/accounts-billing/new-relic-one-user-management/user-type): el usuario principal. Las organizaciones en esta versión de precios tienen acceso a tres tipos de usuarios: usuarios básicos, usuarios principales y usuarios de plataforma completa. El usuario principal tiene más acceso que los usuarios básicos y cuesta menos que un usuario de plataforma completa. Los usuarios principales tienen acceso a algunas características poderosas centradas en desarrolladores como New Relic CodeStream, nuestra UI de logs y la capacidad de crear aplicaciones de New Relic.

Esta versión de precios también [calcula los usuarios facturables de manera diferente](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/user-count-billing#user-count) y tiene [diferentes reglas de degradación de usuario](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/user-count-billing/#user-downgrade-rules).

Para obtener más información sobre esta versión y sobre la disponibilidad, consulte [Lanzamiento de usuarios Core](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/core-users-release).
