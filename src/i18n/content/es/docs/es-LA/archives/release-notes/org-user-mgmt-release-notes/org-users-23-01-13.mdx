Cambiamos la ubicación de algunas configuraciones del [dominio de autenticación](https://docs.newrelic.com/docs/accounts/accounts-billing/new-relic-one-user-management/authentication-domains-saml-sso-scim-more). Los cambios incluyen:

* Ubicamos la UI de **Dominios de autenticación** en el [menú de la UI de**Administración** ](https://docs.newrelic.com/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-ui-and-tasks/#where).
* Movimos la configuración de la sesión del usuario y la configuración de actualización del usuario a la página de la UI **Gestión de usuarios**.
