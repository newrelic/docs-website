Ahora puede consultar el nombre, el ID de usuario, el tipo de usuario, el correo electrónico y la última fecha de actividad de un usuario con nuestra API de NerdGraph. También puede actualizar el tipo de usuario y la dirección de correo electrónico de un usuario.

Para obtener más información, consulte [la documentación de NerdGraph](/docs/apis/nerdgraph/examples/nerdgraph-manage-users).
