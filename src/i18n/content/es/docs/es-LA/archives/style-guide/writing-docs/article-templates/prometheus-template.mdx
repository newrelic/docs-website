## Habilitar la integración

Las métricas de Prometheus deben integrarse con New Relic, puede usar el agente de Prometheus o la integración de Remote Write, consulte [cómo enviar métricas de Prometheus](https://docs.newrelic.com/docs/infrastructure/prometheus-integrations/get-started/send-prometheus-metric-data-new-relic/).

Una vez integrado, utilice la siguiente consulta para confirmar que las métricas se están ingiriendo como se espera:

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'integrationName_%' FACET metricName LIMIT MAX
```

Las entidades de integración también son visibles en el [explorador de entidades](/docs/new-relic-solutions/new-relic-one/core-concepts/new-relic-explorer-view-performance-across-apps-services-hosts#find) con métricas doradas asociadas y un dashboard integrado.

## Encuentra y usa los datos.

### Métrica

Prometheus métrica se almacenan como dimensionales métricas. Puede [consultar usando NRQL](/docs/telemetry-data-platform/get-data/apis/query-metric-data-type/) o usar el [Explorador de datos](/docs/query-your-data/explore-query-data/browse-data/introduction-data-explorer/) para explorar las métricas disponibles, facetas y filtrar por dimensiones asociadas.

Los diferentes conjuntos de métricas expuestos por \[agregue aquí el nombre de la integración] se definen en la \[documentación de Integration\_name]\(agregue un enlace a la documentación del proveedor).

Utilice la siguiente consulta NRQL para comprender la métrica que se ingiere en New Relic:

* Lista de nombres métricos únicos:

  ```sql
  FROM Metric SELECT uniques(metricName) WHERE metricName LIKE 'integrationName_%' LIMIT MAX
  ```

* Cuente el número de actualizaciones métricas:

  ```sql
  FROM Metric SELECT datapointcount() WHERE metricName LIKE 'integrationName_%' FACET metricName
  ```

* Estimar la ingesta de datos (ingesta diaria, en bytes):

  ```sql
  FROM Metric SELECT bytecountestimate() WHERE metricName LIKE 'integrationName_%' SINCE 1 day ago
  ```
