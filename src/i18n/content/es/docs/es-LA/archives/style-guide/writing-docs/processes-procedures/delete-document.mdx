---
title: Borrar un documento
translationType: machine
---

<Callout variant="caution">
  Cuando elimina un documento, su contenido y sus redireccionamientos seguirán estando disponibles en el historial de commits de GitHub.
</Callout>

Para eliminar un documento:

1. Ubique el archivo MDX del documento que desea eliminar.

2. Gestione los redireccionamientos:

   1. Encuentre el documento más relevante para redirigir a los lectores.
   2. [Agregue la URL del documento eliminado como redireccionamiento](/docs/style-guide/rename-or-redirect-document).
   3. Copie cualquier redireccionamiento existente del documento eliminado y agréguelo al nuevo documento.

3. Elimine el título y la ruta del documento del archivo de navegación correspondiente.

4. Elimine el archivo MDX del documento.

5. Elimine los archivos MDX correspondientes del directorio `src/i18n/content`. Para cada documento en inglés, hay un archivo MDX para cada uno de los idiomas localizados. Puede usar el script `i18n-utility` para hacer esto automáticamente:
   ```bash
   yarn i18n-utility delete-orphans
   ```
