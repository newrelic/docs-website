Swiftype es el motor de búsqueda basado en elastic que impulsa la búsqueda en `docs.newrelic.com`.

Como escritor técnico en New Relic, es posible que deba iniciar sesión en Swiftype y realizar diversas tareas para asegurarse de que sus documentos sean reconocidos durante las búsquedas internas.

## Información del rastreador de Swiftype [#crawler-info]

El rastreador dice que rastrea cada 12 horas. La velocidad a la que rastrea es relativamente lenta, lo que significa que podría tardar más que eso en detectar los cambios de la página. También utiliza alguna combinación de `sitemap.xml` y recopilación de enlaces al rastrear.

Podemos activar un rastreo manual una vez cada 12 horas, si es necesario. O bien, podemos hacer que Swiftype rastree páginas específicas cuando sea necesario.

El tiempo promedio de reindexación de los documentos es de cuatro días.

## Agregar manualmente una nueva página al índice de Swiftype [#manually-index]

Es posible que desee agregar manualmente una nueva página al índice de Swiftype cuando el rastreo sea demasiado lento y desee que la página esté disponible de inmediato.

Para agregar manualmente una nueva página en Swiftype:

1. Asegúrese de que su tipo de documento no esté en la lista de ignorados yendo a **Domains &gt; [https://docs.newrelic.com/](https://docs.newrelic.com/)**.

2. Vaya a **New Relic &gt; Content**.

3. En el cuadro de entrada de texto que dice **Filter pages**, pegue la URL de la página que desea indexar.

4. Si la página no está en el índice, Swiftype proporcionará la opción de **Add this URL**. Haga clic en esa opción para agregar la página al índice.

5. Inserte la URL, asegurándose de hacer lo siguiente:

   * Use la URL completa de la siguiente manera: `https://docs.newrelic.com/docs/path/to/doc/`
   * Asegúrese de que la URL tenga una barra diagonal al final

Swiftype debería indexarla en un minuto más o menos. Para comprobar si está indexada, actualice la página y pegue la URL. Tenga en cuenta que a veces la UI de administración está en caché o se retrasa. Puede pedirle a un colega que lo compruebe, usar la API REST para comprobarlo, borrar la caché o volver a cargar la página y comprobar de nuevo.

## Actualizar manualmente el registro de Swiftype existente [#manual-index]

De manera similar a agregar manualmente una nueva página al índice, puede actualizar un registro existente si el rastreo es demasiado lento y desea que el índice se actualice de inmediato. Utilice este método si ha cambiado la URL de una página y la URL antigua se redirige a la nueva. Para una discusión más extensa sobre esto, consulte la sección [cambio de URL](#url-changes) a continuación.

Para actualizar o reindexar manualmente un registro existente:

1. Vaya a **New Relic &gt; Content**.
2. Pegue la URL antigua (con la que se indexó la página por última vez).
3. Si se encuentra en el índice, debería ver la entrada correspondiente, así que seleccione **Detalles**.
4. En la página de detalles del registro, seleccione **Reindexar**.
5. Vuelva a agregar la clasificación para este documento siguiendo los pasos en [Clasificar resultados para un término de búsqueda determinado](#rank-results).

Swiftype debería volver a indexar en un minuto. Tenga en cuenta que ese registro se eliminará del índice, junto con cualquier clasificación personalizada que haya establecido para él, y se crea un nuevo registro para la nueva URL a la que se redirigió el rastreador. Por lo tanto, prepárese para actualizar las clasificaciones de los resultados.

## Eliminar manualmente el registro de swiftype existente [#remove-records]

Es posible que desee eliminar manualmente un registro existente del índice en estos casos:

* Cuando desee eliminar rápidamente un registro de una página que se eliminó sin redireccionamientos
* Si nota que hay más de un registro para una página que cambió de URL recientemente (uno para la URL antigua, uno para la nueva que se descubrió fuera de la redirección).

Para eliminar manualmente un registro del índice:

1. Vaya a **New Relic &gt; Content**.
2. Pegue la URL del registro que desea eliminar.
3. Seleccione **Detalles**.
4. Seleccione **Eliminar este documento** en la parte inferior de la página **Detalles**.

## Clasificar los resultados para un término de búsqueda determinado [#rank-results]

Clasifique los resultados para términos de búsqueda dados para mover ciertas páginas más arriba o más abajo en los resultados. También puede excluir un registro de los resultados para un término de búsqueda dado.

Dado que las páginas de todos nuestros sitios web son manejadas por un solo motor, esto desordena la lista de clasificación. Es mejor buscar URL específicas en lugar de navegar por las URL de las páginas relevantes.

<Callout variant="tip">
  Si una URL cambia para un registro determinado, la clasificación de los resultados se pierde y debe agregarse para el nuevo registro asociado con la nueva URL.
</Callout>

Para clasificar los resultados:

1. Vaya a **New Relic &gt; Result Rankings**.
2. Ingrese en la entrada de texto el término de búsqueda por el que desea clasificar (el uso de mayúsculas no importa).
3. Arrastre los resultados más arriba o más abajo. Es probable que desee buscar la URL de la página, fijarla y moverla.
4. Elimine un resultado seleccionando el botón **X** en el resultado.

Para obtener más detalles, consulte la [documentación oficial de Swiftype](https://swiftype.com/documentation/site-search/guides/result-rankings).

## Agregar alias [#add-alias]

Cuando establece una clasificación de resultados, también puede agregar alias. Un alias es similar a un [sinónimo](#add-synonym), pero solo se aplica a un conjunto de resultados específico.

Para agregar alias:

1. Vaya a **New Relic &gt; Result Rankings**.
2. Ingrese el término de búsqueda.
3. Agregue el alias en la entrada de texto.

## Agregar sinónimo [#add-synonym]

Agregue sinónimos cuando desee que un término de búsqueda muestre los mismos resultados que otro. Ejemplos anteriores incluyen:

* RBAC = controles de acceso basados en roles
* servers = New Relic Infrastructure

Para agregar sinónimos, vaya a **New Relic &gt; Synonyms**.

Para obtener más información, consulte la [documentación oficial](https://swiftype.com/documentation/site-search/guides/synonyms).

## Mejor práctica: términos de búsqueda importantes [#important-search-terms]

Probablemente queramos asegurarnos de que los resultados estén clasificados y sean precisos para los términos de búsqueda que son:

* Se sabe que es muy vago con resultados ruidosos (ejemplo: navegador)
* Los términos de búsqueda más populares en nuestro sitio
* Términos del glosario

## Mejores prácticas: cambios de URL [#url-changes]

Si se cambia la URL de una página que ya está indexada, Swiftype eliminará ese registro asociado con la URL antigua. Y, si existe una redirección a una nueva URL, Swiftype creará un nuevo registro para la página que está asociada con la nueva URL. Cuando eso sucede, las clasificaciones de resultados para el registro antiguo se pierden y deben volver a agregarse para el nuevo registro con la nueva URL.

Activar un nuevo rastreo en Swiftype eventualmente solucionará esto, pero puede llevar mucho tiempo. Como alternativa, puede eliminar resultados específicos para páginas antiguas y decirle manualmente que indexe las nuevas. Esto *debería* sincronizarse con `docs-library-service` la próxima vez que actualice su caché para un término de búsqueda determinado.
