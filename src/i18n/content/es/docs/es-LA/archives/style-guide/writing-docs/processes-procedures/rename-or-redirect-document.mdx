Este documento describe cómo cambiar el título de un documento y cómo crear, editar y eliminar redireccionamientos. Los procedimientos son los mismos tanto para los documentos estándar (&quot;páginas básicas&quot;) como para las notas de la versión.

<Callout variant="caution">
  Cambiar los títulos o actualizar las redirecciones puede crear problemas para encontrar contenido. Si necesita cambiar un título o una redirección, [cree un issue en GitHub](https://github.com/newrelic/docs-website/issues/new/choose) o, si es un empleado de New Relic, comuníquese con el héroe de Docs a través del canal de Slack #help-documentation.
</Callout>

## Formato de URL [#title-url]

La URL de un documento se basa únicamente en su nombre de archivo y ruta de archivo en el repositorio de GitHub. Para obtener más información, consulte [URL del documento](/docs/style-guide/processes-procedures/understand-edit-docs-site-structure#doc-url).

## Cambiar títulos [#titles]

Para cambiar el título de un documento, cambie el título que se utiliza en el campo `title` en el frontmatter en la parte superior del documento.

Si desea actualizar un título en la barra lateral, cambie el `title` para ese documento en el archivo de navegación.

## Cambiar vínculos de anclaje [#anchors]

Siempre que sea posible, no cambie el `[#anchor_ids]` de un H2 o un elemento plegable. No hay forma de redirigir desde un anclaje eliminado a su nuevo valor. Incluso si el anclaje `id` está desactualizado, esto no afecta a la mayoría de los usuarios que no prestan atención a las URL.

## Editar redirecciones [#redirects]

Si cambia la URL de un documento, asegúrese de agregar la URL antigua a la sección de frontmatter `redirects` en la parte superior del documento.
