El equipo de documentación mantiene un diccionario de datos que almacena información de metadatos sobre los tipos de datos predeterminados en la base de datos de New Relic (por ejemplo, transacción, métrica, log) y sus atributos relacionados. Estos metadatos son publicados por nuestro servicio de diccionario de atributos en dos lugares:

* Las experiencias de consulta de la UI de New Relic muestran esta información cuando pasa el cursor sobre los tipos de datos y atributos.
* Los datos aparecen en el [diccionario de atributos](https://docs.newrelic.com/attribute-dictionary/) del sitio de documentación.

<Callout variant="tip">
  Estas son algunas limitaciones sobre el alcance de los datos:

  * Actualmente, la única información relacionada con la infraestructura que tenemos en el diccionario de atributos es para Kubernetes.
  * También tenemos muy pocos atributos para el tipo de datos de métrica —solo unos pocos básicos predeterminados— a pesar de los muchos atributos potenciales que podrían adjuntarse a algunos tipos de datos.
</Callout>

Si es escritor en New Relic y necesita hacer cambios en el diccionario de datos, hará sus cambios en nuestro repositorio privado en GitHub Enterprise. Consulte nuestra unidad de equipo interna de Google Doc sobre cómo configurar el repositorio y dónde encontrar las instrucciones del archivo README.md.
