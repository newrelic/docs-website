Bienvenido a la guía de estilo de New Relic. Hemos escrito estas pautas para los creadores de contenido de New Relic y para los colaboradores de nuestros proyectos de contenido de código abierto, como Docs o nuestros otros respositorios de GitHub de New Relic.

Esta guía no pretende cubrir todas las preguntas de uso. Para cualquier tema que no esté cubierto de forma explícita, nos remitimos a la [Microsoft Writing Style Guide](https://docs.microsoft.com/en-us/style-guide/welcome/) (en particular, a la &quot;A–Z word list&quot; y a la guía [Formatting common text elements](https://docs.microsoft.com/en-us/style-guide/text-formatting/formatting-common-text-elements)) o al [Chicago Manual of Style](https://www.chicagomanualofstyle.org/home.html) (para pautas generales de redacción y edición).

Seguimos las convenciones del inglés estadounidense, aunque si crea recursos específicos para un país, puede usar variaciones regionales del inglés. Por ejemplo, un PDF cuyo objetivo específico sean los clientes británicos también podría seguir las convenciones del inglés británico. Si tiene dudas, use el inglés estadounidense.

Encuentre la información que necesita:

* Para conocer nuestra estrategia de redacción, consulte los documentos de esta sección sobre [voz](/docs/style-guide/writing-strategies/voice-strategies-docs-sound-new-relic/), [cinco preguntas para un contenido excelente](/docs/style-guide/writing-strategies/five-questions-help-write-docs/), [cómo organizar su contenido](/docs/style-guide/writing-strategies/organize-doc) y más.

* Para obtener una referencia rápida sobre el uso de términos, consulte nuestro [Diccionario de uso](/docs/style-guide/word-choice/usage-dictionary).
