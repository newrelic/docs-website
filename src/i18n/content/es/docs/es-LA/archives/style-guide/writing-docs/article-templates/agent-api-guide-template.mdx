Introducción: esta sección presentará el agente y la API en términos generales. Hable sobre cuándo un usuario querría la API y las alternativas al uso de la API (por ejemplo, instrumentación a través de un archivo XML). Mencione que la API a menudo es innecesaria si su framework tiene soporte “listo para usar”. Enlace a la raíz de su referencia de la API, ya sea en el sitio o fuera de él. Advierta al usuario que debe estar en la versión más reciente del agente.

## instrumentar faltan secciones de tu código con transacción. [#creating-transactions]

Para instrumentar su aplicación, New Relic separa cada ruta a través de su código en su propia transacción. New Relic cronometra (o “instrumenta”) el método principal en estas transacciones para medir el rendimiento general de su aplicación, y recopila la traza de la transacción de las transacciones de larga duración para obtener detalles adicionales. Para obtener más información sobre las transacciones, consulte [transacción](/docs/accounts-partnerships/education/getting-started-new-relic/glossary#transaction) y [traza de la transacción](/docs/apm/transactions/transaction-traces/introduction-transaction-traces).
