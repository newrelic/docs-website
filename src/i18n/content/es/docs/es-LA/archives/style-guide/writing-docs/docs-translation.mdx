La documentación de New Relic existe en estos sitios:

* [**docs.newrelic.com**](https://docs.newrelic.com): Inglés
* [**docs.newrelic.com/jp/**](https://docs.newrelic.com/jp/): Japonés
* [**docs.newrelic.com/kr/**](https://docs.newrelic.com/kr/): Coreano
* [**docs.newrelic.com/es/**](https://docs.newrelic.com/es/): Español
* [**docs.newrelic.com/pt/**](https://docs.newrelic.com/pt/): Portugués
* [**docs.newrelic.com/fr/**](https://docs.newrelic.com/fr/): Francés

Puede alternar entre idiomas con un botón en la barra de menú superior.

## Ver el estado de la traducción [#translation-status]

El frontmatter de cada documento incluye su estado de traducción humana.

Si no hay un elemento `translate:` en el frontmatter, el documento no es traducido por humanos a ningún idioma. Aún así, se traducirá automáticamente a todos nuestros idiomas de traducción automática.

Si el elemento `translate:` tiene una abreviatura de idioma, como `jp`, entonces el documento ha sido traducido, será traducido o está bajo consideración para ser traducido. Por ejemplo:

```md
---
title: 'NRQL reference'
translate:
  - jp
  - kr
  - es
  - pt
  - fr
metaDescription: "A detailed reference list of clauses and functions in NRQL, the New Relic query language."
redirects:
  - /docs/insights/using-nrql
```

## Actualizar el documento traducido [#update-translation]

El sitio ejecuta una tarea automática una vez al día para traducir automáticamente los cambios en la documentación a los idiomas objetivo.

## Mostrar el estado de SEO de los documentos traducidos [#translation-seo]

El frontend del sitio utiliza la información del [estado de traducción](#translation-status) del documento para mostrar el elemento SEO `hreflang` para una página. Esto indica a los motores de búsqueda que la página también tiene una versión disponible en el idioma específico.

```html
<link rel="alternate" href="https://docs.newrelic.com/jp/" hreflang="ja" />
```

## Eliminar y mover documentos [#delete]

Cuando realiza cambios en nuestros documentos en inglés, es posible que obtenga un error de traducción no emparejada en GitHub. A continuación, se muestran escenarios en los que realizaría cambios en nuestra carpeta i18n:

* Cuando elimine un archivo mdx, elimine el archivo mdx correspondiente en las carpetas `/kr/` y `/jp/`. **No** actualice el archivo yaml.
* Cuando mueve un archivo mdx de la carpeta X a la carpeta Y, debe mover ese mismo archivo mdx a la carpeta Y en `/kr/` y `/jp/`. **No** actualice el archivo yaml.
* Cuando mueve un archivo mdx a una nueva carpeta, necesita crear esa nueva carpeta en `/kr/` y `/jp/`, luego mover el archivo mdx a ella. **No** actualice el archivo yaml.

En lugar de eliminar o mover archivos manualmente, ejecute estas secuencias de comandos:

* Para mover/cambiar el nombre de los archivos traducidos:

  ```bash
  yarn i18n-utility list-renames
  yarn i18n-utility make-renames
  ```

* Para eliminar archivos traducidos:

  ```bash
  yarn i18n-utility list-orphans
  yarn i18n-utility delete-orphans
  ```
