Este documento explica la diferencia entre títulos y títulos cortos. También profundiza en cómo estos se ven afectados y afectan a las rutas y redirecciones.

## Títulos

Los títulos son el título que se muestra en la parte superior de cada documento. El título de este documento es **Títulos, títulos cortos y rutas**.

El título de un documento se define en el front matter. El título de este documento se define a continuación:

```yaml
title: Titles, short titles, and paths
```

## Títulos cortos

Los títulos cortos se muestran en la navegación de la izquierda. Estos se utilizan en casos donde el título es demasiado largo para leerse fácilmente. El título corto de este documento es **Títulos y títulos cortos**.

El título corto se define en el archivo de navegación correspondiente. El título corto de este documento se define en `src/content/nav/style-guide.yml`:

```yaml
- title: Titles and short titles
  path: /docs/style-guide/structure/titles
```

Lea más sobre [cómo editar la navegación izquierda](/docs/style-guide/processes-procedures/update-left-navigation-pane).

## Rutas y redireccionamientos

La ruta y el nombre de archivo de un documento específico no tienen relación con el título de ese documento. La ruta para este documento es `/docs/style-guide/structure/titles`. Tenga en cuenta que aunque el archivo se llama `titles`, ni el título ni el título corto se llaman `Titles`.

Las redirecciones ignoran por completo el título, el título corto y la ruta de un documento. Lo redireccionará a donde apunte la redirección. [Lea más sobre las redirecciones](/docs/style-guide/processes-procedures/rename-or-redirect-document).
