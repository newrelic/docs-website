## Conceptos básicos

Mostramos indicadores de colores para el estado de alerta en la UI, y es importante para nosotros usar un lenguaje que sea consistente en nuestras pantallas de la UI y API. También estamos comenzando a incluir más en este estado que solo alertas.

Incluya un estado al pasar el cursor para explicar el significado del color, cuando sea necesario. Para las insignias de estado principales en una página de entidad individual, el estado al pasar el cursor enumerará lo que contribuye. Si esto no es posible, utilice los estados al pasar el cursor a continuación.

## Mapeo entre la redacción de la UI y la API

| Color     | Hover de la UI (tooltip)          | Etiqueta de estado de la UI | API             |
| --------- | --------------------------------- | --------------------------- | --------------- |
| Rojo      | Incidente crítico en curso        | Crítico                     | CRÍTICO         |
| Amarillo  | Incidente de advertencia en curso | Degradado                   | ADVERTENCIA     |
| Verde     | No hay alertas en curso           | Operativo                   | NOT\_ALERTING   |
| Gris      | No informa                        | Estado desconocido          | NOT\_CONFIGURED |
| Sin color | -sin estado hover-                | -sin estado hover-          |                 |
