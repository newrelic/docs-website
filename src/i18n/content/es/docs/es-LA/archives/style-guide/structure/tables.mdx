Las tablas ayudan a organizar la información para que a los lectores les resulte más fácil leerla por encima. Sin embargo, si la tabla se vuelve demasiado larga, siga la [pauta de &quot;cinco a nueve&quot;](/docs/style-guide/get-started/introduction-style-guide#organization) y considere reestructurar la información de otras maneras.

Use el formato de tipo oración para el texto en cada columna de la tabla, a menos que sea un nombre de archivo específico o un valor de código que requiera minúsculas o todo en mayúsculas.

<Callout variant="tip">
  La macro de Keyboard Maestro para el componente Table es `kktable`
</Callout>

## Sintaxis de tabla

Nuestras tablas están creadas como componentes de MDX React. En la práctica, son muy similares a las tablas HTML:

```html
<table>
    <thead>
        <tr>
            <th style={{ width: "200px" }}>
                Item
            </th>
            <th>
                Description
            </th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>
                Item name
            </td>
            <td>
                Description of item
            </td>
        </tr>
    </tbody>
</table>
```

<Callout variant="tip">
  El sitio de documentación técnicamente admite [tablas de Markdown](https://www.markdownguide.org/extended-syntax/#tables), pero evitamos usarlas por algunas razones:

  * Existen múltiples variantes de Markdown, y las diferentes variantes utilizan diferentes sintaxis de tablas. Esto se debe a que la especificación original de Markdown de John Gruber no incluía tablas.
  * Las tablas de Markdown no admiten elementos que abarquen varias líneas, y la mayoría de nuestras tablas incluyen bloques de código, listas con viñetas u otros elementos que requieren varias líneas.
</Callout>

## Configuración del ancho de columna [#column-width]

Puede establecer el ancho de la columna con una regla de estilo en el elemento `<th>`:

```html
<th style={{ width: "200px" }}>
```

En general, para las tablas de dos columnas en el sitio de documentos:

1. Establezca la primera columna en 200 píxeles: `style={{ width: "200px" }}`.
2. Para permitir que la tabla se ajuste automáticamente al ancho restante de la página, no establezca un ancho para la segunda columna.

## Tablas para describir las funciones de la UI [#tables-ui]

Al utilizar tablas para describir las funciones disponibles, ofrezca a los lectores una hoja de ruta. Es posible que sepan lo que quieren encontrar o lograr, pero tal vez no sepan cómo se llama o cómo hacerlo.

Por ejemplo, para proporcionar una lista de características para una página de la UI en particular, etiquete la primera columna del encabezado **Si desea...** y etiquete la segunda columna **Haga esto**.
