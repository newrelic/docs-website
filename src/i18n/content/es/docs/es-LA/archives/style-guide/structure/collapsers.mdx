Los colapsadores son elementos expandibles que ocultan el contenido de la página hasta que [los abre](#trigger-collapser). Usamos colapsadores para ocultar contenido en documentos muy largos, por consideración a nuestros lectores. Cada colapsador tiene un `title` (lo que mostramos a los lectores), pero también un `id` que usamos para enlaces de &quot;anclaje&quot; profundos a colapsadores específicos.

Este es un ejemplo de colapsador:

<CollapserGroup>
  <Collapser id="collapser-1" title="Reductor 1">
    Este es nuestro primer reductor de ejemplo.
  </Collapser>

  <Collapser id="collapser-2" title="Reductor 2">
    Este es nuestro segundo expansor de ejemplo.
  </Collapser>
</CollapserGroup>

<Callout variant="tip">
  La macro de Keyboard Maestro para los colapsadores es `kkcollapse`.
</Callout>

## Cree un colapsador [#create]

Para crear un elemento plegable, deberá usar nuestro código de elemento plegable.

Este es un ejemplo del código fuente del colapsador:

```jsx
<CollapserGroup>
  <Collapser
    id="collapser-1"
    title="Collapser 1"
  >
    This is our first example collapser.
  </Collapser>

  <Collapser
    id="collapser-2"
    title="Collapser 2"
  >
    This is our second example collapser.
  </Collapser>
</CollapserGroup>
```

## Activadores de reductores [#trigger-collapser]

El sitio abre automáticamente los elementos plegables en algunos escenarios:

* Llegue a un colapsador individual a través de un ID de anclaje. Por ejemplo, vaya directamente al [Colapsador 1 en el ejemplo anterior](/docs/style-guide/quick-reference/collapsers#collapser-1).
* Use **CMD+F** (o **CTRL+F**) para buscar en la página y todas las secciones plegables se abrirán automáticamente.
* Escriba la tecla de acceso directo `s` para **m**ostrar (abrir) todas las secciones plegables de la página.
