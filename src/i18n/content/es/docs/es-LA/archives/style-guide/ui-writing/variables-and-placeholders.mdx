## Variables

Use variables cuando necesite insertar un valor calculado o el resultado de una consulta en una oración que sea fácil de leer. La guía es la misma ya sea que los llame rellenos, reemplazos, sustituciones o cualquier otro término.

### ¿Qué es una variable? Los elementos en negrita a continuación.

| En el código                                                                                       | En la UI                                                                   |
| -------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Detectamos un comportamiento anómalo en **\[nombre del servicio]**.                                | Detectamos un comportamiento anómalo en **RPM-UI-production**.             |
| El **\[% of crashes]** de los bloqueos comparte el sistema operativo **\[operating system type]**. | El **80 %** de los bloqueos comparten el sistema operativo **iOS 11.1.2**. |

### Conceptos básicos

Si el valor insertado será corto, colóquelo en el lugar más lógico de la oración para que suene natural. Si el valor será largo, ilegible o de otro modo fuera de nuestro control, colóquelo al final de la oración. Si la variable pudiera ser cualquier parte de la oración o a veces singular y a veces plural, sepárela con dos puntos o colóquela en otra línea.

| Hacer                                                                                       | No                                                                                              |
| ------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| Detectamos un comportamiento anómalo en **bob-long-name-32-october-service-legacy-system**. | El servicio **bob-long-name-32-october-service-legacy-system** tiene un comportamiento anómalo. |
| El **80 %** de los bloqueos comparten el nombre de usuario **pdiddybigdog**.                | El **80 %** de los bloqueos comparten el nombre de usuario **pdiddybigdog**.                    |
| Servicios con múltiples errores: **1**                                                      | **1** servicios tienen múltiples errores.                                                       |

## Texto del marcador de posición

Para el texto del marcador de posición en los campos de entrada, use “Ejemplo: ...”. Y en lugares como la documentación donde agregamos ejemplos en línea, use &quot;como&quot;. Por ejemplo, &quot;X requiere que se descarte una acción (como confirmar que un usuario desea eliminar un dashboard)”.
