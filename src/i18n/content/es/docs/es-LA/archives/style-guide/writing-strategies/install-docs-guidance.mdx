## Una descripción general de los métodos de instalación [#overview]

Actualmente, tenemos tres métodos que nuestros clientes pueden usar para instalar New Relic y comenzar el monitoreo de algo:

1. Instalación guiada, nuestra herramienta interactiva de línea de comando para instalar New Relic en diferentes sistemas
2. Instalación manual a través de la página “+ Agregar más datos” en la UI
3. Instalación manual a través del sitio de documentación

La observabilidad instantánea (I/O) **no** es un método de instalación. Simplemente proporciona un catálogo de todas las cosas que alguien podría monitorear a través de New Relic. Una página de observabilidad instantánea simplemente apunta a uno de estos tres métodos, según lo que esté disponible.

CodeStream tiene su propio método de instalación.

## Instalación [#guided]

La [instalación guiada](/docs/new-relic-one/install-configure/new-relic-guided-install-overview/) proporciona un único comando que puede ejecutar en su sistema para instalar New Relic y comenzar el monitoreo de varias cosas.

Cuando alguien ejecuta el comando de la CLI de instalación guiada, este instala el agente de infraestructura y habilita el envío de logs. También detecta integraciones en un sistema y le solicita que elija si desea monitorear esas integraciones o no. Si la instalación guiada detecta una aplicación de un lenguaje compatible, puede instalar el agente APM para ese lenguaje.

Para la documentación, deberíamos dirigir a los usuarios a la instalación guiada siempre que sea apropiado hacerlo. Es decir, cuando es probable que la instalación guiada conduzca a un resultado exitoso.

## Instalación manual a través de agregar más datos [#manual-add]

Las páginas de [Agregar más datos](https://one.newrelic.com/marketplace?state=7ca7c800-845d-8b31-4677-d21bcc061961) proporcionan una ruta de instalación simple y directa para las personas que desean instalar agentes APM y que utilizan las integraciones más populares y las configuraciones de sistema más comunes para esas integraciones.

**Add more data** completa los archivos de configuración de instalación con valores como el nombre de la aplicación y la clave de API para que un cliente no tenga que buscar esa información. También proporcionan la ruta de instalación más sencilla para los casos de uso estándar.

Este método es menos efectivo para los clientes que tienen elementos más complicados u oscuros que intentan monitorear o sistemas no estándar.

**Agregar más datos** también tiene la ventaja de estar en la UI.

## Instalación manual a través del sitio de documentación [#manual-docs]

Los procedimientos de instalación manual, como esta [instalación manual de Java](/docs/apm/agents/java-agent/installation/install-java-agent), deben ser el método de último recurso. Las instrucciones de instalación en el sitio de documentación probablemente estén desactualizadas. También se presentan de una manera bastante confusa que en realidad puede evitar que las personas instalen New Relic. Desde la perspectiva de la documentación, este es el valor predeterminado, porque ahí es donde se centran nuestra energía y atención. También es el lugar donde podemos hacer cambios fácilmente.

En un esfuerzo por ser universalmente completos, nuestros documentos de instalación manual presentan un proceso que parece ser increíblemente complejo. Sin embargo, la complejidad radica en la variedad de opciones. Para cualquier proceso de instalación dado, los pasos son bastante sencillos, una vez que un usuario ha identificado el proceso de instalación que necesita usar.

## Observabilidad instantánea [#io]

[Observabilidad instantánea](https://newrelic.com/instant-observability) es un catálogo público de elementos que New Relic puede monitorear y dashboards y alertas predeterminados útiles. En este catálogo, hay algunas tecnologías que no se ajustan a este modelo, como CodeStream o Atlassian Jira.

Para la mayoría de las páginas de inicio rápido, el botón **Install now** lo lleva a la instalación guiada, a una página para agregar más datos o a una página de documentos de instalación manual, según lo que esté disponible para esa tecnología específica.

## Integrations &amp; Agents en la UI [#add-data]

En la UI, [+ Integración &amp; agentes](https://one.newrelic.com/marketplace?state=7ca7c800-845d-8b31-4677-d21bcc061961) lo lleva a una versión del catálogo de observabilidad instantánea que guía a un usuario más directamente a través del proceso de incorporación para una tecnología en particular.
