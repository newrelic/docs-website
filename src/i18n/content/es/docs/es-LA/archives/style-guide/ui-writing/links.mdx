Los enlaces en nuestra UI deben ser concisos y coincidir con nuestro estilo y voz.

## Conceptos básicos

* Mantenga el texto de vínculo corto para optimizarlo para los lectores de pantalla.
* Comience con el beneficio para el lector, no con la ubicación del enlace.
* Utilice un lenguaje conversacional, pronombres y contracciones, tal como lo hacemos en nuestros otros textos.
* Utilice el nombre o la descripción de la ubicación, en lugar de simplemente &quot;este enlace&quot;.
* Para los enlaces que llevan a los usuarios fuera del producto (como a nuestros sitios de Documentación o Soporte), agregue el ícono de enlace externo al final.

## Código

Al presentar fragmentos de código a los clientes, formatéelos con la fuente monoespaciada Menlo.

```js
var example = "This is an example string in a monospace font!";
```

## Listas

* Escriba en mayúscula la primera letra de cada elemento de la lista.
* Para listas generales de información, use listas no ordenadas (con viñetas).
* Para listas con pasos específicos, use una lista ordenada (de números).
