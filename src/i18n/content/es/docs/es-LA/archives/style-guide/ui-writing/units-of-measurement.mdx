## Conceptos básicos

* Separe las unidades de medida de su valor con un solo espacio.
* Para las mediciones a lo largo del tiempo, inserte una barra diagonal entre la unidad de medida y la unidad de tiempo.

| Unidad de medida      | Hacer     | No       |
| --------------------- | --------- | -------- |
| requests por minuto   | 29.5K rpm | 29.5Krpm |
| requests por segundo  | 14 rps    | 14rps    |
| páginas por minuto    | 6.33 ppm  | 6.33ppm  |
| kilobytes por segundo | 16 KB/s   | 16 KB s  |
