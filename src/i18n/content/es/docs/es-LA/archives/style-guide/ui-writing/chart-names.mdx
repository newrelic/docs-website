New Relic One permite a los usuarios crear y nombrar sus propios gráficos, pero también tiene algunos gráficos seleccionados que proporcionamos. Los nombres de estos gráficos deben ser claros y descriptivos, para que los usuarios sepan lo que están viendo.

## Conceptos básicos

* Use palabras clave claras.
* Proporcione suficiente información para explicar el propósito del gráfico; evite los nombres de una sola palabra.
* Busque la precisión por encima de la coherencia. Preferimos tener nombres ligeramente diferentes para gráficos similares que seguir una convención de nomenclatura que sea perfecta para algunos gráficos pero inexacta para otros.
* Mantenga los nombres en formato de oración.

| Hacer                          | No                   |
| ------------------------------ | -------------------- |
| Las 5 transacciones más lentas | Transacción          |
| Desglose de errores por:       | Errores              |
| Agrupar traza por:             | Agrupación de trazas |
