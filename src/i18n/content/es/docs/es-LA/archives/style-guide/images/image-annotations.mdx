Las anotaciones de imágenes son texto y formas en capturas de pantalla o diagramas que ayudan a hacer referencia a la información y centrar la atención en los aspectos más importantes de la captura de pantalla. Recomendamos que las use con precaución porque a veces pueden ser una distracción y también son difíciles de mantener actualizadas. Tenga en cuenta que puede usar alternativas como [leyendas de imágenes](/docs/style-guide/images/screenshots-images/#captions) o instrucciones directamente en el texto.

Si necesita usar anotaciones de imágenes:

* Sea conciso.
* Asegúrese de que las anotaciones sean fáciles de distinguir del texto de la UI. Por ejemplo, es posible que deba desplazar sus cuadros para que no parezcan elementos de la UI.
* Las anotaciones no se traducen, así que úselas con moderación.
* No use una anotación en la parte superior que actúe como un título. Use una leyenda.
* Asegúrese de que las anotaciones sean visibles en modo oscuro y claro.
* Use nuestro [tema SnagIt de New Relic](https://github.com/newrelic/newrelic-doc-tools) (enlace solo disponible para empleados de New Relic) para mantener sus anotaciones consistentes.

## Instalar el tema SnagIt de New Relic [#install-theme]

Sigue estos pasos:

1. Asegúrese de ejecutar la versión más reciente de SnagIt.

2. En GitHub Desktop, clone el [repositorio](https://github.com/newrelic/newrelic-doc-tools) localmente.

3. Abra SnagIt y seleccione cualquier herramienta para abrir el panel de navegación derecho.

4. En el panel **Quick Styles** de la navegación derecha, seleccione el icono de engranaje en el campo **Theme** y, a continuación, **Import**.

5. En el cuadro de diálogo que se abre, vaya a `YOUR_GIT_DIRECTORY/newrelic-doc-tools/themes`, seleccione el archivo `New-Relic-Docs.snagtheme` y haga clic en **Open**.

## Cuadros de llamadas [#callout-boxes]

Use llamadas para resaltar un elemento dentro de una captura de pantalla. Si es posible, no agregue texto a la captura de pantalla, para eso están nuestros documentos. Los cuadros de llamada no deben obstruir ninguno de los elementos que están señalando. Por ejemplo, un cuadro de llamada alrededor de un botón de la UI no debería cubrir ninguna parte del botón. Si es posible, inserte un espacio de dos píxeles entre el elemento de la UI y el cuadro de llamada.

Este es el formato para agregar cuadros de llamada:

* Forma: cuadrado o rectángulo, relleno transparente, sin radio de borde.
* Color de borde: #00CE7C
* Ancho de línea: 5pt
* Opacidad: 100 %
* Estilo de línea: sólido
* Sin sombras

## Texto de llamada [#callout-text]

Las capturas de pantalla no deberían requerir una llamada de texto el 99 % de las veces; las etiquetas `<figcaption>` y el contenido escrito antes o después de la imagen deberían ser suficientes para explicar la captura de pantalla. Sin embargo, si se requiere un cuadro de texto, no debe superponerse a ningún texto o elemento esencial de la UI.

Si necesita agregar texto a una captura de pantalla, siga estas pautas:

* Forma: cuadrado o rectángulo, color de relleno #00CE7C.
* Color de borde: #00CE7C
* Ancho de línea: 5pt
* Opacidad: 100 %
* Estilo de línea: sólido
* Sin sombras
* Fuente: Arial negrita #FFFFFF, tamaño 24pt, justificado a la izquierda

## Flechas [#arrows]

Use una flecha de una sola punta o una flecha con puntas en ambos extremos en su captura de pantalla cuando desee hacer referencia a elementos dentro de la UI.

Si utiliza una flecha, intente no superponer ningún texto o elemento esencial de la UI.

Este es el formato para agregar una flecha:

* Opacidad: 100 %
* Ancho de línea: 7pt
* Color: #00CE7C
* Estilo de línea: sólido, sin tamaño inicial, tamaño final en 5
* Sin sombras
