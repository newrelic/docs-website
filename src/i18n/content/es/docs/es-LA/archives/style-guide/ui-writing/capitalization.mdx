El uso de mayúsculas ayuda a comunicar la importancia de palabras específicas y puede usarse para indicar un cambio de significado. Para mantener su eficacia, debemos limitar lo que escribimos en mayúsculas.

## Conceptos básicos

* A partir de febrero de 2023, utilice mayúsculas iniciales para tres tipos de contenido de la UI:

  * Títulos de página
  * Navegación izquierda (navegación principal)
  * Títulos en los mosaicos de la página All Capabilities

* Use el formato de oración el resto del tiempo.

* Ponga en mayúscula la primera letra de los nombres propios (nombres de productos, países, acrónimos y nombres de personas) independientemente de dónde aparezcan en una oración.

* Escriba en mayúscula los nombres de los productos como se describe en la página [Productos y capacidades: uso de mayúsculas, marcas comerciales y su uso](/docs/style-guide/capitalization/product-capability-feature-usage).

* No escriba con mayúscula los artículos (un, una, el, la) ni las preposiciones (de, en, para, a, con, etc.) a menos que estén al principio de una oración.

| Hacer                                   | No                                         |
| --------------------------------------- | ------------------------------------------ |
| Las 5 principales trazas de transacción | Las 5 principales trazas de la transacción |
| New Relic es un nombre propio.          | New Relic es un nombre propio.             |
| Pruebe los nuevos dashboard.            | Pruebe los nuevos Dashboards.              |
| Estatua de la Libertad                  | Estatua de la Libertad                     |

## Mayúsculas

| Tipo de copia                       | Ejemplo                                                                                                |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Bytes de datos                      | B, KB, MB                                                                                              |
| Números abreviados superiores a 999 | 1 k, 1 M, 1 B                                                                                          |
| Acrónimos                           | API, CDN, HTTP                                                                                         |
| Zonas horarias                      | PDT, CST, BCN                                                                                          |
| Períodos de tiempo                  | [AM o PM](https://docs.newrelic.com/docs/style-guide/ui-writing/numbers-dates-and-times#date-and-time) |

## Unidades de medida

Las abreviaturas de memoria, ancho de banda y espacio en disco tienen reglas variadas para el uso de mayúsculas.

* Incluya siempre un espacio entre el valor y la unidad de medida.
* Un solo bit de datos va en minúscula (b), mientras que 1204+ bits va con mayúscula inicial (13 Kb).
* Los bytes siempre van en mayúsculas (13 KB, 512 MB).

Los pesos y las distancias van en minúsculas sin puntos después de la abreviatura (ft, lbs, km).

| Hacer   | No      |
| ------- | ------- |
| 32 Kb/s | 32 kb/s |
| 16 s    | 16s     |
| 0.43 MB | 0.43 MB |
| 15 ft   | 15 ft.  |
