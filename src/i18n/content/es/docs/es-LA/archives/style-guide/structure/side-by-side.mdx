El componente `SideBySide` permite dividir la pantalla a la mitad o en más secciones. Un caso de uso común es mostrar una captura de pantalla en la columna derecha y el texto que la acompaña en la izquierda.

Debe envolver el contenido de cada lado dentro de un componente `Side`, pero puede agregar tanto contenido como necesite dentro de cada `Side`.

Técnicamente, el componente admite más de dos columnas `Side`, pero debe evitar usar más de dos.

Este es un ejemplo del componente:

<SideBySide>
  <Side>
    <img alt="example" src="/images/network_screenshot-full_device-performance.webp" />

    <figcaption>
      Vaya a **[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Network**
    </figcaption>
  </Side>

  <Side>
    Este es un contenido increíble del maravilloso equipo de documentación.
  </Side>
</SideBySide>

## Crear un componente SideBySide [#create]

Aquí tiene una plantilla de un componente `SideBySide`:

```jsx
<SideBySide>
    <Side>
        <img alt="Example" src="/images/example-image.webp" />
    </Side>

    <Side>
        This is some awesome content from the amazing documentation team.
    </Side>
</SideBySide>
```

<Callout variant="tip">
  La macro de Keyboard Maestro para SideBySide es `kkside`.
</Callout>
