Al igual que la puntuación, el formato del texto puede tener un gran impacto en la forma en que las personas interpretan nuestras palabras. Por ejemplo, puede usar texto en negrita como una herramienta simple para dar énfasis en un mensaje, o puede usarlo para guiar los ojos de una persona por la UI para que sepa instintivamente qué es importante.

## Conceptos básicos

* El texto en negrita se usa a menudo para mejorar la capacidad de escaneo en la UI y enfatizar palabras específicas en textos más largos.
* Las cursivas se usan a menudo para el texto de sugerencia contextual debajo de los elementos de entrada y pueden transmitir un tono enfocado o un tono tenue al texto.
* El texto subrayado en la UI puede interpretarse fácilmente como un enlace, así que tenga cuidado al usar el formato para un propósito diferente. Considere buscar una solución alternativa a las palabras subrayadas que no funcionarán como enlaces.

## Código

Al presentar fragmentos de código a los clientes, formatéelos con la fuente monoespaciada Menlo.

```javascript
var example = 'This is an example string in a monospace font!';
```

## Listas

* Escriba en mayúscula la primera letra de cada elemento de la lista.
* Para listas generales de información, use listas no ordenadas (con viñetas).
* Para listas con pasos específicos, use una lista ordenada (de números).
