Tenemos varios casos de uso para los tooltips, todos los cuales necesitan un lenguaje y una dirección claros y accesibles.

## Conceptos básicos

* Piense en lo que el usuario necesita saber, sentir y hacer en cada situación.
* Use un lenguaje conversacional.
* Para descripciones emergentes de una sola línea, como nombres de íconos y acciones, mantenga el lenguaje breve y específico, y no termine con un punto.
* Para descripciones emergentes más completas, como definiciones, incluya por qué el elemento es importante para el usuario y termine las oraciones completas con un punto.
* Incluya un enlace a más información donde esté disponible.
