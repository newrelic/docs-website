<Callout variant="tip">
Esta lección es parte de un curso que le muestra cómo crear una aplicación New Relic desde cero.

Cada lección del curso se basa en la anterior, así que cerciorar de completar la última lección, Agregar gráficos circulares, antes de comenzar esta.
</Callout>

En cada lección práctica de este curso, fuiste agregando algo nuevo a tu aplicación Prueba A/B. Creó un nuevo launcher y agregó múltiples componentes de gráficos a su Nerdlet. En esta lección, creará dos nuevos componentes `TableChart` que muestran información sobre cada versión de su sitio web, como la proporción de clientes que se suscriben y aquellos que se dan de baja.

<Steps>
<Step>
Cambie al directorio `add-tables/ab-test` del [repositorio de trabajos del curso](https://github.com/newrelic-experimental/nru-programmability-course):

```sh
cd nru-programmability-course/add-tables/ab-test
```

Este directorio contiene el código que esperamos que tenga su aplicación en este punto del curso. Al navegar al directorio correcto al comienzo de cada lección, deja atrás su código personalizado, proteger así de llevar código incorrecto de una lección a la siguiente.
</Step>

<Step>
En `nerdlets/ab-test-nerdlet`, agregue un nuevo archivo Javascript llamado `totals.js`:

```sh
touch totals.js
```
</Step>

<Step>
En este nuevo archivo, cree un componente llamado `VersionTotals` para contener su primer `TableChart` y algunos datos simulados:

```jsx fileName=nerdlets/ab-test-nerdlet/totals.js
import React from "react";
import { TableChart } from "nr1";

export default class VersionTotals extends React.Component {
constructor(props) {
  super(props);
}

render() {
  const versionATotals = {
    metadata: {
      id: `totals-${this.props.version}`,
      name: `Version ${this.props.version}`,
      columns: ["name", "count"],
    },
    data: [
      {
        name: "Subscriptions",
        count: 0,
      },
      {
        name: "Page views",
        count: 0,
      },
    ],
  };
  return <TableChart data={[versionATotals]} fullWidth />;
}
}
```

`TableChart` es diferente de `PieChart` y `LineChart` en tres grandes aspectos. En primer lugar, no hay atributos de metadatos `color` o `viz` en su serial. `TableChart` tiene una visualización estándar, por lo que ignora cosas como `color`, que no se aplican. En segundo lugar, el serial `TableChart` tiene `columns` metadatos atributo. `columns` determina los nombres de las columnas de la tabla. Finalmente, los datos del serial `TableChart` no emplean valores de x ni de y. En su lugar, emplean claves que coinciden con la columna de la tabla y valores que determinan lo que va en la fila.

Observe que `VersionTotals` toma un accesorio `version` y lo proporciona a los campos `id` y `name` de los metadatos del gráfico. Esto le permite emplear este mismo componente para crear una tabla para las versiones A y B y eliminar el código duplicado.
</Step>

<Step>
En el archivo `index.js` de tu Nerdlet, importa tu nuevo componente y actualiza el método `render()` de tu Nerdlet:

```jsx fileName=nerdlets/ab-test-nerdlet/index.js lineHighlight=5,13-14
import React from 'react';
import NewsletterSignups from './newsletter-signups';
import TotalCancellations from './total-cancellations';
import TotalSubscriptions from './total-subscriptions';
import VersionTotals from './totals';

export default class AbTestNerdletNerdlet extends React.Component {
  render() {
    return <div>
      <NewsletterSignups />
      <TotalSubscriptions />
      <TotalCancellations />
      <VersionTotals version='a' />
      <VersionTotals version='b' />
    </div>
  }
}
```
</Step>

<Step>
Navega hasta la raíz de tu Nerdpack en `nru-programmability-course/add-tables/ab-test`.
</Step>

<Step>
Genera un nuevo UUID para tu Nerdpack:

```sh
nr1 nerdpack:uuid -gf
```

Debido a que clonaste el repositorio de trabajos del curso que contenía un Nerdpack existente, necesitas generar tu propio identificador único. Este UUID asigna su Nerdpack a su cuenta New Relic.
</Step>

<Step>
Entregue su aplicación localmente:

```sh
nr1 nerdpack:serve
```
</Step>

<Step>
Vea sus cambios en [New Relic](https://one.newrelic.com?nerdpacks=local).

Aquí verá los `TableChart` componentes que se muestran en su aplicación.

Cuando terminó, deje de servir su aplicación New Relic presionando `CTRL+C` en la ventana de terminal de su servidor local.
</Step>
</Steps>

<Callout variant="tip">
Hay una tabla más en la guía de diseño que registra las pruebas pasadas. Las columnas de esta tabla son:

* **End Date:** la fecha de finalización de la prueba.
* **Version A Description:** una descripción para la versión A
* **Version B Description:** una descripción para la versión B
* **Winner:** La versión seleccionada como diseño final.

Intente crear esta tabla en su aplicación con estos nombres de columnas y algunos datos falsos, sin mirar un ejemplo de código. Esta práctica reforzará lo que aprendiste en esta lección.

Si necesita ayuda, revise el directorio `add-a-chart-group` del [repositorio de trabajos del curso](https://github.com/newrelic-experimental/nru-programmability-course), que corresponde a la siguiente lección de este curso. Este tiene el código para el componente `PastTests`.
</Callout>

Cada gráfico que agregará a su aplicación a lo largo de este curso es único en su tipo o en los datos que presenta. Hasta ahora, creó tablas, gráficos circulares y un gráfico de líneas, y todos funcionan de forma independiente unos de otros. En la siguiente lección, creará un par de gráficos de líneas más, pero esta vez funcionarán juntos.
