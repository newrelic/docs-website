<Callout variant="tip">
Esta lección es parte de un curso que le muestra cómo crear una aplicación New Relic desde cero. Si aún no lo hiciste, consulta la descripción general.

Cada lección del curso se basa en la anterior, así que cerciorar de completar la última lección, Agregar componentes de gráficos a su aplicación Prueba A/B, antes de comenzar esta.
</Callout>

En este curso, crearás una aplicación Prueba A/B para la plataforma New Relic . Anteriormente, aprendió sobre el SDK New Relic ]\(/docs/New Relic-solutions/build-nr-UI/sdk-component/intro-to-sdk) y su biblioteca de componentes. Ahora es el momento de comenzar a construir tu aplicación centrándote primero en los componentes del gráfico.

Hay varios gráficos que debes crear, lo que puede parecer abrumador al principio, pero hazlo paso a paso. El gráfico superior, y el primero que creará, es un gráfico de líneas que muestra la cantidad de usuarios que se suscriben a su boletín informativo y qué versión de su sitio web se les mostró.

<Steps>
<Step>
Cambie al directorio `add-your-first-chart/ab-test` del [repositorio de trabajos del curso](https://github.com/newrelic-experimental/nru-programmability-course):

```sh
cd nru-programmability-course/add-your-first-chart/ab-test
```

Este directorio contiene el código que su aplicación debe tener en este punto del curso. Al navegar al directorio correcto al comienzo de cada lección, deja atrás su código personalizado, proteger así de llevar código incorrecto de una lección a la siguiente.
</Step>

<Step>
En `nerdlets/ab-test-nerdlet`, agregue un nuevo archivo Javascript llamado `newsletter-signups.js`:

```sh
touch newsletter-signups.js
```
</Step>

<Step>
En este nuevo archivo, cree un componente llamado `NewsletterSignups` para contener su primer `LineChart` y algunos datos simulados:

```jsx fileName=nerdlets/ab-test-nerdlet/newsletter-signups.js
import React from "react";
import { LineChart } from "nr1";

export default class NewsletterSignups extends React.Component {
render() {
  const versionASignups = {
    metadata: {
      id: "version-a-newsletter-signups",
      name: "Version A",
      viz: "main",
      color: "blue",
    },
    data: [
      { x: 0, y: 0 },
      { x: 10, y: 10 },
      { x: 20, y: 15 },
      { x: 30, y: 5 },
      { x: 40, y: 30 },
      { x: 50, y: 25 },
    ],
  };
  const versionBSignups = {
    metadata: {
      id: "version-b-newsletter-signups",
      name: "Version B",
      viz: "main",
      color: "green",
    },
    data: [
      { x: 0, y: 20 },
      { x: 10, y: 5 },
      { x: 20, y: 25 },
      { x: 30, y: 45 },
      { x: 40, y: 50 },
      { x: 50, y: 35 },
    ],
  };
  return <LineChart data={[versionASignups, versionBSignups]} fullWidth />;
}
}
```

Aquí, creó dos seriales de datos arbitrarias que representan las versiones A y B de su prueba. En este momento, estás empleando puntos de datos creados manualmente. En el futuro, los reemplazará con consultas de datos de New Relic.

Observe que especificó un color para cada serial del gráfico. El atributo de metadatos `color` toma cualquier formato de color aceptable para CSS. Configurar `viz: 'main'` significa que desea representar el serial `LineChart` como una línea, el estilo de visualización predeterminado del componente. Para el accesorio `data` en el componente `LineChart` , pasaste los dos seriales en una matriz para que ambas se representen juntas. Finalmente, empleó el accesorio `fullWidth` del gráfico para ampliar el ancho del gráfico y llenar la vista.
</Step>

<Step>
En el archivo `index.js` de tu Nerdlet, importa tu nuevo componente y reemplaza el encabezado predeterminado en el método `render()` de tu Nerdlet con tu nuevo componente:

```jsx fileName=nerdlets/ab-test-nerdlet/index.js lineHighlight=2,6-8
import React from 'react';
import NewsletterSignups from './newsletter-signups';

export default class AbTestNerdletNerdlet extends React.Component {
  render() {
    return <div>
      <NewsletterSignups />
    </div>
  }
}
```
</Step>

<Step>
Navega hasta la raíz de tu Nerdpack en `nru-programmability-course/add-your-first-chart/ab-test`.
</Step>

<Step>
Genera un nuevo UUID para tu Nerdpack:

```sh
nr1 nerdpack:uuid -gf
```

Debido a que clonaste el repositorio de trabajos del curso que contenía un Nerdpack existente, necesitas generar tu propio identificador único. Este UUID asigna su Nerdpack a su cuenta New Relic.
</Step>

<Step>
Entregue su aplicación localmente:

```sh
nr1 nerdpack:serve
```
</Step>

<Step>
Vea sus cambios en [New Relic](https://one.newrelic.com?nerdpacks=local).

Aquí verá el `LineChart` mostrado en su aplicación.

Cuando terminó, deje de servir su aplicación New Relic presionando `CTRL+C` en la ventana de terminal de su servidor local.
</Step>
</Steps>

En siete pasos, le dio vida a su aplicación New Relic. En lugar de un mensaje insípido de &quot;Hola mundo&quot;, su aplicación ahora muestra un gráfico de líneas colorido con dos seriales de datos simuladas. Estos seriales de datos representan el tráfico del lado del servidor para cada uno de los diseños de la competencia en su sitio web de demostración.
