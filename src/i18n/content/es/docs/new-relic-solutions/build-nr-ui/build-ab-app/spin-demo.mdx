Esta lección es parte de un curso que le muestra cómo crear una aplicación New Relic desde cero. Si aún no lo hiciste, consulta la descripción general.
</Callout>

Antes de crear su aplicación New Relic, debe poner en marcha sus servicios de demostración. Este curso depende de dos servicios importantes:

* Un servicio sitio web que muestra un formulario de subscripción al boletín. El texto del encabezado del formulario alterna entre dos versiones porque estás realizando una Prueba A/B para determinar qué texto conduce a una subscripción de mayor calidad.
* Un servicio de simulador que envía tráfico constante al sitio web para que no tengas que generar datos manualmente.

Para poner en marcha sus servicios de demostración, primero debe instalar [Docker](https://docs.docker.com/get-docker/) y [Docker compose](https://docs.docker.com/compose/install/).

## Mejora tus servicios de demostración [#spin]

<Steps>
<Step>
Clona el [repositorio de trabajos del curso](https://github.com/newrelic-experimental/nru-programmability-course) desde GitHub:

```sh
git clone https://github.com/newrelic-experimental/nru-programmability-course
```

Este repositorio contiene código para crear automatizaciones NodeJS New Relic. También contiene un directorio de códigos de aplicación para cada lección del curso. Empleará estos directorios para seguir el contenido del curso.
</Step>

<Step>
Cambie al directorio de demostración, llamado `ab-test-app`:

```sh
cd nru-programmability-course/ab-test-app
```

Este directorio contiene archivos de configuración y archivos README para usar la demostración.
</Step>

<Step>
Compile y ejecute el servicio sitio web y el contenedor del simulador empleando `docker-compose`:

```sh
NEW_RELIC_LICENSE_KEY=YOUR_NEW_RELIC_LICENSE_KEY docker-compose up -d
```

<Callout variant="important">
Cerciorar de reemplazar `YOUR_NEW_RELIC_LICENSE_KEY` con su [clave de licencia](/docs/accounts/accounts-billing/account-setup/new-relic-license-key/) real.
</Callout>

Una vez que esté terminado, visite el sitio web en `localhost:3001`.
</Step>

<Step>
Visite [New Relic](https://one.newrelic.com) y navegue hasta **APM** en el menú de navegación superior. Seleccione **Newsletter** de la lista de servicios instrumentados.

Es posible que tengas que esperar uno o dos minutos para que New Relic reciba datos de tus servicios de demostración. Una vez que esté listo, verás los datos de la transacción, como rendimiento, rendimiento y un puntaje Apdex.
</Step>

<Step>
Para desactivar sus servicios de demostración, ejecute `docker-compose down` desde su directorio `ab-test-app` :

```sh
docker-compose down
```
</Step>
</Steps>

¡Ahora estás listo para crear tu aplicación New Relic!
