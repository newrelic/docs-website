Puede pedirle a un agente de codificación de IA, como Claude Code, Cursor, GitHub Copilot o Codex, que agregue New Relic al proyecto. El agente lee los documentos de instalación, determina qué agente de New Relic necesita el proyecto y realiza los cambios.

## Antes de que empieces [#before-you-begin]

* **Cuenta de New Relic** —si no tiene una, [regístrese para obtener una cuenta de New Relic](https://newrelic.com/signup).
* **Clave de licencia** — Necesitará su <InlinePopover type="licenseKey" />. Para encontrarla, consulte [Clave de licencia](/docs/apis/intro-apis/new-relic-api-keys#license-key).

<Callout variant="important">
Mantenga la clave de licencia fuera del contexto del agente. No la pegue en el chat. Configúrela como la variable de entorno `NEW_RELIC_LICENSE_KEY` donde se ejecuta la aplicación.
</Callout>

## Copie este símbolo [#prompt]

Abra el agente de programación de IA en la carpeta del proyecto y pegue este símbolo:

<Callout variant="tip">
Siga las instrucciones en [https://docs.newrelic.com/docs/new-relic-solutions/get-started/install-with-ai.md](https://docs.newrelic.com/docs/new-relic-solutions/get-started/install-with-ai.md) para agregar New Relic a este proyecto.
</Callout>

Una vez que se ejecute el agente, compruebe qué archivos cambió y verifique que los datos estén llegando a New Relic.

## Instrucciones para agentes de IA [#agent-instructions]

Si es un agente de IA que instala New Relic, siga estos pasos:

1. **Encuentre el stack:** revise los archivos del proyecto, como `package.json`, `pom.xml`, `build.gradle`, `requirements.txt`, `pyproject.toml`, `go.mod`, `*.csproj`, `composer.json`, `Gemfile`, `Dockerfile`, manifiestos de Kubernetes o charts de Helm. Si el stack no está claro, pregúntele al usuario qué monitorear.

2. **Seleccione la guía de instalación:** elija la guía correspondiente de las [guías de instalación](#install-guides) a continuación. Para una URL en `/docs/`, agregue `.md` al final para obtener una versión en markdown.

3. **Mantenga la clave de licencia fuera del contexto:** la clave es un secreto. Nunca necesitará su valor.

   * No le pida la clave al usuario. Si la pega en el chat, indíquele que la revoque y cree una nueva.
   * Haga referencia a la clave únicamente por el nombre `NEW_RELIC_LICENSE_KEY`. Si una guía indica colocar la clave en un archivo de configuración, léala desde esa variable de entorno en su lugar.
   * No ejecute comandos ni lea archivos que muestren la clave, como los archivos `env`, `printenv`, `echo $NEW_RELIC_LICENSE_KEY`, `.env` o los almacenes de secretos.
   * Ejecute `test -n "$NEW_RELIC_LICENSE_KEY" && echo set || echo missing` para comprobar que la clave esté configurada sin exponerla.

4. **Siga la guía:**

   * Pídale al usuario el nombre de una aplicación o sugiera uno basado en el nombre del proyecto.
   * Si la cuenta del usuario está en la [región del centro de datos](/docs/accounts/accounts-billing/account-setup/choose-your-data-center) de la UE o JP, use los extremos que la guía proporciona para esa región.

5. **Verifique:** pídale al usuario que configure `NEW_RELIC_LICENSE_KEY` y reinicie la aplicación, luego siga [Verifique la instalación](#verify). Si no aparecen datos, consulte la página de resolución de problemas indicada para esa tecnología.

6. **Resumir:** indique al usuario qué archivos cambió y dónde encontrar la aplicación en New Relic: <DNT>**APM &amp; Services**</DNT> para aplicaciones, <DNT>**Browser**</DNT> o <DNT>**Mobile**</DNT> para frontends y <DNT>**Infrastructure**</DNT> para hosts.

## Verifique la instalación [#verify]

Verifique en dos etapas: primero que el agente se esté ejecutando, luego que los datos hayan llegado a New Relic.

### Verifique que los datos llegaron a New Relic [#check-data]

Ejecute la consulta para la tecnología que instaló y reemplace cada marcador de posición por el valor que configuró. Los datos pueden tardar algunos minutos en aparecer y algunas consultas solo devuelven resultados después de que la aplicación haya procesado el tráfico.

<table>
<thead>
<tr>
<th style={{ width: "200px" }}>
**Tecnología**
</th>

<th>
**Consultar**
</th>
</tr>
</thead>

<tbody>
<tr>
<td>
Agente APM
</td>

<td>
`SELECT count(*) FROM ApplicationAgentContext WHERE agent.language = 'LANGUAGE' AND appName = 'APP_NAME' SINCE 30 minutes ago`, donde `LANGUAGE` es `nodejs`, `java`, `python`, `dotnet`, `go`, `php` o `ruby`
</td>
</tr>

<tr>
<td>
Cualquier aplicación de APM, después del tráfico
</td>

<td>
`SELECT count(*) FROM Transaction WHERE appName = 'APP_NAME' SINCE 30 minutes ago`
</td>
</tr>

<tr>
<td>
Docker
</td>

<td>
`SELECT count(*) FROM ContainerSample WHERE name = 'CONTAINER_NAME' SINCE 10 minutes ago`
</td>
</tr>

<tr>
<td>
Kubernetes
</td>

<td>
`SELECT count(*) FROM K8sClusterSample WHERE clusterName = 'CLUSTER_NAME' SINCE 10 minutes ago`
</td>
</tr>

<tr>
<td>
Hospedadores
</td>

<td>
`SELECT count(*) FROM SystemSample WHERE hostname = 'HOST_NAME' SINCE 10 minutes ago`
</td>
</tr>

<tr>
<td>
Navegador web, después de cargar una página
</td>

<td>
`SELECT count(*) FROM PageView WHERE appName = 'APP_NAME' SINCE 30 minutes ago`
</td>
</tr>

<tr>
<td>
Mobile, después de una sesión
</td>

<td>
`SELECT count(*) FROM MobileSession WHERE appName = 'APP_NAME' SINCE 30 minutes ago`
</td>
</tr>
</tbody>
</table>

Un recuento superior a cero significa que los datos están fluyendo. Existen dos formas de ejecutar una consulta y ninguna le expone un secreto:

* **Pídale al usuario** que lo pegue en el [generador de consultas](/docs/query-your-data/explore-query-data/query-builder/introduction-query-builder) en New Relic y le indique el resultado.
* **Use la [CLI de New Relic](https://github.com/newrelic/newrelic-cli)** si el usuario la ha instalado y ha configurado un <InlinePopover type="userKey" />como la variable de entorno `NEW_RELIC_API_KEY`. Ejecute `newrelic nrql query --accountId ACCOUNT_ID --query 'QUERY'`. La clave de API del usuario también es un secreto, así que trátela de la misma manera que la clave de licencia.
