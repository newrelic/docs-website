Puede emplear [el dashboard](/docs/query-your-data/explore-query-data/dashboards/introduction-dashboards/) para visualizar y realizar un seguimiento del estado de su sistema, abordar problemas y planear pasos adicionales. Aprenda a compartir toda esa información con su equipo, clientes u otras partes interesadas con varias opciones de importación y exportación.

## Importar dashboards [#import-json]

Importe un dashboard desde su JSON para moverlo a otra cuenta o para modificarlo a nivel de código. Por ejemplo, puede crear un dashboard personalizado fusionando dos existentes en el JSON de un dashboard base. Para obtener el JSON, [descargue el dashboard](#export-dashboards-pdf).

Desde <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Dashboards**</DNT>, use la acción <DNT>**Import dashboard**</DNT> y pegue el JSON. Puede elegir la cuenta y los permisos al importar. No puede cambiar la cuenta después, pero puede [cambiar los permisos](/docs/query-your-data/explore-query-data/dashboards/manage-your-dashboard/#dash-settings) en cualquier momento. La importación requiere permiso para crear dashboard en la cuenta objetivo, y los widget que consultan cuentas a las que no puede acceder no se muestran.

<Callout title="Nota">
Un dashboard importado es una copia. No se mantiene sincronizado con el original, por lo que los cambios posteriores se aplican solo al dashboard que edite.
</Callout>

## Exportar dashboard [#export-dashboards]

### Descargar como JSON, PDF o PNG [#export-dashboards-pdf]

Utilice la acción <DNT>**Download dashboard**</DNT> en el menú <DNT>**...**</DNT> del dashboard para guardar un dashboard en uno de estos formatos:

* **JSON**: mueva un dashboard a otra cuenta o adminístrelo como código, por ejemplo en Terraform. Puede descargar el JSON o copiarlo al portapapeles. El JSON incluye la consulta NRQL y los ID de cuenta de cada widget, independientemente de si exporta los GUID de la entidad o no.
* **PDF y PNG**: comparta una instantánea estática de un dashboard en correos electrónicos, páginas de Confluence o Slack, como las ventas de la semana pasada o los usuarios afectados durante un incidente. Establezca el ancho y el alto en píxeles. Ambos tienen un valor predeterminado de 1920 × 1080.

New Relic no admite [visualizaciones personalizadas](/docs/query-your-data/explore-query-data/dashboards/add-custom-visualizations-your-dashboards/) al exportar un dashboard como PDF o PNG a través de la UI.

### Exportar dashboard a través de NerdGraph [#export-api]

Para exportar dashboards mediante programación con opciones que la UI no ofrece, como anulaciones de variables de plantilla y filtros de entidades, consulte [Tutorial de NerdGraph: exportar dashboards y gráficos como archivos](/docs/apis/nerdgraph/examples/export-dashboards-pdfpng-using-api/#api-dashboard-snapshot).

## Exportar gráficos [#export-charts]

### Exportar como CSV [#export-charts-csv]

Exporte los datos de un gráfico de tabla como archivo CSV con la acción de gráfico <DNT>**Export as CSV**</DNT>.

<img title="Export chart as CSV" alt="Screenshot of how to export a table chart as a CSV file" src="/images/dashboards_screenshot-crop_export-csv.webp" />

### Obtener los datos de un gráfico como JSON [#export-charts-json]

Para obtener la respuesta sin procesar de la consulta de un gráfico en formato JSON, abra <DNT>**View query**</DNT> desde el menú <DNT>**...**</DNT> del gráfico, ejecute la consulta y, luego, establezca el tipo de gráfico en JSON. Puede copiar la respuesta desde allí. Este es el resultado de la consulta, no la configuración del gráfico.

### Obtener un gráfico como imagen o enlace [#chart-image-link]

Comparta un gráfico fuera del dashboard de una de las siguientes dos maneras:

* **Obtener como imagen**: copie un enlace a un PNG del gráfico. El enlace expira después de 90 días.
* **Obtener enlace del gráfico**: cree una URL de gráfico en vivo que cualquier persona pueda ver sin una cuenta de New Relic. Necesita el permiso `Live Url (individual) > Modify`. Consulte [Compartir un gráfico](/docs/query-your-data/explore-query-data/dashboards/share-charts-publicly/#share-chart).

Para crear, enumerar y revocar enlaces de gráficos con NerdGraph, consulte [Tutorial de NerdGraph: crear, enumerar y revocar URL de gráficos de uso compartido público](/docs/apis/nerdgraph/examples/manage-live-chart-urls-via-api/).

### Exportar gráficos a través de NerdGraph [#export-charts-api]

Para generar imágenes de gráficos mediante programación, consulte [Tutorial de NerdGraph: exportar dashboard y gráficos como archivos](/docs/apis/nerdgraph/examples/export-dashboards-pdfpng-using-api/#api-widget-snapshot).
