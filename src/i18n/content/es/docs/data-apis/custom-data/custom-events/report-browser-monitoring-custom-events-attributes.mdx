Puede utilizar el monitoreo del navegador en New Relic para agregar [eventos personalizados y atributos](/docs/insights/insights-data-sources/custom-data/report-custom-event-data).

## Atributo personalizado [#attributes]

Agrega un atributo personalizado a todos los eventos del browser para que puedas consultar o filtrar tus datos para responder más preguntas sobre tu aplicación.

## Evento personalizado [#events]

Emplee el método [`recordCustomEvent`](/docs/browser/new-relic-browser/browser-apis/recordCustomEvent) de la API del browser para capturar cualquier evento con atribución personalizada.

## Acciones de página [#overview]

Emplee la API llamada de la del browser para capturar eventos, acciones, cambios de ruta o cualquier interacción final del usuario con su aplicación.[`addPageAction`](/docs/browser/new-relic-browser/browser-agent-spa-api/add-page-action) La llamada `addPageAction` agrega un evento llamado `PageAction` que contiene el nombre de la acción, los metadatos relacionados con su página y cualquier nombre de atributo personalizado y valores que capture junto con él.

## Crea un evento personalizado [#creating-custom-events]

Para crear un evento `custom` :

1. Asegúrese de que el [agente del navegador esté instalado](/docs/browser/new-relic-browser/installation/install-new-relic-browser-agent) para su aplicación.
2. Llame a la función [`newrelic.recordCustomEvent`](/docs/browser/new-relic-browser/browser-apis/record-custom-event) en la parte relevante del JavaScript de su aplicación.
3. Espere un par de minutos para que la aplicación se ejecute e reporte los eventos `custom` relevantes bajo el tipo de evento que especificó.
4. Ejecute una consulta NRQL del evento que incluya el atributo `eventType` que empleó para capturar el evento (y cualquier atributo asociado que envió junto con el evento).

* Por ejemplo, si envía un evento `custom` con un `eventType` de `Foo` y un atributo de `bar: 123`, podría ejecutar una consulta como esta:
  ```sql
  SELECT * FROM Foo WHERE bar = 123
  ```

## Crear evento PageAction [#creating-pageactions]

Para crear un evento `PageAction` :

1. Asegúrese de que el [agente del navegador esté instalado](/docs/browser/new-relic-browser/installation/install-new-relic-browser-agent) para su aplicación.
2. Llame a la función [`newrelic.addPageAction`](/docs/browser/new-relic-browser/browser-agent-spa-api/newrelicaddpageaction-browser-agent-api) en la parte relevante del JavaScript de su aplicación.
3. Espere un par de minutos hasta que la aplicación se ejecute e informe el evento `PageAction` relevante.
4. Ejecute una [consulta NRQL](/docs/query-data/nrql-new-relic-query-language/nrql-query-examples/insights-query-examples-new-relic-browser-spa) del evento `PageAction` que incluya el atributo `actionName` que utilizó para capturar el evento (y cualquier atributo asociado que envió junto con la acción).

* Por ejemplo, si envía un evento `PageAction` con un `actionName` de `Foo` y un atributo de `bar: 123`, podría ejecutar una consulta como esta:
  ```sql
  SELECT * FROM PageAction WHERE actionName = 'Foo' AND bar = 123
  ```

## Las consideraciones importantes y las mejores prácticas incluyen:

Debes monitorear IA para limitar el número total de tipos de eventos personalizados a aproximadamente cinco. Los tipos de eventos personalizados están pensados para ser empleados para encapsular categorías de alto nivel. Por ejemplo, puede crear un tipo de evento llamado Gestos que contenga muchos eventos con diversos propósitos.

Evite emplear el tipo de evento para nombrar un evento personalizado. Cree tipos de eventos para albergar una categoría de datos y emplee atributos dentro de esa categoría para diferenciar eventos. Si bien puede crear numerosos eventos personalizados, es importante mantener sus datos manejables limitando la cantidad de tipos de eventos informados.
