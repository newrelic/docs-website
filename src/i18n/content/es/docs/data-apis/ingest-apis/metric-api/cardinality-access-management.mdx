Como administrador de dominio de autenticación, realice los siguientes pasos para otorgar acceso a un usuario para gestionar la cuenta y la cardinalidad métrica. Consulte con el usuario sobre sus necesidades específicas y realice la configuración en consecuencia. Para obtener más información sobre la gestión de usuarios, consulte [el tutorial de gestión de usuarios](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/).

<Callout variant="important">
Si el usuario necesita cambiar los presupuestos de cardinalidad mediante NerdGraph o Terraform, consulte [Permisos para NerdGraph y Terraform](#nerdgraph-terraform-permissions).
</Callout>

<Steps>
<Step>
### Agregar licencias a un rol personalizado [#permissions-to-custom-role]

[Cree un nuevo rol personalizado](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/#roles) con las siguientes licencias o agréguelos a un rol existente. Consulte con el usuario para comprender el nivel de acceso requerido.

* `Manage account cardinality`:Ajusta la cotización de cardinalidad de la cuenta.

  * `View`:Puede ver la cotización de cardinalidad de la cuenta.
  * `Modify`: puede actualizar el presupuesto de cardinalidad de la cuenta, en la UI o mediante NerdGraph o Terraform.

* `Manage metric cardinality`:Ajusta la cotización de cardinalidad de la métrica.

  * `View`:Puede ver la cotización de cardinalidad de la métrica.
  * `Modify`: puede actualizar el presupuesto de cardinalidad de las métricas, en la UI o a través de NerdGraph o Terraform.

* `Manage pruning rules`:Gestionar reglas de poda para métrica.

  * `View`:Puede ver las reglas de poda de la métrica.
  * `Modify`:Puede crear y eliminar reglas de poda para la métrica.

* `Customer limits management`:Ajuste los límites de las diferentes capacidades en la cuenta, incluida la cardinalidad.

  * `View`:Puede ver los límites disponibles para las capacidades.
  * `Modify`: puede ajustar los límites de las capacidades, pero no los presupuestos de cardinalidad a través de NerdGraph o Terraform.
</Step>

<Step>
### Agregar rol de usuario y cuenta a un grupo [#group-access]

Para la gestión de cardinalidad, [cree un nuevo grupo](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/#group-access) o gestione un grupo existente de la siguiente manera:

1. Vaya a **[New Relic Administration](https://one.newrelic.com/admin-portal) &gt; Access Management &gt; Groups**.
2. Haga clic en <DNT>**Create a new group**</DNT> o seleccione <DNT>**Manage group access**</DNT> de la lista. <Icon name="fe-more-horizontal" /> Menú de un grupo existente.
3. Para crear un grupo nuevo, proporcione un nombre y haga clic en <DNT>**Create group**</DNT>. Se abre el panel <DNT>**Admin**</DNT> del grupo.
4. En <DNT>**Members**</DNT>, agregue el usuario.
5. En <DNT>**Account access**</DNT>, asocie el rol personalizado con la cuenta deseada para la gestión de cardinalidad.
6. Si la gestión de cardinalidad involucra varias cuentas, en <DNT>**Account access**</DNT>, incluya el rol personalizado para cada cuenta relevante dentro del grupo.
</Step>
</Steps>

## Permisos para NerdGraph y Terraform [#nerdgraph-terraform-permissions]

Puede cambiar los presupuestos de cardinalidad de la cuenta y por métrica en la UI de gestión de cardinalidad, a través de [NerdGraph](/docs/apis/nerdgraph/get-started/introduction-new-relic-nerdgraph) o con el [proveedor de Terraform de New Relic](/docs/more-integrations/terraform/terraform-intro). Para cambiar un presupuesto de cardinalidad a través de NerdGraph o Terraform, el usuario necesita el permiso de cardinalidad para ese presupuesto en cada cuenta que modifique:

| Acción                                              | Permiso requerido para NerdGraph o Terraform |
| --------------------------------------------------- | -------------------------------------------- |
| Ajustar el presupuesto de cardinalidad de la cuenta | `Manage account cardinality: modify`         |
| Ajustar un presupuesto de cardinalidad por métrica  | `Manage metric cardinality: modify`          |

`Customer limits management: modify` no permite a un usuario cambiar los presupuestos de cardinalidad a través de NerdGraph o Terraform. Sigue controlando los demás límites de la cuenta.

Los requests de NerdGraph y Terraform usan una [clave de usuario](/docs/apis/intro-apis/new-relic-api-keys/#user-key), por lo que el request tiene los permisos del usuario que posee la clave. Agregue los permisos al rol de ese usuario y agregue el rol al grupo para cada cuenta que la clave modificará.

<Callout variant="important">
Si NerdGraph o Terraform devuelve un error `Not authorized` al cambiar un presupuesto de cardinalidad, verifique que el usuario propietario de la clave tenga el permiso de la tabla anterior en esa cuenta. La automatización que antes funcionaba solo con `Customer limits management: modify` ahora necesita los permisos de cardinalidad. En NerdGraph, puede cambiar los presupuestos de cardinalidad con la mutación `dataManagementCreateAccountLimit`, utilizando los límites denominados `Dimensional Metric account cardinality ingested per day` y `Dimensional Metric per-metric cardinality ingested per day`.
</Callout>
