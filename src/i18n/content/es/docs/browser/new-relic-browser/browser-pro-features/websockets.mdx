La [API de WebSocket](https://developer.mozilla.org/en-US/docs/Web/API/WebSockets_API) permite abrir una sesión de comunicación interactiva bidireccional entre el navegador del usuario y un servidor. Esta sesión permite enviar y recibir datos sin consultar una respuesta del servidor. Con el monitoreo de browser de New Relic, puede monitorear y rastrear el tráfico y el estado de sus sesiones de websocket.

Los datos de websockets de la API son registrados como eventos de [WebSocket](https://docs.newrelic.com/attribute-dictionary/?dataSource=Browser+agent&event=WebSocket) por el agente de browser. Estos eventos incluyen métricas sobre la conexión, los mensajes recibidos, los datos enviados y cómo se cerró la conexión durante el ciclo de vida del websocket.

## ¿Por qué usar el monitoreo de websockets?

El seguimiento automático de websockets con New Relic proporciona las herramientas y la información valiosa para garantizar que los websockets funcionen como se espera. Con `WebSocket` eventos, puede:

* Monitoree los bytes enviados y recibidos de las conexiones de red
* Examine si los websockets se cierran correctamente o no y el motivo de ello
* Solucione los errores de JavaScript que ocurren durante el ciclo de vida de los websockets
* Cree dashboards personalizados y alertas basadas en websockets

## Requisitos previos [#prerequisites]

* Un agente de browser **Pro** o **Pro + SPA**, versión 1.318.0 o superior.

<Callout variant="important">
  El monitoreo de Websockets no está disponible para el agente de browser Lite
</Callout>

## Habilitar la recopilación automática [#enable-collection]

Mejore la observabilidad y las capacidades de depuración de su aplicación siguiendo estas sencillas instrucciones de configuración.

<Steps>
  <Step>
    Vaya a **[one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Browser**.
  </Step>

  <Step>
    Seleccione la aplicación de su browser .
  </Step>

  <Step>
    En el menú de la izquierda, haga clic en **Application settings**.
  </Step>

  <Step>
    Cerciorar de que esté seleccionado el agente del browser **Pro** o **Pro + SPA** .
  </Step>

  <Step>
    Active **Enable websockets**.
  </Step>
</Steps>

## Deshabilitar la recopilación de websockets [#disable-websockets]

Para deshabilitar los websockets para una aplicación de browser existente:

<Steps>
  <Step>
    Vaya a **[one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Browser**.
  </Step>

  <Step>
    Seleccione la aplicación de su browser .
  </Step>

  <Step>
    En el menú de la izquierda, haga clic en **Application settings**.
  </Step>

  <Step>
    Para deshabilitar los websockets, desactive **Enable websockets**.
  </Step>
</Steps>

## Consumo de datos

`WebSocket` eventos siguen el mismo precio de consumo que los otros bytes de tu navegador. La cantidad de bytes producidos depende del recuento y del atributo de los datos.

Una vez habilitado, el agente capturará automáticamente los websockets a medida que ocurran en la aplicación.

## Encuentra tus datos en New Relic [#find-data]

Los websockets se almacenan como eventos `WebSocket` en New Relic. Consulte el [diccionario de datos](https://docs.newrelic.com/attribute-dictionary/?dataSource=Browser+agent&event=WebSocket) para obtener más información sobre los campos disponibles para usar con `WebSocket` evento. Para obtener un dashboard rápido y útil, consulte este [inicio rápido](https://newrelic.com/instant-observability/browser-web-sockets). Puede consultar y visualizar estos datos para obtener información valiosa sobre el rendimiento de la aplicación:

**Mida la cantidad total de instancias de websocket a lo largo del tiempo**

```nrql
FROM WebSocket
SELECT count(*)
TIMESERIES
```

**Ver los motivos por los que los websockets se cierran inesperadamente**

```nrql
FROM WebSocket
SELECT count(*)
FACET closeReason
```

**Rastrear websockets con errores**

```nrql
FROM WebSocket
SELECT count(*) AS 'Errors'
WHERE hasErrors IS true
TIMESERIES
```

**Ver el promedio de bytes enviados y recibidos**

```nrql
FROM WebSocket
SELECT average(sendBytes), average(messageBytes)
WHERE messageCount IS NOT null
TIMESERIES 
```

**Monitorear la duración promedio de websocket**

```nrql
FROM WebSocket
SELECT average(connectedDuration)
FACET cases(
  WHERE closeWasClean IS true AS 'Connected - Clean',
  WHERE closeWasClean IS NOT true AS 'Connected - Dirty'
)
TIMESERIES
```

Emplee estas consultas o cree las suyas propias para crear dashboards personalizados, configurar alertas y monitorear el rendimiento real de su aplicación sitio web con precisión.
