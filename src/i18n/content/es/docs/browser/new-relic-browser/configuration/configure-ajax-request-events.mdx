En la [versión 1211 del agente](/docs/release-notes/new-relic-browser-release-notes/browser-agent-release-notes/browser-agent-v1211/) o superior, todos los requests de red realizados por una página se registran como eventos `AjaxRequest`. Puede configurar qué requests se registran y qué datos se capturan:

* **[Lista de denegación](#deny-list)**: filtre qué dominios y URL se excluyen del seguimiento de AJAX
* **[Captura de carga](#enable-payload-capture)**: registre los datos completos de la solicitud y la respuesta para depurar fallos

## Lista de denegación [#deny-list]

De forma predeterminada, registramos eventos `AjaxRequest` para todas las solicitudes de red realizadas por su aplicación.

* Para dejar de registrar todos los eventos, agregue un único carácter comodín `*` (asterisco).
  * Ejemplo: `*`
* Para dejar de registrar eventos para un sitio completo, agregue el nombre de dominio.
  * Ejemplo: `mywebsite.com`
* Para dejar de registrar eventos para una página específica, agregue el dominio y la ruta.
  * Ejemplo: `mywebsite.com/photos`
* A partir de la [versión 1.307.0 del agente](/docs/release-notes/new-relic-browser-release-notes/browser-agent-release-notes/browser-agent-v1.307.0/), en cualquier lugar donde encontremos un `*` (asterisco), coincidirá con cualquier longitud de cadena.
  * Ejemplo: `mywebsite.com/shop/*` (para una ruta), `*.mywebsite.com` (para un subdominio), `mywebsite.com/*/shop/*/checkout` (para cadenas de URL intermedias).

La lista de denegación ignora el protocolo, el puerto, la búsqueda y el hash de una URL.

### Accede a la lista de denegados [#access-deny-list]

Para actualizar la lista de URL denegadas que su aplicación filtrará para la creación de eventos, vaya a la página de configuración de la aplicación:

1. Vaya a <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Browser &gt; (select an app) &gt; Settings &gt; Application settings**</DNT>.
2. En la sección <DNT>**AJAX data capture settings**</DNT>, en el campo <DNT>**Deny list**</DNT>, agregue los filtros que desea aplicar a la aplicación.
3. Seleccione <DNT>**Save**</DNT> para actualizar la configuración del agente.
4. [Vuelva a implementar el agente del navegador](/docs/browser/new-relic-browser/installation/upgrade-browser-agent) (ya sea reiniciando el agente <InlinePopover type="apm" />asociado o actualizando la instalación de copiar y pegar del navegador).

<Callout variant="important">
  Guardar los cambios aquí solo actualiza la configuración de `NREUM.init` que se muestra en la página <DNT>**Application settings**</DNT>. No surte efecto automáticamente para los agentes instalados mediante NPM.

  Si instaló el agente del browser mediante el [paquete de NPM](https://www.npmjs.com/package/@newrelic/browser-agent), debe actualizar manualmente el valor de `ajax.deny_list` en la configuración de `init` de la aplicación (o volver a copiarlo desde la UI), y luego volver a compilar e implementar la aplicación para que el cambio surta efecto.
</Callout>

### Validar filtros de la lista de denegación [#validation]

Para validar si los filtros que ha agregado funcionan como se esperaba, ejecute una consulta NRQL para `AjaxRequest` evento que coincida con su filtro.

```sql
FROM AjaxRequest SELECT * WHERE requestUrl LIKE '%example.com%'
```

## Datos de captura de carga [#payload-capture]

<Callout variant="important">
  La captura de carga requiere la versión [1.317.0](/docs/release-notes/new-relic-browser-release-notes/browser-agent-release-notes) o superior del agente del browser.
</Callout>

Puede habilitar la captura de carga para todos los requests o solo para los requests fallidos. Cuando está habilitado, el agente del browser captura las cargas de requests y respuestas para todas las llamadas AJAX de todos los dominios permitidos. Esto es útil para depurar fallas que no son visibles solo desde los metadatos, como errores ocultos en los cuerpos de respuesta.

Cuando habilita la captura de carga de AJAX, el agente del browser agrega los siguientes atributos a los eventos `AjaxRequest`:

* `requestBody`: la carga de la solicitud.
* `requestHeaders`: encabezados de solicitud como JSON.
* `requestQuery`: parámetros de consulta de URL como JSON.
* `responseBody`: la carga de la respuesta.
* `responseHeaders`: los encabezados de respuesta como JSON.
* `ajaxRequest.id`: identificador único para cada request AJAX.

Todos los atributos de datos de carga se truncan a 4096 bytes. Cuando se produce el truncamiento, los últimos 4 bytes se reemplazan con `...` para indicar que el contenido se cortó.

### Habilitar captura de carga [#enable-payload-capture]

Puede habilitar la captura de carga utilizando uno de los siguientes métodos:

<CollapserGroup>
  <Collapser id="enable-ui" title="Habilitar a través de la plataforma de New Relic">
    Para habilitar la captura de carga:

    1. Vaya a <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Browser &gt; (select an app) &gt; Settings &gt; Application settings**</DNT>.

    2. En la sección <DNT>**AJAX data capture settings**</DNT>, habilite el interruptor <DNT>**Capture payload for allowed domains**</DNT>, luego seleccione el modo de captura:

       * <DNT>**Capture only failure responses**</DNT>: captura cargas solo para requests con un código de estado de `0`, un código de `400` o superior, o una firma de error de GraphQL en el `response body`.
       * <DNT>**Capture all responses**</DNT>: captura las cargas para todos los requests, incluidos los exitosos. Utilice esto para depurar fallas ocultas en los cuerpos de respuesta, como errores de GraphQL devueltos con un estado exitoso.

       <Callout variant="important">
         Habilitar la captura de carga para <DNT>**Capture all responses**</DNT> requests puede aumentar su ingesta de datos. Utilice el modo <DNT>**Capture only failure responses**</DNT> a menos que necesite específicamente capturar respuestas exitosas.
       </Callout>

    3. Haga clic en <DNT>**Save**</DNT> para aplicar los cambios.
  </Collapser>

  <Collapser id="configure-nerdgraph" title="Configurar a través de NerdGraph">
    Puede usar la [API de NerdGraph para consultar y actualizar](/docs/apis/nerdgraph/examples/browser-monitoring-config-nerdgraph/#configure-payload-capture) la configuración de captura de carga.

    Los siguientes valores están disponibles para la configuración `capture_payloads`:

    * `"none"`: no captura ningún dato de carga. Esta es la configuración predeterminada.
    * `"failures"`: captura cargas solo para requests con un código de estado de `0`, un código de `400` o superior, o una firma de error de GraphQL en el `response body`.
    * `"all"`: captura los datos de la carga para todas las requests, independientemente del código de estado.
  </Collapser>

  <Collapser id="configure-init" title="Configurar mediante JavaScript">
    Si utiliza el método de instalación de copiar y pegar o de NPM, puede configurar la captura de carga directamente en la configuración de JavaScript.

    #### Copiar/pegar instalación

    Agregue el ajuste `ajax.capture_payloads` a la configuración del navegador antes del cargador del agente:

    ```js
    window.NREUM.init = {
        ...<other init properties>...,
        ajax: {
          deny_list: ["bam.nr-data.net"],
          capture_payloads: 'failures' // or 'none', 'all'
        }
    }
    ```

    #### Instalación de NPM

    Agregue la configuración `ajax.capture_payloads` al inicializar el agente del browser:

    ```js
    import { BrowserAgent } from '@newrelic/browser-agent/loaders/browser-agent'

    const options = {
      init: {
        ...<other init properties>...,
        ajax: {
          deny_list: ["bam.nr-data.net"],
          capture_payloads: 'failures' // or 'none', 'all'
        }
      },
      info: { ... },
      loader_config: { ... }
    }

    new BrowserAgent(options)
    ```

    #### Modos de captura

    Los siguientes valores están disponibles para la configuración `capture_payloads`:

    * `"none"`: no captura ningún dato de carga. Esta es la configuración predeterminada.
    * `"failures"`: captura cargas solo para requests con un código de estado de `0`, un código de `400` o superior, o una firma de error de GraphQL en el `response body`.
    * `"all"`: captura los datos de la carga para todas las requests, independientemente del código de estado.
  </Collapser>
</CollapserGroup>

Cuando habilita la captura de carga por primera vez, New Relic agrega automáticamente reglas de ofuscación de línea de base para proteger los datos confidenciales comunes:

* [**Números de tarjetas de crédito**](/docs/browser/new-relic-browser/configuration/obfuscate-browser-agent-data/#ccn): detecta y enmascara los principales formatos de tarjetas de crédito (Visa, MasterCard, American Express, Discover, etc.)
* [**Números de Seguro Social**](/docs/browser/new-relic-browser/configuration/obfuscate-browser-agent-data/#ssn): detecta y enmascara los patrones de SSN

Puede configurar reglas de ofuscación en la plataforma de New Relic para enmascarar datos confidenciales antes de que se envíen a New Relic. Para obtener más detalles sobre las reglas de ofuscación, consulte [Ofuscar los datos del agente del browser](/docs/browser/new-relic-browser/configuration/obfuscate-browser-agent-data).

Después de habilitar la configuración de captura de carga, puede ver los datos de carga capturados en las siguientes páginas:

* [Detalles de solicitud AJAX](/docs/browser/browser-monitoring/browser-pro-features/ajax-page-identify-time-consuming-calls)
* [Visualización de página](/docs/browser/new-relic-browser/browser-pro-features/page-views-examine-page-performance)
* [Session Replay](/docs/browser/browser-monitoring/browser-pro-features/session-replay/get-started)

### Cómo interactúa la captura de carga con la lista de denegación [#payload-deny-list]

La captura de carga respeta su lista de denegación existente. Para cualquier solicitud AJAX:

* Si la URL está en la lista de denegación, el evento se descarta por completo y no se capturan metadatos ni carga.
* Si la URL no está en la lista de denegación, según su configuración de captura de carga, el agente captura las cargas de solicitud y respuesta y aplica reglas de ofuscación antes de enviar los datos a New Relic.
