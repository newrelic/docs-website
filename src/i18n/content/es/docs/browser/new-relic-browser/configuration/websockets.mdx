## ¿Qué función cumple esta característica?

Esto permite el monitoreo del estado y el tráfico de las conexiones de websockets.

Hay disponible una nueva propiedad en el objeto de inicialización del agente de browser llamada `web_sockets`. Esta configuración controla si se debe emplear la característica de websockets en el agente. Disponible en el agente Browser Pro o Pro + SPA, [versión 1.318.0](/docs/release-notes/new-relic-browser-release-notes/browser-agent-release-notes/browser-agent-v1.318.0) o superior.

## ¿Como lo uso?

Para usar esta característica, deberá visitar la página de configuración de su aplicación y activar el interruptor `"Enable websockets"`. Esta opción está desactivada por defecto.

NerdGraph puede emplear como alternativa para activar y desactivar la configuración. Para ello, ejecute una consulta de mutación en el objeto graphQL `browserSettings` para la propiedad `browserWebSockets`, estableciendo `enabled` en `true` o `false`.

Una vez habilitada, la recopilación de datos para websockets es automática después de volver a desplegar el agente. Los datos de websockets se recopilan como eventos de [WebSocket](https://docs.newrelic.com/attribute-dictionary/?dataSource=Browser+agent&event=WebSocket), que incluyen métricas de conexión, mensajes recibidos, datos enviados y cómo se cerró la conexión. Cada instancia de `WebSocket` se rastrea de forma independiente y emite un evento por vida útil de la conexión.

## Consideraciones adicionales

* Si el [rastreo de sesión](/docs/browser/browser-monitoring/browser-pro-features/session-traces-explore-webpages-life-cycle) está habilitado, los eventos de WebSocket se pueden vincular a través de la propiedad `sessionTraceId` como parte de su rastreo de sesión.
