## El flujo OAuth no se inicia.

* Cerciorar de que su navegador pueda acceder a `localhost`.
* Comprueba la configuración del firewall.
* Verifique que sus herramientas puedan acceder a las URL `OAuth`.

## clave de API no funciona

* Verifique el formato de la clave (comienza con `NRAK-`).
* Verifica las licencias clave en New Relic.
* Cerciorar de que la clave no caducó.

## No se detectó el servidor MCP

* Resetear la aplicación por completo.
* Comprobar la validez de la sintaxis `JSON`.
* Verifique las rutas de los archivos y las licencias.

## Problemas con el proxy remoto de mcp

* Cerciorar de que `Node.js` esté instalado.
* Comprueba la conexión a Internet.
* Verifique que npx pueda acceder al paquete `mcp-remote`.

## Acceso denegado para grupos personalizados

### Problema

No puede conectarse o autenticar correctamente con el servidor New Relic AI MCP y recibe el siguiente mensaje de error: `Missing required capabilities to access MCP server. Please ensure you have the necessary permissions.` Esto suele ocurrir si es afiliado a un grupo de usuarios personalizado sin ninguna concesión a nivel de organización.

### Causa

A su grupo le falta un rol de ámbito organizacional con licencia para leer el servidor MCP. El acceso a esta función de toda la organización debe otorgar explícitamente a su grupo a través de un rol con alcance de organización.

### Resolución

El administrador de su organización que tiene el rol `Authentication Domain Manager` debe implementar una de las siguientes dos soluciones para otorgarle acceso:

1. Otorgue a su grupo un rol con licencia para leer el servidor MCP:

   * El administrador debe agregar uno de los siguientes roles al grupo personalizado al que pertenece: `Organization Read Only`, `Organization Manager` o `Organization Product admin`.
   * El administrador puede crear un [rol personalizado con alcance de organización](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/#roles) y asignarlo a un grupo al que pertenece a través de una [concesión con alcance de organización](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/#access-grants). Esta función personalizada debe incluir la licencia de lectura `New Relic MCP Server`.

2. Agregarte a un grupo autorizado:

   * El administrador debe agregarlo a un grupo de usuarios existente que ya tenga un rol de ámbito de organización con licencia para leer el servidor MCP.

Para obtener información detallada sobre los conceptos de gestión de usuarios, roles y concesiones de organizaciones, consulte la [documentación de gestión de usuariosNew Relic ](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts). Si su organización emplea el Sistema para la Gestión de Identidades entre Dominios (SCIM) para la gestión de usuarios, estos ajustes de grupos y roles deben realizar dentro de su proveedor de identidad externo (IdP).

## Error de conexión inesperado en Claude Code [#connection-error]

### Problema

Recibe un error inesperado al conectar el servidor MCP de New Relic a través de Claude Code.

### Resolución

Ejecute lo siguiente en una terminal nueva y luego vuelva a conectarse:

```shell
claude mcp logout "plugin:nr:nr-mcp-server" 2>&1
```

## Credenciales de OAuth obsoletas en Claude Desktop [#stale-creds]

### Problema

El error de conexión persiste después de cerrar la sesión. Las credenciales de OAuth obsoletas almacenadas en caché en varios almacenes pueden estar provocando que Claude Desktop reutilice credenciales inactivas en lugar de volver a registrarse.

### Resolución

Pídale a Claude que ayude a localizar y borrar las credenciales obsoletas:

```
Stale OAuth client ID or stale refresh and access tokens for MCP server `newrelic-mcp-server` is making
Claude Desktop's Connect reuse dead credentials instead of re-registering. On macOS, find
every store holding it — the "Claude Code-credentials" keychain item (`.mcpOAuth` keys, watch
for a `plugin:` prefix), `~/Library/Application Support/Claude-3p/config.json`
(`custom3pMcpOAuth."newrelic-mcp-server"`), and every registration across `claude mcp list`,
`~/.claude.json`, and project `.mcp.json` files. Show me which stores match before changing
anything; then clear it (quitting Claude Desktop and backing up config.json first), reconnect,
and confirm a new client ID/new access token is issued.
```

## Mensaje de error

* **Conexión rechazada**: Comprueba la URL y la conectividad de red de tus herramientas.
* **Se requiere autenticación**: verifique que la clave de API siga activa y se ingresó correctamente o complete el flujo `OAuth`.
* **Cliente no válido**: problema de configuración `OAuth`, intente con el proxy `mcp-remote`.
* **`Time.UnmarshalJSON`**: Emplear `mcp-remote` proxy para `OAuth`.
