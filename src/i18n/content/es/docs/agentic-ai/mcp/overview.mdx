Ground Truth es la capa de inteligencia operativa de New Relic. Las herramientas de Model Context Protocol (MCP) ayudan a organizar los datos de observabilidad para que los agentes de IA puedan entender mejor el stack de tecnología.

MCP es una forma estándar para que los modelos de IA o agentes reciban información relevante (contexto) sobre un sistema o entorno específico. Este contexto puede ayudar a la IA a comprender la situación actual, realizar tareas con mayor precisión y proporcionar respuestas más útiles. El servidor MCP permite a los agentes de IA compatibles llamar a ciertas herramientas que pueden ayudar a consultar, investigar o actuar sobre los datos de New Relic en lenguaje natural. Esto, a su vez, puede ayudar a acelerar la respuesta a incidentes y el análisis de rendimiento.

## Beneficios potenciales

El servidor MCP ofrece beneficios prácticos para los ingenieros y los equipos de operaciones de las siguientes maneras:

* **Integración directa:** acceda a las herramientas MCP de New Relic directamente desde el entorno de desarrollo compatible. Esto evita cambiar entre diferentes herramientas de IA.
* **Resolución de problemas más rápida:** use MCP para ayudar a encontrar y solucionar problemas rápidamente a partir de los datos de observabilidad, analizar logs de errores y determinar causas probables con información valiosa proporcionada por IA.
* **Consultas operativas:** pídale a su agente de IA que verifique el estado de las alertas, genere reportes de eventos de alerta o analice cómo los despliegues afectan sus sistemas.
* **Consulta de datos simple:** formule preguntas en inglés sencillo y el servidor las convertirá al lenguaje de consulta New Relic (NRQL) para obtener resultados, incluso si no está familiarizado con NRQL.

## Herramientas de desarrollo de IA compatibles [#supported-tools]

New Relic MCP funciona con estos entornos de desarrollo de IA (clientes MCP compatibles):

* **Claude Code:** interfaz de línea de comando para Claude
* **Antigravity CLI:** interfaz de línea de comando para Antigravity
* **Kiro CLI:** interfaz de línea de comando para Kiro
* **Claude Desktop:** aplicación de escritorio para el desarrollo interactivo de IA
* **VS Code:** Entorno de desarrollo integrado con soporte para MCP

Cada entorno ofrece ventajas únicas según las preferencias de su flujo de trabajo. Consulte nuestra [guía de configuración](/docs/agentic-ai/mcp/setup) para obtener instrucciones de configuración específicas del cliente MCP.

## Requisitos previos [#prerequisites]

Para usar New Relic MCP, necesitas:

* Una cuenta de New Relic (MCP está disponible para todas las cuentas: todos los usuarios de datos y CCU pueden acceder a las herramientas principales, los usuarios de aCCU pueden acceder a todas las herramientas, incluidas las avanzadas)
* `Node.js` instalado (necesario para algunos métodos de autenticación)
* Uno de los clientes MCP compatibles mencionados anteriormente instalado

### Acceso de la organización [#org-access]

Antes de poder conectarse, un administrador de New Relic debe realizar lo siguiente:

**Membresía y roles del grupo**

Debe ser miembro de un grupo que tenga asignado un rol de organización predeterminado (`Organization Read Only`, `Organization Manager` o `Organization Product Admin`) o un rol de ámbito de organización personalizado con permiso para leer el servidor MCP. Si el grupo no tiene el permiso requerido, comuníquese con un administrador que tenga el rol `Organization Manager` o `Authentication Domain Manager` para que se lo conceda.

**administrador de control de características**

El administrador de la organización debe habilitar el acceso a MCP a través del [administrador de control de características](/docs/accounts/accounts-billing/new-relic-one-user-management/feature-control-manager/). Los siguientes interruptores controlan el acceso a MCP. **New Relic MCP Server** y **Local Clients** están habilitados de forma predeterminada. Todos los demás subinterruptores están deshabilitados de forma predeterminada y el administrador de New Relic puede habilitarlos según sea necesario.

* **New Relic MCP Server**: requerido para la configuración de MCP. Interruptor principal que debe estar activado para que funcione cualquier acceso a MCP.
* **Clientes locales**: requeridos para conexiones de clientes locales (Claude Code, Claude Desktop, VS Code, Kiro).
* **Claves de API**: requeridas para las conexiones de clave de API, incluidos los scripts automatizados.
* **Herramientas de vista previa**: requeridas si desea acceder a las herramientas de vista previa de MCP (no GA).
* **Atlassian**: requerido para la integración con Atlassian
* **AWS**: requerido para la integración de AWS

### Opciones de autenticación [#auth-options]

* **OAuth (recomendado)**: New Relic proporciona extremos de OAuth preconfigurados:

  * ID del cliente: `pUWGgnjsQ0bydqCbavTPpw==`
  * URL de autorización: `https://oauth2.service.newrelic.com/oauth2/auth`
  * URL del token: `https://oauth2.service.newrelic.com/oauth2/token`
  * Alcances: `["observability:read", "offline", "offline_access"]`

* **Clave de API de usuario**: tenga en cuenta que **algunas herramientas MCP solo son accesibles a través de OAuth**.

  1. Inicie sesión en New Relic.
  2. Seleccione **menú de usuario -&gt; API keys**.
  3. Cree una nueva clave de usuario o copie una existente.
  4. Formato de clave: `NRAK-XXXXXXXXXXXXXXXXXXXXX`.

<Callout variant="important">
  Algunas herramientas solo son accesibles a través de OAuth y no están disponibles cuando se utiliza una clave de API. Estas incluyen herramientas de análisis impulsadas por IA (`natural_language_to_nrql_query`, `generate_alert_insights_report`, `generate_user_impact_report`, `analyze_deployment_impact`) y herramientas de vista previa (`search_traces`, `analyze_trace_anomaly`, `analyze_service_dependencies`). Consulte la [referencia de herramientas](/docs/agentic-ai/mcp/tool-reference) para obtener más detalles.
</Callout>
