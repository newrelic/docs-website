Esta guía le muestra cómo configurar el servidor del Model Context Protocol (MCP) de New Relic con sus clientes de MCP compatibles preferidos. Elija su entorno a continuación para obtener instrucciones específicas de la plataforma.

<Callout variant="important">
  El uso de cualquier herramienta de IA, incluidas, entre otras, las que se enumeran en esta página, con los servidores de MCP de New Relic AI significa que su IA realizará acciones en su cuenta de New Relic en su nombre. Al utilizar cualquiera de los métodos descritos aquí, cree y use cuentas de New Relic adecuadas que tengan los controles de acceso basados en roles (RBAC) deseados y los permisos de menor privilegio adecuados para su caso de uso, requisitos y políticas internas.
</Callout>

Antes de comenzar la configuración de New Relic MCP, cerciorar de completar los [requisitos previos](/docs/agentic-ai/mcp/overview#prerequisites), incluida la configuración de autenticación. A continuación, siga las instrucciones para su entorno de desarrollo específico.

## Filtrado de herramientas con include-tags [#filtering-tools]

Las herramientas de MCP de New Relic se organizan y categorizan mediante etiquetas internas (como `alerting`, `discovery` y `data-access`). Para obtener más detalles, consulte [herramientas de filtrado](/docs/agentic-ai/mcp/tool-reference##filter-tools)

Puedes filtrar dinámicamente las herramientas a las que accede tu agente de IA enviando el encabezado `include-tags` `HTTP` con tus requests como se muestra aquí:

<Callout variant="important">
  **Aviso de región:** los ejemplos de configuración en este tema usan la URL de conexión MCP de la región de EE. UU. (predeterminada): [https://mcp.newrelic.com/mcp/](https://mcp.newrelic.com/mcp/). Si su cuenta de New Relic está en una región diferente, reemplace esta URL con el extremo regional apropiado en todos los archivos de configuración y argumentos de la línea de comando:

  * UE: [https://mcp.eu.newrelic.com/mcp/](https://mcp.eu.newrelic.com/mcp/)
  * JP: [https://mcp.jp.newrelic.com/mcp/](https://mcp.jp.newrelic.com/mcp/)
</Callout>

```json
"servers": {
    "new-relic-mcp-server": {
        "url": "https://mcp.newrelic.com/mcp/",
        "type": "http",
        "headers": {
            "include-tags": "discovery,alerting"
        }
    }
}
```

Para obtener la lista completa de etiquetas disponibles y las herramientas asociadas a cada una, consulte la documentación [de referencia de herramientasNew Relic MCP](/docs/agentic-ai/mcp/tool-reference).

<Callout variant="important">
  A menos que se indique expresamente lo contrario en esta Documentación, solo debe configurar sus clientes de MCP compatibles con el método OAuth. A menos que se indique lo contrario, cualquier configuración con una clave de API no funcionará como se describe en esta Documentación ni como se espera.
</Callout>

## Configuración del código Claude [#claude-code]

Claude Code admite el método de autenticación OAuth. OAuth requiere la versión 2.1.186 de Claude Code o posterior. Si utiliza versiones anteriores, debe autenticarse a través de `/mcp` dentro de Claude en lugar del inicio de sesión de MCP de claude.

1. Cerciorar de tener Claude Code instalado y configurado.

2. Agregue el servidor MCP usando la línea de comando:

   ```shell
   claude mcp add --transport http newrelic https://mcp.newrelic.com/mcp/
   claude mcp login newrelic
   ```

   O bien, edite `~/.claude.json` como se muestra aquí:

   ```json
   {
     "mcpServers": {
       "newrelic": {
         "type": "http",
         "url": "https://mcp.newrelic.com/mcp/"
       }
     }
   }
   ```

3. Siga el flujo de OAuth del navegador para completar la autenticación.

Si encuentra errores de conexión después de la configuración, consulte [Error de conexión inesperado en Claude Code](/docs/agentic-ai/mcp/troubleshoot#connection-error) y [Credenciales de OAuth obsoletas en Claude Desktop](/docs/agentic-ai/mcp/troubleshoot#stale-creds).

## Codex setup [#codex]

Codex supports OAuth authentication method. OAuth requires Codex version 0.154.0 or later.

1. Ensure you have Codex installed and configured.

2. Agregue el servidor MCP usando la línea de comando:

   ```shell
   codex mcp add newrelic --url https://mcp.newrelic.com/mcp/
   ```

   O bien, edite `~/.codex/config.toml` como se muestra aquí:

   ```shell
   [mcp_servers.newrelic]
   url = "https://mcp.newrelic.com/mcp/"
   ```

3. Siga el flujo de OAuth del navegador para completar la autenticación.

## Configuración de la CLI de Antigravity [#antigravity-cli]

<Callout variant="important">
  Actualmente, solo se admite el método de clave de API para la CLI de Antigravity. La compatibilidad con OAuth aún no está disponible.
</Callout>

1. Asegúrese de tener Antigravity CLI instalado en su máquina.

2. Configure el servidor MCP abriendo (o creando) el archivo de configuración:

   * macOS/Linux: `~/.gemini/config/mcp_config.json`
   * Ventanas: `%USERPROFILE%\.gemini\config\mcp_config.json`

   Agregue la siguiente configuración:

   ```json
   {
     "mcpServers": {
       "newrelic": {
         "serverUrl": "https://mcp.newrelic.com/mcp/",
         "headers": {
           "api-key": "NRAK-YOUR-KEY-HERE"
         }
       }
     }
   }
   ```

3. Inicie Antigravity CLI:

   ```shell
   agy
   ```

4. Ejecute `/mcp` para verificar que el servidor de New Relic esté conectado.

## Configuración de la CLI de Kiro [#kiro-cli]

1. Cerciorar de tener la [herramienta Kiro CLI instalada](https://kiro.dev/cli/) en su máquina.
2. Configure el servidor MCP abriendo (o creando) el archivo de configuración ubicado en `~/.kiro/settings/mcp.json` y agregue la siguiente configuración:

```json
{
  "mcpServers": {
    "newrelic-mcp-server": {
      "url": "https://mcp.newrelic.com/mcp/",
      "oauth": {
        "authorizationUrl": "https://oauth2.service.newrelic.com/oauth2/auth",
        "tokenUrl": "https://oauth2.service.newrelic.com/oauth2/token",
        "scopes": ["observability:read", "offline", "offline_access"],
        "usePKCE": true
      },
      "disabled": false
    }
  }
}
```

3. Autenticar y conectar:

   * Abra su terminal y ejecute `kiro-cli`.
   * Escriba el comando `/mcp` y presione Enter.
   * Verá el servidor New Relic listado con una URL. Abra esa URL en su navegador.
   * Complete el proceso de inicio de sesión estándar de New Relic.
   * Una vez autenticado, el navegador confirmará el éxito.

## Configuración de escritorio de Claude [#claude-desktop]

Claude Desktop requiere el proxy `mcp-remote` para la autenticación `OAuth`. Asegúrese de tener `Node.js` instalado en su computadora para que npx funcione.

1. Crea el directorio de configuración (si es necesario):

```shell
mkdir -p "~/Library/Application Support/Claude"
```

2. Edita el archivo de configuración: `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) o `%APPDATA%\Claude\claude_desktop_config.json` (Windows).

   ```json
   {
     "mcpServers": {
       "new-relic-mcp": {
         "command": "npx",
         "args": [
           "-y",
           "mcp-remote",
           "https://mcp.newrelic.com/mcp/"
         ]
       }
     }
   }
   ```

3. Resetear el escritorio de Claude.

## Configuración de VS Code [#vs-code]

Necesita VS Code (versión 1.91 o posterior).

1. Agregue el servidor MCP editando `.vscode/mcp.json` como se muestra aquí:

```json
{
  "servers": {
    "new-relic-mcp": {
      "url": "https://mcp.newrelic.com/mcp/",
      "type": "http"
    }
  }
}
```

2. Crea o abre `mcp.json` en tu espacio de trabajo de VS Code:

   * Si no tienes un directorio `.vscode`, crea uno en la raíz de tu proyecto.

     * Dentro de `.vscode`, cree un archivo llamado `mcp.json`.
     * Agregue su configuración de autenticación.

3. Iniciar servidor:

   * Cerciorar de que su archivo `mcp.json` esté abierto en el editor.
   * Busque un enlace en el que se pueda hacer clic (CodeLens) encima de la configuración de su servidor. Haz clic para iniciar el servidor MCP.

Una vez conectado, puedes interactuar con New Relic AI empleando símbolos de lenguaje natural. El servidor MCP gestionará la autenticación y la recuperación de datos de su cuenta de New Relic.
