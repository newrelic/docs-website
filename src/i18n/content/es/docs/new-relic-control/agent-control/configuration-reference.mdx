Esta página enumera los ajustes de Control de agentes que puede modificar, con sus valores predeterminados. Para obtener una descripción general de la configuración local y remota, y para ver ejemplos de cómo configurar el agente que gestiona Control de agentes, consulte [Gestión de la configuración](/docs/new-relic-control/agent-control/configuration).

La conexión de control de flota (`fleet_control`), `host_id`, el `agents` gestionado y los proveedores de valores se tratan en [Gestión de la configuración](/docs/new-relic-control/agent-control/configuration).

### Sobrescribir los ajustes con variables de entorno [#environment-variables]

Puede establecer cualquier ajuste como variable de entorno. Utilice el prefijo `NR_AC_`, escriba el nombre del ajuste en mayúsculas y utilice un guion bajo doble (`__`) para separar las claves anidadas. Las variables de entorno tienen prioridad sobre el archivo de configuración local.

```bash
# log.level
NR_AC_LOG__LEVEL=DEBUG

# fleet_control.auth_config.client_id
NR_AC_FLEET_CONTROL__AUTH_CONFIG__CLIENT_ID="some-client-id"
```

En los hosts, puede definir estas variables en el archivo de entorno del servicio o en un archivo `environment_variables.yaml` en el directorio de configuración local (`/etc/newrelic-agent-control/` en Linux, `C:\Program Files\New Relic\newrelic-agent-control\` en Windows). El archivo debe ser un mapa YAML plano de claves de cadena a valores de cadena:

```yaml
NR_AC_LOG__LEVEL: "DEBUG"
HTTPS_PROXY: "http://proxy.local:8443"
```

* Las claves deben comenzar con una letra o guion bajo y solo pueden contener letras, dígitos y guiones bajos.
* Control de agentes no supervisa este archivo. Reinicie Control de agentes después de cambiarlo.
* Control de agentes pasa estas variables a los agentes que administra.
* Si el archivo tiene una entrada no válida, Control de agentes no se inicia.

## Proxy: `proxy` [#proxy]

Control de agentes utiliza las variables de entorno `HTTP_PROXY` y `HTTPS_PROXY` de su sistema. También puede configurar un proxy con el ajuste `proxy`. Si se define más de una, Control de agentes las utiliza en este orden de precedencia:

1. La configuración `proxy`
2. La variable de entorno `HTTP_PROXY`
3. La variable de entorno `HTTPS_PROXY`

```yaml
proxy:
  url: https://user:password@proxy.example.com:8080
  ca_bundle_file: /etc/ssl/certs/proxy-ca.pem
```
