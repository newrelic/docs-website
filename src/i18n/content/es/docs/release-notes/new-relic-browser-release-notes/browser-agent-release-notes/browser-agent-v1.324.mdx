## v1.324.0

**[Vea esta versión en GitHub →](https://github.com/newrelic/newrelic-browser-agent/releases/tag/v1.324.0)** para obtener el changelog técnico completo y la información sobre el tamaño de la compilación.

### Característica

#### Mejorar la coincidencia de script en el manifiesto

Los micro frontends registrados con un manifiesto ahora contabilizan cada recurso que coincide con un comparador de manifiestos en sus datos de MicroFrontEndTiming. Anteriormente, cada activo del manifiesto era consumido por su primer recurso coincidente, por lo que un comparador amplio, como una RegExp para fragmentos hash (por ejemplo, /catalog-chunk-\[a-f0-9]+.js/) solo aportaba un fragmento a totalWeight, renderBlocking y a la ventana de tiempo de obtención/ejecución. Todos los fragmentos coincidentes, ya sea que ya estén cargados o se carguen poco después de register(), ahora contribuyen. Por otro lado, cuando se hace referencia a la misma URL del script más de una vez (por ejemplo, una etiqueta `<script>` duplicada, que normalmente se vuelve a servir desde la caché del navegador), el agente ahora mantiene el tiempo de la primera carga en lugar de sobrescribirlo, por lo que un duplicado en caché ya no puede hacer que el tiempo de obtención y ejecución parezca más corto que la carga real.

#### Habilite el rastreo distribuido para micro frontends registrados

Habilita el rastreo distribuido (DT) para los Micro Frontends (MFE) registrados: una llamada AJAX realizada por un MFE registrado ahora establece correctamente la raíz de su traza en la propia entidad de ese MFE, lo que proporciona visibilidad de las propias llamadas al backend de un MFE por primera vez.

### Corrección de errores

#### Prevenir recolecciones de registros descontroladas debido al tamaño inflado del atributo

Se corrigió un error por el cual una página que sobrescribe repetidamente un atributo personalizado podía hacer que el agente enviara una solicitud de logs independiente por cada mensaje de log, inundando la red y agotando los recursos del navegador. El agente ahora rastrea con precisión el tamaño del atributo personalizado cuando se sobrescriben los valores, limita la frecuencia con la que cada característica puede recolectar de forma anticipada y sigue enviando lotes grandes rápidamente para que no se descarte ningún log al hacerlo.

#### fix(jserrors): restablecer la memoria del hash del stack al restablecer la sesión

consulte [https://new-relic.atlassian.net/browse/NR-626097](https://new-relic.atlassian.net/browse/NR-626097) para obtener más detalles Vuelva a enviar el rastreo del stack completo una vez después de un restablecimiento de sesión, en lugar de un hash que el backend ya no pueda resolver debido a los TTL de la caché.

#### encontrar los tiempos del script de la entidad de iframe en el registro

Las entidades de iframe registradas ahora identifican el script que llamó a register() cuando se crean, en lugar de hacerlo después de que el agente principal responda. Anteriormente, la búsqueda se ejecutaba después del ciclo de registro, cuando el script de llamada ya no estaba en el stack de llamadas, por lo que el activo, el tipo y los tiempos de recuperación de la entidad podían faltar o asignarse como atributo al propio script del agente.

## Declaración de apoyo

New Relic recomienda que actualices el agente periódicamente para garantizar que obtengas las últimas características y beneficios de rendimiento. Las versiones anteriores ya no recibirán soporte cuando lleguen [al final de su vida útil](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/). Las fechas de lanzamiento reflejan la fecha de publicación original de la versión del agente.

Las siguientes características se encuentran actualmente en versión preliminar limitada y no recibirán soporte estándar:

* [Monitoreo de micro frontend (MFE)](https://docs-preview.newrelic.com/docs/browser/micro-frontend-monitoring/) mediante la [API register()](https://docs-preview.newrelic.com/docs/browser/register)
* Eventos de tipo [BrowserPerformance “resource”](https://docs.newrelic.com/docs/browser/new-relic-browser/browser-pro-features/page-resources/)

Las nuevas versiones del agente del browser se lanzan a los clientes en pequeñas etapas a lo largo de un periodo de tiempo. Debido a esto, la fecha en que el lanzamiento esté disponible en su cuenta puede no coincidir con la fecha de publicación original. Consulte este [dashboard de estado](https://newrelic.github.io/newrelic-browser-agent-release/) para obtener más información.

De acuerdo con nuestra [política de compatibilidad de navegadores](https://docs.newrelic.com/docs/browser/new-relic-browser/getting-started/compatibility-requirements-browser-monitoring/#browser-types), la v1.324.0 del agente del browser se creó y probó para estos navegadores y rangos de versiones: Chrome 144-154, Edge 144-154, Safari 18-27 y Firefox 146-156. Para dispositivos móviles, la v1.324.0 se compiló y probó para Android OS 17 e iOS Safari 18-26.2.
