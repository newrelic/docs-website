## v1.324.1

**[Vea esta versión en GitHub →](https://github.com/newrelic/newrelic-browser-agent/releases/tag/v1.324.1)** para obtener el changelog técnico completo y la información sobre el tamaño de la compilación.

### Corrección de errores

#### Corrige los indicadores hasMeta/hasSnapshot en las recolecciones de Session Replay

Se solucionó un problema por el que las recopilaciones de Session Replay podían informar incorrectamente `hasMeta` y `hasSnapshot` como `false` en los metadatos de su carga, aunque los datos recopilados incluyeran nodos de instantáneas válidos —más evidente poco después de que una sesión pasara de grabación de solo errores a grabación completa, o cada vez que se reiniciaba el grabador. Estos metadatos se utilizaban en etapas posteriores para determinar si un fragmento de repetición determinado era autosuficiente (es decir, si podía arrancar una repetición por sí solo), por lo que un `false` incorrecto podía provocar que los datos de repetición válidos se procesaran incorrectamente.

### Correcciones de seguridad

#### actualizar fflate a 0.8.3

Se solucionó CVE-2026-45820 - unzipSync podía entrar en un bucle infinito al analizar archivos ZIP64 con formato incorrecto

## Declaración de apoyo

New Relic recomienda que actualices el agente periódicamente para garantizar que obtengas las últimas características y beneficios de rendimiento. Las versiones anteriores ya no recibirán soporte cuando lleguen [al final de su vida útil](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/). Las fechas de lanzamiento reflejan la fecha de publicación original de la versión del agente.

Las siguientes características se encuentran actualmente en versión preliminar limitada y no recibirán soporte estándar:

* [Monitoreo de micro frontend (MFE)](https://docs-preview.newrelic.com/docs/browser/micro-frontend-monitoring/) mediante la [API register()](https://docs-preview.newrelic.com/docs/browser/register)
* Eventos de tipo [BrowserPerformance “resource”](https://docs.newrelic.com/docs/browser/new-relic-browser/browser-pro-features/page-resources/)

Las nuevas versiones del agente del browser se lanzan a los clientes en pequeñas etapas a lo largo de un periodo de tiempo. Debido a esto, la fecha en que el lanzamiento esté disponible en su cuenta puede no coincidir con la fecha de publicación original. Consulte este [dashboard de estado](https://newrelic.github.io/newrelic-browser-agent-release/) para obtener más información.

De acuerdo con nuestra [política de compatibilidad de navegadores](https://docs.newrelic.com/docs/browser/new-relic-browser/getting-started/compatibility-requirements-browser-monitoring/#browser-types), la v1.324.1 del agente del browser se creó y probó para estos navegadores y rangos de versiones: Chrome 144-154, Edge 144-154, Safari 18-27 y Firefox 146-156. Para dispositivos móviles, la v1.324.1 se compiló y probó para Android OS 17 e iOS Safari 18-26.2.
