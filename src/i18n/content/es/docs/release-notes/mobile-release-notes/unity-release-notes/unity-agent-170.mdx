## Mejoras

* Se corrigieron las aplicaciones de iOS que fallaban en el lanzamiento con `Library not loaded: @rpath/NewRelic.framework/NewRelic`. La declaración del administrador de paquetes de Swift agregada en 1.6.0 se ha eliminado y las dependencias de iOS ahora se resuelven solo a través de CocoaPods. Las compilaciones en 1.6.0 hasta 1.6.4 se vieron afectadas a menos que el administrador de paquetes de Swift se deshabilitara manualmente en la configuración de EDM4U iOS Resolver.
* Se solucionó el problema por el que el agente de iOS de New Relic faltaba por completo en las compilaciones de Unity 2019.1 a 2021.2, donde EDM4U suprimió el pod `NewRelicAgent` pero omitió la inyección del administrador de paquetes de Swift porque requiere Unity 2021.3 o una versión más reciente.
* Agente nativo de Android actualizado a la versión 7.8.2
* Agente NDK nativo de Android actualizado a la versión 1.1.5
* Agente nativo de iOS actualizado a la versión 7.7.6
* Las dependencias de iOS ahora se resuelven solo a través de CocoaPods. No es necesario realizar ninguna acción si usó anteriormente el administrador de paquetes de Swift, ya que EDM4U recurre al pod `NewRelicAgent` automáticamente y la configuración **Swift Package Manager Enabled** puede dejarse marcada.
* Si un proyecto de Xcode generado todavía tiene una referencia de paquete `newrelic-ios-agent-spm` de una compilación anterior, elimine el proyecto generado y vuelva a compilar desde Unity para borrarla.
