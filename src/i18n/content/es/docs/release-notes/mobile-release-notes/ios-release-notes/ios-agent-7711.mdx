### Mejoras y optimizaciones

* Session Replay ahora captura texto en las aplicaciones de React Native que usan la arquitectura legacy. El texto dibujado por `RCTTextView` solía registrarse como una vista vacía. Ahora se captura y enmascara de la misma manera que el texto `RCTParagraphComponentView` en la nueva arquitectura.

### Corrección de errores

* Se corrigió el problema por el que Session Replay cargaba el contenido de las vistas bloqueadas. Una vista bloqueada con el identificador de accesibilidad `nr-block` se dibujaba como un cuadro negro, pero su texto aún se enviaba con la reproducción y se podía leer sobre el cuadro en cualquier color que no fuera negro. Una vista de imagen bloqueada también conservaba sus datos de imagen cuando el enmascaramiento de imágenes estaba desactivado. Las vistas bloqueadas ahora se registran en el momento de la captura como un cuadro vacío, sin texto, sin imagen y sin subvistas. Una vista que se bloquea mientras está en la pantalla ahora se actualiza en la reproducción de inmediato, en lugar de mostrar su contenido antiguo hasta la siguiente instantánea completa. Este problema estaba presente en la versión 7.7.10 y anteriores.
* Se corrigió una falla poco común (`SIGSEGV`, o `NSInvalidArgumentException` para un selector no reconocido) en `+[NRMAHTTPUtilities addCrossProcessIdentifier:]`, por lo general a los pocos segundos de iniciar una sesión mientras la aplicación realizaba requests de red. Cada request instrumentado de `NSURLSession` leía la configuración del recopilador del agente y su ID entre procesos sin un bloqueo. Al mismo tiempo, el hilo de recopilación reemplazaba esa configuración y borraba el ID al inicio de la sesión, por lo que un request podía usar un objeto que acababa de liberarse. Ahora ambos se leen y reemplazan de manera segura entre los hilos. También se corrigió una condición de carrera similar cuando se llamaba a `+[NewRelic shutdown]` durante una recopilación. Este problema estaba presente en la versión 7.7.10 y anteriores.
* Se corrigió el problema por el que los requests de red no se registraban después de que el agente recibía una respuesta `/connect` que no podía analizar. El agente almacenaba una configuración vacía hasta la siguiente recolección y descartaba todos los requests registrados en esa ventana. El agente ahora mantiene la configuración existente. Este problema estaba presente en la versión 7.7.10 y anteriores.
* Se corrigió el problema por el que las excepciones controladas guardadas en el dispositivo se descartaban después de una actualización de la aplicación, con el error del servidor &quot;Failed to resolve data: MobileAppVersion&quot;. Las excepciones controladas guardadas se cargaban al inicio de la siguiente sesión, antes de que el agente se hubiera conectado para la nueva versión de la aplicación. Ahora se cargan después de que se completa la conexión. Este problema estaba presente en la versión 7.7.10 y anteriores.
* Se corrigió el problema por el que las excepciones controladas registradas antes de una actualización de la aplicación se reportaban en la nueva versión de la aplicación. Una excepción controlada guardada ahora se carga en la versión de la aplicación en la que se registró. Este problema estaba presente en la versión 7.7.10 y anteriores.
* Se solucionó un problema por el cual `recordCustomEvent:` aceptaba tipos de evento reservados (`Mobile`, `MobileCrash`, `MobileRequest`, `MobileRequestError`, `MobileSession`, `MobileBreadcrumb`) cuando el nuevo sistema de eventos (`NRFeatureFlag_NewEventSystem`) estaba habilitado. El sistema de eventos predeterminado ya rechazaba estos tipos, por lo que el hecho de que se enviara un evento dependía del indicador de característica. Ambos sistemas de eventos ahora los rechazan.
* Se corrigió el problema por el que la herramienta de carga de dSYM (`run-symbol-tool`) no podía convertir un dSYM en un mapa de símbolos cuando una sola línea de código fuente abarcaba 1 MB (`0x100000`) o más de código. Luego, la herramienta recurrió a cargar el dSYM completo. Ahora convierte estas líneas en un mapa de símbolos.
