### Corregido en esta versión

* Se corrigió un error en el que llamar a setUserId con nil siempre iniciaba una nueva sesión.

* Se evitó que los fotogramas antiguos de Session Replay se cargaran con una nueva sesión.

* Se cambió reachability para actualizar una devolución de llamada en caso de cambio en lugar de llamarla cada vez.

* Se corrigió un fallo de invalidación hexadecimal.

* Se corrigió un fallo de vendorId de setUserId.

* Se corrigió la atomicidad en las colecciones de traza de NRMA.

* Se corrigió setUserId para que se mantenga sincrónico.

* Se corrigió un fallo al cambiar Session Replay de un Timer a un DispatchSourceTimer.

* Se corrigió un fallo de NRMAMethodProfiler de CoreData.

* Se corrigió un fallo al hacer que sessionAttributeJSONString tome una instantánea de los diccionarios.

* Se corrigió el texto de MSR al limitar el desplazamiento de compensación de ancho del texto de SwiftUI a su contenido.

* Se corrigió una fuga de memoria de JSErrorController.

* Se corrigió el texto de MSR al hacer referencia al peso de fuente numérico preciso en lugar del atributo binario de negrita.

* Se actualizaron las herramientas de carga de dSYM para agregar el parámetro appVersion a dsym-upload-tools run-symbol-tool.

* Se corrigieron los modales de SwiftUI faltantes en MSR.
