### Nueva característica

* Se actualizó la configuración de compilación de XCFramework para apuntar a una versión de despliegue mínima de iOS 15.0 y tvOS 15.0, en consonancia con los requisitos mínimos de plataforma documentados.

### Corrección de errores

* Se resolvió un bloqueo (`SIGSEGV` dentro de `objc_msgSend`) que ocurría durante las lecturas de configuración de harvest. Ocho propiedades de objeto en `NRMAHarvesterConfiguration` declaradas como `assign` retenían punteros colgantes después del vaciado del autorelease pool de la respuesta `/connect` o del diccionario `NSUserDefaults`.

* Se resolvió un problema en el que se descartaban todas las trazas de actividad de una sesión cuando la respuesta `/connect` omitía el atributo `at_capture`.

* Se corrigió el valor `platform` reportado con errores de React Native para que se reporte como `ReactNative`.

* Se corrigió el campo `agentVersion` en la carga de errores de JavaScript para informar con precisión la versión del agente de iOS en lugar de la versión de la plataforma del host.

* Se actualizó la validación del atributo personalizado: pasar un objeto `NSArray` o `NSDictionary` como atributo de evento ahora registra un error explícito que identifica el tipo no compatible, reemplazando el mensaje de advertencia genérico `"value must be an NSString, NSNumber, or BOOL"`.
