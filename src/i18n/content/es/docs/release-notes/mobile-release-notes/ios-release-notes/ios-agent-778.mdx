### Corrección de errores

* Se solucionó un problema por el que llamar a `recordError` en condiciones de poca memoria podía finalizar la aplicación host. Los informes de errores ahora se descartan y se registran, y los marcos del agente de New Relic se recortan de la parte superior del stack registrado.
* Se solucionó un bloqueo en `NRMALoggerBridge::log` causado por un argumento faltante en una cadena de formato de log al eliminar atributos de sesión. Se corrigieron dos cadenas de formato no válidas adicionales en el mismo componente.
* Se solucionó un problema por el que los timestamp de rastreo distribuido (`tracestate` y la carga `ti`) se enviaban en segundos en lugar de milisegundos al usar el nuevo sistema de eventos.
* Se solucionó un problema en el que los eventos exitosos de `MobileRequest` perdían todos los atributos de rastreo distribuido cuando un SDK multiplataforma pasaba `traceHeaders`.
* Se actualizó el agente nativo para evitar agregar rastreos distribuidos duplicados a las requests reportadas con `traceHeaders` por Flutter, React Native u otros agentes híbridos. Esto se aplica tanto a `MobileRequest` como a `MobileRequestError` en ambos sistemas de eventos.
* Se aplicaron límites mínimos y máximos para las opciones de configuración `MaxEventPoolSize` y `MaxEventBufferTime` (el tiempo máximo de búfer se limitó a 600 segundos).
* Se actualizó `recordCustomEvent` para devolver un valor booleano que indica si el evento se agregó correctamente al usar el nuevo sistema de eventos, en lugar de devolver siempre `YES`.
* Se actualizaron las cargas de errores de JavaScript de React Native para pasar el valor de plataforma `ReactNative` con las mayúsculas y minúsculas correctas, coincidiendo con el comportamiento del agente de Android.
