### Nueva característica

* Se agregó compatibilidad con .NET 11, incluido el entorno de ejecución CoreCLR en Android e iOS, y se eliminaron los objetivos de .NET 9; las excepciones de iOS no controladas en CoreCLR ahora se informan con su rastreo del stack administrado. ([#87](https://github.com/newrelic/newrelic-maui-plugin/pull/87))
* Se agregaron extensiones de privacidad de Session Replay para las vistas de .NET MAUI. ([#102](https://github.com/newrelic/newrelic-maui-plugin/pull/102))

### Mejoras y optimizaciones

* Se actualizó el agente nativo de Android a la versión 7.8.6.
* Se actualizó el agente nativo de iOS a la versión 7.7.11.
