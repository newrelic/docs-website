* Se actualizó el agente nativo de Android a la versión 7.8.4. ([#188](https://github.com/newrelic/newrelic-capacitor-plugin/pull/188))

## Corrección de errores

* Se corrigieron las instalaciones del administrador de paquetes de Swift para aplicaciones con un objetivo de despliegue de iOS inferior a 16.0. El plug-in ahora requiere iOS 15.0, al igual que con CocoaPods. ([#186](https://github.com/newrelic/newrelic-capacitor-plugin/pull/186))
