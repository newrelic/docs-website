### Nueva característica

* Se agregó una opción de configuración `consoleCaptureEnabled` (valor predeterminado `true`) que permite evitar que el agente capture las llamadas de `console.*` como logs. ([#342](https://github.com/newrelic/newrelic-react-native-agent/pull/342))

### Mejoras y optimizaciones

* Se eliminó el token de aplicación de New Relic expuesto. ([#338](https://github.com/newrelic/newrelic-react-native-agent/pull/338))
* Se actualizó el agente nativo de Android a la versión 7.8.5. ([#346](https://github.com/newrelic/newrelic-react-native-agent/pull/346))
* Se actualizó el agente nativo de iOS a la versión 7.7.10. Si usa CocoaPods y su `Podfile.lock` tiene una versión anterior, ejecute `pod update NewRelicAgent` para actualizar a 7.7.10. ([#346](https://github.com/newrelic/newrelic-react-native-agent/pull/346))

### Corrección de errores

* Se solucionó un bloqueo en el que `console.log/warn/error/debug` lanzaba una excepción cuando no se podía serializar un argumento, como un objeto con un getter que lanza una excepción. ([#341](https://github.com/newrelic/newrelic-react-native-agent/pull/341))
