<Callout variant="important" title="Cambio importante en el reporte de errores">
  A partir de la versión 1.9.0, Los errores de JavaScript se informan a través de un nuevo tipo de evento: `MobileJSError`. Con el nuevo Mobile Errors Protocol, los errores de JavaScript de React Native ya no se almacenan en el tipo de evento `MobileHandledException`.

  <DNT>**Action required:**</DNT>

  * <DNT>**Alerts:**</DNT> Actualice sus condiciones de alerta de NRQL para tener como objetivo `MobileJSError`.
  * <DNT>**Dashboards:**</DNT> Actualice cualquier gráfico personalizado que consulte `MobileHandledException` en busca de errores de la capa de JavaScript.
  * <DNT>**Symbolication:**</DNT> Actualice los scripts de compilación a la última versión para admitir la carga de source maps para el nuevo tipo de evento. Consulte el [reporte de errores de JavaScript de React Native](/docs/mobile-monitoring/new-relic-monitoring-react-native/react-native-agent-js-error-reporting).

  Actualice las consultas de la siguiente manera:

  ```sql
  -- Before (1.8.x and lower)
  SELECT count(*) FROM MobileHandledException WHERE platform = 'reactnative'

  -- After (1.9.0 and higher)
  SELECT count(*) FROM MobileJSError
  ```
</Callout>

## Mejoras

* Los errores de JavaScript y los rechazos de promesas no controlados ahora se reportan como un tipo de evento `MobileJSError` de primera clase a través del nuevo Mobile Errors Protocol, en lugar de `MobileHandledException`.
* Se agregó soporte de carga de source maps para simbolizar el rastreo del stack de `MobileJSError` (automático, manual y CodePush/OTA). Consulte el [reporte de errores de JavaScript de React Native](/docs/mobile-monitoring/new-relic-monitoring-react-native/react-native-agent-js-error-reporting).
* Se agregó la opción de configuración `jsErrorReportingEnabled` para habilitar o deshabilitar el reporte de errores de JavaScript (habilitado de forma predeterminada).
* `recordError` ahora acepta los argumentos opcionales `isFatal` y `attributes`, lo que le permite marcar un error como fatal o adjuntar atributos personalizados.
* Se actualizó el agente nativo de Android a la versión 7.8.2.
* Se actualizó el agente nativo de iOS a la versión 7.7.6.
