## Corrección de errores

* Se corrigió la codificación rígida de `andParams: nil` en el puente de iOS, que descartaba silenciosamente los `httpParams` personalizados y los valores de encabezados rastreados de los eventos `MobileRequest`/`MobileRequestError`. Android ya reenviaba los parámetros correctamente.

## Mejoras

* Se actualizó el agente nativo de Android a la versión 7.8.1.
* Se actualizó el agente nativo de iOS a la versión 7.7.6.
