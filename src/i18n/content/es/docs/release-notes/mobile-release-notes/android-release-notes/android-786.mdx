### Mejoras y optimizaciones

* MAUI Session Replay admite el enmascaramiento de texto global (Enmascarar todo, Enmascarar entrada, No enmascarar nada) y el enmascaramiento por vista según etiqueta o clase. Funciona de la misma manera que en Android e iOS nativos, y los campos de contraseña siempre están enmascarados.
* Esta versión se distribuye junto con el agente de Android NDK 1.1.6, que soluciona las fallas del controlador de caídas nativo en dispositivos con PAC habilitado y una caída causada por un stack de señales liberado tras reanudar la aplicación.

### Corrección de errores

* `MobileRequest` Los eventos ya no incluyen los atributos internos `content_type` y `content_length`, que duplicaban `contentType` y `bytesReceived`.
* Se solucionó un bloqueo cuando la aplicación pasa a primer plano y la detección de root lanza una excepción, por ejemplo, un `NullPointerException` de RootBeer en dispositivos SUNMI con Android 14. El agente ahora considera que el dispositivo no está rooteado y continúa ejecutándose.
* Cuando el agente se inicia de forma nativa y el SDK híbrido no establece la plataforma en tiempo de ejecución, el agente ahora la lee de un recurso que distribuye el SDK híbrido. Las aplicaciones de Flutter, React Native, Capacitor y Cordova reportan el `platform` y el `platformVersion` correctos desde el primer evento.

## Declaración de apoyo

Recomendamos actualizar el agente al menos cada tres meses. Encuentre políticas y fechas específicas para el soporte de agentes Android en la [Política de EOL de agentes de monitoreo de celulares](/docs/mobile-monitoring/new-relic-mobile/get-started/mobile-agents-eol-policy/#android-eol).
