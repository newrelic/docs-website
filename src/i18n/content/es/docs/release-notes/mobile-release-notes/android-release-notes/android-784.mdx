### Corrección de errores

* Se resolvió un problema en el que los eventos persistidos se recargaban y reenviaban en cada lanzamiento cuando `EventPersistence` estaba deshabilitado.

* Se corrigió el comportamiento del búfer de eventos para que el agente ahora siga el rango mínimo/máximo para el tiempo del búfer de eventos.

* Se corrigió que `connectionType` se reportara como &quot;desconocido&quot; cuando no se podía resolver el subtipo de red celular.

## Declaración de apoyo

Recomendamos actualizar el agente al menos cada tres meses. Encuentre políticas y fechas específicas para el soporte de agentes Android en la [Política de EOL de agentes de monitoreo de celulares](/docs/mobile-monitoring/new-relic-mobile/get-started/mobile-agents-eol-policy/#android-eol).
