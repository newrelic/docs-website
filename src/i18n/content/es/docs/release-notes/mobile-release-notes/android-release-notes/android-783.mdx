### Mejoras y optimizaciones

* Soporte de AGP 9.4: se agregó soporte para el plug-in de Android Gradle (AGP) 9.4.x al plug-in de Gradle de New Relic.

* Optimización de encabezados de rastreo distribuido: rastreo distribuido simplificado al eliminar el encabezado de solicitud propietario newrelic y depender únicamente de los encabezados estándar traceparent y tracestate del W3C.

* Detección del agente del browser de WebView: se agregaron métricas de compatibilidad para detectar y rastrear si las WebViews activas están utilizando el agente del browser de New Relic.

* Guía de optimización del tamaño del SDK: se agregó documentación sobre las reglas de tree-shaking de ProGuard/R8 para ayudar a los desarrolladores a eliminar el código del agente no utilizado para las características deshabilitadas.

### Corrección de errores

* Corrección de fallo de Session Replay: se corrigió una condición de carrera multihilo al inicializar Curtains en Session Replay que causaba una NullPointerException en el hilo principal.

* Seguimiento del tamaño de la carga de HTTP2: se resolvió un problema en el que el tamaño de la carga de la solicitud de red (bytesReceived) reportaba incorrectamente 0 bytes para flujos de HTTP/2 y Ktor sin encabezado.

* Resolución de fuga de recursos: se resolvió una observación de análisis estático (CWE-404) al cerrar correctamente las instancias de BufferedWriter dentro de SessionReplayFileManager.

## Declaración de apoyo

Recomendamos actualizar el agente al menos cada tres meses. Encuentre políticas y fechas específicas para el soporte de agentes Android en la [Política de EOL de agentes de monitoreo de celulares](/docs/mobile-monitoring/new-relic-mobile/get-started/mobile-agents-eol-policy/#android-eol).
