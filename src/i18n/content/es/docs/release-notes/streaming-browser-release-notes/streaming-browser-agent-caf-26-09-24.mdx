### Nueva característica

* **Exportación de subruta`/browser`:** Ahora está disponible un punto de entrada `@newrelic/video-caf/browser` que excluye el pipeline de dispositivos conectados no utilizado de la dependencia `@newrelic/video-core` empaquetada, manteniendo el paquete ligero. También se incluye un shim de sistema de archivos `browser.js` para los empaquetadores que no respetan el campo `exports`.
* **Exportación con nombre:** `{ CAFTracker }` ahora está disponible como exportación con nombre junto a la exportación predeterminada existente tanto en el punto de entrada raíz como en el de `/browser`.

### Mejoras

* **`@newrelic/video-core` actualizado a 5.1.0**, que incluye archivos de declaración de TypeScript, correcciones de errores de origen y parches de dependencias.
