### Nueva característica

* **Exportación de subruta`/browser`:** ahora está disponible un punto de entrada `@newrelic/video-hls/browser` que excluye el código no utilizado de Vega/dispositivos conectados, lo que reduce el tamaño del paquete para los consumidores de navegadores. También se incluye un shim de sistema de archivos `browser.js` para los empaquetadores que no respetan el campo `exports`.
* **Exportación con nombre:** `{ HLSTracker }` ahora está disponible como exportación con nombre junto a la exportación predeterminada existente tanto en el punto de entrada raíz como en el de `/browser`.

### Mejoras

* **`@newrelic/video-core` actualizado a 5.1.0**, que incluye archivos de declaración de TypeScript, correcciones de errores de origen y parches de dependencias.
