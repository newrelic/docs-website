### Corrección de errores

* Se corrigió el problema por el cual `getSrc()` devolvía la URL temporal de `blob:` del navegador en lugar de la URL real del manifiesto una vez iniciada la reproducción de HLS. El rastreador ahora lee la URL de la instancia subyacente de Hls.js, por lo que la URL real del manifiesto se reporta de manera consistente durante la reproducción.
