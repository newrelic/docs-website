### Nueva característica

* Se agregó el proveedor de valores de Azure Key Vault, que admite la autenticación tanto de identidad administrada como de entidad de servicio.
* La autoinstrumentación ahora obtiene la clave de licencia inyectada como encabezado si no se establece ninguna en todos los sistemas.

### Corrección de errores

* Windows: `install.ps1` ahora detecta y elimina una instalación independiente del agente de infraestructura de New Relic para evitar el reporte duplicado de hosts; si aún es necesario, debe reconfigurarse posteriormente como un subagente administrado por Control de agentes.
* On-host: se corrigieron los reinicios de la integración causados por la sincronización redundante del sistema de archivos y la recreación completa del directorio al escribir archivos de configuración de OHI en el sistema de archivos compartido.
* Se hizo cancelable el retraso inicial de los subprocesos de comprobación de estado para reducir los períodos de espera inactivos del apagado correcto.
* Se corrigieron problemas menores de logging: un campo redundante, un log duplicado, niveles de log incorrecto y uso inconsistente de mayúsculas y minúsculas en los mensajes.
* Control de agentes ahora siempre vuelve a informar su estado de configuración remota al inicio, lo que soluciona un reenvío omitido después del reinicio cuando el servidor realiza requests de una sincronización de estado completo.
* Windows: el apagado/reinicio del sistema pasa por la misma ruta de detención correcta del servicio que una detención manual del servicio en lugar del manejo de señales de control.
