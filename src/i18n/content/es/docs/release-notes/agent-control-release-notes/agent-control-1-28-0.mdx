### Nueva característica

* El análisis de YAML ahora es más estricto con respecto a los mapas vacíos: un valor nulo (un valor vacío, `~` o `null`) donde se espera un mapa, como un `config:` simple en una configuración remota almacenada, se rechaza en lugar de tratarse como un mapa vacío. Use `{}` para un mapa vacío. Los documentos vacíos aún se aceptan.

### Corrección de errores

* En el host: la limpieza del sistema de archivos compartido ya no sigue los enlaces simbólicos, por lo que el contenido fuera del sistema de archivos compartido nunca se elimina y se eliminan los enlaces simbólicos rotos.
* En el host: los errores de inicio que ocurren antes de configurar el logging (por ejemplo, un `local_config.yaml` no válido) ahora se escriben en el archivo de log predeterminado de Control de agentes, por lo que son visibles al ejecutarse como un servicio de Windows.
* En el host: las requests del registro de OCI ahora pasan por el proxy configurado independientemente del esquema de URL del proxy, por lo que ya no se omite un proxy `http://`.
* En el host: un subagente eliminado por una señal (por ejemplo, por el OOM killer) ahora se reporta como terminado por esa señal en lugar de &quot;process exited with code: 0&quot;.
