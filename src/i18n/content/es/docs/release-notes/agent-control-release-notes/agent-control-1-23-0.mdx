### Nueva característica

* Agregar soporte para la sobrescritura de variables mediante la sintaxis `variable.agentConfig` en las claves de configuración remota.
* Agregar soporte para una única entrada de sobrescritura de variable `string_map` mediante la sintaxis `variable.agentConfig.<variable>:<map-key>` en las claves de configuración remota.
* Tipo de agente de infraestructura en el host (linux): exponer la configuración de integración de `nri-docker` a través de una nueva variable `config_docker`.
* Tipo de agente: exigir que el formato del nombre de la variable sea `[A-Za-z0-9_-]`, que comience con una letra y tenga una longitud máxima de 64 caracteres.
* En el host: habilitar la capacidad de actualización automática de forma predeterminada. Las actualizaciones automáticas solo se ejecutan cuando lo ordena el control de flota.

### Corrección de errores

* Supervisor de K8s: forzar una reconciliación de Flux en HelmReleases estancados (p. ej., después de agotar los reintentos de instalación/actualización) cuando llega una nueva configuración remota y reinicia el supervisor del subagente.
* En el host: informar la última falla real (error de lanzamiento o salida distinta de cero) en el `lastErrorMessage` del estado no saludable una vez que se excede la política de reinicio, en lugar del mensaje genérico &quot;Restart policy exceeded&quot;.
* En el host: conservar el directorio de inicio de fluent-bit (`fb.db`) durante las actualizaciones del paquete infra-agent en lugar de almacenarlo en el directorio del paquete reemplazado
