### Nueva característica

* En el host: imponer un límite estricto de memoria de 2400 MiB en el árbol de procesos de Agent Control (AC + todos los agentes secundarios) mediante systemd `MemoryMax` en Linux.

### Corrección de errores

* Linux: evitar la desactivación del servicio systemd después de la actualización del paquete RPM

### Actualizaciones de seguridad

* Se actualizó el crate de Rust futures a 0.3.34
* Se actualizó alpine/helm a v4.2.4
* Se actualizó el crate de Rust serde-saphyr a 1.1.0

Para obtener una descripción detallada de los cambios, consulte las [notas de la versión](https://github.com/newrelic/newrelic-agent-control/releases/tag/1.22.0).
