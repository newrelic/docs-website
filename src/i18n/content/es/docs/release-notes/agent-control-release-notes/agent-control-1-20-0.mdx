### Nueva característica

* Kubernetes: `--release-name` ahora es opcional en `uninstall-agent-control`; omitirlo evita eliminar los CR de HelmRelease/HelmRepository de la propia versión.
* On-host: se agregaron los agentTypes nri-apache y nri-nginx.
* On-host: se agregó el agentType nri-postgresql.
* On-host: se agregó el agentType nri-mysql.
* On-host: se agregó el tipo de agente nri-memcached.
* Los archivos de log rotados ahora tienen 30 días de retención.
* Se agregó el subcomando `agent-type validate --file <path>` a `newrelic-agent-control-cli` y `newrelic-agent-control-k8s-cli` para la validación a nivel de esquema de los archivos de definición de tipo de agente.
* Se extendió `agent-type validate` con validación semántica: cada referencia a `${nr-var:X}` en `deployment` debe tener una declaración `variables` coincidente.
* Habilitar la caché para el registro remoto de tipos de agente
