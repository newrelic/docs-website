### Nueva característica

* Se agregó el proveedor de valores de AWS Secrets Manager (`nr-awssm`), que admite credenciales de clave de acceso y perfiles de instancias EC2.
* Linux y Windows: Control de agentes y sus subagentes ahora reportan `os.version` y `host.arch` como atributos de OpAMP. Linux también reporta `os.name` (el ID de la distribución, p. ej., &quot;debian&quot;).

### Corrección de errores

* En el host: los subagentes sin una comprobación de estado definida ya no registran errores de ejecutables que publican el estado en un canal cerrado.
* Los clientes HTTP ya no obtienen la configuración del proxy fuera de la configuración del proxy de Control de agentes y `ignore_system_proxy: true` se respeta por completo.
* On-host: la salida del subagente que contiene bytes no UTF-8 ya no detiene el reenvío de logs ni finaliza el subagente. Dichas líneas ahora se registran con los bytes no válidos reemplazados.
* Windows: una actualización automática que falla durante la fase de prueba del nuevo binario ya no deja a Control de agentes sin un ejecutable, lo que impedía que el servicio se iniciara después del siguiente reinicio.
