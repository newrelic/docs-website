### Nueva característica

* Sistema de archivos de Windows: se eliminó el código no utilizado y se utilizan API de nivel superior para la interacción con Windows.
* Reporta la capacidad personalizada de OpAMP `com.newrelic.remoteAgentTypeRepoReachable` cuando el respositorio OCI del tipo de agente configurado está accesible al inicio.
* On-host: se agregó el agentType nri-flex.

### Corrección de errores

* Windows: se corrigieron los archivos en los directorios administrados del control del agente que quedaban con permisos que no podía usar. Los directorios administrados ahora usan una ACE de administrador heredable, y el control del agente intenta reparar las ACE al inicio.
