## Mejoras

* **`DotNet/Agent/Installed`:** se actualizó la tarea para detectar las DLL del agente de .NET cuando `newrelic.config` está ausente y se habilitó la coincidencia sin distinción de mayúsculas y minúsculas para `newrelic.config`. Anteriormente, la falta de un archivo de configuración impedía la detección del agente y omitía las tareas posteriores de .NET ([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* **`DotNet/Config/Agent`:** se actualizó la tarea para emitir una advertencia en lugar de un error cuando falta `newrelic.config` ([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* **Configuración de .NET Core:** se actualizó la recopilación de archivos para reunir y analizar archivos de configuración específicos del entorno (como `appsettings.Production.json`). Ya no se recopilan archivos no relacionados con patrones de nomenclatura similares (como `myappsettings.json`) ([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* **Instrumentación personalizada de .NET Core:** se actualizaron las tareas del lector XML para inspeccionar los directorios `extensions` y `extensions/netcore` del agente, en consonancia con la lógica de resolución de archivos del generador de perfiles ([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* **Logs del agente de .NET:** se actualizó el filtrado de logs para que el límite de 1 día se aplique exclusivamente a los logs del generador de perfiles, lo que preserva los logs del agente de los 7 días anteriores. Los logs del generador de perfiles ahora también respetan la marca `-lastModifiedDate` ([#276](https://github.com/newrelic/newrelic-diagnostics-cli/pull/276)).
* **Comprobaciones de versión y EOL del agente de .NET:** se actualizaron los parámetros de fin de vida útil (EOL) y de versión compatible para el agente de .NET. Se agregó la detección discreta para las versiones 4.7.1, 4.7.2, 4.8 y 4.8.1 del framework de .NET, y se habilitó la recopilación de versiones para el agente de .NET Core ([#273](https://github.com/newrelic/newrelic-diagnostics-cli/pull/273)).
* **Nivel de logs del agente de .NET:** se actualizaron las configuraciones del nivel de logs para evaluar los ajustes sin distinción de mayúsculas y minúsculas, lo que coincide con el comportamiento del tiempo de ejecución del agente de .NET ([#274](https://github.com/newrelic/newrelic-diagnostics-cli/pull/274)).
* **Comprobación de TLS de .NET:** se actualizó la validación del registro para que la falta de una clave `SchUseStrongCrypto` ya no se marque como un error, ya que las versiones compatibles del framework de .NET usan TLS 1.2 de forma predeterminada cuando la clave está ausente. Ahora solo se informa un error cuando la clave existe y se establece en un valor distinto de `1` ([#275](https://github.com/newrelic/newrelic-diagnostics-cli/pull/275)).

## Corrección de errores

* Se solucionó un problema por el que las cargas a la región de datos de Japón fallaban debido a una URL de carga no asignada en las compilaciones de lanzamiento ([#277](https://github.com/newrelic/newrelic-diagnostics-cli/pull/277)).
* Se solucionó un problema en la validación de la variable de entorno de generación de perfiles del framework de .NET para comprobar correctamente `COR_ENABLE_PROFILING`. Se agregó compatibilidad tanto para `NEW_RELIC_LOG_DIRECTORY` como para `NEWRELIC_LOG_DIRECTORY` al resolver las ubicaciones de los logs del agente de .NET ([#272](https://github.com/newrelic/newrelic-diagnostics-cli/pull/272)).
* Se solucionó un problema por el que los valores de las variables de entorno que contenían signos de igual (`=`) se truncaban durante el análisis ([#272](https://github.com/newrelic/newrelic-diagnostics-cli/pull/272)).
