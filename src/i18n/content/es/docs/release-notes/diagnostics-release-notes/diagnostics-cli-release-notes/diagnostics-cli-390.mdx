## Nueva característica

* Hemos agregado una nueva suite y las siguientes tareas para el control del agente ([#268](https://github.com/newrelic/newrelic-diagnostics-cli/pull/268)):

  * `onhost-agent-control` suite - Recopila información sobre los registros de agent-control, el estado, la conectividad y los recursos en el host. Para usarlo, ejecute `nrdiag -suites onhost-agent-control`.
  * AgentControl/Config/Agent - Detecta agent-control a través de PATH, rutas de instalación conocidas y el directorio de datos como alternativa; recopila todos los archivos YAML de fleet-data y local-data, conservando la estructura de directorios original para todos los subagentes registrados
  * AgentControl/Config/DirTree - Escribe un árbol de directorios formateado de todas las rutas de instalación de agent-control en el zip para la inspección de la estructura
  * AgentControl/agente/Connect - Comprueba la accesibilidad TCP/TLS de los extremos de OpAMP, JWKS y del token OAuth2 (leyendo las URL de local\_config.yaml); valida que la clave privada de identidad local sea una clave PKCS8 legible y analizable (RSA, Ed25519 o ECDSA)
  * AgentControl/agente/Logs - En Linux, recopila logs a través de `journalctl -u newrelic-agent-control`; en Windows, agrupa todos los archivos `*.newrelic-agent-control.log` rotados por fecha del directorio de logs predeterminado
  * AgentControl/Agent/StatusServer - consulta el servidor de estado local en el host/puerto configurado en local\_config.yaml (por defecto 127.0.0.1:51200) y guarda la respuesta JSON en el zip de diagnósticos
