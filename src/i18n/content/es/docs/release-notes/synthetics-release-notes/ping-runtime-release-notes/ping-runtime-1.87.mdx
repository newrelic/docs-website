<Callout variant="important">
New Relic escanea la imagen de tiempo de ejecución de Ping en busca de vulnerabilidades todos los días y publica una versión con parches todos los jueves. Cada versión incluye correcciones para los CVE del sistema operativo y de la aplicación identificados hasta el martes a las 6:29 p. m. UTC de esa semana. Si identificamos un CVE después de esa hora, la corrección se incluye en la versión del jueves de la semana siguiente.

Publicamos cada versión en la etiqueta `latest`, por lo que las ubicaciones privadas que usan `latest` reciben las correcciones automáticamente. Si usa una etiqueta de versión específica, actualice manualmente a la versión más reciente para obtener las correcciones actuales.
</Callout>
