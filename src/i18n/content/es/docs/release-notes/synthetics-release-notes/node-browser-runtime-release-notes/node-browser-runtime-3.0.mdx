<Callout variant="important">
New Relic escanea la imagen del entorno de ejecución del navegador Node en busca de vulnerabilidades todos los días y publica una versión parcheada todos los jueves. Cada versión incluye correcciones para los CVE del sistema operativo, la aplicación y Chrome identificados hasta el martes a las 6:29 p. m. UTC de esa semana. Si identificamos un CVE después de esa hora, la corrección se incluye en la versión del jueves de la semana siguiente.

Publicamos cada versión en la etiqueta `latest`, que ejecuta Node.js 22 y la última versión estable de Chrome. Las ubicaciones privadas que utilizan `latest` reciben correcciones automáticamente. Si utiliza una etiqueta de versión específica, actualice manualmente a la versión más reciente para obtener las correcciones actuales.
</Callout>
