### Corrección de errores

* Se corrigieron los retrasos de clic de 12-30 segundos en las aplicaciones de Angular y Zone.js. La extensión de navegador de Sintéticos ahora se carga mediante CDP WebSocket (`Extensions.loadUnpacked`) en lugar de BiDi (`webExtension.install`). BiDi de Chrome 153+ introdujo una comprobación de &quot;Waiting for pending navigations&quot; después de cada clic que bloqueaba las respuestas en aplicaciones con macrotareas pendientes. Cambiar a CDP mantiene a BiDi fuera de la sesión, lo que restaura la clásica comprobación de navegación `document.readyState` de menos de un milisegundo de ChromeDriver.
