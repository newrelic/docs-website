### Característica

* Compatibilidad con Google IMA DAI (inserción dinámica de anuncios) en `NRTrackerIMA`
* Habilite el logging con el nivel INFO, y registre la capacidad casi máxima del búfer y los eventos descartados, replicando la API `enableLogging` de iOS.

### Corrección de errores

* Se corrigió el seguimiento de anuncios de IMA para que los anuncios interrumpidos por el final de una pausa se cierren, se ignoren los eventos de cuartil y de clic aislados, los temporizadores por anuncio ya no se trasladen a la siguiente pausa y la duración del anuncio se reporte en milisegundos.
