### Corrección de errores

* **ExoPlayer/HLS:** `contentBitrate` siempre reportaba `0` para las transmisiones HLS. media3 clasifica internamente las cargas de segmentos HLS mixtos de audio + video como `TRACK_TYPE_DEFAULT` en lugar de `TRACK_TYPE_VIDEO` (a diferencia de DASH y las transmisiones progresivas, que no se vieron afectadas). La lógica de captura de tasa de bits del rastreador solo se activaba para `TRACK_TYPE_VIDEO`, por lo que las cargas HLS nunca completaban el campo. `contentBitrate` ahora refleja correctamente la tasa de bits real de la transmisión para el contenido HLS.
