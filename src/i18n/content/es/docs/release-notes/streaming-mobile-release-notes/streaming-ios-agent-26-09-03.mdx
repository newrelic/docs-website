### Nueva característica

* Se agregó soporte para el administrador de paquetes de Swift.
* `NRMediaTailorTracker`: se agregó un nuevo rastreador de inserción de anuncios del lado del servidor (SSAI) de AWS MediaTailor para AVPlayer (iOS 12+ y tvOS 12+), que ofrece paridad de características con `NRIMATracker`.

### Corrección de errores

* `ios-publish`: lógica de reintento modificada para sobrevivir a fallas parciales del pipeline.
