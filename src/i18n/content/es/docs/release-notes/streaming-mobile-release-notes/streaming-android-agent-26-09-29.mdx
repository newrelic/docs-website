### Cambios disruptivos

* **API del rastreador de THEOplayer corregida:** `NRTrackerTHEOPlayer` ahora acepta una instancia de `Player` de THEOplayer en lugar de un `THEOplayerView`. Actualice la integración para pasar la instancia de `theoplayer` en lugar de la vista en sí. El rastreador ya no actúa como proxy del ciclo de vida de Activity —reenvíe `onResume()`, `onPause()` y `onDestroy()` directamente a `THEOplayerView`.
