### ⚠ CAMBIOS CRÍTICOS

* `NRVAVideo.addPlayer()`: ahora retorna sin crear un rastreador cuando no puede identificar el tipo de reproductor y no se estableció un `playerType` explícito, en lugar de usar silenciosamente un rastreador de AVPlayer de forma predeterminada. Si pasa un objeto de reproductor personalizado o encapsulado, establezca `NRVAVideoPlayerConfiguration.playerType` explícitamente.

### Característica

* `NRTHEOplayerTracker`: se agregó un nuevo rastreador para THEOplayer (Dolby OptiView Player) —eventos del ciclo de vida del contenido, seguimiento de QoE/representación y mapeo de errores. Solo iOS, iOS 13.0+. Disponible a través de CocoaPods, XCFrameworks y el administrador de paquetes de Swift.
