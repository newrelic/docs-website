### Corrección de errores

* Se solucionó un problema por el cual el agente APM de Python registraba un error de decodificación JSON en cada recolección al enviar datos a través del gateway, lo que causaba logs duplicados y pérdida de datos de error. Ahora, el gateway responde a las requests de datos del agente APM con HTTP `202 Accepted` y un cuerpo vacío, tal como lo especifica el protocolo del agente.
* Se solucionó un problema por el cual los eventos de span de los agentes APM se registraban con la hora en que el gateway los recibía en lugar de la hora de inicio del span.

### Actualizaciones de seguridad

* Se actualizó la dependencia `golang.org/x/net` a `v0.62.0` para resolver vulnerabilidades de gravedad alta y media.
