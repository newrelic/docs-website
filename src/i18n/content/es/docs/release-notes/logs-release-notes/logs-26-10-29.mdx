### Nueva característica

* Los paquetes nativos ya están disponibles para Debian 13 (Trixie).
* Los paquetes nativos ya están disponibles para Windows Server 2025 (LTSC).
* La [imagen de Docker del plug-in de salida de Fluent Bit](https://hub.docker.com/r/newrelic/newrelic-fluentbit-output) ahora publica una variante de Windows Server 2025 (LTSC).

### Mejoras y optimizaciones

* Fluent Bit se actualizó a la versión 5.1.5. Para obtener más detalles, consulte los [anuncios de Fluent Bit](https://fluentbit.io/announcements/).
* Esta versión incluye el [plug-in de salida de Fluent Bit de New Relic 3.12.0](https://github.com/newrelic/newrelic-fluent-bit-output/releases/tag/v3.12.0).
* El agente de infraestructura recomienda Fluent Bit 5.1.5 paquetes para Linux y Windows.
* La [imagen de Docker del plug-in de salida de Fluent Bit](https://hub.docker.com/r/newrelic/newrelic-fluentbit-output) para Linux utiliza Fluent Bit 5.1.5 con el plug-in de salida 3.12.0. Las variantes de la imagen de Windows incluyen el plug-in de salida 3.12.0 y mantienen sus versiones existentes de Fluent Bit: 5.1.2 para Windows Server 2022 y 2025, y 4.0.3 para Windows Server 2019.
* El [chart de Helm de New Relic Logging](https://github.com/newrelic/helm-charts/tree/master/charts/newrelic-logging) se actualiza a la versión 1.44.0 e instala la nueva imagen del plug-in.
* Los paquetes de Debian 11 (Bullseye) ya no se compilan porque la distribución llegó al fin de su vida útil.

### Actualizaciones de seguridad

* La versión de Go se actualiza a 1.27.3 para aplicar correcciones de CVE, incluido el bloqueo de las claves de CA intermedias comprometidas de eMudhra.
* La imagen de Docker para Linux ya no confía en los certificados raíz emSign ECC Root CA - G3 y AAA Certificate Services.
