### Actualizaciones de seguridad

* La [AWS Unified Lambda](https://github.com/newrelic/aws-unified-lambda) se actualiza a la versión 1.1.5, lo que actualiza Go a 1.27.3 para aplicar correcciones de CVE.
* La [Lambda AWS-log-ingestion](https://github.com/newrelic/aws-log-ingestion) se actualiza a la versión 2.11.5 para corregir [CVE-2026-111064](https://nvd.nist.gov/vuln/detail/CVE-2026-111064) y [CVE-2026-111066](https://nvd.nist.gov/vuln/detail/CVE-2026-111066). Esta versión actualiza la biblioteca aiohttp a 3.14.5 y yarl a 1.25.1, junto con las dependencias relacionadas.
* La [AWS\_s3\_log\_ingestion\_lambda](https://github.com/newrelic/aws_s3_log_ingestion_lambda) se actualiza a la versión 1.4.4 para corregir las dependencias vulnerables de certifi. Esta versión actualiza la biblioteca certifi a 2026.10.23, junto con las dependencias relacionadas.
