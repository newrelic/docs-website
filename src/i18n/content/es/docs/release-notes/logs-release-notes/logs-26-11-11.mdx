### Cambio de compatibilidad

La [plantilla de Dataflow de Google Cloud Pub/Sub a New Relic](https://github.com/newrelic-forks/DataflowTemplates) se actualiza a Apache Beam 2.77.0, lo que la mantiene en un SDK compatible con GCP. Para compilar y ejecutar la plantilla, se requiere Java 11 o una versión posterior. Si utiliza Java 8 para compilar o ejecutar la plantilla, actualice el JDK antes de usar la versión actualizada.
