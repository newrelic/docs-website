## v10.7.1

* **Corrección de error: resuelve ArgumentError en operaciones de múltiples claves con Dalli 5.1.0**

  Esta corrección actualiza la instrumentación de Dalli para aceptar y reenviar argumentos de opciones de solicitud opcionales en operaciones múltiples y en canalización. ¡Agradecemos a [@dbackeus](https://github.com/dbackeus) por contribuir con una corrección! [PR#3642](https://github.com/newrelic/newrelic-ruby-agent/pull/3642)

* **Corrección de error: las requests de Async::HTTP ya no generan `NoMethodError` cuando un segmento no se inicia**

  Si el agente encontraba un error interno al crear el segmento para una request de `Async::HTTP`, la instrumentación continuaba usando ese segmento faltante y podía generar un `NoMethodError`. Esto ya está solucionado, gracias a [@ydah](https://github.com/ydah). [PR#3640](https://github.com/newrelic/newrelic-ruby-agent/pull/3640)
