## v8.12.0

La versión 8.12.0 del agente de Ruby ofrece una nueva instrumentación de Elasticsearch. La versión 8.12.0 del agente de Ruby también aumenta el número predeterminado de eventos personalizados registrados, anuncia la obsolescencia de Ruby 2.3 y aporta una valiosa limpieza de código.

* **Soporte para la instrumentación de Elasticsearch**

  Esta versión del agente de Ruby agrega compatibilidad para instrumentar automáticamente la gema [elasticsearch](https://rubygems.org/gems/elasticsearch). Las versiones 7.x y 8.x son compatibles. [PR#1525](https://github.com/newrelic/newrelic-ruby-agent/pull/1525)

  | Nombre de la configuración        | Por defecto | Comportamiento                                                                                                                               |
  | --------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
  | `instrumentation.elasticsearch`   | auto        | Controla la instrumentación automática de la biblioteca de elasticsearch al inicio. Puede ser uno de `auto`, `prepend`, `chain`, `disabled`. |
  | `elasticsearch.capture_queries`   | verdadero   | Si `true`, el agente captura la consulta de Elasticsearch en la traza de la transacción.                                                     |
  | `elasticsearch.obfuscate_queries` | verdadero   | Si `true`, el agente confunde la consulta de Elasticsearch en la traza de la transacción.                                                    |

* **Aumento del límite de eventos personalizados**

  Esta versión del agente de Ruby aumenta el límite predeterminado de eventos personalizados de 1000 eventos por minuto a 3000 eventos por minuto. Si se estaban limitando los eventos personalizados, este cambio permitirá enviar más eventos personalizados a New Relic. También hay un nuevo límite máximo configurable de 100 000 eventos por minuto. Para cambiar los límites, consulte la documentación de [max\_samples\_stored](https://docs.newrelic.com/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration/#custom_insights_events-max_samples_stored). Para obtener más información sobre el cambio y cómo determinar si se están descartando eventos personalizados, consulte nuestra [publicación](https://support.newrelic.com/s/hubtopic/aAX8W0000008dby/send-more-custom-events-with-the-latest-apm-agents) en el Explorers Hub. [PR#1541](https://github.com/newrelic/newrelic-ruby-agent/pull/1541)

* **Se descontinuó el soporte para Ruby 2.3**

  Ruby 2.3 llegó al final de su vida útil el 31 de marzo de 2019. El agente de Ruby ha descontinuado el soporte para Ruby 2.3 y realizará cambios importantes para esta versión en su próximo lanzamiento principal, v9.0.0 (fecha de lanzamiento aún no planificada). Todas las versiones 8.x.x del agente seguirán siendo compatibles con Ruby 2.3.

* **Limpieza: elimine el código huérfano**

  Tanto en el agente como en las pruebas unitarias, se han producido cambios a lo largo de los años que han dejado ciertas partes del código inalcanzables. Este código huérfano puede complicar el mantenimiento y la refactorización del código, por lo que solucionarlo puede ser muy útil. El miembro de la comunidad [@ohbarye](https://github.com/ohbarye) contribuyó con dos PR de limpieza separados para esta versión; uno para el agente y otro para las pruebas. [PR#1537](https://github.com/newrelic/newrelic-ruby-agent/pull/1537) [PR#1548](https://github.com/newrelic/newrelic-ruby-agent/pull/1548)

  ¡Gracias a [@ohbarye](https://github.com/ohbarye) por contribuir con esta útil limpieza!

## Declaración de apoyo

New Relic recomienda que actualice el agente Ruby regularmente y, como mínimo, cada 3 meses. A partir de este lanzamiento, la versión compatible más antigua es la [6.7.0.359](https://docs.newrelic.com/docs/release-notes/agent-release-notes/ruby-release-notes/ruby-agent-670359).
