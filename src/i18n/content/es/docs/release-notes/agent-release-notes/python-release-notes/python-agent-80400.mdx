## Notas

Esta versión del agente de Python aumenta el límite de eventos personalizados e incluye una corrección de errores.

Instale el agente usando `easy_install/pip/distribute` a través del [Índice de paquetes de Python](https://pypi.python.org/pypi/newrelic) o descárguelo directamente del [sitio de descarga de New Relic](https://download.newrelic.com/python_agent/release).

## Cambios

* **Aumentar el límite de eventos personalizados**

  Esta versión del agente aumenta el límite predeterminado de eventos personalizados de 1200 eventos por minuto a 3600 eventos por minuto. En el caso de que se estuvieran limitando los eventos personalizados, este cambio permitirá enviar más eventos personalizados a New Relic. También hay un nuevo límite máximo configurable de 100 000 eventos por minuto. Para cambiar los límites, consulte la [documentación de event\_harvest](https://docs.newrelic.com/docs/apm/agents/python-agent/configuration/python-agent-configuration/#harvest-limits-custom-event-data). Para obtener más información sobre el cambio y cómo determinar si se están descartando eventos personalizados, consulte nuestra [publicación en el Explorers Hub](https://support.newrelic.com/s/hubtopic/aAX8W0000008dby/send-more-custom-events-with-the-latest-apm-agents).

## Corrección de errores

* **Corrige el error de atributo de NewRelicContextFormatter**

  Se introdujo un error en la v8.3.0 que causó un AttributeError al usar el NewRelicContextFormatter. Esto se ha corregido en esta versión de lanzamiento.
