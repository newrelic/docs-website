## Notas

Esta versión del agente de Python agrega soporte para los comandos de Redis introducidos en Redis v8.10.0 y redis-py v8.1.0. Esta versión también resuelve el problema de los eventos LlmChatCompletion faltantes en LangChain al usar herramientas MCP.

Instale el agente usando `easy_install/pip/distribute` a través del [Índice de paquetes de Python](https://pypi.python.org/pypi/newrelic), usando `conda` a través del [Índice de paquetes de Conda-Forge](https://anaconda.org/conda-forge/newrelic), o descárguelo directamente desde el [sitio de descargas de New Relic](https://download.newrelic.com/python_agent/release).

## Nueva característica

* Se agregaron comandos de Redis introducidos en Redis v8.10.0 y redis-py v8.1.0

  * El agente de Python ahora es compatible con los siguientes comandos agregados recientemente en [Redis](https://pypi.org/project/redis/):

    * `himport_discard_all`
    * `himport_discard`
    * `himport_prepare`
    * `lmovem`
    * `nrange`
    * `nrevrange`
    * `querylabels`
    * `read`
    * `sdiffcard`
    * `sunioncard`
    * `aliaslist`

## Errores

* Se corrigieron los eventos LlmChatCompletion faltantes en Gemini al usar herramientas MCP

  * Anteriormente, faltaban los eventos `LlmChatCompletionMessages` y `LlmChatCompletionSummary` en [Gemini](https://pypi.org/project/google-genai/) al usar herramientas en un agente de [LangChain](https://pypi.org/project/langchain/), si el formato de respuesta no era el JSON predeterminado. Esto se ha resuelto.

* Se cambió al ID de caché de traza en LangChain y el framework de agente

  * Para fines de propagación del contexto, intercambie la instrumentación de [LangChain](https://pypi.org/project/langchain/) y [agente framework](https://pypi.org/project/agent-framework/) para almacenar solo el ID de caché de la traza en lugar de la traza completa en un atributo de referencia. Esto es para evitar que estos objetos se serialicen inesperadamente en caso de fugas. El ID es un objeto mucho más pequeño, mientras que la traza podría contener MB de datos.
