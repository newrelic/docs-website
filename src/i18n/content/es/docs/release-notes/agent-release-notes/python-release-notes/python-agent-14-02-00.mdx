## Notas

Esta versión del agente de Python agrega instrumentación para Microsoft Agent Framework y CrewAI, mejora la instrumentación de banderas de características y el soporte de reenvío de spans de LaunchDarkly, y soluciona varios bloqueos.

Instale el agente usando `easy_install/pip/distribute` a través del [Índice de paquetes de Python](https://pypi.python.org/pypi/newrelic), usando `conda` a través del [Índice de paquetes de Conda-Forge](https://anaconda.org/conda-forge/newrelic), o descárguelo directamente desde el [sitio de descargas de New Relic](https://download.newrelic.com/python_agent/release).

## Nueva característica

* Nueva instrumentación para [Microsoft Agent Framework](https://pypi.org/project/agent-framework/)

  * Se agregó instrumentación para herramientas y agentes en el paquete `agent-framework`.
  * Las configuraciones multiagente aún no están instrumentadas.

* Nueva instrumentación para [CrewAI](https://pypi.org/project/crewai/)

  * Se agregó instrumentación para agentes, equipos y herramientas en el paquete `crewai`.

## Características mejoradas

* Integración mejorada de banderas de características de [LaunchDarkly](https://pypi.org/project/launchdarkly-server-sdk/).

  <Callout title="avance">
  Todavía estamos trabajando en esta característica, ¡pero nos encantaría que la probaras!

  Esta característica se proporciona actualmente como parte de un programa de vista previa de conformidad con nuestras [políticas de prelanzamiento](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy).
  </Callout>

  * Para participar en nuestra integración en versión preliminar pública con LaunchDarkly, habilite las configuraciones `launch_darkly_integration.enabled` y `opentelemetry.enabled` en el archivo de configuración.

  * Instrumentación mejorada de banderas de características en [ldclient](https://pypi.org/project/launchdarkly-server-sdk/).

    * Se agregó el nuevo atributo `feature_flag.url.full` para habilitar la vinculación profunda de la UI.
    * Se modificó el uso de mayúsculas y minúsculas de la clave `inExperiment` para que coincida con LaunchDarkly.
    * Se agregó compatibilidad con valores falsos en los atributos de los indicadores de características.
    * Se redujeron todas las advertencias de integración de LaunchDarkly para que se muestren solo una vez.

  * Reenvío de spans mejorado para [ldobserve](https://pypi.org/project/launchdarkly-observability/).

    * Se agregaron los atributos de span `nr.entity.guid` y `nr.entity.url` para habilitar la vinculación profunda de la UI.
    * Se corrigió la jerarquía de spans para permitir el anidamiento adecuado en la UI.

## Corrección de errores

* Se solucionó un bloqueo en `TimeTrace` cuando el atributo era `None` en `_add_span_event_event`.
* Se solucionó un bloqueo en el wrapper `Config` de LaunchDarkly al volver a los valores predeterminados.
