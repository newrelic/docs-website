## Notas

Esta versión del agente de Python soluciona problemas con los encabezados firmados en botocore (SigV4).

Instale el agente usando `easy_install/pip/distribute` a través del [Índice de paquetes de Python](https://pypi.python.org/pypi/newrelic), usando `conda` a través del [Índice de paquetes de Conda-Forge](https://anaconda.org/conda-forge/newrelic), o descárguelo directamente desde el [sitio de descargas de New Relic](https://download.newrelic.com/python_agent/release).

## Errores

* Solucionar problemas con encabezados firmados en [botocore](https://pypi.org/project/botocore/) (SigV4)

  * El cambio anterior en los encabezados de rastreo distribuido de botocore se ha revertido para evitar que se envíen encabezados duplicados.
  * Anteriormente, cualquier encabezado de rastreo distribuido generado por otras bibliotecas de rastreo podía causar problemas con la instrumentación en botocore debido a la firma de encabezados. Esto se ha solucionado al desactivar la firma de estos encabezados dentro de botocore.
