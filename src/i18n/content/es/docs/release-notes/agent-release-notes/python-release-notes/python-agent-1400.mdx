## Notas

Esta versión del agente de Python agrega utilización para Azure App Services, instrumentación para Azure Service Bus, compatibilidad con un nuevo método de Kinesis y compatibilidad con Google ADK para v2.10.0 y superior. Esta versión también soluciona un problema en httplib donde se duplicaba el encabezado de rastreo distribuido, así como el archivo de instalación `setup.py`.

Instale el agente usando `easy_install/pip/distribute` a través del [Índice de paquetes de Python](https://pypi.python.org/pypi/newrelic), usando `conda` a través del [Índice de paquetes de Conda-Forge](https://anaconda.org/conda-forge/newrelic), o descárguelo directamente desde el [sitio de descargas de New Relic](https://download.newrelic.com/python_agent/release).

## Características eliminadas

* Se eliminó el soporte para Python 3.9

  * Python 3.9 llegó al final de su vida útil el 31 de octubre de 2025 y ya no es compatible con el agente. Considere actualizar la aplicación a una versión compatible de Python para continuar recibiendo actualizaciones del agente de Python.

## Nueva característica

* Utilización del servicio de aplicaciones Azure

  * Se agregó la utilización de Azure App Service para habilitar el mapeo de relaciones de entidades.
  * Esto también agrega una nueva configuración, `utilization.detect_azureappservice`

* Nueva instrumentación para [Azure Service Bus](https://pypi.org/project/azure-servicebus/)

  * Se agregó instrumentación para Microsoft Azure Service Bus.

* Nueva instrumentación para el nuevo método de [Kinesis](https://pypi.org/project/kinesis-python/)

  * El método `update_stream_record_distribution_strategy` ahora se admite en Kinesis.

* Se agregó la versión preliminar pública de la integración de [LaunchDarkly](https://pypi.org/project/launchdarkly-server-sdk/).

  <Callout title="avance">
  Todavía estamos trabajando en esta característica, ¡pero nos encantaría que la probaras!

  Esta característica se proporciona actualmente como parte de un programa de vista previa de conformidad con nuestras [políticas de prelanzamiento](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy).
  </Callout>

  * Para participar en nuestra integración en versión preliminar pública con LaunchDarkly, habilite las configuraciones `launch_darkly_integration.enabled` y `opentelemetry.enabled` en el archivo de configuración.

## Actualizaciones de seguridad

* El paquete interno [urllib3](https://pypi.org/project/urllib3/) se ha actualizado a `2.8.0` para resolver todos los CVE actuales en `urllib3`.

  * Esto resuelve todos los CVE conocidos en el agente hasta la fecha.

## Características mejoradas

* Soporte para [Google ADK](https://pypi.org/project/google-adk/) v2.10.0 y versiones posteriores.

  * La instrumentación se ha actualizado para Google ADK en las versiones 2.10.0 y posteriores.

## Errores

* Encabezados de rastreo distribuido duplicados en [httplib](https://github.com/python/cpython/blob/main/Lib/http/client.py)

  * Se corrigieron los problemas en los que la instrumentación de `httplib` podía producir encabezados duplicados para `traceparent`, lo que resultaba en un valor mal formado.

* `setup.py` el archivo de instalación ahora funciona para todas las versiones compatibles de Python

  * Si un usuario quisiera usar el archivo `setup.py` directamente para instalar el agente de Python en Python 3.12 y versiones posteriores, se encontraría con un `ImportError`. Esto se debe a que `distutils` está obsoleto desde Python 3.10 y se eliminó por completo de la biblioteca estándar en Python 3.12.
