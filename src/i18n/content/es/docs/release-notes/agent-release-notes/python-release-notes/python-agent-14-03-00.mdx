## Notas

Esta versión del agente de Python habilita el monitoreo de IA de forma predeterminada con la nueva configuración `ai_monitoring.basic_telemetry.enabled`, deja obsoleta la configuración `ai_monitoring.enabled` y soluciona un bloqueo en la instrumentación de herramientas de LangChain.

Instale el agente usando `easy_install/pip/distribute` a través del [Índice de paquetes de Python](https://pypi.python.org/pypi/newrelic), usando `conda` a través del [Índice de paquetes de Conda-Forge](https://anaconda.org/conda-forge/newrelic), o descárguelo directamente desde el [sitio de descargas de New Relic](https://download.newrelic.com/python_agent/release).

## Cambios

* El monitoreo de IA ahora está habilitado de forma predeterminada

  * La instrumentación de LLM ahora está habilitada de forma predeterminada y el agente envía `Llm*` eventos personalizados, tramos y métricas (sin el contenido del mensaje) a menos que se configure de otra manera.
  * Para registrar el contenido del símbolo y de la respuesta, establezca [`ai_monitoring.record_content.enabled`](/docs/apm/agents/python-agent/configuration/python-agent-configuration/#ai-monitoring-record-content) en `true`.
  * Para excluirse, establezca [`ai_monitoring.basic_telemetry.enabled`](/docs/apm/agents/python-agent/configuration/python-agent-configuration/#ai-monitoring-basic-telemetry-enabled) en `false` en newrelic.ini, o establezca la variable de entorno `NEW_RELIC_AI_MONITORING_BASIC_TELEMETRY_ENABLED=false`.
  * La configuración [`ai_monitoring.enabled`](/docs/apm/agents/python-agent/configuration/python-agent-configuration/#ai-monitoring-enabled) y la variable de entorno `NEW_RELIC_AI_MONITORING_ENABLED` están obsoletas, pero establecer cualquiera de ellas en `false` también desactiva el monitoreo de IA.

## Corrección de errores

* Se solucionó un bloqueo en la instrumentación de [LangChain](https://pypi.org/project/langchain/) `StructuredTool.invoke` y `StructuredTool.ainvoke` cuando `config` o su `metadata` era `None`.
