## Notas

Esta versión del agente de Python agrega compatibilidad con OpenSearch, Microsoft Azure SQL, nuevos métodos de Kinesis y una nueva configuración de `browser_monitoring.version`. Además, se han realizado mejoras en la instrumentación de Anthropic, MCP y Google ADK. También se han solucionado los problemas con los encabezados firmados en botocore (SigV4) y el análisis de herramientas de Gemini para esta versión.

Instale el agente usando `easy_install/pip/distribute` a través del [Índice de paquetes de Python](https://pypi.python.org/pypi/newrelic), usando `conda` a través del [Índice de paquetes de Conda-Forge](https://anaconda.org/conda-forge/newrelic), o descárguelo directamente desde el [sitio de descargas de New Relic](https://download.newrelic.com/python_agent/release).

## Nueva característica

* Nueva instrumentación para [opensearch-py](https://pypi.org/project/opensearch-py/)

  * Se agregó instrumentación para el conector oficial de la base de datos de OpenSearch.

* Nueva instrumentación para [mssql-python](https://pypi.org/project/mssql-python/)

  * Se agregó instrumentación para Microsoft Azure SQL.

* Nueva instrumentación para nuevos métodos de [Kinesis](https://pypi.org/project/kinesis-python/)

  * Ahora se admiten los siguientes métodos en Kinesis:

    * `create_channel`
    * `delete_channel`
    * `describe_channel`
    * `list_channels`
    * `update_channel`

* Nueva configuración para `browser_monitoring.version`

  * La nueva configuración `browser_monitoring.version` permite a los usuarios especificar versiones específicas de nuestro [agente de monitoreo de Browser](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/introduction-browser-monitoring/) para inyectar.
  * Consulte la lista de [versiones compatibles del agente del browser](https://docs.newrelic.com/docs/browser/browser-monitoring/getting-started/browser-agent-eol-policy/) para elegir.

## Características mejoradas

* Soporte mejorado para [anthropic](https://pypi.org/project/anthropic/).

  * Análisis mejorado de los parámetros de solicitud para el SDK de Anthropic en las versiones 1.0.0 y superiores.
  * Nuevo análisis para respuestas a través de `Messages.with_raw_response.create` que permite una compatibilidad mejorada con LangChain.

* Compatibilidad con [mcp](https://pypi.org/project/mcp/) v2.0.0 y superiores.

  * La instrumentación se ha actualizado tras la importante refactorización realizada en `mcp` v2.0.0 y debería volver a funcionar como se espera.

* Soporte para [Google ADK](https://pypi.org/project/google-adk/) v2.9.0 y versiones posteriores.

  * Se ha actualizado la instrumentación para Google ADK en las versiones 2.9.0 y superiores.

## Errores

* Solucionar problemas con encabezados firmados en [botocore](https://pypi.org/project/botocore/) (SigV4)

  * Anteriormente, cualquier encabezado de rastreo distribuido generado por otras bibliotecas de rastreo podía causar problemas con la instrumentación en botocore debido a la firma de encabezados. Esto se ha solucionado y los encabezados de rastreo distribuido ahora se mutan antes de firmar.

* Corrección para el análisis de herramientas de [Gemini](https://pypi.org/project/google-genai/)

  * Anteriormente, algunas instancias de herramientas creadas con Gemini presentaban errores de análisis y fallaban de forma silenciosa, lo que provocaba que no se obtuviera respuesta para esa solicitud específica. Esto se ha solucionado.
