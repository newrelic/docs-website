### Aviso

* La instrumentación de LLM ahora está habilitada de forma predeterminada y envía `Llm*` eventos personalizados, spans y métricas (sin contenido de mensajes) a menos que se configure lo contrario. Para excluirse, agregue `<aiMonitoring><basicTelemetry enabled="false" /></aiMonitoring>` a `newrelic.config`, o establezca la variable de entorno `NEW_RELIC_AI_MONITORING_BASIC_TELEMETRY_ENABLED` en `false`. El atributo `enabled` en `<aiMonitoring>` y la variable de entorno `NEW_RELIC_AI_MONITORING_ENABLED` están obsoletos y se eliminarán en una futura versión principal, pero establecer cualquiera de ellos en `false` también lo excluirá. ([0b65f33](https://github.com/newrelic/newrelic-dotnet-agent/commit/0b65f338448a6a6213a1db59c4a55844cb4c63af))
* A partir de esta versión, todos los archivos publicados en download.newrelic.com tienen una certificación de procedencia de compilación, que puede verificar con `gh attestation verify <file> --repo newrelic/newrelic-dotnet-agent`. Los hash SHA-256 de los archivos en todas las versiones en download.newrelic.com, incluidas las anteriores, se publican en `release-data/download-site-hashes.json` en el respositorio del agente. ([99335b1](https://github.com/newrelic/newrelic-dotnet-agent/commit/99335b1f2500ead5e0662b0f6646e86bc68caaba))
* A partir de esta versión, los binarios de New Relic dentro de cada paquete (MSI, ZIP, NuGet, deb, rpm y tar.gz) están firmados con Authenticode, y las firmas tienen un timestamp, incluidas las firmas MSI. Los timestamp mantienen las firmas válidas después de que el certificado de firma expira. ([99335b1](https://github.com/newrelic/newrelic-dotnet-agent/commit/99335b1f2500ead5e0662b0f6646e86bc68caaba))

### Actualizando su agente

* Siga los procedimientos estándar para [actualizar el agente .NET](/docs/agents/net-agent/installation-configuration/update-net-agent).
* Si está empleando un agente particularmente antiguo, revise la lista de cambios principales y procedimientos para [actualizar el agente .NET legacy](/docs/apm/agents/net-agent/installation/update-net-agent/#updating_older_net).

Recomendamos actualizar a la última versión del agente tan pronto como esté disponible. Si no puede actualizar a la última versión, actualice su agente a una versión que no tenga más de 90 días de antigüedad. Obtenga más información sobre [cómo mantener a su agente actualizado](/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent). Consulte el [documento de política de fin de vida](/docs/apm/agents/net-agent/getting-started/net-agent-eol-policy) del agente .NET de New Relic para obtener información sobre las versiones del agente y las fechas de soporte.
