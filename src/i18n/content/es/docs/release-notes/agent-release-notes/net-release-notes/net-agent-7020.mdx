### Nueva característica

* Ahora se pueden modificar los archivos XML de instrumentación personalizada sin tener que reiniciar la aplicación monitorizada. Las actualizaciones de instrumentación se aplicarán “dinámicamente” en tiempo de ejecución. Esta característica requería funcionalidad proporcionada por las nuevas API introducidas en .NET Framework 4.5 y versiones posteriores, que esta versión también aborda (consulte la sección “Soporte del framework” a continuación).

### Correcciones

* Boletín de seguridad [NR18-04](https://docs.newrelic.com/docs/accounts-partnerships/welcome-new-relic/security-bulletins/security-bulletin-nr18-04): soluciona un problema por el cual los mensajes de error no se filtraban por completo de las trazas de error y los eventos de error cuando el modo de alta seguridad estaba habilitado.
* Se solucionó un problema con el monitoreo de browser automático que podía causar una excepción de desbordamiento de stack.
* Para la instrumentación personalizada, se respetará el parámetro metricName sin necesidad de establecer transactionNamingPriority.
* El instalador programable ahora se instalará y desinstalará correctamente en escenarios donde hay un espacio en la ruta de los archivos de instalación.

### Soporte de framework

* Esta versión del agente elimina la compatibilidad con las versiones de .NET framework anteriores a la 4.5. Consulte nuestra [publicación de la comunidad](https://support.newrelic.com/s/hubtopic/aAX8W0000008ZIo/net-agent-security-enhancements-and-legacy-framework-deprecation) sobre este tema de noviembre del año pasado para obtener más detalles.
* Esto no es un fin de vida útil para los agentes 6.x (que admiten frameworks de .NET más antiguos), los cuales continuarán funcionando y reportando a New Relic.

### Actualización

* Siga los procedimientos estándar para [actualizar el agente .NET](/docs/agents/net-agent/installation-configuration/update-net-agent).
* Si está actualizando desde un agente particularmente antiguo, revise la lista de cambios importantes y los procedimientos para [actualizar los agentes .NET legacy](/docs/agents/net-agent/troubleshooting/upgrade-legacy-net-agents).
