### Nueva característica

* El código que el generador de perfiles inyecta en la aplicación ahora almacena en caché sus búsquedas en el agente con una caché sin bloqueos, en lugar de resolver cada llamada mediante reflexión, lo que resulta en una menor sobrecarga del agente para aplicaciones .NET. ([#3709](https://github.com/newrelic/newrelic-dotnet-agent/issues/3709)) ([4c7797c](https://github.com/newrelic/newrelic-dotnet-agent/commit/4c7797c45b98cbdd1e8c4652edffabc259a04106))

### Correcciones

* Evite la contaminación cruzada de transacciones en HybridHttpContextStorage ([#3754](https://github.com/newrelic/newrelic-dotnet-agent/issues/3754)) ([2d04565](https://github.com/newrelic/newrelic-dotnet-agent/commit/2d045657d8114ff5c4888a7cef5f369f99b82f82))
* Liberar la transacción del cliente WCF retenida cuando el resultado asíncrono se completa antes del intercambio de la devolución de llamada ([#3772](https://github.com/newrelic/newrelic-dotnet-agent/issues/3772)) ([3ef02f3](https://github.com/newrelic/newrelic-dotnet-agent/commit/3ef02f376163fe74c81b1c97e5cf39cfb016dfd5))
* Omitir la inyección de comentarios de metadatos de SQL para CommandType.StoredProcedure ([#3756](https://github.com/newrelic/newrelic-dotnet-agent/issues/3756)) ([59b92ea](https://github.com/newrelic/newrelic-dotnet-agent/commit/59b92ea2ef9d787d99a5151d6cb8df6df1a86298))

### Actualizando su agente

* Siga los procedimientos estándar para [actualizar el agente .NET](/docs/agents/net-agent/installation-configuration/update-net-agent).
* Si está empleando un agente particularmente antiguo, revise la lista de cambios principales y procedimientos para [actualizar el agente .NET legacy](/docs/apm/agents/net-agent/installation/update-net-agent/#updating_older_net).

Recomendamos actualizar a la última versión del agente tan pronto como esté disponible. Si no puede actualizar a la última versión, actualice su agente a una versión que no tenga más de 90 días de antigüedad. Obtenga más información sobre [cómo mantener a su agente actualizado](/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent). Consulte el [documento de política de fin de vida](/docs/apm/agents/net-agent/getting-started/net-agent-eol-policy) del agente .NET de New Relic para obtener información sobre las versiones del agente y las fechas de soporte.
