## Notas

#### Característica

* Se agregó `ai_monitoring.basic_telemetry.enabled` y se habilitó el monitoreo de IA básico de forma predeterminada ([#4330](https://github.com/newrelic/node-newrelic/pull/4330)) ([c126335](https://github.com/newrelic/node-newrelic/commit/c1263354150cd30349d316acc162f5388bc3449a))

  * La instrumentación de LLM ahora está habilitada de forma predeterminada y envía `Llm*` eventos personalizados, spans y métricas (sin el contenido del mensaje) a menos que se configure de otra manera. Para excluirse, establezca `ai_monitoring.basic_telemetry.enabled` en `false` en `newrelic.js`, o establezca la variable de entorno `NEW_RELIC_AI_MONITORING_BASIC_TELEMETRY_ENABLED` en `false`.
  * `ai_monitoring.enabled` y la variable de entorno `NEW_RELIC_AI_MONITORING_ENABLED` están obsoletas y se eliminarán en una versión principal futura, pero establecer cualquiera de las dos en false también desactiva la opción.

* Se deshabilitó el rastreo del núcleo ([#4394](https://github.com/newrelic/node-newrelic/pull/4394)) ([2d0ee8e](https://github.com/newrelic/node-newrelic/commit/2d0ee8ea2c7355b3764e332b555bcc04f2e691f0))
