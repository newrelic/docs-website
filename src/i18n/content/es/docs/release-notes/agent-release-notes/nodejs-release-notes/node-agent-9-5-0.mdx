## Notas

* Se aumentó el límite predeterminado de eventos personalizados de 1000 eventos por minuto a 3000 eventos por minuto. En el caso de que se estuvieran limitando los eventos personalizados, este cambio permitirá enviar más eventos personalizados a New Relic. También hay un nuevo límite máximo configurable de 100 000 eventos por minuto. Para cambiar los límites, consulte [la documentación de custom\_insights\_events](https://docs.newrelic.com/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration#custom_events_max_samples_stored). Para obtener más información sobre el cambio y cómo determinar si se están descartando eventos personalizados, consulte [nuestra publicación en el Explorers Hub](https://support.newrelic.com/s/hubtopic/aAX8W0000008dby/send-more-custom-events-with-the-latest-apm-agents).

* Se actualizó el proceso de CI para incluir la recopilación de estadísticas de cobertura de código.

* Se agregó un \[documento sobre nuestros indicadores de características actuales)([https://github.com/newrelic/node-newrelic/blob/main/documentation/feature-flags.md](https://github.com/newrelic/node-newrelic/blob/main/documentation/feature-flags.md)).

### Declaración de apoyo:

* New Relic recomienda actualizar el agente regularmente para asegurarse de obtener las últimas características y beneficios de rendimiento. Además, las versiones anteriores dejarán de tener soporte cuando lleguen al [fin de su vida útil](/docs/using-new-relic/cross-product-functions/install-configure/notification-changes-new-relic-saas-features-distributed-software).
