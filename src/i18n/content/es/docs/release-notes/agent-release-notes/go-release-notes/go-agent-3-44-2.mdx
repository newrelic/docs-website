## 3.44.2

### Agregado

* `aws.lambda.eventSource.eventType` soporte de atributo para la integración de `nrlambda`

### Fijado

* `TransactionTrace` correcciones

  * `backtrace` se muestra correctamente en la UI -&gt; Se solucionó un problema por el cual los rastreos inversos no se mostraban correctamente en NR1
  * `timestamp` ya no es nulo -&gt; Se corrigió un problema donde el timestamp siempre se mostraba como nulo
  * `exclusive_duration_millis` ya no es nulo -&gt; Se solucionó un problema por el cual `exclusive_duration_millis` siempre se mostraba como nulo

### Seguridad

* Actualizaciones de seguridad de Dependabot

  * `nrgrpc` se actualizó google.golang.org/grpc a 1.82.1
  * `nrconnect` aumentar golang.org/x/net a 0.55.0

### Declaración de apoyo

Usamos la última versión del lenguaje Go. Como mínimo, usa una versión de Go que el equipo de Go aún soporte. Consulta la [política de EOL del agente de Go](/docs/apm/agents/go-agent/get-started/go-agent-eol-policy) para obtener detalles sobre las versiones compatibles del agente de Go y los componentes de terceros.
