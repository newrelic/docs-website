## 3.45.0

### Agregado

* Se agregó la nueva integración nrecho-v5. Tenga en cuenta que las versiones principales anteriores (v3, v4) aún están disponibles en sus respectivas carpetas
* Se agregó una nueva integración nrgemini que instrumenta el paquete GenAI
* Se agregó compatibilidad con el perfilado continuo   \* NOTA: el perfilado continuo es una nueva característica que aún no está disponible para uso general. El código del componente del lado del agente ahora está presente en el agente, pero para usarlo realmente antes del lanzamiento de disponibilidad general, deberá comunicarse con el representante de ventas de New Relic para unirse a la versión preliminar de forma anticipada.

### Fijado

* Se corrigió un error por el cual los mensajes de LLM se truncaban incorrectamente

### Seguridad

* Actualizaciones de seguridad de Dependabot

  * Se actualizó grpc de 1.82.1 a 1.83.1 en v3/integrations/nrgrpc y /v3
  * Se actualizó amqp091-go de 1.9.0 a 1.13.0 en la integración v3/integrations/nramqp
  * Se actualizó echo/v4 de 4.9.0 a 4.15.3 en v3/integrations/nrecho-v4

### Declaración de apoyo

Empleamos la última versión del lenguaje Go. Como mínimo, no deberías emplear ninguna versión de Go anterior a la compatible con el propio equipo de Go. Consulte la [Política de fin de vida del agente Go](https://docs.newrelic.com/docs/apm/agents/go-agent/get-started/go-agent-eol-policy/) para obtener detalles sobre las versiones compatibles del agente Go y los componentes de terceros.
