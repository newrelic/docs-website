### Nuevas características y mejoras:

* El [perfilado en tiempo real para Java mediante métricas JFR](/docs/agents/java-agent/features/real-time-profiling-java-using-jfr-metrics/) ahora está completamente integrado en el agente de Java. Consulte el [README de JFR core](https://github.com/newrelic/newrelic-jfr-core/blob/main/README.md) para obtener detalles adicionales.

Esta característica requiere una versión compatible de Java 8 (específicamente la versión `8u262` o superior) o Java 11 o superior y actualmente está deshabilitada por defecto. Para habilitarla, establezca lo siguiente en el yaml (con una sangría de 2 espacios en la sección common).

```
jfr:
  enabled: true
```

**Aviso:** Si utilizaba anteriormente el [jar jfr-daemon](https://github.com/newrelic/newrelic-jfr-core) como extensión del agente o proceso independiente, debe eliminar esa opción para evitar posibles conflictos con el servicio JFR que ahora está integrado en el agente.

* No es compatible con Java 7. Para continuar innovando y proporcionar de manera eficiente nuevas capacidades a los clientes que ejecutan en la JVM, esta y las futuras versiones del agente no son compatibles con Java 7. Si ejecuta Java 7, puede continuar usando el agente de Java 6.5.0 o inferior. Para obtener más detalles, consulte este tema en el [Explorers Hub](https://support.newrelic.com/s/hubtopic/aAX8W0000008bni/important-upcoming-changes-to-capabilities-across-synthetics-apm-java-php).
* Agrega soporte para akka http con Scala 2.13. [#271](https://github.com/newrelic/newrelic-java-agent/pull/271)
* Anotación de clase para trazar métodos lambda. [#274](https://github.com/newrelic/newrelic-java-agent/pull/274)
* Anotación de clase para trazar métodos por tipo de retorno. [#275](https://github.com/newrelic/newrelic-java-agent/pull/275)

### Corrige:

* Soluciona un problema que podía causar que se aplicaran múltiples versiones de la instrumentación de `akka-http-core` al mismo tiempo. [#208](https://github.com/newrelic/newrelic-java-agent/pull/208)
* Ahora el agente registrará los eventos descartados en `FINE` en lugar de `WARN` para disminuir la verbosidad. [#296](https://github.com/newrelic/newrelic-java-agent/pull/296)
* Soluciona los comentarios de Javadoc que indicaban incorrectamente que, al llamar a la API de `noticeError` varias veces, se informaría el primer error cuando, de hecho, se informa el último error. [#313](https://github.com/newrelic/newrelic-java-agent/pull/313)

### Declaración de apoyo:

* New Relic recomienda actualizar el agente regularmente para asegurarse de obtener las últimas funciones y beneficios de rendimiento. Además, las versiones anteriores dejarán de tener soporte cuando lleguen al [fin de su vida útil](/docs/using-new-relic/cross-product-functions/install-configure/notification-changes-new-relic-saas-features-distributed-software/).

### Problemas conocidos

* OkHttp

Esta versión contiene un error que hace fallar las versiones 3.X y anteriores de OkHttp. Todos los usuarios afectados deben actualizar a la versión 7.0.1.
