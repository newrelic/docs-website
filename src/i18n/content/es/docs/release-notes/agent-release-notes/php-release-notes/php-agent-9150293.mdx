### Avisos de fin de vida útil

* El soporte para PHP 5.3 y PHP 5.4 en el agente PHP de New Relic está obsoleto y se eliminará en una versión futura. New Relic recomienda encarecidamente actualizar a una [versión soportada de PHP](https://www.php.net/supported-versions.php) —7.3 o superior a la fecha de este lanzamiento. Si desea continuar ejecutando el agente PHP de New Relic con PHP 5.3 y 5.4, recomendamos usar la versión 9.15 del agente para obtener la máxima compatibilidad. Sin embargo, tenga en cuenta que solo podemos ofrecer soporte limitado en este caso.
* Esta versión marca el último agente PHP de New Relic compatible oficialmente para CentOS 5.
* Ya no se proporcionarán compilaciones para MacOS del agente PHP de New Relic, y ya no garantizaremos la compatibilidad en las plataformas MacOS.
* Para obtener más información sobre estos avisos de EOL, consulte nuestra [publicación en Explorers Hub](https://support.newrelic.com/s/hubtopic/aAX8W0000008bKn/important-upcoming-changes-to-capabilities-across-browser-php-python-mobile).

### Nueva característica

* [Se ha agregado compatibilidad con Laminas 3.x.](https://github.com/newrelic/newrelic-php-agent/pull/36)
* [Se ha agregado soporte para Laravel Lumen 6.x, 7.x y 8.x](https://github.com/newrelic/newrelic-php-agent/pull/38)
* [Se ha agregado compatibilidad experimental para excluir subrutas de la instrumentación de Wordpress.](https://github.com/newrelic/newrelic-php-agent/pull/37) Esto reduce la sobrecarga general de la instrumentación de Wordpress, ya que reduce la cantidad de archivos instrumentados, pero a costa de perder visibilidad del código en las subrutas excluidas. Esto se puede habilitar mediante la configuración del archivo ini `newrelic.framework.wordpress.hooks_skip_filename`.

### Corrección de errores

* [Se corrigió la representación de cadena de los nombres de los parámetros arginfo](https://github.com/newrelic/newrelic-php-agent/pull/23). Gracias @TysonAndre por esta contribución.

### Declaración de apoyo

* New Relic recomienda que actualice el agente regularmente y, como mínimo, cada 3 meses. A partir de este lanzamiento, la versión compatible más antigua es la [8.4.0](https://docs.newrelic.com/docs/release-notes/agent-release-notes/php-release-notes/php-agent-840231).
