## Agente PHP de New Relic v12.12.0.41

### Corrección de errores

* Corrige la recuperación del nombre de la base de datos y de la colección de MongoDB para las versiones de la biblioteca de MongoDB 1.21.4 y 2.4.1 y posteriores. ([#1301](https://github.com/newrelic/newrelic-php-agent/pull/1301))
* Corrige una condición de carrera de datos en la recopilación de métricas del daemon que podría bloquear el daemon cuando varios agentes reportan a un solo daemon. ([#1310](https://github.com/newrelic/newrelic-php-agent/pull/1310))
* Pasa `E_DONT_BAIL` al controlador de errores de PHP para que los destructores se ejecuten después de una excepción no detectada. ([#1317](https://github.com/newrelic/newrelic-php-agent/pull/1317))
* Mantiene una referencia a la devolución de llamada pasada a `newrelic_set_error_group_callback()` para evitar un bloqueo o un nombre de grupo de errores incorrecto. ([#1329](https://github.com/newrelic/newrelic-php-agent/pull/1329))
* Elimine el tiempo de inicio del comando Predis una vez que se lea la respuesta. ([#1315](https://github.com/newrelic/newrelic-php-agent/pull/1315))

### Actualizaciones de seguridad

* Actualice la versión de Go utilizada para compilar el daemon a 1.27.3. ([#1304](https://github.com/newrelic/newrelic-php-agent/pull/1304), [#1320](https://github.com/newrelic/newrelic-php-agent/pull/1320), [#1336](https://github.com/newrelic/newrelic-php-agent/pull/1336))

### Declaración de apoyo

* Como se comunicó previamente, el soporte del agente PHP para las siguientes versiones de bibliotecas &amp; frameworks se descontinuó y New Relic recomienda actualizar a la versión más reciente con soporte del proveedor:

  * Slim 2: el soporte se ha descontinuado en todas las versiones del agente PHP desde el 31 de julio de 2026
  * Laravel 11: el soporte se ha descontinuado en todas las versiones del agente PHP desde el 30 de septiembre de 2026
  * Drupal 7: el soporte se ha descontinuado en todas las versiones del agente PHP desde el 15 de octubre de 2026
  * Drupal 9: el soporte se ha descontinuado en todas las versiones del agente PHP desde el 15 de octubre de 2026
  * Guzzle 5: el soporte se ha descontinuado en todas las versiones del agente PHP desde el 15 de octubre de 2026
  * Guzzle 6: el soporte se ha descontinuado en todas las versiones del agente PHP desde el 15 de octubre de 2026

* Como se comunicó previamente, el soporte del agente PHP para las siguientes bibliotecas &amp; frameworks se descontinuó:

  * Joomla: el soporte se ha descontinuado en todas las versiones del agente PHP para todos los Joomla desde el 30 de septiembre de 2026

* El soporte del agente PHP para las siguientes versiones de bibliotecas, frameworks y sistemas operativos se descontinuará y New Relic recomienda actualizar a la versión más reciente con soporte del proveedor:

  * Amazon Linux 2 (AL2): el soporte finaliza el 15 de noviembre de 2026
  * Red Hat Enterprise Linux 8 (RHEL 8): el soporte finaliza el 15 de noviembre de 2026
  * PHP 7.2/7.3: El soporte finaliza el 15 de diciembre de 2026

* New Relic recomienda que actualices el agente periódicamente y como mínimo cada 3 meses. Para obtener más información sobre las versiones de agente compatibles y los plazos de EOL, consulte nuestra [política de EOL del agente PHP de New Relic](https://docs.newrelic.com/docs/apm/agents/php-agent/getting-started/php-agent-eol-policy/).

* Se debe consultar la página [de requisitos y compatibilidad del agente PHP](https://docs.newrelic.com/docs/apm/agents/php-agent/getting-started/php-agent-compatibility-requirements/) para obtener la información más reciente sobre las versiones y plataformas de PHP compatibles.

<Callout variant="important">
**Para la instalación empleando una versión o plataforma de PHP no compatible, se recomienda encarecidamente que deshabilite los mecanismos de actualización automática para los paquetes PHP del agente.** Esto se puede hacer agregando los paquetes del agente PHP a una lista de exclusión para las actualizaciones de paquetes. O puede fijar la versión del paquete PHP del agente a una versión del agente que admita las características antiguas no admitidas. Si no se evitan las actualizaciones, es posible que se instale una versión más nueva del agente y que se elimine el soporte para la función requerida que no tiene soporte. Esto interrumpiría la recopilación de datos de APM.

Los paquetes del agente PHP que se ven afectados son:

* newrelic-php5
* newrelic-php5-common
* newrelic-daemon
</Callout>
