## Notas

Se ha lanzado una nueva versión del agente. Siga los procedimientos estándar para [actualizar el agente de infraestructura](/docs/infrastructure/install-configure-manage-infrastructure/update-or-uninstall/update-infrastructure-agent).

New Relic recomienda que actualice el agente regularmente y, como mínimo, cada 3 meses.

## Cambió

* `nri-docker` a [v1.6.0](https://github.com/newrelic/nri-docker/releases/tag/v1.6.0). Se agregaron nuevas métricas de memoria y almacenamiento. El cálculo de `memoryUsageBytes` y `memoryUsageLimitPercent` ha cambiado. Consulte esta [publicación de actualización del producto](https://support.newrelic.com/s/hubtopic/aAX8W0000008bmH/dockercontainers-memory-metric-updates) y las [notas de la versión de nri-docker](https://github.com/newrelic/nri-docker/releases/edit/v1.6.0) para obtener más información.
* `nri-winservices` a [v0.2.0-beta](https://github.com/newrelic/nri-winservices/releases/tag/v0.2.0-beta).
