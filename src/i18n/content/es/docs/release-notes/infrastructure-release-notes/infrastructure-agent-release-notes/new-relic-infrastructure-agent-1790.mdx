Se ha lanzado una nueva versión del agente. Siga los procedimientos estándar para [actualizar el agente de infraestructura](/docs/infrastructure/install-configure-manage-infrastructure/update-or-uninstall/update-infrastructure-agent). New Relic recomienda que actualice el agente regularmente y, como mínimo, cada 3 meses. A partir de este lanzamiento, la versión compatible más antigua es el [agente de infraestructura 1.65.3](/docs/release-notes/infrastructure-release-notes/infrastructure-agent-release-notes/new-relic-infrastructure-agent-1653/).

## Cambió

* Agregar etiquetas OCI adicionales para alinearse con las etiquetas de AWS. [#2295](https://github.com/newrelic/infrastructure-agent/pull/2295)
* Se agregó soporte para ignorar las ubicaciones de integración predeterminadas a través de `disable_plugin_default_dir_scan`. [#2290](https://github.com/newrelic/infrastructure-agent/pull/2290)
* Se expusieron como públicas las variables de entorno utilizadas por el control del agente (AC). [#2293](https://github.com/newrelic/infrastructure-agent/pull/2293)
* Se corrigió una vulnerabilidad de ejecución remota de código (RCE) causada por salto de directorio. [#2292](https://github.com/newrelic/infrastructure-agent/pull/2292)
* Se actualizaron las dependencias vulnerables marcadas por un escaneo de Trivy y se actualizaron las versiones de OHI integradas (`nri-docker`, `nri-flex`) para solucionar CVE. [#2301](https://github.com/newrelic/infrastructure-agent/pull/2301) [#2302](https://github.com/newrelic/infrastructure-agent/pull/2302)
