## Notas

### 🛡️ Avisos de seguridad

* Se corrigió una vulnerabilidad de ejecución remota de código causada por un cruce de rutas en [#2292](https://github.com/newrelic/infrastructure-agent/pull/2292)
* Se agregaron permisos explícitos a los flujos de trabajo de GitHub Actions para reducir el alcance del token en [#2232](https://github.com/newrelic/infrastructure-agent/pull/2232)
* Se actualizó google.golang.org/grpc de 1.79.3 a 1.82.1 en go.mod en [#2296](https://github.com/newrelic/infrastructure-agent/pull/2296)
* Se actualizaron las versiones de OHI integradas (nri-docker, nri-flex) para corregir CVE conocidos en [#2302](https://github.com/newrelic/infrastructure-agent/pull/2302)
* actualizar las dependencias vulnerables detectadas por el escaneo de Trivy en [#2301](https://github.com/newrelic/infrastructure-agent/pull/2301)

### 🚀 Mejoras

* Se agregó compatibilidad para ignorar las ubicaciones de integración predeterminadas mediante disable\_plugin\_default\_dir\_scan en [#2290](https://github.com/newrelic/infrastructure-agent/pull/2290)
* Se hicieron públicas las variables de entorno utilizadas por el Control del agente en [#2293](https://github.com/newrelic/infrastructure-agent/pull/2293)
* Se agregó compatibilidad con etiquetas de OCI para que coincidan con las etiquetas de AWS (Fase 1 + Fase 2) en [#2295](https://github.com/newrelic/infrastructure-agent/pull/2295)
* Se habilitó NRIA\_DISABLE\_PLUGIN\_DEFAULT\_DIR\_SCAN por defecto para los agentes administrados por el Control del agente en [#2300](https://github.com/newrelic/infrastructure-agent/pull/2300)
* Se eliminó nri-flex de los artefactos de agent-control en [#2291](https://github.com/newrelic/infrastructure-agent/pull/2291)

### 🐞 Correcciones de errores

* Se restauraron los permisos de trabajo faltantes para los flujos de trabajo de lanzamiento y canary en [#2303](https://github.com/newrelic/infrastructure-agent/pull/2303)

### Declaración de apoyo:

Se ha lanzado una nueva versión del agente. Siga los procedimientos estándar para [actualizar el agente de infraestructura](/docs/infrastructure/install-configure-manage-infrastructure/update-or-uninstall/update-infrastructure-agent).

Recomendamos actualizar a la última versión del agente tan pronto como esté disponible. Si no puede actualizar a la última versión, actualice sus agentes a una versión de no más de 90 días. Lea más sobre [cómo mantener los agentes actualizados](https://docs.newrelic.com/docs/new-relic-solutions/new-relic-one/install-configure/update-new-relic-agent/).

Consulte la [política de fin de vida útil del agente de New Relic Infrastructure](https://docs.newrelic.com/docs/infrastructure/infrastructure-agent/infrastructure-agent-eol-policy/) para obtener información sobre las versiones del agente y las fechas de soporte.
