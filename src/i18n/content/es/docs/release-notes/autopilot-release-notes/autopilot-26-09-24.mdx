### Nueva característica

* **Análisis de causa raíz más profundo cuando se le notifica:** Autopilot ahora puede ayudar a trazar una alerta hasta el cambio de código que la originó desde más puntos de entrada, incluidas las investigaciones de incidentes y las activadas por Slack, para que pueda identificar el problema sin tener que buscar en todo el historial de despliegue.
* **Vea los datos completos, no solo el gráfico:** los resultados de la herramienta ahora muestran los datos subyacentes junto a una visualización, para que pueda verificar más fácilmente en qué basó Autopilot su respuesta.
* **Detecte picos intermitentes, no solo promedios:** el análisis de métricas ahora muestra detalles de percentil y el historial de tendencias, lo que hace que un pico breve sea más fácil de detectar de lo que sería solo con un promedio.
* **Consulte un mes completo de alertas en una sola solicitud:** la ventana de revisión de alertas para las consultas de ámbito de entidad se ha ampliado de 7 a 30 días, y una solicitud de gran tamaño ahora se reduce automáticamente en lugar de rechazarse por completo.
* **Acceda directamente a la sesión:** las respuestas ahora incluyen enlaces directos a la sesión para navegador y dispositivos móviles, para que pueda retomar donde Autopilot lo dejó sin tener que buscarlo.

**Actualizaciones de la capacidad de integración de GitHub MCP (vista previa pública)**

La integración con GitHub de Autopilot ahora vincula las alertas activas más directamente al historial de despliegue y lanzamiento, para que pueda clasificarlas sin cambiar de herramientas.

* **Vea las correcciones en curso antes de duplicar el trabajo:** durante la clasificación de alertas, Autopilot ahora revisa GitHub en busca de pull request abiertos que ya estén dirigidos al servicio afectado, para que pueda ver si ya hay un hotfix o una corrección relacionada en marcha antes de comenzar la suya.
* **Detecte la desviación de versiones en el momento en que se activa una alerta:** Autopilot ahora compara el lanzamiento realmente desplegado con la versión que se estaba ejecutando cuando comenzó el incidente, mostrando los lanzamientos recientes o los despliegues no verificados que pueden estar contribuyendo al problema.

### Corrección de errores

* **Consultas corregidas que podían fallar al contar valores únicos:** las preguntas que requerían contar algo único —como cuántos usuarios distintos experimentaron un error específico— podían hacer que Autopilot generara una consulta NRQL no válida y no respondiera. Ahora Autopilot está guiado para manejar esto mejor, lo que hace que sea menos probable que estas preguntas generen un error.
* **Menos respuestas de análisis de errores rechazadas:** se solucionó un problema por el cual solicitar un desglose detallado de errores podía rechazarse por ser demasiado grande para su entrega.
* **Menos tiempos de espera agotados al analizar logs de gran volumen:** se aumentó el tiempo asignado para el análisis de logs para que las cuentas con grandes volúmenes de logs tengan menos probabilidades de agotar el tiempo de espera.
* **Cancelar para detener la ejecución:** cancelar una investigación desde el panel de chat ahora detiene su ejecución en el backend.
* **Carga más rápida y limpia del panel de chat:** el panel de chat ahora carga Ask AI y Autopilot primero en lugar de esperar a la lista completa de agentes, y ya no muestra ninguno de los dos por duplicado en el desplegable de agentes.
* **Fundamentación más coherente en la base de conocimientos:** las respuestas rápidas y directas y las investigaciones de triaje de alertas ahora se basan de manera más coherente en la base de conocimientos antes de responder.
* **Estado de despliegue más preciso en las investigaciones de GitHub:** mejores informes del estado de lanzamiento del servicio.
* **Orientación más clara cuando Autopilot no puede encontrar una respuesta:** se reemplazó un mensaje genérico de &quot;algo salió mal&quot; por una orientación más útil para intentar reformular la pregunta.
* **Se corrigió un error de conexión engañoso:** una redirección relacionada con el inicio de sesión se reportaba como una conexión expirada; ahora se identifica correctamente.
