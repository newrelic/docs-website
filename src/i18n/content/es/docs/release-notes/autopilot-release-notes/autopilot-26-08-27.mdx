## Novedades

### Autopilot: investigaciones más rápidas y confiables

* **Investigaciones más rápidas:** Autopilot ahora envía pasos en paralelo, por lo que verá un tiempo de respuesta más rápido y menos tiempos de espera, especialmente en las requests que se dividen en múltiples subinvestigaciones.
* **Enrutamiento de ruta rápida:** obtendrá respuestas instantáneas en requests simples. Un nuevo motor de ruta rápida reconoce preguntas sencillas y omite pasos innecesarios, por lo que verá una respuesta más rápido.
* **Guardar memoria en el hilo:** dígale a Autopilot en el chat que guarde la información en la memoria y automáticamente agregará ese contexto a la memoria a largo plazo.
* **Copia de NRQL con un clic:** copie las consultas NRQL generadas directamente en el portapapeles con un solo clic desde el panel de chat.
* **Expansión del chat con un clic:** maximice al instante el panel de chat con un solo clic para obtener un espacio de trabajo más amplio y despejado.
* **Accesos directos de navegación de consultas:** desplácese y vuelva a seleccionar consultas anteriores con las teclas de flecha hacia arriba (↑) y hacia abajo (↓) en el cuadro del símbolo.
* **Respuestas más confiables:** solucionamos varios problemas para mejorar las investigaciones y brindar respuestas más completas. Ahora recibirá un mensaje claro si alcanzó el límite de uso por hora en lugar de un error sin procesar, y solucionamos un problema poco frecuente en el que una investigación podía parecer terminada antes de que realmente se completara.

### Actualizaciones de la capacidad de integración de GitHub MCP (vista previa pública)

<Callout title="avance">
  Todavía estamos trabajando en esta característica, ¡pero nos encantaría que la probaras!

  Esta característica se proporciona actualmente como parte de un programa de vista previa de conformidad con nuestras [políticas de prelanzamiento](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy).
</Callout>

**GitHub Enterprise Cloud ahora es compatible:** la integración de GitHub MCP ahora funciona con GitHub Enterprise Cloud además de GitHub público. Si la organización usa una instancia de `YOURSUBDOMAIN.ghe.com`, conéctela a Autopilot mediante el mismo flujo de PAT. El único paso nuevo es ingresar la URL del subdominio de GHE durante la configuración. Ambos casos de uso de investigación funcionan en `GHE.com`: identificación de la causa raíz desencadenada por cambios y búsqueda manual de PR/confirmaciones.

Entornos de GitHub compatibles:

| Tipo de conexión        | Formato de URL          | Disponibilidad             |
| ----------------------- | ----------------------- | -------------------------- |
| GitHub público          | `github.com`            | Vista previa (desde 2.1)   |
| GitHub Enterprise Cloud | `YOURSUBDOMAIN.ghe.com` | Vista previa —nuevo en 2.2 |

**Cambio de configuración para los usuarios de `GHE.com`:** al conectar GitHub en **Configure &gt; Autopilot &gt; External MCP connections**, ingrese `YOURSUBDOMAIN.ghe.com` en el campo de URL de GitHub en lugar de `github.com`. Los permisos de PAT no han cambiado: pull requests: Read, Contents: Read, metadatos: Read. Si la organización de `GHE.com` aplica SAML SSO, autorice el PAT para SSO en GitHub antes de ingresarlo en New Relic —un token no autorizado falla con `403` en el primer uso.

**Limite el alcance del PAT a los repositorios que rastrea activamente:** Autopilot lee las descripciones de PR y los metadatos de cambios de archivos de cada respositorio que autoriza el token.
