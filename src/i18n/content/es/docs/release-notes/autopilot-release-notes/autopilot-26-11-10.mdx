### Novedades

#### Solución de problemas de Kafka con Autopilot

Ahora Autopilot puede solucionar mejor los problemas de Kafka y recomendar los siguientes pasos para mitigarlos, para Kafka monitoreado con la integración en el host de New Relic, OpenTelemetry, Amazon MSK y Confluent Cloud.

* **Estado del Cluster:** comprueba el retraso del consumidor, las particiones con replicación insuficiente y fuera de línea, y el estado del broker y del controlador.
* **Mapeo de relaciones de entidades:** mapea las relaciones en todo el ecosistema, conectando productores, consumidores, temas, brokers, clústeres e infraestructura de host.
* **Rendimiento del cliente:** revisa la solicitud de un productor o consumidor y obtiene la latencia, la espera de I/O, la tasa de consumo y el tiempo de sondeo.

#### Seguimiento de cambios para GitHub Copilot

<Callout title="avance">
¡Aún estamos trabajando en esta característica, pero nos encantaría que la probaras! Esta característica se proporciona actualmente como parte de un programa de vista previa de acuerdo con nuestras [políticas de prelanzamiento](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy).
</Callout>

Autopilot ahora puede ayudar a monitorear el servicio después de cada despliegue e informar los resultados en el pull request. En seis puntos de control después de un despliegue (10 minutos, 30 minutos, 1 hora, 2 horas, 24 horas y 72 horas), Autopilot compara las métricas posteriores al despliegue con una línea de base y publica el resultado como un comentario de PR. Cuando detecta una regresión, Autopilot publica los hallazgos en Slack y abre un issue de GitHub asignado a GitHub Copilot. Con GitHub Copilot Enterprise, Copilot puede proponer una solución como un pull request.

* **Informes de puntos de control en el PR:** en cada punto de control, Autopilot comenta en el pull request con el resultado —sin regresión, no concluyente o regresión detectada— para que el equipo vea la señal sin salir de GitHub.
* **Notificaciones de Slack:** si ha conectado Slack, Autopilot publica un mensaje cuando comienza el monitoreo de un despliegue y responde en el mismo hilo en cada punto de control.
* **Incidencias de regresión automáticas:** cuando Autopilot detecta una regresión, abre una incidencia en GitHub con el detalle de lo que experimentó la regresión, la evidencia que lo respalda, dónde buscar y los criterios de aceptación, y le asigna la incidencia a GitHub Copilot.
* **Desencadenador de etiqueta de PR:** agregue la etiqueta `watchpoint_monitoring` a un pull request antes de desplegar para activar el monitoreo para ese despliegue, sin necesidad de establecer el atributo `watchpoint_monitoring` en el evento de seguimiento de cambios. Puede elegir qué despliegues monitorear, sin necesidad de realizar cambios en el pipeline.

Para obtener instrucciones de configuración y los requisitos previos completos, consulte [Monitorear el despliegue con el seguimiento de cambios de New Relic para GitHub Copilot](/docs/agentic-ai/autopilot/change-tracking-for-github-copilot/).

### Resolución de problemas de Kafka, monitoreo de despliegue y más

#### Nueva característica

* **Solución de problemas de Kafka con Autopilot:** ahora Autopilot puede solucionar mejor los problemas de Kafka y recomendar los próximos pasos para mitigarlos, en el caso de Kafka monitoreado con la integración en el host de New Relic, OpenTelemetry, Amazon MSK y Confluent Cloud.
* **Seguimiento de cambios para GitHub Copilot (versión preliminar):** Autopilot ahora puede ayudar a monitorear el servicio después de cada despliegue y reportar los resultados en el pull request.
* **Ver datos de uso de Autopilot por usuario:** mediante Consumption Management, ahora puede ver el uso de consumo de Autopilot desglosado por usuario.
* **Descubrimiento de logs y métricas para la infraestructura:** durante las investigaciones de infraestructura, Autopilot ahora puede revisar los logs de una entidad y buscar los nombres de las métricas que reporta.

#### Mejoras y correcciones

* **Búsqueda de problemas mejorada:** Autopilot ahora resuelve los problemas de alerta de forma más confiable —las variantes de nombres con sufijos ya no se ocultan tras las coincidencias exactas, los problemas cerrados se pueden resolver de forma más confiable para la investigación retrospectiva y el estado de los informes se muestra para que las entidades obsoletas no prevalezcan sobre las activas.
* **Respuestas rápidas más completas:** las listas muestran cada elemento, hasta 50, y las respuestas incluyen detalles de los recuentos, como entidades críticas y problemas abiertos.
* **Totales de CCU:** los totales de CCU en las respuestas rápidas ya no incluyen cifras de volumen de datos.
* **Rangos de tiempo que solicita:** Autopilot puede solicitarle un rango de tiempo para la investigación.
* **Comprobaciones enfocadas en problemas en curso:** preguntar si un problema sigue ocurriendo ahora comprueba el período más reciente.
* **Tiempos de inicio de incidente mejorados:** las investigaciones de incidentes ahora comienzan desde el momento en que se abrió el problema.
* **Enrutamiento de preguntas más confiable:** Autopilot ha mejorado el manejo de rutas según el contexto de la pregunta.
* **Las investigaciones continúan cuando el servicio de una herramienta está inactivo:** Autopilot continúa con las herramientas restantes cuando el servicio de una herramienta conectada no está disponible.
* **Hallazgos conservados cuando una investigación alcanza el presupuesto:** Autopilot ahora puede resumir los hallazgos que recopiló antes de que una investigación alcanzara el límite de presupuesto.
* **Investigaciones más resilientes:** Autopilot tiene más probabilidades de completar una investigación cuando uno de sus servicios de herramientas conectados no está disponible, y puede recuperarse mejor de ralentizaciones temporales.
* **Resúmenes de investigación más completos:** es más probable que los resúmenes de investigaciones de varios pasos incluyan el análisis completo, y los gráficos aparecen en más de ellos.
* **Mejores respuestas para las preguntas de Sintéticos:** Autopilot ahora puede responder mejor a las preguntas sobre las listas, los recuentos y el estado de todos los monitores de una cuenta, y resuelve mejor una cuenta que mencione en la pregunta. El análisis de una comprobación fallida ahora se centra en el paso que falló.
* **Las preferencias guardadas se adaptan a la pregunta actual:** es menos probable que las preferencias guardadas de conversaciones anteriores influyan demasiado en lo que necesita la pregunta actual, como en el caso de una pregunta aclaratoria cuando no se especifica ninguna entidad.
* **Más de las colecciones de la base de conocimientos:** cuando especifica una colección de la base de conocimientos, Autopilot ahora incluye más de sus resultados y es más probable que avise si no puede recuperar un documento.
* **Más contexto de alerta en las investigaciones:** Autopilot ahora puede basarse en más detalles de la condición de alerta, como los umbrales y la entidad afectada, al investigar un problema.
* **Análisis de workload:** Autopilot ahora puede revisar las entidades miembro de una workload y contar las entidades por atributo.
* **Timestamps consistentes en respuestas rápidas:** los timestamps y las duraciones en las respuestas rápidas son más consistentes.
* **Búsquedas de incidentes para problemas abiertos:** se resolvió un problema que causaba que Autopilot no reportara incidentes para un problema abierto y válido.
* **Estado preciso del paso:** se resolvió un problema que provocaba que un paso de investigación sin terminar se mostrara como completo.
* **Confiabilidad de la búsqueda de entidades:** se resolvió un problema que provocaba que algunas búsquedas de entidades no se activaran.
* **Nuevas conversaciones desde la página de alertas:** el botón **New conversation** ahora abre un nuevo hilo desde la página de alertas.
* **Símbolos de ejemplo específicos de la página:** las páginas que proporcionan sus propios símbolos de ejemplo ahora los muestran en el panel de Autopilot.
