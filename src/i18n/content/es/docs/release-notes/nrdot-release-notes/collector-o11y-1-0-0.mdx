### Característica

* Soporte verificado de observabilidad de Collector para `nrdot-collector:2.8.1` y `opentelemetry-collector-contrib:0.163.2`
* Se eliminó el atributo de recurso `newrelic.service.type` porque ya no es necesario para la detección automática.
* Se estableció `temporality_preference: delta` para evitar una conversión innecesaria durante la ingesta.
