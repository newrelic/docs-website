### Característica

* Caso de uso de host verificado para funcionar con `nrdot-collector:2.0.0`

### Corrección de errores

* Se cambió el nombre de los nodos de configuración `cumulativetodelta` a `cumulative_to_delta` después del cambio de nombre del componente en `v0.157.0`<br />El nombre original `cumulativetodelta` sigue estando disponible como un alias obsoleto.
* Se deshabilitó `system.cpu.logical.count` en la configuración del host<br />La actualización de `v0.157.0` a `receiver/host_metrics` habilitó esta métrica de forma predeterminada. Este cambio restaura el comportamiento anterior.
* Se eliminó la regla de agregación media de `system.cpu.utilization` de la configuración del host<br />La actualización de `v0.157.0` a `receiver/host_metrics` cambió su comportamiento predeterminado para agregar `system.cpu.utilization` por media, lo que hace que la regla eliminada sea redundante.
