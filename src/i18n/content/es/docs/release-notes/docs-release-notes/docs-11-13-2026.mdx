### Nuevos documentos

* Se agregó [Migrar el agente de iOS desde CocoaPods](/docs/mobile-monitoring/new-relic-mobile-ios/installation/migrate-from-cocoapods) para que los equipos de iOS que usan CocoaPods puedan hacer la transición al administrador de paquetes de Swift sin perder la instrumentación ni tener que volver a configurar desde cero.
* Se agregó [Actualizar la integración de reenvío de logs de OCI](/docs/logs/forward-logs/oci-log-forwarder-upgrade) para que los usuarios que ejecutan configuraciones más antiguas del reenviador de logs de OCI tengan una ruta de actualización clara para acceder a las características y correcciones de seguridad actuales.
* Se agregó [Monitoreo de Microsoft SQL Server con NRDOT](/docs/opentelemetry/db360/mssql/introduction) que cubre la instancia administrada de Azure y la base de datos SQL de Azure tanto en Linux como en Windows, para que los equipos puedan configurar la observabilidad completa de la base de datos sin depender de configuraciones personalizadas.

### Cambios importantes

* Se reestructuró la [configuración del agente de Node.js](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration) en páginas específicas por tema para la configuración general, los atributos, el logging, el rastreo, la recolección de errores, el monitoreo de browser y el monitoreo de IA, de manera que los usuarios puedan navegar directamente a la configuración que necesiten en lugar de buscar en una sola página larga.
* Se actualizaron los [límites de usuario de calcular](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/compute-budgets/compute-user-limits) para cubrir los presupuestos de CCU avanzados junto con los de CCU principal, con políticas de aplicación y opciones de notificación separadas para cada medidor, de modo que los administradores puedan controlar los costos de calcular avanzados independientemente del calcular principal.
* Se actualizó la [documentación del agente de Ruby](/docs/apm/agents/ruby-agent/getting-started/introduction-new-relic-ruby) en las páginas de guías de la API, atributos, trabajos en segundo plano, configuración y rastreo distribuido para alinearla con la API del agente actual, de manera que los usuarios que sigan ejemplos existentes no encuentren métodos obsoletos ni nombres de opciones desactualizados.

### Cambios menores

* Se agregó documentación sobre el tipo de gráfico de mapa de árbol a [Tipos de gráficos](/docs/query-your-data/explore-query-data/use-charts/chart-types) para que los usuarios sepan cuándo los mapas de árbol son la visualización adecuada y cómo se diferencian de otros tipos de gráficos ahora que se admite este tipo de gráfico.
* Se actualizó [Compatibilidad y requisitos del agente de .NET](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements) para confirmar la compatibilidad con .NET 11 GA, de modo que los usuarios puedan actualizar su tiempo de ejecución con confianza sabiendo que el agente está verificado.
* Se actualizó la [referencia de herramientas MCP](/docs/agentic-ai/mcp/tool-reference) para agrupar las herramientas bajo etiquetas relacionadas, lo que facilita encontrar la herramienta adecuada para un caso de uso específico sin tener que revisar la lista completa.
* Se actualizó el [agente de Node.js en Microsoft Azure App Services](/docs/apm/agents/nodejs-agent/hosting-services/nodejs-agent-microsoft-azure) con una guía de alojamiento en Azure más clara para reducir el ensayo y error que experimentaban los usuarios al desplegar en Azure App Services.
* Se actualizó [Google Memorystore para Valkey](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-memorystore-valkey) con nombres de métricas corregidos para que las consultas del dashboard y las condiciones de alerta dirigidas a las métricas de Valkey devuelvan datos en lugar de resultados vacíos.
* Se actualizó [FedRAMP](/docs/security/security-privacy/compliance/certificates-standards-regulations/fedramp) con los detalles actuales de la certificación para que los clientes que evalúen los servicios autorizados por FedRAMP dispongan de información de cumplimiento precisa.
* Se actualizó [Conceptos importantes de gestión de usuarios y accesos](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts) para identificar correctamente el rol de usuario de facturación como de ámbito de cuenta y agregar la facturación a las capacidades del administrador de la organización, lo que evita configuraciones incorrectas al configurar el acceso.
* Se actualizó [Modificar la configuración del agente](/docs/new-relic-control/pipeline-control/gateway/modify-agent-configuration) con una guía de configuración ampliada del Gateway de Control de pipelines para cubrir los pasos que faltaban anteriormente.
* Se actualizó [Monitorear Kafka autoadministrado en Kubernetes con OpenTelemetry](/docs/opentelemetry/integrations/kafka/kubernetes-self-managed) para eliminar `kafka.partition.replicas.total` de las configuraciones del recolector, ya que el receptor no recopila esta métrica y su presencia hacía que los usuarios esperaran datos que nunca llegaban.
* Se actualizó [Administrar flujos de trabajo](/docs/workflow-automation/manage-workflows/managing-workflow) con compatibilidad para el historial de versiones en el editor de flujos de trabajo para que los usuarios puedan revisar, comparar y revertir versiones anteriores de sus flujos de trabajo.
* Se actualizó [Límites de los flujos de trabajo](/docs/workflow-automation/limitations-and-faq/workflow-limits) para reflejar el aumento del límite de entrada del flujo de trabajo de 1000 a 3000 caracteres, lo que permite configuraciones de flujos de trabajo más realistas.
* Se actualizó [Reglas y límites de alertas](/docs/alerts/admin/rules-limits-alerts/) para aclarar el límite de facetas para las condiciones de alerta de NRQL que usan agregación anidada, de modo que los usuarios que crean condiciones de alerta complejas conozcan la restricción aplicable.
* Se actualizó [Mediciones de la máquina virtual (VM) de Node.js](/docs/apm/agents/nodejs-agent/extend-your-instrumentation/nodejs-vm-measurements) para eliminar el contenido que hacía referencia al paquete `@newrelic/native-metrics` obsoleto, que fue reemplazado por una implementación en JS puro en la versión v14.11.0.

### Novedades

* [Los límites de usuario de calcular ahora cubren el calcular avanzado](/whats-new/2026/11/whats-new-11-03-compute-user-limits-accu): establezca presupuestos independientes de CCU principal y CCU avanzado por usuario y aplique los límites para cada medidor por separado.
* [Seguimiento de cambios para GitHub Copilot](/whats-new/2026/11/whats-new-11-09-change-tracking-github-copilot): Vincule los despliegues a los pull requests y active flujos de trabajo de corrección automatizados de GitHub Copilot cuando ocurran regresiones.
* [Detectar la instrumentación de New Relic faltante con la herramienta MCP de análisis de brechas](/whats-new/2026/11/whats-new-11-09-gap-analysis-mcp-tool): Escanea los archivos del repositorio local para identificar brechas en los agentes APM, los agentes Browser, los archivos de configuración y los flujos de trabajo de seguimiento de cambios de CI/CD.
