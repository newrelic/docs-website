## Nuevos documentos

* Se agregó la documentación de [Intelligent Exemplar](/docs/distributed-tracing/ui-data/intelligent-exemplar) para la característica de vista previa pública para mostrar trazas anómalas de picos de latencia o errores sin la reconstrucción manual de filtros.
* Se agregó la documentación de [Análisis de correlación de atributos](/docs/distributed-tracing/ui-data/attribute-correlation-analysis) para la característica de vista previa pública para identificar automáticamente los pares atributo-valor que causan picos de latencia o errores.
* Se agregó la documentación de [Madurez del servicio](/docs/service-architecture-intelligence/scorecards/service-maturity) para los niveles de madurez de Scorecards y la puntuación ponderada para realizar un seguimiento de la progresión del servicio hacia la excelencia operativa.
* Se agregó la documentación [Configurar el enrutamiento de múltiples cuentas para el agente eBPF de New Relic](/docs/ebpf/multi-account-routing) para enrutar la telemetría de eBPF a diferentes cuentas de New Relic por namespace de Kubernetes.
* Se agregó la documentación de la [integración de Autopilot con Slack](/docs/agentic-ai/autopilot/connect-to-slack) para conectar Autopilot a Slack para la investigación de incidentes en hilos.
* Se agregó la documentación de [Introducción a las alertas inteligentes](/docs/alerts/smart-alerts) para la característica de vista previa pública para monitorear la cobertura de alertas de la entidad frente a los estándares recomendados y crear condiciones de forma masiva.
* Se agregó la documentación [Variables en notebooks](/docs/query-your-data/explore-query-data/notebooks/notebook-variables) para parametrizar notebooks con variables dinámicas para runbooks de investigación repetibles.
* Se agregó la documentación de [Instrumentación de Puma](/docs/apm/agents/ruby-agent/instrumented-gems/puma-instrumentation) para el muestreo del agente de Ruby de las estadísticas del servidor Puma reportadas como métricas de porciones de tiempo.
* Se agregó la documentación [Monitoreo de MSSQL en Windows RDS con NRDOT](/docs/opentelemetry/database/mssql/windows-rds) para monitorear SQL Server en AWS RDS usando el recolector NRDOT en Windows.

### Cambios importantes

* Se actualizó la documentación de Autopilot en [descripción general](/docs/agentic-ai/autopilot/overview), [configuración](/docs/agentic-ai/autopilot/setup), [uso de Autopilot](/docs/agentic-ai/autopilot/use-autopilot) y [memorias](/docs/agentic-ai/autopilot/memories) con la versión de disponibilidad general (GA), se cambió el nombre de agente de ingeniería de fiabilidad del sitio (SRE) a Autopilot y se actualizó la información de cumplimiento para reflejar la disponibilidad de HIPAA.
* Se actualizó la [documentación del agente eBPF](/docs/ebpf/k8s-installation) para la versión 1.5.0 con soporte ampliado para versiones del kernel (de `v5.8` a `v7.1`), nuevas distribuciones de Linux compatibles (AlmaLinux 9.7+, Oracle Linux 8+, openSUSE Leap 15.5+, SLES 15.7+) y procedimientos de instalación de Kubernetes y Linux actualizados.
* Se actualizaron las [mejores prácticas de eBPF](/docs/ebpf/best-practices) con una nueva sección de muestreo de datos y ajuste fino que explica cómo se muestrea cada tipo de telemetría para el control de volumen de datos y costos.
* Se actualizó la [alta disponibilidad (HA) de Prometheus](/docs/infrastructure/prometheus-integrations/install-configure/prometheus-high-availability-ha) con una nueva tabla de referencia rápida para consolidar los tres valores de deduplicación y un cuadro de introducción actualizado.
* Se actualizó la [configuración manual de la integración de AWS para métricas](/docs/infrastructure/amazon-integrations/aws-integration-for-metrics/manual) al restaurar la sección de configuración de Firehose para la configuración manual de AWS CloudWatch Metric Streams.
* Se actualizó [Administrar equipos](/docs/service-architecture-intelligence/teams/manage-teams) con una nueva sección de widgets de productividad de Team Hub que documenta los requisitos de datos para los widgets de frecuencia de despliegue, tiempo de entrega de cambios, MTTR, tiempo de ciclo de PR y pull requests abiertos.

### Cambios menores

* Se actualizó la [compatibilidad y los requisitos de la integración de Kubernetes](/docs/kubernetes-pixie/kubernetes-integration/get-started/kubernetes-integration-compatibility-requirements) para agregar Kubernetes 1.35 al rango de versiones compatibles.
* Se corrigió [Eventos reportados por el monitoreo de móviles](/docs/data-apis/understand-data/event-data/events-reported-mobile-monitoring) para corregir el tiempo de espera de la sesión de evento `Mobile` y `MobileSession` de 10 minutos a 1 minuto.
* Se actualizó [Monitorear la ejecución del flujo de trabajo](/docs/workflow-automation/manage-workflows/monitor-workflow-execution) para aclarar que el nivel de logs `TRACE` ahora está disponible y documentar su comportamiento para los atributos de salida de acción.
* Se actualizó la [instrumentación de Next.js con el agente híbrido](/docs/apm/agents/nodejs-agent/extend-your-instrumentation/nextjs-instrumentation) para agregar que el enfoque del agente híbrido actualmente solo admite la versión 16 y superior de Next.js.
* Se actualizó la [política de fin de vida útil (EOL) del agente de Ruby](/docs/apm/agents/ruby-agent/getting-started/ruby-agent-eol-policy) para agregar Ruby 10.x y su versión mínima compatible (Ruby 2.6.0).
* Se actualizó [Múltiples registros de usuario](/docs/accounts/accounts-billing/account-setup/multiple-user-records) para aclarar que la eliminación de los dominios de autenticación de una organización es permanente y no se puede deshacer.
* Se actualizó [Ubicaciones de datos de la Ley de Resiliencia Operativa Digital (DORA)](/docs/security/security-privacy/compliance/certificates-standards-regulations/dora/dora-data-locations) con información revisada sobre la ubicación de procesamiento.
* Se corrigió la [resolución de problemas del agente PHP para Fargate](/docs/apm/agents/php-agent/troubleshooting/fargate-nitro-clock-performance-impact) para corregir un enlace roto.
* Se actualizó [Equipos](/docs/service-architecture-intelligence/teams/teams) para aclarar las descripciones de permisos para la página de configuración de automatizaciones y jerarquías.
* Se actualizó [Monitoreo de MSSQL alojado en Windows con NRDOT](/docs/opentelemetry/database/mssql/windows-hosted) con valores predeterminados revisados para los parámetros de configuración de recolección de consultas principales.
