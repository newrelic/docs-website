### Nuevos documentos

* Se agregó cómo [conectar](/docs/agentic-ai/autopilot/connect-to-github), [usar](/docs/agentic-ai/autopilot/use-autopilot-with-github) y [solucionar problemas](/docs/agentic-ai/autopilot/troubleshoot-github-connection) de la nueva integración de Autopilot con GitHub, una característica de vista previa pública que recupera el pull request detrás de un despliegue de seguimiento de cambios durante las investigaciones.
* Se agregaron [acciones de incidencias de Jira](/docs/workflow-automation/setup-and-configure/actions-catalog/jira/jira-issue) al catálogo de acciones de automatización de flujo de trabajo, que cubren las acciones de creación, actualización, búsqueda y transición para incidencias de Jira Cloud.
* Se agregaron [acciones de trabajos de Ansible](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job-launch) al catálogo de acciones de automatización de flujo de trabajo para iniciar y verificar el estado de las plantillas de trabajos de Ansible Automation Platform.
* Se agregó la [acción Ejecutar Autopilot](/docs/workflow-automation/setup-and-configure/actions-catalog/autopilot/newrelic-autopilot) para proporcionar una referencia dedicada en el catálogo de acciones para ejecutar investigaciones de Autopilot desde un flujo de trabajo.
* Se agregó [RCA de alerta con Autopilot y Slack](/docs/workflow-automation/workflow-examples/integrations/autopilot-slack-rca) para mostrar cómo activar un análisis de causa raíz de Autopilot desde una alerta y publicar los hallazgos en Slack.
* Se agregó [Economía unitaria](/docs/cci/financial-intelligence/unit-economics) a Inteligencia para costos en la nube para explicar cómo medir el costo de entregar una sola unidad de valor, como el costo por consulta, y realizar un seguimiento de la eficiencia frente a un punto de referencia.
* Se agregó [Usar destinos entre cuentas en la UI](/docs/apis/nerdgraph/examples/cross-account-destinations/use-cross-account-destinations-in-the-ui) para mostrar dónde aparecen los destinos entre cuentas en la UI de New Relic y cómo usarlos en los flujos de trabajo.

### Cambios importantes

* Se actualizó la [configuración del agente de infraestructura](/docs/infrastructure/infrastructure-agent/configuration/infrastructure-agent-configuration-settings) con los nuevos ajustes `safe_bin_dir`, `agent_temp_dir` y del directorio de logging.
* Se actualizó la [configuración del agente .NET](/docs/apm/agents/net-agent/configuration/net-agent-configuration) con la nueva opción `sqlMetadataCommentsEnabled`, que permite al agente agregar un comentario de GUID de entidad de servicio a las declaraciones SQL instrumentadas para correlacionar los datos de APM con el monitoreo del rendimiento de la consulta.
* Se reestructuró la [Introducción a los notebooks](/docs/query-your-data/explore-query-data/notebooks/introduction-notebooks) para eliminar el aviso de vista previa pública y describir el nuevo modelo de acceso detallado, que incluye roles a nivel de organización (acceso completo, creador) y roles a nivel de notebook (propietario, editor, lector).
* Se actualizó [Inteligencia para costos en la nube: recomendaciones](/docs/cci/financial-intelligence/cci-recommendations) para extender las recomendaciones de dimensionamiento adecuado del motor de optimización nativo a los recursos de Azure, y se agregó orientación sobre los requisitos previos de cobertura de telemetría y la cadencia de actualización de las recomendaciones.
* Se agregó una nueva sección simplificada de gráfico de barras para clasificar las series frente a la más grande, y una opción de umbral Neutral para los gráficos de medidor, a [Tipos de gráficos](/docs/query-your-data/explore-query-data/use-charts/chart-types).
* Se actualizó la [configuración del estado de salud de la workload](/docs/new-relic-solutions/new-relic-one/workloads/workload-status-configuration) con orientación sobre los efectos de cambiar los métodos de configuración, incluido el retraso del estado de salud y la desvinculación y revinculación automática de las condiciones de alerta.

### Cambios menores

* Se agregó un aviso de limitación de soporte de Windows a la [guía de instalación de la integración de MongoDB](/install/mongodb/), señalando que Percona congeló el exportador incluido en su versión actual porque dejó de publicar binarios de Windows.
* Se actualizó [Problemas de carga de clases de JBoss y WildFly](/docs/apm/agents/java-agent/troubleshooting/classloading-issues-from-jboss-and-wildfly) con una nueva sección de resolución de problemas para fallas de inicio causadas por el administrador de logs de JBoss.
* Se actualizó [Redes](/docs/new-relic-solutions/get-started/networks) con bloques de IP de ingesta de datos de doble pila adicionales para los centros de datos de EE. UU. y la UE.
* Se actualizó la [Instrumentación de terceros](/docs/apm/agents/ruby-agent/api-guides/third-party-instrumentation) para el agente de Ruby para aclarar cómo contribuir con nueva instrumentación de gemas y tener en cuenta que `extends_newrelic_rpm` ahora está archivado.
* Se actualizó [FedRAMP](/docs/security/security-privacy/compliance/certificates-standards-regulations/fedramp) para reflejar el nuevo estado de certificación FedRAMP Clase C (moderado).
* Se actualizó el [Cifrado de datos](/docs/security/security-privacy/compliance/data-encryption) para reflejar el cambio de los estándares de cifrado compatibles con FIPS 140-2 a FIPS 140-3.
* Se actualizó [Iniciar una ejecución de flujo de trabajo](/docs/workflow-automation/workflow-automation-apis/start-workflow-run) con una nueva entrada `idempotencyKey`, y se aclaró la validación del formato UUID para `idempotencyKey` en las acciones de notificación de Azure y New Relic en el [catálogo de acciones](/docs/workflow-automation/setup-and-configure/actions-catalog/actions-catalog).
* Se actualizó la [seguridad del agente de infraestructura](/docs/infrastructure/infrastructure-agent/infrastructure-security) para documentar los requisitos de la cuenta de servicio de Windows, incluido el soporte de la cuenta de servicio administrada de grupo (gMSA).
* Se actualizó [Elija su centro de datos](/docs/accounts/accounts-billing/account-setup/choose-your-data-center) para aclarar que la región de EE. UU. es la predeterminada.
* Se actualizó el [Servicio New Relic nativo de Azure](/docs/infrastructure/microsoft-azure-integrations/get-started/azure-native) con la URL actual del listado de Azure Marketplace y se eliminó la nota de disponibilidad de HIPAA desactualizada.
* Se actualizó la [compatibilidad y los requisitos de la integración de Kubernetes](/docs/kubernetes-pixie/kubernetes-integration/get-started/kubernetes-integration-compatibility-requirements) para reflejar las versiones de Kubernetes compatibles de la 1.31 a la 1.35.
* Se corrigió [Sintaxis, cláusulas y funciones de NRQL](/docs/nrql/nrql-syntax-clauses-functions) para corregir la puntuación Apdex predeterminada a 0.4 segundos.
* Se agregó una opción de conector de Databricks (Azure) a [Configurar conectores para New Relic Lens](/docs/new-relic-lens/set-up-connectors).
