  Estamos probando las notas de la versión para informarle qué cambia en nuestra documentación cada semana. Este es un experimento, así que [avísenos a través de un issue de GitHub](https://github.com/newrelic/docs-website/issues/new/choose) si le resultan útiles.

### Cambios importantes

* Revisamos y reescribimos la documentación de integración en el host para [RabbitMQ](/install/rabbitmq/), [JMX](/install/jmx/), [Apache Flink](/install/apache-flink/) y [HAProxy](/install/haproxy/) para facilitar la instalación y asegurar que la documentación sea precisa y esté actualizada.
* Para el [monitoreo sin servidor de AWS Lambda](/docs/serverless-function-monitoring/aws-lambda-monitoring/get-started/compatibility-requirements-aws-lambda-monitoring/), se actualizó la información sobre las versiones de tiempo de ejecución compatibles, las dependencias y el SDK del paquete NuGet de .NET obsoleto.
* Actualizamos nuestros documentos de cumplimiento de [FedRAMP](/docs/security/security-privacy/compliance/certificates-standards-regulations/fedramp/), [HIPAA](/docs/security/security-privacy/compliance/certificates-standards-regulations/hipaa/), [ISO-27001](/docs/security/security-privacy/compliance/certificates-standards-regulations/iso-27001/), [SOC2](/docs/security/security-privacy/compliance/certificates-standards-regulations/soc2/), [TISAX](/docs/security/security-privacy/compliance/certificates-standards-regulations/tisax/), [cifrado de datos](/docs/security/security-privacy/compliance/data-encryption/) y [HITRUST CSF](/docs/security/security-privacy/compliance/hitrust/) para reflejar el estado de cumplimiento de New Relic de 2024.
* Revisión y reorganización continuas de la [documentación de NRQL](/docs/nrql/get-started/introduction-nrql-new-relics-query-language) para mejorar la legibilidad y la calidad.
* Se aclaró que el [almacenamiento sin conexión del monitoreo de móviles](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/configure-settings/#android-offline-storage) de Android está desactivado por defecto y se actualizó el documento de [configuración del almacenamiento sin conexión](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/set-max-offline-storage/#android).
* Se agregó información sobre las [opciones de monitoreo de móviles de Unity](https://docs.newrelic.com/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/configure-settings/#unity).
* Se agregó un extremo de monitoreo sintético para [AWS PrivateLink](/docs/data-apis/custom-data/aws-privatelink).
* Se agregó una sección de resolución de problemas al documento de [integración de Statsd](/docs/more-integrations/open-source-telemetry-integrations/statsd/statsd-monitoring-integration/#troubleshooting).
* Se agregó una nueva sección de opción de configuración de .NET para la [instrumentación del elemento de reglas](/docs/apm/agents/net-agent/configuration/net-agent-configuration/#instrumentation-rules) .
* Se actualizaron los [requisitos de versión de transición del administrador de trabajos](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-transition-guide) del monitoreo sintético.

### Actualizaciones menores

* Se agregaron variables de entorno de [Kubernetes `vsePassphrase`](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-configuration/#kubernetes-env-config) para el monitoreo sintético.
* Se corrigieron algunos enlaces internos rotos.
* Se actualizó la sección de [estado de error de Errors Inbox](/docs/triage-inbox/errors-inbox) con una nueva imagen y más detalles sobre la UI.
* Se actualizaron las versiones del [módulo de tiempo de ejecución del monitoreo sintético](/docs/synthetics/synthetic-monitoring/using-monitors/manage-monitor-runtimes).
* Se agregó información sobre cómo usar [múltiples fuentes de logs con el plug-in de Fluent Bit](/docs/logs/forward-logs/fluent-bit-plugin-log-forwarding).
* Se agregó cómo [consultar los logs de Live Archives a través de la API de NerdGraph](/docs/logs/get-started/live-archives).
* Se actualizaron y corrigieron varios problemas menores de estilo e imágenes.
* Se agregó un [ejemplo de paginación de cursor](/docs/apis/nerdgraph/examples/nerdgraph-api-notifications-channels/#paginate) de inteligencia aplicada de NerdGraph.
* Se corrigió la configuración rota de la [integración de GPU de NVIDIA](/docs/infrastructure/host-integrations/host-integrations-list/nvidia-gpu-integration).
* Se agregó una sección sobre la configuración del [host de carga de mapeo](/docs/mobile-monitoring/new-relic-mobile-android/install-configure/android-agent-crash-reporting) del monitoreo de móviles de Android.
* Se agregaron detalles de configuración para la [integración de monitoreo de Temporal](/docs/infrastructure/host-integrations/host-integrations-list/temporal-monitoring-integration) para Java.
* Se agregó el permiso faltante para [GCP Cloud Functions](/docs/infrastructure/google-cloud-platform-integrations/get-started/integrations-custom-roles).
* Se actualizó el enlace de la documentación relacionado con [el reporte de vulnerabilidades de seguridad](/docs/security/security-privacy/information-security/security-bulletins/#report).
* Se actualizó el documento de seguridad para eliminar la mención de HackerOne, que ya no usamos para nuestro [proceso de divulgación coordinada](/docs/security/security-privacy/information-security/software-development-lifecycle).
* Se agregó información sobre las implicaciones legales del uso de [métodos de proxy del monitoreo de browser](/docs/browser/new-relic-browser/configuration/proxy-agent-requests).
* Se aclaró que el atributo [`coreCount`](https://docs.newrelic.com/attribute-dictionary/?event=SystemSample&attribute=coreCount) para el evento `SystemSample` en Windows cuenta el número de procesadores para la instancia actual del procesador.
* Se actualizaron los documentos de [configuración de monitoreo de rendimiento de red](/docs/network-performance-monitoring/advanced/advanced-config) para describir los cambios relacionados con la API de Meraki y los syslogs de dispositivos de red.
* Se eliminó la fecha de EOL de la [integración de Prometheus OpenMetrics en Kubernetes](/docs/infrastructure/prometheus-integrations/install-configure-prometheus-agent/migration-guide).
* En la navegación izquierda, se cambió el nombre de la instrumentación manual legacy de Serverless a [instrumentación manual sin capas](/docs/serverless-function-monitoring/aws-lambda-monitoring/enable-lambda-monitoring/enable-serverless-monitoring-aws-lambda-layerless/).
* Diversas correcciones menores de redacción para mejorar la claridad y la coherencia con nuestra guía de estilo.
