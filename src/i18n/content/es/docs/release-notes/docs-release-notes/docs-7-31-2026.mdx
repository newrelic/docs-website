## Nuevos documentos

* Ya está disponible la documentación de la [vista previa pública de los registros de eBPF](/docs/ebpf/logs), que incluye una referencia de configuración y mejores prácticas.
* Ya está disponible la documentación de [soporte de certificados personalizados](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-configuration/#custom-ca-certificates) para configurar certificados de CA personalizados en ubicaciones privadas.

### Cambios importantes

* Se actualizó la configuración de monitoreo de [Azure VNet Flow Logs](/docs/network-performance-monitoring/setup-performance-monitoring/cloud-flow-logs/azure-vnet-flow-log-monitoring) con soporte para múltiples planes (`FlexConsumption`, `ElasticPremium`, `Basic`, `Consumption`), extremo de FedRAMP/US Gov Cloud y documentación de enrutamiento de salida en modo privado.
* Se actualizaron los [términos del plan de uso](/docs/licenses/license-information/usage-plans/new-relic-usage-plan) para incluir una definición de &quot;características de evaluación&quot; y una cláusula de período de evaluación gratuito temporal bajo Pay As You Go.

### Cambios menores

* Se actualizó la [gestión de cuentas](/docs/accounts/accounts-billing/account-setup/downgradecancel-account) para incluir un artículo de referencia sobre cómo ver las relaciones entre cuentas.
* Se actualizaron los [requisitos de compatibilidad del agente de Java](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent).
* Se actualizó la documentación de [OpenTelemetry MSSQL](/docs/opentelemetry/database/mssql/introduction) con nuevos detalles de configuración.
* Se actualizó la referencia de atributos de la [API de eventos de seguimiento de cambios](/docs/change-tracking/change-tracking-events) dividiendo las secciones obligatorias y opcionales para una incorporación más rápida.
* Se corrigieron los [comandos de desinstalación del control del agente](/docs/new-relic-solutions/new-relic-one/install-configure/uninstall-agent) para corregir comandos incorrectos.

### EOL

* Página de documentación de la **API REST de fallas móviles v1 retirada**. La API v1 obsoleta ha sido reemplazada por la v2.

    * Se actualizó AWS Unified Lambda a v1.1.3 y se actualizó Go a 1.26.5 para solucionar los CVE.

  * [Agente PHP v12.9.0.38](/docs/release-notes/agent-release-notes/php-release-notes/php-agent-12-9-0-38):

  * [Agente de Java v9.4.0](/docs/release-notes/agent-release-notes/java-release-notes/java-agent-940):

    * Se agregó instrumentación de Vert.x web y core 5.x, módulos de Java Server Faces y Portlet, y un atributo `http.request.method` en llamadas externas, además de correcciones para una fuga de MDC en Log4j2 y vinculación de transacción asíncrona.
