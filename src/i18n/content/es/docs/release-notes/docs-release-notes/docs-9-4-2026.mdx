### Nuevos documentos

* Se agregó [Clasificación de la corrección de vulnerabilidades con el agente de Security RX](/docs/vulnerability-management/agent/overview) para proporcionar orientación sobre el uso del agente de Security RX para analizar CVE, generar planes de corrección y activar el agente de codificación para abrir pull request.
* Se agregó [Flujo de trabajo de Jira de Security RX](/docs/vulnerability-management/workflows/jira) para proporcionar instrucciones paso a paso para crear y sincronizar automáticamente ticket de Jira para vulnerabilidades de seguridad detectadas por Security RX.
* Se agregó [Resolución de problemas de New Relic MCP](/docs/agentic-ai/mcp/troubleshoot) para proporcionar pasos y soluciones comunes de resolución de problemas para resolver problemas de configuración y establecimiento del servidor MCP.

### Cambios importantes

* Se reestructuró el [monitoreo de Microsoft SQL Server con NRDOT](/docs/opentelemetry/database/mssql/introduction) con una nueva referencia de configuración completa, una nueva guía de configuración del recolector de CNCF y documentos de instalación revisados para entornos alojados en Windows, Windows RDS, alojados en Linux y Linux RDS.
* Se actualizó [Tipos de agente](/docs/new-relic-control/agent-control/agent-types) con documentación para configurar el reenvío de logs de Fluent Bit en Agent Control, incluida la ubicación del archivo de configuración, las rutas de los binarios por sistema operativo y el comportamiento de actualización.
* Se actualizó [Administrar flotas](/docs/new-relic-control/fleet-control/manage-fleets) con documentación completa para el nuevo flujo de trabajo de aprobación de configuración en el control de flota. Las aprobaciones de configuración requieren al menos un revisor distinto del autor antes de que se pueda desplegar una versión de configuración, y su cumplimiento comenzará el 22 de septiembre de 2026.
* Se actualizó el [Esquema de definición de Workflow Automation](/docs/workflow-automation/workflow-automation-apis/definition-schema) con la nueva acción State Step para persistir pares de valor principal en los pasos del flujo de trabajo a través de `.workflowState`, y se actualizaron los [límites del flujo de trabajo](/docs/workflow-automation/limitations-and-faq/workflow-limits) y el [monitoreo de ejecución](/docs/workflow-automation/manage-workflows/monitor-workflow-execution) para cubrir el nuevo tipo de paso y los datos de `WorkflowAutomationEvent`.
* Se agregó compatibilidad con VMware vSphere Kubernetes Service (VKS) 3.x a los [Requisitos de compatibilidad de la integración de Kubernetes](/docs/kubernetes-pixie/kubernetes-integration/get-started/kubernetes-integration-compatibility-requirements), que cubre VKS que se ejecuta en vSphere Supervisor 9.0 a 9.1 (vSphere 8.x y 9.x).
* Se actualizaron los [requisitos de compatibilidad del agente .NET](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements) con las últimas versiones de biblioteca compatibles verificadas.
* Se actualizó [Catálogos](/docs/service-architecture-intelligence/catalogs/catalogs) para documentar el filtrado de valores de columna basado en etiquetas a través de píldoras interactivas y el reordenamiento de columnas arrastrando y soltando en la tabla de la vista Personalizar.
* Se agregó una advertencia a [Inteligencia de respuesta con IA](/docs/alerts/alert-event-management/response-intelligence-ai) que indica que la información valiosa generada por IA son sugerencias para guiar la investigación, no causas raíz confirmadas, y deben verificarse con sus datos antes de actuar en consecuencia.
* Se agregó la biblioteca de código abierto `snapdom` a las [Licencias del agente del browser de New Relic](/docs/licenses/product-or-service-licenses/new-relic-browser/new-relic-browser-licenses).
* Se actualizó la [pestaña OpenTelemetry de Errors Inbox](/docs/errors-inbox/otel-tab) para corregir el nombre del atributo de span de `otel.status` a `otel.status_code` y expandir los tipos de span compatibles para incluir `producer`, `client` y `internal` además de `server` y `consumer`.
* Se actualizó [Elija su centro de datos](/docs/accounts/accounts-billing/account-setup/choose-your-data-center) para reflejar que la región de datos de Japón (JP) ahora está disponible de forma general.

### Cambios menores

* Se actualizó [Configurar New Relic MCP](/docs/agentic-ai/mcp/setup) con comandos de la CLI de Claude Code corregidos para la autenticación OAuth, un requisito de versión mínima (Claude Code v2.1.186+), y un formato de configuración JSON simplificado.
* Se agregó `nrExporterEndpoints` a la [Referencia de configuración YAML de Gateway](/docs/new-relic-control/pipeline-control/gateway/yaml-overview) para anular los extremos de ingesta predeterminados de New Relic por canalización, incluido un nuevo campo `otlpEndpoint`, en una sección dedicada de Anulaciones opcionales.
* Se actualizó la [Resolución de problemas de la API de traza](/docs/apm/distributed-tracing/trace-api/troubleshooting-missing-trace-api-data) y los [datos de traza faltantes](/docs/distributed-tracing/troubleshooting/missing-trace-data) con los límites de timestamp del span más antiguo corregidos para OTLP y la API de traza.
* Se agregó una sección de advertencias de cardinalidad a [Administrar la cardinalidad](/docs/data-apis/ingest-apis/metric-api/cardinality-management) que explica qué sucede cuando se alcanza un presupuesto de cardinalidad, cómo identificar las métricas afectadas a través de indicadores de advertencia en gráficos y dashboards, y cómo consultar datos sin procesar mientras se realiza la corrección.
* Se agregó el namespace Direct to Live Archives como una tercera opción de partición a [Particiones de datos](/docs/logs/ui-data/data-partitions) y se agregó orientación a [Live Archives](/docs/logs/get-started/live-archives) que explica que este namespace omite la retención estándar para los logs de cumplimiento y auditoría que van directamente al almacenamiento a largo plazo.
* Se corrigió la descripción del error `403 Forbidden` en el [Informe de errores de JavaScript de React Native](/docs/mobile-monitoring/new-relic-monitoring-react-native/react-native-agent-js-error-reporting) para indicar que la clave de API debe pertenecer a un usuario con permisos de vista de entidad móvil.
* Se actualizó [RCA de alerta con Autopilot y Slack](/docs/workflow-automation/workflow-examples/integrations/autopilot-slack-rca) con un consejo sobre el uso de la variable `{{ issueId }}` para pasar automáticamente el ID del problema de la alerta desencadenante al integrarse con los flujos de trabajo de alerta.
* Se actualizó [Degradar o cancelar cuenta](/docs/accounts/accounts-billing/account-setup/downgradecancel-account) para agregar un aviso que aclara que la última cuenta activa en una organización no se puede cancelar de forma independiente y se debe eliminar eliminando la organización, y se mejoraron los pasos de eliminación de la organización para mayor claridad.
