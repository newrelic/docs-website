### Nuevos documentos

* Se agregó la [acción de AWS EventBridge](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/aws-eventbridge) al catálogo de acciones de Automatización de flujos de trabajo para publicar eventos en Amazon EventBridge.
* Se agregó la [acción de nivel de servicio de New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/newrelic-service-level) al catálogo de acciones de automatización de flujos de trabajo para crear y administrar objetivos de nivel de servicio desde un flujo de trabajo.

### Cambios importantes

* Se actualizó [Crear cargas de trabajo inteligentes](/docs/new-relic-solutions/new-relic-one/workloads/create-intelligent-workload) con la creación masiva a partir de recomendaciones, una sección de filtros de exclusión y una nueva sección de requisitos previos para habilitar el rastreo distribuido.
* Se amplió la [acción de AWS SQS](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/aws-sqs) en el catálogo de acciones de automatización de flujos de trabajo con opciones de configuración adicionales y contenido de referencia ampliado.
* Se actualizó [NRQL para la inteligencia financiera de CCI](/docs/cci/financial-intelligence/nrql-for-cci) con ejemplos de consultas optimizados y explicaciones simplificadas.
* Se agregó una entrada de Oracle Kubernetes Engine (OKE) y compatibilidad con MariaDB/Aurora MySQL al [agente de eBPF](/docs/ebpf/requirements).
* Se agregaron los parámetros de configuración de monitoreo de `agentMetadataReporting` y GenAI a la [instalación de eBPF en Kubernetes](/docs/ebpf/k8s-installation) y a la [instalación de eBPF en Linux](/docs/ebpf/linux-installation).
* Se actualizaron las URL de los extremos de traducción del dashboard de Grafana en [Ver y consultar datos de Prometheus en Grafana](/docs/infrastructure/prometheus-integrations/view-query-data/grafana).
* Se actualizó el comando de actualización de la ruta de configuración del Collector de NRDOT en los documentos de monitoreo de [MySQL](/docs/opentelemetry/database/mysql/hosted) y [PostgreSQL alojado y RDS](/docs/opentelemetry/database/postgresql/hosted).
* Se actualizaron [Tipos de agente](/docs/new-relic-control/agent-control/agent-types) y [Configuración de espejo](/docs/new-relic-control/agent-control/mirror-setup) con los requisitos de verificación de firmas para los espejos de OCI y las definiciones de tipos de agente.
* Se actualizó [Instalar el agente de Java con seguridad de Java 2](/docs/apm/agents/java-agent/additional-installation/install-java-agent-java-2-security) con los permisos requeridos para entornos de Java 9+ para evitar errores de acceso denegado.
* Se actualizaron la [descripción general de MCP](/docs/agentic-ai/mcp/overview) y [Configurar MCP de New Relic](/docs/agentic-ai/mcp/setup) con nuevos ámbitos de OAuth y clave de API.
* Se actualizó el [documento de instalación de la integración de Kubernetes](/docs/kubernetes-pixie/kubernetes-integration/installation/k8s-agent-operator) para agregar compatibilidad con la conexión automática de APM de Kubernetes en los nodos de EKS Fargate.

### Cambios menores

* Se agregó una nota a [Conectar la federación de identidad de carga de trabajo de GCP](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation) para aclarar que los nombres de los grupos y proveedores son sugerencias personalizables.
* Se actualizaron las descripciones de rendimiento de las consultas de la base de datos en [Monitorear Microsoft SQL Server con el recolector de CNCF](/docs/opentelemetry/database/mssql/cncf).

### Novedades

* [Agrupación basada en etiquetas, columnas personalizadas y reordenamiento de columnas en Catalogs](/whats-new/2026/09/whats-new-09-07-catalogs-tag-grouping): ahora puede agrupar entidades y agregar columnas usando cualquier etiqueta, definida por New Relic o personalizada, y reordenarlas para que se adapten al flujo de trabajo, y el diseño se guardará automáticamente.
