### Nuevos documentos

* Un nuevo documento sobre nuestra [integración de NVIDIA Management Library (NVML)](/docs/infrastructure/host-integrations/host-integrations-list/nvml-integration) describe cómo usar el agente de infraestructura y NRI-Flex para monitorear el uso de la GPU y las métricas de rendimiento.

* Cuando la Gestión de vulnerabilidades funciona demasiado bien, una actualización reciente le permite [ignorar las vulnerabilidades](/docs/vulnerability-management/change-vulnerability-status) que no le preocupan.

* Una reestructuración masiva de la categoría de documentos de OpenTelemetry, que incluye un nuevo [APM: monitorear aplicaciones y servicios con OpenTelemetry](/docs/more-integrations/open-source-telemetry-integrations/opentelemetry/get-started/apm-monitoring/opentelemetry-apm-intro) para ofrecerle un punto de partida sólido. Otros cambios:

  * Se reorganizó la categoría **OpenTelemetry &gt; Get started** para agregar documentos de **Descripción general** uniformes a sus subcategorías.
  * Se cambiaron los nombres de los títulos de los documentos para aclarar su contenido.
  * Se consolidaron los documentos relacionados para facilitar la búsqueda de información relacionada.

* Para quienes prefieren no escribir expresiones regulares o patrones Grok para analizar sus logs, el [análisis en tiempo de consulta](/docs/logs/ui-data/query-time-parsing) es una herramienta poderosa para analizar logs directamente en la UI. (Este incluye muchas capturas de pantalla excelentes).

### Cambios importantes

* Continuamos reescribiendo la documentación de integración en el host para facilitar la instalación y asegurar que la documentación sea precisa y esté actualizada. Esta semana: integraciones de monitoreo de [Port](/docs/infrastructure/host-integrations/host-integrations-list/port-monitoring-integration) y [Unix](/docs/infrastructure/host-integrations/host-integrations-list/unix-monitoring-integration).
* Se aclaró cómo administrar y usar las [reglas de retención de datos](/docs/data-apis/manage-data/manage-data-retention) para organizaciones de una o varias cuentas.
* Movimos la información de rastreo de versiones del [rastreo de errores](/docs/triage-inbox/errors-inbox) al [rastreo de versiones](/docs/triage-inbox/version-tracking) y realizamos algunas mejoras en la calidad de vida en el proceso.
* En octubre de 2024, pondremos fin a la vida útil de las versiones minion privado en contenedor (CPM) y tiempo de ejecución sintético legacy. En junio, bloquearemos la creación de nuevos monitores que utilicen estos tiempos de ejecución legacy. Hemos agregado notas al respecto, como este [aviso de fin de vida útil](/docs/apis/synthetics-rest-api/monitor-examples/manage-synthetics-monitors-rest-api/#before-you-start).

### Cambios menores

* En nuestro [tutorial de flujo de trabajo de NerdGraph](/docs/apis/nerdgraph/examples/nerdgraph-api-workflows/#update-workflow), se agregó un ejemplo de GraphQL para añadir un nombre de flujo de trabajo y dos canales.
* Se agregó una nota que indica que al [crear una regla de análisis de logs personalizada](/docs/logs/ui-data/parsing/#custom-parsing), debe pegar los logs sin formato en la UI de análisis.
* Se agregó **Ver Session Replay** a la lista de [permisos de usuario](/docs/accounts/accounts-billing/new-relic-one-user-management/user-permissions/#browser) del navegador.
* Se corrigió el ejemplo incorrecto del archivo de [configuración de Sonarqube](/docs/infrastructure/host-integrations/host-integrations-list/sonarqube-monitoring-integration).
* Agregamos atributos a nuestro diccionario de datos para los tipos de evento `LlmChatCompletionMessage`, `LlmChatCompletionSummary` y `LlmEmbedding`.
* Se agregaron pautas sobre el uso de mayúsculas para Session Replay a nuestra [guía de estilo](/docs/style-guide/capitalization/product-capability-feature-usage).
* Agregamos una definición más sólida de [análisis de logs](/docs/logs/ui-data/parsing) a nuestro párrafo de introducción.
* Se agregó `gov-aws-api.newrelic.com` a nuestra lista de [extremos compatibles con FedRAMP](/docs/security/security-privacy/compliance/fedramp-compliant-endpoints).
* Se agregó un ejemplo de mutación de NerdGraph que muestra cómo [rotar un token de secreto de cliente de Azure](/docs/apis/nerdgraph/examples/nerdgraph-cloud-integrations-api-tutorial/#rotate-azure-token).
* En respuesta a los comentarios de los clientes, actualizamos [Usar sus gráficos](/docs/query-your-data/explore-query-data/use-charts/use-your-charts) para aclarar las opciones de gráficos **Numeric**, **Date**, **Duration** y **Time to Now** en la UI.
* La página de [OpenTelemetry de Errors Inbox](/docs/more-integrations/open-source-telemetry-integrations/opentelemetry/view-your-data/opentelemetry-errors-inbox-page) en la UI tiene un nuevo valor de mensaje de grupo `http.response.status_code`.
* Nuestras [plantillas de mensajes de notificación de alertas](/docs/alerts-applied-intelligence/notifications/message-templates/#escape) ahora admiten caracteres de escape para ayudarle a evitar caracteres que rompan el JSON, entre otras cosas.
* Es posible que haya notado que nuestros bloques de código se ven mucho mejor. Actualizamos muchos de nuestros bloques de código con resaltado de sintaxis específico del lenguaje para que sean más atractivos y fáciles de leer.
* Se actualizaron los ejemplos de código en los documentos de la API [data\_source\_generator](/docs/apm/agents/python-agent/python-agent-api/datasourcegenerator-python-agent-api/#example) y [register\_data\_source](/docs/apm/agents/python-agent/python-agent-api/registerdatasource-python-agent-api/#examples) del agente APM de Python.
* Ampliamos nuestra ayuda para la [resolución de problemas de reenvío de logs de Azure](/docs/logs/forward-logs/azure-log-forwarding/#troubleshoot).
