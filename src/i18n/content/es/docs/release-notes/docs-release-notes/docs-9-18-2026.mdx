### Nuevos documentos

* Se agregó [Configurar el agente de React Native para EAS Build](/docs/mobile-monitoring/new-relic-monitoring-react-native/configure-eas-build-react-native) para brindar orientación sobre las cargas automáticas de mapas de origen, dSYM y archivos de mapeo al compilar con EAS Build.
* Se agregaron las [acciones de AWS Auto Scaling](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/aws-autoscaling) al catálogo de acciones de automatización de flujos de trabajo, que abarcan acciones para administrar instancias, la capacidad deseada, la actualización de instancia y las acciones programadas.

### Cambios importantes

* Se cambió el nombre a [New Relic Ground Truth](/docs/agentic-ai/mcp/overview) (anteriormente New Relic AI MCP) para su disponibilidad general y se cambió la configuración para que sea solo mediante OAuth.
* Se actualizaron [Descripción general de New Relic Lens](/docs/new-relic-lens/overview), [Configurar conectores](/docs/new-relic-lens/set-up-connectors), [Consulta de datos con Lens](/docs/new-relic-lens/query-data) y [Vistas materializadas](/docs/new-relic-lens/materialized-views) para su disponibilidad general.
* Se actualizó [Administración de la configuración](/docs/new-relic-control/agent-control/configuration) con un nuevo sistema de proveedores de valores, y [Resolución de problemas comunes](/docs/new-relic-control/agent-control/troubleshooting) con nombres de configuración corregidos y una nueva sección de resolución de problemas de NRDiag.
* Se actualizaron las páginas de acciones de AWS en el [Catálogo de acciones](/docs/workflow-automation/setup-and-configure/actions-catalog/actions-catalog) con un formato uniforme, nuevas acciones de AWS Bedrock y tres nuevas acciones de Lambda.
* Se reestructuraron las [acciones de notificación de New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/newrelic-notification) para agregar un tipo de archivo adjunto `DASHBOARD_SNAPSHOT` para enviar instantáneas de dashboard a través de notificaciones de flujo de trabajo.
* Se corrigió un selector de análisis de respuestas roto y se agregó una sección de resolución de problemas a [RCA de alerta con Autopilot y Slack](/docs/workflow-automation/workflow-examples/integrations/autopilot-slack-rca).
* Se agregó un control de leyenda y una sección “Visualizar relaciones”, y se convirtieron las tablas de referencia de nodos e íconos en cuadrículas de mosaicos, en [Comprender y usar mapas](/docs/service-architecture-intelligence/maps/advanced-maps).
* Se agregó una sección de configuración de métricas de Kafka a la [configuración del agente .NET](/docs/apm/agents/net-agent/configuration/net-agent-configuration).
* Se agregó una sección sobre el seguimiento de cambios en todo el entorno a [Cómo ver y analizar los cambios en New Relic](/docs/change-tracking/view-analyze-data) y se reestructuró [Rastrear cambios usando NerdGraph](/docs/change-tracking/config/nerdgraph) para ayudar a los usuarios a migrar de los extremos de despliegue de la API REST v2 y v0 obsoletos.
* Se reintrodujeron los tipos de entidad Service Attachment y extremo de Private Service Connect con nuevas tablas de métricas clave en la [integración de monitoreo de Google Compute Engine](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-compute-engine-monitoring-integration).

### Novedades

* [New Relic Ground Truth ya está disponible de forma general](/whats-new/2026/09/whats-new-09-15-ground-truth): Ground Truth brinda a las herramientas de IA y a los agentes acceso controlado a la inteligencia operativa de New Relic a través de MCP, lo que los ayuda a razonar a partir de un contexto operativo más rico con los controles que requieren las empresas.
* [New Relic Lens ya está disponible de forma general](/whats-new/2026/09/whats-new-09-15-nr-lens-ga): Lens le permite conectar y consultar fuentes de datos externas como Snowflake, Iceberg y Google Sheets junto con su telemetría mediante SQL, sin pagar por la ingesta de datos adicional.
