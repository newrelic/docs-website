### Nuevos documentos

* Se agregó [soporte de autenticación Kerberos (SPNEGO) para ubicaciones privadas](/docs/synthetics/synthetic-monitoring/private-locations/synthetics-kerberos-auth-support/), que cubre la configuración del servidor web KDC y SPNEGO y la configuración del administrador de trabajos de Sintéticos.
* Se agregó [Administrar el acceso al control de flota](/docs/new-relic-control/fleet-control/access-management/), que cubre los patrones de acceso basados en roles para el alcance por flota, la separación del ciclo de vida, la administración de grupos delegados y el aislamiento de unidades de negocio.
* Se agregó [Instrumente sus sistemas con Control de agentes](/docs/new-relic-control/agent-control/instrumentation/), que reemplaza la página anterior de Reinstrumentación y cubre la configuración de la instrumentación desde cero o la migración de agentes existentes en Kubernetes, Linux y Windows.
* Se agregó la documentación de [Pathpoint (actualizado)](/docs/pathpoint/get-started-pathpoint/) para la vista previa pública, que cubre flujos, indicadores de estado, KPI y administración de NerdGraph.
* Se agregó la [integración de monitoreo de Google Distributed Cloud Edge](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-distributed-cloud-edge-monitoring-integration/), que cubre los datos que reporta, la activación, la frecuencia de sondeo y la federación de identidades de carga de trabajo.
* Se agregó [RCA de alerta con Autopilot y correo electrónico](/docs/workflow-automation/workflow-examples/integrations/autopilot-email-rca/) para mostrar cómo ejecutar un análisis de causa raíz de Autopilot en una alerta y enviar un informe HTML por correo electrónico, junto con una descripción general de las [plantillas de flujo de trabajo de RCA de Autopilot](/docs/workflow-automation/workflow-examples/integrations/autopilot-rca/).
* Se agregó la acción [Consulta de logs de monitoreo de Azure](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-monitor-querylogs/) al catálogo de acciones de automatización de flujos de trabajo.
* Se agregaron las [acciones de Azure Cosmos DB](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-cosmos-db/) al catálogo de acciones de automatización del flujo de trabajo.
* Se agregaron las [acciones de la API de etiqueta de AWS Resource Groups](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/resourcetagging/aws-resourcetagging/) al catálogo de acciones de automatización de flujos de trabajo.
* Se agregaron [acciones de etiqueta de New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging/) al catálogo de acciones de automatización de flujos de trabajo para agregar, reemplazar y eliminar etiquetas en las entidades de New Relic.

### Cambios importantes

* Se reescribió [Comprender la página de la UI de detalles de la traza](/docs/distributed-tracing/ui-data/trace-details/) para la experiencia actualizada del mapa de entidades.
* Se ampliaron los [Tipos de agente](/docs/new-relic-control/agent-control/agent-types/) con el campo `protocol_version`, una referencia para cada campo de variable y secciones de despliegue separadas para Kubernetes y en el host.
* Se agregaron ejemplos de configuración por agente para los agentes APM de New Relic, el OpenTelemetry Collector, el agente de conexión automática de eBPF y el agente de infraestructura a [Modificar la configuración del agente](/docs/new-relic-control/pipeline-control/gateway/modify-agent-configuration/), junto con una matriz de compatibilidad de agentes y versiones compatibles.
* Se actualizaron el [resumen](/docs/new-relic-control/pipeline-control/gateway/overview/), la [guía de la UI](/docs/new-relic-control/pipeline-control/gateway/ui-guide/) y la [referencia de configuración de YAML](/docs/new-relic-control/pipeline-control/gateway/yaml-overview/) del gateway de Control de pipelines para documentar cómo agregar y eliminar procesadores de Sample rate, Filter y Transform en cualquier etapa de un pipeline.

### Novedades

* [Session Replay ahora tiene su propia categoría de facturación](/whats-new/2026/09/whats-new-09-28-session-replay-billing-category): los datos de Session Replay de Browser y Mobile se reportan en nuevas categorías de facturación, separados de los eventos de Browser y móvil.
* [Una nueva experiencia de mapa de trazas con clústeres inteligentes](/whats-new/2026/09/whats-new-09-28-trace-map-clustering): los mapas de trazas ahora mantienen visibles los servicios de alta importancia y contraen la larga cola en clústeres, para que los cuellos de botella y los servicios que fallan se destaquen.
* [Las flotas basadas en host de New Relic Control ahora están disponibles de forma general](/whats-new/2026/09/whats-new-09-29-host-support-ga): las flotas basadas en host de Linux y Windows para Control de agentes y control de flota ahora están disponibles de forma general, con soporte para la gobernanza de aprobación de configuración, actualizaciones remotas de agentes, logging de auditoría e integraciones en el host.
* [Haga referencia al dashboard actual desde cualquier lugar con `{{selfEntity}}`](/whats-new/2026/09/whats-new-09-29-selfentity-dashboard-variable): una nueva variable de plantilla se resuelve en el GUID de la entidad del dashboard actual, por lo que las consultas, los nombres de los widgets y los enlaces de facetas se mantienen precisos después de duplicar un dashboard.
* [La versión actualizada de Pathpoint ya está disponible en versión preliminar pública](/whats-new/2026/09/whats-new-09-30-pathpoint-2-0): asigne sus recorridos de negocio más críticos a la telemetría que los impulsa, ahora con gestión programática y KPI más completos.
* [Coloque los procesadores de Pipeline donde los necesite con Control de pipelines](/whats-new/2026/09/whats-new-09-30-pipeline-control-processors): agregue, reordene y elimine procesadores de frecuencia de muestreo, filtro y transformación en cualquier punto de un Pipeline.
