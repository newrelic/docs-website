### Nuevos documentos

* Se agregó el [monitoreo de la infraestructura de la nube de Oracle (OCI)](/docs/infrastructure/oci/introduction/) para proporcionar una descripción general del monitoreo de métricas y logs de OCI con New Relic.
* Se agregó [Infraestructura 360](/docs/infrastructure/infrastructure-360/introduction-infrastructure-360/) para ayudarle a descubrir automáticamente su infraestructura de la nube, mapear las relaciones entre los recursos y realizar un seguimiento de los cambios de configuración, lo que incluye la configuración para AWS y Azure, las entidades y los requisitos admitidos, y la resolución de problemas.
* Se agregaron [macros de NRQL](/docs/nrql/nrql-macros/nrql-macros-overview/) para mostrarle cómo guardar una expresión de NRQL como un acceso directo con nombre reutilizable y hacer referencia a ella en las consultas con el símbolo `$`.
* Se agregó [Monitorear el despliegue con el seguimiento de cambios de New Relic para GitHub Copilot](/docs/agentic-ai/autopilot/change-tracking-for-github-copilot/) para mostrarle cómo monitorear cada despliegue y recibir reportes de regresiones en Slack y GitHub.
* Se agregaron [Simbolizar errores de Flutter Dart](/docs/mobile-monitoring/new-relic-mobile-flutter/symbolicate-dart-errors/) y [Simbolizar errores de .NET MAUI C#](/docs/mobile-monitoring/new-relic-mobile-maui-dotnet/symbolicate-csharp-errors/) para explicar cómo generar archivos de símbolos, simbolizar el rastreo del stack y almacenar símbolos para cada lanzamiento.
* Se agregó [LaunchDarkly con el agente de Python](/docs/apm/agents/python-agent/supported-features/launchdarkly-release-observability/) para mostrarle cómo observar de qué manera las marcas de características y los lanzamientos afectan la aplicación al conectar los datos de LaunchDarkly al agente de Python.
* Se agregaron acciones al [catálogo de acciones de automatización de flujos de trabajo](/docs/workflow-automation/setup-and-configure/actions-catalog/actions-catalog/) para [AWS Athena](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/athena/aws-athena/), [AWS DynamoDB](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/dynamodb/aws-dynamodb/), [Azure App Service](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-appservice/), [ejecuciones de flujos de trabajo de GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run/), [secretos de New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/secret/newrelic-secret/) y [New Relic Synthetics](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/synthetics/newrelic-synthetics/), y se agregó una acción de [esperar estado de notificación](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/notification/newrelic-notification-waitforstatus/).
* Se agregó el [Boletín de seguridad NR26-11](/docs/security/new-relic-security/security-bulletins/security-bulletin-nr26-11/) con procedimientos para abordar vulnerabilidades críticas de Node.js, incluida la ejecución remota de código (CVE-2026-111497), que afectan a las ubicaciones públicas y privadas del monitoreo sintético.

### Cambios importantes

* Se actualizó la [referencia de la herramienta MCP](/docs/agentic-ai/mcp/tool-reference/) con una sección de análisis de brechas para la herramienta `analyze_github_newrelic_gaps`, que verifica si falta instrumentación de New Relic en el proyecto.
* Se actualizó [Usar Autopilot con GitHub](/docs/agentic-ai/autopilot/use-autopilot-with-github/) con una nueva sección sobre cómo Autopilot marca los hotfixes abiertos y los pull request abiertos durante una ventana de incidente, y cómo concilia las versiones de lanzamiento.
* Se actualizó [Configurar la propiedad de la entidad](/docs/service-architecture-intelligence/teams/team-ownership/) para la inteligencia de la arquitectura de servicios con la lista de tipos de entidades, por dominio y tipo, que New Relic asigna a los equipos automáticamente a través de la propiedad basada en etiquetas.
* Se actualizó [Tráfico de red](/docs/new-relic-solutions/get-started/networks/) con los dominios del registro de Docker Hub que el Control de agentes en el host utiliza para descargar paquetes del agente desde un registro OCI, y se cambió el dominio del recolector listado a `collector.newrelic.com`.
* Se actualizó [Programar búsquedas NRQL](/docs/nrql/using-nrql/schedule-nrql-searches/) con las capacidades de lectura y modificación de destinos de inteligencia aplicada que necesita para seleccionar o crear un destino de correo electrónico.
* Se actualizaron las páginas de referencia de la [API de Workflow Automation](/docs/workflow-automation/workflow-automation-apis/using-workflow-automation-api/) para flujos de trabajo y programaciones con descripciones coherentes, tablas de parámetros y anclajes de sección.
* Se actualizó [Reenvíe sus logs mediante el agente de infraestructura](/docs/logs/forward-logs/forward-your-logs-using-infrastructure-agent/) con el parámetro `multilineParser`, disponible con el agente de infraestructura v1.53.0 o superior, para combinar entradas multilínea, como los rastreos del stack de Java, en un solo registro de log.
* Se actualizó la [compatibilidad del agente de .NET y los requisitos](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements/) para enumerar las versiones de Windows compatibles actualmente, incluidas Windows Server 2025 y Windows Azure Guest OS Family 5 y superiores.
* Se actualizó la [Compatibilidad y requisitos para el agente Node.js](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent/) con las versiones de paquetes de terceros compatibles más recientes.

### Cambios menores

* Se actualizó la guía de alertas de la [integración de monitoreo de Azure](/docs/infrastructure/microsoft-azure-integrations/azure-integrations-list/azure-monitor/) para usar el método de transmisión del temporizador de eventos en lugar de un desfase de evaluación.
* Se actualizó [Atributos de eventos de alerta](/docs/alerts/create-alert/condition-details/alert-event-attributes/) para explicar que el desplazamiento de evaluación está obsoleto en favor de la configuración de retraso/temporizador.
* Se actualizó la [configuración de la integración de Kafka](/docs/infrastructure/host-integrations/host-integrations-list/kafka/kafka-config/) para explicar que cambiar `CLUSTER_NAME` crea nuevas entidades de broker y topic, y que las aplicaciones de APM permanecen vinculadas a los topics antiguos durante aproximadamente un día.
* Se actualizó [Instrumentar su propia función Lambda](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/instrument-your-own/) para agregar la variable `NEW_RELIC_APP_NAME` requerida a la configuración de ejemplo.
* Se actualizaron las [variables de entorno de la extensión de Lambda](/docs/serverless-function-monitoring/aws-lambda-monitoring/instrument-lambda-function/env-variables-lambda/) con la configuración del presupuesto de reintentos del modo sin servidor y la variable `NEW_RELIC_EXTENSION_SYNCHRONOUS_FLUSH`.
* Se actualizó [Enfoques del agente de Java para Lambda](/docs/apm/agents/java-agent/getting-started/java-agent-approaches-lambda/) para enumerar las variables de entorno que debe configurar.
* Se actualizó [Conectar Autopilot a Slack](/docs/agentic-ai/autopilot/connect-to-slack/) para explicar que Autopilot acepta mensajes de hasta 1000 caracteres.
* Se actualizó [Monitorear la aplicación Flutter](/docs/mobile-monitoring/new-relic-mobile-flutter/monitor-your-flutter-application/) y [Monitorear la aplicación .NET MAUI](/docs/mobile-monitoring/new-relic-mobile-maui-dotnet/monitor-your-net-maui-application/) para explicar que la simbolización en el navegador se aplica solo a las excepciones controladas.
* Se actualizó [Claves de API de New Relic](/docs/apis/intro-apis/new-relic-api-keys/) para cambiar el nombre de “Clave de cuenta predeterminada” a “Clave de cuenta original”.
* Se actualizaron los documentos de [instalación de observabilidad de eBPF](/docs/ebpf/linux-installation/) y [precios y facturación](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/new-relic-one-pricing-billing/) para cambiar el nombre de “eAPM” a “observabilidad de eBPF”.
* Se actualizó el [informe de errores de JavaScript de React Native](/docs/mobile-monitoring/new-relic-monitoring-react-native/react-native-agent-js-error-reporting/) para remitirle al equipo de soporte de New Relic a fin de solicitar un límite mayor de tamaño de source map.

### Novedades

* [Las macros de NRQL ya están disponibles de forma general](/whats-new/2026/10/whats-new-10-26-nrql-macros-ga): guarde una expresión NRQL como un acceso directo reutilizable y con nombre que puede usar en sus consultas y dashboards.
* [La integración de la infraestructura de la nube de Oracle ya está disponible a nivel general](/whats-new/2026/10/whats-new-10-27-oci-ga): monitoree las métricas y los logs de OCI en New Relic junto con AWS, Azure y Google Cloud en una sola plataforma.
