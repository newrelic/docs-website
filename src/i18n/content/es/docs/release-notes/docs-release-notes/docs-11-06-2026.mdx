### Nuevos documentos

* Se agregó [Browser: pestaña para agrupar errores de requests](/docs/triage-inbox/group-request-errors-browser/) para mostrarle cómo agrupar, ordenar y filtrar los requests AJAX y fetch fallidos.
* Se agregó [Comprobación de exposición (vista previa de Security RX)](/docs/vulnerability-management/exposure-check/) para listar las entidades de APM que ejecutan una versión de PHP o Node.js afectada por un aviso de seguridad reciente.
* Se agregó [Identidades del sistema](/docs/accounts/accounts-billing/new-relic-one-user-management/system-identities/) para explicar cómo aprovisionar identidades no humanas que se autentican en New Relic con sus propias credenciales.
* Se agregó la [integración de monitoreo de Google Gemini Enterprise](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-gemini-enterprise-monitoring-integration/), que cubre cómo activar la integración y las métricas de solicitud, latencia, sesión y cuota que recopila para aplicaciones, agentes, herramientas y conectores de datos.
* Se agregaron [acciones de configuración de New Relic Logs](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/log-configurations/newrelic-log-configurations/) al catálogo de acciones de automatización del flujo de trabajo para consultar y actualizar las reglas de análisis de logs, partición y ofuscación.
* Se agregó el [boletín de seguridad NR26-12](/docs/security/new-relic-security/security-bulletins/security-bulletin-nr26-12/) con los pasos para extraer las imágenes de contenedor de ubicación privada de Sintéticos actualizadas después del compromiso de la autoridad de certificación eMudhra.

### Cambios importantes

* Se actualizó [Clasifique la flota de Kubernetes](/docs/kubernetes-pixie/kubernetes-integration/understand-use-data/explore-k8s/), anteriormente la página entre clústeres, con la vista de clasificación de toda la flota que prioriza los problemas en todos los clústeres.
* Se actualizó la [instalación del agente de Ruby](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent/) para simplificar la instalación a tres pasos, y se dividieron los ajustes de la [configuración del agente de Ruby](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration-overview/) en páginas temáticas para que pueda encontrar las opciones por categoría.
* Se eliminó la documentación de CodeStream tras su fin de vida útil el 5 de noviembre de 2026, se reescribieron las páginas de métricas a nivel de código del agente para eliminar las referencias a CodeStream y se agregaron redireccionamientos para que los enlaces existentes sigan funcionando.
* Se actualizó [New Relic Ground Truth](/docs/agentic-ai/mcp/overview/) con una sección sobre cómo asegurar el acceso a MCP, que incluye la revocación de tokens de OAuth y la auditoría de la actividad de inicio de sesión con `NrAuditEvent`.
* Se actualizó [Gestión de acceso para administrar la cardinalidad](/docs/data-apis/ingest-apis/metric-api/cardinality-access-management/) con los permisos que necesita para cambiar los presupuestos de cardinalidad a través de NerdGraph o Terraform.
* Se actualizó [Permisos y roles](/docs/cci/configure-cci/cci-permissions/) para Inteligencia para costos en la nube con los requisitos previos de acceso y una tabla de referencia de permisos.
* Se actualizó [Cargar archivos dSYM](/docs/mobile-monitoring/new-relic-mobile-ios/configuration/upload-dsyms-bitcode-apps/) con la fase de compilación `run-symbol-tool` Run Script, que reemplaza los scripts de carga de Python eliminados en el agente de iOS v7.4.8.
* Se actualizaron las [acciones de AWS Lambda](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/lambda/aws-lambda/) en el catálogo de acciones de automatización de flujos de trabajo con valores de ejemplo concretos para los campos de salida, incluidos mensajes de error de muestra y objetos de respuesta de la API.
* Se actualizó [Administrar tiempos de ejecución de monitores](/docs/synthetics/synthetic-monitoring/using-monitors/manage-monitor-runtimes/) con el tiempo de ejecución de Node.js 22.23.4 y sus módulos de terceros compatibles.

### Cambios menores

* Se actualizó [Browser: pestaña de errores de JavaScript](/docs/triage-inbox/browser-tab/) para renombrar **Errores (Errors Inbox)** a **Errores de JavaScript**.
* Se actualizó [Instalar el agente de Android](/docs/mobile-monitoring/new-relic-mobile-android/install-configure/install-android-agent-gradle/) para recomendar iniciar el agente en el método `onCreate()` de la clase `Application`.
* Se actualizaron [Herramientas de New Relic AI](/docs/agentic-ai/tools/) y las páginas de la UI de monitoreo de móviles con enlaces a las habilidades de Autopilot disponibles para cada área de producto.
* Se actualizó [Reglas y límites de alertas](/docs/alerts/admin/rules-limits-alerts/) para aclarar cómo las condiciones habilitadas y deshabilitadas cuentan para los límites.
* Se actualizaron [Introducción a las alertas compuestas](/docs/alerts/create-alert/create-alert-condition/compound-alerts/compound-alerts/) y [Reglas de silenciamiento](/docs/alerts/get-notified/muting-rules-suppress-notifications/) para explicar que las reglas de silenciamiento ahora se aplican a las alertas compuestas.
* Se actualizó [Enviar datos de New Relic a través de AWS PrivateLink](/docs/data-apis/custom-data/aws-privatelink/) para aclarar que debe seleccionar **PrivateLink Ready partner services** al crear el extremo de la VPC.
* Se agregó el ajuste `safe_dir_check_enabled` a los [ajustes de configuración del agente de infraestructura](/docs/infrastructure/infrastructure-agent/configuration/infrastructure-agent-configuration-settings/). Este ajuste tiene el valor predeterminado `true` en el agente de infraestructura v2.0.1 —un cambio incompatible si dependía del valor predeterminado anterior.
* Se actualizaron [Optimizar los datos de ingesta](/docs/tutorial-optimize-telemetry/data-optimize-techniques/) y [Optimizar la ingesta de datos](/docs/new-relic-solutions/observability-maturity/operational-efficiency/data-governance-optimize-ingest-guide/) para aclarar cómo `enable_process_metrics` y `metrics_process_sample_rate: -1` detienen el muestreo de procesos.
* Se actualizó [Reenvío de logs mediante el agente de infraestructura](/docs/logs/forward-logs/forward-your-logs-using-infrastructure-agent/) para incluir Debian 12 y 13 y Windows Server 2025, y eliminar Debian 11.
* Se actualizaron [Errors Inbox en APM](/docs/apm/errors-inbox/errors-inbox-ui/) y [Servicios externos de Errors Inbox](/docs/triage-inbox/error-external-services/) para explicar que un grupo de errores no resuelto envía una nueva notificación de Slack si el error vuelve a ocurrir después de 14 días.
* Se actualizó la [integración de monitoreo de Azure](/docs/infrastructure/microsoft-azure-integrations/azure-integrations-list/azure-monitor/) para explicar que los tipos de métricas dimensionales dependen de los datos que devuelve Azure, como `summary`, `gauge` o `count`.
* Se actualizó [Primeros pasos con la observabilidad del recolector](/docs/opentelemetry/collector-observability/collector-observability-setup/) para configurar `INTERNAL_TELEMETRY_TRACE_LEVEL=basic` cuando experimente con las trazas del recolector.
* Se actualizó [Identificación del servicio de base de datos con NRDOT](/docs/opentelemetry/db360/capabilities/db-apm/) para requerir el agente de .NET v10.54.0 o superior.
* Se actualizó [Configurar conectores](/docs/new-relic-lens/set-up-connectors/) para reflejar que los nombres de los conectores ahora usan un prefijo de guion bajo (`nrlens_`) en lugar de un guion (`nrlens-`).
* Se actualizó el [Plan de uso](/docs/licenses/license-information/usage-plans/new-relic-usage-plan/) con una sección de Plan Advantage y su tabla de conversión de pago por uso (PAYG).
* Se actualizó [Informar sobre vulnerabilidades de seguridad](/docs/security/security-privacy/information-security/report-security-vulnerabilities/) con una sección sobre informes de vulnerabilidades y el impacto de CVE.
* Se actualizó [Reenviar logs desde Google Cloud Platform](/docs/logs/forward-logs/google-cloud-platform-log-forwarding/) para usar `PubSubToNewRelic` como el nombre correcto de la plantilla de Dataflow.
* Se actualizaron las páginas de compatibilidad y requisitos del [agente Node.js](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent/) y del [agente .NET](/docs/apm/agents/net-agent/getting-started/net-agent-compatibility-requirements/) con las últimas versiones verificadas de la biblioteca.
* Se actualizaron [Compatibilidad y requisitos para el monitoreo de IA](/docs/ai-monitoring/compatibility-requirements-ai-monitoring/) y [Paquetes de Python instrumentados](/docs/apm/agents/python-agent/getting-started/instrumented-python-packages/) con el framework de Microsoft Agent y CrewAI.
* Se actualizó la [integración de monitoreo de Google VertexAI](/docs/infrastructure/google-cloud-platform-integrations/gcp-integrations-list/google-vertexai-monitoring-integration/) para incluir Publisher Model como una entidad de Vertex AI.
