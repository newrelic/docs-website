### Nuevos documentos

* Se agregó [Configurar muestreo](/docs/apm/distributed-tracing/distributed-trace-sampling/), que cubre los contextos de muestreo del agente APM, los tipos de muestreo y los objetivos de muestreo adaptativo.
* Se agregó [Ejemplos de configuración del muestreador](/docs/apm/distributed-tracing/sampler-configuration-examples/), una página complementaria con configuración del mundo real lista para copiar y pegar para solucionar la cobertura desigual del extremo y los desequilibrios del muestreo ascendente.
* Se agregaron [Permisos y roles](/docs/cci/configure-cci/cci-permissions/) para Inteligencia para costos en la nube, que cubren el acceso de solo lectura predeterminado y cómo los administradores de la organización otorgan acceso de modificación a través de roles personalizados existentes o dedicados.

### Cambios importantes

* Se cambió el nombre y se reestructuraron los documentos de monitoreo de base de datos de OpenTelemetry de “Monitoreo de base de datos” a [Base de datos 360 (DB360)](/docs/opentelemetry/db360/introduction/), y se agregaron páginas de métodos de instalación de CLI, Ansible, Chef, Helm y Docker para MSSQL, MySQL, Oracle y PostgreSQL, incluido un nuevo flujo de instalación relacionado con UiPath en las secciones de MSSQL y MySQL.
* Se cambió el nombre de [Errors Inbox](/docs/triage-inbox/errors-inbox/) y sus páginas relacionadas a **Triage inbox**, y se actualizaron las referencias cruzadas a las antiguas rutas de Errors Inbox en la documentación de APM, navegador y móvil.
* Se reestructuraron las páginas del agente de Node.js, incluida la [Introducción a New Relic para Node.js](/docs/apm/agents/nodejs-agent/getting-started/introduction-new-relic-nodejs/), el alojamiento de Heroku y Azure, los mapas de origen, los módulos ES, la instalación, la actualización y la resolución de problemas de Docker, para mayor claridad y coherencia.
* [Búsqueda y generación de informes de NRQL programados](/docs/nrql/using-nrql/schedule-nrql-searches/) ya está disponible de forma general. Se actualizó el documento con detalles de permisos, programación y administración, y se vinculó desde [Usar la UI de Logs](/docs/logs/ui-data/use-logs-ui/).
* [Intelligent Workloads](/docs/new-relic-solutions/new-relic-one/workloads/create-intelligent-workload/) ya está disponible de forma general. Se agregó la creación masiva de carga de trabajo a partir de recomendaciones y filtros de exclusión para delimitar los gráficos de dependencia.
* Se actualizó el contenido de la página de resumen y las capturas de pantalla en [Standard Workloads](/docs/new-relic-solutions/new-relic-one/workloads/use-workloads/), Intelligent Workloads y el documento de Transacción 360, incluida una nueva sección sobre cómo convertir una vista de Transacción 360 en una Carga de trabajo inteligente.
* Se actualizó [Cómo funciona el rastreo distribuido de New Relic](/docs/distributed-tracing/concepts/how-new-relic-distributed-tracing-works/), la guía de planificación de rastreo distribuido para reflejar que el agente móvil (Android v7.8.3+ e iOS v7.7.8+) ahora envía solo encabezados de W3C Trace Context y ya no envía el encabezado propietario legacy `newrelic`.

### Novedades

* [Búsqueda y generación de informes programados ya está disponible de forma general](/whats-new/2026/10/whats-new-10-05-scheduled-search-reporting-ga): ejecute consultas NRQL en su propio horario y reciba notificaciones cuando los resultados cumplan con una condición que defina.
* [Administrar New Relic Notebooks con Terraform](/whats-new/2026/10/whats-new-10-06-notebooks-terraform): defina, administre y aprovisione New Relic Notebooks mediante Terraform, con soporte CRUD completo y acceso programático.
* [Actualizaciones de Intelligent Workloads y Standard Workloads](/whats-new/2026/10/whats-new-10-08-Workloads-GA): las Intelligent Workloads alcanzan la disponibilidad general con creación masiva y filtros de exclusión, y las Standard Workloads obtienen una página de resumen coincidente y compatibilidad con la configuración de estado basada en alertas.
* [La bandeja de entrada de riesgos de rendimiento ya está disponible de forma general](/whats-new/2026/10/whats-new-10-08-performance-risks-inbox): la disponibilidad general de la bandeja de entrada de riesgos de rendimiento agrega una descripción general a nivel de cuenta, soporte de carga de trabajo, información valiosa generada por IA y soporte de servidor MCP de New Relic.
* [La etiqueta de navegación de nivel superior “Errors Inbox” ahora es “Triage Inbox”](/whats-new/2026/10/whats-new-10-08-triage-inbox-nav-label): la entrada de navegación principal de Errors Inbox pasa a llamarse Triage Inbox (Errors Inbox), un cambio solo de etiqueta sin páginas ni características nuevas.

### EOL

* [Aviso de obsolescencia: Kubernetes 1.31 y versiones anteriores](/eol/2026/10/k8s-deprecation-notice-v1.31-and-lower): a partir del 5 de octubre de 2026, la integración de Kubernetes v4.8.0 y versiones posteriores solo es compatible con Kubernetes v1.32 y versiones posteriores.
* [Cambios en las versiones compatibles de Kubernetes](/eol/2026/10/k8s-supported-version-changes): a partir del 19 de octubre de 2026, la integración de Kubernetes admite solo las tres versiones menores más recientes de Kubernetes.
