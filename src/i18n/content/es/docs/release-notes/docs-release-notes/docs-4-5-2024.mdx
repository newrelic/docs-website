<Callout variant="important">
Estamos probando las notas de la versión para informarle qué cambia en nuestra documentación cada semana. Este es un experimento, así que [avísenos a través de un issue de GitHub](https://github.com/newrelic/docs-website/issues/new/choose) si le resultan útiles.
</Callout>

### Nuevos documentos

* Guía práctica sobre cómo usar el [recolector de OpenTelemetry para monitorear las métricas de SingleStore](/docs/more-integrations/open-source-telemetry-integrations/opentelemetry/collector/collector-configuration-examples/opentelemetry-collector-singlestore).

### Cambios importantes

* Los documentos del administrador de trabajos de monitoreo sintético ahora describen cómo configurar [variables definidas por el usuario para monitores con scripts](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-configuration) y qué [versión del administrador de trabajos](/docs/synthetics/synthetic-monitoring/private-locations/job-manager-transition-guide) lo admite.
* Continuamos reescribiendo la documentación de integración en el host para facilitar la instalación y asegurar que la documentación sea precisa y esté actualizada. Esta semana: [Sonarqube](/docs/infrastructure/host-integrations/host-integrations-list/sonarqube-monitoring-integration) y [servicios de Windows](/docs/infrastructure/host-integrations/host-integrations-list/windows-services-integration).
* El rastreo multiaplicación está obsoleto y no será compatible en futuras versiones del agente APM. Actualizamos la documentación para reflejar esto.
* Se eliminaron los documentos relacionados con las métricas acumulativas de OpenTelemetry, que se descontinuaron en 2023.

### Cambios menores

* Enlaces actualizados de la documentación de la API relacionados con la [personalización del monitoreo de IA](/docs/ai-monitoring/customize-agent-ai-monitoring) de Node.js.
* Se aclaró qué [características de Data Plus](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/data-ingest-billing/#data-prices) se aplican a las cuentas Standard, Pro y Enterprise.
* Se aclaró que cuando [actualiza el agente APM de Java](/docs/apm/agents/java-agent/installation/update-java-agent) y usa una de nuestras [API del agente de Java](/docs/apm/agents/java-agent/api-guides/guide-using-java-agent-api), también debe actualizar las dependencias de la API.
* Se actualizó la compatibilidad de la versión del agente APM de Python a 9.8.0 (desde 9.9.0) para monitorear [bibliotecas y frameworks de IA](/docs/apm/agents/python-agent/getting-started/compatibility-requirements-python-agent/#digital-intelligence-platform).
* Enlace actualizado a ServiceNow en las instrucciones de [notificación de destino](/docs/alerts-applied-intelligence/notifications/notification-integrations).
* Nuestro agente de infraestructura ahora recopila todas las [métricas de contenedores de nodos EC2 de la API de Docker](/docs/infrastructure/install-infrastructure-agent/linux-installation/container-instrumentation-infrastructure-monitoring) con la versión V2 de Cgroup durante el monitoreo de un servicio de contenedores de Elastic.
* Información actualizada sobre cómo [encontrar datos de OpenTelemetry `singlestore` ](/docs/more-integrations/open-source-telemetry-integrations/opentelemetry/collector/collector-configuration-examples/opentelemetry-collector-singlestore/#view-data)en la UI.
* Documentación de CodeStream actualizada relacionada con la [búsqueda de logs](/docs/codestream/observability/log-search) y el [monitoreo de rendimiento](/docs/codestream/observability/performance-monitoring).
* Se agregó un enlace a los [atributos de usuario del agente de Java](/docs/triage-inbox/error-users-impacted) admitidos por Errors Inbox.
* Cuando las [condiciones de alerta de NRQL](/docs/alerts-applied-intelligence/new-relic-alerts/alert-conditions/queries-nrql_screenshot-full_nrql-alert-conditions/#condition-tips) agregan datos para ser evaluados, ahora pueden evaluar datos en incrementos de tiempo desde 30 segundos hasta seis horas.
