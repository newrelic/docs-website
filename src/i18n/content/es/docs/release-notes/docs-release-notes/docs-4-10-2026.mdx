### Notas de la versión

* Mantener actualizado con nuestros últimos lanzamientos:

  * [Agente de Java v9.2.0](/docs/release-notes/agent-release-notes/java-release-notes/java-agent-920):

    * Se agregó soporte para Java 26 y el modo de monitoreo sin servidor de AWS Lambda.
    * Se agregó configuración de `log_level_denylist` para el reenvío de logs.
    * Se agregó soporte de nombres automáticos de aplicaciones para logs, muestreadores de trazas y métricas de compatibilidad de entidades.
    * Se agregó instrumentación para OpenTelemetry 1.59.0+ y el cliente HTTP de Reactor Netty.
    * Se corrigió el NPE con la carga de rastreo distribuido y la fuga de memoria en la caché de `ThreadTracker`.

  * [Agente Ruby v10.3.0](/docs/release-notes/agent-release-notes/ruby-release-notes/ruby-agent-10-3-0):

    * Se agregó la asignación de nombres de la consulta de la base de datos mediante comentarios SQL con `/* NewRelicQueryName: CustomName */`.
    * Se agregó instrumentación de Semantic Logger para el reenvío de logs (versiones 4.6.0+).
    * Se agregó la opción de configuración `ignored_middleware_classes`.
    * Se agregó la API `NewRelic::Agent.add_transaction_log_attributes`.
    * Se solucionaron los problemas de cardinalidad de métricas de transmisión de ActionCable y de cumplimiento de FIPS/FedRAMP.
