### Nuevos documentos

* Se agregó [La instrumentación de Kotlin no reporta](/docs/apm/agents/java-agent/troubleshooting/kotlin-instrumentation-not-reporting/) para ayudarle a solucionar la falta de instrumentación de Kotlin mediante la actualización al agente de Java 8.20 o superior y la configuración de la propiedad del sistema `clear_return_stacks`.
* Se agregó la [Guía de migración](/docs/new-relic-control/agent-control/migration-guide/) para el Control de agentes, que cubre la brecha de monitoreo, el mapeo de configuración, la continuidad de la entidad y los pasos de reversión al pasar de un agente de infraestructura independiente al Control de agentes.
* Se agregó [Límites de cálculo de Autopilot](/docs/agentic-ai/autopilot/autopilot-compute-limits/) para mostrarle cómo establecer presupuestos diarios y mensuales de CCU avanzada, aislar la clasificación automatizada de alertas del uso interactivo y rastrear el consumo con NRQL.
* Se agregaron [acciones de AWS SES](/docs/workflow-automation/setup-and-configure/actions-catalog/aws/ses/aws-ses/) al catálogo de acciones de automatización de flujos de trabajo, que cubren la administración de plantillas de correo electrónico y el envío de correos electrónicos a través de Amazon SES.
* Se agregó [Introducción a la observabilidad del recolector](/docs/opentelemetry/collector-observability/collector-observability-setup/), una guía de configuración que cubre notas de facturación y la configuración paso a paso para habilitar la observabilidad del recolector.
* Se agregó la [referencia de KPI de OpenTelemetry Collector](/docs/opentelemetry/collector-observability/collector-observability-kpis/) para explicar cada mosaico de KPI de observabilidad del recolector y sus gráficos de telemetría relacionados.
* Se agregó una nueva guía de resolución de problemas para .NET para consultar cuando [No aparecen datos: la aplicación de .NET framework no usa TLS 1.2](/docs/apm/agents/net-agent/troubleshooting/no-data-appears-net-framework-tls-12/).

### Cambios importantes

* Se actualizó [Eliminar aplicaciones de New Relic](/docs/apm/new-relic-apm/maintenance/remove-applications-new-relic/) con una nueva mutación `agentApplicationDelete` de NerdGraph que permite forzar la eliminación permanente de una aplicación incluso mientras sigue reportando datos.
* Se actualizó la [Integración de monitoreo de Kafka](/docs/infrastructure/host-integrations/host-integrations-list/kafka/kafka-integration/) con métricas de todo el clúster (`KafkaClusterSample`) y nuevas métricas extendidas y opciones de configuración de broker, topic y offset del consumidor.
* Se actualizó la [UI entre clústeres de Kubernetes](/docs/kubernetes-pixie/kubernetes-integration/understand-use-data/kubernetes-cross-cluster/) para incluir secciones de cuadro de mando, tabla y desglose.
* Se actualizó [Instalar el administrador de trabajos de Sintéticos](/docs/synthetics/synthetic-monitoring/private-locations/install-job-manager/) con una tabla de configuración de Podman sin root, un paso de habilitación de persistencia para que los servicios systemd de las cuentas de servicio sigan ejecutándose sin una sesión activa, y `--shm-size=2g` en el comando de creación de pod para evitar que los monitores de navegador fallen debido a los límites de memoria compartida.
* Se actualizaron las [claves de API de New Relic](/docs/apis/intro-apis/new-relic-api-keys/) con una nueva sección “Auditar y administrar las claves de API” que cubre las capacidades y los permisos, se simplificaron los pasos para el reemplazo de claves y se corrigió una descripción invertida del campo `enabled` (`enabled: false` desactiva una clave y `enabled: true` la reactiva).
* Se actualizó el [Tutorial de NerdGraph: administrar claves de API](/docs/apis/nerdgraph/examples/use-nerdgraph-manage-license-keys-user-keys/) con los nuevos campos `owningTeamIds`, `enabled` y `keyUsage` (último uso) para crear, actualizar y consultar claves de API a través de NerdGraph.
* Se actualizó [Resolución de problemas de ubicaciones privadas](/docs/synthetics/synthetic-monitoring/private-locations/troubleshoot-private-locations/) con una nueva sección que explica por qué los monitores de navegador fallan debido a los límites de memoria compartida a nivel de pod de Podman, con comandos de diagnóstico y una solución.
* Se actualizó el [monitoreo de OpenTelemetry Collector](/docs/opentelemetry/collector-observability/collector-observability/) con nuevos modos de vista de recolector independiente frente a adjunto.
* Se actualizó [Compatibilidad y requisitos del agente PHP](/docs/apm/agents/php-agent/getting-started/php-agent-compatibility-requirements/) para eliminar las entradas de Joomla, Drupal 7/9 y Laravel 11 que llegaron al final de su vida útil.
* Se actualizó la versión mínima compatible de iOS de 16 a 15 en [Monitorear la aplicación .NET MAUI](/docs/mobile-monitoring/new-relic-mobile-maui-dotnet/monitor-your-net-maui-application/).
* Se actualizó la [Compatibilidad y requisitos para el agente Node.js](/docs/apm/agents/nodejs-agent/getting-started/compatibility-requirements-nodejs-agent/) con las versiones de paquetes de terceros compatibles más recientes.

### Cambios menores

* Se actualizó la [compatibilidad del agente PHP con Guzzle](/docs/apm/agents/php-agent/frameworks-libraries/guzzle/) para enumerar las versiones compatibles 7-8 y se eliminaron las versiones 5-6 que llegaron al final de su vida útil.
* Se actualizó el nombre de la carpeta XCFramework de iOS a `NewRelic.xcframework` en [Monitorear la aplicación de Unity](/docs/mobile-monitoring/new-relic-mobile-unity/monitor-your-unity-application/).
* Se actualizó el nombre de la variable `distributed_tracing.sampler.remote_parent_not_sampled.trace_id_ratio_based.ratio` en la [configuración del agente Python](/docs/apm/agents/python-agent/configuration/python-agent-configuration/).
* Se actualizó la [guía de instalación de PostgreSQL](/install/postgresql/) para explicar que `nri-postgresql` necesita que se otorgue `USAGE` en `information_schema` en entornos de PostgreSQL reforzados o administrados que revocan los privilegios predeterminados de `PUBLIC`.
* Se actualizaron los pasos de creación de particiones en [Almacenamiento de logs a largo plazo con Live Archives](/docs/logs/get-started/live-archives/) para actualizar la opción desplegable “Send to Live Archives”.
* Se actualizó [Configurar integraciones de monitoreo de Azure](/docs/infrastructure/microsoft-azure-integrations/get-started/activate-azure-integrations/) para explicar que el rol de Lector de monitoreo permite a New Relic sondear recursos mediante la API por lotes de métricas del monitoreo de Azure en lugar de consultar cada recurso individualmente.
* Se actualizaron las [integraciones de notificación de alertas](/docs/alerts/get-notified/notification-integrations/) para explicar que New Relic solo admite la aplicación ServiceNow lista para usar, no sus personalizaciones.
* Se actualizaron los comandos de creación de pods de Podman en [Instalar Sintéticos para stack dual usando Podman](/docs/synthetics/synthetic-monitoring/private-locations/install-synthetics-dual-stack-podman/) y en la [guía de transición del entorno de ejecución de ubicaciones privadas de Sintéticos](/docs/synthetics/synthetic-monitoring/private-locations/runtime-transition-guide/).
