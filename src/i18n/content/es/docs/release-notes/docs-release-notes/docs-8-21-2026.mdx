### Nuevos documentos

* Se agregó el [monitoreo de MySQL a través de OpenTelemetry](/docs/opentelemetry/database/mysql/introduction) como una integración de vista previa pública, que cubre la configuración guiada, la configuración alojada y de Amazon RDS, las configuraciones de múltiples receptores y una referencia completa de métricas.
* Se agregó [monitoreo de PostgreSQL a través de OpenTelemetry](/docs/opentelemetry/database/postgresql/introduction) como una integración de vista previa pública, que cubre la configuración guiada, la configuración alojada y de Amazon RDS, los permisos de `EXPLAIN` y una referencia completa de métricas.
* Se agregaron [capacidades de ubicación privada](/docs/synthetics/synthetic-monitoring/guides/private-location-capabilities) para consolidar las características de ubicación privada del monitoreo sintético, como certificados CA personalizados, mTLS y automatización de Terraform.
* Se agregó [Límites de usuario de calcular](/docs/accounts/accounts-billing/new-relic-one-pricing-billing/compute-budgets/compute-user-limits), ahora disponible de forma general, para establecer presupuestos mensuales de calcular por usuario.
* Se agregaron [recorridos de usuario móvil](/docs/mobile-monitoring/mobile-monitoring-ui/mobile-app-pages/user-journeys) para mostrar la secuencia de eventos que conducen a un bloqueo, error o ANR.
* Se agregó [Configurar el receptor de consulta SQL](/docs/opentelemetry/database/capabilities/sql-query-receiver) como una característica de vista previa pública para ejecutar consultas SQL personalizadas en bases de datos de Oracle o SQL Server e ingestar los resultados como métricas.

### Cambios importantes

* Se actualizaron los [roles personalizados de integraciones de GCP](/docs/infrastructure/google-cloud-platform-integrations/get-started/integrations-custom-roles) con permisos para 18 servicios adicionales, incluidos AlloyDB, Bigtable, Firestore y Vertex AI.
* Se actualizó el [monitoreo de la base de datos de Oracle con NRDOT](/docs/opentelemetry/database/otel-oracledb) con soporte completo para Oracle Autonomous Database (ADB), lo que incluye la instalación, la concesión de privilegios y la configuración de múltiples receptores.

### Cambios menores

* Se corrigieron [Reportar eventos personalizados y atributos](/docs/data-apis/custom-data/custom-events/report-mobile-monitoring-custom-events-attributes) y [Establecer el tamaño máximo del grupo de eventos](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/set-max-event-pool-size) para indicar que el ciclo de recolección de eventos móviles predeterminado es de 60 segundos, no de 600.
* Se aclaró en los [conceptos de administración de usuarios](/docs/accounts/accounts-billing/new-relic-one-user-management/user-management-concepts) que los roles personalizados con alcance de organización no reciben automáticamente permisos para las nuevas características con alcance de organización.
* Se aclaró en [Administrar múltiples registros de usuario](/docs/accounts/accounts-billing/account-setup/multiple-user-records) que para cambiar entre registros de usuario con el mismo correo electrónico se utiliza la opción “Otros usuarios” en el menú de usuario.
* Se aclaró en [Variables de plantilla de dashboard](/docs/query-your-data/explore-query-data/dashboards/dashboard-template-variables) que el botón de alternancia de incluir/excluir se encuentra en el propio desplegable de cada variable, no en la barra de variables compartidas.
* Se aclaró en la [integración de monitoreo de Azure Cost Management](/docs/infrastructure/microsoft-azure-integrations/azure-integrations-list/azure-cost-management-monitoring-integration) que los datos de costos requieren mantener habilitada la integración tradicional de Azure.
* Se eliminó una nota desactualizada en [Compartir notebooks](/docs/query-your-data/explore-query-data/notebooks/share-notebooks) que indicaba que los notebooks carecen de configuraciones de permisos granulares.
* Se agregó cobertura del campo `onCallMembers` al [tutorial de NerdGraph Teams](/docs/apis/nerdgraph/examples/nerdgraph-teams-tutorial).
* Se agregaron pasos a [Solucionar problemas de integraciones de GCP](/docs/infrastructure/google-cloud-platform-integrations/troubleshooting/troubleshooting-gcp-integrations) para solicitar un aumento de cuota de la API de monitoreo de la nube de GCP.
* Se agregó una guía para asignar un rol On-call a los miembros del equipo en [Administrar equipos](/docs/service-architecture-intelligence/teams/manage-teams).
* Se agregó una sección sobre la configuración de [variables de entorno del agente de .NET](/docs/apm/agents/net-agent/other-installation/understanding-net-agent-environment-variables) para aplicaciones alojadas en IIS a través de `ApplicationHost.config`.
* Se reestructuró [La instalación de Windows MSI falla con el error 1603](/docs/infrastructure/infrastructure-troubleshooting/troubleshoot-infrastructure/windows-msi-install-fails-error-1603) para priorizar la falta de los parámetros obligatorios `GENERATE_CONFIG` y `LICENSE_KEY` como la causa más común.
* Se actualizó el [instalador de Windows MSI](/docs/infrastructure/infrastructure-agent/windows-installation/windows-msi-installer) para que el comando de instalación silenciosa predeterminado incluya los parámetros `GENERATE_CONFIG` y `LICENSE_KEY` requeridos.
