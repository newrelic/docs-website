Puede usar mutaciones de [NerdGraph](/docs/apis/nerdgraph/get-started/introduction-new-relic-nerdgraph/) para administrar [reglas de normalización de métricas](/docs/new-relic-solutions/new-relic-one/ui-data/metric-normalization-rules) en New Relic. Al aprovechar estas mutaciones, puede crear, editar, activar y desactivar estas reglas directamente desde la cuenta de New Relic. Esto proporciona un enfoque simplificado y programático para resolver los [problemas de agrupación de métricas (MGI).](/docs/new-relic-solutions/solve-common-issues/troubleshooting/metric-grouping-issues)

Las reglas de normalización de métricas se utilizan para:

* Agrupe o filtre los [datos de intervalo de tiempo de métrica](/docs/data-apis/understand-data/new-relic-data-types/#timeslice-data).
* Administre las métricas de alta cardinalidad al cambiar su nombre, eliminarlas o transformarlas antes de que se ingieran en New Relic.
* Prevenir los [MGI](/docs/new-relic-solutions/solve-common-issues/troubleshooting/metric-grouping-issues) para garantizar que las métricas estén bien organizadas y sean significativas.
* Reducir el número de nombres de métricas únicos reportados a New Relic.

## Requisitos previos [#prerequisites]

* Una [cuenta de New Relic](https://newrelic.com/signup), y con esa cuenta, puede acceder a la clave de usuario de la API que necesita incluir en las [consultas y mutaciones](/docs/apis/nerdgraph/get-started/introduction-new-relic-nerdgraph).

* El tipo de usuario y los roles asignados pueden afectar sus permisos de NerdGraph. Para obtener más detalles, consulte [Factores que afectan el acceso](/docs/accounts/accounts-billing/account-structure/factors-affecting-access-features-data#user-permissions).

<Callout variant="tip">
También puede crear una regla de normalización de métricas usando la plataforma de New Relic. Para obtener más información, consulte [Reglas de normalización de métricas](/docs/new-relic-solutions/new-relic-one/ui-data/metric-normalization-rules).
</Callout>

## Recuperar las reglas de normalización de métricas [#nerdgraph-query]

Utilice la consulta `metricNormalizationRules` para obtener todas las reglas de normalización de métricas asociadas a la cuenta. Esta consulta proporciona una visión general completa de las reglas existentes, incluyendo su estado y configuración.

## Mutaciones [#nerdgraph-mutations]

Administre las reglas de normalización de métricas con las siguientes [mutaciones de NerdGraph](https://docs.newrelic.com/docs/apis/nerdgraph/get-started/introduction-new-relic-nerdgraph/#terminology):

<CollapserGroup>
<Collapser id="create-metric-normalization-rule" title="Crear una regla de normalización de métricas">
Use la mutación `metricNormalizationCreateRule` para crear una nueva regla de normalización de métricas en New Relic.

### parámetro de entrada

<table>
<thead>
<tr>
<th>
Nombre del atributo
</th>

<th>
Tipo de datos
</th>

<th>
Descripción
</th>
</tr>
</thead>

<tbody>
<tr>
<td>
ID de la cuenta
</td>

<td>
Cadena
</td>

<td>
(Obligatorio) El ID de la cuenta asociado a la regla.
</td>
</tr>

<tr>
<td>
acción
</td>

<td>
Cadena
</td>

<td>
(Obligatorio) Seleccione una de las siguientes acciones:

* `REPLACE`: Reemplace las métricas que coinciden con el `matchExpression` con el valor definido en el campo `replacement`.
* `IGNORE`: bloquee el reporte a New Relic de cualquier métrica que coincida con `matchExpression`.
* `DENY_NEW_METRICS`: evite la creación de nuevos nombres de métricas que coincidan con `matchExpression`, mientras permite que los nombres de métricas existentes sigan reportando.
</td>
</tr>

<tr>
<td>
applicationGuid
</td>

<td>
Cadena
</td>

<td>
(Opcional) El GUID único para la aplicación en New Relic. Si se deja en blanco, se convierte en una regla para toda la cuenta.
</td>
</tr>

<tr>
<td>
activado
</td>

<td>
Booleano
</td>

<td>
(Obligatorio) Para habilitar la regla, defínala como `true`.
</td>
</tr>

<tr>
<td>
evalOrder
</td>

<td>
Entero
</td>

<td>
(Obligatorio) Especifique el orden en el que se aplica la regla en relación con otras reglas. Cuanto menor sea el número, mayor será la prioridad evaluada. El valor recomendado es `2000`.
</td>
</tr>

<tr>
<td>
matchExpression
</td>

<td>
Cadena
</td>

<td>
(Obligatorio) Acepta un patrón de [expresión regular](https://regexone.com/) que coincida con las métricas a normalizar. Este campo debe comenzar con un `^` y terminar con un `$`. Define un patrón para identificar qué métricas deben ser afectadas por la regla de normalización. Por ejemplo: `^WebTransaction/Uri/RESTfulExample/users/username/[a-zA-Z0-9]+$` El patrón `^[a-zA-Z0-9]+$` coincide con cualquier cadena compuesta por caracteres en minúscula `(a-z)`, caracteres en mayúscula `(A-Z)` y números `(0-9)`.
</td>
</tr>

<tr>
<td>
notas
</td>

<td>
Cadena
</td>

<td>
Notas adicionales o comentarios sobre la regla de normalización.
</td>
</tr>

<tr>
<td>
reemplazo
</td>

<td>
Cadena
</td>

<td>
Este campo solo es obligatorio cuando se selecciona la opción `REPLACE` de la lista desplegable `action`. Reemplaza cualquier nombre de métrica que coincida con `matchExpression`. Por ejemplo: `WebTransaction/Uri/RESTfulExample/users/username/{username}$`
</td>
</tr>

<tr>
<td>
terminateChain
</td>

<td>
Booleano
</td>

<td>
(Obligatorio) Si se establece en `true`, no se aplicarán más reglas a las métricas coincidentes.
</td>
</tr>
</tbody>
</table>

### Consulta de muestra

```graphql

    mutation {
        metricNormalizationCreateRule(
            accountId: xxxxxx
            rule: {action: REPLACE, applicationGuid: "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxx", enabled: false, evalOrder: 2000, matchExpression: "^WebTransaction/Uri/MGIGenerator_war_exploded/api/MGI/pattern/[a-f0-9]+$", notes: "rules to replace", replacement: "WebTransaction/Uri/MGIGenerator_war_exploded/api/MGI/pattern/{guid}", terminateChain: true}
        ) {
            errors {
                message
                type
            }
            rule {
                action
                applicationGuid
                applicationName
                createdAt
                enabled
                evalOrder
                id
                matchExpression
                notes
                replacement
                terminateChain
            }
        }
    }

```
