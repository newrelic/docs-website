Puede exportar los dashboard y los gráficos individuales como archivos PDF o PNG mediante programación usando las mutaciones `dashboardCreateSnapshotUrl` y `dashboardWidgetCreateSnapshotUrl` de NerdGraph. La API admite opciones que no están disponibles en la UI, como las sobrescrituras de variables de plantilla y los filtros de entidad. También puede [exportar dashboard mediante la UI](/docs/query-your-data/explore-query-data/dashboards/dashboards-charts-import-export-data/#export-dashboards-pdf).

## Exportar un dashboard como PDF o PNG [#api-dashboard-snapshot]

La mutación `dashboardCreateSnapshotUrl` genera una URL de instantánea para una página completa del dashboard.

<Callout variant="tip">
El parámetro `guid` requiere el GUID de la **página**, no el GUID del dashboard. Un dashboard puede tener varias páginas. Para encontrar los GUID de la página, use la consulta `entitySearch` o abra la página del dashboard y seleccione <DNT>**Manage JSON**</DNT> en el menú <DNT>**...**</DNT>.

```graphql
{
  actor {
    entitySearch(query: "parentId ='YOUR_DASHBOARD_GUID' AND tags.isDashboardPage = 'true'") {
      results {
        entities {
          guid
          name
        }
      }
    }
  }
}
```
</Callout>

**Esquema de mutación:**

```graphql
mutation {
  dashboardCreateSnapshotUrl(
    guid: EntityGuid!
    params: SnapshotUrlInput
  ): String
}

input SnapshotUrlInput {
  timeWindow: SnapshotUrlTimeWindowInput
  display: SnapshotUrlDisplayInput
  variables: [SnapshotUrlVariableInput!]
  filter: String
  format: SnapshotUrlFormat
}

input SnapshotUrlTimeWindowInput {
  beginTime: EpochMilliseconds
  endTime: EpochMilliseconds
  duration: Milliseconds
}

input SnapshotUrlDisplayInput {
  width: Int
  height: Int
}

input SnapshotUrlVariableInput {
  name: String!
  values: [String!]!
}

enum SnapshotUrlFormat {
  PDF
  PNG
}
```

```graphql

  dashboardCreateSnapshotUrl(
    guid: "YOUR_DASHBOARD_PAGE_GUID"
    params: {
      format: PNG
      display: {
        width: 1920
        height: 1080
      }
    }
  )
}
```

<Collapser id="variables-filter" title="Exportar con anulaciones de variables y un filtro">
Utilice esto para fijar valores de variables y filtros específicos en el snapshot, útil para la automatización de informes programados.

```graphql
mutation {
  dashboardCreateSnapshotUrl(
    guid: "YOUR_DASHBOARD_PAGE_GUID"
    params: {
      variables: [
        { name: "environment", values: ["production"] }
        { name: "region", values: ["us-east-1", "eu-west-1"] }
      ]
      filter: "env = 'production' AND service = 'checkout'"
    }
  )
}
```
</Collapser>
</CollapserGroup>

<Callout variant="important">
Las URL de las instantáneas son de acceso público sin autenticación y caducan después de 3 meses. Compártalas con cuidado de acuerdo con las políticas de datos de su organización.
</Callout>

## Exportar un gráfico como imagen [#api-widget-snapshot]

La mutación `dashboardWidgetCreateSnapshotUrl` genera una URL de una instantánea en PDF o PNG de un solo widget de gráfico. El widget no necesita existir en un dashboard —puede definirlo en línea, lo que resulta útil para generar instantáneas de gráficos de forma programática.

**Esquema de mutación:**

```graphql
mutation {
  dashboardWidgetCreateSnapshotUrl(
    widget: DeclarativeUiWidget!
    params: DashboardWidgetSnapshotUrlInput
  ): WidgetSnapshotResult
}

type WidgetSnapshotResult {
  url: String!
}
```

El argumento `params` es opcional. Úselo para cambiar el formato de salida o el tamaño de la instantánea.

El parámetro `widget` acepta un `DeclarativeUiWidget` — un objeto JSON con tres capas anidadas:

```
declarative/widget envelope
└── widget node        ← title and widget-level props
    └── visualization  ← visualization type and configuration
```

```json
{
  "type": "declarative/widget",
  "version": 1,
  "content": {
    "type": "widget",
    "props": {
      "title": "My Chart Title"
    },
    "content": {
      "type": "visualization",
      "id": "viz.line",
      "props": {
        // visualization-specific config (nrqlQueries, colors, thresholds, etc.)
      }
    }
  }
}
```

**Ejemplos:**

<CollapserGroup>
<Collapser id="line-chart-snapshot" title="Exportar un gráfico de líneas">
```graphql
mutation {
  dashboardWidgetCreateSnapshotUrl(
    widget: {
      version: 1
      type: "declarative/widget"
      content: {
        type: "widget"
        props: { title: "Throughput by environment" }
        content: {
          type: "visualization"
          id: "viz.line"
          props: {
            nrqlQueries: [
              {
                accountIds: [YOUR_ACCOUNT_ID]
                query: "SELECT count(*) FROM Transaction TIMESERIES"
              }
            ]
            legend: { enabled: true }
          }
        }
      }
    }
  ) {
    url
  }
}
```
</Collapser>

<Collapser id="billboard-snapshot" title="Exportar un gráfico de cartelera con umbral">
```graphql
mutation {
  dashboardWidgetCreateSnapshotUrl(
    widget: {
      version: 1
      type: "declarative/widget"
      content: {
        type: "widget"
        props: { title: "Error rate" }
        content: {
          type: "visualization"
          id: "viz.billboard"
          props: {
            nrqlQueries: [
              {
                accountIds: [YOUR_ACCOUNT_ID]
                query: "SELECT percentage(count(*), WHERE error IS true) AS 'Error rate' FROM Transaction SINCE 1 hour ago"
              }
            ]
            thresholds: [
              { alertSeverity: "WARNING", value: 1 }
              { alertSeverity: "CRITICAL", value: 5 }
            ]
          }
        }
      }
    }
  ) {
    url
  }
}
```
</Collapser>
</CollapserGroup>

<Callout variant="tip">
El campo `actor.account.nrql.staticChartUrl` legacy en NerdGraph sigue estando disponible, pero no admite las últimas características de visualización, como umbrales, formato de color y tipos de gráficos más nuevos. `dashboardWidgetCreateSnapshotUrl` es el enfoque recomendado de ahora en adelante.
</Callout>

<Callout variant="important">
`dashboardWidgetCreateSnapshotUrl` las URL de las instantáneas son de acceso público sin autenticación y caducan después de 3 meses.
</Callout>

## Resolución de problemas [#troubleshooting]

Esto es lo que debe hacer si experimenta alguno de los siguientes errores al intentar exportar un dashboard:

* Desde UI de New Relic: <DNT>**We ran into an error while creating the PDF. Please try again**</DNT>

* De New Relic NerdGraph: <DNT>**Operation on dashboard entity failed with guid:YOUR\_GUID with cause: Error 504: upstream request timeout**</DNT>

Estos errores pueden ocurrir si la exportación excede el tiempo de respuesta máximo de la API. Compruebe si algún widget en su dashboard utiliza un periodo de tiempo amplio —por ejemplo, comparando datos de todo un mes. Si es así, intente reducir el periodo de tiempo.

Otra posible causa es un dashboard con una gran cantidad de widgets. Intente eliminar los widgets no utilizados para ver si esto resuelve el error.
