<DNT>Autopilot</DNT> La memoria permite a <DNT>Autopilot</DNT> retener el contexto en las conversaciones y controlar quién puede leer, crear, actualizar o eliminar ese contexto almacenado.

## Acceso a memoria predeterminado [#default-access]

New Relic proporciona acceso predeterminado a la memoria a través de estos roles estándar:

### Acceso con alcance de cuenta

<table>
  <thead>
    <tr>
      <th>
        Acción
      </th>

      <th>
        Rol requerido
      </th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>
        Leer memoria
      </td>

      <td>
        Solo lectura, usuario estándar o usuario completo (cualquier nivel de usuario)
      </td>
    </tr>

    <tr>
      <td>
        Crear o modificar memoria
      </td>

      <td>
        Administrador de todos los productos
      </td>
    </tr>

    <tr>
      <td>
        Eliminar memoria
      </td>

      <td>
        Administrador de todos los productos
      </td>
    </tr>
  </tbody>
</table>

### Acceso con alcance de organización

<table>
  <thead>
    <tr>
      <th>
        Acción
      </th>

      <th>
        Rol requerido
      </th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>
        Leer la memoria en toda la organización
      </td>

      <td>
        Solo lectura de la organización, Administrador de la organización o Administrador de productos de la organización
      </td>
    </tr>

    <tr>
      <td>
        Crear o modificar la memoria en toda la organización
      </td>

      <td>
        Administrador de la organización
      </td>
    </tr>

    <tr>
      <td>
        Eliminar memoria en toda la organización
      </td>

      <td>
        Administrador de la organización
      </td>
    </tr>
  </tbody>
</table>

Es posible que necesite un rol personalizado si los permisos predeterminados no satisfacen las necesidades de su organización.

## Requisitos previos [#prerequisites]

* [Requisitos generales de NerdGraph](/docs/apis/nerdgraph/get-started/introduction-new-relic-nerdgraph/#authentication)
* Rol de administrador de la organización, para crear roles personalizados

<Callout variant="tip">
  También puede [crear un rol personalizado para la memoria a través de la UI](/docs/accounts/accounts-billing/new-relic-one-user-management/account-user-mgmt-tutorial/#roles). </Callout>

## Crear un rol personalizado mediante la API de NerdGraph [#create-role]

Cada una de las siguientes llamadas API maneja una parte de la creación y asignación de un rol personalizado para la memoria. Expanda cada una para ver sus parámetros de entrada y la solicitud y respuesta de muestra.

<CollapserGroup>
  <Collapser id="find-permission-ids" title="Buscar los ID de permisos necesarios para la memoria">
    Use la consulta `customerAdministration` para recuperar una lista de capacidades, sus ID de permisos e información relacionada. Filtre por característica para obtener los permisos de la memoria.

    **parámetro de entrada**

    <table>
      <thead>
        <tr>
          <th>
            Parámetro
          </th>

          <th>
            Tipo de datos
          </th>

          <th>
            Descripción
          </th>
        </tr>
      </thead>

      <tbody>
        <tr>
          <td>
            `eq`

             (Requerido)
          </td>

          <td>
            Cadena
          </td>

          <td>
            Establezca el valor en 

            `Memory`

             (con alcance de cuenta) o 

            `Memory For Organization`

             (con alcance de organización) para recuperar los permisos coincidentes.
          </td>
        </tr>
      </tbody>
    </table>

    **Ejemplo de solicitud — a nivel de cuenta**

    ```graphql
    {
      customerAdministration {
        permissions(filter: { feature: { eq: "Memory" } }) {
          items {
            feature
            category
            id
            product
          }
        }
      }
    }
    ```

    **Ejemplo de respuesta**

    ```json
    {
      "data": {
        "customerAdministration": {
          "permissions": {
            "items": [
              {
                "category": "READ",
                "feature": "Memory",
                "id": "xxxxx",
                "product": "New Relic AI"
              },
              {
                "category": "MODIFY",
                "feature": "Memory",
                "id": "xxxxxx",
                "product": "New Relic AI"
              },
              {
                "category": "DELETE",
                "feature": "Memory",
                "id": "xxxxxx",
                "product": "New Relic AI"
              }
            ]
          }
        }
      }
    }
    ```

    Ejecuta la misma consulta con `feature: { eq: "Memory For Organization" }` para recuperar los ID de permisos a nivel de organización (READ, MODIFY, DELETE para memoria por organización).

    De la respuesta, copia los ID de permiso donde `feature` sea `Memory` o `Memory For Organization`, que coincidan con el nivel de acceso que deseas otorgar. Necesitarás estos ID para crear el rol personalizado.
  </Collapser>

  <Collapser id="retrieve-organization-id" title="Recuperar el ID de su organización">
    Recupera el ID de tu organización, que usarás en mutaciones posteriores. Para un rol con alcance de cuenta, recupera también el ID de la cuenta.

    **Solicitud de muestra**

    ```graphql
    {
      actor {
        organization {
          id
        }
        accounts {
          id
          name
        }
      }
    }
    ```

    **Ejemplo de respuesta**

    ```json
    {
      "data": {
        "actor": {
          "organization": {
            "id": "YOUR_ORGANIZATION_ID"
          },
          "accounts": [
            {
              "id": "YOUR_ACCOUNT_ID",
              "name": "Your Account Name"
            }
          ]
        }
      }
    }
    ```

    Copie los ID que necesita de la respuesta. Los usará para crear el rol personalizado.
  </Collapser>

  <Collapser id="create-custom-role" title="Crear el rol personalizado">
    Use la mutación `customRoleCreate` para crear su rol personalizado para la gestión de la memoria.

    **parámetro de entrada**

    <table>
      <thead>
        <tr>
          <th>
            Parámetro
          </th>

          <th>
            Tipo de datos
          </th>

          <th>
            Descripción
          </th>
        </tr>
      </thead>

      <tbody>
        <tr>
          <td>
            `id`

             (Requerido)
          </td>

          <td>
            Cadena
          </td>

          <td>
            El ID de la organización (ámbito de organización) o el ID de la cuenta (ámbito de cuenta) de la llamada anterior.
          </td>
        </tr>

        <tr>
          <td>
            `type`

             (Requerido)
          </td>

          <td>
            Cadena
          </td>

          <td>
            Establézcalo en 

            `organization`

             para un rol con alcance de organización o en 

            `account`

             para un rol con alcance de cuenta.
          </td>
        </tr>

        <tr>
          <td>
            `name`

             (Requerido)
          </td>

          <td>
            Cadena
          </td>

          <td>
            El nombre para mostrar del rol personalizado.
          </td>
        </tr>

        <tr>
          <td>
            `permissionIds`

             (Requerido)
          </td>

          <td>
            Matriz de números enteros
          </td>

          <td>
            Los ID de permisos de la memoria identificados anteriormente.
          </td>
        </tr>

        <tr>
          <td>
            `scope`

             (Requerido)
          </td>

          <td>
            Cadena
          </td>

          <td>
            Establezca en 

            `organization`

             o 

            `account`

            , que coincida con 

            `type`

            .
          </td>
        </tr>
      </tbody>
    </table>

    **Ejemplo de solicitud — rol con alcance de cuenta**

    ```graphql
    mutation {
      customRoleCreate(
        container: { id: "YOUR_ACCOUNT_ID", type: "account" }
        name: "Memory manager"
        permissionIds: [xxxxx, xxxxx]
        scope: "account"
      ) {
        id
      }
    }
    ```

    **Ejemplo de solicitud — rol con alcance de organización**

    ```graphql
    mutation {
      customRoleCreate(
        container: { id: "YOUR_ORGANIZATION_ID", type: "organization" }
        name: "Memory manager (org-wide)"
        permissionIds: [xxxxx, xxxxx]
        scope: "organization"
      ) {
        id
      }
    }
    ```

    **Ejemplo de respuesta**

    ```json
    {
      "data": {
        "customRoleCreate": {
          "id": 9999999
        }
      }
    }
    ```

    Guarde el ID de rol devuelto —lo necesitará para asignar este rol a un grupo de usuarios.
  </Collapser>

  <Collapser id="add-role-to-group" title="Agregar el rol personalizado a un grupo de usuarios">
    Después de crear el rol personalizado, asígnelo a un grupo de usuarios.

    **Recuperar los ID de grupos**

    Emplee la consulta `customerAdministration` para obtener una lista de grupos de usuarios disponibles.

    **parámetro de entrada**

    <table>
      <thead>
        <tr>
          <th>
            Parámetro
          </th>

          <th>
            Tipo de datos
          </th>

          <th>
            Descripción
          </th>
        </tr>
      </thead>

      <tbody>
        <tr>
          <td>
            `id`

             (Requerido)
          </td>

          <td>
            Cadena
          </td>

          <td>
            ID de su organización.
          </td>
        </tr>
      </tbody>
    </table>

    **Solicitud de muestra**

    ```graphql
    {
      customerAdministration {
        groups(filter: { organizationId: { eq: "YOUR_ORGANIZATION_ID" } }) {
          nextCursor
          items {
            id
            name
            users {
              items {
                id
                email
              }
            }
          }
        }
      }
    }
    ```

    De la respuesta, copie el ID de grupo para el grupo al que desea asignar el rol de memoria.

    **Asigna el rol al grupo**

    Emplee la mutación `authorizationManagementGrantAccess` para asignar el rol personalizado a un grupo de usuarios.

    **parámetro de entrada**

    <table>
      <thead>
        <tr>
          <th>
            Parámetro
          </th>

          <th>
            Tipo de datos
          </th>

          <th>
            Descripción
          </th>
        </tr>
      </thead>

      <tbody>
        <tr>
          <td>
            `roleId`

             (Requerido)
          </td>

          <td>
            Cadena
          </td>

          <td>
            El ID del rol personalizado de la llamada anterior.
          </td>
        </tr>

        <tr>
          <td>
            `groupId`

             (Requerido)
          </td>

          <td>
            Cadena
          </td>

          <td>
            El ID de grupo obtenido anteriormente.
          </td>
        </tr>
      </tbody>
    </table>

    **Ejemplo de solicitud — rol con alcance de cuenta**

    ```graphql
    mutation {
      authorizationManagementGrantAccess(
        grantAccessOptions: {
          accountAccessGrants: { accountId: "YOUR_ACCOUNT_ID", roleId: "YOUR_ROLE_ID" }
        }
        groupId: "YOUR_GROUP_ID"
      ) {
        roles {
          id
          name
          accountId
          roleId
          groupId
          displayName
        }
      }
    }
    ```

    **Ejemplo de solicitud — rol con alcance de organización**

    ```graphql
    mutation {
      authorizationManagementGrantAccess(
        grantAccessOptions: {
          organizationAccessGrants: { roleId: "YOUR_ROLE_ID" }
        }
        groupId: "YOUR_GROUP_ID"
      ) {
        roles {
          id
          name
          organizationId
          roleId
          groupId
          displayName
        }
      }
    }
    ```

    **Ejemplo de respuesta**

    ```json
    {
      "data": {
        "authorizationManagementGrantAccess": {
          "roles": [
            {
              "displayName": "Memory manager",
              "groupId": null,
              "id": "99999999",
              "name": "memory_manager",
              "organizationId": "YOUR_ORGANIZATION_ID",
              "roleId": 99999
            }
          ]
        }
      }
    }
    ```
  </Collapser>
</CollapserGroup>
