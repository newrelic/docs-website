  La API REST para etiquetas ha llegado al final de su vida útil a partir del 30 de junio de 2022 (extendido desde el 31 de marzo de 2022). Para obtener más información, consulte nuestra documentación sobre [etiquetas](/docs/new-relic-one/use-new-relic-one/core-concepts/tagging-use-tags-organize-group-what-you-monitor) y nuestra [publicación en el foro de soporte](https://support.newrelic.com/s/hubtopic/aAX8W0000008cts/important-upcoming-changes-to-capabilities-and-support-across-errors-classic) sobre el fin de vida útil.

## Listar etiquetas existentes [#list\_labels][#list_labels]

Para enumerar las etiquetas que existen en su cuenta, use este comando:

```sh
curl 'https://api.newrelic.com/v2/labels.json' \
     -H "Api-Key:NEW_RELIC_USER_KEY" -i
```

### Ver el resultado [#list\_label\_output][#list_label_output]

La salida de la etiqueta incluye:

* El nombre de clave completo de la etiqueta (por ejemplo, `Staging:Test1`), así como el componente y el nombre de la clave.
* La aplicación `health_status` (rojo, naranja, verde, gris) y el ID de la aplicación para la etiqueta en cada categoría
* Aplicaciones que tienen esta etiqueta; por ejemplo, la etiqueta `Staging:Test1` se ha aplicado a una aplicación (4937390) y dos hosts (3801143 y 5879721).
