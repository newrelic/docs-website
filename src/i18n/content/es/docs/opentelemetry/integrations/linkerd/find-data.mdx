Después de configurar OpenTelemetry Collector para Linkerd, la telemetría de la malla fluye hacia New Relic como eventos `Metric`, `Span` y `Log` en el ámbito de la entidad de Linkerd.

## Encuentre la entidad de Linkerd [#find-entity]

1. Ingresa a [one.newrelic.com](https://one.newrelic.com) y selecciona **Entity Explorer**.
2. Busque el nombre del clúster.
3. Seleccione la entidad de Linkerd para abrir el dashboard integrado.

El dashboard integrado cubre la tasa de solicitudes, la latencia p50/p95/p99, la tasa de éxito, las conexiones TCP, el estado del certificado mTLS, el estado del plano de control y el inventario de pods en malla.

### Linkerd dashboard [#dashboard]

El dashboard de la entidad de Linkerd proporciona una descripción general de la telemetría de la malla de servicios. Incluye:

| Sección          | Paneles                                                                     |
| ---------------- | --------------------------------------------------------------------------- |
| Top-line         | Conexiones TCP, solicitudes servidas por proxies                            |
| Traffic          | Tasa entrante, tasa saliente                                                |
| Salud            | Tasa de éxito, tasa de errores, códigos de estado HTTP                      |
| latencia         | Latencia de solicitudes p50/p95/p99, latencia de salida p99                 |
| Seguridad        | Vencimiento del certificado mTLS, tasa de actualización del certificado     |
| Plano de control | Política de autorización, profundidad de la cola, tasa de solicitudes de CP |
| Topología        | Uso de memoria del proxy, operaciones por servicio                          |
| Inventario       | Pods en la malla                                                            |

## Ejemplo de consulta NRQL [#queries]

Reemplace `<YOUR_CLUSTER>` con el nombre de su clúster en cada consulta.

<table>
  <thead>
    <tr>
      <th>
        Objetivo
      </th>

      <th>
        Consulta NRQL
      </th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>
        Tasa de solicitudes por servicio
      </td>

      <td>
        ```sql
        SELECT rate(sum(request_total), 1 minute) AS 'Req/min' FROM Metric WHERE k8s.cluster.name = '<YOUR_CLUSTER>' AND linkerd_control_plane_component IS NULL FACET k8s.deployment.name SINCE 30 minutes ago TIMESERIES
        ```
      </td>
    </tr>

    <tr>
      <td>
        Latencia p99 por servicio
      </td>

      <td>
        ```sql
        SELECT histogram(response_latency_ms, width: 50, slide_by: 10) FROM Metric WHERE k8s.cluster.name = '<YOUR_CLUSTER>' AND linkerd_control_plane_component IS NULL FACET k8s.deployment.name SINCE 30 minutes ago
        ```
      </td>
    </tr>

    <tr>
      <td>
        Tasa de éxito de HTTP
      </td>

      <td>
        ```sql
        SELECT sum(response_total) AS 'Total responses', filter(sum(response_total), WHERE classification = 'success') / sum(response_total) * 100 AS 'Success %' FROM Metric WHERE k8s.cluster.name = '<YOUR_CLUSTER>' FACET k8s.deployment.name SINCE 30 minutes ago
        ```
      </td>
    </tr>

    <tr>
      <td>
        Vencimiento del certificado mTLS
      </td>

      <td>
        ```sql
        SELECT latest(identity_cert_expiration_timestamp_seconds) AS 'Cert expires (epoch)' FROM Metric WHERE k8s.cluster.name = '<YOUR_CLUSTER>' FACET k8s.deployment.name SINCE 10 minutes ago
        ```
      </td>
    </tr>

    <tr>
      <td>
        Profundidad de cola del plano de control
      </td>

      <td>
        ```sql
        SELECT latest(control_plane_queue_length) AS 'Queue depth' FROM Metric WHERE k8s.cluster.name = '<YOUR_CLUSTER>' AND linkerd_control_plane_component IS NOT NULL FACET linkerd_control_plane_component SINCE 10 minutes ago
        ```
      </td>
    </tr>

    <tr>
      <td>
        Conexiones TCP abiertas
      </td>

      <td>
        ```sql
        SELECT rate(sum(tcp_open_connections), 1 second) AS 'TCP connections' FROM Metric WHERE k8s.cluster.name = '<YOUR_CLUSTER>' FACET k8s.deployment.name SINCE 30 minutes ago TIMESERIES
        ```
      </td>
    </tr>

    <tr>
      <td>
        Rastreo distribuido por servicio (solo ruta de APM)
      </td>

      <td>
        ```sql
        SELECT count(*) FROM Span WHERE k8s.cluster.name = '<YOUR_CLUSTER>' FACET service.name SINCE 30 minutes ago
        ```
      </td>
    </tr>

    <tr>
      <td>
        Verifique que los spans del proxy se estén recopilando con atributos de Linkerd
      </td>

      <td>
        ```sql
        SELECT count(*) FROM Span WHERE k8s.cluster.name = '<YOUR_CLUSTER>' AND linkerd_control_plane_component IS NOT NULL FACET service.name SINCE 10 minutes ago
        ```
      </td>
    </tr>
  </tbody>
</table>

Si la consulta “Verify proxy spans” devuelve 0, el procesador `transform/linkerd_component_inject` no se está ejecutando o falta `linkerd_control_plane_ns` en los spans. Consulte [Solucionar problemas del monitoreo de Linkerd](/docs/opentelemetry/integrations/linkerd/troubleshooting) para obtener los pasos de remediación.
