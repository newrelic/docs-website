Utilice esta guía para instalar y configurar NRDOT para monitorear un clúster de Elasticsearch autohospedado en un servidor Linux o en una máquina virtual (VM). Una vez que lo configure, el recolector exporta las métricas del clúster de Elasticsearch a New Relic. Para obtener información sobre las métricas de host, los logs y las etiquetas personalizadas, consulte [Configuración avanzada](/docs/opentelemetry/integrations/elasticsearch/advanced-configuration).

## Compatibilidad y requisitos [#requirements]

### Soportado

* Elasticsearch 7.16 o posterior

### Necesita

* Una [clave de licencia](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key) de New Relic
* Privilegios de root o sudo en el host
* Privilegios de administrador de clúster de Elasticsearch con privilegio de clúster `monitor` o `manage` (consulte los [privilegios de seguridad de Elasticsearch](https://www.elastic.co/guide/en/elasticsearch/reference/current/security-privileges.html))
* Conectividad HTTPS saliente (puerto 443) al [extremo OTLP](/docs/opentelemetry/best-practices/opentelemetry-otlp) de New Relic
* Un nombre de usuario y contraseña de Elasticsearch (si el clúster requiere autenticación)

<Steps>
<Step>
## Instalar recolector NRDOT [#install]

Instale el recolector NRDOT y ejecútelo como un servicio de systemd. Consulte [Instalar NRDOT](/docs/opentelemetry/nrdot/nrdot-collector/).
</Step>

<Step>
## Configurar el recolector NRDOT [#configure]

1. Haga una copia de seguridad de la configuración predeterminada del recolector y, a continuación, ábrala para editarla:

   ```bash
   sudo cp /etc/nrdot-collector/config.yaml /etc/nrdot-collector/config.yaml.backup
   sudo nano /etc/nrdot-collector/config.yaml
   ```

### Parámetro de configuración [#configuration-parameters]

La siguiente tabla describe los parámetros de configuración clave utilizados en la configuración anterior:

| Parámetro                    | Descripción                                                                                                                                              |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `endpoint`                   | La URL del clúster de Elasticsearch.                                                                                                                     |
| `collection_interval`        | El intervalo entre las extracciones de métricas. El valor predeterminado es 15s.                                                                         |
| `elasticsearch.cluster.name` | Un nombre único que identifica este clúster en New Relic.                                                                                                |
| `NEW_RELIC_MEMORY_LIMIT_MIB` | El límite de memoria, en MiB, para el procesador `memory_limiter` del recolector, configurado para adaptarse al entorno.                                 |
| `NEWRELIC_LICENSE_KEY`       | Su clave de licencia de New Relic.                                                                                                                       |
| `NEWRELIC_OTLP_ENDPOINT`     | El extremo OTLP de New Relic para la región de la cuenta, según los [extremos OTLP de New Relic](/docs/opentelemetry/best-practices/opentelemetry-otlp). |

3. Almacene el archivo de configuración.

De forma opcional, puede agregar autenticación de clúster seguro, métricas de host, recopilación de logs o etiquetas de metadatos personalizadas. Consulte [Configuración avanzada](/docs/opentelemetry/integrations/elasticsearch/advanced-configuration).
</Step>

<Step>
## Establezca las variables de entorno [#env-vars]

Establezca las credenciales y los detalles de conexión que el recolector necesita para enviar datos a New Relic.

```bash
sudo mkdir -p /etc/systemd/system/nrdot-collector.service.d
cat <<EOF | sudo tee /etc/systemd/system/nrdot-collector.service.d/environment.conf
[Service]
Environment="NEWRELIC_OTLP_ENDPOINT=<YOUR_NEWRELIC_OTLP_ENDPOINT>"
Environment="NEWRELIC_LICENSE_KEY=<YOUR_NEWRELIC_LICENSE_KEY>"
Environment="NEW_RELIC_MEMORY_LIMIT_MIB=100"
EOF
```
</Step>

<Step>
## Reinicie el recolector NRDOT [#restart]

Reinicie el recolector para aplicar los cambios:

```bash
sudo systemctl daemon-reload
sudo systemctl restart nrdot-collector.service
```
</Step>

<Step>
## Verificar la recopilación de datos [#verify]

En un plazo de -5 minutos después de reiniciar el recolector, ejecute esta consulta en New Relic para confirmar que los datos están fluyendo (reemplace `<YOUR_ELASTICSEARCH_CLUSTER_NAME>` por el nombre del clúster):

```sql
FROM Metric SELECT count(*)
WHERE metricName LIKE 'elasticsearch.%'
AND elasticsearch.cluster.name = '<YOUR_ELASTICSEARCH_CLUSTER_NAME>'
SINCE 10 minutes ago
```

<Callout variant="tip">
También puede revisar el propio recolector: `nrdot-collector.service` debería reportar `active (running)` (`sudo systemctl status nrdot-collector.service`), sin errores de conexión en los logs (`sudo journalctl -u nrdot-collector.service -f`).
</Callout>

Si no ve datos en -5 minutos, consulte la [resolución de problemas de Elasticsearch](/docs/opentelemetry/integrations/elasticsearch/troubleshooting).
</Step>

<Step>
## Encuentra y utiliza tus datos [#find-and-use]

Una vez que New Relic recopile los datos, puede acceder al monitoreo de Elasticsearch a través de la UI de New Relic.

Para buscar el dashboard de Elasticsearch en New Relic:

1. Vaya a <DNT>**one.newrelic.com &gt; Integrations &amp; Agents**</DNT>.
2. En la pestaña <DNT>**All**</DNT>, haga clic en <DNT>**Dashboards**</DNT>, luego busque <DNT>**Elasticsearch (OpenTelemetry Collector)**</DNT> para ver el dashboard.

O, desde la navegación de la izquierda:

1. Haga clic en <DNT>**Dashboards**</DNT>.
2. Busque el dashboard <DNT>**Elasticsearch (OpenTelemetry Collector)**</DNT> para verlo.

Después de configurar el monitoreo de Elasticsearch con NRDOT, puede:

* [Cree un dashboard personalizado](/docs/query-your-data/explore-query-data/dashboards/introduction-dashboards/) para visualizar las métricas de Elasticsearch
* [Configure alertas](/docs/alerts/create-alert/create-alert-condition/alert-conditions/) para umbrales críticos de estado y rendimiento del clúster
* [Explore los datos](/docs/query-your-data/explore-query-data/browse-data/introduction-data-explorer/) con las capacidades de consulta de New Relic
</Step>
</Steps>

<Callout variant="tip">
**Correlacione APM con Elasticsearch**: para conectar la aplicación APM y el clúster de Elasticsearch, incluya el atributo de recurso `es.cluster.name="your-cluster-name"` en las métricas de APM. Esto le permite ver los datos de APM y Elasticsearch juntos en New Relic.
</Callout>
