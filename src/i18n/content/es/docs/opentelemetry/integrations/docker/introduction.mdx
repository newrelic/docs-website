La integración de Docker OpenTelemetry monitorea el estado y el rendimiento de las aplicaciones en contenedores al recopilar métricas en tiempo real directamente desde Docker Engine. Obtiene visibilidad sobre el uso de la CPU, la memoria, la I/O de red y la I/O de disco para cada contenedor en ejecución, de modo que pueda detectar cuellos de botella de recursos y fallas de contenedores antes de que afecten a los servicios.

## Capacidades [#capabilities]

Esta integración proporciona:

* **Métricas**: uso y utilización de CPU, uso y porcentaje de memoria, I/O de red (bytes y paquetes enviados y recibidos, descartes y errores), I/O de bloques y conteo de procesos (PID)
* **Entidades**: los contenedores de Docker aparecen como entidades monitoreadas en New Relic, vinculados al host
* **Logs**: recopile los logs de los contenedores. Para conocer los pasos de configuración, consulte [Configuración avanzada](/docs/opentelemetry/integrations/docker/advanced-configuration#logs).

## Elija su ruta de instalación [#choose]

* **[NRDOT Collector](/docs/opentelemetry/integrations/docker/install-nrdot) (recomendado)**: distribución de OpenTelemetry de New Relic, preconfigurada para enviar datos a New Relic. Utilice esta opción si aún no ejecuta otro OpenTelemetry Collector.
* **[OpenTelemetry Collector Contrib](/docs/opentelemetry/integrations/docker/install-otelcol-contrib)**: el recolector de la comunidad upstream. Úselo si ya ejecuta OpenTelemetry Collector Contrib para otros workloads y desea agregar el monitoreo de Docker a la misma instancia.

## Instalación de un vistazo [#at-a-glance]

La página de instalación lo guía a través de:

1. Verifique la compatibilidad y reúna los requisitos previos
2. Instale el recolector elegido
3. Configurar los permisos del socket de Docker
4. Configurar el recolector
5. Reinicie el recopilador
6. Verifique que los datos fluyan a New Relic
