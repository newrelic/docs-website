Monitoree el rendimiento de su base de datos PostgreSQL utilizando New Relic Distribution of OpenTelemetry (NRDOT) con información valiosa integral sobre las métricas de la base de datos, el rendimiento de las consultas y el estado del sistema.

Este enfoque basado en NRDOT complementa nuestra actual On-Host Integration (OHI) al aprovechar los estándares de OpenTelemetry para el monitoreo de bases de datos, lo que facilita la integración con su stack de observabilidad existente.

## Elige tu método de instalación [#install]

Puede instalar NRDOT Collector para el monitoreo de PostgreSQL de las siguientes maneras:

* [Configuración autohospedada](/docs/opentelemetry/database/postgresql/hosted)
* [Configuración de AWS RDS o Aurora](/docs/opentelemetry/database/postgresql/rds)

## Instalación de un vistazo [#glance]

Las tareas de alto nivel para instalar NRDOT Collector para el monitoreo de PostgreSQL son:

<Steps>
  <Step>
    ### Requisitos previos [#prerequisites]

    Antes de instalar, asegúrese de tener:

    * PostgreSQL `14` y superior
    * Una [clave de licencia](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key) de New Relic.
    * Conectividad de red entre el host donde instala el Collector NRDOT y su base de datos PostgreSQL.
    * Conectividad de red a la [documentación de los extremos OTLP de New Relic](/docs/opentelemetry/best-practices/opentelemetry-otlp/)
    * Esta integración está disponible como parte del programa de vista previa pública (public preview) de New Relic. Consulte con el Gerente de su organización para activarla desde la página de [Previsualizaciones y pruebas (Previews &amp; Trials)](https://one.newrelic.com/admin-portal/promotion-management/home).

    Para obtener información detallada sobre los requisitos previos compatibles, consulte el documento [Compatibilidad](/docs/opentelemetry/database/postgresql/compatibility).
  </Step>

  <Step>
    ### Instalar NRDOT Collector [#install]

    Elija su ruta de instalación según su infraestructura:

    * **[PostgreSQL autohospedado](/docs/opentelemetry/database/postgresql/hosted)**
    * **[Monitoreo de RDS PostgreSQL](/docs/opentelemetry/database/postgresql/rds)**
  </Step>

  <Step>
    ### Configurar el usuario de monitoreo de PostgreSQL [#user]

    Cree y proporcione los permisos necesarios al usuario de monitoreo para que NRDOT Collector recopile métricas y consulte muestras.
  </Step>

  <Step>
    ### Configurar el Colector NRDOT [#configure]

    Configure el Collector de NRDOT para conectarse a su base de datos de PostgreSQL y a su cuenta de New Relic. Esto incluye configurar los detalles de conexión, la autenticación y cualquier opción de configuración adicional.
  </Step>

  <Step>
    ### Encuentra y utiliza tus datos [#find]

    Una vez que se estén recopilando sus datos, puede acceder a un monitoreo integral de bases de datos PostgreSQL a través de la UI de New Relic.

    Para encontrar su entidad de base de datos PostgreSQL en New Relic:

    1. Vaya a <DNT>**[https://one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT>.
    2. En el menú desplegable **<DNT>Entity type</DNT>**, seleccione <DNT>**PostgreSQL instance**</DNT> y luego haga clic en <DNT>**Apply**</DNT>.
    3. Seleccione su base de datos PostgreSQL de la lista de entidades.
  </Step>
</Steps>
