<Callout title="Avance">
  Todavía estamos trabajando en esta característica, ¡pero nos encantaría que la probaras!

  Esta función se proporciona actualmente como parte de una vista previa de conformidad con nuestras [políticas de prelanzamiento](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy/).
</Callout>

Puede configurar NRDOT Collector para monitorear múltiples instancias de PostgreSQL desde un recolector. Esto es útil si tiene múltiples bases de datos PostgreSQL ejecutándose en diferentes hosts o puertos y desea recopilar métricas de todas ellas utilizando una sola instancia de NRDOT Collector.

<Steps>
  <Step>
    ## Requisitos previos [#prerequisites]

    * NRDOT está instalado y configurado para sus instancias de PostgreSQL:
      * [PostgreSQL autohospedado](/docs/opentelemetry/database/postgresql/hosted)
  </Step>

  <Step>
    ## Agregar configuración de múltiples receptores [#multi]

    El siguiente ejemplo muestra cómo configurar el Collector de NRDOT para monitorear dos instancias de PostgreSQL mediante una configuración de múltiples receptores. Puede agregar más receptores según sea necesario para instancias adicionales de PostgreSQL.

    ```yaml
    receivers:
      nrpostgresql/db1: &nrpostgresql-common
        endpoint: "<YOUR_DB1_HOST>:<YOUR_DB1_PORT>"
        username: "<YOUR_DB_USERNAME>"
        password: "<YOUR_DB_PASSWORD>"
        databases:
          - <YOUR_DB1_DATABASE_NAME>
        collection_interval: 10s
      nrpostgresql/db2:
        <<: *nrpostgresql-common
        endpoint: "<YOUR_DB2_HOST>:<YOUR_DB2_PORT>"
        databases:
          - <YOUR_DB2_DATABASE_NAME>

    service:
      pipelines:
        metrics:
          receivers: [nrpostgresql/db1, nrpostgresql/db2]
          exporters: [otlp/newrelic]
    ```
  </Step>

  <Step>
    ## Reiniciar NRDOT Collector [#restart]

    Es necesario reiniciar, no es opcional — el recolector carga su configuración una vez al inicio y no se recarga en caliente. Cualquier cambio de configuración no tiene efecto hasta que reinicie el proceso.

    ```bash
    sudo systemctl restart nrdot-collector
    ```
  </Step>
</Steps>
