De forma predeterminada, `EXPLAIN` se ejecuta directamente como el usuario de monitoreo, y PostgreSQL comprueba los privilegios de tabla en el momento de la planificación — por lo que las sentencias de bloqueo de filas o de escritura fallan con `permission denied` a menos que el usuario de monitoreo tenga acceso de escritura, lo cual nunca debería tener.

## Cree la función auxiliar EXPLAIN [#explain]

Para recopilar planes de consulta para declaraciones de bloqueo o escritura sin otorgar acceso de escritura al usuario de monitoreo, cree la siguiente función en cada base de datos:

```sql
CREATE OR REPLACE FUNCTION otel.explain_statement(l_query text)
RETURNS json
LANGUAGE plpgsql
SECURITY DEFINER
AS $$
DECLARE
    v_plan json;
    v_param_count int;
    v_nulls text := '';
    i int;
BEGIN
    SET TRANSACTION READ ONLY;
    SET plan_cache_mode = force_generic_plan;

    EXECUTE 'PREPARE otel_explain_stmt AS ' || l_query;

    SELECT COALESCE(array_length(parameter_types, 1), 0) INTO v_param_count
    FROM pg_prepared_statements WHERE name = 'otel_explain_stmt';

    IF v_param_count > 0 THEN
        FOR i IN 1..v_param_count LOOP
            v_nulls := v_nulls || CASE WHEN i > 1 THEN ', ' ELSE '' END || 'null';
        END LOOP;
        v_nulls := '(' || v_nulls || ')';
    END IF;

    EXECUTE 'EXPLAIN (FORMAT JSON) EXECUTE otel_explain_stmt' || v_nulls INTO v_plan;
    DEALLOCATE otel_explain_stmt;
    RETURN v_plan;
EXCEPTION WHEN OTHERS THEN
    IF EXISTS (SELECT 1 FROM pg_prepared_statements WHERE name = 'otel_explain_stmt') THEN
        DEALLOCATE otel_explain_stmt;
    END IF;
    RAISE;
END;
$$;

GRANT EXECUTE ON FUNCTION otel.explain_statement(text) TO <YOUR_DB_USERNAME>;
```

### Mecánica de recopilación de planes de ejecución

* **Límite de velocidad:** `top_query_collection.max_explain_each_interval` (predeterminado `1000`) limita a `EXPLAIN`por extracción.
* **Almacenamiento en caché:** `query_plan_cache_size` / `query_plan_cache_ttl` (predeterminado `1000` entradas/ `1h`) almacena en caché un plan una vez obtenido, identificado por ID de consulta.
