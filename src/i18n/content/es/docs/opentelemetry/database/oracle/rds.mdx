Obtenga información valiosa y completa sobre el rendimiento de la base de datos de Amazon RDS Oracle con el monitoreo de la base de datos, el análisis de consultas y las métricas del estado del sistema mediante el recolector de New Relic Distribution of OpenTelemetry (NRDOT).

<Callout variant="tip" title="Instalación guiada">
  Para instalar a través de la UI de New Relic en su lugar, vaya a <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; Oracle (OpenTelemetry)** </DNT>. Esta página solo cubre la ruta de instalación de la CLI.
</Callout>

## Requisitos previos [#prerequisites]

Antes de comenzar, cerciorar de tener lo siguiente:

* [Clave de licencia](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)de New Relic válida
* Arquitectura compatible: Linux con AMD64 y ARM64
* Conectividad de red al [extremo OTLP de New Relic](/docs/opentelemetry/best-practices/opentelemetry-otlp)
* Oracle Database `19c` o posterior

### Inscribirse en la vista previa [#enroll]

Esta integración está disponible como parte del programa de vista previa pública (public preview) de New Relic. Comuníquese con el gerente de la organización para activarla desde la página de [Previsualizaciones y pruebas (Previews &amp; Trials)](https://one.newrelic.com/admin-portal/promotion-management/home).

  <Step>
    ## Instalar NRDOT Collector [#installation]

    Seleccione el método de distribución de instalación adecuado para su entorno Linux:

    <CollapserGroup>
      <Collapser title="Para la arquitectura AMD64" id="amd64-rds">
        * Para sistemas Debian/Ubuntu, ejecute:

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_amd64.deb" --output nrdot-collector.deb && sudo dpkg -i nrdot-collector.deb
          ```

        * Para sistemas RHEL/CentOS/OEL, ejecute:

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_x86_64.rpm" --output nrdot-collector.rpm && sudo rpm -ivh nrdot-collector.rpm
          ```
      </Collapser>

      <Collapser title="Para la arquitectura ARM64" id="arm64-rds">


        * Para sistemas RHEL/CentOS/OEL, ejecute:

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_arm64.rpm" --output nrdot-collector.rpm && sudo rpm -ivh nrdot-collector.rpm
          ```

  <Step>
    ## Configurar el usuario de la base de datos [#database-user]

    Cree un usuario de monitoreo con los privilegios necesarios para su base de datos Oracle RDS.

    1. Inicie sesión en la base de datos raíz como administrador:

       ```sql
       CREATE USER <USERNAME> IDENTIFIED BY "<USER_PASSWORD>";
       ```

    2. Otorgar privilegios de `CONNECT` al usuario recién creado:

       ```sql
       GRANT CONNECT TO <USERNAME>;
       ```
  </Step>

  <Step>
    ## Actualizar la configuración de NRDOT Collector [#update-config]

    Actualice la configuración del NRDOT Collector para utilizar el archivo `oracle-config.yaml`.

    ```bash
    sudo sed -i 's|OTELCOL_OPTIONS="--config=/etc/nrdot-collector/config.yaml"|OTELCOL_OPTIONS="--config=/etc/nrdot-collector/oracle-config.yaml"|' /etc/nrdot-collector/nrdot-collector.conf
    ```

    <Callout variant="tip">
      Tú también puedes:

      * [Configure múltiples receptores](/docs/opentelemetry/database/oracle/multi-receiver): para monitorear múltiples instancias de Oracle Database desde un recolector.
      * [Configure SQL Query Receiver](/docs/opentelemetry/database/capabilities/sql-query-receiver/): para recopilar métricas personalizadas de su Oracle Database.
      * [Vincule su Oracle Database con APM](/docs/opentelemetry/database/capabilities/db-apm): para correlacionar el rendimiento de la aplicación con las operaciones de la base de datos. Esto le permite ver exactamente qué aplicaciones están generando workloads de base de datos específicas.
      * [Configure la gestión de secretos](/docs/opentelemetry/database/capabilities/db-apm/#secret-management): Para administrar de forma segura información confidencial, como las credenciales de bases de datos. Esto ayuda a mejorar la seguridad de su configuración de monitoreo al evitar la codificación rígida de datos sensibles en los archivos de configuración.
    </Callout>
  </Step>

  <Step>
    ## Reiniciar NRDOT Collector [#restart-collector]

    Después de actualizar la configuración, reinicie el NRDOT Collector:

    ```bash
    sudo systemctl restart nrdot-collector.service
    sudo systemctl status nrdot-collector.service
    ```

    <Callout variant="tip">
      Reinicie siempre el NRDOT Collector después de realizar cambios de configuración para garantizar que los nuevos ajustes surtan efecto.
    </Callout>
  </Step>

  <Step>
    ## Encuentra y utiliza tus datos [#find-use-data]

    Una vez que se estén recopilando sus datos, puede acceder a un monitoreo integral de bases de datos Oracle a través de la UI de New Relic.

    Para encontrar su entidad de base de datos Oracle en New Relic:

    1. Vaya a <DNT>**[https://one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT>.
    2. Establezca los criterios de búsqueda como <DNT>`instrumentation.provider = opentelemetry`</DNT>.
    3. Seleccione su base de datos Oracle de la lista de entidades.
  </Step>
