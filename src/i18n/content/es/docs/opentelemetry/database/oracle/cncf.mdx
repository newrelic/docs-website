  Esta función se proporciona actualmente como parte de una vista previa de conformidad con nuestras [políticas de prelanzamiento](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy/).
</Callout>

Puede usar OpenTelemetry Collector Contribution para la base de datos de Oracle para monitorear su instancia. OpenTelemetry Collector Contribution es un proyecto respaldado por la comunidad que proporciona una forma de recopilar telemetry data de la base de datos de Oracle y enviarlo a New Relic.

De forma predeterminada, la Contribución del OpenTelemetry Collector recopila métricas de la base de datos de Oracle y las envía a New Relic. Sin embargo, estas son métricas limitadas. Para enviar métricas de rendimiento de consultas, métricas de tiempo de espera, métricas de sesión, métricas de almacenamiento de ASM y otras métricas avanzadas, deberá configurar la Contribución del OpenTelemetry Collector. Esta guía proporciona instrucciones para configurar la Contribución del OpenTelemetry Collector para recopilar métricas avanzadas de la base de datos de Oracle y enviarlas a New Relic.

<Steps>
  <Step>
    ## Requisitos previos [#prerequisites]

    * OpenTelemetry Collector Contrib (`otelcol-contrib`) instalado y configurado en su sistema. Puede descargar la última versión desde la página de [lanzamientos de OpenTelemetry Collector](https://github.com/open-telemetry/opentelemetry-collector-releases/releases).
  </Step>

  <Step>
    ## Habilite las métricas de la UI [#enable]

    Puede enriquecer su experiencia en la plataforma de New Relic agregando y habilitando las diversas métricas en su archivo de configuración `otelcol-contrib`. Al usar la configuración proporcionada en esta sección, puede completar los datos para las siguientes páginas en la plataforma de New Relic:

    * <DNT>Overview</DNT>
    * <DNT>Query performance</DNT>
    * <DNT>Wait events</DNT>
    * <DNT>Sessions</DNT>

    <CollapserGroup>
      <Collapser id="overview" title="Habilitar métricas de la página Overview">
        La página <DNT>Overview</DNT> muestra una vista de alto nivel de la instancia de la base de datos de Oracle, incluidas métricas clave como la utilización de la CPU, el tiempo de espera, I/O, la memoria y el uso de sesiones.

        Para poblar los datos de la página <DNT>Overview</DNT> en la plataforma de New Relic, agregue la siguiente configuración al archivo de configuración `otelcol-contrib`:

        ```yaml
        receivers:
          oracledb:
            # Metrics required by the "Oracle Database Monitoring (OTel)" dashboard
            metrics:
              oracledb.buffer_cache.utilization:
                enabled: true
              oracledb.consistent_gets:
                enabled: true
              oracledb.cpu_time:
                enabled: true
              oracledb.database.cpu.utilization:
                enabled: true
              oracledb.database.wait.utilization:
                enabled: true
              oracledb.db_block_gets:
                enabled: true
              oracledb.enqueue_deadlocks:
                enabled: true
              oracledb.execution.utilization:
                enabled: true
              oracledb.executions:
                enabled: true
              oracledb.hard_parses:
                enabled: true
              oracledb.host.cpu.utilization:
                enabled: true
              oracledb.library_cache.utilization:
                enabled: true
              oracledb.logical_reads:
                enabled: true
              oracledb.logons:
                enabled: true
              oracledb.parse.rate:
                enabled: true
              oracledb.parse_calls:
                enabled: true
              oracledb.pga_memory:
                enabled: true
              oracledb.physical_io.requests:
                enabled: true
              oracledb.physical_reads:
                enabled: true
              oracledb.physical_writes:
                enabled: true
              oracledb.processes.usage:
                enabled: true
              oracledb.sessions.usage:
                enabled: true
              oracledb.sga.usage:
                enabled: true
              oracledb.shared_pool.utilization:
                enabled: true
              oracledb.sql_service.response.duration:
                enabled: true
              oracledb.sqlnet.io.transferred:
                enabled: true
              oracledb.tablespace_size.usage:
                enabled: true
              oracledb.transactions.usage:
                enabled: true
              oracledb.user_commits:
                enabled: true
              oracledb.user_rollbacks:
                enabled: true
        ```
      </Collapser>

      <Collapser id="query-performance" title="Habilitar métricas de rendimiento de consultas, de sesión y de espera">
        Para completar los datos de las páginas <DNT>Query performance</DNT>, <DNT>Wait events</DNT> y <DNT>Sessions</DNT>, agregue la siguiente configuración al archivo de configuración `otelcol-contrib`:

        ```yaml
        receivers:
          oracledb:
            events:
              db.server.query_sample:
                enabled: true
              db.server.top_query:
                enabled: true
              db.server.session.wait_sample:
                enabled: true

            top_query_collection:
              max_query_sample_count: 1000
              top_query_count: 200
              collection_interval: 60s
              allowed_comment_keys:
                - nr_service_guid

            query_sample_collection:
              max_rows_per_query: 100
              allowed_comment_keys:
                - nr_service_guid

            session_wait_event_collection:
              max_rows_per_query: 100
        ```
      </Collapser>

      <Collapser id="asm" title="Habilite las métricas de grupo de discos y de disco de ASM">
        El receptor de la base de datos Oracle admite el monitoreo de instancias de ASM (Automatic Storage Management). El receptor recopila métricas críticas del estado del almacenamiento, que incluyen la capacidad del grupo de discos, el espacio libre utilizable, los discos sin conexión y los errores de lectura/escritura de los discos físicos.

        Ejecute lo siguiente como usuario privilegiado de Oracle para otorgar acceso:

        ```sql
        GRANT SELECT ON V_$ASM_DISKGROUP_STAT TO <username>;
        GRANT SELECT ON V_$ASM_DISK_STAT TO <username>;
        ```

        Agregue la siguiente configuración al archivo de configuración `otelcol-contrib`. Las 5 métricas están **deshabilitadas de forma predeterminada** (opcional):

        ```yaml
        receivers:
          oracledb:
            datasource: "oracle://otel:password@localhost:51521/XE"
            metrics:
              oracledb.asm.disk_group.free:
                enabled: true
              oracledb.asm.disk_group.capacity:
                enabled: true
              oracledb.asm.disk_group.usable_free:
                enabled: true
              oracledb.asm.disk_group.offline_disks:
                enabled: true
              oracledb.asm.disk.errors:
                enabled: true
        ```

        Para obtener una descripción de estas métricas, consulte la [referencia de métricas](/docs/opentelemetry/database/oracle/metrics-reference/#asm).
      </Collapser>
    </CollapserGroup>
  </Step>

  <Step>
    ## Reiniciar el OpenTelemetry Collector [#restart]

    Reinicie el OpenTelemetry Collector para aplicar los cambios de configuración:

    ```bash
    sudo systemctl restart otelcol-contrib
    ```
  </Step>
</Steps>
