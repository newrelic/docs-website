## Problemas comunes

<CollapserGroup>
  <Collapser id="test-connection" title="Probar la conectividad de red">
    Ejecute el siguiente comando para verificar que el puerto de la base de datos de Oracle sea accesible desde este host.

    ```bash
    (timeout 3 bash -c '</dev/tcp/<YOUR_ENDPOINT>/<YOUR_PORT>' && echo "PORT OPEN - Network connection successful!") || echo "CONNECTION FAILED - Port closed or firewall blocking"
    ```

    **Resultado esperado:** `PORT OPEN - Network connection successful!`
  </Collapser>

  <Collapser id="otlp-endpoint-connection" title="Probar la conectividad del extremo OTLP">
    Ejecute el siguiente comando para verificar que su host pueda alcanzar el extremo OTLP de New Relic seleccionado.

    ```bash
    ENDPOINT="<YOUR_OTLP_ENDPOINT>"
    HOST=$(echo "$ENDPOINT" | sed 's|https://||' | cut -d: -f1)
    PORT=$(echo "$ENDPOINT" | awk -F: '{print $NF}')
    (timeout 2 bash -c "</dev/tcp/$HOST/$PORT" && echo "✅ SUCCESS") || echo "❌ FAILED"
    ```

    **Resultado esperado:** `✅ SUCCESS`
  </Collapser>
</CollapserGroup>
