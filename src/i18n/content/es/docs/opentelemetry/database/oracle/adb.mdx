Obtenga información valiosa completa sobre el rendimiento de su Oracle Autonomous Database (ADB) con el monitoreo de base de datos, el análisis de consultas y las métricas de estado del sistema utilizando el recolector de New Relic Distribution of OpenTelemetry (NRDOT).

<Callout variant="tip" title="Instalación guiada">
  Para instalar a través de la UI de New Relic en su lugar, vaya a <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; Oracle (OpenTelemetry)** </DNT>. Esta página solo cubre la ruta de instalación de la CLI.
</Callout>

## Requisitos previos [#prerequisites]

Antes de comenzar, cerciorar de tener lo siguiente:

* [Clave de licencia](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)de New Relic válida
* Arquitectura compatible: Linux con AMD64 y ARM64
* Conectividad de red al [extremo OTLP de New Relic](/docs/opentelemetry/best-practices/opentelemetry-otlp)
* Oracle Database `19c` o posterior

Comuníquese con el gerente de la organización para activarla desde la página de [Previsualizaciones y pruebas (Previews &amp; Trials)](https://one.newrelic.com/admin-portal/promotion-management/home).

<Steps>
  <Step>
    ## Instalar NRDOT Collector [#installation]

    Seleccione el método de distribución de instalación adecuado para su entorno Linux:

    <CollapserGroup>
      <Collapser title="Para la arquitectura AMD64" id="amd">
        * Para sistemas Debian/Ubuntu, ejecute:

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_amd64.deb" --output nrdot-collector.deb && sudo dpkg -i nrdot-collector.deb
          ```

        * Para sistemas RHEL/CentOS/OEL, ejecute:

          ```bash
          NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_x86_64.rpm" --output nrdot-collector.rpm && sudo rpm -ivh nrdot-collector.rpm
          ```
      </Collapser>

      <Collapser title="Para la arquitectura ARM64" id="arm">

      </Collapser>

  <Step>
    ## Configurar el usuario de la base de datos [#database-user]

    Cree un usuario de monitoreo con los privilegios necesarios para la instancia de base de datos Oracle ADB. Ejecute las siguientes sentencias como SYS dentro del ADB objetivo para crear un usuario de monitoreo local:

    ```sql
    CREATE USER <USER_NAME> IDENTIFIED BY "<YOUR_PASSWORD>";
    GRANT CREATE SESSION TO <USER_NAME>;
    ```
  </Step>

  <Step>
    ## Otorgar privilegios de monitoreo para Autonomous Database [#grant-privileges]

    Ejecute estos comandos como administrador dentro de su ADB. Esto le da a la herramienta de monitoreo el acceso básico que necesita para recopilar métricas, rastrear eventos y encontrar sus instancias de base de datos.

    ```sql
    GRANT SELECT ON SYS.V_$INSTANCE   TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$DATABASE   TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$CONTAINERS TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$DATAFILE   TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$PDBS       TO <USER_NAME>; 
    GRANT SELECT ON SYS.V_$SYSSTAT                    TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$SYSMETRIC                  TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$SESSION                    TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$RESOURCE_LIMIT             TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$OSSTAT                     TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$SGAINFO                    TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$ROWCACHE                   TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$PARAMETER                  TO <USER_NAME>;
    GRANT SELECT ON SYS.DBA_TABLESPACE_USAGE_METRICS  TO <USER_NAME>;
    GRANT SELECT ON SYS.DBA_TABLESPACES               TO <USER_NAME>;
    GRANT SELECT ON SYS.DBA_DATA_FILES                TO <USER_NAME>;
    GRANT SELECT ON SYS.DBA_FREE_SPACE                TO <USER_NAME>;
    GRANT SELECT ON SYS.DBA_RECYCLEBIN                TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$SQL            TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$SQL_PLAN_STATISTICS_ALL       TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$LOCK           TO <USER_NAME>;
    GRANT SELECT ON SYS.V_$SESSION_EVENT  TO <USER_NAME>;
    GRANT SELECT ON SYS.DBA_PROCEDURES    TO <USER_NAME>;
    GRANT SELECT ON SYS.DBA_OBJECTS       TO <USER_NAME>;
    ```
  </Step>

  <Step>
    ## Reiniciar NRDOT Collector [#restart-collector]

    Después de configurar el recolector, reinicie el servicio NRDOT Collector para aplicar los cambios:

    ```bash
    sudo systemctl restart nrdot-collector
    ```

    Para verificar que el recolector se esté ejecutando correctamente, verifique el estado del servicio:

    ```bash
    sudo systemctl status nrdot-collector
    ```

    <Callout variant="tip">
      Reinicie siempre el NRDOT Collector después de realizar cambios de configuración para garantizar que los nuevos ajustes surtan efecto.
    </Callout>
  </Step>

  <Step>
    ## Encuentra y utiliza tus datos [#find-use-data]

    Después de configurar la integración de Oracle ADB, puede comenzar a monitorear y analizar el rendimiento de la base de datos en New Relic:

    1. Vaya a **[one.newrelic.com](https://one.newrelic.com) &gt; All Entities**.
    2. Filtre por **Oracle** para encontrar las entidades de la base de datos.
    3. Seleccione la entidad de Oracle ADB para ver dashboards, métricas y logs.

    Para obtener más información sobre el monitoreo de bases de datos de Oracle, consulte la [documentación de monitoreo de bases de datos](/docs/database-monitoring/oracle-monitoring/).
  </Step>
