Esta referencia proporciona configuraciones YAML completas para el monitoreo de la base de datos de Oracle con el Collector de la distribución de New Relic de OpenTelemetry (NRDOT). Estas configuraciones con todas las características incluyen métricas de infraestructura del host junto con el monitoreo de la base de datos para entornos de producción.

<Callout variant="important">
  **¿Busca comenzar rápidamente?** Estas son configuraciones avanzadas para uso en producción. Si está configurando el monitoreo de la base de datos Oracle por primera vez, le recomendamos comenzar con la configuración estándar en nuestras guías de configuración y volver a estas configuraciones completas una vez que haya verificado la funcionalidad básica.
</Callout>
