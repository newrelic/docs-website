Obtenga información valiosa y detallada sobre el rendimiento de su Oracle Database con nuestra solución de monitoreo basada en OpenTelemetry. Rastree métricas de bases de datos, analice el rendimiento de las consultas, monitoree el uso de recursos y correlacione el rendimiento de la base de datos con sus aplicaciones.

Este enfoque basado en NRDOT complementa nuestra actual On-Host Integration (OHI) al aprovechar los estándares de OpenTelemetry para el monitoreo de bases de datos, lo que facilita la integración con su stack de observabilidad existente.

## Capacidades [#capabilities]

* **Estándares de OpenTelemetry**: se integra a la perfección con las herramientas de observabilidad existentes
* **Métricas integrales**: información valiosa y detallada sobre el rendimiento de la base de datos, los eventos de espera y el uso de recursos
* **Información valiosa a nivel de consulta**: identifique y analice las consultas de rendimiento lento y la actividad de la sesión
* **Despliegue flexible**: funciona con entornos CDB/PDB en el host y Amazon RDS
* **Correlación de APM**: conecte el rendimiento de la base de datos a las trazas de la aplicación

## Elija su ruta de instalación [#choose]

Puede instalar el NRDOT Collector para el monitoreo de Oracle Database de las siguientes maneras:

* Entornos autohospedados: instalación manual en su propia infraestructura

  * [Base de datos de contenedor (CDB) en el host](/docs/opentelemetry/database/oracle/host-cdb): monitoree una base de datos de contenedor completa, incluidas todas las bases de datos conectables que dependen de ella.
  * [Base de datos conectable (PDB) en el host](/docs/opentelemetry/database/oracle/host-pdb): monitoree una base de datos conectable individual.

* Entornos de AWS RDS: monitoreo de Oracle Database administrado en la nube
  * [Monitoreo de RDS](/docs/opentelemetry/database/oracle/rds): monitoree una instancia de Oracle Database que se ejecuta en Amazon RDS.

* Entornos de Oracle Cloud: monitoreo de Oracle Database completamente administrado
  * [Monitoreo de Autonomous Database (ADB)](/docs/opentelemetry/database/oracle/adb): monitoree una instancia de Oracle Autonomous Database.

## Instalación guiada [#ui-install]

La instalación guiada está disponible en <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; Integrations &amp; Agents &gt; Oracle (OpenTelemetry)**</DNT>. La UI proporciona un flujo de trabajo guiado de extremo a extremo.

## Instalación de un vistazo [#at-a-glance]

<Steps>
  <Step>
    ### Requisitos previos [#prerequisites]

    * [Clave de licencia](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)de New Relic válida
    * Arquitectura compatible: Linux con AMD64 y ARM64
    * Conectividad de red al [extremo de New Relic OTLP](/docs/opentelemetry/best-practices/opentelemetry-otlp/)
    * Oracle Database 19c o posterior
  </Step>

  <Step>
    ### Instalar NRDOT Collector [#install-step]

    Instale el NRDOT Collector en su sistema siguiendo las instrucciones para su entorno específico

    * [CDB](/docs/opentelemetry/database/oracle/host-cdb)
    * [PDB](/docs/opentelemetry/database/oracle/host-pdb)
    * [RDS](/docs/opentelemetry/database/oracle/rds)
    * [ADB](/docs/opentelemetry/database/oracle/adb)
  </Step>

  <Step>
    ### Configurar el usuario de monitoreo [#user]

    Cree un usuario de Oracle Database dedicado con los permisos de solo lectura necesarios para permitir que el NRDOT Collector recopile métricas y datos de rendimiento de consultas.
  </Step>

  <Step>
    ### Configurar el Colector NRDOT [#configure]

    Configure el NRDOT Collector para conectarse a su instancia de Oracle Database. Esto implica especificar los detalles de conexión, el método de autenticación y cualquier opción de configuración adicional requerida para el entorno.
  </Step>

  <Step>
    ### Reiniciar NRDOT Collector [#restart]

    Después de configurar el NRDOT Collector, reinicie el servicio para aplicar los cambios y comenzar a recopilar datos de su instancia de Oracle Database.
  </Step>

  <Step>
    ### Encuentra y utiliza tus datos [#find]

    Una vez que se estén recopilando sus datos, puede acceder a un monitoreo integral de Oracle Database a través de la UI de New Relic.

    Para encontrar su entidad de base de datos Oracle en New Relic:

    1. Vaya a <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT>.
    2. Establezca los criterios de búsqueda como <DNT>`instrumentation.provider = opentelemetry`</DNT>.
    3. Seleccione su base de datos Oracle de la lista de entidades.
  </Step>
</Steps>
