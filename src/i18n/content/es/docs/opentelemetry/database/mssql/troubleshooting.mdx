Solucione los problemas comunes que puede encontrar durante el monitoreo de Microsoft SQL Server con el NRDOT Collector.

## Problemas comunes

### Problemas de conectividad de red

Si encuentra algún problema de conectividad de red con el NRDOT Collector, ejecute los siguientes comandos para probar la conectividad con su instancia de SQL Server:

* Para Windows, ejecute:

  ```shell
  Test-NetConnection -ComputerName <YOUR_IP_ADDRESS> -Port <YOUR_PORT_NUMBER>
  ```

* Para Linux, ejecute:

  ```bash
  nc -zv <YOUR_IP_ADDRESS> <YOUR_PORT_NUMBER>
  ```
