Esta referencia proporciona configuraciones YAML completas para el monitoreo de Microsoft SQL Server con el Collector de New Relic Distribution of OpenTelemetry (NRDOT). Estas configuraciones con todas las características incluyen todas las métricas disponibles, ajustes avanzados del procesador y canalizaciones optimizadas para entornos de producción en Linux y Windows, tanto en despliegues autohospedados como en AWS RDS.

<Callout variant="important">
  **¿Busca comenzar rápidamente?** Estas son configuraciones avanzadas para uso en producción. Si está configurando el monitoreo de SQL Server por primera vez, le recomendamos comenzar con las configuraciones estándar en nuestras guías de configuración y volver a estas configuraciones completas una vez que haya verificado la funcionalidad básica.
</Callout>

## Configurar el receptor [#receiver]

Puede usar `max_concurrent_queries` para controlar cuántas consultas de métricas ejecuta el receptor en paralelo en SQL Server durante cada ciclo de extracción. El valor predeterminado es 4 si se omite o se establece en 0.

```yaml
    receivers:
    nrsqlserver:
        max_concurrent_queries: 4  # default is 4 if omitted or set to 0
```
