Puede utilizar la OpenTelemetry Collector Contribution para Microsoft SQL Server para monitorear su instancia. La OpenTelemetry Collector Contribution es un proyecto respaldado por la comunidad que proporciona una forma de recopilar telemetry data de Microsoft SQL Server y enviarlo a New Relic.

Por defecto, la OpenTelemetry Collector Contribution recopila métricas de Microsoft SQL Server y las envía a New Relic. Sin embargo, estas son métricas limitadas. Para enviar métricas de rendimiento de consultas, métricas de tiempo de espera, métricas de sesión y otras métricas avanzadas, deberá configurar la OpenTelemetry Collector Contribution. Esta guía proporciona instrucciones para configurar la OpenTelemetry Collector Contribution para recopilar métricas avanzadas de Microsoft SQL Server y enviarlas a New Relic.

<Steps>
  <Step>
    ## Requisitos previos [#prerequisites]

    * OpenTelemetry Collector Contrib (`otelcol-contrib`) instalado y configurado en su sistema. Puede descargar la última versión desde la página de [lanzamientos de OpenTelemetry Collector](https://github.com/open-telemetry/opentelemetry-collector-releases/releases).
  </Step>

  <Step>
    ## Enable UI metrics [#enable]

    Puede enriquecer su experiencia en la plataforma de New Relic agregando y habilitando las diversas métricas en su archivo de configuración `otelcol-contrib`. Al usar la configuración proporcionada en esta sección, puede completar los datos para las siguientes páginas en la plataforma de New Relic:

    * <DNT>Overview</DNT>
    * <DNT>Query performance</DNT>
    * <DNT>Wait events</DNT>
    * <DNT>Sessions</DNT>
    * <DNT>Clients</DNT>

    <CollapserGroup>
      <Collapser id="overview" title="Habilitar métricas de la página Overview">
        La página <DNT>Overview</DNT> muestra una vista de alto nivel de su instancia de Microsoft SQL Server, incluidas métricas clave como el recuento de bases de datos, I/O, latencia, operaciones, espacio de tempdb, tasa de interbloqueo y más.

        Para poblar los datos de la página <DNT>Overview</DNT> en la plataforma de New Relic, agregue la siguiente configuración al archivo de configuración `otelcol-contrib`:

        ```yaml
        receivers:
            sqlserver:

                # Enable comprehensive database metrics
              metrics:
                sqlserver.database.count:
                  enabled: true
                sqlserver.database.io:
                  enabled: true
                sqlserver.database.latency:
                  enabled: true
                sqlserver.database.operations:
                  enabled: true
                sqlserver.database.tempdb.space:
                  enabled: true
                sqlserver.database.tempdb.version_store.size:
                  enabled: true
                sqlserver.deadlock.rate:
                  enabled: true
                sqlserver.os.wait.duration:
                  enabled: true
                sqlserver.processes.blocked:
                  enabled: true
                sqlserver.memory.grants.pending.count:
                  enabled: true
                sqlserver.memory.area:
                  enabled: true
        ```
      </Collapser>

      <Collapser id="query-performance" title="Habilitar métricas de rendimiento de consulta, sesión, espera y cliente">
        Puede poblar datos para las siguientes páginas en la plataforma de New Relic:

        * <DNT>Query performance</DNT>: muestra información detallada sobre las consultas que se ejecutan en su instancia de Microsoft SQL Server en las siguientes pestañas:

          * <DNT>Normalized queries</DNT>: muestra estadísticas agregadas por consulta, incluidas ejecuciones, duración promedio, tiempo promedio de CPU y lecturas lógicas. Haga clic en una consulta para ver información detallada de la consulta seleccionada, incluidas las estadísticas de rendimiento agregadas, los planes de consulta observados y las muestras individuales recientes con un desglose del tipo de espera.
          * <DNT>Query samples</DNT>: muestra ejecuciones de consulta individuales, incluidas la hora de inicio, la duración, el tipo de espera, el tiempo de espera, la base de datos, el usuario de la base de datos, la correlación de APM y el host del cliente.

        * <DNT>Wait events</DNT>: muestra información sobre los eventos de espera que ocurren en la instancia de Microsoft SQL Server. La vista de muestras de consulta muestra las consultas que están esperando actualmente junto con su tipo de espera y tiempo de espera.

        * <DNT>Sessions</DNT>: muestra información sobre las sesiones conectadas a su instancia de Microsoft SQL Server, incluidos los recuentos de sesiones, los estados de las sesiones, la duración promedio de las sesiones activas, las sesiones bloqueadas y los detalles de las sesiones individuales.

        * <DNT>Clients</DNT>: muestra información sobre los clientes conectados a su instancia de Microsoft SQL Server, incluidas las sesiones activas, las sesiones bloqueadas, los usuarios de BD conectados y los detalles del host del cliente.

        Para poblar los datos en estas páginas, agregue la siguiente configuración a su archivo de configuración `otelcol-contrib`:

        ```yaml
        receivers:
            sqlserver:

                events:
                    db.server.query_sample:
                        enabled: true
                    db.server.top_query:
                        enabled: true

                top_query_collection:
                    lookback_time: 45s
                    max_query_sample_count: 100
                    top_query_count: 30
                    collection_interval: 30s

                query_sample_collection:
                    max_rows_per_query: 100
        ```
      </Collapser>

      <Collapser id="waits" title="Habilitar todas las esperas en la pestaña de evento de espera">
        La vista All waits muestra el tiempo de espera a nivel de instancia desglosado por categoría de espera y tipo de espera individual.

        Para habilitar <DNT>All waits</DNT> en la pestaña <DNT>Wait event</DNT> de la plataforma de New Relic, agregue la siguiente configuración al archivo de configuración `otelcol-contrib`:

        ```yaml

        receivers:
            sqlserver:

                metrics:
                    sqlserver.os.wait.duration:
                        enabled: true

        ```
      </Collapser>
    </CollapserGroup>
  </Step>

  <Step>
    ### Reiniciar el OpenTelemetry Collector

    Reinicie el OpenTelemetry Collector para aplicar los cambios de configuración. Puede hacerlo ejecutando el siguiente comando:

    ```bash
    Restart-Service -Name "otelcol-contrib"
    ```
  </Step>
</Steps>
