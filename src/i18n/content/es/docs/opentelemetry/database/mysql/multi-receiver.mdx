  Esta función se proporciona actualmente como parte de una vista previa de conformidad con nuestras [políticas de prelanzamiento](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy/).
</Callout>

Puede configurar NRDOT Collector para monitorear múltiples instancias de MySQL desde un recolector. Esto es útil si tiene múltiples bases de datos MySQL ejecutándose en diferentes hosts o puertos y desea recopilar métricas de todas ellas utilizando una sola instancia de NRDOT Collector.

<Steps>
  <Step>
    ## Requisitos previos [#prerequisites]

    * NRDOT está instalado y configurado para sus instancias de MySQL:

      * [MySQL autohospedado](/docs/opentelemetry/database/mysql/hosted)
      * [Monitoreo de RDS MySQL](/docs/opentelemetry/database/mysql/rds)
  </Step>

  <Step>
    ## Agregar configuración de múltiples receptores [#multi]

    El siguiente ejemplo muestra cómo configurar el Collector de NRDOT para monitorear dos instancias de MySQL utilizando una configuración de múltiples receptores. Puede agregar más receptores según sea necesario para instancias adicionales de MySQL.

    ```yaml
    receivers:
      nrmysql/instance1: &nrmysql-common
        endpoint: "<INSTANCE_1_HOST>:<PORT>"
        username: "<YOUR_DB_USERNAME>"
        password: "<YOUR_DB_PASSWORD>"
        collection_interval: 10s
      nrmysql/instance2:
        <<: *nrmysql-common
        endpoint: "<INSTANCE_2_HOST>:<PORT>"

    service:
      pipelines:
        metrics:
          receivers: [nrmysql/instance1, nrmysql/instance2]
          exporters: [otlp/newrelic]
    ```
  </Step>

  <Step>
    ## Reiniciar NRDOT Collector [#restart]

    Es necesario reiniciar, no es opcional — el recolector carga su configuración una vez al inicio y no se recarga en caliente. Cualquier cambio de configuración no tiene efecto hasta que reinicie el proceso.

    ```bash
    sudo systemctl restart nrdot-collector
    ```
  </Step>
</Steps>
