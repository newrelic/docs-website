Puede instalar el NRDOT Collector para el monitoreo de MySQL utilizando la instalación guiada desde la plataforma de New Relic, que proporciona una configuración guiada por la plataforma a través de la UI de New Relic. Este es el enfoque recomendado para inicios rápidos.

<Steps>
  <Step>
    ### Requisitos previos [#prerequisites]

    Asegúrese de que su entorno cumpla con nuestra [compatibilidad y requisitos previos](/docs/opentelemetry/database/mysql/compatibility).
  </Step>

  <Step>
    ### Instalación [#guided]

    Para instalar el NRDOT Collector utilizando la instalación guiada:

    1. Inicie sesión en su [cuenta de New Relic](https://one.newrelic.com/).

    2. Vaya a <DNT>**left navigation pane &gt; + Integration &amp; Agents &gt; MySQL (OpenTelemetry)**</DNT>.

    3. En la pantalla <DNT>Select an account</DNT>, seleccione la cuenta en la que desea instalar la integración de MySQL y haga clic en <DNT>**Continue**</DNT>.

    4. En la pantalla <DNT>Enter your credential</DNT>, seleccione una de las siguientes opciones y luego haga clic en **Continue**:

       * **Use una clave existente**: si ya tiene una clave de licencia, proporcione la clave de licencia. Para obtener más información, consulta [Claves de usuario](/docs/apis/intro-apis/new-relic-api-keys/#user-key).
       * **Crear una nueva clave**: si no tiene una clave de licencia, haga clic en **Create a new key** para crear una.

    5. En la pantalla <DNT>Select platform</DNT>, seleccione la plataforma para instalar la integración de MySQL y haga clic en <DNT>**Continue**</DNT>.

    6. Siga las instrucciones en pantalla para configurar la integración para la plataforma seleccionada.

    7. Después de la instalación, en la pantalla <DNT>Test your integration</DNT>, haga clic en **Test connection** para verificar que el Collector de NRDOT pueda conectarse a su instancia de MySQL y enviar datos a New Relic.
  </Step>

  <Step>
    ### (Opcional) Configurar la correlación de APM y base de datos [#optional-service-id]

    Para correlacionar el rendimiento de su aplicación con las operaciones de la base de datos, puede configurar la identificación del servicio de base de datos. Esta característica le permite ver exactamente qué aplicaciones están generando workloads de base de datos específicas. Para obtener más información, consulte [configurar la identificación del servicio de base de datos](/docs/opentelemetry/database/capabilities/db-apm/) para obtener la correlación entre APM y la base de datos en New Relic.

    <Callout variant="important">
      Para ver los datos de rendimiento de la base de datos en APM, ambas entidades deben estar en la misma cuenta de New Relic. Si las entidades están en diferentes cuentas de New Relic, debe tener acceso a ambas cuentas para ver los datos.
    </Callout>
  </Step>

  <Step>
    ### Encuentra y utiliza tus datos [#find-use-data]

    Una vez que se estén recopilando sus datos, puede acceder a un monitoreo integral de bases de datos MySQL a través de la UI de New Relic.

    Para encontrar su entidad de base de datos MySQL en New Relic:

    1. Vaya a <DNT>**[https://one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT>.
    2. En el menú desplegable **<DNT>Entity type</DNT>**, seleccione <DNT>**MySQL instance**</DNT> y luego haga clic en <DNT>**Apply**</DNT>.
    3. Seleccione su base de datos MySQL de la lista de entidades.
  </Step>
</Steps>
