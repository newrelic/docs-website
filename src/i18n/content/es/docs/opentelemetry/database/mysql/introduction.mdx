Monitoree el rendimiento de su base de datos MySQL usando New Relic Distribution of OpenTelemetry (NRDOT) con información valiosa integral sobre las métricas de la base de datos, el rendimiento de las consultas y el estado del sistema.

Este enfoque basado en NRDOT complementa nuestra actual On-Host Integration (OHI) al aprovechar los estándares de OpenTelemetry para el monitoreo de bases de datos, lo que facilita la integración con su stack de observabilidad existente.

## Cómo puede configurar NRDOT para MySQL [#configure]

<Steps>
  <Step>
    ### Requisitos previos [#prerequisites]

    * Una [clave de licencia](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key) de New Relic.
    * Conectividad de red entre el host donde instala el NRDOT Collector y su base de datos MySQL.
    * Conectividad de red a la [documentación de los extremos OTLP de New Relic](/docs/opentelemetry/best-practices/opentelemetry-otlp/)
    * Esta integración está disponible como parte del programa de vista previa pública (public preview) de New Relic. Consulte con el Gerente de su organización para activarla desde la página de [Previsualizaciones y pruebas (Previews &amp; Trials)](https://one.newrelic.com/admin-portal/promotion-management/home).

    Para conocer los requisitos detallados, consulte [Compatibilidad y requisitos previos](/docs/opentelemetry/database/mysql/compatibility).
  </Step>

  <Step>
    ### Instalar NRDOT Collector [#installation]

    Elija su ruta de instalación según su infraestructura:

    * [MySQL autohospedado](/docs/opentelemetry/database/mysql/hosted)
    * [Monitoreo de RDS MySQL](/docs/opentelemetry/database/mysql/rds)
  </Step>

  <Step>
    ### Encuentra y utiliza tus datos [#find]

    Una vez que se estén recopilando sus datos, puede acceder a un monitoreo integral de bases de datos MySQL a través de la UI de New Relic.

    Para encontrar su entidad de base de datos MySQL en New Relic:

    1. Vaya a <DNT>**[https://one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT>.
    2. En el menú desplegable **<DNT>Entity type</DNT>**, seleccione <DNT>**MySQL instance**</DNT> y luego haga clic en <DNT>**Apply**</DNT>.
    3. Seleccione su base de datos MySQL de la lista de entidades.
  </Step>
</Steps>
