Puede usar el OpenTelemetry Collector para Microsoft SQL Server para monitorear la instancia. El OpenTelemetry Collector es un proyecto respaldado por la comunidad que recopila telemetry data de Microsoft SQL Server y lo envía a New Relic.

De forma predeterminada, OpenTelemetry Collector recopila métricas limitadas de Microsoft SQL Server. Para enviar el rendimiento de las consultas, el tiempo de espera, la sesión y otras métricas avanzadas, deberá configurar OpenTelemetry Collector. Esta guía le muestra cómo configurarlo para recopilar métricas avanzadas de Microsoft SQL Server y enviarlas a New Relic.

<Steps>
  <Step>
    ## Requisitos previos [#prerequisites]

    * OpenTelemetry Collector Contrib (`otelcol-contrib`) instalado y configurado en su sistema. Puede descargar la versión más reciente desde la página de [lanzamientos de OpenTelemetry Collector](https://github.com/open-telemetry/opentelemetry-collector-releases/releases).
  </Step>

  <Step>
    ## Habilite las métricas de la UI [#enable]

    Puede enriquecer la experiencia en la plataforma de New Relic al agregar y habilitar métricas en el archivo de configuración `otelcol-contrib`. Con la configuración proporcionada en esta sección, puede completar datos para las siguientes páginas en la plataforma de New Relic:

    * <DNT>Overview</DNT>
    * <DNT>Query performance</DNT>
    * <DNT>Wait events</DNT>
    * <DNT>Sessions</DNT>
    * <DNT>Clients</DNT>
    * <DNT>Stored procedures</DNT>

    <CollapserGroup>
      <Collapser id="overview" title="Habilitar métricas de la página Overview">
        La página <DNT>Overview</DNT> muestra una vista de alto nivel de su instancia de Microsoft SQL Server, incluidas métricas clave como el recuento de bases de datos, I/O, latencia, operaciones, espacio de tempdb, tasa de interbloqueo y más.

        Para poblar los datos de la página <DNT>Overview</DNT> en la plataforma de New Relic, agregue la siguiente configuración al archivo de configuración `otelcol-contrib`:

        ```yaml
        receivers:
            sqlserver:

                # Enable comprehensive database metrics
              metrics:
                sqlserver.database.count:
                  enabled: true
                sqlserver.database.io:
                  enabled: true
                sqlserver.database.latency:
                  enabled: true
                sqlserver.database.operations:
                  enabled: true
                sqlserver.database.tempdb.space:
                  enabled: true
                sqlserver.database.tempdb.version_store.size:
                  enabled: true
                sqlserver.deadlock.rate:
                  enabled: true
                sqlserver.os.wait.duration:
                  enabled: true
                sqlserver.processes.blocked:
                  enabled: true
                sqlserver.memory.grants.pending.count:
                  enabled: true
                sqlserver.memory.area:
                  enabled: true
        ```
      </Collapser>

      <Collapser id="query-performance" title="Habilite las métricas de rendimiento de la consulta, sesión, espera, cliente y procedimiento almacenado">
        Puede poblar datos para las siguientes páginas en la plataforma de New Relic:

        * <DNT>Query performance</DNT>: muestra información detallada sobre las consultas que se ejecutan en la instancia de Microsoft SQL Server en las siguientes pestañas:

          * <DNT>Normalized queries</DNT>: muestra los gráficos de ejecución y tiempo promedio de CPU.
          * <DNT>Query samples</DNT>: muestra las ejecuciones individuales de las consultas, que incluyen la hora de inicio, la duración, el tipo de espera, el tiempo de espera, la base de datos, el usuario de la base de datos y el host del cliente.
          * <DNT>Stored procedures</DNT>: muestra métricas de rendimiento para los principales procedimientos almacenados.

        * <DNT>Wait events</DNT>: muestra información sobre los eventos de espera que ocurren en la instancia de Microsoft SQL Server. La vista de muestras de consulta muestra las consultas que están esperando actualmente junto con su tipo de espera y tiempo de espera.

        * <DNT>Sessions</DNT>: muestra información sobre las sesiones conectadas a su instancia de Microsoft SQL Server, incluidos los recuentos de sesiones, los estados de las sesiones, la duración promedio de las sesiones activas, las sesiones bloqueadas y los detalles de las sesiones individuales.

        * <DNT>Clients</DNT>: muestra información sobre los clientes conectados a su instancia de Microsoft SQL Server, incluidas las sesiones activas, las sesiones bloqueadas, los usuarios de BD conectados y los detalles del host del cliente.

        * <DNT>Stored procedures</DNT>: muestra métricas de rendimiento para los principales procedimientos almacenados.

        Para poblar los datos en estas páginas, agregue la siguiente configuración a su archivo de configuración `otelcol-contrib`:

        ```yaml
        receivers:
            sqlserver:

                events:
                    db.server.query_sample:
                        enabled: true
                    db.server.top_query:
                        enabled: true
                    db.server.query_plan:
                        enabled: true
                    db.server.top_procedure:
                        enabled: true

                # Top query collection configuration
                top_query_collection:
                    lookback_time: 60s
                    max_query_sample_count: 1000
                    top_query_count: 250
                    collection_interval: 60s

                # Query sample collection configuration
                query_sample_collection:
                    max_rows_per_query: 100

                # Top stored procedure collection configuration
                top_procedure_collection:
                    max_procedure_sample_count: 1000
                    top_procedure_count: 250
                    collection_interval: 60s
        ```
      </Collapser>

      <Collapser id="waits" title="Habilitar todas las esperas en la pestaña de evento de espera">
        La vista All waits muestra el tiempo de espera a nivel de instancia desglosado por categoría de espera y tipo de espera individual.

        Para habilitar <DNT>All waits</DNT> en la pestaña <DNT>Wait event</DNT> de la plataforma de New Relic, agregue la siguiente configuración al archivo de configuración `otelcol-contrib`:

        ```yaml
        receivers:
            sqlserver:

                metrics:
                    sqlserver.os.wait.duration:
                        enabled: true
        ```
      </Collapser>
    </CollapserGroup>
  </Step>

  <Step>
    ## Reiniciar el OpenTelemetry Collector

    Reinicie el OpenTelemetry Collector para aplicar los cambios de configuración ejecutando el siguiente comando:

    ```powershell
    Restart-Service -Name "otelcol-contrib"
    ```
  </Step>
</Steps>
