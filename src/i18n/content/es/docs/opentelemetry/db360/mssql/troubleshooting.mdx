Solucione los problemas comunes que puede encontrar durante el monitoreo de Microsoft SQL Server con el NRDOT Collector.

## Problemas comunes [#common-issues]

### Problemas de conectividad de red [#network-connectivity]

Si encuentra algún problema de conectividad de red con el NRDOT Collector, ejecute los siguientes comandos para probar la conectividad con su instancia de SQL Server:

* Para Windows, ejecute:

  ```shell
  Test-NetConnection -ComputerName <YOUR_IP_ADDRESS> -Port <YOUR_PORT_NUMBER>
  ```

* Para Linux, ejecute:

  ```bash
  nc -zv <YOUR_IP_ADDRESS> <YOUR_PORT_NUMBER>
  ```

## Los datos no aparecen en New Relic [#data-not-flowing]

* Para verificar si hay problemas relacionados con el límite de tasa, ejecute:

  ```sql
  SELECT * FROM NrIntegrationError
  ```

* Si los datos aún no fluyen, compruebe si hay reglas de descarte configuradas en los eventos de métrica y log de evento. Consulte [Descartar datos de log con reglas de filtro de descarte](/docs/logs/ui-data/drop-data-drop-filter-rules/) y [Control de Pipeline](/docs/new-relic-control/pipeline-control/overview/).
