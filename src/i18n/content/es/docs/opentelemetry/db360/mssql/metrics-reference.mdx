Monitoree el rendimiento de la base de datos de SQL Server con métricas exhaustivas recopiladas por el NRDOT Collector. Por defecto, New Relic recopila las métricas referenciadas en la sección [Métricas disponibles](#default). Puede mejorar el monitoreo habilitando las métricas deseadas que se enumeran en la sección [Métricas adicionales](#additional-metrics).

## Métricas disponibles [#default]

Las siguientes métricas se recopilan automáticamente para la funcionalidad de la UI de New Relic. Estas están habilitadas de forma predeterminada y funcionan en cualquier plataforma a través de una conexión directa a SQL Server.
