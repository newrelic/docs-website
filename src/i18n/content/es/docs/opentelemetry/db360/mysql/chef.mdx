Puede instalar y configurar el Collector de NRDOT para el monitoreo de MySQL mediante el libro de recetas de Chef `newrelic-install`. El libro de recetas instala el recolector, crea el usuario de monitoreo y configura el recolector cuando ejecuta la receta `newrelic-install::default`.

<Callout variant="tip" title="Instalación guiada">
  Para instalar a través de la UI de New Relic en su lugar, vaya a <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; MySQL (Database 360)](https://onenr.io/0oQDYBNG1wy)** </DNT>. Esta página solo cubre la instalación manual.
</Callout>

<Steps>
  <Step>
    ## Requisitos previos [#prerequisites]

    * Una cuenta de New Relic con una [clave de licencia](/docs/apis/intro-apis/new-relic-api-keys/#overview-keys) válida.
    * Un [ID de cuenta](/docs/accounts/accounts-billing/account-structure/account-id) de New Relic.
    * MySQL 5.7 o posterior.
    * Chef 15 o posterior.
    * Un host recolector de Linux que ejecuta Debian/Ubuntu o RHEL/CentOS.
    * Para MySQL autohospedado: acceso administrativo al servidor de MySQL (la cuenta `root` o equivalente), mediante autenticación basada en contraseña.
    * Para MySQL o Aurora en AWS RDS: conectividad de red desde el host del recolector hasta el extremo de RDS, y el nombre de usuario y la contraseña maestros de RDS.
    * Conectividad de red al [extremo OTLP de New Relic](/docs/opentelemetry/best-practices/opentelemetry-otlp) para su región.

    Para obtener información detallada sobre los requisitos, consulte [Compatibilidad y requisitos previos](/docs/opentelemetry/db360/mysql/compatibility).
  </Step>

  <Step>
    ## Descargar el cookbook de Chef [#chef-download-cookbook]

    Descargue el [cookbook de Chef](https://supermarket.chef.io/cookbooks/newrelic-install) `newrelic-install` desde Chef Supermarket al directorio del repositorio de Chef:

    ```bash
    knife supermarket install newrelic-install
    ```
  </Step>

  <Step>
    ## Reemplace los atributos predeterminados [#chef-configure]

    Reemplace los atributos predeterminados en `attributes/default.rb` con los detalles de la cuenta:

    <CollapserGroup>
      <Collapser id="chef-host" title="MySQL autohospedado">
        Este cookbook monitorea una o más instancias de MySQL desde un único recolector. En lugar de un único conjunto de host/puerto/credencial, lee dos archivos que ya deben existir en el nodo: un archivo de instancias (YAML) que enumera cada instancia a monitorear, y un archivo de secretos (`KEY=VALUE`) con un inicio de sesión y contraseña de administrador para cada una, indexados para coincidir. Consulte la página de [instalación de la CLI](/docs/opentelemetry/db360/mysql/cli/#cli-install) para conocer los formatos de archivo exactos.

        ```ruby
        default['newrelic_install']['NEW_RELIC_API_KEY']    = <API key>
        default['newrelic_install']['NEW_RELIC_ACCOUNT_ID'] = <Account ID>
        default['newrelic_install']['NEW_RELIC_REGION']     = <Region>
        default['newrelic_install']['targets'] = [
          'nrdot-collector-mysql'
        ]
        default['newrelic_install']['env']['NR_CLI_MYSQL_CONFIG_PRESET']  = <1 Basic, 2 Advanced, default 1>
        default['newrelic_install']['env']['NR_CLI_MYSQL_INSTANCES_FILE'] = <path to the instances YAML file on the node>
        default['newrelic_install']['env']['NR_CLI_MYSQL_SECRETS_FILE']   = <path to the secrets file (KEY=VALUE per instance) on the node>
        # See all available targets at: https://github.com/newrelic/chef-install
        ```

        <Callout variant="important">
          El cookbook se conecta a MySQL a través de TCP mediante una contraseña, por lo que la cuenta de administrador en el archivo de secretos debe usar autenticación basada en contraseña. En algunas instalaciones de Debian/Ubuntu, `root`@`localhost` usa por defecto el plug-in `auth_socket` (sin contraseña, solo socket local), lo cual no funcionará aquí. Cámbielo antes de ejecutar la receta:

          ```bash
          mysql -u root -e "ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '<password>';"
          ```
        </Callout>

      <Collapser id="chef-rds" title="MySQL o Aurora en AWS RDS">
        Este cookbook monitorea uno o más extremos de RDS MySQL o Aurora desde un solo recolector, usando el mismo patrón de archivo de instancias/archivo de secretos que la versión autohospedada (ambos archivos ya deben existir en el nodo).

        ```ruby
        default['newrelic_install']['NEW_RELIC_API_KEY']    = <API key>
        default['newrelic_install']['NEW_RELIC_ACCOUNT_ID'] = <Account ID>
        default['newrelic_install']['NEW_RELIC_REGION']     = <Region>
        default['newrelic_install']['targets'] = [
          'nrdot-collector-mysql-rds'
        ]
        default['newrelic_install']['env']['NR_CLI_MYSQL_CONFIG_PRESET']  = <1 Basic, 2 Advanced, default 1>
        default['newrelic_install']['env']['NR_CLI_MYSQL_INSTANCES_FILE'] = <path to the instances YAML file on the node, using RDS endpoints as host>
        default['newrelic_install']['env']['NR_CLI_MYSQL_SECRETS_FILE']   = <path to the secrets file (KEY=VALUE per instance) on the node>
        # See all available targets at: https://github.com/newrelic/chef-install
        ```

  <Step>
    ## Cargue el cookbook de Chef [#chef-upload-cookbook]

    Cargue el cookbook de Chef `newrelic-install` en su servidor de Chef:

    ```bash
    knife cookbook upload newrelic-install
    ```
  </Step>

  <Step>
    ## Actualice la lista de ejecución [#chef-run-list]

    Agregue la receta `newrelic-install` a la lista de ejecución de un nodo:

    ```json
    "run_list": [
      "recipe[newrelic-install]"
    ]
    ```
  </Step>

  <Step>
    ## Encuentra y utiliza tus datos [#find]

    Una vez que sus datos se estén recopilando, puede acceder al monitoreo integral de bases de datos MySQL a través de la UI de New Relic.

    Para encontrar su entidad de base de datos MySQL en New Relic:

    1. Vaya a <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; All capabilities &gt; Databases**</DNT>.
    2. En el menú desplegable **<DNT>Entity type</DNT>**, seleccione <DNT>**MySQL instance**</DNT> y luego haga clic en <DNT>**Apply**</DNT>.
    3. Seleccione su base de datos MySQL de la lista de entidades.
  </Step>
</Steps>
