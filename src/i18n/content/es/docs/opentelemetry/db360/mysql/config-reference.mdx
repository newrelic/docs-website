Esta referencia proporciona configuraciones YAML completas para el monitoreo de MySQL con el Collector de la distribución de OpenTelemetry de New Relic (NRDOT). Estas configuraciones con todas las características incluyen todas las métricas disponibles y los ajustes avanzados del procesador para entornos de producción en despliegues autohospedados y de Amazon RDS.

<Callout variant="important">
  **¿Desea comenzar rápidamente?** Estas son configuraciones avanzadas para uso en producción. Si está configurando el monitoreo de MySQL por primera vez, recomendamos comenzar con la configuración estándar en nuestras guías de configuración y volver a estas configuraciones completas una vez que haya verificado la funcionalidad básica.
</Callout>

## Autoalojado [#hosted]

    Esta configuración habilita el catálogo completo de métricas de MySQL que el receptor `nrmysql` puede producir.

    ```yaml
    extensions:
      health_check:

    receivers:
      otlp:
        protocols:
          grpc:
          http:

      nrmysql:
        endpoint: "<YOUR_DB_HOST>:<YOUR_DB_PORT>"
        transport: tcp
        username: "<YOUR_DB_USERNAME>"
        password: "<YOUR_DB_PASSWORD>"
        allow_native_passwords: true
        collection_interval: 15s
        initial_delay: 1s
        # "procedure" collects EXPLAIN plans for write statements (UPDATE/DELETE/INSERT/REPLACE)
        # without granting DML to the monitoring user, via a SQL SECURITY DEFINER procedure.
        # Falls back to "inline" (default) automatically if the procedure is absent for a schema.
        # Requires one-time setup per schema -- see Prerequisites -> DML query plan collection.
        explain_mode: procedure
        statement_events:
          digest_text_limit: 4096
          time_limit: 24h
          limit: 500
        query_sample_collection:
          max_rows_per_query: 100
          # APM-DB correlation: surfaces the nr_service_guid SQL comment tag (e.g. injected by
          # transaction_tracer.sql_metadata_comments in the Java agent) as db.query.comment_tags /
          # db.query.comment_tags.nr_service_guid. Empty list by default -- nothing is extracted
          # unless the key is explicitly allow-listed here.
          allowed_comment_keys: [nr_service_guid]
        top_query_collection:
          lookback_time: 60
          max_query_sample_count: 5000
          top_query_count: 200
          collection_interval: 60s
          query_plan_cache_size: 1000
          query_plan_cache_ttl: 1h
          allowed_comment_keys: [nr_service_guid]
        events:
          db.server.query_sample:
            enabled: true
          db.server.top_query:
            enabled: true
          db.server.query_plan:
            enabled: true
        resource_attributes:
          db.system.version:
            enabled: true
        metrics:
          # ---- Default-enabled metrics (kept explicit for visibility) ----
          mysql.buffer_pool.data_pages:
            enabled: true
          mysql.buffer_pool.limit:
            enabled: true

            enabled: true
          mysql.index.io.wait.time:
            enabled: true
          mysql.locks:

          mysql.opened_resources:

      batch:

      resource_detection:
        detectors: ["system"]
        system:
          hostname_sources: ["os"]
          resource_attributes:
            host.id:
              enabled: true

      resource_detection/cloud:
        detectors: ["gcp", "ec2", "azure"]
        timeout: 2s
        override: true

      resource_detection/env:
        detectors: ["env"]
        timeout: 2s
        override: true

    exporters:
      otlp/newrelic:
        endpoint: "<YOUR_NEWRELIC_OTLP_ENDPOINT>"
        headers:
          api-key: "<YOUR_NEWRELIC_LICENSE_KEY>"
        compression: gzip
        sending_queue:
          enabled: true
          sizer: bytes
          queue_size: 100_000_000
          num_consumers: 10
          batch:
            sizer: bytes
            max_size: 1_000_000
            min_size: 0
            flush_timeout: 5s
        retry_on_failure:
          enabled: true
          initial_interval: 5s
          max_interval: 30s
          max_elapsed_time: 300s

    service:
      telemetry:
        metrics:
          level: none

      extensions: [health_check]

      pipelines:
        metrics/mysql:
          receivers: [nrmysql]
          processors:
            - resource_detection
            - resource_detection/cloud
            - resource_detection/env
            - batch
          exporters: [otlp/newrelic]

        logs/mysql:
          receivers: [nrmysql]
          processors:
            - resource_detection
            - resource_detection/cloud
            - resource_detection/env
            - batch
          exporters: [otlp/newrelic]

        traces:
          receivers: [otlp]
          processors: [transform, resource_detection, resource_detection/cloud, resource_detection/env, batch]
          exporters: [otlp/newrelic]

        metrics:
          receivers: [otlp]
          processors: [resource_detection, resource_detection/cloud, resource_detection/env, batch]
          exporters: [otlp/newrelic]

        logs:
          receivers: [otlp]
          processors: [resource_detection, resource_detection/cloud, resource_detection/env, batch]
          exporters: [otlp/newrelic]

Tenga en cuenta que la configuración completa de características ingiere más datos que una configuración estándar, lo que puede aumentar la factura total.
    </Callout>
