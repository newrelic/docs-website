Obtenga información valiosa y exhaustiva sobre el rendimiento de la base de datos Oracle con el monitoreo de base de datos, el análisis de consultas y las métricas de estado del sistema mediante el Collector de New Relic Distribution of OpenTelemetry (NRDOT), que se ejecuta como un contenedor hermano de una instancia de base de datos Oracle que ya se está ejecutando en Docker.

<Callout variant="tip" title="Instalación guiada">
Para instalar a través de la UI de New Relic en su lugar, vaya a <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; Oracle (Database 360)](https://onenr.io/0kjnebKW7Ro)**</DNT>. Esta página solo cubre la ruta de instalación de Docker.
</Callout>

<Callout variant="tip">
¿Busca automatizar esto a escala en su lugar? Consulte la [instalación de Ansible](/docs/opentelemetry/db360/oracle/ansible), la [instalación de Chef](/docs/opentelemetry/db360/oracle/chef) o la [instalación del chart de Helm](/docs/opentelemetry/db360/oracle/helm) para Kubernetes.
</Callout>

## Requisitos previos [#prerequisites]

Antes de comenzar, cerciorar de tener lo siguiente:

* Docker instalado en el host.
* Un contenedor de base de datos Oracle que ya esté en ejecución (base de datos Oracle `19c` o posterior), con `sqlplus` disponible en su interior.
* La contraseña de `sys` para ese contenedor.
* Una [clave de licencia](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key) de New Relic válida.
* Conectividad de red desde el contenedor del recolector al [extremo OTLP de New Relic](/docs/opentelemetry/best-practices/opentelemetry-otlp).

<Steps>
<Step>
## Configurar el usuario de la base de datos y otorgar privilegios [#database-user]

Cree un usuario de monitoreo y concédale las vistas necesarias para la recopilación de métricas, consultas y eventos ejecutando SQL en su contenedor de Oracle con `docker exec`. Elija la pestaña que coincida con su despliegue, ya sea una base de datos de contenedor (CDB) multiinquilino o una única base de datos conectable (PDB):

<CollapserGroup>
<Collapser id="docker-cdb" title="Base de datos de contenedor (CDB)">
Esto crea un usuario común (necesario para usar el prefijo `C##`) y le concede visibilidad en cada PDB bajo la CDB. Reemplace `<YOUR_ORACLE_CONTAINER_NAME>`, `<YOUR_SYS_PASSWORD>`, `<YOUR_DB_USERNAME>` y `<YOUR_DB_PASSWORD>` con sus propios valores:

```bash
docker exec -i <YOUR_ORACLE_CONTAINER_NAME> sqlplus sys/'<YOUR_SYS_PASSWORD>' as sysdba << 'EOF'
ALTER SESSION SET CONTAINER = CDB$ROOT;

-- Create the common user and set container-data visibility
CREATE USER c##<YOUR_DB_USERNAME> IDENTIFIED BY "<YOUR_DB_PASSWORD>" CONTAINER=ALL;
GRANT CREATE SESSION TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
ALTER USER c##<YOUR_DB_USERNAME> SET CONTAINER_DATA=ALL CONTAINER=CURRENT;

-- Grant system and dynamic performance views
GRANT SELECT ON V_$INSTANCE                   TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON V_$DATABASE                   TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON V_$CONTAINERS                 TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON V_$DATAFILE                   TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON V_$SYSSTAT                    TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON V_$CON_SYSSTAT                TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON V_$SYSMETRIC                  TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON V_$CON_SYSMETRIC              TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON V_$SESSION                    TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON V_$RESOURCE_LIMIT             TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON V_$OSSTAT                     TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON V_$SGAINFO                    TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON V_$ROWCACHE                   TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON V_$PARAMETER                  TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON CDB_TABLESPACE_USAGE_METRICS  TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON CDB_TABLESPACES               TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON DBA_DATA_FILES                TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON DBA_FREE_SPACE                TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON DBA_RECYCLEBIN                TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON V_$SQL                        TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON V_$SQL_PLAN_STATISTICS_ALL    TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON V_$LOCK                       TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON V_$SESSION_EVENT              TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON DBA_PROCEDURES                TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON DBA_OBJECTS                   TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON V_$PDBS                       TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON CDB_SERVICES                  TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON CDB_DATA_FILES                TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON CDB_PROCEDURES                TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON CDB_OBJECTS                   TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON V_$ASM_DISKGROUP_STAT          TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;
GRANT SELECT ON V_$ASM_DISK_STAT               TO c##<YOUR_DB_USERNAME> CONTAINER=ALL;

EXIT;
EOF
```

<Callout variant="tip">
Oracle requiere el prefijo `C##` para los usuarios comunes. Los dos últimos permisos (`V_$ASM_DISKGROUP_STAT` y `V_$ASM_DISK_STAT`) solo son necesarios si desea recopilar [métricas de disco y grupos de discos de ASM](/docs/opentelemetry/db360/oracle/metrics-reference/#asm). Omítalos si no utiliza ASM.
</Callout>
</Collapser>

<Step>
## Asegurar la conectividad de red de Docker [#network]

Cree una red compartida definida por el usuario (si aún no tiene una) y conecte el contenedor de Oracle a ella, para que el contenedor del recolector pueda resolverla por nombre:

```bash
docker network create <YOUR_DOCKER_NETWORK> 2>/dev/null || true
docker network connect <YOUR_DOCKER_NETWORK> <YOUR_ORACLE_CONTAINER_NAME> 2>/dev/null || true
```

<Callout variant="tip">
Es seguro volver a ejecutar ambos comandos: `|| true` ignora los errores &quot;already exists&quot; o &quot;already connected&quot; de una ejecución anterior.
</Callout>
</Step>

### Parámetro de configuración [#configuration-parameters]

| Parámetro                                             | Descripción                                                                                                                                                                  |
| ----------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<YOUR_ORACLE_CONTAINER_NAME>`                        | El nombre (o nombre de host de Docker que se puede resolver mediante DNS) del contenedor de base de datos Oracle en ejecución.                                               |
| `<YOUR_DB_USERNAME>`                                  | El usuario de monitoreo que creó en [Configurar el usuario de la base de datos y otorgar privilegios](#database-user) (el prefijo `C##` se agrega automáticamente para CDB). |
| `<YOUR_DB_PASSWORD>`                                  | La contraseña del usuario de monitoreo que creó en [Configurar el usuario de la base de datos y otorgar privilegios](#database-user).                                        |
| `<YOUR_CDB_SERVICE_NAME>` / `<YOUR_PDB_SERVICE_NAME>` | El nombre del servicio de Oracle para la CDB o PDB.                                                                                                                          |
| `<YOUR_NEWRELIC_OTLP_ENDPOINT>`                       | El extremo OTLP de New Relic. Para obtener más información, consulte [Extremos OTLP de New Relic](/docs/opentelemetry/best-practices/opentelemetry-otlp/).                   |
| `<YOUR_NEWRELIC_LICENSE_KEY>`                         | Su [clave de licencia](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key) de New Relic.                                                                           |
</Step>

<Step>
## Iniciar el contenedor del NRDOT Collector [#start]

Ejecute el recolector en la misma red de Docker que el contenedor de Oracle:

```bash
docker run -d \
  --name nrdot-collector \
  --network <YOUR_DOCKER_NETWORK> \
  --platform linux/amd64 \
  -v "$PWD/oracle-config.yaml:/etc/nrdot-collector/oracle-config.yaml" \
  newrelic/nrdot-collector:latest \
  --config /etc/nrdot-collector/oracle-config.yaml
```

<Callout variant="tip">
`--platform linux/amd64` evita incompatibilidades de arquitectura en Apple Silicon y otros hosts ARM64 donde la propia imagen de Oracle normalmente solo se distribuye para AMD64. Omítalo si el host y las imágenes ya son nativos de AMD64.
</Callout>

Confirme que el contenedor del recolector se esté ejecutando:

```bash
docker ps --filter name=nrdot-collector
```

Si no se está ejecutando, revise sus logs en busca de errores. Las causas más comunes son problemas de indentación de YAML en `oracle-config.yaml` o un contenedor Oracle inalcanzable:

```bash
docker logs nrdot-collector
```

<Callout variant="tip">
Después de cambiar `oracle-config.yaml`, reinicie el contenedor para aplicar los cambios:

```bash
docker restart nrdot-collector
```
</Callout>
</Step>

<Step>
## Encuentra y utiliza tus datos [#find-use-data]

Una vez que se estén recopilando sus datos, puede acceder a un monitoreo integral de Oracle Database a través de la UI de New Relic.

Para encontrar su entidad de base de datos Oracle en New Relic:

1. Vaya a <DNT>**[https://one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT>.
2. Establezca los criterios de búsqueda como <DNT>`instrumentation.provider = opentelemetry`</DNT>.
3. Seleccione su base de datos Oracle de la lista de entidades.
</Step>
</Steps>
