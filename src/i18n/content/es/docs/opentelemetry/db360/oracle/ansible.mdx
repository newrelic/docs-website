Puede instalar y configurar el Collector de NRDOT para el monitoreo de la base de datos de Oracle mediante el rol de Ansible `newrelic.newrelic_install`. El rol instala el recolector, crea el usuario de la base de datos de monitoreo y configura el recolector en un solo play.

<Callout variant="tip" title="Instalación guiada">
  Para instalar a través de la UI de New Relic en su lugar, vaya a <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; Oracle (Database 360)](https://onenr.io/0kjnebKW7Ro)**</DNT>. Esta página solo cubre la instalación manual.
</Callout>

<Steps>
  <Step>
    ## Requisitos previos [#prerequisites]

    * Una cuenta de New Relic con una [clave de licencia](/docs/apis/intro-apis/new-relic-api-keys/#overview-keys) válida.
    * Un [ID de cuenta](/docs/accounts/accounts-billing/account-structure/account-id) de New Relic.
    * Oracle Database 19c o posterior.
    * Ansible Core 2.13 o 2.14, Python 3.10 y las colecciones `ansible.windows` y `ansible.utils`.
    * Para Oracle autohospedado: Oracle Linux 7, 8 o 9, con acceso SSH (con reenvío de agente) al host de la base de datos de Oracle donde el usuario de SSH puede ejecutar `sudo su - oracle` sin un símbolo de contraseña.
    * Para Oracle en AWS RDS: un host del recolector que ejecute Debian/Ubuntu o CentOS/RHEL/OEL.
    * Para la base de datos Oracle Autonomous Database (ADB): un host recolector que ejecute Debian/Ubuntu o CentOS/RHEL/OEL, con Oracle Instant Client (`sqlplus`) instalado y en `PATH`; la IP de salida de cada instancia permitida en la lista de control de acceso de ADB; y la Oracle Wallet de cada instancia descargada y descomprimida en un directorio propio en el host objetivo.
  </Step>

  <Step>
    ## Instale el rol [#install-role]

    ```bash
    ansible-galaxy install newrelic.newrelic_install
    ```
  </Step>

  <Step>
    ## Configure el playbook [#configure]

    <CollapserGroup>
      <Collapser id="ansible-host" title="Base de datos Oracle autohospedada">
        Este rol monitorea una o más instancias de la base de datos Oracle (cada una accesible a través de SSH) desde un único recolector. En lugar de un único conjunto de host/contenedor/credenciales, lee un archivo de instancias (YAML) que ya debe existir en el host objetivo, que enumera cada instancia a monitorear, y opcionalmente un archivo de secretos para fijar las contraseñas del usuario de monitoreo en lugar de generarlas automáticamente. Consulte la [instalación de la CLI](/docs/opentelemetry/db360/oracle/cli/#install) para conocer los formatos de archivo exactos.

        Cree un archivo denominado `playbook.yml` y copie el siguiente contenido en él. Establezca `targets` en `oracle-otel` y reemplace los valores del marcador de posición por los suyos:

        ```yaml
        - name: Install New Relic NRDOT for Oracle Database
          hosts: all
          roles:
            - role: newrelic.newrelic_install
          vars:
            targets:
              - oracle-otel
          environment:
            NEW_RELIC_API_KEY: <API key>
            NEW_RELIC_ACCOUNT_ID: <Account ID>
            NEW_RELIC_REGION: <Region>
            NR_CLI_ORACLE_INSTANCES_FILE: <path to the instances YAML file on the target host>
            NR_CLI_ORACLE_SECRETS_FILE: <optional path to a secrets file pinning monitoring passwords, on the target host>
            NR_CLI_ORACLE_CONFIG_PRESET: <1 Basic, 2 Advanced, default 1>
        ```

        <Callout variant="tip">
          Para habilitar el logging de depuración, agregue `verbosity: "debug"` debajo de `vars` en el playbook.
        </Callout>

Cree un archivo denominado `playbook.yml` y copie el siguiente contenido en él. Establezca `targets` en `oracle-otel-rds` y reemplace los valores de los marcadores de posición por los suyos:

        ```yaml
        - name: Install New Relic NRDOT for Oracle Database on RDS
          hosts: all
          roles:
            - role: newrelic.newrelic_install
          vars:
            targets:
              - oracle-otel-rds
          environment:
            NEW_RELIC_API_KEY: <API key>
            NEW_RELIC_ACCOUNT_ID: <Account ID>
            NEW_RELIC_REGION: <Region>
            NR_CLI_ORACLE_INSTANCES_FILE: <path to the instances YAML file on the target host>
            NR_CLI_ORACLE_SECRETS_FILE: <path to the secrets file (KEY=VALUE per instance) on the target host>
            NR_CLI_ORACLE_CONFIG_PRESET: <1 Basic, 2 Advanced, default 1>
        ```
