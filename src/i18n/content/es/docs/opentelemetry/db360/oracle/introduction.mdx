Obtenga información valiosa y detallada sobre el rendimiento de su Oracle Database con nuestra solución de monitoreo basada en OpenTelemetry. Rastree métricas de bases de datos, analice el rendimiento de las consultas, monitoree el uso de recursos y correlacione el rendimiento de la base de datos con sus aplicaciones.

Este enfoque basado en NRDOT complementa nuestra actual On-Host Integration (OHI) al aprovechar los estándares de OpenTelemetry para el monitoreo de bases de datos, lo que facilita la integración con su stack de observabilidad existente.

A diferencia de las integraciones en el host, NRDOT opera de forma independiente del agente de infraestructura. No requiere el agente de infraestructura para recopilar telemetría de la base de datos. NRDOT también incluye capacidades nativas de monitoreo de host, por lo que puede elegir:

* Use el agente de infraestructura para el monitoreo de hosts junto con NRDOT para el monitoreo de bases de datos, o
* Utilice NRDOT para monitorear tanto la base de datos como el host.

## Capacidades [#capabilities]

* **Estándares de OpenTelemetry**: se integra a la perfección con las herramientas de observabilidad existentes
* **Métricas integrales**: información valiosa y detallada sobre el rendimiento de la base de datos, los eventos de espera y el uso de recursos
* **Información valiosa a nivel de consulta**: identifique y analice las consultas de rendimiento lento y la actividad de la sesión
* **Despliegue flexible**: funciona con entornos CDB/PDB en el host y Amazon RDS
* **Correlación de APM**: conecte el rendimiento de la base de datos a las trazas de la aplicación

## Elija su ruta de instalación [#choose]

Puede instalar el NRDOT Collector para el monitoreo de Oracle Database de las siguientes maneras:

* Entornos autohospedados: instalación manual en su propia infraestructura

  * [Base de datos de contenedor (CDB) en el host](/docs/opentelemetry/db360/oracle/host-cdb): monitoree una base de datos de contenedor completa, incluidas todas las bases de datos conectables que contiene.
  * [Base de datos conectable (PDB) en el host](/docs/opentelemetry/db360/oracle/host-pdb): monitoree una base de datos conectable individual.

* Entornos de AWS RDS: monitoreo de Oracle Database administrado en la nube
  * [Monitoreo de RDS](/docs/opentelemetry/db360/oracle/rds): monitoree una instancia de base de datos Oracle que se ejecuta en Amazon RDS.

* Entornos de Oracle Cloud: monitoreo de Oracle Database completamente administrado
  * [Monitoreo de Autonomous Database (ADB)](/docs/opentelemetry/db360/oracle/adb): monitoree una instancia de Oracle Autonomous Database.

* [New Relic CLI](/docs/opentelemetry/db360/oracle/cli): instale y configure el recolector con un solo comando

* [Ansible](/docs/opentelemetry/db360/oracle/ansible): instale y configure el recolector a escala mediante el rol de Ansible `newrelic.newrelic_install`

* [Chef](/docs/opentelemetry/db360/oracle/chef): instale y configure el recolector a escala usando el cookbook de Chef `newrelic-install`

* [Chart de Helm](/docs/opentelemetry/db360/oracle/helm): instale y configure el monitoreo de la base de datos Oracle en Kubernetes usando el chart de Helm `oracle-otel`

* [Docker](/docs/opentelemetry/db360/oracle/docker): ejecute el recolector como un contenedor hermano de una instancia de base de datos de Oracle que ya se ejecuta en Docker

## Instalación guiada [#ui-install]

La instalación guiada está disponible en <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; Oracle (Database 360)](https://onenr.io/0kjnebKW7Ro)**</DNT>. La UI proporciona un flujo de trabajo guiado de extremo a extremo.

## Instalación de un vistazo [#at-a-glance]

1. Verifique la compatibilidad y reúna los requisitos previos.
2. Instalar el NRDOT Collector.
3. Configurar el usuario de monitoreo.
4. Configurar el NRDOT Collector.
5. Reinicie el Collector NRDOT.
6. Verifique que los datos estén fluyendo a New Relic.
