Monitoree el rendimiento de la base de datos de Oracle con métricas exhaustivas recopiladas por el NRDOT Collector. De forma predeterminada, New Relic recopila las métricas y los eventos a nivel de consulta a los que se hace referencia en la sección [Métricas y eventos predeterminados](#default). Puede mejorar el monitoreo habilitando las métricas deseadas que se enumeran en la sección [Métricas de características completas](#full-feature).
