Obtenga información valiosa y completa sobre el rendimiento de la base de datos conectable (PDB) de Oracle con el monitoreo de la base de datos, el análisis de consultas y las métricas de estado del sistema mediante el recolector New Relic Distribution of OpenTelemetry (NRDOT).

<Callout variant="tip" title="Instalación guiada">
Para instalar a través de la UI de New Relic en su lugar, vaya a <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; Oracle (Database 360)](https://onenr.io/0kjnebKW7Ro)**</DNT>. Esta página solo cubre la instalación manual.
</Callout>

<Callout variant="tip">
Si necesita monitorear toda la base de datos de contenedor en lugar de una base de datos conectable individual, consulte la [instrumentación de CDB](/docs/opentelemetry/db360/oracle/host-cdb).
</Callout>

## Requisitos previos [#prerequisites]

Antes de comenzar, cerciorar de tener lo siguiente:

* Una [clave de licencia](/docs/apis/intro-apis/new-relic-api-keys/#ingest-license-key)de New Relic válida
* Arquitectura compatible: Linux con AMD64 y ARM64
* Conectividad de red al [extremo OTLP de New Relic](/docs/opentelemetry/best-practices/opentelemetry-otlp)
* Oracle Database `19c` o posterior

<Step>
## Instalar NRDOT Collector [#installation]

Seleccione el método de distribución de instalación adecuado para su entorno Linux:

<CollapserGroup>
<Collapser title="Para la arquitectura AMD64" id="amd">
* Para sistemas Debian/Ubuntu, ejecute:

  ```bash
  NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_amd64.deb" --output nrdot-collector.deb && sudo dpkg -i nrdot-collector.deb
  ```

* Para sistemas RHEL/CentOS/OEL, ejecute:

  ```bash
  NRDOT_VERSION=$(curl -s https://api.github.com/repos/newrelic/nrdot-collector-releases/releases/latest | grep '"tag_name":' | awk -F'"' '{print $4}') && curl -L "https://github.com/newrelic/nrdot-collector-releases/releases/download/${NRDOT_VERSION}/nrdot-collector_${NRDOT_VERSION}_linux_x86_64.rpm" --output nrdot-collector.rpm && sudo rpm -ivh nrdot-collector.rpm
  ```
</Collapser>

<Step>
## Configurar el usuario de la base de datos [#database-user]

Cree un usuario de monitoreo con los privilegios necesarios para la instancia de Oracle Database PDB.

1. Ejecute la siguiente declaración como SYS antes de crear el usuario o ejecutar cualquier concesión:
   ```sql
   ALTER SESSION SET CONTAINER = "<YOUR_PDB>";
   ```
2. Ejecute las siguientes sentencias como SYS dentro de su PDB objetivo para crear un usuario de monitoreo local:
   ```sql
   CREATE USER <YOUR_DB_USERNAME> IDENTIFIED BY "<YOUR_DB_PASSWORD>";
   GRANT CREATE SESSION TO <YOUR_DB_USERNAME>;
   ```
</Step>

<Step>

GRANT SELECT ON V_$SYSMETRIC                  TO <YOUR_DB_USERNAME>;
GRANT SELECT ON V_$SESSION                    TO <YOUR_DB_USERNAME>;

GRANT SELECT ON V_$OSSTAT                     TO <YOUR_DB_USERNAME>;
GRANT SELECT ON V_$SGAINFO                    TO <YOUR_DB_USERNAME>;
GRANT SELECT ON V_$ROWCACHE                   TO <YOUR_DB_USERNAME>;
GRANT SELECT ON V_$PARAMETER                  TO <YOUR_DB_USERNAME>;

GRANT SELECT ON DBA_TABLESPACES               TO <YOUR_DB_USERNAME>;
GRANT SELECT ON DBA_DATA_FILES                TO <YOUR_DB_USERNAME>;
GRANT SELECT ON DBA_FREE_SPACE                TO <YOUR_DB_USERNAME>;
GRANT SELECT ON DBA_RECYCLEBIN                TO <YOUR_DB_USERNAME>;
GRANT SELECT ON V_$SQL            TO <YOUR_DB_USERNAME>;
GRANT SELECT ON V_$SQL_PLAN_STATISTICS_ALL       TO <YOUR_DB_USERNAME>;
GRANT SELECT ON V_$LOCK           TO <YOUR_DB_USERNAME>;
GRANT SELECT ON V_$SESSION_EVENT  TO <YOUR_DB_USERNAME>;
GRANT SELECT ON DBA_PROCEDURES    TO <YOUR_DB_USERNAME>;

</Callout>
</Step>

<Step>
## Actualizar la configuración de NRDOT Collector [#update]

Actualice la configuración del NRDOT Collector para utilizar el archivo `oracle-config.yaml`:

```bash
sudo sed -i 's|OTELCOL_OPTIONS="--config=/etc/nrdot-collector/config.yaml"|OTELCOL_OPTIONS="--config=/etc/nrdot-collector/oracle-config.yaml"|' /etc/nrdot-collector/nrdot-collector.conf
```

<Callout variant="tip">
Tú también puedes:

* [Configurar múltiples receptores](/docs/opentelemetry/db360/oracle/multi-receiver): para monitorear múltiples instancias de base de datos Oracle desde un recolector.
* [Configurar el receptor de consultas SQL](/docs/opentelemetry/db360/capabilities/sql-query-receiver/): para recopilar métricas personalizadas de la base de datos Oracle.
* [Vincule su Oracle Database con APM](/docs/opentelemetry/db360/capabilities/db-apm): para correlacionar el rendimiento de la aplicación con las operaciones de la base de datos. Esto le permite ver exactamente qué aplicaciones están generando cargas de trabajo de base de datos específicas.
* [Configurar la gestión de secretos](/docs/opentelemetry/db360/capabilities/db-apm/#secret-management): para administrar de forma segura información confidencial, como las credenciales de bases de datos. Esto ayuda a mejorar la seguridad de su configuración de monitoreo al evitar la codificación rígida de datos sensibles en los archivos de configuración.
</Callout>
</Step>

<Step>
## Reiniciar NRDOT Collector [#restart-collector]

Después de actualizar la configuración, reinicie el NRDOT Collector:

```bash
sudo systemctl restart nrdot-collector.service
sudo systemctl status nrdot-collector.service
```

<Callout variant="tip">
Reinicie siempre el NRDOT Collector después de realizar cambios de configuración para garantizar que los nuevos ajustes surtan efecto.
</Callout>
</Step>

<Step>
## Encuentra y utiliza tus datos [#find-use-data]

Una vez que se estén recopilando sus datos, puede acceder a un monitoreo integral de Oracle Database a través de la UI de New Relic.

Para encontrar su entidad de base de datos Oracle en New Relic:

1. Vaya a <DNT>**[https://one.newrelic.com](https://one.newrelic.com) &gt; All Capabilities &gt; Databases**</DNT>.
2. Establezca los criterios de búsqueda como <DNT>`instrumentation.provider = opentelemetry`</DNT>.
3. Seleccione su base de datos Oracle de la lista de entidades.
</Step>
</Steps>
