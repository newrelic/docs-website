Puede instalar y configurar el Collector de NRDOT para el monitoreo de la base de datos de Oracle mediante el libro de recetas de Chef `newrelic-install`. El libro de recetas instala el recolector, crea el usuario de la base de datos de monitoreo y configura el recolector cuando ejecuta la receta `newrelic-install::default`.

<Callout variant="tip" title="Instalación guiada">
  Para instalar a través de la UI de New Relic en su lugar, vaya a <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; Oracle (Database 360)](https://onenr.io/0kjnebKW7Ro)**</DNT>. Esta página solo cubre la instalación manual.
</Callout>

<Steps>
  <Step>
    ## Requisitos previos [#prerequisites]

    * Una cuenta de New Relic con una [clave de licencia](/docs/apis/intro-apis/new-relic-api-keys/#overview-keys) válida.
    * Un [ID de cuenta](/docs/accounts/accounts-billing/account-structure/account-id) de New Relic.
    * Oracle Database 19c o posterior.
    * Chef 15 o posterior.
    * Para Oracle autohospedado: Oracle Linux 7, 8 o 9, con acceso SSH (con reenvío de agente) al host de la base de datos de Oracle donde el usuario de SSH puede ejecutar `sudo su - oracle` sin un símbolo de contraseña.
    * Para Oracle en AWS RDS: un host del recolector que ejecute Debian/Ubuntu o CentOS/RHEL/OEL.
    * Para la base de datos autónoma de Oracle (ADB): un host del recolector que ejecute Debian/Ubuntu o CentOS/RHEL/OEL, con Oracle Instant Client (`sqlplus`) instalado y en `PATH`; la IP de salida de cada instancia permitida en su lista de control de acceso de ADB; y la Oracle Wallet de cada instancia descargada y descomprimida en su propio directorio en el nodo.
  </Step>

  <Step>
    ## Descargar el cookbook de Chef [#download-cookbook]

    Descargue el [cookbook de Chef](https://supermarket.chef.io/cookbooks/newrelic-install) `newrelic-install` desde Chef Supermarket al directorio del repositorio de Chef:

    ```bash
    knife supermarket install newrelic-install
    ```
  </Step>

  <Step>
    ## Reemplace los atributos predeterminados [#configure]

    Reemplace los atributos predeterminados en `attributes/default.rb` con los detalles de la cuenta:

    <CollapserGroup>
      <Collapser id="chef-host" title="Base de datos Oracle autohospedada">
        Este libro de recetas monitorea una o más instancias de base de datos de Oracle (cada una accesible a través de SSH) desde un único recolector. En lugar de un único conjunto de host/contenedor/credenciales, lee un archivo de instancias (YAML) que ya debe existir en el nodo, que enumera cada instancia a monitorear, y, opcionalmente, un archivo de secretos para fijar las contraseñas del usuario de monitoreo en lugar de generarlas automáticamente. Consulte la [instalación de la CLI](/docs/opentelemetry/db360/oracle/cli/#install) para conocer los formatos de archivo exactos.

        ```ruby
        default['newrelic_install']['NEW_RELIC_API_KEY']    = <API key>
        default['newrelic_install']['NEW_RELIC_ACCOUNT_ID'] = <Account ID>
        default['newrelic_install']['NEW_RELIC_REGION']     = <Region>
        default['newrelic_install']['targets'] = [
          'nrdot-collector-oracle'
        ]
        default['newrelic_install']['env']['NR_CLI_ORACLE_INSTANCES_FILE'] = <path to the instances YAML file on the node>
        default['newrelic_install']['env']['NR_CLI_ORACLE_SECRETS_FILE']   = <optional path to a secrets file pinning monitoring passwords, on the node>
        default['newrelic_install']['env']['NR_CLI_ORACLE_CONFIG_PRESET']  = <1 Basic, 2 Advanced, default 1>
        # See all available targets at: https://github.com/newrelic/chef-install
        ```

      <Collapser id="chef-rds" title="Oracle Database en AWS RDS">
        Este libro de recetas monitorea uno o más extremos de RDS Oracle desde un único recolector, utilizando el mismo patrón de archivo de instancias/archivo de secretos que el autohospedado (ambos archivos ya deben existir en el nodo).

        ```ruby
        default['newrelic_install']['NEW_RELIC_API_KEY']    = <API key>
        default['newrelic_install']['NEW_RELIC_ACCOUNT_ID'] = <Account ID>
        default['newrelic_install']['NEW_RELIC_REGION']     = <Region>
        default['newrelic_install']['targets'] = [
          'nrdot-collector-oracle-rds'
        ]
        default['newrelic_install']['env']['NR_CLI_ORACLE_INSTANCES_FILE'] = <path to the instances YAML file on the node>
        default['newrelic_install']['env']['NR_CLI_ORACLE_SECRETS_FILE']   = <path to the secrets file (KEY=VALUE per instance) on the node>
        default['newrelic_install']['env']['NR_CLI_ORACLE_CONFIG_PRESET']  = <1 Basic, 2 Advanced, default 1>
        # See all available targets at: https://github.com/newrelic/chef-install
        ```

  <Step>
    ## Cargue el cookbook de Chef [#upload-cookbook]

    Cargue el cookbook de Chef `newrelic-install` en su servidor de Chef:

    ```bash
    knife cookbook upload newrelic-install
    ```
  </Step>

  <Step>
    ## Actualice la lista de ejecución [#run-list]

    Agregue la receta `newrelic-install` a la lista de ejecución de un nodo:

    ```json
    "run_list": [
      "recipe[newrelic-install]"
    ]
    ```
  </Step>
