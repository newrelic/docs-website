Monitoree el rendimiento de su base de datos PostgreSQL utilizando New Relic Distribution of OpenTelemetry (NRDOT) con información valiosa integral sobre las métricas de la base de datos, el rendimiento de las consultas y el estado del sistema.

Este enfoque basado en NRDOT complementa nuestra actual On-Host Integration (OHI) al aprovechar los estándares de OpenTelemetry para el monitoreo de bases de datos, lo que facilita la integración con su stack de observabilidad existente.

A diferencia de las integraciones en el host, NRDOT opera de forma independiente del agente de infraestructura. No requiere el agente de infraestructura para recopilar telemetría de la base de datos. NRDOT también incluye capacidades nativas de monitoreo de host, por lo que puede elegir:

* Use el agente de infraestructura para el monitoreo de hosts junto con NRDOT para el monitoreo de bases de datos, o
* Utilice NRDOT para monitorear tanto la base de datos como el host.

## Elige tu método de instalación [#install]

Puede instalar el NRDOT Collector para el monitoreo de PostgreSQL de las siguientes maneras:

* **Instalación manual**: configure el recolector en su propia infraestructura

  * [Configuración autohospedada](/docs/opentelemetry/db360/postgresql/hosted)
  * [Configuración de AWS RDS o Aurora](/docs/opentelemetry/db360/postgresql/rds)

* **[New Relic CLI](/docs/opentelemetry/db360/postgresql/cli)**: instale y configure el recolector con un solo comando

* **[Ansible](/docs/opentelemetry/db360/postgresql/ansible)**: instale y configure el recolector a escala usando el rol de Ansible `newrelic.newrelic_install`

* **[Chef](/docs/opentelemetry/db360/postgresql/chef)**: instale y configure el recolector a escala usando el cookbook de Chef de `newrelic-install`

* **[Chart de Helm](/docs/opentelemetry/db360/postgresql/helm)**: instale y configure el monitoreo de PostgreSQL en Kubernetes usando el chart de Helm de `postgresql-otel`

* **[Docker](/docs/opentelemetry/db360/postgresql/docker)**: ejecute el recolector como un contenedor hermano de una instancia de PostgreSQL que ya se ejecuta en Docker

## Instalación guiada [#guided-installation]

La instalación guiada está disponible en <DNT>**[one.newrelic.com &gt; Integrations &amp; Agents &gt; PostgreSQL (Database 360)](https://onenr.io/00jlEJKbdQW)**</DNT>. La UI proporciona un flujo de trabajo guiado de extremo a extremo.

## Instalación de un vistazo [#glance]

1. Verifique la compatibilidad y reúna los requisitos previos.
2. Instalar el NRDOT Collector.
3. Configurar el usuario de monitoreo.
4. Configurar el NRDOT Collector.
5. Reinicie el Collector NRDOT.
6. Verifique que los datos estén fluyendo a New Relic.
