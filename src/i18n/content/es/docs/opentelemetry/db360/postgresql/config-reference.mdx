Esta referencia proporciona configuraciones YAML completas para el monitoreo de PostgreSQL con el Collector de la distribución de OpenTelemetry de New Relic (NRDOT). Estas configuraciones con todas las características incluyen el catálogo completo de métricas de PostgreSQL para entornos de producción en despliegues autohospedados y de Amazon RDS.

<Callout variant="important">
  **¿Desea comenzar rápidamente?** Estas son configuraciones avanzadas para uso en producción. Si está configurando el monitoreo de PostgreSQL por primera vez, le recomendamos comenzar con la configuración estándar de nuestras guías de configuración y volver a estas configuraciones completas una vez que haya verificado la funcionalidad básica.
</Callout>
