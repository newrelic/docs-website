Como usuario de New Relic, es posible que escriba consultas NRQL complejas de forma repetida en distintos dashboards. Recordar y volver a escribir varias líneas de una consulta cada vez requiere mucho tiempo y es propenso a errores. Cuando los datos cambian y las consultas deben ajustarse, debe actualizar manualmente cada instancia de esa consulta en toda la organización, lo cual se convierte en una carga de mantenimiento significativa.

Las macros de NRQL resuelven este problema al permitirle guardar una expresión de NRQL como un acceso directo reutilizable y con nombre. Puede hacer referencia a una macro en una consulta con el símbolo `$` seguido de su nombre, por ejemplo, `$prod_filter`, y New Relic sustituye la expresión guardada antes de que se ejecute la consulta. Puede usar macros en el [generador de consultas](/docs/query-your-data/explore-query-data/query-builder/introduction-query-builder/) y en los dashboards.

## Qué puede hacer con las macros [#macros-features]

Puede usar las macros de NRQL para:

* **Cree expresiones reutilizables**: convierta una expresión de la consulta NRQL en una macro con un nombre descriptivo, para que no tenga que volver a escribir o recordar la expresión completa cada vez.
* **Reutilice expresiones en todas las cuentas**: las macros son entidades a nivel de organización. Cualquier cuenta de la organización puede usar una macro sin redefinirla, y todos los usuarios con el rol adecuado pueden acceder y usar todas las macros creadas dentro de la organización.
* **Actualice las consultas de forma centralizada**: cuando edita una macro, todas las consultas que usan esa macro reflejan automáticamente el cambio, sin que tenga que buscar y actualizar cada consulta de forma individual.

## Requisitos previos [#prerequisites]

Para usar las macros de NRQL, necesita:

* **Acceso a la cuenta**: acceso a una cuenta de la organización donde desea usar macros. Las macros son entidades a nivel de organización, por lo que, una vez creadas, están disponibles en todas las cuentas de la organización.
* **Conocimientos de NRQL**: conocimientos básicos de la [sintaxis de NRQL](/docs/nrql/get-started/introduction-nrql-how-nrql-works/), ya que la expresión de una macro es una expresión de NRQL.

## Permisos de macro [#macro-permissions]

Antes de crear o usar macros, es importante comprender cómo funcionan los permisos y quién tiene acceso a las macros.

### asociación de organización [#organization-association]

Cada macro es un recurso que pertenece a la organización en la que se creó. Esta asociación es permanente y no se puede cambiar. Las macros no se pueden compartir entre diferentes organizaciones. Si se elimina la organización, la macro también se elimina. Si un usuario se traslada a otra organización, no tendrá acceso a las macros de su organización anterior.

### modelo de licencias actual [#current-permissions-model]

Las macros de New Relic utilizan roles integrados con capacidades CRUD para controlar el acceso. El acceso a las macros es solo a nivel de organización y lo establece un administrador.
