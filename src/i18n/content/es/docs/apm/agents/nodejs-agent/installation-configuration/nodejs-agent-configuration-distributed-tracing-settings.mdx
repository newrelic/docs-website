Esta página describe la configuración del agente de Node.js para el rastreo distribuido, incluidos los encabezados de W3C Trace Context, los controles de muestreo, los eventos de span, Infinite Tracing y la instrumentación del servidor gRPC.

<Callout variant="important">
El rastreo de aplicaciones múltiples ha quedado obsoleto en favor de [Distributed tracing](/docs/enable-distributed-tracing) y se eliminará en una versión futura de agente.
</Callout>

## rastreo distribuido [#dt-main]

[rastreo distribuido](/docs/intro-distributed-tracing) te permite ver el camino que sigue una solicitud a medida que viaja a través de un sistema distribuido. Al configurar a través del archivo de configuración, coloque la siguiente opción en la sección `distributed_tracing` . Está activado de forma predeterminada en Node.js agente 8.3.0 y superior.

<Callout variant="important">
Habilitar rastreo distribuido deshabilita [el rastreo de múltiples aplicaciones](#cross-app-tracing) y tiene efectos en otras características de APM. Antes de habilitar, lea la [guía de transición](/docs/transition-guide-distributed-tracing). Requiere [la versión 4.7.0 o superior del agente Node.js.](/docs/agents/nodejs-agent/installation-configuration/upgrade-nodejs-agent)
</Callout>

Para obtener más información sobre cómo configurar rastreo distribuido, consulte [Habilitar rastreo distribuido para su aplicación Node.js.](/docs/apm/agents/nodejs-agent/installation-configuration/distributed-tracing-nodejs-agent)

<td>
`NEW_RELIC_DISTRIBUTED_TRACING_SAMPLER_ROOT`
</td>
</tr>
</tbody>
</table>

Controla cómo se toman las decisiones de muestreo para los spans raíz-transacciones que no tienen un elemento principal remoto (lo que significa que carecen de un encabezado de rastreo distribuido `traceparent` o `newrelic` entrante). Los valores válidos son:

* `adaptive` (predeterminado): utiliza el algoritmo de muestreo adaptativo integrado de New Relic.
* `always_on`: muestrea todos los spans.
* `always_off`: no muestrea ningún span.
* `trace_id_ratio_based`: muestrea una proporción fija de trazas, determinada de forma determinista por el ID de la traza.

Por ejemplo, para configurar esto en el archivo de configuración, usaría:

```js
distributed_tracing: {
  enabled: true,
  sampler: {
    root: 'always_on'
  }
}
```

Cuando se establece en `trace_id_ratio_based`, también debe proporcionar un `ratio` (un número entre `0` y `1`):

```js
distributed_tracing: {
  enabled: true,
  sampler: {
    root: {
      trace_id_ratio_based: {
        ratio: 0.5
      }
    }
  }
}
```

O a través de variables de entorno:

```ini
NEW_RELIC_DISTRIBUTED_TRACING_SAMPLER_ROOT=trace_id_ratio_based
NEW_RELIC_DISTRIBUTED_TRACING_SAMPLER_ROOT_TRACE_ID_RATIO_BASED_RATIO=0.5
```

Cuando establece esto en `adaptive`, opcionalmente puede anular el objetivo de muestreo (a 1-120 transacciones/minuto) específicamente para este muestreador:

```js
distributed_tracing: {
  enabled: true,
  sampler: {
    root: {
      adaptive: {
        sampling_target: 50
      }
    }
  }
}
```

O a través de variables de entorno:

```ini
NEW_RELIC_DISTRIBUTED_TRACING_SAMPLER_ROOT=adaptive
NEW_RELIC_DISTRIBUTED_TRACING_SAMPLER_ROOT_ADAPTIVE_SAMPLING_TARGET=50
```
</Collapser>

Cuando el encabezado traceparent tiene un indicador de muestreo de `01`, esto controla cómo manejar el muestreo de spans. Los valores de cadena permitidos son:

* `adaptive` (predeterminado): utiliza el algoritmo de muestreo adaptativo integrado de New Relic.
* `always_on`: muestrea todos los spans.
* `always_off`: no muestrea ningún span.
* `trace_id_ratio_based`: muestrea una proporción fija de trazas, determinada de forma determinista por el ID de la traza.

Esta configuración tiene prioridad sobre [`remote_parent_not_sampled`](#dt-sampler-remote-parent-not-sampled) cuando ambas podrían aplicarse.

Por ejemplo, para habilitar esto en el archivo de configuración, usaría:

```js
distributed_tracing: {
  enabled: true,
  sampler: {
    remote_parent_sampled: 'always_on'
  }
}
```

Cuando establece esto en `trace_id_ratio_based`, debe proporcionar un valor de `ratio` de `0`-`1`. Cuando establece esto en `adaptive`, opcionalmente puede anular el objetivo de muestreo específicamente para este muestreador. Para conocer la sintaxis equivalente, consulte los ejemplos de forma de objeto y variable de entorno en [`sampler.root`](#dt-sampler-root) y sustituya `remote_parent_sampled` por `root`.
</Collapser>

## Rastreo infinito

Para activar Infinite Tracing, agregue la configuración a continuación. Establezca la configuración de Infinite Tracing en la sección `infinite_tracing` . Además se debe [habilitar](/docs/apm/agents/nodejs-agent/installation-configuration/distributed-tracing-nodejs-agent) rastreo distribuido. Tenga en cuenta que rastreo distribuido está habilitado de forma predeterminada para las versiones 8.3.0 y posteriores del agente APM de Node.js.
