<Steps>
<Step>
## Agregue el agente a la aplicación [#install]

Añade `newrelic` a tu `package.json`:

```json
"newrelic": "latest"
```

Luego, actualice el Dockerfile o el comando de inicio para cargar el agente. La forma de hacerlo depende de si la aplicación usa CommonJS o ESM:

<CollapserGroup>
<Collapser id="docker-cjs" title="Aplicación que usa CommonJS">
* `ENTRYPOINT`

  ```bash
  ENTRYPOINT ["node", "-r", "newrelic", "YOUR_PROGRAM.js"]
  ```

* `CMD`

  ```bash
  CMD ["node", "-r", "newrelic", "YOUR_PROGRAM.js"]
  ```

* script de npm como `npm start`

  ```bash
  npm pkg set scripts.start="node -r newrelic your-program.js"
  ```
</Collapser>

<Collapser id="docker-esm" title="Aplicación que usa ESM">
* `ENTRYPOINT`

  ```bash
  ENTRYPOINT ["node", "--import", "newrelic/esm-loader.mjs", "-r", "newrelic", "YOUR_PROGRAM.js"]
  ```

* `CMD`

  ```bash
  CMD ["node", "--import", "newrelic/esm-loader.mjs", "-r", "newrelic", "YOUR_PROGRAM.js"]
  ```

* script de npm como `npm start`

  ```bash
  npm pkg set scripts.start="node --import newrelic/esm-loader.mjs -r newrelic your-program.js"
  ```
</Collapser>
</CollapserGroup>

<Callout variant="important">
Si no puede usar el indicador `-r`, agregue `require('newrelic')` como la **primera línea** del módulo principal de la aplicación. No use este enfoque con Babel u otros transpiladores —causará problemas de instrumentación.
</Callout>
</Step>

<Step>
## Configurar el agente [#configure]

Pase el nombre de la aplicación y la clave de licencia como variables de entorno al ejecutar el contenedor. Estas son las únicas opciones de configuración requeridas:

```bash
docker run -e NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
           -e NEW_RELIC_APP_NAME="Your Application Name" \
           YOUR_IMAGE_NAME:latest
```

También puede establecer la configuración mediante directivas `ENV` en el Dockerfile:

```dockerfile
ENV NEW_RELIC_APP_NAME="Your Application Name"
```

Para ver todas las demás opciones de configuración, consulte la [configuración del agente de Node.js](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration).
</Step>

<Step>
## Verifique que los datos estén fluyendo [#verify]

Compile y ejecute el contenedor, y luego envíe al menos dos requests a la aplicación. Espere 2-3 minutos y abra [one.newrelic.com &gt; APM](https://one.newrelic.com/apm) para buscar la aplicación por su nombre.

<Callout variant="tip">
¿No aparece la aplicación? Consulte [Resolución de problemas de la instalación de Node.js](/docs/apm/agents/nodejs-agent/troubleshooting/troubleshooting-your-nodejs-installation).
</Callout>
</Step>
</Steps>
