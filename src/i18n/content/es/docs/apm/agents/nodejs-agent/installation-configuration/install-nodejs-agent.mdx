<Steps>
<Step>
## Instalar el agente [#install]

Instale el paquete del agente en el directorio de la aplicación:

```bash
npm install newrelic
```

<Callout variant="important">
Si utiliza Next.js, consulte la [guía de instrumentación del agente híbrido de Next.js](/docs/apm/agents/nodejs-agent/extend-your-instrumentation/nextjs-instrumentation/).
</Callout>

Luego, copie el archivo de configuración predeterminado del paquete en la raíz de la aplicación:

```bash
cp node_modules/newrelic/newrelic.js .
```
</Step>

<Step>
## Configurar el agente [#configure]

Abra `newrelic.js` en la raíz de la aplicación. Los únicos dos ajustes que **debe** cambiar antes de pasar a producción:

1. Establezca `license_key` en su <InlinePopover type="licenseKey" />.
2. Establezca `app_name` como un nombre significativo para la aplicación.

```js
exports.config = {
  app_name: ['Your Application Name'],
  license_key: 'YOUR_LICENSE_KEY',
  // ...
}
```

También puede configurar estos valores mediante variables de entorno en lugar de editar el archivo:

```bash
NEW_RELIC_APP_NAME="Your Application Name"
NEW_RELIC_LICENSE_KEY="YOUR_LICENSE_KEY"
```
</Step>

<Step>
## Inicie el agente [#start]

Cargue el agente antes de cualquier otra instrucción `require` agregando `-r newrelic` al comando de inicio:

```bash
node -r newrelic ./your-app.js
```

Si la aplicación utiliza ESM, agregue la opción `--import newrelic/esm-loader.mjs`:

```bash
node --import newrelic/esm-loader.mjs -r newrelic ./your-app.js
```

Para una aplicación de Next.js, cargue nuestro agente a través de `NODE_OPTIONS='-r newrelic' next start`.

Si usa Nest.js y el comando `nest start` para iniciar la aplicación, modifique el binario de inicio para cargar el agente de New Relic: `nest start --exec 'node -r newrelic'`. [Aquí hay una aplicación Nest.js de ejemplo](https://github.com/newrelic/newrelic-node-examples/tree/main/nestjs).
</Step>

<Step>
## Verifique que los datos estén fluyendo [#verify]

Si la versión del agente es 14.9.0 o superior, puede ejecutar este comando para validar la configuración:

```bash
npx newrelic validate-config --config-file ./newrelic.js
```

1. Envíe al menos dos requests a la aplicación.

2. Espere 2-3 minutos, luego abra [one.newrelic.com &gt; APM](https://one.newrelic.com/apm) y busque la aplicación por nombre.

<Callout variant="tip">
¿No aparece la aplicación? Consulte [Resolución de problemas de la instalación de Node.js](/docs/apm/agents/nodejs-agent/troubleshooting/troubleshooting-your-nodejs-installation).
</Callout>
</Step>
</Steps>
