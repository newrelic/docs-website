Instale el agente de Node.js de New Relic en Azure App Service para Windows mediante la extensión de sitio de Azure de New Relic.

<Callout variant="important">
Este método es para aplicaciones de Azure App Service **basadas en Windows** desplegadas solo como código. Para contenedores de Linux en Azure, use el [método estándar de instalación de npm](/docs/apm/agents/nodejs-agent/installation-configuration/install-nodejs-agent) y pase `NEW_RELIC_LICENSE_KEY` como configuración de la aplicación. Para una aplicación basada en Linux desplegada manualmente, consulte [Agente de Node.js en Microsoft Azure App Services](/docs/apm/agents/nodejs-agent/hosting-services/nodejs-agent-microsoft-azure).

Para las aplicaciones que se ejecutan en Windows 32, no está disponible el soporte completo de las métricas a nivel de código (ruta de archivo, línea, columna) —la creación de perfiles se reduce solo al nombre de la función.
</Callout>

<Steps>
<Step>
## Instale la extensión del sitio [#install]

1. Desde la página de inicio de Azure, haga clic en **App Services** y seleccione la aplicación objetivo.
2. En el menú izquierdo, en **Development Tools**, seleccione **Extensions**.
3. Haga clic en **+ Add** en la parte superior de la página y, luego, seleccione **New Relic Node Agent** en el desplegable.
4. Acepte los términos legales y haga clic en **OK**.

Una vez instalada, la extensión crea:

* Archivos del agente y dependencias en `C:\home\site\wwwroot\node_modules`
* Una transformación XDT (`applicationHost.xdt`) que inyecta automáticamente `NODE_OPTIONS=-r newrelic` en el inicio de la aplicación
</Step>

<Step>
## Configurar el agente [#configure]

En el menú izquierdo de la aplicación, vaya a **Settings &gt; Environment variables** y agregue:

| Configuración           | Valor                                |
| ----------------------- | ------------------------------------ |
| `NEW_RELIC_LICENSE_KEY` | Su clave de licencia de New Relic    |
| `NEW_RELIC_APP_NAME`    | El nombre que aparecerá en New Relic |

La extensión establece automáticamente `NODE_OPTIONS` en `-r newrelic`. Cualquier `NODE_OPTIONS` definido previamente se restablecerá. Para todas las demás opciones de configuración, consulte la [configuración del agente de Node.js](/docs/apm/agents/nodejs-agent/installation-configuration/nodejs-agent-configuration).
</Step>

<Step>
## Verifique que los datos estén fluyendo [#verify]

Inicie la aplicación y envíe al menos dos requests. Espere 2-3 minutos y abra [one.newrelic.com &gt; APM](https://one.newrelic.com/apm) para buscar la aplicación por su nombre.

Si la extensión no se puede instalar, revise el log en:

```
C:\home\SiteExtensions\NewRelic.Azure.Websites.Extension.NodeAgent\install.log
```

Si el agente está instalado pero no aparecen los datos, revise:

```
C:\home\site\wwwroot\newrelic_agent.log
```

<Callout variant="tip">
¿No aparece la aplicación? Consulte [Resolución de problemas de la instalación de Node.js](/docs/apm/agents/nodejs-agent/troubleshooting/troubleshooting-your-nodejs-installation).
</Callout>
</Step>
</Steps>
