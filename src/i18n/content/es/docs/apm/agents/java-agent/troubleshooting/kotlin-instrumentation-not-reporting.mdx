## Problema

Si falta instrumentación en la aplicación de Kotlin, establezca [los logs del agente en el nivel más detallado](/docs/agents/java-agent/troubleshooting/generating-logs-troubleshooting-java).

Los logs deberían mencionar `ArrayIndexOutOfBoundsException`. Los clientes con la versión del agente 8.2.0 en adelante verán el siguiente mensaje:

```
Unexpected ArrayIndexOutOfBoundsException thrown during class transformation. Try restarting the Java Agent with flag -Dnewrelic.config.class_transformer.clear_return_stacks=true
```

## Solución

Asegúrese de que la versión del agente de Java sea 8.20 o posterior. Si la versión instalada es anterior a 8.20, actualice el agente de Java a una versión compatible (se recomienda la última versión).

Reinicie el agente de Java o la aplicación de Java con la propiedad del sistema:

```
-Dnewrelic.config.class_transformer.clear_return_stacks=true
```
