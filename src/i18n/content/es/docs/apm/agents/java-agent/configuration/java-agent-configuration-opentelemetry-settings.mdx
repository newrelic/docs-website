Los ajustes de OpenTelemetry configuran la integración del agente con la instrumentación de OpenTelemetry y la exportación de datos OTLP.

## OpenTelemetry [#opentelemetry]

A partir de la versión `9.1.0` del agente de Java, se ha agregado compatibilidad con la API de OpenTelemetry Tracing, Metrics y Logs, ofreciendo una experiencia de &quot;lo mejor de ambos mundos&quot; al combinar la visibilidad profunda de New Relic con las señales de OpenTelemetry.

Con esta funcionalidad, las API de OpenTelemetry Tracing, Metrics y Logs pueden usarse para instrumentar directamente su aplicación de forma personalizada, en combinación con las API del agente Java de New Relic, mientras que el agente Java integra todo a la perfección en una experiencia de APM familiar. Además, algunas bibliotecas que proporcionan instrumentación nativa de OpenTelemetry o de biblioteca independiente pueden utilizarse para brindar una visibilidad mejorada de su aplicación.

Las siguientes opciones de configuración determinan qué señales de OpenTelemetry se deben capturar e incorporar a la experiencia de New Relic APM.

```yml
  opentelemetry:
    enabled: false
    logs:
      enabled: true
    metrics:
      enabled: true
      include: "MeterName1,MeterName2"
      exclude: "MeterName3,MeterName4"
    traces:
      enabled: true
      include: "TracerName1,TracerName2"
      exclude: "TracerName3,TracerName4"
```

Establecer en true para permitir que se habiliten las señales individuales de OpenTelemetry, o en false para deshabilitar todas las señales de OpenTelemetry. El valor predeterminado es falso.

Se puede establecer mediante la propiedad del sistema:

```ini
-Dnewrelic.config.opentelemetry.enabled=false
```

Se puede establecer mediante la variable de entorno:

```ini
NEW_RELIC_OPENTELEMETRY_ENABLED
```

Una cadena delimitada por comas de medidores de OpenTelemetry (p. ej. &quot;MeterName1,MeterName2&quot;) cuyas señales deben incluirse. De forma predeterminada, se incluyen todos los Medidores. Esto anulará cualquier exclusión de medidores predeterminada en el agente, reactivándolos efectivamente.

El valor predeterminado es una cadena vacía.

Se puede establecer mediante la propiedad del sistema:

```ini
-Dnewrelic.config.opentelemetry.metrics.include=MeterName1,MeterName2
```

Se puede establecer mediante la variable de entorno:

```ini
NEW_RELIC_OPENTELEMETRY_METRICS_INCLUDE
```
</Collapser>

```ini
-Dnewrelic.config.opentelemetry.metrics.exclude=MeterName3,MeterName4
```

Se puede establecer mediante la variable de entorno:

```ini
NEW_RELIC_OPENTELEMETRY_METRICS_EXCLUDE
```
