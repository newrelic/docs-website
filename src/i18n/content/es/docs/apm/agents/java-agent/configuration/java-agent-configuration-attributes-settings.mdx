La configuración de atributos controla qué atributos recopila el agente y agrega a transacciones, errores, trazas y eventos.

<Callout variant="tip">
Volver al índice completo de ajustes: [configuración del agente de Java](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file)
</Callout>

## Atributo [#attributes]

Para configurar estas opciones, use la sección `attributes`. Para [anularlas](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file#System_Properties), use una propiedad del sistema con el prefijo `newrelic.config.attributes`.

Los atributos son pares de valor principal relacionados con las trazas de la transacción, los errores de traza, <InlinePopover type="browser" />y los eventos de transacción. Hay una sección `attribute` en cada destino. Para obtener más información, consulte [Atributos del agente de Java](/docs/apm/agents/java-agent/attributes/java-agent-attributes), [Habilitación y deshabilitación de atributos](/docs/apm/agents/java-agent/attributes/java-agent-attributes) y [Ejemplos de atributos](/docs/apm/agents/java-agent/attributes/java-agent-attributes).

El informe de atributos se puede configurar a través de los siguientes medios.

YAML:

```yml
attributes:
  http_attribute_mode: both
```

Propiedad del sistema:

```properties
-Dnewrelic.config.attributes.http_attribute_mode=both
```

Variable ambiental:

```properties
NEW_RELIC_ATTRIBUTES_HTTP_ATTRIBUTE_MODE=both
```

Las opciones de configuración son:

* `standard` : Los informes utilizarán estándares (es decir, OTEL) atributo. Se recomienda esta configuración. Minimizará el impacto en la funcionalidad y mantendrá el nivel más bajo de ingesta para los informes de atributos.
* `legacy` : Los informes se realizarán mediante el atributo HTTP reintroducido; esta configuración puede afectar la funcionalidad actual o futura.
* `both` : Esta es la configuración predeterminada, los informes se realizarán mediante el atributo HTTP reintroducido y el atributo OTEL. Esta configuración también aumentará su ingesta de datos.

<Callout variant="important">
Disponible desde [agente de Java versión 8.8.0](/docs/release-notes/agent-release-notes/java-release-notes/java-agent-880). La configuración predeterminada, `both`, aumentará la ingesta de datos. Para evitar un aumento en la ingesta de datos, debe anular el valor predeterminado configurando `http_attribute_mode` en `legacy` o `standard`.
</Callout>
