Los ajustes de JFR configuran el perfilado en tiempo real basado en Java Flight Recorder para el monitoreo continuo del rendimiento de la JVM.

<Callout variant="tip">
Volver al índice completo de ajustes: [configuración del agente de Java](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file)
</Callout>

## JFR (perfiles en tiempo real)

El agente de Java utiliza Java Flight Recorder (JFR) para recopilar datos JVM de alta fidelidad para [la creación de perfiles en tiempo real](/docs/agents/java-agent/features/real-time-profiling-java-using-jfr-metrics/).

Configure el perfilado en tiempo real en la sección `jfr` en el YAML del agente. Estas opciones de configuración se pueden sobrescribir con [propiedades del sistema](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file#System_Properties) con el prefijo `newrelic.config.jfr.` o con [variables de entorno](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file#Environment_Variables) con el prefijo `NEW_RELIC_JFR_`.

Configúrelo en `true` para habilitar [la creación de perfiles en tiempo real con JFR](/docs/agents/java-agent/features/real-time-profiling-java-using-jfr-metrics/). Esta configuración se aplicará dinámicamente y no requiere reiniciar JVM.

<Callout variant="important">
La creación de perfiles en tiempo real con JFR está activada de forma predeterminada en el agente de Java [versión 7.1.0](/docs/release-notes/agent-release-notes/java-release-notes). Si tiene cualquier otro agente versión 7.0.0 o superior, puede activar JFR cambiando el valor a `true`.

El número máximo de eventos de JFR almacenados en la cola de memoria del agente. Aumentar este valor puede ayudar a evitar vacíos en los datos de JFR, pero también aumentará el consumo de recursos del agente. Si la cola es demasiado grande, es posible que se descarten datos si se superan los límites de la canalización del backend. Para obtener más información, consulte los [límites de ingesta de la API de eventos](/docs/data-apis/ingest-apis/event-api/introduction-event-api/#limits).

<Callout variant="important">
Esto se aplica al agente de Java [versión 8.17.0 o superior](/docs/release-notes/agent-release-notes/java-release-notes).
</Callout>
</Collapser>
