Esta página cubre la ruta de instalación estándar para el agente de Java de New Relic en cualquier servidor de aplicaciones compatible o framework basado en JVM. Siga estos pasos para descargar el agente, configurarlo y verificar que los datos fluyan a New Relic.

## Compatibilidad y requisitos [#requirements]

### Soportado

* Java 8, 11, 17, 21, 24, 25 y 26 *(Java 7 solo es compatible con el agente v6.5.4 y versiones anteriores)*
* Lenguajes basados en la JVM: Java, Scala, Kotlin y Clojure
* Servidores de aplicaciones y frameworks: Tomcat, Spring Boot, JBoss/WildFly, Glassfish, Jetty, WebLogic, WebSphere, Grails, ColdFusion, Solr, Play, Resin, Tanuki Wrapper y Geronimo —consulte la [compatibilidad y los requisitos](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent) para conocer los rangos de versiones compatibles
* Cualquier proceso de JVM que acepte un argumento `-javaagent`

### No soportado

* Al ejecutarse junto a otros agentes APM —el agente de Java no puede garantizar un comportamiento correcto cuando otro agente APM está activo en la misma JVM

### Necesita

* Una cuenta de New Relic y<InlinePopover type="licenseKey" />
* Una JVM con soporte para SSL SHA-2 (256 bits)
* Permiso para editar el script de inicio del servidor de aplicaciones o la configuración de la JVM
* Permiso para crear un directorio para alojar los archivos del agente

## Instalar [#install]

<Steps>
<Step>
### Descargue el agente de Java [#install-step-1]

Descargue `newrelic-java.zip` utilizando uno de estos métodos:

<Tabs>
<TabsBar>
<TabsBarItem id="curl">curl</TabsBarItem> <TabsBarItem id="powershell">PowerShell</TabsBarItem> <TabsBarItem id="web">Web</TabsBarItem>
</TabsBar>

<TabsPages>
<TabsPageItem id="curl">
```bash
curl -O https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip
unzip newrelic-java.zip
```
</TabsPageItem>

<TabsPageItem id="powershell">
```powershell
Invoke-WebRequest -Uri https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip -OutFile newrelic-java.zip
Expand-Archive -Path newrelic-java.zip -DestinationPath .
```
</TabsPageItem>

<TabsPageItem id="web">
Descargue `newrelic-java.zip` de la página de [notas de la versión del agente de Java](/docs/release-notes/agent-release-notes/java-release-notes/).
</TabsPageItem>
</TabsPages>
</Tabs>

Después de descomprimir, el directorio `newrelic/` contiene el archivo jar del agente (`newrelic.jar`) y el archivo de configuración (`newrelic.yml`) que configurará en los próximos pasos.
</Step>

<Step>
### Coloque los archivos del agente [#install-step-2]

Cree un directorio permanente y mueva los archivos del agente a este:

```bash
mkdir -p /opt/newrelic
mv newrelic/* /opt/newrelic/
```

Recomendamos `/opt/newrelic` en Linux/macOS o `C:\opt\newrelic` en Windows. Asegúrese de que `newrelic.jar` **no** esté en el classpath de la aplicación ni en ningún directorio listado en `java.endorsed.dirs`.
</Step>

<Step>
### Pase el `-javaagent` [#install-step-3]

Agregue el indicador `-javaagent` a la configuración de inicio de la JVM del servidor de aplicaciones, que apunte a la ruta completa de `newrelic.jar`. El método difiere según el servidor —expanda el que coincida con el entorno:

<CollapserGroup>
<Collapser id="tomcat" title="Tomcat">
Elija el método para la configuración de Tomcat:

<Tabs>
<TabsBar>
<TabsBarItem id="tomcat-setenvsh">setenv.sh (Linux/macOS)</TabsBarItem> <TabsBarItem id="tomcat-setenvbat">setenv.bat (Windows)</TabsBarItem> <TabsBarItem id="tomcat-windows-service">Servicio de Windows</TabsBarItem> <TabsBarItem id="tomcat-commons-daemon">Apache Commons daemon</TabsBarItem>
</TabsBar>

<TabsPages>
<TabsPageItem id="tomcat-setenvsh">
Cree `CATALINA_BASE/bin/setenv.sh` si no existe y luego agregue:

```bash
export CATALINA_OPTS="$CATALINA_OPTS -javaagent:/opt/newrelic/newrelic.jar"
```
</TabsPageItem>

<TabsPageItem id="tomcat-setenvbat">
Cree `CATALINA_BASE/bin/setenv.bat` si no existe y luego agregue:

```batch
SET "CATALINA_OPTS=%CATALINA_OPTS% -javaagent:C:\opt\newrelic\newrelic.jar"
```
</TabsPageItem>

<TabsPageItem id="tomcat-windows-service">
1. Seleccione **Start &gt; Apache Tomcat X.Y.Z &gt; Configure Tomcat &gt; Java**.

2. En el cuadro de texto **Java Options**, ingrese el argumento. Utilice barras diagonales `/` como separador de ruta. Para Tomcat 6, agregue un salto de línea después del argumento `-javaagent`.

   ```
   -javaagent:/opt/newrelic/newrelic.jar
   ```

3. Seleccione **Apply** y, luego, reinicie Tomcat.
</TabsPageItem>

<TabsPageItem id="tomcat-commons-daemon">
La versión de Apache Commons daemon (jsvc) incluida con Tomcat 6 no admite el argumento `-javaagent`. Una compilación desde el código fuente principal lo admite mediante el prefijo `-X`. Consulte el [informe de errores de Apache](https://issues.apache.org/jira/browse/DAEMON-84) y el [respositorio de código fuente de Apache Commons](https://commons.apache.org/svninfo.html).
</TabsPageItem>
</TabsPages>
</Tabs>
</Collapser>

<Collapser id="spring-boot" title="Bota de primavera">
Agregue el argumento `-javaagent` antes del argumento `-jar` en la línea de comando:

```bash
java -javaagent:/opt/newrelic/newrelic.jar -jar /path/to/your-application.jar
```
</Collapser>

</Callout>

<Collapser id="glassfish" title="Glassfish">
1. Desde la consola de administración de Glassfish, seleccione **Application Server &gt; JVM Settings &gt; JVM Options**.

2. Seleccione **Add JVM Option** y agregue:

   ```
   -javaagent:/opt/newrelic/newrelic.jar
   ```

3. Guarde y reinicie Glassfish.

*Si Glassfish no se inicia, la ruta `-javaagent` puede ser incorrecta. También puede configurar los argumentos de JVM editando `domain.xml` directamente.*

<Callout variant="important">
Un error en Glassfish 2.1 impide que las clases en el cargador de clases arrancar utilicen la API de logging de Java. Esto se soluciona en la versión 2.1.1 y superiores.
</Callout>
</Collapser>

## Configurar [#configure]

Edite `newrelic/newrelic.yml` y establezca estos dos valores obligatorios:

```yaml
license_key: 'YOUR_LICENSE_KEY'
app_name: 'My Application'
```

El agente lee `newrelic.yml` desde el mismo directorio que `newrelic.jar` al inicio. También puede anular cualquier configuración empleando las propiedades del sistema de Java (por ejemplo, `-Dnewrelic.config.license_key=YOUR_KEY`) o variables de entorno.

Al usar el archivo de configuración, restrinja los permisos de lectura/escritura solo para el propietario del proceso del servidor de la aplicación:

```bash
chmod 600 /opt/newrelic/newrelic.yml
```

Consulte la [configuración del agente de Java](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file) para ver todas las opciones disponibles.

## Verifique la instalación [#verify]

Reinicie el servidor de aplicaciones. Envíe al menos dos requests, luego espere 2-3 minutos y la aplicación aparecerá en [APM y servicios](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29).

Si no aparecen datos después de cinco minutos, consulte [No aparecen datos (Java)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java).
