Esta página explica cómo instalar el agente de Java de New Relic en un contenedor de Docker agregando el jar del agente a la imagen y pasando el argumento `-javaagent` de la JVM al inicio.

## Compatibilidad y requisitos [#requirements]

### Soportado

* Java 8, 11, 17, 21, 24, 25 y 26 *(Java 7 solo es compatible con el agente v6.5.4 y versiones anteriores)*
* Cualquier imagen de Docker que ejecute una aplicación de Java (Tomcat, Spring Boot o similar) que acepte un argumento de JVM `-javaagent`
* Consulte la [compatibilidad y requisitos](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent) para conocer los rangos de versiones de framework y biblioteca compatibles

### No soportado

* Al ejecutarse junto a otros agentes APM —el agente de Java no puede garantizar un comportamiento correcto cuando otro agente APM está activo en la misma JVM

### Necesita

* Una cuenta de New Relic y<InlinePopover type="licenseKey" />
* Una JVM con soporte para SSL SHA-2 (256 bits)
* Docker instalado con un contenedor de aplicación Java

## Instalar [#install]

Descargue `newrelic-java.zip`: \[#install-step-1]

```bash
curl -O https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip
unzip newrelic-java.zip
```

Agregue el jar del agente a su `Dockerfile`. El siguiente ejemplo usa Tomcat —ajuste la ruta para el servidor de aplicaciones:

```dockerfile
RUN mkdir -p /usr/local/tomcat/newrelic
ADD ./newrelic/newrelic.jar /usr/local/tomcat/newrelic/newrelic.jar
ENV JAVA_OPTS="$JAVA_OPTS -javaagent:/usr/local/tomcat/newrelic/newrelic.jar"
```

Cree la imagen de Docker como de costumbre.

## Configurar [#configure]

Pase el nombre de la aplicación y la clave de licencia como variables de entorno al ejecutar el contenedor:

```bash
docker run -e NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
           -e NEW_RELIC_APP_NAME="Your Application Name" \
           YOUR_IMAGE_NAME:latest
```

También puede usar directivas `ENV` en su `Dockerfile`:

```dockerfile
ENV NEW_RELIC_APP_NAME="Your Application Name"
```

Para todas las demás opciones de configuración, consulte la [configuración del agente de Java](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file).

## Verifique la instalación [#verify]

Ejecute el contenedor y envíe al menos dos requests a la aplicación. Espere 2-3 minutos y la aplicación aparecerá en [APM y servicios](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29).

Si no aparecen datos después de cinco minutos, consulte [No aparecen datos (Java)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java).
