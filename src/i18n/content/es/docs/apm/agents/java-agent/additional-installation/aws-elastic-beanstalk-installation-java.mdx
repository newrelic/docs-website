Esta página cubre la instalación del agente de Java de New Relic en AWS Elastic Beanstalk agregando el agente al paquete de la aplicación y configurando el argumento de la JVM `-javaagent` a través de la consola de Elastic Beanstalk.

## Compatibilidad y requisitos [#requirements]

### Soportado

* Java 8, 11, 17, 21, 24, 25 y 26 *(Java 7 solo es compatible con el agente v6.5.4 y versiones anteriores)*
* Plataforma Tomcat de Elastic Beanstalk
* Plataforma Java SE de Elastic Beanstalk
* Consulte la [compatibilidad y requisitos](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent) para conocer los rangos de versiones de framework y biblioteca compatibles

### No soportado

* Contenedores de Docker en Elastic Beanstalk —utilice el [método de instalación de Docker](/docs/apm/agents/java-agent/additional-installation/install-new-relic-java-agent-docker) en su lugar
* Al ejecutarse junto a otros agentes APM —el agente de Java no puede garantizar un comportamiento correcto cuando otro agente APM está activo en la misma JVM

### Necesita

* Una cuenta de New Relic y<InlinePopover type="licenseKey" />
* Una JVM con soporte para SSL SHA-2 (256 bits)
* Una [cuenta de AWS](http://aws.amazon.com/elasticbeanstalk/) con su aplicación Java desplegada en Elastic Beanstalk

## Instalar [#install]

Descargue `newrelic-java.zip` y extraiga `newrelic.jar` y `newrelic.yml`: \[#install-step-1]

```bash
curl -O https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip
unzip newrelic-java.zip
```

## Configurar [#configure]

Edite `newrelic.yml` y establezca los dos valores requeridos:

1. Establezca `license_key` en su <InlinePopover type="licenseKey" />.
2. Establezca `app_name` como un nombre significativo para la aplicación.

**Solo para la plataforma Tomcat** —Pase el indicador `-javaagent` a través de la consola de Elastic Beanstalk:

1. Abra la consola de Elastic Beanstalk y seleccione el entorno.

2. En el panel izquierdo, seleccione **Configurations**.

3. Desplácese hasta **Updates, monitoring, and logging** y haga clic en **Edit**.

4. En **Platform Software**, agregue al campo **JVM Options**:

   ```
   -javaagent:/full/path/to/newrelic.jar
   ```

   Para encontrar la ruta a `newrelic.jar` en la instancia EC2, conéctese a la instancia y ejecute:

   ```bash
   sudo find /var -name "newrelic.jar"
   sudo find /usr -name "newrelic.jar"
   ```

5. Haga clic en **Apply**.

Para todas las demás opciones de configuración, consulte la [configuración del agente de Java](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file).

## Verifique la instalación [#verify]

Elastic Beanstalk actualizará el entorno. Envíe al menos dos requests, luego espere 2-3 minutos y la aplicación aparecerá en [APM y servicios](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29).

Si no aparecen datos después de cinco minutos, consulte [No aparecen datos (Java)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java).
