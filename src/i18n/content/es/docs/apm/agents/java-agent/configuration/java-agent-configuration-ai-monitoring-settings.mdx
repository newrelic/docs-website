La configuración de monitoreo de IA controla cómo el agente instrumenta las llamadas al modelo de lenguaje extenso (LLM) y captura los datos de respuesta de la IA.

<Callout variant="tip">
Volver al índice completo de ajustes: [configuración del agente de Java](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file)
</Callout>

## Monitoreo de IA [#ai-monitoring]

Esta sección detalla las opciones de configuración del agente de Java para [el monitoreo de IA](/docs/ai-monitoring/intro-to-ai-monitoring). Esta característica se puede configurar en la estrofa del archivo de configuración yaml `ai_monitoring` , con propiedades del sistema con prefijo `newrelic.config.ai_monitoring.` o con variables de entorno con prefijo `NEW_RELIC_AI_MONITORING_` .

<Callout variant="important">
Si el rastreo distribuido está deshabilitado o el modo de alta seguridad está habilitado, el monitoreo de IA no recopilará datos de IA.
</Callout>

<Callout variant="important">
Cuando está habilitado, el monitoreo de IA registra una copia en tiempo real de las entradas y salidas enviadas hacia y desde los modelos que usted elige monitorear, incluida cualquier información personal contenida en ellas. Usted es responsable de obtener el consentimiento de su modelo de usuario para que su interacción pueda ser registrada por un tercero (New Relic) con el propósito de proporcionar la función de monitoreo de IA.
</Callout>
