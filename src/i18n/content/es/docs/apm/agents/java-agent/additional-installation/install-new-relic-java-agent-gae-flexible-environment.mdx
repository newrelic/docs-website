Esta página cubre la instalación del agente de Java de New Relic en un [entorno flexible de Google App Engine (GAE)](https://cloud.google.com/appengine/docs/flexible/java/) mediante un entorno de ejecución de Docker personalizado.

<Callout variant="important">
No utilice el entorno estándar de GAE ni el [“modo nativo”](https://cloud.google.com/appengine/docs/flexible/java/) de Google App Engine —el agente de Java requiere un entorno de ejecución personalizado.
</Callout>

## Compatibilidad y requisitos [#requirements]

### Soportado

* Java 8, 11, 17, 21, 24, 25 y 26 *(Java 7 solo es compatible con el agente v6.5.4 y versiones anteriores)*
* Entorno flexible de Google App Engine con un entorno de ejecución de Docker personalizado
* Consulte la [compatibilidad y requisitos](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent) para conocer los rangos de versiones de framework y biblioteca compatibles

### No soportado

* Entorno estándar de GAE —requiere un entorno de ejecución personalizado; el entorno estándar no lo admite
* Modo nativo de GAE —el agente de Java requiere un entorno de ejecución personalizado
* Al ejecutarse junto a otros agentes APM —el agente de Java no puede garantizar un comportamiento correcto cuando otro agente APM está activo en la misma JVM

### Necesita

* Una cuenta de New Relic y<InlinePopover type="licenseKey" />
* Una JVM con soporte para SSL SHA-2 (256 bits)
* Un proyecto de Google Cloud Platform con una aplicación de App Engine creada (consulte los [procedimientos de Google App Engine para Java](https://cloud.google.com/appengine/docs/flexible/java/managing-projects-apps-billing#create))
* La CLI de `gcloud` instalada e inicializada (consulte la [documentación del SDK de Google Cloud](https://cloud.google.com/sdk/gcloud/))
* Maven o Gradle con el [plug-in de App Engine](https://cloud.google.com/appengine/docs/flexible/java/using-maven) configurado

## Instalar [#install]

Descargue `newrelic-java.zip` y descomprímalo en el proyecto: \[#install-step-1]

```bash
curl -O https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip
unzip newrelic-java.zip
```

Configure `app.yaml` para un entorno de ejecución personalizado:

```yaml
runtime: custom
env: flex
```

Configure el `Dockerfile` para agregar el agente y pasar el argumento `-javaagent`. El siguiente ejemplo usa Tomcat:

```dockerfile
ADD ./newrelic/newrelic.jar /usr/local/tomcat/newrelic/newrelic.jar
ENV JAVA_OPTS="$JAVA_OPTS -javaagent:/usr/local/tomcat/newrelic/newrelic.jar"
```

Compile el proyecto:

```bash
mvn clean install
```

## Configurar [#configure]

Edite `newrelic/newrelic.yml` y establezca los dos valores requeridos:

1. Establezca `license_key` en su <InlinePopover type="licenseKey" />.
2. Establezca `app_name` como un nombre significativo para la aplicación.

Para todas las demás opciones de configuración, consulte la [configuración del agente de Java](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file).

## Verifique la instalación [#verify]

Desplegar en GAE:

```bash
gcloud --project YOUR_PROJECT_NAME app deploy
```

Espere hasta que se complete el despliegue. Envíe al menos dos requests, luego espere 2-3 minutos y la aplicación aparecerá en [APM y servicios](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29).

Si no aparecen datos después de cinco minutos, consulte [No aparecen datos (Java)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java).
