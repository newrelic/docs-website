El agente de Java de New Relic instrumenta la aplicación de Java automáticamente, lo que le brinda visibilidad de las transacciones, los errores y el rendimiento de la JVM sin cambiar el código de la aplicación. Una vez instalado, puede ver el tiempo de respuesta, el rendimiento, la tasa de errores y el estado de la JVM de la aplicación en la plataforma de New Relic en cuestión de minutos. Utilice el agente de Java para encontrar cuellos de botella de rendimiento, diagnosticar errores en contexto y comprender cómo se comporta la aplicación con tráfico real.

## Capacidades [#capabilities]

* **Métricas** —tiempo de respuesta, rendimiento, tasa de errores, puntuación Apdex y métricas de la JVM (heap, recolección de basura, recuentos de subprocesos) por aplicación y transacción
* **Eventos** —eventos de transacción, eventos de error y eventos personalizados consultables mediante NRQL
* **Logs** — Datos de log de aplicación correlacionados con trazas y errores mediante [logs en contexto](/docs/logs/logs-context/java-configure-logs-context-all/)
* **Trazas** — Rastreo distribuido que vincula requests entre servicios, además de trazas de la transacción y planes de ejecución de SQL para consultas lentas
* **Entidad** — La aplicación aparece como una entidad de servicio en New Relic, visible en APM y servicios y en el explorador de entidades

## Elija su ruta de instalación [#choose]

* **Servidores de aplicaciones y JVM independiente** (recomendado) — La ruta estándar para Tomcat, Spring Boot, JBoss/WildFly, Glassfish, Jetty, WebLogic, WebSphere y cualquier JVM que acepte un argumento `-javaagent`
* **Maven** — Úselo cuando la compilación ya utilice Maven; el agente se descarga y se descomprime como dependencia de compilación mediante `maven-dependency-plugin`
* **Gradle** — Úselo cuando su compilación ya use Gradle; las tareas de descarga impulsadas por `de.undercouch.download` obtienen y desempaquetan el agente automáticamente
* **Azure App Service (Windows)** — Úselo cuando la aplicación Java se ejecute en Azure Windows App Service; la extensión de sitio de New Relic inyecta el agente sin modificar el script de inicio
* **Docker** — Úselo para aplicaciones Java en contenedores; pase `-javaagent` mediante `JAVA_TOOL_OPTIONS`
* **AWS Elastic Beanstalk** — Úselo para aplicaciones de Tomcat o Java SE desplegadas en Elastic Beanstalk
* **Google App Engine** — Úselo para aplicaciones que se ejecutan en el entorno flexible de GAE a través de un entorno de ejecución de Docker personalizado
* **AWS Lambda** — Utiliza una ruta de instalación diferente a la del agente estándar; consulte el [monitoreo de funciones serverless](/docs/serverless-function-monitoring/aws-lambda-monitoring/enable-lambda-monitoring/enable-serverless-monitoring-aws-lambda-legacy#java)

## Instalación guiada [#ui-install]

La instalación guiada está disponible en <DNT>**[one.newrelic.com](https://one.newrelic.com) → Integrations &amp; Agents → Java**</DNT>. La UI proporciona un flujo de trabajo integral guiado que completa previamente la clave de licencia y el nombre de la aplicación.

## Instalación de un vistazo [#at-a-glance]

1. Verifique [la compatibilidad y los requisitos](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent)
2. Descargar y colocar los archivos del agente
3. Configurar el agente con la clave de licencia y el nombre de la aplicación
4. Verifique que los datos fluyan a New Relic
