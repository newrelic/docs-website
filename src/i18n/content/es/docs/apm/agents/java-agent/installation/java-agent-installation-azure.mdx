Esta página explica cómo instalar el agente de Java de New Relic en Azure App Service para Windows mediante la extensión de sitio del agente de Java de New Relic. La extensión inyecta el agente automáticamente sin modificar el script de inicio de la aplicación.

## Compatibilidad y requisitos [#requirements]

### Soportado

* Aplicaciones de Java que se ejecutan en Azure Windows App Service
* Versiones del agente de Java de New Relic compatibles con Java 8 y versiones posteriores *(Java 7 solo es compatible con el agente v6.5.4 y versiones anteriores)*
* Consulte la [compatibilidad y requisitos](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent) para conocer los rangos de versiones de framework y biblioteca compatibles

### No soportado

* Contenedores de Linux en Azure —use el [método de instalación de Docker](/docs/apm/agents/java-agent/additional-installation/install-new-relic-java-agent-docker) y pase `-javaagent` mediante `JAVA_TOOL_OPTIONS`
* Al ejecutarse junto a otros agentes APM —el agente de Java no puede garantizar un comportamiento correcto cuando otro agente APM está activo en la misma JVM

### Necesita

* Una cuenta de New Relic y<InlinePopover type="licenseKey" />
* Una JVM con soporte para SSL SHA-2 (256 bits)
* Una aplicación de Java que se ejecuta en Azure Windows App Service
* La aplicación objetivo debe detenerse antes de instalar la extensión para evitar una instrumentación parcial

## Instalar [#install]

<Steps>
<Step>
### Instale la extensión del sitio [#install-step-1]

1. Desde la página de inicio de Azure, seleccione **App Services**, luego seleccione la aplicación objetivo.
2. En el menú izquierdo, desplácese hasta **Development Tools** y seleccione **Extensions**.
3. Seleccione **+ Add** en la parte superior de la página para abrir el desplegable de la extensión.
4. Seleccione **New Relic Java Agent**.
5. Acepte los términos legales y seleccione **OK** para comenzar la instalación.

Una vez instalada, la extensión crea:

* **Archivos del agente** en `C:\home\NewRelic\JavaAgent\newrelic\` (jars, configuración, fuentes)
* **Transformación XDT** (`applicationHost.xdt`) que inyecta automáticamente la variable de entorno `JAVA_TOOL_OPTIONS` al iniciar la aplicación

*Si la extensión no se puede instalar, revise el log en `C:\home\SiteExtensions\NewRelic.Azure.WebSites.Extension.JavaAgent\install.log`.*
</Step>

<Step>
### Configurar el agente [#install-step-2]

1. En el menú izquierdo de la aplicación, vaya a **Settings &gt; Configuration**.
2. Agregue la siguiente configuración de la aplicación:

| Configuración           | Valor                                               |
| ----------------------- | --------------------------------------------------- |
| `NEW_RELIC_LICENSE_KEY` | Su clave de licencia de New Relic                   |
| `NEW_RELIC_APP_NAME`    | El nombre que aparece en la plataforma de New Relic |

También puede agregar [ajustes de configuración adicionales](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file/#Environment_Variables) como ajustes de la aplicación para personalizar aún más el agente.
</Step>
</Steps>

## Verifique la instalación [#verify]

Inicie la aplicación. Envíe al menos dos requests, luego espere 2-3 minutos y la aplicación aparecerá en [APM y servicios](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29).

Si no aparecen datos después de cinco minutos, consulte [No aparecen datos (Java)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java).
