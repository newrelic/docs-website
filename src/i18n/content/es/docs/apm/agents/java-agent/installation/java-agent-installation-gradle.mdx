Esta página explica la instalación del agente de Java de New Relic mediante Gradle. Las tareas de Gradle impulsadas por el plug-in `de.undercouch.download` obtienen y desempaquetan `newrelic-java.zip` en el directorio del proyecto.

## Compatibilidad y requisitos [#requirements]

### Soportado

* Java 8, 11, 17, 21, 24, 25 y 26 *(Java 7 solo es compatible con el agente v6.5.4 y versiones anteriores)*
* Gradle 6.x o superior
* `de.undercouch.download` plug-in versión 5.3.0 o superior
* Cualquier servidor de aplicaciones compatible o proceso de JVM independiente que acepte un argumento `-javaagent`
* Consulte la [compatibilidad y requisitos](/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent) para conocer los rangos de versiones de framework y biblioteca compatibles

### No soportado

* Al ejecutarse junto a otros agentes APM —el agente de Java no puede garantizar un comportamiento correcto cuando otro agente APM está activo en la misma JVM

### Necesita

* Una cuenta de New Relic y<InlinePopover type="licenseKey" />
* Una JVM con soporte para SSL SHA-2 (256 bits)
* Un proyecto de Gradle con `build.gradle`

## Instalar [#install]

<Steps>
<Step>
### Agregue el plug-in de descarga [#install-step-1]

Agregue el plug-in `de.undercouch.download` al bloque `plugins` de su `build.gradle`:

```groovy
plugins {
    id "de.undercouch.download" version "5.3.0"
}
```
</Step>

<Step>
### Agregar tareas de descarga y descompresión [#install-step-2]

Agregue dos tareas a `build.gradle` —una para descargar el zip del agente y otra para descomprimirlo:

```groovy
task downloadNewrelic(type: Download) {
    mkdir 'newrelic'
    src 'https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip'
    dest file('newrelic')
}

task unzipNewrelic(type: Copy) {
    from zipTree(file('newrelic/newrelic-java.zip'))
    into rootDir
}
```

Esto coloca los archivos del agente en un directorio `newrelic/` en la raíz del proyecto, que contiene:

* `newrelic.jar` —el agente de Java
* `newrelic.yml` — el archivo de configuración del agente
* `newrelic-api.jar` — el jar de la API del agente de Java
* `README`
</Step>

<Step>
### Ejecute las tareas [#install-step-3]

Ejecute ambas tareas para descargar y descomprimir el agente:

```bash
./gradlew downloadNewrelic
./gradlew unzipNewrelic
```
</Step>

<Step>
### Pase el `-javaagent` [#install-step-4]

Agregue el argumento `-javaagent` de la JVM que apunta a `newrelic.jar` al iniciar la aplicación. El método exacto depende del servidor de aplicaciones —consulte [Pase el argumento de la JVM para el servidor](/docs/apm/agents/java-agent/installation/java-agent-installation-app-servers#install-step-3) para obtener instrucciones específicas del servidor.

Para un jar de Spring Boot, por ejemplo:

```bash
java -javaagent:/path/to/newrelic/newrelic.jar -jar my-app.jar
```
</Step>
</Steps>

## Configurar [#configure]

Edite `newrelic/newrelic.yml` y establezca dos valores obligatorios:

```yaml
license_key: 'YOUR_LICENSE_KEY'
app_name: 'My Application'
```

El agente lee `newrelic.yml` desde el mismo directorio que `newrelic.jar` al inicio. También puede anular cualquier configuración empleando las propiedades del sistema de Java (por ejemplo, `-Dnewrelic.config.license_key=YOUR_KEY`) o variables de entorno.

Consulte la [configuración del agente de Java](/docs/apm/agents/java-agent/configuration/java-agent-configuration-config-file) para ver todas las opciones disponibles.

## Verifique la instalación [#verify]

Reinicie la aplicación. Envíe al menos dos requests, luego espere 2-3 minutos y la aplicación aparecerá en [APM y servicios](https://one.newrelic.com/nr1-core?filters=%28domain%20IN%20%28%27APM%27%2C%20%27EXT%27%29%20AND%20type%20IN%20%28%27APPLICATION%27%2C%20%27SERVICE%27%29%29).

Si no aparecen datos después de cinco minutos, consulte [No aparecen datos (Java)](/docs/apm/agents/java-agent/troubleshooting/no-data-appears-java).
