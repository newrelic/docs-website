Puede instalar el agente PHP de New Relic desde archivos tar comprimidos en cualquier sistema operativo compatible en cualquier arquitectura de procesador compatible. Sin embargo, para RedHat o CentOS en x86\_64 es más común utilizar el [paquete RPM](/docs/agents/php-agent/installation/php-agent-installation-aws-linux-redhat-centos/). Para Ubuntu o Debian en x86\_64 es más común utilizar el [paquete Debian](/docs/agents/php-agent/installation/php-agent-installation-ubuntu-debian).

## Descargar la distribución tar [#download]

A diferencia de otras opciones de instalación, los archivos tar no requieren ninguna configuración de repositorio especial. Todo lo que necesitas hacer es descargar el archivo y seguir estas instrucciones.

Descargue el archivo de distribución tar correspondiente desde <DNT>**[download.newrelic.com/php\_agent/release/](https://download.newrelic.com/php_agent/release/)**</DNT>:

* Para Linux con GNU libc (la mayoría de las distribuciones de Linux), descargue `newrelic-php5-X.X.X.X-linux.tar.gz`.
* Para Linux con musl libc (Alpine Linux), descargue `newrelic-php5-X.X.X.X-linux-musl.tar.gz`.

<Callout variant="tip">
El nombre del paquete para el agente PHP es `newrelic-php5`. Aunque el nombre del paquete hace referencia a PHP 5, este paquete funciona para todas [las versiones de PHP compatibles](/docs/agents/php-agent/getting-started/php-agent-compatibility-requirements#php-release).
</Callout>

## Instalar o actualizar [#install]

Con la instalación del archivo tar, los pasos para la instalación por primera vez y para la actualización son los mismos. Reemplace XXXX con la versión correcta de New Relic. Para instalar o actualizar el agente:

1. Descargue el archivo tar apropiado del [sitio web de New Relic](https://download.newrelic.com/php_agent/release/) y guárdelo en un disco local en una ubicación conveniente. No utilice la carpeta `/tmp` .

2. Descomprime y extrae el archivo:

   ```bash
   gzip -dc newrelic-php5-X.X.X.X-OS.tar.gz | tar xf -
   ```

3. Cambie al directorio recién creado:

   ```bash
   cd newrelic-php5-X.X.X.X-OS
   ```

4. Ejecute el script de instalación:

   ```bash
   ./newrelic-install
   ```

5. Cambie el [nombre de la aplicación](/docs/site/naming-your-application) predeterminada por un nombre significativo.

6. Reinicie su servidor web (Apache, Nginx, PHP-FPM, etc.).

7. Espere unos minutos hasta que su aplicación envíe datos y luego [verifique el rendimiento de su aplicación en la UI](/docs/apm/applications-menu/monitoring/apm-overview-page).

## Verifique el archivo tar [#verify]

A partir de la versión 12.13.0.43 del agente PHP, puede verificar cada archivo tar en el sitio de descargas con la huella digital de la clave de firma y el hash SHA-256 del archivo tar. Ambos se publican en el [directorio `release-data` ](https://github.com/newrelic/newrelic-php-agent/tree/main/release-data)del respositorio de GitHub del agente PHP.

Para verificar un archivo tar:

1. Descargue el archivo tar, su archivo `.asc` (el nombre del archivo tar con `.asc` agregado, en la misma carpeta) y la clave pública. Este comando imprime la URL de la clave pública y su huella digital:

   ```bash
   curl -s https://raw.githubusercontent.com/newrelic/newrelic-php-agent/main/release-data/signing-key-fingerprints.json | jq -r '.keys[] | select(.purpose == "tarball" and .status == "active") | .public_key_url, (.fingerprint | [scan(".{4}")] | join(" "))'
   ```

2. Muestre la huella digital del archivo de clave y compárela con la huella digital del paso 1. Si coinciden, importe la clave:

   ```bash
   gpg --show-keys --with-fingerprint NEWRELIC_TARBALL_XXXXXXXX.public
   gpg --import NEWRELIC_TARBALL_XXXXXXXX.public
   ```

3. Verifique la firma:

   ```bash
   gpg --verify newrelic-php5-X.X.X.X-OS.tar.gz.asc newrelic-php5-X.X.X.X-OS.tar.gz
   ```

   La salida debe decir `Good signature`, y la línea `Primary key fingerprint` debe coincidir con la huella digital del paso 1. `gpg` también imprime una advertencia de que la clave no está certificada con una firma de confianza. Esto es lo esperado.

4. Compare el hash SHA-256 del archivo tar con el que se indica para este en `tarball-hashes.json`. Los dos hash deben ser idénticos:

   ```bash
   sha256sum newrelic-php5-X.X.X.X-OS.tar.gz
   curl -s https://raw.githubusercontent.com/newrelic/newrelic-php-agent/main/release-data/tarball-hashes.json | jq -r '.releases[].files[] | select(.filename == "newrelic-php5-X.X.X.X-OS.tar.gz") | .sha256'
   ```
