<Callout title="avance">
Todavía estamos trabajando en esta característica, ¡pero nos encantaría que la probaras!

Esta característica se proporciona actualmente como parte de un programa de vista previa de conformidad con nuestras [políticas de prelanzamiento](/docs/licenses/license-information/referenced-policies/new-relic-pre-release-policy).
</Callout>

El agente de Python de New Relic se integra con la gestión de características de LaunchDarkly para que pueda observar cómo las marcas de características y los lanzamientos afectan a la aplicación. Esta integración utiliza el plug-in de observabilidad de LaunchDarkly y la compatibilidad con OpenTelemetry en el agente de Python para conectar los datos de LaunchDarkly con los datos de New Relic APM.

Este documento explica cómo instalar los paquetes requeridos y habilitar la integración.

## Requisitos previos [#prerequisites]

Antes de comenzar, asegúrese de tener:

* Una [clave de licencia](/docs/apis/intro-apis/new-relic-api-keys/#license-key) de New Relic
* Una cuenta y licencia de LaunchDarkly
* Una aplicación escrita en Python y monitoreada con el [agente APM de New Relic para Python](/docs/apm/agents/python-agent/installation/install-new-relic-python-agent)
* Acceso a la beta de OpenTelemetry (OTel) de LaunchDarkly

## Instalación y configuración [#install]

<Steps>
<Step>
### Instale los paquetes requeridos [#install-packages]

Instale los siguientes paquetes de Python dentro del mismo entorno que la aplicación:

* `newrelic`
* `launchdarkly-observability`

```bash
pip install newrelic launchdarkly-observability
```

Los siguientes paquetes también son necesarios y, por lo general, se instalan automáticamente como dependencias de `launchdarkly-observability`:

* `opentelemetry-api`
* `launchdarkly-eventsource`
* `launchdarkly-server-sdk`
* `launchdarkly-server-sdk-otel`

Si estas dependencias no se instalan automáticamente, instálelas manualmente usando `pip`:

```bash
pip install opentelemetry-api launchdarkly-eventsource launchdarkly-server-sdk launchdarkly-server-sdk-otel
```
</Step>

<Step>
### Habilitar la integración [#enable-integration]

Para habilitar la integración, establezca tanto `launch_darkly_integration.enabled` como `opentelemetry.enabled` en `true`. Seleccione uno de los siguientes métodos de configuración para configurar la aplicación:

<CollapserGroup>
<Collapser id="use-newrelic-ini" title="Utilice newrelic.ini">
Agregue lo siguiente a su archivo `newrelic.ini` :

```ini
launch_darkly_integration.enabled = true
opentelemetry.enabled = true
```
</Collapser>

<Collapser id="use-pyproject-toml" title="Utilice pyproject.toml">
Agregue lo siguiente a su archivo `pyproject.toml` :

```toml
[tool.newrelic]
launch_darkly_integration.enabled = true
opentelemetry.enabled = true
```
</Collapser>

<Collapser id="use-environment-variables" title="Utilice variables de entorno">
Establezca las siguientes variables de entorno:

```bash
export NEW_RELIC_LAUNCH_DARKLY_ENABLED=true
export NEW_RELIC_OPENTELEMETRY_ENABLED=true
```

<Callout variant="tip">
Para obtener más información sobre la configuración de OpenTelemetry, consulte la documentación sobre la [configuración del agente de Python](/docs/apm/agents/python-agent/configuration/python-agent-configuration#opentelemetry-enabled).
</Callout>
</Collapser>
</CollapserGroup>
</Step>

<Step>
### Verifique la integración [#verify]

Después de habilitar estos ajustes, reinicie la aplicación para que el agente de Python cargue la configuración actualizada. A continuación, genere tráfico de prueba y verifique que la aplicación continúe reportando datos en [<DNT>**APM &amp; services**</DNT>](/docs/apm/apm-ui-pages/monitoring/apm-summary-page-view-transaction-apdex-usage-data).
</Step>
</Steps>
