Este método es para instalar el agente de Ruby como un plug-in de Rails para **Rails 2 o superior**.

<Callout variant="important">
Para la mayoría de los casos de uso, [instale el agente de Ruby como una gema](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent) en su lugar. El método de la gema proporciona un mejor control sobre las versiones y dependencias.
</Callout>

<Steps>
<Step>
## Instale el plug-in de Rails [#install]

Instale el plug-in desde GitHub en el directorio `vendor/plugins` de la aplicación:

```sh
script/plugin install git://github.com/newrelic/newrelic-ruby-agent.git
mv vendor/plugins/rpm vendor/plugins/newrelic-ruby-agent
```

Si no puede instalar directamente desde la URL de git, clone el respositorio en el directorio `vendor/plugins` manualmente.
</Step>

<Step>
## Configurar el agente [#configure]

Copie el archivo `newrelic.yml` del directorio del plug-in al subdirectorio `config` de la aplicación:

```sh
cp vendor/plugins/newrelic-ruby-agent/newrelic.yml config/newrelic.yml
```

Edite `config/newrelic.yml` y establezca los dos valores requeridos:

1. Establezca `license_key` en su <InlinePopover type="licenseKey" />.
2. Establezca `app_name` como un nombre significativo para la aplicación.

Para ver todas las demás opciones de configuración, consulte la [configuración del agente Ruby](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration).
</Step>

<Step>
## Verifique que los datos estén fluyendo [#verify]

Reinicie el servidor web y luego envíe al menos dos requests a la aplicación. Espere 2-3 minutos y abra [one.newrelic.com &gt; APM](https://one.newrelic.com/apm) para buscar la aplicación por nombre.

<Callout variant="tip">
¿No aparece la aplicación? Consulte [No se muestran datos (Ruby)](/docs/apm/agents/ruby-agent/troubleshooting/no-data-appears-ruby).
</Callout>
</Step>
</Steps>
