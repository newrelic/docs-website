<Steps>
<Step>
## Agregue la gema al Gemfile [#install]

Agregue la gema del agente de Ruby a su `Gemfile`:

```ruby
gem 'newrelic_rpm'
```

Su `Dockerfile` debe ejecutar `bundle install` como parte de la compilación:

```dockerfile
COPY Gemfile Gemfile.lock ./
RUN bundle install
```

**Notas específicas del framework:**

* **Rails**: Rails llama automáticamente a `Bundler.require`, por lo que `newrelic_rpm` es necesario durante el inicio sin pasos adicionales.
* **Roda o Sinatra**: debe llamar manualmente a `require 'newrelic_rpm'` en la aplicación.
* **Otras aplicaciones Rack**: para usar el monitoreo de browser automático, incluya manualmente los [middlewares de Rack](/docs/agents/ruby-agent/frameworks/rack-middlewares#manual) proporcionados por el agente.
</Step>

<Step>
## Configurar el agente [#configure]

Pase el nombre de la aplicación y la clave de licencia como variables de entorno al ejecutar el contenedor —no las codifique de forma rígida en la imagen:

```bash
docker run -e NEW_RELIC_LICENSE_KEY=YOUR_LICENSE_KEY \
           -e NEW_RELIC_APP_NAME="Your Application Name" \
           YOUR_IMAGE_NAME:latest
```

También puede configurarlos mediante `ENV` en su `Dockerfile`:

```dockerfile
ENV NEW_RELIC_APP_NAME="Your Application Name"
```

Para ver todas las demás opciones de configuración, consulte la [configuración del agente Ruby](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration).
</Step>

<Step>
## Verifique que los datos estén fluyendo [#verify]

Ejecute el contenedor y envíe al menos dos requests a la aplicación. Espere 2-3 minutos, luego abra [one.newrelic.com &gt; APM](https://one.newrelic.com/apm) y busque la aplicación por nombre.

<Callout variant="tip">
¿No aparece la aplicación? Consulte [No se muestran datos (Ruby)](/docs/apm/agents/ruby-agent/troubleshooting/no-data-appears-ruby).
</Callout>
</Step>
</Steps>
