<Steps>
<Step>
## Instale la gema y configure su aplicación [#install]

Agregue la gema `newrelic_rpm` a su `Gemfile`:

```ruby
gem 'newrelic_rpm'
```

Luego, ejecute:

```sh
bundle install
```

<TabsBarItem id="native-mode">Modo nativo (Rails o Sinatra)</TabsBarItem> <TabsBarItem id="docker-runtime">Entorno de ejecución de Docker personalizado</TabsBarItem>

<TabsPages>
<TabsPageItem id="native-mode">
Al utilizar el modo nativo de GAE, debe proporcionar el código de la aplicación y un `app.yaml`. GAE lo despliega automáticamente en una imagen Docker estándar prediseñada. No se necesita ningún Dockerfile adicional.
</TabsPageItem>

<TabsPageItem id="docker-runtime">
Si la aplicación necesita bibliotecas o encabezados específicos, utilice un entorno de ejecución personalizado. Cree un `Dockerfile` y establezca `app.yaml` en:

```yaml
runtime: custom
env: flex
```

New Relic recomienda el método de entorno de ejecución personalizado. También recomienda que permita a Google App Engine manejar las comprobaciones de estado.
</TabsPageItem>
</TabsPages>
</Tabs>
</Step>

<Step>
## Configurar el agente [#configure]

Descargue [`newrelic.yml`](https://github.com/newrelic/newrelic-ruby-agent/blob/dev/newrelic.yml) del respositorio de GitHub de New Relic y cópielo en el directorio `config` de la aplicación.

Establezca los dos valores requeridos:

1. Establezca `license_key` en su <InlinePopover type="licenseKey" />.
2. Establezca `app_name` como un nombre significativo para la aplicación.

Para ver todas las demás opciones de configuración, consulte la [configuración del agente Ruby](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration).
</Step>

<Step>
## Implemente y verifique [#verify]

Despliegue la aplicación mediante la CLI de `gcloud`:

```bash
gcloud app deploy
```

Espere hasta que se complete el despliegue. Envíe al menos dos requests, luego espere 2-3 minutos y abra [one.newrelic.com &gt; APM](https://one.newrelic.com/apm) para buscar su aplicación por nombre.

<Callout variant="tip">
¿No aparece la aplicación? Consulte [No se muestran datos (Ruby)](/docs/apm/agents/ruby-agent/troubleshooting/no-data-appears-ruby).
</Callout>
</Step>
</Steps>
