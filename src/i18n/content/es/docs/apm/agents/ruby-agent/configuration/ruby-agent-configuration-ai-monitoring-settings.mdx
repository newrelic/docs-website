Configure los ajustes de monitoreo de IA del agente de Ruby para habilitar la instrumentación de LLM y controlar si el contenido de entrada y salida se captura en los eventos de IA.

## Monitoreo de IA [#ai-monitoring]

Esta sección incluye la configuración del agente Ruby para configurar el monitoreo de IA.

<Callout variant="important">Debe habilitar rastreo distribuido para capturar datos de traza y retroalimentación. Está activado de forma predeterminada en Ruby agente 8.0.0 y superiores.</Callout>

Si `false`, toda la instrumentación LLM (OpenAI solo por ahora) se deshabilitará y no se enviará ninguna métrica, evento o span. El monitoreo de IA se desactiva automáticamente si el modo `high_security` está activado.
</Collapser>

Si es `false`, la instrumentación de LLM (OpenAI solo por ahora) no capturará el atributo `content` en los eventos LlmChatCompletionMessage ni el atributo `input` en los eventos LlmEmbedding. Esta es una configuración de seguridad opcional para evitar el registro de datos confidenciales enviados a los LLM y recibidos de estos.
