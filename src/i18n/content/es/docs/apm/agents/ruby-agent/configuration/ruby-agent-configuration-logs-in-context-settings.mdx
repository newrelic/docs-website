Configure los ajustes de logging de la aplicación del agente de Ruby para controlar el reenvío de logs, la decoración local, los atributos personalizados en los logs de evento y la recopilación de métricas de logs.

## Registro de aplicaciones [#application-logging]

El agente Ruby admite [el logs en el contexto de APM](/docs/apm/new-relic-apm/getting-started/get-started-logs-context). Para obtener algunos consejos sobre cómo configurar el registro para el agente Ruby, consulte [Configurar el logs en el contexto de Ruby](/docs/logs/logs-context/configure-logs-context-ruby).

Las opciones de configuración disponibles relacionadas con el registro incluyen:

<td>
`NEW_RELIC_APPLICATION_LOGGING_FORWARDING_LOG_LEVEL`
</td>
</tr>
</tbody>

Establece el nivel mínimo que debe tener un log de evento para ser reenviado a New Relic. Los logs en el nivel configurado y cualquier gravedad mayor se reenvían, por ejemplo, `debug` reenvía todos los logs de eventos, mientras que `error` reenvía solo los eventos `error`, `fatal` y `unknown`. Valores válidos, de menor a mayor gravedad: `debug`, `info`, `warn`, `error`, `fatal`, `unknown` (no distingue entre mayúsculas y minúsculas).

Este orden se basa en los valores enteros de las constantes `Logger::Severity` de Ruby (consulte [https://github.com/ruby/logger/blob/113b82a06b3076b93a71cd467e1605b23afb3088/lib/logger/severity.rb](https://github.com/ruby/logger/blob/113b82a06b3076b93a71cd467e1605b23afb3088/lib/logger/severity.rb)).
</Collapser>
