<Steps>
<Step>
## Instale el complemento New Relic [#install]

<Tabs>
<TabsBar>
<TabsBarItem id="heroku-website">Sitio web de Heroku</TabsBarItem> <TabsBarItem id="heroku-toolbelt">Heroku toolbelt</TabsBarItem>
</TabsBar>

<TabsPages>
<TabsPageItem id="heroku-website">
1. Vaya a la [página de complementos de Heroku para New Relic](https://elements.heroku.com/addons/newrelic#pricing) y seleccione un plan de suscripción.
2. En **Select an app**, seleccione la aplicación.
3. Haga clic en **Submit Order Form**.
</TabsPageItem>

<TabsPageItem id="heroku-toolbelt">
Ejecute el siguiente comando y reemplace `$planlevel` con el [plan de suscripción adecuado](https://elements.heroku.com/addons/newrelic#pricing):

```bash
heroku addons:create newrelic:$planlevel
```
</TabsPageItem>
</TabsPages>
</Tabs>

La instalación del complemento crea automáticamente una cuenta de New Relic y configura el acceso para los hosts de Heroku.
</Step>

<Step>
## Configurar el agente [#configure]

Agregue la gema `newrelic_rpm` a su `Gemfile`:

```ruby
gem 'newrelic_rpm'
```

Configure el nombre de la aplicación mediante Heroku toolbelt:

```bash
heroku config:set NEW_RELIC_APP_NAME='Your Application Name'
```

La clave de licencia es configurada automáticamente por el complemento. Para ver todas las demás opciones de configuración, consulte la [configuración del agente Ruby](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration).
</Step>

<Step>
## Verifique que los datos estén fluyendo [#verify]

Reinicie el dyno y genere algo de tráfico a la aplicación:

```bash
heroku restart
```

Espere 2-3 minutos y abra [one.newrelic.com &gt; APM](https://one.newrelic.com/apm) para buscar la aplicación por nombre.

<Callout variant="tip">
¿No aparece la aplicación? Consulte [No se muestran datos (Ruby)](/docs/apm/agents/ruby-agent/troubleshooting/no-data-appears-ruby).
</Callout>
</Step>
</Steps>
