<Steps>
<Step>
## Instalar la gema [#install]

Agregue la gema del agente de Ruby al Gemfile:

```ruby
gem 'newrelic_rpm'
```

Luego, ejecute:

```sh
bundle install
```

<Callout variant="important">
Si utiliza el agente en un contenedor de Docker, instale el agente dentro de cada contenedor. Consulte [Instalar el agente de Ruby en Docker](/docs/apm/agents/ruby-agent/installation/ruby-agent-installation-docker) para ver un ejemplo de despliegue basado en Docker.
</Callout>

**Notas específicas del framework:**

* **Rails**: Rails llama automáticamente a `Bundler.require`, por lo que `newrelic_rpm` es necesario durante el inicio sin pasos adicionales.
* **Roda o Sinatra**: debe llamar manualmente a `require 'newrelic_rpm'` en la aplicación.
* **Otras aplicaciones Rack**: para usar el monitoreo de browser automático, incluya manualmente los [middlewares de Rack](/docs/agents/ruby-agent/frameworks/rack-middlewares#manual) proporcionados por el agente.
</Step>

<Step>
## Configurar el agente [#configure]

Descargue [`newrelic.yml`](https://github.com/newrelic/newrelic-ruby-agent/blob/dev/newrelic.yml) del respositorio de GitHub de New Relic y cópielo en el directorio `config` de la aplicación.

Los únicos dos ajustes que **debe** cambiar antes de pasar a producción:

1. Establezca `license_key` en su <InlinePopover type="licenseKey" />.
2. Establezca `app_name` como un nombre significativo para la aplicación.

Como alternativa, genere el archivo de configuración con la CLI:

```sh
bundle exec newrelic_rpm install --license_key="YOUR_LICENSE_KEY" "YOUR_APP_NAME"
```
</Step>

<Step>
## Verifique que los datos estén fluyendo [#verify]

1. Reinicie su servidor web.

2. Envíe al menos dos requests a la aplicación.

3. Espere 2-3 minutos, luego abra [one.newrelic.com &gt; APM](https://one.newrelic.com/apm) y busque la aplicación por nombre.

<Callout variant="tip">
¿No aparece la aplicación? Consulte [No se muestran datos (Ruby)](/docs/apm/agents/ruby-agent/troubleshooting/no-data-appears-ruby).
</Callout>
</Step>
</Steps>
