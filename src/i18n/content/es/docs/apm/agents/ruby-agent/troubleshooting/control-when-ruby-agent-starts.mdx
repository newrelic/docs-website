## Problema

El agente de Ruby no se inicia o no informa datos a New Relic.

## Solución

Para resolver este problema:

<CollapserGroup>
<Collapser id="version-3-6-1-or-later" title="Verifique la versión de su agente Ruby.">
Verifique [la versión de su agente Ruby](/docs/release-notes/agent-release-notes/ruby-release-notes) y actualícela si es necesario.
</Collapser>

<Collapser id="environment" title="Verifique el entorno de la aplicación utilizada.">
Cuando la gema `newrelic_rpm` Ruby sea requerida en su entorno de aplicación, intentará determinar si iniciar el monitoreo automáticamente y comenzar a transmitir métrica a New Relic, o permanecer deshabilitado.

* Producción y prueba: el agente normalmente está configurado para monitor automáticamente en estos entornos.

* Prueba y desarrollo: el agente normalmente permanece deshabilitado en estos entornos.

  Para controlar esta lógica, establezca la clave de configuración `monitor_mode` en `true` o `false` en cada sección de entorno de `newrelic.yml`.
</Collapser>

<Collapser id="forcing-start" title="Obligar al agente a comenzar.">
Para anular la lógica de inicio automático del agente, el mecanismo más sencillo es establecer una variable de entorno `NEW_RELIC_AGENT_ENABLED=true` ; Por ejemplo:

```sh
NEW_RELIC_AGENT_ENABLED=true rake assets:precompile
```
</Collapser>

<Collapser id="autostart-config" title="Personalice las variables de configuración de inicio automático.">
Si está ejecutando la versión 3.6.1 o superior del agente Ruby, existen algunas razones por las que el agente se negará a iniciarse:

* El agente detecta que está en una sesión interactiva; por ejemplo, una sesión `rails console` o `irb` .

* El agente detecta que está en una de las tareas de rake integradas de Rails; por ejemplo, `assets:precompile` o `db:migrate`.

  Puede utilizar variables de configuración en el archivo `newrelic.yml` de su agente Ruby para personalizar el comportamiento de inicio automático de constantes, nombres de script y tareas de rake.

## Problema

El agente de Ruby se inicia en contextos en los que no quiero que se inicie.

## Solución

<CollapserGroup>
<Collapser id="configure-where-the-agent-starts" title="Personalice la configuración para controlar cuándo se inicia el agente">
El agente de Ruby hace algunas suposiciones sobre los contextos en los que la mayoría de los clientes desean que el agente se inicie automáticamente.

Hay tres opciones de configuración disponibles para personalizar este comportamiento:

* [`autostart.denylisted_constants`](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration-other-settings#autostart-denylisted_constants) La mayoría de las constantes de esta lista son comandos de Rails que realizan operaciones que rara vez se benefician del monitoreo.

  La lista no incluye `Rails::Command::RakeCommand`, que permite ejecutar comandos como [`rails db:*`](https://guides.rubyonrails.org/command_line.html#bin-rails-db) así como `rails solid_queue:start`, y otros comandos de Rails relacionados con tareas de Rake.

* [`autostart.denylisted_executables`](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration-other-settings#autostart-denylisted_executables) Esta configuración controla los ejecutables, como `rspec` y `irb`.

* [`autostart.denylisted_rake_tasks`](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration-other-settings#autostart-denylisted_rake_tasks) Antes de Rails 5.1, se usaba `rake` en lugar de `thor` para muchos comandos, como `db:migrate`. Los valores predeterminados para esta configuración enumeran muchos comandos de esa época. También puede agregar sus propios comandos `rake` a esta lista.
</Collapser>

<Collapser id="manually-start-and-stop-the-agent" title="Iniciar y detener manualmente el agente">
La API [`NewRelic::Agent.manual_start`](https://www.rubydoc.info/gems/newrelic_rpm/NewRelic/Agent#manual_start-instance_method) se puede usar para iniciar el agente en contextos específicos. Si establece `:agent_enabled` en `false` en el archivo de configuración o define la variable de entorno `NEW_RELIC_AGENT_ENABLED=false`, aún puede iniciar manualmente el agente mediante esta API.

```ruby
NewRelic::Agent.manual_start(agent_enabled: true)
```

Si desea detener el agente antes de que termine el proceso, puede llamar a [`NewRelic::Agent.shutdown`](https://www.rubydoc.info/gems/newrelic_rpm/NewRelic/Agent#shutdown-instance_method).
</Collapser>
</CollapserGroup>
