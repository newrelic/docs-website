Con el agente de Ruby, puede inyectar el [agente de monitoreo de browser](/docs/browser/new-relic-browser/getting-started/introduction-new-relic-browser) en las páginas web de forma automática o manual. Por defecto, si el agente de Ruby detecta Javascript, instala automáticamente <InlinePopover type="browser" />.

Si prefiere agregar el monitoreo de browser de forma manual o desea obtener información sobre las opciones para instalar el agente del browser, [consulte la guía de instalación del agente del browser](/docs/browser/new-relic-browser/installation/install-new-relic-browser-agent).

## Requisitos [#requirements]

La instrumentación automática del browser está disponible [para todas las versiones compatibles del agente de Ruby](/docs/apm/agents/ruby-agent/getting-started/ruby-agent-eol-policy/). Para asegurarse de que el entorno esté listo para la instrumentación automática, revise la [guía de compatibilidad y requisitos del monitoreo de browser](/docs/browser/new-relic-browser/getting-started/compatibility-requirements-browser-monitoring).

## Utilizar instrumentación automática. [#auto-instrumentation]

La configuración predeterminada de New Relic habilita la instrumentación automática del monitoreo de browser:

```yaml
browser_monitoring:
  auto_instrument: true
```

Esta es la forma más sencilla de monitorear a los usuarios finales. El agente de Ruby examina cada página de la aplicación cuando se carga e inyecta automáticamente el JavaScript del navegador en el encabezado. La instrumentación automática funciona para los entornos que utilizan Rack. Por motivos de rendimiento, el agente solo escanea los primeros 50 000 caracteres de la respuesta de la aplicación en busca del punto de instrumentación del encabezado. En los casos en los que esté presente una etiqueta meta `X-UA-Compatible` y la etiqueta `<head>` tenga más de 50 000 caracteres, la instrumentación automática fallará de forma controlada.

La instrumentación automática busca una etiqueta meta `X-UA-Compatible` e inserta el JavaScript directamente después de ella. Si la instrumentación automática no puede encontrar una etiqueta meta `X-UA-Compatible`, lo insertará después de la etiqueta de apertura head. Si no puede, lo insertará después de la etiqueta de apertura body. Si alguna de estas etiquetas está envuelta en condicionales o comentarios, es probable que la instrumentación automática falle.

La instrumentación automática no se producirá en las páginas con un encabezado `Content-Disposition` de archivo adjunto o cuando detecte requests de streaming.

Si la instrumentación automática no logra instrumentar correctamente las páginas de la aplicación, deberá [instrumentarlas manualmente](#manual-instrumentation) usando la API del agente.

## instrumentar manual a través de la API del agente [#manual-instrumentation]

Puede configurar el monitoreo de usuario final de forma manual incluyendo los script adecuados en sus páginas. Utilice la API del agente de Ruby de New Relic para generar el script. La API inyecta este script en sus páginas.

Por ejemplo, para modificar la plantilla de su aplicación para llamar al agente, use:

```erb
<head>
    <%= ::NewRelic::Agent.browser_timing_header rescue "" %>
    # existing template code ...
</head>
```

## Soporte de CSP Nonce [#csp-nonce-support]

Si la política de seguridad de contenido está configurada en “unsafe-inline”, puede instrumentar automáticamente el agente del browser. Si desea utilizar un [CSP Nonce](https://content-security-policy.com/nonce/), es posible que deba agregar alguna configuración manual.

### CSP nonce de Rails [#rails-csp-nonce]

[Las versiones 5.2+ de Rails](https://guides.rubyonrails.org/security.html#adding-a-nonce) incluyen una característica para establecer un nonce de CSP mediante una API. En las versiones 9.10.0+ del agente de Ruby, el nonce de CSP de Rails se detectará automáticamente y se aplicará al script de inyección del agente del browser.

Puede desactivar esta característica actualizando el `newrelic.yml` a lo siguiente:

```yaml
  browser_monitoring:
    content_security_policy_nonce: false
```

O establezca la variable de entorno, `NEW_RELIC_BROWSER_MONITORING_CONTENT_SECURITY_POLICY_NONCE=false`.

### Llamada API [#api-call]

Puede pasar un nonce de CSP a la API de `NewRelic::Agent.browser_timing_header` en las versiones 7.1.0+ del agente de Ruby.

Al pasar un nonce a este método, debe desactivar la instrumentación automática del monitoreo de browser y usar la instrumentación manual a través de la API del agente.

Actualice el `newrelic.yml` a:

```yaml
browser_monitoring:
  auto_instrument: false
```

O establezca la variable de entorno, `NEW_RELIC_BROWSER_MONITORING_AUTO_INSTRUMENT=false`.

Ahora puede pasar un nonce como argumento al método API para permitir que el agente inserte el nonce en la instrumentación del browser . Por ejemplo, `NewRelic::Agent.browser_timing_header(nonce)`.

## Resolución de problemas [#troubleshooting]

Si no se reportan los datos del navegador, vea el código fuente HTML y confirme que dos bloques de script similares a los siguientes estén en el encabezado HTML:

```html
<script type="text/javascript">window.NREUM||(NREUM={});...</script>
```

Si no están presentes, verifique:

* La configuración de instrumentación automática
* La ubicación de la instrumentación manual en sus archivos de plantilla
* La forma en que aplica un nonce

## Desactivar la instrumentación automática [#disable-instrumentation]

El valor predeterminado de [`auto-instrument`](/docs/apm/agents/ruby-agent/configuration/ruby-agent-configuration-browser-monitoring-settings#browser-monitoring) es `true` (incluso cuando no se especifica). Para desactivar la instrumentación automática, establezca este indicador en `false`.

```yaml
browser_monitoring:
  auto_instrument: false
```

Para desactivar la instrumentación automática solo para ciertos controladores o acciones de controlador, utilice [`newrelic_ignore_enduser`](/docs/agents/ruby-agent/installation-configuration/ignoring-specific-transactions#page-load-timing-rum). La instrumentación del lado del servidor no se ve afectada por esta llamada.
