Instale el agente Ruby de New Relic para iniciar el monitoreo de la aplicación Ruby. Elija el método que coincida con el entorno en la navegación izquierda.

Necesita una [cuenta de New Relic](https://newrelic.com/signup) y su <InlinePopover type="licenseKey" />para completar la instalación. Consulte los [requisitos del agente Ruby y los frameworks compatibles](/docs/apm/agents/ruby-agent/getting-started/ruby-agent-requirements-supported-frameworks) antes de comenzar.

| Método                                                                                                              | Usar cuando                                                                                         |
| ------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| [Estándar (Bundler/Gemfile)](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent)                 | La mayoría de las aplicaciones de Ruby —Rails, Sinatra, Roda, Rack y otros entornos basados en UNIX |
| [Plug-in de Rails](/docs/apm/agents/ruby-agent/installation/ruby-agent-installation-rails-plugin)                   | Aplicaciones Rails 2+ que usan el método de instalación de plug-in legacy                           |
| [Docker](/docs/apm/agents/ruby-agent/installation/ruby-agent-installation-docker)                                   | Aplicaciones Ruby en contenedores                                                                   |
| [Heroku](/docs/apm/agents/ruby-agent/installation/ruby-agent-heroku)                                                | Aplicaciones desplegadas en Heroku usando el complemento de New Relic                               |
| [Google App Engine](/docs/apm/agents/ruby-agent/installation/install-new-relic-ruby-agent-gae-flexible-environment) | Aplicaciones que se ejecutan en el entorno flexible GAE                                             |
