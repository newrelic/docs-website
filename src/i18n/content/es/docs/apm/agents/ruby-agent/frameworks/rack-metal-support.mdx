[Los middlewares de rack](/docs/agents/ruby-agent/frameworks/rack-middlewares) se instrumentan automáticamente con la versión 3.9.0 o superior del agente Ruby.

El módulo `NewRelic::Agent::Instrumentation::Rack` se eliminó en la versión 4.0.0 del agente de Ruby. Elimine cualquier referencia a este módulo del código. Para obtener más información, consulte [Instrumentado de controladores Metal](/docs/agents/ruby-agent/frameworks/instrumenting-metal-controllers).
