Instrumentar [transacción](/docs/apm/transactions/intro-transactions/transactions-new-relic-apm) usando C SDK para que pueda monitor cualquier aplicación en Linux que use un lenguaje que pueda importar biblioteca C. Después de instrumentar manualmente transacciónes en su código fuente agregando funciones de New Relic, puede ver los datos en la [página<DNT>**Transactions**</DNT> ](/docs/apm/applications-menu/monitoring/transactions-page)en la UI de New Relic.

## Instrumentar una transacción [#c-agent-txn]

Para instrumentar una transacción para que pueda monitor en la UI de New Relic, incluya las funciones de New Relic que inician y detienen la instrumentación alrededor de la transacción. La función que utilices depende de si quieres instrumentar a [web o transacción no web](/docs/apm/transactions/intro-transactions/transactions-new-relic-apm#types).

1. Agregue el siguiente código inmediatamente <DNT>**before**</DNT> la transacción que desea monitor:

   Para transacciones web:

   ```c
   newrelic_txn_t *txn;
   /* ... */
   txn = newrelic_start_web_transaction(app, "NAME_YOUR_TRANSACTION");
   ```

   Para transacciones sin web:

   ```c
   newrelic_txn_t *txn;
   /* ... */
   txn = newrelic_start_non_web_transaction(app, "NAME_YOUR_TRANSACTION");
   ```

2. Agregue el siguiente código inmediatamente después de la transacción web o transacción no web que desea monitorear:

   ```c
   newrelic_end_transaction(&txn);
   ```

## Instrumentar los segmentos y errores. [#segments-errors]

Los segmentos son las funciones y llamadas que componen una transacción. Después de instrumentar su transacción, usted puede:

* [Instrumentar segmentos](/docs/instrument-segments-c-agent) de una transacción si desea obtener más datos sobre las funciones llamadas durante esa transacción.
* [Instrumentar errores](/docs/instrument-errors-c-agent) para que pueda utilizar la UI de New Relic para monitor los errores que ocurren durante su transacción.
