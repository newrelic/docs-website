Utilice la mutación `workflowAutomationCreateSchedule` para crear una programación de una definición de workflow.

<Callout variant="tip">
El número de programaciones y la duración mínima para una programación determinada se definen en [Límites del sistema de flujos de trabajo](/docs/workflow-automation/limitations-and-faq/workflow-limits).
</Callout>

### opción logLevel [#loglevel-option]

La opción `logLevel` controla la cantidad de información de logging generada durante la ejecución del flujo de trabajo.

* `NONE` (predeterminado): no genera salida de log.
* `INFO`: genera información a nivel de paso.
* `DEBUG`: agrega un atributo a los logs de inicio del paso con todas las entradas del paso de acción, usando el formato `workflowAutomation.inputs.<inputName>: <inputValue>`.
* `TRACE`: además de la salida de `DEBUG`, agrega un atributo a los logs de inicio del paso con todas las salidas del paso de acción, usando el formato `workflowAutomation.outputs.<outputName>: <outputValue>`.

## Solicitud de muestra [#sample-request]

Emplee el [generador de consultas](https://one.newrelic.com/nerdgraph-graphiql?state=b8f3b3a9-8d3e-c03e-5da4-34b98a57ff8f) para crear y editar un flujo de trabajo. Consulte [el explorador de la API de NerdGraph](/docs/apis/nerdgraph/get-started/nerdgraph-explorer).

```graphql
  mutation {
    workflowAutomationCreateSchedule(
      scope: {id: "12345678", type: ACCOUNT}
      definition: {name: "healthyHeartbeat", version: 1}
      cronExpression: "0 0 * * *"
      timezone: "Asia/Kolkata"
      options: {logLevel: DEBUG}
      tags: [{key: "environment", values: ["production"]}]
    ) {
      scheduleId
    }
  }
```
