Utilice la mutación `workflowAutomationStopWorkflowRun` para detener un workflow en ejecución.

## parámetro de entrada [#input-parameters]

<thead>
<tr>
<th style={{ width: "200px" }}>

`accountId`
</td>

<td>
Número
</td>

<td>
(Obligatorio) El ID de cuenta.
</td>
</tr>

<tr>
<td>
`runId`
</td>

<td>
Cadena
</td>

<td>
(Obligatorio) El identificador único de la ejecución del workflow que se va a detener. Obtenido de la API `StartWorkflowRun`.
</td>
</tr>
</tbody>
</table>

## Solicitud de muestra [#sample-request]

```graphql
mutation {
  workflowAutomationStopWorkflowRun(
    accountId: 12345678
    runId: "7ffbe082-8efa-4d3d-901a-a08bcf22bcd3"
  ) {
    runId
  }
}
```

## Ejemplo de respuesta [#sample-response]

La mutación devuelve:

* `runId`: El identificador único de la ejecución del flujo de trabajo detenido. Devuelve un `runId` vacío si no se encuentra el flujo de trabajo.
