Utilice la mutación `workflowAutomationStartWorkflowRun` para iniciar una ejecución de workflow para una definición de workflow especificada.

<Callout variant="important">
Para conocer los límites de las ejecuciones de workflow simultáneas y los pasos por ejecución, consulte [Límites del sistema de workflow](/docs/workflow-automation/limitations-and-faq/workflow-limits).
</Callout>

### opción logLevel [#loglevel-option]

La opción `logLevel` controla la cantidad de información que genera el workflow durante la ejecución.

* `NONE` (predeterminado): no genera salidas de log.
* `INFO`: genera información a nivel de paso.
* `DEBUG`: agrega un atributo a los logs de inicio del paso con todas las entradas del paso de acción, usando el formato `workflowAutomation.inputs.<inputName>: <inputValue>`.
* `TRACE`: además de la salida de `DEBUG`, agrega un atributo a los logs de inicio del paso con todas las salidas del paso de acción, usando el formato `workflowAutomation.outputs.<outputName>: <outputValue>`.

## Solicitud de muestra [#sample-request]

Emplee el [generador de consultas](https://one.newrelic.com/nerdgraph-graphiql?state=b8f3b3a9-8d3e-c03e-5da4-34b98a57ff8f) para crear y editar un flujo de trabajo. Consulte [el explorador de la API de NerdGraph](/docs/apis/nerdgraph/get-started/nerdgraph-explorer).

```graphql
mutation {
  workflowAutomationStartWorkflowRun(
    definition: {name: "json-parsing", version: 1}
    workflowInputs: [
      {key: "checkOperational", value: "false"}
      {key: "checkNonOperational", value: "true"}]
    scope: {id: "12345678"}
    idempotencyKey: "45e65924-5316-479c-a977-f6adfa17e07a"
    options: {logLevel: INFO}
  ) {
    runId
  }
}
```

## Ejemplo de respuesta [#sample-response]

La mutación devuelve:

* `runId`: El identificador único para la ejecución del flujo de trabajo. Use este ID con las API `WorkflowRunInfo`, `SignalWorkflowRun` o `StopWorkflowRun`.
