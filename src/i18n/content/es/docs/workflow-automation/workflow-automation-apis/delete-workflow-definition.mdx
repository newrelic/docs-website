Utilice la mutación `workflowAutomationDeleteWorkflowDefinition` para eliminar todas las versiones de una definición de workflow con el nombre especificado.

<Callout variant="important">
* Para eliminar una definición, no debe haber programaciones que la utilicen. Si la definición es utilizada actualmente por una programación, la eliminación falla y devuelve un error.
* Todas las ejecuciones de workflow en curso continúan hasta completarse incluso si se elimina la definición.
</Callout>

## Solicitud de muestra [#sample-request]

```graphql
  workflowAutomationDeleteWorkflowDefinition(
    definition: {name: "my-workflow"}
    scope: {id: "12345678", type: ACCOUNT}
  ) {
    definition {
      name
    }
  }
}
```
