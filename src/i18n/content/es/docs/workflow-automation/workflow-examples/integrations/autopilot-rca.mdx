Las siguientes plantillas de flujo de trabajo automatizan el análisis de causa raíz impulsado por <DNT>Autopilot</DNT>para las alertas de New Relic:

* **[RCA de alerta con Autopilot y Slack](/docs/workflow-automation/workflow-examples/integrations/autopilot-slack-rca)** — Publica los hallazgos en un canal de Slack utilizando el formato Block Kit
* **[RCA de alerta con Autopilot y correo electrónico](/docs/workflow-automation/workflow-examples/integrations/autopilot-email-rca)** — Envía los hallazgos como un correo electrónico en formato HTML

Estas plantillas aceptan una entrada `issueId` y ejecutan <DNT>Autopilot</DNT> con un símbolo de RCA. Comprueban si <DNT>Autopilot</DNT> devolvió una respuesta utilizable y enrutan la salida al destino elegido. Difieren en el tipo de destino y en cómo formatean la salida de <DNT>Autopilot&apos;s</DNT>.

## Requisitos [#requirements]

Todas las plantillas requieren un ID de incidencia de alerta de New Relic en formato UUID. Cada plantilla también requiere un destino de notificación configurado —consulte las páginas individuales de las plantillas para conocer los requisitos previos específicos del destino.

<Callout variant="tip">
  Al activar cualquiera de estas plantillas desde <DNT>**Alert Workflows**</DNT>, utilice `{{ issueId }}` como valor para la entrada `issueId`. Esta variable pasa automáticamente el ID del problema de la alerta desencadenante al flujo de trabajo.
</Callout>

## Notas de configuración [#configuration]

Tenga en cuenta lo siguiente al configurar cualquiera de estas plantillas.

<Callout variant="important">
  Escriba los valores del selector `expression` en una sola línea. El motor de flujo de trabajo no evalúa los escalares de bloque YAML de varias líneas (`|` o `|-`) como expresiones de selector —no producen ninguna salida de forma silenciosa.
</Callout>

<Callout variant="tip">
  <DNT>Autopilot&apos;s</DNT> `finalAnswer` el campo puede devolverse como una cadena sin formato o como un objeto codificado en JSON dependiendo del contexto del símbolo. Los selectores de cada plantilla manejan ambas formas automáticamente.
</Callout>
