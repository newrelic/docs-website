Este documento describe los diversos datos de observabilidad que se pueden utilizar para monitorear las ejecuciones del flujo de trabajo o las programaciones.

## Auditorías

Todas las llamadas de mutación de NerdGraph se auditan y los datos están disponibles para su consulta en `NrAuditEvent` en la cuenta de los clientes.

### WorkflowRun

```sql
SELECT actionIdentifier, actorId, actorType, description
FROM NrAuditEvent 
WHERE targetType = 'workflow_run'
SINCE 1 hour ago
```

### WorkflowSchedule

```sql
SELECT actionIdentifier, actorId, actorType, description
FROM NrAuditEvent 
WHERE targetType = 'workflow_schedule'
SINCE 1 hour ago
```

## Evento

Todas las ejecuciones de flujos de trabajo emiten datos `WorkflowAutomationEvent` en NRDB en la cuenta del cliente que se usó para iniciar, o programar, un flujo de trabajo.

Se crea un nuevo namespace `WorkflowAutomation` para los datos de eventos de las ejecuciones de flujos de trabajo.

### Consulta de ejemplo

Por ejemplo:

```sql
SELECT *
FROM WorkflowAutomationEvent
where definitionName = 'json-parsing' and runId = '31c973d2-c669-4bd7-9b15-7e3a70a4a074'
SINCE 1 month ago
```

## Logs

Opcionalmente, un flujo de trabajo se puede iniciar, o programar, especificando una opción de nivel de detalle `logLevel`. Esos logs se agregan a la cuenta del flujo de trabajo que se usó para iniciar o programar el flujo de trabajo.

Los logs tienen los siguientes atributos:

* `workflowAutomation.name` es el nombre de WorkflowDefinition
* `workflowAutomation.version` es la versión de WorkflowDefinition
* `workflowAutomation.runId` es el runId del flujo de trabajo
* `entityGuid` es el ID de WorkflowDefinition

Si se inició desde una ocurrencia de horario:

* `workflowAutomation.scheduleId`

Para el tipo de paso Action, al usar `DEBUG`, cada entrada de acción agrega un atributo adicional a la entrada de log con el formato `workflowAutomation.inputs.<inputName>: <inputValue>`.

Para el tipo de paso de acción, al usar `TRACE`, cada salida de acción agrega un atributo adicional a la entrada de registro con el formato `workflowAutomation.outputs.<outputName>: <outputValue>`.

### Ejemplo de consulta NRQL

Puede consultar su log con la siguiente consulta NRQL:

```sql
SELECT message FROM Log WHERE workflowAutomation.runId = '{run_id}' SINCE 3 hours ago
```

<img title="Diagram of log attributes for workflow runs" alt="Diagram of log attributes for workflow runs" src="/images/log_attributes.webp" />

Además de `workflowAutomation.runId`, algunos otros atributos de log que pueden ayudar con la consulta de datos log son:

* `workflowAutomation.name`
* `workflowAutomation.version`

Para las ejecuciones programadas, las entradas de log también tendrán el atributo `workflowAutomation.scheduleId`.
