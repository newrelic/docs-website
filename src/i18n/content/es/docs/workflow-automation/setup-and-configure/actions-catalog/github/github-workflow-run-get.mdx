Recupera los detalles, el estado y la conclusión de una ejecución específica de flujo de trabajo de GitHub Actions mediante su ID de ejecución numérico. Por lo general, el ID de ejecución se obtiene de un paso `gitHub.workflowRun.trigger` o `gitHub.workflowRun.list` anterior.

Para la configuración de la autenticación, consulte las [acciones de ejecución del flujo de trabajo de GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run).

<td>
```yaml
name: poll_workflow_run
description: Get the status of a specific GitHub Actions workflow run
steps:
  - name: get_run
    type: action
    action: gitHub.workflowRun.get
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      runId: ${{ .steps.trigger_run.outputs.response.workflow_run_id }}
      selectors:
        - name: status
          expression: ".status"
        - name: conclusion
          expression: ".conclusion"
        - name: htmlUrl
          expression: ".html_url"
    next: end
```
