Las acciones de Azure Cosmos DB le permiten leer, escribir y administrar documentos y bases de datos en Azure Cosmos DB directamente desde los flujos de trabajo. Todas las acciones se autentican mediante una entidad de servicio de Azure AD y se comunican con el plano de datos de Cosmos DB.

## Obtener un elemento [#azure-cosmos-getitem]

Esta acción lee un único documento por ID de un contenedor de Azure Cosmos DB mediante la API REST [Azure Cosmos DB - Get Document](https://learn.microsoft.com/en-us/rest/api/cosmos-db/get-a-document).

## Actualizar un elemento [#azure-cosmos-updateitem]

Esta acción reemplaza o inserta/actualiza un documento en un contenedor de Azure Cosmos DB mediante la API REST [Azure Cosmos DB - Replace Document](https://learn.microsoft.com/en-us/rest/api/cosmos-db/replace-a-document). De forma predeterminada (`upsert: false`), el documento ya debe existir. Establezca `upsert: true` para crear el documento si no existe.
