El identificador de la acción es `newrelic.alerts.searchPolicies`.

Busca políticas de alertas con filtrado opcional por ID o nombre. Admite paginación basada en cursor. Si se omiten todos los filtros, se devuelven todas las políticas de la cuenta.

              ```yaml
              name: search_alert_policies
              description: Search alert policies by name
              steps:
                - name: searchPolicies
                  type: action
                  action: newrelic.alerts.searchPolicies
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    nameLike: "Production"
                    selectors:
                      - name: policies
                        expression: ".data.actor.account.alerts.policiesSearch.policies"
                  next: end
              ```
