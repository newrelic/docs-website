Reporta eventos personalizados a New Relic.

Para los prerrequisitos, consulte las [acciones de New Relic Ingest](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/ingest/newrelic-ingest#prerequisites).

## Enviar eventos a New Relic

El identificador de la acción es `newrelic.ingest.sendEvents`.

Informa un evento personalizado a New Relic.

    <TabsPageItem id="newrelic-ingest-send-events-example">
      El siguiente ejemplo envía varios eventos personalizados con atributos compartidos y por evento, y luego los recupera con una consulta NRQL.

      <table>
        <thead>
          <tr>
            <th>
              Ejemplo de flujo de trabajo
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: heartbeat_newrelicIngestSendEvents

              workflowInputs:
                cellName:
                  type: String

              steps:
                - name: runAction
                  type: action
                  action: newrelic.ingest.sendEvents
                  version: 1
                  inputs:
                    attributes:
                      colour: red
                      id: 1234
                    events:
                      - eventType: HeartBeat
                        test: "OK"
                        attributes:
                          foo: bar
                      - eventType: HeartBeat1234
                        test: "OK1234"
                        attributes:
                          foo: bar
                      - eventType: HeartBeat12345
                        test: "OK12345"
                        attributes:
                          foo: bar
                          colour: yellow
                      - eventType: HeartBeat12345678
                        test: "OK12345678"
                    selectors:
                      - name: success
                        expression: ".success"
              ```

              **Resultado esperado:**

              ```yaml
                {
                  "success": true
                }
              ```

              **Recuperar evento:**

              Tras ejecutar correctamente un flujo de trabajo, puede recuperar el evento asociado ejecutando una consulta en la cuenta que ejecutó el flujo de trabajo:

              ```sql
              SELECT * FROM HeartBeat
              ```
            </td>
          </tr>
