Esta página proporciona una referencia de las acciones de AWS EC2 disponibles en el catálogo de acciones de automatización de flujo de trabajo. Utilice estas acciones para administrar instancias EC2 e instantáneas de EBS.

## Requisitos previos

Antes de emplear las acciones AWS en la automatización del flujo de trabajo, cerciorar de tener lo siguiente:

* Una cuenta de AWS con las licencias adecuadas.
* Credenciales de AWS configuradas (credenciales de usuario de IAM, ARN de rol de IAM o credenciales de sesión).
* Las licencias IAM necesarios para los servicios específicos de AWS que planea emplear.

Consulte [Configurar credenciales de AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials/) para obtener información sobre cómo crear usuarios y roles de IAM, y configurar credenciales de AWS estáticas y de sesión para la integración con las acciones de AWS de automatización de flujos de trabajo.

## Instancia de ejecución

## Solicitar el reinicio de una instancia

El identificador de la acción es `aws.ec2.rebootInstances`.

Solicita el reinicio de las instancias especificadas. Esta operación es asincrónica —solo pone en cola una solicitud para reiniciar las instancias especificadas. La operación se realiza correctamente si las instancias son válidas y le pertenecen. Se ignoran las solicitudes para reiniciar instancias terminadas. Si una instancia no se apaga correctamente en unos pocos minutos, Amazon EC2 realiza un reinicio forzado.
