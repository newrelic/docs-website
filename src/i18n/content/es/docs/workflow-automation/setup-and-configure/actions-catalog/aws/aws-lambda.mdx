Esta página proporciona una referencia de las acciones de AWS Lambda disponibles en el catálogo de acciones de automatización de flujo de trabajo. Utilice estas acciones para administrar e invocar funciones Lambda como parte de las definiciones de su flujo de trabajo.

## Requisitos previos

Antes de emplear acciones de AWS Lambda en la automatización del flujo de trabajo, cerciorar de tener lo siguiente:

* Una cuenta de AWS con las licencias adecuadas.
* Credenciales de AWS configuradas (credenciales de usuario de IAM, ARN de rol de IAM o credenciales de sesión). Se debe proporcionar al menos una opción de credencial —el rol de IAM tiene prioridad sobre las claves de acceso estáticas.
* Los permisos de IAM necesarios para las operaciones de Lambda específicas que planea utilizar.

Consulte [Configurar credenciales de AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials/) para obtener información sobre cómo crear usuarios y roles de IAM, y configurar credenciales de AWS estáticas y de sesión para la integración con las acciones de AWS de automatización de flujos de trabajo.

## Enumerar funciones Lambda

## Obtener el historial de ejecución duradera de Lambda

El identificador de la acción es `aws.lambda.getDurableExecutionHistory`.

Recupera el historial de ejecución de una [ejecución duradera de Lambda](https://docs.aws.amazon.com/lambda/latest/dg/durable-functions.html), que muestra todos los pasos, las devoluciones de llamada y los eventos que ocurrieron. Esta acción se aplica solo a las ejecuciones duraderas de Lambda —no puede recuperar el historial de invocaciones para funciones Lambda regulares. El historial está disponible mientras la ejecución está en curso y durante un período de retención configurable después de que se completa (1-90 días, 30 días por defecto).

Para ejecuciones de larga duración con muchos pasos o devolución de llamada, establezca `includeExecutionData` en `false` cuando solo necesite tipos de evento y timestamp en lugar de carga completa —esto produce una respuesta más compacta.

## Establecer la simultaneidad de la función Lambda

Establece la simultaneidad reservada para una función Lambda —el número máximo de ejecuciones simultáneas. La configuración de simultaneidad se aplica a todas las versiones publicadas y a la versión no publicada. Establecer `reservedConcurrentExecutions` en `0` deshabilita la función sin eliminarla.
