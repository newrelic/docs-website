El identificador de la acción es `newrelic.alerts.listMutingRules`.

Lista las reglas de silenciamiento para una cuenta. Filtra opcionalmente por estado habilitado. Esta acción no está paginada por cursor y devuelve todas las reglas coincidentes en una sola respuesta.

                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
