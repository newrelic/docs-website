Esta página proporciona una referencia de las acciones de AWS Bedrock disponibles en el catálogo de acciones de automatización del flujo de trabajo. Utilice estas acciones para invocar agentes de Bedrock como parte de las definiciones de flujo de trabajo.

## Requisitos previos

Antes de usar las acciones de AWS Bedrock en la automatización del flujo de trabajo, asegúrese de tener:

* Una cuenta de AWS con las licencias adecuadas.
* Credenciales de AWS configuradas (credenciales de usuario de IAM, ARN de rol de IAM o credenciales de sesión). Se debe proporcionar al menos una opción de credencial —el rol de IAM tiene prioridad sobre las claves de acceso estáticas.
* Los permisos de IAM necesarios para las operaciones de Bedrock (`bedrock:InvokeAgent`, `bedrock:InvokeModel`).

Consulte [Configurar credenciales de AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials/) para obtener información sobre cómo crear usuarios y roles de IAM, y configurar credenciales de AWS estáticas y de sesión para la integración con las acciones de AWS de automatización de flujos de trabajo.

## Invocar un agente de Bedrock

El identificador de la acción es `aws.bedrock.invokeAgent`.

Invoca un agente de AWS Bedrock con un símbolo y devuelve la respuesta del agente.
