Esta página proporciona una referencia de las acciones de AWS Step Functions disponibles en el catálogo de acciones de automatización del flujo de trabajo. Utilice estas acciones para iniciar, detener, reimpulsar e inspeccionar las ejecuciones de Step Functions y las máquinas de estado desde las definiciones del flujo de trabajo.

## Requisitos previos

Antes de usar las acciones de AWS Step Functions en la automatización del flujo de trabajo, asegúrese de tener:

* Una cuenta de AWS con las licencias adecuadas.
* Credenciales de AWS configuradas (credenciales de usuario de IAM, ARN de rol de IAM o credenciales de sesión).
* Los permisos de IAM necesarios para las operaciones de Step Functions.

Consulte [Configurar credenciales de AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials/) para obtener información sobre cómo crear usuarios y roles de IAM, y configurar credenciales de AWS estáticas y de sesión para la integración con las acciones de AWS de automatización de flujos de trabajo.

## Licencias IAM requeridos

Los permisos que necesita dependen de las acciones de Step Functions a las que llame el flujo de trabajo. Use el siguiente ejemplo como plantilla para una política de privilegios mínimos que cubra las siete acciones.

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "states:StartExecution",
        "states:StopExecution",
        "states:RedriveExecution",
        "states:DescribeExecution",
        "states:ListExecutions",
        "states:DescribeStateMachine",
        "states:ListStateMachines"
      ],
      "Resource": "arn:aws:states:<region>:<account-id>:*"
    }
  ]
}
```

<Callout variant="important">
  Reemplace `<region>` y `<account-id>` con los valores reales y restrinja `Resource` a los ARN de máquina de estado o de ejecución específicos donde sea posible.
</Callout>

## Iniciar una ejecución de Step Functions

El identificador de la acción es `aws.stepFunctions.startExecution`.

Inicia una ejecución de una máquina de estado de AWS Step Functions. Si se realiza correctamente, devuelve el `executionArn` de la nueva ejecución, que puede pasar a [`aws.stepFunctions.describeExecution`](#describe-a-step-functions-execution) para consultar su estado.

## Detener una ejecución de Step Functions

El identificador de la acción es `aws.stepFunctions.stopExecution`.

Detiene una ejecución de Step Functions en curso. AWS marca la ejecución como `ABORTED` una vez que se detiene.

<Callout variant="important">
  Esta acción solo es compatible con las máquinas de estado `STANDARD`. No puede detener `EXPRESS` ejecuciones.
</Callout>

## Reimpulsar una ejecución de Step Functions

El identificador de la acción es `aws.stepFunctions.redriveExecution`.

Reimpulsa una ejecución de Step Functions fallida, con tiempo de espera agotado o cancelada, reanudándola desde el último estado no exitoso sin comenzar de nuevo desde el principio.

<Callout variant="important">
  Esta acción solo es compatible con las máquinas de estado `STANDARD`. Una ejecución solo se puede reimpulsar si no ha `SUCCEEDED`, está dentro de los 14 días posteriores a su finalización y tiene menos de 24 999 eventos de historial.
</Callout>

## Describir una ejecución de Step Functions

El identificador de la acción es `aws.stepFunctions.describeExecution`.

Devuelve el estado, la entrada, la salida y los timestamp para una ejecución de Step Functions. Utilice esta acción para sondear el resultado de una ejecución iniciada por [`aws.stepFunctions.startExecution`](#start-a-step-functions-execution).

<Callout variant="important">
  Esta acción admite `STANDARD` ejecuciones de máquinas de estado directamente. Solo puede describir `EXPRESS` ejecuciones que despachó un Map Run.
</Callout>

              ```yaml
                  type: action
                  action: aws.stepFunctions.describeExecution

                  inputs:

                    region: us-east-1
                    executionArn: ${{ .workflowInputs.executionArn }}
                    selectors:
                      - name: status
                        expression: '.response.status'
                      - name: output
                        expression: '.response.output'
              ```
