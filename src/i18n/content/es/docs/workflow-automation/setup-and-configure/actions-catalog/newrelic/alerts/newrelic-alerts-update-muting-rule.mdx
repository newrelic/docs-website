El identificador de la acción es `newrelic.alerts.updateMutingRule`.

Actualiza una regla de silenciamiento existente. Todos los campos, excepto `accountId` y `id`, son opcionales —solo se cambian los campos que proporcione.

      El siguiente ejemplo desactiva una regla de silenciamiento después de que finalice una ventana de despliegue.

      <table>
        <thead>
          <tr>
            <th>
              Ejemplo de flujo de trabajo
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: update_muting_rule
              description: Disable a muting rule
              steps:
                - name: updateMutingRule
                  type: action
                  action: newrelic.alerts.updateMutingRule
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    id: ${{ .workflowInputs.mutingRuleId }}
                    enabled: false
                  next: end
              ```
            </td>
