## Ejecutar Autopilot [#newrelic-autopilot-run]

Ejecuta New Relic Autopilot — un agente de IA que analiza alertas, investiga posibles causas raíz y sugiere acciones de corrección. Seleccione **Run Autopilot** en el catálogo de acciones del editor de flujo de trabajo — no necesita especificar un ID de agente.

          type: action

          version: '1'

            prompt: Summarize recent alert activity for my account
            context:
