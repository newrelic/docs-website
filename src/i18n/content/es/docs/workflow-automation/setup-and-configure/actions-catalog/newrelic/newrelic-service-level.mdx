Esta página proporciona una referencia de todas las acciones de nivel de servicio de New Relic disponibles en el catálogo de acciones de automatización de flujos de trabajo. Estas acciones le permiten crear, actualizar, eliminar y listar indicadores de nivel de servicio (SLI) y sus objetivos de nivel de servicio (SLO) directamente desde un flujo de trabajo —lo que permite la incorporación automatizada de servicios, la corrección de SLO y los flujos de trabajo de cumplimiento.

## Requisitos previos

Antes de usar las acciones de nivel de servicio de New Relic en la automatización del flujo de trabajo, asegúrese de tener lo siguiente:

Una cuenta de New Relic con los permisos apropiados para administrar los niveles de servicio.

## Actualizar un nivel de servicio

El identificador de la acción es `newrelic.serviceLevel.update`.

Actualiza la configuración de un indicador de nivel de servicio existente o sus objetivos de nivel de servicio. Usa `newrelic.nerdgraph.execute`.

Los campos `name` y `description` son opcionales individualmente —omitir cualquiera de ellos conserva el valor existente. Los campos `target` y `windowDays` son a todo o nada: proporcione ambos para cambiar el objetivo de SLO, u omita ambos para mantener el SLO existente sin cambios.

Para la configuración de eventos (`validEvents*`, `conditionEvents*`, `eventCategory`, `facets`), omitir cualquier campo lo elimina en lugar de conservarlo. Para cambiar un campo en la sección de eventos, vuelva a proporcionar la definición completa de eventos actuales junto con el cambio.
