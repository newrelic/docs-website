Esta página proporciona una referencia de la acción `ansible.job.getStatus` disponible en el catálogo de acciones de automatización de flujos de trabajo. Utilice esta acción para sondear un trabajo creado por [`ansible.job.launch`](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job-launch) hasta que alcance un estado terminal.

Para conocer los requisitos previos, consulte las [acciones de trabajo de Ansible](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job#prerequisites).

## Obtener el estado de un trabajo de Ansible

El identificador de la acción es `ansible.job.getStatus`.

Obtiene el estado y los detalles de un trabajo de Automation Controller. Los estados del trabajo progresan de `pending` a `waiting` a `running` antes de alcanzar un estado terminal: `successful`, `failed`, `error` o `canceled`. El extremo es `GET https://{host}/api/controller/v2/jobs/{jobId}/`.

              steps:
                - name: get_status
                  type: action
                  action: ansible.job.getStatus
                  version: 1
                  inputs:
                    host: ${{ :secrets:host }}
                    authToken: ${{ :secrets:ansibleControllerToken }}
                    jobId: "128"
                    selectors:
                      - name: status
                        expression: ".status"
                      - name: failed
                        expression: ".failed"
                  next: end
