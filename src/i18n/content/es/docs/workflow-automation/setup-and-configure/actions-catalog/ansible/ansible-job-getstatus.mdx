Esta página proporciona una referencia de la acción `ansible.job.getStatus` disponible en el catálogo de acciones de automatización de flujos de trabajo. Utilice esta acción para recuperar el estado y los detalles de un trabajo de la plataforma Ansible Automation (Automation Controller). Utilice esta acción para consultar un trabajo creado por [`ansible.job.launch`](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job-launch). Esta acción se basa en la acción base `http.get`.

**Extremo:** `GET https://{host}/api/controller/v2/jobs/{jobId}/`

## Requisitos previos

Antes de usar esta acción en la automatización del flujo de trabajo, asegúrese de tener:

* Una instancia de la plataforma Ansible Automation (Automation Controller) accesible a través de HTTPS.
* Un token OAuth2 con alcance de escritura (cree uno en **Automation Controller → usuario → token**)
* El ID de trabajo numérico a sondear (generalmente el campo `id` devuelto por `ansible.job.launch`).
