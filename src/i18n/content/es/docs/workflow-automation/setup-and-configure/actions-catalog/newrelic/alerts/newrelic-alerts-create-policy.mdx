El identificador de la acción es `newrelic.alerts.createPolicy`.

Crea una nueva política de alertas. Una política agrupa condiciones de alerta relacionadas y controla cómo las infracciones crean incidentes.

          <tr>
            <td>
              ```yaml
              name: create_alert_policy
              description: Create an alert policy
              steps:
                - name: createPolicy
                  type: action
                  action: newrelic.alerts.createPolicy
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    name: "Production Services"
                    incidentPreference: "PER_CONDITION"
                    selectors:
                      - name: policyId
                        expression: ".data.alertsPolicyCreate.id"
                  next: end
              ```
