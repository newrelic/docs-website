Elimina una o más claves de etiqueta y todos los valores bajo ellas de una entidad de New Relic.

Para conocer los prerrequisitos, consulte las [acciones de etiqueta de New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites).

## Eliminar etiquetas

El identificador de la acción es `newrelic.tagging.deleteTags`.

Elimina una o más claves de etiqueta y todos los valores bajo ellas de una entidad de New Relic. Para eliminar solo valores específicos mientras se mantienen otros valores bajo la misma clave, utilice [`newrelic.tagging.deleteTagValues`](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging-deletetagvalues) en su lugar. Desarrollado en `newrelic.nerdgraph.execute`.
