Transiciona una incidencia de Jira a un estado diferente. Utilice la acción [Obtener transiciones de incidencias de Jira](/docs/workflow-automation/setup-and-configure/actions-catalog/jira/jira-issue-gettransitions) para recuperar los ID de transición disponibles antes de llamar a esta acción.

Para la configuración de la autenticación, consulte las [acciones de incidencias de Jira](/docs/workflow-automation/setup-and-configure/actions-catalog/jira/jira-issue).

              steps:
                - name: transitionJiraIssue
                  type: action
                  action: jira.issue.doTransition
                  version: 1
                  inputs:
                    authToken: ${{ :secrets:jiraAuthToken }}
                    domain: mycompany
                    issueKey: "PROJ-123"
                    transitionId: "181"
                    fields:
