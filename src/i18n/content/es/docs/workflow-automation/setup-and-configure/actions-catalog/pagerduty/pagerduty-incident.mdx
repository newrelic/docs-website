Esta página proporciona una referencia de todas las acciones de incidentes de PagerDuty disponibles en el catálogo de acciones de automatización del flujo de trabajo. Utilice estas acciones para crear, recuperar, listar, actualizar y resolver incidentes de PagerDuty directamente desde un flujo de trabajo.

## Requisitos previos

Antes de usar las acciones de PagerDuty en la automatización del flujo de trabajo, necesita:

* Una cuenta de PagerDuty con los permisos apropiados para gestionar incidentes.
* Un token de API de PagerDuty (token de usuario o token de cuenta).
* La dirección de correo electrónico `from` del usuario que realiza la solicitud (necesaria para los tokens de cuenta en las acciones relevantes).
