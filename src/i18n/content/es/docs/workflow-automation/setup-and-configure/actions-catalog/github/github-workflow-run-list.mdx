Enumera las ejecuciones de flujo de trabajo de GitHub Actions para un respositorio, con filtrado opcional por flujo de trabajo, rama, evento, estado y más. Si se proporciona `workflowId`, la lista se limita a ese flujo de trabajo específico; de lo contrario, devuelve las ejecuciones de todo flujo de trabajo en el respositorio.

Para la configuración de la autenticación, consulte las [acciones de ejecución del flujo de trabajo de GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run).

<tr>
<td>
```yaml
name: list_workflow_runs
description: List GitHub Actions workflow runs for a specific workflow
steps:
  - name: list_runs
    type: action
    action: gitHub.workflowRun.list
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      workflowId: deploy.yml
      branch: main
      status: completed
      resultsPerPage: 10
      selectors:
        - name: totalCount
          expression: ".total_count"
        - name: latestRunId
          expression: ".workflow_runs[0].id"
        - name: latestConclusion
          expression: ".workflow_runs[0].conclusion"
    next: end
```
