Esta página proporciona una referencia de las acciones de configuración de New Relic Logs disponibles en el catálogo de acciones de automatización del flujo de trabajo. Utilice estas acciones para consultar los recursos de configuración de logs —reglas de análisis, reglas de partición de datos, expresiones y reglas de ofuscación y ajustes del pipeline— y realizar operaciones como validar patrones Grok y actualizar la configuración del pipeline, directamente desde una definición de flujo de trabajo.

## Requisitos previos

Antes de usar las acciones de configuración de New Relic Logs en la automatización del flujo de trabajo, asegúrese de tener:

* Cuenta de New Relic con los permisos apropiados para acceder a la configuración de administración de logs.
* El ID de cuenta para cada cuenta cuya configuración de logs desea consultar o actualizar.
