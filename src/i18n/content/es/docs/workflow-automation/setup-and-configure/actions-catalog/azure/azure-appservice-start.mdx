Inicia una aplicación web detenida de Azure App Service. Utilice esta acción para restaurar el acceso después de un apagado programado, una detención manual o una reducción de escala provocada por un incidente.

Para la configuración de la autenticación, consulte las [acciones de Azure App Service](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-appservice).

<TabsPageItem id="azureappservicestartexample">
```yaml
name: startAzureAppService
description: Start a stopped Azure App Service
steps:
  - name: start_app_service
    type: action
    action: azure.appService.start
    version: 1
    inputs:
      clientId: ${{ :secrets:azure-client-id }}
      clientSecret: ${{ :secrets:azure-client-secret }}
      tenantId: ${{ :secrets:azure-client-tenant }}
      subscriptionId: "12345678-1234-1234-1234-123456789abc"
      resourceGroupName: "my-resource-group"
      appServiceName: "my-web-app"
    next: end
```
