Elimina valores de etiqueta específicos de una entidad de New Relic, dejando intactos otros valores bajo la misma clave.

Para conocer los prerrequisitos, consulte las [acciones de etiqueta de New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites).

## Eliminar valores de etiqueta

El identificador de la acción es `newrelic.tagging.deleteTagValues`.

Elimina pares de valor principal específicos de las etiquetas de una entidad de New Relic. Mantenemos otros valores bajo la misma clave. Para eliminar una clave de etiqueta completa y todos sus valores, utilice [`newrelic.tagging.deleteTags`](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging-deletetags) en su lugar. Basado en `newrelic.nerdgraph.execute`.

              steps:
                - name: removeUiTagValue
                  type: action
                  action: newrelic.tagging.deleteTagValues
                  version: 1
                  inputs:
                    entityGuid: ${{ .workflowInputs.entityGuid }}
