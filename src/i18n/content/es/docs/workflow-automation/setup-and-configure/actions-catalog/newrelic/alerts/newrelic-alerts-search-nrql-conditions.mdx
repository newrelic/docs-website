El identificador de la acción es `newrelic.alerts.searchNrqlConditions`.

Busca condiciones de alerta NRQL (estáticas o de línea de base) con filtrado opcional por nombre, política, texto de consulta NRQL u operador de términos. Admite paginación basada en cursor. Omitir todos los filtros devuelve todas las condiciones de la cuenta.

              ```yaml
              name: search_nrql_conditions
              description: Search NRQL alert conditions
              steps:
                - name: searchConditions
                  type: action
                  action: newrelic.alerts.searchNrqlConditions
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    policyId: ${{ .workflowInputs.policyId }}
                    nameLike: "error rate"
                    selectors:
                      - name: nrqlConditions
                        expression: ".data.actor.account.alerts.nrqlConditionsSearch.nrqlConditions"
                  next: end
              ```
