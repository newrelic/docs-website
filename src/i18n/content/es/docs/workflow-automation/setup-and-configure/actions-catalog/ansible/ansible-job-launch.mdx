Esta página proporciona una referencia de la acción `ansible.job.launch` disponible en el catálogo de acciones de automatización de flujos de trabajo. Utilice esta acción para lanzar una plantilla de trabajo de Ansible Automation Platform (Automation Controller) desde un paso del flujo de trabajo.

Para conocer los requisitos previos, consulte las [acciones de trabajo de Ansible](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job#prerequisites).

## Lanzamiento de una plantilla de trabajo de Ansible

El identificador de la acción es `ansible.job.launch`.

Realiza el lanzamiento de una plantilla de trabajo de la plataforma Ansible Automation (Automation Controller) y devuelve el trabajo creado. En caso de éxito, devuelve un trabajo `id` que puede usar con [`ansible.job.getStatus`](/docs/workflow-automation/setup-and-configure/actions-catalog/ansible/ansible-job-getstatus) para consultar el trabajo hasta que alcance un estado terminal. El extremo es `POST https://{host}/api/controller/v2/job_templates/{jobTemplateId}/launch/`.

              ```yaml
              name: launch-ansible-remediation
              description: Launch an Ansible job template to remediate an incident
              steps:
                - name: launch_job
                  type: action
                  action: ansible.job.launch
                  version: 1
                  inputs:
                    host: ${{ :secrets:host }}
                    authToken: ${{ :secrets:ansibleControllerToken }}
                    jobTemplateId: "42"
                    extraVars:
                      target_env: staging
                      app_version: "1.2.3"
                    selectors:
                      - name: jobId
                        expression: ".id"
                  next: end
              ```
