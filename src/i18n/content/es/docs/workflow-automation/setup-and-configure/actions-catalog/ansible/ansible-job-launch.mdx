Esta página proporciona una referencia completa de las acciones de trabajos de Ansible disponibles en el catálogo de acciones de automatización de flujos de trabajo. Estas acciones le permiten lanzar y administrar plantillas de trabajos de la plataforma Ansible Automation (Automation Controller).

## Requisitos previos

Antes de usar las acciones de Ansible en la automatización del flujo de trabajo, asegúrese de tener:

* Una instancia de la plataforma Ansible Automation (Automation Controller) accesible a través de HTTPS.
* Un token OAuth2 con alcance de escritura para el lanzamiento de trabajos (cree uno en **Automation Controller &gt; Users &gt; Tokens**).
* El ID numérico de la plantilla de trabajo que desea lanzar.
* La configuración `ask_*_on_launch` habilitada en la plantilla de trabajo para cada entrada opcional que planea usar (`extraVars`, `limit`, `inventory`).

    El extremo es `POST https://{host}/api/controller/v2/job_templates/{jobTemplateId}/launch/`
