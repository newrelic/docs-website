Recupera la ejecución del flujo de trabajo de GitHub Actions más reciente para un flujo de trabajo específico. Útil cuando se desconoce el ID de ejecución exacto —por ejemplo, inmediatamente después de desencadenar una ejecución. Siempre devuelve como máximo una ejecución.

Para la configuración de la autenticación, consulte las [acciones de ejecución del flujo de trabajo de GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run).

<tr>
<td>
```yaml
name: get_latest_workflow_run
description: Retrieve the most recent workflow run for a specific workflow
steps:
  - name: get_latest_run
    type: action
    action: gitHub.workflowRun.getLatest
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      workflowId: deploy.yml
      branch: main
      event: workflow_dispatch
      selectors:
        - name: runId
          expression: ".workflow_runs[0].id"
        - name: conclusion
          expression: ".workflow_runs[0].conclusion"
        - name: htmlUrl
          expression: ".workflow_runs[0].html_url"
    next: end
```
</td>
