Esta página proporciona una referencia de todas las acciones de notificación de New Relic disponibles en el catálogo de acciones de automatización de flujos de trabajo. Estas acciones le permiten enviar mensajes a destinos configurados, generar URL de señales con intervención humana y activar otras ejecuciones de flujos de trabajo.

## Requisitos previos

Antes de usar las acciones de notificación de New Relic en la automatización del flujo de trabajo, asegúrese de tener:

* Una cuenta de New Relic con las licencias adecuadas.
* Una clave de licencia de New Relic (si se envían datos a una cuenta diferente).
* Las licencias necesarias para los servicios específicos de New Relic que planea emplear.

Consulta [Clave de licencia](/docs/apis/intro-apis/new-relic-api-keys#license-key) para obtener información sobre cómo crear y administrar tu clave de licencia de la cuenta de New Relic.
