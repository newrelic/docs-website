Esta página proporciona una referencia de todas las acciones de trabajo de Ansible disponibles en el catálogo de acciones de automatización del flujo de trabajo. Use estas acciones para lanzar y monitorear las plantillas de trabajo de la plataforma de automatización de Ansible (Automation Controller) desde sus flujos de trabajo.

## Requisitos previos

Antes de usar acciones de Ansible en la automatización del flujo de trabajo, necesita:

* Una instancia de la plataforma Ansible Automation (Automation Controller) accesible a través de HTTPS.
* Un token OAuth2 con alcance de escritura para el lanzamiento de trabajos (cree uno en **Automation Controller &gt; Users &gt; Tokens**).
* Un ID numérico de plantilla de trabajo para la plantilla que desea lanzar.
* La configuración `ask_*_on_launch` habilitada en la plantilla de trabajo para cada entrada opcional que planea usar (`extraVars`, `limit`, `inventory`).
