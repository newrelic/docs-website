Esta página proporciona una referencia de las acciones de AWS Athena disponibles en el catálogo de acciones de automatización del flujo de trabajo. Utilice estas acciones para ejecutar consultas SQL en Amazon Athena, comprobar su estado de ejecución y recuperar los resultados directamente desde una definición de flujo de trabajo.

## Requisitos previos

Para los requisitos previos y la configuración de credenciales, consulte [Configurar las credenciales de AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials).

## Iniciar una ejecución de consulta [#start-query-execution]

El identificador de la acción es `aws.athena.startQueryExecution`.

Ejecuta una consulta SQL en Amazon Athena y devuelve el ID de ejecución de la consulta. Esta acción no espera a que se complete la consulta —utilice `aws.athena.getQueryExecution` para comprobar el estado y `aws.athena.getQueryResults` para recuperar los resultados.

**Ejemplo**

```yaml
name: start-athena-query
description: Run a SQL query against Athena
steps:
  - name: startQuery
    type: action
    action: aws.athena.startQueryExecution
    version: '1'
    inputs:
      awsRoleArn: ${{ :secrets:awsRoleArn }}
      region: us-east-2
      queryString: "SELECT * FROM my_table LIMIT 10"
      database: "my-database"
      catalog: "AwsDataCatalog"
      outputLocation: "s3://my-athena-results-bucket/path/"
      workGroup: "primary"
      selectors:
        - name: queryExecutionId
          expression: ".response.QueryExecutionId"
    next: end
```

## Obtener resultados de la consulta [#get-query-results]

El identificador de la acción es `aws.athena.getQueryResults`.

Devuelve las filas y los metadatos de columna de una ejecución de consulta de Athena completada. Los resultados están paginados —cuando la respuesta incluya un `NextToken`, páselo como `nextToken` en la siguiente llamada para recuperar la página siguiente. La primera fila de `ResultSet.Rows` siempre es la fila de encabezado (nombres de columna).
