Esta página proporciona una referencia de las acciones de New Relic Synthetics disponibles en el catálogo de acciones de automatización del flujo de trabajo. Estas acciones le permiten activar ejecuciones de prueba a pedido para monitores existentes, gestionar los tiempos de inactividad de las ventanas de mantenimiento y leer los detalles del monitor directamente desde una definición de flujo de trabajo.

## Requisitos previos

Antes de usar las acciones de New Relic Synthetics en la automatización del flujo de trabajo, asegúrese de tener:

* Una cuenta de New Relic con los permisos apropiados para acceder a los monitores de Sintéticos.
* El GUID de entidad de cada monitor que desee establecer como objetivo. Puede encontrar el GUID de un monitor en New Relic en **Synthetics &gt; \[nombre del monitor] &gt; Settings**.

## Iniciar una prueba automatizada [#start-automated-test]

El identificador de la acción es `newrelic.synthetics.startAutomatedTest`.

Activa una ejecución de prueba automatizada de Sintéticos a pedido para uno o más monitores y devuelve un `batchId` para consultar los resultados mediante `newrelic.synthetics.getAutomatedTestResult`.

<Callout variant="important">
Solo se admiten los tipos de monitor de API con script, navegador con script, paso y navegador simple. Los monitores SIMPLE (ping) son rechazados por la API con un error de tipo de monitor incompatible.
</Callout>

## Obtener el resultado de la prueba automatizada [#get-automated-test-result]

## Crear un tiempo de inactividad de monitor [#create-monitor-downtime]

El identificador de la acción es `newrelic.synthetics.createMonitorDowntime`.

Programa un tiempo de inactividad único de un monitor de Sintéticos (ventana de mantenimiento) para uno o más monitores específicos. La API devuelve una etiqueta de zona horaria resuelta (como `Pacific Standard Time`) en lugar del nombre de IANA enviado.

<Callout variant="important">
`monitorGuids` admite valores nulos en el esquema de GraphQL, pero es obligatorio en la práctica —omitirlo genera un error del servidor. No existe un modo de tiempo de inactividad para toda la cuenta; el tiempo de inactividad siempre tiene como objetivo monitores específicos.
</Callout>

## Editar un tiempo de inactividad del monitor [#edit-monitor-downtime]

El identificador de la acción es `newrelic.synthetics.editMonitorDowntime`.

Edita un tiempo de inactividad de monitor de Sintéticos existente identificado por el GUID de su entidad.

<Callout variant="important">
`monitorGuids` es obligatorio en cada llamada de edición. La API no conserva la lista existente cuando se omite este campo —en su lugar, la deja vacía. Pase siempre el conjunto completo deseado de GUID de monitores.
</Callout>
