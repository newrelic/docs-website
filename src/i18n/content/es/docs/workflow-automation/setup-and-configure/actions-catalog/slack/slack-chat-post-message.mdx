Envía un mensaje a un canal de Slack con un archivo adjunto opcional.

Para conocer los requisitos previos, consulte [Acciones de chat de Slack](/docs/workflow-automation/setup-and-configure/actions-catalog/slack/slack-chat#prerequisites).

## Publicar un mensaje

El identificador de la acción es `slack.chat.postMessage`.

Envía un mensaje a un canal de Slack, con un archivo adjunto opcional.

    <TabsPageItem id="slack-post-message-example">
      **Ejemplo 1: enviar un mensaje de Slack**

      <table>
        <thead>
          <tr>
            <th>
              Ejemplo de flujo de trabajo
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: SendMessage

              steps:
                - name: send_slack_message
                  type: action
                  action: slack.chat.postMessage
                  version: 1
                  inputs:
                    token: ${{ :secrets:dn_staging_slack_token }}
                    channel: ${{ .workflowInputs.channel }}
                    text: ${{ .workflowInputs.text }}
                    selectors:
                      - name: threadTs
                        expression: ".threadTs"
                      - name: channelID
                        expression: ".channelID"
              ```

              **Entradas:**

              ```json
              {
                "inputs": [
                  {
                    "key" : "channel",
                    "value" : "test-channel-workflow"
                  },
                  {
                    "key" : "text",
                    "value" : "This is my message *with bold text* and `code backticks`"
                  }
                ]
              }
              ```

              **Resultado esperado:**

              ```json
              [
                {
                  "threadTs": "1718897637.400609",
                  "channelID": "C063JK1RHN1",
                  "success": true
                }
              ]
              ```
            </td>
          </tr>
        </tbody>
      </table>
