Esta página proporciona una referencia de todas las acciones de ingesta de New Relic disponibles en el catálogo de acciones de automatización de flujo de trabajo. Estas acciones le permiten enviar eventos, logs y métricas a New Relic desde sus flujos de trabajo.

## Requisitos previos

Antes de usar las acciones de New Relic Ingest en la automatización del flujo de trabajo, asegúrese de tener:

* Una cuenta de New Relic con las licencias adecuadas.
* Una clave de licencia de New Relic (requerida al enviar datos a una cuenta distinta a la cuenta de ejecución del flujo de trabajo).

Consulta [Clave de licencia](/docs/apis/intro-apis/new-relic-api-keys#license-key) para obtener información sobre cómo crear y administrar tu clave de licencia de la cuenta de New Relic.
