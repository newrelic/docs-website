El identificador de la acción es `newrelic.alerts.updateBaselineNrqlCondition`.

Actualiza una condición de alerta de NRQL de línea de base existente. Todos los campos, excepto `accountId` y `id`, son opcionales —solo se cambian los campos que proporcione; los campos omitidos mantienen su valor actual.

                - name: updateBaselineCondition
                  type: action
                  action: newrelic.alerts.updateBaselineNrqlCondition
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    id: ${{ .workflowInputs.conditionId }}
