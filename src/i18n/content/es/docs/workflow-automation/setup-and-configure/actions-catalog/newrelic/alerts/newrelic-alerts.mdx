Esta página proporciona una referencia de todas las acciones de alertas de New Relic disponibles en el catálogo de acciones de automatización del flujo de trabajo. Estas acciones le permiten crear, actualizar, eliminar, obtener y buscar políticas de alertas, condiciones NRQL (estáticas y de línea de base), condiciones compuestas y reglas de silenciamiento directamente desde un flujo de trabajo.

## Requisitos previos

Antes de usar las acciones de alertas de New Relic en la automatización del flujo de trabajo, asegúrese de tener:

* Una cuenta de New Relic con los permisos apropiados para administrar alertas.
* Un ID de cuenta de New Relic para la cuenta donde residen los recursos de alerta.
