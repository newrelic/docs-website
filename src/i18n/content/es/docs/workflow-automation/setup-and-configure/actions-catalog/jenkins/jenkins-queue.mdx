Esta página proporciona una referencia de las acciones de la cola de Jenkins disponibles en el catálogo de acciones de automatización de flujos de trabajo. Utilice estas acciones para inspeccionar y administrar las compilaciones que esperan en la cola de compilación de Jenkins.

## Requisitos previos

Antes de usar las acciones de la cola de Jenkins en la automatización de flujos de trabajo, necesita:

* Un servidor de Jenkins accesible desde New Relic Workflow Automation a través de HTTPS. Si su instancia de Jenkins está detrás de un firewall o en una red privada, permita el acceso entrante desde New Relic Workflow Automation.
* Un token de API de Jenkins para la cuenta con la que se ejecuta el flujo de trabajo. Genere uno desde el perfil de usuario de Jenkins: **Configure &gt; API Token &gt; Add new Token**.
* Un secreto en el New Relic Secrets Service que contiene el valor codificado en Base64 de `username:apiToken`. Referéncielo en el flujo de trabajo como `${{ :secrets:<keyName> }}`.

## Obtener un elemento de la cola de Jenkins

El identificador de la acción es `jenkins.queue.getItem`.

Obtiene los detalles del elemento de la cola, incluido el número de compilación una vez que comienza la ejecución. Utilice esta acción para sondear la cola después de desencadenar una compilación con [`jenkins.job.trigger`](/docs/workflow-automation/setup-and-configure/actions-catalog/jenkins/jenkins-job#trigger-a-jenkins-job) para recuperar el número de compilación necesario para otras acciones del trabajo.

El campo `executable.number` en la respuesta contiene el número de compilación una vez que la compilación comienza a ejecutarse. Es `null` mientras el elemento todavía está en la cola.

          <tr>
            <td>
              ```yaml
              name: poll-jenkins-queue
              description: 'Trigger a build and poll the queue until the build number is available'
              steps:
                - name: trigger_build
                  type: action
                  action: jenkins.job.trigger
                  version: 1
                  inputs:
                    authToken: ${{ :secrets:jenkinsAuthToken }}
                    url: "https://jenkins.example.com"
                    jobName: "my-application-build"
                    selectors:
                      - name: "queueId"
                        expression: ".queueId"
                  next: poll_queue

                - name: poll_queue
                  type: loop
                  for:
                    in: ${{ [range(0; 10)] }}
                    steps:
                      - name: get_queue_item
                        type: action
                        action: jenkins.queue.getItem
                        version: 1
                        inputs:
                          authToken: ${{ :secrets:jenkinsAuthToken }}
                          url: "https://jenkins.example.com"
                          queueId: ${{ .steps.trigger_build.outputs.queueId }}
                          selectors:
                            - name: "buildNumber"
                              expression: ".responseBody | fromjson.executable.number // null"

                      - name: check_if_started
                        type: switch
                        switch:
                          - condition: ${{ .steps.get_queue_item.outputs.buildNumber != null }}
                            next: end
                        next: wait_and_retry

                      - name: wait_and_retry
                        type: wait
                        seconds: 2
                        next: continue
              ```
            </td>
          </tr>

## Cancelar una compilación de Jenkins en cola

El identificador de la acción es `jenkins.queue.cancel`.

Cancela una compilación de Jenkins en cola antes de que comience a ejecutarse. Requiere un `queueId` obtenido de una llamada `jenkins.job.trigger` anterior.

Esta acción falla si la compilación ya ha comenzado a ejecutarse. Para detener una compilación que ya está en ejecución, utilice [`jenkins.job.stop`](/docs/workflow-automation/setup-and-configure/actions-catalog/jenkins/jenkins-job#stop-a-running-jenkins-build) en su lugar.
