Esta página proporciona una referencia de las acciones de AWS DynamoDB disponibles en el catálogo de acciones de automatización del flujo de trabajo. Utilice estas acciones para leer, escribir, actualizar y eliminar elementos en las tablas de DynamoDB, y para inspeccionar o modificar la configuración de las tablas directamente desde la definición de un flujo de trabajo.

## Requisitos previos

Para los requisitos previos y la configuración de credenciales, consulte [Configurar las credenciales de AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials).

Todas las acciones de DynamoDB aceptan las mismas entradas de autenticación. Utilice `awsRoleArn` (recomendado) o el par de claves de acceso.

```yaml
name: put-dynamodb-item
description: Write an order item to DynamoDB
steps:
  - name: putOrderItem
    type: action
    action: aws.dynamodb.putItem
    version: '1'
    inputs:
      awsRoleArn: ${{ :secrets:awsRoleArn }}
      region: us-east-2
      tableName: Orders
      item:
        orderId: { "S": "123" }
        status: { "S": "PLACED" }
    next: end
```

## Escanear una tabla [#scan]
