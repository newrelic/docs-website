Consulta y lista los problemas de inteligencia de alertas de New Relic para una cuenta con filtrado y paginación opcionales.

Para conocer los prerrequisitos, consulte las [acciones de problemas de New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/issue/newrelic-issue#prerequisites).

## Listar problemas

El identificador de la acción es `newrelic.issue.list`.

Consulta y enumera los problemas de New Relic (problemas de IA) de una cuenta, y devuelve el estado en tiempo real, la línea de tiempo, las entidades correlacionadas y los detalles del impacto de los problemas activos o pasados. Admite el filtrado por estado, prioridad, origen, entidad, condición, política, estado de correlación y reconocimiento, un intervalo de tiempo y paginación basada en cursor. Basado en `newrelic.nerdgraph.execute`.

            <td>
              Sin filtros —enumera todas las incidencias de la cuenta, independientemente del estado, la prioridad u otros filtros. Solo se requiere `accountId`:

              ```yaml
              name: newrelic_issue_list_all
              description: list all issues for an account with no filters
              steps:
                - name: newrelic_issue_list
                  type: action
                  action: newrelic.issue.list
                  version: 1
                  inputs:
                    accountId: 123456
                  next: end
              ```

              El siguiente ejemplo utiliza filtros básicos para enumerar los problemas activos y de alta prioridad de una cuenta:

              ```yaml
              name: newrelic_issue_list_workflow
              description: list newrelic issues
              steps:
                - name: newrelic_issue_list
                  type: action
                  action: newrelic.issue.list
                  version: 1
                  inputs:
                    accountId: 123456
                    states: ["ACTIVATED", "CREATED"]
                    priority: ["CRITICAL", "HIGH"]
                  next: end
              ```

              El siguiente ejemplo usa múltiples filtros para problemas críticos, no silenciados y no reconocidos dentro de un período de tiempo específico, con selectores que aplanan la respuesta para la paginación:

              ```yaml
              name: newrelic_issue_list_advanced
              description: list unacknowledged critical issues in a time window
              steps:
                - name: newrelic_issue_list
                  type: action
                  action: newrelic.issue.list
                  version: 1
                  inputs:
                    accountId: 123456
                    states: ["ACTIVATED"]
                    priority: ["CRITICAL"]
                    isAcknowledged: false
                    mutingStates: ["NOT_MUTED"]
                    startTime: 1785900000000
                    endTime: 1785998400000
                    selectors:
                      - name: issues
                        expression: ".data.actor.account.aiIssues.issues.issues"
                      - name: nextCursor
                        expression: ".data.actor.account.aiIssues.issues.nextCursor"
                  next: end
              ```

              Para paginar los resultados adicionales del tercer ejemplo, tome la salida `nextCursor` y vuelva a pasarla como entrada `cursor` en una llamada de seguimiento.
