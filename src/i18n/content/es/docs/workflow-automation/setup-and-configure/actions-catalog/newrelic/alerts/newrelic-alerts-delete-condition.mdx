El identificador de la acción es `newrelic.alerts.deleteCondition`.

Elimina una condición de alerta existente. Funciona en distintos tipos de condiciones —estáticas, de línea de base y otras.

                  type: action
                  action: newrelic.alerts.deleteCondition
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    id: ${{ .workflowInputs.conditionId }}
                  next: end
