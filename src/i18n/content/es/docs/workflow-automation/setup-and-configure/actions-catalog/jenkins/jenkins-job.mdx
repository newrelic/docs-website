Esta página proporciona una referencia de las acciones de trabajos de Jenkins disponibles en el catálogo de acciones de automatización de flujo de trabajo. Utilice estas acciones para activar y administrar las compilaciones de Jenkins.

## Requisitos previos

Antes de usar las acciones de trabajo de Jenkins en la automatización del flujo de trabajo, necesita:

* Un servidor de Jenkins accesible desde New Relic Workflow Automation a través de HTTPS. Si su instancia de Jenkins está detrás de un firewall o en una red privada, permita el acceso entrante desde New Relic Workflow Automation.
* Un token de API de Jenkins para la cuenta con la que se ejecuta el flujo de trabajo. Genere uno desde el perfil de usuario de Jenkins: **Configure &gt; API Token &gt; Add new Token**.
* Un secreto en el New Relic Secrets Service que contiene el valor codificado en Base64 de `username:apiToken`. Referéncielo en el flujo de trabajo como `${{ :secrets:<keyName> }}`.
* Para trabajos basados en carpetas, la ruta completa de la carpeta al trabajo usando `/` como separador (por ejemplo, `deployments/production/my-job`).

## Desencadenar un trabajo de Jenkins

El identificador de la acción es `jenkins.job.trigger`.

Desencadena una compilación de Jenkins con parámetros opcionales. En caso de éxito, devuelve un `queueId` que puede usar con [`jenkins.queue.getItem`](/docs/workflow-automation/setup-and-configure/actions-catalog/jenkins/jenkins-queue#jenkins-queue-getitem) para realizar un seguimiento del progreso de la compilación y recuperar el número de compilación una vez que comienza la ejecución.

## Obtener el estado de una compilación de Jenkins

El identificador de la acción es `jenkins.job.getStatus`.

Obtiene el estado de la compilación de un trabajo de Jenkins. Use esta acción para sondear una compilación iniciada por `jenkins.job.trigger`.

Para comprobar una compilación específica en lugar de la última, proporcione su `buildNumber`. Obtenga el número de compilación sondeando la cola con [`jenkins.queue.getItem`](/docs/workflow-automation/setup-and-configure/actions-catalog/jenkins/jenkins-queue#jenkins-queue-getitem) después de desencadenar la compilación.

                  version: 1
                  inputs:
                    authToken: ${{ :secrets:jenkinsAuthToken }}
                    url: "https://jenkins.example.com"
                    jobName: "deployments/production-deploy"
                    buildNumber: 42
                    selectors:
                      - name: buildStatus
                        expression: ".responseBody | fromjson.result"
                      - name: isBuilding
                        expression: ".responseBody | fromjson.building"

                - name: handle_result
                  type: switch
                  switch:

                  next: notify_failure

    <TabsPageItem id="jenkins-job-getconsoleoutput-example">
      El siguiente ejemplo recupera los logs de compilación y comprueba si hay errores.

      <table>
        <thead>
          <tr>
            <th>
              Ejemplo de flujo de trabajo
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: get-jenkins-build-logs
              description: 'Retrieve Jenkins build logs and check for errors'
              steps:
                - name: get_build_logs
                  type: action
                  action: jenkins.job.getConsoleOutput
                  version: 1
                  inputs:
                    authToken: ${{ :secrets:jenkinsAuthToken }}
                    url: "https://jenkins.example.com"
                    jobName: "deployments/production-deploy"
                    buildNumber: 142
                    selectors:
                      - name: buildLogs
                        expression: ".responseBody"
                      - name: hasErrors
                        expression: ".responseBody | contains(\"ERROR\") or contains(\"FAILED\")"

                - name: check_for_errors
                  type: switch
                  switch:
                    - condition: ${{ .steps.get_build_logs.outputs.hasErrors }}
                      next: handle_error
                  next: end
              ```
            </td>
          </tr>
        </tbody>
