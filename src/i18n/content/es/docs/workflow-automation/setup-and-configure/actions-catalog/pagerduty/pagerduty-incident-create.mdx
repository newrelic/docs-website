## Crear un incidente de PagerDuty

El identificador de la acción es `pagerduty.incident.create`.

Crea un nuevo incidente en PagerDuty con el servicio, título, prioridad y otros atributos opcionales especificados.

    <TabsPageItem id="pagerduty-incident-create-example">
      El siguiente ejemplo crea un nuevo incidente de PagerDuty con un servicio, urgencia, cuerpo y política de escalamiento.

      <table>
        <thead>
          <tr>
            <th>
              Ejemplo de flujo de trabajo
            </th>
          </tr>
        </thead>

        <tbody>
          <tr>
            <td>
              ```yaml
              name: create-pagerduty-incident
              description: Create a new PagerDuty incident
              steps:
                - name: create
                  type: action
                  action: pagerduty.incident.create
                  version: 1
                  inputs:
                    token: ${{ :secrets:pagerdutyApiToken }}
                    type: incident
                    title: Test incident
                    service:
                      id: P123456
                      type: service_reference
                    urgency: low
                    body:
                      type: incident_body
                      details: Test Body
                    incidentKey: a12345-b678910-c111213
                    escalationPolicy:
                      id: P54321
                      type: escalation_policy_reference
                    selectors:
                      - name: incidentId
                        expression: .responseBody | fromjson.incident.id
                  next: end
              ```
            </td>
