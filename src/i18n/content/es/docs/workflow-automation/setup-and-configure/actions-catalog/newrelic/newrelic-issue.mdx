Esta página proporciona una referencia de todas las acciones de problemas de New Relic disponibles en el catálogo de acciones de automatización de flujos de trabajo. Estas acciones le permiten reconocer, anular el reconocimiento y resolver problemas de Alert Intelligence, y consultar problemas para habilitar la lógica condicional en sus flujos de trabajo.

## Requisitos previos

Antes de usar las acciones de problemas de New Relic en la automatización del flujo de trabajo, asegúrese de tener:

* Una cuenta de New Relic con los permisos apropiados para administrar los problemas de Alert Intelligence.
* Las licencias necesarias para los servicios específicos de New Relic que planea emplear.
