Esta página proporciona una referencia de todas las acciones de etiqueta de New Relic disponibles en el catálogo de acciones de automatización del flujo de trabajo. Estas acciones le permiten agregar, reemplazar y eliminar etiquetas en las entidades de New Relic directamente desde los flujos de trabajo.

## Requisitos previos

Antes de usar las acciones de etiqueta de New Relic en la automatización de flujos de trabajo, asegúrese de tener:

* Una cuenta de New Relic con los permisos apropiados para administrar etiquetas de entidad.
