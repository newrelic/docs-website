Recupera los detalles y el estado actual de una aplicación web de Azure App Service. Útil para comprobar si una aplicación se está ejecutando antes de decidir iniciarla, detenerla o reiniciarla.

Para la configuración de la autenticación, consulte las [acciones de Azure App Service](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-appservice).

<TabsPageItem id="azureappservicegetexample">
```yaml
name: getAzureAppService
description: Get the current state of an Azure App Service
steps:
  - name: get_app_service
    type: action
    action: azure.appService.get
    version: 1
    inputs:
      clientId: ${{ :secrets:azure-client-id }}
      clientSecret: ${{ :secrets:azure-client-secret }}
      tenantId: ${{ :secrets:azure-client-tenant }}
      subscriptionId: "12345678-1234-1234-1234-123456789abc"
      resourceGroupName: "my-resource-group"
      appServiceName: "my-web-app"
      selectors:
        - name: appState
          expression: ".response.properties.state"
    next: end
```
