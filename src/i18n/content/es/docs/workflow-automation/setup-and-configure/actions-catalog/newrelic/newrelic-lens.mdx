Esta página proporciona una referencia de las acciones de New Relic Lens disponibles en el catálogo de acciones de automatización de flujos de trabajo. Estas acciones le permiten ejecutar consultas ANSI SQL en fuentes de datos conectadas a través de New Relic Lens directamente desde un paso del flujo de trabajo.

## Requisitos previos

Antes de usar las acciones de New Relic Lens en la automatización del flujo de trabajo, asegúrese de tener:

* Una cuenta de New Relic con las licencias adecuadas.
* Una o más fuentes de datos conectadas en New Relic Lens.
* Los permisos necesarios para el servicio New Relic Lens.
