Esta página proporciona una referencia de las acciones de AWS EventBridge disponibles en el catálogo de acciones de automatización de flujo de trabajo. Use estas acciones para emitir eventos, administrar el estado de la regla y ejecutar operaciones de archivo, reproducción y origen de eventos de socios.

## Requisitos previos

Para los requisitos previos y la configuración de credenciales, consulte [Configurar las credenciales de AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials).

## Enviar un único evento a un bus de eventos

El identificador de la acción es `aws.eventBridge.putEvent`.

Envía un único evento personalizado a un bus de eventos de AWS EventBridge para que pueda coincidir con las reglas. Este es un contenedor de conveniencia de entrada única —use `aws.eventBridge.putEvents` para enviar múltiples eventos en una sola llamada.
