El catálogo de acciones de New Relic proporciona acciones prediseñadas para proveedores de cloud, herramientas de DevOps, plataformas ITSM y la propia plataforma de New Relic. Utilice estas acciones como pasos en las automatizaciones de su flujo de trabajo para desencadenar despliegues, gestionar incidentes y automatizar tareas operativas en sus herramientas y servicios.

Las acciones siguen una convención de nomenclatura jerárquica: `company.product.action`
