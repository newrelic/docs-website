El identificador de la acción es `newrelic.notification.waitForStatus`.

Sondea el resultado de la entrega de una notificación enviada por un paso `newrelic.notification.send` anterior. Dado un `sessionId`, esta acción sondea `NrNotificationsEvent` hasta que la notificación alcance un estado terminal (`SUCCESS` o `FAIL`) o transcurra el `timeout` especificado. Para los destinos de Slack, también devuelve el valor `thread_ts` necesario para responder en el hilo que creó la notificación.

<tr>
<td>
```yaml
name: notify_and_wait
description: Send a Slack notification then wait for its delivery status
steps:
  - name: sendNotification
    type: action
    action: newrelic.notification.send
    version: 1
    inputs:
      type: slack
      destinationId: "your-destination-id"
      parameters:
        channel: "your-slack-channel"
        text: "Deployment finished"
      selectors:
        - name: sessionId
          expression: ".response.sessionId"
    next: waitForStatus

  - name: waitForStatus
    type: action
    action: newrelic.notification.waitForStatus
    version: 1
    inputs:
      sessionId: ${{ .steps.sendNotification.outputs.sessionId }}
      timeout: 15
      selectors:
        - name: deliveryStatus
          expression: ".notificationStatus.status"
        - name: threadTs
          expression: ".notificationStatus.threadTs"
    next: end
```
