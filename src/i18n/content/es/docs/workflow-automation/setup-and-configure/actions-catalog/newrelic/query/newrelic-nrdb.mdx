Esta página proporciona una referencia de las acciones de New Relic NRDB disponibles en el catálogo de acciones de automatización del flujo de trabajo. Estas acciones le permiten consultar la base de datos de New Relic.

## Requisitos previos

Antes de usar las acciones de NRDB de New Relic en la automatización del flujo de trabajo, asegúrese de tener:

* Una cuenta de New Relic con las licencias adecuadas.
* Una clave de licencia de New Relic (si se envían datos a una cuenta diferente).
* Las licencias necesarias para los servicios específicos de New Relic que planea emplear.

Consulta [Clave de licencia](/docs/apis/intro-apis/new-relic-api-keys#license-key) para obtener información sobre cómo crear y administrar tu clave de licencia de la cuenta de New Relic.

## Consultar NRDB

El identificador de la acción es `newrelic.nrdb.query`.

Ejecuta una consulta NRQL entre cuentas a través de la API de NerdGraph.
