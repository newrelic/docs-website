Enumera las aplicaciones web de Azure App Service en un grupo de recursos. Devuelve resultados paginados —si el grupo de recursos contiene suficientes aplicaciones para abarcar varias páginas, se incluye un campo `nextLink` en la respuesta para recuperar la página siguiente.

Para la configuración de la autenticación, consulte las [acciones de Azure App Service](/docs/workflow-automation/setup-and-configure/actions-catalog/azure/azure-appservice).

Si la respuesta incluye un campo `nextLink`, hay páginas de resultados adicionales. Captúrelo con un selector y llame a `azure.execute.api` directamente con esa URL como `urlPath` para obtener la página siguiente.
</TabsPageItem>

<TabsPageItem id="azureappservicelistexample">
```yaml
name: listAzureAppServices
description: List Azure App Services in a resource group
steps:
  - name: list_app_services
    type: action
    action: azure.appService.list
    version: 1
    inputs:
      clientId: ${{ :secrets:azure-client-id }}
      clientSecret: ${{ :secrets:azure-client-secret }}
      tenantId: ${{ :secrets:azure-client-tenant }}
      subscriptionId: "12345678-1234-1234-1234-123456789abc"
      resourceGroupName: "my-resource-group"
      selectors:
        - name: appNames
          expression: "[.response.value[].name]"
        - name: nextLink
          expression: ".response.nextLink // \"\""
    next: end
```
