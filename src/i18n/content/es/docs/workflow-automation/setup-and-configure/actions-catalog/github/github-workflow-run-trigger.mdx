Desencadena una ejecución del flujo de trabajo de GitHub Actions mediante un evento `workflow_dispatch`. El flujo de trabajo objetivo debe tener configurado un desencadenador `workflow_dispatch`. GitHub devuelve HTTP 204 No Content en caso de éxito.

Para la configuración de la autenticación, consulte las [acciones de ejecución del flujo de trabajo de GitHub](/docs/workflow-automation/setup-and-configure/actions-catalog/github/github-workflow-run).

<td>
```yaml
name: trigger_github_workflow
description: Trigger a GitHub Actions workflow run
steps:
  - name: trigger_run
    type: action
    action: gitHub.workflowRun.trigger
    version: 1
    inputs:
      token: ${{ :secrets:github-PAT-token }}
      owner: your_user_name
      repo: test-workflow
      workflowId: deploy.yml
      ref: main
      inputs:
        environment: staging
        version: "1.2.3"
    next: end
```
