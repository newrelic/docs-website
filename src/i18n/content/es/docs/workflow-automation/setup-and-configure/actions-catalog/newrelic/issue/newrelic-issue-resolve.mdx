Cierra una incidencia abierta de New Relic Alert Intelligence una vez que se completa la remediación.

Para conocer los prerrequisitos, consulte las [acciones de problemas de New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/issue/newrelic-issue#prerequisites).

## Resolver problema

El identificador de la acción es `newrelic.issue.resolve`.

Resuelve un problema abierto de New Relic (AI Issues), cerrándolo una vez que se completan los pasos de remediación. El estado del problema cambia a `CLOSED` y New Relic registra la resolución en el registro del problema. Desarrollado en `newrelic.nerdgraph.execute`.
