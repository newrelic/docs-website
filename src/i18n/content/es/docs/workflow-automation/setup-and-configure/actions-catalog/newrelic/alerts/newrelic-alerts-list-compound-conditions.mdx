El identificador de la acción es `newrelic.alerts.listCompoundConditions`.

Enumera las condiciones de alerta compuestas para una cuenta con filtrado de ID opcional y paginación basada en cursor. Las condiciones compuestas no están disponibles a través de una acción get independiente —esta es la única acción que muestra su estructura de componentes.

                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
