El identificador de la acción es `newrelic.alerts.getNrqlCondition`.

Recupera los detalles de una única condición de alerta de NRQL. Funciona tanto para los tipos de condición estática como de línea de base.

              ```yaml
              name: get_nrql_condition
              description: Get an NRQL alert condition
              steps:
                - name: getCondition
                  type: action
                  action: newrelic.alerts.getNrqlCondition
                  version: 1
                  inputs:
                    accountId: ${{ .workflowInputs.accountId }}
                    id: ${{ .workflowInputs.conditionId }}
                    selectors:
                      - name: conditionName
                        expression: ".data.actor.account.alerts.nrqlCondition.name"
                  next: end
              ```
