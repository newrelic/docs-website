Reemplaza todo el conjunto de etiquetas de una entidad de New Relic con las etiquetas proporcionadas.

Para conocer los prerrequisitos, consulte las [acciones de etiqueta de New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites).

## Reemplazar etiquetas

El identificador de la acción es `newrelic.tagging.replaceTags`.

Reemplaza todo el conjunto de etiquetas de una entidad de New Relic con las etiquetas proporcionadas. Esta acción es destructiva: elimina cualquier etiqueta existente que no esté incluida en la entrada `tags`. Para agregar etiquetas sin eliminar las existentes, utilice [`newrelic.tagging.addTags`](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging-addtags) en su lugar. Desarrollado en `newrelic.nerdgraph.execute`.
