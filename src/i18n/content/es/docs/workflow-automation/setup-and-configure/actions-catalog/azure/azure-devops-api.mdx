La acción de API de Azure DevOps le permite llamar a cualquier [API REST de Azure DevOps](https://learn.microsoft.com/en-us/rest/api/azure/devops/?view=azure-devops-rest-7.1) directamente desde sus flujos de trabajo, sin necesidad de una acción dedicada para cada operación.

## Ejecutar una API de Azure DevOps [#azure-devops-api]

Esta acción le permite ejecutar cualquier operación documentada en la [referencia de la API REST de Azure DevOps](https://learn.microsoft.com/en-us/rest/api/azure/devops/?view=azure-devops-rest-7.1). Proporcione la organización, la ruta de la API, el método HTTP y el cuerpo de la solicitud opcional —la acción maneja la autenticación automáticamente.

    <TabsPageItem id="azuredevopsapiexample">
      ### Ejemplo: obtener proyectos

      ```yaml
        - name: getProjects
          type: action
          action: azure.devops.api
          version: 1
          inputs:
            clientId: ${{ :secrets:azure-client-id }}
            clientSecret: ${{ :secrets:azure-client-secret }}
            tenantId: ${{ :secrets:azure-client-tenant }}
            organization: ${{ :secrets:organization }}
            urlPath: _apis/projects
            method: GET
      ```

      ### Ejemplo: crear un pipeline

      ```yaml
        - name: createPipeline
          type: action
          action: azure.devops.api
          version: 1
          inputs:
            clientId: ${{ :secrets:azure-client-id }}
            clientSecret: ${{ :secrets:azure-client-secret }}
            tenantId: ${{ :secrets:azure-client-tenant }}
            organization: ${{ :secrets:organization }}
            urlPath: myProject/_apis/pipelines?api-version=7.1
            method: POST
            body:
              name: testPipeline
              folder: \
              configuration:
                type: yaml
                path: pipelineConfig.yml
                repository:
                  id: 1a8bcfa4-1412-4b3b-af36-4ff1aa5860a1
                  name: testRepository
                  type: azureReposGit
            selectors:
              - name: pipelineId
                expression: .response.id
              - name: pipelineName
                expression: .response.name
      ```

      ### Ejemplo: ejecutar un pipeline

      ```yaml
        - name: runPipeline
          type: action
          action: azure.devops.api
          version: 1
          inputs:
            clientId: ${{ :secrets:azure-client-id }}
            clientSecret: ${{ :secrets:azure-client-secret }}
            tenantId: ${{ :secrets:azure-client-tenant }}
            organization: ${{ :secrets:organization }}
            urlPath: myProject/_apis/pipelines/1/runs?api-version=7.1-preview.1
            method: POST
            body:
              resources: {}
              variables: {}
      ```

      ### Ejemplo: eliminar un pipeline

      ```yaml
        - name: deletePipeline
          type: action
          action: azure.devops.api
          version: 1
          inputs:
            clientId: ${{ :secrets:azure-client-id }}
            clientSecret: ${{ :secrets:azure-client-secret }}
            tenantId: ${{ :secrets:azure-client-tenant }}
            organization: ${{ :secrets:organization }}
            urlPath: myProject/_apis/build/definitions/1?api-version=7.1-preview.7
            method: DELETE
      ```
