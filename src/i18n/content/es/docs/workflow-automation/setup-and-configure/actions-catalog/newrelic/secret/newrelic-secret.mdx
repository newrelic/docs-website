Esta página proporciona una referencia de las acciones de New Relic Secrets Management disponibles en el catálogo de acciones de automatización del flujo de trabajo. Estas acciones le permiten listar secretos e inspeccionar su historial de versiones directamente desde una definición de flujo de trabajo.

<Callout variant="important">
No hay ninguna acción para recuperar el valor de un secreto. Descifrar un secreto mediante una acción de flujo de trabajo expondría el valor en el historial y los logs de la ejecución. Para usar el valor de un secreto como entrada para un paso de flujo de trabajo, haga referencia a este directamente usando la sintaxis `${{ :secrets:keyName }}` en su lugar.
</Callout>

## Requisitos previos

Antes de usar las acciones de secretos de New Relic en la automatización del flujo de trabajo, asegúrese de tener:

* Una cuenta de New Relic con los permisos apropiados para leer Secrets Management.
* El `scopeId` (ID de cuenta o ID de organización) y `scopeType` (`ACCOUNT` o `ORGANIZATION`) para el alcance que desea consultar.

## Listar versiones del secreto [#list-versions]

El identificador de la acción es `newrelic.secret.listVersions`.

Enumera todas las versiones de un secreto de New Relic Secrets Management, incluidas las versiones eliminadas temporalmente cuando se solicitan.

<td>
```yaml
name: list_secret_versions
description: List all versions of a New Relic secret
steps:
  - name: listSecretVersions
    type: action
    action: newrelic.secret.listVersions
    version: 1
    inputs:
      key: "jira_auth_token"
      scopeId: "11933347"
      scopeType: "ACCOUNT"
      fetchDeleted: true
      selectors:
        - name: latestVersion
          expression: ".data.customerAdministration.secretVersions.latestVersion"
    next: end
```

## Listar secretos [#list-secrets]

El identificador de la acción es `newrelic.secret.list`.
