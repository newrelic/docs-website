Agrega una o más etiquetas a una entidad de New Relic, conservando las etiquetas existentes.

Para conocer los prerrequisitos, consulte las [acciones de etiqueta de New Relic](/docs/workflow-automation/setup-and-configure/actions-catalog/newrelic/tagging/newrelic-tagging#prerequisites).

## Agregar etiqueta

El identificador de la acción es `newrelic.tagging.addTags`.

Agrega una o más etiquetas a una entidad de New Relic. Agregar un valor a una clave que ya existe lo anexa en lugar de reemplazarlo. Desarrollado en `newrelic.nerdgraph.execute`.
