Esta página proporciona una referencia de las acciones de la API de etiquetas de AWS Resource Groups disponibles en el catálogo de acciones de automatización del flujo de trabajo. Use estas acciones para obtener, agregar, actualizar y eliminar etiquetas en recursos de AWS en todos los servicios.

## Requisitos previos

Para los requisitos previos y la configuración de credenciales, consulte [Configurar las credenciales de AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials).

## Obtener etiquetas por ARN

El identificador de la acción es `aws.resourceGroupsTaggingApi.getResourceTags`.

Devuelve las etiquetas para uno o más recursos de AWS especificados por ARN.

<Callout variant="important">
  No puede combinar `resourceArnList` con `tagFilters`, `resourceTypeFilters` o entradas de paginación. AWS rechaza esa combinación con un `InvalidParameterException`. Para buscar recursos por etiqueta o tipo, use [`aws.resourceGroupsTaggingApi.getResourcesByTag`](#get-resources-by-tag) en su lugar.
</Callout>

```yaml
name: get-resource-tags-by-arn
description: 'Get tags for AWS resources by ARN'
steps:
  - name: getResourceTagsByArn
    type: action
    action: aws.resourceGroupsTaggingApi.getResourceTags
    version: '1'
    inputs:
      awsRoleArn: "arn:aws:iam::123456789012:role/my-workflow-role"
      region: "us-east-2"
      resourceArnList:
        - "arn:aws:dynamodb:us-east-2:123456789012:table/my-table"
      selectors:
        - name: tags
          expression: ".response.ResourceTagMappingList"
    next: end
```

## Obtener recursos por etiqueta

El identificador de la acción es `aws.resourceGroupsTaggingApi.getResourcesByTag`.

Busca recursos de AWS por valor principal de etiqueta y/o tipo de recurso. Solo devuelve recursos que tienen etiqueta.

<Callout variant="important">
  No puede combinar `tagFilters` o `resourceTypeFilters` con `resourceArnList` en la misma llamada. AWS rechaza esa combinación con un `InvalidParameterException`. Para recuperar etiquetas para ARN específicos, use [`aws.resourceGroupsTaggingApi.getResourceTags`](#get-tags-by-arn) en su lugar.

```yaml
      resourcesPerPage: 50
      selectors:

          expression: ".response.ResourceTagMappingList"
    next: end
```

## Agregar o actualizar etiquetas en recursos

El identificador de la acción es `aws.resourceGroupsTaggingApi.tagResources`.

Agrega o actualiza hasta 50 etiquetas en 1-20 recursos de AWS en distintos servicios en una sola llamada.

<Callout variant="important">
  La acción reporta fallas parciales por ARN en `response.FailedResourcesMap` en lugar de como un error de nivel superior. Verifique `response.FailedResourcesMap` incluso cuando `success` sea `true`, porque un ARN fallido en un lote no hace que falle toda la llamada.
</Callout>

## Eliminar etiquetas de los recursos

El identificador de la acción es `aws.resourceGroupsTaggingApi.untagResources`.

**Flujo de trabajo de ejemplo**

```yaml
name: remove-tags-from-resources
description: 'Remove tags from AWS resources'
steps:
  - name: untagResources
    type: action
    action: aws.resourceGroupsTaggingApi.untagResources
    version: '1'
    inputs:
      awsRoleArn: "arn:aws:iam::123456789012:role/my-workflow-role"
      region: "us-east-2"
      resourceArnList:
        - "arn:aws:sqs:us-east-2:123456789012:my-queue"
      tagKeys:
        - Environment
      selectors:
        - name: failedResources
          expression: ".response.FailedResourcesMap"
    next: end
```
