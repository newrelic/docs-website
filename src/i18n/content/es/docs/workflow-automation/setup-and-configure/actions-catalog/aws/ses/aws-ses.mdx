Esta página proporciona una referencia de las acciones de AWS Simple Email Service (SES) disponibles en el catálogo de acciones de automatización del flujo de trabajo. Utilice estas acciones para crear, actualizar, recuperar y eliminar plantillas de correo electrónico, y para enviar correos electrónicos a través de Amazon SES.

## Requisitos previos

Para los requisitos previos y la configuración de credenciales, consulte [Configurar las credenciales de AWS](/docs/workflow-automation/setup-and-configure/set-up-aws-credentials).

## Crear una plantilla

El identificador de la acción es `aws.ses.createTemplate`.

Crea una plantilla de correo electrónico en Amazon SES para enviar correos electrónicos con plantillas.

<Callout variant="important">
Se debe proporcionar al menos `textPart` o `htmlPart`. SES requiere que la plantilla tenga contenido en el cuerpo en al menos un formato.
</Callout>

```yaml

description: 'Create an email template in Amazon SES'
steps:
  - name: createWelcomeTemplate
    type: action
    action: aws.ses.createTemplate
    version: '1'
    inputs:
      awsRoleArn: "arn:aws:iam::123456789012:role/my-workflow-role"
      region: us-east-2
      templateName: WelcomeEmailTemplate
      subjectPart: "Welcome to Our Service"
      textPart: "Hello, welcome aboard."
      htmlPart: "<h1>Hello</h1><p>Welcome aboard.</p>"
    next: end
```

**Flujo de trabajo de ejemplo**

```yaml
name: send-ses-bulk-templated-email
description: 'Send bulk templated emails through Amazon SES'
steps:
  - name: sendBulkWelcomeEmail
    type: action
    action: aws.ses.sendBulkTemplatedEmail
    version: '1'
    inputs:
      awsRoleArn: "arn:aws:iam::123456789012:role/my-workflow-role"
      region: us-east-2
      source: no-reply@example.com
      template: WelcomeEmailTemplate
      defaultTemplateData: '{"name": "Guest"}'
      destinations:
        - destination:
            toAddresses:
              - alice@example.com
          replacementTemplateData: '{"name": "Alice"}'
        - destination:
            toAddresses:
              - bob@example.com
          replacementTemplateData: '{"name": "Bob"}'
      selectors:
        - name: sendStatuses
          expression: ".response.Status"
    next: end
```
