Con los límites de usuario de calcular, puede establecer presupuestos diarios o mensuales para usuarios individuales en la organización y administrar el acceso a los recursos de New Relic en función del consumo de calcular. Cada presupuesto hace un seguimiento del calcular principal (CCU principales) y del calcular avanzado (CCU avanzadas) como medidores separados. Cuando un usuario alcanza el presupuesto asignado para un medidor, puede bloquear el acceso a los recursos asociados hasta el final del período presupuestario o hasta que aumente el presupuesto.

También simplifica la gestión de presupuestos a escala con un presupuesto de usuario global que se aplica a todos los usuarios, por lo que no necesita configurar un presupuesto para cada usuario individualmente. Para los usuarios con necesidades específicas, puede crear presupuestos de anulación personalizados.

Utilice los límites de usuario de calcular para hacer lo siguiente:

* Controlar los costos de cómputo limitando el consumo por usuario
* Monitoree el consumo de cómputo a nivel de usuario
* Mantenga la visibilidad de los patrones de uso de calcular de los usuarios en toda la organización
* Administrar los presupuestos de calcular de los usuarios en una gran organización

## Capacidades clave

Hay dos tipos de presupuesto disponibles:

* **Presupuesto global de usuario**: establezca un presupuesto predeterminado que se aplique a todos los usuarios de la organización.
* **Presupuestos de anulación personalizados**: asigne presupuestos específicos a usuarios individuales que necesiten límites más altos o más bajos que el presupuesto global.

Para ambos tipos de presupuesto, configure lo siguiente por medidor:

* **Límite de CCU principal**: se establece como un porcentaje del presupuesto de calcular a nivel de organización, con el valor de CCU equivalente calculado automáticamente. Elija **Block CCU usage** o **Do not block CCU usage** como el tipo de límite para este medidor.
* **Límite de CCU avanzada**: establézcalo como un porcentaje del presupuesto de cálculo a nivel de organización, con el valor de CCU equivalente calculado automáticamente. Elija **Block CCU usage** o **Do not block CCU usage** como el tipo de límite para este medidor.

El seguimiento del presupuesto solo se aplica cuando configura un presupuesto global o presupuestos de anulación personalizados.

Si ha configurado un presupuesto global, todos los usuarios reciben automáticamente ese presupuesto. Si solo ha creado presupuestos de anulación personalizados sin un presupuesto global, los usuarios sin presupuestos personalizados tienen acceso sin restricciones.

Si necesita administrar el uso de New Relic Autopilot, utilice la característica [Límites de cálculo de Autopilot](/docs/agentic-ai/autopilot/autopilot-compute-limits/) en su lugar.

## Cómo funcionan los límites de usuario

Los límites de usuario rastrean el consumo de cálculo de cada usuario en dos medidores independientes: cálculo principal (CCU principales) y cálculo avanzado (CCU avanzadas). Cuando asigna un presupuesto a un usuario, la actividad de cálculo cuenta para el medidor adecuado. Cada medidor tiene su propio valor de presupuesto y tipo de límite.

Por ejemplo, si un usuario tiene un presupuesto de 10 000 CCU principales y un presupuesto de 5000 CCU avanzadas, la actividad de cálculo estándar, como ejecutar consultas y actualizar dashboards, cuenta para el límite de CCU principal, y la actividad de cálculo avanzado, como Ask AI, Live Archives y MCP, cuenta para el límite de CCU avanzada.

Cuando un usuario alcanza su presupuesto asignado para un medidor, entra en vigor el tipo de límite configurado para ese medidor.

### Medidores de cálculo principal y avanzado

Calcular principal (CCU principales) abarca dashboard, generador de consultas y llamadas API. Calcular avanzado (CCU avanzadas) abarca características como Live Archives y características impulsadas por IA.

Cuando se agota el presupuesto de CCU principal de un usuario y el tipo de límite se establece en **Block CCU usage**, pierde el acceso a lo siguiente:

* [Dashboards](/docs/query-your-data/explore-query-data/dashboards/introduction-dashboards)
* [Generador de consultas](/docs/query-your-data/explore-query-data/query-builder/introduction-query-builder)
* Llamada API

Cuando se agota el presupuesto de CCU avanzado de un usuario y el tipo de límite está establecido en **Block CCU usage**, pierde el acceso a lo siguiente:

* [Ask AI](/docs/agentic-ai/new-relic-ai) (V1 y V2)
* [Live Archives](/docs/logs/get-started/live-archives) (el botón Consultar Live Archives y el control de alternancia Usar Live Archives en el generador de consultas)
* [MCP](/docs/agentic-ai/mcp/overview)
* [Errors Inbox](/docs/apm/errors-inbox/errors-inbox-ui) (Explicar error y generar Insights)

Los siguientes productos que consumen CCU avanzadas no son compatibles con esta característica de límites de usuario de calcular y siguen estando accesibles incluso cuando el presupuesto de CCU avanzadas de un usuario alcanza el 100 %:

* Control de pipelines
* Cardinalidad ilimitada
* Transacción 360
* Security RX
* Conocimiento de New Relic AI
* Autopilot

<Callout variant="tip">
La lista de productos de CCU avanzados sujetos a cumplimiento puede crecer a medida que más productos alcancen la disponibilidad general. Vuelva a consultar aquí para obtener actualizaciones sobre los productos de CCU avanzados compatibles.
</Callout>

### Frecuencia del presupuesto

Cuando crea un presupuesto, elige si se restablece de forma diaria o mensual. La elección correcta depende de los patrones de trabajo de los usuarios y de qué tan estrictamente necesite controlar los costos.

La siguiente tabla compara los presupuestos mensuales y diarios:

| Comportamiento                | Mensual                                 | A diario                                  |
| ----------------------------- | --------------------------------------- | ----------------------------------------- |
| **Se reinicia**               | Inicio de cada mes calendario (UTC)     | Inicio de cada día calendario (UTC)       |
| **Levantamiento del bloqueo** | Inicio del próximo mes calendario (UTC) | Inicio del siguiente día calendario (UTC) |

Elija un presupuesto mensual si se aplica alguna de las siguientes opciones:

* Sus usuarios tienen un uso diario variable que se promedia a lo largo de un período de facturación —por ejemplo, desarrolladores que ejecutan consultas intensivas al final de un sprint, pero que por lo demás tienen un uso ligero
* Desea que el período del presupuesto se alinee con su ciclo de facturación
* Solo desea un restablecimiento por mes

Elija un presupuesto diario si se aplica alguna de las siguientes opciones:

* Desea limitar cuánto puede consumir una consulta o script fuera de control en un solo día
* Sus usuarios tienen un uso diario constante y desea un límite diario fijo
* Desea una ventana de recuperación más corta: un usuario bloqueado por un presupuesto diario recupera el acceso al día siguiente, en lugar de esperar hasta fin de mes

<Callout variant="tip">
Los límites diarios pueden bloquear a los usuarios en días de alto uso incluso cuando su uso total se habría mantenido dentro de un presupuesto mensual. Revise los patrones de uso típicos de sus usuarios antes de aplicar límites diarios de forma general.
</Callout>

### Notificaciones de presupuesto

Las notificaciones se activan de forma independiente para cada medidor de cómputo. Las notificaciones en la aplicación se activan en los cuatro umbrales; las notificaciones por correo electrónico se activan solo al 75 % y al 100 %.

| Umbral   | Urgencia    | Notificación en la aplicación | Correo electrónico |
| -------- | ----------- | ----------------------------- | ------------------ |
| **50 %** | Información | ✓                             | —                  |
| **75 %** | Advertencia | ✓                             | ✓                  |
| **95%**  | Crítico     | ✓                             | —                  |
| **100%** | Crítico     | ✓                             | ✓                  |

Por ejemplo, un usuario con un presupuesto de 100 000 CCU principales y un presupuesto de 200 000 CCU avanzados recibe notificaciones de CCU principales a los 50 000, 75 000, 95 000 y 100 000 CCU principales, y notificaciones de CCU avanzados por separado a los 100 000, 150 000, 190 000 y 200 000 CCU avanzados. Las notificaciones por correo electrónico se envían en los umbrales del 75 % y 100 % para cada medidor.

### Aplicación del presupuesto

Como administrador de la organización, configura los tipos de límite de forma independiente para cada medidor de cálculo. Esto significa que puede, por ejemplo, aplicar **Block CCU usage** al cálculo principal de un usuario mientras establece **Do not block CCU usage** para el cálculo avanzado, o aplicar el mismo tipo de límite a ambos.

**Para el cómputo principal, elija una de las siguientes opciones:**

* **Block CCU usage** (Bloquear el uso de CCU): cuando un usuario agota su presupuesto, notifíquele y bloquee el acceso al generador de consultas, Dashboards y llamadas API: ejecutar consultas, actualizar dashboards y realizar llamadas API.
* **Do not block CCU usage** (No bloquear el uso de CCU): cuando un usuario agota el presupuesto, notifíquele, pero no bloquee el acceso a ningún producto que consuma CCU. Esta opción mantiene el acceso completo a la plataforma, pero no evita los excesos de uso.

**Para calcular avanzado, elija una de las siguientes opciones:**

* **Block CCU usage** (Bloquear uso de CCU): cuando un usuario agota su presupuesto, se le notifica y se bloquea el acceso a funciones como: [Ask AI](/docs/agentic-ai/new-relic-ai), [Live Archives](/docs/logs/get-started/live-archives), [MCP](/docs/agentic-ai/mcp/overview) y [Errors Inbox](/docs/apm/errors-inbox/errors-inbox-ui).
* **Do not block CCU usage** (No bloquear el uso de CCU): cuando un usuario agota el presupuesto, notifíquele, pero no bloquee el acceso a las acciones que consumen CCU. Esta opción mantiene el acceso completo a la plataforma, pero no evita los excesos de uso.

Cuando están bloqueados, los usuarios ven una pantalla que dice que han usado su presupuesto para el período y que pueden comunicarse con un administrador de la organización si tienen alguna pregunta.

<Callout variant="tip">
Si va a implementar límites de presupuesto por primera vez, comience con **Do not block CCU usage** para ambos medidores. Esto le permite observar los patrones de uso reales antes de habilitar el bloqueo, lo que reduce la posibilidad de que se produzcan interrupciones de acceso inesperadas.
</Callout>

<Callout variant="important">
Para los presupuestos mensuales, los bloqueos permanecen vigentes hasta el final del mes calendario (UTC). Para los presupuestos diarios, los bloqueos permanecen vigentes hasta el final del día calendario (UTC). En ambos casos, puede restaurar el acceso antes aumentando el presupuesto del usuario. Los datos de consumo se actualizan en unas pocas horas (normalmente de 2 a 4 horas), por lo que el bloqueo no ocurre exactamente al 100 %. Los usuarios podrían exceder el presupuesto antes de que el bloqueo entre en vigor.
</Callout>

## Configurar un presupuesto global de usuario

Si su organización abarca varias organizaciones de New Relic, inicie sesión en cada una por separado para crear y administrar los límites de usuario para sus usuarios.

<Steps>
<Step>
### Acceder a Presupuestos de cómputo

1. Vaya a <DNT>**[one.newrelic.com](https://one.newrelic.com) &gt; [user menu](/docs/accounts/accounts-billing/general-account-settings/intro-account-settings)**</DNT>.
2. Seleccione <DNT>**Administration &gt; Compute Budgets**</DNT>.
</Step>

<Step>
### Abra el asistente de presupuesto global

En la tarjeta <DNT>**Global user budget**</DNT>, haga clic en <DNT>**Manage budget**</DNT>. Se abre el asistente <DNT>**Manage global budget**</DNT>.
</Step>

<Step>
### Establecer la frecuencia del presupuesto

En <DNT>**Set the frequency**</DNT>, seleccione con qué frecuencia se restablece el presupuesto:

* <DNT>**Monthly**</DNT>: realiza un seguimiento del uso a lo largo del mes calendario y se restablece al comienzo de cada mes (UTC).
* <DNT>**Daily**</DNT>: rastrea el uso a lo largo de cada día calendario y se restablece al inicio de cada día (UTC).

Haga clic en <DNT>**Next**</DNT>.
</Step>

<Step>
### Definir presupuesto de CCU principal

1. En <DNT>**Budget allocation**</DNT>, ingrese el porcentaje del presupuesto de CCU principales de la organización para asignar a cada usuario. El asistente muestra el valor equivalente de CCU avanzadas a medida que escribe. Por ejemplo, si la organización tiene 800 000 CCU principales y establece el 5 %, cada usuario recibe 40 000 CCU principales. Los presupuestos de los usuarios pueden exceder el presupuesto total de la organización.

2. En <DNT>**Limit type**</DNT>, elija qué sucede cuando un usuario alcanza el 100 % del presupuesto de CCU principal:

   * <DNT>**Block CCU usage**</DNT>: notifique al usuario y bloquee el acceso a las acciones que consumen CCU: ejecutar consultas, actualizar dashboards y realizar llamadas API.
   * <DNT>**Do not block CCU usage**</DNT>: notifique al usuario, pero mantenga el acceso completo a la plataforma. Esto no evita los excesos.

Haga clic en <DNT>**Next**</DNT>.
</Step>

<Step>
### Defina el presupuesto de CCU avanzadas

1. En <DNT>**Budget allocation**</DNT>, ingrese el porcentaje del presupuesto de CCU avanzado de la organización para asignar a cada usuario. El asistente muestra el valor de CCU equivalente a medida que escribe. Los presupuestos de usuario pueden exceder el presupuesto total de la organización.

2. En <DNT>**Limit type**</DNT>, elija qué sucede cuando un usuario alcanza el 100 % del presupuesto de CCU avanzadas:

   * <DNT>**Block CCU usage**</DNT>: notifica al usuario y bloquea el acceso a [Ask AI](/docs/agentic-ai/new-relic-ai), [Live Archives](/docs/logs/get-started/live-archives), [MCP](/docs/agentic-ai/mcp/overview) y [Errors Inbox](/docs/apm/errors-inbox/errors-inbox-ui).
   * <DNT>**Do not block CCU usage**</DNT>: notifique al usuario, pero mantenga el acceso completo a la plataforma. Esto no evita los excesos.

Haga clic en <DNT>**Next**</DNT>.
</Step>

<Step>
### Revisar notificaciones

Esta página confirma los umbrales de notificación que reciben los usuarios para cada medidor de calcular. No se necesita ninguna configuración. Haga clic en <DNT>**Finish**</DNT> para crear el presupuesto global de usuario.
</Step>
</Steps>

## Configurar presupuestos de anulación personalizados

Cree presupuestos de anulación personalizados para los usuarios que necesiten límites diferentes al presupuesto global. Utilice este enfoque al incorporar un equipo o aplicar un límite uniforme a un grupo sin configurar a cada usuario individualmente.

<Steps>
<Step>
### Crear un presupuesto de usuario

Desde la página <DNT>**User Limits**</DNT>, haga clic en <DNT>**Create a user budget**</DNT>. Se abre el asistente <DNT>**Create custom user budget**</DNT>.
</Step>

<Step>
### Establezca la frecuencia y seleccione usuarios

1. En <DNT>**Set the frequency**</DNT>, seleccione con qué frecuencia se restablece el presupuesto:

   * <DNT>**Monthly**</DNT>: realiza un seguimiento del uso a lo largo del mes calendario y se restablece al comienzo de cada mes (UTC).
   * <DNT>**Daily**</DNT>: rastrea el uso a lo largo de cada día calendario y se restablece al inicio de cada día (UTC).

2. En <DNT>**Select users**</DNT>, elija uno o más usuarios en el desplegable para asignar este presupuesto de anulación personalizado. Cuando selecciona varios usuarios, el mismo presupuesto se aplica a cada usuario individualmente —no comparten un solo presupuesto.

Haga clic en <DNT>**Next**</DNT>.
</Step>

<Step>
### Definir presupuesto de CCU principal

1. En <DNT>**Budget allocation**</DNT>, ingrese el porcentaje del presupuesto de CCU principales de la organización para asignar a este usuario. El asistente muestra el valor de CCU equivalente a medida que escribe. Los presupuestos de usuario pueden exceder el presupuesto total de la organización.

2. En <DNT>**Limit type**</DNT>, elija qué sucede cuando el usuario alcanza el 100 % del presupuesto de CCU principales. Esto puede diferir de la configuración del presupuesto global.

   * <DNT>**Block CCU usage**</DNT>: notifique al usuario y bloquee el acceso a las acciones que consumen CCU: ejecutar consultas, actualizar dashboards y realizar llamadas API.
   * <DNT>**Do not block CCU usage**</DNT>: notifique al usuario, pero mantenga el acceso completo a la plataforma. Esto no evita los excesos.

Haga clic en <DNT>**Next**</DNT>.
</Step>

<Step>
### Defina el presupuesto de CCU avanzadas

1. En <DNT>**Budget allocation**</DNT>, ingrese el porcentaje del presupuesto de CCU avanzado de la organización para asignar a este usuario. El asistente muestra el valor de CCU equivalente a medida que escribe. Los presupuestos de usuario pueden exceder el presupuesto total de la organización.

2. En <DNT>**Limit type**</DNT>, elija qué sucede cuando el usuario alcanza el 100 % del presupuesto de CCU avanzado. Esto puede diferir de la configuración del presupuesto global.

   * <DNT>**Block CCU usage**</DNT>: notifica al usuario y bloquea el acceso a [Ask AI](/docs/agentic-ai/new-relic-ai), [Live Archives](/docs/logs/get-started/live-archives), [MCP](/docs/agentic-ai/mcp/overview) y [Errors Inbox](/docs/apm/errors-inbox/errors-inbox-ui).
   * <DNT>**Do not block CCU usage**</DNT>: notifique al usuario, pero mantenga el acceso completo a la plataforma. Esto no evita los excesos.

Haga clic en <DNT>**Next**</DNT>.
</Step>

<Step>
### Revisar notificaciones

Revise los umbrales de notificación que se aplican a este usuario para cada medidor de cómputo. Haga clic en <DNT>**Finish**</DNT> para crear el presupuesto de anulación personalizado.
</Step>
</Steps>

Después de crearlos, los presupuestos de sobrescritura personalizados aparecen en la tabla de presupuestos de usuario como partidas independientes. Puede actualizarlos individualmente o usar el desplegable <DNT>**Group by**</DNT> para ver y administrar los usuarios que comparten la misma asignación, tipo de límite y frecuencia.

## Administrar límites de usuario

### Ver consumo de presupuesto

Los administradores de la organización ven la tarjeta <DNT>**Global user budget**</DNT> en la parte superior de la página <DNT>**Compute Budgets**</DNT>. La tarjeta muestra las cantidades configuradas de CCU principal y CCU avanzada, el porcentaje asignado por usuario y el tipo de límite para cada medidor.

Debajo de la tarjeta, la tabla <DNT>**User budgets**</DNT> muestra los presupuestos de anulación personalizados con las siguientes columnas:

| Columna                  | Descripción                                                                                                                                                  |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Usuario**              | La dirección de correo electrónico del usuario                                                                                                               |
| **Frecuencia**           | Si el presupuesto se restablece de forma diaria o mensual                                                                                                    |
| **Uso principal**        | Consumo actual de CCU principal como porcentaje de la asignación, o **Blocked** si el usuario supera el presupuesto con la opción Block CCU usage habilitada |
| **Asignación principal** | El monto del presupuesto de CCU principal y el tipo de límite configurado (Bloquear o No bloquear)                                                           |
| **Uso avanzado**         | Consumo actual de CCU avanzadas como porcentaje de la asignación, o **Cerca del límite** cuando se acerca al umbral                                          |
| **Asignación avanzada**  | La cantidad del presupuesto de CCU avanzadas y el tipo de límite configurado (Bloquear o No bloquear)                                                        |

Utilice <DNT>**Group by &gt; Allocation, limit, and frequency**</DNT> para agrupar en un clúster a los usuarios que comparten la misma configuración de presupuesto. Cada encabezado de grupo resume la configuración, por ejemplo: `Core CCU 45,000 CCU · Block | Advanced CCU 100,000 CCU · Do not block | Monthly`.

Los **administradores de la organización** pueden hacer lo siguiente:

* Ver todos los presupuestos de anulación personalizados en la tabla con todos los detalles

* Acceda a un menú de tres puntos (**⋯**) junto a cada presupuesto. El menú incluye las siguientes opciones:

  * <DNT>**View**</DNT>: ver información detallada del presupuesto, consumo y tendencias
  * <DNT>**Edit**</DNT>: modificar la configuración del presupuesto
  * <DNT>**Delete**</DNT>: eliminar el presupuesto

Los **usuarios de solo lectura** pueden hacer lo siguiente:

* Ver su propio presupuesto como una línea en la tabla, ya sea una modificación personalizada o un presupuesto global
* Acceda solo a la opción <DNT>**View**</DNT> desde el menú de tres puntos

Los usuarios de solo lectura no pueden ver los presupuestos de otros usuarios ni usar <DNT>**Edit**</DNT> o <DNT>**Delete**</DNT>.

### Vista de detalles del presupuesto [#budget-details]

Cuando ve un presupuesto (disponible para todos los usuarios para su propio presupuesto), puede ver:

* Consumo actual de CCU principal y CCU avanzado
* Porcentaje de cada presupuesto utilizado
* Tendencias de consumo para el período
* Estado de bloqueo al 100 % para cada medidor
* Estado de notificación

### Ajustar presupuestos [#adjust-budgets]

Como administrador de la organización, puede modificar los presupuestos en cualquier momento:

* <DNT>**Edit existing budgets**</DNT>: actualice las cantidades del presupuesto, la frecuencia o los tipos de límite para un solo usuario, o use la vista de grupo para actualizar el presupuesto para todos los usuarios de un grupo a la vez
* <DNT>**Increase a user&apos;s budget**</DNT>: restaure el acceso a los usuarios bloqueados o proporcione capacidad adicional
* <DNT>**Decrease budgets**</DNT>: ajuste los montos del presupuesto para los períodos presupuestarios actuales y futuros
* <DNT>**Delete budgets**</DNT>: elimine tanto los presupuestos globales como los de anulación personalizados. Cuando elimina un presupuesto de anulación personalizado, el usuario vuelve automáticamente al presupuesto de usuario global (si configuró uno).

Los cambios en los presupuestos entran en vigor en aproximadamente 15 minutos.

<Callout variant="important">
Eliminar un presupuesto personalizado no elimina el seguimiento del presupuesto. El seguimiento del presupuesto continúa bajo el presupuesto global (si ha configurado uno).
</Callout>

### Gestionar usuarios bloqueados

Cuando un usuario es bloqueado debido al consumo del presupuesto, puede hacer lo siguiente:

* Ver un mensaje que indica que han utilizado su presupuesto para el período
* Ver los detalles de su presupuesto para verificar el consumo
* Contactarlo para solicitar un aumento de presupuesto

Para restaurar el acceso de un usuario bloqueado, elija una de las siguientes opciones:

* Aumentar su presupuesto. Consulte [Ajustar presupuestos](#adjust-budgets).
* Esperar hasta que el presupuesto se restablezca al inicio del próximo período del presupuesto. Consulte [Frecuencia del presupuesto](#budget-frequency).

<Callout variant="tip">
Publique una lista interna de gerentes de la organización para que los usuarios sepan a quién contactar para solicitar aumentos de límites, y asegúrese de que al menos uno esté disponible para aprobar los aumentos rápidamente durante un incidente de servicio.
</Callout>

## Escenarios comunes

**¿Cuándo se restablecen los presupuestos?** Depende de la frecuencia que seleccionó al configurar el presupuesto:

* **Mensual**: los presupuestos se restablecen al inicio de cada mes calendario (UTC).
* **Diario**: los presupuestos se restablecen al inicio de cada día calendario (UTC).

**¿Qué sucede con las consultas en curso cuando un usuario alcanza el 100 % de su presupuesto de CCU principal?** Las consultas en ejecución se completan. El bloqueo solo evita que se inicien nuevas consultas, cargas de dashboard y llamadas API después de la aplicación del bloqueo. Consulte la nota anterior sobre los retrasos en los informes de datos de consumo.

**¿Qué sucede cuando un usuario alcanza el 100 % de su presupuesto de CCU avanzadas?** Si el tipo de límite de CCU avanzadas está establecido en **Block CCU usage**, los usuarios pierden el acceso a [Ask AI](/docs/agentic-ai/new-relic-ai), [Live Archives](/docs/logs/get-started/live-archives), [MCP](/docs/agentic-ai/mcp/overview) y [Errors Inbox](/docs/apm/errors-inbox/errors-inbox-ui). Si el tipo de límite es **Do not block CCU usage**, los usuarios continúan teniendo acceso completo, pero reciben notificaciones.

**¿Qué le sucede a un usuario cuando elimino su presupuesto de anulación personalizado?** El usuario vuelve automáticamente al presupuesto de usuario global si ha configurado uno. Si no existe un presupuesto global, el usuario tiene acceso sin restricciones.

**¿Qué sucede con los usuarios que no tienen un presupuesto asignado?** Los usuarios sin un presupuesto asignado tienen acceso sin restricciones a dashboard, generador de consultas, llamadas API y características de IA.

**¿Con qué rapidez se hacen efectivos los cambios de presupuesto?** Los cambios de presupuesto se hacen efectivos en aproximadamente 15 minutos.
