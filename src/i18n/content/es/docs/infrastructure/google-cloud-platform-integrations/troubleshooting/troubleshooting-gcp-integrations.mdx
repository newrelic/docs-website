Esta página cubre problemas comunes con las integraciones de Google Cloud Platform (GCP) de New Relic y cómo resolverlos.

## No aparecen datos después de la configuración [#no-data]

### Verifique los conceptos básicos [#no-data-basics]

* Espere 5 minutos después de completar la configuración. Los datos tardan unos minutos en llegar.
* Confirme que seleccionó al menos un servicio durante la configuración.
* Verifique que <DNT>**Stackdriver Monitoring API**</DNT> esté habilitado en su proyecto de GCP.

### Integración de Workload Identity Federation [#no-data-wif]

Si se conectó con la [federación de identidades de workflow (WIF)](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation):

* Verifique que las cinco [API requeridas](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation#step-2) estén habilitadas.
* Confirme que la cuenta de servicio tenga los roles <DNT>**Viewer**</DNT> y <DNT>**Service Usage Consumer**</DNT>.
* Verifique que el rol <DNT>**Workload Identity User**</DNT> esté otorgado a la entidad principal del grupo en su cuenta de servicio.

### Integración de cuenta de servicio [#no-data-sa]

Si se conectó con una [cuenta de servicio de New Relic](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account):

* Verifique que el ID de la cuenta de servicio de New Relic aparezca en el IAM de su proyecto.
* Confirme que tiene los roles <DNT>**Viewer**</DNT> y <DNT>**Service Usage Consumer**</DNT>.
* Si utiliza [restricciones de dominio](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account#reqs), asegúrese de que New Relic esté permitido.

## Errores de autenticación [#auth-errors]

### Reautorizar New Relic [#reauthorize]

Si ve errores de autenticación de API cuando [integra sus servicios de Google Cloud Platform (GCP)](/docs/introduction-google-cloud-platform-integrations) con New Relic, vuelva a autorizar a New Relic para usar sus API de GCP:

1. Vaya a <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP**</DNT>.
2. En la página de tu cuenta de GCP, selecciona <DNT>**Reauthorize New Relic**</DNT>.
3. Siga los procedimientos estándar para [conectar sus servicios de GCP a New Relic](/docs/infrastructure/google-cloud-platform-integrations/get-started/connect-google-cloud-platform-services-new-relic).

Si volver a autorizar no resuelve los errores, puede desvincular la integración y volver a conectarse. Consulte los pasos de desvinculación en su [guía de conexión](/docs/infrastructure/google-cloud-platform-integrations/get-started/connect-google-cloud-platform-services-new-relic).

Los motivos comunes de estos errores incluyen:

* Un usuario revocó manualmente la autorización de New Relic para usar las API de GCP desde la aplicación de administración de cuentas de Google.
* La autorización para que New Relic utilice API de GCP no incluye uno o más de los permisos ([alcances de Google OAuth](https://developers.google.com/identity/protocols/googlescopes)) necesarios para consultar una o más API de GCP.
* La autorización para que New Relic utilice las API de GCP ha caducado.

## Métricas faltantes para un servicio específico [#missing-metrics]

* Confirme que el servicio está habilitado en <DNT>**Infrastructure &gt; GCP &gt; Manage services**</DNT>.
* Verifique que el servicio de GCP en sí esté activo y genere métricas. Algunos servicios solo reportan métricas cuando están en uso.
* Si utiliza un [rol de IAM personalizado](/docs/integrations/google-cloud-platform-integrations/get-started/integrations-custom-roles), verifique que tiene los permisos específicos del servicio para ese servicio.

## Métricas obsoletas o retrasadas [#stale-metrics]

* Verifique las cuotas de la API de monitoreo de la nube de GCP en su proyecto de GCP. Si alcanza los límites de tasa, la recopilación de datos puede ralentizarse. Para solicitar una cuota mayor:

  1. En la consola de Google Cloud, vaya a <DNT>**IAM &amp; Admin &gt; Quotas &amp; System Limits**</DNT>.
  2. Filtrar por <DNT>**Service: Cloud Monitoring API**</DNT>.
  3. Busque la cuota llamada <DNT>**Time series queries per minute**</DNT>, selecciónela y haga clic en <DNT>**Edit Quotas**</DNT> para solicitar un aumento.

* Para las integraciones de WIF, verificar que el token de la cuenta de servicio no haya sido revocado.

* Revise el dashboard de estado de la cuenta en <DNT>**Infrastructure &gt; GCP**</DNT> para ver si hay errores reportados.

## Proyectos de GCP no visibles durante la configuración [#no-projects]

* La cuenta autenticada necesita el permiso `resourcemanager.projects.get` para listar proyectos.
* Como alternativa, use la API de NerdGraph para vincular proyectos por ID sin necesidad de enumerarlos.

## Obtener más ayuda [#get-help]

Si nada de lo anterior resuelve su problema, comuníquese con el soporte de New Relic con:

* Su ID de cuenta de New Relic.
* El ID del proyecto de GCP.
* Qué método de conexión usó (WIF o cuenta de servicio).
* Cualquier mensaje de error que vea en la UI.
