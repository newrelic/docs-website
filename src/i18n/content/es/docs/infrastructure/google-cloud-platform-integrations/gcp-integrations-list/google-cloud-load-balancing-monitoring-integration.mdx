[Las integraciones de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluyen una que informa datos de [Google Cloud Load Balancing](https://cloud.google.com/load-balancing/) a New Relic. Este documento explica cómo activar la integración de GCP Cloud Load Balancing y describe los datos que informa.

## Característica

Cloud Load Balancing es el servicio administrado basado en software de Google Cloud para distribuir el tráfico entre regiones, con compatibilidad para HTTP(S), proxy TCP/SSL y equilibrio de carga L4 (red). La integración de New Relic Load Balancing recopila la tasa de requests, la latencia, el rendimiento de bytes y las métricas de conexión para cada variante de equilibrador de carga.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con la federación de identidades de workload (Workload Identity Federation) (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar con cuenta de servicio o cuenta de usuario](/docs/connect-google-cloud-platform-services-infrastructure)

## Frecuencia de sondeo [#polling]

La integración de New Relic consulta sus servicios de GCP de acuerdo con un intervalo de sondeo que varía según la integración. La frecuencia de sondeo de Google Cloud Load Balancing es de 5 minutos. La resolución es 1 punto de datos cada minuto.

<Callout variant="important">
  Cloud Load Balancing admite intervalos de sondeo de 1 minuto para la integración de WIF en versión preliminar limitada. Para solicitar acceso, comuníquese con el [soporte de New Relic](https://support.newrelic.com/).
</Callout>

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, sus recursos de Cloud Load Balancing aparecen como entidades en el explorador de entidades de New Relic. Para ver el dashboard y administrar los servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas las métricas de Cloud Load Balancing disponibles en el monitoreo de la nube de GCP se recopilan como métricas dimensionales en el tipo de evento `Metric`. Las métricas adicionales más allá de esta tabla se recopilan automáticamente. Consulte la [documentación de métricas de Cloud Load Balancing de Google](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-loadbalancing) para obtener la lista completa.

## Cuenta de servicio o cuenta de usuario [#service-account]

### Buscar y utilizar datos [#find-data]

Después de activar la integración y esperar unos minutos (según la [frecuencia de](#polling) sondeo ), los datos aparecerán en la New Relic UI. Para [buscar y utilizar sus datos](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), incluidos enlaces a su <InlinePopover type="dashboards" />y configuración de alertas, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

Para ver [datos métricos](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics) para su integración de equilibrio de carga de GCP en New Relic, [cree una consulta NRQL ](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql)para [los eventos](/docs/data-apis/understand-data/new-relic-data-types/#event-data) `GcpHttpLoadBalancerSample`, `GcpHttpExternalRegionalLoadBalancerSample`, `GcpInternalHttpLoadBalancerSample`, `GcpTcpSslProxyLoadBalancerSample` y `GcpInternalLoadBalancerSample` y sus atributos relacionados.
