[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa datos de [Google Distributed Cloud Edge](https://cloud.google.com/distributed-cloud/edge) a New Relic. Este documento explica cómo activar la integración <DNT>GCP Distributed Cloud Edge</DNT> y describe los datos que reporta.

## Característica

<DNT>Google Distributed Cloud Edge</DNT> es la plataforma de edge computing local y administrada de <DNT>Google Cloud</DNT> para ejecutar cargas de trabajo de <DNT>Kubernetes</DNT> en hardware propiedad de los clientes. La integración de <DNT>Distributed Cloud Edge</DNT> de New Relic recopila el inventario de hardware y las métricas de estado de las máquinas (nodos) y los clústeres de borde en el despliegue: telemetría de CPU, memoria, disco, red, GPU y energía/PSU, junto con el ciclo de vida del clúster y el estado de la versión.

## Activar la integración [#activate]

<Callout variant="important">
  Esta integración está disponible solo cuando conecta su proyecto de <DNT>GCP</DNT> con <DNT>**Workload Identity Federation**</DNT>. No está disponible para conexiones de cuentas de servicio o cuentas de usuario.
</Callout>

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure) con <DNT>**Workload Identity Federation**</DNT>.

## Frecuencia de sondeo [#polling]

Las integraciones de New Relic consultan los servicios <DNT>GCP</DNT> según un intervalo de sondeo que varía según la integración. La frecuencia de sondeo para <DNT>Google Distributed Cloud Edge</DNT> es de 5 minutos. La resolución es 1 punto de datos cada minuto.

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

New Relic recopila todas las métricas <DNT>Distributed Cloud Edge</DNT> disponibles en <DNT>GCP Cloud Monitoring</DNT> como métricas dimensionales en el tipo de evento `Metric`.

Esta integración no crea entidades en el explorador de entidades de New Relic. Consulte sus métricas directamente en el tipo de evento `Metric`, por ejemplo:

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'gcp.edgecontainer.%' FACET metricName
```

Las métricas contienen las etiquetas de recursos de la máquina o clúster perimetral subyacente, por lo que puede desglosar por nombre de clúster, ID de máquina y ubicación sin una entidad.
