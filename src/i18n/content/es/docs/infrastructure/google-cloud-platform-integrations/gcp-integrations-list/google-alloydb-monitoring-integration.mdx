[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa datos de [Google Cloud AlloyDB](https://cloud.google.com/alloydb) a New Relic. Este documento explica cómo activar la integración de GCP AlloyDB y describe los datos reportados.

## Característica

AlloyDB es un servicio de base de datos compatible con PostgreSQL, completamente administrado y creado para workloads transaccionales y analíticas exigentes. La integración de New Relic AlloyDB recopila métricas de rendimiento, disponibilidad y utilización de recursos en clústeres, instancias, bases de datos y nodos de instancia.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con la federación de identidades de workload (Workload Identity Federation) (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar con cuenta de servicio o cuenta de usuario](/docs/connect-google-cloud-platform-services-infrastructure)

## Frecuencia de sondeo [#polling]

La integración de New Relic consulta sus servicios de GCP de acuerdo con un intervalo de sondeo que varía según la integración. La frecuencia de sondeo para Google Cloud AlloyDB es de 5 minutos. La resolución es 1 punto de datos cada minuto.

<Callout variant="important">
  AlloyDB para PostgreSQL admite intervalos de sondeo de 1 minuto para integraciones de WIF en versión preliminar limitada. Para solicitar acceso, comuníquese con el [soporte de New Relic](https://support.newrelic.com/).
</Callout>

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, sus recursos de AlloyDB aparecen como entidades en el explorador de entidades de New Relic. Para ver los dashboards y administrar los servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Toda la métrica de AlloyDB disponible en el monitoreo de la nube de GCP se recopila como métrica dimensional en el tipo de evento `Metric`. Las métricas adicionales más allá de esta tabla se recopilan automáticamente. Consulte la [documentación de métrica de AlloyDB de Google](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-alloydb) para obtener la lista completa.
