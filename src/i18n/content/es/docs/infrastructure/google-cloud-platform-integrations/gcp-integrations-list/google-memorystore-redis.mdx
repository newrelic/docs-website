[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa los datos de [Google Memorystore for Redis](https://cloud.google.com/memorystore/docs/redis) a New Relic. Este documento explica cómo activar la integración de GCP Memorystore for Redis y describe los datos que reporta.

## Característica

Memorystore for Redis es el servicio de Redis completamente administrado de Google Cloud. La integración de Memorystore for Redis de New Relic recopila métricas de CPU, memoria, red, keyspace, persistencia, replicación y rendimiento de comandos para cada instancia de Redis.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con la federación de identidades de workload (Workload Identity Federation) (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar con cuenta de servicio o cuenta de usuario](/docs/connect-google-cloud-platform-services-infrastructure)

## Frecuencia de sondeo [#polling]

Las integraciones de New Relic consultan sus servicios de GCP según un intervalo de sondeo que varía según la integración. La frecuencia de sondeo de Google Memorystore para Redis es de 5 minutos. La resolución es 1 punto de datos cada minuto.

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, sus instancias de Memorystore para Redis aparecen como entidades en el explorador de entidades de New Relic. Para ver dashboards y administrar servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas las métricas de Memorystore para Redis disponibles en el monitoreo de la nube de GCP se recopilan como métricas dimensionales en el tipo de evento `Metric`. Las métricas adicionales más allá de esta tabla se recopilan automáticamente. Consulte la [documentación de métricas de Memorystore para Redis de Google](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-redis) para obtener la lista completa.
