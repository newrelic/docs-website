[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa datos de [Google Memorystore for Valkey](https://cloud.google.com/memorystore/docs/valkey) a New Relic. Este documento explica cómo activar la integración de GCP Memorystore for Valkey y describe los datos que reporta.

## Característica

Memorystore for Valkey es el servicio de Valkey completamente administrado de Google Cloud, que proporciona un almacén de datos en memoria compatible con Redis de código abierto. La integración de Memorystore for Valkey de New Relic recopila métricas a nivel de instancia y por nodo en CPU, memoria, clientes, keyspace, persistencia y red para cada despliegue de Valkey.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con Workload Identity Federation](/docs/connect-google-cloud-platform-services-infrastructure)

## Frecuencia de sondeo [#polling]

La integración de New Relic consulta sus servicios de GCP de acuerdo con un intervalo de sondeo que varía según la integración. La frecuencia de sondeo de Google Memorystore para Valkey es de 5 minutos. La resolución es 1 punto de datos cada minuto.

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, sus recursos de Memorystore for Valkey aparecen como entidades en el explorador de entidades de New Relic. Para ver los dashboards y administrar los servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas las métricas de Memorystore for Valkey disponibles en el monitoreo de la nube de GCP se recopilan como métricas dimensionales en el tipo de evento `Metric`. Las métricas adicionales más allá de esta tabla se recopilan automáticamente. Consulte la [documentación de métricas de Memorystore de Google](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-memorystore) para obtener la lista completa.
