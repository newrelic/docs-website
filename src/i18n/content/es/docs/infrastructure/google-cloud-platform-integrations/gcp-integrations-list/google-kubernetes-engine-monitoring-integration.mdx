[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa datos de [Google Kubernetes Engine](https://cloud.google.com/kubernetes-engine/) (GKE) a New Relic. Este documento explica cómo activar la integración de GCP Kubernetes Engine y describe los datos que reporta.

## Característica

Google Kubernetes Engine es el servicio administrado de Kubernetes de Google Cloud. La integración de GKE de New Relic recopila la métrica de CPU, memoria, red, volumen y tiempo de actividad en el contenedor, los nodos y el pod que conforman su clúster.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con la federación de identidades de workload (Workload Identity Federation) (recomendado)](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation)
* [Conectar con cuenta de servicio o cuenta de usuario](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account)

## Frecuencia de sondeo [#polling]

La integración de New Relic consulta sus servicios de GCP de acuerdo con un intervalo de sondeo que varía según la integración. La frecuencia de sondeo para Google Kubernetes Engine es de 5 minutos. La resolución es 1 punto de datos cada minuto.

<Callout variant="important">
  **Recomendado: utilice la integración de New Relic Kubernetes para GKE.** Con Workload Identity Federation, la integración de GCP recopila métricas de GKE, pero no crea entidades. Para obtener una observabilidad completa de GKE —entidades de clúster, nodo, pod y contenedor, dashboards y alertas—, instale la [integración de New Relic Kubernetes](https://docs.newrelic.com/docs/kubernetes-pixie/kubernetes-integration/installation/kubernetes-integration-install-configure/) en su clúster de GKE.

  Google Kubernetes Engine (GKE) admite intervalos de sondeo de 1 minuto para integraciones de WIF en versión preliminar limitada. Para solicitar acceso, comuníquese con el [soporte de New Relic](https://support.newrelic.com/).
</Callout>

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

All Google Kubernetes Engine metrics available in GCP Cloud Monitoring are collected as dimensional metrics in the `Metric` event type, under the `gcp.kubernetes.io.*` namespace. Query them directly on the `Metric` event type, for example:

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'gcp.kubernetes.io.%' FACET metricName
```

Metrics carry the resource labels of the underlying Kubernetes object, so you can facet by cluster name, namespace, node name, pod name, and container name.

## Cuenta de servicio o cuenta de usuario [#service-account]

### Buscar y utilizar datos [#find-data]

Después de activar la integración y esperar unos minutos (según la [frecuencia de](#polling) sondeo ), los datos aparecerán en la New Relic UI. Para [buscar y utilizar sus datos](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), incluidos enlaces a su <InlinePopover type="dashboards" />y configuración de alertas, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

Los datos que New Relic recibe de su integración de Google Kubernetes Engine incluyen los siguientes datos métricos. Para obtener más información sobre estas métricas, consulte la documentación de Google sobre [métricas para Kubernetes Engine](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-container).

### GcpKubernetesContenedorMuestra [#GcpKubernetesContainer]
