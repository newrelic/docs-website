[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa datos de [Google Memorystore for Memcached](https://cloud.google.com/memorystore/docs/memcached) a New Relic. Este documento explica cómo activar la integración de GCP Memorystore for Memcached y describe los datos que reporta.

## Característica

Memorystore para datos Memcache es el servicio Memcached completamente administrado de Google Cloud. La integración de New Relic Memorystore para datos Memcache recopila métricas de CPU, memoria, conexión, tasa de aciertos y almacenamiento de elementos a nivel de nodo para cada nodo Memcached.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con la federación de identidades de workload (Workload Identity Federation) (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar con cuenta de servicio o cuenta de usuario](/docs/connect-google-cloud-platform-services-infrastructure)

## Frecuencia de sondeo [#polling]

La integración de New Relic consulta sus servicios de GCP de acuerdo con un intervalo de sondeo que varía según la integración. La frecuencia de sondeo de Google Memorystore para Memcached es de 5 minutos. La resolución es 1 punto de datos cada minuto.

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, sus recursos de Memorystore for Memcached aparecen como entidades en el explorador de entidades de New Relic. Para ver el dashboard y administrar los servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas las métricas de Memorystore para Memcached disponibles en el monitoreo de la nube de GCP se recopilan como métricas dimensionales en el tipo de evento `Metric`. Las métricas adicionales más allá de esta tabla se recopilan automáticamente. Consulte la [documentación de métricas de Memorystore para Memcached de Google](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-memcache) para obtener la lista completa.
