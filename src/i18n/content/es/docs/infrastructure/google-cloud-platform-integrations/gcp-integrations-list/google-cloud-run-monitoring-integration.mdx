[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa datos de [Google Cloud Run](https://cloud.google.com/run) a New Relic. Este documento explica cómo activar la integración de GCP Cloud Run y describe los datos que reporta.

## Característica

Cloud Run es la plataforma de contenedores sin servidor completamente administrada de Google Cloud para ejecutar servicios sin estado y trabajos puntuales. La integración de Cloud Run de New Relic recopila métricas de solicitudes, latencia, uso de contenedores y ejecución en todos los servicios (a través de revisiones) y trabajos.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con la federación de identidades de workload (Workload Identity Federation) (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar con cuenta de servicio o cuenta de usuario](/docs/connect-google-cloud-platform-services-infrastructure)

## Frecuencia de sondeo [#polling]

La integración de New Relic consulta sus servicios de GCP de acuerdo con un intervalo de sondeo que varía según la integración. La frecuencia de sondeo para Google Cloud Run es de 5 minutos. La resolución es 1 punto de datos cada minuto.

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, sus recursos de Cloud Run aparecen como entidades en el explorador de entidades de New Relic. Para ver el dashboard y administrar los servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas las métricas de Cloud Run disponibles en el monitoreo de la nube de GCP se recopilan como métricas dimensionales en el tipo de evento `Metric`. Las métricas adicionales más allá de esta tabla se recopilan automáticamente. Consulte la [documentación de métricas de Cloud Run de Google](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-run) para obtener la lista completa.

## Cuenta de servicio o cuenta de usuario [#service-account]

### Buscar y utilizar datos [#find-data]

Después de activar la integración y esperar unos minutos (según la [frecuencia de](#polling) sondeo ), los datos aparecerán en la New Relic UI. Para [buscar y utilizar sus datos](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), incluidos enlaces a su <InlinePopover type="dashboards" />y configuración de alertas, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

  <tbody>
    <tr>
      <td>
        `container.BillableInstanceTime`
      </td>

      <td>
        Segundos
      </td>

      <td>
        Tiempo facturable agregado de todas las instancias de contenedor de la revisión. Para una instancia de contenedor determinada, el tiempo facturable se produce cuando la instancia de contenedor se inicia o se procesa al menos una solicitud. El tiempo facturable se redondea a los 100 milisegundos más cercanos. Ejemplos: si una revisión con 2 instancias de contenedor ha estado atendiendo tráfico continuamente en el último minuto, el valor es 2s/s con el alineador de &quot;velocidad&quot; predeterminado. Si una revisión recibió una sola solicitud que duró 30 ms en el último minuto, se redondea a 100 ms y se promedia a 1,7 ms/s durante el minuto con el alineador de &quot;velocidad&quot; predeterminado.
      </td>
    </tr>

    <tr>
      <td>
        `container.cpu.AllocationTime`
      </td>

      <td>
