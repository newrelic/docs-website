[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa los datos de [Google Firebase Realtime Database](https://firebase.google.com/products/realtime-database) a New Relic. Este documento explica cómo activar la integración de GCP Firebase Database y describe los datos que reporta.

## Característica

Firebase Realtime Database es la base de datos cloud NoSQL de Google Cloud que permite almacenar y sincronizar datos entre usuarios en tiempo real. La integración de la base de datos de Firebase de New Relic recopila métricas de I/O, red, almacenamiento, conexión y reglas de seguridad para cada namespace de la base de datos.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con la federación de identidades de workload (Workload Identity Federation) (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar con cuenta de servicio o cuenta de usuario](/docs/connect-google-cloud-platform-services-infrastructure)

## Frecuencia de sondeo [#polling]

Las integraciones de New Relic consultan sus servicios de GCP de acuerdo con un intervalo de sondeo que varía según la integración. La frecuencia de sondeo para la base de datos de Firebase de Google Cloud es de 5 minutos. La resolución es 1 punto de datos cada minuto.

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, sus recursos de base de datos de Firebase aparecen como entidades en el explorador de entidades de New Relic. Para ver el dashboard y administrar los servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas las métricas de la base de datos de Firebase disponibles en el monitoreo de la nube de GCP se recopilan como métricas dimensionales en el tipo de evento `Metric`. Las métricas adicionales más allá de esta tabla se recopilan automáticamente. Consulte la [documentación de la métrica de la base de datos de Firebase de Google](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-firebasedatabase) para obtener la lista completa.

### Buscar y utilizar datos [#find-data]

Después de activar la integración y esperar unos minutos (según la [frecuencia de](#polling) sondeo ), los datos aparecerán en la New Relic UI. Para [buscar y utilizar sus datos](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), incluidos enlaces a su <InlinePopover type="dashboards" />y configuración de alertas, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.
