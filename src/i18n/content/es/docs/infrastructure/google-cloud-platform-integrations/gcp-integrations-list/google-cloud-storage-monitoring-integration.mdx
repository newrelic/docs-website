[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa los datos de [Google Cloud Storage](https://cloud.google.com/storage) a New Relic. Este documento explica cómo activar la integración de GCP Cloud Storage y describe los datos que reporta.

## Característica

Google Cloud Storage es el servicio de almacenamiento de objetos de GCP para servir contenido de sitios web, archivo y recuperación ante desastres, y distribuir objetos de datos mediante descarga directa. La integración de New Relic Cloud Storage recopila métricas de solicitudes de API, red, recuento de objetos y bytes almacenados para cada bucket.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con la federación de identidades de workload (Workload Identity Federation) (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar con cuenta de servicio o cuenta de usuario](/docs/connect-google-cloud-platform-services-infrastructure)

## Frecuencia de sondeo [#polling]

La integración de New Relic consulta sus servicios de GCP de acuerdo con un intervalo de sondeo que varía según la integración. La frecuencia de sondeo para Google Cloud Storage es de 5 minutos. La resolución es 1 punto de datos cada minuto.

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, sus buckets de Cloud Storage aparecen como entidades en el explorador de entidades de New Relic. Para ver el dashboard y administrar los servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas las métricas de Cloud Storage disponibles en el monitoreo de la nube de GCP se recopilan como métricas dimensionales en el tipo de evento `Metric`. Las métricas adicionales más allá de esta tabla se recopilan automáticamente. Consulte la [documentación de métricas de Cloud Storage de Google](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-storage) para obtener la lista completa.

## Cuenta de servicio o cuenta de usuario [#service-account]

### Buscar y utilizar datos [#find-data]

Después de conectar la integración a New Relic y esperar unos minutos, los datos aparecerán en la UI de New Relic. Para [encontrar y usar los datos de integración](/docs/telemetry-data-platform/understand-data/new-relic-data-types/), incluidos sus <InlinePopover type="dashboards" />y su configuración de alerta, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; Google Cloud Storage</DNT>.

Para crear un dashboard personalizado para la integración, [cree una consulta](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights) para el `GcpStorageBucketSample` tipo de evento con el valor del proveedor `GcpStorageBucket`.

### GcpStorageBucketSample [#gcp-storage-bucket-sample]

La integración reporta [datos métricos](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics) para todos los valores de `method` y `response_code`:

* `response_code`: El código de respuesta de las solicitudes.
* `method`: El nombre del método API llamado.
