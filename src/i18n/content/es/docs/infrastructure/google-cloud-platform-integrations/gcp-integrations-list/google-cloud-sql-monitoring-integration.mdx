[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que reporta datos de [Google Cloud SQL](https://cloud.google.com/sql/docs/) a New Relic. Este documento explica cómo activar la integración de GCP Cloud SQL y describe los datos que reporta.

## Característica

Cloud SQL es el servicio de base de datos completamente administrado de Google Cloud para MySQL, PostgreSQL y SQL Server. La integración de Cloud SQL de New Relic recopila métricas de CPU, memoria, disco, conexión, replicación y a nivel de base de datos para cada instancia de Cloud SQL y sus bases de datos.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con la federación de identidades de workload (Workload Identity Federation) (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar con cuenta de servicio o cuenta de usuario](/docs/connect-google-cloud-platform-services-infrastructure)

## Frecuencia de sondeo [#polling]

La integración de New Relic consulta sus servicios de GCP de acuerdo con un intervalo de sondeo que varía según la integración. La frecuencia de sondeo para Google Cloud SQL es de 5 minutos. La resolución es 1 punto de datos cada minuto.

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, sus recursos de Cloud SQL aparecen como entidades en el explorador de entidades de New Relic. Para ver el dashboard y administrar los servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas las métricas de Cloud SQL disponibles en el monitoreo de la nube de GCP se recopilan como métricas dimensionales en el tipo de evento `Metric`. Las métricas adicionales más allá de esta tabla se recopilan automáticamente. Consulte la [documentación de métricas de Cloud SQL de Google](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-cloudsql) para obtener la lista completa.

## Cuenta de servicio o cuenta de usuario [#service-account]

### Buscar y utilizar datos [#find-data]

Después de activar la integración y esperar unos minutos (según la [frecuencia de](#polling) sondeo ), los datos aparecerán en la New Relic UI. Para [buscar y utilizar sus datos](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), incluidos enlaces a su <InlinePopover type="dashboards" />y configuración de alertas, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

Para ver [datos métricos](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics) para su integración GCP SQL en New Relic, [cree una consulta NRQL ](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql)para `GcpCloudSqlSample` [evento](/docs/data-apis/understand-data/new-relic-data-types/#event-data) y su atributo relacionado.
