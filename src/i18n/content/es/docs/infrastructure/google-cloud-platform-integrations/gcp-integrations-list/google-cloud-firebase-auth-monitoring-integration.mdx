[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa datos de [Google Firebase Authentication](https://firebase.google.com/products/auth) a New Relic. Este documento explica cómo activar la integración de GCP Firebase Authentication y describe los datos que reporta.

## Característica

Firebase Authentication es el servicio de identidad de Google Cloud que proporciona SDK y proveedores de autenticación fáciles de usar para el inicio de sesión federado, por teléfono, correo electrónico/contraseña y autenticación anónima. La integración de Firebase Authentication de New Relic recopila métricas de verificación telefónica para cada inquilino de Firebase Auth.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con Workload Identity Federation](/docs/connect-google-cloud-platform-services-infrastructure)

## Frecuencia de sondeo [#polling]

Las integraciones de New Relic consultan sus servicios de GCP según un intervalo de sondeo que varía según la integración. La frecuencia de sondeo para Google Cloud Firebase Authentication es de 5 minutos. La resolución es 1 punto de datos cada minuto.

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, sus recursos de Firebase Authentication aparecen como entidades en el explorador de entidades de New Relic. Para ver el dashboard y administrar los servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas las métricas de Firebase Authentication disponibles en el monitoreo de la nube de GCP se recopilan como métricas dimensionales en el tipo de evento `Metric`. Las métricas adicionales más allá de esta tabla se recopilan automáticamente. Consulte la [documentación de métricas de Firebase Authentication de Google](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-firebaseauth) para obtener la lista completa.
