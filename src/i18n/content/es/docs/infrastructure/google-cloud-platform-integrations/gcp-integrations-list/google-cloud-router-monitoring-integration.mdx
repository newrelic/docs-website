[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa los datos de [Google Cloud Router](https://cloud.google.com/network-connectivity/docs/router) a New Relic. Este documento explica cómo activar la integración de GCP Cloud Router y describe los datos que reporta.

## Característica

Cloud Router es el servicio de enrutamiento con BGP completamente administrado de Google Cloud para Cloud VPN, Cloud Interconnect y Cloud NAT. La integración de Cloud Router de New Relic recopila métricas de sesión BGP, anuncio de rutas y gateway NAT (conexiones abiertas, tráfico, paquetes descartados) para cada Cloud Router y Gateway NAT.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con la federación de identidades de workload (Workload Identity Federation) (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar con cuenta de servicio o cuenta de usuario](/docs/connect-google-cloud-platform-services-infrastructure)

## Frecuencia de sondeo [#polling]

La integración de New Relic consulta sus servicios de GCP de acuerdo con un intervalo de sondeo que varía según la integración. La frecuencia de sondeo de Google Cloud Router es de 5 minutos. La resolución es 1 punto de datos cada minuto.

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, sus recursos de Cloud Router aparecen como entidades en el explorador de entidades de New Relic. Para ver el dashboard y administrar los servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas las métricas de Cloud Router disponibles en el monitoreo de la nube de GCP se recopilan como métricas dimensionales en el tipo de evento `Metric`. Las métricas adicionales más allá de esta tabla se recopilan automáticamente. Consulte la [documentación de métricas de Cloud Router de Google](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-router) para obtener la lista completa.
