[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa los datos [Google Cloud Pub/Sub](https://cloud.google.com/pubsub/) a New Relic. Este documento explica cómo activar la integración de GCP Pub/Sub y describe los datos que informa.

## Característica

Como parte de la Google Cloud [solución de análisis](https://cloud.google.com/solutions/stream-analytics) de flujos, el servicio Cloud Pub/Sub ingiere y entrega flujos de eventos para un rápido procesamiento y análisis de datos. La integración de Pub/Sub de New Relic recopila métricas de publicación, entrega, acumulación y retención en temas, suscripciones y snapshots.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con la federación de identidades de workload (Workload Identity Federation) (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar con cuenta de servicio o cuenta de usuario](/docs/connect-google-cloud-platform-services-infrastructure)

## Frecuencia de sondeo [#polling]

La integración de New Relic consulta sus servicios de GCP de acuerdo con un intervalo de sondeo que varía según la integración. La frecuencia de sondeo para Google Cloud Pub/Sub es de 5 minutos. La resolución es 1 punto de datos cada minuto.

<Callout variant="important">
  Cloud Pub/Sub admite un intervalo de sondeo de 1 minuto para la integración de WIF en versión preliminar limitada. Para solicitar acceso, comunicar con el [soporte de New Relic](https://support.newrelic.com/).
</Callout>

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, sus recursos de Pub/Sub aparecen como entidades en el explorador de entidades de New Relic. Para ver el dashboard y administrar los servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas las métricas de Pub/Sub disponibles en el monitoreo de la nube de GCP se recopilan como métricas dimensionales en el tipo de evento `Metric`. Las métricas adicionales más allá de esta tabla se recopilan automáticamente. Consulte la [documentación de métricas de Pub/Sub de Google](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-pubsub) para obtener la lista completa.

## Cuenta de servicio o cuenta de usuario [#service-account]

### Buscar y utilizar datos [#find-data]

Después de activar la integración y esperar unos minutos (según la [frecuencia de](#polling) sondeo ), los datos aparecerán en la New Relic UI. Para [buscar y utilizar sus datos](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), incluidos enlaces a su <InlinePopover type="dashboards" />y configuración de alertas, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

Los temas de Pub/Sub se denominan entidades que representan canales de mensajes, y las suscripción se denominan entidades que representan destinos de mensajes sobre un tema en particular.

Para ver [datos métricos](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics) para su integración GCP Pub/Sub en New Relic, [cree una consulta NRQL ](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql)para `GcpPubSubTopicSample` y `GcpPubSubSubscriptionSample` [evento](/docs/data-apis/understand-data/new-relic-data-types/#event-data) y su atributo relacionado.
