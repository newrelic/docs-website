[Las integraciones de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [<DNT>Google Cloud Platform</DNT> (<DNT>GCP</DNT>)](https://cloud.google.com/) incluyen una que reporta datos de [<DNT>Gemini Enterprise</DNT>](https://cloud.google.com/gemini-enterprise) a New Relic. Este documento explica cómo activar la integración de <DNT>GCP Gemini Enterprise</DNT> y describe los datos reportados.

## Característica

<DNT>Gemini Enterprise</DNT> es la plataforma de <DNT>Google Cloud</DNT> para crear y ejecutar aplicaciones de búsqueda empresarial y de agente de IA, desarrollada en <DNT>Discovery Engine</DNT>. La integración de <DNT>Gemini Enterprise</DNT> de New Relic recopila métricas de requests, latencia y sesión para aplicaciones (motores), agentes, las herramientas que invocan esos agentes y conectores de datos, junto con recuentos de recursos y consumo de cuota por ubicación y por usuario.

## Activar la integración [#activate]

<Callout variant="important">
Esta integración está disponible solo cuando conecta su proyecto de <DNT>GCP</DNT> con <DNT>**Workload Identity Federation**</DNT>. No está disponible para conexiones de cuentas de servicio o cuentas de usuario.
</Callout>

Para habilitar la integración, siga los procedimientos estándar para [conectar el servicio de <DNT>GCP</DNT> a New Relic](/docs/connect-google-cloud-platform-services-infrastructure) con <DNT>**Workload Identity Federation**</DNT>.

## Frecuencia de sondeo [#polling]

Las integraciones de New Relic consultan los servicios <DNT>GCP</DNT> según un intervalo de sondeo que varía según la integración. La frecuencia de sondeo para <DNT>Gemini Enterprise</DNT> es de 5 minutos. La resolución es 1 punto de datos cada minuto.

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, los recursos de <DNT>Gemini Enterprise</DNT> aparecen como entidades en el explorador de entidades de New Relic. Para ver los dashboards y administrar los servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

New Relic recoge la métrica de <DNT>Gemini Enterprise</DNT> disponible en <DNT>GCP Cloud Monitoring</DNT> como métrica dimensional en el tipo de evento `Metric`, por ejemplo:

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'gcp.discoveryengine.%' FACET metricName
```

#### Métricas de ubicación

Las métricas de ubicación son agregados por ubicación para el proyecto. Incluyen los recuentos de recursos, como el número de motores, almacenes de datos, documentos y eventos de usuario, y el volumen de requests de búsqueda. También incluyen el uso, los límites y los recuentos de límites excedidos para más de 140 cuotas de <DNT>Gemini Enterprise</DNT>, que cubren áreas como agentes, generación de imágenes y videos, anclaje web y requests de búsqueda.

La mayoría de las métricas de ubicación son métricas de cuota. Cada cuota se reporta como un máximo de tres métricas, nombradas agregando un sufijo `usage`, `limit` o `exceeded`, por ejemplo, `gcp.discoveryengine.quota.search_requests_regional.usage`. Las métricas de cuota llevan las etiquetas `metric.limit_name` y `metric.regional_location`.

La ubicación también define otra métrica sin cuota, como `gcp.discoveryengine.engines_regional`. <DNT>Google Cloud</DNT> no reporta datos para esta en todos los proyectos y, cuando no lo hace, no aparece en New Relic. Los mismos recuentos también se reportan como métrica de cuota, por ejemplo, `gcp.discoveryengine.quota.engines_regional.usage`.

Para ver la lista completa de las métricas de ubicación, consulte la sección `discoveryengine` de la [referencia de métricas de Cloud Monitoring de Google](https://docs.cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-discoveryengine). New Relic recopila las métricas GA y beta que se enumeran allí.
