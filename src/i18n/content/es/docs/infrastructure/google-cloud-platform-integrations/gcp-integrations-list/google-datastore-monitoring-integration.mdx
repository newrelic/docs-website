[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa los datos de [almacenamiento de datos de Google Cloud](https://cloud.google.com/datastore) a New Relic. Este documento explica cómo activar la integración de almacenamiento de datos de GCP y describe los datos que reporta.

## Característica

Cloud Datastore (almacenamiento de datos) es la base de datos de documentos NoSQL de Google Cloud para aplicaciones web y móviles. La integración de almacenamiento de datos de New Relic recopila métricas de solicitudes de API, lectura/escritura de entidades y escritura de índices, con desgloses por método de API, código de respuesta y tipo de entidad.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con la federación de identidades de workload (Workload Identity Federation) (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar con cuenta de servicio o cuenta de usuario](/docs/connect-google-cloud-platform-services-infrastructure)

## Frecuencia de sondeo [#polling]

Las integraciones de New Relic consultan sus servicios de GCP según un intervalo de sondeo que varía según la integración. La frecuencia de sondeo para el almacenamiento de datos de Google Cloud es de 5 minutos. La resolución es 1 punto de datos cada minuto.

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, sus recursos de almacenamiento de datos aparecen como entidades en el explorador de entidades de New Relic. Para ver el dashboard y administrar los servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas las métricas de almacenamiento de datos disponibles en el monitoreo de la nube de GCP se recopilan como métricas dimensionales en el tipo de evento `Metric`. Las métricas adicionales más allá de esta tabla se recopilan automáticamente. Consulte la [documentación de métricas de almacenamiento de datos de Google](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-datastore) para obtener la lista completa.

## Cuenta de servicio o cuenta de usuario [#service-account]

### Buscar y utilizar datos [#find-data]

Después de activar la integración y esperar unos minutos (según la [frecuencia de](#polling) sondeo ), los datos aparecerán en la New Relic UI. Para [buscar y utilizar sus datos](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), incluidos enlaces a su <InlinePopover type="dashboards" />y configuración de alertas, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

Los datos se adjuntan al siguiente [tipo de evento](/docs/data-apis/understand-data/new-relic-data-types/#event-data):
