[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa datos de [Google Firebase Hosting](https://firebase.google.com/products/hosting) a New Relic. Este documento explica cómo activar la integración de GCP Firebase Hosting y describe los datos que reporta.

## Característica

Firebase Hosting es el servicio de alojamiento completamente administrado de Google Cloud para contenido web estático y dinámico. La integración de Firebase Hosting de New Relic recopila métricas de almacenamiento y salida de red para cada dominio de Firebase Hosting.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con la federación de identidades de workload (Workload Identity Federation) (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar con cuenta de servicio o cuenta de usuario](/docs/connect-google-cloud-platform-services-infrastructure)

## Frecuencia de sondeo [#polling]

La integración de New Relic consulta sus servicios de GCP de acuerdo con un intervalo de sondeo que varía según la integración. La frecuencia de sondeo para Google Cloud Firebase Hosting es de 5 minutos. La resolución es 1 punto de datos cada minuto.

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, sus recursos de Firebase Hosting aparecen como entidades en el explorador de entidades de New Relic. Para ver el dashboard y administrar los servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas las métricas de Firebase Hosting disponibles en el monitoreo de la nube de GCP se recopilan como métricas dimensionales en el tipo de evento `Metric`. Las métricas adicionales más allá de esta tabla se recopilan automáticamente. Consulte la [documentación de métricas de Firebase Hosting de Google](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-firebasehosting) para obtener la lista completa.

## Cuenta de servicio o cuenta de usuario [#service-account]

### Buscar y utilizar datos [#find-data]

Después de activar la integración y esperar unos minutos (según la [frecuencia de](#polling) sondeo ), los datos aparecerán en la New Relic UI. Para [buscar y utilizar sus datos](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), incluidos enlaces a su <InlinePopover type="dashboards" />y configuración de alertas, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

Los datos se adjuntan al siguiente [tipo de evento](/docs/data-apis/understand-data/new-relic-data-types/#event-data):
