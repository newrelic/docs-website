[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa datos de [Firebase App Hosting](https://firebase.google.com/docs/app-hosting) a New Relic. Este documento explica cómo activar la integración de GCP Firebase App Hosting y describe los datos que reporta.

## Característica

Firebase App Hosting es el servicio de alojamiento administrado de Google para aplicaciones web dinámicas renderizadas en el servidor creadas con frameworks como Next.js y Angular. La integración de New Relic Firebase App Hosting recopila el rendimiento de requests y el volumen de tráfico de respuesta para cada backend de App Hosting.

## Activar la integración [#activate]

<Callout variant="important">
  Esta integración está disponible solo cuando conecta su proyecto de GCP con la Workload Identity Federation. No está disponible para conexiones de cuentas de servicio o cuentas de usuario.
</Callout>

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure) con la Workload Identity Federation.

## Frecuencia de sondeo [#polling]

La integración de New Relic consulta sus servicios de GCP de acuerdo con un intervalo de sondeo que varía según la integración. La frecuencia de sondeo para Firebase App Hosting es de 5 minutos. La resolución es 1 punto de datos cada minuto.

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Todas las métricas de Firebase App Hosting disponibles en el monitoreo de la nube de GCP se recopilan como métricas dimensionales en el tipo de evento `Metric`.

Esta integración no crea entidades en el explorador de entidades de New Relic. Consulte sus métricas directamente en el tipo de evento `Metric`, por ejemplo:

```sql
FROM Metric SELECT count(*) WHERE metricName LIKE 'gcp.firebaseapphosting.%' FACET metricName
```
