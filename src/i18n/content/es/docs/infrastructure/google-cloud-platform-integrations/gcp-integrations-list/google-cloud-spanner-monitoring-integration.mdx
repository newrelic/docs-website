[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa los datos de [Google Cloud Spanner](https://cloud.google.com/spanner/) a New Relic. Este documento explica cómo activar la integración de GCP Cloud Spanner y describe los datos que reporta.

## Característica [#features]

Google Cloud Spanner es un servicio de base de datos relacional distribuido globalmente creado para la cloud. La integración de New Relic Spanner recopila métricas de nodo, CPU, almacenamiento, sesión, solicitud de API y consulta para cada instancia de Spanner y las bases de datos alojadas en ella.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con la federación de identidades de workload (Workload Identity Federation) (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar con cuenta de servicio o cuenta de usuario](/docs/connect-google-cloud-platform-services-infrastructure)

## Frecuencia de sondeo [#polling]

La integración de New Relic consulta sus servicios de GCP de acuerdo con un intervalo de sondeo que varía según la integración. La frecuencia de sondeo para Google Cloud Spanner es de 5 minutos. La resolución es 1 punto de datos cada minuto.

<Callout variant="important">
  Cloud Spanner admite intervalos de sondeo de 1 minuto para integraciones de WIF en versión preliminar limitada. Para solicitar acceso, comuníquese con el [soporte de New Relic](https://support.newrelic.com/).
</Callout>

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, sus recursos de Spanner aparecen como entidades en el explorador de entidades de New Relic. Para ver los dashboards y administrar los servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas las métricas de Spanner disponibles en el monitoreo de la nube de GCP se recopilan como métricas dimensionales en el tipo de evento `Metric`. Las métricas adicionales más allá de esta tabla se recopilan automáticamente. Consulte la [documentación de métricas de Spanner de Google](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-spanner) para ver la lista completa.

#### Entidad

<CollapserGroup>
  <Collapser id="entities-table" title="Entidades de Spanner">
    Se sintetiza una entidad `GCPSPANNERINSTANCE` para cada instancia de Spanner, y una entidad `GCPSPANNERDATABASE` para cada base de datos dentro de ella. ## Cuenta de servicio o cuenta de usuario [#service-account]

### Buscar y utilizar datos [#find-data]

Después de activar la integración y esperar unos minutos (según la [frecuencia de](#polling) sondeo ), los datos aparecerán en la New Relic UI. Para [buscar y utilizar sus datos](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), incluidos enlaces a su <InlinePopover type="dashboards" />y configuración de alertas, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

Para ver [datos métricos](/docs/integrations/new-relic-integrations/getting-started/#metric) para su integración de GCP Spanner en New Relic, [cree una consulta NRQL ](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql)para `GcpSpannerInstanceSample` y `GcpSpannerDatabaseSample` [evento](/docs/data-apis/understand-data/new-relic-data-types/#event-data) y su atributo relacionado.
