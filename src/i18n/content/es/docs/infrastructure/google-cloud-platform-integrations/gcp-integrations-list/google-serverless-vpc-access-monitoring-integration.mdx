[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa datos de [Google Cloud Serverless VPC Access](https://cloud.google.com/vpc/docs/serverless-vpc-access) a New Relic. Este documento explica cómo activar la integración de GCP Serverless VPC Access y describe los datos reportados.

## Característica

Serverless VPC Access permite que los servicios Serverless en Google Cloud (Cloud Run, Cloud Functions, App Engine) accedan a recursos de IP interna dentro de una red de VPC a través de conectores administrados. La integración de New Relic VPC Access recopila métricas de recuento de instancias, CPU, memoria y rendimiento de red para cada conector.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con la federación de identidades de workload (Workload Identity Federation) (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar con cuenta de servicio o cuenta de usuario](/docs/connect-google-cloud-platform-services-infrastructure)

## Frecuencia de sondeo [#polling]

La integración de New Relic consulta sus servicios de GCP de acuerdo con un intervalo de sondeo que varía según la integración. La frecuencia de sondeo para Google Cloud Serverless VPC Access es de 5 minutos. La resolución es 1 punto de datos cada minuto.

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, sus conectores de VPC Access aparecen como entidades en el explorador de entidades de New Relic. Para ver los dashboards y administrar los servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas las métricas de Serverless VPC Access disponibles en el monitoreo de la nube de GCP se recopilan como métricas dimensionales en el tipo de evento `Metric`. Las métricas adicionales más allá de esta tabla se recopilan automáticamente. Consulte la [documentación de métricas de Serverless VPC Access de Google](https://cloud.google.com/monitoring/api/metrics_gcp_p_z#gcp-vpcaccess) para obtener la lista completa.

## Cuenta de servicio o cuenta de usuario [#service-account]

### Buscar y utilizar datos [#find-data]

Después de activar la integración y esperar unos minutos (según la [frecuencia de](#polling) sondeo ), los datos aparecerán en la New Relic UI. Para [buscar y utilizar sus datos](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), incluidos enlaces a su <InlinePopover type="dashboards" />y configuración de alertas, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP &gt; (select an integration)</DNT>.

Los datos se adjuntan al siguiente [tipo de evento](/docs/data-apis/understand-data/new-relic-data-types/#event-data):
