[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa datos de [Google Cloud API Gateway](https://cloud.google.com/api-gateway) a New Relic. Este documento explica cómo activar la integración de GCP API Gateway y describe los datos que reporta.

## Característica

Google Cloud API Gateway es un servicio completamente administrado para crear, proteger y realizar el monitoreo de API frente a los servicios de backend de Google Cloud. La integración de API Gateway de New Relic recopila métricas de tráfico de requests y códigos de respuesta para cada gateway, con desgloses por configuración de API y clase de código de respuesta.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con Workload Identity Federation](/docs/connect-google-cloud-platform-services-infrastructure)

## Frecuencia de sondeo [#polling]

La integración de New Relic consulta sus servicios de GCP de acuerdo con un intervalo de sondeo que varía según la integración. La frecuencia de sondeo para API Gateway de Google Cloud es de 5 minutos. La resolución es 1 punto de datos cada minuto.

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, sus recursos de API Gateway aparecen como entidad en el explorador de entidad de New Relic. Para ver el dashboard y administrar los servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas las métricas de API Gateway disponibles en el monitoreo de la nube de GCP se recopilan como métricas dimensionales en el tipo de evento `Metric`. Las métricas adicionales más allá de esta tabla se recopilan automáticamente. Consulte la [documentación de métricas de API Gateway de Google](https://cloud.google.com/monitoring/api/metrics_gcp_a_b#gcp-apigateway) para obtener la lista completa.
