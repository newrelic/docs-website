[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa datos de [Google BigQuery](https://cloud.google.com/bigquery/) a New Relic. Este documento explica cómo activar la integración de GCP BigQuery y describe los datos que reporta.

## Característica

BigQuery es el almacén de datos sin servidor de Google Cloud. La integración de New Relic con BigQuery recopila métricas de consulta, ejecución, almacenamiento y utilización de ranuras tanto a nivel de proyecto como de conjunto de datos.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con la federación de identidades de workload (Workload Identity Federation) (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar con cuenta de servicio o cuenta de usuario](/docs/connect-google-cloud-platform-services-infrastructure)

## Frecuencia de sondeo [#polling]

La integración de New Relic consulta sus servicios de GCP de acuerdo con un intervalo de sondeo que varía según la integración. La frecuencia de sondeo para Google BigQuery es de 5 minutos. La resolución es 1 punto de datos cada minuto.

<Callout variant="important">
  BigQuery admite intervalos de sondeo de 1 minuto para las integraciones de WIF en versión preliminar limitada. Para solicitar acceso, comuníquese con el [soporte de New Relic](https://support.newrelic.com/).
</Callout>

## Activar Tabla métrica [#table-metrics]

La colección de tablas métricas de BigQuery está deshabilitada de forma predeterminada. Esto afecta la métrica enumerada en [GcpBigQueryTableSample](#table-sample). Para recopilar esas métricas, active la configuración &quot;Habilitar tabla métrica&quot; en el menú de configuración de la integración de BigQuery.

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, sus recursos de BigQuery aparecen como entidades en el explorador de entidades de New Relic. Para ver los dashboards y administrar los servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas las métricas de BigQuery disponibles en el monitoreo de la nube de GCP se recopilan como métricas dimensionales en el tipo de evento `Metric`. Las métricas adicionales más allá de esta tabla se recopilan automáticamente. Consulte la [documentación de métricas de BigQuery de Google](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-bigquery) para obtener la lista completa.
