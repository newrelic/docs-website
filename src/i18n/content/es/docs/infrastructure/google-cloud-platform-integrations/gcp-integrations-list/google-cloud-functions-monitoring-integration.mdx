[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa los datos de [Google Cloud Functions](https://cloud.google.com/functions/) a New Relic. Este documento explica cómo activar la integración de GCP Cloud Functions y describe los datos que reporta.

## Característica

Cloud Functions es el servicio de cómputo sin servidor de Google Cloud para funciones basadas en eventos. La integración de Cloud Functions de New Relic recopila métricas de recuento de ejecuciones, tiempo de ejecución, uso de memoria y tasa de errores para cada función.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con la federación de identidades de workload (Workload Identity Federation) (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar con cuenta de servicio o cuenta de usuario](/docs/connect-google-cloud-platform-services-infrastructure)

## Frecuencia de sondeo [#polling]

La integración de New Relic consulta sus servicios de GCP de acuerdo con un intervalo de sondeo que varía según la integración. La frecuencia de sondeo para Google Cloud Functions es de 5 minutos. La resolución es 1 punto de datos cada minuto.

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, sus recursos de Cloud Functions aparecen como entidades en el explorador de entidades de New Relic. Para ver dashboards y administrar servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas las métricas de Cloud Functions disponibles en el monitoreo de la nube de GCP se recopilan como métricas dimensionales en el tipo de evento `Metric`. Las métricas adicionales más allá de esta tabla se recopilan automáticamente. Consulte la [documentación de métricas de Cloud Functions de Google](https://cloud.google.com/monitoring/api/metrics_gcp#gcp-cloudfunctions) para obtener la lista completa.

## Cuenta de servicio o cuenta de usuario [#service-account]

### Buscar y utilizar datos [#find-data]

Después de activar la integración y luego esperar unos minutos (según la [frecuencia de sondeo](#polling)), los datos aparecerán en la UI. Para [ver y utilizar sus datos](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), incluidos enlaces a su <InlinePopover type="dashboards" />y configuración de alerta, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT> y luego seleccione una integración.
