[La integración de New Relic](/docs/infrastructure/introduction-infra-monitoring) con [Google Cloud Platform (GCP)](https://cloud.google.com/) incluye una que informa los datos de [Google Firebase Storage](https://firebase.google.com/products/storage) a New Relic. Este documento explica cómo activar la integración de GCP Firebase Storage y describe los datos que reporta.

## Característica

Firebase Storage es el servicio de almacenamiento de objetos de Google Cloud para contenido generado por el usuario en la aplicación de Firebase, respaldado por depósitos de Cloud Storage. La integración de New Relic Firebase Storage recopila la métrica de evaluación de reglas de seguridad de Firebase Storage para cada depósito.

## Activar la integración [#activate]

Para habilitar la integración, siga los procedimientos estándar para [conectar su servicio de GCP a New Relic](/docs/connect-google-cloud-platform-services-infrastructure):

* [Conectar con la federación de identidades de workload (Workload Identity Federation) (recomendado)](/docs/connect-google-cloud-platform-services-infrastructure)
* [Conectar con cuenta de servicio o cuenta de usuario](/docs/connect-google-cloud-platform-services-infrastructure)

## Frecuencia de sondeo [#polling]

La integración de New Relic consulta sus servicios de GCP de acuerdo con un intervalo de sondeo que varía según la integración. La frecuencia de sondeo para Google Firebase Storage es de 5 minutos. La resolución es 1 punto de datos cada minuto.

## Federación de identidades de workload (Workload Identity Federation) [#wif]

### Buscar y utilizar datos [#find-data-wif]

Después de habilitar la integración, sus depósitos de Firebase Storage aparecen como entidades en el explorador de entidades de New Relic. Para ver el dashboard y administrar los servicios, vaya a <DNT>[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP</DNT>.

Todas las métricas de Firebase Storage disponibles en el monitoreo de la nube de GCP se recopilan como métricas dimensionales en el tipo de evento `Metric`. Consulte la [documentación de métricas de Firebase Storage de Google](https://cloud.google.com/monitoring/api/metrics_gcp_d_h#gcp-firebasestorage) para obtener la lista completa.
