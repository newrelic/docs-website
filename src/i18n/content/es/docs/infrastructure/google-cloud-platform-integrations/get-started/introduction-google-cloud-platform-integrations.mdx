Las integraciones de Google Cloud Platform (GCP) de New Relic son parte de [New Relic Infrastructure](/docs/infrastructure/new-relic-infrastructure/getting-started/introduction-new-relic-infrastructure) y llevan las métricas de sus servicios en la nube al [monitoreo de infraestructura](/docs/infrastructure), donde puede consultar datos, crear dashboards y configurar alertas junto con el resto de su telemetría. Si aún no tiene una cuenta de New Relic, [cree una](https://newrelic.com/signup) antes de comenzar.

## Compare las opciones de conexión [#connect]

<Callout variant="important">
  \*Los intervalos de sondeo de 1 minuto para integraciones de WIF están en versión preliminar limitada y disponibles solo para servicios seleccionados. Servicios que WIF admite actualmente: Managed Service for Apache Kafka, Cloud Dataflow, Cloud Dataproc, Cloud Spanner, Google Kubernetes Engine (GKE), BigQuery, AlloyDB for PostgreSQL, Cloud Load Balancing y Cloud Pub/Sub. Para solicitar acceso, comuníquese con el [soporte de New Relic](https://support.newrelic.com/).
</Callout>

Recomendamos <DNT>**Workload Identity Federation**</DNT> para las nuevas integraciones. Utiliza credenciales de corta duración para una mejor seguridad, cubre un conjunto más amplio de métricas y recopila automáticamente nuevas métricas a medida que GCP las agrega. Si ya tiene una integración de cuenta de servicio, sigue funcionando —puede agregar nuevos proyectos con WIF junto a su configuración existente.

<Callout variant="important">
  * **Mayor ingesta de datos:** WIF recopila todas las métricas de disponibilidad general (GA) y Beta junto con las etiquetas nativas para los servicios de Google Cloud compatibles. La ingesta para el mismo conjunto de servicios suele ser mayor que con la integración basada en cuentas de servicio.
  * **Cargos de la API de Google Cloud:** Google Cloud factura las llamadas API de monitoreo de la nube realizadas por la integración de WIF al proyecto de Google Cloud integrado. Consulte los [precios de observabilidad de Google Cloud](https://cloud.google.com/products/observability/pricing) para obtener más detalles.
</Callout>

Para obtener información sobre los permisos y roles que New Relic necesita para monitorear sus servicios de GCP, consulte [Integración y roles personalizados](/docs/infrastructure/google-cloud-platform-integrations/get-started/integrations-custom-roles).

## Guías de configuración [#setup-guides]

* **Workload Identity Federation (recomendado)**

  * [Integre manualmente su proyecto/carpeta de GCP](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation) — utiliza credenciales de corta duración para mayor seguridad
  * [Automatizar con Terraform](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-workload-identity-federation-terraform) — automatiza la configuración de WIF mediante Terraform

* [Cuenta de servicio de New Relic](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-service-account) — utiliza una cuenta de servicio administrada por New Relic

* [Cuenta de usuario de Google](/docs/infrastructure/google-cloud-platform-integrations/get-started/install-and-configure/connect-gcp-user-account) — usa las credenciales de su cuenta de usuario de Google
