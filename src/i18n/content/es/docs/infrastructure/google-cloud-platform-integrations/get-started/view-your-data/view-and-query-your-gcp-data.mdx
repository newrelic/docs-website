Después de completar el proceso de configuración, los datos de su cuenta de Google Cloud Platform se reportan directamente a New Relic a [intervalos de sondeo](/docs/infrastructure/google-cloud-platform-integrations/get-started/view-your-data/polling-intervals-gcp-integrations) regulares. Sus datos aparecen en la UI de New Relic en unos minutos.

## Ver tus datos de GCP [#view]

Para ver sus datos de GCP:

1. Vaya a <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities)**</DNT>.
2. Busque <DNT>**Google Cloud Platform**</DNT> y seleccione el mosaico.

Para [encontrar y usar sus datos](/docs/infrastructure/integrations/find-use-infrastructure-integration-data), incluidos los enlaces a <InlinePopover type="Dashboards" />y la configuración de alerta, vaya a <DNT>**[one.newrelic.com &gt; All capabilities](https://one.newrelic.com/all-capabilities) &gt; Infrastructure &gt; GCP**</DNT>.

## Consulta tus datos [#query]

Puede ver y reutilizar la consulta NRQL tanto en el dashboard preconfigurado <InlinePopover type="Dashboards" />como en el <DNT>**Events explorer**</DNT>. Esto le permite adaptar las consultas a sus necesidades específicas.

El evento, el dashboard y otros datos están disponibles para todos los servicios en New Relic.

## Entidades de GCP [#entities]

Sus recursos de GCP también aparecen como entidades en el explorador de entidades para los servicios con compatibilidad total con entidades. Cada entidad tiene una página de resumen con métricas doradas y un dashboard prediseñado.

Los nuevos recursos pueden tardar unos minutos en detectarse y sintetizarse como entidades. Para obtener más información, consulte [Límites del sistema de integración en la nube](/docs/data-apis/manage-data/view-system-limits).

## Que sigue [#whats-next]

* Para buscar los nombres de las métricas que New Relic recopila para cada servicio, consulte las [métricas de integración de GCP](/docs/infrastructure/google-cloud-platform-integrations/get-started/gcp-integration-metrics).
* Para comprender con qué frecuencia New Relic sondea sus datos, consulte [Intervalos de sondeo para la integración de GCP](/docs/infrastructure/google-cloud-platform-integrations/get-started/view-your-data/polling-intervals-gcp-integrations).
* Si sus datos no aparecen como se esperaba, consulte [Solucionar problemas de la integración de GCP](/docs/infrastructure/google-cloud-platform-integrations/troubleshooting/troubleshooting-gcp-integrations).
